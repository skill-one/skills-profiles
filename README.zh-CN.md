# skills-profiles

本仓库收集的那些 agent skills，每个写了六个角度的档案，外加把两者连起来的清单。
由 `just index` 从这棵树生成——不要手改。
English: [README.md](README.md)

`skills/<id>/` 是发布的 skill 原件：拷进 skills 目录就等于装上了。
`profiles/<id>/` 是为它写的内容，`skills.jsonl` 是这两者的清单。
