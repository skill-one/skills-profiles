# skills-profiles

The agent skills this repository collects, each labelled with one closed-domain
category by the Jev endpoint and described in Chinese by a chat model, plus the
catalog joining it all. Written by `just index` - generated, so do not edit it.
中文: [README.zh-CN.md](README.zh-CN.md)

`skills/<id>/` holds the skill's own `SKILL.md` with what was written about it -
the domain label and the Chinese `SKILL.zh.md` page, whose front matter carries
the Chinese description - and `skills.jsonl` is the catalog joining them. Beside
the skills, `repos.jsonl` holds each repository's GitHub profile, and
`owners/<owner>.png` each owner's avatar.
