# 落地式销售产品调研 📦

落地式销售业务的产品调研。识别具有可靠供应商、健康利润空间和可控竞争力的盈利产品。评估运输时间、退货风险和营销可行性。

**支持的平台：** Amazon、Shopify、WooCommerce、Walmart、TikTok Shop、Etsy、eBay、BigCommerce。

由 [Nexscope](https://www.nexscope.ai/?co-from=skill) 构建 — 您的用于更智能电子商务决策的AI助手。

## 安装

```bash
npx skills add nexscope-ai/eCommerce-Skills --skill dropshipping-product-research -g
```

## 使用

```
帮我寻找宠物配件领域的落地式销售产品。启动预算为2000美元。我想通过Shopify使用Meta广告进行销售。
```

## 功能

- 落地式销售的可行性评分（利润空间、重量、易碎性、退货风险）
- 供应商可靠性评估框架
- 按起运地/目的地分析运输时间和成本
- 营销角度识别（社交媒体、付费广告、SEO）
- 针对落地式销售细分市场的竞争分析
- 趋势验证和持久性评估

## 该技能的工作原理

**步骤1：** 从用户消息中收集信息 — 产品、平台、当前情况和目标。

**步骤2：** 使用多项选择格式提出一个后续问题，以解决所有剩余问题。允许使用缩写答案（例如，“1b 2c 3a”）。

**步骤3：** 使用下方的框架和方法进行研究和分析。

**步骤4：** 提供结构化、可操作的输出，包含具体建议，而不是模糊的建议。

## 输出格式

- 以调研结果摘要开头
- 在可用的情况下包含具体数据点和基准
- 提供优先行动项
- 当基于不完整数据时，用 ⚠️ 标注估计
- 以具体的下一步行动结束
