# 亚马逊PPC广告活动优化 📢

从零开始构建盈利的PPC广告活动结构，或使用数据驱动的出价调整审计和优化现有活动。无需API密钥——开箱即用。

## 安装

```bash
npx skills add nexscope-ai/Amazon-Skills --skill amazon-ppc -g
```

## 两种模式

| 模式 | 使用场景 | 输入 | 输出 |
|------|-------------|-------|--------|
| **A — 构建新活动** | 为新产品启动PPC | 产品信息 + 关键词 + 利润率 | 完整的活动蓝图 + 关键词分组 + 初始出价 |
| **B — 优化现有活动** | 改进现有活动 | 活动数据 + 搜索词报告 + 当前ACoS | 优化方案 + 出价调整 + 负面关键词列表 |

## 功能

- **ACoS财务框架**：根据产品利润率计算盈亏平衡ACoS、目标ACoS和最大CPC——这是每个出价决策的基础
- **活动架构设计**：构建结构化的自动 → 广泛 → 精确漏斗，并在活动之间进行适当的负面关键词隔离
- **关键词分组**：根据信心水平将关键词组织到活动桶中，并设置匹配类型和初始出价
- **出价优化**：使用行业标准公式（根据ACoS范围按百分比减少/增加出价）应用基于ACoS的出价调整规则
- **关键词漏斗分析**：识别迁移机会（自动→广泛→精确）和浪费的支出（高点击无销量的术语）
- **负面关键词管理**：生成种子列表（跨活动、不相关术语、通用浪费修饰符）并根据搜索词数据持续添加
- **搜索词报告分析**：解析用户提供的活动数据，以查找盈利术语、浪费术语和优化差距
- **竞争对手ASIN定位**：构建针对竞争对手产品页面的产品定位活动
- **集成链**：与 [amazon-keyword-research](https://github.com/nexscope-ai/Amazon-Skills/tree/main/amazon-keyword-research) 集成以获取关键词输入，与 [amazon-listing-optimization](https://github.com/nexscope-ai/Amazon-Skills/tree/main/amazon-listing-optimization) 集成以进行预发布列表质量检查

## 此技能如何收集信息

用户很少一开始就提供所有信息——而且也不需要。此技能采用**渐进式信息收集**方法：

**步骤1：从提示中提取信息。** 解析用户已经提供的内容——ASIN、价格、ACoS数字、活动名称、关键词等。

**步骤2：自动发现。** 如果提供了ASIN，运行捆绑的 `scripts/fetch-competitor.sh <ASIN>` 获取价格、类别、BSR和竞争对手背景。此脚本处理亚马逊的反机器人保护。如果用户提到没有ASIN的产品类型，使用 `web_search` 了解市场。

**步骤3：识别差距。** 将您拥有的与所需的内容进行比较（见下文模式A步骤A1和模式B步骤B1中的所需信息表格）。专注于**关键**信息以继续：
- 模式A关键：**产品成本**（用于计算ACoS）+ **每月广告预算**（用于调整活动规模）+ **关键词或竞争对手ASIN**（用于构建活动）
- 模式B关键：**当前ACoS** + **利润率**（了解差距并设置目标）

**步骤4：一个综合的后续提示。** 仅在一条对话消息中询问缺失的关键信息——而不是问卷：

```
模式A示例：
"I found your product — Paiaite Dog T-Shirt, $5.99 on Amazon. To build your
campaigns, I need three things:
  1. Your product cost per unit (so I can calculate your break-even ACoS)
  2. Your monthly ad budget (so I can size the campaigns right)
  3. Any target keywords or competitor ASINs? (Or I can research for you)"

模式B示例：
"Got it — ACoS is too high. To give you specific actions, can you share:
  1. Your profit margin (or product cost, I'll calculate it)
  2. Which campaigns are running and their rough ACoS?
Search term report data is a bonus but not required to start."
```

**步骤5：在卡住时使用估算。** 如果用户无法提供某些信息（例如，不知道确切费用），使用合理的类别估算，并明确注明假设。永远不要因为等待完美数据而阻塞进度。

## 关键概念

三个公式驱动此技能中的每个建议。它们在这里介绍，并在步骤A2（用于模式A）和步骤B2（用于模式B）中应用。

**盈亏平衡ACoS** = 广告支出前的利润率。如果你的产品在亚马逊费用后以$40的价格销售，成本为$15，你的利润率是$25/$40 = 62.5%。在62.5% ACoS下，你将所有利润都花在广告上——盈亏平衡。

**目标ACoS** = 盈亏平衡ACoS - 期望的利润率。希望在广告后获得25%的利润？目标ACoS = 62.5% - 25% = 37.5%。

**关键词漏斗** = 核心PPC优化循环，应用于步骤A4/A6（构建）和步骤B3（优化）：
```
自动活动（发现新术语）
    ↓ 2+订单的术语
手动广泛活动（在更广泛的匹配中测试）
    ↓ 2+销售的术语
手动精确活动（以精确度扩展赢家）

在每个步骤中：将迁移的术语作为NEGATIVE添加到源活动中，以防止重复支出。
```

## 模式A工作流程——构建活动结构

### 步骤A1：收集产品信息

需要以下详细信息。许多信息可以自动提取（见上文的“此技能如何收集信息”）——仅询问确实缺失的信息。

| 详细信息 | 如何获取 | 是否关键 |
|--------|--------------|:---------:|
| ASIN | 从用户的提示中获取 | 有帮助 |
| 产品名称和类别 | 从ASIN获取或询问 | 有帮助 |
| 销售价格 | 从ASIN获取或询问 | ✅ 是 |
| 产品成本（落地成本） | 必须询问用户 | ✅ 是 |
| 每月广告预算 | 必须询问用户 | ✅ 是 |
| 亚马逊费用（推荐费 + FBA） | 估算~15%推荐费 + FBA按尺寸 | 可以估算 |
| 新产品 vs 成熟产品 | 询问或从上下文中推断 | 有帮助 |

### 步骤A2：计算ACoS目标

使用关键概念中的公式，计算控制所有出价决策的财务框架：

```
📊 PPC 财务框架

销售价格:           $39.99
总成本:             $18.50 (产品 $8 + 运费 $3 + 亚马逊费用 $7.50)
广告前利润:       $21.49
利润率:           53.7%

盈亏平衡ACoS:         53.7% (将所有利润都花在广告上)
目标ACoS（成熟产品）    30.0% (保留~24%的利润率)
目标ACoS（新产品）    50.0% (激进——前4-8周可接受)

目标ACoS下的最大CPC:  $1.20 (在10%的转化率下)
公式: 最大CPC = 销售价格 × 目标ACoS × 转化率
```

如果用户不知道他们的转化率，使用类别基准：10-15%是平均数。

### 步骤A3：收集关键词

关键词可以来自三个来源（使用一个或组合）：

1. **从 [amazon-keyword-research](https://github.com/nexscope-ai/Amazon-Skills/tree/main/amazon-keyword-research) 技能获取**（推荐）：先运行关键词研究，然后将排名关键词列表输入到此技能。
2. **从竞争对手ASIN获取**：用户提供1-3个竞争对手ASIN → 对每个运行 `scripts/fetch-competitor.sh <ASIN>` → 从其标题和要点中提取关键词。脚本返回标题、品牌、要点、价格、类别、BSR和评论数量。
3. **从用户的列表获取**：用户提供自己的关键词（例如，来自Helium 10、搜索词报告或手动研究）。

此外，使用亚马逊自动完成扩展关键词：`curl -s "https://completion.amazon.com/api/2017/suggestions?mid=ATVPDKIKX0DER&alias=aps&prefix=<URL-ENCODED-KEYWORD>" | python3 -c "import sys,json; [print(s['value']) for s in json.load(sys.stdin).get('suggestions',[])]"`

### 步骤A4：构建活动结构和分组关键词

**默认：4个活动。** 这是新产品发布的标准结构：

| 优先级 | 活动 | 它的作用 | 是否始终包含？ |
|:--------:|----------|--------------|:---------------:|
| 1 | **自动发现** | 亚马逊自动匹配您的广告到搜索词——收集购物者实际搜索的数据 | ✅ 是 |
| 2 | **手动精确** | 您的10-15个已证明的精确匹配关键词——最高控制力，最低ACoS | ✅ 是 |
| 3 | **手动广泛** | 所有研究关键词的广泛匹配——发现变体和长尾术语 | ✅ 是 |
| 4 | **产品定位** | 在竞争对手产品页面上显示您的广告——窃取他们的流量 | ✅ 如果有竞争对手ASIN |

**如果预算紧张：** 首先启动优先级1+2（自动 + 精确）。一周后添加优先级3。当您有竞争对手ASIN时添加优先级4。

将关键词组织到这些活动桶中：

查看下文的**模式A输出**模板，以获取每个活动的关键词分组的精确格式。

### 步骤A5：设置初始出价

**最大CPC（来自步骤A2）是您的盈利上限**——不是实际出价。实际竞争出价取决于类别和关键词竞争。

**如何推荐出价：**
1. 计算最大CPC作为财务护栏（您可以负担得起）
2. 对于实际起始出价，告诉用户在Seller Central中创建活动时检查亚马逊的**建议出价范围**——这反映了真实的拍卖数据
3. 如果亚马逊的建议出价 > 最大CPC，标记差距并解释：要么接受损失（排名启动），提高产品价格，或跳过该关键词

**当您没有建议出价数据时**，使用这些类别相对的起始点：
| 活动类型 | 起始出价 | 调整后 |
|--------------|-------------|-------------|
| 手动精确 | 亚马逊建议出价或最大CPC（取较低者） | 7天，点击20+ |
| 手动广泛 | 精确出价的70-80% | 7天 |
| 自动 | 精确出价的50-70% | 7天 |
| 产品定位 | 精确出价的50-70% | 7天 |

**重要：** 这些是起始点。真正的优化发生在1-2周的数据之后——根据每个关键词的实际ACoS进行调整。

### 步骤A6：构建负面关键词种子列表

在启动前生成初始负面关键词列表。三种类型：

1. **跨活动负面**：将所有精确活动关键词作为负面添加到广泛和自动活动中（防止内部竞争——这是关键概念中的关键词漏斗隔离）。
2. **不相关术语负面**：与您的产品共享词语但属于错误类别/意图的术语。例如，对于“竹制切菜板”：
   - 错误材料： "塑料切菜板", "玻璃切菜板"
   - 错误产品： "切菜板油", "切菜板支架"
   - 错误意图： "如何清洁切菜板", "切菜板DIY"
3. **通用浪费负面**：常见的低意图修饰符： "免费", "便宜", "二手", "DIY", "评论", "reddit", "如何"

## 模式B工作流程——优化现有活动

### 步骤B1：收集活动数据

需要以下详细信息。遵循相同的渐进式收集方法——首先从用户的提示中提取，然后在一条后续提示中询问缺失的关键信息（见上文的“此技能如何收集信息”）。

| 详细信息 | 是否关键 | 备注 |
|--------|:---------:|-------|
| 活动名称和类型 | ✅ 是 | 自动/手动/广泛/精确 |
| 整体ACoS | ✅ 是 | 如果有，按活动提供 |
| 每月广告支出和广告销量 | ✅ 是 | 用于预算效率分析 |
| 产品利润率 | ✅ 是 | 用于计算盈亏平衡ACoS |
| 顶级支出关键词及其ACoS | 有帮助 | 启用具体的出价调整 |
| 搜索词报告（CSV） | 奖励 | 启用关键词漏斗分析 |
| CTR和转化率 | 奖励 | 更深入的性能洞察 |

### 步骤B2：性能审计

使用关键概念中的ACoS公式，在五个维度上进行分析： (1) 财务健康——盈亏平衡与当前ACoS，每月利润/亏损； (2) 活动效率——按活动ACoS与 🔴🟡🟢 状态； (3) 关键词性能——按盈利/边际/亏损/零销量分组关键词； (4) 预算分配——支出是否与收入成比例？建议转移； (5) 错过机会——未在手动中的转化术语，没有负面关键词的高支出零销量术语，资金不足的赢家。

### 步骤B3：关键词漏斗分析

应用关键概念中的关键词漏斗到用户的实际数据。三种操作：
- **向上迁移**（2+订单）：自动 → 精确或广泛 → 精确。在源活动中添加为负面。
- **添加负面**（10+点击，0销售）：添加为源活动中的精确或短语负面。
- **观察列表**（<20点击）：数据还不够——标记为下一个审查周期。

### 步骤B4：出价调整

对20+点击的关键词应用基于ACoS的出价调整（最低统计显著性）：
- ACoS > 200%：减少出价30-50%
- ACoS 100-199%：减少出价20%
- ACoS目标+10%到99%：减少出价10-15%
- ACoS等于目标（±10%）：无变化
- ACoS低于目标：增加出价10-20%
- 10+点击0销售：暂停关键词

输出一个表格：关键词 | 当前出价 | 当前ACoS | 新出价 | 原因

### 步骤B5：生成优化行动方案

将步骤B1-B4中的所有内容汇编成优先级行动方案。遵循下文中的**模式B输出**模板。

## 这些活动如何协同工作

标准：4 个活动。如果预算紧张，先启动 P1+P2，其余稍后添加。

  自动（P1）→ 发现新搜索词        ↓ 2+ 订单的词
  广泛（P3）→ 在更宽泛匹配中测试关键词 ↓ 2+ 销售的词
  精确（P2）→ 最佳关键词，最低 ACoS
  产品定向（P4）→ 在竞争对手页面投放广告

分开的活动防止内部竞争（自己与自己竞价）。

如果建议出价 > 你的最高 CPC，该关键词可能无利可图 — 参考财务框架中的⚠️标志获取指导。
