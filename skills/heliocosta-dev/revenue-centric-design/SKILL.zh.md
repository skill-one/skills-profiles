# 以收入为中心的设计

这是从产品设计师 Richard ([@richardrx](https://x.com/richardrx), "为初创公司设计") 提取的 **134 条原则**的精炼指南——Richard 擅长转化率优化、降低用户流失率及应用行为科学（前 Volkswagen、PayPal、IBM 产品设计师）。其核心思想是他提出的 **以收入为中心的设计 (RCD)** 哲学：设计决策应同时服务于用户和业务——既要创造价值，也要产生收入，不可偏废。

在帮助他人改进数字产品（尤其是 SaaS/初创公司）如何 **获取用户、激活用户、留存用户、变现用户或实现差异化** 时使用此技能——例如落地页、用户引导、定价策略、免费试用、用户流失、用户体验流程、功能范围、市场定位或增长策略。

## 核心原则：9 条以收入为中心的设计

1. **中立即省略**——不引导的界面会损害转化率。
2. **对所有人说话的人说服不了任何人**——无目标用户画像 → 泛泛的价值 → 更差的留存率。
3. **先提供价值，再询问**——证明必须在使用户质疑选择之前出现。
4. **你的承诺与你的证明同等重要**——市场相信你展示的，而非你声称的。
5. **同质化竞争价格，差异化竞争品类**——在机制、叙事或体验上形成对比。
6. **默认是你的替用户做的决定**——初始状态定义大众行为。
7. **留存是构建出来的，而非请求来的**——感知到的损失比承诺的收益更能留住用户。
8. **扩展源于使用**——在达到上限时升级，而非通过中断。
9. **价格是筛选器**——定价定义了谁进入、谁留存、谁升级。
