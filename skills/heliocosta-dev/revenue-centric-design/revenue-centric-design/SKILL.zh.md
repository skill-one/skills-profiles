# 以收入为中心的设计

这是从产品设计师 Richard ([@richardrx](https://x.com/richardrx), "为初创公司设计") 提取的 **134 条原则**的精炼指南——Richard 擅长转化率优化、降低用户流失率及应用行为科学（前 Volkswagen、PayPal、IBM）。其核心是他提出的哲学 **以收入为中心的设计 (RCD)**：设计决策应同时服务于用户和业务——既要创造价值，也要产生收入，不能偏废任何一方。

在帮助他人改进数字产品（尤其是 SaaS / 初创公司）如何 **获取、激活、留存、变现或差异化** 时使用此技能——例如落地页、引导流程、定价策略、试用版、用户流失、交互流程、功能范围、市场定位或增长策略。

2. 将建议建立在这些原则之上；引用具体原则，并在用户需要了解原始内容时链接源帖文。
3. 先提出**命名机制**（例如，诱因效应、蔡格尼克效应、瑞士刀指数、GBB、尤金·施瓦茨的 5 个认知层级、损失规避、峰终定律）——命名杠杆本身就是价值。
4. 以证据为导向：许多原则附带研究、数据或案例。保留引用，而不是轻描淡写。

## 核心框架：9 条以收入为中心的设计原则

1. **中立即省略**——不引导的界面会损害转化率。
2. **人人对话无人信**——无目标客户画像 → 泛泛的价值 → 更差的留存率。
3. **先提供价值再询问**——证明必须先于用户质疑其选择。
4. **你的承诺如证据般有力**——市场相信你展示的，而非声称的。
5. **同质化竞争靠价格，差异化竞争靠品类**——在机制、叙事或体验上形成对比。
6. **默认是替用户做的决定**——初始状态定义大众行为。
7. **留存是构建而非请求**——感知到的损失比承诺的收益更能留住用户。
8. **扩展源于使用**——在达到限制时升级，而非通过中断。
9. **价格是筛选器**——定价定义了谁进入、谁留存、谁升级。
