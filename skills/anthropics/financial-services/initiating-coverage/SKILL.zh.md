# 启动覆盖

通过结构化的5任务工作流程创建机构级股票研究报告。每个任务必须单独执行，并使用经过验证的输入。

## 概述

此技能将根据机构标准（摩根大通、高盛、摩根士丹利格式）生成全面的首次覆盖报告。任务将单独执行，每个任务在继续之前都会验证先决条件。

**默认字体**：在整个文档中始终使用Times New Roman（除非用户指定其他字体）。

---

**此技能仅以单任务模式运行。**

```
请求1：任务1 - 公司研究（独立）
           ↓ [用户审查输出并请求下一个任务]
请求2：任务2 - 财务建模（独立）

```

**注意**：任务1和2可以按任何顺序执行。任务3-5有严格的依赖关系，必须在继续之前验证输入。

## 任务1：公司研究

**目的**：研究公司的业务、管理、竞争地位、行业和风险。

**先决条件**：✅ 无（完全独立）
- 公司名称或股票代码

**流程**：
1. 验证提供的公司名称/股票代码
2. 从参考资料/task1-company-research.md加载详细说明
3. 执行定性研究工作流程
4. 交付研究文档

**输出**：公司研究文档（6,000-8,000字）
- 公司概览和历史
- 管理层简介（300-400字 × 3-4名高管）
- 产品和服务分析
- 行业概述
- 竞争分析（5-10家竞争对手）
- 市场规模分析
- 风险评估（8-12个风险）

**文件名**：`[公司]_Research_Document_[日期].md`

**⚠️ 仅交付此1个文件。不要完成总结，不要额外文档。**

**⚠️ 不要走捷径：**
- ✅ 写满完整的6,000-8,000字（不是总结）
- ✅ 完成3-4名高管的所有300-400字简介
- ✅ 彻底分析所有5-10家竞争对手
- ✅ 覆盖4个类别中的所有8-12个风险
- ❌ 不要缩短部分以节省时间
- ❌ 不要跳过任何必需部分

**继续前的验证**：此任务不需要验证。

## 任务2：财务建模

**目的**：提取历史财务数据并构建包含预测和情景的全面Excel财务模型。

**先决条件**：⚠️ 开始前验证
- **必需**：访问公司财务数据
  - 对于上市公司：从SEC EDGAR获取最新10-K文件
  - 对于私营公司：财务报表或可用估计
  - 或：用户提供的预先提取的历史财务数据
- **可选**：公司研究（任务1）以获取业务背景

**输入验证**：
```
开始前 - 选择方法：

选项A：提取财务数据（最常见）
- [ ] 有访问10-K或财务报表？
- [ ] 准备提取3-5年的数据？

选项B：用户提供了预先提取的财务数据
- [ ] 收到历史财务数据文件？
- [ ] 包含损益表、现金流量表、资产负债表（3-5年）？

可选：
- [ ] 公司研究（任务1）完成以获取背景？
```

**流程**：
1. 验证访问财务数据
2. 从参考资料/task2-financial-modeling.md加载详细说明
3. **步骤1**：提取历史财务数据（如果需要）
4. **步骤2+**：构建包含6个基本标签的预测模型
5. 交付Excel模型

**输出**：Excel财务模型 (.xlsx)
- 6个基本标签：
  1. **收入模型** - 产品分解（20-30行）+ 地域分解（15-20行）
  2. **损益表** - 完整的P&L，历史（3-5年）+ 预测（5年）
  3. **现金流量表** - 经营/投资/融资活动，历史+预测
  4. **资产负债表** - 资产/负债/权益，历史+预测
  5. **情景** - 牛市/基准/熊市比较表
  6. **DCF输入** - 为任务3估值准备

**文件名**：`[公司]_Financial_Model_[日期].xlsx`

**⚠️ 仅交付此1个文件。不要完成总结，不要额外文档。**

**⚠️ 不要走捷径：**
- ✅ 如果提取财务数据：提取3个财务报表的所有行项目（3-5年）
- ✅ 构建所有6个预测标签，并包含完整细节

- ✅ 构建完整的损益表，包含40-50行项目（不是简化的）
- ✅ 包含完整的现金流量表和资产负债表，包含所有行项目
- ✅ 完成所有三个情景（牛市/基准/熊市）的不同参数
- ❌ 不要创建简化/简化的版本
- ❌ 不要跳过任何6个基本标签
- ❌ 不要跳过历史财务数据提取（如果需要）

**继续到任务3前的验证**：
- [ ] 历史财务数据提取（如果需要）或提供
- [ ] Excel文件创建并可打开
