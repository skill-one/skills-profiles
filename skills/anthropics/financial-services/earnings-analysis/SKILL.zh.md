# 股票研究 盈利更新

创建专业的 **盈利更新报告**，分析已覆盖公司的季度业绩，遵循机构标准（摩根大通、高盛、摩根士丹利格式）。

**主要特点：**
- **长度**：8-12页
- **字数**：3,000-5,000字
- **表格**：1-3个总结表格（非全面性）
- **图表**：8-12个图表
- **交付时间**：1-2天（在盈利发布后的24-48小时内）
- **受众**：已熟悉该公司的客户
- **重点**：新内容 - 超额/未达预期，更新预估，投资逻辑影响
- **字体**：全文使用Times New Roman（除非用户另有指定）

## 使用场景

在以下情况下使用：
- 用户请求："为[公司]创建2024年Q3盈利更新"
- 用户请求："分析[公司]的季度业绩"
- 用户请求："盈利发布后[公司]的报告"
- 用户请求："为[公司]的Q1/Q2/Q3/Q4更新"

**不使用情况：**
- 用户请求"首次覆盖报告" → 使用不同技能
- 用户请求"快讯"或"简报" → 不同格式
- 公司尚未被覆盖 → 需要先进行首次覆盖

## 关键要求

### 1. 速度与及时性
- 在盈利发布后的24-48小时内发布
- 只关注新信息
- 不要过多重复公司背景

### 2. 超额/未达预期分析
- 首先说明公司是否超额或未达预期
- 定量差异（例如："收入超额1200万美元或3%"）
- 解释结果为何与预期不同

### 3. 总结格式
- 表格保持在1-3个（仅总结，非全面性）
- 无完整的损益表/现金流量表/资产负债表（仅关键指标）
- 假设读者已看过首次覆盖报告

### 4. 引用与来源归属 ⭐⭐⭐ 必须执行

**关键**：所有数据必须使用具体来源和可点击的超级链接进行引用。

**在所有图表和表格中包含具体引用和可点击的超级链接：**

```
来源：2024年Q3 10-Q文件，2024年11月8日发布；公司盈利发布
        [超级链接"10-Q"到：https://www.sec.gov/cgi-bin/viewer?accession=...]
        [超级链接"盈利发布"到：https://investor.company.com/news/q3-2024]
```

**超级链接在Word中的显示方式：**
- 文件名显示为蓝色、下划线的可点击链接
- 读者可Ctrl+点击直接打开来源
- 不是纯文本URL - 带有显示文本的格式化超级链接

**必须引用的来源列表：**

在每次盈利更新中引用：
- ✅ 盈利发布（日期和URL）
- ✅ 10-Q文件（文件日期和EDGAR链接）
- ✅ 盈利电话会议记录（日期）
- ✅ 投资者演示/补充材料（如有）
- ✅ 一致预期来源（彭博/FactSet等，日期）
- ✅ 先前指引（来自上一季度的材料）

**带可点击超级链接的参考部分：**

在报告末尾包含"来源"部分：

```
来源与参考

盈利材料（2024年Q3）：
• 盈利发布（2024年11月7日）
  [超级链接整行到：https://investor.company.com/news/q3-2024-earnings]

• 表格10-Q（2024年11月8日提交）
  [超级链接到：https://www.sec.gov/cgi-bin/viewer?accession=...]

• 盈利电话会议记录（2024年11月7日）
  [超级链接到：https://seekingalpha.com/article/...]

• 投资者演示（2024年11月7日）
  [超级链接到：https://investor.company.com/presentations/q3-2024.pdf]
```

**验证清单：**
- [ ] 每个图表都有具体文件和日期的来源
- [ ] 每个表格都有文件引用的来源
- [ ] 超额/未达预期分析引用了一致预期来源和日期
- [ ] 指引变化引用了当前和先前指引来源
- [ ] 关键统计数据有脚注
- [ ] 来源部分列出了所有材料及URL
- [ ] 所有URL都是可点击的超级链接（不是纯文本）
- [ ] 所有SEC文件都超级链接到EDGAR查看器

### 5. 更新预估
- 根据结果更新前瞻性预估
- 清晰显示旧预估与新预估
- 解释变化的原因

## 高级工作流程

盈利更新流程分为5个阶段：

### 阶段1：数据收集（30-60分钟）

**🚨🚨🚨 训练数据已过时 🚨🚨🚨**

**开始前 - 按顺序完成以下4步：**
1. **检查当前日期** - 记下当前日期
2. **搜索最新数据** - 使用网络搜索："[公司]最新盈利结果"
3. **验证日期** - 确认盈利发布在最近3个月内
4. **检查电话会议记录日期** - 确认记录日期与发布日期一致

**常见错误**：使用训练数据中的过时盈利电话会议记录，而不是搜索最新数据。

**要求：**
- ✅ 搜索最新盈利 - 不要依赖训练数据
- ✅ 记下当前日期和找到的发布日期
- ✅ 确认发布日期在当前日期的3个月内
- ✅ 确认记录日期与发布日期一致
- ✅ 如果日期不匹配或已过期（>3个月），重新搜索

**参考[参考资料/工作流程.md](references/workflow.md)**了解详细的搜索程序和验证步骤。

### 阶段2：分析（2-3小时）
- 每个关键指标的超额/未达预期分析
- 分段/地理区域/产品分析
- 利润率和指引分析
- 更新财务模型和预估

**参考[参考资料/工作流程.md](references/workflow.md)**了解详细的分析框架。

### 阶段3：图表生成（1-2小时）
创建8-12个图表，重点关注季度趋势和新内容：
- 季度收入进展
- 季度EPS进展
- 季度利润率趋势
- 收入按分段/地理区域划分
- 关键运营指标
- 超额/未达预期总结
- 预估修订
- 估值图表

**参考[参考资料/工作流程.md](references/workflow.md)**了解图表规格。

### 阶段4：报告创建（2-3小时）
创建8-12页DOCX报告，具有特定结构。

**参考[参考资料/报告结构.md](references/report-structure.md)**了解完整的逐页模板和格式要求。

**高级结构：**
- 第1页：盈利总结，评级和目标价
- 第2-3页：详细结果分析
- 第4-5页：关键指标和指引
- 第6-7页：更新投资逻辑
- 第8-10页：估值和预估
- 第11-12页：附录（可选）

### 阶段5：质量检查与交付（30分钟）
在交付前验证内容、格式、准确性和及时性。

**参考[参考资料/最佳实践.md](references/best-practices.md)**了解质量清单和常见错误避免方法。

## 输出规范

**主要交付物**：DOCX报告（8-12页）
**文件名**：`[公司]_Q[季度]_[年份]_盈利更新.docx`
**示例**：`Nike_Q2_FY24_Earnings_Update.docx`

**内容：**
- 第1页：总结，评级，目标价，关键要点
- 第2-3页：详细结果分析
- 第4-5页：关键指标和指引
- 第6-7页：更新逻辑评估
- 第8-10页：估值和预估
- 第11-12页：附录（可选）
- 8-12个嵌入图表
- 1-3个总结表格
- 完整的带可点击超级链接的来源部分

**可选交付物**：XLS模型更新（盈利更新可选）
