# 可比公司分析

## ⚠️ 重要提示：数据源优先级（请首先阅读）

**始终遵循以下数据源层级：**

1. **首选：检查MCP数据源** - 如果有S&P Kensho MCP、FactSet MCP或Daloopa MCP可用，请仅使用它们获取财务和交易信息
2. **如果上述MCP数据源可用，请勿使用网络搜索**
3. **只有在MCP不可用时：** 然后使用彭博终端、SEC EDGAR文件或其他机构来源
4. **切勿将网络搜索作为主要数据源** - 它缺乏机构级分析所需的准确性、审计追踪和可靠性

**为什么这很重要：** MCP来源提供经过验证的、机构级的數據，并具有正确的引用。网络搜索结果可能过时、不准确或不适用于财务分析。

## 概述
本技能教導Claude构建机构级的可比公司分析，该分析结合了运营指标、估值倍数和统计基准测试。输出是一个结构化的Excel/电子表格，通过同行比较使投资决策更加明智。

**参考材料和背景信息：**

提供了一个可比公司分析的示例，位于`examples/comps_example.xlsx`。在使用此示例文件或其他此技能目录中的示例文件时，请智能地使用它们：

**应使用示例进行：**
- 理解结构层次（部分如何流动）
- 掌握预期的严谨程度（统计深度、文档标准）
- 学习原则（清晰的标题、透明的公式、审计追踪）

**不应使用示例进行：**
- 精确复制格式或指标
- 不考虑上下文而复制布局
- 不论受众如何都应用相同的视觉风格

**始终首先问自己：**
1. **“你有首选格式，还是我应该调整模板样式？”**
2. **“受众是谁？”**（投资委员会、董事会演示、快速参考、详细备忘录）
3. **“关键问题是什么？”**（估值、增长分析、竞争定位、效率）
4. **“背景是什么？”**（并购评估、投资决策、行业基准测试、绩效评估）

**根据具体情况调整：**
- **行业背景**：大型科技巨头需要不同的指标，而新兴SaaS初创公司则不同
- **行业特定需求**：尽早添加相关指标（例如，云ARR、企业客户、开发者生态系统，适用于科技行业）
- **公司熟悉程度**：知名公司可能需要较少的背景信息，更多关注增量分析
- **决策类型**：并购需要不同的侧重点，而不是持续的投资组合监控

**核心原则：** 使用模板原则（清晰的结构、统计严谨性、透明的公式），但根据背景变化执行。目标是机构级分析，而不是机构级外观的模板。

用户提供的示例和明确偏好始终优先于默认值。

## 核心理念
**“先构建正确的结构，然后让数据讲述故事。”**

从迫使战略思考什么重要的标题开始，输入干净的数据，构建透明的公式，并让统计数据自动出现。一个好的可比公司分析应该能够被任何没有构建它的人立即阅读。

## ⚠️ 重要提示：公式优先于硬编码 + 逐步验证

**环境 — Office JS与Python：**
- **如果在Excel（Office插件/Office JS）中运行：** 直接使用Office JS (`Excel.run(async (context) => {...})`)。通过`range.formulas = [["=E7/C7"]]`编写公式，而不是`range.values`。无需单独的重新计算步骤——Excel原生处理。使用`range.format.*`设置颜色/字体。
- **如果生成独立的.xlsx文件：** 使用Python/openpyxl。编写`cell.value = "=E7/C7"`（公式字符串）。
- 原则相同——只需转换API调用。
- **Office JS合并单元格陷阱：** 不要调用`.merge()`然后对合并范围设置`.values`（会抛出`InvalidArgument`——范围仍然报告其合并前的维度）。相反，仅将值写入左上角单元格，然后合并+格式化整个范围：
  ```js
  ws.getRange("A1").values = [["TECHNOLOGY — COMPARABLE COMPANY ANALYSIS"]];
  const hdr = ws.getRange("A1:H1");
  hdr.merge();
  hdr.format.fill.color = "#1F4E79";
  hdr.format.font.color = "#FFFFFF";
  hdr.format.font.bold = true;
  ```

**公式，而不是硬编码：**
- 每个派生值（利润率、倍数、统计数据）必须是引用输入单元格的Excel公式——绝不能粘贴预计算的数字
- 当使用Python/openpyxl构建表格时：编写`cell.value = "=E7/C7"`（公式字符串），而不是`cell.value = 0.687`（计算结果）
- 唯一硬编码的值应该是原始输入数据（收入、EBITDA、股价等）——而且其中每一个都应该带有其来源的单元格注释
- 为什么：模型必须在输入更改时自动更新。硬编码的利润率是一个潜伏的沉默错误。

**逐步与用户验证：**
- 设置结构后 → 在填充数据前向用户展示标题布局
- 输入原始输入后 → 向用户展示输入块并确认来源/期间，然后再构建公式
- 构建运营指标公式后 → 向用户展示计算出的利润率并与用户进行合理性检查，然后再转向估值
- 构建估值倍数后 → 向用户展示倍数并确认它们是否合理，然后再添加统计数据
- 不要端到端构建整个表格然后呈现它——通过确认每个部分来尽早捕获错误

## 第1节：文档结构 & 设置

### 标题块（第1-3行）
```
第1行：[分析标题] - 可比公司分析
第2行：[公司列表及股票代码] • [公司1（TICK1）] • [公司2（TICK2）] • [公司3（TICK3）]
第3行：截至[期间] | 除每股金额和比率外，所有金额均以[百万/十亿美元]计
```

**为什么这很重要：** 立即建立背景。打开此文件的人知道他们在看什么，创建时间以及如何解释数字。

### 视觉约定标准（可选 - 用户的格式偏好和上传的模板始终优先）

**重要提示：** 这些只是建议默认值。始终优先考虑：
1. 用户的明确格式偏好
2. 来自任何上传模板文件的格式
3. 公司/团队风格指南
4. 如果没有其他指导，则使用这些默认值

**建议的字体和排版：**
- **字体家族**：Times New Roman（专业、易读、行业标准）
- **字体大小**：数据单元格11pt，标题12pt
- **粗体文本**：部分标题、公司名称、统计标签

**默认颜色和阴影——专业的蓝灰色调（越少越好）：**
- **保持克制**——仅使用蓝色和灰色。不要引入绿色、橙色、红色或多种强调色。干净的可比公司表格总共使用3-4种颜色。
- **部分标题**（例如，“运营统计数据 & 财务指标”）：
  - 深蓝色背景（`#1F4E79`或`#17365D`海军蓝）
  - 白色粗体文本
  - 跨所有列的整行阴影
- **列标题**（例如，“公司”、“收入”、“利润率”）：
  - 浅蓝色背景（`#D9E1F2`或类似的淡蓝色）
  - 黑色粗体文本
  - 居中排列
- **数据行**：
  - 白色背景用于公司数据
  - 黑色文本用于公式；蓝色文本用于硬编码输入
- **统计行**（最大值、75分位数等）：
  - 浅灰色背景（`#F2F2F2`）
  - 黑色文本，左对齐标签
- **这就是整个调色板**：深蓝 + 浅蓝 + 浅灰 + 白色。除非用户模板另有说明，否则不要添加其他颜色。

**建议的格式约定：**
- **小数精度**：
  - 百分比：1位小数（12.3%）
  - 倍数：1位小数（13.5x）
  - 美元金额：无小数，千位分隔符（69,632）
  - 利润率显示为百分比：1位小数（68.7%）
- **边框**：无边框（干净、简洁的外观）
- **对齐**：所有指标居中对齐，以获得干净、统一的外观
- **单元格尺寸**：所有列宽度应均匀/相等，所有行高度应一致（创建干净、专业的网格）

**注意：** 如果用户提供模板文件或指定不同的格式，请使用该文件。

## 第2节：运营统计数据 & 财务指标

### 核心列（从这些开始）
1. **公司** - 具有一致格式的名称
2. **收入** - 规模指标（根据背景可能是LTM、季度或年度）
3. **收入增长** - 同比百分比变化
4. **毛利润** - 收入减去销货成本
5. **毛利率** - GP/收入（基本盈利能力）
6. **EBITDA** - 利息、税、折旧、摊销前收益
7. **EBITDA利润率** - EBITDA/收入（运营效率）

### 可选添加（根据行业/目的选择）
- **季度与LTM** - 如果季节性重要，则包含两者
- **自由现金流** - 适用于资本密集型或SaaS业务
- **FCF利润率** - FCF/收入（现金流生成效率）
- **净利润** - 适用于成熟、盈利的公司
- **营业利润** - 适用于具有不同折旧和摊销的业务
- **CapEx指标** - 适用于资产密集型行业
- **规则40** - 专门针对SaaS（增长率% + 利润率%）
- **FCF转换率** - 用于质量收益分析（高级）

### 公式示例（以第7行为例）
```excel
// 核心比率 - 这些总是计算的
毛利率（F7）：=E7/C7
EBITDA利润率（H7）：=G7/C7

// 可选比率 - 如果相关则包含
FCF利润率：=[FCF]/[收入]
净利润率：=[净利润]/[收入]
规则40：=[增长率%]+[FCF利润率%]
```

**黄金法则：** 每个比率应该是[某项] / [收入]或[某项] / [此表格中的某项]。保持简单。

### 统计块（公司数据之后）

**重要提示：** 必须为所有可比指标（比率、利润率、增长率、倍数）添加统计公式。

```
留出一个空白行用于视觉分隔
- 最大值：=MAX(B7:B9)
- 75分位数：=QUARTILE(B7:B9,3)
- 中位数：=MEDIAN(B7:B9)
- 25分位数：=QUARTILE(B7:B9,1)
- 最小值：=MIN(B7:B9)
```

**需要统计的列（可比指标）：**
- 收入增长率%、毛利率%、EBITDA利润率%、EPS
- EV/收入、EV/EBITDA、P/E、股息收益率%、贝塔

**不需要统计的列（规模指标）：**
- 收入、EBITDA、净利润（绝对规模因公司规模而异）
- 市值、企业价值（不同规模的跨公司不可比）

**注意：** 在公司数据和统计行之间添加一个空白行进行视觉分隔。不要添加“行业统计数据”或“估值统计数据”标题行。

**为什么分位数很重要：** 它们显示分布，而不仅仅是平均值。75分位数倍数告诉你“溢价”公司交易在什么水平。

## 第3节：估值倍数 & 投资指标

### 核心估值列（从这些开始）
1. **公司** - 与运营部分相同的顺序
2. **市值** - 当前市场估值
3. **企业价值** - 市值 ± 净债务/现金
4. **EV/收入** - 市场为每美元销售额支付多少
5. **EV/EBITDA** - 市场为每美元收益支付多少
6. **P/E比率** - 价格相对于净利润

### 可选估值指标（根据背景选择）
- **FCF收益率** - FCF/市值（用于现金流分析）
- **PEG比率** - P/E/增长率（用于增长型公司）
- **市净率** - 市值与账面价值（适用于资产密集型业务）
- **ROE/ROA** - 返回指标（用于盈利能力比较）
- **收入/EBITDA CAGR** - 历史增长率（用于趋势分析）
- **资产周转率** - 收入/资产（用于运营效率）
- **债务/权益** - 杠杆（用于资本结构分析）

**关键原则：** 包含3-5个对您行业重要的核心倍数。不要因为可以而包含每个可能的指标。

### 公式示例
```excel
// 核心倍数 - 总是包含这些
EV/收入：=[企业价值]/[LTM收入]
EV/EBITDA：=[企业价值]/[LTM EBITDA]
P/E比率：=[市值]/[净利润]

// 可选倍数 - 如果数据可用则包含
FCF收益率：=[LTM FCF]/[市值]
PEG比率：=[P/E]/[增长率%]
```

### 跨参考规则
**重要提示：** 估值倍数必须引用运营指标部分。绝不能两次输入相同的原始数据。如果收入在C7，则EV/收入公式应引用C7。

### 统计块
与运营部分结构相同：最大值、75分位数、中位数、25分位数、最小值。在公司数据和统计之间添加一个空白行进行视觉分隔。不要添加“估值统计数据”标题行。

## 第4节：注释 & 方法论文档

### 必须包含的组件

**数据源 & 质量：**
- 数据来自哪里？（S&P Kensho MCP、FactSet MCP、Daloopa MCP、彭博、SEC文件）
- 它涵盖什么期间？（2024年第四季度、审计数据）
- 它是如何验证的？（与10-K/10-Q交叉核对）
- 注意：如果可用，优先考虑MCP数据源（S&P Kensho、FactSet、Daloopa）以获得更好的准确性和可追溯性

**关键定义：**
- EBITDA计算方法（毛利润 + 折旧和摊销，或营业利润 + 折旧和摊销）
- 自由现金流公式（营业现金流 - CapEx）
- 特殊指标解释（规则40、FCF转换率）
- 期间定义（LTM、CAGR计算期间）

**估值方法论：**
- 企业价值是如何计算的？（市值 + 净债务）
- 使用了哪些增长率？（历史CAGR、前瞻性估计）
- 是否进行了任何调整？（排除一次性项目、标准化利润率）

**分析框架：**
- 投资假设是什么？（云/SaaS效率）
- 最重要的指标是什么？（现金流生成、资本效率）
- 读者应该如何解释统计数据？（分位数提供背景）

## 第5节：选择正确的指标（决策框架）

### 首先问“我正在回答什么问题？”

**“哪家公司被低估了？”**
→ 重点关注：EV/收入、EV/EBITDA、P/E、市值
→ 跳过：运营细节、增长指标

**“哪家公司效率最高？”**
→ 重点关注：毛利率、EBITDA利润率、FCF利润率、资产周转率
→ 跳过：规模指标、绝对金额

**“哪家公司增长最快？”**
→ 重点关注：收入增长率%、EBITDA CAGR、用户/客户增长
→ 跳过：利润率指标、杠杆比率

**“哪家是最好的现金流生成者？”**
→ 重点关注：FCF、FCF利润率、FCF转换率、CapEx强度
→ 跳过：EBITDA、P/E比率

### 行业特定指标选择

**软件/SaaS：**
必须包含：收入增长率、毛利率、规则40
可选：ARR、净美元留存、CAC回收期
跳过：资产周转率、库存指标

**制造业/工业：**
必须包含：EBITDA利润率、资产周转率、CapEx/收入
可选：ROA、库存周转率、订单积压
跳过：规则40、SaaS指标

**金融服务：**
必须包含：ROE、ROA、效率比率、P/E
可选：净息差、贷款损失准备
跳过：毛利率、EBITDA（对银行没有意义）

**零售/电子商务：**
必须包含：收入增长率、毛利率、库存周转率
可选：同店销售额、客户获取成本
跳过：重研发或CapEx指标

### “5-10规则”

**5个运营指标** - 收入、增长、2-3个利润率/效率指标
**5个估值指标** - 市值、EV、3个倍数
**= 10个总列** - 足够讲述故事，但不会让你迷失方向

如果你有超过15个指标，你很可能包含了一些噪音。无情地编辑。

## 第6节：最佳实践 & 质量检查

### 开始之前
1. **定义同行群体** - 公司必须是真正可比的（相似的商业模式、规模、地理区域）
2. **选择正确的期间** - LTM平滑季节性；季度显示趋势
3. **提前标准化单位** - 百万与十亿的决策会影响一切
4. **映射数据源** - 了解每个数字的来源

### 在构建过程中
1. **首先输入所有原始数据** - 在编写公式之前完成蓝色文本
2. **对所有硬编码输入添加单元格注释** - 右键单击单元格 → 插入注释 → 记录来源或假设

   **对于来源数据，精确引用其来源：**
   - 示例："彭博终端 - MSFT 股票 DES，访问 2024-10-02"
   - 示例："2024年第四季度 10-K文件，第42页，'总收入'项目"
   - 示例："截至 2024-10-02 的 FactSet 一致预期"
   - **尽可能包含超链接**：右键单击单元格 → 链接 → 粘贴 SEC 文件、数据源或报告的 URL

   **对于假设，解释推理：**
   - 示例："基于同行中位数假设 15% 的 EBITDA 利润率，公司不披露"
   - 示例："估计企业价值为市值 + 5000 万美元净债务（来自第三季度资产负债表，第四季度尚未可用）"
   - 示例："基于街市共识每股收益 3.45 美元（12 位分析师估计的平均值）的市盈率"

   **这很重要**：启用审计追踪、数据验证、假设透明度和未来更新
3. **逐行构建公式** - 在继续之前测试每个计算
4. **对标题使用绝对引用** - $C$6 锁定标题行
5. **格式保持一致** - 百分比作为百分比，而不是小数
6. **添加条件格式** - 自动突出显示异常值

### 精神检查
- **利润率测试**：毛利率 > EBITDA 利润率 > 净利润率（根据定义始终如此）
- **多重合理性**： 
  - EV/收入：通常为 0.5-20 倍（行业差异很大）
  - EV/EBITDA：通常为 8-25 倍（行业间相对一致）
  - 市盈率：通常为 10-50 倍（取决于增长率）
- **增长-倍数相关性**：更高的增长率通常意味着更高的倍数
- **规模-效率权衡**：大公司通常有更好的利润率（规模效益）

### 常见错误避免
❌ 在公式中混合市值和企业价值
❌ 分子分母使用不同的时间段（LTM 与季度）
❌ 将数字硬编码到公式中而不是单元格引用
❌ **没有单元格注释引用来源或解释假设的硬编码输入**
❌ 当可用时缺少指向 SEC 文件或数据源的链接
❌ 包含过多没有明确目的的指标
❌ 包含业务模式不同的可比公司
❌ 使用未披露的过时数据
❌ 错误计算百分比的平均值（应为中位数）

## 第 7 节：工作流程及实用技巧

### 分步流程
1. **设置结构**（30 分钟）
   - 创建所有标题
   - 格式化单元格（蓝色为输入，黑色为公式）
   - 锁定单位和日期引用

2. **收集数据**（60-90 分钟）
   - 从主要来源获取（S&P Kensho MCP、FactSet MCP、Daloopa MCP（如果可用）；否则彭博、SEC）
   - 将所有原始数字输入蓝色
   - 在注释部分记录来源

3. **构建公式**（30 分钟）
   - 从简单的比率（利润率）开始
   - 进阶到倍数（EV/收入）
   - 添加交叉检查（利润率是否有意义？）

4. **添加统计数据**（15 分钟）
   - 复制所有列的公式结构
   - 验证范围是否正确（B7:B9，而不是 B7:B10）
   - 检查四分位数逻辑

5. **质量控制**（30 分钟）
   - 运行精神检查
   - 验证公式引用
   - 检查 #DIV/0! 或 #REF! 错误
   - 与已知基准进行比较

6. **文档**（15 分钟）
   - 完成注释部分
   - 添加数据来源
   - 定义方法
   - 日期标记分析

### 专业技巧
- **保存模板**：构建一次，永久重用
- **颜色编码异常值**：条件格式化大于 2 个标准差值
- **链接到源文件**：链接到彭博截图或 SEC 文件
- **版本控制**：保存为 "Comps_v1_2024-12-15"，清晰日期
- **协作审查**：让其他人检查你的公式

### Excel 格式检查清单（可选 - 根据用户偏好调整）
- [ ] 字体设置为用户喜欢的样式（默认：Times New Roman，11pt 数据，12pt 标题）

- [ ] 列标题根据用户模板设置（默认：浅蓝色/灰色 #D9E2F3，黑色加粗文本）
- [ ] 统计数据行根据用户模板设置（默认：浅灰色 #F2F2F2）
- [ ] 不应用边框（干净、简洁的外观）

## 第 10 节：红旗与警告标志

### 数据质量问题
🚩 不一致的时间段（混合季度和年度）  
🚩 没有解释就缺少数据  
🚩 数据源之间存在重大差异（>10% 差异）

### 估值红旗
🚩 EBITDA 为负的公司使用 EBITDA 倍数估值（使用收入倍数代替）  
🚩 市盈率 >100 倍，没有高增长故事  
🚩 利润率不符合行业逻辑

### 可比性问题
🚩 不同的财政年度结束（导致时间问题）  
🚩 混合纯业务和综合企业  
🚩 业务模式有重大差异，标记为 "可比"

**不确定时，排除公司。** 3 家完美的可比公司比 6 家可疑的可比公司更好。

## 第 11 节：公式参考指南

### 基本Excel公式
```excel
// 统计函数
=AVERAGE(range)          // 简单平均值
=MEDIAN(range)           // 中值
=QUARTILE(range, 1)      // 25% 分位数
=QUARTILE(range, 3)      // 75% 分位数
=MAX(range)              // 最大值
=MIN(range)              // 最小值
=STDEV.P(range)          // 标准差

// 财务计算
=B7/C7                   // 简单比率（利润率）
=SUM(B7:B9)/3            // 多个公司的平均值
=IF(B7>0, C7/B7, "N/A")  // 条件计算
=IFERROR(C7/D7, 0)       // 处理除零错误

// 跨工作表引用
='Sheet1'!B7             // 引用另一个工作表
=VLOOKUP(A7, Table1, 2)  // 从数据表中查找
=INDEX(MATCH())          // 高级查找

// 格式化
=TEXT(B7, "0.0%")        // 百分比格式
=TEXT(C7, "#,##0")       // 千位分隔符
```

### 常见比率公式
```excel
毛利率 = 毛利润 / 收入
EBITDA 利润率 = EBITDA / 收入
FCF 利润率 = 自由现金流 / 收入
FCF 转换率 = 自由现金流 / 营业现金流
ROE = 净利润 / 股东权益
ROA = 净利润 / 总资产
资产周转率 = 收入 / 总资产
债务/权益 = 总债务 / 股东权益
```

## 关键原则总结

1. **结构驱动洞察** - 正确的标题迫使正确的思考
2. **少即是多** - 5-10 个重要指标比 20 个不重要指标更好
3. **为你的问题选择指标** - 估值分析 ≠ 效率分析
4. **统计数据显示模式** - 中位数/四分位数揭示比平均值更多
5. **透明度胜过复杂性** - 简单公式每个人都能理解
6. **可比性是关键** - 最好排除而不是强迫不良可比公司
7. **记录你的选择** - 在注释部分解释哪些指标及其原因
