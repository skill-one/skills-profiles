# /draft-offer

> 如果你看到不熟悉的占位符，或者需要检查哪些工具已连接，请参阅 [CONNECTORS.md](../../CONNECTORS.md)。

为新的员工起草一封完整的录用通知书。

## 使用方法

```
/draft-offer $ARGUMENTS
```

## 我需要你提供的信息

- **职位和头衔**：是什么职位？
- **级别**：初级、中级、高级、专家等。
- **地点**：他们将在哪里工作？（这会影响薪酬和福利）
- **薪酬**：基本工资、股权、签收奖金（如果适用）
- **入职日期**：他们什么时候应该开始工作？
- **招聘经理**：他们向谁汇报？

如果你没有所有这些细节，我会帮助你思考。

## 输出

```markdown
## 录用通知书草稿：[职位] — [级别]

### 薪酬包
| 组成部分 | 细节 |
|-----------|---------|
| **基本工资** | $[X]/年 |
| **股权** | [X股/单位]，[归属计划] |
| **签收奖金** | $[X] (如果适用) |
| **目标奖金** | 基本工资的[X]% (如果适用) |
| **第一年总薪酬** | $[X] |

### 条款
- **入职日期**：[日期]
- **汇报对象**：[经理]
- **地点**：[办公室 / 远程 / 混合办公]
- **雇佣类型**：[全职，非工时]

### 福利概要
[与候选人相关的关键福利亮点]

### 录用通知书文本

亲爱的 [候选人姓名]，

我们很高兴地提供给你 [公司] 的 [职位] 职位...

[完整的录用通知书文本]

### 招聘经理的备注
- [如果需要，谈判指导]
- [薪酬范围背景]
- [任何标志或注意事项]
```

## 如果连接器可用

如果 **~~HRIS** 已连接：
- 拉取级别/职位的薪酬范围数据
- 核对人员编制批准
- 自动填充福利细节

如果 **~~ATS** 已连接：
- 从申请中拉取候选人详细信息
- 在管道中更新录用状态

## 小贴士

1. **包含总薪酬** — 候选人会比较总薪酬，而不仅仅是基本工资。
2. **具体说明股权** — 分享股份数量、当前估值方法、归属计划。
3. **个性化** — 提及面试过程中的某件事，使其更温暖。
