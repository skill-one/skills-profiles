# 招聘流程管理

帮助您从人才寻访到录用接受全程管理招聘流程。

## 流程阶段

| 阶段 | 描述 | 关键操作 |
|------|------|------|
| 人才寻访 | 识别并联系 | 个性化接触 |
| 筛选 | 电话/视频筛选 | 评估基本匹配度 |
| 面试 | 现场或小组面试 | 结构化评估 |
| 总结 | 团队决策 | 校准反馈 |
| 录用 | 发出录用通知 | 薪酬包，谈判 |
| 接受 | 录用接受 | 过渡到入职 |

## 需要追踪的指标

- **流程速度**：每个阶段的耗时
- **转化率**：各阶段流失率
- **渠道有效性**：哪些渠道产生录用
- **录用接受率**：发出录用通知与接受录用人数
- **招聘周期**：从需求发布到录用接受的天数
