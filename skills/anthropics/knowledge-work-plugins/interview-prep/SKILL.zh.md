# 面试准备

创建结构化的面试计划，以始终如一且公平地评估候选人。

## 面试设计原则

1. **结构化**：针对该职位的所有候选人都使用相同的问题
2. **基于能力**：将问题与特定技能和行为映射
3. **基于证据**：使用行为性和情境性问题
4. **多元化小组**：多个视角减少偏见
5. **评分制**：使用评分标准，而非凭感觉

## 面试计划组件

### 职位能力

为该职位定义4-6个关键能力（例如，技术技能、沟通能力、领导力、解决问题能力）。

### 问题库

针对每个能力，提供：
- 2-3个行为性问题（“请告诉我一次……的经历”）
- 1-2个情境性问题（“你会如何处理……”）
- 追问问题

### 评分表

在一致的量表（1-4）上对每个能力进行评分，并清晰描述每个级别的表现。

### 总结模板

结构化的格式，供面试官分享发现并做出决定。

## 输出

生成完整的面试工具包：小组分配（谁面试什么）、按能力分类的问题库、评分标准，以及总结模板。
