# /runbook

> 如果你看到不熟悉的占位符，或者需要检查哪些工具已连接，请参阅 [CONNECTORS.md](../../CONNECTORS.md)。

为重复性任务或流程创建分步操作手册。

## 使用方法

```
/runbook $ARGUMENTS
```

## 输出

```markdown

### 目的
[此手册完成的工作以及何时使用]

- [ ] [需要的数据或输入]
```

## 如果连接了连接器

如果 **~~知识库** 已连接：
- 搜索现有手册进行更新，而不是从头开始创建
- 将完成的手册发布到你的运维维基

如果 **~~ITSM** 已连接：
- 将手册链接到相关的工单类型和变更请求
- 从值班计划中自动填充升级联系人

## 小贴士

1. **非常具体** — "运行脚本" 不是一个步骤。"从运维服务器运行 `python sync.py --prod --dry-run`" 才是。
2. **包含故障模式** — 每个步骤中可能出错的内容以及如何处理。
3. **测试手册** — 让不熟悉流程的人按照手册操作。修复他们卡住的地方。
