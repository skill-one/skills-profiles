# 联系人研究

从 Common Room 中检索全面的联系人资料。支持通过电子邮件、社交账号或姓名+公司进行查询。返回包含活动历史记录、Spark、评分、网站访问记录和 CRM 字段等丰富数据。

## 第 1 步：定位联系人

Common Room 支持多种查询方法 — 使用用户提供的信息：

| 用户提供的信息 | 查询方法 |
|----------------|----------|
| 电子邮件地址 | 通过电子邮件查询（最可靠） |
| LinkedIn、Twitter/X 或 GitHub 账号 | 通过社交账号查询 — 明确指定账号类型 |
| 姓名 + 公司 | 通过姓名+组织域名进行身份解析；如果存在歧义，则显示匹配结果 |
| 仅姓名 | 通过姓名搜索；如果存在多个匹配项，则显示简要列表并要求用户确认 |

如果没有找到匹配项，请回复："Common Room 没有此人的记录。" 不要猜测或编造联系人资料。

## 第 2 步：获取联系人字段

使用 Common Room 对象目录查看可用的字段组及其内容。对于完整资料，请求所有组。对于有针对性的问题，仅请求相关内容。

**需要了解的关键字段组：**
- **评分** — 始终以原始值或百分位数返回，绝不能返回标签
- **近期活动** — 使用 `Contact Initiated` 筛选器（过去 60 天）查看其行为，而不是您团队的行为
- **网站访问记录** — 总访问次数 + 具体页面（过去 12 周）
- **Spark** — 追踪一段时间内的参与度演变时，检索所有 Spark

## 第 3 步：运行 Spark 丰富（如果可用）

如果 Spark 可用，请使用它。Spark 提供：
- 专业背景和工作历史
- 社交存在感和影响力信号
- 人设分类：倡导者、经济购买者、技术评估者、最终用户或守门人
- 在购买过程中的推断角色

如果 Spark 不可用但存在真实活动数据（近期行为、网站访问记录、社区参与），则根据这些信号推断人设。如果 Spark 和活动数据均不可用，则分类为未知 — 不要仅凭职位猜测人设。

当用户希望了解此联系人的参与度如何随时间演变时，请检索**所有 Spark**（而不仅仅是最近的 Spark）。

## 第 4 步：评估账户背景

为该联系人的母公司获取简要的账户快照。注意：
- 账户层面的开放机会、扩张信号或流失风险
- 该公司其他联系人是否也活跃
- 此人的参与度与其同事相比如何

## 第 5 步：确定对话角度

根据活动和信号，展示最强的 2-3 个钩子：
- 近期的 `Contact Initiated` 活动（社区帖子、产品活动、支持工单）
- 他们最近访问的特定网页 — 特别是如果它表明了评估意图
- 职位变动、晋升或公司新闻
- 他们的 Spark 人设及其对沟通风格的影响
- 他们在一个已知活跃交易中的角色

## 输出格式

仅包含实际返回数据的部分。省略没有数据的部分，而不是用猜测填充。

**当数据丰富时：**

```
## [联系人姓名] — 资料概览

**概述**
[2 句话：他们的身份、角色和关系状态]

**详细信息**
- 职位：[职位]
- 公司：[公司]
- 电子邮件：[电子邮件]
- LinkedIn：[URL]
- 其他资料：[Twitter/X、GitHub、CRM 链接（如果可用）]

**评分** [如果返回评分]
[所有评分作为原始值或百分位数]

**近期活动**（过去 60 天） [如果返回活动]
[3-5 个带日期的要点]

**网站访问记录**（过去 12 周） [如果存在访问数据]
[总访问次数 + 访问的页面列表]

**Spark 资料概览** [如果 Spark 数据非空]
[人设类型、背景摘要、影响力信号]

**细分** [如果返回细分]
[此联系人所属的细分名称列表]

**账户背景**
[1-2 句关于其公司状态的话]

**对话起点**
[2-3 个具体、有信号支持的开启话题]
```

**当数据稀疏（例如，仅返回姓名、职位、电子邮件、标签；sparkSummary 为空）时：**

```
## [联系人姓名] — 资料概览（有限数据）

**可用数据：** [列出 Common Room 返回的内容]

[仅呈现返回的字段]

**网络搜索**
[搜索其姓名+公司找到的结果]

**注意：** Common Room 对此联系人数据有限。没有活动历史记录、评分或 Spark 资料可用。我可以进行更深入的网络搜索或查询其公司以获取更多背景信息。
```

不要从稀疏数据中生成对话起点、人设推断或参与度评估。这些需要真实信号。

## 质量标准

- 查询必须使用正确的输入类型方法 — 不要猜测电子邮件与账号的区别
- 评分必须为原始值/百分位数 — 绝不能返回标签
- `Contact Initiated` 活动（过去 60 天）是主要参与度信号 — 优先展示
- 如果 Spark 不可用，请说明 — 不要仅凭职位猜测人设
- 标记任何最近活动超过 30 天的联系人
