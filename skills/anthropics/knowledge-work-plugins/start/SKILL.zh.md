# 生物研究启动

> 如果您看到不熟悉的占位符或需要检查哪些工具已连接，请参阅 [CONNECTORS.md](../../CONNECTORS.md)。

您正在帮助一位生物研究员熟悉生物研究插件。请按顺序完成以下步骤。

## 第 1 步：欢迎

显示此欢迎信息：

```
生物研究插件

您在生命科学领域的 AI 驱动研究助手。该插件将文献检索、数据分析流程和科学策略——所有这些都集成在一个地方。
```

## 第 2 步：检查可用的 MCP 服务器

通过列出可用工具来测试哪些 MCP 服务器已连接，并将结果分组：

**文献与数据源：**
- ~~文献数据库 — 生物医学文献检索
- ~~文献数据库 — 预印本访问（生物学和医学）
- ~~期刊访问 — 学术出版物
- ~~数据存储库 — 协作研究数据（Sage Bionetworks）

**药物发现与临床：**
- ~~化学数据库 — 生物活性化合物数据库
- ~~药物靶点数据库 — 药物靶点发现平台
- ClinicalTrials.gov — 临床试验注册
- ~~临床数据平台 — 临床试验站点排名和平台帮助

**可视化与 AI：**
- ~~科学插图 — 创建科学图形和图表
- ~~AI 研究平台 — 用于生物学的 AI（组织病理学、药物发现）

报告哪些服务器已连接，哪些尚未设置。

## 第 3 步：调查可用技能

列出此插件中可用的分析技能：

| 技能 | 它的作用 |
|-------|-------------|
| **单细胞 RNA 质量控制** | 基于 MAD 过滤的 scRNA-seq 数据质量控制 |
| **scvi-tools** | 单细胞组学的深度学习（scVI、scANVI、totalVI、PeakVI 等） |
| **Nextflow 流水线** | 运行 nf-core 流水线（RNA-seq、WGS/WES、ATAC-seq） |
| **仪器数据转换器** | 将实验室仪器输出转换为 Allotrope ASM 格式 |
| **科学问题选择** | 选择研究问题的系统框架 |

## 第 4 步：可选设置 — 二进制 MCP 服务器

提到两个额外的 MCP 服务器作为独立安装可用：

- **~~基因组平台** — 访问云端分析数据和流程
  安装：从 https://github.com/10XGenomics/txg-mcp/releases 下载 `txg-node.mcpb`
- **~~工具数据库**（哈佛 MIMS）— 用于科学发现的 AI 工具
  安装：从 https://github.com/mims-harvard/ToolUniverse/releases 下载 `tooluniverse.mcpb`

这些需要下载二进制文件，并且是可选的。

## 第 5 步：询问如何提供帮助

询问研究员今天在做什么。根据常见工作流程建议起点：

1. **文献综述** — "搜索 ~~文献数据库中关于 [主题] 的最新论文"
2. **分析测序数据** — "对我的单细胞数据运行质量控制" 或 "设置 RNA-seq 流水线"
3. **药物发现** — "搜索 ~~化学数据库中针对 [蛋白质] 的化合物" 或 "为 [疾病] 寻找药物靶点"
4. **数据标准化** — "将我的仪器数据转换为 Allotrope 格式"
5. **研究策略** — "帮助我评估一个新的项目想法"

等待用户的回复，并引导他们使用适当的工具和技能。
