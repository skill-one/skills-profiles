# 构图

布置画面并移动摄像机：网格系统、安全区域、焦点层次、负空间、视差分层，以及布局如何随时间引导视线。产出构图笔记、图层结构（背景/中景/前景）和具体的摄像机移动计划（含数值）。

## 使用场景

- 定义画面的布局、焦点和负空间。
- 规划元素进入/退出方向和运动路径。
- 设计摄像机推/拉、摇、跟和视差移动。
- 在安全区域内将一个构图适配到16:9、9:16和1:1。

## 决策树

```
你在布置什么？
├─ 静态画面的布局
│   └─ 设置网格 → 将一个焦点放置在三分法点位上
│      → 排序层次（大小>对比度>颜色>位置）→ 保留负空间
├─ 物体进入/离开的位置
│   └─ 遵循阅读方向；最近边缘；进入时缓出；退出时缓入
│      (新内容 → 从右侧/下方进入；返回/撤销 → 反向操作)
├─ 深度感/摄像机移动
│   └─ 分为背景/中景/前景图层（三个运动图层）
│      → 每个节拍一个摄像机移动（推 | 摇 | 跟 | 视差），缓入缓出
└─ 跨构图适配（16:9 / 9:16 / 1:1）
    └─ 在16:9中主构，焦点在中心带 → 重新堆叠（不裁剪）用于9:16
       → 保持关键内容在标题安全区域内
```

**交叉参考 — 应用共享框架。** 这项技能是`动画原理`的空间一半。明确应用它们：

- **三分法** (`动画原理`) 有两种形式，这项技能在空间上使用它们：(a) *构图三分法* — 将焦点放置在三分法点位上（33%/67%）；(b) *距离* — 没有元素在未设置中间关键帧或缩放/不透明度变化的情况下移动超过约1/3的帧，因此进入时保持可读。
- **三个运动图层** (`动画原理`：主要/次要/环境) 直接映射到深度：**前景 = 主要**（眼睛跟随的移动），**中景 = 次要**（主体+辅助反应），**背景 = 环境**（缓慢、低对比度动态）。视差速度与该角色成正比。
- 在编号摄像机移动之前确定**三个支柱**（情感意图/视觉叙事/运动工艺）和选择的**运动个性** (`运动艺术设计`) — 精品需要缓慢的长推，活力需要甩动摇移。

## 核心工作流程

### 1. 建立网格

网格提供对齐和节奏。默认使用**12列网格**用于横屏网页/视频（它可以分成 halves, thirds, quarters, sixths）并带有间隙和外部边距。对于1920px宽的帧：外部边距80-120px，12列，间隙24-32px。

```
content_width = frame_width - 2 * margin
column_width  = (content_width - (cols - 1) * gutter) / cols
```

示例（1920宽，边距100，间隙24，12列）：内容1720，列 = (1720 - 11*24)/12 = 121.3px。

一个**基线网格**（垂直节奏）的8px是标准间距单位；以8的倍数（8/16/24/32/48/64）调整大小和空间，以实现视觉一致性。

### 2. 放置焦点

使用**三分法**：将画面分成3x3网格；将主要主体放置在三分线或交点上（"力量点"），而不是正中心 — 除非作品故意使用对称性来营造静态/正式感。交点大致位于水平垂直33%/67%。

按此优先级顺序建立**视觉层次**以引导视线：**大小 > 对比度 > 颜色 > 位置**。最大、对比度最高的元素最先吸引注意力。每帧仅建立一个主要焦点；次要元素辅助，从不竞争。

### 3. 将负空间用作节奏

不要填满画面。焦点周围的充足负空间使其读起来更高端、自信，并为运动留出呼吸空间。空白是主动的构图元素，不是剩余部分。

### 4. 分层场景（背景/中景/前景）以实现深度和视差

将构图分为深度图层：**背景**（最慢、最低对比度、通常去饱和/模糊），**中景**（主体），**前景**（最快，可能在其穿越时模糊）。视差 = 以不同速度移动图层以模拟深度。

这些深度图层就是`动画原理`的**三个运动图层**在Z轴上的投影 — 每个图层的角色决定了其速度、对比度和获得的运动量：

| 深度 | 运动图层 | 视差速度 | 对比度/焦点 | 这里有什么 |
|---|---|---|---|---|
| 背景 | 环境 | 0.1–0.3x | 低，通常去饱和/模糊 | 天空，渐变，纹理，场景装饰 |
| 中景 | 次要 | 0.5–0.7x | 中等；支持主体 | 主体环境，辅助元素 |
| 前景 | 主要 | 1.0–1.5x | 主体清晰；前景道具在穿越时模糊 | 主体+最近道具 |

前景可能超过1.0以读起来像非常近。主要移动是眼睛跟随的；永远不会给两个图层竞争主要运动。

### 5. 摄像机语言（适用于2D和3D）

- **推/拉** — 放大进入或远离主体（推镜头）。建立亲密感或揭示背景。800-2000ms，缓入缓出。
- **摇/俯仰/移动** — 将画面在场景中平移。揭示空间，跟随动作。
- **跟拍** — 保持移动的主体在画面中（通常略微偏离中心，引导动作）。
- **视差** — 分层移动，增强深度。

**一个镜头，一个意图。** 不要同时推+摇+旋转 — 组合移动读起来很混乱。选择单个移动来服务于节拍。内联时间要点：摄像机移动使用缓入缓出 (`cubic-bezier(0.65, 0, 0.35, 1)`)；除了连续循环外，永远不要`linear`；慢速更具电影感。

### 6. 进入/退出方向传递意义

遵循阅读方向（从左到右，从上到下在从左到右的区域）的运动感觉自然流畅；反向操作会制造紧张感或表示"返回/撤销"。将方向与意图匹配：
- 新内容到达 -> 从右侧/下方进入。
- 退出/返回 -> 向右或向下退出，或反向进入。
- 深入挖掘 -> 放大/推入。

元素通常应通过最近帧边缘进入和退出，进入时轻微缓出，退出时加速。

### 7. 安全区域和多维度适配

将所有关键内容（文本、标志、人脸、CTA）保留在**标题安全区域内**，以免被裁剪或隐藏在平台UI后面。

| 维度 | 使用 | 标题安全区域 | 备注 |
|---|---|---|---|
| 16:9 | YouTube, 网页横幅 | 约5% 所有边 | 历史上广播标题安全区域为10% |
| 9:16 | Reels, TikTok, 故事 | 顶部 ~12-14%，底部 ~18-20%，两侧 ~6% | 平台UI占用顶部和底部 |
| 1:1 | 信息流帖子 | ~6-8% 所有边 | 对称 |
| 4:5 | 信息流（更高） | 两侧 ~6%，顶部/底部 ~8% | 最大化信息流空间 |

设计**焦点足够居中**，以便它能在所有裁剪中存活，然后让次要元素根据维度重新流式化。对于16:9 -> 9:16，垂直重新堆叠，而不是简单地裁剪两侧。

## 实例分析

### 良好实例 — 产品主角，16:9 → 9:16

> **简报**：应用启动横幅，精品个性，必须在网页横幅和Reel中工作。
>
> - **网格**：1920×1080，边距100，间隙24，12列。手机模型跨越列7–11（右侧力量列）。
> - **焦点**：手机屏幕在右侧三分线交点（1280, 360）上 — 不居中。一个焦点；标题（列1–5）是次要的，对比度较低。
> - **深度（三个运动图层）**：背景 = 柔和渐变漂移，0.2x，环境。中景 = 手机模型，0.6x，次要阶段。前景 = 一个模糊的UI碎片飘过，1.2x + 3px模糊，读作主要深度提示。
> - **摄像机**：单个推入，缩放1.0→1.10，1600ms缓入缓出，原点在手机屏幕上 — 符合精品（缓慢，无超调）。不添加摇。
> - **9:16适配**：重新堆叠 — 标题移动到手机*上方*，手机上移到上中部以清除底部19%的CTA/导航区域，字体+20%。焦点在裁剪中存活，因为它开始于中心带。
>
> 为什么有效：一个焦点，深度角色分配，一个摄像机移动，安全区域感知的重新流式化，而不是盲目裁剪。

### 反模式 — "所有居中，所有移动"的帧

> - 手机模型居中，标题居中上方，标志居中下方 → 三个元素在同一轴上竞争，没有层次，没有力量点。
> - 所有三个图层以1.0x速度向左滑动 → 没有视差，没有深度，读作"整个模板移动了"（违反了**三分法/距离**：全宽滑动，没有中间关键帧）。
> - 摄像机同时执行推+摇+轻微旋转 → 混乱，没有单一意图。
> - 9:16通过裁剪16:9两侧制作 → 标题和标志被裁剪，手机太低被导航栏遮挡。
>
> 修复：选择一个焦点力量点，为每个图层分配一个深度角色+不同的视差速度，一个摄像机移动，并垂直重新流式化，而不是裁剪。

## 常见错误

| 症状 | 原因 | 修复 |
|---|---|---|
| 画面感觉扁平/"模板移动" | 所有图层以同一速度移动；没有深度角色 | 为背景/中景/前景分配环境/次要/主要角色 + 0.2/0.6/1.2x 视差 |
| 眼睛不知道该看向哪里 | 2+元素在相等大小/对比度，全部居中 | 在三分法点位上有一个焦点；按大小>对比度>颜色>位置排序 |
| 摄像机移动读起来很混乱 | 推+摇+旋转组合 | 每个节拍一个移动；选择服务于意图的那个 |
| 手机上内容被裁剪 | 设计用于16:9，裁剪到9:16 | 垂直重新堆叠；将关键内容保留在标题安全区域内（9:16顶部13% / 底部19%） |
| 进入读起来像"滑动"，不是"事件" | 元素在未设置中间关键帧的情况下移动超过1/3的帧 | 使用中间关键帧中断，或与缩放/不透明度配对（三分法，距离） |
| 看起来廉价/拥挤 | 画面从边缘到边缘填满 | 在焦点周围保留负空间；它是一个主动元素 |
| 运动与故事冲突 | 在编号摄像机移动之前选择意图 | 在编号移动之前确定三个支柱+运动个性 (`运动艺术设计`) |

## 交付物 — 构图计划

一个好的构图计划是交给实现技能 (`gsap-web`, `remotion-video`, `after-effects`) 的，包含：

- **帧规格**：维度，分辨率，帧率，网格（列 / 边距 / 间隙），基线单位。
- **焦点**：三分法点位上的坐标（px或%）+ 每个元素的层次排序。
- **图层映射**：每个元素分配背景/中景/前景 → 环境/次要/主要，以及视差速度。
- **进入/退出**：每个元素 — 边缘，方向，缓动类型，以及是否旅行超过1/3（以及如何中断）。
- **摄像机移动**：单个移动，其属性+从→到值，持续时间，缓动，变换原点。
- **安全区域**：每个目标维度标题安全边距+垂直重新堆叠计划。
- **交叉参考**：哪些运动个性和哪些支柱决策驱动了时间。

### 完成前 — 检查清单

- [ ] 恰好一个主要焦点，在三分法点位上（或故意对称）。
- [ ] 层次排序（大小 > 对比度 > 颜色 > 位置）；次要元素不竞争。
- [ ] 在焦点周围保留负空间。
- [ ] 每个元素分配一个深度图层（背景/中景/前景 = 环境/次要/主要）+ 视差速度。
- [ ] 一个摄像机移动，不堆叠；缓动（循环时线性）；英雄移动800–2000ms。
- [ ] 进入/退出使用最近边缘，遵循阅读方向，缓出进入 / 缓入退出。
- [ ] 没有元素在未设置中间关键帧或缩放/不透明度变化的情况下移动超过1/3的帧。
- [ ] 关键内容在所有目标维度标题安全区域内；垂直是重新堆叠，不是裁剪。
- [ ] 运动个性 + 三个支柱在编号任何移动之前确定。
