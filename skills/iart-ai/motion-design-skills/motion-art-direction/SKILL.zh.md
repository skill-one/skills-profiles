# 运动方向

在任何人开始绘制动画帧之前，为动态作品做出创意决策。方向是判断层面：它将简报和品牌转化为一套小而可重复的运动规则——一种缓动词汇、一种时间尺度、一种过渡家族——这样每一镜头都感觉像是出自同一只手。好的方向主要是减法：决定什么**不**要动。

## 使用时机

- 开始任何作品——解释视频、发布电影、UI演示、数据故事、循环动画——并且外观/感觉尚未确定。
- 动画感觉“忙碌”、“廉价”或“不一致”，而原因是决策而非技艺。
- 协调其他技能（gsap/lottie/shader/three.js）：方向设定了它们执行的规则。
- 将品牌或简报转化为团队（或代理人）可以遵循的直接选择。

## 一条规则

**先定义运动语言，再根据它进行动画。** 运动语言是一个简短的技术规范——从以下各项中各选一个：缓动家族、基础时间单位、过渡家族、错落节奏、运动强度。作品中的所有元素都遵循它。一致性读作自信；多样性读作噪音。如有疑问，请重用，不要发明。

## 方向工作流程

| 步骤 | 决策 | 输出 |
|---|---|---|
| 1. 简报 | 受众、一条信息、平台、时长、情绪（3个形容词） | 一行创意意图 |
| 2. 调性与能量 | 它在冷静↔动态和柔和↔锐利之间的位置 | 下方矩阵中的一个点 |
| 3. 运动语言 | 锁定技术规范表 | 运动语言技术规范（已填写） |
| 4. 层级 | 排序可移动元素：主角 / 辅助 / 纹理 | 运动层级列表 |
| 5. 限制步骤 | 删除不传达意义的运动 | 保持静态的列表 |
| 6. 镜头方向 | 每个镜头的意图，而非关键帧 | 方向笔记（见模板） |
| 7. 一致性检查 | 与技术规范进行审计 | 每个镜头的通过/失败 |

## 调性与能量矩阵

将作品放置在两个轴上；单元格决定了运动语言的默认值。

| | 柔和（有机、缓动） | 锐利（精确、利落） |
|---|---|---|
| **冷静** | 奢侈品、健康、编辑——慢速、长缓动、充足的停留、最小错落 | 高端科技、金融科技——谨慎、干净的近似线性移动、紧凑但不匆忙 |
| **动态** | 俏皮、生活方式、儿童——弹跳/过冲、弹簧感、宽松时间 | 运动、炒作、游戏——快速剪辑、硬性弹跳、在节拍上强烈的过冲 |

选择一个单元格并坚持。在一个作品中混合单元格是最常见的“不一致”运动原因。

## 运动个性（命名的预设）

调性矩阵告诉你作品*在哪里*；一个**运动个性**是你可以交给动画师使用的命名、数值预设。每个项目选择一个并处处应用。这是共享词汇——其他技能（例如 `gsap-web`、`micro-interaction`、视频包）只需说“使用 Premium 个性”。

| 个性 | 时长 | 特征缓动 | 过冲 | 读作 |
|---|---|---|---|---|
| **俏皮** | 150–300ms | `ease-out-back` / `cubic-bezier(0.34,1.56,0.64,1)` | 10–20% | 有趣、弹跳、异想天开 |
| **高端** | 350–600ms | `cubic-bezier(0.4,0,0.2,1)` | 0% | 优雅、简约、奢华 |
| **企业** | 200–400ms | `cubic-bezier(0.2,0,0,1)` | 0–3% | 干净、专业、值得信赖 |
| **活力** | 100–250ms | `ease-out-expo` | 15–30% | 大胆、动态、炒作 |

默认：UI/产品使用**企业**，插图/生活方式使用**俏皮**。映射到矩阵——Premium≈冷静-柔和，企业≈冷静-锐利，俏皮≈动态-柔和，活力≈动态-锐利。个性填充了下方技术规范中的“缓动家族 / 基础时间单位 / 运动强度”行。

## 运动语言技术规范

核心文件。为每一行选择一个选项并在所有地方重用。

| 属性 | 选择一个 | 示例（冷静-锐利 / 高端科技） |
|---|---|---|
| 缓动家族 | 约90%移动的标志性曲线 | `cubic-bezier(0.22, 1, 0.36, 1)`（减速、软着陆） |
| 基础时间单位 | 原子时长；其他作为倍数构建 | 0.4s（进入0.4s，大移动0.8s，微0.2s） |
| 过渡家族 | 镜头如何连接 | 仅匹配剪辑+交叉溶解；无擦除/旋转 |
| 错落节奏 | 组合元素之间的延迟 | 60ms 瀑布，自上而下 |
| 运动强度 | 距离/缩放/过冲预算 | 行程 ≤ 24px，缩放 0.96→1.0，过冲 ≤ 2% |
| 停留纪律 | 移动之间的最小休息 | 每个节拍后 ≥ 0.3s 的静止 |

最多两个缓动：一个“进入”（退出）和一个“退出”（进入/着陆）。必须证明存在的第三个曲线。

## 运动层级

并非所有元素都值得运动。对每个元素进行排名，然后按列表进行动画——并提前停止。这三个层级是通用的**三个运动层**（见 `animation-principles`）：主角 = **主要**，辅助 = **次要**，纹理 = **环境**。

| 层级 | 它是什么 | 如何运动 |
|---|---|---|
| 主角 | 镜头要表达的东西 | 获得最大胆、最慢、最缓动的移动；落在节拍上 |
| 辅助 | 帮助主角落下的上下文 | 更小、更快、缓动*离开*道路；从不竞争 |
| 纹理 | 背景、颗粒、环境漂移 | 只有潜意识的——慢速循环、低对比度、无硬切 |

如果两个元素在一帧中争夺眼球，方向就失败了。将其中一个降级为辅助。

## 限制——什么**不**要动画

高级移动。对每个元素提问：*运动是否传达意义？*如果不是，保持静止。

- 不要一次性动画整个帧——错落或保持锚点，让眼睛有一个归宿。
- 不要过渡过渡（没有动画擦除*和*旋转*和*淡入淡出）。
- 不要循环动画观众仍在阅读的文本。
- 不要在严肃/金融内容中添加过冲——它读作玩具般。
- 每个作品只有一个“哇”时刻。第二个会取消第一个。

## 节奏与韵律

节奏是剪辑的心跳。故意变化它：紧张（更快、更紧凑）→释放（停留）。在时间线上映射能量，然后再计时单个移动——大多数作品需要一个低能量的开场、一个构建、一个高峰和一个稳定的结束卡。在音频上剪辑和着陆关键时刻（见 launch-video 用于节拍同步）；沉默和静止是节奏工具，而不是填补空白。

## 一致性检查

在签发前，将每个镜头与技术规范表进行审计：

- 相似移动上是否使用相同的缓动家族？（没有随机的 `linear` 或 `ease`。）
- 所有时长都是基础单位的倍数吗？
- 镜头之间是否仅使用选定的过渡家族？
- 组合揭示的错落节奏是否相同？
- 是否遵守停留纪律——没有两个移动堆叠而没有休息？
- 每帧是否正好一个主角？

任何“否”都是方向缺陷，而非技艺偏好——在抛光前修复它。
