# 首席研究助理

这项技能通过分析您的产品/服务、了解您的理想客户画像，并提供可执行的市场拓展策略，帮助您识别和筛选潜在客户。

## 使用此技能的场景

- 寻找适合您产品/服务的潜在客户或客户
- 建立联系潜在合作伙伴的公司名单
- 确定销售拓展的目标账户
- 研究符合您理想客户画像的公司
- 为业务拓展活动做准备

## 此技能的功能

1. **理解您的业务**：分析您的产品/服务、价值主张和目标市场
2. **识别目标公司**：根据以下条件找到符合您理想客户画像的公司：
   - 行业和领域
   - 公司规模和地点
   - 技术栈和工具使用情况
   - 成长期和融资情况
   - 您的产品能解决的业务痛点
3. **优先排序**：根据匹配分数和相关性对潜在客户进行排序
4. **提供联系策略**：建议如何通过个性化信息接触每个潜在客户
5. **丰富数据**：收集关于决策者和企业背景的相关信息

## 使用方法

### 基本使用方法

只需描述您的产品/服务以及您希望找到的内容：

```
我正在开发 [产品描述]。为我找到 10 家位于 [地点/行业] 的公司，这些公司适合作为该产品的潜在客户。
```

### 结合您的代码库

从您的产品源代码目录中运行，以获得更好的结果：

```
查看我在这个仓库中正在开发的内容，并识别出 10 家位于 [地点/行业] 的公司，这些公司将从该产品中受益。
```

### 高级使用方法

进行更精准的研究：

```
我的产品：[描述]
理想客户画像：
- 行业：[行业]
- 公司规模：[规模范围]
- 地点：[地点]
- 当前痛点：[痛点]
- 使用的技术：[技术栈]

为我找到 20 个符合条件的潜在客户，并为每个潜在客户提供联系策略。
```

## 使用说明

当用户请求潜在客户研究时：

1. **理解产品/服务**
   - 如果在代码目录中，分析代码库以了解产品
   - 询问关于价值主张的澄清问题
   - 确定关键功能和优势
   - 了解它解决了什么问题

2. **定义理想客户画像**
   - 确定目标行业和领域
   - 确定公司规模范围
   - 考虑地理偏好
   - 了解相关痛点
   - 记录任何技术要求

3. **研究和识别潜在客户**
   - 搜索符合标准的公司
   - 寻找需求信号（招聘信息、技术栈、最新新闻）
   - 考虑增长指标（融资、扩张、招聘）
   - 识别具有互补产品/服务的公司
   - 检查预算指标

4. **优先排序和评分**
   - 为每个潜在客户创建匹配分数（1-10）
   - 考虑以下因素：
     - 与理想客户画像的匹配度
     - 立即需求的信号
     - 预算可用性
     - 竞争格局
     - 时间指标

5. **提供可执行输出**

   对每个潜在客户，提供：
   - **公司名称**和网站
   - **为什么他们适合**：基于其业务的特定原因
   - **优先分数**：1-10分并附解释
   - **决策者**：目标角色/头衔（例如，“工程副总裁”）
   - **联系策略**：个性化方法建议
   - **价值主张**：您的产品如何解决他们的特定问题
   - **对话开场白**：在接触中要提及的特定点
   - **LinkedIn链接**：如果可用，便于快速连接

6. **格式化输出**

   以清晰、可扫描的格式呈现结果：

   ```markdown
   # 潜在客户研究结果
   
   ## 摘要
   - 找到的潜在客户总数：[X]
   - 高优先级（8-10）：[X]
   - 中优先级（5-7）：[X]
   - 平均匹配分数：[X]
   
   ---
   
   ## 潜在客户 1：[公司名称]
   
   **网站**：[URL]
   **优先分数**：[X/10]
   **行业**：[行业]
   **规模**：[员工数量/收入范围]
   
   **为什么他们适合**：
   [2-3 基于其业务的特定原因]
   
   **目标决策者**：[角色/头衔]
   **LinkedIn**：[URL 如果可用]
   
   **针对他们的价值主张**：
   [针对该公司的具体优势]
   
   **拓展策略**：
   [个性化方法 - 提及特定痛点、公司最新消息或相关背景]
   
   **对话开场白**：
   - [具体点 1]
   - [具体点 2]
   
   ---
   
   [重复每个潜在客户]
   ```

7. **提供下一步行动建议**
   - 建议将结果保存为 CSV 以便 CRM 导入
   - 提供撰写个性化拓展消息的服务
   - 建议根据时间进行优先排序
   - 建议对顶级潜在客户进行后续研究

## 示例

### 示例 1：来自 Lenny 的简报

**用户**： "我正在开发一款在 AI 编码助手查询中屏蔽敏感数据的工具。找到潜在客户。"

**输出**：创建一个优先级列表，包括：
- 使用 AI 编码助手（Copilot、Cursor 等）
- 处理敏感数据（金融科技、医疗保健、法律）
- 在 GitHub 仓库中有使用编码代理的证据
- 可能意外在代码中暴露了敏感数据
- 包括相关决策者的 LinkedIn 链接

### 示例 2：本地企业

**用户**： "我经营一家专注于远程团队生产力的咨询公司。找到我在湾区最近转为远程的 10 家公司。"

**输出**：识别出：
- 最近发布远程招聘信息的公司
- 宣布远程优先政策的公司
- 招聘分布式团队的公司
- 显示远程工作挑战的公司
- 为每个潜在客户提供个性化拓展策略

## 获取最佳结果的技巧

- **具体说明**您的产品及其独特价值
- **从代码库运行**（如果适用）以自动获取上下文
- **提供理想客户画像的背景信息**
- **指定约束条件**，如行业、地点或公司规模
- **请求对有希望的潜在客户进行后续研究**以获取更深入的见解

- 详细研究特定公司
- 分析竞争对手的客户群
