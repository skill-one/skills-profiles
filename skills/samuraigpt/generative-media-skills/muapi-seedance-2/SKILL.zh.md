# 🎬 Seedance 2.0 电影专家

**"导演级" AI 视频编排的终极技能。**
Seedance 2.0 不是一个描述性模型；它是一个 *指令性* 模型。它对技术电影摄影、物理指令和精确的摄像机语法响应最佳。

## 核心能力

1.  **文本到视频 (t2v)**：根据导演简报生成电影视频——中文、全球或 VIP 级别。
2.  **图像到视频 (i2v)**：动画 1–9 张参考图像——中文、全球（智能模式）或 VIP 级别。
3.  **视频扩展 (extend)**：无缝继续现有的 Seedance 2.0 视频（中文级别）。
4.  **首帧与尾帧 (first-last)**：在起始图像和结束图像之间插值生成流畅的视频（全球/VIP）。
5.  **全模态参考 (omni)**：包含图像 + 音频 + 角色参考的全模态参考（所有级别）。
6.  **全模态参考训练 (omni-train)**：训练一个自定义的持久角色，用于身份一致的生成。
7.  **角色表 (character)**：从 1–3 张图像构建可重复使用的角色（中文级别）。
8.  **视频编辑 (video-edit)**：使用提示 + 可选的参考图像编辑现有视频（中文级别）。
9.  **水印移除 (watermark-remove)**：移除 Seedance 2.0 水印（基础或 Pro）。

## ⚠️ 限制

- **上传的图像/视频中不得包含逼真的真人面孔**（角色/omni-train 模式除外）。
- `--mode extend` 需要 `request_id`，该 ID 来自先前的 `seedance-v2.0-t2v` 或 `seedance-v2.0-i2v` 任务。
- `--mode first-last` 需要 `--tier global` 或 `--tier vip`。
- 全球/VIP omni **不支持**视频参考（仅支持图像 + 音频）。
- `--quality` 仅适用于中文级别。

## 🏗️ 技术规范：导演简报

使用此六组件层次结构构建提示。顺序很重要——先构图，后纹理和微观运动：

| 组件 | 指令类型 | 示例 |
|:---|:---|:---|
| **场景** | 环境 + 光线 | "一个被雨水浸湿的赛博朋克街道，紫色的霓虹灯在湿漉漉的沥青上反射。" |
| **主题** | 身份 + 细节 | "一个穿着黑色风衣的女人，坚定的专注，电影般的皮肤纹理。" |
| **动作** | 流体交互 | "穿过人群向前走，风衣在风中微微飘动。" |
| **摄像机** | 运动 + 镜头 + 速度 | "中景跟拍镜头，35mm 镜头，6 秒内缓慢后退的摇摄。轻微的手持抖动。" |
| **音频** | 音乐 + 音效 + 环境音 | "低环境嗡嗡声，远处交通声，5 秒时有一个钢琴音符。没有对话。" |
| **节奏/风格** | 时间 + 情绪 + 等级 | "电影史诗，暖色调等级，浅景深。慢速构建——单个动作，无场景切换。" |

> **Seedance 2.0 原生生成音频。** 始终包含一个音频指令——即使是一个句子。没有它，模型会生成随机的环境音，可能无法匹配您的场景。

### 时间分段提示（推荐用于 10 秒以上的视频）
将提示分成时间分段，以实现精确控制：
```
0–3 秒：[开场场景，摄像机运动，建立动作]
3–6 秒：[中段发展，主题在运动中]
6–10 秒：[高潮或关键动作节拍]
10–15 秒：[解决，品牌/产品展示，文本/标语淡入]
```

> **单节拍规则**：每个分段应包含一个动作。4–7 秒 = 一个节拍。10–15 秒 = 最多 3–4 个节拍。在分段中加载多个叙事变化会降低输出质量。

### 负面提示

Seedance 2.0 支持直接在提示中附加负面指导。使用普通语言在末尾：

```
[您的导演简报] 避免摄像机抖动，跳跃剪辑，镜头畸变，过曝，水印，文本叠加。
```

常见的负面添加：
- `避免：突然剪辑，场景切换，多个地点。`（用于单镜头拍摄）
- `避免：真人面孔，逼真人物。`（用于纯产品内容）
- `避免：快速运动，模糊，不稳定构图。`（用于平滑产品展示）

## 🧠 提示优化协议

**代理必须在执行前将用户意图转换为技术性的"导演简报"。**

1.  **技术语法**：使用摄像机术语：*推入/拉出，起重机镜头，快速摇摄，跟踪镜头，柱状透镜，浅景深，高速俯冲，轨道弧*。
2.  **物理指令**：使用"衍射图案"、"体积射线"或"次表面散射"而不是"良好光线"。
3.  **时间码符号**：对于多节拍场景，使用 `[00:00-00:05s]` 格式指定时间。
4.  **标签参考**：如果提供文件，使用：*"复制 @video1 的摄像机运动，同时保持 @image1 的视觉风格。"*（小写，1 基数索引）
5.  **顺序很重要**：开头的标记定义构图；结尾的标记定义纹理和微观运动。
6.  **多图像 i2v**：提供最多 9 张参考图像。模型跨所有输入混合方面（风格、身份、环境）。
7.  **音频是强制性的**：Seedance 2.0 原生生成音频。始终包含一个音频行——音乐类型/音调，关键音效，环境纹理。无声指导 = 随机音频。
8.  **单节拍纪律**：每个时间分段 = 一个动作。将两个叙事节拍塞进 4 秒会降低物理和运动一致性。

## ❌ 常见错误避免

1. **模糊参考**：不要说"参考 @Video1"——明确参考什么（镜头？动作？效果？节奏？）
2. **冲突指令**：不要在同一段落要求"固定镜头"和"轨道镜头"。
3. **超载**：不要在4-5秒内塞入太多场景——保持物理合理性。
4. **缺少 @分配**：如果上传5张图片，确保每张都有明确用途的参考。
5. **忽略音频**：音效设计极大提升效果——始终包含音频指导。
6. **忘记时长**：匹配提示复杂度与生成时长。
7. **真实人脸**：不要上传真实人类照片——系统会屏蔽。
8. **关键词堆砌**：不要使用"8k, 杰作, 趋势"。使用技术描述。
9. **动作不连贯**：避免"男人跑然后停下"。使用流畅的过渡语言。
10. **缺少音频指导**：Seedance 2.0原生生成音频——始终指定音乐基调，音效或环境音。遗漏会导致随机音效。
11. **每段叙事过载**：每段定时段落应包含一个动作高潮。4秒内多个场景切换会导致物理和运动伪影退化。
12. **FPV无持续运动**：FPV需要丰富的运动环境——静态房间配合FPV意图无法触发沉浸效果。搭配走廊、街道、自然地形或产品飞越使用。
13. **无人机无目的地**：无人机镜头需要解决点——指定相机下降方向或到达目标。单独的"无人机镜头"会产生漫无目的的漂浮。
