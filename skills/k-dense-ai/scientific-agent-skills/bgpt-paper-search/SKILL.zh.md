# BGPT 论文搜索

## 概述

BGPT 是一个远程 MCP 服务器，它搜索一个由原始实验数据构建的精选科学论文数据库。与传统文献数据库返回标题和摘要不同，BGPT 返回实际论文内容的结构化数据——方法、定量结果、样本量、质量评估以及每篇论文 25+ 项元数据字段。

## 何时使用此技能

使用此技能时：
- 搜索具有特定实验细节的科学论文
- 进行系统文献综述或范围文献综述
- 跨研究查找定量结果、样本量或效应量
- 比较不同研究中使用的方法
- 查找具有质量分数或证据评级的论文
- 需要全文论文的结构化数据（而不仅仅是摘要）
- 为荟萃分析或临床指南构建证据表

## 设置

BGPT 是一个远程 MCP 服务器——无需本地安装。在使用前请在代理的 MCP 设置中配置它；此技能指示代理调用 `search_papers` MCP 工具，本身不会启用 MCP 访问。

### Claude Desktop / Claude Code

添加到您的 MCP 配置中：

```json
{
  "mcpServers": {
    "bgpt": {
      "command": "npx",
      "args": ["mcp-remote", "https://bgpt.pro/mcp/sse"]
    }
  }
}
```

### npm（替代方案）

```bash
npx bgpt-mcp
```

## 使用方法

配置好 BGPT MCP 服务器后，通过代理的 MCP 界面调用其 `search_papers` 工具（不是通过 Bash）：

```
搜索关于："CRISPR 基因编辑在人类细胞中的效率"的论文
```

服务器返回结构化结果，包括：
- **标题、作者、期刊、年份、DOI**
- **方法**：实验技术、模型、方案
- **结果**：包含定量数据的关键发现
- **样本量**：受试者/样本数量
- **质量分数**：研究质量评估
- **结论**：作者结论和启示
