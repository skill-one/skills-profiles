# wind-mcp-skill (`wind-alice/alicemarket/wind-mcp-skill`)

## blackbox

**function**: 你问金融市场的问题，我给可查证的数据答案——股票、基金、指数、债券、宏观指标的行情、筛选、财务与资讯，只报告真实查到的结果，不编数字。

- input: 「筛选沪深市场市值超500亿且连续5日上涨的股票」, output: 一份符合条件的股票名单，含各股的市值、涨跌幅等对应数据
- input: 「贵州茅台今天最新价多少？中证500的PE现在处于历史什么分位？」, output: 茅台的最新价、涨跌幅，以及中证500当前PE/PB数值和所处历史分位
- input: 「中国近10年新能源汽车产销量怎么样？」, output: 按年份排列的产销量数据序列，可据此看出趋势变化
