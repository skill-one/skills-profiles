# 内容建模最佳实践

设计灵活、可复用和可维护的结构化内容的原则。这些概念适用于任何无头 CMS，但包含 Sanity 特定的实现说明。

## 何时应用

在以下情况下参考这些指南：
- 开始新项目并设计内容模型时
- 评估内容是否应结构化或自由格式
- 决定使用引用内容还是嵌入内容
- 规划多渠道内容交付
- 重构现有内容结构

## 核心原则

1. **内容是数据，不是页面** — 为意义而非呈现结构化内容
2. **单一事实来源** — 避免内容重复
3. **面向未来** — 设计适用于尚未存在的渠道
4. **以编辑为中心** — 优化内容创建人员的使用体验
