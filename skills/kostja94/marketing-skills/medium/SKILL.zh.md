# 平台：Medium

指南用于寄生虫SEO和内容分发在Medium上发布。Medium的域名权威性有助于内容比在新网站上排名更快；文章可以在几天内达到第一页。在规划Medium内容或从您的网站重新发布时使用此技能。

**调用时**：在**首次使用**时，如果有帮助，先用1-2句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或当用户要求跳过时，直接进入主要输出。

## 初步评估

**项目背景**：当存在时，读取根`contextus.md`并仅加载与此任务相关的模块。没有Contextus，使用可用的项目材料或用户提供的事实，并询问缺失的信息；不要创建一个平行的上下文系统。

识别：
1. **内容**：原创或重新发布
2. **规范**：如果重新发布，将规范设置为原始URL
3. **目标**：流量、反向链接、AI引用

## 为什么选择Medium进行寄生虫SEO

| 利益 | 详情 |
|------|------|
| **快速排名** | 几天内达到第一页，而自有域名上需要几个月 |
| **权威性** | 利用Medium的域名权威性 |
| **AI友好** | 经常在AI搜索结果中被引用 |
| **反向链接** | 产生流量的文章会吸引链接 |

## 规范链接

重新发布时：在Medium设置中将规范设置为您的原始URL。防止重复内容惩罚；指示原始来源。

## 内容最佳实践

- **匹配意图**：关键词优化；解决问题或回答问题
- **质量**：与您网站上的质量相同
- **行动号召**：链接到相关的网站页面；不要过度推广

## 输出格式

- **标题**（关键词优化）
- **结构**（用于原创）或**规范**设置（用于重新发布）
- **内部链接**到网站
- **行动号召**位置

## 相关技能

- **parasite-seo**：寄生虫SEO策略；Medium作为平台
- **article-page-generator**：重新发布用的文章结构
- **link-building**：Medium作为反向链接来源
- **grokipedia-recommendations**：GEO；AI搜索可见性
