# 平台：YouTube SEO

提供有关YouTube视频和频道优化的指南，以实现搜索和发现。**Google现在优先考虑YouTube视频搜索结果**；YouTube和Reddit约占AI概述中约78%的社交媒体引用。标题、描述和缩略图形成一个相互关联的系统；使用系统化关键词策略的频道，观看时长延长156%，点击率提高89%，搜索发现率提高312%。在优化YouTube搜索、Google搜索和AI引用的视频时使用此技能。有关嵌入式视频SEO，请参阅**video-optimization**。

**调用时**：在**首次使用**时，如果有帮助，先用1-2句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接进入主要输出。

## 初步评估

**项目背景**：当存在时，读取根`contextus.md`并仅加载与此任务相关的模块。没有Contextus时，使用可用的项目材料或用户提供的事实，并请求缺失信息；不要创建一个平行的上下文系统。

识别：
1. **视频类型**：教程、评测、博客、Shorts
2. **目标关键词**：主要和次要
3. **受众**：订阅者与随意观看者

## 视频标题

| 规则 | 指南 |
|------|-----------|
| **长度** | 60个字符以内；移动端可能显示部分 |
| **关键词** | 主要关键词在前5-55个字符内 |
| **结构** | 社会证明/权威 + 情感触发 + 主要关键词 |
| **风格** | 口语化；避免关键词堆砌 |
| **避免** | 除强调外，避免全大写 |

## 视频描述

| 规则 | 指南 |
|------|-----------|
| **前2-3句话** | 自然包含主要和次要关键词；元描述不超过160个字符 |
| **链接** | 网站、商店、相关资源 |
| **可读性** | 自然流畅；帮助搜索引擎理解主题 |

## 标签

- 帮助YouTube理解内容；标题和描述更重要
- 使用相关标签；避免过度优化

## 缩略图

90%表现最佳的视频使用自定义缩略图。

| 规则 | 指南 |
|------|-----------|
| **对比度** | 高对比度；易读字体；醒目的颜色 |
| **构图** | 三分法；简单、不杂乱 |
| **受众** | 考虑订阅者与随意观看者 |
| **测试** | 有效策略会变化；测试风格 |

## 标题 + 描述 + 缩略图

在三者中强化相同的核心信息；针对不同的算法方面。

## 输出格式

- **标题**选项（60个字符以内）
- **描述**（前160个字符 + 全部）
- **标签**（相关集合）
- **缩略图**指导（元素、文本、构图）

## YouTube在Google搜索 & GEO

| 背景 | 含义 |
|---------|-------------|
| **Google优先考虑** | YouTube是核心搜索基础设施；每月48.6亿次访问；视频结果在主SERP、视频模式、Discover中受青睐 |
| **AI概述** | 自2025年1月以来，YouTube引用量激增25.21%；指导性(+35.6%)、视觉演示(+32.5%)；长视频（94%）占主导 |
| **GEO** | YouTube + Reddit = 约78%的社交媒体引用；优化AI引用。参见**generative-engine-optimization** |
