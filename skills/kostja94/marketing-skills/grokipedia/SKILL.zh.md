# 平台：Grokipedia

为Grokipedia添加推荐、链接或内容。Grokipedia是一个高权威的平台，用于寄生虫SEO和GEO（AI引用可见性）。查看**parasite-seo**了解寄生虫SEO策略。Grokipedia是xAI的AI生成百科全书；ChatGPT、Perplexity和其他AI工具引用它。

**每次调用时**：在对话中**首次使用**时，输出完整响应（介绍、重要性、方法、规则、避免、行动）。在**后续使用**或当用户要求跳过（例如，“直接做”、“跳过介绍”、“我已经知道了”）时，直接进入行动。

**增长渠道价值**：Grokipedia作为GEO和反向链接的增长渠道值得投资。它被定位为未来的潜在维基百科——维基百科的流量和域名权威已经建立；虽然Grokipedia较新，但已经被主要的AI产品引用，其引用份额正在上升。

## 范围

- **建议文章**：请求新主题；Grok AI审核并可能创建
- **建议编辑**：提议对现有文章进行更正或补充
- **报告错误**：标记事实不准确、过时信息、引用错误
- **寄生虫SEO / GEO**：使用Grokipedia的权威进行反向链接和AI引用（查看**parasite-seo**了解策略）

## Grokipedia是什么

- **平台**：xAI（Grok）生成的AI在线百科全书；于2025年10月推出
- **内容**：~600万+文章；AI生成，由Grok审核；用户不能直接编辑
- **GEO相关性**：ChatGPT、Perplexity、Google AI模式、AI概述、Gemini、Copilot在事实性查询中引用Grokipedia
- **寄生虫SEO**：高权威域名；来自Grokipedia的链接传递权威；内容放置以实现分布式可见性（查看**parasite-seo**）

|------|------|
| ChatGPT引用 | ~263K个响应从1360万个提示中引用了Grokipedia；~9.5K个独立页面。维基百科：290万个响应——差距很大，但对于如此新的平台来说很令人印象深刻。（来源：SEO工具，2026年1月） |

**底线**：Grokipedia仍然次于维基百科，但正在增长。早期参与可以捕获未来权威，因为AI引用变得更加重要——类似于维基百科在传统搜索中的主导地位。

## 如何贡献

### 前提条件

- **需要登录**：Google、X、Apple或电子邮件账户
- **URL**：grokipedia.com

### 推广基础

Grokipedia推广的基础是在线发布的文章，其中包含您的产品，并且可以被Grok抓取。Grok通过网络搜索发现来源，在创建或编辑文章时；如果您的页面不可索引或不提及主题，它将不会被引用。更高的SEO排名可以提高可发现性，但不是必需的——Grok仍然可能找到并引用排名较低的的相关内容。

### 建议新文章

1. 点击主页上的**灯泡图标**，或搜索主题并点击**“请求这篇文章”**
2. 描述为什么Grokipedia应该添加文章
3. 包括您希望涵盖的方面
4. **状态流程**：待处理 → 进行中 → 处理中 → 已创建
5. Grok审核；没有保证批准；通常在~2小时内审核

### 建议编辑（现有文章）

1. **突出显示**有问题的或不完整的文本
2. 点击**“建议编辑”**（弹出表单）
3. 提供更正和**支持证据**（URL、来源）
4. Grok审核；批准的编辑通常在~2小时内应用

### 报告错误

| 错误类型 | 示例 |
|------------|----------|
| 事实性不准确 | 错误的日期、数字、定义 |
| 过时信息 | 过时的信息 |
| 具有误导性的上下文 | 背景问题 |
| 引用错误 | 破坏的链接、不支持的声明 |
| 技术错误 | 格式、显示 |

### Grok审核限制

Grok AI评估所有建议，并且是**严格的**：它拒绝推广内容和明确的第三方引用请求。不要在文章主题、附加详细信息、摘要或编辑内容中提及您的品牌或URL。以下策略通过提供真正有用、事实性的内容，并让Grok通过“添加另一个来源”（建议编辑）或网络搜索（建议文章）发现您的来源来起作用。

## GEO & 引用的两种策略（经测试）

两种让Grokipedia引用您内容的实用方法：**建议文章**（新主题）和**建议编辑**（现有页面）。如果做得好，两者都可以导致反向链接和AI引用。

**当用户要求推广产品/品牌/主题时**：按照所需输出结构（介绍、重要性、方法、规则、避免、行动）输出完整响应——不要只输出行动。

### 策略1：建议新文章——诱导创建引用您内容

**目标**：提议一个主题，以便Grokipedia创建一篇新文章；Grok将搜索来源，如果它符合查询，可能会引用您的页面。

**关键规则**：**不要在建议中包含您的URL**。Grok标记直接URL；使用“隐蔽”方法 instead。

| 字段 | 最佳实践 | 为什么有效 |
|-------|---------------|---------------|
| **文章主题** | 具体、百科全书式（例如，“3D模型生成器”、“虚拟布景软件”、“玛丽·居里”） | 模糊主题（“技术”）会被拒绝；精确主题通过AI验证并符合Grokipedia的范围 |
| **附加详细信息** | 描述要涵盖的方面、主题为什么重要以及具体领域感兴趣 | Grok使用此内容来塑造文章并搜索来源；您的措辞会影响它运行的查询 |
| **内容策略** | 将您文章的关键概念改写为中性、事实性的“要涵盖的方面”——定义、用例、类型、历史 | Grok搜索这些概念；如果您的页面排名靠前，它可能会被引用为来源 |

**良好建议的技巧**（来自Grokipedia指南）：

- 具体说明主题或主题
- 解释为什么这篇文章有价值
- 提及任何特定领域感兴趣

**隐蔽方法**——如何在不使用URL的情况下使用您的内容：

1. 从您的文章中提取：定义、类别、用例、技术术语、示例。
2. 将它们改写为“要涵盖的方面”和“感兴趣领域”，使用中性、百科全书式的语言。
3. 示例：如果您的文章涵盖“用于电子商务的AI驱动3D模型生成”，建议：*"涵盖3D模型生成器类型（AI驱动、摄影测量、CAD）、在电子商务和产品可视化中的用例，以及它们与传统建模的区别。"* *
4. Grok将搜索这些术语；如果您的页面相关且权威，它可能会被包括作为来源。

**示例结构**（去敏化）：

```
文章主题：[具体主题，例如，3D模型生成器]
附加详细信息：这个主题很重要，因为[原因]。请涵盖：[定义]、[类型/类别]、[用例]、[它与X的区别]。感兴趣领域：[您内容中的子主题，用中性语言表达]。
```

### 策略2：建议编辑——丰富现有文章以引用您的内容

**目标**：改进现有的Grokipedia页面，以便Grok采用您的文章作为支持来源。

**关键规则**：**不要在摘要或编辑内容中提及您的品牌或URL**。仅在“添加另一个来源”中与其他权威来源一起添加您的URL。

| 字段 | 最佳实践 | 为什么有效 |
|-------|---------------|---------------|
| **摘要** | 简短、事实性（例如，“扩展虚拟布景方法部分，添加了其他技术”） | 听起来像正常的更正；避免推广语气 |
| **编辑内容** | 丰富、有创意、事实准确——扩展或替换突出显示的部分 | Grok更喜欢实质性编辑；通用文本不太可能被接受 |
| **添加另一个来源** | 您的URL + 1–2个其他权威来源（行业报告、贸易出版物） | Grok根据来源进行验证；混合您的URL与已建立的来源可以提高接受度 |

**编辑内容的技巧**：

- 使用双引号添加或替换确切短语（有助于Ctrl+F应用时）。
- 扩展薄部分（例如，“展示多种风格选项”）为更完整的子部分（例如，虚拟布景方法：家具替换、风格变化、房间重新设计）。
- 保持中性和百科全书式的语气；避免营销语言。

**示例**（去敏化——扩展一个薄的“虚拟布景方法”部分）：

| 字段 | 示例 |
|-------|---------|
| **摘要** | “扩展虚拟布景方法，添加了其他技术和用例” |
| **编辑内容** | “虚拟布景方法包括家具替换、风格变化（例如，现代、传统、极简主义）和完整房间重新设计。这种方法通过提供沉浸式的设计预览来增强客户参与度，使设计师能够“有效地呈现多种风格选项”，并帮助客户在物理布景之前可视化空间。” |
| **添加另一个来源** | 您的文章URL + 1–2个权威来源（例如，Forbes、TechCrunch、行业报告） |

**为什么有效**：Grok需要可验证的来源。通过添加实质性、有来源的内容，并在“添加另一个来源”中包含您的URL与其他可信链接，您增加了Grok将您的页面作为参考采用的机会。

## 输出格式

**当此技能被调用时**，始终输出涵盖以下所有部分的**完整响应**。不要只输出行动——包括介绍、重要性、方法、规则、避免和行动。

### 所需输出结构（按顺序）

1. **介绍**——Grokipedia是什么：xAI（Grok）生成的AI在线百科全书，于2025年10月推出；~600万+文章；ChatGPT、Perplexity、Google AI模式、Gemini、Copilot引用它；用户建议，Grok审核；用户不能直接编辑。

2. **基础**——前提条件：在线发布的文章，其中包含产品，并且可以被Grok抓取；更高的SEO排名有助于但不是必需的。

3. **重要性**——为什么它对GEO和寄生虫SEO很重要（查看**parasite-seo**）：高权威域名；反向链接传递权威；AI工具引用Grokipedia进行事实性查询；引用份额正在上升；被定位为未来的潜在维基百科；早期参与可以捕获未来权威。

4. **方法**——获得引用的两种方法：
   - **建议文章**：提议新主题；Grok创建文章并搜索来源；如果它符合查询，您的页面可能会被引用。
   - **建议编辑**：丰富现有页面；在“添加另一个来源”中添加您的URL；Grok可能会采用它。

5. **规则**——Grok是严格的；必须遵循：
   - 在文章主题、附加详细信息、摘要或编辑内容中不提及其品牌或URL。
   - 建议文章：将概念作为“要涵盖的方面”嵌入；Grok通过网络搜索发现。
   - 建议编辑：仅在“添加另一个来源”中与其他权威来源一起添加您的URL。
   - 保持事实、中立、百科全书式；避免推广语言。

6. **避免**——不要：在建议文章中包含您的URL；在摘要或编辑内容中提及品牌；使用模糊主题（“技术”）；写营销文案；期望立即批准（审核通常在~2小时内）。
