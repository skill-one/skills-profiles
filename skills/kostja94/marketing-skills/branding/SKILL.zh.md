# 品牌策略

指导品牌策略：使命、价值观、定位、品牌故事、品牌声音和视觉识别。品牌一致性强的公司收入提升23-33%；人们通过故事记住的信息比单纯的事实多约22倍。在定义新品牌、审核一致性或跨触点对齐信息时使用此技能。

**关键词**：品牌策略、品牌指南、视觉识别、品牌故事、品牌声音、设计令牌、演示文稿、企业标识、风格指南、定位

**调用时机**：在**首次使用**时，如果有助于理解，先用1-2句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接提供主要输出。

## 范围

- **品牌策略**：使命、价值观、定位、差异化、目标受众
- **品牌故事**：起源故事、英雄之旅、叙事弧、品牌原型
- **品牌声音与语气**：声音、语气、避免使用术语、推荐用词
- **品牌视觉识别**：颜色、字体、标志规则——策略层面；在**品牌视觉生成器**、**标志生成器**中实施

## 初步评估

**项目背景**：当存在根`contextus.md`时，读取并仅加载与此任务相关的模块。没有Contextus时，使用可用的项目材料或用户提供的事实，并询问缺失信息；不要创建并行背景系统。

识别：
1. **范围**：新品牌、审核或对齐
2. **触点**：网站、社交、产品UI、目录、内容
3. **现有资产**：品牌指南、标志、风格指南

## 品牌策略支柱

| 支柱 | 目的 |
|------|------|
| **品牌使命** | 品牌超越利润存在的理由；一句话 |
| **品牌价值观** | 4-5个核心价值观；你代表什么；差异化 |
| **目标受众** | 你服务的人；ICP；要完成的任务 |
| **定位** | 对于[客户]来说，我们的[产品]是一种[类别]，它[利益]。与[竞争对手]不同，我们[差异化]是因为[原因] |
| **差异化** | 为什么是你而不是替代品；具体而非模糊 |

## 品牌故事

### 起源故事

- **内容**：旅程、创始、里程碑、塑造公司的个人经历
- **目的**：情感连接；58%的客户基于公司价值观购买
- **要素**：谁创立的；为什么创建；克服的挑战；愿景；如何发展

### 英雄之旅（客户作为英雄）

| 要素 | 内容 |
|------|------|
| **英雄** | 你的客户；他们的需求、愿望、背景 |
| **问题** | 他们面临的问题；他们现在如何解决 |
| **启发性的洞察** | 创造紧迫感的重新框架 |
| **品牌的作用** | 指导者、工具或合作伙伴——不是英雄；你如何实现解决方案 |
| **转变** | 更好的未来是什么样子；证据（案例研究、客户评价） |

### 品牌叙事弧

- **主人公**：面临挑战的客户
- **赌注**：如果什么都不改变会发生什么
- **证据**：数据、案例研究、客户评价
- **行动号召**：在故事中放置行动号召；激发行动

## 品牌声音与语气

| 要素 | 定义 | 例子 |
|------|------|------|
| **声音** | 品牌个性；跨触点保持一致 | 专业 / 友好 / 技术 / 大胆 |
| **语气** | 你如何表达；根据上下文调整 | 自信但不傲慢；有帮助；简洁 |
| **避免** | 行话、永远不使用的术语 | "精简"、"革命化"、"协同" |
| **推荐** | 一致使用术语 | "审核"而不是"分析"；"客户"而不是"用户" |

**Contextus品牌模块**：维护项目特定的声音、语气、禁止语言和推荐术语在Contextus中。

## 品牌指南结构

单一事实来源。包括：

- **使命与价值观**：你存在的理由；你代表什么
- **定位**：一句话；差异化
- **故事**：起源故事；英雄之旅摘要
- **声音与语气**：声音、语气、避免、推荐
- **标志**：使用规则、清晰空间、变体（亮/暗）
- **颜色**：主要、次要、行动号召（HEX、RGB、CMYK）
- **字体**：字体家族、层次结构、尺寸
- **图像**：摄影语气；图标风格

## 视觉规格交付（设计令牌）

当用户需要**可操作的规格**（而不仅仅是策略）——用于网络、幻灯片或印刷品时——生成一个**令牌表**，团队可以将其粘贴到设计系统、媒体包或幻灯片主样式中。与**品牌视觉生成器**对齐以获取完整的网络/CSS细节。

| 令牌类别 | 记录内容 | 示例字段 |
|------|------|------|
| **颜色** | 命名角色+如果适用则为亮/暗的值 | 主要`#______`，文本主要`#______`，背景`#______`，强调1-3，行动号召，边框，错误/成功 |
| **字体** | 家族、权重、尺寸范围、行高 | 显示 / H1–H3 / 正文 / 标题；网络安全或系统备用 |
| **间距** | 基准单位和范围 | 例如 8px基准；部分间隙；标志清晰空间以`em`或`px`表示 |
| **非文本强调** | 图表、形状、分隔符 | 旋转强调颜色；避免任意一个独立色调超出调色板 |

**跨表面应用令牌**

- **网络/产品**：CSS变量或设计令牌；参见**品牌视觉生成器**。
- **幻灯片（PowerPoint、Google幻灯片、Keynote）**：设置幻灯片主样式的背景+默认标题/正文字体来自令牌表；将主题颜色映射到主要/次要/背景/文本；尽可能在每节幻灯片中重用一个强调色。
- **文档（Word、Google文档、PDF）**：使用令牌中的字体和颜色定义段落样式（标题、标题1-3、正文、标题），设置默认页面背景如果品牌使用米白。

如果用户**粘贴现有的品牌PDF或项目符号列表**，提取并规范化到这个令牌表，然后再建议实施。
