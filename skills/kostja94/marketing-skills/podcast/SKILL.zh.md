# 内容：播客

指导播客策略、内容创作、分发、营销和SEO。播客在竞争激烈的市场中竞争（300万个活跃节目，全球5亿听众）；可发现性是主要挑战。发现渠道：约32%搜索引擎，约28%播客应用，约24%社交媒体，约16%口口相传。

**调用时**：在**首次使用**时，如果有帮助，先用1-2句话说明这项技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接进入主要输出。

## 初步评估

**项目背景**：当存在时，读取根`contextus.md`并仅加载与此任务相关的模块。没有Contextus，使用可用的项目材料或用户提供的事实，并请求缺失信息；不要创建平行背景系统。

识别：
1. **阶段**：规划、启动、增长
2. **格式**：访谈、单人、联合主持、叙事
3. **细分领域**：目标受众、听众画像
4. **目标**：下载量、权威性、潜在客户生成、再利用

## 内容策略

| 元素 | 指导方针 |
|------|----------|
| **细分领域聚焦** | 通过听众画像定义受众；定制化内容能穿透噪音 |
| **质量胜于花招** | 粘性、独特、有价值的内容；大多数主持人在持续5-6个月后看到显著增长 |
| **节目结构** | 介绍、主要内容、行动号召；一致格式有助于留存 |

## 分发与发现

| 渠道 | 分享率 | 优化 |
|------|--------|-------|
| **搜索引擎** | 约32% | 文本稿、节目简介、SEO优化的标题/描述 |
| **播客应用** | 约28% | 标题、描述、封面艺术；类别选择 |
| **社交媒体** | 约24% | 片段、引用、再利用的内容 |
| **口口相传** | 约16% | 交叉推广、嘉宾出现 |

**多渠道**：跨平台再利用内容，以扩大发现表面。

## 播客SEO

搜索引擎无法收听音频。基于文本的内容至关重要：

| 元素 | 指导方针 |
|------|----------|
| **文本稿** | 完整或关键时刻文本稿；可索引、可访问 |
| **节目简介** | SEO优化；吸引自然搜索流量；自然包含关键词 |
| **标题** | ≤60个字符；关键词；吸引人的语言 |
| **描述** | 节目特定；关键词；语音搜索友好 |
| **反向链接** | 建立到节目简介、嘉宾文章、目录列表的链接 |

**模式**：使用**PodcastEpisode**和**PodcastSeries**获取丰富结果。参见**schema-markup**了解实现方法。
