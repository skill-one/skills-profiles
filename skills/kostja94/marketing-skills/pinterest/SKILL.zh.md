# 平台：Pinterest

指导 Pinterest Pin 的创建和优化。Pinterest 用户与 Google 的搜索方式不同；长尾关键词如“简单晚餐食谱”比宽泛术语表现更好。在创建 Pins、优化板块或规划 Pinterest 内容时使用此技能。

**调用时**：在**首次使用**时，如果有帮助，先用 1-2 句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或当用户要求跳过时，直接提供主要输出。

## 初步评估

**项目背景**：当存在根 `contextus.md` 文件时，读取该文件并仅加载与此任务相关的模块。没有 Contextus 时，使用可用的项目材料或用户提供的事实，并询问缺失信息；不要创建一个平行的上下文系统。

识别：
1. **内容类型**：产品、食谱、教程、灵感
2. **板块**：Pin 首次保存的位置（决定 Pinterest 的理解方式）
3. **目标**：流量、销量、邮件订阅

## Pin 标题

| 规则 | 指导方针 |
|------|-----------|
| **长度** | 最多 100 个字符；前 40 个字符在信息流中可见 |
| **关键词** | 主要关键词在前 40 个字符内 |
| **公司名称** | 在第一句话中 → 邮件订阅转化率提高 54% |

## Pin 描述

| 规则 | 指导方针 |
|------|-----------|
| **长度** | 220-232 个字符最佳 |
| **关键词** | 主要关键词 + 2-3 个相关；自然放置 |
| **行动号召** | 清晰、可执行 → 邮件订阅率提升 70%，销量提升 6% |
| **价格** | 当相关时 → 销量增加 28% |

## 板块 SEO

- **板块名称**和**描述**是排名因素
- **首次保存**板块决定 Pinterest 对内容的理解
- 在板块标题和描述中使用关键词

## 2025 算法提示

- **新鲜内容**：新 URL + 新图片 + 新板块 = 最大分发
- **替代文本**：带有替代文本的 Pin 获得约 25% 的更多展示次数，点击率提升 123%
- **一致性**：关键词优化的内容保存到相关板块

## 输出格式

- **标题**（少于 100 个字符）
- **描述**（220-232 个字符）
- **板块推荐**
- **替代文本建议**
