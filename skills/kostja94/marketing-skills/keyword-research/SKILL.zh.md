# SEO 内容：关键词研究

本指南指导 SEO 关键词研究：寻找目标关键词、评估难度、理解搜索意图以及构建主题地图。~95% 的关键词每月搜索量少于 10 次；低搜索量、高意图的关键词通常能更快获得排名和转化。

**调用方式**：在**首次使用**时，如果有帮助，先用 1-2 句话说明本技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接提供主要输出。

## 初步评估

**项目背景**：当存在根 `contextus.md` 文件时，读取该文件并仅加载与此任务相关的模块。没有 Contextus 时，使用可用的项目材料或用户提供的事实，并询问缺失信息；不要创建一个平行的背景系统。

识别：
1. **产品/服务**：你提供什么
2. **受众**：谁会搜索它
3. **目标**：流量、转化、品牌
4. **工具访问**：Google 关键词规划师、Google 趋势或 SEO 工具

## 发现方法

### 基础发现

| 方法 | 目的 |
|------|------|
| **用户视角** | 用户的痛点是什么？他们会搜索什么？产品背景中的客户语言 |
| **工具扩展** | 相关关键词、问题、建议；Google 自动完成、PAA、相关搜索 |
| **竞争对手反向分析** | 分析竞争对手的标题、H1、URL；识别他们排名的主题；找到差距 (#4–10 = 机会) — 参见 **竞争对手研究** |
| **Google PAA** | 人们也问和相关搜索；来自真实用户行为的信号，高价值 |
| **从文章中提取** | 当审核现有内容时：从标题、H1、H2、元关键词、前 100 个字中提取种子关键词；然后搜索 `"[主要关键词]"` 或 `"[主要关键词] 相关关键词"` 寻找机会；如果知道竞争对手，使用 `"[主要关键词]" site:competitor.com` |

### Google 自动完成（长尾发现）

Google 自动完成反映了真实用户搜索；建议仅在查询有实际流量时出现。免费；通常能发现关键词工具遗漏的低搜索量长尾词。~70% 的搜索流量是长尾；竞争度低，转化率高。

**字母方法**（种子 + 空格 + 字母）：
- 输入种子关键词 + 空格 + 每个字母：`keyword a`，`keyword b`，... `keyword z`
- 记录相关建议；用数字 0-9 重复
- 示例：`SEO a` -> "SEO 审计," "SEO 代理"；`SEO b` -> "SEO 基础," "SEO 最佳实践"

**位置变体**（种子在不同位置）：
- **前缀**：`a keyword`，`b keyword`（发现用户添加什么）
- **后缀**：`keyword a`，`keyword b`（最常见；字母方法）
- **中间**：`how to keyword a`，`best keyword for`（问题 + 修饰词组合）

**问题修饰词**：
- `how to keyword`，`what is keyword`，`why keyword`，`when to keyword`，`keyword vs`
- `keyword for beginners`，`keyword for small business`，`keyword without`

**为什么有效**：关键词工具过滤低搜索量词；自动完成仅显示有实际流量的查询。与 PAA 和相关搜索结合使用以实现全面覆盖。按意图（信息性、商业性、交易性）分类结果。

### 增量发现

- **用户反馈**：支持、社区、评论、NPS—高频问题 = 未满足的搜索需求
- **多平台搜索**：Reddit、Quora、X（Twitter）、Hacker News—真实问题和讨论

## 搜索意图

| 意图 | 内容类型 | 示例 |
|------|----------|------|
| **信息性** | 博客、指南、FAQ | "如何优化网站地图" |
| **导航性** | 品牌页面 | "alignify 登录" |
| **商业性** | 比较、评论 | "SEO 工具比较" |
| **交易性** | 产品、价格 | "最佳 SEO 工具价格" |

### 意图识别

**修饰词**（通常表示意图）：

| 意图 | 修饰词 |
|------|--------|
| 信息性 | "如何," "什么," "为什么," "指南," "教程" |
| 商业性 | "最佳," "比较," "vs," "评论," "顶级" |
| 交易性 | "购买," "价格," "便宜," "优惠券," "免费运输" |
| 本地化 | 地点名称 |

**SERP 检查**：搜索该词—知识卡片/Wiki → 信息性；产品列表/评论 → 商业性；品牌网站 → 导航性。更广泛的术语通常显示混合 SERP。参见 **serp-features** 了解特征类型。

## 长尾扩展

- **Google 自动完成**：字母方法、位置变体、问题修饰词；见上文。长尾的主要来源。
- **意图修饰词**：核心 + "如何," "最佳," "vs," "比较," "价格"
- **问题词**： "如何," "什么," "为什么," "何时"
- **功能修饰词**：核心 + "-er/-or"（例如，"图像优化器"用于工具类型查询）；通常转化率更高
- **聚类**：按 SERP 重叠（相同顶级页面）、语义相似性或意图分组。

## 关键词聚类与主题地图

| 方法 | 使用 |
|------|------|
| **SERP 重叠** | 关键词具有重叠的顶级排名页面 → 相同集群 |
| **语义** | 按含义、LSI、相关概念分组 |
| **意图** | 按意图分组；集群内意图不同时，分离页面 |

**支柱-集群**（将关键词映射到结构）：
- **支柱**（中心）：广泛主题页面；链接到集群
- **集群**（分支）：专注子主题；链接回支柱
- 优先目标长尾；然后支柱。在主题内相互链接集群。
- 参见 **内容策略** 了解完整的支柱-集群规划和实施。

## 评估与筛选

| 因素 | 考虑 |
|------|------|
| **搜索量** | 每月搜索量；~100+/月典型底线；利基市场可放宽 |
| **关键词难度 (KD)** | 新网站目标低 KD |
| **CPC** | 高 CPC 通常 = 强大的商业意图 |
| **SERP 特征** | 特性片段、PAA、零点击；SERP 特征可以在不点击的情况下满足意图—影响实际流量；参见 **serp-features**（零点击部分）、**特性片段** |
| **筛选顺序** | 1) 移除不相关的 2) 过滤极低搜索量 3) 评估可实现性 4) 优先商业/交易性 |

## 产品定位测试（SEO 适用性）

测试定位是否清晰到足以供搜索：

- **XXX + 功能词**：生成器、创建者、制造商、构建者、改变者、缩短器、刮取器、转换器、下载器、翻译器、扩展器、摘要器、调整器、移除器、提取器、记录器、重写器、解决者、计算器；或平台、工具、软件、应用程序、提供者、助手、Copilot
- **输入 + to + 输出**：例如，"图像到视频," "文本到语音"—清晰的输入/输出信号意图

**Agent/Copilot 产品**：纯原生 Agent 难以通过 SEO 发展；用户很少搜索 "agent"。首先发布相关功能（例如，CRM、销售机器人用于销售 agent）以建立流量，然后引导到 Agent 产品。

## 原则

- **核心规则**：必须有人搜索它—使用工具验证；避免发明术语
- **功能关键词**：工具类型（-er/-or）通常转化率更高；用户更接近行动
- **多语言**：在目标语言中重新研究；不要翻译现有列表。参见 **翻译** 了解翻译工作流程。

## SEO–PPC 关键词协同

关键词研究服务于 SEO 和 Google 广告。对齐两个渠道，避免重复、蚕食和浪费支出。

| 数据流 | 使用 |
|------|------|
| **keyword-research → google-ads** | 关键词列表、集群、意图；支持术语（登录、论坛、价格）→ PPC 的否定关键词 |
| **google-ads → keyword-research** | PPC 转化率、搜索词报告 → SEO 优先级；高转化 PPC 术语 = 值得自然排名 |
| **keyword-research → landing-page** | 集群 → 每个意图的专用 LP；PAA 问题 → FAQ 部分 |
| **GSC 有机排名 4+** | 如果你有机排名良好，考虑减少/暂停这些术语的 PPC 以避免蚕食 |

**PPC 数据用于 SEO 优先级**：`SEO ROI ≈ (有机点击 × PPC 转化率 × 客户价值) − SEO 成本`。使用 PPC 转化数据验证要追求哪些关键词进行自然排名。

**参考**：[Backlinko – SEO 和 PPC：8 智能对齐方式](https://backlinko.com/seo-and-ppc)

## 报告工作流程

1. **解析** — 读取 Excel/CSV，从标题推断关键词、搜索量、KD、意图等
2. **丰富** — 网络搜索，访问竞争对手/产品页面；如果存在，读取根 `contextus.md`
3. **构建** — 为报告结构化数据
4. **生成** — 以选定格式输出报告

## 输出格式

- **关键词列表**，包含搜索量、KD、意图
- **关键词映射**到页面/内容
- **内容差距**（竞争对手排名，你未排名）
- **优先级**实施排名
- **主题地图**（集群 → 支柱 → 页面映射）

### 报告结构参考

| 部分 | 内容 |
|------|------|
| 执行摘要 | 优先级（前 3） |
| 关键词概述 | 总关键词数、主要意图、平均 KD、内容差距计数 |
| 关键词列表 | 关键词、搜索量、KD、意图、优先级、目标页面 |
| 关键词映射 | 页面/URL、目标关键词、状态 |
