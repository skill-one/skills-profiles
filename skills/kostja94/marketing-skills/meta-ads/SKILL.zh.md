# 付费广告：Meta 广告

指导 Meta（Facebook/Instagram）广告的设置、广告系列结构、受众定向以及创意优化。Meta 擅长需求生成和视觉化产品；在创造需求或创意资产具有优势时使用。

**何时调用**：在**首次使用**时，如有助益，先用 1–2 句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接提供主要输出。

## 广告系列结构

**层级结构**：广告系列（Campaign）→ 广告组（Ad Set）→ 广告（Ad）（共 3 层）

**原则**：每个广告系列对应一个目标。同一目标的多个广告系列会分散预算和数据，从而延缓算法的学习阶段。按目标进行整合；专注于清晰的结构和数据驱动的决策。

```
账户
├── 广告系列：拉新（Prospecting）
│   ├── 广告组：类似受众 1%（Lookalike 1%）
│   └── 广告组：广泛（Advantage+）（Broad (Advantage+)）
├── 广告系列：再营销（Retargeting）
└── 广告系列：测试（Testing）
```

**命名规范**：`META_[目标]_[受众]_[优惠]_[日期]`（例如：`META_Conv_Lookalike-Customers_FreeTrial_2024Q1`）

## Advantage+ 与自动化

| 功能 | 用途 |
|---------|-----|
| **Advantage+ 购物广告系列** | 电商；自动发现受众 |
| **动态广告** | 产品目录；自动生成创意 |
| **自动位置投放** | 让 Meta 在信息流（Feed）、快拍（Stories）、Reels 中自动优化 |
| **Advantage+ 受众** | 广泛定向；由算法寻找转化用户 |

提供多样化的创意资产以支持多种广告格式；多样性有助于算法表现更佳。

## 广告系列目标

| 目标 | 适用场景 |
|-----------|----------|
| 认知度（Awareness） | 触达；品牌回忆度 |
| 流量（Traffic） | 点击到网站 |
| 转化（Conversions） | 潜在客户获取；销售；应用安装 |
| 互动（Engagement） | 视频观看量；帖子互动 |

## 受众定向

| 类型 | 最佳适用对象 |
|------|----------|
| **类似受众（Lookalikes）** | 基于最佳客户（按 LTV 衡量），而非所有客户 |
| **兴趣/行为** | 广泛范围；让算法进行优化 |
| **Advantage+** | 自动化；手动控制更少 |
| **再营销（Retargeting）** | 网站访客；互动用户；自定义受众 |

**排除项**：现有客户；近期转化者（7–14 天）。

## 创意最佳实践

- **图片**：产品清晰；前后对比；人脸；文字占比 &lt;20%
- **视频（15–30 秒）**：0–3 秒钩子；3–8 秒问题；8–20 秒解决方案；20–30 秒行动号召（CTA）
- **投放位置**：信息流（FB/IG）；快拍/Reels；快拍使用竖屏格式
- **数量**：每个广告组提供 3–5 个广告变体用于测试

## 优化

- **学习阶段**：每个广告组每周需 50+ 次转化才能结束；避免在学习期间频繁更改
- **CBO 与 ABO**：广告系列预算优化（Campaign Budget Optimization）整合支出；在扩大规模时使用
- **频率**：保持 &lt;3 以避免疲劳
- **创意更新**：计划持续测试；创意疲劳是关键调节手段——当表现下降时进行更新

## 追踪

- **Meta Pixel** + **转化 API（Conversions API）**：服务端追踪以实现更精准的归因
- **事件 API（Events API）**：应用事件；服务端到服务端
