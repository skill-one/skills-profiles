# 预算与竞标

1. 确立目标、转化价值、毛利、现金流限制、销售能力、归因不确定性、季节性以及平台最低证据。
2. 将支出和结果标准化到可比较的时间段和定义。
3. 计算盈亏平衡界限，并展示公式、输入、不确定性以及敏感性案例。
4. 区分承诺基准线、受控实验和备用容量。
5. 使用边际证据而非仅凭混合平均值来比较持有、重新分配、扩展、缩减或实验选项。
6. 返回一个决策完整的计划，包括平台/活动金额、时间、负责人、约束条件、成功指标和回滚触发条件。

例如70/20/10规则、固定CPA倍数、固定预算-CPA比率以及固定百分比扩展等规则是可选的启发式方法，绝非普遍授权。
