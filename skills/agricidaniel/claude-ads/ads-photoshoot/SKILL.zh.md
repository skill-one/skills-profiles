# 产品摄影变体

1. 确认产品图片的授权，并收集经过验证的品牌资料、产品特性、预期用途、供应商能力、成本上限和输出源。
2. 除非操作员明确批准变更，否则需保留产品几何形状、包装、标志、标签、颜色和材质。
3. 定义不同的生产假设，例如影棚拍摄、场景使用、成分故事、比例/细节或生活方式；不得暗示未经支持的产品效果。
4. 生成批准的宽高比，并记录源哈希值、提示版本、供应商/模型、成本、输出哈希值和尺寸。
5. 验证产品保真度、视觉缺陷、安全区域、可访问性和政策。
6. 将资产和清单原子式存储在运行目录中。

必须进行人工审核。未经授权，不得创建欺骗性的前后对比证据、人物或背书，或从视觉暗示中得出受监管的声明。
