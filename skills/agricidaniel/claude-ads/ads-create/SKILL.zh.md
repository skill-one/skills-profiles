# 活动概念与文案

1. 加载经过验证的设置/品牌资料、目标、受众、优惠、证据、平台/位置要求、政策背景和可选的审计发现。
2. 将事实性声明、运营者批准的声明和创意假设分开。
3. 对于Meta工作，根据`skills/ads-meta/SKILL.md`中的合同要求收集账户、像素和转化冷启动维度。当任何维度为冷或`未知`时，在简报中注明，不要重用成熟账户的创意基准或性能声明，并且绝不能因为像素是新的就称现有创意为不良。
4. 生成实质性不同的策略概念，而非仅限于表面修改。
5. 对于每个概念，定义洞察、承诺、证据、钩子、叙事、行动号召、反对意见、平台适应性、目的地和实验假设。
6. 验证文案限制和政策，并与当前平台参考进行比对。仅加载`ads/references/google-creative-specs.md`、`meta-creative-specs.md`、`youtube-creative-specs.md`、`linkedin-creative-specs.md`、`tiktok-creative-specs.md`和`microsoft-creative-specs.md`中的活跃文件；使用日期来源账本来支持当前规范声明。
7. 在运行目录中返回一个版本化的创意简报和文案演示文稿。

不要编造证言、认证、稀缺性、价格、结果或受监管的声明。在生产和发布前仍需人工审核。
