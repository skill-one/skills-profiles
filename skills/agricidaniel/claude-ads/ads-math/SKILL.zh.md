# 付费媒体财务模型

1. 识别决策并收集单位、货币、期间、税收/退税处理、利润率、归因基础及不确定性。
2. 展示公式并将每个输入映射到操作值或引用文件。
3. 验证分母、符号、缺失值、不兼容窗口及单位转换。
4. 计算基准、下行及上行情景，其中不确定性影响决策。
5. 将平台归因收入、混合业务收入、现金流及贡献利润区分开。
6. 返回机器可读的输入、公式、输出、敏感性及决策影响。

不得虚构缺失的财务输入、隐藏除零错误，或在不提供其假设的情况下呈现点预测。
