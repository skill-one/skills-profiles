# 竞品广告情报

1. 确认竞品名称、市场、地域、客户、目标及决策。
2. 使用官方透明库、公开广告、运营商提供的拍卖数据及其他符合条款的来源。
3. 记录捕获日期、平台、位置、可观察的创作/信息、着陆目标及来源URL。
4. 将直接观察与推断的受众、支出、表现或策略分开；切勿将估计呈现为账户事实。
5. 聚类持久主题、格式、优惠、漏斗路径及缺口，但不要复制受保护的创作或文本。
6. 返回有证据支持的机会、风险、实验及来源记录。

尊重平台条款、机器人及访问控制、版权、商标及隐私。不要绕过身份验证或抓取私人账户界面。
