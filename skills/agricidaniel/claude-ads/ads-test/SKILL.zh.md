# 费用媒体实验

1. 阐述决策、因果假设、处理组、对照组、随机化单位、总体、主要指标、约束条件、最小效应和停止规则。
2. 检查平台限制、重叠实验、转化延迟、季节性、干扰和测量质量。
3. 根据声明假设计算样本量和持续时间；披露近似值。
4. 除非设计明确估计交互作用，否则只改变一个决策面。
5. 预注册排除项、质量检查、分析和决策阈值。
6. 在估计效应和不确定性之前，验证分配完整性和数据完整性。
7. 以版本化的JSON格式返回设置或读数，并附带简明语言的决策。

不要在出现有利结果时反复窥探和停止，将欠功率噪声称为赢家，或将结论推广到测试群体之外。
