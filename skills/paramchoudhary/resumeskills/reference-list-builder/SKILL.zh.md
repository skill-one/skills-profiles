# 参考书目构建器

## 何时使用此技能

当用户：
- 需要创建专业的参考书目
- 想要获得选择合适参考的帮助
- 需要正确格式化参考
- 正在为工作申请准备参考
- 提及：“参考”、“参考书目”、“专业参考”、“参考核查”

## 核心功能

- 格式化专业参考书目
- 指导参考选择策略
- 准备参考简介材料
- 预期参考核查问题
- 处理困难的参考情况
- 协调参考联系

## 参考策略

### 谁是好的参考人？

**理想参考人：**
- 以前的直接经理（最重要）
- 观察过你工作的资深同事
- 跨职能合作伙伴
- 客户或客户
- 直接下属（用于领导职位）
- 教授或顾问（适用于近期毕业生）

**参考人等级：**
1. **最有价值：** 最近的直接主管
2. **非常宝贵：** 了解你工作的资深领导者
3. **宝贵：** 同事和跨职能合作伙伴
4. **可接受：** 客户、供应商、教授
5. **避免：** 朋友、家人、仅限HR联系人

### 需要避免的人

- ❌ 当前雇主（未经许可）
- ❌ 几乎不了解你的人
- ❌ 仅来自10年以上的参考
- ❌ 朋友（除非特别说明）
- ❌ 可能给出平淡反馈的人
- ❌ 事先未联系过的人

## 参考书目格式

### 标准格式

```
专业参考书目

简·史密斯
产品高级总监
TechCorp Inc.
电话：(555) 123-4567
邮箱：jane.smith@techcorp.com
关系：3年直接主管（2020-2023）

约翰·多伊
工程副总裁
前公司
电话：(555) 234-5678
邮箱：john.doe@previous.com
关系：5个主要项目的跨职能合作伙伴
```

### 需要包含的信息

**必需：**
- 全名
- 当前职位
- 当前公司
- 电话号码
- 专业邮箱
- 你与他们之间的关系

**可选：**
- LinkedIn链接
- 最佳联系时间
- 偏好的联系方式

### 格式指南

- 与你的简历风格匹配（字体、格式）
- 3-5个参考（仅如果要求更多）
- 与简历分开的单独页面
- 标头应与简历标头匹配
- 标题应包含“参考”或“专业参考”

## 参考准备

### 第一步：征得同意

**在列出任何人之前：**
- 打电话或发邮件征得同意
- 确认他们的联系信息
- 解释你申请的职位
- 评估他们的意愿和热情

**脚本：**
```
“嗨[姓名]，希望你一切顺利！我正在申请[公司]的[职位]职位，不知道你是否愿意作为我的参考人。这个职位涉及[简要描述]，我认为你对[特定项目/技能]的看法特别有价值。如果他们联系你，你会愿意与他们交谈吗？”
```

### 第二步：向参考人简要介绍

**发送给他们：**
- 你的简历副本
- 职位描述
- 你想强调的关键点
- 特定项目
- 他们可能被联系的时间表

**简介邮件模板：**
```
主题：参考准备 - [职位]在[公司]

嗨[姓名]，

非常感谢你同意作为参考人！以下是一些背景信息以帮助你：

**职位：** [职位]在[公司]
**他们正在寻找：** [关键要求]

**我强调的重点：**
- [成就1]
- [成就2]
- [技能他们应该提及]

**我们共同工作他们可能会询问：**
- [项目1]
- [项目2]

我附上了我的简历和职位描述供参考。他们可能在接下来的[时间范围]内联系。

请让我知道如果你有任何问题，再次感谢！

最好的，
[你的名字]
```

### 第三步：跟进

参考人核查后：
- 无论结果如何都要感谢你的参考人
- 告诉他们结果
- 提供互惠

## 处理特殊情况

### 当前雇主不知道

**选项：**
- 询问参考核查可以推迟到后期
- 使用已经离开公司的同事
- 坦诚： “我的当前雇主不知道我在找工作”
- 使用其他专业参考

### 经理离开了公司

**选项：**
- 在LinkedIn上找到他们
- 使用他们的个人邮箱/电话
- 在参考书目中包含他们新的公司
- 解释“前任经理，现在在[新公司]”

### 与过去的经理关系不好

**选项：**
- 使用该职位的另一位主管
- 使用资深同事
- 选择来自不同职位的参考
- 如果被问及，准备好解释

### 专业经验有限

**选项：**
- 教授或学术顾问
- 实习主管
- 志愿组织领导者
- 教练或导师
- 客户联系人

### 参考人不会给出正面评价

**不要使用他们。** 拥有较少参考比一个平淡或负面参考更好。

## 参考核查人会问什么

### 常见问题

**绩效：**
- “你会如何描述[姓名]的工作？”
- “他们的主要职责是什么？”
- “他们的表现是否符合预期？”

**技能：**
- “他们的最大优势是什么？”
- “哪些方面可以改进？”
- “你会如何评价他们的[特定技能]？”

**工作风格：**
- “他们如何应对压力/截止日期？”
- “他们如何与团队合作？”
- “他们如何处理冲突？”

**性格：**
- “你会重新雇佣他们吗？”
- “还有什么其他我应该知道的吗？”
- “他们与同龄人相比如何？”

### “你会重新雇佣他们吗？”这个问题

**最重要的问题。** 简要介绍参考人可能会问到这个问题，并确保他们可以热情地回答。

## 参考时间

### 何时提供参考

- **不要随初始申请一起提供**（除非要求）
- **面试时带上**（准备好）
- **被问及时提供**（通常在最终面试后）
- **每次提供前都要询问**（每次确认许可）

### 常见时间线

1. **申请：** “参考人可应要求提供” （简历上可选）
2. **第一轮面试：** 准备好名单但不要提供
3. **最终轮：** “你能提供参考人吗？” → 分享名单
4. **参考核查：** 公司联系你的参考人
5. **提供职位：** 跟进参考人，感谢他们

## 参考清单

- ✅ 准备好3-5个参考人
- ✅ 所有参考人都已同意
- ✅ 联系信息是当前且准确的
- ✅ 参考人了解具体职位
- ✅ 每个参考人都有你的简历和谈话要点
- ✅ 至少有一位直接主管
- ✅ 参考人涵盖你工作的不同方面
- ✅ 参考人是热情的（而不仅仅是愿意）
- ✅ 确定了备用参考人
- ✅ 计划了感谢信息
