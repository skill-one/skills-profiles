# 自动更新功能

该功能通过运行夜间定时任务来保持 OpenClaw 的更新，该任务会执行一个外部 shell 脚本——因此即使网关重启，更新也能正常工作。

## 快速设置

要启用自动更新，请说“设置自动更新器”，我将：
1. 将更新脚本复制到您的家目录
2. 创建一个定时任务，每天凌晨 4 点执行该脚本

## 为什么使用脚本？

代理在网关重启时无法执行命令。我们使用一个独立的 shell 脚本，该脚本独立于代理运行。

## 更新脚本

```bash
#!/bin/bash
# OpenClaw 自动更新器

openclaw gateway stop
openclaw update.run
openclaw gateway start
```

## 更改更新时间

告诉我“将更新时间改为 [时间]”，我将更新定时任务计划。

## 手动更新

说“立即更新自己”并我将立即运行脚本。

## 故障排除

检查日志文件：`~/openclaw-update.log`
