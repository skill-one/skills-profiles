# 寻找关键词

使用意图映射、难度调整的机会评分和集群播种，从种子主题构建优先级关键词宇宙。

## 开始前

收集此上下文（如未提供，请询问）：

1. **域名和目标。** 这个网站是做什么的？主要转化是什么（线索、注册、销售、流量）？
2. **种子主题。** 核心主题领域——不是单个关键词，而是业务类别（例如，“项目管理软件”、“芝加哥个人伤害法”）。
3. **现有排名。** 网站是否已经在该领域排名？现有排名告诉你在哪里防御，在哪里扩展。
4. **限制条件。** 预算、团队规模、内容速度——这些决定了是追逐头部关键词还是专注于长尾关键词。

## 第 0 步：资源竞争筛选

在构建新的关键词列表之前，检查网站是否已经针对某些关键词。为已经排名的关键词创建新页面可能会分散权重，损害两个页面。

对于每个你正在考虑的关键词：

1. **搜索 `site:yourdomain.com [keyword]`** — 是否已有页面已经针对此关键词？
2. **检查 Google 搜索控制台** — 是否已有页面已经获得此关键词的展示次数？
3. 如果是：**更新现有页面** 而不是创建新页面。
4. 如果多个页面针对相同的关键词：你存在资源竞争问题。在扩展之前进行整合。

### 易于获取的果实检查

在追逐新关键词之前，寻找现有成果：

- **第 11-20 位** — 你几乎在第一页。这些关键词需要内容改进或更好的内部链接，而不是新页面。
- **高展示次数，低点击率** — 标题/元描述优化可以解锁流量，无需新内容。
- **排名下降** — 你正在失去排名的关键词可能需要内容更新（见 recover-content）。

在构建净新关键词列表之前解决这些问题。

## 关键词宇宙构建

分三个层级构建宇宙：

### 第 1 层 — 头部关键词（高流量，高难度）

- 通常 1-2 个词
- 定义类别
- 使用支柱页面或主页进行目标
- 现实时间线：新网站 6-18 个月

### 第 2 层 — 主体关键词（中等流量，中等难度）

- 通常 2-3 个词，足够明确意图
- 使用专用着陆页或集群文章进行目标
- 成熟网站 3-6 个月窗口期

### 第 3 层 — 长尾关键词（低流量，低难度）

- 3 个词以上，特定意图
- 最快排名，最高转化率
- 使用博客文章、常见问题部分、支持内容进行目标
- 新鲜内容 4-12 周窗口期

对于每个层级，生成：

| 关键词 | 月均流量 | 难度（0-100） | 意图 | 层级 | 优先级 |
|---------|---------------|-------------------|--------|------|----------|
| ... | ... | ... | 信息性 / 交易性 / 导航性 / 商业性 | 1/2/3 | 高 / 中 / 低 |

## 意图分类

按搜索意图和子类别对每个关键词进行分类：

### 信息性（用户想学习）

| 子类别 | 信号词 | 示例 | 内容类型 |
|-------------|-------------|---------|-------------|
| 教育性 | what, why, definition, explain | "what is SEO" | 指南，解释 |
| 指导性 | how to, steps, tutorial, guide | "how to set up GA4" | 步骤教程 |
| 探索性 | types of, techniques, strategies | "link building techniques" | 全面总结 |
| 故障排除 | not working, fix, error, why is | "why is my site not ranking" | 诊断指南 |

### 商业调查（用户正在评估）

| 子类别 | 信号词 | 示例 | 内容类型 |
|-------------|-------------|---------|-------------|
| 比较 | vs, compared to, or | "Ahrefs vs SEMrush" | 对比 |
| 寻求评论 | review, worth it, honest | "Ahrefs review" | 深入评论 |
| 最佳 | best, top, tools for | "best SEO tools" | 精选列表 |
| 评估 | for [audience], features, pricing | "SEO tools for small business" | 买家指南 |

### 交易性（用户准备行动）

| 子类别 | 信号词 | 示例 | 内容类型 |
|-------------|-------------|---------|-------------|
| 购买 | buy, price, discount, deal | "buy Ahrefs subscription" | 产品/价格页面 |
| 注册/试用 | free trial, sign up, demo | "Ahrefs free trial" | 着陆页 |
| 下载 | download, template, PDF, checklist | "SEO checklist PDF" | 受限资源 |
| 聘用/参与 | hire, agency, near me, book | "SEO agency near me" | 服务页面 |

### 导航性（寻找特定品牌）

| 子类别 | 信号词 | 示例 | 内容类型 |
|-------------|-------------|---------|-------------|
| 品牌搜索 | [brand name] | "HubSpot" | 主页/品牌页面 |
| 功能搜索 | [brand] + [feature] | "Ahrefs keyword explorer" | 功能页面 |
| 支持/文档 | [brand] + login, docs, help | "Ahrefs API docs" | 支持内容 |

### 搜索引擎结果页面功能与意图的相关性

使用此方法预测每个关键词可以针对的搜索引擎结果页面功能：

| 搜索引擎结果页面功能 | 信息性 | 商业性 | 交易性 | 导航性 |
|-------------|--------------|-----------|--------------|-------------|
| 特性摘要 | 非常高 | 高 | 低 | 低 |
| 人们也问 | 非常高 | 非常高 | 低 | 中等 |
| AI 概述 | 非常高 | 高 | 低-中 | 低 |
| 购物结果 | 非常低 | 中等 | 非常高 | 低 |
| 本地包 | 低 | 低 | 高 | 低 |
| 网站链接 | 低 | 低 | 中等 | 非常高 |

### 意图转化潜力

| 意图 | 平均转化率 | 培养长度 |
|--------|-------------------|---------------|
| 信息性 | 0.5-2% | 长（几周到几个月） |
| 商业调查 | 2-5% | 中等（几天到几周） |
| 交易性 | 5-15% | 短（立即到几天） |
| 导航性 | N/A — 品牌依赖 | N/A |

### 常见分类错误

| 错误 | 正确分类 |
|---------|----------------------|
| 将 "best CRM software" 作为信息性处理 | 商业调查 |
| 将 "how much does X cost" 作为信息性处理 | 商业 / 交易性 |
| 忽略 "SEO services" 中的本地意图 | 交易性（本地） |
| 假设 "SEO tools" 具有单一意图 | 混合——检查搜索引擎结果页面以确认 |

具有不同意图的两个关键词永远不应该针对同一页面。

## 机会评分

对每个关键词进行评分：

```
机会评分 = (流量 x (1 - 难度/100)) x 意图乘数
```

意图乘数：
- 交易性：1.5
- 商业调查：1.3
- 信息性：1.0
- 导航性：0.2

这会浮现出低竞争、高意图的目标，而不是虚荣流量游戏。

## 集群播种

将关键词宇宙分组为主题集群：

| 集群名称 | 支柱关键词 | 支持关键词（3-5） | 总流量 |
|---|---|---|---|
| ... | ... | ... | ... |

每个集群需要一个支柱页面（头词）和 3-8 个支持页面（主体 + 长尾）。
