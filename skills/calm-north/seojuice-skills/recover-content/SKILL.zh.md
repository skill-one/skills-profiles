# 恢复内容

使用衰减分诊框架诊断和逆转现有页面的流量损失：刷新、整合、重定向或淘汰。

## 开始前

收集此背景信息（如未提供，请询问）：

1. **哪些页面正在失去流量？** 具体URL或一般性“整个博客都在下降”。
2. **失去了多少流量？** 百分比下降或绝对数字。
3. **在多长时间内？** 慢慢下降几个月与突然下降。
4. **有任何最近的更改吗？** 网站改版、CMS迁移、内容编辑、算法更新时间。

如果用户不知道哪些页面正在下降，建议检查 Google 搜索控制台 → 性能 → 页面，按过去6个月的点击变化排序。

## 识别衰减

内容衰减是指页面随着时间的推移逐渐失去搜索流量。常见信号：

- 连续3个月每月点击量下降
- 位置从第1页滑落到第2页以上
- 展示量稳定但CTR下降（竞争对手的标题/片段更好）
- 展示量下降（Google不再认为该页面相关）

### 综合衰减评分

对每个页面在5个加权信号上评分以确定行动优先级：

| 信号 | 权重 | 评分方法（0-100） |
|------|------|---------------------|
| 流量下降 | 30% | 0 = 无下降，50 = 20-40% 下降，100 = >60% 下降 |
| 位置下降 | 25% | 0 = 稳定，50 = 失去3-5个位置，100 = 从第1页掉落 |
| CTR下降 | 15% | 0 = 稳定，50 = 20% 下降，100 = >40% 下降 |
| 内容新鲜度 | 15% | 0 = 本季度更新，50 = 6-12个月陈旧，100 = >2年陈旧 |
| 竞争性取代 | 15% | 0 = 没有新的竞争对手，50 = 新进入者在第1页，100 = 从前3名被取代 |

```
综合衰减评分 = (流量 x 0.30) + (位置 x 0.25) + (CTR x 0.15)
              + (新鲜度 x 0.15) + (取代 x 0.15)
```

| 评分 | 阶段 | 响应 |
|------|------|------|
| 0-20 | 健康 | 继续监控 |
| 21-40 | 早期衰减 | 添加到刷新队列（下个月） |
| 41-60 | 活跃衰减 | 本周安排刷新 |
| 61-80 | 显著衰减 | 立即刷新或重写决定 |
| 81-100 | 终端衰减 | 重写、重定向或淘汰 |

### 警报优先级矩阵

当多个信号同时触发时，升级：

| 信号组合 | 优先级 | 响应时间 |
|----------|--------|----------|
| 流量下降 + 位置下降 | P1 关键 | 48小时内刷新 |
| 流量下降 + CTR下降 | P1 关键 | 立即重写标题/元数据 |
| 位置下降 + 竞争性取代 | P2 高 | 1周内刷新 |
| 仅CTR下降 | P3 中 | 本周重写标题和元数据 |
| 仅新鲜度指标 | P3 中 | 2周内安排刷新 |

## 衰减分诊框架

对每个衰减页面应用此决策树：

### 决策1：主题是否仍然相关？

- **是** → 进入决策2
- **否**（产品停止、事件过去、技术过时）→ **淘汰**。301重定向到最相关的页面或父类别。

### 决策2：网站上是否有其他页面针对相同主题？

- **是** → **整合**。将两个页面中最好的内容合并到一个页面。301重定向较弱的页面。
- **否** → 进入决策3

### 决策3：搜索意图是否已改变？

检查当前针对目标关键词的排名。SERP是否从：
- 列表 → 长篇指南？
- 博客文章 → 产品页面？
- 文本 → 视频？
- 一般性 → 具体性？

- **是，意图改变** → **重写**。重建页面以匹配当前意图。保留URL。
- **否** → 进入决策4

### 决策4：内容是否只是过时？

检查：陈旧统计数据、过时的截图、已弃用的工具/方法、标题中的旧日期、损坏的外部链接。

- **是，过时** → **刷新**。更新事实、截图、示例和日期。添加涵盖近期发展的新部分。
- **否** → **深入调查**。问题可能是技术性的（失去反向链接、页面速度慢、移动问题）或竞争性的（更强的页面现在排名更高）。

## 不同内容类型的刷新手册

不同内容类型需要不同的刷新方法。使用匹配的手册：

### 博客文章/文章（3-4小时）

1. 用当前年份或新鲜钩子更新标题（10分钟）
2. 用新角度重写引言（20分钟）
3. 用当前来源更新所有统计数据（30-60分钟）
4. 添加1-2个新部分，涵盖竞争对手解决的空白（60-90分钟）
5. 更新截图和图像（30分钟）
6. 添加或刷新FAQ部分，包含当前的PAA问题（20分钟）
7. 刷新指向最近相关内容的外部链接（15分钟）
8. 更新元描述（5分钟）
9. 添加或更新结构化标记——至少dateModified（10分钟）
10. 更新日期后重新发布并重新提交到搜索控制台（5分钟）

### 统计数据/数据汇总（4-5小时）

1. 验证每个统计数据——移除没有当前来源的
2. 用当前数据替换过时的统计数据（2年内）
3. 添加来自近期研究的新统计数据
4. 更新所有来源链接——替换损坏的引用
5. 在标题和正文中更新年份参考
6. 如不存在，添加数据可视化
7. 更新元描述和标题

### 如何指南（3-3.5小时）

1. 验证所有步骤是否仍按原文工作
2. 更新任何更改界面的截图
3. 如有任何新方法出现，添加替代方法
4. 更新工具推荐（移除已弃用，添加当前）
5. 添加常见故障点的故障排除部分
6. 用近期问题更新FAQ
7. 测试所有外部链接

### 刷新检查清单（通用）

对于任何内容类型，始终完成：

- [ ] 将所有统计数据和数据点更新为当前年份
- [ ] 替换过时的示例和截图
- [ ] 添加新部分，涵盖自上次更新以来的发展
- [ ] 移除或更新损坏的外部链接
- [ ] 改进标题和元描述（检查竞争对手的标题以获取CTR想法）
- [ ] 从最近的、相关内容中添加内部链接
- [ ] 扩展竞争对手更好地覆盖的薄弱部分
- [ ] 添加原创见解、数据或专家引言（E-E-A-T信号）
- [ ] 更新发布/修改日期
- [ ] 重新提交到Google搜索控制台以重新索引

## 整合检查清单

合并两个页面时：

- [ ] 确定更强的URL（更多反向链接、更好的位置、更老）
- [ ] 将较弱页面中的最佳内容移动到较强页面
- [ ] 设置从较弱URL到较强URL的301重定向
- [ ] 更新所有指向较弱URL的内部链接
- [ ] 检查较弱URL的反向链接——重定向将传递权威

## 优先级

为每个页面刷新优先级评分：

| 因素 | 权重 |
|------|------|
| 当前流量价值 | 25% |
| 衰减严重性（综合评分） | 20% |
| 竞争性机会 | 20% |
| 刷新难度（反向——越容易越高） | 15% |
| 战略重要性（转化、品牌） | 10% |
| 风险中的反向链接权益 | 10% |

然后对页面进行排名：

| 页面 | 衰减评分 | 流量损失 | 优先级评分 | 行动 | 努力 |
|------|----------|----------|------------|------|------|
| ... | 72（显著） | 1,200/月 | 85 | 刷新 | 3-4小时 |
| ... | 45（活跃） | 300/月 | 60 | 整合 | 2小时 |

专注于（a）流量最多的页面，（b）推动转化，以及（c）最容易修复的页面。对高流量页面进行快速刷新比在低流量页面上进行完整重写要好。

### 内容淘汰选项

当页面无法挽救时，选择正确的退出：

| 选项 | 使用时机 |
|------|----------|
| 301重定向 | 内容有反向链接或残余流量——将权益发送到最相关的页面 |
| 整合 | 同一主题的多个薄弱页面——将最佳内容合并到一个URL |
| 无索引 | 内部实用页面，不应排名，但应服务于用户 |
| 删除（410） | 没有价值、没有链接、没有流量——清洁移除 |

## 输出格式

### 内容恢复计划：[域名]

**衰减摘要**
- 分析页面数：[数量]
- 需要采取行动的页面数：[数量]
- 预计可恢复的流量：[损失流量的总和]

**分诊结果**

| 页面 | 流量损失 | 诊断 | 行动 | 努力 |
|------|----------|------|------|------|
| ... | ... | 意图改变 / 过时 / 互相竞争 / 不相关 | 刷新 / 整合 / 重定向 / 淘汰 | 低 / 中 / 高 |

**优先行动**

对于每个高优先级页面：
- 具体需要改变的内容
- 要更新、扩展或删除的部分
- 恢复后的预计影响
