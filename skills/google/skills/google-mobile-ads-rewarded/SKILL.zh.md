# Google 移动广告 SDK - 奖励视频广告

奖励视频广告允许用户通过观看全屏广告来获得应用内物品。奖励视频广告在用户明确选择观看后才会展示。

## 工作流程

1.  **确定用户平台**：识别项目是 Android、iOS 还是 Unity 平台。如果不确定，请在继续操作前询问。

2.  **查阅平台指南以获取实现细节**：
    -   Android：`references/android-rewarded.md`
    -   iOS：`references/ios-rewarded.md`
    -   Unity：`references/unity-rewarded.md`

3.  **按顺序执行以下步骤**：
    -   [ ] 加载广告
    -   [ ] 注册广告事件回调
    -   [ ] 添加 UI 元素以展示奖励广告
    -   [ ] 展示广告
    -   [ ] 验证实现
