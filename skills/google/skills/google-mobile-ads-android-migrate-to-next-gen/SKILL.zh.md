# Google移动广告SDK的AI迁移代理说明

## 迁移工作流

使用此清单来跟踪您的迁移进度：

*   **配置Gradle**：
    -   [ ] 将 `com.google.android.gms:play-services-ads` 替换为最新的稳定版本的 `com.google.android.libraries.ads.mobile.sdk:ads-mobile-sdk`。如果您无法直接访问Maven，请运行以下命令来获取最新版本。`latest` 标签中返回的版本是GMA Next-Gen SDK的最新版本：

        ```bash
        curl -sS https://dl.google.com/dl/android/maven2/com/google/android/libraries/ads/mobile/sdk/ads-mobile-sdk/maven-metadata.xml | sed -n 's/.*<latest>\(.*\)<\/latest>.*/\1/p'
        ```

    -   [ ] 更新 `minSdk` (24+) 和 `compileSdk` (34+)。
    -   [ ] 在应用级别的构建文件中全局排除 `play-services-ads` 和 `play-services-ads-lite`，以避免重复符号错误。
    -   [ ] 在进入下一步之前同步Gradle。
*   **逐文件迁移**：
    -   [ ] 按照API映射表和方法映射表重构代码库，将导入、类名和方法签名迁移到GMA Next-Gen SDK。
*   **验证和构建**：
    -   [ ] 运行 `gradle build -x test` 以确认成功的清理构建。解决任何与GMA SDK相关的编译错误。

## 核心迁移规则

*   **App ID使用**：**始终**使用 `AndroidManifest.xml` 中的 `com.google.android.gms.ads.APPLICATION_ID` 元数据标签的值作为 `InitializationConfig` 中的 `applicationId`。
    *   *约束*：在清单中保留 `<meta-data>` 标签；它仍然需要用于使用用户消息平台SDK的发布商。
*   **初始化顺序**：
    1.  在后台线程上调用 `MobileAds.initialize()`。
    2.  确保 `initialize()` 在任何其他SDK方法**之前**被调用。
    3.  如果使用 `RequestConfiguration`，将其捆绑到 `InitializationConfig.Builder.setRequestConfiguration()` 中。**不要**在初始化之前调用 `MobileAds.setRequestConfiguration()`。
*   **UI线程**：**强制要求**：GMA-Next Gen SDK中的回调在后台线程上被调用。**所有与UI相关的操作**（例如，Toast、视图更新、Fragment事务）**必须**在GMA SDK回调中用 `runOnUiThread {}` 或 `Dispatchers.Main.launch {}` 包装。跳过此步骤将导致应用程序崩溃。
*   **中介**：实现 `com.google.android.gms.ads.mediation.Adapter` 的类**必须**继续使用 `com.google.android.gms.ads`。

## 格式特定说明

### 横幅广告

*   使用 `com.google.android.libraries.ads.mobile.sdk.banner.AdView` 来加载GMA Next-Gen SDK横幅广告。
*   以下API检查横幅是否可折叠：
    `adView.getBannerAd().isCollapsible()`。

### 原生广告

*   **NativeAdLoader**：`NativeAdLoader` 是抽象的，不能被实例化。它被静态使用（例如，`NativeAdLoader.load(...)`）。
*   以下API现在设置在 `NativeAdRequest.Builder` 上：
    *   `.setCustomFormatIds(customFormatIds: List<String>)`
    *   `.disableImageDownloading()`
    *   `.setMediaAspectRatio(mediaAspectRatio: NativeMediaAspectRatio)`
    *   `.setAdChoicesPlacement(adChoicesPlacement: AdChoicesPlacement)`
    *   `.setVideoOptions(videoOptions: VideoOptions)`
*   **移除**：删除所有“关闭此广告”逻辑；它在GMA Next-Gen SDK中不受支持。
*   **MediaView**：`NativeAd` 不再具有直接的 `mediaView` 变量；使用 `registerNativeAd(nativeAd, mediaView)` 将广告与视图关联起来。

### 广告预加载

*   除非映射表中另有说明，GMA Next-Gen SDK中的广告预加载方法与旧SDK具有相同的API签名和参数。
