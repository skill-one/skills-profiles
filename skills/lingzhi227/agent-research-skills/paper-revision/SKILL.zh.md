# 论文修改

根据审稿人反馈系统性地修改论文。

## 输入

- `$0` — 审稿人评论/反馈
- `$1` — 当前论文草稿（main.tex 或论文目录）

## 参考文献

- 修改工作流和提示：`~/.claude/skills/paper-revision/references/revision-prompts.md`

## 工作流

### 第 1 步：解析和优先级排序问题
针对每条审稿人评论：
1. 提取具体问题
2. 分类：重大修改、次要修改、疑问、建议
3. 映射到受影响的论文部分
4. 优先级排序：优先处理重大问题

### 第 2 步：规划修改
创建修改计划：
```
问题 → 受影响部分 → 所需操作 → 新内容/实验
```

操作类别：
- **澄清**：重写文字以增强清晰度
- **补充实验**：运行新实验，添加结果
- **新分析**：添加消融实验、统计测试或对比分析
- **结构调整**：移动、合并或拆分部分
- **引用**：添加缺失的参考文献

### 第 3 步：执行修改
针对每个计划的修改：
1. 阅读当前部分
2. 应用针对性编辑（保留周围结构）
3. 如需新实验：使用 experiment-code 技能
4. 如需新图表/表格：使用 figure-generation / table-generation 技能
5. 标记修改（使用 `\textcolor{blue}{...}` 标记修改后的文字）

### 第 4 步：验证改进效果
- 重新运行自我审查技能以检查分数是否提升
- 确认所有审稿人问题均已解决
- 检查修改是否引入新问题
- 确保页数仍符合会议要求

### 第 5 步：撰写修改摘要
生成差异摘要：
- 列出所有修改及对应部分引用
- 注明添加的新实验、图表或表格
- 将每项修改与所解决的问题进行交叉引用

## 规则

- 必须解决所有审稿人问题 — 不得遗漏
- 除非需要结构调整，否则保留论文结构
- 新结果必须来自实际实验，而非凭空想象
- 清晰标记所有修改内容以供审稿人参考
- 修改前保留上一版本副本
- 修改后比较新分数与旧分数
