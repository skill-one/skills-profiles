# UGC脚本

将产品简介和目标受众转化为创作者可以拍摄的UGC风格短剧广告脚本：包括钩子、正文、行动号召、每个概念的3-5个钩子变体以及拍摄所需的交付说明。

策略师撰写脚本；创作者执行；编辑整合——"你不是在为创作者支付创意策略师的费用"（萨凡纳·桑切斯，《社交萨凡纳》）。角色保持分离；将它们结合是导致平庸输出的最常见原因。

## 范围

不在范围内——应转交给其他地方处理：

- 视频制作、选角、创作者来源、编辑、后期制作。坚决不做。
- 对现有钩子/文稿进行评分或排名 → `mbfinotti/advertising-skills@ad-hook-analyzer`。
- 静态广告文案A/B变体（信息流和搜索广告的标题/正文/行动号召文本）→ `mbfinotti/advertising-skills@ad-copy-variants`。
- 完整活动创意简报（信息支柱、视觉指南、品牌禁止事项）→ `mbfinotti/advertising-skills@ad-creative-brief`。此技能仅撰写脚本本身以及拍摄所需的交付说明。
- 判断广告何时过时 → `mbfinotti/advertising-skills@ad-creative-fatigue`。
- 设计变体的测试矩阵和样本量 → `mbfinotti/advertising-skills@ad-creative-test-plan`。

## 面谈

每条消息问一个问题。尽可能提供多选项。跳过用户简介中已经回答的内容。

1. 产品——它是什么，它实际上做什么？
2. 优惠——免费试用、折扣码、演示、候补名单、直接购买？
3. 目标受众——谁，以及意识阶段：无意识 / 问题意识 / 解决方案意识 / 产品意识？
4. B2B还是B2C？
5. 平台和位置——短剧垂直信息流、故事、专业网络信息流、视频前贴片？
6. 目标时长——默认15-25秒，付费社交中最常引用的时段。
7. 执行者——真实客户、付费创作者、创始人、员工，或尚未选角的构思测试？
8. 现有证据——评论、过去广告的评论、支持工单、销售通话笔记、观察到的成功广告？
9. 受监管类别（健康、金融、补充剂）？该广告在哪些市场运行？
10. 数量——多少个概念，每个概念多少个钩子变体？默认：2-3个概念 × 3-5个钩子 × 2个行动号召。
11. 截止日期——广告必须在何时上线？
12. 单次胜利还是复合资产——单个广告填充当前位置，还是脚本库和可重复使用的格式以供构建？
13. 努力上限——可用小时数、谁可以出镜，以及已经存在的内容：产品片段、屏幕录制、已获公众使用的客户成果记录？

以下每个选项菜单都按这些最后三个问题的答案进行默认排序。根据它们重新排序，并说明哪个答案移动了什么：

- 复合指令推广资产门控钩子原型和客户证言，因为资产比使用它的广告更持久。
- 本周拍摄将它们推迟到下一轮——说"推迟"，并保留它们在菜单中。
- 无法解除的约束（无片段、无已批准结果、类别禁令）删除选项——删除的选项会以删除命名，而不是停靠在排名底部。

## 工作流程

1. 运行面谈。
2. 通过评论挖掘构建证据库——主要输入，由Copyhackers（乔安娜·韦伯）作为命名方法教授：从客户自己的渠道中提取客户自己的语言，然后镜像回来。按效率顺序处理来源——每单位挖掘的返回引语：
   - 公开评论 == 过去广告评论：真正的联系，不是耸肩——两者都是公开的，已经是客户的话，并且都可以直接从屏幕上读取，无需许可。选择产品实际拥有的。
   - 支持工单：需要内部访问，并且客户的话在到达脚本之前需要他们的同意。
   - 销售通话笔记：需要某人花费时间挖掘，并用其他东西无法提供的反对语言回报。
   - 根据用户已持有的内容重新排序：标记的工单导出或通话录音库降至接近零，并超过公开评论——对于大多数B2B产品，公开评论太薄弱，无法承载概念。
   - 将每个引语记录为四列：
     - 精确引语。
     - 来源。
     - 背后的愿望或问题。
     - 情感标签。
   - 如果可以浏览网页，请拉取产品的最新公开评论；否则请要求用户粘贴证据。
   - 永远不要编造钩子、痛点、声明或证言行话。编造的评论和证言是监管违规行为，而不仅仅是薄弱的写作。
   - 没有任何证据？说出来，仅从简介中撰写，并标记每个脚本为`UNVALIDATED - voice-of-customer not sourced`。
3. 定义每个概念：一个受众细分 × 一个动机（客户自己的话） × 一个格式。固定优惠。概念、钩子和优惠是三个分别可测试的变量（拉尔夫·伯恩斯，《永久流量》）——保持两个不变，改变一个。
4. 根据以下结构起草正文，适配目标时长。保持跨钩子变体固定。
5. 每个概念撰写3-5个钩子变体，加上2个行动号召变体。一次拍摄可产生6个以上编辑组合针对单个正文——这是在不重新拍摄的情况下隔离创意变量的标准方法。
   - 每个钩子是一个三元组：口语行 + 屏幕文本 + 开头视觉，每个都承载不同的信息。
   - 从[参考资料/hook-archetypes.md](./references/hook-archetypes.md)中选择不同的原型，该文件按每单位生产努力获得的说服力对它们进行排序。默认：对话原型领先（怀疑者的回合、问题指称、POV），以及当资产已存在时，资产门控原型（先证明、无声评论、前后对比）获得一个位置。几乎相同的开场白重新测试已知内容。
   - 说明什么比例被剥夺。前后对比和先证明在列表中携带最强的证据，但拍摄成本最高，因此效率阅读会无限期推迟它们，并且屏幕永远不会向观众展示可检查的内容。当其资产已存在且已清除时，当面谈答案是复合指令时，或一旦第一轮钩子落入自身噪音范围内，就推广一个。
   - 被约束排除的原型从该概念菜单中**删除**并在脚本包中命名为**删除**：
     - 受监管类别禁止前后对比。
     - 缺少产品片段会导致无声评论。
     - 未清除的结果会导致先证明和大胆声明。
   - 永远不要将已删除的原型排名靠后；被排除的原型在列表底部获得简要介绍，下一轮将简要介绍证言。
6. 检查每个钩子到正文的过渡：正文的第一行必须扩展钩子的前提。根据需要重写过渡行——永远不要让正文偏离钩子承诺的内容。
7. 锁定钩子和行动号召逐字；中间作为带示例短语的要点。这是从业者平衡真实性与控制的实践——见脚本深度部分。
8. 每个脚本添加交付说明：
   - 节拍时间。
   - 每个节拍屏幕上显示的内容。
   - 语气和朗读方向。
   - 要举到摄像机前的物品。
   - 该做/不该做的事——这些比单纯的积极指令携带更多信息。
9. 运行合规检查，使用[参考资料/compliance-checklist.md](./references/compliance-checklist.md)。披露行是脚本行——用广告运行在的每个市场的语言撰写它们。
10. 运行你首选的人性化技能到每行口语和屏幕文本。强制性：读取机器撰写的UGC会破坏整个格式依赖的真实性。永远不要将原始初稿作为最终稿发送。
11. 按照以下结构（见下文）和测量计划组装脚本包。如果你的框架具有持久内存，请存储证据来源、选择的概念和获胜钩子以供下次迭代；否则将它们放入包中，以便用户可以重新提供。

## 脚本深度

两极都失败，并且每个都有其自身的失败特征：

- 太模糊（"只是谈谈你为什么喜欢它"）→ 创作者发明策略，而片段错过了角度。
- 太脚本化（每个字都锁定）→ 交付变得僵硬，创作者自己的受众感觉到广告并跳过。

锁定两个携带测试的节拍——钩子和行动号召——并将中间简要介绍为带示例短语的节拍。将实际客户评论引语作为谈话要点交给创作者，这样行话听起来真实，因为它们是真实的。

## 脚本结构

- 默认骨架：钩子 → 问题 → 解决方案 → 2-3个价值主张 → 社会证明 → 行动号召。目标为付费社交的15-25秒。
  - 低于10秒：倾向于沟通不足。
  - 超过45秒：完成率急剧下降。
- 常见节拍分割：钩子0-3秒，价值主张3-15秒，证明或演示15-25秒，行动号召在最后的5秒内。
- 用"四个U"测试钩子行：独特、紧迫、超具体、有用。
- 前置钩子，但不要将"3秒"视为行为定律：它是从平台在3秒观看时间内计算"观看"的反向工程。独立眼动追踪（Lumen Research，通过WARC）在10%品牌意识提升背后有1.4秒的注意力，在提示回忆背后有3.9秒——真正的窗口可能比传说短。
  - 永远不要引用"8秒注意力跨度"：它追溯到2015年的报告，没有可信来源，已被驳斥。
- 在前几秒后，保留率急剧下降。剪掉行而不是将它们合并成一个更长的视频。

用一般直接响应框架构建正文，按效率顺序在15-25秒：PAS（问题-煽动-解决）> BAB（前后对比）> AIDA。这三个都花费相同的写作成本，因此排序是适配而不是努力：

- PAS：仅对话。
- BAB：需要一个可拍摄的先前状态，并加上一条典型的清除行。
- AIDA：四个阶段很少在25秒内落地。

默认为PAS。当先前状态已经在摄像机上时，移动到BAB。仅在较长的B2B格式中移动到AIDA。

这些是经典的文案框架，不是UGC原生的发明——没有一个包括付费社交期望的社会证明节拍，所以添加它。

## 平台说明

可选；当用户未指定平台时跳过。这些是放置事实，不是供应商说明。

- 短剧信息流在不同的阈值计算"观看"（某些是2秒，其他是3秒），因此钩子速率在不同平台间不可比。仅将脚本与同一放置上的其他脚本进行比较。
- 保持屏幕文本在每秒屏幕时间的5-10个字左右。
- 假设静音。特别是在专业网络信息流中，大多数视频是无声观看的——字幕和屏幕文本必须单独传递信息。

## B2B改编

从B2C无缝转移：

- 快速前置钩子。
- 本地未打磨的感觉。
- 单个行动号召。
- 基于真实客户语言。
- 屏幕文本在静音时传递信息。
- 钩子/正文/行动号召骨架本身。

无法转移：

- 拖动和冲动购买框架。
- 折扣紧迫行动号召。
- 单一决策者假设。
- 纯粹美观的UGC。

B2B购买通过一个由6-10人组成的委员会在较长时间窗口内进行，因此一个脚本很少单独转换——按意识阶段规划脚本。

以教学而不是推销开头："人们来领英是为了学习，而不是观看广告"（AJ Wilcox，《B2Linked》）。面对摄像机的人性专家在专业网络上优于精加工的企业视频。

使用挑战→解决方案→结果作为B2B骨架，并以量化结果和命名角色结束结果。证言长度格式比B2C长——大约45-90秒——并且超过两分钟完成率急剧下降。

B2B创作者证言的三个B2C替代方案，按效率顺序。成本与价值相反，因此在此阅读每个轴后再选角：

- 效率：创始人主导 > 员工生成 > 客户/从业者证言
- 成本：客户证言 > 员工生成 > 创始人主导
- 价值：客户证言 > 员工生成 > 创始人主导
- 合规成本：客户证言（他们的姓名批准，加上一般预期结果行） > 员工生成（在脚本中披露就业） > 创始人主导（自我明显，仍然标记）

1. **创始人主导**——为什么我们创建这个，被破坏的现状，发生了什么。一个人的小时和日历；这是本周唯一能发货的。三者中证明最弱：观众会折扣一个供应商讲述自己的故事。
2. **员工生成**——"我们在这里实际如何做X"，从业者声音，真实的流程或屏幕在摄像机上。需要内部批准和某人愿意被拍摄。购买从业者可信度，创始人无法声称。
3. **客户/从业者证言**——真实用户，命名角色，量化结果，当结果不同时加上一般预期结果行。需要外部调度和他们的批准，并且它需要一个已记录的结果才能存在。购买列表中唯一的第三方证明。

**这个比例剥夺了客户证言。**

- 价值最高，成本最高：唯一携带第三方证明的级别，也是唯一其资产需要公司外部人员同意的级别。
- 比例总是选择创始人主导，因此账户将无限期发送供应商讲述自己故事的视频，并且从未将客户放在摄像机前。
- 在命名客户已同意出现并带有量化结果时推广它，当面谈答案是复合指令时（已清除的证言可在每个后续脚本中重复使用），或一旦创始人主导视频停止移动数字——那是观众折扣来源，重写无法修复。

当内部有人做产品替换的工作并展示真实屏幕时，升级到员工生成。否则默认为创始人主导。

这个顺序是默认值，不是法律。根据账户和面谈的截止日期、持久性和努力上限答案重新排序它：有现有受众的创始人胜过冷客户证言，并且已清除用于公开使用的案例研究使客户证言成为这里最便宜而不是最贵的级别。当没有记录的客户成果存在且无法获得时，**从该账户菜单中删除客户证言并说明**——不要将其排名靠后，下一轮简要介绍一个无人能提供的证言。

## 输出形状

按每个概念交付一个脚本包，使用两列音频/视频约定：每行一个节拍，视觉效果在一列，音频在另一列，加上时间列。估计旁白时间为口语字数 ÷ 150字/分钟。

- **概念**：细分，动机（逐字证据引语 + 来源），格式，优惠。
- **钩子变体（3-5）**：口语行/屏幕文本/开头视觉的表格，带有原型标签。逐字锁定。
- **正文**：节拍按节拍——时间，口语节拍，屏幕文本，视觉。要点节拍带示例短语，不是锁定行。
- **行动号召变体（2）**：请求，带有口语和屏幕措辞。逐字锁定。
- **交付说明**：朗读方向，语气，场景，道具，节奏和该做/不该做的事。
- **合规**：披露行，覆盖的市场，以及声明笔记。
- **验证状态**：基于（有来源）或`UNVALIDATED`。
- **测量计划**：此包测试哪个单一变量，加上基线以下。

见[参考资料/script-examples.md](./references/script-examples.md)了解一个B2C包的工作示例、一个B2B包的工作示例和一个带注释的负面示例，说明哪里出了问题。

## 调用示例

- 为我们的餐计划应用撰写3个UGC广告概念，面向忙碌的父母，20秒竖屏视频，每个概念包含5个钩子。
- 将这些客户评论转化为创始人主导的专业网络视频脚本，时长30秒。
- 已预订周五的创作者 - 为折扣优惠撰写证言式广告脚本，并附上配送备注。

## 失败模式

- 指导模糊（“只需保持真实”）→ 创作者自行发明策略。修复：锁定钩子和行动号召，简要说明中间部分为节奏点。
- 每个词都锁定 → 生硬的交付方式，读起来像广告。修复：采用相同规则，从另一面入手。
- 钩子未兑现 → 持有率崩溃。修复：过渡句扩展钩子前提（第6步）。
- 通用钩子 → 测试中无任何可学习之处。测试：如果竞争对手能用逐字相同的开场白，则重写它。
- 静态或标志卡片作为第一帧 → 最常被引用的低钩子率原因。修复：以动态画面、人物或钱景开场。
- 问题段落列出功能而非命名疼痛出现的时刻。修复：使用证据文档中的情感标签。
- 品牌声音在人物口中（“革命性配方”）→ 读起来像广告并失效。修复：仅使用证据中出现的词语。
- 堆叠的行动号召 → 每个请求稀释其他请求。修复：每个脚本仅包含一个请求。
- 虚构的客户声音 → 监管风险。修复：标记为 `UNVALIDATED`。
- 同时改变所有内容 → 无任何学习成果。修复：在测试钩子时固定概念和优惠。
- 拍摄前未签署使用权 → 无法使用的素材。在交付备注中标记；文件工作超出范围。

## 衡量标准

以账户自身的基线而非已发布的数字为目标。首先获取可比位置的滞后中位数钩子率和持有率；新脚本通过时需击败该中位数并清除以下诊断标准。逐个变量迭代，直到达标。

已发布的基准数据差异太大，无法作为目标：供应商“良好”的钩子率在同一平台上对同一指标的范围大致在18%到40%之间，且每个供应商都销售能证明该数字的指标分析。将任何外部数字视为合理性检查，而非目标。

按顺序诊断并仅修复失败阶段：

- 低钩子率（3秒播放量 ÷ 展示量）→ 开头失败。重写钩子；不要触碰目标定位。
- 健康钩子率，低持有率（15秒播放量 ÷ 3秒播放量）→ 身体部分或钩子到身体的过渡失败。
- 健康持有率，低点击率 → 行动号召薄弱或模糊。
- 健康点击率，低转化率 → 优惠或着陆页，而非脚本。

钩子率衡量注意力，而非价值 - 两个钩子率相同的广告在回报上可能相差数倍，因为一个能留住观众至行动号召，而另一个则不能。切勿仅凭钩子率进行扩展。
