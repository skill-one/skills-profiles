# 创意简报

撰写一个效果营销创意简报：针对每个概念的测试规范，而不是附加了指标的品牌简报。经典的代理简报以单一主张为中心，每个活动撰写一次，并故意保持松散，以便激发灵感。效果简报用**可证伪的创意假设**取代了那个主张，每个概念每个冲刺都撰写一次，并对钩子、规范和决策阈值有明确的说明，因为每个周期都有数十个变体发布。

风险被记录在案。BetterBriefs 项目（IPA，1,700多名营销人员和代理人员，70多个国家）发现，受访者估计约33%的营销预算因简报不佳而浪费，而80%的营销人员认为他们写的简报很好，而只有10%的代理机构同意。代理机构将差距命名为重点（83%）、清晰度（79%）和灵感（65%）。

一个诚实检查框定了其他所有内容。Motion 对 12.9 亿美元的 Meta 花费（涉及 578,750 个创意）的分析发现，大约 5% 的创意成为赢家——这是任何简报都无法撤销的命中率。因此，简报的工作不是承诺赢家；而是最大化每次出击的质量、干净度和多样性。

这项技能止于批准的简报文件，并且永远不会产生最终创意。撰写最终广告文案属于 `mbfinotti/advertising-skills@ad-copy-variants`；逐帧创作者脚本——台词、拍摄列表——属于 `mbfinotti/advertising-skills@ugc-ad-scripts`。这个简报撰写钩子方向，而不是钩子脚本；这是界限。

其他地方也要移交：给现有视频开头的评分给 `mbfinotti/advertising-skills@ad-hook-analyzer`，决定一个正在运行的广告是否过时给 `mbfinotti/advertising-skills@ad-creative-fatigue`，测试的样本大小和结构给 `mbfinotti/advertising-skills@ad-creative-test-plan`，以及目标受众计划给 `mbfinotti/advertising-skills@ad-audience-targeting`。

## 面谈

在起草任何东西之前进行面谈。每个消息一个问题；在可能的情况下提供多个选择答案；跳过已经回答或可见在提供的材料中的任何内容。

- 活动目标，以及创意将根据哪个单一主要 KPI 进行评判？
- 平台和位置？
- B2B 还是 B2C/DTC？
- 目标受众的知晓程度：未知 / 问题知晓 / 解决方案知晓 / 产品知晓 / 最知晓？("所有受众"不是一个答案——这是最常见的简报缺陷；坚持每个简报一个水平。)
- 谁执行简报：内部设计师、视频编辑、自由职业 UGC 创作者或代理机构？（这决定了要多么具体，以及是否适用权利和披露字段。）
- 生产能力、截止日期和修订上限？截止日期是硬性的吗？（下方的格式和测试意图排序跨越数小时到一周的时间效应，因此在没有它的情况下无法排序。）
- 你想要现在可用的最快出击，还是学习效果会随着未来的简报累积——一个经过验证的画像、一个清除的证明资产、一个拥有的素材库？（前者倾向于静态和钩子测试，后者倾向于视频/UGC 和画像测试。）
- 努力上限：谁可以在不请求许可的情况下被拉入，以及你是否能获得创作者权利和声明批准？（“否”会删除步骤而不是延迟它们。）
- 品牌强制性要求和合规约束？（受监管类别？哪些声明在出现在付费广告之前需要提供证据？）
- 已经存在的证据是什么：客户评论、销售通话笔记、广告评论、过去的赢家及其指标、竞争对手广告？
- 预算和预期交付数量？
- 平台自动增强是开启还是关闭——以及是否有人真的知道？

## 在简报之前进行头脑风暴

永远不要从面谈到一个完成的简报跳转；简报会硬化假设，所以首先揭示它们。

1. 用一句话重述活动目标和受众洞察；在继续之前获得确认。
2. 挖掘证据（方法在 [references/angle-frameworks.md](references/angle-frameworks.md) 中）并筛选出候选的痛苦/欲望和画像。
3. 提出两个到三个候选概念方向——每个方向都有其信息角度、所依赖的证据、格式系列、权衡——以及一个推荐及其理由。一次一个地提出缩小范围的问题。
4. 一旦选定了方向（或混合），逐段起草简报并验证每一段再继续：背景 + 受众，然后信息 + 假设，然后钩子 + 艺术方向，然后测试部分。
5. 设立明确的批准关卡：没有批准的简报不是最终简报。将拒绝的方向记录在角度库中——它们是未来的测试，而不是浪费。

## 工作流程

1. 运行面谈。
2. 使用 [references/angle-frameworks.md](references/angle-frameworks.md) 中的挖掘方法收集证据：评分式评论挖掘、最频繁的 1-2 星反对意见、超越评论的客户声音（B2B：通话笔记、CRM 评论、搜索词）、按长期性筛选的竞争对手广告、过去的赢家及其指标。简报中的每个声明都引用一个来源；没有证据的简报是一个愿望清单。
3. 运行上述头脑风暴模式。
4. 修复翻译链（下文）：痛苦 → 画像 → 信息角度 → 知晓程度 → 钩子方向 → 格式。
5. 使用 [references/brief-template.md](references/brief-template.md) 为每个概念撰写**一个简报**，选择格式变体（静态 / 搜索 / 视频-UGC，按 Format Variants 下方排序）。获胜概念的变体继承原始简报；只有真正不同的概念才会获得新的简报。目标长度：1-2 页，包括参考文献。
6. 填写测试意图块并通过命名约定分配资产名称——永远不要将命名留给上传者。
7. 如果你能够浏览网页，请拉取每个目标位置的平台**当前发布的**宽高比和安全区；否则在规格字段中写入“导出前在位置预览”。已发布的宽高比数字相差几十像素，因此硬编码的数字是任何一方的缺陷。
8. 将草稿与失败模式表进行对照，然后将信息角度和钩子选项行通过你首选的人类化技能——它们必须读作对话式的人类声明，而不是营销文案。
9. 移交。运行修订循环：每轮修订收集一次反馈（分散的零散笔记会消耗修订上限），如果创意没有解决简报的前两个主要反对意见，则将创意退回。
10. 结果出来后，将结果写入简报的学习字段和角度库。如果你的 harness 具有持久内存，请记住角度库、按触发类型记住钩子性能和每个概念的结果，以便下一个简报从历史中开始。

## 翻译链

知识产权核心，也是大多数简报忽略的部分。Motion 的创意策略引擎是命名公开的方法论：**痛苦（或欲望）→ 画像 → 信息角度 → 知晓程度 → 钩子 → 格式。**

- 痛苦是默认的锚点；为没有功能问题的理想化或奢侈品类别保留欲望。
- 画像处于次要地位：不同生活环境中人们感到相同痛苦的不同生活情境。每个痛苦 × 画像单元都是一个信息角度的机会。
- 信息角度是一个对话式的人类声明，捕捉该交叉点的洞察力——明确不是标语或口号。
- 角度保持不变，只有其表达方式会改变。

链背后的命名框架——尤金·施瓦茨的五个知晓层次（《突破性广告》，1966 年；施瓦茨自己的词是 _层次_，而不是阶段）及其被忽视的兄弟，市场成熟度——加上痛苦 × 画像矩阵和知晓到钩子映射，都存在于 [references/angle-frameworks.md](references/angle-frameworks.md) 中。

## 固定词汇

"概念"、"角度"和"钩子"在整个行业中使用不一致——策略师、文案和媒体购买者各自有不同的含义，而在一个模糊的标签下进行测试会破坏学习。实用的解决方案是在独立的维度上添加标签，而不是争论一个词（Dara Denney 的分解使用五个：格式、创作者、信息、图像、画像）。这项技能修正了词汇，并且每个简报都在其自己的标题中重述这些定义：

- **概念**：一个独特的创意——一个简报，一个概念。
- **角度**：为什么这个人应该关心的论点，用人类句子表述。
- **钩子**：视频的前 1-3 秒或静态的第一阅读元素——角度的**表达**。
- **格式**：执行容器（证言、演示、创始人、我们与你们、静态、轮播……）。
- **迭代**：改变现有概念的一个元素的变体；不是新概念，不是新简报。

## 简报骨架

紧凑的形状；每个字段的指导和格式变体在 [references/brief-template.md](references/brief-template.md) 中；工作示例加上一个注释不佳简报在 [references/examples.md](references/examples.md) 中。

```
创意简报 - <概念名称>，<日期> - 定义标题（概念/角度/钩子/格式/迭代）
1 背景      目标 + 主要 KPI | 平台 + 位置 | 发起 + 生产日期 | 预算
2 受众      画像 + 生活情境 | 知晓程度（五个之一） | 在看到广告之前的信念 | 核心反对意见 | B2B：此简报针对的委员会角色
3 信息      信息角度（一个对话式句子） | 价值主张 | 一个证明点 | 证据引用（评论/通话笔记/赢家每个声明追溯到）
4 假设      "如果我们以 [痛苦] 和 [证明] 开头，那么 [受众] 将 [行动]" 类型（效率顺序）：钩子 | 证明 | 格式 | 角度 | 画像
5 钩子      3-5 个方向，每个方向由触发类型标记；视频：口语 / 视觉 / 文本覆盖
               每个选项；推荐第一个测试 + 理由
6 艺术      2-3 个参考广告，每个一条注释 | 做（最多 2 个） / 不要（最多 2 个） | 宽高比 + 安全区（"位置预览中预览"） | 声音设计 + 可访问性 | 每种类型的增强/关闭 | AI 披露行
7 交付物    算术（例如 2 个钩子 x 1 个主要编辑 = 3 个文件） | 迭代与净新标志 | 命名约定 | 修订上限 | UGC：使用权利（在哪里 / 多久 / 地区）
               + 创作者级别的披露
8 测试      变化的一个变量 + 保持不变的内容 | 任何呼叫前的最低花费或展示次数
               | 决策 KPI + 其基准 | 获胜时 / 失败时 | 学习写入的位置
```

## 钩子方向

视频钩子有三个层次；在简报和标签中分别标记它们（Motion 的惯例）：

- **口语** - 摄像机中的第一句话。
- **视觉** - 第一帧中发生的事情。
- **文本覆盖** - 屏幕上的文本。

对于静态：主要文本钩子、标题、标题钩子。提供 3-5 个选项，每个选项标记一个触发类型，加上推荐第一个测试和原因。

价值不是触发器的属性——知晓程度设定了它（映射在 [references/angle-frameworks.md](references/angle-frameworks.md) 中），因此一个被知晓程度排除的触发器无论多么便宜都没有价值。首先根据知晓程度进行关卡，然后按已在拍摄的身体或已设计的布局上花费的成本对幸存者进行排名。八个触发类型，按效率顺序：

1. **痛苦激动** - 一句口语，并且证据已经被挖掘。接近零。
2. **身份呼喊** - 一句口语加上一个覆盖。接近零。
3. **反叛 / 破除神话** - 写作接近零；花费政治资本，当声明与品牌或类别正统观念相矛盾时。
4. **紧迫性 / 风险** - 写作接近零；受报价机制限制，并且任何稀缺性或截止日期声明在运行之前必须为真。
5. **好奇心差距** - 写作接近零，加上解决字段：循环在哪里结束。
6. **社会证明 / 信誉** - 当评论墙或徽章已经存在时接近零；必须在一周内收集，加上证言证实和受监管类别中的批准。
7. **理想化 / 欲望** - 一个需要拍摄或制作的未来状态。
8. **模式中断** - 它自己的帧或设置：一个拍摄，而不是重写。

- 努力：模式中断 > 理想化 > 社会证明 > 好奇心差距 > 痛苦激动 == 身份呼喊 == 反叛 == 紧迫
- 合规成本：社会证明 > 紧迫 > 反叛 > 理想化 == 痛苦激动 == 身份呼喊 == 好奇心差距 == 模式中断

四向努力平局是真实的，不是耸肩：痛苦激动、身份呼喊、反叛和紧迫性每个都是针对已存在的镜头的一句口语，所以它们之间没有东西可以交换。反叛和紧迫性然后在合规性上分离，这就是为什么它们在下一行保持平局。五向合规平局也持有相同的原因：这五个中没有哪一个声明结果、命名人物或承诺截止日期，所以没有一个会触发该类别已经要求的审查。

**这个顺序剥夺了：社会证明，以及它后面的模式中断。** 社会证明是唯一携带第三方证据的触发器，但它排在第六位，因为收集墙或徽章需要一周和批准。模式中断在努力中排在最后，因为它需要一个自己的帧拍摄。

一个完全由比率撰写的简报将永远测试四个一行的触发器，并且永远不会将证据展示给读者。当资产已经存在并且已清除时，请推广它们——社会证明的成本会崩溃到接近零，而其价值保持不变——或者当面谈答案是累积指令时，这证明支付一次模式中断拍摄是合理的，并且可以在本季度内重复使用该镜头。

删除而不是降级：如果不存在清除的客户结果并且无法获得，**社会证明从这个简报的触发器菜单中删除，并命名为删除**；如果类别禁止反叛或紧迫性所依赖的声明，则删除它们。被排除的触发器在列表底部被简要介绍，但仍然由下一个人阅读。

默认第一个测试：知晓程度实际认可的最高排名幸存触发器。这是一个默认值，不是法律——它会随着类别和执行者而移动。根据面谈答案重新排名，并说明哪个答案移动了哪个触发器：一个硬截止日期将你限制在四个一行的内部。然后根据这个账户已经拥有的东西重新排名——一个内部编辑可以在下午内制作一个新的开篇帧，一个清除的库客户镜头，一个真正擅长镜头的创始人——每个都会将昂贵的触发器向上移动几个位置。

方向，而不是脚本："以问题开头，直接命名"是方向；确切的词属于执行者或 `mbfinotti/advertising-skills@ugc-ad-scripts`。从证据中获取钩子选项，而不是从空白页：从公共广告库中拉取竞争对手广告，并按**长期性而不是时效性**筛选——一个运行数月后的广告是经过验证的（Foreplay 的 Jack Kavanagh）——并使用 Ben Heath 的钩子工厂方法（几个视频主体 × 许多口语和视觉钩子变体在一个拍摄中捕获）来制作钩子选项以低成本生产。

- **参考示例胜过形容词**。“真实”和“高端”对不同的人意味着不同的东西；参考广告对每个人来说都意味着相同的东西。包含 2-3 个同类别参考广告，每条广告附有一条关于从中获取什么的一行注释。
- 品牌的“应该做”和“不应该做”限制在约 2 条以内；更长的列表会停止被阅读。
- 按放置位置命名宽高比，但不要硬编码安全区域像素 - 发布的数字在像素上相差约 10 个像素。改为在导出之前要求每个放置位置的预览。
- 设计讨论：每个重要的声明都必须作为屏幕上的文本清晰可见；字幕是必选项。简报中需要注明的例外：Reels 倾向于声音开启（根据 Benly 的说法，约 70-80% 的带音频观众），因此最佳的 Reels 创意可以双向使用。
- 可访问性字段：WCAG 4.5:1 的最小对比度用于文本，视频上的字幕，替代文本，并且每秒不超过三次闪烁。
- Meta 的“20% 文本规则”已于 2020 年废除：没有硬性限制，也没有拍卖惩罚。将文本密度视为性能偏好。在供应商帖子中流传着关于持续隐藏交付惩罚的传言，但未经证实 - 建议这样说，而不是将传说编码为规则。
- **增强字段**：平台自动增强功能默认开启，并扩展变量空间而无需询问。一个无人设置的切换按钮是一个不受控制的变量，因此简报按类型记录增强的开启/关闭状态。
- **AI 披露行**：在平台自己的工具之外生成的内容通常必须在广告管理器中声明（平台自动标记其自己的工具的输出）；未披露的 AI 内容是常见的拒绝原因。简报字段，而不是事后想法。

## 测试意图

每个简报都包含一个可证伪的假设 - Directive Consulting 的 B2B 模板通用性很好：_“如果我们以 [痛点] 和 [证据] 开头，那么 [受众] 将会 [行动]。"_ 输入它，改变一个变量，并保持其他所有内容不变。

五种类型，按效率顺序排列：

- **钩子** - 从同一拍摄中多一个剪辑。
- **证据** - 交换证据，无需重新拍摄。
- **格式** - 新的容器，所以需要新的制作。
- **角度** - 新的概念和新的简报。
- **角色** - 新的研究，新的受众，平行的简报。

这个顺序在另外两个轴上反转，这就是命名类型的全部意义所在：

- 努力程度：角色 > 角度 > 格式 > 证据 > 钩子
- 价值（学习成果如何转移到账户中，以及持续时间）：角色 == 角度 > 格式 > 证据 > 钩子

角色和角度在价值上相同，因为任何一级的结果都会重写其下游的所有简报 - 错误的角色和错误的角度都会使它们下面已经测试的钩子、格式和证据失效。它们在努力程度上分离，这是唯一可以排序它们的因素。

**这个顺序会损害：角色，以及它后面的角度。** 它们是两种价值最高的类型，也是两种最昂贵的类型，所以一个比例会每次选择钩子。这是仅迭代测试计划的记录失败：在没有人测试过的前提下，数月内的钩子剪辑。

在概念系列平坦时推广它们 - 没有钩子无法挽救错误的角度，没有角度无法挽救错误的角色 - 当平坦系列是你唯一运行过的系列（直接跳过级别），或者当面试答案是复合学习任务时。一个能够在几天内建立角色的研究团队会压缩努力轴，并仅凭成本推广它。

默认级别：**钩子**，每当角度已经在某个地方获胜时 - 钩子测试是从同一拍摄中多一个剪辑，并在一个冲刺内解决。一个硬性的短期截止日期会把你困在那里。

重新排序针对你已经持有的不公平优势，例如一个已经批准但未使用的证据资产（命名客户成果，第三方徽章），这使得证据测试成为最低级别的级别，而不是第三级。当账户无法运行任何类型时 - 没有预算进行角色研究，没有第二个受众进行测试 - 删除该级别并说明，而不是将其留在无人能采取行动的列表顶部。

- 将交付成果声明为算术（`2 个钩子 × 1 个主要编辑 = 3 个文件`）并明确标记迭代与净新之间的区别：调整大小不是新设计；一个视频的三个钩子剪辑不是三个概念。这个字段是防止范围争议的原因。
- 在任何删除/扩展调用之前提交最低证据。归因的起始点，而不是法律：在阅读钩子率（SparkUGC）之前至少有 2,000 次展示，以及在大约 5-10 次转化或 5-10 倍目标 CPA 的 5-10 次支出之前进行基于转化的调用（Taylor Sicard）。根据账户的量进行调整。
- 指标陷阱：钩子率在 Meta 上是 3 秒播放 ÷ 展示，但在 TikTok 上计为 2 秒 - 永远不要跨平台进行基准测试。发布的参考范围，归因且永不通用：Meta 冷启动流量上 25-30%+ 的钩子率是健康的，25%+ 的保持率（SparkUGC；Motion）。
- 提前决定在获胜和失败时会发生什么，以及学习成果会记录在哪里 - 一个整个团队都会阅读的系统，而不是只有一份幻灯片演示。
- **命名**：简报分配资产名称。四个级别 - 概念 → 迭代 → 格式 → 测试变量 - ASCII 仅，变量之间用下划线分隔（通过 Apogee 发布的约定）。示例：`PainFirst_V2_9x16_HookQuestion`。

## B2B 与 B2C

翻译链，钩子层，艺术规则和测试块对两者都起相同的作用。不同之处在于：

**B2B**：一个产品需要 _并行_ 的角色简报（经济买家，技术评估员，最终用户），因为购买委员会在接近 10 个月的周期中平均有 8-13 人（SalesHive） - 不是一次一个角色。简报的 KPI 是 SQL 率或机会成本，而不是单独的 CTR：Directive 的示例中有一个变体在点击上获胜（+35%），同时产生的转化较少，CPA 较高 - 一个针对 CTR 优化的 B2B 简报会购买昂贵的垃圾线索。

证据是一个可量化的成果加上一个徽章或产品截图，而不是前后对比。实践者主导的访谈视频往往比精良的品牌视频更有效（AJ Wilcox）。产品营销负责 ICP 和差异化准确性 - 在每个简报中咨询他们。

**B2C/DTC**：更快的周期，作为明确简报字段的提供机制，在角度和钩子中审查挖掘的逐字语言，创作者格式占主导地位。

## 格式变体

完整的字段列表在 [references/brief-template.md](references/brief-template.md) 中。根据每个生产小时获得的学习量选择容器，然后让放置位置否决选择。三个，按效率顺序排列：

1. **静态** - 一位设计师花费一小时或两小时，并且直接读取角度。最便宜诚实的尝试，也是默认的第一个概念。
2. **搜索** - 一个下午编写资产池，但读取被稀释，因为系统组装广告。只有在关键词需求已经存在的情况下才进入排名；如果没有，它会退出而不是排名最后。
3. **视频/UGC** - 学习最强，因为三个钩子层是分别隔离的，并且账单最大：创作者搜索，拍摄，权利，修订轮。一周的协调，而不是小时。

- 努力程度：视频/UGC > 搜索 > 静态
- 每个概念的学习价值：视频/UGC > 静态 > 搜索
- 合规成本：视频/UGC（创作者使用权，付费合作伙伴关系和证言披露，AI 类似性披露，当面部是合成的时）> 静态 == 搜索（无论类别已经要求何种主张证实）

静态和搜索在合规性上相同，因为它们都不会引入一个人，一个性能或一个权利持有人：它们触发的唯一审查是类别在简报存在之前已经要求的声明证实。

**这个顺序会损害：视频/UGC。** 价值轴的顶端，效率的底端，所以它每次都会输给设计师在一小时内完成的静态。一个仅凭比率进行的团队简报会无限期地发送静态，永远不会建立素材库，并且仍然无法说哪个钩子层推动了数字。

在以下任何一项上推广它，并命名是哪一项促成的：

- 面试中的复合任务。拍摄购买素材，一个经过验证的创作者和权利协议，使每个后续视频简报都成为编辑工作。
- 放置否决了替代方案：在 Reels-或 TikTok 首位放置上，静态几乎无法获得交付，所以视频/UGC 领先，不是因为它更便宜。
- 静态在概念系列中已经达到平台期。没有新的布局可以挽救角度，其交付格式是错误的。
- 账户已经持有昂贵的部分 - 内部工作室，常驻创作者名单，拥有的素材库 - 每个都直接压缩了努力轴。

删除，不要降级。如果用户回答他们根本无法获得创作者权利或主张批准，**视频/UGC 从此简报的格式菜单中删除，并命名为删除**，而不是排名最后，下一个冲刺将其读作仅仅昂贵并无论如何都简报它。对于没有关键词需求的情况，相同的处理方式 - 它会退出而不是排名最后（以上）。

硬性截止日期是不同的：它会将你固定在这个简报的静态上，但不会从此删除视频/UGC，所以说“推迟到下一个冲刺”，而不是“删除”。

打破直觉的变体是 **搜索**：没有钩子，没有视觉 - 系统组装广告。简报一个资产池（最多 15 个标题，每个 30 个字符，4 个描述，每个 90 个字符，在响应式搜索广告中）并将标题映射到痛点 / 产品 / 证据主题 - 搜索的消息支柱等效物（Directive）。

两个警告应该出现在每个搜索简报中：

- 广告强度是一个内容质量信号，对广告排名没有直接影响；永远不要追求它。
- 固定会严格限制组合测试（一项发布分析称，单个固定标题的测试减少超过 75%）。

对于 **UGC**：钩子方向不是钩子脚本，要点超过逐字行，修订上限和使用权利（在哪里，多长时间，哪个地理区域）作为简报字段，以及创作者级别的 FTC 披露，平台广告标签无法满足。

## 衡量是否有效

按此顺序进行测量 - 效率，而不是重要性 - 而不是一次全部三个：

1. **重新简报率** - 在生产开始之前发送回简报以澄清的比例。由发送简报的人保持计数，所以接近零运行，并且是主要的简报质量 KPI。这项技能的实际目标，而不是一个研究常数：低于 20%，从你自己的历史中收紧。
2. **简报到启动周期时间** - 每个简报两个日期。Directive 的发布 B2B 基准是 10 个工作日或更少。
3. **简报到获胜概念比例** - 在一个滚动 90 天的窗口内（一个机构发布的运营 KPI） - 一个持续的工作，并且直到足够的概念发货后才会产生噪音。诚实地读取分母：获胜者在大规模运行中约占 5% 的创意（Motion），所以根据你自己的历史趋势进行判断，而不是绝对标准。

如果该滚动日志已经在你的报告堆栈中存在：比率变得免费而不是昂贵，并且移动到顶部。

直到每个模板字段都包含有证据引用的真实内容，并且执行者确认在阅读过程中没有澄清问题。

然后跟踪三个 KPI 在滚动日志上：

- 上升的重新简报率是简报问题。
- 获胜比率随着干净的简报而崩溃是概念多样性问题。

## 常见失败模式

行按“先修复”顺序排列，并且这个顺序纯粹是价值：每个修复在开始生产之前的简报编写分钟数都相同（`目标 == 认知 == 基准 == 一切以下`），所以唯一区分它们的是每个修复能买到的东西。前四个使它们下面的所有修复都不可读 - 没有 KPI 的简报无法判断，没有认知级别的简报无法选择钩子，而目标移动的测试根本无法读取。根据这个团队实际重复的失败重新排序：一个写紧假设但每个季度都烧毁创作者的商店首先修复反馈行，无论一般顺序说什么。

| 陷阱                                      | 为什么它会燃烧                                                                                   | 修复                                                                   |
| ----------------------------------------- | --------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 在目标存在之前简报交付成果                | 没有假设的量级教学无物                                                                           | 目标和 KPI 是面试问题的第一个；没有目标，没有简报                      |
| 认知级别空白或“所有受众”                | 每个级别都需要不同的开场；所有受众的定位服务于 none                                             | 每个简报一个级别；当级别真正不同时拆分简报                              |
| 简报中没有性能基准                      | 删除/扩展决定由感觉做出                                                                           | 决定 KPI + 阈值 + 最低证据，在启动之前写入                              |
| 在测试过程中更改目标                      | 测试变量不再是唯一变量                                                                        | 冻结测试窗口的目标；目标更改是它们自己的测试                          |
| 多条信息塞入一个广告                      | 观众选择 none                                                                                 | 一个角度，一个证据点；多余的信息成为单独的概念                         |
| 钩子方向留给执行者的判断                  | 最高杠杆元素未经测试和记录                                                                    | 3-5 标记选项加上推荐的首个测试                                        |
| 用模糊形容词代替参考广告                  | “高端”和“真实”对每个读者解码不同                                                            | 2-3 个类别参考，每个一条注释                                          |
| 通用规格在跨平台重复使用                  | 放置位置会裁剪，截断和叠加不同                                                                | 每个放置位置的宽高比；在导出之前进行放置预览                          |
| 过度脚本创作者                          | 交付停止听起来自然 - UGC 工作的原因                                                          | 要点和钩子方向；字是创作者的                                          |
| 太多的利益相关者添加冲突反馈              | 修订轮会成倍增加；信息会稀释                                                                  | 一个批准人；每个修订一个整合的反馈轮                                  |
| 结果仅存储在幻灯片演示中                  | 丢失变体在下一个冲刺中教学无物                                                                | 简报中的学习字段 + 一个持久的角库                                      |
| 迭代瘫痪（有争议 - Dara Denney）         | 优化纯变量隔离的简报格式会产生所有看起来都一样的创意                                             | 保留一部分简报用于真正的新概念，而不仅仅是迭代                          |
