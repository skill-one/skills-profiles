# 榜主映射

将关于账户的已知信息——联系人列表中的职务、通话记录、电子邮件和会议活动、CRM联系人角色——转化为利益相关者地图。该地图：

- 指出可能的董事长、经济购买者和阻碍者或反对者。
- 根据证据强度对每个任务进行评级。
- 说明尚未被证实的内容。
- 附上下一步具体的行动，以证实或证伪。

角色定义来自MEDDICC（董事长、经济购买者）和挑战者（动员者、阻碍者），作为命名来源；这项技能识别和测试人员——它从不根据任何缩写词对交易进行评分。

整个过程中使用的信心标签：

- **已验证**——在命名来源中确认。
- **二手信息**——仅通过其他发布者记录。
- **供应商数据**——供应商自己的相关性平台数据集，从未被独立复制。
- **推断**——这项技能自身的推理，而不是引用的声明。

这里的任何供应商相关性都不是因果关系，永远不是。

## 面谈

映射之前进行面谈。每条消息一个问题；在可能的情况下提供多个选择答案；跳过用户数据已经回答的内容。

- B2B，还是高考虑度的B2C？（这里的B2C是指需要考虑的家庭购买——改造、太阳能、私立学校、金融产品——而不是冲动零售。）
- 交易规模和细分市场？（交易性/中市场/企业——这设定了覆盖基准和预期的委员会规模。）
- 有哪些联系人数据？（联系人列表和职务、通话记录或文本、电子邮件/会议活动、CRM联系人角色字段——粘贴或附加所有可用内容。）
- 交易处于哪个阶段？（早期发现、评估、提案、采购/纸面流程——后期阶段需要更多已证实角色。）
- 团队是否运行销售方法论（MEDDICC/MEDDPICC、挑战者、米勒·海曼、其他）？地图将在重要之处使用其词汇。
- 行业或监管环境？（受监管的购买者默认为委员会增加合规和法律席位。）
- 产品是否涉及客户数据？（如果是，则假设存在安全审查者，无论是否出现——**推断**来自从业者共识，即安全可以在其他人批准后否决。）
- 关于该组织的已知信息——汇报线、在此账户的先前交易、上次购买者是谁？
- 当前主要联系人是谁，为什么是他们？（答案通常揭示交易是否为单线程。）
- 必须在什么日期之前证实下一个任务——关闭日期、董事会会议、预算周期？（硬性日期会促进近零、同周的要求，并删除任何延迟超过它的内容，从共同构建的商业案例开始。）
- 一次性胜利，还是复合资产——这个账户是否也是参考、扩张基础、团队将重新销售的品牌？（复合任务会促进慢、高价值的操作：共同构建的案例、高管赞助人、培养的第二位董事长。）
- 努力上限是多少——这个联系人可以花费多少政治资本，多少销售代表时间，以及是否可以生存被拒绝的要求？（低上限，或者已经花费过资本的联系人，将梯子放在其廉价档位并删除概念验证。）

## 工作流程

1. 运行面谈；在分配任何角色之前收集联系人数据。
2. 盘点证据。对于每个联系人，分开三堆：观察到的行为（他们明显做了什么）、声明的声明（他们对自己或流程所说的）、职务/组织推断。这些堆是下面的证据层——永远不要将它们混合。
3. 从分类法中为每个联系人分配候选角色，并用证据评分标准对每个分配进行评级。证据矛盾或空的联系人得到“未知”，而不是猜测。
4. 测试董事长候选人：列出已经做出的资本成本要求，跟进情况，以及要运行的请求的梯子档位——以档位命名，并说明提升或保留该档位的原因。
5. 指出经济购买者，或者明确标记“EB未知”以及会揭示他们的发现行动。如果董事长已经推迟了EB访问，则对推迟进行分类（下文四点阅读），并运行其反制措施；如果证据没有命名任何阅读，则按本节的顺序运行它们。
6. 通过分类法下按效率顺序假设阻碍者，明确包括至少一个尚未在任何通话中出现的职能，并删除此交易确实没有座位的职能。
7. 运行与细分市场基准的覆盖检查；将单线程标记为覆盖差距。（交易笔记的全面红旗审查属于交易红旗技能，而不是这里。）
8. 注意董事长风险：是否存在第二位董事长候选人、高管赞助人、暴露于工作变动或重组？
9. 根据[参考资料/利益相关者地图模板.md](参考资料/利益相关者地图模板.md)组装地图；运行质量门；迭代，直到每个项目都通过。
10. 带有刷新触发器交付：地图是一个活生生的工件，在每个阶段变更、新利益相关者出现或董事长工作变动信号时重新回顾——不是一次性交付（**二手信息**，米勒·海曼从业者纪律通过已发布的综合）。）
11. 如果您的 harness 具有持久内存，请记住地图、每个分配背后的证据以及打开的下一步行动——下一次运行从已证实的基础开始，而不是重新推导。否则，将地图文件交给用户保存并重新提供。

## 角色分类法

每行定义和区分测试。完整的框架分歧（米勒·海曼的教练与MEDDICC的董事长、挑战者的职务拒绝）在[参考资料/证据和基准.md](参考资料/证据和基准.md)中。

| 角色                      | 定义                                                                                                                                                               | 区分测试                                                                                        |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| 董事长                  | “在客户组织中拥有权力、影响力和随之而来的信誉，并愿意和能力协助您的人”（**已验证**，MEDDICC） | 花费内部政治资本：通过具有资本成本的请求并跟进                        |
| 教练/信息提供者         | 有帮助，分享流程和政治，但缺乏权力或不会花费资本                                                                                             | 提供信息；在要求EB介绍时犹豫或推迟                                      |
| 应援者                   | 热情，参加每个会议，没有组织影响力                                                                                                                | 无法调动预算或覆盖任何人的偏好；热情是唯一的证据                        |
| 赞助人                   | 高级，为交易提供姓名和权威                                                                                                                             | 赞同但不做内部销售工作或构建案例                                       |
| 动员者（挑战者）    | 由共识构建倾向定义，而不是职务（**已验证**作为挑战者分类法）                                                                             | 对见解做出硬性问题并推动内部变革                                         |
| 经济购买者            | “当别人说不行时说行，当别人说行时说不行”（**已验证**，MEDDICC）                                                                        | 可以为此购买释放自由裁量或未预算的资金                                        |
| 预算持有者             | 拥有预算线                                                                                                                                                       | 可能没有权力将预算转移到此购买                                                     |
| 签署人                 | 签署合同                                                                                                                                                           | 可能是执行EB决定的代表——永远不要将两者混淆（**二手信息**，MEDDICC指南） |
| 批准人                  | 流程中要求的签字（采购、法律、安全）                                                                                                                      | 控制纸面流程；不是基于价值的决策者                                           |
| 阻碍者                   | 在风险、竞争优先级或政治上提出异议                                                                                                                       | 公开提出异议；可以被解决或收买                                                   |
| 反对者/反董事长        | 积极工作以击败交易，通常默默地                                                                                                                            | 很少参加任何会议；只能通过二级效应（停滞、重新出现的异议）才能看到              |

## 证据层和信心

根据支持它的最强证据对每个角色分配进行评级：

- 花费成本的行为优于花费低成本的行为。
- 花费低成本的行为优于声明的声明。
- 声明的声明优于职务。

| 层级                     | 证据                                                        | 示例                                                                                                    |
| ------------------------ | --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 1 - 花费成本的行为       | 联系人做了花费努力或政治资本的事情                             | 安排EB会议；转发商业案例；在代表未参加的会议中为交易辩护 |
| 2 - 低成本行为           | 可观察但便宜的行为                                    | 快速回复，会议出席，分享非敏感信息                                        |
| 3 - 声明的声明         | 他们所说的话，未经证实                                  | “我是决策者”；“我会内部支持这个”                                                  |
| 4 - 职务推断      | 从职务、部门、资历猜测角色                              | “负责此类别的副总裁，所以可能是EB”                                           |

信心规则（**推断**，这项技能的评分标准）：

- **高**：至少有一个层级1项目，与其余证据一致。
- **中**：层级2或层级3证据得到第二个独立项目的证实。
- **低**：单个未经证实的项目，或任何层级4。
- 职务本身是最弱的层级，永远不会产生超过低评级——职务可以提出假设，永远不会确认角色。
- 缺失或矛盾的输入会扩大不确定性：将信心上限设置为低，并将角色标记为“未知”，而不是默认为典型的组织图。
- 公司规模使职务推断弯曲：在小公司中，职能负责人直接购买；在1000名员工以上，相同的职务通常距离预算两级（**二手信息**，已发布的资格提示启发式）。

## 董事长的测试

董事长是通过花费内部资本的要求和跟进来证明的，而不是通过热情。“没有董事长，就没有交易”（**已验证**，MEDDICC）。以下四个规范要求是一个梯子，而不是一个列表，按两个轴进行评级：

- **努力**——联系人的自身政治资本，加上日历延迟和可逆性。一个被拒绝的要求会花费他们可能无法收回的立场。
- **价值**——关于这个人是否真正是董事长的证据强度。

- 努力：共同构建案例 > EB介绍 > 标准分享 > 可转发电子邮件
- 价值：共同构建案例 > EB介绍 > 标准分享 > 可转发电子邮件
- 效率：标准分享 > 可转发电子邮件 > EB介绍 > 共同构建案例
- 合规成本：标准分享（在正式的RFP或公共采购中，要求竞争性报价可能会取消投标）> 可转发电子邮件 == EB介绍 == 共同构建案例（在零接触点时真正相等：不触及政策、合同条款或签字）

努力和价值评级相同，这就是为什么行顺序不能是：最强的证据也是最有可能被拒绝的要求。按效率顺序运行梯子。

| 档位 | 要求                                                                                                           | 联系人的努力                                         | 购买的证据                                                                              |
| ---- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 1    | 分享内部评估标准、竞争供应商或预算                                              | 一个小时，加上一个通常被打破的规范                      | 层级 1：他们为你承担了真正的风险，竞争性画面在同一移动中到达  |
| 2    | 转发代表编写的内部摘要，或联系客户参考                                        | 近零，同一天                                      | 弱层级 1：他们的名字现在已内部与你关联——证明意愿，而不是立场 |
| 3    | 安排与经济购买者或高管赞助人的会议                                             | 一周的日历延迟；可见的立场被花费       | 层级 1，加上交易最诊断性的答案——以及EB会议本身            |
| 4    | 共同构建——不仅仅是接收——内部商业案例，并在代表未参加的会议上展示它                                         | 高管审查周期；公开投入，难以撤回 | 可用的最强证据：他们在你无法进入的会议室中为交易辩护       |

一次只推进一个档位：

- 对于未测试的联系人，默认为档位 1。
- 每次上一个档位在规定的时限内通过跟进时，就爬升一个档位。
- 永远不要重复通过的档位：一个第二次便宜的请求不会购买新的证据，重复一个档位是地图在整个季度保持中等级信心的原因。

档位 4 是效率顺序所缺乏的：最高价值，最差比率，最后每一轮，并且一个只计算效率的集合永远不会运行它。无论如何都要提升它，当任何以下情况发生时：

- 档位 3 已通过，或者结构上不可能（EB 不与供应商会面）。
- 决策已进入代表无法参加的委员会。
- 竞争对手在房间里，地图剩下的唯一风险是此联系人是否在那里为你辩护。

删除，不要降级，被交易的约束规则排除的请求；被排除的请求在底部无声地重新出现作为范围。

- 在正式的RFP或公共部门交易中删除档位 1。
- 在评估阶段之前删除档位 4：发现阶段的交易没有委员会会议要展示。

这个订单是默认的，不是法律。它会随着分段、阶段以及执行者而变化：一个有现有执行关系的代表为第3级付出的费用远低于一个首次进入账户的新卖家。

根据对这个交易已有的了解重新排序：

- 与EB（经济买家）的现有关系会删除第3级（介绍费用已经支付）。
- 已经花费过资本的联系人从他们通过的级别开始。
- 对于委员会来说太早的交易会停留在第1-2级。

根据面试答案重新排序，并说明哪个答案移动了哪个级别。

第3级的诊断：“如果你的倡导者不愿意或无法介绍你给EB，这可能是一个信号，表明他们不是一个真正的倡导者，你需要做工作”（**已验证**，MEDDICC）。Nate Nasralla的前期承诺测试在发现过程中确保第2级的证据： “如果我给你写一封总结我们一直在工作的简短邮件，你愿意转发它吗？”（**已验证**）——承诺本身，然后是后续行动，都是证据。

阅读回复：在规定时间内跟进是Tier-1证据——升级。在资本成本问题上两次犹豫或推诿会将联系人从倡导者降级为教练；不要依赖他们的优势来推进交易。（一个流传的“40%的所谓倡导者未能通过此测试”的数字是实践者的传说，没有可追溯的方法论——仅作说明。）

MEDDICC发布的警告标志表明联系人不是一个倡导者（**已验证**）：

- 缺乏信息共享。
- 反对介绍。
- 缺乏内部支持。
- 组织访问有限。
- 内部阻力时犹豫不决。

在整个周期中重新测试，而不是在资格认证时只测试一次。

## 经济买家发现

“经济买家不太可能举手告诉你他们是EB。这是你的工作来识别他们”（**已验证**，MEDDICC）。根据分类法区分EB与预算持有者、签字人和批准人——EB是即使预算未批准也能资助此交易的人。角色识别问题（这项技能的所有问题——完整发现集属于销售发现问题技能）：

- “谁必须批准你上次购买此类解决方案？”
- “谁是此类购买的预算持有者——他们能否将预算转移到这里？”
- “如果其他人都说行，只有一个人可以说不，那是谁？”

**当倡导者推迟EB访问时**——交易中最具诊断价值的事件之一。四种标准解读，每种都有其应对策略（**二手**，MEDDICC衍生来源的实践者共识）。

根据证据而非选择来诊断解读，因此以下排名故意保持狭窄：它决定在证据没有说明哪个解读适用的情况下，首先运行哪个应对策略。证据已经命名诊断的排名将是虚假的精确度。

- 效率（每名代表小时和联系人资本单位的EB访问）：EB准备好的单页 > 决策路径探测 > 令人信服的事件重访 > 重新运行倡导者测试
- 价值（它解决什么）：重新运行倡导者测试 > 决策路径探测 > EB准备好的单页 > 令人信服的事件重访

| 解读                                                        | 应对策略                                                                             | 努力                                                   | 它打开大门的几率                                                                             |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 害怕失去控制或暴露缺乏权威                                     | 价值交换：一个简短的、EB准备好的商业案例，让他们在展示时看起来很好 | 一小时的代表时间；几乎零联系人的资本           | 良好——而且这是唯一一个也有助于解读1和3的玩法，这也是它排在第一的原因 |
| 保护关系，或者真正的决定权在别处                                | 给他们一个理由，让EB想要会议；探测实际决策路径         | 一小时，在已经预订的下一个电话中             | 访问适度，信息量高——无论哪种方式，它都返回了地图上最大的未知数          |
| 没有活跃的交易——没有紧迫性                                    | 重访令人信服的事件；如果没有，地图不是问题                       | 一小时，交易可能在这个电话上结束                | 访问低——但一个负面答案可以节省四分之一的错误指导的努力                        |
| 不是真正的倡导者——没有资格获得会议                            | 重新运行上一级的倡导者测试；如果再次失败，降级为教练              | 一周的延迟，并且联系人的资本再次花费        | 低——它解决了地图，而不是打开大门                                              |

最后手段：通过另一条路径多线程到EB。它在每个轴上都排在最后，而它排在最后的原因是不可逆性，而不是小时数。绕过倡导者可能会破坏信任，并将倡导者转变为反对者，这是这张地图上唯一将资产转变为负债的行为（**二手**，实践者来源一致）。

从单线程交易中直接删除它，而不是保留它：有一个真正的关系就没有剩下什么可以卖的了。给与获取软化了要求：用联系人想要的东西换取介绍，并事先声明为条件（**已验证**，Jason Bay的模式）。

## 阻碍者分类法

按功能假设阻碍者，而不是按谁出现了。文献中的反复模式：交易因安全、法律或财务中从未被映射也从未出现在电话中的单个沉默的反对者而死亡（**二手**，实践者来源的综合）。根据相同的研究基础合成的表格，行按效率排序——每单位工作的否决权风险，而不是按资历或功能有多响亮。

- 努力：技术POC > 政治重组 > ROI模型在他们自己的数字中 > 安全包 == 合规包 > 采购、法律和现有玩家的（在接近零时相等：每个都是你已拥有的材料的一次发送）
- 效率：法律 > 安全 == 合规 > 采购 > 经济 > 现有忠诚派 > 政治 > 技术
- 合规成本：合规/居民承诺 > 法律红线 > 其他（接近零）——一个居民选项或为清除一个审查而让步的自定义条款会绑定它之后的所有续订，并且这是这里你无法悄悄撤销的唯一玩法

安全和合规在两行上并列，因为它们是同一份工作——制作证据包——但针对不同的审查者：当包存在时，一小时；当它必须从头开始时，四分之一小时。

| 阻碍者                      | 信号和动机                                                   | 否决权                            | 中和/收买                                      | 努力                                                                          |
| ---------------------------- | ----------------------------------------------------------------------- | ------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 法律                        | DPA/MSA红线；责任，数据权利                                | 阻止不可接受的条件        | 用标准条款预先阻止                             | 接近零：在他们在要求之前发送标准文件之前                              |
| 安全 / 信息安全           | 问卷，认证审查；数据隔离，合规立场                          | 在其他人批准后可以否决 | 认证，架构文档，SSO                   | 如果包存在，一小时；如果必须从头开始，四分之一小时                              |
| 合规 / 隐私         | 数据居民和监管审查；审计要求                    | 否决居民/合规          | 合规摘要；居民选项                     | 如果包存在，一小时；如果必须从头开始，四分之一小时                              |
| 采购                  | 在纸质处理阶段出现；价格，条款，供应商风险               | 控制合同条款和时间表  | 早期参与；给倡导者谈判掩护            | 接近零，但如果在纸质阶段之前运行                                           |
| 经济（CFO，预算持有者） | TCO/ROI问题；控制资金；成本和机会成本          | 如果ROI未证明，会阻止资金        | ROI模型在他们自己的数字中；美元商业案例 | 一周——并且它需要倡导者的资本来获得他们的数字               |
| 现有忠诚派           | 倡导现状；转换成本，沉没关系                 | 为“不做任何事”集结        | 无行动成本框架；控制而不是转换    | 接近零来制作，但转换很少成功——只为控制预算                      |
| 政治                    | 竞争性计划，地盘；地位，控制，竞争对手项目              | 非正式；可以集结反对        | 对他们的议程保持一致；行政赞助人                 | 一周或更长时间，如果他们的竞争对手项目获得资助，则无法获胜                 |
| 技术（CTO，架构师）   | “我们需要通过IT来运行这个”；集成清洁度，标准    | 否决权，很少预算         | 早期表面；技术验证，POC                 | 双方各四分之一工程时间                                     |

概念验证是这个订单所缺乏的：它产生最强的技术证据，并且在表格上具有最差的比率，并且它是唯一一个也花费买家的工程时间和倡导者的资本来安排的玩法。当任何一个持有时，提升它：

- 技术审查者持有真正的否决权，并已经声明了文档无法回答的集成异议。
- 产品差异化仅在买家的自己环境中可见。

删除这个交易排除的行，而不是低负载携带它们：

- 对于一个不受监管的买家，其产品不涉及个人数据的合规/隐私行。
- 对于B2C家庭，整个法律/安全/合规/采购块（见模板的适应性）。

一个停在最底部的行会作为纸质阶段的非计划范围返回。

注意资历不匹配：映射在高管（CISO）上过度索引，而实际运行审查的人（安全架构师）对任何无法干净集成的内容持有非正式否决权（**二手**）。最危险的反对者往往不在任何电话上——地图必须包含关于缺席人员的假设，而不仅仅是关于在场人员的观察。根据这个账户已经给你的东西重新排序这些玩法：来自先前交易的现有安全审查通过，内部解决方案架构师，或为另一个买家编写的合规包都会将他们的行提升。

## 覆盖检查

- 按分段进行的基准（**供应商数据**和实践者启发式算法，相关性，不是目标）：中市场约4-7名参与联系人，~10名50K-$250K，11-17+名战略企业。Gartner的调查将中位数购买小组放在6-10名决策者（**已验证**为Gartner的数字，2017，n=750）。
- 单线程是一个覆盖差距：一个真正的关系意味着交易会随着一个离开而死亡。将任何超过50K的单线程交易视为结构上落后——在Gong的1.8M交易分析中，超过50K的多线程交易在实质性更高的比率上获胜（其“130%提升”是**供应商数据**，相关性）。在这里标记差距；交易红旗技能拥有更广泛的审查。
- 计算关系，而不是名字：“你实际上在交易中受到保护——还是只是有多个电子邮件地址和一个真正的关系”（**已验证**引言，30MPC/Gong报告）。
- 挑战者逆流，这样地图就不会被读作“更多的联系人=更好”：CEB的数据显示，随着购买小组规模的增长，购买可能性**下降**（81%在一名决策者，55%在两名，六名中位数在30年代）因为共识变得更难（**已验证**为CEB的公开声明）。更多的利益相关者使购买变得更难；多线程是卖家**管理**购买小组复杂性的一种方式，而不是导致获胜的力量。添加联系人以覆盖真实角色，永远不要为了膨胀计数而添加。

## 倡导者风险

- 大约20%的B2B联系人一年内更换工作（**供应商数据**，一个工作变更警报供应商引用了一个专业网络分析）——一个多个月交易依赖于一个倡导者结构上脆弱，而且大多数离职都是沉默的。
- 地图必须回答三个问题：
  - 是否在培养第二个倡导者候选人？
  - 是否有一个高管赞助人，其承诺在中层离职后仍然存在？
  - 工作变更是否会在几天内被检测到（警报）或在下一个幽灵电子邮件时被发现？
- 在倡导者离职信号下：立即激活冗余候选人，依靠高管赞助人保持连续性——并注意离职也是倡导者下一家公司的一个机会。

## B2B和B2C

高考虑B2C以不同的名称运行相同的多元角色逻辑：消费者理论的家庭决策单位（**已验证**，Schiffman & Kanuk / AMA学术分类法）。

- **发起者** - 提出需求
- **影响者** - 形成标准
- **决策者** - 持有权力
- **购买者** - 执行购买
- **用户** - 消费
- **守门人** - 控制信息流

映射到这项技能的角色（**推断**，分析转移，不是经验测量等价物）：

- 决策者 ≈ 经济买家
- 守门人 ≈ 行政/采购筛选
- 影响者 ≈ 技术评估
- 用户 ≈ 最终用户
- 热情的配偶，如果卖另一个，就是倡导者
- 怀疑的家长、姻亲或共同签字人是沉默的反对者
- “不做任何事”在厨房翻新中与在企业管理软件中一样是真正的竞争对手

两者都完全适用：

- 证据层。
- 倡导者测试（一个让热情的合作伙伴付出代价的请求——“你会在周四之前让你的配偶走一遍这个报价吗？”）。
- 推迟解读。
- 自信规则。
- 质量门。

在地图上说明，而不是让它隐含。

不会转移：

- 没有采购、法律或安全否决功能，没有书面纸质流程，也没有CRM工具。
- 力量地图变成非正式直觉。
- 角色根据购买而变化（汽车的决定者可能是学校的一个影响者）。
- 家庭情感动态没有被影响/情绪评分捕捉。

从模板中删除这些行；保留所有其他内容。

## 调用和预期输出

典型调用：

- “这是Meridian交易的联系人列表和我的通话笔记——谁是我的倡导者，谁实际签字，谁会阻碍这个？”
- “映射这个机会的利益相关者；我的主要联系人很棒，但我不知道她是不是倡导者，还是只是朋友。”
- “我们销售家用太阳能；丈夫预订了咨询并且非常喜欢——在我发送提案之前映射这个家庭。”

交付一个利益相关者地图（完整的模板在[references/stakeholder-map-template.md](references/stakeholder-map-template.md)）：

```
利益相关者图谱 - <账户>, <交易规模/细分>, <阶段>, <日期>
每个利益相关者：姓名、职位、分配角色、证据层级+证据本身，
                  信心程度、仍需验证的差距、下一步行动（证明/证伪）
关键人物测试：提出的请求、观察到的跟进情况、下一步请求及其层级和原因
经济购买者：姓名+证据，或“未知”+浮现行动
阻碍因素：每个合理职能至少1个假设，包括尚未参与会议的人员
覆盖范围：参与联系次数与细分基准对比；单线联系标志
关键人物风险：冗余候选人、高管赞助人、工作变动风险
刷新触发器：何种事件强制进行该图谱的重新梳理
```

## 常见失败模式

| 失败                                                     | 修正                                                                                                                                                         |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 将响应速度误认为权力                                      | 快速回复为层级2；每个会议都参加的联系人可能没有组织影响力 - 根据投入资本而非热情来评估                                                                 |
| 根据职位分配关键人物                                      | 职位为层级4，上限为低；关键人物需通过已通过的资本成本请求来证明，否则不足                                                                                      |
| 仅梳理参会人员                                          | 最危险的负面因素从不参会；强制提出缺席职能的阻碍假设                                                                                                          |
| 将图谱视为一次性成果                                      | 每个阶段变更、新利益相关者或工作变动信号时重新梳理；未满足的角色和难以理解的立场是图谱上最有价值的内容                                                                 |
| 绕过关键人物直接接触经济购买者                            | 首先按排名顺序执行推迟应对措施；绕过会将关键人物转化为负面因素，在单线交易中直接删除                                                                                   |
| 提出最大请求，或重复最便宜请求                            | 从层级1逐级攀登请求；已通过的层级不会带来新证据，层级4需要其推动条件                                                                                           |
| 将经济购买者与签字人或预算持有者混淆                      | 签字人可能是代表；预算持有者可能缺乏重定向权限；测试“当他人说否时说是的”情况                                                                                   |
| 将邮箱地址计为覆盖范围                                    | 多个联系人只有一个真实关系仍是单线联系                                                                                                                         |
| 将陈述主张视为证明                                      | “我是决策者”为层级3；在提高信心超过中等前需通过行为佐证                                                                                                        |

## 质量门槛

对照所有八项对草拟图谱评分。通过标准：8/8。迭代直至无失败项。

1. 每个命名利益相关者都带有角色、证据层级及实际证据、信心程度和下一步行动。
2. 没有高信心分配仅基于职位；没有关键人物在未通过资本成本测试前为高信心，且下一步请求需说明其层级及非上一层级的原因。
3. 经济购买者需命名并附证据，或明确标记未知并附浮现行动 - 永不沉默忽略。
4. 至少存在一个阻碍/负面假设，且至少一个指明尚未在任何会议中出现的职能。
5. 覆盖范围计数与细分基准对比，并标记是否存在单线联系。
6. 关键人物风险需回答：冗余候选人、高管赞助人和检测方法均需涉及（或诚实标记缺席）。
7. 图谱上每个供应商统计数据均标记为相关性；不将陈述主张作为已证明行为呈现。
8. 需说明刷新触发器 - 图谱声明何时失效。

## KPIs和衡量标准

- 每次刷新，图谱有效当：
  - 前版本的下一步行动被执行并验证其分配（在两次刷新中从未离开层级3-4的分配是差距而非事实）。
  - 关键人物通过新的资本成本请求。
  - 提案阶段未出现之前未至少假设的利益相关者。
- 在交易中，追踪在提案/解决方案呈现阶段前已接触经济购买者的图谱比例 - 顶级表现者在Ebsta/Pavilion的千万级机会分析中更频繁早期接触EB（**供应商数据**，相关性，平台选择偏差适用）- 以及归因于未映射负面因素损失的占比。未映射负面因素损失下降是诚实的成功信号。

可选集成说明：

- CRM联系人角色字段播种层级4假设。
- 对话智能转录提供层级1/2行为证据。
- 工作变动警报补充关键人物风险行。

三者均为类别 - 同类工具均可，无任何工具图谱仍可运行。
