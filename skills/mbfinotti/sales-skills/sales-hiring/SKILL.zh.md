# 销售招聘

构建招聘经理在招聘SDR/BDR或AE时所需的四项关键成果，并确保其具有证据支持：角色评分卡、结构化面试流程（含题库）、评分式模拟通话工作样本以及30-60-90分阶段计划。在每一个阶段，结构化都优于直觉——这项技能的全部目的就是强制执行这一点。

为每个基准输出标注简短的括号内名称，标明其来源——同行评审、调查、众包、供应商数据或特定从业者——并且永远不要将低级别的成果呈现为高级别的，或把供应商的声明当作事实。

如果用户被证明是准备销售面试的候选人，而不是正在运行招聘的招聘经理，请停止并引导他们到 `mbfinotti/sales-skills@sales-career` - 这个技能永远不会指导候选人。

超出范围，不要偏离以下内容：

- 招募候选人
- 撰写或发布招聘广告
- 运行申请人跟踪系统
- 将佣金计划作为策略练习来设计
- SDR至AE的晋升机制

薪酬仅在此处作为公布的范围、基本/变量分成以及塑造候选人漏斗和分阶段的薪酬，这些因素会影响招聘流程和分阶段计划。

## 面试

在生成任何内容之前先提问。在以下十个问题停止。

- 每条消息一个问题。
- 提供多项选择选项。
- 跳过用户消息中已经回答的问题。

问题8-10旨在在用户决定路径之前重新排序此技能的顺序——在此询问它们，永远不要在其他时间。

1. 团队阶段：(a) 首次销售招聘，创始人仍在销售；(b) 招聘2-4人，剧本正在形成；(c) 招聘5-30人，存在可重复的剧本；(d) 30人以上，扩展已知的模型。
2. 心中的角色：(a) SDR/BDR；(b) AE；(c) 全周期代表；(d) 不确定——为我推荐一个。
3. 流程来源组合：(a) 主要为入站；(b) 主要为出站；(c) 平衡组合。
4. ACV和典型销售周期长度：(a) 低于~$5K，低于一个月；(b) ~$5-25K，1-3个月；(c) ~$25-100K，3-6个月；(d) 超过~$100K，6个月以上。
5. 市场：(a) 大型企业B2B；(b) 高速度内部销售（SMB/中市场B2B）；(c) B2C/消费者。
6. 薪酬理念：基本工资为主（60:40或更高）还是激进提成（50:50，无上限加速器）？并且您是否会在招聘广告中公布范围？
7. 招聘管辖权：美国（哪些州，值得注意的是纽约/科罗拉多/加利福尼亚/纽约/华盛顿/伊利诺伊），欧盟（哪些国家），英国，其他——这决定了合规性检查。
8. 截止日期：必须在什么日期前签署录用通知？（a）本月；(b) 本季度；(c) 没有硬性日期。
9. 一次性或复合型：一次性招聘，还是多个招聘中的第一个，其中评分卡、题库和评分标准被重复使用？（a）一次性；(b) 复合型。
10. 努力上限：您可以花费多少面试官小时数在每个候选人身上，并且您有招聘人员和现有的培训小组吗？（a）低于~5小时，没有招聘人员，没有小组；(b) ~5-15小时；(c) 更多，有招聘支持。

## 理解答案

以上每个答案都会驱动一个输出；使用它们，而不仅仅是记录它们。

- **Q3 + Q4决定角色推荐（Q2），并且它们会翻转顺序。** 默认情况下，ACV低于~$25K且周期低于三个月的入站流程：
  - 效率：全周期代表 > 仅AE > SDR + AE分成
  - 价值（每个招聘产生的流程和关闭的收入）：SDR + AE分成 > 仅AE > 全周期代表
  - 努力程度（需要运行的流程、需要编写的分阶段计划、需要监督的交接、填补职位空缺的时间）：SDR + AE分成 > 全周期代表 > 仅AE
    在ACV高于~$25K且周期为3-6个月及以上的出站流程中，价值线获胜，分成将主导——一个代表无法同时 prospect 已映射的账户列表并运行六个月的交易。**去/不去，以删除的形式陈述：** 虽然入站量可以保持关闭者的日程表满员，但请从菜单中删除SDR + AE分成，而不是将其排名最后，因为被排除的选项停在最底部会重新出现为人员编制。只有当AE出现空日程表综合征或公司承诺将出站作为战略 **[调查 + 从业者]** 时才将其放回。如果用户在Q2中选择的角色与此相矛盾，请在继续之前质疑选择并说明原因。
- **Q1决定候选人画像。**
  - 首次招聘：创始人主导销售交接问题。招聘一个不依赖基础设施就能销售的建设者，并将大型公司的丰富经验视为风险（“硬币操作”的代表，他们引进公式而不是建立自己的公司）。Mark Roberge对其自己团队的回归分析发现，侵略性和异议处理与成功几乎不相关；可培训性、好奇心、智力和工作道德可以预测成功（他自己的单一公司回归分析，而不是更广泛的研究）。对于亲自运行此面试的创始人或CEO，SaaStr反复提出的对前2-10名代表的框架是一个在评分卡之上叠加的单一直觉测试，而不是它的替代品：您，创始人，实际上会从这个人那里购买产品吗（从业者意见）。
  - 招聘5-30人：可重复性问题。从组织的顶尖表现者中建立画像，并每次都招聘相同的代表。

  也警告：团队规模翻倍需要按比例翻倍每个需求生成源，否则新招聘者会饿死。

- **Q5设置流程长度、工作样本内容、预测权重、薪酬分成和来源**——见B2B和B2C部分。
- **Q6塑造漏斗和分阶段计划。**
  - 基本工资为主的分成会吸引风险规避的候选人，并且适合从零开始没有流程的代表。
  - 激进的50:50计划加上无上限加速器会自我选择自信的关闭者。
  - 未公布的“有竞争力的OTC”会吓跑强候选人，他们会将其解读为配额设定为失败（从业者意见）。

  公布范围在越来越多的司法管辖区也是法律要求（Q7）。

- **Q7触发合规性检查**在流程步骤4中。
- **Q8促进快速行动的选项。** 本月日期：
  - 删除5-6阶段的企事业流程
  - 推广单流程角色，而不是SDR + AE分成
  - 推广重用现有题库，而不是编写一个

  没有硬性日期会保留下面所有默认顺序。

- **Q9决定工作样本是否保持饥饿。**
  - 一次性：建设成本分摊到单个候选人池，因此运行模拟通话，但建设要薄弱——没有季度评分标准更新，没有评分者培训计划。
  - 复合型：冻结的评分标准和题库服务于未来的每个招聘，这会促进正确地并首先建设——这是Selection证据中覆盖效率顺序的条件。
- **Q10删除级别，而不是重新排序。**
  - 每个候选人低于~5小时面试官小时数：削减到3-4阶段，并仅保留结构化面试和工作样本。
  - 没有招聘人员和没有培训小组：Selection证据表中的每小时都成为招聘经理自己的——根据它重新排序，而不是根据一个有团队的团队。

## 流程

按顺序生成四个成果。交付每个成果，使用用户逐部分验证它，然后移动到下一个——永远不要未经审查地一次性倾倒所有四个。

1. 运行面试。使用“理解答案”确认或质疑角色选择，并在用户可以否决的一个简短段落中说明理由。
2. **成果1 - 角色评分卡。** 从 `[references/scorecard-template.md](references/scorecard-template.md)` 构建它。三个部分：
   - 一个使命的句子
   - 3-8个可衡量的成果按重要性和量化排名（例如，“第一年净新ACV 1.2M”，“每个季度40个SQL”），永远不要模糊的责任
   - 5-7个按市场和团队阶段加权的能力

   评分卡也作为面试评分标准和分阶段计划里程碑地图，因此即使用户抵制也要量化成果。避免全能运动员画像：在这些成果上要有狭窄、深入的能力。

3. **成果2 - 面试流程 + 题库。**
   - 设计角色和市场的阶段顺序：SDR 3-4阶段跨越数天-数周；AE 4-6阶段；企业级AE 5-6阶段跨越数周，当候选人池小且热时，会有一个倒置的漏斗（招聘经理在早期）。
   - 将评分式工作样本放在第2或第3阶段，永远不要放在最后。两个位置在价值上相同：`价值：第2-3阶段 == 最后`，一个真正的平局，因为它是同一个工具，同一个评分标准，无论它放在哪里。它们只在小时上分开：`消耗的面试官小时数：最后 > 第2-3阶段`，对于无法销售的候选人，每个候选人需要10多个小时，以及额外的填补职位空缺时间会因竞争性报价而失去候选人。因此，最后的位置被从菜单中删除，而不是排在第2-3阶段之后；质量门5强制执行它。
   - 每个评分卡能力编写2-3个行为性问题加上1-2个情境性问题，并使用深入探测，从 `[references/interview-question-bank.md](references/interview-question-bank.md)`。删除每个脑筋急转弯、“向我推销这支笔”、“最大的弱点”和“你是否可培训”——它们没有证明的预测价值 **[同行评审 + 大规模测量的内部分析]**。
   - 为每个面试官分配一个能力，并在所有候选人的角色中保持相同的面试官和相同的问题。结构，而不是人员编制，是提高有效性的关键；小组不会比单个培训的面试官增加有效性（同行评审）——小组的价值是治理，而不是测量。
   - 现在定义评分机制：每个分数需要一个证据引用，分数在任何简报之前独立提交，并且最终数字机械地结合预设权重。招聘经理在预先承诺的阈值内决定。
   - 如果用户希望在流程中添加人格评估，应用下面的评估规则并加载 `[references/assessment-validity-audit.md](references/assessment-validity-audit.md)`。
   - 运行Q7司法管辖区的合规性检查，使用 `[references/legal-landscape.md](references/legal-landscape.md)`：删除所有地方的薪资历史问题，公布范围，并标记任何AI筛选工具进行偏见审计和高风险AI义务。
4. **成果3 - 工作样本设计 + 评分标准。** 从 `[references/mock-call-design.md](references/mock-call-design.md)` 构建。设计一个模拟通话，让候选人销售用户的而不是自己的产品：
   - 提前发送准备包
   - 一个硬性实时场景
   - 在通话中注入一个未编写的异议
   - 在反馈后重新运行一个市场（可培训性测试，取代无用的自我报告问题）

   在行为锚定的0-3评分标准上评分，有5-8个类别，冻结一个季度，为评分者提供参考框架培训。评分即兴发挥和适应性，永远不要追求完美。根据市场匹配内容：冷呼叫 + 异议处理为SDR/高速度/B2C，发现深度 + 多线程交易策略 + 领域计划为企业。
5. **成果4 - 30-60-90分阶段计划。** 从 `[references/ramp-plan-template.md](references/ramp-plan-template.md)` 构建。
   - 第0-30天：产品/ICP/工具培训，以认证门结束（一个真正的考试，必须通过）；影子模拟通话和沙盒模拟通话。
   - 第31-60天：有指导的实时活动，每个通话都进行审查，第一次机会。
   - 第61-90天：自我寻找的流程，第一笔交易，预测准确性。

   添加：
   - 一个分阶段的配额分阶段计划（25/50/75/100%在连续季度中）
   - 第1-3个月为AE的非恢复性提取
   - 一个与管理员不同的同行伙伴
   - 以情境-行为-影响形式进行检查

   包括预警列表和行动规则：一个错过所有三个90天里程碑（认证、指导改进、自我寻找的流程）的招聘需要决定，而不是希望——非自愿离职在早期聚集，并且生产窗口很短（调查）。
6. 在所有四个成果上运行质量门。迭代直到它通过。
7. 如果您的套件具有持久内存，请存储评分卡、冻结的评分标准、流程设计和分阶段里程碑——稍后的指导和审查会从它们开始。如果没有内存，请告诉用户保留这些成果作为规范包并重新提供它们。

## Selection证据

两个排序控制流程，并且它们不一致，因此永远不要将一个当作另一个来引用。有效性说明一个工具购买什么；效率说明在可用的小时内首先构建什么。读取 `>` 为“更多这个轴”；效率线是构建顺序。

有效性是修正的操作值（Sackett等人2022年修正，同行评审；早期数字被高估了）。

- 效率：结构化面试 > 工作知识考试 > 推荐信检查 > 认知测试 > 工作样本
- 价值：结构化面试 > 工作知识考试 > 工作样本 > 认知测试 > 推荐信检查
- 努力程度：工作样本 > 结构化面试 > 工作知识考试 > 认知测试 == 推荐信检查（平局：对两者都没有构建，运行时间不到一小时）
- 合规成本：认知测试 > 工作样本 > 推荐信检查 > 工作知识考试 == 结构化面试（平局：内容有效的工具，其唯一接触是它们内部的问题——两者都不会触发审计、同意义务或第三方数据处理）

行按效率顺序排列，而不是有效性顺序：

| 工具                | 有效性      | 构建                                                                                                             | 每位候选人运行时间                                                                            | 该行成本                                                                                                                                                                  |
| ------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 结构化面试        | .42         | 一周 - 银行、锚点、面试官培训                                                                      | 每位面试官一小时                                                                      | 最高有效性，并且这一周被后来的每位招聘人员重复使用。有效性随着结构化程度提高而增加（无结构化为 .20，高度结构化为 .57），所以构建过程是购买系数的关键 |
| 工作知识考试      | .40         | 一周编写时间                                                                                                   | 接近零，自我评分                                                                      | 自己的产品无法在招聘前进行测试，所以这成为第30天的认证关卡（工件4） - 它购买的是晋升决策，而不是招聘决策                              |
| 推荐人核实        | ~.26 或更低 | 接近零                                                                                                         | 每位最终候选人一小时                                                                    | 便宜且诚实地说明其本质：欺诈和索赔检查。永远不要像面试或工作样本一样将其加权                                                                    |
| 认知测试          | .31         | 接近零，现成                                                                                                    | 接近零                                                                                    | 最便宜的一行，也是为什么便宜不能导致问题的原因：对客观销售几乎无用（下文有说明），并且五个工具中合规负担最重                          |
| 工作样本（模拟通话） | .33         | 一周设计时间，然后是一个常设工作 - 每季度更新评分标准，对新评分员的参考框架重新校准 | 每位评分员一小时 x 两位，加上候选人准备时间，这些时间成本导致人员流失和时间填补成本 | 这里最低的比率，无论如何都是强制性的。与认知测试相比，不良影响较低，尽管这个差距在现任样本中夸大了                                                  |

**已从菜单中删除，但未排名最后：个人资料（经验性键入），.38（同行评审）。** 经验性键入需要数百名过去招聘人员的成果数据；Q1（a）-（c）的任何团队都没有这些数据，并且降级行将无声地返回为范围。

**效率顺序剥夺了什么：工作样本。** 它具有真实有效性，并且是循环中唯一的“可以做”检查。它同时是：

- 构建成本最高的工具
- 唯一需要持续维护的工具
- 唯一使用候选人时间的工具

所以一个比率在每一轮中都会埋葬它。无论如何，当以下任何一项成立时，请将工作样本提升为第一个构建：

- 这是我们第一个销售招聘，因此没有现任基准来校准面试
- 循环不断通过表现良好但未达标候选人
- Q9回答了复合问题，这会将构建成本分摊到每个未来的招聘人员

**默认设置：**

- 构建结构化面试，然后是工作样本
- 仅对最终候选人进行推荐人核实
- 保留工作知识考试在晋升阶段

只有在承诺将其与客观销售结果验证的情况下才添加认知测试，这需要大多数团队没有的数据，需要四分之一的工作量。

销售特定说明（同行评审）：认知能力与主管评分的相关性为 .40，但与客观销售结果的相关性仅为 .04 - 它预测的是经理对销售人员的看法，而不是销售人员销售的东西。成就/责任心显示出相反的模式（.41与客观销售结果），使其成为更值得信赖的信号。验证任何关卡都需要与客观销售结果相关，而不是绩效评估。

机械组合分数：基于公式的组合预测值为 .44，而专家在脑海中混合印象的预测值为 .28 - 整体判断会消耗高达一半的有效性（同行评审）。这是唯一一个不需要比率的技能选择：机械组合既是更高价值的选项，也是更便宜的选项 - 加权总和与一小时的争论相比。通过在复盘前进行独立评分来实施它：房间中最响亮的声音无法锚定已经提交的分数。

**在使用上述任何排序之前重新排名。** 每一个都是默认值，而不是法律，并且每个都会随着上下文和执行者的变化而变化：

- 一个已经培训好的面试小组会降低结构化面试的构建成本至零，并将工作样本移至第一位
- 没有招聘人员会将表格中的每一小时都变成招聘经理自己的时间，这会缩短循环并提升廉价行
- 第一个招聘没有顶级表现者数据，这是提升工作样本的条件；第三十个招聘有这些数据，这是将经验性键入重新列入菜单的唯一条件

**评估规则：**

- 除非它出现在《Buros心理测量年鉴》中并具有同行评审的基准效度，否则将任何商业销售个性评估视为未验证。
- 永远不要让任何评估关卡或否决候选人。
- 供应商“预测效度”声明超过 ~.55的是营销，而不是心理测量 - 即使是最好的预测者，真实的基准效度也很少超过 .50。

命名供应商审计位于 [references/assessment-validity-audit.md](references/assessment-validity-audit.md)。

## B2B 和 B2C

共享基础在企业 B2B、高速内部销售和B2C/消费者之间完全相同 - 没有哪个细分市场因为其循环较短而得到豁免：

- 书面评分卡
- 结构化面试
- 评分工作样本
- 复盘前的独立评分
- 机械分数组合
- 禁止问题列表
- 法律限制

在哪里细分市场真正分化 - 未排名，故意：Q5选择列，所以这些是查找而不是菜单，并且用户无法在它们之间选择排序选项将是虚假的精度。

| 维度           | 企业 B2B                                                                | 高速内部销售                      | B2C/消费者                                                                                              |
| -------------- | ----------------------------------------------------------------------------- | -------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 循环长度         | 5-6 个阶段，几周；为稀缺人才反转漏斗                                      | 3-4 个阶段，几天到 ~2 周          | 2-4 个阶段，几天；速度赢得候选人                                                                   |
| 工作样本内容 | 模拟发现，多线程交易策略，区域/30-60-90 演示                               | 模拟冷电话，异议处理              | 模拟消费者电话端到端（电话通常是整个交易），异议处理，脚本适应性 |
| 预测器加权     | 发现深度，商业头脑，利益相关者导航                                      | 活动弹性，可指导性，动力        | 活动弹性，拒绝容忍度，动力；合规纪律，如果产品受到监管     |
| 薪酬分割       | ~50:50，绝对变量较大                                                   | 入门时底薪为主（新销售没有管道） | 通常佣金为主，带底薪；预期更高的流失率 - 预算回填                               |
| 招聘           | 主动猎头一小部分映射列表                                                  | 入口，高容量漏斗，快速筛选    | 高容量漏斗，快速筛选                                                                       |

在 B2C 工作时标记基准来源：发布的晋升、任期和达成数字偏向北美 B2B SaaS（调查）。向 B2C 用户展示时，将其作为方向性，而不是他们的基线。

## 质量关卡

在最终交付前，根据所有十二条检查评分四个工件。通过阈值：12/12 - 每个检查都追溯到特定发现，所以遗漏是证据违规，而不是风格选择。迭代直到每个检查通过；将检查清单与工件一起报告。

1. 评分卡有 3-8 个结果，每一个都量化并排序（基于结果的评分卡方法）。
2. 角色推荐（SDR vs AE vs 全周期）明确引用用户的 ACV、周期长度和入口答案，包括 SDR 请求的空日历规则。
3. 每个面试问题都映射到命名的评分卡能力，并且是行为或情境性的；相同的问句集适用于每个候选人（结构化 > 非结构化，同行评审）。
4. 任何地方都没有脑筋急转弯，“向我推销这支笔”，“最大的弱点”，或“你能被指导吗”。
5. 评分工作样本位于循环的第 2 或第 3 阶段，永远不会是最后阶段。
6. 工作样本销售招聘公司的产品，注入一个非脚本异议，并在反馈后重跑一个片段作为行为指导性测试。
7. 工作样本评分标准是行为锚定的（0-3，5-8 类别），并声明为季度冻结；任何对话指标锚定都被标记为供应商数据，相关性。
8. 面试官在复盘前提交独立、引用证据的分数，并且最终组合是机械的，具有预设权重（机械 > 整体，同行评审）。
9. 没有评估关卡或否决任何候选人；循环中的任何评估都按照评估规则标记。
10. 职位发布内容声明真实的底薪 + OTE 范围；循环中任何地方都不出现薪资历史问题；来自 Q7 的区域标记得到解决。
11. 晋升计划包含第 30 天认证关卡，第 60 天指导活动里程碑，第 90 天自我来源管道里程碑，分步定额晋升，以及错过所有三者的行动规则。
12. 所有四个工件中的每个基准数字都带有其证据标签，并且没有供应商声明被作为事实呈现。

## 常见失败模式

未排名，故意：每一行都是一个缺陷，必须有一个强制修复，并且按比率排序缺陷意味着底部的缺陷是可选的。

| 失败                               | 修复                                                                                                                                  |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 招聘全能运动员                     | 对 3-8 个结果进行狭窄、深度能力评分；一个令人印象深刻但不匹配的背景是一个不匹配                                           |
| 铜币操作的第一个招聘              | 对于第一个招聘，侧重于构建特质而不是大公司经验；导入的公式很少在与公司的运动接触后幸存下来                               |
| 模拟电话运行在最后                  | 将其移至第 2-3 阶段；应用工作流步骤 3 中的放置排序                                                                |
| 复盘后评分                         | 在任何人说话之前收集书面的独立分数；复盘用于校准，而不是产生分数                                                        |
| 一个混合的直觉分数                 | 按能力评分，带有证据引用和机械组合；单一平均值隐藏了关键点                                                             |
| 评估作为关卡                      | 应用评估规则；未验证的工具最多只是颜色，并且没有工具可以单独否决                                                         |
| “有竞争力的 OTE”，没有范围         | 发布底薪 + OTE；模糊不清会过滤掉目标候选人，并违反几个司法管辖区的薪酬透明度规则                                     |
| 添加 SDR 以显得成熟                | 应用空日历规则；在 AE 之前添加 SDR 会使其容量饱和，只会增加成本和交接损失                                           |
| 晋升第一天过载                     | 将入职分散到第一周；深度工作从第二周开始                                                                            |
| 希望超过第 90 天                    | 错过所有三个 90 天里程碑会触发决策；晚上的补救尝试很少能击败基本比率                                               |
| 克隆团队或顶级表现者                | 侧重于招聘团队缺少的内容；不同的配置文件会增加覆盖范围，而不是风险                                                   |
| 从希望中设定配额                  | 将配额与晋升参考中的晋升基准进行理智检查；无法实现的一年一数会导致早期令人遗憾的流失                                  |

## KPIs

事后评估招聘 - 以及这项技能的输出 - 使用：

- **晋升达成 vs 分步计划**：按队列，按时达成 25/50/75/100 定额步骤的百分比。
- **生产力达成时间** vs 角色基准（SDR ~3.2 个月 **[调查，2025 年版]**；AE 6.2 个月，记录的最高值 **[调查，2026 年版]** - 同一份调查的较早版本读数为 5.7；使用最新版可用的调查，并将较旧的版本视为趋势背景，而不是基线）。
- **90 天里程碑完成**：认证通过，指导通话改进，自我来源管道 - 按招聘跟踪。
- **流失率，遗憾 vs 非自愿**：SDR 总流失率平均为 39%，近三分之二为非自愿，在收入低于 20M 美元的地区更糟（调查）；非自愿退出集中在早期通常指示循环，遗憾退出指示晋升或经理。
- **循环过程 KPIs**：招聘时间 vs 角色规范（SDR 21-35 天；企业 AE 45-70+ 天，从业者估计），阶段到阶段流失率，录用接受率。

如果你可以浏览网页或查询当前市场数据，在引用它们之前刷新薪酬范围和晋升基准；否则，请标记每个数字的版本年份和层级，并告诉用户本地验证。

本技能中的薪酬和法律内容是信息性的，不是法律建议 - 让法律顾问和人力资源部门审查发布内容、评估使用和任何录用语言，尤其是佣金/OTE 和保证 vs 变动薪酬条款。
