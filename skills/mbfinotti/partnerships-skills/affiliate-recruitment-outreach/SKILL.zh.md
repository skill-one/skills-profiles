# 联盟招募外联

起草联盟计划经理用于积极招募新联盟成员的文案和序列计划。这项技能仅涉及积极外联。

联盟招募没有公认的行业标准框架。唯一具有广泛采用的联盟原生词汇是实践者Geno Prussakov提出的积极/消极招募划分：

- _消极_招募使计划易于被发现。
- _积极_招募联系已识别的潜在目标。

此空间中流传的供应商和课程模型（五轮飞轮、"完美合作伙伴"列表、20-60-20划分）是个别商业计划，而非行业标准。切勿将其呈现为标准。

## 面试

在起草任何内容之前进行询问。每条消息问一个问题；尽可能提供选择题答案。跳过用户已回答的问题。

- 该计划是B2B SaaS还是B2C电商/DTC？（或者两者都有——那么下游所有内容都要进行细分。）
- 什么使产品值得推广——联盟成员受众实际关心的价值主张？
- 已确定的佣金是多少，确切地说：比率/模式、Cookie或归因窗口、支付条款？这项技能传达佣金；它从不设计或调整佣金。
- 该列表针对哪些联盟类别？（内容/评测/比较网站、优惠券/返现/忠诚度、新闻邮件运营商、社区、YouTube/播客、顾问/代理/集成合作伙伴、现有客户、竞争对手当前的联盟成员。）
- 潜在目标列表来自哪里，以及它有多热？（竞争对手反向链接分析、市场目录、活动联系人、现有客户、入站相邻、购买。）
- 潜在目标位于哪里？（美国 / 欧洲 / 英国 / 加拿大 / 混合——这决定了每个细分市场的法律制度。）
- 品牌声音是什么？（正式、同行休闲、俏皮——或者提供一个示例消息。）
- 你实际上可以兑现哪个CTA：申请链接、预批准账户、回复更多信息、或已安排通话？
- 谁签署邮件，以及从哪个地址？
- 必须在什么日期前，招募的联盟成员开始产生？（一个活日期、下个季度、或没有固定日期。）
- 这是一次性胜利——一个发布、一个季节性推广——还是一个您明年仍将运行的复合渠道？
- 努力上限是多少：经理每周小时数，以及什么已经拥有？（现有的联盟名单、已授权的反向链接或发布者发现工具、已保留的代理、现有的客户列表。）

最后三个问题决定下游所有排名—— sourcing类别、发现方法、层级关注分配、节奏、CTA——所以在起草前问这些问题，而不是在选择时问。

- 一个硬性近日期会提升快速层级：竞争对手-联盟成员和SERP sourcing、5次触达节奏、回复更多信息CTA。它会降低互补供应商和代理/集成合作伙伴，这些供应商支付的时间会推迟一个季度。
- 一个复合指令会逆转这种情况：互补供应商、代理和播客合作伙伴会提升，而长层级1的追求变得可行。
- 一个低努力上限会删除需要协调或采购而不是需要协调的层级——说明你删除了哪些层级以及原因。
- 任何已拥有的东西会根据所有这些重新排序：一个已授权的反向链接工具会提升链接相交sourcing，一个已保留的代理会提升12次尝试的节奏，一个现有的休眠合作伙伴名单会击败一个全新的层级1建设。

这项技能及其参考中的每个排名都是一个默认值，而不是法律——它会随着细分市场、列表和执行者而变化。在呈现任何内容之前，根据答案重新排名，并大声说出什么发生了变化。

## 工作流程

1. 运行面试；在触摸列表之前收集所有答案。
2. 评估每个潜在目标：受众匹配优先，然后是流量/权威，然后是现有变现证据。将“已经推广竞争对手”视为一个积极信号，而不是冲突。参见[参考资料/潜在目标sourcing和评估.md](参考资料/潜在目标sourcing和评估.md)。
3. 运行手动品牌安全筛选——商标竞价、优惠券注入/广告软件、垃圾邮件网站——并在任何外联之前删除失败者。
4. 如果你可以浏览网页，请自己验证潜在目标网站；否则，请要求用户提供反向链接/链接相交或发布者发现工具的指标。
5. 根据sourcing参考资料对幸存者进行分层（1/2/3），层级决定个性化深度、节奏长度以及本周花费的小时数顺序——首先对层级1进行耗尽，然后向下。
6. 按管辖区对列表进行细分；应用每个细分市场的外联制度。标记加拿大和德国的潜在目标——没有记录的同意基础，不要向他们发送冷邮件。参见[参考资料/外联合规.md](参考资料/外联合规.md)。
7. 在起草之前，构思推广角度：进入构思模式，并提出2-3个候选角度，包括权衡和推荐，使用经理自己的词汇（潜在目标列表、推广角度、序列、激活）。
8. 一次问一个构思问题；在经理明确选择一个角度之前，不要写任何消息。
9. 根据[参考资料/推广解剖.md](参考资料/推广解剖.md)起草每个层级和细分市场的第一次接触。每条消息都引用关于该潜在目标的一个具体、可验证的事情——不要编造熟悉感。
10. 根据[参考资料/序列和节奏.md](参考资料/序列和节奏.md)起草后续序列，包括旋转角度和分手触达。
11. 运行你首选的人性化技能到每条起草的消息上。永远不要将原始第一稿模型输出作为最终版本——它看起来像是联盟成员会立即删除的通用模板。
12. 对每条消息进行自我检查，对照下面的质量门槛；迭代，直到每条消息在所有项目上都通过。
13. 分部分呈现计划——层级、角度、第一次接触、序列、跟踪——并在最终确定之前与用户验证每个部分。
14. 交出完整工件（下一部分），包括管道跟踪计划。
15. 如果你的harness具有持久内存，记住批准的角度、品牌声音、佣金事实和潜在目标层级——之后的运行将直接跳过面试。

## 需要领先——以及需要保留

领先一个受众匹配理由：为什么这个计划适合他们的受众，用一句话说明。然后是经济因素，说明清楚——联盟成员早期评估经济因素，所以让佣金易于找到，而不是隐藏它。

- B2B SaaS：领先于循环佣金和Cookie/归因窗口；增加一个产品转化的证明点（转化率、评测可信度）。CTA偏向回复更多信息或已安排通话。
- B2C电商/DTC：领先于订单价值、如果已知，每点击收入，以及季节性/促销匹配。CTA偏向申请链接或预批准账户。
- 两者相同：个性化深度、一次一问规则、消息长度、后续纪律以及所有法律约束。只有证明点、CTA和激励框架会分化。

永远保留：

- 功能堆。
- 未挣得财富收益计算（“你可以每月赚X美元”）。
- 长文本。
- 陈词滥调“合作伙伴关系提议”框架。

有记录的实践者指导一致认为，过长的第一次邮件和假设性收益计算会杀死回复。

## 预期输出

交付一个结构化工件：

```
招募外联计划 - <计划>, <日期>
潜在目标层级：层级1/2/3细分、数量、每个层级的评估理由
法律层级：管辖区桶 + 应用于每个桶的制度
选择的角度：批准的推广角度 + 为什么胜过其他选项
第一次接触：主题 + 正文，每个层级/细分一个变体
序列：表格 - 触达 / 天 / 渠道 / 角度 / 消息摘要
分手触达：最终消息 + 什么会在后期重新打开线程
跟踪计划：管道阶段、在哪里跟踪、审查节奏、KPI + 目标
```

## 节奏

联盟招募的两个候选节奏：

- 12次尝试节奏：第一次联系后7天跟进，然后每周一次，在约12次尝试后约3个月内关闭文件，尝试间轮换渠道（电子邮件、社交DM、联系表）。
- 3-5次触达节奏：递增间隔（第0天 / 3天 / 7天 / 14天 / 21-28天）。

两者共享这些核心原则：

- 单次触达被忽略，而不是被拒绝——不回复通常意味着忙碌。
- 跟进简短（1-2句话）。
- 每次跟进增加一个新角度。
- 发送的分手邮件会被尊重。

根据经理的小时数选择，而不是哪个来源听起来更全面：

- 效率（每经理小时的回复率）：`5次触达 / ~4周 > 12次尝试 / ~3个月`
- 价值（最终触达列表的份额）：`12次尝试 > 5次触达`
- 努力程度（最早）：`12次尝试 > 5次触达`
- 合规成本（最早）：`12次尝试 > 5次触达`

对于标准列表默认采用4周内的5次触达——四个价值触达加上强制分手触达，后者在21-28天到达，并使窗口期超过三周。12次尝试节奏的成本大约是发送次数的两倍半加上每次尝试的渠道搜索，这使得它成为一个持续性的工作，而不是一个活动。

它也是这个顺序所剥夺的：价值线顶端、努力线顶端、比率最后，所以它单独永远不会赢得一轮。故意推广它，因为经理既命名又能每周投入小时数的层级1潜在目标。

当潜在目标没有记录的同意基础时，删除这两个节奏而不是缩短任何一个。参见[参考资料/序列和节奏.md](参考资料/序列和节奏.md)。

## 质量门槛

对序列中的每条消息根据所有八个项目进行评分。通过阈值：每条消息8/8。迭代——重起草、重新运行人性化器——直到没有项目失败。

1. 提及关于这个潜在目标的一个具体、可验证的事实（他们的内容、他们推广什么）。不要编造熟悉感。
2. 恰好一个请求，匹配经理确认他们可以兑现的CTA。
3. 第一次接触不超过120字；跟进不超过50字。（工作大写字母，不是联盟特定的已发布标准，但与一般冷触达研究一致——参见[参考资料/推广解剖.md](参考资料/推广解剖.md)。）
4. 佣金事实与面试答案完全一致——从不四舍五入，从不夸大。
5. 没有功能堆、没有假设性收益计算、没有“合作伙伴关系提议”陈词滥调。
6. 发送者身份、需要时物理地址以及可工作的退订满足潜在目标的管辖区；没有加拿大/德国的冷邮件而没有同意基础。
7. 角度在序列中旋转；没有“只是检查一下”触达。
8. 在人性化器通过后，大声读起来像人类。

## KPI

- 外联侧：每个层级和每个角度的回复率和申请率。预期冷电子邮件规范回复率（大致3-9%，来自一般冷触达研究——不是联盟特定数据）。
- 计划侧，真正重要的KPI：成为销售活跃的招募联盟成员的份额——“活动指数”（实践者基准：成熟计划中约20%的联盟成员每周至少产生一次点击；自我报告，不是独立衡量）。
- 申请和批准只是虚荣指标——一个从不推广的招募者浪费了你的外联和回报。
- 在CRM或电子表格中跟踪外联管道（已联系 → 回复 → 申请 → 活跃）；计划仪表板显示批准和支付，而不是外联。在活动中每周进行一次审查。

## 常见失败模式

| 失败                                                                 | 修复                                                                 |
| ------------------------------------------------------------------------------------ | ------------------------------------------------------------------- |
| 从一个通用模板进行大规模轰炸                                                 | 分层列表；按潜在目标个性化；小批量                                  |
| 单独以佣金%领先，没有受众匹配                                             | 有一句匹配的话；经济因素说明清楚后                               |
| 编造熟悉感（“长期以来一直欣赏你的工作”）                                | 引用一个可验证的具体细节，或诚实地说明为什么找到他们                |
| 招募吞噬合作伙伴类型（优惠券注入、广告软件、商标竞价者）                     | 在外联前进行品牌安全筛选，而不是加入后                             |
| 慢速申请审查使提议变得令人沮丧                                             | 在启动外联之前承诺24-48小时审查                               |
| 提议后出现的条款与电子邮件相矛盾                                             | 在面试问题3上设置门槛；电子邮件仅说明已确认的条款                 |
| 在第一次邮件后没有跟进                                                   | 交付序列，包括第一次接触，而不是单独的第一次接触                     |
| 承诺宽松披露以关闭潜在目标                                                 | 永远不要——联盟推广需要披露的材料联系                             |

## 调用示例

- "为40位我们希望在B2B SaaS计划中想要比较网站编辑起草第一次接触邮件和后续序列——12个月25%循环，已决定。"
- "我们的联盟招募邮件没有回复。这是我们最后发送的三个——重写它们并修复节奏。"
- "我们有一个200个潜在目标的列表，混合了英国个体经营者、美国博主和德国媒体网站。分层列表，并告诉我我们可以冷邮件哪些人。"
