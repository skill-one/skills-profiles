# 影响者活动简报

品牌向已签约创作者提供的创意简报草稿，用于特定活动：交付成果、关键信息、限制条件、披露、时间表、审核轮次。

创作者简报没有命名、跨供应商采用的框架。公开指南是一系列单一供应商的公式，没有在自身发布者之外被采用：

- 某发布者的九部分列表
- 另一个发布者的五问框架
- 第三个发布者的做与不做区块

四个无关发布者中唯一得到证实的结构化理念是将不可协商项与偏好项分开，因此这项技能围绕此理念构建。来源标签如下标明声明来源：

- **证实**：三个或更多独立发布者
- **单一供应商**：一家公司的发布公式
- **调查**：一家供应商运行的、方法公开的调查
- **推断**：合理的默认值，而非发布公式

此处切勿将任何公式呈现为行业标准。

## 面谈

在起草前进行面谈。每条消息一个问题；尽可能提供多项选择题；跳过用户已回答的内容。

- B2B创作者计划还是B2C品牌合作？（这决定了交付成果类型、审批链和证明风格。）
- 用一句话描述活动目标及指标？（认知度 / 考虑 / 转化 - 这也设定了自由度。）
- 签约创作者是谁，在哪个平台或渠道类型？（短视频、专业网络、通讯录、播客……）
- 签约协议已承诺哪些交付成果？（这是事实来源；简报可能指定它们，但绝不能更改它们。）
- 关键信息是什么 - 最多三个 - 及每个背后的证明？（没有品牌可以支持的证明，任何声明都不会发布。）
- 哪些品牌限制条件和禁止话题适用？
- 在简报发出前，哪些声明需要法律或监管批准？
- 必须在什么日期前完成成果，这是固定的活动时刻（发布、活动、季节性日期）吗？（接近日期会促进高自由度 - 框架简报通过日历可能没有的审核轮次强制执行。）
- 一次性活动，还是您打算与该创作者重复关系的第一次？（重复意图会促进高自由度；授予自由并在验证时撤销会失去创作者。）
- 您的努力上限是什么：签约协议包含的审核轮次、可用的简报时间，以及是否有内部审核员？（一轮或无审核员会完全排除低自由度选项。）
- 内容将作为付费媒体运行吗？（这决定了音频许可，以及在B2B中，思想领袖广告机制 - 必须现在解决，不能以后。）
- 创作者将使用哪些跟踪机制：促销代码、跟踪链接、专用落地页？
- 谁审核草稿，谁最终批准？

## 工作流程

1.  运行面谈；在写一个字之前收集所有答案。
2.  将交付成果与签约协议核对。任何矛盾之处：停止，向用户标记，并永不悄悄重写 - 协议获胜。重新谈判属于谈判技能。
3.  进入信息角度的头脑风暴模式（下一节）。在用户选择角度之前，不写任何简报。
4.  根据以下排名默认设定创意自由度级别（单供应商映射：高用于认知度，中用于考虑，低用于转化）。这三个级别不是由口味选择的等成本替代方案 - 根据每单位简报努力返回的活动结果排名它们：

   - 效率（每简报小时的结果）：高 > 中 > 低
   - 价值（购买的结果）：在认知度和考虑中，高 > 中 > 低；在转化中，低 > 中 > 高，其中优惠、代码和CTA只有在简报锁定它们时才会出现
   - 努力程度（简报小时数、审批轮次、协调）：低 > 中 > 高 - 低成本约一周的协调加上它花费的执行框架的轮次，高成本约一小时和一个轮次
   - 合规成本（简报发出前必须获得的批准）：低 > 中 == 高 - 中等和高将相同的声明集发送给法律部门，只有低添加必须批准的脚本框架措辞

   - 默认为 **高**，并说明。
   - 在首次合作或创作者对该类别不熟悉时降级为 **中**。
   - 只有当活动指标是兑换或注册数量，且优惠机制必须逐字呈现时，才降级为 **低**。

   当签约协议包含一轮或更少的修订时，直接从菜单中删除低，并说明原因：框架简报通过在此不存在的轮次强制执行。永不将其放在列表底部 - 被排除的级别会重新出现在验证时的范围内。

   这种排序会剥夺：低自由度具有高价值和高努力，因此它在每一轮中都会失败，效率优先的习惯会低估那些为推动数字付费的转化活动。在指标是兑换数量，或受监管类别强制脚本批准时，仍然要提升它。

   排名是默认值，不是法律 - 它会随着目标和执行者而变化。根据您对当前用户的了解重新排名：

   - 受监管类别强制脚本批准会提升低，无论目标是什么
   - 与该品牌合作过的创作者会提升一级高，因为限制条件已经被内化
   - 没有内部审核员会提升高，因为没有人可以运行低级别消耗的轮次

   自由度也是创作者报告最稀缺的维度（调查 - 2025年10月对自己创作者数据库的一项供应商运行的调查，n=403位创作者，±4.9%的95%置信度）：10%报告了真正的创意控制，53%希望更多。仅以该方法论引用这些数据，永不归因于具体个人。轮次机制、锁定/开放式列表和排名限制菜单：[references/freedom-and-guardrails.md](references/freedom-and-guardrails.md)。

## 调用和预期输出

典型调用：

- “为刚刚签约的创作者编写活动简报 - 短视频，3月12日发布，协议包含两轮修订。”
- “将这份已签约协议备忘录转换为创作者简报：一份通讯录深度解析加上一份专业网络帖子，转化目标，代码JULES15。”

交付一份简报文档（完整模板在[references/brief-template.md](references/brief-template.md)）：

```
创作者活动简报 - <品牌> x <创作者>, <活动名称>
活动目标   : 一句话 + 指标
为什么是你   : 为什么选择这位创作者；活动依赖其哪些优势
关键信息    : 选定的角度；最多3条信息，每条都有其证明点
不可协商项 : 锁定的事实 - 优惠详情、强制措辞、禁止声明
偏好项     : 自由度级别（高/中/低）+ 创作者可以决定的内容
交付成果    : 每项 - 格式 / 数量 / 时长 / 规格 / 链接机制 / 草稿截止日期 / 发布窗口
披露      : 必须措辞 + 位置 + 平台工具 + 发布后验证者
时间表        : 日期里程碑 - 问题、概念、草稿、修订、发布日期
审核          : 谁审核，包含的轮次（=已签约协议的轮次），反馈渠道
跟踪        : 代码 / 跟踪链接 / 落地页 - 发布前经过测试
权利与付费   : 声明付费媒体意图；引用已签约协议中的使用条款，永不重述
```

## B2B和B2C

- 对两者都一样（发布指南从未按商业模式对这些进行细分 - 一个弱普遍性信号，本身是推断）：
  - 简报结构
  - 不可协商项/偏好项划分
  - 交付成果精确度
  - 披露义务
  - 有边界的修订
  - 不脚本原则
- 诚实限制：大多数发布指南都是B2C形状的，尽管现在有一个B2B特定来源（ContentGrip的简报手册，Ariana Sorensen）：对于受监管类别（金融科技、医疗保健、网络安全、企业软件），添加要求审核员姓名或团队、证据要求、禁止词汇、强制免责声明和审批SLA，审核分段 - 法律审核声明和免责声明，产品审核准确性，品牌审核契合度。这证实并强化了下面的审批链声明。
- 唯一来源的B2B特定机械约束（单供应商）：在思想领袖广告格式中，广告创意就是创作者自己的帖子，修改必须来自原始作者。在自然帖子发布之前解决付费准备情况 - 否则无法推广帖子。
- 来源（ContentGrip，受监管的B2B类别）：审批链添加按功能（法律、产品、品牌）命名的审核员加上审批SLA，延长了审核窗口 - 按每个审核员检查的内容分段，而不是作为一次通用的堆栈。
- 交付成果组合有效性（调查 - Content Marketing Institute / MarketingProfs 2025 B2B基准研究，980位B2B受访者中的1,186位，于2024年中进行）：B2B营销人员将网络研讨会（51%）和电子邮件通讯（37%）评为他们最有效的分发渠道，而播客的使用报告逐年下降。这是一个渠道效果信号，不是定价基准 - 该研究什么都没定价。
- 交付成果组合定价和可衡量性（单供应商账户 - Ahrefs的Igor Gorbenko，在超过100万美元的创作者赞助支出上）：LinkedIn和YouTube跟踪清晰；通讯录性能取决于合作伙伴提供的数据，可见性有限；播客赞助最难将品牌认知度归因于受众不认识的名字，五个播客活动最初的1.4万美元产生了该账户称为“糟糕”的结果。同一个账户将赞助帖子定价分为三个档次：500-2,000为基准，3,000-9,000为不划算的中间档次，10,000以上为具有记录和固定可跟踪受众的创作者 - 其自己的例子是YouTube和通讯录。
- 标记为推断，而非记录实践：B2B交付成果偏向通讯录时段、播客阅读量、网络研讨会和长篇帖子。
- 在三个独立的B2B创作者营销发布者（Directive Consulting的Casie Akins、Walker Sands的Payal Pathak、ContentGrip的SaaS创作者覆盖）中证实：亲身、手动的运营经验是B2B受众真正信任的信誉层 - 真实的执行，而不是个性或覆盖范围 - 而业务结果指标（管道影响、演示请求、交易速度）是分开的层，用于衡量和证明活动之后的项目。将两者视为同一内容内互补的证明层，而不是严格的B2B与B2C交换一种证明类型为另一种证明类型。
- B2C：短视频、故事格式和内容提要位置有详细记录，以及受监管类别的限制条件（健康、美容、食品） - 见[references/freedom-and-guardrails.md](references/freedom-and-guardrails.md)。

## 质量门

将起草的简报与所有十个项目进行评分。通过标准：10/10。迭代 - 重新起草并重新验证 - 直至没有任何项目失败。

1.  协议一致性测试：每个交付成果、审核轮次数量和权利提及时都精确匹配已签约协议；任何矛盾之处都标记给了用户，绝不能悄悄重写。
2.  互换性测试（单供应商测试，此处作为门，采用）：如果任何创作者都能根据这份简报制作内容，这份简报就破坏了品牌为获取受众信任而支付的东西。它必须对所有人失败，除了这位创作者。
3.  每个项目都是明确的不可协商项或偏好项；没有介于两者之间未标记的项目。
4.  没有锁定的声音：没有脚本句子，除了强制法律措辞，没有摄像机指令，没有音乐或剪辑选择，没有规定的标题措辞。
5.  每个交付成果都带有数量、时长或长度、宽高比（视觉格式）、链接或代码机制、草稿截止日期和发布窗口。
6.  披露有自己的部分 - 措辞、位置、平台工具、验证者 - 永远不是脚注。
7.  如果有可能进行放大，则声明付费媒体意图；在B2B思想领袖格式中，付费准备情况在发布前解决。
8.  声明自由度级别，从高默认值开始，任何降级都说明原因。
9.  关键信息不超过三个，每个都有品牌可以支持的证明点；列出禁止声明。
10. 简报不超过一页或两页，只包含适用于此内容类型的5-10条品牌规则，而不是整个风格指南。

## KPI和衡量

- 没有可信赖的简报质量或修订次数基准。
  - 最大的年度行业基准研究（315位营销人员，100位专家）不衡量任何东西。
  - 流传的“37%的创作者”数据无法验证来源 - 永不引用它。
  - 在别处找到的任何修订次数数字都是供应商断言。
- 简报声明活动目标和创作者必须使用的跟踪机制。设计KPI和归因是衡量技能的工作 - 将其路由到那里。
- 与自己的活动日志进行基准比较。每个活动跟踪：
  - 使用的修订次数与包含的轮次
  - 按时草稿率
  - 第一次提交的规格合规率
  - 发布时的披露合规性
  - 创作者是否重新签约
  - 活动指标与其目标
- 如果您的框架具有持久内存，请跨会话保留该日志；否则，将表格交给用户维护。

## 常见失败模式

| 失败                                                         | 解决方案                                                                                                              |
| --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 完整逐字脚本创作                                               | 固定事实，自由表达；内容在“技术上正确”但与创作者正常风格不符，无法吸引人                                           |
| 公开披露缺失或脚注                                              | 设立专门章节 - 措辞、位置、平台工具、验证者；广告商负责，而不仅仅是创作者                                          |
| 无限制的修改轮次                                               | 在简报中说明次数；它等于交易包含的内容 - 简报不会凭空创造数字                                                     |
| 交付规格与已签署的交易矛盾                                     | 停止并标记；交易优先；重新谈判归谈判技巧所有                                                                  |
| 附上整个品牌风格指南                                           | 提取与该内容类型相关的5-10条规则；其余都是噪音                                                                   |
| 模糊的交付内容（“3个短视频”）                                 | 指定数量、时长、宽高比、链接机制、每项规格的截止日期                                                             |
| 创建后宣布付费推广                                             | 平台热门音频未授权用于付费媒体 - 迟宣布迫使重新编辑；在简报中宣布                                                    |
| 在简报中给予自由但在验证时微观管理                               | 仅根据不可协商项评判草稿；偏好是创作者的决定，应保持原样                                                         |
| 内容发布前没有实时跟踪                                           | 在发布窗口开启前测试代码、链接或着陆页；未跟踪的内容将永远无法归因                                                  |
