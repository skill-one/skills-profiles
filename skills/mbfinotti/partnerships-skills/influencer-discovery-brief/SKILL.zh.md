# 影响者发掘简报

定义资源标准，并制作合作伙伴经理用于筛选候选创作者的发掘简报——谁符合资格，按什么加权标准，以及提供什么证据。

"3R"（触达、相关性、共鸣）是评判影响力的一个真实反复出现的行业惯例，但研究无法追溯到其经典的起源者——将其视为一个流动的助记符，而不是一个可引用的方法。"4R"变体增加"参考"是某个影响者分析供应商的框架，而不是行业标准。因此，这项技能基于经理批准的明确加权标准工作，而不是基于一个被呈现为权威的命名模型。

## 面谈

在获取任何信息之前进行面谈。每条消息问一个问题；在可能的情况下提供多项选择题答案。跳过用户已经回答过的任何问题。

- 这是一个B2C品牌活动还是B2B创作者/思想领袖计划？（或者两者都有——那么针对每个轨道分别权衡标准。）
- 品牌或产品是什么，以及创作者的受众真正关心的价值主张是什么？
- 营销目标是什么：提高知名度、转化、内容付费或建立信任？目标会改变标准的权重，所以在评分之前回答。
- 目标客户是谁——人口统计、角色、购买背景？（不是目标创作者；创作者是一个渠道，通往这个人。）
- 营销活动在哪些平台运行？
- 哪些地理区域/市场实际上能转化这个产品？（其他任何地方的受众都是你付费获取的触达，不能使用。）
- 预算层级是什么，以及报酬是现金、产品还是混合？
- 实际上会从筛选名单中签约多少位创作者？
- 品牌安全红线是什么，产品是否属于受监管类别（酒精、健康、金融、赌博、儿童）？
- 有任何竞争对手或类别排他性冲突需要执行吗？谁已经在名单上？（这对于受众重叠检查是必要的。）
- 你能实际获得哪些受众数据：创作者发现平台导出、受众洞察导出、媒体资料或仅公开资料？（一个许可的发现平台将其导出权限从最慢的获取选项变为最快的。仅公开资料删除了菜单中的两阶段加权门。）
- 必须在什么日期之前提交筛选名单，以及等待什么？（一周内的日期会促进名单获取、客户提及通过和地板门加权。一个季度使得社交聆听和完全目标导向的评分变得可行。）
- 一次性活动还是你会再次运行的创作者计划？（一次性活动在筛选名单上停止。重复计划证明完全目标导向的评分通过，其批准的权重是唯一可以调整的营销后拟合率KPI的输出。）
- 努力上限是什么——你自己的时间、你可以请求的数据，以及你是否可以承诺一个持续的监控工作？（个人上限删除了社交聆听。没有平台许可证的预算所有者删除了发现平台导出。）

将最后三个答案带到以下所有排名中。它们是唯一可以重新排序此经理默认设置的输入。

此技能中的每个排序都是默认值，而不是法律。它按每单位努力返回的合格候选人进行排名，这永远不会是按最低成本排序的顺序，并且会随着上下文和运行通过的人而变化。

在推荐任何东西之前，根据你对这位经理的已有了解重新排名。说明哪个答案移动了哪个通过，以便重新排序是可审计的，而不是你断言的偏好。

- 一个已经许可的发现平台将其导出通过移到前面。
- 一个具有绩效历史的现有创作者名单使名单获取成为最强的通过，而不仅仅是最低成本的。
- 一个太小以至于平台数据库无法覆盖的利基删除了导出通过，并促进了客户提及和社交聆听。

## 工作流程

1. 运行面谈；在查看任何候选人之前收集所有答案。
2. 将目标翻译成草稿加权标准集——提高知名度、转化、内容付费和建立信任每个权重都不同。参见[参考资料/获取标准与加权.md](references/sourcing-criteria-and-weighting.md)。
3. 进入头脑风暴模式：按排名顺序呈现加权方法，以推荐开始，并使用经理自己的语言给出每个方法的权衡（标准、地板、淘汰、筛选名单）。完整的权衡在[参考资料/获取标准与加权.md](references/sourcing-criteria-and-weighting.md)。

   - 效率：两阶段受众匹配门 > 目标导向固定权重 > 地板门加相等权重，只要每个候选人可以获得一个受众匹配数字；地板门领先，其他两个在只有公开资料的情况下无法负担得起。

   默认使用两阶段门。当数据答案是仅公开资料，或者日期答案在不到一周内时，降至地板门。当答案是重复计划时，至少支付一次完全目标导向评分通过——这是唯一能产生可调整权重的途径。

4. 一次问一个头脑风暴问题；在经理明确选择加权方法之前，不要评分任何东西。
5. 通过获取通过构建原始候选人库。存在六个获取通过；将它们视为预算，而不是清单。按此顺序运行它们，并在库足够深以承受淘汰时停止。

   - **现有名单和CRM** - 一小时，无工具访问。唯一返回与你的品牌相关的绩效历史的通过：谁已经发布，做了什么，谁会再次签约。它不会返回任何净新名字，并且步骤9的重叠检查需要它。

   - **客户和社区提及** - 一天提取支持、社区线程、评论文本，以及一个“你关注哪些创作者”的问题到一个已经发出的调查中。名字附带匹配证据到达，因为你的买家明显在关注他们，并且这是唯一能接触到播客、通讯录和平台未索引的封闭社区的通过。

   - **发现平台导出** - 拥有许可证时接近于零：一个过滤查询返回广度，并且步骤8的受众人口统计评分。没有许可证，一个季度和采购对话。仅覆盖供应商索引的内容——在狭窄的B2B利基和非社交格式中很薄。

   - **竞争对手合作** - 一小时浏览竞争对手的标记和披露帖子。预先合格：他们接受赞助，他们属于类别，并且在联系你之前可以查看他们的赞助与有机参与。每个竞争对手都使用相同的列表，并且排他性淘汰删除了其中一部分。

   - **利基关键词和标签搜索** - 一小时仍然是小时，无工具访问。它主要手工重新导出导出返回的内容，合格率每小时很低；只有在没有平台覆盖利基时才值得它的位置。

   - **社交聆听** - 一周设计查询和一个持续工作来维护。它揭示了创作者已经在未经提示的情况下谈论类别，是任何通过中最强的独特名称产出，但它是一个监控系统，其发现输出是副产品。

   - 努力程度：社交聆听 > 没有许可证的发现平台导出 > 客户和社区提及 > 竞争对手合作 == 标签搜索（平局：都是一小时的手动浏览，无工具访问，无其他人许可） > 名单和CRM == 拥有许可证的发现平台导出（平局：都是一小时查询你已持有的数据）

   - 合规成本：客户和社区提及（在将支持、社区或调查数据重新用于你从中构建营销活动的列表之前进行隐私审查） > 由爬虫运行的标签搜索（一个违反平台条款的行为，会导致帐户被封禁——手动阅读几乎为零） > 发现平台导出（供应商许可证管理你可以重新导出和保留的内容） > 名单和CRM（过去的合同可能包含排他性或重新接触条款） == 竞争对手合作 == 社交聆听（无曝光）

   - 价值，作为其他通过会遗漏的合格创作者：客户和社区提及 > 社交聆听 > 发现平台导出 > 竞争对手合作 > 名单和CRM > 标签搜索

   - 效率：名单和CRM > 客户和社区提及 > 发现平台导出 > 竞争对手合作 > 社交聆听 > 标签搜索

   **始终运行：**

   - 名单获取和客户提及通过一起——它们花费一天，并返回其他任何东西都不做的两种名字。

   **按此顺序添加下一个：**

   - 发现平台导出第三；当许可证已经存在时将其移到第一——相同的查询然后花费一小时，并且还提供评分数据。

   - 竞争对手合作，当池仍然很薄三个通过之后。

   - 社交聆听，当答案说是一个重复计划，并且有人将拥有持续工作时。

   **删除而不是降级：**

   - 标签搜索的爬虫变体：它破坏平台条款，并且被封禁的帐户会带着手动通过一起下。

   - 完全删除导出通过，当利基没有平台覆盖且没有许可证存在时。

   社交聆听是这个顺序被剥夺的——在价值上第二，在努力程度上第一，所以它在每次效率轮中都失去，并且遵循比率单独的经理永远不会构建一个揭示其他人都找不到的创作者的通过。

6. 如果你能够浏览网页，请亲自验证每个候选人的公开资料；否则请要求经理粘贴发现平台或受众洞察导出。永远不要基于记忆或假设评分。
7. 在任何评分之前，对照淘汰清单筛选每个候选人；淘汰失败直接进入拒绝名单及其原因。参见[参考资料/品牌安全筛选.md](references/brand-safety-screening.md)。
8. 按标准用批准的权重评分幸存者，并附上一个证据来源。信号在[参考资料/受众匹配和参与信号.md](references/audience-fit-and-engagement-signals.md)；层级和利基映射在[参考资料/创作者层级和利基映射.md](references/creator-tiers-and-niche-mapping.md)。
9. 按加权总分排名；检查筛选名单中的受众重叠，并与现有名单对比；降级重复受众的候选人。
10. 将简报与以下质量门对照检查；迭代直到每个项目都通过。
11. 分部分呈现简报——标题、标准、淘汰、筛选名单、拒绝名单——在最终确定之前验证每个项目与经理。
12. 如果你的套件具有持久内存，记住批准的标准权重、红线和目标受众定义——以后的运行将直接跳过面谈。

在排名的筛选名单处停止。接触消息和交给选定创作者的创意简报属于兄弟技能，而不是这个技能。

## B2C与B2B——标准差异之处

- B2C：权衡受众人口统计、地理和美学/内容匹配；粉丝层级具有真实意义（纳米/微型用于参与和转化，宏观/巨型用于触达）。
- B2B：权衡创作者的工作头衔和雇主信誉，评论中的人是谁（评论者是否匹配ICP？），演讲和出版物历史，以及通讯录订阅者质量。将原始粉丝数量视为几乎无价值。上述指导是实践者的推理：当B2B经理问权重来自哪里时，在简报中说明这一免责声明。
- 两者相同：受众匹配优于创作者匹配，地理验证，品牌安全筛选，受众重叠检查，以及同意权重之前查看候选人。

## 预期输出

交付一个结构化工件（参考资料/示例.md中的完整工作示例）：

```
发掘简报 - <品牌>, <日期>
标题    : 品牌，目标，目标客户，转化市场，平台
标准  : 表格 - 标准 / 权重 / 如何衡量 / 地板
淘汰  : 筛选清单在评分前应用，带有红线
筛选名单 : 表格 - 候选人 / 每个标准得分 / 加权总分 / 排名
            / 每个得分证据链接
拒绝  : 候选人 + 一行原因（淘汰失败或地板错过）
```

每个得分都引用其证据；每个拒绝都说明其原因。一个经理不能逐行审计的简报是没有完成的。

## 质量门

将完成的简报与以下每个项目对照检查，并验证每个筛选名单候选人。通过阈值：7/7。迭代——重新评分、重新获取、重新筛选——直到没有任何失败。

这些阈值是可审计筛选名单的工作惯例，而不是测量的行业标准。

1. 权重在评分第一个候选人之前由经理明确批准。
2. 每个淘汰标准在评分开始之前应用于每个候选人。
3. 每个评分单元格都带有引用的证据来源（资料链接、导出或粘贴的数据）——没有记忆评分的单元格。
4. 没有候选人仅基于粉丝数量评分；每个筛选名单候选人都具有受众匹配和参与证据。
5. 验证每个筛选名单候选人的受众地理与转化市场。
6. 检查筛选名单中的受众重叠，并与现有名单对比。
7. 每个拒绝候选人都有一个声明的、具体的原因。

## KPI——筛选名单质量，不是活动表现

衡量发现过程本身。活动KPI属于测量技能。

没有可靠的已发布的行业基准存在这些比率。不要编造目标：建立你自己的基线并跟踪趋势。

- 筛选到筛选名单比率：每筛选名单候选人数筛选的候选人。随着时间的推移下降意味着获取通过正变得更有针对性。
- 筛选名单到签约比率：经理实际签约的筛选名单候选人。持续低意味着标准与经理真正想要的不匹配——重新审视权重。
- 标准权重稳定性：批准权重在发现周期之间变化多少。权重稳定意味着标准正在成熟；权重波动意味着目标不明确。
- 营销后拟合率：后来被判断为合适的一部分筛选名单签约创作者。将其反馈到权重中。

- 努力程度：营销后拟合率（一个季度等待加上每个签约创作者收集的判断） > 筛选到筛选名单 == 筛选名单到签约 == 标准权重稳定性（近零——所有三个都是简报已经产生的计数）
- 价值：营销后拟合率（唯一一个说标准本身是否正确的） > 筛选名单到签约 > 筛选到筛选名单 == 标准权重稳定性（平局，因为它们都不判断筛选名单，只判断产生它的通过，并且它们直到第二个周期存在之前都不读取）
- 效率：筛选名单到签约 > 筛选到筛选名单 == 标准权重稳定性 > 营销后拟合率

从第一个周期开始跟踪这三个免费比率。无论如何从第一个周期开始收集拟合率——它的滞后正是为什么它永远不会开始，并且它是唯一可以纠正错误标准集的信号。

## 常见失败模式

| 失败情况                                                    | 解决方法                                                                                                      |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 追随者数量崇拜                                               | 优先考虑受众匹配度和互动性；根据批准标准限制或取消每条推广内容的触达权重                                |
| 与创作者形象匹配而非其受众                                     | 评估关注者和评论者，而非发布者；对目标客户群体抽样评论区                                             |
| 受众地域不匹配                                               | 核实每个候选人的地域细分；转化市场外的受众是不可用的触达                                             |
| 互动率操纵和部落化                                             | 应用浅层红色警示检查；将无法验证的候选者标记为“真实性未核实”                                        |
| 垂类稀释（不相关的内容类别）                                 | 对近期发布内容进行分类；执行垂类分享下限                                                         |
| 过度依赖美观度/制作质量                                         | 将美观度匹配度作为次要加权标准（仅限B2C），永远不能作为受众匹配度的代理指标                           |
| 忽略候选名单中的受众重叠                                     | 在排名前运行重叠检查；降级重复受众 - 永远不要为同一批眼球付费两次                                     |
| 推广后进行品牌安全筛选                                         | 在评分前运行淘汰检查，评分前进行任何接触                                                         |
| 在权重未确定前进行评分                                       | 头脑风暴关卡会阻止评分，直到经理明确选择权重方法                                                   |
| 将一个平台的互动公式应用于另一个平台                           | 使用每个平台自己的公式；永远不要直接比较跨平台比率                                               |

## 调用示例

- "为B2C护肤品发布构建发现简报 - 我们需要8位微型创作者，预算40K，转化目标。"
- "我们需要B2B思想领袖参与开发者工具推广活动。定义筛选标准和淘汰检查。"
- "根据我们的品牌安全和互动质量标准对这14位候选创作者进行评分，每项评分需提供证据。"
