# 影响者合作

起草合作经理用于向单个经过筛选的影响者或创作者提出合作建议的第一接触推销和后续计划，并在收到第一个积极回复后停止。

没有命名行业标准的框架用于创作者推销。已发布的指导是一系列针对单一渠道的公式，没有品牌或跨供应商采用：

- 某个供应商的软性号召行动与具体请求的拆分
- 某个商业指南的四问题首次信息清单
- 某个顾问未命名的六步流程

永远不要将它们呈现为标准。

## 面谈

在起草任何内容之前进行询问。每条消息一个问题；在可能的情况下提供多项选择答案。跳过用户已经回答过的任何问题。

- 这是一个面向消费者的品牌合作还是面向企业的创作者项目？（产品销售给消费者还是企业——这决定了信息框架和交付类型。）
- 品牌生产什么，以及为什么这条创作者的受众会关心？（产品是什么，以及为什么这条创作者的受众会关心。）
- 创作者是谁，在哪些平台，以及哪些证据表明他们符合？（具体帖子、受众数据、发现简报——符合证据是必需的输入，而不是在这里编造的。）
- 提供什么样的补偿模式，以及具体数字是多少？（固定费用 $X / 佣金 % + 归因窗口 + 付款计划 / 仅赠送产品 / 混合模式。）这项技能传达了报价；它从不设计或调整报价。
- 你心目中的活动形式是什么——大致交付内容和时间？（在第一条消息中保持为一行草图。）
- 创作者实际列出的联系方式是什么：商务电子邮件、仅限私信，还是经理/代理人？
- 品牌声音是什么？（正式、同侪休闲、俏皮——或者指向一个示例消息。）
- 谁签署，从哪个地址或账户？
- 你实际上可以履行哪个号召行动：回复获取详细信息、回复时提供产品样品、简短通话，或申请链接？（你本周无法履行的任何内容都应从菜单中删除，而不是排名靠后。）
- 回复必须在何时到达——这个推销必须赶上的是否有发布或活动日期？（硬性日期促进了近乎零努力的角度、回复获取详细信息的号召行动和单一后续节奏；没有日期则让一个小时的立足和更长的节奏发挥作用。）
- 一次性胜利，还是你打算复合的关系？（复合促进了经理路线和长尾节奏；一次性胜利促进了创作者自己列出的联系方式，并在三条消息后停止。）
- 你每条推销的努力上限是多少——用于立足、可以发送的产品、你可以提供的日历？（一个小时的立足购买了内容特定角度；没有产品会删除样品号召行动；没有日历会删除通话号召行动。）

这项技能给出的每个排序都是默认值，而不是法律：它会随着上下文和执行者的不同而变化。在提出任何内容之前，根据你对这个用户的了解重新排序，然后说明哪个答案移动了哪个选项：

- 与此创作者或其经理的现有关系
- 创作者已经认识的品牌
- 已经掌握的受众数据
- 完全没有赠送产品

## 工作流程

1. 运行面谈；在写一个字之前收集所有答案。
2. 立足个性化：如果你可以浏览网页，加载创作者最近两三个帖子并亲自确认符合证据；否则请用户提供推销将引用的具体帖子、系列或受众特征。永远不要编造熟悉感。
3. 根据[参考资料/渠道和经理.md](references/channel-and-manager.md)确认收件人。创作者发布的商务联系方式决定结果；如果发布多个，默认顺序是`列出的经理 > 列出的商务电子邮件 > 私信`。绕过列出的经理是一种失败模式，而不是捷径。
4. 进入个性化角度的头脑风暴模式：提出 2-3 个候选角度，包括权衡和推荐，用经理自己的词汇（角度、钩子、符合、交付内容、号召行动）表达。从[参考资料/推销解剖.md](references/pitch-anatomy.md)中的排序角度菜单中提取——默认顺序`已经推荐的 > 最近发布 > 具体内容 > 他们的产品我们使用 > 格式符合 > 声明的重叠`——并删除任何不适用于此创作者的角度，而不是将其排名靠后。
5. 一次只问一个头脑风暴问题。在经理明确选择一个角度之前，不要写任何消息。
6. 根据[参考资料/推销解剖.md](references/pitch-anatomy.md)起草第一次接触，并根据确认的收件人进行调整。从该文件中的排序菜单中选择一个号召行动——默认顺序`回复获取详细信息 > 回复时提供样品 > 简短通话 > 申请链接`——并删除品牌无法履行的任何内容。补偿透明度遵循以下模式：
   - 佣金报价优先列出确切的机制
   - 固定费用报价命名模式，但不提供费率卡
7. 根据[参考资料/后续节奏.md](references/follow-up-cadence.md)起草后续计划：默认顺序`两次后续 > 一次后续 > 长尾`，然后关闭文件。
8. 运行你首选的人性化技能，对推销和每个后续内容进行人性化处理。永远不要将原始第一草稿模型输出作为最终版本——AI 告白措辞正是导致推销被立即删除的大众模板气味。
9. 根据下方的质量门槛进行自我检查；重新起草并重新运行人性化处理，直到每个项目都通过。
10. 分部分展示推销包——角度、第一次接触、后续计划、停止规则——并在最终确定之前与用户验证每个部分。
11. 交出完整工件（下一节）。在收到积极回复时，这项技能的工作就完成了：将声明的补偿事实不变地带入谈判。
12. 如果你的框架具有持久记忆，请记住批准的角度、品牌声音、补偿事实和结果——之后为同一品牌提出的推销将直接跳过大部分面谈。

## 调用和预期输出

典型的调用：

- "为我们的陶瓷花盆发布向 @plantsbypriya 推销——她已被筛选，Instagram 上有 48k 粉丝，报价是赠送产品和 15% 佣金。"
- "为我们的短名单上的 DevOps 订阅者作家撰写第一次接触电子邮件——2,000 美元的赞助深度探索，她列出了一个合作伙伴关系电子邮件。"

交付一个结构化的工件：

```
INFLUENCER PITCH PACKAGE - <创作者>, <日期>
选择的角度   : 批准的个性化角度 + 为什么优于其他选项
第一次接触    : 主题（仅限电子邮件）+ 消息正文，根据确认的渠道进行调整
后续计划     : 表格 - 接触 / 天 / 渠道 / 角度 / 一行总结
停止规则      : 积极回复 -> 停止并交出；最终接触后沉默 -> 关闭文件
交出笔记      : 补偿事实如声明，提及的交付内容，承诺的号召行动——用于谈判阶段
```

## B2B 和 B2C

- **B2B**
  - 与创作者受众拥有的商业需求交谈，而不仅仅是产品利益——这是始终如一记录的 B2B 特定规则。
  - 交付内容偏向于网络研讨会、白皮书、文章和播客阅读。
  - 赠送是记录的 B2B 实践，但与 B2C 不同地塑造：延长平台访问权限、会议通行证、测试邀请或活动主持，而不是实体产品。Zapier 的创作者合作伙伴度假村是一个真实命名的例子，2025 年的行业报告将线下赠送活动列为社交帖子之后第二有效的 B2B 创作者内容类型。如果这些形式都不适用，则默认为费用或佣金。
  - 预期更长的、多利益相关者的购买周期将塑造推销中“转化”的含义。
- **B2C**
  - 交付内容偏向于帖子、视频和故事。
  - 赠送和佣金报价很常见，并有详细记录。

诚实的限制：这里的推销解剖和节奏指导是未按商业模式分段发布的，这弱弱表明从业者将其视为通用的。将其应用于两者，知道普遍性是一个推断，而不是记录的规则。

## 质量门槛

门槛按消息类型划分：后续消息限制为一到两句话，不能重述第一次接触的内容（见节奏参考），因此它不能携带补偿条款或完整的电子邮件结构。

对后续消息与第一次接触列表进行评分会使门槛无法通过，并且循环永远不会终止。迭代、重新起草并重新运行人性化处理，直到每个项目都通过。

**第一次接触 - 所有九个项目，9/9。**

1. 以一个可验证的、创作者特定的 фактов 开头（一个命名的帖子、系列或受众特征），将其作为受众符合，而不是奉承。
2. 交换测试：将创作者的名字替换为另一个创作者的名字将迫使重写。如果消息在交换后仍然存在，则它是一个模板。
3. 补偿模式和真实数字都存在且与面谈完全一致。
   - 佣金推销声明费率、归因窗口和付款计划。
   - 固定费用推销命名模式，但不提供费率卡。
   - 仅赠送产品的推销直言不讳，并从未暗示付款。
4. 恰好一个请求，低摩擦，匹配经理确认他们可以履行的号召行动。
5. 根据确认的渠道进行调整：电子邮件的完整结构，2-4 句话和没有链接的私信，如果列出了经理，则寄给经理。
6. 没有记录的负面信号：通用问候语、表情符号诱饵主题、编造的熟悉感、功能倾倒、费率卡倾倒、侵略性谈判语言、长活动提案。
7. B2B 推销声明商业需求；B2C 推销声明受众购买符合。
8. 没有披露语言、合同条款或排他性要求——记录的从业者工作流程将这些放在协议之后，绝不会在冷推销中。
9. 通过人性化处理，并在口语中读起来像人类。

**每个后续消息 - 上述项目 4、6、8 和 9，以及以下三个，7/7。**

10. 一到两句话。没有重述第一次接触的内容。
11. 带有一个新的小角度——保留自第一条消息的证明点、更容易的请求版本，或一个真实的时机钩子。永远不要“只是检查一下”、“推进这个”或“你看到我的电子邮件了吗？”。
12. 低压力：不要自责，不要编造截止日期，不要读起来像追逐。沉默很忙，不是拒绝。

项目 1、2、3、5 和 7 是根据第一次接触的内容构建的，因此不在后续消息中评分。项目 11 执行项目 2 在第一次接触中做的工作：一个可以针对任何创作者不变发送的后续消息会失败它。

## KPIs

- 没有可信的回复率基准可用于创作者接触。关于这个主题的唯一调查明确拒绝发布一个。永远不要引用任何流传的数字作为事实或目标——每个数字都可以追溯到错误的引用或单一来源的自我报告：
  - “8.5% 的回复率”
  - “99% 被忽略”的通用问候语声明
  - 某个从业者自我报告的“90% 响应率”
- 与你自己的日志进行基准比较：跟踪每个推销在一个平面表格中（创作者、渠道、角度、发送日期、后续使用、结果、回复天数）。在投出十几个推销后，你自己的每个角度和每个渠道的回复率才是重要的基准。
- 核心指标：
  - 回复率（任何回复）
  - 积极回复率（愿意交谈）
  - 回复天数
  - 哪些角度产生了在后续阶段存活下来的推销，记录在下游阶段关闭后
- 如果你的框架具有持久记忆，请跨会话保留日志；否则将表格交给用户维护。

## 常见失败模式

| 失败                                                   | 修复                                                                                                                    |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 模板气味——个性化可替换为任何创作者 | 重新运行角度头脑风暴；引用一个可验证的特定内容；应用交换测试                                          |
| 补偿问题隐藏或遗漏                   | 根据解剖规则声明模式 + 真实数字；模糊读作低价                                                                  |
| 将付费合作模板用于佣金报价     | 佣金将风险转嫁给创作者——优先列出费率、窗口、付款，每笔销售估计                        |
| 推销错误的渠道                                | 在做任何其他事情之前重新运行第 3 步中的收件人门——已发布的联系方式决定，排名仅用于打破平局 |
| 忽略或绕过列出的经理                 | 用完整个性化推销经理；只有在创作者要求时才直接推销                      |
| 编造熟悉感（“一直是你的工作粉丝”）      | 一个可验证的特定内容，或者诚实地说明你是如何找到他们的                                                            |
| 第一次消息中包含费率卡或完整活动提案        | 一行交付内容草图；细节属于回复后                                                            |
| 推销中包含披露、合同或排他性条款   | 协议后主题；将披露路由到合规技能                                                        |
| 在收到积极回复后在推销线程中谈判    | 停止——交出笔记将事实带入谈判阶段                                                    |
