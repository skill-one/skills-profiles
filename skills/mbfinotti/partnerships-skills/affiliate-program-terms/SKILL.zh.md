# 联盟计划条款

草拟联盟成员加入基于佣金的计划时接受的条款和条件。不存在单一的、权威的“如何起草联盟条款”框架——绩效营销协会的零售商联盟协议指南是最接近行业清单的东西，而条款集本身在真实发布的协议中高度标准化。指导起草的原则是杰诺·普鲁萨科夫的：“你未明确禁止的任何做法，都隐含地被允许”——这份文件的价值在于列举，而非包罗万象。

这些协议几乎是普遍的非可协商点击确认的附合合同，通过行为接受并修订为“持续参与等于接受”。它们在注册时就约束了真实的人，这就是为什么法律审查以下是工作流程步骤，而不是脚注。

## 法律审查是步骤，而非脚注

生成的文件是供法律审查的草案——绝不是法律建议，也不是最终合同。

1. 在起草任何内容之前声明：“这将是一份供合格律师审查的草案，而不是法律建议。联盟条款具有法律约束力。”
2. 用 `[LEGAL REVIEW: <原因>]` 在需要特定律师关注的条款旁边进行标记，而不是将它们集中放在页脚。
3. 始终标记以下条款：
   - 适用法律/仲裁。
   - 已赚取佣金被没收。
   - GDPR角色分配。
   - 商标竞价禁令。
   - 单方面修订。
   - 赔偿和责任上限。
   - 税收/独立承包商身份。
4. 在交付的文件中重复免责声明，并加上指示保留每个内联标记，直到律师批准。

律师批准、标准的条款骨架以及访谈中出现的每个司法管辖区的义务——FTC披露、P2B通知和理由陈述、ASA标签——都是门槛，而不是菜单项。它们要么被起草，要么文件无法交付，因此它们从未进入效率排序，也从未被努力交换。只有真正可选的政策立场会被排序，每个排序都位于该立场被选择的位置。

## 访谈

在起草前提问，并遵循以下规则：

- 每条消息一个问题。
- 提供多项选择题答案。
- 跳过用户已经回答的内容。

在开始之前先问前三个问题——它们会重新排序以下面的每个政策立场，并且在用户选择一个立场后再问它们为时已晚。

- 必须在什么日期前发布条款：一个固定的近期日期的注册页面开放，还是计划仍在设计中？固定的近期日期会直接删除关键词白名单和按合作伙伴层级品牌竞价的位置——这两个在启动前都无法按合作伙伴逐个判定。
- 一次性文件，还是带日期版本和变更记录的维护文件？一次性文件促进了需要持续判定的严格立场；维护文件使白名单或退货储备变得可行。
- 努力上限：谁起草和谁审查——内部律师、外部律师或仅由计划经理——以及是否已有已发布的条款上有活跃的联盟成员？已发布的条款仅在修订周期中收紧（对欧盟/英国商业用户为15天的通知期，每个都有离开而非接受的权利），因此每个收紧都是与现有联盟成员的谈判，可逆性而非小时数是约束条件。
- B2B SaaS、B2C电商，还是两者兼有？
- 内部/SaaS托管计划，还是网络托管？网络托管意味着网络的最终条款是基准，而这份文件只是计划特定的层。
- 联盟成员和客户在哪里？
  - 欧盟/英国商业用户可能会触发P2B程序规则——内部计划是否在范围内是一个律师问题，因此提问并标记它，而不是假设任何一方。
  - 美国会触发FTC披露。
  - 英国会增加ASA/CAP和CMA的曝光。
- 哪些佣金机制在其他地方已经确定——比率、定期与一次性、验证窗口、支付门槛？本文件引用它们；它从不设计它们。
- 任何已知的滥用问题？
- 哪个品牌关键词竞价位置？按以下顺序提供四个标准位置，按每个位置在起草、判定和重新谈判中每单位能买到的价值排序：

  - 效率：严格禁止 > 仅商标禁令带修饰符允许 > 按合作伙伴层级划分 > 关键词白名单
  - 努力：关键词白名单（一个持续的工作——每个关键词的请求、判定、对实时广告的审计） > 按合作伙伴层级划分（定义层级需要一周，然后与每个被推广或拒绝的合作伙伴进行谈判） > 仅商标禁令带修饰符允许（比严格禁止多一小时，因为允许的修饰符也需要列举） > 严格禁止（近零——一个列举的条款加上品牌作为否定关键词）
  - 价值：关键词白名单 == 按合作伙伴层级划分（两者都通过不同的路线将可转换的商标加交通量保留给值得信赖的合作伙伴，同时排除其他人） > 仅商标禁令带修饰符允许 > 严格禁止（品牌术语的利润得到恢复，但代价是只在那里转换的合作伙伴）
  - 合规成本：按合作伙伴层级划分 > 关键词白名单 > 仅商标禁令带修饰符允许 == 严格禁止（相同：每个都是一次由律师批准的统一规则，无论其宽度）。前两者将不同的规则应用于不同的联盟成员——P2B要求你陈述的 grounds，以及不一致的执行会摧毁的——因此两者都需要律师对歧视问题进行审查，并且它们在没有修订周期的情况下不会放宽或收紧。

  首先提出严格禁止，因为它赢得了比率；它也是这里最少工作的情况，不是原因。白名单是这个顺序中受挫的——价值轴的顶端，比率轴的底端，每一轮都被击败。

  当一个已命名的合作伙伴已经驱动品牌术语的流量，否则你会将其让渡给非关联的套利，并且有人拥有判定的持续工作，这时推广它。删除白名单和层级划分，当没有人拥有这个工作时：一个无人执行的立场与许可无异。

  - 效率：限制 > 禁止 == 允许完全

  - 限制（仅发行代码，没有过期或未发行的代码，没有商标加优惠券条款）成本一周的定义和监管，但它保持了发现流量，同时消除了代码抓取套利。
  - 禁止几乎为零编写，并保持了利润，代价是订单。
  - 允许完全几乎为零编写，并保持了订单，为套利提供资金。

  起草细节在 [references/prohibited-tactics.md](references/prohibited-tactics.md)。

  - 浏览器扩展被允许还是被禁止？效率：直接禁止 > 允许带暂停义务。禁止是一个条款；允许是一个持续的工作，因为暂停规则只有在其能获得点击流证据时才值得其墨水，并且每个允许的扩展都必须继续满足披露和真实用户利益测试，你现在要对其作出保证。当扩展合作伙伴已经驱动了相当一部分跟踪收入，并且证据可用时，推广许可；见同一参考资料中的措辞。
  - 批准模式：人工审核还是自动批准？这里不排名——本文件编写资格条款，而两者之间的权衡属于兄弟欺诈检测技能，它根据计划规模对它进行排名。接受答案并据此起草。
  - 修订现有条款，还是从空白页开始？如果修订，请求当前文件。

本技能中的每个排序都是默认值，而不是法律：它随着上下文和执行者的变化而变化。在提出任何建议之前，根据你对用户的了解重新排序。内部律师使每个审查密集的立场更便宜，并推广有争议的立场。一个已发布的计划与活跃的联盟成员使每个收紧的成本为一次修订周期加上离开的联盟成员，并相应地降级。一个受监管的垂直领域——金融服务、健康、赌博——可以在任何努力水平上使允许的品牌竞价或审查内容立场不可用，这会删除它，而不是降级它。

## 工作流程

1. 交付法律审查声明，然后运行访谈。
2. 确认边界：比率和层级在其他地方设计（见参考资料）；条款引用现有的结构，不再更多。
3. 在任务不明确的地方问澄清问题——基准文件（网络最终条款与自己的），有争议的区域立场，哪些地理区域计算——在写一个字之前。
4. 从 [references/clause-library.md](references/clause-library.md) 组装标准骨架。骨架对于B2B SaaS和B2C电商基本相同；不同的条款在 [references/b2b-vs-b2c-contrast.md](references/b2b-vs-b2c-contrast.md) 中。
5. 起草禁止行为部分及其执行阶梯从 [references/prohibited-tactics.md](references/prohibited-tactics.md)。列举每个被禁止的行为；不要依赖一个包罗万象的条款。禁止列表不是菜单——只有访谈中确定的三个计划立场是选择，阶梯是一个序列而不是排名。
6. 起草终止、验证/追回和修订机制从 [references/termination-and-payment-mechanics.md](references/termination-and-payment-mechanics.md)。关闭三个最常遗漏的条款：
   - 终止时的待处理佣金。
   - 执行阶梯。
   - 自动品牌许可证撤销。

   追回授权在佣金在交易安全之前支付时是一个门槛——追回窗口总是先于追回风险到期。在它到期后继续工作的两个控制被排名在该文件中；兄弟欺诈技能将未发现的尾部视为一个阻止性发现，这是促进储备的条件。

7. 从 [references/jurisdiction-and-compliance.md](references/jurisdiction-and-compliance.md) 为访谈中出现的每个地理区域叠加司法管辖区域义务。
8. 如果你能够浏览网页，在引用之前重新核实每个监管数字、生效日期和通知期——罚款金额每年按通货膨胀调整，指南会修订。否则，将每个标记为“根据起草时——重新核实”。
9. 标记三个真正有争议的区域，而不是断言一个已确定的答案（下一节）。
10. 运行完整性检查；迭代草案，直到每一行都通过。
11. 分段向用户验证骨架部分，然后交付完整的草案，重复免责声明，并保留所有 `[LEGAL REVIEW]` 标记。
12. 如果你的框架具有持久内存，记住已确定的立场——地理区域、品牌竞价政策、验证和追回窗口、有争议区域的选择——以便以后的修订从它们开始，而不是重新访谈。

## 三个有争议的区域

提出选项并标记 `[LEGAL REVIEW]`；永远不要断言一个已确定的答案。

- **商标竞价禁令**——仅合同性；搜索引擎不会执行它们，并且作为关键词竞价一个商标通常是合法的。该条款仍然作为合同终止触发器起作用。要采取的四个位置中的哪一个在访谈中排名，用户选择它。
- **终止时没收已赚取的佣金**——合法性未确定，与美国各州充公法存在张力。优先考虑狭窄的追回（欺诈、退货、取消）而不是没收。这不是效率问题：合法性决定它，而不是每单位努力的回报。
- **GDPR中联盟成员和网络的角色**——处理商 vs 联合控制者 vs 独立控制者在主要网络中存在真正的争议。广告商始终是控制者；在DPA中明确解决其余部分。

  故意未排名：这是对同一法律事实的三种竞争性解读，而不是具有不同回报的三个选项，因此按努力排序会制造法律本身不支持的建议。展示所有三个，命名哪些主要网络采取哪些立场，并让律师决定。

## 完整性检查

在交付之前，直到每个项目都通过；迭代直到它通过。

- [ ] 每个标准条款都已起草或明确标记为“故意省略 - <原因>”。
- [ ] 三个常见遗漏的条款存在：终止时的待处理佣金、禁止行为执行阶梯、自动品牌许可证撤销。
- [ ] 访谈中出现的每个司法管辖区域触发器都得到解决：P2B通知期（或范围问题标记为 `[LEGAL REVIEW]`）、FTC披露义务、ASA/CAP标签、GDPR/DPA角色。
- [ ] 在佣金在交易安全之前支付的地方起草追回授权——它是一个门槛，从未被遗漏，因为一个没有收款路径的撤销权什么也没执行。
- [ ] 负余额结转被起草；追回储备被起草或明确标记为“故意省略 - <原因>”，并命名剩余的追回尾部。
- [ ] 每个有争议的区域要么与此计划无关，要么标记为选项和 `[LEGAL REVIEW]`。
- [ ] 禁止行为被列举，并带有执行阶梯；没有裸的包罗万象条款。
- [ ] 佣金语言引用已确定的结构；草案中没有任何内容发明了比率、层级或阈值。
- [ ] 法律审查免责声明随交付的文件一起提供，并且每个内联标记都完整。

## 调用示例

- “为我们的B2B SaaS起草联盟计划条款——12个月的20%定期佣金已经确定，联盟成员主要是美国和欧盟。”
- “我们商店的联盟协议没有提到优惠券扩展——重写禁止行为部分，并带有执行阶梯。”
- “我们正在从网络托管计划转移到内部；编写联盟成员在注册时接受的协议。”

## 常见失败模式

| 缺陷                                          | 后果                                                                                                                                                                                                                              | 修复                                                                                                                                                                                                            |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 终止时没有关于待处理佣金的条款                 | 每次终止都会发生争议，甚至小额诉讼                                                                                                                                             | 区分欺诈（没收）与非欺诈（支付至终止日期的累积佣金）                                                                                             |
| 禁止行为清单模糊，没有等级制度                 | 未列出的行为被默许；没有除终止外的比例性回应                                                                                                                                     | 列举行为；警告 → 废除 → 暂停 → 终止 → 恢复                                                                                                   |
| 没有自动品牌许可撤销                         | 终止后，前合作伙伴继续使用品牌资产                                                                                                                                             | 任何终止时自动撤销 + 资产销毁窗口                                                                                                               |
| 获得佣金的全部没收                           | 法律上存在争议；面临没收风险；看起来具有惩罚性                                                                                                                                  | 仅针对欺诈、退货、取消进行有限撤销                                                                                                             |
| 无需通知的单方面修订                         | 对欧盟/英国业务用户无效，无论P2B是否适用——是否达到内部商户计划尚不明确，因此应将其视为风险，而非确定性                                                                                | 电子通知 + 继续参与确认 + 对欧盟/英国业务用户进行15天通知，范围问题标记为 `[法律审查]`                                                              |
