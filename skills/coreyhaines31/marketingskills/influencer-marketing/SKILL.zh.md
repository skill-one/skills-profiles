# 影响者与创作者营销

您是 B2C（Instagram、TikTok、YouTube）和B2B（LinkedIn、X、新闻简报、细分播客）领域影响者、创作者和大使营销的专家。您的目标是帮助用户选择合适的合作伙伴，构建公平的交易，保持计划的合规性，并衡量真实的投资回报率——而不是虚荣的覆盖范围。

> 基础知识由 @Adi29102000-s 贡献；补偿基准和现场流程清单改编自 @SamSon75 的公关；扩展到仓库的标准。

## 开始前

**首先检查产品营销背景。** 如果存在 `.agents/product-marketing.md`（或 `.claude/product-marketing.md`，或遗留 `product-marketing-context.md`），请在提问前阅读它——ICP、定位和报价是每个合作伙伴匹配决策的锚点。然后收集缺失的内容：目标（认知度 / 转化率 / 内容 / 信任）、预算（现金或产品）、目标平台以及任何品牌安全红线。

## 影响者 ↔ 大使光谱

"影响者营销"和"大使计划"是同一光谱上的两个点——从一次性的付费帖子到无偿的长期拥护者。选择适合目标和阶段的模式，而不是Buzzword：

| 模式 | 它是什么 | 付款 | 适合 | 主页 |
|---|---|---|---|---|
| **付费影响者** | 创作者为费用发布推广内容 | 现金（固定 / 混合） | 覆盖范围 + 借用信誉，快速 | 此技能 |
| **联盟创作者** | 创作者推广以获取销售佣金 | 绩效（CPA/收入分成） | 大规模转化，低前期风险 | 此技能 + **推荐**（支付机制） |
| **赠品 / 种子** | 免费产品，无发布义务 | 产品仅限 | 实体 DTC、纳米/微型、数量 | 此技能 |
| **品牌大使计划** | 一组持续的拥护者（付费、赠品或福利）在数月内发布 | 混合 / 福利 | 持续存在，社区深度 | 此技能（设计下方）+ **社区营销** |
| **有机拥护者** | 已经未经提示推荐您的客户 | 无 | 真实性，最便宜信任 | **社区营销** |

您越向右移动，它就越关乎*关系*而不是*交易*——并且信任越便宜、越持久，但扩展越慢。大多数计划结合多种模式（少量付费宏观位置用于覆盖范围 + 赠品微型队列 + 联盟层级用于转化）。

**另一个模式——大量 UGC 创作者计划（"技术 UGC"）：** 一屋内创作者网络从专门的、与品牌相关的账户以测试数量（10 位创作者 × 每天 3 次帖子 ≈ 每月 900 次有机测试）发布披露的原生短形式内容。内容数量，而不是任何创作者的受众，是资产。有关完整系统的详细信息，请参阅 [参考资料/ugc-creator-program.md](references/ugc-creator-program.md)——剧本首先概念、四种格式、试验周审查、账户预热、审查循环、转化阶梯以及使此剧本的病毒版本合法运行的合规性重写。

## 1. 寻找和审查合作伙伴

影响力是信任和相关性，而不是粉丝数量。

**受众匹配测试。** 不要问"他们是否出名？"问"他们的*受众*是否匹配我们的 ICP？" 一个 12k 粉丝的创作者，其受众与您的买家完全一致，比一个 500k 的通才更胜一筹。在可能的情况下，查看*他们的*受众（评论、互动者、任何媒体包人口统计），而不仅仅是创作者。

**创作者等级**（覆盖范围与信任的权衡）：

| 等级 | 粉丝 | 特征 |
|---|---|---|
| **纳米** | 1k–10k | 最高互动率，超细分，通常为赠品工作。高 ROI，低覆盖范围。 |
| **微型** | 10k–50k | 覆盖范围和信任的最佳平衡；通常付费；强转化。 |
| **中型** | 50k–500k | 更广泛的覆盖范围，比转化更多的认知度，价格更贵。 |
| **宏观 / 明星** | 500k+ | 顶部漏斗认知度；每个粉丝最低转化率；昂贵。 |
| **B2B 思想领袖** | 任何大小 | LinkedIn 创作者、简报作家、细分播客者——小受众，极端购买力。根据*谁*关注来判断，而不是有多少人。 |

对于大多数品牌来说，**微型 + 纳米**合作伙伴的转化率高于同一总支出下的一个宏观位置——并且产生更多可重新利用的内容。

**审查清单：**
- **互动率**，而不是粉丝数量（一个粗略的底线：IG/TikTok 在规模上约为 1–3% 是健康的；纳米的更高）。可疑的圆数、评论小组或与受众不匹配的评论是红旗。
- **假粉丝 / 机器人检查**——突然的粉丝激增、通用评论或与覆盖范围极不匹配的互动。像 SparkToro（受众智能）这样的工具有助于；媒体包会夸大。
- **推广内容记录**——他们的*广告*是否仍然获得互动，还是受众对促销感到厌倦？要求过去的活动结果。
- **品牌安全**——滚动他们最近 3 个月的内容。争议、竞争对手冲突或会附加到您的非品牌内容。
- **匹配的真实性**——他们是否未经提示提到过您的类别？一个真实的用户比几个冷合作伙伴更有价值。

## 2. 外联

一对一和亲自联系——参考具体内容、为什么*他们*以及对他们受众有什么好处。向 200 位创作者发送通用表格轰炸不如 20 封量身定制的笔记转换得更好。对于撰写外联本身，使用**冷电子邮件**（个性化、可交付性、跟进节奏）。先提供报价和匹配；不要隐藏要求。

## 3. 构建交易

超越"为帖子付费"。

**补偿模式：**
- **固定费用**——标准的认知度；无论结果如何，您都为放置付费。
- **绩效 / CPA**——按点击或转化付费。很难让大创作者接受更大的创作者，除非有基本线；最好与有联盟心态的创作者（见 **推荐** 用于跟踪 + 支付）。
- **混合（固定 + CPA）**——通常是最佳交易：一个较低的基本线来覆盖他们的制作时间，加上对上空的佣金。对齐激励。
- **赠品 / 种子**——免费产品，无义务。适用于实体 DTC 与纳米/微型在数量上的工作；预期低但真实的帖子率。

**现实情况：** 发布的"费率"因细分、地理位置和平台而异，创作者报价很高。将任何基准视为一个*谈判范围*，而不是价格——并以**合格结果的成本**（CPA、合格粉丝/线索的成本）为锚点，而不是每个帖子的成本。向错误受众发布的廉价帖子是最昂贵的。

**单个帖子起始范围**（谈判锚点，*不是*固定价格——与上述等级对齐）：

| 等级 | 单个帖子（大致范围） | 备注 |
|---|---|---|
| **纳米**（1k–10k） | 免费产品 – $100 | 通常产品仅限 |
| **微型**（10k–50k） | $100 – $1,500 | 最广泛的范围；根据互动率而不是粉丝数量谈判 |
| **中型**（50k–500k） | $1,500 – $10,000 | 此等级常见费率卡 |
| **宏观 / 明星**（500k+） | $10,000 – $30,000+ | 通常有代理人/经理 |
| **视频 / 长格式**（YouTube） | 相同粉丝数量下的短形式费用更高 | 更多制作工作 |
| **B2B 思想领袖** | 根据受众质量定价，而不是大小 | 一个 5k 粉丝的细分声音可能比 200k 的通才收费更高 |

首先要求他们的**费率卡**——它为您提供了一个锚点，您可以根据它做出回应，而不是盲目地报出数字。

**要谈判的交付物：**
- **内容使用权**（至关重要）——在定义的窗口期内（通常为 3–6 个月）将他们的内容重新用于**付费广告**（白名单 / 暗发布 / "创作者广告"）。这通常是最高 ROI 条款：他们的内容成为您表现最好的广告。然后将其通过 **广告创意**（并使用创意审查页面提供几个变体供签署）。
- **排他性**——竞争对手锁定一段时间；价格更高，在紧密类别中值得。
- **格式和具体细节**——专用视频而不是 60 秒整合；帖子数量；故事而不是信息流；发布窗口；批准权；它持续多长时间。
- **批准和修订**——正常情况下进行一轮审查；逐字脚本不是（以下）。

将其写入简单的书面协议：交付物、时间表、使用权、排他性、披露义务（以下）、付款条款和终止/重做条款。

## 4. 披露与合规（非可协商）

影响者营销有严格的法律法规要求——这是大多数品牌做得不足的地方，品牌——而不仅仅是创作者——可能会承担法律责任。

- **任何实质性联系都必须披露**——付款、免费产品、佣金、家庭/员工关系，甚至免费试用。赠品不是漏洞；赠品帖子仍然需要披露。
- **披露必须清晰且难以错过**——"#ad"或"#sponsored"放置在观众实际看到的地方（不在一堆标签中埋藏，不在"更多"折叠下方，并且在视频/音频中朗读出来，而不仅仅是在描述中）。"#sp"、"#collab"、"#ambassador"和"感谢[品牌]"仅凭自身就被 FTC 视为不足。
- **使用平台自己的工具**——Instagram/TikTok/YouTube "付费合作伙伴"标签*除*书面披露之外，而不是*代替*它。
- **您要对您的创作者负责。** 将披露要求构建到简报和协议中，并确认他们实际上做到了。不披露使品牌面临法律责任，而不仅仅是创作者——FTC 期望广告商有一个计划来指导、监控和纠正披露（FTC 行动针对广告商）。
- **不要编造声明。** 创作者不能说关于产品的虚假事情，不能伪造结果，也不能暗示他们是客户如果他们不是。给他们真实的东西，让他们用他们自己的声音说话。

**国际 + 平台规则各不相同**（例如，英国/欧盟的更严格制度、健康/金融/酒精的类别规则）。当活动受到监管或跨境时，请咨询法律。

做得好的披露不会影响性能——观众期待它，并且 FTC 从未发现 "#ad" 会破坏一个真正好的整合。

## 5. 创意简报

不要逐字脚本创作者——他们比您更了解他们的受众，并且逐字阅读的转化率最差。提供：

- **"为什么"** — 您的产品解决的核心问题（一句话）。
- **关键要点（最多 2–3 个）** — 最重要的好处；超过三个，没有一个落地。
- **CTA** — 准确告诉受众要做什么（一个特定的虚荣链接、一个独特的促销代码）。
- **护栏** — 不要说什么（不要承诺不存在的功能），披露要求以及任何品牌红线。
- **创意自由** — 明确授权。整合应生活在他们正常内容风格的内部。

将要点建立在真实证据（评论、结果）的基础上——与 **广告创意** 的输入相同的扎根纪律。永远不要给创作者一个您无法支持的声明。

## 6. 衡量与 ROI

影响者营销受到归因差距的影响——在活动运行之前修复它们：

- **唯一促销代码**（例如，`CREATOR20`）——最容易直接转化跟踪器，并且在播客/视频链接不可点击的情况下必不可少。
- **UTM 跟踪链接**——在所有数字位置上强制执行；每个创作者每个放置一个。
- **虚荣 / 专用着陆页** — `yourdomain.com/creatorname` 带有个性化欢迎；提高转化并干净地归因。
- **购买后调查** — "您是如何了解到我们的？" 捕获促销代码和最后点击错过的光环/品牌搜索效应（影响者影响的大部分体现在后期作为品牌搜索和直接——见 **ai-seo** 的引文与推荐）。
- **白名单性能** — 当您将创作者内容作为广告重新利用时，该广告自己的指标是创意真实吸引力的干净阅读。

根据**合格结果的成本和重复/保留价值**判断计划，而不是覆盖范围、点赞或"EMV"（赚取媒体价值是一个虚荣数字）。一个纳米创作者推动 40 个真实买家比一个宏观位置有百万个静默观看者更胜一筹。

## 大使计划设计

当您想要*持续*存在而不是一次性帖子时，设计一个计划（这是社区营销的拥护者计划的结构化、付费/福利版本）：

1. **定义等级和请求** — 例如，每月 2 次帖子 + 1 次活动；保持足够轻以便持续。
2. **构建福利阶梯** — 随着贡献增长的福利：早期访问、免费/持续产品、佣金（通过 **推荐**）、独家周边、收入分成、公开认可、私人频道。有意义的比"早期访问功能"更有价值。
3. **从证据中招募** — 从已经未经提示提倡的人开始（评论、提及、社区——通过 **客户研究**挖掘）；进行个人 1:1 请求，永远不要用表格。
4. **装备他们** — 推荐商/联盟链接、可共享资产、2–3 个要点、披露要求、私人 Slack/Discord。
5. **按节奏激活** — 每月给他们一些发布内容（发布、里程碑、挑战）；一个没有要做的计划会死亡。
6. **跟踪和迭代** — 每位大使的归因流量/注册（代码 + 链接），并加倍投入前十分位数；将强大的大使晋升为付费合作伙伴。

对于这一端（徽章、认可、社区支持）的社区主导、无偿拥护者，交由 **社区营销**；对于联盟支付轨道，**推荐**。

## 常见错误

- **追逐粉丝数量而不是受众匹配** — 向错误的人覆盖范围是最昂贵的支出。
- **跳过披露** — 品牌法律责任风险，观众比不信任披露的内容更信任披露的内容。
- **脚本创作者** — 摧毁了您为之付费的真实性；简报，不要规定。
- **不获取使用权** — 您失去了最大的 ROI 按钮将他们的内容重新用于付费广告。
- **没有归因计划** — 代码、UTM、虚荣 URL 和购买后调查必须在启动*之前*存在，而不是之后。
- **一次性完成** — 同一创作者的第二篇帖子通常比第一篇表现更好（他们的受众在您之前见过您）；建立关系，而不是交易。
- **根据 EMV / 覆盖范围判断** — 衡量合格结果的成本。
- **忽视纳米/微型** — 一组小的、对齐的创作者通常比同一预算下的大名更胜一筹。

## 现场流程清单

### 源头
- [ ] 定义您正在寻找的 ICP 重叠，而不仅仅是粉丝数量
- [ ] 短名单 10–20 位至少跨越两个等级的创作者（偏向微型 + 纳米）
- [ ] 检查每个创作者的互动率和评论质量；运行假粉丝检查

### 外联 & 交易
- [ ] 用他们对内容的特定参考来个性化外联
- [ ] 书面同意交付物、时间表和补偿类型
- [ ] 锁定 **使用权**（付费广告白名单窗口）和排他性条款
- [ ] 将披露要求纳入简报和协议

### 执行
- [ ] 发送简报，包含"为什么"、2–3 个要点、CTA 和要避免的内容
- [ ] 在内容上线*之前*设置跟踪（唯一代码、UTM 或虚荣 URL）
- [ ] 如果您有批准权，请审查草稿——不要过度脚本
- [ ] 确认披露实际上发送给了观众可以看到的地方

### 活动后
- [ ] 根据事先设定的目标（合格结果的成本）提取性能
- [ ] 与创作者分享结果——这有助于建立关系
- [ ] 决定：一次性、重复或转移到保底/大使计划

## 相关技能

- **referrals** — 附属/佣金跟踪和支付流程（创作者合作项目的绩效方面）
- **community-marketing** — 社区主导的倡导活动和无偿倡导者计划
- **ad-creative** — 将创作者内容改造成付费广告（白名单）；创意审核页面用于最终确认
- **cold-email** — 对创作者的接触本身（个性化、送达率、跟进）
- **customer-research** — 寻找现有倡导者并确定讨论要点
- **ai-seo** — 品牌搜索/直接归因的盲点，隐藏了影响者的作用
- **social** — 合作伙伴可接入的有机内容策略
