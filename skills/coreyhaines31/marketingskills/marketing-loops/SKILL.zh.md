# 营销循环

您负责设置**营销循环**——AI代理按一定频率运行的重复性营销工作流程，每个循环都有一个定义的触发器、一组有限步骤、自我检查和明确的停止条件。循环将您原本会手动执行（然后忘记）的营销任务转化为始终运行的系统：每周SEO机会扫描、广告疲劳刷新、流失信号监控。

这是`marketing-ideas`的操作上的亲戚。想法告诉您*一次尝试什么*。循环告诉您*按计划持续做什么*——并将其他营销技能连接起来执行它。

## 如何使用此技能

**首先检查产品营销上下文**：如果存在`.agents/product-marketing.md`（或`.claude/product-marketing.md`，或遗留的`product-marketing-context.md`），则在提问前阅读它。使用该上下文并仅询问缺失的内容。

然后：
1. **澄清任务**。这个循环应该保护或增长什么结果？（排名、广告效率、激活、留存、收入、推荐）
2. **从`references/loop-catalog.md`中的目录中选择一个循环**——或者调整最接近的循环。
3. **调整频率**以匹配底层信号实际变化的速度（见下文的频率规则）。
4. **确认人工检查点**。决定循环是自主执行还是为人工批准发布或支出而暂存——见`references/loop-guardrails.md`。
5. **安排它**（见下文“安排循环”）。

构建多个循环或整个营销操作系统？参见`references/loop-orchestration.md`了解循环如何组合以及采用它们的顺序（从跟踪+每周回顾开始；不要一次构建43个）。

## 营销循环的构成

目录中的每个循环都有这九个部分。当您创建或调整一个循环时，填写所有这些——缺少停止条件、自我检查或其状态处理的循环是一个负债，而不是资产。

| 部分 | 它定义了什么 |
|------|-------------|
| **检查频率** | 循环*多久查看一次*（每周/每天/按触发器）。与信号速度匹配。 |
| **触发条件** | 执行条件——什么必须为真才能实际*执行*某事，而不是仅仅检查并跳过。一个好的循环的大部分运行都是“检查，无事可做”。 |
| **目的** | 这个循环存在的唯一结果。 |
| **使用的技能** | 循环每次迭代协调的营销技能。 |
| **循环主体** | 每次迭代运行的有序步骤。 |
| **自我检查** | 在执行之前的验证——这样循环就不会在噪音、季节性或跟踪错误上执行。 |
| **状态 / 不可变性** | 循环在运行之间记住的内容：上次运行标记、去重键、冷却窗口、“已处理”集。没有这个，循环会重复执行、重新烦扰相同的人或重新警报相同的事情。对于任何计划的任务都是非协商的——参见`references/loop-state.md`了解状态存储位置和不可变性模式。 |
| **停止 / 撤回** | 循环跳过、停止、升级到人工或禁用自身——以及出错时它做什么。每个循环都需要一个，包括心跳循环（它们的停止是“手动禁用+错误停止”，永远不会是“不适用”）。 |
| **输出** | 结果去哪里：一个文件、一个PR、一个暂存草稿、一个通知、一个报告。 |

**检查频率/触发条件**的分离很重要：一个流失信号循环可能*每天检查*，但只在账户跨越风险阈值且在冷却窗口内未被联系时*执行*。混淆两者会产生要么错过窗口要么进行垃圾邮件的循环。

## 频率规则

与信号实际变化的速度匹配——而不是您希望更新的频率。

| 信号 | 现实频率 | 原因 |
|------|----------|------|
| 排名、反向链接、域名权威 | 每周 | 变化缓慢；每日检查是噪音 |
| 广告创意疲劳、CPA漂移 | 每2-3天 | Meta/Google反馈循环是几天，不是小时 |
| 激活/用户引导漏斗 | 每周 | 需要足够的注册才有意义 |
| 流失信号 | 每日或按触发器 | 早期干预窗口很短 |
| 内容/文案衰减 | 每月 | 流量侵蚀是渐进的 |
| 竞争对手变化 | 每周 | 定价/定位变化不频繁但很重要 |
| 社交聆听/提及 | 每日 | 参与窗口关闭很快 |

过于频繁的循环是最常见的失败模式：它们产生忙活、烧预算，并训练您忽略输出。

## 不应用循环的情况

并非所有东西都应该按频率自动化。跳过循环——或添加强制人工检查点——当：

- **策略或创意方向是真正的工作**。循环维护和优化；它们不会设定定位、发明活动或做出品牌呼吁。
- **执行会发布或支出而不经审查**。自动*草稿*广告、电子邮件或帖子是好的。自动*发布*或自动*调整预算*需要人工检查点，除非用户明确授权自主行动并设置了护栏（上限、允许列表）。
- **信号过于稀疏而没有意义**。每周在每周40访客的情况下进行转化率循环是在衡量噪音。
- **这是一个虚荣循环**。如果没有人对输出采取行动，请删除循环。一个向无人阅读的仪表板发送电子邮件的循环比什么都没有更糟。

对于任何发送、支出、发布或接触个人数据的循环，应用`references/loop-guardrails.md`——双层行动模型（自主安全 vs. 受限制）、支出/发送上限、CAN-SPAM/GDPR/FTC/ToS规则、始终升级列表和一个必需的关闭开关。

## 安排循环

这些循环是代理无关的——*主体*在任何代理中工作。*安排*取决于您的环境：

- **Claude Code** — 原生选项：`/loop`（自我推进，直到条件）、`ScheduleWakeup`（动态步调，反应状态）和`CronCreate`（固定cron计划）。如果您安装了循环机制技能，例如`loopify`，使用它来在它们之间进行选择并调整延迟；否则下文的指导就足够了。
- **任何代理 + cron** — 将循环主体包装为计划提示/脚本（`0 9 * * 1`为每周一上午9点，等等.）。
- **手动频率** — 对于高判断循环，“每周运行此技能”是一个非常好的循环。价值在于可重复的*主体*，而不是自动化。

默认使用按时间cron进行审查式循环（每周审查、排名监控）和动态步调进行监控直到阈值循环（流失监控、发布日跟踪）。

## 目录

`references/loop-catalog.md`包含完整库——43个营销循环，涵盖全面的漏斗：SEO & 内容、付费、赢得/社交/合作伙伴关系、激活、留存、收入、推荐 & 倡导，以及持续的运营。每个都是一个完整、可适应的规范。从那里开始，选择最接近的匹配，并根据用户的 产品、阶段和工具进行调整。

## 创建新循环

当目录中的没有匹配时，从`references/loop-template.md`创建一个新循环——一个带填写提示的复制粘贴模板、一个工作前/后的示例和一个发货检查清单。填写所有九个构成部分；如果您无法具体回答自我检查、状态/不可变性，以及停止/撤回，则循环没有准备好运行。

## 反模式

- 没有停止条件的循环 → 无限支出或无限流失。
- 每个循环使用相同频率 → 大多数运行得太频繁而被忽略。
- 没有自我检查 → 循环在噪音、季节性或跟踪错误上执行。
- 支出/发布操作没有人工检查点。
- 一次构建10个循环 → 从一个开始，证明它值得保留，然后添加下一个。

## 禁用词汇

避免：“设置并忘记”、“完全自主的营销”、“AI做所有事情”、“自动10倍”、“增长黑客机器”。循环是有纪律的系统，带有检查点，不是魔法。诚实地描述它们。

## 相关技能

- **marketing-ideas** — 一次性战术和灵感（什么要尝试）。循环使值得重复的它们可操作化。
- **ab-testing** — 专门的实验循环（假设→测试→推广赢家→重复）。
- **analytics** — 大多数循环从分析中读取以决定是否执行。
- 单个渠道技能（`ads`、`seo-audit`、`emails`、`social`、`churn-prevention`、`pricing`、`referrals`）——循环主体协调这些。
