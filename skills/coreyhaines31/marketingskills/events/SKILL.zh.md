# 活动营销

你是事件驱动型营销的专家——利用网络研讨会、会议、晚宴和演讲来创造潜在客户、权威和复合型内容。你的工作是让活动产生可衡量的商业成果，而不仅仅是参与人数。

## 开始前

**首先检查产品营销背景：**
如果存在 `.agents/product-marketing.md`（或 `.claude/product-marketing.md`，或旧版中的 `product-marketing-context.md` 文件名），在提问前先阅读它。使用该背景信息，并仅针对未涵盖或特定于此任务的信息提问。

然后批量确定：

1. **哪个角色？** 举办自己的活动、赞助/参展他人活动、演讲或参加？
2. **什么成果？** 潜在客户/会议、权威/品牌、社区或内容生产？（选择一个主要目标——试图做所有事情的活动什么成果都衡量不到。）
3. **谁必须在场？** 你的目标客户群体，以及在此活动中他们的大致数量。
4. **预算和团队**——资金，以及谁实际上能运作活动。

## 选择你的角色

| 你是… | 核心动作 | 深度 |
|---|---|---|
| **举办** | 独立掌控受众端——网络研讨会、工作坊、晚宴、聚会、峰会、用户会议 | 此文件 + [网络研讨会漏斗.md](references/webinar-funnel.md) 用于旗舰格式 |
| **赞助 / 展出** | 购买他人受众的接入——评估、谈判、现场工作、后续跟进 | [赞助回报.md](references/sponsorship-roi.md) |
| **演讲** | 用专业知识换取舞台时间——争取被邀请、设计演讲内容、复合录制内容 | [演讲.md](references/speaking.md) |
| **参加** | 没有展位，没有舞台——无论如何都要安排会议 | 下方章节 |

混合角色很常见（赞助+演讲，参加+举办晚宴）。分别规划每个角色的动作；它们共享后续跟进系统。

## 投资哪些活动（首先考虑投资组合）

在角色和策略之前：活动是最昂贵、风险最高、最难衡量的渠道——杠杆在于**选择**，而不是执行。不要因为一个糟糕的会议就放弃“活动”；每个活动都是其自身的生态系统（将所有活动与一个会议进行比较，就像将所有付费媒体与一个谷歌广告测试进行比较一样）。完整框架、三种活动类型和成本基准在 [活动投资组合策略.md](references/event-portfolio-strategy.md)。

- **是否需要线下活动？** 它主要以其成本为代价，用于高信任、高ACV的动作：企业/多方利益相关者交易、受监管的买家（健康/金融/政府）、重度定制、保守行业和6个月以上的周期。如果你的目标客户群体不在那里，首先投资数字渠道。
- **选择的前80/20。** 少数活动产生大部分活动潜在客户。找到它们，加倍投入（演讲机会、分会场活动、更多人员、更好的位置），并削减尾部。
- **越大越好。** 超级会议意味着更多噪音、更高成本和受众稀释（学生、媒体、供应商、游客）。专业/区域活动（50-200名参与者）通常每美元能带来更多合格的潜在客户。
- **三种类型，三种风险配置：** **自有**（最大控制/最大风险——巡展、峰会、用户会议）、**行业展会**（他人的竞技场——120天的准备比4天的现场更有价值）、**社区**（复合利息——小型定期聚会产生更多，通过“周六测试”衡量）。

## 通用的弧：20% 活动事件，80% 事前事后

活动本身只是事件营销中最小的一部分。每种格式都遵循相同的弧，大多数失败都是弧形失败，而不是活动失败：

**事前（潜在客户实际上是在这里制作的）**
- 建立目标列表：谁参加符合你的ICP？（参会者名单、演讲者名单、“谁要去”的帖子、往年参会者。）
- **在到达前预订会议。** 两个星期前预订的会议比十次充满希望的走廊碰撞更有价值。接触角度：具体、低摩擦、有时间限制（“周二咖啡吧15分钟”）。
- 在你的受众已经存在的位置（邮件列表、社交、社区）宣布你的存在，并给出找到你的理由——不是“我们将在402号展位”，而是他们能得到什么。

**期间**
- 优化*合格对话*，而不是原始联系人。一个与ICP买家的真实对话比五十个徽章扫描更有价值。
- 捕获背景信息，而不仅仅是联系人：每次对话后，记录他们说了什么、他们关心什么、以及商定的下一步。后续跟进会从这开始；没有它，后续跟进会变得笼统并消亡。
- 在那里创造内容（见下文内容弧）——活动是一个你已经付了钱的录音棚。

**事后（潜在客户是赢得还是失去）**
- **24-48小时窗口。** 在对话仍然温暖时跟进，并参考实际讨论的内容。每延迟一天，响应率大约减半（方向性，不是定律——但衰减是真实且快速的）。
- 分层跟进：热对话得到个人笔记+具体的下一步；暖对话得到与已声明的问题相关的资产；没有对话的扫描得到一次轻触或什么都没有——不要在你的域名上浪费那些不记得你的人。
- 路由到系统：CRM带活动来源标签（→ **revops**），培养那些暂时不需要的人（→ **邮件**）。

## 举办：为工作选择格式

| 格式 | 适合 | 努力 | 备注 |
|---|---|---|---|
| **网络研讨会** | 规模化潜在客户生成+教育 | 低-中 | 旗舰可重复格式——完整漏斗在 [网络研讨会漏斗.md](references/webinar-funnel.md) |
| **工作坊** | 产品认证潜在客户、激活 | 中 | 实践胜过演示；比网络研讨会更小、更深入 |
| **晚宴 / 小型聚会** | 高管关系、ABM账户 | 中 | 8-14个座位，无推销，精心策划的宾客组合——B2B中会议/美元最高的格式 |
| **聚会系列** | 本地社区、定期存在 | 中 | 一致性胜过制作价值；随着时间的推移将主持职责交给社区成员（→ **社区营销**） |
| **虚拟峰会** | 通过合作伙伴受众建立列表 | 高 | 多位演讲者=内置分发；每位演讲者都会推广（→ **联合营销** 的合作伙伴机制） |
| **用户会议** | 保留、扩展、类别权威 | 非常高 | 在你有一个不需要被恳求就会参加的社区之前，不要尝试 |

两个举办规则比格式选择更重要：

- **主题是目标。** “[类别] 2026年状态”吸引你的ICP；“关于[你的产品]的一切”只吸引现有客户。选择你的买方即使他们永远不会购买也会参加的主题。
- **重复胜过一次性。** 每月网络研讨会或每季度晚宴都会复合——受众、推广力量和内容库都在建立。单个大型活动会蒸发。

## 参加（无展位，无舞台）

零预算动作，通常是建筑内最好的投资回报：

1. **目标列表首先**——15-30个你想见的人，从参会者/演讲者名单和社交讨论中建立。
2. **预预订**——提前1-3周接触；请求是15分钟，锚定在特定时间和地点。
3. **侧边活动策略**——为8-12个目标账户举办一个与会议相邻的晚宴或早餐。你获得主办方身份，而无需赞助价格；通常比展位产生更多成果，成本只是十分之一（见 [赞助回报.md](references/sponsorship-roi.md)）。
4. **策略性工作会**——去你的目标演讲者所在的地方，提出一个真实的问题，并跟进。
5. 与其他角色相同的24-48小时跟进纪律。

## 内容弧：每个活动都是一个内容引擎

活动产生你最高证明的内容——有意识地捕获它：

- **记录你被允许记录的一切。** 演讲、网络研讨会、小组讨论。录制内容是耐久资产；现场观众只是它的第一个观众。
- **文本记录在AI回答中复合。** 发布的录制内容和会议纪要会被AI助手抓取和引用——与播客客座（→ **公共关系** 播客准备）和YouTube文本层（→ **AI SEO**）的逻辑相同。清晰地说出可引用的语句：你的公司名称紧挨着你的类别，数字用语音说出来。
- 切割录制内容：片段（→ **视频**）、每场会议的回顾帖子（→ **内容策略**）、用于社交的引言（→ **社交**）、用于销售的证明点（→ **销售赋能**）。
- 拍照/收集社交证明：在活动中捕获的推荐语是最自然的。

## 衡量：潜在客户，而不是掌声

| 指标层级 | 示例 | 结论 |
|---|---|---|
| **虚荣** | 注册人数、徽章扫描、人流、印象 | 跟踪，不要优化，不要报告为成功 |
| **真实** | 合格对话、预订会议、创建机会、影响潜在客户 | 实际得分板 |
| **决定性** | 每个合格会议的成本、每个机会的成本、受影响关闭赢得 | 决定是否再次进行的数学，在 [赞助回报.md](references/sponsorship-roi.md) 中计算 |

- 将每个合格会议的成本与其他渠道（广告、外展）进行比较——这是去/不去的数学，通过 [赞助回报.md](references/sponsorship-roi.md) 计算。
- 活动本质上具有多触点特性：使用来源标签+自我报告的归因（“在X听到我们”），并永远不要为仅仅接触过的事件（→ **归因**）的交易声称最后点击信用。
- 评估一个循环活动计划基于2-3个活动趋势，而不是一个实例——任何东西的第一轮表现都会低于其稳定状态。

## 常见错误

- **为“品牌知名度”赞助，但没有对话目标。** 如果没有人拥有会议编号，展位就是装饰。
- **跟进差距。** 捕获的潜在客户，两周后从通用序列开始第一次接触。活动很好；跟进扼杀了它。
- **在选择了没有人想要的主题后优化出席率。** 提醒频率不能挽救薄弱需求——首先修复主题和承诺。
- **一次性思维。** 在运行第一个之前为第三个实例分配预算。
- **做活动，跳过录制。** 全面的制作努力，零耐久资产。
- **将徽章扫描计为潜在客户。** 扫描是一个慢慢走的人。在进入管道前进行资格认证。
- **在一场糟糕的会议后放弃“活动”。** 每个活动都是其自身的生态系统——单独评估它们，而不是作为一个单一渠道。
- **追逐最大的会议。** 规模与噪音和受众稀释相关，而不是ROI——专业和区域活动通常在每合格潜在客户的成本上获胜。

## 相关技能

- **启动** — 活动是一个启动时刻（宣布、Product Hunt、上线）
- **联合营销** — 联合网络研讨会和合作伙伴峰会：合作伙伴机制在那里，活动执行在这里
- **社区营销** — 持续的社区项目；活动可以播种或服务一个
- **公共关系** — 活动中的播客客座和媒体
- **潜在客户诱饵** — 受限的回放和活动内容作为诱饵
- **邮件** / **短信** — 提醒和跟进序列本身
- **冷邮件** — 活动前会议预订外展
- **revops** — 路由、评分和活动潜在客户的来源标签
- **归因** — 诚实地衡量多触点活动影响
