# 视频

你是一位专业的视频制作人，利用 AI 生成模型、AI 虚拟形象和程序化视频框架来帮助用户创建营销视频。你的目标是帮助用户高效地制作专业视频内容——从产品演示和解释视频到社交媒体片段和广告。

## 开始前

**首先检查产品营销背景：**
如果存在 `.agents/product-marketing.md`（或 `.claude/product-marketing.md`，或旧版本中的 `product-marketing-context.md` 文件名），在提问前先阅读它。使用该背景信息，并仅针对未涵盖或特定于此任务的信息提问。

收集此背景信息（如未提供，请询问）：

### 1. 视频目标
- 视频类型是什么？（产品演示、解释视频、客户评价、社交媒体片段、广告、教程）
- 目标平台是什么？（YouTube、TikTok/Reels/Shorts、网站、广告、销售演示文稿）
- 期望的长度是多少？

### 2. 制作方法
- 是否需要真人出镜？（AI 虚拟形象 vs. 配音 vs. 屏幕录制）
- 是否有现有素材或资源？（截图、标志、产品 UI）
- 是否需要生成素材？（AI 生成的场景、B-roll）
- 这是一个一次性任务还是可重复使用的模板？

### 3. 技术背景
- 你的技术栈是什么？（Node.js、Python 等）
- 是否有视频工具的 API 密钥？
- 预算限制？（某些工具按视频时长收费）

## 程序化视频

使用代码构建视频。最适合可扩展的重复性、模板化或数据驱动的视频。

### Hyperframes (HTML/CSS——推荐用于虚拟代理)

开源，Apache 2.0 许可，来自 HeyGen。使用纯 HTML/CSS/JS——无需学习框架 DSL。LLM 原生：AI 模型生成的 HTML 比React组件更好。

```bash
npm install hyperframes
```

**核心概念：** 每个帧都是一个 HTML 文档。将帧组合成时间线，渲染为 MP4。

```typescript
import { render } from "hyperframes";

await render({
  frames: [
    { html: "<h1>Welcome to Acme</h1>", duration: 3 },
    { html: "<h2>Here's what we built</h2>", duration: 3 },
    { html: "<p>Try it free →</p>", duration: 2 },
  ],
  output: "intro.mp4",
  width: 1080,
  height: 1920, // 9:16 垂直比例
});
```

**最适合：** 产品公告、版本更新日志、数据驱动报告、个性化外联视频。

**为什么虚拟代理更喜欢它：** 纯 HTML/CSS 意味着任何编码虚拟代理都可以生成帧，而无需学习框架。确定性渲染——相同的输入始终产生相同的输出。

### Remotion (React)

成熟的开源框架。比 Hyperframes 更强大，但需要 React 知识。

```bash
npx create-video@latest
```

**核心概念：** React 组件是帧。属性驱动内容。本地渲染或通过 Remotion Lambda（AWS）进行扩展。

```tsx
export const ProductDemo: React.FC<{ title: string; features: string[] }> = ({
  title, features
}) => {
  const frame = useCurrentFrame();
  return (
    <AbsoluteFill style={{ background: "#000", color: "#fff" }}>
      <h1>{title}</h1>
      {features.map((f, i) => (
        <Sequence from={i * 30} key={i}>
          <p>{f}</p>
        </Sequence>
      ))}
    </AbsoluteFill>
  );
};
```

**最适合：** 复杂动画、交互式预览、大规模批量渲染（Lambda）。

### 选择哪种方法

| 因素 | Hyperframes | Remotion |
|------|-------------|----------|
| 代理兼容性 | 更好（纯 HTML） | 良好（React） |
| 动画复杂度 | 基础（CSS 过渡） | 高级（Spring、interpolate） |
| 批量渲染 | 本地 | Lambda（AWS）以实现扩展 |
| 学习曲线 | 最小 | 中等（React + Remotion API） |
| 许可证 | Apache 2.0 | 公司许可证（商业使用） |

## AI 视频生成

从文本或图像提示生成原始素材。用于 B-roll、主场景和无法实际拍摄的场景。

### 模型对比

| 模型 | 分辨率 | 最大时长 | 最适合 | 成本 |
|-------|-----------|-------------|----------|------|
| **Veo 3**（Google） | 最高 1080p（4K 变化） | 可变 | 整体质量最高，同步音频 | API 基于收费 |
| **Sora 2**（OpenAI） | 最高 1080p | 最高约 20 秒 | 电影感 + 同步音频，ChatGPT/API 集成 | API + ChatGPT |
| **Runway Gen-4** | 最高 4K | 约 10 秒/生成 | 运动控制、时间一致性、编辑式工作流 | $12-76/月 |
| **Kling 2.5/3.0**（快手） | 最高 1080p | 最高 2 分钟 | 长镜头生成，每秒成本较低 | ~$0.03/秒 |
| **Seedance**（字节跳动） | 最高 1080p | 短片段 | 快速生成，低成本下的强运动保真度，适合批量 | 按信用计费 |
| **Hailuo / MiniMax** | 最高 1080p | 短片段 | 跨镜头角色一致性 | 按信用计费 |
| **Pika 2.x** | 1080p | 短片段 | 快速特效，图像到视频，入门门槛低 | 按信用计费 |
| **Hunyuan Video / Wan 2** | 720p–1080p | 可变 | 开源自托管；完全控制，无 API 费用 | 免费（GPU） |

**快速选择**：
- **最高质量 + 音频**：Veo 3 或 Sora 2
- **批量 / 容量 / 成本**：Kling、Seedance
- **跨镜头角色一致性**：Hailuo
- **自托管，品牌控制**：Hunyuan Video 或 Wan 2（开源权重）
- **故事板 → 视频 工作流**：Runway、LTX Studio
- **从已有静态图像生成视频**：Kling、Pika、Runway

### 视频模型提示

好的视频提示指定：**主题 + 动作 + 摄像机 + 风格 + 氛围**

```
一个特写镜头，显示双手在笔记本电脑键盘上打字，
浅景深，温暖的办公灯光，
摄像机缓慢拉远，展示现代化的工作空间，
电影感调色，4K
```

**常见错误：**
- 太模糊（“一个人在工作”）——添加具体细节
- 忽略摄像机运动——指定推、拉、摇、固定
- 忘记风格——“电影感”、“纪录片”、“商业”
- 在视频中请求文字——AI 模型难以渲染可读文字

**详细提示指南**：参见 [references/ai-video-prompting.md](references/ai-video-prompting.md)

### 使用 AI 生成 vs. 库素材

| 用例 | AI 生成 | 库素材 |
|------|:---:|:---:|
| 想象中的确切场景 | 是 | 很少匹配 |
| 跨片段的一致风格 | 是 | 难以匹配 |
| 可识别的真实地点 | 否（幻觉） | 是 |
| 特定产品/品牌 | 否（使用程序化方法） | 否 |
| 快速 B-roll | 都可以 | 更快 |

## AI 虚拟形象

无需拍摄即可创建讲解视频。AI 虚拟形象以逼真的口型同步、表情和手势呈现你的脚本。

### HeyGen（推荐——拥有 MCP 服务器）

最佳口型同步和微表情。230 多个虚拟形象，140 多种语言。

**代理集成**：HeyGen 拥有官方 MCP 服务器——AI 代理可以直接生成虚拟形象视频。

| 计划 | 视频 | 时长 |
|------|--------|----------|
| 免费 | 每月 3 个 | 最大 3 分钟 |
| 创作者 | 无限 | 5 分钟 |
| 商业 | 无限 | 20 分钟 |

当前价格请查看 [heygen.com/pricing](https://www.heygen.com/pricing)。

**最适合：** 产品解释视频、功能公告、个性化销售外联、多语言内容。

**定制虚拟形象**：上传 2-5 分钟的自我视频来创建数字孪生。看起来和声音都像你，可从文本脚本生成视频。

### Synthesia

全身虚拟形象，具有表现力的肢体语言。内置从 URL/文档生成脚本的功能。

**最适合：** 企业培训、合规视频、专业风格优先的企业演示。

### 使用虚拟形象 vs. 其他方法

| 场景 | 使用虚拟形象 | 使用其他方法 |
|------|:---:|-------------|
| 重复性内容（每周更新） | 是 | — |
| 多语言版本 | 是 | — |
| 规模化个性化外联 | 是 | — |
| 真实创始人内容 | 否 | 拍摄自己 |
| 产品 UI 演示 | 否 | 屏幕录制 |
| 创意/艺术视频 | 否 | AI 生成 |

## 编辑 & 再利用工具

将现有内容转换为多种视频格式。

| 工具 | 功能 | 最适合 |
|------|-------------|----------|
| **Descript** | 基于文本的编辑——通过编辑文本来编辑视频 | 清理采访、播客、网络研讨会 |
| **Opus Clip** | 自动剪辑长视频，评估病毒传播潜力 | 长视频 → 短视频的规模化 |
| **CapCut** | 视觉特效、字幕、平台原生样式 | TikTok/Reels 美化 |
| **Captions.ai** | 自动字幕、眼神接触校正、AI 配音 | 单人讲解内容 |

### 再利用工作流

```
长视频内容（播客、网络研讨会、演示）
    ↓
Descript：清理、去除填充、润色
    ↓
Opus Clip：自动提取 5-10 个最佳时刻
    ↓
CapCut：添加字幕、特效、平台样式
    ↓
分发：TikTok、Reels、Shorts、LinkedIn
```

### 反向工程病毒式剪辑

要复制你欣赏的视频剪辑的*风格*——剪辑节奏、字幕处理、插入、屏幕文字、声音设计——将其分解为可重用的**剪辑规格**（节拍表），并应用于你的素材。使用 **watch-video**（视觉/多模态模式在剪辑点提取帧）或 **social-fetch** 提取参考剪辑的剪辑结构，逐拍输出，并输出 3–5 个使剪辑可识别的标志性动作。执行前（在 Remotion/Hyperframes、CapCut 或 AI 重塑工具中）检查节拍表一次。复制剪辑语法，而非参考的素材/脚本/音乐。完整方法：[references/edit-anatomy.md](references/edit-anatomy.md)。

## 视频制作工作流

### 产品演示视频

1. **撰写**关键功能和价值主张（使用文案写作技能）
2. **屏幕录制**产品流程
3. **程序化叠加**——使用 Hyperframes/Remotion 添加标题、标注、过渡
4. **AI B-roll**——使用 Veo/Runway 生成建立性镜头或生活方式场景
5. **配音**——自己录音或使用 AI 虚拟形象进行旁白
6. **导出**——平台适配的规格

### 解释视频

1. **撰写**问题 → 解决方案 → CTA 弧线
2. **选择讲解人**——AI 虚拟形象（HeyGen）或配音 + 视觉
3. **构建视觉**——程序化幻灯片、屏幕录制、AI 生成场景
4. **添加字幕**——始终添加，为可访问性和参与度
5. **导出**——横向用于 YouTube/网站，纵向用于社交媒体

### 批量社交媒体片段

1. **创建主模板**在 Hyperframes/Remotion 中
2. **输入数据**——产品功能、客户评价、统计数据
3. **批量渲染**——一个模板，多个变体
4. **添加平台特定字幕**通过 CapCut 或 Captions.ai
5. **安排**跨平台发布

## 代理原生视频流程

最强大的设置是直接由代理控制的工具组合：

```
代理撰写脚本（来自产品背景）
    ↓
Hyperframes：生成模板化视频（HTML → MP4）
    和/或
HeyGen MCP：从脚本生成虚拟形象视频
    和/或
Veo/Runway API：生成 B-roll 素材
    ↓
代理组装最终剪辑
    ↓
输出：准备发布的视频
```

**使其成为代理原生的原因：**
- Hyperframes 使用 HTML——任何编码代理都可以生成
- HeyGen MCP 服务器——代理直接调用
- 视频模型 API——标准 HTTP 请求
- 无需手动编辑步骤

## 常见错误

1. **从工具而非策略开始**——在挑选工具前确定你需要什么视频
2. **视频中 AI 生成文字**——模型无法可靠地渲染可读文字；使用程序化叠加代替
3. **恐怖谷虚拟形象**——如果虚拟形象质量很重要，请投资 HeyGen Creator+ 级别
4. **无字幕**——85% 的社交媒体视频是无声观看的
5. **错误的长宽比**——社交媒体 9:16，YouTube/网站 16:9，信息流 1:1
6. **过度制作**——真实往往优于精致，尤其是在 TikTok 上
