从用户指定的范围内，逐个移除破折号和替代破折号使用的连字符，同时保留连字符、范围和有意使用的标记。

## 目标

将每个不应保留的括号破折号替换为其子句实际需要的标记或文字。目标是任何执行括号破折号工作的连字符，无论其确切字符如何：U+2014及其更长的或重新用途的类似字符在页面上看起来都一样。用户拥有范围：一个段落、字段、文件、选择或树。未经询问，不要扩大范围。

## 工作流程

1. **查找**：从用户处获取确切的范围，并定位其中执行括号破折号工作的每个连字符，根据其在句子中的作用，而不是其代码点来判断：任何用于引出旁注、同位语、突然转折或缺失连词的标记。括号破折号（U+2014）是常见的；水平线（U+2015）以及两连字符和三连字符（U+2E3A、U+2E3B）看起来都一样，应一并计算。连字符（U+2013）是边界情况：当它连接可以放置括号破折号的子句时，它会被计算，但当它跨越范围端点时（无论数字范围还是非数字范围，如`1990–2020`、`伦敦–巴黎`路线），它保持不变。执行非括号工作的连字符（连字符、减号、范围）保持不变。将任何真正模糊的情况作为判断，而不是盲目更改。

2. **按角色替换**：根据每个出现的语法角色选择：
   - *旁注*：当被破折号分隔的内容可以从句子中提取出来时，使用逗号或括号。
   - *同位语*：当被破折号分隔的内容命名、定义或扩展其前面的名词时，使用冒号或逗号。
   - *突然转折*：当破折号标记一个转折、中断或重启时，使用句号、分号或逗号。
   - *假连词断句*：当破折号代表缺失的“和”、“但”、“因为”、“所以”或其他真实连接词时，重写句子。

3. **保留**：除非用户明确包含且上下文证明其错误，否则保留不变：
   - 合并词、减号和负数
   - 范围，如`1-10`、`1–10`或`伦敦–巴黎`；范围连字符不是括号破折号
   - 代码、差异、命令输出、标识符、序列化数据、URL、路径、锚点和查询字符串
   - 风格化散文中引用或明显有意使用的括号破折号；这些作为判断出现，永远不会作为盲目突变出现

4. **重读**：替换每个句子后重新阅读。修正不自然的节奏、悬垂标点、重复空格和替换引入的连接词丢失。如果句子现在需要文字而不是标点，重写解决该问题的最小子句。

5. **报告**：说明检查的范围、找到和更改的连字符数量、按角色使用的替换方式，以及保留或作为判断出现的内容。

## 规则

- 不要进行全盘替换。相同的字形在不同的子句中可能需要不同的标点。
- 不要用连字符替换括号破折号作为清理。
- 使用编辑安全进行突变：编辑 Unicode 安全（`PYTHONUTF8=1`）并逐个替换每个连字符，而不是全盘扫除；如果范围内不包含此类破折号，报告“未找到”而不是更改附近标点。
- 保留用户的语气。这项技能在请求时移除标记；它不会在用户拥有的范围内扁平化风格。

## 验证

完成前确认：

1. 范围保持用户所有。
2. 每个替换都是根据语法角色逐个选择的。
3. 保留情况保持未更改或作为判断报告。
4. 报告包括计数和任何判断。
