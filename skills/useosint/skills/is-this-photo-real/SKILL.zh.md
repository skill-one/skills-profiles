# 这张照片是真的吗

验证顺序是整个技巧：**先查来源，后看像素**。找到最早的副本并阅读其说明文字，能解决比所有取证工具加起来还多的问题，而且它能提供你可以展示给别人的证据。像素取证产生的是色彩热图和论点。

初学者的错误是在下载的JPEG文件上运行错误级别分析，并宣布这张照片是假的。第二个错误是寻找深度伪造：绝大多数欺骗性媒体都是**真实片段配上虚假说明**——正确的像素，错误的战争，错误的年份，错误的国家。

## 筛选：你实际上在回答什么问题

| 要验证的声明 | 首先做这个 | 不要做这个 |
|---|---|---|
| "这张照片显示了X事件发生在Y地" | `找到原始照片`，然后 `从像素中定位地理位置` | 任何取证工具。重新构建上下文会完全不留像素痕迹。 |
| "这是一张未经修改的照片" | 信号级分析，在你能获得的最低处理副本上 | 分析截图或平台下载；两者都会破坏信号。 |
| "这个人视频里说过这话" | 来源，然后音视频一致性，然后逐帧检查面部边界行为 | AI检测器分数。 |
| "这张图像是AI生成的" | 缺乏相机物理原理和不连贯的物体结构 | 仅基于检测器结论。 |
| "这张截图是真实的" | 布局、字体和界面版本一致性；如果存在，则检查底层记录 | 图像取证。伪造的截图是在浏览器中制作的，而不是在图像编辑器中。 |

然后始终要问如果声明是真的，这张图像会是什么样子，把它写下来，并专门检查这些方面。验证是在验证假设；寻找异常会失败，因为异常无处不在。

## 方法

1. **获取最好的副本**。每次重新编码、调整大小和截图都会破坏取证信号。追寻原始上传或机构版本，而不是平台版本。给它哈希值，在副本上工作。如果你只有截图，请说明并降低所有下游结论。
2. **来源**。运行 `找到原始照片`；对于视频，提取并搜索关键帧。你需要一个更早的版本、不同的说明文字、摄影师署名，以及通过 `读取已删除页面` 得到的与页面日期相互印证的来源。一个带有不同说明文字的较早副本就足以了结案件。
3. **元数据**。运行 `文件元数据中的秘密`：编辑链、缩略图与图像比较、时间戳不一致性、制造备注是否适合声明的设备。
4. **来源签名**。检查C2PA内容凭证。
5. **内部一致性**。标志语言、车牌、货币、制服、车辆型号、季节、天气和阴影，通过 `从像素中定位地理位置` 与声明的日期和地点进行对照。这是普通侦探工作，比取证更有效率。
6. **物理一致性**。光照、阴影、反射、透视。
7. **信号级取证**。噪声残差、JPEG量化双压缩、克隆检测、色彩滤波器阵列痕迹。容易过度解读，在平台处理的文件上毫无价值。
8. **记录你验证了什么**，而不是一个结论。

## 光照、阴影和几何——支撑不倒的检查

没有工具或你能向编辑或法院解释的推理能免疫于重新压缩。这就是你应该花时间的地方。**阴影汇聚**是最强的。阳光是平行的，所以在透视图像中，从每个阴影的尖端通过它所投射物体的基座画出的线必须相交于一点——光源的投影。画三个或四个。如果一个物体的线拒绝与其他线相交，它可能不在原始场景中；倾斜的地面是混淆因素，所以只使用一个平面。然后：
户外场景的阴影方向和本影硬度应该是一致的；眼睛、玻璃和抛光金属中的高光应该同意光源在哪里；反射必须显示它前面的东西，位置正确且反转；平行线应该汇聚到一个共同的消失点上，人们的眼睛水平与一个地面平面上一致；真实镜头会留下光学特征——一致景深、高对比度边缘处的色差、暗角、随亮度变化的噪声底。在具有这些特征的图像中，没有任何这些特征的元素，在图像的其他地方具有这些特征，是后来添加的。

## 错误级别分析及其为何大多被错误使用

ELA以已知的JPEG质量重新保存图像并显示差异，其理论是不同次数压缩的区域会做出不同的反应。它产生自信的胡说八道的四个原因：它对**内容**有反应，所以边缘和纹理会发光，而平坦的天空和皮肤会变暗，这意味着每张图像都有“可疑的明亮区域”；一次重新保存就会破坏它，所以在社交媒体下载上的ELA描述的是平台的编码器，而不是更早的版本；它无法定位现代编辑，因为内容感知填充、生成式编辑和完整重新保存会留下没有差异历史的痕迹可供寻找；并且在两个方向上都失败，未受影响的图像上的明亮区域和被操纵图像上的干净输出都是常规现象。

它的用武之地：在一个直接来自相机的单代JPEG上，来自不同压缩来源的粘贴区域可以真正显示出来。案例狭窄。将其作为弱输入，仅在最低处理的文件上使用，永远不要将其作为发布结论的基础。更具说服力的亲戚——与相机签名进行比较的量化表比较，以及双压缩检测——也被平台处理击败。

## C2PA和内容凭证

C2PA将一个加密签名的清单绑定到文件，记录捕获和编辑历史。在哪里存在，它是目前可用的最强来源证据，因为它可验证而不是推断性的。一个**有效的**清单意味着签名方断言了这段历史，文件自签名以来未更改，你知道该向谁追究责任——而不是内容是否真实。一张拍摄了舞台场景的已签名照片是一张已签名的照片。

**缺失**几乎意味着什么都没有：大多数相机都不签名，大多数编辑管道都不保留清单，平台在重新编码期间会剥离它们。缺失凭证是默认状态，而不是红旗。IPTC用于标记合成媒体的数字源类型字段，以及特定于模型的不可见水印——正面是你在可以检查的地方的强烈证据，负面只表示未找到某个供应商的标记。

## AI生成——持久的迹象和会过时的迹象

任何基于模型当前弱点的迹象都将被修复。优先考虑基于物理和结构的迹象。

**持久，因为它们需要一个生成器没有的世界模型：** 不可能的照明（不一致的阴影方向、物体下方缺少阴影、主体从没有光源的方向照明）；背景物体的结构不一致（一个不连接的自行车架、栏杆的立柱间距变化、台阶踏板不对齐、一条消失并重新出现的皮带、有图案的织物其图案忽略了褶皱）；文本退化，特别是小、重复或外围文本；接触和遮挡错误，例如一只手围绕杯子但没有包围它，或者脚没有接触地面；缺乏相机物理——没有传感器噪声、没有色差、均匀的焦点，以及高频细节太少（“过度平滑的皮肤”实际上就是如此）；而且没有任何合理的来源。

**会过时——检查，但不要依赖：** 指纹和牙齿计数、耳朵不对称、前景文本混乱、珠宝损坏、可疑对称的面孔。

**检测工具。** 具有不可审计推理的自信分数。它们在压缩、调整大小、放大、重度编辑和低光照的真实照片上产生误报，对新训练数据之外的生成器产生漏报，并且对抗性脆弱——轻微重新压缩就会移动分数。运行多个，将它们视为一个弱信号，永远不要发布一个基于一个结论的结论。如果你的证据是来自网站的百分比，那么你没有任何证据。

## 视频

- **容器和编码器**。`ffprobe -show_format -show_streams` 和 MediaInfo 提供编码器字符串、帧速率、旋转矩阵和轨道结构；典型的平台重新编码值意味着你没有原始版本。`ffprobe -show_frames` 暴露帧类型——重复的帧意味着帧速率转换或插入慢动作，在静态画面中间出现的未解释的关键帧可以标记为拼接，交错或电视电影伪影揭示了没有人提到的管道。
- **生成损失**。块状、色带和蚊子噪声随着每次重新编码而叠加。严重退化的镜头很旧，或者被广泛复制——并且每个信号级测试都无效。
- **音频**。口型漂移、房间声学与可见空间不匹配、环境在摄像机进入室内时没有变化、编辑点处的噪声电平跳跃。大多数伪造视频中最薄弱的环节，也是最不受检查的。
- **面部交换行为**。发际线和下颌处闪烁或模糊，面部光照不跟踪头部运动，牙齿和舌头在说话时退化，面部分辨率与帧不同，在侧面转弯和手遮挡时出现故障。
- **用于反向搜索的关键帧**。视频验证最常见的成果是找到更早的版本。提取命令位于 `找到原始照片`。

## 这哪里出错了

- **每个过滤器都有一个基础率问题**。在一张真实的照片上运行六个取证工具，某物看起来会异常。异常是真实图像的正常状态。
- **平台做了**。调整大小、重新编码、色度亚采样和元数据剥离产生人们归因于操纵的艺术品。在解释任何艺术品之前，确定处理历史。
- **你会拿到最差的副本**——一个重新发布的裁剪截图。大多数信号级分析在它上面都无效，诚实的报告也说如此。
- **“未操纵”不是一个结论**。检测到的操纵的缺失是关于你的测试，而不是关于图像的声明。
- **一张真照片可能完全具有误导性**。选择性构图、舞台场景和带有虚假说明的真实图像都会通过所有取证测试。
- **驳斥会放大**。详细的驳斥会传播原始声明——这是一个值得故意做出的编辑判断。材料有时被故意种植以供发现和驳斥，或者为了看看谁在调查；参见 `在不被制造的情况下进行调查`。
- **根据相似性进行识别**是这里最高后果的错误——因为“这个人Z长得像所以是Z”不是一个发现。

## 置信度分级

分别分级每个声明——一张图像可以有一个确认的来源、一个被反驳的说明和一个未经确认的真实性。

- **确认原始且正确描述**——从可信的来源定位最早的副本，日期独立证实，位置视觉验证，内部细节一致，元数据或几何形状没有矛盾。
- **确认重新构建上下文**——同一张图像有证据表明更早发布了一个不同的、更好的来源说明。这里最常见的积极发现。
- **可能被操纵**——一个具体的、可描述的物理或几何不一致性，你可以指出，最好有插入元素的来源。不是热图。
- **可能合成**——多个持久的生成迹象，没有来源历史，没有与相机一致的压缩或元数据，没有较早的副本。指出迹象。
- **未经确认**——没有找到较早的副本，没有发现任何错误。大多数案件结束的地方。
- **无法评估**——可用的副本对于需要的问题的测试太处理了。说明哪些测试无效以及为什么。

## 工作示例

一段视频流传，显示了一场爆炸，标题是当天对一库名城的袭击。

`yt-dlp` 拉取最好的版本，而不是屏幕录制。`ffprobe` 显示帧速率和编码器字符串是平台重新编码的典型，所以信号级测试被排除——记录下来，而不是哀叹。

在场景变化时提取关键帧。第四帧什么都没击中。第九帧，唯一带有天际线的帧，击中了一个十八个月前在不同国家的新闻网站。十分钟后有初步答案。但较早的页面上的视频更短，所以哪个是父级？嫌疑版本在四秒处有一个硬切和音频噪声电平跳跃，并且切后的环境与可见空间不匹配。添加了音频，而不是视频。

值得记录的死胡同：AI检测器将帧评分为一半可能是合成的。它们是真实广播镜头的重新编码裁剪——正是这些工具欺骗的输入。丢弃。

发现：**确认重新构建上下文**，`读取已删除页面` 证实了较早页面的日期；音频**可能被操纵**；由于可用的副本，底层视频的真实性**无法在信号级别评估**。

**报告标准**。说明你验证了什么，你无法验证什么，以及每个结论基于什么——永远不要一个简单的“假”或“真”。一条可辩护的线读作：*图像至少三年前发布，在新闻网站上，署名摄影师；位置与署名相符，而不是声明相符；没有检测到操纵，但可用的副本是平台重新编码，所以信号级测试没有意义。*“我们的分析表明这是假的”不是。包括你运行的测试及其负面结果、文件的处理历史和你的假设，然后把包交给 `撰写情报简报`。

## 转折点

| 你得到什么 | 发送给 |
|---|---|
| 较早的副本、署名、原始说明 | `找到原始照片` |
| 编辑链、设备、时间戳 | `文件元数据中的秘密` |
| 位置和日期验证 | `从像素中定位地理位置`，`这个在哪里被拍摄` |
| 已删除或更改的源页面 | `读取已删除页面` |
| 发布或种植域 | `谁拥有这个域`，`被动重建域` |
| 放大媒体的账户 | `寻找一个账号`，`从社交媒体获取生活模式` |
| 背后传播的协调网络 | `绘制网络`，`在野外发现漏洞` |
| 媒体中或署名上的知名个人 | `找到任何人` |

## 法律和道德注意事项

在大多数司法管辖区，对知名人士提出伪造指控存在诽谤风险，而“我们的工具说”不是一个辩护。将材料上传到在线取证服务会向这些服务披露，对于某些服务，还会向公共画廊披露——在提交任何敏感内容之前，请检查该工具是否会发布提交内容。如果媒体描绘了犯罪、受害者或亲密内容：最小化副本，不要重新分发，在儿童性虐待材料的情况下立即停止并报告给适当的当局，而不是分析它。参见 [../../ETHICS.md](../../ETHICS.md)。
