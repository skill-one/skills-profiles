# 跟踪飞机和船舶

飞机和船舶通过无线电广播它们的存在，志愿者们用廉价的接收器记录下所有信息。这让你能够追踪大多数民用交通的移动历史，并通过注册信息找到所有权归属。代价是：数据由交通工具自行报告，所以其真实性完全取决于操作者的选择。初学者错误是追踪错误的识别码——尾号、呼号、船舶名称和MMSI都会变化，而ICAO十六进制码和IMO编号基本不会。首先确定耐久的识别码，下游的所有信息才能在名称变更后仍然有效。

## 筛选：你拥有哪个识别码？

| 你拥有 | 解析到 | 原因 |
|---|---|---|
| 尾号/注册码 (`N…`, `G-…`, `D-…`) | ICAO 24位十六进制码 | 注册码会在飞机出售或重新注册时重新分配；十六进制码跟随当前的注册码，但这是追踪器依赖的 |
| 航班号或呼号 | 该航段的特定机身 | 呼号是按航班分配的，并且每天会被不同的飞机重复使用 |
| ICAO十六进制码 | 无需——你已经到了这里 | 耐久的飞机选择器，通过广播发送 |
| 船舶名称 | IMO编号 | 名称会随销售和逃避行为而变化；船体不会 |
| MMSI | IMO编号 | MMSI是由船旗国颁发的无线电身份，在重新船旗时会重新颁发 |
| IMO编号 | 无需——你已经到了这里 | 永久有效，直到船体报废 |
| 车辆照片 | 可见识别码，然后是上述内容 | 目击者照片档案按注册码和名称索引 |

关于哪些识别码是永久有效的，哪些不是的完整说明，请参阅[识别码参考](reference/identifiers.md)。

## 飞机：ADS-B实际工作原理

配备ADS-B Out的飞机每秒广播一次通过GNSS计算出的位置，未加密。任何拥有接收器的人都能听到。聚合器是志愿者接收器网络，所以**覆盖范围是业余爱好者居住的地图，而不是飞机飞行的区域**。

三个字段很重要，并且经常被混淆：

- **ICAO 24位地址**——六个十六进制字符，由国家注册机构从国家分配的块中分配。它是协议中的地址，并且只在重新注册时变化。这是你的选择器。
- **注册码（尾号）**——喷涂在机身上，由国家注册机构分配，会随所有权或国家变化。追踪器通过查找表从十六进制码中推导出它，这就是为什么重新注册的飞机在某些网站上显示*旧*注册码，而在其他网站上显示*新*注册码的原因。
- **呼号**——本次航班传输的内容。对商业交通是航空公司航班号，通常对通用航空是注册码，有时是运营商自己的指定码。按航班分配，作为长期选择器无意义。

传输Mode S但未传输ADS-B位置的飞机仍然可以通过**多边定位**定位，其中多个接收器比较信号到达时间。这需要多个接收器同时听到飞机，所以在低空时效果很差，在密集覆盖范围之外会消失。

### 重要的空白区域

- **海洋、极地航线和人口稀疏地区**没有地面接收器。这些地区的覆盖范围需要基于卫星的ADS-B，而并非所有聚合器都有，并且这通常是一个付费产品。跨大西洋的航班在海洋中消失是正常的，不是发现。
- **军事和国家飞机**经常不广播、间歇性广播，或使用无法解析到注册信息库的识别码。缺席并不能证明其活动。
- **隐私项目**。FAA的“限制显示的飞机数据”项目允许机主请求其飞机不被聚合器接收。隐私地址方案允许符合条件的飞机在指定期间广播临时替代ICAO地址，而不是分配的地址，从而在指定期间内打破十六进制码与注册码的链接。机制也存在，用于从公共注册信息库中隐藏机主详细信息。
- **聚合器以不同的方式尊重屏蔽**。抑制是通过在数据分发层进行过滤来工作的，所以一个基于独立志愿者源的网络可以显示另一个网络隐藏的飞机——并且政策会变化，包括当网站变更所有权时。检查多个来源，并记录你使用的时间和日期。

### 所有权，以及信任问题

国家注册机构将注册码映射到注册机主：FAA注册信息库用于`N`编号，英国CAA注册信息库用于`G-`，其他地方有类似机构。[数据源目录](reference/data-sources.md)列出了值得了解的机构。

期望一个法律实体，而不是个人。注册机主通常是信托、单一目的LLC、租赁公司或银行受托人。在美国这是结构性的：注册要求美国公民身份或资格，所以外国机主通常使用一个机主信托和一个国内受托人。离岸注册机构——马恩岛、阿鲁巴、百慕大、开曼群岛、圣马力诺——主要服务于这个市场，并且它们的缩写本身就是一个信号。公司空壳不是死胡同；它是`who-really-owns-it`的交接。

注册码也会被回收。释放的尾号可以重新分配给不同的机翼，所以与该注册码相关联的旧跟踪或照片可能是不同的飞机。检查注册信息库的历史记录，以获取标记和日期的每个声明。

## 船舶：AIS如何不同，以及为什么这很重要

AIS看起来像海事的ADS-B，并且在唯一重要的方面有所不同：**应答器由船员操作**。位置是GNSS计算得出的，但关闭它是驾驶舱的一个开关，并且大部分有效载荷是手动输入的。

- **A类**应答器对于国际公约规定的大型商业和客运船舶是强制性的，以更高的功率传输，并且更新频繁。**B类**是自愿的，功率较低——小型船只和渔船最多只能部分覆盖。
- **静态数据**（名称、IMO、呼号、尺寸、船舶类型）在安装时配置，并且通常是可靠的。
- **航行数据**（目的地、预计到达时间、吃水深度、航行状态）由船员每次航行时输入，并且经常是错误的：过时的目的地、玩笑条目、空白字段、错误的港口代码。将其视为一个提示——除了吃水深度，两个位置之间没有港口停靠而报告的变化是船舶之间转移的证据。

**变暗是发现**。关闭应答器的船舶，或传输与图像矛盾的位置的船舶，正在做它们不希望归因的事情——这是逃避制裁和暗舰工作的核心行为。在称之为之前，排除良性原因：接收器范围外，卫星重访间隙，拥挤水域的VHF碰撞，以及设备故障都会产生相同外观的空白。

AIS也是**可伪造的**——协议中没有身份验证，所以位置可以被完全伪造，并且有观察记录船舶似乎在陆地上航行或出现在两个地方。在特定海岸线附近的GNSS干扰会破坏诚实船舶的位置。跟踪是一个关于位置的声明，而不是对位置的观察。

地面接收是视线VHF，所以仅限于沿海地区。**卫星AIS**覆盖开阔的海洋，但按轨道重访采样而不是连续采样，在多个传输在一个足迹中碰撞的地方遇到困难，并且通常是一个付费层级。

### 船舶身份和所有权

IMO编号是船体的永久识别码，并且在销售、重命名和重新船旗后仍然有效——这正是逃避行为者重命名和重新船旗的原因，但他们无法摆脱它。MMSI由船旗国颁发，在重新船旗时更改，所以同一IMO的新MMSI是一个重新船旗事件，并有日期。名称可以自由更改。

船旗选择是分析信息。开放注册机构——方便旗——将注册码出售给没有国家联系的机主，并且一个船体通过一系列执法声誉薄弱的小型开放注册机构移动是一个模式。港口国控制检查数据库记录按IMO编号的拘留和缺陷，这是对船舶真实状况的少数独立检查之一。

所有权记录区分注册机主、受益机主、商业经理、技术经理和承租人——通常是不同司法管辖区中的不同实体，注册机主通常是单船公司。将其带到`who-really-owns-it`和`x-ray-a-company`。

## 这与你有什么关系

- **覆盖范围不是真相**。没有数据意味着没有接收器听到它；在地球表面的大部分区域，空白是默认状态。
- **交通工具是来源**。位置来自飞机或船舶自己的导航系统。两者都可能出错，AIS也可能被故意伪造。
- **聚合器的不一致是信息量大的**。不同的接收器网络、屏蔽政策和注册信息快照。当两个网站对飞机的身份有分歧时，这通常指向最近的重新注册或抑制。
- **注册信息是快照**。注册信息基于文件，而不是基于销售，并且存在滞后。当前的提取并不能证明去年控制该交通工具的人是谁。
- **识别码冲突**。注册码会被重新分配；MMSI会被重复使用、复制和伪造；船舶名称根本不唯一。
- **历史轨迹是付费功能**。免费层级显示一个短窗口。如果一个轨迹很重要，立即捕捉它。
- **机身不是乘客**。飞机可以空飞、载员工飞行，并且会被租出去。指定交通工具并不能说明谁在船上。

## 评估发现

- **确认**——位置被不同类型的独立来源证实：显示车辆在特定时间出现在那里的图像、权威记录中的港口停靠、通过`geolocate-from-pixels`地理定位的照片、提交或通知。对于身份，是日期权威的注册信息条目。
- **可能**——来自信誉良好的聚合器的一致的多接收器轨迹，没有任何矛盾，或者一个注册信息与一个次要商业数据库一致的拥有权。
- **未确认**——单接收器或单聚合器轨迹，来自已经怀疑伪造的车辆的任何位置，航行数据字段，推断的目的地，或有意称为空白，但不排除覆盖和设备原因。

除非你能证明在那个时候该区域存在覆盖——例如，其他船舶在整个空白期间都在附近报告——否则永远不要将AIS空白评级为“变暗”。这个检查将发现与猜测分开。

## 实例分析

目标：测试一个说法，即一家公司飞机将高管飞往他们声称从未访问过的管辖区。

从新闻照片中获取注册码。它解析到ICAO十六进制码，但第一个追踪器显示没有任何历史——这是一个有教育意义的死胡同：该飞机在隐私项目中，并且该网站尊重抑制。一个基于未过滤志愿者源构建的社区聚合器有相同的十六进制码和两年的轨迹。

这些显示了一个重复的基地和四个进入相关地区的行程。其中两个有干净的定位日志；其他两个在海上消失数小时，这是覆盖范围，而不是逃避行为。注册信息列出了特拉华州的一个LLC作为机主，所以所有权并不能证明谁在飞行——这需要`who-really-owns-it`。

评级：在仅基于跟踪数据的情况下，两个日期在目的地机场的出现是可能的，并且当出现一张地理定位的目击者照片显示该飞机在那里时，一个日期被确认为确认。谁在船上仍然未知，并且报告为未知。

## 法律和条款

接收这些广播是被动且在大多数司法管辖区合法的——它们是未加密的传输，旨在供公众接收——尽管无线电法规因地区而异，所以在构建接收器之前请检查当地规定。追踪网站是另一回事：抓取它们通常违反其条款，并且其历史档案是许可产品。按提供的API和免费层级使用。

注册信息通常带有重用限制，有时还包括个人机主的家庭地址。这仍然是GDPR和类似体系下的个人数据——不要因为注册信息打印了它就重新发布它。当局正朝着允许机主隐藏个人详细信息的方向发展；将其视为一个合法的选择，而不是绕过障碍。

制裁工作有严格的界限：船舶由IMO编号指定，与指定船舶或其经营者进行的交易在许多司法管辖区承担严格责任，所以请检查当前的指定情况，而不是记忆。追踪私人个人的飞机，与公司或公众人物的公开身份相比，接近这条线——在开始之前要有合理的目标。
