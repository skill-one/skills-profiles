# 谁真正拥有它

注册机构将品牌转化为具有编号、日期、地址和指定人员的法律实体。没有人会首先告诉你的事情：**注册结构因司法管辖区而异，这种差异就是整个游戏。**一个国家免费发布完整的账目、股东名册和董事的出生日期。它的邻国只发布名称和状态代码，其余部分收费。你的研究策略不是“查找公司”——而是“弄清楚这个司法管辖区允许我查看什么，然后围绕差距制定计划”。

第二件事：按**公司编号**而不是名称搜索。编号一旦发出，就会持续存在，贯穿更名、合并和解散。名称则不会。

## 筛选

| 你持有的信息 | 从这里开始 | 原因 |
|---|---|---|
| 名称，未知司法管辖区 | 使用 OpenCorporates 作为跨司法管辖区索引 | 查找候选实体，并告诉你应该去哪个注册机构。不是真相来源 |
| 名称，已知司法管辖区 | 直接使用国家注册机构 | 总是比任何聚合器更丰富、更新 |
| 公司编号 | 发出注册机构的网站 | 持久性、无歧义性，没有名称匹配问题 |
| 美国上市的公司 | SEC EDGAR，包括其跨申报的全文搜索 | 申报内容远远超过任何公司注册机构所持有的内容 |
| 金融市场参与者 | GLEIF 的 LEI 搜索 | LEI 记录包括直接和最终母公司的关系，而大多数注册机构都不包含这些信息 |
| 个人，想了解其公司 | 注册机构中的董事姓名搜索（见下文） | 这是这项技能中最高的价值转换点 |
| 离岸实体 | ICIJ 离岸泄露数据库，加上该司法管辖区发布的信息 | 通常是唯一能够查看封闭注册的方式 |
| 跨境集团 | OpenSanctions 和 OCCRP Aleph 与注册机构一起使用 | 聚合索引捕捉到单个注册机构看不到的关系 |

## 方法

1. **解决实体问题。** 在聚合器中搜索以找到候选实体，然后转到主注册机构并提取规范记录。记录法定名称、编号、司法管辖区、实体类型、成立日期、状态和注册办事处。注意所有以前的名称——你将需要它们进行诉讼和媒体搜索。
2. **拉取申报历史记录，而不仅仅是摘要页面。** 摘要是一个当前状态的视图。申报列表是时间线，而时间线是故事所在的地方。
3. **阅读董事记录。** 姓名、角色、任命和辞职日期、国籍和居住国（如果已发布）、服务地址，以及在某些注册机构中，出生月份和年份——这是一个真正强大的 `find-anyone` 消歧点。
4. **阅读所有权记录。** 股本、股权类别、分配和转让，以及注册机构有时的最终所有权声明。
5. **阅读收费注册。** 收费、留置权、抵押和担保利益会指明受担保的贷款人，而贷款人是人们不会去寻找的对手方。一家没有任何收费和账户的公司显然没有明显的融资。
6. **运行董事转换。** 将每位董事的精确注册规范化名称在董事索引中搜索他们的其他任命。这是将单个实体变成网络的地方。
7. **运行地址转换。** 在注册办事处中搜索注册机构。然后决定地址实际上是什么，然后再进行加权——见下文。
8. **筛选。** 在 OpenSanctions 中搜索实体和每个命名人员。将命中作为审查项目而不是发现；音译名称匹配是嘈杂的。
9. **绘制图表。** 多实体结果转到 `graph-the-network`；完成的图片转到 `x-ray-a-company`。

## 最终所有权，以及它何时失效

最终所有权注册要求公司声明超过某个阈值的自然人在最终拥有或控制该公司的自然人士。轨迹大致上是注册机构向公众开放，然后在几个司法管辖区中，由于隐私方面的法律挑战，重新限制为能够证明合法利益的人。假设访问是条件性的，并在计划之前检查当前模式。

四种结构性失效模式：

- **代理人。** 代理人董事或股东被记录，真实，且经济上无关紧要。在许多地方是合法的。注册是准确的且无用的。
- **信托和基金会。** 它们设置了一个大多数公司注册机构无法穿透的结构。一家由基金会拥有的公司可以有一个技术上完整的声明，但没有可识别的人类。
- **分层。** 跨越四个司法管辖区的一条链，其中每个注册机构只看到自己的链接。它是这样设计的。
- **阈值。** 一个捕获超过某个百分比持有者的注册机构在结构上对每个坐在其下方的群体是盲目的。

当你遇到其中一种情况时，正确的输出是一个记录的终点：“控制追溯到 Y 司法管辖区中的 X 实体，其注册机构不是公开的；声明的最终所有者是 Z，他也是 40 个无关实体的声明所有者，并被评为代理人。” 这是一项发现。

## 注册代理和大量地址

每个司法管辖区都要求一个注册地址，并且存在一个提供地址的成立代理行业。一个地址托管数千家公司是完全正常的。在加权之前，确定它是什么：一家律师事务所或会计事务所托管客户是普通的；一个虚拟办公室提供者是稍微有趣的；一个住宅地址有数百家公司是不普通的。有用的信号不是数量，而是**重叠**——哪些特定的其他实体与你的实体共享董事、申报代理或申报日期。同一天在同一个地址由同一个代理人成立的实体是一批，而一批是值得关注的。

## 离岸司法管辖区和泄露数据

几个司法管辖区几乎什么也不发布：名称和状态，有时甚至不是这些，官员和所有者仅由注册代理持有。对于这些，ICIJ 离岸泄露数据库是一个合法且广泛使用的调研来源。它汇集了几个新闻调查中关于离岸结构的实体、官员、中介和地址，并且通常是唯一能够查看封闭注册的公共途径。

正确使用它。它是一个历史快照，不是实时注册，所以缺席意味着什么，存在是截至泄露。它记录结构，而不是违规行为——离岸成立是合法且普遍的。名称按泄露文件中记录的方式记录，带有由此产生的音译不一致性。将命中视为需要通过申报、法院记录或同期文件进行核实的线索，并在书面文件中谨慎描述它。OCCRP Aleph 将泄露与注册机构和文件索引并列，值得运行相同的名称。

## 董事转换

这里可用的最高价值操作。一个人在各个司法管辖区担任董事的历史揭示了以前的冒险、已解散的公司、反复出现的共同董事以及出现在其他地方的业务关系。

使其发挥作用：在注册机构的规范化董事姓名格式中搜索，而不是你的首选拼写。在允许的情况下，尝试在注册机构中单独使用姓氏。如果注册机构发布出生月份和年份，请使用它——这是区分常见姓名的最佳判别器。搜索以前的和已婚的姓名。考虑音译：一个人可以在三个注册机构中出现在同一名称的三个罗马化版本下，并且没有任何索引将它们链接起来。

然后进行验证。在相同名称下的两个董事职位不是同一个人。通过匹配的出生月份/年份、匹配的服务地址、匹配的共同董事或来自 `find-anyone` 的证实来源来确认。普通姓名的董事转换的误报率是这项技术产生自信错误网络图的主要方式。

## 已解散的公司和历史记录

解散移除了一个实体的法律人格；它通常不会移除其记录。大多数注册机构在解散后保留申报数年，而这些申报通常是调查中最具信息量的，因为它们记录了主要当事人宁愿没有人发现的失败。保留期限各不相同，一些注册机构最终会清除，所以当你找到它们时，存档已解散公司的申报。董事的已解散实体轨迹是公司尽职调查中最强的单一信号。

## 申报日期作为时间线

按时间顺序阅读申报历史记录，然后再阅读任何单个文件。模式携带信息，文件本身不携带：

- 在交易、招标或提案之前不久成立。
- 一组官员辞职，尤其是在申报文件或审计员变更之前或之后。
- 股权转让与注册办事处变更同时发生。
- 从及时申报突然变为迟延申报。
- 一家沉寂的公司突然开始申报活动。
- 申报被倒签或一天内批量提交，这通常意味着代理人正在弥补合规失败。

## 这会出错的地方

- **申报未验证。** 大多数注册员检查完整性，而不是真实性。注册机构记录证明在申报义务下提交了声明。
- **陈旧性是内置的。** 年度申报周期意味着已发布的图片可能落后于现实一年或更长时间，状态字段在解散或恢复后更新缓慢。
- **聚合器滞后并规范化。** 一个跨司法管辖区索引有部分覆盖范围，因国家而异，按自己的时间表更新，并以失去细节的方式规范化名称和角色。在源处确认任何重要事项。
- **双向名称匹配失败。** 法律后缀、标点符号、重音、音译和合并后的更名会导致假阴性；常见姓名会导致假阳性。
- **错误注册错误。** 联邦与州与市注册、外国公司分支机构的单独注册，以及合伙企业、合作社、信托和慈善机构的完全不同体系。找不到实体通常意味着你搜索了错误的注册机构。
- **编辑制度。** 许多注册机构中会抑制住宅地址和完整的出生日期，并且一些注册机构允许个别董事申请保护。被抑制的地址不是隐藏的地址。
- **付费层隐藏了重要文件。** 几个注册机构提供免费摘要，并收取实际重要的申报费用。预算或报告中说你没有阅读它们。

## 置信度评级

- **确认**——在主要注册机构或监管机构提交的文件中声明，检索并注明日期，实体由编号识别。
- **可能**——来自信誉良好的聚合器或 LEI 记录，与主要记录一致，未被反驳。
- **未确认**——从共享地址、共享名称或未经核实的泄露数据集中推断。
- **评估**——你的判断，标记为该名称，例如，董事是代理人。说明依据，并将其与事实分开。

单独评级身份归属与记录本身。申报可以是真实的，仍然不是你的那个人。

## 工作示例

问题：英国供应商的董事控制其他实体吗？

1. 注册机构记录提供了公司编号、一位董事和出生月份和年份。锚点已建立。
2. 精确名称形式的董事索引返回了十一个任命。六个共享出生月份和年份——同一个人。五个不共享，并保留下来。
3. 在六个中，有两个在强制解散后解散。两个的申报历史记录显示在解散前账户逾期。来源和记录。
4. 地址转换在注册办事处返回了大约 300 个实体，但它解析为一家特许会计师事务所。加权低。死胡同。
5. 更好的信号：六个中的两个共享一个*第二个*董事，该董事在 ICIJ 数据库中作为离岸实体的董事出现。记录为线索，评级为未确认，并转到 `find-anyone` 进行证实，而不是作为链接记录。
6. 输出：六个确认的董事职位，两个不利历史，一个未确认的离岸关联，明确标记为该名称。

## 法律和 ToS 注意事项

大多数注册机构数据是公开发布供再使用的，但条件不同：几个国家注册机构施加许可条款、归属要求或速率限制，并且几个注册机构提供官方 API 或批量产品，专门用于防止网络界面抓取。使用它们。董事个人信息是个人信息——住宅地址和完整的出生日期在许多注册机构中受到保护，并且故意规避受保护的地址制度在某些司法管辖区是犯罪行为。最终所有权访问可能需要你声明合法利益；声明你实际拥有的合法利益，并书面声明。泄露数据集是合法的，由新闻机构为该目的发布，但仅基于泄露条目将命名人员描述为违规行为既是证据问题也是诽谤问题。核实，并谨慎写作。
