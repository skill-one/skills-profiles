# 寻找原始图像

目标几乎从来不是“找到匹配项”。它应该是**找到最早的出版物并阅读其页面**。匹配项告诉你图像存在于其他地方；最早的页面则告诉你摄影师、日期、标题和姓名——这才是你实际依赖的关键。

初学者的错误：将完整帧上传到一个引擎，一无所获，然后得出结论说图像未被索引。裁剪到一个独特的对象并重新搜索会发现完整帧搜索无法找到的东西。

## 根据你持有的内容选择引擎

| 你持有 | 从...开始 | 原因 |
|---|---|---|
| 一张脸 | Yandex | 它的索引是基于面部相似性构建的，因此它会返回看起来相同的不同人以及同一人在其他照片中的出现。没有其他通用引擎能做到这一点。 |
| 一张脸，Yandex失败 | 专门的识别人脸引擎（见下文） | 只有在解决了法律和同意问题之后。 |
| 北美/西欧以外的街景 | Yandex | 深度索引俄罗斯、中亚、东欧、土耳其和中国网络内容，而谷歌却未充分抓取。 |
| 产品、书籍封面、艺术品、植物、动物 | Google Lens | 物体和实体识别，与购物和知识图谱相关联。 |
| 图像中的文字 | Google Lens | 它会识别图像帧并让你搜索提取的字符串。通常文字就是答案，而图像搜索则无关紧要。 |
| 地标或著名建筑 | Google Lens | 地标分类是其最强的单一功能。 |
| 混乱照片中的一个特定区域 | Bing 视觉搜索 | 在上传的图像上画一个框，它将仅重新搜索该区域——任何引擎中最快的裁剪和重试循环。 |
| 新闻照片、迷因或任何你怀疑是旧照片的内容 | TinEye | 唯一的主要引擎按最早排序，并且可以可靠地显示*修改*后的副本。 |
| 中文或中国托管的内容 | Baidu 图像搜索 | 其他引擎根本没有的覆盖范围。 |

至少运行三个。它们经常不一致，而这种不一致就是信息：TinEye 从几年前的某个时间点找到确切的副本，而 Lens 只找到最近的转载，这是循环媒体的特征。

### 每个引擎实际在做什么

**Yandex** 基于视觉相似性进行匹配，并具有强大的面部识别组件。它的结果页面将“包含此图像的网站”与“相似图像”分开——只有第一组才是证据。它比其他引擎更能容忍裁剪、旋转和重度压缩。

**Google Lens** 已从整图像重复匹配转向“这是什么，我能卖给你什么”。对于溯源工作，使用列出包含图像的页面的选项，而不是视觉匹配轮播，并预期它会返回视觉上相似但无关的照片，就好像它们是匹配项一样。

**Bing 视觉搜索** 位于两者之间。它的区域选择工具是使用它的原因：无需下载、裁剪、重新上传循环。

**TinEye** 是基于爬取的，并且相对较小——许多图像返回零结果，并且从 TinEye 中消失并不能证明什么。它做的是其他任何东西都不做的东西：精确和近似重复匹配，能够按最早排序，以及检测已被裁剪、色彩偏移或水印的副本，它将它们与你的输入并排显示给你。

## 方法

1. **修复输入。** 获取最高分辨率的副本——文件本身，而不是它的屏幕截图。屏幕截图会添加缩放和重新压缩，这会损失匹配项。在编辑副本之前，先在原始文件上运行 `secrets-in-file-metadata`。
2. **完整帧，所有引擎。** 便宜，有时立即。
3. **裁剪并重新搜索。** 这是整个技能中收益最高的步骤。完整帧的指纹主要由背景主导；紧密裁剪到脸、标志、徽标、车辆、纹身、建筑角落，并分别搜索每个裁剪。转载会被裁剪并重新构图，所以当帧不匹配时，裁剪通常会匹配。
4. **水平翻转。** 镜像是规避自动匹配的常规方式，也是屏幕录制和视频转载的常规产物。翻转并重新运行相同的引擎。
5. **对低质量输入进行预处理和重试**——放大、去噪、校正电平。参见 [reference/preprocessing.md](reference/preprocessing.md)。
6. **对于视频**，提取关键帧并将它们作为静态图像进行搜索。从开始、中间和结束搜索一帧，以及任何包含标志或脸的帧。关键帧命中通常是打破视频案例的关键。
7. **按最早排序。** 在 TinEye 中，按最早排序。然后将该日期视为上限，而不是答案，并转到步骤 8。
8. **阅读匹配页面。** 打开它们。收集：摄影师署名、代理机构、标题、命名人物、页面日期、图像 URL 中的文件名（通常是 `2019-04-city-event-03.jpg`），以及任何周围的文章文本。这是选择器所在的地方。

## 确定首次发布，而不仅仅是匹配

最早已知的副本日期是对你的搜索覆盖范围的声明，而不是对世界的声明。为了巩固它：

- 检查匹配页面的日期与 `read-deleted-pages` —— 存档在页面实际存在时对 URL 边界的第一次捕获，并且页面的显示日期可能会由其 CMS 向前或向后调整。
- 使用 `google-like-a-spy` 的日期限制搜索运算符来查找同一事件或标题的更早的文字提及。
- 查找同一图像的更高分辨率版本。最高版本通常最接近源；通讯社的副本通常比推特转载的副本更大。TinEye 的最大图像排序在这里很有用。
- 检查明显的图库。一张照片被归功于三个不同国家的不同新闻事件是图库，而“原始”是一个许可页面。
- 图像帧中的水印和代理机构缩写比任何索引都更有说服力。裁剪水印并单独搜索它。

## 针对特定人脸的引擎以及何时不使用它们

PimEyes 和 FaceCheck.ID 爬取开放网络上的脸并进行生物特征相似性匹配。它们会发现普通引擎不会发现的人。它们也带来了真正的风险：

- 面部模板在 GDPR 第 9 条下是**生物特征数据**——需要明确的法律依据的特殊类别，而不仅仅是合法利益。伊利诺伊州 BIPA 和德克萨斯州 CUBI 制定了在未经书面同意的情况下收集生物特征标识符的私人权利和法定损害赔偿。
- PimEyes 自己的条款将其定位为搜索**你自己的**脸的工具，并提供了一个选择退出选项。将第三方脸通过它运行违反了这些条款，无论你的意图如何。
- Search4Faces 索引来自俄罗斯社交平台的脸，并且在主题的足迹是 VK 或 Odnoklassniki 时是实际的选择。

在拥有文件授权或合法保护目的时使用人脸搜索——在欺诈案件中核实交易对手、在主题同意的情况下进行身份验证、失踪人员工作或检查你的风险。不要用它来从照片中识别陌生人，将名字与抗议人群中的人脸关联起来，或定位私人个人。在案例文件中注明你运行了它以及原因。并且将人脸引擎的命中视为**未经确认**——相似性假阳性很常见，并且该引擎没有给你审计的理由。

## 哪里会出错

- **相似不等于相同。** 每个引擎都将“包含此图像的页面”和“看起来像此图像的图像”混合到一个视觉网格中。只有第一组才是证据。通过打开它并比较像素级细节来确认候选者——手的姿势、布料的折痕、反射。
- **缺席是默认值，而不是发现。** 未索引、新发布的、登录受保护的、仅限应用的图像返回零结果。“四个引擎都没有结果”意味着图像不在这些索引中，这是原创性的弱证据，并且对真实性没有任何证据。
- **图库照片污染归属。** 出现在四十个无关网站上的“CEO”头像是一个图库模型，使用它的实体可能是假的——这本身就是一个发现，而且是一个很好的发现。
- **AI 生成的图像没有起源可寻。** 零匹配加上生成性提示是一个独特的后果；把它交给 `is-this-photo-real` 而不是得出照片是未发表的原创品的结论。
- **引擎重写历史。** 结果不可重现：索引会删除页面，结果会重新排序，你上周找到的命中可能已经消失了。屏幕截图结果页面并立即存档匹配 URL。
- **裁剪会误导。** 草地或天空的裁剪会返回数千个自信但无意义的匹配。裁剪到*不寻常*的东西，而不仅仅是存在的东西。
- **你可能会泄露。** 将客户的图像上传到商业引擎会向该供应商披露它，并且可能会使你的兴趣去匿名化。对于敏感材料，搜索一个省略了识别细节的裁剪——或者不搜索。参见 `investigate-without-getting-made`。

## 置信度分级

- **确认原始来源**——你有一个早于所有其他副本的页面，由一个合理的来源托管（摄影师、代理机构、主题自己的账户），页面上的日期得到独立存档捕获的证实，并且不存在更大的或更早的版本。
- **可能**——最早的副本在引擎中一致，并且主机合理，但日期仅依赖于页面的自身声明，或者存档没有该时期的捕获。
- **仅匹配**——你可以证明图像在给定日期和 URL 出现。确切地说。不要将其升级为“原始”。
- **未经确认**——视觉相似性而没有像素级验证，或者是一个人脸引擎的命中，或者是一个你无法重现的单一引擎的结果。

## 工作示例

一个账户发布了一张标题为“今天早上警察突击，[城市]”的照片。

完整帧在 Lens 中：只有通用的抗议警察图库。Yandex：十几个相似的警察照片，没有一个匹配。TinEye：没有结果——我注意到这无信息量，因为 TinEye 的索引很小。

裁剪到肩部补丁，在 Bing 中使用区域选择重新搜索。它被识别为来自与标题声称不同的国家的市属力量。

裁剪背景中的商店招牌，在 Lens 中 OCR，并搜索商号作为文本。两个命中，都是该国另一条街道。图像搜索本身是死胡同——但*文本*选择器找到了它。

回到 Yandex 与商店裁剪：三年前的新闻画廊，同一条街道，同一个商店遮阳篷，相同的障碍物排列。摄影师署名。存档显示在声明的日期后两天捕获了该画廊页面，这证实了它。

结论：**确认**这张图像是在声称的事件多年前、在另一个国家发布的。重新语境化，而不是伪造。将位置交给 `geolocate-from-pixels`，将摄影师署名交给 `find-anyone`。

| 你得到什么 | 发送给 |
