# 我完成了什么

## 触发条件

需要一个简短、高信号的工作完成总结，时间范围为特定时间段（例如：昨天、过去3天或上周）。

## 工作流程

1. 将请求的时间窗口解析为具体日期。
2. 读取当前git用户邮箱在该时间段内撰写的提交记录。
3. 排除合并提交和未提交的变更。
4. 将最重要的已发布变更综合为简洁的状态更新。
5. 在最终总结中包含实际使用的日期范围。

## 指导原则

- 保持高度简洁和信息密集。
- 优先突出实质性的行为或架构变更。
- 忽略纯美化性变更（格式调整、导入、轻微重命名）。
- 不推断意图或动机，仅描述变更的功能性影响。

## 输出

- 一条适合状态更新的简短总结
- 实际日期范围
- 可选：仅针对重大变更的2-5个要点
