# 保护上下文窗口

上下文窗口在会话中是有限的且不可再生的。每个 token 都应该物有所值。

**原因：** 上下文溢出会降低推理质量，产生压缩伪影，并中断进程。

**模式：**
- **隔离大型有效载荷。** 将冗长输出、截图和大文档路由到子代理。主上下文获取的是摘要，而不是原始数据。
- **保持常用内容内联。** 每次调用都使用的模板和参考资料应放在技能文件中，而不是每次读取都耗费成本的独立文件中。
- **分阶段控制并限定范围。** 限制每个阶段的文件数量，设置回合预算，考虑机制成本。
