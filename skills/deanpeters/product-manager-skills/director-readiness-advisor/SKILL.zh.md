## 目的

使用自适应问题和针对性指导，引导产品经理（PM）和总监（Director）应对PM到Director过渡过程中的具体挑战。诊断您在旅程中的位置，并提供基于实战经验、针对您情况的实用指导——而不是通用的领导力建议。

这不是一个准备就绪清单。这是一次指导对话，它指出了实际困难之处、为什么困难以及如何解决这些问题。

## 输入

**最适合：** 您在PM到Director旅程中的位置：准备过渡、面试、新上任，或在经历艰难开局后重新调整。
**也很有用：** 您的组织背景（团队规模、您将向谁汇报）以及您感受到的具体阻力。

在调用本身提供的任何内容——技能名称后的文本、粘贴的上下文摘要或附加的`ARGUMENTS:`行——都视为已给出的答案。使用它并跳过它所涵盖的内容；不要重复提问。

**空手而来？那也没关系。** 顾问会先询问哪个四种情况描述了您，然后进行分支。

**示例调用：** `我担任Director角色60天了，我以前的同事现在向我汇报——这很尴尬，我仍在做PM工作。指导我。`

## 关键概念

### 四种过渡情况

PM到Director的过渡根据您所在的位置而有所不同：

1. **准备过渡** — 仍然是PM，积极发展为Director角色
2. **面试Director职位** — 在积极的内部晋升或外部工作搜索中
3. **新上任** — 最近被提升或被聘为Director（前6个月）
4. **重新调整** — 担任Director一段时间了；某些方面没有按预期发展

每种情况都有不同的指导重点。最大的错误是将“新上任”的建议应用于担任该职位两年的员工，或“准备过渡”的建议应用于正在面试过程中的员工。

### 底层模型

此技能直接借鉴了Altitude & Horizon框架——有关完整思维模型的`skills/altitude-horizon-framework/SKILL.md`，请参阅。在此处使用的核心概念：
- 高度（范围）和时间（视野）作为两个轴的变化
- 服务员与餐厅经营者之间的区别
- 四种过渡区域：思考高度、角色转变、英雄综合征恢复、方向创建
- 命名的失败模式：英雄综合征、对流程过敏、讨好型领导力、即时满足陷阱

## 应用

此交互式技能会问**1个诊断问题+最多3个自适应后续问题**，然后根据您的情况提供**3-5个编号的针对性建议**。

---

### 第0步：会话开始

**代理说：**

在开始之前，您可以选择如何运行此会话：

1. **指导** — 我会一次问一个问题，并根据您的答案构建建议（大多数情况下推荐）
2. **上下文摘要** — 提前分享您的情况，我将直接进行指导
3. **最佳猜测** — 告诉我什么也不说；我将为您提供最常见过渡情况（新上任的Director，0-3个月内）的最高价值建议

---

### 问题1：您在哪里？

**代理问（Q1/3）：**

“您在PM到Director旅程中处于什么位置？”

1. **准备过渡** — 仍然是PM角色，积极发展为Director
2. **面试Director职位** — 在积极的内部晋升或外部工作搜索中
3. **新上任** — 最近被提升或被聘为Director（大约前6个月）
4. **重新调整** — 担任Director一段时间了；某些方面没有按预期发展

**或者直接描述您的情况。**

---

### 分支1：准备过渡

#### 问题1B（Q2/3）：

**代理问：**

“在过渡之前，您最想缩小哪些差距？”

1. **思考高度** — 我仍然倾向于直接解决客户问题，而不是设计系统
2. **利益相关者导航** — 我在组织政治、高管动态或跨职能影响力方面遇到困难
3. **战略叙事** — 我还无法在与管理层的对话中令人信服地将我的工作与公司战略联系起来
4. **方向创建** — 我等待上级的清晰指示，而不是为我的团队创建方向

**或者描述您的主要发展领域。**

#### 问题1C（Q3/3）：

**代理问：**

“您的准备时间有多长——您距离过渡有多近？”

1. **6个月以上** — 有意识地构建；没有立即压力
2. **3-6个月** — 开始表明准备就绪；准备与我的经理进行谈话
3. **积极申请** — 目前正在行动中，正在面试或即将进行

**或者描述您的时间表。**

#### 分支1建议：

**代理提供（基于1B + 1C）：**

*示例输出，1B = 战略叙事 + 1C = 3-6个月：*

“根据您的差距（战略叙事）和时间表（3-6个月），以下是最具杠杆效应的步骤：

1. **重新调整您的1对1对话** — 从报告战术进展转变为提出战略问题：'我的工作如何与今年业务的目标相联系？我看不到的组织背景是什么？' 这同时建立了战略思维肌肉，并向您的经理发出了准备就绪的信号。

2. **现在建立您的级联习惯** — 从上一个QBR或全体会议中选择一个公司优先事项，并写下一页的翻译：您的团队的工作如何与之联系？非正式地与您的经理分享。您不需要许可来练习这项技能。

3. **审计您的英雄综合征** — 跟踪未来两周：您有多少次跳进来解决别人可以用您的指导来解决的问题？拯救与发展的比率是Director准备情况的领先指标。

4. **不要过度关注Director思维** — 仍然是PM时最常见的错误：在当前角色上花费过多精力进行高度/视野思考，而忽略了服务当前角色。充分扮演您的PM角色。Director准备情况将体现在您工作的质量上，而不是超出您水平的表现。

选择一个数字深入了解任何这些，或询问特定内容。”

---

### 分支2：面试Director职位

#### 问题2B（Q2/3）：

**代理问：**

“您的面试背景是什么？”

1. **内部晋升** — 在我目前的公司中被考虑
2. **外部搜索** — 在新公司面试
3. **两者都有** — 同时进行内部和外部流程

#### 问题2C（Q3/3）：

**代理问：**

“您在面试准备中最想解决什么？”

1. **内化框架** — 我希望深入理解Altitude & Horizon模型，以便我能流利地表达它，而不仅仅是背诵它
2. **构建我的故事** — 我理解这些概念，但难以将它们与我的个人经验联系起来
3. **练习回答** — 我想使用此框架练习回答可能的Director面试问题
4. **识别我的差距** — 我想知道我尚未展示的过渡区域，以及如何诚实地解决它们

**或者描述您最需要什么。**

#### 分支2建议：

**代理提供（基于2B + 2C）：**

*示例输出，2B = 外部 + 2C = 练习回答：*

“最有效的Director面试准备不是记忆答案——而是内化思考，使其自然流露。这两个技能是您的准备工具：

1. **将`altitude-horizon-framework`作为学习会话** — 不要只是阅读它。在每个部分后，暂停并回答：'我在自己的工作中曾在什么高度或视野下操作？我的故事是什么？' 四种过渡区域和命名失败模式几乎直接映射到常见的Director面试问题。

2. **将此顾问作为模拟运行** — 即使您已经在面试，也要完成分支1（准备）。它提出的发展步骤是面试官探查的肌肉。如果您无法完成这个练习，您还没有建立答案。

3. **为每个过渡区域构建一个故事** — Altitude & Horizon框架给了您四个区域；您至少需要一个具体、具体的故事来描述每个区域。使用区域名称作为结构：'这里是我必须调整思考高度的时候...这里是什么触发了角色转变...这里是我必须创建方向而不是等待的时候。' 面试官会立即识别这种自我意识。

4. **用Director语言重新调整您的PM成就** — 您几乎肯定有这方面的经验；只是表述方式不对。不要以“我发布了X”开头。以：'我的团队面临的最战略性问题是什么[X]。以下是我如何考虑产品组合权衡...' 使用功能或成果作为证据，而不是作为标题。

5. **为差距问题诚实准备** — 如果您还没有管理直接报告人员、没有管理预算或没有在产品组合级别操作，不要回避它。最强大的答案是：'这里是我的差距，这里是我如何发展的，这里是我将在前90天内专注于学习的内容。' 诚实加计划比回避要好得多。

选择一个数字深入了解，或描述您想练习什么。”

---

### 分支3：新上任

#### 问题3B（Q2/3）：

**代理问：**

“您目前最紧迫的挑战是什么？”

1. **仍然像PM一样思考** — 我仍然倾向于直接解决问题，而不是指导他人解决问题
2. **英雄综合征** — 我知道我应该让我的团队拥有事情，但我无法停止跳进来
3. **方向不明确** — 我在等待上级的清晰指示，但指示没有到来，我的团队在漂泊
4. **利益相关者转变** — 我仍然与错误的人关系密切——与工程师相处的时间太多，而与同辈和高管相处的时间太少

**或者描述最紧迫的挑战。**

#### 问题3C（Q3/3）：

**代理问：**

“您在Director角色中有多长时间了？”

1. **不到1年** — 仍在过渡期
2. **1-2年** — 过了过渡期；这感觉像是一种持续的模式
3. **2年以上** — 在角色中已确立；这已成为一个结构性问题

#### 分支3建议：

**代理提供（基于3B + 3C）：**

*示例输出，3B = 方向不明确 + 3C = 继承团队：*

“在没有明确方向的继承团队是新上任Director在前90天内最常见的失败模式。以下是应该做的事情：

1. **本周运行级联上下文图** — 不要等待上级的完美清晰。取最近听到的公司优先事项（QBR、全体会议、您经理提出的明确目标），并将其向下翻译：这对您的业务单元、产品组合、团队的具体责任意味着什么？一页纸。分享它。在您了解更多信息时进行修订。

2. **立即重新调整您的1对1对话** — 大多数继承团队将使用1对1对话来向您简要介绍功能状态和战术优先事项。重新定向：'我想了解您的每个产品如何与我对业务目标负责的通过线相联系。帮助我看到这条主线。' 这从第一天就建立了高度。

3. **明确地向您的团队命名模糊性** — 不要假装您有您没有的清晰度。'我仍在构建领导层希望我们去的方向图。这是我目前的最佳翻译。我将在两周后更新它。' 团队宁愿有诚实的部分背景，也不愿沉默。

4. **在您理解之前不要急于重新组织** — 对于继承团队，本能是重新组织流程和结构以反映您的想法。等待60-90天。了解什么在起作用以及为什么再改变它。房间里的小猴并不总是错的——其中一些人建立了这个地方。

选择一个数字深入了解，或描述什么阻碍了您。”

---

### 分支4：重新调整

#### 问题4B（Q2/3）：

**代理问：**

“核心阻力是什么？在角色感觉最破败的地方在哪里？”

1. **我仍然像PM一样行动** — 我无法放手战术工作；我正在与我的团队一起做IC工作
2. **我的团队没有表现出色** — 我手下的PM们没有成长；质量和交付不一致
3. **我的高管关系不起作用** — 我没有得到所需的可见性、信任或支持
4. **我没有产品组合清晰度** — 我的产品组合缺乏连贯的战略；我管理的是一系列路线图，而不是一个系统

**或者描述什么不起作用。**

#### 问题4C（Q3/3）：

**代理问：**

“您在Director角色中有多长时间了？”

1. **不到1年** — 仍在过渡期
2. **1-2年** — 过了过渡期；这感觉像是一种持续的模式
3. **2年以上** — 在角色中已确立；这已成为一个结构性问题

#### 分支4建议：

**代理提供（基于4B + 4C）：**

*示例输出，4B = 仍然像PM一样行动 + 4C = 1-2年：*

“在12个月以上担任Director后仍然做IC工作的Director没有过渡——他们已经陷入了一个不可持续的混合角色。以下是诊断和修复：

1. **精确命名英雄综合征模式** — 跟踪未来两周：您有多少时间花在解决问题而不是开发能够解决问题的人身上？大多数处于这种模式的Director的IC工作时间在60-70%。目标是更接近20%。

2. **识别是什么让您陷入其中** — 通常有三个原因：(a) 您信任自己的判断胜过团队的判断，(b) 团队还没有发展得足够好，没有您就无法拥有事情，(c) 您正在获得强化IC行为的奖励信号（表扬、可见性）。是哪一个？

3. **为您的顶级3个IC活动创建一个明确的交接** — 列出您最常做的三个PM应该拥有的事情。对于每个：写下“做得好”的样子，与PM讨论拥有它，然后在他们遇到困难时不要救援。通过失败进行指导是这项工作。

4. **改变奖励循环** — 作为PM时得到的表扬不会作为Director得到。Director的成功更安静、更延迟。找到新的信号：一个PM独自完成困难的利益相关者对话，一个团队创建自己的上下文级联，一个您做出的产品组合决策在压力下经受住考验。开始注意到这些胜利。

5. **如果这种模式在1-2年后根深蒂固，请考虑角色是否适合您** — 有些人作为高级IC或Principal PM更快乐、更有效。这不是失败——这是自我认知。IC路径是合法的；停留在Director角色中而像PM一样运作是不匹配的。

选择一个数字深入了解，或告诉我您想解决什么下一个问题。”

**代理输出：** 一对一重新定义策略、级联习惯养成练习、英雄综合征审计，以及在担任产品经理期间仍需警惕过度依赖总监思维。

## 常见陷阱

### 陷阱 1：将准备视为清单
**症状：** 询问“我需要做些什么才能晋升？”并像处理任务一样逐项解决

**后果：** 你会优化看似准备就绪的表象，而不是真正锻炼能力。面试官和管理者能分辨出其中的差异。

**解决方法：** 使用此顾问工具来识别对你情况最重要的一个或两个具体行为改变，而不是一个全面的发展计划。

---

### 陷阱 2：错误识别你的情况
**症状：** 当你实际上处于活跃的面试过程中时选择“准备中”，或者当你已经担任该职位18个月时选择“新入职”

**后果：** 你会得到针对错误情况的指导。

**解决方法：** 对你实际所处的阶段保持诚实，而不是你希望达到的阶段。

---

### 陷阱 3：寻求许可
**症状：** 询问此顾问你是否“准备好”进行过渡

**后果：** 没有准备就绪的测试。过渡是一个决定，而不是一个毕业。

**解决方法：** 使用这项技能来识别对你来说最困难的具体内容以及如何应对——而不是获得通过/不通过的评判。
