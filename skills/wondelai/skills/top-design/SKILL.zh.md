# 顶级设计：获奖数字体验

创建达到世界级数字代理机构水平的网站和应用程序。这项技能体现了那些持续赢得FWA、Awwwards、CSS设计奖和Webby奖的工作室的工艺。

## 核心原则

**每个像素都是有意为之的——没有默认设置，没有偶然。** 你所效仿的代理机构——Locomotive、Studio Freight、AREA 17、Active Theory、Hello Monday——共享着共同的基因：字体即设计，运动创造情感，留白是一种武器，性能是不可协商的（60fps或不要）。

**基础：** 8/10和10/10之间的差距不是技能——它是意图。8/10有良好的字体和流畅的动画；10/10有让你惊叹的字体和讲述故事的动画。每个决策都必须回答：“这服务于体验，还是仅仅在填充空间？”

## 评分

**目标：10/10。** 使用下面的评分标准对任何数字体验进行0-10评分——10/10的体验会在Awwwards上展示。始终说明当前分数以及达到10/10所需的特定改进。

### 评分标准

| 分数 | 等级 | 描述 |
|------|------|------|
| **0-2** | 业余 | 默认字体，没有层次结构，通用布局，模板感 |
| **3-4** | 基础 | 良好的字体，一些层次结构，但令人难忘 |
| **5-6** | 称职 | 良好的基础，干净的执行，但缺乏灵魂 |
| **7-8** | 专业 | 强大的字体，有意为之的运动，明确的观点 |
| **9** | 杰出 | 签名时刻，难忘的细节，近乎完美的工艺 |
| **10** | 世界级 | 会赢得Awwwards每日最佳，定义了新标准 |

### 类别评分（每个0-10）

**字体排版（权重：25%）**
| 分数 | 标准 |
|------|------|
| 0-3 | 系统字体，统一比例，默认追踪 |
| 4-6 | 高级字体，一些比例对比，基本层次结构 |
| 7-8 | 剧烈比例对比（10:1+），完美的追踪，光学对齐 |
| 9-10 | 字体排版即设计——令人惊叹的时刻，自定义/可变字体，字体作为建筑 |

**视觉构图（权重：25%）**
| 分数 | 标准 |
|------|------|
| 0-3 | 一切居中，等间距，刚性网格，没有张力 |
| 4-6 | 一些不对称，不错的间距节奏，基本深度 |
| 7-8 | 有意为之的网格中断，分层元素，强大的负空间 |
| 9-10 | 磁性构图，意外的比例变化，呼吸和惊喜的元素 |

**运动与交互（权重：20%）**
| 分数 | 标准 |
|------|------|
| 0-3 | 没有动画或默认/线性运动 |
| 4-6 | 基本过渡，一些滚动效果 |
| 7-8 | 自定义缓动，协调的揭示，有目的的视差 |
| 9-10 | 讲述故事的运动，完美的时机编排，滚动感觉被发明 |

**颜色与氛围（权重：15%）**
| 分数 | 标准 |
|------|------|
| 0-3 | 随机颜色，纯黑/白，没有情绪 |
| 4-6 | 一致调色板，一些氛围 |
| 7-8 | 颜色感觉被掌控，上下文变化，有意为之的对比 |
| 9-10 | 颜色感觉为这个项目被发明，可以感受到的氛围 |

**细节与工艺（权重：15%）**
| 分数 | 标准 |
|------|------|
| 0-3 | 默认光标，没有悬停状态，通用一切 |
| 4-6 | 基本悬停状态，一些自定义元素 |
| 7-8 | 磁性按钮，品牌选择颜色，如果用户批准，自定义光标 |
| 9-10 | 考虑了每个微细节——焦点状态，加载，空状态，滚动指示器 |

### 快速评分公式
```
总分 = (字体排版 x 0.25) + (构图 x 0.25) + (运动 x 0.20) + (颜色 x 0.15) + (细节 x 0.15)
```

## 10/10设计的七根支柱

### 1. 字体排版作为建筑

**核心概念：** 字体排版不是设计上的装饰——它是设计本身。你的字体、比例和追踪决定了颜色情绪、动画风格、间距节奏和整体个性。

**为什么有效：** 剧烈的比例对比创造了即使在模糊或从远处看到时也能传达层次结构。纪念碑式展示字体和亲密正文之间的张力是让人们停止滚动的原因。

**关键洞察：**
- 巨大的比例对比是不可协商的——显示和正文之间最小10:1（例如，180px / 14px）；极端视口填充的字体
- 大字体的负追踪（-0.02em到-0.05em）将显示紧密地组织成协调的单位；正文需要充足的行高（1.5-1.7）
- 字体选择定义了等级——高级字体铸造（Pangram Pangram，Dinamo，Grilli Type，Klim，Commercial Type）或高质量的Google替代品（Space Grotesk，Instrument Serif，Fraunces）；永远不要Inter，Roboto，Arial或system-ui用于英雄体验
- 可变字体允许在悬停时进行权重动画，而不会导致布局偏移
- 光学对齐优于数学对齐——视觉调整，而不仅仅是数字调整
- 控制标题的每一行换行——漂亮的换行需要关键断点处的手动干预

**应用：** 视口填充的显示硬降至正文（Locomotive英雄）；可变字体与悬停权重动画（Studio Freight）；极比例对比的衬线/无衬线字体搭配（AREA 17编辑）。显示=一个声明，3-7个字；正文=最小16-18px，45-75个字符的度量。

选择字体或构建字体比例时查看[参考资料/字体排版.md](references/typography.md)——按风格命名的字体搭配，完整的流体`clamp()`和基于步骤的比例，追踪/行距阶梯，以及字体子集/FOUT机制。

### 2. 布局与构图

**核心概念：** 精通网格，以便你可以有意为之地打破它——每个违规行为都应该感觉是故意的，而不是偶然的。密度和呼吸空间的节奏创造了吸引注意力的阅读体验。

**为什么有效：** 白空间是积极的设计材料，它创造了张力和控制节奏。不对称产生了视觉能量，而居中构图无法做到；有意重叠或溢出的元素感觉生动而自信。

**关键洞察：**
- 白空间作为武器——业余爱好者填充每个空白；10/10设计师使用空白来创造控制眼睛的张力
- 不对称平衡产生兴趣——将元素从中心偏移，让图像超出容器
- 意外的比例变化创造节奏——交替巨大/亲密，密集/稀疏以叙事节奏
- 网格悖论——一个强大的底层网格是什么让打破有意义；没有它，打破是混乱

**应用：** 偏移标题与溢出图像（`margin-left: 8.33%；margin-right: -5vw`）；不同卡片大小有意为之的不对称（Locomotive展示）；重叠元素以产生深度（Active Theory）。交替全宽沉浸与包含阅读部分。

**道德边界：** 布局实验绝不能牺牲导航清晰度——用户必须始终知道他们在哪里以及如何继续前进。

选择[参考资料/布局系统.md](references/layout-systems.md)时布局部分或响应式——网格框架，断点系统，以及不对称/溢出元素模式。

### 3. 运动与动画

**核心概念：** 每个动画都必须回答“为什么它会移动？”精英运动的三个定律：意图优于装饰，自定义曲线（永远不要线性），编排优于孤立。

**为什么有效：** 编排的运动引导注意力，传达层次结构，并创造情感共鸣。自定义缓动曲线给运动一种物理质量，默认浏览器缓动无法实现。

**关键洞察：**
- 自定义缓动是强制性的——`ease`，`ease-in`，`ease-out`，`linear`是被禁止的；使用`cubic-bezier(0.16, 1, 0.3, 1)`（指数输出），`cubic-bezier(0.25, 1, 0.5, 1)`（四次方输出），`cubic-bezier(0.87, 0, 0.13, 1)`（指数输入输出）
- 页面加载遵循严格的编排——结构（0-200ms），英雄标题字词交错（200-600ms），副标题（400-800ms），导航级联（600-900ms），支持元素（800-1200ms）；参考典当所的每个元素的典型交错值
- 相互关系动画，而不是孤立动画——一起移动的元素感觉协调和有意为之
- 60fps是不可协商的——如果动画掉帧，简化或删除它

**应用：** 编排交错页面加载揭示（Studio Freight）；剪影/遮罩图像滚动进入时的揭示（AREA 17）；悬停权重变化和磁性按钮（Dogstudio）。文本行单独向上滑动——永远不要作为一个块淡入；页面变形而不是切割。

**道德边界：** 运动绝不能阻止交互或引起运动病——尊重`prefers-reduced-motion`，保持所有内容在没有动画的情况下可访问，并证明任何超过1.2秒的东西。

选择[参考资料/动画模式.md](references/animation-patterns.md)时实施运动——可复制粘贴的滚动揭示，交错加载编排，页面过渡，以及磁性/悬停微交互的代码。

### 4. 颜色与对比

**核心概念：** 颜色应该感觉是为每个项目发明的——永远不要从通用的调色板生成器中提取。三种方法：单色紧张（95%一种颜色，5%强调色），大胆签名（拥有自己的组合），上下文变化（调色板响应内容）。

**为什么有效：** 颜色在阅读一个字之前就创造了氛围。纯黑/白感觉数字而缺乏生气；温暖的变体感觉物理和经过考虑。有节制的强调色精确地吸引眼球到预期的位置。

**关键洞察：**
- 永远不要使用纯黑或纯白——#0a0a0a和#fafaf9有一种物理质量，而#000/#fff缺乏
- 建立功能层次结构——文本主要，文本次要（60%不透明度），文本第三（40%），表面，边框（10%）以保持深度
- 一个强大的强调色使用有限（#ff4d00或类似）比复杂的彩色调色板更好
- 上下文颜色变化在部分之间创建视觉章节
- 设计系统以适应亮和暗环境，而不是单个实例

**应用：** 单色与签名强调色（Locomotive：奶油色+黑色+橙色火花）；每个案例研究的上下文颜色变化（AREA 17）；暗模式与一个生动的强调色（Stripe：海军蓝+紫色）。从CSS自定义属性（`--color-dark/-light/-accent`加上功能`--color-text-primary/-surface`）驱动一切；强调色仅在CTA，链接和单个细节时刻出现。

选择[参考资料/案例研究.md](references/case-studies.md)时，如果您需要任何支柱的示例——按机构分解的真实颜色系统，字体处理和微交互，以逆向工程。

### 5. 基于滚动的设计

**核心概念：** 滚动是网络的主要交互，应该感觉是设计的，而不是默认的。将滚动视为一个叙事工具——控制节奏，创造揭示，建立张力，传递签名时刻。

**为什么有效：** 默认滚动是机械的，并将所有内容视为同等重要。当滚动位置驱动揭示和过渡时，浏览内容变成了参与而不是被动。

**关键洞察：**
- 平滑滚动是基础——实现Lenis或Locomotive Scroll以使用每个获奖网站使用的加权，物理感
- 视差必须是有目的的——有限制，仅在装饰性元素上；永远不要在文本或关键内容上
- 固定部分创造叙事时刻——在内容在内部转换时锁定部分
- 水平滚动画廊需要清晰的视觉提示
- 揭示应该是渐进的——元素在它们可见时进入，创造发现
- 滚动速度可以调节动画速度以获得响应式感觉

**应用：** 固定英雄与滚动驱动转换（Apple深度探索）；水平滚动画廊与提示（Studio Freight）；滚动驱动动画序列（Active Theory）。使用IntersectionObserver进行轻量级的类切换；保留GSAP ScrollTrigger用于复杂的多步骤序列。

**道德边界：** 滚动劫持是敌对的UX——用户必须始终能够以自己的速度滚动并访问所有内容。

查看[参考资料/技术堆栈.md](references/technical-stack.md)以连接平滑滚动（Lenis/Locomotive设置，库权衡）和[参考资料/动画模式.md](references/animation-patterns.md)用于固定，水平画廊和滚动速度序列。

### 6. 性能与加载

**核心概念：** 性能是一天一日的设计约束，而不是优化步骤。一个美丽的动画掉帧或一个令人惊叹的字体导致布局偏移未能通过工艺测试。

**为什么有效：** 用户将性能视为质量——即时加载和流畅滚动感觉高级，无论视觉复杂性如何，而一个令人惊叹的网站在卡顿时感觉是损坏的。

**关键洞察：**
- 子集和预加载字体——只需要字形，`font-display: swap`或`optional`，预加载关键文件
- 优化图像——WebP/AVIF带回退，响应式`srcset`，折叠下方的懒加载
- GPU加速动画——仅动画`transform`和`opacity`；永远不要`width`，`height`，`top`，`left`，或`margin`
- CLS接近零——保留空间用于图像，字体和动态内容（`aspect-ratio`在容器上）
- LCP低于2.5秒——优化英雄的关键渲染路径
- 加载状态是设计元素——自定义骨架和进度指示器，而不是事后思考

**应用：** 子集/预加载/交换字体（`<link rel="preload" as="font" crossorigin>`）；AVIF/WebP带响应式`srcset`（`<picture>`回退）；GPU仅动画（`transform: translate3d()` + `opacity`）。使用Lighthouse针对90+进行审计；代码拆分和延迟非关键JS。

**道德边界：** 快但无法访问不是有效的权衡——永远不要为了速度而剥离可访问性功能或语义HTML。

选择[参考资料/技术堆栈.md](references/technical-stack.md)时选择库或达到性能预算——推荐堆栈和具体的字体/图像/动画优化技术。

### 7. 微交互

**核心概念：** 工艺存在于设计师跳过的1%中：品牌选择颜色，磁性按钮，设计的焦点状态，考虑周到的加载状态，精心设计的错误页面，正确的微字体。

**重要：** 自定义光标是仅限选择。除非用户明确请求或确认，否则永远不要替换原生光标——不当使用的自定义光标损害可用性并感觉是花哨的。始终先询问。

**为什么有效：** 微交互表明每个像素都被考虑到了。单独微妙，集体变革——用户感觉到嵌入体验中的关怀。

**关键洞察：**
- 自定义光标反映品牌个性，在交互元素上有变体（受上述选择规则约束）
- 品牌的`::selection`颜色适用于所有背景
- 每个链接和卡片都有一个考虑周到的悬停状态——比例，覆盖或有意义的变换
- 焦点状态是可见的，同时也是美丽的——品牌指示器键盘用户可以清楚地看到
- 加载，空，404和错误状态是设计的，有帮助的时刻
- 微字体是正确的——智能引号，en/em连字符，标题上没有或孤儿，`text-wrap: balance`在关键文本上

**道德边界：** 焦点状态必须满足键盘可见性要求，即使风格为品牌，错误/空/404状态必须真正有帮助，而不仅仅是装饰性的。

查看[参考资料/动画模式.md](references/animation-patterns.md)以获取可复制粘贴的磁性按钮，光标和`::selection`/悬停微交互代码。

## 设计流程

按此顺序工作——顺序是纪律：

1. **先概念后代码。** 首先定义四个要素：
```
品牌精髓：什么单一词汇能捕捉其灵魂？
视觉张力：什么对立力量创造吸引力？
标志性瞬间：什么将成为人们截图分享的内容？
技术雄心：什么将挑战浏览器的极限？
```
2. **首先设计标志性瞬间** —— 而不是页眉。每个10/10级项目至少有一个让人们驻足分享的瞬间（一个前所未见的英雄动画、足够大胆的排版以至于成为视觉焦点、一个讲述故事的滚动序列）。通过提问来明确它：人们会截图什么？向同事描述什么？试图逆向工程什么？以及什么让它无可辩驳地属于这个项目？
3. **接下来选择展示字体** —— 它决定了其他所有内容（支柱1）。
4. **在视觉设计的同时原型化动效，而不是之后** —— 动效不是精修（支柱3）。
5. **克制发布** —— 3件完美的事胜过10件平庸的事。无情地删减。

## 实施说明

1. **先构思桌面端，再构建移动端** —— 大胆设想，逐步实现
2. **使用项目规范** —— 如果有Tailwind 4+和/或shadcn/ui可用，将其设计令牌和组件作为10/10级工艺的基础，而不是与之对抗

## 常见错误

每个修正都指向定义规则的支柱——此处不要重新推导值。

| 错误 | 为什么失败 | 修正（见） |
|------|-----------|----------|
| 使用Inter、Roboto、Arial或system-ui作为主要字体 | 应用程序字体暗示通用，而非高端 | 高端铸造厂或优质的Google替代品（支柱1） |
| 统一字号比例（所有内容在2倍范围内） | 没有层级，没有令人惊叹的瞬间 | 打开展示到身体的比例（支柱1） |
| `ease`、`ease-in`、`ease-out`或`linear`缓动 | 机械、无生气——立即暗示业余 | 禁用——使用自定义的cubic-bezier（支柱3） |
| 同时动画化所有内容 | 视觉噪音，没有层级或叙事 | 根据重要性错开和排序（支柱3） |
| 所有内容居中对齐 | 安全但无聊——没有张力或能量 | 非对称性、网格偏移、溢出元素（支柱2） |
| 所有地方等距 | 单调——眼睛无处停留 | 变化密度：密集部分，然后留出呼吸空间（支柱2） |
| 纯粹的#000000 / #ffffff | 无生气且刺眼 | 温暖变体（支柱4） |
| 默认浏览器滚动 | 机械，平等对待所有内容 | 平滑滚动库（支柱5） |
| 紫色到蓝色的渐变英雄 | “AI渐变”——通用趋势追随 | 项目特有的签名颜色方法（支柱4） |
| 没有标志性瞬间 | 称职但令人难忘 | 首先设计截图值得的瞬间（过程步骤2） |
| 专业界面中的任何表情符号 | 暗示休闲/业余工艺 | 定制图标或排版处理 |
| 文本或关键内容上的视差 | 晕动病，可访问性失败 | 视差仅用于装饰性背景元素（支柱5） |
| 动画阻塞交互 | 有敌意的用户体验 | 保持所有动画非阻塞（支柱3） |
| 未修改的Font Awesome图标 | 模板级设计 | 定制图标，或大幅定制以匹配品牌 |
| 默认表单样式 | 瞬间打破工艺错觉 | 设计每个输入、选择、复选框和按钮（支柱7） |

## 快速诊断

每行回答“是”得1分，然后将分数映射到评分标准：11-12 -> 9-10，8-10 -> 7-8，5-7 -> 5-6，低于5 -> 0-4。声明分数。

| 问题 | 如果不是 | 修正（见） |
|------|---------|----------|
| 英雄排版是否让人在滚动中途驻足？ | 展示字体不具支配力 | 支柱1——比例、独特的字体、填满视口 |
| 有人会截图任何部分吗？ | 没有标志性瞬间 | 过程步骤2——使一个部分变得非凡 |
| 当你眯起眼睛时设计是否仍然可读？ | 层级太扁平 | 更大的标题、更多的空白、更强的强调 |
| 所有缓动曲线都是自定义的（没有`ease`/`linear`）？ | 动效感觉默认 | 支柱3——自定义cubic-bezier |
| 构成中有非对称张力吗？ | 布局感觉安全 | 支柱2——偏移、溢出、变化密度 |
| 颜色是否为这个项目量身定制？ | 通用调色板 | 支柱4——单色张力、签名或情境 |
| 页面加载是否协调？ | 元素同时弹出 | 支柱3——错开的揭示序列 |
| 滚动是否感觉定制且有分量？ | 默认浏览器滚动 | 支柱5——平滑滚动库 |
| 是否考虑了微细节（选择、焦点、光标）？ | 默认浏览器行为仍然存在 | 支柱7——定制的选择、设计的焦点（光标可选） |
| CLS接近零且LCP低于2.5秒？ | 性能损害质量 | 支柱6——子集字体、WebP/AVIF、仅变换/不透明度 |
| 每个动画是否回答“为什么这个动？” | 装饰性动效 | 支柱3——删除没有叙事或指导的动效 |
| 焦点状态既美观又可访问吗？ | 一个为了另一个牺牲 | 支柱7——符合品牌指示符的WCAG可见性 |
