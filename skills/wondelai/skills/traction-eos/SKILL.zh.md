# 创业运营系统 (EOS)

一个用于经营企业的完整系统，包含六个关键组成部分。专为希望统一愿景和执行力的创业公司（收入 200 万至 5000 万美元，10 至 250 名员工）设计。

## 核心原则

**大多数企业都遭受着相同的核心问题：人员、愿景、执行力。** 没有执行力的愿景是幻觉；没有愿景的执行力是漫无目的。EOS 通过一个实用的每周运营节奏将两者联系起来，该节奏加强了任何组织的六个关键组成部分。

## 评分

**目标：10/10。** 根据六个快速诊断行中有多少通过（每个组成部分要么到位，要么不到位）来评分，映射到下面的区间。区间：**9-10** = 所有六个诊断行都通过，并且岩石持续达到 80%+ 完成率；**7-8** = 五个行通过，一个组成部分薄弱；**5-6** = 三到四个行通过；**3-4** = 一到两个行通过；**<=2** = 没有运营节奏。始终说明当前分数、失败的诊断行以及每个的下一步行动。

## 六个关键组成部分

```
愿景 → 人员 → 数据 → 问题 → 流程 → 执行力
```

### 1. 愿景组成部分

**问题：** 组织中的每个人都清楚你要去哪里以及你打算如何到达吗？

**工具：愿景/执行力组织器 (V/TO)** — 在两页纸上回答八个问题：

| 问题 | 定义内容 | 示例 |
|------|----------|------|
| **核心价值观** | 3-7 不可协商的信念 | "承担责任"、"做正确的事"、"成长或死亡" |
| **核心重点** | 目的/事业/热情 + 利基市场 | "简化中小企业" + "云会计" |
| **十年目标** | 大胆、有挑战性、雄心勃勃的目标 | "1000 万美元收入" 或 "1 万名客户" |
| **营销策略** | 目标市场、3 个独特性、经过验证的流程、保证 | 你服务谁，你为什么与众不同 |
| **三年蓝图** | 三年后公司看起来什么样 | 收入、利润、员工人数、关键指标 |
| **一年计划** | 收入、利润、可衡量的指标、目标 | 今年具体的指标 |
| **季度岩石** | 本季度 3-7 个优先事项 | 90 天内最重要的几件事 |
| **问题清单** | 所有未解决的问题 | 问题、想法、机会 |

**流程：** 领导层一起完成 V/TO（2 天的离岗活动），与整个组织分享，每季度回顾，每年更新。

**关键洞察：** 如果领导团队不能就 V/TO 达成一致，你有一个更大的问题——统一性是第一位的。

填写 V/TO 时请参阅 [参考资料/vto.md](references/vto.md) — 八个问题的模板和离岗活动流程。

### 2. 人员组成部分

**问题：** 你是否在正确的位置有正确的人？

**工具：责任图** — 不是组织结构图；它定义了结构并明确了谁负责什么。

```
愿景家 ←→ 整合者
              ├── 销售/营销
              ├── 运营
              └── 财务
```

- **愿景家：** 大胆的想法、文化、关键关系、创造性解决问题
- **整合者：** 日常运营、管理团队、执行愿景
- **规则：** 每个位置一个人 — 共享责任就是没有责任

**工具：人员分析器** — 在两个维度上评估每一个人：

1. **合适的人（核心价值观契合）：** 在每个核心价值观上评分 +、+/- 或 -。必须所有都是 "+"；一个 "+/-" 是需要谈话；任何 "-" 都意味着不合适。
2. **合适的岗位（GWC）：** **G**ets it（理解角色）、**W**ants it（真诚地）、**C**apacity（精神、身体、情感）。必须所有都是 "是"。

**人员决策：**
- 合适的人，合适的岗位 → 保留并投资
- 合适的人，不合适的岗位 → 调到合适的岗位
- 不合适的人，合适的岗位 → 培训或退出（最难的决定）
- 不合适的人，不合适的岗位 → 立即退出

构建责任图或运行人员分析器时请参阅 [参考资料/people.md](references/people.md) — 模板加上 GWC 评分指南。

### 3. 数据组成部分

**问题：** 你是基于客观数据还是主观意见进行管理？

**工具：记分卡** — 一份包含 5-15 个数字的每周报告卡，告诉你业务进展如何。每周数据比每月数据提前 2-4 周发现问题，并取代直觉管理，实现问责制。

**记分卡规则：**
- 基于活动的指标（领先指标），而不是结果（滞后指标）
- 每周数字 — 每月太慢无法反应
- 每个数字都有所有者和目标
- 红色/绿色：在轨道或偏离轨道

**示例：**

| 指标 | 所有者 | 目标 | W1 | W2 | W3 | W4 |
|------|-------|------|----|----|----|----|
| 收入 | 销售主管 | 每周 5 万美元 | ✓ | ✓ | ✗ | ✓ |
| 新线索 | 市场营销 | 每周 100 个 | ✓ | ✗ | ✓ | ✓ |
| 现金余额 | 财务 | >20 万美元 | ✓ | ✓ | ✓ | ✓ |

**指标选择：** 如果你需要休假 4 周，哪些 5-15 个数字会告诉你业务进展如何？

构建记分卡时请参阅 [参考资料/data.md](references/data.md) — 模板加上如何选择领先指标。

### 4. 问题组成部分

**问题：** 你是否快速识别、讨论和解决问题？

**工具：问题解决轨道 (IDS)** — **I**dentify → **D**iscuss → **S**olve：

1. **识别：** 询问 "为什么？" 直到找到根本原因（而不是症状）；用一句话说明问题
2. **讨论：** 每个人都提供意见（而不是平等的时间）；停止跑题；一次一个问题，时间限制 5-15 分钟
3. **解决：** 做出决定，分配行动项（谁 + 什么 + 何时），继续前进

**三种类型的问题：**

| 类型 | 示例 | 行动 |
|------|------|------|
| **问题** | 客户流失、团队冲突、故障 | IDS → 解决 |
| **想法** | 新功能、流程变更、机会 | IDS → 决定（是/否/稍后） |
| **障碍** | 岩石受阻、资源限制 | IDS → 移除或升级 |

**问题清单规则：** 任何人都可以添加问题；优先处理最重要的问题；未解决的问题会延续——不是每次会议都能解决所有问题。

**常见的 IDS 失败：** 讨论症状而不是根本原因，每周重复同一个问题，没有明确的行动项就结束会议。

主持 IDS 时请参阅 [参考资料/issues.md](references/issues.md) — 一个五问工作示例和跑题控制策略。

### 5. 流程组成部分

**问题：** 你是否记录并始终如一地遵循核心流程？

**工具：核心流程记录** — 20/80 法则：记录 20% 的流程以获得 80% 的一致性。

**需要识别的核心流程：** 人力资源（招聘、入职、评估）、销售（线索 → 关闭）、运营（交付、履行）、客户服务（支持 → 解决）、财务（开票、收款）。

**记录格式：** 命名流程，列出 5-20 个主要步骤，提供足够的细节（不是 50 页的手册），尽可能使其可视化。

**示例：销售流程 "The Closer"**
1. 筛选线索（BANT：预算、权力、需求、时间线）
2. 探索电话（30 分钟，问题指南）
3. 演示（根据他们的痛点定制）
4. 提案（24 小时内）
5. 跟进（7 天内 3 次接触）
6. 关闭或淘汰

**所有人员都遵循 (FBA)：** 记录它，培训它，衡量合规性，每季度更新。

记录核心流程时请参阅 [参考资料/process.md](references/process.md) — 完整模板和 HR/销售/运营的工作示例。

### 6. 执行力组成部分

**问题：** 你是否每天都在执行你的愿景？

#### 岩石（季度优先事项）

未来 90 天内要完成的 3-7 件最重要的事情。90 天足够长，可以取得有意义的成果，但又足够短，以保持紧迫感。

**设定岩石的流程：**
1. 回顾 V/TO（愿景、三年、一年）
2. 头脑风暴本季度必须完成的事情以保持进度
3. 窄化为 3-7 个公司岩石，每个岩石有一个所有者
4. 每个领导成员也设定 3-7 个个人岩石
5. 与整个组织分享并每周跟踪

**SMART 岩石：** 具体（"推出新的定价页面"，而不是"改进定价"）、可衡量（有明确的完成标准）、90 天内可实现、考虑到资源、有时间限制（在本季度末完成）。

**岩石评分：** 完成 = 打勾（没有部分分数）；未完成 = 转移或删除。目标 80%+ 完成率。注意那些只是"正常业务"的岩石——它们不会推动进展。

设定季度岩石时请参阅 [参考资料/rocks.md](references/rocks.md) — 二进制完成测试、九行错误表和季度中段检查。

#### 十级会议（每周领导会议）

**EOS 中最重要的会议。** 每周、同一天、同一时间、同一议程——90 分钟，从不更长。

| 时间 | 部分 | 目的 |
|------|------|------|
| 5 分钟 | **过渡** | 好消息，个人和职业 |
| 5 分钟 | **记分卡** | 回顾每周数字 |
| 5 分钟 | **岩石回顾** | 每个岩石的进度/偏离进度 |
| 5 分钟 | **头条新闻** | 客户/员工快速更新 |
| 5 分钟 | **待办事项列表** | 上周的待办事项：完成或未完成 |
| 60 分钟 | **IDS** | 识别、讨论、解决问题 |
| 5 分钟 | **总结** | 回顾待办事项，评分 1-10 |

**规则：**
- 准时开始和结束——保护节奏是使其有效的原因
- 没有手机/笔记本电脑（除了议程）——IDS 需要全神贯注
- IDS 占 60 分钟的 90 分钟——解决问题是重点，更新不是
- 结束时评分 1-10（因此称为"十级"）；低于 8 表示讨论如何改进
- 待办事项是 7 天的行动项，有所有者；完成 = 100% 完成；目标 90%+ 完成率

运行或修复十级会议时请参阅 [参考资料/level-10.md](references/level-10.md) — 促进脚本和如何解释会议评分。

## EOS 实施时间表

典型推广：2 年完成全面实施。

| 阶段 | 时间线 | 重点 |
|------|--------|------|
| **专注日** | 第 1 天（8 小时） | 责任图、岩石、记分卡、十级会议 |
| **愿景建设日 1** | 第 1 个月 | V/TO：核心价值观、核心重点、十年目标 |
| **愿景建设日 2** | 第 2 个月 | V/TO：营销策略、三年、一年、岩石 |
| **季度会议** | 每 90 天 | 回顾岩石，设定新岩石，IDS 主要问题 |
| **年度规划** | 每年 | 完整 V/TO 回顾，一年计划，Q1 岩石 |

**自我实施**（阅读书籍，遵循工具——免费，较慢）与 **EOS 实施者**（认证促进者——更快，昂贵）。

规划推广时请参阅 [参考资料/implementation.md](references/implementation.md) — 阶段性顺序和自我与实施者决策。有关真实公司如何顺序的示例，请参阅 [参考资料/案例研究.md](references/case-studies.md)。

## 组织检查

对每个陈述评分 1-5：

| 组成部分 | 陈述 | 评分 (1-5) |
|----------|------|-------------|
| **愿景** | 领导团队就我们的方向和如何到达达成一致 | |
| **人员** | 我们在正确的位置有正确的人 | |
| **数据** | 我们基于每周 5-15 个数字的记分卡进行管理 | |
| **问题** | 我们快速永久地解决问题 | |
| **流程** | 核心流程被记录并由所有人员遵循 | |
| **执行力** | 我们设定并实现 90 天的优先事项（岩石） | |

**评分：** 25-30 强劲（微调） | 20-24 良好（弥补差距） | 15-19 一般（大量工作） | 低于 15 弱（考虑 EOS 实施者）。

## 常见错误

| 错误 | 失败原因 | 修复 |
|------|----------|------|
| **跳过十级会议** | 每周节奏丢失，问题堆积 | 保护会议，从不取消 |
| **没有记分卡** | 直觉管理，经常意外 | 选择 5-15 个每周数字 |
| **保留不合适的人** | 拖累整个团队 | 人员分析器，做出艰难的决定 |
| **V/TO 未共享** | 团队不知道愿景 | 与整个公司分享 |

对于特定于岩石的错误（太多、太模糊、正常业务、季度中段变更），请参阅 [参考资料/rocks.md](references/rocks.md) — 完整九行表格和修复。

## 快速诊断

| 问题 | 如果没有 | 行动 |
|------|-------|------|
| 领导团队就愿景达成一致吗？ | 误调 | 一起完成 V/TO |
| 正确的人在正确的位置吗？ | 绩效问题 | 对所有座位运行人员分析器 |
| 每周基于数据管理吗？ | 反应式管理 | 建立每周记分卡 |
| 永久解决问题吗？ | 重复相同的问题 | 在十级会议中 IDS |
| 核心流程记录吗？ | 不一致性 | 记录前 5 个流程 |
| 设定并跟踪 90 天的优先事项吗？ | 没有执行力 | 设定季度岩石 |
