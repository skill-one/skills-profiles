# 钩子模型框架

构建养成习惯型产品的框架。习惯并非被创造——它们是通过钩子模型的连续循环而建立起来的。

## 核心原则

**钩子模型** = 一个四阶段循环，将用户的问题与您的解决方案频繁地联系起来，以形成习惯，将使用从刻意转变为自动。

```
触发器 → 行动 → 可变奖励 → 投资
    ↑                                      │
    └──────────────────────────────────────┘
```

## 评分

**目标：10/10。** 在审查或创建产品参与机制时，通过四个快速诊断行（内部触发器、简单行动、可变奖励、投资加载下一个触发器）对循环进行评分：每行获得2分（完全满足）、1分（部分满足）或0分（缺失），然后 `score = round(total / 8 × 10)`。然后应用道德门槛：如果操纵矩阵将产品定位为庄家（或它触发了任何“不使用时”的条件），则无论机制如何，都将分数限制在3分。等级：9-10 = 完整循环，识别内部触发器，道德清晰；5-6 = 循环运行但依赖外部触发器或可预测的奖励；<=3 = 破坏性循环或榨取性设计。始终说明当前分数以及阻止10/10的具体诊断行。

## 四个阶段

### 1. 触发器

**核心概念：** 行为的执行器。触发器是外部的（环境驱动的：通知、电子邮件、广告）或内部的（情绪驱动的）——目标是引导用户从外部触发器转向内部触发器。

**为什么有效：** 每个习惯都以一个提示符开始。外部触发器让用户开始使用，但内部触发器——无聊、孤独、不确定、错失恐惧——在没有提醒的情况下驱动使用，因为情绪本身在提醒之前就会触发。

**关键洞察：**
- 将您的产品映射到它解决的特定负面情绪（无聊、孤独、困惑、错失恐惧）
- 有效的外部触发器是时机恰当、可操作，并导向最简单的下一步行动
- 如果用户在约30天后仍然需要外部提示，则没有形成内部触发器

**产品应用：**

| 环境 | 应用 | 示例 |
|------|------|------|
| **引导流程** | 外部触发器建立第一个循环 | 带有一个清晰行动的欢迎电子邮件 |
| **留存** | 将产品映射到内部情绪触发器 | Instagram解决无聊；Google解决困惑 |
| **重新激活** | 外部触发器在习惯形成前填补空白 | 推送：“你的朋友刚刚发布了一张照片” |

**文案模式：**
- “在你离开期间发生了什么，不要错过”（错失恐惧触发器）
- “你的朋友刚刚...”（社交触发器，过渡到内部）
- “继续你之前的地方”（常规触发器）

**道德边界：** 不要构建在脆弱情绪状态（抑郁、成瘾、悲伤）上触发的触发器——这些用户无法行使循环所假设的自主权。

在映射触发器时查看 [参考资料/触发器.md](references/triggers.md)——情绪到产品的映射练习和外部到内部的过渡计划。

### 2. 行动

**核心概念：** 在预期奖励时做的最简单行为，由Fogg行为模型指导：行为 = 动机 + 能力 + 触发器，所有因素在同一时间汇聚。

**为什么有效：** 增加动机很困难且不可靠；减少摩擦（增加能力）更容易且更有效。每多一个步骤、字段或决策都是一个流失点。

**关键洞察：**
- 简单性的六个要素：时间、金钱、体力、脑力循环、社会偏差、非常规
- 行动是在预期奖励时的最简单行为——不是完整任务
- 赫克定律：更多选择 = 更慢的决策；减少选项以提高行动率

**产品应用：**

| 环境 | 应用 | 示例 |
|------|------|------|
| **注册流程** | 最小化字段和步骤 | 一键登录Google/Apple |
| **核心行动** | 几秒钟内可完成 | Twitter：输入280个字符并发布 |
| **渐进式披露** | 仅在初始奖励后请求更多信息 | Duolingo：先玩，后创建账户 |

**文案模式：**
- “只需一次点击即可...”（强调简单性）
- “无需信用卡”（金钱/风险简单性）
- 按钮应为动词：“发布”、“保存”、“分享”——而不是“提交”或“继续”

**道德边界：** 当您简化行动时，不要与成本或后果一起剥离——一键购买仍应显示价格和承诺。

在将循环适应您的内容时查看 [参考资料/产品应用.md](references/product-applications.md)——B2B SaaS、电子商务、健康和生产力工具的行动和投资模式。

### 3. 可变奖励

**核心概念：** 保持用户持续回来的阶段。预期奖励——而不是奖励本身——创造多巴胺，奖励必须是可变的（不可预测的）以维持参与度。

**为什么有效：** 大脑的多巴胺系统对不确定奖励的预期反应最强——老虎机效应。三种奖励类型——部落（社交）、狩猎（资源）、自我（掌握）——满足人类的基本需求。

**关键洞察：**
- 部落 = 社交认可；狩猎 = 搜索资源/信息；自我 = 个人掌握
- 可预测的奖励会失去力量；有限的变异性最终会变得可预测——目标是无限变异性
- 自主性至关重要：用户必须感觉掌控一切；强迫参与适得其反

**产品应用：**

| 环境 | 应用 | 示例 |
|------|------|------|
| **社交功能（部落）** | 可变社交认可 | Instagram点赞——你永远不知道有多少 |
| **内容源（狩猎）** | 不可预测的资源流 | 无限滚动，算法驱动的内容变化 |
| **游戏化（自我）** | 可变难度成就 | Duolingo连续击中和惊喜挑战 |

**文案模式：**
- “查看最新内容”（暗示可变性）
- “3人回应了你的帖子”（部落奖励，可变数量）
- “你解锁了一个新成就！”（自我奖励，意外）

**道德边界：** 如果用户在参与后持续感觉更糟（后悔、时间损失、焦虑），奖励系统是榨取性的——避免没有自然停止点的无限滚动。

在设计奖励时查看 [参考资料/奖励.md](references/rewards.md)——部落/狩猎/自我模式、四种强化时间表和奖励时机。关于可变奖励背后的多巴胺/预期机制，请查看 [参考资料/神经科学基础.md](references/neuroscience-foundations.md)。

### 4. 投资

**核心概念：** 用户投资时间、数据、精力、社会资本、金钱等，这些投资改善了产品的下一次使用，提高了转换成本，并加载了下一个触发器。

**为什么有效：** 人们重视他们付出的努力（IKEA效应）。投资不是关于立即奖励——它改善了下一次循环，创造了一个自我强化的循环。

**关键洞察：**
- 投资应在奖励之后，而不是之前——用户在感觉良好时投资
- 每个投资都应加载下一个触发器（发布内容触发回复通知）
- 小投资会累积：偏好 → 更好的推荐 → 更多使用；存储价值随时间增长

**产品应用：**

| 环境 | 应用 | 示例 |
|------|------|------|
| **数据投资** | 历史记录改善个性化 | Spotify：更多收听 = 更好的推荐 |
| **内容投资** | 用户创建的内容他们不会放弃 | Instagram帖子、Notion文档 |
| **声誉/社交投资** | 仅在平台存在的社交资本 | Airbnb房东评分、LinkedIn网络 |

**文案模式：**
- “完成您的个人资料以获得更好的匹配”（投资 → 未来价值）
- “用得越多，它就越智能”（累积投资）
- “邀请您的团队协作”（社交投资）

**道德边界：** 投资应真正改善体验——永远不要用人为的转换成本或不可能的数据导出困住用户；通过真实价值使留下成为更好的选择。

## 习惯区

两个轴决定产品是否可以成为习惯：

| | 低频率 | 高频率 |
|--|--------|--------|
| **高感知价值** | 可行产品（需要广告/营销） | **习惯区** |
| **低感知价值** | 失败 | 失败 |

问：用户多久需要参与一次，每次参与的感知价值是什么，频率是否足够高以形成自动行为？

## 习惯测试

5%规则：当至少5%的用户显示未经提示的习惯性使用时，习惯已形成。

**三个问题：**
1. **习惯用户是谁？** 哪些用户参与最频繁，他们分享了什么？
2. **他们在做什么？** 确定习惯路径——将重度用户与休闲用户区分开来的行动序列。
3. **他们为什么这样做？** 哪个内部触发器和情绪先于使用？

在运行测试时查看 [参考资料/习惯测试.md](references/habit-testing.md)——队列分析、找到习惯路径和确认5%阈值。对于真实产品中这些循环的案例拆解（Instagram、Slack、Duolingo、Pinterest和失败案例），请查看 [参考资料/案例研究.md](references/case-studies.md)。

## 操纵矩阵

评估养成习惯型产品道德的框架：

| | **制作者使用产品** | **制作者不使用** |
|--|------------------|-----------------|
| **实质改善用户生活** | **促进者** | **贩卖者** |
| **未改善生活** | **娱乐者** | **庄家** |

问：我会自己使用这个产品吗？它是否真正帮助用户实现他们的目标？我是否在利用脆弱性或满足需求？

### 不使用钩子模型时

- 您的产品并未真正改善生活
- 您正在针对脆弱人群（儿童、易成瘾用户）
- 商业模式依赖于用户后悔
- 参与与用户福祉冲突

在操纵矩阵标记问题时查看 [参考资料/道德边界.md](references/ethical-boundaries.md)——暗模式目录以及如何保护脆弱用户。

### 监管环境

关注新兴监管：儿童应用（COPPA、GDPR-K）、暗模式（FTC执法加剧）、“成瘾性”通知实践和宝箱（扩大游戏规则）。

## 引导流程审计清单

优化引导流程以养成习惯：

### 第一个触发器
- [ ] 第一个行动明显且容易；对这位用户来说正确的外部触发器
- [ ] 在要求投资之前，价值主张清晰

### 第一个行动
- [ ] 核心行动在60秒内可完成，摩擦已消除
- [ ] UI熟悉（无需新学习）

### 第一个奖励
- [ ] 立即反馈，包含可变元素（惊喜、愉悦）
- [ ] 奖励连接到内部触发器

### 第一个投资
- [ ] 投资在奖励之后请求（而不是之前），小但有意义
- [ ] 投资加载下一个触发器

### 循环完成
- [ ] 清晰返回触发器的路径；在适当的时间发送外部触发器
- [ ] 通过钩子进行测量的进展

## 常见错误

| 错误 | 为什么失败 | 修复 |
|------|----------|------|
| **无限依赖外部触发器** | 您是在租用注意力，而不是建立习惯 | 将产品映射到情绪；在30天内过渡到内部触发器 |
| **核心行动过于复杂** | 用户在获得奖励之前就放弃了 | 简化为最小可行行动；应用六个能力因素 |
| **使用可预测的奖励** | 多巴胺反应随新奇性减弱 | 在部落、狩猎和自我奖励中添加可变性 |
| **在奖励之前请求投资** | 用户尚未获得价值 | 顺序：触发器、行动、奖励，然后投资 |
| **忽略钩子的道德** | 用户后悔、反弹、监管风险 | 使用操纵矩阵；成为促进者，而不是庄家 |

## 快速诊断

审核任何产品功能：

| 问题 | 如果没有 | 行动 |
|------|--------|------|
| 内部触发器是什么？ | 用户需要提醒使用它 | 研究用户情绪 |
| 行动是否简单？ | 用户开始但未完成 | 消除摩擦 |
| 奖励是否可变？ | 用户感到无聊 | 添加不可预测性 |
| 投资是否加载下一个触发器？ | 用户不会回来 | 将投资与触发器连接 |
