# 产品定位框架

April Dunford 的 "Obviously Awesome" 方法论：一个结构化、可重复的流程，用于定义你的产品如何在为特定客户群体高度关注的领域成为全球最佳。定位决定了客户将你与什么进行比较，他们会注意到哪些功能，并最终决定是否购买。

## 核心原则

**定位不是信息传递。定位是背景。**

定位定义了客户评估你产品的背景——他们将你归入哪个类别，他们会将你与哪些替代方案进行比较，以及他们如何判断你的价值。客户总是相对于替代方案进行评估；没有绝对的产品认知——在一个背景下看起来昂贵的产品的，在另一个背景下可能看起来很便宜。故意选择使你的独特优势显而易见的背景：做得好，信息传递、销售和定价将变得容易得多；做得不好，再多的巧妙文案也救不了你。

## 评分

**目标：10/10。** 使用下表中的等级，对任何产品的定位进行 0-10 的评分，并始终说明当前分数以及达到 10/10 所需的具体改进。

| 分数 | 描述 |
|------|------|
| 0-2  | 没有明确的定位；客户无法解释产品是什么或面向谁 |
| 3-4  | 含糊不清：类别不明确，差异化薄弱，目标客户是“所有人” |
| 5-6  | 部分明确：某些方面清晰，其他方面缺失；团队成员对产品的描述不同 |
| 7-8  | 强劲：所有五个方面都已定义，团队达成一致，客户通常理解其价值 |
| 9-10 | 卓越：每个方面都加强了其他方面；客户立即明白产品是什么、为什么不同以及为什么他们应该关心 |

## 定位画布

定位的 10 个输出结果，集中在一个地方。步骤 1-5 构建顶部五个，其余部分由此衍生。每个团队成员都应该填写这个画布并得出相同的答案——分歧表明存在不一致。

| 组成部分 | 填写问题 | 示例答案 |
|----------|----------|----------|
| 竞争替代品 | 如果我们的产品不存在，客户会使用什么？ | 电子表格、顾问、什么都不做 |
| 独特属性 | 我们有什么而替代品没有的？ | 财务模型上的实时协作 |
| 价值主题 | 这些属性能实现什么价值？ | 每周节省 10 小时的财务报告时间 |
| 最佳客户 | 谁最关心这个价值？ | 管理多个业务单元的中市场首席财务官 |
| 市场类别 | 哪个市场框架使我们的价值显而易见？ | 财务规划与分析软件 |
| 相关趋势 | 哪些市场动态现在创造了紧迫感？ | 远程财务团队需要实时协作 |
| 定位声明 | 对于 [目标客户]，我们是 [类别] 的 [关键价值] | “对于中市场首席财务官，我们是为实时协作而构建的财务规划与分析平台” |
| 关键证据点 | 哪些证据表明我们的主张是真实的？ | 案例研究、使用数据、第三方基准 |
| 销售叙事 | 我们如何在销售对话中讲述这个故事？ | 问题 -> 旧方法 -> 新方法 -> 我们的解决方案 -> 证据 |
| 信息传递 | 哪个外部标题源自定位？ | “与您的业务同步的财务规划” |

在为真实产品填写画布时，请参阅 `[references/positioning-canvas.md](references/positioning-canvas.md)`——它有空白模板和三个完全示例（B2B SaaS、消费者应用、专业服务）。

## 五步定位流程

### 第一步：确定你的竞争替代品

**核心概念：** 了解如果你的产品明天消失，你的最佳客户会做什么——不仅仅是直接竞争对手，而是他们今天解决任何问题的方式：手动流程、电子表格、雇佣某人或什么都不做。

**为什么有效：** 客户总是相对于替代方案评估产品，所以“差异化”只有在客户心中相对于真实的替代方案才有意义。

**关键洞察：**
- 访谈 15-20 位现有满意客户，而不是潜在客户——他们可以告诉你他们实际上是从什么产品切换过来的
- 最常见的替代方案通常不是一个产品——它是一个电子表格、一个手动流程或现状
- “什么都不做”在许多市场中是你的最大竞争对手
- 将类似的替代方案分组（例如“通用电子表格”而不是 Excel、Sheets、Numbers）
- 不同的客户群体可能有不同的替代方案

**产品应用：**

| 背景 | 应用 | 示例 |
|------|------|------|
| 新产品发布 | 访谈早期采用者，了解他们使用的产品 | “70% 使用电子表格，20% 使用通用的项目管理工具，10% 雇佣承包商” |
| 重新定位 | 调查流失和留存客户 | 留存客户将你与顾问进行比较，而不是软件 |
| 竞争分析 | 按细分市场映射替代方案 | 企业与 Salesforce 比较；中小企业与电子表格比较 |

**文案模式：**
- “与 [竞争替代品] 不同，[产品] 可以 [独特功能]”
- “停止使用 [痛苦的替代品] 来完成 [工作]”
- “你已经用完了 [替代品]。这是下一步。”

**道德边界：** 基于实际客户研究确定替代方案，永远不要基于假设或愿望。

在准备或进行客户访谈时，请参阅 `[references/competitive-alternatives.md](references/competitive-alternatives.md)`——它有完整的问题脚本、五种替代方案类型、分组和“什么都不做”分析。

### 第二步：确定你的独特属性

**核心概念：** 列出你拥有而竞争替代品没有的每个属性——功能、能力、公司特征或方法。它们必须既是独特的也是真实的。

**为什么有效：** 独特属性是差异化的原材料：如果它不独特，就不能使你差异化，如果它不真实，你就会失去信任。

**关键洞察：**
- 超越功能：架构、商业模式、团队专业知识、集成、社区
- “更好”不是独特的——“快 10%” 不符合标准；“一个能够实时处理的根本性不同算法”可能符合标准
- 每个属性都必须通过“只有我们”测试：“只有我们 [属性]”
- 属性是关于你产品的客观事实；利益是客户从它们中获得的东西——不要混淆两者
- 将相关的属性分组（它们将成为步骤 3 中的价值主题）

**产品应用：**

| 背景 | 应用 | 示例 |
|------|------|------|
| 功能发布 | 检查它是否创造了独特属性 | “唯一具有内置时区感知调度的项目管理工具” |
| 竞争响应 | 在竞争对手更新后重新验证独特性 | 每季度对前五个替代方案进行属性审核 |
| 收购 | 确定收购的哪些属性是独特的 | “他们的 NLP 引擎处理医疗术语——没有其他 EMR 这样做” |

**文案模式：**
- “唯一 [类别] 可以 [独特属性]”
- “从零开始构建以 [独特能力]”
- “没有其他 [类别] 可以 [独特事情]，因为 [原因]”

**道德边界：** 永远不要声称不真实存在的属性——如果竞争对手有，它就是基本要求。

在运行属性发现工作坊时，请参阅 `[references/unique-attributes.md](references/unique-attributes.md)`——它有引导过程、“只有我们”验证和按主题分组。

### 第三步：将属性映射到客户价值

**核心概念：** 对于每个独特属性，应用“那又怎样？”测试，直到你达到客户实际关心的价值，然后将相关的价值分组为两个或三个价值主题。

**为什么有效：** 客户购买结果，而不是功能——属性在用客户的语言表达其重要性之前是无意义的。价值主题为你的定位叙事提供了结构，并使其易于记忆。

**关键洞察：**
- “那又怎样？”链：功能 -> 优势 -> 价值（“实时协作”-> “财务团队同时工作”-> “每个季度提前 3 天结账”）
- 用客户的语言而不是内部术语表达价值
- 大多数产品支持 2-4 个价值主题——更多意味着定位不集中
- 每个主题都要有证据支持：案例研究、数据、客户评价
- 主题通常围绕节省时间、节省金钱、降低风险、实现增长或提高质量

**产品应用：**

| 背景 | 应用 | 示例 |
|------|------|------|
| 信息传递开发 | 从价值主题构建层次结构 | 主要：“提前 3 倍结账。”次要：“消除版本控制错误。” |
| 销售赋能 | 每个主题的谈话要点 | 每个主题都成为带有证据的销售部分 |
| 内容营销 | 主题的内容支柱 | 博客系列、白皮书、网络研讨会按价值主题组织 |

**文案模式：**
- “使用 [产品]，通过 [独特属性] 实现 [价值结果]”
- “我们的客户 [可衡量的结果]，因为他们 [独特能力]”
- “[百分比]% 的客户在 [时间段] 内报告 [价值]”

在运行属性上的“那又怎样？”链时，请参阅 `[references/value-mapping.md](references/value-mapping.md)`——它有完整的“功能->优势->价值”演练和证据点创建。

### 第四步：定义你的最佳目标客户

**核心概念：** 确定使人们最关心你只提供的价值的特征——你产品目前最完美的客户定义，而不是你的总目标市场。

**为什么有效：** 最佳客户购买最快，流失最少，推荐最多，扩展最多；为它们定位，然后自然会向外扩展。他们的客户评价和案例研究也最具说服力。

**关键洞察：**
- 特征必须在与客户交谈之前就能识别：职位、公司规模、行业、技术堆栈——而不是心理特征
- 从你最快乐、最成功的现有客户开始
- “所有人”永远不是一个有效的目标——即使是水平产品也有最佳细分市场
- 最佳匹配不一定是最大的市场——它是最容易到达、最容易被说服和保留的
- 定义负面标准：什么表明某人不是合适的客户

**产品应用：**

| 背景 | 应用 | 示例 |
|------|------|------|
| 市场进入策略 | 首先向最佳匹配细分市场推出 | “B 级到 D 级 SaaS，50-500 名员工，有专门的 RevOps 人员” |
| 销售资格 | 根据最佳匹配标准对线索进行评分 | +20 RevOps 职位，+15 SaaS 行业，+10 对于 50-500 名员工 |
| 产品路线图 | 优先考虑最佳匹配请求 | “最佳匹配客户都要求 Salesforce 集成——下一步构建它” |

**文案模式：**
- “为 [特定客户类型] 构建，他们 [特定情况]”
- “如果你是 [角色] 在 [公司类型]，你知道 [痛点]”
- “为 [细分市场] 而构建，而不是为所有人调整的通用工具”

**道德边界：** 最佳匹配定义是关于专注，而不是排除——永远不要贬低其他细分市场。

在定义最佳匹配标准时，请参阅 `[references/target-customers.md](references/target-customers.md)`——它有可行动的细分市场测试、负面标准、角色和最佳匹配与 TAM 的区别。

### 第五步：选择你的市场类别

**核心概念：** 选择使你的独特价值最明显的市场参考框架。三种战略选择：在现有类别中与对手正面竞争，创建子类别，或创建新类别。

**为什么有效：** 类别在客户心中触发关于你的产品做什么、与谁竞争以及如何定价的假设——正确的类别利用了这些假设为你服务；错误的类别则与之对抗。

**关键洞察：**
- **正面竞争：** 声称在已建立的类别中“最佳”；你继承了所有假设和竞争对手
- **子类别：** 重新定义现有类别的一部分是如何被评估的（“房地产 CRM”）——内置认知，但标准有所改变
- **新类别：** 只有当它真正不同于任何现有产品时；你支付“教育税”，在客户理解你之前教他们类别
- 改变类别会改变一切：竞争对手、评估标准、定价和购买者预期
- 测试选择：潜在客户在对话的前 30 秒内是否“理解”？

**产品应用：**

| 背景 | 应用 | 示例 |
|------|------|------|
| 初创公司定位 | 选择初始类别 | “AI 写作助手”（现有）而不是“内容智能平台”（新） |
| 市场扩张 | 随着产品成熟而改变类别 | “电子邮件营销工具”->“客户参与平台” |
| 竞争响应 | 当竞争对手涌入你的类别时重新定义 | “项目管理”->“产品开发工作流” |

**文案模式：**
- 现有： “最佳 [类别] 对于 [最佳匹配客户]”
- 子类别： “[修饰符] [类别]——[类别] 重新想象为 [特定需求]”
- 新类别： “推出 [新类别]：[一句话定义]”

**道德边界：** 不要为了回避竞争而纯粹创建新类别——只有当你的产品无法在现有框架内理解时才这样做。

在在正面竞争、子类别和新类别之间选择时，请参阅 `[references/market-category.md](references/market-category.md)`——它有决策框架和教育税分析。

## 市场参考点

趋势作为顺风：一个真实、广泛认可的、直接连接到你的独特价值的趋势，使定位感觉及时且必然，而不是任意的。将趋势作为支持证据，而不是定位的核心。例如：“随着财务团队去远程办公，实时协作不再是锦上添花——它是必需的。”

**趋势滥用的警告信号：** 你的定位只有在考虑到趋势时才有意义；趋势与没有独特的属性连接；趋势是愿望而不是实际发生。

## 团队定位练习

定位需要跨职能协调：包括创始人（愿景）、产品（独特属性）、销售（异议和替代方案）、营销（类别和信息传递）和客户成功（最佳匹配证据）。分三部分进行：提前 1-2 周收集客户研究和赢/输数据（准备工作），进行 2-3 小时的工作坊，通过所有五个步骤达成共识，以及后续工作记录画布并协调面向客户的材料。最重要的输出是协调——每个人以相同的方式描述产品。

在主持工作坊时，请参阅 `[references/team-exercise.md](references/team-exercise.md)`——它有分钟议程、准备工作清单和远程适应方案。

## 常见错误

| 错误 | 为什么失败 | 修复 |
|------|----------|------|
| 为所有人定位 | 稀释差异化；没有人觉得它是为它们构建的 | 将最佳匹配定义到最关心的细分市场 |
| 将定位与信息传递混淆 | 没有策略的文字听起来不错，但不会引起共鸣 | 先做定位工作；从它推导信息传递 |
| 列出功能而不是价值 | 客户购买结果；功能列表让人不知所措 | 应用“那又怎样？”测试，直到你达到客户价值 |
| 抄袭竞争对手的定位 | 邀请在他们的术语上进行直接比较 | 从只有你能拥有的属性构建定位 |
| 定位变化太频繁 | 让客户、销售和市场感到困惑 | 承诺 6-12 个月；更频繁地调整信息传递 |
| 过早创建新类别 | 支付“教育税”，但没有资源教育 | 首先在现有类别或子类别中；只有在有势头和资源时才创建新类别 |
| 忽视竞争替代品 | 差异化存在于真空中 | 运行步骤 1 的快乐客户访谈，了解他们之前使用的产品 |

## 快速诊断

| 问题 | 如果没有 | 行动 |
|------|---------|------|
| 每个团队成员都能用同样的方式描述产品吗？ | 定位不一致 | 进行团队定位练习 |
| 潜在客户在30秒内能否理解你的业务？ | 类别错误或不清晰 | 重新评估你的市场类别选择 |
| 你能说出3件你做而竞争对手没有的事情吗？ | 独特属性薄弱 | 结合客户意见进行深度属性挖掘 |
| 你知道如果没有你，客户会使用什么替代品吗？ | 未知竞争替代品 | 运行步骤1的替代品满意客户访谈 |
| 你能说明为什么最佳匹配客户选择你吗？ | 价值主题不明确 | 运行“那又怎样？”映射练习 |
| 你的最佳匹配定义是否足够具体，可以主动定位？ | 目标过于宽泛 | 分析最佳客户共同的可行动特征 |

当你需要一个经过验证的范例来模拟真实合作时，请参考 [references/case-studies.md](references/case-studies.md) —— 它详细介绍了重新定位的成功案例、利基市场发现和类别创建的完整流程。
