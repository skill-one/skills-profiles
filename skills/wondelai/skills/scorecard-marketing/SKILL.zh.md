# 评分卡营销技能

一种经过验证的4步系统，通过互动评估来生成合格线索，而互动评估会附带丰富的关于每个潜在客户的数据。

## 核心原则

**一切皆由线索生成驱动。** 人们购买是为了解决他们当前现实与期望现实之间的心理紧张关系——评分卡通过提出揭示性问题来唤醒沉睡的欲望。

**基础：** 主动搜索者更难销售（已经决定，预算已定）；拥有沉睡欲望的人会向帮助他们发现需求的人购买。互动评估创造心理参与，静态内容无法做到——这就是为什么它们的转化率比PDF下载高几倍（参见[转化基准](#转化基准)）。

## 评分

**目标：10/10。** 根据六个[快速诊断](#快速诊断)行对漏斗进行评分：`得分 = round(满足行数 / 6 × 10)`。读取波段为：**9-10** = 所有六个都通过（沉睡欲望钩子，首先捕获电子邮件，评分类别，每个层级独特的 内容和CTA，层级细分跟进）；**5-7** = 漏斗存在，但通用结果或后期电子邮件捕获导致损失2-3行；**≤3** = 没有概念钩子或没有评分。始终给出当前得分和需要关闭的具体行数以达到10/10。

## 4步评分卡系统

### 1. 登录页面

**核心概念：** 登录页面的唯一目的：让访客开始问卷。它必须创造足够的好奇心并承诺足够的价值，使点击“开始”感觉无法抗拒。

**为什么有效：** 概念钩子触动沉睡的欲望；围绕分数的框架触发测量、排名和改进的原始驱动力。好奇心加上低承诺（“只需3分钟”）消除摩擦。

**关键洞察：**
- 概念钩子是最重要的元素——它定义了访客给自己评分的内容。5种钩子类型：**趋向**（目标）、**消除痛苦**、**准备**（决策验证）、**类别**（与标准比较）、**知识**（测试你所知道的内容）
- “趋向”钩子（“你准备好[目标]了吗？”）优于基于恐惧的钩子
- 3C——清晰度、可信度、联系——都必须存在
- 奖励（免费书籍、咨询、报告）提高完成率；时间预期（“少于3分钟”）减少放弃

**产品应用：**

| 上下文 | 登录页面元素 | 示例 |
|---------|---------------------|---------|
| **概念钩子** | 围绕访客想要的分数框架 | “你的营销评分是多少？” |
| **趋向** | 以目标为导向的钩子 | “你准备好扩展你的业务了吗？” |
| **准备检查** | 决策验证钩子 | “你应该启动第二个地点吗？完成这个清单” |

**文案模式：**
- "[标题：概念钩子+承诺] 你准备好[期望结果]了吗？”
- 回答[X]个快速问题，发现[具体洞察]并获得个性化建议”
- “[CTA按钮] 开始测试（不到3分钟）”

**道德边界：** 钩子必须承诺评估实际提供的价值——永远不要用销售话术伪装成结果进行诱饵和切换。

当你需要为特定细分市场提供一个起始钩子时，请参阅[参考资料/行业示例.md](references/industry-examples.md)——50多个评分卡概念和登录页面标题跨行业。

### 2. 问卷

**核心概念：** 问卷在收集线索数据的同时提供游戏化体验：首先捕获联系信息，然后询问按类别分组的有评分的问题，以揭示痛点、欲望和资格信号。

**为什么有效：** 人们喜欢回答关于自己的问题（自我参照编码），并且在问题之前捕获电子邮件可以在放弃时保留线索。评分类别使结果感觉科学，增加对建议的信任。

**关键洞察：**
- 线索捕获表单首先（姓名、电子邮件、可选电话）
- 问题数量随漏斗阶段扩展：冷到暖8-15个，暖到销售20-50个，客户到粉丝30-150个
- 将问题分组为2-7个可衡量的类别；为每个答案分配1-5分，对重要答案赋予更高的权重
- 在“未分类”组中添加资格问题（预算、紧迫性、公司规模）
- 避免销售性、引导性、查找性和术语性问题

**产品应用：**

| 上下文 | 问题类型 | 示例 |
|---------|--------------|---------|
| **是/否** | 复选项目 | “你每周锻炼3次以上吗？” |
| **滑动条** | 程度/频率 | “X对你有多重要？” |
| **开放式文本** | 罕见——减慢完成速度 | “过去是什么阻止了你？” |

**文案模式：**
- 使用“你”语言： “你对你的[主题]有多自信？”而不是“评估你的自信水平”
- 进度指示器（“问题5/12”）减少放弃；“快完成了！”保持动力
- 类别名称应该对受访者有意义，而不是内部术语

**道德边界：** 不要收集你不会用来改进他们结果的数据——每个资格问题（预算、紧迫性、规模）必须明显影响建议，而不仅仅是将他们路由到销售。

在编写或评论问题时，请参阅[参考资料/心理学.md](references/psychology.md)——紧张分类法（痛苦/欲望/沮丧）、4-6个量化甜点点和个性化统计数据。

### 3. 结果页面

**核心概念：** 结果页面根据受访者的分数提供个性化价值，创造他们目前状态与可能状态之间的紧张关系，并有一个针对其层级的清晰下一步。

**为什么有效：** 评分、个性化结果比通用建议更有价值，并触发改进的驱动力（见[心理学](#为什么这个系统有效)下方）。

**关键洞察：**
- 显示总分和类别细分，以突出优势和劣势
- 按层级编写动态内容——默认低/中/高；自定义层级（“初创公司/扩展公司/表现者/独角兽”）增加参与度
- 甜点：得分“基础扎实，有改进空间”的潜在客户转化率最高
- PDF报告（个性化封面、详细建议）扩展价值并进入销售会议
- 每个层级不同的CTA：低→免费活动；中→书籍+发现通话；高→直接咨询

**产品应用：**

| 上下文 | 结果元素 | 示例 |
|---------|----------------|---------|
| **总分** | 类别总分 | “你的[主题]评分：67/100” |
| **类别细分** | 可视化优势/劣势 | 5个类别分数的蜘蛛图 |
| **PDF报告** | 个性化可下载文档 | 带有姓名、类别分析、建议的封面 |

**文案模式：**
- “你的[主题]评分是[X]/[总分]。这意味着什么…”
- 低层级： “这个领域需要关注。这里有一些简单的第一步… 我们的团队专门帮助处于你阶段的人。”
- 高层级： “基础优秀！专注于保持标准。我们为像你一样的高级客户在[具体高级报价]上工作。”

**道德边界：** 永远不要夸大或贬低计算分数来引导潜在客户购买——层级必须反映他们的实际答案。

在构建实际工具时，请参阅[参考资料/技术实施.md](references/technical-implementation.md)——评分/权重逻辑、条件内容规则、PDF生成和平台比较。

### 4. 销售和营销

**核心概念：** 将评估数据转化为系统引擎：推广驱动流量到登录页面，而跟进序列按分数层级细分线索，并向转化事件培育他们。

**为什么有效：** 评分卡线索带有自我报告的痛点、资格信号和分数——销售对话从发现转向推荐，自动细分提供每个线索相关的跟进。

**关键洞察：**
- 通过领英投票、Facebook/谷歌广告、电子邮件列表、播客CTA、书籍二维码进行推广
- 完成后立即触发结果电子邮件+PDF；发送放弃电子邮件以恢复未完成的开始
- 按层级细分培育活动——不是一刀切滴灌
- 高价票多步骤漏斗：阶段1（8-15个问题，基本分数）、阶段2（15-25个，详细报告）、阶段3（30-50个，基准+路线图）

**产品应用：**

| 上下文 | 销售/营销策略 | 示例 |
|---------|----------------------|---------|
| **付费流量** | 广告到登录页面 | “你的领导力评分是多少？免费测试” |
| **放弃** | 恢复电子邮件序列 | “你开始测试但没有完成。你的进度已保存。” |
| **销售电话** | 数据驱动的对话 | 代表以“我看到你在运营上得分4/10…”开头 |

**文案模式：**
- “获取[主题]评分卡”作为所有渠道的通用CTA
- 结果电子邮件： “你的[主题]评分已准备好。根据你的结果，我们建议…”
- 培育： “上周你在[类别]上得分[X]。这个月有3种方法可以提高这个分数。”

**道德边界：** 永远不要利用自我报告的痛点来施压潜在客户——他们自愿提供的数据是为了定制帮助，而不是制造紧迫感。

在漏斗实时表现不佳或设置跟踪时，请参阅[参考资料/分析优化.md](references/analytics-optimization.md)——关键指标、要A/B测试的内容、漏斗放弃分析、CRM集成和线索评分。

## 评分卡命名策略

**有效的名称结合**主题清晰度、结果承诺和简洁性。

**公式：**
- “[主题]评分卡” — “业务增长评分卡”
- “[结果]准备度评估” — “领导力准备度评估”
- “你的[主题]评分是多少？” — “你的营销评分是多少？”
- “[形容词][主题]测试” — “完整健康测试”

## 转化基准

- 传统PDF线索磁铁：3-10%转化率
- 评分卡/测验漏斗：30-50%转化率
- 顶尖表现者：70%+优化后的登录页面

## 为什么这个系统有效背后的心理学

1. **紧张创造：** 问题揭示沉睡的欲望
2. **互惠：** 你提供了价值（洞察），他们愿意对话
3. **自我资格：** 他们告诉你他们的问题和预算
4. **个性化：** 人们愿意用定制结果交换数据，然后期望报价与之匹配（支持统计数据保存在参考资料/心理学.md）
5. **游戏化：** 原始驱动力去评分、排名和改进
6. **承诺：** 投入的时间增加跟进

## 实施检查清单

1. [ ] 定义理想客户及其期望结果
2. [ ] 选择一个概念钩子（来自登录页面部分的5种类型之一）
3. [ ] 根据你的方法论编写2-7个评分类别
4. [ ] 创建10-40个有分值的问题
5. [ ] 设置3个评分层级，带有动态内容
6. [ ] 编写带有3C（清晰度、可信度、联系）的登录页面
7. [ ] 配置线索表单字段
8. [ ] 设置带有结果的自动电子邮件
9. [ ] 创建按层级跟进序列
10. [ ] 在发布前用5-10个人测试

## 常见错误

| 错误 | 为什么失败 | 修复 |
|---------|-------------|------|
| **对冷流量问太多问题** | 放弃在15个问题后激增 | 冷8-15个问题；为暖线索保留20-50个 |
| **测验后捕获电子邮件** | 失去所有放弃线索 | 在第一个问题之前捕获线索 |
| **所有层级都使用通用结果** | 没有个性化=没有紧张，没有行动 | 每个层级每个类别都有独特的动态内容 |
| **销售性问题** | “你准备好购买了吗？”破坏信任 | 围绕他们的情况，而不是你的报价 |
| **结果页面上没有明确的CTA** | 潜在客户得到分数就离开了 | 针对每个层级的具体下一步 |
| **一刀切的跟进** | 低和高得分者需要不同的报价 | 按分数层级细分培育活动 |
| **跳过概念钩子** | 登录页面没有吸引力 | 首先对你的受众测试3-5个钩子 |

## 快速诊断

| 问题 | 如果没有 | 行动 |
|----------|-------|--------|
| 钩子是否针对沉睡的欲望？ | 登录页面表现不佳 | 使用5种钩子类型之一重写（见登录页面部分） |
| 是否在问题之前捕获电子邮件？ | 失去所有放弃线索 | 将线索捕获移到问卷之前 |
| 问题是否分组到评分类别中？ | 结果感觉任意 | 创建2-7个类别，带有分值 |
| 每个层级是否都有独特的动态内容？ | 通用结果，没有紧张 | 按层级编写个性化见解和CTA |
| 是否有每个层级的特定CTA？ | 潜在客户没有转化就离开了 | 将每个层级映射到下一步（活动、通话、咨询） |
| 是否按分数细分跟进电子邮件？ | 培育感觉不相关 | 按层级分离序列，带有定制内容 |
