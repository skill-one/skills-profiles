# 可预测收入框架

一种系统化方法，用于构建可扩展、可预测的 B2B 销售机器——即外向型潜在客户开发系统，该系统帮助 Salesforce 增加了 1 亿美元的可重复收入。

## 核心原则

**可预测的潜在客户开发驱动可预测的收入。** 销售中最大的错误是让同一个人进行潜在客户开发和关闭——专业化可以创建可重复、可扩展的机器。传统的冷拨电话已经过时了；冷拨电话 2.0（大规模、个性化的冷电子邮件，为正确的人生成转介）是新的外向型销售方式。

## 评分

**目标：10/10。** 通过为满足五个 [快速诊断](#快速诊断) 行的每个行奖励 2 分（潜在客户开发/关闭分离、定义的外向型流程、3 个月管道可预测性、已知的潜在客户类型组合、标准化的 SDR→AE 移交）来对销售流程进行 0-10 分的评分。等级：**9-10** = 角色分离加上可重复的流程可以预测管道；**5-6** = 某些专业化，但临时的潜在客户开发或不可预测的管道；**≤3** = 一个人进行潜在客户开发和关闭，收入取决于英雄行为。始终提供当前分数和阻止 10/10 的具体诊断行。

## 三种类型的潜在客户

**并非所有潜在客户都是平等的——区别对待。**

| 类型 | 来源 | 转化率 | 成本 | 示例 |
|------|------|--------|------|------|
| **种子** | 口碑、转介、自然 | 最高 | 最低（需要时间） | 客户转介、NPS 驱动 |
| **网** | 营销活动、内向型 | 中等 | 中等 | 内容、SEO、网络研讨会 |
| **矛** | 外向型潜在客户开发 | 较低但可预测 | 较高（人员密集型） | 冷拨电话 2.0 |

**关键洞察：** 大多数公司过度投资于网，而投资于矛不足；种子是最好的，但无法快速制造。相应地投资——客户成功和转介计划（种子）、内容和付费获取（网）、SDR 团队（矛）。

在决定投资何处时查看 [参考资料/lead-types.md](references/lead-types.md)——它根据公司阶段按比例划分种子/网/矛预算。

## 销售角色专业化

**第一个原则：分离潜在客户开发和关闭。** 当 AE 进行潜在客户开发并关闭时，他们会讨厌潜在客户开发，管道就会变成丰年或荒年。

| 角色 | 重点 | 指标 |
|------|------|------|
| **SDR（销售发展代表）** | 外向型潜在客户开发→合格的机遇 | 每月合格的会议 |
| **MDR（市场发展代表）** | 内向型潜在客户资格 | 每月合格的潜在客户 |
| **AE（客户执行代表）** | 关闭交易 | 关闭的收入、胜率 |
| **CSM（客户成功经理）** | 保留和扩展账户 | 保留率、扩展收入 |

### SDR（销售发展代表）

生成合格的管道：研究目标账户、发送冷拨电话 2.0 电子邮件、转介给正确的人、使用 ANUM 资格、传递给 AE。不是他们的工作：关闭、内向型潜在客户或现有客户。一个 SDR 通常每月生成 10-20 个合格的机遇——衡量机遇、响应率、预订会议和管道价值。

### AE（客户执行代表）

从合格的管道关闭交易：运行发现、演示、谈判、关闭、移交给 CSM。不是他们的工作：潜在客户开发（SDR）、内向型资格（MDR）或售后管理（CSM）。衡量关闭的收入、胜率、平均交易规模和销售周期长度。

### CSM（客户成功经理）

保留和扩展账户：入职、推动采用、发现扩展机遇、防止流失。衡量净收入保留率、流失率、扩展收入和 NPS/CSAT。

**良性循环：** SDR 生成管道→AE 关闭→CSM 保留/扩展→满意的客户转介（种子）。

在定义新角色或组织结构时查看 [参考资料/roles.md](references/roles.md)——它包含每个角色的完整章程、职业路径和招聘概况。

## 冷拨电话 2.0

**取代传统冷拨电话的外向型潜在客户开发**，后者在各个方面都失败了：1-3% 的连接率、守门人、品牌损害、没有可扩展性。

```
1. 构建列表→2. 发送大规模电子邮件→3. 获取转介→4. 联系转介→5. 资格
```

### 第 1 步：构建目标账户列表

定义您的理想客户画像（公司规模、行业、技术堆栈、地理位置、痛点），然后通过 LinkedIn 销售导航器、ZoomInfo/Apollo/Clearbit 或行业目录构建列表。每个 SDR 每个季度目标为 200-500 个账户。

### 第 2 步：转介电子邮件

**核心创新：不要直接给决策者发电子邮件——给他们的上级发电子邮件并请求向下转介。** 高级人员会转发电子邮件，并且转介的响应率会提高 3-5 倍，因为介绍来自公司内部。电子邮件只要求一件事——“谁是合适的人？”——少于 100 个字，没有推销内容、没有附件、没有链接、易于转发。响应率：9-15% 对比传统冷电子邮件的 1-3%。有关逐字模板、主题行打开率表和完整的 Day 1/3/7/14/30 序列正文，请打开 [参考资料/cold-calling-2.md](references/cold-calling-2.md)。

### 第 3 步：跟进

| 天数 | 行动 |
|------|------|
| 1 | 发送转介电子邮件 |
| 3 | 如果没有回复，跟进 |
| 7 | 第二次跟进（不同的角度） |
| 14 | 终止电子邮件（“我应该关闭您的文件吗？”） |
| 30 | 重新参与（新的触发事件或内容） |

第 14 天的**终止电子邮件**通常在序列中获得了最高的响应——人们会对失去机会做出反应（稀缺性）。

### 第 4 步：使用 ANUM 资格

| 标准 | 问题 | 强信号 | 弱信号 |
|------|------|--------|--------|
| **A** 权限 | 这个人能决定吗？ | 决策者或强影响者 | 没有购买力 |
| **N** 需求 | 他们有您解决的问题吗？ | 活动的痛点，寻求解决方案 | “有好处” |
| **U** 紧迫性 | 他们何时必须解决？ | 本季度，预算已分配 | “以后再说” |
| **M** 金钱 | 他们能负担得起吗？ | 预算存在，在范围内 | 没有预算，太贵 |

电话结构：建立关系（2 分钟）→ 设置议程（“了解您的情况，看看是否有匹配”）→ 带有 ANUM 的发现问题（10-15 分钟）→ 下一步（如果合格，安排 AE 演示）。

### 第 5 步：移交给 AE

包括账户背景和 ICP 匹配、联系信息和角色、痛点、ANUM 笔记、商定的下一步和竞争情报。SDR 在简短的 3 方通话或电子邮件中介绍 AE，然后放下。

**道德界限：** 遵守垃圾邮件法律（CAN-SPAM、GDPR）并立即尊重退订——包括立即从序列中删除敌对的“停止给我发电子邮件”，而不是在下一个预定接触时删除。

在运行 ANUM 发现通话时查看 [参考资料/资格.md](references/qualification.md)——它包含每个标准的完整发现问题库。

## 管道数学

从收入目标倒推：

```
收入目标 ÷ 平均交易规模 = 需要的交易
需要交易 ÷ 胜率 = 需要的机遇
需要的机遇 ÷ SDR 转化率 = 需要的潜在客户
需要的潜在客户 ÷ 响应率 = 需要的电子邮件
```

**示例：** $100 万 ARR ÷ $20K 交易 = 50 笔交易；÷ 25% 胜率 = 200 个机遇；在 10% 响应率和 10% 响应到合格转化的情况下 = 20,000 封电子邮件 ≈ 2-3 SDR（每个发送 300-500/月）。

| 指标 | 基准 |
|------|------|
| 每天每 SDR 的电子邮件数量 | 50-100 |
| 响应率 | 9-15% |
| 每月每 SDR 的合格机遇 | 10-20 |
| AE 演示到关闭率 | 20-30% |
| 平均销售周期 | 30-90 天 |

在根据收入目标调整 SDR 团队规模时查看 [参考资料/pipeline-math.md](references/pipeline-math.md)——它包含完整的产能规划和收入模型模板。

## 构建销售发展团队

在您想要一个关于建立或扩展机器的完整先例时查看 [参考资料/案例研究.md](references/case-studies.md)——它逐步介绍了 Salesforce、HubSpot 和其他实施，包括起始状态、结果和失败模式。

### 招聘 SDR

招聘可指导性（最重要的特质）、好奇心、强写作能力、韧性和组织能力——经验是可选的。寻找应届毕业生、职业转换者和内部调动。职业路径：SDR（6-18 个月）→ 高级 SDR → AE 或 SDR 经理。

### SDR 爆发时间

| 阶段 | 时间线 | 期望 |
|------|------|------|
| 培训 | 第 1-2 周 | 产品知识、工具、流程 |
| 影子 | 第 3-4 周 | 观察经验丰富的 SDR，练习 |
| 爆发 | 第 2-3 个月 | 50% 的配额 |
| 完全配额 | 第 4 个月及以后 | 100% 的配额 |

期望 3-4 个月才能完全投入生产。

### SDR 薪酬

基本加变量，通常为 60/40 或 70/30。按生成的合格机遇支付变量，并为关闭的机遇和超出配额提供奖金。

在招聘或构建薪酬计划时查看 [参考资料/团队建设.md](references/team-building.md)——它包含面试评分卡、入职课程和详细的薪酬结构。

## 指标和仪表板

### 领先指标（可预测的）

每天每 SDR 发送的电子邮件数量、响应率、每周预订的会议、每月合格的机遇、生成的管道价值。

### 滞后指标（结果）

关闭的收入、胜率、平均交易规模、销售周期长度、客户获取成本（CAC）。

### 效率指标

每个合格机遇的成本、SDR:AE 比率（通常为 2-3 个 SDR 每个AE）、LTV:CAC（目标 >3:1）、投资回报期。

**节奏：** 每日活动指标→每周管道→每月收入→每季度效率。

在构建销售仪表板时查看 [参考资料/metrics.md](references/metrics.md)——它包含 KPI 定义、公式和按节奏划分的仪表板布局。

## 常见错误

| 错误 | 为什么失败 | 修复 |
|------|----------|------|
| **AE 进行潜在客户开发** | 丰年或荒年管道 | 招聘专门的 SDR |
| **长、推销性的电子邮件** | 响应率低 | 短、转介为重点的电子邮件 |
| **没有 ICP 定义** | 浪费在错误的账户上的努力 | 在招聘 SDR 之前定义 ICP |
| **SDR 太少** | 没有足够的管道 | 从收入目标倒推 |
| **没有移交流程** | 潜在客户掉落 | 标准化 SDR→AE 移交 |
| **衡量活动，而不是结果** | 忙碌但效率低下 | 跟踪合格的机遇，而不是电子邮件 |

## 快速诊断

审计任何 B2B 销售流程：

| 问题 | 如果没有 | 行动 |
|------|----------|------|
| 潜在客户开发和关闭是否分离？ | SDR 做两者=瓶颈 | 创建专门的 SDR 角色 |
| 是否有定义的外向型流程？ | 临时的潜在客户开发 | 实施 Cold Calling 2.0 |
| 您能否预测 3 个月的管道？ | 收入不可预测 | 构建管道数学模型 |
| 您是否知道您的潜在客户类型组合？ | 过度依赖一个来源 | 平衡种子、网、矛 |
| SDR→AE 移交是否标准化？ | 潜在客户在过渡中丢失 | 创建移交清单 |
