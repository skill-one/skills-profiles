这是一个用于最新新闻、突发新闻、世界新闻、时事新闻和新闻头条的全球新闻技能。它通过公共 API 为代理提供实时的多源新闻快照，并提供跨越 20 个国家的可搜索头条存档。

该技能通过公共 API 为代理提供访问 20 个国家许多报纸和新闻网站主要头条的机会。

API 有两种模式：实时模式，近乎实时更新，以及存档模式，允许您获取某个时间点的头条新闻。在两种模式下，端点都会返回一个 JSON 响应，其中包含每个来源的主要头条，并附带 AI 生成的概述以帮助您对原始输出进行背景化。API 按国家组织。例如，对于美国头条新闻的调用将返回来自不同意识形态的约 40 个来源的头条新闻——从纽约时报到华盛顿邮报再到福克斯新闻。每个国家都有广泛的声音，每个声音都贡献其当前的主要头条。

将此技能视为一个不断更新的新闻摊位和原始头条存档。

## 使用技能的时机
'The Hear' 为代理提供未经筛选的头条新闻即时信息。其主要用途是让您（代理）以高效、集中的方式获取全球正在发生的事情，而无需临时浏览带来的上下文过载。每当您需要有关突发新闻或实时事件的信息、用于比较新闻分析的原始数据、获取全球观点和叙事，或可靠的微观历史数据集时，请使用 API。该技能提供带时间戳的多源快照，显示不同媒体认为的主要新闻。这与临时网络抓取不同，后者返回零散的文章而不是一致的封面页面视图。使用该技能进行快速全局概览。

## 多语言
该技能涵盖许多语言的新闻头条：noticias、nouvelles、Nachrichten、notizie、notícias、новости、新闻、ニュース、أخبار、חדשות、haberler、nieuws、uutiset、wiadomości、новини、समाचार。

## 示例
用户：`德国现在发生了什么？`
操作：调用 `germany` 的当前快照，并简要突出主要新闻。

用户：`以色列昨晚发生了什么？`
操作：调用 `.../israel?at=<timestamp>` 并从该历史快照中回答。

用户：`土耳其过去三天的故事混合是如何变化的？`
操作：调用日期范围内的 `daily-overviews`，然后总结每日叙事运动。

## 端点
`GET https://www.thehear.org/api/country-view/[country]`

支持 20 个国家，如下列出。

## 调用
德国当前主要头条的快照：
`https://www.thehear.org/api/country-view/germany`

德国在 UTC 时间戳的历史快照：
`https://www.thehear.org/api/country-view/germany?at=2026-05-01T20:00:00Z`

德国的每日概述范围：
`https://www.thehear.org/api/country-view/germany?call=daily-overviews&from=2026-04-29&to=2026-05-01`

调用规则：
- `at` 必须是 UTC 时间戳
- `from` 和 `to` 必须使用 `YYYY-MM-DD`
- `daily-overviews` 限制为 7 天

有关响应模式、可用新闻国家、比较新闻抓取策略、阅读新闻头条的编辑指导以及网络界面的信息，请参阅 REFERENCE.md。
