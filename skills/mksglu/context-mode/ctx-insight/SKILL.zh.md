# 上下文模式洞察

在用户默认浏览器中打开托管式洞察面板。

## 操作说明

1. 调用 `ctx_insight` MCP 工具（无需参数）。该工具将在默认浏览器中打开
   <https://context-mode.com/insight> 并返回一条确认信息。
2. 向用户显示工具的输出。
3. 告知用户：
   - "已在 https://context-mode.com/insight 打开洞察面板"
   - context-mode.com/insight 的登录页面是登录和价格信息的唯一权威来源。
   - 如果浏览器未自动打开，请分享 URL 以便用户手动打开。
