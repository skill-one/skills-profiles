# 上下文模式统计

显示当前会话的上下文节省情况。

## 使用说明

1. 调用 `mcp__context-mode__ctx_stats` MCP 工具（无需参数）。
2. **关键提示**：你必须将工具输出的**全部内容**作为 Markdown 文本直接复制粘贴到你的回复消息中。不要总结，不要折叠，不要释义。用户必须能看到完整的表格，而无需按 ctrl+o。精确复制工具返回的每一行。
3. 输出全部内容后，添加一句突出关键节省指标的话，例如：
   - "上下文模式节省了 **12.4倍** — 92% 的数据保留在沙盒中。"
   - 如果还没有数据： "本次会话尚未有上下文模式调用。"

## 清理

- **`ctx_purge(confirm: true)`** — 永久删除知识库中的所有索引内容。使用 `/context-mode:ctx-purge` 执行此操作。
