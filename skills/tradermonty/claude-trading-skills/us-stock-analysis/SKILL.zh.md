# 美股分析

## 概述

对美股进行全面分析，涵盖基本面分析（财务状况、业务质量、估值）、技术分析（指标、趋势、模式）、同行比较，并生成详细的投资报告。通过网络搜索工具获取实时市场数据，并应用结构化分析框架。

## 数据来源

始终使用网络搜索工具收集当前市场数据：

**主要获取数据：**
1. **当前股价和交易数据**（价格、成交量、52周区间）
2. **财务报表**（损益表、资产负债表、现金流量表）
3. **关键指标**（市盈率、每股收益、收入、利润率、债务比率）
4. **分析师评级和目标价**
5. **最新新闻和发展动态**
6. **同行/竞争对手数据**（用于比较）
7. **技术数据**（移动平均线、相对强弱指数、MACD，当可用时）

**搜索策略：**
- 使用股票代码 + 需要的具体数据（例如，"AAPL 2024 财务指标"）
- 用于全面数据：搜索收益报告、投资者演示文稿或 SEC 文件
- 用于技术数据：搜索 "AAPL 技术分析" 或使用金融数据网站
- 始终验证数据时效性（优先考虑上个季度的数据）

**优质来源：**
- Yahoo Finance、Google Finance、MarketWatch、Seeking Alpha、Bloomberg、CNBC
- 公司投资者关系页面
- SEC 文件（10-K、10-Q）用于详细财务数据
- TradingView、StockCharts 用于技术数据

## 分析类型

本技能支持四种分析类型。确定用户需要哪种类型：

1. **基本股票信息** - 快速概览，包含关键指标
2. **基本面分析** - 深入了解业务、财务状况、估值
3. **技术分析** - 图表模式、指标、趋势分析
4. **综合报告** - 结合所有方法的完整分析

## 分析工作流程

### 1. 基本股票信息

**使用场景：** 用户需要快速概览或基本信息

**步骤：**
1. 搜索当前股票数据（价格、成交量、市值）
2. 收集关键指标（市盈率、每股收益、收入增长率、利润率）
3. 获取52周区间和年初至今表现
4. 查找最新新闻或重大发展动态
5. 以简洁的摘要格式呈现

**输出格式：**
- 公司简介（1-2句话）
- 当前价格和交易指标
- 关键估值指标（表格）
- 近期表现
- 值得注意的最新新闻（如有）

### 2. 基本面分析

**使用场景：** 用户需要财务分析、估值评估或业务评估

**步骤：**
1. **收集全面财务数据：**
   - 收入、收益、现金流量（3-5年趋势）
   - 资产负债表指标（债务、现金、营运资本）
   - 盈利能力指标（利润率、净资产收益率、投资回报率）

2. **参考 references/fundamental-analysis.md** 获取分析框架

3. **参考 references/financial-metrics.md** 获取指标定义和计算方法

4. **分析业务质量：**
   - 竞争优势
   - 管理层业绩记录
   - 行业地位

5. **执行估值分析：**
   - 计算关键比率（市盈率、市净率、市销率、企业价值/息税折旧摊销前利润）
   - 与历史平均水平比较
   - 与同行组比较
   - 估算合理价值区间

6. **识别风险：**
   - 公司特定风险
   - 市场宏观风险
   - 财务数据中的警示信号

7. **生成输出**，遵循 references/report-template.md 结构

**关键分析：**
- 盈利能力趋势（利润率改善/下降）
- 现金流量质量（自由现金流与收益）
- 资产负债表强度（债务水平、流动性）
- 增长可持续性
- 估值与同行和历史平均值的比较

### 3. 技术分析

**使用场景：** 用户需要技术分析、图表模式或交易信号

**步骤：**
1. **收集技术数据：**
   - 当前价格和近期价格走势
   - 成交量趋势
   - 移动平均线（20日、50日、200日）
   - 技术指标（相对强弱指数、MACD、布林带）

2. **参考 references/technical-analysis.md** 获取指标定义和模式

3. **识别趋势：**
   - 上升趋势、下降趋势或横盘
   - 趋势强度

4. **定位支撑和阻力水平：**
   - 近期高低点
   - 移动平均线水平
   - 整数价位

5. **分析指标：**
   - 相对强弱指数：超买（>70）或超卖（<30）
   - MACD：交叉和背离
   - 成交量：确认或背离
   - 布林带：收窄或扩张

6. **识别图表模式：**
   - 反转模式（头肩顶、双顶/双底）
   - 持续模式（旗形、三角形）

7. **生成技术展望：**
   - 当前趋势评估
   - 关键水平观察
   - 风险/回报分析
   - 短期和中期展望

**解读指南：**
- 使用多个指标确认信号
- 考虑成交量进行验证
- 注意价格与指标之间的背离
- 始终确定风险水平（止损）

### 4. 综合投资报告

**使用场景：** 用户需要详细报告、投资建议或完整分析

**步骤：**
1. **执行数据收集**（如基本信息部分）

2. **执行基本面分析**（遵循上述工作流程）

3. **执行技术分析**（遵循上述工作流程）

4. **参考 references/report-template.md** 获取完整报告结构

5. **综合分析结果：**
   - 整合基本面和技术分析见解
   - 制定看涨和看跌案例
   - 评估风险/回报

6. **生成建议：**
   - 买入/持有/卖出评级
   - 目标价及时间范围
   - 信心水平
   - 入场策略

7. **创建格式化报告**，遵循模板结构

**报告必须包含：**
- 带有建议的执行摘要
- 公司概述
- 投资逻辑（看涨和看跌案例）
- 基本面分析部分
- 技术分析部分
- 估值分析
- 风险评估
- 催化因素和时间表
- 结论

## 股票比较分析

**使用场景：** 用户需要比较两只或更多股票（例如，“比较 AAPL vs MSFT”）

**步骤：**
1. **收集所有股票的数据：**
   - 遵循每个股票代码的数据收集步骤
   - 确保可比时间段

2. **参考 references/fundamental-analysis.md** 和 references/financial-metrics.md

3. **创建并排比较：**
   - 业务模式比较
   - 财务指标表格（所有关键比率）
   - 估值指标表格
   - 增长率比较
   - 盈利能力比较
   - 资产负债表强度

4. **识别相对优势：**
   - 每家公司擅长的领域
   - 量化优势

5. **技术比较：**
   - 相对强度
   - 动量比较
   - 哪个处于更好的技术位置

6. **生成建议：**
   - 哪只股票更具吸引力及其原因
   - 考虑基本面和技术因素
   - 投资组合配置建议
   - 风险调整后回报评估

**输出格式：** 遵循 references/report-template.md 中的“比较报告结构”

## 输出指南

**一般原则：**
- 使用表格表示财务数据和比较（便于扫描）
- 突出显示关键指标和发现
- 包含数据来源和日期
- 尽可能量化
- 呈现看涨和看跌观点
- 明确假设和不确定性

**格式化：**
- **标题** 用于清晰分隔章节
- **表格** 用于指标、比较、历史数据
- **项目符号** 用于列表、因素、风险
- **粗体文本** 用于关键发现、重要指标
- **百分比** 用于增长率、回报、利润率
- **货币** 格式一致（$B 表示十亿，$M 表示百万）

**语气：**
- 客观平衡
- 承认不确定性
- 用数据支持主张
- 避免夸张
- 清晰呈现风险
