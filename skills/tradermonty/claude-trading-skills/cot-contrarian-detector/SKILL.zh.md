# COT 逆势探测器

## 概述

实现杰森·沙皮罗（Jason Shapiro）COT（交易商承诺）逆势流程的第一步：检测大型投机者何时被挤入期货市场的单边。拥挤头寸是逆势交易的*前提条件*，而不是交易信号——市场只有在拥挤被新闻失败和价格行为反转（步骤2-3）确认后才是可交易的，而这项技能将指导用户手动完成这些步骤。

**核心论点（沙皮罗）：** 大型投机者（对冲基金、CTA、动量交易者）倾向于在趋势衰竭时达到最大头寸，而不是在趋势启动时。当它们已经被挤入单边时，下一次大行情更有可能将它们轧空，而不是进一步奖励它们。对投机者进行逆势操作，而不是对商业头寸（商业头寸因结构性原因进行对冲，并且不是群体心理信号）。

## 何时使用此技能

**英文：**
- “投机者目前被挤入哪些市场？”
- “运行COT报告分析” / “显示COT头寸极端情况”
- “现在有人在黄金/美元/债券中被‘困住’吗？”
- 用户想寻找逆势期货设置
- 用户要求进行杰森·沙皮罗风格的COT筛选

**日文：**
- 「COTレポートで買われすぎ・売られすぎのポジションを調べて」
- 「投機筋が偏っている市場は？」
- 「ジェイソン・シャピロ式の逆張り分析をして」

**不要使用的情况：**
- 用户需要当前的交易信号——单独的拥挤是不可操作的；见下方的安全护栏
- 用户询问个股——COT报告仅涵盖CFTC期货市场（指数、利率、外汇、金属、能源、农业、加密货币），不包括单只股票

## 前置条件

- **FMP API密钥：** 必须设置。设置`FMP_API_KEY`环境变量或传递`--api-key`。**COT端点需要FMP Premium+计划**——免费层密钥将无法访问。
- **Python 3.9+** 并安装`requests`。
- **API预算：** 每个市场一次调用（`--core`为23次，完整宇宙最多~65次），加上当既不给出`--symbols`也不给出`--core`时的市场列表调用一次。

## 工作流程

### 第一阶段：运行拥挤筛选

```bash
# 精选核心期货宇宙（23个流动性/代表性市场）
python3 skills/cot-contrarian-detector/scripts/screen_cot_crowding.py --core --output-dir reports/

# 明确的符号
python3 skills/cot-contrarian-detector/scripts/screen_cot_crowding.py --symbols "ES,GC,CL" --output-dir reports/

# 完整宇宙（所有~65个FMP的COT列表涵盖的市场）
python3 skills/cot-contrarian-detector/scripts/screen_cot_crowding.py --output-dir reports/
```

脚本获取每个市场的每周传统COT报告（大型投机者多空头寸），计算每个市场的156周（3年）和26周COT指数，并对极端情况进行分类：

- `CROWDED_LONG` — COT指数 >= 90（接近3年净多头高位）
- `CROWDED_SHORT` — COT指数 <= 10（接近3年净空头高位）
- `NEUTRAL` — 介于两者之间

计算指数所需历史数据不足的市场不会被无声地忽略——它们会出现在`skipped`列表中，并附带原因（例如“历史数据不足：40/156周”）。

### 第二阶段：展示拥挤报告

展示生成的Markdown报告，突出显示：
- 哪些市场是`CROWDED_LONG` / `CROWDED_SHORT` 以及程度如何
- 26周指数作为背景（拥挤是新鲜的还是陈旧的？）
- 周环比净头寸波动（快速移动的群体更脆弱）
- 方法论注释和免责声明——拥挤不是交易信号

### 第三阶段：手动指导步骤2-5（沙皮罗流程）

对于用户想要追求的任何`CROWDED_LONG` / `CROWDED_SHORT`市场，加载`references/shapiro-methodology.md`并逐步完成剩余步骤——这些**不会自动完成**：

1. ~~拥挤检测~~（已完成——这项技能）
2. **新闻失败**——使用WebSearch检查最近对群体方向有利的新闻是否未能按群体的预期推动价格（例如，拥挤多头市场在利好消息中没有上涨）。这是核心优势，也是最重要的手动确认。
3. **价格行为确认**——检查周线图是否有反转模式或在新高/新低处失败。
4. **入场**——对群体进行逆势操作，以最近摆动极端点为止损，并使用小而固定的风险规模（见`position-sizer`技能）。
5. **出场**——当头寸趋于中性（COT指数回到50附近）或止损被触发时。

仅凭拥挤不要建议入场——步骤2和3必须首先确认。

## 输出

- **JSON：** `reports/cot_crowding_<as-of-date>.json` — 机器可读，包含`run_context`块（schema_version, params, universe, data_date）以及`markets`（排名结果）和`skipped`（不会被无声地忽略）。
- **Markdown：** `reports/cot_crowding_<as-of-date>.md` — 人类可读报告，包含拥挤多头 / 拥挤空头 / 完整排名 / 周环比波动 / 跳过市场 / 方法论部分。

## 节奏

CFTC在周五下午3:30 ET发布COT报告，头寸截至**前一星期二**——数据在发布时总是3天以上陈旧，到下一个周五最多9天陈旧。运行此技能：
- **每周**，在周五发布后或周末，以获取最新数据
- **临时**，当用户询问特定市场的头寸时——无论哪种情况，底层数据都来自最新的周五发布

## 安全护栏

- **单独的拥挤不是交易信号。** 它是一个前提条件。在`references/shapiro-methodology.md`的步骤2（新闻失败）和步骤3（价格行为）也确认之前，不要建议入场。
- **数据是滞后的。** COT头寸在读取时是3-9天陈旧；不要将它们视为实时信号。
- **对投机者进行逆势操作，而不是对商业头寸。** 此技能仅查看非商业（“大型投机者”）头寸——商业对冲流量因结构性原因而不同，并且不是群体心理信号。
- **不是投资建议。** 所有输出仅供研究/教育目的。
