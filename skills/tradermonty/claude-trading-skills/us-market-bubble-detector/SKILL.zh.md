# 美国市场泡沫检测技能（修订版v2.1）

## v2.1版本中的关键修订

**与v2.0相比的重大变更：**
1. ✅ **强制性量化数据收集** - 使用测量值，而非印象或猜测
2. ✅ **明确的阈值设置** - 每个指标都有具体的数值标准
3. ✅ **两阶段评估流程** - 量化评估 → 定性调整（严格顺序）
4. ✅ **更严格的定性标准** - 最高+3分（从+5分降低），需要可衡量的证据
5. ✅ **防止确认偏差** - 明确的检查清单，避免过度评分
6. ✅ **细粒度风险阶段** - 增加了"风险升高"阶段（8-9分），用于精细化的风险管理

---

## 使用此技能的时机

在以下情况下使用此技能：

**英文：**
- 用户询问"市场是否处于泡沫中？"或"我们是否处于泡沫中？"
- 用户寻求关于获利了结、新入场时机或卖空决策的建议
- 用户报告社会现象（非投资者入场、媒体狂热、IPO泛滥）
- 用户提到"这次不同了"或"革命性技术"成为主流的叙事
- 用户咨询现有头寸的风险管理

**日文：**
- ユーザーが「今の相場はバブルか？」と尋ねる
- 投資の利確・新規参入・空売りのタイミング判断を求める
- 社会現象(非投資家の参入、メディア過熱、IPO氾濫)を観察し懸念を表明
- 「今回は違う」「革命的技術」などの物語が主流化している状況を報告
- 保有ポジションのリスク管理方法を相談

## 评估流程（严格顺序）

### 第一阶段：强制性量化数据收集

**关键：** 开始评估前必须收集以下数据

#### 1.1 市场结构数据（最高优先级）
```
□ 买/卖期权比率（CBOE股票买/卖期权比率）
  - 来源：CBOE DataShop或web_search "CBOE买/卖期权比率"
  - 收集：5日移动平均

□ VIX（恐惧指数）
  - 来源：Yahoo Finance ^VIX或web_search "VIX当前"
  - 收集：当前值 + 过去3个月的百分位数

□ 波动性指标
  - 21日已实现波动率
  - VIX的历史位置（确定是否在最低10分位数）
```

#### 1.2 杠杆与头寸数据
```
□ FINRA 保证金债务余额
  - 来源：web_search "FINRA保证金债务最新"
  - 收集：最新月份 + 同比变化

□ 广度（市场参与度）
  - S&P 500中超过50日移动平均的股票百分比
  - 来源：web_search "S&P 500广度50天移动平均"
```

#### 1.3 IPO与新发行数据
```
□ IPO数量与首日表现
  - 来源：Renaissance Capital IPO或web_search "IPO市场 2025"
  - 收集：季度数量 + 中位数首日回报率
```

**⚠️ 关键：** 未收集第一阶段数据不得进行评估

---

### 第二阶段：量化评估（量化评分）

使用收集到的数据，根据以下标准进行机械评分：

#### 指标1：买/卖期权比率（市场情绪）
```
评分标准：
- 2分：P/C < 0.70（过度乐观，看涨期权为主）
- 1分：P/C 0.70-0.85（略微乐观）
- 0分：P/C > 0.85（健康谨慎）

理由：P/C < 0.7在历史上是泡沫时期的特征
```

#### 指标2：波动性抑制 + 新高
```
评分标准：
- 2分：VIX < 12 AND 主要指数在52周高位的5%以内
- 1分：VIX 12-15 AND 接近高点
- 0分：VIX > 15 OR 距离高点超过10%

理由：极低波动性 + 高点表明过度自满
```

#### 指标3：杠杆（保证金债务余额）
```
评分标准：
- 2分：YoY +20%或更多 AND 历史最高
- 1分：YoY +10-20%
- 0分：YoY +10%或更少 OR 负增长

理由：杠杆快速增加是泡沫的先兆
```

#### 指标4：IPO市场过热
```
评分标准：
- 2分：季度IPO数量 > 5年平均的2倍 AND 中位数首日回报率 +20%+
- 1分：季度IPO数量 > 5年平均的1.5倍
- 0分：正常水平

理由：劣质IPO泛滥是后期泡沫的特征
```

#### 指标5：广度异常（领导力狭窄）
```
评分标准：
- 2分：新高 AND < 45%的股票超过50DMA（领导力狭窄）
- 1分：45-60%超过50DMA（略微狭窄）
- 0分：> 60%超过50DMA（健康广度）

理由：由少数股票推动的反弹是脆弱的
```

#### 指标6：价格加速
```
评分标准：
- 2分：过去3个月回报率超过过去10年的95分位数
- 1分：过去3个月回报率在过去的85-95分位数之间
- 0分：低于85分位数

理由：快速价格加速是不可持续的
```

---

### 第三阶段：定性调整（修订版v2.1）

**限制：** 最高+3分（从v2.0的+5分降低）

**⚠️ 确认偏差预防检查清单：**
```
添加任何定性分数前：
□ 我是否有具体、可衡量的数据？（非印象）
□ 一个独立观察者是否会得出相同结论？
□ 我是否避免了与第二阶段的分数重复计算？
□ 我是否已记录具体证据并注明来源？
```

#### 调整A：社会渗透（0-1分，严格标准）
```
+1分：必须满足所有三个标准：
  ✓ 直接用户报告非投资者的建议
  ✓ 具体示例，包括名称/日期/对话
  ✓ 多个独立来源（最少3个）

+0分：任何标准缺失

⚠️ 无效示例：
- "AI叙事很普遍"（不可衡量）
- "我看到关于Takaichi贸易的文章"（非直接报告）
- "每个人都在谈论股票"（模糊，未验证）

✅ 有效示例：
"我的理发师询问了NVDA（11月1日），牙医提到了AI股票（11月2日），
Uber司机讨论了加密货币（11月3日）"
```

#### 调整B：媒体/搜索趋势（0-1分，需要测量）
```
+1分：必须满足两个标准：
  ✓ Google Trends显示同比增长5倍以上（测量）
  ✓ 主流报道得到确认（Time封面，电视特别节目有日期）

+0分：搜索趋势 <5倍 OR 无主流报道

⚠️ 关键："叙事升高"无数据 = +0分

如何验证：
1. 搜索"[主题] Google Trends 2025"并记录数字
2. 搜索"[主题] Time杂志封面"以获取具体日期
3. 搜索"[主题] CNBC特别节目"以确认节目

✅ 有效示例：
"Google Trends：'AI股票'为780（基线150 = 5.2倍）。
Time封面'AI革命'（2025年10月15日）。
CNBC 'AI投资特别节目'（2025年10月3个节目）。"

⚠️ 无效示例：
"AI/技术叙事似乎升高"（不可衡量）
```

#### 调整C：估值脱节（0-1分，避免重复计算）
```
+1分：必须满足所有标准：
  ✓ P/E >25（如果未在第二阶段量化评分中计算）
  ✓ 主流讨论中明确忽略基本面
  ✓ "这次不同了"在主要媒体中有记录

+0分：P/E <25 OR 基本面支持估值

⚠️ 自查问题（如果任何为是，分数=0）：
- P/E是否已在第二阶段量化评分中？
- 公司是否有真实收益支持估值？
- 叙事是否得到基本面改善的支持？

✅ 有效示例 (+1分)：
"S&P P/E = 35倍（历史18倍）。
CNBC文章：'收益不重要在AI时代'（2025年10月）。
彭博：'传统指标过时'（2025年11月）。"

⚠️ 无效示例：
"P/E 30.8但公司有真实收益且AI有基本面支持"
（基本面支持 = +0分）
```

**第三阶段总分：最多+3分**

---

### 第四阶段：最终判断（修订版v2.1）

```
最终分数 = 第二阶段总分（0-12分）+ 第三阶段调整（0到+3分）
范围：0到15分

判断标准（与风险预算）：
- 0-4分：正常（风险预算：100%）
- 5-7分：谨慎（风险预算：70-80%）
- 8-9分：风险升高（风险预算：50-70%） ⚠️ v2.1新增
- 10-12分：狂热（风险预算：40-50%）
- 13-15分：关键（风险预算：20-30%）
```

**v2.1中的关键变更：**
- 增加了"风险升高"阶段（8-9分），用于更精细化的定位
- 9分不再是极端防御区（之前为40%风险预算）
- 现在允许在8-9分水平使用50-70%风险预算
- 从谨慎到狂热阶段过渡更平滑

## 重要原则（修订版）

### 1. 数据 > 印象
忽略"许多新闻报道"或"专家表示谨慎"，没有量化数据。

### 2. 严格顺序：量化 → 定性
始终按此顺序评估：第一阶段（数据收集）→ 第二阶段（量化）→ 第三阶段（定性调整）。

### 3. 定性指标的上限
定性调整总分限制为+5分。它不能推翻量化评估。

### 4. "出租车司机"是象征性的
不要轻易承认大众渗透，除非非投资者直接提出建议。

## 常见错误及解决方案（修订版）

### 错误1：基于新闻报道评估
❌ "许多关于Takaichi贸易的报道" → 媒体饱和2分
✅ 验证Google Trends数字 → 使用测量值评估

### 错误2：对专家评论过度反应
❌ "警告过热" → 狂热区
✅ 使用Put/Call、VIX、保证金债务的测量值进行判断

### 错误3：对价格上涨情绪化反应
❌ 1天内上涨4.5% → 价格加速2分
✅ 验证在10年分布中的位置 → 客观评估

### 错误4：仅基于估值判断
❌ P/E 17 → 估值脱节2分
✅ P/E + 叙事依赖 + 其他量化指标进行综合判断

## 根据泡沫阶段推荐的行动（修订版v2.1）

### 正常（0-4分）
**风险预算：100%**
- 继续正常投资策略
- 设置ATR 2.0×跟踪止损
- 应用阶梯式获利了结规则（+20%获利了结25%）

**卖空：不允许**
- 综合条件未满足（0/7项）

### 谨慎（5-7分）
**风险预算：70-80%**
- 开始部分获利了结（减少20-30%）
- 收紧ATR至1.8×
- 减少新头寸规模50%

**卖空：不推荐**
- 等待更清晰的反转信号

### 风险升高（8-9分） ⚠️ v2.1新增
**风险预算：50-70%**
- 增加获利了结（减少30-50%）
- 收紧ATR至1.6×
- 新头寸：高度选择性，仅优质
- 开始建立现金储备以抓住未来机会

**卖空：谨慎考虑**
- 确认至少2/7综合条件后
- 小型探索性头寸（正常规模的10-15%）
- 严格止损（ATR 2.0×）

**新增阶段理由：**
此区域代表高度谨慎，但非极端防御。
市场显示警告信号，但非立即崩溃。
保持对优质头寸的敞口，同时建立灵活性。

### 狂热（10-12分）
**风险预算：40-50%**
- 加速阶梯式获利了结（减少50-60%）
- 收紧ATR至1.5×
- 除重大回调外，不建立新多头头寸

**卖空：积极考虑**
- 确认至少3/7综合条件后
- 小型头寸（正常规模的20-25%）
- 定义风险（期权，紧止损）

### 关键（13-15分）
**风险预算：20-30%**
- 主要获利了结或完全对冲实施
- ATR 1.2×或固定止损
- 现金保存模式 - 准备重大错位

**卖空：推荐**
- 确认至少5/7综合条件后
- 小型头寸逐步加仓，确认后金字塔式加码
- 紧止损（ATR 1.5×或更高）
- 考虑买入看跌期权以定义风险

---

## 卖空的综合条件（7项）

确认至少满足以下3项后，才考虑卖空：

```
1. 周线图显示更低高点
2. 量能见顶
3. 杠杆指标急剧下降（保证金债务下降）
4. 媒体/搜索趋势见顶
5. 弱势股票率先下跌
6. VIX飙升（超过20）
7. 联邦政策变化信号
```

## 摘要：v2.1 修订要点

**v2.0 问题（识别于2025年11月）：**
- 定性调整过于宽松（最高+5分）
- "AI叙事提升" → +1分（无数据）
- "市盈率30.8" → +1分（与定量重复计算）
- **结果：11/16分 - 缺乏证据的过度悲观**

**v2.1 解决方案：**
- 定性调整更严格（最高+3分）
- "AI叙事提升" → 0分（未量化）
- "市盈率30.8但AI有基本面支撑" → 0分（基本面支持）
- **结果：9/15分 - 平衡、数据驱动的评估**

**关键改进：**
1. **防止确认偏差：** 添加定性分数前需执行明确清单
2. **要求可衡量证据：** 无具体数据（谷歌趋势、媒体报道）不得给分
3. **防止重复计算：** 估值不得与第二阶段定量重复
4. **细化风险阶段：** 增加"提升风险"（8-9分）用于精细化定位
5. **平衡风险预算：** 9分=50-70%（非40%极端防御）

**核心原则：**
> "我们信仰上帝；其他人必须提供数据。" - W. Edwards Deming

**2025年教训：**
即使数据驱动框架也可能因主观定性调整而被削弱。
v2.1要求所有定性分数必须有**可衡量证据**。
独立观察者必须能验证每次调整。

**版本历史：**
- **v2.0**（2025年10月27日）：强制收集定量数据
- **v2.1**（2025年11月3日）：更严格的定性标准、防止确认偏差、细化风险阶段

**v2.1修订原因：**
防止因未量化的"叙事"评估和重复计算导致过度评分。
确保所有泡沫风险评估均可独立验证且无确认偏差。
