# 期权策略顾问

## 概述

该技能使用理论定价模型提供全面的期权策略分析和教育。它帮助交易者理解、分析和模拟期权策略，而无需实时市场数据订阅。

**核心功能：**
- **Black-Scholes 定价**：理论期权价格和希腊字母计算
- **策略模拟**：主要期权策略的盈亏分析
- **盈利策略**：与盈利日历集成的盈利前波动率交易
- **风险管理**：头寸规模、希腊字母敞口、最大亏损/盈利分析
- **教育重点**：策略和风险指标的详细解释

**数据来源：**
- FMP API：股票价格、历史波动率、股息、盈利日期
- 用户输入：隐含波动率 (IV)、无风险利率
- 理论模型：Black-Scholes 用于定价和希腊字母

## 前置条件

- Python 3.9+ 以及 `numpy`、`scipy`、`requests`

## 支持的策略

### 收入策略
1. **保护性看涨期权** - 持有股票，卖出看涨期权（产生收入，限制上涨）
2. **有担保看跌期权** - 用现金卖出看跌期权（收取溢价，愿意买入股票）
3. **穷人的保护性看涨期权** - LEAPS 看涨期权 + 短期看涨期权（资本高效）

### 保护策略
4. **保护性看跌期权** - 持有股票，买入看跌期权（保险，限制下行）
5. **领式期权** - 持有股票，卖出看涨期权 + 买入看跌期权（限制上下行）

### 方向性策略
6. **牛市看涨期权价差** - 买入较低行权价看涨期权，卖出较高行权价看涨期权（有限风险/收益看涨）
7. **牛市看跌期权价差** - 卖出较高行权价看跌期权，买入较低行权价看跌期权（信用价差，看涨）
8. **熊市看涨期权价差** - 卖出较低行权价看涨期权，买入较高行行权价看涨期权（信用价差，看跌）
9. **熊市看跌期权价差** - 买入较高行权价看跌期权，卖出较低行权价看跌期权（有限风险/收益看跌）

### 波动率策略
10. **买入跨式期权** - 买入平值看涨期权 + 平值看跌期权（从任何方向的大幅波动中获利）
11. **买入宽跨式期权** - 买入虚值看涨期权 + 虚值看跌期权（比跨式期权便宜，需要更大波动）
12. **卖出跨式期权** - 卖出平值看涨期权 + 平值看跌期权（从无波动中获利，无限风险）
13. **卖出宽跨式期权** - 卖出虚值看涨期权 + 虚值看跌期权（从无波动中获利，更宽的区间）

### 范围策略
14. **铁蝶式期权** - 牛市看跌期权价差 + 熊市看涨期权价差（从区间内波动中获利）
15. **铁飞鸟式期权** - 卖出平值跨式期权，买入虚值宽跨式期权（从紧密区间获利）

### 高级策略
16. **日历价差** - 卖出短期期权，买入长期期权（从时间衰减中获利）
17. **斜式价差** - 日历价差，不同行权价（方向性 + 时间衰减）
18. **比例价差** - 不平衡价差（一边的合约更多）

### 第 2 步：计算历史波动率（如果未提供 IV）

**目标：** 从历史价格变动中估计波动率。

**方法：**
```python
# 获取 90 天的价格数据
prices = get_historical_prices("AAPL", days=90)

# 计算每日回报率
returns = np.log(prices / prices.shift(1))

# 年化波动率
HV = returns.std() * np.sqrt(252)  # 252 个交易日
```

**输出：**
- 历史波动率（年化百分比）
- 对用户的提示：“HV = 24.5%，考虑使用当前市场 IV 以获得更准确的结果”

**用户可以覆盖：**
- 从经纪商平台（ThinkorSwim、TastyTrade 等）提供 IV
- 脚本接受 `--iv 28.0` 参数

### 第 3 步：使用 Black-Scholes 定价期权

**Black-Scholes 模型：**

对于欧式期权：
```
看涨期权价格 = S * N(d1) - K * e^(-r*T) * N(d2)
看跌期权价格 = K * e^(-r*T) * N(-d2) - S * N(-d1)

其中：
d1 = [ln(S/K) + (r + σ²/2) * T] / (σ * √T)
d2 = d1 - σ * √T

S = 当前股票价格
K = 行权价
r = 无风险利率
T = 到期时间（年）
σ = 波动率（IV 或 HV）
N() = 标准正态分布累积函数
```

**调整：**
- 对看涨期权减去股息现值
- 美式期权：使用近似或注意“欧洲定价，可能低估美式期权”

**Python 实现：**
```python
from scipy.stats import norm
import numpy as np

def black_scholes_call(S, K, T, r, sigma, q=0):
    """
    S: 股票价格
    K: 行权价
    T: 到期时间（年）
    r: 无风险利率
    sigma: 波动率
    q: 股息收益率
    """
    d1 = (np.log(S/K) + (r - q + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
    d2 = d1 - sigma*np.sqrt(T)

    call_price = S*np.exp(-q*T)*norm.cdf(d1) - K*np.exp(-r*T)*norm.cdf(d2)
    return call_price

def black_scholes_put(S, K, T, r, sigma, q=0):
    d1 = (np.log(S/K) + (r - q + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
    d2 = d1 - sigma*np.sqrt(T)

    put_price = K*np.exp(-r*T)*norm.cdf(-d2) - S*np.exp(-q*T)*norm.cdf(-d1)
    return put_price
```

**每个期权部位的输出：**
- 理论价格
- 提示：“市场价格可能因买卖价差和美式与欧洲定价而不同”

### 第 4 步：计算希腊字母

**希腊字母**衡量期权价格对各种因素的敏感性：

**Delta (Δ)：** 股票价格每变动 1 美元，期权价格的变化
```python
def delta_call(S, K, T, r, sigma, q=0):
    d1 = (np.log(S/K) + (r - q + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
    return np.exp(-q*T) * norm.cdf(d1)

def delta_put(S, K, T, r, sigma, q=0):
    d1 = (np.log(S/K) + (r - q + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
    return np.exp(-q*T) * (norm.cdf(d1) - 1)
```

**Gamma (Γ)：** 股票价格每变动 1 美元，Delta 的变化
```python
def gamma(S, K, T, r, sigma, q=0):
    d1 = (np.log(S/K) + (r - q + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
    return np.exp(-q*T) * norm.pdf(d1) / (S * sigma * np.sqrt(T))
```

**Theta (Θ)：** 每天期权价格的变化（时间衰减）
```python
def theta_call(S, K, T, r, sigma, q=0):
    d1 = (np.log(S/K) + (r - q + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
    d2 = d1 - sigma*np.sqrt(T)

    theta = (-S*norm.pdf(d1)*sigma*np.exp(-q*T)/(2*np.sqrt(T))
             - r*K*np.exp(-r*T)*norm.cdf(d2)
             + q*S*norm.cdf(d1)*np.exp(-q*T))

    return theta / 365  # 每天计算
```

**Vega (ν)：** 波动率每变动 1%，期权价格的变化
```python
def vega(S, K, T, r, sigma, q=0):
    d1 = (np.log(S/K) + (r - q + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
    return S * np.exp(-q*T) * norm.pdf(d1) * np.sqrt(T) / 100  # 每变动 1%
```

**Rho (ρ)：** 利率每变动 1%，期权价格的变化
```python
def rho_call(S, K, T, r, sigma, q=0):
    d2 = (np.log(S/K) + (r - q + 0.5*sigma**2)*T) / (sigma*np.sqrt(T)) - sigma*np.sqrt(T)
    return K * T * np.exp(-r*T) * norm.cdf(d2) / 100  # 每变动 1%
```

**头寸希腊字母：**

对于包含多个部位的策略，跨所有部位汇总希腊字母：
```python
# 示例：牛市看涨期权价差
# 买入 1 份 $180 看涨期权
# 卖出 1 份 $185 看涨期权

delta_position = (1 * delta_long) + (-1 * delta_short)
gamma_position = (1 * gamma_long) + (-1 * gamma_short)
theta_position = (1 * theta_long) + (-1 * theta_short)
vega_position = (1 * vega_long) + (-1 * vega_short)
```

**希腊字母解释：**

| 希腊字母 | 含义 | 示例 |
|-------|---------|---------|
| **Delta** | 方向性敞口 | Δ = 0.50 → 如果股票 +$1，则盈利 $50 |
| **Gamma** | Delta 加速 | Γ = 0.05 → 如果股票 +$1，Delta 增加 0.05 |
| **Theta** | 每日时间衰减 | Θ = -$5 → 每天因时间流逝损失 $5 |
| **Vega** | 波动率敏感性 | ν = $10 → 如果 IV 增加 1%，则盈利 $10 |
| **Rho** | 利率敏感性 | ρ = $2 → 如果利率增加 1%，则盈利 $2 |

### 第 5 步：模拟策略盈亏

**目标：** 在到期时计算不同股票价格下的盈亏。

**方法：**

生成股票价格范围（例如，当前价格的 ±30%）：
```python
current_price = 180
price_range = np.linspace(current_price * 0.7, current_price * 1.3, 100)
```

对于每个价格点，计算盈亏：
```python
def calculate_pnl(strategy, stock_price_at_expiration):
    pnl = 0

    for leg in strategy.legs:
        if leg.type == 'call':
            intrinsic_value = max(0, stock_price_at_expiration - leg.strike)
        else:  # put
            intrinsic_value = max(0, leg.strike - stock_price_at_expiration)

        if leg.position == 'long':
            pnl += (intrinsic_value - leg.premium_paid) * 100  # 每份合约
        else:  # short
            pnl += (leg.premium_received - intrinsic_value) * 100

    return pnl * num_contracts
```

**关键指标：**
- **最大盈利**：最高可能的盈亏
- **最大亏损**：最差可能的盈亏
- **盈亏平衡点**：盈亏为 0 的股票价格
- **盈利概率**：盈利价格范围的百分比（简化）

**示例输出：**
```
牛市看涨期权价差：AAPL $180/$185（30 DTE，10 份合约）

当前价格：$180.00
净成本：每价差 $2.50（总计 $2,500）

最大盈利：$2,500（在 $185+ 时）
最大亏损：-$2,500（在 $180- 时）
盈亏平衡：$182.50
风险/回报：1:1

盈利概率：~55%（如果股票保持在 $182.50 以上）
```

### 第 6 步：生成盈亏图（ASCII 艺术图）

**股票价格下盈亏的可视化表示：**

```python
def generate_pnl_diagram(price_range, pnl_values, current_price, width=60, height=15):
    """生成 ASCII 盈亏图"""

    # 归一化到图表尺寸
    max_pnl = max(pnl_values)
    min_pnl = min(pnl_values)

    lines = []
    lines.append(f"\n盈亏图：{strategy_name}")
    lines.append("-" * width)

    # Y 轴级别
    levels = np.linspace(max_pnl, min_pnl, height)

    for level in levels:
        if abs(level) < (max_pnl - min_pnl) * 0.05:
            label = f"    0 |"  # 零线
        else:
            label = f"{level:6.0f} |"

        row = label
        for i in range(width - len(label)):
            idx = int(i / (width - len(label)) * len(price_range))
            pnl = pnl_values[idx]
            price = price_range[idx]

            # 确定字符
            if abs(pnl - level) < (max_pnl - min_pnl) / height:
                if pnl > 0:
                    char = '█'  # 盈利
                elif pnl < 0:
                    char = '░'  # 亏损
                else:
                    char = '─'  # 盈亏平衡
            elif abs(level) < (max_pnl - min_pnl) * 0.05:
                char = '─'  # 零线
            elif abs(price - current_price) < (price_range[-1] - price_range[0]) * 0.02:
                char = '│'  # 当前价格线
            else:
                char = ' '

            row += char

        lines.append(row)

    lines.append(" " * 6 + "|" + "-" * (width - 6))
    lines.append(" " * 6 + f"${price_range[0]:.0f}" + " " * (width - 20) + f"${price_range[-1]:.0f}")
    lines.append(" " * (width // 2 - 5) + "股票价格")

    return "\n".join(lines)
```

### 第 7 步：策略特定分析

根据策略类型提供定制指导：

```
- 买入 1 份 $175 看跌期权（30 DTE）收取 $2.00

最大盈利：无限（股票可以无限上涨）
最大亏损：每股 -$7 = ($5 股票亏损 + $2 溢价）

希腊字母：

- Theta：-$6/天（时间衰减成本）

保护：保证以 $175 出售，无论股票下跌多远

何时使用：
- 持有股票，担心短期下跌
- 盈利即将到来，需要保护
- 停损单的替代方案（无法被强制平仓）

成本：“保险溢价” - 通常为股票价值的 1-3%

退出计划：
- 如果股票上涨，则到期无价值（保险成本）
- 如果股票跌破 $175，则行权看跌期权
- 如果股票下跌但想保留股票，则卖出看跌期权
```

**铁三角策略：**

```
- 买入$170认沽期权，成本$0.50
- 卖出$185认沽期权，收益$1.50
- 买入$190认沽期权，成本$0.50

最大亏损：$300（如果股票移动到$170-$190之外）
盈亏平衡点：$173和$187
利润区间：$175到$185（58%概率）

希腊字母：
- Delta：~0（市场中性）
- Theta：+$15/天（时间衰减收益）
- Vega：-$25（做空波动率）

何时使用：
- 预期低波动率，区间内波动
- 大幅波动后，认为盘整
- 高IV环境（卖出昂贵期权）

风险：如果一侧被测试，风险无限
- 使用2倍信用额度止损（在-$400处退出）

调整：
- 如果一侧被测试，及时滚动该侧
- 在达到50%最大利润时提前关闭以减少尾部风险
```

```
- 买入$180认沽期权，成本$4.50
```

## 关键原则

### 理论定价局限性

**用户应了解：**
1. **Black-Scholes假设：**
   - 欧式期权（不能提前行权）
   - 波动率恒定（IV在现实中变化）
   - 无交易成本
   - 连续交易

2. **实际与理论：**
   - 买卖价差：实际成本高于理论
   - 美式期权：可以提前行权（尤其是价内认沽期权）
   - 流动性：流动性差的期权市场较宽
   - 股息：除息日影响定价

3. **最佳实践：**
   - 作为教育工具和比较分析使用
   - 在交易前从经纪商获取实时报价
   - 理论价格约等于市价中间价
   - 考虑佣金和滑点

### 波动率指导

**历史波动率与隐含波动率：**

```
历史波动率（HV）：发生了什么
- 根据过去的价格变动计算
- 客观，基于数据
- 可免费获取（FMP API）

隐含波动率（IV）：市场预期什么
- 从期权价格中推导
- 主观，基于供需
- 需要实时期权数据（用户提供）

比较：
- IV > HV：期权昂贵（考虑卖出）
- IV < HV：期权便宜（考虑买入）
- IV = HV：价格合理
```

**IV百分位数：**

用户提供当前IV，我们计算百分位数：
```python
# 获取1年HV数据
historical_hvs = calculate_hv_series(prices_1yr, window=30)

# 计算IV百分位数
iv_percentile = percentileofscore(historical_hvs, current_iv)

if iv_percentile > 75:
    guidance = "高IV - 考虑卖出溢价（贷入价差，铁三角策略）"
elif iv_percentile < 25:
    guidance = "低IV - 考虑买入期权（看涨/看跌期权，贷入价差）"
else:
    guidance = "正常IV - 任何策略都合适"
```

## 故障排除

**问题：IV不可用**
- 解决方案：使用HV作为替代，通知用户
- 询问用户从经纪商平台提供IV

**问题：期权价格为负**
- 解决方案：检查输入（行权价与股票价格）
- 深度价内期权可能有数值问题

- 解决方案：验证输入（T，sigma，r）
- 检查是否使用年度值与日值

**问题：策略太复杂**
- 解决方案：分解为合约，分别分析
- 参考参考资料了解策略细节
