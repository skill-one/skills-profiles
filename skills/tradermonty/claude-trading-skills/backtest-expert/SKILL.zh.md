# 回测专家

基于专业方法论，采用系统化方法回测交易策略，优先考虑稳健性而非乐观结果。

## 核心理念

**目标**：寻找在现实中“亏损最少”的策略，而非纸上“盈利最多”的策略。

**原则**：增加摩擦力，检验假设，看哪些能存活下来。如果一个策略在悲观条件下依然能保持稳定，那么它在实盘中成功的可能性就更大。

## 使用场景

在以下情况下使用此技能：
- 开发或验证系统化交易策略
- 评估一个交易想法是否足够稳健，可以用于实盘
- 排查回测结果可能存在误导的原因
- 学习正确的回测方法论
- 避免常见陷阱（曲线拟合、前瞻偏差、幸存者偏差）
- 评估参数敏感性和状态依赖性
- 为滑点与执行成本设定现实预期

## 前置条件

- Python 3.9+（用于评估脚本）
- 无需API密钥
- 无需外部数据依赖——指标由用户提供

## 工作流程

### 1. 陈述假设

用一句话定义优势。

**示例**："在财报中上涨超过3%且在首个小时内回落至前一交易日收盘价的股票，提供了均值回归机会。"

如果你无法清晰地表达优势，不要继续进行测试。

### 2. 用零自由裁量权编码规则

完整具体地定义：
- **入场**：精确条件、时机、价格类型
- **出场**：止损、盈利目标、基于时间的出场
- **头寸规模**：固定金额、仓位百分比、波动率调整
- **过滤器**：市值、成交量、行业、波动率条件
- **投资组合**：哪些工具有资格

**关键**：不允许主观判断。每个决策都必须基于规则且明确无误。

### 3. 运行初始回测

测试覆盖：
- **至少5年**（最好10年以上）
- **多种市场状态**（牛市、熊市、高/低波动率）
- **现实成本**：佣金+保守的滑点

检查初始结果的基本可行性。如果基础有问题，迭代假设。

### 4. 对策略进行压力测试

这是测试时间中80%应花费的地方。

**参数敏感性**：
- 在基准的50%、75%、100%、125%、150%测试止损
- 在基准的80%、90%、100%、110%、120%测试盈利目标
- 将入场/出场时机变化±15-30分钟
- 寻找稳定性能的“平台”，而非狭窄的峰值

**执行摩擦**：
- 将滑点增加到典型估计的1.5-2倍
- 模拟最坏情况下的成交（买入在要价+1个点，卖出在出价-1个点）
- 添加现实的订单拒绝场景
- 测试悲观佣金结构

**时间稳健性**：
- 分析年度表现
- 要求多数年份具有正预期
- 确保策略不依赖1-2个异常时期
- 分别在不同市场状态下测试

**样本量**：
- 绝对最小值：30笔交易
- 优选：100笔以上
- 高置信度：200笔以上

### 5. 样本外验证

**向前分析**：
1. 在训练期（例如，前3年）优化
2. 在验证期（第4年）测试
3. 滚动向前并重复
4. 比较样本内与样本外表现

**警告信号**：
- 样本外表现低于样本内的50%
- 需要频繁重新优化参数
- 不同时期参数变化剧烈

### 6. 评估结果

**需要回答的问题**：
- 优势是否能在悲观假设下存活？
- 表现是否在参数变化中保持稳定？
- 策略是否适用于多种市场状态？
- 样本量是否足够统计置信？
- 结果是否现实，而非“好得不真实”？

**决策标准**：
- ✅ **部署**：通过所有压力测试且表现可接受
- 🔄 **优化**：核心逻辑合理但需要调整参数
- ❌ **放弃**：未通过压力测试或依赖脆弱假设

使用评估脚本进行结构化、定量的评估：

```bash
python3 skills/backtest-expert/scripts/evaluate_backtest.py \
  --total-trades 150 \
  --win-rate 62 \
  --avg-win-pct 1.8 \
  --avg-loss-pct 1.2 \
  --max-drawdown-pct 15 \
  --years-tested 8 \
  --num-parameters 3 \
  --slippage-tested \
  --output-dir reports/
```

该脚本在5个维度（样本量、预期、风险管理、稳健性、执行现实性）进行评分，检测警告信号，并输出部署/优化/放弃的结论。

## 关键测试原则

### 惩罚策略

在所有地方增加摩擦力：
- 佣金高于现实
- 滑点1.5-2倍典型值
- 最坏情况成交
- 订单拒绝
- 部分成交

**理由**：能在悲观假设下存活的策略，往往在实盘中表现更好。

### 寻求平台，而非峰值

寻找参数范围稳定表现，而非导致表现峰值的最佳值。

**好**：止损在1.5%到3.0%之间策略仍盈利
**差**：策略仅在止损精确为2.13%时才有效

稳定表现表明真实优势；狭窄的峰值暗示曲线拟合。

### 测试所有情况，而非精选案例

**错误方法**：研究精选的“市场领导者”
**正确方法**：测试所有符合条件的股票，包括失败的

精选案例导致幸存者偏差，高估策略质量。

### 分离想法生成与验证

**直觉**：用于生成假设
**验证**：必须完全数据驱动

切勿让对想法的执着影响对测试结果的解释。

## 常见失败模式

识别这些模式以节省时间：

1. **参数敏感性**：仅在精确参数值时有效
2. **状态特定**：某些年份表现好，其他年份差
3. **滑点敏感性**：加入现实成本后无利可图
4. **小样本**：交易太少，统计置信度不足
5. **前瞻偏差**：“好得不真实”的结果
6. **过度优化**：参数过多，样本外结果差

见`references/failed_tests.md`获取详细示例和诊断框架。

## 关键提醒

**时间分配**：20%时间产生想法，80%时间试图打破它们。

**无状态要求**：如果策略需要“完美状态”才能工作，它不适合系统化交易。

**警告信号**：如果回测结果看起来太好（>90%胜率，最小回撤，完美时机），仔细审计是否存在前瞻偏差或数据问题。

**工具限制**：了解你的回测平台的怪癖（插值方法、处理低流动性、数据对齐问题）。

**统计显著性**：小优势需要大样本量证明。每笔交易5%的优势需要100笔以上交易才能区分运气。

## 自由裁量与系统化差异

此技能专注于**系统化/量化**回测，其中：
- 所有规则事先编码
- 执行中无自由裁量或“感觉”
- 测试涵盖所有历史案例，而非精选案例
- 故意剔除新闻、宏观等状态

自由裁量交易者研究方式不同，此技能可能不适用于需要主观判断的设置。
