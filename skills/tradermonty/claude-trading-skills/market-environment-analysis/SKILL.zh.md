# 市场环境分析

全面分析工具，用于随时了解市场状况并创建专业的市场报告。

## 核心工作流程

### 1. 初始数据收集
使用 web_search 工具收集最新市场数据：
1. 主要股票指数（标普500、纳斯达克、道琼斯、日经225、上证综指、恒生指数）
2. 外汇汇率（美元/日元、欧元/美元、主要货币对）
3. 商品价格（西德克萨斯中质原油、黄金、白银）
4. 美国国债收益率（2年期、10年期、30年期）
5. VIX指数（恐慌指标）
6. 市场交易状态（开盘/收盘/当前值）

### 2. 市场环境评估
从收集的数据中评估以下内容：
- **趋势方向**：上升趋势/下降趋势/区间震荡
- **风险情绪**：风险偏好/风险规避
- **波动率状态**：VIX指数反映的市场焦虑程度
- **行业轮动**：资本流向何处

### 3. 报告结构

#### 标准报告格式：
```
1. 执行摘要（3-5个关键点）
2. 全球市场概览
   - 美国市场
   - 亚太市场
   - 欧洲市场
3. 外汇与商品趋势
4. 重要事件与经济指标
5. 风险因素分析
6. 投资策略启示
```

## 脚本使用

### market_utils.py
提供报告创建的常用功能：
```bash
# 生成报告标题
python scripts/market_utils.py

# 可用功能：
- format_market_report_header(): 创建标题
- get_market_session_times(): 检查交易时间
- categorize_volatility(vix): 解释VIX水平
- format_percentage_change(value): 格式化价格变动
```

## 重要注意事项

### 时区意识
- 考虑所有主要市场时区
- 美国市场：傍晚至清晨（亚洲时间）
- 欧洲市场：下午至傍晚（亚洲时间）
- 亚太市场：上午至下午（当地时间）

### 经济日历优先级
按重要性分类：
- ⭐⭐⭐ 关键（FOMC、NFP、CPI等）
- ⭐⭐ 重要（GDP、零售销售等）
- ⭐ 参考水平

### 数据源优先级
1. 官方发布（央行、政府统计）
2. 主要财经媒体（彭博、路透社）
3. 经纪人报告
4. 分析师一致预期

## 故障排除

### 数据收集注意事项
- 检查市场假日（假日日历）
- 注意夏令时变化
- 区分快照数据与最终数据

### 市场波动率应对
1. 首先整理事实
2. 参考历史类似事件
3. 多重来源验证
4. 保持客观分析

## 定制选项

根据用户投资风格调整：
- **日内交易者**：日内图表、订单流关注
- **波段交易者**：每日/周技术分析重点
- **长期投资者**：基本面、宏观经济学关注
- **外汇交易者**：货币相关性、利率差异
- **期权交易者**：波动率分析、希腊字母监控
