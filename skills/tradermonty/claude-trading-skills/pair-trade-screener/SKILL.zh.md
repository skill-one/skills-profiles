# 配对交易筛选器

## 概述

该技能通过配对交易识别和分析统计套利机会。配对交易是一种市场中性策略，通过两个相关性强的证券的相对价格变动获利，而不管整体市场方向如何。该技能使用严格的统计方法，包括相关性分析和协整检验，以找到稳健的交易对。

**核心方法：**
- 识别具有高相关性和相似行业/部门敞口的一对股票
- 检验协整性（长期统计关系）
- 计算价差z分数以识别均值回归机会
- 根据统计阈值生成入场/出场信号
- 提供市场中性敞口的头寸规模

**主要优势：**
- 市场中性：在上涨、下跌或横盘市场中获利
- 风险管理：限制对广泛市场变动的敞口
- 统计基础：数据驱动，非主观判断
- 分散化：与传统全做多策略不相关

## 何时使用此技能

当用户提出以下请求时使用此技能：
- 询问“配对交易机会”
- 需要“市场中性策略”
- 请求“统计套利筛选”
- 询问“哪些股票一起波动？”
- 想对冲行业敞口
- 请求均值回归交易想法
- 询问相对价值交易

示例用户请求：
- “在科技行业寻找配对交易机会”
- “哪些股票是协整的？”
- “筛选统计套利机会”
- “寻找均值回归对”
- “当前有哪些好的市场中性交易？”

## 分析工作流程

### 第1步：定义配对宇宙

**目标：** 建立用于分析配对关系的股票池。

**选项A：基于行业的筛选（推荐）**

选择特定行业进行筛选：
- 科技
- 金融
- 医疗保健
- 消费 discretionary
- 工业
- 能源
- 材料
- 消费必需品
- 公用事业
- 房地产
- 通信服务

**选项B：自定义股票列表**

用户提供要分析的特定股票代码：
```
示例：["AAPL", "MSFT", "GOOGL", "META", "NVDA"]
```

**选项C：特定行业**

在行业中缩小焦点：
- 示例：科技行业的“软件”
- 示例：金融行业的“区域银行”

**筛选标准：**
- 最小市值：20亿美元（中端和以上）
- 最小平均成交量：每天100万股（流动性要求）
- 活跃交易：无退市或非活跃股票
- 相同交易所偏好：避免跨交易所问题

### 第2步：检索历史价格数据

**目标：** 获取用于相关性和协整分析的价格历史。

**数据要求：**
- 时间范围：2年（至少252个交易日）
- 频率：每日收盘价
- 调整：调整分割和股息
- 清洁数据：无缺口或缺失值

**FMP API端点：**
```
GET /v3/historical-price-full/{symbol}?apikey=YOUR_API_KEY
```

**数据验证：**
- 验证所有符号的日期范围一致性
- 删除缺失数据超过10%的股票
- 使用前向填充方法填充小缺口
- 记录数据质量问题

**脚本执行：**
```bash
uv run --with 'statsmodels>=0.14,<0.15' python \
  skills/pair-trade-screener/scripts/find_pairs.py \
  --sector Technology \
  --lookback-days 730 \
  --output /tmp/pair-trade/technology.json
```

### 第3步：计算相关性和贝塔

**目标：** 识别具有强线性关系的候选配对。

**相关性分析：**

对于宇宙中的每对股票(i, j)：
1. 计算皮尔逊相关系数(ρ)
2. 计算滚动相关性（90天窗口）以进行稳定性检查
3. 过滤ρ ≥ 0.70（强正相关性）的配对

**相关性解释：**
- ρ ≥ 0.90：非常强的相关性（最佳候选）
- ρ 0.70-0.90：强相关性（良好候选）
- ρ 0.50-0.70：中等相关性（边缘）
- ρ < 0.50：弱相关性（排除）

**贝塔计算：**

对于每个候选配对（股票A、股票B）：
```
Beta = Covariance(A, B) / Variance(B)
```

贝塔表示对冲比率：
- Beta = 1.0：等金额度
- Beta = 1.5：每1.00美元的A对应1.50美元的B
- Beta = 0.8：每1.00美元的A对应0.80美元的B

**相关性稳定性检查：**
- 计算多个时期（6个月、1年、2年）的相关性
- 要求相关性保持稳定（不会恶化）
- 标记最近相关性低于历史相关性超过0.15的配对

### 第4步：协整检验

**目标：** 统计验证长期均衡关系。

**协整的重要性：**
- 相关性衡量短期共同运动
- 协整证明长期均衡关系
- 协整配对可预测地均值回归
- 非协整配对可能永久性偏离

**增强迪基-福勒（ADF）检验：**

对于每个相关配对：
1. 计算价差：`Spread = Price_A - (Beta × Price_B)`
2. 对价差序列运行ADF检验
3. 检查p值：p < 0.05表示协整（拒绝单位根的零假设）
4. 提取ADF统计量以进行强度排名

**协整解释：**
- p值 < 0.01：非常强的协整（★★★）
- p值 0.01-0.05：中等协整（★★）
- p值 > 0.05：无协整（排除）

**半衰期计算：**

估计均值回归速度：
```
Half-Life = -log(2) / log(mean_reversion_coefficient)
```

- 半衰期 < 30天：快速均值回归（适合短期交易）
- 半衰期 30-60天：中等速度（标准）
- 半衰期 > 60天：慢速均值回归（长期持有期）

**Python实现：**
```python
from statsmodels.tsa.stattools import adfuller

# 计算价差
spread = price_a - (beta * price_b)

# ADF检验
result = adfuller(spread)
adf_stat = result[0]
p_value = result[1]

# 解释
is_cointegrated = p_value < 0.05
```

### 第5步：价差分析和Z分数计算

**目标：** 量化当前价差与均衡的偏差。

**价差计算：**

两种常见方法：

**方法1：价格差（加法）**
```
Spread = Price_A - (Beta × Price_B)
```
适用：价格水平相似的股票

**方法2：价格比率（乘法）**
```
Spread = Price_A / Price_B
```
适用：价格水平不同的股票，更容易解释

**Z分数计算：**

衡量价差偏离其均值的多少个标准差：
```
Z-Score = (Current_Spread - Mean_Spread) / Std_Dev_Spread
```

**Z分数解释：**
- Z > +2.0：股票A相对于B昂贵（做空A，做多B）
- Z > +1.5：中等昂贵（注意入场）
- Z -1.5到+1.5：正常范围（无交易）
- Z < -1.5：中等便宜（注意入场）
- Z < -2.0：股票A相对于B便宜（做多A，做空B）

**历史价差分析：**
- 计算90天滚动窗口的均值和标准差
- 绘制历史Z分数分布
- 确定最大历史Z分数偏差
- 检查结构断裂（价差状态变化）

### 第6步：生成入场/出场建议

**目标：** 提供具有明确规则的行动交易信号。

**入场条件：**

**保守方法（Z ≥ ±2.0）：**
```
做多信号：
- Z分数 < -2.0（价差2个以上标准差低于均值）
- 价差是均值回归的（协整p < 0.05）
- 半衰期 < 60天
→ 操作：买入股票A，做空股票B（对冲比率=贝塔）

做空信号：
- Z分数 > +2.0（价差2个以上标准差高于均值）
- 价差是均值回归的（协整p < 0.05）
- 半衰期 < 60天
→ 操作：做空股票A，做多股票B（对冲比率=贝塔）
```

**激进方法（Z ≥ ±1.5）：**
- 较低阈值，交易更频繁
- 赢率更高，但每笔交易平均利润较小
- 需要更严格的风险管理

**出场条件：**

**主要出场：均值回归（Z = 0）**
```
当价差返回均值（Z分数穿过0）时出场
→ 同时关闭两腿
```

**次要出场：部分获利了结**
```
当Z分数达到±1.0时出场50%
剩余50%在Z分数=0时出场
```

**止损：**
```
当Z分数超出±3.0（极端偏离）时出场
风险：可能关系结构断裂
```

**时间出场：**
```
如果在90天内没有均值回归，则出场
防止无限期持有断裂对
```

### 第7步：头寸规模和风险管理

**目标：** 确定用于市场中性敞口的金额。

**市场中性规模：**

对于配对（股票A、股票B）与贝塔=β：

**等金额度敞口：**
```
如果投资组合规模=10,000美元分配给这对：
- 买入5,000美元的股票A
- 做空5,000 × β的股票B

示例（β = 1.2）：
- 买入5,000美元股票A
- 做空6,000美元股票B
→ 市场中性，贝塔=0
```

**头寸规模考虑：**
- 每对配对的总体分配：投资组合的10-20%
- 最大配对：5-8个活跃配对以实现分散化
- 配对之间的相关性：避免高度相关的配对

**风险指标：**
- 每对的最大亏损：投资组合的2-3%
- 止损触发器：Z分数 > ±3.0或价差亏损-5%
- 投资组合级风险：所有配对风险之和≤10%

### 第8步：生成配对分析报告

**目标：** 创建包含发现和建议的结构化Markdown报告。

**报告部分：**

1. **执行摘要**
   - 分析的总配对数
   - 找到的协整配对数
   - 按统计强度排名的前5个机会

2. **协整配对表**
   - 配对名称（股票A/股票B）
   - 相关系数
   - 协整p值
   - 当前z分数
   - 交易信号（做多/做空/无）
   - 半衰期

3. **详细分析（前10对）**
   - 配对描述
   - 统计指标
   - 当前价差位置
   - 入场/出场建议
   - 头寸规模
   - 风险评估

4. **价差图表（文本）**
   - 历史Z分数图（ASCII艺术）
   - 标记入场/出场水平
   - 当前位置指示器

5. **风险警告**
   - 相关性恶化的配对
   - 检测到的结构断裂
   - 低流动性警告

**文件命名约定：**
```
pair_trade_analysis_[SECTOR]_[YYYY-MM-DD].md
```

示例：`pair_trade_analysis_Technology_2025-11-08.md`

## 输出

`find_pairs.py`创建请求的父目录并写入一个包含`metadata`和`pairs`键的JSON对象。每个配对包括相关性、对冲比率、ADF结果、半衰期、当前z分数、信号和生成时间戳。进度和排名摘要写入stdout。文件系统错误产生简洁的stderr消息和非零退出。

`analyze_spread.py`将单个配对的统计报告写入stdout，并且不创建文件。两个命令在发出API请求之前拒绝无效或非有限阈值、不足的回溯窗口和重复符号。缺少`statsmodels`在stderr生成安装命令，而不会产生回溯。

## 质量标准

### 统计严谨性

**有效配对的最小要求：**
- ✓ 相关性 ≥ 0.70（2年期间）
- ✓ 协整p值 < 0.05（ADF检验）
- ✓ 价差平稳性确认
- ✓ 半衰期 < 90天
- ✓ 近期6个月内无结构断裂

**排除配对的红旗：**
- 近期6个月相关性下降 >0.20
- 协整p值 > 0.05
- 半衰期随时间增加（均值回归减弱）
- 重要公司事件（合并、分拆、破产风险）
- 流动性问题（平均成交量 < 50万股/天）

### 实际考虑

**交易成本：**
- 假设每腿0.1%的往返成本
- 每对的总成本 = 0.4%（入场+出场，两腿）
- 最小z分数阈值应超过交易成本

**卖空：**
- 验证股票可卖空（非难借）
- 考虑卖空利息成本
- 监控卖空挤压风险

**执行：**
- 同时入场/出场两腿（避免单腿风险）
- 使用限价单控制滑点
- 入场前预先定位卖空

深入探讨协整测试：
- **什么是协整？**：直观解释
- **ADF检验**：分步流程
- **P值解读**：统计显著性阈值
- **半衰期估计**：AR(1)模型方法
- **结构断裂**：检测状态变化
- **实际案例**：真实配对研究

## 故障排除

**问题：未发现协整配对**

解决方案：
- 扩大宇宙（降低市值阈值）
- 放松协整p值至0.10
- 尝试不同行业（公用事业通常协整良好）
- 将观察期延长至3年

**问题：所有z分数接近零（无交易信号）**

解决方案：
- 正常市场状况（配对处于均衡状态）
- 过一段时间再检查或扩大宇宙
- 将入场阈值降至±1.5而不是±2.0

**问题：配对相关性失效**

解决方案：
- 检查公司事件（盈利、指引变化）
- 确认无并购活动或重组
- 如确认结构断裂，从观察列表中移除配对
- 观察30天后重新入场
