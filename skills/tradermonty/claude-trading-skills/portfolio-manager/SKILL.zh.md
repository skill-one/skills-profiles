# 投资组合管理器

## 概述

通过与 Alpaca MCP 服务器集成来获取实时持仓数据，然后执行涵盖资产配置、多元化、风险指标、个股评估和再平衡建议的全面分析。生成包含可操作见解的详细投资组合报告。

此技能利用 Alpaca 的经纪 API 通过 MCP（模型上下文协议）访问实时投资组合数据，确保分析基于实际的当前持仓，而不是手动输入的数据。

## 使用场景

在以下用户请求时调用此技能：
- "分析我的投资组合"
- "查看我的当前持仓"
- "我的资产配置是多少？"
- "检查我的投资组合风险"
- "我应该再平衡我的投资组合吗？"
- "评估我的持仓"
- "投资组合绩效回顾"
- "我应该买入或卖出哪些股票？"
- 任何涉及投资组合级分析或管理的请求

## 前置条件

### Alpaca MCP 服务器设置

此技能需要配置并连接 Alpaca MCP 服务器。MCP 服务器提供对以下内容的访问：
- 当前投资组合持仓
- 账户净值和买入权限
- 历史持仓和交易记录
- 持有证券的市场数据

**使用的 MCP 服务器工具：**
- `get_account_info` - 获取账户净值、买入权限、现金余额
- `get_positions` - 检索所有当前持仓，包括数量、成本基础和市场价值
- `get_portfolio_history` - 历史投资组合绩效数据
- 市场数据工具用于价格报价和基本面分析

如果 Alpaca MCP 服务器未连接，请通知用户并提供来自 `references/alpaca-mcp-setup.md` 的设置说明。

### REST 备用连接检查

从仓库根目录运行连接检查。首先使用模拟凭证；切勿将凭证粘贴到报告中或将它们提交到仓库。

```bash
export ALPACA_API_KEY="<alpaca-key-id>"
export ALPACA_SECRET_KEY="<alpaca-secret-key>"
export ALPACA_PAPER="true"
uv run python skills/portfolio-manager/scripts/check_alpaca_connection.py
```

该命令将写入经过编辑的诊断摘要到 stdout，并且仅在账户和持仓端点成功时返回零。它不会创建报告文件或下订单。

## 工作流程

### 第 1 步：通过 Alpaca MCP 或 REST 备用方式获取投资组合数据

当可用时，使用 Alpaca MCP 服务器工具收集当前投资组合信息。在计划的 Hermes 任务中，即使存在 Alpaca 凭证，MCP 工具也可能不可用；在这种情况下，直接使用 Alpaca REST API，并使用 `ALPACA_API_KEY`、`ALPACA_SECRET_KEY` 和 `ALPACA_PAPER`。

**1.1 获取账户信息：**
```
首选：使用 mcp__alpaca__get_account_info 获取：
- 账户净值（总投资组合价值）
- 现金余额
- 买入权限
- 账户状态

备用 REST 端点：
- 模拟：https://paper-api.alpaca.markets/v2/account
- 实时： https://api.alpaca.markets/v2/account
标头：
- APCA-API-KEY-ID=$ALPACA_API_KEY
- APCA-API-SECRET-KEY=$ALPACA_SECRET_KEY
```

**1.2 获取当前持仓：**
```
首选：使用 mcp__alpaca__get_positions 获取所有持仓：
- 证券代码
- 持有数量
- 平均入场价格（成本基础）
- 当前市场价格
- 当前市场价值
- 未实现盈亏（美元和百分比）
- 持仓规模占投资组合的百分比

备用 REST 端点：
- 模拟：https://paper-api.alpaca.markets/v2/positions
- 实时： https://api.alpaca.markets/v2/positions
```

**1.3 获取投资组合历史（可选）：**
```
首选：使用 mcp__alpaca__get_portfolio_history 进行绩效分析：
- 历史净值
- 时间加权回报计算
- 回撤分析

备用 REST 端点：
- /v2/account/portfolio/history
```

**计划任务备用规则：**
- 清晰标记来源为 `Alpaca REST 备用` 而不是 MCP。
- 使用 `ALPACA_PAPER=true` 选择模拟端点；否则使用实时端点。
- 仍然验证长期市场价值加上现金大致与净值相吻合，并突出显示如果 `long_market_value > equity` 则存在杠杆。
- 对于每周核心投资组合 cron 任务，使用净值作为分母以及总市值：`gross_long_exposure = long_market_value / equity`，`cash_pct = cash / equity`，并在总敞口明显超过 100% 或现金为负时明确标记杠杆融资的投资组合。不要让行业权重看起来无害，当账户被杠杆化时，仅使用总长除数。
- 当请求强调股息持仓或强制审查触发时，从实时持仓构建标准化监控输入并将其交给 `kanchi-dividend-review-monitor`，而不是将股息审查视为仅叙述性部分。同时，当请求账户位置笔记时，为 `kanchi-dividend-us-tax-accounting` 构建税务规划输入；如果账户类型或持有期窗口不可用，则标记为降级。

**数据验证：**
- 验证所有持仓都有有效的证券代码
- 确认市场价值大致总和为账户净值
- 检查是否存在任何过时或非活跃持仓
- 处理边缘情况（分数股、期权、如果支持则加密货币）

### 第 2 步：丰富持仓数据

对于投资组合中的每个持仓，收集额外的市场数据和基本面数据：

**2.1 当前市场数据：**
- 实时或延迟价格报价
- 日交易量和流动性指标
- 52 周区间
- 市值

**2.2 基本面数据：**
使用 WebSearch 或可用的市场数据 API 获取：
- 行业和行业分类
- 关键估值指标（市盈率、市净率、股息收益率）
- 最近收益和财务健康状况指标
- 分析师评级和价格目标
- 最近新闻和重大发展

**2.3 技术分析：**
- 价格趋势（20 日、50 日、200 日移动平均线）
- 相对强度
- 支撑和阻力水平
- 动量指标（RSI、MACD 如果可用）

### 第 3 步：投资组合级分析

使用参考文件中的框架执行全面的投资组合分析：

#### 3.1 资产配置分析

**阅读 references/asset-allocation.md** 以了解配置框架

分析当前配置在多个维度上的情况：

**按资产类别：**
- 股票与固定收益、现金与另类投资
- 与用户风险配置文件的目标配置进行比较
- 评估配置是否与投资目标匹配

**按行业：**
- 技术、医疗保健、金融、消费等
- 识别行业集中风险
- 与基准行业权重进行比较（例如，标普 500）

**按市值：**
- 大盘股与中盘股与小盘股分布
- 大型股集中风险
- 市值多元化评分

**按地域：**
- 美国 vs 国际 vs 新兴市场
- 国内集中风险评估

**输出格式（示意性值）：**
```markdown
## 资产配置

### 当前配置与目标
| 资产类别 | 当前 | 目标 | 差异 |
|-------------|---------|--------|----------|
| 美国股票 | 70.0% | 60.0% | +10.0 pp |

### 行业细分
[饼图描述或包含行业百分比的表格]

### 顶级持仓
| 排名 | 代码 | 占投资组合的百分比 | 行业 |
|------|--------|----------------|--------|
| 1 | AAPL | 8.5% | 技术 |
```

#### 3.2 多元化分析

**阅读 references/diversification-principles.md** 以了解多元化理论

评估投资组合多元化质量：

**持仓集中度：**
- 识别顶级持仓及其总权重
- 标记任何单个持仓是否超过 10-15% 的投资组合
- 计算赫芬达尔-赫希曼指数（HHI）进行集中度测量

**行业集中度：**
- 识别主导行业
- 标记任何行业是否超过 30-40% 的投资组合
- 与基准行业多元化进行比较

**相关性分析：**
- 估计主要持仓之间的相关性
- 识别高度相关的持仓（潜在的冗余）
- 评估真实的多元化收益

**持仓数量：**
- 最佳范围：个人投资组合 15-30 股
- 标记如果少于 10 股则多元化不足或超过 50 股则过度多元化

**输出（示意性值）：**
```markdown
## 多元化评估

**集中风险：** [低 / 中 / 高]
- 顶级 5 持仓代表 42% 的投资组合
- 最大单个持仓：AAPL 占 12%

**行业多元化：** [优秀 / 良好 / 一般 / 差]
- 主导行业：技术占 31%
- [跨行业平衡评估]

**持仓数量：** [最佳 / 多元化不足 / 过度多元化]
- 总持仓：18 股
- [建议]

**相关性问题：**
- [列出任何高度相关的持仓对]
- [多元化改进建议]
```

#### 3.3 风险分析

**阅读 references/portfolio-risk-metrics.md** 以了解风险测量框架

计算和解释关键风险指标：

**波动性指标：**
- 估计投资组合贝塔（持仓贝塔的加权平均值）
- 单个持仓波动性
- 投资组合标准差（如果可用历史数据）

**下行风险：**
- 最大回撤（从投资组合历史）
- 当前从峰值回撤
- 持有重大未实现亏损的持仓

**风险集中度：**
- 高波动性股票的百分比（贝塔 > 1.5）
- 投机性/亏损公司百分比
- 杠杆使用（如果适用）

**尾部风险：**
- 对潜在黑天鹅事件的敞口
- 单个股票集中风险
- 行业特定事件风险

**输出（示意性值）：**
```markdown
## 风险评估

**整体风险配置：** [保守 / 中等 / 激进]

**投资组合贝塔：** 1.12（市场为 1.00）
- 解释：投资组合比市场[更/更少]波动

**最大回撤：** -14.2%（从 $125,000 到 $107,250）
- 当前从峰值回撤：-6.3%

**高风险持仓：**
| 代码 | 占投资组合的百分比 | 贝塔 | 风险因素 |
|--------|----------------|------|-------------|
| NVDA | 11% | 1.65 | 高波动 |

**风险集中度：**
- 31% 在一个行业（技术）
- 18% 在贝塔高于 1.5 的股票
- [其他集中风险]

**风险评分：** 68/100（中等风险）
```

#### 3.4 绩效分析

使用可用数据评估投资组合绩效：

**绝对回报：**
- 整体投资组合未实现盈亏（美元和百分比）
- 表现最好的持仓（前 5 名按百分比收益）
- 表现最差的持仓（后 5 名按百分比亏损）

**时间加权回报（如果历史可用）：**
- 年初回报
- 1 年、3 年、5 年年化回报
- 与基准（标普 500、相关指数）进行比较

**持仓级绩效：**
- 赢家与输家比率
- 赢家平均收益
- 输家平均亏损
- 接近 52 周高点/低点的持仓

**输出（示意性值）：**
```markdown
## 绩效回顾

**投资组合总价值：** $100,000
**总未实现盈亏：** $8,500 (+9.3%)
**现金余额：** $5,000 (5% 的投资组合)

**表现最佳：**
| 代码 | 收益 | 持仓价值 |
|--------|------|----------------|
| AAPL | +22.4% | $12,240 |

**表现最差：**
| 代码 | 亏损 | 持仓价值 |
|--------|------|----------------|
| INTC | -12.0% | $6,600 |

**与基准比较（示意性值）：**
- 投资组合回报：+9.3%
- 标普 500 回报：+7.8%
- Alpha：+1.5 个百分点
```

### 第 4 步：个股分析

对关键持仓（按投资组合权重前 10-15 名）执行详细分析：

**阅读 references/position-evaluation.md** 以了解持仓分析框架

对每个重要持仓：

**4.1 当前投资策略验证：**
- 如果已知用户上下文，为什么启动此持仓？
- 投资策略是否实现或破裂？
- 最近公司发展和新闻

**4.2 估值评估：**
- 当前估值指标（市盈率、市净率等）
- 与历史估值范围比较
- 与行业同行比较
- 过高估 / 公平 / 低估评估

**4.3 技术健康状况：**
- 价格趋势（上升趋势、下降趋势、横盘）
- 持仓相对于移动平均线
- 支撑和阻力水平
- 动量状态

**4.4 持仓规模：**
- 当前投资组合权重
- 考虑到信念和风险，规模是否合适？
- 过度配置或配置不足与最佳配置

**4.5 行动建议：**
- **持有** - 持仓规模合适且策略完好
- **增持** - 配置不足，策略加强
- **减持** - 过度配置或估值拉伸
- **卖出** - 策略破裂，有更好的机会

**每个持仓的输出（示意性值）：**
```markdown
### AAPL - Apple Inc. (8.5% 的投资组合)

**持仓详情：**
- 股票：50
- 平均成本：$150.00
- 当前价格：$170.00
- 市场价值：$8,500
- 未实现盈亏：$1,000 (+13.3%)

**基本面快照：**
- 行业：[行业]
- 市值：$3.2T
- 市盈率：31.4 | 股息收益率：0.5%
- 最近发展：[关键新闻或收益]

**技术状态：**
- 趋势：[上升趋势 / 下降趋势 / 横盘]
- 价格与 50 日 MA 比较：高于 4.2%
- 支撑：$162.00 | 阻力：$176.00

**持仓评估：**
- **策略状态：** [完好 / 削弱 / 破裂 / 加强]
- **估值：** [低估 / 公平 / 过高估]
- **持仓规模：** [最佳 / 过度配置 / 配置不足]

**建议：** [持有 / 增持 / 减持 / 卖出]
**理由：** [1-2 句话解释]
```

### 第 5 步：再平衡建议

**阅读 references/rebalancing-strategies.md** 以了解再平衡方法

生成具体的再平衡建议：

**5.1 确定再平衡触发因素：**
- 持仓与目标权重显著偏离
- 需要调整的行业/资产类别配置
- 需要减持的过度配置持仓
- 需要增持的配置不足领域
- 税务考虑（资本利得影响）

**5.2 制定再平衡计划：**

**需要减持的持仓：**
- 超过阈值偏离目标的过度配置持仓
- 价格上涨显著的股票（估值问题）
- 超过 15-20% 投资组合的集中持仓
- 策略破裂的持仓

**需要增持的持仓：**
- 配置不足的行业或资产类别
- 目前配置不足的高信念持仓
- 改善多元化的新机会

**现金部署：**
- 如果现金过剩（>10% 的投资组合），建议部署
- 根据机会和配置差距优先考虑

**5.3 优先级：**
按优先级对再平衡行动进行排序：
1. **立即** - 风险降低（减持集中持仓）
2. **高优先级** - 主要配置偏离（>10% 从目标）
3. **中优先级** - 中等偏离（5-10% 从目标）
4. **低优先级** - 微调和机会性调整

**输出（示意性值）：**
```markdown
## 再平衡建议

### 摘要
- **需要再平衡：** [是 / 否 / 可选]
- **主要原因：** [集中风险 / 行业偏离 / 现金部署 / 等]
- **估计交易：** 2 个卖出订单，3 个买入订单

### 推荐行动

#### 高优先级：风险降低
**减持 NVDA** 从 18% 到 12% 的投资组合
- **要卖出的股份数量：** 25 股（约 $3,000）
- **理由：** [过度配置 / 估值延伸 / 等]
- **税务影响：** $600 资本利得（估计）

#### 中优先级：资产配置
**增持投资级债券敞口**
- **目标：** 从 10% 增加到 20%
- **建议证券：** [选择符合用户指令的流动性证券]
- **投资金额：** 约 $10,000

#### 现金部署
**当前现金：** $5,000 (5% 的投资组合)
- **建议：** [部署 / 保持以备机会 / 减少到目标]
- **建议配置：** [跨行业/股票的分配]

### 实施计划
1. [第一个行动 - 最高优先级]
2. [第二个行动]
3. [第三个行动]
...

**时间考虑：**
- [税务年度规划 / 盈利季节 / 市场状况]
- [如果适用，建议分阶段执行]
```

## 分析框架

### 目标配置模板

此技能包含针对不同投资者类型的参考配置模型：

**阅读参考资料/目标配置.md** 获取详细模型：

- **保守型**（资本保全、收入导向）
- **稳健型**（平衡增长和收入）
- **增长型**（长期资本增值）
- **激进型**（最大增长、高风险承受能力）

每个模型包括：
- 资产类别目标（股票/债券/现金/另类投资）
- 行业指南
- 市值分布
- 地区配置
- 头寸规模规则

当用户未指定配置策略时，可作为比较基准使用。

### 风险特征评估

如果用户的目标配置未知，根据以下因素评估适当的风险特征：
- 年龄（如提及）
- 投资期限（如提及）
- 当前配置（揭示偏好）
- 头寸类型（保守型与投机型股票）

**阅读参考资料/风险特征问卷.md** 获取评估框架

## 输出指南

**语气和风格：**
- 客观且分析性
- 具有明确理由的可执行建议
- 承认市场预测的不确定性
- 平衡乐观与风险意识
- 尽可能量化

**数据呈现：**
- 表格用于比较和指标
- 百分比用于配置和回报
- 美元金额用于绝对值
- 全报告保持一致格式

**建议清晰度：**
- 明确的行动动词（TRIM、ADD、HOLD、SELL）
- 基于实时头寸规模和当前价格得出的具体数量
- 优先级（立即、高、中、低）
- 每项建议的支撑理由

**视觉描述：**
- 描述配置拆分，如同创建饼图
- 行业权重作为条形图等效物
- 绩效趋势使用方向指示器（↑ ↓ →）

## 错误处理

**如果Alpaca MCP服务器未连接：**
1. 告知用户需要Alpaca集成
2. 提供参考资料/alpaca-mcp-setup.md中的设置说明
3. 提供替代方案：手动数据输入（不太理想，用户提供头寸的CSV）

**如果API返回不完整数据：**
- 使用可用数据继续
- 在报告中注明限制
- 建议手动验证缺失头寸

**如果头寸数据似乎过时：**
- 标记问题
- 建议刷新连接或检查Alpaca状态
- 带有保留地继续分析

**如果用户没有头寸：**
- 承认空投资组合
- 提供投资组合构建指导，而不是分析
- 建议使用value-dividend-screener或us-stock-analysis获取股票想法

## 高级功能

### 税收亏损套利机会

识别适合税收亏损套利的头寸：
- 损失>5%的头寸
- 持有期考虑（避免洗售规则）
- 替代证券建议（类似但非实质性相同）

### 股息收入分析

对于包含股息支付股票的投资组合：
- 估计年度股息收入
- 股息增长率轨迹
- 股息覆盖率和可持续性
- 长期持有成本收益率

### 相关系数矩阵

对于包含5-20个头寸的投资组合：
- 估计主要头寸之间的相关性
- 识别冗余头寸（相关性>0.8）
- 建议分散化改进

### 情景分析

模拟不同情景下的投资组合表现：
- **牛市**（+20%股权增值）
- **熊市**（-20%股权下跌）
- **行业轮动**（科技疲软，价值强劲）
- **利率上升**（对成长股和债券的影响）
