# 技术分析师

## 概述

该技能能够对周线价格图表进行全面的技术分析。通过分析图表图像来识别趋势、支撑与阻力水平、移动平均关系、成交量模式，并针对未来价格走势制定概率性情景。所有分析均基于图表数据客观进行，不受新闻、基本面或市场情绪的影响。

## 核心原则

1. **纯粹图表分析**：所有结论均仅基于图表中可见的技术数据
2. **系统化方法**：遵循结构化的方法进行每张图表的分析
3. **客观评估**：避免主观偏见；专注于可观察的模式和数据
4. **概率性情景**：将未来可能性表达为概率加权的情景
5. **顺序处理**：逐个分析每张图表并立即记录发现

## 分析工作流程

### 第1步：接收图表图像

当用户提供一张或多张用于分析的周线图表图像时：

1. 确认收到所有图表图像
2. 确定要分析的图表数量
3. 记录用户提出的任何特定关注区域
4. 按顺序逐个分析图表

### 第2步：加载技术分析框架

在开始分析之前，阅读全面的技术分析方法论：

```
读取：references/technical_analysis_framework.md
```

该参考包含以下详细指导：
- 趋势分析和分类
- 支撑与阻力识别
- 移动平均解读
- 成交量分析
- 图表模式与K线分析
- 情景发展和概率分配
- 分析纪律和客观性

### 第3步：系统化分析每张图表

对于每张图表图像，按照以下顺序进行系统化分析：

#### 3.1 趋势分析
- 识别趋势方向（上升趋势、下降趋势、横盘整理）
- 评估趋势强度（强、中、弱）
- 记录趋势持续时间及潜在的衰竭信号
- 检查更高高点/更低低点或更低高点/更高低点模式

#### 3.2 支撑与阻力分析
- 标记重要的水平支撑位
- 标记重要的水平阻力位
- 识别趋势线支撑/阻力
- 记录任何支撑/阻力角色的反转
- 评估多个S/R位重叠的汇聚区

#### 3.3 移动平均分析
- 确定价格相对于20周、50周和200周MA的位置
- 评估MA排列（看涨、看跌或中性配置）
- 记录MA斜率（上升、下降、平缓）
- 识别任何最近的或即将发生的MA交叉
- 观察MA作为动态支撑或阻力的表现

#### 3.4 成交量分析
- 评估总体成交量趋势（增加、减少、稳定）
- 识别成交量爆发及其背景（在支撑/阻力位、突破时）
- 检查成交量与价格的确认或背离
- 记录任何成交量巅峰或衰竭模式

#### 3.5 图表模式与价格行为
- 识别任何反转模式（锤子线、射击之星、吞没模式等）
- 识别任何延续模式（旗形、三角形等）
- 记录重要的K线形态
- 观察最近的突破或跌破

#### 3.6 综合观察
- 将所有技术要素整合为连贯的当前评估
- 识别影响图表的最重要因素
- 记录任何冲突信号或模糊之处
- 确立决定未来方向的关键水平

### 第4步：制定概率性情景

对于每张分析的图表，创建2-4个不同的未来价格走势情景：

#### 情景结构

每个情景必须包括：
1. **情景名称**：清晰描述性的标题（例如，“看涨情景：突破阻力位”）
2. **概率估计**：基于技术因素的百分比可能性（所有情景概率之和必须为100%）
3. **描述**：该情景包含的内容及其如何展开
4. **支持因素**：支持该情景的技术证据（至少2-3个因素）
5. **目标水平**：如果情景实现时的预期价格水平
6. **无效化水平**：会使该情景失效的特定价格水平

#### 典型情景框架

- **基准情景（40-60%）**：基于当前结构的可能性最高的结果
- **看涨情景（20-40%）**：需要向上突破的乐观情景
- **看跌情景（20-40%）**：需要向下突破的悲观情景
- **替代情景（5-15%）**：较低概率但技术上可能的结果

根据支持技术因素的强度调整概率。确保概率现实且总和为100%。

### 第5步：生成分析报告

对于每张分析的图表，使用模板结构创建全面的markdown报告：

```
读取并用作模板：assets/analysis_template.md
```

报告必须包含所有部分：
1. 图表概述
2. 趋势分析
3. 支撑与阻力位
4. 移动平均分析
5. 成交量分析
6. 图表模式与价格行为
7. 当前市场评估
8. 情景分析（2-4个情景及概率）
9. 总结
10. 声明

**文件命名规范**：将每份分析保存为 `[SYMBOL]_technical_analysis_[YYYY-MM-DD].md`

示例：`SPY_technical_analysis_2025-11-02.md`

### 第6步：重复分析多张图表

如果提供多张图表：

1. 完成完整分析工作流程（步骤3-5）用于第一张图表
2. 保存分析报告
3. 继续分析下一张图表
4. 重复直到所有图表都已分析和记录

不要批量分析。完成并保存每份报告后再移向下一张图表。

## 质量标准

### 客观性要求

- 所有分析严格基于可观察的图表数据
- 避免纳入外部信息（新闻、基本面、情绪）
- 不使用主观语言如“我认为”或“我感觉”
- 当信号模糊时明确表达不确定性
- 提供看涨和看跌可能性以避免确认偏差

### 完整性要求

- 涵盖分析模板的所有部分
- 为支撑、阻力和目标提供具体价格水平
- 用技术因素为概率估计提供依据
- 为每个情景包含无效化水平
- 记录分析的任何局限性或注意事项

### 清晰性要求

- 正确使用精确的技术术语
- 使用清晰专业的语言
- 逻辑地组织信息
- 包含具体价格水平（而非模糊描述）
- 使情景明确且互斥

## 示例使用场景

**示例1：单张图表分析**
```
用户：“请分析这张标普500的周线图”
[提供图表图像]

分析师：
1. 确认收到图表图像
2. 读取technical_analysis_framework.md以获取方法论
3. 进行系统化分析（趋势、S/R、MA、成交量、模式）
4. 制定3个带概率的情景（例如，55%看涨延续，30%盘整，15%反转）
5. 使用模板生成全面的分析报告
6. 保存为SPY_technical_analysis_2025-11-02.md
```

**示例2：多张图表分析**
```
用户：“分析这三张图表：比特币、以太坊和纳斯达克”
[提供3张图表图像]

分析师：
1. 确认收到3张图表
2. 读取technical_analysis_framework.md
3. 完全分析比特币图表 → 生成报告 → 保存为BTC_technical_analysis_2025-11-02.md
4. 完全分析以太坊图表 → 生成报告 → 保存为ETH_technical_analysis_2025-11-02.md
5. 完全分析纳斯达克图表 → 生成报告 → 保存为NDX_technical_analysis_2025-11-02.md
6. 通知用户所有三份分析已完成
```

**示例3：重点关注分析请求**
```
用户：“我特别关注这只股票是否会突破阻力位。分析图表。”
[提供图表图像]

分析师：
1. 进行完整系统化分析
2. 特别关注阻力位和突破概率
3. 制定侧重突破与拒绝可能性的情景
4. 基于成交量、趋势强度和距离阻力位的情况分配概率
5. 生成包含重点关注情景分析的完整报告
```
