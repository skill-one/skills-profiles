# 行业分析师

## 概述

这项技能能够全面分析行业和产业表现图表，以识别市场周期定位并预测可能的轮动情景。分析结合了观察到的表现数据与既定的行业轮动原则，提供客观的市场评估和概率性情景预测。

## 何时使用此技能

在以下情况下使用此技能：
- 用户提供行业表现图表（通常为1周和1个月的时间范围）
- 用户提供显示相对表现数据的行业表现图表
- 用户要求分析当前市场周期定位
- 用户询问行业轮动评估或预测
- 用户需要市场定位的概率加权情景

示例用户请求：
- "分析这些行业表现图表，并告诉我我们在市场周期中的位置"
- "根据这些表现图表，哪些行业将表现优于下一阶段？"
- "根据这些数据，防御性轮动的概率是多少？"
- "审查这些行业和产业图表，并提供情景分析"

## 分析工作流程

在分析行业/产业表现图表时，请遵循以下结构化工作流程：

### 第1步：数据收集和观察

首先，仔细检查所有提供的图表图像，以提取以下内容：
- **行业级表现**：识别哪些行业（科技、金融、可选消费品等）表现优于/劣于
- **产业级表现**：注意表现强劲或疲软的特定产业
- **时间范围比较**：比较1周与1个月的表现，以识别趋势一致性或背离
- **变动幅度**：评估相对表现差异的大小
- **变动广度**：确定表现是集中还是广泛

分析图表时用英语思考。记录关键行业和产业的特定数值表现。

### 第2步：市场周期评估

加载行业轮动知识库以指导分析：
- 阅读 `references/sector_rotation.md` 以访问市场周期和行业轮动框架
- 将观察到的表现模式与每个周期阶段的预期模式进行比较：
  - 早期周期复苏
  - 中期周期扩张
  - 晚期周期
  - 萧条

通过以下方式确定最符合当前观察的周期阶段：
- 将表现优异的行业映射到典型的周期领导者
- 将表现疲软的行业映射到典型的周期落后者
- 评估多个行业的一致性
- 评估与防御性行业与周期性行业表现的一致性

### 第3步：当前情况分析

将观察结果综合为客观评估：
- 说明当前表现最接近哪个市场周期阶段
- 突出支持证据（哪些行业/产业证实了这一观点）
- 注意任何矛盾信号或异常模式
- 根据信号一致性评估置信度

使用数据驱动语言和特定的表现数值参考。

### 第4步：情景开发

根据行业轮动原则和当前定位，为下一阶段开发2-4个潜在情景：

对于每个情景：
- 描述市场周期过渡
- 识别可能表现优异的行业
- 识别可能表现疲软的行业
- 指定确认此情景的催化剂或条件
- 分配概率（参见 `sector_rotation.md` 中的概率评估框架）

情景应从最可能（最高概率）到替代/反主流情景的范围。

### 第5步：输出生成

创建具有以下部分的Markdown文档：

**必需部分：**
1. **执行摘要**：2-3句概述关键发现
2. **当前情况**：当前表现模式和周期定位的详细分析
3. **支持证据**：支持周期评估的特定行业和产业表现数据
4. **情景分析**：2-4个情景，包括描述和概率分配
5. **推荐定位**：基于情景概率的战略和战术定位建议
6. **关键风险**：需要监控的显著风险或矛盾信号

## 关键分析原则

进行分析师时：

1. **客观优先**：让数据引导结论，而非先入为主
2. **概率思维**：通过概率范围表达不确定性
3. **多时间范围**：比较1周和1个月的数据以确认趋势
4. **相对表现**：关注相对强度，而非绝对回报
5. **广度重要**：广泛的表现比孤立运动更重要
6. **无绝对性**：市场很少完全遵循教科书模式
7. **历史背景**：参考典型轮动模式，但承认其独特性

## 概率指南

根据证据强度应用以下概率范围：

- **70-85%**：强证据，多个跨行业和时间范围的确认信号
- **50-70%**：中等证据，部分确认信号但有混合指标
- **30-50%**：弱证据，有限或矛盾信号
- **15-30%**：与当前指标相反的投机情景，但可能

所有情景的总概率应约为100%。

## 重要说明

- 所有分析思考应以英语进行
- 输出的Markdown文件必须为英语
- 每次分析参考行业轮动知识库
- 保持客观性，避免确认偏差
- 如果有新数据，应更新概率评估
- 图表通常显示1周和1个月期间的表现
