# CANSLIM 股票筛选器 - 第三阶段（完整 CANSLIM）

## 概述

该技能使用威廉·欧奈尔（William O'Neil）的成熟 CANSLIM 方法筛选美国股票，这是一种系统化方法，用于识别基本面强劲且具有价格动力的成长型股票。CANSLIM 分析 7 个关键组成部分：**C** 当前的收益、**A** 年度增长、**N** 新兴/新高、**S** 供应/需求、**L** 领导者/RS 排名、**I** 机构支持，以及 **M** 市场方向。

**第三阶段** 实现了全部 7 个 CANSLIM 组成部分（C、A、N、S、L、I、M），代表 **100% 的完整方法论**。

**两阶段方法：**
1. **第一阶段（FMP API + Finviz）**：使用所有 7 个 CANSLIM 组成部分分析股票池
2. **第二阶段（报告）**：按综合评分排序并生成可操作的报告

**主要功能：**
- 综合评分（0-100 分制）具有加权组成部分
- **Finviz 备用**用于机构持股数据（当 FMP 数据不完整时自动触发）
- 渐进式过滤以优化 API 使用
- JSON + Markdown 输出格式
- 解释带：卓越+（90+）、卓越（80-89）、强劲（70-79）、高于平均水平（60-69）
- 市场保护（M 组成部分门控）

**第三阶段.1 组成部分权重（原始 O'Neil 权重）：**
- C（当前收益）：15%
- A（年度增长）：20%
- N（新兴性）：15%
- S（供应/需求）：15%
- L（领导者/RS 排名）：20% — 多周期加权 RS（3m/6m/12m 对可配置基准）
- I（机构）：10%
- M（市场方向）：5%

**加权 RS 公式：**
```
加权 RS = 0.40 × rel_3m + 0.30 × rel_6m + 0.30 × rel_12m
```
可用周期在缺失时重新归一化。默认基准是 `^GSPC`；用 `--rs-benchmark SPY/QQQ/IWM/...` 覆盖。

**多周期数据不完整时的备用层次结构：**
1. 无基准 → 加权绝对股票表现 + 20% 惩罚。
2. 所有多周期窗口缺失但 >=50 根价格历史 → 落回到传统的 365 天全窗口绝对回报作为评分输入（如果没有基准，则 20% 惩罚）。
3. <50 根价格历史 → 评分=0，`error` 设置。

### 第一步：验证 API 访问和需求

检查用户是否配置了 FMP API 密钥：

```bash
# 检查环境变量
echo $FMP_API_KEY

# 如果未设置，提示用户提供它
```

**需求：**
- **FMP API 密钥**（免费层：每天 250 次调用，足够用于 40 只股票）
- **Python 3.9+** 及所需库：
  - `requests`（FMP API 调用）
  - `beautifulsoup4`（Finviz 网页抓取）
  - `lxml`（HTML 解析）

**安装：**
```bash
pip install requests beautifulsoup4 lxml
```

如果 API 密钥缺失，指导用户：
1. 在 https://site.financialmodelingprep.com/developer/docs 注册
2. 获取免费 API 密钥（每天 250 次调用）
3. 设置环境变量：`export FMP_API_KEY=your_key_here`

### 第二步：确定股票池

**选项 A：默认池（推荐）**
使用市值排名前 40 的 S&P 500 股票（脚本中预定义）：

```bash
python3 skills/canslim-screener/scripts/screen_canslim.py
```

**选项 B：自定义池**
用户提供特定代码或行业：

```bash
python3 skills/canslim-screener/scripts/screen_canslim.py \
  --universe AAPL MSFT GOOGL AMZN NVDA META TSLA
```

**选项 C：行业特定**
用户可以提供行业聚焦列表（技术、医疗保健等）

**API 预算考虑（第三阶段）：**
- 40 只股票 × 7 FMP 调用/股票 = 280 API 调用
  - FMP：每只股票 7 个调用（概况、报价、收益×2、历史_90d、历史_365d、机构）
  - Finviz：约 1.8 调用/股票（机构持股备用，2 秒速率限制，不计入 FMP 预算）
- 市场数据（^GSPC 报价、^VIX 报价、^GSPC 52 周历史）：3 FMP 调用
- 总计：每次筛选运行约 283 FMP 调用（超出免费层 250 次调用）
- **建议**：使用 `--max-candidates 35` 免费层（35 × 7 + 3 = 248 调用），或升级到 FMP 起步层（每月 29.99 美元，每天 750 次调用）以进行完整的 40 股票筛选

### 第三步：执行 CANSLIM 筛选脚本

使用适当参数运行主筛选脚本：

```bash
cd skills/canslim-screener/scripts

# 基本运行（40 只股票，报告中前 20 只）
python3 screen_canslim.py --api-key $FMP_API_KEY

# 自定义参数
python3 screen_canslim.py \
  --api-key $FMP_API_KEY \
  --max-candidates 40 \
  --top 20 \
  --output-dir ../..

# 自定义 RS 基准（第三阶段.1）
python3 screen_canslim.py --rs-benchmark SPY

# 禁用 L 组成部分（节省每只股票的 365 天获取；L 固定在 50 的中性）
python3 screen_canslim.py --disable-rs
```

**脚本工作流程（第三阶段 - 完整 CANSLIM）：**
1. **市场方向（M）**：分析 S&P 500 趋势与 50 天 EMA（使用真实历史数据以获得准确的 EMA）
   - 如果检测到熊市（M=0），警告用户提高现金配置
2. **S&P 500 历史数据**：获取 52 周数据用于 M 组成部分的 EMA 和 L 组成部分的 RS 计算
3. **股票分析**：对每只股票计算：
   - **C 组成部分**：季度 EPS/收入增长（YoY）
   - **A 组成部分**：3 年 EPS CAGR 和稳定性
   - **N 组成部分**：距离 52 周高，突破检测
   - **S 组成部分**：基于成交量的积累/分配（上涨日 vs 下跌日成交量）
   - **L 组成部分**：52 周相对强度 vs S&P 500
   - **I 组成部分**：机构持有人数量 + 持股比例（Finviz 备用）
4. **综合评分**：所有 7 个组成部分的加权平均值
5. **排名**：按综合评分排序（最高优先）
6. **报告**：生成 JSON + Markdown 输出

**预期执行时间（第三阶段）：**
- 40 只股票：**~2 分钟**（每只股票额外获取 52 周历史数据用于 L 组成部分）
- Finviz 备用增加 ~2 秒/股票（速率限制）
- L 组成部分需要每只股票的 365 天历史数据

**Finviz 备用行为：**
- 当 FMP `sharesOutstanding` 不可用时自动触发
- 从 Finviz.com 抓取机构持股比例（免费，无需 API 密钥）
- 将 I 组成部分准确度从 35/100（部分数据）提高到 60-100/100（完整数据）
- 用户看到：`✅ 使用 Finviz 机构持股为 NVDA：68.3%`

### 第五步：分析顶级候选股并提供建议

审查顶级排名的股票并与知识库交叉参考：

**参考文档：**
1. `references/interpretation_guide.md` - 了解评级带和投资组合规模
2. `references/canslim_methodology.md` - 深入了解组成部分含义（现在包括 S 和 I）
3. `references/scoring_system.md` - 了解评分公式（第三阶段权重）

**分析框架：**

对于 **卓越+ 股票（90-100 分）**：
- 所有组成部分接近完美（C≥85, A≥85, N≥85, S≥80, L≥85, I≥80, M≥80）
- 指导：立即买入，激进仓位规模（15-20% 的投资组合）
- 示例： "NVDA 评分 97.2 - 爆炸性季度收益（100），强劲 3 年增长（95），处于新高（98），成交量积累（85），RS 领导者（92），强劲机构支持（90），上升趋势市场（100）"

对于 **卓越股票（80-89 分）**：
- 卓越的基本面 + 强劲动量
- 指导：强力买入，标准规模（10-15% 的投资组合）

对于 **强劲股票（70-79 分）**：
- 各组成部分均稳固，轻微弱点
- 指导：买入，标准规模（8-12% 的投资组合）
- 第三阶段示例： "股票评分 77.5 - 强劲收益（85），稳健增长（80），接近高（70），积累（60），RS 领导者（75），良好机构（60），上升趋势（90）"

对于 **高于平均水平股票（60-69 分）**：
- 达到阈值，一个组成部分较弱
- 指导：回调时买入，保守规模（5-8% 的投资组合）

**熊市覆盖：**
- 如果 M 组成部分 = 0（检测到熊市），**不要买入**，无论其他分数如何
- 指导：提高 80-100% 现金，等待市场复苏
- CANSLIM 在熊市中无效（4 只股票中有 3 只跟随市场趋势）

## 资源

### 脚本目录 (`scripts/`)

**主脚本：**
- `screen_canslim.py` - 主协调脚本
  - 筛选工作流程的入口点
  - 处理参数解析、API 协调、排名、报告
  - 使用方式：`python3 screen_canslim.py --api-key KEY [选项]`

- `fmp_client.py` - FMP API 客户端包装
  - 速率限制（调用之间 0.3 秒）
  - 429 错误处理，60 秒重试
  - 会话级缓存
  - 方法：`get_income_statement()`, `get_quote()`, `get_historical_prices()`, `get_institutional_holders()`

- `finviz_stock_client.py` - Finviz 网页抓取客户端 ← **新**
  - 基于 BeautifulSoup 的 HTML 解析
  - 从 Finviz.com 抓取机构持股比例
  - 速率限制（调用之间 2.0 秒）
  - 无需 API 密钥（免费网页抓取）
  - 方法：`get_institutional_ownership()`, `get_stock_data()`

**计算器 (`scripts/calculators/`):**
- `earnings_calculator.py` - C 组成部分（当前收益）
  - 季度 EPS/收入增长（YoY）
  - 评分：50%+ = 100 分，30-49% = 80 分，18-29% = 60 分

- `growth_calculator.py` - A 组成部分（年度增长）
  - 3 年 EPS CAGR 计算
  - 稳定性检查（无负增长年份）
  - 评分：40%+ = 90 分，30-39% = 70 分，25-29% = 50 分

- `new_highs_calculator.py` - N 组成部分（新兴性）
  - 距离 52 周高
  - 成交量确认的突破检测
  - 评分：高 5% + 突破 = 100 分，10% + 突破 = 80 分

- `supply_demand_calculator.py` - S 组成部分（供应/需求）← **新**
  - 基于成交量的积累/分配分析
  - 上涨日成交量 vs 下跌日成交量比率（60 天回溯）
  - 评分：比率 ≥2.0 = 100 分，1.5-2.0 = 80 分，1.0-1.5 = 60 分

- `leadership_calculator.py` - L 组成部分（领导者/相对强度）
  - 52 周股票表现 vs S&P 500 基准
  - RS 排名估计（1-99 分，O'Neil 风格）
  - 评分：RS 90+ 超越市场 = 100 分，RS 80-89 = 80 分

- `institutional_calculator.py` - I 组成部分（机构）
  - 机构持有人数量（来自 FMP）
  - 持股比例（来自 FMP 或 Finviz 备用）
  - 超级投资者检测（伯克希尔哈撒韦、贝德福德等）
  - 评分：50-100 持有人 + 30-60% 持股 = 100 分

- `market_calculator.py` - M 组成部分（市场方向）

## 故障排除

### 问题1：FMP API 速率限制超出

**症状：**
```
ERROR: 429 Too Many Requests - Rate limit exceeded
Retrying in 60 seconds...
```

**原因：**
- 在短时间内运行多个筛选
- 超出每日250次调用（免费套餐限制）
- 其他应用程序使用相同API密钥

**解决方案：**
1. **等待重试**：脚本自动在60秒后重试
2. **减少范围**：使用`--max-candidates 30`降低API使用量
3. **检查每日使用量**：免费套餐在UTC午夜重置
4. **升级套餐**：FMP Starter ($29.99/月) 提供750次/日调用

### 问题2：缺少必需库

**症状：**
```
ERROR: required libraries not found. Install with: pip install beautifulsoup4 requests lxml
```

**解决方案：**
```bash
# 安装所有必需库
pip install requests beautifulsoup4 lxml

# 或单独安装
pip install beautifulsoup4
pip install requests
pip install lxml
```

### 问题3：Finviz备用执行缓慢

**症状：**
```
Execution time: 2 minutes 30 seconds for 40 stocks (比预期慢)
```

**原因：**
- Finviz速率限制（每请求2.0秒）
- 所有股票因FMP数据缺失触发备用

**解决方案：**
1. **接受延迟**：40只股票1-2分钟是Finviz备用的正常时间
2. **监控备用使用**：检查日志中"使用Finviz机构持股"消息
3. **降低速率限制**（高级）：编辑`finviz_stock_client.py`，将`rate_limit_seconds=2.0`改为`1.5`（风险：IP封禁）

**注意**：Finviz备用增加~2秒/股票，但显著提高I组件准确性（35→60-100分）

### 问题4：Finviz网页抓取失败

**症状：**
```
WARNING: Finviz request failed with status 403 for NVDA
⚠️ 使用Finviz机构持股数据 - FMP流通股数不可用。Finviz备用也不可用。评分降低50%。
```

**原因：**
- Finviz阻止抓取请求（检测到User-Agent）
- 速率限制超出（请求过多）
- 网络问题或Finviz宕机

**解决方案：**
1. **等待重试**：速率限制几分钟后重置
2. **检查网络连接**：验证对finviz.com的网络访问
3. **接受备用**：脚本继续仅使用FMP持有人计数（I评分最高70/100）
4. **手动验证**：手动检查Finviz网站以确认IP被封

**优雅降级：**
- 脚本不会因Finviz问题失败
- 转退为FMP持有人计数
- 报告中显示质量警告

### 问题5：没有股票满足最低阈值

**症状：**
```
✓ 成功分析40只股票
前5只股票：
  1. AAPL  -  58.3 (平均)
  2. MSFT  -  55.1 (平均)
  ...
```

**原因：**
- 市场低迷（M组件低）
- 选定的范围缺乏成长股
- 市场轮动远离成长股

**解决方案：**
1. **检查M组件**：若M=0（市场低迷），按CANSLIM规则增加现金
2. **扩大范围**：尝试不同行业或市值范围
3. **降低预期**：平均评分（55-65）在弱市中仍可能具有操作价值
4. **等待更好的时机**：CANSLIM在牛市中效果最佳

### 问题6：数据质量警告

**症状：**
```
⚠️ 收入下降但EPS增长（可能是回购扭曲）
⚠️ 使用Finviz机构持股数据 (68.3%) - FMP流通股数不可用。
```

**解读：**
- 这些**不是错误** - 它们是计算器的质量标志
- 收入警告：EPS增长可能来自股份回购，而非有机增长
- Finviz警告：数据源从FMP切换到Finviz（仍准确）

**操作：**
1. 查看完整报告中的组件详情
2. 与基本面分析交叉验证
3. 根据风险水平调整仓位大小
4. Finviz数据可靠 - 无需对数据源警告采取行动
