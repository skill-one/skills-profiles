# 市场研究报告

## 概述

市场研究报告是全面性的战略文件，通过分析行业、市场和竞争格局来为商业决策、投资策略和战略规划提供信息。这项技能可以生成 **50多页的专业级报告**，包含丰富的视觉内容，其交付成果模式参考了麦肯锡、BCG、贝恩、Gartner和Forrester等顶级咨询公司的产出。

**主要特点：**
- **全面的篇幅**：报告设计为50多页，无代币限制
- **视觉丰富的内容**：开始时生成5-6个关键图表（根据需要写作过程中会添加更多）
- **数据驱动分析**：与市场数据查询深度集成
- **多框架方法**：波特五力模型、PESTLE、SWOT、BCG矩阵、TAM/SAM/SOM
- **专业格式化**：咨询公司级别的排版、颜色和布局
- **可执行的建议**：战略重点，包含实施路线图

**输出格式**：LaTeX带专业样式，编译为PDF。使用`market_research.sty`样式包，确保格式一致且专业。

## 使用此技能的时机

当需要以下情况时，应使用此技能：
- 创建用于投资决策的全面市场分析
- 开发用于战略规划的行业报告
- 分析竞争格局和市场动态
- 进行市场规模估算（TAM/SAM/SOM）
- 评估市场进入机会
- 准备并购活动的尽职调查材料
- 创建用于行业定位的思想领导力内容
- 开发市场进入策略文档
- 分析监管政策和政策对市场的影响
- 为新产品发布构建商业案例

### 核心分析（约35页）

#### 第一章：市场概述与定义（4-5页）

**内容要求：**
- 市场定义和范围
- 行业生态系统映射
- 关键利益相关者及其角色
- 市场边界和邻近关系
- 历史背景和演变

**必需视觉图表（2）：**
1. 市场生态系统/价值链图表
2. 行业结构图表

**关键数据点：**
- 市场定义标准
- 包含/排除细分
- 地理范围
- 分析时间范围

---

#### 第二章：市场规模与增长分析（6-8页）

**内容要求：**
- 总可服务市场（TAM）计算
- 可服务可获取市场（SAM）定义
- 可获取市场（SOM）估算
- 历史增长分析（5-10年）
- 增长预测（5-10年）
- 增长驱动因素和抑制因素
- 区域市场分解
- 细分级分析

**必需视觉图表（4）：**
1. 市场增长轨迹图表（历史+预测）
2. TAM/SAM/SOM同心圆图表
3. 区域市场分解（饼图或树图）
4. 细分增长比较（条形图）

**关键数据点：**
- 当前市场规模（带来源）
- 历史和预测CAGR
- 按区域划分的市场规模
- 按细分划分的市场规模
- 预测的关键假设

**数据来源：**
使用`research-lookup`查找：
- 市场研究报告（Gartner、Forrester、IDC等）
- 行业协会数据
- 政府统计数据
- 公司财务报告
- 学术研究

## 工作流程

### 第一阶段：研究与数据收集

**步骤1：定义范围**
- 明确市场定义
- 设置地理边界
- 确定时间范围
- 确定要回答的关键问题

**步骤2：进行深入研究**

使用`research-lookup`广泛收集市场数据：

```bash
# 市场规模和增长数据
python skills/research-lookup/scripts/research_lookup.py \
  "当前[市场]行业的市场规模和预测增长率是多少？包括TAM、SAM、SOM估算和CAGR预测"

# 竞争格局
python skills/research-lookup/scripts/research_lookup.py \
  "[市场]市场的前10名竞争对手是谁？他们的市场份额和竞争定位是什么？"

# 行业趋势
python skills/research-lookup/scripts/research_lookup.py \
  "2024-2030年[市场]行业的主要趋势和增长驱动因素是什么？"

# 监管环境
python skills/research-lookup/scripts/research_lookup.py \
  "哪些监管政策和政策变化正在影响[市场]行业？"
```

**步骤3：数据组织**
- 创建`sources/`文件夹，包含研究笔记
- 按章节组织数据
- 识别数据差距
- 根据需要开展后续研究

### 第二阶段：分析与框架应用

**步骤4：应用分析框架**

针对每个框架进行结构化分析：

- **市场规模**：TAM → SAM → SOM，带明确假设
- **波特五力模型**：对每个力量进行高/中/低评级，并说明理由
- **PESTLE**：分析每个维度，并说明趋势和影响
- **SWOT**：内部优势/劣势，外部机会/威胁
- **竞争定位**：定义轴，绘制竞争对手

**步骤5：发展见解**
- 将发现综合为关键见解
- 识别战略影响
- 制定建议
- 优先级排序机会

### 视觉质量要求

- **分辨率**：所有图像至少300 DPI
- **格式**：PNG为位图，PDF为矢量图
- **无障碍性**：使用对色盲友好的调色板
- **一致性**：整个报告使用相同的配色方案
- **标注**：所有坐标轴、图例和数据点都有标注
- **来源归属**：图表说明中标注来源

### 数据质量要求

- **时效性**：数据不超过2年（优先使用当年数据）
- **来源**：所有统计数据都归因于特定来源
- **验证**：可能时交叉参考多个来源
- **假设**：所有预测都说明其潜在假设
- **局限性**：承认数据局限性和空白

### 撰写质量要求

- **客观性**：呈现平衡分析，承认不确定性
- **清晰度**：避免术语，定义技术术语
- **精确性**：使用具体数字而不是模糊的限定词
- **结构**：清晰的标题，逻辑流程，平滑过渡
- **可操作性**：建议具体且可执行

## LaTeX格式化

### 使用样式包

`market_research.sty`包提供专业格式。在文档中包含它：

```latex
\documentclass[11pt,letterpaper]{report}

```

### 盒子环境

使用彩色盒子突出关键内容：

```latex
% 关键见解框（蓝色）
\begin{keyinsightbox}[关键发现]
市场预计将以15.3%的CAGR增长至2030年。
\end{keyinsightbox}

% 市场数据框（绿色）
\begin{marketdatabox}[市场快照]
\begin{itemize}
    \item 市场规模（2024年）：452亿美元
    \item 预测规模（2030年）：987亿美元
    \item CAGR：15.3%
\end{itemize}
\end{marketdatabox}

% 风险框（橙色/警告）
\begin{riskbox}[关键风险]
监管变化可能影响40%的市场参与者。
\end{riskbox}

% 建议框（紫色）
\begin{recommendationbox}[战略建议]
优先考虑亚太地区的市场进入。
\end{recommendationbox}

% 提示框（灰色）
\begin{calloutbox}[定义]
TAM（整体可服务市场）代表总收入机会。
\end{calloutbox}
```

## 故障排除

### 常见问题

**问题**：报告页数不足50页
- **解决方案**：扩展附录中的数据表，添加更详细的公司简介，包含更多区域分解

**问题**：视觉材料未渲染
- **解决方案**：检查LaTeX中的文件路径，确保图像在figures/文件夹中，验证文件扩展名

**问题**：参考文献缺失条目
- **解决方案**：在第一次xelatex后运行bibtex，检查.bib文件的语法错误

**问题**：表格/图表溢出
- **解决方案**：使用`\resizebox`或`adjustbox`包，减少图像宽度百分比

**问题**：生成视觉材料质量差
- **解决方案**：使用`--doc-type report`标志，增加迭代次数`--iterations 5`
