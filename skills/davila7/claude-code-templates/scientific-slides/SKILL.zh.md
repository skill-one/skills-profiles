# 科学幻灯片

## 概述

科学演示是传达研究、分享成果以及与学术和专业观众互动的关键媒介。这项技能为创建有效的科学演示提供了全面指导，从结构、内容开发到视觉设计和演示准备。

**重点关注**：会议、研讨会、答辩和职业讲座的口头演示。

**关键设计理念**：科学演示应当视觉吸引人且基于研究。务必避免枯燥、文字过多的幻灯片。优秀的科学演示结合了：
- **引人入胜的视觉效果**：高质量的图表、图像、图表（而不仅仅是项目符号）
- **研究背景**：从研究查询库中引用恰当的文献以建立可信度
- **最小化文字**：项目符号作为提示，您口头提供解释
- **专业设计**：现代配色方案、强烈的视觉层次结构、充足的留白
- **故事驱动**：清晰的叙事弧，而不仅仅是数据堆砌

**请记住**：乏味的演示 = 遗忘的科学。在保持科学严谨性的同时，使您的幻灯片视觉上令人难忘，并通过恰当的引用。

## 使用此技能的时机

当您需要以下情况时，应使用此技能：
- 准备会议演示（5-20分钟）
- 开发学术研讨会（45-60分钟）
- 创建论文或学位论文答辩演示
- 设计资助提案演示
- 准备期刊俱乐部演示
- 在机构或公司进行研究讲座
- 关于科学主题的教学或教程演示

## 使用 Nano Banana Pro 生成幻灯片

**此技能使用 Nano Banana Pro AI 自动生成令人惊叹的演示幻灯片。**

根据输出格式，有两种工作流程：

### 默认工作流程：PDF 幻灯片（推荐）

使用 Nano Banana Pro 将每张幻灯片生成为一个完整的图像，然后组合成 PDF。这会产生最令人惊叹的视觉效果。

**工作原理：**
1. **规划演示文稿**：为每张幻灯片创建详细计划（标题、要点、视觉元素）
2. **生成幻灯片**：调用 Nano Banana Pro 为每张幻灯片创建完整的幻灯片图像
3. **组合为 PDF**：将幻灯片图像组装成一个 PDF 演示文稿

**步骤 1：规划每张幻灯片**

在生成之前，为您的演示创建详细计划：

```markdown
# 演示文稿计划：机器学习的介绍

## 幻灯片 1：标题幻灯片
- 标题："机器学习：从理论到实践"
- 副标题："2025 年人工智能会议"
- 演讲者：Jane Smith 博士，XYZ 大学
- 视觉元素：现代抽象神经网络背景

## 幻灯片 2：引言
- 标题："机器学习的重要性"
- 要点：行业采用、突破性应用、未来潜力
- 视觉元素：显示不同机器学习应用（医疗保健、金融、机器人）的图标

## 幻灯片 3：核心概念
- 标题："三种学习类型"
- 内容：监督学习、无监督学习、强化学习
- 视觉元素：显示每种类型的示例的三部分图表

...（继续为所有幻灯片）
```

**步骤 2：生成每张幻灯片**

使用 `generate_slide_image.py` 脚本创建每张幻灯片。

**关键：格式一致性协议**

为确保演示文稿中所有幻灯片的格式统一：

1. **在演示文稿开始时定义格式目标**，并在每个提示中包含它：
   - 配色方案（例如，“深蓝色背景，白色文字，金色点缀”）
   - 字体样式（例如，“粗体无衬线标题，干净的正文文字”）
   - 视觉风格（例如，“极简、专业、企业美学”）
   - 布局方法（例如，“充足的留白，左对齐内容”）

2. **在生成后续幻灯片时始终附加上一张幻灯片**，使用 `--attach`：
   - 这允许 Nano Banana Pro 查看并匹配现有风格
   - 在整个演示文稿中创建视觉连续性
   - 确保颜色、字体和设计语言的统一

3. **默认作者为 "K-Dense"**，除非指定其他名称

4. **在引用研究的幻灯片中直接包含引用**：
   - 在提示文本中添加引用，以便它们出现在生成的幻灯片上
   - 使用格式："包含引用：(作者等人，年份)" 或 "显示参考文献：作者等人，年份"
   - 对于多个引用，在提示中列出所有引用
   - 引用应出现在幻灯片底部的小字或相关内容附近

5. **为结果幻灯片附加现有图形/数据**（对数据驱动演示文稿至关重要）：
   - 创建关于结果的幻灯片时，始终检查以下位置的现有图形：
     - 工作目录（例如，`figures/`、`results/`、`plots/`、`images/`）
     - 用户提供的输入文件或目录
     - 与演示文稿相关的任何数据可视化、图表或图形
   - 使用 `--attach` 将这些图形附加到 Nano Banana Pro，以便它可以包含它们：
     - 附加实际数据图形/图表以用于结果幻灯片
     - 附加相关图表以用于方法学幻灯片
     - 附加标题幻灯片的标志或机构图像
   - 附加数据图形时，在提示中描述您想要的内容：
     - "创建一张展示附加结果图表的幻灯片，突出显示关键发现"
     - "围绕这张附加图形创建一张幻灯片，添加标题和要点解释数据"
     - "将附加图形纳入结果幻灯片，并解释数据"
   - **在创建结果幻灯片之前**：列出工作目录中的文件以找到相关图形
   - 可以附加多个图形：`--attach fig1.png --attach fig2.png`

**包含格式一致性、引用和图形附加的示例：**

```bash
# 标题幻灯片（第一张幻灯片 - 建立风格）
python scripts/generate_slide_image.py "演示文稿标题：'机器学习：从理论到实践'。副标题：'2025 年人工智能会议'。演讲者：K-Dense。格式目标：深蓝色背景 (#1a237e)、白色文字、金色点缀 (#ffc107)、极简设计、无衬线字体、充足的边距、无装饰元素。" -o slides/01_title.png

# 内容幻灯片带引用（附加上一张幻灯片以保持一致性）
python scripts/generate_slide_image.py "演示文稿幻灯片标题 '机器学习的重要性'。三个要点，带简单图标：1) 行业采用，2) 突破性应用，3) 未来潜力。引用：在底部以小字包含：(LeCun 等人，2015；Goodfellow 等人，2016)。格式目标：匹配附加幻灯片风格 - 深蓝色背景、白色文字、金色点缀、极简专业设计、无视觉杂乱。" -o slides/02_intro.png --attach slides/01_title.png

# 背景幻灯片带多个引用
python scripts/generate_slide_image.py "演示文稿幻灯片标题 '深度学习革命'。关键里程碑：ImageNet 突破 (2012)、Transformer 架构 (2017)、GPT 模型 (2018 年至今)。引用：在底部显示参考文献：(Krizhevsky 等人，2012；Vaswani 等人，2017；Brown 等人，2020)。格式目标：精确匹配附加幻灯片风格 - 相同颜色、字体、极简设计。" -o slides/03_background.png --attach slides/02_intro.png

# 结果幻灯片 - 附加实际数据图形（对数据驱动演示文稿至关重要）
# 首先，检查哪些图形存在：ls figures/ 或 ls results/
python scripts/generate_slide_image.py "演示文稿幻灯片标题 '模型性能结果'。创建一张展示附加准确率图表的幻灯片。关键发现：1) 达到 95% 准确率，2) 比基线高 12%，3) 在测试集中保持一致。引用：在底部包含：(我们的结果，2025)。格式目标：精确匹配附加幻灯片风格。" -o slides/04_results.png --attach slides/03_background.png --attach figures/accuracy_chart.png

# 结果幻灯片 - 多图形比较
python scripts/generate_slide_image.py "演示文稿幻灯片标题 '前后比较'。创建一个并排比较幻灯片，使用两个附加图形。左侧：基线结果，右侧：我们改进的结果。添加简要标签解释改进。格式目标：精确匹配附加幻灯片风格。" -o slides/05_comparison.png --attach slides/04_results.png --attach figures/baseline.png --attach figures/improved.png

# 方法学幻灯片 - 附加现有图表
python scripts/generate_slide_image.py "演示文稿幻灯片标题 '系统架构'。展示附加的架构图表，并添加简要解释性要点：1) 输入处理，2) 模型推理，3) 输出生成。格式目标：精确匹配附加幻灯片风格。" -o slides/06_architecture.png --attach slides/05_comparison.png --attach diagrams/system_architecture.png
```

**重要提示**：在创建结果幻灯片之前：
1. 列出工作目录中的文件：`ls -la figures/` 或 `ls -la results/`
2. 检查用户提供的目录以找到相关图形
3. 附加所有应在幻灯片上出现的图形
4. 描述 Nano Banana Pro 应如何整合附加图形

**提示模板：**

在每次提示中包含以下元素（根据需要进行自定义）：
```
[幻灯片内容描述]
引用：在底部以小字包含：(作者1 等人，年份；作者2 等人，年份)
格式目标：[背景颜色]，[文字颜色]，[点缀颜色]，极简专业设计，无装饰元素，与附加幻灯片风格一致。
```

## 核心功能

### 1. 演示文稿结构和组织

构建具有清晰叙事流程和针对不同场景的适当结构的演示文稿。有关详细指导，请参阅 `references/presentation_structure.md`。

**通用故事弧**：
1. **钩子（Hook）**：吸引注意力（30-60秒）
2. **背景（Context）**：建立重要性（谈话的5-10%）
3. **问题/差距（Problem/Gap）**：识别未知领域（谈话的5-10%）
4. **方法（Approach）**：解释你的解决方案（谈话的15-25%）
5. **结果（Results）**：展示关键发现（谈话的40-50%）
6. **启示（Implications）**：讨论意义（谈话的15-20%）
7. **结尾（Closure）**：令人难忘的结论（1-2分钟）

**特定谈话结构**：
- **会议演讲（15分钟）**：专注于1-2个关键发现，方法部分简略
- **学术研讨会（45分钟）**：全面覆盖，详细方法，多个研究
- **论文答辩（60分钟）**：完整论文概述，涵盖所有研究
- **项目提案（15分钟）**：强调重要性、可行性和影响
- **期刊俱乐部（30分钟）**：对已发表工作的批判性分析

### 2. 幻灯片设计原则

创建专业、易读且易于访问的幻灯片，以增强理解。有关完整设计指南，请参阅 `references/slide_design_principles.md`。

**反模式：避免枯燥、文字过多的演示**

❌ **使演示枯燥、令人难忘的原因**：
- 大段文字（每张幻灯片超过6个要点）
- 字体太小（正文小于24pt）
- 只有黑色文字在白色背景上（没有视觉吸引力）
- 没有图像或图形（只有要点）
- 通用模板，没有定制
- 密集的、段落式的要点
- 缺少研究背景（没有引用）
- 所有幻灯片看起来都一样（重复）

✅ **使演示吸引人、令人难忘的原因**：
- 高质量视觉元素主导（图表、照片、图表、图标）
- 大而清晰的文字作为点缀（不是主要内容）
- 现代、有目的性的配色方案（不是默认主题）
- 充足的留白（幻灯片有呼吸空间）
- 基于研究的背景（从research-lookup获取适当引用）
- 幻灯片布局多样化（不只是要点列表）
- 故事驱动的流程，有视觉锚点
- 专业、精致的外观

**核心设计原则**：

**视觉优先策略**（关键）：
- 先使用视觉元素（图表、图像、图表），再添加文字作为支持
- 每张幻灯片都应该有强烈的视觉元素（图表、图表、照片、图表）
- 文字解释或补充视觉元素，而不是取代它们
- 思考：“我如何展示，而不仅仅是告诉？”
- 目标：60-70%的视觉内容，30-40%的文字

**简洁而有影响力**：
- 每张幻灯片一个主要思想
- 最少文字（3-4个要点，每个4-6个词为佳）
- 充足的留白（幻灯片的40-50%）
- 清晰的视觉焦点
- 大胆、自信的设计选择

**字体设计以吸引人**：
- 无衬线字体（Arial、Calibri、Helvetica）
- 大字体：正文24-28pt（不是最小18pt）
- 标题36-44pt（加粗）
- 高对比度（最小4.5:1，推荐7:1）
- 使用大小来建立层次结构，而不仅仅是粗细

**配色方案**：
- 现代配色方案（不是默认的蓝/灰）
- 考虑你的主题：生物技术？鲜艳的颜色。物理学？简洁的暗色。健康？温暖的色调。
- 有限调色板（总共3-5种颜色）
- 高对比度组合
- 对色盲安全（避免红绿组合）
- 有目的地使用颜色（不是装饰）

**布局以增加视觉兴趣**：
- 多样化布局（不只是要点列表）
- 使用两列布局（文字+图表）
- 关键结果使用全屏图表
- 非对称构图（比居中更有趣）
- 三分法则用于焦点
- 保持一致，但不重复

### 3. 幻灯片数据可视化

将科学图表适应演示场景。有关详细指导，请参阅 `references/data_visualization_slides.md`。

**与期刊图表的关键区别**：
- 简化，不要复制
- 字体更大（最小18-24pt）
- 更少的面板（分到多张幻灯片）
- 直接标签（不是图例）
- 通过颜色和大小强调
- 复杂数据的逐步披露

**可视化最佳实践**：
- **条形图**：比较离散类别
- **折线图**：趋势和轨迹
- **散点图**：关系和相关性
- **热图**：矩阵数据和模式
- **网络图**：关系和连接

**常见错误**：
- 字体太小（小于18pt）
- 一张幻灯片上太多面板
- 复杂的图例
- 对比度不足
- 杂乱的布局

### 4. 特定谈话指导

不同的演示场景需要不同的方法。有关每种类型的全面指导，请参阅 `references/talk_types_guide.md`。

**会议演讲**（10-20分钟）：
- 结构：简短介绍→最小化方法→关键结果→快速结论
- 重点：1-2个主要发现
- 风格：吸引人、节奏快、令人难忘
- 目标：激发兴趣，建立联系，获得邀请

**学术研讨会**（45-60分钟）：
- 结构：全面覆盖，详细方法
- 重点：多个发现，分析的深度
- 风格：学术性，互动性，讨论导向
- 目标：展示专业知识，获得反馈，合作

**论文答辩**（45-60分钟）：
- 结构：完整论文概述，所有研究
- 重点：展示掌握和独立思考
- 风格：正式，全面，准备好接受质询
- 目标：通过考试，辩护研究决策

**项目提案**（10-20分钟）：
- 结构：问题→重要性→方法→可行性→影响
- 重点：创新，初步数据，团队资质
- 风格：有说服力，专注于结果和影响
- 目标：获得资金，展示可行性

**期刊俱乐部**（20-45分钟）：
- 结构：背景→方法→结果→批判性分析
- 重点：理解和批判已发表的工作
- 风格：教育性，批判性，促进讨论
- 目标：学习，批判，讨论启示

### 6. 视觉审查和迭代

通过视觉检查实施迭代改进。有关完整工作流程，请参阅 `references/visual_review_workflow.md`。

**视觉验证工作流程**：

**步骤1：生成PDF**（如果尚未为PDF）
- PowerPoint：导出为PDF
- Beamer：编译LaTeX源代码

**步骤2：转换为图像**
```bash
# 使用pdf_to_images脚本
python scripts/pdf_to_images.py presentation.pdf review/slide --dpi 150

# 或使用pptx技能的缩略图工具
python ../document-skills/pptx/scripts/thumbnail.py presentation.pptx review/thumb
```

**步骤3：系统检查**

检查每张幻灯片：
- **文字溢出**：文字被裁剪在边缘
- **元素重叠**：文字与图像或其他文字重叠
- **字体大小**：文字太小（小于18pt）
- **对比度**：文字和背景之间对比度不足
- **布局问题**：错位，间距差
- **视觉质量**：像素化图像，渲染质量差

**步骤4：记录问题**

创建问题日志：
```
幻灯片编号 | 问题类型 | 描述 | 优先级
----------|----------|------|-------
3        | 文字溢出 | 要点4超出框外 | 高
7        | 重叠 | 图像与标题重叠 | 高
12       | 字体大小 | 轴标签太小 | 中
```

**步骤5：应用修复**

修改源文件：
- PowerPoint：编辑文本框，调整元素大小
- Beamer：调整LaTeX代码，重新编译

**步骤6：重新验证**

重复步骤1-5，直到没有关键问题为止。

**停止标准**：
- 没有文字溢出
- 没有不适当的重叠
- 所有文字可读（≥18pt等价）
- 对比度充足（≥4.5:1）
- 专业外观

## 演示文稿开发工作流程

### 阶段1：规划（创建幻灯片之前）

**定义场景**：
1. 谈话类型是什么？（会议、研讨会、答辩等）
2. 时长是多少？（分钟数）
3. 观众是谁？（专家、一般、混合）
4. 场地是什么？（房间大小、A/V设置、线上/线下）
5. 谈话后会发生什么？（问答、讨论、社交）

**研究和文献综述**（使用research-lookup技能）：
1. **搜索背景文献**：找到5-10篇关键论文，建立背景
2. **识别知识差距**：使用research-lookup找到未知领域
3. **查找比较研究**：找到具有类似方法或结果的文章
4. **收集支持性引用**：收集支持你解释的论文
5. **构建参考文献列表**：创建.bib文件或引用列表用于幻灯片
6. **记录关键发现以引用**：记录要引用的具体结果

**开发内容大纲**：
1. 确定核心信息1-3个
2. 选择要展示的关键发现
3. 选择关键图表（通常15分钟谈话3-6个）
4. 规划具有适当引用的叙事弧
5. 按部分分配时间

**15分钟谈话的示例大纲**：
```
1. 标题（30秒）
2. 钩子：引人入胜的问题（60秒）[通过research-lookup引用1-2篇论文]
3. 背景（90秒）[引用3-4篇关键论文建立背景]
4. 研究问题（45秒）[引用显示差距的论文]
5. 方法概述（2分钟）
6-8. 主要结果1（3分钟，3张幻灯片）
9-10. 主要结果2（2分钟，2张幻灯片）
11-12. 结果3或验证（2分钟，2张幻灯片）
13-14. 讨论和启示（2分钟）[与2-3篇先前研究比较]
15. 结论（45秒）
16. 致谢（15秒）

注意：在创建幻灯片之前，使用research-lookup找到背景（幻灯片2-4）和讨论（幻灯片13-14）的论文。
```

### 阶段2：设计和创建

**选择实现方法**：

**选项A：PowerPoint（通过PPTX技能）**
1. 阅读 `assets/powerpoint_design_guide.md`
2. 阅读 `document-skills/pptx/SKILL.md`
3. 选择方法（程序化或基于模板）
4. 创建具有一致设计的母版幻灯片
5. 按大纲构建演示文稿

**选项B：LaTeX Beamer**
1. 阅读 `references/beamer_guide.md`
2. 从 `assets/` 选择合适的模板
3. 自定义主题和颜色
4. 用LaTeX编写内容
5. 编译为PDF

**设计考虑**（使其具有视觉吸引力）：
- **选择现代配色方案**：匹配你的主题（生物技术=鲜艳，物理学=简洁，健康=温暖）
  - 使用pptx技能的配色方案示例（蓝绿、鲜红、深紫和祖母绿等）
  - 不是默认的蓝/灰主题
  - 3-5种颜色，高对比度
- **选择干净字体**：无衬线，大尺寸（24pt+ 正文）
- **规划视觉元素**：每张幻灯片需要哪些图像、图表、图标？
- **创建多样化布局**：混合全图、两列、文字叠加（不只是要点）
- **设计部分分隔符**：具有引人注目图形的视觉分隔符
- **规划动画/构建**：控制复杂幻灯片的信息流
- **增加视觉兴趣**：背景图像、色块、形状、图标

### 阶段3：内容开发

**填充幻灯片**（视觉优先策略）：
1. **先使用视觉元素**：规划每张关键要点的图表、图像、图表、图标
2. **广泛使用research-lookup**：找到8-15篇论文以获取适当引用
3. **先添加视觉骨干**：添加所有图表、图表、图像、图表
4. **添加最少文字作为支持**：要点补充视觉元素，而不是取代它们
5. **设计部分分隔符**：使用图像或图形的视觉分隔符（不只是文字）
6. **美化标题/结论**：使其具有视觉冲击力，包括联系信息
7. **添加过渡/构建**：控制信息流

**视觉内容要求**（制作引人入胜的幻灯片）：
- **图片**：使用高质量的照片、插图、概念性图形
- **图标**：概念的可视化表现（非装饰性）
- **图表**：流程图、示意图、流程图
- **图形**：简化的研究图形，标签大（18-24pt）
- **图表**：清晰的数据可视化，信息明确
- **图形**：视觉隐喻、概念性插图
- **色块**：使用彩色形状进行视觉化内容组织
- 目标：每张幻灯片至少1-2个强视觉元素

**科学内容**（基于研究）：
- **引用**：使用研究查找广泛查找相关论文
  - 引言：引用3-5篇论文建立背景和差距
  - 背景：用图表展示关键前期工作（非仅引用）
  - 讨论：引用3-5篇论文与你的结果进行比较
  - 使用作者-年份格式（Smith等人，2023年）提高可读性
  - 引用建立可信度和科学严谨性
- **图形**：从论文简化，标签大（最小18-24pt）
- **公式**：大而清晰，解释每个术语（谨慎使用）
- **表格**：最少，突出关键比较（非数据堆砌）
- **代码/算法**：使用语法高亮，保持简短

**文本指南**（少即是多）：
- 项目符号，绝不使用段落
- 每张幻灯片3-4个项目符号（仅当必要时最多6个）
- 每个项目符号4-6个词（6×6规则更短）
- 关键术语加粗
- 文本是辅助角色，视觉是主角
- 使用构建控制节奏

## 常见陷阱避免

### 内容错误

**枯燥乏味的演示**（关键要避免）：
- 问题：文本密集的幻灯片，没有视觉兴趣，缺少研究背景
- 迹象：所有项目符号，无图片，默认模板，无引用
- 解决方案：
  - 使用研究查找找到8-15篇论文以建立可信背景
  - 每张幻灯片都添加高质量视觉元素（图形、照片、图表、图标）
  - 选择反映你主题的现代调色板
  - 变幻幻灯片布局（不是所有项目符号列表）
  - 用视觉讲故事，文本要少

**内容过多**：
- 问题：试图包含论文中的所有内容
- 解决方案：对于短演讲，专注于1-2个关键发现，用视觉展示

**文本过多**：
- 问题：幻灯片上的完整段落，密集的项目符号，逐字阅读
- 解决方案：每张幻灯片3-4个项目符号，每个4-6个词，让视觉传达信息

**缺少研究背景**：
- 问题：无引用，没有支持的主张，定位不清
- 解决方案：使用研究查找找到论文，引言中引用3-5篇，讨论中引用3-5篇

**叙事差**：
- 问题：跳跃主题，没有清晰故事，没有流程
- 解决方案：遵循故事线，使用视觉过渡，保持线索

**结果过快**：
- 问题：简化的方法，简化的结果，长的讨论
- 解决方案：将40-50%的时间用于结果，用视觉展示数据

### 设计错误

**通用默认外观**：
- 问题：使用未定制的默认PowerPoint/Beamer主题，看起来过时
- 解决方案：选择现代调色板，自定义字体/布局，增加视觉个性

**文本密集，视觉贫乏**：
- 问题：所有项目符号幻灯片，无图片或图形，看起来很无聊
- 解决方案：每张幻灯片都添加图形、照片、图表、图标，使其具有视觉吸引力

**字体太小**：
- 问题：正文小于18pt，从远处看不可读，看起来不专业
- 解决方案：正文24-28pt（不仅仅是18pt最小值），标题36-44pt

**对比度低**：
- 问题：浅色背景上的浅色文本，可见性差，难以阅读
- 解决方案：高对比度（7:1更佳，不仅仅是4.5:1最小值），使用对比度检查器测试

**幻灯片杂乱**：
- 问题：太多元素，没有空白，令人不知所措
- 解决方案：每张幻灯片一个想法，40-50%的空白，充足的间距

**格式不一致**：
- 问题：幻灯片之间不同的字体、颜色、布局，看起来很业余
- 解决方案：使用主幻灯片，保持设计系统，专业一致性

**缺少视觉层次**：
- 问题：所有大小和颜色相同，没有强调，焦点不明确
- 解决方案：大小差异（标题大，正文中等），用颜色强调，清晰的焦点

### 时间错误

**不练习**：
- 问题：第一次运行就是在演示中
- 解决方案：至少用计时器练习3-5次

**没有时间检查点**：
- 问题：直到太晚才意识到落后
- 解决方案：设置3-4个检查点，全程监控

**超时**：
- 问题：非常不专业，会占用问答时间
- 解决方案：精确练习时间，准备Plan B（跳过幻灯片）

**跳过结论**：
- 问题：时间不够，匆忙结束或跳过结尾
- 解决方案：绝不跳过结论，删除早期内容

## 快速入门指南

### 对于15分钟会议演讲（PDF工作流 - 推荐使用）

1. **研究和计划**（45分钟）：
   - **使用研究查找**找到8-12篇相关论文用于引用
   - 建立参考文献列表（背景、比较研究）
   - 概述内容（引言→方法→2-3个关键结果→结论）
   - **为每张幻灯片创建详细计划**（标题、关键点、视觉元素）
   - 目标15-18张幻灯片

2. **使用Nano Banana Pro生成幻灯片**（1-2小时）：

   **重要提示**：使用一致的格式，附加之前的幻灯片，并包含引用！

   ```bash
   # 标题幻灯片（建立风格 - 默认作者：K-Dense）
   python scripts/generate_slide_image.py "标题幻灯片：'你的研究标题'。会议名称，K-Dense。格式目标：[你的调色板]，简约专业设计，无装饰元素，干净商务。" -o slides/01_title.png
   
   # 引言幻灯片带引用（附加之前以保持一致性）
   python scripts/generate_slide_image.py "幻灯片标题'为什么这很重要'。三个关键点，带简单图标。引用：在底部包含：[Smith等人，2023年；Jones等人，2024年]。格式目标：完全匹配附加幻灯片风格。" -o slides/02_intro.png --attach slides/01_title.png
   
   # 继续为每张幻灯片生成（始终附加之前，在相关位置包含引用）
   python scripts/generate_slide_image.py "幻灯片标题'方法'。关键方法点。引用：[基于Chen等人，2022年]。格式目标：完全匹配附加幻灯片风格。" -o slides/03_methods.png --attach slides/02_intro.png
   
   # 合并为PDF
   python scripts/slides_to_pdf.py slides/*.png -o presentation.pdf
   ```

3. **审查和迭代**（30分钟）：
   - 打开PDF并审查每张幻灯片
   - 重新生成需要改进的幻灯片
   - 重新合并为PDF

4. **练习**（2-3小时）：
   - 带计时器练习3-5次
   - 目标13-14分钟（留出缓冲时间）
   - 录制自己，观看回放
   - **准备问题**（使用研究查找来预测）

5. **最终确定**（30分钟）：
   - 如有必要，生成备用/附录幻灯片
   - 保存多个副本
   - 在演示电脑上测试

总时间：~5-6小时高质量AI生成演示

## 总结：关键原则

1. **视觉优先设计**：每张幻灯片都需要强视觉元素（图形、图片、图表） - 避免纯文本幻灯片
2. **基于研究**：使用研究查找找到8-15篇论文，引言中引用3-5篇，讨论中引用3-5篇
3. **现代美学**：选择与主题匹配的现代调色板，不要使用默认主题
4. **极简文本**：每张幻灯片3-4个项目符号，每个4-6个词（24-28pt字体），让视觉讲故事
5. **结构**：遵循故事线，将40-50%的时间用于结果
6. **高对比度**：7:1更佳，专业外观
7. **多样化布局**：混合全图形、两列、视觉叠加（不是所有项目符号）
8. **时间**：练习3-5次，~1张幻灯片/分钟，绝不跳过结论
9. **验证**：视觉审查工作流以捕获溢出和重叠
10. **空白**：幻灯片40-50%为空白，视觉呼吸空间

**记住**：
- **无聊=遗忘**：枯燥、文本密集的幻灯片无法传达你的科学
- **视觉+研究=影响**：结合引人入胜的视觉和研究背景
- **你是演讲，幻灯片是视觉支持**：它们应该增强，而不是取代你的演讲
