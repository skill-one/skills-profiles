# 用户体验研究员 & 设计师

面向用户中心的研究和体验设计的综合工具包。

## 核心功能
- 基于数据的人物角色生成
- 客户旅程图绘制
- 可用性测试框架
- 研究综合与洞察
- 设计验证方法

## 关键脚本

### persona_generator.py
根据用户数据和访谈创建研究支持的人物角色。

**使用方法**： `python scripts/persona_generator.py [json]`

**功能**：
- 分析用户行为模式
- 识别人物角色原型
- 提取心理特征
- 生成场景
- 提供设计启示
- 基于样本量进行置信度评分
