# 科研写作

## 概述

**这是深度研究和写作工具的核心技能**—结合AI驱动的深度研究与格式良好的书面输出。生成的每个文档都基于全面的文献检索和通过研究查询技能验证的引用。

科研写作是一个以精确和清晰的方式传达研究的过程。使用IMRAD结构、引用（APA/AMA/Vancouver）、图表/表格和报告指南（CONSORT/STROBE/PRISMA）撰写手稿。将此技能应用于研究论文和期刊投稿。

**关键原则：始终使用完整段落和流畅的散文进行写作。绝不要在最终手稿中提交项目符号列表。** 使用两阶段流程：首先使用研究查询创建包含要点的小节提纲，然后将这些提纲转换为完整段落。

## 使用此技能的时机

当出现以下情况时，应使用此技能：
- 写作或修改科学手稿的任何部分（摘要、引言、方法、结果、讨论）
- 使用IMRAD或其他标准格式构建研究论文
- 以特定样式（APA、AMA、Vancouver、Chicago、IEEE）格式化引用和参考文献
- 创建、格式化或改进图表、表格和数据可视化
- 应用特定研究的报告指南（CONSORT用于试验、STROBE用于观察性研究、PRISMA用于综述）
- 撰写符合期刊要求的摘要（结构化或非结构化）
- 准备提交给特定期刊的手稿
- 提高写作清晰度、简洁性和精确性
- 确保正确使用特定领域的术语和命名法
- 回应审稿人意见并修改手稿

## 核心功能

### 1. 手稿结构和组织

**IMRAD格式**：指导论文通过在大多数科学学科中使用的标准引言、方法、结果和讨论结构。这包括：
- **引言**：建立研究背景，确定差距，陈述目标
- **方法**：详细说明研究设计、人群、程序和分析方法
- **结果**：客观地呈现结果，不做解释
- **讨论**：解释结果，承认局限性，提出未来方向

有关IMRAD结构的详细指南，请参阅`references/imrad_structure.md`。

**替代结构**：支持特定学科的格式，包括：
- 综述文章（叙述性、系统性、范围性）
- 病例报告和病例系列
- 元分析和合并分析
- 理论/建模论文
- 方法论文和方案

### 2. 针对性写作指导

**摘要撰写**：撰写简洁、独立的摘要（100-250字），捕捉论文的目的、方法、结果和结论。支持结构化摘要（带标签部分）和非结构化单段格式。

**引言发展**：构建引人入胜的引言，包括：
- 建立研究问题的重要性
- 系统地回顾相关文献
- 确定知识差距或争议
- 陈述明确的研究问题或假设
- 解释研究的创新性和重要性

**方法记录**：确保可重复性，包括：
- 详细描述参与者/样本
- 清晰的程序记录
- 统计方法及其合理性
- 设备和材料规格
- 道德批准和知情同意声明

**结果展示**：以以下方式呈现结果：
- 从主要到次要结果的逻辑流程
- 与图表和表格的整合
- 统计显著性及效应量
- 客观报告，不做解释

**讨论构建**：通过以下方式综合结果：
- 将结果与研究问题联系起来
- 与现有文献进行比较
- 坦诚承认局限性
- 提出机制解释
- 建议实际意义和未来研究

### 3. 引用和参考文献管理

跨学科正确应用引用样式。有关全面的样式指南，请参阅`references/citation_styles.md`。

**主要引用样式：**
- **AMA（美国医学协会）**：上标编号引用，在医学中常见
- **Vancouver**：方括号中的编号引用，生物医学标准
- **APA（美国心理学会）**：文内作者-日期引用，社会科学中常见
- **Chicago**：注释-参考文献或作者-日期，人文和科学
- **IEEE**：方括号中的编号，工程和计算机科学

**最佳实践：**
- 尽可能引用原始来源
- 包含最新文献（活跃领域最近5-10年）
- 在引言和讨论中平衡引用分布
- 核对所有引用与原始来源
- 使用参考文献管理软件（Zotero、Mendeley、EndNote）

### 4. 图表和表格

创建有效的数据可视化，增强理解。有关详细最佳实践，请参阅`references/figures_tables.md`。

**何时使用表格与图表：**
- **表格**：精确的数值数据、复杂的数据集、需要精确值的多个变量
- **图表**：趋势、模式、关系、最好通过视觉理解的比较

**设计原则：**
- 使每个表格/图表通过完整的标题自我解释
- 在所有显示项中使用一致的格式和术语
- 标注所有轴、列和行，包括单位
- 包括样本量（n）和统计注释
- 遵循“每1000字一个表格/图表”的指南
- 避免在文本、表格和图表之间重复信息

**常见图表类型：**
- 条形图：比较离散类别
- 折线图：显示随时间变化的趋势
- 散点图：显示相关性
- 箱线图：显示分布和异常值
- 热图：可视化矩阵和模式

### 5. 按研究类型划分的报告指南

通过遵循既定的报告标准，确保完整性和透明度。有关全面的指南详细信息，请参阅`references/reporting_guidelines.md`。

**关键指南：**
- **CONSORT**：随机对照试验
- **STROBE**：观察性研究（队列、病例对照、横断面）
- **PRISMA**：系统评价和荟萃分析
- **STARD**：诊断准确性研究
- **TRIPOD**：预测模型研究
- **ARRIVE**：动物研究
- **CARE**：病例报告
- **SQUIRE**：质量改进研究
- **SPIRIT**：临床试验方案
- **CHEERS**：经济评价

每个指南都提供清单，确保报告所有关键方法学要素。

### 6. 写作原则和风格

应用基本的科研写作原则。有关详细指南，请参阅`references/writing_principles.md`。

**清晰度**：
- 使用精确、无歧义的语言
- 在首次使用时定义技术术语和缩写
- 保持段落内和段落间的逻辑流程
- 在适当的时候使用主动语态以增强清晰度

**简洁性**：
- 消除冗余的词语和短语
- 倾向于较短的句子（平均15-20个词）
- 移除不必要的限定词
- 严格尊重字数限制

**准确性**：
- 报告精确值，并使用适当的精度
- 在整个文本中保持术语一致性
- 区分观察结果和解释
- 适当承认不确定性

**客观性**：
- 无偏见地呈现结果
- 避免夸大结果或意义
- 承认矛盾的证据
- 保持专业、中立的语气

### 7. 写作过程：从提纲到完整段落

**关键：始终使用完整段落，绝不要在科学论文中提交项目符号列表。**

科学论文必须使用完整的、流畅的散文撰写。使用此两阶段方法进行有效写作：

**阶段1：创建包含要点的小节提纲**

开始新部分时：
1. 使用研究查询技能收集相关文献和数据
2. 创建结构化提纲，用项目符号标记：
   - 要呈现的主要论点或发现
   - 要引用的关键研究
   - 要包含的数据点和统计数据
   - 逻辑流程和组织
3. 这些项目符号作为框架——它们不是最终手稿

**示例提纲（引言部分）：**
```
- 背景：AI在药物发现中的应用日益增多
  * 引用最近的综述（Smith 2023，Jones 2024）
  * 传统方法缓慢且昂贵
- 差距：在罕见疾病中的应用有限
  * 仅有的2项先前研究（Lee 2022，Chen 2023）
  * 小数据集仍然是一个挑战
- 我们的方法：从常见疾病迁移学习
  * 新颖架构结合X和Y
- 研究目标：在3个罕见疾病数据集上验证
```

**阶段2：将要点转换为完整段落**

提纲完成后，将每个项目符号扩展为适当的散文：

1. **将项目符号转换为包含主语、动词和宾语的完整句子**
2. **添加过渡词**，在句子和想法之间（然而，此外，相反，随后）
3. **自然地整合引用**，而不是作为列表
4. **添加上下文和解释**，项目符号中省略的内容
5. **确保每个段落内的逻辑流程**
6. **变化句子结构**，以保持读者参与度

**示例转换到散文：**

```
人工智能方法在过去十年中在药物发现管道中获得了显著进展
（Smith，2023；Jones，2024）。虽然这些计算方法显示出加速识别治疗候选物的潜力，
但传统的实验方法仍然缓慢且资源密集，通常需要数年的实验室工作和大量的资金投入。
然而，AI在罕见疾病中的应用有限，只有两项先前研究展示了概念验证结果
（Lee，2022；Chen，2023）。主要障碍是罕见疾病训练数据的缺乏。

为了应对这一挑战，我们开发了一种迁移学习方法，利用从特征明确的常见疾病中获取的知识
来预测罕见疾病的治疗靶点。我们的新颖神经网络架构结合了用于分子特征提取的卷积层
和用于蛋白质-配体相互作用建模的注意力机制。本研究的目的是在三个独立罕见疾病数据集上验证我们的方法，
评估结果的预测准确性和生物学可解释性。
```

**提纲与最终文本之间的关键区别：**

| 提纲（规划阶段） | 最终手稿 |
|------------------|----------|
| 项目符号和片段 | 完整的句子和段落 |
| 电报式笔记 | 完整的解释和上下文 |
| 引用列表 | 整合到散文中的引用 |
| 简要想法 | 发展的论点和过渡 |
| 仅限您查看 | 用于发表和同行评审 |

**要避免的常见错误：**

- ❌ **绝不**在最终手稿中留下项目符号
- ❌ **绝不**提交列表，而应该使用段落
- ❌ **不要**在结果或讨论部分使用编号或项目符号列表（特殊情况除外，如研究假设或纳入/排除标准）
- ❌ **不要**写句子片段或不完整的想法
- ✅ **要**在方法中偶尔使用列表（例如，纳入/排除标准、材料列表）
- ✅ **要**确保每个部分都作为连贯的散文流动
- ✅ **要**朗读段落以检查自然流动

**何时列表是可接受的（有限情况）：**

列表可能仅在特定上下文中出现在科学论文中：
- **方法**：纳入/排除标准、材料和试剂、参与者特征
- **补充材料**：扩展方案、设备列表、详细参数
- **绝不**在：摘要、引言、结果、讨论、结论

**与研究查询的集成：**

研究查询技能对于阶段1（创建提纲）至关重要：
1. 使用研究查询搜索相关论文
2. 提取关键发现、方法和数据
3. 将发现组织为提纲中的项目符号
4. 然后在阶段2将提纲转换为完整段落

这种两阶段流程可确保您：
- 系统地收集和组织信息
- 在写作前创建逻辑结构
- 生成经过润色的、适合发表的散文
- 保持对叙事流程的关注

### 8. 期刊特定格式

调整手稿以满足期刊要求：
- 遵循作者指南，包括结构、长度和格式
- 应用期刊特定的引用样式
- 满足图表/表格规范（分辨率、文件格式、尺寸）
- 包括所需声明（资金、利益冲突、数据可用性、伦理批准）
- 遵守每个部分的字数限制
- 如果提供模板，则按照模板要求格式化

### 9. 特定领域的语言和术语

调整语言、术语和惯例，以匹配特定的科学学科。每个领域都有既定的词汇、首选短语和特定领域的惯例，这些惯例表明专业知识并确保目标受众的清晰度。

**识别特定领域的语言惯例：**
- 回顾目标期刊中近期高影响力论文中使用的术语
- 注意特定领域的缩写、单位和符号系统
- 确定首选术语（例如，“参与者”与“受试者”、“化合物”与“药物”、“标本”与“样本”）
- 观察通常如何描述方法、生物体或技术

**生物医学和临床科学：**
- 使用精确的解剖和临床术语（例如，“心肌梗死”而不是“心脏病发作”在正式写作中）
- 遵循标准疾病命名法（ICD、DSM、SNOMED-CT）
- 首先使用通用名报告药物名称，如有必要，在括号中提供品牌名称
- 临床研究中使用“患者”，社区研究中使用“参与者”
- 遵循人类基因组变异学会（HGVS）命名法报告遗传变异
- 使用标准单位报告实验室值（大多数国际期刊使用SI单位）

**分子生物学与遗传学：**
- 基因符号使用斜体（例如，*TP53*），蛋白质使用常规字体（例如，p53）
- 遵循物种特异性基因命名法（人类用大写：*BRCA1*；小鼠用句子大小写：*Brca1*）
- 首次提及时完整写出生物体名称，然后使用公认缩写（例如，*大肠杆菌*，然后*E. coli*）
- 使用标准遗传符号（例如，+/+，+/-，-/- 表示基因型）
- 使用已建立的分子技术术语（例如，“定量PCR”或“qPCR”，而不是“实时PCR”）

**化学与药物科学：**
- 遵循IUPAC命名法对化学化合物进行命名
- 新化合物使用系统名称，著名物质使用常用名称
- 使用标准符号指定化学结构（例如，SMILES，InChI用于数据库）
- 报告浓度时使用适当的单位（mM，μM，nM，或% w/v，v/v）
- 使用公认的化学反应命名法描述合成路线
- 使用“生物利用度”，“药代动力学”，“IC50”等术语，并与领域定义保持一致

**生态学与环境科学：**
- 物种使用双名法（斜体：*Homo sapiens*）
- 在相关情况下，首次提及时指定分类学权威
- 使用标准化的栖息地和生态系统分类
- 使用一致的生态指标术语（例如，“物种丰富度”，“香农多样性指数”）
- 使用现场标准术语描述采样方法（例如，“样线”，“样方”，“标记重捕”）

**物理学与工程学：**
- 除非领域惯例另有规定，否则始终遵循SI单位
- 使用标准符号表示物理量（标量与矢量，张量）
- 使用已建立的术语描述现象（例如，“量子纠缠”，“层流”）
- 在相关情况下指定设备型号和制造商
- 使用与领域标准一致数学符号（例如，ℏ表示约化普朗克常数）

**神经科学：**
- 使用标准大脑区域命名法（例如，参考Allen脑图谱等图谱）
- 使用已建立的标准立体定位系统指定大脑区域坐标
- 遵循神经术语惯例（例如，正式写作中用“动作电位”而不是“尖峰”）
- 根据测量方法适当使用“神经活动”，“神经元放电”，“脑激活”
- 使用正确的具体性描述记录技术（例如，“全细胞电压钳”，“细胞外记录”）

**社会科学与行为科学：**
- 在适当情况下使用以人为本的语言（例如，“患有精神分裂症的人”而不是“精神分裂症患者”）
- 使用标准心理结构和使用经过验证的评估名称
- 遵循APA指南以减少语言中的偏见
- 使用已建立的术语指定理论框架
- 对于人类研究，使用“参与者”而不是“受试者”

**一般原则：**

**匹配受众专业知识：**
- 对于专业期刊：自由使用领域特定术语，仅定义高度专业或新颖的术语
- 对于广泛影响期刊（例如，*Nature*，*Science*）：定义更多技术术语，为专业概念提供背景
- 对于跨学科受众：在精确性和可访问性之间取得平衡，首次使用时定义术语

**策略性地定义技术术语：**
- 首次使用时定义缩写：“信使RNA (mRNA)”
- 为更广泛的受众撰写时，提供专业技术的简要解释
- 避免对目标受众熟知的术语过度定义（表明对该领域不熟悉）
- 如果不可避免地出现大量专业术语，则创建词汇表

**保持一致性：**
- 对同一概念使用相同术语（不要在“药物”，“药物”和“药物”之间交替）
- 遵循一致的缩写系统（在首次定义后决定使用“PCR”或“聚合酶链反应”）
- 在整个过程中应用相同的命名法系统（尤其是对于基因，物种，化学物质）

**避免领域混合错误：**
- 不要使用临床术语进行基础科学（例如，不要称小鼠为“患者”）
- 避免使用非正式或过于笼统的术语代替精确的领域术语
- 不要从相邻领域引入术语，除非确保正确使用

**验证术语使用：**
- 查阅领域特定风格指南和命名法资源
- 检查目标期刊近期论文中术语的使用方式
- 使用特定领域数据库和本体（例如，Gene Ontology，MeSH术语）
- 不确定时，引用建立术语的关键参考

### 10. 常见错误避免

**主要拒稿原因：**
1. 不适当，不完整或描述不足的统计数据
2. 过度解释结果或缺乏支持的结论
3. 描述不佳的方法影响可重复性
4. 样本量小，有偏差或不适当
5. 写作质量差或难以理解的文本
6. 文献综述或背景不足
7. 图表不清楚或设计不佳
8. 未遵循报告指南

**写作质量问题：**
- 不当的时态混合（方法/结果用过去时，既定事实用现在时）
- 过多的行话或未定义的缩写
- 段落断开会破坏逻辑流程
- 段落之间缺少过渡
- 不一致的符号或术语

## 手稿开发工作流程

**阶段1：规划**
1. 确定目标期刊并查阅审稿人指南
2. 确定适用的报告指南（CONSORT，STROBE等）
3. 概述手稿结构（通常为IMRAD）
4. 规划图表作为论文的骨干

**阶段2：起草**（对每个部分使用两阶段写作过程）
1. 从图表和表格开始（核心数据故事）
2. 对于以下每个部分，遵循两阶段过程：
   - **第一**：使用研究查找创建带有项目符号的提纲
   - **第二**：将项目符号转换为带有流畅散文的完整段落
3. 撰写方法（通常最容易首先起草）
4. 起草结果（客观描述图表/表格）
5. 撰写讨论（解释研究结果）
6. 撰写引言（设定研究问题）
7. 撰写摘要（综合完整故事）
8. 创建标题（简洁且描述性强）

**记住**：项目符号仅用于规划——最终手稿必须是完整的段落。

**阶段3：修改**
1. 检查逻辑流程和“红线”贯穿始终
2. 验证术语和符号的一致性
3. 确保图表/表格具有自解释性
4. 确认遵循报告指南
5. 验证所有引用准确且格式正确
6. 检查每个部分字数
7. 校对语法，拼写和清晰度

**阶段4：最终准备**
1. 根据期刊要求格式化
2. 准备补充材料
3. 撰写封面信突出重要性
4. 完成提交清单
5. 收集所有必需的声明和表格
