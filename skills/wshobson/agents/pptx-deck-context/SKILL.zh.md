# PPTX文件制作背景

在协调或PPTX对象创作之前，需准备该文件。这项技能拥有业务叙述、来源谱系和设计锁定权。

## 决策顺序

1. 确认受众、决策、幻灯片数量、语言、来源和品牌要求。
2. 使用用户选择的叙述框架。若未指定，则提供`mckinsey`、`scqa`、`pyramid`、`mece`、`action-title`、`assertion-evidence`、`exec-summary-first`或`custom`；不得默认选择。
3. 为每个指标、引用、图表数值和事实声明分配稳定的来源ID，并规划`source_ref`。
4. 选择有文档记录的设计方向。优先使用用户品牌指南，其次参考只读参考文件证据，最后从`references/design-profiles.md`中选用可复用的配置文件。
5. 在制作幻灯片前，将框架、假设、来源清单、调色板、字体、间距和签名元素记录在`summary`中。

## 规则

- 一张幻灯片应传达一个信息，在框架要求时使用行动式标题。
- 将设计参考视为设计证据，而非内容或资产来源。
- 未经记录的许可证据，不得复制外部字体、图片、图标或标志。
- 将设计信号转化为明确的填充、字体、间距和边界框；不得依赖自动布局引擎。
- 保持长来源材料简洁。请求摘要或与决策相关的节选，而非将文件规格转为文档转储。

有关可复用配置文件的指导，请参阅`references/design-profiles.md`。
