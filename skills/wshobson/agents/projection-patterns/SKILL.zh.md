# 投影模式

构建事件溯源系统中的投影和读取模型的全面指南。

## 使用此技能的场景

- 构建 CQRS 读取模型
- 从事件创建物化视图
- 优化查询性能
- 实现实时仪表板
- 从事件构建搜索索引
- 跨流聚合数据

## 核心概念

### 1. 投影架构

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│ 事件存储   │────►│ 投影器     │────►│ 读取模型  │
│             │     │             │     │ (数据库)  │
│ ┌─────────┐ │     │ ┌─────────┐ │     │ ┌─────────┐ │
│ │ 事件   │ │     │ │ 处理器   │ │     │ │ 表格   │ │
│ └─────────┘ │     │ │ 逻辑   │ │     │ │ 视图   │ │
│             │     │ └─────────┘ │     │ │ 缓存   │ │
└─────────────┘     └─────────────┘     └─────────────┘
```

### 2. 投影类型

| 类型           | 描述                 | 用例               |
| -------------- | --------------------------- | ---------------------- |
| **实时**       | 从订阅实时获取       | 当前状态查询        |
| **补齐**    | 处理历史事件         | 重建读取模型        |
| **持久**       | 存储检查点           | 重启后恢复         |
| **内联**     | 与写入使用相同事务   | 强一致性           |

## 最佳实践

### 应该做

- **使投影幂等** - 安全重放
- **使用事务** - 用于多表更新
- **存储检查点** - 失败后恢复
- **监控延迟** - 报警投影延迟
- **计划重建** - 设计为可重建

### 不应该做

- **不要耦合投影** - 每个投影独立
- **不要忽略错误处理** - 失败时记录和报警
- **不要忽略顺序** - 事件必须按顺序处理
- **不要过度规范化** - 为查询模式反规范化
