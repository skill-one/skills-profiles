# /em:stress-test — 商业假设压力测试

**命令：** `/em:stress-test <假设>`

对任何商业假设进行压力测试，在市场发现之前打破它。收入预测。市场规模。竞争优势壁垒。招聘速度。客户留存。

---

## 为什么大多数假设是错误的

创始人天生是乐观主义者。这是一种优势——你需要乐观才能从零开始创业。但当商业模式中的假设被与你创业时相同的乐观情绪所膨胀时，它就变成了劣势。

**最危险的假设是所有人都同意的假设。**

当整个团队都相信5000万美元的市场是真实的，当每一次投资者沟通都进展顺利，你便假设融资轮次将关闭，当你的模型显示到12月将有2000万美元的年收入，而没有人质疑时——那时你最容易受到暴露。

压力测试不是悲观主义。它是校准。

## 压力测试方法论

### 第1步：隔离假设

明确陈述它。不是“我们的市场很大”，而是“在德国中小企业中，B2B支出管理软件的总可寻址市场为23亿欧元。”

假设越具体，越容易测试。模糊的假设是无法证伪的——因此是无用的。

**常见假设类型：**
- **市场规模** — TAM、SAM、SOM；增长率；客户细分
- **客户行为** — 付费意愿、流失率、扩张、推荐
- **收入模式** — 转化率、交易规模、销售周期、CAC
- **竞争地位** — 壁垒持久性、竞争对手响应速度、转换成本
- **执行** — 团队速度、招聘时间线、产品时间线、运营扩展
- **宏观** — 监管环境、经济状况、技术可用性

### 第2步：寻找反证

对每一个假设，主动寻找证明它是错误的证据。

提问：
- 谁尝试过这个并且失败了？
- 哪些数据与这个假设相矛盾？
- 熊市情况是怎样的？
- 如果一个聪明的怀疑者看着这个，他们会指出什么？
- 这种假设的基础概率是多少？

**反证来源：**
- 在相邻市场失败的同类公司
- 来自类似企业的客户流失数据
- 类似预测的历史准确性
- 具有矛盾数据的行业报告
- 尝试过这个的竞争对手发现了什么

目标不是找到停止的理由——而是揭示你不知道的事情。

### 第3步：模拟下行风险

大多数计划模拟基准情况和上行情况。压力测试意味着明确模拟下行情况。

**对于定量假设（收入、增长、转化率）：**

| 情景 | 假设值 | 概率 | 影响 |
|------|--------|------|------|
| 基准情况 | [原始值] | ? | |
| 熊市情况 | -30% | ? | |
| 压力情况 | -50% | ? | |
| 灾难性 | -80% | ? | |

每个级别的关键问题：**企业能否生存？计划是否有意义？**

**对于定性假设（壁垒、产品市场契合度、团队能力）：**

- 什么是最早表明这个假设是错误的信号？
- 你需要多长时间才能注意到？
- 在它破裂和被你发现之间会发生什么？

### 第4步：计算敏感性

一些假设比其他假设更重要。敏感性分析回答：**如果这一个假设发生变化，结果会变化多少？**

示例：
- 如果CAC翻倍，那会如何影响续航能力？
- 如果流失率从5%上升到10%，那会如何影响24个月内的NRR？
- 如果交易周期是6个月而不是3个月，那会如何影响第三季度的收入？

高敏感性 = 这个假设是一个关键杠杆。错误 = 大问题。

### 第5步：提出对冲措施

对于每一个高风险假设，都应该有一个对冲措施：

- **验证对冲** — 在下注之前测试它（试点、客户对话、小型实验）
- **应急对冲** — 如果它是错误的，B计划是什么？
- **早期预警对冲** — 什么领先指标会在太晚之前告诉你它正在破裂，以便你能够采取行动？

## 按假设类型进行的压力测试模式

### 收入预测

**常见失败：**
- 自下而上的模型假设100%的管道转化
- 没有考虑交易滑移、流失率、季节性
- 新渠道在规模测试之前假设会起作用

**压力问题：**
- 你实际的管道历史获胜率是多少？
- 如果你的前3笔交易滑移到下个季度，会发生什么？
- 如果你的新销售代表需要4个月而不是2个月才能上手，模型会是什么样子？
- 如果扩张收入没有实现，增长率是多少？

**测试：** 基于历史获胜率，而不是期望值，构建收入模型。

### 市场规模

**常见失败：**
- TAM从行业报告自上而下计算，而没有自下而上的验证
- 混淆总市场与服务市场
- 假设100%的SAM是可触及的

**压力问题：**
- 你ICP中的公司有多少家实际上是存在的，你能说出它们的名字吗？
- 你在1-3年的可服务可获取市场是多少？
- 你ICP中目前有多少比例的公司在为解决这个问题使用任何解决方案？
- “获胜”是什么样子，以及那需要多少市场份额？

**测试：** 构建目标账户列表。数一数。乘以ACV。那就是你的SAM。

### 竞争优势壁垒

**常见失败：**
- 壁垒是可以在6个月内建立的技术优势
- 尚未实现的网络效应
- 需要规模的数据优势，而你没有

**压力问题：**
- 如果一个资金充足的竞争对手在90天内复制了你的最佳功能，客户会做什么？
- 在尝试过替代方案的客户中，你的留存率是多少？
- 壁垒是今天真实的还是规模上的理论？
- 竞争对手达到功能对等需要花费多少成本？

**测试：** 询问流失客户他们为什么离开，以及竞争对手是否可以留住他们。

### 招聘计划

**常见失败：**
- 招聘时间假设标准招聘周期，而不是当前市场
- 没有模拟（3-6个月才能达到完全生产力）
- 关键招聘依赖：计划只有在特定人员被招聘到时才起作用

**压力问题：**
- 如果销售副总裁招聘需要5个月而不是2个月，会发生什么？
- 如果你只招聘了计划的70%的员工，执行情况会是什么样子？
- 如果他们明天离开，哪个单一的人会对计划造成最大损害？
- 如果招聘冻结，当前团队是否能够实现计划？

**测试：** 使用0净新招聘模拟计划。什么仍然起作用？

### 竞争对手反应

**常见失败：**
- 假设现有企业不会做出反应（如果你在获胜，他们会）
- 低估反应速度
- 没有模拟资源不对称性

**压力问题：**
- 如果市场领导者6个月内复制了你的产品，价格会如何变化？
- 如果竞争对手为攻击你的领域融资3000万美元，你会怎么做？
- 哪些客户与你的竞争对手有供应商关系？

## 压力测试输出

```
假设：[明确的陈述]
来源：[这个假设的来源——模型、投资者陈述、团队直觉]

反证
• [挑战这个假设的具体证据]
• [同类失败案例]
• [与假设相矛盾的数据点]

下行模型
• 熊市情况（-30%）：[对计划的影响]
• 压力情况（-50%）：[对计划的影响]
• 灾难性情况（-80%）：[对计划的影响——企业能否生存？]

敏感性
这个假设有[高/中/低]敏感性。
10%的变化 → [结果变化X]

对冲措施
• 验证：[如何在下注前测试这个]
• 应急：[如果它是错误的，B计划是什么]
• 早期预警：[要观察的领先指标——以及在什么阈值采取行动]
```
