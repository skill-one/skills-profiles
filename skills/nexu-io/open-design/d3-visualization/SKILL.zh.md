# d3-可视化

> 来自 @jiannanya 的精选。

## 功能

教会代理生成 D3 图表和交互式数据可视化。包含各种图表类型和技术的 D3.js 技能示例，使代理具备生成复杂、交互式可视化的专家级知识。适用于编辑式仪表板、报告、数据丰富的原型和解释性图形。

## 来源

- 上游：https://github.com/jiannanya/snow-d3/
- 类别：`图表`

## 使用方法

此目录项在 OpenDesign 中宣传该技能，以便代理在规划过程中发现它。若要运行完整上游工作流及其原始资源、脚本和参考文档，请将上游包安装到您的活跃代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/jiannanya/snow-d3/

# 将 snow-d3/ 文件夹克隆或复制到您工作区的 skills/ 目录
git clone https://github.com/jiannanya/snow-d3.git skills/snow-d3
```

然后通过名称（`d3-visualization`）或使用此技能 frontmatter 中列出的触发短语之一来请求代理调用该技能，例如：

> "为我销售数据创建一个可缩放的树状图"
> "构建一个类似示例 07 的力导向网络图，但用于我的数据集"
> "使用 D3 生成一个日历热力图"
