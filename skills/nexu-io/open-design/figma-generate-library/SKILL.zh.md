# figma-generate-library

> 从 Figma 的 MCP 服务器指南中精选。

## 功能

从一个代码库中构建或更新 Figma 中的专业级设计系统库。适用于保持 Figma 源码与已发布组件同步。

## 来源

- 上游：https://github.com/figma/skills
- 类别：`figma`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划时发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/figma/skills
```

然后请代理通过名称（`figma-generate-library`）或使用此技能 frontmatter 中列出的触发短语来调用此技能。
