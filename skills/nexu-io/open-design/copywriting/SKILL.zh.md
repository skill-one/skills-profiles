# 市场营销文案撰写

> 根据Corey Haines整理。

## 功能

为落地页、主页和广告撰写和重写营销文案。在产品发布期间，可作为文案主管的合作伙伴使用。

## 来源

- 上游：https://github.com/coreyhaines31/marketingskills
- 类别：`marketing-creative`

此目录条目在OpenDesign中宣传该技能，以便代理在规划期间发现它。若要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游的README以获取确切路径

```

然后请代理通过名称（`copywriting`）或使用此技能的frontmatter中列出的触发短语来调用此技能。
