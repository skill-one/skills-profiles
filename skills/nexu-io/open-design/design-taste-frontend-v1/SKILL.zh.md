# 高级代理前端技能

## 1. 活跃基线配置
* **设计偏差 (DESIGN_VARIANCE):** 8 (1=完美对称, 10=艺术混沌)
* **运动强度 (MOTION_INTENSITY):** 6 (1=静态/无运动, 10=电影感/魔法物理)
* **视觉密度 (VISUAL_DENSITY):** 4 (1=艺术画廊/空气感, 10=飞行员驾驶舱/密集数据)

**AI 指令:** 所有生成的标准基线严格设置为这些值 (8, 6, 4)。不要要求用户编辑此文件。否则，始终倾听用户：根据他们在聊天提示中明确的要求动态调整这些值。使用这些基线（或用户覆盖的）值作为您的全局变量来驱动第 3 至 7 节中的特定逻辑。

## 2. 默认架构与约定
除非用户明确指定不同的技术栈，否则请遵守这些结构约束以保持一致性：

* **依赖项验证 [强制]:** 在导入任何第三方库（例如 `framer-motion`, `lucide-react`, `zustand`）之前，您必须检查 `package.json`。如果缺少包，您必须在提供代码之前输出安装命令（例如 `npm install package-name`）。**永远**不要假设库存在。
* **框架与交互性:** React 或 Next.js。默认使用服务器组件 (`RSC`)。
    * **RSC 安全性:** 全局状态仅在客户端组件中有效。在 Next.js 中，将提供者包装在 `"use client"` 组件中。
    * **交互性隔离:** 如果第 4 或 7 节（运动/液态玻璃）处于活动状态，特定的交互式 UI 组件必须作为具有 `'use client'` 的最顶部的隔离叶组件提取。服务器组件必须专门渲染静态布局。
* **状态管理:** 使用本地的 `useState`/`useReducer` 进行隔离 UI。严格使用全局状态以避免深度属性钻取。
* **样式策略:** 使用 Tailwind CSS (v3/v4) 进行 90% 的样式。
    * **Tailwind 版本锁定:** 首先检查 `package.json`。不要在 v3 项目中使用 v4 语法。
    * **T4 配置保护:** 对于 v4，不要在 `postcss.config.js` 中使用 `tailwindcss` 插件。使用 `@tailwindcss/postcss` 或 Vite 插件。
* **反表情符号策略 [关键]:** **永远**不要在代码、标记、文本内容或替代文本中使用表情符号。用高质量图标（Radix、Phosphor）或干净的 SVG 原语替换符号。表情符号被禁止。
* **响应式与间距:**
  * 标准化断点 (`sm`, `md`, `lg`, `xl`)。
  * 使用 `max-w-[1400px] mx-auto` 或 `max-w-7xl` 包含页面布局。
  * **视口稳定性 [关键]:** **永远**不要使用 `h-screen` 用于全高度的 Hero 部分。**始终**使用 `min-h-[100dvh]` 以防止在移动浏览器（iOS Safari）上发生灾难性的布局跳跃。
  * **网格优于 Flex-Math:** **永远**不要使用复杂的 flexbox 百分比数学 (`w-[calc(33%-1rem)]`)。**始终**使用 CSS 网格 (`grid grid-cols-1 md:grid-cols-3 gap-6`) 以获得可靠的结构。
* **图标:** 您必须使用 `@phosphor-icons/react` 或 `@radix-ui/react-icons` 作为导入路径（检查已安装版本）。全局标准化 `strokeWidth`（例如，仅使用 `1.5` 或 `2.0`）。

## 3. 设计工程指令（偏差校正）
LLM 对特定的 UI 陈腐模式有统计偏差。使用这些工程规则主动构建高级界面：

**规则 1: 确定性排版**
* **显示/标题:** 默认为 `text-4xl md:text-6xl tracking-tighter leading-none`。
    * **反松散:** 避免使用 `Inter` 进行“高级”或“创意”感觉。强制使用独特的字符，使用 `Geist`、`Outfit`、`Cabinet Grotesk` 或 `Satoshi`。
    * **技术 UI 规则:** 对于 Dashboard/软件 UI，严格禁止使用衬线字体。在这些上下文中，使用高端无衬线字体配对（`Geist` + `Geist Mono` 或 `Satoshi` + `JetBrains Mono`）。
* **正文/段落:** 默认为 `text-base text-gray-600 leading-relaxed max-w-[65ch]`。

**规则 2: 颜色校准**
* **约束:** 最大 1 个强调色。饱和度 < 80%。
* **LILA 禁令:** 严格禁止“AI 紫色/蓝色”美学。没有紫色按钮发光，没有霓虹渐变。使用绝对中性基础（Zinc/Slate）和高对比度、单一强调色（例如 Emerald、Electric Blue 或 Deep Rose）。
* **颜色一致性:** 在整个输出中坚持一个调色板。不要在同一项目中在暖色和冷灰色之间波动。

**规则 3: 布局多样化**
* **反居中偏差:** 当 `LAYOUT_VARIANCE > 4` 时，严格禁止居中的 Hero/H1 部分。强制使用“分屏”（50/50）、“左对齐内容/右对齐资产”或“非对称空白”结构。

**规则 4: 材质性、阴影和“反卡片过度使用”**
* **仪表盘硬化:** 对于 `VISUAL_DENSITY > 7`，严格禁止通用卡片容器。使用 `border-t`、`divide-y` 或纯粹负空间进行逻辑分组。数据指标应该呼吸，而不是被框住，除非需要 z-index（提升）功能。
* **执行:** 仅在提升传达层次结构时使用卡片。当使用阴影时，将其色调调整为背景色。

**规则 5: 交互式 UI 状态**
* **强制生成:** LLM 自然生成“静态”成功状态。您必须实现完整的交互周期：
  * **加载:** 与布局大小匹配的骨骼加载器（避免使用通用的圆形旋转器）。
  * **空状态:** 精美组合的空状态，指示如何填充数据。
  * **错误状态:** 清晰的行内错误报告（例如，表单）。
  * **触觉反馈:** 在 `:active` 上，使用 `-translate-y-[1px]` 或 `scale-[0.98]` 来模拟物理按压，指示成功/操作。

**规则 6: 数据与表单模式**
* **表单:** 标签必须位于输入框上方。辅助文本是可选的，但应在标记中存在。错误文本位于输入框下方。使用标准的 `gap-2` 输入块。

## 4. 创意主动性（反松散实施）
为积极对抗通用的 AI 设计，系统性地实施这些高端编码概念作为您的基线：
* **“液态玻璃”折射:** 当需要玻璃效果时，超越 `backdrop-blur`。添加 1px 内边框（`border-white/10`）和微妙的内阴影（`shadow-[inset_0_1px_0_rgba(255,255,255,0.1)]`）以模拟物理边缘折射。
* **磁性微观物理（如果 MOTION_INTENSITY > 5）:** 实现被鼠标光标轻微拉向按钮。**关键:** **永远**不要使用 React `useState` 进行磁性悬停或连续动画。**仅**使用 Framer Motion 的 `useMotionValue` 和 `useTransform` 在 React 渲染周期之外，以防止在移动设备上性能崩溃。
* **持续微观交互:** 当 `MOTION_INTENSITY > 5` 时，在标准组件（头像、状态点、背景）中嵌入连续、无限的微观动画（脉冲、打字机、漂浮、闪烁、轮播）。对所有交互元素应用高端弹簧物理（`type: "spring", stiffness: 100, damping: 20`）——不要使用线性缓动。
* **布局过渡:** 始终使用 Framer Motion 的 `layout` 和 `layoutId` 属性，以实现平滑的重新排序、调整大小和跨状态变化的共享元素过渡。
* **交错编排:** 不要立即挂载列表或网格。使用 `staggerChildren`（Framer）或 CSS 级联（`animation-delay: calc(var(--index) * 100ms)`）创建顺序瀑布式揭示。**关键:** 对于 `staggerChildren`，父级（`variants`）和子级必须位于相同的客户端组件树中。如果数据异步获取，请将数据作为属性传递到中央父级 Motion 包装器。

## 5. 性能护栏
* **DOM 成本:** 仅将纹理/噪声滤镜应用于固定、`pointer-event-none` 伪元素（例如，`fixed inset-0 z-50 pointer-events-none`），**永远**不要应用于滚动容器，以防止连续的 GPU 重绘和移动性能下降。
* **硬件加速:** **永远**不要动画化 `top`、`left`、`width` 或 `height`。**仅**通过 `transform` 和 `opacity` 动画。
* **Z-索引限制:** **永远**不要未经提示地滥用 `z-50` 或 `z-10`。严格使用 z-索引用于系统层级的层上下文（粘性导航栏、模态框、覆盖层）。

## 6. 技术参考（旋钮定义）

### 设计偏差 (DESIGN_VARIANCE) (级别 1-10)
* **1-3 (可预测):** Flexbox `justify-center`，严格的 12 列对称网格，相等的填充。
* **4-7 (偏移):** 使用 `margin-top: -2rem` 重叠，不同的图像宽高比（例如，4:3 旁边是 16:9），左对齐的标题在中心对齐的数据上方。
* **8-10 (非对称):** 砖砌布局，CSS 网格使用分数单位（例如，`grid-template-columns: 2fr 1fr 1fr`），巨大的空白区域（`padding-left: 20vw`）。
* **移动覆盖:** 对于级别 4-10，任何 `md:` 上的非对称布局都必须在视口 `< 768px` 上激进地回退到严格的单列布局（`w-full`，`px-4`，`py-8`）以防止水平滚动和布局破坏。

### 运动强度 (MOTION_INTENSITY) (级别 1-10)
* **1-3 (静态):** 没有自动动画。仅使用 CSS `:hover` 和 `:active` 状态。
* **4-7 (流体 CSS):** 使用 `transition: all 0.3s cubic-bezier(0.16, 1, 0.3, 1)`。使用 `animation-delay` 级联进行加载动画。严格专注于 `transform` 和 `opacity`。谨慎使用 `will-change: transform`。
* **8-10 (高级编排):** 复杂的滚动触发揭示或视差。使用 Framer Motion 钩子。**永远**不要使用 `window.addEventListener('scroll')`。

### 视觉密度 (VISUAL_DENSITY) (级别 1-10)
* **1-3 (艺术画廊模式):** 大量的空白。巨大的部分间隙。一切感觉都非常昂贵和干净。
* **4-7 (日常应用模式):** 标准间距用于标准 Web 应用。
* **8-10 (驾驶舱模式):** 微小的填充。没有卡片框；只是 1px 线条来分隔数据。一切都打包得很紧。**强制:** 使用 Monospace (`font-mono`) 为所有数字。

## 7. AI 告知（禁止模式）
为确保高级、非通用的输出，您必须严格避免这些常见的 AI 设计签名，除非明确请求：

### 视觉与 CSS
* **无霓虹/外部发光:** 不要使用默认的 `box-shadow` 发光或自动发光。使用内边框或微妙的色调阴影。
* **无纯黑色:** **永远**不要使用 `#000000`。使用 Off-Black、Zinc-950 或 Charcoal。
* **无过度饱和强调色:** 将强调色去饱和，使其与中性色优雅融合。
* **无过度渐变文本:** 不要使用大标题的文本填充渐变。
* **无自定义鼠标光标:** 它们已过时，会破坏性能和可访问性。

### 排版
* **无 Inter 字体:** 禁用。使用 `Geist`、`Outfit`、`Cabinet Grotesk` 或 `Satoshi`。
* **无超大 H1:** 第一个标题不应尖叫。通过重量和颜色控制层次结构，而不仅仅是巨大的规模。
* **衬线限制:** 仅在创意/编辑性设计中使用衬线字体。**永远**不要在干净的仪表盘上使用衬线。

### 布局与间距
* **完美对齐和间距:** 确保填充和边距是数学上完美的。避免浮动元素与尴尬的间隙。
* **无 3 列卡片布局:** 通用的“水平 3 个相等卡片”功能行被禁止。使用 2 列锯齿形、非对称网格或水平滚动方法。

### 内容与数据（“Jane Doe”效应）
* **无通用名称:** “John Doe”、“Sarah Chan”或“Jack Su”被禁止。使用高度创意、听起来真实的名称。
* **无通用头像:** **不要**使用标准的 SVG “鸡蛋”或 Lucide 用户图标作为头像。使用创意、可信的照片占位符或特定样式。
* **无假数字:** 避免可预测的输出，如 `99.99%`、`50%` 或基本电话号码（`1234567`）。使用有机、混乱的数据（`47.2%`、`+1 (312) 847-1928`）。
* **无初创公司松散名称:** “Acme”、“Nexus”、“SmartFlow”。发明高级、上下文相关的品牌名称。
* **无填充词:** 避免AI文案写作陈词滥调，如“提升”、“无缝”、“释放”或“下一代”。使用具体的动词。

### 外部资源与组件
* **无破旧的 Unsplash 链接:** 不要使用 Unsplash。使用绝对可靠的占位符，如 `https://picsum.photos/seed/{random_string}/800/600` 或 SVG UI Avatars。
* **shadcn/ui 自定义:** 您可以使用 `shadcn/ui`，但**永远**不要在其通用默认状态下使用。您必须自定义半径、颜色和阴影以匹配高端项目美学。
* **生产就绪的清洁度:** 代码必须极其干净、视觉引人注目、令人难忘，并在每个细节上都经过精心润色。

## 8. 创意武器库（高端灵感）
不要默认使用通用 UI。从这个高级概念库中提取，以确保输出视觉引人注目且令人难忘。在适当的情况下，利用 **GSAP (ScrollTrigger/Parallax)** 进行复杂的滚动叙事或 **ThreeJS/WebGL** 进行 3D/Canvas 动画，而不是基本的 CSS 运动。**关键:** **永远**不要在相同的组件树中混合 GSAP/ThreeJS 与 Framer Motion。默认使用 Framer Motion 进行 UI/Bento 交互。**仅**使用 GSAP/ThreeJS 用于隔离的全页滚动叙事或 Canvas 背景，并在严格的 `useEffect` 清理块中包装。

### 标准英雄范式
* 停止在深色图像上居中文本。尝试非对称英雄部分：文本干净地对齐到左侧或右侧。背景应显示高质量的相关图像，并带有微妙的风格化淡出（根据是浅色模式还是深色模式，优雅地淡入背景色）。

### 导航与菜单
* **Mac OS Dock 放大:** 导航栏在边缘；图标在悬停时流畅缩放。
* **磁性按钮:** 被鼠标光标物理拉向的按钮。
* **粘性菜单:** 子项像粘性液体一样从主按钮分离。
* **动态岛屿:** 一种药丸形 UI 组件，会变形以显示状态/警报。
* **上下文径向菜单:** 在点击坐标处展开的圆形菜单。
* **浮动快速拨号:** 弹出成曲线的次要操作的 FAB。
* **巨型菜单揭示:** 全屏下拉菜单，以交错淡入方式显示复杂内容。

### 布局与网格
* **Bento 网格:** 非对称、瓦片式分组（例如，Apple 控制中心）。
* **砖砌布局:** 无固定行高的交错网格（例如，Pinterest）。
* **Chroma 网格:** 网格边框或瓷砖显示微妙的连续动画颜色渐变。
* **分屏滚动:** 两个屏幕半部分在滚动时向相反方向滑动。
* **窗帘揭示:** 在滚动时像窗帘一样中间分开的英雄部分。

### 卡片与容器
* **视差倾斜卡片:** 跟随鼠标坐标进行 3D 倾斜的卡片。
* **聚光灯边框卡片:** 卡片边框在光标下方动态照明。
* **玻璃效果面板:** 真正的磨砂玻璃，带有内折射边框。
* **全息箔卡片:** 在悬停时移动彩虹光反射的 iridescent、彩虹光。
* **Tinder 滑动堆栈:** 用户可以滑动掉的物理卡片堆栈。
* **变形模态框:** 按钮无缝扩展为其自己的全屏对话框容器。

### 滚动动画
* **粘性滚动堆栈:** 卡片粘在顶部，并物理地堆叠在彼此之上。
* **水平滚动劫持:** 垂直滚动平滑地转换为水平画廊滚动。
* **火车头滚动序列:** 视频或 3D 序列，其帧率直接与滚动条绑定。
* **缩放视差:** 当您滚动时，中央背景图像无缝缩放/缩小。
* **滚动进度路径:** 随着用户滚动而绘制的 SVG 矢量线或路线。
* **液体滑动过渡:** 像粘性液体一样擦除屏幕的页面过渡。

### 画廊与媒体
* **穹顶画廊:** 感觉像全景穹顶的 3D 画廊。
* **Coverflow 轮播:** 中心聚焦，边缘倾斜回的 3D 轮播。
* **拖动平移网格:** 您可以自由地向任何方向拖动的无边界网格。
* **手风琴图像滑块:** 窄垂直/水平图像条在悬停时完全展开。
* **悬停图像轨迹:** 鼠标留下一个弹出/淡出图像的轨迹。
* **故障效果图像:** 在悬停时短暂地发生 RGB 通道偏移的数字失真。

### 字体与文本
* **Kinetic Marquee（动态跑马灯）**：无限循环的文本带，在滚动时改变方向或加速。
* **Text Mask Reveal（文本遮罩揭示）**：大型字体作为透明窗口，展示视频背景。
* **Text Scramble Effect（文本打乱效果）**：加载或悬停时，呈现矩阵风格的字符解码效果。
* **Circular Text Path（环形文本路径）**：文本沿旋转的圆形路径弯曲排列。
* **Gradient Stroke Animation（渐变描边动画）**：轮廓文本的描边上持续流动的渐变效果。
* **Kinetic Typography Grid（动态字体网格）**：字母网格在光标附近躲避或旋转。

### 微交互与效果
* **Particle Explosion Button（粒子爆炸按钮）**：成功时，CTA按钮碎裂成粒子。
* **Liquid Pull-to-Refresh（液体下拉刷新）**：移动端刷新指示器像分离的水滴。
* **Skeleton Shimmer（骨架闪烁）**：光标框内移动的光反射效果。
* **Directional Hover Aware Button（方向感知悬停按钮）**：悬停填充从鼠标进入的精确侧边进入。
* **Ripple Click Effect（涟漪点击效果）**：视觉波浪从点击坐标精确扩散。
* **Animated SVG Line Drawing（动画SVG线绘制）**：矢量实时绘制自己的轮廓。
* **Mesh Gradient Background（网格渐变背景）**：类似熔岩灯的有机动画色块。
* **Lens Blur Depth（镜头模糊深度）**：动态聚焦模糊背景UI层，突出前景操作。

## 9. “运动引擎”的Bento范式
在生成现代SaaS仪表盘或功能区域时，你必须使用以下“Bento 2.0”架构和运动理念。这超越了静态卡片，并强制执行“Vercel核心与Dribbble简洁”的美学，高度依赖持续的运动物理效果。

### A. 核心设计理念
* **美学**：高端、极简、实用。
* **调色板**：背景色为`#f9fafb`。卡片为纯白色(`#ffffff`)，带有1px的`border-slate-200/50`边框。
* **表面**：所有主要容器使用`rounded-[2.5rem]`。应用“扩散阴影”（非常浅、范围很广的阴影，例如`shadow-[0_20px_40px_-15px_rgba(0,0,0,0.05)]`）以创造深度而不杂乱。
* **字体**：严格的`Geist`、`Satoshi`或`Cabinet Grotesk`字体堆栈。标题使用微妙的追踪(`tracking-tight`)。
* **标签**：标题和描述必须放置在卡片的**外部和下方**，以保持干净的画廊式展示。
* **像素完美**：卡片内使用充足的`p-8`或`p-10`内边距。

### B. 动画引擎规格（持续运动）
所有卡片必须包含**“持续微交互”**。使用以下Framer Motion原则：
* **弹簧物理**：无线性缓动。使用`type: "spring", stiffness: 100, damping: 20`以获得高端、有重量的感觉。
* **布局过渡**：大量使用`layout`和`layoutId`属性，确保平滑的重新排序、调整大小和共享元素状态过渡。
* **无限循环**：每张卡片必须有“活动状态”，无限循环（脉冲、打字机、浮动或轮播）以确保仪表盘感觉“生动”。
* **性能**：将动态列表包裹在`<AnimatePresence>`中，并优化至60fps。**性能关键**：任何持续运动或无限循环都必须使用`React.memo`进行记忆化，并完全隔离在其自己的微观客户端组件中。切勿在父布局中触发重新渲染。

### C. 5种卡片原型（微动画规格）
在构建Bento网格时（例如，第1行：3列 | 第2行：2列分70/30）实现这些特定微动画：
1. **智能列表**：垂直堆叠的项，具有无限自动排序循环。项使用`layoutId`交换位置，模拟AI实时优先级排序任务。
2. **命令输入**：具有多步打字机效果的搜索/AI栏。它循环通过复杂提示，包括闪烁的光标和带有闪烁加载渐变的“处理”状态。
3. **实时状态**：带有“呼吸”状态指示器的调度界面。包括弹出通知徽章，使用“过冲”弹簧效果出现，持续3秒后消失。
4. **宽数据流**：水平“无限轮播”的数据卡片或指标。确保循环无缝（使用`x: ["0%", "-100%"]`）且感觉毫不费力。
5. **上下文UI（聚焦模式）**：文档视图，动画化文本块的交错高亮，然后是带有微图标的浮动操作工具栏“浮入”。
