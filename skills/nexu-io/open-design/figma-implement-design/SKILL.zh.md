# figma-implement-design

> 来自 Figma MCP 服务器指南的精选。

## 功能

将 Figma 设计转换为具有 1:1 视觉保真度的生产就绪代码。适用于将 Figma 帧直接交给前端代理。

## 来源

- 上游：https://github.com/figma/skills
- 分类：`figma`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游捆绑包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/figma/skills
```

然后请代理通过名称（`figma-implement-design`）或使用此技能 frontmatter 中列出的触发短语之一来调用此技能。
