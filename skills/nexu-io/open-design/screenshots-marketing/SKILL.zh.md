# screenshots-marketing

> 由 @Shpigford 精选。

## 功能说明

使用 Playwright 生成营销截图。适用于落地页主视觉、App Store 截图以及版本更新视觉设计。

## 来源

- 上游链接：https://github.com/Shpigford/screenshots
- 分类：`screenshots`

## 使用方法

此目录项在 OpenDesign 中宣传该技能，以便代理在规划阶段发现它。若要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到当前代理的技能目录中：

```bash
# 查看上游 README 获取确切路径
open https://github.com/Shpigford/screenshots
```

然后通过名称（`screenshots-marketing`）或使用本技能 frontmatter 中列出的触发短语，要求代理调用此技能。
