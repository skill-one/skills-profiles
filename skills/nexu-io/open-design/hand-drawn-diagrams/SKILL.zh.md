# 手绘图表

> 来自 @muthuishere 的精选。

## 功能

根据提示生成手绘 Excalidraw 图表 — 动画 SVG、托管编辑链接和 PNG 导出。可与 Claude Code、Codex、Gemini CLI 以及任何支持标准技能路径的代理协同工作。

- 上游：https://github.com/muthuishere/hand-drawn-diagrams
