# 使用 Tesseract 编辑视频

CLI 可能会为某些命令发送基本的使用遥测数据。您可以通过 `TESSERACT_SKILL=tesseract-video` 和 [其他归因变量](references/telemetry.md) 提供可选的归因。尊重 CLI 的遥测数据禁用设置；切勿代表用户启用遥测数据。

从用户的素材中进行有目的的编辑。Tesseract 是本地编辑和渲染引擎；代理提供编辑判断。输出既是可播放的视频，也是可编辑的项目。

## 从素材开始

1. 从包含此 `SKILL.md` 的目录中解析此技能的根路径。阅读 [CLI 安装](references/installation.md) 并在每次会话中检查所需的 Tesseract 版本。在整个任务中使用解析的可执行路径。脚本和参考相对于已安装的技能，而不是猜测的 home 目录或开发检出。
2. 阅读 [本地操作](references/local-operation.md)。使用主机可用的媒体工具探测提供的媒体，在有意义的位置采样帧，并聆听其音频。元数据不会告诉您一个镜头描绘了什么。如果无法试听音频，则披露该限制，而不是声称进行了完整审查。
3. 从请求中确定交付成果、受众、宽高比、时长、必须保留的时刻和提供的品牌资产。仅请求实质性改变编辑的缺失信息。对于小的修正，保留现有编辑的风格和范围。
4. 在规划新编辑之前，阅读 [编辑决策](references/editorial-decisions.md)。对于每个节奏点决定 **素材**、**带图形的素材** 或 **全图形** 以及原因。这不是配额：不要仅为了展示引擎而添加运动图形。

对于新广告或其开头的修订，阅读 [广告钩子](references/ad-hooks.md)。从实际素材、提议和证据中构建开头的视觉钩子。考虑不同的概念，选择最强的，并在提供音乐时将其揭示/运动和有目的的 SFX 映射到确认的开头音乐提示上。在润色其余部分之前，渲染并检查钩子及其转场到广告。保留不相关修订的范围。

当音乐设定节奏或修剪谈话素材时，阅读 [波形编辑](references/waveform-editing.md)。在规划画面时间之前生成并 **打开** 音乐波形；通过聆听确认节奏点、短语和主要变化，并将视觉到达映射到它们。对于语音，使用概览和缩放源波形来选择暂停修剪、保护安静词语边界并保留自然呼吸。波形标记是候选者，永远不会是自动剪切决策。

对于重要的新视频，共享简洁的编辑计划，包括源时刻、其叙事目的、图形处理和音频意图。常规授权编辑可以继续。不要对每个本地预览或修订都要求新的批准。

## 作者化编辑

- 新编辑：`tsrct project create` 创建可移植的 `.tsrct` 文档；在放置其图层之前导入本地素材。现有的 `.tsrct`：检查并检出一个可编辑的 JSON 副本。保留原始和稳定的 ID。通过 `project commit` 保存 JSON，或在渲染之前使用 `project apply` 应用受支持的操作批处理。
- 在更改项目结构之前，阅读 [原生作者化](references/native-authoring.md)。源时间、编辑时间和图层时间是不同的时钟。特别是，移动片段不应无声地改变它播放的源时刻。
- 将素材剪切、完整场景和可编辑的叠加层作为文档的单个合成中的原生图层保留。使用组来组织场景。`activeRange` 将片段放置在其父级中；`sourceRange` 选择源时刻。不要创建基础视频、字幕或音频轨道。
- 对于谈话头剪切，遵循 [视线连续性](references/editorial-decisions.md#talking-head-eyeline-continuity)：使用适当的构图对齐说话者的眼睛高度和屏幕位置跨剪切，包括推入。检查渲染的出/入帧并播放，同时保留自然的头部运动和有意的摄像机变化。
- 对于运动工作，阅读 [运动设计](references/motion-design.md)，然后仅阅读相关的作者化参考。示例展示了真实的模式；它们的视觉风格不是必需的模板。
- 对于每个新的编辑或声音遍历，阅读 [声音设计](references/sound-design.md)。考虑对话、音乐、微 SFX、结构提示和 foley/环境音；使用作品需要的角色。从提供的/本地资源或程序化助手添加适当的声音，无需每条提示的批准。使用 `project import-asset --kind audio` 导入选定的文件，然后将它们保留为可编辑的音频图层。使用 [音频和时机](references/audio-and-timing.md) 进行放置、压低、本地准备和测量。保留有用的源音频和选择的音乐。不要制作虚构的语音或字幕。
- 当谈话音频需要清理时，阅读 [语音清理](references/speech-cleanup.md)。诊断房间噪音与混响/回声，根据需要使用受限的 EQ/动态或本地噪音减少，并在匹配的响度下进行比较。保留声音细节和时机；插件没有捆绑的去混响模型。
- 保留排版、图形、素材和音频的原生和可编辑性。使用 `project import-asset --kind image` 将提供的图像作为资源导入，而不是作为文本、矢量图形或整个场景的扁平化替换。使用现有素材；此插件不提供生成视频或头像服务。
- 尊重用户的品牌参考。Mirage 品牌标识此插件，而不是用它创建的每个视频。

## 仅在需要时查询功能

使用 [本地操作](references/local-operation.md) 通过安装的 CLI 的模式。

阅读 [功能](references/capabilities.md) 获取功能映射和限制，
[FX 作者化](references/fx-authoring.md) 获取原生图层和素材，
[motion](references/motion.md) 获取支持的关键帧和脚本操作。搜索需要的具体定义，而不是转储整个模式。操作模式包括支持的独立操作及其字段限制；使用 [本地操作](references/local-operation.md) 选择操作，而不是 JSON 检出/提交。安装的模式和实际渲染是权威的。

## 审查和交接

使用 [胶片条审查](references/filmstrip-review.md) 检查和纠正视觉更改。对于对话剪切和音乐时机，遵循 [波形编辑](references/waveform-editing.md)。最后，使用 [审查和交付](references/review-and-delivery.md)；报告实际检查和任何限制。使用绝对本地文件链接，并在支持时内联显示视频。Premiere 循环、云同步和发布尚未实现。

如果主机无法执行本地命令或访问本地 GPU/文件系统，解释此软件包需要一个本地执行环境。不要用托管服务替换或无声地切换渲染引擎。
