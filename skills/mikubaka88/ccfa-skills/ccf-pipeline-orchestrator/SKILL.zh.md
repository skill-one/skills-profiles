# CCF 管道编排器

## 家族文件契约

在编写前，为每个任务/工件确定规范输出和一个稳定的作业目录。重用明确的或已建立的作业路径；否则使用项目根目录 `ccfa-workfiles/<用途>/<工件ID>/`，仅在需要时包含 `source/`、`assets/`、`cache/` 和 `build/`。就地更新当前文件；不要分散中间文件或创建迭代副本。保留输入和所需证据；仅清理由本任务创建的已验证可丢弃文件。使用 UTF-8 文本 I/O，并在保存或渲染后检查中文文本。对于文件工作，应用 [artifact-contracts.md](../ccf-common/references/artifact-contracts.md) 并在技能转换时重用相同的路径。

## 协作契约

在专家执行前，首先阅读并应用 [ccf-humanization](../ccf-humanization/SKILL.md)，然后应用 [ccf-common](../ccf-common/SKILL.md)。在每次交接时，重用其适用的活跃规则或刷新缺失/变更的规则。即使没有文本，两个预检也是必需的；详细编辑、实验和维护模式仅在相关时运行。

保留一个集成所有者，并积极使用其他技能来解决缺失的先决条件或检查材料发现。重用适用的证据；不要跳过必要的准备工作以节省代币。在最终确定前，集成贡献并验证受影响的成果。遵循条件 [合作路线](../ccf-common/references/routing.md)；避免无关阶段和重复报告。

## 核心规则

作为项目协调员和工作流规划者运行。明确目标，映射当前阶段，更新或读取 `ccfa.yaml`，定义关卡，并命名下一个所有者技能。专家技能拥有下游输出。对于仅计划请求，返回计划。对于明确请求端到端执行，通过完成协调授权所有者，而不是在命名下一个技能后停止。遵循 `../ccf-common/references/task-modes.md`：如果用户要求短期计划、清单、YAML 更新、表格或叙述路线图，使用该可见形状，而不是强制固定报告。

在规划和每个贡献技能之前确保 Humanization 和 Common 处于活跃状态。在交接时重用其适用规则。在授权的写作阶段内应用 Humanization 的详细文本模式；原始计划和渲染仍然接收其基线，而无需文稿编辑工作流。

遵循 `../ccf-common/references/handoff-modes.md` 和 `../ccf-common/references/artifact-contracts.md`。后续用户更正通常引导活跃项目：保留有效的已完成工作，更新受影响的需求，并继续。不要编造已完成阶段或自动后台作业。

## 工作流

1. 确定目标场所、当前阶段、可用工件、约束、截止日期压力和用户的即时目标。
2. 当可用时读取 `ccfa.yaml`；如果缺失，继续使用提供的工件。不要要求设置或创建项目状态仅为了路由工作；仅在它限制请求的跟踪时才披露其缺失。
3. 对于不明确的项目，使用 `references/workflow-planning/intake-protocol.md`、`approach-options.md` 和 `design-brief-template.md`。
4. 使用 `../ccf-common/references/routing.md` 分配集成所有者。从请求的结果向后工作到缺失的先决条件和材料检查，包括用户未命名的上游工作。区分有界贡献和下一工件所有权；在整个过程中携带活跃预检，并在相关时应用详细的 Humanization 模式。保留明确的范围限制。
5. 通过其所需证据、输出、通过条件、阻塞性和负责技能定义每个适用的关卡。标记先决条件已满足、缺失、冲突或超出范围；重用有效的证据，并在推进依赖结论前解决缺失/冲突的证据。工具完成本身不能通过关卡。
6. 使用 `../ccf-common/references/handoff-modes.md` 中的连续性/返回契约：携带当前范围、证据/版本、规范路径、编辑所有权和确切的下一步操作。仅在授权状态维护时更新现有的 `ccfa.yaml` 阶段/关卡字段；保留无关字段和架构。仅计划请求提出更改而不编写。
7. 集成专家结果，与源证据解决冲突，并检查受影响的下游结论。根据实际证据推进关卡；保留有效的已完成工作并继续围绕阻塞性的独立阶段。仅重新打开变更的依赖关系或未解决的发现。完成时请求的输出和适用的先决条件/检查已完成，或确定剩余不完整的精确依赖结果。

## 自适应输出契约

首先放置请求的工件：路线图、下一步决策、任务列表、交接包或 `ccfa.yaml` 补丁指令。仅用于标准规划、模糊的多阶段项目或用户要求完整协调报告时，才使用以下完整结构。

```text
项目目标：
当前阶段：
已知工件：
缺失工件：
关卡决策：
下一个所有者技能：
交接包：
ccfa.yaml 更新：
风险 / 阻塞性：
```
