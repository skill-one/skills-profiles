# 重新设计技能

## 工作原理

将此应用于现有项目时，请按以下顺序操作：

1. **扫描** — 读取代码库。识别框架、样式方法（Tailwind、原生 CSS、styled-components 等）以及当前的设计模式。
2. **诊断** — 运行以下审核。列出您发现的每个通用模式、弱点以及缺失的状态。
3. **修复** — 与现有技术栈配合应用有针对性的升级。不要从零开始重写。改进现有内容。

## 设计审核

### 字体排印

检查并修复以下问题：

- **浏览器默认字体或 Inter 到处都是。** 使用具有特色的字体替换。好的选项：`Geist`、`Outfit`、`Cabinet Grotesk`、`Satoshi`。对于编辑/创意项目，使用衬线标题搭配无衬线正文。
- **标题缺乏存在感。** 增加显示文本的大小，收紧字间距，减少行高。标题应感觉沉重且有意为之。
- **正文文本太宽。** 将段落宽度限制在约 65 个字符。增加行高以提高可读性。
- **仅使用常规（400）和粗体（700）字重。** 引入中等（500）和半粗体（600），以实现更微妙的结构层次。
- **比例字体中的数字。** 使用等宽字体或启用表格数字（`font-variant-numeric: tabular-nums`）用于数据密集型界面。
- **缺少字间距调整。** 使用负间距跟踪大标题，使用正间距跟踪小写字母或标签。
- **到处都是全大写的子标题。** 尝试小写斜体、句子大小写或小写字母。
- **孤立的单词。** 单个单词独自坐在最后一行。使用 `text-wrap: balance` 或 `text-wrap: pretty` 修复。

### 颜色和表面

- **纯 `#000000` 背景。** 使用浅黑色、深煤色或浅色调的深色（`#0a0a0a`、`#121212` 或深蓝色）。
- **饱和度过高的强调色。** 将饱和度保持在 80% 以下。降低强调色的饱和度，使其与中性色融合，而不是尖叫。
- **超过一种强调色。** 选择一种。删除其余的。一致性胜过多样性。
- **混合暖色和冷色灰度。** 坚持一个灰度系列。使用一致的色调（暖色或冷色，不是两者兼有）对所有灰度进行染色。
- **紫色/蓝色“AI 渐变”美学。** 这是最常见的 AI 设计指纹。使用中性基色和单个经过深思熟虑的强调色替换。
- **通用的 `box-shadow`。** 将阴影染色以匹配背景色调。使用彩色阴影（例如，蓝色背景上的深蓝色阴影）而不是纯黑色低不透明度。
- **完全没有纹理的扁平设计。** 为背景添加微妙的噪声、颗粒或微图案。纯扁平矢量感觉单调。
- **完美的均匀渐变。** 使用径向渐变、噪声叠加或网格渐变打破统一性，而不是标准的 45 度线性渐变。
- **不一致的照明方向。** 审核所有阴影，确保它们暗示一个单一、一致的光源。
- **随机深色区域在浅色模式页面（反之亦然）。** 单个深色背景区域打破原本浅色的页面看起来像复制粘贴的错误。要么完全采用深色模式，要么在整个页面中保持一致的背景色调。如果需要对比度，请使用同一调色板的稍深色调，而不是在奶油色页面中间突然跳到 `#111`。
- **空白的扁平区域没有视觉深度。** 仅在普通背景上显示文本的区域感觉不完整。添加高质量的背景图像（模糊、叠加或遮罩）、微妙的图案或环境渐变。当没有真实资源时，使用可靠的占位符来源，如 `https://picsum.photos/seed/{name}/1920/1080`。尝试在英雄区域、功能块或 CTA 背景中使用背景图像，即使是在低不透明度的全宽照片也能增加存在感。

### 布局

- **所有内容居中对称。** 使用偏移边距、混合长宽比或左对齐标题覆盖居中内容来打破对称性。
- **三个相等卡片列作为功能行。** 这是最通用的 AI 布局。替换为 2 列之字形、非对称网格、水平滚动或马赛克布局。
- **使用 `height: 100vh` 为全屏区域。** 使用 `min-height: 100dvh` 以防止移动浏览器（iOS Safari 视口问题）上的布局跳跃。
- **复杂的 flexbox 百分比数学。** 使用 CSS Grid 替代，以获得可靠的 multicolumn 结构。
- **没有最大宽度容器。** 添加一个容器约束（约 1200-1440px）并使用自动边距，以便在宽屏幕上内容不会延伸到边缘。
- **卡片高度相等被 flexbox 强制。** 允许可变高度或使用马赛克，当内容长度不同时。
- **所有内容使用统一的 border-radius。** 变更半径：内部元素使用更小的半径，容器使用更柔和的半径。
- **没有重叠或深度。** 元素平坦地彼此相邻。使用负边距创建层叠和视觉深度。
- **对称的垂直填充。** 顶部和底部填充总是相同的。进行视觉调整——底部填充通常需要稍大。
- **仪表板总是有左侧边栏。** 尝试顶部导航、浮动命令菜单或可折叠面板。
- **缺少空白。** 倍增间距。让设计呼吸。密集布局适用于数据仪表板，而不是营销页面。
- **卡片组中的按钮未底部对齐。** 当卡片具有不同长度的内容时，CTA 会出现在随机高度。将按钮固定到每个卡片的底部，以便它们在内容上方形成一条干净的水平线。
- **功能列表从不同的垂直位置开始。** 在定价表或比较卡片中，功能列表应在所有列中从相同的 Y 位置开始。使用一致的高度间距或固定高度标题/价格块。
- **并排元素的不一致垂直韵律。** 当放置卡片、列或面板时，对齐共享元素（标题、描述、价格、按钮）跨所有项目。基线未对齐会使布局看起来不完整。
- **看起来不正确的数学对齐。** 按数学中心对齐并不总是看起来对眼睛来说居中。图标旁边的文本、圆形中的播放按钮或按钮中的文本通常需要 1-2px 的视觉调整才能感觉正确。

### 交互和状态

- **按钮没有悬停状态。** 添加背景变化、轻微缩放或在悬停时平移。
- **没有激活/按下反馈。** 在按下时添加微妙的 `scale(0.98)` 或 `translateY(1px)` 以模拟物理点击。
- **即时过渡，无持续时间。** 为所有交互元素添加平滑过渡（200-300ms）。
- **缺少焦点环。** 确保键盘导航的可见焦点指示器。这是一个无障碍性要求，不是可选的。
- **没有加载状态。** 使用与布局形状匹配的骨架加载器替换通用的圆形旋转器。
- **没有空状态。** 空的仪表板显示空白是一个错失的机会。设计一个“开始使用”的视图。
- **没有错误状态。** 为表单添加清晰的、内联错误消息。不要使用 `window.alert()`。
- **死链接。** 链接到 `#` 的按钮。要么链接到真实的目的地，要么在视觉上禁用它们。
- **没有导航中当前页面的指示。** 以不同的样式突出显示活动导航链接，以便用户知道他们在哪里。
- **滚动跳跃。** 锚点点击立即跳跃。添加 `scroll-behavior: smooth`。
- **使用 `top`、`left`、`width`、`height` 的动画。** 切换到 `transform` 和 `opacity` 以获得 GPU 加速的平滑动画。

### 内容

- **“John Doe”或“Jane Smith”等通用名称。** 使用多样化、听起来真实的名称。
- **假圆数字，如 `99.99%`、`50%`、`$100.00`。** 使用有机、凌乱的数字：`47.2%`、`$99.00`、`+1 (312) 847-1928`。
- **占位符公司名称，如“Acme Corp”、“Nexus”、“SmartFlow”。** 发明与上下文相关的、可信的品牌名称。
- **AI 撰写陈词滥调。** 永远不要使用“提升”、“无缝”、“释放”、“下一代”、“游戏改变者”、“深入”、“编织”或“在...的世界中”。使用简洁、具体的语言。
- **成功消息中的感叹号。** 删除它们。要自信，不要大声。
- **“Oops!”错误消息。** 直接说明：“连接失败。请重试。”
- **被动语态。** 使用主动语态：“我们无法保存您的更改”而不是“犯了错误”。
- **所有博客文章日期都相同。** 随机化日期以使其看起来真实。
- **多个用户使用相同的头像图像。** 为每个不同的人使用唯一的资源。
- **Lorem Ipsum。** 永远不要使用占位符拉丁文。编写真实的草稿副本。
- **每个标题都使用标题大小写。** 使用句子大小写。

### 组件模式

- **通用的卡片外观（边框 + 阴影 + 白色背景）。** 删除边框，或者只使用背景颜色，或者只使用间距。卡片只有在提升传达层次结构时才存在。
- **始终有一个填充按钮 + 一个幽灵按钮。** 添加文本链接或次要样式以减少视觉噪音。
- **圆形的“新”和“Beta”徽章。** 尝试方形徽章、旗帜或纯文本标签。
- **手风琴 FAQ 部分。** 使用并排列表、可搜索的帮助或内联渐进式披露。
- **3 卡片轮播评论，带点。** 替换为马赛克墙、嵌入的社交帖子或单个旋转引言。
- **带有 3 桶的定价表。** 使用颜色和强调突出显示推荐的层级，而不仅仅是高度。
- **用于所有内容的模态框。** 使用内联编辑、滑入面板或可展开部分，而不是弹出窗口执行简单操作。
- **头像圆圈专一。** 尝试圆角矩形或圆角方形，以获得不那么通用的外观。
- **亮/暗切换始终是太阳/月亮切换。** 使用下拉菜单、系统偏好检测或将其集成到设置中。
- **带有 4 列的页脚链接农场。** 简化。专注于主要的导航路径和法定链接。

### 图标

- **专一使用 Lucide 或 Feather 图标。** 这些是“默认”AI 图标选择。使用 Phosphor、Heroicons 或自定义集以实现差异化。
- **火箭用于“启动”，盾牌用于“安全”。** 使用不太明显的图标（螺栓、指纹、火花、保险库）替换陈词滥调的隐喻。
- **图标之间 stroke 宽度不一致。** 审核所有图标并标准化为一种 stroke 重量。
- **缺少 favicon。** 始终包含一个品牌 favicon。
- **“多元化团队”的股票照片。** 使用真实团队照片、抓拍照片或一致的插图风格，而不是不自然的股票图像。

### 代码质量

- **div 汤碗。** 使用语义 HTML：`<nav>`、`<main>`、`<article>`、`<aside>`、`<section>`。
- **内联样式与 CSS 类混合。** 将所有样式移至项目的样式系统。
- **硬编码像素宽度。** 使用相对单位（`%`、`rem`、`em`、`max-width`）以获得灵活的布局。
- **图像缺少 alt 文本。** 描述图像内容以供屏幕阅读器使用。决不将 `alt=""` 或 `alt="image"` 置于有意义的图像上。
- **任意的 z-index 值，如 `9999`。** 在主题/变量中建立干净的 z-index 规模。
- **已注释的死亡代码。** 在发布前删除所有调试残留物。
- **import 幻觉。** 检查每个 import 是否存在于 `package.json` 或项目依赖中。
- **缺少 meta 标签。** 添加正确的 `<title>`、`description`、`og:image` 和社交分享 meta 标签。

### 战略性遗漏（AI 通常会忘记的内容）

- **没有法律链接。** 在页脚中添加隐私政策和条款服务链接。
- **没有“返回”导航。** 用户流程中的死胡同。每页都需要一种返回方式。
- **没有自定义 404 页面。** 设计一个有帮助的、品牌化的“页面未找到”体验。
- **没有表单验证。** 添加客户端验证电子邮件、必填字段和格式检查。
- **没有“跳过到内容”链接。** 对键盘用户至关重要。添加一个隐藏的跳过链接。
- **没有 cookie 同意。** 如果受管辖区域要求，请添加合规的同意横幅。

## 升级技巧

在升级项目时，从这些高影响力的技巧中汲取灵感，以替换通用模式：

### 字体排印升级

- **可变字体动画。** 在滚动或悬停时插值权重或宽度，使文本感觉生动。
- **轮廓到填充过渡。** 文本开始时是轮廓描边，然后在滚动进入或交互时填充颜色。
- **文本遮罩揭示。** 大型排版作为视频或动画图像背后的窗口。

### 布局升级

- **打破网格/不对称性。** 故意忽略列结构的元素——重叠、超出屏幕或使用计算随机偏移。
- **最大化空白。** 大胆使用负空间以迫使焦点集中在单个元素上。
- **视差卡片堆栈。** 在滚动时粘附并物理堆叠在彼此之上的部分。
- **分屏滚动。** 屏幕的两半向相反方向滑动。

### 动画升级

- **平滑滚动带惯性。** 与浏览器默认值解耦，以获得更沉重、电影般的感受。
- **交错进入。** 元素以轻微的延迟级联进入，结合 Y 轴平移和淡入效果。决不一次性挂载所有内容。
- **弹簧物理。** 使用基于弹簧的运动替代线性缓动，以在所有交互元素上获得自然、沉重的感受。
- **滚动驱动揭示。** 内容通过扩展遮罩、擦除或与滚动进度绑定的 SVG 路径进入。

### 表面升级

- **真正的玻璃态。** 超越 `backdrop-filter: blur`。添加 1px 内边框和微妙的内阴影以模拟边缘折射。
- **聚光灯边框。** 卡片边框在光标下方动态照明。
- **颗粒和噪声叠加。** 一个固定的、`pointer-events-none` 叠加层，带有微妙的噪声，以打破数字平面感。
- **彩色、染色阴影。** 阴影携带背景色调，而不是使用通用的黑色。
