# 纸艺拼贴动画生成器

将简短的叙述行、故事主题、观点句或抽象概念转化为连贯的编辑式纸艺拼贴动画序列。视觉语言是高端半色调纸艺拼贴：平面大胆色块、黑白摄影剪贴、选择性彩色卡纸点缀、暖米色关键线、柔和纸艺阴影、触感定格动画组装，以及清晰的拼贴音效。

这个基于Hub的技能使用Hub原生的图像、视频、音频和可选的后处理功能。它优先考虑风格连贯性、色彩和谐、受控的纸张纹理、定格动画拼贴节奏，以及默认保留触感拼贴音效的音频策略，同时明确不添加背景音乐、旁白或字幕，除非用户要求。

## 使用场景

当用户需要时，使用此技能：

- 将简短脚本行转化为视觉隐喻拼贴动画
- 通过拼贴B-roll解释简单故事或文学主题
- 用于叙述或社交视频的编辑式纸艺拼贴动画
- 半色调拼贴动画，物体从空色块中组装出来
- 将一批简短抽象句或故事节点转化为独立的视觉隐喻动画片段
- 具有触感知识解释功能的拼贴动画，可能包括纸张点击、噼啪声、滑动、按压和沙沙声，但不包括自动音乐或旁白

当用户需要时，不要使用此技能：

- 真实的产品广告或主持人主导视频
- 精确的可编辑图层、时间轴关键帧或透明剪裁资产
- 精确的标志放置或可读字体
- 仅需要书面视频提示而不进行生成

## 默认创意目标

除非用户另有说明：

- 输出比例：16:9横向
- 片段长度：每个片段约4秒
- 音频默认：保留或生成触感纸艺拼贴音效，如纸张滑动、噼啪声、按压、轻微沙沙声和轻柔敲击声
- 默认：不添加背景音乐。当这可能有助于时，您可以询问用户是否需要背景音乐，但仅在用户明确确认后添加音乐
- 默认：不添加旁白、口语叙述或主持人叙述。当项目可能受益时，您可以询问用户是否需要旁白/口播，但在用户明确确认后，才进行撰写、合成或添加口语音频
- 默认：不添加字幕。当项目可能受益时，您可以询问用户是否需要字幕，但在用户明确确认后，才创建或嵌入字幕
- 视觉风格：高端编辑式半色调纸艺拼贴
- 运动风格：触感定格动画组装，不是慢速缩放、通用漂浮或平滑数字层运动
- 默认视频生成模型：`MiniMax-H3`，除非用户明确指定其他模型、模型不可用或硬性功能要求排除它
- 图像/视频中的文字：避免可读字母、数字、UI、字幕、水印和标志
- 图像质量和深度：优先考虑视觉吸引人、分层的16:9构图，具有清晰的 foreground、midground 和 background 深度，强烈的主题层次结构，丰富的场景设计，以及受控的负空间

## 音频策略

此技能的默认交付方式是**带有拼贴音效，不带有背景音乐、旁白或字幕**。

1. 在第一次生产计划确认时，明确说明默认媒体方法：保留或生成触感纸艺拼贴音效；默认不添加背景音乐、旁白/口播和字幕。
2. 可以询问用户是否需要**旁白叙述/口播**、**背景音乐**或**字幕**，特别是对于解释器，但将所有三项作为可选附加项，而不是默认项。
3. 不要推断解释器自动需要口语旁白。如果用户不选择旁白，则创建视觉故事节点，而不是旁白脚本。
4. 不要推断社交视频自动需要背景音乐或字幕。如果用户不选择它们，则保留片段音效。
5. 在生成视频片段时，如果选定的视频模型支持音频，请求同步触感拼贴音效：纸张滑落、噼啪声、压平、轻柔敲击和轻微纸张沙沙声。
6. 在最终组装期间，保留包含拼贴音效的原始片段音轨。默认情况下，不要丢弃音轨。
7. 仅在用户要求静音、生成的音频包含不需要的语音/音乐，或用户请求单独的音乐/旁白混音时，才移除或替换音频。仅在用户明确要求时，才创建字幕。

## 全局风格规则

将以下规则应用于项目中的每个静态图像和视频：

1. **统一整体视觉风格。** 每个片段都应感觉像是同一系列编辑式纸艺拼贴的一部分：半色调剪贴、平面色块、暖米色关键线、柔和物理阴影、干净构图、触感纸张材质和协调的拼贴音效。
2. **控制纸张纹理强度。** 纸张不能看起来完全平坦，但也不能变得过于陈旧、脏污、褶皱或发黄，除非用户明确要求。优先选择干净、精致的手工纹理：微妙的纤维、略微不规则的撕裂边缘、轻微的鱼鳞纤维、分层接缝和柔和阴影。
3. **统一色调。** 不要引入与批准的静态图像或批次调色板冲突的牛皮纸、棕色、泛黄或破损的基纸。从与批准的最终静态图像的主要颜色方向匹配的纸张字段开始每个片段。
4. **使运动看起来像定格动画拼贴。** 使用清晰的纸张片动作：逐片出现，滑入或噼啪声到位，轻轻弹跳，压平，暂停，然后锁定到最终构图。避免快速旋转、过度翻转、混乱的物体飞行、全局淡入淡出、平滑数字摇摄、缩放或通用漂浮。
5. **保持片段协调。** 一旦一个或两个片段建立了批准的批次风格和音效节奏，后续片段和修订应参考该节奏和色调，使整个序列感觉连贯。
6. **默认为抛光的16:9分层场景。** 除非用户明确请求其他平台框架，否则计划并生成16:9横向。使用更宽的画布构建吸引人的前景/中景/背景分离、更丰富的环境道具、清晰的主题层次结构，以及没有使画面变得杂乱的电影感横向构图。
7. **强调纸艺拼贴工艺。** 每个静态图像和片段都应使纸艺拼贴方法可见：可分离的纸张组、半色调摄影剪贴、彩色卡纸点缀、触感阴影、撕裂边缘、分层接缝和定格动画动作，如弹出、滑入、轻微弹跳、压平、暂停和锁定。

## 第1步：解析输入

对于每一行、概念、故事或主题，提取：

- 核心含义：观众应该理解什么
- 情感：平静、紧急、讽刺、惊讶、荒谬、澄清、反思、神秘或俏皮
- 动作动词：打开、连接、泄漏、存档、压缩、分裂、照亮、绑定、组装、揭示、落下、追逐、转换、碰撞
- 视觉隐喻：一个具体的图像，表达想法而不在屏幕上写脚本
- 关键物体：三到六个大型可读纸艺组
- 音频暗示：是否节奏受益于纸张滑动、噼啪声、按压、敲击、沙沙声或啪嗒声音效

对于故事主题，除非用户指定数量，否则将故事分成三到六个简洁的节点。相似的节点可以共享相同的设计语言，但每个节点应有独特的隐喻、物体集、色块和音效节奏。

## 第2步：关卡1 — 生产计划文档批准

在生成任何媒体之前，创建一份简洁的生产计划文档并等待用户批准。在用户确认此文档之前，不要生成静态图像或视频。

生产计划必须包括：

### 简报

- 主题或来源行
- 预期受众/使用上下文（如果已知）
- 画幅和持续时间假设
- 节奏和节奏
- 视觉风格摘要
- 媒体方法，声明为：默认拼贴音效保留或生成；除非用户明确要求，否则不添加背景音乐、旁白/口播和字幕
- 可选附加问题（当有用时）：询问用户是否需要旁白叙述/口播、背景音乐或字幕，但保持它们为可选

### 视觉隐喻

对于每个计划片段：

- 核心含义
- 情感
- 一句话视觉主张
- 三到六个关键物体
- 建议的背景颜色和强调色
- 预期的组装顺序
- 预期的拼贴音效时刻，如滑动、噼啪声、按压、敲击、沙沙声或啪嗒声

### 脚本/视觉节拍轨道

如果用户明确要求旁白，请撰写简洁的旁白脚本。如果用户没有明确要求旁白，则**不要**撰写旁白脚本；相反，请撰写无声的视觉节拍轨道，解释观众从序列中理解的内容。

如果用户只需要为现有行生成B-roll，请保留原始行作为上下文，而不是编造旁白。

### 故事板

对于每个片段，包括：

- 片段标题
- 最终帧描述
- 运动想法
- 大约持续时间
- 拼贴音效想法
- 风格连贯性和色彩和谐说明

在展示生产计划文档后，等待用户批准、拒绝或修订。如果用户只批准编号项目的一部分，请仅移动这些项目并修订其余部分。

## 第3步：构建静态图像规范

批准生产计划后，为每个批准的片段编写紧凑的视觉规范。规范应自包含且适合图像生成。

包括：

- 脚本含义或故事节点
- 视觉隐喻
- 画幅
- 背景色块
- 强调色
- 关键物体组和它们的作用
- 构图、前景/中景/背景深度和负空间
- 最终帧关系
- 风格连贯性说明
- 避免此特定静态图像的列表

使用此风格签名：

```text
平面大胆色块，黑白半色调摄影剪贴，选择性彩色卡纸点缀，暖米色关键线，柔和纸艺阴影，细未涂布纸张颗粒，高端编辑式纸艺拼贴，干净精致手工撕裂纸边，微妙纤维边缘，分层纸接缝
```

色彩指导：

- 烧焦橙色或红色：劳动、时间压力、紧急
- 芥末黄：工具、警告、累积错误
- 墨绿色：认知、重置、判断、超现实平静
- 深紫色：记忆、结构、神秘、梦境逻辑
- 青色：合作、执行、系统流程
- 玫瑰红：荒谬、仪式、戏剧性张力

不要将钴蓝色设为自动默认。通过纸张纹理、半色调处理、关键线、阴影、构图和受控调色板保持批次视觉统一。仅在故事节点受益于对比时才改变色块。

## 第4步：关卡2 — 生成并批准静态图像

为每个批准的片段生成一个最终静态图像。静态图像必须看起来像是未来动画的完成最后一帧。

静态图像要求：

- 使用用户指定的画幅；否则默认为16:9横向
- 平面大胆纸张背景，带有微妙纤维纹理
- 三到六个大型可分离物体组，除非批准的故事板需要稍多
- 清晰的中心主题，强烈的视觉层次结构，充足的干净负空间，以及可见的前景/中景/背景分层
- 黑白半色调摄影剪贴作为主要结构，结合丰富的场景道具，支持故事节点
- 仅在需要澄清层次结构时使用选择性彩色卡纸点缀
- 暖米色关键线、柔和物理纸艺阴影、精致撕裂边缘和微妙分层纸接缝
- 除非明确要求，否则不包含可读文字、假字母、数字、字幕、UI、水印或标志

将生成的静态图像展示给用户并等待批准，然后再进行视频生成。如果静态图像看起来太忙、颜色不匹配、纸张层太多、数字边缘太平坦或纸张纹理过于陈旧/发黄，请在视频生成前修订静态图像。

## 第5步：规划定格动画组装

对于每个批准的静态图像，准备一个运动计划，将批准的静态图像视为完成的最终帧。

默认运动顺序：

1. 从与批准的静态图像的主要背景颜色和色调匹配的干净纸张色块开始，而不是不匹配的牛皮纸或棕色基纸。
2. 基本结构作为滑入、噼啪声或压到位的纸张片出现。
3. 角色或卡纸、物体或主要隐喻元素进入。
4. 次要物体逐个组装，带有小弹跳、压平和暂停节拍。
5. 最终关系锁定到批准的构图。
6. 在动画结束时，短暂地保持完成后的类似静态图像帧。

运动提示指导：

```text
纸艺拼贴定格动画组装。从与批准的静态图像的背景颜色和色调匹配的干净纸张字段开始。逐片组装场景，使用触感定格动画时间：前景、中景和背景纸艺组按可读顺序出现；每个纸艺物体出现，滑入或噼啪声到位，轻微弹跳，压平，暂停，并锁定到位。保留半色调点、米色关键线、微妙纤维撕裂边缘、分层纸接缝、柔和阴影、纸张颗粒、色块和批准的画幅。结束并保持与批准的静态图像帧匹配的完成构图。音效设计：仅触感拼贴音效，与纸张片运动同步：轻柔纸张滑动、噼啪声、压平敲击、轻微沙沙声和适当的地方纸张啪嗒声。默认：不添加背景音乐、旁白、对话或字幕，除非用户明确要求。不要有牛皮纸开场，不要有棕色/泛黄基纸，除非批准，不要有快速旋转，不要有混乱的物体飞行，不要有平滑数字层运动，不要有场景切换，不要有摄像机移动，不要有缩放，不要有变形，不要有新物体，不要有文字，不要有标志，不要有水印，不要有UI。
```

## 第6步：生成拼贴音效B-roll片段

在关卡2批准后，为每个批准的静态图像生成一个视频片段。

生成要求：

- 使用批准的静态图像作为视觉参考/最终帧锚点，只要选定的Hub视频模型支持
- 使用与静态图像相同的画幅
- 目标约为四秒，除非用户请求不同长度
- 默认生成或保留触感拼贴音效，当支持时：纸张滑动、噼啪声、压平敲击、轻微沙沙声、轻微啪嗒声
- 默认：不生成或添加背景音乐，除非用户明确要求音乐
- 默认：不生成或添加旁白、口语叙述或主持人音频，除非用户明确要求旁白/口播
- 如果生成的片段包含有用的拼贴音效，请在后期制作和最终组装期间保留它
- 如果生成的片段包含不需要的语音、音乐、假UI声音或嘈杂的环境音，请根据用户目标移除或重新生成音频
- 保持镜头视觉稳定；除非用户要求，否则不要添加摄像机移动
- 保留拼贴材质语言、最终构图和已建立的批次风格
- 在修订后续片段时，如果有助于风格/节奏参考，可以使用最佳批准的先前片段

使用 `MiniMax-H3` 作为此技能的默认视频生成模型。除非 `MiniMax-H3` 失败、不可用或无法满足硬性功能要求，否则不要要求用户选择模型。如果用户明确指定了另一个模型，请将该模型作为主要模型，并在需要时仅调整参数。

- 象征性隐喻或故事情节无需在屏幕上书写
- 静帧具有强烈的纯净色域，默认的16:9构图吸引人，对象层级清晰，前景/中景/背景深度可见
- 对象组数量保持可读性，不会满屏碎片化
- 影片从与批准的静帧或批量调色板匹配的色域开始
- 组装过程逐个可见，而非全局淡入
- 动作呈现为定格动画拼贴：单独的纸张组弹出或滑入，轻微弹跳，压平，暂停并锁定
- 默认：触感拼贴音效是理想的；背景音乐、旁白/口播和字幕在未明确要求的情况下不出现
- 纸张纹理受控：不过于扁平，不过于陈旧，除非批准，否则不使用棕色/牛皮纸
- 色调在批量中保持一致
- 最终帧应接近批准的静帧
- 不应有任何可读的无关字母、假UI、字幕、水印或标志

如果象征性隐喻保持清晰且最终构图仍与批准的静帧相似，细节上的微小偏差是可以接受的。重大偏差、添加文本、假UI、不匹配的开场色、不想要的牛皮纸基底、过度褶皱/脏污的纸张纹理、丢失的定格动画组装、不想要的背景音乐或旁白应根据问题出现的位置进行重新生成或后期处理。

## 第8步：可选组装、音乐、旁白和交付

如果用户要求多片段故事视频，请按照确认的故事板顺序组装批准的片段，并默认保留每个片段的原始拼贴音效。

仅在明确要求时添加背景音乐、旁白/口播或字幕。当用户在片段已存在后要求背景音乐或旁白时，将其与拼贴音效混合，而不是替换音效，除非用户要求静音原始音效。

对于每个完成的项目，交付：

- 最终B-roll视频路径或最终组装视频路径
- 相关的批准静帧路径
- 一句话解释脚本或视觉节奏如何成为视觉隐喻
- 媒体说明：默认拼贴音效，并列出任何明确要求的背景音乐、旁白/口播或字幕添加
- 任何QA备注，如果片段因微小可接受的偏差而通过

对于批量工作，按项目编号分组输出，并将用户的原始行或故事情节与其结果附在一起。

## 故障处理

- 如果生产计划默认为无声视频，除非用户明确要求，否则将其更正为仅拼贴音效。
- 如果生产计划包含背景音乐、旁白/口播或字幕而没有明确用户请求，请移除它们，并将背景音乐、旁白/口播和字幕作为可选选项呈现。
- 如果生产计划感觉过于字面化，请返回第1关卡，使视觉提案更具对象驱动性。
- 如果静帧包含假文本或UI，请在视频生成前重新生成静帧；不要仅尝试在视频提示中修复它。
- 如果静帧或片段过于视觉繁忙，减少纸张层数，简化对象数量，并恢复负空间。
- 如果视频缺乏组装动作，减少对象数量，并使逐步到达顺序更加明确。
- 如果动作感觉像平滑的数字层，请围绕定格动画节奏重写提示：出现→轻微弹跳→压平→暂停→锁定。
- 如果纸张看起来过于扁平，请添加微妙的撕裂边缘、纤维纹理、分层接缝和柔和阴影。
- 如果纸张看起来过于陈旧或脏污，请移除牛皮纸、棕色/发黄基底、严重褶皱、污渍和磨损处理。
- 如果开场色与批准的静帧冲突，请从与静帧相同的主背景色开始。
- 如果最终帧与静帧偏差过大，请加强指示，批准的静帧是完成的最终构图。
- 如果生成的音频缺少拼贴音效但视觉效果其他方面很强，请询问用户是否保留，重新生成更强的音效方向，或添加/后期同步音效。
- 如果生成的音频包含不想要的背景音乐或旁白，请在最终交付前移除或重新生成它。
- 如果需要精确的层控制，建议使用分层动画或编辑工作流程，而不是继续此技能。
