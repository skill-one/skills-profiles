# 极简产品广告生成器

使用此技能引导非专业用户通过流程式工作流，创建极简风格的产品广告视频，用于电商推广和产品发布。目标用户是电商卖家、小品牌主、独立创作者和个体卖家；用户应至少提供一张产品图片或相关素材。

核心原则是：**先确认素材和简报，构建产品事实和产品叙事主轴，用独立的锚点照片锁定产品视觉效果，用精准的节拍故事板控制视频，然后用原生音频或基于音乐进行剪辑来完成影片。** 此技能不再默认使用4格锚点表，因为视频模型可能会复制面板布局。默认使用三张独立的锚点照片加上一个精准的节拍文本故事板作为视频控制系统。

## 启动门

每次触发此技能时，在任何分析、文案撰写、锚点生成或视频生成之前，运行一个完整但轻量级的启动门。只确认生产所需的信息。在此处不询问音乐；音乐将在后续的音乐步骤中处理。

启动门必须一次性确认以下所有信息：

1. **产品图片和相关素材**
   - 要求用户上传产品图片和相关素材，例如产品照片、包装图片、渲染图、细节照片、现有视频素材或视觉参考。
   - 如果当前消息或当前画布/会话中已经包含素材，则说明已检测到素材。不要再次要求用户上传；只需确认是否使用当前素材。
   - 如果有多个候选素材且其角色不明确，询问哪一张应该是主要产品图片。

2. **产品变体状态**
   - 确认这是单一变体还是多个变体/颜色/型号。
   - 如果有多个变体，确认哪个是主要变体。
   - 如果用户没有指定，代理可以根据产品图片推荐一个，但后续故事板仍需写明具体颜色或变体名称。

3. **目标时长**
   - 5秒 / 10秒 / 15秒，推荐默认为10秒。

4. **宽高比**
   - 16:9 / 9:16 / 1:1 / 4:3 / 3:4 / 匹配参考图片。
   - 一旦选定，锚点表、视频和最终交付必须严格保持此比例。

5. **苹果风格模板**
   - 白色科技 / 暗边光 / 品牌色域 / 轻生活方式场景。

6. **画框内文案**
   - 用户提供的文案，或代理生成的苹果风格英文文案。

7. **视频模型策略**
   - 默认模型是MiniMax-H3，因为它通常能生成更干净的苹果风格产品特写、负空间和高端产品电影相机语言。
   - 在启动门期间不要要求用户选择视频模型。将“默认模型：MiniMax-H3”作为采用启动门结果的一部分显示。
   - 如果用户明确要求其他模型，在能力检查后遵循用户的选择。
   - Seedance仅在用户明确要求更强的多镜头执行、要求Seedance或接受H3失败或无法满足请求结构后的回退时才作为备用。

启动门是强制性的。如果用户已经上传了产品素材，只需跳过上传请求；**不要**跳过其余的启动门。代理必须在分析、锚点生成、故事板或视频生成之前，一次性确认产品变体状态、目标时长、宽高比、苹果风格模板和画框内文案。视频模型不是启动门问题：默认使用MiniMax-H3并显示在完成的启动门结果中。如果用户说“你决定 / 就做吧”，代理可以为其余字段选择推荐默认值，但必须在继续之前显示采用的选项作为完成的启动门结果。

## 运作原则

1. **独立的锚点照片是默认的视觉控制系统**
   - 默认生成三张独立的锚点照片，而不是一张4格表，因为视频模型可能会复制面板布局到最终影片中。
   - 三张锚点照片通常涵盖：主角/引人注目的主视图、材料或功能细节，以及最终文案构图。
   - 不要创建单独的结构-动作锚点，除非它与主角视图重叠。除非产品确实需要一个独立的机制参考，否则将结构/动作提示合并到材料细节锚点中。
   - 每张锚点照片必须是一张完整独立的 产品照片。不要创建网格布局、分屏、拼贴板、带框面板、产品墙或故事板表。
   - 精准的节拍故事板决定实际拍摄顺序、动作和文本行为。不要使用锚点照片作为直接拍摄替代。

2. **画框内文案必须作为集成视频运动出现，而不是字幕回退**
   - 文案锚点照片中的文本仅是字体、位置、单行布局和两段式颜色处理的参考。这意味着整个视频不能只使用这一行文案。
   - 精准的节拍故事板可能定义跨镜头的多个简短英文文案行。每行必须为3-5个英文单词，单行，可读，并遵循两段式颜色规则：在白色科技风格中，前半部分使用黑色或深灰色；在暗边光风格中，前半部分可以使用白色，后半部分始终使用具体的产品颜色。不要使用孤立的1-2个单词的特征标签。
   - 视频生成必须包含故事板文案在画框内。
   - 文案不需要出现在每个镜头中。如果视频模型倾向于使排版出错，应主动减少文案频率。对于10秒的影片，通常只保留一个中段文案时刻和一个最终文案时刻；不要在每镜头中放置文本。最终镜头必须包含一条稳定的单行文案。
   - 默认情况下，要求视频模型直接生成画框内排版及其时间。不要将文本无声地降级为后期制作字幕或预留空位以供后期叠加。仅在用户明确要求或集成视频排版失败且用户接受回退时才使用后期制作回退。

3. **产品主体颜色是硬性保真度约束**
   - 苹果风格意味着干净的构图、高端光线、克制的运动和负空间；**不**意味着将产品本身变成白色、银色或AirPods风格。
   - 产品的原始主体颜色、强调色、材料色调和用户图片中可见的表面处理必须在所有锚点照片和视频中保留。
   - 只有背景、照明环境和构图可以转向所选的苹果风格模板。**不要**重新着色产品主体，除非用户明确要求。
   - 最终文案强调色必须来自真实的产品主色，而不是通用的银色/白色苹果调色板。

4. **每个产品都需要一个产品特定的叙事**
   - 不要重用一个固定的耳塞模板或写模糊的短语如“产品状态变化”。
   - 故事板必须基于产品类别、形状、材料、结构以及可见动作。
   - 产品运动必须视觉化和具体，例如“盖子打开30度，内部反射出现”，或“旋钮旋转时，高亮沿边缘滑动”。

4. **进度必须可见**
   - 每一步之后，显示已生成的内容和下一步需要做出的决策。
   - 不要未经用户确认就自动运行整个流程。

## 排版规则

- 画框内广告文案必须为英文。
- 如果用户提供中文文案，将其翻译成简洁的英文或请求批准英文版本。
- 可见的画框内文案必须为3-5个英文单词，最好不超过32个英文字符（包括空格）。不要写孤立的1-2个单词的特征标签。
- 文案应感觉像苹果产品电影：感官化、利益导向、材料导向或轻价值主张；避免促销口号和电商特征标签措辞。
- 字体参考：SF Pro Display / SF Pro Text。在提示中优先使用`SF Pro Display Semibold`。
- 每个镜头最多使用两种文本颜色。
- 在白色科技风格中，前半部分使用黑色或深灰色；白色文本禁止在白色背景上。在暗边光风格中，前半部分可以使用白色。后半部分始终使用具体的产品颜色。
- 文本必须保持在一条线上。不要换行、堆叠或分成多行。
- 任何时候画框内只能出现一条单行英文文案。不要显示两行文本、两行标题、标题+副标题对或同时出现多个文本块。两段式排版必须在同一条线上继续或替换，永远不会分成上下行。
- 不要将文本放在字幕位置。优先选择垂直居中的视觉区域，作为构图的一部分左对齐或右对齐。文本应稍大，感觉像产品电影视觉元素，而不是解释性字幕。
- 批准的中段模式：干净的负空间，产品运动或产品特写引导画框，画框保持不拥挤，仅出现一条单行英文文案。文本可以靠近产品边缘、产品表面或特写高亮区域，使其感觉像产品图像的一部分而不是像字幕一样漂浮。不要破坏负空间或添加第二个文本块只是为了添加文案。
- 默认的两段式文本运动必须保持可见：前半部分先淡入或微妙滑入，然后后半部分稍后淡入或微妙滑入。当后半部分出现时，前半部分在同一行内轻微移动以腾出空间。
- 移动应微妙，约10-15像素或文本宽度的8-12%。运动应平滑且克制；避免弹跳、霓虹或花哨的UI效果。
- 不要使排版完全静态，仅仅为了避免两行文本。正确的解决方案是同行两段式入场、微妙移动、淡入或轻柔滑入；错误解决方案是上下行分割、两行标题或移除文本运动。

## 第1步：素材检查和产品事实摘要

如果产品素材不可用，要求用户上传。如果素材已经可用，则使用它并分析：

- 产品类别。
- 主体位置和画面占用。
- 图片质量：清晰度、照明、构图和可见细节。
- 产品主色和可能的主变体。
- 可展示的结构：打开、旋转、抬起、弹开、折叠、弹出、发光、屏幕、纹理等。
- 可用于故事板的实际外观特征：材料、边缘、按钮、端口、包装、透明部分、屏幕或独特的轮廓。

如果图片质量不可用，停止并给出具体的重拍建议。

输出简短的产品事实摘要：

- 使用的素材。
- 产品类别。
- 主色候选和主变体建议。
- 质量通过/失败。
- 可展示的结构/特征。

## 第2步：确认生产简报

将启动门答案转化为可执行的生产简报。不要再次询问已经确认的参数。简报驱动叙事主轴、文案、锚点表和故事板。

生产简报必须包括：

- 使用的产品素材。
- 主要变体/产品主色。
- 宽高比。
- 目标时长。
- 选择的苹果风格模板。
- 单一变体/多变体策略。
- 画框内文案模式：用户提供的文案，或代理生成的苹果风格英文文案。

多变体产品规则：

- 用户选择风格；不要自动移除所有其他变体。
- 每个多变体项目必须首先决定一个主要变体。
- 其他变体不应在非常开始时全部出现；它们仅在过程节拍、过渡或最终完整集中出现。
- 如果用户没有指定主要变体，代理可以选择最视觉稳定的变体，并使用其他变体进行节奏和分层。
- 避免电商矩阵、九宫格显示、堆叠、分散布局、所有颜色平铺或全屏产品墙。

## 第3步：选择产品叙事主轴

在文案撰写和锚点生成之前，选择一个轻量级的产品叙事主轴。不要使用广泛的企业品牌电影结构；此技能专注于为实体产品制作短苹果风格电影。

如果用户没有选择方向，提供2-3个简洁的方向，推荐一个，并在确认后继续。如果用户说“你决定”，使用推荐的。

推荐的骨架：

1. **产品发布**（默认推荐）
   - 负空间开场 → 主变体建立主角视图 → 材料/结构细节 → 自然产品动作 → 变体或颜色关系 → 全文案收尾。
   - 适合耳塞、手表、数字配件、小型家电、香氛设备等。

2. **特征触点**
   - 产品静止 → 交互触发 → 特征动作 → 细节放大 → 结果/感觉 → 收尾帧。
   - 适合有明显打开、旋转、磁吸弹开、光变、屏幕、折叠、雾气或类似动作的产品。

3. **颜色系列**
   - 主变体单独出现 → 支持变体轻柔滑入 → 颜色顺序形成 → 材料和结构保持统一 → 完整集收尾 → 文案落地。
   - 适合多色、多变体或多型号产品。

输出一句描述所选叙事主轴的句子，例如：

> 此影片使用颜色系列骨架：紫色主变体建立主角视图，其他颜色作为支持层进入，完整产品集收尾时出现英文文案。

## 第4步：指导运动语言

在文案撰写和锚点生成之前，定义影片的运动语言。此步骤不生成资产；它定义运动强度、过渡逻辑和后期故事板的节奏峰值。

规则：

1. **过渡由真实产品或视觉元素驱动**
   - 优先选择产品边缘、材料高亮、打开/旋转/弹开/滑动动作、变体排列中的几何变化、颜色进入和退出、匹配的相机方向或匹配的产品轮廓。
   - 不要使用无意义的白光闪烁、抽象粒子、随机光效或随机剪辑来伪造高端运动。

2. **每节拍一个主要动作**
   - 次要元素应稍晚出现，并且不应在同一时间争夺注意力。
   - 示例：产品先进入，然后文本出现；主变体先稳定，然后支持变体滑入；材料高亮先扫过，然后文本运动开始。

3. **设置强烈的安静时刻**
   - 5秒影片：1个小高峰 + 1个稳定收尾。
   - 10秒影片：1-2个高峰 + 1-2个刹车时刻。
   - 15秒影片：2-3个高峰 + 2个安静刹车时刻。
   - 高峰可能是产品动作完成、变体进入、后半部分文案揭示或完整产品收尾。
   - 刹车时刻可能是材料细节暂停、可读文案保持或最终帧保持。

4. **保持安全空间清晰**
   - 产品轮廓保持清晰，单行文案保持可读，主要变体不被遮挡。
   - 仅在用户提供时才添加标志。不要生成假标志。

5. **避免虚假科技装饰、镜像白舞台和空洞的开场**
   - 避免虚假科技界面、无意义的玻璃卡片、装饰性文字墙、未经证实的指标、随机粒子效果和堆叠灯光效果、全片使用相同缓动风格，以及全屏产品墙。
   - 白科技风格不是镜像白舞台，也不是死板的白色照明。不要将产品放置在反光地板、玻璃桌子或廉价工作室镜面上。
   - 苹果风格的白色空间应该是简单的白色背景；冲击力来自引人注目的产品角度、真实的产品动作、摄像机节奏和负空间构图，而不是镜像反射或等待在空洞的画面中。
   - 开场不能是空洞的死时间。应快速展现吸引人的产品动作或角度，例如产品从其结构中平滑旋转出来、从开合机构中浮现、沿轮廓滑动，或通过边缘高亮显示。具体动作应根据当前产品形态推断，而不是硬编码到耳塞上。

输出一个简短的“运动语言”声明，例如：

> 此片使用产品边缘高亮和紫色主变体滑动动作驱动转场。主要峰值是变体入场和全屏落地，产品和文案以稳定最终状态结束。

## STEP 5: 生成或确认苹果风格英文文案

在生成文案锚点和故事板之前，获取该帧的最终英文文案行。

规则：

1. 分析产品类别、使用感受和叙事主轴。
2. 生成2-3个苹果风格的英文选项，每个3-5个词。
3. 不要使用固定模板或固定口号；为每个产品推断新的文案。
4. 避免促销性语言。
5. 如果用户已有文案，优先使用。中文文案必须本地化为简洁的英文。

用户确认文案后，继续锚点生成。如果用户说“你决定”，选择推荐文案并继续。

## STEP 6: 生成三个独立的产品锚点照片

生成**三个独立的锚点照片**，与用户选择视频设置的相同宽高比和分辨率。必须是三个分开的图像输出，而不是一个组合的3面板或4面板图。背景遵循所选风格，且三个照片必须共享统一的光影、等级和背景语言，同时保持独立的产品照片。

锚点照片角色：

- 照片1：主角/引人注目的主视图锚点，锁定最吸引人的产品视图、轮廓和开场视觉方向。避免以丑陋的极端材质特写作为开场参考。
- 照片2：材质/功能细节锚点，锁定表面材质、纹理、反射、触感质量，以及最重要的可见机制或结构。如果产品需要开合、对接、折叠、卡扣、按钮、端口、盖子、屏幕或触摸提示，将这些提示合并到这张照片中。
- 照片3：最终文案锚点，锁定最终产品构图、字体感受、文本位置、单行布局和两段式色彩处理。文案是格式参考，并不限制后期视频仅使用这一行。

多变体处理：

- 锚点照片必须继承所选叙事主轴和风格策略。
- 照片1/2优先围绕主变体构建视觉系统。
- 其他变体仅支持节奏；不要将所有内容扁平化或填满画面。
- 照片3可以显示主变体加上几个支持变体，或一套完整的收尾构图，但必须保留负空间和顺序。

最终文案锚点排版规则：

- 必须包含步骤5确认的文案；不要使用占位符文案。
- 文本必须保持在单行上。
- 字体：SF Pro Display Semibold。
- 文本颜色必须明确分为两部分：文案前半部分使用黑色或白色，后半部分使用具体的产品主色。例如，主色为紫色时，写“前半部分黑色/白色，后半部分紫色”。不要只写“产品色+黑色或白色”。
- 照片3可能只包含此格式参考的文案行，不包含其他文本；但后期视频文案受精确节拍故事板的控制，可能包含多个简短英文文案行。

展示三个独立的锚点照片，并要求用户批准、编辑或重新生成特定照片，然后再进行精确节拍故事板。

## STEP 7: 精确节拍和文本故事板表格

在生成任何视频片段之前，创建并回顾精确节拍文本故事板表格。这不是艺术作品；它是视频模型的执行表格。

故事板表格必须按“用户选择声明→节拍内容→原则”组织。

### 用户选择声明

写明确认的风格、宽高比、时长、叙事主轴、主变体、产品主色、变体策略和文案。示例：

> 白科技风格，16:9，10秒，色彩家族主轴，紫色为主变体，其他颜色为支持层，文案：色彩相遇声音。

### 节拍内容表格

推荐列：

| 时间范围 | 拍摄 | 拍摄目的 | 视觉引导 | 视觉/摄像机动作 | 变体状态 | 文案 | 文本颜色 | 文本效果 | 转场/连续性 | 节奏意图 |
|---|---|---|---|---|---|---|---|---|---|---|

表格规则：

- 5秒建议3-4个节拍。
- 10秒建议5-7个节拍。
- 15秒建议6-9个节拍。
- 使用秒作为时间范围；不要要求帧数。
- 保持每个节拍一个主要动作；次要层稍晚出现。
- 明确定义主变体单独出现、支持变体进入和全套闭合的时间点。
- 文案分割仅能以“前半部分/后半部分”的 plain language 描述。不要写箭头、斜杠、加号或分隔符，因为模型可能将它们渲染为画面内文案。
- 文本颜色必须使用具体的产品色名，并在白科技风格中写“前半部分黑色或深灰色，后半部分具体产品色”；仅在暗边缘照明风格中前半部分可以是白色。例如，在白科技风格中，主色为紫色时，写“前半部分黑色或深灰色，后半部分紫色”。不要写“产品色+黑色或白色”。
- 如果排版易出错，先减少文本节拍：对于10秒视频，通常只使用一个中段文案时刻和一个最终文案时刻，其他节拍标记为无文案。不要在每个拍摄中都放文案。
- 最终节拍必须是一个稳定的单帧产品闭合+单行文案。永远不要以四面板、分屏、故事板板、锚点表布局、产品窗格或框架网格结束。文案仍属于垂直居中的构图区域，作为框架的一部分左对齐或右对齐，而不是在字幕位置。用户提供时才添加标志。

节奏意图词汇：设置、建立、准备、冲击、刹车、稳定。

### 原则

1. 核心文本保持在单行上。
2. 任何时候，仅允许出现单行英文文案；禁止两行文本、上/下行分割、标题+副标题对，或同时出现多个文本块。
3. 使用两种文本颜色：黑色或白色+确认的具体产品色。
4. 文本必须出现在视频内；不要仅依赖后期制作备用方案。
5. 拍摄连续性=元素连续性+动作连续性+形式连续性。
6. 平滑度=缓动+无尴尬时间+无缝进入和退出。
7. 总节奏遵循用户选择的时长。
8. 文本动作必须可见：前半部分先淡入或微妙滑入，后半部分稍晚淡入或微妙滑入。当后半部分出现时，前半部分在同一行内微妙移动以腾出空间。不要使文案完全静态，也不要将其分割为上/下行。
9. 如果风格已确认，表格必须严格遵循该风格。

用户确认故事板表格后，继续视频生成。

## STEP 8: 视频生成

直接从确认的三个独立锚点照片+精确节拍文本故事板表格生成视频。视频风格、背景、照明、情绪和节奏遵循所选风格。宽高比和尺寸必须严格遵循用户选择的设置；如果用户选择16:9，生成16:9，不要自动改为其他比例。

视频参考规则：

- 在视频生成过程中，不要将原始产品图像传递给视频模型。
- 原始产品图像仅用于产品分析和锚点生成。
- 使用三个独立锚点照片以保持产品一致性、主角视图、材质/功能细节、最终构图和排版布局。
- 创意控制来自精确节拍故事板：拍摄顺序、产品动作、文案、文本动作、连续性和转场。
- 锚点照片仅作为产品锚点，用于保护身份、主体色、材质和布局。永远不要将它们视为故事板本身，也永远不要将三个照片变成三个连续的视频片段。
- 视频输出必须是一个连续的全帧广告片。不要显示四面板、分屏、拼贴布局、框架、故事板板、网格布局或任何在视频内重现锚点表布局的拍摄。这对结尾尤其重要：永远不要回到网格、故事板板、小窗口蒙太奇或产品墙。
- 默认为单个H3全帧产品片，不是多个第一帧片段，除非用户明确要求不同结构。
- 视频生成默认使用MiniMax-H3原生音频，除非用户明确要求其他模型或静音。使用后期苹果风格科技BGM方向作为音频提示，使画面节奏和声音同步生成。

视频提示必须包括：

- 三个独立锚点照片和每个照片的角色。
- 完整的精确节拍故事板表格；逐个节拍阅读并重写每个节拍到视频提示中。不要仅总结早期节拍或省略后期排版、变体或收尾要求。
- 确切的文案行。视频提示必须逐字拼写每个画面内文案行、其时间窗口、前半部分/后半部分进入时间、颜色和单行行为。不要仅依赖故事板表格，也不要总结为“文案节拍同步”或“留出文案空间”。
- 提示完整性检查：如果最终视频生成提示未包含每个预期英文文案行，任务未准备好派发。重写提示后再进行视频生成。
- 单行排版硬约束：任何时候，画面内仅允许出现单行英文文案；禁止两行、两行标题、标题+副标题对或同时出现多个文本块。如果排版易出错，减少文案频率而不是在每个拍摄中都放文案。
- 两段式文本动作规则：前半部分和后半部分必须在同一行内继续或替换，永远不会分割为上/下行；动作必须可见，前半部分先淡入或微妙滑入，后半部分稍晚淡入或微妙滑入，同时前半部分在同一行内轻微移动。不要使排版完全静态。
- 拍摄连续性硬约束。
- MiniMax-H3原生音频设置和音乐提示；默认开启原生音频，除非用户明确要求静音或另一模型。
- 不要传递原始产品图像。

## STEP 9: music-2.6 科技BGM

视频生成默认首先使用MiniMax-H3原生音频，苹果风格的科技BGM方向应写入视频提示。如果H3的原生音乐不悦耳、音量过大、音量过小、不同步，或用户要求新音乐，使用`music-2.6`生成更长的独立器乐BGM并替换视频音频轨道。不要默认使用ElevenLabs；仅在用户明确要求严格目标时长时使用ElevenLabs，并遵循费用确认规则。

默认音乐方向：

```text
约100 BPM，快速科技感，块和弦，拨弦和空灵感床，底鼓+低音炮+正弦波，木制打击乐，突然切断，0.5秒内一切停止，仅留下拨弦尾音衰减。
```

扩展解释：

- 科技感，苹果风格，产品发布感。
- 允许节奏驱动，但不能变成廉价EDM。
- 拨弦应清晰、愉悦、向前；空灵感床应感觉高端。
- 底鼓和低音炮用于编辑点；避免低沉的贝斯。
- 木制打击乐增加触感纹理，不是复杂的鼓点循环。
- 无人声，无合成波，无复古，无游戏，无廉价企业股票音乐。

## STEP 10: 音乐分析、节拍同步编辑和交付验证

在最终交付前，根据音乐分析编辑或组装。不要简单地将音乐放在视频下。

音乐分析：

- 检测节奏、强拍、能量段和清晰的单音击打。
- 找到一个8-12秒的连续声音段，能量适合产品展示。
- 不要盲目使用前10秒。
- 优先选择一个有明确入口点、后半部分无沉默或崩溃、且足够稳定时间用于闭合帧的段。

音频组装规则：

- 保持视频图像，剪辑连续音乐段，替换视频音频轨道。
- 静音原始视频轨道；仅保留新音乐。
- 控制音乐音量：不要最大化音量，不要使用侵略性限制，不要将音乐音量调得过高；但也不要调得太低以至于拨弦、节奏点和产品展示失去清晰度。
- 不要使用长淡出。仅在需要时应用0.1-0.3秒的尾音淡出。
- 组装后，检查长沉默或可闻的掉线。

预交付验证：

- 视频宽高比、时长和语言与简报匹配。
- 产品外观、主变体和变体时间与锚点表和故事板匹配。
- 文案可读、单行、不拥挤，不包含额外箭头或符号；不出现两行文本、上/下分割、标题+副标题对或多个文本块同时出现。
- 最终帧有稳定的产品+文案闭合。
- 音乐音量不过高也不过低。
- 输出在画布上，多资产输出分组。

交付包括：

- 最终视频路径或画布输出。
- 时长、宽高比和语言。
- 简短创意摘要。
- 使用的文案和音乐段。
- 是否应用了节拍同步编辑。
- 具体的后续改进，如节奏、文案、主变体、音频或平台裁剪。

## 失败处理

- 产品图像太弱：停止，提供重拍指导，等待更好的图像。
- 文案过长：压缩为3-5个英文词并请求批准。
- 文本锚点错误：在视频生成前重新生成文本锚点。
- 锚点表产品保真度失败：使用更强的产品保护指令重新生成。
- 故事板模板化：回到精确节拍表格，根据产品形态和叙事主轴重写。
- 文案未出现在视频中：重新运行视频提示，明确要求至少在中段和最终节拍出现文案。
- 视频排版变形：重新生成文本锚点或降低文本拍摄为基于锚点的微妙动作。
- 宽高比错误：立即使用用户选择的宽高比重新运行。
- 音乐质量差：重试`music-2.6`，不要强求时长，从较长轨道中剪辑最佳段。
- 最终组装后半部分无声：重新分析音乐，选择连续可闻段，使用直接音频替换。
