## 广告文案框架

### AIDA 框架
```
引起注意 → 激发兴趣 → 激发欲望 → 促使行动

示例:
A: "正在为 [问题] 烦恼吗？"
I: "我们的 [产品] 帮助 [目标用户] 实现 [利益点]"
D: "[社会证明] + [独特价值]"
A: "[行动号召] - [紧迫性/优惠]"
```

### PAS 框架
```
问题 → 激化问题 → 提供解决方案

示例:
P: "厌倦了 [痛点]？"
A: "每天，[更糟糕的情况]。[情感影响]。"
S: "[产品] 通过 [机制] 解决这个问题。[行动号召]"
```

### BAB 框架
```
之前 → 之后 → 过渡

示例:
B: "之前: [当前状态]"
A: "之后: [期望状态]"
B: "过渡: [你的产品] 使其成为可能。[行动号召]"
```

## A/B 测试变体

### 生成测试变体

```yaml
ab_test_strategy:
  要测试的元素:
    - 标题: 情感 vs 理性
    - 行动号召: 软性 vs 硬性
    - 社会证明: 数字 vs 评价
    - 紧迫性: 稀缺性 vs 截止日期
    - 利益点: 主要 vs 次要
  
  变体生成:
    - 每个广告组: 3-5 个变体
    - 测试时长: 最少 7-14 天
    - 统计显著性: 95%
    
  示例变体:
    标题测试:
      A: "首次订单节省 50%"  # 优惠导向
      B: "加入 10,000+ 满意客户"   # 社会证明
      C: "停止在 [X] 上浪费金钱"      # 问题导向
    
    行动号召测试:
      A: "免费开始"               # 低承诺
      B: "立即获取优惠"            # 紧迫性
      C: "了解如何使用"               # 好奇心
```
