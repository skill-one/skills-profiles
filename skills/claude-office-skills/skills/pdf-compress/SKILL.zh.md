# PDF 压缩

减小 PDF 文件大小，以便更轻松地共享、更快地加载和高效存储。

## 概述

此功能可帮助您：
- 显著减小 PDF 文件大小
- 平衡质量与文件大小
- 针对特定用例（网络、打印、存档）进行优化
- 批量压缩多个文件
- 了解压缩的权衡

## 如何使用

### 基本压缩
```
"压缩此 PDF 以减小文件大小"
"使此 PDF 更小以便通过电子邮件发送"
"优化此 PDF 以便在网络上查看"
```

### 带目标压缩
```
"压缩此 PDF 至小于 5 MB"
"至少减小 50% 的文件大小"
"优化为最小文件大小"
```

### 质量级别
```
"使用高质量压缩（最小损失）"
"为屏幕查看压缩"
"最大压缩，质量不重要"
```

## 压缩级别

### 预设
| 级别 | 目标用途 | 图片质量 | 大小减小 |
|-------|------------|---------------|----------------|
| **最小** | 存档 | 原始 | 5-15% |
| **低** | 打印 | 接近原始 | 15-30% |
| **中** | 通用用途 | 良好 | 30-50% |
| **高** | 电子邮件/网络 | 可接受 | 50-70% |
| **最大** | 仅预览 | 减小 | 70-90% |

### 用例推荐
| 用例 | 推荐级别 | 理由 |
|----------|-------------------|--------|
| 打印生产 | 最小/低 | 质量关键 |
| 电子邮件附件 | 中/高 | 平衡大小/质量 |
| 网络下载 | 高 | 快速加载 |
| 快速预览 | 最大 | 速度优先 |
| 存档 | 低 | 长期质量 |
| 演示文稿 | 中 | 屏幕上良好 |

## 压缩技术

### 图片优化
```markdown
## 图片压缩设置

### 分辨率降低
| 目标 | DPI | 用途 |
|--------|-----|---------|
| 屏幕 | 72 | 网络查看 |
| 电子书 | 150 | 数字文档 |
| 办公室打印 | 200 | 基本打印 |
| 专业打印 | 300 | 职业打印 |
| 原始 | N/A | 无降低 |

### 格式转换
| 从 | 到 | 节省 | 质量影响 |
|------|-----|---------|----------------|
| TIFF | JPEG | 70-90% | 有些损失 |
| PNG | JPEG | 50-80% | 有些损失 |
| BMP | JPEG | 90%+ | 有些损失 |
| JPEG | JPEG（重新压缩） | 20-50% | 累积损失 |

### 质量级别
| 设置 | JPEG 质量 | 视觉影响 |
|---------|--------------|---------------|
| 最大 | 90-100 | 难以察觉 |
| 高 | 75-89 | 最小 |
| 中 | 50-74 | 放大时可见 |
| 低 | 25-49 | 可见伪影 |
```

### 内容优化
```markdown
## 额外优化

### 字体优化
- [ ] 子集字体（删除未使用的字符）
- [ ] 尽可能转换为标准字体
- [ ] 删除重复的字体实例

### 结构优化
- [ ] 删除未使用的对象
- [ ] 清理元数据
- [ ] 线性化以供网络使用（快速网络查看）
- [ ] 删除书签（可选）
- [ ] 删除评论/注释（可选）

### 内容删除（注意）
- [ ] 删除隐藏图层
- [ ] 删除 JavaScript
- [ ] 删除表单字段
- [ ] 删除嵌入文件
```

### 优化计划
```markdown
## 压缩策略：[文档名称]

### 当前状态
- 文件大小：150 MB
- 页数：200
- 问题：对电子邮件太大（限制：25 MB）

### 目标
- 最大大小：20 MB
- 保持可读性

### 推荐方法
1. **图片**：降低至 150 DPI，JPEG 70%
   - 预计节省：~100 MB
2. **字体**：子集嵌入字体
   - 预计节省：~5 MB
3. **清理**：删除元数据，优化结构
   - 预计节省：~5 MB

### 预期结果
- 最终大小：~20 MB
- 质量：适合屏幕/通用用途
```

### 前后指南
```markdown
## 质量比较指南
```

## 工具推荐

### 在线工具
- **SmallPDF**：简单，质量良好
- **ILovePDF**：免费，支持批量处理
- **PDF24**：可配置选项
- **Adobe 在线**：专业质量

### 桌面软件
- **Adobe Acrobat Pro**：最佳控制
- **Foxit PDF 编辑器**：良好替代品
- **PDF-XChange**：许多选项
- **预览（Mac）**：基本，内置

### 命令行
- **Ghostscript**：强大，可脚本化
- **qpdf**：快速，无损选项
- **pdfcpu**：现代 Go 工具
- **img2pdf**：针对图片

## 限制

- 无法执行实际压缩（仅提供指导）
- 某些 PDF 的可压缩内容最小
- 扫描文档主要是图片
- 已压缩的 PDF 节省空间较少
- 极端压缩会影响质量
- 矢量图形压缩量不大
