# 内容研究撰写者

研究主题并为博客、文章和营销材料创建引人入胜的内容。

## 概述

这项技能可以帮助您：
- 彻底研究主题
- 撰写引人入胜的博客文章和文章
- 创建SEO优化的内容
- 开发各种内容格式
- 保持品牌声音的一致性

## 如何使用

### 研究请求
```
"为博客文章研究[主题]"
"关于[主题]的关键要点是什么？"
"查找关于[主题]的统计数据和示例"
```

### 撰写请求
```
"撰写一篇关于[主题]的博客文章"
"撰写一篇1500字的文章关于[主题]"
"起草关于[主题]的社交媒体帖子"
```

### 带有指南
```
"为[受众]撰写关于[主题]的内容。语气：[专业/休闲]。包含[要求]。"
```

## SEO指南

### 内容优化
```markdown
## SEO清单

### 标题
- [ ] 包含主要关键词
- [ ] 60 个字符以内
- [ ] 有吸引力且值得点击

### 元描述
- [ ] 包含主要关键词
- [ ] 150-160 个字符
- [ ] 清晰的价值主张

### 标题 (H1, H2, H3)
- [ ] H1 与标题匹配/密切相关
- [ ] H2 中自然包含关键词
- [ ] 逻辑层次结构

### 内容
- [ ] 主要关键词在第一 100 个单词内
- [ ] 关键词密度 1-2%
- [ ] 包含相关关键词/LSI 术语
- [ ] 内部链接：[X] 个链接
- [ ] 外部链接：[X] 个权威来源

### 媒体
- [ ] 带有 alt 文本的图片
- [ ] 压缩文件大小
- [ ] 描述性文件名

### 可读性
- [ ] 短段落 (2-4 句话)
- [ ] 每 300 个单词一个子标题
- [ ] 列表使用项目符号
- [ ] 阅读水平：[年级 X]
```

## 风格指南

### 语气选项
| 语气 | 描述 | 示例 |
|------|-------------|---------|
| 专业 | 正式、权威 | "研究表明..." |
| 休闲 | 友好、易亲近 | "你知道那种感觉吗..." |
| 教育 | 清晰、指导性 | "让我们来分解一下..." |
| 说服 | 令人信服、以行动为导向 | "想象一下实现..." |
| 俏皮 | 有趣、吸引人 | "这里有个转折..." |

### 最佳实践
1. **早期吸引**：第一句话应该吸引注意力
2. **具体**：数据 > 模糊的主张
3. **使用示例**：使抽象具体化
4. **分块**：标题、项目符号、图片
5. **强力收尾**：清晰的要点或行动号召

## 限制

- 无法保证 SEO 排名
- 统计数据应经核实
- 无法访问付费来源
- 品牌声音需要指导
- 视觉内容描述仅限文字
