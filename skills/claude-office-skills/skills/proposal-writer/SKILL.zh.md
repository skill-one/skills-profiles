# 商务提案撰写助手

## 概述

该技能可帮助您创建专业、有说服力的商务提案，清晰传达价值并赢得订单。从简单的报价到全面的RFP回复。

**应用场景：**
- 销售提案和报价
- 项目提案
- 合作提案
- RFP/RFI回复
- 基金申请
- 服务协议

## 如何使用

1. 告诉我关于机会的信息（客户、项目、需求）
2. 分享您的解决方案和定价
3. 指明所需的提案类型和长度
4. 我将为您创建结构清晰、有吸引力的提案

**示例提示：**
- "创建网站改版服务的提案"
- "撰写联合营销的合作提案"
- "起草IT服务的RFP回复"
- "生成新功能的提案"

## 提案撰写最佳实践

### 执行摘要
- 最后撰写（在完整提案之后）
- 应能独立存在
- 以客户利益为先，而非您的功能
- 最多1页

### 了解需求部分
- 显示您已做好功课
- 引用具体的客户挑战
- 使用他们的语言和术语
- 承认他们的目标

### 解决方案部分
- 关注成果，而非活动
- 解释"为什么"，而不仅仅是"什么"
- 在需要时使用视觉辅助
- 易于理解

### 定价部分
- 尽可能提供选项
- 首先展示较高选项
- 透明说明包含内容
- 说明投资回报

### 行动号召
- 使下一步行动清晰明确
- 移除犹豫（易于说"是"）
- 适当制造紧迫感
- 提供问题联系方式


## 定制选项

告诉我您的偏好：
- **长度：** 简短（2-3页）、标准（5-10页）、全面
- **风格：** 保守/企业、现代/创意、技术
- **重点：** 价格竞争、价值导向、关系建立
- **格式：** 文档、演示文稿幻灯片、邮件友好

## 限制

- 无法研究特定客户（提供背景信息）
- 定价必须由您提供
- 法律条款应由法律顾问审查
- 可能适用行业特定法规
- 无法保证订单达成

## 示例

### 示例：SaaS实施提案

**输入：** "为一家500人公司实施我们的HR软件。3个月时间表，75,000美元预算，包括培训和售后支持。"

**输出：**

# HR软件实施提案

**致：** [客户公司]
**由：** [您的公司]
**日期：** [日期]

---

## 执行摘要

我们很高兴与 [客户公司] 合作，通过我们的综合HR软件平台现代化您的HR运营。此次实施将简化您的人员流程，减少行政负担，并为您的500人组织提供实时洞察。

**关键优势：**
- 减少40%的HR行政时间
- 员工数据的单一信息源
- 自服务门户减少60%的HR工单
- 12周内完成全面实施
