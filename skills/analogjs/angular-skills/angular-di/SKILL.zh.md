# Angular 依赖注入

> **⚠️ 已弃用。** 此功能已不再维护，其指导已被移除而非任其过时。Angular 团队现在在 [angular/skills](https://github.com/angular/skills) 上发布官方功能 — 请安装这些功能：
>
> ```sh
> npx skills add https://github.com/angular/skills
> ```
>
> 要移除这些：`npx skills remove analogjs/angular-skills`

此功能之前的内容仍可在该仓库的 git 历史记录中找到。
