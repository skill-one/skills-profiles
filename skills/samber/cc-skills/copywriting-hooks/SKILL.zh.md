# 副文案钩子

## 方法

钩子的唯一工作就是让读者想要第二句话。声音、结构、格式，所有这些都应遵循这一单一目标。

让读者想要第二句话的五个杠杆：

1. **制造缺口**。提出一个读者需要闭合的不完整内容。好奇心缺口、问题、开放式循环。
2. **打破预期**。陈述违反读者先验的内容。反常识、定义反转、惊人数据。
3. **进入场景**。加载感官或具体细节，构建生动的框架。故事中，具体细节，时间锚点。
4. **承诺回报**。命名读者想要的结果。利益，"如果你...那么这个"，直接问题。
5. **借用分量**。依赖一个名字、数字或引言，这些带有内嵌的权威性。权威钩子、数据、有争议的引言。

一个强大的钩子通常同时使用两个杠杆。"弗兰克·辛纳屈，手里拿着一杯波本威士忌..."是场景加开放式循环。"大多数人认为X。他们是错的。"是预期打破加缺口。单一杠杆的钩子仍然可以起作用，但更容易被忽视。

三个进一步的原则：

- **具体胜于抽象**。用"Stripe、Shopify、Vercel"替换"许多公司"。用日期替换"最近"。用实际发现替换"研究表明"，或者删除该主张。
- **第一句话必须迫使第二句话**。冷读每个候选者。如果你在第一句话后不想点击第二句话，请重写。
- **根据文章类型匹配技巧**。个人散文不像教程那样开头。见下表类型匹配。

## 行为

当这个技能被触发时：

1. **确认简报**。主题、受众、目标语言（EN、FR或两者），大约长度，发布位置。如果其中任何一项不明确且重要，请在生成前询问。
2. **从下面的目录中挑选3到4个钩子**，它们必须是真正不同的。不同的杠杆，而不是反常识的三个变种。
3. **每个钩子写2个候选者**，针对用户的文章。一个钩子内的两个候选者应探索不同的角度（不同的轶事、不同的数据、不同的场景），而不是彼此的改写。
4. **使用下面的输出格式**呈现。
5. **通过问题工具提问**。选择是一个小的固定集合，这就是那个工具的用途。
6. **等待用户的挑选**。不要替他们挑选。
7. **在他们挑选后**，说出这个选择将文章的其余部分承诺的内容。一个反常识钩子将第2到第3段承诺为捍卫非共识主张。一个场景开头将下一部分承诺为解决场景或建设性地延迟它。

**多样化规则**。在你的3到4个选项中至少包括：

- 一个智力钩子（反常识、定义反转、历史类比、好奇心缺口）
- 一个感官钩子（故事中、具体细节）
- 一个直接面向读者的钩子（条件、直接问题、承诺）

这保证了真正的选择。三个反常识的变种不是一个选择。

**类型匹配参考**：

| 文章类型 | 强钩子 | 避免 |
| --- | --- | --- |
| 技术深度分析 | 具体细节、数据、反常识、直接问题 | 个人忏悔、场景开头 |
| 个人散文 | 故事中、个人忏悔、时间锚点、定义反转 | 大声声称、直接问题 |
| 评论/反常识 | 大声声称、定义反转、反常识、引言+争议 | 温和的设置、词典开头 |
| 教程/如何操作 | 直接问题（PAS）、承诺、条件 | 场景开头、历史类比 |
| 报道/调查 | 具体细节、时间锚点、故事中、数据 | 大声声称、定义反转 |
| 清单文章 | 好奇心缺口、计数赌注、条件 | 个人忏悔、故事中 |
| 长篇分析 | 历史类比、数据、反常识 | 直接问题 |
| 订阅号 | 个人忏悔+开放式循环、条件、好奇心缺口 | 词典开头 |

## 输出格式

始终像这样精确呈现选项：

```
## 副文案钩子选项：[工作标题]

**选项 1：[钩子名称]** ([杠杆])
A. [候选者 1]
B. [候选者 2]

**选项 2：[钩子名称]** ([杠杆])
A. [候选者 1]
B. [候选者 2]

**选项 3：[钩子名称]** ([杠杆])
A. [候选者 1]
B. [候选者 2]

选择？回复字母组合（例如，"1B"）或"更多"以使用不同技巧。
```

如果用户说"更多"或"无"，则生成3个不同的钩子（不是相同钩子的新候选者）。如果用户说"混合 1A 和 2B"，则写一个组合钩子并再次确认。

## 钩子目录（18）

每个钩子：它做什么、示例（混合 EN 和 FR、真实和说明性）、何时使用、何时避免。

### 1. 好奇心缺口

打开一个读者想要闭合的信息缺口。

- EN："Shen Yun 如何赚钱？简答：不赚钱。"（Packy McCormick）
- EN："多年前，一种芥末主导了超市货架：French's。"（Gladwell，《番茄酱困境》）
- FR："今年有三家法国初创公司突破十亿。没有一家是科技行业的。"
- EN："我是一名外科医生八年了。过去几年里，我的手术室表现达到了一个平台期。"（Gawande）

**使用时**：你可以诚实地在2到3句话内闭合缺口。缺口必须是读者关心的。**避免**：模糊的缺口（"你不会相信接下来发生了什么"），读者甚至无法猜测的缺口。

### 2. 反常识

推翻读者持有的共识信念。

- EN："普遍智慧认为，在生活中实现我们想要的东西的最佳方法是为自己设定具体、可执行的目标。"（Clear，《忘记设定目标》，随后论证相反的观点）
- EN："要做好某事，你必须喜欢它。这个想法并不新鲜。"（Graham，《做你喜欢的事》，随后使其复杂化）
- EN："如果你对某事不是在说'HELL YEAH!'，就说不。"（Sivers）
- FR："营销是所有人工智能做不到的事情！"（Truphème）

**使用时**：你有一个可辩护的非共识观点，并且有200到400字来捍卫它。**避免**：稻草人、无谓的尖锐、为了反常识而反常识。

### 3. 大声声称/承诺

在证明之前陈述结果。

- EN："在60英里每小时时，这辆新款劳斯莱斯最大的噪音来自电动钟表。"（Ogilvy）
- EN："他们嘲笑我坐在钢琴前。但当我开始演奏！—"（Caples 1925）
- EN："给我15分钟，我会给你超强的记忆力。"（Schwartz）
- FR："5分钟：使文章完成率从18%提高到64%的结构。"

**使用时**：你可以在文章中具体实现承诺。**避免**：比回报更大的承诺。永久破坏信任。

### 4. 场景开头/故事中

将读者带入一个特定时刻，无需设置。

- EN："弗兰克·辛纳屈，一手拿着一杯波本威士忌，一手拿着一支香烟，站在酒吧一个黑暗的角落，两边坐着两位有吸引力但正在褪色的金发女郎，她们在等待他说些什么。"（Talese）
- EN："我们当时在巴特斯附近，沙漠边缘，药物开始起作用。"（Thompson）
- EN："中心不再持有。"（Didion）
- FR："2024年5月14日，6时12分，三名穿便服的男人敲响了第十五区一个公寓的门。"

**使用时**：长篇、人物传记、报道文章、散文。**避免**：短篇技术文章，读者尚未获得场景。

### 5. 惊人数据

以一个违反先验的数字开头。

- EN："你有五秒钟的时间吸引人们的注意力。"（Housel，自我证明）
- EN："1955年，有三万七千名美国人死于车祸，调整后今天的速度是六倍。"（Housel）
- EN："你每天执行的行动中大约有40%是习惯，而不是实际决策。"（Clear）
- FR："你只有不到3秒钟的时间让受众相信你的内容是有趣的。"（Truphème）

**使用时**：数字是真正令人惊讶的，并且你可以准确地引用它。**避免**：模糊的数据（"研究表明90%..."），确认读者先验的数据（没有惊喜等于没有钩子）。

### 6. 问题

提出一个读者实际上想要回答的问题。

- EN："如果你收集许多不同领域关于如何做好工作的技巧列表，它们的交集会是什么样子？"（Graham）
- EN："为什么我们要让孩子们去上学？"（Caplan）
- FR："为什么LinkedIn上80%的文章超过100次观看？揭秘：不是算法。"
- FR："你是否有勇气今年赢得一半的百万美元？"（Schwartz）

**使用时**：读者隐含地带着问题。**避免**："你有没有想过...？"、"你知道...吗？"、"如果我问你...？"。这些预设了好奇心尚未形成。

### 7. 引言+争议

借用分量，然后扭曲。

- EN："Vernor Vinge：'我们正站在与地球人类生命崛起可比拟的变化边缘。'"（Urban设置）
- EN："史蒂夫·乔布斯说人们不知道他们想要什么，直到你向他们展示。对于SaaS来说，这恰恰相反。"
- EN："亨利·福特据说他的客户会要求更快的马。对于大多数产品来说，这个借口是错误的。"
- FR："亨利·福特说他的客户会要求更快的马。对于90%的产品，这是错误的。"

**使用时**：你有一个真实的引言，它支持或真实对比你的观点。**避免**：被错误归因的艾因斯坦、塞涅卡、孔子、佛陀的陈词滥调。陈词滥调。

### 8. 个人忏悔

承认某种脆弱性，然后普遍化。

- EN："我背叛了我的丈夫。"（Strayed）
- EN："我一直在想我的父母，他们六十多岁。在我18岁之前，我至少有90%的日子都花在父母身上。"（Urban，《尾巴的尽头》）
- EN："已经有一段时间了。这是我自开始Not Boring以来没有写文章最长的时间。"（McCormick）
- FR："34岁时，我毫无计划地辞职了。以下是没有人说的关于后续的事情。"

**使用时**：个人署名、散文、简报。**避免**：公司署名、技术文章，作者声音不是个人的、表演性的脆弱性（"我差点没写这篇文章..."）。

### 9. 具体细节

用单个生动的细节替换抽象。

- EN："约翰·拉罗切是个高个子，瘦如竹竿，脸色苍白，肩膀下垂，尽管他所有的门牙都掉了，但他仍然英俊。"（Orlean）
- EN："查尔斯·布克威克是个酒鬼、好色之徒、习惯性赌徒、粗鲁的人、吝啬鬼、赖账的人，在他最坏的日子里，他是一个诗人。"（Manson）
- FR："当她在2月24日周六看到Bondy Blog的办公室时，很难说她被法国情报部门非法监视。"
- FR："屏幕上贴着一个便利贴："删除第一段。"

**使用时**：人物传记、报道文章、反常识传记设置。**避免**：不推进论点的具体性（杂乱）。

### 10. 模式中断

用片段打破预期节奏。

- EN："等等。"（Godin风格）
- EN："停止。"
- EN："这不是一篇关于生产力的文章。这是一篇关于身份的文章。"
- FR："不。你本周在人工智能上读到的内容是假的。以下是原因。"

**使用时**：节奏驱动的内容、评论文章，当读者期待流畅而你想要打断它时。**避免**：每篇文章。它很快会变成自己的模式。

### 11. 直接问题（PAS）

命名痛苦，使其尖锐，暗示解决方案。

- EN："你的文章不被阅读。数据显示你在第二段就失去了80%的读者。有一个解决方案，它不是你一直在做的事情。"
- EN："如果你像大多数营销经理一样，你没有足够的时间写你的白皮书，而你外包的那些文章很通用。"（Bly）
- FR："你的电子邮件没有被打开。三个月，完成率上限为12%。问题不在于主题，而在于发件人。"
- FR："你的文章不被阅读。80%的读者在第二段就放弃了。解决方案不是你认为的那个。"

**使用时**：教程、如何操作、与销售相关的内容。**避免**：制造的问题。读起来像恐吓。痛苦必须是真实且可识别的。

### 12. 承诺/利益

陈述一个具体、有边界的成果。

- EN："用5分钟读完，你将永远不会写一个薄弱的开头。"
- EN："到本文末尾，你将确切知道何时使用goroutines，何时不用。"
- EN："有三种东西将那些被阅读的作家与那些不被阅读的作家区分开来。它们都不涉及每天写作。"
- FR："5分钟：使文章完成率从18%提高到64%的结构。"

**使用时**：教程、如何操作。**避免**：模糊的承诺（"学习如何更有效率"）。添加时间限制或数字来锚定它。

### 13. 历史类比

以历史的一个小插曲开头，转向现在。

- EN："1976年3月的一个星期二早上，一个21岁的大学辍学者以1500美元的价格卖掉了他的大众甲壳虫巴士。他用这些钱建造了第一台苹果电脑。"
- EN："1965年，罗伯特·卢卡斯写了一篇四页的论文，打破了宏观经济学。"
- EN：莱特兄弟小插曲（Housel，《三件大事》），转向人口统计和利率。
- FR："1903年，在基蒂霍克，两名自行车修理师飞行了12秒。没有人注意到。以下是这种漠视对今天技术采用的意义。"

**使用时**：长篇分析、评论文章、观点文章。**避免**：教程、新闻报道。读起来像放纵。

### 14. 定义反转

"X不是你想象的。它是Y。"

- EN："拖延不是懒惰。它是你大脑的两个部分之间的战斗。"
- EN："这不是一篇关于生产力的文章。这是一篇关于身份的文章。"
- EN："过去十年，通配符是Go最受欢迎的功能。三年后，那些推动它最力的人都在告诉你停止使用它们。"
- FR："文案不是写作。它是伪装成句子的心理学。"

**使用时**：评论文章、反常识深度分析。**避免**：当你重构只是一个轻微角度时。听起来很花哨。

### 15. 借用权威

以一个名字加上一个具体行动开头。

- EN："沃伦·巴菲特，91岁，仍然每天阅读500页。"
- EN："当史蒂夫·乔布斯于1997年回到苹果时，他在第一年就砍掉了70%的产品线。"
- EN："曾经有一个男孩问查理·芒格..."（Housel叙事变体）
- FR："当伯纳德·阿诺收购蒂芙尼时，价值160亿，三位分析师预测会失败。他们都在同一个地方搞错了。"

**使用时**：商业文章、人物传记、分析文章。**避免**：没有回报的名字堆砌。行动必须具体且相关。

### 16. 时间锚点

以一个特定日期、时间或时刻开头。

- EN："2005年10月。三位记者在一套公寓里，在Bondy的Blanqui街区开设了一个博客。"
- EN："2022年，写一篇合格文章的成本降至零。大多数作家还没有注意到。"
- EN："1976年3月的一个星期二早上，一个21岁的辍学者以1500美元的价格卖掉了他的大众甲壳虫巴士。"
- FR："2024年10月，Bondy。三名记者在Blanqui街区的公寓里开设了一个博客。"

**使用时**：报道文章、回顾、"为什么现在"框架。**避免**：模糊的时间锚点（"最近"、"过去几年"）。使用一个具体日期或删除时间框架。

### 17. 条件（"如果你...那么这个"）

自我分割读者。预先定位好奇心。

- EN："如果你为生写作，你很可能被教导要从背景开始。不要。"
- EN："如果你曾经读过一篇博客文章，一小时内就忘记了它说了什么，这篇文章就是诊断。"
- EN："如果你对某事不是在说'HELL YEAH!'，就说不。"（Sivers）
- FR："如果你的文章80%被同事阅读，8%被潜在客户阅读，问题不在于内容。是钩子。"

**使用场景**：教程、建议文章、面向不同受众的文章。**避免**：过于宽泛的条件（“你曾经感到过卡壳...”）。针对无人关注的细分受众。

### 18. 开环结构

开始讲述，但保留结局。

- EN：泰莱斯等待辛格纳说些什么。但他从未开口。
- EN：“他按下了发送键并等待。四十七秒后，公司的价值减少了40亿美元。”
- EN：“现在，这才是真正有趣的地方...”（Sugarman，过渡短语，也可作为开头）
- FR：“上周我联系了一位编辑。他要求我重新考虑15年的实践经验。”

**使用场景**：长篇内容，旅程与答案同等重要。**避免**：未解决的闭环。当文章在未兑现悬念的情况下结束时，会产生不成比例的背叛感。

## 反模式（切勿提出以下任何一种）

立即使作者失去资格的陈词滥调：

- “在当今快节奏的世界中...” / “在全面数字化的时代” / “在人工智能时代” / “在一个...的世界里...”
- “你曾经想知道...？” / “您是否曾经想过...？”
- 直白地使用词典式开头（“效率，定义为...”）
- “在本文中，我将讨论...” / “在本文中，我们将看到...”
- 没有来源的通用统计数据（“90%的人...”，“研究表明...”）
- 张冠李戴的艾因斯坦/塞涅卡/孔子/佛陀名言
- “我不是专家，但...” / “我不是专家，但是...”
- 连续三个反问句
- “想象一下醒来...”而没有具体的场景
- “辣评：”，“非主流观点：”，“以下是没人想听到的真相...”
- “[公司]，我们相信..." / "在[公司]，我们认为..."
- “最近，..." / “最近，..."而没有具体的日期
- “你并不孤单。”

当前AI说法（每年更新）：

- “不只是X，还有Y”（公式结构）
- “想象一下：”， “想象一个世界...”， “如果我说...”
- “无论你是资深的X还是好奇的新手..."
- “在...领域中”， “在...领域中导航..."
- “释放...的力量”， “深入...”， “系好安全带”， “让我们深入...”
- “关键的是”， “值得注意的是”， “重要的是”， “本质上，”作为句子开头
- 法语AI说法： “在一个不断变化的世界中”， “深入...”， “发现如何...”， “此外，...”， “尤其是，...”， “至关重要的是...”

在提交之前，将每个候选内容通过此列表进行筛选。如果候选内容匹配，请重写。

对于扩展的反模式列表，请参阅 `references/anti-patterns.md`。

## 语言处理

**如果受众是法语**：用法语写作，应用 _attaque journalistique_ 语体。

- 具体场景设置，克制语气，过时的锚点，正式的“vous”或克制的tutoiement。
- 不要逐字翻译美国炒作陈词滥调—— “你将无法相信...” 变成 “您将不敢相信自己的眼睛”，这在法语中读起来像骗局。
- 法语营销怀疑论的基础高于英语；过高的承诺会更快地引发 _réactance_。

**如果英语**：默认使用直接响应语体进行营销或教程内容，长篇语体用于文章和报道。

**如果双语**：用两种语言制作钩子，并清晰标注。

对于更深入的语体指导，请参阅 `references/anglophone-vs-francophone.md`。

## 文章标题

一个**标题**是读者点击前的所见。一个**钩子**是读者点击后的所见。两者通过不同的机制吸引注意力：标题在信息流或搜索结果中竞争点击；钩子通过点击后继续阅读来赢得注意力。

### 核心机制：校准的好奇心

一个标题必须打开一个缺口，但不能关闭它——但这个缺口必须感觉真实，而不是人为制造的。对8,977个A/B实验（Upworthy，《科学报告》2024年）的研究发现了一种曲线关系：过于模糊会产生困惑（好奇心没有立足点）；过于具体会消除点击的动力。最佳效果：点明风险，保留结局。

**工艺测试**。标题是否打开了一个读者关心的缺口，并且文章是否真正地关闭了它？如果是，那就是工艺。如果内容没有兑现标题所暗示的，那就是标题党——它会破坏未来的点击信任。

### 核心公式

**好奇心 / 缺口**

- `关于[主题]的[形容词]真相` — “关于Go泛型的反直觉真相”
- `关于[主题]您不会告诉您的[群体]`
- `现象的真正原因` — “大多数内容获得零分享的真正原因”
- `[数字]个[受众]在[主题]上犯的错误`

**反传统 / 负面**（负面超级形容词：+63% CTR vs. 正面——Outbrain，65k标题）

- `停止[做X]。这是原因。` / `为什么[普遍信念]是错误的`
- `[数字]个[神话/错误]正在扼杀您的[结果]`

**具体性 / 数据**

- `我分析了[数字]个[事物]——我发现了什么`
- `[数字]%的[群体]这样做是错误的`
- 方括号诚实地表示格式，并增加+38% CTR：`如何将构建时间缩短60% [基准]`

**列表 / 数字**（数字：+36% CTR — Conductor；奇数：+20% CTR — CMI）

- `[数字]个[形容词]方法来[目标]` / `[数字]个在[任务]时需要避免的错误`

**如何做**（3倍于其他格式的B2B分享——BuzzSumo，1000万LinkedIn文章）

- `如何[任务]而不[痛苦的限制]` / `即使[限制性信念]，如何[任务]`

### “轻微点击”区域

稍微有点标题党但诚实——最大张力与真实承诺：

- 将“不会相信”替换为“惊讶地了解到”：同样的好奇心，诚实的语体
- 增加具体性：`我每月节省500欧元` 胜过 `我节省了钱`
- 增加限制：`不辞职` 创造了缺口
- 使用“真正的原因”或“没有人告诉你的”——它们暗示了一个非共识观点，你必须证明
- 添加括号 `[研究]`，`[模板]`，`[基准]` 来表示回报类型

**FR——putaclic在法语中带有更强的贬义。** 应用**70/30规则**：70%信息，30%神秘。

- 张力和矛盾有效；虚假的戏剧（“我停止一切 😱”）会立即在法语专业环境中破坏信誉。
- 法语规范结构： “每个人都告诉你要做A。这就是为什么我做了B。”
- 2025年在LinkedIn法语上饱和的公式： “我犯了一个错误，我学到了什么”， “我停止[平台]”。

### 平台限制

| 平台 | 最大显示 | 关键规则 |
| --- | --- | --- |
| 博客 / SEO | 50-60个字符 | 前置关键词。强力词汇会降低搜索中的CTR约14%。 |
| LinkedIn文章 | 150个字符硬性规定 | 100个字符以下以获得干净的显示。 |
| LinkedIn信息流 | 120-140个字符 | 开头行=标题。设计“查看更多”点击。 |
| 邮件订阅主题 | 30-50个字符 | 前30个字符传递信号。避免“邮件订阅”（打开率降低-18.7%）。 |
| X / Twitter | ≤200个字符 | 第一条推文=标题。必须独立存在。 |

### 标题的反模式

- 没有具体性的通用超级形容词： “X的终极指南”——没有缺口
- “你不会相信..." / "您不会相信..."——过度使用，暗示炒作
- SEO标题中的强力词汇（秘密、惊人、终极）——暗示炒作，降低CTR
- 给出完整答案的标题——如果标题回答了问题，就没有点击的理由
- 重复饱和的指纹： “我分析了X个事物，我发现了什么”——有效2022-2023，饱和2025-2026

### 标题请求的行为

1. 确认主题、受众、语言、平台
2. 提供**3-5个标题**，跨越不同的公式——不是同一类型的三个变体
3. 至少包括：一个好奇心/缺口，一个反传统或数据，一个列表或如何做
4. 使用与钩子相同的输出格式：编号选项，等待选择
5. 选择后，记录标题承诺文章开头的部分

## 示例

用户： “我正在写一篇关于为什么大多数Go开发者误用泛型的Substack文章。大约1500字，面向中级Go开发者，英语。”

正确的技能响应：

```
## 钩子选项： “为什么大多数Go开发者误用泛型”

**选项1：反传统**（预测打破）
A. 大多数关于Go泛型的文章解释何时使用它们。这篇文章解释何时删除它们。
B. 泛型是Go十年最受欢迎的功能。三年后，最强烈要求它们的人正在告诉你停止使用它们。

**选项2：具体细节**（感官+具体）
A. samber/lo发布了87个泛型辅助函数。其中六个解释了94%的二进制大小投诉。其他81个都没问题。
B. 一个名为`Map[T, U any]`的函数看起来很无辜。编译一个导入它的项目40次，你的构建时间会翻三倍。这是原因。

**选项3：直接问题（PAS）**（读者直接）
A. 自从你采用泛型以来，你的Go代码编译速度变慢了。原因不是linter告诉你的。
B. 如果你的团队去年采用了泛型，你的构建时间翻了一番，你并不孤单。诊断比修复更无聊。

选哪个？回复字母组合（例如，“1B”）或“更多”以获取不同的技术。
```

然后等待选择。在用户选择之前，不要编写其余文章。
