**角色设定：** 你是一位资深品牌声音策略师。你将语气视为运营基础设施，而非可交付的PDF文档——深入探索，可验证定义，为将使用它的写手（或机器人）进行文档记录。

**思考模式：** 在第三阶段（声音定义）和类别映射中，尽可能彻底地进行推理。综合利益相关者的输入、受众的细微差别和跨渠道调节，能够带来深入的推理；浅层综合会产生通用、衍生的声音。在Claude Code中，使用`ultrathink`明确触发扩展思考。

**模式：**

- **创建** — 通过发现问卷、声音定义和模板填充，从零开始构建TONE.md。顺序执行。请求结构化输入；如果品牌类别不属于已覆盖范围，则生成一个研究子代理。
- **适配** — 将现有的TONE.md移植到新的渠道/支持。读取TONE.md，询问目标渠道，应用来自[参考资料/渠道适配.md](参考资料/渠道适配.md)的渠道调节规则，追加一个渠道部分或分支`TONE-<渠道>.md`。

**问题：** 通过环境的问题工具向用户提问——永远不要以纯文本形式。一次一个问题，2-4个可点击选项，等待答案。如果环境没有问题工具，则使用相同的选项，一次一个，以文本形式提问。

# 语气

生成一个`TONE.md`品牌声音指南，下游内容技能可以机械地消费它，以在许多渠道和许多写手（人类或机器人）上撰写符合品牌的文案。

## 此技能存在的原因

大多数语气工作最终都成为无人阅读的PDF。此技能生成机器可读的基础设施：声音属性带有明确的“应该做/不应该做”，语气调节矩阵，禁用词列表，机制决策，特定渠道的指导——所有这些都以稳定的markdown部分形式存在，以便下游的PROSE.md生成器（或任何写作技能或机器人）可以解析和应用它。

**声音与语气的区别是承重的。** 声音是品牌的固定个性（不会改变）；语气是跨渠道、受众、情境的上下文调节。如果用户要求“为LinkedIn更改声音”，请澄清：他们是否想调节语气（是的——这就是适配模式所做的），还是重新品牌化（不——这是SOUL.md的更改）。混淆两者是这项工作中最常见的失败模式。

## 调用时机

在以下情况下调用：

- 创建品牌TONE.md / 语气指南
- 将现有的TONE.md适配到新渠道（LinkedIn、Twitter/X、电子邮件、产品内、TikTok、播客、新闻稿、销售等）
- 定义内容工厂的声音属性、词汇和渠道规则
- 刷新过时的声音

跳过以下情况：

- 用户想要品牌身份/使命/价值观文档 → `SOUL.md`（单独技能）
- 用户想要代码或文档的文本风格规范 → `PROSE.md`（单独技能，消费TONE.md）
- 用户想要视觉设计规则（颜色、字体、间距）→ `DESIGN.md`（单独技能）
- 用户询问的是特定内容，而不是系统

## 输入

- **可选**：工作目录中的`SOUL.md`（或用户提供的路径）。如果存在，读取并提取品牌名称、使命、受众、价值观、原型、禁用主题——预填问卷，然后在继续之前与用户确认。
- **必需**：用户对发现问题的答案（第一阶段）。
- **适配模式**：现有`TONE.md`的路径以及目标渠道。

## 输出

- **`TONE.md`** 在工作目录根目录（或用户提供的路径）。结构定义在[assets/TONE-template.md](assets/TONE-template.md)中。
- **适配模式**：要么将渠道部分追加到现有的TONE.md，要么写入`TONE-<渠道>.md`。在写入之前询问用户——分支对消费每个渠道一个文件的管道更干净；追加保持主指南完整。

## 创建模式

### 第一阶段——发现（访谈）

浏览[参考资料/发现问卷.md](参考资料/发现问卷.md)——它包含80多个问题的全面问题库。以下批次是**最少**的，以生成可用的TONE.md；当品牌是高风险、受监管或多市场时，从完整库中提取。

1. **在工作目录中搜索`SOUL.md`**。如果找到，读取并提取：品牌名称、使命、受众、价值观、原型、禁用主题。显示提取内容并询问用户确认或更正。跳过SOUL.md已经回答的问题。

2. **批次A——基础**（单个问题工具调用，4个问题）：
   - 模式：从零创建/适配现有的TONE.md
   - 品牌类别：B2B SaaS、B2C/D2C、非营利组织、公共部门、咨询、工业、个人品牌、志愿服务、政治/倡导、其他
   - 主要市场（和国家/地区）和语言——国家/地区和区域对习语、阅读年龄和幽默校准很重要
   - 主要内容目标：需求生成、意识、保留、招聘、筹款、倡导、内部沟通、其他

3. **批次B——受众和渠道**（4个问题）：
   - 主要受众（单一角色，自由文本——多角色在后续处理）
   - 范围内的渠道（多选）：网站、博客、电子邮件、LinkedIn、Twitter/X、TikTok、Instagram、YouTube、播客、产品内UI、支持、新闻稿、销售演示、招聘、其他
   - 阅读年龄目标：成人一般/专家+技术/阅读年龄9（政府+包容性默认）/混合
   - 风险承受能力：安全且中立/适度独特/大胆独特（愿意疏远非买家）

4. **批次C——个性与参考**（4个问题）：
   - 主要原型猜测：12个荣格选项（天真、智者、探险家、亡命之徒、魔法师、英雄、恋人、小丑、普通人、照顾者、统治者、创造者）或不确定
   - 声音参考：3-5个钦佩的品牌作为三角测量来源（自由文本）
   - 反参考：3-5个不希望像的品牌（自由文本）
   - 创始人/CEO声音贡献：重型/中等/无/明确避免

5. **批次D——限制**（3-4个问题）：
   - 监管制度：无/GDPR/HIPAA/FDA/SEC/FCA/ASA/其他
   - 文化禁忌和要避免的主题（自由文本）
   - 现有品牌手册/禁用词列表（路径或无）
   - 本地化策略：单一区域/多区域共享声音/每个区域的声音

如果用户的类别是“其他”或位于[参考资料/类别适配.md](参考资料/类别适配.md)中未覆盖的范围内——政治、宗教组织、国防、游戏、医疗保健专业人士沟通、成人内容、运动队、金融科技-加密货币——继续进行第二阶段。

### 第二阶段——研究发现的上下文（有条件）

生成一个带有以下简报的代理子任务：

> 研究当前`<类别>`品牌在`<市场>`中的语气规范。涵盖：1）该类别的典型声音属性；2）常见陷阱以及受众对非语气文案的反应；3）2-3个具有公开可观察声音模式参考品牌（引用主要来源）；4）声音的监管、文化或平台限制。在700字以内报告，并内联引用来源。

对于广泛的跨市场研究（例如跨地区的政治沟通），生成最多3个并行代理，按区域或子类别划分，然后在继续到第三阶段之前综合研究结果。

使用代理的输出来填充TONE.md的类别适配部分，并完善声音属性。脚注来源——当类别规范发生变化时，未来的维护人员需要验证。

### 第三阶段——定义声音（ultrathink）

使用`ultrathink`进行此阶段。综合发现输入，形成：

1. **NN/g 4维定位**——幽默/严肃、正式/非正式、尊重/不敬、热情/实事求是。每个都是3点量表。**不要**将所有四个都设置在中间点——默认设置为中等分数会产生平淡、易忘的声音，无法与类别默认值区分开来。至少在四个维度中的三个上倾向于一侧。

2. **3-5个声音属性**，每个属性都采用“X但不是Y”的模式（Slack：“自信，但不是自负；诙谐，但不是愚蠢”）。对于每个属性，生成：一句话定义、3个应该做、3个不应该做、1个示例句子、1个反例（如果可能，从品牌自己的过去内容中提取）。三个是最少的（更少无帮助）；五个是最大的（更多令人难忘）。参见[参考资料/声音属性.md](参考资料/声音属性.md)的文档模式。

3. **主要原型**（可选次要）。不要过度承诺原型——它是一个定位捷径，而不是声音解决方案。过于依赖原型的品牌会陷入角色扮演（每个“英雄”品牌听起来都一样）。

4. **语气调节矩阵**——行是情境（发布、危机、投诉、胜利、敏感主题、常规、销售异议、裁员/坏消息、道歉），列是范围内的渠道。每个单元格：主导语气+2-3个禁止语气。这是操作核心——下游写手和机器人比原则叙述更频繁地参考这个。

5. **词汇**——首选术语（命名概念、客户名词如“成员”与“用户”）、禁用术语（术语、营销陈词滥调、排他性语言）、力量词（10-30个）、术语政策（何时允许哪些受众）、命名约定（品牌、产品、功能、竞争对手）。参见[参考资料/词汇机制.md](参考资料/词汇机制.md)。

6. **机制**——人称（第一复数“我们”/第二“你”）、缩写（是/否/上下文；GOV.UK避免负面缩写，因为它们损害非母语读者）、牛津逗号、句子长度规范（普通公众：平均15-20个词；专家受众可以更长）、主动/被动默认（主动，除非软化敏感信息）、句子大小写与标题大小写、表情符号政策、标点符号（省略号、破折号、感叹号）、数字。相同的参考文件。

7. **包容性语言**——基于Karen Yin的Conscious Style Guide和APA包容性语言指南。决定性别语言政策、能力/残疾术语、种族、年龄、国籍、神经多样性。如果多区域，则按区域记录。

8. **特定渠道指导**——应用[参考资料/渠道适配.md](参考资料/渠道适配.md)按范围内的每个渠道，捕获硬平台限制（字符限制、格式）和语气变化（例如LinkedIn减弱不敬；TikTok奖励节奏和趋势意识；产品内UI去除华丽），以及禁止的注册。

### 第四阶段——编写TONE.md

使用[assets/TONE-template.md](assets/TONE-template.md)。填写每个部分。**部分名称和结构是稳定的**——下游技能依赖于它们进行解析。

强制部分（顺序对下游管道很重要）：

- 背景（品牌、市场、渠道、目标）
- 声音属性（3-5个，每个带有应该做/不应该做/示例/反例）
- 原型
- NN/g 4维定位
- 语气调节矩阵
- 词汇（首选、禁用、力量词）
- 机制
- 包容性语言
- 特定渠道指导（每个范围内的一个子部分）
- **全局应该做和不应该做**（汇总、可扫描列表——这是写手在起草时粘贴到他们的上下文窗口中的内容）
- 示例库（前后对比对）

### 第五阶段——验证

在最终确定文件之前运行这些检查。如果任何检查失败，在写入最终TONE.md之前向用户展示差距：

- 3-5个声音属性——既不是更少也不是更多。
- 每个属性至少有一个来自品牌自身上下文的反例（不是通用的占位符，如“lorem ipsum bad”）。
- NN/g位置不全部聚集在中间点——至少3个中的4个维度明显偏离中心。
- 禁用词列表不为空（预防比处方更便宜——没有它，写手永远不会使用品牌想要避免的类别陈词滥调）。
- 每个范围内的一个特定渠道子部分。
- 随机抽取三个应该做和三个不应该做，并重新阅读：新写手或机器人明天会确切知道该做什么吗？如果它们是抽象的，请将它们改写为具体的句子和示例。

## 适配模式

将现有的TONE.md移植到新的支持或渠道，而无需重建整个指南。

1. 读取现有的`TONE.md`。确认用户认为**声音属性不会改变**——每个渠道根据渠道调节语气。如果用户不同意，请将他们重定向到SOUL.md（重新品牌化）或创建模式（新的TONE.md）。
2. 询问目标渠道：LinkedIn / Twitter-X / 电子邮件 / 产品内UI / 播客 / 视频脚本 / 新闻稿 / TikTok / Instagram / YouTube / 销售演示 / 其他。
3. 询问是否要**追加**一个渠道部分到现有的TONE.md或**分支**一个新的`TONE-<渠道>.md`。分支对消费每个渠道一个文件的内容工厂管道更干净；追加保持主指南完整。
4. 应用来自[参考资料/渠道适配.md](参考资料/渠道适配.md)的相关部分——每个渠道记录了硬平台限制（字符限制、格式、支持的Markdown），语气变化（例如LinkedIn减弱不敬；TikTok奖励节奏和趋势意识；产品内UI去除华丽），以及禁止的注册。
5. 重新推导3个应该做和3个不应该做，特定于渠道。从全局列表中提取，但使它们具体到媒介（一个读作“保持简洁”的全局应该做，变成“在第一个90个字符中带头动词”对于Twitter/X）。
6. 重新做语气调节矩阵的相关列。
7. 编写适配部分或新文件。

## 重要限制

- **声音不会改变。语气会改变。** 如果你发现自己为某个渠道重写声音属性，请停止——这是SOUL.md的更改，而不是渠道适配。
- **没有PDF输出，没有装饰性格式。** TONE.md是纯Markdown，以便任何下游技能或机器人可以确定性地解析它。避免ASCII艺术、在声音属性部分中复杂的表格，或任何会破坏Markdown解析器的内容。
- **为研究得出的声明引用来源。** 当第二阶段的研究为TONE.md提供信息时，在类别部分中脚注来源——未来的维护人员需要在规范变化时验证（尤其是快节奏类别，如游戏和加密货币）。
- **不要原封不动地借用声音。** “我们想听起来像Oatly / Mailchimp / Duolingo”简报会产生衍生的声音，受众越来越能检测到（尤其是AI生成的）。使用参考进行三角测量，而不是模仿。风格下的策略使声音有效，而不是表面的姿态。
- **禁用词列表比力量词列表做更多工作。** 预防比处方更便宜——遇到“我们不使用'leverage'（除非在金融意义上）”的写手永远不会再次使用它。相比之下，力量词列表很少在此时被查阅。
- **政治、受监管行业、宗教组织、国防、医疗保健专业人士沟通、游戏、成人内容、运动队、金融科技-加密货币** → 通过第二阶段进行研究。不要应用消费者品牌的默认值。每个都有由受众、监管和平台塑造的声音规范，这些规范会覆盖通用指南。
- **对于多区域品牌**，按区域记录声音，而不是从一种源语言翻译。翻译是标准；将英语品牌声音表面翻译成法语或日语会产生不适应当地市场的生硬文案。

## 免责声明

此技能并不详尽。语气的学科正在迅速发展，尤其是在AI生成内容将差异化转移到其他地方时。

- 参考规范来源以获取当前最佳实践：Mailchimp的内容风格指南、GOV.UK的风格指南、Nielsen Norman Group的《声音的四个维度》、Karen Yin的Conscious Style Guide、Margot Bloomstein的《值得信赖的》、以及[参考资料/参考品牌.md](参考资料/参考品牌.md)中发布的品牌声音指南。
- 声音规范因类别和区域而异；在提交到TONE.md之前，请先验证任何让您惊讶的模式，以品牌实际类别和市场为准。
