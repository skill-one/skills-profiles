# impeccable (`pbakaus/impeccable/impeccable`)

## blackbox

**function**: 审查并直接改好你的网页/应用界面——从整体布局到字体、配色、间距、动效、报错提示，最后交付能直接用的代码。

- input: 一个网页的截图或 URL，说「帮我看看这个页面有什么问题」, output: 一份评审报告：逐条指出体验问题并打分，每条都附具体的改法建议
- input: 一句需求，如「给我的 SaaS 产品做一个定价页」, output: 完整可运行的页面代码，桌面和手机都适配好，打开就能用
- input: 现有页面的代码 + 一句指令，如「太花哨了，调得安静克制一点」, output: 改好的代码：视觉更收敛、重点更突出，功能原样保留，不推倒重来
- input: 现有页面代码 + 「补上加载失败、网络出错这些情况的处理」, output: 补全了报错提示、加载状态、极端情况兜底的代码，细节经得起真实用户折腾
