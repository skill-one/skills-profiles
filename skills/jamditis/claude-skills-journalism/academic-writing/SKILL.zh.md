# 学术写作与研究方法

系统化方法用于学术写作、研究设计以及学术交流。

## 研究设计基础

### 研究问题发展

```markdown
## 构建研究问题

### FINER 标准
- **F**easible（可行性）：你能实际完成这项研究吗？
- **I**nteresting（趣味性）：它对领域重要吗？
- **N**ovel（新颖性）：它是否增加新知识？
- **E**thical（伦理性）：它能否合乎伦理地进行？
- **R**elevant（相关性）：它是否解决实际问题？

### 问题类型
| 类型 | 目的 | 示例 |
|------|-------|-------|
| 描述性 | 记录现象 | "X 的特征是什么？" |
| 比较性 | 比较组别/条件 | "X 在不同组别中如何差异？" |
| 相关性 | 检验关系 | "X 和 Y 之间是否存在关系？" |
| 因果性 | 建立因果关系 | "X 是否导致 Y？" |
| 探索性 | 生成假设 | "哪些因素可能解释 X？" |

### 优化你的问题
从宽泛开始 → 逐步缩小范围

草稿 1："社交媒体如何影响政治？"
草稿 2："Twitter 使用如何影响政治极化？"
草稿 3："接触党派性 Twitter 账户如何影响美国成年人政治态度极化？"
草稿 4："增加接触同质化意识形态的 Twitter 信息流是否会增加 18-35 岁美国政治参与者的情感极化？"
```

### 文献综述策略

```markdown
## 系统文献检索

### 按领域选择数据库
- **跨学科**：Web of Science、Scopus、Google Scholar
- **社会科学**：JSTOR、ProQuest、SSRN
- **传播学**：Communication Abstracts、ComAbstracts
- **健康**：PubMed、MEDLINE、CINAHL
- **教育**：ERIC
- **商业**：Business Source Complete

### 检索策略模板
1. **从研究问题中识别关键概念**
2. **为每个概念生成同义词**
3. **结合布尔运算符**

示例：对于"社交媒体政治极化"

概念 1：社交媒体
- OR：Twitter、Facebook、Instagram、"社交网站"、"在线平台"、"数字媒体"

概念 2：政治
- OR：党派性、意识形态、选举、公民

概念 3：极化
- OR：分裂、极端主义、"态度变化"、"极端化"

组合检索：
(Twitter OR Facebook OR "社交媒体" OR "社交网站")
AND (政治 OR 党派性 OR 意识形态)
AND (极化 OR 分裂 OR 极端主义)

### 包含/排除标准
记录你的标准：
- 发表日期范围：[X 至当前]
- 语言：[仅英语 / 多种语言]
- 发表类型：[仅同行评审 / 包含预印本]
- 地理范围：[全球 / 特定国家]
- 方法论：[所有 / 特定方法]

### 管理检索
- 保存检索以供后续重新运行
- 将结果导出到参考文献管理器
- 跟踪每个阶段的检索结果数量
- 记录每次检索的日期
```

## 论文结构与写作

### IMRaD 结构（科学论文）

```markdown
## 标准研究论文部分

### 摘要（通常 150-300 字）
- 背景（1-2 句）
- 目的/目标（1 句）
- 方法（2-3 句）
- 结果（2-3 句）
- 结论（1-2 句）

### 引言
**漏斗结构：**
1. 广泛背景 - 为什么这个主题重要？
2. 缩小焦点 - 具体问题是什么？
3. 差距识别 - 我们不知道什么？
4. 研究问题/假设 - 你将研究什么？
5. 贡献预览 - 为什么这项研究重要？

### 文献综述
**按主题组织，而非按时间顺序：**
1. 主题 1：关键发现、争论、差距
2. 主题 2：关键发现、争论、差距
3. 主题 3：关键发现、争论、差距
4. 综合分析：主题如何与你的研究相关

### 方法
**可重复性测试：** 另一个研究者能否仅凭这一部分复制你的研究？

包括：
- 参与者/样本（谁，如何选择，N）
- 材料/测量（什么工具，其效度）
- 程序（一步一步发生了什么）
- 分析方法（统计检验、定性方法）
- 伦理考量（IRB、知情同意）

### 结果
**报告，不要解释：**
- 系统地呈现发现
- 使用表格/图表呈现复杂数据
- 报告效应量，而不仅是 p 值
- 针对每个研究问题/假设

### 讨论
**反向漏斗结构：**
1. 关键发现总结
2. 在文献背景下解释
3. 理论意义
4. 实践意义
5. 局限性
6. 未来研究方向
7. 结论
```

### 学术写作风格

```markdown
## 写作规范

### 语气和时态
| 部分 | 时态 | 示例 |
|------|-------|-------|
| 摘要 | 过去（方法/结果），现在（结论） | "我们发现... 这表明..." |
| 引言 | 现在（建立既有知识） | "研究表明..." |
| 方法 | 过去 | "参与者完成了..." |
| 结果 | 过去 | "分析显示..." |
| 讨论 | 现在 + 过去 | "这些发现表明... 我们发现..." |

### 委婉语言
适当使用委婉语（避免过度主张）：
- "这表明..."（不是"这证明了..."）
- "可能与...有关"（不是"导致"）
- "结果表明..."（不是"结果明确证明..."）
- "一种可能的解释..."（不是"解释..."）

### 按功能分类的过渡词
**添加：** furthermore、moreover、additionally、in addition
**对比：** however、nevertheless、conversely、in contrast
**因果关系：** therefore、consequently、as a result、thus
**示例：** for instance、specifically、to illustrate
**顺序：** first、subsequently、finally、meanwhile
**总结：** in summary、overall、in conclusion

### 段落
每个段落应：
1. 以主题句开头
2. 包含一个主要观点
3. 包括支持证据
4. 与相邻段落建立联系
5. 平均 100-200 字（因领域而异）
```

### 常见写作问题

```markdown
## 需要避免的问题

### 词藻过多
❌ "重要的是要注意结果表明..."
✅ "结果表明..."

❌ "为了调查..."
✅ "为了调查..."

❌ "共有 50 名参与者..."
✅ "五十名参与者..."

### 动词薄弱
❌ "研究由研究人员进行"
✅ "研究人员进行了研究"

❌ "发现显著差异"
✅ "我们发现显著差异"

### 含糊语言
❌ "一些研究表明..."
✅ "三项研究（作者，年份；作者，年份；作者，年份）表明..."

❌ "结果具有显著性"
✅ "结果具有统计学意义（p < .05, d = 0.45）"

### 不必要的术语
- 首次使用时定义技术术语
- 当简单词语同样精确时使用更简单的词语
- 考虑你的受众的专业水平

### 引文问题
❌ 未注明引用二级来源
✅ "(作者，年份，引自 作者，年份)"

❌ 未综合的字符串引文
✅ 将提出相同观点的引文分组；区分不同观点的引文
```

## 发表策略

### 期刊选择

```markdown
## 评估期刊

### 质量指标
- 影响因子（谨慎使用）
- 接受率
- 审稿时间
- 发表时间
- 领域声誉
- 索引（Web of Science、Scopus）

### 匹配指标
- 范围匹配
- 受众匹配
- 文章类型（实证、理论、综述）
- 开放获取途径（见下文）

### 开放获取途径
- **黄金 OA**：在完全开放获取期刊上开放发表；通常需要文章处理费 (APC)，通常 $1,000-$3,000+。
- **绿色 OA**：封闭获取期刊，但作者在允许的豁免期内将接受的手稿存档在存储库（机构、arXiv 等）。
- **钻石/白金 OA**：完全开放获取期刊，无 APC；由赞助商（学会、大学、联盟）支持。在社会科学和人文领域越来越常见。
- **混合型**：封闭获取期刊，允许单独文章以 APC 开放获取。注意：混合型*不符合* Plan S 合规性，也不符合许多资助方 OA 要求，提交前请核实。
- **青铜**：免费阅读但无正式 OA 许可；出版商可以撤销访问。合规目的视为非 OA。
- **资助方要求（美国+欧洲，截至 2026 年）**
- **OSTP Nelson备忘录（美国）**：联邦资助研究必须出版后立即公开获取，无豁免期。实施截止日期为 2025 年底，因此截至 2026 年所有主要美国联邦资助者（NIH、NSF、DOE、NASA 等）均适用。
- **Plan S（cOAlition S）**：欧洲资助者（Wellcome、UKRI、ANR 等）要求立即开放获取（黄金或白金 OA），或无豁免期、CC-BY 许可的绿色 OA。混合型不符合要求。
- 提交前核实资助方最新政策，接受途径会变化，部分资助者会限制 APC。
- **预警（掠夺性期刊）**
- 侵略性邮件营销
- 快速"同行评审"（几天）
- 不明确的编委会
- 未被主要数据库索引
- "付费发表"而无明确的 OA 模型
- 网站质量差

### 审核期刊和伦理资源
- **Think. Check. Submit.**（thinkchecksubmit.org），合法性清单。
- **DOAJ**（开放获取期刊目录），经审核的 OA 期刊索引。
- **Journal Citation Reports**，Web of Science 的付费产品，用于影响因子。
- **Cabells 掠夺性报告**，基于订阅的 Beall's List 替代品，该列表于 2017 年被下架（只有过时的镜像仍然存在，不要依赖它们作为当前真理来源）。
- **Retraction Watch Database**，可搜索的撤回和出版商不当行为记录；用于审核作者和期刊。
- **COPE**（出版伦理委员会，publicationethics.org），编辑和作者在伦理和诚信方面的权威指南。
- **ICMJE**（国际医学期刊编辑委员会，icmje.org/recommendations），定义作者资格、利益冲突披露和报告标准，在许多领域使用。
```

## 预印本和持久标识符

### 预印本服务器（发布工作版本，提前获得引用）

预印本是作者在正式同行评审前发布的稿件。目前大多数期刊都允许（或积极鼓励）预印本发布；如果您不确定，请在发布前核实目标期刊的政策。

| 服务器 | 领域 | 备注 |
|--------|-------|-------|
| **arXiv** (arxiv.org) | 物理学、数学、计算机科学、定量生物学、经济学、统计学 | 最古老、最大；由各领域进行审核。 |
| **SSRN** (ssrn.com) | 社会科学、法律、经济学、金融学 | 自2016年起由Elsevier拥有，一些作者更倾向于将SocArXiv作为替代选项。 |
| **bioRxiv** (biorxiv.org) | 生物学 | 冷泉港实验室；被广泛引用。 |
| **medRxiv** (medrxiv.org) | 健康科学、医学 | 轻度审核以确保安全声明；未经预先登记不得预印临床试验结果。 |
| **EarthArXiv** | 地球科学、行星科学、环境科学 | 通过OSF基础设施运行的社区项目。 |
| **PsyArXiv** | 心理学 + 行为科学 | 由OSF托管。 |
| **SocArXiv** | 社会学 + 社会科学 | 由OSF托管；是Elsevier的独立替代品。 |
| **EngrXiv** | 工程学 | 由OSF托管。 |

**预印本的原因：** 优先权声明上的时间戳更快，在期刊接受前即可被引用，并在最终评审前获得更广泛的反馈。（2026年OSTP Nelson备忘录规定了联邦资助的美国研究在发表时立即公开其同行评审版本，这不是预印本要求。预印本是另一种自愿选择，补充但不满足Nelson备忘录的合规要求。）

### 持久标识符，获取ORCID并使用DOI

- **ORCID iD** (orcid.org)，免费16位标识符，可明确地将您链接到不同的出版商、资助机构和机构。大多数主要期刊和资助机构都要求提供ORCID。将其与您的简历、稿件、数据集、软件和资助申请关联起来。
- **DOI** (doi.org)，学术对象的持久标识符。在稿件被接受时由期刊自动分配；您也可以通过Zenodo（zenodo.org）或您所在机构的存储库为您的数据集、代码、海报和预印本创建DOI，这对于引用非期刊输出非常有用。
- **ROR** (ror.org)，研究组织的持久标识符，资助机构和出版商使用它来区分机构名称。

## 研究伦理

### 伦理考虑清单

```markdown
## 在开始研究之前

### 人类受试者
- [ ] 获得IRB/伦理委员会批准
- [ ] 建立知情同意程序
- [ ] 确定并保护弱势群体
- [ ] 制定隐私和保密措施
- [ ] 制定数据安全计划
- [ ] 风险/收益比可接受

### 数据管理
- [ ] 制定数据管理计划
- [ ] 安排安全存储
- [ ] 记录共享/存档计划
- [ ] 确定保留期限
- [ ] 制定销毁程序

### 作者身份
- [ ] 讨论贡献标准（使用ICMJE定义：实质性贡献 + 撰写/修订 + 最终批准 + 责任）
- [ ] 确定作者顺序
- [ ] 所有贡献者都将满足作者身份标准
- [ ] 计划对非作者贡献者表示感谢
- [ ] **CRediT分类法**（credit.niso.org）为每位作者分配角色，大多数主要期刊现在要求或建议CRediT，它有14个标准化的贡献者角色（概念化、方法学、软件、验证、形式分析、调查、资源、数据管理、初稿撰写、撰写-审查和编辑、可视化、监督、项目管理、资金获取）。

### 利益冲突
- [ ] 识别财务利益冲突
- [ ] 识别非财务利益冲突
- [ ] 制定披露计划

### 可重复性
- [ ] 在数据收集前在**OSF**（osf.io）或**AsPredicted**（aspredicted.org）上预先注册分析计划，区分确认性分析和探索性分析，并防止HARKing。检查目标期刊是否接受**已注册报告**（在数据收集前对设计进行同行评审，无论结果如何原则上都接受），这种格式现在存在于2026年心理学、生物医学和社会科学领域的350多家期刊。
- [ ] 将代码共享（考虑使用GitHub发布+Zenodo DOI为版本化、可引用的代码存档）
- [ ] 将数据共享（FAIR原则；机构存储库、Dryad、Figshare或适当的特定领域存储库）
- [ ] 将材料共享
```

### 避免研究不当行为

```markdown
## 不当行为的类型

### 捏造
- 编造数据或结果
- 在任何情况下都是不可接受的

### 欺诈
- 操纵数据、设备或流程
- 选择性地省略数据以改变结论
- 超出可接受调整范围的图像操作

### 抄袭
- 未经归因使用他人的文字
- 自我抄袭（未经说明地重复自己已发表的作品）
- 过度接近地释义

### 其他可疑行为
- P-hacking（运行多次分析直到获得显著结果）
- HARKing（在结果已知后假设）
- 薄饼切片（将一项研究拆分成多篇论文）
- 赠送/幽灵作者
- 选择性报告结果
```

## AI / 大型语言模型在学术写作中的应用

LLM辅助写作是2024-2026年学术出版中定义的伦理问题。每个主要期刊、资助机构和伦理机构都在这个时间段内发布了政策，并且政策仍在收紧。将以下内容视为底线，而不是上限：在提交前，请阅读目标期刊当前的投稿指南和资助机构最新的政策。

### 每个都普遍禁止的（截至2026年）

- **LLM作者身份。** ICMJE、COPE、Nature、Science、NEJM、Cell、JAMA、Lancet以及主要大学出版社都明确禁止将LLM（ChatGPT、Claude、Gemini等）列为合著者。LLM无法满足作者身份要求的责任和批准标准。使用致谢部分或方法/披露声明，而不是作者署名。

- **生成捏造的引用。** LLM已被证明可以生成看似合理但实际上捏造的DOI、页码，甚至不存在的作者/标题组合。稿件中的每一条引用都必须与来源核实，LLM引起的假引用率自2023年以来一直是撤稿的主要触发因素。

- **生成数据、结果或图像。** 合成实验数据、捏造图表或使用生成式AI来“填补”未实际获得的结果是COPE定义下的研究不当行为。

- **未披露的重大使用。** 大多数期刊要求披露任何超出琐碎拼写/语法辅助的LLM使用。未披露有意义的使用可能是撤稿的理由。

### 通常允许的（需披露）

- 想法头脑风暴和提纲
- 语言润色和语法校正
- 翻译自己的写作
- 为分析生成代码（需明确测试）
- 总结自己的笔记或转录
- 生成样板部分（封面信、IRB语言），然后进行事实核查并拥有

### 披露语言（模板）

大多数期刊希望方法/致谢声明中命名工具、版本（如果可用）以及它被用于什么。示例：

> 在准备这项工作的过程中，作者使用了[工具名称，例如GPT-5.6 Sol、Claude Opus 5、Gemini 3.7 Flash]来[具体用途，例如润色引言；为第3.2节中的聚类分析起草代码]。使用该工具后，作者根据需要审查和编辑了内容，并对发表内容负全部责任。

根据目标期刊的确切要求调整措辞，Elsevier、Springer Nature、Wiley、Taylor & Francis、IEEE和ACM各自发布了自己的首选语言。

### 提交前的披露清单

- [ ] 阅读目标期刊当前的投稿指南中的AI/LLM政策（每年更新多次）。
- [ ] 阅读您的资助机构的政策，一些（Wellcome、NSF）的规定比期刊更严格。
- [ ] 使用期刊的首选语言添加披露声明。
- [ ] 手动核实每一条引用，不要信任LLM输出的任何DOI、作者列表、页码范围或引用段落。
- [ ] 核实每一个数字声明、日期和命名事实。
- [ ] 重新阅读整篇稿件，确保您的声音和论证结构占主导地位，而不是LLM的。
- [ ] 如果LLM用于代码或分析，使用种子重新运行并验证所有报告的数字是否可重复。

### 检测工具（有限可靠性）

GPTZero、Turnitin AI检测、Originality.ai等工具已记录对非母语英语作者和合法人类撰写的技术文本的高误报率，以及对当前模型轻微编辑的高误报率。**Pangram Labs**（pangram.com）已发布更严格的基准测试，并在大致相同设置下表现优于旧检测器，但仍不是最终的仲裁者，并且在作者大幅编辑LLM输出时共享相同的根本限制。检测结果不应作为不当行为的唯一依据；依赖它作为审查信号的期刊越来越多地撤回这一做法。将检测结果视为与作者进一步讨论的标志，而不是自有的证据。

## 生产力和工作流程

### 写作常规

```markdown
## 可持续学术写作

### 每日写作练习
- 每天同一时间写作（习惯养成）
- 从最小可行目标开始（例如，30分钟）
- 跟踪进度（字数、时间）
- 保护写作时间免受会议/邮件干扰
```

### 管理大型项目
1. 分解为尽可能小的任务
2. 为每个部分设定截止日期
3. 安排定期写作时间
4. 预留缓冲时间
5. 尽早并经常获取反馈

### 克服障碍
- 从最简单的部分开始
- 撰写“糟糕的第一稿”（安妮·拉莫特）
- 使用占位符标记引用/数据
- 与同事讨论想法
- 改变环境
- 返回提纲/结构
```
