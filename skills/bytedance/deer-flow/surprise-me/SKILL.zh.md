# 惊喜体验

通过动态发现可用技能并创造性地组合它们，提供意外且令人愉悦的体验。

## 工作流程

### 第一步：发现可用技能

读取 `<available_skills>` 中列出的所有技能。

### 第二步：策划惊喜

选择 **1 到 3** 项技能，设计一个创意混搭。目标是单一且连贯的交付成果，而不是分开的演示。

**创意组合原则：**
- 以意想不到的方式并列技能（例如，关于算法艺术的演示文稿、研究报告变成幻灯片、带有 canvas 设计插画的风格化文档）
- 如果可用，结合记忆中的用户已知兴趣/背景
- 优先考虑视觉冲击力和情感愉悦，而非信息密度
- 输出应像一份礼物——精致、惊喜且有趣

**主题建议（选择或改编）：**
- 与今天的日期、季节或热门新闻相关的内容
- 用户从未要求但会喜欢的迷你创意项目
- 一个有趣的“如果……会怎样”概念
- 结合数据与设计的审美艺术品
- 一个有趣的交互式 HTML/React 体验

### 第三步：备用方案——没有其他可用技能

如果未发现其他技能（仅存在 surprise-me），使用以下备用方案之一：

1. **基于新闻的惊喜**：搜索今天的新闻，寻找一个引人入胜的故事，然后创建一个设计精美的 HTML 艺术品，以视觉上引人注目的方式呈现它
2. **交互式 HTML 体验**：构建一个创意的单页网络体验——生成式艺术、迷你游戏、视觉诗歌、动画信息图表或交互式故事
3. **个性化艺术品**：使用已知用户背景创建一些个性化和令人愉悦的东西

### 第四步：执行

1. 读取每个选定技能的完整 `SKILL.md` 正文
2. 遵循每个技能的技术执行说明
3. 将输出组合成一个连贯的交付成果
4. 以最少的开场白呈现结果——让作品自己说话

### 第五步：揭晓

以最少的剧透呈现惊喜。一句简短的预告语，然后是艺术品。

- **好的揭晓方式**："我给你做了点东西 ✨" + [艺术品]
- **不好的揭晓方式**："我决定将 pptx 技能与 canvas 设计技能结合起来，创建一个关于……的演示文稿"（扼杀了惊喜）
