# 使用对等连接连接 VPC

## 概述

关于使用 VPC 对等连接在两个 VPC 之间建立私有网络连接的专业知识。涵盖完整生命周期：创建对等连接、接受连接、更新两个 VPC 中的路由表、配置 DNS 解析以及调整跨 VPC 流量的安全组。支持同区域、跨区域和跨账户对等场景。

## 创建 VPC 对等连接

要在两个 VPC 之间建立对等连接，请严格按照流程操作。
参见 [VPC 对等连接流程](references/vpc-peering-connection.md)。

该流程至少需要请求者和接受者 VPC ID。它会验证两个 VPC 是否存在，检查 CIDR 重叠，创建并接受对等连接，更新所有路由表并配置 DNS 解析。

## 故障排除

### 对等连接卡在 pending 状态

跨账户连接需要接受者账户手动接受。同账户连接且 `auto_accept: true` 应自动转换。

### 路由创建失败

检查是否存在相同目标 CIDR 的现有路由。应替换现有路由而不是创建新路由。

### DNS 解析不工作

两个 VPC 都必须在 VPC 设置中启用 DNS 解析和 DNS 域名，而不仅仅是对等连接选项。

### 跨区域连接问题

验证两个区域都添加了路由，并且安全组允许来自对等 VPC CIDR 块的流量。
