# 期权收益曲线技能

通过 `visualize:show_widget` 生成一个完全交互式的 HTML 小部件，显示：
- **到期收益曲线**（虚线灰色）—— 到期时的内在价值
- **理论价值曲线**（实线彩色）—— 当前 DTE/IV 的 Black-Scholes 价格
- 所有关键参数的动态滑块
- 实时统计数据：最大利润、最大亏损、盈亏平衡点、当前现货 P&L

## 第 1 步：从用户输入中提取策略

当用户提供截图或文本时，提取：

| 字段 | 在哪里查找 | 缺失时的默认值 |
|---|---|---|
| 策略类型 | 标题栏 / 合约描述 | "自定义" |
| 标的资产 | 股票代码 | SPX |
| 行权价 | 标题或合约表中的 K1、K2、K3... | 最近的一个整数 |
| 支付/收取的权利金 | 填充价格或平均价格 | 5.00 |
| 数量 | 头寸大小 | 1 |
| 乘数 | 股票期权为 100，SPX 为 100 | 100 |
| 到期日 | 标题中的日期 | 30 DTE |
| 现货价格 | 截图或文本中显示的标的资产当前价格 | 实时报价（见下文）；如果没有报价，则取中间行权价 |
| 波动率 | 显示在希腊字母面板中，或通过 vega 估计 | 20% |
| 无风险利率 | — | 4.3% |

**截图的现货价格**：现货是标的资产的当前价格，而经纪商的截图经常省略它或将其显示在行权价很远的地方——不要从行权价标签中读取。使用显示的价格，否则使用实时报价（见下文的 SPX 探针，或 yfinance 用于其他标的资产）。只有在没有报价时才回退到中间行权价，并告知用户您已这样做。

## 第 2 步：识别策略类型

匹配到下面支持的一种策略，然后阅读 `references/strategies.md` 中的相应部分。

| 策略 | 合约数量 | 关键标识符 |
|---|---|---|
| **蝶式价差** | 买入 K1，卖出 2×K2，买入 K3 | 3 个行权价，标题中包含 "Butterfly" |
| **垂直价差** | 买入 K1，卖出 K2（相同到期日） | 2 个行权价，贷方或借方 |
| **日历价差** | 买入远期到期 K，卖出近期到期 K | 相同行权价，2 个到期日 |
| **铁蝶式价差** | 卖出 K2/K3，买入 K1/K4 翅膀 | 4 个行权价，2 个价差 |
| **跨式价差** | 买入看涨期权 K + 买入看跌期权 K | 相同行权价，两种类型 |
| **宽跨式价差** | 买入虚值看涨期权 + 买入虚值看跌期权 | 2 个行权价，均虚值 |
| **备兑看涨期权** | 长头 100 股 + 卖出看涨期权 K | 股票 + 空头看涨期权 |
| **裸看跌期权** | 卖出看跌期权 K | 单个合约 |
| **比例价差** | 买入 1×K1，卖出 N×K2 | 不等的数量 |

对于未列出的策略，使用 `自定义` 模式：分解为单个合约并汇总其 P&L。

## 第 3 步：计算收益

### Black-Scholes 看跌期权价格
```
d1 = (ln(S/K) + (r + σ²/2)·T) / (σ·√T)
d2 = d1 - σ·√T
put = K·e^(-rT)·N(-d2) - S·N(-d1)
```

### Black-Scholes 看涨期权价格（通过看跌期权平价）
```
call = put + S - K·e^(-rT)
```

### 蝶式看跌期权收益（到期）
```
if S >= K3: 0
if S >= K2: K3 - S
if S >= K1: S - K1
else: 0
```
每股净 P&L = 收益 − 支付的权利金

### 垂直价差（看涨期权借方）收益（到期）
```
long_call = max(S - K1, 0)
short_call = max(S - K2, 0)
payoff = long_call - short_call - 净借方
```

### 日历价差理论价值
日历不能表示为简单的到期函数——始终使用 Black-Scholes 定价法为两个合约定价：
```
value = BS(S, K, T_far, r, IV_far) - BS(S, K, T_near, r, IV_near)
```
对于日历的到期曲线：近期合约到期作废，远期合约 = Black-Scholes 剩余 T。

### 铁蝶式价差收益（到期）
```
put_spread = max(K2-S, 0) - max(K1-S, 0)   // 空头看跌期权价差
call_spread = max(S-K3, 0) - max(S-K4, 0)  // 空头看涨期权价差
payoff = 收到的信用 - put_spread - call_spread
```

## 第 4 步：渲染小部件

在构建之前，使用 `visualize:read_me` 并加载模块 `["chart", "interactive"]`。

### 必需的控件（滑块）

**结构部分：**
- 所有行权价（K1、K2、K3... 根据策略需要）
- 支付/收取的权利金
- 数量
- 乘数（默认为 100，清晰显示）

**定价变量部分：**
- 波动率 %（5–80%，步长 0.5）
- DTE — 到期日（0–90）
- 无风险利率 %（0–8%）

**现货价格：**
- 全宽滑块，范围 = [min_strike - 20%, max_strike + 20%]，默认为实际当前现货

### 必需的统计卡片（实时更新）
- 最大利润（到期）
- 最大亏损（到期）
- 盈亏平衡点 — 对于双边策略显示两个
- 当前现货价格的理论 P&L

### 图表规格
- X 轴：SPX/标的资产价格
- Y 轴：总美元 P&L（不是每股）
- 蓝色实线 = 当前 DTE/IV 的理论价值
- 灰色虚线 = 到期收益
- 绿色虚线垂直线 = 行权价（K2 中心行权价更亮）
- 黄色虚线垂直线 = 当前现货价格
- 0 上方填充 = 绿色 10% 透明度；0 下方 = 红色 10% 透明度
- 提示：悬停时显示两条曲线
