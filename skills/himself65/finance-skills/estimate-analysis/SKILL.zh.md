# 估算分析技能

使用 Yahoo Finance 数据，通过 [yfinance](https://github.com/ranaroussi/yfinance) 深入分析分析师的估算和修订趋势。涵盖每股收益 (EPS) 和收入估算分布、修订动能、增长预测和多周期比较——全面了解市场认为公司未来将走向何方。

**重要提示**：数据仅供研究和教育目的使用。非投资建议。yfinance 与雅虎公司无关。

## 第 2 步：确定股票代码并收集估算数据

从用户请求中提取股票代码。在一个脚本中获取所有与估算相关的数据。

```python
import yfinance as yf
import pandas as pd

ticker = yf.Ticker("AAPL")  # 替换为实际股票代码

# --- 估算数据 ---
earnings_est = ticker.earnings_estimate      # 各周期的每股收益估算
revenue_est = ticker.revenue_estimate        # 各周期的收入估算
eps_trend = ticker.eps_trend                 # 每股收益估算随时间的变化
eps_revisions = ticker.eps_revisions         # 上涨/下调修订次数
growth_est = ticker.growth_estimates         # 增长率估算

# --- 历史背景 ---
earnings_hist = ticker.earnings_history      # 追踪记录
info = ticker.info                           # 公司基本信息
quarterly_income = ticker.quarterly_income_stmt  # 近期实际数据
```

### 每个数据源提供的内容

| 数据源         | 显示内容                     | 重要性                     |
|---------------|-----------------------------|-----------------------------|
| `earnings_estimate` | 各周期的当前每股收益共识 (0q, +1q, 0y, +1y) | 估算水平——分析师的预期         |
| `revenue_estimate` | 各周期的当前收入共识         | 收入预期                     |
| `eps_trend`   | 每股收益估算的变化 (7d, 30d, 60d, 90d 前) | 修订方向——预期上升或下降         |
| `eps_revisions` | 过去 7 天和 30 天的上涨/下调修订次数 | 修订广度——大多数分析师是提高还是下调？ |
| `growth_estimates` | 与同行和行业的增长率估算比较 | 相对定位                     |
| `earnings_history` | 过去 4 个季度的实际值与估算值比较 | 校准——这些估算的历史表现如何？ |

## 第 4 步：构建估算分析

### 第 1 部分：估算概述

从 `earnings_estimate` 和 `revenue_estimate` 中呈现每个可用周期的当前共识（0q, +1q, 0y, +1y）：共识、低值、高值、范围宽度（作为共识的百分比）、分析师数量和同比增长。标记：

- **范围宽度**——范围超过共识 15% 表示高度不确定性
- **分析师覆盖范围**——少于 5 位分析师表示覆盖面较窄
- **增长轨迹**——各周期增长是加速还是减速

### 第 2 部分：修订趋势 (EPS 趋势)

通常是可操作性最强的部分。从 `eps_trend` 中，显示每个周期的当前估算值及其 7 天、30 天、60 天和 90 天前的值，并总结方向以及近期变动是否加速。

如何解读：
- 估算在财报发布前上升 = 积极布局（条形图上升）
- 估算下降 = 分析师下调数字，通常是负面信号
- 估算持平 = 没有新的信息被定价
- 近期加速或减速比总变动更重要

### 第 3 部分：修订广度 (EPS 修订)

从 `eps_revisions` 中，显示每个周期的过去 7 天和 30 天的上涨/下调修订次数，以及修订比率 Up / (Up + Down)。比率高于 0.7 是强烈看涨；低于 0.3 是看跌。

### 第 4 部分：增长估算

从 `growth_estimates` 中，比较公司每个周期的预期增长率（及其过去 5 年的年增长率）与行业、部门和标普 500，并说明其预期是比同行增长更快还是更慢。

### 第 5 部分：历史估算准确性

从 `earnings_history` 中，显示过去四个季度的估算值与实际每股收益以及意外百分比，然后评估：

- **达标率**——四个季度中有多少个季度达标
- **平均意外**——幅度和方向
- **意外趋势**——达标是变大还是变小？意外的缩小与上升的估算可能意味着标准正在追上现实。

## 第 5 步：综合并回复

首先突出关键洞察——各周期的修订方向和广度——然后显示用户关心的部分的表格。解释而不仅仅是列表示：修订趋势是否证实或反驳了股票的近期价格行动，增长预期与当前市盈率定价相比如何，估算准确性历史对今天的共识有何启示？

标记适用的细微差别：估算通常围绕共识聚集，因此实际结果的分布比低/高值更宽；修订动能可能在单一指引变化或宏观事件后逆转；Yahoo Finance 估算可能落后于实时共识提供者数小时或数天；远期（+1y）估算本质上不太可靠。最后，重申注意事项：分析师估算反映的是共识观点，而非确定性；修订是信号，而非保证；这不是投资建议。
