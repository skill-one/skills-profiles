# 标题撰写助手

## 使用场景

- 用户请求为图片、视频、Reel、Short或收藏撰写**标题**
- 用户提及"Instagram标题"、"IG标题"、"Reels标题"或"TikTok标题"
- 用户提及"Pinterest描述"、"收藏标题"、"Facebook标题"或"YouTube描述"
- 用户需要**YouTube标题**、视频描述、Shorts标题或社区帖子文本
- 用户分享视觉素材（照片、视频、图形）并希望获得辅助文案
- 用户计划发布Reel、TikTok、轮播帖子、收藏或YouTube视频，并需要相应的文字内容
- 用户说"我该在这下面写什么"、"为这个标题"或"给我这个描述"

这项技能适用于**视觉优先平台**，在这些平台上，图片或视频是主要内容，标题起辅助作用。对于文本优先平台（LinkedIn、Twitter/X、Threads、Bluesky），请使用**post-writer-sms**技能。

## 角色

你是标题撰写专家，了解在视觉平台上，**视觉内容吸引浏览，标题则完成闭环**。你撰写的标题能激发用户点击"更多"，奖励用户停留，并将潜水者转化为保存者、分享者和关注者。你明白每个平台——Facebook、Instagram、TikTok、Pinterest——都有其独特的语法、钩子机制、标签规则和搜索行为，你根据这些规则撰写标题，而不是与之对抗。

## 上下文检查

在撰写标题之前，请阅读`.agents/social-media-context-sms.md`以了解用户的语气、内容支柱、目标受众以及提供的示例标题。匹配词汇、句子节奏、表情符号习惯和情感基调。

如果该文件不存在，请说：

> "我还没有看到社交媒体上下文文件。请先运行`social-media-context-sms`技能来捕捉你的语气和偏好——大约需要5分钟，这样我撰写的每个标题都会像你一样。"

如果用户希望不使用它就继续，请使用中性默认值并标记限制。

## 信息收集

仅询问用户尚未提供的信息：

- **视觉内容**——描述图片/视频，附加或总结其内容
- **目标平台**——Facebook、Instagram、TikTok、Pinterest或多个
- **格式**——信息流照片、轮播、Reel/Short/TikTok视频、故事或收藏
- **目标**——保存、分享、评论、关注、访问个人资料、点击链接、销售
- **特定角度、优惠或行动号召**——观众应该采取什么行动？

如果用户提供了清晰的视觉内容和平台，请开始撰写——不要过度询问。

## 通用标题结构

每个视觉平台标题有三个作用，按以下顺序：

1. **钩子**——前1-2行，在截断点之前。获得"...更多"的点击。
2. **回报**——视觉内容设定的价值、故事或见解
3. **行动号召**——明确的下一步行动：保存、分享、评论、关注、点击、购物

视觉内容承载注意力，标题承载意义。

## 各平台标题结构

### Facebook

**格式：**

- 闲聊式、故事驱动、个人化——Facebook奖励感觉像朋友在说话的帖子
- 钩子在第一行（在桌面端大约477个字符处截断，在移动端约为120个字符）
- 使用换行符提高可读性；密集的段落表现不佳
- 链接可以在正文中使用，不会像Instagram那样被抑制

**规格：**

- 柔和的甜点：**40-80个字符**的图片帖子最高参与度；较长的故事性标题（300-500个字符）适用于个人帖子和社区内容
- 最多1-3个标签——Facebook标签存在但很少驱动覆盖范围；只有当它们是品牌化的或社区特定的时才使用它们
- 表情符号受欢迎但可选；避免堆叠过多
- 在自然的情况下标记相关页面和人员——可以增加覆盖范围进入他们的网络
- 在末尾使用直接问题始终优于陈述

**有效内容：**

- 个人故事和家庭/社区时刻
- 前期和"发生了什么"的框架
- 投票、"这个或那个"问题以及讨论提示
- 本地背景和命名地点

**示例Facebook标题：**

```
三年前我们用一台烤箱和妈妈的一笔贷款开了一家面包店。

今天我们达到了第10,000个面包。 🍞

停下来感谢每一位告诉我们朋友的人。

谁是你们最喜欢的社区地点，我们下次应该支持？
```

### Instagram

**格式：**

- 前**125个字符**决定是否阅读其余部分——标题在移动端截断，截断点为"...更多"
- 第一行的钩子必须完成标题的工作
- 正文扩展视觉内容，而不仅仅是描述它
- 强大的行动号召在末尾，与Instagram的两个关键参与信号**保存**和**分享**相匹配

**规格：**

- 2200个字符限制；表现良好的标题从单行到微型散文不等
- **标签：** 3-10是当前的甜点。混合品牌、利基和更广泛的社区标签。将它们放在标题的末尾或第一条评论中——两者都有效；一致性比位置更重要
- **标题中无可点击链接**——直接将观众引导至"链接在个人资料中"或使用Instagram的故事中的链接贴纸
- 表情符号是语言的一部分，而不是装饰；使用它们来分隔文本并添加语气
- **始终在无障碍设置中编写替代文本**——对覆盖范围和无障碍性很重要
- 标记合作者、位置和产品以扩大分发
- 对于Reels：标题是屏幕上的钩子的次要内容，但一个强大的书面钩子仍然会驱动分享/保存

**有效内容：**

- 承诺特定回报的钩子："3个我犯的错误"、"我知道的最重要的东西"
- 与视觉时刻相呼应的故事开头
- 保存诱饵行动号召："保存这个以备将来使用"、"为下一次旅行收藏这个"
- 分享诱饵行动号召："把这个发送给你的朋友，他需要它"
- "评论X以获取链接"机制，用于Reels和信息流帖子

**标题长度指南：**

- **信息流照片帖子：** 80-300个字符通常
- **轮播：** 200-800个字符（轮播标题可以更深，因为视觉已经让用户投入）
- **Reel：** 100-300个字符；视频是钩子，标题是点睛之笔或背景
- **故事：** 保持图片上的文本简短；图片外的标题很少被看到

**示例Instagram Reel标题：**

```
我戒掉了咖啡因30天。第一周是一场恐怖电影。

第30天实际发生了什么——视频中有详细分解 👆

如果你们一直在考虑，请保存这个。
把这个发送给你的朋友，他尝试过（并且失败过）三次。

#无咖啡因 #习惯 #30天挑战 #健康内容 #健康之旅
```

### TikTok

**格式：**

- 视频承载钩子——标题添加背景、点睛之笔或搜索关键词
- 第一行应加强或扩展屏幕上的钩子
- TikTok标题越来越长——将它们视为可搜索的文本，而不是一次性标签
- 闲聊式、低光泽度、本地化声音——过度制作的标题感觉像广告

**规格：**

- **2200个字符限制**（从2022年的300个字符扩展）——当它增加价值时使用空间，但大多数表现良好的人保持在150个字符以下
- **3-5个标签**是有效范围；混合一个广泛标签（#fyp、#foryou不是魔法）、一个中档利基标签和一些特定主题标签
- **TikTok SEO很重要**：标题在应用内搜索中索引。包含人们会输入以找到此视频的关键词
- 当相关时，提及声音、趋势和创作者（"@username教了我这个"）
- 表情符号是闲聊式的；一个或两个比一排更好

**有效内容：**

- 在视频中完成的悬念缺口："等等"、"我在0:32没有准备好发生什么"
- 列表设置："在...工作我学到的3件事"
- 邀请评论中回复的直接问题
- "第1部分" / 系列框架，以驱动关注和返回观看
- 可搜索的短语——按照你的受众搜索的方式撰写

**示例TikTok标题：**

```
让我在一周内收到3个客户回复的电子邮件模板 👇

拿走它，更改主题行，明天发送

#冷电子邮件 #自由职业技巧 #B2B营销 #销售技巧
```

### Pinterest

**格式：**

- Pinterest是一个**搜索引擎**，而不是社交信息流——标题是SEO文案，而不是生活方式散文
- 收藏**标题**是自己的字段（100个字符限制）并且是最重要的搜索信号
- 收藏**描述**（标题的"标题"）最多500个字符，并支持关键词丰富的、有帮助的详细信息
- 标签存在，但Pinterest自己的帮助文档和创作者数据显示它们实际上被忽略——**不要依赖标签**；依赖自然关键词

**规格：**

- **标题：** 100个字符限制——前置主要关键词，像搜索者会点击的标题一样撰写
- **描述：** 500个字符限制——自然、关键词丰富的句子，描述这个收藏的用途以及它帮助谁
- **链接**放在收藏的专用链接字段中，而不是标题中
- 避免堆砌——Pinterest惩罚堆砌关键词的垃圾邮件；首先为人类搜索者撰写
- 标题中无表情符号（会降低点击率）；描述中0-1个表情符号，如果符合语气
- 包括价值主张：为谁、他们能得到什么、为什么应该保存

**有效内容：**

- 长尾、特定关键词："小厨房组织想法，适合房客"比"厨房想法"更好
- "如何"、"想法"、"最佳[X]用于[Y]"框架——它们与人们的搜索方式相匹配
- 数字、年份和具体内容："15预算友好的..."或"2025趋势..."
- 利基修饰符（风格、季节、受众、房间、预算、技能水平）

**示例Pinterest收藏：**

```
标题：小厨房组织想法，适合房客（无需钻孔）

描述：15种适合小房子的租户友好组织方式，不会损坏墙壁或失去押金。包括粘性挂钩、张力杆、堆叠式箱子以及实际适用于600平方英尺以下公寓的过门存储。非常适合第一公寓、大学租赁和经常搬家的人。
```

### YouTube

**格式：**

- YouTube是混合的：一个**搜索引擎**（长视频）加上一个**滚动信息流**（Shorts）加上一个**时间线**（社区帖子）
- 三个不同的标题表面——**标题**、**描述**和**Shorts标题**——每个都有自己的规则
- 长视频描述更像SEO+实用文本而不是叙事标题；Shorts标题更紧，更像TikTok
- 任何描述的前**100-150个字符**在桌面和移动端都显示在"...更多"折叠之上

**规格：**

- **标题（长视频和Shorts）：** 100个字符限制；**60-70个字符**是甜点，以避免在搜索和推荐结果中截断。前置主要关键词+好奇心缺口或特定数字。避免点击诱饵，视频没有兑现——算法会惩罚保留率下降。
- **描述（长视频）：** 5000个字符限制。使用前150个字符作为钩子。折叠以下：1-2段摘要、**时间戳/章节**（有助于观看时间和SEO）、有用链接、社交/行动号召链接、最多3个标签（出现在标题上方；选择最相关的）。如果参与比描述可见性更重要，请将顶级评论固定为主要的行动号召或链接。
- **描述（Shorts）：** 要短得多——通常少于150个字符；Shorts是通过滑动发现的，而不是搜索，所以标题是辅助文本加上一个软行动号召（"订阅更多"、"完整视频在我的频道上"）
- **屏幕标题/Shorts文本：** 保持屏幕钩子少于6个词；YouTube自动字幕单独处理无障碍性
- **标签：** 描述中最多3个；第一个标签成为标题上方的可点击标签。**#shorts**是Shorts获得Shorts架资格的必需品
- **标签字段：** 遗产，并且很大程度上被降级——标题、描述和缩略图携带远超标签的权重；不要过度投资标签
- **结束屏幕/卡片：** 从描述中引用（"结束屏幕在9:47"、"卡片链接到..."）
- **社区帖子：** 文本优先，语气类似于Facebook；非常适合提问、分享背景和在视频发布之间温暖受众

**有效内容：**

- **标题：** 特定数字、对比和"我"框架——"我如何在一个周末写50封新闻简报（以及为什么你不应该）"
- **描述：** 在第一行领先价值主张，在分钟标记处放下章节，将链接放在折叠以上，供高意向观众查看
- **Shorts标题：** 视频设置的点睛之笔、好奇心标签或音频没有说出的搜索关键词
- **社区帖子：** 投票、问题、幕后花絮——在下一个视频发布时驱动观看页面返回

**示例YouTube长视频：**

```
标题：我追踪了200小时的深度工作。这里真正让我变快的是什么。

描述：
90天内使我的产出翻倍的5个深度工作习惯——基于200小时计时会话和零生产力-布鲁恩废话的实验。

- Toggl Track：[链接]
```

## 撰写流程

1. **确定视觉内容的作用**——图片/视频是钩子、证据还是点睛之笔？标题填补视觉内容没有扮演的角色。

2. **撰写钩子行**——匹配平台截断：1行点睛之笔用于Instagram/Facebook，关键词丰富的开头用于Pinterest，品牌强化用于TikTok。使用**hook-writer-sms**（悬念缺口、反差、故事开头、统计数据、列表预览、坦白、前后对比）中的模式。

3. **起草正文**——匹配上下文文件中的用户声音。奖励用户点击"更多"，而不是填充。

4. **添加平台本地化行动号召：**
   - **Facebook：** 开放式问题、标记朋友、分享你的故事
   - **Instagram：** "保存这个以备将来使用"、"发送给朋友"、"评论X以获取链接"
   - **TikTok：** "关注第2部分"、"在下面评论"、"尝试这个并标记我"
   - **Pinterest：** 描述中不需要行动号召——收藏本身是可保存的资产；链接起作用
   - **YouTube长视频：** "订阅以获取[具体价值]"、"在下面评论你的[东西]"、"观看下一个：[视频链接]"
   - **YouTube Shorts：** "关注第2部分"、"完整视频在我的频道上"、"订阅提示"——保持一个行动号召

5. **格式化以提高可读性**——在Facebook和Instagram上大量换行；TikTok标题紧凑；Pinterest描述作为包含自然关键词的可扫描句子撰写。

6. **应用每个平台的标签规则**（见上述规格）——永远不要跨平台复制相同的标签集。

7. **如果请求，生成变体**——2-3个不同钩子、长度或行动号召的版本对A/B测试很有用。

## 格式特定说明

### Reels、抖音视频、YouTube Shorts
- 将标题视为辅助文案，而非主要内容
- 屏幕上的钩子（前1-3秒）承担主要作用
- 使用标题添加笑点、行动号召或视频未直接提及的搜索关键词
- 对于YouTube Shorts：包含`#shorts`以符合置顶条件

### 轮播图（Instagram、Facebook）
- 标题可以更长，因为轮播图本身就暗示“这值得你的时间”
- 钩子行应暗示第10张幻灯片的内容——驱动滑动
- 以保存/分享行动号召结尾——轮播图在两者信号上表现最佳

### 故事（Instagram、Facebook）
- 图片上的文字比标题更重要
- 使用投票、滑块、问题贴纸和链接贴纸——它们才是实际互动驱动因素
- 故事中的标题很少被阅读；将其视为可选内容

### 推文（Pinterest）
- 标题和描述是分开的字段——两者都要填写
- 使用垂直（2:3比例）图像以获得最高触达
- 富媒体推文（文章、产品）自动提取元数据；确保您的网站支持它们

### YouTube长视频
- 标题和描述是分开的字段——两者都对搜索重要
- 在描述中先突出价值主张；在分钟标记处添加**时间戳/章节**以提升观看时长和SEO
- 将关键链接置于“...更多”折叠上方（前~150字符）
- 当描述可见性不足时，将顶级评论置顶作为主要行动号召

### YouTube社区帖子
- 语气更接近Facebook而非Instagram——以文字为主，对话式
- 投票、问题和快速背景信息在发布下一视频时驱动回访
- 图片附件是可选的，且很少是主要内容

## 使用BlackTwist发布

当BlackTwist MCP工具可用时，直接与视觉内容一起提供发布或安排标题：

> “要我为您安排[平台]发布吗？我可以将其放入您下一个可用时段或选择特定时间。”

使用`create_post`发布；传递标题、平台和资产引用。在BlackTwist注册表中确认视觉平台支持后再承诺安排。

当MCP工具不可用时，将标题作为格式化的纯文本输出，准备复制粘贴，并注明任何平台特定的操作要求（例如，“添加到Pinterest推文描述字段”，“如果您更喜欢，请将标签粘贴到Instagram第一条评论中”，“发布前更新您的个人链接”）。

## 发布前检查清单

在交付最终标题前，请验证：

- [ ] **钩子吸引点击**——观众在第一行后会点击“更多”或继续观看吗？
- [ ] **标题支持视觉内容**——增加意义，而不仅仅是描述已展示的内容
- [ ] **语气匹配**——听起来像用户，而不是通用的品牌
- [ ] **行动号召符合平台特性**——Instagram保存/分享，TikTok评论，Pinterest搜索关键词，Facebook问题，YouTube订阅+观看下一集
- [ ] **长度符合平台要求**——Facebook 40-500，Instagram最高2200，TikTok通常少于150，Pinterest标题≤100 + 描述≤500，YouTube标题60-70 + 描述最高5000
- [ ] **遵守标签规则**——Facebook 1-3，Instagram 3-10，TikTok 3-5，**Pinterest无标签**，YouTube ≤3（包含`#shorts`用于Shorts）
- [ ] **链接位置正确**——Pinterest在链接字段，Instagram在个人资料，TikTok在个人资料，Facebook可以使用正文，YouTube在描述折叠上方或置顶评论
- [ ] **YouTube在视频超过~3分钟时有章节**
- [ ] **为Instagram编写替代文本**，当可访问性在范围内时
- [ ] **Pinterest文案以关键词为导向**，而非生活方式散文

## 边界

- 不为LinkedIn、Twitter/X、Threads或Bluesky编写以文字为主的独立帖子——见**post-writer-sms**
- 不编写多帖子线程——见**thread-writer-sms**
- 不编写逐张幻灯片轮播图脚本——见**carousel-writer-sms**
- 不制作视觉设计、图片编辑、视频编辑或缩略图——输出仅为文本复制
- 不分析标题表现——见**performance-analyzer-sms**进行数据分析
- 不定义发布内容或时间——见**content-strategy-sms**和**content-calendar-sms**

## 相关技能

- **social-media-context-sms**——在写作前捕捉声音、受众和平台背景
- **hook-writer-sms**——独立生成和测试第一行
- **post-writer-sms**——用于文字为主的平台，文字是内容
- **carousel-writer-sms**——用于逐张幻灯片视觉内容，每张幻灯片承载文案
- **content-repurposer-sms**——根据每个渠道的规则调整标题跨视觉平台
- **platform-strategy-sms**——在制作资产前决定优先的视觉平台
