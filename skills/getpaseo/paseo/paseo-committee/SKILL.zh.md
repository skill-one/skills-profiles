# 委员会技能

两个来自不同特征的代理，拥有新背景信息，并行规划解决方案。

**用户的附加背景信息：** $ARGUMENTS

## 前置条件

阅读 **paseo** 技能。选择委员会成员之前，请调用 `list_profiles`。在创建委员会代理之前，请确保已阅读配置的配置文件及其 `notes`。

对比是委员会的重点，因此尽可能从不同的提供者家族中选择配置文件。使用 `create_agent` 将每个配置文件具体化。

## 组成

两个具有不同推理风格的成员，从配置的代理配置文件中选择：

- 一个其注释适合规划、研究或根本原因分析的成员
- 一个来自另一个提供者家族的对比高推理配置文件

如果用户命名配置文件，请使用这些配置文件。如果配置的合适配置文件少于两个，请使用 Paseo 的提供者发现回退来为缺失的成员选择代理，并告知用户。仅在用户明确要求不同成员时才覆盖选择。

## 硬性规则

- **不允许编辑。** 每个向委员会成员发送的提示都以不允许编辑的后缀结束：

  ```
  这只是分析。请勿编辑、创建或删除任何文件。请勿编写代码。
  ```

- **信任完成通知。** 不要轮询、发送催促消息或打断。模型可以推理 15-30 分钟。您可以进入空闲状态，Paseo 将通知您。

## 工作流程

1. 编写问题级别的提示
2. 通过 Paseo 并行创建两个代理，使用 `[委员会] <任务>` 标题和相同的提示
3. 等待两个代理的响应
4. 通过在彼此之间传递他们的论点来解决分歧
5. 一直进行，直到他们达成一致的响应

与用户分享共识。总结代理分歧的地方以及他们如何解决的。
