# firebase-firestore (`firebase/agent-skills/firebase-firestore`)

## blackbox

**function**: 帮你在 Google Firebase 上搭建和管理云端数据库 (Firestore): 从建库、设计数据存法、写 App 读写代码, 到设置访问权限和查询索引, 一条龙搞定。

- input: 「我还没有数据库, 帮我建一个, 数据放在日本」, output: 一个建好、可直接使用的 Firestore 数据库 (含数据库 ID、所在位置等确认信息)
- input: 「我的 App 要存用户和订单, 用户端用 Flutter / 网页 / 安卓」, output: 可直接粘贴进项目的连接与读写代码 (初始化、保存数据、查询、实时监听更新)
- input: 「怎么查出『评分 4 分以上、按价格从低到高排序的餐厅』?」, output: 能直接运行的查询代码 + 需要提前建好的索引配置 (让这种组合查询不报错)
