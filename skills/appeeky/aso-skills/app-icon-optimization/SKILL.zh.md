# 应用图标优化

你需要协助设计、审核和应用图标 A/B 测试，以最大化点击率（TTR）——即用户在搜索结果或浏览中看到你的应用后点击该应用的百分比。

## 图标是你的最具影响力的资产

图标是用户在搜索结果中看到的**第一件事**——在标题、评分或截图之前。一个有吸引力的图标可以在不进行其他更改的情况下将 TTR 提升 20–40%。在浏览/图表中，它通常是唯一争夺注意力的视觉元素。

## 图标设计原则

### 1. 小尺寸下的简洁性

图标在 60×60pt（iPhone 搜索结果）中渲染。在该尺寸下，细节会消失。

- 最多 2 个元素
- 不使用文本（在小尺寸下难以辨认；苹果不鼓励使用）
- 强大的轮廓，一眼就能识别
- 在最终确定前，在 60×60px 下进行测试

### 2. 与 App Store 背景的色差

App Store 有白色/浅色背景（浅色模式）和深色背景（深色模式）。

- 两种模式下都具有高对比度
- 避免白色图标——它们在浅色模式下会消失
- 避免非常深的图标——它们在深色模式下会消失
- 考虑在图标背景上添加微妙的阴影或边框

### 3. 类别视觉语言

匹配并区别于你的类别规范：

| 类别       | 常见模式     | 如何脱颖而出     |
|------------|--------------|-----------------|
| 生产力     | 蓝色、干净、极简 | 暖色调、粗犷的标记 |
| 健康/健身   | 绿色、橙色、充满活力 | 高级深色、精致     |
| 金融       | 蓝色、绿色、保守 | 粗犷、独特的标记   |
| 游戏       | 明亮、角色、动作 | 如果竞争对手很吵，则采用高级/深色 |
| 社交       | 圆形、柔和颜色 | 如果信息流柔和，则采用锋利、独特的图标 |
| 冥想       | 紫色、蓝色、平静 | 意想不到的对比色   |
| 照片/视频   | 渐变、相机     | 单一强烈的标记     |

**规则：**查看你前 20 名竞争对手的图标。然后设计以立即区分开来。

### 4. 可识别的标记

图标需要一个单一、难忘的标记——而不是场景或构图。问自己：

> "有人能用 3 个词描述这个图标吗？"

- ✅ "红色对话框" | ❌ "有人使用渐变手机的场景"
- ✅ "粗橙色火焰" | ❌ "抽象彩色形状"

### 5. 品牌一致性

图标是你在 App Store 中的品牌标记。它应该：
- 与你应用的主色调匹配
- 与你的启动画面、推送通知和营销保持一致
- 作为网站图标、社交媒体头像和新闻稿资产使用

## 需要的图标尺寸

| 平台       | 尺寸         |
|------------|--------------|
| iPhone (App Store) | 1024×1024px (主图) |
| iPhone (主屏幕) | 60×60pt @1x, @2x, @3x |
| iPad       | 76×76pt @1x, @2x |
| 手表       | 40×40pt – 44×44pt |
| Android 适应图标 | 108×108dp (安全区域 66×66dp) |

提交单个 1024×1024px PNG（无透明度，无圆角——苹果会应用蒙版）。

## 图标 A/B 测试

### iOS — 产品页面优化

1. App Store Connect → 你的应用 → 产品页面优化 → 创建测试
2. 创建最多 3 个图标变体
3. 设置流量分配（每个变体 20–33%）
4. 运行至少 7 天或直到达到统计显著性

**访问：**App Store Connect → App Store → 产品页面优化

### Android — Play Store 实验

1. Play Console → 店铺列表实验 → 新实验
2. 上传最多 3 个图标变体
3. 设置流量分割
4. Google 报告每个变体的安装转化率

### 要测试的内容

一次测试一个变量：

| 测试       | 变体         |
|------------|--------------|
| 色彩方案   | 相同标记，3 种不同的背景颜色 |
| 标记风格   | 平面 vs 插画 vs 3D |
| 深色 vs 浅色 | 深色背景 vs 浅色背景 |
| 角色vs抽象   | 基于角色的 vs 几何/抽象的 |
| 带文本 vs 无文本 | 仅标记 vs 标记+简短文本 |

### 阅读结果

- **主要指标：**安装转化率（展示→安装）
- **最小样本：**每个变体 1,000+ 展示以获得可靠的信号
- **显著性阈值：**p < 0.05 或 Appeeky/Play Console 置信指示器

## 图标审核

对照以下内容评估你当前的图标：

```
60×60px 下的清晰度：        [1–10]
  - 小尺寸下可识别的标记？
  - 无难以辨认的文本？

色差：            [1–10]
  - 在白色（浅色模式）下有效？
  - 在深色背景下有效？

类别差异化：  [1–10]
  - 与前 10 名竞争对手的图标区分开来？

简洁性：                [1–10]
  - 最多 2 个元素？
  - 能用 3 个词描述？

品牌一致性：           [1–10]
  - 与应用的视觉身份一致？

总体： [N]/50
```

在向设计师简报时：

```
应用： [名称和一句话描述]
类别： [类别]
主要受众： [谁使用它]
品牌颜色： [十六进制值]
情绪/感觉： [高级 / 玩乐 / 可信赖 / 充满活力 / 平静]

图标应传达的内容： [核心价值或身份]
要避免的内容： [不要复制竞争对手 X，避免 Y]

要区别于的竞争对手： [列出 3–5 个带图标的]
我喜欢的参考图标： [列出 3–5 个来自其他应用]

交付物：
- 3 个 1024×1024px 的不同概念
- 每个概念在 App Store 搜索上下文中测试 60×60px 模拟
- 最终：PNG，无 alpha，无圆角
```
