# Stitch 设计风格 — 语义设计系统技能

## 概述
此技能生成针对 Google Stitch 屏幕生成的优化 `DESIGN.md` 文件。它将经过实战检验的抗滑前端工程指令翻译成 Stitch 的原生语义设计语言——描述性、自然语言的规则与精确值，Stitch 的 AI 代理可以解释这些规则来生成优质、非通用的界面。

生成的 `DESIGN.md` 作为提示 Stitch 生成与精心策划的高代理设计语言一致的新屏幕的**单一事实来源**。Stitch 通过支持特定颜色值、排版规范和组件行为的**"视觉描述"**来解释设计。

## 前置条件
- 通过 [labs.google.com/stitch](https://labs.google.com/stitch) 访问 Google Stitch
- 可选：Stitch MCP 服务器，用于与 Cursor、Antigravity 或 Gemini CLI 进行程序化集成

## 目标
生成一个 `DESIGN.md` 文件，编码：
1. **视觉氛围** — 氛围、密度和设计理念
2. **色彩校准** — 中性色、强调色和禁止的图案及其十六进制代码
3. **排版架构** — 字体堆栈、比例层级和反模式
4. **组件行为** — 按钮和输入框等组件的交互状态
5. **布局原则** — 网格系统、间距理念和响应式策略
6. **动效理念** — 动画引擎规范、弹簧物理和持续性的微交互
7. **反模式** — 明确禁止的 AI 设计陈词滥调

## 分析与合成说明

### 1. 定义氛围
评估目标项目的意图。使用风格谱系中的描述性形容词：
- **密度**："艺术馆空灵"（1-3）→ "日常应用平衡"（4-7）→ "驾驶舱密集"（8-10）
- **变化度**："可预测对称"（1-3）→ "偏移非对称"（4-7）→ "艺术混乱"（8-10）
- **动效**："静态约束"（1-3）→ "流体 CSS"（4-7）→ "电影级编排"（8-10）

默认基线：创造力 9，变化度 8，动效 6，密度 5。根据用户的氛围描述动态调整。

### 2. 映射色彩调色板
为每种颜色提供：**描述性名称** + **十六进制代码** + **功能角色**。

**强制约束**：
- 最大 1 个强调色。饱和度低于 80%
- 严格禁止 "AI 紫色/蓝色霓虹" 风格——没有紫色按钮发光，没有霓虹渐变
- 使用绝对中性色基（Zinc/Slate）与高对比度单一强调色
- 整个输出使用单一调色板——没有暖色/冷色灰度波动
- 永远不要使用纯黑色（`#000000`）——使用 Off-Black、Zinc-950 或 Charcoal

### 3. 建立排版规则
- **展示/标题**：紧密间距，受控比例。不是尖叫。通过重量和颜色建立层级，而不仅仅是巨大的尺寸
- **正文**：宽松行距，每行最多 65 个字符
- **字体选择**：`Inter` 在优质/创意语境中禁止。强制使用独特字符：`Geist`、`Outfit`、`Cabinet Grotesk` 或 `Satoshi`
- **衬线字体禁止**：通用衬线字体（`Times New Roman`、`Georgia`、`Garamond`、`Palatino`）禁止。如果需要衬线字体用于编辑/创意语境，仅使用独特的现代衬线字体：`Fraunces`、`Gambarino`、`Editorial New` 或 `Instrument Serif`。衬线字体在仪表板或软件 UI 中始终禁止
- **仪表板约束**：仅使用无衬线字体搭配（`Geist` + `Geist Mono` 或 `Satoshi` + `JetBrains Mono`）
- **高密度覆盖**：当密度超过 7 时，所有数字必须使用等宽字体

### 4. 定义英雄区域
英雄区域是第一印象，必须创意、引人注目且永不通用：
- **行内图像排版**：在标题中直接嵌入小型、上下文相关的照片或视觉元素。图像在类型高度处行内显示，圆角，作为视觉标点。这是标志性的创意技巧
- **禁止重叠**：文本绝不能与图像或其他文本重叠。每个元素占据自己的干净空间区域
- **禁止填充文本**："滚动探索"、"向下滑动"、滚动箭头图标、弹跳箭头是禁止的。内容应自然吸引用户
- **非对称结构**：当变化度超过 4 时，禁止居中英雄布局
- **CTA 限制**：最多一个主要 CTA。没有次要的 "了解更多" 链接

### 5. 描述组件样式
为每种组件类型描述形状、颜色、阴影深度和交互行为：
- **按钮**：在激活状态下提供触感推反馈。没有霓虹外发光。没有自定义鼠标光标
- **卡片**：仅当高度传达层级时使用。阴影色调为背景色。在高密度布局中，用边框顶部分隔符或负空间替换卡片
- **输入/表单**：标签在输入框上方，辅助文本可选，错误文本在下方。标准间距
- **加载状态**：与布局尺寸匹配的骨骼加载器——没有通用的圆形旋转器
- **空状态**：组合构图指示如何填充数据
- **错误状态**：清晰的行内错误报告

### 6. 定义布局原则
- 无重叠元素——每个元素占据自己的清晰空间区域。无绝对定位内容堆叠
- 当变化度超过 4 时，禁止居中英雄区域——强制使用分割屏幕、左对齐或非对称空白
- 通用 "水平方向 3 个等宽卡片" 功能行是禁止的——使用 2 列之字形、非对称网格或水平滚动
- CSS 网格优先于 Flexbox 数学——永远不要使用 `calc()` 百分比技巧
- 使用最大宽度约束（例如，1400px 居中）包含布局
- 全高度区域必须使用 `min-h-[100dvh]`——永远不要使用 `h-screen`（iOS Safari 灾难性跳跃）

### 7. 定义响应式规则
每个设计必须在所有视口下工作：
- **移动优先折叠（< 768px）**：所有多列布局折叠为单列。没有例外
- **无水平滚动**：移动端的水平溢出是关键失败
- **排版缩放**：标题通过 `clamp()` 缩放。正文文本最小 `1rem`/`14px`
- **触摸目标**：所有交互元素最小 `44px` 触摸目标
- **图像行为**：行内排版图像（文字之间的照片）在移动端堆叠在标题下方
- **导航**：桌面水平导航折叠为干净的移动菜单
- **间距**：垂直区域间距按比例减少（`clamp(3rem, 8vw, 6rem)`）

### 8. 编码动效理念
- **弹簧物理默认**：`stiffness: 100, damping: 20`——优质、有分量的感觉。没有线性缓动
- **持续性微交互**：每个激活组件应有无限循环状态（脉冲、打字机、漂浮、闪烁）
- **交错编排**：永远不要立即挂载列表——使用级联延迟进行瀑布式揭示
- **性能**：仅通过 `transform` 和 `opacity` 动画。永远不要动画化 `top`、`left`、`width`、`height`。仅在固定伪元素上使用纹理/噪点滤镜

### 9. 列出反模式（AI 指令）
在 `DESIGN.md` 中将以下内容编码为明确的 "禁止" 规则：
- 任何地方都不使用表情符号
- 不使用 `Inter` 字体
- 不使用通用衬线字体（`Times New Roman`、`Georgia`、`Garamond`）——仅在需要时使用独特的现代衬线字体
- 不使用纯黑色（`#000000`）
- 不使用霓虹/外发光阴影
- 不使用过度饱和的强调色
- 大标题上不使用过多的渐变文本
- 不使用自定义鼠标光标
- 不重叠元素——始终保持干净的空间分离
- 不使用 3 列等宽卡片布局
- 不使用通用名称（"John Doe"、"Acme"、"Nexus"）
- 不使用伪造的圆数字（`99.99%`、`50%`）
- 不使用伪造的数据或统计数据——永远不要生成指标、性能数字、正常运行时间百分比、响应时间或任何用户未明确提供的数据。"99.98% UPTIME SLA"、"124ms AVG. RESPONSE"、"18.5k DEPLOY CYCLES" 是虚构的 AI 填充。如果真实数据不可用，请使用清晰的占位符标签 `[metric]` 而不是编造数字
- 不使用伪造的系统/指标区域——"SYSTEM PERFORMANCE METRICS"、"KEY STATISTICS"、"BY THE NUMBERS" 仪表板卡片填充了虚构数据是禁止的
- 不使用 `LABEL // YEAR` 格式——"SYSTEM // 2024"、"METRICS // 2025" 是懒惰的 AI 习惯，不是真实设计排版
- 不使用 AI 文案陈词滥调（"提升"、"无缝"、"释放"、"下一代"）
- 不使用填充 UI 文本："滚动探索"、"向下滑动"、滚动箭头、弹跳箭头
- 不使用损坏的 Unsplash 链接——使用 `picsum.photos` 或 SVG 头像
- 高变化度项目不使用居中英雄区域

## 输出格式（DESIGN.md 结构）

```markdown
# 设计系统：[项目名称]

## 1. 视觉主题与氛围
（对氛围、密度、变化度和动效强度的描述。
示例："一个约束、艺术馆空灵的界面，具有自信的非对称布局和流体弹簧物理动效。氛围是临床但温暖的——就像一个光线充足的建筑工作室。")

## 2. 色彩调色板与角色
- **画布白** (#F9FAFB) — 主要背景表面
- **纯色表面** (#FFFFFF) — 卡片和容器填充
- **炭黑墨水** (#18181B) — 主要文本，Zinc-950 深度
- **柔和钢色** (#71717A) — 次要文本、描述、元数据
- **低语边框** (rgba(226,232,240,0.5)) — 卡片边框，1px 结构线
- **[强调色名称]** (#XXXXXX) — 单一强调色用于 CTA、激活状态、焦点环
（最多 1 个强调色。饱和度 < 80%。没有紫色/霓虹。）

## 3. 排版规则
- **展示**：[字体名称] — 紧密间距，受控比例，重量驱动的层级
- **正文**：[字体名称] — 松散行距，最大 65ch 宽度，中性次要颜色
- **等宽**：[字体名称] — 用于代码、元数据、时间戳、高密度数字
- **禁止**：Inter，优质语境中的通用系统字体。仪表板中禁止衬线字体。

## 4. 组件样式
* **按钮**：平面，无外发光。激活状态时 -1px 平移触感。主要使用强调色填充，次要使用幽灵/轮廓
* **卡片**：圆角充足（2.5rem）。扩散低语阴影。仅当高度传达层级时使用。高密度：用边框顶部分隔符或负空间替换
* **输入**：标签在上方，错误在下方。强调色焦点环。不使用浮动标签
* **加载器**：与布局尺寸匹配的骨骼闪烁。没有圆形旋转器
* **空状态**：组合构图——不仅仅是 "无数据" 文本

## 5. 布局原则
（网格优先响应式架构。非对称分割英雄区域。严格 768px 以下单列折叠。最大宽度包含。
不使用 Flexbox 百分比数学。充足的内部填充。）

## 6. 动效与交互
（所有交互元素使用弹簧物理。交错级联揭示。
激活的仪表板组件有持续性微循环。仅使用硬件加速的 transform。
隔离客户端组件用于 CPU 密动画。）

## 7. 反模式（禁止）
（明确禁止的模式列表：无表情符号、无 Inter、无纯黑色、无霓虹发光、无 3 列等宽网格、无 AI 文案陈词滥调、无通用占位符名称、无损坏图像链接。）

## 最佳实践
- **描述性**："深炭黑墨水 (#18181B)" — 不仅仅是 "深色文本"
- **功能性**：解释每个元素的作用
- **一致性**：整个文档使用相同的术语
- **精确性**：包括精确的十六进制代码、rem 值、像素值（括号内）
- **主观性**：这不是中性的模板——它强制执行特定的优质美学

## 成功技巧
1. 从氛围开始——在详细说明标记之前理解氛围
2. 寻找模式——识别一致的间距、尺寸和样式
3. 考虑语义——通过目的命名颜色，而不仅仅是外观
4. 考虑层级——记录视觉重量如何传达重要性
5. 编码禁止项——反模式与规则同等重要

## 避免常见错误
- 使用技术术语而不翻译（"rounded-xl" 而不是 "圆角充足"）
- 省略十六进制代码或仅使用描述性名称
- 忘记设计元素的功能角色
- 氛围描述过于模糊
- 忽视反模式列表——这些是使输出优质的关键
- 默认使用通用的 "安全" 设计，而不是强制执行策划美学
