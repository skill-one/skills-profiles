# 簇分析 & 留存率探索器

## 目的
通过簇分析用户参与度和留存模式，识别用户行为、功能采用和长期参与的趋势。结合定量洞察与定性研究建议。

## 工作原理

### 第一步：读取并验证您的数据
- 接受包含用户簇信息的 CSV、Excel 或 JSON 数据文件
- 验证数据结构：簇标识符、时间段、参与度指标
- 检查缺失值和数据质量问题
- 汇总关键统计数据（簇大小、日期范围、可用指标）

### 第二步：生成定量分析
- 计算簇留存率和参与度趋势
- 识别留存曲线、流失模式及异常情况
- 计算各簇的功能采用率
- 计算月度环比或期度环比变化
- 如有请求，生成使用 pandas 和 numpy 的 Python 分析脚本

### 第三步：创建可视化
- 生成留存热力图（簇与时间段对比）
- 创建显示簇进展的折线图
- 构建功能采用对比图表
- 可视化流失点和参与度趋势
- 输出为交互式图表或静态图像

### 第四步：识别洞察与模式
- 发现一个或多个显著模式：
  - 特定簇的早期流失
  - 后期阶段参与度变化
  - 功能采用集群
  - 季节性或时间性趋势
- 突出显示意外发现和偏差
- 比较簇表现以建立基准

### 第五步：建议后续研究
- 推荐定性研究方法：
  - 针对流失用户进行用户访谈
  - 对参与度高的簇进行功能使用调查
  - 关键交互模式会话回放
  - 高留存与低留存簇的赢/输分析
- 设计后续定量研究
- 建议进行 A/B 测试或功能实验

## 使用示例

**示例 1：上传 CSV 数据**
```
上传 cohort_engagement.csv，列包括：cohort_month、weeks_active、
user_id、feature_x_usage、engagement_score

请求："分析留存模式，并识别为何 2025 年第四季度簇表现不如第三季度"
```

**示例 2：描述数据格式**
```
"我拥有 2025 年 1 月至 12 月的月度用户簇数据。每行显示：
簇日期、用户 ID、购买频率和支持工单。
分析哪些簇表现出最佳长期留存。"
```

**示例 3：功能采用分析**
```
上传 feature_usage.xlsx，包含簇采用数据。

请求："比较新功能在各簇中的采用曲线。
哪些簇采用最快？是否存在任何模式？"
```

## 核心功能

- **数据读取**：导入 CSV、Excel、JSON、SQL 查询结果
- **留存分析**：计算并可视化随时间的留存率
- **簇比较**：比较不同簇组的指标
- **异常检测**：标记异常模式或流失情况
- **Python 脚本**：生成可复用的分析代码用于持续分析
- **可视化**：创建热力图、图表和交互式仪表板
- **研究设计**：建议有针对性的后续研究和访谈方法
- **统计摘要**：提供定量指标和相关性分析

## 获取最佳效果的建议

1. **包含时间维度**：提供跨多个时间段的数据
2. **明确定义簇**：使簇分组明确（注册月份、功能发布日期等）
3. **提供背景信息**：解释期间的产品变更、发布或事件
4. **多个指标**：包含留存、参与度、功能使用、收入等
5. **足够的数据**：至少 3-4 个簇以识别有意义模式
6. **请求特定输出**：要求可视化、Python 脚本或研究建议

## 输出格式

您将收到：
- **数据摘要**：簇概览和数据质量评估
- **定量发现**：关键指标、留存率和趋势分析
- **可视化**：显示留存曲线、采用模式的图表
- **模式识别**：数据中的 2-3 个重要洞察
- **研究建议**：具体的定性和定量后续研究
- **分析脚本**（如请求）：用于可重复分析的 Python 代码
- **下一步行动**：基于发现优先的行动建议
