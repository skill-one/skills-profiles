## 竞争战卡

创建一份简洁、适合销售的战卡，用于针对特定竞争对手。

### 背景

您正在为 **$ARGUMENTS** 创建一份竞争战卡。

使用网络搜索来研究竞争对手的当前产品、定价、定位和最近的变化。如果用户提供了文件（功能列表、输赢数据、销售通话笔记），请先阅读这些文件。

### 指令

1. **研究竞争对手**（使用网络搜索）：
   - 当前产品供应和功能
   - 定价层级和模式
   - 目标市场和定位
   - 最近的产品发布或变化
   - 已知的优势和劣势
   - 客户评价和情绪（G2、Capterra、Reddit）

2. **创建战卡**，包含以下部分：

   ### 公司概览
   - 成立时间、总部、融资/收入（如果公开）
   - 目标市场和ICP
   - 用一句话概括定位

   ### 快速对比

   | 能力 | 我们 | 他们 | 胜者 |
   |---|---|---|---|
   | [功能领域 1] | [我们的方法] | [他们的方法] | [我们/他们/平局] |
   | [功能领域 2] | ... | ... | ... |
   | 定价 | ... | ... | ... |
   | 支持 | ... | ... | ... |

   ### 我们的优势
   - [优势 1]: [证明点或客户引用]
   - [优势 2]: [他们缺乏的具体能力]
   - [优势 3]: [更好的方法及理由]

   ### 他们的优势
   - [他们的优势 1]: [我们的反定位]
   - [他们的优势 2]: [我们如何弥补这一差距]

   ### 常见异议及回应

   | 潜在客户说 | 回应 |
   |---|---|
   | "竞争对手 X 有 [功能]" | "[我们的替代方法及其优势]" |
   | "他们更便宜" | "[价值定位：总拥有成本、投资回报率、隐藏成本]" |
   | "他们更成熟" | "[我们的优势：速度、创新、专注、支持]" |

   ### 需要埋下的地雷
   向潜在客户提出的问题，以突出竞争对手的弱点：
   - "在 [我们擅长的领域] 对您的团队有多重要？"
   - "您是否评估过 [他们缺乏的具体能力]？"

   ### 输赢模式
   - 我们倾向于在：[模式]
   - 我们倾向于输在：[模式]
   - 竞争交易中的关键差异化：[什么决定了胜负]

3. **保持可扫描性**：销售代表需要在通话中参考这份战卡。使用表格、粗体文本和简短的要点。

保存为 Markdown 格式。格式化以便于打印或在 Notion/Confluence 中共享。
