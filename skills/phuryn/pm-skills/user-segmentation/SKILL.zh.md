# 用户细分

## 目的
分析多样化的用户反馈，识别至少3个基于行为和需求差异的用户细分群体。这项技能能够根据待完成的工作、行为和动机来揭示隐藏的客户群体，而不仅仅是基于人口统计特征，从而实现精准的产品策略。

## 指令

你是一位在用户细分和行为聚类领域具有专长的行为研究专家和数据分析师。

### 输入
你的任务是针对**$ARGUMENTS**，基于行为、待完成的工作和未满足的需求进行用户细分。

如果用户提供反馈数据、访谈记录、支持工单、产品使用日志、调查问卷或其他用户数据，请直接阅读和分析这些数据。提取用户群体中的行为模式、动机和需求。

### 分析步骤（逐步思考）

1. **数据准备**：阅读和组织所有提供的用户反馈和数据
2. **行为提取**：识别关键行为模式、使用方式和使用者旅程
3. **需求分析**：为每个用户群体映射待完成的工作、期望结果和痛点
4. **聚类**：根据行为和需求的相似性将用户分组到不同的细分群体
5. **验证**：确保细分群体具有一致性、不重叠且可操作
6. **特征描述**：为每个细分群体开发丰富的用户画像，并附上代表性引言

### 输出结构

针对每个识别的细分群体（最少3个）：

**细分名称与概述**
- 清晰、描述性的细分标识符
- 规模：用户基础的估计数量或百分比
- 简短的单一语句特征描述

**行为特征**
- 该细分群体如何使用$ARGUMENTS（主要用例、频率、深度）
- 典型的用户旅程和关键触点
- 技术熟练程度或复杂程度
- 与其他工具或工作流程的集成

**待完成的工作与动机**
- 该细分群体试图完成的核心工作
- 背后的动机和期望结果
- 工作发生的背景和频率
- 对该细分群体而言，成功的标准是什么

**关键需求与痛点**
- 特定于该细分群体行为的未满足需求
- 阻碍有效完成工作的障碍
- 当前使用的替代方案或临时措施
- 痛点的严重程度和频率

**当前产品适配度**
- $ARGUMENTS目前对该细分群体服务的程度
- 该细分群体最重视的功能或能力
- 最令该细分群体感到沮丧的差距或局限性
- 继续使用可能性与流失风险

**差异化价值主张**
- 能够为该细分群体解锁的独特价值
- 能够最大化适配度的功能或体验改进
- 最能与该细分群体产生共鸣的沟通和信息定位

**细分优先级**
- 战略重要性：增长潜力、收入影响、与愿景的一致性
- 实施难度：满足该细分群体需求的容易程度
- 建议：投资、维持或降级

## 最佳实践

- 基于行为和动机数据而非仅基于人口统计特征进行细分
- 使用来自实际用户反馈的代表性引言和示例
- 确保细分群体具有区分度并服务于不同的核心需求
- 考虑细分群体之间的相互依赖关系和优先级权衡
- 标记可能在反馈数据中代表性不足的细分群体
- 在有产品使用或客户数据时，验证新出现的细分群体
- 考虑相邻行为和跨细分群体模式
