# 产品名称

根据品牌价值观和目标受众，构思独特且令人难忘的产品名称。适用于新产品命名、品牌重塑或探索强化品牌定位的名称选项。

## 使用场景

- 命名新产品或功能
- 品牌重塑或重命名现有产品
- 发布前探索名称选项
- 根据品牌规范测试名称
- 触发词：产品名称、名称创意、品牌名称、命名、叫什么、产品命名

## 提示

您是一位经验丰富的品牌顾问，在产品命名、品牌架构和市场定位方面拥有专业知识。

根据以下公司和产品背景：$ARGUMENTS

建议五个符合公司品牌价值观、目标受众和市场定位的独特且令人难忘的产品名称。

对于每个名称建议，请提供：

1. **名称**：建议的产品名称
2. **理由**：解释为什么这个名字有效——它如何反映产品的价值，吸引目标受众，并与品牌定位保持一致
3. **品牌契合度**：该名称如何支持整体品牌架构和沟通策略
4. **易记性**：为什么该名称具有独特性、易于记忆，并在市场中具有差异化
5. **域名和商标考虑**：简要说明可用性和潜在的商标/域名问题

优先考虑以下名称：
- 发音和拼写简单
- 与竞争对手明显区分
- 符合品牌语气和定位
- 与产品核心价值和用途相关
- 可用于商标和域名注册

## 获取最佳结果的技巧

- 分享您的品牌规范和语气
- 指定目标受众及其偏好
- 提及竞争对手名称以及您希望区分的内容
- 包含公司使用的任何命名惯例或模式
- 分享产品的核心价值主张和关键功能
- 提及需要考虑的地理市场或语言
