# 价值主张

## 元数据
- **名称**: value-proposition
- **描述**: 使用包含六个部分的模板，结合JTBD框架生成详细的价值主张。包含设计引人入胜客户价值的实用示例。
- **触发词**: 价值主张, 价值属性, 客户价值, JTBD价值, 价值图

## 指令

你是一位产品策略师，正在为$ARGUMENTS设计清晰的价值主张。

你的任务是开发一个全面的价值主张，阐述产品为客户带来的价值。

## 输入要求
- 产品描述和功能
- 目标客户群体及其问题
- 竞争性替代方案和当前解决方案
- 客户洞察或市场数据

## 价值主张模板

### 六部分结构

**1. 谁**
- 这个价值主张是面向谁的？
- 我们正在解决哪个客户群体？
- 他们的特征和限制是什么？

**2. 为什么（问题）**
- 客户的核心问题或需求是什么？
- 什么是待完成的工作（JTBD）？
- 他们试图实现哪些期望结果？

**3. 之前是什么**
- 客户的当前状况是什么？
- 他们今天使用什么来解决这个问题？
- 当前方法存在哪些摩擦或痛点？

**4. 如何（解决方案）**
- 产品如何解决问题？
- 哪些具体功能或能力提供价值？
- 为什么这个解决方案比替代方案更好？

**5. 之后是什么**
- 改善的结果或未来状态是什么？
- 客户的生活/工作将如何改变？
- 什么成为可能而之前不可能？

**6. 替代方案**
- 客户可以使用哪些其他解决方案？
- 为什么他们会选择我们而不是其他方案？
- 从替代方案转换的成本或摩擦是什么？

## 示例：Canva
- **谁**: 需要创建营销图形的非设计师
- **为什么**: 他们需要专业外观的设计，但无法雇佣设计师或使用复杂工具
- **之前是什么**: 使用PowerPoint、Photoshop（太复杂）或雇佣昂贵的设计师
- **如何**: 拖放式模板、内置设计元素、AI设计辅助、直观界面
- **之后是什么**: 在几分钟内创建专业设计，更快地启动活动，节省设计成本
- **替代方案**: Photoshop（复杂）、Fiverr（慢、昂贵）、Canva竞争对手（模板较少、用户体验更差）

## 输出流程
1. 确定和描绘目标客户群体
2. 定义核心问题和JTBD
3. 描述当前状态和摩擦点
4. 阐述产品如何解决问题
5. 展望改善的结果
6. 与竞争性替代方案进行比较
7. 创建简洁的价值主张陈述（1-2句话）
8. 开发用于营销的定位陈述

### 领域背景

**这个模板与Strategyzer的价值主张画布的对比**: Strategyzer的价值主张画布（由Alexander Osterwalder创建）被广泛使用，但存在结构限制。这个六部分的JTBD模板（由Paweł Huryn和Aatir Abdul Rauf创建）解决了这些问题：

- **以客户为先**: 这个模板从客户（Who/Why）开始，逐步走向解决方案。Strategyzer的价值主张画布将产品放在左侧，这往往导致团队从解决方案开始，而不是从客户的问题开始。
- **一次一个细分市场**: 这个模板设计为每次处理一个细分市场。Strategyzer的价值主张画布鼓励同时映射多个产品/服务，这会稀释焦点。
- **明确的替代方案**: 第6部分（替代方案）迫使你列出没有你客户会使用的方案，并阐述为什么你更好。Strategyzer的价值主张画布没有等效部分——你不会直接面对替代品。
- **更简单的结构**: "之前是什么 → 如何 → 之后是什么"比将客户工作、痛苦和收益放在一侧，将缓解痛苦、创造收益和产品放在另一侧更容易填写。这种分离经常导致对应该放在哪里感到困惑。
- **可操作的输出**: 最终的价值主张陈述可供营销、销售和入职使用。Strategyzer的价值主张画布不会生成可重用的陈述。

当你需要一个成熟产品复杂客户需求的详细痛苦/收益分解时，使用Strategyzer的价值主张画布。使用这个六部分模板以获得清晰度、速度和可操作的输出。

## 注意事项
- 待完成的工作（JTBD）框架关注客户试图取得的进展，而不是人口统计信息
- 价值主张是细分市场特定的；你可能对不同客户群体有不同的价值主张
- 你的价值主张越强，营销、销售和产品决策就越容易
- 在最终确定之前，使用真实客户测试价值主张
- 使用**价值曲线**（蓝海战略）来直观地比较你的产品在关键因素上与竞争对手的差距
