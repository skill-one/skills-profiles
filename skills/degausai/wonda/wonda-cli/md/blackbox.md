# wonda-cli (`degausai/wonda/wonda-cli`)

## blackbox

**function**: 你说一句话, 我帮你生成图片、视频、配音或音乐, 还能把做好的内容直接发布到 LinkedIn、Reddit、X (推特) 等社交平台。

- input: 一句画面描述, 如「雨夜霓虹下的东京街头, 电影感」, output: 一张生成好的图片文件 (mp4 也能做: 一句话 → 一段视频)
- input: 一段 10 秒以上的人声录音 + 一句台词, output: 用同款嗓音念出这句台词的音频文件
- input: 一段推文文案 + 指定发布到 X/LinkedIn/Reddit 账号, output: 发布成功的帖子, 附帖子链接
