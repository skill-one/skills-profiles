# media-use (`heygen-com/hyperframes/media-use`)

## blackbox

**function**: 你用一句话描述要什么媒体——配乐、音效、图片、图标、官方 logo、配音、字幕、调色、去背景——我直接给你能马上使用的成品文件。

- input: 项目文件夹 + 一句话:「给这个 30 秒产品视频配段轻快的背景音乐」, output: 一个已备好的本地 .mp3 文件, 直接拖进时间线就能用
- input: 一段解说文案(纯文本), output: 对应的配音音频文件, 选好合适的音色直接出成品
- input: 一段实拍视频 + 反馈:「画面太暗太平, 想要复古胶片感」, output: 调色处理后的成片, 亮度和色调调好, 带复古质感, 可预览确认后再定稿
- input: 「我要 Stripe 的官方 logo」, output: 官方原版 logo 文件(svg/png), 保证正版不重绘
- input: 一段带人声的音频或视频, output: 生成的字幕文件(.srt)或逐句文字稿
