# 切曲线 — 技术目录

五种 SEAM 技术，一条原则：**在峰值速度处切割，切割两侧的方向和速度相匹配** — 加上场景内的两种技术（§6 到达，§7 滑动）。
缝线法则 — 向量法则，当前，账本，缝线门 — 存在于 `motion-doctrine` 中；先阅读它。这项技能是参数和机制。
所有 GSAP 代码模板（工作器 + 注册表）：`examples/gsap-implementation.md`。

## 目录

| #   | 技术                  | 范围                          | 轴                | 用途                                                |
| --- | -------------------------- | ------------------------------ | ------------------- | ------------------------------------------------------ |
| 1   | **缩放穿过**（向前） | 场景内文本交换         | Z，朝向观众    | 深入同一思考的进展                               |
| 2   | **逆缩放穿过**   | 到达 / 高潮点          | Z，远离观众    | 有更大的东西着陆                                 |
| 3   | **切曲线**          | 场景之间                 | X / Y               | 默认边界，电影的当前                           |
| 4   | **瀑布切割**          | 文本到文本的缝线              | X，按单词         | 大文本高潮之间的单词级交接                      |
| 5   | **摇摄聚焦模糊切割**    | 同一表面状态交换        | X / Y / Z           | 你想要看到的那个切割 — 一个单反相机聚焦拉花       |
| 6   | **瀑布进入**        | 场景内到达（无缝线）     | Y，从下方       | 标题卡，段落开篇，列表介绍                      |
| 7   | **推曲线**            | 场景内组滑动（无缝线） | X / Y               | 重新定位一个组合的组以腾出空间            |

## Z 方向是一个标志

"同一轴" 在 Z 上并不足够 — d(scale)/dt 的符号必须跨越切割匹配：

| Z 矢量       | 退出缩放          | 进入缩放          | 变体              |
| -------------- | ------------------- | -------------------- | -------------------- |
| 推（向前） | 增长 `1 → 1.2`   | 增长 `0.75 → 1`   | 缩放穿过         |
| 拉（向后）    | 收缩 `1 → 0.8` | 收缩 `1.25 → 1` | 逆缩放穿过 |

禁止的镜像：一个后退的退出由一个从小处增长的进入回答（拉翻转为推 — 常见的，因为从小处增长是默认的元素入口），以及一个推退出由一个过大的收缩回答。这绑定传入场景的 OWN 入口在缝线窗口内（切割 + ~0.5s），而不仅仅是包装补间：保持传入帧组合，或编写其入口以匹配符号。根据缝线门规则 7 验证。

## 模糊逻辑（所有 Z 变体）

| 主体                                       | 峰值模糊   | 原因                                                            |
| --------------------------------------------- | ----------- | -------------------------------------------------------------- |
| 文本缩放（标题，词组）             | **10px**    | 20px 模糊字母形式 — 切割被视为故障，而不是速度 |
| 全帧表面（窗口，卡片，截图） | **18–20px** | 较轻的模糊在大表面上读取为渲染故障      |

交换帧在两侧具有相同的峰值模糊。模糊包装器，而不是子元素。

## 1. 缩放穿过（向前）

Z 轴速度匹配的切割；**永远不会同时显示两个文本。** 一切都在增长： outgoing 文本加速朝向相机，一个硬交换在峰值模糊时隐藏， incoming 文本继续增长到焦点平面。标题和短短语。总计 ≈ 0.4s。

| 阶段          | 缩放    | 模糊     | 不透明度           | 缓动                                       | 持续时间 |
| -------------- | -------- | -------- | ----------------- | ------------------------------------------ | -------- |
| 退出           | 1 → 1.2  | 0 → 10px | 1 → 0.15          | power3.in（不透明度：单独 `none` 补间） | 0.2s     |
| 切割（`tl.set`） | in: 0.75 | 10px     | out: 0 / in: 0.15 | —                                          | —        |
| 进入          | 0.75 → 1 | 10 → 0px | 0.15 → 1          | expo.out                                   | 0.5s     |

退出不透明度必须是其自己的线性补间 — `power3.in` 持续不透明度接近 1 太久。
在进入中所有属性共享 `expo.out`。

## 2. 逆缩放穿过（向后）

拉回镜像：outgoing 元素后退；incoming 到达过大的（就像刚刚在相机后面）并缩回到焦点平面。一切都在收缩。花费在到达/高潮点上 — 一条高潮线，一个巨大的回复，一个保持的结束状态 — 永远不是普通的边界。总计 ≈ 0.7s（30% 退出 / 70% 进入）。

| 阶段          | 缩放    | 模糊     | 不透明度           | 缓动                                       | 持续时间 |
| -------------- | -------- | -------- | ----------------- | ------------------------------------------ | -------- |
| 退出           | 1 → 0.8  | 0 → 10px | 1 → 0.15          | power3.in（不透明度：单独 `none` 补间） | ~0.2s    |
| 切割（`tl.set`） | in: 1.25 | 10px     | out: 0 / in: 0.15 | —                                          | —        |
| 进入          | 1.25 → 1 | 10 → 0px | 0.15 → 1          | expo.out                                   | ~0.5s    |

模糊是 10px 文本缩放；18–20px 仅当两侧都是全出血表面时。

**符号纪律：** incoming 场景作为组合帧到达在缩回的包装器内 — 缝线窗口内没有从小处增长的介绍。排练入口发生在缩回稳定后，或开始 ≥1 并缩回。

## 3. 切曲线（默认场景边界）

X/Y 速度匹配的切割 — 所有场景到场景边界的默认，在电影的当前，而不是强调。outgoing 英雄在一个方向上加速，切割在运动中着陆，incoming 英雄继续相同方向并减速。总计 ≈ 0.6s；方向 左 / 右 / 上 / 下（默认左）。

**部分旅行：** ~12% 的帧（≈230px 在 1920） — 永远不是全屏移动。

| 方向 | 退出          | 进入开始 → 结束 |
| --------- | ------------- | ----------------- |
| 向左  | `x: 0 → −230` | `x: +230 → 0`     |
| 向右  | `x: 0 → +230` | `x: −230 → 0`     |
| 向上    | `y: 0 → −230` | `y: +230 → 0`     |
| 向下  | `y: 0 → +230` | `y: −230 → 0`     |

机制：

- **镜像缓动：** 退出 `power4.in` + 进入 `power4.out`，相同距离和持续时间 — 两个 `power4.inOut` 的一半，所以在切割处速度匹配。
- **淡出技巧：** 退出不透明度在约 25–30% 的旅行完成时完成（淡出 ≈ 0.18–0.3s vs 运动 0.3–0.34s）；进入在路径中约 0.35 不透明度时点燃。调整最后一个淡出元素在切割时死亡 — 一个没有任何移动的间隙读作死空气。
- 退出 0.2–0.4s；进入 ≥ 退出。可选模糊 8–10px。
- **舞台地面：** `#root` 必须是不透明的
  (`background: var(--canvas-deep, var(--canvas, #000))`) — 中间窗口切割打开一个总和不透明度 < 1 的窗口，否则会闪烁白色（见 `seam-craft`）。

`push-slide` 存在，但违反了部分旅行和中间运动阶段；优先选择切曲线。

## 4. 瀑布切割（按单词的切曲线）

按单词粒度的切曲线 — 文本到文本缝线的最强左向切割。outgoing 单词在自己的曲线上 ramps out；incoming 单词在飞行中瀑布式进入 — 眼睛可以跨越缝线的一波。

**范围：** 工作者在单个多高潮合成（堆叠的全帧 `.beat` 层）内编写，不是注册表/注入器类型 — 它补间单词跨度，而不是剪辑包装器。进入和退出文本合成块的边界仍然得到正常的注册表过渡。不计入 2–3 过渡预算。

| 参数           | 值                 | 原因                                         |
| ------------------- | --------------------- | ------------------------------------------- |
| 旅行              | ±230px (~12% 帧)   | 部分旅行 + 速度 > 全帧推                     |
| 退出                | 0.34s `power4.in`     | 加速度就是切割                 |
| 退出淡出           | 0.18s, 从 x 开始  | 单词在约 25–30% 的旅行后消失 — 没有拖影   |
| 退出交错        | +0.022s 阅读顺序 | 行剥离，不是块滑动           |
| 进入               | 0.3s `power4.out`     | 组合的后半部分 — 速度匹配 |
| 进入开始不透明度 | 0.35                  | 路径中点燃；二进制 0→1 爆炸          |
| 进入间隙          | 0.05s × 0.84 衰减    | 加速瀑布，解决组合     |

规则：

- 每个链一个方向，骑乘当前。逆缩放是链的 ARRIVAL 拍头。
- 构建时所有单词设置为 `x: +230, 不透明度: 0` — `immediateRender: false`
  单独留下静止时未开始的单词可见。
- 短第一拍可能退出整行：它的淡出在切割前结束 ~0.02s，所以当下一个单词点燃时它仍然在条纹中 — 没有死间隙。
- 变换/不透明度仅（安全搜索）；不透明的舞台地面适用。

## 5. 摇摄聚焦模糊切割（可见的切割）

切割可见的唯一变体：一个失焦模糊尖峰隐藏了一个单帧硬交换 — 一个手持单反相机的聚焦拉花。作为偶尔的花哨用于同一表面在一个视觉主题内的状态交换；永远不是默认边界。

与其他不同的地方：outgoing 保持完全不透明，直到切割（模糊隐藏交换 — 没有早期淡出）；缓动 `power2.in` / `power2.out`（柔和光学，不是动量）。

规则：

- 仅在叙事拍头时触发，≤ 每约 8s 一次；永远不在字幕中或期间保持。
- 在峰值模糊处切割（≥6px；峰值 8–12px，≤16–18px 最大） — 在上升过程中交换显示切割。
- 一个微妙的缩放（~1.06 镜头呼吸）把它当作光学销售。
- 双方方向相同 — 向量法则仍然适用。进入 ≥ 退出持续时间。
- 模糊包装器；一个元素上在一个补间中永远不会模糊 + 不透明度（无头合成错误）；永远不会直接模糊 `<video>`（包装它）。

## 6. 瀑布进入（场景内到达 — 不是缝线）

交错到达瀑布：单词/元素从下方（一个一致的方向）鞭打进来，每个都在前一个稳定之前开始 — 一个加速的波浪，最终解决为组合布局。标题卡，段落开篇，列表/功能介绍。缝线兄弟是 §4；不要混合他们的规则：

|               | §6 进入（到达）                            | §4 瀑布切割（缝线）                                   |
| ------------- | --------------------------------------------- | --------------------------------------------------------- |
| 不透明度       | 二进制 0→1 通过 `tl.set` 在进入时 — 永远不淡 | 在路径中点燃 — 淡出就是速度技巧 |
| 轴默认  | Y，从下方                                 | X，骑乘当前                                     |
| Outgoing side | 无                                          | 单词在镜像 power4.in 上 ramps out                      |

编排：

- **重叠，不要排队** — 下一个元素在 ±2 帧内开始，之前之前稳定；间隙在瀑布中收缩；最后一个元素弹跳。
- **速度因重量变化** — 重/锚元素旅行更远更长；轻单词/标点符号快速进入：

| 参数 | 锚/重 | 正常单词 | 轻/标点符号 |
| --------- | ------------ | ----------- | ----------------- |
| Y 偏移  | 60–80px      | 40–50px     | 30–48px           |
| 持续时间  | 0.16–0.20s   | 0.13–0.16s  | 0.10–0.13s        |
| 重叠   | 0–2f 间隙     | 1f 重叠  | 1–2f 重叠      |

- 缓动 `power4.out`（expo.out 以获得额外弹跳）；永远不在进入上 `.inOut`。
- 每个瀑布一个方向。
- 将最后一个单词分成碎片以延长高潮；碎片旅行更远。
- 后置解决，组通常滑动以腾出下一个拍头的空间 — 那是 §7。

## 7. 推曲线（场景内组滑动 — 不是缝线）

慢-快-慢重新定位组合的组（单词行，卡片堆栈，列表）以揭示内容或腾出空间。没有单个内置缓动产生它 — `power4.inOut` 撞到停止。在一个属性上链三个补间：

| 阶段     | 缓动            | 距离 | 时间 | 感觉                                     |
| --------- | --------------- | -------- | ---- | ---------------------------------------- |
| 1 拉入 | `power3.in`     | ~10%     | ~20% | 几乎不移动 — 运动注册，没有震动            |
| 2 爆发   | `none` (线性) | ~65%     | ~18% | ~2× 平均 px/帧 — 有目的                |
| 3 尾巴    | `power4.out`    | ~25%     | ~62% | 慢慢爬到静止 — 消除敲击                  |

规则：

- 尾巴在时间上是 ≥3× 拉入。如果它仍然敲击：延长尾巴的时间（不是距离）或使用 `power5.out`。
- 阶段 2 保持线性 — 缓动它失去爆发对比。
- 在阶段 2 期间揭示新内容 — 爆发掩盖了其外观。
- 垂直相同比例；按比例缩放距离，保持时间比例。

## 反模式

| 不要                                                                      | 而应                                                                           |
| -------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 缩放过程中可见两个文本                                                      | 在模糊峰值处硬切，一次一个文本                                                 |
| 文本缩放主体的20px模糊                                                      | 10px文本；仅在全帧使用18-20px                                                 |
| 逆缩放退出 → 从小到大进入（或推 → 过度收缩）                               | 匹配缩放速度的符号；在切±0.1s时验证                                           |
| 在Z缝包裹的tween中，输入合成动画的缩放放大                                 | 保持合成状态；在缝稳定后或匹配符号的舞台进入                                   |
| 交换时的模糊/不透明度不匹配                                                | 切割帧处值相同                                                             |
| 柔和的进入缓动 (`power2.out`)                                             | 对称退出：`power4.out` / `expo.out`                                          |
| 全屏外退出/进入                                                           | 部分移动（约12%）+ 提前淡出                                                 |
| 切割两侧的 `.inOut` 缓动                                                   | 对称 `power4.in` / `power4.out`                                              |
| 单个元素在切割前很久就开始淡出                                             | 淡出结束约在切割前0.02s，或文字级联                                          |
| 水帘级联中的等间距                                                       | 每个文字缩小间距×0.84                                                      |
| 正文文本的缩放通过                                                         | 仅标题和短短语                                                             |
| 无曲线切割的场景切割                                                       | 这是默认边界                                                               |
| 相反方向连续边界                                                         | 一个当前；保留向量用于意义                                                   |
| 中窗切割后的未绘制 `#root`                                                | 不透明舞台地面                                                             |
| 队列进入（每个等待前一个稳定）                                             | 重叠±1-2帧 — 级联是波浪，不是队列                                             |
| 每个级联元素相同的偏移/持续时间                                             | 按权重变化：锚点移动更远，标点快速定位                                       |
| §6到达时的渐变不透明度淡出                                                 | 通过 `tl.set` 的二进制0→1 — 淡出与快速定位冲突（缝切割淡出；到达不淡）          |
| 群组滑动的单一缓动 (`power4.inOut`, `slow()`)                             | §7三阶段链                                                              |
| 尾部比3倍加速坡度更短                                                     | 延长尾部的时间，而不是距离                                                  |
