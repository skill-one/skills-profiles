# 运动准则（网关）

在编排任何动画前，请阅读此准则。它决定了每个转场处会发生什么，以及每个场景如何表现；技术技巧将其实现。这些规则优先于通用/上游运动指导。它所防止的失败：孤立创作的场景——观众的惯性在每个剪辑点都会消失，场景在进入和退出之间会晃动。

## 路线图

| 决策（此技巧）                              | 实现技巧                                                                              |
| ------------------------------------------ | ------------------------------------------------------------------------------------ |
| 转场选择 + 参数 + 代码                     | `cut-the-curve` §1–5（目录）                                                            |
| 文本/元素进入级联                         | `cut-the-curve` §6（瀑布式进入）                                                          |
| 场内组重新定位（无剪辑）                   | `cut-the-curve` §7（推曲线）                                                              |
| 光标引导动作/场景启动/变形点火             | `oversized-cursor`                                                                        |
| 转场渲染机制/白闪保护                     | `seam-craft`                                                                            |
| 产品发布/解释/字幕工作                   | 在上游技巧之上叠加 `text-beat-economics`、`brand-faithful`、`captions-overlay` |

创作顺序：**矢量账本（`ledger.json`）→ 从中STAMP主转场（`scripts/seam-stamp.mjs --ledger ledger.json --write index.html`）→ 持续运动路线按阶段 → 载体和原因 → 构建合成 → 验证（`scripts/seam-gate.mjs`）。** 仅手工编写Tier-A变形/匹配剪辑；STAMP的转场通过构造通过网关。

# 第一部分 — 转场法则

## 矢量法则

> 场景A的退出方式决定了场景B的进入方式：相同轴，相同方向，匹配速度，两边都在运动中剪辑。

1. **轴** — x保持x，y保持y，Z保持Z。切勿在剪辑点交换轴。
2. **方向** — 切勿镜像。在Z轴上，方向=缩放变化的符号：放大=推（相机向前），缩小=拉（相机向后）。一个退行的退出由从小放大的进入响应是镜像矢量——最常见的违规行为，因为从小放大是默认的元素进入。
3. **速度** — 进入初始速度≈退出最终速度，通过镜像缓动（退出 `power4.in` + 进入 `power4.out`，相同距离和持续时间；进入侧通过概念路径获得≥50%）。机制在 `cut-the-curve` 中。
4. **阶段** — 剪辑在两边的中途落地。剪辑前稳定下来，或剪辑后从静止开始，是死节奏。

## 电流

每部电影选择一个主导方向（默认：左）。每个普通转场都使用它。其他矢量被保留——使用一个意味着：

| 矢量                    | 含义                                                         |
| ----------------------- | ------------------------------------------------------------- |
| 电流（左）              | “下一个节拍”——中性的前进进度                              |
| 向上                    | 提升——一个结论或揭示高于之前的内容                        |
| Z向前（缩放通过）       | 深入同一思考——推得更深                                      |
| Z向后（反向缩放）       | 到达——某件更大的东西落地                                  |
| 缩放爆发（向外爆炸）   | 离开一个世界——表面炸过相机                                |

- 切勿在相反方向上运行连续转场——乒乓球读作错误。
- 方向变化需要一个可见的原因（点击/弹跳/撞击）或章节边界。

## 矢量账本

在创作任何主时间轴之前编写——作为**项目根目录下的 `ledger.json`**（模式：`references/seam-gate.md`）。每行一个转场：剪辑时间，退出和进入矢量（轴+有符号方向；Z行携带缩放符号），选择器，技巧。退出和进入必须匹配；如果一行不匹配，修复计划，而不是缓动。验证器在运行时采样之前静态检查行的连续性。

## 载体

眼睛跟随对象，而不是抽象。最强的转场在匹配位置和速度下，手工传递一个具体载体：路径中的光标，缩小/停靠到下一个布局的容器，飞入其确切位置的标记，瀑布剪辑的词组。如果没有自然载体，场景英雄携带它（部分旅行+早期淡出，进入时在飞行中）。切勿交叉淡入淡出——它根本没有载体。

## 因果运动

链式运动，使每个移动都明显由上一个移动启动：点击 → 压缩 → 释放弹簧 → 飞行 → 撞击 → 反弹 → 揭示。

- 效果从导致帧开始——相同时间线位置，永远不会“之后”。
- 反应按隐含质量缩放：大元素反弹较慢，小元素猛地反弹。
- 力量是改变方向的许可；无原因的翻转是乒乓球。

## 转场网关（构建网关——运行验证器，退出0或转场未完成）

```bash
node <SKILL_DIR>/scripts/seam-stamp.mjs --ledger ledger.json --write index.html  # 生成
node <SKILL_DIR>/scripts/seam-gate.mjs  verify --ledger ledger.json --project .  # 验证
```

脚本（用法+账本模式：`references/seam-gate.md`）按转场数值强制执行：账本行连续性，退出在剪辑时仍在移动，进入在飞行中（永远不会从静止开始），测量方向=账本方向，进入/退出速度匹配（警告），**零重叠**（每帧一侧可见——剪辑不是溶解），**Z符号**规则（d(scale)/dt两边相同符号；进入场景自己的进入被扫描以查找符号冲突），载体矩形连续性包括祖先缩放。使用 `seam-gate.mjs probe --t <剪辑>` 在编写账本时查找每个转场的真实载体选择器。

脚本无法检查的规则——仍然是你：

1. **编辑重新打开转场。** 对场景的第一/最后一秒的任何更改（包括重新计时到新的VO）使该边界的审计失效——重新运行验证器。
2. **音频是时钟。** 根据VO的真实单词时间戳重新计时场景；切勿为了适应插槽而匆忙阅读。VO再生重新打开其转场。
3. **剪辑门禁陷阱**（零重叠失败的主要原因）：一个 `data-start` 早于其进入缓动的剪辑在初始不透明度下未隐藏——设置初始 `autoAlpha: 0` AND `data-start` = 剪辑时间，永远不会更早。

# 第二部分 — 表现（场景保持表现）

## 无闲置晃动

闲置正弦循环（呼吸、漂浮、漂流、发光脉冲）作为持续运动被禁止——它们读作“视频在等待”。一个在进入完成后仍有几秒钟剩余的场景是规划错误：增加故事，而不是晃动。进入和退出之间的每个阶段都属于以下路线之一（在计划中命名路线）：

| 路线                  | 它是什么                                                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **分阶段揭示**     | 暂时保留内容；在旁白节拍上支付它——帧不断获得信息（≥2内容组的默认） |
| **有意图的相机**     | 一个映射的缩放+平移路径：建立广角→旅行→到达主题                                               |
| **序列UI生命**  | 产品随时间行为：进度推进，高亮逐步，计数器跳动                                         |
| **动画序列**     | 元素表演一个节拍：一张卡片文件到一堆中，一个项目被拖动，一个结果组装                           |
| **光标引导动作**  | 一个超大的光标引导眼睛到触发器；它的点击点燃下一个节拍（`oversized-cursor`）                   |

测试：在任何一秒暂停——必须有有意义的东西在飞行中（一个揭示落地，相机在旅行，UI做旁白所说的事）。

## 高潮前的静止

在主要动作和其结果之间安排一个 **0.3–0.75秒的暂停**——戏剧性的逗号。一个场景直接从动作跳到结果会失去它。

## 时间意图

- 单一进入≤~800ms；较长的积累=多元素交错，而不是一个慢元素。
- 退出≈进入的75%。例外：`cut-the-curve`反转这一点（进入~127%的退出）。
- 总交错≤500ms；有8个以上元素时，收紧每个项目的延迟或交错前几个。
- 禁止的缓动：`bounce.out` / `elastic.out`。进入过冲 `back.out(1.4–1.7)` 是可以的。
- 相似元素共享一个缓动+持续时间意图——切勿每个元素都有独特的组合。

## 过渡词汇

每部电影只使用2–3个场景间过渡，并重复它们；默认边界是**电流方向的 `cut-the-curve`**。手工编写的共享元素变形（`intent: morph`）不计入预算。

## 反模式

| 不要                                                                      | 而是使用                                          |
| -------------------------------------------------------------------------- | ------------------------------------------------ |
| 每个场景的进入在孤立状态下编写                                  | 首先编写矢量账本                                |
| 场景之间交叉淡入淡出                                                   | 电流方向的 `cut-the-curve`                       |
| 退出完成，然后场景改变                                               | 两边在运动中剪辑                                 |
| 进入在剪辑后从静止开始                                               | 进入≥50%通过概念路径                           |
| 反向缩放退出→从小放大进入（或推→超大小回缩）                         | 匹配缩放速度符号（转场网关7）                   |
| 进入场景自己的Z转场交接下的弹入介绍                                   | 保持其开帧组合，或匹配符号                      |
| 闲置晃动/呼吸/漂浮以填补时间                                           | 分配一个持续运动路线；或增加故事                  |
| 无原因的方向翻转                                                   | 花费一个力量，或保持电流                         |
| 保留矢量用作多样性                                                   | 默认为电流；在意义上花费它们                      |
| 原因几帧后才发生反应                                               | 同帧点火                                      |
| 动作直接跳到结果                                                   | 安排高潮前静止（0.3–0.75秒）                   |
