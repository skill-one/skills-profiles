# motion-graphics (`heygen-com/hyperframes/motion-graphics`)

## blackbox

**function**: 把一句话、一个数字、一组数据或一个 logo, 做成几秒钟有设计感的动画短视频, 直接交付可用的 MP4 成片。

- input: 一句口号或金句, 如「数据不会说谎」, output: 文字逐字弹出、节奏卡点的动态字幕短视频 (MP4), 可直接发社交平台
- input: 一个关键数字和说明, 如「2024 年营收增长 137%」, output: 数字从 0 滚动到目标值、配环形进度条的统计动画 (MP4)
- input: 一组数据, 如四个季度的销售额, output: 柱状图/折线图依次生长、逐项高亮的图表动画 (MP4)
- input: 公司 logo 图片文件, output: 几秒钟的 logo 揭晓动画; 也可输出透明背景版本, 直接叠加到其他视频上
