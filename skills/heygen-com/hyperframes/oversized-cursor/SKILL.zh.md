# 超大光标——视觉引导者

一个故意设计得超大尺寸的 macOS 风格指针，在画面中作为 _可见的主角_ 行进：它从画面外进入，引导观众的视线到下一个兴趣点，点击触发后续事件，然后离开。已在多个发布影片中经过实践验证。

**其存在的原因。** 大光标移动是发布视频中成本最低、收益最高的动态元素之一：一个元素，仅使用 transform 变换的补间动画，它 (1) 在原本可能显得死寂的场景中将视线引导至屏幕上， (2) 为变形/过渡提供因果触发 ("点击触发了这个效果")， (3) 在启动新场景或复杂动画序列时将视线从沉闷状态中分离出来。越大越好——实际尺寸的光标在视频尺度下会消失不见。

## 尺寸与外观（公司规范）

- **全画面场景：`7cqw`** (≈134px 在 1920 分辨率下)。模拟/小画面变体：`4.6–5.5cqw`。绝不小于此尺寸。
- 全部使用 SVG 箭头几何形状。两种经过验证的填充方式——白色主体+黑色描边，或黑色主体 (`#1c1c1c`) + 白色描边 (1.4px)。根据每场画面的对比度选择，并在整部影片中保持一致。
- **品牌元素光标（关键策略）。** macOS 箭头是默认值，而非强制要求。当主题品牌具有可识别的光标身份——一个协作设计工具的彩色多人箭头带名称标签（Figma 风格），一个创意套件的精确十字准星，一个独特的产品指针——应使用那个光标：为任何熟悉产品的观众提供即时可识别的品牌语言。相同的规则保持不变（超大比例尺，物理进入/退出，尖端定位，点击触发），名称标签变体作为一个刚性单元移动（标签跟随箭头）。仅在元素确实可参考时才使用它；一个无人认识的光标只是一个奇怪的箭头——默认回到 macOS。

```css
#root .cursor {
  position: absolute;
  left: 48%;
  top: 115%； /* 画面下方——静止姿态就是画面外 */
  width: 7cqw;
  height: 7cqw;
  z-index: 20;
  filter: drop-shadow(0 4px 6px rgba(0,0,0,0.3));
  pointer-events: none;
  will-change: transform;
}
```

## 进入规则——物理，绝不暴露

光标 **始终从画面外进入**（规范：从下方，`top:115–120%`），以减速滑翔的方式移动到第一个目标。它必须 _感觉像它进入了房间_。绝不以静止位置进行不透明度淡入，绝不进行遮罩揭示——这会被视为故障（一个真实且反复观察到的失效模式）。

- 默认路径：**沿 y 轴直上** 到目标——不使用碎片化的对角线。当对角线确实是故事（朝向画面外目标进入）时，对角线是允许的，但无论如何都是一条连续的矢量。
- `duration: 0.4–0.92s`，`ease: power3.out`，`immediateRender: false` 在 fromTo 上。

```js
tl.fromTo(
  cursor,
  { left: "48.6%", top: "115%" },
  { left: "48.6%", top: "55%", duration: 0.85, ease: "power3.out", immediateRender: false },
  0.25,
);
```

## 尖端定位与点击轻击

热点是箭头 **尖端**，而非框中心。将**尖端**落在目标的中心，并围绕尖端进行所有按压缩放：`transformOrigin: '21% 14%'`（对于 24 单位 viewBox 中的房屋箭头路径）。

点击 = 非对称压缩/扩展（1:2 比例被视为真实的轻击）：

```js
tl.to(cursor, { scale: 0.84, duration: 0.1, ease: "power2.in", transformOrigin: "21% 14%" }, t);
tl.to(
  cursor,
  { scale: 1, duration: 0.22, ease: "power2.out", transformOrigin: "21% 14%" },
  t + 0.1,
);
```

**目标反应是一个独立的、并行的补间动画**（按钮：`scale: 0.94` + 按压颜色/阴影，从相同的 `t` 开始）。仅光标轻击（例如聚焦文本输入）不会获得目标反应。与 `cursor-click-ripple` / `press-release-spring` 配合使用以实现目标侧效果。

## 点击触发下一个节拍

绝不允许变形、打字运行、窗口变形或定义场景的动画直接 _开始_。将光标停在触发器上，让点击引发它，同帧：

- 点击 ▸ 菜单/子菜单级联，切换翻转
- 点击 ▸ 打字启动进入输入框
- 点击 ▸ 作曲家变形下 / 窗口缩小
- 点击 ▸ 标志点火 / 飞行启动
- 点击 ▸ 播放状态翻转 + 产品模拟 UI 生命唤醒

在长节拍期间它不拥有（打字、旁白），光标 **向旁边漂移** (0.5–0.9s, `power2.out`) — 绝不冻结在动作上方，绝不无聊地晃动。

## 退出规则与跨场景转场

两种认可的退出方式——都为物理，**绝不进行原地不透明度淡入**：

1. **离开画面**：以 `power2.in` 加速离开最近边缘 (`left:'118%'`, `left:'-12%'` 或 `top:'116%'`)，0.5–0.7s。
2. **曲线转场**：在硬切前的最后 ~0.3s，光标开始加速 (`power2.in`) 向下一个场景的点击点，覆盖该路径的前 ~1/3；下一个合成 `gsap.set` 将光标置于转场姿态并继续以匹配速度 `power2.out`。光标本身成为缝合的载体元素：

```js
// 场景 A，最后 0.3s — 开始旅程：
tl.to(cursor, { left: "40.7%", top: "63.7%", duration: 0.3, ease: "power2.in" }, CUT - 0.3);
// 场景 B，t=0 — 以匹配速度完成：
gsap.set(cursorB, { left: "40.7%", top: "63.7%" });
tl.to(cursorB, { left: "22%", top: "45%", duration: 0.6, ease: "power2.out" }, 0);
```

## 检查清单

- [ ] ≥ 7cqw 全画面（4.6–5.5cqw 在模拟内）——不确定时，更大
- [ ] 从画面外以单一连续矢量进入（无淡入/遮罩揭示）
- [ ] 尖端落在目标中心；按压围绕 `transformOrigin: '21% 14%'` 旋转
- [ ] 每次点击引发事件，同帧
- [ ] 在不拥有节拍时向旁边漂移；零空闲晃动
- [ ] 物理退出（离开画面或曲线转场）——无原地淡入
