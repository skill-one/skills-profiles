---
name: resolving-merge-conflicts
description: 适用于需要解决正在进行的 git merge/rebase 冲突时。
---

1. **查看当前的合并/变基状态**。检查 git 历史记录和冲突文件。

2. **为每个冲突找到主要来源**。深入理解每个变更为什么产生，以及原始意图是什么。阅读提交信息，检查 Pull Requests，检查原始的问题/工单。

3. **解决每个代码块（hunk）**。尽可能保留双方意图。如果两者不兼容，选择符合本次合并目标的一方，并记录权衡取舍。**不要**引入新行为。始终解决冲突；不要使用 `--abort`。

4. 发现项目的 **自动化检查** 并运行它们，通常是类型检查、测试、格式化。修复合并引入的问题。

5. **完成合并/变基**。将所有内容暂存并提交。如果正在变基，继续变基流程直到所有提交都完成。
