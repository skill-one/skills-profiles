# 旅行规划器

## 概述

这项技能将 Claude 转换为全面的旅行规划助手，能够保存您的旅行偏好，并生成包含行程、预算分解、打包清单和文化指南的详细个性化旅行计划，适用于任何目的地。

## 何时使用此技能

在以下旅行相关任务中调用此技能：
- 规划行程和创建行程单
- 预算规划和费用跟踪
- 目的地研究和推荐
- 打包清单
- 文化礼仪和该做/不该做的事
- 旅行前准备时间表
- 旅行偏好管理

## 工作流程

### 第 1 步：检查现有偏好

检查是否存在旅行偏好：

```bash
python3 scripts/travel_db.py is_initialized
```

如果返回“false”，则进入第 2 步（设置）。如果返回“true”，则进入第 3 步（行程规划）。

### 第 2 步：初始偏好收集

当不存在偏好时，收集全面的旅行信息：

**旅行风格与预算：**
- 预算水平：经济型、中档、豪华型
- 旅行节奏：休闲、适中、紧凑
- 住宿偏好：旅舍、酒店、Airbnb、度假村
- 旅行同伴：独自一人、情侣、家庭、团体

**兴趣与活动：**
- 观光与地标
- 食物与烹饪体验
- 冒险与户外活动
- 文化与历史
- 海滩与休闲
- 夜生活与娱乐
- 购物
- 自然与野生动物
- 摄影
- 健康与水疗

**饮食与健康：**
- 饮食限制（素食、纯素食、过敏）
- 无障碍需求
- 健康考虑
- 健身水平

**语言与技能：**
- 会说的语言
- 旅行经验水平
- 对冒险的接受程度

**过往旅行：**
- 已访问的国家/城市
- 最喜欢的目的地
- 梦想清单目的地

**保存偏好：**

```python
import sys
sys.path.append('[SKILL_DIR]/scripts')
from travel_db import save_preferences

preferences = {
    "travel_style": "冒险型",
    "budget_level": "中档",
    "accommodation_preference": ["精品酒店", "Airbnb"],
    "interests": ["文化", "食物", "徒步", "摄影"],
    "dietary_restrictions": ["素食"],
    "pace_preference": "适中",
    "travel_companions": "情侣",
    "language_skills": ["英语", "西班牙语"],
    "previous_destinations": ["巴黎", "东京", "巴塞罗那"],
    "bucket_list": [
        {"destination": "新西兰", "notes": "指环王取景地"},
        {"destination": "秘鲁", "notes": "马丘比丘"}
    ]
}

save_preferences(preferences)
```

将 `[SKILL_DIR]` 替换为实际技能路径。

### 第 3 步：创建新行程

当用户想规划行程时，收集以下信息：

**必要信息：**
1. **目的地**：城市/国家
2. **日期**：出发和返回日期（或灵活的日期范围）
3. **时长**：天数
4. **预算**：总预算或每日预算
5. **目的**：度假、商务、特殊场合
6. **必看/必做**：特定景点或活动

**创建行程：**

```python
from travel_db import add_trip

trip = {
    "destination": {
        "city": "巴塞罗那",
        "country": "西班牙",
        "region": "加泰罗尼亚"
    },
    "departure_date": "2025-06-15",
    "return_date": "2025-06-22",
    "duration_days": 7,
    "budget": {
        "total": 2500,
        "currency": "USD"
    },
    "purpose": "度假",
    "travelers": 2,
    "climate": "温暖的地中海气候",
    "activities": ["观光", "美食之旅", "海滩", "建筑"],
    "accommodation": {
        "type": "精品酒店",
        "location": "哥特区"
    }
}

trip_id = add_trip(trip, status="current")
```

### 第 4 步：研究目的地

使用网络搜索收集最新信息：

**必要研究：**
1. **入境要求** - 签证、护照、疫苗接种
2. **最佳旅行时间** - 天气、季节、节日
3. **安全信息** - 旅行建议、安全区域、常见骗局
4. **文化规范** - 该做/不该做的事（使用 `references/cultural_etiquette.md` 作为指南）
5. **当地交通** - 地铁、公交车、出租车、应用程序
6. **主要景点** - 必看地点的开放时间和价格
7. **美食推荐** - 当地特色、热门餐厅
8. **区域** - 住宿地点、探索区域
9. **一日游选项** - 附近景点
10. **实用信息** - 货币、小费、电源插座、语言

**搜索主题：**
- "[目的地] [国籍] 签证要求"
- "[目的地] 最佳旅行时间天气"
- "[目的地] 文化该做/不该做的事"
- "[目的地] 主要景点和活动"
- "[目的地] 当地交通指南"
- "[目的地] 住宿区域"
- "[目的地] 食物和餐厅"
- "[目的地] 避免的骗局"
- "[目的地] 预算指南"
- "[目的地] 7天行程"

### 第 5 步：生成详细旅行计划

创建包含所有组件的全面计划：

**A. 每日行程**

根据用户的节奏偏好和研究结构每日行程：

```
第1天：抵达 & 哥特区
- 上午 (9:00 AM)：抵达巴塞罗那，酒店入住
- 晚上午 (11:00 AM)：哥特区步行游览
  - 巴塞罗那大教堂
  - Reial 广场
  - Las Ramblas（短暂步行）
- 下午 (2:00 PM)：在 Cal Pep 用午餐（小吃）
- 下午 (4:00 PM)：毕加索博物馆
- 晚上 (7:00 PM)：在 El Born 区域用晚餐
- 晚上 (9:00 PM)：沿滨水区散步

交通：从机场乘地铁（30分钟，€5）
预计费用：€120/人（餐食、博物馆、交通）
备注：提前在线预订毕加索博物馆门票
```

对每天重复，确保：
- 逻辑的地理分组
- 现实的行程安排，留有缓冲时间
- 活动类型的混合
- 餐饮建议
- 交通细节
- 预计费用
- 预订备注

**D. 文化该做/不该做的事**

研究和呈现国家特定指南（使用 `references/cultural_etiquette.md` 作为模板）：

```
西班牙 / 巴塞罗那 - 文化礼仪

该做：
✓ 用“Hola”和亲吻脸颊问候（朋友）
✓ 学习基本的西班牙语/加泰罗尼亚语短语
✓ 晚餐晚（9-10 PM是正常的）
✓ 慢慢享用餐食
✓ 衣着时尚（当地人衣着得体）
✓ 尊重午休时间（2-5 PM，一些商店关门）
✓ 用餐前说“Bon profit”
✓ 服务良好时小费5-10%

不该做：
✗ 不要期望早晚餐（餐厅8 PM开门）
✗ 不要在市中心穿沙滩服装
✗ 不要假设每个人都说英语
✗ 不要称之为西班牙 - 当地人称之为加泰罗尼亚
✗ 不要匆忙吃餐
✗ 在公共场合不要大喊大叫
✗ 在弥撒期间不要拍照

餐饮礼仪：
- 午餐：2-4 PM
- 晚餐：9-11 PM
- 服务费可能包含（检查账单）
- 用餐时说“La cuenta, por favor”
- 分享小吃是可以的
- 面包不是所有餐厅都免费

安全提示：
- 在Las Ramblas和地铁注意扒手
- 在拥挤的地方将包放在前面
- 不要在海滩留下贵重物品
- 对陌生人提供的帮助要小心
- 使用官方出租车或Uber/Cabify
```

## 最佳实践

1. **彻底研究** - 使用网络搜索获取最新、准确的信息
2. **保持现实** - 不要过度安排；留出休息和随性的时间
3. **提前预订** - 热门景点在旺季会售完
4. **预算缓冲** - 额外添加10-20%以应对意外费用
5. **尊重文化** - 研究并遵循当地习俗
6. **安全第一** - 检查旅行建议，向大使馆登记
7. **保持灵活** - 天气和情况会变化
8. **记录一切** - 线下保存确认信息、重要信息

## 技术说明

**数据存储：**
- 偏好：`~/.claude/travel_planner/preferences.json`
- 行程：`~/.claude/travel_planner/trips.json`

**CLI命令：**
```bash
# 检查初始化
python3 scripts/travel_db.py is_initialized

# 查看数据
python3 scripts/travel_db.py get_preferences
python3 scripts/travel_db.py get_trips current
python3 scripts/travel_db.py stats

# 生成计划
python3 scripts/plan_generator.py --trip-id <id> --output plan.json

# 导出备份
python3 scripts/travel_db.py export > backup.json
```
