# 演讲稿制作工具

## 概述

根据行业最佳实践生成专业的PowerPoint演讲稿。该技能创建结构化的演示文稿，用于融资、销售和业务发展，采用经过验证的10页格式。

## 何时使用此技能

在用户请求以下内容时激活此技能：
- 用于融资的投资人演讲稿
- 销售或业务发展演示文稿
- 产品发布演示文稿
- 创业公司演讲比赛讲稿
- 任何遵循标准演讲稿格式的结构化商业演示

## 工作流程

### 第1步：收集信息

从用户那里收集必要信息以填充演讲稿。使用对话式方法收集以下类别的详细信息：

**必要信息：**
1. **公司基本信息**：公司名称、标语（一句话描述你做什么）
2. **问题**：你正在解决什么问题？如有可用，请包含数据或统计数据
3. **解决方案**：你的产品/服务如何解决问题？关键功能和优势
4. **商业模式**：你如何赚钱？定价、收入来源

**推荐信息**（如有可用，请包含）：
5. **市场机会**：市场规模（TAM/SAM/SOM）、增长率、市场趋势
6. **产品详情**：产品功能、截图、技术亮点
7. **进展**：关键指标、收入、用户、增长率、里程碑、客户证言
8. **竞争**：竞争对手、竞争优势、差异化
9. **团队**：创始人和核心团队成员及其相关背景
10. **财务与需求**：融资金额、资金用途、财务预测、里程碑

**方法：**
- 提出开放式问题以了解业务
- 在可能的情况下，探查特定指标和数据点
- 对于缺失的信息，提供创建可后续更新的占位符幻灯片的选项
- 根据可用信息调整标准的10页结构

### 第2步：组织内容

将收集到的信息组织成标准的演讲稿结构：

1. **标题幻灯片**：公司名称 + 标语
2. **问题**：解决的痛点
3. **解决方案**：产品/服务概述
4. **市场机会**：市场规模和增长
5. **产品**：功能和能力
6. **进展**：指标和成就
7. **商业模式**：收入和定价
8. **竞争**：竞争格局
9. **团队**：关键人物
10. **财务与需求**：融资需求和预测

**参考最佳实践**：有关每张幻灯片内容和结构的详细指导，请参阅`references/pitch_deck_best_practices.md`。使用grep搜索特定部分：

```bash
grep -A 10 "### [幻灯片编号]. [幻灯片名称]" references/pitch_deck_best_practices.md
```

### 第3步：创建JSON数据文件

将收集到的信息格式化为JSON文件，该文件将被演讲稿生成脚本使用。创建一个名为`pitch_data.json`的文件，其结构如下：

```json
{
  "company_name": "公司名称",
  "tagline": "一句话描述你做什么",
  "problem": [
    "问题陈述1，包含数据/统计数据",
    "问题陈述2，展示影响",
    "问题陈述3，展示紧迫性"
  ],
  "solution": [
    "你的产品如何解决问题",
    "关键功能1及其优势",
    "关键功能2及其优势",
    "独特价值主张"
  ],
  "market": [
    "TAM：可服务市场总额，含美元数字",
    "SAM：可服务市场",
    "SOM：可获取市场",
    "市场增长率和发展趋势"
  ],
  "product": [
    "产品功能1",
    "产品功能2",
    "技术亮点",
    "用户体验优势"
  ],
  "traction": [
    "收入：$X（YY%增长）",
    "用户：X,XXX活跃用户",
    "关键里程碑1",
    "客户证言或社会证明"
  ],
  "business_model": [
    "收入模式（例如，SaaS订阅）",
    "定价：$XX/月每个用户",
    "单位经济：CAC、LTV、利润率",
    "销售渠道"
  ],
  "competition": {
    "our_advantages": [
      "优势1",
      "优势2",
      "不公平优势/防御性"
    ],
    "competitors": [
      "竞争对手1",
      "竞争对手2",
      "替代解决方案"
    ]
  },
  "team": [
    "创始人1：姓名 - 背景和相关经验",
    "创始人2：姓名 - 背景和相关经验",
    "关键招聘：姓名 - 背景以及他们的重要性",
    "知名顾问"
  ],
  "financials": [
    "融资：$X种子轮/系列A轮",
    "资金用途：XX%工程，XX%销售，XX%运营",
    "本次融资的里程碑",
    "运行时间：X-X个月到下一个里程碑"
  ]
}
```

**注意：**
- 除`company_name`外，所有字段都是可选的
- 使用数组表示项目符号（将渲染为项目符号列表）
- 竞争可以是一个包含`our_advantages`和`competitors`键的对象（用于两列布局），或者是一个简单的数组
- 保持项目符号简洁（每条1-2行）
- 尽可能包含具体数字和指标

### 第4步：生成PowerPoint

执行Python脚本以创建PowerPoint演示文稿：

```bash
python3 scripts/create_pitch_deck.py pitch_data.json output_filename.pptx
```

该脚本将：
- 生成具有正确格式的专业PowerPoint文件
- 应用一致的颜色方案和字体
- 根据可用数据创建幻灯片（如数据未提供则跳过部分）
- 输出一个`.pptx`文件，准备好演示或进一步自定义

### 第5步：审查和迭代

向用户提供生成的演讲稿位置，并提供建议：
- 如果信息可用，添加缺失部分
- 精炼项目符号以提高清晰度和影响力
- 根据特定受众（投资人 vs. 销售演讲）调整结构
- 提供演示讲稿的指导

**迭代方法：**
- 用户可以使用新信息更新JSON文件
- 重新运行脚本以重新生成更新的演示文稿
- 对于脚本能力之外的版面设计定制，建议在PowerPoint中手动编辑

## 设计指南

生成的演讲稿遵循以下设计原则：

**颜色方案：**
- 主要：蓝色（#2962FF）用于标题和强调
- 次要：灰色（#646464）用于正文
- 纯白色背景，提高可读性

**字体：**
- 标题幻灯片：54pt加粗
- 小节标题：40pt加粗
- 正文：18-20pt，适当行距

**布局：**
- 一致边距和间距
- 每张幻灯片一个关键信息
- 每张幻灯片的项目符号限制为3-5项
- 比较幻灯片使用两列布局

**视觉层次：**
- 每张幻灯片顶部有清晰的标题
- 内容组织得当，间距适当
- 强调可读性和专业外观

## 示例使用场景

**场景1：寻求种子轮融资的早期阶段创业公司**
- 重点突出问题、解决方案、市场机会和团队
- 强调创始人专长和早期进展
- 清晰的融资需求和资金用途

**场景2：创建销售演示文稿的成长阶段公司**
- 强调产品功能和客户投资回报率
- 包含客户证言和案例研究
- 弱化融资，重点突出价值主张

**场景3：产品发布演示**
- 重点突出产品功能和市场需求
- 包含演示或产品截图
- 强调创新和竞争定位

## 定制和扩展

生成基本讲稿后：
- 用户可以在PowerPoint中手动添加图片、图表和自定义图形
- 建议创建附录幻灯片以提供详细信息备份
- 建议导出PDF以分享（PowerPoint中的“另存为”→PDF）
- 建议演示时间（通常10-15分钟，10张幻灯片）

## 故障排除

**脚本错误：**
- 确保`python-pptx`库已安装：`pip3 install python-pptx`
- 验证JSON文件是否格式正确（如有需要，使用JSON验证器）
- 检查文件路径是否正确，用户是否有写入权限

**内容问题：**
- 如果幻灯片显得拥挤，将每个幻灯片的项目符号减少到3-5项
- 对于复杂的竞争分析，考虑在PowerPoint中手动创建比较表格
- 对于财务预测，考虑在Excel中创建图表并作为图像导入
