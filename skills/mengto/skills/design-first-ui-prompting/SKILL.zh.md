# 以设计为先的 UI 提示技巧

这项技巧用于**以设计为先的提示**：将模糊的想法转化为产生一致 UI 的紧密规范。

## 核心原则
像设计系统一样提示，而不是凭空想象。

## 提示结构（复制/粘贴）
使用这个骨架，然后填充空白。

```text
目标
- 我们在制作什么？（例如，着陆页英雄图 / 欢迎引导 / 仪表盘 / 轮播图）
- 这是谁的？（用户画像）
- 成功标准是什么？（清晰度、转化率、氛围）

格式
- 尺寸/宽高比：（例如，1080x1350）
- 安全边距：（例如，90px）

布局（用文字描述的线框图）
- 网格：（例如，瑞士6列）
- 位置：（例如，文字左/图片右）
- 层级：H1 → 副标题 → 正文 → 行动召唤

字体系统
- 字体风格：（例如，Söhne / Neue Haas / SF Pro）
- 粗细：（H1 700，正文 400）
- 行距：（H1 紧凑，正文 易读）
- 字间距：（微标签更宽）

颜色 + 材质
- 背景：（十六进制或描述）
- 文字：（白色/象牙白/炭灰）
- 仅限一个强调色：（青色/酸橙色/紫色）
- 纹理：（微妙的颗粒感，无塑料 HDR）

图像 / UI 风格
- UI 风格：（极简/玻璃/编辑/趣味3D）
- 如果是照片：光照+裁剪+纹理规则
- 如果是3D：材质+光照+柔和度

文案（精确渲染）
- 第一行：
- 第二行：
- ...

约束（仅更改1-2件事）
- 字体：___
- 风格：___
- 模式：___

负面提示
- 无标志、无水印
- 无提供的行之外的额外文字
- 无混乱的字体排版
```

## 提高一致性的规则

### 1) 锁定一个“系统”，然后用变体迭代
- 首次输出：掌握**布局 + 层级 + 文案**。
- 变体：每次只更改**一个变量**：
  - 角度/裁剪
  - 强调色
  - 卡片排列
  - 背景色调

### 2) 将字体排版视为易碎品
如果模型一直拼写错误：
- 使用**两步工作流程**：
  1) 生成不带文字（预留干净的文字安全区域）
  2) 在 Figma 中排版

### 3) 使用“约束卡片”
当你想让模型遵循某种风格：
- 添加一个小型“约束”面板，包含明确值。
- 它像迷你风格指南一样锚定输出。

示例：
```text
约束
字体  CANELA
风格  极简
模式  暗色
```

### 4) 保持本地参考包
不要让模型“记住”品味。
- 将参考保存到 git 忽略的本地参考文件夹，例如 `refs/...`
- 将提示指向参考风格

## 快速迭代清单（要调整的内容）
- 间距：边距、行距、基线韵律
- 对比度：背景与文字
- 层级：一个英雄行，一个支持行
- 仅限一个强调色（不要彩虹色）
- 纹理：添加颗粒感，移除平滑

## 要问的问题（当用户含糊不清时）
- 这个屏幕的单一信息是什么？
- 层级是什么（H1 / 副标题 / 行动召唤）？
- 哪种风格路线：极简编辑/趣味3D/玻璃UI？
- 任何必须保留的约束（字体风格、颜色、间距、网格）？
