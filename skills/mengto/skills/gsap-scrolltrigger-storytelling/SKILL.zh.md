# GSAP ScrollTrigger 叙事技巧

## 使用场景
- 使用 GSAP ScrollTrigger 构建电影感的粘性产品叙事，结合渐进式 UI 揭示、滚动同步动画、平滑插值和沉浸式区域过渡。

## 工作流程

## 适用范围
- 当页面应呈现为滚动驱动的产品故事而非静态营销布局时，适用此技巧。
- 使用 GSAP ScrollTrigger 作为粘性区域、渐进式界面揭示、固定场景、滚动时间轴和区域间沉浸式过渡的主编排层。
- 保留实际产品叙事和界面清晰度。动画应增强理解，而非用戏剧性效果隐藏基本内容。

## 体验目标
- 创建粘性产品叙事，每个滚动片段揭示新的产品状态、功能层、数据视图、设备框架或工作流步骤。
- 使用滚动同步动画，使文案、UI 面板、截图、覆盖层和背景氛围作为一个编排序列同步移动。
- 构建渐进式 UI 揭示：逐帧绘制、淡入控件、滑入面板、数值递增、高亮区域、状态切换，随用户推进逐步展现。
- 保持整体氛围电影感、高端和沉浸式，通过控制节奏、干净的场景布置、深度和有意为之的过渡实现。

## 实现指南
- 使用 GSAP 时间轴配合 ScrollTrigger `scrub` 实现主滚动叙事，仅用常规补间动画处理辅助的进入或悬停效果。
- 使用 `pin: true` 固定长格式故事区域，并将每个场景映射到明确的时间轴标签，以便轻松调整序列。
- 优先使用 transform 和 opacity 动画而非影响布局的属性。仅在真正需要的动画元素上谨慎使用 `will-change`。
- 在 React 组件中使用 `gsap.context()` 并在卸载时清理，确保 ScrollTriggers 正确销毁。
- 在图像、字体或异步内容加载后刷新 ScrollTrigger，如果这些资源影响区域高度或固定偏移。
- 使用 `matchMedia()` 或等效断点，使桌面粘性编排在小屏幕上优雅简化。

## 动画模式
- 粘性产品框架：固定主元素，而周围叙事按步更新。
- 层级揭示：逐个引入标签、覆盖层、面板和产品状态，使用短偏移和共享的缓动语言。
- 区域交接：让当前场景缩放、遮罩、模糊或平移进入下一区域，而非突然结束。
- 平滑插值：使用滚动平滑、quickSetter/quickTo 或插值值实现指针跟随和滚动响应细节。
- 电影深度：使用前景/背景视差、微妙摄像机移动、变暗层、遮罩和焦点转换，不牺牲可读性。

## 调节旋钮
- 固定时长：密集产品故事可延长，单状态变化场景应缩短。
- 滚动感觉：直接滚动用于精确技术演示，缓动滚动营造电影感产品短片效果。
- 揭示密度：复杂 UI 可增加微揭示，叙事区域需减少以让文案主导。
- 过渡强度：保留高冲击力过渡用于区域交接，而非每个小内容变更。

## 避免
- 在每个滚动节拍触发无关动画而无明确叙事节点。
- 使用粘性/固定区域使读者停留过久或让页面感觉破碎。
- 在滚动时间轴场景中动画化宽度、高度、top、left 或布局属性，当 transform 可完成工作时。
- 让电影效果降低文本对比度、覆盖 CTA 或遮挡区域应解释的产品 UI。
- 组件卸载或路由变更后让 ScrollTriggers 处于活跃状态。
