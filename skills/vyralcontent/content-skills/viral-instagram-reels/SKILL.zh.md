# 病毒式Instagram Reels

专门帮助用户规划、撰写和诊断Instagram Reels。这里的机制与TikTok和Shorts不同：发送冷启动触达，强调原创性，并且试验Reels允许您在Reels触及您的粉丝动态之前，在非粉丝身上测试Reels。这项技能编码了仅适用于Reels的规则，这些规则改变了今天一个优秀的Reels是什么样的。它不会预测病毒性。它只是增加了胜算，并告诉您在这个表面上应该优化什么。

要进行跨平台钩子制作，请参阅`viral-hooks`。要进行创意构思系统，请参阅`viral-short-form-ideas`。要进行深入的标题工作，请参阅`viral-captions-and-ctas`。当问题专门针对Reels时，使用这项技能。

## 运作原则（首先阅读这些，并在整个过程中应用）

1. **每触达的发送量是获取新受众的指标。** 当Instagram决定是否将Reels推送给非粉丝时，私信分享通常比点赞大约多三到五倍。设计Reels和CTA以获取分享，而不是点赞。
2. **观看时间仍然是最大的单一信号。** 前三秒是公共转折点。在三秒前掉线被视为失败的钩子，并限制了种子测试。
3. **在提交前进行冷启动测试。** 如果Reels旨在触达非粉丝，并且您有超过1,000名粉丝，则默认首先使用试验Reels。失败的作品永远不会触及您的粉丝动态指标。成功之作在发布给所有人之前会获得确认的冷启动信号。
4. **原创性是强制执行的，而不是鼓励的。** 看起来像转载的Reels会被从冷启动分发中剔除。去除第三方水印，拍摄或大幅编辑自己的视频，并保持滚动30天的窗口期内多数原创。
5. **标题和屏幕上的文字是SEO表面。标签不是。** Mosseri明确表示标签不会提高触达。三个到五个相关的标签是可行的上限。将关键词放在标题和屏幕上。
6. **Reels是一个发现表面，而不是一个粉丝表面。** 您现有的粉丝只看到您Reels的一小部分。为从未听说过您的人规划每一个Reels。
7. **诚实的框架。** 模式匹配，而不是预测。说“这通常会提高发送量”，并解释原因。永远不要承诺Reels会病毒式传播。

## 工作流程

适应需求。不要审问用户。如果他们想要快速制作钩子，请跳到步骤3并推断其余部分。

1. **明确简报**（只询问缺失的内容）：主题或产品，目标（冷启动触达与粉丝培养与从这次Reels获取关注），账户类型（创作者与商业，因为音频访问不同），以及账户规模（少于1K意味着还没有试验Reels）。
2. **决定测试路径。** 如果目标是冷启动触达并且账户有资格，则通过试验Reels首先 → `references/trial-reels.md`。
3. **为三秒的悬崖撰写钩子。** 具体、明确，没有“嘿伙计们”的介绍。有关钩子原型，请参阅`viral-hooks`；这项技能涵盖了Reels上的不同之处（文本覆盖时间、静音观众的屏幕钩子、预览可分享回报的钩子）→ `references/reels-hook.md`。
4. **为发送而不是点赞构建结构。** 构建Reels，使回报是特定某个人需要看到的东西。将CTA从“关注获取更多”重新定义为“将这个发送给那个朋友，他/她[具体情况]” →
   `references/sends-playbook.md`。
5. **原创性和音频通过。** 确认没有TikTok或CapCut水印，视频素材符合Meta的原创内容指南，音频选择适合账户类型 →
   `references/originality-and-audio.md`。
6. **标题、屏幕上的文字、标签。** 将标题作为SEO + 发送提示写入。将关键词短语放在屏幕上。最多五个标签 →
   `references/caption-and-search.md`（以及参见`viral-captions-and-ctas`）。
7. **发布后：诚实地阅读Insights。** 跳过本次帖子的比率、分享率、粉丝。病毒式观看次数而没有粉丝意味着Reels没有使主题易于理解 → `references/insights.md`。

## 模式（根据用户询问的内容进行路由）

- **“为我写一个关于X的Reels”** → 步骤1-6，使用
  `assets/reels-script-template.md`。除非用户指定否则默认为15到30秒的目标。
- **“我应该用试验Reels测试这个吗？”** → `references/trial-reels.md`。
  基于目标、账户规模和风险承受能力的快速决策树。
- **“为什么这个Reels没有触达？”** → 诊断模式。走
  `references/diagnose-flop.md`：原创性标志、三秒掉线、发送信号、音频剥离、标题SEO。根据他们分享的Insights，具体说明最可能的原因。
- **“修复我的Reels钩子”** → 根据`assets/reels-hook-checklist.md`进行批评，然后重写薄弱的部分。专注于屏幕上的文字、第一帧和三秒的回报承诺。
- **“帮助我写标题”** → 使用
  `references/caption-and-search.md`的标题模式。第一行关键词、发送提示CTA、三个到五个标签。对于更深入的标题制作，指向
  `viral-captions-and-ctas`。
- **“我如何使用编辑应用”** → `references/edits-app.md`。当它有帮助时（无水印、更深入的Insights），它不能修复（编辑不会挽救一个弱的钩子），目前仅限移动端。

## 示例

**用户：** “我制作了一个22秒的护肤Reels，展示了我的早晨例行公事。18K观看次数，12个关注者，发送量低。出了什么问题？”

**好的回复：** 首先指出最可能的原因（Reels触达了但没使主题易于理解，所以观众看了又划走），然后按顺序进行诊断。询问分享率和跳线率来自Insights。检查第一秒的屏幕上的文字（无声时这个细分领域是否易于理解？）。检查CTA（是“关注获取更多”还是一个发送提示，比如“将这个发送给那个购买每种精华液的朋友”？）。建议重新剪辑：保留素材，重写前三秒以命名这个例行公事解决的特定问题，并将结束卡片替换为针对一个命名人格的发送提示。提供起草新开头和新标题的服务。永远不要承诺重新剪辑会达到某个数字。
