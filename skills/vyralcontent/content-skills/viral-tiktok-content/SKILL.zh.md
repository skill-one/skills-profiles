# 病毒式抖音内容

专门帮助用户为抖音撰写、塑造或修改内容。这项技能编码了抖音为你推荐页面的实际排名方式、视频需要达到的完成率、如何使用声音以及如何避免抖音暗中惩罚的内容。它不能预测病毒性，但可以提高成功的几率。

有关跨平台钩子原型，请参阅 `viral-hooks`。有关 Reels 或 Shorts，请参阅 `viral-instagram-reels` 和 `viral-youtube-shorts`。有关创意构思，请参阅 `viral-short-form-ideas`。有关标题撰写和行动号召，请参阅 `viral-captions-and-ctas`。

## 运作原则（首先阅读这些，并在整个过程中应用）

1. **为你推荐页面是一个兴趣图谱，而不是粉丝图谱。** 抖音直接表示：粉丝数量和过去的点击量不是直接的排名输入。每个视频都基于其元数据、声音和早期信号进行重新测试。
2. **完成率是关键。** 观看时间和完成率比点赞更重要。瞄准工作基准：>100% 在 15 秒以内（循环计算），~70% 在 15–30 秒，~50% 在 30–60 秒，~40% 在 60 秒以上。低于门槛，分发就会停滞。
3. **前 3 秒是整个钩子。** 保持 85%+ 在第 3 秒之后，通常会使总观看量增加数倍，而 60% 以下的钩子则相反。不要有标志、 "嘿，大家欢迎回来" 或开场动画。
4. **保存和分享比点赞更重要。** 保存被视为未来的意图，分享被视为社会证明。为 "把这个发给朋友" 或 "我以后需要这个" 而设计。
5. **分发是测试后再扩展。** 新上传的视频首先会展示给一小群相似的用户。强烈的早期信号会推动视频更广泛地传播，薄弱的信号则会将其保留。过时的视频可以重新进入测试，所以不要删除表现不佳的视频。
6. **诚实地说明预测。** 说明什么通常有效以及原因。永远不要承诺为你推荐页面的位置。重新使用的 YouTube 或 Instagram 剪辑几乎总是需要一个新钩子，并且要去掉水印才有机会。

## 工作流程

根据需求进行调整。不要审问用户。如果他们想要快速获取钩子，可以跳到第 3 步。

1. **明确简报**（只询问缺失的内容）：主题或产品、受众、目标（触达、保存、关注、购物点击）、目标长度、账户类型（创作者与商业影响声音访问）、限制（无脸、品牌规则、AI 使用）。
2. **选择长度层级并确认该层级的完成率计算** → `references/retention-math.md`。
3. **生成抖音风格的钩子。** 6–10 个符合抖音为你推荐页面行为模式的钩子（动作中段、反差、坦白、视觉+语言、感官锚点）→ `references/tiktok-hooks.md`。
4. **为抖音节奏构建脚本。** 钩子、升级、回报，设计为循环或触发保存 → `references/script-structure.md`。
5. **声音和原生功能。** 在其 48–72 小时窗口内使用流行音频以获取触达，使用原创音频以获取可重复使用的知识产权。决定是否需要二重唱、拼接或可购物链接 → `references/sounds.md`，`references/native-features.md`。
6. **标题、屏幕文字、标签。** 将第一句话放在前面（它在 "更多" 之前显示，并且抖音对其索引最强烈）。3–5 个具体标签，不是 20 个。标题撰写在 `viral-captions-and-ctas` 中。
7. **反模式检查。** 跨平台发布时不要有抖音水印、不要有诱导互动、不要在没有披露切换的情况下发布 AI 真实人物内容、不要 "关注以获取更多" → `references/anti-patterns.md`。

## 模式（根据用户请求进行路由）

- **"给我一个关于 X 的抖音钩子"** → 第 3 步，返回一组标记的抖音风格钩子，然后提供将最强的构建成脚本的服务。
- **"写一个抖音脚本"** → 完整工作流程，使用 `assets/tiktok-script-template.md`。默认为 21–34 秒，除非用户想要创作者奖励（然后为 60 秒以上）。
- **"使这个脚本符合抖音风格"** → 诊断节奏、钩子位置和长度与 `references/retention-math.md`。重写开头，收紧中间，设置循环或保存。
- **"这是抖音还是 Reel/Short？"** → 通过信号密度（声音、节奏、原生功能）进行回答。如果不是抖音，则指向匹配的平台技能。
- **"改进我的抖音视频"** → 批评模式。识别 3 秒悬崖失败的位置、完成率下降的位置以及缺失的信号（保存、分享、重看）。具体说明第二个标记。
- **"这周我应该跟随哪些抖音趋势？"** → 免费技能无法看到实时趋势。指导工作流程：通过创意中心、声音页面和你的为你推荐页面，在 48–72 小时窗口内发现声音。叠加个性。
- **"设置一个抖音购物视频"** → 先解决问题，然后是产品。6 秒钩子，6 秒屏幕上显示产品，实际使用中的演示，柔和收尾。使用 `assets/shop-video-template.md`。

## 示例

**用户：** "给我一个关于 39 美元可重复使用冷泡咖啡机的抖音钩子。"

**良好响应：** 推断简报（创作者账户，21–34 秒，目标是保存和购物兴趣）。返回 6–10 个标记的抖音风格原型钩子，每个都以回报开头并具体：

- *动作中段：* 摄像头已经倒出冷泡。 "使用这个 39 美元的玩意儿代替我 400 美元的意式咖啡设备已经 47 天了。"
- *反差：* "昂贵的咖啡设备是为什么你的咖啡尝起来更差。"
- *坦白：* "我在咖啡行业工作。我不应该喜欢这个。我每天都用它。"
- *视觉+语言复合：* 缓慢倒出，冰块破裂，屏幕文字： "这个 39 美元的咖啡机悄悄取代了我的整个架子。"

然后以一个看起来像开头的帧结束脚本，以便重新观看。如果他们在抖音购物上销售，提供将最强的构建成完整脚本和可购物视频版本的服务。永远不要以品牌开头。
