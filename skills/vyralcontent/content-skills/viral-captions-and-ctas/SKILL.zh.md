# 病毒式标题和行动号召

帮助用户撰写视频周围的文字：标题、屏幕文字、话题标签、行动号召（CTA）和置顶评论。这是决定一个优质视频是否会被传播、保存和分享的文案层。它不能预测病毒性。它排除那些抑制传播的规律，并推动那些倾向于提升传播力的规律。

有关钩子（hooks）和开篇句，请参阅 `viral-hooks`。有关平台算法深度，请参阅 `viral-tiktok-content`、`viral-youtube-shorts`、`viral-instagram-reels`。有关创意构思，请参阅 `viral-short-form-ideas`。有关完整脚本，请参阅 `viral-short-form` 总体。

## 运作原则（首先阅读这些，并在整个过程中应用）

1. **标题现在是SEO的关键。** Instagram对标题进行索引，用于应用内搜索和谷歌搜索。TikTok将标题作为主要分类输入进行读取。YouTube Shorts将标题和描述的前125个字符视为直接的排名信号。话题标签不再是发现的关键。文字才是。
2. **大多数观众静音观看。** 大约85%的社交视频是静音观看的。如果屏幕文字没有传达故事，那么对于大多数观众来说，视频就不存在。将标题烧入视频中。不要相信自动生成的标题。
3. **分享和保存比点赞和关注更重要。** 值得撰写的CTA与算法重度动作（分享、保存、完整观看）相关，而不是轻量级动作（“点赞”、“关注”、“在下方评论”）这些动作被视为吸引注意力的诱饵。
4. **吸引注意力的诱饵是传播的税。** “评论YES获取链接”、“标记一个朋友”、“点赞获取第二部分”、“关注获取更多”在Meta和TikTok的政策下都被视为诱饵。每个动作购买了一个小动作，并支付了传播的罚款。
5. **每个视频只提出一个要求。** 堆叠点赞、保存、分享、关注、私信会稀释所有这些动作。选择与内容类型匹配的动作，并赢得它。
6. **本地化，不要跨平台发布。** 为TikTok编写的标题不如为Reels重新编写的标题，也不如为Shorts重新编写的标题。不同的截断点、不同的关键词词汇、不同的话题标签惯例。
7. **模式匹配，而不是预测。** 标题和CTA往往以某种方式表现。这里没有保证结果。诚实是品牌。

## 工作流程

根据需求进行调整。如果用户只是想快速获取一个标题，可以跳到第3步。

1. **明确需求**（仅缺少的部分）：平台、视频主题和格式、受众、目标（搜索传播 vs 分享 vs 保存 vs 长视频点击）、任何品牌声音限制。
2. **选择主要动作。** 每个视频一个，与格式匹配。教程或列表 -> 保存。故事或推荐 -> 分享。观点 -> 带立场评论。悬念 -> 观看长视频。
3. **编写标题**，符合平台的截断点和SEO形状 -> `references/caption-craft.md`。第一行赢得点击。主要关键词一次，早期。正文添加上下文或回报；永远不会重复屏幕钩子。
4. **规范屏幕文字。** 标题块 + 正文标题，烧入平台的安全区域 -> `references/on-screen-text.md`。
5. **决定话题标签。** IG和TikTok上3到5个专业标签；YouTube描述中3到5个，加上#Shorts -> `references/hashtag-reality.md`。没有30个标签的墙，没有 #fyp填充。
6. **编写CTA。** 如果知道实际的下落点，在5秒前放置；否则在70%的位置附近。措辞来自 `references/ctas-that-work.md`。通过 `assets/bait-check.md` 进行检查。
7. **设置评论区。** 置顶评论或第一评论种子。预先阻止可预测的反对意见，放下不适合的链接，或发布第二个钩子 -> `references/pinned-comments.md`。

## 模式（根据用户的需求进行路由）

- **“为这个视频写一个标题”** -> 步骤1、2、3、5、7。返回标题 + 3到5个话题标签 + 建议的置顶评论。标记可见部分截断。
- **“修复我的CTA”** -> 根据 `references/ctas-that-work.md` 中的诱饵形状和“一个要求”规则进行诊断。为不同的目标（分享、保存、长视频点击）重写两到三个版本。
- **“我应该添加话题标签 / 有多少”** -> `references/hashtag-reality.md`。给出每个平台的数量和哪些标签值得空间。
- **“正确的置顶评论是什么”** -> `references/pinned-comments.md`。提供两个选项：反对意见杀手和第二个钩子。
- **“这是吸引注意力的诱饵吗”** -> `assets/bait-check.md`。直接判断。如果是，重写以保持相同意图，但去除诱饵形状。
- **“规范屏幕文字”** -> `references/on-screen-text.md` + `assets/on-screen-text-spec.md`。标题、正文节奏、重量、安全区域。
- **“为另一个平台重写”** -> 应用新的截断点、SEO词汇和话题标签惯例。不要复制粘贴。

## 示例

**用户：** “为我关于如何停止视黄醇剥落皮肤的Reel写一个标题。45秒的谈话头，展示日常护理。”

**良好响应：** 推断需求（Reels、美容受众、主要动作是分享，因为是个人推荐），然后返回：

标题（可见行落在~125个字符的“更多”截断点之前）：

> 视黄醇剥落皮肤的原因与视黄醇无关。将这个分享给你的朋友，他们一直责怪品牌。
>
> 我换了两个产品，四天内剥落停止。视频中逐步展示，确切的产品在置顶评论中。

话题标签（4个，专业）：`#retinolroutine #sensitiveskinroutine #dryskintips #beautyroutine`。置顶评论：产品名称和色号，“第14天”反对意见杀手。屏幕文字：居中顶部加粗标题，安全区域内的卡拉OK正文，白色带黑色轮廓。CTA在~30秒，轻量级隐含分享。

为什么这有效：反差第一行赢得点击，分享CTA命名了特定接收者（Reels上最重的动作），话题标签专业且数量少，置顶评论携带了不适合干净呈现的产品列表。

什么会出错： “关注获取更多护肤技巧，如果你同意就点赞，评论YES获取日常护理。” 三个要求，都是诱饵形状，并且缺少最重的动作（分享）。
