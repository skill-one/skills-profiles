# gstack (`garrytan/gstack/gstack`)

## blackbox

**function**: 像个懂行的前台总机: 你用一句大白话说需求, 它判断该派给哪项专门能力 (查 bug、审代码、测试网站、部署上线、写文档……), 交出对应的结果, 说不出需求也没关系, 它会帮你对号入座。

- input: 我刚改完几个文件, 帮我看看代码有没有问题, output: 一份代码评审报告: 指出具体哪几行有问题、为什么、怎么改
- input: 网站已经上线了, 帮我测一遍看能不能正常用, output: 一份 QA 报告: 发现的 bug 清单, 附截图证据
- input: 页面打不开了, 帮我查查为什么, output: 原因定位说明 + 修好的代码
