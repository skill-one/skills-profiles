# Tailwind 移动优先技能

使用此技能进行 Tailwind CSS 移动优先响应式设计：断点策略、流体字体和间距、触摸目标、容器查询、安全区域、响应式布局、媒体、导航和移动性能。

## 使用此技能的场景

当用户询问由 frontmatter 触发器覆盖的任务时使用，特别是实施指导、调试、架构选择、生产加固或该领域性能敏感决策。从此协调器开始，然后加载匹配请求详细程度焦点参考文件。

## 核心工作流程

1. 从移动基线无前缀工具开始，然后使用 `sm:`, `md:`, `lg:`, `xl:`, 和 `2xl:` 逐步增强。
2. 根据内容需求选择断点，而不是设备名称；仅在设计系统需要时覆盖 Tailwind v4 主题断点。
3. 使用 `clamp()` 结合 `rem + vw` 实现断点间平滑缩放，同时保持可访问性。
4. 使交互元素符合触摸安全标准，推荐 44px 目标尺寸、充足间距、清晰标签和移动导航模式。
5. 使用容器查询处理必须响应自身宽度而非视口宽度的可重用组件。
6. 使用 `aspect-ratio` 工具保留媒体尺寸，并使用安全区域工具处理带切口的设备和固定移动 UI。

## 关键注意事项

- 无前缀 Tailwind 类在所有尺寸下应用；断点前缀工具在对应断点及以上尺寸下应用。
- 先为桌面排序类不会使设计变为桌面优先，但常会掩盖意图并增加错误。
- 仅在触摸设备上失效的悬停交互；将悬停状态与焦点、激活状态或显式控件组合使用。
- 未保留宽高比的音视频和图像可能导致累积布局偏移。
- 固定底部导航必须考虑安全区域偏移并增加内容间距以避免重叠。
