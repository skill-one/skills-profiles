# qwen-agent

将**简单、自包含**的任务卸载到运行在无头Claude Code实例（`claude-9arm`）中的Qwen模型。保留需要Claude推理的高昂成本工作。

## 命令

`claude-9arm`是一个shell别名→`claude --model qwen3.6-35b-a3b`通过9arm网关路由。使用`-p`以无头方式运行：

```bash
claude-9arm -p "<自包含任务提示>" --allowedTools Bash Read Edit Write Glob Grep
```

- **这是默认调用方式。** 标志列表限定子代理可以在无需提示的情况下使用哪些工具，以便它可以无干扰地完成简单工作。没有它，子代理会在第一个编辑或命令时等待批准而停滞。
- 别名中嵌入了`--allowedTools '*'`，Claude Code会**静默忽略**并发出警告（`Wildcard tool name "*" is not supported`）。该警告是预期的且无害的——你追加的`--allowedTools`才是生效的。
- 对于仅编辑、低风险的任务，你可以改用`--permission-mode acceptEdits`（自动接受文件编辑，但Bash仍会提示——不要用于验证/构建/测试运行）。

## 编写任务提示（最重要的一步）

qwen子代理对这个对话**没有任何**上下文。模糊的提示是#1的失败模式。每个提示必须是自包含的：

- 每个输入和输出文件使用**绝对路径**（`/Users/tpatinya/proj/src/foo.ts`，而不是`foo.ts`）。
- **明确的输入、输出和验收标准**——要改什么，完成的标准是什么。
- **不引用**“我们讨论过的文件”、“上面”或先前的回合。
- 将qwen视为一个能干但字面意义的初级：详细说明步骤，保持范围狭窄。

差：`清理导入`
好：`在 /Users/tpatinya/proj/src/api.ts中，删除未使用的导入并按字母顺序排序剩余的导入语句。不要更改任何其他代码。确认文件仍然可以解析。`

## 注意上下文窗口（128k）

Qwen使用**128k-token上下文窗口**运行——比Claude小得多。整个工作（你的提示+它读取的每个文件+它自己的推理和编辑）必须能放在里面。将分配的任务大小分配给模型，而不仅仅是“是否简单”：

- **在分配前估计占用空间**：必须读取+打开+写入的文件字节数 + ÷ 4 ≈ token。如果单个任务会引入大文件或一次引入许多文件，它将放不下。
- **将大任务拆分为独立的块**，每个块都触及有限的切片——例如，每个运行一个文件（或几个小文件），每个运行一个目录，每个运行一个日志段。将块作为单独的`claude-9arm`调用运行（前台，或根据返回合同部分的后台并行）。
- **不要让它读取不需要的内容。** 指向所需的精确文件/路径；永远不要告诉它“扫描仓库”或读取整个大树。
- **在验证时注意上下文耗尽症状**：截断的编辑、忽略的后续指令，或省略了它被告知要触及的文件的摘要通常意味着任务溢出——拆分得更小并重试。

当任务本质上太大而无法整齐分割（它需要整个代码库的上下文才能正确执行）时，这表明它不是qwen任务——保留给自己。

## 工作目录

Bash工具的`cd`在调用之间重置，`cd &&`可能会触发权限提示。不要依赖cwd：

- 在提示中放入**绝对路径**，或
- 使用`--add-dir /abs/path`向子代理授予目录访问权限。

## 返回合同

- **默认（文本）**：qwen的最终消息打印到stdout——直接读取它。
- **需要解析结果**：添加`--output-format json`并提取`result`字段。
- **后台 / 并行（一次运行多个）**：重定向到日志并以Bash工具的`run_in_background: true`运行，然后在完成时读取日志：

  ```bash
  claude-9arm -p "<任务>" --allowedTools Bash Read Edit Write Glob Grep > /tmp/qwen-<标签>.log 2>&1
  ```

  将独立任务作为单独的后台运行启动；在完成时收集每个日志。在分配2个+无关的简单任务时使用此方法。

## 工作流程检查清单

1. 确认任务是简单且低风险的（见描述）。如果它需要设计判断或此聊天的上下文，**自己完成**——不要委托。
2. 检查它是否适合qwen的**128k上下文窗口**——估计文件占用空间并将大任务拆分为每个文件/每个目录的有限块（见“注意上下文窗口”）。
3. 编写一个完全自包含的提示，包含绝对路径和验收标准。
4. 运行`claude-9arm -p "..." --allowedTools Bash Read Edit Write Glob Grep`（前台），或后台重定向用于并行任务。
5. **自己验证输出**——qwen更便宜且不太可靠。在报告成功之前，检查文件/结果是否确实满足验收标准。

## 一次性设置（可选，移除重复提示）

为了阻止委托运行时的每次调用权限提示，为命令添加Bash允许规则（通过`update-config`技能，或通过编辑设置）：

```json
{ "permissions": { "allow": ["Bash(claude-9arm:*)"] } }
```

## 不要委托的情况

架构/设计、需要推理的调试、安全敏感的更改、任何需要此对话上下文的任务，或错误廉价模型编辑代价高昂的任务。如有疑问，保留。
