将自然语言Unity编辑器搜索请求转换为有用的Unity搜索查询，简要解释它们，并在适当的时候使用查询打开Unity搜索窗口。

## 默认行为

如果提示明确说明Unity搜索、快速搜索、搜索窗口、打开搜索或要求Unity搜索查询，即使目标属于其他领域（如光照、UI、物理、音频或动画），也使用此技能处理搜索请求。

对于诸如“查找”、“搜索”、“定位”、“列出”、“过滤”、“查找”、“在哪里”、“哪些资源使用”或“什么引用”具体Unity资产或场景对象的请求：

1. 确定请求主要关于项目资产、场景对象还是两者。
2. 构建一个简洁的Unity搜索查询。
3. 在打开搜索之前或同时显示查询。
4. 通过运行编辑器端代码片段打开Unity搜索，除非用户明确要求仅提供查询文本。
5. 如果打开搜索失败，返回查询并告诉用户手动将其粘贴到Unity搜索中。

当用户说“不要打开搜索”、“仅查询”、“我应该使用什么查询”、“只给我查询”或类似内容时，不要打开搜索。

如果用户要求一般性解释、项目概述、文件夹结构摘要、架构概述、游戏系统概述或“如何做”编程答案，除非提示明确要求Unity搜索、搜索查询或打开搜索窗口，否则不要使用此技能。

如果用户提到“这个”、“选定”或“当前”而没有附加资产、场景对象、可见名称或路径，请要求提供名称/路径，而不是编造一个。

## 范围

将只读Unity搜索/快速搜索查询范围限制为：

- 项目资产，如材质、纹理、预制件、场景、脚本、着色器、音频片段、精灵、网格、模型、动画、字体、渲染纹理和ScriptableObject资产
- 场景对象和组件，如相机、灯光、刚体、碰撞器、渲染器、画布对象、UI组件、粒子系统、音频源、动画器、地形对象和命名的GameObject
- 路径、标签、类型、文件名、关键字和基于引用的资产搜索
- 当从对话或附件中可以获取名称/路径时，使用选定或命名的资产

不要安装包、运行菜单命令、编辑资产、修改场景、搜索外部文档、搜索存储库文本、检查构建日志、删除结果、修复搜索结果或执行依赖关系图分析。如果用户要求对结果采取行动，请先打开搜索或提供查询，然后在任何单独的修改技能或工作流程之前请求确认。

## 将C#传递给`eval`

`eval`编译的是一个**语句块，而不是文件**。有两个后果，都是编译错误：

- **没有`using`指令。** 编译器将`using UnityEditor;`读取为资源释放语句并拒绝它（`CS0210`）。
- **类型必须完全限定。** 一个裸的`SearchService`无法解析（`CS0246`），而一个裸的`Object`与`object`具有歧义（`CS0104`）。

`unity-cli`技能拥有先决条件——安装CLI、确认连接的编辑器、添加项目的`com.unity.pipeline`包以及发现命令目录。您需要`eval`；如果它不存在，请生成查询文本并说明窗口无法打开。

## 查询生成规则

使用最简单的查询，它可能会产生请求的结果。

- 对于资产和组件请求，优先使用类型过滤器，例如`t:material`、`t:texture`、`t:prefab`、`t:scene`、`t:script`、`t:shader`、`t:Light`或`t:Rigidbody`。
- 除非需要引号，否则保留用户提供的名称和关键字作为普通查询术语。
- 当用户提供文件夹或说“在Assets/…”或“在…下”时，使用`dir:`。
- 当用户要求Unity资产标签时，使用`l:`。
- 当用户询问什么引用、使用、依赖、包含或连接到资产时，使用`ref=`。
- 只有当它们明显改进查询时，才使用搜索表达式，例如`t:prefab ref={t:texture}`或`t:scene ref={t:prefab}`。
- 对于选定/当前措辞，仅当它在聊天上下文中存在时才使用已知的选定资产名称或路径；否则请要求提供。
- 对于诸如“在哪里使用Rigidbody”的广泛关系请求，首先使用简单的关键字或组件查询，然后如果用户需要彻底的代码/属性分析，请说明脚本审计是单独的。
- 对于混合搜索和修复工作的请求，首先生成并打开查询；除非用户明确确认单独的后续操作，否则不要修改结果。
- 不要为不确定的请求编造不支持的过滤器。如果无法使用Unity搜索语法可靠地表达请求，请打开最安全的查询并说明限制。

## 打开Unity搜索

仅在编辑器中运行C#以打开搜索窗口。这是一个编辑器UI操作，不得更改项目资产或场景内容。

在打开搜索时：

1. 在生成的C#字符串中安全地转义查询。
2. 优先使用资产和场景提供程序，这是v1技能。
3. 如果提供程序不可用，则回退到活动提供程序。
4. 记录打开的查询。
5. 如果命令失败，则永远不要声称搜索已打开。

## 响应格式

保持面向用户的响应简短：

```text
查询：`t:material`
使用该查询打开了Unity搜索。
```

如果不打开搜索：

```text
查询：`t:prefab ref={t:texture}`
将此查询粘贴到Unity搜索中。
```

如果请求不明确但仍然可搜索，请选择最可能的查询并提及假设。只有在搜索目标无法推断时才提问，例如在没有资产、场景、类型、名称或上下文的情况下“查找那个东西”。
