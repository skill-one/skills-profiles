# 图层调色板创建

## 工作流程

### 第一步：参数收集
若尚未提供，请等待用户指定以下参数：
- **调色板名称**：资源的名称。
- **网格类型**：矩形、六边形或等距。
- **单元格大小**：可选（默认基于网格类型）。
- **排序轴**：等距调色板所需。

### 第二步：资源创建
使用 `UnityEditor.Tilemaps.GridPaletteUtility.CreateNewPalette` 创建图层调色板资源。

## 分支逻辑（网格类型）

### 路径 A：矩形
- 使用 **自动** 单元格尺寸。默认单元格尺寸：`(1, 1, 0)`。

### 路径 B：六边形
- 使用单元格尺寸：`(0.8659766, 1, 1)`。

### 路径 C：等距
- 使用单元格尺寸：`(1, 0.5, 1)`。
- 使用 **自定义排序轴**，值为 `(0, 0, 1)`。

### 路径 D：等距 Z 作为 Y
- 使用单元格尺寸：`(1, 0.5, 1)`。
- 使用 **自定义排序轴**，值为 `(0, 0, 1)`。

## 创建后
确保图层调色板资源中包含一个作为子资源的 `GridPalette`。
