# 热成像仪

将两个热成像仪审查流程作为异步后台子代理并行运行，然后合成其结果。

## 工作流程

1. 从用户请求、PR、当前分支或相关更改文件中确定审查范围。
2. 收集审查者评估变更所需的所有差异和任何文件/上下文摘录，以避免猜测。
3. 使用 `run_in_background: true` 在同一消息中启动两个子代理：
   - `subagent_type: "thermo-nuclear-review-subagent"` 用于错误、破坏、安全、开发异常回归、功能标志泄漏和其他分支审计风险。
   - `subagent_type: "thermo-nuclear-code-quality-review-subagent"` 用于可维护性、结构、文件大小增长、意大利面条式代码、抽象和代码库健康风险。
4. 将相同范围的差异/文件上下文传递给每个子代理，并要求其返回带有文件引用和证据的优先级发现。
5. 两个子代理完成后，以发现结果优先、跨审查者去重的方式合成结果。加重重叠发现的权重，使用自己的判断解决分歧，并保持摘要简短。

如果单个后台摘要已经对用户可见，则无需逐字重述。展示统一结论、最高信号发现以及任何剩余的不确定性。
