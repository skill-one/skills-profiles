# 不要阻塞人类

人类异步地监督工作。代理必须保持不被阻塞。做出合理的决策，继续执行，让人类事后进行纠正。

**原因：** 每一次权限暂停都会停滞流程，并使人类成为瓶颈。由于代码更改是可逆的和可审查的，一个错误的决策通常比阻塞造成的损失要小。

**模式：**
- **先执行，再展示。** 做完工作，展示结果。不要问“我应该做X吗？”做X，并解释原因。
- **使系统具备自愈能力。** 当你发现问题时，记录它并在下一轮中修复。

**边界：**
- **不可逆的操作**（强制推送、删除生产数据、发送外部消息）仍然需要确认。
- **可逆的操作**（编写代码、编辑笔记、拆分任务）应该在不阻塞的情况下继续执行。
- **产品方向**来自人类。*执行*不应该阻塞。
