# 使操作幂等

设计操作，使其无论运行多少次或从何处开始，都能收敛到正确的状态。每个修改状态的操作都应回答：“如果运行两次会怎样？如果上一次运行中途崩溃会怎样？”

**原因：** 命令、生命周期操作和处理循环通常在会崩溃、重启和重试是正常的地方运行。如果部分状态变化会影响下一次运行的结果，那么每次重启都变成了一次调试过程。

**模式：**
- 收敛式启动：扫描现有状态，清理过期的产物，采用活动的会话
- 基于内容的清理：通过内容等价性比较，而不是创建顺序
- 自愈锁：使用基于PID的过期锁检测
- 幂等式调度：失败的工作干净地重新生成，每次循环后重新生成输入

**测试：**
1. 如果连续运行两次会怎样？
2. 如果上一次运行在所有可能的点都崩溃了会怎样？
3. 重新执行是否收敛到相同的状态？

如果任何答案都是“取决于留下的状态是什么”，那么该操作需要一个协调步骤。
