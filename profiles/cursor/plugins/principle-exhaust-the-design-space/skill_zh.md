# 彻底探索设计空间

当一项新颖的交互方式或架构决策没有既定先例时，在实施前应探索多个具体的替代方案。构建错误的东西比探索三个选项的成本更高。

**规则。** 当正确答案不明显时，构建2-3个竞争性的原型或草图。将它们并排比较。只有到那时才进行承诺。设计两次是这个规则的另一种说法。第一种形状的第二次风味不计入其中。

**适用情况：**
- 新颖的UI交互（代码库中没有先例）
- 具有多个可行方法的架构选择
- 产品设计决策，其中用户体验取决于感觉而非逻辑

**不适用的情况：**
- 机械实施，其中模式已确立
- 具有明确目标状态的错误修复或重构
- 约束条件规定只有一种可行方法的变更
