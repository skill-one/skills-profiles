# 知识代理

从 claude-mem 观察 中构建和查询 AI 驱动的知识库。

## 什么是知识代理？

知识代理是观察结果集合，这些结果被编译成一个对话式 AI 会话。从您的观察历史中构建语料库，对其进行预置（将知识加载到 AI 会话中），然后以对话的方式向其提问。

可以将它们视为自定义的“大脑”：“关于钩子的所有信息”、“上个月的所有决策”、“工作服务器的所有修复程序”。

## 工作流程

### 第 1 步：构建语料库

```text
build_corpus name="hooks-expertise" description="关于钩子生命周期的所有信息" project="claude-mem" concepts="hooks" limit=500
```

过滤选项：
- `project` — 按项目名称过滤
- `types` — 以逗号分隔：决策、修复程序、功能、重构、发现、变更
- `concepts` — 以逗号分隔的概念标签
- `files` — 以逗号分隔的文件路径（前缀匹配）
- `query` — 语义搜索查询
- `dateStart` / `dateEnd` — ISO 日期范围
- `limit` — 最大观察结果数（默认 500）

### 第 2 步：预置语料库

```text
prime_corpus name="hooks-expertise"
```

这将创建一个加载了所有语料库知识的 AI 会话。对于大型语料库，这可能需要一些时间。

### 第 3 步：查询

```text
query_corpus name="hooks-expertise" question="5 个生命周期钩子是什么，每个钩子何时触发？"
```

知识代理从其语料库中回答问题。后续问题将保持上下文。

### 第 4 步：列出语料库

```text
list_corpora
```

显示所有语料库及其统计信息和预置状态。

## 小贴士

- **聚焦的语料库效果最佳** — “钩子架构”优于“所有信息”
- **预置一次，多次查询** — 会话在多次查询中保持持久
- **重新预置以获取新上下文** — 如果对话偏离主题，重新预置以重置
- **重建以更新** — 当添加新的观察结果时，重建然后重新预置

## 维护

### 重建语料库（使用新的观察结果刷新）

```text
rebuild_corpus name="hooks-expertise"
```

重建后，重新预置以加载更新的知识：

### 重新预置（新会话）

```text
reprime_corpus name="hooks-expertise"
```

清除先前的问答上下文并将语料库加载到新会话中。
