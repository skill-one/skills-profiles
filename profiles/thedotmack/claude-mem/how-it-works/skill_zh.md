# claude-mem 的工作原理

## 它的功能

Claude 进行的每次读取、编辑和 Bash 操作都会转化为一个压缩的观察记录。观察记录会在会话结束时进行总结。相关的观察记录会自动注入到未来的提示中，以便下一次会话从上一次的上下文中开始——无需重新解释代码库，无需重新发现决策。

## 它何时启动

在项目中的第二个会话时，记忆注入功能会启动。

在全新项目中的第一个会话会为记忆库播种；后续会话会自动注入相关过去的上下文。如果你希望一次性将整个仓库加载到记忆库中（约需 5 分钟，可选），请运行 `/learn-codebase`。

## 数据存储位置

所有数据都保存在本机的 `~/.claude-mem` 目录下。

除了调用你配置的用于压缩的 AI 提供商（Claude / OpenRouter / Gemini）之外，没有任何数据会离开你的机器。SQLite 数据库、向量索引、日志和设置都存储在该目录下，并在运行 `npx claude-mem uninstall` 时被干净地移除。
