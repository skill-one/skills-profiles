# GPT-Image2 风格库

使用此技能将用户的图像生成意图转换为使用 awesome-gpt-image-2 风格库的生产就绪 GPT-Image2 提示。

## 示例输出

![城市生命系统图谱示例](assets/city-life-system-map.png)

示例请求：`使用 gpt-image-2-style-library 技能生成城市生命系统图谱`

## 参考

- 在选择模板或风格之前，请阅读 `references/style-library.md`。
- 参考信息是从存储库中的 `data/style-library.json` 生成的。
- 当模板名称、类别、封面或风格标签很重要时，优先参考此信息而非内存。

## 工作流程

1. 识别用户的语言并使用该语言回答。
2. 确定用户的输出目标：产品、海报、UI、信息图表、品牌、照片、插画、角色、场景、历史、文档或特殊任务。
3. 按以下顺序匹配请求：模板类别、视觉风格标签、场景标签，然后是最接近的示例案例。
4. 如果有一个模板明显最强，则直接使用它。如果有多个可能性，则提供 2-3 个选项并附上简短理由，要求用户选择。
5. 使用以下模块构建最终提示：
   - 主题和任务
   - 构成和布局
   - 视觉风格和材料
   - 文本和标签要求
   - 纵横比和输出格式
   - 约束和负面细节
6. 包含所选模板名称和任何有用的示例案例 ID。

## 输出默认值

- 首先提供可复制的提示。
- 保持约束具体：确切的文本、纵横比、可读的标签、布局层次结构以及避免伪影。
- 对于中文请求，除非用户要求英文，否则将最终提示以中文编写。
- 对于英文请求，除非用户要求中文，否则将最终提示以英文编写。
- 当用户要求多个概念时，重用一个模板并变化主题、构成、调色板和场景。

## 维护

当源存储库发生变化时，运行：

```bash
npm run generate:style-skill
```

要将技能安装到本地 Codex 技能文件夹中，运行：

```bash
npm run install:skill
```
