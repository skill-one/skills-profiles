# 顶级设计：获奖数字体验

创建达到世界级数字代理机构水准的网站和应用。这项技能体现了那些持续赢得FWA、Awwwards、CSS设计奖和Webby奖的工作室的工艺。

## 核心原则

**每个像素都经过精心设计——没有默认设置，没有偶然。** 你所效仿的代理机构——Locomotive、Studio Freight、AREA 17、Active Theory、Hello Monday——共享着共同的基因：字体设计就是设计本身，动画创造情感，留白是一种武器，性能是不可协商的（60帧/秒或无）。

**基础：** 8/10和10/10之间的差距不是技能——而是意图。8/10具有良好的字体设计和流畅的动画；10/10的字体设计令人惊叹，动画讲述故事。每个决策都必须回答："这个设计是否服务于体验，或者只是填充空间？"

## 评分

**目标：10/10。** 使用下面的评分标准对任何数字体验进行0-10分的评分——10/10的体验会在Awwwards上展示。始终说明当前分数以及达到10/10所需的特定改进。

### 评分标准

| 分数 | 等级 | 描述 |
|------|------|------|
| **0-2** | 业余级 | 默认字体，没有层次结构，通用布局，模板感 |
| **3-4** | 基础级 | 良好的字体设计，有一些层次结构，但令人难忘 |
| **5-6** | 合格级 | 良好的基础知识，干净的执行，但缺乏灵魂 |
| **7-8** | 专业级 | 强大的字体设计，有目的的动画，明确的观点 |
| **9** | 杰出级 | 签名时刻，难忘的细节，近乎完美的工艺 |
| **10** | 世界级 | 会赢得Awwwards每日最佳，定义新的标准 |

### 类别评分（每个0-10分）

**字体设计（权重：25%）**
| 分数 | 标准 |
|------|------|
| 0-3 | 系统字体，统一比例，默认追踪 |
| 4-6 | 高级字体，一些比例对比，基本层次结构 |
| 7-8 | 剧烈比例对比（10:1+），完美的追踪，光学对齐 |
| 9-10 | 字体设计就是设计——令人惊叹的时刻，自定义/可变字体，字体作为建筑 |

| 分数 | 标准 |
|------|------|
| 0-3 | 一切居中，等距，刚性网格，没有张力 |
| 4-6 | 一些不对称性，不错的间距节奏，基本深度 |
| 7-8 | 有目的的网格破坏，分层元素，强烈的负空间 |
| 9-10 | 磁性构图，意外的比例变化，呼吸和惊喜的元素 |

**动画与交互（权重：20%）**
| 分数 | 标准 |
|------|------|
| 0-3 | 没有动画或默认/线性动画 |
| 4-6 | 基本过渡，一些滚动效果 |
| 7-8 | 自定义缓动，协调的揭示，有目的的视差 |
| 9-10 | 讲述故事的动画，完美时机编排，滚动感觉被创造 |

**色彩与氛围（权重：15%）**
| 分数 | 标准 |
|------|------|
| 0-3 | 随机颜色，纯黑/白，没有情绪 |
| 4-6 | 协调的调色板，一些氛围 |
| 7-8 | 色彩感觉被掌控，情境变化，有意对比 |
| 9-10 | 色彩感觉为这个项目被创造，可以感受到的氛围 |

**细节与工艺（权重：15%）**
| 分数 | 标准 |
|------|------|
| 0-3 | 默认光标，没有悬停状态，通用一切 |
| 4-6 | 基本悬停状态，一些自定义元素 |
| 7-8 | 磁性按钮，品牌选择颜色，自定义光标（如果用户批准） |
| 9-10 | 考虑了每个微细节——焦点状态，加载，空状态，滚动指示器 |

### 快速评分公式
```
总分 = (字体设计 x 0.25) + (构图 x 0.25) + (动画 x 0.20) + (色彩 x 0.15) + (细节 x 0.15)
```

## 顶级设计的七根支柱

### 1. 字体设计作为建筑

**核心概念：** 字体设计不是设计上的装饰——它就是设计本身。你的字体、比例和追踪决定了色彩情绪、动画风格、间距节奏和整体个性。

**为什么有效：** 剧烈的比例对比在模糊或从远处看到时也能传达层次结构。纪念碑式展示字体和亲密正文之间的张力是让人们停止滚动的原因。

**关键洞察：**
- 巨大的比例对比是不可协商的——显示和正文之间的最小比例至少为10:1（例如，180px / 14px）；极点填充的字体
- 大字体的负追踪（-0.02em到-0.05em）将显示紧密地组合成协调的单位；正文需要充足的行高（1.5-1.7）
- 字体选择定义了等级——高级字体铸造（Pangram Pangram，Dinamo，Grilli Type，Klim，Commercial Type）或高质量的Google替代品（Space Grotesk，Instrument Serif，Fraunces）；永远不要Inter，Roboto，Arial或system-ui用于英雄体验
- 可变字体允许在悬停时进行权重动画，而不会导致布局偏移
- 光学对齐优于数学对齐——视觉调整，而不仅仅是数字调整
- 控制标题的每一行换行——漂亮的换行需要关键断点处的手动干预

**应用：** 视口填充的显示硬降至正文（Locomotive英雄）；可变字体与悬停权重动画（Studio Freight）；极点比例对比的衬线/无衬线字体搭配（AREA 17编辑）。显示=一个声明，3-7个字；正文=最小16-18px，45-75个字符的度量。

选择字体或构建字体比例时查看[参考资料/typography.md](references/typography.md)——按风格命名的字体搭配，完整的流体`clamp()`和基于步骤的比例，追踪/行距梯度和字体子集/FOUT机制。

### 2. 布局与构图

**核心概念：** 掌握网格，以便可以有意地打破它——每个违规行为都应该感觉是故意的，而不是偶然的。密度和呼吸空间的节奏创造了吸引注意力的阅读体验。

**为什么有效：** 留白是积极的设计材料，它创造了张力并控制了节奏。不对称性产生了视觉能量，居中构图无法做到；有意重叠或溢出的元素感觉生动而自信。

**关键洞察：**
- 留白作为武器——业余者填充每个空白；顶级设计师使用空白来创造控制眼睛的张力
- 不对称平衡产生兴趣——将元素从中心偏移，让图像超出容器
- 意外的比例变化创造节奏——交替巨大/亲密，密集/稀疏以进行叙事节奏
- 网格悖论——一个强大的底层网格是什么让破坏有意义；没有它，破坏是混乱

**应用：** 偏移标题与出血图像（`margin-left: 8.33%； margin-right: -5vw`）；不同卡片大小有意不对称（Locomotive展示）；重叠元素以产生深度（Active Theory）。交替全宽沉浸式与包含阅读部分。

**道德边界：** 布局实验绝不能牺牲导航清晰度——用户必须始终知道他们在哪里以及如何继续前进。

布局部分或进行响应式设计时查看[参考资料/布局系统.md](references/layout-systems.md)——网格框架，断点系统，以及不对称/出血元素模式。

### 3. 动画与动画

**核心概念：** 每个动画都必须回答"为什么这个移动？"精英动画的三个定律：目的重于装饰，自定义曲线（永远不要线性），编排重于孤立。

**为什么有效：** 编排的动画引导注意力，传达层次结构，并创造情感共鸣。自定义缓动曲线给运动带来了物理质量，默认浏览器缓动无法实现。

**关键洞察：**
- 自定义缓动是强制性的——`ease`，`ease-in`，`ease-out`，`linear`是被禁止的；使用`cubic-bezier(0.16, 1, 0.3, 1)`（指数输出），`cubic-bezier(0.25, 1, 0.5, 1)`（四次方输出），`cubic-bezier(0.87, 0, 0.13, 1)`（指数输入输出）
- 页面加载遵循严格的编排——结构（0-200ms），英雄标题字词交错（200-600ms），副标题（400-800ms），导航级联（600-900ms），支持元素（800-1200ms）；参考保持每个元素的断点值的规范
- 相互关联地动画，而不是孤立地——一起移动的元素感觉连贯和有意
- 60帧/秒是不可协商的——如果动画掉帧，简化或删除它

**应用：** 编排的交错页面加载揭示（Studio Freight）；滚动进入时的clip-path/mask图像揭示（AREA 17）；悬停权重偏移和磁性按钮（Dogstudio）。文本行单独滑动并交错——永远不要作为一个块淡入；页面变形而不是剪切。

**道德边界：** 动画绝不能阻止交互或引起运动病——尊重`prefers-reduced-motion`，保持所有内容在没有动画的情况下也可访问，并证明任何超过1.2秒的东西。

实现动画时查看[参考资料/动画模式.md](references/animation-patterns.md)——可复制粘贴的滚动揭示，交错加载编排，页面过渡，以及磁性/悬停微交互的代码。

### 4. 色彩与对比

**核心概念：** 色彩应该感觉是为每个项目被创造的——永远不要从通用的调色板生成器中获取。三种方法：单色紧张（95%一种颜色，5%强调色），大胆签名（拥有自己的组合），情境变化（调色板响应内容）。

**为什么有效：** 色彩在阅读任何文字之前就创造了氛围。纯黑/白感觉数字化和无生气；暖色变体感觉物理化和经过考虑。有节制的强调色会精确地将眼睛吸引到预期的位置。

**关键洞察：**
- 永远不要使用纯黑或纯白——#0a0a0a和#fafaf9具有物理质量，而#000/#fff缺乏
- 构建功能层次结构——文本主要，文本次要（60%不透明度），文本第三（40%），表面，边框（10%）以保持一致的深度
- 一个强大的强调色被谨慎使用（#ff4d00或类似）胜过复杂的多种颜色调色板
- 情境色彩变化在部分之间创造视觉章节
- 为光和暗环境设计系统，而不是单个实例

**应用：** 单色与签名强调色（Locomotive：奶油色+黑色+橙色火花）；每个案例研究的情境变化（AREA 17）；暗模式与一个鲜艳的强调色（Stripe：海军蓝+紫色）。从CSS自定义属性（`--color-dark/-light/-accent`加上功能`--color-text-primary/-surface`）驱动一切；强调色仅出现在CTA，链接和单个细节时刻。

需要任何支柱的详细示例时查看[参考资料/案例研究.md](references/case-studies.md)——按机构分解的真实颜色系统，字体处理和微交互，以逆向工程。

### 5. 基于滚动的设计

**核心概念：** 滚动是网络的主要交互，应该感觉是设计的，而不是默认的。将滚动视为一种叙事工具——控制节奏，创造揭示，建立张力，传递签名时刻。

**为什么有效：** 默认滚动是机械的，并将所有内容视为同等重要。当滚动位置驱动揭示和过渡时，浏览内容变成了参与而不是被动。

**关键洞察：**
- 平滑滚动是基础——实现Lenis或Locomotive Scroll以获得每个获奖网站使用的加权，物理感觉
- 视差必须是有目的的——有限制，并且仅用于装饰性元素；永远不要用于文本或关键内容
- 固定部分创造叙事时刻——在内容在其内部转换时锁定部分
- 水平滚动画廊需要清晰的视觉提示
- 揭示应该是渐进的——元素在它们可见时进入，创造发现
- 滚动速度可以调节动画速度以获得响应式感觉

**应用：** 固定英雄与滚动驱动转换（Apple深度探索）；水平滚动画廊与提示（Studio Freight）；滚动驱动动画序列（Active Theory）。使用IntersectionObserver进行轻量级的类切换；保留GSAP ScrollTrigger用于复杂的多步骤序列。

**道德边界：** 滚动劫持是敌对的UX——用户必须始终能够以自己的速度滚动并访问所有内容。

查看[参考资料/技术堆栈.md](references/technical-stack.md)以连接平滑滚动（Lenis/Locomotive设置，库权衡）和[参考资料/动画模式.md](references/animation-patterns.md)以获取固定，水平画廊和滚动速度序列。

### 6. 性能与加载

**核心概念：** 性能是一天一开始的设计约束，而不是优化步骤。一个漂亮的动画如果掉帧，或者一个惊人的字体如果导致布局偏移，都会失败工艺测试。

**为什么有效：** 用户将性能视为质量——即时加载和流畅滚动感觉高级，无论视觉复杂性如何，而一个惊人的网站如果卡顿感觉是损坏的。

**关键洞察：**
- 子集和预加载字体——仅需要所需字形，`font-display: swap`或`optional`，预加载关键文件
- 优化图像——WebP/AVIF带备用，响应式`srcset`，折叠下方懒加载
- GPU加速动画——仅动画`transform`和`opacity`；永远不要`width`，`height`，`top`，`left`，或`margin`
- CLS接近零——为图像，字体和动态内容保留空间（容器上的`aspect-ratio`）
- LCP低于2.5秒——优化英雄的关键渲染路径
- 加载状态是设计元素——自定义骨架和进度指示器，而不是事后思考

**应用：** 子集/预加载/交换字体（`<link rel="preload" as="font" crossorigin>`）；AVIF/WebP带响应式`srcset`（`<picture>`备用）；GPU仅动画（`transform: translate3d()` + `opacity`）。使用Lighthouse针对90+进行审计；代码拆分并延迟非关键JS。

**道德边界：** 快但无法访问不是有效的权衡——永远不要为了速度而剥离可访问性功能或语义HTML。

选择库或遇到性能预算时查看[参考资料/技术堆栈.md](references/technical-stack.md)——推荐堆栈和具体的字体/图像/动画优化技术。

### 7. 微交互

**核心概念：** 工艺存在于设计师跳过的1%中：品牌选择颜色，磁性按钮，设计的焦点状态，考虑周到的加载状态，精心设计的错误页面，正确的微字体。

**重要：自定义光标仅限自愿选择。** 除非用户明确请求或确认，否则永远不要替换原生光标——不当使用自定义光标会损害可用性并感觉是花哨的。始终先询问。

**为什么有效：** 微交互表明每个像素都被考虑到了。单独微妙，集体变革——用户能感受到嵌入在体验中的关怀。

**关键洞察：**
- 自定义光标反映品牌个性，交互元素上有变体（受上述自愿规则约束）
- 品牌的`::selection`颜色适用于所有背景
- 每个链接和卡片都有一个经过考虑的悬停状态——缩放，覆盖或有意义的变化
- 焦点状态既美观又可见——品牌指示器键盘用户可以清楚地看到
- 加载，空，404和错误状态是设计的，有帮助的时刻
- 微字体是正确的——智能引号，en/em连字符，标题上没有孤字，`text-wrap: balance`在关键文本上

**道德边界：** 焦点状态必须满足键盘可见性要求，即使它们被品牌化设计，错误/空/404状态必须真正有帮助，而不仅仅是装饰。

查看[参考资料/动画模式.md](references/animation-patterns.md)以获取可复制粘贴的磁性按钮，光标和`::selection`/悬停微交互代码。

## 设计流程

按此顺序工作——顺序是纪律：

1. **代码之前是概念。** 首先定义四个东西：
```
品牌本质：什么单个词捕捉到灵魂？
视觉张力：什么对立力量创造兴趣？
签名时刻：什么会让人们截图并分享？
技术野心：什么会推动浏览器的极限？
```
2. **首先设计签名时刻**——不是标题。每个10/10项目至少有一个人们会停下来分享的时刻（一个从未见过的英雄动画，字体大胆到成为视觉本身，一个讲述故事的滚动序列）。通过询问确定它：什么会让人们截图，向同事描述，试图逆向工程，以及什么让它明确地是“这个项目”？
3. **接下来选择显示字体**——它决定了其余部分（支柱1）。
4. **与视觉设计一起原型设计动画，而不是之后**——动画不是装饰（支柱3）。
5. **以克制的方式发布**——3件事完美胜过10件事平庸。无情地削减。

## 实施说明

1. **概念化桌面优先，构建移动优先**——梦想伟大，逐步实施
2. **使用项目约定**——如果可用，使用Tailwind 4+和/或shadcn/ui，将它们的设计令牌和组件扩展为10/10工艺的基础，而不是与它们对抗

## 常见错误

每个修复都指向定义规则的支柱——在这里不要重新推导值。

| 错误 | 为什么失败 | 修复（见） |
|------|----------|-----|
| Inter，Roboto，Arial，或system-ui作为主要字体 | 应用程序字体表示通用，而不是高级 | 高级铸造或高质量的Google替代品（支柱1） |
| 统一字体比例（所有在2x内） | 没有层次结构，没有令人惊叹的时刻 | 打击显示到正文的比例（支柱1） |
| `ease`，`ease-in`，`ease-out`或`linear`缓动 | 机械的，无生气的——立即表明业余 | 禁止——使用自定义cubic-bezier（支柱3） |
| 同时动画所有东西 | 视觉噪音，没有层次结构或叙事 | 按重要性交错和序列（支柱3） |
| 一切居中对齐 | 安全但无聊——没有张力或能量 | 不对称性，网格偏移，出血元素（支柱2） |
| 每处都使用相等的间距 | 单调——眼睛没有地方休息 | 变化密度：密集部分，然后呼吸空间（支柱2） |
| 纯 #000000 / #ffffff | 无生气且刺眼 | 暖色变体（支柱4） |
| 默认浏览器滚动 | 机械的，将所有内容视为同等重要 | 平滑滚动库（支柱5） |
| 紫色到蓝色的渐变英雄 | "AI渐变"——通用的趋势追随 | 专为项目定制的颜色方法（支柱4） |
| 没有签名时刻 | 能干但令人难忘 | 首先设计截图时刻（流程步骤2） |
| 专业界面中的任何表情符号 | 指示休闲/业余工艺 | 自定义图标或字体处理 |
| 文本或关键内容上的视差 | 运动病，可访问性失败 | 视差仅用于装饰性背景元素（支柱5） |
| 动画阻止交互 | 敌对UX | 保持所有动画非阻塞（支柱3） |
| 未修改的Font Awesome图标 | 模板级设计 | 自定义图标，或大量定制以匹配品牌 |
| 默认表单样式 | 立即破坏工艺错觉 | 设计每个输入，选择，复选框和按钮（支柱7） |

## 快速诊断

每行回答"是"得1分，然后将计数映射到评分标准带：11-12 -> 9-10，8-10 -> 7-8，5-7 -> 5-6，低于5 -> 0-4。声明该分数。

| 问题 | 如果不是 | 修复（见） |
|------|-------|--------|
| 英雄字体设计是否让人们在滚动中暂停？ | 显示字体不引人注目 | 支柱1——比例，独特的字体，视口填充 |
| 是否有人会截图任何部分？ | 没有签名时刻 | 流程步骤2——使一个部分非凡 |
| 当你模糊眼睛时，设计是否仍然可读？ | 层次结构太平坦 | 更大的标题，更多的空白，更强的强调色 |
| 所有缓动曲线是否都是自定义的（没有`ease`/`linear`）？ | 动画感觉默认 | 支柱3——自定义cubic-bezier |
| 构图中是否有不对称张力？ | 布局感觉安全 | 支柱2——偏移，出血，变化密度 |
| 色彩是否感觉是为这个项目被创造的？ | 通用调色板 | 支柱4——单色紧张，签名或情境 |
| 页面加载是否编排？ | 元素同时弹出 | 支柱3——交错揭示序列 |
| 滚动是否感觉定制和加权？ | 默认浏览器滚动 | 支柱5——平滑滚动库 |
| 是否考虑了微细节（选择，焦点，光标）？ | 默认浏览器行为仍然存在 | 支柱7——品牌选择，设计的焦点（光标自愿选择） |
| CLS是否接近零且LCP低于2.5秒？ | 性能损害质量 | 支柱6——子集字体，WebP/AVIF，仅`transform`/`opacity` |
| 每个动画是否回答"为什么这个移动？" | 装饰性动画 | 支柱3——删除没有叙事或指导的动画 |
| 焦点状态是否既美观又可访问？ | 一个牺牲了另一个 | 支柱7——品牌指示器满足WCAG可见性要求 |
| 错误/空/404状态是否真正有帮助？ | 仅仅是装饰 | 支柱7——焦点状态必须满足键盘可见性要求，错误/空/404状态必须真正有帮助 |
