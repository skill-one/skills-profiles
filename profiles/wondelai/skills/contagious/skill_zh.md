# 口碑与病毒式传播框架

基于乔纳·伯杰（Jonah Berger）对事物为何能流行的研究，这是一个用于工程化口碑传播、使产品、想法和内容具有传染性的框架。利用它将可分享性设计到产品、活动和内容中，而不是寄希望于运气。

## 核心原则

**病毒式传播并非天生的，而是被设计出来的。** 产品之所以传播，是因为它们被设计出来——无论是有意还是无意——供人们分享。只有7%的口碑传播发生在网上；其余93%发生在线下对话中，因此病毒式传播关乎分享心理学，而非社交媒体机制。这些心理模式是可预测的，可以使用STEPPS框架将其工程化到任何事物中。

参见：[references/word-of-mouth.md](references/word-of-mouth.md) 当简报过度关注社交媒体时——它阐述了线上线下案例，列出了对话触发因素，并提供了口碑测量/审计方法。

## 评分

**目标：10/10。** 对六个STEPPS驱动因素（六个快速诊断行）进行评分——**0**表示缺失，**1**表示存在但较弱，**2**表示强烈且刻意——得出原始0-12分，然后映射：11-12 -> 10，9-10 -> 8-9，6-8 -> 6-7，3-5 -> 4-5，0-2 -> <=3。等级：
- **9-10** — 三个或更多驱动因素达到强度2，其中至少有一个是公共价值或社交货币（自我传播的），并且品牌通过了特洛伊木马测试。
- **6-8** — 两个驱动因素真实强大，但传播仍然依赖于付费触达或产品品质本身。
- **<=5** — 至多一个弱驱动因素；分享是偶然的，而非被设计的。

报告原始分数、映射分数以及需要提升的具体驱动因素以达到10/10。

## STEPPS概述

**不是清单——而是乘数。** 每个原则独立地增加分享；最具有传染性的想法同时激活多个原则，但即使做好一个或两个也能显著增加口碑传播。

| 原则 | 核心问题 | 分享驱动因素 |
|-----------|--------------|----------------|
| **S — 社交货币** | 分享它是否让人们看起来很棒？ | 自我提升 |
| **T — 触发因素** | 环境中有什么能提醒人们？ | 顶部可获取性 |
| **E — 情感** | 它是否激发高唤醒感？ | 生理唤醒 |
| **P — 公开性** | 他人是否能看到人们使用它？ | 观察学习 |
| **P — 实用价值** | 它是否足够有用以至于可以传递？ | 利他主义和帮助 |
| **S — 故事** | 品牌是否嵌入在叙事中？ | 娱乐和身份 |

## STEPPS框架

### 1. 社交货币

**核心概念：** 人们分享让他们看起来很棒的东西——聪明、酷、消息灵通。让人们感觉自己像是内行，他们会传播它来提升自己的形象。

**为什么有效：** 分享是自我表现——听众从他们传递的内容中推断分享者的特质，因此人们像整理衣服一样整理分享。机制：给分享者提供地位或身份的回报，你就将营销外包给了他们的自尊。

**关键洞察：**
- **非凡性** — 令人惊讶、新颖或极端的东西让分享者看起来很有趣；“你听说过吗？”是一个强大的分享触发因素
- **游戏机制** — 排行榜、徽章和地位等级创造了人们想要展示的可见成就
- **排他性和稀缺性** — 秘密菜单和仅限邀请的访问方式让人们拥有“内部知识”来分享
- **内在非凡性** — 即使是平凡的产品也有非凡的角度；这是框架，而不是产品

**产品应用：**

| 环境 | 应用 | 示例 |
|---------|------------|---------|
| 内容平台 | 内部统计数据或年度回顾 | Spotify Wrapped |
| 移动应用 | 可分享的成就卡片 | Duolingo连续学习徽章 |
| B2B产品 | 用户想要引用的基准数据 | HubSpot营销状态报告 |

**文案模式：**
- "大多数人不知道的是..."
- "你是首批尝试的人之一..."
- "你解锁了[成就]..."

**道德边界：** 创造真实的内部价值，而不是虚假的稀缺性或人为制造的排他性，这些会滋生毒性。

参见：[references/social-currency.md](references/social-currency.md) 当产品感觉不非凡时——它有内在非凡性练习、游戏机制设计、排他性类型，以及评分审计。

### 2. 触发因素

**核心概念：** 顶部可获取意味着舌尖可触及。将你的产品与环境线索——视觉、听觉、时间、习惯——联系起来，让日常生活不断提醒人们谈论你。

**为什么有效：** 大多数口碑传播不是由兴奋驱动的，而是由对话中顶部可获取的内容驱动的；与频繁线索联系的产品更容易被提及，因为它们在记忆中更容易获取。

**关键洞察：**
- **频率胜过强度** — 每日线索（咖啡）优于强大但罕见的线索（假期）；Kit Kat将其与咖啡休息时间联系起来
- **栖息地很重要** — 绘制人们遇到与你的产品相关的环境的时间和地点
- **竞争性触发因素** — 将竞争对手的时刻与你的品牌联系起来
- **持续与临时** — 持续的环境触发因素持续口碑传播；事件触发因素仅使其激增

**产品应用：**

| 环境 | 应用 | 示例 |
|---------|------------|---------|
| 食品/饮料 | 与每日习惯联系 | Kit Kat + 咖啡休息时间 |
| 生产力工具 | 与重复工作流程时刻绑定 | “每周一例会时..." |
| 金融产品 | 与发薪日联系 | “每次你领工资时..." |

**文案模式：**
- “每次你[频繁活动]，想想..."
- “下次你[日常习惯]..."
- “现在是[日期/时间]——时候到了..."

**道德边界：** 建立真实、有用的关联——劫持敏感环境（悲伤、健康恐慌）作为触发因素适得其反。

参见：[references/triggers.md](references/triggers.md) 当选择要附加的线索时——它有栖息地分析工作表、频率矩阵和4步触发因素设计过程。

### 3. 情感

**核心概念：** 当我们关心时，我们会分享。高唤醒感——积极的（敬畏、兴奋、幽默）或消极的（愤怒、焦虑）——驱动分享；低唤醒感（悲伤、满足）会抑制分享。

**为什么有效：** 生理唤醒——心跳加速、激活状态——创造分享的需求。这是激活而非抑制，不是积极与消极。

**关键洞察：**
- 高唤醒驱动分享：敬畏、兴奋、幽默、鼓舞、愤怒、焦虑
- 低唤醒抑制它：满足和放松没有紧迫感；悲伤使人们退缩
- **敬畏是最具分享力的情感** — 感觉渺小面对巨大或令人惊讶的事物传播最远
- **情感框架** — 相同的事实可以有不同的唤醒感框架；事实提供信息，框架激励分享

**产品应用：**

| 环境 | 应用 | 示例 |
|---------|------------|---------|
| 发布内容 | 通过意想不到的规模或美感工程敬畏感 | Apple发布会揭秘 |
| 产品演示 | 通过意想不到的使用方式产生幽默 | Blendtec "它能粉碎吗？" |
| 社会活动 | 对不公正的正当愤怒 | Dove "真实之美"挑战美丽标准 |

**文案模式：**
- “我简直不敢相信[惊人事实]..."
- "看看发生了什么..."
- "这会改变你如何思考..."

**道德边界：** 工程愤怒以获取点击率会腐蚀信任——仅在真正值得的原因下谨慎使用高唤醒的负面情绪。

参见：[references/emotion.md](references/emotion.md) 当内容感觉平淡时——它有情感分享矩阵、敬畏工程技巧和幽默设计规则。

### 4. 公开性

**核心概念：** 为展示而设计，为增长而设计。如果人们能看到他人使用你的产品，他们更有可能采用它——设计可观察性。

**为什么有效：** 可见的选择为观察者解决了不确定性——看到他人使用产品降低了他们的感知风险，并提供了零边际成本的社会证明，因此可观察性使每个用户都成为被动、持续的广告牌。

**关键洞察：**
- **行为残留** — 设计可见的痕迹，这些痕迹比使用时间更长：Livestrong腕带比捐赠时间更长
- **自我广告产品** — 每封Hotmail电子邮件都携带“在Hotmail获取免费电子邮件”；产品通过使用为自己做广告
- **公开=可模仿** — 人们只能模仿他们能观察到的东西；找到让不可见使用可见的方法

**产品应用：**

| 环境 | 应用 | 示例 |
|---------|------------|---------|
| 电子邮件/消息 | 品牌签名 | “从我的iPhone发送” |
| 物理产品 | 使用期间可见的品牌 | Apple的向外 MacBook标志——每台打开的笔记本电脑都是一个广告牌 |
| SaaS工具 | 将工具的公共输出归功于工具 | “由[工具]提供”在客户网站上 |

**文案模式：**
- “向世界展示你[成就/身份]..."
- “分享你的[输出]——由[品牌]提供..."
- “加入[数字]其他人..."

**道德边界：** 可见性必须赋权，绝不能羞辱——用户始终控制什么成为公共的，而私人数据（失败、健康、财务）保持私密。

参见：[references/public-visibility.md](references/public-visibility.md) 当使用不可见时——它有公共与私人分解、行为残留设计清单和Apple标志设计教训。

### 5. 实用价值

**核心概念：** 人们分享有用的信息来帮助他人。你能使用的新闻会传播——尤其是包装起来便于传递的。

**为什么有效：** 分享实用价值是利他主义——如果你的内容节省人们的时间、金钱或精力，他们会转发给他们的网络作为礼物。

**关键洞察：**
- **前景理论** — 人们根据参考点判断交易：20美元的商品减10元比1000美元的商品减10元感觉更好
- **100规则** — 低于100元，使用百分比折扣（“50%折扣”）；超过100元，使用金额（“200元折扣”）
- **窄受众=更广泛的分享** — 狭义内容被转发给“需要这个的人”
- **知识包装** — 清单、操作指南和技巧集合比文章更具分享性

**产品应用：**

| 环境 | 应用 | 示例 |
|---------|------------|---------|
| 定价/促销 | 通过100规则框架交易 | “节省40%”低于100元 vs. “节省500元”超过100元 |
| 内容营销 | 可转发的编号清单 | “7种减少电费的方法” |
| B2B内容 | 可分享的工具和基准 | 免费ROI计算器，可分享结果 |

**文案模式：**
- “[数字]步指南到..."
- “快速技巧：[立即有用的建议]..."
- “分享这个给需要听到的人"

**道德边界：** 价值必须是真实的——虚高的“原始”价格和点击率生活技巧比它们产生的分享更快地摧毁信任。

参见：[references/practical-value.md](references/practical-value.md) 当框架交易或包装技巧时——它应用前景理论、100规则快速参考和知识包装层次结构。

### 6. 故事

**核心概念：** 人们不分享信息——他们讲述故事。将你的想法嵌入人们想要重述的叙事中，品牌就像特洛伊木马一样一起传播。

**为什么有效：** 人类用叙事思考，沉浸故事会降低批判性防御——嵌入的信息比直接推销更容易被接受。

**关键洞察：**
- **特洛伊木马测试** — 如果某人能在不提及品牌的情况下复述故事，故事就失败了；品牌必须是不可或缺的
- **可复述性** — 故事必须能在非正式对话中生存；10分钟的设置不会传播
- **有价值的病毒性** — 没有人将搞笑广告归因于品牌是一个失败
- **叙事运输** — 沉浸的听众更容易接受嵌入的信息

**产品应用：**

| 环境 | 应用 | 示例 |
|---------|------------|---------|
| 品牌营销 | 叙事与产品不可分割 | Blendtec "它能粉碎吗？"——无法在不提及品牌的情况下复述 |
| PR/赢得媒体 | 本身就值得讲述的噱头 | Barclay Prime的100美元牛排 |
| 产品发布 | 围绕客户问题的起源故事 | “我们建立这个是因为我们的创始人找不到..." |

**文案模式：**
- “这是...的故事”
- “一切始于[创始人/客户]意识到..."
- “没有人相信[大胆声明]——直到..."

**道德边界：** 故事必须是真实的或明确的虚构——编造的证词和虚构的起源最终会暴露并毒化未来的口碑传播。

参见：[references/stories-trojan-horse.md](references/stories-trojan-horse.md) 当塑造叙事时——它有品牌整合测试和四个故事模板（演示、噱头、起源、客户英雄）。

| 阶段 | STEPPS组合 | 策略 |

## 常见错误

| 错误 | 为什么失败 | 修复 |
|---------|-------------|-----|
| 只关注线上分享 | 93%的口碑传播是线下 | 设计对话触发因素，而不仅仅是分享按钮 |
| 可分享但未链接到品牌 | 人们分享笑话，忘记是谁制作的 | 应用特洛伊木马测试 |
| 使用低唤醒感 | 悲伤和满足不会激活分享 | 为敬畏、兴奋、幽默或愤怒重新框架 |
| 不可见的产品使用 | 没有人模仿他们看不到的 | 添加行为残留和可见信号 |
| 单独依赖产品品质 | 没有STEPPS的优质产品传播缓慢 | 刻意将2-3个STEPPS工程化到体验中 |
| 稀有、强大的触发因素 | 频繁的线索产生的口碑传播少于每日的 | 优先考虑触发频率而不是强度 |

## 快速诊断

| 问题 | 如果没有... | 行动 |
|----------|----------|--------|
| 分享这个是否让人们看起来很棒？ | 没有社交货币 | 添加非凡性、排他性或成就 |
| 是否有日常线索回忆它？ | 没有触发因素 | 与频繁的环境或习惯联系 |
| 它是否激发高唤醒感？ | 低激活 | 为敬畏、兴奋、幽默或正当愤怒重新框架 |
| 是否能看到他人使用它？ | 不可见的使用 | 添加可见信号或品牌输出 |
| 它是否足够有用以至于可以转发？ | 低实用价值 | 包装为技巧、清单或工具，人们会转发给朋友 |
| 品牌是否嵌入在可复述的故事中？ | 没有叙事载体 | 创建一个需要你品牌的特洛伊木马故事 |
