# 冷启动问题

一个用于启动和扩展由网络效应决定的产品（如市场、社交应用、消息和协作工具）的框架——源自Andrew Chen的《冷启动问题》。使用它来推出在用户出现之前毫无价值的产品，按网络顺序进行增长，并导航五个阶段：冷启动、临界点、逃逸速度、触及天花板和护城河。

## 核心原则

**网络效应最初是负债，而非资产。** 价值存在于用户之间的连接中，而在第一天并没有任何连接——正是这种力量使得密集网络不可阻挡，也使得空网络毫无用处。你不会通过向市场推出产品来摆脱困境；你通过一次构建一个微小的、完整的、自我维持的网络来摆脱困境，首先解决其困难面，然后使用可重复的剧本对相邻网络进行倾斜，直到市场跟随。

## 评分

**目标：10/10。** 根据以下原则对网络化产品的启动计划和增长策略进行0-10评分。报告当前分数以及达到10/10所需的特定更改。

- **9-10：** 命名原子网络，具有可测量的魔法时刻，首先解决困难面，可重复的倾斜剧本，密度/流动性指标，明确的天花板和护城河计划
- **7-8：** 清晰的原子网络和困难面关注，但倾斜策略是临时的或指标仍然跟踪总数而非密度
- **5-6：** 承认网络效应，但启动目标是一个广泛的市场，并且双方都同等对待
- **3-4：** 通用用户获取计划；网络思维仅限于“添加邀请并希望它传播”
- **0-2：** 一次性向所有人推出，虚荣心注册，没有困难面策略，没有流动性措施

## 框架

### 1. 网络效应基础

**核心概念：** 网络化产品将人与人连接起来——买家与卖家、创作者与受众、同事与同事——随着合适的人加入而变得更有价值。网络效应有三种不同的形式：获取效应（网络吸引自己的新用户）、参与效应（更多用户使每次会话更有价值）和经济效应（密度提高盈利能力和单位经济）。产品可以在一个方面很强，在另一方面很弱。

**为什么有效：** 将“网络效应”视为一个单一的法力属性隐藏了增长实际上来自和在哪里破裂。梅特卡夫定律（价值随n²增长）是一种过度简化——它计算节点，而不是活跃的相关连接，一百万个分散的用户可能比五千个在一个密集社区中的用户价值更低。每个大型网络实际上都是一个网络中的网络：Uber是数百个城市级市场，Slack是数百万个团队级网络。每个子网络的密度和质量胜过原始用户数量。

**关键洞察：**
- 三个效应是解耦的：病毒式获取可以掩盖死板的参与——下载量上升，房间空无一人
- 梅特卡夫计算节点；价值存在于活跃的连接中——衡量密度，而不是总数
- 反网络效应是真实的：在密集网络中复合增长的动态在稀疏网络中复合空虚
- 网络，而不是功能集，是护城河——竞争对手可以复制产品，但不能复制上面的人
- 总体指标是谎言；将每个指标按子网络（城市、团队、类别）细分，以看到真实的健康状况

**应用：**

| 上下文 | 应用 | 示例 |
|---------|-------------|---------|
| 指标设计 | 用密度指标替换总数 | 跟踪每周活跃网络，而不是注册用户 |
| 增长诊断 | 分别归因于三个效应的增长 | 病毒因素与会话频率与转化，每个网络一个 |
| 策略审查 | 将产品视为一个网络中的网络 | 市场是一个城市-类别对的网络 |

有关三个端到端的工作场景——一个B2B工具找到其原子网络、一个服务市场播种一个城市、一个社交应用从大爆炸式启动中恢复——当您想使用完整示例来建模计划时，请参阅[references/case-studies.md](references/case-studies.md)。

### 2. 冷启动：原子网络

**核心概念：** 原子网络是最小的稳定和自我维持的网络——足够多的合适的人，产品可以提供其核心价值，群体可以自行保持。Slack需要大约一个团队内的三个用户，Zoom需要两个，一个市场可能需要一个邮政编码或类别。选择一个网络，而不是市场，并为这个微小群体构建杀手级产品——即使它看起来不可扩展。

**为什么有效：** 网络一次一个网络地成功或失败。一个完全适用于一个社区中五十个人的产品证明了循环，并且可以复制；一个对分散的五十万人只有一半适用的产品证明不了什么，并且死于空虚。微小的完整网络还暴露了魔法时刻——显示网络运行的经验（车到达，队友回复）——这成为每个后续网络的激活条。

**关键洞察：**
- 小的是更好的：找到产品起作用的最小尺寸，然后为确切这个群体过度提供
- 严格限制第一个网络——一家公司、一个校园、一个社区、一个收藏家利基——以便以创始人级别的努力实现密度
- 精确定义魔法时刻并对其进行测量；以网络达到它为所有扩张设置障碍
- 为微小网络设计的杀手级产品看起来像玩具（Facebook在哈佛，eBay的收藏品）——利基外观是密度的代价
- 为空的一侧进行Flintstone：创始人手动提供内容、库存或匹配，直到网络独自站立

**应用：**

| 上下文 | 应用 | 示例 |
|---------|-------------|---------|
| 启动范围 | 选择一个网络，而不是市场 | “奥斯汀一家经纪公司的代理人”，而不是“美国住房市场” |
| 激活 | 定义并测量魔法时刻 | 新成员在几分钟内发布并得到一个队友回复 |
| 空的一侧 | 手动为缺失的供应进行Flintstone | 创始人亲自履行前100个市场订单 |

**道德边界：** Flintstone意味着在幕后做真正的工作——永远不要编造虚假用户、评论或活动，欺骗网络上的用户。

有关[references/atomic-networks.md](references/atomic-networks.md)的详细信息，请参阅在范围第一个启动时——它有5步最小尺寸推导、演员/动作/响应/时间魔法时刻模板、测量和零率步骤、诚实Flintstone规则、单人备用方案和启动清单。

### 3. 解决困难面

**核心概念：** 每个网络都有一个困难面——一小部分人做了不成比例的工作，并且很难吸引和留住：卖家、创作者、司机、主机、组织者。他们有更好的替代方案和更高的期望，如果没有他们，容易面会发现一个空产品。了解他们的动机——金钱、地位、效用——并首先为它们构建产品和经济。

**为什么有效：** 容易面在困难面提供价值后才出现，而不是之前。没有创作者的内容应用、没有供应的市场、没有组织者设置协作工具——所有这些都是空房间。“为了工具而来，为了网络而留”是经典的困难面楔子：一个单人工具（Instagram的滤镜、OpenTable的预订簿）一次一个地招募困难面，在存在任何网络之前，然后网络使离开变得不可想象。

**关键洞察：**
- 通过工作而不是金钱支付来识别困难面：少数百分之一的用户在维基百科、YouTube和大多数市场创造了大部分价值
- 明确映射动机：金钱（司机、卖家）、地位（创作者、顶级评论家）、效用（需要工具的组织者）——每个都要求不同的产品投资
- 首先为困难面构建专业的工作流程和经济；容易面主要需要一个干净的消费者体验
- 早期为稀缺面提供补贴——保证、奖金、零费用——并公布淡出计划，以便信任在撤回后仍然存在
- 早期的困难面人员会快速专业化：计划第三个月的工具、分析和付款改进，而不是第三年

**应用：**

| 上下文 | 应用 | 示例 |
|---------|-------------|---------|
| 市场播种 | 在需求之前招募和补贴供应 | 在启动前八周保证更干净的收入 |
| 社交或内容应用 | 用地位和影响力取悦创作者 | 早期粉丝优势、推荐、创作者资金 |
| B2B协作 | 给组织者单人价值 | 单独使用的项目跟踪器；邀请团队使其更好 |

**道德边界：** 困难面经济必须诚实——将启动补贴作为临时激励，并且永远不要在计划悄悄降低条款的基础上建立人们的生活。

有关[references/hard-side.md](references/hard-side.md)的详细信息，请参阅在设计和供应面获取和经济学时——它将金钱/地位/效用动机映射到产品投资，并详细说明三种命名的剧本（工具优先、内容优先、补贴）。

### 4. 临界点和逃逸速度

**核心概念：** 一旦第一个原子网络运行起来，增长就变成了一个可重复的剧本，用于倾斜下一个网络，然后是下一个——每个启动比上一个更便宜。核心倾斜工具：邀请制机制（策展+稀缺性+社会证明）、为启动付费（补贴、保证、预先承诺的供应）、影响者或社区播种。倾斜后，逃逸速度不是一个里程碑，而是一个运营模式：持续放大获取、参与和经济效应。

**为什么有效：** 邀请制启动看起来排他性，但设计上构建了密度——每个邀请者至少有一个已经在里面，网络沿着真实的社会图谱复制，稀缺性制造了社会证明，这会吸引下一个队列。付费将金钱转化为密度，这是竞争对手无法复制的资产。大爆炸式启动则相反：Google+将数亿注册用户推入空房间，薄弱的网络从未保留。

**关键洞察：**
- 邀请制同时做三件事：策展早期文化，创造稀缺性炒作，导入每个用户的社交图谱
- 补贴是网络CAC：花费制造流动性，衡量每个活跃网络的成本，按公布的计划淡出
- 大爆炸式启动是典型的反模式——快速填充，薄弱网络；压力峰值落在空虚上，并且永远不会回来
- 倾斜后，将三个力量作为命名的工件运行：获取（病毒循环、推荐），参与（强化循环、再参与），经济（转化、补贴撤回、定价）
- 每个倾斜的网络都会降低下一个的成本：溢出意识、可移植剧本、可重复使用的供应关系

**应用：**

| 上下文 | 应用 | 示例 |
|---------|-------------|---------|
| 消费者启动 | 邀请制加上推荐树 | 等待名单加上每个活跃用户五个邀请；跟踪邀请图密度 |
| 市场城市#2 | 付费制造流动性 | 九十天的司机收入保证，随着填充率上升而淡出 |
| 倾斜后增长 | 将三个力量作为工件运行 | 推荐循环，消化再参与，转化率优化 |

**道德边界：** 稀缺性和排他性必须是真实的——假的等待名单和制造的“有限名额”是欺骗，不是策略。

有关[references/tipping-playbooks.md](references/tipping-playbooks.md)的详细信息，请参阅计划网络#2及以后——邀请制和推荐树机制、付费启动和供应预先承诺策略、市场选择、反模式、以及用于门控的流动性指标。

### 5. 天花板和护城河

**核心概念：** 增长总是停滞。火箭船曲线是一系列S曲线，并且每个曲线都会遇到天花板：市场饱和、渠道退化（CAC爬升、横幅盲点、病毒疲劳）、困难面起义、规模质量崩溃——垃圾邮件、过度拥挤、情境崩溃。护城河本身就是网络：保护困难面，预期竞争对手会挑选你最密集的细分市场，并记住捆绑填充容易面但很少赢得困难面。

**为什么有效：** 每个获取渠道随着受众习惯并竞争对手涌入而衰减——第一个横幅广告以两位数的速率被点击；今天的平均数只是百分之几。网络也从内部退化：规模吸引垃圾邮件并崩溃了早期网络创造亲密情境的价值，因此质量工作变成了增长工作。而且网络之间的竞争是不对称的：挑战者通过将原子网络纪律应用于一个未被满足的利基来获胜——这正是挑战者如何解包现有产品的方式。

**关键洞察：**
- 将增长绘制为堆叠的S曲线；在当前曲线变平之前开始下一个曲线（地理、细分市场、用例、产品）
- CAC爬升和病毒疲劳是法律，不是失败——在当前渠道仍然起作用时计划下一个渠道
- 观察困难面起义信号：转化率投诉、多归属、有组织的抗议——困难面首先离开并带走网络
- 质量干预措施——策展、排名、验证、垃圾邮件防治、子分组——是规模增长投资，而不是成本中心
- 通过过度服务你的最密集细分市场来防御挑选；这正是大卫攻击巨人之处
- 捆绑购买分销，而不是忠诚度——它填充容易面的座位，而深度参与仍然属于持有困难面的人

**应用：**

| 上下文 | 应用 | 示例 |
|---------|-------------|---------|
| 停滞增长 | 诊断第一个天花板何时被击中 | 按网络分离饱和、CAC爬升和品质衰减流失 |
| 规模质量 | 为信任和策展循环提供资金 | 评分、验证级别、垃圾邮件过滤器作为增长工件 |
| 竞争防御 | 防御困难面免受竞争对手侵害 | 在竞争对手为顶级卖家提供补贴之前匹配多归属 |

**道德边界：** 修复起义和垃圾邮件意味着为用户提供根本原因——不要用公关来压制合法的困难面不满。

有关[references/scale-ceiling-moat.md](references/scale-ceiling-moat.md)的详细信息，请参阅增长停滞或出现竞争对手时——它将三个力量作为增长工件运行，诊断第一个天花板何时被击中，并详细说明规模质量干预措施和门控的挑选防御。

## 常见错误

| 错误 | 为什么失败 | 修复 |
|---------|-------------|-----|
| 向市场而不是网络推出 | 用户到达分散；没有人找到任何人 | 选择一个原子网络并饱和它 |
| 计算注册用户而不是密度 | 虚荣总数掩盖空房间 | 衡量每周活跃网络，填充率，匹配时间 |
| 同等对待双方 | 困难面是瓶颈和飞行风险 | 首先为困难面构建产品和经济学 |
| 大爆炸式启动 | 快速填充，薄弱网络；炒作落在空虚上 | 逐个网络倾斜，使用可重复的剧本 |
| 假造稀缺性或活动 | 用户发现欺骗；信任崩溃 | 用真实工作Flintstone；保持邀请稀缺性真实 |
| 在#1稳定之前克隆网络#2 | 复制一个损坏的循环会放大失败 | 以魔法时刻和保留条为门控扩张 |
| 假设网络效应永远增强 | 垃圾邮件、过度拥挤和情境崩溃复合太多 | 为质量、信任和策展提供资金作为增长工件 |
| 忽略挑选竞争对手 | 利基玩家剥离开你最密集的细分市场 | 过度服务密集利基；防御困难面经济学 |

## 快速诊断

| 问题 | 如果没有 | 行动 |
|----------|-------|--------|
| 你能命名你的第一个原子网络（谁，在哪里，有多少人）吗？ | 你正在向市场推出，而不是向网络 | 通过地理、组织或兴趣进行约束，直到自我维持 |
| 魔法时刻是否已定义和测量？ | 你无法区分活网络和死网络 | 定义它，按网络测量它，以它为门控扩张 |
| 你知道你的困难面是谁以及他们为什么留下吗？ | 供应流失，并且容易面跟随它出去 | 映射金钱/地位/效用动机；首先为它们构建 |
| 产品是否为其第一个用户传递价值？ | 纯粹的鸡和蛋，没有楔子 | 添加为工具而来的价值或Flintstone差距 |
| 是否有一个关于倾斜下一个网络的书面剧本？ | 每个启动都是昂贵的单次赌注 | 从启动#1编码邀请、补贴和播种 |
| 你是否在测量流动性（填充率、匹配时间）？ | 增长光学隐藏网络健康状况 | 向核心仪表板添加按网络密度的指标 |
| 你知道第一个天花板何时会击中吗？ | 停滞将作为谜团到来 | 现在建模饱和、CAC爬升和品质衰减 |
| 是否有任何东西在防御困难面免受竞争对手侵害？ | 挑选者将剥离开你的最佳细分市场 | 深化困难面经济学和专业人士工具 |
