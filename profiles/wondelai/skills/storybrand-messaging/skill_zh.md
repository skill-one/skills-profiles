# StoryBrand 沟通框架

让您的信息清晰易懂，让客户愿意倾听。客户购买的并非最好的产品，而是他们最快能理解的产品。

## 核心原则

**客户是英雄，而非您的品牌。**您的品牌是帮助英雄获胜的向导。将自己定位为英雄，您就会与客户竞争；将自己定位为向导，您就会为他们服务。

## 评分

**目标：10/10。**通过快速诊断对任何营销文案或品牌信息进行评分：每满足一行得1分（共7行），加上通过鸡尾酒会测试的一句口号最多得3分（清晰且一次就能记住）。评分标准：9-10分 = 客户是英雄，所有三个问题层级都被提及，同时展现了同理心和权威，有一个三步计划，一个明显的直接行动号召，并描绘了成功与失败的风险；5-6分 = 部分应用SB7框架，但内部问题、风险或行动号召缺失；<=3分 = 品牌自居为英雄、以功能为导向或没有明确的诉求。始终说明当前分数以及达到10/10所需的特定改进措施。

## SB7 框架

每个引人入胜的故事都遵循相同的模式。使用此结构进行所有信息传递：

### 1. 一个角色（英雄）

**核心概念：**客户是英雄，而您的任务是定义他们想要的一件事。具体说明这个单一愿望。

**为什么有效：**命名一个愿望会打开故事缺口——客户所在位置与期望位置之间的距离。这种张力会吸引他们，因为他们感到被理解并希望填补这个缺口。

**关键洞察：**
- 每个信息传递专注于一个愿望——多个愿望会稀释故事缺口
- 将愿望与生存（身体、财务、关系或精神）联系起来
- 理想身份具有强大的力量（“成为每个人尊敬的领导者”）
- 不同细分市场有不同的愿望——根据角色、阶段和痛苦强度分别撰写信息传递

**产品应用：**

| 上下文 | 应用 | 示例 |
|--------|------|------|
| 首页标题 | 将愿望作为结果 | “您想要一个美丽的笑容”（而非“我们的牙科很出色”） |
| 登录页面 | 每页一个愿望 | “您想要提前退休” |
| 细分市场 | 每个细分市场定制愿望 | CEO：“无混乱地扩展” vs. IC：“无摩擦地完成最佳工作” |

**文案模式：**
- “您想要[具体愿望]..."
- “想象[理想身份]..."
- “如果您能[单一明确结果]..."

参见：[参考资料/品牌脚本.md](参考资料/品牌脚本.md) —— 当您需要从零开始为客户草拟所有七个元素时，在此填写品牌脚本工作表。

### 2. 遇到一个问题

**核心概念：**在三个层级上定义问题——外部（具体的）、内部（情感的）、哲学（不公正的）——并用一个具体的反派来拟人化它。

**为什么有效：**公司销售针对外部问题的解决方案，但客户购买针对内部问题的解决方案。命名问题如何让他们感觉——困惑、不知所措、尴尬——会触动购买背后的情感驱动因素。

**关键洞察：**
- 外部：“我的投资分散”；内部：“我感觉不知所措”；哲学：“人们不应该需要成为专家才能顺利退休”
- 一个好的反派是具体且 relatable 的，而非抽象的——“为让您困惑而设计的华尔街术语”，而非“复杂性”
- 大多数品牌停留在外部问题，忽略了驱动购买的内部问题

**产品应用：**

| 上下文 | 应用 | 示例 |
|--------|------|------|
| 网站问题部分 | 提及所有三个层级 | 外部：“分散的工具。” 内部：“您感到不知所措。” 哲学：“团队值得清晰。” |
| 电子邮件培育 | 以内部问题开头 | “厌倦了感觉像在猜测？” |
| 广告文案 | 拟人化反派 | “停止让令人困惑的软件偷走您的夜晚。” |

**文案模式：**
- “您厌倦了[内部问题]..."
- “[反派]一直在阻止您[愿望]..."
- “不公正的是[哲学问题]..."

### 3. 遇到一位向导

**核心概念：**您的品牌是向导，表达同理心和权威。同理心表明您理解痛苦；权威证明您能解决问题。

**为什么有效：**客户寻找的是向导，而非另一个英雄——想想尤达，而不是卢克。同理心让他们感到被看见，权威（客户评价、公司标志、统计数据、奖项）让他们感到安全，两者结合创造了信任。

**关键洞察：**
- 用“我们理解”语言表达同理心；用客户评价、公司标志、统计数据、奖项展示权威
- 不要让您的起源故事成为焦点——那是英雄行为；简短、相关的资质就足够了

**产品应用：**

| 上下文 | 应用 | 示例 |
|--------|------|------|
| 关于页面 | 先表达同理心，再展示资质 | “我们知道在财务术语中感到迷失是什么样子。这就是为什么10,000个家庭信任我们。” |
| 首页社会证明 | 同理心标题+权威标志 | “您并不孤单。加入5,000多个找到清晰感的团队。” + 客户标志 |
| 销售电话 | 以同理心开头，以权威结尾 | “我理解——那听起来很令人沮丧。以下是为像您这样的团队有效的方法。” |

**文案模式：**
- “我们理解[同理心陈述]是什么样子..."
- “我们已帮助[数量]个[客户]实现[结果]..."
- “您不必独自解决这个问题..."

参见：[参考资料/销售对话.md](参考资料/销售对话.md) —— 在编写销售电话或发现会议脚本时打开；涵盖发现问题、处理异议和完整的SB7销售脚本。

### 4. 给他们一个计划

**核心概念：**提供两个计划：流程计划（3-4步展示如何与您合作）和协议计划（消除风险的承诺）。

**为什么有效：**清晰的计划就像过溪的踏脚石——它减少了认知负荷和感知风险。没有计划，路径会显得模糊，客户会犹豫不决。

**关键洞察：**
- 流程计划：最多3-4个编号步骤，动词，易记名称（“1. 安排通话。2. 获取定制计划。3. 30天内看到结果。”）
- 协议计划：消除恐惧的承诺（“保证100%满意”，“随时取消”）
- 超过4个步骤会让人不知所措；编号暗示顺序和轻松

**产品应用：**

| 上下文 | 应用 | 示例 |
|--------|------|------|
| 网站计划部分 | 带图标的3步流程 | “1. 预约演示。2. 上线。3. 30天内看到结果。” |
| 定价页面 | 协议计划减少焦虑 | “无合同。随时取消。30天退款保证。” |
| 电子邮件行动号召 | 引用计划 | “开始很简单——只需三个步骤。” |

**文案模式：**
- “这是如何运作的：步骤1... 步骤2... 步骤3..."
- “开始很简单。只需[步骤1]。”
- “我们承诺[协议计划承诺]。”

### 5. 并号召行动

**核心概念：**如果您不要求，他们就不会行动。使用直接行动号召（主要转化行动）和过渡行动号召（较低承诺的替代方案）。

**为什么有效：**客户只有在被要求行动时才会行动。过渡行动号召让尚未准备好的客户留在您的故事中，直到他们准备好。

**关键洞察：**
- 直接：“立即购买”，“安排通话”，“开始使用”；过渡：“下载免费指南”，“观看演示”，“参加测验”
- 将直接行动号召设计为视觉上突出的按钮（对比色），并在页面下方重复
- 使用行动语言（“获取”而非“提交”）；每页一个明显的直接行动号召

**产品应用：**

| 上下文 | 应用 | 示例 |
|--------|------|------|
| 首页 | 展位上方直接行动号召，重复 | “免费开始”在页眉和每个部分下方 |
| 博客文章 | 文章末尾过渡行动号召 | “下载我们的免费清单” |
| 电子邮件 | 每条信息一个直接行动号召 | 一个“安排您的通话”按钮 |

**文案模式：**
- “现在获取[期望结果]。”
- “今天开始您的免费[试用/演示/评估]。”
- “下载您的免费[引流磁石]。”

**道德边界：**永远不要将付费行动标记为“免费”或过渡行动号召——按钮文本必须与点击后的结果一致。

参见：[参考资料/网站线框图.md](参考资料/网站线框图.md) —— 在布局首页或网站时打开；提供按部分划分的结构和内部页面模板。

### 6. 帮助他们避免失败

**核心概念：**展示如果客户不行动会发生什么。没有风险，就没有故事。

**为什么有效：**人类有损失厌恶——对失去的恐惧比获得承诺更能激励。对可能发生的事情的尝试会促使客户从“感兴趣”转变为“承诺”。

**关键洞察：**
- 尝试后果就足够了——不要进行恐慌宣传
- 关注机会成本，而非惩罚（“又一年感到停滞”）
- 将失败与成功信息对比，创造对比效果

**产品应用：**

| 上下文 | 应用 | 示例 |
|--------|------|------|
| 登录页面风险部分 | 行动号召前的简要失败场景 | “没有清晰的信息，您将不断输给理解速度更快的竞争对手。” |
| 电子邮件主题行 | 轻微紧迫性 | “您是否在让收入落空？” |
| 销售对话 | 提及不采取行动的成本 | “如果6个月内没有改变，您的团队会发生什么？” |

**文案模式：**
- “不要让[负面结果]发生，当[解决方案]如此简单时。”
- “在[解决问题]之前，您会等待多久？”
- “没有[解决方案]的每一天，您都在[不采取行动的成本]。”

### 7. 并以成功结束

**核心概念：**描绘与您合作后的生活画面——在地位、完整性和自我实现方面。成功关闭了在元素1中打开的故事缺口。

**为什么有效：**人们需要看到目的地才能开始旅程。展示转变——而非功能——让客户将自己置于未来，并感受到其吸引力。

**关键洞察：**
- 地位：“成为公认的专家”；完整性：“终于有财务上的安心”；自我实现：“成为您注定要成为的领导者”
- 用前后对比和具体数字展示转变
- 保持成功画面具体，绝不模糊或泛泛而谈

**产品应用：**

| 上下文 | 应用 | 示例 |
|--------|------|------|
| 首页成功部分 | 具体的成功画面 | “想象每天打开收件箱都有潜在客户——无需冷启动。” |
| 案例研究 | 前后对比带数字 | “之前：2%转化率。之后：90天内11%。” |
| 客户评价 | 客户描述他们的成功 | “我终于知道每一分钱都花在哪里了。” |

**文案模式：**
- “想象[具体成功画面]..."
- “加入[数量]个[客户]，现在[成功结果]..."
- “终于，[完整性结果]——没有[旧烦恼]。”

## 一句话

一句话解释您做什么。在所有地方使用它。

**公式：**[问题] + [解决方案] + [结果]

**结构：**“我们帮助[角色]解决[问题]的[解决方案]，以便他们能够[结果]。”

**示例：**“我们帮助感到被营销压垮的小企业主创建清晰的信息，以便他们能够增加收入。”

**测试：**有人能听完后一次重复吗？（鸡尾酒会测试）

参见：[参考资料/一句话.md](参考资料/一句话.md) —— 在起草一句话时打开；约20个行业示例加上三种替代公式（PSR、BAB、“我们存在的原因”）。

## 语调和声音指南

在各个渠道保持品牌声音一致，同时根据上下文进行调整。

**传达向导品质：**同理心（“我们理解...”）、权威（“在我们的经验中...”）、自信（“这是有效的方法...”）、乐于助人（“让我们向您展示...”）。

**避免：**英雄语言（“我们是最好的...”）、术语（使用客户的语言）、居高临下和犹豫不决的弱点。

参见：[参考资料/电子邮件序列.md](参考资料/电子邮件序列.md) —— 在构建培育或欢迎序列时打开；SB7映射模板和主题行公式。
参见：[参考资料/多渠道一致性.md](参考资料/多渠道一致性.md) —— 在将信息传递调整到渠道时打开；社交、视频、播客和公关手册。

## 常见错误

| 错误 | 为什么失败 | 修复 |
|------|----------|------|
| 自居为英雄 | 与客户竞争 | 定位为向导 |
| 多个信息传递 | 让人困惑 | 每个资产一个清晰的信息 |
| 聪明 > 清晰 | 人们不会解码信息传递 | 总是选择清晰 |
| 功能导向 | 客户购买转变 | 以结果为导向 |
| 没有明确的行动号召 | 没有方向 = 没有行动 | 要求销售 |
| 没有风险 | 没有紧迫性 = 没有动力 | 描绘失败画面 |
| 以“我们”开头 | 以自我为中心 | 从客户的问题开始 |

## 快速诊断

| 问题 | 如果不 | 行动 |
|------|-------|------|
| 一个穴居人能在5秒内理解提议吗？ | 信息太复杂 | 简化为一个愿望，一个结果 |
| 客户是否明显是英雄？ | 品牌与客户竞争 | 从客户的角度重写 |
| 是否命名了内部问题，而不仅仅是外部问题？ | 错过了情感驱动因素 | 添加“感觉如何”语言 |
| 您是否展现同理心和权威？ | 信任差距 | 添加“我们理解”+ 证明点 |
| 是否有一个清晰的3步计划？ | 路径感觉有风险 | 添加流程+协议计划 |
| 是否有一个明显的行动号召？ | 没人行动 | 添加突出、重复的直接行动号召 |
| 您是否展示成功和失败的风险？ | 没有叙事张力 | 描绘两个结果画面 |
