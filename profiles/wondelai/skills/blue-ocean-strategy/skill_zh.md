# 蓝海战略框架

创造不受竞争影响的非竞争性市场空间的战略框架，基于差异化与低成本的同时追求。

## 核心原则

**不在血腥的红色海洋中竞争。创造非竞争性市场空间的蓝海。** 大多数公司在现有行业中争夺份额；赢家通过为买方和自身提供价值飞跃，在新的市场空间中创造竞争无关性。基于竞争的策略是零和博弈——价值创新创造新需求并打破价值-成本权衡。

## 评分

**目标：10/10。** 根据该战略满足五个快速诊断行数的多少，映射到以下等级：

- **9-10** — 分散化的战略画布曲线，消除并创造因素，打破价值-成本权衡，将非客户转化为客户，并实现10倍效用飞跃（全部5行）。
- **7-8** — 价值创新是真实的，但有一个门槛较弱（例如，强烈的分散化和成本削减，但仍在追逐现有客户而非非客户）。
- **5-6** — 无成本削减的差异化，或无价值飞跃的成本削减：在相同因素上优于竞争对手，尚未实现价值创新（2-3行）。
- **<=3** — 与竞争对手在相同因素上竞争，具有类似画布曲线：红色海洋（0-1行）。

报告当前分数，哪些诊断行未通过，以及达到10/10所需的特定ERRC/六路径行动。

## 框架

### 1. 红海与蓝海

**核心概念：** 红海是竞争对手争夺萎缩利润的现有市场空间；蓝海是竞争无关性的新市场空间。

| 红海战略 | 蓝海战略 |
|--------|--------|
| 在现有市场空间中竞争 | 创造非竞争性市场空间 |
| 击败竞争对手 | 使竞争无关 |
| 开发现有需求 | 创造和捕获新需求 |
| 实现价值-成本权衡 | 打破价值-成本权衡 |
| 与差异化或低成本保持一致 | 追求差异化与低成本 |

**例子：** 在航线、便利设施和价格上竞争的航空公司是红海；Cirque du Soleil发明了新的娱乐形式，Netflix用流媒体取代租赁，任天堂Wii用易于操作的体感游戏交换图形性能是蓝海。

当你想要一个完整的案例来模拟移动时，请参阅[references/blue-ocean-examples.md](references/blue-ocean-examples.md)——Cirque du Soleil、Netflix、Yellow Tail和任天堂Wii按因素分解。

### 2. 价值创新

**核心概念：** 蓝海战略的基石——同时追求差异化与低成本，为买方和公司创造价值飞跃。消除和减少过度服务的因素同时削减成本，同时提高和创造因素提升买方价值，因此价值增长速度快于成本增长，竞争对手假设的固定权衡被打破。

| 传统观点 | 价值创新观点 |
|------|------|
| 高价值 = 高成本 | 高价值可以 = 低成本 |
| 差异化或削减成本 | 差异化与削减成本 |
| 在既定因素上表现更好 | 新因素；消除旧因素 |

**例子——Cirque du Soleil：** 消除了动物表演、明星表演者、多个场馆（成本降低）；减少了刺激和幽默；提高了场馆质量、艺术音乐和舞蹈；创造了主题、优化环境、多个演出。结果：价格高于马戏团，成本低于剧院，一个新市场。

当你测试一个想法是否是真实的价值创新时，请参阅[references/value-innovation.md](references/value-innovation.md)——包含所有三个术语的效用x价格x成本公式以及每个测试问题的测试问题。

### 3. 战略画布

**核心概念：** 诊断工具——绘制行业竞争的因素与你的产品水平和竞争对手的提供水平。红海显示每个人的曲线看起来都一样；分散化的曲线预示着蓝海。

**如何使用：**
1. 列出行业的竞争因素（葡萄酒：价格、声望、陈酿质量、葡萄园传统、复杂性、范围、营销）
2. 绘制你的曲线和竞争对手的——在红海中预期曲线几乎相同
3. 询问：买方实际上并不在乎哪些因素？什么可以被消除、减少、提高或创造？买方体验在哪里受到伤害？

**例子——Yellow Tail葡萄酒：**

| 因素 | 行业平均水平 | Yellow Tail |
|----|----------|----------|
| 价格、声望、陈酿质量 | 中高 | 低 |
| 葡萄园传统、复杂性、范围 | 高 | 低 |
| 易于饮用 | 低 | 高 |
| 乐趣/冒险、可及性 | 低 | 高 |

**结果：** 不同的曲线 = 蓝海。

当你绘制自己的画布时，请参阅[references/strategy-canvas.md](references/strategy-canvas.md)——空白模板和逐步构建说明。

### 4. 四种行动框架（ERRC网格）

**核心概念：** 四个问题重构买方价值——消除和减少削减成本；提高和创造提升价值。

| 行动 | 问题 | 例子 | 效果 |
|----|----|----|----|
| **消除** | 哪些理所当然的因素对买方没有价值？ | Cirque：动物、明星；Southwest：餐食、座位分配；IKEA：销售人员、组装 | 成本降低；摩擦消除 |
| **减少** | 什么可以远低于行业标准？ | Yellow Tail：声望、复杂性；Salesforce v1：定制 | 成本降低；过度服务停止 |
| **提高** | 什么应该远高于行业标准？ | Cirque：艺术价值；Dyson：吸力、设计；Apple：用户体验 | 价值提升；难以匹敌 |
| **创造** | 行业从未提供过什么？ | Netflix：无限流媒体、无滞纳金；Uber：实时跟踪、无现金支付 | 新需求；吸引非客户 |

**道德边界：** 不要消除买方真正重视的因素（尤其是安全或可及性）——在削减之前测试假设。

当你与团队进行练习时，请参阅[references/errc-grid.md](references/errc-grid.md)——3.5小时工作坊格式、验证清单和用于Zoom、IKEA、MinuteClinic和Khan Academy的新ERRC矩阵。

### 5. 六路径框架

**核心概念：** 六种系统方法，超越现有行业边界，发现蓝海机会。

| 路径 | 跨越 | 例子 | 如何应用 |
|----|----|----|----|
| **1. 替代行业** | 解决相同需求的替代形式 | NetJets：航空公司的替代品和私人喷气机拥有 | 绘制替代品 → 在它们之间发现未满足的需求 |
| **2. 战略群体** | 追求相似策略的集群 | Lexus：可负担的奢侈品 | 发现过度/未满足的需求 → 在群体之间定位 |
| **3. 买方链条** | 购买者与使用者与影响者 | Novo Nordisk胰岛素笔：将焦点从医生转移到患者；Bloomberg：交易员而非IT购买者 | 确定链条中的每个买方 → 服务被忽视的买方 |
| **4. 互补产品** | 使用前、使用中、使用后的情况 | 婴儿看护补充电影 → “约会之夜”套餐 | 绘制完整体验 → 套装痛点 |
| **5. 功能 ↔ 情感诉求** | 翻转行业的吸引力基础 | Swatch：手表作为时尚；The Body Shop：化妆品作为道德 | 确定当前吸引力 → 建立混合体 |
| **6. 时间** | 不可逆转的趋势 | iPod/iTunes预测数字音乐；Tesla在电动汽车上 | 预测趋势的终点 → 今天为此做准备 |

当你按路径逐个寻找机会时，请参阅[references/six-paths.md](references/six-paths.md)——每个六种路径的提示问题和 worked example。

### 6. 非客户的三级

**核心概念：** 蓝海是由转化非客户创造的，而不是通过窃取竞争对手的客户——非客户揭示了行业留下的未满足的需求。

| 级别 | 他们是谁 | 机会 | 例子 |
|----|----|----|----|
| **1. 即将到来** | 市场的边缘，最低限度使用，准备跳船 | 小变化赢得他们 | Pret A Manger：希望快速且健康的职业人士 |
| **2. 拒绝** | 考虑过行业并故意拒绝它 | 移除拒绝背后的障碍 | JCDecaux：城市拒绝户外广告，直到公交车站免费 |
| **3. 未探索** | 从未考虑过你是一个选项的遥远市场 | 为他们的需求重新定义产品 | Callaway Big Bertha：初学者和偶尔的高尔夫球手 |

**过程：** 绘制所有三个级别 → 在级别之间找到共同点 → 确定什么将解锁巨大需求 → 建立产品以转化他们。

当你衡量潜在需求时，请参阅[references/non-customers.md](references/non-customers.md)——如何绘制三个级别中的每一个，以及找到解锁它们的共同点。

### 7. 战略顺序：效用 → 价格 → 成本 → 采用

**核心概念：** 严格按顺序验证蓝海想法——首先提供卓越的买方效用，然后是可负担的价格，然后是盈利成本，然后是采用障碍。任何关卡失败都意味着在继续之前需要重新工作。

| 步骤 | 问题 | 如何 |
|----|----|----|
| **1. 买方效用** | 是否有卓越的效用？ | 检查六个杠杆（生产力、简单性、便利性、风险降低、乐趣/形象、环境友好性）在买方体验周期（购买 → 交付 → 使用 → 补充 → 维护 → 废弃）；解决最大的障碍 |
| **2. 战略价格** | 对大多数买方是否可负担？ | 与其他形式中的替代品相比价，而不是你的成本或直接竞争对手——Cirque定价高于马戏团，低于剧院 |
| **3. 目标成本** | 我们能否在那种价格下盈利？ | 战略价格 − 目标利润 = 目标成本；通过ERRC和合作实现它——永远不会牺牲效用，永远不会“以后” |
| **4. 采用** | 谁会抵制——员工、合作伙伴、公众、监管机构？ | 事先发现障碍：教育利益相关者，运行试点，早期参与合作伙伴 |

**道德边界：** 通过真正解决利益相关者的担忧来赢得采用，而不是通过碾压承担转变成本的员工和合作伙伴。

当你按关卡逐个验证想法时，请参阅[references/sequence.md](references/sequence.md)——买方效用地图、战略定价走廊和目标成本计算表。当你从想法转向推广时，请参阅[references/implementation.md](references/implementation.md)——克服四个组织障碍并使团队支持转变。

## 常见错误

| 错误 | 为什么失败 | 修复 |
|----|----|----|
| **在相同因素上竞争** | 停留在红色海洋 | 使用ERRC消除和创造因素 |
| **差异化而无成本关注** | 不是价值创新 | 消除/减少的同时提高/创造 |
| **渐进主义** | 没有价值飞跃 | 在关键因素上瞄准10倍改进 |
| **模仿竞争对手** | 红色海洋思维 | 跨越六路径寻找替代品 |
| **忽视采用** | 伟大的想法，没有执行 | 事先计划采用障碍 |

## 快速诊断

| 问题 | 如果没有 | 行动 |
|----|----|----|
| 战略画布是否显示不同的曲线？ | 仍在红色海洋 | 应用ERRC框架 |
| 我们是否消除并创造？ | 不是价值创新 | 使用所有四种行动 |
| 我们是否打破了价值-成本权衡？ | 传统竞争 | 确定过度服务的因素以削减 |
| 我们是否转化了非客户？ | 争夺现有份额 | 绘制非客户的三级 |
| 是否有买方效用的飞跃？ | 渐进式改进 | 在关键效用杠杆上瞄准10倍 |
