# 构建组件

## 何时使用此技能

当用户需要：

- 构建新的 UI 组件（基础元素、组件、模块、模板）
- 实现无障碍功能（ARIA、键盘导航、焦点管理）
- 创建可组合组件 API（插槽、渲染属性、受控/非受控状态）
- 设置设计令牌和主题系统
- 将组件发布到 npm 或注册中心
- 编写组件文档
- 实现多态性或子元素模式
- 使用数据属性进行样式化/状态管理
