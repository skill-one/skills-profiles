# 付费广告：Meta 广告

指导 Meta (Facebook/Instagram) 广告设置、活动结构、受众定位和创意优化。Meta 擅长需求生成和视觉产品；在创建需求或创意素材强劲时使用。

**调用时机**：在 **首次使用** 时，如果有帮助，先用 1-2 句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在 **后续使用** 或用户要求跳过时，直接进入主要输出。

## 活动结构

**层级**：活动 → 广告组 → 广告（3 级）

**原则**：每个活动一个目标。为同一目标创建多个活动会分摊预算和数据，延长算法的学习阶段。按目标整合；注重清晰的结构和数据驱动的决策。

```
账户
├── 活动：潜在客户
│   ├── 广告组：1% 相似受众
│   └── 广告组：宽泛 (Advantage+)
├── 活动：再营销
└── 活动：测试
```

**命名**：`META_[目标]_[受众]_[产品]_[日期]`（例如，`META_Conv_Lookalike-Customers_FreeTrial_2024Q1`）

## Advantage+ & 自动化

| 功能 | 使用场景 |
|------|-----|
| **Advantage+ 购物活动** | 电子商务；自动受众发现 |
| **动态广告** | 产品目录；自动生成创意 |
| **自动投放位置** | 让 Meta 跨 Feeds、Stories、Reels 优化 |
| **Advantage+ 受众** | 广泛定位；算法寻找转化者 |

提供多样化的创意素材以支持多种广告格式；算法在多样性下表现更佳。

## 活动目标

| 目标 | 使用场景 |
|------|-----|
| 认知 | 覆盖范围；品牌召回 |
| 流量 | 点击网站 |
| 转化 | 领域；销售；应用安装 |
| 互动 | 视频观看；帖子互动 |

## 受众定位

| 类型 | 适合场景 |
|------|-----|
| **相似受众** | 基于高价值客户（按 LTV），而非所有客户 |
| **兴趣/行为** | 广泛；让算法优化 |
| **Advantage+** | 自动化；手动控制较少 |
| **再营销** | 网站访客；互动者；自定义受众 |

**排除**：现有客户；近期转化者（7-14 天内）。

## 创意最佳实践

- **图片**：清晰的产品；前后对比；人像；文字 &lt;20%
- **视频 (15-30 秒)**：0-3 秒吸引注意力；3-8 秒提出问题；8-20 秒提供解决方案；20-30 秒行动号召
- **投放位置**：Feeds (FB/IG)；Stories/Reels；竖屏用于 Stories
- **数量**：每个广告组 3-5 个广告变体用于测试

## 优化

- **学习阶段**：每个广告组每周 50+ 转化以退出；学习期间避免频繁变更
- **CBO vs ABO**：活动预算优化整合支出；在扩展时使用
- **频率**：&lt;3 以避免疲劳
- **创意刷新**：计划持续测试；创意疲劳是主要杠杆——当性能下降时刷新

## 追踪

- **Meta 像素** + **转化 API**：服务器端以实现更好的归因
- **事件 API**：应用事件；服务器到服务器
