# SEO 内容：竞争对手研究

提供关于SEO、内容、反向链接和定位的竞争对手研究指南。在规划内容、审核文章、建立链接或评估市场地位时使用。

**调用时机**：在**首次使用**时，如果有帮助，先以1-2句话概述此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接进入主要输出。

## 研究类型

| 类型 | 目的 | 输出 |
|------|---------|--------|
| **关键词/主题** | 竞争对手排名的主题；差距 | 关键词机会；内容创意 |
| **内容** | 结构、长度、与顶尖排名者的差距 | 长度目标；H2结构；内容差距 |
| **反向链接** | 链接配置文件；链接到竞争对手的网站 | 链接差距；拓展目标 |
| **定价** | 竞争对手定价、定位 | 定价背景；差异化 |
| **SEO指标** | 有机流量、与竞争对手的排名对比 | 基准；机会领域 |

## 竞争对手关键词/主题分析

| 方法 | 实践 |
|--------|----------|
| **逆向工程** | 分析竞争对手标题、H1、URL；识别其排名的主题 |
| **SERP重叠** | 关键词与重叠的排名页面 → 相同集群；#4–10 = 机会 |
| **site:运算符** | `site:competitor.com` 查看索引页面 |
| **工具** | Ahrefs、Semrush—竞争对手关键词重叠、差距分析 |

**输出**：关键词机会；竞争对手涵盖而您未涵盖的主题。

## 竞争对手内容分析

| 元素 | 检查 |
|---------|-------|
| **字数** | 顶部10个平均；您内容的目标长度 |
| **H2结构** | 涵盖的主题；要采用的结构 |
| **内容差距** | 顶尖排名者涵盖而您遗漏的内容 |
| **关键词布局** | 核心关键词在标题、H1、前100字中 |
| **格式** | 列表、表格、FAQ；匹配或改进 |

**使用时机**：审核或创建文章时；参见 **article-page-generator** 进行研究阶段整合。

### 竞争对手文章获取工作流（用于文章分析）

在分析或审核单篇文章时，使用此轻量级工作流获取竞争对手文章：

1. **获取URL**：来自用户、项目上下文第11节，或通过网页搜索 `"[目标关键词]"` 找到排名靠前的页面
2. **获取内容**：使用mcp_web_fetch或WebSearch获取2-3个排名靠前的页面
3. **分析**：字数、H2结构、关键词布局、内容差距、CTA、模式
4. **输出**：竞争对手URL、简要结构对比、内容差距、长度目标、关键词机会

**输出格式**：竞争对手URL；每个URL的字数和H2结构；与您文章的内容差距；推荐长度目标；关键词机会（顶尖排名者使用而您的文章遗漏的术语）。

## 竞争对手反向链接分析

| 操作 | 目的 |
|--------|---------|
| **比较配置文件** | 您的反向链接与竞争对手 |
| **链接差距** | 链接到竞争对手但未链接到您的网站 |
| **机会** | 拓展到这些网站；他们可能链接的内容 |

**工具**：Ahrefs、Semrush—链接交集、竞争对手反向链接报告。参见 **backlink-analysis**。

## 竞争对手定价

| 使用 | 实践 |
|-----|----------|
| **定位** | 与竞争对手相比您的位置 |
| **差异化** | 价格不同时的价值主张 |
| **替代页面** | 包含哪些；如何定位 |

参见 **pricing-strategy**、**alternatives-page-generator**。

## 数据来源

| 来源 | 使用 |
|--------|-----|
| **SimilarWeb** | 流量、参与度、按域的流量来源 |
| **Ahrefs** | 竞争对手域名、反向链接、DR |
| **SEMrush** | 有机竞争对手、流量份额 |
| **GA** | 推荐流量、按来源的获取方式 |
| **PostHog** | 竞争对手功能使用（如果跟踪） |

## 报告工作流

1. **解析** — 读取Excel/CSV，从标题中推断域名、访问量、流量来源等
2. **丰富** — 网页搜索，访问竞争对手网站；如果存在，读取 `project-context.md`
3. **构建** — 为报告结构化数据
4. **生成** — 以选定格式输出报告

## 输出格式

- **识别的竞争对手**
- **研究类型**（关键词、内容、反向链接、定价）
- **发现**（差距、机会、基准）
- **建议**（要创建的内容、要追求的链接、定位）

### 报告结构参考

| 部分 | 内容 |
|---------|---------|
| 执行摘要 | 关键发现（前3个），前3个建议 |
| 竞争对手概述 | 竞争对手、类别、市场地位、关键优势 |
| 产品比较 | 功能/能力与我们的对比 |
| SWOT分析 | 我们的优势/劣势/机会/威胁；竞争对手深入分析 |
| 营销与信息传递 | 价值主张、目标受众、关键渠道 |
| 差距与机会 | 差距、机会、优先级 |
| 优先级建议 | 建议、影响、努力、负责人 |
