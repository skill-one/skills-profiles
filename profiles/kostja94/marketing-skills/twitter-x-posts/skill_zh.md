# 平台：X (推特)

指南X发布文案的创作和优化。用于生成可在X上发布的帖子、串流和内容。适用于文案代理、设计代理（图像规格）和视频代理（视频发布规格）。

**调用时**：在**首次使用**时，如果有帮助，先以1-2句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接提供主要输出。

## 输出：发布就绪文案

此技能使代理能够生成可直接发布的X帖子文案。输出包括字符计数文本、串流结构以及平台合规的格式。

## 字符限制

| 类型 | 限制 | 备注 |
|------|-------|-------|
| **标准帖子** | 280字符 | 大多数用户 |
| **高级** | 25,000字符 | X高级订阅用户 |
| **URL** | 计入23个字符 | t.co缩短所有链接 |
| **表情符号** | 约2个字符每个 | 因表情符号而异 |

## 最佳长度（参与度）

| 使用场景 | 字符 | 目的 |
|----------|------------|---------|
| **一般** | 71-100 | 参与度的最佳区间 |
| **推广** | 120-130 | 产品/优惠帖子 |
| **提问** | 60-80 | 引导回复 |
| **适合转发** | 约116 | 留出“RT @用户:”的空间 |

## 串流格式

- **结构**：3-5个连续的帖子；编号为1/5、2/5等。
- **第一篇帖子**：强烈的钩子；第一行不写“串流”
- **最后一篇帖子**：行动号召、总结或提问
- **每篇帖子**：约80个字符；可以独立存在

## 帖子结构（钩子 + 价值 + 行动号召）

| 部分 | 比例 | 指南 |
|------|-------|-----------|
| **钩子** | 10% | 前1-2行；提问、事实或情感；约50个字符 |
| **价值** | 70% | 实用信息；使用串流进行深度 |
| **行动号召** | 20% | 引导回复、提问或行动 |

以开放性问题结尾以驱动回复。串流结构可以扩展印象约10倍。

## 算法（Grok AI）

### 信号权重

| 信号 | 影响 |
|--------|--------|
| **回复** | 最高 (~54-75倍点赞)；质量>数量 |
| **作者回复** | 活跃回复链约75倍可见性 |
| **收藏** | 2026信号；保存推荐 |
| **媒体** | 图片/视频约2倍；视频2-4倍曝光 |
| **外部链接** | 降低分数约50%；优先内部引用 |
| **帖子限制** | 每天5-8篇；每天超过10篇会降低后期可见性约80% |

**内容**：开放性问题、争议性观点、故事；避免“如果同意请转发”的诱饵。

### TweepCred

| 阈值 | 效果 |
|-----------|--------|
| **< 65** | 只有最后3篇帖子会进入为你推荐 |
| **新账户** | 需要+17才能出现在信息流中 |
| **蓝V** | 自动获得100分 |

监控账户健康状况；避免垃圾信息、批量操作、过度链接。

### 分发

首先在小组中测试帖子；前30分钟的早期互动决定覆盖范围。专业领域的持续一致性有助于SimClusters匹配。

## 链接优化

| 实践 | 指南 |
|----------|-----------|
| **惩罚** | 外部链接约-50%；常规账户：自2025年起链接帖子0%参与度 |
| **位置** | 将链接放在回复中，而不是主帖子中 |
| **比例** | 每篇帖子最多1个链接 |
| **高级** | Premium+最安全，用于链接 (~0.25-0.3%参与度) |
| **预览** | 标题≤70个字符，描述≤200个字符；1200×628图像 |

## 高级影响

| 等级 | 覆盖范围 | 链接帖子 |
|------|-------|------------|
| **常规** | <100/篇 | 0%参与度 |
| **高级 ($8)** | ~600/篇 | ~0.25-0.3% |
| **高级+ ($40)** | ~1550/篇 | 链接最安全 |

高级约10倍于常规的覆盖范围。如果X是核心渠道，高级会有所帮助。

## 视频

- **曝光**：比文本高2-4倍
- **长度**：8-30秒短视频更受欢迎
- **VQV**：高视频完成率可提升分数2-3倍

## Twitter Cards + SEO

卡片（og:image、title、description）可提升CTR约64%，参与度约26%。用于社交SEO；X流量可加速Google索引。对于程序化SEO（模板+数据页面大规模），使用programmatic-seo。

| 格式 | 尺寸 | 使用 |
|-------|------------|-----|

| **方形** | 800×800 | 单张图像 |
