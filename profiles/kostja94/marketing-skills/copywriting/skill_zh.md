# 内容：文案撰写

指导**短文案营销**——广告、落地页、邮件、行动号召。文案框架（PAS、AIDA、BAB）为以转化为导向的文案提供结构。对于**文章正文内容**（博客文章、指南、长文案），请参考**article-content**。

**调用时机**：在**首次使用**时，如果有助于理解，可先用1-2句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接进入主要输出。

## 初步评估

**首先检查项目背景**：如果存在 `.claude/project-context.md` 或 `.cursor/project-context.md`，请阅读第2节（定位）、第3节（价值主张）、第8节（品牌与声音）。

识别：
1. **背景**：广告、落地页、邮件、行动号召或通用
2. **目标**：认知、考虑、转化、留存
3. **受众**：目标客户画像、阶段、痛点

## 文案框架

| 框架 | 结构 | 适用场景 |
|-------|-------|----------|
| **PAS** | 问题 → 煽动 → 解决方案 | 直接响应；销售页面；落地页 |
| **AIDA** | 注意力 → 兴趣 → 欲望 → 行动 | 故事驱动；广告；邮件；社论 |
| **BAB** | 之前（问题）→ 之后（结果）→ 桥接（如何） | 转型；客户评价；案例研究 |
| **FAB** | 特性 → 优势 → 利益 | 产品页面；特性列表 |
| **4U** | 有用、紧急、独特、超具体 | 标题；主题行 |

### PAS（问题、煽动、解决方案）

- **问题**：清晰识别读者的痛点
- **煽动**：增强情感冲击力；让问题显得紧急
- **解决方案**：将产品/服务作为答案呈现

### AIDA（注意力、兴趣、欲望、行动）

- **注意力**：用强大的标题或开头吸引
- **兴趣**：通过事实、故事或情感诉求建立参与度
- **欲望**：突出利益点，说明产品如何解决问题
- **行动**：包含清晰的行动号召

### BAB（之前、之后、桥接）

- **之前**：当前问题状态
- **之后**：期望结果
- **桥接**：你的解决方案如何弥合差距

## 标题公式

| 公式 | 示例 |
|-------|-------|
| **如何[结果]** | "如何在30天内翻倍转化率" |
| **[数字]种[利益]** | "7种无需招聘即可降低客户流失的方法" |
| **[谁] + [利益]** | "希望更快上线的营销人员" |
| **[问题]? 这里是[解决方案]** | "SEO遇到困难？这里有一劳永逸的解决方案" |
| **[之前] → [之后]** | "90天内从0到10K用户" |
| **[形容词][名词]为[受众]** | "为SaaS创始人准备的终极指南" |

**规则**：关键词前置；保持在60个字符以内以符合搜索结果页；避免标题党；确保广告与页面内容一致。

**信息增益（差异化）**：重复竞争对手说法的文案毫无价值。以独特角度、专有数据或逆向见解为切入点。"这个标题/承诺比其他人多了什么？" 参考**article-content**了解长文案中的完整信息增益策略。

## 按场景撰写文案

| 场景 | 重点 | 技能 |
|-------|-------|-------|
| **广告文案** | 钩子、利益点、行动号召；平台限制 | paid-ads-strategy, google-ads, meta-ads |
| **落地页** | 标题、价值主张、行动号召；首屏可见 | landing-page-generator, hero-generator |
| **邮件** | 主题行、预览、正文、行动号召 | email-marketing |
| **行动号召** | 价值导向；使用行动动词；避免"提交" | cta-generator |
| **文章/博客** | 标题公式、行动号召文案；正文 → **article-content** | article-content, article-page-generator |

## 广告文案与落地页文案的区别

| 元素 | 广告 | 落地页 |
|-------|-------|--------|
| **承诺** | 必须与页面标题一致 | 相同承诺；进行扩展 |
| **长度** | 简洁；平台限制 | 足够解释价值 |
| **行动号召** | 点击跳转；"了解更多" | 转化；"免费试用" |

**避免**：广告承诺与页面不匹配；不匹配会增加跳出率。

## 行动号召文案最佳实践

- **价值导向**："免费试用"而非"提交"
- **行动动词**："获取"、"尝试"、"下载"、"加入"
- **具体**："获取免费审计"而非"点击这里"
- **A/B测试**：颜色、文案、位置、大小

## 输出格式

- **框架**（PAS、AIDA、BAB）建议
- **标题**选项（2-3个变体）
- **正文**文案结构
- **行动号召**文案选项
- **A/B测试**建议（如适用）
