# SEO：实体SEO

指导基于实体的SEO——使您的品牌、产品和作者在搜索引擎的知识系统中被识别为不同的实体。谷歌已从关键词匹配转向基于含义的理解（蜂鸟、排名脑、BERT、MUM）；实体理解是搜索处理查询的核心。围绕实体构建的内容可以在AI驱动的搜索中获得约3.2倍的可见性。参考文献：[Semrush](https://www.semrush.com/blog/entity-based-seo-strategy/)、[Search Engine Land](https://searchengineland.com/guide/entity-first-content-optimization)。

**调用时机**：在**首次使用**时，如果有助于理解，用1-2句话概述该技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接进入主要输出。

## 范围

- **实体定义**：单一、独特、定义明确的事物（人物、地点、组织、产品、事件）
- **实体与关键词**：实体 = 底层概念；关键词 = 文本字符串
- **知识图谱**：谷歌的实体数据库；支持消歧义和相关概念
- **实施**：模式（组织、人物）；内容中的实体信号；跨平台的统一性

## 什么是实体？

**实体**是一个单一、独特、定义明确且可区分的事物或概念——例如人物、地点、组织、产品、事件。实体具有：

| 属性 | 含义 |
|------|------|
| **唯一标识** | "Apple Inc." ≠ "apple (水果)" 尽管使用相同的词语 |
| **属性** | 成立时间、地点、行业 |
| **关系** | 与其他实体的连接（例如 Apple Inc. → 史蒂夫·乔布斯、iPhone） |

**实体SEO** = 优化搜索引擎以识别、分类并在知识图谱中连接您的品牌/产品/作者。关键词具有歧义性；实体在上下文中保持一致的含义。

## 实体SEO的重要性

- **搜索演变**：谷歌使用实体来理解意图，而不仅仅是匹配短语
- **知识图谱**：数十亿的实体和关系；消歧义、相关概念
- **AI搜索**：实体优化的内容在AI结果中可见性提高约3.2倍
- **E-E-A-T**：实体信号支持体验、专业、权威性、信任。参见 **eeat-signals**
- **GEO**：AI概述、Copilot、Perplexity引用实体；清晰的标识改进引用。参见 **generative-engine-optimization**

## 实体信号（内容最佳实践）

| 实践 | 目的 |
|------|------|
| **清晰的品牌/产品名称** | 一致命名；避免与相似实体混淆 |
| **作者身份** | 人物模式；作者简介；链接到作者页面 |
| **组织身份** | 全站组织模式；标志、sameAs |
| **可引用段落** | 每个区块独立可理解；支持AI提取 |
| **一致性** | 同一名称、描述、标志跨网站、社交、目录 |

## 实体SEO的模式

### 组织

- **位置**：**最低要求**——主页；**最佳**——根布局/全局组件（layout.tsx、_document、全局页眉），以便出现在每个页面。**不要**局限于关于页面；关于页面使用AboutPage模式。参见 **schema-markup** 获取完整位置表。
- **必需**：`@id`、`name`、`url`；添加 `logo`、`sameAs`（社交、Wikidata）
- **可选**：`description`、`address`、`contactPoint`；在适用情况下使用最具体的类型（LocalBusiness、SoftwareApplication等）

**@id**：使用稳定URL（例如 `https://example.com/#organization`）进行跨页面的实体链接。在主页上链接Organization ↔ WebSite以获取站点链接搜索框。

### 人物

- **使用**：作者页面；文章作者；团队成员
- **属性**：`name`、`url`；`affiliation`（组织）；`sameAs`（LinkedIn、Twitter）
- **@id**：启用实体链接；例如 `https://example.com/author/jane/#person`

参见 **schema-markup** 获取完整的 VideoObject、Article、Product 等；组织和人物是实体SEO的核心。

## 知识面板与知识卡片

| 功能 | 描述 | 可获得性 |
|------|------|----------|
| **知识面板** | SERP中的实体信息（品牌、人物、地点） | WikiData、合作伙伴关系；大多数网站无法直接获得 |
| **知识卡片** | SERP顶部的语义答案 | 与知识面板相同 |

**操作**（有限控制）：
- **声明**：谷歌商家资料；在可用时建议更新
- **一致性**：跨所有平台使用相同的品牌名称、描述、标志
- **实体主页**：权威的关于页面作为主要参考
- **WikiData / Wikipedia**：可以支持知识面板生成

参见 **serp-features** 获取SERP上下文中的知识面板；**multi-domain-brand-seo** 获取Hub-Spoke实体一致性。

## 实体与多域/品牌

在使用多个域（Hub-Spoke）时：
- **一致性**：Hub和Spoke上使用相同的品牌名称、描述、标志
- **实体主页**：Hub上的权威关于页面作为主要参考
- **模式**：组织模式，用于相关实体
- **实体混淆**：避免传统品牌、子品牌、目录稀释品牌认知

参见 **multi-domain-brand-seo** 获取完整策略。

## GEO与AI引用

实体信号增强GEO引用：
- **直接答案格式** + **实体信号** = 更清晰的AI提取
- **可引用段落** 具有清晰的品牌/产品/作者身份
- **分发**：网站、YouTube、论坛、Reddit——跨平台保持一致的实体身份

参见 **generative-engine-optimization** 获取完整GEO策略。

## 输出格式

- **实体审计**（品牌、产品、作者身份差距）
- **模式**（组织、人物；@id位置）
- **一致性**清单（跨触点名称、标志、描述）
- **知识面板**（如果符合条件则声明；建议更新）
