# 内容：翻译

指导多语言内容的翻译工作流程、术语、风格和质量。涵盖何时使用人工翻译与机器翻译、术语表和风格指南的创建，以及SEO考虑因素。关于i18n实施、hreflang和URL结构，请参阅**localization-strategy**。

**调用方式**：在**首次使用**时，如果有帮助，先用1-2句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接提供主要输出。

## 范围

- **工作流程**：简报→翻译→审阅
- **术语**：术语表创建和管理
- **风格指南**：每种语言的语气、语调、格式
- **人工翻译与机器翻译**：何时使用每种方式；后期编辑
- **质量**：QA、一致性、SEO
- **市场特定**：按地区划分的术语

## 初步评估

**首先检查项目背景**：如果存在`.claude/project-context.md`或`.cursor/project-context.md`，请阅读它以了解品牌语气、目标市场和产品术语。

识别：
1. **内容类型**：产品UI、营销文案、博客、着陆页、文档
2. **目标语言**：优先地区
3. **现有资源**：术语表、风格指南、翻译记忆库（TM）

## 1. 翻译工作流程

### 简报→翻译→审阅

| 阶段 | 目的 | 输出 |
|------|------|------|
| **简报** | 背景、受众、语气、术语表参考、风格指南 | 翻译员简报文档 |
| **翻译** | 初次翻译；在可用时使用术语表+TM | 草稿翻译 |
| **审阅** | 母语人士审阅；一致性、品牌语气、SEO | 最终翻译 |

### 翻译员简报

在每个项目中包含：
- **背景**：内容用途（着陆页、产品UI、博客）
- **受众**：目标市场、用户画像
- **语气**：正式、休闲、技术性
- **术语表**：链接或附加；必须使用的术语
- **风格指南**：参考或关键规则
- **限制**：字符限制（UI）、SEO关键词自然包含

### 内容类型工作流程

| 内容类型 | 方法 | 备注 |
|----------|------|------|
| **产品UI** | 术语表关键；短字符串；一致性 | 使用TM；避免机器翻译 |
| **营销文案** | 品牌语气；文化适应 | 人工翻译；参见术语 |
| **博客/文章** | SEO；自然关键词布局 | 在目标语言中重新研究关键词；不要翻译关键词列表 |
| **着陆页** | 转化导向；CTA清晰度 | 人工；测试本地化CTA |
| **技术文档** | 精确性；术语表 | TM+术语表；考虑MT+后期编辑以应对高容量 |

## 2. 术语表与术语

### 术语表目的

- **一致性**：所有内容中相同术语的翻译方式相同
- **品牌**：产品名称、功能名称、批准措辞
- **合规性**：安全、法律、监管术语
- **成本**：减少返工；加速审阅

### 术语表结构

| 字段 | 目的 |
|------|------|
| **源术语** | 原始（例如，英语） |
| **目标术语** | 批准的翻译 |
| **背景** | 出现位置；使用说明 |
| **不翻译** | 品牌名称、产品名称（当适用时） |

### 市场特定术语

| 术语 | 英文 | 中文 | 备注 |
|------|------|------|------|
| **生成式AI** | Generative AI, GenAI | AIGC（人工智能生成内容） | 在中国使用"AIGC"；英语使用"Generative AI" |
| **影响者** | Influencer | KOL（关键意见领袖） | "KOL"在中国营销中常见 |
| **用户** | User | 用户 | 取决于上下文 |
| **仪表盘** | Dashboard | 控制台、仪表盘 | 选择一个；在术语表中记录 |

**原则**：不要翻译术语列表；研究目标市场如何搜索和表达。参见**keyword-research**进行多语言关键词研究。

## 3. 风格指南（翻译）

### 定义元素

| 元素 | 目的 |
|------|------|
| **语气** | 品牌个性；正式与休闲 |
| **语调** | 根据内容类型变化（支持=有帮助；营销=有说服力） |
| **语域** | 在区分正式（您）与非正式（你）的语言中 |
| **标点符号** | 引号、空格（例如，法语中冒号前不加空格） |
| **格式** | 日期、数字、单位；地区特定 |
| **禁止** | 避免使用的术语或短语 |

### 按语言考虑

- **中文**：简体与繁体；量词使用
- **德语**：正式（Sie）与非正式（du）；复合名词
- **日语**：敬语；正式场合的敬语（keigo）
- **阿拉伯语**：从右到左；正式与方言

## 4. 人工翻译与机器翻译

### 何时使用人工翻译

| 场景 | 原因 |
|------|------|
| **产品UI** | 术语、UX清晰度、品牌 |
| **营销文案** | 说服力、文化差异、CTA |
| **着陆页** | 转化；测试过的文案 |
| **法律、合规** | 准确性、责任 |
| **品牌关键** | 标语、活动文案 |

### 机器翻译（MT）可能可接受的情况

| 场景 | 条件 |
|------|------|
| **高容量、低风险** | 内部文档、用户生成内容 |
| **草稿/筛选** | MT+人工后期编辑（MTPE） |
| **实时** | 聊天、支持；附带免责声明 |

### 避免

- **原始MT用于产品/营销**：术语错误、文化失误、SEO不佳
- **无后期编辑的MT用于面向客户的内容**
- **翻译关键词列表**而不是在目标语言中重新研究

## 5. 翻译记忆库（TM）与TMS

### 翻译记忆库

- **内容**：存储批准的源↔目标句子对
- **好处**：一致性；重用；降低每字成本；加快交付
- **最佳实践**：维护TM；清理重复项；与术语表对齐

### 翻译管理系统（TMS）

- **用于**：集中工作流程；术语表+TM集成；供应商管理
- **何时**：多语言；持续翻译；团队协作

## 6. 质量与SEO

### 质量检查清单

- [ ] 正确使用术语表术语
- [ ] 遵循风格指南
- [ ] 无未翻译字符串
- [ ] 数字、日期、单位本地化
- [ ] 尊重字符限制（UI）
- [ ] 完成母语人士审阅

### 翻译内容的SEO

- **关键词**：在目标语言中重新研究；不要从源语言翻译
- **元数据**：标题、描述翻译；参见**title-tag**、**meta-description**
- **Hreflang**：技术实施在**localization-strategy**中；翻译生成内容
- **薄内容**：避免一次性发布许多低质量翻译页面；可能触发处罚。参见**localization-strategy**多语言风险。

## 输出格式

- **翻译员简报**（背景、受众、术语表、风格）
- **术语表**添加或更新
- **风格指南**针对目标语言的说明
- **人工翻译与机器翻译**建议
- **质量**检查清单

## 相关技能

### 策略与技术

- **localization-strategy**：i18n、hreflang、URL结构、按市场定价；翻译为本地化页面生成内容
- **content-strategy**：多语言内容规划；避免薄翻译
- **content-marketing**：内容类型和格式；翻译作为单一渠道适应

### SEO与内容

- **keyword-research**：多语言关键词研究；不要翻译关键词列表
- **page-metadata**：hreflang实施
- **title-tag、meta-description**：按地区翻译元数据
- **copywriting**：源文案待翻译；品牌语气
- **image-optimization**：为翻译页面本地化图像文件名

### 页面

- **article-page-generator**：文章结构；翻译时考虑SEO
- **landing-page-generator**：着陆页文案；人工翻译以实现转化
