# 内容：文章内容

指导创建**文章主体内容**——博客文章、指南和长篇作品的实际文本（引言、正文、结论）。重点在于**写什么内容**。关于**内容放置位置**（页面结构、模式、元数据），请参阅**article-page-generator**。关于简短转化文案（广告、着陆页、行动号召），请参阅**copywriting**。

**调用时**：在**首次使用**时，如果有帮助，先用1-2句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或当用户要求跳过时，直接提供主要输出。

## 范围

- **文章主体**：引言、正文部分、结论、行动号召
- **内容结构**：钩子、问答模式、段落长度、可扫描性
- **字数**：根据文章类型和搜索意图
- **写作框架**：AIDA、PAS、BAB应用于文章
- **GEO元素**：TL;DR、关键要点、先回答

## 文章类型与字数（2025年）

**质量重于长度**：Google优先考虑全面覆盖搜索意图，而不是字数。根据主题深度和意图匹配长度。

| 类型 | 字数 | 用例 |
|------|------------|----------|
| **新闻/公告** | 300-600 | 产品更新、突发新闻、常见问题解答 |
| **短形式** | 500-800 | 着陆页、产品页面（可扫描） |
| **标准文章/操作指南** | 1,000-1,500 | 单一主题；可操作；列表文章 |
| **列表文章** | 1,200-2,000 | "Top 10"、"最佳X"；编号列表可提高点击率约70% |
| **集群文章** | 800-2,500 | 子主题；链接到核心文章 |
| **核心/支柱文章** | 2,000-3,500+ | 全面；集群中心；6-12个部分 |
| **竞争性关键词** | 1,800-2,500 | 第一页SEO文章平均约2,400字 |

**基于意图**（Google 2025）：验证1,200-2,000；探索2,000-3,500；比较600-1,200；做900-1,500；知道300-800。信息性内容比交易性内容长约40%。

**避免**：少于300字（内容单薄）；超过7,000字（通常由于注意力分散而表现不佳）。

## 内容创作工作流程

### 四个输入

文章内容基于**四个输入**。请参阅**article-page-generator**了解完整工作流程。

| 输入 | 目的 |
|-------|---------|
| **产品** | 连接、功能、行动号召位置 |
| **关键词** | 目标关键词、主要/次要 |
| **文章意图** | 信息性、商业性、交易性 |
| **竞争对手文章** | 采用的结构、内容差距、长度目标 |

### 信息增益（内容密度高于字数）

**信息增益**=页面提供的净新信息，超出顶级排名结果中存在的信息。Google评估独特价值，而不是全面性。内容密度（每100字中的独特实体、数据点、见解）比字数更重要。Skyscraper技术（更长更好）不再区分；AI使全面性变得廉价。

**信息增益的四个来源**：
- **反叙事**：为什么“最佳实践”在某些情况下失效；有证据支持
- **时效性新鲜度**：竞争对手内容和LLM截止日期后的数据或发展
- **专家视角**：直接引语、从业者经验；不是重新包装的建议
- **专有数据**：原始调查、内部基准、用户行为模式

**避免共识内容**：重复顶级10个结果中的常见事实=零信息增益。在写作前审核SERP；列出“共识层”；识别差距（未回答的问题、过时的数据、未服务的细分市场）。以新内容开头；先回答问题。

**密度检查**：计算独特数据点、原创见解、具体声明。如果新信息与字数的比率低，则删除填充内容。高密度内容（800-1,500字，3个以上原创点）通常优于长篇重述指南。

### TL;DR或关键要点（GEO）

选择一个；放在引言之后。具有这些元素的内容在AI引擎中被引用的频率更高。

| 格式 | 规格 |
|--------|------|
| **TL;DR** | 50-100字的粗体摘要段落 |
| **关键要点** | 5-7个要点 |

请参阅**generative-engine-optimization**了解完整的GEO策略。

### 引言

**长度**：40-120字；2-3段。读者在8秒内决定；钩子必须立即起作用。

| 元素 | 指南 |
|---------|-----------|
| **钩子** | 前1-2句话：痛点、统计数据或问题；好奇心差距；具体数据或反事实 |
| **主要关键词** | 前100字中 |
| **期望** | 设置读者将学习的内容 |

**钩子类型**：“你正在做X错”；“97%的Y…”；粗体问题；挑战假设。精心设计的钩子可以提高CTR 30-50%。

### 正文

| 元素 | 指南 |
|---------|-----------|
| **QAE模式** | 问题（H2）→ 回答（2句话）→ 证据（数据、示例、列表） |
| **先回答** | 直接回答在每次H2后的40-60字内 |
| **回答块** | 100-200字每节；直接回答+上下文+证据 |
| **段落长度** | 40-80字；2-4句话；避免大段文字 |
| **分割长块** | 列表、H3、图片、调用框每2-3段 |
| **可扫描性** | 前置关键信息（F模式）；**粗体**关键短语；每段一个想法 |

**长形式（1,000+字）**：每500-600字放置一个参与钩子；混合40-50%解释性文本、20-25%示例、10-15%数据、5-10%视觉。

### 结论

**总结**+**行动号召**：订阅新闻、相关内容、**产品**（在相关时链接到产品/功能）。与产品相关的内容自然地与产品联系在一起。

### 产品连接

文章应与产品（解决的问题、功能、用例）相关联。避免纯通用内容。在结论中或上下文适合时自然链接到产品/功能页面。

## 写作框架

将**文案**框架应用于文章结构。请参阅**文案**了解完整的PAS、AIDA、BAB。

| 框架 | 文章用途 |
|-----------|-------------|
| **AIDA** | 引言（注意力）；正文（兴趣、欲望）；结论（行动/行动号召） |
| **PAS** | 操作指南：引言中的问题；正文中的加剧；整个解决方案 |
| **BAB** | 案例研究、转型：之前→之后→桥梁 |

**根据受众选择**：AIDA适用于准备购买的；PAS适用于痛点驱动的；BAB适用于转型寻求者。

## 文章标题

请参阅**文案**了解标题公式（如何、数字、问题→解决方案）。对于文章标题具体：

- **长度**：50-60个字符；请参阅**title-tag**
- **主要关键词**靠近开头
- **数字**和强力词可以提高CTR约36%

## 参考文献 & 引用

| 场景 | 实践 |
|----------|----------|
| **数据或统计数据** | 引用内联（例如："根据[来源](url)，72%的…")或参考文献部分 |
| **专家引言** | 归因；链接到来源 |
| **参考文献部分** | 5个以上引用；列在末尾，在相关文章之前 |
| **格式** | 内联链接优先；编号参考文献[1]、[2]用于学术风格 |

请参阅**eeat-signals**了解E-E-A-T、作者简介、引用、引用格式。

## 内容质量

| 元素 | 指南 |
|---------|-----------|
| **可读性** | 8-10级（Flesch-Kincaid）；短句子、清晰语言 |
| **深度** | 匹配类型；全面覆盖优于填充 |
| **原创性** | 独特角度、数据、示例；避免单薄或重新包装的内容 |
| **信息增益** | 这增加了什么，顶级10个结果没有？反叙事、新鲜数据、专家引言或专有见解 |
| **E-E-A-T** | 作者简介、引用、专家引言——请参阅**eeat-signals** |

## 内容审核清单

在审核或优化文章内容时：

| 维度 | 检查 |
|-----------|-------|
| **钩子** | 引言以痛点、统计数据或问题开头？ |
| **关键词在100字内** | 主要关键词存在吗？ |
| **QAE模式** | H2作为问题？每个部分先回答（40-60字）？ |
| **字数** | 匹配类型？（300-600新闻，1,000-2,500集群，2,500+核心） |
| **段落长度** | 每个段落40-80字？没有大段文字？ |
| **产品连接** | 与产品相关联？自然链接到功能/价格？ |
| **行动号召** | 位置（结论、中文章）；清晰度；产品链接 |
| **参考文献** | 数据/统计引用？5个以上引用的参考文献部分？ |
| **差距** | 顶级排名文章覆盖了什么这篇文章遗漏了？ |
| **信息增益** | 至少一个：反叙事、新鲜数据、专家视角、专有数据？还是共识重新包装？ |

请参阅**竞争对手研究**了解竞争对手分析；**article-page-generator**了解页面结构和元数据。
