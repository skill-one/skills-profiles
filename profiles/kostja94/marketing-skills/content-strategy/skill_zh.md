# SEO 内容：内容策略

提供 SEO 内容策略指南：主题簇、支柱页面、簇内文章和编辑规划。有关跨所有渠道（博客、邮件、社交、视频）的内容营销，请参阅 **content-marketing**。有关翻译工作流程和多语言内容，请参阅 **translation**。

**调用时机**：在 **首次使用** 时，如果有助于理解，可先以 1-2 句话概述该技能涵盖的内容及其重要性，然后提供主要输出。在 **后续使用** 或当用户要求跳过时，直接提供主要输出。

## 初步评估

**首先检查项目背景**：如果存在 `.claude/project-context.md` 或 `.cursor/project-context.md`，请阅读其中关于产品、受众和证明点的内容。

识别：
1. **关键词**：来自关键词研究——有关发现和簇化，请参阅 **keyword-research**
2. **现有内容**：已存在的内容
3. **资源**：内容能力、工具
4. **目标**：流量、转化、权威性

**产品导向型 SEO**：围绕产品/用户进行 SEO，而非围绕行业/搜索引擎。有关产品导向型 SEO 原则、适合 SEO 的产品和工作流程顺序，请参阅 **seo-strategy**。

## 主题簇

主题簇按 **主题** 组织内容，而非孤立的关键词。**支柱页面** 涵盖广泛的核心主题；**簇内文章** 涵盖子主题；所有内容通过内部链接连接。这向搜索引擎和 AI 系统传递主题权威信号。

### 结构

```
支柱页面（广泛主题，2,000-5,000+ 字）
    <-> 内部链接
簇 1（子主题，800-2,500 字）
簇 2（子主题）
...
簇 6-12（子主题）
    <-> 簇间链接
```

### 支柱页面

| 属性 | 指导方针 |
|------|----------|
| **长度** | 2,000-5,000+ 字；综合指南 |
| **关键词** | 搜索量较高的宽泛头部术语 |
| **角色** | 中心；链接到所有簇内文章；针对主要主题 |
| **转化** | 在相关情况下链接到产品/功能页面 |

### 簇内文章

| 属性 | 指导方针 |
|------|----------|
| **数量** | 每个支柱 6-12 篇文章（最少 6 篇以建立权威） |
| **长度** | 每篇 800-2,500 字；聚焦于一个子主题 |
| **关键词** | 每篇文章针对长尾、特定意图的关键词 |
| **链接** | 每个簇链接到支柱；支柱链接回簇；相关簇互相链接 |

### 内部链接模型

| 链接类型 | 目的 |
|------|------|
| **支柱到簇内** | 中心分散权威；用户发现子主题 |
| **簇内到支柱** | 传递关系；将价值传递给中心 |
| **簇间** | 相关子主题；加强主题覆盖 |

### 结构和内容同等重要

**框架和正文质量都重要**：目录、章节逻辑和内容深度对 SEO 和用户体验都至关重要。结构薄弱会削弱优秀写作；写作薄弱会削弱优秀结构。从一开始就要规划两者。

### 主题簇为何有效

- **主题权威**：针对多个变体排名；全面覆盖传递专业信号
- **避免内容竞争**：每个主题/关键词一个页面；无竞争页面
- **更好的内部链接**：逻辑清晰；爬虫理解结构
- **AI 引用**：簇化内容比独立内容获得约 42% 的更多 AI 引用
- **流量**：有机流量增加约 30%；排名持续时间约 2.5 倍长

### 实施步骤

1. **选择 3-7 个核心主题** -> 业务相关性、搜索需求、竞争机会
2. **映射子主题** -> 人人也会问、竞争对手分析、关键词工具
3. **内容审计** -> 识别可成为支柱或簇内的现有页面；发现空白点
4. **先构建簇内**（可选）-> 簇内页面通常首先排名；之后添加支柱
5. **创建支柱** -> 综合指南；链接到所有簇内
6. **建立链接** -> 支柱 <-> 簇内；簇内 <-> 簇内
7. **每季度更新** -> 维持新鲜度和权威性

### 示例

- **支柱**： "SEO 指南"（针对 "SEO"）
- **簇内**： "技术 SEO"、"页面 SEO"、"链接建设"、"内容 SEO"、"本地 SEO"、"E-E-A-T"

## 内容类型

| 类型 | 用途 | SEO 适用性 |
|------|------|------------|
| **操作指南** | 信息意图；高分享潜力 | 高 -> 符合搜索意图 |
| **比较** | 商业意图；"X vs Y" | 高 |
| **列表文章** | "Top 10"、"最佳 X" | 高 |
| **术语表** | 定义查询；内部链接中心 | 高 |
| **工具/计算器** | 可链接资产；参与度 | 高 |
| **案例研究** | 证明；支持转化 | 中 -> 支持转化 |
| **融资 / PR** | 融资轮次、收购 | 低 -> 品牌/PR，非搜索驱动 |
| **产品更新** | 功能发布、发布说明 | 低 -> 内部受众 |
| **新闻 / 趋势** | 行业新闻、热点话题 | 中 -> 快速峰值，短期生命周期 |

### 常青内容与时效内容组合

- **常青**（70-75%）：支柱指南、操作指南、比较、术语表。驱动长期流量、反向链接、权威性。每 6-12 个月刷新。
- **时效**（25-30%）：季节性、趋势、新闻。产生快速流量，显示主题相关性。将时效内容链接到常青支柱。
- **平衡**：常青过多 = 博客感觉陈旧；时效过多 = 流量不稳定，内容更替频繁。

## 编辑日历

- 将关键词映射到内容
- 按机会优先级排序（量 -> 意图 -> 可行性）
- 按能力安排时间
- 包含现有内容的更新计划

## 输出格式

- **主题簇** 图（支柱 + 6-12 个簇内）
- **内容日历**（主题、关键词、截止日期）
- **内部链接** 计划
- **现有内容更新** 计划

## 相关技能

- **content-marketing**：内容类型、格式、渠道、再利用；SEO 内容是一个渠道
- **translation**：多语言内容；翻译工作流程、术语表；避免内容薄弱的翻译
- **seo-strategy**：SEO 工作流程顺序、产品导向型 SEO、审计方法；在从零规划 SEO 时使用
- **website-structure**：规划要构建的页面；结构指导内容簇和支柱位置
- **keyword-research**：关键词驱动内容计划
- **programmatic-seo**：使用模板 + 数据的程序化 SEO 以扩展页面；补充主题簇
- **content-optimization**：字数、H2 关键词、关键词密度、多媒体、列表 -> 页面内容优化
- **internal-links**：簇内需要内部链接
- **link-building**：内容策略创建可链接资产
- **heading-structure**：内容结构使用标题
