# 平台：领英

指导领英帖子文案的创作和优化。用于生成可发布的专业内容。适用于文案代理和设计代理（图片规格）。

**调用时**：在**首次使用**时，如果有帮助，先用1-2句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接提供主要输出。

## 输出：可发布文案

此技能使代理能够生成针对参与度优化的领英帖子文案。输出包括字符计数文本和“查看更多”阈值的结构。

## 帖子类型和入口（自然流量）

| 类型 | 需要注意的内容 |
|------|----------------|
| **发布帖子** | 短更新；如果粘贴URL，可以包含**链接预览**。与其他更新相同的动态消息格式。 |
| **照片** | 单个或多个图片（动态消息中的轮播图）。 |
| **视频** | 上传的文件（与**领英直播**区分，领英直播是直播流，有独立的访问控制）。 |
| **撰写文章** | **文章**=长格式编辑器，**独立**于短消息框；长URL，更适合深度和部分**站外**发现。 |
| **文档** | PDF / PPT / DOC（动态消息中的幻灯片）。官方限制（请查看当前帮助）：每个文件约为**~100MB / ~300页**——发布时请核实。 |
| **投票** | 参与度驱动；保持问题和选项易于扫描。 |
| **更多**（菜单） | 通常包括**庆祝**、**招聘**风格的分享、**寻找专家**等（因产品/地区而异）。 |
| **转发** | 转发或**引用**另一位成员的帖子并附上你的看法——增加背景信息；避免空转发。 |
| **通讯录** | **系列**订阅；与一次性帖子不同，但随时间推移具有复合触达效果。 |
| **活动** | 通过专用流程创建/推广活动，而不是纯文本帖子。 |

**产品详情**：[开始在领英发布](https://www.linkedin.com/help/linkedin/answer/a518996) · [上传和分享文档](https://www.linkedin.com/help/linkedin/answer/a518909)

**对文案的重要性**：根据**形式**匹配CTA和长度（例如，一个文档演示文稿与一个5行的热评）。不要将**短帖子**和**文章**视为可互换的。

## 平台定位

领英是一个职业网络——其核心价值是职业身份、B2B关系和专业内容。与一般社交平台的主要区别：

| 维度 | 领英 | Meta / X / TikTok |
|-----------|----------|--------------------|
| **主要意图** | 求职、B2B社交、行业学习 | 娱乐、社交、发现 |
| **身份** | 真实姓名 + 职业历史 | 用户名或生活方式形象 |
| **内容语气** | 专业、建设性 | 随意、娱乐、观点 |
| **B2B潜在客户价值** | 高（职位名称 + 公司定位） | 低到中等 |
| **算法信号** | 专业兴趣 + 网络 + 编辑推荐 | 参与度、观看时间、病毒式传播 |

**优先考虑领英的情况**：针对B2B买家、建立专业权威、招聘或发布行业思想领导力。对于消费者品牌知名度或娱乐，其他平台通常更有效。

## 动态消息排名依据（写作要点）

- 动态消息**不是**纯粹的倒序时间好友列表。它混合了**一级联系人、关注、公司/话题兴趣**以及来自**经济图谱**的推荐“外部网络”内容，还包括广告。[动态消息排名依据](https://www.linkedin.com/help/linkedin/answer/a9554004)
- 相关性使用帖子的**上下文**、**个人资料和网络信号**以及**行为**（阅读、反应、评论、分享、**停留**）。人口统计信息如年龄或性别**不**用于排名动态消息可见性（根据公开帮助指南）。
- 近期公开沟通中的平台方向：更多**LLM/语义**理解，更少**不真实参与**和**参与诱饵**/低质量重复；优先考虑**真实专业知识**和**有意义**的讨论。[关于动态消息工程的背景（博客）](https://www.linkedin.com/blog/engineering/feed/engineering-the-next-generation-of-linkedins-feed)

**写作影响**：强烈的**首行**和**主题深度**；添加实质内容的评论；避免看起来自动化的模板或“豆荚”协调。

## 站外搜索可见性（SEO & GEO）

领英内容在**选择性**基础上对搜索引擎可见——了解哪些内容会被SEO索引，哪些会被GEO引用。

### Google索引内容与登录受保护内容对比

| 表面 | 搜索可见性 | GEO（AI引用）价值 |
|---------|-----------------|-------------------------|
| **公开个人资料**（标题、关于、经验） | 索引，用于名称/公司/角色查询 | 强实体信号；可引用段落 |
| **文章**（长格式编辑器） | 设置为公开时索引 | 高；包含关键词的结构化段落 |
| **公司页面** | 索引，用于品牌查询 | 中等；品牌实体信号 |
| **短动态消息** | **登录受保护**——不索引 | **低**；如果登录后则无法引用 |
| **通讯录期数** | 如果公开则索引；如果是订阅-only则登录受保护 | 取决于可见性设置 |

### 通过领英进行SEO

- **标题**是个人资料上SEO最可见的字段——将其视为标题标签。包含主要关键词 + 价值主张（例如：“B2B SaaS营销 | 帮助初创公司通过内容实现规模化”）。
- **关于部分**：写面向公众的段落，包含关键词和证明点。这部分被索引，并且经常出现在Google搜索片段中。
- **精选部分**：用于展示关键链接（网站、案例研究、新闻稿）。这些出现在你的公开个人资料上，并增加反向链接价值。
- **文章**：长格式内容在Google上独立排名。将其视为次要出版物，而不是主要出版物——用规范或独特文章改写网站内容。
- **一致性**：在领英、你的网站和其他公开简介中保持名称、标题和实体名称的一致性。查看**实体SEO**的`sameAs`对齐。

### 通过领英进行GEO

- **实体一致性**：你的领英个人资料是一个高权威实体来源。AI搜索工具（ChatGPT、Perplexity、Google AI概述）可以在回答“谁是[人]”或“[公司]做什么”查询时引用你的领英个人资料。
- **可引用段落**：将你的关于部分写成答案优先格式（每个块40-60个字），以便AI工具可以直接提取并引用。
- **证据链接**：在精选和关于部分添加指向你的网站、案例研究、演讲和出版物的链接。AI工具引用外部链接作为支持参考。
- **公开文章**：在相关主题上发布领英文章；结构良好的文章包含数据和引用，会增加AI引用的可能性。
- **限制**：登录受保护的短动态消息对AI爬虫和搜索引擎不可见。不要依赖动态消息帖子进行GEO。

**可操作的检查清单**：
- [ ] 标题包含主要关键词 + 价值主张（视为元标题）
- [ ] 关于部分写成答案优先格式（可引用段落）
- [ ] 精选部分展示网站、案例研究、关键出版物
- [ ] 实体名称（姓名、公司、职位）在领英和网站上一致
- [ ] 至少发布一篇公开文章，主题与相关行业相关
- [ ] 领英个人资料URL使用自定义别名（不是默认ID字符串）

对于实施细节：**open-graph**（链接预览）、**entity-seo**（人物/组织sameAs）、**generative-engine-optimization**（跨平台GEO）。

## 个人资料模块用于发现

影响搜索可见性和AI引用的关键领英个人资料模块：

| 模块 | SEO/GEO价值 | 优化 |
|--------|---------------|--------------|
| **标题** | 最高——索引，出现在搜索片段中 | 超出职位名称定制；包含关键词 + 目标受众 + 价值 |
| **关于** | 高——索引；可被AI引用 | 写成答案优先格式；包含证明点、外部链接 |
| **精选** | 中等——在公开个人资料上展示关键链接 | 添加网站URL、案例研究、新闻稿、作品集 |
| **经验（媒体）** | 低-中等——媒体附件被索引 | 添加相关文档、链接、图片到每个职位 |
| **技能与认可** | 低——索引但信号薄弱 | 包含相关技能；认可增加社会证明 |
| **文章** | 高——索引且可排名 | 发布包含关键词和数据的长格式内容 |
| **自定义URL** | 间接——干净的URL提高了可分享性 | 设置为firstnamelastname或类似 |

有关完整的个人资料模块清单，请参阅[领英帮助：向你的个人资料添加部分](https://www.linkedin.com/help/linkedin/answer/a540837)。

## 字符限制

| 类型 | 限制 | 备注 |
|------|-------|-------|
| **帖子** | 3,000字符 | 最佳：1,300-1,600 |
| **首行（关键）** | 210-235字符 | 在“查看更多”之前可见；60-80%的人在这里决定 |
| **短帖子** | 100-200字符 | 投票、公告、引用 |

## 按内容类型划分的最佳长度

| 类型 | 字符 | 使用 |
|------|------------|-----|
| **短** | 100-200 | 投票、公告、引用 |
| **中等** | 300-1,200 | 案例研究、技巧、幕后花絮 |
| **长** | 1,200-2,000 | 思想领导力、分析 |
| **甜点** | 1,300-1,600 | 最高参与度 |
| **避免** | >2,000 | 参与度下降约35% |

## 首行（钩子）

- **在首140字符内放置关键信息**
- **强烈的开头**：具体结果、痛点、大胆声明、惊人统计数据
- **避免**：模糊的暗示、标签优先、通用问候

## 图片规格（设计代理适用）

| 格式 | 尺寸 | 使用 |
|--------|------------|-----|
| **单张图片** | 1200×627 (1.91:1) | 动态消息；链接预览 |
| **方形** | 1200×1200 | 单张图片 |
| **轮播图（自然流量）** | 最多20张图片 | 多图片帖子 |
| **文件** | ≤10 MB；JPG/PNG | 原生上传表现更好 |
| **垂直** | 更受欢迎 | 88%在移动设备上浏览 |

## 最佳实践

- **移动优先**：88%的用户在移动设备上
- **投票和文档（PDF）帖子**：通常对触达效果强；与清晰的要点搭配使用
- **帖子频率**：公司页面每周最低是一个常见标准；个人通常**每周几次**如果可持续
- **替代文本**：添加以提高可访问性
- **B2B语气**：专业和建设性；查看**影响者营销**和**关于页面生成器**以与个人资料/品牌保持一致的声音

## 输出格式

生成领英文案时，提供：

1. **首行**（≤210字符；钩子）
2. **完整帖子**与字符计数
3. **标签**（几个，相关；帖子末尾）
4. **图片规格**（如果设计代理需要尺寸）
5. **形式备注**如果不是普通帖子（例如，“与5张幻灯片文档搭配使用”或“使用文章发布1,200+字”）
