# 平台：YouTube SEO

指导YouTube视频和频道优化以实现搜索和发现。**Google现在优先考虑YouTube视频搜索结果**；YouTube + Reddit约占AI概述中社交媒体引用的~78%。标题、描述和缩略图形成一个相互关联的系统；使用系统化关键词策略的频道观看时长延长156%，CTR提升89%，搜索发现率提高312%。在优化视频以供YouTube搜索、Google搜索和AI引用时使用此技能。有关嵌入式视频SEO，请参阅**video-optimization**。

**调用时**：在**首次使用**时，如果有帮助，先用1-2句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接进入主要输出。

## 初步评估

**首先检查项目背景**：如果存在`.claude/project-context.md`或`.cursor/project-context.md`，请阅读第6节（关键词）、第11节（内容策略）。

识别：
1. **视频类型**：教程、评测、Vlog、Shorts
2. **目标关键词**：主要和次要
3. **受众**：订阅者与随意观看者

## 视频标题

| 规则 | 指南 |
|------|-----------|
| **长度** | 60个字符以内；移动端可能显示部分 |
| **关键词** | 主要关键词在前5-55个字符内 |
| **结构** | 社会证明/权威 + 情感触发 + 主要关键词 |
| **风格** | 对话式；避免关键词堆砌 |
| **避免** | 除强调外，避免全大写 |

## 视频描述

| 规则 | 指南 |
|------|-----------|
| **前2-3句话** | 自然包含主要和次要关键词；元描述不超过160字符 |
| **链接** | 网站、商店、相关资源 |
| **可读性** | 自然流畅；帮助搜索引擎理解主题 |

## 标签

- 帮助YouTube理解内容；标题和描述更重要
- 使用相关标签；避免过度优化

## 缩略图

90%表现最佳的视频使用自定义缩略图。

| 规则 | 指南 |
|------|-----------|
| **对比度** | 高对比度；易读字体；醒目颜色 |
| **构图** | 三分法；简单、不杂乱 |
| **受众** | 考虑订阅者与随意观看者 |
| **测试** | 有效策略会演变；测试风格 |

## 标题 + 描述 + 缩略图

在三者中强化相同的核心信息；针对不同的算法方面。

## 输出格式

- **标题**选项（60个字符以内）
- **描述**（前160字符 + 完整）
- **标签**（相关集合）
- **缩略图**指导（元素、文字、构图）

## YouTube在Google搜索 & GEO

| 背景 | 含义 |
|---------|-------------|
| **Google优先级** | YouTube是核心搜索基础设施；月访问量48.6B；视频结果在主SERP、视频模式、Discover中受青睐 |
| **AI概述** | 自2025年1月以来，YouTube引用量激增25.21%；指导性(+35.6%)、视觉演示(+32.5%)；长视频（94%）占主导 |
| **GEO** | YouTube + Reddit = ~78%的社交媒体引用；优化AI引用。参见**generative-engine-optimization** |
