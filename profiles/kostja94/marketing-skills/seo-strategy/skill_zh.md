# 策略：SEO

SEO策略指南：工作流程顺序、优先级、产品导向SEO以及何时使用何种技能。在从零开始规划SEO、审计现有网站或决定下一步做什么时，使用此技能。

**调用时机**：在**首次使用**时，如果有助于理解，先用1-2句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接提供主要输出。

## 战略背景：为何要SEO

| 价值 | 理由 |
|------|------|
| **流量控制** | ~68%的初始网络流量来自搜索；搜索聚合了大多数用户意图 |
| **增长渠道** | ~87%的消费者在发现新类别时倾向于使用Google；43%的转化来自自然搜索（相对于~11%的社交） |
| **成本效益** | SEO用户LTV是付费广告的3-5倍；排名第一的点击率~27.6%，而第十名~2.4% |
| **长期资产** | 高质量的SEO资产可带来3-5年的流量；核心网络指标与转化相关（例如，每快0.1秒+8%） |

**SEO = Google优化**：Google占据~91%的全球搜索份额；B2B买家将搜索作为研究起点。首先优化Google；有关非Google市场的**本地化策略**，请参阅**localization-strategy**。

**参考**：[Alignify – AI搜索时代SEO核心价值和挑战](https://alignify.co/zh/insights/reasons-you-need-seo)

## 何时投资SEO

| 阶段 | 建议 |
|------|------|
| **冷启动** | 使用邮件、广告或影响者获取首批用户；SEO需要时间（沙盒期，6个月以上） |
| **PMF之后** | SEO可扩展；与付费广告结合以获得更快反馈；请参阅**pmf-strategy**、**paid-ads-strategy** |
| **团队** | 许多中小企业使用承包商；SEO涵盖内容、链接、技术、用户体验——在扩展时组建全职团队 |

**原则**：不要为了SEO而SEO；不要与Google规则对抗；优先考虑真实的用户体验。

## AI搜索时代与渠道整合

| 挑战 | 响应 |
|------|------|
| **零点击、AI概述** | ~30%的点击进入Google自有资产；AI概述占SERP的12-15%；TOFU（什么/为什么/如何）的CTR下降 |
| **算法波动** | 每年5000多次更新；流量波动常见；专注于有帮助的内容，E-E-A-T |
| **响应** | 将SEO提升到**搜索体验优化**——以用户为中心，而非排名为中心；请参阅**generative-engine-optimization**以实现AI可见性 |

**渠道整合**：SEO + 广告（验证关键词，再营销）；SEO + 影响者（反向链接，提及）；SEO + 社交媒体（UGC，嵌入内容）。插件/应用程序：功能链接回网站。

## 工作流程顺序

**在优化页面之前修复基础。** 按照以下顺序执行：

| 阶段 | 重点 | 技能 |
|------|------|------|
| **1. 技术** | 可爬取性、索引、站点地图 | robots.txt、xml-sitemap、canonical-tag、索引、indexnow、site-crawlability |
| **2. 页面内** | 元数据、结构、模式 | title-tag、meta-description、page-metadata、schema-markup、internal-links、url-structure、heading-structure |
| **3. 内容** | 关键词、集群、优化 | keyword-research、content-strategy、content-optimization |
| **4. 页面外** | 反向链接、权威性 | link-building、backlink-analysis |

技术问题会阻塞索引和爬取；页面内问题会限制内容排名；内容和页面外会随时间建立权威性。

## 产品导向SEO

SEO利用你已经拥有的内容——品牌、功能、场景、输入、输出、提示、流程、知识——以结构化的方式发布。即使没有SEO，你也会展示产品功能；SEO使这些内容能够为你带来流量。

**原则**：围绕产品/用户进行SEO，而不是围绕行业/搜索引擎。

### 适合SEO的产品类型

| 类型 | 原因 |
|------|------|
| **工具** | 用户有明确的使用案例和需求 |
| **内容** | 用户有明确的信息需求 |
| **电子商务** | 用户有明确的购买需求 |
| **服务** | 用户有明确的服务需求 |

**Agent/Copilot产品**：纯原生Agent难以通过SEO增长；用户很少搜索“agent”。首先发布相关功能（例如，CRM、销售代理的销售机器人）以建立流量，然后引导至Agent产品。请参阅**keyword-research**进行产品定位测试。

## SEO审计方法

| 场景 | 顺序 | 重点 |
|------|------|------|
| **新网站** | domain-selection → website-structure → 技术 → 页面内 → 内容 | 首先选择域名（如果需要）；规划页面；建立基础；添加内容 |
| **现有网站** | 技术审计 → 页面内审计 → 内容差距 → 页面外 | 首先修复爬取/索引问题；然后元数据、模式；然后内容差距；然后链接 |
| **低流量** | keyword-research → content-strategy → content-optimization | 通常内容或意图不匹配 |
| **未索引** | 索引、robots.txt、site-crawlability | 技术障碍 |

## SEO路线图优先级

| 优先级 | 含义 | 示例 |
|------|------|------|
| **P0** | 阻塞项——优先修复 | 爬取性、索引、robots.txt阻塞 |
| **P1** | 核心——尽快执行 | Title、meta、模式、站点地图、内部链接 |
| **P2** | 重要——但不紧急 | Open Graph、Twitter Cards、IndexNow |
| **P3** | 可选 | 富结果、站点链接优化 |

## 付费-自然搜索协同

SEO和PPC共享同一SERP——广告、AI概述、视频、自然链接。如果没有协同，你可能会面临重复、蚕食和浪费支出。**共享关键词数据**：使用**keyword-research**进行两者；使用**google-ads**进行搜索定位。PPC转化数据可以优先考虑SEO关键词；有机排名4+可能减少对这些术语的PPC需求。

**参考**：[Backlinko – SEO和PPC：8种智能协同方式](https://backlinko.com/seo-and-ppc)

## 相关技能

- **domain-selection**：初始域名选择（品牌/PMD/EMD，TLD）；在新网站之前进行
- **website-structure**：规划要构建的页面；在技术阶段之前或与之一同进行
- **keyword-research**：发现；指导内容策略、内容优化和google-ads
- **google-ads, paid-ads-strategy**：付费-自然搜索协同；冷启动；PPC数据用于SEO优先级
- **pmf-strategy**：在扩展SEO之前验证PMF；冷启动使用其他渠道
- **content-strategy**：主题集群、支柱页面；内容规划
- **programmatic-seo**：基于模板的扩展；手动内容的替代方案
- **parasite-seo**：高权威平台；自有网站SEO的替代方案
- **generative-engine-optimization**：AI搜索可见性；补充传统SEO
- **localization-strategy**：多语言SEO
- **domain-architecture**：域名结构（子文件夹/子域名/独立）；在多个产品时进行或与网站结构一同进行
- **rebranding-strategy**：域名变更、301重定向；在品牌重塑时使用
- **multi-domain-brand-seo**：当Hub和Spoke域共存时控制品牌搜索
