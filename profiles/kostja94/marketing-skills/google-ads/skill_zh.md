# 付费广告：谷歌广告

提供谷歌广告设置、广告活动结构、关键词定位和优化的指南。谷歌广告擅长高意向搜索流量；当用户主动搜索您的解决方案时使用。

**调用时机**：在**首次使用**时，如果有帮助，先用1-2句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接进入主要输出。

## 两种模式：PMF测试与转化驱动

| 模式 | 使用时机 | 预算 | 落地页 | 指标 |
|------|------|------|--------------|---------|
| **PMF测试** | 预PMF阶段；在构建产品前验证想法 | $47–500；从小规模开始 | 简单LP：标题、利益点、解决的问题、CTA（“加入等待名单”、“获取早期访问权限”） | 点击率、注册率、跳出率；低点击率/高跳出率 = 消息传递/定位问题 |
| **转化驱动** | PMF验证后；商业化 | 扩张；ROAS目标 | 全流程；广告与页面一致性 | ROAS、CAC、转化率 |

**PMF测试**：无需完整产品。使用Unbounce、Carrd或Webflow构建落地页。运行广告到相关搜索词；衡量点击量、参与度、注册量。测试消息传递（例如，“自由职业者最快应用”vs“团队最简单时间追踪器”）、定价（广告/LP中的不同价格点）、受众（关键词定位、市场定位）。允许4-6周的PMax学习阶段。将其作为学习工具，而不仅仅是营销渠道。

**参考**：[Marketing Cactus – Using Google Ads to Test Product-Market Fit](https://mktcactus.com/en/using-google-ads-to-test-product-market-fit-before-launching/)

## 广告活动结构

```
账户
├── 广告活动：品牌（搜索）
├── 广告活动：非品牌（搜索）
├── 广告活动：竞争对手（搜索）—可选；对竞争对手品牌+“替代品”/“vs”进行出价
├── 广告活动：再营销（展示）
└── 广告活动：性能最大
```

### 竞争对手品牌关键词

**使用时机**：对"[竞争对手]替代品"、""[竞争对手] vs [你]"进行出价，以拦截高意向流量。谷歌允许竞争对手术语作为关键词；未经许可，您不能在广告文案中使用竞争对手名称。

**落地页**：使用**专用落地页**（比较/替代品页面），而不是博客文章。搜索竞争对手品牌的用户期望直接替代品——博客会增加跳出率；比较页面与意向匹配，转化效果更好。参考**alternatives-page-generator**了解结构。

**最佳实践**：
- 单独创建广告活动；精确/短语匹配；添加您的品牌作为否定关键词
- H1与搜索意向一致（例如，"[竞争对手] vs [你]"）
- 特性比较表；一句话差异化；强力CTA
- 预期质量得分较低，CPC较高；优化LP相关性

**命名**：`GOOG_[目标]_[受众]_[产品]_[日期]`（例如，`GOOG_Search_Brand_Demo_Ongoing`）

## 广告活动类型

| 类型 | 适合场景 |
|------|----------|
| **搜索** | 高意向查询；关键词定位；落地页至关重要 |
| **展示** | 提高知名度；再营销；更广泛的覆盖范围 |
| **YouTube** | 视频；提高知名度；考虑 |
| **性能最大** | 自动化；跨渠道；商品+搜索+展示 |

## 性能最大（PMax）优化

**学习期**：至少运行**6周**以使算法逐步提升。最好作为搜索的补充，而不是替代。

**资产组**：按*受众意向*（例如，高意向搜索者、购物车放弃者、类别研究者）组织，而不仅仅是按产品类别。受众信号比无信号提高CPA和ROAS。

**资产要求**（每个资产组）：
- ≥5张图片（包括1200×1200）
- ≥5个文本资产（4个标题，5个描述）
- 尽可能使用视频
- 定期刷新创意以保持性能

**信号**：添加再营销列表和Customer Match以加速学习。

**每周健康检查**：如果品牌术语>30%的转化；意外的地理转化；任何位置>15%的总支出；资产组性能低于“良好”，请标记。

## 关键词策略

- **品牌**：保护品牌术语；排除非品牌活动
- **否定关键词**：每周构建；避免不相关的查询。添加**支持术语**（登录、论坛、定价、帮助）从**keyword-research**——这些是现有客户，而不是潜在客户。
- **匹配类型**：广泛（发现）→ 短语 → 精确（控制）

**关键词来源**：使用**keyword-research**获取关键词列表、群组、意向。将每个群组映射到专用落地页；相关性提高质量得分并降低CPC。

## 质量得分杠杆

| 因素 | 行动 |
|------|------|
| 预期点击率 | 提高广告相关性；测试标题 |
| 广告相关性 | 使广告文案与关键词意向一致 |
| 落地页 | 广告与页面一致性；快速加载；移动友好 |

**目标**：质量得分≥6；越高=更低CPC，更好的广告排名。**基准**：将质量得分从5提高到7可以降低30-50%的CPC。

## 出价策略

| 每月转化量 | 策略 |
|-------------------|----------|
| <30 | 手动CPC（智能出价需要足够量级才能优化） |
| 30–50 | 目标CPA；智能出价有效的最低量级 |
| 50–100 | 目标CPA |
| 100+ | 目标ROAS |

**智能出价**：AI驱动的出价（目标CPA、目标ROAS）在转化量足够时通常比手动提供更好的ROI；需要≥30次转化在30天内才能有效工作。

## 跟踪

- **增强转化**：服务器端信号以更好地进行归因
- **离线转化导入**：B2B；CRM → 谷歌广告
- **UTM**：GA4跨检查的一致参数

## 付费-自然搜索蚕食

当您在关键词上自然排名（位置4+）并且也运行PPC时，付费广告可能会吸收原本会流向自然搜索的点击。**审计**：交叉参考GSC自然搜索排名与搜索词报告。如果自然搜索排名良好，测试暂停这些词的PPC，以释放预算用于更高影响力的关键词。

**参考**：[Backlinko – SEO and PPC: 8 Smart Ways to Align](https://backlinko.com/seo-and-ppc)
