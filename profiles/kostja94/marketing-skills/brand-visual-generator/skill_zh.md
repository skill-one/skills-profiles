# 组件：品牌视觉识别

为一致的品牌呈现提供视觉识别指南。拥有一致品牌形象的公司可看到高达23-33%的收入增长；94%的消费者表示一致性会影响购买决策。

**关键词**：视觉识别、设计令牌、色彩搭配、字体排印、CSS变量、演示文稿、品牌指南、前端美学、无障碍设计

**调用时机**：在**首次使用**时，如果有助于理解，可先以1-2句话概述此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或当用户要求跳过时，直接提供主要输出。

## 初步评估

**首先检查项目背景**：如果存在`.claude/project-context.md`或`.cursor/project-context.md`，请阅读第12节（视觉识别），了解颜色、字体排印和间距。参考**品牌化**了解品牌策略和视觉识别策略层。

识别：
1. **范围**：新品牌、审计或组件设计
2. **触点**：网络、印刷、社交、产品界面、**幻灯片**（PowerPoint、Google Slides、Keynote）、**文档**（Word、Google Docs、PDF报告）
3. **现有资源**：标志、风格指南、设计文件

## 最佳实践

### 字体排印

- **两字体系统**：一个用于标题的展示字体，一个用于文本的正文字体。对比与和谐：差异足够明显以区分角色，相似足够以保持整体感。
- **正文字体**：优先考虑易读性——大x高度、开放的反白空间。对于中性/安全：Source Sans 3、Lora、IBM Plex Sans。**对于独特性**：避免过度使用的AI字体（Inter、Roboto、Arial、系统字体）；优先选择具有特色的字体选择，提升品牌形象。参考**前端美学**。
- **标题字体**：传达品牌声音；必须在不到一秒内可读。承载个性，而正文处理基础设施。
- **字体比例**：使用1.25–1.5（大三度或纯五度）的比例建立层级。每个区块限制为3–4种样式。
- **搭配规则**：装饰性字体仅与中性字体搭配。分配不同角色；避免混合超过两种字体家族。
- **尺寸**：英雄、章节、副标题、正文、说明文字；响应式缩放。行长最大120字符；行间距宽裕。

### 色彩搭配

- **结构**：主要色、次要色、行动召唤（CTA）、背景色、文字色。使用灵活的系统（核心英雄色+互补色），而不是单一固定的颜色。
- **行业映射**：金融→蓝色、灰色、海军蓝（稳定性）；奢侈品→玫瑰金、酒红、黑色（排他性）；科技→蓝绿色、霓虹点缀、煤灰（创新）；健康→薰衣草、桃色、薄荷（平静）；可持续性→鼠尾草绿、大地色系。
- **再现**：HEX、RGB、CMYK用于印刷和数字。对于**程序化幻灯片**（例如python-pptx），将品牌HEX映射到RGB元组`(R, G, B)`用于填充和文字；在交付物中保留一个单一的来源真相表（HEX + RGB）。
- **无障碍设计**：普通文本对比度≥4.5:1，大文本（18px+或14px+粗体）≥3:1，交互元素≥3:1。不要仅依赖颜色传递信息。

### 间距

- **外边距**：水平（例如120px）、垂直章节填充
- **网格**：一致的间距比例（8px基础常见）
- **标志清晰空间**：标志周围的最低空间；记录在品牌指南中

### 标志使用

- **变体**：主要、次要、徽标；亮色/暗色背景
- **最小尺寸**：防止难以辨认
- **不要**：拉伸、重新着色、未经批准添加效果

### 应避免的反模式

- **美学优先于功能性**：不要为了视觉效果而牺牲可用性。
- **不明确的CTA**：每个章节限制为一次主要CTA；视觉区分主要与次要。
- **不一致的元素**：像素化图标、间距/字体排印/色彩不匹配会降低信任度。
- **糟糕的文本层级**：无序、杂乱的文本会使用户困惑。
- **过度使用效果**：阴影、弹出窗口、拥挤的UI会分散对内容的注意力。
- **盲目追逐潮流**：仅在符合项目需求时才采用潮流。
- **忽视性能**：重型资源和复杂布局会降低加载时间。
- **通用AI美学**：Inter、Roboto、Arial、Space Grotesk和系统字体导致千篇一律的设计；避免陈词滥调的方案（例如白色上的紫色渐变）。当品牌差异化很重要时，优先选择独特的选项。
- **使用表情符号作为图标**：使用SVG图标（Heroicons、Lucide、Simple Icons）——永远不要使用表情符号（🎨 🚀 ⚙️）作为UI图标；表情符号看起来不专业且不一致。
- **不稳定的悬停状态**：使用颜色/不透明度过渡悬停；避免缩放变换导致布局偏移或内容跳跃。

### 无障碍设计检查清单

- **对比度**：普通文本≥4.5:1；大文本≥3:1；交互元素≥3:1。
- **焦点**：可见的焦点指示器（≥2px实线，3:1对比度）；逻辑的Tab顺序；无键盘陷阱。
- **色彩**：永远不要仅使用颜色传递信息；为状态（错误、成功）添加文字或图标。
- **键盘**：所有交互元素可通过Tab、Enter、Spacebar访问。
- **减少动画**：尊重`prefers-reduced-motion`动画。

## 前端美学

指导独特、生产级的前端实现。组件（英雄、CTA、页脚等）和页面（着陆页、主页、功能页）应参考这些原则进行视觉差异化。**意图重于强度**：大胆的极简主义和精致的极简主义在精确执行时都有效。

### 字体排印

- **避免通用AI字体**：Inter、Roboto、Arial、系统字体、Space Grotesk。这些会创建千篇一律的视觉效果。
- **独特搭配**：一个展示字体（标题、个性）+一个精致的正文字体（易读性）。选择具有特色、意想不到的字体，提升界面。
- **一致性**：使用CSS变量；每个区块限制为3–4种字体样式。

### 动画

- **高冲击时刻**：一个精心编排的页面加载，使用交错延迟(`animation-delay`)比分散的微交互更能带来愉悦感。
- **优先级**：HTML使用纯CSS；当可用时，React使用动画库。滚动触发和悬停状态令人惊喜。
- **无障碍设计**：始终尊重`prefers-reduced-motion`；提供减少或无动画的替代方案。

### 空间构图

- **意想不到的布局**：不对称、重叠、对角线流动、打破网格的元素。
- **平衡**：宽裕的负空间或受控的密度——有意为之。
- **层级**：清晰的视觉流程；避免可预测、均匀分布的布局。

### 背景 & 视觉细节

- **氛围重于扁平**：创建深度，而不是默认使用纯色。
- **技术**：渐变网格、噪点纹理、几何图案、分层透明度、戏剧性阴影、装饰性边框、颗粒覆盖。
- **上下文**：匹配效果以匹配整体美学；不要分散对内容的注意力。

### 永远不要

- 过度使用的字体家族（Inter、Roboto、Arial、系统字体）
- 陈词滥调的配色方案（例如白色上的紫色渐变）
- 可预测的布局和千篇一律的组件模式
- 缺乏特定上下文个性的设计
- 使用表情符号作为UI图标（使用SVG：Heroicons、Lucide、Simple Icons）

## AI品牌美学（可选）

对于AI/SaaS产品，考虑这些视觉趋势和品牌原型；有意识地采用、忽略或反其道而行，以避免千篇一律。

### 视觉趋势

| 趋势 | 信号 |
|------|------|
| **米白/米色** | 信任、克制、高级感无光泽 |
| **有机渐变** | 独特性；添加颗粒、纹理 |
| **数字印象派** | 情绪重于文字；暗示性而非描述性 |
| **Lomo/不完美** | 探索性、人类创造力 |
| **当代写实** | 精确性、可靠性、精通 |
| **草图/涂鸦** | 人类思考、探索重于确定性 |
| **非品牌学术** | 权威；作品自证 |
| **技术插图** | 严谨性、工程深度 |
| **古怪可爱** | 亲和力；对抗末日叙事 |
| **变形物体** | 新生、学习系统 |
| **未来主义超现实主义** | 新世界的大门 |
| **外太空** | 探索、未知 |
| **ASCII/像素** | 复古、俏皮、技术 |
| **生成艺术** | 算法化、活系统 |

### 品牌原型

| 原型 | 语气 | 视觉 |
|------|------|------|
| **受欢迎的领导者** | 严肃性、稳定性、信任 | 淡灰色、暖米色；印象派 |
| **温和的人本主义者** | 技术重于人文 | 手绘、日常瞬间、自然 |
| **技术狂理想主义者** | 工程文化 | 不完美、古怪、非品牌 |
| **大胆建设者** | 开创性、变革性 | 暗色调、太空参考 |
| **乌托邦梦想家** | 可能实现什么 | 复古未来主义、超现实世界 |

## 幻灯片 & 文档（非网络）

当用户要求**演示文稿或文档**品牌化时——不仅仅是网站：

- **幻灯片母版**：背景色来自令牌；标题字体=展示/标题令牌；正文=正文令牌；默认标题/正文尺寸与**品牌化**/第12节的字体比例对齐。
- **主题颜色**：将主要色、次要色、背景色、文字色和一个强调色映射到演示应用程序的主题（PowerPoint *设计→变体*，Google Slides *主题*，Keynote *文档*设置），使形状和图表继承调色板。
- **图表 & 形状**：以固定顺序循环强调色（例如主要色→次要色→三级），而不是随机颜色；保持演示文稿的品牌一致性。
- **文档**：尽可能与网络使用相同的字体和标题层级；指定段落样式名称（标题、标题1–3、正文）与点大小和颜色。

策略和叙事层保持在**品牌化**中；本节是**视觉执行**，适用于办公/幻灯片工具。

## 品牌指南结构（单一真相来源）

确保跨触点的一致性。包括：

- **标志**：使用规则、清晰空间、最小尺寸、变体（亮色/暗色）
- **颜色**：主要色、次要色、CTA、背景色、文字色（HEX、RGB、CMYK）
- **字体排印**：字体家族、层级、尺寸、间距
- **图像**：摄影色调、主题、视觉氛围
- **图标**：风格、笔画粗细、使用规则

## 输出格式

- **字体排印**规范（字体、粗细、尺寸、颜色）
- **色彩**调色板（HEX、使用规则、行业映射）
- **间距**比例
- **标志**清晰空间和变体
- **前端美学**（可选）：动画、空间构图、背景——用于独特实现
- **反模式**和无障碍设计检查清单
- **AI产品**（可选）：视觉趋势和原型对齐
- **上下文模板**用于项目上下文第12节
- **幻灯片/文档**（当请求时）：主题映射+母版字体排印+图表强调色顺序
