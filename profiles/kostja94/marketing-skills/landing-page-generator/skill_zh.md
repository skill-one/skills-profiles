# 页面：着陆页

指导着陆页的结构、转化流程和优化。**主要用途**：**付费广告（PPC/SEM）** — 着陆页通常用于接收付费流量；广告与页面的匹配对于转化至关重要。参见 **paid-ads-strategy** 了解何时使用付费广告和广告与页面匹配原则。也适用于联盟营销注册、产品发布、线索捕获、网络研讨会注册和其他单一目标转化页面。**规模**：当构建许多着陆页（特定城市、特定产品、特定集成）时，使用 **programmatic-seo**（模板+数据）和 **template-page-generator** 进行模板设计。与主页（多用途）和产品页面（目录）不同。

**调用时机**：在 **首次使用** 时，如果有帮助，先用1-2句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在 **后续使用** 或用户要求跳过时，直接进入主要输出。

## 付费广告：着陆页要求

当着陆页接收付费流量时：页面立即显示广告承诺；移动优先（CTA在视窗上方，快速加载）；最小化表单（字段较少）；视窗上方建立信任。参见 **paid-ads-strategy** 了解完整的广告与页面匹配和Quality Score。

## 初步评估

**首先检查项目背景**：如果存在 `.claude/project-context.md` 或 `.cursor/project-context.md`，请阅读它以了解产品、受众和价值主张。

识别：
1. **页面目标**：注册、购买、线索捕获、网络研讨会、下载
2. **流量来源**：付费广告、邮件、联盟营销、自然流量
3. **受众**：冷受众与热受众；如果已知，请细分

## 着陆页结构（五步流程）

| 步骤 | 目的 | 元素 |
|------|---------|----------|
| **1. 停止滚动** | 在约2.6秒内吸引注意力 | 标题、副标题、英雄图片或视频 |
| **2. 建立信任** | 在提出要求之前提供社会证明 | Logo、客户评价、评分、客户数量 |
| **3. 解释价值** | 优点、功能、用例 | 清晰的文案；为谁、做什么 |
| **4. 消除疑虑** | 处理反对意见 | 常见问题解答、保证、比较 |
| **5. 提出要求** | 单一主要CTA | 一个明确的行动；在逻辑位置重复 |

每个元素都应服务于这五个功能之一。具有多个竞争性供应的页面会减少约266%的线索。

## 标题公式

**[为谁]** + **[具体结果]** + **[时间/限定词]**

- **避免**：抽象的承诺（“释放你的潜力”、“改变你的业务”）
- **优先**：具体的（“将发票处理时间缩短70%—无需新软件”）

## CTA最佳实践

- **一个主要CTA**：没有竞争性行动；创建一个“单向街道”指向转化
- **在移动端视窗上方**：拇指可触达；约65%以上的流量来自移动端
- **价值导向的文案**：“开始免费试用”而不是“提交”
- **与信任信号配对**：客户数量、Logo或统计数据紧邻按钮
- **移除或最小化导航**：可以增加2-28%的转化率

## 程序化着陆页（规模）

当您需要 **许多着陆页**（例如，特定城市、特定产品、特定集成）时，使用 **programmatic-seo**：一个模板+数据=数百或数千个LP。将着陆页结构（五步流程、CTA、信任）应用于模板；参见 **template-page-generator** 进行模板设计。示例："[产品] for [城市]" LPs使用本地数据；"[应用A] + [应用B]"集成注册页面。

## 页面类型

| 类型 | 用途 | CTA目标页面 |
|------|-----|-----------------|
| **点击通过** | 在发送到供应之前预热受众；最适合SaaS、订阅 | pricing-page, products-page, signup |
| **线索捕获** | 收集电子邮件进行培育；表单5个或更少字段（较长的表单会导致约81%的放弃） | newsletter-signup, contact-page |
| **产品导向** | 深入了解功能和优势；产品发布 | products-page, features-page |
| **比较** | X与Y；竞争对手品牌关键词广告；商业意图 | alternatives-page, features-page, pricing-page |
| **用例/解决方案** | 对于难以拆分为工具的集成产品 | features-page, services-page |
| **免费工具** | 独立实用工具；线索生成；相同ICP；摘自产品 | tools-page-generator；当受限制时，工具页面作为LP |
| **桥梁/奖金** | 通过您的链接购买额外激励 | pricing-page, products-page |
| **网络研讨会/活动** | 活动注册；在直播前收集注册 | resources-page（网络研讨会作为资源） |

## 着陆页 ↔ 页面类型（内容与流程）

**从以下内容中提取**（步骤2-4）：
- **customer-stories-page-generator**：客户评价、案例研究用于社会证明；挑战→解决方案→结果片段
- **faq-page-generator**：反对意见处理常见问题解答部分；重用与转化相关的问答
- **features-page-generator**：以优点为先的功能文案用于“解释价值”步骤
- **resources-page-generator**：作为交换的电子邮件磁铁（电子书、模板）；网络研讨会作为资源

**CTA发送到**：
- **pricing-page-generator**：点击通过LP → pricing；signup, trial
- **products-page-generator**：产品LP → 产品详情或目录
- **services-page-generator**：服务LP → 联系、报价、预订
- **contact-page-generator**：线索捕获LP → 联系表单；B2B演示请求
- **affiliate-page-generator, creator-program**：合作伙伴注册=着陆页类型

**内部链接**：
- 链接LP到 **homepage**（品牌锚点）；**about-page**（信任）；**privacy-page**（表单合规）
- 避免孤儿LP：确保至少有一个来自站点地图、导航或活动中心的内部链接

## 性能和设计

- **加载时间**：少于2.5秒；每多一秒可能损失约7%的转化率
- **移动优先**：响应式；无需滚动即可看到CTA
- **视觉效果**：英雄图片或视频可以提高转化率高达80%
- **前端美学**：对于独特的字体、动画、空间布局、背景——参见 **brand-visual-generator** Frontend Aesthetics
- **披露**：在适用情况下遵守FTC合规的联盟营销/付费披露

## 交付前检查清单

在交付着陆页之前，请验证：

| 类别 | 检查 |
|------|-------|
| **视觉** | 不要使用表情符号作为图标（使用SVG）；使用一致的图标集（Heroicons/Lucide）；悬停状态不会导致布局偏移 |
| **交互** | 所有可点击元素都有 `cursor-pointer`；悬停提供清晰的反馈；过渡时间为150-300ms |
| **可访问性** | 图片有替代文本；表单输入有标签；颜色不是唯一的指示；`prefers-reduced-motion`得到尊重 |
| **布局** | 移动端没有水平滚动；内容不在固定导航后面隐藏；在375px、768px、1024px处响应式 |
| **性能** | 加载时间少于2.5秒；LCP优化；图片使用WebP/懒加载 |
| **图片** | 参见 **image-optimization** 进行alt、格式、响应式、懒加载 |

## 输出格式

- **标题** 和副标题
- **结构**（五步流程部分）
- **信任信号** 位置
- **CTA** 文案和位置
- **反对意见处理**（常见问题解答、保证）
- **内部链接**（目标页面）
- **SEO** 元数据（如果页面被索引）
