# 内容：视觉内容

指导网站、社交媒体、电子邮件和其他渠道的视觉内容规划和创作。图像不仅适用于网站——社交帖子、信息图表和再利用的内容都需要视觉元素。在内容日历中进行以视觉为先的规划可以提高参与度；跨渠道一致性和再利用可以最大化投资回报率。

**调用时机**：在**首次使用**时，如果有助于理解，可以先用1-2句话说明这项技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**时或当用户要求跳过时，直接进入主要输出。

## 范围

- **使用图像的时机**：根据内容类型和格式
- **根据场景的规格**：网站与社交媒体与电子邮件
- **平台图像规格**：X（推特）、领英、Pinterest、Instagram、Facebook、YouTube
- **再利用**：一个视觉元素 → 多种格式和渠道
- **以视觉为先的规划**：包含图像规划的内容日历

## 1. 使用图像的时机

| 内容类型 | 视觉需求 | 备注 |
|----------|----------|------|
| **文章 / 博客** | 主图、文章内图像、截图 | 参见 **image-optimization**（网络图像优化，alt、WebP、LCP） |
| **社交帖子** | 单个图像、轮播图或链接预览 | 以下为各平台特定规格 |
| **信息图表** | 主要格式；数据可视化 | 再利用为社交（裁剪）、博客（完整） |
| **案例研究** | 客户照片、结果图表、标志 | 再利用为领英轮播图、博客 |
| **产品更新** | 截图、功能图形 | 更新日志、电子邮件、社交 |
| **电子邮件** | 头图、内联图形 | 保持轻量级；许多客户会阻止图像 |
| **着陆页** | 主图、信任徽章、截图 | 参见 **hero-generator**、**image-optimization** |

## 2. 网站与社交媒体与电子邮件

| 场景 | 优先级 | 技能 |
|------|--------|------|
| **网站** | alt文本、WebP、LCP、响应式、懒加载 | **image-optimization** |
| **社交帖子** | 平台尺寸、宽高比、文件大小 | **平台技能**（X、领英、Pinterest等） |
| **OG / Twitter Cards** | 1200×630、1200×675（链接预览） | **open-graph**、**twitter-cards** |
| **电子邮件** | 内联友好；避免大图像；为被阻止的图像添加alt | **email-marketing** |

## 3. 平台图像规格（社交媒体）

| 平台 | 帖子图像 | 故事 / Reels | 个人资料 | 备注 |
|------|----------|--------------|----------|------|
| **X（推特）** | 1200×675（16:9）、800×800 | — | 400×400 | 参见 **twitter-x-posts** |
| **领英** | 1200×627、1200×1200；轮播图最多20张 | — | 400×400 | 参见 **linkedin-posts**；移动端偏好垂直格式 |
| **Pinterest** | 1000×1500（2:3） | — | 165×165 | alt文本可提升25%曝光率；参见 **pinterest-posts** |
| **Instagram** | 1080×1350（4:5）、1080×1080 | 1080×1920（9:16） | 320×320 | 4:5在信息流中表现优于方形 |
| **Facebook** | 1200×630、1080×1080 | 1080×1920 | 320×320 | |
| **YouTube** | 缩略图 1280×720 | — | 800×800 | |

**通用**：1080px宽度适用于大多数平台；垂直（4:5、9:16）在移动优先的信息流中表现优于方形。将关键元素（标志、文本）置于安全中心——平台可能会裁剪。

## 4. 视觉再利用

**原则**：一个核心视觉元素 → 多种裁剪/格式 → 多种渠道。

| 核心视觉元素 | 调整 | 渠道 |
|-------------|------|------|
| **信息图表** | 完整（博客）、裁剪部分（Instagram、领英轮播图）、方形（X） | 博客、领英、Instagram、X |
| **案例研究图形** | 主图（博客）、单页（领英）、故事（Instagram） | 博客、领英、Instagram |
| **产品截图** | 主图（着陆页）、帖子（X、领英）、邮件头图 | 网站、社交、电子邮件 |
| **引言图形** | 方形（X、领英）、4:5（Instagram） | X、领英、Instagram |

**工作流程**：在最大需求尺寸下设计；导出平台特定裁剪。使用一致的颜色、字体、标志位置（参见 **brand-visual-generator**）。

---

## 5. 以视觉为先的内容规划

- **在内容日历中规划图像**：不要将视觉元素作为事后补充；视觉元素驱动参与度
- **按主题批量处理**：围绕主题集群或活动集中创建视觉元素，以保持一致性
- **再利用列**：在日历中标注哪个核心元素将成为哪个渠道的哪种视觉格式
- **资源库**：按活动/主题组织；标记以便重用

---

## 6. 格式特定备注

### 信息图表

- **尺寸**：800–1200px宽度；高度根据内容变化
- **导出**：PNG用于网络；PDF用于下载
- **再利用**：切片为3–5页用于领英轮播图；单个数据用于X/Instagram

### 社交帖子图像

- **文字叠加**：保持最小；许多平台弃用文字密集型图像
- **品牌化**：标志在角落；与 **brand-visual-generator** 保持一致
- **alt文本**：为领英、Pinterest、X添加（无障碍+Pinterest SEO）；参见 **image-optimization** 的alt最佳实践

### 文章 / 博客图像

- **主图**：通常是LCP候选；按 **image-optimization** 优化
- **文章内图像**：支持叙事；alt文本、说明按 **image-optimization**
- **截图**：有助时标注；保持文件大小低
