# SEO: 本地

本地SEO指南：Google商家资料、NAP一致性以及引文建设。在40多个权威网站上拥有准确NAP信息的商家，在Google地图上的可见度可提高约19%。在优化本地搜索、设置GBP或审核引文时，使用此技能。

**调用时**：在**首次使用**时，如果有帮助，先用1-2句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接提供主要输出。

## 初步评估

**首先检查项目背景**：如果存在`.claude/project-context.md`或`.cursor/project-context.md`，则阅读第4节（受众）和第5节（网站）。

识别：
1. **业务类型**：店面型 vs 服务区域型
2. **位置**：单一或多个
3. **当前列表**：现有的GBP、目录

## NAP一致性

**NAP** = 名称、地址、电话。对本地排名至关重要。

| 规则 | 指南 |
|------|------|
| **完全匹配** | "Street"与"St."或"LLC"不一致 = Google可能将它们视为不同实体 |
| **优先修复** | 在添加新的引文之前，先审计和修复不一致性 |
| **工具** | BrightLocal、Whitespark、Moz Local用于审计 |

## Google商家资料

| 元素 | 指南 |
|------|------|
| **地址** | 实际地址；无邮政信箱 |
| **描述** | 750个字符；主要关键词在前100个字符内 |
| **营业时间** | 准确；季节性可用性 |
| **类别** | 主要类别与业务类型匹配 |
| **服务区域** | 如无店面，则隐藏地址；定义服务区域 |

## 引文建设

**精准定位**优于向每个目录提交。

**优先顺序**：
1. Google商家资料
2. Apple地图
3. Yelp、Bing地点、Facebook
4. Better Business Bureau、Foursquare、Nextdoor
5. 垂直目录（Healthgrades、Angi等）

## 引文审计

- 不正确或过时的数据
- 重复条目
- 在关键目录上缺失列表

在添加前修复；累积错误会损害排名。

## 输出格式

- **NAP**（用于一致性的精确格式）
- **GBP**优化清单
- **引文**优先列表
- **审计**发现（如适用）

## 相关技能

- **geo**：GEO用于AI搜索；本地+AI重叠
- **localization-strategy**：多语言；本地+i18n
- **directory-submission**：目录列表；不同于本地引文
