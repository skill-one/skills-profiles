# 平台：TikTok

指导TikTok标题和视频脚本创作。用于生成可发布的标题和视频规格。适合文案代理、视频代理（格式、时长）和设计代理（缩略图）。

**调用时**：在**首次使用**时，如果有帮助，先用1-2句话说明这项技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接提供主要输出。

## 输出：可发布的文案

这项技能使代理能够生成TikTok标题和视频脚本。标题驱动SEO、可访问性和观看时长（带标题可提升12-20%的观看时长）。80%以上的用户不看声音观看。

## 标题结构

| 元素 | 长度 | 目的 |
|------|--------|-------|
| **钩子** | 5-7个字 | 抓住注意力；制造好奇心 |
| **背景** | 1-2句话 | 尺寸、价格、背景故事——视频中未展示的信息 |
| **行动号召** | 可选 | “保存这个”，“链接在简介中” |

**钩子示例**：“如果你在Etsy上销售，请停止滚动”，“这花了我47次尝试”，“等最后的结果”

## 视频规格（供视频代理使用）

| 规格 | 值 | 备注 |
|------|--------|-------|
| **宽高比** | 9:16（竖屏） | 标准；填满手机 |
| **分辨率** | 1080x1920 px | 推荐 |
| **时长** | 3秒 - 10分钟 | 15-60秒用于技巧；1-3分钟用于教程 |
| **格式** | MP4、MOV | H.264、AAC |
| **文件大小** | <=5MB（安卓），<=88MB（iOS） | 因设备而异 |

## 标题最佳实践

- **对比度**：字体/背景强对比度；75%的人静音观看
- **自动标题**：TikTok内置的；算法奖励；编辑以提高准确性
- **关键词**：提升搜索可见性
- **可读性**：在多个设备上测试

## 内容按时长分类

| 时长 | 使用场景 |
|------|--------|
| **15-60秒** | 快速技巧、幽默、钩子 |
| **1-3分钟** | 教程、故事讲述 |
| **3-10分钟** | 深入探讨（长格式） |

## 输出格式

生成TikTok内容时，提供：

1. **标题**（钩子 + 背景 + 行动号召）
2. **视频脚本**（如果视频代理）
3. **视频规格**（9:16，1080x1920，时长）
4. **话题标签**（3-5个；细分相关）

## 相关技能

- **tiktok-ads**：TikTok付费推广；信息流广告、火花广告（提升自然流量）；视频规格和标题与自然内容一致
- **influencer-marketing**：TikTok是关键的影响者平台
- **twitter-x-posts**：跨平台发布短视频
