# SEO 内容：关键词研究

本指南提供关键词研究方法，用于 SEO：寻找目标关键词、评估难度、理解搜索意图以及构建主题地图。~95% 的关键词每月搜索量少于 10 次；低搜索量、高意图的关键词通常能更快获得排名和转化。

**使用时机**：首次使用时，如果有助于理解，先用 1-2 句话说明本技能涵盖的内容及其重要性，然后提供主要输出。后续使用或用户要求跳过时，直接提供主要输出。

## 初步评估

**首先检查项目背景**：如果存在 `.claude/project-context.md` 或 `.cursor/project-context.md` 文件，请阅读其中关于产品、受众和定位的信息。

识别：
1. **产品/服务**：你提供的内容
2. **受众**：搜索这些内容的人
3. **目标**：流量、转化、品牌
4. **工具访问**：Google 关键词规划师、Google 趋势或 SEO 工具

## 发现方法

### 基础发现

| 方法 | 目的 |
|------|------|
| **用户视角** | 用户痛点是什么？他们会搜索什么？从产品背景中提取用户语言 |
| **工具扩展** | 相关关键词、问题、建议；Google 自动完成、PAA、相关搜索 |
| **竞争对手反向分析** | 分析竞争对手标题、H1、URL；识别他们排名的主题；寻找差距 (#4–10 = 机会) — 参见 **竞争对手研究** |
| **Google PAA** | 用户也问和相关搜索；来自真实用户行为的信号，高价值 |
| **从文章中提取** | 审计现有内容时：从标题、H1、H2、元关键词、前 100 字中提取种子关键词；然后搜索 `"[主要关键词]"` 或 `"[主要关键词] 相关关键词"` 寻找机会；如果知道竞争对手，使用 `"[主要关键词]" site:competitor.com` |

### Google 自动完成（长尾发现）

Google 自动完成反映真实用户搜索；建议只有在查询有实际流量时才会出现。免费；常能发现关键词工具遗漏的低搜索量长尾词。~70% 的搜索流量是长尾；竞争度低，转化率高。

**字母法**（种子词 + 空格 + 字母）：
- 输入种子关键词 + 空格 + 每个字母：`keyword a`，`keyword b`，... `keyword z`
- 记录相关建议；用数字 0-9 重复
- 示例：`SEO a` -> "SEO 审计," "SEO 代理"；`SEO b` -> "SEO 基础," "SEO 最佳实践"

**位置变体**（种子词在不同位置）：
- **前缀**：`a keyword`，`b keyword`（发现用户添加的前缀）
- **后缀**：`keyword a`，`keyword b`（最常见；字母法）
- **中间**：`how to keyword a`，`best keyword for`（疑问词 + 修饰词组合）

**疑问词修饰**：
- `how to keyword`，`what is keyword`，`why keyword`，`when to keyword`，`keyword vs`
- `keyword for beginners`，`keyword for small business`，`keyword without`

**工作原理**：关键词工具过滤低搜索量词；自动完成只显示有实际流量的查询。与 PAA 和相关搜索结合使用，实现全面覆盖。按意图分类结果（信息型、商业型、交易型）。

### 逐步发现

- **用户反馈**：支持、社区、评论、NPS—高频问题 = 未满足的搜索需求
- **多平台搜索**：Reddit、Quora、X（Twitter）、Hacker News—真实问题和讨论

## 搜索意图

| 意图 | 内容类型 | 示例 |
|------|----------|------|
| **信息型** | 博客、指南、FAQ | "如何优化网站地图" |
| **导航型** | 品牌页面 | "alignify 登录" |
| **商业型** | 比较、评论 | "SEO 工具比较" |
| **交易型** | 产品、价格 | "最佳 SEO 工具价格" |

### 意图识别

**修饰词**（常表示意图）：

| 意图 | 修饰词 |
|------|--------|
| 信息型 | "如何"，“什么”，“为什么”，“指南”，“教程” |
| 商业型 | "最佳"，“比较”，“vs”，“评论”，“顶级” |
| 交易型 | "购买"，“价格”，“便宜”，“优惠券”，“免费配送” |
| 本地型 | 地点名称 |

**SERP 检查**：搜索该词—知识卡片/Wiki → 信息型；产品列表/评论 → 商业型；品牌网站 → 导航型。较宽泛的词常显示混合 SERP。参见 **SERP 特性** 了解特性类型。

## 长尾扩展

- **Google 自动完成**：字母法、位置变体、疑问词修饰；见上文。主要的长尾来源。
- **意图修饰**：核心词 + "如何"，“最佳"，“vs"，“比较"，“价格"
- **疑问词**： "如何"，“什么"，“为什么"，“何时"
- **功能修饰**：核心词 + "-er/-or"（例如，"图像优化器"用于工具类型查询）；通常转化率更高
- **聚类**：按 SERP 重叠（相同排名页面）、语义相似性或意图分组。

## 关键词聚类与主题地图

| 方法 | 用途 |
|------|------|
| **SERP 重叠** | 关键词有重叠的排名页面 → 相同聚类 |
| **语义** | 按意义、LSI、相关概念分组 |
| **意图型** | 按意图分组；聚类内意图不同时，分离页面 |

**支柱-聚类**（将关键词映射到结构）：
- **支柱**（中心）：宽泛主题页面；链接到聚类
- **聚类**（分支）：专注子主题；链接回支柱
- 先目标长尾；再支柱。主题内聚类互链。
- 参见 **内容策略** 了解支柱-聚类规划和实施。

## 评估与筛选

| 因素 | 考虑 |
|------|------|
| **搜索量** | 月搜索量；~100+/月为典型下限；细分领域可放宽 |
| **关键词难度 (KD)** | 新网站目标低 KD |
| **CPC** | 高 CPC 常表示强商业意图 |
| **SERP 特性** | 特性片段、PAA、零点击；特性片段可满足意图而不点击—影响实际流量；参见 **SERP 特性**（零点击部分），**特性片段** |
| **筛选顺序** | 1) 移除不相关 2) 过滤极低搜索量 3) 评估可实现性 4) 优先商业/交易型 |

## 产品定位测试（SEO 适用性）

测试定位是否清晰到足以被搜索：

- **XXX + 功能词**：生成器、创建者、制造商、构建者、改变者、缩短器、刮取器、转换器、下载器、翻译器、扩展器、摘要器、调整器、移除器、提取器、记录器、重写器、解决者、计算器；或平台、工具、软件、应用、提供者、助手、Copilot
- **输入 + to + 输出**：例如，"图像 to 视频"，"文本 to 语音"—清晰输入/输出信号意图

**Agent/Copilot 产品**：纯原生 Agent 难以通过 SEO 发展；用户很少搜索 "agent"。先发布相关功能（例如，CRM、销售机器人用于销售 agent）建立流量，再引导至 Agent 产品。

## 原则

- **核心规则**：必须有人搜索它—用工具验证；避免创造术语
- **功能关键词**：工具类型 (-er/-or) 通常转化率更高；用户更接近行动
- **多语言**：在目标语言中重新研究；不要翻译现有列表。参见 **翻译** 了解翻译工作流。

## SEO–PPC 关键词协同

关键词研究服务于 SEO 和 Google 广告。对齐两个渠道，避免重复、蚕食和浪费支出。

| 数据流 | 用途 |
|------|------|
| **关键词研究 → google-ads** | 关键词列表、聚类、意图；支持词（登录、论坛、价格）→ PPC 负面关键词 |
| **google-ads → 关键词研究** | PPC 转化率、搜索词报告 → SEO 优先级；高转化 PPC 词 = 值得自然排名 |
| **关键词研究 →着陆页** | 聚类 → 每个意图的专用 LP；PAA 问题 → FAQ 部分 |
| **GSC 有机排名 4+** | 如果你有良好有机排名，考虑减少/暂停这些词的 PPC，避免蚕食 |

**PPC 数据用于 SEO 优先级**：`SEO ROI ≈ (有机点击 × PPC 转化率 × 客户价值) − SEO 成本`。用 PPC 转化数据验证要追求的自然排名关键词。

**参考**：[Backlinko – SEO 和 PPC：8 智能对齐方式](https://backlinko.com/seo-and-ppc)

## 报告工作流

1. **解析** — 读取 Excel/CSV，从标题推断关键词、搜索量、KD、意图等
2. **丰富** — 网络搜索，访问竞争对手/产品页面；如果存在，读取 `project-context.md`
3. **构建** — 构建报告数据结构
4. **生成** — 输出报告

## 输出格式

- **关键词列表**：包含搜索量、KD、意图
- **关键词映射**：到页面/内容
- **内容差距**（竞争对手排名，你未排名）
- **优先级**：实施排名
- **主题地图**（聚类 → 支柱 → 页面映射）

### 报告结构参考

| 部分 | 内容 |
|------|------|
| 执行摘要 | 优先级（前 3） |
| 关键词概述 | 总关键词数，主要意图，平均 KD，内容差距数量 |
| 关键词列表 | 关键词，搜索量，KD，意图，优先级，目标页面 |
| 关键词映射 | 页面/URL，目标关键词，状态 |
| 内容差距 | 竞争对手排名，你未排名的关键词 |
| 行动计划 | 优先级，行动，影响，工作量 |
| 附录 | 搜索意图参考（信息型，商业型，交易型，导航型） |
