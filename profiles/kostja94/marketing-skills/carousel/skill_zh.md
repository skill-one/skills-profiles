# 组件：轮播布局

用于顺序展示内容的轮播（滑块）布局指南。轮播每次显示一个或少数几个项目；用户通过滑动或点击来切换。在空间有限且需要轮换多个项目时效果最佳——例如客户评价、引言、标志、画廊精选。

**调用方式**：在**首次使用**时，如果有助于理解，先用1-2句话说明此功能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或用户要求跳过时，直接提供主要输出。

## 何时使用轮播

| 使用轮播时 | 使用网格/列表时 |
|-----------|----------------|
| **空间有限** | 完整目录可见 |
| 一次聚焦一个；需要轮换 | 浏览、比较多个项目 |
| 客户评价、引言、标志、精选画廊 | 产品、模板、博客索引 |
| 页面顶部；英雄区域或板块突出 | 完整列表；发现内容 |

参考**网格**进行同级层级展示；参考**列表**进行文本密集型扫描；参考**瀑布流**进行高度不等的画廊。

## 轮播 vs 网格 vs 列表 vs 瀑布流

| 布局 | 结构 | 适用于 |
|------|------|--------|
| **网格** | 等行等列；全部可见 | 产品、模板、功能 |
| **列表** | 单列；堆叠 | 博客索引、文档、搜索结果 |
| **瀑布流** | 列；高度不等 | Pinterest风格画廊 |
| **轮播** | 幻灯片；一个/少数几个可见；滑动/点击 | 客户评价、标志、精选项目 |

## 最佳实践

### 可访问性

- **键盘导航**：使用箭头键移动；使用Enter/Space键激活；焦点可见
- **用户控制**：不要过快自动切换；允许暂停；如果`prefers-reduced-motion`设置则避免自动切换
- **提示信息**：屏幕阅读器用户需要知道当前幻灯片和总数（例如"第2页，共5页"）
- **触摸目标**：移动端上一页/下一页按钮尺寸≥44×44px

### 性能

- **懒加载**：按需加载屏幕外的幻灯片；避免预先加载所有图片
- **预留空间**：预留幻灯片空间以避免布局偏移（CLS）

### SEO

- **DOM中包含内容**：所有轮播内容必须在页面加载时包含在初始HTML中。Google不会模拟点击；在幻灯片切换时通过AJAX加载的内容不可发现。与**选项卡折叠**相同。
- **建议**：在HTML中服务器渲染所有幻灯片；仅使用CSS/JS进行显示/隐藏。参考**渲染策略**。

## 使用案例

| 使用案例 | 格式 | 页面技能 |
|---------|------|---------|
| **客户评价** | 引言轮播；多个客户评价 | **客户评价生成器** |
| **展示/画廊** | 精选项目；轮换 | **展示页面生成器** |
| **媒体报道标志** | "被报道"标志条或引言轮播 | **媒体报道页面生成器** |
| **社区** | 英雄区域下方的横幅轮播 | **社区论坛** |

## 相关技能

- **网格**：用于完整目录；当轮播过于限制时
- **列表**：用于文本密集型扫描
- **瀑布流**：用于高度不等的画廊
- **卡片**：轮播幻灯片内的卡片结构
- **客户评价生成器**：客户评价轮播；评价作为内容
- **展示页面生成器**：画廊格式选项（网格、瀑布流、轮播）
- **选项卡折叠**：类似SEO要求——内容在加载时存在于DOM中
- **渲染策略**：SSR、SSG；内容在初始HTML中供爬虫获取
