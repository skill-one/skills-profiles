# 付费广告：抖音广告

指导抖音广告设置、创意策略和优化。抖音在年轻人群（18-34岁）和病毒式视频方面表现优异；当您的受众偏年轻且您有视频创意能力时使用。

**调用时机**：在**首次使用**时，如果有帮助，先用1-2句话说明此技能涵盖的内容及其重要性，然后提供主要输出。在**后续使用**或当用户要求跳过时，直接提供主要输出。

## 为什么选择抖音

- **人口统计**：18-34岁；Z世代和更年轻的千禧一代
- **创意速度**：短视频；原生感；UGC风格表现良好
- **成本**：触达方面通常比Meta的CPM更低
- **互动**：高观看时长；带声音的文化

## 广告格式

| 格式 | 使用场景 |
|------|-----|
| **Feed内广告** | 原生视频；9-15秒或更长；主要格式 |
| **TopView** | 第一印象；高端；提升认知度 |
| **Spark Ads** | 提升自然帖子效果；原生；创作者合作 |
| **Collection** | 产品目录；电商 |

## 创意最佳实践

- **钩子（0-3秒）**：模式打断；提问；大胆陈述
- **竖屏**：9:16用于信息流；符合平台原生特性
- **声音**：音乐和字幕很重要；许多人带声音观看
- **UGC风格**：真实；未精修的通常表现更佳
- **前3秒**：决定是否观看

## 定向

| 类型 | 使用场景 |
|------|-----|
| **兴趣** | 广泛；算法驱动 |
| **人口统计** | 年龄；性别；位置 |
| **相似人群** | 基于转化者或互动者 |
| **再营销** | 网站访客；视频观看者 |

## 追踪

- **抖音像素** + **事件API**：服务器端以获得更好的归因
- **UTM**：跨平台比较的一致参数

## 预算与竞价

- **最低**：因目标而异
- **竞价**：从手动开始；在转化量达到一定规模后切换到自动
- **创意数量**：计划高频刷新；创意是主要杠杆
