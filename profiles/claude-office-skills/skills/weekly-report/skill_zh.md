# 周报

## 概述

这项技能可以帮助您创建一致、结构良好的每周状态报告，有效地向您的团队、经理或利益相关者传达进展、阻碍和计划。

**使用场景：**
- 个人贡献者状态更新
- 团队负责人汇总报告
- 项目状态更新
- 高管摘要
- 客户进度报告

## 如何使用

1. 告诉我本周您完成了什么
2. 分享任何阻碍或挑战
3. 描述下周的计划
4. 指定您的受众（经理、团队、高管、客户）

**示例提示：**
- "为我经理创建每周状态报告"
- "根据这些个人更新生成团队汇总报告"
- "撰写我们项目进展的高管摘要"
- "起草面向客户的每周更新"

## 写作指南

### 成就
- 使用动作动词（完成、交付、启动、解决）
- 具体说明结果，而不仅仅是活动
- 尽可能量化影响
- 链接到业务价值

**良好：** "将API响应时间减少40%，改善了50K日用户的体验"
**不佳：** "参与了性能改进工作"

### 阻碍
- 具体说明问题
- 解释影响（延迟、依赖）
- 说明您需要什么帮助
- 包括任何尝试过的解决方案

**良好：** "等待IT提供API凭证（工单#1234）。这阻碍了本周计划的集成工作。需要升级给IT经理。"
**不佳：** "无法推进集成工作"

### 下周计划
- 对容量保持现实
- 优先考虑前3-5项
- 包括依赖关系
- 注明任何风险或假设

```markdown
# [报告标题]

**期间：** [日期范围]
**作者：** [姓名]
**受众：** [团队/经理/高管/客户]

[基于模板的结构化内容]
```

## 定制选项

告诉我您的偏好：
- **长度：** 简要（要点）、标准、详细
- **受众：** 团队、经理、高管、客户
- **重点：** 成就、阻碍、指标
- **频率：** 可适应每日/双周/每月
- **语气：** 休闲团队更新或正式利益相关者报告

## 限制

- 无法访问您实际的工作系统或日历
- 依赖于您提供的信息
- 可能需要根据您组织的特定格式进行调整
- 发送前应检查准确性

## 示例

### 示例：快速状态更新

**输入：** "我完成了仪表板重新设计，修复了3个错误，仍在处理用户认证功能，因为它因等待安全审查而延迟。下周我将专注于完成认证并开始移动优化。"

**输出：**

# 每周状态报告

**姓名：** [您的姓名]
**本周：** [当前周]

## 🎯 摘要
完成了仪表板重新设计里程碑。用户认证功能进行中，等待安全审查。

## ✅ 成就
- 完成了仪表板重新设计（UI/UX里程碑）
- 解决了生产中的3个错误
- 推进了用户认证功能开发

## 🚧 进行中
| 任务 | 状态 | 预计完成时间 |
|------|--------|---------------------|
| 用户认证功能 | 70% | 等待安全审查 |

## 🚫 阻碍
- **安全审查待定** - 用户认证功能无法部署，直到安全团队完成审查。影响：2-3天延迟。*行动需要：跟进安全团队的时间表。*

## 📅 下周优先事项
1. 完成用户认证功能（安全审查后）
2. 开始移动优化工作
3. 处理仪表板重新设计的任何反馈

## 💬 备注
- 仪表板重新设计准备好进行利益相关者演示（如需要）
