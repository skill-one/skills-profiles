# 求职信

## 概述

这项技能可以帮助您撰写个性化的、有说服力的求职信，有效地向潜在雇主传达您的价值，并增加您获得面试的机会。

**使用场景：**
- 求职申请
- 职业转型
- 内部调动
- 推荐介绍
- 探索性申请

## 如何使用

1. 分享职位招聘信息或描述该职位
2. 告诉我关于您的相关经验
3. 提及您想要突出显示的任何具体要点
4. 我将为您创建一份量身定制的求职信

**示例提示：**
- "为谷歌的资深产品经理职位撰写一封求职信"
- "创建一份从教师到企业培训师的职业转型求职信"
- "起草一封突出我的 Python 和机器学习经验的求职信"
- "帮我写一封推荐求职信 - 张三向我推荐了我"

## 求职信结构

### 赢得胜利的公式

```
[包含联系信息的页眉]

[日期]

[招聘经理姓名/职位]
[公司名称]
[地址]

尊敬的[姓名/招聘经理]，

**开场白**（1 段）
- 立即吸引注意力
- 表达对特定职位的热情
- 如适用，提及推荐人姓名
- 提及一项具体成就或联系

**价值主张**（2 段）
- 将您的经验与他们的要求相匹配
- 提供具体、量化的成就
- 展示您了解他们的挑战
- 证明文化契合度

**为何选择该公司**（1 段）
- 展示您已进行过研究
- 将您的价值观与他们的价值观联系起来
- 解释为何现在以及为何在这里

**有力的结尾**（1 段）
- 重申您的兴趣
- 明确行动号召
- 表达对后续步骤的热情

此致，
[您的姓名]
```

## 写作技巧

### 有效开场白

**好的开场白：**
- "在领导[公司]最大产品发布后，我已准备好将这种热情带到[目标公司]。"
- "[推荐人姓名]建议我联系 - 在了解[公司]在[项目]方面的工作后，我知道我必须申请。"
- "您的职位描述与我的背景完全匹配：[具体匹配]。"
- "我一直以来都很欣赏[公司]对[具体事物]的方法，自从[何时/如何了解他们]。"

**避免：**
- "我写这封信是为了申请..."（无聊）
- "我相信我会是一个很好的匹配..."（通用）
- "敬启者"（不个性）
- 以您的生平故事开头

### 量化您的成就

| 而不是 | 写 |
|--------|----|
| "增加了销售额" | "年增长率 45%，增加收入 200 万美元" |
| "管理了一个团队" | "领导 12 人的团队跨越 3 个时区" |
| "提高了效率" | "将处理时间从 5 天缩短到 4 小时" |
| "处理客户问题" | "每月解决 50 多个客户升级，满意度 98%" |

### 展示公司研究

提及具体的东西，比如：
- 近期的新闻、融资或发布
- 与您产生共鸣的公司价值观
- 您欣赏的具体产品或服务
- 他们正在解决的行业挑战
- 您欣赏的公司文化元素

### 常见错误避免

1. **重复您的简历** - 添加新的见解，而不是摘要
2. **过于通用** - 针对每个申请进行定制
3. **专注于您想要什么** - 专注于您能提供什么
4. **太长** - 保持在一页，3-4 段
5. **拼写和错误** - 多次校对
6. **错误的 公司名称** - 发送前仔细检查
7. **讨论薪水** - 留待面试
8. **负面语言** - 始终保持积极

## 输出格式

```markdown
## 求职信

**职位：** [角色]
**公司：** [公司]
**量身定制：** [针对的具体方面]

---

[完整的求职信文本]

---

## 突出显示的关键点
- [与要求匹配的成就 1]
- [与要求匹配的成就 2]

## 定制说明
- [任何进一步个性化的建议]
```

## 定制选项

告诉我您的偏好：
- **语气：** 专业、对话式、热情、自信
- **长度：** 简洁（250 字）、标准（350 字）、详细（450 字）
- **重点：** 技能、成就、文化契合度、职业故事
- **行业：** 企业、初创公司、非营利组织、创意、技术

## 局限性

- 无法访问实际的职位招聘信息（请提供文本）
- 与您关于经验的背景信息配合最佳
- 应检查日期和细节的准确性
- 可能需要针对非常专业的行业进行调整
- 无法保证面试回调

## 示例

### 示例：技术角色求职信

**输入：** "为 Stripe 的资深软件工程师职位撰写一封求职信。我有 6 年的 Python/Go 经验，在当前公司构建了支付系统，并且我对金融科技充满热情。"

**输出：**

尊敬的招聘经理，

领导[公司]最大的产品发布后，我已准备好将这种热情带到 Stripe - 这正是我申请资深软件工程师职位的原因。您的使命是增加互联网的 GDP，这与我的经验使金融科技变得可访问和可靠产生共鸣。

在[当前公司]，我使用 Python 和 Go 架构了我们的核心支付处理系统，将交易失败率降低了 40%，并将吞吐量从 1,000 提高到 10,000 笔交易每秒。我领导了与多个支付提供商的集成，并实施了欺诈检测系统，防止了 200 万美元的潜在损失。这项工作不仅需要技术卓越，还需要对金融法规和用户信任的深刻理解。

让我特别关注 Stripe 的原因是我对开发者优先的方法。我广泛使用了 Stripe 的 API，并欣赏文档和 SDK 中的周到考虑。有机会构建依赖于此的数百万企业的基础设施，并与在 API 设计方面设定了标准的工程师共事，正是我正在寻找的挑战。

我非常期待讨论我的支付系统经验和金融科技热情如何能够为 Stripe 的持续增长做出贡献。感谢您考虑我的申请。

顺颂商祺，
[您的姓名]

---

**突出显示的关键点：**
- 直接的支付系统经验（与领域匹配）
- 量化的成就（5000 万，40% 降低，10 倍吞吐量）
- Go 和 Python 专业知识（与技术栈匹配）
- 熟悉 Stripe 产品（显示研究）
- 基础设施规模思维（与 Stripe 的挑战匹配）
