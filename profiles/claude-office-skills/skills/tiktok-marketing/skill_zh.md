# TikTok营销

全面的TikTok营销技能，涵盖内容策略、视频创作流程、发布优化和数据分析。与n8n自动化集成，实现可扩展的内容生产。

## 概述

本技能可实现：
- TikTok内容策略开发
- AI驱动的视频脚本生成
- 自动化发布流程
- 标签和趋势优化
- 性能分析和报告

## 标签策略

### 标签组合公式

```yaml
hashtag_strategy:
  total: 5-7个标签 (TikTok最佳)
  
  组合:
    - 专门性标签: 2-3个
      示例: ["#小企业技巧", "#营销技巧"]
      触达: 10万-100万次观看
      
    - 热门标签: 1-2个
      示例: ["#fyp", "#viral", "#trending"]
      触达: 1亿+次观看
      
    - 品牌标签: 1个
      示例: ["#你的品牌名", "#你的活动"]
      触达: 自定义
      
    - 社区标签: 1个
      示例: ["#tiktokmademedoit", "#learnontiktok"]
      触达: 100万-1000万次观看
```

### 标签研究流程

```
1. 搜索你的领域关键词
2. 记录前10个视频中使用的标签
3. 检查标签观看次数
4. 混合高(1亿+), 中(100万-1000万), 低(10万-100万)触达的标签
5. 测试并追踪表现
6. 每周轮换表现不佳的标签
```

## 自动化工作流 (n8n)

### 工作流1：AI视频内容管道

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ Google Sheets │───▶│ OpenAI       │───▶│ ElevenLabs   │
│ (创意)       │    │ (脚本)       │    │ (配音)       │
└──────────────┘    └──────────────┘    └──────────────┘
                                               │
┌──────────────┐    ┌──────────────┐    ┌──────┴───────┐
│ TikTok       │◀───│ 视频编辑器   │◀───│ 图像生成     │
│ (发布)       │    │ (组合)       │    │ (视觉效果)  │
└──────────────┘    └──────────────┘    └──────────────┘
```

**n8n配置**:
```yaml
workflow: "AI TikTok内容生成器"

节点:
  1. 触发器:
      类型: 定时任务
      cron: "0 9 * * *"  # 每天早上9点
  
  2. 获取创意:
      类型: Google Sheets
      操作: 获取下一个未使用行
      表单: "内容创意"
  
  3. 生成脚本:
      类型: OpenAI
      模型: gpt-4
      提示: |
        为{TikTok创意}创建一个TikTok脚本
        格式: 吸睛(3秒) + 内容(20秒) + 行动号召(3秒)
        风格: 休闲、吸引人，带文字叠加
  
  4. 生成配音:
      类型: ElevenLabs
      语音: "年轻专业人士"
      脚本: "{脚本}"
  
  5. 生成视觉效果:
      类型: DALL-E
      提示: "{视觉描述}"
  
  6. 创建视频:
      类型: 视频编辑器
      模板: "TikTok竖屏"
      资源: [配音, 视觉效果, 字幕]
  
  7. 发布:
      类型: TikTok
      字幕: "{生成字幕}"
      标签: "{标签}"
      计划: "{最佳时间}"
  
  8. 更新追踪器:
      类型: Google Sheets
      操作: 标记为已发布
```

### 工作流2：多平台发布

```yaml
workflow: "发布到TikTok + Instagram Reels + YouTube Shorts"

触发器:
  类型: Google Drive
  事件: 新视频上传
  文件夹: "/准备发布"

操作:
  1. 检测视频:

  2. 生成字幕:

  3. 并行发布:
      - TikTok:

      - YouTube:
          类型: Shorts
          标题: "{YouTube标题}"

  4. 在Airtable中追踪:
      数据库: "内容追踪器"
      字段: [视频链接, 平台, 发布时间, 状态]
  
  5. Slack通知:
      频道: "#内容已发布"
      消息: "已发布到所有平台: {标题}"
```

| 观看时长 | >50% | 改进吸睛部分 |
| 互动率 | >5% | 优化行动号召 |

| 关注率 | >2% | 强化价值主张 |

## 趋势识别

### 如何提前发现趋势

```yaml
趋势来源:
  - TikTok发现页面: 每天检查
  - 创作者搜索洞察: 应用内分析
  - TrendTok应用: 趋势追踪工具
  - Exploding Topics: 早期趋势检测
  - Twitter/X: 跨平台趋势

趋势标准:
  - 声音使用增长: 48小时内>500%
  - 尚未饱和: 使用量<10K
  - 符合你的领域: 可添加独特角度
  - 积极情绪: 无争议

行动速度:
  - 第1-2天: 最高潜力
  - 第3-5天: 仍有良好效果
  - 第6天后: 可能已饱和
```
