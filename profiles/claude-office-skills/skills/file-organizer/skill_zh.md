# 文件组织器

智能根据文件内容和元数据组织并重命名文件。

## 概述

此技能可以帮助您：
- 分析文件内容以确定分类
- 建议文件夹结构
- 生成一致的命名规范
- 识别和处理重复文件
- 创建组织系统

## 如何使用

### 分析文件
```
"分析这些文件并建议如何组织它们"
"这个文件属于哪个类别？"
"为这份文档建议一个更好的文件名"
```

### 组织
```
"为我的项目文件创建文件夹结构"
"整理我的下载文件夹"
"按供应商和日期对发票进行排序"
```

## 命名规范

### 推荐格式

**文档**
```
YYYY-MM-DD_类别_描述_v1.ext
示例：2026-01-29_合同_客户名_NDA_v1.pdf
```

**图片**
```
YYYY-MM-DD_事件/项目_描述_NNN.ext
示例：2026-01-29_产品发布_主图_001.png
```

**发票/收据**
```
YYYY-MM-DD_供应商_金额_发票号.ext
示例：2026-01-29_Adobe_149.99_INV-12345.pdf
```

**会议笔记**
```
YYYY-MM-DD_会议类型_主题.ext
示例：2026-01-29_团队同步_Q1规划.md
```

### 命名规则
- 使用下划线或连字符，不要使用空格
- 以日期开头，便于按时间排序
- 包含关键标识符（客户、项目、类型）
- 添加版本号以区分迭代版本
- 保持名称简洁但描述清晰

## 分析能力

### 基于内容的分类
- **文档**: 合同、报告、信件、表格
- **财务**: 发票、收据、报表、预算
- **媒体**: 照片、视频、音频、图形
- **代码**: 源文件、配置文件、文档
- **数据**: 电子表格、数据库、导出文件

### 元数据提取
- 创建/修改日期
- 作者信息
- 文件尺寸（图片/视频）
- 时长（音频/视频）
- 页数（文档）

## 自动化规则

### 示例规则
```markdown
## 自动组织规则

### 规则1：发票
- 触发条件：PDF文件内容包含"Invoice"或"INV-"
- 操作：移动到/财务/发票/[年份]/[月份]/
- 重命名：YYYY-MM-DD_供应商_金额.pdf

### 规则2：截图
- 触发条件：文件名匹配"Screenshot*.png"
- 操作：移动到/截图/[年-月]/
- 重命名：YYYY-MM-DD_HH-MM_截图.png

### 规则3：下载清理
- 触发条件：下载文件夹中超过30天的文件
- 操作： 
  - 如果是文档 → 归档
  - 如果是安装程序 → 删除
  - 如果是媒体 → 排序到适当文件夹
```

## 最佳实践

### 组织原则
1. **PARA方法**：项目、区域、资源、归档
2. **日期优先**：便于按时间排序
3. **描述性名称**：未来你会感谢自己
4. **扁平化更好**：避免深层嵌套（最多3-4级）
5. **定期维护**：每月安排审核

### 文件卫生
- 删除重复文件和临时文件
- 归档已完成项目
- 对重要文件使用云同步
- 保持命名一致
- 记录你的系统

## 限制

- 无法访问受保护/加密的文件
- 大文件移动需要手动执行
- 内容分析依赖于文件格式支持
- 无法保证完美分类
- 重要文件建议手动审核
