# PDF 转换器

将 PDF 文件转换为多种格式，反之亦然，同时保留格式。

## 概述

此技能可帮助您：
- 将 PDF 转换为可编辑格式（Word、Excel）
- 将文档转换为 PDF
- 从 PDF 中提取图像
- 优化转换质量
- 处理批量转换

## 支持的转换

### PDF 转换为其他格式
| 目标格式 | 最佳用途 | 质量 |
|---------------|----------|---------|
| **Word (.docx)** | 文本密集型文档 | ⭐⭐⭐⭐ |
| **Excel (.xlsx)** | 表格和数据 | ⭐⭐⭐⭐ |
| **PowerPoint (.pptx)** | 演示文稿 | ⭐⭐⭐ |
| **图像 (.png/.jpg)** | 视觉快照 | ⭐⭐⭐⭐⭐ |
| **文本 (.txt)** | 纯文本提取 | ⭐⭐⭐⭐ |
| **HTML** | 网页内容 | ⭐⭐⭐ |
| **Markdown (.md)** | 结构化文本 | ⭐⭐⭐ |

### 其他格式转换为 PDF
| 源格式 | 质量说明 |
|---------------|---------------|
| **Word (.docx)** | 优秀保留 |
| **Excel (.xlsx)** | 良好，检查分页符 |
| **PowerPoint (.pptx)** | 动画扁平化时优秀 |
| **图像** | 取决于分辨率 |
| **HTML** | 可变，CSS 可能不同 |
| **文本 (.txt)** | 完美，但基本 |

## 如何使用

### 基本转换
```
"将此 PDF 转换为 Word"
"将此文档保存为 PDF"
"将此 PDF 提取为图像"
```

### 带选项
```
"将 PDF 转换为 Word，保留精确格式"
"将 PDF 的 1-5 页导出为 300 DPI 的 PNG 图像"
"将 Excel 转换为 PDF，所有列适应单页"
```

### 批量转换
```
"将此文件夹中的所有 PDF 转换为 Word 文档"
"从这些 10 个 Word 文件创建 PDF"
```

## 转换指南

### PDF 转换为 Word
```markdown
## PDF 转换为 Word

### 最佳实践
1. **检查源 PDF 类型**：
   - 原生 PDF（来自 Word 等）：最佳结果
   - 扫描 PDF：先进行 OCR
   - 基于图像：有限精度

2. **格式考虑**：
   - 复杂布局可能偏移
   - 字体未安装时可能替换
   - 表格可能需要调整
   - 标题/页脚需要检查

### 质量设置
| 设置 | 结果 |
|---------|--------|
| **精确** | 精确匹配布局，更难编辑 |
| **可编辑** | 优化编辑，可能偏移布局 |
| **纯文本** | 纯文本，无格式 |

### 常见问题
| 问题 | 解决方案 |
|-------|----------|
| 文本为图像 | 转换前运行 OCR |
| 字体缺失 | 嵌入或替换字体 |
| 表格损坏 | 在 Word 中手动调整 |
| 颜色丢失 | 检查颜色配置设置 |
```

## 故障排除

### 常见问题
| 问题 | 原因 | 解决方案 |
|---------|-------|----------|
| 文本不可选 | 扫描 PDF | 转换前应用 OCR |
| 字符缺失 | 字体问题 | 嵌入字体或转换 |
| 图像质量差 | 低 DPI | 使用更高分辨率 |
| 文件大小大 | 未压缩 | 应用压缩 |
| 格式丢失 | 复杂布局 | 使用 "精确" 模式 |

### 质量检查表
转换后验证：
- [ ] 所有文本存在且可读
- [ ] 格式大致保留
- [ ] 图像包含且清晰
- [ ] 表格结构正确
- [ ] 链接功能正常（如适用）
- [ ] 页数匹配

## 限制

- 无法执行实际文件转换（仅提供指导）
- 扫描 PDF 需要预处理 OCR
- 复杂布局可能无法完美转换
- 加密 PDF 需要密码
- 转换中某些格式始终丢失
- 质量取决于源 PDF 类型
