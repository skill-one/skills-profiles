# 邮件分类器

自动对邮件进行分类和优先级排序，帮助管理收件箱过载。

## 概述

此功能可以帮助您：
- 按类别和类型对邮件进行分类
- 确定优先级和紧急程度
- 识别所需操作
- 过滤低价值邮件
- 高效处理邮件

## 分类类别

### 主要类别
| 类别 | 描述 | 示例 |
|------|-------------|----------|
| **需要行动** | 需要您的回复/操作 | 请求、批准、问题 |
| **仅供参考** | 信息性，无需操作 | 更新、公告、报告 |
| **等待中** | 您正在等待他人 | 跟进、待回复 |
| **已转交** | 转发给其他人 | 收件人错误、团队事务 |
| **存档** | 保留但无需操作 | 确认、收据 |
| **删除** | 低价值，可删除 | 垃圾邮件、无关促销 |

### 邮件类型
| 类型 | 描述 |
|------|-------------|
| **会议** | 邀请、更新、取消 |
| **任务/请求** | 有人要求您做某事 |
| **问题** | 需要您的答案 |
| **更新/报告** | 状态更新、进度报告 |
| **批准** | 需要您的签字 |
| **订阅内容** | 订阅内容 |
| **营销** | 促销内容 |
| **警报/通知** | 系统警报、通知 |
| **个人** | 工作相关 |
| **垃圾邮件/钓鱼** | 不想要或可疑 |

### 优先级级别
| 优先级 | 回复时间 | 指示 |
|----------|---------------|------------|
| 🔴 **紧急** | 几小时内 | 今天截止、高管请求、阻塞问题 |
| 🟠 **高** | 24小时内 | 重要客户、时间敏感、直接请求 |
| 🟡 **普通** | 一周内 | 标准请求、常规事务 |
| 🟢 **低** | 随时方便 | 仅供参考、订阅内容、非紧急更新 |

## 如何使用

### 单封邮件分类
```
"分类此邮件：[粘贴邮件内容]"
```

### 批量分类
```
"分类这些邮件并按优先级组织：
1. [邮件 1]
2. [邮件 2]
3. [邮件 3]"
```

### 带规则
```
"分类我的邮件。将来自 @client.com 的邮件视为高优先级"
```

## 自定义规则

### 定义您的规则
```markdown
## 我的邮件规则

### VIP 发件人（始终高优先级）
- CEO、CFO、CTO
- 直接经理
- 主要客户：@bigclient.com

### 自动存档
- 订阅内容（除非来自 [特定]）
- 自动报告（阅读后）
- 仅抄送邮件（如果没有 @提及）

### 自动转交
- IT 支持请求 → it-team@
- 人力资源问题 → hr@

### 警报（标记为紧急）
- 主题中包含 "紧急"
- 法律/合规提及
- 客户投诉
```

## 垃圾邮件/钓鱼检测

### 警报迹象
```markdown
## 可疑邮件指标

**风险级别**：🔴 高 / 🟠 中 / 🟢 低

### 检测到红标
- [ ] 发件人域名与显示名称不匹配
- [ ] 紧急压力策略
- [ ] 请求凭证/个人信息
- [ ] 可疑链接（悬停检查）
- [ ] 预期附件
- [ ] 语法/拼写错误
- [ ] 通用问候语 ("尊敬的客户")

### 建议
[不要点击链接 / 报告为钓鱼邮件 / 安全继续]
```

## 工作流程建议

### 处理顺序
```markdown
## 推荐处理顺序

### 早晨（30 分钟）
1. 🔴 紧急邮件优先（2 封邮件，约 10 分钟）
2. 🟠 高优先级（3 封邮件，约 15 分钟）
3. 2 分钟内快速完成（5 封邮件，约 5 分钟）

### 批量处理
- 🟡 普通优先级 - 安排 1 小时块
- 🟢 订阅内容 - 下班前或周末

### 立即转交
- 转发 [邮件 X] 给 [人员] 处理
```

## 集成建议

### 日历集成
- 会议邮件 → 检查/更新日历
- 截止日期提及 → 创建日历提醒

### 任务集成
- 行动项 → 创建任务
- 跟进 → 设置提醒

### CRM 集成
- 客户邮件 → 登录 CRM
- 领域查询 → 创建领域记录

## 限制

- 无法直接访问邮箱账户
- 分类基于提供的内容
- 可能错过邮件线程的上下文
- 无法保证钓鱼检测
- 边缘情况需要个人判断
