# Shopify 自动化

全面的 Shopify 电子商务自动化，涵盖库存管理、订单处理、客户工作流程和分析。基于 n8n 的电子商务工作流模板。

## 概述

本技能涵盖：
- 库存管理和警报
- 订单处理自动化
- 客户生命周期工作流程
- 多渠道同步
- 分析和报告

## 库存管理

### 低库存警报

```yaml
工作流: "库存警报系统"
计划: "每日上午9点"

步骤：
  1. 获取库存：
      Shopify:
        端点: 产品
        包含: 变体
        
  2. 筛选低库存：
      条件: 库存数量 <= 重新订购阈值
      默认阈值: 10
      
  3. 分类紧急程度：
      紧急: 库存数量 <= 5
      警告: 库存数量 <= 10
      
  4. 生成报告：
      按组: [类别, 紧急程度]
      
  5. 通知：
      Slack:
        频道: "#库存警报"
        消息: |
          ⚠️ *低库存警报*
          
          🚨 *紧急 (≤5件):*
          {紧急商品}
          
          ⚠️ *警告 (≤10件):*
          {警告商品}
          
          [在 Shopify 中查看]({管理链接})
          
  6. 创建采购订单：
      如果: 自动重新订购启用
      模板: 为每个供应商生成采购订单
```

### 预测重新订购

```yaml
工作流: "智能库存重新订购"

分析：
  数据源：
    - 销售历史: 过去90天
    - 季节性趋势: 同比
    - 当前速度: 过去14天
    
  计算：
    每日销售率: 平均(每天销售单位)
    库存天数: 当前库存 / 每日销售率
    重新订购点: 每日销售率 * 提前期 * 安全系数
    
  安全系数：
    高速度: 1.5
    正常: 1.3
    运动缓慢: 1.1
    
操作：
  自动重新订购：
    条件: 库存天数 <= 提前期 + 缓冲区
    操作: 生成采购订单
    通知: 采购团队
```

## 订单处理

### 订单履行工作流

```yaml
工作流: "订单处理管道"
触发: Shopify订单创建

步骤：
  1. 验证订单：
      检查：
        - 欺诈分数: < 阈值
        - 库存可用: true
        - 支付捕获: true
        
  2. 分类订单：
      规则：
        - 高价值: 总额 > $500
        - 国际: 国家 != 母国
        - 加急: 运输方式 == "快速"
        - 订阅: 包含订阅商品
        
  3. 分配履行：
      路由：
        - 如果: 国际
          仓库: 国际枢纽
        - 如果: 加急
          优先级: 高
        - 默认:
          仓库: 距离客户最近
          
  4. 创建运输标签：
      载体: 基于服务级别
      集成: [shipstation, easypost, shippo]
      
  5. 更新库存：
      操作: 减少库存
      
  6. 通知客户：
      邮件: 订单确认模板
      短信: 如果选择启用
      
  7. 更新系统：
      - 会计: 创建发票
      - CRM: 更新客户记录
      - 分析: 记录订单数据
```

### 订单状态自动化

```yaml
订单状态通知：
  确认:
    延迟: 立即
    邮件: "感谢您的订单！"
    
  处理中:
    延迟: 状态变化时
    邮件: "我们正在准备您的订单"
    
  已发货:
    延迟: 立即
    邮件: |
      您的订单正在运输中！
      追踪: {追踪号码}
      载体: {载体}
      预计送达: {eta}
    短信: "您的订单已发货！追踪: {追踪链接}"
    
  已送达:
    延迟: 送达后1天
    邮件: "您的订单如何？留下评价！"
    
  延迟:
    触发: 3天无追踪更新
    操作: 主动客户沟通
```

## 客户工作流程

### 购买后序列

```yaml
工作流: "购买后参与"

序列：
  第0天:
    触发: 订单送达
    操作: 
      - 邮件: 配送确认
      - 开始评价计时器
      
  第3天:
    操作:
      - 邮件: 评价请求
        模板: |
          Hi {first_name},
          
          您喜欢您的 {产品名称} 吗？
          
          我们很想知道您的想法！
          [留下评价]({评价链接})
          
  第7天:
    条件: 未提交评价
    操作:
      - 邮件: 评价提醒
      - 提供: 下次订单10%折扣
      
  第14天:
    操作:
      - 邮件: 相关产品
        个性化: 基于购买
      
  第30天:
    条件: 消耗品
    操作:
      - 邮件: 补充提醒
        折扣: 返回客户
```

### 客户细分

```yaml
细分：
  VIP:
    标准:
      - 总消费: >= $1000
      - 订单: >= 5
    操作:
      - 标签: "VIP"
      - 添加到列表: "VIP客户"
      - 优先支持: true
      - 新产品优先体验
      
  风险:
    标准:
      - 最后订单: > 90天
      - 以前的订单: >= 2
    操作:
      - 标签: "挽回"
      - 邮件序列: 重新激活
      - 提供: 特别折扣
      
  新客户:
    标准:
      - 订单: 1
      - 首次订单以来天数: <= 30
    操作:
      - 邮件序列: 新手引导
      - 推荐: 畅销产品
      
  批发:
    标准:
      - 平均订单价值: >= $500
      - 订单: >= 3
    操作:
      - 标签: "B2B潜力"
      - 通知: 销售团队
```

## 多渠道同步

### 库存同步

```yaml
多渠道库存:
  平台:
    - Shopify: 主要
    - 亚马逊: 次要
    - eBay: 次要
    - 沃尔玛: 次要
    
  同步规则:
    频率: 实时
    安全库存: 5单位  # 安全缓冲区
    
    分配:
      Shopify: 100%  # 完整库存
      亚马逊: 可用 - 缓冲区
      eBay: 可用 - 缓冲区
      沃尔玛: 可用 - 缓冲区
      
  操作:
    销售时:
      - 立即更新所有渠道
      - 如果缺货: 暂停列表
      
    重新补货时:
      - 立即更新所有渠道
      - 如果暂停: 重新激活列表
```

### 价格同步

```yaml
价格同步:
  基础价格: Shopify
  
  渠道调整:
    亚马逊:
      加价: +15%  # 考虑费用
      
    eBay:
      加价: +10%
      
    批发:
      折扣: -30%
      
  自动化:
    - 价格变化时: 同步所有渠道
    - 竞争对手监控: 可选
    - 动态定价: 基于需求
```

## 分析与报告

### 每日销售报告

```yaml
工作流: "每日销售报告"
计划: "每日上午8点"

指标:
  收入:
    - 总销售额
    - 平均订单价值
    - 与昨日对比
    - 与上周同日对比
    
  订单:
    - 订单数量
    - 销售单位
    - 新客户与回头客
    
  产品:
    - 畅销产品
    - 表现不佳的产品
    - 缺货商品
    
  渠道:
    - 按来源: [直接, 谷歌, 脸书, 邮件]
    - 转化率
    
输出:
  格式: |
    📊 *每日销售报告 - {日期}*
    
    💰 *收入*
    今日: ${总销售额} ({与昨日变化})
    AOV: ${aov}
    
    📦 *订单*
    数量: {订单数量}
    新客户: {新客户}
    
    🏆 *畅销产品*
    1. {产品1} - {单位1}单位
    2. {产品2} - {单位2}单位
    3. {产品3} - {单位3}单位
    
    ⚠️ *注意*
    - {低库存数量}个产品低库存
    - {放弃购物车}个放弃购物车 (${价值})
    
  目的地:
    - Slack: "#每日销售"
    - 邮件: 领导团队
    - Google Sheets: 销售追踪
```
