# 招标书撰写助手

## 概述

这项技能能帮助你创建专业、有说服力的商业招标书，清晰传达价值并赢得订单。从简单的报价单到全面的RFP回复。

**使用场景：**
- 销售报价单
- 项目招标书
- 合作伙伴招标书
- RFP/RFI回复
- 基金申请
- 服务协议

## 如何使用

1. 告诉我关于机会的信息（客户、项目、需求）
2. 分享你的解决方案和定价
3. 指定所需的招标书类型和长度
4. 我将为你创建结构清晰、有吸引力的招标书

**示例提示：**
- "创建网站改版服务的招标书"
- "撰写联合营销的合作伙伴招标书"
- "起草IT服务的RFP回复"
- "生成新功能的招标书"

## 招标书撰写最佳实践

### 执行摘要
- 最后撰写（在完整招标书之后）
- 应能独立存在
- 以客户利益为先，而不是你的功能
- 最多1页

### 了解部分
- 显示你做了功课
- 提及具体的客户挑战
- 使用他们的语言和术语
- 承认他们的目标

### 解决方案部分
- 关注结果，而不是活动
- 解释为什么，而不仅仅是是什么
- 在需要时使用视觉辅助
- 使其易于理解

### 定价部分
- 尽可能提供选项
- 首先以较高选项作为锚点
- 透明说明包含内容
- 证明投资价值

### 行动号召
- 使下一步行动清晰明确
- 移除障碍（容易说"是"）
- 适当制造紧迫感
- 提供联系方式以提问

## 定制选项

告诉我你的偏好：
- **长度：** 简短（2-3页），标准（5-10页），全面
- **风格：** 保守/企业，现代/创意，技术
- **重点：** 价格竞争，价值导向，关系建立
- **格式：** 文档，演示幻灯片，邮件友好

## 限制

- 无法研究特定客户（提供背景信息）
- 定价必须由你提供
- 法律条款应由法律顾问审查
- 可能适用行业特定法规
- 无法保证订单达成
