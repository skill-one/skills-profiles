# 工作描述生成器

生成专业、包容的工作描述，吸引合格候选人。

## 概述

此技能帮助人力资源专业人士和招聘经理创建全面的工作发布，包括：
- 清晰传达角色期望
- 使用包容性、无偏见的语言
- 遵循行业最佳实践
- 吸引多元化、合格的候选人

## 如何使用

提供以下信息：
1. **职位名称**：职位名称
2. **部门**：团队或部门
3. **级别**：入门级、中级、高级、主管、总监等
4. **雇佣类型**：全职、兼职、合同
5. **地点**：现场、远程、混合
6. **主要职责**：该角色将做什么
7. **要求**：必须具备的资质
8. **加分项**：优先资质
9. **公司信息**：公司简介（可选）

## 最佳实践

### 语言指南
- 使用"you"而不是"理想的候选人"
- 避免性别化语言（he/she → they）
- 删除不必要的术语
- 明确要求与加分项的区别
- 尽可能包含薪资范围（可提高申请率30%）

### 需要避免的警示标志
- "摇滚明星" / "忍者" / "大师" → 使用"专家"或"专家"
- "快节奏环境" → 具体说明工作量
- 过多的要求 → 限制在5-7个必须要求
- 模糊的职责 → 使用可衡量的成果

### 包容性语言
| 而不是 | 使用 |
|-------|-----|
| "年轻有活力" | "有动力且热情" |
| "母语为英语" | "英语流利" |
| "文化契合" | "价值观一致" |
| "数字原住民" | "精通数字工具" |

## 示例

### 示例请求
```
创建以下职位的工作描述：
- 职位：高级前端开发人员
- 部门：工程
- 级别：高级（5年以上经验）
- 类型：全职、远程
- 技术栈：React、TypeScript、GraphQL
- 团队规模：8名工程师
- 公司：B2B SaaS初创公司，B轮
```

### 示例输出

```markdown
# 高级前端开发人员

## 关于我们
我们是一家B轮B2B SaaS初创公司，正在改变企业管理工作流程的方式。我们的工程团队超过40人，为财富500强公司开发产品。

## 关于该职位
加入我们8人的前端团队，设计和构建下一代平台。您将对技术决策产生重大影响，并指导初级开发人员。

## 您将做什么
- 使用React和TypeScript设计和实现复杂的UI功能
- 与设计师合作，创建直观的用户体验
- 优化应用程序性能和可访问性
- 参与我们的GraphQL API设计
- 通过代码审查和结对编程指导初级开发人员
- 参与技术规划和架构讨论

## 我们在寻找

### 必须具备
- 5年以上前端开发经验
- 精通React和TypeScript
- 具有GraphQL或类似查询语言的丰富经验
- 建立可访问、高性能Web应用程序的记录
- 出色的沟通能力

### 加分项
- 具有设计系统经验
- 对开源项目有贡献
- 在B2B SaaS公司工作过
- 熟悉测试框架（Jest、Cypress）

## 我们提供
- 具有竞争力的薪资：$150,000 - $190,000
- 股权包
- 完全远程，灵活的工作时间
- 医疗、牙科和视力保险
- 每年$2,000的学习预算
- 家庭办公津贴

## 如何申请
将您的简历和您感兴趣原因的简短说明发送至careers@company.com
```

## 领域知识

### 职位级别（典型）
| 级别 | 年限 | 范围 |
|-------|-------|-------|
| 入门级/初级 | 0-2 | 个人任务 |
| 中级 | 2-5 | 独立项目 |
| 高级 | 5-8 | 技术领导力 |
| 资深/主管 | 8-12 | 跨团队影响 |
| 原则/总监 | 12+ | 组织范围 |

### 标准福利考虑
- 医疗保险
- 退休计划（401k、养老金）
- 休假/休假政策
- 远程工作选项
- 职业发展
- 产假
- 设备/津贴

## 限制

- 无法保证法律合规性（需人力资源/法律审核）
- 薪资基准可能无法反映当地市场
- 行业特定要求需要领域输入
- 无法验证提供的公司信息
