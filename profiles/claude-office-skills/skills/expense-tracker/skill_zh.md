# 费用跟踪器

全面的费用管理技能，用于跟踪、处理和自动化费用工作流程。

## 核心工作流程

### 1. 收据处理流程

```
收据到报销：
┌─────────────────┐
│  收据图像      │
│  (照片/PDF)    │
└────────┬────────┘
         ▼
┌─────────────────┐
│  OCR提取        │
│  - 供应商       │
│  - 金额         │
│  - 日期         │
│  - 项目         │
└────────┬────────┘
         ▼
┌─────────────────┐
│  自动分类        │
│  - 旅行         │
│  - 餐饮         │
│  - 软件         │
└────────┬────────┘
         ▼
┌─────────────────┐
│  政策检查        │
│  - 限额         │
│  - 审批         │
└────────┬────────┘
         ▼
┌─────────────────┐
│  提交报告        │
└─────────────────┘
```

### 2. 费用类别

| 类别   | 示例   | 默认限额   |
|--------|--------|------------|
| 旅行   | 航班、酒店、交通 | 每日$500 |
| 餐饮   | 团队晚餐、客户餐费 | 每人$100 |
| 软件   | SaaS订阅 | 每月$200 |
| 设备   | 硬件、外设 | 每件$1000 |
| 办公室 | 物资、打印 | 每月$50 |
| 培训   | 课程、会议 | 每年$2000 |

## 收据OCR模板

### 提取字段

```yaml
receipt_extraction:
  required:
    - vendor_name
    - total_amount
    - transaction_date
    - payment_method
  
  optional:
    - line_items
    - tax_amount
    - tip_amount
    - currency
    - receipt_number
  
  validation:
    date_format: "YYYY-MM-DD"
    amount_precision: 2
    currency_codes: ["USD", "EUR", "GBP", "CNY"]
```

## 政策合规

### 自动检查规则

```yaml
compliance_rules:
  receipt_required:
    threshold: 25
    message: "超过$25的费用需要收据"
  
  meal_per_person:
    limit: 75
    message: "人均餐饮限额超出"
  
  提前预订
    travel_days: 14
    savings_expected: 0.20
    message: "提前14天预订旅行可节省费用"
  
  推荐供应商
    酒店: ["万豪", "希尔顿", "凯悦"]
    航空公司: ["联合航空", "达美航空", "美国航空"]
    message: "在可用时使用推荐供应商"
```

### 违规处理

```yaml
violation_actions:
  轻微违规:
    - 标记待审核
    - 通知提交者
    - 允许说明理由
  
  严重违规:
    - 拒绝费用
    - 通知经理
    - 要求纠正
  
  重复违规:
    - 升级至人力资源
    - 需要培训
```

## 报销处理

### 支付计划

```yaml
reimbursement:
  处理天数: [1, 15]  # 双月
  支付方式:
    - 直接存款
    - 工资附加
    - 支票
  
  时间:
    提交截止日期: 5  # 处理前天数
    审批截止日期: 3
    支付延迟: 2  # 处理后工作日
```

## 最佳实践

1. **及时提交**: 交易后7天内提交费用
2. **附上收据**: 始终包含电子收据
3. **正确分类**: 使用标准类别
4. **添加背景**: 每项费用附上业务目的
5. **提交前检查**: 检查政策合规性
6. **实时记录里程**: 实时记录业务里程
