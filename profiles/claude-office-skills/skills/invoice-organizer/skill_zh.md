# 发票组织器

组织、分类和跟踪发票和收据，以实现更好的财务管理。

## 概述

此技能可帮助您：
- 从发票中提取关键数据
- 自动分类费用
- 跟踪付款状态
- 一致地组织文件
- 准备税务/审计

## 如何使用

### 处理发票
```
"从这张发票中提取数据"
"分类这张收据"
"将这张发票添加到我的跟踪列表"
```

### 组织
```
"组织我的发票文件夹"
"为收据创建归档系统"
"按供应商和日期对发票进行排序"
```

### 报告
```
"按类别汇总发票"
"显示未付款的发票"
"生成第一季度费用报告"
```

## 自动化规则

### 自动处理
```markdown
## 发票自动化规则

### 电子邮件处理
| 触发器 | 操作 |
|--------|------|
| 发件人：*@vendor1.com | 自动分类：软件 |
| 主题："发票" | 添加到审查队列 |
| 附件：PDF | 提取数据 |

### 自动分类
| 条件 | 类别 | 置信度 |
|------|------|------|
| 供应商 = Adobe | 软件 > 订阅 | 高 |
| 包含 "flight" | 旅行 > 交通 | 高 |
| 金额 < $50 | 办公室 > 用品 | 中 |

### 提醒
| 条件 | 提醒 |
|------|------|
| 3天内到期 | 电子邮件提醒 |
| 过期 | 每日通知 |
| 大额发票（>$1000） | 需要经理批准 |
```

## 限制

- 无法执行实际文件操作
- OCR 质量影响数据提取
- 类别可能需要手动调整
- 无法直接与会计软件集成
- 汇率需要外部验证
- 税务建议应来自专业人士
