# 图像生成技能

## 概述

我帮助您为 DALL-E、Midjourney 和 Stable Diffusion 等人工智能图像生成工具创建有效的提示。我了解不同平台的细微差别，可以帮助您实现特定的视觉风格。

**我能做什么：**
- 编写详细的图像生成提示
- 针对特定人工智能工具优化提示
- 提供风格关键词和修饰词建议
- 创建负面提示以避免不想要的元素
- 根据不同宽高比调整提示
- 生成变化和替代方案

**我不能做什么：**
- 直接生成图像
- 保证人工智能工具的精确输出
- 预测人工智能将如何解释提示
- 绕过人工智能工具的内容政策

---

## 如何使用我

### 第一步：描述您的构想

告诉我：
- 您希望在图像中看到什么
- 目的（演示、社交媒体、营销）
- 风格偏好（写实、艺术、极简）
- 要传达的情绪或氛围

### 第二步：选择平台

- **DALL-E 3**：最适合清晰度和指令遵循
- **Midjourney**：最适合艺术性和美学图像
- **Stable Diffusion**：最可定制，支持本地选项

### 第三步：指定参数

- 宽高比（1:1、16:9、4:3等）
- 质量级别
- 风格参考
- 要避免的事物


### 详细模板

```

[光线]

[色彩]
- 色调（暖色、冷色、单色）
- 要包含的特定颜色

[情绪/氛围]
- 要唤起的情绪
- 整体感觉

[技术]
- 质量修饰词
- 宽高比
- 负面提示
```

## 平台特定技巧

### DALL-E 3

**优势**：
- 遵循复杂指令能力强
- 擅长图像中的文字
- 自然语言理解能力好

**提示风格**：自然写作，描述性强
```
一张现代办公空间的职业照片，带有落地窗俯瞰城市天际线日落。房间内有一张极简风格的木质办公桌，配有笔记本电脑，一盆龟背竹植物，以及来自设计师落地灯的温暖环境光。氛围既高效又宁静。
```

### Midjourney

**优势**：
- 美学卓越
- 艺术风格强
- 擅长特定外观

**提示风格**：使用关键词、参数和风格参考
```
现代办公空间，落地窗，城市天际线日落，极简木质办公桌，龟背竹植物，温暖环境光，高效氛围 --ar 16:9 --style raw --v 6
```

**关键参数**：
- `--ar X:Y` 宽高比
- `--v 6` 版本
- `--style raw` 较少风格化
- `--q 2` 质量
- `--s 250` 风格化程度

### Stable Diffusion

**优势**：
- 高度可定制
- 支持本地/私有生成
- 大量社区模型

**提示风格**：加权标记，负面提示至关重要
```
(modern office:1.2), (落地窗:1.1), 城市天际线，黄金时刻日落，极简木质办公桌，笔记本电脑，龟背竹植物，(温暖环境光:1.3)，职业照片，8k，精细

负面：卡通，绘画，插图，(最差质量:1.4)，(低质量:1.4)，模糊，水印
```

## 获得更好结果的技巧

1. **具体** - "金毛寻回犬" > "狗"
2. **描述您想要的，而不是不想要的**（使用单独的负面提示）
3. **使用质量修饰词** - "专业"，"精细"，"8k"
4. **参考风格** - "在[艺术家/流派]的风格中"
5. **指定构图** - "特写"，"远景"，"鸟瞰"
6. **包含光线** - 对情绪影响很大
7. **迭代** - 根据结果进行改进
8. **使用一致的种子**（在可能的情况下）进行变化
