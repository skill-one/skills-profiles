# 发票自动化

全面的发票自动化技能，用于在多个会计平台上生成、发送、跟踪和核对发票。

## 核心工作流程

### 3. 自动化工作流程

**从时间跟踪自动生成发票：**
```yaml
触发器: 每周工时表批准
操作:
  - 汇总可计费工时
  - 计算总额
  - 生成发票
  - 发送给客户
  - 记录到会计系统
```

**付款提醒序列：**
```yaml
提醒:
  - 到期前3天
    模板: 友好提醒
  - 到期后1天
    模板: 付款到期
  - 到期后7天
    模板: 逾期通知
  - 到期后30天
    模板: 最终通知
```

```markdown

**发票编号:** INV-{YYYY}{MM}-{####}
**日期:** {issue_date}
**到期日:** {due_date}

### 付款给:
{customer_name}
{customer_address}
{customer_email}

### 项目:
| 描述     | 数量 | 单价 | 金额 |
|----------|-----|------|------|
| {item_1} | {q}  | ${price} | ${amt} |

**小计:** ${subtotal}
**税 ({tax_rate}%):** ${tax_amount}
**总计:** ${total}

### 付款方式:
- 银行转账: {bank_details}
- 信用卡: {payment_link}
- PayPal: {paypal_email}
```

## API集成示例

### QuickBooks发票创建

```javascript
const invoice = {
  CustomerRef: { value: "123" },
  Line: [
    {
      DetailType: "SalesItemLineDetail",
      Amount: 1000,
      SalesItemLineDetail: {
        ItemRef: { value: "1" },
        Qty: 10,
        UnitPrice: 100
      }
    }
  ],
  DueDate: "2024-02-15",
  EmailStatus: "NeedToSend"
};
```

### Stripe发票

```javascript
const invoice = await stripe.invoices.create({
  customer: 'cus_xxx',
  collection_method: 'send_invoice',
  days_until_due: 30,
  auto_advance: true
});

await stripe.invoiceItems.create({
  customer: 'cus_xxx',
  invoice: invoice.id,
  price: 'price_xxx',
  quantity: 1
});

await stripe.invoices.sendInvoice(invoice.id);
```

## 最佳实践

1. **编号一致**: 使用连续可搜索的发票编号
2. **清晰条款**: 始终指定付款条款和接受的付款方式
3. **及时发送**: 在交付后立即发送发票
4. **自动提醒**: 为逾期发票设置提醒序列
5. **定期核对**: 每周将付款与发票匹配
6. **备份记录**: 在多个系统中保留副本
