# 悬疑邮件分析器

分析邮件中的网络钓鱼尝试、诈骗和安全威胁，以防范欺诈行为。

## 概述

此功能可以帮助您：
- 识别网络钓鱼尝试
- 检测诈骗模式
- 分析可疑链接
- 评估邮件真实性
- 提供安全操作建议

## 如何使用

### 分析邮件
```
"这封邮件是否合法？"
"检查这封邮件是否存在网络钓鱼"
"分析这条可疑信息"
```

### 提供邮件内容
包括：
- 发件人电子邮件地址
- 主题行
- 完整邮件正文
- 任何链接（不要点击它们！）

## 威胁指标

### 红旗清单
```markdown
## 邮件安全评估

### 发件人分析
- [ ] **域名不匹配**：显示名称与电子邮件域名不匹配
- [ ] **相似域名**：microsoft.corn、amaz0n.com
- [ ] **免费商业邮箱**：官方公司使用gmail.com
- [ ] **随机字符**：x7y2z@suspicious.com
- [ ] **无回复地址**：无法回复发件人

### 内容分析
- [ ] **紧急压力**："立即行动"、"账户被冻结"
- [ ] **威胁语言**："法律行动"、"账户关闭"
- [ ] **过于美好**：中奖者、遗产
- [ ] **泛化问候**："尊敬的客户" vs 您的名字
- [ ] **语法/拼写错误**：不寻常的错误
- [ ] **请求敏感信息**：密码、社会安全号码、信用卡
- [ ] **意外附件**：尤其是 .exe、.zip、.docm

### 链接分析
- [ ] **鼠标悬停显示不同URL**：显示 vs 实际链接
- [ ] **缩短的URL**：bit.ly、tinyurl隐藏目标
- [ ] **HTTP（非HTTPS）**：对敏感页面不安全
- [ ] **拼写错误的域名**：paypa1.com、netlfix.com
- [ ] **IP地址URL**：http://192.168.1.1/login
- [ ] **过多的子域名**：secure.login.verify.site.com

### 技术指标
- [ ] **缺少安全头**：SPF、DKIM、DMARC失败
- [ ] **不寻常的发送时间**：凌晨3点从"本地银行"
- [ ] **批量邮件标记**：存在大量邮件头
```

## 常见诈骗类型

### 网络钓鱼类别
```markdown
## 网络钓鱼攻击类型

### 1. 凭证网络钓鱼
**目标**：窃取登录凭证
**伪装成**：银行、电子邮件提供商、社交媒体
**策略**：假冒登录页面、紧急账户问题
**示例**："您的密码今天到期"

### 2. CEO/商业电子邮件诈骗
**目标**：转账欺诈
**伪装成**：高管、供应商、合作伙伴
**策略**：紧急、权威、保密
**示例**："请转账50,000美元用于紧急交易，保持机密"

### 3. 技术支持诈骗
**目标**：远程访问或付款
**伪装成**：微软、苹果、互联网服务提供商
**策略**：假冒病毒警报、账户被入侵
**示例**："检测到您的计算机病毒，立即致电"

### 4. 发票/付款诈骗
**目标**：向欺诈账户付款
**伪装成**：供应商、客户、内部
**策略**：假冒发票、更改银行信息
**示例**："更新发票付款的银行账户"

### 5. 包裹投递诈骗
**目标**：凭证或恶意软件
**伪装成**：联邦快递、联合包裹、美国邮政服务、敦豪速递
**策略**：投递失败、跟踪问题
**示例**："包裹无法投递，点击重新安排"

### 6. 税务/政府诈骗
**目标**：个人信息或付款
**伪装成**：美国国税局、社会保障管理局、政府机构
**策略**：法律威胁、退款承诺
**示例**："美国国税局通知：立即采取行动"
```

### 合法 vs 网络钓鱼对比
```markdown
## 如何识别差异

### 银行邮件示例

| 方面 | 合法 | 网络钓鱼 |
|--------|------------|----------|
| 发件人 | alerts@chase.com | chase-alert@gmail.com |
| 问候 | "你好，约翰·史密斯" | "尊敬的客户" |
| 紧急 | "方便时请查看" | "立即采取行动" |
| 链接 | 链接到chase.com | 链接到chase-verify.com |
| 操作 | "登录您的账户" | "在此处输入密码" |
| 语气 | 专业、冷静 | 威胁、紧急 |
| 个性化 | 账户编号4532 | 无具体信息 |
```

## 行动指南

### 该怎么做
```markdown
## 响应协议

### 如果邮件可疑（🔴🟠）
1. ❌ 不要点击链接
2. ❌ 不要下载附件
3. ❌ 不要回复
4. ❌ 不要拨打邮件中的电话号码
5. ✅ 通过官方渠道验证
   - 直接访问官方网站（输入URL）
   - 拨打已知的客户服务电话
6. ✅ 报告邮件
   - 转发给IT安全部门
   - 报告被冒充的公司
7. ✅ 删除邮件

### 如果您已经点击了
1. ✅ 断开互联网连接（如果怀疑恶意软件）
2. ✅ 立即更改密码
3. ✅ 启用双因素认证
4. ✅ 监控账户是否存在可疑活动
5. ✅ 运行杀毒软件扫描
6. ✅ 向IT部门报告
7. ✅ 如果分享了财务信息，考虑信用监控

### 报告渠道
- **通用网络钓鱼**：reportphishing@apwg.org
- **美国国税局诈骗**：phishing@irs.gov
- **联邦贸易委员会**：reportfraud.ftc.gov
- **公司特定**：通常为phishing@company.com
```

## 邮件头分析

### 该检查什么
```markdown
## 邮件头深入分析

### 需要检查的关键头
| 头 | 显示什么 |
|--------|---------------|
| From | 显示的发送者 |
| Return-Path | 实际回复地址 |
| Received | 服务器路径（底部=起源） |
| SPF | 发送者是否授权？ |
| DKIM | 签名是否有效？ |
| DMARC | 政策结果 |

### 认证结果
| 结果 | 含义 |
|--------|---------|
| pass | 合法 |
| fail | 可能被伪造 |
| softfail | 可能被伪造 |
| none | 未设置政策 |
```

## 限制

- 无法在没有提供的情况下访问实际邮件头
- 无法验证实时域名声誉
- 无法点击或分析实时链接
- 一些复杂的网络钓鱼可能通过分析
- 合法邮件可能存在一些警告标志
- 人工判断对于最终决定至关重要
