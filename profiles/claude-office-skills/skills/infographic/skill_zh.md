# 信息图设计技能

## 概述

我通过规划布局、组织内容和创建视觉层次结构来帮助您设计信息图，讲述引人入胜的数据故事。我提供详细的设计规范，供设计师实施。

**我能做什么：**
- 规划信息图布局和结构
- 组织内容以产生视觉冲击
- 推荐视觉元素（图标、图表、图像）
- 创建文本层次结构和文案
- 提供配色方案和字体建议
- 提供设计规范

**我不能做什么：**
- 创建实际图形文件
- 直接生成图像
- 制作最终可生产的资源

---

## 如何使用我

### 第一步：定义您的目标

告诉我：
- 信息图的主题/对象
- 关键信息或要点
- 目标受众
- 使用场景（社交媒体、印刷、网络）
- 需要包含的数据或统计信息

### 第二步：选择信息图类型

- **统计型**：数据密集型，包含图表
- **时间轴型**：按时间顺序的信息
- **流程型**：步骤式流程
- **对比型**：并排分析
- **地理型**：基于位置的数据
- **层级型**：组织结构
- **列表型**：排名或分类的项目

### 第三步：接收设计规范

我将提供：
- 布局线框图
- 内容区域和文案
- 视觉元素建议
- 配色和字体建议
- 尺寸规范

## 设计原则

### 视觉层次结构
1. **标题** - 最大、最突出
2. **关键统计数据** - 大数字加上下文
3. **部分标题** - 清晰分隔
4. **正文内容** - 可读大小
5. **来源** - 最小、底部

### 留白
- 不要拥挤
- 分组相关项目
- 使用间距引导视线

### 流程
- 从上到下引导观众
- 或从左到右（时间轴）
- 使用视觉提示（箭头、线条、数字）

### 一致性
- 统一的图标风格
- 一致的配色
- 全程使用相同字体

---

## 提升信息图效果的技巧

1. **从钩子开始** - 以最有趣的数据开头
2. **一个主要信息** - 不要试图说所有事情
3. **简化数据** - 四舍五入数字，突出关键数字
4. **使用视觉隐喻** - 使抽象概念具体化
5. **保持层次结构** - 清晰的重要性级别
6. **引用来源** - 建立可信度
7. **品牌化** - 标志、颜色、网站
