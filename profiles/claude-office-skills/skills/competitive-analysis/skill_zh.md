# 竞争分析技能

## 概述

我帮助你系统地分析竞争对手，为战略决策提供信息。我比较产品、功能、定价、市场定位和进入市场策略。

**我能做什么：**
- 建立竞争对手档案
- 创建功能对比矩阵
- 分析定价策略
- 绘制市场定位图
- 识别竞争优势
- 生成战略建议

**我不能做什么：**
- 获取竞争对手内部数据
- 提供实时定价更新
- 持续监控竞争对手活动
- 获取专有市场研究

---

## 如何使用我

### 第一步：定义范围

告诉我：
- 你的公司/产品（用于背景信息）
- 要分析的竞争对手（或让我帮你识别）
- 行业/市场细分
- 地理范围
- 要关注的具体方面

### 第二步：选择分析类型

- **快速对比**：功能/定价矩阵
- **完整档案**：全面的竞争对手深度分析
- **战略分析**：SWOT、定位、建议
- **战斗卡**：面向销售的竞争对手摘要

### 第三步：指定输出

- 对比表格
- 定位图
- SWOT分析
- 战略建议
- 销售战斗卡

## 分析框架

### 波特竞争分析

```
┌─────────────────────────────────────────────────────────────┐
│                  竞争对手分析                         │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  1. 未来目标         2. 当前策略                │
│     - 驱动竞争对手的是什么？        - 他们如何竞争             │
│       竞争对手？        - 他们正在做什么？         │
│                                                              │
│  3. 假设          4. 能力                    │
│     - 关于自身       - 优势                    │
│     - 关于行业       - 劣势                   │
│                                                              │
│             ↓ 结合 = 竞争对手响应档案 ↓       │
│                                                              │
│  - 竞争对手会做什么？                                  │
│  - 竞争对手在哪里脆弱？                           │
│  - 什么会引发最大的报复？                          │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 竞争定位矩阵

```
                    高端
                       │
   市场细分高端       │       广域高端
   (专业化，       │       (市场领导者,
    高价)        │        高端品牌)
                       │
市场狭窄 ────────────────┼──────────────────── 市场广泛
   聚焦               │                     聚焦
                       │
   市场细分价值       │       成本领先
   (专业化，       │       (大众市场,
    价值价格)       │        低成本)
                       │
                     价值
```
