# PDF OCR 提取

使用 OCR 技术从扫描文档和基于图像的 PDF 中提取文本。

## 概述

此技能可帮助您：
- 从扫描文档中提取文本
- 使图像 PDF 可搜索
- 数字化纸质文档
- 处理手写文本（有限）
- 批量处理多个文档

## 如何使用

### 基本OCR
```
"从这份扫描的 PDF 中提取文本"
"OCR 这份文档图像"
"使这个 PDF 可搜索"
```

### 带选项
```
"提取 1-10 页的文本，英文语言"
"OCR 这份文档，保留布局"
"提取并以结构化数据输出"
```

## 文档类型

### 不同文档类型的 OCR 质量预期
| 文档类型 | 预期质量 | 提示 |
|---------------|------------------|------|
| **打印文档** | ⭐⭐⭐⭐⭐ 95%+ | 最佳结果 |
| **印刷书籍** | ⭐⭐⭐⭐ 90%+ | 注意老化 |
| **表格** | ⭐⭐⭐⭐ 85%+ | 检查框可能需要手动 |
| **表格/数据** | ⭐⭐⭐ 80%+ | 结构可能需要修复 |
| **手写（整洁）** | ⭐⭐ 60-80% | 结果不稳定 |
| **手写（草书）** | ⭐ 30-60% | 通常需要手动审核 |
| **混合内容** | ⭐⭐⭐ 75%+ | 取决于复杂性 |

## 预处理技巧

### 图像质量检查清单
OCR 之前确保：
- [ ] **分辨率**： 300 DPI 最低（600 用于小字）
- [ ] **对比度**： 清晰的黑色文本在白色背景上
- [ ] **对齐**： 文档是直的（未倾斜）
- [ ] **完整性**： 无裁剪边缘
- [ ] **清洁度**： 无污渍、标记或阴影

### 常见预处理步骤
| 问题 | 解决方案 |
|-------|----------|
| 低分辨率 | 首先放大图像 |
| 倾斜/旋转 | 自动校正倾斜 |
| 对比度差 | 调整级别/阈值 |
| 噪声/点 | 应用降噪 |
| 阴影 | 扁平化光照 |
| 彩色文档 | 转换为灰度 |

## 语言支持

### 支持的语言
- **优秀**： 英语、西班牙语、法语、德语、意大利语
- **良好**： 中文（简体/繁体）、日语、韩语
- **中等**： 阿拉伯语、希伯来语（从右到左支持）、印地语
- **基础**： 许多其他语言，质量不一

### 多语言文档
```
"OCR 这份文档，自动检测语言"
"提取文本，主要：英语，次要：中文"
```

## 工具推荐

### 云服务
- Google Cloud Vision（极高准确度）
- Amazon Textract（适合表格）
- Azure Computer Vision（平衡）
- Adobe Acrobat（集成）

### 桌面软件
- ABBYY FineReader（最佳准确度）
- Adobe Acrobat Pro（可靠）
- Readiris（性价比高）
- Tesseract（免费，开源）

### 编程库
- pytesseract（Python + Tesseract）
- EasyOCR（Python，多语言）
- PaddleOCR（Python，适合亚洲语言）

## 限制

- 无法保证 100% 准确度
- 手写文本准确度低
- 非常小的文本可能无法提取
- 装饰性字体有问题
- 背景图像降低质量
- 无法读取复杂图形中的文本
- 处理时间随页数增加而增加
