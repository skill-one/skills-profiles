# 员工筛选

根据职位要求筛选工作申请，高效识别顶尖候选人。

## 概述

此技能可帮助您：
- 根据职位要求评估简历
- 一致地给候选人打分
- 区分必须具备和优先具备的资质
- 标记潜在问题
- 对申请人进行面试排序

## 如何使用

### 单个候选人
```
"根据我们的[职位名称]要求筛选这份简历"
"评估该申请人的[职位]角色"
```

### 批量筛选
```
"为高级开发人员职位筛选这10份申请"
"根据我们的要求对候选人进行排名"
```

### 带有标准
```
"筛选标准：5年以上Python、AWS经验，机器学习为优先"
```

```markdown

### 优先具备（推荐）
| 要求 | 奖分 | 标准 |
|-------------|-------|----------|
| [技能3] | +5分 | [描述] |

```

## 最佳实践

### 公平筛选
- 仅关注与工作相关的标准
- 忽略受保护特征
- 使用一致的评分
- 记录决策
- 考虑多元化背景

### 偏见意识
- 姓名/性别偏见：关注资质
- 亲近偏见：多元化面试小组
- 确认偏见：评分前避免直觉
- 晕轮效应：单独评估每个标准

### 法律注意事项
- 仅使用与工作相关的标准
- 一致应用标准
- 保留筛选记录
- 有人力资源部门审核流程
- 考虑不利影响

## 局限性

- 无法核实工作经历
- 可能忽略非传统背景的背景信息
- 评分是指导而非绝对
- 无法全面评估文化契合度或软技能
- 人类判断对最终决定至关重要
