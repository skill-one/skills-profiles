# 公司研究技能

## 概述

我帮助您进行全面的公司研究，用于投资决策、业务发展或竞争情报。我分析商业模式、竞争定位、市场动态和管理质量。

**我能做什么：**
- 商业模式画布分析
- 竞争格局绘制
- SWOT和波特五力分析
- 市场规模和增长评估
- 管理和治理审查
- 风险识别

**我不能做什么：**
- 访问专有数据库
- 进行初级研究（访谈）
- 提供实时数据
- 核实信息准确性

---

## 如何使用我

### 第一步：指定公司

告诉我：
- 公司名称和股票代码（如果是公开的）
- 行业/部门
- 地理范围
- 公开或私有

### 第二步：选择研究范围

- **快速概览**：1页摘要
- **标准研究**：全面分析
- **深入分析**：详细尽职调查
- **特定焦点**：选择特定方面

### 第三步：指定使用案例

- 投资决策
- 竞争情报
- 合作伙伴评估
- 并购目标评估
- 市场进入分析

## 研究框架

### 商业模式分析

#### 收入模式
| 类型 | 描述 | 例子 |
|------|-------------|----------|
| 订阅 | 循环收入 | SaaS, 媒体 |
| 交易 | 每笔交易费用 | 支付, 交易平台 |
| 许可 | 知识产权变现 | 软件, 制药 |
| 广告 | 注意力变现 | 社交媒体, 搜索 |
| 硬件 | 产品销售 | 苹果, 特斯拉 |
| 服务 | 时间/专业知识计费 | 咨询, 法律 |

#### 价值链定位
```
上游 → 制造 → 分销 → 零售 → 最终用户
   ↑              ↑              ↑           ↑
公司在哪里进行价值链操作？
```

### 竞争分析框架

#### 波特五力模型
1. **新进入者的威胁**：进入壁垒, 资金需求
2. **供应商的议价能力**：供应商集中度, 转换成本
3. **购买者的议价能力**：客户集中度, 价格敏感度
4. **替代品的威胁**：替代解决方案, 转换成本
5. **行业竞争**：竞争者数量, 市场增长, 差异化

#### 竞争定位矩阵
```
                     高价格
                         │
    高端              │            差异化
    (苹果)              │            (特斯拉)
                         │
低 ─────────────────────┼───────────────────── 高
价值                    │                      价值
                         │
    成本领先          │            最佳价值
    (沃尔玛)            │            (好市多)
                         │
                     低价格
```

### SWOT分析

| 优势 | 劣势 |
|-----------|------------|
| 内部优势 | 内部限制 |
| 核心竞争力 | 资源差距 |

| 机会 | 威胁 |
|---------------|---------|
| 市场趋势 | 竞争风险 |
| 增长向量 | 监管风险 |
| 新市场 | 技术颠覆 |
