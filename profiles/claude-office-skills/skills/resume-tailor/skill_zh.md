# 简历定制技能

## 概述

我帮助你针对特定的职位申请定制简历。与其向所有地方发送相同的通用简历，我会帮你突出最相关的经验，并匹配招聘人员和ATS系统正在寻找的语言。

**我能做什么：**
- 分析职位描述以识别关键要求
- 重组你的经验以突出相关技能
- 提出关键词优化建议以兼容ATS
- 通过量化成就改进要点
- 调整不同行业的语气和格式

**我不能做什么：**
- 编造你没有的经验
- 保证你一定能得到工作
- 取代真实资质的必要性

---

## 如何使用我

### 第一步：分享你的材料
提供：
1. **你的当前简历**（粘贴文本或上传）
2. **你申请的职位描述**
3. **任何附加背景信息**（职业转换？内部调动？具体顾虑？）

### 第二步：我会分析
我会识别：
- 雇主想要的关键技能和资质
- 你的经验如何与他们的要求相匹配
- 需要弥补的差距和需要强调的优势

### 第三步：获取你的定制简历
我会提供：
- 优化后的简历版本
- 具体的修改建议和原因
- 申请的额外建议

## 简历如何引起注意

### ATS（申请人跟踪系统）优化

大多数大公司使用ATS在人类看到简历之前进行筛选。

**ATS工作原理：**
1. 扫描与职位描述匹配的关键词
2. 根据关键词匹配百分比对候选人进行排名
3. 只有排名靠前的简历才会被人类审阅者看到

**优化技巧：**
| 做 | 不要 |
|-----|-------|
| 使用职位发布中的确切关键词 | 使用ATS无法识别的巧妙同义词 |
| 书写全称并包含缩写 | 假设ATS知道所有缩写 |
| 使用标准部分标题 | 使用像"我的旅程"这样的创意标题 |
| 以PDF或DOCX格式提交 | 提交非标准格式 |
| 使用简单格式 | 使用表格、列、图形 |

### 各类强力动词

**领导力：**
- 指导、领导、管理、协调、发起
- 倡导、开创、建立、启动

**成就：**
- 实现、交付、超越、超过、表现优异
- 增加、减少、改进、优化、简化

**技术：**
- 开发、设计、实施、架构、设计
- 自动化、集成、迁移、部署、扩展

**沟通：**
- 合作、展示、谈判、影响、倡导
- 撰写、记录、培训、指导、促进

### 量化公式

将薄弱要点转化为强有力的要点：

**薄弱：** "负责销售"
**强：** "通过获取45个企业账户，产生了250万美元的新收入"

**公式：** [强力动词] + [什么] + [量化结果] + [如何/背景]

**示例：**
- "通过实施CI/CD管道，将部署时间缩短了75%（从4小时到1小时）"
- "管理跨职能团队，由12名工程师组成，分布在3个时区，按时交付产品"
- "通过实施主动支持计划，将客户留存率提高了23%"

## 行业特定指南

### 技术/软件工程

**必须包含的部分：**
- 技术技能（语言、框架、工具）
- 项目（如果公开，请提供GitHub链接）
- 带有影响指标的经验

**需要包含的关键词：**
- 职位发布中提到的特定技术
- 方法论（敏捷、Scrum、DevOps）
- 规模指标（用户、交易、数据大小）

**示例要点：**
> "架构微服务迁移，将延迟降低40%，并支持10倍的流量增长"

### 商业/咨询

**必须包含的部分：**
- 突出专业知识的职业概述
- 关键成就部分
- 教育背景（尤其是针对入门级）

**需要包含的关键词：**
- 商业成果（收入、效率、投资回报率）
- 方法论（六西格玛、精益、战略）
- 客户/利益相关者管理

**示例要点：**
> "领导战略计划，为6个业务部门节省了1500万美元"

### 市场/创意

**必须包含的部分：**
- 作品集链接
- 营销活动结果及指标
- 工具和平台专业知识

**需要包含的关键词：**
- 特定平台（Google Ads、HubSpot等）
- 指标（ROAS、CTR、转化率）
- 内容类型（SEO、社交、电子邮件）

**示例要点：**
> "通过跨5个渠道的整合内容策略，将合格线索增加150%"

### 医疗保健

**必须包含的部分：**
- 执照和认证
- 临床经验
- 合规/监管知识

**需要包含的关键词：**
- 特定认证（RN、CNA等）
- 系统（Epic、Cerner）
- 合规术语（HIPAA、联合委员会）

### 金融

**必须包含的部分：**
- 执照（CFA、CPA、系列7）
- 技术技能（Excel、SQL、Python）
- 交易/交易经验

**需要包含的关键词：**
- 交易规模和类型
- 监管知识
- 特定方法论（DCF、LBO）

## 获得更好结果的技巧

1. **包含完整的职位描述** - 不要总结，我需要确切的关键词
2. **分享你的完整简历** - 我需要看到你所有的经验来选择要突出什么
3. **告诉我你的顾虑** - 担心差距？职业转换？让我知道
4. **指定公司** - 不同公司有不同的文化
5. **迭代** - 根据你的反馈我们可以一起完善

## 常见问题

**问：我应该有多个版本的简历吗？**
答：是的！有一个"基础"简历，包含所有内容，然后为每个申请定制。保留2-3个针对不同角色类型的版本。

**问：我的简历应该有多长？**
答： 
- 0-5年经验：1页
- 5-15年：1-2页
- 15年以上或高管：最多2页
- 学术CV：可以更长

**问：我应该包含我所有的工龄吗？**
答：专注于相关经验。旧或不相关的职位可以总结为一行或省略。

**问：个人项目呢？**
答：如果相关就包含！尤其是对于技术职位或职业转换者。展示主动性和热情。

## 限制

- 我无法验证你的经验 - 要诚实
- 我不知道内部公司文化 - 需要单独研究
- ATS系统各不相同 - 没有保证能通过所有系统
- 我看不到你的实际格式 - 你需要自己应用更改
- 对于高管职位，请考虑专业简历服务
