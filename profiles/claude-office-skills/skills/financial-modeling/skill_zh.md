# 财务建模技能

## 概述

我帮助您构建集成式三报表财务模型，将利润表、资产负债表和现金流量表相互关联。这些模型对于估值、预算和战略规划至关重要。

**我能做什么：**
- 构建利润表预测
- 创建资产负债表预测
- 生成现金流量表
- 建模营运资本需求
- 构建债务计划和利息计算
- 创建情景分析（基准/牛市/熊市案例）

**我不能做什么：**
- 获取实时财务数据
- 保证预测准确性
- 提供会计建议
- 替代专业财务分析

---

## 如何使用我

### 第一步：提供历史数据

我需要 2-3 年的：
- 利润表（收入、销货成本、营业费用）
- 资产负债表（资产、负债、股东权益）
- 现金流量表（可选但有助于分析）

### 第二步：定义预测假设

关键驱动因素：
- 收入增长率
- 毛利率
- 营业费用比率
- 资本支出占收入的百分比
- 营运资本天数（应收账款周转天数、存货周转天数、应付账款周转天数）

### 第三步：选择模型范围

- **基础版**：仅包含利润表
- **标准版**：利润表 + 资产负债表
- **完整版**：包含现金流量表的完整三报表模型

## 模型架构

### 三报表关联

```
┌─────────────────────────────────────────────────────────────┐
│                    利润表                             │
│  收入 → 毛利润 → 营业收入 → 净利润                     │
└─────────────────────────┬───────────────────────────────────┘
                          │
        净利润流入留存收益
                          │
                          ▼
┌─────────────────────────────────────────────────────────────┐
│                    资产负债表                            │
│  资产 = 负债 + 股东权益                              │
│  （必须通过现金作为调节项平衡）                        │
└─────────────────────────┬───────────────────────────────────┘
                          │
        资产负债表项目变动驱动现金流量表
                          │
                          ▼
┌─────────────────────────────────────────────────────────────┐
│                  现金流量表                            │
│  营业活动现金流量 + 投资活动现金流量 + 融资活动现金流量 = 现金变动    │
│  期末现金流入资产负债表                    │
└─────────────────────────────────────────────────────────────┘
```

### 关键公式

#### 利润表驱动因素
```
收入 = 去年收入 × (1 + 增长率)
销货成本 = 收入 × (1 - 毛利率%)
毛利润 = 收入 - 销货成本
营业费用 = 收入 × 营业费用%
EBITDA = 毛利润 - 营业费用
折旧与摊销 = 去年固定资产 × 折旧与摊销率 OR 收入 × 折旧与摊销%
EBIT = EBITDA - 折旧与摊销
利息 = 平均负债 × 利率
EBT = EBIT - 利息
税项 = EBT × 税率
净利润 = EBT - 税项
```

#### 资产负债表驱动因素
```
应收账款 = 收入 × (DSO / 365)
存货 = 销货成本 × (DIO / 365)
应付账款 = 销货成本 × (DPO / 365)
固定资产 = 去年固定资产 + 资本支出 - 折旧与摊销
留存收益 = 去年留存收益 + 净利润 - 股利
现金 = 总负债 + 股东权益 - 其他资产（调节项）
```

#### 现金流量表
```
经营活动现金流量：
  净利润
  + 折旧与摊销（非现金）
  - 应收账款增加
  - 存货增加
  + 应付账款增加
  = 经营活动现金流量

投资活动现金流量：
  - 资本支出
  = 投资活动现金流量

融资活动现金流量：
  + 债务发行
  - 债务偿还
  - 股利
  = 融资活动现金流量

现金净变动 = 经营活动现金流量 + 投资活动现金流量 + 融资活动现金流量
```

## 获得更好结果的技巧

1. **提供清晰的历史数据**，格式保持一致
2. **明确说明增长驱动因素**（销量 vs 价格，有机 vs 收购）
3. **说明行业背景**，以便进行适当基准比较
4. **要求情景分析**，了解结果范围
5. **要求关键假设敏感性表**

## 局限性

- 预测的准确性取决于假设质量
- 无法模拟复杂的公司结构
- 自动化处理一次性项目
- 简化的税务计算
- 假设货币不变（无外汇建模）
