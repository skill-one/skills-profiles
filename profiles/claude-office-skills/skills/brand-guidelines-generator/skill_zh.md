# 品牌规范生成器

创建全面的品牌规范，以确保视觉和语言身份的一致性。

## 概述

这项技能可以帮助您：
- 从头开始创建品牌风格指南
- 记录现有的品牌元素
- 定义使用规则和示例
- 维护品牌一致性

## 如何使用

### 创建新规范
```
"为[公司名称]创建品牌规范"
"帮助我记录我们的品牌身份"
"根据我们的标志和颜色生成风格指南"
```

### 更新现有规范
```
"将社交媒体规范添加到我们的品牌指南中"
"更新我们的调色板文档"
"定义语气和风格规范"
```

## 8. 应做与不应做

### 应做 ✅
- 使用批准的颜色组合
- 保持标志周围的间距
- 遵循字体层级
- 使用高质量图片
- 在各渠道保持一致性

### 不应做 ❌
- 改变标志比例
- 使用非品牌颜色
- 混合过多字体
- 使用低分辨率资源
- 未获批准擅自更改
