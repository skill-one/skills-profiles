# DCF估值技能

## 概述

我帮助您构建折现现金流（DCF）模型，以估算公司的内在价值。DCF是投资银行、对冲基金和专业投资者所使用的根本性估值黄金标准。

**我能做什么：**
- 基于财务数据构建完整的DCF模型
- 计算加权平均资本成本（WACC）
- 预测未来自由现金流
- 估算终值（戈登增长模型或退出倍数）
- 对关键假设进行敏感性分析
- 生成专业估值摘要

**我不能做什么：**
- 保证预测的准确性
- 考虑不可预测的未来事件
- 提供投资建议
- 替代专业的财务尽职调查

---

## 如何使用我

### 第一步：提供财务数据

我需要：
- 历史财务数据（3-5年的收入、EBITDA、资本支出、折旧与摊销）
- 当前流通股数量
- 当前股价（可选，用于比较）
- 行业/部门背景

### 第二步：设定假设

需要指定的关键假设（或我将使用行业默认值）：
- 收入增长率（第1-5年）
- EBITDA利润率趋势
- 资本支出占收入的百分比
- 营运资本变化
- 终值增长率
- 折现率（WACC）

### 第三步：选择模型类型

- **标准DCF**：5年预测+终值
- **两阶段DCF**：高增长+稳定增长阶段
- **三阶段DCF**：增长、过渡、成熟阶段

## DCF模型框架

### 第一步：预测自由现金流（FCF）

```
权益自由现金流（UFCF）=
    EBIT × (1 - 税率)
  + 折旧与摊销
  - 资本支出
  - 营运资本变化
```

### 第二步：计算WACC

```
WACC = (E/V × Re) + (D/V × Rd × (1 - Tc))

其中：
E = 股权市值
D = 债务市值
V = E + D（总价值）
Re = 股权成本（CAPM：无风险利率 + β × 市场风险溢价）
Rd = 债务成本
Tc = 企业所得税率
```

#### 股权成本CAPM公式
```
Re = Rf + β × (Rm - Rf)

其中：
Rf = 无风险利率（10年期国债）
β = 股票贝塔（系统性风险）
Rm - Rf = 股权风险溢价（通常为5-6%）
```

### 第三步：计算终值

#### 方法A：戈登增长模型
```
终值 = FCF(n+1) / (WACC - g)

其中：
FCF(n+1) = 最终年FCF × (1 + g)
g = 终值增长率（通常为2-3%，≤ GDP增长率）
```

#### 方法B：退出倍数
```
终值 = EBITDA(n) × 退出倍数

各行业常见倍数：
- 科技：10-15倍
- 医疗保健：8-12倍
- 消费：6-10倍
- 工业：5-8倍
```

### 第四步：折现到现值

```
企业价值 = Σ [FCF(t) / (1 + WACC)^t] + [TV / (1 + WACC)^n]

股权价值 = 企业价值 - 净债务 + 现金

内在价值每股 = 股权价值 / 流通股数量
```

## 获取更好结果的技巧

1. **提供历史数据**以获得更准确的预测
2. **明确说明增长假设**而不是使用默认值
3. **指定行业**以获得适当的可比公司
4. **要求敏感性分析**以了解估值范围
5. **与市盈率、EV/EBITDA等倍数进行交叉验证**以进行合理性检查

---

## 局限性

- 垃圾进垃圾出 - 结果取决于假设质量
- 终值通常占总价值的60-80%
- 不考虑期权或实物期权价值
- 假设在整个预测期内WACC保持不变
- 不适用于早期阶段亏损公司
