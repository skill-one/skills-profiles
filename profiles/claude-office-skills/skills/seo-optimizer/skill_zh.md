## 关键词研究框架

### 研究流程

```yaml
keyword_research:
  step_1_seed_keywords:
    sources:
      - 头脑风暴：核心产品术语
      - 竞争对手：前3名竞争对手关键词
      - 客户语言：支持工单、评论
      - 相关搜索：谷歌建议
      
  step_2扩展：
    工具：
      - 谷歌关键词规划师
      - ahrefs/semrush
      - answerthepublic
      - 谷歌趋势
    
  step_3分类：
    按意图：
      信息性："如何"、"什么是"、"指南"
      导航性：品牌术语
      商业性："最佳"、"vs"、"评论"
      交易性："购买"、"价格"、"演示"
      
  step_4优先级：
    评分：
      搜索量：1-5（越高越好）
      关键词难度：1-5（越低越好）
      商业相关性：1-5（越高越好）
      优先级分数：(量 × 相关性) / 难度
```

## 站内 SEO 检查清单

### 内容元素

```yaml
on_page_checklist:
  title_tag:
    格式："主要关键词 | 次要关键词 | 品牌"
    长度：50-60个字符
    要求：
      - 关键词在开头：是
      - 每页唯一：是
      - 引人点击：是
      
  meta_description:
    长度：150-160个字符
    要求：
      - 包含关键词：是
      - 包含行动号召：是
      - 每页唯一：是
      
  h1_tag：
    数量：每页1个
    要求：
      - 包含主要关键词：是
      - 与标题略有不同：是
      
  标题结构：
    h2：主要部分（2-6个）
    h3：子部分
    h4：细节（如有需要）
    关键词：自然出现在标题中
    
  内容：
    字数：
      产品页面：500-1000
      博客文章：1500-2500
      主题页面：3000+
    关键词使用：
      密度：1-2%
      在前100个字：是
      在最后100个字：是
      LSI关键词：包含相关术语
      
  图片：
    alt文本：描述性+关键词
    文件名：keyword-descriptive-name.jpg
    压缩：针对网络优化
    
  内部链接：
    数量：每页3-5个
    锚文本：关键词丰富
    结构：主题集群
    
  外部链接：
    数量：2-3个到权威网站
    rel：nofollow（如有需要）
```

### URL 结构

```yaml
url_best_practices:
  格式：domain.com/类别/关键词别名
  
  规则：
    - 全小写：始终
    - 连字符：单词之间
    - 长度：少于75个字符
    - 关键词：包含主要
    - 日期：除非是新闻
    - 参数：尽可能避免
    
  示例：
    好："/blog/seo-optimization-guide"
    坏："/blog/2024/01/15/the-ultimate-seo-guide-for-beginners-in-2024/"
```

## 技术SEO审核

### 审核清单

```yaml
technical_seo_audit:
  可抓取性：
    - robots_txt：正确配置
    - sitemap_xml：提交给GSC
    - 抓取错误：无
    - 被阻塞资源：检查
    
  可索引性：
    - 真名标签：正确
    - noindex页面：仅有意为之
    - 重复内容：已解决
    - 薄内容：改进或无索引
    
  网站速度：
    指标：
      - lcp：<2.5s（最大内容绘制）
      - fid：<100ms（首次输入延迟）
      - cls：<0.1（累积布局偏移）
    工具：
      - 谷歌页面速度洞察
      - gtmetrix
      - webpagetest
    常见修复：
      - 图片优化
      - 懒加载
      - 简化CSS JS
      - 浏览器缓存
      - CDN实现
      
  移动友好性：
    - 响应式设计：是
    - 点击目标：适当大小
    - 字体大小：可读
    - 视口配置：是
    
  HTTPS：
    - ssl证书：有效
    - 混合内容：无
    - HTTP重定向：到HTTPS
    
  结构化数据：
    类型：
      - 组织
      - 产品
      - 文章
      - FAQ
      - 面包屑
    验证：谷歌丰富结果测试
```

### 核心网络指标优化

```yaml
core_web_vitals:
  lcp优化：
    - 预加载英雄图片
    - 优化服务器响应时间
    - 移除渲染阻塞资源
    - 使用CDN
    
  fid优化：
    - 最小化javascript
    - 推迟非关键JS
    - 使用web workers
    - 分割长任务
    
  cls优化：
    - 设置图片尺寸
    - 预留广告空间
    - 避免在现有内容上方插入
    - 使用变换动画
```

## 内容优化

### 内容简报模板

```yaml
content_brief:
  标题："{SEO优化标题}"
  
  目标关键词：
    主要："[主要关键词]"
    次要：["关键词2"、"关键词3"]
    LSI：["相关术语1"、"相关术语2"]
    
  搜索意图：信息性|商业性|交易性
  
  目标字数：2000
  
  概要：
    - h2：引言
      备注：钩子+预览
      
    - h2：什么是[主题]
      h3：定义
      h3：为什么重要
      
    - h2：如何[主要动作]
      h3：步骤1
      h3：步骤2
      h3：步骤3
      
    - h2：最佳实践
      h3：实践1
      h3：实践2
      
    - h2：常见错误
    
    - h2：FAQ
      问题：来自人们也问
      
    - h2：结论
      包含：行动号召
      
  要超越的竞争对手：
    - url_1：字数，差距
    - url_2：字数，差距
    - url_3：字数，差距
    
  独特角度：什么让我们与众不同
  
  内部链接：
    - "[锚文本](/相关页面)"
    
  行动号召：读者应该采取什么行动
```
