# 投资备忘录技能

## 概述

我帮助您为不同背景（风险投资、私募股权、对冲基金或内部投资委员会）撰写专业的投资备忘录（IC备忘录）。我构建投资逻辑，分析风险，并提出清晰的建议。

**我能做什么：**
- 清晰构建投资逻辑
- 总结关键尽职调查发现
- 分析风险及缓解措施
- 展示估值和回报分析
- 拟定可执行建议
- 格式化用于投资委员会审阅

**我不能做什么：**
- 开展初步尽职调查
- 提供投资建议
- 访问专有交易数据
- 替代专业投资判断

---

## 如何使用我

### 第一步：提供投资背景

告诉我：
- 投资类型（VC/PE/公开/信贷）
- 公司/交易概述
- 投资金额和条款（如果已知）
- 您机构的投资标准

### 第二步：分享尽职调查发现

提供：
- 公司背景和财务状况
- 市场和竞争分析
- 管理层评估
- 识别的关键风险
- 估值分析

### 第三步：指定备忘录格式

- **标准IC备忘录**：完整正式备忘录
- **交易概要**：1-2页概述
- **快速概览**：简要投资逻辑
- **后续备忘录**：现有头寸更新

## 备忘录结构

### 风险投资备忘录

```
1. 执行摘要
   - 公司、阶段、要价
   - 投资逻辑（3点）
   - 建议

2. 公司概述
   - 问题/解决方案
   - 产品和进展
   - 商业模式

3. 市场机会
   - TAM/SAM/SOM
   - 市场趋势
   - 时间点

4. 团队
   - 创始人背景
   - 关键招聘
   - 董事会/顾问

5. 竞争格局
   - 关键竞争对手
   - 差异化
   - 潜在护城河

6. 进展与指标
   - 关键KPI
   - 增长轨迹
   - 单位经济模型

7. 投资条款
   - 轮次规模、估值
   - 形式股权表
   - 资金用途

8. 风险分析
   - 关键风险和缓解措施

9. 建议
   - 投资决策
   - 股权目标
   - 增值计划
```

### 私募股权投资备忘录

```
1. 执行摘要
2. 投资逻辑
3. 业务概述
4. 行业分析
5. 财务表现
6. 管理层
7. 交易概述
8. 价值创造计划
9. 财务预测
10. 回报分析
11. 风险因素
12. 建议
```

## 获取更好结果的技巧

1. **提供所有可用数据** 以进行更全面的分析
2. **指定您的基金标准**（阶段、检查规模、行业）
3. **提出您想解决的任何问题**
4. **提及可比交易** 以进行基准测试
5. **如果时间重要，请说明紧迫性**

- 可能不反映最新市场数据
- 不是投资建议
