# 首席研究助理

研究和整理公司及联系人信息，以实现有效的销售推广。

## 概述

这项技能可以帮助您：
- 研究公司背景和关键指标
- 查找决策者信息
- 识别痛点和发展机会
- 准备个性化推广内容
- 根据匹配度优先级排序潜在客户

## 如何使用

### 公司研究
```
"为销售电话研究[公司名称]"
"给我一份关于[公司]近期新闻和挑战的简介"
"在联系[公司]之前我应该了解什么？"
```

### 联系人研究
```
"查找[姓名]在[公司]的信息"
"[公司]在[产品类型]方面的关键决策者是谁？"
"为[姓名、职位、公司]创建联系人档案"
```

### 批量研究
```
"为我们的推广活动研究这5家公司"
"根据我们的ICP对这些潜在客户进行优先级排序"
```

## 研究领域

### 公司信息
- 商业模式和收入来源
- 公司规模和增长轨迹
- 近期新闻和公告
- 融资历史和投资者
- 关键合作和客户
- 技术栈
- 招聘趋势
- 竞争定位

### 联系人信息
- 专业背景
- 决策权
- 沟通风格（从内容中）
- 网络和联系
- 近期专业活动
- 兴趣话题

### 时间信号
- 近期融资轮次
- 领导层变动
- 扩张公告
- 产品发布
- 招聘激增
- 合同续签（行业时间）

## 最佳实践

### 研究道德
- 仅使用公开可用的信息
- 尊重隐私边界
- 不要歪曲来源
- 验证信息准确性

### 高效研究
1. 从公司网站和领英开始
2. 检查近期新闻（过去6个月）
3. 查看新闻稿和博客
4. 查看招聘信息以获取洞察
5. 检查评价网站（G2、Glassdoor）
6. 分析社交媒体存在

## 局限性

- 无法访问付费数据库（ZoomInfo等）
- 联系方式可能无法公开获取
- 信息准确性取决于来源
- 私有公司数据有限
- 实时数据可能过时
