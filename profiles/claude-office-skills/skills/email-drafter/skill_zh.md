# 邮件撰写助手

## 概述

这项技能可以帮助您为各种商业场景撰写专业的电子邮件。它能够理解上下文，保持适当的语气，并遵循不同情况下的电子邮件最佳实践。

**使用场景：**
- 回复客户咨询
- 会后跟进
- 请求信息或批准
- 专业地传达困难消息
- 冷启动和介绍
- 感谢和赞赏邮件

## 如何使用

1. 告诉我电子邮件场景（回复、新邮件、跟进等）
2. 提供背景信息：收件人、关系、目的
3. 分享需要包含的任何具体要点
4. 我将为您起草合适的邮件

**示例提示：**
- "在与技术公司（Acme Corp）的销售会议后起草一封跟进邮件"
- "写一封礼貌的逾期发票提醒邮件"
- "帮助我专业地拒绝这个会议请求"
- "起草一封联系潜在合作伙伴的冷启动邮件"

## 邮件模板与结构

### 专业邮件结构

```
主题：[清晰、具体、以行动为导向]

[问候语 - 根据关系选择合适的]

[开头 - 提供背景/参考]

[正文 - 主要信息，按优先级组织]

[行动号召 - 明确下一步行动]

[结尾 - 适当的结束语]

[签名]
```

### 语气指南

| 场景         | 语气       | 关键要素     |
|------------|----------|------------|
| 客户沟通     | 专业、热情 | 尊重、清晰、乐于助人 |
| 内部团队     | 直接、友好 | 效率、协作     |
| 高管/资深人士 | 简洁、尊重 | 先说重点、数据驱动   |
| 冷启动       | 有吸引力、以价值为导向 | 钩子、相关性、明确的请求 |
| 困难消息     | 富有同情心、清晰 | 承认、解释、下一步行动 |
| 跟进         | 礼貌、坚持 | 提及、增加价值、易于回复 |

### 主题行最佳实践

**好的主题行：**
- "需要行动：周五前批准第四季度预算"
- "会议跟进：项目阿尔法下一步行动"
- "快速提问：下周您的空闲时间"
- "感谢 - 今天会议很愉快"

**避免：**
- 模糊：如"你好"或"快速提问"
- 过长：超过50个字符
- 全大写或过多标点符号
- 蒙蔽性点击诱饵

### 常见邮件场景

#### 1. 会议跟进

```
主题：跟进：[会议主题] - 下一步行动

你好 [姓名]，

感谢您抽出时间[今天/昨天]与我见面。我非常享受关于[主题]的讨论。

正如我们所讨论的，以下是关键行动项：
• [行动1] - [负责人] - [截止日期]
• [行动2] - [负责人] - [截止日期]

我将在[日期]前[您的下一步行动]。如果您遗漏了任何内容或有任何问题，请告诉我。

期待我们继续合作。

此致，
[您的姓名]
```

#### 2. 请求/询问邮件

```
主题：请求：[具体请求]

你好 [姓名]，

希望您一切安好。

我联系您是因为[简要背景]。您能[具体请求]吗？

为了给您更多背景：
• [相关细节1]
• [相关细节2]

如果可能的话，我希望能于[日期]前得到您的回复。如果您需要任何其他信息，请随时告诉我。

感谢您的时间。

此致，
[您的姓名]
```

#### 3. 礼貌拒绝

```
主题：回复：[原始主题]

你好 [姓名]，

感谢您考虑我参加[机会/请求]。

经过慎重考虑，我无法[参与/参加/承担]此事，因为[简要、诚实的理由]。

[可选：替代建议或未来可能性]

我感谢您的理解，并希望未来能[联系/合作]。

此致，
[您的姓名]
```

#### 4. 道歉/问题解决

```
主题：道歉：[简要问题描述]

尊敬的 [姓名]，

我想真诚地为[具体问题]向您道歉。我理解这[造成了不便/影响了您的工作等]。

发生的事情是这样的：[简要解释，不要找借口]

为了弥补，我已经[采取的行动/将采取的行动]：
• [纠正措施1]
• [纠正措施2]

我致力于确保这种情况不再发生，通过[预防措施]。

请告诉我是否还有其他我能做的。

诚挚地，
[您的姓名]
```

## 输出格式

当我起草邮件时，我会提供：

```
## 邮件草稿

**主题：** [建议的主题行]

**收件人：** [收件人]
**抄送：** [如果适用]

---

[邮件正文]

---

## 备注
- [任何考虑或替代方案]
- [建议发送时间]
```

## 定制选项

告诉我您的偏好：
- **语气**：正式、半正式、休闲
- **长度**：简短（2-3句话）、标准、详细
- **风格**：直接、外交、热情
- **结束语**：最好、问候、感谢、干杯等

## 限制

- 无法发送邮件（仅起草）
- 可能不了解您组织的特定沟通规范
- 应检查姓名、日期和细节的准确性
- 不适用于未经审查的法律或高度敏感的通信

## 示例

### 示例1：面试后跟进

**用户：** "在参加技术公司（TechCorp）的产品经理职位面试后起草一封感谢邮件。我见到了产品副总裁陈Sarah。"

**输出：**

**主题：** 感谢 - 产品经理面试

尊敬的Sarah，

感谢您今天[今天/昨天]抽出时间与我见面，讨论技术公司的产品经理职位。我非常享受了解团队在扩展企业市场方面的愿景。

我们的谈话让我对这一机会更加兴奋。我对您提到的构建分析仪表板的挑战特别感兴趣，我相信我在当前职位上领导类似项目的经验将很好地转化为这一角色。

我非常希望加入技术公司团队，并为您的产品战略做出贡献。如果您需要我提供任何其他信息，请随时联系。

再次感谢您提供的机会。我期待您的回复。

此致，
[您的姓名]
