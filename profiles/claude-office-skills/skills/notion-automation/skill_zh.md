# Notion 自动化

通过跨平台集成、模板和智能触发器，自动化 Notion 数据库和工作流程。基于 n8n 的 Notion 工作流模板。

## 概述

本技能涵盖：
- 数据库自动化和触发器
- 模板和页面创建
- 跨平台同步（Slack、日历、CRM）
- 内容管理工作流程
- 团队协作自动化

---

## 核心工作流程

### 1. 表单 → Notion 数据库

```yaml
workflow: "表单到 Notion"
trigger: typeform_submission OR google_form

steps:
  1. 捕获数据:
      字段: [姓名, 邮箱, 公司, 留言, 来源]
      
  2. 丰富数据:
      clearbit: 通过邮箱查找
      添加: [公司规模, 行业]
      
  3. 创建 Notion 页面:
      数据库 ID: "线索数据库"
      属性:
        名称: "{姓名}"
        邮箱: "{邮箱}"
        公司: "{公司}"
        状态: "新"
        来源: "{来源}"
        创建时间: "{时间戳}"
      内容:
        - 标题: "联系方式"
        - 文本: "{留言}"
        - 分隔线
        - 标题: "丰富数据"
        - 文本: "行业: {行业}, 规模: {公司规模}"
        
  4. 通知:
      slack:
        频道: "#新线索"
        消息: "新线索: {姓名} 来自 {公司}"
```

### 2. Notion → 邮件摘要

```yaml
workflow: "每周 Notion 摘要"
计划: "周一 9 点"

steps:
  1. 查询 Notion:
      数据库: "任务"
      过滤:
        - 属性: "截止日期"
          日期: 本周
        - 属性: "状态"
          不等于: "完成"
          
  2. 按负责人分组:
      方法: 聚合
      
  3. 生成摘要:
      遍历: 负责人
      模板: |
        Hi {负责人},
        
        这是你的本周任务:
        
        {遍历任务 in 任务}
        • {任务标题} - 截止: {任务截止日期}
        {结束遍历}
        
        总计: {任务数量} 个任务
        
  4. 发送邮件:
      收件人: 每个负责人
      主题: "你的每周任务摘要"
```

### 3. Slack → Notion 任务

```yaml
workflow: "Slack 到 Notion 任务"
触发器: slack 反应 (✅ 表情)

steps:
  1. 捕获消息:
      提取: [文本, 作者, 频道, 时间戳, 线索]
      
  2. 解析任务:
      人工智能提取:
        标题: 提取行动项
        截止日期: 如果提到提取日期
        优先级: 从上下文中推断
        
  3. 创建 Notion 任务:
      数据库: "任务"
      属性:
        标题: "{提取标题}"
        状态: "待办"
        来源: "Slack - #{频道}"
        负责人: "{slack_user_to_notion_user}"
        截止日期: "{截止日期}"
        优先级: "{优先级}"
      内容:
        - 引用: "{原始消息}"
        - 文本: "来自 Slack 消息创建"
        - 链接: "{slack_permalink}"
        
  4. 线索回复:
      slack:
        线索时间戳: "{时间戳}"
        消息: "✅ 在 Notion 创建任务: {notion_url}"
```

### 4. 日历同步

```yaml
workflow: "Google 日历 ↔ Notion"
触发器: 双向

google_to_notion:
  触发器: 日历事件创建
  动作:
    - 创建 Notion 页面:
        数据库: "会议"
        属性:
          标题: "{事件.title}"
          日期: "{事件.start}"
          参会者: "{事件.attendees}"
          地点: "{事件.location}"
          日历链接: "{事件.link}"

notion_to_google:
  触发器: notion 页面创建
  过滤: 数据库 == "会议"
  动作:
    - 创建日历事件:
        标题: "{页面.Title}"
        开始: "{页面.Date}"
        描述: "{页面.Notes}"
        参会者: "{页面.Attendees}"
```

### 5. 内容管道

```yaml
workflow: "内容发布管道"

数据库结构:
  属性:
    - 标题: 标题
    - 状态: 选择 [想法, 写作, 审阅, 发布]
    - 作者: 人物
    - 截止日期: 日期
    - 平台: 多选 [博客, LinkedIn, Twitter]
    - 内容: 富文本
    
自动化:
  状态更改为审阅:
    - 通知 Slack: "#内容审阅"
    - 分配审阅者: 轮流
    - 设置截止日期: 3 天后
    
  状态更改为发布:
    - 发布到平台: 基于 Platform 属性
    - 更新分析追踪器: 添加行
    - 7 天后归档
```

## 数据库模板

### 项目管理

```yaml
项目数据库:
  名称: "项目"
  属性:
    - 名称: 标题
    - 状态: 选择
        选项: [规划, 进行中, 审阅, 完成]
    - 优先级: 选择
        选项: [P0, P1, P2, P3]
    - 所有者: 人物
    - 团队: 多选
    - 开始日期: 日期
    - 截止日期: 日期
    - 进度: 数字 (百分比)
    - 相关任务: 关系 → 任务
    
  视图:
    - 板: 按状态分组
    - 时间线: Gantt 图
    - 日历: 按截止日期
    - 表格: 所有属性
    
  自动化:
    - 当: 所有任务完成
      然后: 设置状态 "完成"
    - 当: 截止日期临近 (3 天)
      然后: Slack 提醒给所有者
```

### CRM 数据库

```yaml
crm 数据库:
  名称: "联系人"
  属性:
    - 名称: 标题
    - 邮箱: 邮箱
    - 公司: 文本
    - 阶段: 选择
        选项: [线索, 合格, 提案, 谈判, 已关闭]
    - 价值: 数字 (货币)
    - 最后联系: 日期
    - 下一步行动: 文本
    - 所有者: 人物
    - 相关交易: 关系 → 交易
    
  自动化:
    - 当: 阶段更改
      然后: 记录活动 + 通知所有者
    - 当: 14 天无联系
      然后: Slack 警报 "需要跟进"
```

### 内容日历

```yaml
内容日历:

  属性:
    - 标题: 标题

    - 状态: 选择 [想法, 草稿, 审阅, 安排, 发布]
    - 发布日期: 日期
    - 作者: 人物
    - 平台: 多选

## API 模式

### 查询数据库

```javascript
// n8n Notion 查询
{
  "database_id": "abc123",
  "过滤": {
    "and": [
      {
        "属性": "状态",
        "选择": {
          "等于": "进行中"
        }
      },
      {
        "属性": "截止日期",
        "日期": {
          "在或之前": "{{$今天}}"
        }
      }
    ]
  },
  "排序": [
    {
      "属性": "优先级",
      "方向": "升序"
    }
  ]
}
```

### 创建页面

```javascript
// n8n Notion 创建页面
{
  "父级": { "database_id": "abc123" },
  "属性": {
    "名称": {
      "标题": [{ "文本": { "内容": "{{$json.title}}" }}]
    },
    "状态": {
      "选择": { "名称": "新" }
    },
    "标签": {
      "多选": [
        { "名称": "{{$json.tag1}}" },
        { "名称": "{{$json.tag2}}" }
      ]
    }
  },
  "子项": [
    {
      "对象": "块",
      "类型": "heading_2",
      "heading_2": {
        "富文本": [{ "文本": { "内容": "概述" }}]
      }
    },
    {
      "对象": "块",
      "类型": "段落",
      "段落": {
        "富文本": [{ "文本": { "内容": "{{$json.content}}" }}]
      }
    }
  ]
}
```

## 集成配方

### Notion + Slack + 日历

```yaml
会议工作流程:
  触发器: notion_page_created
  数据库: "会议"
  
  动作:
    1. 创建日历事件:
        google_calendar:
          标题: "{标题}"
          日期: "{日期}"
          
    2. 创建 Slack 频道:
        如果: "{类型}" == "项目启动会"
        名称: "proj-{项目名称}"
        
    3. 发送邀请:
        给: "{参会者}"
        包括: [日历链接, notion 链接, slack 频道]
        
    4. 创建会议文档:
        notion:
          模板: "会议笔记模板"
          链接到: 原始页面
```

### Notion + GitHub

```yaml
github 同步:
  触发器: github_issue_created
  
  动作:
    - 创建 Notion 页面:
        数据库: "工程任务"
        属性:
          标题: "{issue.title}"
          GitHub: "{issue.url}"
          标签: "{issue.labels}"
          负责人: map_github_to_notion("{issue.assignee}")
          
  反向同步:
    触发器: notion 状态更改
    到: "完成"
    动作: 关闭 github 问题
```

### 自动化

**1. 新内容想法 → Slack**
```yaml
触发器: 页面创建, 状态 = "想法"
动作: post_to_slack("#内容想法")
消息: "💡 新内容想法: {标题} 由 {作者}"
```

**2. 准备审阅 → 分配编辑**
```yaml
触发器: 状态更改为 "编辑"
动作: 
  - 分配编辑器 (轮流)
  - 设置截止日期 (+3 天)
  - slack_dm 编辑器
```

**3. 发布 → 更新追踪器**
```yaml
触发器: 状态更改为 "发布"
动作:
  - add_to_analytics_sheet
  - post_celebration_slack
  - 安排参与度检查 (+7 天)
```

### 视图
1. **日历** - 查看发布计划
2. **Kanban** - 跟踪状态
3. **按作者** - 个人工作量
4. **本周** - 过滤视图

### 模板
- 博客文章模板
- 社交线索模板
- 订阅模板
