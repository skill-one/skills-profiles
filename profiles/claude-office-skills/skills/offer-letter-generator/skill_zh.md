# Offer Letter Generator

生成专业的雇佣录用通知书，清晰传达工作条款和薪酬。

## 概述

此技能创建正式的录用通知书，具有以下特点：
- 清晰说明职位和薪酬
- 概述关键雇佣条款
- 保持法律合规意识
- 创建积极的候选人体验

## 如何使用

提供以下信息：

### 必填
1. **候选人姓名**：全名（法定姓名）
2. **职位名称**：所提供的职位
3. **开始日期**：建议的入职日期
4. **薪酬**：基本工资和支付频率
5. **雇佣类型**：全职、兼职、合同
6. **汇报对象**：经理姓名和职位

### 可选
7. **股权/奖金**：股票期权、签字奖金、年度奖金
8. **福利**：健康保险、401k、带薪休假总结
9. **工作地点**：办公室地址或远程
10. **回复截止日期**：录用通知书到期时间
11. **附加条件**：背景调查、推荐信等

## 模板部分

### 开头
```
我们很高兴为您提供[公司名称]的[职位名称]职位录用通知。经过我们的面试流程，我们相信您的技能和经验使您成为我们团队的优秀成员。
```

### 职位详情
```
职位：[职位名称]
部门：[部门]
汇报对象：[经理姓名]，[经理职位]
开始日期：[日期]
工作地点：[地点/远程]
雇佣类型：[全职/兼职/合同]
```

### 薪酬
```
基本工资：$[金额]每[年/月/小时]
支付周期：[双周/月度]

[如适用:]
签字奖金：$[金额]，支付[时间]
年度奖金：最高为基本工资的[X]%，基于个人和公司绩效
股权：[X]股票期权，分[Y]年归属，[Z]年分水岭
```

### 福利总结
```
您将有资格获得我们全面的福利套餐，包括：
- 医疗、牙科和视力保险
- 401k计划，公司匹配[X]%
- 每年[X]天带薪休假
- [其他福利]

入职培训期间将提供完整的福利详情。
```

### 附加条件
```
此录用通知有如下附加条件：
- 成功完成背景调查
- 验证您在[国家]的合法工作资格
- [其他附加条件]
```

### 接受条款
```
请通过签署并返回此信函在[日期]前表示接受。如果未在此日期前接受，此录用通知将失效。

如有任何疑问，请联系[姓名]的[邮箱/电话]。

我们期待欢迎您加入我们的团队！
```

## 最佳实践

### 应做
- 使用清晰、简洁的语言
- 包括所有实质性条款
- 明确指定截止日期
- 提供问题联系方式
- 包含签名部分

### 不应做
- 不要做出标准条款之外的承诺
- 不要包含歧视性语言
- 不要遗漏附加条件
- 不要遗漏重要细节
- 不要使用过于复杂的法律术语

### 法律注意事项
- 录用通知书通常不是合同（如需，可添加免责声明）
- 应明确说明非工时雇佣（美国）
- 股权条款应参考完整协议
- 发送前需经法律/人力资源部门审核

## 局限性

- 这是一份模板指南，不是法律建议
- 雇佣法律因地区而异
- 必须结合公司特定政策
- 复杂股权安排需法律审核
- 国际录用通知有额外要求
