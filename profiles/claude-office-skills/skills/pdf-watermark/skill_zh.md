# PDF 水印与页面元素

为 PDF 文档添加水印、页码、页眉、页脚和其他叠加元素。

## 概述

此功能可帮助您：
- 添加文本或图像水印
- 插入页码
- 创建页眉和页脚
- 应用印章和标签
- 批量处理多个文档

## 使用方法

### 水印
```
"为该 PDF 添加 '机密' 水印"
"应用斜向 '草稿' 水印"
"将公司标志作为水印添加"
```

### 页码
```
"为该 PDF 添加页码"
"从第 3 页开始编号页码"
"在底部居中添加 '第 X 页，共 Y 页'"
```

### 页眉/页脚
```
"添加带有文档标题的页眉"
"创建带有日期和页码的页脚"
"将公司名称添加到每页页眉"
```

## 水印选项

```markdown
## 文本水印配置

### 内容
- **文本**: 机密
- **字体**: Arial 粗体
- **大小**: 72 pt
- **颜色**: #FF0000 (红色)
- **不透明度**: 30%

### 位置
- **放置**: 居中
- **旋转**: 45° 斜向
- **偏移 X**: 0
- **偏移 Y**: 0

### 页面
- **应用于**: 所有页面 / 仅第一页 / 自定义范围
- **跳过页面**: [无]

### 预览
```
    ╔════════════════════════╗
    ║                        ║
    ║    C O N F I D E N     ║
    ║      T I A L           ║
    ║                        ║
    ╚════════════════════════╝
```
```

### 图像水印
```markdown
## 图像水印配置

### 图像
- **文件**: logo.png
- **大小**: 200 x 100 px
- **不透明度**: 20%
- **保持宽高比**: 是

### 位置
| 预设 | 描述 |
|------|------|
| 居中 | 页面中间 |
| 右上角 | 角标 |
| 底部居中 | 页脚区域 |
| 平铺 | 重复图案 |

### 当前设置
- **位置**: 右下角
- **边距**: 边缘 20px
- **位于文本后**: 是 (背景)

```

### 水印预设
| 预设 | 文本 | 样式 | 用途 |
|------|------|------|------|
| **草稿** | 草稿 | 灰色，斜向，50% | 进行中 |
| **机密** | 机密 | 红色，斜向，30% | 敏感文档 |
| **副本** | 副本 | 蓝色，水平，25% | 复制件 |
| **已批准** | 已批准 | 绿色，印章样式 | 批准 |
| **样本** | 样本 | 灰色，平铺 | 示例文档 |
| **禁止复制** | 禁止复制 | 红色，斜向，40% | 限制 |

## 页码

### 配置选项
```markdown
## 页码配置

### 格式
| 样式 | 示例 |
|------|------|
| 简单 | 1, 2, 3 |
| 页码 X | 第 1 页 |
| X of Y | 1 of 25 |
| 分节 | 1-1, 1-2 |
| 罗马数字 | i, ii, iii |
| 字母 | A, B, C |

### 位置
| 位置 | 对齐 |
|------|------|
| 页眉 | 左侧 / 居中 / 右侧 |
| 页脚 | 左侧 / 居中 / 右侧 |

### 当前设置
- **格式**: 第 {n} 页，共 {total} 页
- **位置**: 页脚，居中
- **字体**: Arial，10pt
- **起始页**: 第 1 页
- **跳过页**: 封面 (第 1 页)
```

### 高级编号
```markdown
## 高级页码方案

### 分节编号
| 页面范围 | 格式 | 示例 |
|----------|------|------|
| 1 (封面) | 无 | - |
| 2-5 (前言) | 罗马数字 | i, ii, iii, iv |
| 6-100 (正文) | 阿拉伯数字 | 1, 2, 3... |
| 101-110 (附录) | 字母 | A-1, A-2 |

### 前缀/后缀
- **前缀**: "第 "
- **后缀**: " - 公司名称"
- **结果**: "第 5 页 - 公司名称"
```

### 布局 (三列)
| 左侧 | 居中 | 右侧 |
|------|------|------|
| [标志] | 文档标题 | [日期] |

### 样式
- **字体**: Arial，10pt
- **颜色**: #333333
- **下方线**: 是，0.5pt 灰色

### 动态字段
| 字段 | 代码 | 输出 |

| 页码 | {page} | 5 |
| 总页数 | {pages} | 25 |
| 日期 | {date} | 2026 年 1 月 29 日 |
| 时间 | {time} | 14:30 |
| 文件名 | {filename} | report.pdf |
| 标题 | {title} | Q4 报告 |

## 输出示例

### 水印报告
```markdown
## 水印应用报告

### 文件
- **输入**: quarterly_report.pdf
- **输出**: quarterly_report_watermarked.pdf
- **页数**: 45

### 应用元素
| 元素 | 详细信息 | 页数 |
|------|----------|------|
| 水印 | "机密" 斜向 | 所有页 |

| 页码 | "第 X 页，共 Y 页"，页脚居中 | 2-45 |

| 页脚 | 版权声明 | 所有页 |

### 验证
- [ ] 水印可见但不遮挡内容
- [ ] 页码连续且正确
- [ ] 页眉/页脚位置正确
- [ ] 无内容重叠问题
```

## 工具推荐

### 在线工具
- **SmallPDF**: 简单水印
- **ILovePDF**: 良好页码功能
- **PDF24**: 免费，可配置
- **Sejda**: 多种选项

### 桌面软件
- **Adobe Acrobat Pro**: 完全控制
- **Foxit PDF 编辑器**: 良好功能
- **PDF-XChange**: 多种选项
- **预览 (Mac)**: 基础功能

### 程序化
- **pdf-lib** (JavaScript): 完全控制
- **PyPDF2** (Python): 基础水印
- **iText** (Java/.NET): 专业
- **PDFBox** (Java): 良好选项

## 限制

- 无法执行实际水印 (仅提供指导)
- 图像水印需要适当分辨率
- 部分受保护的 PDF 无法修改
- 复杂水印可能增加文件大小
- 位置可能因不同页面尺寸而变化
- 字体可用性影响文本水印
