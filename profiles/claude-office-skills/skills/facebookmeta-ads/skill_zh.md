# Facebook/Meta 广告

全面的自动化 Facebook 和 Instagram 广告技能。

## 核心工作流程

### 1. 营销活动结构

```
META 广告层级结构：
┌─────────────────────────────────────────────────────────┐
│ 🎯 营销活动 (目标)                                      │
│    目标：转化、流量、认知度等。                         │
├─────────────────────────────────────────────────────────┤
│   ├── 📊 广告组 1 (受众 + 预算)                        │
│   │   ├── 受众：相似受众 1%                            │
│   │   ├── 预算：每天 $50                             │
│   │   ├── 布局：信息流 + 故事                         │
│   │   │                                               │
│   │   ├── 📝 广告 1：图片 + 文案 A                    │
│   │   ├── 📝 广告 2：视频 + 文案 A                    │
│   │   └── 📝 广告 3：轮播图 + 文案 B                  │
│   │                                                     │
```

## API 示例

### 创建营销活动

```javascript
// 创建营销活动
const campaign = await fb.api('/act_123/campaigns', 'POST', {
  name: 'Q1 潜客获取',
  objective: 'CONVERSIONS',
  status: 'PAUSED',
  special_ad_categories: []
});

// 创建广告组
const adSet = await fb.api('/act_123/adsets', 'POST', {
  name: 'LAL 1% - US',
  campaign_id: campaign.id,
  optimization_goal: 'OFFSITE_CONVERSIONS',
  billing_event: 'IMPRESSIONS',
  bid_strategy: 'LOWEST_COST_WITHOUT_CAP',
  daily_budget: 5000, // 分
  targeting: {
    geo_locations: { countries: ['US'] },
    custom_audiences: [{ id: 'lookalike_id' }]
  },
  promoted_object: {
    pixel_id: 'pixel_123',
    custom_event_type: 'PURCHASE'
  }
});

// 创建广告
const ad = await fb.api('/act_123/ads', 'POST', {
  name: '视频广告 - 文案 A',
  adset_id: adSet.id,
  creative: {
    creative_id: 'creative_123'
  },
  status: 'PAUSED'
});
```

## 最佳实践

1. **测试受众**：从广泛开始，然后优化
2. **创意多样性**：测试多种格式
3. **像素准确性**：验证追踪设置
4. **预算分配**：70% 潜客获取，30% 再营销
5. **频率限制**：注意广告疲劳
6. **移动优先**：为移动体验设计
7. **A/B 测试**：系统化的创意测试
8. **归因**：了解客户旅程
