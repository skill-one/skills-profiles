# 加密货币报告技能

## 概述

我帮助您全面分析加密货币和区块链项目。我涵盖代币经济学、协议机制、链上指标、竞争定位和投资考量。

**我能做什么：**
- 代币经济学分析（供应、分配、归属）
- 协议/技术评估
- 链上指标解读
- 市场和竞争分析
- 风险因素识别
- 投资逻辑发展

**我不能做什么：**
- 获取实时价格或链上数据
- 预测价格走势
- 提供投资建议
- 审计智能合约

---

## 如何使用我

### 第一步：指定项目

告诉我：
- 代币/项目名称和代码
- 区块链网络
- 项目类别（L1、L2、DeFi、NFT等）
- 任何特定指标

### 第二步：选择分析范围

- **快速概览**：代币摘要和关键指标
- **深度分析**：全面协议分析
- **代币经济学重点**：供应和分配分析
- **技术评审**：协议机制和安全

### 第三步：提供背景（可选）

- 链上数据（TVL、交易、用户）
- 代币持有者分布
- 近期发展或新闻

## 分析框架

### 项目类别

| 类别 | 示例 | 关键指标 |
|------|------|----------|
| L1层 | ETH、SOL、AVAX | TPS、TVL、开发者活动 |
| L2层 | ARB、OP、MATIC | TVL、交易量、费率节省 |
| DeFi | UNI、AAVE、MKR | TVL、交易量、收入 |
| 基础设施 | LINK、GRT、FIL | 使用情况、集成、收入 |
| 游戏/NFT | AXS、SAND、IMX | 用户数、交易量、交易量 |
| 稳定币 | USDC、DAI、FRAX | 市值、锚定稳定性 |

### 代币经济学分析

#### 供应指标
```
最大供应：将永远存在的总代币数
总供应：迄今为止铸造的代币数
流通供应：市场可用的代币
通胀率：年度供应增长
```

#### 分配评估
| 持有者类型 | 典型范围 | 关注程度 |
|------------|----------|----------|
| 团队 | 10-20% | >25%令人担忧 |
| 投资者 | 15-25% | >30%令人担忧 |
| 国库 | 10-20% | 取决于治理 |
| 社区 | 40-60% | 越高越好 |
| 生态系统 | 10-20% | 用于激励 |

#### 归属分析
- 悬崖期
- 线性与里程碑归属
- 解锁时间表影响

### 链上指标

| 指标 | 描述 | 告诉你什么 |
|------|------|------------|
| TVL | 已锁定的总价值 | 协议采用情况 |
| 活跃用户 | 每日/每月活跃钱包 | 真实使用情况 |
| 交易计数 | 链上交易 | 活动水平 |
| 燃气费 | 交易成本 | 对区块空间的需求 |
| 开发者提交 | GitHub活动 | 开发势头 |
| 代币速度 | 转换率 | 持有行为 |

### 估值方法

#### 相对估值
- 市值/TVL
- 年化收入/FDV
- P/S比率（协议收入）
- 与同行比较

#### 代币价值积累
- 费用分配
- 购回和销毁
- 质押奖励
- 治理权
