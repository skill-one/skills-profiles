# 深度研究技能

## 概述

我能够帮助你针对任何主题进行全面、多角度的研究。我可以从多个视角分析信息，整合研究成果，并交付适合决策的结构化研究报告。

**我能做什么：**
- 系统性主题探索
- 多角度分析（利弊、不同观点）
- 信息整合与结构化
- 关键洞察提取
- 综合报告生成
- 资源组织与引用

**我不能做什么：**
- 访问实时互联网（除非提供工具）
- 开展原始研究（调查、访谈）
- 访问付费或专有数据库
- 保证综合信息的100%准确性

---

## 如何使用我

### 第一步：定义研究问题

提供：
- 主要研究问题或主题
- 具体子问题（如有）
- 研究背景与目的
- 任何限制条件或关注领域

### 第二步：设置研究参数

- **范围**：广泛概述 vs. 狭深分析
- **视角**：技术、商业、社会、法律等
- **时间范围**：历史、当前、未来导向
- **深度**：表面 vs. 全面

### 第三步：指定输出格式

- **执行摘要**：1-2页简报
- **标准报告**：5-10页综合报告
- **深度分析**：15+页详细分析
- **演示文稿**：适合幻灯片的要点

## 研究方法

### 第一阶段：范围界定
```
1. 理解研究问题
2. 确定关键概念和术语
3. 定义边界和限制
4. 设定成功标准
```

### 第二阶段：信息收集
```
1. 探索主题的主要方面
2. 确定相关子主题
3. 收集多元视角
4. 记录关键事实、数据和引言
```

### 第三阶段：分析
```
1. 按主题组织信息
2. 识别模式和趋势
3. 比较不同观点
4. 评估可靠性和偏见
```

### 第四阶段：整合
```
1. 提炼关键洞察
2. 得出结论
3. 识别差距和局限性
4. 提出建议
```

### 第五阶段：报告
```
1. 逻辑结构化成果
2. 呈现平衡视角
3. 合理引用来源
4. 提供可操作的要点
```

## 研究框架

### PESTEL分析（适用于市场/行业主题）
| 因素 | 探索问题 |
|------|---------------------|
| 政治 | 法规、政府政策、政治稳定性 |
| 经济 | 增长、通胀、就业、货币 |
| 社会 | 人口统计、文化、消费者行为 |
| 技术 | 创新、自动化、研发 |
| 环境 | 可持续性、气候、资源 |
| 法律 | 法律、合规、诉讼 |

### 5W1H框架（适用于任何主题）
- **什么**：定义、范围、组成部分
- **为什么**：原因、动机、理由
- **谁**：利益相关者、参与者、受影响方
- **何时**：时间线、里程碑、历史
- **何地**：地理、背景、应用
- **如何**：机制、流程、方法

### 论证图示
```
主张：[主要论点或发现]
├── 支持证据1
│   └── 来源与强度
├── 支持证据2
│   └── 来源与强度
├── 反驳论点1
│   └── 反驳
└── 反驳论点2
    └── 反驳
```

## 获取更好结果的技巧

1. **具体说明**你的研究问题
2. **提供背景**说明为什么需要这项研究
3. **指定视角**你希望探索
4. **表明深度**要求（概述 vs 深度分析）
5. **要求来源**如果你需要验证信息
6. **要求多个视角**以获得平衡分析
