# 亚马逊卖家

全面的技能，用于自动化亚马逊卖家运营和FBA管理。

## 核心工作流程

### 1. 卖家中心流水线

```
亚马逊卖家运营：
┌─────────────────────────────────────────────────────────┐
│                    商品列表管理                    │
│  创建 → 优化 → 定价 → 库存 → 监控                │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│                    订单履行                    │
│  FBA：亚马逊处理 │ FBM：卖家处理              │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│                    广告（PPC）                    │
│  推广商品 │ 品牌推广 │ 展示                  │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│                    分析与增长                    │
│  销售报告 │ 利润分析 │ 市场调研              │
└─────────────────────────────────────────────────────────┘
```

### 2. 自动化触发器

```yaml
automations:
  - name: 库存不足警报
    trigger:
      metric: fba_inventory
      condition: "< 14天的供应量"
    actions:
      - 发送警报：slack
      - 创建发货计划
      - 向供应商重新订购
      
  - name: 价格调整
    trigger:
      event: 竞争对手价格变动
      threshold: 5%
    actions:
      - 重新计算价格
      - 更新商品列表
      - 记录变更
      
  - name: 评价请求
    trigger:
      event: 订单送达
      delay: 7天
    actions:
      - 检查退货状态
      - 发送评价请求
```

## 定价策略

### 动态定价

```yaml
pricing_rules:
  - name: 竞争购买框
    条件：
      - has_buy_box: false
      - competitor_price: "<= my_price"
    操作：
      调整：匹配最低 - $0.01
      底价：最低利润价格
      
  - name: 基于需求
    条件：
      - sales_velocity: "> 2x_average"
      - stock_level: "> 60_days"
    操作：
      调整：+5%
      最高价：最高价格
      
  - name: 清仓
    条件：
      - stock_age: "> 150_days"
      - sales_velocity: "< 0.5x_average"
    操作：
      调整：-15%
      底价：成本 + 费用
```

### 利润计算器

```yaml
profit_calculation:
  收入：
    - 销售价格
    - 运输信用
    
  成本：
    - 商品成本
    - 运输至FBA
    - FBA履行费
    - 推荐费 (典型15%)
    - 存储费 (每月)
    - 入境运输
    - PPC成本 (基于ACoS)
             
  公式： |
    利润 = 销售价格
             - 商品成本
             - FBA费 (基于尺寸)
             - 推荐费 (典型15%)
             - 存储费 (每月)
             - 入境运输
             - PPC成本 (基于ACoS)
             
  示例：
    销售价格：$29.99
    商品成本：$8.00
    fba_fee：$4.75
    referral_fee：$4.50
    storage_fee：$0.25
    运输：$1.50
    ppc_cost：$2.00
    利润：$8.99 (30%利润率)
```

7. **季节性规划**：第四季度库存准备
