## 概述

我通过推荐合适的图表类型、生成流行图表库的配置以及应用数据可视化最佳实践，帮助您设计有效的数据可视化图表。

**我能做什么：**
- 为您的数据推荐合适的图表类型
- 生成 ECharts/Chart.js 配置
- 设计仪表盘布局
- 应用可视化最佳实践
- 创建 Excel 图表规范
- 提供配色方案和样式建议

**我不能做什么：**
- 直接渲染图表（请使用生成的配置在工具中显示）
- 从零开始创建自定义图表类型
- 直接访问您的数据

## 图表选择指南

### 比较图表
| 图表类型 | 适用于 | 数据要求 |
|----------|--------|----------|
| 条形图 | 比较类别 | 类别+数值 |
| 分组条形图 | 多个系列比较 | 类别+多个系列 |
| 堆积条形图 | 部分与整体比较 | 类别+组件数值 |

### 趋势图表
| 图表类型 | 适用于 | 数据要求 |
|----------|--------|----------|
| 折线图 | 随时间变化 | 时间序列数据 |
| 面积图 | 累计趋势 | 时间序列（可选堆叠） |
| 微型图 | 紧凑趋势 | 简单时间序列 |

### 分布图表
| 图表类型 | 适用于 | 数据要求 |
|----------|--------|----------|
| 直方图 | 数值分布 | 数值 |
| 箱线图 | 分布摘要 | 具有四分位的数值 |
| 散点图 | 相关性 | 两个数值变量 |

### 部分与整体图表
| 图表类型 | 适用于 | 数据要求 |
|----------|--------|----------|
| 饼图 | 简单比例（≤5项） | 类别+百分比 |
| 环形图 | 带总和的比例 | 类别+百分比 |
| 树状图 | 层级比例 | 层级数据+数值 |

### 特殊图表
| 图表类型 | 适用于 | 数据要求 |
|----------|--------|----------|
| 漏斗图 | 过程阶段/转化 | 阶段+数值 |
| 仪表盘 | 单个 KPI 与目标比较 | 当前值+目标 |
| 热力图 | 矩阵比较 | 行+列+数值 |
| 雷达图 | 多维比较 | 每个项目多个指标 |
| 沙漏图 | 流程/转换 | 来源+目标+数值 |

## 决策树

```
您想展示什么？
│
├─ 比较
│   ├─ 项目之间 → 条形图
│   ├─ 随时间 → 折线图
│   └─ 多个系列 → 分组/堆积条形图
│
├─ 构成
│   ├─ 静态 → 饼图/环形图（≤5）或树状图
│   ├─ 随时间 → 堆积面积图
│   └─ 层级 → 树状图/旭日图
│
├─ 分布
│   ├─ 单个变量 → 直方图
│   ├─ 多个数据集 → 箱线图
│   └─ 两个变量 → 散点图
│
├─ 关系
│   ├─ 两个变量 → 散点图
│   ├─ 三个变量 → 气泡图
│   └─ 相关矩阵 → 热力图
│
└─ 流程/过程
    ├─ 顺序阶段 → 漏斗图
    ├─ 转换 → 沙漏图
    └─ 单个指标 → 仪表盘
```

## 图表配置

### ECharts

```javascript
const option = {
  title: {
    text: '图表标题',
    left: 'center'
  },
  tooltip: {
    trigger: 'axis'
  },
  legend: {
    data: ['系列1', '系列2'],
    bottom: 10
  },
  xAxis: {
    type: 'category',
    data: ['1月', '2月', '3月', '4月', '5月', '6月']
  },
  yAxis: {
    type: 'value'
  },
  series: [
    {
      name: '系列1',
      type: 'bar',
      data: [120, 200, 150, 80, 70, 110]
    },
    {
      name: '系列2',
      type: 'line',
      data: [100, 180, 160, 90, 80, 100]
    }
  ]
};
```

### Chart.js

```javascript
const config = {
  type: 'bar',
  data: {
    labels: ['1月', '2月', '3月', '4月', '5月', '6月'],
    datasets: [{
      label: '系列1',
      data: [120, 200, 150, 80, 70, 110],
      backgroundColor: 'rgba(54, 162, 235, 0.8)'
    }]
  },
  options: {
    responsive: true,
    plugins: {
      title: {
        display: true,
        text: '图表标题'
      }
    }
  }
};
```

## ECharts 常用配置

### 条形图
```javascript
{
  xAxis: { type: 'category', data: categories },
  yAxis: { type: 'value' },
  series: [{
    type: 'bar',
    data: values,
    itemStyle: { color: '#5470c6' }
  }]
}
```

### 折线图
```javascript
{
  xAxis: { type: 'category', data: categories },
  yAxis: { type: 'value' },
  series: [{
    type: 'line',
    data: values,
    smooth: true,
    areaStyle: {} // 用于面积图
  }]
}
```

### 饼图
```javascript
{
  series: [{
    type: 'pie',
    radius: ['40%', '70%'], // 环形
    data: [
      { value: 100, name: 'A' },
      { value: 200, name: 'B' }
    ]
  }]
}
```

### 散点图
```javascript
{
  xAxis: { type: 'value' },
  yAxis: { type: 'value' },
  series: [{
    type: 'scatter',
    data: [[x1, y1], [x2, y2]],
    symbolSize: 10
  }]
}
```

## 最佳实践

### 数据墨水比例
- 移除不必要的网格线
- 最小化图表垃圾
- 让数据成为焦点

### 清晰性
- 清晰、描述性的标题
- 带单位的标记坐标轴
- 适当的精度（不要太多小数）

### 比较
- 条形图的 y 轴从零开始
- 使用一致的尺度进行比较
- 逻辑排序数据

### 配色
- 有目的地使用颜色
- 考虑色盲用户
- 不要使用太多颜色（≤7）

### 交互
- 工具提示显示详细信息
- 缩放用于密集数据
- 下钻用于层级

## 更好图表的技巧

1. **了解您的受众** - 技术型 vs. 高管型
2. **从问题开始** - 您试图回答什么？
3. **选择合适的图表** - 不要强迫数据进入错误格式
4. **简化** - 少即是多
5. **清晰标记** - 假设观众没有背景信息
6. **用真实用户测试** - 信息是否清晰？
7. **考虑无障碍性** - 颜色、对比度、替代文本
