# 学术搜索技能

## 概述

我帮助您导航学术文献，查找相关论文，理解研究方法，并整合研究成果，以支持您的研究项目或文献综述。

**我能做什么：**
- 构建学术搜索查询
- 推荐数据库和搜索策略
- 分析论文摘要和总结
- 解释研究方法
- 帮助构建文献综述结构
- 识别研究空白

**我不能做什么：**
- 直接访问全文论文（除非提供）
- 执行实际数据库搜索
- 访问付费期刊
- 开展原创研究

## 搜索查询构建

### 逻辑运算符

```
AND：必须同时出现两个术语
     "机器学习" AND 医疗保健

OR：可以出现任一术语
     "深度学习" OR "神经网络"

NOT：排除术语
     气候变化 NOT 政治

():  组合术语
     (AI OR "人工智能") AND 伦理
```

### 高级技巧

#### 1. PICO框架（医学/健康）
```
P - 群体/患者
I - 干预措施
C - 比较
O - 结果

示例: "老年人患者" AND "运动疗法" AND "认知功能"
```

#### 2. 概念映射
```
主要概念：教育中的机器学习
├── 同义词：人工智能、深度学习
├── 相关：自适应学习、智能辅导
└── 应用：个性化、评估、分析

查询: ("机器学习" OR "人工智能" OR "深度学习") 
       AND (教育 OR 学习 OR "辅导系统")
```

#### 3. 引文链
```
正向引文：这篇论文被谁引用了？
反向引文：这篇论文引用了什么？
→ 两种方法都有助于找到相关研究
```

## 论文分析框架

### 阅读策略：三段式方法

#### 第一段：浏览（5-10分钟）
- 阅读标题、摘要、引言
- 浏览标题和图表
- 阅读结论
- **结果**：决定是否值得深入阅读

#### 第二段：理解（30-60分钟）
- 仔细阅读但跳过证明和细节
- 记录关键点和问题
- 理解图表和表格
- **结果**：掌握主要贡献

#### 第三段：深入（数小时）
- 虚拟重新实现这项工作
- 挑战每个假设
- 识别优势和劣势
- **结果**：专家级理解

### 批判性分析问题

| 方面 | 问题 |
|--------|-------|
| 研究问题 | 是否清晰？重要？新颖？ |
| 方法论 | 是否适当？严谨？可重复？ |
| 结果 | 令人信服？统计有效？ |
| 局限性 | 是否承认？有多严重？ |
| 贡献 | 有什么新内容？有多重要？ |

## 引文格式

### APA第7版
```
作者A. A. & 作者B. B. (年份). 文章标题. 
期刊名称, 卷(Issue), 页码-页码. https://doi.org/xxxxx
```

### IEEE
```
[1] 作者A. 和 作者B., "文章标题," 期刊名称, 
vol. X, no. X, pp. XX-XX, 月份年份.
```

### 芝加哥
```
作者姓氏, 姓名. "文章标题." 期刊名称 卷, 
no. Issue (年份): 页码-页码.
```

## 获取更好结果的技巧

1. **从综述文章开始**以了解研究格局
2. **使用引文链** - 正向和反向
3. **检查作者简介**以查找相关研究
4. **设置警报**以获取您主题的新论文
5. **使用参考文献管理器**（Zotero, Mendeley）
6. **先阅读摘要**以高效筛选
7. **关注近期 + 经典**论文
