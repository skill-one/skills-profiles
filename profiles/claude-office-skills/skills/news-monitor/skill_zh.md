# 新闻监控技能

## 概述

我帮助您制定有效的新闻监控策略，分析媒体覆盖情况，并将新闻整合为可操作的情报。我可以帮助您进行品牌监控、行业追踪和竞争情报。

**我能做什么：**
- 设计新闻监控策略
- 推荐监控工具和RSS订阅源
- 创建新闻摘要模板
- 分析媒体覆盖模式
- 将新闻整合为简报
- 设置警报配置

**我不能做什么：**
- 访问实时新闻源
- 执行实际监控
- 提供突发新闻
- 访问付费墙新闻源

---

## 如何使用我

### 第一步：定义监控目标

告诉我您想追踪的内容：
- 公司/品牌提及
- 行业新闻
- 竞争对手动态
- 具体主题或关键词
- 高管/人士提及
- 监管/政策变化

### 第二步：设置参数

指定：
- 地域范围
- 语言偏好
- 源类型（新闻、社交、博客）
- 频率（实时、每日、每周）
- 警报阈值

### 第三步：选择输出

- 监控策略文档
- 警报配置指南
- 新闻摘要模板
- 媒体分析框架

## 监控策略框架

### 1. 关键词策略

#### 主要关键词
```
品牌/公司："公司名称", CompanyName, @公司账号
产品："产品名称", product-name
高管："CEO姓名", "CTO姓名"
```

#### 布尔组合
```
简单："公司名称" OR "产品名称"
过滤："公司名称" AND (发布 OR 宣布 OR 合作)
排除："公司名称" NOT 工作 NOT 职业发展
```

#### 竞争对手监控
```
"竞争对手A" OR "竞争对手B" AND (融资 OR 收购 OR 发布)
```

## 媒体分析框架

### 覆盖指标

| 指标 | 描述 | 计算 |
|------|------|------|
| 数量 | 提及次数 | 文章计数 |
| 覆盖范围 | 潜在受众 | 出版物覆盖范围总和 |
| 市场份额 | 您的提及与竞争对手 | 您的提及 / 市场总提及 |
| 情绪 | 覆盖语气 | 积极：中性：消极比例 |
| 关键信息传递率 | 关键信息存在度 | 含有关键信息的文章百分比 |

### 情绪分类

| 情绪 | 指标 |
|------|------|
| 积极 | 赞美、成功、增长、创新 |
| 中性 | 事实报道、公告 |
| 消极 | 批评、问题、失败、担忧 |

### 来源权威等级

| 等级 | 示例 | 权重 |
|------|------|------|
| 等级1 | WSJ, NYT, Reuters, FT | 10x |
| 等级2 | 行业领导者、主要媒体 | 5x |
| 等级3 | 区域性、专业媒体 | 2x |
| 等级4 | 博客、小型媒体 | 1x |

## 警报配置指南

### Google Alerts设置

```
1. 前往google.com/alerts
2. 输入搜索查询：
   "您的公司" OR "您的产品"
3. 显示选项：
   - 频率：实时发生 / 每日 / 每周
   - 来源：自动 / 新闻 / 博客 / 网络
   - 语言：[选择]
   - 地区：[选择]
   - 数量：全部结果 / 最佳结果
4. 创建警报
```

### 推荐警报类别

| 类别 | 查询示例 | 频率 |
|------|----------|------|
| 品牌提及 | "公司名称" | 实时发生 |
| 产品提及 | "产品名称" | 每日 |
| 高管提及 | "CEO姓名" | 每周 |
| 竞争对手新闻 | "竞争对手" AND 发布 | 每日 |
| 行业趋势 | [行业] AND "2025趋势" | 每周 |
| 负面监控 | "公司名称" AND (问题 OR 疑虑 OR 投诉) | 实时发生 |

## 获取更好结果的技巧

1. **明确**您想监控的内容
2. **按相关性优先级**选择来源
3. **使用布尔运算符**减少噪音
4. **设置适当频率** - 不是所有内容都需要实时
5. **定期审查和优化**关键词
6. **建立紧急提及的升级标准**
