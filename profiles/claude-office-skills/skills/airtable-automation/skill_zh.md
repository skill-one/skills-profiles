# Airtable 自动化

使用视图、自动化、集成和跨平台工作流来自动化 Airtable 数据库。基于 n8n 的 Airtable 集成模板。

## 概述

本技能涵盖：
- 数据库设计和视图
- 内置自动化
- n8n 集成工作流
- 公式和汇总设计
- 报告和仪表板

## 数据库设计

### 基础结构模板

```yaml
base: "项目管理"

tables:
  项目:
    字段:
      - 名称: 单行文本 (主键)
      - 状态: 单选 [计划中, 进行中, 暂停, 已完成]
      - 优先级: 单选 [P0, P1, P2, P3]
      - 负责人: 协作者
      - 开始日期: 日期
      - 截止日期: 日期
      - 预算: 货币
      - 任务: 链接到记录 (任务)
      - 进度: 汇总 (任务.状态, COUNTIF(完成)/COUNT)
      - 剩余天数: 公式 (DATETIME_DIFF(截止日期, TODAY(), 'days'))
      
  任务:
    字段:
      - 任务名称: 单行文本 (主键)
      - 项目: 链接到记录 (项目)
      - 状态: 单选 [待办, 进行中, 审核中, 已完成]
      - 指派给: 协作者
      - 截止日期: 日期
      - 预计工时: 数字
      - 实际工时: 数字
      - 附件: 附件
      
  团队:
    字段:
      - 名称: 单行文本 (主键)
      - 邮箱: 邮件
      - 角色: 单选 [项目经理, 开发者, 设计师, 测试人员]
      - 当前项目: 链接到记录 (项目)
      - 工作量: 数字 (每周小时数)
      - 利用率: 汇总 (从任务计算)
```

## 自动化

### 内置 Airtable 自动化

```yaml
automation_1:
  名称: "新建任务通知"
  触发器:
    当: 记录创建
    表: 任务
  动作:
    - 发送到 Slack:
        频道: "#项目更新"
        消息: |
          📋 新建任务！
          任务: {任务名称}
          项目: {项目}
          指派给: {指派给}
          截止日期: {截止日期}

automation_2:
  名称: "过期任务提醒"
  触发器:
    当: 记录匹配条件
    表: 任务
    条件:
      - 状态: 不是 "已完成"
      - 截止日期: 今天之前
  动作:
    - 发送邮件:
        收件人: "{指派给.email}"
        主题: "⚠️ 过期任务: {任务名称}"
        正文: "您的任务 '{任务名称}' 的截止日期是 {截止日期}。"
    - 更新记录:
        字段: 状态
        值: "过期"

automation_3:
  名称: "项目完成"
  触发器:
    当: 记录更新
    表: 项目
    字段: 进度
    条件: 等于 100%
  动作:
    - 更新记录:
        字段: 状态
        值: "已完成"
    - 发送到 Slack:
        频道: "#胜利"
        消息: "🎉 项目 '{名称}' 已完成！"
```

### n8n 集成工作流

```yaml
workflow: "表单到 Airtable 到 CRM"

触发器: typeform_submission

步骤:
  1. 创建 Airtable 记录:
      base: "线索"
      表: "联系人"
      字段:
        名称: "{表单.姓名}"
        邮箱: "{表单.邮箱}"
        公司: "{表单.公司}"
        来源: "网站表单"
        创建时间: "{时间戳}"
        
  2. 丰富数据:
      clearbit: 查找邮箱
      更新记录:
        公司规模: "{clearbit.company_size}"
        行业: "{clearbit.industry}"
        
  3. 同步到 HubSpot:
      创建联系人:
        邮箱: "{邮箱}"
        属性: from_airtable
        
  4. 通知销售:
      slack:
        频道: "#新线索"
        消息: "新线索: {姓名} 来自 {公司}"
```

## 公式参考

### 常用公式

```yaml
formulas:
  剩余天数:
    公式: "DATETIME_DIFF({截止日期}, TODAY(), 'days')"
    输出: 数字
    
  是否过期:
    公式: "IF(AND({状态}!='已完成', {截止日期}<TODAY()), '是', '否')"
    输出: 文本
    
  全名:
    公式: "CONCATENATE({名}, ' ', {姓})"
    输出: 文本
    
  进度条:
    公式: |
      REPT('▓', ROUND({进度}/10, 0)) & 
      REPT('░', 10-ROUND({进度}/10, 0)) & 
      ' ' & ROUND({进度}, 0) & '%'
    输出: 文本 (可视化进度)
    
  状态表情:
    公式: |
      SWITCH({状态},
        '待办', '⬜',
        '进行中', '🔵',
        '审核中', '🟡',
        '已完成', '✅',
        '❓'
      )
    输出: 文本
    
  剩余工作日:
    公式: "WORKDAY_DIFF(TODAY(), {截止日期})"
    输出: 数字
    
  季度:
    公式: |
      'Q' & CEILING(MONTH({日期})/3) & ' ' & YEAR({日期})
    输出: 文本
```

### 汇总示例

```yaml
rollups:
  任务数量:
    链接字段: 任务
    聚合: COUNT(values)
    
  总工时:
    链接字段: 任务
    汇总字段: 预计工时
    聚合: SUM(values)
    
  完成率:
    链接字段: 任务
    汇总字段: 状态
    聚合: |
      COUNTALL(IF(values='已完成', 1)) / COUNT(values) * 100
      
  平均评分:
    链接字段: 评论
    汇总字段: 评分
    聚合: AVERAGE(values)
```

## 集成模式

### Airtable + Slack

```yaml
slack_integration:
  新记录通知:
    触发器: 记录创建
    动作: 发送到频道
    模板: |
      *新建 {表} 记录*
      {字段1}: {value1}
      {字段2}: {value2}
      <{记录URL}|在 Airtable 中查看>
      
  每日摘要:
    时间表: "工作日 9 点"
    查询: 记录到期
    动作: 发送摘要
    
  剪贴板命令:
    命令: /airtable-add
    动作: 从 Slack 创建记录
```

### Airtable + 日历

```yaml
calendar_sync:
  airtable_to_google:
    触发器: 带日期创建记录
    动作: 创建日历事件
    映射:
      标题: "{名称}"
      开始时间: "{日期}"
      描述: "{笔记}"
      
  google_to_airtable:
    触发器: 日历事件创建
    动作: 创建 Airtable 记录
    映射:
      名称: "{event.title}"
      日期: "{event.start}"
      类型: "会议"
```

### Airtable + Zapier/n8n

```yaml
multi_step_workflow:
  名称: "线索处理流程"
  
  触发器:
    平台: airtable
    事件: 新记录
    表: 原始线索
    
  步骤:
    - 丰富:
        服务: clearbit
        输入: 邮箱
        输出: 公司数据
        
    - 评分:
        服务: ai_scoring
        标准: [公司规模, 行业, 职位]
        输出: 线索评分
        
    - 路由:
        条件: 线索评分
        高: 指派给销售
        中: 添加到培育
        低: 标记为冷线索
        
    - 更新 Airtable:
        表: 合格线索
        字段: [丰富数据, 评分, 指派]
        
    - 通知:
        如果: 高评分
        slack: 销售代表 DM
```

## 报告模板

### 每周状态报告

```yaml
report_automation:
  时间表: "周五 5 点"
  
  查询:
    本周完成:
      表: 任务
      过滤: 
        - 状态: 已完成
        - 完成日期: 本周
        
    进行中:
      表: 任务
      过滤:
        - 状态: 进行中
        
    过期:
      表: 任务
      过滤:
        - 状态: 不是 已完成
        - 截止日期: 今天之前
        
  输出:
    格式: markdown
    目的地: [slack, 邮件]
    模板: |
      # 每周状态报告 - {周}
      
      ## 已完成 ({完成数量})
      {完成列表}
      
      ## 进行中 ({进行中数量})
      {进行中列表}
      
      ## 过期 ({过期数量}) ⚠️
      {过期列表}
      
      ## 指标
      - 完成率: {rate}%
      - 按时交付: {on_time}% 
```

### 仪表板视图

```yaml
dashboard:
  名称: "项目仪表板"
  
  组件:
    - 汇总条形图:
        指标:
          - 总项目: COUNT(项目)

        类型: 条形图

    - 团队利用率:
        类型: 水平条形图
        数据: 按任务数量分组的人员
```

## 自动化

**1. 新内容想法**
```
触发器: 记录创建
动作: Slack to #内容想法
```

**2. 准备审核**
```
触发器: 状态 → 审核中
动作: 邮件编辑 + 设置截止日期
```

**3. 已发布**
```
触发器: 状态 → 已发布
动作: 
- 发布到社交调度器
- 添加分析跟踪行
- 在 Slack 中庆祝 🎉
```
