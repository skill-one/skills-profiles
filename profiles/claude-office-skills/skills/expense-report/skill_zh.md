# 费用报告

## 概述

这项技能可以帮助您将业务费用整理成清晰、分类的报告，适用于报销申请、会计和税务准备。

**使用场景：**
- 创建费用报销报告
- 整理用于税务准备的收据
- 对业务费用进行分类
- 汇总差旅费用
- 准备月度/季度费用汇总

## 如何使用

1. 提供您的费用信息（收据、交易或描述）
2. 指定目的（报销、税务准备、预算跟踪）
3. 告诉我您的费用类别或政策
4. 我将为您创建一个结构化的费用报告

**示例提示：**
- "根据这些收据为我创建一次商务旅行的费用报告"
- "对本月费用进行分类和汇总"
- "将这些费用格式化为报销格式"
- "帮助我整理自由职业业务的费用以用于报税"

## 处理指南

### 收据要求
- **保留收据用于：** 所有超过 $25 (美元) 或当地阈值的费用
- **所需信息：** 日期、供应商、金额、支付方式
- **餐饮：** 包括参会人员和业务目的
- **缺失收据：** 在报告中注明解释

### 货币转换
- 使用费用发生当日的汇率
- 记录汇率来源（银行、XE.com 等）
- 保留原始货币及转换后的金额

### 里程计算
- 当前 IRS 比率（2024 年）：每英里 $0.67（请核实当前比率）
- 记录：日期、目的地、目的、里程
- 使用里程表读数或地图应用程序

## 限制

- 无法直接扫描或读取收据图片
- 税务建议应咨询专业人士
- 汇率应核实准确性
- 公司政策可能有特定要求
- 无法将报告提交到您的费用系统

## 示例

### 示例：快速费用整理

**输入：**
