# 与 PDF 对话

针对 PDF 文档进行智能对话 - 提问、获取摘要、提取特定信息。

## 概述

此功能可让您：
- 提问 PDF 内容相关问题
- 获取不同详细程度的摘要
- 提取特定数据点
- 比较多个 PDF 中的信息
- 快速查找相关章节

## 如何使用

### 基本交互
1. 分享或上传 PDF 文档
2. 提出您的问题或请求
3. 获取带引用的上下文答案

### 问题类型

**事实性问题**
```
"这份文档中提到的合同价值是多少？"
"这份协议涉及哪些方？"
"提到了哪些关键日期？"
```

**摘要**
```
"用 3 个要点总结这份文档"
"给我一份执行摘要"
"涵盖了哪些主要内容？"
```

**提取**
```
"提取所有提到的人名和头衔"
"列出文档中的所有财务数据"
"查找所有行动项或交付成果"
```

**分析**
```
"这份合同中提到了哪些风险？"
"是否存在任何模糊的条款？"
"A 方有哪些义务？"
```

## 输出格式

### Q&A 格式
```markdown
**问题**：[您的问题]

**答案**：[对您问题的直接回答]

**来源**：第 [X] 页，第 [Y] 节
> "[文档中的相关引用]"

**置信度**：[高/中/低]
```

### 摘要格式
```markdown
## 文档摘要

**类型**：[合同/报告/手册等]
**页数**：[X]
**日期**：[如提及]

### 关键点
1. [要点 1]
2. [要点 2]
3. [要点 3]

### 重要细节
- [细节 1]
- [细节 2]
```

### 提取格式
```markdown
## 提取信息

### [类别 1]
| 项目 | 值 | 位置 |
|------|-------|----------|
| [项目 1] | [值] | 第 X 页 |
| [项目 2] | [值] | 第 Y 页 |

### [类别 2]
...
```

## 最佳实践

### 获取更好的答案
1. **具体提问**："终止条款是什么？" vs "告诉我关于合同的内容"
2. **引用章节**："第 5.2 节关于责任是什么？"
3. **追问**：基于之前的答案进行深入理解

### 获取更好的提取
1. **指定格式**："提取为表格" 或 "以要点形式列出"
2. **命名字段**："提取：姓名、日期、金额、描述"
3. **设置标准**："仅提取超过 10,000 美元的金额"

### 获取更好的摘要
1. **指定长度**："用 100 字总结" 或 "3 个要点"
2. **聚焦领域**："仅总结财务条款"
3. **受众**："为法律团队总结" vs "为高管总结"

## 示例工作流

### 合同审查
```
1. "这是什么类型的合同？"
2. "涉及哪些方及其角色？"
3. "每方的关键义务是什么？"
4. "合同期限和续签流程是什么？"
5. "终止条件是什么？"
6. "是否存在任何不寻常或令人担忧的条款？"
```

### 研究论文分析
```
1. "主要论点或假设是什么？"
2. "使用了什么方法？"
3. "关键发现是什么？"
4. "提到了哪些局限性？"
5. "他们建议哪些未来研究？"
```

### 财务报告
```
1. "报告的总收入是多少？"
2. "与去年相比如何？"
3. "主要支出类别是什么？"
4. "对下一季度有何指导？"
5. "将所有财务指标提取到表格中"
```

## 多文档支持

处理多个 PDF 文档时：

```
"比较合同 A 和合同 B 的条款"
"哪个文档提到了 [主题]？"
"创建一个比较所有文档关键点的摘要表"
```

### 比较输出
```markdown
## 文档比较

| 方面 | 文档 A | 文档 B |
|------|--------|--------|
| 合同期限 | 2 年 | 3 年 |
| 价值 | 50,000 美元 | 75,000 美元 |
| 终止 | 30 天通知 | 60 天通知 |

### 主要差异
1. [差异 1]
2. [差异 2]

### 相似之处
1. [相似之处 1]
2. [相似之处 2]
```

## 处理挑战

### 扫描 PDF（基于图像）
- 自动应用 OCR
- 质量取决于扫描质量
- 可能存在识别错误

### 复杂布局
- 表格可能需要重新格式化
- 多列文本从左到右处理
- 脚注单独处理

### 长文档
- 针对特定章节提问以提高准确性
- 请求分页摘要以获取概览
- 使用针对性问题而非宽泛问题

## 限制

- 无法执行 PDF 中嵌入的代码
- 需要密码才能打开密码保护的 PDF
- 超过 500 页的 PDF 可能需要分块处理
- 手写内容识别有限
- 无法保证扫描文档的 100% 准确性
- 图表和图像仅被描述，不进行数值分析

## 隐私声明

文档内容根据 AI 提供商的隐私政策进行处理。对于敏感文档，请考虑：
- 使用本地解决方案
- 先进行信息脱敏
- 检查数据保留政策
