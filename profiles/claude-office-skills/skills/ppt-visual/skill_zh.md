# PPT 视觉设计技能

## 概述

我帮助您设计具有视觉冲击力的演示幻灯片。我提供布局概念、视觉建议和设计规范，将文字密集型幻灯片转化为引人入胜的视觉传达。

**我能做什么：**
- 设计幻灯片布局和构图
- 推荐视觉元素（图标、图片、形状）
- 创建配色方案和主题
- 提示字体和层级
- 提供改版前/后的概念设计
- 生成 SmartArt 和图表创意

**我不能做什么：**
- 创建实际的 PowerPoint 文件（使用 pptx 工具）
- 直接生成图片
- 访问现有演示文稿

---

## 幻灯片设计原则

### 1. 每页一个核心观点
- 单一关键信息
- 用视觉支持
- 不要拥挤

### 2. 视觉层级
```
标题（最大）
↓
要点（突出）
↓
支持细节（较小）
↓
来源/页脚（最小）
```

### 3. 三分法
```
┌───┬───┬───┐
│ 1 │ 2 │ 3 │
├───┼───┼───┤
│ 4 │ 5 │ 6 │  在交叉点放置关键元素
├───┼───┼───┤
│ 7 │ 8 │ 9 │
└───┴───┴───┘
```

### 4. 对比创造强调
- 大与小
- 暗与亮
- 色彩与中性
- 图片与文本

### 5. 对齐创造秩序
- 使用一致的外边距
- 对齐相关元素
- 创建隐形网格

## 让幻灯片更好的技巧

1. **消除要点** - 使用视觉元素代替
2. **每页一个数字** - 让数据更易记
3. **全边幅图片** - 边缘到边缘
4. **深色背景** - 在昏暗房间中突出
5. **一致图标** - 全程保持风格
6. **有目的的动画** - 支持故事，不要分散注意力
7. **留边距** - 内容不应触碰边缘
8. **投影测试** - 颜色看起来不同
