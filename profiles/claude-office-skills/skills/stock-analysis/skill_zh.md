# 股票分析技能

## 概述

我使用基本面和技术分析方法帮助您分析股票。我可以评估美国、中国A股和香港市场的公司。

**我能做什么：**
- 基本面分析（市盈率、市净率、净资产收益率、收入增长、利润率）
- 技术分析（趋势、支撑/阻力位、指标）
- 同行比较和行业定位
- 风险评估和投资逻辑
- 生成结构化分析报告

**我不能做什么：**
- 提供实时股价（使用外部数据源）
- 提供投资建议或推荐
- 保证未来表现
- 获取专有交易数据

## 分析框架

### 基本面分析指标

#### 估值比率
| 指标 | 公式 | 解释 |
|------|------|------|
| 市盈率 | 价格 / 每股收益 | <15低估，>25昂贵 |
| 市净率 | 价格 / 账面价值 | <1潜在价值，>3已包含增长 |
| 市销率 | 价格 / 收入 | 对亏损公司有用 |
| 企业价值/EBITDA | 企业价值 / EBITDA | <10有吸引力，>15昂贵 |
| 市盈率相对盈利增长比率 | 市盈率 / 增长率 | <1相对于增长低估 |

#### 盈利能力指标
| 指标 | 公式 | 良好基准 |
|------|------|------|
| 毛利率 | 毛利润 / 收入 | >40%强大的定价能力 |
| 营业利润率 | 营业收入 / 收入 | >15%高效运营 |
| 净利润率 | 净利润 / 收入 | >10%健康的盈利能力 |
| 净资产收益率 | 净利润 / 股东权益 | >15%良好的资本效率 |
| 投资资本回报率 | NOPAT / 投资资本 | >WACC价值创造 |

#### 增长指标
| 指标 | 要寻找的内容 |
|------|------|
| 收入增长 | >10%年增长率表明强劲需求 |
| 每股收益增长 | 应快于收入（经营杠杆） |
| 自由现金流增长 | 可持续增长动力 |

#### 财务健康状况
| 指标 | 公式 | 安全范围 |
|------|------|------|
| 负债权益比 | 总负债 / 权益 | 大多数行业<1 |
| 流动比率 | 流动资产 / 流动负债 | >1.5健康的流动性 |
| 利息保障倍数 | EBIT / 利息支出 | >5舒适 |
| 自由现金流收益率 | 自由现金流 / 市值 | >5%有吸引力 |

### 技术分析模式

#### 趋势指标
- **移动平均线**：50日、200日交叉
- **MACD**：动量和趋势方向
- **相对强弱指数**：超买（>70）/ 超卖（<30）

#### 图表模式
- **支撑/阻力位**：关键价格水平
- **头肩顶**：反转模式
- **双顶/双底**：反转信号
- **突破**：成交量确认的移动
