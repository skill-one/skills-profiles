# Slack 工作流

使用智能工作流自动化工具有通知、站会收集、审批流程和跨平台集成。基于 n8n 自动化模式。

## 概述

本技能涵盖：
- 自动化通知和警报
- 每日站会收集
- 审批工作流
- 跨平台集成
- 频道管理自动化

---

## 核心工作流

### 1. 每日站会机器人

```yaml
workflow: "异步站会"
schedule: "工作日 上午 9:00"

步骤：
  1. 发送提示：
      频道：每个团队成员（私信）
      消息： |
        👋 早上好！是站会时间了。
        
        请分享：
        1️⃣ 你昨天完成了什么？
        2️⃣ 你今天在做什么？
        3️⃣ 有什么阻碍？
        
        在此线程中回复 👇
        
  2. 收集回复：
      超时：2小时
      提醒：1小时后
      
  3. 汇总摘要：
      时间：上午 11:00
      频道：#team-standup
      格式： |
        📋 *每日站会 - {日期}*
        
        {遍历每个成员}
        *{姓名}*
        ✅ 昨天：{昨天完成}
        📌 今天：{今天计划}
        🚧 阻碍：{阻碍}
        
        ---
        {结束遍历}
        
        *摘要：*
        • {总人数} 名团队成员回复
        • {阻碍数量} 个阻碍被标记
        
  4. 标记阻碍：
      如果：阻碍数量 > 0
      通知：经理
      操作：创建讨论线程
```

### 2. 审批工作流

```yaml
workflow: "费用审批"
触发：表单提交 或 剪贴板命令

步骤：
  1. 接收请求：
      数据：
        - 申请人
        - 金额
        - 类别
        - 描述
        - 收据链接
        
  2. 分配审批：
      规则：
        - 如果：金额 < 100
          审批人：直接经理
          
        - 如果：金额 >= 100 AND 金额 < 1000
          审批人：部门主管
          
        - 如果：金额 >= 1000
          审批人：[部门主管, 财务]
          类型：顺序
          
  3. 发送审批请求：
      频道：私信给审批人
      消息： |
        📝 *费用审批请求*
        
        *来自：* {申请人}
        *金额：* ${金额}
        *类别：* {类别}
        *描述：* {描述}
        
        [查看收据]({收据链接})
        
      操作：
        - 按钮： "✅ 批准"
          操作：批准
        - 按钮： "❌ 拒绝"
          操作：拒绝
        - 按钮： "💬 提问"
          操作：请求信息
          
  4. 处理响应：
      批准：
        - 通知申请人： "您的费用已批准！ 🎉"
        - 创建任务：在会计系统中
        - 记录：在费用追踪器中
        
      拒绝：
        - 通知申请人： "费用未批准。原因：{原因}"
        - 记录：带有拒绝原因
        
  5. 如果无响应则升级：
      超时：24小时
      操作：提醒审批人
      最终升级：48小时
```

### 3. 新员工入职

```yaml
workflow: "员工入职"
触发：新员工添加到 HRIS

时间线：
  7天前：
    - 创建频道：
        - "#welcome-{姓名}"
        - 添加到：["#general", "#team-{部门}"]
    - 通知 IT： "为 {姓名} 设置笔记本电脑"
    - 通知经理： "入职 7 天后开始"
    
  第1天：
    - 上午：
        - 发布欢迎： "#general"
          消息： |
            🎉 请欢迎 *{姓名}* 加入团队！
            
            职位：{职位}
            团队：{部门}
            地点：{办公室}
            
            有趣的事实：{有趣的事实}
            
            打招呼并让他们感觉受欢迎！ 👋
            
        - 私信新员工：
            消息： |
              欢迎加入 {公司}！ 🚀
              
              您的第一步：
              1. [完成 HR 文件]({hr链接})
              2. [设置您的账户]({it链接})
              3. [认识团队]({组织架构图})
              
              您的伙伴是 @{伙伴姓名} - 随时联系！
              
    - 下午：
        - 安排介绍：与关键利益相关者
        
  第3天：
    - 检查：
        私信： "第一周怎么样？有什么问题吗？"
        
  第7天：
    - 问卷：
        问题： "您的入职体验如何？"
        评分：1-5
        
  第30天：
    - 反馈请求：
        私信： "您入职一个月了！我们可以改进什么？"
```

### 4. 事件响应

```yaml
workflow: "事件警报"
触发：监控警报 或 手动

严重程度级别：
  紧急：
    - 创建频道： "#incident-{时间戳}"
    - 通知： "@频道 在 #engineering"
    - 联系：值班工程师
    - 创建会议室：视频链接
    - 开始计时：用于解决跟踪
    
  高：
    - 通知： "#engineering-alerts"
    - 指派：值班工程师
    - 创建工单：在 Jira 中
    
  中：
    - 通知： "#engineering-alerts"
    - 创建工单：在 Jira 中
    
  低：
    - 创建工单：在 Jira 中
    - 通知：下一个工作日

事件频道模板： |
  🚨 *事件：{标题}*
  
  *严重程度：* {严重程度}
  *状态：* 调查中
  *开始时间：* {时间戳}
  *指挥官：* @{指挥官}
  
  ---
  
  *受影响系统：*
  {系统}
  
  *客户影响：*
  {影响}
  
  ---
  
  📋 *行动：*
  • [ ] 确定根本原因
  • [ ] 实施修复
  • [ ] 验证解决
  • [ ] 通知利益相关者
  
  🔗 *链接：*
  • [运行手册]({运行手册链接})
  • [仪表板]({仪表板链接})
  • [视频会议室]({视频链接})

解决流程：
  1. 指挥官宣布： "已解决"
  2. 通知利益相关者：解决消息
  3. 24小时后归档频道
  4. 在 Notion 中创建事后分析
  5. 在日历中安排回顾
```

## 剪贴板命令

### 自定义命令

```yaml
剪贴板命令：
  /kudos：
    描述： "给队友认可"
    使用： "/kudos @人 因 [原因]"
    操作：
      - 发布到： "#kudos"
      - 格式： |
          🌟 *认可！*
          
          @{发送者} 给了 @{接收者} 认可
          
          > {原因}
          
      - 记录：在认可电子表格中
      
  /pto：
    描述： "申请休假"
    使用： "/pto [开始日期] 到 [结束日期] 因 [原因]"
    操作：
      - 创建审批：pto审批工作流
      - 更新日历：锁定日期
      - 通知团队：如果批准
      
  /standup：
    描述： "提交异步站会"
    使用： "/standup"
    操作：
      - 打开模态框：站会表单
      - 收集回复：昨天，今天，阻碍
      - 发布到： "#team-standup"
      
  /poll：
    描述： "创建快速投票"
    使用： "/poll '问题' '选项 1' '选项 2' ..."
    操作：
      - 创建消息：带反应
      - 跟踪投票：通过反应计数
      - 关闭投票：24小时后或手动
```

## 频道管理

```yaml
频道自动化：
  项目频道：
    触发：jira项目创建
    操作：
      - 创建频道： "#proj-{项目键}"
      - 添加成员：项目团队
      - 设置主题："{项目名称} - {项目描述}"
      - 排钉消息：项目资源
      - 归档：项目完成后
      
  客户频道：
    触发：交易成功
    操作：
      - 创建频道： "#customer-{公司}"
      - 添加成员：[客户成功经理, 销售代表, 支持]
      - 设置目的："{公司} 的支持频道"
      - 集成：zendesk警报
      
  清理：
    时间表：每月
    规则：
      - 如果归档：
          无消息：90天
          AND：
            未排钉：true
            不是客户频道：true
      - 归档前通知：7天
```

## n8n 实现

```javascript
// HubSpot 触发器 → Slack 节点
{
  "节点": [
    {
      "名称": "HubSpot 触发器",
      "类型": "n8n-nodes-base.hubspotTrigger",
      "参数": {
        "eventsUi": {
          "事件值": ["deal.propertyChange"]
        },
        "属性": "dealstage",
        "值": "closedwon"
      }
    },
    {
      "名称": "格式化消息",
      "类型": "n8n-nodes-base.set",
      "参数": {
        "值": {
          "消息": "🎉 *交易成功！*\n\n🏢 {{$json.company}}\n💰 ${{$json.amount}}"
        }
      }
    },
    {
      "名称": "Slack",
      "类型": "n8n-nodes-base.slack",
      "参数": {
        "频道": "#wins",
        "文本": "={{$json.message}}"
      }
    }
  ]
}
```
