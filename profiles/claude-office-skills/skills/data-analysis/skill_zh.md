# 数据分析助手

在电子表格中分析数据，发现洞察，并创建引人入胜的可视化。

## 概述

这项技能可以帮助您：
- 理解和探索您的数据
- 执行统计分析
- 生成洞察和建议
- 创建图表和可视化
- 编写公式和查询

## 如何使用

### 开始使用
1. 分享您的电子表格或数据文件
2. 描述您想要分析的内容
3. 获取洞察、公式或可视化

### 分析类型

**探索性分析**
```
"您在这份数据中看到了哪些模式？"
"给我这份数据集的概述"
"哪些是关键统计数据？"
```

**特定问题**
```
"按地区总收入是多少？"
"哪些产品增长最快？"
"X和Y之间是否存在相关性？"
```

**可视化请求**
```
"创建一个显示销售趋势的图表"
"制作一个比较Q1和Q2的图表"
"显示客户年龄的分布"
```

## 公式生成

### 请求公式
```
"编写一个计算同比增长的公式"
"创建一个VLOOKUP来匹配客户数据"
"根据条件创建动态求和"
```

### 公式输出
```markdown
## 公式：[目的]

### Excel/Google Sheets
```excel
=SUMIFS(Sales[Amount], Sales[Region], "North", Sales[Date], ">="&DATE(2025,1,1))
```

### 解释
- `SUMIFS`: 求满足多个条件的值
- 第一个参数：求和列
- 随后的参数对：条件列 + 条件值

### 使用方法
将公式放置在您希望显示结果的单元格 [X] 中。
```

## 最佳实践

### 为更好的分析
1. **首先清理数据**: 处理缺失值、重复项
2. **明确定义指标**: 你到底在衡量什么？
3. **考虑背景**: 行业基准、季节性
4. **验证发现**: 与其他数据源交叉检查

### 为更好的可视化
1. **保持简洁**: 每个图表传达一个主要信息
2. **清晰标记**: 标题、坐标轴、图例
3. **使用适当的刻度**: 不要误导性地截断
4. **考虑色盲用户**: 使用图案或不同颜色

## 限制

- 无法直接在您的数据上执行代码
- 大型数据集可能需要抽样
- 复杂的统计模型需要专业工具
- 实时数据需要实时连接
- 无法保证100%的OCR数据准确性
