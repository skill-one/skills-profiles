# Monday.com 自动化

全面的技能，用于自动化 Monday.com 工作管理和团队工作流程。

## 自动化配方

### 内置自动化

```yaml
自动化：
  - 名称: "状态变更通知"
    触发器:
      类型: 状态变更
      列: "状态"
      到: "完成"
    动作:
      类型: 通知
      目标: 项目订阅者
      消息: "✅ {{item.name}} 已完成！"
  
  - 名称: "截止日期分配"
    触发器:
      类型: 日期到达
      列: "截止日期"
    动作:
      类型: 更改状态
      列: "状态"
      到: "逾期"
  
  - 名称: "自动分配新项目"
    触发器:
      类型: 项目创建
      组: "接收中"
    动作:
      类型: 分配人员
      列: "负责人"
      值: "团队领导"
  
  - 名称: "状态变更时移动"
    触发器:
      类型: 状态变更
      列: "状态"
      到: "完成"
    动作:
      类型: 移动到组
      目标: "已完成"
  
  - 名称: "创建依赖任务"
    触发器:
      类型: 状态变更
      列: "状态"
      到: "待审核"
    动作:
      类型: 创建项目
      板: "审核板"
      值:
        名称: "审核: {{item.name}}"
        链接: "{{item.link}}"
```

### 自定义自动化

```yaml
        频道: "#alerts"
        消息: "⚠️ SLA 风险: {{item.name}}"
  
  - 名称: "预算汇总"
    触发器:
      类型: 列变更
      列: "预算"
    动作:
      类型: 更新父级
      列: "总预算"
      公式: "SUM(subitems.Budget)"
```

## 集成工作流

### Slack 集成

```yaml
slack_automations:
  - 触发器: 状态变更到完成
    动作:
      发送到频道: "#wins"
      消息: "🎉 {{person}} 完成了 {{item}}!"
      
  - 触发器: 项目卡住
    动作:
      发送到频道: "#blockers"
      消息: "🚧 {{item}} 卡住了。负责人: {{person}}"
      
  - 触发器: 新项目创建
    动作:
      发送到频道: "#tasks"
      消息: "📋 新任务: {{item}} ({{board}})"
```

## 最佳实践

1. **组组织**: 使用组表示工作流程阶段
2. **一致列**: 在各板之间标准化
3. **自动化规则**: 减少手动更新
4. **镜像列**: 连接相关板
5. **仪表板视图**: 提供高管可见性
6. **模板**: 重用板结构
7. **子项目**: 将复杂任务分解
8. **依赖关系**: 显示任务关系
