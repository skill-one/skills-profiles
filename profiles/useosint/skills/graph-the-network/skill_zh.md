# 绘制网络图

三十个选择器和三十个选择器的图包含相同的信息，而只有其中一种方式能让你看到两个集群共享一个节点。这就是全部的论证：人类无法检测到跨行的共享元素，但在布局中能立即检测到它们。初学者的错误是将图视为输出——在报告结束时绘制的图片。这是案例的工作记忆，它由最初的透视构建，报告则由此生成。

## 在第二个节点之前确定架构

所有下游有用信息——去重、中心性、查询、报告表格——都取决于前十分钟做出的决策。两条规则：

**每个真实世界的实体对应一个节点。** 别名是属性，不是节点。如果“J. Okonkwo”、“jokonkwo”和“Joseph Okonkwo”是三个节点，那么你计算的任何指标都是错误的：度数被分成三份，因此案例中最重要的那个人看起来是外围的，两个集群之间的共享连接永远不会出现，因为它分布在重复项中。根据证据合并并记录合并（哪些选择器，什么置信度）——未记录的合并是无法审计的断言，即两个事物是同一个事物。

让人犯错的例外：一个人和他们的账户是不同的事物。建模 `Person —operates→ Account`，因为操作者可以改变，账户可以被共享。将它们合并会使这两个事实都无法表示。

**一组封闭的边类型。** 自由文本边标签在一个图中产生 `owns`、`owned-by`、`ownership` 和 `is owner of`，而没有任何查询能找到它们全部。固定词汇表，保持它小，保持方向一致，并将其写在案例文件的顶部。包含实体类型、边类型、必需属性和别名/合并约定的起始架构：
[reference/schema-starter.md](reference/schema-starter.md)。

## 源和置信度放在边上

这是将一个有用的图与一个漂亮的图区分开来的做法，而且是最常被忽略的做法。

节点的来源几乎不是问题。断言在于 *关系*：“这个人控制这家公司”、“这个域名由这个行为者运营”。因此，每条边至少携带：来源（URL、工具或证据 ID）、检索时间戳、来源等级（参见 `investigate-anything`）和置信度。没有它，由注册文件断言的边和由两个发布相似文本的账户推断的边会完全相同——一旦绘制，一个薄弱的链接与一个强大的链接无法区分，并且会被当作事实进行推理。

用视觉方式表示置信度：实线表示确认，虚线表示可能，点线表示未确认。然后看看你的图，并注意到你依赖的结构中有多少是点线的。保持一个 `confirmed-only` 视图，并检查你的结论是否在它消失后仍然成立——如果它崩溃了，你的发现是你最薄弱边的一个产物。

为任何可以结束的边添加时间有效性——`valid_from` / `valid_to`——例如就业、域名注册、地址、董事职位、IP 解析。没有时间的图默默地断言所有事物都共存，这制造了从未重叠的人之间的关系。五年前担任同一公司董事的人不是连接的；无时间的图说他们是。

## 图实际上给你什么

- **共享基础设施。** 一个注册人电子邮件、一个分析或广告标识符、一个 TLS 证书、一个连接看似无关的网站的重复头像哈希。将 `who-owns-this-domain`、`find-hidden-subdomains` 和 `find-exposed-servers` 输入图中，这些就会在没有你寻找它们的情况下作为高度节点出现。
- **桥梁。** 一个移除后会将图分成不连接组件的节点。在实践中，这是连接两个身份或两个网络的人或资产，而且通常是发现。形式上，这是高介数中心性；视觉上，这是两个块之间的节点。
- **度数与介数。** 最高度数的节点通常是 *最明显* 的参与者——公共董事、前台或共享服务。控制方通常位于中度数和高介数：连接很少，但其中重要的连接。计算两者并比较；它们不一致的地方要仔细检查差异。
- **社区。** 模块化/社区检测将图划分为集群。主要用途是找到位于错误集群中的节点。
- **空白。** 在密集邻域中只有一个边的节点是收集空白，而不是关于世界的事实。让稀疏区域驱动下一个透视。

将中心性视为一个指向你应查看位置的指针，而不是一个结论。它衡量你的收集与现实一样多：你列举得最彻底的事物成为图的中心。

## 工具

| 情况 | 选择 |
|---|---|
| 少于 ~200 个节点，一个分析师，需要最终出现在报告中 | 电子表格或 CSV 中的节点和边表，用 Graphviz 渲染或导入 Gephi |
| 查询驱动的工作：路径、共享属性、“谁连接 A 和 B” | Neo4j with Cypher |
| 布局、指标、社区检测、演示 | Gephi |
| 从节点自动透视，并且你有许可 | Maltego |

诚实的默认值：对于大多数调查，两个 CSV——节点和边——加上一个简单的渲染器比所有重型工具都好。它们是可比较的、版本可控的、可由从未见过该工具的人审查的，并且可以导入到所有上述工具中。当你有理由（转换自动化，或图太大无法在脑海中容纳）时才采用 Maltego 或 Neo4j，而不是默认采用。

Maltego 的模型值得理解，即使你不用它：实体携带转换，这些转换是服务器端查找，将一个实体转换为相关实体（域名到子域名到 IP 到证书）。转换是收集，因此每个转换都是可归因于你的网络操作，并且每个结果都带有底层数据源具有的准确性。Maltego 自己的图是转换输出的权威，而不是关于世界。

Cypher 值得学习的一个原因是路径查询。询问“是否存在最多四个关系链连接这个人到那家公司，以及它是什么”是 Neo4j 中的一个查询，而在其他任何地方都是手动苦干。

```cypher
MATCH p = shortestPath((a:Person {id:'p-kestrel'})-[*..4]-(c:Company {id:'c-nordvale'}))
RETURN p
```

功能比较、导入格式、Gephi CSV 列名，以及何时每个工具是错误的选择：[reference/tool-comparison.md](reference/tool-comparison.md)。

## 哪里会出错

**过度连接。** 经典的失败。足够的边，所有事物都连接到所有事物；图变成一个毛发球，并停止传递信息。这通过低价值边发生：同一个国家、同一个注册商、同一个托管提供商、同一个网络邮件域名、同一个流行 CDN IP。Cloudflare 上的两个网站不是相关的。有两个 Gmail 地址的人不是相关的。规则：只有当边 *区分* 时才值得它的位置——如果大量无关实体会共享它，那就是上下文，而不是关系。将这些建模为节点属性，或者干脆删除它们。

**共享服务边被误读为关系。** 共享托管、注册商隐私服务、公司注册代理的注册地址、支付处理器、邮件转发套件：所有这些都产生真实的共享节点，并且当事人之间没有关系。始终询问有多少其他实体触摸那个节点——一个有四百个公司的注册地址是代理的地址。

**实体解析错误，双向。** 将一个人分成三个人（隐藏发现）和将两个人合并成一个（制造它）。合并更危险，因为图看起来像强烈的相互印证：两个集群由你执行的合并连接。记录每次合并的证据并能够取消合并。

**布局通过置信度进行清洗。** 一个点线推断的边被绘制，然后截图，然后在三个步骤后，它成为报告中一个无人能追溯的图表中的线。从数据文件生成报告图形，而不是从手工编辑的图片。

**图作为论据。** 一个布局良好的图在证据之外具有不成比例的说服力。布局算法是美观的；在力导向图中，邻接关系不是一个发现。引用边，而不是图像。

**不完整图上的指标。** 在你通过列举一个角色穷尽地构建的图上计算中心性将使该角色加冕。在报告任何指标旁边注明收集覆盖率。

## 置信度分级

对边进行分级，而不是对图进行分级。

- **确认**——关系由权威原始记录（注册文件、签署的证书、两个端点上的自我声明交叉链接）声明，或者由两个独立收集的来源通过循环报告检查。
- **可能**——一个强来源，或者一个独特的共享选择器足够罕见以至于可以区分（自托管分析 ID、不寻常的重复密码哈希、个人域名），没有矛盾的证据。
- **未确认**——一个共享属性，许多无关实体可能共享，或者仅凭风格或时间上的相关性。用点线绘制，或者根本不绘制。
- **拒绝**——追溯到共享服务、经纪人馈送或巧合。保留拒绝的边在文件中，标记原因；否则下一个分析师会重新添加它们。

路径的强度仅取决于其最弱的边。报告任何链的最小边置信度，而不是平均置信度。

## 示例

案例：三个欺诈域名，表面上无关。节点和边保存在两个 CSV 中，来自最初的透视。

WHOIS 在所有三个域名上都是隐私保护的，因此注册人边不可用——明显的办法是走死胡同。通过 `read-deleted-pages` 检索的存档副本表明，其中两个包含隐私保护前的注册快照，提供了两个 `Person —registered→ Domain` 边，来源和日期，确认。

添加 IP 解析创建了一个连接所有三个以及四十个无关网站的明显中心：共享 CDN 地址。度数使其成为图中中心节点，这是无意义的。它被降级为节点属性，并作为边删除——毛发球随着它消失而消失。

真正的桥梁是一个自托管的分析标识符，出现在两个域名的存档 HTML 中，并在第四个不在范围内的网站上，一个个人作品集携带真实姓名。在确认视图中的介数将该标识符，而不是可见的注册人，放在两个集群之间。时间边显示作品的标识符使用在第三个域名存在之前结束，因此该域名保持不连接——这样说使报告保持诚实。

## 法律和处理说明

一个案例图是针对已识别的人的专用配置文件，它比其中任何单个项目都更敏感——聚合是这种技术的要点，而聚合是数据保护法规审查的要点。第三方节点会快速积累（亲戚、同事、同住者）；在图发送到任何地方之前修剪与目标无关的任何人，并从发布图形中删除他们。将图文件与案例的其他部分使用相同的加密和保留规则存储，如 [../../ETHICS.md](../../ETHICS.md)。
托管图平台意味着将案例上传到第三方——在将主题的选择器粘贴到云转换之前，检查这是否被允许。
