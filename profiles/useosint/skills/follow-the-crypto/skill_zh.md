# 跟踪加密货币

公链是伪匿名，而非匿名。每一笔转账都永久对任何人可见；所缺失的是地址到个人的映射。因此整个游戏在于归因，而归因几乎总是在离岸点发生——即价值通过收集身份文件的服务转换为法币的点。犯罪与离岸点之间的一切都只是你需要跟随的管道。

初学者错误是将聚类启发式的输出视为事实。“这些地址属于同一实体”是一种具有已知失效模式的概率推理，而商业归因标签是专有的猜测，你无法审计。自信地追踪；谨慎地归因。

## 筛选：你持有的是什么？

| 你持有 | 从...开始 | 为什么 |
|---|---|---|
| 地址字符串 | 通过其形状识别链，然后使用区块浏览器 | 格式通常决定链和脚本类型——参见[地址格式表](reference/address-formats.md) |
| 交易哈希 | 探索器的交易视图 | 提供双方信息、手续费、区块时间和任何合约调用 |
| ENS或命名服务名称 | 解析为地址，然后检查*反向*记录 | 正向解析由名称所有者设置；反向由地址所有者设置，是更强的主张 |
| `0x…`地址 | 在每个主要EVM链上检查相同地址 | 一个私钥，一个地址，多个链。目标认为无人关注的链上的活动很常见 |
| 恐怖分子勒索信或诈骗中的支付要求 | 探索器加上诈骗报告聚合器 | 他人可能已经报告，给你受害者数量和首次发现日期 |
| 钱包的屏幕截图 | 手动提取地址并验证校验和 | 屏幕截图可能被错误转录，相似地址会被故意种植 |

## 方法

**1. 确定链和地址类型。** 字符串会告诉你。比特币传统公钥哈希地址以`1`开头；脚本哈希，历史上是多签和包裹的SegWit，以`3`开头；原生SegWit bech32以`bc1q`开头；Taproot以`bc1p`开头。以太坊和每个EVM链使用`0x`加上40个十六进制字符，大小写混合作为EIP-55校验和。完整表格在上述参考文件中。

**2. 在区块浏览器中打开地址并正确阅读。** 余额是最不重要的字段。重要的是：首次出现和最后出现的时间戳（活动寿命）、总收到金额与当前余额（被清空的地址是管道，持有地址是目的地）、交易数量和交易对手方集合。在EVM链上还要阅读内部交易、代币转账标签，以及地址是否有代码——带有字节码的地址是合约，而不是个人的钱包，其行为由该代码定义。

**3. 为链选择正确的心理模型。** UTXO链如比特币没有账户：一笔交易消耗离散的未花费输出并创建新的输出，因此“地址的余额”是一个派生的汇总，价值明显分裂和合并。你通过输出的图追踪*硬币*。账户模型链如以太坊的余额由转账突变，因此你追踪*账户到账户的边*，一笔交易可能引发一系列内部转账和代币运动，这些在顶级视图不会出现。混淆两者是最常见的错误来源。

**4. 聚类，并知道每个启发式方法的价值。**

- **共同输入所有权** 是强大的：如果一个UTXO交易花费多个输入，构建它的任何人必须持有所有这些密钥，因此这些地址共享一个控制器。这是每个比特币聚类引擎的骨干。
- **变更地址识别** 是弱的。启发式方法——未四舍五入的金额输出、脚本类型与输入匹配而其他不匹配的输出、从未见过的地址的输出以及不必要的输入规则——单独都是不可靠的，并在跳转中复合它们的错误。一个错误的变更调用会将整个下游追踪发送给陌生人。
- **地址重复** 免费将活动归因于一个身份，并且在不把自己视为目标的人中很常见。

**5. 找到离岸点。** 交易所为每个客户分配一个唯一的存款地址，然后定期将这些存款扫入集中的热钱包。这次扫入是线索：许多独立的地址定期流入一个大型钱包，是交易所存款结构。到达存款地址是追踪的最有价值的结果，因为交易所持有KYC记录，属于它的人——可通过法律程序由执法部门获取，而不是由你。记录存款地址、金额、时间戳和交易所识别依据，并移交。

**6. 通过模式识别服务和合约交互。** 等额输出在一个交易中有许多参与者是CoinJoin。固定额存款和后来从同一合约提款是Tornado风格的混合池。一笔转账到一个合约后，在不同的链上发生事件是桥接。在两个地址之间按时间表重复的编号转账看起来像工资或订阅，而不是市场操作。剥链——一大笔钱反复花费一小部分并转发剩余部分——是典型的洗钱和提现模式。

## 追踪中断的地方，以及你仍然可以说什么

**CoinJoin** 通过设计中断共同输入所有权：输入属于不同的人。忽略这种设计的简单聚类将无关用户合并为一个巨大的错误集群——这是一个众所周知且严重的失效模式。

**混合池** 通过密码学中断存款-提款链接。存活的是元数据泄露：一个在低交易量时较小的匿名集、存款和提款时间、一笔提款的gas是从也资助了存款的地址支付的，以及提款到已经与他们关联的地址的用户。

**跨链桥接和交换服务** 没有通过密码学中断链接，但确实通过*实践*中断，因为它们将追踪转移到具有不同工具链的另一条链。两链之间的金额和时间相关性通常会重新建立它。即时无账户交换服务是同样的问题，但增加了一个保留自己日志的托管跳转。

**隐私币** 是一个硬停止，而不是减速。环签名、隐身地址和保密金额意味着没有公开的发送者、没有公开的接收者和没有公开的金额可以追踪。直白地说，而不是暗示你可以走得更远。在可选屏蔽的链上，大部分活动是透明的，泄露发生在屏蔽/透明边界。

**污染分析** 在任何这些之后都是建模选择，而不是测量。毒药、理发、FIFO和后进先出在同一数据上给出实质上不同的答案，并且某些司法管辖区的法院对混合资金施加自己的规则。始终说明你使用了哪种模型。“40%被污染”而没有命名模型是毫无意义的。

## 这对你意味着什么

- **地址污染。** 攻击者从与合法对手方首尾字符匹配的地址发送零值或灰尘转账。这些出现在受害者的历史记录中，并将粗心的分析师引向完全无关的地址。始终比较完整字符串。
- **灰尘。** 未经请求的微小金额发送到许多地址，意图被花费并因此合并集群。收到的转账不能证明接收者的意图或关系。
- **探索器标签是第三方主张。** 公共名称标签、自我提交的合约验证和社区提供的实体标签在质量上有所不同，有时只是错误或过时的。标签是一个线索。引用标签人。
- **商业归因是不可审计的。** 链分析供应商的实体标签源于专有的未披露方法，并在法庭上受到质疑。永远不要将供应商标签作为事实真相；将其作为该供应商的评估。
- **合约为从未接触过它的人转移价值。** 一个DEX路由器、一个多签、一个托管钱包或一个NFT市场作为交易对手方出现。它是基础设施，而不是嫌疑人。
- **时间戳是区块时间。** 它们近似于交易被挖掘的时间，而不是人类行动的时间，并且它们不能可靠地说明时区。
- **相同地址，不同链，不同人是有可能的**——但相反是实际风险：假设链不相关，而密钥是相同的。
- **链重组和未确认交易。** 你在mempool中看到的东西可能永远不会确认。引用已确认的交易和区块高度。

## 评估发现

- **确认**——链上事实：这笔交易在这个区块中将这个金额从这个地址转移到那个地址。这些是密码学上可验证的，你应该这样说而不加犹豫。也确认：实体自己发布的地址，在已验证的签名消息或域名上，或在`recon-a-domain-passively`中验证的域名上。
- **可能**——基于共同输入所有权构建的集群，没有CoinJoin模式；通过与多个独立标签匹配的结构行为识别的服务；与社交资料匹配的ENS名称，具有匹配的正向*和*反向记录。
- **未确认**——任何基于变更地址启发式、单个商业标签、未签名的主权声明、仅基于时间相关性或跨越混合事件的集群。

归因到命名个人永远不会是仅链上证据。当离链记录——传票回复、法院文件、签名消息、实体的自我披露——关闭了差距时，它才会被确认。

## 示例

受害者报告支付了勒索要求到`bc1q…`，并提供了交易ID。

探索器显示一个来自受害者的输入和两个输出：0.4137 BTC到一个新的`bc1q`地址和较小的金额到另一个。变更启发式表明未四舍五入的较大输出是支付，较小的输出是受害者的变更——但受害者确认要求的金额是较小的数字，所以启发式在这里是反的。只有因为人类证实了它才避免了死胡同；在文件中记录这一点。

追踪勒索输出：在一天内它与其他十一个输入合并到一个交易中。共同输入所有权意味着十二个都是同一个控制器，并且没有指示CoinJoin的等值结构。合并后的输出转发到一个从数千个无关地址接收并按固定时间表扫出的地址——一个交易所热钱包结构。它之前的地址只从我们的集群接收，是存款地址。

分级：交易事实确认；十二地址集群可能；交易所识别可能，基于结构加上两个独立标签；账户持有者的身份未知，只能通过法律程序获取。以这种方式报告，并将存款地址和时间戳标记给受害者的律师。

## 法律和合规

阅读公共账本不受监管。根据它采取行动可能会受到监管。制裁机构在其指定人员名单上发布特定的数字货币地址——美国OFAC SDN名单将它们作为明确的地址条目——与指定地址交易在许多司法管辖区是严格责任事项。在互动之前检查名单，并且永远不要向目标地址发送“测试交易”：这是互动，它会标记你，并且可能违反规定。

将某人命名为地址的所有者是一项严重的公开指控，具有诽谤风险，并且基础推理是概率性的。批量购买或处理泄露的交易所客户数据会带来数据保护义务，无论它如何到达你；参见`what-leaked-about-you`。在资产追回或犯罪举报的目标下，保留证据链：记录区块高度、交易ID和捕获时间戳，而不是探索器的屏幕截图。
