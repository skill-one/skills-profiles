# 调查任何事

前门。所有后续工作都比应该先进行的思考更快，这就是为什么大多数糟糕的调查不是收集失败——它们是框架失败。你可以用四十种工具对一个名字进行分析，并产生一份对错人的自信报告。这里的工作是决定你要回答什么问题，什么能算作答案，以及什么能证明你错误。

## 核心词汇

在repo中的每个技能中都使用，仅在此处定义。

- **选择器** — 一个可识别的数据点：名字、用户名、电子邮件、电话、域名、IP、钱包、哈希值、车牌、IMO、公司编号。
- **转换** — 将一个选择器转换为新的选择器（电子邮件→漏洞记录→重复使用的用户名→论坛个人资料→真实姓名）。调查就是一系列转换。每个转换也是一个跳转到不同人的机会。

## 第一步 — 授权范围

阅读[../../ETHICS.md](../../ETHICS.md)，然后写下五件事：

1. **主题** — 具体的实体，区别于任何具有相似名字的人。写下你的区分标准（“是公司09xxxxxx的董事J. Okonkwo”，而不是“J. Okonkwo”）。
2. **目标** — 见第二步。
3. **在范围内** — 选择器类型、来源，以及是否允许交互。
4. **超出范围** — 你不会做的事情：登录属于主题的任何东西，联系他们、家人、医疗或宗教数据，以及任何与目标无关的选择器。
5. **司法管辖区** — 谁的法律管辖你、主题和数据。在欧盟/英国，聚合关于活人的零散公共事实是处理个人数据，需要合法依据和最小化。

如果你不能说明是谁授权的以及依据什么，就停止。不是“小心进行”——停止。未经授权的调查不能通过好的报告在后期修复。

**完成时** — 所有五项都写下来，并且你能说出会导致你超出范围的特定行动。

## 第二步 — 构建一个可回答的问题

“了解X”不是一个目标；它没有停止条件，所以它在你感到无聊或找到某个感觉像结果的东西时终止。重写请求，直到它有一个主题、一个它所提供的决策，以及一个可以解决它的条件。

| 模糊 | 可回答 |
|---|---|
| 调查这家公司 | 这个供应商是否有未披露的所有者受到制裁，并且它是否从发票上的地址运营？ |
| 这个账户是谁 | `@handle`的操作者与已离职的命名人员是否是同一个人，或者不是？ |
| 调查这个域名 | `example.com`是否由与钓鱼域名相同的一方运营，在共享的基础设施上？ |

然后写下否定：什么发现意味着“不”。如果什么都不能，那么问题是无法证伪的，无论你看到什么都会确认它。

**完成时** — 目标是一句话，并且你已经写下了“否定”答案会是什么样子。

## 第三步 — 在收集之前编写收集计划

无目的的转换看起来是有成效的，因为每个转换都会产生一些东西。收集计划是问题的列表，每个问题都映射到最有可能解决它的来源，按成本和侵入性排序——这样你会在进入一个有趣的分支三小时后注意到它什么也没回答。

对于每个问题：回答它的指标、产生它的来源或技能、是否被动，以及如果它返回为空你会做什么。始终以被动优先：在接触主题之前，耗尽档案、注册机构和日志。计划会随着你的学习而修订——重点是偏差会变得可见。

**完成时** — 每个目标问题都有一个命名的来源或技能，以及第一/备用顺序。

## 第四步 — 根据起始选择器进行路由

输入工作流技能的名称。

| 你有 | 运行 |
|---|---|
| 一个人的名字或真实身份 | `find-anyone` |
| 一个公司、品牌或发票实体 | `x-ray-a-company` |
| 一个域名、网站或IP | `recon-a-domain-passively` |
| 一个用户名或用户名 | `hunt-a-handle` |
| 一个电子邮件地址 | `what-an-email-reveals` |
| 一个电话号码 | `whose-number-is-this` |
| 一个照片或视频用于定位或验证 | `where-was-this-taken` |
| 你已经归因的一个社交资料 | `pattern-of-life-from-socials` |

没有明确的起始点？从既是**唯一且索引**的选择器开始——电子邮件和域名比名字和用户名更占优势，因为名字会冲突，用户名会被陌生人占用。

技术技能在你描述你在做什么时会自行加载。在触摸任何受主题控制的东西之前，运行`investigate-without-getting-made`。保持案例从第一个转换开始在一个图中：`graph-the-network`。

**完成时** — 路由的工作流已经运行，并且其发现已与来源一起记录。

## 第五步 — 在收集时而不是之后对来源进行评级

使用海军部（北约式）方案：每个项目都有一个**字母表示来源**和一个**数字表示信息**，独立评级。

- 字母A–F：来源的记录和访问权限。A = 可靠的历史，没有对真实性的怀疑；F = 无法判断。
- 数字1–6：内容是否被其他独立来源确认，以及它本身是否合乎逻辑。1 = 在其他地方确认；6 = 无法判断。

独立性很重要：一家公司注册文件是B2，一份管理良好的报纸报告该文件是B2，而一个匿名论坛帖子重复该报纸是D3——不是新的证实。评级的是你实际触摸的*来源*，而不是它声称拥有的来源。完整网格、示例和常见的错误评级：
[reference/source-grading.md](reference/source-grading.md)。

**完成时** — 每个保留的发现都带有两个字符的评级。

## 第六步 — 对每个假设进行测试

竞争假设分析（ACH）的存在是因为调查的自然模式——选择最可能的故事，寻找支持——总是成功的。支持任何可能的故事都很容易找到。

列出每个假设，包括无聊的假设（“是同名但不同的人”，“账户被出售”，“共享IP是共享主机”）。
构建一个证据与假设的矩阵，并对每个单元格只问证据是否与该假设*一致*。然后按列工作：假设中不一致最少的那个获胜，而不是支持最多的那个。**与每个假设一致的证据没有诊断价值**——主题有一个LinkedIn并不能区分任何东西。一小部分诊断项目比一百个一致的更有价值。工作表和填充的示例：[reference/ach-worksheet.md](reference/ach-worksheet.md)。

**完成时** — 你列出了至少一个你不想的假设，并记录了什么证据会推翻你最喜欢的假设。

## 哪里会出错

**确认偏误，OSINT版。** 你被告知一个人在物流行业工作。你找到一个物流个人资料并停止询问是否是同名但不同的人。迹象是，一旦你找到候选人，你的区分标准就会消失——你基于它们来*寻找*，然后停止将它们应用于*测试*。修复：在搜索之前，写下真实主题必须具有的属性和它们不能具有的属性；检查每个候选人与两者都进行核对。拒绝是发现，并应包含在报告中。

**循环报告。** 三个来源同意，所以你将其评级为确认。三个都复制了一个博客帖子，或者都从同一个聚合器或同一个泄露数据集中获取。这是自信错误归因的最常见原因，除非你寻找它，否则它是看不见的。对于每个相互印证的来源，找到它的起源：按顺序检查发布日期，寻找相同的措辞或一个复制的打字错误，并检查“独立”的人员搜索网站是否转售相同的经纪人信息——见`dig-through-data-brokers`。独立意味着*不同的收集*，而不是不同的网站。

**过时的数据被呈现为当前。** 注册机构、WHOIS和经纪人记录携带它们被捕获的日期，而不是今天的真相。在每项事实旁边记录观察日期；通过`read-deleted-pages`存档页面。

**选择器漂移。** 每个转换都有改变人的风险。五个转换的链，每个转换90%可能是一个抛硬币。重新锚定：在每次转换后，说明哪个确认的选择器将新的选择器与主题联系起来。

**工具输出作为证据。** 一个统计员的成绩单、一个漏洞聚合器的匹配、一个面部搜索分数——这些都是线索。工具没有验证身份；它匹配了一个字符串或一个向量。

## 置信评级

除非技术技能另有说明，否则适用于repo。

- **确认** — 两个或多个真正独立的来源（不同的收集，不是不同的网站），或者一个权威的原始记录，如签署的注册文件，加上没有矛盾。
- **可能** — 一个强大的来源，或者几个弱来源通过了循环报告检查，并且替代假设已被测试且较弱。
- **未确认** — 一个未确认的线索。在报告中说明；不要因为后续文本依赖于它而悄悄推广它。
- **拒绝** — 被否认。记录它和原因。

## 停止时

当目标问题回答到决策所需的置信度，或者当你可以证明可用的开源信息无法回答它，并说明什么会（记录请求、传票、采访）时停止。 “我们无法建立X，在检查A、B和C之后”是一个可交付成果，并且通常是诚实的。当您跨越范围边界时也停止——这是一个重新授权事件，而不是在流程中做出的判断。

**完成时** — 目标已回答或记录为不可回答，并且`write-the-intel-brief`已运行。

## 示例

目标：发票上的供应商`Nordvale Trading`是否受被禁止实体的前董事控制？区分标准：董事出生月份/年份。

`x-ray-a-company`返回一个注册记录，其中董事“A. Kestrel”出生月份/年份匹配，地址是一个邮件转发套件。两个人员搜索网站和一个商业名录网站都显示A. Kestrel的相同家庭地址——明显的相互印证，直到每个都被追溯到，并且三个都携带来自一个经纪人信息流的相同街道名称拼写错误。循环；评级为D3并放弃。

竞争假设：（1）同一个人，（2）不同的A. Kestrel，（3）用作提名的名字。诊断项目：被禁止实体的文件和Nordvale的列表显示同一个不寻常的会计公司，并且发票页脚中的域与被禁止实体的旧网站共享注册电子邮件（`who-owns-this-domain`）。这与（2）不一致，与（1）和（3）一致。报告为可能，提名的假设被标记为未测试，并命名了差距：在该司法管辖区，受益所有权没有披露。

## 转换

每个工作流在运行时都会为`graph-the-network`，并在结束时为`write-the-intel-brief`。选择器到技能路由是第四步；每个技术技能都列出了自己的转换。

## 法律注意事项

公开可用不是许可。数据保护法适用于公共个人数据的聚合，并且聚合比任何部分更敏感。服务条款管理自动化收集，即使数据是公开的，并且抓取争议取决于授权和合同，而不是页面是否可见。未经书面授权，切勿验证、探测或向主题所属的系统发送流量。
