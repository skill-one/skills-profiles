# 动画设计技能

## 何时应用

使用此技能的情况：
- 创建 UI 动画（按钮、卡片、模态框、页面过渡）
- 设计微交互和反馈动画
- 构建加载、成功或错误状态
- 动画化插图或装饰元素
- 规划滚动触发或基于进度的动画
- 建立品牌运动身份
- 编排多元素序列

**决策树：**
1. 它是否具有功能性目的（反馈、指导）？ → 响应性时间规则
2. 它是否表达品牌个性？ → 运动个性原型
3. 它是否讲述故事或引导注意力？ → 迪士尼原则 + 编排
4. 这是一个复杂的包含多元素的场景？ → 1/3 规则 + 交错模式

---

## 快速参考：8 步检查清单

在创建任何动画之前：

1. **情感目标？** — 快乐、平静、紧迫、优雅
2. **运动个性？** — 活泼、高端、企业、活力
3. **主要属性？** — 位置、缩放、旋转、不透明度
4. **持续时间？** — 见下表持续时间
5. **缓动类型？** — 进入=减速，退出=加速
6. **主角元素？** — 应用布景原则
7. **次要和背景层？** — 增加丰富性
8. **1/3 规则？** — 运动距离、同时运动的元素

---

## 三大支柱（关键）

每个动画在做出任何技术决定之前都必须满足三大支柱：

| 柱石 | 问题 | 驱动 |
|------|------|------|
| **情感意图** | 观众应该感受到什么？ | 缓动、时间、振幅 |
| **视觉叙事** | 微故事是什么？ | 设置 → 动作 → 解决 |
| **运动工艺** | 我们如何使其看起来可信？ | 物理、次要运动、路径 |

**三大运动层**（平面动画=缺少层）：
- **主要**：观众跟随的主要动作
- **次要**：支持丰富性（阴影、图标移动）
- **背景**：背景生活（渐变、微妙脉冲）

> 深入研究：[director/core-philosophy.md](director/core-philosophy.md)

## 运动个性

每个项目选择一个原型。始终如一地应用。

| 原型 | 持续时间 | 缓动 | 超调 | 关键词 |
|------|----------|------|------|------|
| **活泼** | 150-300ms | ease-out-back | 10-20% | 有趣、奇幻、弹跳、可爱 |
| **高端** | 350-600ms | cubic-bezier(0.4,0,0.2,1) | 0% | 优雅、简约、奢华、精致 |
| **企业** | 200-400ms | cubic-bezier(0.2,0,0,1) | 0-3% | 干净、专业、商业、仪表盘 |
| **活力** | 100-250ms | ease-out-expo | 15-30% | 动态、活力、大胆、刺激 |

**默认**：UI 使用企业风格，插图使用活泼风格。

**品牌运动身份** — 定义三个常数：
1. **标志性缓动**：80% 的动画使用一条曲线
2. **持续时间调色板**：3 个持续时间（快速 / 标准 / 慢）
3. **进入模式**：一种一致的进入风格

> 深入研究：[director/motion-personality.md](director/motion-personality.md)

## 属性选择

| 效果目标 | 主要属性 | 次要属性 |
|----------|----------|----------|
| 进入/退出 | 位置 | 不透明度、缩放 |
| 强调/注意力 | 缩放 | 旋转（微妙）、不透明度脉冲 |
| 状态变化 | 不透明度、颜色 | 缩放（按压反馈） |
| 方向/流程 | 位置 | 旋转（跟随路径） |
| 深度/3D 感觉 | 缩放 + 阴影 | 位置（视差） |
| 加载/进度 | 旋转（旋转器） | 缩放、不透明度脉冲 |
| 成功 | 缩放（弹出） | 颜色、旋转（勾选绘制） |
| 错误/警告 | 位置（摇晃） | 颜色、旋转（摇摆） |

**简单阈值**：使用完成所需的最少属性。一个 = 直接。两个 = 精致。三个+ = 可能过于令人眼花缭乱。

> 深入研究：[reference/property-selection.md](reference/property-selection.md)

## 持续时间表

| 元素类型 | 持续时间 | 理由 |
|----------|----------|------|
| 提示 / 微反馈 | 80-120ms | 必须感觉即时 |
| 按钮按压 / 切换 | 120-180ms | 响应性反馈 |
| 图标过渡 | 150-250ms | 清晰的状态变化 |
| 卡片进入 / 退出 | 200-350ms | 空间感知 |
| 模态框 / 对话框 | 300-400ms | 注意力转移 |
| 页面过渡 | 400-600ms | 上下文切换 |
| 戏剧性揭示 | 600-1200ms | 逐步构建 |

**距离按比例缩放持续时间**：100px = 基础。200px = 1.3x。400px = 1.6x。

**进入 > 退出**：进入比退出长 30-50%。用户更关心出现的内容。

**交互反馈**：
- 悬停：<100ms
- 按下：<150ms
- 释放/稳定：200-300ms
- 错误摇晃：300-400ms（2-3 次振荡）

> 深入研究：[reference/timing-easing-tables.md](reference/timing-easing-tables.md)

## 缓动选择

**方向规则**：
- **进入** → 减速（快速开始，柔和着陆）：ease-out 家族
- **退出** → 加速（柔和开始，快速离开）：ease-in 家族
- **屏幕上** → 两端平滑：ease-in-out 家族
- **循环背景** → 无缝：基于正弦的 ease-in-out

**行业标准**：

| 标准 | 立方贝塞尔 | 用于 |
|------|------------|------|
| Material Design 3 | (0.2, 0, 0, 1) | 屏幕默认 |
| MD3 强调 | (0.05, 0.7, 0.1, 1) | 进入、注意力 |
| MD3 加速 | (0.3, 0, 1, 1) | 退出、关闭 |
| Apple HIG | (0.25, 0.1, 0.25, 1) | 标准 iOS |
| Snappy UI | (0.2, 0, 0, 1) | 快速、果断 |
| 轻柔浮动 | (0.4, 0, 0.2, 1) | 背景、环境 |
| 弹跳稳定 | (0.175, 0.885, 0.32, 1.275) | 超调、活泼 |

**基于 Material 的缓动**：

| Material | 持续时间缩放 | 超调 |
|----------|---------------|------|
| 刚性（金属、石头） | 1.2x | 0% |
| 弹性（橡胶、凝胶） | 0.8x | 15-25% |
| 流体（水、油漆） | 1.5x | 5% |
| 纸张（卡片、纸张） | 1.0x | 3-5% |
| 气体（烟雾、雾气） | 2.0x | 0% |
| 玻璃（易碎） | 0.9x | 0% |

> 深入研究：[reference/timing-easing-tables.md](reference/timing-easing-tables.md)

## 常见模式

### 按钮按压（活泼）
1. **预期**：缩放到 0.97（50ms，ease-out）
2. **挤压**：缩放到 [1.04, 0.96]（100ms，ease-in）
3. **跟随**：超调到 1.02，稳定到 1.0（弹簧，200ms）
4. **次要**：阴影在按压时缩小，图标向下移动 2px
5. **总计**：~150ms 按压 + 200ms 稳定

### 卡片进入（高端）
1. **开始**：目标下方 20px，不透明度 0
2. **路径**：轻微曲线（中间点 X 偏移 10px）
3. **缓动**：ease-out-cubic 减速
4. **跟随**：阴影在卡片到达后 50ms 出现
5. **次要**：内容在卡片落地后 100ms 淡入
6. **布景**：其他卡片变暗至 80%

### 成功状态（活泼）
1. **主要**：带有 ease-out-back 的缩放弹出
2. **次要**：勾选绘制
3. **背景**：细微粒子爆发
4. **颜色**：绿色填充
5. **总计**：300-400ms

### 错误摇晃（企业）
1. **主要**：位置水平振荡 2-3 次，±10-15px
2. **缓动**：ease-in-out 用于尖锐停止
3. **颜色**：红色色调
4. **总计**：300-400ms
5. **无超调**：错误感觉坚定

> 更多模式：[patterns/entrance-exit.md](patterns/entrance-exit.md) | [patterns/state-feedback.md](patterns/state-feedback.md)

## 编排要点

**协调进入**：
- 领先主角 — 主要元素第一个或最突出地进入
- 空间一致性 — 所有元素从同一方向进入
- 反向运动 — 主角向右移动 → 环境向左移动 20-30% 速度

**1/3 规则（距离）**：没有运动超过 1/3 屏幕而无需关键帧更改。

**1/3 规则（元素）**：3 个以上元素时，同时运动的元素不超过 1/3。

**交错预算**：

| 模式 | 延迟 | 总预算 | 用例 |
|------|------|--------|------|
| 微级级联 | 20-40ms | <200ms | 列表项、网格单元 |
| 标准 | 50-100ms | <400ms | 卡片、面板、导航 |
| 戏剧性 | 100-200ms | <600ms | 主角部分 |
| 波浪 | 30-60ms | <500ms | 数据可视化 |

**关键**：总交错必须保持在 500ms 以下。

## 情感到运动的映射

| 情感 | 特性 | 路径 | 缓动 | 持续时间 |
|------|------|------|------|----------|
| 快乐 | 弹跳、弧线 | 弯曲、向上 | ease-out-back | 200-400ms |
| 平静 | 平滑、流动 | 温和曲线 | sine ease-in-out | 500-1000ms |
| 紧迫 | 尖锐、快速 | 直线 | ease-out | 100-200ms |
| 悲伤 | 缓慢、向下 | 下垂曲线 | cubic ease-in-out | 600-1200ms |
| 惊讶 | 突然、扩展 | 径向向外 | ease-out-expo | 150-300ms |
| 优雅 | 缓慢、控制 | 长弧线 | (0.4,0,0.2,1) | 400-700ms |
| 活泼 | 弹跳、不规则 | 弧线、波浪线 | ease-out-back | 200-350ms |

**路径作为语言**：角度 = 紧张。曲线 = 友好。螺旋 = 奇幻。对角线 = 目的。垂直 = 增长/重量。水平 = 进展。

> 深入研究：[director/emotion-mapping.md](director/emotion-mapping.md)

## 质量规则

### 关键 — 永远不要违反
1. **空间运动永远不要线性** — 始终使用缓动曲线（仅用于旋转器、进度条）
2. **重要状态变化永远不要仅使用不透明度** — 结合位置或缩放
3. **永远不要超过 1/3 屏幕** 而没有中间关键帧
4. **始终三个运动层** — 主要 + 次要 + 背景

### 高 — 强烈遵循
1. 持续时间与元素类型匹配（见表格）
2. 使用方向性缓动（进入 ease-out，退出 ease-in）
3. 应用迪士尼原则（尤其是预期、跟随）
4. 保持场景中的一致个性

> 完整清单：[reference/quality-checklist.md](reference/quality-checklist.md)

## 快速参考：故障排除

| 问题 | 可能原因 | 修复 |
|------|----------|------|
| 看起来像机器人 | 线性缓动或没有弧线 | 添加缓动曲线 + 弧形路径 |
| 感觉太慢 | 持续时间过长于元素类型 | 检查持续时间表，使用 ease-out |
| 感觉廉价/平面 | 缺少次要 + 背景 | 添加阴影运动 + 背景生活 |
| 太分散 | 移动的元素太多 | 应用 1/3 规则，减少振幅 |
| 没有个性 | 每处使用通用缓动 | 一致地应用个性原型 |
