# 网络研究技能

## 研究流程

### 第一步：创建并保存研究计划

在分配给子代理之前，你必须：

1. **创建研究文件夹** - 将所有研究文件组织在当前工作目录相关的专用文件夹中：
   ```
   mkdir research_[主题名]
   ```
   这有助于保持文件的组织性，并防止在工作目录中产生杂乱。

2. **分析研究问题** - 将其分解为明确、不重叠的子主题

3. **编写研究计划文件** - 使用 `write_file` 工具创建 `research_[主题名]/research_plan.md`，其中包含：
   - 主要研究问题
   - 2-5 个具体的研究子主题
   - 每个子主题的预期信息
   - 如何综合结果

**规划指南：**
- **简单事实查找**：1-2 个子主题
- **比较分析**：每个比较元素 1 个子主题（最多 3 个）
- **复杂调查**：3-5 个子主题

### 第二步：分配给研究子代理

对于你的计划中的每个子主题：

1. **使用 `task` 工具** 创建一个研究子代理，包含：
   - 清晰、具体的研究问题（不要使用缩写）
   - 指令将研究结果写入文件：`research_[主题名]/findings_[子主题].md`
   - 预算：最多 3-5 次网络搜索

2. **最多并行运行 3 个子代理** 以进行高效研究

**子代理指令模板：**
```
研究 [具体主题]。使用 web_search 工具收集信息。
完成研究后，使用 write_file 将你的研究结果保存到 research_[主题名]/findings_[子主题].md。
包括关键事实、相关引言和来源 URL。
最多使用 3-5 次网络搜索。
```

### 第三步：综合研究结果

所有子代理完成后：

1. **查看本地保存的发现文件**：
   - 首先运行 `list_files research_[主题名]` 查看创建了哪些文件
   - 然后使用 `read_file` 并提供 **文件路径**（例如，`research_[主题名]/findings_*.md`）
   - **重要**：仅对本地文件使用 `read_file`，不要对 URL 使用

2. **综合信息** - 创建一个全面答复，包括：
   - 直接回答原始问题
   - 整合所有子主题的见解
   - 使用 URL 引用具体来源（来自发现文件）
   - 识别任何差距或局限性

3. **编写最终报告**（可选）- 如果需要，使用 `write_file` 创建 `research_[主题名]/research_report.md`

**注意**：如果你需要从 URL 获取更多信息，请使用 `fetch_url` 工具，而不是 `read_file`。

## 最佳实践

- **在分配前规划** - 总是先编写 research_plan.md
- **清晰的子主题** - 确保每个子代理具有明确、不重叠的范围
- **基于文件的通信** - 让子代理将研究结果保存到文件，而不是直接返回
- **系统化综合** - 在创建最终答复之前，读取所有发现文件
- **适当停止** - 不要过度研究；每个子主题 3-5 次搜索通常足够
