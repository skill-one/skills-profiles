# 社交媒体内容技能

## 先研究（必填）

在撰写任何社交媒体内容之前，你必须进行以下研究：

1. 使用 `task` 工具并设置 `subagent_type: "researcher"`
2. 在描述中指定主题和保存位置：

```
task(
    subagent_type="researcher",
    description="研究 [主题]. 保存结果到 research/[slug].md"
)
```

示例：
```
task(
    subagent_type="researcher",
    description="研究2025年可再生能源趋势。保存结果到 research/renewable-energy.md"
)
```

3. 研究完成后，在撰写前阅读研究结果文件

## 输出结构（必填）

每个社交媒体帖子必须同时包含内容和图片：

**领英帖子：**
```
linkedin/
└── <slug>/
    ├── post.md        # 帖子内容
    └── image.png      # 必须生成：视觉图像
```

**推特/X串文：**
```
tweets/
└── <slug>/
    ├── thread.md      # 串文内容
    └── image.png      # 必须生成：视觉图像
```

示例：关于“提示工程”的领英帖子 → `linkedin/prompt-engineering/`

你必须完成以下步骤：
1. 将内容写入正确路径
2. 使用 `generate_image` 生成图片并保存到帖子旁边

没有图片的社交媒体帖子是不完整的。

## 平台规范

### 领英

**格式：**
- 1300字符限制（约210字符后显示更多）
- 第一行至关重要 - 必须吸引人
- 使用换行符提高可读性
- 结尾使用3-5个标签

**语气：**
- 专业但个人化
- 分享见解和学习
- 提问以促进互动
- 使用“我”分享经验

**结构：**
```
[钩子 - 1句引人入胜的话]

[空行]

[背景 - 为什么这很重要]

[空行]

[主要见解 - 2-3段简短段落]

[空行]

[号召行动或问题]

#标签1 #标签2 #标签3
```

### 推特/X

**格式：**
- 每条推文280字符限制
- 使用串文表达长内容（使用1/🧵格式）
- 每条推文不超过2个标签

**串文结构：**
```
1/🧵 [钩子 - 主要见解]

2/ [支持点1]

3/ [支持点2]

4/ [示例或证据]

5/ [结论+号召行动]
```

## 图片生成

每个社交媒体帖子都需要一个吸引眼球的图片。使用 `generate_social_image` 工具：

```
generate_social_image(prompt="详细描述...", platform="linkedin", slug="你的帖子slug")
```

该工具将图片保存到 `<平台>/<slug>/image.png`。

### 社交图片最佳实践

社交图片需要在拥挤的信息流中在小尺寸下也能清晰显示：
- **大胆简洁的构图** - 一个明确的焦点
- **高对比度** - 在滚动时突出显示
- **图片中不包含文字** - 字太小无法阅读，平台会自行添加
- **方形或4:5比例** - 适用于所有平台

### 高效撰写提示

包含以下元素：

1. **单一焦点**：一个明确的主题，不是杂乱的场景
2. **大胆风格**：鲜艳的颜色、强烈的形状、高对比度
3. **简单背景**：纯色、渐变或微妙纹理
4. **情绪/能量**：匹配帖子语气（鼓舞人心、紧迫、深思熟虑）

### 示例提示

**用于见解/技巧帖子：**
```
一个发光的灯泡悬浮在深紫色渐变背景中，灯泡由相互连接的金色几何线条构成，向外散发柔和的光线。简约、引人注目、高对比度。方形构图。
```

**用于公告/新闻：**
```
由彩色几何形状组成的抽象火箭船向上发射，留下粒子尾迹。明亮珊瑚色和青色方案，背景为干净白色。充满活力、庆祝的语气。大胆扁平插画风格。
```

**用于引人深思的内容：**
```
两个重叠的半透明圆圈，一个蓝色一个橙色，在中心形成发光的交集。代表合作或想法的交集。深炭灰背景，柔和的空灵光晕。简约而引人深思。
```

## 内容类型

### 公告帖子
- 首先发布新闻
- 解释影响
- 包含链接或下一步

### 见解帖子
- 分享一个具体的学习
- 简要说明背景
- 使其可操作

### 提问帖子
- 提出一个真实的问题
- 首先给出你的看法
- 保持聚焦于一个主题
