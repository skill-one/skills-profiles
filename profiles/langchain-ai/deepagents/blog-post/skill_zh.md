# 博客写作技巧

## 先进行调研（必选）

在撰写任何博客文章之前，你必须分配调研任务：

1. 使用 `task` 工具并设置 `subagent_type: "researcher"`
2. 在描述中，指定主题和保存位置：

```
task(
    subagent_type="researcher",
    description="调研 [主题]. 将调研结果保存到 research/[slug].md"
)
```

示例：
```
task(
    subagent_type="researcher",
    description="调研2025年AI代理的当前状态。将调研结果保存到 research/ai-agents-2025.md"
)
```

3. 调研完成后，在撰写前阅读调研结果文件

## 输出结构（必选）

每个博客文章必须同时包含文章内容和封面图片：

```
blogs/
└── <slug>/
    ├── post.md        # 博客文章内容
    └── hero.png       # 必须生成：封面图片
```

示例：关于"2025年AI代理"的文章 → `blogs/ai-agents-2025/`

**你必须完成以下步骤：**
1. 将文章内容写入 `blogs/<slug>/post.md`
2. 使用 `generate_image` 生成封面图片并保存到 `blogs/<slug>/hero.png`

**没有封面图片的博客文章不完整。**

## 博客文章结构

每个博客文章应遵循以下结构：

### 1. 开头（钩子）
- 以引人入胜的问题、统计数据或陈述开头
- 让读者想要继续阅读
- 控制在2-3句话

### 2. 背景（问题）
- 解释为什么这个主题重要
- 描述问题或机会
- 与读者的经验建立联系

### 3. 主要内容（解决方案）
- 分为3-5个主要部分，使用H2标题
- 每个部分涵盖一个要点
- 在需要时包含代码示例、图表或截图
- 使用项目符号表示列表

### 4. 实际应用
- 展示如何应用这些概念
- 如适用，提供分步说明
- 提供代码片段或模板

### 5. 结论和行动号召
- 总结关键要点（最多3个要点）
- 以明确的行动号召结束
- 链接到相关资源

## 封面图片生成

撰写文章后，使用 `generate_cover` 工具生成封面图片：

```
generate_cover(prompt="图片的详细描述...", slug="你的博客slug")
```

该工具将图片保存到 `blogs/<slug>/hero.png`。

### 高效撰写图片提示

按照以下元素构建提示：

1. **主题**：主要焦点是什么？具体且具体。
2. **风格**：艺术方向（极简主义、等距、扁平化设计、3D渲染、水彩等）
3. **构图**：元素如何排列（居中、三分法、对称）
4. **调色板**：特定颜色或氛围（暖土色调、冷蓝紫色、高对比度）
5. **光照/氛围**：柔和漫射光、戏剧性阴影、黄金时刻、霓虹光
6. **技术细节**：宽高比考虑、用于文本叠加的负空间

### 示例提示

**对于技术博客文章：**
```
等距3D插图，展示代表AI代理的相互连接的发光立方体，每个立方体都有微妙的电路图案。立方体通过发光的数据流连接。深海军蓝背景(#0a192f)，带有电蓝色(#64ffda)和柔和紫色(#c792ea)的点缀。极简风格，顶部有大量负空间用于标题。专业技术美学。
```

**对于教程/指南：**
```
干净的扁平化插图，展示双手在键盘上打字，抽象的代码符号向上漂浮，变成灯泡和齿轮。从柔和珊瑚到浅桃色的渐变背景。友好、亲切的风格。居中构图，留有文本叠加空间。
```

**对于思想领导力：**
```
人类剪影轮廓与几何神经网络图案的抽象可视化。分割构图 - 左侧有机水彩纹理过渡到右侧干净的矢量线。柔和的灰绿色和暖陶土色调。沉思、前瞻性的氛围。
```

## SEO注意事项

- 在标题和第一段中包含主要关键词
- 自然地在全文中3-5次使用关键词
- 标题控制在60个字符以内
- 撰写元描述（150-160个字符）

## 质量检查清单

完成前：
- [ ] 文章保存到 `blogs/<slug>/post.md`
- [ ] 封面图片生成在 `blogs/<slug>/hero.png`
- [ ] 开头在2句话内吸引注意力
- [ ] 每个部分都有明确目的
- [ ] 结论总结关键要点
- [ ] 行动号召告诉读者下一步该做什么
