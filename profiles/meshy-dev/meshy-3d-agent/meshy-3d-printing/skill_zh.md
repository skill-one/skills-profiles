# Meshy 3D打印

使用Meshy CLI **0.3.0** 将所需的打印文件以预期尺寸交付，根据需要提供分析/修复结果，并在请求时提供切片器交接。这项技能是自包含的。常规数字资产属于meshy-3d-generation。

| 需求 | 参考 |
|---|---|
| CLI运行器、凭证或输出位置 | [设置](references/setup.md) |
| 本地准备、云端生成或产品工作流程 | [打印配方](references/printing.md) |
| 成本、等待、预览、交付或查找先前模型 | [交付](references/delivery.md) |
| 失败或不确定的操作 | [故障排除](references/troubleshooting.md) |

根据需要阅读相关部分。配方说明了有效命令；仅选择用户输出所需的阶段。

## 选择本地或云端工作

| 请求 | 路径 |
|---|---|
| 缩放、定向或接地现有OBJ | 本地 `mesh prepare-print`；无需认证或余额 |
| 打开现有STL或3MF | 本地 `slicer detect` 和 `slicer open`；无需认证或余额 |
| 从文本或照片生成白色模型 | 无需纹理生成几何形状；根据需要进行分析/修复；准备文件 |
| 多色模型 | 生成/重用几何形状；根据需要进行分析/修复；纹理；多色打印 |
| 创意实验室灯、钥匙扣、冰箱磁铁或人物模板 | 原型 → 审查 → 构建 → 选择产品资产 |

小雕像本身并不需要创意实验室。根据预期产品推断路径；仅在缺少的选择实质性改变结果时询问尺寸、颜色或样式。对于现有模型，区分本地准备和云端可打印性分析；本地尺寸检查不能确定完全可打印性。

## 云端授权

使用设置自动解析运行器（兼容 `meshy` 或 `npm exec --yes --package=meshy-cli@0.3.0 -- meshy …`）。仅限本地工作在运行器设置时停止。云端工作重用验证的会话。如果需要登录，请保持 `auth login --device` 运行，在**注释/进度中显示其URL和用户代码，而不是最终答案**，并等待本回合中的相同工具会话。退出后，验证 `auth status` 并继续打印作业。不要在聊天中询问“完成”消息或凭证；设置有主机等待程序。

## 打印特定约束

- 修复会改变几何形状并丢弃纹理。使用修复后的几何形状进行下游处理，并在多色输出前重新纹理化。在功能部件、薄特征或其他要求使其相关时使用分析；其报告不建立材料适用性。
- 准备一个Y向上的OBJ作为新Z向上的文件，在请求的高度、居中和接地。不要重复变换或将其应用于STL、3MF或浮雕产品输出。多色3MF无需OBJ转换。产品ZIP和可选的灯底座在打印配方中有不同的处理方式。
- API、下载和几何操作使用CLI。本地输入有50 MiB限制。业务命令使用 `--output-schema v1 --format json --no-update-check`；写入包含解析的 `--workspace WORKSPACE`。读取返回的路径和ID，而不是猜测。
- 使用 `create --async` 一次提交云端任务，保留其资源和谱系，并在同一任务上 `wait`。等待期间保持回合活跃。未知的提交和中断的下载是恢复情况，而不是再次生成的权限。
- 在批准的范围内和预算内工作；在花费前提出额外的付费阶段。交付描述了适用的估算。本地准备和可打印性分析是免费的。

## 完成交接

显示可用的渲染预览，并交付文件路径、尺寸、分析/修复状态和报告费用。仅在请求或已授权时启动检测到的切片器；`launch_requested` 并不证明成功导入或启动物理打印机。如果没有合适的切片器安装，仍然交付文件。解释相关的剩余检查，如支撑和壁厚，而不要将未测试的模型描述为可保证打印。
