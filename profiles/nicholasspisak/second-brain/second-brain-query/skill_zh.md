# 第二大脑 — 查询

通过搜索和整合维基中的知识来回答问题。

## 搜索策略

### 1. 从索引开始

阅读 `wiki/index.md` 以识别相关页面。扫描所有分类部分（来源、实体、概念、综合）中的条目，查找与问题相关的条目。

### 2. 使用 qmd 处理大型维基

如果安装了 `qmd`（使用 `command -v qmd` 检查），请使用它进行搜索：

```bash
qmd search "查询词" --path wiki/
```

当维基超过约 100 页时，扫描索引会变得低效，此时此方法尤其有用。

### 3. 阅读相关页面

阅读由索引或搜索识别的维基页面。遵循 `[[维基链接]]` 以从链接页面中拉取相关背景信息。阅读足够多的页面以提供全面的答案，但不要阅读整个维基。

### 4. 如有需要，检查原始来源

如果维基页面未能完全回答问题，请检查 `wiki/sources/` 中的相关来源摘要以获取更多详细信息。仅在最后手段时才访问 `raw/` 中的文件。

## 整合答案

### 格式

将答案格式与问题匹配：
- **事实性问题** → 直接回答并附上引用
- **比较** → 表格或结构化比较
- **探索** → 带有链接概念的叙述
- **列表/目录** → 带有简短描述的编号列表

### 引用

始终使用 `[[维基链接]]` 语法引用维基页面。示例：

> 根据 [[来源 - 文章标题]]，关键发现是 X。这与 [[概念名称]] 中描述的更广泛模式相联系，而 [[实体名称]] 也对此进行了探索。

### 提供保存有价值答案的选项

如果答案生成了一些值得保留的内容——比较、分析、新联系或综合——请提供保存选项：

> "这个比较可能对你的维基很有用。要我将其保存为综合页面吗？"

如果用户同意：
1. 在 `wiki/synthesis/` 中创建一个新页面，并添加正确的 frontmatter
2. 在 `wiki/index.md` 中添加一个条目到综合部分
3. 追加到 `wiki/log.md`：`## [YYYY-MM-DD] 查询 | 问题摘要`

## 规范

- **首先搜索维基。** 只有当维基没有答案时，才去原始来源。
- **引用你的来源。** 每个事实性声明都应该链接到它来自的维基页面。
- **有价值的答案会累积。** 鼓励将好的分析保存回维基。
- 使用 `[[维基链接]]` 进行所有内部引用。永远不要使用原始文件路径。

## 相关技能

- `/second-brain-ingest` — 将新来源处理成维基页面
- `/second-brain-lint` — 检查维基是否存在问题
