# scroll-world

生成一个着陆页，其中**滚动驱动相机**：它从场景外部潜入其内部，然后飞出并进入下一个场景，持续进行，没有任何可见的剪辑。视觉效果是人工智能生成的——静止图像通过Higgsfield（或Codex）生成，视频链通过**Monid by default**（按剪辑付费的Seedance 2.0；Higgsfield信用作为备用）——页面只是根据滚动位置刮擦预渲染视频。这是苹果滚动产品页面背后的技术——相机真正移动，滚动只驱动时间。

**您将生成的内容**：N个场景静止图像 → N个“潜入”相机剪辑 → N-1个“连接器”剪辑，无缝连接连续场景 → 一个可移植的刮擦引擎，将整个链作为一个飞行播放。

**使或破坏它的一个规则**：接缝必须*帧完全相同*。在生成任何连接器之前，请阅读[无缝链](#step-5--the-seamless-chain-the-critical-part)。如果做得不对，这是最常见的失败，并且会在场景之间产生可见的“弹出”。

不要假设前端框架。`references/scrub-engine.js`中的刮擦引擎是自包含的纯JS（它构建自己的DOM + 向其提供的容器注入自己的CSS），因此可以无缝地放入纯HTML、Next.js、Vue、Python提供的页面等。这项技能的价值是Higgsfield管道、提示和接缝方法——不是框架。

## 步骤 0 — 初始化

1. **Monid CLI — 默认视频链后端。** 检查`monid --version`、`monid keys list`（活动密钥）和`monid balance`——链按剪辑计费，美元（步骤 1.7 有具体数字；1080p N=6 链约 $27）。如果CLI缺失或余额不足以支付链，请说明，并改用Higgsfield信用渲染链——模型相同，管道相同，计费方不同（步骤 4 → Monid 后端）。
2. **Higgsfield CLI — 即使在Monid路径上也需要**：它渲染场景静止图像（`gpt_image_2`）并是`kling3_0` NSFW备用和备用链的家。如果`higgsfield`不在`$PATH`中，按照`higgsfield-generate`技能进行安装。如果`higgsfield workspace list`认证失败，请要求用户运行`higgsfield auth login`（交互式OAuth——您不能运行它），如果需要，请运行`higgsfield workspace set <id>`。确认信用足以支付静止图像（~N 图像生成）——如果链回退到此，还需要`(2N-1)`视频生成。
3. **ffmpeg / ffprobe** 在`$PATH`中（帧提取 + 编码）。
4. **图像工具**用于背景抠图，如果您想要浮动的场景：PIL（`python3 -c "import PIL"`)，或者`cwebp`/`sips`。可选——见步骤 3。
5. **(可选) Codex CLI**——如果`codex`在`$PATH`上（≥ 0.125）并且`codex login status`报告ChatGPT登录，场景静止图像可以通过Codex内置的`image_gen`生成（使用相同的gpt-image-2模型）并计费到用户的ChatGPT订阅，而不是Higgsfield信用——在步骤 1.7 提供它，步骤 2 中的命令。缺少它只是移除了这个选项。
6. 注意事项：macOS安装**bash 3.2**（没有`declare -A`）；不要在脚本中使用关联数组。Higgsfield生成需要**3–8 分钟每个**——始终以脱机（后台）方式运行它们并轮询，永远不要以前台阻塞调用。媒体标志拒绝按工作UUID引用——传递**本地文件路径**到`--image/--start-image/--end-image`。视频模型在接受的参数方面有所不同（例如，Kling没有`--resolution`）并且在它们是否支持开始/结束图像调节方面有所不同——在批量处理之前，确认所选模型的模式与`higgsfield model get <job_type>`一致，并查看步骤 4 模型表。

## 步骤 1 — 访谈用户

主题由用户确定——以纯文本问题形式提问，永远不要用虚构的多个选择。虚构的行业列表会偏向他们，并读起来像你决定他们的业务；让他们用自己的话回答（他们自己的真实业务、客户的业务或任何想法）。保留结构化的多个选择（Claude Code中的`AskUserQuestion`；其他地方的纯是或非问题）用于真正可枚举的、低风险的选项——艺术方向、相机风格和品牌套件方法——甚至在那里，也要表明他们可以走自己的路（“其他”）。只问那些你不能合理默认的问题。涵盖：

1. **主题**（公开提问，不是多个选择）——“这个世界应该是什么？你的业务、客户的业务或任何想法——一个词或一句话就足够了。”捕获行业/产品 + 一句话简报（例如，“一家珍珠奶茶公司，从叶子到最后一口”），如果他们有品牌名称，请记录下来；如果没有，下面会提出一个。
2. **品牌套件**——提供三个路径，选择一个：
   - 从URL导入：`higgsfield marketing-studio brand-kits fetch --url <site> --wait`（拉取名称、颜色、语气）。然后使用`brand-kits list --json`读回。
   - 用户直接给你调色板 + 名称 + 语气。
   - 你提出调色板 + 名称并让他们批准。捕获**4–6 个命名的十六进制值**、一个显示名称和一些语气词。
3. **艺术方向**——默认是“软磨砂低多边形**粘土模型**，等距，倾斜位移微型，暖光。”提供替代方案（平面纸艺，光泽玩具，粘土动画，霓虹夜色）。无论选择什么，都成为共享的**风格前缀**，在场景提示中逐字重复使用（这是使世界连贯的原因）。
4. **相机风格——始终询问；这是电影的个性，不是技术细节。** 通过感觉提问（Claude Code中的`AskUserQuestion`；其他地方的纯问题）并记录答案作为`CAMERA`。选项映射到步骤 4 的架构——步骤 4 然后实现选择，它永远不会重新决定它：
   - **“飞越世界”**——相机潜入每个场景，拉起并飞出，并跳转到微缩世界到下一个场景；角度不断变化，大的表现性空中动作（这是旗舰演示的外观）→ 架构 B。推荐将其作为场景/微型艺术方向的默认选项。
   - **“一个连续的行走”**——单个前向飞行，滑过每个场景直接进入下一个场景，从不拉回；每个场景都有表现性的但始终向前的动作（相机语法表）。→ 架构 A。推荐将其作为接地/照片真实艺术方向的默认选项。
   - **“固定的等距滑行”**——相机在整个电影中保持一个固定的角度，Emons风格；世界滑过/朝它移动，没有旋转，没有揭示。→ 架构 A + 每个腿部提示中固定的等距子句（prompts.md）。
   在每行说明中说明权衡（B 在接缝处反转方向——在微型模型中很迷人，在现实主义中令人震惊；锁定等距是平静且重新录制成本最低；行走介于两者之间）。
5. **旅程（部分）**——相机飞行的有序场景。建议一套来自主题自身价值链的，并允许用户编辑。5–7 个效果很好。波霸示例：农场 → 珍珠厨房 → 旗舰店 → 配送 → 社区广场 → 英雄产品。每个部分都需要：场景简短描述（模型中有什么），眉题，标题，一句话正文，0–3 个标签药丸。最后一个部分通常是英雄产品 + CTA。
6. **移动版本——始终询问；永远不要默默地生成两者。** 以两个选项提问（Claude Code中的`AskUserQuestion`；其他地方的纯问题）：
   *"想要移动优化的版本吗？移动版本是原生 9:16 竖屏渲染的第二相机链——为手机而不是横屏电影而组成——这大约 doubles the Higgsfield 信用支出（说明估计数字）。*
   选项："仅桌面" / "桌面 + 移动（原生 9:16 — ~2× 信用）"。信用成本必须告知用户，而不仅仅是暗示。
   它控制的内容：
   - **是** → 渲染并行 9:16 竖屏链，并将其作为移动变体发送（步骤 6 / pipeline.md §6b）：竖屏起始画布 → 9:16 倾斜 + 连接器帧锁定 → 720 宽 `-m.mp4` 编码 → `stillMobile` 竖屏海报。连接`clipMobile`/`connectorsMobile`/`stillMobile`（步骤 7）；运行完整的移动 QA（步骤 8）。预算 ~2N-1 额外视频生成 + NSFW 重新录制。
   **永远不要默认发送中心裁剪作为移动版本**——如果信用不足以支付竖屏链，请说明，并提议提供裁剪编码（pipeline.md §6）作为明确标记的临时方案，用户必须批准。
   - **否** → 完全跳过移动编码和接线。引擎的电话硬化（seek-coalescing，iOS 初始化，安全区域CSS）始终开启——这不是“移动版本”，只是当手机访问时页面不会崩溃——所以仅桌面构建仍然优雅地降级。

**预算——引擎按成本显示，在渲染之前决定。** 显示渲染层级（`AskUserQuestion`），然后计算并说明用户 N 个场景的估计总成本——N 个静止图像 + (2N−1) 个视频 [视频 ×2 如果移动] + ~15% 重新录制余地——并在生成之前获得许可。**
   - **视频层级**（仅目录——每个选项帧锁定接缝，步骤 4）：

     | 层级 | 模型 | 粗略成本 |
     |---|---|---|
     | 草稿 / 预览 | `seedance_2_0_mini` (720p) | ~¼ 标准成本 |
     | 标准（默认） | `seedance_2_0` (1080p) | 基线 |
     | 替代 | `kling3_0` (720p 原生) | ≈ 标准；不同的外观 + 内容过滤器 |

     草稿也用作预览路径：廉价地运行整个链，批准旅程，在标准上重新渲染最终腿部（pipeline.md 注释）——建议在余额紧张时提示它。
   - **后端**——Monid 是链的默认计费方（步骤 0.1；pipeline.md 中的接线 → Monid 后端）。相同的 Seedance 2.0，按剪辑计费美元，而不是信用。按 token 定价 (`w × h × 24 × sec / 1024` at $7/1M (480p/720p) 或 $7.7/1M (1080p) — 测量：1080p 8 秒潜水 ≈ $2.99，5 秒连接器 ≈ $1.87；720p ≈ $1.21 / $0.76；480p ≈ $0.28 / $0.35。N=6 桌面链在 1080p 下 ≈ $27，720p 下约为 ~$11 vs Higgsfield Plus 月度订阅 ≈ $32 / $16 — 每个剪辑 ~15% 更便宜，与 Plus 年度具有同等价值；对于一次性构建，结构上更好（按使用付费，没有月度过期）。在 Monid 中，草稿/预览层级是**480p 的相同终点**——没有模型交换，所以预览→最终保持一个模型。说明`monid balance`与估计值；**回退到 Higgsfield 信用**（上面的模型层级）当用户更喜欢他们的订阅，余额不足，或者模型必须是`kling3_0`（Higgsfield 仅限模型）。它是相同的底层模型（`seedance_2_0` ≙ Monid 的 `seedance-2.0`），所以完成一个被遗弃的链在另一个计费方上是一个合理的救援——但服务堆栈不同，跨提供商的接缝特征是**未经测试**：在渲染其余内容之前，检查第一个被救援的接缝。

### Monid 后端——默认链计费方（合格 2026-07-25）

Monid 的 **`bytedance /v1/video/seedance-2.0`** 在 2026 年 7 月通过了两个付费探测，并且是**默认**方式，用于渲染链，适用于**两种架构**——它使用的是清单中的 `seedance-2.0`，按美元计费（pipeline.md 中的接线 → Monid 后端）；Higgsfield 仅在备用计费方或仅限 Higgsfield 模型的情况下渲染链。

- **I/O 合同与 Higgsfield CLI 不同**：
  1. **图像通过 URL 传递，绝不内联。** `content` 项目是 `"type":"image_url","image_url":{"url":…},"role":"first_frame"|"last_frame"`；base64 数据 URL 被拒绝（"Must be a public https:// URL or an asset://<id> reference"). 本地帧通过 Monid 的免费工作区文件系统传输：`sfs /put` → `curl -T` 传输字节 → `sfs /cat` 返回已签名的公共 URL 以便粘贴到正文 (`$0`, 显式构建用于此)。结果 URL 过期（~24–48 小时）——立即下载。
  2. **明确传递 `ratio`** (`16:9` 桌面，`9:16` 移动链)——显式地应用于每个连接的剪辑。
  3. **每个剪辑都进行计费检查**：成本是 token 定价 (`w × h × 24 × sec / 1024` at $7–7.7/1M (480p/720p) 或 $7.7/1M (1080p) — 测量：1080p 8 秒潜水 ≈ $2.99，5 秒连接器 ≈ $1.87；720p ≈ $1.21 / $0.76；480p ≈ $0.28 / $0.35。N=6 桌面链在 1080p 下 ≈ $27，720p 下约为 ~$11 vs Higgsfield Plus 月度订阅 ≈ $32 / $16 — 每个剪辑 ~15% 更便宜，与 Plus 年度具有同等价值；对于一次性构建，结构上更好（按使用付费，没有月度过期）。在 Monid 中，草稿/预览层级是**480p 的相同终点**——没有模型交换，所以预览→最终保持一个模型。说明`monid balance`与估计值；**回退到 Higgsfield 信用**（上面的模型层级）当用户更喜欢他们的订阅，余额不足，或者模型必须是`kling3_0`（Higgsfield 仅限模型）。它是相同的底层模型（`seedance_2_0` ≙ Monid 的 `seedance-2.0`），所以完成一个被遗弃的链在另一个计费方上是一个合理的救援——但服务堆栈不同，跨提供商的接缝特征是**未经测试**：在渲染其余内容之前，检查第一个被救援的接缝。

**合格协议**（每个探测都是一次廉价的 480p 剪辑）：
(1) 提示 + 来自一个真实静止图像的 `first_frame` 必须匹配输入到编解码器噪声（PSNR ≳ 30 dB）并且 `cost.value` 必须匹配广告单元； (2) 对于连接器任务，添加来自不同静止图像的 `last_frame` — 结束必须落在该构图上（Seedance 风格的近似值可以，接缝由引擎的交叉淡入覆盖）。通过 → 支付每剪辑的美元层级（架构 A 如果仅使用 start-only；完整清单如果 start+end）。**

**Monid CLI “Polling timed out after 120s”** → 只有本地等待死亡；运行在服务器端继续。用 `monid runs get -r <runId> -w 120`（在 `monid runs list` 中找到 id）。结果 URL 过期（~24–48 小时）——立即下载。

**Monid minimax 在提示存在时丢掉图像** → `prompt` + `first_frame_image` 一起返回一个无关的 t2v 剪辑，并计费到错误的矩阵单元（$0.56 vs $0.28 观察）。图像仅帧锁定，但没有相机控制。直到包装器被修复，那个端点不能链——使用 Monid 的 seedance-2.0。

**Monid 计费意外** → 矩阵/token 定价端点按选择器匹配计费：
  - 明确传递每个选择器字段 (`model`, `resolution`, `duration`) 并从每个剪辑的运行结果中读取 `cost.value`。任何正文中的大 base64 字段也可以弹出一个 HTML 错误页面（"Unexpected token '<'") — 另一个原因帧是通过 sfs URL 传输的。

**Monid 模式自上次构建以来已更改** → 它会发生（seedance 在 2026 年 7 月晚些时候是 t2v 仅限，然后获得了 first/last-frame 支持）。在每次构建之前运行 `monid inspect`；当输入模式与 `pipeline.md` 文档中的模式不同时，重新运行步骤 4 的合格探测。

**Codex 静止图像挂起在“从 stdin 读取其他输入…”** → 从一个脚本启动的并行 `codex exec` 调用共享父级的 stdin；一个获胜，其余永远阻塞（观察：3 个中 1 个完成，2 个挂起，第二个批次从未开始）。始终在后台运行的 `codex exec` 添加 `< /dev/null`——管道的 `gen_still_codex` 有它；如果您修改了命令，请保留它。

**白框场景** → `gpt_image_2` 返回一个实心背景；要么将其与页面背景匹配，要么将其抠图（步骤 3）。

**macOS 上的 bash 3.2** → 脚本中没有关联数组。

**连接器抓取了错误场景的帧**（或在尚未存在的帧上出错）→ 数组循环在 **zsh**（macOS 默认交互式 shell），其中数组是 1 索引的，而不是 bash 的 0 索引。保持每个由数组驱动的链步骤在 `#!/bin/bash` 脚本中运行，通过 `bash script.sh`——永远不要在交互式 shell 中内联数组循环。
