# Logo Generator

生成专业的SVG标志和高端展示演示文稿，用于产品及品牌。

## 工作流程

### 第一阶段：信息收集

从用户处收集必要信息：

1. **产品/品牌名称**（必填）
2. **行业/类别**（例如：人工智能、金融科技、设计工具）
3. **核心概念**（例如：连接、流动、安全、简洁）
4. **设计偏好**：
   - 风格：简约/复杂，几何/有机
   - 颜色偏好：单色/特定颜色
   - 氛围：冷/暖，专业/友好

用简洁的问题收集这些信息。一次不要问太多问题，以免让用户感到不知所措。

### 第二阶段：模式匹配与SVG生成

根据收集到的信息：

1. 基于 `references/design_patterns.md` 生成至少6个设计变体
   - 将模式与产品特性相匹配
   - 使用不同的模式类型和组合以增加多样性
   - 包含单一模式和混合模式构图
   - 变化复杂度级别（从简单的几何图形到分层构图）
   - 每个变体应感觉明显不同，而不仅仅是参数调整
   - 解释每个变体的设计原理

2. 为每个变体生成SVG代码
   - 使用 `viewBox="0 0 100 100"` 以便于缩放
   - 保持代码简洁且结构良好
   - 使用 `currentColor` 以实现灵活的颜色控制
   - 可选：为网页展示添加微妙的动画效果

3. 创建交互式展示网页
   - 在网格布局中展示所有6个以上的标志变体
   - 使用 `assets/showcase_template.html` 中的模板
   - 包含悬停效果和流畅的过渡
   - 为每个变体添加设计原理
   - 允许轻松比较不同变体

### 第三阶段：迭代与优化

允许用户提供反馈：

- 选择喜欢的变体（从6个以上缩小到2-3个）
- 调整特定参数（大小、间距、旋转）
- 从不同变体中组合元素
- 更改颜色或添加渐变
- 修改动画或效果
- 生成探索特定方向的额外变体

根据反馈进行有针对性的调整。除非用户要求，否则不要重新生成所有内容。

### 第四阶段：高端展示生成

一旦用户选择了一个喜欢的标志方向：

1. **将SVG导出为PNG**
   - 使用 `scripts/svg_to_png.py` 将SVG转换为PNG
   - 默认大小：1024x1024像素
   - 确保透明背景

2. **选择展示风格**
   - 查看 `references/background_styles.md`
   - 根据产品类型和氛围推荐4种风格
   - 解释每种风格为何适合

3. **生成展示图像**
   - 设置环境（将 `.env.example` 复制到 `.env`，添加API密钥）
   - 使用 `scripts/generate_showcase.py` 并带 `--all-styles` 标志
   - 或单独生成特定风格
   - 每个图像使用PNG作为参考，并使用Nano Banana API

4. **创建最终演示网页**
   - 结合SVG变体和展示图像
   - 使用专业布局和微排版
   - 包含所有资产的下载链接

### 第五阶段：交付

向用户提供：

- 交互式HTML展示页面
- SVG文件（可编辑的矢量格式）
- PNG导出（如果需要，提供不同尺寸）
- 展示图像（4个专业背景）

## 关键设计原则

1. **提供多样性**：生成至少6个不同的变体，为用户提供真实的选择
2. **从简开始**：从基本模式开始，仅在需要时增加复杂度
3. **有意义的设计**：将视觉元素与产品概念相连接
4. **可扩展性**：确保标志在各种尺寸下都能使用
5. **专业质量**：匹配高端品牌身份标准
6. **灵活性**：为不同使用场景提供多个变体

## 技术说明

### SVG最佳实践

- 保持 `viewBox` 为 `0 0 100 100` 以确保一致性
- 使用 `<g>` 标签进行语义分组
- 利用 `<defs>` 实现可重用元素
- 使用 `<clipPath>` 实现遮罩效果
- 优先使用几何基元而不是复杂路径

### 展示图像生成

`generate_showcase.py` 脚本需要：
- Python 3.8+
- 依赖项：`pip install -r requirements.txt`
- `.env` 文件中的环境变量
- 参考PNG图像（从SVG导出）

支持官方Google Gemini API和第三方端点，通过 `GEMINI_API_BASE_URL` 访问。

### 可用的背景风格

从 `references/background_styles.md`：

**12种专业风格可用**：

**暗色风格**（6种）：
- void（绝对虚空）- 绝对简约主义，硬核科技
- frosted（磨砂穹顶）- 现代呼吸空间，高端产品
- fluid（流体深渊）- 人工智能原生流动性，动态系统
- spotlight（物理影棚）- 工作室灯光，编辑质量
- analog_liquid（物理流体）- 在纯色基础上添加金属光泽，创意品牌
- led_matrix（数字硬件）- 数字复古，赛博朋克美学

**亮色风格**（6种）：
- editorial（纸本编辑）- 特种纸张，人文品牌
- iridescent（幻彩透砂）- 光学材料，科技硬件
- morning（晨雾光域）- 人工智能柔和，易接近的产品
- clinical（无菌影棚）- 空间秩序，算法驱动品牌
- ui_container（容器化界面）- 原生数字产品，SaaS平台
- swiss_flat（瑞士扁平）- 绝对扁平，永恒权威

每种风格都有特定的视觉特征和适用场景。参考文档中有详细信息。

## 常见模式

### 模式：同心圆点

```svg
<svg viewBox="0 0 100 100">
  <g>
    <!-- 内环：6个点 -->
    <circle cx="50" cy="38" r="3" fill="currentColor"/>
    <!-- 在环形排列中添加更多点 -->
  </g>
</svg>
```

### 模式：带线条强调的几何形状

```svg
<svg viewBox="0 0 100 100">
  <polygon points="50,30 70,60 30,60" fill="none" stroke="currentColor" stroke-width="2"/>
  <circle cx="50" cy="30" r="4" fill="currentColor"/>
</svg>
```

### 模式：节点网络

```svg
<svg viewBox="0 0 100 100">
  <path d="M 30 70 Q 50 70, 50 50 T 70 30" stroke="currentColor" stroke-width="2" fill="none"/>
  <circle cx="30" cy="70" r="4" fill="currentColor"/>
  <circle cx="50" cy="50" r="5" fill="currentColor"/>
  <circle cx="70" cy="30" r="4" fill="currentColor"/>
</svg>
```

更多模式和组合，请参阅 `references/design_patterns.md`。

## 故障排除

**SVG无法正确显示**：检查 `viewBox` 并确保所有路径都已闭合

**PNG导出失败**：验证已安装 `cairosvg` (`pip install cairosvg`)

**展示生成失败**：
- 检查 `.env` 文件中的 `GEMINI_API_KEY` 是否有效
- 验证参考PNG是否存在且可读
- 检查API配额/速率限制

**第三方API无法工作**：确保 `GEMINI_API_BASE_URL` 格式正确（例如：`https://api.example.com/v1`）
