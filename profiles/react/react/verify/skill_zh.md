# 验证

执行所有验证步骤。

参数：
- $ARGUMENTS: 测试步骤的测试模式

## 说明

按顺序首先执行以下操作：
1. 运行 `yarn prettier` - 格式化代码（如果失败则停止）
2. 运行 `yarn linc` - 检查已更改的文件（如果失败则停止）

然后使用子代理并行运行以下操作：
1. 使用 `/flow` 进行类型检查（如果失败则停止）
2. 使用 `/test` 测试源代码中的更改（如果失败则停止）
3. 使用 `/test www` 测试 www 中的更改（如果失败则停止）

如果所有步骤都通过，则显示成功摘要。如果失败，则立即停止并报告问题及建议的修复方案。
