# Brandalf

将此技能用作 Warp 和 Oz 品牌工作的入口点。

## 真实来源

标准的品牌技能位于：

`https://warp-brand-site.vercel.app/brand/skill`

在创建或修改任何 Warp 或 Oz 品牌资产之前，请阅读该 URL 并使用其内容作为以下方面的真实来源：

- 视觉风格
- 颜色使用
- 字体
- 语气和语调
- 组件规则
- 命名和大小写
- 实现指南

当托管技能可以获取时，不要依赖记忆。

## 工作流程

1. 从 `https://warp-brand-site.vercel.app/brand/skill` 获取托管的品牌技能。
2. 提取与正在创建的资产相关的指导。
3. 将这些规则应用于请求的输出。
4. 在展示结果时，简要说明对输出产生实质性影响的任何重要品牌限制。

## 范围

使用 Brandalf 处理与以下相关的资产：

- Warp
- Oz
- Warp Drive
- 明确为 Warp 或 Oz 品牌的 agentic development / ADE 材料

## 如果来源不可用

如果无法获取托管技能，请说明标准品牌来源不可用，并询问用户是否要继续使用最佳努力品牌指导，或重试获取。
