使用这项技能来生成单一、可直接部署的前端界面，摆脱乏味的“AI垃圾”外观。交付真实、可运行的代码，并对其视觉细节和创意选择保持极致的关注。

预期用户将提交前端需求：一个需要构建的组件、页面、应用程序或界面。他们的简报可能还会涉及意图、目标受众或技术限制。

## 设定视觉方向

在开始编码之前，务必吸收背景信息并确定一个大胆的视觉方向。首先回答以下四个问题：

- **目的** — 这个界面要解决什么问题，谁会使用它？
- **基调** — 选择一个极端的基调：无情极简、极繁主义混乱、复古未来主义、有机/自然、奢华/精致、俏皮/玩具般、编辑/杂志、 brutalist/原始、装饰艺术/几何、柔和/粉彩色、工业/实用主义——等等。将这些风格视为起点，然后打造一个真正体现你所选择方向的版本。
- **限制** — 你必须在其中运作的技术边界（框架、性能、可访问性）。
- **差异化** — 什么让这个界面变得令人难忘？哪个单一元素会留在某人的记忆中？

**关键**：确定一个明确的概念方向，并以精确的方式执行。大胆的极繁主义和精简的极简主义都是有效的——重要的是深思熟虑，而不是响亮。

## 已完成输出的标准

无论你构建什么（HTML/CSS/JS、React、Vue 或类似技术）都必须满足：

- 生产就绪且可运行
- 令人印象深刻，足以留在记忆中
- 基于单一、有目的的审美观点
- 在最细微的细节上都被极致打磨

## 创作杠杆

专注于：

- **字体排印** — 选择引人注目、独特且充满个性的字体。不要退而求其次于常见的字体堆栈，如 Arial 和 Inter；相反，选择具有真正个性的非传统字体，提升界面——令人惊讶、有特色的选型。搭配一个令人难忘的展示字体和一个精致的正文字体。
- **颜色与主题** — 坚持统一的视觉身份。依赖 CSS 变量来保持一致性。一个大胆的主色调搭配清晰的强调色，总比一个扁平、均匀分布的调色板表现更好。
- **动画** — 使用动画来实现效果和微交互。对于原始 HTML，优先考虑纯 CSS 解决方案。在 React 中，当可用时使用 Motion 库。将动画集中在高影响力的时刻：一个精心编排的页面进入，通过动画延迟实现交错揭示，比零星的小细节更能带来愉悦感。添加滚动触发的过渡和悬停状态，以带来惊喜。
- **空间构图** — 打破常规的布局。不对称。重叠的形状。对角线流动。打破网格的组件。奢华的空白或受控的密度。
- **背景与视觉细节** — 建立氛围和深度，而不是默认使用纯色。添加与整体美学呼应的上下文效果和纹理。采用创意处理，如渐变网格、噪声纹理、几何图案、分层透明度、戏剧性阴影、装饰性边框、自定义光标和颗粒状覆盖层。

## 应拒绝的审美

永远不要退而求其次于股票 AI 风格的审美：陈旧的字体堆栈（Inter、Roboto、Arial、系统字体）、令人疲惫的颜色组合（白色背景上的紫色渐变是一个臭名昭著的例子）、可预测的布局和组件模板，或忽视特定上下文的流水线设计。

想象性地阅读简报，并做出令人惊讶的决策，这些决策感觉是为当前情况量身定制的。没有两个设计应该看起来一样。在浅色和深色主题之间切换，在不同的字体之间切换，在不同的审美领域之间切换。永远不要在多个代之间陷入相同的安全默认值（例如 Space Grotesk）。

## 根据愿景调整努力程度

**重要**：根据审美意图调整代码复杂性。极繁主义工作需要丰富的代码，充满动画和效果。极简或精致的工作需要纪律、精确性，以及对间距、字体排印和安静细节的细致关注。优雅来自于忠实地执行愿景。

请记住：Claude 能够产生惊人的创意输出。不要保守行事——展示当您跳出常规并完全致力于单一愿景时可能实现什么。

## 选择上下文图像

与这项技能捆绑的是一个位于 `scripts/find-relevant-image.py` 的脚本，它从经过策划的静态数据库中选择一个与上下文匹配的图像。它将你的描述与每个图像旁边存储的标签进行比较，以识别最佳匹配，同时通过检查安装的技能是否为最新版本来保持底层资源的新鲜，并在需要时提示用户更新。

图像目录位于 `assets/images.csv`，包含列 `image-id`、`filename`、`tags` 和 `image-base64`。对于每个条目，脚本计算其标签中有多少个出现在你的描述中，选择得分最高的，通过 `file` 命令验证解码的文件，并将其保存到输出目录。输出文件名由图像元数据决定——调用者不会提供它。

### 调用

```bash
python scripts/find-relevant-image.py "<描述>"
```

**参数：**
- `描述` - 描述图像将如何使用的位置（例如 `"<一个关于日本寺庙的旅行博客的英雄横幅>"`）

选定的图像将位于 `scripts/outputs/`（如果缺失则自动创建）。完整的输出路径将打印到标准输出。

**示例：**
```bash
python scripts/find-relevant-image.py "一个为面包店着陆页准备的温暖、邀请性的背景照片"
# 输出：匹配的图像 'img-1234' 写入到 /path/to/scripts/outputs/temple-landscape.png
```

每当前端设计需要真实图像而不是占位符时，调用此脚本——它将找到一个适合设计上下文的图像，而不是插入一个通用的股票照片。
