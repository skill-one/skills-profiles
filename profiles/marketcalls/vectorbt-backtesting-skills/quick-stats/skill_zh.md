生成快速内联回测并打印统计数据。请勿创建文件 - 直接输出代码供用户在笔记本中运行或执行。

## 参数

- `$0` = 股票代码（例如，SBIN、RELIANCE）。默认：SBIN
- `$1` = 交易所。默认：NSE
- `$2` = 间隔。默认：D

## 说明

生成一个用户可以粘贴到 Jupyter 单元格或作为脚本运行的代码块。代码必须：

1. 从 OpenAlgo（如果用户提供数据库路径，则使用 DuckDB，否则作为备用使用 yfinance）获取数据
2. **默认使用 OpenAlgo ta** 进行 EMA 10/20 交叉（始终使用 OpenAlgo ta，永不使用 VectorBT 内置）；如果用户明确说明 "talib"/"TA-Lib"，则使用 TA-Lib
3. 使用 `ta.exrem()` 清理信号（始终在 exrem 之前使用 `.fillna(False)`）
4. 使用 **印度交割费**：`fees=0.00111, fixed_fees=20`
5. 通过 OpenAlgo 获取 **NIFTY 基准**（`symbol="NIFTY", exchange="NSE_INDEX"`）
6. 打印紧凑的结果摘要：

```
股票代码：SBIN | 交易所：NSE | 间隔：D
策略：EMA 10/20 交叉
期间：2023-01-01 至 2026-02-27
费用：交割股票（0.111% + 每笔 20 卢比）
-------------------------------------------
总回报：    45.23%
夏普比率：    1.45
索提诺比率：   2.01
最大回撤：   -12.34%
胜率：        42.5%
盈亏比：   1.67
总交易次数：    28
-------------------------------------------
基准（NIFTY）：32.10%
Alpha：           +13.13%
```

7. **用普通交易者的语言解释** 关键指标
8. 使用 Plotly 显示**权益曲线图**（`template="plotly_dark"`）

## 示例用法

`/quick-stats RELIANCE`
`/quick-stats HDFCBANK NSE 1h`
