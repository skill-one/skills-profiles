# DfAM 检查

来源：维护在 [earthtojake/text-to-cad](https://github.com/earthtojake/text-to-cad) 中。
使用已安装的本地技能文件作为运行时事实来源；仓库链接仅用于溯源和发布审核。

使用此技能在切片或打印前生成保守的、有证据支持的 DfAM 报告。它本地测量几何事实，并与每个进程的设计限制进行比较；它从不切片、上传或启动打印任务。

## 几何检查

在当前项目的 Python 环境中使用 `scripts/dfam_tool.py` 进行所有几何事实（首先安装 `requirements.txt` — 每次运行都需要）。该工具仅报告事实：它报告测量结果，从不发出通过/失败或准备就绪状态。比较和裁决属于此工作流。当工具可以测量时，不要凭肉眼或从渲染中估算壁厚、悬垂角度或支撑体积。

```bash
python scripts/dfam_tool.py measure part.stl --angle-limit 45
python scripts/dfam_tool.py orientations part.stl --angle-limit 45
```

在测量前，根据 `references/process-limits.md` 将 `--angle-limit` 设置为目标工艺的自支撑角度，当目标工艺变化时重新运行：汇总的支撑面积事实会根据它进行分类。

STEP/STP 输入是边界表示的 CAD，不是网格。当 `$cad` 技能安装时，首先用它导出 STL 侧文件，然后在此处测量 STL。报告修复措施，而不是尝试原始 STEP 解析。在 STEP 上运行 `measure` 会以 `{"error": "failed to load mesh: ..."}` 退出 1；这是错误输入信号，不是缺失依赖 — 不要安装额外的网格加载器来绕过它。

无法计算的属性家族会在其位置返回 `{"error": ...}`，而不是让报告的其他测量结果失效 — `wall_thickness` 在依赖集不完整时这样做，`support_volume` 在没有凸包的几何体上这样做。该报告是部分性的：它包含 `"partial": true`，在 `partial_sections` 中命名家族，并且命令退出 **2**（0 是完整报告，1 是完全无法加载的网格）。将每个此类对象视为未测量的事实（`❓ 需要更多信息`），而不是零的测量值，并且在比较壁限制前重新安装 `requirements.txt`。

## 工作流

1. 收集打印意图：目标工艺、材料、层高以及用户可以提供的任何机器或材料数据表。如果工艺未知，使用默认的 45° 限制测量一次，然后按候选工艺逐项呈现结果，而不是猜测单一裁决。
2. 阅读 `references/process-limits.md` 并为目标工艺选择限制列。用户提供的机器/材料数据表会覆盖默认值；为每个比较引用所使用的来源。
3. 在精确的上传文件上运行 `measure`。不要仅检查生成器脚本、源 CAD 模型或文件的控制台摘要。
4. 当工艺需要支撑且测量的支撑面积不为零时运行 `orientations`。报告任何实质上减少支撑面积的候选方案，并说明其高度权衡。
5. 将每个测量事实与引用的限制进行比较，并以受约束状态标签报告结果：
   - `✅ pass`：测量的事实满足引用的限制。
   - `❌ fail`：测量的事实直接违反引用的限制。
   - `❓ need more info`：缺失工艺上下文、未测量的几何体、采样过于稀疏无法信任或工具限制。
6. 按严重程度排序结果：首先 watertightness（阻止每个工艺的切片），然后壁厚，然后悬垂/支撑，然后方向和成本信号。

## 比较

仅比较可信的证据对。

- 为每个结果引用限制来源（工艺限制表格行或用户的资料字段）和测量事实（JSON 字段路径）。
- 即使 `min_mm` 单独可能是采样异常，也将低于壁厚限制的 `p05_mm` 视为违规；报告两个值。
- 在装配体上，`wall_thickness` 报告 `body_count` 和 `per_body` 拆解。将违规归因于它所属的体；跨多个体分布的薄部件不是针对整个部件的发现。
- 不要将支撑角度结果应用于粉末工艺（SLS、MJF）；相关的粉末工艺检查是困体积粉末逃逸，该工具尚未测量 — 当可能存在封闭空腔时，将其报告为 `❓ need more info`。
- 不要无声地缩放几何体。`scale.units_suspect` 从包围盒对角线测量：当它是 `true` 时，来源可能在米或英寸，每个向下面的面都显示为位于板上，悬垂和支撑的数值为 0.0 没有意义。报告单位/缩放发现，并在比较任何东西与材料限制前要求用户确认单位。
- 支撑体积比率是粗略的上限；将其作为成本信号，而不是硬性失败，除非用户已设置明确预算。

## 重新设计交接

对于每个 `❌ fail`，包括一个具体的、平实的语言重新设计指令和目标数值（例如 "将 [12.4, 3.0, 8.1] 处的壁厚从 0.6 毫米增加到 ≥1.2 毫米" 或 "将 [23.3, 10.0, 52.0] 处的悬垂倒角到 ≥45°"）。当 `$cad` 技能安装时，提供使用它应用重新设计指令并在此处重新测量再生几何体的选项，重复直到没有 `❌ fail` 发现。当 `$cad-viewer` 安装时，将测量的文件路径交给它，以便用户可以直观检查结果。
