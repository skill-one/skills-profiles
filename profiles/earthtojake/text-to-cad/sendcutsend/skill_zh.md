# SendCutSend

来源：维护在 [earthtojake/text-to-cad](https://github.com/earthtojake/text-to-cad)。
使用已安装的本地技能文件作为事实来源；仓库链接仅用于来源和发布审核。

使用此技能为 DXF 和 STEP/STP 文件生成保守的、有证据支持的 SendCutSend 预检报告。

将 SendCutSend 的订购指南、目录 JSON 和规格 JSON 视为证据源，而不是稳定的 API。字段名、类型和覆盖范围可能有所不同。不要将缺失、无法解析、`N/A` 或冲突的源数据转换为通过或失败。直接从官方 URL 获取源，仅使用本地检查代码来测量特定文件事实；从明确的比较中编写最终报告。

## 几何检查

使用活动项目的 Python 环境进行本地几何检查代码。如果 `$cad` 技能可用，首先使用它进行 STEP/STP/DXF 几何检查、测量和验证工作流，然后添加任何仍然缺失的 SendCutSend 特定目标测量。使用 `build123d.import_step` 进行 STEP/STP 检查，并直接使用 `ezdxf` 包（`import ezdxf`；它随 build123d 一起安装）进行 DXF 检查，当需要几何事实时。通过其自身名称导入 `ezdxf` —— `build123d.ezdxf` 仅解析为附带命名空间泄漏，不是 build123d API 的一部分。不要使用原始文本解析或替代几何后端来获取几何事实。

## CAD 查看器交接

完成创建或修改 `.dxf`、`.step` 或 `.stp` 上传候选的 SendCutSend 工作 后，你必须始终在安装了 `$cad-viewer` 时将其显式文件路径(s)交给 `$cad-viewer`。如果 `$cad-viewer` 不可用或启动失败，则报告该问题，而不是静默地省略交接。

## 官方来源

在每次审核之前，直接从 `references/official-sources.md` 中列出的官方 URL 获取并检查当前的 SendCutSend 源文档。

在源参考文献中，使用源 URL、访问日期和 JSON `_meta` 值，当有帮助时。如果一个源无法获取，报告当前 SendCutSend 源不可用，并避免对依赖检查的判断。

## 工作流

1. 收集订单意图。
   - 优先选择 DXF 用于激光切割和 2D 板材轮廓。
   - 优先选择 STEP/STP 用于 CNC 路径和 3D 模型上传工作流。
   - 记录文件类型、预期流程、材料/SKU、厚度、数量、服务、表面处理和硬件。
   - 如果订单上下文缺失或模糊，检查足够的源数据以提供具体选项，然后要求用户确认后再编写准备就绪的判断。包含相关的源链接的候选 SKUs/材料/厚度/服务；当可用时，包含来自规格 JSON 的 `photo_url` 图片和 `learn_more_url` 链接。
2. 阅读 `references/official-sources.md`，直接获取官方来源，然后检查返回的文档。防御性地规范化源事实：解析数字字符串、尺寸字符串、`N/A`、缺失字段、混合类型和缺失的服务数组为明确的注释。
3. 当可用时使用 `$cad` 检查确切的上传文件，并使用目标 Python/`build123d` 检查任何缺失的事实。不要仅检查源生成器、CAD 模型或生成器控制台摘要。
   - DXF：测量单位、边界、图层、实体类型、开放/重复几何、不支持的注释、候选孔/圆、线形统计、弯线候选、弯到切割距离、弯线相邻切割几何、局部法兰深度以及根据所选服务需要的退化零面积轮廓。
   - STEP/STP：测量可解析性、单位提示、实体/表面信号、边界框、壳/实体信号、有效性、可用时板材厚度、弯曲范围内圆柱弯面半径以及根据所选服务需要的限制。
   - 保持每个检查辅助器仅包含事实。它可以报告测量值、解析错误和限制，但必须不发出通过/失败/准备就绪状态。
4. 根据证据质量选择源记录。
   - 使用确切的 SKU 作为唯一的权威目录/规格连接。
   - 如果仅提供材料和厚度，仅在候选匹配唯一且足够精确时使用选定的材料；否则列出来自源记录的候选项和图片/链接，并要求用户选择。
   - 使用目录 JSON 进行订购性：库存、切割流程、可用服务、尺寸限制、硬件和表面处理。
   - 使用规格 JSON 进行工程值：公差、孔、桥梁、弯曲、攻丝、锪孔、硬件插入、表面处理和材料属性。
   - 使用订购指南进行平语言工作流和通用文件格式规则。

## 比较

仅比较可信的证据对。

- 确定检查是否适用。
- 引用源字段路径或指南部分。
- 引用测量的文件事实。
- 仅当源要求和测量的文件事实都可用且可信时才比较。
- 如果需要测量缺失或风险，编写一个针对特定几何事实的小型 `build123d`/`ezdxf` 检查器。
- 将每个测量的上传风险、可制造性问题或引用的要求违规视为当前错误。不要推断任何替代 SendCutSend UI 分类。
- 对于 DXF 单位，一起检查 `$INSUNITS`、标题扩展、测量边界和订购上下文。如果 `$INSUNITS` 缺失、不支持或不是 SendCutSend 指南预期的 DXF 单位代码（`1` 英寸或 `4` 毫米），报告单位/比例错误，并建议重新导出或确认单位，然后再应用尺寸、法兰或材料特定的比较。不要静默地缩放几何或使用不确定的比例来发布材料特定的通过/失败检查。
- 对于带有弯线的 2D 文件，沿每个弯线检查法兰长度。在每个跨度或采样点测量每个弯线两侧最近的切割/自由边缘，包括中断弯线跨度或创建局部自由边缘的凹口、槽、间隙、分割标签和切割孔。比较最小局部法兰深度与所选 SKU 的 `bending_specs.min_flange_length_before_bend` 和 `bending_specs.min_flange_length_after_bend`。除非引用的源为该服务提供了孔到弯或特征到弯的规则，否则不要将法兰长度限制应用于普通的封闭孔或内部切割孔；按引用的规则要求分别报告。不要将附近的弯线相邻切割几何视为仅是角释放，除非剩余的局部法兰仍然满足法兰长度最小值。如果任何局部法兰深度低于 SKU 最小值，报告 `❌ fail`。不要依赖源级汇总值，当导出的几何有局部切割孔、中断的弯线、分割的弯线段、释放、标签或不受支持的区域时。
- 按物理原因将弯线发现分开。不要将弯线相邻几何合并为通用的法兰失败。报告不同的行，用于最小法兰/接触长度错误、弯线或模具区域几何交叉、来自附近自由边缘或切割孔的不足弯线接触/支持、未覆盖弯曲区域的弯线、分割/公共轴弯线段以及切割几何接触或交叉弯线。如果 SendCutSend 源未暴露确切的模具区域/接触阈值，将测量的文件事实引用为直接文件检查，并明确标记源限制的比较。
- 对于 STEP/STP 弯曲零件，在模型包含板材弯曲几何或预期服务包括弯曲时检查弯线半径。使用 `$cad`/`build123d`/OCP 尽可能提取圆柱形或环状弯面及其半径，分组重复的弯线半径，并与所选 SKU 的 `bending_specs.effective_bend_radius` 或 `bending_specs.bend_radius` 比较。如果选定的材料/SKU 未知，报告测量的弯线半径集，并在准备就绪的判断之前要求材料/厚度。如果测量的半径与选定的 SKU 工具半径冲突，报告弯线半径不匹配错误。

使用受约束的状态标签报告：

- `✅ pass`：测量的文件事实满足引用的当前要求。
- `❌ fail`：测量的上传风险、可制造性问题或直接测量的引用当前要求违规。
- `❓ need more info`：缺失上下文、缺失源证据、未测量的几何、源冲突或工具限制。

## 诊断图像

当发现更容易通过视觉理解时，如果图像生成或图像编辑功能可用，则主动生成简洁的诊断图。使用生成的或编辑的图像用于标注、图例和前后解释。在存在 `❌ fail`、空间上模糊的几何问题或需要前后解释的几何编辑时，不要等待用户请求就进行此操作。如果图像生成工具不可用，则报告该限制，并在报告中描述预期的图。

在生成图像之前，运行布局预检：

- 选择解释修复所需的最小标注集。
- 估计标签是否会挤占几何、相互重叠或超出画布。如果可能发生拥挤，则在生成前标记它，并切换到编号标记加侧边图例、更大的画布或单独的详细视图。
- 将长测量值和规则文本放在图例中，而不是直接放在密集的几何上。
- 包括测量的失败距离、引用的最小值和提议的移动或间隙目标。

生成图像后，在交付前检查渲染的图像。如果标签重叠、被裁剪、难以阅读或遮挡几何，则在报告前重新生成或修订图。

## DXF 审核

对于激光板材切割，从刷新的源和测量的 DXF 几何事实开始。

检查：

- 单个、可上传的 DXF 文件，其中包含 1:1 比例的模型几何
- 单位和整体零件尺寸；将缺失、不支持或意外的 `$INSUNITS` 视为比例错误，直到用户确认单位
- 服务要求闭合轮廓的闭合切割轮廓
- 退化或零面积闭合轮廓、两点闭合多段线和奇数度切割端点
- 重复或重叠的切割几何
- 不支持的注释、文本、尺寸、图像、构造线或隐藏指令图层
- 订购指南和上传工作流中的图层/颜色/线形约定
- 弯线实体、弯线段长度、分割/公共轴弯线、每个弯线两侧的局部法兰深度、最近的非弯线切割边缘或切割孔距离、弯线跨度覆盖、不足的弯线接触/支持、模具区域或弯线相邻切割几何交叉，以及切割几何接触或交叉弯线，当弯曲在范围内时
- 仅当源事实和测量的文件事实都支持比较时，检查最小孔、槽、腹板宽度、内部几何、零件密度、嵌套和间距
- 弯曲、攻丝、锪孔、硬件、表面处理或去毛刺的二级服务要求，当请求时

## STEP 审核

对于 CNC 路径或 3D 模型上传，从刷新的源和测量的 STEP 几何事实开始。

检查：

- STEP/STP 文件可读性以及实体而不是松散的曲线或表面
- 单位、比例、边界框、厚度和特征尺寸
- 弯曲在范围内时板材弯线半径；比较测量的圆柱形弯面半径与所选 SKU 的 `bending_specs.effective_bend_radius` 或 `bending_specs.bend_radius`
- 锐利的内角、小孔/槽、薄壁、岛屿、深腔、工具访问和公差，仅当文件检查可以测量事实时
- 几何是否代表更适合作为 DXF 用于激光切割的板材轮廓
- 材料、厚度、表面处理和二级服务兼容性

## 报告

包括文件路径、假设的服务、材料/订单上下文、检查的源文件和访问日期、检查的几何事实、按实际影响排序的发现以及具体的下一步编辑。在发现表中，包括一个 `Rule source` 列，其中包含指向源 URL 的 Markdown 链接以及用于该行的特定 JSON 字段路径或指南部分。如果一行仅基于直接文件检查且没有外部规则，则说 `Direct file inspection`；不要将源留空。除非每个必需的引用检查都通过或明确超出所选服务，否则不要称文件为 "SendCutSend ready"。

使用 `references/report-template.md` 当结构化报告会帮助时。
