# 关键词研究

用于SEO和GEO规划的关键词发现、评分和聚类。

## 快速入门

```
为[主题/产品/服务]研究关键词
```

```
[竞争对手网址]排名的关键词有哪些，我应该瞄准哪些？
```

## 技能合约

**预期输出**：优先级关键词简报和`memory/research/`的标准交接摘要。

- **读取**：主题或种子关键词、目标市场/语言、业务目标、网站DR以及任何用户提供的或工具指标。
- **写入**：面向用户的研究成果和可重用的摘要。
- **促进**：持久的优先级关键词、竞争对手事实和待定策略决策到`memory/hot-cache.md`、`memory/open-loops.md`和`memory/research/`。
- **完成条件**：每个入选的关键词都包含量级+难度+意图，每个都有来源参考、观察时间/窗口、市场/语言和证据标签；适用的缺失值为`Unknown`并说明其缺失原因，永不N/A；关键词被分组为支柱+聚类中心；交付物名称至少包含3个优先级Quick Win / Growth / GEO机会。
- **主要后续技能**：当关键词集准备好进行市场比较时，[竞争对手分析](../competitor-analysis/SKILL.md)。

**触手可及的快捷方式**（当`~~搜索控制台`连接时）：在广泛发现之前，挖掘您自己的GSC查询数据中排名在~5–20位的术语——第一页尾部和第二页。这些是已被证明的需求，一个小小的推动就能转化，因此它们是最快的机遇集。搜索分析API按点击量排序，**没有位置过滤器**，因此请求高`rowLimit`并在客户端过滤5–20窗口，然后附加量级 / 难度 / 意图到该短名单。首先处理这个集合；将其指标视为**已测量**。

## 指令

当用户请求关键词研究时，运行八个阶段并宣布每个阶段为`[阶段X/8: 名称]`：

1. **范围**——明确产品、受众、业务目标、DR、地理区域和语言。
2. **发现**——从核心、问题、解决方案、受众和行业术语中获取种子。
3. **变体**——使用修饰符和长尾模式进行扩展。
4. **分类**——按意图（信息性、导航性、商业性、交易性）进行标签。
5. **评分**——分配难度（1-100）并计算`机遇 = (量级 × 意图值) / 难度`，意图值`1 / 1 / 2 / 3`。
6. **GEO检查**——标记对AI回答友好的查询，如问题、定义、比较、列表和如何操作。
7. **聚类**——将关键词分组为支柱+聚类主题中心。
8. **交付**——输出执行摘要、Quick Wins / Growth / GEO机会、主题聚类、内容日历和下一步计划。

将每个指标标记为**已测量**（工具/导出）、**用户提供**、**计算**、**估计**、**代理**或**未知**；保留每个字段的查询、区域、语言、来源参考、观察时间和窗口。保留冲突来源。如果适用的指标不可用，请将其标记为未知并说明缺失原因——N/A仅适用于真实不适用字段。注意力代理永远不会成为搜索量，而未知的关键输入会使机遇评分`NOT_SCORED`。

### 影响×置信度视角（可选，叠加在阶段5）

当您有比量级/难度更丰富的信号时，在`机遇`分数之上添加第二遍：

- **影响** = 量级 + CPC + 转化阶段 + 趋势方向（赢得该术语的价值）。
- **置信度** = 难度 + 当前排名位置 + 主题权威（赢得它的可能性）。
- **优先级 = 影响 × 置信度**——突出显示既有价值*又能*赢得的术语，而不仅仅是高量级的。

根据其模式对每个关键词进行转化阶段标签：

- **BOFU**——商业性/交易性，或包含"定价"、"最佳"、"vs"、"服务"、"代理"、"雇佣"、"购买"。
- **MOFU**——信息性带有购买信号："如何"、"指南"、"ROI"、"案例研究"、"评论"。
- **TOFU**——纯粹信息性（定义、广泛问题）。

当目标是收入时，首先处理BOFU；使用TOFU/MOFU进行覆盖和GEO答案。 （影响×置信度+转化阶段评分改编自外部SEO-ops竞争分析。）

**质量标准**：每个建议至少包含一个具体数字。将通用建议改写为具体关键词 + 量级 + 难度 + 原因。
