agentmemory 是一个用于编码代理的记忆服务器。它运行在本地，捕获观察结果，对它们进行索引以实现混合检索，并通过 REST 和 MCP 提供服务。它基于 iii 引擎构建。

## iii 基本元素

一切都是一个函数、一个触发器或 iii 引擎上的工作状态。没有独立的插件系统；工作状态注册函数（`mem::*`）和 HTTP 触发器（`api::*`），引擎则路由调用。agentmemory 不会绕过 iii；新功能是一个新函数加上一个触发器。

## 检索模型

召回是混合的：BM25 关键词搜索加上向量相似度加上链接概念的图扩展。默认安装不需要 API 密钥，因为嵌入在设备上运行，BM25 也无需密钥。LLM 提供商仅添加更丰富的摘要和自动注入，这两者都是可选的。

## 存储和生命周期

记忆包含内容、概念、文件、重要性和时间戳，按会话分组，并可选择链接到提交。捕获、压缩、整合和遗忘的生命周期使存储在时间上保持有用，而不是无限制地增长。

## 端口

REST 是 3111 端口的锚点。流 = N+1（3112），查看器 = N+2（3113），引擎 = N+46023（49134）。`--instance N` 将整个块偏移 N*100。

## 查看器

实时网络查看器位于 `http://localhost:3113`，显示会话运行时记忆的构建过程。适用于演示和确认捕获是否正常工作。

## 参见

- agentmemory-mcp-tools 和 agentmemory-rest-api 用于界面。
- agentmemory-hooks 用于自动捕获。
- agentmemory-config 用于端口和功能标志。
