代理记忆技能遵循单一层级格式，以保持可快速浏览、准确和最新。请精确匹配。

## 目录布局

```text
plugin/skills/<name>/
  SKILL.md      (必需，少于100行)
  REFERENCE.md  (可选，密集事实；自动生成数据表)
  EXAMPLES.md   (可选，已处理的会话记录)
```

## SKILL.md 规则

- 前置内容：`name`、`description`、可选的`argument-hint`和`user-invocable`。仅对用户作为斜杠命令运行的技能设置`user-invocable: true`；参考和知识技能为`false`。
- 描述为两句话，是代理在决定加载技能时唯一看到的内容。第一句说明能力。第二句以"Use when"开头，列出具体触发条件。与同级技能区分，少于1024字符，第三人称。
- 主体顺序：快速入门（一个具体示例）、原因（指导原则）、工作流（编号步骤与决策门）、反模式（对顶级错误的错误与正确对比）、检查清单、参见（同级技能的交叉链接）、参考或故障排除指针。
- 少于100行。将密集事实移至REFERENCE.md，将示例移至EXAMPLES.md。
- 交叉引用仅链接一级深度。共享的恢复步骤位于`../_shared/TROUBLESHOOTING.md`，永不内联。

## 保持最新

存在于源中的事实（工具名称和参数、REST端点、环境变量、连接适配器、钩子事件）由生成器生成，永不手动输入。编辑源，然后运行`npm run skills:gen`。CI运行`npm run skills:check`并在出现偏差时失败，因此生成的表格不能落后于代码。

## 风格

无外部或竞争对手产品名称。无表情符号。无破折号。无填充内容。陈述事实并停止。

## 检查清单

- 描述包含一个"Use when"句子和真实触发条件。
- SKILL.md少于100行。
- 无时效性声明，无重复的故障排除块。
- 存在具体示例；生成的事实来自生成器。
- 交叉链接解析且仅有一级深度。
