评估并改进感觉通用、不一致或结构不佳的排版——将默认文本转化为有意为之、精心制作的类型。

## 必须的准备

调用 `/impeccable`——它包含设计原则、反模式和**情境收集协议**。在继续之前，请遵循该协议——如果还没有设计背景，你必须先运行 `/impeccable teach`。

## 评估当前排版

分析当前排版薄弱或通用的方面：

1. **字体选择**：
   - 我们是否使用不可见的默认字体？（Inter、Roboto、Arial、Open Sans、系统默认）
   - 字体是否与品牌个性相符？（一个俏皮的品牌不应使用企业字体）
   - 字体家族是否过多？（超过2-3个几乎总是混乱）

2. **层级**：
   - 你能一眼区分标题、正文和副标题吗？
   - 字体大小是否过于接近？（14px、15px、16px = 模糊的层级）
   - 重量对比是否足够强烈？（中等与常规几乎看不见）

3. **尺寸与比例**：
   - 是否有统一的类型比例，还是尺寸是随机的？
   - 正文是否满足最小可读性？（16px+）
   - 尺寸策略是否适合上下文？（固定 `rem` 比例用于应用UI；流体 `clamp()` 用于营销/内容页面的标题）

4. **可读性**：
   - 行长是否舒适？（45-75个字符理想）
   - 行高是否适合字体和上下文？
   - 文本与背景之间是否有足够的对比度？

5. **一致性**：
   - 相同的元素是否在整个文档中风格一致？
   - 字体重量是否使用一致？（同一角色在一个部分使用粗体，在另一个部分使用半粗体）
   - 字间距是故意的还是默认的？

**关键**：目标不是让文本“更花哨”——而是让它更清晰、更易读、更有意图。好的排版是看不见的；坏的排版是分散注意力的。

## 规划排版改进

参考[排版参考](reference/typography.md)中的完美技能，获取关于比例、搭配和加载策略的详细指导。

创建一个系统性的计划：

- **字体选择**：是否需要更换字体？什么适合品牌/上下文？
- **类型比例**：建立模块比例（例如，1.25比例）并具有清晰的层级
- **重量策略**：哪些重量服务于哪些角色？（常规用于正文，半粗体用于标签，粗体用于标题——或适合的任何内容）
- **间距**：行高、字间距和排版元素之间的边距

## 系统性地改进排版

### 字体选择

如果需要更换字体：
- 选择反映品牌个性的字体
- 与真实的对比搭配（衬线+无衬线，几何+人文主义）——或者使用单个家族的多个重量
- 确保网络字体加载不会导致布局偏移（`font-display: swap`，度量匹配的回退）

### 建立层级

构建清晰的类型比例：
- **5个尺寸涵盖大多数需求**：副标题、次要、正文、副标题、标题
- **使用一致的比例**（1.25、1.333或1.5）
- **结合维度**：大小+重量+颜色+空间以建立强烈的层级——不要仅依赖大小
- **应用UI**：使用基于 `rem` 的固定类型比例，可选在1-2个断点处调整。流体尺寸破坏了密集、基于容器的布局所需的空间可预测性
- **营销/内容页面**：使用 `clamp(min, preferred, max)` 通过流体尺寸为标题和显示文本。保持正文固定

### 修复可读性

- 在文本容器上设置 `max-width` 使用 `ch` 单位（`max-width: 65ch`）
- 根据上下文调整行高：标题更紧密（1.1-1.2），正文更宽松（1.5-1.7）
- 对于浅色背景文本稍微增加行高
- 确保正文至少为 16px / 1rem

### 细节优化

- 使用 `tabular-nums` 用于数据表和应对齐的数字
- 应用适当的 `letter-spacing`：小写字母和大写字母稍微开放，大型显示文本默认或紧密
- 使用语义标记名称（`--text-body`，`--text-heading`），而不是值名称（`--font-16`）
- 设置 `font-kerning: normal` 并在适当的地方考虑OpenType功能

### 重量一致性

- 为每个重量定义明确的角色并坚持
- 不要使用超过3-4个重量（常规、中等、半粗体、粗体就足够了）
- 只加载你实际使用的重量（每个重量都会增加页面加载）

**永远不要**：
- 使用超过2-3个字体家族
- 随意选择尺寸——坚持一个比例
- 将正文设置为低于16px
- 使用装饰/显示字体用于正文
- 禁用浏览器缩放（`user-scalable=no`）
- 使用 `px` 用于字体大小——使用 `rem` 尊重用户设置
- 当个性重要时默认为Inter/Roboto/Open Sans
- 搭配相似的但并不相同的字体（两个几何无衬线字体）

## 验证排版改进

- **层级**：你能瞬间识别标题与正文与副标题吗？
- **可读性**：正文在长段落中是否舒适易读？
- **一致性**：同一角色的元素是否在整个文档中风格一致？
- **个性**：排版是否反映了品牌？
- **性能**：网络字体是否高效加载而不会导致布局偏移？
- **可访问性**：文本是否满足WCAG对比度比率？是否可以缩放到200%？

记住：排版是界面设计的基石——它承载了大部分信息。正确处理排版是你能够做出的最高杠杆改进。
