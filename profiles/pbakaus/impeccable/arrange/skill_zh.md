评估并改进单调、拥挤或结构薄弱的布局和间距——将通用排列转化为有意为之、富有节奏感的构图。

## 评估当前布局

分析当前空间设计存在哪些薄弱之处：

1. **间距**：
   - 间距是否一致或任意？（随机的填充/边距值）
   - 所有间距是否都相同？（所有地方使用相等的填充=没有节奏）
   - 相关元素是否紧密分组，组与组之间有足够的间距？

2. **视觉层次**：
   - 应用眯眼测试：眯起（隐喻性的）眼睛——你仍然能识别出最重要的元素、第二重要的元素和清晰的分组吗？
   - 层次结构是否有效实现？（空间和权重本身可能就足够——但当前方法是否有效？）
   - 空白区域是否引导视线关注重点？

3. **网格与结构**：
   - 是否有清晰的底层结构，还是布局感觉随机？
   - 是否到处都使用相同的卡片网格？（图标+标题+文本，无休止地重复）
   - 所有内容是否居中？（左对齐的非对称布局感觉更设计感，但不是硬性规则）

4. **节奏与多样性**：
   - 布局是否有视觉节奏？（交替紧凑/宽松的间距）
   - 每个部分的结构是否都相同？（单调重复）
   - 是否有有意为之的惊喜或强调时刻？

5. **密度**：
   - 布局是否过于拥挤？（没有足够的呼吸空间）
   - 布局是否过于稀疏？（没有目的的过多空白）
   - 密度是否与内容类型匹配？（数据密集型 UI 需要更紧凑的间距；营销页面需要更多空间）

**关键**：布局问题往往是导致界面即使颜色和字体都很好看时感觉“不对劲”的根本原因。空间是一种设计材料——有目的地使用它。

## 规划布局改进

参考 `impeccable` 技能中的 [空间设计参考](reference/spatial-design.md) 获取关于网格、节奏和容器查询的详细指导。

创建系统化计划：

- **间距系统**：使用一致的尺度——无论是框架的内置尺度（例如，Tailwind）、基于 rem 的令牌，还是自定义系统。具体值不如一致性重要。
- **层次策略**：空间将如何传达重要性？
- **布局方法**：什么结构适合内容？Flex 用于 1D，Grid 用于 2D，命名区域用于复杂页面布局。
- **节奏**：间距应该在何处紧凑，何处宽松？

## 系统性地改进布局

### 建立间距系统

- 使用一致的间距尺度——框架尺度（Tailwind 等）、基于 rem 的令牌或自定义尺度都行。重要的是值来自定义集合，而不是任意数字。
- 如果使用自定义属性，请语义化命名令牌：`--space-xs` 通过 `--space-xl`，而不是 `--spacing-8`
- 使用 `gap` 而不是边距进行同级间距——消除边距折叠技巧
- 使用 `clamp()` 实现在大屏幕上呼吸的流体间距

### 创建视觉节奏

- **紧凑分组**用于相关元素（兄弟之间 8-12px）
- **宽松分隔**用于不同部分之间（48-96px）
- **部分内间距多样化**——不是每一行都需要相同的间隙
- **非对称构图**——当有意义时，打破可预测的居中内容模式

### 选择合适的布局工具

- **使用 Flexbox 进行 1D 布局**：项目行、导航栏、按钮组、卡片内容、大多数组件内部。Flex 更简单，更适合大多数布局任务。
- **使用 Grid 进行 2D 布局**：页面级结构、仪表板、数据密集型界面、任何需要行和列协调控制的场景。
- **不要默认使用 Grid**，当使用带 `flex-wrap` 的 Flexbox 更简单、更灵活时。
- 使用 `repeat(auto-fit, minmax(280px, 1fr))` 实现无断点的响应式网格。
- 使用命名网格区域（`grid-template-areas`）进行复杂页面布局——在断点处重新定义。

### 打破卡片网格单调性

- 不要默认将所有内容都使用卡片网格——间距和对齐自然会创建视觉分组
- 仅在内容真正独特且可操作时使用卡片——永远不要将卡片嵌套在卡片内
- 变化卡片大小、跨列或混合卡片与非卡片内容以打破重复

### 加强视觉层次

- 使用最少数量的维度实现清晰的层次结构。空间本身可能就足够——元素周围的空白区域会吸引视线。一些最复杂的设计仅通过空间和权重就实现了节奏。只有当更简单的方法不够用时，才添加颜色或大小对比。
- 注意阅读流程——在从左到右的语言中，视线自然地从左上到右下扫描，但主要操作位置取决于上下文（例如，对话框右下角，导航顶部）。
- 通过邻近性和分隔创建清晰的内容分组。

### 管理深度与提升

- 创建一个语义 z-index 尺度（下拉菜单 → 粘性 → 模态背景 → 模态 → 提示 → 工具提示）
- 建立一致的阴影尺度（sm → md → lg → xl）——阴影应该是微妙的
- 使用提升来加强层次结构，而不是作为装饰

### 光学调整

- 如果图标在几何中心但视觉上感觉偏离中心，可以微调它——但只有在你确信它确实看起来错误时才这样做。不要推测性地调整。

**永远不要**：
- 使用自定义尺度之外的任意间距值
- 使所有间距相等——多样性创造层次结构
- 将所有内容都包裹在卡片内——不是所有内容都需要容器
- 将卡片嵌套在卡片内——使用间距和分隔符在内部建立层次结构
- 到处使用相同的卡片网格（图标+标题+文本，重复）
- 将所有内容居中——左对齐的非对称感更设计感
- 默认使用英雄指标布局（大数字、小标签、统计数据、渐变）作为模板。如果显示真实用户数据，突出显示的指标可以起作用——但它应该显示实际数据，而不是装饰性数字。
- 默认使用 CSS Grid，当 Flexbox 更简单时——为工作选择最简单的工具
- 使用任意 z-index 值（999、9999）——建立语义尺度

## 验证布局改进

- **眯眼测试**：你能用模糊的视线识别出主要、次要和分组吗？
- **节奏**：页面是否有令人满意的紧凑和宽松间距的节拍？
- **层次结构**：最重要的内容在 2 秒内是否显而易见？
- **呼吸空间**：布局是否感觉舒适，而不是拥挤或浪费？
- **一致性**：间距系统是否均匀应用？
- **响应性**：布局是否在各种屏幕尺寸上优雅地适应？

记住：空间是最未被充分利用的设计工具。具有正确节奏和层次结构的布局可以使简单内容看起来更精致和有意为之。
