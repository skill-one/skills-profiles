# 动画术语

## 初始响应

当这个技能首次被调用且没有具体问题时，仅响应：

> 我可以为你描述的任何运动效果命名，我的知识来源于 Emil Kowalski 的动画哲学。

在用户提问之前，不要提供任何其他信息。

将运动或效果的模糊描述转换为精确术语，以便用户知道如何提问。

## 快速入门

用户松散地描述一个效果。你以以下格式返回匹配的术语：

```
**错开** — 以每个项目之间有微小延迟的方式依次动画多个项目，创建级联效果。
```

如果有多个术语可能适用，首先列出最佳匹配项，然后列出 1-2 个备选项，并附上一行说明它们如何不同。

## 指令

1. **意图优先，而非关键词。** 用户描述他们 *看到* 或 *感受到* 的内容（“弹簧般”、“滑落”、“自行绘制”），而不是技术名称。将感觉映射到下面的词汇表中。
2. **逐字引用词汇表。** 其描述具有权威性——使用它们时保持原样，不要释义。
3. **区分相近术语。** 当两个术语竞争时（*路径裁剪* 对 *遮罩*、*弹出* 对 *弹跳*、*共享元素过渡* 对 *布局动画*），进行对比，以便用户选择。
4. **当没有任何术语完全匹配时，** 命名最接近的术语，并明确说明这是一个近似值，或者用词汇表中的词汇描述该效果（例如，“那是一个 *错开* 的 *缩放* 进入”）。
5. **坚持这个词汇表。** 如果一个术语确实不在这里，请这样说，而不是编造一个——尽管你可以用这些词汇解释这个概念。
6. **保持简洁。** 一个命名问题需要一个名称，而不是一篇论文。首先提供术语；只有在提问时才扩展。

## 示例

**示例 1 — 基于感觉**
用户：“当弹出框似乎从您点击的按钮而不是其中心生长出来时，这是什么效果？”
输出：
```
**源感知动画** — 元素从其触发器动画，例如弹出框从打开它的按钮而不是其自己的中心生长出来，而默认的 CSS 是从其自己的中心生长出来。
```

**示例 2 — 区分**
用户：“一个图像变成另一个图像的东西。”
输出：
```
**变形** — 一个形状平滑地变成另一个形状，例如 Dynamic Island。

相近备选项：
- **交叉淡入淡出** — 如果它们在同一位置简单地相互淡入淡出。
- **共享元素过渡** — 如果一个元素从一个位置移动并变形到另一个位置。
```

**示例 3 — 物理感觉**
用户：“那种 iOS 滚动效果，当您拉得太远时会抵抗并弹回。”
输出：
```
**弹性效果** — 当您拖动超出边界时的抵抗和弹回（iOS 超滚动感觉）。
```

## 词汇表

一个精心挑选的快照，反映了项目的 `/vocabulary` 页面；当其中任何一个更改时，请保持这两个页面同步。

### 进入和退出 — 元素如何出现和消失
- **淡入 / 淡出** — 元素通过改变不透明度出现或消失。
- **滑入** — 元素从屏幕外滑入（左、右、上或下）进入。
- **缩放进入** — 元素在出现时从小尺寸增长到完整尺寸，通常与淡入搭配使用。
- **弹出** — 元素以轻微的过冲出现，就像它弹入位置一样。
- **揭示** — 内容逐渐被揭示，通常通过动画路径裁剪或遮罩。
- **进入 / 退出** — 元素添加到或从屏幕上移除时播放的动画。

### 序列和计时 — 协调多个元素或时刻
- **关键帧** — 动画中的定义点（0%、50%、100%），浏览器填充这些点之间的空白。
- **插值 / 插值** — 在起始值和结束值之间生成所有中间帧，使运动连续。
- **错开** — 以每个项目之间有微小延迟的方式依次动画多个项目，创建级联效果。
- **编排** — 故意计时多个动画，使它们感觉像协调的运动。
- **延迟** — 动画开始前的时间。
- **持续时间** — 动画需要多长时间。
- **填充模式** — 元素在动画开始前或结束后是否保持其第一帧或最后一帧的样式（例如，向前）。
- **阶梯动画** — 被分成离散步骤的动画，例如倒计时计时器。

### 运动和变换 — 改变元素的位置、大小或角度
- **平移** —沿 X 或 Y 轴移动元素。
- **缩放** — 使元素变大或变小。
- **旋转** — 围绕一个点旋转元素。
- **倾斜** — 沿 X 或 Y 轴斜切元素，将其从矩形形状中剪切出来。
- **3D 倾斜 / 翻转** — 在 3D 空间中旋转（rotateX / rotateY）以增加深度。
- **透视** — 3D 效果看起来有多强——较低的值会夸张深度，就像观众更近一样。
- **变换原点** — 缩放或旋转增长或旋转的锚点。
- **源感知动画** — 元素从其触发器动画，例如弹出框从打开它的按钮而不是其自己的中心生长出来，而默认的 CSS 是从其自己的中心生长出来。

### 状态之间的过渡 — 连接一个状态、视图或元素到另一个状态、视图或元素
- **交叉淡入淡出** — 一个元素淡出时，另一个元素在同一位置淡入。
- **连续过渡** — 一个保持用户方向的变化，通过视觉连接前后。例如，使同一个矩形变大变小。
- **变形** — 一个形状平滑地变成另一个形状，例如 Dynamic Island。
- **共享元素过渡** — 一个元素从一个位置移动并变形到另一个位置，例如缩略图扩展成卡片。
- **布局动画** — 当元素的大小或位置发生变化时，它会动画到新位置而不是直接跳转。
- **手风琴 / 折叠** — 一个部分平滑地扩展和折叠其高度以显示或隐藏内容。
- **方向感知过渡** — 内容向前滑动一个方向，向后滑动相反方向，以便导航具有方向感。

### 滚动 — 与滚动或在不同视图之间导航相关的运动
- **滚动揭示** — 元素在进入视口时淡入或滑入位置。
- **滚动驱动动画** — 其进度直接与滚动位置相关的动画。
- **视差** — 背景和前景在滚动时以不同的速度移动，创建深度。
- **页面过渡** — 在从一页或路由导航到另一页时播放的动画。
- **视图过渡** — 浏览器在两个状态或页面之间变形，连接共享元素。

### 反馈和交互 — 对用户操作的响应
- **悬停效果** — 当光标移动到元素上时的视觉变化。
- **按 / 点击反馈** — 当元素被点击时轻微缩放，使其感觉有物理性。
- **按住以确认** — 在用户按住按钮时填充的进度效果。
- **拖动** — 通过抓取移动元素，释放时通常带有动量。
- **拖动以重新排序** — 拖动列表中的项目以重新排序，而其他项目移动以腾出空间。
- **滑动以关闭** — 将元素拖出屏幕以关闭它，就像抽屉或提示。
- **弹性效果** — 当您拖动超出边界时的抵抗和弹回（iOS 超滚动感觉）。
- **摇晃 / 摇摆** — 快速的左右抖动，表示错误或拒绝的输入。
- **涟漪** — 从点击点扩大的圆形，确认点击。

### 缓动 — 动画过程中速度的变化
- **缓动** — 动画加速或减速的速率。
- **缓出** — 开始快，结束慢。大多数 UI 和任何响应用户的内容的默认值。
- **缓入** — 开始慢，结束快。通常避免；可能会感觉迟钝。
- **缓入缓出** — 慢，快，慢。适用于屏幕上已经存在的元素从 A 到 B 的移动。
- **线性** — 恒定速度。避免用于 UI；保留用于旋转器或滚动字幕。
- **三次贝塞尔曲线** — 您定义的用于精确控制的自定义缓动曲线。
- **非对称缓动** — 一个加速和减速速率不同的曲线。感觉比对称的更生动。

### 弹簧动画 — 作为固定持续时间缓动的替代方案的基于物理的运动
- **弹簧** — 由物理（张力、质量、阻尼）驱动的运动，而不是固定持续时间。
- **刚度 / 张力** — 弹簧向目标拉扯的强度。更高的感觉更响亮。
- **阻尼** — 弹簧稳定所需的时间。较低的阻尼意味着更多的弹跳和振荡。
- **质量** — 动画元素感觉有多重。更多的质量使其更慢、更迟钝。
- **弹跳** — 一个过冲并稳定的弹簧，增加趣味性。
- **感知持续时间** — 弹簧感觉完成的时间，即使它仍在下面进行微小的稳定。
- **动量** — 运动携带速度，尤其是在拖动或中断后。
- **速度** — 元素移动有多快以及哪个方向。弹簧在中断时将其传递到下一个动画，因此被弹开的元素保持其速度。
- **可中断动画** — 可以在飞行中平滑重定向的动画，而不是首先完成。

### 循环和环境运动 — 自己运行的动画
- **滚动字幕** — 文本或内容在循环中连续滚动。
- **循环** — 重复的动画，次数固定或无限。
- **交替（yo yo）** — 每次迭代播放向前然后反转的循环，而不是跳回开始。
- **轨道** — 元素在另一个元素周围沿连续路径循环。
- **脉冲** — 轻柔的重复缩放或不透明度变化以吸引注意力。
- **漂浮** — 轻柔的连续上下漂浮，使静态元素感觉生动且无重量。
- **空闲动画** — 在元素只是坐着等待交互时播放的微妙运动。

### 精致和效果 — 将好与区分开来的小细节
- **模糊** — 用于柔化元素或掩盖微小缺陷的模糊滤镜。
- **路径裁剪** — 将元素裁剪到形状，用于揭示、遮罩和前后滑动器。
- **遮罩** — 使用形状或渐变隐藏或揭示元素的一部分——就像路径裁剪，但边缘柔和、可淡入淡出。
- **前后滑动器** — 可拖动的分隔符，在两个叠加的图像之间滑动以比较它们。
- **线条绘制** — 自己绘制的 SVG 路径，就像一个看不见的笔迹。
- **文本变形** — 文本在更改时逐个字符动画，吸引对新值的注意力。
- **骨架 / 闪烁** — 在内容加载时显示的带有移动光泽的占位符。
- **数字滚动器** — 数字滚动或计数到值。
- **表格数字** — 固定宽度的数字，以便数字在变化时不移动。对于滚动器、计时器和计数器至关重要。
- **打字机** — 文本逐个字符出现，就像被键入一样。

### 性能 — 使运动平滑而不是卡顿的因素
- **帧率（FPS）** — 每秒绘制的帧数。60fps 是平滑运动的基本线；120fps 是在较新的显示器上。
- **卡顿** — 浏览器因为无法跟上动画而掉帧时出现的可见卡顿。
- **掉帧** — 浏览器错过了绘制帧的截止日期，导致运动中的微小卡顿。
- **合成** — 让 GPU 在自己的层上移动或淡入元素，而无需重新计算布局或绘制。
- **will-change** — 一个 CSS 提示，表示一个元素即将动画，因此浏览器可以提前将其提升到自己的层。
- **布局抖动** — 动画宽度、高度、顶部或左边的属性，迫使浏览器每帧重新计算布局，导致卡顿。

### 需要了解的原则 — 指导何时以及如何动画的概念
- **有目的的动画** — 运动应该服务于一个功能——定向、提供反馈、显示关系——而不仅仅是装饰。
- **预期** — 在移动前在相反方向上的一个小预拉，暗示即将发生的事情。
- **跟随** — 元素的一部分在主运动停止后继续移动并稍微稳定，增加重量。
- **挤压和拉伸** — 在移动时变形元素，以传达重量、速度和灵活性。
- **感知性能** — 正确的动画使界面感觉更快，即使它不是这样。
- **使用频率** — 用户看到动画越频繁，它应该越短、越微妙。
- **空间一致性** — 动画以便元素保持其身份和位置跨状态，以便用户永远不会失去跟踪它们去哪里。
- **硬件加速** — 动画变换和不透明度让 GPU 保持运动平滑。
- **减少运动** — 尊重用户的 `prefers-reduced-motion` 设置，通过降低或删除运动。
