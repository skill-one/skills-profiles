# 动画词汇

## 初始响应

当此技能在没有具体问题的情况下被首次调用时，仅回复以下内容：

> 我已准备好为您描述的任何动作效果命名，我的知识源自 Emil Kowalski 的动画理念。

在用户提问之前，不要提供任何其他信息。

## 快速开始

用户粗略描述一个效果。按照以下格式返回匹配的术语（如有）：

```
**Stagger** — 依次动画多个元素，每个元素之间留有短暂延迟，形成级联效果。
```

如果多个术语都符合，先列出最佳匹配，再列出 1–2 个替代方案，并附上说明它们差异的简短备注。

## 说明

1. **理解意图，而非关键词。** 用户描述的是他们*看到或感受到*的内容（如“有弹性”、“滑出”、“自行入画”），而非技术名称。将这种感受映射到下方的词汇表中。
2. **逐字引用词汇表。** 其描述具有权威性——请原样使用，不要进行改写。
3. **辨析易混淆的术语。** 当两个术语相互竞争（*Clip-path* 与 *Mask*、*Pop in* 与 *Bounce*、*Shared element transition* 与 *Layout animation*）时，进行对比，以便用户做出选择。
4. **若完全无匹配项时**，指出最接近的术语，并明确说明这是近似表述，或者在词汇表的词汇范围内描述该效果（例如“这就是一组 *scale-in* 的 *stagger* 入场效果”）。
5. **限定在本词汇表内。** 若某术语确实不在本表内，应明确说明，而非自行创造——不过您可以使用这些词汇来解释该概念。
6. **保持简洁。** 命名问题只需要一个名称，而非长篇大论。以术语开头，仅在用户要求时进行展开。

## 示例

**示例 1 — 基于感受**
用户：“弹出层似乎从点击的按钮中生长出来，而不是从它的中心（这是 CSS 的默认设置）产生的，这种效果叫什么？”
输出：
```
**Origin-aware animation** — 元素从其触发器处动画出场，例如弹出层从打开它的按钮中生长出来，而非从自身的中心（这是 CSS 的默认设置）出场。
```

**示例 2 — 辨析**
用户：“那种一个图像变成另一个图像的效果。”
输出：
```
**Morph** — 一个形状平滑地转变为另一个形状，例如 Dynamic Island。

容易混淆的替代项：
- **Crossfade** — 如果它们在同一位置互相淡入淡出。
- **Shared element transition** — 如果元素从一个位置移动并变形至另一个位置。
```

**示例 3 — 基于物理感受**
用户：“那种在拉得太远时会产生阻力并回弹的 iOS 滚动效果。”
输出：
```
**Rubber-banding** — 拖拽越过边界时产生的阻力与回弹效果（即 iOS 的过度滚动感受）。
```

## 词汇表

_一份精选快照，镜像项目的 `/vocabulary` 页面；当任一方发生变更时，保持两者同步。_

### 进入与退出 — 元素出现与消失的方式
- **Fade in / Fade out** — 元素通过改变不透明度出现或消失。
- **Slide in** — 元素从屏幕外（左、右、上或下）滑入进入。
- **Scale in** — 元素出现时从较小尺寸扩展到完整尺寸，通常与淡入搭配使用。
- **Pop in** — 元素出现时带有轻微过冲，如同弹入原位般的效果。
- **Reveal** — 内容通过逐渐展示的方式显现，通常通过动画化 clip-path 或 mask 实现。
- **Enter / Exit** — 元素被添加到屏幕或从屏幕移除时播放的动画。

### 序列与 timing — 协调多个元素或时间点
- **Keyframes** — 动画中定义的点（0%、50%、100%），浏览器会填充这些点之间的间隙。
- **Interpolation / Tween** — 生成起始值与结束值之间的所有中间帧，使运动连续。
- **Stagger** — 依次动画多个元素，每个元素之间留有短暂延迟，形成级联效果。
- **Orchestration** — 有意识地安排多个动画的时序，使它们看起来像一场协调一致的动作。
- **Delay** — 动画开始前的时间。
- **Duration** — 动画持续的时间长度。
- **Fill mode** — 动画开始前或结束后，元素是否保持第一帧或最后一帧的样式（例如 forwards 模式）。
- **Stepped animation** — 被划分为离散步骤的动画，如倒计时计时器。

### 移动与变换 — 改变元素的位、置、尺寸或角度
- **Translate** — 沿 X 或 Y 轴移动元素。
- **Scale** — 使元素变大或变小。
- **Rotate** — 围绕一个点旋转元素。
- **Skew** — 沿 X 或 Y 轴倾斜元素，将其剪切变形，偏离矩形形状。
- **3D tilt / Flip** — 在 3D 空间（rotateX / rotateY）中旋转，以增加深度。
- **Perspective** — 3D 效果看起来有多强烈的程度——数值越低，深度感越夸张，仿佛观众离得越近。
- **Transform origin** — 缩放或旋转时，大小或角度扩展或旋转的锚点。
- **Origin-aware animation** — 元素从其触发器处动画出场，例如弹出层从打开它的按钮中生长出来，而非从自身的中心（这是 CSS 的默认设置）出场。

### 状态、视图或元素之间的转换 — 将一种状态、视图或元素连接至另一种
- **Crossfade** — 一个元素淡出时，另一个元素在同一位置淡入。
- **Continuity transition** — 通过视觉连接前后，保持用户对场景的方位感的变化。例如，将同一个矩形放大再缩小。
- **Morph** — 一个形状平滑地转变为另一个形状，例如 Dynamic Island。
- **Shared element transition** — 元素从一个位置移动并变形至另一个位置，例如缩略图扩展为卡片。
- **Layout animation** — 当元素的尺寸或位置发生变化时，它动画至新位置，而非瞬间切换。
- **Accordion / Collapse** — 某部分通过平滑展开和折叠其高度来展示或隐藏内容。
- **Direction-aware transition** — 内容向前滑动时沿一个方向，回退时沿相反方向滑动，从而使导航具有方向感。

### 滚动 — 与滚动或在不同视图间导航相关联的运动
- **Scroll reveal** — 元素进入视口时淡入或滑入到正确位置。
- **Scroll-driven animation** — 动画的进度直接与滚动位置绑定。
- **Parallax** — 滚动时背景和前景以不同速度移动，从而创造深度感。
- **Page transition** — 从某一页面或路由导航至另一页面或路由时播放的动画。
- **View transition** — 浏览器在两种状态或页面之间进行变形，连接共享元素。

### 反馈与交互 — 响应用户操作
- **Hover effect** — 光标在元素上移动时产生的视觉变化。
- **Press / Tap feedback** — 元素被点击时产生的轻微缩小，使其具有物理质感。
- **Hold to confirm** — 用户在按住按钮时填充进度的确认效果。
- **Drag** — 抓取并移动元素，释放时通常带有惯性。
- **Drag to reorder** — 在列表中拖动项目进行重排，其他项目会移动以让出空间。
- **Swipe to dismiss** — 将元素拖出屏幕以关闭它，类似抽屉或提示框。
- **Rubber-banding** — 拖拽越过边界时产生的阻力与回弹效果（即 iOS 的过度滚动感受）。
- **Shake / Wiggle** — 快速左右抖动，以表示错误或未通过输入。
- **Ripple** — 从点击位置扩大的圆形，以确认按压。

### Easing — 动画过程中速度如何变化
- **Easing** — 动画加速或减速的速率。
- **Ease-out** — 开始快，结束慢。大多数 UI 及所有响应用户操作的默认设置。
- **Ease-in** — 开始慢，结束快。通常不建议使用；可能显得拖沓。
- **Ease-in-out** — 慢、快、慢。适用于已在屏幕上从 A 处移动到 B 的元素。
- **Linear** — 恒定速度。避免用于 UI；预留给旋转器或滚动条。
- **Cubic-bezier** — 用于精确控制的自定义缓动曲线。
- **Asymmetric easing** — 加速和减速速率不同的曲线。比对称曲线更生动。

### 弹簧动画 — 基于物理的运动，作为固定时长缓动的替代方案
- **Spring** — 由物理（张力、质量、阻尼）驱动的运动，而非设定时长。
- **Stiffness / Tension** — 弹簧向目标位置拉扯的强烈程度。数值越高，感觉越干脆。
- **Damping** — 弹簧收敛的速度。阻尼越低，弹跳和振荡越明显。
- **Mass** — 被动画化元素感觉有多重。质量越大，运动越慢且越拖沓。
- **Bounce** — 一种会过冲后落定的弹簧，增添了趣味性。
- **Perceptual duration** — 弹簧感觉完成的时间，尽管其底层仍有微小的持续收定。
- **Momentum** — 带有动量的运动，尤其在拖拽或中断后。
- **Velocity** — 元素移动的速度和方向。弹簧在被打断时将其带入下一个动画，因此被轻甩的元素会保持其速度。
- **Interruptible animation** — 可以在飞行中途平滑转向，而非优先完成自身的动画。

### 循环与环境动画 — 独立运行的动画
- **Marquee** — 文本或内容循环不间断地滚动。
- **Loop** — 重复播放的动画，可重复设定次数或无限次。
- **Alternate (yoyo)** — 每次迭代先正向播放再反向播放的循环，而非跳回起点。
- **Orbit** — 元素围绕另一个元素在连续路径上做圆周运动。
- **Pulse** — 柔和重复的缩放或不透明度变化，以吸引注意。
- **Float** — 柔和且连续的上下漂浮，使静态元素显得生动且具有轻盈感。
- **Idle animation** — 元素静止不动、等待交互时播放的微妙运动。

### 打磨与效果 — 将优良与卓越区分开来的细微细节
- **Blur** — 用于柔化元素或遮掩微小瑕疵的模糊滤镜。
- **Clip-path** — 将元素裁剪为指定形状，用于显现、遮罩以及前后对比滑块。
- **Mask** — 使用形状或渐变隐藏或显露元素的某部分——类似 clip-path，但带有柔和、可淡入淡出的边缘。
- **Before / after slider** — 一个可拖拽的分隔线，在两张叠加图片之间滑动以进行对比。
- **Line drawing** — 一条自行绘制的 SVG 路径，如同隐形画笔在勾勒它。
- **Text morph** — 文本在变化时逐字符动画，将注意力引向新值。
- **Skeleton / Shimmer** — 内容加载时显示、带有移动光晕的占位符。
- **Number ticker** — 数字滚动或计数至某个数值。
- **Tabular numbers** — 固定宽度的数字，使数字在变化时不会发生位移。对于滚动条、计时器和计数器至关重要。
- **Typewriter** — 文本逐字符出现，如同正在打字一般。

### 性能 — 确保运动流畅而非卡顿的因素
- **Frame rate (FPS)** — 每秒绘制的帧数。60fps 是流畅运动的基准，新一代显示器的流畅动效可达 120fps。
- **Jank** — 浏览器因无法跟上动画的节奏而掉帧时出现的明显卡顿。
- **Dropped frame** — 浏览器未能按时绘制的一帧，导致运动出现微小的卡顿。
- **Compositing** — 让 GPU 在独立图层上移动或淡出元素，而无需重新计算布局或重绘。
- **will-change** — 一个 CSS 提示，表明元素即将进行动画，以便浏览器能提前将其提升到独立图层。
- **Layout thrashing** — 对宽度、高度、top 或 left 等属性进行动画，强制浏览器每帧重新计算布局，导致卡顿。

### 需了解的原则 — 指导何时以及如何进行动画的概念
- **Purposeful animation** — 运动应服务于某种功能——引导方向、提供反馈、展现关系——而不仅仅是装饰。
- **Anticipation** — 在动作发生前，向相反方向做一次小的预运动，暗示即将发生的动作。
- **Follow-through** — 元素的主要运动停止后，其部分会继续运动并微调落下，增添重量感。
- **Squash & stretch** — 在元素移动时对其进行变形，以传达重量、速度和灵活性。
- **Perceived performance** — 合适的动画能让界面感觉更快速，即便其实际性能并非如此。
- **Frequency of use** — 用户看到动画的次数越多，该动画应越短且越细微。
- **Spatial consistency** — 在动画中确保元素在各状态下保持其身份和位置，使用户永远不会弄丢事物的位置。
- **Hardware acceleration** — 对 transform 和 opacity 进行动画，让 GPU 保持运动流畅。
- **Reduced motion** — 根据用户的 `prefers-reduced-motion` 设置，降低或移除运动。
