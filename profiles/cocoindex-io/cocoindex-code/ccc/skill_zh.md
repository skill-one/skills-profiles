# ccc - 语义代码搜索与索引

`ccc` 是 CocoIndex 代码的命令行工具，提供对当前代码库的语义搜索和索引管理功能。

## 所有权

代理负责当前项目的 `ccc` 生命周期——包括初始化、索引和搜索。不要要求用户执行这些步骤；应自动处理它们。

- **初始化**：如果 `ccc search` 或 `ccc index` 因初始化错误失败（例如，“不在已初始化的项目目录中”），请从项目根目录运行 `ccc init`，然后运行 `ccc index` 构建索引，最后重试原始命令。
- **索引新鲜度**：通过在索引可能已过时时运行 `ccc index`（或 `ccc search --refresh`）来保持索引最新——例如，会话开始时，或在进行重大代码更改（新文件、重构、重命名模块）后。如果连续搜索之间没有更改代码，则无需重新索引。
- **安装**：如果找不到 `ccc` 命令（命令未找到），请参考 [management.md](references/management.md) 中的安装说明并通知用户。

## 搜索代码库

执行语义搜索：

```bash
ccc search <查询词>
```

查询应描述要查找的概念、功能或行为，而不是确切的代码语法。例如：

```bash
ccc search 数据库连接池
ccc search 用户身份验证流程
ccc search 错误处理重试逻辑
```

### 过滤结果

- **按语言** (`--lang`，可重复）：将结果限制为特定语言。

  ```bash
  ccc search --lang python --lang markdown 数据库模式
  ```

- **按路径** (`--path`)：将结果限制为相对于项目根目录的通配符模式。如果省略，则默认为当前工作目录（仅返回该子目录下的结果）。

  ```bash
  ccc search --path 'src/api/*' 请求验证
  ```

### 分页

结果默认为第一页。要检索更多结果：

```bash
ccc search --offset 5 --limit 5 数据库模式
```

如果所有返回的结果看起来都相关，请使用 `--offset` 获取下一页——第一页之外很可能还有更多有用的匹配项。

### 处理搜索结果

搜索结果包括文件路径和行范围。要更详细地查看结果：

- 使用编辑器内置的文件读取功能（例如，`Read` 工具）加载匹配的文件并读取返回范围内的行以获取完整上下文。
- 在没有文件读取工具的终端中，使用 `sed -n '<开始>,<结束>p' <文件>` 提取特定行范围。
