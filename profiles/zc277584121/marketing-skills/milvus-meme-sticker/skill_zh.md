# Milvus表情贴纸

为技术营销场景创作原创贴纸风格表情包。输出效果应像开发者微信群中会发送的内容：紧凑、富有表现力、幽默、能引起情感共鸣，且安全可发布，因为它不重复使用现有表情包模板、名人、截图、动漫或其他知识产权。

在会话中生成第一个贴纸前，请阅读`references/style-guide.md`。

## 工作流程

1. 从源段落或用户请求中识别情绪：不知所措、困惑、如释重负、自豪、震惊、筋疲力尽，或“为什么这么难？”。
2. 除非用户要求具体方向，否则先生成三个方形变体。
3. 使用抽象的Milvus鸟/鹰吉祥物作为 recurring 角色，而不是复制官方标志。
4. 保持图像无文字。无标题、标签、字母、UI文字、假代码片段或带文字的对话框。
5. 偏爱紧凑的贴纸构图，具有清晰的轮廓和大而可读的面部表情。
6. 将最佳或选定的源图像以高分辨率保存，然后运行`scripts/resize_sticker.py`导出真实贴纸尺寸。
7. 插入或交付小型导出图像，而不仅仅是大型生成图像。

## 提示规则

使用类似这样的提示，仅调整情绪和场景：

```text
方形1:1贴纸风格表情包插图，无文字，无字母，无标题。
受Milvus类鸟/鹰启发的抽象吉祥物，简化且不复制任何具体标志。角色身体轻盈，仅部分带有柔和的蓝色点缀，喙和口部非蓝色，超大表现力眼睛，以及搞笑夸张的[EMOTION]表情。

场景：[SCENE]。开发者群聊贴纸氛围，手绘，粗犷干净的轮廓，白色贴纸边框，紧凑构图在小尺寸下可读。
使用浅蓝色点缀调色板，搭配彩色次要点缀；不要让整个角色都变成蓝色。无真实品牌，无现有表情包模板，无名人，无截图，无IP角色，无任何文字。
```

## 风格规范

- 保持吉祥物抽象：鸟/鹰启发，圆润的贴纸风格，不是写实动物，也不是任何官方标志的复制。
- 使用浅蓝色作为点缀，而不是全身涂满。避免蓝色牙齿、蓝色口腔内部或失去表情的全蓝色脸。
- 使喙、口部、眼睛、汗水及情绪标记在颜色和明暗上清晰区分。
- 偏爱富有表现力的面部和身体姿态，而非详细道具。
- 仅在解释痛点时使用道具：文档、连接器插头、数据库圆筒、云存储桶、聊天气泡、票证、代码括号。
- 避免文字，因为此贴纸必须跨越语言并在微小尺寸下保持可读性。
- 避免照片写实、3D玩具渲染、光泽吉祥物品牌和精炼的企业插画。它应该感觉像手绘的贴纸表情包。

## 小尺寸导出

生成图像通常太大，不够像真实贴纸。生成后始终创建小型衍生品：

```bash
python3 scripts/resize_sticker.py path/to/source.png --out-dir path/to/output-dir
```

默认创建：

- `512x512` 用于文章插入，当某些细节应保持可见时。
- `240x240` 用于微信风格贴纸主图像比例。
- `120x120` 用于缩略图检查。
- `50x50` 用于微小面板可读性检查。

使用在上下文中仍可读的最小版本。对于Markdown文章，优先选择`240x240`或`512x512`，如有必要，可添加明确的显示尺寸。

## 质量检查

在展示最终结果前，检查图像并验证：

- 无可见文字或伪文字。
- 吉祥物并非全蓝色。
- 嘴巴、喙、眼睛和表情可读。
- 情绪在`240x240`尺寸下依然明显。
- 贴纸轮廓紧凑，不过于杂乱。
- 图像不类似已知表情包模板、名人、动漫或现有IP角色。
