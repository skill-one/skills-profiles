# 技能：原始视频处理

对原始屏幕录制视频进行后处理以改善节奏——移除静音片段，然后加速处理结果。

> **前提条件**：必须安装 FFmpeg 和 uv。

---

## 使用场景

用户录制了屏幕录制视频，并在发布前希望对其进行清理。原始录制中常见的问题：
- 长暂停/死寂，用于思考或等待加载
- 键盘敲击声和其他应视为静音的低级背景噪音
- 整体节奏感觉缓慢，可以通过轻微加速来改善

---

## 默认工作流程

当用户提供原始视频文件时，默认按顺序运行以下脚本：

### 第一步：移除静音片段

```bash
uv run --python 3.12 /path/to/skills/raw-video-processing/scripts/remove_silence.py <input.mp4> -t="-20dB" -d 0.5
```

此脚本检测并剪切静音部分（包括键盘声音），生成 `<input>_nosilence.mp4`。

**始终传递这些参数**（针对包含键盘噪音的屏幕录制进行调优）：
- `-t="-20dB"` — 侵略性阈值，过滤掉键盘敲击声和背景噪音（使用 `=` 语法以避免 argparse 将负值视为标志）
- `-d 0.5` — 移除短静音（最小 0.5 秒）
- `-p 0.2` — 保留语音边界周围的呼吸空间（默认，通常无需传递）

脚本会打印详细摘要：发现的静音片段数量、移除的总静音量，以及所有保留片段的带时间戳信息。查看此输出以确认结果看起来合理。

### 第二步：加速视频

```bash
uv run --python 3.12 /path/to/skills/raw-video-processing/scripts/speed_video.py <input>_nosilence.mp4
```

此脚本对移除静音的视频应用速度倍数，生成 `<input>_nosilence_1.2x.mp4`。

**默认参数**：
- `--speed 1.2` — 1.2 倍播放速度（微妙的提升，不会感觉仓促）

---

## 脚本选项

### remove_silence.py

| 标志 | 默认值 | 描述 |
|------|---------|-------------|
| `-o`, `--output` | `<input>_nosilence.mp4` | 自定义输出路径 |
| `-t`, `--threshold` | `-30dB` | dB 中的静音阈值（越高越侵略性）。**始终使用 `-20dB` 用于屏幕录制** — 传递为 `-t="-20dB"` 以避免 argparse 对负值的问题 |
| `-d`, `--duration` | `0.8` | 要移除的最小静音持续时间（秒）。**使用 `0.5` 用于屏幕录制** |
| `-p`, `--padding` | `0.2` | 保留在非静音片段周围的填充 |
| `--dry-run` | 关闭 | 仅打印检测到的片段，不导出 |

### speed_video.py

| 标志 | 默认值 | 描述 |
|------|---------|-------------|
| `-o`, `--output` | `<input>_<speed>x.mp4` | 自定义输出路径 |
| `-s`, `--speed` | `1.2` | 播放速度倍数 |

---

## 自定义场景

- **仅移除静音** — 仅运行第一步。
- **仅加速** — 直接在输入文件上运行第二步。
- **保守清理** — 如果默认值剪切过多语音，使用 `-t="-30dB" -d 0.8`。
- **额外侵略性清理** — 使用 `-t="-15dB" -d 0.3` 和 `--speed 1.5` 进行最大压缩。
- **提交前预览** — 在 remove_silence.py 上使用 `--dry-run` 以查看将要剪切的内容，而不会创建文件。
- **自定义输出名称** — 在任一脚本上使用 `-o` 控制输出路径。

---

## 重要提示

- 始终在 speed_video **之前** 运行 remove_silence。静音检测基于原始音频；先加速会改变音频特性，使静音检测准确性降低。
- 对于长视频（>30 分钟），静音移除步骤可能需要几分钟，因为它会逐段处理。
- 两个脚本都保留视频质量——remove_silence 使用流复制（无需重新编码），而 speed_video 使用 FFmpeg 默认值重新编码。
