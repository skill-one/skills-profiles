# Uncodixify

这份文档旨在教你如何在构建 UI 时尽可能地避免 Codex 风格。

Codex UI 是默认的 AI 美学风格：柔和的渐变、悬浮的面板、眉形标签、装饰性文案、仪表盘中的英雄区域、过大的圆角、转换动画、戏剧性的阴影以及试图显得过于高端的布局。它是那种会大喊“这是 AI 制作的”的视觉语言，因为它遵循了阻力最小的路径。

这份文件是你的指南，用于打破这种模式。下面列出的所有内容都是 Codex UI 的默认行为。你的任务是识别这些模式，完全避免它们，并构建感觉像人类设计、功能性强且真诚的界面。

当你阅读这份文档时，你正在学习应该避免做什么。被禁止的模式是你的警示信号。正常的实现是你的蓝图。严格遵循它们，你将创建出感觉像 Linear、Raycast、Stripe 或 GitHub 的 UI，而不是另一个通用的 AI 仪表盘。

这就是如何做到 Uncodixify。

## 保持普通（Uncodexy-UI 标准）

- 侧边栏：普通（固定宽度 240-260px，实心背景，简单的右边界框，没有悬浮外壳，没有圆角外边框）
- 头部：普通（简单文本，没有眉形标签，没有大写标签，没有渐变文本，只是 h1/h2 具有正确的层级结构）
- 区域：普通（标准填充 20-30px，仪表盘中没有英雄块，没有装饰性文案）
- 导航：普通（简单链接，微妙的悬停状态，没有转换动画，除非功能性强，否则没有徽章）
- 按钮：普通（实心填充或简单边框，最大半径 8-10px，没有药丸形状，没有渐变背景）
- 卡片：普通（简单容器，最大半径 8-12px，微妙的边框，阴影模糊度超过 8px，没有悬浮效果）
- 表单：普通（标准输入，字段上方有清晰标签，没有花哨的悬浮标签，简单的焦点状态）
- 输入：普通（实心边框，简单焦点环，没有动画下划线，没有变形形状）
- 模态框：普通（居中覆盖层，简单背景，没有滑入动画，直接的关闭按钮）
- 下拉菜单：普通（简单列表，微妙的阴影，没有花哨的动画，清晰的选择状态）
- 表格：普通（干净的行，简单边框，微妙的悬停，除非需要，否则没有斑马条纹，文本左对齐）
- 列表：普通（简单项目，一致间距，没有装饰性圆点，清晰的层级结构）
- 选项卡：普通（简单下划线或边框指示器，没有药丸背景，没有滑动动画）
- 徽章：普通（小文本，简单边框或背景，半径 6-8px，没有光晕，仅在需要时使用）
- 头像：普通（简单圆形或圆角方形，没有装饰性边框，除非功能性强，否则没有状态环）
- 图标：普通（简单形状，一致大小 16-20px，没有装饰性图标背景，单色或微妙颜色）
- 字体排印：普通（系统字体或简单无衬线字体，清晰的层级结构，没有混合衬线/无衬线组合，可读的尺寸 14-16px 正文）
- 间距：普通（一致的比例 4/8/12/16/24/32px，没有随机间隙，没有过度填充）
- 边框：普通（1px 实线，微妙颜色，没有厚重的装饰性边框，没有渐变边框）
- 阴影：普通（微妙的 0 2px 8px rgba(0,0,0,0.1) 最大，没有戏剧性的阴影，没有彩色阴影）
- 过渡：普通（100-200ms 缓动，没有弹跳动画，没有转换效果，简单的透明度/颜色变化）
- 布局：普通（标准网格/弹性布局，没有创意不对称性，可预测的结构，清晰的内容层级结构）
- 网格：普通（一致的列，标准间隙，没有创意重叠，响应式断点）
- 弹性盒：普通（简单对齐，标准间隙，没有创意 justify 伎俩）
- 容器：普通（最大宽度 1200-1400px，居中，标准填充，没有创意宽度）
- 包装器：普通（简单的包含 div，没有装饰性目的，仅功能性强）
- 面板：普通（简单的背景区分，微妙的边框，没有悬浮分离面板，没有玻璃效果）
- 工具栏：普通（简单的水平布局，标准高度 48-56px，清晰的操作，没有装饰性元素）
- 页脚：普通（简单布局，标准链接，没有装饰性区域，最小高度）
- 面包屑：普通（简单带分隔符的文本，没有花哨的样式，清晰的层级结构）

想想 Linear。想想 Raycast。想想 Stripe。想想 GitHub。它们不会试图吸引注意力。它们只是工作。停止装硬汉。做普通 UI。

- 登录页面需要它的区域。如果英雄区域需要完整区域，如果仪表盘需要带有侧边栏和正确布局的完整区域。不要发明新的布局。
- 在你的内部推理中，假装你没有看到这一点，列出你将要做的所有事情，并且不要做它！
- 尝试复制 Figma/Designer 制作的组件，不要自己发明

## 绝对禁止

- 你习惯于做的事情，并且对你来说是基本的“是”。 
- 没有过大的圆角。
- 没有药丸过载。
- 没有作为默认视觉语言的悬浮玻璃形态外壳。
- 没有用于假装品味的柔和公司渐变。
- 没有通用的暗 SaaS UI 组合。
- 没有装饰性侧边栏块。
- 除非明确要求，否则不要“控制室”伪装。
- 不要使用衬线标题 + 系统无衬线字体后备组合作为“高端”的捷径。
- 不要使用 `Segoe UI`、`Trebuchet MS`、`Arial`、`Inter`、`Roboto` 或安全默认堆栈，除非产品已经使用它们。
- 除非信息架构真正需要，否则不要使用粘性左侧轨道。
- 不要将度量卡片网格作为第一直觉。
- 不要使用仅用于填充空间的假图表。
- 不要使用随机的光晕、模糊雾气、磨砂面板或圆锥渐变甜甜圈作为装饰。
- 除非有真实的产品原因，否则不要在内部 UI 中使用“英雄区域”。
- 不要创建死空间的对齐，只是为了看起来昂贵。
- 不要过度填充的布局。
- 不要使手机折叠只是将所有东西堆叠成一个长米色三明治。
- 除非它们来自产品声音，否则不要使用装饰性标签，如“实时脉冲”、“夜间轮班”、“操作员清单”。
- 不要使用通用创业文案。
- 不要因为容易生成而做出的样式决定。

- 任何类型的标题都不允许

```html
<div class="headline">
  <small>团队指令</small>
  <h2>一个地方跟踪今天要紧的事情。</h2>
  <p>
    布局保持严格和可读性：实时项目健康、团队活动
    和近期优先事项，没有通常的仪表盘填充。
  </p>
</div>
```

这是不被允许的。

- 不允许 `<small>` 标题
- 大圆角 `span` 绝对禁止
- 颜色趋向蓝色——**不，不好。** 暗淡的柔和颜色最佳。

- 结构中的任何内容都是**非常大的禁止**。

```html
<div class="team-note">
  <small>专注</small>
  <strong>
    保持更新简短，阻塞可见，下一步行动易于发现。
  </strong>
</div>
```

这一项是**最大的禁止**。


## 特别禁止（基于错误）

- 所有内容的边框半径都在 20px 到 32px 的范围内（到处使用 12px - 太多了）
- 在侧边栏、卡片、按钮和面板上重复相同的圆角矩形
- 侧边栏宽度约为 280px，顶部有品牌块，下方有导航链接（品牌块：248px）
- 悬浮分离的侧边栏带有圆角外壳
- 没有产品特定原因将画布图表放置在玻璃卡片中
- 圆形图表与手波动的百分比配对
- 使用光晕而不是层级的 UI 卡片
- 混合对齐逻辑，其中一些内容紧贴左边缘，而一些内容悬浮在中心块中
- 过度使用柔和的灰蓝色文本，削弱对比度和清晰度
- “高端暗模式”，实际上意味着蓝黑色渐变加上青色点缀（背景中有径向渐变）
- 感觉像模板而不是品牌的 UI 字体排印
- 眉形标签（“3 月快照”大写字母，字母间距）
- 仪表盘中使用英雄区域（有完整的英雄条带和装饰性文案）
- 作为页面标题的装饰性文案，如“操作清晰，没有杂乱”
- 到处解释 UI 做什么的区域笔记和迷你笔记
- 悬停时的转换动画（导航链接上的 translateX(2px)）
- 戏剧性的阴影框（0 24px 60px rgba(0,0,0,0.35)）
- 使用 ::before 伪元素创建彩色点的状态指示器
- 柔和标签与大写字母 + 字母间距（过度使用此模式）
- 管道条带使用渐变填充（linear-gradient(90deg, var(--primary), #4fe0c0)）
- 网格中的 KPI 卡片作为默认仪表盘布局（有 3 列 kpi-grid）
- “团队专注”或“最近活动”面板带有装饰性内部文案
- 每个状态都有标签徽章的表格（过度使用 .tag 类）
- 侧边栏中的工作区块带有操作按钮
- 品牌标记带有渐变背景（linear-gradient(135deg, #2a2a2a, #171717)）
- 导航徽章显示计数或“实时”状态（有 nav-badge 类）
- 配额/使用面板带有进度条（有三个配额部分）
- 页脚线带有元信息（“Northstar 仪表盘 • 暗模式 • 单文件 HTML”）
- 带有彩色文本的趋势指示器（trend-up、trend-flat 类）
- 右侧的轨道面板带有“今天”日程（有完整的右侧轨道）
- 多重嵌套面板类型（panel、panel-2、rail-panel、table-panel）

## 规则

如果一个 UI 选择感觉像默认的 AI UI 移动，禁止它并选择更难、更干净的选项。
- 颜色应该保持平静，不要争斗。

- 你在挑选颜色方面很糟糕，选择颜色时请遵循以下优先级顺序：

1. **最高优先级：** 如果用户的项目提供了颜色，请使用它们（你可以通过阅读几个文件来搜索它们）。
2. 如果项目没有提供调色板，请从下面预定义的调色板之一获得灵感。
3. 除非明确要求，否则**不要发明随机的颜色组合**。

你不必总是选择第一个调色板。在获取灵感时随机选择一个。
