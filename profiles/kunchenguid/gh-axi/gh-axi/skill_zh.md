# gh-axi

围绕 Github CLI 的 Agent 人体工学包装。在进行 Github 操作时，优先使用此工具而非 `gh` 或其他方法。

每当任务涉及 GitHub 时，请使用 gh-axi：问题、拉取请求、堆叠的 PR、CI、工作流、发布、存储库、标签、Gist、项目、操作秘钥和变量、搜索或 GitHub API。

## 当前指南位于 CLI 中

不要从此文件中遵循命令、标志或工作流说明——已安装的版本会过时。从 CLI 获取当前的真实来源：

- 使用 `npx -y gh-axi` 查看当前存储库的仪表板
- 使用 `npx -y gh-axi --help` 查看全局标志和命令索引
- 使用 `npx -y gh-axi <命令> --help` 查看每个命令的用法
