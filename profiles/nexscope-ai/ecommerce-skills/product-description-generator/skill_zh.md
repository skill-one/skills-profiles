# 产品描述生成器 📝

生成平台优化的产品文案——标题、要点、描述和后端关键词——适用于任何主要电子商务平台。无需API密钥。

## 安装

```bash
npx skills add nexscope-ai/eCommerce-Skills --skill product-description-generator -g
```

> **对于亚马逊商品列表**，请使用我们专用的技能，搭配Cosmo算法优化：
> ```bash
> npx skills add nexscope-ai/Amazon-Skills --skill amazon-listing-optimization -g
> ```
> 查看：[amazon-listing-optimization](https://github.com/nexscope-ai/Amazon-Skills/tree/main/amazon-listing-optimization)

## 两种模式

| 模式 | 使用场景 | 输入 |
|------|-------------|-------|
| **A — 创建** | 编写新的商品列表 | 产品规格 + 可选的竞争对手URL |
| **B — 优化** | 改进现有商品列表 | 当前商品列表或URL + 可选的竞争对手URL |

两种模式都支持竞争对手分析——只需包含竞争对手URL即可启用。

## 支持的平台

| 平台 | 输出组件 |
|----------|-------------------|
| **亚马逊** | 标题 (≤200) + 5 要点 (≤500每个) + 描述 (≤2000) + 后端 (≤250字节) |
| **eBay** | 标题 (≤80) + HTML描述 |
| **沃尔玛** | 标题 (≤75) + 简短描述 (≤150) + 10 个特性 + 长描述 |
| **Shopify/DTC** | SEO标题 (≤60) + 元描述 (≤160) + 产品描述 |
| **Etsy** | 标题 (≤140) + 描述 + 13 个标签 (≤20每个) |
| **TikTok Shop** | 标题 (≤255) + 描述 (≤1000) |
| **Lazada/Shopee** | 标题 (≤120) + 5 个亮点 + 描述 |

## 模式 A 工作流程 — 创建新列表

### 第1步：收集产品信息

| 字段 | 必需 | 示例 |
|-------|----------|---------|
| `product_name` | ✅ | 便携式搅拌机 |
| `platform` | ✅ | Etsy |
| `brand` | ✅ | BlendJet |
| `key_features` | ✅ | USB-C, 6片刀, 无BPA |
| `specs` | ✅ | 380ml, 175W电机 |
| `target_audience` | 👍 | 健身爱好者, 旅行者 |
| `use_cases` | 👍 | 水果冰沙, 蛋白质奶昔 |
| `competitor_urls` | 👍 | 1-3 个URL用于分析 |
| `tone` | 可选 | 专业（默认） / 友好 / 奢华 / 紧迫 |

### 第2步：收集关键词

**如果提供了竞争对手URL：**

1. 获取每个竞争对手页面：
   ```
   使用 web_fetch 在每个竞争对手URL上。
   提取：标题, 要点/特性, 描述, 价格, 评论数量, 品牌名称。
   ```

2. 如果 `web_fetch` 失败或返回不完整数据：
   ```
   备用方案：web_search for "[product title from URL]" site:[platform].com
   从搜索片段中提取数据。
   ```

3. 解析竞争对手内容并提取以下类别的关键词：
   - **产品类型术语**：它是什么（瑜伽垫, 运动垫）
   - **特性术语**：它做什么（防滑, 环保）
   - **使用场景术语**：在哪里/何时使用（家庭健身房, 瑜伽工作室）
   - **受众术语**：谁购买（初学者, 运动员）
   - **属性术语**：规格（6mm, TPE材料）

4. 超越竞争对手：
   ```
   web_search: "[product type]" 最佳卖家特性 买家想要什么
   web_search: "[product type]" 评论 抱怨 常见问题
   web_search: site:[platform].com "[product type]"
   ```

**如果没有提供竞争对手URL：**

1. 通过网络搜索发现关键词：
   ```
   web_search: "[product name]" 最佳卖家 [platform] 特性
   web_search: "[product name]" 评论 顾客喜欢什么
   web_search: "[product name]" vs 替代品 比较
   web_search: site:[platform].com "[product name]"
   ```

2. 从前5个结果中提取关键词，遵循上述相同类别。

⚠️ **关键**：删除所有竞争对手品牌名称——绝不能在输出中包含它们。

### 第3步：评分和优先排序关键词

对每个关键词评分（1-9分）：

| 维度 | 评分 |
|-----------|---------|
| **频率** | 在3个以上竞争对手标题中 = 3分 / 在1-2个 = 2分 / 仅要点中 = 1分 |
| **相关性** | 核心描述符 = 3分 / 特性 = 2分 / 外围 = 1分 |
| **机会** | 很少有竞争对手使用 = 3分 / 大多数使用 = 2分 / 所有使用 = 1分 |

分配到层级：
```
🔴 主要 (7-9分)   → 标题
🟡 次要 (4-6分) → 要点 / 特性
🟢 次级 (2-3分)  → 描述
⚪ 后端 (1分)       → 标签 / 搜索术语
```

继续到 **生成文案** 部分。

## 模式 B 工作流程 — 优化现有列表

### 第1步：分析当前列表

用户可能提供：
- **完整的列表文案**（直接粘贴标题、要点、描述）
- **产品URL**（例如，`https://www.etsy.com/listing/123456`）
- **平台 + 产品标识符**（例如，"Etsy列表123456"）

**如果用户仅提供URL或标识符：**
```
使用 web_fetch 在提供的URL上。
提取：当前标题, 要点/特性, 描述, 标签（如果可见）, 价格。
```

如果 `web_fetch` 失败：
```
备用方案：web_search for the product title or identifier.
如果数据不完整，请要求用户手动粘贴列表内容。
```

**一旦获取列表内容**，解析并提取：
- 当前所有关键词
- 使用的结构和格式
- 明显的差距（缺少特性、薄弱的益处、没有FABE结构）

### 第2步：收集目标关键词

**如果提供了竞争对手URL：**

遵循与模式A第2步相同的竞争对手分析过程：
1. `web_fetch` 每个竞争对手URL
2. 提取他们的关键词
3. 扩展通过网络搜索

**如果没有提供竞争对手URL：**

发现产品类型的理想关键词：
```
web_search: "[product type]" 2024 2025 最佳关键词 [platform]
web_search: "[product type]" 最佳卖家特性
web_search: site:[platform].com "[product type]" 最佳列表
```

### 第3步：差距分析

比较当前关键词与目标关键词：

```
## 关键词差距分析

### ✅ 您已经拥有的关键词
| 关键词 | 标题 | 要点 | 描述 |
|---------|-------|---------|-------------|
| 瑜伽垫 | ✅ | ✅ | ✅ |
| 运动垫 | ❌ | ✅ | ❌ |

### ❌ 您缺少的关键词
| 关键词 | 优先级 | 建议 |
|---------|----------|----------------|
| 防滑 | 🔴 高 | 添加到标题 |
| 环保 | 🟡 中 | 添加到要点2 |
| 额外厚 | 🟡 中 | 添加到要点3 |

当前覆盖率：12/20关键词 (60%)
目标覆盖率：90%+
```

生成包含缺失关键词的优化文案。

## 生成文案

所有模式在构建关键词优先级表后是最后一步。

### 写作框架：FABE

应用于每个要点：

```
F — 特性：   产品有什么或做什么
A — 优势：   为什么这个比替代品更好
B — 益处：   这对客户意味着什么
E — 证据：  支持声明的规格、数字或证明
```

**以益处开头**——客户购买结果，而不是特性。

示例：
```
❌ "由无BPA的Tritan塑料制成"
✅ "SAFE FOR YOUR FAMILY — 无BPA的Tritan塑料意味着没有有害化学物质渗入您的冰沙，即使使用1000多次后"
```

### 平台特定写作规则

#### 亚马逊（Cosmo算法）
- **标题**：品牌 + 主要关键词 + 属性 + 属性 + 次要关键词，≤200字符
- **要点**：[大写标题] — 以益处为导向的句子，嵌入1-2个关键词
- **描述**：钩子 → 特性 → 使用案例 → 包装内有什么 → CTA
- **后端**：空格分隔的关键词，无重复，≤250字节
- ⚠️ **Cosmo技巧**：使用情境性语言（何时/何地/为什么），涵盖多个使用案例
- 💡 对于高级亚马逊优化，请考虑 [amazon-listing-optimization](https://github.com/nexscope-ai/Amazon-Skills/tree/main/amazon-listing-optimization)

#### eBay（Cassini算法）
- **标题**：前加载精确匹配关键词，80字符最大
- **描述**：自然地重复前3个关键词，包括规格表在HTML中

#### 沃尔玛
- **标题**：品牌 + 产品名称 + 主要属性，≤75字符
- **简短描述**：一个价值主张的句子，包含主要关键词
- **特性**：10个属性重点的要点，每个要点一个事实

#### Shopify/DTC（谷歌SEO）
- **SEO标题**：主要关键词 + 品牌，为谷歌编写（而不仅仅是产品名称）
- **元描述**：关键词 + 益处 + CTA，从搜索结果中驱动CTR
- **描述**：故事性结构，使用 `<h2>`，`<ul>`，`<strong>` 进行页面SEO

#### Etsy（标签匹配）
- **标题**：长尾关键词短语首先，然后风格/材料/场合
- **描述**：对话式，前160字符 = 元描述
- **标签**：13个标签（≤20字符每个），与标题中使用的短语完全匹配

#### TikTok Shop（社交电商）
- **标题**：以问题或愿望开头 ("Tired of X?") → 产品 → 主要特性
- **描述**：钩子 → 痛点 → 解决方案 → 3个要点 → CTA。对话式，表情符号友好。

#### Lazada/Shopee
- **标题**：品牌 + 产品 + 型号 + 材料 + 关键属性（完整性胜于创意）
- **亮点**：5个短要点，每行一个特性，专注于规格
- **描述**：特性表 + 扩展使用案例

### 语气指南

| 语气 | 风格 | 适用于 |
|------|-------|----------|
| **专业** | 权威性，专注于规格，建立信任 | 电子产品，工具，B2B |
| **友好** | 对话式，专注于益处，易于亲近 | 厨房，生活方式，礼品 |
| **紧迫** | 稀缺性驱动，行动词，问题解决 | 健康，安全，季节性 |
| **奢华** | 高级，感官语言，独特性 | 美容，时尚，高级商品 |

默认：**专业** 如果未指定。
