# 亚马逊关键词研究 🔍

为亚马逊卖家提供免费关键词研究。无需API密钥——开箱即用。

## 安装

```bash
npx skills add nexscope-ai/Amazon-Skills --skill amazon-keyword-research -g
```

## 功能

- **长尾关键词挖掘**：从亚马逊自动完成引擎中提取100-200个真实搜索词
- **竞争对手分析**：产品数量、价格范围、平均评分、评论分布、顶级品牌
- **季节性趋势检测**：12个月谷歌趋势数据，识别旺季和需求变化
- **市场机会评分**：结合竞争密度、价格空间和需求信号的综合评分（1-10分）
- **多市场支持**：美国、英国、德国、法国、意大利、西班牙、日本、加拿大、澳大利亚、印度、墨西哥、巴西
- **关键词对比**：多个关键词的并排分析

## 工作流程

### 第1步：收集自动完成数据

运行捆绑脚本收集亚马逊自动完成建议：

```bash
<skill>/scripts/research.sh "<关键词>" [市场]
```

**参数：**
- `关键词`（必填）：要研究的种子关键词
- `市场`（可选）：`us`（默认）、`uk`、`de`、`fr`、`it`、`es`、`jp`、`ca`、`au`、`in`、`mx`、`br`

**脚本的作用：**
- 使用种子关键词查询亚马逊自动完成API
- 扩展前缀："best [关键词]"、"cheap [关键词]"、"top [关键词]"
- 扩展a-z后缀："[关键词] a"、"[关键词] b"、... "[关键词] z"
- 返回去重排序的真实搜索建议列表——每行一个

**为什么这很重要：** 亚马逊自动完成反映了真实购物者实际输入的内容。这些不是猜测——它们是直接来自亚马逊搜索引擎的需求信号。前缀和字母扩展捕捉了基本自动完成遗漏的长尾词，这些词通常竞争较小且意图更高。

示例：
```bash
<skill>/scripts/research.sh "portable blender" us
# 返回100-200个长尾关键词
```

对于多市场研究，每个市场运行一次脚本。

### 第2步：分析竞争

使用`web_search`收集竞争对手情报：

1. 搜索`"<关键词>" site:amazon.com`——注意大致结果数量以了解竞争密度
2. 搜索`"<关键词>" amazon best sellers price review`——提取价格模式、平均评分、主导品牌
3. 总结：总竞争对手数量、价格范围（最低/平均/最高）、平均星级评分、前5个按可见性排序的品牌

**为什么这很重要：** 没有竞争背景的原始关键词量毫无意义。一个有10,000次搜索但被3个根深蒂固的品牌（每个有10,000多条评论）主导的关键词和一个相同搜索量的分散卖家关键词的机会截然不同。价格范围揭示了利润空间——如果所有价格都低于$10，在FBA费用后利润空间将非常狭窄。

### 第3步：检查季节性

使用`web_fetch`在谷歌趋势上：

```
https://trends.google.com/trends/explore?q=<关键词>&geo=US
```

如果谷歌趋势返回429错误，则回退到`web_search`获取季节性数据：
```
"<关键词>" seasonal trends demand peak months
```

识别：趋势方向（上升/下降/稳定）、季节性峰值（哪些月份）、同比变化。

**为什么这很重要：** 季节性决定了现金流风险。一个产品80%的销量在第四季度意味着你需要提前几个月备货，而其余时间可能积压滞销库存。上升趋势意味着需求增长和新进入者有更多空间；下降趋势意味着你在争夺一个不断缩小的市场。这种背景将一个关键词从一个数字转化为一个商业决策。

### 第4步：综合报告

将所有数据组合成以下输出格式。

**为什么结构很重要：** 按意图（商业性 vs 信息性 vs 狭义）分组关键词有助于卖家了解人们不仅搜索什么，还为什么搜索。机会评分将多个信号浓缩为一个可操作的数字，但背后的分解才是实际指导决策的东西——所以始终显示理由。

## 多关键词对比

当用户要求对比两个或多个关键词时，分别对每个关键词运行完整工作流程（步骤1-4），然后以并排对比表的形式呈现结果。

**示例用户输入：**
```
对比"笔记本电脑支架" vs "显示器支架" vs "平板电脑支架"在亚马逊美国——我应该销售哪一个？
```

**如何执行：** 运行脚本3次：
```bash
<skill>/scripts/research.sh "laptop stand" us
<skill>/scripts/research.sh "monitor stand" us
<skill>/scripts/research.sh "tablet stand" us
```

然后为每个关键词完成步骤2-3，并输出对比表：

| 指标 | 笔记本电脑支架 | 显示器支架 | 平板电脑支架 |
|------|-------------|---------------|-------------|
| 长尾数量 | — | — | — |
| 平均价格 | — | — | — |
| 顶级品牌主导 | — | — | — |
| 趋势方向 | — | — | — |
| 机会评分 | — | — | — |

最后，以**建议**说明哪个关键词机会最佳及其原因。
