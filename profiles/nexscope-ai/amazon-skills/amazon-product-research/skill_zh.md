## 工作流程

### 步骤 1：产品与市场情报

使用 `web_search` 收集全面的市场数据：

1. **搜索量及兴趣**：`"[产品]" Amazon 搜索量趋势`
2. **市场规模指标**：`"[产品]" 市场规模 营收 Amazon`
3. **品类定位**：`"[产品]" Amazon 品类 畅销商品`
4. **季节性规律**：`"[产品]" 季节性需求趋势 Amazon`

**需提取内容：**
- 近似搜索量（如有可用数据）
- 市场增长指标（增长/稳定/下降）
- 品类背景（主品类、子品类）
- 季节性波动及高峰期

### 步骤 2：竞争深度分析

系统地分析竞争格局：

1. **竞争密度**：`"[产品]" site:amazon.com` - 总结果数量
2. **头部卖家分析**：`"best [产品]" Amazon 头部评价`
3. **价格区间映射**：`"[产品]" Amazon 价格 $X $Y $Z`（测试不同区间）
4. **品牌主导度**：`"[产品]" Amazon 品牌市场领导者`

**竞争指标：**
- **竞争者总数**：搜索结果中的产品数量
- **市场集中度**：前3个品牌的预估市场份额
- **评价分布**：拥有 100+、1000+、5000+ 评价的产品数量
- **价格区间**：低端（$）、中端（$$）、高端（$$$）区间
- **品质指标**：平均评分、常见投诉

**竞争评分（1-10）：**
- 9-10：市场极度分散，无主导品牌
- 7-8：存在部分成熟品牌，但仍有新进入空间
- 5-6：市场状况不一，存在较强竞争者
- 3-4：2-3个主导品牌控制大部分销量
- 1-2：市场由单一大品牌或 Amazon basics 主导

### 步骤 3：需求验证

使用多个来源验证真实需求：

1. **Google Trends**：在 `https://trends.google.com/trends/explore?q=[产品]&geo=US` 上使用 `web_fetch`
2. **亚马逊自动补全**：手动检查 `[产品] + [字母]` 的提示
3. **相关搜索**：`"人们还搜索 [产品]"` 的规律
4. **社交验证**：`"[产品]" reddit 评价与投诉 site:reddit.com`

**需求信号：**
- **搜索趋势**：过去12个月的上升/稳定/下降趋势
- **自动补全深度**：亚马逊建议的变体数量
- **社交热度**：社区讨论量及情感倾向
- **季节性**：存在明显规律 vs. 全年需求一致

**需求评分（1-10）：**
- 9-10：强劲上升趋势，搜索量持续增长
- 7-8：需求稳定且较高，搜索模式一致
- 5-6：中等需求，存在季节性波动
- 3-4：趋势下降或需求极度季节性
- 1-2：需求低且零散，或仅为小众市场

### 步骤 4：盈利分析

计算真实的盈利潜力：

1. **定价研究**：从竞争分析中提取价格区间
2. **成本估算**：使用 `"[产品]" Alibaba 批发价` 研究供应商成本
3. **FBA费用计算**：根据产品尺寸/重量使用亚马逊费用结构计算
4. **总成本明细**：产品 + 运费 + FBA + 亚马逊费用 + 营销

**盈利框架：**
```
售价：                   $X.XX
- **产品成本 (40%)**：    -$X.XX  
- **亚马逊费用 (15%)**：     -$X.XX
- **FBA 费用 (浮动)**：     -$X.XX  
- **运费 (5-10%)**：      -$X.XX
- **营销费用 (10-20%)**：    -$X.XX
- **退货/杂费 (5%)**：     -$X.XX
= **净利润率**：     $X.XX (目标：售价的 20%+)
```

**盈利潜力评分（1-10）：**
- 9-10：可能实现 30%+ 净利润率，可定位高端
- 7-8：20-30% 利润率，具备良好销量潜力
- 5-6：15-20% 利润率，尚可但在竞争中具一定挑战性
- 3-4：10-15% 利润率，紧张但可行
- 1-2：低于10% 利润率，高风险低回报

### 步骤 5：市场进入评估

评估障碍与要求：

1. **投资分析**：`"sell [产品] Amazon 创业成本投资"`
2. **法规研究**：`"[产品]" FDA 认证要求 Amazon`（如适用）
3. **采购复杂性**：`"[产品]" 供应商起订量 制造`
4. **差异化机会**：分析竞品差评以寻找改进机会

**进入障碍：**
- **资金要求**：初始库存投入所需金额
- **法规合规**：所需的认证、测试、审批
- **技术复杂度**：制造难度、品控
- **品牌要求**：品类是否偏向成熟品牌
- **季节性时机**：上市窗口及库存规划复杂性

**进入难度评分（1-10，10分为最容易）：**
- 9-10：产品简单，投资低，无监管要求
- 7-8：投资适中，合规标准
- 5-6：投资较高，或存在部分监管要求
- 3-4：产品复杂，或资金需求较大
- 1-2：监管严格，复杂度与投资均较高

## 产品机会评分系统

### 综合评分计算（1-10）

为各因素赋予权重并计算综合得分：

**因素权重：**
- 市场需求（25%）：搜索量及增长趋势
- 竞争水平（20%）：市场饱和度及主导程度
- 盈利潜力（20%）：真实利润率预期
- 进入难度（15%）：障碍与所需投资
- 市场增长（10%）：品类扩张 vs. 衰退
- 差异化（5%）：与竞争者拉开差距的能力
- 季节性（3%）：需求一致性 vs. 季节性波动
- 风险因素（2%）：监管、趋势或市场风险

**综合机会类别：**
- **9-10**：🟢 优质机会 - 优先考虑
- **7-8**：🟡 良好机会 - 值得追求
- **5-6**：🟡 中等机会 - 需谨慎推进
- **3-4**：🔴 较差机会 - 高风险
- **1-2**：🔴 避免 - 不具备可行性

## 输出格式

### 完整产品调研报告

**📊 [产品名称] 机会分析**

**🎯 综合机会评分：X.X/10** (🟢🟡🔴)

**📈 市场分析**
- **需求层级**：高/中/低（基于搜索量指标）
- **市场趋势**：增长/稳定/下降（12个月模式）
- **季节性**：全年需求 / [月份] 存在季节性峰值 / 高度季节性
- **品类**：[主品类] > [子品类]
- **市场规模**：[预估年营收/大型/中型/小众]

**🏆 竞争评估**  
- **竞争水平**：低/中/高（竞争者密度）
- **市场领导者**：[前2-3个品牌及预估市场份额]
- **价格区间**：低端：$X-Y，中端：$X-Y，高端：$X-Y  
- **评价格局**：[高评价产品的分布情况]
- **市场空白**：[未被满足的细分领域或价格区间]

**💰 盈利潜力**
```
目标售价：            $XX.XX
预估产品成本：         $XX.XX (XX%)
亚马逊与FBA费用：       $XX.XX (XX%)  
**运输与物流：**            $XX.XX (XX%)
**营销预算：**              $XX.XX (XX%)
**预估净利润：**            $XX.XX (XX% 利润率)**
```
- **利润率评估**：优秀/良好/紧张/较差
- **销量潜力**：[高/中/低，基于市场规模]
- **价格敏感度**：[市场对价格变化的敏感程度]

**🚀 市场进入分析**
- **启动投资**：$X,XXX - $X,XXX（库存与设置）  
- **最小起订量**：X 件（典型供应商要求）
- **法规要求**：[无/标准/需复杂认证]
- **上市时间**：X-X 个月（从采购到上市）  
- **关键成功因素**：[该品类最核心的要素]

**⚠️ 风险评估**
- **市场风险**：[趋势可持续性、季节性、竞争状况]
- **运营风险**：[采购、品控、物流]  
- **法规风险**：[合规要求、政策变化]
- **财务风险**：[库存、现金流、利润率压力]

**🎯 推荐策略**

**若得分为 7-10 分**： 
- **推进/不推进**：✅ 建议推进
- **进入策略**：[高端定位/性价比策略/细分市场聚焦]  
- **差异化**：[与竞争者拉开差距的核心领域]
- **上市时间表**：[最佳时间节点与里程碑]
- **成功指标**：[需跟踪的 KPI]

**若得分为 4-6 分**：
- **有条件建议**：调整后考虑
- **需改进之处**：[需要做出何种调整]
- **替代方案**：[不同的定位或市场]
- **风险缓解**：[如何降低已识别风险]

**若得分为 1-3 分**：
- **不建议**：风险较高，有更优机会
- **主要问题**：[避免的主要原因]
- **替代产品**：[建议的相关机会]

## 高级调研技巧

### 1. 跨品类分析
寻找在相邻品类中成功的产品，将其机会向本品类拓展。

### 2. 功能缺口分析

### 3. 价格点验证
测试多个价格区间，找到最优定位。

### 4. 季节性优化
研究历史规律，优化上市时机。

### 5. 法规深度研究
对于受监管品类，需尽早核实所有合规要求。
