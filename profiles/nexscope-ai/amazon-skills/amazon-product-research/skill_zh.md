# 亚马逊产品调研 🔍

亚马逊卖家的完整产品调研框架。验证想法，分析机会，评估竞争。

## 安装

```bash
npx skills add nexscope-ai/Amazon-Skills --skill amazon-product-research -g
```

## 功能

- **产品机会评分**：涵盖8个关键因素的1-10分综合评分
- **需求分析**：搜索量、季节性模式、增长趋势
- **竞争评估**：竞争对手数量、主导地位、市场碎片化
- **盈利潜力计算**：利润率分析、FBA费用影响、定价策略
- **市场进入分析**：壁垒、所需投资、盈利所需时间
- **采购指导**：供应商选项、最小起订量要求、质量考量
- **风险评估**：市场风险、监管问题、趋势可持续性
- **多平台支持**：美国、英国、德国、法国、意大利、西班牙、日本、加拿大、澳大利亚、印度、墨西哥、巴西

## 工作流程

### 第一步：产品与市场情报

使用`web_search`收集全面的市场数据：

1. **搜索量与兴趣**：`"[产品]" Amazon搜索量趋势`
2. **市场规模指标**：`"[产品]" Amazon市场规模收入`
3. **类别定位**：`"[产品]" Amazon类别畅销产品"`
4. **季节性模式**：`"[产品]" Amazon季节性需求趋势"`

**需要提取的内容：**
- 大约的搜索量（如果可用）
- 市场增长指标（增长/稳定/下降）
- 类别背景（主要类别、子类别）
- 季节性波动和高峰期

### 第二步：竞争深度分析

系统性地分析竞争格局：

1. **竞争密度**：`"[产品]" site:amazon.com` - 总结果数量
2. **顶尖卖家分析**：`"最佳[产品]" Amazon顶级评价`
3. **价格范围映射**：`"[产品]" Amazon价格 $X $Y $Z`（测试不同范围）
4. **品牌主导地位**：`"[产品]" Amazon品牌市场领导者`

**竞争指标：**
- **总竞争对手**：搜索结果中的产品数量
- **市场集中度**：前3个品牌的市场份额估计
- **评价分布**：有多少产品有100+、1000+、5000+条评价
- **价格范围**：预算（$）、中端（$$）、高端（$$$）细分市场
- **质量指标**：平均评分、常见投诉

**竞争评分（1-10）：**
- 9-10：高度碎片化市场，没有主导者
- 7-8：一些成熟品牌，但仍有新进入者的空间
- 5-6：混合市场，有一些强劲的竞争对手
- 3-4：2-3个主导品牌控制大部分销售
- 1-2：市场由1个主要品牌或亚马逊基础产品主导

### 第三步：需求验证

使用多个来源验证真实需求：

1. **谷歌趋势**：`web_fetch` on `https://trends.google.com/trends/explore?q=[产品]&geo=US`
2. **亚马逊自动完成**：手动检查`[产品] + [字母]`建议
3. **相关搜索**：`"人们还搜索[产品]"`模式
4. **社交验证**：`"[产品]" reddit评价投诉 site:reddit.com`

**需求信号：**
- **搜索趋势**：12个月内上升/稳定/下降
- **自动完成深度**：亚马逊建议多少种变体
- **社交热度**：社区中的讨论量、情绪
- **季节性**：清晰的模式与持续全年需求

**需求评分（1-10）：**
- 9-10：强劲上升趋势，增长搜索量
- 7-8：稳定高需求，一致搜索模式
- 5-6：中等需求，有季节性变化
- 3-4：下降趋势或非常季节性需求
- 1-2：低/零星需求或利基市场

### 第四步：盈利能力分析

计算实际盈利潜力：

1. **定价研究**：从竞争分析中提取价格范围
2. **成本估算**：使用`"[产品]" Alibaba批发价格`调研供应商成本
3. **FBA费用计算**：使用亚马逊费用结构，根据产品尺寸/重量
4. **总成本分解**：产品+运输+FBA+亚马逊费用+营销

**盈利框架：**
```
销售价格：           $X.XX
- 产品成本（40%）：    -$X.XX  
- 亚马逊费用（15%）：     -$X.XX
- FBA费用（变化）：     -$X.XX  
- 运输（5-10%）：      -$X.XX
- 营销（10-20%）：    -$X.XX
- 退货/杂项（5%）：     -$X.XX
= 净利润率：     $X.XX (目标：销售价格的20%以上)
```

**盈利能力评分（1-10）：**
- 9-10：30%+净利润率可能，高端定位
- 7-8：20-30%利润率，良好销量潜力
- 5-6：15-20%利润率，良好但竞争激烈
- 3-4：10-15%利润率，紧张但可行
- 1-2：<10%利润率，高风险/低回报

### 第五步：市场进入评估

评估壁垒和要求：

1. **投资分析**：`"在亚马逊卖[产品]启动成本投资"`
2. **监管研究**：`"[产品]" FDA认证要求 Amazon"`（如果适用）
3. **采购复杂性**：`"[产品]" 供应商最小订单量制造"`
4. **差异化机会**：分析竞争对手评价中的常见投诉

**进入壁垒：**
- **资本要求**：需要多少初始库存投资
- **监管合规**：认证、测试、批准要求
- **技术复杂性**：制造难度、质量控制
- **品牌要求**：是否类别偏爱成熟品牌
- **季节性时机**：推出窗口和库存规划复杂性

**进入难度评分（1-10，其中10=最简单）：**
- 9-10：简单产品，低投资，无监管
- 7-8：中等投资，标准合规
- 5-6：较高投资或一些监管要求
- 3-4：复杂产品或重大资本需求
- 1-2：严格监管，高复杂性，重大投资

## 产品机会评分系统

### 总体评分计算（1-10）

对每个因素进行加权计算，得出综合评分：

**因素权重：**
- 市场需求（25%）：搜索量和增长趋势
- 竞争水平（20%）：市场饱和度和主导地位
- 盈利潜力（20%）：实际利润率预期
- 进入难度（15%）：壁垒和所需投资
- 市场增长（10%）：类别扩张与衰退
- 差异化（5%）：与竞争对手区分的能力
- 季节性（3%）：需求一致性与季节性高峰
- 风险因素（2%）：监管、趋势或市场风险

**总体机会类别：**
- **9-10**：🟢 优秀机会 - 高优先级
- **7-8**：🟡 良好机会 - 值得追求
- **5-6**：🟡 中等机会 - 谨慎进行
- **3-4**：🔴 差机会 - 高风险
- **1-2**：🔴 避免 - 不可行

## 输出格式

### 完整产品调研报告

**📊 [产品名称]机会分析**

**🎯 总体机会评分：X.X/10** (🟢🟡🔴)

**📈 市场分析**
- **需求水平**：高/中/低（搜索量指标）
- **市场趋势**：增长/稳定/下降（12个月模式）
- **季节性**：全年/季节性高峰在[月份]/高度季节性
- **类别**：[主要类别] > [子类别]
- **市场规模**：[估计年收入/大/中/利基]

**🏆 竞争评估**  
- **竞争水平**：低/中/高（竞争对手密度）
- **市场领导者**：[前2-3个品牌和估计市场份额]
- **价格范围**：预算：$X-Y，中端：$X-Y，高端：$X-Y
- **评价格局**：[高评价产品的分布]
- **市场空白**：[未服务的细分市场或价格点]

**💰 盈利潜力**
```
目标销售价格：    $XX.XX
估计产品成本：  $XX.XX (XX%)
亚马逊 + FBA费用：       $XX.XX (XX%)  
运输与物流：    $XX.XX (XX%)
营销预算：        $XX.XX (XX%)
估计净利润：    $XX.XX (XX%利润率)
```
- **利润率评估**：优秀/良好/紧张/差
- **销量潜力**：[高/中/低，基于市场规模]
- **价格敏感性**：[市场看起来有多敏感]

**🚀 市场进入分析**
- **启动投资**：$X,XXX - $X,XXX（库存+设置）
- **最小起订量**：X单位（典型供应商要求）
- **监管要求**：[无/标准/需要复杂认证]
- **上市时间**：X-X个月（采购到推出）
- **关键成功因素**：[这个类别中最重要的是什么]

**⚠️ 风险评估**
- **市场风险**：[趋势可持续性、季节性、竞争]
- **运营风险**：[采购、质量控制、物流]
- **监管风险**：[合规要求、政策变化]
- **财务风险**：[库存、现金流、利润率压力]

**🎯 推荐策略**

**如果评分7-10**： 
- **Go/No-Go**：✅ 建议追求
- **进入策略**：[高端定位/价值策略/利基焦点]  
- **差异化**：[与竞争对手区分的关键领域]
- **推出时间表**：[最佳时机和里程碑]
- **成功指标**：[要跟踪的KPI]

**如果评分4-6**：
- **有条件推荐**：考虑修改
- **需要改进**：[需要改变什么]
- **替代方法**：[不同的定位或市场]
- **风险缓解**：[如何降低已识别风险]

**如果评分1-3**：
- **不推荐**：高风险，有更好的机会  
- **主要问题**：[避免的主要原因]
- **替代产品**：[建议相关机会]

## 高级调研技巧

### 2. 特征差距分析

### 4. 季节性优化
研究历史模式，优化推出时机

### 5. 监管深度分析
对于受监管类别，尽早验证所有合规要求
