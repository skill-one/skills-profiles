# ⚡ Bun 开发

> 使用 Bun 运行时进行快速、现代的 JavaScript/TypeScript 开发，灵感来源于 [oven-sh/bun](https://github.com/oven-sh/bun)。

## 详细指南

在执行此技能之前，请阅读 [详细指南](references/detailed-guide.md)。该指南保留了完整流程和参考资料。请将其安全性、先决条件和验证要求视为强制性要求。对于专注工作，加载相关章节；对于端到端工作，请完整阅读指南。

## 何时使用此技能

当您需要以下情况时，使用此技能：

- 使用 Bun 启动新的 JS/TS 项目
- 从 Node.js 迁移到 Bun
- 优化开发速度
- 使用 Bun 的内置工具（打包器、测试运行器）
- 排查特定的 Bun 问题

---

## 限制
- 仅当任务明确符合上述范围时，才使用此技能。
- 不要将输出视为环境特定验证、测试或专家评审的替代品。
- 如果缺少必要的输入、权限、安全边界或成功标准，请停止并请求澄清。
