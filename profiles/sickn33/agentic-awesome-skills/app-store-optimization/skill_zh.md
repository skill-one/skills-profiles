# 应用商店优化（ASO）技能

这项综合技能为在苹果App Store和谷歌Play商店上成功发布和优化移动应用提供完整的ASO能力。

## 功能

### 研究与分析
- **关键词研究**：分析关键词搜索量、竞争度和相关性，以实现应用发现
- **竞争对手分析**：深入研究您所在类别的表现优异的应用
- **市场趋势分析**：识别您应用类别中的新兴趋势和机会
- **用户评论情感分析**：从用户评论中提取见解，以识别优势问题
- **类别分析**：评估最佳类别和子类别放置策略

### 元数据优化
- **标题优化**：创建具有最佳关键词放置（特定平台的字符限制）的引人入胜的标题
- **描述优化**：制作可转换并排名的简短和完整描述
- **副标题/促销文本**：优化苹果特定的副标题（30个字符）和促销文本（170个字符）
- **关键词字段**：使用战略选择最大化苹果的100个字符关键词字段
- **类别选择**：主要和次要类别的数据驱动建议
- **图标最佳实践**：设计高转化率应用图标的指南
- **截图优化**：创建可驱动安装的截图的策略
- **预览视频**：应用预览视频的最佳实践
- **本地化**：为全球范围进行多语言优化策略

### 转化优化
- **A/B测试框架**：规划和跟踪元数据实验以实现持续改进
- **视觉资产测试**：测试图标、截图和视频以实现最大转化率
- **商店列表优化**：全面的页面优化，以实现从展示到安装的转化
- **行动号召**：优化描述和促销材料中的行动号召

### 评分与评论管理
- **评论监控**：跟踪和分析用户评论以获取可操作的见解
- **回复策略**：回复评论的模板和最佳实践
- **评分提升**：提高应用评分的自然策略
- **问题识别**：从评论中展示常见问题和功能请求

### 发布与更新策略
- **发布前检查清单**：在提交到商店之前完成验证
- **发布时间**：优化发布时间以实现最大可见性和下载量
- **更新节奏**：规划最佳更新频率和功能推出
- **功能公告**：制作“新功能”部分以重新吸引用户
- **季节性优化**：利用季节性趋势和活动

### 分析与跟踪
- **ASO评分**：跨多个因素计算整体ASO健康状况评分
- **关键词排名**：跟踪关键词位置随时间的变化
- **转化指标**：监控展示到安装的转化率
- **下载速度**：跟踪下载趋势和势头
- **性能基准测试**：与类别平均水平和竞争对手进行比较

### 平台特定要求
- **苹果App Store**：
  - 标题：30个字符
  - 副标题：30个字符
  - 促销文本：170个字符（无需应用更新即可编辑）
  - 描述：4,000个字符
  - 关键词：100个字符（逗号分隔，无空格）
  - 新功能：4,000个字符
- **谷歌Play商店**：
  - 标题：50个字符（以前为30个字符，2021年增加）
  - 简短描述：80个字符
  - 完整描述：4,000个字符
  - 没有关键词字段（关键词从标题和描述中提取）

## 输出格式

### 关键词研究报告
- 推荐关键词列表及搜索量估计
- 竞争水平分析（低/中/高）
- 每个关键词的相关性分数
- 主要和次要关键词的战略建议
- 长尾关键词机会

### 优化元数据包
- 平台特定标题（字符数验证）
- 副标题/促销文本（苹果）
- 简短描述（谷歌）
- 完整描述（两个平台）
- 关键词字段（苹果 - 100个字符）
- 所有字段的字符数验证
- 关键词密度分析
- 之前/之后的比较

### 竞争对手分析报告
- 类别中前10名竞争对手
- 他们的元数据策略
- 关键词重叠分析
- 视觉资产评估
- 评分和评论量比较
- 确定的差距和机会

### ASO健康评分
- 总分（0-100）
- 类别细分：
  - 元数据质量（0-25）
  - 评分和评论（0-25）
  - 关键词表现（0-25）
  - 转化指标（0-25）
- 具体改进建议
- 优先行动项

### A/B测试计划
- 假设和测试变量
- 测试持续时间建议
- 成功指标定义
- 样本量计算
- 统计显著性阈值

### 发布检查清单
- 发布前验证（所有必需的资产、元数据）
- 商店合规性验证
- 测试清单（设备、操作系统版本）
- 市场准备项目
- 发布后监控计划

## 脚本

### keyword_analyzer.py
分析关键词的搜索量、竞争度和相关性。提供主要和次要关键词的战略建议。

**主要功能：**
- `analyze_keyword()`：分析单个关键词指标
- `compare_keywords()`：比较多个关键词
- `find_long_tail()`：发现长尾关键词机会
- `calculate_keyword_difficulty()`：评估竞争水平

### metadata_optimizer.py
优化标题、描述和关键词字段，并进行平台特定字符限制验证。

**主要功能：**
- `optimize_title()`：创建引人入胜、关键词丰富的标题
- `optimize_description()`：生成以转化为重点的描述
- `optimize_keyword_field()`：最大化苹果的100个字符关键词字段
- `validate_character_limits()`：确保符合平台限制
- `calculate_keyword_density()`：分析元数据中的关键词使用情况

### competitor_analyzer.py
分析顶级竞争对手的ASO策略并识别机会。

**主要功能：**
- `get_top_competitors()`：识别类别领导者
- `analyze_competitor_metadata()`：提取和分析竞争对手关键词
- `compare_visual_assets()`：评估图标和截图
- `identify_gaps()`：找到竞争机会

### aso_scorer.py
跨多个维度计算全面的ASO健康评分。

**主要功能：**
- `calculate_overall_score()`：计算0-100的ASO评分
- `score_metadata_quality()`：评估标题、描述、关键词
- `score_ratings_reviews()`：评估评分质量和数量
- `score_keyword_performance()`：分析排名位置
- `score_conversion_metrics()`：评估展示到安装的比率
- `generate_recommendations()`：提供优先行动项

### ab_test_planner.py
计划和跟踪元数据和视觉资产的A/B测试。

**主要功能：**
- `design_test()`：创建测试假设和变量
- `calculate_sample_size()`：确定所需测试持续时间
- `calculate_significance()`：评估统计显著性
- `track_results()`：监控测试性能
- `generate_report()`：总结测试结果

### localization_helper.py
管理多语言ASO优化策略。

**主要功能：**
- `identify_target_markets()`：推荐本地化优先级
- `translate_metadata()`：生成本地化元数据
- `adapt_keywords()`：研究特定地区关键词
- `validate_translations()`：检查每语言的字符限制
- `calculate_localization_roi()`：估计本地化影响

### review_analyzer.py
分析用户评论的情感、问题和功能请求。

**主要功能：**
- `analyze_sentiment()`：计算正面/负面/中性的比例
- `extract_common_themes()`：识别频繁提到的主题
- `identify_issues()`：展示错误和用户投诉
- `find_feature_requests()`：提取所需功能
- `track_sentiment_trends()`：监控情感随时间变化
- `generate_response_templates()`：创建评论回复草稿

### launch_checklist.py
生成全面的发布前和更新检查清单。

**主要功能：**
- `generate_prelaunch_checklist()`：完成提交验证
- `validate_app_store_compliance()`：检查苹果指南
- `validate_play_store_compliance()`：检查谷歌政策
- `create_update_plan()`：计划更新节奏和功能
- `optimize_launch_timing()`：推荐发布日期
- `plan_seasonal_campaigns()`：识别季节性机会

## 最佳实践

### 关键词研究
1. **搜索量与竞争度**：平衡高搜索量关键词和可实现的排名
2. **相关性优先**：只瞄准与您的应用真正相关的关键词
3. **长尾策略**：包括3-4个词的短语，竞争度较低
4. **持续研究**：关键词趋势会变化，每季度研究一次
5. **竞争对手关键词**：不要盲目复制；确保与您的功能相关

### 元数据优化
1. **关键词前置**：在标题/描述中放置最重要的关键词
2. **自然语言**：先为人类写作，SEO其次
3. **功能优势**：关注用户优势，而不仅仅是功能
4. **A/B测试所有内容**：系统地测试标题、描述、截图
5. **定期更新**：每次重大更新后刷新元数据
6. **字符限制**：使用每个字符——不要浪费宝贵的空间
7. **苹果关键词字段**：逗号之间无复数、重复或空格

### 视觉资产
1. **图标**：必须在小尺寸下可识别（60x60px）
2. **截图**：前2-3张至关重要——大多数用户不会滚动
3. **标题**：使用截图标题讲述您的价值故事
4. **一致性**：与应用设计匹配视觉风格
5. **A/B测试图标**：图标是最重要的视觉元素

### 评论与评分
1. **快速回复**：在24-48小时内回复评论
2. **专业语气**：即使负面评论也要礼貌
3. **解决问题**：显示您正在积极修复报告的问题
4. **感谢支持者**：认可正面评论
5. **策略性提示**：在积极体验后请求评分

### 发布策略
1. **软发布**：考虑先在小市场发布
2. **PR时间**：与发布协调媒体覆盖
3. **频繁更新**：初始更新表明积极开发
4. **密切监控**：前两周每天跟踪指标
5. **快速迭代**：立即修复关键问题

### 本地化
1. **优先市场**：从英语、西班牙语、中文、法语、德语开始
2. **母语人士**：使用专业翻译，而不是机器翻译
3. **文化适应**：某些功能在不同文化中的反响不同
4. **本地测试**：在发布前让母语人士审查
5. **衡量ROI**：按地区跟踪下载量以评估影响

## 限制

### 数据依赖
- 关键词搜索量估计是近似的（没有苹果/谷歌的官方数据）
- 竞争对手数据可能不完整（针对私有应用）
- 评论分析仅限于公开评论（无法访问私人反馈）
- 历史数据可能不适用于新应用

### 平台限制
- 苹果App Store关键词更改需要提交应用（促销文本除外）
- 谷歌Play商店元数据更改需要1-2小时才能索引
- A/B测试需要大量流量才能获得统计显著性
- 商店算法是专有的，且会无通知更改

### 行业差异
- ASO基准因类别差异显著（游戏与工具）
- 季节性对不同类别影响不同
- 地理市场具有不同的竞争环境
- 文化偏好影响不同国家的效果

### 范围边界
- 不包括付费用户获取策略（苹果搜索广告、谷歌广告）
- 不涵盖应用开发或UI/UX优化
- 不包括应用分析实施（使用Firebase、Mixpanel等）
- 不处理应用提交技术问题（配置文件、证书）

### 不使用此技能的情况
- 适用于网络应用（不同SEO策略适用）
- 适用于未在公共商店中的企业应用
- 适用于仅在beta/TestFlight中的应用
- 如果您需要付费广告策略（使用营销技能）
