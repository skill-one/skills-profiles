# 文档模板

> 常见文档类型的模板和结构指南。

---

## 1. README 结构

### 必要部分（优先顺序）

| 部分 | 目的 |
|------|------|
| **标题 + 一句话简介** | 这是什么？ |
| **快速入门** | 5 分钟内运行 |
| **功能** | 我能做什么？ |
| **配置** | 如何自定义 |
| **API 参考** | 链接到详细文档 |
| **贡献** | 如何提供帮助 |
| **许可证** | 法律 |

### README 模板

```markdown
# 项目名称

简短的描述性一句话。

## 快速入门

[运行的最小步骤]

## 功能

- 功能 1
- 功能 2

## 配置

| 变量 | 描述 | 默认值 |
|----------|-------------|---------|
| PORT | 服务器端口 | 3000 |

## 文档

- API 参考
- 架构

## 许可证

MIT
```

## 2. API 文档结构

### 每个端点的模板

```markdown

通过 ID 获取用户。

**参数:**
| 名称 | 类型 | 必填 | 描述 |
|------|------|------|------|
| id | string | 是 | 用户 ID |

**响应:**
- 200: 用户对象
- 404: 用户未找到

**示例:**
[请求和响应示例]
```

## 3. 代码注释指南

### JSDoc/TSDoc 模板

```typescript
/**
 * 函数的功能简介。
 * 
 * @param paramName - 参数的描述
 * @returns 返回值的描述
 * @throws ErrorType - 当出现这种错误时
 * 
 * @example
 * const result = functionName(input);
 */
```

### 何时注释

| ✅ 注释 | ❌ 不注释 |
|-----------|-----------|
| 原因（业务逻辑） | 什么（明显） |
| 复杂算法 | 每一行 |
| 非明显行为 | 自解释代码 |
| API 合约 | 实现细节 |

为什么我们要做这个决定？

## 6. AI 友好型文档 (2025)

### llms.txt 模板

用于 AI 爬虫和代理：

```markdown
# 项目名称
> 一句话目标。

## 核心文件
- [src/index.ts]: 主入口
- [src/api/]: API 路由
- [docs/]: 文档

## 关键概念
- 概念 1: 简要解释
- 概念 2: 简要解释
```

### MCP 准备型文档

用于 RAG 索引：
- 清晰的 H1-H3 层级结构
- 数据结构的 JSON/YAML 示例
- Mermaid 流程图
- 自包含部分

## 7. 结构原则

| 原则 | 原因 |
|-----------|------|
| **可扫描** | 标题、列表、表格 |
| **先示例** | 展示，而不仅仅是说明 |
| **渐进式细节** | 简单 → 复杂 |
| **保持更新** | 过时 = 具误导性 |

---

> **记住：** 模板是起点。根据你的项目需求进行调整。

这项技能适用于执行概述中描述的工作流程或操作。

## 限制
- 仅在任务明确匹配上述范围时使用此技能。
- 不要将输出视为环境特定验证、测试或专家评审的替代品。
- 如果缺少必要的输入、权限、安全边界或成功标准，请停止并请求澄清。
