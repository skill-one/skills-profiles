# Tailwind CSS 模式（v4 - 2025）

> 现代 utility-first CSS，具有 CSS 原生配置。

## 何时使用
在配置 Tailwind v4、使用 CSS-first 主题和设计令牌，或实现容器查询和现代 Tailwind 模式时使用此技能。

---

## 1. Tailwind v4 架构

### v3 与 v4 的变化

| v3（遗留） | v4（当前） |
|-------------|--------------|
| `tailwind.config.js` | 基于 CSS 的 `@theme` 指令 |
| PostCSS 插件 | Oxide 引擎（速度提升 10 倍） |
| JIT 模式 | 原生，始终开启 |
| 插件系统 | CSS 原生功能 |
| `@apply` 指令 | 仍然可用，但已不推荐 |

### v4 核心概念

| 概念 | 描述 |
|---------|-------------|
| **CSS-first** | 配置在 CSS 中，而不是 JavaScript 中 |
| **Oxide 引擎** | 基于 Rust 的编译器，速度更快 |
| **原生嵌套** | 无需 PostCSS 的 CSS 嵌套 |
| **CSS 变量** | 所有令牌都暴露为 `--*` 变量 |

## 2. 基于 CSS 的配置

### 主题定义

```
@theme {
  /* 颜色 - 使用语义化名称 */
  --color-primary: oklch(0.7 0.15 250);
  --color-surface: oklch(0.98 0 0);
  --color-surface-dark: oklch(0.15 0 0);
  
  /* 间距尺度 */
  --spacing-xs: 0.25rem;
  --spacing-sm: 0.5rem;
  --spacing-md: 1rem;
  --spacing-lg: 2rem;
  
  /* 字体 */
  --font-sans: 'Inter', system-ui, sans-serif;
  --font-mono: 'JetBrains Mono', monospace;
}
```

### 何时扩展 vs 覆盖

| 操作 | 何时使用 |
|--------|----------|
| **扩展** | 在默认值旁边添加新值 |
| **覆盖** | 完全替换默认尺度 |
| **语义化令牌** | 项目特定的命名（primary、surface） |

## 3. 容器查询（v4 原生）

### 断点 vs 容器

| 类型 | 响应内容 |
|------|-------------|
| **断点** (`md:`) | 视口宽度 |
| **容器** (`@container`) | 父元素宽度 |

### 容器查询用法

| 模式 | 类名 |
|---------|---------|
| 定义容器 | 在父元素上使用 `@container` |
| 容器断点 | 在子元素上使用 `@sm:`, `@md:`, `@lg:` |
| 命名容器 | 使用 `@container/card` 以提高特异性 |

### 何时使用

| 场景 | 使用 |
|----------|-----|
| 页面级布局 | 视口断点 |
| 组件级响应式 | 容器查询 |
| 可重用组件 | 容器查询（上下文无关） |

---

## 4. 响应式设计

### 断点系统

| 前缀 | 最小宽度 | 目标 |
|--------|-----------|--------|
| (无) | 0px | 移动端基础 |
| `sm:` | 640px | 大型手机/小型平板 |
| `md:` | 768px | 平板 |
| `lg:` | 1024px | 笔记本电脑 |
| `xl:` | 1280px | 台式机 |
| `2xl:` | 1536px | 大型台式机 |

### 移动端优先原则

1. 首先编写移动端样式（无前缀）
2. 使用前缀添加较大屏幕的覆盖样式
3. 示例：`w-full md:w-1/2 lg:w-1/3`

## 5. 暗黑模式

### 配置策略

| 方法 | 行为 | 何时使用 |
|--------|----------|----------|
| `class` | `.dark` 类切换 | 手动主题切换器 |
| `media` | 遵循系统偏好 | 无用户控制 |
| `selector` | 自定义选择器（v4） | 复杂主题 |

### 暗黑模式模式

| 元素 | 浅色 | 深色 |
|---------|-------|------|
| 背景 | `bg-white` | `dark:bg-zinc-900` |
| 文本 | `text-zinc-900` | `dark:text-zinc-100` |
| 边框 | `border-zinc-200` | `dark:border-zinc-700` |

## 6. 现代布局模式

### Flexbox 模式

| 模式 | 类名 |
|---------|---------|
| 中心对齐（两个轴） | `flex items-center justify-center` |
| 垂直堆叠 | `flex flex-col gap-4` |
| 水平行 | `flex gap-4` |
| 间距分布 | `flex justify-between items-center` |
| 包裹网格 | `flex flex-wrap gap-4` |

### Grid 模式

| 模式 | 类名 |
|---------|---------|
| 自动适应响应式 | `grid grid-cols-[repeat(auto-fit,minmax(250px,1fr))]` |
| 非对称（Bento） | `grid grid-cols-3 grid-rows-2` 并使用跨度 |
| 侧边栏布局 | `grid grid-cols-[auto_1fr]` |

> **注意：** 优先使用非对称/Bento 布局，而不是对称的 3 列网格。

## 7. 现代颜色系统

### OKLCH vs RGB/HSL

| 格式 | 优势 |
|--------|-----------|
| **OKLCH** | 感知均匀，更适合设计 |
| **HSL** | 直观的色调/饱和度 |
| **RGB** | 遗留兼容性 |

### 颜色令牌架构

| 层级 | 示例 | 目的 |
|-------|---------|---------|
| **原始** | `--blue-500` | 原始颜色值 |
| **语义化** | `--color-primary` | 基于用途的命名 |
| **组件** | `--button-bg` | 组件特定 |

## 8. 字体系统

### 字体堆栈模式

| 类型 | 推荐 |
|------|-------------|
| 无衬线 | `'Inter', 'SF Pro', system-ui, sans-serif` |
| 等宽 | `'JetBrains Mono', 'Fira Code', monospace` |
| 展示 | `'Outfit', 'Poppins', sans-serif` |

### 字体尺度

| 类名 | 大小 | 使用 |
|-------|------|-----|
| `text-xs` | 0.75rem | 标签、说明文字 |
| `text-sm` | 0.875rem | 次要文本 |
| `text-base` | 1rem | 正文 |
| `text-lg` | 1.125rem | 主标题 |
| `text-xl`+ | 1.25rem+ | 标题 |

## 9. 动画与过渡

### 内置动画

| 类名 | 效果 |
|-------|--------|
| `animate-spin` | 持续旋转 |
| `animate-ping` | 注意力脉冲 |
| `animate-pulse` | 轻微的不透明度脉冲 |
| `animate-bounce` | 弹跳效果 |

### 过渡模式

| 模式 | 类名 |
|---------|---------|
| 所有属性 | `transition-all duration-200` |
| 特定属性 | `transition-colors duration-150` |
| 带缓动 | `ease-out` 或 `ease-in-out` |
| 悬停效果 | `hover:scale-105 transition-transform` |

## 10. 组件提取

### 何时提取

| 信号 | 操作 |
|--------|--------|
| 相同的类组合 3 次以上 | 提取组件 |
| 复杂的状态变体 | 提取组件 |
| 设计系统元素 | 提取并记录 |

### 提取方法

| 方法 | 何时使用 |
|--------|----------|
| **React/Vue 组件** | 需要动态、需要 JavaScript |
| **CSS 中的 `@apply`** | 静态、不需要 JavaScript |
| **设计令牌** | 可重用的值 |

---

## 11. 反模式

| 不要 | 要 |
|-------|-----|
| 到处使用任意值 | 使用设计系统尺度 |
| `!important` | 正确处理特异性 |
| 内联 `style=` | 使用实用工具 |
| 重复长类名列表 | 提取组件 |
| 混合 v3 配置与 v4 | 完全迁移到 CSS-first |
| 大量使用 `@apply` | 优先使用组件 |

---

## 12. 性能原则

| 原则 | 实现 |
|-----------|----------------|
| **清除未使用的** | v4 中自动执行 |
| **避免动态性** | 无模板字符串类 |
| **使用 Oxide** | v4 默认，速度提升 10 倍 |
| **缓存构建** | CI/CD 缓存 |
