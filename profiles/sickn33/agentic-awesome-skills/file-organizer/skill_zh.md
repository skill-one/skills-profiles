# 文件组织工具

## 何时使用此技能

- 下载文件夹杂乱无章
- 找不到文件因为它们散落在各处
- 存在重复文件占用空间
- 文件夹结构不再合理
- 想要建立更好的组织习惯
- 开始新项目需要良好结构
- 清理旧项目准备归档

## 此技能的功能

1. **分析当前结构**：检查您的文件夹和文件以了解您拥有什么
2. **查找重复文件**：识别系统中的重复文件
3. **建议组织方案**：根据您的内容提出合理的文件夹结构
4. **自动清理**：在您的批准下移动、重命名和组织文件
5. **保持上下文**：根据文件类型、日期和内容做出智能决策
6. **减少杂乱**：识别您可能不再需要的旧文件

## 使用说明

当用户请求文件组织帮助时：

1. **理解范围**

   提出澄清问题：

   - 哪个目录需要组织？（下载、文档、整个主文件夹？）
   - 主要问题是什么？（找不到东西、重复、太乱、没有结构？）
   - 有任何文件或文件夹要避免吗？（当前项目、敏感数据？）
   - 组织的激进程度如何？（保守与彻底清理）

2. **分析当前状态**

   检查目标目录：

   ```bash
   # 获取当前结构的概览
   ls -la [目标目录]

   # 检查文件类型和大小
   find [目标目录] -type f -exec file {} \; | head -20

   # 识别最大文件
   du -sh [目标目录]/* | sort -rh | head -20

   # 统计文件类型
   find [目标目录] -type f | sed 's/.*\.//' | sort | uniq -c | sort -rn
   ```

   总结发现：

   - 文件和文件夹总数
   - 文件类型分布
   - 大小分布
   - 日期范围
   - 明显的组织问题

3. **识别组织模式**

   根据文件确定逻辑分组：

   **按类型**：

   - 文档（PDF、DOCX、TXT）
   - 图片（JPG、PNG、SVG）
   - 视频（MP4、MOV）
   - 压缩文件（ZIP、TAR、DMG）
   - 代码/项目（包含代码的目录）
   - 电子表格（XLSX、CSV）
   - 演示文稿（PPTX、KEY）

   **按用途**：

   - 工作与个人
   - 活动与归档
   - 项目特定
   - 参考材料
   - 临时/草稿文件

   **按日期**：

   - 当前年份/月份
   - 前几年
   - 非常旧的（归档候选）

4. **查找重复文件**

   当请求时，搜索重复文件：

   ```bash
   # 通过哈希查找精确重复文件
   find [目录] -type f -exec md5 {} \; | sort | uniq -d

   # 查找名称相似的文件
   find [目录] -type f -printf '%f\n' | sort | uniq -d

   # 查找大小相似的文件
   find [目录] -type f -printf '%s %p\n' | sort -n
   ```

   对于每组重复文件：

   - 显示所有文件路径
   - 显示大小和修改日期
   - 建议保留哪个（通常是最新或命名最好的）
   - **重要**：删除前必须确认

5. **提出组织计划**

   在进行更改前提供清晰的计划：

   ```markdown
   # [目录] 组织计划

   ## 当前状态

   - X 个文件分布在 Y 个文件夹中
   - 总大小 [大小]
   - 文件类型：[分布]
   - 问题：[列出问题]

   ## 建议结构

   [目录]/
   ├── 工作/
   │ ├── 项目/
   │ ├── 文档/
   │ └── 归档/
   ├── 个人/
   │ ├── 照片/
   │ ├── 文档/
   │ └── 媒体/
   └── 下载/
   ├── 待整理/
   └── 归档/

   ## 我将进行的更改

   1. **创建新文件夹**：[列表]
   2. **移动文件**：
      - X 个 PDF → 工作/文档/
      - Y 张图片 → 个人/照片/
      - Z 个旧文件 → 归档/
   3. **重命名文件**：[任何重命名模式]
   4. **删除**：[重复文件或垃圾文件]

   ## 需要您决定的文件

   - [列出任何不确定的文件]

   准备继续？(是/否/修改)
   ```

6. **执行组织**

   在批准后系统性地组织：

   ```bash
   # 创建文件夹结构
   mkdir -p "path/to/new/folders"

   # 带清晰日志移动文件
   mv "old/path/file.pdf" "new/path/file.pdf"

   # 使用一致模式重命名文件
   # 示例："YYYY-MM-DD - 描述.ext"
   ```

   **重要规则**：

   - 删除任何东西前必须确认
   - 记录所有移动以备撤销
   - 保留原始修改日期
   - 优雅处理文件名冲突
   - 遇到意外情况时停止并询问

7. **提供总结和维护建议**

   组织完成后：

   ```markdown
   # 组织完成！✨

   ## 更改内容

   - 创建 [X] 个新文件夹
   - 组织 [Y] 个文件
   - 通过删除重复文件释放 [Z] GB
   - 归档 [W] 个旧文件

   ## 新结构

   [显示新的文件夹树]

   ## 维护建议

   为保持组织：

   1. **每周**：整理新下载
   2. **每月**：审查并归档已完成的项目
   3. **每季度**：检查新重复文件
   4. **每年**：归档旧文件

   ## 您的快速命令

   # 查找本周修改的文件

   find . -type f -mtime -7

   # 按类型整理下载

   [自定义命令]

   # 查找重复文件

   [自定义命令]
   ```

## 最佳实践

### 文件夹命名

- 使用清晰描述性名称
- 避免空格（使用连字符或下划线）
- 具体化："客户提案"而不是"文档"
- 使用前缀排序："01当前"、"02归档"

### 文件命名

- 包含日期："2024-10-17会议记录.md"
- 描述性："q3财务报告.xlsx"
- 名称中避免版本号（使用版本控制）
- 移除下载痕迹："document-final-v2 (1).pdf" → "document.pdf"

### 何时归档

- 6个月以上未触碰的项目
- 可能以后参考的已完成工作
- 迁移到新系统后的旧版本
- 不确定是否删除的文件（先归档）
