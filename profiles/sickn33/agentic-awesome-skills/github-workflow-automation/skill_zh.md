# 🔧 GitHub 工作流自动化

> 使用 AI 辅助自动化 GitHub 工作流，灵感来源于 [Gemini CLI](https://github.com/google-gemini/gemini-cli) 和现代 DevOps 实践。

## 详细指南

执行此技能前，请阅读 [详细指南](references/detailed-guide.md)。该指南保留了完整流程和参考资料。将其安全性、先决条件和验证要求视为强制性。对于专注工作，加载相关章节；对于端到端工作，完整阅读指南。

## 何时使用此技能

在以下情况下使用此技能：

- 使用 AI 自动化 PR 审查
- 设置问题分派自动化
- 创建 GitHub Actions 工作流
- 将 AI 集成到 CI/CD 管道
- 自动化 Git 操作（变基、挑选）

---

## 限制

- 仅当任务明确匹配上述范围时才使用此技能。
- 不要将输出视为环境特定验证、测试或专家审查的替代品。
- 如果缺少必需的输入、权限、安全边界或成功标准，请停止并请求澄清。
