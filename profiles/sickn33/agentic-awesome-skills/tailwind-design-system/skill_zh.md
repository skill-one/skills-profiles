# Tailwind 设计系统

使用 Tailwind CSS 构建 production-ready 设计系统，包括设计令牌、组件变体、响应式模式和可访问性。

## 使用此技能当

- 使用 Tailwind 创建组件库
- 实现设计令牌和主题
- 构建响应式和可访问的组件
- 在代码库中标准化 UI 模式
- 迁移到或扩展 Tailwind CSS
- 设置暗黑模式和配色方案

## 不使用此技能当

- 任务与 Tailwind 设计系统无关
- 您需要此范围之外的不同的域或工具
