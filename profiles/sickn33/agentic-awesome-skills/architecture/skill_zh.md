## 核心原则

**"简单是终极的复杂。**"

- 从简单开始
- 仅在证明有必要时才增加复杂性
- 你可以随时添加模式
- 移除复杂性比添加它要困难得多

## 验证清单

在最终确定架构之前：

- [ ] 需求清晰理解
- [ ] 约束条件已识别
- [ ] 每个决策都有权衡分析
- [ ] 考虑了更简单的替代方案
- [ ] 对重要决策编写了ADR
- [ ] 团队专业知识与所选模式匹配
