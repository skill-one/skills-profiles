# 代理记忆系统

记忆是智能代理的基石。没有它，每一次交互都从零开始。这项技能涵盖了代理记忆的架构：短期记忆（上下文窗口）、长期记忆（向量存储）以及组织它们的认知架构。

关键洞察：记忆不仅仅是存储，更是检索。如果找不到正确的信息，存储的一百万个事实也毫无意义。分块、嵌入和检索策略决定了你的代理是记得还是忘记。

该领域存在术语不一致的问题。我们使用CoALA认知架构框架：语义记忆（事实）、情景记忆（经验）和程序记忆（如何操作的知识）。
