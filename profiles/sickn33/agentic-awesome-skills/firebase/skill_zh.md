# Firebase

Firebase 可在几分钟内为你提供完整的后端服务——认证、数据库、存储、函数和托管。但便捷的设置隐藏了真实的复杂性。安全规则是你最后的防线，而且它们常常是错误的。Firestore 查询有限制，而当你设计完数据模型后才会意识到这一点。

本技能涵盖 Firebase 认证、Firestore、实时数据库、云函数、云存储和 Firebase 托管。关键洞察：Firebase 优化用于读密集型、非规范化的数据。如果你在考虑关系模型，那你就想错了。

2025年课程：Firestore 的价格可能会让你吃惊。读取操作在达到某个阈值之前很便宜，但之后就会变得昂贵。一个设计不当的监听器可能比专用数据库的成本更高。根据你的查询模式而非数据关系来规划你的数据模型。
