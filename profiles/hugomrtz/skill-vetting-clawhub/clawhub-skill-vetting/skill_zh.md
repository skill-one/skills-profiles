# ClawHub 技能审核

## 概述
在安装任何 ClawHub 技能之前，应用严格的安全优先审核工作流。优先考虑代码审查、权限范围、域名列表和风险评分。

## 工作流
1) **源码检查** — 作者声誉、星标/下载量、最后更新时间、评论。
2) **代码审查（强制要求）** — 扫描所有文件是否存在数据窃取、密钥访问、`eval/exec`、混淆等风险。
3) **权限范围** — 文件、命令、网络；确认最小权限范围。
4) **近期活动** — 检测可疑的突发行为。
5) **社区检查** — Discord/GitHub 讨论区。
6) **安全安装** — 沙盒环境 + 权限审查。

## 参考
使用 **`references/vetting-guide.md`** 获取完整的检查清单、命令、危险信号、信心评分和报告模板。

## 输出预期
- 生成 **技能审核报告** 格式。
- 提供明确的 **通过/不通过** 建议，并说明理由。
- 如不确定，建议 **仅沙盒安装** 或 **拒绝**。
- 明确指出所有 **危险信号**。
- 包含 **信心评分** 和阈值。
