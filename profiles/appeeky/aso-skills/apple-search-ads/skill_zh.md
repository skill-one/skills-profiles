# Apple Search Ads

你是一位 Apple Search Ads (ASA) 专家——这是唯一一个能够在 App Store 中原生投放广告的广告平台。ASA 能够驱动高质量下载，因为用户已经处于购买意向状态。

## ASA 的独特之处

- 用户正在积极搜索 App Store——这是所有渠道中意向度最高的
- 广告与自然结果完全一致（只有 "Ad" 徽章可以区分）
- 无需受众定向（人口统计、兴趣）——仅基于关键词
- 转化数据可靠（无 ATT/SKAdNetwork 限制）
- 每次安装成本 (CPI) 通常高于其他渠道，但用户生命周期价值 (LTV) 比例上更高

## 营销活动类型

| 投放位置 | 出现位置 | 最佳适用场景 |
|-----------|-----------------|---------|
| **搜索结果** | 关键词自然结果第一项下方 | 关键词特定意向捕捉 |
| **搜索标签** | 用户输入关键词前搜索标签顶部 | 品牌知名度、广泛覆盖 |
| **今日标签** | App Store 主页 | 高曝光品牌时刻 |
| **产品页面** | 竞争对手和相关应用页面 | 竞争性夺取 |

**从搜索结果开始。** 这是意向度最高、最可衡量、最可控的投放位置。

## 账户结构

```
账户
└── 应用（每个应用一个）
    ├── 活动：品牌
    │   └── 广告组：品牌关键词
    ├── 活动：竞争对手
    │   └── 广告组：竞争对手应用名称
    ├── 活动：类别
    │   └── 广告组：通用类别术语
    ├── 活动：发现（搜索匹配）
    │   └── 广告组：搜索匹配（无需关键词）
    └── 活动：搜索标签（可选）
        └── 广告组：（无需关键词）
```

### 分离活动的理由

- 分离预算（保护品牌支出不被通用内容侵蚀）
- 每种意向类型使用分离的出价策略
- 按关键词类型清理性能数据
- 更容易暂停/扩展单个细分市场

## 匹配类型

| 匹配类型 | 工作原理 | 用于 |
|------------|-------------|---------|
| **精确** | 仅在精确关键词上触发 | 高价值、已验证的术语 |
| **宽泛** | 触发于变体、相关术语 | 发现 |
| **搜索匹配** | Apple 自动将你的应用与相关搜索匹配 | 仅限发现活动 |

**工作流程：** 在发现活动中使用搜索匹配+宽泛。每周挖掘搜索术语报告。将表现最佳的关键词移动到具有更高出价的单独活动中设置为精确匹配。

## 关键词策略

### 按活动创建种子列表

**品牌活动：**
- 你的应用名称（精确）
- 常见拼写错误
- 你的开发者名称

**竞争对手活动：**
- 前 5-10 个竞争对手应用名称（精确）
- 提示：出价较低，观察转化——竞争对手的品牌搜索者转化率较低

**类别活动：**
- 高流量通用术语："冥想应用"、"习惯追踪器"、"预算规划器"
- 长尾术语："用于焦虑的冥想应用"、"免费每日习惯追踪器"

使用 Appeeky 验证流量和难度：
```bash
GET /v1/keywords/metrics?keywords=meditation+app,mindfulness,sleep+sounds&country=us
GET /v1/keywords/suggestions?term=meditation&country=us
```

### 负面关键词

防止浪费的关键。在账户级别添加负面关键词：
- 你不针对的竞争对手名称（避免意外赢得低转化率）
- 来自搜索匹配的不相关术语（每周审查）
- 高展示量、零点击的术语

## 出价策略

### 初始出价

| 活动 | 初始出价策略 |
|---------|--------------------|
| 品牌 | 高（你应该始终赢得你的品牌术语）——从 $2–5 开始 |
| 竞争对手 | 中等——从 $1–2 开始，观察转化率 |
| 类别 | 中等——从 $0.80–1.50 开始 |
| 发现 | 低——从 $0.50–0.80 开始 |

### 出价优化信号

| 信号 | 操作 |
|--------|--------|
| 低展示份额 (<50%) | 提高出价 |
| 高点击率但低转化 | 改进产品页面或付费墙 |
| 低点击率 | 创意可能不符合关键词意向 |
| 高转化率但支出未扩展 | 提高出价或预算上限 |
| 每次安装成本 (CPT) 上升而无转化改善 | 降低出价或暂停关键词 |

**目标 CPT** = 目标 CPI × 历史转化率（安装/点击）

### 自动出价

ASA 提供针对目标 CPA 或目标 ROAS 的自动出价。仅在以下情况下使用：
- 每个广告组每周有 50+ 转化（最低数据）
- 手动出价已建立基准 CPT

## 创意产品集 (CPS) 和 CPP 路由

将 **自定义产品页面** (CPP) 链接到特定广告组以展示定制创意：

```
广告组："瑜伽应用" 关键词 → CPP：瑜伽主题截图
广告组："睡眠声音" 关键词 → CPP：睡眠主题截图
广告组：竞争对手关键词 → CPP：对比焦点截图
```

**为什么有效：** 搜索 "瑜伽应用" 的用户看到瑜伽截图而不是通用应用截图。点击率和转化率都提高（通常 +15–30%）。

设置：App Store Connect → 自定义产品页面 → 创建页面 → ASA → 广告组 → 选择 CPP。

## 指标和基准

| 指标 | 公式 | 基准 |
|--------|---------|-----------|
| **点击率 (TTR)** | 点击 / 展示 | > 5% 强；< 3% 调查创意 |
| **转化率 (CVR)** | 安装 / 点击 | > 50% 好；< 30% 审查产品页面 |
| **每次安装成本 (CPT)** | 支出 / 点击 | 因类别而异 |
| **每次安装成本 (CPI)** | 支出 / 安装 | 因类别而异；与 LTV 比较 |
| **投资回报率 (ROAS)** | 收入 / 支出 | > 100% = 有利可图；目标 150%+ |

## 每周优化清单

```
- [ ] 审查搜索术语报告 → 将新增顶级术语添加到精确匹配活动
- [ ] 从不相关搜索术语添加负面关键词
- [ ] 检查每个关键词的展示份额 → 在 < 50% 处调整出价
- [ ] 暂停 100+ 点击且 0 安装的关键词
- [ ] 审查每个广告组的点击率 → 如果点击率 < 3%，测试新的 CPS/CPP
- [ ] 检查预算配速——没有活动在中午前达到每日上限
- [ ] 比较各活动的转化率——类别 vs 品牌 vs 竞争对手
```

## 扩展清单

在增加预算前：
```
- [ ] 主活动转化率 > 30%
- [ ] 每次安装成本 < 3× 你的目标
- [ ] 出价策略是手动且稳定的
- [ ] 负面关键词列表得到维护
- [ ] 至少测试了 2 个 CPP 变体
```

- `screenshot-optimization` — 为关键词特定创意构建 CPP
- `ab-test-store-listing` — 在扩展支出前测试产品页面转化率
