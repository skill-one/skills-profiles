# 竞争对手追踪

您可以设置并运行持续的竞争对手监控——在它们影响您的排名之前，捕捉元数据变化、关键词变化、评分下降和新功能发布。

## 一次性分析 vs 持续追踪

| | `competitor-analysis` 技能 | 此技能 (`competitor-tracking`) |
|---|---|---|
| **频率** | 一次性深度分析 | 每周/每月重复 |
| **输出** | 策略文档 | 变更日志 + 提醒 |
| **重点** | 差距分析、定位 | 发生了什么变化以及为什么这很重要 |
| **数据** | 快照 | 差异（之前 vs 之后） |

## 设置：定义您的监控清单

1. 检查 `app-marketing-context.md`
2. 询问：**您的前 3-5 名竞争对手是谁？**（如果可能，获取 App ID）
3. 询问：**您希望多久审查一次？**（建议每周）
4. 询问：**您最担心的是什么？**（关键词、评分、创意、价格）

如果未知，使用 Appeeky 识别竞争对手：
```bash
GET /v1/keywords/ranks?keyword=meditation&country=us&limit=10
GET /v1/apps/:id/intelligence  # 检查竞争对手数组
```

## 需要追踪的内容

### 元数据变化

每周使用 Appeeky 检查：
```bash
GET /v1/apps/:id  # 标题、副标题、描述
```

留意：
- **标题变化** — 新的关键词正在被瞄准，重新定位
- **副标题变化** — 测试新的钩子或关键词
- **描述变化** — 消息策略转变（尤其是在 Google Play）
- **截图更新** — 新的创意方向或 A/B 测试获胜者已发布

### 关键词排名变化

```bash
GET /v1/apps/:id/keywords  # 他们的排名关键词
GET /v1/keywords/ranks?keyword=[shared keyword]  # 谁在什么位置排名
```

留意：
- 他们新排名的关键词（他们优化了这些——您应该吗？）
- 他们放弃的关键词（机会来捕捉）
- 一个竞争对手在共享关键词上超过您

### 评分和评论

```bash
GET /v1/apps/:id/reviews?sort=recent&limit=20
GET /v1/apps/:id  # 当前评分
```

留意：
- 评分下降（他们发布了一个糟糕的更新——机会突出您的稳定性）
- 围绕特定投诉的 1 星激增（您可以解决的用户新痛点）
- 新的正面评论赞扬您没有的功能

### 图表位置

```bash
GET /v1/market/movers?genre=[genre_id]&country=us
GET /v1/categories/:id/top?country=us&limit=25
```

留意：
- 一个竞争对手进入或退出您类别的前 10 名
- 新的竞争对手从图表上升进入您的领域

### 定价和付费墙

每 4-6 周手动检查：
- 试验长度变化
- 价格变化（降低 = 侵略性增长；提高 = LTV 优化）
- 新的付费墙格式或计划

## 每周竞争对手报告模板

每周一运行此分析：

```
竞争对手更新 — [日期] 周的

追踪的应用：[列出名称]

检测到的变更：
━━━━━━━━━━━━━━━━━
[竞争对手名称]
  元数据：[已更改 / 未更改]
    → [如果有具体更改]
  顶级关键词：[获得 X / 失去 Y / 稳定]
  评分：[X.X → X.X] （本周 +/-N 个评分）
  图表位置：[#N → #N 在类别中]
  新评论主题：[如果有显著变化]

[针对每个竞争对手重复]

识别的机会：
1. [竞争对手 X 放弃了关键词 Y——考虑瞄准它]
2. [竞争对手 X 关于 Z 的投诉激增——您的优势]
3. [竞争对手 X 提高了价格——定位机会]

威胁：
1. [竞争对手 X 现在排名 #3 对于 [关键词]——我们排在 #8]
2. [发现了新进入者：[名称]——检查他们的元数据]

行动项：
1. [对某个变更的特定响应]
2. [基于竞争对手差距要瞄准的关键词]
```

## 每月深度分析触发器

在以下情况下运行完整的 `competitor-analysis`：
- 一个竞争对手在类别图表中上升 10+ 位
- 一个竞争对手更改了他们的标题（表明重大重新定位）
- 新的竞争对手进入您类别的前 10 名
- 您在竞争对手最近瞄准的关键词上的排名下降

## 自动化选项

### 手动（推荐给小团队）

设置日历提醒。运行上述 Appeeky API 调用。填写模板。

### 半自动化

构建一个脚本，每周调用 Appeeky 并比较结果：

```bash
#!/bin/bash
APPS=("6759740679" "987654321" "111222333")
KEY="apk_your_key"

for APP_ID in "${APPS[@]}"; do
  echo "=== $APP_ID ==="
  curl -s "https://api.appeeky.com/v1/apps/$APP_ID" \
    -H "X-API-Key: $KEY" | jq '.data | {title, subtitle, rating, reviewCount}'
done
```

每周存储结果并与上一周的输出进行比较。

### Appeeky MCP（在 Claude/Cursor 中）

每周一询问您的代理：
```
"对应用 [ID1]、[ID2]、[ID3] 进行竞争对手检查，并
与上周比较他们的元数据和顶级关键词。"
```

代理将使用 `get_app`、`get_app_keywords`、`get_app_reviews` 生成报告。

## 竞争对手响应剧本

| 发生了什么变化 | 响应 |
|-------------|---------|
| 竞争对手在标题中瞄准了您的 #1 关键词 | 防御：检查您的元数据是否完全优化；考虑增加 ASA 出价 |
| 竞争对手放弃了一个您共享的关键词 | 机会：加倍努力，增加 ASA 中的出价 |
| 竞争对手升级了截图 | 审计您的——它们在类别中仍然是最好的吗？ |
| 竞争对手的评分低于 4.0 | 在差距可见时，在推广文本中提及您的评分 |
| 竞争对手推出了一个您没有的功能 | 记录在路线图中；同时突出您的差异化优势 |
| 新的竞争对手进入前 10 名 | 对他们运行完整的 `competitor-analysis` |

## 相关技能

- `competitor-analysis` — 深度一次性竞争策略
- `keyword-research` — 对您发现的关键词差距采取行动
- `market-movers` — 自动捕捉图表级别的竞争对手移动
- `apple-search-ads` — 使用 ASA 出价对竞争对手关键词移动做出响应
- `aso-audit` — 在发现竞争差距后对自己运行
