# ASC 指标

您分析用户在 Appeeky 中同步的 **官方 App Store Connect 数据** — 精确的下载量、收入、IAP、订阅和试用情况。这是第一方数据，不是估算数据。

## 前置条件

- 已连接 ASC 的 Appeeky 账户（设置 → 集成 → App Store Connect）
- Indie 计划或更高（每个请求 2 个积分）
- 每日同步数据；最多可查看 90 天的历史数据

如果 ASC 未连接，提示用户在 [appeeky.com/settings](https://appeeky.com) 连接它，然后返回。

## 初步评估

1. 检查 `app-marketing-context.md` — 读取它以了解应用上下文
2. 询问：**您想分析什么？**（下载量、收入、订阅、国家细分、趋势比较）
3. 询问：**哪个时间段？**（默认：最近 30 天）
4. 询问：**特定应用还是所有应用？**

## 获取数据

### 第 1 步 — 列出可用应用

```bash
GET /v1/connect/metrics/apps
```

如果用户尚未知道应用信息，将其与 `app_apple_id` 匹配。

### 第 2 步 — 获取概览（组合）

```bash
GET /v1/connect/metrics?from=YYYY-MM-DD&to=YYYY-MM-DD
```

### 第 3 步 — 获取应用详情（单个应用）

```bash
GET /v1/connect/metrics/apps/:appId?from=YYYY-MM-DD&to=YYYY-MM-DD
```

响应包括：`daily[]`、`countries[]`、`totals`。

查看完整 API 参考：[appeeky-connect.md](../../tools/integrations/appeeky-connect.md)

## 分析框架

### 期间对比

获取两个等长的时间窗口并比较：

| 指标 | 先前期间 | 当前期间 | 变化 |
|------|----------|----------|------|
| 下载量 | [N] | [N] | [+/-X%] |
| 收入 | $[N] | $[N] | [+/-X%] |
| 订阅 | [N] | [N] | [+/-X%] |
| 试用 | [N] | [N] | [+/-X%] |
| 试用→订阅率 | [X]% | [X]% | [+/-X pp] |

**需要关注：**
- 下载量上升但收入持平 → 定价或付费墙问题
- 试用上升但转化率持平 → 付费墙或用户引导问题
- 收入上升但下载量持平 → 良好的变现改进

### 每日趋势分析

从 `daily[]` 中识别：
- **峰值** — 是否由功能、更新或媒体报道触发？
- **下降** — 与应用更新、季节性或算法变化相关联
- **趋势方向** — 7 天移动平均 vs 先前 7 天

### 国家细分

按下载量和收入对 `countries[]` 排序：
1. **下载量前 5 的国家** — 您是否在这些市场进行 ASO 投入？
2. **收入前 5 的国家** — 更高的 ARPD（每下载平均收入）= 优先进行 ASO
3. **下载量高、收入低** — 变现较弱的市场
4. **下载量低、收入高** — 未充分挖掘的付费市场（本地化）

### 收入质量检查

根据数据计算：

| 指标 | 公式 | 基准 |
|------|------|------|
| ARPD | 收入 / 下载量 | > $0.05 良好；> $0.20 优秀 |
| 试用率 | 试用 / 下载量 | > 20% 表示强付费墙覆盖 |
| 订阅转化率 | 订阅 / 试用 | > 25% 是强劲的 |
| 每订阅收入 | 收入 / 订阅 | 取决于定价 |

当检测到显著变化（>20%）时，标记它：

```

    可能原因：[列出 2-3 个假设]
    下一步：[具体的诊断行动]
```

## 常见问题

**"为什么我的下载量下降？"**
1. 拉取每日趋势 — 何时开始的？
2. 检查是否在该日期发布了更新
3. 检查关键词排名（使用 `keyword-research` 技能）
4. 检查竞争对手活动（使用 `competitor-analysis` 技能）

**"我应该为哪些国家进行本地化？"**
拉取国家细分 → 按下载量排序 → 标记高下载量非英语市场 → 使用 `localization` 技能

**"我的变现在改善吗？"**
比较期间内的试用率和试用→订阅率 → 使用 `monetization-strategy` 技能进行付费墙改进

## 相关技能

- `app-analytics` — 完整分析堆栈设置和 KPI 框架
- `monetization-strategy` — 提高订阅转化率和付费墙
- `retention-optimization` — 使用指标作为输入减少流失
- `localization` — 扩大国家数据中表现最好的市场
- `ua-campaign` — 验证付费安装是否显示在下载量峰值中
