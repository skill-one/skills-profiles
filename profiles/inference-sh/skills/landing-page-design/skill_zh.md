# 站点页面设计

通过 [inference.sh](https://inference.sh) CLI 使用 AI 生成的视觉效果设计高转化率的站点页面。

## 快速入门

> 需要 inference.sh CLI（belt）。[安装说明](https://raw.githubusercontent.com/inference-sh/skills/refs/heads/main/cli-install.md)

```bash
belt login

# 生成英雄图片
belt app run falai/flux-dev-lora --input '{
  "prompt": "专业人士微笑着使用笔记本电脑显示干净的仪表板界面，明亮的现代办公室，自然光照，温暖而富有生产力的氛围，生活方式营销摄影",
  "width": 1248,
  "height": 832
}'

# 研究竞争对手的站点页面
belt app run tavily/search-assistant --input '{
  "query": "2024 年最佳 SaaS 站点页面示例 转化率"
}'
```

## 头部公式

在滚动前可见的部分必须在 5 秒内传达价值。

```
┌─────────────────────────────────────────────────┐
│  [Logo]              [导航]        [CTA 按钮]  │
│                                                 │
│   标题 (6-12 个字)                         │
│   ─────────────────────────                     │
│   副标题 (15-25 个字)        [英雄图片] │
│                                    显示        │
│   [主要 CTA 按钮]            结果，而不是  │
│   "免费试用"              产品   │
│                                                 │
│   社会证明： "被 10,000+ 团队信赖"      │
│   [logo] [logo] [logo] [logo] [logo]            │
└─────────────────────────────────────────────────┘
```

### 5 个元素

| 元素 | 规则 | 示例 |
|---------|------|---------|
| **标题** | 6-12 个字，陈述结果 | "几分钟内完成文档，而不是几天" |
| **副标题** | 15-25 个字，扩展说明 | "AI 驱动的文档，从您的代码库自动生成。不需要模板。" |
| **英雄图片** | 显示结果，而不是产品 | 满意地看着结果的人，而不是 UI 截图 |
| **主要 CTA** | 动词 + 价值 | "免费试用" 而不是 "提交" 或 "了解更多" |
| **社会证明** | Logo、数量或微型见证 | "被 10,000+ 团队在 [logos] 信赖" |

## 标题

### 转化公式

| 公式 | 示例 |
|---------|---------|
| [结果] 没有 [痛点] | "没有设计技能也能创建漂亮的文档" |
| [结果] 在 [时间段] | "5 分钟内发布您的网站" |
| [更好方式] 来 [常见任务] | "更快的方式来构建 API" |
| 停止 [痛点]。开始 [结果]。 | "停止猜测。开始了解。" |
| [数字] [事物] 来 [结果] | "一个工具来管理您所有的数据" |

### 标题失败的原因

```
❌ "欢迎来到我们的平台" (没有说明价值)
❌ "世界上最先进的 AI 驱动解决方案" (空话，没有具体内容)
❌ "我们帮助企业成长" (模糊，通用)
❌ "下一代企业软件" (它做什么?)

✅ "自动将客户反馈转化为产品功能"
✅ "像数据库一样思考的电子表格"
✅ "在您的用户发现问题之前找到并修复错误"
```

## 英雄图片

### 显示结果，而不是产品

```
❌ 您的仪表板截图 (无聊，一眼难以解析)
❌ 抽象的几何背景 (什么也不说)
❌ 手握的股票照片 (陈词滥调)

✅ 满意地看着屏幕上清晰结果的专业人士团队
✅ 变化前/后
✅ 使用您的产品的最终结果
```

## CTA 按钮

### 文本

| 好的 CTA | 坏的 CTA |
|-----------|----------|
| "免费试用" | "提交" |
| "免费开始" | "点击这里" |
| "查看实际效果" | "了解更多" (低承诺) |
| "创建您的第一个报告" | "注册" (模糊) |
| "免费试用 14 天" | "注册" |

**公式：** 动词 + 价值/结果 + (可选：降低风险)

### 设计

| 元素 | 规则 |
|---------|------|
| 颜色 | 与背景高对比度 — 必须是最显眼的元素 |
| 大小 | 最小 44px 高度 (点击目标)，足够宽以容纳文本 + 填充 |
| 位置 | 头部可见，在每次主要部分后重复 |
| 空白 | 按钮周围有足够的填充，不要挤它 |
| 次要 CTA | 如果需要，使用文本链接在下方 ("或观看演示") |

## 章节顺序

站点页面的验证顺序：

| 章节 | 目的 | 关键元素 |
|---------|---------|-------------|
| 1. **英雄** | 核心价值，主要 CTA | 标题 + 图片 + CTA |
| 2. **社会证明** | 建立信任 | Logo、数量、徽章 |
| 3. **问题** | 创建同理心 | 他们认识到的痛点 |
| 4. **解决方案/功能** | 展示您如何解决 | 3 个关键功能与视觉效果 |
| 5. **工作原理** | 降低复杂性 | 3 步：注册、配置、受益 |
| 6. **见证** | 证明它有效 | 2-3 个具体的客户引言 |
| 7. **定价** | 启用决策 | 清晰的层级，突出推荐 |
| 8. **常见问题解答** | 处理异议 | 5-7 个常见问题 |
| 9. **最终 CTA** | 捕获剩余部分 | 重复主要 CTA 并增加紧迫感 |

## 社会证明类型

| 类型 | 影响 | 位置 |
|------|--------|-----------|
| **公司 Logo** | 最快处理，高信任 | 英雄下方 |
| **用户数量** | 规模信号 | 英雄或社会证明条 |
| **星级评分** | 产品质量 | CTA 附近 |
| **见证** | 详细可信度 | 专用章节 |
| **案例研究统计数据** | 具体证明 | 功能章节 |
| **信任徽章** | 安全/合规 | 表单附近、定价、页脚 |

```bash
# 研究社会证明统计数据
belt app run exa/answer --input '{
  "question": "与没有社会证明相比，具有社会证明的 SaaS 站点页面的平均转化率是多少?"
}'
```

## 表单设计

| 规则 | 影响 |
|------|--------|
| 每个字段减少转化 ~11% | 最小化字段 |
| 姓名 + 邮箱 = 最大注册 | 不要询问电话、公司、角色 |
| 单列布局 | 不要使用多列表单 |
| 内联验证 | 立即显示错误，而不是提交时 |
| 清晰的错误消息 | "需要邮箱" 而不是 "第 3 个字段错误" |
| 提交按钮文本 = 动作 | "创建账户" 而不是 "提交" |

## 移动优化

| 规则 | 原因 |
|------|-----|
| CTA 按钮全宽 | 容易用拇指点击 |
| 滚动时粘性 CTA | 始终可访问 |
| 无水平滚动 | 破坏移动布局 |
| 字体最小 16px | iOS 放大小于 16px 的输入 |
| 点击目标最小 48x48px | Apple HIG，Google Material |
| 图片响应式 | 不要溢出视口 |
| 优先考虑标题 + CTA | 简化头部可见部分 |

## 页面速度

| 规则 | 目标 | 原因 |
|------|--------|-----|
| 英雄图片 | < 200 KB | 首先加载 |
| 总页面重量 | < 2 MB | 移动数据，耐心 |
| 滚动后懒加载 | 总是 | 只加载可见内容 |
| 最小化 JavaScript | < 200 KB | 阻碍渲染 |
| LCP (Largest Contentful Paint) | < 2.5s | Google 核心网络价值 |

## 常见错误

| 错误 | 问题 | 修复 |
|---------|---------|-----|
| 没有清晰的标题 | 访客不知道您做什么 | 6-12 个字，结果导向 |
| CTA 说 "了解更多" | 太低承诺 | 动词 + 具体价值 |
| 英雄是产品截图 | 难以解析，无聊 | 显示结果，使用生活方式图像 |
| 多个竞争 CTA | 决策瘫痪 | 一个主要 CTA，最多一个次要 |
| 没有社会证明 | 没有信任信号 | 添加 Logo、数量或见证 |
| 太多表单字段 | 转化率下降 ~11% 每个字段 | 姓名 + 邮箱最大 |
| 仅桌面设计 | 60%+ 流量是移动的 | 首先设计移动端 |
| 最终 CTA 没有紧迫感 | 访客离开并忘记 | "开始您的免费 14 天试用" |
