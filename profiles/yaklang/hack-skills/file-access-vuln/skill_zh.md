# 文件访问路由器

这是文件系统路径、下载端点、上传管道和文件预览处理的路由入口。

## 使用场景

- 参数、文件名、下载端点或导入流程影响文件路径
- 目标支持上传、预览、转码、提取、共享、下载或代理文件访问
- 您需要判断这是路径遍历/LFI问题还是上传验证/处理链问题

## 技能图谱

- [路径遍历 LFI](../path-traversal-lfi/SKILL.md)：路径遍历、文件读取、包装器滥用、包含链
- [上传不安全文件](../upload-insecure-files/SKILL.md)：上传验证、存储路径、处理链、覆盖风险、预览/共享边界

## 推荐流程

1. 首先识别入口点是路径参数、下载端点还是上传工作流
2. 然后定位问题出现在接受、存储、处理或服务阶段
3. 短路径链和上传绕过样本合并到主主题技能中；无需单独的载荷入口
