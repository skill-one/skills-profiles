# 品牌识别

从策略到执行的创建和管理品牌识别的全面指南。

## 品牌策略基础

### 什么是品牌？

```
品牌 = 人们心中的认知

品牌不是：
✗ 仅是一个标志
✗ 仅是一个视觉识别
✗ 你对自己的描述

品牌是：
✓ 对客户的承诺
✓ 情感连接
✓ 声望和信任
✓ 他人对你的描述
```

### 品牌层级

```
┌─────────────────────────────────────────┐
│           品牌使命                 │
│     你存在的理由（超越利润）       │
├─────────────────────────────────────────┤
│           品牌愿景                  │
│     你将要去向                  │
├─────────────────────────────────────────┤
│           品牌任务                  │
│     你将如何到达那里              │
├─────────────────────────────────────────┤
│           品牌价值观                  │
│     你所相信的                  │
├─────────────────────────────────────────┤
│         品牌个性                  │
│     你如何沟通                  │
├─────────────────────────────────────────┤
│         品牌识别                  │
│     视觉和语言表达              │
└─────────────────────────────────────────┘
```

## 品牌策略

### 品牌使命

```
模板：
我们存在是为了 [行动] 为 [受众]，
通过 [方式] 所以 [影响]。

示例：
耐克："为世界上的每一位运动员带来灵感和创新。"
巴塔哥尼亚："我们的业务是为了拯救我们的家园星球。"
特斯拉："加速世界向可持续能源的转型。"
```

### 品牌定位

```
定位声明模板：

对于 [目标受众]，
他们 [需要/想要]，
[品牌名称] 是一个 [类别]，
它 [关键利益]。
与 [竞争对手] 不同，
我们 [独特差异化]。

示例：
对于需要快速健康餐食的忙碌专业人士，
HelloFresh 是一个餐食配送服务，
它提供预先分量的食材和简单的食谱。
不同于去超市购物，
我们消除食物浪费和决策疲劳。
```

### 竞争定位图

```
               高价格
                    │
                    │
        高端     │     奢侈
        质量     │     独家
                    │
    ────────────────┼────────────────
                    │
        价值       │     地位
        基础       │     象征
                    │
                    │
               低价格

    低感知价值 ───────── 高感知价值
        价值                  价值
```

## 视觉识别系统

### 标志设计原则

```
有效标志特征：
┌─────────────────────────────────────────┐
│ ✓ 简洁：适用于任何尺寸             │
│ ✓ 易记：独特且独特     │
│ ✓ 经典：避免潮流              │
│ ✓ 多功能：适用于所有环境      │
│ ✓ 适当：符合行业        │
└─────────────────────────────────────────┘
```

### 标志类型

| 类型            | 描述         | 适合于                          |
| --------------- | ------------ | ----------------------------- |
| **文字标志**    | 公司名称样式 | 独特名称 (谷歌, 可口可乐)  |
| **字母标志**    | 仅使用首字母 | 长名称 (IBM, HBO)             |
| **品牌标志**   | 仅使用符号   | 已建立品牌 (苹果, 耐克)  |
| **组合标志**   | 符号 + 文字标志   | 多功能 (阿迪达斯, 芝士汉堡) |
| **徽章**      | 文字在符号内  | 传统 (星巴克, 哈雷)   |
| **吉祥物**      | 角色           | 友好品牌 (肯德基, 米其林)   |

### 标志安全区域

```
┌─────────────────────────────────────┐
│                                     │
│    ┌─────────────────────┐          │
│    │                     │          │
│    │    ┌───────────┐    │          │
│    │    │   标志    │    │  X = 标志高度
│    │    │           │    │
│    │    └───────────┘    │  最小安全区域
│    │         X           │  = X 在所有方向
│    │         ↓           │
│    └─────────────────────┘          │
│              X                      │
└─────────────────────────────────────┘
```

### 色彩系统

```
主色调板：
┌─────────────────────────────────────────┐
│ 主色调        │ 用于主要元素 │
│ #0066FF        │ 60% 的设计          │
├────────────────┼────────────────────────┤
│ 次色调        │ 支持元素    │
│ #00CC88        │ 30% 的设计          │
├────────────────┼────────────────────────┤
│ 强调色        │ CTA, 突出显示       │
│ #FF6B00        │ 10% 的设计          │
└────────────────┴────────────────────────┘

扩展色调板：
- 中性灰色 (背景, 文本)
- 成功/错误/警告状态
- 每种颜色的浅色/深色变体
```

## 品牌声音和语气

### 声音属性

```
定义 3-5 个声音特征：

示例（科技初创公司）：
┌─────────────────────────────────────────┐
│ 大胆                                    │
│ 我们不是：攻击性, 傲慢         │
│ 我们是：自信, 直接, 坚定    │
├─────────────────────────────────────────┤
│ 友好                                │
│ 我们不是：不专业, 随意       │
│ 我们是：温暖, 易接近, 有人情味       │
├─────────────────────────────────────────┤
│ 清晰                                   │
│ 我们不是：过度简化, 降低水平  │
│ 我们是：直截了当, 无专业术语    │
└─────────────────────────────────────────┘
```

### 语气范围

```
根据上下文调整语气：

俏皮 ◄────────────────────► 严肃

网站文案    ●───────────────────────
错误消息  ───────────●────────────
法律页面     ─────────────────────●──
社交媒体    ●───────────────────────
客户支持 ───────●───────────────
```

### 写作指南

```
要：
✓ 使用主动语态
✓ 保持句子简短
✓ 直接面向用户 (你/你的)
✓ 具体而非模糊
✓ 展示, 不要讲述

不要：
✗ 使用专业术语而不解释
✗ 写大段文字
✗ 显得居高临下
✗ 过度承诺
✗ 使用空洞的超级形容词
```

## 品牌指南文档

### 必要部分

```
1. 品牌概述
   - 品牌故事
   - 使命, 愿景, 价值观
   - 目标受众

2. 标志使用
   - 主要标志版本
   - 安全区域规则
   - 最小尺寸
   - 错误使用示例

3. 色彩板
   - 主要颜色 (十六进制, RGB, CMYK, 潘通)
   - 次要颜色
   - 色彩组合
   - 无障碍要求

4. 字体
   - 字体家族
   - 层级和使用
   - 网络字体与印刷字体
   - 备用字体

5. 图像和摄影
   - 风格指南
   - 摄影处理
   - 插画风格
   - 图标系统

6. 声音和语气
   - 写作原则
   - 上下文语气
   - 示例文案

7. 应用
   - 名片
   - 信头纸
   - 电子邮件签名
   - 社交媒体模板
   - 演示文稿模板
```

| 类型            | 描述        | 示例                     |
| --------------- | ------------ | ------------------------ |
| **描述性**      | 描述功能    | 通用电气, PayPal     |

| **混合**        | 组合词语     | Facebook, YouTube, Instagram |

### 标语公式

```
有效标语：
┌─────────────────────────────────────────┐
│ 利益导向: "Just Do It" (耐克)    │
│ 类别定义: "Search On" (谷歌)    │
│ 挑战性: "Think Different" (苹果)  │
│ 命令式: "Open Happiness" (可口可乐)│
│ 超级形容词: "The Ultimate Driving      │
│              Machine" (宝马)             │

特征:
- 短 (2-5 个词理想)
- 易记
- 品牌独特
- 永恒 (非时效性)
- 与定位一致
```

## 品牌审计

### 审计清单

```
视觉一致性
- [ ] 标志正确使用
- [ ] 色彩符合品牌调色板
- [ ] 字体一致
- [ ] 图像风格一致

声音一致性
- [ ] 语气适合渠道
- [ ] 关键信息得到强化
- [ ] 术语一致

体验一致性
- [ ] 客户旅程一致
- [ ] 触点连贯
- [ ] 承诺兑现

竞争定位
- [ ] 差异化清晰
- [ ] 目标受众到达
- [ ] 市场地位维持
```

### 品牌健康指标

| 指标             | 衡量内容               |
| ------------------ | ---------------------- |
| **认知度**      | 知道品牌的人的百分比           |
| **考虑度**      | 会考虑购买的人的百分比    |
| **偏好度**      | 比竞争对手更喜欢的人的百分比  |
| **忠诚度**      | 重复购买率           |
| **NPS**            | 推荐可能性        |
| **市场份额**     | 品牌提及量与竞争对手的比例 |

## 品牌重塑

### 何时重塑品牌

```
当需要重塑品牌时:
✓ 公司战略发生根本性变化
✓ 与另一家公司合并
✓ 目标受众发生重大变化
✓ 品牌有负面联想
✓ 视觉识别严重过时

不要仅仅因为:
✗ 新营销团队想要留下自己的印记
✗ 竞争对手已经重塑品牌
✗ "我们厌倦了我们的标志"
✗ 轻微的业务发展
```

### 重塑类型

| 类型        | 范围                     | 何时             |
| ----------- | ------------------------- | ---------------- |
| **更新**    | 更新现有元素  | 每 5-10 年 |
| **部分**    | 显著的视觉更新 | 策略转变   |
| **全面**    | 完全翻新         | 转型   |

## 最佳实践

### 要：

- 在设计前先进行策略
- 彻底研究竞争对手
- 与目标受众测试
- 创建全面指南
- 在系统内允许灵活性
- 规划所有触点
- 记录一切
- 定期审查和更新

### 不要：

- 跳过策略阶段
- 盲目跟随潮流
- 创建过于僵化的系统
- 忽视数字应用
- 忘记无障碍性
- 频繁重塑品牌
- 忽视内部采用
- 低估实施

## 品牌开发流程

```
阶段 1: 发现 (2-4 周)
├── 利益相关者访谈
├── 竞争分析
├── 受众研究
└── 品牌审计 (如果存在)

阶段 2: 策略 (2-3 周)
├── 定位开发
├── 品牌架构
├── 消息框架
└── 品牌个性

阶段 3: 识别 (4-6 周)
├── 视觉概念探索
├── 标志开发
├── 色彩和字体
├── 设计系统创建

阶段 4: 表达 (3-4 周)
├── 品牌指南
├── 模板和资源
├── 应用模型
└── 发布材料

阶段 5: 激活 (持续)
├── 内部发布
├── 外部发布
├── 培训和采用
└── 监控和改进
```
