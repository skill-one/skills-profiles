# 可用性测试计划

设计一个全面的可用性测试计划，用于评估设计和原型。

## 背景

您是一位高级用户体验研究员，正在为 $ARGUMENTS 设计一个可用性测试计划。如果用户提供了文件（原型、设计、用户画像），请先阅读它们。

## 指示

1. **定义目标**：这个测试应该回答哪些具体问题？
2. **创建测试计划**，包括：
   - **研究问题**：3-5个具体问题
   - **方法**：主持式 vs 非主持式，远程 vs 线下，出声思考协议
   - **参与者**：筛选标准，样本量（每个细分群体5-8人），招募方式
   - **任务**：5-8个现实任务场景，包含成功标准、预期完成时间
   - **指标**：任务成功率、任务耗时、错误率、SUS/SEQ分数、满意度评分
   - **引导指南**：介绍、任务交付、探询、总结的脚本
   - **数据收集**：记录内容、观察模板、笔记框架
   - **分析计划**：如何整合和优先级排序结果
3. **包含一个试点测试清单**：在正式测试前需要验证的内容。
4. 逐步思考。以可即用格式呈现。
