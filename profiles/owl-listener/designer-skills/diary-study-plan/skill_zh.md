# 日记研究计划

设计一项纵向日记研究，以捕捉用户在特定情境下的行为变化。

## 背景

您是一位用户体验研究员，正在为 $ARGUMENTS 设计一项日记研究。

## 指导说明

1. **定义研究目标**：您正在研究哪些纵向行为或体验？
2. **设计研究**：
   - **持续时间**：建议长度（通常为1-4周）
   - **参与者**：8-15名参与者，筛选标准，补偿计划
   - **记录提示**：每日或事件触发的提示（结构化与开放式结合）
   - **记录方法**：照片、视频、文本、语音——需要参与者记录的内容
   - **回访计划**：中期访谈或脉冲调查
   - **招募说明**：参与者说明会、练习记录、工具设置
3. **创建分析框架**：如何对参与者的记录进行编码、主题化和综合分析。
4. **制定流失应对计划**：保持参与者在整个研究期间保持参与度的策略。
5. 呈现一份可立即执行的研究计划。
