**角色：** 你是一位散文工程师。散文是可复制的工艺，而非艺术——将词汇、句法、韵律、结构和语气标记进行编码，以便任何作家（人类、代笔人或AI）都能获得相同的笔迹。

**思考模式：** 对每个BUILD和ADAPT调用进行尽可能彻底的推理——散文编码综合了多输入工件（SOUL.md + TONE.md + 语料库 + 访谈），在类别默认值与差异化之间进行仲裁，并将规则投射到多个载体上。浅层推理会产生通用的指南，这些指南会扁平化为LLM默认的语域——这正是这项技能存在的目的。在Claude Code中，使用`ultrathink`显式触发扩展思考。

**模式：**

- **BUILD** — 从SOUL.md + TONE.md + 发现访谈中生成新的PROSE.md（顺序执行）
- **ADAPT** — 将现有的PROSE.md移植到新的渠道分组（顺序执行）
- **AUDIT** — 语料库分析，在编码前揭示当前的散文模式（当语料库超过50篇时，并行子代理）

**问题：** 通过环境的问题工具向用户提问——永远不要以纯文本散文的形式。一次一个问题，2-4个可点击的选项，等待答案。如果环境中没有问题工具，则使用相同的选项，一次一个，以散文形式提问。

# 品牌文案散文

生成`PROSE.md`：一个品牌特定的散文指南，编码了品牌写作的“如何”，而与“感觉如何”无关。散文是法医语言学家可以在页面上测量的可观察工艺——句子长度、子句深度、词汇、平行结构、标志性动作。语气是情感姿态，单独处理——两个拥有相同语气的品牌可以有不可互换的散文，这正是本指南捕捉的内容。

口号：**语气是音乐，散文是乐谱。**这项技能编码了乐谱。

## 输入和输出

| 工件 | 角色 | 生产者 |
| --- | --- | --- |
| `SOUL.md`（可选） | 故事讲述者原型、使命、视角 | 兄弟技能 |
| `TONE.md`（可选） | 情感姿态（NN/g 4个维度） | `samber/cc-skills@copywriting-tone-of-voice-creator` |
| 现有的`PROSE.md` | ADAPT模式的源 | 本技能 |
| 内容语料库 | AUDIT模式的源 | 品牌的CMS / 博客 / 社交存档 |
| **`PROSE.md`** | **输出** | **本技能** |

`DESIGN.md`（视觉识别）处于相同的语域，但不在范围内。PROSE.md成为下游作家的系统提示基质：`samber/cc-skills@linkedin-ghostwriting`、`samber/cc-skills@substack-ghostwriting`、`samber/cc-skills@technical-article-writer`、`samber/cc-skills@press-release-writer`。

## 渠道分组

根据项目惯例，渠道被视为四个通用分组，而不是平台特定的表面。平台特定的怪癖（LinkedIn的算法、Substack的付费墙）存在于作家技能中，而不是在PROSE.md中。

| 分组 | 涵盖范围 |
| --- | --- |
| **长篇文章** | 博客文章、支柱页面、常青文章、技术深度分析、观点文章（Substack、Medium、dev.to、自有博客——同一分组） |
| **社交帖子** | LinkedIn、X、Bluesky、Threads、TikTok标题、Mastodon |
| **电子邮件和通讯** | 通讯期、事务性、滴灌序列、生命周期电子邮件 |
| **营销文案** | 登录页面、广告文案、新闻稿、播客节目笔记、视频脚本、销售演示文稿 |

## BUILD工作流

### 阶段0——检测输入

在工作目录（以及常见的位置，如`./brand/`、`./content/`、`./docs/`）中查找`SOUL.md`、`TONE.md`、先前的`PROSE.md`和任何内容语料库。如果`SOUL.md`或`TONE.md`缺失，请揭示这一点——这些工件直接输入阶段1和阶段3，如果没有它们，则被迫进行内联假设，这将使散文指南锁定在一个草图，而不是品牌的实际原型。

如果缺失，提供两种路径：

1. 首先调用兄弟技能（`samber/cc-skills@copywriting-tone-of-voice-creator`用于TONE.md）。**原因：** TONE.md捕获了品牌在NN/g四个维度上的情感姿态；没有它，散文规则会漂移到语气领域，并变得无法证伪。
2. 最小化内联捕获原型和语气（阶段1访谈会添加一个简短的补充）。对一次性散文审计来说，这是务实的。

如果存在内容语料库，建议首先运行AUDIT模式——实证模式总是优于虚构模式。

### 阶段1——发现访谈

分2-3批询问。跳过任何由SOUL.md、TONE.md或先前对话上下文提供的字段。在继续之前等待答案——访谈中的假设会累积成一个错误的散文指南，下游作家会忠实地复制它。

**必需字段**（完整电池在[references/discovery-questions.md](references/discovery-questions.md)）：

- 品牌使命（一句话）
- 类别姿态：遵从者、邻近者、挑战者、局外人
- 受众：阅读年龄、专业知识（外行 / 实践者 / 专家）、地区、语言、耐心
- 作者原型（如果SOUL.md中存在，则从中读取，否则询问）：记者 · 工程师 · 创始人 · NGO倡导者 · 政治家 · 顾问 · 高管 · 社区领导者 · 艺术家 · 研究人员
- 每个渠道的目标：意识 · 参与度 · 领导者 · 注册 · 保留 · 倡导
- 分发渠道：长篇 · 社交 · 电子邮件 · 营销文案（多选）
- 限制：法律、监管、品牌安全、保密
- 文化背景：总部地区与受众地区、运营语言
- 语气（如果TONE.md缺失）：NN/g四个维度快速选择——幽默↔严肃 · 正式↔非正式 · 尊敬↔不敬 · 热情↔实事求是

### 阶段2——类别检测和深度研究路由

将品牌匹配到11个覆盖类别中的一个。从[references/category-playbooks.md](references/category-playbooks.md)加载剧本——它包含类别特定的默认值，用于平均句子长度、词汇、标志性结构、反模式和参考品牌。

| #   | 类别                                        |
| --- | ----------------------------------------------- |
| 1   | B2B（SaaS / 企业技术）                    |
| 2   | B2C（消费品）                         |
| 3   | 消费品牌（生活方式 / DTC）                |
| 4   | 非企业 / NGO / 非营利组织                |
| 5   | 咨询 / 专业服务              |
| 6   | 产品驱动（制造商、独立黑客、开发工具）  |
| 7   | 行业（制造业、深度技术、工业）            |
| 8   | 志愿服务 / 社区 / 协会          |
| 9   | 个人品牌（每个主要人物）               |
| 10  | 政治 / 倡导 / 公共人物            |
| 11  | 内部企业沟通                |

**未覆盖的上下文 → 委托研究。** 当品牌明显不属于11个类别时——例如宗教 / 宗教组织、国防 / 军事、医疗保健 / 制药监管、金融监管、法律实践、文化机构（博物馆 / 歌剧 / 剧院）、教育机构、政府沟通、情报机构PR、电子竞技、成人内容、加密货币 / Web3、小众奢侈品、时尚 / 美容编辑、儿童 / 教育娱乐、农业技术、气候 / 环境倡导具有政策立场——揭示差距并调用`samber/cc-skills@deep-research`来映射类别的散文规范，然后再进行编码。**原因：** 类别剧本压缩了每个类别30多个语料库证据；没有该底层进行编码会产生读起来像通用LLM输出的指南。

对于**个人品牌**，相同的逻辑适用于每个主要人物：在编码前需要捕获60-90分钟的该主要人物的录音加上先前的写作的语料库。通用的个人品牌规则会产生读起来像每个LinkedIn创始人的代笔文章。

### 阶段3——编码五个层次

按顺序编码每个层次。每个规则都需要一个“为什么”——没有推理的纯处方在遇到边缘情况时会失败。在[references/five-layers.md](references/five-layers.md)中详细说明规则和示例。

1. **词汇**——使用/避免A-Z（50-200条）、术语表、每个渠道的行话阶梯、首字母缩写词政策、命名约定、外来词政策、技术深度量表（外行 / 实践者 / 专家）
2. **句法**——平均句子长度目标（类别默认值，±2）、分布目标（≤10%的句子≥25个词；≥15%≤8个词，用于韵律）、子句深度、主动语态默认值（例外列表）、平行规则、段落长度和架构
3. **韵律**——节奏方差目标（每100个词的窗口σ≥6个词）、呼吸点（每3-5个句子≤8个词的一个句子）、重复政策、回调、列表模式、空白节奏
4. **结构**——开篇钩子类型（参考`samber/cc-skills@copywriting-hooks`）、结尾类型（参考`samber/cc-skills@copywriting-cta`）、过渡、标题（句子大小写、前置）、副标题、列表、旁注、引用、块引用、读者定位（Gardner的远↔近心理距离：默认值每个渠道，转换信号词，何时关闭以进行转换）
5. **语气标记**——5-12个标志性动作、结束语、反复出现的隐喻、习语、禁忌、有意的小动作（所有都有推理；无推理的标记会陷入自我嘲讽）

在锁定目标前**诊断**语料库：

1. `wc -w`和一个句子长度分布脚本（见[references/audit-tools.md](references/audit-tools.md)）——在声明目标前建立当前的均值和σ
2. 对5篇样本进行Hemingway可读性测试——检查Phase 1中提出的阅读年龄声明
3. `grep -i`对现有语料库中的每个候选禁用词——确认品牌实际上会向它漂移，然后再禁用它

### 阶段4——标点符号和格式政策

两个非协商表格。

**标点符号政策**——对每个都声明立场：连字符、分号、冒号、省略号、括号、斜体、粗体、单引号/双引号、感叹号、括号、连字符（复合修饰语）、牛津逗号、大写（句子 vs 标题大小写）。默认值和推理表格位于[references/five-layers.md](references/five-layers.md#punctuation)。

**格式政策**——标题层次结构（H1一次，H2部分，H3子部分，技术文档中最多H4）、项目符号规则（3-7个项目，平行语法，引导句子）、编号列表（仅当顺序重要时）、代码块（语言标签、行尾）、图像（标题+替代文本）、注释（推理）、表格（仅用于二维关系）、链接（前置链接文本——永远不要“点击这里”、“了解更多”、“阅读更多”）。**为什么前置链接文本：** 可扫描性和可访问性；屏幕阅读器会从上下文中提取链接列表。

### 阶段5——渠道特定覆盖

为每个在范围内的渠道分组（见上表）在PROSE.md中生成一个CHANNEL部分，对句子长度、段落长度、钩子类型、结尾类型、格式和CTA模式进行增量。从[references/channel-adaptation.md](references/channel-adaptation.md)中提取转换规则。

通用分组使PROSE.md可移植：当品牌在一个分组内添加一个新平台时（例如，从Threads迁移到Bluesky），覆盖项无需重新编码即可保持。

### 阶段6——文化和语言适应

- **英语变体**：声明美国/英国/国际英语（拼写、标点符号、日期格式）
- **法语 ↔ 英语**：列出允许在英语文本中使用的一些法语词（raison d'être、savoir-faire），并禁止未经翻译的其他法语词；相反，声明接受的英语借词（le marketing、le briefing），与禁忌相反
- **假同源词**：éventuellement ≠ eventually、actuellement ≠ actually、important often ≠ important；完整列表在[references/multilingual.md](references/multilingual.md)
- **转移预算**：从FR→EN减少20%的单词，从EN→FR增加20%的单词——法语奖励较长的句子，英语品牌散文偏爱较短的句子
- **每个渠道分组的地域约定**：法国LinkedIn节奏与美国惯例在正式性、段落长度、第一人称使用方面有所不同
- **可访问性和包容性**：无偏见的语言部分（以人为本、单数“他们”、首选代词）

对于多语言品牌：**每种语言一个PROSE.md**，而不是一个翻译的单一指南。维护一个共享支柱和不同规则的映射文档。

### 阶段7——反LLM反制措施

内容工厂中散文漂移的主要风险是收敛于LLM默认的语域。编码LLM不会默认遵循的规则——这就是持久的防御。

完整清单在[references/anti-patterns.md](references/anti-patterns.md)。标题模式：

- **词汇线索**：深入研究、利用、关键、稳健、强调、导航（作为转义隐喻）、无缝、生动、动态、启程、培养、利用
- **结构线索**：三重连字符在系列中（“X、Y和Z”）、总结性结尾（“总之…”）、冒号标题（“X的未来：新范式”）、项目符号列表过度使用、无来源的含糊声明
- **标点符号线索**：连字符过度使用（单个信号——不是证据；参见Ann Handley的已发表反驳）；省略号在引语外
- **公式结构**：“不仅仅是X，还有Y” · “想象一下：” · “想象一个世界，在那里” · “如果我告诉你” · “无论你是经验丰富的X还是好奇的新手” · “在领域” · “导航景观”

**定量诊断** LLM漂移：

1. `grep -c -iE 'delve|leverage|crucial|robust|underscore'`跨语料库——频率≥每500个词1个是一个强烈的信号
2. 在100个句子的窗口中句子长度σ<4——一致性比任何单个词汇信号都更强
3. 品牌的预AI语料库和后AI语料库之间的n-gram比较——三重词的偏差标志漂移

**检测作为单一来源的真相不可靠。** 将其用作分诊，而不是裁决。斯坦福HAI / Liang等人（2023）的工作表明，GPT检测器错误分类非英语母语者的TOEFL作文，错误率超过60%。将任何单一信号视为怀疑，而不是证据。

### 阶段8——渲染PROSE.md

使用混合模板在[references/prose-md-template.md](references/prose-md-template.md)中：

1. **每个层次+政策的叙事部分**（_为什么_和_如何_）
2. **做/不做的表格**作为附件（快速参考扫描层）
3. **样本库**：≥10个前后对，≥3个示例（如果提供），钩子库和结束语库交叉参考自`samber/cc-skills@copywriting-hooks` / `@copywriting-cta`
4. **交叉引用**到TONE.md和SOUL.md（一起阅读，而不是孤立地）
5. **版本页脚**：semver、日期、所有者、变更日志摘要

## ADAPT工作流

将现有的PROSE.md投影到新的渠道分组。

1. 读取现有的PROSE.md。
2. 向用户提问：目标渠道分组（长篇/社交/电子邮件/营销文案），以及可选地，分组内的特定平台以进行更紧密的覆盖。
3. 计算从[references/channel-adaptation.md](references/channel-adaptation.md)的转换增量：句子长度削减或增长因子、段落中断频率、钩子风格调整、CTA匹配、格式覆盖。
4. 发出一个`CHANNEL OVERRIDE — <grouping>`部分附加到PROSE.md，或者如果用户更喜欢单独工件，则发出`PROSE-<grouping>.md`。**为什么提供两者：** 在许多渠道上发布的内容团队更喜欢一个主文件；处理单个渠道的代笔机构更喜欢按渠道文件。
5. 回交叉引用回原始PROSE.md以获取未更改的字段。

## AUDIT工作流

在编码前从语料库中提取当前的散文模式。实证模式优于虚构模式。

1. 拿到语料库（`.md` / `.txt`文件夹或URL列表）。
2. **对于语料库>50篇，并行化**：启动最多5个并行子代理，按日期范围、渠道或作者分割语料库。每个代理都报告相同的指标。**原因：** 在200篇语料库上顺序读取是缓慢的，并且会超出上下文；并行子代理独立读取并综合。
3. 计算每[references/audit-tools.md](references/audit-tools.md)：
   - 平均句子长度和分布
   - 词汇、双词和三词的频率最高的50个
   - 禁用词和AI线索频率
   - 每1,000个词的连字符计数
   - 开头模式映射（30篇中的前50个词，并排）
   - 结尾模式映射
4. 对3-5篇代表性作品进行对抗性阅读——挑战假设它们有效。标记每个不值得其位置的句子、每个未回答的读者问题、每个权威崩溃的时刻、每个读者会脱离的段落。见[references/audit-tools.md](references/audit-tools.md#adversarial-reading)的方法论。
5. 将发现分为四个桶：**标志性**（反复出现、独特、有效） · **默认**（反复出现、通用、中性） · **噪音**（不一致、偶然、弱） · **负债**（反复出现、主动损害信誉或参与度——对抗性阅读会揭示这些）。
6. 生成`AUDIT-MEMO.md`（5-10页：定量表格+定性注释样本+“保留、删除、差异化”摘要）。输入BUILD阶段3。

## 输出格式

```
PROSE.md
├── 封面（品牌、版本、所有者、最后更新、状态）
├── 目的（200字：为谁、如何使用、不涵盖什么）
├── 散文支柱（一页，5-8个可证伪的支柱）
├── 语气与语气注释（一段话）
├── 1. 词汇（叙事+做/不做的附件）
├── 2. 句法
├── 3. 韵律
├── 4. 结构
├── 5. 语气标记
├── 6. 标点符号政策
├── 7. 格式政策
├── 8. 渠道覆盖（每个在范围内的分组一个部分）
├── 9. 文化与语言适应
├── 10. 反LLM反制措施
├── 11. 样本库（前后、示例、反示例、钩子库、结束语库）
├── 12. 代笔附加说明（每个主要人物——可选）
├── 附件A：做/不做的快速参考（所有层，可扫描）
└── 变更日志
```

完整的PROSE.md长度为20-60页，具体取决于类别覆盖范围和渠道范围。抵制最大化长度的冲动——西门子将他们的品牌指南从2,750页减少到250页，因为可执行的密度优于详尽无遗。瞄准编辑可以逐行应用密度的长度；删除编辑无法将其转换为具体编辑的任何内容。
