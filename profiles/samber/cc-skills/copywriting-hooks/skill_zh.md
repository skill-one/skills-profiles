# 副文案钩子

## 方法

钩子的唯一工作就是让读者想要第二句话。声音、结构、格式，所有这些都遵循这一个工作。

是什么让读者想要第二句话，是五个**杠杆**：

1. **制造差距**。提出一个读者需要闭合的不完整事物。好奇心差距、问题、开放式循环。
2. **打破预测**。陈述一个违反读者先验的事物。反常识、定义反转、惊人的统计数据。
3. **进入场景**。加载感官或具体的细节，构建一个生动的框架。故事中、具体细节、时间锚点。
4. **承诺回报**。命名读者想要的结果。利益、"如果你...那么这个"，直接问题。
5. **借用分量**。依赖一个名字、数字或引言，这些都带有内嵌的权威。权威钩子、统计数据、带有不同意见的引言。

一个强大的钩子通常同时使用两个杠杆。"弗兰克·辛纳屈，拿着一杯波本威士忌..."是场景加开放式循环。"大多数人认为X。他们是错的。"是预测打破加差距。单一杠杆的钩子仍然可以起作用，但更容易被忽视。

三个进一步的原则：

- **具体胜于抽象**。用"Stripe、Shopify、Vercel"代替"许多公司"。用日期代替"最近"。用实际发现代替"研究显示"，或者删除该声明。
- **第一句话必须迫使第二句话**。冷读每个候选者。如果你在第一句话之后不想点击第二句话，就重写。
- **根据文章类型匹配技巧**。个人散文不会像教程那样开头。见下表的文章类型匹配。

---

## 行为

当这个技能被触发时：

1. **确认简报**。主题、受众、目标语言（英语、法语或两者），大约长度，在哪里发布。如果其中任何一项不明确且重要，请在生成之前询问。
2. **从下面的目录中选择3到4个钩子**，它们必须是真正不同的。不同的杠杆，而不是反常识的三个变种。
3. **每个钩子写2个候选者**，针对用户的文章。一个钩子内的两个候选者应该探索不同的角度（不同的轶事、不同的统计数据、不同的场景），而不是彼此的改写。
4. **使用下面的输出格式**呈现。
5. **通过问题工具提问**。选择是一个小的固定集合，这就是那个工具的用途。
6. **等待用户的挑选**。不要为他们挑选。
7. **在他们挑选之后**，命名这个选择将剩余文章提交给的内容。一个反常识钩子将提交第2到第3段来捍卫非共识的主张。一个场景开头将提交下一部分来解决场景或建设性地延迟它。

**多样化规则**。在你的3到4个选项中至少包括：

- 一个智力钩子（反常识、定义反转、历史类比、好奇心差距）
- 一个感官钩子（故事中、具体细节）
- 一个直接面向读者的钩子（条件、直接问题、承诺）

这保证了真正的选择。三个反常识的变种不是选择。

**类型匹配参考**：

| 文章类型 | 强钩子 | 避免 |
| --- | --- | --- |
| 技术深度分析 | 具体细节、统计数据、反常识、直接问题 | 个人忏悔、场景开头 |
| 个人散文 | 故事中、个人忏悔、时间锚点、定义反转 | 大声声明、直接问题 |
| 评论/反常识 | 大声声明、定义反转、反常识、带有不同意见的引言 | 温和的设置、词典开头 |
| 教程/如何做 | 直接问题（PAS）、承诺、条件 | 场景开头、历史类比 |
| 报道/调查 | 具体细节、时间锚点、故事中、统计数据 | 大声声明、定义反转 |
| 清单文章 | 好奇心差距、计数的赌注、条件 | 个人忏悔、故事中 |
| 长篇分析 | 历史类比、统计数据、反常识 | 直接问题 |
| 订阅邮件 | 个人忏悔加开放式循环、条件、好奇心差距 | 词典开头 |

## 输出格式

始终像这样精确呈现选项：

```
## 副文案钩子选项：[工作标题]

**选项 1：[钩子名称]** ([杠杆])
A. [候选者 1]
B. [候选者 2]

**选项 2：[钩子名称]** ([杠杆])
A. [候选者 1]
B. [候选者 2]

**选项 3：[钩子名称]** ([杠杆])
A. [候选者 1]
B. [候选者 2]

选择？回复字母组合（例如，"1B"）或"更多"以使用不同技巧。
```

如果用户说"更多"或"没有"，则生成3个不同的钩子（不是相同钩子的新候选者）。如果用户说"混合 1A 和 2B"，则写一个组合钩子并再次检查。

## 钩子目录（18）

每个钩子：它做什么、例子（混合英语和法语、真实和说明性）、何时使用、何时避免。

### 1. 好奇心差距

打开读者想要闭合的信息差距。

- 英语："Shen Yun 如何赚钱？简答：他们不赚钱。"（Packy McCormick）
- 英语："多年前，一种芥末主导了超市货架：French's。"（Gladwell，《番茄酱困境》）
- 法语："今年有三家法国初创公司突破了10亿。其中没有一家是科技公司的。"
- 英语："我已经是一名外科医生八年了。在过去几年里，我的手术室表现达到了平台期。"（Gawande）

**使用时**：你可以诚实地在2到3句话内闭合差距。差距必须是读者关心的。**避免**：模糊的差距（"你不会相信接下来发生了什么"），读者甚至无法猜测。

### 2. 反常识

推翻读者持有的共识信念。

- 英语："普遍观点认为，在生活中实现我们想要的东西的最佳方法是为特定的、可执行的目标设定目标。"（Clear，《忘记设定目标》，然后论证相反的观点）
- 英语："要做好某事，你必须喜欢它。这个想法并不新鲜。"（Graham，《做你喜欢的事》，然后使其复杂化）
- 英语："如果你对某事不喊'耶！'，就说不。"（Sivers）
- 法语："营销是人工智能无法做的一切！"（Truphème）

**使用时**：你有一个可辩护的非共识观点，并且有200到400字来捍卫它。**避免**：稻草人、无谓的挑衅、为了挑衅而挑衅的反常识。

### 3. 大声声明/承诺

在证明之前直接陈述结果。

- 英语："在60英里每小时时，这辆新劳斯莱斯最大的噪音来自电动钟表。"（Ogilvy）
- 英语："他们嘲笑我坐在钢琴前。但当我开始演奏！—"（Caples 1925）
- 英语："给我15分钟，我会给你超强的记忆力。"（Schwartz）
- 法语："5分钟：使文章完成率从18%提高到64%的结构"

**使用时**：你可以在文章中具体实现承诺。**避免**：比回报更大的承诺。永久破坏信任。

### 4. 场景开头/故事中

将读者带入一个特定的时刻，无需设置。

- 英语："弗兰克·辛纳屈，一手拿着一杯波本威士忌，另一手拿着一支香烟，站在酒吧一个黑暗的角落里，两边坐着两位有吸引力但正在等待他说什么的褪色金发女郎。"（Talese）
- 英语："我们当时在巴斯特沃附近，沙漠边缘，药物开始起作用。"（Thompson）
- 英语："中心不再持有。"（Didion）
- 法语："2024年5月14日，6时12分，三名穿着便服的男人敲响了第十五区一个公寓的门。"

**使用时**：长篇、人物传记、报道文章、散文。**避免**：短篇技术文章，读者还没有获得场景。

### 5. 惊人的统计数据

以一个违反先验的数字开头。

- 英语："你有五秒钟的时间吸引人们的注意力。"（Housel，自我证明）
- 英语："1955年，有3.7万名美国人死于车祸，调整后的当前比率是6倍。"（Housel）
- 英语："你每天执行的行动中大约有40%是习惯，而不是实际决定。"（Clear）
- 法语："你有不到3秒钟的时间让你的受众相信你的内容是有趣的。"（Truphème）

**使用时**：数字真正令人惊讶，并且你可以准确地引用它。**避免**：模糊的统计数据（"研究表明90%..."），确认读者先验的统计数据（没有惊喜等于没有钩子）。

### 6. 问题

提出一个读者实际上想要回答的问题。

- 英语："如果你收集了许多不同领域做伟大工作的技巧列表，它们的交集会是什么样子？"（Graham）
- 英语："为什么我们要让孩子们去上学？"（Caplan）
- 法语："LinkedIn上，80%的文章在发布后一小时内就被遗忘了。这是为什么。"
- 法语："你敢在今年赢得50万美元的一半吗？"（Schwartz）

**使用时**：读者隐含地带着问题。**避免**："你有没有想过...？"、"你知道...吗？"、"如果我问你...?"。这些预设了尚未形成的好奇心。

### 7. 引用+不同意见

借用分量，然后扭曲。

- 英语："文纳·文奇：'我们正站在与地球人类生命崛起可比拟的变化的边缘。'"（Urban设置）
- 英语："史蒂夫·乔布斯说人们不知道他们想要什么，直到你向他们展示。对于SaaS来说，这完全相反。"
- 英语："据说亨利·福特说他顾客想要的是更快的马。对于大多数产品来说，这个借口是错误的。"
- 法语："亨利·福特据说他说他的顾客想要的是更快的马。对于90%的产品来说，这是错误的。"

**使用时**：你有一个真实的引用，它支持或真实地对比你的观点。**避免**：被错误归因的艾因斯坦、塞涅卡、孔子、佛陀的陈词滥调。陈词滥调。

### 8. 个人忏悔

承认某种脆弱性，然后普遍化。

- 英语："我背叛了我的丈夫。"（Strayed）
- 英语："我一直在想我的父母，他们现在六十多岁。在我18岁之前，我花了一些时间和我父母在一起，至少有我90%的日子。"（Urban，《尾巴的尽头》）
- 英语："这已经有一段时间了。这是我自从开始Not Boring以来没有写文章最长的时间。"（McCormick）
- 法语："34岁时，我辞职了，没有B计划。以下是没有人说的后续情况。"

**使用时**：个人署名、散文、订阅邮件。**避免**：企业署名、技术文章，作者声音不是个人的、表演性的脆弱性（"我几乎没写这个..."）。

### 9. 具体细节

用生动的细节代替抽象。

- 英语："约翰·拉罗切是个高个子，瘦如豆茎，眼睛苍白，肩膀下垂，尽管他所有的门牙都掉了，但他非常英俊。"（Orlean）
- 英语："查尔斯·布克威克是个酗酒者、好色之徒、慢性赌徒、粗鲁的人、吝啬鬼、赖账者，在他最糟糕的日子里，他是个诗人。"（Manson）
- 法语："当她在2024年2月24日到达Bondy博客的总部时，很难说她被法国情报部门非法盯上了。"
- 法语："我的屏幕上贴着一个便利贴：'删除你的第一段。'"

**使用时**：人物传记、报道文章、反常识传记设置。**避免**：不推进论点的具体性（杂乱）。

### 10. 模式中断

用片段打破预期的节奏。

- 英语："等一下。"（Godin风格）
- 英语："停。"
- 英语："这不是一篇关于生产力的文章。这是一篇关于身份的文章。"
- 法语："不。你本周在LinkedIn上读到的关于人工智能的一切都是假的。这是为什么。"

**使用时**：节奏驱动的内容、评论文章、当读者期待流畅而你想要中断它时。**避免**：每篇文章。它很快就会成为自己的模式。

### 11. 直接问题（PAS）

命名痛苦，使其尖锐，暗示解决方案。

- 英语："你的文章没有被阅读。数据显示，你在第二段之后失去了80%的读者。有一个解决办法，它不是你一直在做的事情。"
- 英语："如果你像大多数营销经理一样，你没有足够的时间来写你的白皮书，而你外包的那些文章都很通用。"（Bly）
- 法语："你的电子邮件没有被打开。三个月，打开率停滞在12%。问题不在于主题行，而在于发件人。"
- 法语："你的文章没有被阅读。80%的读者在第二段就放弃了。解决方案不是你认为是那个。"

**使用时**：教程、如何做、与销售相关的内容。**避免**：制造的问题。读起来像恐吓。痛苦必须是真实的、可识别的。

### 12. 承诺/利益

陈述一个具体、有界的成果。

- 英语："用5分钟读完这篇文章，你将永远不会再写一个薄弱的开头。"
- 英语："到这篇文章结束时，你将确切地知道何时使用goroutines以及何时不使用。"
- 英语："有三种事情区分了被阅读的作家和不被阅读的作家。其中没有一种是每天写。"
- 法语："5分钟：使文章完成率从18%提高到64%的结构"

**使用时**：教程、如何做。**避免**：模糊的承诺（"学习如何更有效率"）。添加时间限制或数字来锚定它。

### 13. 历史类比

以历史中的一个片段开头，然后转向现在。

- 英语："1976年3月的一个星期二早上，一个21岁的大学辍学者以1500美元的价格卖掉了他的甲壳虫巴士。他用这些钱建造了第一个苹果电脑。"
- 英语："1965年，罗伯特·卢卡斯写了一篇四页的论文，打破了宏观经济学。"
- 英语：莱特兄弟的片段（Housel，《三个大事》），转向人口统计和利率。
- 法语："1903年，在基蒂霍克，两个修理自行车的兄弟飞行了12秒。没有人注意到。这是技术采用今天告诉我们的。"

**使用时**：长篇分析、评论文章、观点文章。**避免**：教程、新闻报道。读起来像放纵。

### 14. 定义反转

"X不是你想象的。它是Y。"

- 英语："拖延不是懒惰。它是你大脑的两个部分之间的战斗。"
- 英语："这不是一篇关于生产力的文章。这是一篇关于身份的文章。"
- 英语："通配符是十年中请求的最多的Go功能。三年后，那些推动它最力的人告诉你停止使用它们。"
- 法语："副文案不是写作。它是一种伪装成句子的心理学。"

**使用时**：评论文章、反常识深度分析。**避免**：当你重新定义只是一个轻微的角度时。听起来很花哨。

### 15. 权威借用

以一个名字加上一个具体行动开头。

- 英语："沃伦·巴菲特，91岁，仍然每天阅读500页。"
- 英语："当史蒂夫·乔布斯于1997年回到苹果时，他在第一年就砍掉了70%的产品线。"
- 英语："曾经有一个男孩问查理·芒格..."（Housel叙事变体）
- 法语："当伯纳德·阿诺特以160亿欧元收购蒂芙尼时，三位分析师都预测会失败。他们都在同一个地方弄错了。"

**使用时**：商业文章、人物传记、分析文章。**避免**：没有回报的名字引用。行动必须具体且相关。

### 16. 时间锚点

以一个具体的日期、时间或时刻开头。

- 英语："2005年10月。三名记者在一个公寓里设立了博客，公寓位于Blanqui区。"
- 英语："在2022年，写一篇合格文章的成本降为零。大多数作家都没有注意到。"
- 英语："1976年3月的一个星期二早上，一个21岁的辍学者以1500美元的价格卖掉了他的甲壳虫巴士。"
- 法语："2005年10月，Bondy。三名记者在Bondy博客的一个公寓里设立了博客。"

**使用时**：报道文章、回顾、"为什么现在"框架。**避免**：模糊的时间锚点（"最近"，"过去几年"）。使用具体的日期或删除时间框架。

### 17. 条件（"如果你...那么这个"）

自我分割读者。预先定位好奇心。

- 英语："如果你为生写作，你很可能被教导要从背景开始。不要。"
- 英语："你曾经读过一篇博客文章，一小时内就忘记了它说了什么，这篇文章就是诊断。"
- 英语："如果你对某事不喊'耶！'，就说不。"（Sivers）
- 法语："如果你的文章有80%被你的同事阅读，只有8%被你的潜在客户阅读，问题不在于内容。在于钩子。"

**使用时**：教程、建议文章、分段受众。**避免**：太宽泛的条件（"如果你曾经感到停滞..."）。没有人感兴趣。

### 18. 开放式循环

开始一些事情，隐藏解决方案。

- 英语：Talese的辛纳屈等待他说些什么。他从未说。
- 英语："他按下了发送键，等待着。47秒后，这家公司的价值减少了40亿美元。"
- 英语："现在这里才是真正有趣的地方..."（Sugarman，过渡短语，也是有效的开头）
- 法语："我上周被一位编辑联系了。他要求我做的让我重新考虑了15年的实践。"

**使用时**：长篇，旅程与答案同样重要的文章。**避免**：未解决的循环。当文章结束时没有回报时，会产生不成比例的背叛。

## 反模式（永远不要提出任何这些）

立即取消作者资格的陈词滥调开头：

- "在当今快节奏的世界中..." / "在一切数字化的时代" / "在人工智能时代" / "在一个..." /
- "你有没有想过...?" / "您是否曾经想过...?"
- 词典开头直接使用（"生产力，定义为..."）/
- "在这篇文章中，我将讨论..." / "在这个文章中，我们将看到..."
- 没有来源的通用统计数据（"90%的人...", "研究表明..."）/
- 被错误归因的艾因斯坦/塞涅卡/孔子/佛陀的引言
- "我不是专家，但..." / "我不是专家，但是..."
- 连续三个反问句
- "想象一下醒来..."没有具体场景
- "大胆观点："，"不受欢迎的观点："，"以下是没有人想听到的真相..."
- "[公司]，我们相信..." / "[企业]，我们相信..."
- "最近，..." / "最近，..."没有具体日期
- "X / Twitter" ≤200个字符
- 第一条推文=标题。必须能够独立存在。

当前人工智能说法（每年刷新）：

- "它不仅仅是X，它是Y"（公式结构）
- "想象一下："，"想象一个世界，其中..."，"如果我问你...?"
- "无论你是经验丰富的X还是好奇的新手..."
- "在...领域..."，"在...景观中..."
- "解锁...的力量"，"深入..."，"系好安全带"，"让我们开始吧"
- "关键地"，"值得注意的是"，"重要的是"，"本质上,"作为句子开头
- 法语人工智能说法："在一个不断变化的世界中"，"深入...", "发现如何...", "此外,...", "尤其是,...", "它至关重要，"

## 语言处理

**如果受众是法语**：用法语写作，应用 _attaque journalistique_ 注册。

- 具体场景设置、克制语气、日期锚点、正式"vous"或克制的tutoiement。
- 不要逐字翻译美国炒作陈词滥调——"你不会相信..."变成"你会大吃一惊"，这在法语中读起来像骗局。
- 法语营销怀疑论基线高于英语；过高的承诺会更快地触发_reactance_。

**如果英语**：默认为直接响应注册，用于营销或教程内容，长篇注册用于散文和报道文章。

**如果双语**：用两种语言生成钩子，清晰标记。

对于更深的注册指导，请参阅`references/anglophone-vs-francophone.md`。

## 文章标题

标题是读者点击之前看到的。钩子是他们点击后读到的。两者都通过不同的机制获得关注：标题在信息流或搜索结果中竞争点击；钩子赢得持续阅读。

### 核心机制：校准好奇心

标题必须打开一个差距，但不能闭合它——但这个差距必须感觉是真实的，而不是人为制造的。对8,977个A/B实验（Upworthy，《科学报告》2024）的研究发现了一种曲线关系：过于模糊会产生困惑（没有好奇心的基础）；过于具体会消除点击的动力。甜点：命名风险，隐藏解决方案。

**工艺测试**。标题是否打开了一个读者关心的差距，而文章是否真正关闭了它？如果是，那就是工艺。如果内容没有兑现标题暗示的，那就是点击广告——它会破坏未来点击的信任。

### 核心公式

**好奇心/差距**

- `关于[主题]的[形容词]真相` — "关于Go泛型反直觉的真相"
- `什么是[群体]不会告诉您关于[主题]的` — "什么是[受众]对[主题]的错误理解"
- `关于[现象]的真实原因` — "关于大多数内容零分享的真实原因"
- `[数字]个[受众]对[主题]的错误理解`

**反常识/负面**（负面超级形容词：+63% CTR vs. 正面 — Outbrain, 65k标题）

- `停止[做X]。这是为什么。` / `为什么[普遍信念]是错误的`
- `[数字]个[神话/错误]正在杀死你的[结果]`

**具体性/数据**

- `我分析了[数字]个[事物] — 我发现了什么`
- `[数字]%的[群体]这样做是错误的`
- 方括号诚实地指示格式，并增加+38% CTR：`如何将构建时间缩短60% [基准]`

**列表/数字**（数字：+36% CTR — Conductor；奇数：+20% CMI — CMI）

- `[数字]个[形容词]方法来实现[目标]` / `[数字]个避免[任务]时的错误`

**如何做**（3倍于其他格式的B2B分享 — BuzzSumo，10M LinkedIn文章）

- `如何[任务]而不[痛苦的约束]` / `即使[限制性信念]，如何[任务]`

### "putaclic léger"区域

稍微有点点击广告但诚实——最大张力与真实承诺：

- 将"不会相信"替换为"惊讶地发现"：同样的好奇心，诚实语气
- 添加具体性："我每月节省了€500"比"我节省了钱"更好
- 添加约束："不辞职"创造了差距
- 使用"真实原因"或"没有人告诉你的"——它们暗示了一个非共识观点，你必须证明
- 添加括号`[研究]`, `[模板]`, `[基准]`来指示回报类型

**FR — putaclic在法语中带有更强的贬义权重。** 应用**70/30规则**：70%信息，30%神秘。

- 张力和矛盾起作用；虚假的戏剧（"我几乎没写这个... 😱"）立即破坏法语专业环境中的信誉。
- 法语规范结构："每个人都告诉你做A。这是为什么我做了B。"
- 2025年LinkedIn法语饱和的公式："我犯了一个错误，我学到了什么"

### 平台限制

| 平台 | 最大显示 | 关键规则 |
| --- | --- | --- |
| 博客/SEO | 50-60个字符 | 前置关键词。权力词会降低搜索中的CTR约14%。 |
| LinkedIn文章 | 150个字符硬 | 100个字符以下以获得干净的显示。 |
| LinkedIn信息流 | 120-140个字符 | 开头行=标题。设计"查看更多"点击。 |
| 订阅邮件主题 | 30-50个字符 | 前30个字符携带信号。避免"订阅邮件"（−18.7%打开率）。 |
| X / Twitter | ≤200个字符 | 第一条推文=标题。必须能够独立存在。 |

### 标题反模式

- 没有具体性的通用超级形容词："终极指南X" — 没有差距
- "你不会相信..." / "Vous n'allez pas y croire..." — 过于使用，暗示炒作
- SEO标题中的权力词（秘密、惊人、终极） — 指示炒作，降低CTR
- 给出完整答案的标题——如果标题回答了问题，就没有点击的理由
- 重复饱和指纹："我分析了X事物，这里是我发现的" — 有效2022-2023，饱和2025-2026

### 标题请求行为

1. 确认主题、受众、语言、平台
2. 提供**3-5个标题**，跨不同的公式——不是同一类型的三个变体
3. 至少包括：一个好奇心/差距，一个反常识或数据，一个列表或如何做
4. 使用与钩子相同的输出格式：编号选项，等待选择
5. 在选择之后，注意标题将文章开头提交给的内容
