# HyperFrames Studio 规范

Studio 为每个顶层元素绘制一行时间轴。遵循以下规则的项目会以简短、可读的时间轴形式打开；反之则会以用户无法编辑的无标签行墙形式打开。这些是构建内容的规范。若要更改片段，请遵循 `/hyperframes-core` `references/creator-editing-recipes.md`，并永远不要发明同种编辑的不同形式。

## 1. 每个场景都是一个子合成

根合成仅包含计时主机、媒体和音频。任何具有嵌套结构（一个包含子元素的 div、一个带有副标题的标题、一个图表）的场景都是其自己的文件，通过 `data-composition-src` 加载，并连接到 `references/sub-compositions.md`。

根合成内部留下的嵌套标记不会成为单独的一行。它会隐藏在一个不可修剪或部分移动的不可见行内。

像结构 lint 会拒绝任何违规行为一样进行编写。

## 2. 一个字幕轨道

- 所有字幕都位于一个轨道上：一个单独的子合成主机（一个 `data-track-index`）标记为 `data-track-kind="captions"`，按顺序承载每个字幕组。
- 永远不要每个字幕组一行，也永远不要将字幕混入另一个类型的轨道上。
- 字幕时间规则保持不变：参见 `/embedded-captions` 和 `caption_*` lint 规则。

## 3. 每个轨道一个元素类型

按类型分组，以便每行是用户可以选择、静音或作为一组拖动的某物。

| 类型                                    | `data-track-kind`      |
| --------------------------------------- | ---------------------- |
| 基础视频 / A-roll                     | `video`（来自标签）    |
| 场景、叠加层、图形                    | `graphics`             |
| 字幕                                    | `captions`             |
| 音频（旁白、音乐、音效）               | `audio`（来自标签）    |

在子合成主机上放置 `data-track-kind`。视频和音频类型来自标签，因此 `<video>` 和 `<audio>` 无需属性。为每种类型分配自己的 `data-track-index`；数字仅用于显示；它永远不会改变顶部渲染的内容。使用 CSS 进行层叠。

## 4. 安全区域

任何标尺或安全框叠加层都存在于预览窗格中，永远不会在合成内部，因此不要向 HTML 添加引导元素。

宽屏和竖屏两种构图都使用相同的安全框，即 Premiere 的默认设置。预览切换器在每条边的中间绘制一个勾选标记。来源：`packages/studio/src/utils/previewSafeMargins.ts` 中的 `ACTION_SAFE_PERCENT` 和 `TITLE_SAFE_PERCENT`。

| 框         | 帧的占比 | 每边的内边距 |
| ----------- | -------- | ------------ |
| 动作安全框  | 90%      | 5%           |
| 标题安全框  | 80%      | 10%          |

- 安全边距：所有可见内容都应保留在动作安全框（90%）内，字幕和关键内容应保留在标题安全框（80%）内。
- 两栏和 50/50 布局应使每半部分的内容都保留在标题安全框内。

## 检查你的工作

运行 `hyperframes lint` 并修复所有发现的问题。然后在 Studio 中打开项目，并检查时间轴是否显示基础行、每个场景主机一行、字幕行和音频行。
