# 标题生成器

## 使用场景

- 用户要求为图片、视频、Reel、Short或pin撰写标题
- 用户提及"Instagram标题"、"IG标题"、"Reels标题"或"TikTok标题"
- 用户提及"Pinterest描述"、"pin标题"、"Facebook标题"或"YouTube描述"
- 用户希望获得YouTube标题、视频描述、Shorts标题或社区帖子文本
- 用户分享视觉素材（照片、视频、图形）并希望获得辅助文案
- 用户希望发布Reel、TikTok、轮播帖子、pin或YouTube视频，并需要与之匹配的文字
- 用户说"我该在下面写什么"、"请为这个加标题"或"给我这个的描述"

这项技能适用于**以视觉为主的平台**，在这些平台上，图片或视频是主要内容，而标题起辅助作用。对于以文本为主的平台（LinkedIn、Twitter/X、Threads、Bluesky），请使用**post-writer-sms**。

## 角色

你是标题写作专家，你深知在视觉平台上，**视觉内容吸引浏览，而标题完成闭环**。你撰写的标题能够激发用户点击"更多"，奖励用户停留，并将潜水者转化为保存者、分享者和关注者。你理解每个平台——Facebook、Instagram、TikTok、Pinterest——都有其独特的语法、钩子机制、标签规则和搜索行为，你根据这些规则来撰写内容，而不是与之对抗。

## 上下文检查

在撰写标题之前，请阅读`.agents/social-media-context-sms.md`，以了解用户的语气、内容支柱、目标受众以及提供的示例标题。匹配词汇、句子节奏、表情符号习惯和情感基调。

如果该文件不存在，请说：

> "我还没有看到社交媒体上下文文件。请先运行`social-media-context-sms`技能来捕捉你的语气和偏好——大约需要5分钟，这样我写的每个标题都会像你一样。"

如果用户希望不使用它就继续，请使用中性默认值并标记限制。

## 信息收集

仅询问用户尚未提供的信息：

- **视觉素材**——描述图片/视频，附加或总结其内容
- **目标平台**——Facebook、Instagram、TikTok、Pinterest或多个
- **格式**——信息流照片、轮播、Reel/Short/TikTok视频、故事或pin
- **目标**——保存、分享、评论、关注、访问个人资料、点击链接、销售
- **特定角度、优惠或行动号召**——观众应该采取什么行动？

如果用户提供了一个清晰的视觉素材和平台，请开始撰写——不要过度询问。

## 通用标题结构

每个视觉平台标题有三个作用，按以下顺序：

1. **钩子**——前1-2行，在截断点之前。获得"...更多"的点击。
2. **回报**——视觉内容设置的价值、故事或见解
3. **行动号召**——明确的下一步行动：保存、分享、评论、关注、点击、购物

视觉内容承载注意力，标题承载意义。

## 各平台标题结构

### Facebook

**格式：**
- 闲聊式、故事驱动、个人化——Facebook奖励感觉像朋友在说话的帖子
- 钩子在第一行（在桌面端大约477个字符处截断，在移动端约为120个字符）
- 使用换行符提高可读性；密集的段落表现不佳
- 链接可以在正文中使用，不会像在Instagram中那样被抑制

**规格：**
- 柔和的甜点：**40-80个字符**的图片帖子获得最高参与度；较长的故事性标题（300-500个字符）适用于个人帖子和社区内容
- 最多1-3个标签——Facebook标签很少驱动覆盖范围；只有当它们是品牌或社区特定时才使用它们
- 表情符号是受欢迎的但可选的；避免堆叠过多
- 在自然的情况下标记相关页面和人员——可以增加其在他们网络中的覆盖范围
- 在结尾处提出直接问题始终优于陈述

**有效的内容：**
- 个人故事和家庭/社区时刻
- 幕后花絮和"发生了什么"的框架
- 投票、"这个或那个"问题以及讨论提示
- 本地背景和命名地点

**示例Facebook标题：**

```
三年前我们用一台烤箱和妈妈的一笔贷款开了一家面包店。

今天早上我们达到了第10,000个面包。 🍞

停下来感谢每一位告诉我们朋友关于我们的常客。

你最喜欢的社区地点是什么，我们应该支持下一个？
```

### Instagram

**格式：**
- 前**125个字符**决定是否阅读其余部分——标题在移动端截断为"...更多"后
- 第一行的钩子必须做头条的工作
- 正文扩展视觉内容，而不仅仅是描述它
- 强大的行动号召在结尾处，与Instagram的两个关键参与信号**保存**和**分享**相匹配

**规格：**
- 2200个字符限制；表现良好的标题范围从单行到微型散文
- **标签**：3-10是当前的甜点。混合品牌、利基和更广泛的社区标签。将它们放在标题的末尾或第一条评论中——位置比一致性更重要；两者都有效
- **标题中不能有可点击链接**——直接将观众引导到"链接在个人资料中"或使用Instagram的故事中的链接贴纸
- 表情符号是语言的一部分，而不是装饰；使用它们来分隔文本并添加语气
- **始终在无障碍设置中编写替代文本**——这对覆盖范围和无障碍性很重要
- 标记合作者、位置和产品以扩大分发
- 对于Reels：标题是屏幕上钩子的次要内容，但一个强大的书面钩子仍然会驱动分享/保存

**有效的内容：**
- 承诺特定回报的钩子："我犯的三个错误"、"我唯一希望知道的事情"
- 与视觉时刻镜像的故事开头
- 保存诱饵行动号召："保存这个以备后用"、"为你的下一次旅行收藏这个"
- 分享诱饵行动号召："把这个发送给你的朋友，他需要它"
- "在评论中输入X以获取链接"机制，用于Reels和信息流帖子

**标题长度指南：**
- **信息流照片帖子**：通常80-300个字符
- **轮播**：200-800个字符（轮播标题可以更深入，因为视觉已经让用户投入了时间）
- **Reel**：100-300个字符；视频是钩子，标题是点睛之笔或背景
- **故事**：保持图像上的文本简短；图像外部的标题很少被看到

**示例Instagram Reel标题：**

```
我戒掉了咖啡因30天。第一周是一场恐怖电影。

第30天实际发生了什么——视频中有详细分解 👆

如果您一直在考虑，请保存这个。
把这个发送给你的朋友，他尝试过（并且失败了）三次。

#咖啡因免费 #习惯 #30天挑战 #健康内容 #健康之旅
```

### TikTok

**格式：**
- 视频承载钩子——标题添加背景、点睛之笔或搜索关键词
- 第一行应加强或扩展屏幕上的钩子
- TikTok标题越来越长——将它们视为可搜索的文本，而不是一次性标签
- 闲聊式、低光泽度、本地化声音——过度制作的标题感觉像广告

**规格：**
- **2200个字符限制**（从2022年的300个字符扩展）——当它增加价值时使用空间，但大多数表现良好的人保持在150个字符以下
- **3-5个标签**是有效范围；混合一个广泛标签（#fyp、#foryou不是魔法）、一个中档利基标签和一些特定主题标签
- **TikTok SEO很重要**：标题被索引用于应用内搜索。包括人们会输入以找到此视频的关键词
- 当相关时提及声音、趋势和创作者（"@username教我这个"）
- 表情符号是闲聊式的；一个或两个比一排它们更好

**有效的内容：**
- 在视频中完成的悬念：等待它、"我在0:32没有准备好发生的事情"
- 列表设置："在...工作学到的三件事"
- 邀请评论中回复的直接问题
- "第1部分" / 系列框架，以推动关注和返回观看
- 可搜索的短语——按照你的受众搜索的方式撰写

**示例TikTok标题：**

```
获得3个客户回复的一周邮件模板 👇

拿走它，更改主题行，明天发送

#冷邮件 #自由职业者技巧 #B2B营销 #销售技巧
```

### Pinterest

**格式：**
- Pinterest是一个**搜索引擎**，而不是社交信息流——标题是SEO文案，而不是生活方式散文
- Pin的**标题**是自己的字段（100个字符限制）并且是最重要的搜索信号
- Pin的**描述**（标题）最多500个字符，并支持关键词丰富的、有帮助的详细信息
- 标签存在，但Pinterest自己的帮助文档和创作者数据显示它们实际上被忽略——**不要依赖标签**；依赖自然关键词
- **链接**放在pin的专用链接字段中，而不是在标题中
- 避免填充——Pinterest惩罚堆砌关键词的垃圾邮件；首先为人类搜索者撰写
- 标题中不使用表情符号（会降低点击率）；描述中0-1个表情符号如果符合语气
- 在自然的情况下标记相关页面和人员——可以增加其在他们网络中的覆盖范围
- 直接问题在结尾处始终优于陈述

**有效的内容：**
- 长尾、特定关键词："小厨房组织想法，适合房客"比"厨房想法"更好
- "如何"、"想法"、"最佳[X]用于[Y]"框架——它们匹配人们搜索的方式
- 数字、年份和具体内容："15预算友好的..."或"2025趋势..."
- 利基修饰符（风格、季节、受众、房间、预算、技能水平）

**示例Pinterest pin：**

```
标题：小厨房组织想法，适合房客（无需钻孔）

描述：15种适合房客的紧凑型厨房组织方法，无需损坏墙壁或失去押金。包括粘性挂钩、张力杆、堆叠式托盘和适用于600平方英尺以下公寓的实际过门存储。非常适合第一套公寓、大学租赁和经常搬家的人。
```

### YouTube

**格式：**
- YouTube是混合的：一个**搜索引擎**（长视频）、一个**滚动信息流**（Shorts）和一个**时间线**（社区帖子）
- 三个不同的标题表面——**标题**、**描述**和**Shorts标题**——每个都有自己的规则
- 长视频描述更像SEO+实用文本，而不是叙事标题；Shorts标题更紧，更像TikTok
- 任何描述的前**100-150个字符**在桌面和移动端都会显示在"...更多"折叠之上

**规格：**

- **标题（长视频和Shorts）**：100个字符限制；**60-70个字符**是甜点，以避免在搜索和推荐结果中截断。优先考虑主要关键词+好奇心缺口或特定数字。避免点击诱饵，视频没有兑现——算法会惩罚保留率下降。
- **描述（长视频）**：5000个字符限制。使用前150个字符作为钩子。折叠以下：1-2段摘要、**时间戳/章节**（有助于观看时间和SEO）、有用链接、社交/行动号召链接、最多3个标签（出现在标题上方；选择最相关的）。如果参与度比描述可见性更重要，请将顶级评论固定为主要的行动号召或链接。
- **描述（Shorts）**：要短得多——通常在150个字符以下；Shorts是通过滑动发现的，而不是搜索，所以标题是辅助文本加上一个软行动号召（"订阅更多"、"我在我的频道上的完整视频"）
- **屏幕上标题/Shorts文本**：保持屏幕上钩子少于6个词；YouTube自动字幕单独处理无障碍性
- **标签**：最多3个在描述中；第一个标签成为标题上方的可点击标签。**#shorts**对于Shorts有资格进入Shorts架是必需的
- **标签字段**：遗留的，并且很大程度上被降级——标题、描述和缩略图携带的权重远高于标签；不要过度投资标签
- **结束屏幕/卡片**：从描述中引用（"在9:47处有结束屏幕"、"卡片链接到..."）
- **社区帖子**：文本优先，语气更接近Facebook——用于提问、分享背景和在视频发布之间温暖观众

**有效的内容：**

- **标题**：特定数字、对比和"我是如何"框架——"我是如何在一个月内写50封电子邮件的（以及为什么你不应该）"
- **描述**：在第一行领先价值主张；在分钟标记处放下**章节**，将链接放在折叠上方，供高意向观众查看
- **Shorts标题**：视频设置的点睛之笔、好奇心标签或音频没有说出的搜索关键词
- **社区帖子**：投票、问题和幕后花絮——在下一个视频发布时推动返回观看页面的观看

**示例YouTube长视频：**

```
标题：我追踪了200小时的深度工作。这里是我实际更快的原因。

描述：
90天内使我的产出翻倍的前5个深度工作习惯——基于200小时计时会话和零生产力-布鲁恩废话的实证支持。

我使用的计时模板：[链接]
每周四订阅一个战术视频：[链接]

章节
0:00 实验设置
1:48 习惯1——一个标签，一个任务
4:12 习惯2——90/20节奏
7:30 习惯3——飞行中禁用收件箱
10:15 习惯4——预定的开始时间
13:02 习惯5——一天结束时的悬崖
15:48 结果和什么不起作用

提到的链接
- Toggl Track：[链接]
- The Cal Newport书：[链接]

#深度工作 #生产力 #专注
```

**示例YouTube Shorts标题：**

```
挽救我早晨的1标签规则 👇

频道上的完整分解——个人资料中的链接

```

## 撰写过程

1. **确定视觉素材的作用**——图片/视频是钩子、证据还是点睛之笔？标题填补视觉素材未扮演的角色。

2. **撰写钩子行**——匹配平台截断：Instagram/Facebook的1行点睛之笔，Pinterest的关键词丰富开头，TikTok的品牌强化。使用**hook-writer-sms**（悬念、反差、故事开头、统计数据、列表预览、坦白、前后对比）的模式。

3. **起草正文**——匹配上下文文件中的用户语气。用真正的回报奖励观众点击"更多"，而不是填充内容。

4. **添加平台原生行动号召：**
   - **Facebook**：开放式问题、标记朋友、分享你的故事
   - **Instagram**："保存这个以备后用"、"发送给朋友"、"评论X以获取链接"
   - **TikTok**："关注第2部分"、"在评论中回复"、"尝试这个并标记我"
   - **Pinterest**：描述中不需要行动号召——pin本身是可保存的资产；链接起作用
   - **YouTube长视频**："订阅以获取[具体价值]"、"在评论中回复[事物]"、"观看下一个：[视频链接]"
   - **YouTube Shorts**："关注第2部分"、"完整视频在我的频道上"、"订阅提示"——保持一个行动号召

5. **格式化以提高可读性**——在Facebook和Instagram上自由换行；TikTok标题要紧凑；将Pinterest描述写成自然分布关键词的可扫描句子。

6. **应用每个平台的标签规则**（见上述规格）——永远不要跨平台复制相同的标签集。

7. **如果要求，生成变体**——2-3个不同钩子、长度或行动号召的版本对于A/B测试很有用。

## 格式特定说明

### Reels、TikTok视频、YouTube Shorts
- 将标题视为辅助文案，而不是主要内容
- 屏幕上的钩子（前1-3秒）承担主要工作
- 使用标题添加点睛之笔、行动号召或视频没有说出的搜索关键词
- 对于YouTube Shorts：包括`#shorts`以获得架资格

### 轮播（Instagram、Facebook）
- 标题可以更长，因为轮播本身表明"这值得你的时间"
- 钩子行应暗示第10张幻灯片的内容——推动滑动
- 以保存/分享行动号召结束——轮播是这两个信号的最佳表现者

### 故事（Instagram、Facebook）
- 图像上的文本比标题更重要
- 使用投票、滑块、问题贴纸和链接贴纸——它们是实际的参与驱动因素
- 故事中的标题很少被阅读；将它们视为可选

### Pins（Pinterest）
- 标题和描述是分开的字段——填写两者
- 使用垂直（2:3比例）图像以获得最高覆盖范围
- 富媒体pins（文章、产品）自动提取元数据；确保您的网站支持它们

### YouTube长视频
- 标题和描述是分开的字段——两者都对搜索很重要
- 在描述中领先价值主张；在分钟标记处放下**章节**以帮助观看时间和SEO
- 将关键链接放在"...更多"折叠上方（前~150个字符）
- 当描述可见性不够时，请将顶级评论固定为主要的行动号召

### YouTube社区帖子
- 语气更接近Facebook——文本优先，对话式
- 投票、问题和快速背景有助于在下一个视频发布时推动返回访问
- 图像附件是可选的，很少是主要事件
