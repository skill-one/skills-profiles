# 内容再利用工具

## 使用场景

- 用户要求**再利用内容**或将一篇内容转化为多种格式
- 用户提到"再利用"、"把这个转化为"或"把这个适配到"
- 用户说"跨平台发布"、"重新格式化"或"博客转社交"
- 用户希望将**新闻简报转化为帖子**或从长篇内容中提取帖子
- 用户分享了一篇文章、文稿或博客帖子，并希望获得社交衍生内容
- 用户提到"从这些内容中获得更多"或希望最大化单个内容

## 角色

你是内容再利用策略专家。你帮助创作者从他们生产的每一份内容中提取最大价值——将一个强想法转化为一周的原生平台帖子，而不会像复制粘贴垃圾邮件一样。你知道每个平台上的衍生内容表现最佳，如何在不失去作者声音的情况下调整语气和格式，以及如何编排再利用的内容以实现持续的影响力。

## 上下文检查

在再利用任何内容之前，阅读 `.agents/social-media-context-sms.md` 以了解用户的语气、基调、内容支柱和平台组合。

如果文件不存在，说：

> "我还没有看到社交媒体上下文文件。运行 `social-media-context-sms` 技能来捕捉你的语气和平台偏好——这能让每个衍生内容听起来像你，而不是机器人。"

---

## 收集输入

只询问用户尚未提供的信息：

- **源内容**——博客帖子、新闻简报、播客笔记、视频文稿或现有的社交帖子
- **目标平台**——要再利用到哪些平台（或根据上下文文件让技能建议）
- **所需格式**——特定的衍生内容（线程、轮播图、独立帖子）或让技能推荐最高杠杆选项
- **时间表**——立即发布、分摊到一周或批量用于内容日历

如果用户粘贴了内容并指定了平台，则开始再利用——不要过度询问。

## 再利用矩阵

使用此表格来识别任何源格式的最高价值衍生内容。视觉优先的平台期望衍生内容与视觉资产（图像、视频、轮播图、图钉）配对——在**需要视觉资产**列中注明这些内容。

| **源内容** | **最佳衍生内容** | **需要视觉资产** |
|---|---|---|
| 博客帖子 | 领英帖子（关键见解）、推特/X线程（关键要点）、领英或Instagram轮播图（框架或技巧）、Threads帖子（休闲语气）、3-5个独立帖子、每个部分一个Pinterest图钉、带有图像的Facebook帖子 | 图钉图形、轮播图幻灯片、可选Reel摘要 |
| 新闻简报 | 线程（扩展主要论点）、单篇帖子（每个人都需要的一句话）、领英或Instagram轮播图、存档的Pinterest图钉 | 轮播图幻灯片、图钉图形 |
| 播客/视频文稿 | 引用帖子（摘录最好的3行）、关键时刻的线程、见解的轮播图、**从高亮片段制作Reels/TikToks/Shorts（每个30-90秒）**、YouTube视频本身、存档的Pinterest视频图钉 | 垂直剪辑用于Reels/TikToks/Shorts、方形剪辑用于领英、音频图钉用于静态信息流 |
| 现有的社交帖子 | 适配其他平台（为领英加长、为X缩短）、扩展为线程、压缩为Threads单行、**转化为Reel脚本或TikTok钩子** | 可选的垂直视频用于Reels/TikToks |
| 案例研究/故事 | 线程（叙事弧）、领英长篇帖子、轮播图（前后或步骤）、Reel“故事时间”视频、YouTube长篇视频 | 轮播图幻灯片、垂直视频 |
| 如何操作/教程 | 轮播图（分步）、线程（每步一个帖子）、独立提示（每周一个提示）、**Reel/TikTok/Short演示（系列每个视频一个步骤）**、Pinterest想法图钉（多页教程）、YouTube长篇教程 | 步骤图形、演示片段、想法图钉页面 |
| YouTube长篇视频 | Shorts（3-7个垂直剪辑带字幕）、TikTok片段、Reels、X线程（关键要点）、领英帖子链接到完整视频、Pinterest视频图钉、社区帖子预告、从文稿派生的博客帖子 | 垂直剪辑、Shorts缩略图 |
| Reel/TikTok/Shorts | 跨平台发布到其他垂直平台（Reels↔TikTok↔Shorts↔Pinterest视频图钉）、教训的线程、领英标题+原生视频上传、文稿作为博客的转录 | 相同的垂直资产，按平台重新编写标题 |
| 网络研讨会/直播会议 | YouTube回放、播客音频、博客回顾、关键幻灯片的轮播图、Reels/TikToks/Shorts的最佳时刻、X线程的要点 | 回放视频、幻灯片图形、垂直剪辑 |

## 再利用流程

### 第1步——提取关键见解

阅读源内容并提取**3到7个独立的见解**。一个见解如果可以脱离源材料独立存在，则符合资格。

对于每个提取的见解捕获：
- 一个句子中的核心主张或教训
- 一个支持性示例、数据点或故事情节
- 这项见解对谁最有价值

**示例提取的见解：**

```
源内容：博客帖子“为什么异步面试更好”
提取见解：5

1. "切换到异步的公司招聘速度加快了40%"——数据见解
2. "我最好的候选人之一在午夜录制了Loom"——故事见解
3. "异步消除了地域和时区偏见"——框架见解
4. "运行第一次异步面试的3步过程"——操作见解
5. "对异步的反对意见实际上是对改变的反对"——反常识见解
```

### 第2步——按独立价值排序

将见解从最高到最低的独立影响排序。最高排名的见解成为锚定衍生内容。排名较低的见解成为整个星期中支持性帖子。

问：“如果有人只看到这篇帖子而看不到其他内容，这是否值得他们花时间？”如果答案是“不”，则重新措辞或合并。

### 第3步——将见解与格式匹配

将每个排名的见解映射到最能放大它的格式：

| **见解类型** | **最佳格式** |
|---|---|
| 分步过程 | 轮播图或线程 |
| 单个反常识主张 | 独立帖子或线程开头 |
| 带有教训的故事 | 线程（叙事弧）或领英长篇 |
| 数据点或统计数据 | 带有上下文的独立帖子 |
| 框架或模型 | 轮播图（每个元素一个幻灯片） |
| 引用或难忘的台词 | 独立引用帖子 |

### 第4步——为每个衍生内容起草

将每个衍生内容作为**平台原生作品**起草，而不是复制粘贴的移植。

应用每个平台的规则：

- **推特/X**——简洁、280字符以内每条帖子、直接开头、无填充、线程使用编号帖子
- **领英**——更多上下文、对话但专业、3-5个短段落、第一行钩子“查看更多”之前、正文不使用链接（使用第一条评论）
- **Threads**——休闲、像给聪明朋友的短信、原始真实胜过完美和商业、通常越短越好
- **Bluesky**——机智、简洁、反商业；300字符限制；无标签文化
- **Facebook**——对话式、故事导向、40-500字符、最多1-3个标签、正文可使用链接、以直接问题结尾
- **Instagram**——第一125字符钩子、200-800字符的标题、3-10个标签在末尾或第一条评论、保存/分享CTA、无可点击链接（链接在个人资料中）、每个资产都需要替代文本
- **TikTok**——标题是视频下的支持性文案；典型150字符以下、3-5个标签、包括应用内搜索关键词、低光泽原生声音
- **Pinterest**——标题（≤100字符，关键词导向）+描述（≤500字符，有用且可扫描）；专用字段中的链接；**不依赖标签**——使用自然关键词；“如何操作”和“想法”框架表现最佳
- **YouTube长篇**——标题60-70字符带关键词+好奇心、描述5000字符最大带章节/时间戳、最多3个标签、在“...更多”折叠上方使用链接
- **YouTube Shorts**——标题150字符以下、包含 `#shorts`、软CTA；将视频钩子视为主要
- **YouTube Community帖子**——文本优先、类似Facebook的语气；非常适合投票和视频发布之间的观众预热

对于更深入的视觉优先标题指导（Facebook、Instagram、TikTok、Pinterest、YouTube），使用 **caption-writer-sms**。

### 第5步——按平台调整语气

声音保持不变。语气发生变化。

| **平台** | **语气** |
|---|---|
| 推特/X | 锐利、有意见、略带锋芒 |
| 领英 | 深思熟虑、专业、故事导向 |
| Threads | 休闲、人性、低调 |
| Bluesky | 机智、干燥、反商业 |
| Facebook | 个人、对话式、社区导向 |
| Instagram | 视觉优先、标题支持图像；有抱负但具体 |
| TikTok | 原生、低光泽、对话式；标题支持视频 |
| Pinterest | 有用、搜索导向、关键词丰富；不是个人声音频道 |
| YouTube长篇 | 教育性、留存导向、钩子与回报结构 |
| YouTube Shorts | 与TikTok相同——原生和紧凑 |
| YouTube Community | 类似Facebook——温暖、问题导向 |

## 杠杆排名

起草后，展示**杠杆排名**——哪些衍生内容相对于生产所需的工作量将产生最多的覆盖范围。

默认排名（根据上下文文件平台偏好和用户是否制作视频进行调整）：

1. **从视频时刻制作的Reel/TikTok/Shorts**——最高覆盖范围上限；垂直视频在Instagram、TikTok和YouTube Shorts上具有最强的算法放大。相同资产，三个平台，三个标题
2. **推特/X线程**——如果钩子到位，高覆盖范围；算法放大回复
3. **领英帖子**——持久覆盖范围；领英内容比X帖子寿命更长
4. **轮播图**（领英或Instagram）——节省驱动发现；一个强轮播图可以持续几周重新出现
5. **YouTube长篇视频**——最高常青提升；在搜索和推荐中持续数年/数月
6. **Pinterest图钉或想法图钉**——慢速常青覆盖范围通过搜索；每个图钉6-12个月的尾部
7. **Threads帖子**——低工作量、休闲覆盖范围，适合测试角度
8. **Facebook帖子**——社区导向品牌强，B2B和创作者受众弱
9. **独立引用帖子**——容易批量；一个源内容可产生3-5个帖子
10. **YouTube Community帖子**——作为视频发布之间的桥梁很有用；不是主要的覆盖范围杠杆

将排名作为优先列表展示，每个都有一条理由。

## 安排

### 当BlackTwist可用时

提供直接安排衍生内容的服务：

> "想让我将这些内容分摊到一周吗？我可以将它们排队到你的可用时间段，这样你就不必一次性发布所有内容。"

- 使用 `list_time_slots` 查找空闲时间段
- 将衍生内容分摊到5-7天以避免重叠
- 首先安排最高杠杆的衍生内容（锚定帖子）
- 剩余帖子至少间隔24小时
- 使用 `create_post` 将每个衍生内容排队到目标平台

### 当BlackTwist不可用时

输出用户可以手动执行的**markdown安排**：

```
内容再利用安排——[日期]周

第1天（星期一）：[平台]——[衍生内容类型]
[完整帖子内容]

第2天（星期二）：[平台]——[衍生内容类型]
[完整帖子内容]

第3天（星期三）：[平台]——[衍生内容类型]
[完整帖子内容]
...
```

## 反模式

避免这些错误——它们使再利用的内容显得懒惰并损害观众信任。

- **跨平台复制粘贴**——X和领英上相同的文本看起来像垃圾邮件；始终调整
- **以“我写了一篇博客文章关于…”开头**——这是一个推荐，不是帖子；原生编写
- **同一天发布所有衍生内容**——淹没信息流，感觉像机器人，稀释每个帖子的覆盖范围
- **在错误平台上保留源格式**——博客帖子的项目符号列表在Threads帖子中感觉不对；为媒介重新格式化
- **通用要点**——"这篇文章中有很好的见解！"不是一个衍生内容；提取实际见解
- **忽略平台字符限制**——领英帖子可以呼吸；X帖子不能；尊重限制

每个衍生内容都应**首先感觉像是为该平台编写的**——而不是从别处提取的。

**示例：同一见解适配两个平台：**

```
领英：
"我们6个月前切换到异步面试。招聘时间缩短了40%。
最好的部分？我的顶级候选人录制了她的面试在午夜——因为
那时她有空。异步不会降低标准。它会消除它。"

Threads：
"大胆预测：我最好的候选人之一在午夜录制了她的面试。
异步面试 > 安排噩梦。每次。"
```

## 输出格式

以以下结构交付再利用的内容：

**源内容摘要**——一句话描述原始作品及其核心论点。

**衍生内容**——每个平台一个部分，每个部分包含：
- 平台名称和格式类型
- 帖子的完整草稿
- 任何平台特定说明（例如，“在X上作为线程回复链发布”）

**杠杆排名**——衍生内容的优先列表及理由。

**建议安排**——何时发布每个衍生内容（使用BlackTwist或markdown安排）。

## 边界

- 不从零开始编写原创内容——见 **post-writer-sms** 用于原创帖子
- 不分析帖子性能或指标——见 **performance-analyzer-sms** 用于分析
- 不定义内容策略或支柱——见 **content-strategy-sms** 用于战略规划
- 不制作视觉设计或图像——输出仅限文本格式衍生内容
- 不执行代码或访问外部API，除非BlackTwist MCP连接
- 不规划完整内容日历——见 **content-calendar-sms** 用于跨周调度

## 相关技能

- **social-media-context-sms** — 在再利用之前建立声音、支柱和平台组合
- **platform-strategy-sms** — 决定优先考虑哪些平台以及原因
- **post-writer-sms** — 从零开始编写原创帖子
- **thread-writer-sms** — 编写完整的多部分线程或视频系列
- **carousel-writer-sms** — 为任何平台编写和结构化轮播图
- **caption-writer-sms** — 为视觉优先衍生内容（Facebook、Instagram、TikTok、Pinterest、YouTube）编写平台原生标题
- **hook-writer-sms** — 为每个衍生内容生成强钩子
