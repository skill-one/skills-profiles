## 平台战术

### 领英

**算法信号**（按影响排名）：
1. **停留时间** — 算法测量人们停留在您的帖子上的时间；具有明确价值的长帖子会鼓励这种行为
2. **评论** — 比点赞权重更高；回复您自己的评论也会计入并延长互动窗口
3. **早期互动** — 前 60–90 分钟至关重要；起步缓慢会抑制传播
4. **保存** — 信号高价值内容；用“稍后保存”的 CTA 提示保存

**帖子长度：**
- 信息流帖子：**1,200–1,500 个字符** 是最佳点——足够传递价值，短到足以显示“查看更多”，从而增加停留时间
- 不要发布大段文字；每 1–2 句话用换行符分隔
- 第一行必须阻止滚动——像主题行一样对待它

**格式规则：**
- 短段落（最多 1–2 行）
- 帖子正文中不要包含链接——领英会抑制带有外部链接的帖子的触达；**将链接放在第一条评论中**
- 适当地使用粗体强调（如果需要，通过第三方格式化器）
- 编号或项目符号列表对于“如何操作”内容表现良好

**最佳内容类型：**
| 格式 | 为什么有效 |
|---|---|
| 个人故事加教训 | 高情感共鸣，高评论率 |
| 行业观点/热门观点 | 驱动回复和引用互动 |
| “如何操作”/战术分解 | 高保存和分享 |
| 轮播（PDF） | 高停留时间，可分享，算法偏好 |
| 幕后故事 | 建立信任，竞争较低 |

**发布时间：** 周二至周四，在受众所在时区的上午 7–9 点或中午 12–1 点。

**示例领英帖子结构：**

```
我花了 3 年时间招聘错误的人。

错误很简单：我优化技能，而不是判断力。

当我想反转这一点时，发生了什么：

→ 招聘时间缩短了 40%
→ 第一年的留存率从 60% 提高到 91%
→ 我最好的招聘来自我从未考虑过的行业

教训：技能可以教授。判断力不能。

你的 #1 招聘筛选标准是什么？在下方留言。

#招聘 #领导力 #初创企业
```

**标签策略：** 在帖子的末尾使用 **3–5 个相关标签**。不要堆砌。选择一个宽泛的（#营销），一个专业的（#b2bmarketing），一个可选的热门标签。

**互动模式：**
- 在发布前后评论 5–10 个您所在领域的帖子——触发互惠并扩大您网络的影响力
- 在您发布的帖子中，在头 2 小时内回复每条评论
- 在每条帖子的末尾提出一个直接问题，以促进评论

### 推特/X

**算法信号**（按影响排名）：
1. **回复** — 最强的互动信号；引发对话的内容会被放大
2. **引用推文** — 扩大覆盖面到新的网络
3. **收藏** — 向算法传递高价值内容的信号；对于教育性线程效果强烈
4. **点赞** — 仍然重要，但权重低于回复

**推文与线程：**
- **单推文**（< 280 字符）：最适合热点评论、笑话、反应和一句话——更高的触达上限
- **线程**：最适合分解、如何操作和讲故事——高收藏，适合建立权威；钩子推文必须独立存在并驱动点击展开

**格式规则：**
- 钩子推文决定线程是否被阅读——在知道完整内容后，最后写它
- 线程中的每个推文应以点击下一个的理由结束（悬念、编号承诺或“但这里有陷阱：”）
- 避免在第一条推文中放入线程编号（“1/12”）——它暗示内容很长，并减少钩子推文的互动

**标签使用：** **最多 0–2 个标签**。在推特/X 上，标签很少提高触达，看起来很杂乱。仅用于直播活动或热门话题。

**互动窗口：** 发布后的**前 30 分钟**至关重要。在您的受众在线时发布；安排回复您自己的推文以延长窗口。

**示例推特/X 钩子：**

```
大多数产品经理招聘是为了技能。

最好的产品经理招聘是为了判断力。

区别很大。原因：🧵
```

**社区建设：**
- 做一个“回复的人”——对您所在领域的大型账户进行有思考的回复，让您接触到他们的受众
- 与 5–10 个同行建立互惠的互动循环：互相点赞、回复和引用对方的内容
- 当您有话可加时，引用推文优于转发；添加您的声音并扩大覆盖面

### Threads

**平台文化：**
- Threads 奖励**对话式、不精致、人性化的内容**——语气更接近群聊而不是广播
- 表演性或过于精致的领英风格内容表现不佳
- 幽默、脆弱和真实反应比权威信号更有效

**从推特跨平台发布：** 不要复制粘贴推文线程到 Threads。格式、语气和文化不同。调整：
- 移除推特特定的惯例（线程编号、“如果同意请转发”）
- 使语气更温暖和随意
- 短帖子在这里往往优于线程

**互动模式：**
- 回复文化很强——Threads 用户期望作者出现在评论中
- 提出真实问题（不只是互动诱饵）能驱动良好对话
- 提及的人标签比在其他平台上更有效

**标签行为：** 标签在 Threads 上是功能性的，但不如 Instagram 那样文化嵌入。使用 **1–3 个相关标签**——更多用于发现性而不是社区。

**发现机制：** Threads 基于互动信号和主题相关性将内容推送给非关注者。获得早期来自您关注者之外账户的回复的内容会得到提升。

**Instagram 集成：** 如果您有现有的 Instagram 存在，您的 Instagram 受众可以自动关注您在 Threads 上的账户。如果您有现有的 Instagram 存在，请巧妙地交叉推广。

---

### Bluesky

**平台差异：**
- Bluesky 是去中心化的，早期采用者众多——文化重视**真实性、反企业语气和真实专业知识**
- 公开推广会遭到怀疑；以价值和个性为先
- 社区偏向科技、新闻、学术界和政治——相应地调整内容

**自定义信息流：**
- Bluesky 的自定义信息流由第三方算法编辑——进入相关信息流会大大扩大触达
- 研究您所在领域的自定义信息流（例如，“科学”、“科技”、主题信息流），并发布符合其编辑标准的内容
- 在您的帖子中使用相关关键词，而不仅仅是标签——许多信息流是关键词驱动的

**入门包：**
- 入门包是编辑的关注列表——被包含在相关入门包中是增长最快的方式之一
- 与您所在领域创建入门包的活跃社区成员建立关系
- 考虑创建您自己领域的入门包，包含值得关注的人——这会建立善意和可见性

**社区动态：**
- 回复文化是活跃且实质性的——用户参与想法，而不仅仅是反应头条新闻
- 长回复和真实辩论受到奖励
- 在新账户上发布的前 20–30 条帖子中避免自我推广内容；先建立您的声音

**内容发现：**
- 具有特定关键词的帖子比模糊语言在信息流和搜索中表现更好
- 支持图像和链接，但文本优先的帖子通常获得更多互动
- 一致性比频率更重要；每天 1–2 条高质量帖子优于 10 条低质量的帖子

## 跨平台发布指导

### 什么适合跨平台发布，什么适合原生发布

| 内容类型 | 跨平台发布？ | 备注 |
|---|---|---|
| 主要公告 | 是——调整每个 | 根据平台调整语气和格式 |
| 个人故事 | 是——调整每个 | 移除平台特定的参考 |
| 热点评论/观点 | 部分——重度调整 | 语气跨平台差异很大 |
| 平台特定格式（轮播、线程） | 否 | 原生格式无法直接翻译 |
| 幽默/随意反应 | 否 | 幽默在每个平台上读起来都不同 |
| 如何操作/教育性 | 是——调整长度 | 推特上缩短；领英上扩展 |

### 每个平台的原生调整清单

跨平台发布之前，为每个目的地运行此清单：

**领英：**
- [ ] 长度是 1,200–1,500 字符
- [ ] 每 1–2 句话换行
- [ ] 链接移至第一条评论
- [ ] 以问题结束
- [ ] 添加 3–5 个标签

**推特/X：**
- [ ] 适合 280 字符 OR 正确地拆分为线程
- [ ] 钩子推文独立存在
- [ ] 标签减少到 0–2
- [ ] 语气直接、有力
- [ ] CTA 移除或使其隐含

**Threads：**
- [ ] 语气随意、对话式
- [ ] 移除推特特定的惯例
- [ ] 如果原本是长格式帖子，则缩短
- [ ] 以一个真实的问题或观察结束

**Bluesky：**
- [ ] 移除企业/推广语言
- [ ] 包含相关关键词以供信息流发现
- [ ] 语气真实、略带不敬
- [ ] 标签用于上下文（1–3）

### 常见的跨平台发布错误

- **未经调整语气地复制粘贴**——领英帖子在其他平台上听起来很机械
- **在领英帖子正文中保留外部链接**——始终移至第一条评论
- **在其他平台上使用推特线程格式**——编号推文在其他地方看起来很奇怪
- **在所有平台上同时发布**——受众在不同时间活跃
- **假设相同的 CTA 在所有地方都有效**——在 Bluesky 上“关注我的领英”听起来很奇怪

## 平台选择框架

### 决策矩阵：目标 → 最佳平台

| 主要目标 | 最佳平台 | 次要平台 |
|---|---|---|
| B2B 领导者生成 | 领英 | 推特/X |
| 思想领导力/职业 | 领英 | Bluesky |
| 社区建设 | Threads | Bluesky |
| 受众增长（一般） | 推特/X | Threads |
| 科技/专业信誉 | Bluesky | 推特/X |
| 品牌知名度（广泛） | 推特/X | 领英 |
| 个人品牌（随意） | Threads | 推特/X |

### 何时添加新平台，何时加倍投入

**添加新平台时：**
- 在您的主要平台上达到增长平台
- 您的目标受众在其他地方明显更活跃
- 您有适合新平台的内容格式（例如，视觉内容 → Instagram）
- 您可以无需大量时间增加即可调整现有内容

**加倍投入现有平台时：**
- 在当前平台上发布不一致
- 互动在缓慢增长——一致性会累积
- 添加新平台会分散您的注意力低于可持续阈值
- 您的受众明显集中在某个平台上

**经验法则：** 掌握一个平台，然后再添加第二个。做得好的两个平台胜过做得差的四个。

**示例平台选择输出：**

```
推荐主要：领英
原因：您的目标是 B2B 领导者生成，并且您的受众（高级买家）
最活跃在领英。您的故事性声音与领英的算法信号（停留时间、评论）
很匹配。

推荐次要：推特/X
原因：触达放大——使用线程来提高知名度，然后在领英上转化。领英上每周发布 3 次，X 上每周发布 5 次。
```

## 语气调整

同样的声音，不同的语调。在所有地方使用您的真实视角——调整交付方式。

| 平台 | 语调 | 示例（相同想法） |
|---|---|---|
| 领英 | 专业、有洞察力 | “在产品领域工作了 10 年后，我最常见的招聘错误是什么——以及如何避免它。” |
| 推特/X | 直接、有力 | “大多数产品经理招聘是为了技能。最好的产品经理招聘是为了判断力。区别很大。” |
| Threads | 随意、对话式 | “热点评论：招聘‘文化契合’通常只是招聘舒适。告诉我我错了” |
| Bluesky | 真实、略带不敬 | “‘文化契合’招聘神话让团队同质化，并称之为有意为之。我们可以做得更好。” |
