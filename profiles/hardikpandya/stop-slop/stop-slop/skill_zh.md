# 停止冗余

消除散文中可预测的AI写作模式。

## 核心规则

1. **删除填充性短语。** 去除清嗓子式的开场白、强调性拐杖以及所有副词。参见 [references/phrases.md](references/phrases.md)。

2. **打破公式化结构。** 避免二元对比、负面列举、戏剧性碎片化、修辞铺垫、虚假代理。参见 [references/structures.md](references/structures.md)。

3. **使用主动语态。** 每个句子都需要一个人类主语在行动。没有被动结构。没有无生命物体执行人类行为（"投诉变成了解决方案"）。

4. **保持具体。** 没有模糊的陈述（"原因是结构性的"）。说出具体事物。没有懒惰的极端（"每个"、"总是"、"从不"）做模糊的工作。

5. **让读者在场。** 没有距离感的叙述者声音。"你" 比 "人们" 更好。具体细节比抽象概念更好。

6. **变化节奏。** 混合句子长度。两个项目比三个更好。以不同的方式结束段落。不要使用破折号。

7. **信任读者。** 直接陈述事实。跳过软化、辩护、手把手。

8. **删除可引用的内容。** 如果听起来像引言，就重写它。

## 快速检查

在提交散文之前：

- 有任何副词吗？删除它们。
- 有任何被动语态吗？找到执行者，让他们成为主语。
- 无生命物体执行人类动词（"决策浮现"）？说出具体的人。
- 句子以疑问词开头吗？重新结构它。
- 有任何 "这是什么/这个/那个" 清嗓子的开场白吗？直接切入要点。
- 有任何 "不是X，而是Y" 的对比吗？直接陈述Y。
- 三个连续的句子长度相同吗？打破一个。
- 段落以有力的单行结尾吗？变化它。
- 任何地方有破折号吗？删除它。
- 模糊的陈述（"影响是重大的"）？说出具体的含义。
- 距离感的叙述者（"没有人设计这个"）？让读者置身场景。
- 元连接词（"本文的其余部分..."）？删除。让文章自然推进。

## 评分

在每个维度上评分1-10：

| 维度 | 问题 |
|-----------|----------|
| 直接性 | 陈述或宣告？ |
| 节奏 | 变化或节拍一致？ |
| 信任 | 尊重读者智力？ |
| 真实性 | 听起来像人类吗？ |
| 密度 | 有任何可删减的内容吗？ |

低于35/50：修改。
