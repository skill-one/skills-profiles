## 核心工作流程

### 1. 项目设置

收集需求：
- **类型**：单曲 / 播放列表 / 专辑
- **用途**：个人 / 客户 / 商业发行
- **风格**：流派、情绪、能量水平
- **人声**：男性 / 女性 / 混合 / 无人声
- **语言**：歌词目标语言
- **时长**：曲目长度或播放列表总时长（每生成不超过 8 分钟）
- **限制**：内容限制、品牌规范

### 2. 提示构建

**风格提示公式：**
```
[流派], [BPM] BPM, [情绪], [主要乐器], [人声类型], [制作风格]
```

**负面提示（V5）：** 直接添加排除项：
```
欢快流行, 120 BPM, 无吉他, 无失真, 清晰混音
```

**歌词结构：** 在歌词字段中放置元标签（比风格提示更有效）：
```
[段落标签]
[情绪/能量指令]
歌词内容（每行 6-12 个音节以获得最佳对齐）
```

参考 [references/style-library.md](references/style-library.md) 获取按流派测试过的提示。
参考 [references/metatags.md](references/metatags.md) 获取结构标签和人声控制。

### 3. 生成过程

1. 每个曲目生成 2-4 个版本（V5 速度提升 10 倍）
2. 根据以下标准选择最佳输出：
   - BPM 准确性（如果关键需用外部工具验证）
   - 人声清晰度和情感（V5 具有真实的人声音色）
   - 混音质量和乐器分离度
   - 对提示的遵循度
3. 应用后期处理：
   - **扩展**：添加段落、修复突然的结尾（使用回调：保持相同氛围）
   - **重制**：微妙（统一质量） / 中等 / 广泛（更多变化）
   - **裁剪**：移除不需要的引言/结尾
   - **封面**：改变风格或人声
   - **替换段落**：重新生成特定部分（Studio）

### 4. 质量检查清单

- [ ] BPM 符合目标（±5 BPM 可接受）
- [ ] 人声清晰且富有表现力
- [ ] 无音频伪影（V5 具有更好的频率分离）
- [ ] 结构完整（引言 → 主歌 → 副歌 → 结尾）
- [ ] 能量水平适合用途
- [ ] 歌词清晰且正确
- [ ] 音乐记忆一致（主题在 8 分钟内正确重复）

### 5. 导出与交付

- **发行**：WAV 16 位/44.1kHz
- **预览/草稿**：MP3 320kbps
- **音轨**：人声、鼓、贝斯、吉他、合成器等（专业版/首席版）
- **MIDI**：导出可用（Studio）
- **封面**：3000x3000px 用于发行

## Suno Studio（仅限首席版）

Suno Studio 是一个生成式音频工作站（GAW），结合了 DAW 编辑和 AI 生成。

### 主要功能

| 功能 | 描述 |
|------|------|
| **多轨时间轴** | 精确排列、分层、编辑 |
| **音轨分离** | 自动分离为人声、鼓、贝斯等 |
| **版本轨道** | 比较多个生成版本 |
| **混音** | 组合不同版本的最佳部分 |
| **替换段落** | 重新生成任何片段并平滑淡入淡出 |
| **BPM/音高控制** | 每个轨道调整速度和音高 |
| **录音** | 直接录制到时间轴 |
| **片段到歌曲** | 上传短片段，扩展为完整作品 |
| **MIDI 导出** | 导出用于外部 DAW 编辑 |
| **自动保存** | 项目自动保存 |

### Studio 工作流程

1. 在 Studio 中创建或导入歌曲
2. 在详情面板中查看音轨 → 全部插入到时间轴
3. 使用版本轨道试听版本
4. 将最佳部分混音到主轨道
5. 添加/替换乐器或人声
6. 导出：完整歌曲、选定范围或多轨

## V5 功能概览

| 功能 | 优势 |
|------|------|
| **持久记忆** | 主题在 8 分钟内保持一致 |
| **负面提示** | 排除元素：无人声、无吉他 |
| **更好的人声** | 自然发音、真实情感 |
| **更清晰的混音** | 卓越的频率分离，减少“浑浊” |
| **更快生成** | 速度提升 10 倍 |
| **智能编排** | 自动结构主歌、副歌、桥段 |
| **Hoooks** | 创建可分享的短片段用于推广 |

## 项目特定工作流程

### 单曲

1. 定义风格、情绪、目标时长（最长 8 分钟）
2. 编写带元标签的结构化歌词（每行 6-12 个音节）
3. 生成并选择最佳版本
4. 如需扩展（使用回调保持一致性）
5. 微妙重制以润色

### 播放列表创建

1. 定义主题、总时长、曲目数量
2. 规划能量曲线（参考 [references/bpm-guide.md](references/bpm-guide.md)）
3. 创建一致的风格模板或保存 Persona
4. 按进度生成曲目
5. 所有曲目微重制（微妙）以保持连贯性
6. 验证总时长和过渡

### 企业/客户项目

1. 研究背景（公司、品牌、价值观）
2. 确定关键信息和语气
3. 编写包含品牌元素的歌词
4. 使用适当的职业风格生成
5. 如需精确编辑（首席版 Studio）
6. 准备多个版本供客户审阅
7. 记录修订过程

## 最佳实践

### 应该

- 为速度关键项目指定精确 BPM
- 编写原创歌词（加强版权主张）
- 使用时代参考（“80 年代合成器”、“90 年代 boom bap”）
- 保持提示聚焦：1-2 个流派 + 1 个情绪 + 乐器
- 在第一行放置重要标签
- 在扩展时使用回调：保持副歌相同氛围
- 使用负面提示排除不需要的元素
- 保存成功的提示和 Persona 以供重用
- 歌词每行保持 6-12 个音节以获得最佳对齐

### 不应该

- 提及具体艺术家（版权风险）
- 提示中包含矛盾术语
- 使用模糊描述（“好听的歌”）
- 播放列表跳过重制步骤
- 忽视目标受众的内容限制
- 无回调链式扩展（会导致漂移）
