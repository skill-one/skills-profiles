# 精美的阴影

## 使用场景
- 表面需要抛光、分层的高度感。
- 默认的 Tailwind 阴影感觉过于通用或生硬。
- 设计需要中性、精致的深度，没有彩色辉光。

## 阴影工具类
使用以下精确的 Tailwind 类。

### Beautiful sm
用于紧凑型卡片、表单控件、药丸和更安静的表面。

```txt
shadow-[0px_2px_3px_-1px_rgba(0,0,0,0.1),0px_1px_0px_0px_rgba(25,28,33,0.02),0px_0px_0px_1px_rgba(25,28,33,0.08)]
```

### Beautiful md
用于卡片、面板、弹出框和默认的提升表面样式。

```txt
shadow-[0px_0px_0px_1px_rgba(0,0,0,0.06),0px_1px_1px_-0.5px_rgba(0,0,0,0.06),0px_3px_3px_-1.5px_rgba(0,0,0,0.06),_0px_6px_6px_-3px_rgba(0,0,0,0.06),0px_12px_12px_-6px_rgba(0,0,0,0.06),0px_24px_24px_-12px_rgba(0,0,0,0.06)]
```

### Beautiful lg
用于英雄级媒体、功能提示、模态框样式的容器和最强的提升效果。

```txt
shadow-[0_2.8px_2.2px_rgba(0,_0,_0,_0.034),_0_6.7px_5.3px_rgba(0,_0,_0,_0.048),_0_12.5px_10px_rgba(0,_0,_0,_0.06),_0_22.3px_17.9px_rgba(0,_0,_0,_0.072),_0_41.8px_33.4px_rgba(0,_0,_0,_0.086),_0_100px_80px_rgba(0,_0,_0,_0.12)]
```

## 示例

```html
<div class="rounded-xl bg-white shadow-[0px_0px_0px_1px_rgba(0,0,0,0.06),0px_1px_1px_-0.5px_rgba(0,0,0,0.06),0px_3px_3px_-1.5px_rgba(0,0,0,0.06),_0px_6px_6px_-3px_rgba(0,0,0,0.06),0px_12px_12px_-6px_rgba(0,0,0,0.06),0px_24px_24px_-12px_rgba(0,0,0,0.06)]">
  ...
</div>
```

## 使用规则
- 使用 `Beautiful sm` 用于紧凑型卡片、表单控件、药丸和更安静的表面。
- 使用 `Beautiful md` 用于卡片、面板、弹出框和默认的提升表面样式。
- 使用 `Beautiful lg` 用于英雄级媒体、功能提示、模态框样式的容器和最强的提升效果。
- 与干净的表面填充和一致半径搭配使用。
- 除非交互明确改变了高度，否则每个组件状态使用一种阴影强度。

## 避免
- 在同一组件上混合这些与默认的 Tailwind 阴影等级。
- 使用强烈的颜色为这些阴影上色；保持它们的中性和精致。
- 将 `Beautiful lg` 应用于密集列表或微小的控件。
- 在一个元素上堆叠多个阴影工具类。
- 在非常低对比度的布局中，将这些用作清晰边框的替代品。
