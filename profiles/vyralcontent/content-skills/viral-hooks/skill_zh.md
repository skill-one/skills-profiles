# 病毒式钩子

帮助用户撰写或修改短视频的前1到3秒内容：
即钩子。这项技能对钩子原型进行编码，包括三个层次（视觉、语言、屏幕文字），命名创作者框架，以及算法在完成决策前导致用户流失的反模式。它不预测病毒性。它为用户提供经过验证的开头，而不是一个空白画框。

有关完整脚本结构，请参阅 `viral-short-form`。有关平台算法的具体信息，请参阅 `viral-tiktok-content`、`viral-youtube-shorts` 和 `viral-instagram-reels`。有关标题和行动号召的撰写，请参阅 `viral-captions-and-ctas`。

## 操作原则（首先阅读，并在整个过程中应用）

1. **钩子是入口，不是装饰。** TikTok、Reels 和 Shorts 大约在1.5到3秒内决定是否继续分发。如果钩子失败，视频中的其他内容都无关紧要。
2. **一次交回一批，而不是单行。** 一个钩子是一次猜测。至少三个原型中的六到十个钩子是一种策略。用户选择角度，而不仅仅是措辞。
3. **钩子有三个层次。** 视觉、语言和屏幕文字在最初1到2秒内协同工作。在一个平坦的开头画框上的一条巧妙的语言线只是半个钩子。
4. **具体比聪明更有效。** 具体名词、奇数和命名赌注比模糊的吸引力更有效。"我花了400美元在咖啡设备上" 能打动人。"你不会相信发生了什么" 则不能。
5. **匹配承诺与回报。** 一个过度承诺视频所提供内容的钩子会获得点击，但会损害其下方的满意度信号。诱饵和调包是最快降级的办法。
6. **模式匹配，而不是预测。** 钩子提高了概率。它们不保证任何东西。说明通常有效的原因，而不是一个视频会病毒式传播。
7. **如果你写不出钩子，这个想法可能很薄弱。** 将钩子写作视为想法验证，而不是最终润色。一个难以写出简洁开头句的想法通常存在更深层次的问题。

## 工作流程

根据需求进行调整。不要审问用户。如果他们想要快速获取钩子，请跳到第3步并推断其余部分。

1. **明确简报**（只询问缺失的内容）：主题或视频想法、受众、平台、目标（触达、保存、点击长视频）、任何限制（无脸、品牌声音）。
2. **选择角度。** 选择适合想法的三个或更多原型。不要在一个原型中运行所有十个。有关菜单，请参阅 `references/hook-archetypes.md`。
3. **生成六到十个钩子** 在这些原型中。对于每个钩子，写出语言线、勾勒视觉钩子（第一帧显示的内容）和屏幕文字（3到7个字）。按原型标记每个钩子。
4. **通过检查清单。** 具体名词、回报可见或暗示、无清嗓子、钩子在3秒内解决、如果声音关闭视觉也有效。
5. **评论模式（如果他们带来了草稿）：** 对照 `references/hook-anti-patterns.md` 中的反模式进行诊断。具体说明注意力在哪里下降以及为什么。重写薄弱部分；不要只是标记它们。
6. **诚实地结束。** 建议拍摄两个到三个变体，并阅读前三秒的留存率来选择赢家。钩子是测试的，而不是猜测的。

## 模式（根据用户请求进行路由）

- **"给我X的钩子"** → 步骤1到4。返回标记的原型批次，并绘制所有三个层次。提供将最强的开发成脚本（转交给 `viral-short-form`）。
- **"让这个开头更强"** → 评论模式。确定哪个层次薄弱，命名反模式，然后重写三个用户可以进行A/B测试的变体。
- **"什么钩子原型适合这个想法？"** → 将想法与两个或三个原型匹配，解释权衡，在每个原型中写一个示例，以便用户可以感受到差异。
- **"评论这个草稿钩子"** → 通过 `assets/hook-checklist.md` 和 `references/hook-anti-patterns.md` 进行测试。诊断、重写、提供固定版本和两个变体。
- **"将这个开头用于另一个平台"** → 保持原型，交换节奏和文字风格。原型是可移植的；执行不是。

## 示例

**用户：** "给我一个关于39美元可重复使用冷泡咖啡机的视频的钩子。"

**良好响应：** 推断简报（产品视频，可能是TikTok或Reels，目标可能是保存），然后返回标记的原型批次，每个都有三个层次绘制。例如：

- *反传统：* "你300美元的咖啡设备是为什么味道更差。" 视觉：两个并排的杯子，一个标记有价格。文字："$300 vs $39"
- *调查员：* "我测试了50美元以下的每个冷泡咖啡机。有一个实际上有效。" 视觉：六个咖啡机排成一排，一个已经倒出。文字："6测试。1赢家。"
- *权威+差距：* "我在特种咖啡领域工作了8年。真正的升级不是机器。" 视觉：咖啡师围裙，手放在廉价机器上。文字："8年经验。39美元真相。"
- *成本坦白：* "我花了400美元在咖啡设备上，所以你可以跳到39美元的那个。" 视觉：一堆收据，然后是机器。文字："$400到$39"

然后通过 `viral-short-form` 提供将最强的开发成脚本。永远不要返回单个钩子，永远不要以品牌名称开头，永远不要承诺视频会病毒式传播。
