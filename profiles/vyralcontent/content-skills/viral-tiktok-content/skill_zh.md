# 病毒式抖音内容

专门帮助用户为抖音撰写、塑造或修改内容。这项技能编码了抖音为你推荐页面的实际排名方式、视频需要达到的完成率、如何使用声音以及如何避免抖音暗中惩罚的内容。它不能预测内容的病毒性，但它能提高成功的几率。

有关跨平台钩子原型，请参阅 `viral-hooks`。有关 Reels 或 Shorts，请参阅 `viral-instagram-reels` 和 `viral-youtube-shorts`。有关创意构思，请参阅 `viral-short-form-ideas`。有关标题制作和行动号召，请参阅 `viral-captions-and-ctas`。

## 运作原则（首先阅读这些，并在整个过程中应用）

1. **为你推荐页面是一个兴趣图谱，而不是粉丝图谱。** 抖音直接表示：粉丝数量和过去的点击量不是直接的排名输入。每个视频都基于其元数据、声音和早期信号进行重新测试。
2. **完成率是关键。** 观看时间和完成率比点赞更重要。瞄准工作基准：15秒以内（循环计算）>100%，15-30秒约70%，30-60秒约50%，60秒以上约40%。低于基准，分发就会停滞。
3. **前3秒是整个钩子。** 保持85%+在3秒后的观看率通常比60%以下的钩子多几倍的观看量。不要有标志、欢迎回来或开场动画。
4. **保存和分享比点赞更重要。** 保存被视为未来的意图，分享被视为社会证明。为“转发给朋友”或“我以后需要这个”而设计。
5. **分发是测试后扩展。** 新上传的视频首先展示给一小部分相似用户群体。强烈的早期信号会推动视频扩大范围，弱的信号会将其保留。过时的视频可以重新进入测试，所以不要删除表现不佳的视频。
6. **诚实地说明预测。** 说明什么通常有效以及原因。永远不要承诺为你推荐页面的位置。重新使用的YouTube或Instagram片段几乎总是需要一个新钩子，并且移除水印才有机会。

## 工作流程

根据需求进行调整。不要审问用户。如果他们需要快速获取钩子，可以跳到第3步。

1. **明确简报**（只询问缺失的内容）：主题或产品、受众、目标（触达、保存、关注、购物点击）、目标长度、账户类型（创作者与商业影响声音访问）、限制（无脸、品牌规则、AI使用）。
2. **选择长度层级并确认该层级的完成率计算** → `references/retention-math.md`。
3. **生成抖音风格的钩子。** 6-10个符合抖音为你推荐页面行为模式的钩子（动作中段、反差、坦白、视觉+语言、感官锚点）→ `references/tiktok-hooks.md`。
4. **为抖音节奏构建脚本。** 钩子、升级、回报，设计为循环或触发保存 → `references/script-structure.md`。
5. **声音和原生功能。** 在其48-72小时窗口内的流行音频用于触达，原创音频用于可重复使用的知识产权。决定是否需要二重唱、拼接或可购物链接 → `references/sounds.md`，`references/native-features.md`。
6. **标题、屏幕文字、标签。** 首句前置（它显示在“更多”之上，抖音对其索引最硬）。3-5个具体标签，不是20个。标题制作在 `viral-captions-and-ctas` 中。
7. **反模式检查。** 跨平台发布时没有抖音水印、不要诱导互动、不要AI逼真人物内容（没有披露切换）、不要“关注获取更多” → `references/anti-patterns.md`。

## 模式（根据用户请求进行路由）

- **“给我一个关于X的抖音钩子”** → 第3步，返回一组标记的抖音风格钩子，然后提供将最强的构建成脚本的服务。
- **“写一个抖音脚本”** → 完整工作流程，使用 `assets/tiktok-script-template.md`。默认为21-34秒，除非用户需要创作者奖励（然后为60秒以上）。
- **“将这个脚本改为抖音风格”** → 诊断节奏、钩子位置和长度与 `references/retention-math.md`。重写开头，收紧中间，设置循环或保存。
- **“这是抖音还是Reel/Short？”** → 通过信号密度（声音、节奏、原生功能）回答。如果不是抖音，则指向匹配的平台技能。
- **“改进我的抖音视频”** → 批评模式。识别3秒悬崖失败的位置、完成率下降的位置以及缺失的信号（保存、分享、重看）。具体说明第二标记。
- **“这周我应该跟哪些抖音趋势？”** → 免费技能无法看到实时趋势。指导工作流程：通过创意中心、声音页面和你的为你推荐页面，在48-72小时窗口内发现声音。叠加个性。
- **“设置一个抖音购物视频”** → 先解决问题，再介绍产品。6秒钩子，6秒屏幕上显示产品，实际使用中演示，柔和收尾。使用 `assets/shop-video-template.md`。

## 示例

**用户：** “给我一个关于39美元可重复使用冷泡咖啡机的抖音钩子。”

**良好响应：** 推断简报（创作者账户，21-34秒，目标是保存和购物兴趣）。返回6-10个标记的抖音风格原型钩子，每个都回报优先且具体：

- *动作中段：* 摄像头已经倒冷泡。 “使用这个39美元的东西代替我400美元的意式咖啡设备的第47天。”
- *反差：* “昂贵的咖啡设备是为什么你的咖啡味道更差。”
- *坦白：* “我在咖啡行业工作。我不应该喜欢这个。我每天都用它。”
- *视觉+语言复合：* 缓慢倒水，冰块破裂，屏幕文字： “39美元的咖啡机，悄悄取代了我整个货架。”

然后以一个看起来像开头的帧结束脚本，以便重新观看触发。如果他们在抖音购物上销售，提供将最强的构建成完整脚本和可购物视频版本的服务。永远不要以品牌开头。
