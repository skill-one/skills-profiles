# 爆款短视频创意

帮助用户批量生成短视频创意，并运行创意构思系统，而不是等待灵感的到来。这项技能将那些高产创作者使用的命名框架和挖掘模式进行编码，使他们能够在不筋疲力尽或重复自己的情况下产生数百个想法。它不会预测哪个想法会成功。但它确保有足够多的强有力候选者，使得成功率变得重要。

关于钩子写作，请参考 `viral-hooks`。关于平台算法机制，请参考 `viral-tiktok-content`、`viral-youtube-shorts` 和 `viral-instagram-reels`。关于标题、行动号召和屏幕文字，请参考 `viral-captions-and-ctas`。关于脚本结构和留存，请参考 `viral-short-form` 总体框架。

## 运作原则（首先阅读这些，并在整个过程中应用）

1. **创意构思是一个系统，而不是一种情绪。** 每周发布固定产出的创作者运行一个有输入和输出的流程。基于灵感的创作者会突然发布内容然后保持沉默。将头脑风暴视为一个定期的生产阶段。
2. **限制条件产生创意；空白页面不会。** 无限制的“想一个视频”几乎总是什么也得不到或得到一些泛泛的内容。下面的每个框架都增加了一个限制条件（一个支柱、一个格式、一个受众、一个问题），并让限制条件进行思考。
3. **主题与角度。** 主题是你所涵盖的内容。角度是你如何涵盖。一个主题有数百个角度。空白页面的问题几乎总是角度缺失的问题，而不是主题缺失的问题。
4. **低成本测试，然后扩大赢家。** 推文或单行发布是测试一个想法最便宜的方式。一个精炼的30秒短视频大约贵10倍。想法应该通过生产成本阶梯逐步提升。
5. **捕捉和创作是不同的模式。** 快速捕捉（语音备忘录、笔记应用）通过整周收集原始材料。深入的会话将捕捉内容转化为脚本化的想法。混合这两种模式会扼杀两者。
6. **捕捉到的想法不是一个制作好的视频。** 一个从未发布的待办事项列表是任何捕捉系统最常见的失败。每个想法都需要一个状态和一个删除规则，否则流程会堵塞。
7. **模式匹配，而不是预测。** 框架倾向于提升数量和一致性。它们不保证任何单个视频的表现。

## 工作流程

根据需求进行调整。不要审问用户。如果他们现在想要20个想法，直接跳到第4步并推断其余部分。

1. **明确简报**（只询问缺失的内容）：细分领域、受众、平台、格式限制，以及这是一次性头脑风暴还是持续系统的开始。
2. **建立或检查支柱。** 如果用户没有，草拟3到5个。如果他们有超过5个，建议合并。支柱是所有其他内容依赖的第一个限制条件 -> `references/pillars.md`。
3. **选择创意构思引擎。** 矩阵式发散以增加数量，重新利用一个强有力想法产生多个角度，挖掘研究驱动的全新材料 -> `references/frameworks.md`。
4. **生成。** 运行所选引擎的整个流程。产生按支柱、格式或角度标记的输出，以便用户可以扫描和选择。
5. **过滤和排名。** 让候选者在快速评估中通过（受众匹配、你能构思出钩子、直觉兴奋） -> `references/idea-evaluation.md`。
6. **交接和安排。** 将赢家安排进一个节奏中。将其余内容移至带有到期日期的滑动文件中。建议对表现最好的前几个进行重新角度规划，一旦他们发布。

## 模式（根据用户请求进行路由）

- **“我卡住了，给我20个想法”** -> 从他们最近几篇发布或快速描述中推断支柱，然后运行内容矩阵引擎。返回标记、分组的输出。不要首先请求简报。
- **“为我构建一个内容系统/支柱”** -> 步骤1和2深入，加上 `assets/pillar-worksheet.md`。建议每个支柱每周一次节奏。
- **“将这个想法变成5个角度”** -> 重新利用模式。运行一个主题多角度的流程（消费、回应、策展、教学、叙事） -> `references/repurposing.md`。
- **“这周我应该发布什么”** -> 轻简简报 + 步骤4限制在5到7个，混合一个趋势候选者与四个常青内容，按支柱平衡。
- **“从我的受众/竞争对手那里找想法”** -> 挖掘模式。引导用户通过评论挖掘、Reddit、自动完成和竞争对手的异常值 -> `references/mining.md`。
- **“评价我的想法列表”** -> 评估模式。根据 `references/idea-evaluation.md` 对每个进行评分，并将最弱的重写为更强的角度，而不是简单地删除它们。

## 示例

**用户：** “我制作关于家用意式咖啡的视频。我完全没想法了。给我20个可以使用的。”

**良好响应：** 从细分领域推断出三个支柱（设备、技巧、购买决策），然后运行一个小矩阵：3个支柱 x 7种风格（可操作的教程、反常识观点、成本坦白、前后对比、等级列表、初学者错误指出、幕后花絮）并返回约20个按支柱分组的想法，每个想法具体到可以拍摄：

- **设备/反常识：** “你800美元的磨豆机是你意式咖啡尝起来平淡的原因。”
- **技巧/可操作：** “3秒的压粉检查解决了我的通道问题。”
- **购买/成本坦白：** “我花了2400美元在咖啡设备上，所以你可以跳到180美元的设置。”

然后标记两个最高杠杆的选择（具体性 + 明显的钩子潜力），建议在提交完整脚本之前将最好的一个作为单人访谈测试，并提供重新利用模式以产生5个角度变体的服务。永远不要交回一个未经区分的20个模糊想法列表。分组、标记、排名。
