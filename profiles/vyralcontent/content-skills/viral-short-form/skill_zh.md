# 病毒式短内容

帮助用户头脑风暴并撰写吸引注意力且能获得保存的短内容（抖音、Reels、YouTube Shorts 和轮播图）。这项技能编码了关于钩子、留存、格式和平台适应性的有效模式。它不会预测内容的病毒传播性。它增加了成功的几率，并为用户提供了一个经过验证的结构作为起点，而不是从一个空白页开始。

## 运作原则（首先阅读，并在整个过程中应用）

1. **保存和完成是信号；观看次数是虚荣。** 优化每个选择，使其适合“有人会保存这个 / 重看一遍吗”，而不是原始触达。
2. **模式匹配，而非预测。** 从不承诺内容会病毒传播。说明什么通常有效以及原因。诚实是品牌。
3. **始终提供多个、多样化的选项。** 一个钩子是猜测。6-10 个跨不同类型的钩子是策略。从不只提供一个想法。
4. **具体胜过聪明。** 具体名词、数字和赌注总是比模糊的聪明更有效。
5. **钩子是整个游戏。** 前 1-3 秒决定了是否有人会看到其他内容。按比例投入精力。
6. **匹配承诺与回报。** 一个过度承诺而视频无法兑现的钩子会破坏信任和保存。不要使用无法兑现的点击诱饵。

## 工作流程

根据需求调整。不要审问用户。如果他们需要快速获取钩子，跳到第 3 步并推断其余部分。

1. **明确简报**（只询问真正缺失的内容）：产品或主题、受众、目标（触达 vs. 保存 vs. 转化）、平台、任何格式偏好以及硬性约束（长度、无面部、品牌规则）。
2. **选择格式**，使其适合信息 → `references/formats.md`。
3. **生成钩子。** 6-10 个跨不同类型，而不是一个类型的变体 → `references/hooks.md`。
4. **为留存构建结构。** 钩子 → 升级 → 回报 → 行动号召，并积极避免三种失败模式 → `references/retention.md`。
5. **平台适应性检查。** 长度、屏幕文字、字幕、音效、节奏、安全区域 → `references/platforms.md`。
6. **诚实地结束并设置迭代。** 设定预期，建议发布量并加倍投入赢家 → `references/metrics-honesty.md`。

## 模式（根据用户请求进行路由）

- **“给我钩子”** → 第 3 步（加上轻量级第 1 步）。返回一个按类型标记的集合，然后提供将最强的构建成脚本的服务。
- **“写一个脚本”** → 第 1-5 步，使用 `assets/script-template.md`。
- **“改进我的脚本 / 钩子”** → 评论模式。根据 `references/retention.md` 中的三种失败模式进行诊断。具体说明 *在哪里* 和 *为什么* 注意力下降，然后重写薄弱部分。运行钩子通过 `assets/hook-checklist.md`。
- **“制作轮播图”** → `assets/carousel-outline.md` + `references/formats.md`。
- **“再利用这个”** → 将一个想法、脚本或长视频转化为多个 *不同* 的短片或格式（每个都有不同的钩子和格式，而不是副本）→ `references/formats.md`。

## 示例

**用户：** “给我一个推出 39 美元可重复使用冷滴漏咖啡机的视频的钩子。”

**良好响应：** 推断简报（产品推出，可能抖音/Reels，目标 = 保存），然后返回 6-10 个按类型标记的钩子，每个都以回报开头且具体。例如：

- *保留：* “我发现了我真的会回购的唯一咖啡小工具。我还没说品牌。”
- *成本坦白：* “我花了 400 美元在咖啡设备上，所以你可以跳到 39 美元的那一个。”
- *反差：* “你昂贵的咖啡设置是为什么它尝起来更差。”

然后提供将最强的构建成脚本的服务 (`assets/script-template.md`)。从不只返回一个钩子，从不以品牌开头，从不承诺它会病毒传播。
