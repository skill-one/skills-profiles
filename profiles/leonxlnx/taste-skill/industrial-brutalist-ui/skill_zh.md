# 技能：工业 Brutalism 与战术遥测 UI

## 1. 技能元数据
**名称：** 工业Brutalism 与战术遥测界面工程
**描述：** 精通构建融合了中世纪瑞士字体设计、工业制造手册和复古未来主义航空航天/军事终端界面的网页界面。该学科要求绝对掌握刚性模块化网格、极端字体大小对比、纯粹功利主义调色板以及模拟模拟退化的程序化（点阵、CRT扫描线、位图抖动）。目标是构建投射原始功能、机械精度和高数据密度的数字环境，故意摒弃传统消费级UI模式。

## 2. 视觉原型
设计系统通过融合两种截然不同但高度兼容的视觉范式运作。**每个项目选择其中一个并坚持。不要在同一界面中交替或混合两种模式。**

### 2.1 瑞士工业印刷
源自1960年代的企业识别系统和重型机械蓝图。
*   **特征：** 高对比度浅色模式（新闻纸/米色基材）。依赖大型、粗体的无衬线字体。无情的结构网格由可见的分隔线勾勒。激进、不对称地使用负空间，点缀超大、溢出视口的数字或字母形式。大量使用主色调红色作为警报/强调色。

### 2.2 战术遥测与CRT终端
源自机密军事数据库、遗留大型机以及航空航天平视显示器（HUD）。
*   **特征：** 独占暗色模式。高密度表格数据呈现。绝对主导等宽字体。集成技术框架装置（ASCII括号、十字准星）。应用模拟硬件限制（磷光闪烁、扫描线、低位深度渲染）。

## 3. 字体架构
字体是主要的结构和装饰基础设施。图像是次要的。该系统要求在规模、重量和间距上存在极端差异。

### 3.1 宏字体（结构化标题）
*   **分类：** 新无衬线/粗体无衬线。
*   **最佳网络字体：** Neue Haas Grotesk (黑体), Inter (特粗/黑体), Archivo Black, Roboto Flex (粗体), Monument Extended。
*   **实现参数：**
    *   **规模：** 使用流体字体以巨大规模部署（例如，`clamp(4rem, 10vw, 15rem)`）。
    *   **间距（字间距）：** 极其紧凑，通常是负的（`-0.03em` 至 `-0.06em`），迫使字形形成坚固的建筑块。
    *   **行距：** 高度压缩（`0.85` 至 `0.95`）。
    *   **大小写：** 独占大写，以产生结构冲击。

### 3.2 微字体（数据与遥测）
*   **分类：** 等宽/技术无衬线。
*   **最佳网络字体：** JetBrains Mono, IBM Plex Mono, Space Mono, VT323, Courier Prime。
*   **实现参数：**
    *   **规模：** 固定和小（`10px` 至 `14px` / `0.7rem` 至 `0.875rem`）。
    *   **间距：** 丰富（`0.05em` 至 `0.1em`）以模拟机械打字机间距或终端矩阵。
    *   **行距：** 标准至紧凑（`1.2` 至 `1.4`）。
    *   **大小写：** 独占大写。用于所有元数据、导航、单位ID和坐标。

### 3.3 纹理对比（艺术性破坏）
*   **分类：** 高对比度衬线。
*   **最佳网络字体：** Playfair Display, EB Garamond, Times New Roman。
*   **实现参数：** 极其吝啬地使用。必须经过重度后处理（点阵过滤器、1位抖动）以退化矢量完美性，并创建与干净无衬线字体的纹理并置。

## 4. 色彩系统
色彩架构毫不妥协。渐变、柔和阴影和现代半透明是严格禁止的。颜色模拟物理介质或原始发光显示器。

**关键：** 每个项目选择一个基材调色板并始终如一地使用。在同一界面中绝不能混合浅色和深色基材。

### 如果是瑞士工业印刷（浅色）：
*   **背景：** `#F4F4F0` 或 `#EAE8E3`（磨砂、未漂白文件纸）。
*   **前景：** `#050505` 至 `#111111`（碳墨）。
*   **强调色：** `#E61919` 或 `#FF2A2A`（航空/危险红色）。这是唯一的强调色。用于删除线、粗结构分隔线或关键数据高亮。

### 如果是战术遥测（深色）：
*   **背景：** `#0A0A0A` 或 `#121212`（停用CRT。避免纯 `#000000`）。
*   **前景：** `#EAEAEA`（白磷）。这是主要文本颜色。
*   **强调色：** `#E61919` 或 `#FF2A2A`（航空/危险红色）。相同的红色，相同的规则。
*   **终端绿色（`#4AF626`）：** 可选。仅用于单个特定UI元素（例如，一个状态指示器或一个数据读数）——绝不能作为通用文本颜色。如果它没有明确用途，则完全省略。

## 5. 布局和空间工程
布局必须看起来经过数学工程。它拒绝传统的网页填充，而是倾向于可见的分区。

*   **蓝图网格：** 严格遵循CSS网格架构。元素不浮动；它们精确地锚定到网格轨道和交叉点。
*   **可见分区：** 广泛使用实线边框（`1px` 或 `2px solid`）来划分信息的不同区域。水平规则（`<hr>`）频繁跨越整个容器宽度以隔离操作单元。
*   **双模密度：** 布局在极端数据密度（紧密排列的等宽元数据聚集在一起）和巨大的计算负空间之间切换，以框定宏字体。
*   **几何形状：** 绝对拒绝 `border-radius`。所有角落必须精确为90度，以强制执行机械刚性。

## 6. UI组件和符号
标准Web UI约定被功利主义、工业图形元素取代。

*   **语法装饰：** 使用ASCII字符来框定数据点。
    *   *框定：* `[ 交付系统 ]`, `< 重新启动 >`
    *   *方向：* `>>>`, `///`, `\\\\`
*   **工业标记：** 显著集成注册（`®`）、版权（`©`）和商标（`™`）符号，作为结构几何元素，而不是法律文本。
*   **技术资产：** 在网格交叉点集成十字准星（`+`），重复垂直线（条形码），粗水平警告条纹和随机字符串数据（例如，`REV 2.6`，`UNIT / D-01`）以模拟活动机械过程。

## 7. 纹理和后处理效果
为了防止设计看起来纯粹是数字的，通过CSS和SVG滤镜在前端工程模拟模拟退化。

*   **点阵和1位抖动：** 将连续色调图像或大型衬线字体转换为点阵图案。通过预处理或CSS `mix-blend-mode: multiply` 叠加结合SVG径向点图案实现。
*   **CRT扫描线：** 对于终端界面，应用背景的 `repeating-linear-gradient` 来模拟水平电子束扫描（例如，`repeating-linear-gradient(0deg, transparent, transparent 2px, rgba(0,0,0,0.1) 2px, rgba(0,0,0,0.1) 4px)`）。
*   **机械噪音：** 对DOM根应用全局低不透明度的SVG静态/噪音滤镜，以在深色和浅色模式之间引入统一的物理颗粒。

## 8. Web工程指令
1.  **网格确定性：** 使用 `display: grid; gap: 1px;` 并使用对比鲜明的父/子背景颜色来生成数学上完美的、剃刀薄的分隔线，而无需复杂的边框声明。
2.  **语义刚性：** 使用精确的语义标签（`<data>`，`<samp>`，`<kbd>`，`<output>`，`<dl>`）构建DOM，以准确反映遥测的技术性质。
3.  **字体限制：** 仅对宏字体使用CSS `clamp()` 函数，以确保巨大的文本规模激进地执行，同时保持跨视口的结构完整性。
