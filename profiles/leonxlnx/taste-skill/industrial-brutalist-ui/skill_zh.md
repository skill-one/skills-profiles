# 技能：工业粗野主义与战术遥测用户界面

## 1. 技能元信息
**名称：** 工业粗野主义与战术遥测界面工程
**描述：** 精通构建融合中世纪（Mid-century）瑞士排版设计、工业制造手册与复古未来主义航空航天/军用终端界面的网络界面。此学科要求对严格模块化网格、极端的排版比例对比、纯粹功能主义色彩方案，以及模拟模拟信号衰变（半色调、CRT 扫描线、位图抖动能）具备绝对掌控力。目标是构建呈现出原始功能、机械精度与高数据密度的数字环境，有意摒弃传统消费级用户界面模式。

## 2. 视觉原型
设计系统通过融合两种截然不同但高度兼容的视觉范式运作。**每个项目需从两者中挑选其一并始终贯穿使用。请勿在同一界面内交替或混用两种模式。**

### 2.1 瑞士工业印刷
源于 1960 年代企业识别系统与重型机械制造蓝图。
*   **特性：** 高对比度浅色模式（新闻纸/米白基底）。依赖单体、粗重的无衬线排版。由可见分割线勾勒出的严苛结构网格。激进的非对称使用留白，以超大、溢出视口的数字或字母组合进行点缀。大量使用主红色作为警示/强调色。

### 2.2 战术遥测与 CRT 终端
源于机密军用数据库、遗留大型机与航空航天抬头显示（Heads-Up Displays, HUDs）。
*   **特性：** 深色模式专属。高密度表格数据呈现。等宽排版（Monospaced）的绝对主导。集成技术框架元素（ASCII 括号、十字准星）。应用模拟硬件限制（磷光发光、扫描线、低位深渲染）。

## 3. 排版架构
排版是主要的组织结构与装饰性基础设施。图像为次要元素。系统要求极端的字号、字重与字距差异。

### 3.1 宏观排版（结构标题）
*   **分类：** 新粗体 / 重型无衬线。
*   **最佳网页字体：** Neue Haas Grotesk (Black), Inter (Extra Bold/Black), Archivo Black, Roboto Flex (Heavy), Monument Extended。
*   **实现参数：**
    *   **字号：** 使用流体排版以超大字号部署（例如 `clamp(4rem, 10vw, 15rem)`）。
    *   **字距（字距调整）：** 极其紧凑，通常为负值（`-0.03em` 至 `-0.06em`），迫使字形形成坚实的建筑区块。
    *   **行高：** 极度压缩（0.85 至 0.95）。
    *   **大小写：** 仅用于结构冲击力，全部为大写。

### 3.2 微观排版（数据与遥测）
*   **分类：** 等宽 / 技术无衬线。
*   **最佳网页字体：** JetBrains Mono, IBM Plex Mono, Space Mono, VT323, Courier Prime。
*   **实现参数：**
    *   **字号：** 固定且较小（10px 至 14px / 0.7rem 至 0.875rem）。
    *   **字距：** 宽松（0.05em 至 0.1em），以模拟机械打字机的间距或终端矩阵。
    *   **行高：** 标准至紧凑（1.2 至 1.4）。
    *   **大小写：** 仅用于元数据、导航、单位 ID 与坐标，全部为大写。

### 3.3 质感对比（艺术性破坏）
*   **分类：** 高对比度衬线。
*   **最佳网页字体：** Playfair Display, EB Garamond, Times New Roman。
*   **实现参数：** 极少使用。必须经过重度后期处理（半色调滤镜、1 位抖动），以破坏矢量完美性，与干净的无衬线字体形成质感上的对比。

## 4. 色彩系统
色彩架构不容妥协。渐变、柔和阴影与现代化通透效果被严格禁止。色彩需模拟物理媒介或原始发光显示。

**关键：** 每个项目需选择一套基底色板并保持一致使用。同一界面内切勿混用浅色与深色基底。

### 若采用瑞士工业印刷（浅色）：
*   **背景：** `#F4F4F0` 或 `#EAE8E3`（哑光、未漂白文档纸）。
*   **前景：** `#050505` 至 `#111111`（碳墨）。
*   **强调色：** `#E61919` 或 `#FF2A2A`（航空/危险红）。这是唯一的强调色。用于删除线、加粗的结构分割线或关键数据高亮。

### 若采用战术遥测（深色）：
*   **背景：** `#0A0A0A` 或 `#121212`（停用 CRT。避免使用纯 `#000000`）。
*   **前景：** `#EAEAEA`（白色磷光）。这是主要文本颜色。
*   **强调色：** `#E61919` 或 `#FF2A2A`（航空/危险红）。同样的红色，同样的规则。
*   **终端绿（`#4AF626`）：** 可选。仅用于单一的特定 UI 元素（例如一个状态指示器或一个数据读取结果）——绝不能作为通用文本颜色使用。若其无法发挥明确作用，请完全省略。

## 5. 布局与空间工程
布局必须呈现为数学工程化的效果。其摒弃常规网页内边距，改用可见的分区划分。

*   **蓝图网格：** 严格遵守 CSS Grid 架构。元素不会悬浮，而是精确锚定到网格轨道与交叉点。
*   **可见分区：** 大量运用实线边框（1px 或 2px solid）界定不同的信息区域。水平规则（`<!hr>`）频繁跨越整个容器宽度，以分隔操作单元。
*   **双模密度：** 布局在极端数据密度（紧密排列的等宽元数据簇聚）与大量计算出的负空间（框架宏观排版）之间交替。
*   **几何形态：** 绝对摒弃 `border-radius`。所有角落必须恰好为 90 度，以强化机械刚性。

## 6. UI 组件与符号系统
标准网页 UI 惯例被实用的工业图形元素取代。

*   **语法装饰：** 利用 ASCII 字符来框定数据点。
    *   **框定：** `[ DELIVERY SYSTEMS ]`, `< RE-IND >`
    *   **方向：** `>>>`, `///`, `\\\\`
*   **工业标识：** 显著整合注册（®）、版权（©）与商标（™）符号，将其作为结构几何元素，而非法律文本使用。
*   **技术资产：** 整合十字准星（`+`）、重复垂直线（条形码）、加粗水平警示条纹与随机字符串数据（如 `REV 2.6`, `UNIT / D-01`），以模拟活跃的机械过程。

## 7. 质感与后处理效果
为防止设计呈现纯数字感，将模拟的模拟信号衰变通过 CSS 与 SVG 滤镜整合到前端。

*   **半色调与 1 位抖动：** 将连续色调图像或大面积衬线排版转化为点阵图案。通过预加工或 CSS `mix-bl end-mode: multiply` 叠加结合 SVG 径向点图案实现。
*   **CRT 扫描线：** 针对终端界面，通过 `repeating-linear-gradient` 应用于背景，以模拟水平电子束扫描（例如 `repeating-linear-gradient(0deg, transparent, transparent 2px, rgba(0,0,0,0.1) 2px, rgba(0,0,0,0.1) 4px)`）。
*   **机械噪点：** 对 DOM 根节点应用全局、低透明度的 SVG 静态/噪点滤镜，为深色与浅色模式引入统一的物理颗粒感。

## 8. 网页工程指令
1.  **网格确定性：** 使用 `display: grid; gap: 1px;`，通过对比的父级/子级背景色生成数学上完美、极致纤细的分割线，无需复杂的边框声明。
2.  **语义严谨性：** 使用精确的语义化标签（`<!data>`、`<!samp>`、`<!kbd>`、`<!output>`、`<!dl>`）构建 DOM，以准确反映遥测的技术特性。
3.  **排版自适应：** 仅使用 CSS `clamp()` 函数应用于宏观排版，确保大字号文本激进缩放，同时在所有视口中保持结构完整性。
