# Sentry 工作流

保持您的 Sentry SDK 更新。本页面帮助您为您的任务找到合适的工作流技能。

## 开始这里 — 在做任何事之前请阅读

- 如果用户提到 **升级 Sentry、迁移 SDK 版本或修复已弃用的 API** → `sentry-sdk-upgrade`

> 修复或调查生产问题？那是独立的 `sentry-debug-issue` 技能。
