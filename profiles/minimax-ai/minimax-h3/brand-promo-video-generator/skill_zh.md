# 品牌宣传视频生成器

为品牌、产品、网站、应用程序、商店或个人项目创建一个精制的短片宣传视频。当用户拥有标志、产品图片、屏幕截图、网站链接或仅仅是清晰的创意，并希望代理将这些材料转化为一个干净的品牌轮播时，使用此技能。

此 Hub 适配将第三方 Vibe Motion / Remotion 实现细节替换为 Hub 本地编排：源研究、资产验证、故事规划、图像/视频生成、可选语音或音乐，以及编辑组装。在正常执行期间，不要初始化外部项目或依赖 npm 验证器。

## 工具覆盖规则

`allowed-tools` 列表必须覆盖此技能中的完整生产承诺：源查找、图像准备/生成、视频片段生成、可选语音/音乐/音频生成、最终编辑/组装、媒体检查和画布分组。如果运行时未提供列出的生成或编辑工具之一，请明确将交付品降级为预生产套餐，而不是声称可以生成最终宣传视频。

## 第一步：接收资产并解决简报

在进行任何故事规划或生成之前，运行必要的用户接收流程。要求用户上传或提供必须验证的元素的链接：

- 标志文件或官方标志源页面
- 字体文件、字体名称、排版指南或显示品牌排版的官方网站页面
- 品牌颜色、色彩系统、风格指南或清晰显示官方颜色的页面
- 产品图片、UI 屏幕截图、包装、渲染、片段或其他品牌图像
- 产品信息：官方产品名称、功能列表、发布重点、声明、CTA、免责声明和目标受众
- 公司/产品官方 URL 或官方源包

将用户上传的资产视为在预生产和概念规划中可用。除非存在具体的风险信号，例如可见的第三方水印、明显抓取的市场图像、用户措辞矛盾、法律/医疗/金融合规声明或用户要求商业发布，否则在第一次接收流程中不要反复询问独立的权利/许可问题。将来源记录为“用户提供”，并在源摘要中显示权利注意事项，而不是阻塞流程。

在相同的开场接收流程中，要求用户选择：

- 目标持续时间，通常为 15-30 秒；当用户想要快速发布电影时，建议 15 秒
- 纵横比；提供常见选择，如 16:9、9:16、1:1、4:3、3:4 或匹配提供的参考

当它们尚未清晰时，还要确定活动重点、分发渠道、旁白语言、屏幕文字语言和可见文字需求。在用户提供可用材料或明确确认哪些元素不可用之前，不要继续创意方向。

宣传内容的语言规则：从品牌材料、目标受众和平台背景中选择旁白和屏幕文字语言，而不是从聊天语言机械地选择。如果品牌资产和可见源文字主要是英语或全球企业英语，除非用户明确要求中文本地化，否则默认旁白和屏幕文字为英语。如果用户是中国人，但说他们是作为新用户进行测试，请将聊天回复保持在中文，但计划实际视频文字为最适合品牌活动的语言。

如果标志、产品 UI、人物、吉祥物、包装、字体、色彩系统或其他承载身份的资产无法验证，请停止并要求授权原始版本，而不是生成一个合理的替代品。

## 第二步：构建品牌真相表

在创意生产之前，研究或检查最强大的可用来源并总结品牌真相表：

1. 用户提供的原始导出
2. 官方公司网站、静态包、新闻室、品牌门户、媒体包、新闻包或官方存储库
3. 公司控制的媒体库
4. 许可的库存或授权合作伙伴套件

提取：

- 精确的标志变体、清晰空间和使用限制
- 官方字体或可见的排版行为
- 主要、次要和动态品牌颜色
- 品牌语气、原则、视觉主题和交互语言
- 当前产品名称、功能、场景、指标、口号、CTA 和免责声明
- 官方摄影、渲染、UI 屏幕截图、片段、新闻资产和媒体包材料

不要使用标志聚合网站、搜索缩略图、粉丝重现、Pinterest 转发或 AI 生成的替代品作为承载身份的来源。过程图形仅允许作为非代表性运动层：蒙版、渐变、色彩字段、网格、辉光、粒子、轨迹、排版、验证数据图表和过渡几何形状。

## 第三步：创建来源清单

在紧凑的清单中记录每个承载身份的资产，该清单可以交付给用户。清单可以是文本节点或表格，并应包括：

- 稳定的资产 ID 和角色
- 当可用时，本地路径或画布节点引用
- 精确的源 URL 或用户提供的源注释
- 源类型，例如官方网站、媒体包、用户提供的原始或许可库存
- 用于比较的验证目标
- 权利或发布注意事项
- 真实性状态：已验证、用户提供、许可或阻止

清单本身不授予发布权利。如果授权不明确，请将视频标记为非官方概念，并告诉用户商业发布需要许可。

## 第四步：选择故事骨干

当用户尚未选择一个时，呈现 2-3 个简洁的创意方向，推荐一个，并在确认后继续。使用产品类别来选择骨干：

- AI / SaaS：用户意图 -> 思考或规划 -> 功能 -> 执行 -> 有用输出 -> 证明 -> 标志
- 物理产品：英雄揭示 -> 交互 -> 功能宏观 -> 使用上下文 -> 结果 -> 标志
- 服务/公司：背景 -> 过程 -> 证据 -> 结果 -> 承诺 -> 标志
- 以图像为主的品牌：真实图像 -> 视觉主题 -> 利益 -> 情感回报 -> 标志

保持故事产品特定。显示实际功能、交互、场景、输出和证明，而不是在抽象效果后面隐藏故事。

## 第五步：规划精确的节拍

在生成之前，规划一个基于帧的时间线。使用 30fps 作为规划惯例，除非输出管道要求否则。

对于 15 秒的电影，目标为 5-8 个主要节拍。对于 30 秒的电影，目标为 8-12 个主要节拍。每个节拍应定义：

- 开始和结束时间或帧范围
- 视觉所有者和真实资产 ID
- 主要动作
- 在镜头中显示的产品或品牌证明
- 文字和可读保持
- 颜色状态
- 进入和退出过渡
- 运动意图：设置、预期、承诺、冲击、制动、稳定

一个有用的 15 秒模式是：品牌钩子、用户意图或设置、产品机制、功能或场景、输出或证明、产品回报、最终标志和 CTA。当退出运动自然提供下一镜头时，使用 6-12 帧重叠。

## 第六步：指导运动语言

通过控制构建强度：

- 让产品运动、光标路径、UI 流动、光、滚动内容、对象边缘或匹配的几何形状驱动过渡
- 使用 2-5 个有意为之的颜色状态与含义相关联
- 每个节拍保持一个主要动作；稍微延迟次要层
- 建立 2-3 个高能量峰值和较安静制动时刻
- 保留可读的轮廓、文字和标志清晰空间
- 避免假 HUD、任意玻璃卡片、装饰性文字墙、未验证的指标和到处都相同的缓动

对于 AI 产品，至少包含一个可读链，例如：提示 -> 规划 -> 并行功能 -> 生成的结果 -> 证明。对于物理或服务产品，显示从用户操作到具体结果的因果关系。

## 第七步：生成前硬确认

在生成任何视频、图像序列、语音、音乐或最终编辑之前，停止并显示用户完成的预生产套餐：

- 来源清单或源摘要
- 品牌真相表
- 选择创意方向
- 精确节拍/镜头计划
- 可见文字、CTA、旁白和音频计划
- 已知的真实性、权利或占位符注意事项

在生成之前使用简洁的确认步骤。如果用户在看到预生产套餐后明确表示批准或意图继续——例如“确认”、“生成”、“继续”、“继续”、“下一步”、“可以”、“继续”、“下一步”或类似——将其视为生成权限，除非消息还要求更改。如果用户要求跳过流程，仍然首先提供紧凑的源摘要、品牌真相表和节拍计划，然后在他们表示批准时继续。仅在用户回复含糊不清或要求更改时才提供修订选择。

## 第八步：生成 Hub 资产

在硬确认门通过后，仅使用 Hub 本地生成和编辑。保持每个调度自包含，具有选择的模型、纵横比、真实参考路径和原始请求。

典型生产流程：

1. 生成或准备经过验证的静态帧、UI 板、产品英雄帧或运动就绪的故事图像。
2. 从这些帧或从精确的文本提示生成视频片段，保留相同的比例和品牌资产。
3. 默认音频策略对于原生品牌轮播：当用户要求背景音乐、音乐、音轨、环境声音或说 nothing beyond 需要一个完成的宣传视频时，优先选择所选视频模型的视频原生音频，而不是生成单独的音乐轨道。对于默认的 MiniMax H3 路径，设置原生音频为真 (`generate_audio=true`)，并在视频提示中提示品牌安全的器乐音乐 / UI 声音设计。
4. 仅在用户明确需要可控旁白、配音、对话、可替换的独立背景音乐、精确的音乐持续时间独立于视频、后期制作混音或所选视频模型无法生成合适音频时，生成单独的语音或音乐。不要在视频原生音频和单独音频生成之间重复音轨。
5. 在编辑中组装片段、任何明确分开的音频和最终品牌锁定。仅在用户明确要求字幕时添加字幕。

不要重绘或近似标志、文字标记、产品 UI、包装、吉祥物、人物或品牌场景。仅使用生成的材料进行抽象运动、氛围、过渡几何形状或不会模仿官方产品证据的明确概念场景。

## 第九步：交付前验证

在最终响应之前，检查：

- 标志和承载身份的资产来自经过验证或用户授权的来源
- 产品名称、功能措辞、声明、指标、口号和 CTA 与官方来源一致或明确标记为概念文字
- 视频持续时间、纵横比和语言与简报一致
- 文字可读且不拥挤
- 最终标志没有被拉伸、裁剪或重建
- 运动具有清晰的可视所有权，并且不会遮挡产品
- 输出在画布上，多资产输出被分组

如果输出未通过真实性检查，请用官方/用户授权的来源替换有问题的资产或停止并要求该资产。永远不要改进模仿。

## 第十步：交付

提供：

- 最终视频路径或画布输出
- 持续时间、纵横比和语言
- 简短的创意摘要
- 来源清单或源摘要
- 权利/免责声明注意事项（如有必要）
- 下一次迭代的特定建议，例如节奏、声明清晰度、CTA、音频或平台裁剪

## 失败恢复

- 错误或近似的标志：删除它，定位当前的官方文件或要求用户的原始版本，然后重新生成或重新编辑。
- 看起来像假的 产品/UI：用官方、用户提供的或许可的媒体替换。不要润色模仿。
- 美丽但通用：添加完整的产品交互、验证声明或真实输出。
- 快但混乱：减少同时动作，分配视觉所有者，并在剪辑之间保留匹配的运动。
- 平滑但慢：缩短保持时间，重叠过渡，仅在关键信息周围制动。
- 资产不可用：要求授权原始版本；永远不要猜测。
