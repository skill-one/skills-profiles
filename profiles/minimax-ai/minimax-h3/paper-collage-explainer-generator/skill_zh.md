# 纸艺拼贴解释生成器

将简短的叙述行、故事主题、视角句或抽象概念转化为连贯的编辑纸艺拼贴动画序列。视觉语言是高端半色调纸艺拼贴：平面大胆色块、黑白摄影剪贴、选择性彩色卡纸点缀、温暖米色关键线、柔和纸艺阴影、触感定格动画组装，以及清晰的拼贴音效。

这个基于Hub的技能使用Hub原生的图像、视频、音频和可选的后处理功能。它优先考虑风格连贯性、色彩和谐、受控的纸张纹理、定格动画拼贴节奏，以及默认保留触感拼贴音效的音频策略，明确不添加背景音乐、旁白或字幕，除非用户要求。

## 使用场景

当用户需要时使用此技能：

- 将简短脚本行转化为视觉隐喻拼贴动画
- 通过拼贴B-roll解释简单故事或文学主题
- 用于叙述或社交视频的编辑纸艺拼贴动画
- 半色调拼贴动画，物体从空色块中组装
- 将一批简短抽象句或故事节拍转化为独立的视觉隐喻动画片段
- 具有触感知识解释，可能包括纸张点击、啪嗒、滑动、按压和沙沙声，但不包含自动音乐或旁白

当用户需要时不要使用此技能：

- 真实的产品广告或主持人主导视频
- 精确可编辑的图层、时间轴关键帧或透明剪贴资产
- 精确的标志放置或可读的字体
- 仅需要书面视频提示而不进行生成

## 默认创意目标

除非用户另有说明：

- 输出比例：16:9横向
- 片段长度：每个片段约4秒
- 音频默认：保留或生成触感纸艺拼贴音效，例如纸张滑动、啪嗒、按压、轻微沙沙声和轻柔敲击声
- 默认：不添加背景音乐。当这可能有助于时，您可以询问用户是否需要背景音乐，但在明确用户确认后添加音乐
- 默认：不添加旁白、口语叙述或主持人叙述。当项目可能受益时，您可以询问用户是否需要旁白/口播，但在明确用户确认后进行撰写、合成或添加口语音频
- 默认：不添加字幕。当这可能有助于时，您可以询问用户是否需要字幕，但在明确用户确认后创建或嵌入字幕
- 视觉风格：高端编辑半色调纸艺拼贴
- 动作风格：触感定格动画组装，不是慢速缩放、通用漂浮或平滑数字层移动
- 默认视频生成模型：`MiniMax-H3`，除非用户明确指定其他模型、模型不可用或硬性功能要求排除它
- 图像/视频中的文字：避免可读字母、数字、UI、字幕、水印和标志，除非明确要求
- 图像质量和深度：优先考虑视觉吸引人、分层的16:9构图，具有清晰的 foreground、midground 和 background 深度，强烈的主题层次结构，丰富的场景设计但可读，以及受控的负空间

## 音频策略

此技能的默认交付是**包含拼贴音效，不包含背景音乐、旁白或字幕**。

1. 在第一次生产计划确认时，明确说明默认媒体方法：保留或生成触感纸艺拼贴音效；默认不添加背景音乐、旁白/口播和字幕。
2. 可以询问用户是否需要**旁白叙述/口播**、**背景音乐**或**字幕**，特别是对于解释视频，但将所有三项作为可选附加项，不是默认项。
3. 不要推断解释视频自动需要口语旁白。如果用户不选择旁白，则创建视觉故事节拍，而不是旁白脚本。
4. 不要推断社交视频自动需要背景音乐或字幕。如果用户不选择它们，则仅保留片段音效。
5. 在生成视频片段时，如果选定的视频模型支持音频，请求同步触感拼贴音效：纸片滑动、啪嗒、压平、轻柔敲击和轻微纸张沙沙声。
6. 在最终组装期间，保留包含拼贴音效的原始片段音轨。默认情况下不要丢弃音轨。
7. 仅在用户要求静音、生成的音频包含不需要的语音/音乐，或用户请求单独的音乐/旁白混音时移除或替换音频。仅在用户明确要求时创建字幕。

## 全局风格规则

将以下规则应用于项目中的每个静态图像和视频：

1. **统一整体视觉风格。** 每个片段都应感觉像是同一编辑纸艺拼贴系列的组成部分：半色调剪贴、平面色块、温暖米色关键线、柔和物理阴影、干净构图、触感纸张材质和协调的拼贴音效。
2. **控制纸张纹理强度。** 纸张不应看起来完全平坦，但也必须不会显得过于陈旧、脏污、褶皱或发黄，除非用户明确要求。优先选择干净、精致的手工纹理：微妙的纤维、略微不规则的撕裂边缘、轻微的鱼鳞纤维、分层接缝和柔和阴影。
3. **统一色调。** 不要引入牛皮纸、棕色、泛黄或破损的基底纸，除非它们与批准的静态图像或批次调色板冲突。从与批准的最终静态图像主色调方向匹配的纸张色块开始每个片段。
4. **使动作看起来像定格动画拼贴。** 使用清晰的纸片动作：逐片出现，滑动或啪嗒到位，轻柔弹跳，压平，暂停，然后锁定到最终构图。避免快速旋转、过度翻转、混乱的物体飞行、全局淡入、平滑数字平移、缩放或通用漂浮。
5. **保持片段协调。** 一旦一个或两个片段建立了批准的批次风格和音效节奏，后续片段和修订应参考该节奏和风格，使整个序列感觉连贯。
6. **默认为精良的16:9分层场景。** 除非用户明确请求其他平台框架，否则计划和在16:9横向生成。使用更宽的画布构建吸引人的前景/中景/背景分离、更丰富的环境道具、清晰的主题层次结构和电影般的横向构图，而不会使框架变得杂乱。
7. **强调纸艺拼贴工艺。** 每个静态图像和片段都应使纸艺拼贴方法可见：可分离的纸组、半色调摄影剪贴、彩色卡纸点缀、触感阴影、撕裂边缘、分层接缝和定格动画动作，如弹出、滑入、轻柔弹跳、压平、暂停和锁定。

## 第1步：解析输入

对于每一行、概念、故事或主题，提取：

- 核心含义：观众应该理解什么
- 情感：平静、紧急、讽刺、惊讶、荒谬、澄清、反思、神秘或俏皮
- 动作动词：打开、连接、泄漏、存档、压缩、拆分、照亮、绑定、组装、揭示、落下、追逐、转换、碰撞
- 视觉隐喻：一个具体的图像，表达想法而不在屏幕上写脚本
- 关键物体：三到六个大可读纸组
- 音频暗示：是否节奏受益于纸张滑动、啪嗒、按压、敲击、沙沙声或啪嗒音效

对于故事主题，除非用户指定数量，否则将故事分成三到六个简洁的节拍。相似的节拍可以共享相同的设计语言，但每个都应该有独特的隐喻、物体集、色块和SFX节奏。

## 第2步：关卡1 — 生产计划文档批准

在生成任何媒体之前，创建一份简洁的生产计划文档并停止等待用户批准。在用户确认此文档之前不要生成静态图像或视频。

生产计划必须包括：

### 简要说明

- 主题或来源行
- 预期的受众/使用上下文（如果已知）
- 画幅和持续时间假设
- 调调和节奏
- 视觉风格摘要
- 媒体方法，声明为：默认拼贴SFX保留或生成；除非用户明确要求，否则不添加背景音乐、旁白/口播和字幕
- 可选附加问题：当有用时，询问用户是否需要旁白叙述/口播、背景音乐或字幕，但保持它们为可选

### 视觉隐喻

对于每个计划片段：

- 核心含义
- 情感
- 一句话视觉主张
- 三到六个关键物体
- 建议的背景色和强调色
- 预期的组装顺序
- 预期的拼贴SFX时刻，如滑动、啪嗒、按压、敲击、沙沙声或啪嗒

### 脚本/视觉节拍轨道

如果用户明确要求旁白，请撰写简洁的旁白脚本。如果用户没有明确要求旁白，请**不要**撰写旁白脚本；相反，请撰写无声视觉节拍轨道，解释观众从序列中理解的内容。

如果用户只需要现有行的B-roll，请保留原始行作为上下文，而不是编造旁白。

### 故事板

对于每个片段，包括：

- 片段标题
- 最终帧描述
- 动作想法
- 大约持续时间
- 拼贴SFX想法
- 风格连贯性和色彩和谐笔记

在呈现生产计划文档后，等待用户批准、拒绝或修订。如果用户只批准编号项目的一部分，请仅移动那些项目并修订其余部分。

## 第3步：构建静态图像规范

批准生产计划后，为每个批准的片段撰写紧凑的视觉规范。规范应自包含且适合图像生成。

包括：

- 脚本含义或故事节拍
- 视觉隐喻
- 画幅
- 背景色块
- 强调色
- 关键物体组和它们的作用
- 构图、前景/中景/背景深度和负空间
- 最终帧关系
- 风格连贯性笔记
- 避免此特定静态图像的列表

使用此风格签名：

```text
平面大胆色块、黑白半色调摄影剪贴、选择性彩色卡纸点缀、温暖米色关键线、柔和纸艺阴影、细未涂布纸张纹理、高端编辑纸艺拼贴、干净精致的撕边纸张边缘、微妙的纤维边缘、分层纸张接缝
```

色彩指导：

- 烧焦橙色或红色：劳动、时间压力、紧急
- 芥末黄：工具、警告、累积错误
- 墨绿：认知、重置、判断、超现实平静
- 深紫色：记忆、结构、神秘、梦境逻辑
- 青色：合作、执行、系统流程
- 玫瑰红：荒谬、仪式、戏剧张力

不要将钴蓝色设为自动默认色。通过纸张纹理、半色调处理、关键线、阴影、构图和受控调色板保持批次视觉统一。仅在故事节拍受益于对比时才改变色块。

## 第4步：关卡2 — 生成并批准静态图像

为每个批准的片段生成一个最终静态图像。静态图像必须看起来像未来动画的完成最后一帧。

静态图像要求：

- 使用用户指定的画幅；否则默认为16:9横向
- 平面大胆纸张背景，带有微妙纤维纹理
- 三到六个大可分离的物体组，除非批准的故事板需要稍多
- 清晰的中心主题，强烈的视觉层次结构，充足的干净负空间，以及可见的前景/中景/背景分层
- 黑白半色调摄影剪贴作为主要结构，结合丰富的场景道具支持故事节拍
- 仅在需要澄清层次结构时使用选择性彩色卡纸点缀
- 温暖米色关键线、柔和物理纸艺阴影、精致撕边边缘和微妙分层纸张接缝
- 除非明确要求，否则不包含可读文字、假字母、数字、字幕、UI、水印或标志

将生成的静态图像展示给用户并停止等待批准，然后再进行视频生成。如果静态图像看起来太忙、颜色不匹配、纸张层太多、数字边缘太平坦或陈旧/发黄的纸张纹理太多，请在视频生成前修订静态图像。

## 第5步：规划定格动画组装

对于每个批准的静态图像，准备一个运动计划，将批准的静态图像视为完成的最终帧。

默认运动顺序：

1. 从与批准的静态图像背景色和色调匹配的干净纸张色块开始，而不是不匹配的牛皮纸或棕色基底。
2. 基础结构作为滑入、啪嗒或压入位置的纸片出现。
3. 人物、卡片、物体或主要隐喻元素进入。
4. 次要物体逐个组装，带有小弹跳、压平和暂停节拍。
5. 最终关系锁定到批准的构图。
6. 在结尾处短暂保持完成的类似静态图像帧。

运动提示指导：

```text
纸艺拼贴定格动画组装。从与批准的静态图像背景色和色调匹配的干净纸张色块开始。逐片组装场景，使用触感定格动画时间：前景、中景和背景纸组按可读顺序出现；每个纸片对象出现，滑入或啪嗒到位，轻柔弹跳，压平，暂停，并锁定到位。保留半色调点、米色关键线、微妙的纤维撕边边缘、分层纸张接缝、柔和阴影、纸张纹理、色块和批准的画幅。结束并保持与批准的静态图像帧匹配的完成构图。音效设计：触感拼贴音效仅，与纸片运动同步：轻柔纸张滑动、啪嗒、压平敲击、轻微沙沙声和适当的地方啪嗒。默认：不添加背景音乐、旁白/口播、对话或字幕，除非用户明确要求。没有不匹配的牛皮纸开场，没有棕色/泛黄基底，除非批准，没有快速旋转，没有混乱的物体飞行，没有平滑数字层移动，没有场景切换，没有相机移动，没有缩放，没有变形，没有新物体，没有文字，没有标志，没有水印，没有UI。
```

## 第6步：生成拼贴音效B-roll片段

在关卡2批准后，为每个批准的静态图像生成一个视频片段。

生成要求：

- 使用批准的静态图像作为视觉参考/最终帧锚点，只要选定的Hub视频模型支持
- 使用与静态图像相同的画幅
- 目标大约为四秒，除非用户请求了不同长度
- 默认支持时生成或保留触感拼贴音效：纸张滑动、啪嗒、压平敲击、轻微沙沙声、微小啪嗒
- 默认：不生成或添加背景音乐，除非用户明确要求音乐
- 默认：不生成或添加旁白、口语叙述或主持人音频，除非用户明确要求旁白/口播
- 如果生成的片段包含有用的拼贴音效，请在后期制作和最终组装期间保留它
- 如果生成的片段包含不需要的语音、音乐、假UI声音或嘈杂的环境音，根据用户目标移除或重新生成音频
- 保持镜头视觉稳定；除非用户要求，否则不要添加相机移动
- 保留拼贴材质语言、最终构图和已建立的批次风格
- 在修订后续片段时，如果有助于风格/节奏参考，可以使用最佳批准的前一个片段

使用 `MiniMax-H3` 作为此技能的默认视频生成模型。除非 `MiniMax-H3` 失败、不可用或无法满足硬性功能要求，否则不要询问用户选择模型。如果用户明确指定了另一个模型，请将该模型作为主要模型，并在需要时仅调整参数。

## 第7步：质量审查

根据这些标准审查静态图像和片段：

- 隐喻或故事节拍无需在屏幕上写脚本即可理解
- 静态图像具有强烈的干净色块、默认的吸引人16:9构图、清晰的物体层次结构和可见的前景/中景/背景深度
- 物体组数量保持可读，不是满屏的碎片
- 片段从与批准的静态图像或批次调色板匹配的色块开始
- 组装逐片可见，不是全局淡入
- 动作看起来像定格动画拼贴：单独的纸组弹出或滑入，轻柔弹跳，压平，暂停，并锁定到位
- 默认：触感拼贴音效是理想的；背景音乐、旁白/口播和字幕在未明确要求时不存在
- 纸张纹理受控：不扁平，不过于陈旧，不是棕色/牛皮纸，除非批准
- 色调在整个批次中保持一致
- 最终帧与批准的静态图像保持接近
- 没有不需要的可读字母、假UI、字幕、水印或标志

如果微小细节的轻微漂移不会使隐喻变得模糊，并且最终构图仍然类似于批准的静态图像，则可以接受。如果出现重大漂移、添加文本、假UI、不匹配的开场色、不需要的牛皮纸基底、过度褶皱/脏污的纸张纹理、丢失的定格动画组装、不需要的背景音乐或不需要的旁白，则应根据问题出现的位置重新生成或进行后期处理。

## 第8步：可选组装、音乐、旁白和交付

如果用户要求多片段故事视频，请按确认的故事板顺序组装批准的片段，并默认保留每个片段的原始拼贴音效。

仅在明确要求时添加背景音乐、旁白/口播或字幕。当用户在片段已经存在后请求背景音乐或旁白时，将音乐与拼贴音效混合，而不是替换音效，除非用户要求静音原始音效。

对于每个完成的项目，交付：

- 最终B-roll视频路径或最终组装视频路径
