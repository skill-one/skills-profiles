# 学术研究写作助手

这项技能能够帮助创建符合学术规范的高质量研究文档，包含经过验证的同行评审来源和IEEE格式的引用。

## 核心原则

1. **学术严谨性**：遵循学术写作规范，保持客观性
2. **来源验证**：仅使用同行评审的可靠学术来源
3. **规范引用**：生成准确的IEEE格式参考文献
4. **研究诚信**：确保所有论点都有经过验证的来源支持

## 工作流程

### 1. 理解需求

明确研究文档类型和需求：

- 文档类型（研究论文、文献综述、论文章节等）
- 研究主题和范围
- 目标篇幅
- 具体指南（机构、期刊、会议）
- 需要的章节
- 截止日期考虑

### 2. 研究规划

制定研究策略：

- 确定关键研究问题
- 定义搜索关键词
- 确定相关学术数据库（Google Scholar、IEEE Xplore、PubMed、ACM 数字图书馆、ScienceDirect）
- 建立来源的纳入/排除标准
- 规划文档结构

### 3. 来源发现与验证

**查找来源：**

使用 `web_search` 从以下来源查找同行评审的资料：
- Google Scholar (scholar.google.com)
- IEEE Xplore (ieeexplore.ieee.org)
- PubMed (pubmed.ncbi.nlm.nih.gov)
- ACM Digital Library (dl.acm.org)
- arXiv (arxiv.org) - 用于相关领域的预印本
- 特定领域的数据库

**搜索策略：**
- 从宽泛的搜索开始："机器学习医疗保健"
- 使用具体术语进行细化："深度学习医学诊断 2023"
- 使用引号搜索精确短语："卷积神经网络"
- 策略性地组合术语
- 搜索最近发表的文献（除非需要历史背景，否则为过去 5-7 年）

**验证清单：**

对每个来源进行验证：
- [ ] 发表在同行评审的期刊或会议上
- [ ] 作者资质和机构隶属关系
- [ ] 发表场所声誉
- [ ] 引用次数（越高表示影响力越大）
- [ ] 研究方法合理性
- [ ] 与研究问题的相关性

**警示信号：**
- 掠夺性期刊（检查 journalquality.info 或 beallslist）
- 缺乏同行评审过程
- 无机构隶属关系
- 可疑的发表行为
- 无合法评审的付费发表

### 4. 文档结构

按照标准学术结构创建文档：

**研究论文：**
1. 标题
2. 摘要（150-250 字）
3. 关键词（5-7 个术语）
4. 引言
   - 背景和上下文
   - 问题陈述
   - 研究目标
   - 贡献声明
   - 论文组织
5. 文献综述/相关工作
   - 理论框架
   - 先前研究综述
   - 研究差距识别
6. 方法论（如适用）
   - 研究设计
   - 数据收集
   - 分析方法
7. 结果/发现
8. 讨论
   - 解释
   - 意义
   - 限制
9. 结论
   - 发现总结
   - 未来工作
10. 参考文献（IEEE 格式）

**文献综述：**
1. 标题
2. 摘要
3. 引言
4. 审阅方法
5. 主题部分（按主题/领域组织）
6. 讨论和综合
7. 结论
8. 参考文献

### 5. 写作指南

**学术语气：**
- 使用正式、客观的语言
- 使用第三人称（除非方法学上合适，否则避免使用 "我" 或 "我们"）
- 使用精确的技术术语
- 保持中立立场（呈现多种观点）
- 适当使用限定性语言（"表明"、"显示"、"可能"）

**段落结构：**
- 主题句
- 带有引用的支撑证据
- 分析和解释
- 过渡到下一点

**引用整合：**
- 带有上下文引入来源
- 使用信号短语（"根据 Smith 等人 [1]..."、"Jones 的研究 [2] 表明..."）
- 平衡直接引用（谨慎使用）与释义
- 对每个来自外部来源的事实声明进行引用
- 使用方括号中的引用编号 [1], [2], [3]

**避免：**
- 抄袭（始终释义并引用）
- 不支持的主张
- 休闲或口语化语言
- 无证据的个人观点
- 过度引用
- 维基百科或非学术来源

### 6. IEEE 参考文献格式

按照以下模式生成 IEEE 格式的参考文献：

**期刊文章：**
```
[1] A. 作者, B. 作者, 和 C. 作者, "文章标题," 期刊名称, vol. X, no. Y, pp. ZZ-ZZ, 月份 年份.
```

**会议论文：**
```
[2] A. 作者 和 B. 作者, "论文标题," 在 会议名称 会议中, 城市, 国家, 年份, pp. ZZ-ZZ.
```

**书籍：**
```
[3] A. 作者, 书名, 版本. 城市, 州: 出版社, 年份.
```

**书籍章节：**
```
[4] A. 作者, "章节标题," 在 书名 中, 版本, 编者. 城市, 州: 出版社, 年份, pp. ZZ-ZZ.
```

**网站/在线：**
```
[5] A. 作者. "网页标题." 网站名称. URL (访问 月份 日, 年份).
```

**技术报告：**
```
[6] A. 作者, "标题," 机构, 城市, 州, 报告编号, 月份 年份.
```

**论文/学位论文：**
```
[7] A. 作者, "标题," 博士论文, 部门缩写, 大学, 城市, 州, 年份.
```

**专利：**
```
[8] A. 发明人, "标题," 国家专利号, 月份 日, 年份.
```

**标准：**
```
[9] 标准标题, 标准号, 年份.
```

**关键 IEEE 规则：**
- 按出现顺序连续编号参考文献
- 使用方括号 [1], [2], [3]
- 多位作者：≤6 位全部列出；>6 位使用 "et al."
- 使用首字母缩写名
- 按照IEEE标准缩写期刊名称
- 如有可用，包含 DOI
- 保持格式一致

### 7. 质量保证

最终确定前验证：

**内容：**
- [ ] 清晰的研究问题/目标
- [ ] 逻辑流程和组织
- [ ] 充足的来源覆盖（研究论文至少 15-20 个）
- [ ] 所有来源验证为同行评审
- [ ] 论点有引用支持
- [ ] 方法论清晰解释（如适用）
- [ ] 结果/发现清晰呈现
- [ ] 承认限制

**技术：**
- [ ] IEEE 参考文献格式正确
- [ ] 所有文内引用与参考文献列表匹配
- [ ] 无缺失参考文献
- [ ] 引用编号一致
- [ ] 图表标题和编号正确

**写作质量：**
- [ ] 保持学术语气
- [ ] 清晰简洁的语言
- [ ] 无语法错误
- [ ] 段落间过渡流畅
- [ ] 摘要准确总结论文

## 实施方法

创建学术文档时：

1. 大量使用 `web_search` 查找同行评审来源
2. 验证每个来源的学术可信度
3. 提取相关信息并综合发现
4. 使用正式学术风格写作
5. 自然地整合引用
6. 生成完整的 IEEE 参考文献列表
7. 使用适当工具（docx、pdf 或 markdown）创建文档

## 输出格式

创建文档为：
- **DOCX**：用于完整研究论文、论文、学位论文（使用 docx 技能）
- **PDF**：用于最终提交版本（使用 pdf 技能）
- **Markdown**：用于草稿、文献综述或在线发布

## 注意事项

- 始终优先考虑来源质量而非数量
- 优先使用最近 5-7 年的来源（除非需要历史背景）
- 全程保持研究诚信
- 对来源有疑问时，搜索额外验证
- 使用 `web_fetch` 访问完整文章（如可用）
