# 从仓库结构创建 LLMs.txt 文件

在仓库根目录下，根据 https://llmstxt.org/ 的官方 llms.txt 规范，从零开始创建一个新的 `llms.txt` 文件。该文件为大型语言模型 (LLMs) 提供高级指导，告知它们在哪里可以找到相关内容以理解仓库的目的和规范。

## 主要指令

创建一个全面的 `llms.txt` 文件，作为 LLMs 理解和有效导航仓库的入口点。该文件必须符合 llms.txt 规范，并针对 LLM 消费进行优化，同时保持人类可读性。

## 分析和规划阶段

在创建 `llms.txt` 文件之前，必须完成彻底的分析：

### 第 1 步：审查 llms.txt 规范

- 审查 https://llmstxt.org/ 的官方规范，确保完全符合
- 理解所需的格式结构和指南
- 记录特定的 markdown 结构要求

### 第 2 步：仓库结构分析

- 使用适当工具检查完整的仓库结构
- 确定仓库的主要目的和范围
- 目录所有重要目录及其目的
- 列出对 LLM 理解有价值的关键文件

### 第 3 步：内容发现

- 确定 README 文件及其位置
- 查找文档文件（`/docs/`、`/spec/` 等目录中的 `.md` 文件）
- 定位规范文件及其目的
- 发现配置文件及其相关性
- 查找示例文件和代码示例
- 确定任何现有的文档结构

### 第 4 步：创建实施计划

根据您的分析，创建一个结构化的计划，包括：

- 仓库目的和范围摘要
- 按重要性排序的 LLM 理解的关键文件列表
- 提供附加上下文的次要文件
- llms.txt 文件的组织结构

## 实施要求

### 格式合规

`llms.txt` 文件必须按照规范严格遵循以下结构：

1. **H1 标题**：单行包含仓库/项目名称（必需）
2. **Blockquote 摘要**：块引用格式的简短描述（可选但推荐）
3. **附加详情**：零个或多个无标题的 markdown 部分用于提供上下文
4. **文件列表部分**：零个或多个包含 markdown 链接列表的 H2 部分

### 内容要求

#### 必要元素

- **项目名称**：作为 H1 的清晰、描述性标题
- **摘要**：解释仓库目的的简洁块引用
- **关键文件**：按类别组织的必要文件（H2 部分）

#### 文件链接格式

每个文件链接必须遵循：`[描述性名称](相对路径)：可选描述`

#### 部分组织

将文件组织成逻辑 H2 部分，例如：

- **文档**：核心文档文件
- **规范**：技术规范和要求
- **示例**：示例代码和使用示例
- **配置**：设置和配置文件
- **可选**：次要文件（特殊含义 - 可为更简短的上下文跳过）

### 内容指南

#### 语言和风格

- 使用简洁、清晰、无歧义的语言
- 避免无解释的术语
- 为人类和 LLM 读者编写
- 在描述中保持具体和有信息量

#### 文件选择标准

包含以下文件：

- 解释仓库的目的和范围
- 提供必要的技术文档
- 展示使用示例和模式
- 定义接口和规范
- 包含配置和设置说明

排除以下文件：

- 仅为实现细节的文件
- 包含冗余信息的文件
- 构建工件或生成内容
- 与理解项目无关的文件

## 执行步骤

### 第 1 步：仓库分析

1. 完全检查仓库结构
2. 阅读主 README.md 以理解项目
3. 确定所有文档目录和文件
4. 目录规范文件及其目的
5. 查找示例文件和配置文件

### 第 2 步：内容规划

1. 确定主要目的声明
2. 为块引用编写简洁摘要
3. 将已识别的文件分组为逻辑类别
4. 按重要性为 LLM 理解优先排序文件
5. 为每个文件链接创建描述

### 第 3 步：文件创建

1. 在仓库根目录创建 `llms.txt` 文件
2. 遵循精确的格式规范
3. 包含所有必需部分
4. 使用正确的 markdown 格式
5. 确保所有链接是有效的相对路径

### 第 4 步：验证

1. 验证符合 https://llmstxt.org/ 规范
2. 检查所有链接是否有效且可访问
3. 确保文件作为有效的 LLM 导航工具
4. 确认文件既人类可读又机器可读

## 质量保证

### 格式验证

- ✅ H1 标题包含项目名称
- ✅ 块引用摘要（如果包含）
- ✅ 用于文件列表的 H2 部分
- ✅ 正确的 markdown 链接格式
- ✅ 无损坏或无效链接
- ✅ 全程格式一致

### 内容验证

- ✅ 清晰、无歧义的语言
- ✅ 全面覆盖必要文件
- ✅ 内容逻辑组织
- ✅ 适当的文件描述
- ✅ 作为有效的 LLM 导航工具

### 规范合规

- ✅ 精确遵循 https://llmstxt.org/ 格式
- ✅ 使用所需的 markdown 结构
- ✅ 适当实施可选部分
- ✅ 文件位于仓库根目录（`/llms.txt`）

## 成功标准

创建的 `llms.txt` 文件应：

1. 使 LLMs 能够快速理解仓库的目的
2. 提供清晰的文档导航
3. 精确遵循官方 llms.txt 规范
4. 全面且简洁
5. 有效服务于人类和机器读者
6. 包含理解项目所有关键文件
7. 全程使用清晰、无歧义的语言
8. 逻辑组织内容以便轻松消费
