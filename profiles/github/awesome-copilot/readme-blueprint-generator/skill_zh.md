# README 生成提示

通过分析 .github/copilot 目录中的文档文件和 copilot-instructions.md 文件，生成此存储库的全面 README.md。请按照以下步骤操作：

1. 扫描 .github/copilot 文件夹中的所有文件，例如：
   - 架构
   - 代码示例
   - 编码规范
   - 项目文件夹结构
   - 技术栈
   - 单元测试
   - 工作流分析

2. 同时审查 .github 文件夹中的 copilot-instructions.md 文件

3. 创建一个包含以下部分的 README.md：

## 项目名称和描述
- 从文档中提取项目名称和主要目的
- 包含对项目功能的简洁描述

## 技术栈
- 列出使用的主要技术、语言和框架
- 在有版本信息时包含版本信息
- 主要从 Technology_Stack 文件中获取此信息

## 项目架构
- 提供架构的概述
- 如果文档中有描述，考虑包含简单的图表
- 从 Architecture 文件中获取信息

## 入门指南
- 根据技术栈包含安装说明
- 添加设置和配置步骤
- 包含任何先决条件

## 项目结构
- 简要概述文件夹组织
- 从 Project_Folder_Structure 文件中获取信息

## 主要功能
- 列出项目的主要功能和特性
- 从各种文档文件中提取信息

## 开发工作流
- 总结开发过程
- 如果有分支策略信息，则包含分支策略信息
- 从 Workflow_Analysis 文件中获取信息

## 编码规范
- 总结关键的编码规范和约定
- 从 Coding_Standards 文件中获取信息

## 测试
- 解释测试方法和工具
- 从 Unit_Tests 文件中获取信息

## 贡献
- 贡献项目的指南
- 参考任何代码示例以获取指导
- 从 Code_Exemplars 和 copilot-instructions 中获取信息

## 许可证
- 如果有可用，则包含许可证信息

使用 Markdown 正确格式化 README，包括：
- 清晰的标题和副标题
- 在适当的地方使用代码块
- 使用列表提高可读性
- 链接到其他文档文件
- 如果信息可用，则包含构建状态、版本等徽章

保持 README 简洁且信息丰富，专注于新开发人员或用户需要了解的项目信息。
