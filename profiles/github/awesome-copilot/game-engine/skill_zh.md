# 游戏引擎技能

使用 HTML5 Canvas、WebGL 和 JavaScript 构建基于 Web 的游戏和游戏引擎。这项技能包括入门模板、参考文档以及使用 Phaser、Three.js、Babylon.js 和 A-Frame 等框架进行 2D 和 3D 游戏开发的分步工作流程。

## 使用此技能的场景

- 使用 Web 技术从零开始构建游戏引擎或游戏
- 实现游戏循环、物理效果、碰撞检测或渲染
- 使用 HTML5 Canvas、WebGL 或 SVG 进行游戏图形
- 添加游戏控制（键盘、鼠标、触摸、游戏手柄）
- 创建 2D 平台游戏、打砖块式游戏、迷宫游戏或 3D 体验
- 使用瓦片地图、精灵或动画
- 为 Web 游戏添加音频
- 使用 WebRTC 或 WebSockets 实现多人功能
- 优化游戏性能
- 发布和分发 Web 游戏

## 前置条件

- 掌握 HTML、CSS 和 JavaScript 的基础知识
- 使用支持 Canvas/WebGL 的现代 Web 浏览器
- 文本编辑器或 IDE
- 可选：Node.js 用于构建工具和本地开发服务器

## 核心概念

以下概念构成了每个基于 Web 的游戏引擎的基础。

### 游戏循环

每个游戏引擎都围绕游戏循环旋转——这是一个连续的循环，包括：

1. **处理输入** - 读取键盘、鼠标、触摸或游戏手柄输入
2. **更新状态** - 更新游戏对象的位置、物理效果、人工智能和逻辑
3. **渲染** - 将当前游戏状态绘制到屏幕上

使用 `requestAnimationFrame` 实现平滑、浏览器优化的渲染。

### 渲染

- **Canvas 2D** - 适用于 2D 游戏、基于精灵的渲染和瓦片地图
- **WebGL** - 硬件加速的 3D 和高级 2D 渲染
- **SVG** - 基于矢量的图形，适用于 UI 元素
- **CSS** - 适用于基于 DOM 的游戏元素和过渡效果

### 物理和碰撞检测

- **2D 碰撞检测** - AABB、圆形和基于 SAT 的碰撞检测
- **3D 碰撞检测** - 边界框、边界球和射线投射
- **速度和加速度** - 基本的牛顿物理效果用于移动
- **重力** - 平台游戏中的恒定向下加速度

### 控制

- **键盘** - 箭头键、WASD 和自定义按键绑定
- **鼠标** - 点击、移动和指针锁定，用于 FPS 风格的控制
- **触摸** - 移动设备的触摸事件和虚拟摇杆
- **游戏手柄** - 游戏手柄 API 用于控制器支持

### 音频

- **Web 音频 API** - 程序化声音生成和空间音频
- **HTML5 音频** - 简单的音频播放，用于音乐和音效

## 分步工作流程

### 创建基本的 2D 游戏

1. 设置一个包含 `<canvas>` 元素的 HTML 文件
2. 获取 2D 渲染上下文
3. 使用 `requestAnimationFrame` 实现游戏循环
4. 创建具有位置、速度和大小属性的游戏对象
5. 处理键盘/鼠标输入以实现玩家控制
6. 实现游戏对象之间的碰撞检测
7. 添加得分、生命值和胜负条件
8. 添加音效和音乐

### 构建 3D 游戏

1. 选择一个框架（Three.js、Babylon.js、A-Frame 或 PlayCanvas）
2. 设置场景、相机和渲染器
3. 加载或创建 3D 模型和纹理
4. 实现光照和着色器
5. 添加物理效果和碰撞检测
6. 实现玩家控制和相机移动
7. 添加音频和视觉特效

### 发布游戏

1. 优化资源（压缩图像、压缩代码）
2. 跨浏览器和设备测试
3. 选择分发平台（Web、应用商店、游戏门户）
4. 如有必要，实现变现功能
5. 通过游戏社区和社交媒体进行推广

## 故障排除

| 问题 | 解决方案 |
|------|------|
| Canvas 为空 | 确保在获取上下文后并在游戏循环内调用绘图方法 |
| 游戏运行速度不同 | 在更新计算中使用时间差而不是固定值 |
| 碰撞检测不一致 | 使用连续碰撞检测或减少快速移动对象的步长 |
| 音频无法播放 | 浏览器需要用户交互才能播放音频；从点击处理程序触发播放 |
| 性能差 | 使用浏览器开发者工具进行性能分析，减少绘图调用，使用对象池，优化资源大小 |
| 触摸控制无响应 | 阻止默认触摸行为，并将触摸事件与鼠标事件分开处理 |
| WebGL 上下文丢失 | 处理 `webglcontextlost` 事件并在 `webglcontextrestored` 时恢复状态 |
