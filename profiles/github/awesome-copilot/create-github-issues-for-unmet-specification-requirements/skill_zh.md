# 为未满足的规范要求创建 GitHub 问题

为 `${file}` 中的规范中未实现的要求创建 GitHub 问题。

## 流程

1. 分析规范文件以提取所有要求
2. 检查代码库中每个要求的实现状态
3. 使用 `search_issues` 搜索现有问题以避免重复
4. 使用 `create_issue` 为每个未实现的要求创建新问题
5. 使用 `feature_request.yml` 模板（若无则使用默认模板）

## 要求

- 规范中每个未实现的要求创建一个单独的问题
- 清晰的要求 ID 和描述映射
- 包含实现指南和验收标准
- 创建前验证现有问题

## 问题内容

- 标题：要求 ID 和简要描述
- 描述：详细的要求、实现方法和上下文
- 标签：feature、enhancement（根据情况使用）

## 实现检查

- 在代码库中搜索相关的代码模式
- 检查 `/spec/` 目录中的相关规范文件
- 验证要求是否未部分实现
