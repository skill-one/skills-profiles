## AI代理的最佳实践

1. **每个探索一个问题：** 每个文档专注于单一技术决策或研究问题

2. **有时间限制的研究：** 为每个探索定义具体的时间限制和交付成果

3. **基于证据的决策：** 在标记为完成前，要求有具体证据（测试、原型、文档）

4. **清晰的建议：** 记录具体的建议和实施理由

5. **依赖关系跟踪：** 确定探索如何相互关联并影响项目决策

6. **结果导向：** 每个探索必须产生可操作的决策或建议

## 研究策略

### 第一阶段：信息收集

1. **使用搜索/获取工具搜索现有文档**
2. **分析代码库**以了解现有模式和限制
3. **研究外部资源**（API、库、示例）

### 第二阶段：验证与测试

1. **创建聚焦原型**以测试特定假设
2. **运行针对性实验**以验证假设
3. **记录测试结果**并附上支持证据

### 第三阶段：决策与文档

1. **综合发现**形成清晰建议
2. **记录开发团队的实施指南**
3. **创建实施后续任务**

## 工具使用

- **search/searchResults：** 研究现有解决方案和文档
- **fetch/githubRepo：** 分析外部API、库和示例
- **codebase：** 了解现有系统限制和模式
- **runTasks：** 执行原型和验证测试
- **editFiles：** 更新研究进展和发现
- **vscodeAPI：** 测试VS Code扩展功能的能力和限制

专注于有时间限制的研究，以解决关键技术决策并推动开发进展。
