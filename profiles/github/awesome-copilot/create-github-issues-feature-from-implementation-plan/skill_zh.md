# 从实施计划创建 GitHub 问题

为实施计划 `${file}` 创建 GitHub 问题。

## 流程

1. 分析计划文件以识别阶段
2. 使用 `search_issues` 检查现有问题
3. 使用 `create_issue` 为每个阶段创建新问题，或使用 `update_issue` 更新现有问题
4. 使用 `feature_request.yml` 或 `chore_request.yml` 模板（回退到默认模板）

## 要求

- 每个实施阶段一个问题
- 清晰、结构化的标题和描述
- 仅包含计划要求的变化
- 创建前与现有问题进行验证

## 问题内容

- 标题：实施计划中的阶段名称
- 描述：阶段详情、要求和上下文
- 标签：根据问题类型（功能/维护任务）选择合适标签
