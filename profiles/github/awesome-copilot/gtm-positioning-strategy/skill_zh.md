# 定位策略

找到并占据一个有利的、可防御的市场位置。将泛化信息转化为明确的差异化——或者至少在承诺之前测试你的差异化是否真的能引起共鸣。

## 使用时机

**触发因素：**
- "我们的信息听起来和竞争对手一模一样"
- "品牌知名度高但转化率低"
- "销售团队无法解释我们的不同之处"
- "买家认为我们是可互换的"
- "在重新品牌化之前我们应该重新定位吗？"
- "我们如何测试定位声明？"

**背景：**
- 提供相似产品的竞争激烈市场
- 信息转化效果不佳
- 新产品发布
- 重新定位现有产品
- 销售团队报告买家困惑

---

## 核心框架

### 1. 一个词可以改变一切（“自主”问题）

**模式：**

自主AI产品的早期企业对话。定位为“自主AI代理”。

开发者：“很酷，但很吓人。”
管理者：“这会取代我们的团队吗？”
交易进展：缓慢。有很多“我们会考虑的。”

**改变：**

一个词：“自主”→“AI队友”

相同的产品。相同的功能。不同的框架。

**结果：**

开发者：“这对我有帮助。”
管理者：“这让我的团队更有效率。”
交易进展：明显更快。

**为什么这很重要：**

定位不是你做什么，而是你**不做什么**。

我们本可以说“取代开发者”（对某些任务来说技术上是真的）。这会扼杀所有企业交易。

**框架：词语选择塑造买家心理**

**让企业感到恐惧的词语：**
- 自主（暗示：失去控制，取代人类）
- 取代（威胁：工作安全）
- 完全自动化（移除：人类判断）
- AI优先（意味着：不明确，术语）

**能转化的词语：**
- 队友（暗示：合作，帮助）
- 增强（帮助：让人类变得更好）
- 你保持控制（安抚：人类监督）
- 处理重复性工作（具体：节省时间）

**如何测试词语选择：**

不要猜测。去测试。

**测试1：外发邮件A/B**
- 向100个潜在客户发送版本A（“自主代理”）
- 向100个潜在客户发送版本B（“AI队友”）
- 衡量：回复率，预约会议率
- 信号强度：高（真实的买家意向）

**测试2：网站首页A/B**
- 版本A：当前定位
- 版本B：新的词语选择
- 衡量：关键CTA的点击率
- 持续时间：至少1-2周
- 信号强度：中等（兴趣但没有承诺）

**测试3：销售电话脚本**
- 一半的AE使用定位A
- 一半使用定位B
- 衡量：演示到试用转化率
- 信号强度：高（真实的销售周期）

**常见错误：**

基于内部共识而不是客户反馈来改变定位。你的团队不是买家。

### 2. 在承诺之前测试（定位逐步推出）

**模式：**

定位变化会带来风险。品牌混淆。销售错位。客户流失（如果现有客户不认识你）。

**通过分阶段推出来降低风险：**

**爬行阶段（1-2周）：验证**

在不投入产品/组织资源的情况下测试信息。

**行动：**
- A/B测试网站标题（新与现有）
- 运行两个外发邮件序列（不同的定位角度）给冷潜在客户
- 向现有客户询问：“如果我们描述自己为[新定位]，你们还会认出我们吗？”

**衡量：**
- 跟踪网页变体的CTR
- 跟踪外发邮件序列的回复率
- 记录定性反馈

**Go/No-Go：**
- 至少有一个定位变体在回复率上比现有版本高20%+
- 现有客户不会说“等等，这不是你们做的事”
- 如果有明显的赢家，则继续；如果平局，则运行更长时间或测试新角度

**行走阶段（2-3周）：对齐**

如果测试验证，则对齐产品和销售到新的定位（但不要公开重新品牌化）。

**行动：**
- 重写网站文案（首页，企业页面，CTA）
- 创建销售赋能：更新的演示文稿，电话脚本，邮件模板
- 更新文档以匹配新的叙述
- 构建特定用例的示例

**衡量：**
- 销售团队对信息可用性的反馈
- 网站分析中的参与度（尚未转化）
- 段落分析（谁在回应？）

**Go/No-Go：**
- 销售团队说新信息更容易使用
- CTR指标优于现有版本
- 没有主要客户混淆
- 继续到运行

**运行阶段（2-3周和持续）：扩展**

全力投入。这是重新品牌化。

**行动：**
- 为每个用例启动专门的着陆页
- 按定位角度进行外发活动
- 更新所有面向客户的材料
- 训练客户成功团队关于新的叙述
- 宣布重新定位（如果合适）

**衡量：**
- 按定位角度的管道量
- 按定位角度的获胜率
- 按渠道的CAC效率
- 客户保留率（我们失去任何人吗？）

**常见错误：**
- 跳过爬行（在没有验证的情况下跳到完整重新品牌化）
- 并行运行阶段（如果在推出过程中更改信息，会造成混淆）
- 在重新定位之前等待完美产品（产品应该跟随定位，而不是先于定位）
- 在每个阶段都不进行衡量（无法确定测试是否“获胜”）

### 3. 定位清晰度诊断

**模式：**

如果你的信息与竞争对手的信息非常相似，那么你有一个定位问题，而不是产品问题。

**定位失败表现为：**
- 所有竞争对手都描述几乎相同的价值主张
- 差异化需要解释复杂的技术细节
- 买家认为产品是可互换的
- 营销指标（CTR，参与度）弱于行业基准
- 销售对话因比较问题而偏离轨道

**如何执行：**

**步骤1：竞争对手信息审核**
- 收集5-7个直接竞争对手的首页标题
- 确定共同声明（这些是标准化的）
- 绘制竞争对手在哪里声称独特价值

**示例：**

如果每个人都说是“最快”，“最可靠”，“最容易使用”——这些是基本要求，而不是差异化。

**步骤2：评估你的实际优势**
- 你能做而竞争对手不能做，而无需大量研发？
- 你的最佳客户为什么选择你？（问他们）
- 你有什么结构性优势？（部署模式，数据所有权，定价，网络效应等）

**步骤3：找到未满足的定位**
- 现有解决方案在哪里让用户失望？
- 大家都在忽略什么问题？
- 哪个买家群体未被服务？

**步骤4：提出明确的声明**

必须：
- 现在你能够拥有的东西（不是未来路线图）
- 竞争对手无法轻易复制的东西（结构性优势）
- 与你的最佳客户群体产生共鸣

**常见错误：**
- 声称你在每个人都在做的事情方面“更好”（不可信）
- 定位在竞争对手已经拥有的功能上
- 同时定位多个位置（选择一个）
- 在重新定位之前等待完美产品

### 4. 市场定位架构（三层）

**第一层：市场背景**
- 市场正在经历什么问题？
- 为什么现在会出现这个问题？
- 如果问题得不到解决会发生什么？

**示例：**
“基础设施团队在混合环境中管理日益复杂的部署。组织采用微服务和分布式系统。这创造了传统监控工具无法处理的操作复杂性。”

**第二层：定位声明（1-2句话）**
- **我们服务谁**：什么客户群体？
- **我们解决的问题**：具体痛点
- **我们的不同之处**：为什么我们比替代方案更重要
- **证据**：为什么他们应该相信我们？

**示例：**
“我们通过[核心能力]帮助平台团队更快地交付，将[工作流A]，[工作流B]和[业务成果]实时连接起来。”

**第三层：叙述**

将定位扩展为故事：
- 为什么世界正在变化
- 为什么现有解决方案不起作用
- 为什么我们的方法更好
- 使用我们的未来会是什么样子

**如何执行：**

在测试之前写出所有三层。首先用爬行-行走-运行方法测试第二层（定位声明）。如果验证通过，则构建第三层。

---

### 5. 标题和副标题测试

**原则**：清晰的定位需要可测试的结构：标题（你是谁？）+ 副标题（为谁？为什么？）。

**主要标题格式：**
- "可定制的[形容词][类别]，[差异化]"
- "[产品]用于[特定用例]"
- "[产品]，[核心利益]"

**示例：**
- "可定制的平台用于[工作流]"
- "自主团队的基础设施"
- "企业级[现有产品]替代品"

**警告标志：**
- 使用竞争对手名称（防御性，不是自信）
- 太技术化（买家不会理解）
- 声称多个利益（选择一个）
- 模糊不清（“X的未来”——不可信）

**副标题目的：**

澄清谁，为什么，与现状有何不同。

**示例：**
- "随时随地部署。即时扩展。您的基础设施，您的规则。"
- "对于被重复性工作淹没的团队。自动化处理80%，人类处理20%。"
- "企业级。无锁定。与您的现有堆栈兼容。"

**如何测试：**

A/B测试标题+副标题组合：
- 变体A：当前信息
- 变体B：新的定位角度
- 变体C：不同的差异化声明

衡量CTR，回复率，转化率。

基于数据选择赢家，而不是意见。

### 6. 定位防御性评估

**原则**：定位只有在其竞争对手无法轻易复制时才有价值。

**防御性等级：**

**1. 结构性优势（最强）**
- 难以复制：独特数据所有权，部署灵活性，定价模式，网络效应
- 示例：“为监管行业构建，支持本地部署”（无法在不重建架构的情况下复制）

**2. 市场位置（如果第一个最强）**
- 如果您首先拥有并扩展，则可以防御
- 示例：“第一个用于[特定工作流]的AI平台”（抄袭者看起来是衍生的）

**3. 产品功能（最弱）**
- 容易复制：UX，特定功能
- 示例：“更快的API调用”（竞争对手在6周内推出速度改进）

**如何评估：**

对于每个定位声明，询问：

1. 竞争对手能否用单个产品冲刺复制这个？（是=不可防御）
2. 我们是否有结构性优势？（否=临时定位）
3. 考虑到当前产品，这是可信的吗？（否=现在不要声称它）
4. 我们能否在竞争对手反应之前拥有这个位置？（否=太慢）

**常见错误：**

定位在竞争对手可以轻易匹配的功能上。这会创建定位跑步机——你总是在防御，从未拥有。

## 决策树

### 我们是否应该重新定位？

```
品牌知名度高但转化率低吗？
├─ 是→定位问题，测试新角度
└─ 否→继续...
    │
    我们的信息听起来像竞争对手吗？
    ├─ 是→定位问题
    └─ 否→不是定位问题
```

### 我们应该测试哪个定位角度？

```
竞争对手能否轻易复制结构性优势？
├─ 是→定位在结构性优势上
└─ 否→继续...
    │
    我们在类别中是第一个吗？
    ├─ 是→定位在类别所有权上
    └─ 否→找到未服务的细分市场/用例
```

### 我们是否应该从爬行阶段过渡到行走阶段？

```
新定位是否在20%+上优于现有版本？
├─ 是→过渡到行走（对齐阶段）
└─ 否→继续...
    │
    我们是否运行了足够长的测试（2+周）？
    ├─ 否→运行更长时间
    └─ 是→尝试不同的定位角度或保持现有版本
```

## 常见错误

**1. 声称在每个人都在做的事情方面“更好”**
   - 不可信。找到不同的角度。

**2. 定位在容易复制的功能上**
   - 竞争对手会匹配。需要结构性优势。

**3. 在重新定位之前等待完美产品**
   - 产品工作应该跟随定位，而不是先于定位

**4. 同时测试太多定位角度**
   - 无法确定什么在起作用。一次测试一个。

**5. 跳过验证阶段**
   - 在没有测试的情况下跳到完整重新品牌化=风险

**6. 对所有买家角色使用一个定位**
   - 不同的角色关心不同的事情

**7. 没有差异化的通用定位**
   - “最佳类别”，“创新”=无意义

## 快速参考

**爬行-行走-运行测试：**
- 爬行（1-2周）：A/B测试信息，衡量回复率
- 行走（2-3周）：对齐销售/产品到赢家角度
- 运行（持续）：完整重新定位，衡量管道/转化

**能转化的词语：**
- ✅ 队友，增强，你保持控制
- ❌ 自主，取代，完全自动化

**定位审核步骤：**
1. 收集竞争对手信息
2. 识别你的实际优势（问客户）
3. 找到未服务的位置
4. 提出明确、可防御的声明

**防御性等级：**
1. 结构性优势（独特数据，部署灵活性，定价模式）
2. 市场位置（类别所有权）
3. 产品功能（最弱，容易复制）

**测试等级（信号强度）：**
1. 外发回复率（最高）
2. 销售电话转化率（高）
3. 网站CTR（中等）
