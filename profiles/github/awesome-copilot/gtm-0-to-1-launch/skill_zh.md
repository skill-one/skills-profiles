# 从0到1的启动

将新产品从想法推向首批客户。目标不是头条新闻——而是找到10位无法没有你的客户。

## 何时使用

**触发因素：**
- "我们如何推出这个产品？"
- "首批客户获取策略"
- "我们推出了但没人使用"
- "Product Hunt与直接触达？"
- "我们有认知但无转化"
- "我如何知道这是否有效？"

**背景：**
- 新产品发布
- 感觉像新产品的功能发布
- 寻找首批10-50位客户
- 验证产品-市场契合度
- 诊断早期增长停滞的原因

---

## 核心框架

### 1. 媒体曝光≠增长（一次获得12位注册用户的启动案例）

**模式：**

协调了一个功能发布，并进行了全面的媒体宣传。TechCrunch、VentureBeat、产品博客。大型发布日。

**结果：**
- 5万次曝光
- 12位注册用户
- 2位转化用户

**失败原因：**

优化了媒体热度，而非用户价值。该功能尚未准备好供自助使用。它需要教育、背景知识、手把手指导。媒体为你带来观众。但观众而无激活=虚荣指标。

**效果更好的做法：**

直接联系50位目标客户。"我们开发了[功能]，因为像你们这样的团队在[问题]上遇到困难。想要早期访问？" 亲自引导他们完成设置。获取反馈，迭代。

**结果：** 50封邮件 → 15位回复（30%回复率）→ 8位试用 → 4位转化（50%试用到付费转化率）。

**教训：**

早期客户来自直接触达，而非媒体曝光。媒体在后期很重要（A轮融资公告、重大里程碑）。对于0到1，它是分心因素。

### 2. 三层诊断（为什么启动停滞）

**模式：**

你发布了产品。你有一些认知度。但转化率很弱。问题存在于三个层次中的某一个，每个层次都需要不同的干预措施。

**第一层：定位问题**

症状：
- 消息听起来像竞争对手
- 差异化需要解释复杂的技术细节
- 购买者认为你与替代品可以互换
- 销售对话因比较问题而偏离主题

诊断：你是在"在错误的战场上进行非对称战争"——与资金更雄厚的公司竞争功能。绘制竞争对手声称独特价值的领域。找到他们难以轻易复制的定位。

修复：建立一个你可以结构化拥有的主张（而不仅仅是通过产品功能）。在投入产品资源之前，通过外联消息进行测试。

**第二层：体验问题**

症状：
- 强大的认知度但弱激活
- 用户注册但未完成第一个工作流程
- 多个入口点导致决策瘫痪
- 文档是功能导向的，而非结果导向的

诊断：灵活性而缺乏明确默认值是一种负债，而非功能。用户面临"选择悖论"——太多选项，没有足够的指导来达到"啊哈时刻"。

修复：确定2-3个"不可动摇的使用案例"，这些案例能立即提供价值。将引导限制为这些特定的使用案例。将高级功能作为掌握路径进行设置。围绕"待完成的工作"重写帮助内容，而不是功能列表。

**第三层：对齐问题**

症状：
- 团队报告"没有带宽"来服务客户
- 不同部门优化不同的指标
- 每个想法都有相等的权重（没有裁决标准）
- 没有明确的北极星将活动与结果联系起来

诊断："探索模式"——每个倡议都有相等的优先级——在资源受限时会变得具有破坏性。

修复：定义一个单一的共享北极星。将其用作每个决策的裁决标准："这有助于我们赢得客户吗？" 删除那些不能逐步提升的活动。每周而不是每季度使进展可见。

**如何使用这个框架：**

当启动停滞时，在投入资源之前诊断哪个层次出了问题。在定位问题上是修复体验浪费工程时间。在定位问题上修复对齐问题浪费营销支出。

### 3. 首批10位客户框架

**原则：** 首批10位客户不是为了收入，而是为了学习。

**你在学习什么：**
1. 产品是否真的解决了问题？
2. 激活流程是什么？（他们如何获得价值？）
3. 出现哪些反对意见？（价格、功能、集成？）
4. 真正的购买者是谁？（头衔、角色、预算授权？）
5. 销售周期是什么？（天、周、月？）

**如何找到他们：**

**渠道1：个人网络（前2-3位）**
- "我正在构建[X]，我可以获得你的反馈吗？"
- 转化为付费客户（不要免费提供——免费用户会给出不同的反馈）

**渠道2：直接触达（客户3-20位）**
- 建立100个目标账户的列表
- 针对他们的具体痛点进行个性化
- 测试消息变体——哪个角度能获得回复？

**渠道3：天花板时刻目标定位（最高意向）**
- 最高意向的潜在客户是那些已经采用了可比较的解决方案并达到其上限的人
- 他们已经投资于学习一个工具，达到其上限，并且转换成本低
- 围绕限制进行触达："我们看到团队在需要[能力]时超出[现有解决方案]的范围。这就是我们构建的。"
- 这些比冷触达转化率高3-5倍，因为他们已经理解了问题

**渠道4：社区（开发者产品）**
- "构建[X]来解决[问题]，寻找早期用户"
- 提供白手套引导
- 适用于用户聚集在Slack/Discord/论坛的产品

### 4. 2周实验周期

**模式：**

早期阶段的速度比完美更重要。限制不是你是否正确——而是你如何快速测试假设并迭代。

**如何执行：**

- 在开始之前，用明确的成功标准来定义每个测试
- 每个实验测试一个变量（消息、渠道、定价、功能）
- 最多运行2周——如果到那时没有显示出信号，就不会有
- 如果它有效，一周内分配3倍资源
- 如果无效，放弃并转移到下一个测试
- 无论结果如何，都要记录你学到的知识

**操作手册规则：**

每个成功的实验在扩展之前都必须成为操作手册。结构：目标 → 步骤 → 预期输出 → 指标 → 风险。如果陌生人无法执行操作手册，它就没有被记录好。

**为什么这很重要：**

单次的胜利不会复合。系统化的实验会。目标不是单个启动——而是构建一个可重复的机器来快速测试假设。

**常见错误：**

在测试前过度规划。等待"完美"的条件再启动。因为已经投入了情感能量而与失败实验停留太长时间。用70%的信息做决策。

### 5. 合作主导的市场进入（当你没有分销渠道时）

**模式：**

而不是通过直接销售进入新市场，使用与成熟玩家的合作来加速。

**如何执行：**

1. 确定目标细分市场的市场领导者
2. 带着客户问题而不是合作建议接触——"如果您的用户可以访问[功能]？"从你的需求转移到他们的需求
3. 从小处着手：帮助他们解决一个特定的问题（狭窄集成，而不是全面合作）
4. 在要求更广泛的承诺之前，用3-6个月的试点证明价值
5. 一起建立参考客户——减少他们的风险
6. 利用他们的GTM：一旦集成，他们就会向他们的基础市场进行营销

**超级节点模式：**

将自己定位为其他工具自然连接的集成中心。你拥有其他平台需要的关键数据或工作流程。这会复合——每个新合作伙伴使你更有价值给下一个。

**类别顺序：**

不要在 everywhere 追求合作伙伴。每个季度主导2-3个类别：
1. 带着真实的用例领先："我们的用户每月询问[合作伙伴]集成50次"
2. 一旦与顶级玩家合作，竞争对手会感到紧迫与你合作
3. 在一个类别中成功建立2-3个合作伙伴后，创建联合客户故事

**常见错误：**

在明确的集成路径之前启动合作伙伴关系。期望合作伙伴在没有支持的情况下推动认知度。将合作伙伴关系视为销售渠道，而不是平台扩展。

### 6. PMF验证清单

**产品-市场契合度是指客户拉着你，而不是你推他们。**

**留存率：**
- [ ] 第1周用户中有40%+在第4周返回
- [ ] 使用率随时间增加
- [ ] 客户在没有销售推动的情况下续订

**自然增长：**
- [ ] 口碑推荐正在发生
- [ ] 客户询问"我可以添加我的团队吗？"
- [ ] 没有付费营销的传入兴趣

**销售速度：**
- [ ] 销售周期缩短
- [ ] 试用转化率>30%
- [ ] 客户说"我们需要这个"

**定性：**
- [ ] >40%的人如果产品消失会非常失望（Sean Ellis测试）
- [ ] 客户可以说明它的用途（明确的用例）
- [ ] 客户公开倡导

**如果你没有这些，你还没有PMF。不要扩展营销/销售。**

## 决策树

### 为什么我们的启动停滞？

```
潜在客户是否理解你在做什么？
├─ 否 → 第一层：定位问题
│         修复：在改变产品之前测试新消息
└─ 是 → 继续...
    │
    用户注册后是否激活？
    ├─ 否 → 第二层：体验问题
    │         修复：将引导限制为2-3个用例，引导到啊哈时刻
    └─ 是 → 继续...
        │
        团队是否对重要事项保持一致？
        ├─ 否 → 第三层：对齐问题
        │         修复：单一北极星，每周可见性，删除非必要
        └─ 是 → 继续迭代，你走在了正确的轨道上
```

### 媒体发布还是直接触达？

```
自助服务准备吗？（用户在10分钟内获得价值）
├─ 否 → 仅直接触达（媒体不会转化）
└─ 是 → 你是否有>100万美元的基金来宣布？
    ├─ 是 → 两者（媒体用于认知度，触达用于转化）
    └─ 否 → 首先进行直接触达，然后媒体
```

## 常见错误

**1. 优化头条新闻而不是激活**
5万次曝光和12位注册用户。媒体≠增长。

**2. 在发布前没有目标客户列表**
无差别攻击在0到1时不起作用。首先建立100个账户的列表。

**3. 灵活性而缺乏默认值**
给用户提供所有选项会让他们瘫痪。选择2-3个不可动摇的使用案例并硬引导。

**4. 免费提供产品**
免费用户会给出礼貌的反馈。付费用户会给出诚实的反馈。

**5. 在学习前扩展**
首批10位客户是为了学习，而不是收入。记录一切。

**6. 过度规划，测试不足**
2周实验，明确的终止标准。快速行动，记录学习成果。

**7. 诊断错误的层次**
在体验问题上修复定位问题=浪费营销。在定位问题上修复体验问题=浪费工程。

## 快速参考

**三层诊断：**
第一层：定位（消息听起来像竞争对手）→ 测试新消息
第二层：体验（认知度但无激活）→ 引导到啊哈时刻
第三层：对齐（团队分散）→ 单一北极星，每周可见性

**首批10位客户：**
个人网络（2-3）→ 直接触达（3-20）→ 天花板时刻目标定位（最高意向）→ 社区（开发者产品）

**2周实验周期：**
假设 → 成功标准 → 实验（最多2周）→ 终止或3倍 → 记录操作手册

**PMF信号：**
40%+ 第1周→4留存 + 口碑 + 销售周期缩短 + >40%非常失望

**合作主导进入：**
客户问题优先 → 狭窄试点 → 一起建立参考客户 → 利用他们的GTM
