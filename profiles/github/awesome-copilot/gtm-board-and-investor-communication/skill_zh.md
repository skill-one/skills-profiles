# 董事会和投资者沟通

构建能够建立信任并推动决策的董事会会议、投资者更新和高层沟通结构——而不是无人阅读的幻灯片。

## 使用场景

**触发因素：**
- "我该如何准备我们的董事会会议？"
- "我们的投资者更新应该包含什么内容？"
- "我们未达预期指标，该如何沟通？"
- "董事会幻灯片结构"
- "我们应该多久向投资者更新一次？"
- "我们的董事会会议效率低下"

**背景：**
- 种子轮到成长期公司
- 董事会会议准备和后续跟进
- 月度/季度投资者更新
- 处理未达标和坏消息
- 从董事会到组织的级联战略

---

## 核心框架

### 1. 先讲故事，再展示数据

**模式：**

大多数董事会会议都以数据倾泻开始。一页又一页的指标，然后10分钟的问答环节，董事会成员试图弄清楚这一切的含义。

反过来。叙事应该引导；数据应该证实。

**运作方式：**

从你的旅程中你所在的位置开始。不是“这是我们的ARR”，而是“这是我们在本季度开始前的信念、我们学到的知识以及我们现在所处的位置”。然后展示验证叙事的数据。

**董事会会议结构：**

**会前阅读材料（会议前48-72小时发送）**
- 财务仪表盘（ARR、烧钱率、续航能力、管道）
- 指标记分卡，包含健康状况指标（绿色/黄色/红色）
- 2-3页的叙事摘要，涵盖市场背景和战略更新
- 规则：如果可以阅读，就不要演示

**会议（90-120分钟）**

1. **市场背景和会前阅读材料的问题**（15分钟）
   - 自上次会议以来市场发生了哪些变化？
   - 董事会询问会前阅读材料中任何不清楚的地方
   - 不要重新展示数据

2. **CEO战略更新——“三件事”**（15分钟）
   - **哪些方面在起作用**（2-3个显示动力的领域）
   - **哪些方面没有起作用**（1-2个具体差距，而不是模糊的）
   - **我们正在如何解决这些问题**（具体变化，而不是承诺）
   - 这不是数据，而是叙事

3. **决策事项**（30-45分钟）
   - 1-3个需要董事会输入或批准的主题
   - 做好准备：“我们正在决定X和Y之间，董事会的意见？”
   - 带着决定离开，而不是“我们将在下个季度重新审视”

4. **深入探讨**（20-30分钟）
   - 深入探讨一个主题（每次会议轮流）
   - 带来负责该主题的职能负责人
   - 示例：定价策略、竞争格局、组织设计、市场扩张

5. **总结**（10分钟）
   - 总结做出的决定和行动负责人
   - 闭门会议（没有管理层）
   - CEO和董事会主席的简报

**常见错误：**

- 在叙事之前以数据开始（董事会在没有背景的情况下会在数字中迷失）
- 多个竞争的叙事（董事会无法综合——选择一个弧线）
- 试图深入讨论太多主题（导致在所有事情上都做出仓促的决定）
- 没有深入探讨（董事会变成了橡皮图章）
- 用好消息填满会议（董事会不信任只分享胜利的CEO）

### 2. “三件事”叙事模型

**模式：**

企业太复杂，无法用一条标题来总结。三个不同的点——哪些方面在起作用、哪些方面没有、哪些方面正在改变——让董事会几分钟内就能把握现状和轨迹。

**哪些方面在起作用（2-3个方面）：**
具体说明。不是“销售情况良好”，而是“达成了第一个六位数的企业交易，验证了商业动力。”量化动力：
- 新产品发布获得采用
- 销售动力成熟（第一个大客户，可重复的动因出现）
- 社区/生态系统里程碑

**哪些方面没有起作用（1-2个方面）：**
同样具体。不是“我们遇到了一些挑战”，而是“自助服务转化率较弱——强大的认知度但转化率为0.1%”。董事会需要了解实际问题，而不是委婉的说法。

**我们正在如何解决这些问题（针对每个“没有起作用”的方面）：**
阐明具体变化。哪些产品变化？哪些组织变化？时间表是什么？投入了哪些资源？

**为什么这有效：**

董事会成员阅读数十份更新。三件事模型为他们提供了一个心理文件系统：动力（感觉良好）、风险（注意）、代理（这个团队处理问题）。没有它，董事会要么过度关注一个坏指标，要么错过40页幻灯片中隐藏的真实问题。

### 3. 进度是方向性的，而不是绝对的

**模式：**

如果你目标是50K用户，那么达到100K用户并不重要——或者如果你错过了200K。背景非常重要。展示你朝着目标取得的进展，而不仅仅是数字。

**如何展示进度：**

- **按计划进行：** "目标100K活跃开发者。目前70K。所有计划都在按计划进行。信心：高。"
- **有风险：** "目标100K活跃开发者。目前50K。获取成本高于预期。测试新渠道。调整目标：85K。信心：中等。"
- **领先：** "目标100K活跃开发者。目前95K。超过获取预测。新合作伙伴加速增长。信心：非常高。"

**规则：**
1. 上游设定目标（每个指标都需要一个目标）
2. 作为目标百分比展示进度，而不仅仅是绝对数字
3. 承认失误；解释转变
4. 根据轨迹声明信心水平

**常见错误：**

在错过时改变目标。董事会会跟踪这一点。如果Q1目标是100K而你达到了60K，不要将Q2目标定为75K并称之为“修订后的指导”。声明失误，解释原因，展示恢复计划。信誉比指标增长得更快。

### 4. 四层指标等级制度

**模式：**

太多的指标会让董事会感到困惑。太少会错过重要信号。将你的指标分为四个等级，并且每个季度都不改变它们。

**第一层：北极星（1个指标）**
最能代表公司健康状况的单一指标。
- 示例：ARR、活跃用户、完成任务
- 显示趋势线，而不仅仅是当前状态
- 这是董事会如果忘记其他一切应该记住的唯一指标

**第二层：驱动指标（3-5个指标）**
预测北极星的领先指标。
- 用户获取率
- 保留曲线（有多少上个月活跃的用户在本月仍然活跃？）
- 功能采用率（使用关键功能的用户百分比）
- DAU/MAU比率
- 管道覆盖率
- 跟踪这些指标的原因：在收入影响之前提供早期预警

**第三层：健康指标（3-5个指标）**
团队和运营健康状况的信号。
- 烧钱率和续航能力
- 人员与计划的对比
- 工程师速度/交付速度
- NPS或客户满意度
- 跟踪这些指标的原因：增长的能力限制

**第四层：红旗（2-3个阈值）**
如果它们跨越阈值，则需要立即采取行动的指标。
- 裂变率高于X%
- 获取成本高于$Y
- 保留率下降大于Z%
- 跟踪这些指标的原因：触发战略对话，而不仅仅是监控

**纪律规则：**
1. **每个季度使用相同的指标。** 建立一个4-6个季度的记录。可以添加新指标，但永远不要删除旧指标。
2. **每个指标一句背景信息。** 这个指标告诉我们什么？是好的还是坏的？有什么启示？
3. **实际值与计划值，始终如一。** 永远不要展示一个指标而不展示你计划的值。差异是对话。
4. **需要时进行细分。** 总使用量隐藏了细分市场。按客户类型、细分市场、产品线进行细分——任何平均数掩盖了现实。
5. **使用健康指标。** 绿色/黄色/红色状态，供董事会快速评估。让董事会扫描仪表板并在黄色和红色上放大。

**常见错误：**

根据这个季度哪个指标看起来不错而改变你展示的指标。董事会会立即注意到。这是最快失去你对数字信誉的方式。每次都显示相同的仪表板——当一个指标看起来不好时，那就是对话。

### 5. 在董事会询问之前传递坏消息

**模式：**

当坏消息被延迟或粉饰时，董事会的信心会下降。他们可以处理坏消息。他们无法处理惊喜。他们讨厌缓慢的决策。

**预览模式：**

在坏消息影响整个董事会之前，在会议前48-72小时向主要董事预览。

- **谁：** 董事会主席或经验最丰富的董事
- **什么：** 问题、你的评估、你的计划
- **为什么：** 董事可以为整个董事会设定框架，避免惊喜震惊，并且可能见过这种模式

然后向整个董事会发送一封简短电子邮件：

“在我们下次会议之前，我想标记一些事情。[具体问题]。到目前为止我们所知道的事情、我们还不知道的事情以及我们正在如何处理它。我将在董事会会议上提供完整更新。”

**坏消息框架：**

对于每一条坏消息，四个要素：

1. **发生了什么**（具体，一句话——不是防御性的）
   - “我们错过了Q1 10个新企业客户的预期；实现了7个”

2. **为什么会发生**（根本原因，而不是借口）
   - “客户评估时间表因我们没有及早诊断出产品差距而延误”
   - 承担责任：“我们误解了需求信号”而不是“市场发生了变化”

3. **影响是什么**（诚实地说明严重性）
   - “影响Q1 ARR约$50K，将我们推至原始指导之下”

4. **我们正在如何解决**（具体行动、负责人、时间表）
   - “改变了销售动力，在产品准备就绪之前进行资格认证；将Q2目标修订为15（包括Q1积压的7个）”

**如何不沟通一个失误：**
- “我们错过了Q1目标，但我们的管道很强劲”
- “外部因素减缓了交易，但我们相信Q2”
- “我们遇到了一些实施挑战，但现在已经解决了”

所有都很模糊。都是防御性的。没有一个解释根本原因或计划。

**后续跟进模式：**

每个后续的董事会更新都应该参考之前提出的问题：“上季度我标记了[问题]。更新：[进展]。状态：[已解决/进行中/升级]。”

这建立了跟进记录。董事会记得谁跟踪他们自己的问题。

**常见错误：**

在好消息之间夹着坏消息，希望没人注意到。董事会成员会立即注意到这一点。这比坏消息本身更损害信任。

### 6. 月度投资者更新

**模式：**

大多数创始人最多每季度发送一次投资者更新。最好的创始人每月发送——即使情况不好时也是如此。尤其是在情况不好时。

**为什么每月：**
- 保持投资者参与，而无需安排电话会议
- 当你需要帮助（介绍、建议、过桥）时，投资者已经有了背景
- 一致性表明运营纪律；不规则的更新表明混乱

**格式：**

**主题行：** [公司名称] — [月份]更新

**开头（1段）：**
一个标题。简短背景。

**TL;DR（3个要点）：**
- 一个数字（目前最重要的指标）
- 一个胜利（具体——客户名称、交易规模、里程碑）
- 一个挑战（以及你正在如何解决它）

**关键指标（每月相同的表格）：**

| 指标 | 本月 | 上月 | 3个月平均 | 与计划对比 |
|------|------|------|----------|---------|
| ARR | | | | |
| MRR增长 | | | | |
| 烧钱率 | | | | |
| 续航能力（月数） | | | | |
| 管道 | | | | |
| 客户 | | | | |

不要包含与上次更新未改变的指标——专注于什么是新的。

**关键更新（2-3个要点）：**
- 主要招聘、产品发布、合作伙伴/客户胜利
- 战略转变或路线修正
- 具体到足以重要

**请求（1-2个要点）：**
- 你需要什么帮助？介绍、招聘线索、战略建议
- 具体说明： “寻找[公司类型]的副总裁工程介绍”而不是“寻找工程人才”

**节奏规则：**
- 每月同一天。第一个星期一，最后一个星期五——选择一个，永远不要错过
- 在重大新闻发生后一周内发送（不要为下一个预定更新而保留）
- 在积极融资期间：每周更新以温暖投资者，每月更新给现有投资者

**常见错误：**
只有在情况好的时候才发送更新。六个月的 tốt news 后保持沉默告诉投资者你并没有告诉他们的事情。

### 7. 烧钱率关于纪律；收入关于牵引力

**模式：**

向董事会传达的财务沟通有两个不同的故事。不要将它们混淆。

**烧钱率沟通：**
- 月度比率、月数续航能力、同比改善
- 效率提升（你削减了什么，你优化了什么？）
- 资本计划：已获得、目标、时间表

烧钱故事是：“我们是纪律严明的运营者，让资本发挥更大的作用。”

**收入沟通：**
- 月度增长率、CAC、LTV、回报期
- 客户细分（自助服务与企业，混合是什么？）
- 货币化计划与时间表

收入故事是：“我们拥有牵引力并知道如何增长它。”

**协调两者：**
最好的财务沟通显示：“我们正在减少烧钱，同时加快增长。”这是运营杠杆的证据，这是董事会可以听到的最令人信服的事情。

**常见错误：**

将烧钱与增长混淆。一个听到“我们正在快速增长”同时烧钱率上升的董事会认为你正在购买增长。一个听到“我们削减了烧钱40%”同时增长停滞的董事会认为你处于生存模式。分别讲述两个故事，然后连接它们。

### 8. 从董事会到组织的级联战略

**模式：**

在董事会房间决定的战略如果团队不知道它，那就没什么意义。创建一个系统的沟通级联。

**四个级别：**

**级别1：执行团队（每周）**
- 战略优先事项和新兴风险
- 需要协调的关键决策

**级别2：扩展领导层（每两周）**
- 战略如何影响每个职能部门
- 关键优先事项以及如何衡量成功

**级别3：全员大会（每月，60分钟）**
- 领导层更新（15分钟）：我们在哪里，发生了什么变化
- 胜利庆祝（10分钟）：客户、发布、人员
- 深入探讨（20分钟）：一个战略计划的详细说明
- 问答（15分钟）：真实问题，真实答案

**级别4：团队特定（持续进行）**
- 团队目标如何与公司战略联系
- 这个团队具体来说，成功看起来像什么

**测试：**

随机选择一个员工。他们能解释公司的战略吗？如果不能，级联是broken的。只在执行层存在的战略不是战略——它是秘密。

**将OKR与级联连接：**
- 公司OKR来自战略
- 职能OKR与公司对齐
- 团队OKR与职能对齐
- 个人了解他们如何做出贡献

**常见错误：**

信息不一致。如果不同的领导者告诉不同的故事关于公司的去向，组织会优化冲突的目标。写下战略。一页。让每个人使用相同的词语。

## 决策树

### 董事会会议与投资者更新

```
这是一个董事会会议吗？
├─ 是 → 完整结构：预读 + 三件事 + 决策 + 深入探讨
└─ 否 → 继续...
    │
    这是一个重大事件吗（融资关闭、重大失误、关键招聘）？
    ├─ 是 → 立即更新（不要等待预定时间）
    └─ 否 → 月度投资者更新格式
```

### 如何构建指标

```
你达到目标了吗？
├─ 是 → 声明它，继续。不要过度庆祝。
└─ 否 → 继续...
    │
    你理解原因吗？
    ├─ 是 → 根本原因 + 计划 + 修订时间表
    └─ 否 → 说“我们正在诊断” + 你正在做什么来找出答案
        │
        错误是重大的吗（影响续航能力、战略或董事会信心）？
        ├─ 是 → 在董事会会议前向主要董事预览
        └─ 否 → 在“三件事”叙事中包含，"哪些方面没有起作用"
```

## 常见错误

**1. 董事会会议作为状态报告**
董事会成员可以阅读。发送预读。使用会议进行决策和讨论，而不是数据演练。

**2. 每个季度都改变指标**
指标的一致性建立信任。你一旦用看起来不错的指标替换看起来不好的指标，你就告诉了董事会你的数字不可信。

**3. 没有明确的请求**
每个投资者更新、每个董事会会议都应该有一个请求。介绍、建议、批准、耐心。投资者想帮忙——如果你从不请求，他们会疏远。

**4. 代替描述进行辩护**
当你花10分钟解释一个失误时，董事会会听到防御性。声明失误，声明原因，声明计划。继续前进。

**5. 战略留在董事会会议室**
如果你的团队能解释战略，你就没有沟通它。级联它，否则它就不存在。

**6. 董事会会议中的惊喜**
坏消息永远不应该第一次在董事会会议中着陆。向主要董事预览（会议前48-72小时）。向整个董事会发送简短电子邮件。让董事会处理，然后再开会。

## 快速参考

**董事会会议流程：**
预读（会议前48-72小时）→ 问题（15分钟）→ 三件事叙事（15分钟）→ 决策事项（30-45分钟）→ 深入探讨（20-30分钟）→ 闭门会议（10分钟）

**三件事模型：**
起作用 + 没有起作用 + 我们正在如何解决它

**指标等级：**
北极星（1）→ 驱动（3-5）→ 健康（3-5）→ 红旗（2-3个阈值）

**坏消息协议：**
预览主要董事（会议前48-72小时）→ 向整个董事会发送标记电子邮件 → 发生了什么 → 为什么 → 影响 → 计划 → 每个后续会议跟进

**月度投资者更新：**
TL;DR（3个要点）→ 相同指标表格 → 关键更新（2-3）→ 具体请求（1-2）

**沟通级联：**
执行（每周）→ 领导层（每两周）→ 全员大会（每月）→ 团队（持续进行）

## 相关技能

- **operating-cadence**：内部会议节奏，为董事会准备提供支持
- **enterprise-account-planning**：用于董事会报告的管道和交易指标
- **technical-product-pricing**：需要董事会输入的定价决策
