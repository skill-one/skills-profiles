# 制作技能模板

一个用于创建新 Agent 技能的元技能。当您需要搭建新的技能文件夹、生成 SKILL.md 文件或帮助用户理解 Agent 技能规范时，请使用此技能。

## 使用此技能的场景

- 用户询问“创建一个技能”、“制作一个新技能”或“搭建一个技能”
- 用户希望为他们的 GitHub Copilot 设置添加专业能力
- 用户需要帮助构建具有捆绑资源的技能
- 用户希望将此模板复制作为起点

## 前置条件

- 理解技能应实现的目标
- 具有清晰、关键词丰富的功能描述和触发条件
- 了解所需的任何捆绑资源（脚本、引用、资源、模板）

## 创建新技能

### 第 1 步：创建技能目录

创建一个使用小写、连字符命名的文件夹：

```
skills/<skill-name>/
└── SKILL.md          # 必须包含
```

### 第 2 步：使用 Frontmatter 生成 SKILL.md

每个技能都需要带有 `name` 和 `description` 的 YAML Frontmatter：

```yaml
---
name: <skill-name>
description: '<它做什么>. 在 <特定触发条件、场景、用户可能说的关键词> 时使用.'
---
```

#### Frontmatter 字段要求

| 字段 | 必须包含 | 限制条件 |
|-------|----------|----------|
| `name` | **是** | 1-64 个字符，仅限小写字母/数字/连字符，必须与文件夹名称匹配 |
| `description` | **是** | 1-1024 个字符，必须描述做什么和何时使用 |
| `license` | 否 | 许可证名称或指向捆绑的 LICENSE.txt 的引用 |
| `compatibility` | 否 | 如果需要，1-500 个字符的环境要求 |
| `metadata` | 否 | 用于附加属性的键值对 |
| `allowed-tools` | 否 | 空格分隔的预批准工具列表（实验性） |

#### 描述最佳实践

**关键**：`description` 是自动技能发现的主要机制。请包含：

1. **技能做什么**（功能）
2. **何时使用它**（触发条件、场景、文件类型）
3. **用户在提示中可能提到的关键词**

**良好示例**：

```yaml
description: '使用 Playwright 测试本地 Web 应用的工具包。在要求验证前端功能、调试 UI 行为、捕获浏览器截图或查看浏览器控制台日志时使用。支持 Chrome、Firefox 和 WebKit。'
```

**不良示例**：

```yaml
description: 'Web 测试辅助工具'
```

### 第 3 步：编写技能主体

在 Frontmatter 之后，添加 Markdown 说明。推荐部分：

| 部分 | 目的 |
|-------|------|
| `# 标题` | 简要概述 |
| `## 何时使用此技能` | 强化描述触发条件 |
| `## 前置条件` | 必需的工具、依赖项 |
| `## 分步工作流程` | 用于任务的编号步骤 |
| `## 故障排除` | 常见问题和解决方案 |
| `## 参考` | 捆绑文档的链接 |

### 第 4 步：添加可选目录（如果需要）

| 文件夹 | 目的 | 何时使用 |
|-------|------|----------|
| `scripts/` | 可执行代码（Python、Bash、JS） | 执行操作的自动化 |
| `references/` | 代理读取的文档 | API 参考、模式、指南 |
| `assets/` | 作为原样使用的静态文件 | 图片、字体、模板 |
| `templates/` | 代理修改的起始代码 | 扩展的脚手架 |

## 示例：完整技能结构

```
my-awesome-skill/
├── SKILL.md                    # 必须包含说明
├── LICENSE.txt                 # 可选的许可证文件
├── scripts/
│   └── helper.py               # 可执行自动化
├── references/
│   ├── api-reference.md        # 详细文档
│   └── examples.md             # 使用示例
├── assets/
│   └── diagram.png             # 静态资源
└── templates/
    └── starter.ts              # 代码脚手架
```

## 快速入门：复制此模板

1. 复制 `make-skill-template/` 文件夹
2. 重命名为您的技能名称（小写、连字符）
3. 更新 `SKILL.md`：
   - 将 `name:` 更改为与文件夹名称匹配
   - 编写关键词丰富的 `description:`
   - 用您的说明替换主体内容
4. 根据需要添加捆绑资源
5. 使用 `npm run skill:validate` 进行验证

## 验证清单

- [ ] 文件夹名称是小写且带有连字符
- [ ] `name` 字段与文件夹名称完全匹配
- [ ] `description` 是 10-1024 个字符
- [ ] `description` 解释了做什么和何时使用
- [ ] `description` 被单引号包围
- [ ] 主体内容少于 500 行
- [ ] 捆绑资源每个小于 5MB

## 故障排除

| 问题 | 解决方案 |
|------|----------|
| 技能未被发现 | 使用更多关键词和触发条件改进描述 |
| 名称验证失败 | 确保小写、无连续连字符、与文件夹匹配 |
| 描述太短 | 添加功能、触发条件和关键词 |
| 资源未找到 | 使用相对于技能根目录的相对路径 |
