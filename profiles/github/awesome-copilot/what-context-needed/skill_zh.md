# 你需要哪些上下文？

在回答我的问题之前，告诉我你需要查看哪些文件。

## 我的问题

{{question}}

## 说明

1. 根据我的问题，列出你需要检查的文件
2. 解释每个文件的相关性
3. 注明你已经在这个对话中看到过的文件
4. 确定你不确定的地方

## 输出格式

```markdown
## 我需要的文件

### 必须查看（回答准确所需）
- `path/to/file.ts` — [为什么需要]

### 应该查看（有助于完整回答）
- `path/to/file.ts` — [为什么有帮助]

### 已查看
- `path/to/file.ts` — [从对话中之前的部分]

### 不确定之处
- [没有看到代码，我不确定的事情]
```

在我提供这些文件后，我会再次提出我的问题。
