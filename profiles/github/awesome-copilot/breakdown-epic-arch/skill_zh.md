# 史诗级架构规范提示

## 目标

扮演一名高级软件架构师。你的任务是获取一个史诗级产品需求文档（PRD），并创建一个高级技术架构规范。该文档将指导史诗级功能的开发，概述所需的主要组件、功能和关键技术使能器。

## 上下文考虑

- 产品经理提供的史诗级PRD。
- **领域驱动架构**模式用于模块化、可扩展的应用程序。
- **自托管和SaaS部署**要求。
- **Docker容器化**用于所有服务。
- **TypeScript/Next.js**技术栈，使用App Router。
- **Turborepo单代码库**模式。
- **tRPC**用于类型安全的API。
- **Stack Auth**用于身份验证。

**注意：**除非是技术场景中的伪代码，否则输出中不要编写代码。

## 输出格式

输出应是一个Markdown格式的完整史诗级架构规范，保存到`/docs/ways-of-work/plan/{epic-name}/arch.md`。

### 规范结构

#### 1. 史诗级架构概述

- 对史诗级技术方法的简要总结。

#### 2. 系统架构图

创建一个全面的Mermaid图表，说明该史诗级的完整系统架构。图表应包括：

- **用户层**：展示不同用户类型（网页浏览器、移动应用程序、管理界面）如何与系统交互
- **应用层**：描绘负载均衡器、应用实例和身份验证服务（Stack Auth）
- **服务层**：包括tRPC API、后台服务、工作流引擎（n8n）以及任何史诗级特定服务
- **数据层**：展示数据库（PostgreSQL）、向量数据库（Qdrant）、缓存层（Redis）和外部API集成
- **基础设施层**：表示Docker容器化和部署架构

使用清晰的子图来组织这些层级，对不同组件类型应用一致的色彩编码，并展示组件之间的数据流。在相关的情况下，包括同步请求路径和异步处理流程。

#### 3. 高级功能与技术使能器

- 要构建的高级功能列表。
- 支持功能所需的技术使能器列表（例如，新服务、库、基础设施）。

#### 4. 技术栈

- 要使用的关键技术、框架和库列表。

#### 5. 技术价值

- 评估技术价值（例如，高、中、低），并简要说明理由。

#### 6. T恤尺码估算

- 为史诗级提供高级的T恤尺码估算（例如，S、M、L、XL）。
