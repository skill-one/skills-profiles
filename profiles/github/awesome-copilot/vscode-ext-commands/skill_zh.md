# VS Code 扩展命令贡献

这项技能帮助你为 VS Code 扩展贡献命令

## 何时使用这项技能

当你需要执行以下操作时，请使用这项技能：
- 向你的 VS Code 扩展添加或更新命令

# 使用说明

VS Code 命令必须始终定义一个 `title`，与其类别、可见性或位置无关。我们为每种“类型”的命令使用几种模式，并具有一些特性，如下所述：

* 普通命令：默认情况下，所有命令应在命令面板中可访问，必须定义一个 `category`，除非该命令将在侧边栏中使用，否则不需要 `icon`。

* 侧边栏命令：其名称遵循特殊模式，以下划线（`_`）开头并以 `#sideBar` 结尾，例如 `_extensionId.someCommand#sideBar`。必须定义 `icon`，并且可能或可能没有 `enablement` 的规则。侧边栏专用的命令不应在命令面板中可见。将其贡献到 `view/title` 或 `view/item/context` 时，我们必须告知其显示的 _顺序/位置_，并且可以使用“相对于其他命令/按钮”的术语来帮助你识别正确的 `group`。此外，定义新命令的可见条件（`when`）也是一个良好的实践。
