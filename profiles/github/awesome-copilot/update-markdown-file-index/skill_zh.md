# 更新 Markdown 文件索引

使用来自文件夹 `${input:folder}` 的文件索引/目录更新 markdown 文件 `${file}`。

## 流程

1. **扫描**: 读取目标 markdown 文件 `${file}` 以了解现有结构
2. **发现**: 列出指定文件夹 `${input:folder}` 中匹配模式 `${input:pattern}` 的所有文件
3. **分析**: 确定是否存在现有的表格/索引部分需要更新，或创建新结构
4. **结构**: 根据文件类型和现有内容生成适当的表格/列表格式
5. **更新**: 替换现有部分或添加新部分以包含文件索引
6. **验证**: 确保 markdown 语法有效且格式一致

## 文件分析

对于每个发现的文件，提取：

- **名称**: 根据上下文包含或不包含扩展名的文件名
- **类型**: 文件扩展名和类别（例如，`.md`，`.js`，`.py`）
- **描述**: 第一行注释、标题或推断出的用途
- **大小**: 文件大小供参考（可选）
- **修改**: 最后修改日期（可选）

## 表格结构选项

根据文件类型和现有内容选择格式：

### 选项 1：简单列表

```markdown
## ${folder} 中的文件

- [filename.ext](path/to/filename.ext) - 描述
- [filename2.ext](path/to/filename2.ext) - 描述
```

### 选项 2：详细表格

```markdown
| 文件 | 类型 | 描述 |
|------|------|------|
| [filename.ext](path/to/filename.ext) | 扩展名 | 描述 |
| [filename2.ext](path/to/filename2.ext) | 扩展名 | 描述 |
```

### 选项 3：分类部分

按类型/类别分组文件，使用单独的部分或子表格。

## 更新策略

- 🔄 **更新现有**: 如果存在表格/索引部分，替换内容同时保留结构
- ➕ **添加新**: 如果没有现有部分，使用最佳格式创建新部分
- 📋 **保留**: 维持现有的 markdown 格式、标题级别和文档流程
- 🔗 **链接**: 在仓库内使用相对路径创建文件链接

## 部分识别

查找具有以下模式的现有部分：

- 包含 "index"、"files"、"contents"、"directory"、"list" 等标题
- 具有文件相关列的表格
- 包含文件链接的列表
- 标记文件索引部分的 HTML 注释

## 要求

- 保留现有的 markdown 结构和格式
- 使用相对路径创建文件链接
- 在可用时包含文件描述
- 默认按字母顺序排序文件
- 处理文件名中的特殊字符
- 验证所有生成的 markdown 语法
