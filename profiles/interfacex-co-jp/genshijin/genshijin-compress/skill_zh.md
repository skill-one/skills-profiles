# genshijin-compress

## 目的

将自然语言文件（CLAUDE.md, todos, 配置）转换为原始人模式以减少输入令牌数量。压缩版本将覆盖原文件，人类可读版本将保存为 `<filename>.original.md`。

## トリガ器

`/genshijin-compress <filepath>` 或“内存文件压缩”等请求。

## 处理流程

1. 检测与此 SKILL.md 同目录的 `scripts/` 目录

2. 执行:
   ```
   cd <包含SKILL.md的目录> && python3 -m scripts <绝对文件路径>
   ```

3. CLI 处理内容:
   - 文件类型检测（不消耗令牌）
   - 使用Claude API/CLI进行压缩
   - 输出验证（不消耗令牌）
   - 错误时: 使用Claude仅修正对应部分（不重新压缩）
   - 最大2次重试
   - 失败时: 向用户报告错误，原文件保持不变

4. 将结果返回给用户

## 压缩规则

### 删除

- 敬语/礼貌用语（です/ます/ございます）
- 填充词（えーと/まあ/ちなみに/一応/とりあえず/基本的に/ざっくり言うと）
- 开头语（ご質問ありがとうございます/お力になれれば幸いです）
- 模糊表达（〜かもしれません/〜と思われます/おそらく）
- 冗长表达（〜することができる→〜できる、〜というものは→〜は）
- 冗长连接（〜ということになりますので→だから、〜させていただく→する）
- 明显助词（が/の/を/に/で/は/と/も）
- 形容动词活用词尾（な/に/で/だ）→ 词干形式
- 形式名词（こと/もの/ため）→ 名词化或省略
- 辅助动词（ている/ておく/てしまう）→ 状态表达

### 完全保留（绝对不修改）

- 代码块（fenced ``` 和缩进）
- 行内代码（`backtick`）
- URL/链接（完整URL、Markdown链接）
- 文件路径（`/src/components/...`, `./config.yaml`）
- 命令（`npm install`, `git commit`, `docker build`）
- 技术术语（库名、API名、协议、算法）
- 专有名词（项目名、人名、公司名）
- 日期、版本号、数字
- 环境变量（`$HOME`, `NODE_ENV`）
- 错误消息原文

### 结构保留

- 所有Markdown标题（标题文本完全保留，下文仅压缩）
- 项目符号层级（嵌套级别保持）
- 编号列表（编号保持）
- 表格（结构保持、单元格内文本仅压缩）
- Frontmatter/YAML头部

### 压缩

- 体言止め/用言止め
- 汉字连接吸收助词（「高負荷時に高速」→「高負荷時高速」）
- 和语→汉语化（「速く動作」→「高速動作」）
- 断片OK: 「コミット前テスト実行」不可「コミット前に必ずテストを実行してください」
- 删除「〜してください」「〜することを忘れずに」→ 仅描述操作
- 合并重复项目符号
- 同模式多个示例保留1个

重要规则:
``` ... ``` 内完全复制。
禁止:
- 删除注释
- 删除空格
- 更改行顺序
- 命令缩写
- 任何简化

行内代码（`...`）完全保留。反引号内绝对不修改。

包含代码块的文件:
- 代码块视为只读区域
- 仅压缩外部文本
- 禁止压缩代码周边区域的合并

## 示例

### 示例1

原文:
> 推送main分支前请务必执行测试套件。这有助于早期发现错误，防止损坏的构建部署到生产环境。

压缩:
> main push前执行测试。早期发现错误，防止损坏构建生产部署。

### 示例2

原文:
> 该应用程序采用以下组件的微服务架构。API网关处理所有接收请求并路由到适当服务。认证服务负责管理用户会话和JWT令牌。

压缩:
> 微服务架构。API网关 全接收请求路由到服务。认证服务 用户会话+JWT令牌管理。

## 边界

- 仅压缩自然语言文件（.md, .txt, 无扩展名）
- 绝对不修改: .py, .js, .ts, .json, .yaml, .yml, .toml, .env, .lock, .css, .html, .xml, .sql, .sh
- 混合文件（散文+代码）仅压缩散文部分
- 无法判断代码或散文时保持不变
- 原文件备份到FILE.original.md后覆盖
- FILE.original.md绝对不压缩（跳过）
- 密码文件（.env, credentials, id_rsa 等）绝对不发送 → 拒绝

## 安全

压缩将向Anthropic API发送原始数据。以下拒绝:

- `.env`, `.netrc`
- `credentials.*`, `secrets.*`, `passwords.*`
- SSH密钥（`id_rsa`, `id_ed25519` 等）
- 证书（`.pem`, `.key`, `.p12`, `.crt` 等）
- 目录 `.ssh`, `.aws`, `.gnupg`, `.kube`, `.docker` 下
- 文件名包含 `secret`/`credential`/`password`/`apikey`/`token`/`privatekey` 的文件

启发式误检时可通过文件名更改规避。
