# 假设神谕——可能性空间探索器

一个通过严谨的多分支情景分析来探索不确定未来的结构化系统。与其给出单一预测，神谕映射的是完整的**可能性空间**——分叉的时间线，每条路径都有其自身的逻辑、概率和后果。

基于假设范式：即推测性问题（"如果X会怎样？"）并非闲云野梦，而是一种**基本的计算操作**——大脑在投入资源于某一未来之前模拟未来的方式。

已发表研究：[假设范式（DOI：10.5281/zenodo.18736841）](https://doi.org/10.5281/zenodo.18736841) | [IDNA v2 / 统一数字意识理论（DOI：10.5281/zenodo.18807387）](https://doi.org/10.5281/zenodo.18807387)

## 何时使用此技能

当用户：

- 提问"如果…"、"如果…会怎样…"或"探索可能性"
- 面对没有明显答案的岔路口决策
- 希望进行最佳情况/最坏情况/可能情况分析并附带概率
- 需要应急计划、风险映射或战略选项比较
- 希望对某个想法进行压力测试或思考二阶后果

针对特定领域的框架（初创公司、技术架构、危机应对等），请参阅[references/scenario-templates.md](references/scenario-templates.md)。

## 核心原则：0·IF·1

每个情景分析包含三个要素：

- **0**——未表达状态（尚未发生的事，潜力）
- **1**——已表达状态（当前现实）
- **IF**——条件纽带（将0转化为1的决策、事件或变化）

分析的质量取决于IF的精确性。模糊的"如果事情出错会怎样？"会产生模糊的结果。精确的"如果我们的主要供应商在第三季度提价30%会怎样？"会产生可操作的情报。

## 如何运行神谕

### 第一阶段——构建问题

将用户的假设性问题提炼：

**分解为组件：**

- **变量：** 具体什么发生了变化？（每个分析一个变量）
- **幅度：** 有多大？（尽可能量化）
- **时间段：** 在多长时间内？
- **背景：** 变化前的当前状态是什么？

**如果问题模糊，则提炼：**

- "如果AI接管了？" → "如果在未来3年内，[特定行业]中40%的当前知识型工作任务被AI自动化？"
- "如果我们失败了？" → "如果从现在开始，月收入连续6个月低于5K？"

在继续之前，向用户展示提炼后的问题以确认。

### 第二阶段——映射可能性空间

使用此框架生成**4-6个情景分支**：

| 分支             | 定义                                                                   | 目的                                            |
| ------------------ | ---------------------------------------------------------------------------- | -------------------------------------------------- |
| **Ω 最佳情况**    | 一切顺利。关键假设都得到验证。出现幸运的转折。     | 定义上限——最大上行空间是多少？                    |
| **α 可能情况**  | 根据当前证据最可能的路径。没有重大意外。               | 将预期锚定在现实中                             |
| **Δ 最坏情况**   | 关键假设失败。两件坏事同时发生。                    | 定义下限——最大下行空间是多少？                    |
| **Ψ 意外变量**    | 一个未被追踪的意外变量进入。黑天鹅地带。               | 对无法想象的情景进行压力测试                   |
| **Φ 反常识**   | 意见领袖的相反观点被证明是真的。                     | 挑战群体思维并揭示隐藏假设                     |
| **∞ 二阶效应** | 一阶效应触发级联后果，无人预测。                     | 绘制涟漪效应                             |

### 第三阶段——分析每个分支

针对每个情景分支，提供：

```
╔══════════════════════════════════════════════╗
║  分支：[Ω/α/Δ/Ψ/Φ/∞] — [分支名称]    ║
╠══════════════════════════════════════════════╣
║  概率：[X%]                           ║
║  时间段：[何时可能实现]                ║
║  置信度：[高/中/低]                   ║
╠══════════════════════════════════════════════╣
║  叙述：                                  ║
║  [用2-3句话描述该情景逐步展开的过程]          ║
║                                              ║
║  关键假设：                            ║
║  • [什么必须为该情景发生而成立]    ║
║  • [以及这个]                                ║
║                                              ║
║  触发条件：                         ║
║  • [该分支成为现实的早期信号]                         ║
║  • [第二个信号]                           ║
║                                              ║
║  后果：                               ║
║  → 立即：[首先发生什么]           ║
║  → 30天：[接下来发生什么]                   ║
║  → 6个月：[将导致哪里]               ║
║                                              ║
║  必要响应：                          ║
║  [如果该分支激活应采取的行动——具体、可操作]          ║
║                                              ║
║  大多数人忽略的：                      ║
║  [关于该情景的非显而易见见解，传统分析会忽略]        ║
╚══════════════════════════════════════════════╝
```

### 第四阶段——综合

分析所有分支后，提供：

**概率分布：**

```
Ω 最佳情况 ····· [██████░░░░] 15%
α 可能情况 ··· [████████░░] 45%
Δ 最坏情况 ···· [██████░░░░] 20%
Ψ 意外变量 ····· [███░░░░░░░]  8%
Φ 反常识 ···· [████░░░░░░░]  7%
∞ 二阶效应 ·· [███░░░░░░░]  5%
```

**稳健行动：** 在多个分支中都有益的行动是什么？这些是无论未来如何实现都不应错过的行动。

**对冲行动：** 什么准备可以防范最坏分支，同时不牺牲上行空间？

**决策触发器：** 什么具体、可观察的信号会导致你更新哪个分支最有可能？定义触发器。

**1%洞见：** 关于这种情况，几乎每个分析它的人都会忽略的什么事情？非显而易见的模式、隐藏的假设、被忽略的变量。

## 黄金比例加权

当存在证据时，使用黄金比例对主要情景进行加权：

- **主要未来（最可能）：** 61.8%的注意力/资源
- **替代未来：** 38.2%的注意力/资源

这可以防止过度投入单一路径和过度分散过多应急情况。自然界也使用此比例进行分支（树木、河流、血管）。战略规划也可以这样做。

## 模式

### 快速神谕（2-3分钟）

仅3个分支：最佳、可能、最坏。简短叙述。用于快速决策。

### 深度神谕（5-10分钟）

所有6个分支。完整分析，包括后果、触发器和综合。用于高风险决策。

### 情景链

将一个神谕分析的输出输入到另一个神谕中。"如果Δ分支发生，在那个分支内部的可能性是什么？"递归深度用于复杂的战略规划。

### 逆向神谕

从期望的结果开始并反向工作："实现X需要满足什么条件？到达该结果的路径最可能是什么？"用于目标设定和战略设计。

### 竞争神谕

从多个利益相关者角度分析相同的假设："如果我们推出此产品，从我们的角度、他们的角度和市场的角度看，可能性空间是什么？"

## 这不是什么

- 不是预测——它是一个可能性地图。神谕不会声称知道未来；它帮助你为多个未来做准备。
- 不是水晶球——概率是基于现有证据的估计，不是确定性。
- 不是行动的替代品——世界上最好的情景分析，如果没有后续决策和执行，就毫无价值。
