# 科学批判性思维

## 概述

批判性思维是评估科学严谨性的系统化过程。使用GRADE和Cochrane ROB框架评估方法、实验设计、统计有效性、偏差、混杂因素和证据质量。应用这项技能对科学声明进行批判性分析。

## 何时使用这项技能

当需要：
- 评估研究方法和实验设计
- 评估统计有效性和证据质量
- 识别研究中的偏差和混杂因素
- 审查科学声明和结论
- 进行系统评价或荟萃分析
- 应用GRADE或Cochrane偏倚风险评估
- 对研究论文进行批判性分析

## 核心能力

七个能力领域，每个领域都有要问的问题以及答案的含义，在
[references/core_capabilities.md](references/core_capabilities.md)中：

1. **方法学批判** — 设计、对照、混杂因素以及该方法是否能够回答所提问题。
2. **偏倚检测** — 选择偏倚、测量偏倚、发表偏倚和认知偏倚。
3. **统计分析评估** — 功效、多重性、p值误用和效应量。

6. **研究设计指导** — 在数据收集前如何加强设计。
7. **声明评估** — 区分已展示的内容和所断言的内容。

## 应用指南

### 一般方法

1. **保持建设性**
   - 识别优点和缺点
   - 提出改进建议而非仅批评
   - 区分致命缺陷和轻微限制
   - 认识到所有研究都有局限性

2. **保持具体**
   - 指向具体实例（例如，“表2显示…”或“在方法部分…”）
   - 引用有问题的陈述
   - 提供具体问题的例子
   - 引用违反的具体原则或标准

3. **保持适度**
   - 使批评的严重程度与问题的重要性相匹配
   - 区分对有效性的主要威胁和次要问题
   - 考虑问题是否影响主要结论
   - 承认您自身评估中的不确定性

4. **应用一致标准**
   - 在所有研究中使用相同标准
   - 不要对您不喜欢的发现应用更严格的标准
   - 承认您自身的潜在偏倚
   - 基于方法而非结果进行判断

5. **考虑背景**
   - 承认实际和伦理限制
   - 考虑特定领域的效应量和方法规范
   - 识别探索性vs.验证性背景
   - 考虑评估研究时的资源限制

### 提供批评时

**按以下结构提供反馈：**

1. **摘要：** 简要概述评估内容
2. **优点：** 做得好的地方（对可信度和学习很重要）
3. **问题：** 按严重程度组织的问题
   - 严重问题（威胁主要结论的有效性）
   - 重要问题（影响解释但不致命）
   - 轻微问题（值得注意但不改变结论）
4. **具体建议：** 改进的可操作建议
5. **总体评估：** 关于证据质量和可得出结论的平衡结论

**使用精确术语：**
- 具体命名偏倚、谬误和方法学问题
- 引用既定标准和指南
- 引用科学方法学的原则
- 准确使用技术术语

### 不确定时

- **承认不确定性：** “可能是X或Y；需要Z的额外信息”
- **询问澄清问题：** “[方法学细节]是否完成？这影响解释。”
- **提供条件评估：** “如果X完成，则Y成立；如果不完成，则Z是问题”
- **注明什么额外信息将解决不确定性**

## 请记住

**科学批判性思维涉及：**
- 使用既定原则进行系统评估
- 提高科学的建设性批评
- 与证据强度相匹配的适度信心
- 关于不确定性和局限性的透明度
- 一致应用标准
- 认识到所有研究都有局限性
- 怀疑与证据开放之间的平衡

**始终区分：**
- 数据（观察到的内容）和解释（其含义）
- 相关性和因果关系
- 统计显著性和实际重要性
- 探索性vs.验证性发现
- 已知和未知的内容
- 对声明的证据和零假设的证据

**批判性思维的目标：**
1. 准确识别优缺点
2. 确定哪些结论得到支持
3. 识别局限性和不确定性
4. 为未来工作提出改进建议
5. 推进科学理解
