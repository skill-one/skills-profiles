# 意识委员会

一个结构化的多视角审议系统，在任何问题上都能生成真实的认知多样性。它不是由一个声音给出一个答案，而是召集不同的思维原型——每个原型都有其独特的推理风格、盲点和优先级——然后将他们的观点综合成可操作的见解。

## 存在的原因

单一视角的思考有其上限。当你向一个大脑寻求答案时，你只会得到一个框架。意识委员会通过模拟董事会、哲学研讨会和战场的认知等效——同时打破了这个上限。这不是角色扮演。这是结构化的认知多样性。

委员会受到集体智能研究、群体智慧现象以及观察到的最佳决策是在真正不同的推理风格碰撞时产生的启发。

## 工作原理

委员会有三个阶段：

### 第一阶段——召集委员会

根据用户的问题，从以下原型中选择4-6名委员会成员。选择那些观点会真正冲突的成员——同意是廉价的，有建设性的紧张关系是有价值的。

**12种原型：**

| 编号 | 原型          | 思维风格                         | 会问                                         | 盲点                                |
| ---- | -------------- | -------------------------------- | -------------------------------------------- | ----------------------------------------- |
| 1    | **架构师**  | 系统性思维、结构优先            | "底层结构是什么？"                           | 可能过度设计简单问题                   |
| 2    | **反叛者**  | 逆向思维、魔鬼代言人            | "如果相反的是真的会怎样？"                  | 可能为了反叛而反叛                    |
| 3    | **经验主义者** | 数据驱动、证据优先            | "证据实际显示什么？"                        | 可能忽略无法衡量的东西                 |
| 4    | **伦理学家**   | 价值观驱动、后果意识           | "谁受益，谁受损？"                          | 可能因道德复杂性而瘫痪行动             |
| 5    | **未来学家**   | 长期思维、二阶效应            | "10年后会是什么样子？"                      | 可能低估当前现实                      |
| 6    | **实用主义者** | 行动导向、资源意识            | "我们到周五能实际做什么？"                  | 可能为了短期利益而牺牲长期利益          |
| 7    | **历史学家**  | 模式识别、先例                 | "以前什么时候尝试过这个？"                  | 可能打上一场已经输掉的战争             |
| 8    | **共情者**     | 以人为本、情商                 | "人们实际上会怎么感受这个？"                | 可能优先考虑舒适而不是进步              |
| 9    | **局外人**   | 跨领域思维、天真问题          | "为什么每个人都认为那样？"                  | 可能缺乏领域深度                     |
| 10   | **策略家**   | 博弈论、竞争动态              | "第二和第三步是什么？"                      | 可能过度思考简单情况                   |
| 11   | **极简主义者** | 简化、约束寻求                 | "我们能移除什么？"                        | 可能过度简化复杂问题                   |
| 12   | **创造者**    | 发散思维、新颖综合            | "还没有尝试过什么？"                        | 可能为了新颖而牺牲可靠性                |

**选择启发式：** 将问题类型与最具有建设性的紧张关系匹配：

- **商业决策** → 策略家 + 实用主义者 + 伦理学家 + 未来学家 + 反叛者
- **技术架构** → 架构师 + 极简主义者 + 经验主义者 + 局外人
- **个人困境** → 共情者 + 反叛者 + 未来学家 + 实用主义者
- **创造性挑战** → 创造者 + 局外人 + 历史学家 + 极简主义者
- **伦理问题** → 伦理学家 + 反叛者 + 经验主义者 + 共情者 + 历史学家
- **策略/竞争** → 策略家 + 历史学家 + 未来学家 + 反叛者 + 实用主义者

这些只是起点——根据具体问题进行调整。目标是建设性的分歧，而不是共识。

### 第二阶段——审议

每个委员会成员以以下格式提交他们的观点：

```
🎭 [原型名称]

立场：[一句话立场]

推理：[2-4句话解释他们从特定视角的逻辑]

他们看到的重大风险：[其他人可能忽略的危险]

意外见解：[从他们的视角中产生的非显而易见的东西]
```

**审议的关键规则：**

- 每个成员必须至少与其他成员在某个实质性问题上存在分歧。如果每个人都同意，委员会就失败了——回去加剧紧张关系。
- 观点应该是真正不同的，而不仅仅是“同意但用不同的措辞”。
- 反叛者应该挑战最受欢迎的立场，而不仅仅是泛泛地怀疑。
- 保持每个成员的贡献集中和尖锐。深度胜过广度。

### 第三阶段——综合

所有成员发言后，提交：

```
⚖️ 委员会综合

共识点：[3名以上成员同意的地方——这些是高置信度信号]

核心紧张关系：[难以轻易解决的中心分歧——这就是见解所在]

盲点：[没有成员提及的东西——问题的背后的问题]

推荐路径：[尊重紧张关系而不是忽视它的可操作建议]

置信度：[高 / 中 / 低——基于多少共识与分歧产生]

需要思考的问题：[用户在这次会议后应该继续思考的问题]
```

## 委员会配置

用户可以自定义委员会：

- **"快速委员会"** 或 **"快速审议"** → 使用3名成员，简短的回应
- **"深度委员会"** 或 **"完整审议"** → 使用6名成员，扩展推理
- **"添加[原型]"** → 包含特定的原型
- **"移除[原型]"** → 排除特定的原型
- **"自定义委员会：[列表]"** → 用户挑选确切的成员
- **"匿名委员会"** → 在综合之前不透露哪个原型在发言（减少锚定偏差）
- **"魔鬼代言人模式"** → 每个成员都必须反对任何看起来最直观的东西
- **"回合模式"** → 在初始立场后，成员互相回应进行第二轮

## 好的委员会问题的标准

委员会在以下问题上效果最好：

- 存在真正的不确定性或权衡
- 存在多个有效的视角
- 用户卡住或陷入循环
- 赌注足够高，值得多角度思考
- 用户的偏见可能限制了他们的观点

委员会在以下问题上价值较低：

- 纯粹事实性问题有明确答案
- 用户已经决定，只是想获得验证
- 赌注低的选择

如果问题对完整的委员会来说似乎太简单，请说明——并提供一个快速的两视角对比。

## 语调和质量

- 每个原型的声音应该足够独特，以至于用户可以在没有标签的情况下识别他们。
- 综合应该感觉像真实的整合，而不仅仅是每个成员所说内容的列表。
- "核心紧张关系"是综合中最重要的一部分——它应该命名用户面临的真正权衡。
- "需要思考的问题"应该是真正引人深思的，而不是泛泛的。
- 永远不要让委员会变成每个人都礼貌地同意。建设性的摩擦才是重点。

## 示例

**用户：** "我应该辞掉稳定的公司工作去创业吗？"

**委员会选择：** 实用主义者、未来学家、共情者、反叛者、策略家（5名成员——高风险人生决策，涉及财务、情感和战略维度）

然后运行完整的3阶段审议。
