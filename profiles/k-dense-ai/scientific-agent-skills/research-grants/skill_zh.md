# 科研经费申请书撰写

## 概述

科研经费申请书撰写是指为联邦机构和基金会开发竞争性资金提案的过程。掌握特定机构的要求、评审标准、叙述结构、预算编制和合规性，适用于美国国家科学基金会（NSF）、美国国立卫生研究院（NIH）、美国能源部（DOE）、国防高级研究计划局（DARPA）以及台湾国家科学委员会（NSTC）的提交。

**关键原则：**经费申请书是具有说服力的文件，必须同时展示科学严谨性、创新性、可行性和更广泛的影响力。每个机构都有其独特的优先事项、评审标准、格式要求和战略目标，必须加以应对。

## 使用此技能的时机

当进行以下工作时，应使用此技能：
- 撰写NSF、NIH、DOE、DARPA或NSTC项目的科研提案
- 准备项目描述、具体目标或技术叙述
- 开发更广泛影响或意义声明
- 创建研究时间表和里程碑计划
- 准备预算说明和人员分配计划
- 回应项目征召或资助公告
- 在重新提交中回应评审人意见
- 规划多机构合作提案
- 撰写初步数据或可行性部分
- 准备简历、履历或设施描述

## 视觉增强（可选）

优秀的提案通常包含1-3个图表（时间表、工作流程图、初步数据）。图表有助于评审，但不是清晰目标和方法的替代品。

**图表何时有帮助：**
- 研究方法和工作流程图
- 项目时间表或甘特图
- 概念框架或系统架构（技术提案）
- 实验设计流程图
- 更广泛影响活动图
- NSTC CM03研究架构图（通常预期）

**如何创建图表：**
- **首选：** 使用**科学示意图**技能（`--doc-type grant`）从自然语言描述生成AI图表
- **替代方案：** 在常用工具中构建图表（matplotlib、Illustrator、PowerPoint等）

从仓库根目录运行，并设置`OPENROUTER_API_KEY`：

```bash
python skills/scientific-schematics/scripts/generate_schematic.py "项目时间表，包含1-3年的里程碑" -o figures/timeline.png --doc-type grant
```

**披露：** AI示意图生成会将您的提示发送到[OpenRouter](https://openrouter.ai/)（第三方API）。除非您的项目适合，否则请勿包含未发表的敏感信息。

## 机构特定概述

### NSF（美国国家科学基金会）
**使命：** 促进科学进步，提升国家健康、繁荣和福祉

**关键特点：**
- 遵循[PAPPG 24-1](https://www.nsf.gov/policies/pappg)（有效日期为2024年5月20日），除非征召公告覆盖
- 智力价值 + 更广泛影响（同等权重）
- 15页项目描述限制（大多数项目；包括来自先前NSF支持的成果，最多5页）
- 强调教育、多样性和社会效益
- 鼓励合作研究
- 强调开放数据和开放科学
- 评审过程包括专家小组和临时评审人

### NIH（美国国立卫生研究院）
**使命：** 提升健康、延长寿命、减少疾病和残疾

**关键特点：**
- 具体目标（1页）+ 研究策略（R01为12页）
- 意义、创新性、方法作为核心评审标准
- R01通常需要初步数据
- 强调严谨性、可重复性和临床相关性
- 大多数R01采用模块化预算（250K增量）
- 提供多次重新提交机会

### DOE（美国能源部）
**使命：** 通过能源、环境和核挑战确保美国的安保和繁荣

**关键特点：**
- 聚焦能源、气候、计算科学、基础能源科学
- 通常要求成本分摊或行业合作
- 强调国家实验室合作
- 强大的计算和实验整合
- 能源创新和商业化途径
- 因办公室而异（ARPA-E、科学办公室、EERE等）

### DARPA（国防高级研究计划局）
**使命：** 为国家安全进行突破性技术的关键投资

**关键特点：**
- 高风险、高回报的变革性研究
- 聚焦“DARPA难题”（如果真的会发生，谁在乎）
- 强调原型、演示和过渡路径
- 通常需要多个阶段（可行性、开发、演示）
- 强大的项目管理和小步跟踪
- 团队合作通常要求
- 因项目经理和BAA（广泛机构公告）差异很大

### NSTC（台湾国家科学委员会）
**使命：** 推进台湾的科学突破、工业应用和社会影响。

**关键特点：**
- **CM03表格：** 核心技术提案格式。
- **双语：** 摘要要求中英文。
- **创新与可行性：** 主要评审重点。
- **初步数据：** 对可信度至关重要。
- **研究架构图：** 必须的视觉元素，用于清晰表达。

## 应避免的常见错误

### 概念性错误

1. **未能回应评审标准：** 未明确讨论意义、创新性、方法等。
2. **与机构使命不符：** 提出的研究不符合机构目标
3. **意义不明确：** 未能阐明研究的重要性
4. **创新性不足：** 将渐进式工作呈现为变革性
5. **目标模糊：** 不具体或不可衡量的目标

### 写作错误

1. **组织混乱：** 缺乏清晰的结构和流程
2. **过多术语：** 对更广泛的评审小组不可理解
3. **冗长：** 不必要的复杂或冗长的写作
4. **缺乏背景：** 假设评审人深入了解您的领域
5. **术语不一致：** 对同一概念使用不同术语

### 技术错误

1. **方法不足：** 不足以判断可行性
2. **过于雄心勃勃：** 时间表/预算中提出太多内容
3. **无初步数据：** 对于需要证明可行性的机制
4. **时间表不佳：** 不切实际或缺乏合理依据
5. **预算不匹配：** 预算不支持拟议的活动

### 格式错误

1. **超出页数限制：** 自动拒绝
2. **错误字体或页边距：** 非合规格式
3. **缺少必需部分：** 不完整的申请
4. **图表质量差：** 难以辨认或不专业的图表
5. **引用不一致：** 参考文献格式错误

### 战略错误

1. **选择错误项目或机制：** 提出到不适当的机会
2. **团队薄弱：** 缺乏专业知识或缺少关键合作者
3. **无更广泛影响：** 对于NSF，未能充分回应
4. **忽视项目优先事项：** 未与当前重点领域保持一致
5. **提交过晚：** 技术问题或准备仓促

## 经费开发工作流程

### 第一阶段：规划和准备（截止日期前2-6个月）

**活动：**
- 确定合适的资助机会
- 审查项目公告和要求
- 如有必要，咨询项目官员
- 组建团队并确认合作
- 开发初步数据（如需要）
- 概述研究计划和具体目标
- 审查成功提案（如可用）

**产出：**
- 选定的资助机会
- 具有明确定义的角色的团队
- 具体目标的初步概述
- 需要的初步数据差距分析

### 第二阶段：起草（截止日期前2-3个月）

**活动：**
- 撰写具体目标或目标（从这里开始！）
- 开发项目描述/研究策略
- 创建图表和数据可视化
- 起草时间表和里程碑
- 准备初步预算
- 撰写更广泛影响或意义部分
- 要求支持信/合作信

**产出：**
- 叙述部分的第一稿
- 带有说明的初步预算
- 时间表和管理计划
- 合作者的支持信

### 第三阶段：内部评审（截止日期前1-2个月）

**活动：**
- 将草稿分发给共同研究员
- 寻求同事和导师的反馈
- 如有要求，请求机构评审
- 如有可能，进行模拟评审
- 根据反馈修改
- 根据反馈完善预算和预算说明

**产出：**
- 包含反馈的修订草稿
- 与修订计划一致的完善预算
- 识别的弱点和缓解策略

### 第四阶段：最终确定（截止日期前2-4周）

**活动：**
- 叙述的最终修订
- 准备所有必需的表格和文件
- 最终确定预算和预算说明
- 汇编简历、履历和当前及拟议
- 收集支持信
- 准备数据管理计划（如需要）
- 撰写项目摘要/摘要
- 仔细检查所有材料

**产出：**
- 完整、精炼的提案
- 所有必需的补充文件
- 根据机构要求格式化

### 第五阶段：提交（截止日期前1周）

**活动：**
- 机构评审和批准
- 上传到提交门户
- 验证所有文档和格式
- 在截止日期前24-48小时提交
- 确认成功提交
- 收到确认和提案编号

**产出：**
- 提交的提案
- 提交确认
- 所有材料的存档副本

**关键提示：** 切勿等到截止日期。门户可能会崩溃，文件可能会损坏，可能会发生紧急情况。目标是在48小时前提前提交。
