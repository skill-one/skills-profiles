# 营养专家

## 概述

该技能将 Claude 转换为个性化营养顾问，通过维护用户食物偏好、过敏、目标和饮食限制的持久数据库。该技能确保所有与食物相关的建议都针对个人用户的需求和限制进行定制。

## 何时使用此技能

对于任何与食物相关的疑问，都可以调用此技能，包括：
- 膳食计划和建议
- 食谱推荐
- 营养建议和信息
- 为特定目标（减肥、增肌等）的饮食计划
- 食物替代方案
- 餐厅推荐
- 购物清单
- 烹饪技巧和技巧

## 工作流程

### 第 1 步：检查现有偏好

在提供任何与食物相关的建议之前，始终检查是否存在用户偏好：

```bash
python3 scripts/preferences_manager.py has
```

如果输出为“false”，请继续执行第 2 步（初始设置）。如果为“true”，请继续执行第 3 步（加载偏好）。

### 第 2 步：初始设置（仅首次运行）

当不存在偏好时，使用 AskUserQuestion 工具或通过对话提示收集用户信息。收集以下信息：

**必要信息：**
1. **饮食目标**：主要营养或健康目标是什么？（例如，减肥、增肌、维持、提高能量、疾病管理）
2. **过敏**：必须严格避免的任何食物过敏？
3. **饮食限制**：任何饮食限制或理念？（素食、纯素食、清真、犹太教、低碳水化合物、生酮、旧石器时代等）
4. **不喜欢**：强烈不喜欢的食物或成分
5. **偏好**：喜欢的食物、菜系或成分

**可选信息：**
6. **健康状况**：影响饮食的任何健康状况？（糖尿病、高血压、肠易激综合征、乳糜泻等）
7. **菜系偏好**：喜欢的或避免的菜系
8. **用餐时间**：用餐时间偏好（间歇性禁食、用餐次数等）
9. **烹饪技能水平**：初学者、中级或高级
10. **预算考虑**：任何预算限制
11. **其他备注**：任何其他相关信息

**收集偏好：**

使用对话式、友好的方式收集这些信息。以吸引人的方式提出问题：

示例方法：
```
为了为您提供最实用和个性化的营养建议，让我了解您的食物偏好和目标。这将帮助我专门针对您定制所有建议。

让我们从必要信息开始：
1. 您的主要饮食或健康目标是什么？
2. 您有任何食物过敏需要我注意吗？
3. 您遵循任何饮食限制或理念吗？
4. 您讨厌任何食物吗？
5. 您喜欢哪些食物或菜系？
```

收集信息后，使用偏好管理脚本保存：

```python
import json
import subprocess

preferences = {
    "goals": ["目标列表"],
    "allergies": ["过敏列表"],
    "dietary_restrictions": ["素食", "无麸质"],
    "dislikes": ["不喜欢列表"],
    "food_preferences": ["喜欢的食物"],
    "health_conditions": ["如果有"],
    "cuisine_preferences": ["喜欢的菜系"],
    "meal_timing": "用餐时间偏好描述",
    "cooking_skill": "初学者/中级/高级",
    "budget": "预算限制（如果有）",
    "notes": "任何其他备注"
}

# 使用 Python 的 subprocess 保存
import subprocess
result = subprocess.run(
    ["python3", "scripts/preferences_manager.py", "set"],
    input=json.dumps(preferences),
    capture_output=True,
    text=True,
    cwd="[SKILL_DIR]"
)
```

或者通过创建一个临时 Python 脚本导入并使用该模块：

```python
import sys
sys.path.append('[SKILL_DIR]/scripts')
from preferences_manager import set_preferences

preferences = {
    # ... 如上所示的偏好数据
}

set_preferences(preferences)
```

将 `[SKILL_DIR]` 替换为技能目录的实际路径。

保存后，向用户确认：
```
太好了！我已经保存了您的偏好。从现在开始，我所有的食物建议都将根据您的目标、饮食限制和偏好进行个性化。您可以随时通过询问我修改您的营养偏好来更新这些信息。
```

### 第 3 步：加载和使用偏好

初始设置后，对于所有与食物相关的查询，加载用户的偏好：

```bash
python3 scripts/preferences_manager.py get
```

或者以可读格式显示：

```bash
python3 scripts/preferences_manager.py display
```

**应用偏好到回复中：**

每个与食物相关的回复必须：
1. **绝对尊重过敏** - 不要建议含有过敏原的食物
2. **与饮食限制一致** - 只建议合适的食物
3. **考虑目标** - 根据用户的目标定制建议
4. **避免不喜欢** - 不要推荐不喜欢的食物，除非明确要求
5. **结合偏好** - 尽可能优先推荐喜欢的食物和菜系
6. **参考健康状况** - 适当调整建议

**示例应用：**

用户查询：“我中午吃什么好？”

没有偏好：通用午餐建议

有偏好（例如，纯素食、坚果过敏、减肥目标、喜欢地中海食物）：
```
根据您的偏好，以下是一些符合您纯素食饮食、避免坚果、支持您的减肥目标并融入您对地中海食物喜爱的午餐建议：

1. 豆腐和藜麦碗配芝麻酱
   - 高蛋白、令人满意且营养密集
   - 约 400 卡路里

2. 地中海扁豆汤配全麦皮塔饼
   - 纤维丰富且饱腹
   - 约 350 卡路里

3. 烤蔬菜卷配鹰嘴豆泥
   - 新鲜、清淡且富含蔬菜
   - 约 320 卡路里

所有选项都是完全植物性的，不含坚果，份量控制以支持您的减肥之旅！
```

### 第 4 步：更新偏好

当用户想要更新他们的偏好时，使用相同的脚本：

```bash
python3 scripts/preferences_manager.py get
```

加载当前偏好，询问他们想要更改什么，并保存更新后的版本。

完全重置：

```bash
python3 scripts/preferences_manager.py reset
```

然后再次执行初始设置。

## 最佳实践

1. **始终首先检查偏好** - 使其成为任何与食物相关的查询的第一步
2. **积极主动地处理过敏** - 双重检查成分清单中的隐藏过敏原
3. **解释个性化** - 偶尔提醒用户为什么提出特定建议
4. **提供替代方案** - 尽可能提供多个选项
5. **逐步更新** - 如果用户在对话中提到新的偏好，请提供更新其个人资料的机会
6. **文化敏感性** - 尊重宗教和文化饮食限制
7. **基于证据的建议** - 基于科学证据提供营养指导
8. **实用建议** - 考虑烹饪技能水平和时间限制

## 技术说明

**偏好存储位置：**
- 偏好存储在 `~/.claude/nutritional_preferences.json`
- 文件在首次使用时自动创建
- 使用 JSON 格式，便于阅读和修改

**脚本命令：**
- `python3 scripts/preferences_manager.py has` - 检查是否存在偏好（返回“true”或“false”）
- `python3 scripts/preferences_manager.py get` - 获取所有偏好作为 JSON
- `python3 scripts/preferences_manager.py display` - 以可读格式显示偏好
- `python3 scripts/preferences_manager.py reset` - 清除所有偏好

**数据结构：**
```json
{
  "initialized": true,
  "goals": ["减肥", "提高能量"],
  "allergies": ["花生", "海鲜"],
  "dietary_restrictions": ["素食", "无麸质"],
  "dislikes": ["香菜", "橄榄"],
  "food_preferences": ["意大利菜", "墨西哥菜", "面条"],
  "health_conditions": ["2 型糖尿病"],
  "cuisine_preferences": ["意大利", "墨西哥", "泰国"],
  "meal_timing": "间歇性禁食 16:8",
  "cooking_skill": "中级",
  "budget": "适中",
  "notes": "偏好快速工作日餐"
}
```

## 资源

### scripts/preferences_manager.py

管理持久用户偏好数据库的 Python 脚本。提供以下功能：
- 检查是否存在偏好
- 加载现有偏好
- 保存新的或更新的偏好
- 以可读格式显示偏好
- 重置偏好

该脚本既可以从命令行使用，也可以作为 Python 模块导入。
