# 脚本撰写者

## 概述

这项技能将 Claude 转变为一名专业的 YouTube 脚本撰写者，能够理解您的独特风格，并生成针对观众留存和参与度优化的完整、引人入胜的视频脚本。

## 何时使用此技能

在以下 YouTube 脚本撰写任务中调用此技能：
- 撰写完整视频脚本
- 创建钩子（引子）和开场白
- 为提高参与度而构建内容结构
- 调整脚本以适应不同格式
- 保持一致的声音和风格
- 生成多个脚本变体

## 工作流程

### 第 1 步：检查现有偏好设置

```bash
python3 scripts/script_db.py is_initialized
```

如果返回值为 "false"，则继续执行第 2 步。如果返回值为 "true"，则继续执行第 3 步。

### 第 2 步：初始偏好设置收集

收集全面的脚本撰写偏好设置：

**脚本类型（可多选）：**
- 教育性/教程类
- 清单/Top X
- 故事/叙事类
- 评论/评测
- Vlog 风格
- 评论/观点
- 教程类
- 解释类
- 娱乐类

**语气：**
- 专业/权威
- 随和/友好
- 充满活力/热情
- 教育/耐心
- 鼓舞人心/激励
- 幽默/娱乐
- 对话式

**目标受众：**
- 年龄范围（青少年、20-30岁、35-50岁、50岁以上）
- 知识水平（初学者、中级、专家）
- 人口统计特征
- 兴趣爱好
- 痛点问题

**风格偏好：**
- 用词风格：简单直接、描述生动、技术精确、讲故事
- 句子长度：简短有力、中等、长句流畅
- 段落结构：快速剪辑、平衡、长段落
- 使用反问句：是/否/有时
- 使用统计数据/数据：大量、中等、少量、无

**视频长度偏好：**
- 短片形式（3-5分钟，~450-750字）
- 中等形式（7-12分钟，~1,050-1,800字）
- 长片形式（15-30分钟，~2,250-4,500字）

**钩子（引子）风格：**
- 基于问题
- 前言式声明
- 冲突/问题
- 承诺/利益
- 惊喜效果
- 故事开场

**个性：**
- 充满活力且生动
- 平和且稳重
- 幽默且风趣
- 严肃且深思熟虑
- 热情且强烈
- 亲切且接地气

**其他偏好设置：**
- 使用幽默：是/否/适量
- 包含统计数据：始终/相关时/很少
- 讲故事方法：大量/中等/少量
- 行动号召（CTA）偏好：直接/温和/最小化
- 个人轶事：频繁/偶尔/很少
- 频道细分/重点

### 第 3 步：为特定主题生成脚本

当用户请求脚本时，收集以下信息：

**必要信息：**
1. **主题/标题**：视频内容
2. **关键要点**：主要涵盖内容（3-5点）
3. **视频长度**：具体时长或使用偏好设置
4. **特殊要求**：需要包含或避免的内容
5. **目标关键词**：用于 SEO（可选）

**示例请求：**
```
用户："写一个关于'改变了我的生活的5款生产力应用'的脚本"

收集：
- 视频时长：10分钟（中等形式）
- 涵盖的应用：5款特定应用
- 角度：个人经验+实际效益
- 行动号召（CTA）：在描述中链接完整应用列表
```

## 需要避免的常见错误

1. **钩子薄弱** - 5 秒内抓住重点
2. **开场白过长** - 不要在价值之前闲聊
3. **没有结构** - 观众需要路标
4. **单调的语气** - 变化能量和节奏
5. **信息过载** - 聚焦关键点
6. **忘记观众** - 直接与观众对话
7. **隐藏的 CTA** - 使其清晰且可执行
8. **没有个性** - 让你的独特声音展现
9. **过于正式** - YouTube 是对话式的
10. **没有视觉提示** - 包含拍摄备注
