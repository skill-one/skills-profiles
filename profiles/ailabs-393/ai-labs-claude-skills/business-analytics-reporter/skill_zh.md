# 商业分析报告

## 概述

生成全面的商业绩效报告，分析销售额和收入数据，识别业务薄弱环节，解读统计数据所反映的问题，并提供可执行的提升策略。该技能利用数据驱动分析来检测薄弱环节，并根据商业框架推荐具体的策略。

## 使用场景

在以下情况下调用此技能：
- "分析我的业务数据，告诉我我们在哪些方面存在不足"
- "生成需要改进领域的报告"
- "这些销售数据告诉我们关于业务绩效的哪些信息？"
- "创建包含改进策略的业务分析报告"
- "识别收入数据中的薄弱环节"
- "我们应该使用哪些策略来提高业务指标？"

该技能期望接收包含业务数据（销售、收入、交易）的CSV文件，其中包含日期、金额、类别或产品等列。

## 核心工作流程

### 第1步：数据加载和探索

首先了解数据结构以及用户想要分析的内容。

**如有需要，请提出澄清问题：**
- 分析应重点关注哪些具体指标或领域？
- 是否有特定的时间段或类别感兴趣？
- 报告是否应包含可视化或专注于书面分析？

**加载和探索数据：**
```python
import pandas as pd

# 加载CSV文件
df = pd.read_csv('business_data.csv')

# 显示基本信息
print(f"数据形状：{df.shape}")
print(f"列：{df.columns.tolist()}")
print(f"日期范围：{df['date'].min()} 至 {df['date'].max()}")
print(df.head())
```

### 第2步：运行自动分析

使用捆绑的分析脚本生成全面洞察：

```bash
python scripts/analyze_business_data.py path/to/business_data.csv output_report.json
```

该脚本将：
1. 自动检测数据结构（收入列、日期列、类别）
2. 计算统计指标（均值、中位数、增长率、波动性）
3. 识别趋势和模式
4. 检测薄弱环节和表现不佳的细分市场
5. 根据发现生成改进策略
6. 输出结构化的JSON报告

**输出结构：**
```json
{
  "metadata": {...},
  "findings": {
    "basic_statistics": {...},
    "trend_analysis": {...},
    "category_analysis": {...},
    "variability": {...}
  },
  "weak_areas": [...],
  "improvement_strategies": [...]
}
```

### 第3步：解读分析结果

阅读生成的JSON报告，并以平实的语言为用户解读发现。

**重点关注：**
1. **当前状态**：数据反映的业务绩效
2. **薄弱环节**：已识别的具体问题及其严重程度
3. **根本原因**：这些问题存在的原因（使用参考资料中的商业框架）
4. **影响**：这些弱点对业务的影响

**示例解读：**
```
根据对2024年1月至12月销售数据的分析：

当前状态：
- 总收入：120万美元，月均收入10万美元
- 平均增长率：-3.5%，表明绩效下降
- 收入稳定性：高波动性（CV：58%），表明表现不一致

已识别的薄弱环节：
1. 收入增长（高严重程度）：平均增长率为-3.5%
2. 绩效一致性（中等严重程度）：45%的时间段表现下降
3. 类别绩效（中等严重程度）：4个表现不佳的类别
```

### 第4步：生成详细建议

参考商业框架参考资料提供战略建议：

**加载商业框架以提供背景：**

- 运营卓越框架
- 以客户为中心的策略
- 定价策略框架
- 常见薄弱环节解决方案

**将建议结构化为：**

针对每个已识别的薄弱环节，提供：
1. **战略计划名称**：清晰、可执行的计划名称
2. **目标**：该策略旨在实现的目标
3. **关键行动**：3-5个具体、优先的行动步骤
4. **预期影响**：高/中/低
5. **时间表**：现实的实施时间
6. **成功指标**：如何衡量改进

```

**收入趋势的示例代码：**

import plotly.graph_objects as go

fig = make_subplots(specs=[[{"secondary_y": True}]])

# 添加收入线
fig.add_trace(
    go.Scatter(x=df['date'], y=df['revenue'], name="收入",
               line=dict(color='blue', width=3)),
    secondary_y=False
)

# 添加增长率线
fig.add_trace(
    go.Scatter(x=df['date'], y=df['growth_rate'], name="增长率",
               line=dict(color='green', dash='dash')),
    secondary_y=True
)

fig.update_layout(title_text="收入表现与增长率")
fig.show()
```

## 关键分析指标

分析脚本自动计算以下指标：

### 增长分析
- **平均增长率**：收入周期性变化百分比
- **负增长周期数**：负增长周期的数量
- **趋势方向**：整体轨迹（增长、下降、稳定）

### 稳定性分析
- **变异系数（CV）**：衡量收入波动性
  - CV < 25%：稳定绩效
  - CV 25-50%：中等波动性
  - CV > 50%：高波动性（标记为弱势环节）

### 类别绩效
- **收入贡献**：按类别的百分比分解
- **表现不佳的类别**：按平均绩效排名最低的25%
- **最佳/最差表现者**：表现最佳和最差的类别

### 统计指标
- 所有数值列的均值、中位数、标准差
- 最小/最大值和范围
- 总汇总

## 高效报告技巧

1. **从大局出发**：首先展示整体绩效和关键发现
2. **按严重程度优先**：首先关注高严重程度的问题
3. **具体明确**：提供具体的数字和百分比，而不是模糊的评估
4. **以行动为导向**：每个弱势环节都应有可执行的建议
5. **考虑背景**：考虑行业基准和业务背景
6. **可视化沟通**：使用图表使趋势立即清晰
7. **面向高管**：结构化以快速扫描，带有清晰的标题和摘要

## 常见弱势领域和检测

分析自动检测这些常见的业务问题：

| 弱势领域 | 检测标准 | 典型根本原因 |
|----------|----------|--------------|
| 收入增长 | 平均增长率为负 | 市场饱和、竞争加剧、定位不佳 |
| 绩效一致性 | >40%下降周期 | 缺乏经常性收入、季节性依赖 |
| 收入稳定性 | CV > 50% | 客户集中、需求波动 |
| 类别绩效 | 排名最低的25%类别 | 产品市场契合度差、定价问题、低知名度 |
