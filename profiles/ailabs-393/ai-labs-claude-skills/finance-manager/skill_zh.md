# 财务管理器

一套全面的个人财务管理工具，可处理交易数据、执行复杂的财务分析、生成可操作的见解，并创建美观的可视化报告。

## 核心功能

1. **交易数据处理**：从PDF、CSV或JSON文件中提取财务数据
2. **财务分析**：计算关键指标、识别支出模式、追踪储蓄
3. **可视化**：生成带有图表和图形的交互式HTML报告
4. **预算建议**：根据支出模式提供个性化、可操作的建议
5. **趋势分析**：识别支出模式、异常情况以及优化机会

## 工作流程

### 1. 数据提取和准备

**对于PDF文件：**
```bash
python scripts/extract_pdf_data.py <input.pdf> <output.csv>
```

**对于CSV/JSON文件：**
- 确保数据包含以下列：`日期`、`描述`、`收入`（类别）、`类型`、`金额`
- 日期格式：YYYY-MM-DD或可解析的日期字符串
- 金额：收入为正，支出为负

### 2. 财务分析

对交易数据运行全面分析：
```bash
python scripts/analyze_finances.py <transactions.csv> > analysis_output.json
```

**输出包括：**
- 汇总统计（总收入、支出、净储蓄、储蓄率）
- 支出趋势（每日平均、最大支出、类别百分比）
- 预算建议（根据支出模式个性化）
- 可视化数据（用于制图）

### 3. 报告生成

创建带有可视化的交互式HTML报告：
```bash
python scripts/generate_report.py <analysis_output.json> <report.html>
```

**报告功能：**
- 关键指标的汇总仪表板
- 交互式饼图显示按类别的支出
- 比较收入与支出的柱状图
- 带颜色编码的指示器（绿色表示正，红色表示负）
- 个性化建议部分
- 响应式设计，适用于所有设备

### 4. 完整工作流程示例

```bash
# 从PDF提取数据
python scripts/extract_pdf_data.py finance_data.pdf transactions.csv

# 分析数据
python scripts/analyze_finances.py transactions.csv > analysis.json

# 生成可视化报告
python scripts/generate_report.py analysis.json financial_report.html
```

## 关键指标和基准

### 储蓄率
```
储蓄率 = (总收入 - 总支出) / 总收入 × 100
```

**基准：**
- 低于10%：需要改进
- 10-20%：良好
- 20-30%：优秀  
- 高于30%：杰出

### 类别指南（占收入的百分比）
- 住房：25-30%
- 交通：10-15%
- 食品：10-15%
- 公用事业：5-10%
- 储蓄：至少20%

有关详细的框架和方法，请参阅 `references/financial_frameworks.md`。

## 分析功能

### 汇总统计
- 期间的总收入和支出
- 净储蓄（可以是正或负）
- 储蓄率百分比
- 交易数量
- 覆盖的日期范围

### 支出趋势
- 每日平均支出
- 前5大支出详情
- 类别百分比分解
- 支出随时间的变化

### 预算建议

系统根据以下内容生成个性化建议：
- 储蓄率阈值
- 类别支出百分比
- 收入多样化
- 预算指南比较

**示例建议：**
- "⚠️ 您的储蓄率低于10%。考虑减少非必要支出。"
- "🍽️ 食品支出占支出的18%。考虑制定菜单计划以降低成本。"
- "✅ 优秀的储蓄率！您正在朝着良好的财务健康状况发展。"

## 可视化组件

### 类别支出图（环形图）
显示按类别划分的支出比例，并带颜色编码。

### 收入与支出图（柱状图）
显示每月收入和支出的比较，以识别现金流趋势。

### 交互功能
- 悬停提示显示确切值
- 响应式设计适应屏幕尺寸
- 带颜色编码的正（绿色）和负（红色）指示器

## 获取最佳效果的建议

### 数据质量
- 确保所有交易都正确分类
- 使用一致的类别名称
- 包含完整的日期信息
- 验证金额是否正确标记（收入为正，支出为负）

### 分析频率
- 每月运行分析以追踪趋势
- 月末生成报告以供审查
- 比较月度变化以识别变化

### 对建议采取行动
- 按潜在影响优先考虑建议
- 根据见解设定具体、可衡量的目标
- 定期重新运行分析以跟踪进度

## 常见用例

"分析我的10月份支出并创建报告"

**预算优化：**  
"我在哪里花费过多？"

**趋势分析：**
"这个月的支出与上个月相比如何？"

**目标设定：**
"我的储蓄率是多少以及如何提高？"

"按交易分解我的食品支出"

**PDF处理：**
"从我的银行对账单PDF中提取所有交易"

## 最佳实践

1. **一致的分类**：在所有交易中使用相同的类别名称
2. **定期分析**：每月运行以尽早发现趋势
3. **采取行动**：使用建议进行具体的支出更改
4. **跟踪进度**：比较月度报告
5. **验证数据**：在分析前始终检查提取的PDF数据的准确性
