# 创业项目验证器

一个通过系统性市场调研、竞争分析、问题验证和定位策略来分析创业想法的全面工具。这项技能有助于评估一个创业想法是否具有真实的市场潜力以及如何有效地进行定位。

## 核心工作流程

当用户提出一个创业想法时，请遵循以下系统验证流程：

### 1. 想法澄清与范围界定（2-3分钟）

在研究开始前确保完全理解：

**提取关键信息：**
- 解决的问题
- 目标客户/市场
- 提出的解决方案
- 商业模式（如果提及）
- 地域焦点（默认：全球/美国）

**只有在关键信息缺失时才提出澄清问题：**
- "您的目标客户具体是谁？"
- "他们目前面临什么问题？"
- "他们今天如何解决这个问题？"

**不要**询问您可以独立研究的信息（市场规模、竞争对手、趋势）。

### 2. 研究计划制定（1分钟）

根据想法创建研究计划，确定以下内容：
- 需要的市场规模查询
- 竞争对手研究关键词
- 问题验证搜索
- 趋势分析主题
- 定价/商业模式研究

使用 `references/research_templates.md` 中的模板进行查询制定。

### 3. 全面市场研究（至少10-15次工具调用）

在所有维度上执行系统研究。**始终使用至少10-15次网络搜索**以确保彻底分析。

#### A. 市场机会（3-5次搜索）
搜索：
- 市场规模和预测
- 增长率和趋势
- TAM/SAM计算
- 行业报告和预测

**查询示例：**
- "[行业] 2025年市场规模"
- "全球[产品类别]市场预测"
- "[行业]增长率CAGR"

#### B. 竞争格局（3-5次搜索）
搜索：
- 直接竞争对手
- 替代解决方案
- 市场领导者
- 近期融资/收购

**查询示例：**
- "[解决方案类型]公司"
- "[产品类别]替代方案"
- "最佳[产品类型] 2025"
- "[行业]初创公司融资"

#### C. 问题验证（2-3次搜索）
搜索：
- 问题的证据
- 当前痛点
- 客户行为模式
- 现有预算分配

**查询示例：**
- "[目标客户]挑战[行业]"
- "为什么[目标客户]需要[解决方案]"
- "[问题]统计数据"

#### D. 市场趋势（2-3次搜索）
搜索：
- 技术趋势
- 监管变化
- 消费者行为变化
- 投资模式

**查询示例：**
- "[行业] 2025年趋势"
- "[技术/市场]的未来"
- "[行业]投资报告"

#### E. 商业模式研究（1-2次搜索）
搜索：
- 该领域内的定价模式
- 单位经济基准
- 客户获取策略

**查询示例：**
- "[产品]定价模式"
- "[行业]平均客户获取成本"

**关键点：** 使用 `web_fetch` 从权威来源（Gartner、McKinsey、Statista、Crunchbase、行业报告）读取完整文章以获取详细数据，而不仅仅是片段。

### 4. 数据分析与综合

收集数据后，使用 `references/frameworks.md` 中的框架进行分析：

#### 市场机会评估
- 计算/估计TAM、SAM、SOM
- 评估增长轨迹
- 识别市场趋势（有利/不利）
- 评估市场成熟度阶段

#### 竞争定位
- 绘制竞争格局（直接/间接/相邻）
- 识别市场空白
- 评估进入壁垒
- 评估所需的竞争优势

#### 问题-解决方案匹配
- 验证问题的频率和强度
- 评估支付意愿
- 评估当前解决方案及其局限性
- 识别独特价值主张机会

#### 商业模式可行性
- 估计单位经济潜力
- 评估可扩展性
- 评估定价能力
- 考虑客户获取渠道

**可选：** 如果有定量数据，创建一个JSON文件并使用 `scripts/market_analyzer.py` 计算指标并生成额外见解。

### 5. 风险与机会识别

清晰地说明：
- **关键风险：** 终止交易或重大挑战
- **可管理风险：** 可通过策略/执行解决
- **主要机会：** 市场空白、时机优势、趋势
- **需要验证的假设：** 需要测试的假设

### 6. 定位策略

制定具体建议：
- **目标市场细分：** 主要滩头市场
- **价值主张：** 核心利益陈述
- **差异化策略：** 如何脱颖而出
- **市场进入策略：** 分销和获取策略
- **定位声明：** 简洁的市场定位

### 7. 报告生成

创建一个全面的markdown报告，包含：

```markdown
# [创业想法] 验证报告

## 执行摘要
- 一段概述
- 最终建议：强烈建议推进 / 继续验证 / 建议转向 / 不可行
- 3-5个关键发现

## 市场分析
### 市场规模与增长
- TAM/SAM/SOM估计及来源
- 增长率和轨迹
- 市场成熟度评估

### 市场趋势
- 关键有利趋势
- 潜在不利因素
- 时机考虑

## 竞争格局
### 直接竞争对手
- 列表及简要描述
- 市场份额/定位
- 优势与劣势

### 间接竞争
- 替代解决方案
- 替代品

### 竞争空白
- 未满足的需求
- 定位机会

## 问题-解决方案匹配
### 问题验证
- 问题的证据
- 频率和强度
- 当前解决方案及其局限性

### 解决方案差异化
- 独特价值主张
- 竞争优势
- 潜在护城河

## 商业模式评估
### 收入模式
- 定价策略一致性
- 单位经济潜力
- 可扩展性因素

### 客户获取
- 主要渠道
- CAC考虑
- 销售周期估计

## 风险分析
### 关键风险
- 终止交易
- 重大挑战

### 可管理风险
- 可解决的关注点
- 缓解策略

## 定位建议
### 目标市场
- 主要客户细分
- 滩头市场策略

### 价值主张
- 核心利益陈述
- 关键差异化

### 市场进入策略
- 分销方法
- 合作机会
- 初期获取策略

## 验证下一步
1. 立即验证假设的行动
2. 需要的客户访谈
3. MVP或原型测试
4. 需要追踪的指标

## 来源
[列出所有关键来源及链接]
```

**格式指南：**
- 使用清晰的标题和子标题
- 突出显示关键指标和发现
- 包含具体数字及来源
- 使用项目符号提高可读性
- 逐行引用链接
- 执行摘要不超过200字

## 质量标准

### 研究全面性
- **至少10-15次网络搜索** 跨所有维度
- 使用权威来源（优先：Gartner、Forrester、McKinsey、Statista、Crunchbase、行业分析师）
- 从多个来源交叉验证数据
- 获取完整文章进行详细分析，而不仅仅是片段

### 分析深度
- 应用 `references/frameworks.md` 中的多个框架
- 提供具体数字和估计（而不是模糊陈述）
- 识别机会和风险
- 提供具体的行动建议

### 报告质量
- 清晰的执行摘要及明确建议
- 结构良好，逻辑清晰
- 具体且可操作的见解
- 正确引用来源
- 坦诚数据局限性和假设

## 捆绑资源

### `references/frameworks.md`
全面的市分析框架，包括：
- TAM/SAM/SOM分析方法
- 波特五力模型
- 问题-解决方案匹配标准
- 商业模式评估框架
- 风险评估类别
- 定位框架

**使用场景：** 在分析过程中参考以确保所有维度全面评估。

### `references/research_templates.md`
搜索查询模板和可靠数据来源，包括：
- 市场规模研究查询
- 竞争分析搜索
- 问题验证查询
- 趋势分析关键词
- 按类别推荐的数据来源
- 来源质量等级

**使用场景：** 在研究计划和执行过程中制定有效搜索并识别权威来源。

### `scripts/market_analyzer.py`
用于定量市场分析的Python脚本：
- 市场指标计算（TAM/SAM/SOM百分比，增长预测）
- 单位经济分析（LTV:CAC，回收期，利润率）
- 可行性评分算法
- 自动化报告生成

**使用场景：** 当有定量数据时使用，计算指标将增强分析。通过JSON文件输入数据，输出计算指标和markdown报告部分。

**示例用法：**
```bash
python scripts/market_analyzer.py analysis_data.json
```

**输入格式：**
```json
{
  "startup_name": "示例创业公司",
  "market_data": {
    "tam": 10000000000,
    "sam": 2000000000,
    "som": 200000000,
    "current_market_size": 5000000000,
    "growth_rate": 15,
    "years": 5,
    "competition_level": "medium",
    "market_maturity": "growing"
  },
  "business_data": {
    "cac": 500,
    "ltv": 2000,
    "monthly_revenue": 50,
    "revenue": 1000,
    "cost": 300
  }
}
```

## 常见错误避免

1. **研究不足：** 不要依赖1-3次搜索。始终执行至少10-15次搜索。

2. **结论模糊：** 避免类似"市场很大"而没有具体数字的陈述。

3. **遗漏关键维度：** 确保分析涵盖市场机会、竞争、问题验证、趋势和商业模式。

4. **过度乐观：** 呈现平衡观点，包括真实风险和挑战。

5. **来源质量差：** 优先考虑主要来源和知名分析师，而不是博客和推广内容。

6. **忽略时机：** 市场准备度和趋势时机是关键因素。

7. **无行动建议：** 始终提供具体的验证下一步。
