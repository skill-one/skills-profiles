# 研究论文撰写助手

## 概述

本技能指导创建符合IEEE和ACM会议/期刊发表标准的正式学术研究论文。它确保论文结构规范、格式正确、采用学术写作风格，并全面涵盖研究主题。

## 工作流程

### 1. 理解研究主题

当被要求撰写研究论文时：

1. **与用户明确主题和范围**：
   - 主要研究问题或贡献是什么？
   - 目标受众（会议、期刊、普通学术）？
   - 期望篇幅（页数或字数）？
   - 是否需要特定章节？
   - 使用哪种格式标准（IEEE或ACM）？

2. **如需，收集背景资料**：
   - 审阅提供的任何研究材料、数据或参考文献
   - 了解领域和技术背景
   - 确定关键相关研究或现有研究以供参考

### 2. 论文结构

遵循标准学术论文结构：

```
1. 标题和摘要
   - 简洁反映主要贡献的标题
   - 摘要：150-250字总结目的、方法、结果、结论

2. 引言
   - 动机和问题陈述
   - 研究差距和意义
   - 主要贡献（通常3-5个要点）
   - 论文组织段落

3. 相关工作/背景
   - 相关研究的文献综述
   - 与现有方法的比较
   - 当前工作的定位

4. 方法论/方法/系统设计
   - 提出方法/系统的详细描述
   - 如适用，架构图
   - 算法或程序
   - 设计决策和理由

5. 实现（如适用）
   - 技术细节
   - 使用的工具和技术
   - 挑战和解决方案

6. 评估/实验/结果
   - 实验设置
   - 数据集或测试场景
   - 性能指标
   - 结果展示（表格、图表）
   - 分析和解释

7. 讨论
   - 结果的意义
   - 局限性和有效性威胁
   - 经验教训

8. 结论和未来工作
   - 贡献总结
   - 影响和意义
   - 未来研究方向

9. 参考文献
   - 正确引用格式的完整书目
```

### 3. 学术写作风格

应用学术研究中的写作规范：

**语气和语调：**
- 正式、客观、精确的语言
- 第三人称视角（避免使用"我"或"我们"，除非描述具体贡献）
- 现在时用于既定事实，过去时用于具体研究
- 清晰直接的陈述，避免不必要的复杂性

**技术精确性：**
- 首次使用时定义所有缩写："情境感知系统(C-AS)"
- 正确且一致地使用领域特定术语
- 用具体指标或证据量化主张
- 避免使用"非常"、"很多"、"显著"等模糊术语，除非有数据支持

**论证：**
- 清晰陈述主张，然后用证据支持
- 逻辑递进：动机→问题→解决方案→验证
- 明确与相关工作的比较和对比
- 承认局限性和反论点

**特定章节指南：**

*摘要：*
- 第一句：宽泛的背景和动机
- 第二/三句：具体问题和差距
- 中间：方法和方法论
- 结尾：关键结果和贡献
- 独立性（无需全文即可读懂）

*引言：*
- 从现实动机或引人入胜的问题开始
- 从一般到具体（倒金字塔结构）
- 结尾清晰列出贡献和论文路线图
- 用例子说明问题

*相关工作：*
- 按主题或方法分组相关研究
- 明确比较："与专注于Y的[X]不同，我们的方法..."
- 确定差距："然而，这些方法没有解决..."
- 清晰定位你的工作

*结果：*
- 清晰地用表格/图表展示数据
- 客观描述趋势和模式
- 定量比较基线
- 承认意外或负面的结果

### 4. 格式指南

**IEEE格式（默认）：**
- 页面大小：A4（210mm×297mm）
- 页边距：顶部19mm，底部43mm，左右14.32mm
- 双栏布局，栏间距4.22mm
- 字体：全文Times New Roman
  - 标题：24pt加粗
  - 作者姓名：11pt
  - 章节标题：10pt加粗，编号（1.、1.1、1.1.1）
  - 正文：10pt
  - 图表说明：8pt
- 行距：单倍行距
- 段落：无缩进，段落间3pt间距
- 图表：居中，说明在下方
- 表格：居中，说明在上方

**ACM格式（可选）：**
- 标准ACM会议论文格式
- 摘要单栏，正文双栏
- 摘要后包含CCS概念和关键词部分
- 使用ACM引用格式

### 5. 引用和参考文献

**文内引用：**
- 使用编号引用："近期研究[1,2]表明..."
- 多个引用按时间顺序：[3,7,12]
- 引用特定章节："如[5,第3节]所示..."

**参考文献格式（IEEE风格）：**
```
[1] A. 作者, B. 作者, 和 C. 作者, "论文标题," 在会议名称, 年份, pp. 123-456.
[2] D. 作者, "期刊文章标题," 期刊名称, 卷X, 第Y期, pp. 123-456, 月份年份.
[3] E. 作者, 书名, 版本. 城市: 出版社, 年份.
```

**参考文献列表要求：**
- 按第一作者姓氏字母顺序排列（或按引用顺序编号）
- 如有，包含DOI或URL
- 全文至少15-20篇参考文献
- 混合近期（近5年）和基础性作品

### 6. 内容生成过程

**分步方法：**

1. **创建大纲**
   - 开发按章节的详细大纲
   - 定义每个章节的关键点
   - 确定需要图表的位置

2. **迭代起草章节**
   - 先从方法论（核心贡献）开始
   - 然后引言（现在贡献已明确）
   - 相关工作（定位贡献）
   - 结果和评估
   - 讨论和结论
   - 最后写摘要（全文总结）

3. **添加引用**
   - 在撰写过程中引用相关工作
   - 用文献证据支持主张
   - 创建完整的参考文献列表

4. **审查和修改**
   - 检查章节之间的逻辑衔接
   - 确保术语一致性
   - 确认所有图表都在正文中引用
   - 确认摘要与内容一致
   - 验证引用完整性

## 示例

**示例1：用户要求撰写综述论文**
```
用户: "撰写一篇关于情境感知系统近期进展的综述论文"

响应:
1. 明确范围: "我将撰写一篇关于情境感知系统的综述论文。几个问题:
   - 是否应侧重特定方面（如需求工程、实现技术）？
   - '近期'的时间范围：5年还是10年？
   - 期望篇幅：10-15页，或20-30页的全面综述？
   - IEEE或ACM格式？"

2. 明确后，创建大纲显示：
   - 情境感知系统的分类
   - 综述方法
   - 分类方案
   - 不同方面的章节覆盖
   - 趋势和未来方向

3. 按综述结构起草，包含广泛的相关工作覆盖
```

**示例2：用户要求撰写实验论文**
```
用户: "撰写一篇关于我开发的新算法检测视觉语言模型幻觉的论文"

响应:
1. 收集细节：
   - 算法方法和创新性
   - 实验设置和数据集
   - 结果和指标
   - 比较基线

2. 按实验论文结构：
   - 引言：幻觉检测的动机
   - 相关工作：现有检测方法
   - 提出方法：详细算法描述
   - 实验：数据集、指标、设置
   - 结果：与基线的定量比较
   - 分析：消融实验、错误分析
   - 结论：贡献和未来工作

3. 强调可复现性和实证验证
```

## 重要提示

- **开始前始终请求澄清**主题范围
- **质量优先于速度**：花时间结构化并清晰写作
- **适当引用**：学术诚信要求正确归属
- **诚实说明局限性**：承认研究的差距或约束
- **保持一致性**：术语、符号和风格全程一致
- **用户提供研究内容**：本技能负责结构和写作；用户提供技术贡献和发现
