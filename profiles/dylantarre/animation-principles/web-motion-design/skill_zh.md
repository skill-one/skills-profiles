# Web 动效设计

将迪士尼 12 条动画原理应用于 CSS、JavaScript 和前端框架。

## 快速参考

| 原理 | Web 实现 |
|------|----------|
| 压缩与拉伸 | 交互状态下的 `transform: scale()` |
| 预期动作 | 动作前轻微反向运动 |
| 舞台效果 | 通过动效层级集中用户注意力 |
| 直接前进/姿势到姿势 | JS 帧动画 vs CSS 关键帧 |
| 追随与重叠 | 错开的子元素动画、弹性缓动 |
| 缓入缓出 | `ease-in-out`、三次贝塞尔曲线 |
| 弧线 | `motion-path` 或 bezier 平移变换 |
| 次要动作 | 阴影、辉光随主要动效响应 |
| 时序 | 微动效：100-200ms，标准过渡：200-400ms |
| 夸张 | 超过 1.0 的缩放，过度动画 |
| 固体绘制 | 一致的 `transform-origin`、3D 透视 |
| 吸引力 | 平滑 60fps、有目的的动效设计 |

## 原理应用

**压缩与拉伸**：按钮按下时应用 `scaleY` 压缩，悬停时应用 `scaleX` 拉伸。保持体积恒定——若压缩 Y，则轻微扩展 X。

**预期动作**：展开下拉菜单前先缩小 2-3%。向左滑动内容前先向右移动 5px。

**舞台效果**：模态框聚焦时暗化背景元素。通过动效引导视线——先动画化重要元素。

**直接前进 vs 姿势到姿势**：使用 CSS `@keyframes` 实现可重复的、可预测的动画（姿势到姿势）。使用 JavaScript/GSAP 实现动态、基于物理的动效（直接前进）。

**追随与重叠**：子元素应在父元素停止运动后完成运动。使用递减值的 `animation-delay` 实现自然错开。

**缓入缓出**：UI 动效绝不用 `linear`。标准缓动：`cubic-bezier(0.4, 0, 0.2, 1)`。进入：`cubic-bezier(0, 0, 0.2, 1)`。退出：`cubic-bezier(0.4, 0, 1, 1)`。

**弧线**：自然界中的元素沿弧线运动而非直线。使用 `offset-path` 或结合 X/Y 变换与不同缓动。

**次要动作**：按钮悬停时阴影放大/模糊。按钮内图标旋转时按钮缩放。背景粒子随主要元素响应。

**时序**：微动效：100-200ms。标准过渡：200-400ms。复杂序列：400-700ms。页面过渡：300-500ms。

**夸张**：悬停状态缩放至 1.05-1.1 而非 1.01。错误抖动移动 10-20px 而非 2px。使动效明显但不刺眼。

**固体绘制**：保持一致的 `transform-origin`。使用 `perspective` 实现立体深度。避免冲突变换造成视觉错误。

**吸引力**：目标 60fps——仅当可能时使用 `transform` 和 `opacity`。通过自定义缓动曲线添加微妙个性。动效应显刻意。

## 代码模式

```css
/* 弹性按钮带压缩/拉伸 */
.button:active {
  transform: scale(0.95, 1.05);
  transition: transform 100ms cubic-bezier(0.4, 0, 0.2, 1);
}

/* 展开前的预期动作 */
.dropdown-enter {
  animation: dropdown-open 300ms cubic-bezier(0.34, 1.56, 0.64, 1);
}

@keyframes dropdown-open {
  0% { transform: scaleY(0.98); opacity: 0; }
  100% { transform: scaleY(1); opacity: 1; }
}
```

## 性能规则

1. 仅动画化 `transform` 和 `opacity` 以实现 GPU 加速
2. 少量使用 `will-change` 并在动画后移除
3. 动效可预测时优先使用 CSS
4. 在低功耗设备上测试
