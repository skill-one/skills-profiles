# 视频运动图形

将迪士尼的12条动画原理应用于After Effects、Premiere Pro和视频运动设计。

## 原理应用

**压缩与拉伸**：使用不同X/Y值的缩放属性。超调表达式创造弹性运动。形状图层比预合成更自然地变形用于有机压缩。

**预期**：在主要动作前添加2-4帧反向运动。为揭示效果蓄力——轻微缩小后再放大。位置预期：先向相反方向移动。

**舞台化**：使用景深引导焦点。暗角框定重要内容。次要元素添加运动模糊。构图引导视线至焦点。

**直线前进 vs 姿态到姿态**：传统逐帧动画用于角色动画。基于关键帧的动画用于图形动画。大多数运动图形是姿态到姿态的，带有表达式细化。

**后效 & 交错**：使用`valueAtTime()`表达式制造滞后。错开图层动画的偏移。次要元素在主要停止后继续4-8帧。父子关系带有延迟响应。

**缓入 / 缓出**：精通图形编辑器——绝不使用线性关键帧。Easy Ease是起点，自定义曲线。贝塞尔手柄控制加速度。速度图显示速度。

**弧线**：启用运动路径编辑。自动旋转对齐路径。添加漫游关键帧创造平滑弧线。自然运动很少直线行进。

**次要动作**：粒子响应主要运动。阴影和反射跟随。背景元素随视差移动。音频波形驱动视觉元素。

**节奏**：24fps：电影感，运动模糊必要。30fps：广播标准，更平滑。60fps：数字优先，非常平滑。定格帧（2秒、3秒）用于风格化节奏。

**夸张**：运动图形可以超越现实。比例超调至120-150%。旋转超出最终位置。色彩和效果可以强调夸张。

**立体绘画**：3D图层保持空间一致性。视差创造深度层级。元素间保持一致的光照方向。Z定位创造可信空间。

**吸引力**：平滑插值，无刺耳切换。色彩校正统一构图。字体有分量和个性。运动感觉有意且专业。

## After Effects技巧

### 超调表达式
```javascript
// 应用于任何属性以实现弹性超调
freq = 3;
decay = 5;
n = 0;
if (numKeys > 0) {
    n = nearestKey(time).index;
    if (key(n).time > time) n--;
}
if (n > 0) {
    t = time - key(n).time;
    amp = velocityAtTime(key(n).time - .001);
    w = freq * Math.PI * 2;
    value + amp * (Math.sin(t * w) / Math.exp(decay * t) / w);
} else {
    value;
}
```

### 错开表达式
```javascript
// 基于图层索引延迟
delay = 0.1;
d = delay * (index - 1);
time - d;
```

## 节奏参考

| 元素 | 持续时间 | 缓动 |
|------|----------|------|
| 文字揭示 | 15-25帧 | 缓出 |
| Logo动画 | 30-60帧 | 自定义曲线 |
| 过渡 | 10-20帧 | 缓入-缓出 |
| 下三分之一入 | 12-18帧 | 缓出 |
| 下三分之一出 | 8-12帧 | 缓入 |

## 导出考量

- 最终帧率预览
- 快速运动时启用运动模糊
- 1倍速度检查节奏，非RAM预览
- 考虑广播安全区域
- 在目标显示格式上测试
