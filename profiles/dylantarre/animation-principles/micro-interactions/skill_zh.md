# 微交互动画

将迪士尼12条动画原则应用于小型UI反馈时刻和界面细节。

## 快速参考

| 原则 | 微交互实现 |
|------|-----------|
| 压缩与拉伸 | 按钮按压压缩、切换弹跳 |
| 预期 | 悬停状态提示、点击前反馈 |
| 舞台化 | 将注意力集中于活动元素 |
| 平直前进/姿态到姿态 | 进度与状态变化 |
| 追随/重叠 | 涟漪效果、稳定运动 |
| 缓入/缓出 | 快速但平滑的过渡 |
| 弧线 | 切换开关、圆形菜单 |
| 次要动作 | 图标响应父级状态 |
| 时序 | 大多数交互100-300ms |
| 夸张 | 清晰但不分散注意力 |
| 线条绘制 | 一致的变换行为 |
| 吸引力 | 令人愉悦、有目的的反馈 |

## 原则应用

**压缩与拉伸**：按钮按压时轻微压缩（scaleY: 0.95）。切换滑块在触碰边界时压缩。通知徽章在更新时弹跳。保持微妙——这是UI而非卡通。

**预期**：悬停状态为点击做准备。按钮在点击动画前轻微抬起/变大。可拖拽元素在抓取开始时抬升。加载旋转器在旋转前加速。

**舞台化**：活动表单字段清晰区分。错误状态要求注意。成功确认不容置疑。一次交互反馈一个。

**平直前进与姿态到姿态**：进度指示器连续动画（平直前进）。复选框在状态间快速切换（姿态到姿态）。组合：加载指示器在状态变更时快速切换。

**追随与重叠**：涟漪效果扩展至点击点。切换开关先超出再稳定。复选标记在框填满后轻微延迟绘制。菜单项交错出现。

**缓入/缓出**：快速缓出以获得响应感。100ms缓出感觉即时。避免线性——看起来会损坏。快速进入，柔和稳定。

**弧线**：切换开关沿轻微弧线移动。圆形操作按钮径向扩展。下拉箭头平滑旋转。菜单项可沿曲线路径移动。

**次要动作**：图标随按钮状态变化而变色。徽章计数随父级通知更新。辅助文本随输入聚焦出现。阴影随高度变化。

**时序**：即时反馈：50-100ms。标准过渡：100-200ms。复杂微交互：200-300ms。任何更长时间都会让小UI感觉迟缓。

**夸张**：足够引人注意，但不过分分散注意力。错误抖动：3-5px，而非20px。成功缩放：1.05-1.1，而非1.5。微妙但不容忽视。

**线条绘制**：变换原点很重要——按钮从中心缩放，工具提示从指针。相似元素保持一致行为。动画期间保持视觉完整性。

**吸引力**：微交互增添个性而不至于压倒用户。用户应感觉界面响应灵敏且生动。小惊喜累积成整体体验质量。

## 组件模式

### 按钮状态
```css
.button {
    transition: transform 100ms ease-out,
                box-shadow 100ms ease-out;
}
.button:hover {
    transform: translateY(-1px);
    box-shadow: 0 2px 8px rgba(0,0,0,0.15);
}
.button:active {
    transform: translateY(0) scale(0.98);
    box-shadow: 0 1px 2px rgba(0,0,0,0.1);
}
```

### 切换开关
```css
.toggle-thumb {
    transition: transform 200ms cubic-bezier(0.34, 1.56, 0.64, 1);
}
.toggle-thumb.active {
    transform: translateX(20px);
}
```

### 复选框
```css
.checkmark {
    stroke-dasharray: 20;
    stroke-dashoffset: 20;
    transition: stroke-dashoffset 200ms ease-out 50ms;
}
.checkbox:checked + .checkmark {
    stroke-dashoffset: 0;
}
```

## 时序参考

| 交互 | 持续时间 | 缓动 |
|------|----------|------|
| 悬停 | 100ms | ease-out |
| 点击/轻点 | 100ms | ease-out |
| 切换 | 150-200ms | spring/elastic |
| 复选框 | 150ms | ease-out |
| 聚焦环 | 100ms | ease-out |
| 工具提示显示 | 150ms | ease-out |
| 工具提示隐藏 | 100ms | ease-in |
| 徽章更新 | 200ms | elastic |
| 表单错误 | 200ms | ease-out |

## 最佳实践

1. 每个交互元素都需要反馈
2. 禁用状态：无动画，降低不透明度
3. 将相关反馈组合在一起
4. 不要对每个变更都动画——过滤不必要的更新
5. 无动画测试——功能不应依赖它
6. 尊重`prefers-reduced-motion`
