# ADK 快速参考

> **目前仅支持 Python。** 本快速参考当前涵盖 Python ADK SDK。
> 对其他语言的支持即将到来。

## 参考文件

| 文件 | 内容 |
|------|----------|
| `references/python.md` | Python ADK API 快速参考 — agent（代理）、tools（工具）、auth（认证）、orchestration（编排）、callbacks（回调）、plugins（插件）、state（状态）、artifacts（工件）、context caching/compaction（上下文缓存/压缩）、session rewind（会话回放） |
阅读 `references/python.md` 获取完整的 API 快速参考。

要获取 ADK 文档索引（文档页面的标题和 URL），请使用 `curl https://adk.dev/llms.txt`。

> **要创建一个新的 agent 项目？** 使用 `/adk-scaffold` 而不是 — 这个技能用于在现有项目中编写代码。
