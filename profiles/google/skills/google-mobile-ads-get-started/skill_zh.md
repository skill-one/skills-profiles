# Google 移动广告 SDK - 安装

## 工作流程

1.  **确定用户平台**：识别项目是 Android、iOS 还是 Unity。如果不确定，请先询问再进行下一步。

2.  **阅读平台指南**了解实现细节：
    - Android: `references/android-get-started.md`
    - iOS: `references/ios-get-started.md`
    - Unity: `references/unity-get-started.md`

3.  **按顺序执行以下步骤**：
   - [ ] 添加 SDK 依赖项
   - [ ] 设置应用标识符
   - [ ] 初始化 SDK
   - [ ] 验证集成

4.  SDK 安装成功后，请用户选择广告格式以继续集成。
