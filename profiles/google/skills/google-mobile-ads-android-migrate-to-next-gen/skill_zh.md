# Google Mobile Ads SDK 迁移代理说明

## 迁移工作流

使用此清单来跟踪您的迁移进度：

*   **配置 Gradle**：
    -   [ ] 将 `com.google.android.gms:play-services-ads` 替换为最新稳定版本的 `com.google.android.libraries.ads.mobile.sdk:ads-mobile-sdk`。如果您无法直接访问 Maven，请运行以下命令来获取最新版本。`latest` 标签中返回的版本是 GMA Next-Gen SDK 的最新版本：

        ```bash
        curl -sS https://dl.google.com/dl/android/maven2/com/google/android/libraries/ads/mobile/sdk/ads-mobile-sdk/maven-metadata.xml | sed -n 's/.*<latest>\(.*\)<\/latest>.*/\1/p'
        ```

    -   [ ] 更新 `minSdk` (24+) 和 `compileSdk` (34+)。
    -   [ ] 在应用级别的构建文件中全局排除 `play-services-ads` 和 `play-services-ads-lite`，以避免重复符号错误。
    -   [ ] 在进入下一步之前同步 Gradle。
*   **逐文件迁移**：
    -   [ ] 按照 API 映射表和方法映射表重构代码库，将导入、类名和方法签名迁移到 GMA Next-Gen SDK。
*   **验证和构建**：
    -   [ ] 运行 `gradle build -x test` 以确认成功进行干净的构建。解决任何与 GMA SDK 相关的编译错误。

## 核心迁移规则

*   **App ID 使用**：**始终**使用 `AndroidManifest.xml` 中 `com.google.android.gms.ads.APPLICATION_ID` 元数据标签的值作为 `InitializationConfig` 中的 `applicationId`。
    *   *约束*：在清单中保留 `<meta-data>` 标签；它仍然需要用于使用用户消息平台 SDK 的发布商。
*   **初始化顺序**：
    1.  在后台线程上调用 `MobileAds.initialize()`。
    2.  确保 `initialize()` 在任何其他 SDK 方法之前被调用。
    3.  如果使用 `RequestConfiguration`，将其捆绑到 `InitializationConfig.Builder.setRequestConfiguration()`。**不要**在初始化之前调用 `MobileAds.setRequestConfiguration()`。
*   **UI 线程**：**强制要求**：GMA-Next Gen SDK 中的回调在后台线程上被调用。**所有与 UI 相关的操作**（例如 Toast、视图更新、Fragment 事务）**必须**在 GMA SDK 回调内部用 `runOnUiThread {}` 或 `Dispatchers.Main.launch {}` 包裹。跳过此步骤将导致应用程序崩溃。
*   **中介**：实现 `com.google.android.gms.ads.mediation.Adapter` 的类**必须**继续使用 `com.google.android.gms.ads`。

## 格式特定说明

### Banner 广告

*   使用 `com.google.android.libraries.ads.mobile.sdk.banner.AdView` 来加载 GMA Next-Gen SDK 的 Banner 广告。
*   以下 API 用于检查 Banner 是否可折叠：
    `adView.getBannerAd().isCollapsible()`。

### Native 广告

*   **NativeAdLoader**：`NativeAdLoader` 是抽象的，不能被实例化。它用于静态方式（例如，`NativeAdLoader.load(...)`）。
*   以下 API 现在设置在 `NativeAdRequest.Builder` 上：
    *   `.setCustomFormatIds(customFormatIds: List<String>)`
    *   `.disableImageDownloading()`
    *   `.setMediaAspectRatio(mediaAspectRatio: NativeMediaAspectRatio)`
    *   `.setAdChoicesPlacement(adChoicesPlacement: AdChoicesPlacement)`
    *   `.setVideoOptions(videoOptions: VideoOptions)`
*   **移除**：删除所有 "Mute This Ad" 逻辑；它在 GMA Next-Gen SDK 中不受支持。
*   **MediaView**：`NativeAd` 不再具有直接的 `mediaView` 变量；使用 `registerNativeAd(nativeAd, mediaView)` 将广告与视图关联起来。

### 广告预加载

*   除非映射表中指定，否则 GMA Next-Gen SDK 中的广告预加载方法与旧 SDK 具有相同的 API 签名和参数。
