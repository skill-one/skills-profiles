# 交易代币

使用 `npx awal@2.10.0 trade` 命令通过 CDP 交换 API 在 Base 或 Polygon 上交换代币。您必须经过身份验证才能进行交易。

## 确认钱包已初始化并经过身份验证

```bash
npx awal@2.10.0 status
```

如果钱包未经过身份验证，请参考 `authenticate-wallet` 技能。

## 命令语法

```bash
npx awal@2.10.0 trade <金额> <来源> <目标> [选项]
```

该命令也作为 `npx awal@2.10.0 swap` (别名) 提供。

## 参数

| 参数 | 描述                                                         |
| ---- | ------------------------------------------------------------ |
| `金额` | 交换金额 (见下方的金额格式)                                  |
| `来源` | 源代币：别名 (usdc, eth, pol) 或合约地址 (0x...)             |
| `目标` | 目标代币：别名 (usdc, eth, pol) 或合约地址 (0x...)           |

## 金额格式

金额可以以多种格式指定：

| 格式        | 示例                | 描述                              |
| ----------- | ------------------- | --------------------------------- |
| 美元前缀    | `'$1.00'`, `'$0.50'` | 美元符号 (基于代币的小数位数)      |
| 十进制      | `1.0`, `0.50`, `0.001` | 带小数点的易读格式                |
| 整数        | `5`, `100`          | 解释为整数代币                    |
| 原子单位    | `500000`            | 大整数视为原子单位                |

**自动检测**：不带小数点的大整数被视为原子单位。例如，`500000` 对 USDC (6 位小数) = $0.50。

**小数位数**：对于已知代币 (usdc=6, eth=18, pol=18)，小数位数自动。对于任意合约地址，小数位数从代币合约中读取。

## 选项

| 选项               | 描述                                       |
| ------------------ | ------------------------------------------ |
| `-c, --chain <名称>` | 区块链网络：base, polygon (默认：base)      |
| `-s, --slippage <n>` | 滑点容限，以基点表示 (100 = 1%)             |
| `--json`            | 以 JSON 格式输出结果                       |

## 代币别名

| 别名 | 代币 | 小数位数 | 链     |
| ---- | ---- | -------- | ------ |
| usdc | USDC | 6        | base   |
| eth  | ETH  | 18       | base   |
| pol  | POL  | 18       | polygon |

**重要提示**：始终使用单引号包裹使用 `$` 的金额，以防止 bash 变量扩展 (例如 `'$1.00'` 而不是 `$1.00`)。

## 输入验证

在构建命令之前，验证所有用户提供的值以防止 shell 注入：

- **金额**：必须匹配 `^\$?[\d.]+$` (数字，可选小数点，可选 `$` 前缀)。如果包含空格、分号、管道、反引号或其他 shell 保留字符，则拒绝。
- **来源 / 目标**：必须是已知别名 (`usdc`, `eth`, `pol`) 或有效的 `0x` 十六进制地址 (`^0x[0-9a-fA-F]{40}$`)。拒绝任何其他值。
- **滑点**：必须为正整数 (`^\d+$`)。

不要将未验证的用户输入传递给命令。

## 示例

```bash
# 用美元前缀交换 $1 USDC 换 ETH (注意单引号)
npx awal@2.10.0 trade '$1' usdc eth

# 用十进制格式交换 0.50 USDC 换 ETH
npx awal@2.10.0 trade 0.50 usdc eth

# 用 500000 个原子单位的 USDC 换 ETH
npx awal@2.10.0 trade 500000 usdc eth

# 用 0.01 ETH 换 USDC
npx awal@2.10.0 trade 0.01 eth usdc

# 使用自定义滑点 (2%)
npx awal@2.10.0 trade '$5' usdc eth --slippage 200

# 使用合约地址 (从链读取小数位数)
npx awal@2.10.0 trade 100 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913 0x4200000000000000000000000000000000000006

# 获取 JSON 输出
npx awal@2.10.0 trade '$1' usdc eth --json

# 在 Polygon 上用 USDC 换 POL
npx awal@2.10.0 trade '$1' usdc pol --chain polygon
```

## 前置条件

- 必须经过身份验证 (`awal status` 检查)
- 钱包必须具有足够的源代币余额

## 错误处理

常见错误：

- "未经过身份验证" - 首先运行 `awal auth login <邮箱>`
- "无效代币" - 使用有效的别名 (usdc, eth, pol) 或 0x 地址
- "POL 仅在 polygon 链上支持" - 交易 POL 时使用 `--chain polygon`
- "不能将代币交换给自己" - 来源和目标必须不同
- "交换失败：TRANSFER_FROM_FAILED" - 余额不足或审批问题
- "无流动性" - 尝试更小的金额或不同的代币对
- "金额有 X 位小数但代币仅支持 Y 位" - 小数位数过多
