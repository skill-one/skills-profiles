# Obsidian 画布创建器

将文本内容转换为结构化的 Obsidian 画布文件，支持思维导图和自由布局。

## 何时使用此技能

- 用户请求从文本创建画布、思维导图或视觉图表
- 用户希望空间性地组织信息
- 用户提到 "Obsidian 画布" 或类似的可视化工具
- 将结构化内容（文章、笔记、提纲）转换为视觉格式

## 核心工作流程

### 1. 分析内容

读取和理解输入内容：
- 识别主要主题和层级关系
- 提取要点、事实和支撑细节
- 记录任何现有结构（标题、列表、章节）

### 2. 确定布局类型

询问用户选择或从上下文中推断：

**思维导图布局：**
- 从中心呈放射状结构
- 父子关系
- 清晰的层级
- 适用于：头脑风暴、主题探索、层级内容

**自由布局：**
- 自定义位置
- 灵活的关系
- 多种连接类型
- 适用于：复杂网络、非层级内容、自定义排列

### 3. 规划结构

**对于思维导图：**
- 确定中心概念（根节点）
- 绘制主要分支（主要主题）
- 组织次要分支（子主题）
- 定位叶节点（细节）

**对于自由布局：**
- 分组相关概念
- 识别连接模式
- 规划空间区域
- 考虑视觉流向

### 4. 生成画布

创建遵循画布规范的 JSON：

**节点创建：**
- 分配唯一的 8-12 字符十六进制 ID
- 根据内容长度设置适当尺寸
- 应用一致的配色方案
- 确保无坐标重叠

**边创建：**
- 连接父子关系
- 使用适当的箭头样式
- 为复杂关系添加标签
- 选择线型（直线用于层级，曲线用于交叉引用）

**分组（可选）：**
- 为相关节点创建视觉容器
- 使用微妙的背景颜色
- 添加描述性标签

### 5. 应用布局算法

**思维导图布局计算：**

参考 `references/layout-algorithms.md` 获取详细算法。关键原则：

- 中心根节点位于 (0, 0)
- 主要节点呈放射状分布
- 根据兄弟节点数量分配次要节点
- 保持最小间距：水平 320px，垂直 200px

**自由布局原则：**

- 从逻辑分组开始
- 清晰分离地定位分组
- 使用曲线连接跨分组
- 在画布上平衡视觉权重

### 6. 验证和输出

输出前：

**验证清单：**
- 所有节点具有唯一 ID
- 无坐标重叠（检查距离 > 节点尺寸 + 间距）
- 所有边引用有效节点 ID
- 分组（如有）具有标签
- 颜色使用一致格式（十六进制或预设数字）
- JSON 正确转义（中文引号：『』用于双引号，「」用于单引号）

**输出格式：**
- 完整、有效的 JSON 画布文件
- 无额外说明文本
- 可直接导入 Obsidian

## 节点尺寸指南

**基于文本长度调整尺寸：**
- 短文本（<30 字符）：220 × 100 px
- 中等文本（30-60 字符）：260 × 120 px  
- 长文本（60-100 字符）：320 × 140 px
- 非常长文本（>100 字符）：320 × 180 px

## 配色方案

**预设颜色（推荐）：**
- `"1"` - 红色（警告、重要）
- `"2"` - 橙色（行动项）
- `"3"` - 黄色（问题、笔记）
- `"4"` - 绿色（积极、已完成）
- `"5"` - 青色（信息、细节）
- `"6"` - 紫色（概念、抽象）

**自定义十六进制颜色：**
用于品牌一致性或特定主题。始终使用大写格式：`"#4A90E2"`

## 严格规则

1. **引号处理：**
   - 中文双引号 → 『』
   - 中文单引号 → 「」
   - 英文双引号 → `\"`

2. **ID 生成：**
   - 8-12 字符随机十六进制字符串
   - 必须在所有节点和边中唯一

3. **Z-Index 顺序：**
   - 先输出分组（底层）
   - 然后子分组
   - 最后文本/链接节点（顶层）

4. **间距要求：**
   - 最小水平间距：节点中心间 320px
   - 最小垂直间距：节点中心间 200px
   - 计算时考虑节点尺寸

5. **JSON 结构：**
   - 顶层仅包含 `nodes` 和 `edges` 数组
   - 无额外包装对象
   - 输出中无注释

6. **禁止使用 Emoji：**
   - 节点文本中不要使用任何 Emoji 符号
   - 使用颜色编码或文本标签代替进行视觉区分

## 示例

### 简单思维导图请求
用户："创建关于太阳系行星的思维导图"

处理：
1. 确定中心："太阳系"
2. 主要分支：内行星、外行星、矮行星
3. 次要节点：单个行星及其关键事实
4. 应用放射状布局
5. 生成具有适当间距的 JSON

### 自由布局内容请求
用户："将这篇文章转换为画布" + [文章文本]

处理：
1. 提取文章结构（引言、正文章节、结论）
2. 识别关键概念和关系
3. 空间上分组相关章节
4. 使用带标签的边连接
5. 应用自由布局并划分清晰区域

## 高质量画布技巧

1. **保持文本简洁**：每个节点应可快速浏览（建议不超过 2 行）
2. **使用层级结构**：按重要性和关系分组
3. **平衡画布**：分布节点避免聚集
4. **策略性使用颜色**：用颜色编码含义而非仅装饰
5. **有意义连接**：仅添加澄清关系的边
6. **在 Obsidian 中测试**：验证输出是否正确打开

## 常见错误避免

- 节点重叠（始终检查距离）
- 引号转义不一致（破坏 JSON 解析）
- 缺少分组标签（导致侧边栏导航问题）
- 节点文本过多（使用文件节点处理长内容）
- ID 重复（每个必须唯一）
- 未连接的节点（除非有意形成孤岛）
