# Anthropic Brand Styling

## 概览

要访问 Anthropic 的官方品牌身份和风格资源，请使用此技能。

**关键词**：品牌塑造、企业形象、视觉形象、后期处理、风格设计、品牌色彩、字体设计、Anthropic 品牌、视觉格式、视觉设计

## 品牌规范

### 色彩

**主要色彩：**

- Dark: `#141413` - 主要文本和深色背景
- Light: `#faf9f5` - 浅色背景和深色背景上的文本
- Mid Gray: `#b0aea5` - 次要元素
- Light Gray: `#e8e6dc` - 细微背景

**强调色：**

- Orange: `#d97757` - 主要强调色
- Blue: `#6a9bcc` - 次要强调色
- Green: `#788c5d` - 三级强调色

### 字体设计

- **标题**：Poppins（回退到 Arial）
- **正文**：Lora（回退到 Georgia）
- **说明**：为获得最佳效果，字体应在您的环境中预装

## 功能

### 智能字体应用

- 将 Poppins 字体应用于标题（24pt 及更大）
- 将 Lora 字体应用于正文
- 如果无法使用自定义字体，则自动回退到 Arial/Georgia
- 在所有系统中保持可读性

### 文本样式

- 24pt 及以上的标题：Poppins 字体
- 正文：Lora 字体
- 根据背景智能选择颜色
- 保持文本层次和格式

### 形状和强调色

- 非文本形状使用强调色
- 在橙色、蓝色和绿色强调色之间循环
- 在保持品牌一致性的同时，保持视觉吸引力

## 技术细节

### 字体管理

- 在可用时使用系统安装的 Poppins 和 Lora 字体
- 为标题（Arial）和正文（Georgia）提供自动回退
- 无需安装字体 - 可与现有的系统字体配合工作
- 为获得最佳效果，请预先在您的环境中安装 Poppins 和 Lora 字体

### 颜色应用

- 使用 RGB 颜色值进行精确的品牌匹配
- 通过 python-pptx 的 RGBColor 类进行应用
- 在不同系统中保持颜色保真度
