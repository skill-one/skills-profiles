算法哲学是计算美学运动，通过代码表达出来。输出 .md 文件（哲学）、.html 文件（交互式查看器）和 .js 文件（生成式算法）。

这个过程分为两个步骤：
1. 算法哲学创建 (.md 文件)
2. 通过创建 p5.js 生成式艺术来表现 (.html + .js 文件)

首先，进行这项任务：

## 算法哲学创建

首先，创建一个算法哲学（不是静态图像或模板），它将通过以下方式被解释：
- 计算过程、涌现行为、数学之美
- 种子式随机性、噪声场、有机系统
- 粒子、流动、场、力
- 参数化变化和受控混沌

### 关键理解
- 接收到的：用户的一些微妙输入或指令，需要考虑，但应将其作为基础；不应限制创作自由。
- 创建的：算法哲学/生成式美学运动。
- 接下来的：同一版本接收哲学并使用代码表达它——创建 90% 算法生成、10% 基本参数的 p5.js 绘图。

考虑这种方法：
- 为生成式艺术运动撰写宣言
- 下一个阶段涉及编写使其生动起来的算法

哲学必须强调：算法表达。涌现行为。计算之美。种子式变化。

### 如何生成算法哲学

**命名运动**（1-2 个词）："有机湍流" / "量子谐振" / "涌现静止"

**阐述哲学**（4-6 段落——简洁但完整）：

为了捕捉算法的本质，表达这个哲学如何通过以下方式体现：
- 计算过程和数学关系？
- 噪声函数和随机模式？
- 粒子行为和场动力学？
- 时间演化和系统状态？
- 参数化变化和涌现复杂性？

**关键指南：**
- **避免冗余**：每个算法方面只应提及一次。除非增加新的深度，否则避免重复关于噪声理论、粒子动力学或数学原理的概念。
- **强调工艺**：哲学必须反复强调，最终的算法应看起来像是花费了无数小时开发、精心打磨、来自该领域绝对顶尖的人的作品。这种框架至关重要——重复短语如“精心设计的算法”、“深层次计算专长的产物”、“痛苦的优化”、“大师级实现”。
- **留出创作空间**：具体说明算法方向，但要简洁到足以让下一个 Claude 在极高水平工艺下进行解释性实现选择。

哲学必须引导下一个版本以算法方式表达思想，而不是通过静态图像。美存在于过程，而不是最终帧。

### 哲学示例

**"有机湍流"**
哲学：受自然法则约束的混沌，从混乱中产生秩序。
算法表达：由多层 Perlin 噪声驱动的流场。数千个粒子跟随矢量力，它们的轨迹累积成有机密度图。多个噪声八度创造湍流区域和宁静区域。速度和密度产生颜色——快速粒子燃烧得明亮，慢速粒子渐变为阴影。算法运行直至平衡——精心调谐的平衡，其中每个参数都通过无数次迭代由计算美学大师进行优化。

**"量子谐振"**
哲学：离散实体表现出波浪状干涉模式。
算法表达：粒子初始化在网格上，每个粒子携带一个随正弦波演变的相位值。当粒子靠近时，它们的相位发生干涉——建设性干涉产生明亮节点，破坏性干涉产生虚空。简单的谐波运动产生复杂的涌现曼陀罗。结果是痛苦的频率校准，其中每个比率都经过精心选择以产生共振之美。

**"递归低语"**
哲学：跨尺度的自相似性，有限空间中的无限深度。
算法表达：递归细分分支的结构。每个分支略有随机性，但受黄金比例约束。L-系统或递归细分生成类似树的结构，既感觉数学又感觉有机。微妙的噪声扰动打破完美对称。线权重随每次递归级别减小。每个分支角度都是深度数学探索的产物。

**"场动力学"**
哲学：通过它们对物质的影响使无形的力量可见。
算法表达：由数学函数或噪声构建的矢量场。粒子在边缘诞生，沿着场线流动，在达到平衡或边界时死亡。多个场可以吸引、排斥或旋转粒子。可视化只显示轨迹——无形力量的幽灵般证据。通过力平衡精心编排的计算之舞。

**"随机结晶"**
哲学：随机过程结晶成有序结构。
算法表达：随机圆圈排列或 Voronoi 分割。从随机点开始，让它们通过松弛算法演变。单元相互推挤直至平衡。基于单元大小、邻居数量或中心距离的颜色。产生的有机瓦片感觉既随机又不可避免。每个种子都产生独特的结晶之美——大师级生成算法的标志。

*这些都是精简示例。实际的算法哲学应该是 4-6 段实质性的段落。*

### 基本原则
- **算法哲学**：创建一个计算世界观，通过代码表达
- **过程重于结果**：始终强调美源于算法的执行——每次运行都是独特的
- **参数化表达**：思想通过数学关系、力、行为传达，而不是静态构图
- **艺术自由**：下一个 Claude 以算法方式解释哲学——提供创作实施空间
- **纯生成式艺术**：这是关于制作活的算法，而不是带随机性的静态图像
- **专家工艺**：反复强调最终算法必须感觉精心设计、通过无数次迭代优化、是计算美学领域绝对顶尖的人的深层次专长产物

**算法哲学应该是 4-6 段落长。** 用充满诗意的计算哲学来指导意图。避免重复相同点。将这个算法哲学作为 .md 文件输出。

## 推断概念种子

**关键步骤**：在实现算法之前，从原始请求中识别微妙的理念线索。

**基本原则**：
概念是一个**嵌入在算法本身中的微妙、利基参考**——不一定是字面的，总是复杂的。熟悉主题的人会直观地感受到它，而其他人只是体验到了精湛的生成式构图。算法哲学提供了计算语言。推断出的概念提供了灵魂——无形地编织在参数、行为和涌现模式中的安静概念 DNA。

这是**非常重要**的：参考必须如此精致，以至于它能增强作品的深度，而不宣告自己。像爵士乐手通过算法和声引用另一首歌——只有知道的人才能捕捉到它，但每个人都欣赏生成式之美。

### 技术要求

**种子式随机性（Art Blocks 模式）**：
```javascript
// 始终使用种子以实现可重复性
let seed = 12345; // 或用户输入的哈希值
randomSeed(seed);
noiseSeed(seed);
```

**参数结构——遵循哲学**：

为了建立从算法哲学中自然产生的参数，考虑：“这个系统的哪些特性可以调整？”

```javascript
let params = {
  seed: 12345,  // 始终包含种子以实现可重复性
  // 颜色
  // 添加控制您的算法的参数：
  // - 数量（多少个？）
  // - 尺度（多大？多快？）
  // - 概率（多可能？）
  // - 比率（什么比例？）
  // - 角度（什么方向？）
  // - 阈值（行为何时改变？）
};
```

**设计有效参数时，专注于系统需要可调的特性，而不是从“模式类型”的角度思考。**

**核心算法——表达哲学**：

**关键**：算法哲学应决定要构建什么。

为了通过代码表达哲学，避免思考“我应该使用哪种模式？”而应思考“如何通过代码表达这个哲学？”

如果哲学是关于**有机涌现**，可以考虑使用：
- 随时间累积或生长的元素
- 受自然规则约束的随机过程
- 反馈回路和交互

如果哲学是关于**数学之美**，可以考虑使用：
- 几何关系和比率
- 三角函数和谐波
- 精确计算产生意想不到的模式

如果哲学是关于**受控混沌**，可以考虑使用：
- 在严格边界内的随机变化
- 分叉和相变
- 混乱中产生秩序

**算法从哲学中流淌，而不是从选项菜单中流淌。**

为了指导实现，让概念本质指导创意和原创选择。构建一个表达此请求特定愿景的东西。

**画布设置**：标准的 p5.js 结构：
```javascript
function setup() {
  createCanvas(1200, 1200);
  // 初始化您的系统
}

function draw() {
  // 您的生成式算法
  // 可以是静态（noLoop）或动画
}
```

### 工艺要求

**关键**：为了达到精通，创建算法，使其感觉像是通过无数次迭代由精通生成式艺术的大师产生的。小心地调整每个参数。确保每个模式都有目的。这不是随机噪声——这是受控混沌，通过深度专业知识进行优化。

- **平衡**：复杂性而不视觉噪声，秩序而不僵化
- **色彩和谐**：深思熟虑的调色板，而不是随机的 RGB 值
- **构图**：即使在随机中，也要保持视觉层次和流动
- **性能**：流畅执行，针对实时动画进行优化
- **可重复性**：相同的种子始终产生相同的输出

### 输出格式

输出：
1. **算法哲学**——作为 markdown 或解释生成式美学的文本
2. **单个 HTML 文件**——从 `templates/viewer.html` 构建的自我包含的交互式生成艺术（见步骤 0 和下一节）

HTML 文件包含所有内容：p5.js（来自 CDN）、算法、参数控制、UI——所有内容都在一个文件中，可以立即在 claude.ai 艺术品或任何浏览器中工作。从模板文件开始，而不是从头开始。

## 交互式艺术品创建

**提醒**：`templates/viewer.html` 应该已经阅读过（见步骤 0）。将其作为起点使用。

为了允许探索生成式艺术，创建一个自我包含的 HTML 艺术品。确保此艺术品可以立即在 claude.ai 或任何浏览器中工作——无需设置。内嵌所有内容。

### 关键：什么是固定 vs 可变

`templates/viewer.html` 文件是基础。它包含所需的精确结构和样式。

**固定（始终按所示完全包含）**：
- 布局结构（页眉、侧边栏、主画布区域）
- Anthropic 品牌化（UI 颜色、字体、渐变）
- 侧边栏中的种子部分：
  - 种子显示
  - 上一个/下一个/随机/跳转按钮
  - 随机按钮
  - 跳转至种子输入 + Go 按钮
- 侧边栏中的操作部分：
  - 重新生成按钮
  - 重置按钮

**可变（为每个艺术品自定义）**：
- 整个 p5.js 算法（setup/draw/classes）
- 参数对象（定义艺术品需要什么）
- 侧边栏中的参数部分：
  - 参数控制的数量
  - 参数名称
  - 滑块的 min/max/step 值
  - 控制类型（滑块、输入等）
- 颜色部分（可选）：
  - 如果用户应控制调色板，则添加颜色选择器
  - 如果艺术品使用固定颜色，则跳过此部分
  - 如果艺术品是单色的，则不需要颜色控制
  - 根据艺术品的需要决定

**每个艺术品应有独特的参数和算法！** 固定部分提供一致的 UX——其他所有内容都表达独特的愿景。

### 必须具备的功能

**1. 参数控制**
- 用于数值参数的滑块（粒子数量、噪声比例、速度等）
- 颜色选择器用于调色板颜色
- 参数更改时实时更新
- 重置按钮以恢复默认值

**2. 种子导航**
- 显示当前种子编号
- “上一个”和“下一个”按钮以循环种子
- “随机”按钮用于随机种子
- 输入字段以跳转到特定种子
- 请求时生成 100 个变化（种子 1-100）

**3. 单一文件结构**
```html
<!DOCTYPE html>
<html>
<head>
  <!-- p5.js 从 CDN - 始终可用 -->
  <script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.7.0/p5.min.js"></script>
  <style>
    /* 所有样式内联 - 简洁、最小化 */
    /* 画布在顶部，控制在下部 */
  </style>
</head>
<body>
  <div id="canvas-container"></div>
  <div id="controls">
    <!-- 所有参数控制 -->
  </div>
  <script>
    // 所有 p5.js 代码内联在此处
    // 参数对象、类、函数
    // setup() 和 draw()
    // UI 处理程序
    // 一切自我包含
  </script>
</body>
</html>
```

**关键**：这是一个单一的艺术品。没有外部文件，没有导入（除了 p5.js CDN）。所有内容内联。

**4. 实现细节——构建侧边栏**

侧边栏结构：

**1. 种子（固定）**——始终按所示包含：
- 种子显示
- 上一个/下一个/随机/跳转按钮

**2. 参数（可变）**——为艺术品创建控制：
```html
<div class="control-group">
    <label>参数名称</label>
    <input type="range" id="param" min="..." max="..." step="..." value="..." oninput="updateParam('param', this.value)">
    <span class="value-display" id="param-value">...</span>
</div>
```
根据参数数量添加尽可能多的 control-group div。

**3. 颜色（可选/可变）**——如果艺术品需要可调整颜色，则包含：
- 如果用户应控制调色板，则添加颜色选择器
- 如果艺术品使用固定颜色，则跳过此部分
- 如果艺术品是单色的，则不需要颜色控制

**4. 操作（固定）**——始终按所示包含：
- 重新生成按钮
- 重置按钮
- 下载 PNG 按钮

**要求**：
- 种子控制必须工作（上一个/下一个/随机/跳转/显示）
- 所有参数必须有 UI 控制
- 重新生成、重置、下载按钮必须工作
- 保持 Anthropic 品牌化（UI 样式，不是艺术品颜色）

### 使用艺术品

HTML 艺术品可以立即工作：
1. **在 claude.ai**：作为交互式艺术品显示——立即运行
2. **作为文件**：保存并在任何浏览器中打开——无需服务器
3. **分享**：发送 HTML 文件——它是完全自我包含的

## 创作过程

**用户请求** → **算法哲学** → **实现**

每个请求都是独特的。过程包括：

1. **解释用户的意图**——正在寻求什么样的美学？
2. **创建算法哲学**（4-6 段落）描述计算方法
3. **用代码实现它**——构建表达此哲学的算法
4. **设计适当的参数**——什么应该可调？
5. **构建匹配的 UI 控制**——用于这些参数的滑块/输入

**常数**：
- Anthropic 品牌化（颜色、字体、布局）
- 种子导航（始终存在）
- 自我包含的 HTML 艺术品

**变量**：
- 算法本身
- 参数
- UI 控制
- 视觉结果

为了获得最佳结果，信任创造力，并让哲学指导实现。
