## 工作流程

### 1. 明确需求
- **询问用户**：单页幻灯片或多页幻灯片（3-4页）？
- **询问用户**：是否有任何特定的关注领域或主题需要强调？
- **仅在使用户确认后**，才进行调研

### 2. 调研与规划
**数据来源：**
- **主要来源**：公司申报文件（BamSEC、SEC EDGAR - "第1项. 业务"，MD&A），投资者演示文稿，公司网站
- **市场数据**：Bloomberg、FactSet、CapIQ（价格、股份数量、市值、净债务、企业价值、持股情况）
- **预测**：FactSet/CapIQ对NTM收入、EBITDA、EPS的共识
- **新闻**：过去90天的新闻稿、并购活动、指引变更

**所需指标：**
- **财务指标**：收入、EBITDA、利润率（%）、EPS、FCF（±3年）
- **估值**：市值、企业价值、收入倍数、EBITDA倍数、市盈率倍数
- **增长率**：同比增长率（%）
- **持股情况**：前五大股东及其持股比例
- **业务板块**：产品组合和/或地域组合（%细分）

**标准化：**
- 将所有金额转换为一致货币
- 保持一致的比例（全程使用$mm或$bn，不混合使用）

**在构建之前：**
- 打印大纲以与用户讨论（每个项目4-5个要点）（实际数字，无占位符）
- 打印样式选择：字体、颜色（十六进制代码）、每个数据集的图表类型
- 获取用户确认：“此大纲和视觉策略是否符合您的愿景？”

### 3. 幻灯片逐页创建
**关键：**您必须一次创建一个幻灯片，并在继续下一个幻灯片之前获得用户批准。

**对于每个幻灯片：**
1. 使用PptxGenJS仅创建此一个幻灯片
2. **强制要求：转换为图像进行审查** - 您必须将幻灯片转换为图像以便进行视觉验证：
   ```bash
   soffice --headless --convert-to pdf presentation.pptx
   pdftoppm -jpeg -r 150 -f 1 -l 1 presentation.pdf slide
   ```
3. **强制视觉审查**：在继续之前，您必须仔细检查渲染的幻灯片图像：
   - **文本重叠检查**：扫描每个文本元素 - 是否有任何标签、项目符号或标题相互碰撞？
   - **文本截断检查**：是否有任何文本在边界处被截断？所有单词是否都完全可见？
   - **图表边界检查**：图表是否保持在它们的容器内？所有轴标签是否都完全可见？
   - **象限完整性**：一个象限中的内容是否渗入相邻象限？
4. **如果检测到任何重叠或截断**：立即使用以下策略按顺序修复：
   - **首先**：减小字体大小（向下调整1-2pt）
   - **其次**：缩短文本（缩写，删除不太关键的信息）
   - **第三**：调整元素位置或容器大小
   - **重新渲染并再次验证** - 直至所有文本整洁地排列，才可继续
5. 向用户展示幻灯片图像并附带下载链接
6. **停止并等待明确的用户批准**，然后再创建下一个幻灯片。在用户确认之前，不要继续。

**您必须在每一页上检查以下特定问题：**
- 表格行与下方文本冲突
- 图表x轴标签在底部被截断
- 长项目符号绕入相邻内容
- 象限内容渗入相邻象限
- 标题文本与下方内容重叠
- 图例文本与图表元素重叠
- 页脚/来源文本与主要内容冲突

## 幻灯片格式要求

### 信息密度至关重要

**首要目标是最大信息密度。** 忙碌的高管应在30秒内理解整个公司故事。填满每个象限至极限。

**每个象限目标：**
- **公司概览**：至少6-8个要点（总部、成立时间、员工人数、CEO/CFO、市值、股票代码、行业、关键数据）
- **业务与定位**：6-8个要点（收入驱动因素、产品、市场份额%、竞争优势、客户数量、地域组合）
- **关键财务指标**：8-10行表格或图表+4-5个关键指标（收入、EBITDA、利润率、EPS、FCF、增长率、估值倍数）
- **第四象限**：5-7个要点（持股比例、近期并购、发展动态、催化剂）

**信息打包技巧：**
- 合并相关事实：“总部：奥斯汀，德克萨斯州；成立时间：2003年；140,000名员工”
- 始终包含数字：“收入$50B”而不是“大型收入”
- 添加上下文：“EBITDA利润率：25%（高于行业平均18%）”
- 包含同比增长变化：“收入：$125M（同比增长28%）”
- 使用百分比：“企业价值占收入的62%”

**如果一个象限看起来过于稀疏，请添加更多：**
- 业务板块细分（%）
- 地域收入细分
- 客户集中度（前10名= X%）
- 近期合同获胜（$值）
- 指引与共识
- 内部人持股%

**行间距 - 每个部分使用单个文本框：**
```python
def add_section(slide, x, y, w, header_text, bullets, header_size=10, bullet_size=8):
    """标题+项目符号在单个文本框中，具有自然间距"""
    tb = slide.shapes.add_textbox(x, y, w, Inches(len(bullets) * 0.18 + 0.3))
    tf = tb.text_frame
    tf.word_wrap = True

    # 标题段落
    p = tf.paragraphs[0]
    p.text = header_text
    p.font.bold = True
    p.font.size = Pt(header_size)
    p.font.color.rgb = RGBColor(0, 51, 102)
    p.space_after = Pt(6)  # 标题后的小间距

    # 项目符号段落
    for bullet in bullets:
        p = tf.add_paragraph()
        p.text = bullet
        p.font.size = Pt(bullet_size)
        p.space_after = Pt(3)
    return tb
```

**关键间距原则：**
- 将标题+项目符号放在同一个文本框中（不要单独的标题文本框）
- 使用`space_after = Pt(6)`在标题后，`Pt(3)`在项目符号之间
- 不要硬编码间距 - 让段落间距自然处理
- 如果内容溢出，减小字体1pt，而不是删除内容

- **3-4个密集幻灯片** - 使用象限、列、表格、图表
- **所有正文文本使用项目符号** - 绝不使用段落。**每个部分使用一个文本框，所有项目符号都在里面** - 不要为每个项目符号点创建单独的文本框。使用PptxGenJS项目符号格式：
  ```javascript
  // 正确：单个文本框带项目符号列表 - 每个数组项都成为项目符号

      { text: 'CEO：埃隆·马斯克；CFO：瓦伊布哈·塔内贾', options: { bullet: { indent: 10 }, breakLine: true } },

    ],

  );

  // 错误：多个单独的文本框 - 导致对齐问题
  // slide.addText('总部：奥斯汀', { x: 0.5, y: 1.0, bullet: true });
  ```

  **项目符号格式技巧：**
  - `bullet: { indent: 10 }` - 控制项目符号缩进（较小=更紧凑）
  - `paraSpaceAfter: 6` - 每个段落后的点数间距

  - 包含具体数字和百分比以增加信息密度
- **标题大小写**：标题（不是ALL CAPS），左对齐
- **一致字体**：包括表格在内，到处都使用
- **公司品牌颜色** - 您必须通过网络搜索研究实际品牌颜色，然后再创建幻灯片。不要猜测或假设颜色。

## 第一页布局

必须通过“30秒理解测试”对忙碌的高管有效。

### 幻灯片设置（关键）
**使用4:3宽高比**（标准IB演示文稿格式）：
```javascript
const pptx = new pptxgen();
pptx.layout = 'LAYOUT_4x3';  // 10"宽 × 7.5"高 - 必须使用此设置
```

### 幻灯片坐标系统
PptxGenJS使用英寸。4:3幻灯片 = **10"宽 × 7.5"高**。
- **x**：从左边缘的水平位置（0 = 左，10 = 右）
- **y**：从顶部的垂直位置（0 = 顶，7.5 = 底）
- **内容必须保持在边界内** - 所有边缘留出0.3"边距

### 第一页定位（英寸）
```
┌─────────────────────────────────────────────────────────────────┐
│ y=0.2  标题：公司名称（股票代码）                             │
├────────────────────────────┬────────────────────────────────────┤
│ y=0.6  公司概览        │ y=0.6  业务与定位            │
│ x=0.3, w=4.7               │ x=5.0, w=4.7                       │
│ h=3.0                      │ h=3.0                              │
├────────────────────────────┼────────────────────────────────────┤
│ y=3.7  关键财务指标      │ y=3.7  股票/近期发展        │
│ x=0.3, w=4.7               │ x=5.0, w=4.7                       │
│ h=3.5                      │ h=3.5                              │
└────────────────────────────┴────────────────────────────────────┘
                                                            y=7.5
```

### 标题部分（y=0.2）
**公司名称（股票代码）** - 示例：`特斯拉公司 (TSLA)`
```javascript
slide.addText('特斯拉公司 (TSLA)', { x: 0.3, y: 0.2, w: 9.4, h: 0.35, fontSize: 18, bold: true });
```

### 四象限布局（y=0.6到y=7.2）

| 象限 | 位置 | 内容 |
|------|------|------|
| **1** | x=0.3, y=0.6, w=4.7, h=3.0 | **公司概览**：总部、成立时间、关键数据、业务摘要（4-5个要点） |
| **2** | x=5.0, y=0.6, w=4.7, h=3.0 | **业务与定位**：收入驱动因素、产品/服务、竞争地位、增长驱动（4-5个要点） |
| **3** | x=0.3, y=3.7, w=4.7, h=3.5 | **关键财务指标**：收入、EBITDA、利润率、EPS、FCF + 估值（市值、企业价值、倍数） — **表格或图表，不能两者都有** |
| **4** | x=5.0, y=3.7, w=4.7, h=3.5 | **对于上市公司**：1年股票价格图表+前五大股东。**对于非上市公司**：近期发展或持股/并购历史 |

### 字体大小 - 使用这些确切值
| 元素 | 大小 | 备注 |
|------|------|------|
| 幻灯片标题 | 24pt | 粗体，公司品牌颜色 |
| 象限标题 | 14pt | 粗体，带强调条 |
| 正文/项目符号 | 11pt | 常规粗细 |
| 表格文本 | 10pt | 密集表格使用9pt |
| 图表标签 | 9pt | 保持标签简短 |
| 来源/页脚 | 8pt | 幻灯片底部 |

**关键：**如果文本溢出，减小字体1pt并重新渲染。

### 视觉强调（必需）
每个象限标题必须左侧有一个彩色强调条：
```javascript
// 为象限标题添加强调条
slide.addShape(pptx.shapes.RECTANGLE, {
  x: 0.3, y: 0.6, w: 0.08, h: 0.25,
  fill: { color: 'E31937' }  // 使用公司品牌颜色
});
slide.addText('公司概览', {
  x: 0.45, y: 0.6, w: 4.5, h: 0.3, fontSize: 14, bold: true, fontFace: 'Arial'
});
```

**视觉元素包括：**
- 所有部分标题旁边的强调条（品牌颜色）
- 上下象限之间的细水平分隔线
- 如果可用，在右上角放置公司标志
- 轻微的网格线（浅灰色#CCCCCC）在表格中

### 第一页格式
- **字体**：Arial（或按用户/品牌指南指定）
- **象限标题**：首字母大写（不是ALL CAPS），例如，“公司概览”而不是“COMPANY OVERVIEW”
- **项目符号**：在开始时加粗关键术语，例如，“**市场地位**：领先的全球制造商..."
- 只有白色背景 — 没有框、填充或阴影
- 部分标题：粗体文本，遵循品牌指南进行样式设置
- 所有象限大小和位置对齐

## 图表（多页简介）

**对于多页简介**：包含2-3个实际的PptxGenJS图表。永远不要使用占位符区域或静态图像。

**对于单页简介**：使用表格进行财务数据（更节省空间）。仅在图表替换表格时添加图表，而不是添加图表。

| 数据类型 | 图表类型 |
|----------|----------|
| 收入趋势 | 线形或柱形（多年） |
| 地域细分 | 水平条形图 |
| 产品组合 | 带百分比的饼图 |
| 财务比较 | 柱形图 |
| 股票价格（1年每日） | 线形图 |

### 图表代码示例

**水平条形图（适合4:3幻灯片的右下象限）：**
```javascript
slide.addChart(pptx.charts.BAR, [{

  x: 5.0, y: 4.1, w: 4.5, h: 3.0,  // 适合4:3幻灯片的右下象限

  dataLabelFontSize: 10, catAxisLabelFontSize: 10, valAxisLabelFontSize: 10,
  dataLabelFormatCode: '$#,##0.0B',

```

**饼图（适合4:3幻灯片的右下象限）：**

## 财务数据格式

**始终使用本地的PptxGenJS表格或图表 - 绝不使用纯文本段落或HTML表格。**

使用`slide.addTable()`添加财务数据（适合4:3幻灯片的左下象限）：
```javascript
// 首先添加带强调条的标题
slide.addShape(pptx.shapes.RECTANGLE, {
  x: 0.3, y: 3.7, w: 0.08, h: 0.25, fill: { color: 'E31937' }
});
slide.addText('关键财务指标与估值', {
  x: 0.45, y: 3.7, w: 4.5, h: 0.3, fontSize: 14, bold: true, fontFace: 'Arial'
});

// 财务数据表格
slide.addTable([
  [{ text: '指标', options: { bold: true, fill: '003366', color: 'FFFFFF' } },
   { text: 'FY24', options: { bold: true, fill: '003366', color: 'FFFFFF' } },
   { text: 'FY25E', options: { bold: true, fill: '003366', color: 'FFFFFF' } }],
  ['收入', '$51.4B', '$54.2B'],
  ['同比增长', '+6.0%', '+5.5%'],
  ['EBITDA', '$8.9B', '$9.5B'],
  ['EBITDA利润率', '17.3%', '17.5%'],
  ['EPS', '$3.42', '$3.75'],
  ['市值', '$185B', '—'],
  ['EV/EBITDA', '12.5x', '11.7x']
], {
  x: 0.45, y: 4.1, w: 4.3, h: 3.0,  // 标题下方在左下象限
  fontFace: 'Arial', fontSize: 10,
  border: { pt: 0.5, color: 'CCCCCC' },
  valign: 'middle',
  colW: [1.8, 1.25, 1.25]  // 列宽
});
```

❌ **不正确**：如“注意：FY2024收入增长+1.0%，净利润$5.1B...”
❌ **不正确**：无法正确转换为PowerPoint的HTML表格

对于预测，使用熊市/基准/牛市情景的表格结构。
