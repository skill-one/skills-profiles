# 刷新演示文稿

更新演示文稿中的数值。演示文稿是格式化的权威来源；你只更改数值。

## 环境检查

此技能在 PowerPoint 插件和聊天中都有效。在开始之前，确定你处于哪种环境——编辑机制不同，意图相同：

- **插件** — 演示文稿实时打开；直接编辑文本框、表格单元和图表数据。
- **聊天** — 演示文稿是上传的文件；通过使用新值重新生成受影响的幻灯片并将结果写回进行编辑。

无论如何：最小化更改，保留现有格式。

这是一个四阶段过程，第三阶段是一个审批关卡。在用户看到计划之前不要编辑。

## 第一阶段 — 获取数据

使用 `ask_user_question` 来了解新数值如何到达：

- **粘贴映射** — 用户输入或粘贴 "收入 48.5 亿 → 51.2 亿，EBITDA 12 亿 → 13.5 亿。" 最清晰的情况。
- **上传的 Excel** — 旧/新列，或用户希望提取的新输出表。读取它，确认哪一列是哪一列，然后再信任它。
- **仅新值** — "第四季度收入为 51.2 亿，利润率为 22%。" 你来弄清楚每个值替换的是什么。可行，但在触摸任何东西之前确认映射——将 "$51.2 亿" 映射到收入，但用户实际上是指毛利润，这是一个安静的灾难。

还要询问关于 **派生数值** 的问题：如果收入变动，用户是否希望重新计算增长率 и доля 百分比，还是保持不变？大多数演示文稿在某处嵌入了 "+15% 同比" 现在已经过时。是否要触摸这些是一个用户应该做出的判断，而不是你。

## 第二阶段 — 读取所有内容，找到所有内容

读取每一张幻灯片。对于每个旧值，找到每一个实例——包括那些看起来不同的情况：

| 变体 | 示例 |
|---|---|
| 比例 | `$48.5 亿`，`$0.485 万亿`，`$485,000,000` |
| 精度 | `$48.5 亿`，`$485.0 亿`，`~$485 亿` |
| 单位样式 | `$48.5 亿`，`$485MM`，`$485 亿`，`485M` |
| 嵌入 | "收入增长到 48.5 亿"，"一个 48.5 亿的业务"，坐标轴标签 |

一个在幻灯片 3 上显示 `$48.5 亿`，在幻灯片 8 的图表坐标轴上显示 `485`，在幻灯片 15 的脚注中显示 `$485.0 万亿` 的演示文稿中有三个相同的数值实例。查找替换会错过其中的两个。你不应该这样。

**数值隐藏的位置：**
- 文本框（明显）
- 表格单元
- 图表数据标签和坐标轴标签
- 图表源数据——驱动条形的数值，而不仅仅是它们上的标签
- 脚注、来源行、小字
- 演讲者笔记，如果用户关心这些

建立一个列表：对于每个旧值，它出现的位置，它出现的确切文本，以及它将成为什么。这个列表是计划。

## 第三阶段 — 展示计划，获得批准

**这是一个对某人花费时间制作的演示文稿的破坏性操作。** 在编辑任何东西之前，显示完整的更改列表。将其格式化为可扫描：

```
$48.5 亿 → $51.2 亿（收入）
  幻灯片 3  — 标题框："收入增长到 48.5 亿"
  幻灯片 8  — 图表坐标轴标签："485"
  幻灯片 15 — 脚注："$485.0 万亿在 2024 财年收入"

$12 亿 → $13.5 亿（调整后 EBITDA）
  幻灯片 3  — 表格单元
  幻灯片 11 — 正文文本："$12 亿的调整后 EBITDA"

FLAGGED — 可能是派生的，不在你的映射中：
  幻灯片 3  — "+15% 同比"（增长率——如果基准年没有改变，则可能过时？
  幻灯片 7  — "12% 市场份额"（这是否是从 $485 亿 / 市场规模计算出来的？）
```

标记部分很重要。你不仅仅是在执行查找替换——你是在捕捉用户在晚上 11 点会忽略的二阶效应。如果映射说 `$485 亿 → $51.2 亿`，而幻灯片 3 还在旁边有 `+15% 同比`，那么这个增长率现在可能不正确。标记它；不要默默地修复它，不要默默地留下它。

使用 `ask_user_question` 进行审批：按所示进行，按所示进行但跳过标记的项目，或让他们先修订映射。

## 第四阶段 — 执行，保留，报告

对于每个更改，进行能够完成它的最小编辑。这取决于你的环境：

- **插件** — 直接在实时演示文稿中编辑特定的运行、单元格或图表系列。
- **聊天** — 使用新值重新生成受影响的幻灯片，保留其他所有元素完全不变，并将其写回文件。

无论如何，标准都是相同的：

- **形状中的文本** — 更改值，保留字体/大小/颜色/粗体状态完全不变。如果 `$485 亿` 是 14pt 海军蓝粗体，位于句子中，那么 `$51.2 亿` 也是 14pt 海军蓝粗体，位于同一句子中。
- **表格单元** — 更改单元格，保留表格不变。
- **图表数据** — 更新底层系列值，使条形/线条实际移动。仅编辑标签而不编辑数据会留下一个说谎的图表。

不要重新格式化任何你不需要触摸的东西。演示文稿现有的样式在定义上就是正确的；你是一个外科医生，不是一个翻新者。

在最后一次编辑后，报告实际发生的事情：

```
在 8 张幻灯片上更新了 11 个值。

更改：
  [来自第三阶段的列表，现在使用过去时]

仍然标记——未更改：
  幻灯片 3 — "+15% 同比"（派生的；单独确认）
  幻灯片 7 — "12% 市场份额"
```

对每张编辑过的幻灯片运行标准的视觉验证检查。一个变长的数值 (`$485 亿` → `$1,205 亿`) 现在可能会溢出其文本框或推宽表格列宽。在用户发现之前抓住它。

## 你没有做的事情

- **不是重建幻灯片** — 如果一张幻灯片的叙事与新的数值不再合理（"利润率压缩"，但利润率上升了），标记它，不要重写它。
- **不是重新计算除非要求** — 派生数值是用户的决定。你的第一阶段问题涵盖了这一点。
- **不是触摸格式** — 如果演示文稿使用 `$MM`，而用户的映射说 `$M`，请匹配演示文稿，而不是映射。值会变化；风格保持不变。
