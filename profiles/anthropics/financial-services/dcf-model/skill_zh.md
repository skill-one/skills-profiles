# DCF 模型构建器

## 概述

此技能将根据投资银行标准为股票估值创建机构级 DCF 模型。每次分析都会生成一个详细的 Excel 模型（DCF 表格底部包含敏感性分析）。

## 工具

默认使用用户提供的信息和 MCP 服务器提供的数据源。

## 关键约束 - 首先阅读这些内容

这些约束适用于所有 DCF 模型构建。开始之前请查看：

**环境：Office JS 与 Python/openpyxl：**
- **如果在 Excel 中运行（Office 插件 / Office JS 环境）：** 直接使用 Office JS — 不要使用 Python/openpyxl。通过 `range.formulas = [["=D19*(1+$B$8)"]]` 直接编写公式。无需单独的重新计算步骤；Excel 原生计算。使用 `range.format.*` 进行样式设置。相同的公式覆盖硬编码规则适用：设置 `.formulas`，不要 `.values` 用于派生单元格。

- **如果生成独立的 .xlsx 文件（没有活动的 Excel 会话）：** 使用下面描述的 Python/openpyxl，然后在交付前运行 `recalc.py`。
- 本技能的其余部分使用 openpyxl 示例 — 在该环境中将转换为 Office JS API 调用，但所有原则（公式字符串、单元格注释、部分检查点、敏感性表格循环）完全相同。

**⚠️ Office JS 合并单元格陷阱：** 在构建部分标题时使用合并单元格，不要调用 `.merge()` 然后在合并范围内设置 `.values` — Office JS 仍然报告范围的原始维度，并将抛出 `InvalidArgument: The number of rows or columns in the input array doesn't match the size or dimensions of the range`。相反，仅将值写入左上角单元格，然后合并并格式化整个范围：

```js
// 错误 — 抛出 InvalidArgument:
const hdr = ws.getRange("A7:H7");
hdr.merge();
hdr.values = [["MARKET DATA & KEY INPUTS"];]";  // 1×1 数组与 1×8 范围不匹配 → 失败

// 正确 — 值首先写入单个单元格，然后合并 + 格式化范围:
ws.getRange("A7").values = [["MARKET DATA & KEY INPUTS"]];
const hdr = ws.getRange("A7:H7");
hdr.merge();
hdr.format.fill.color = "#1F4E79";
hdr.format.font.bold = true;
hdr.format.font.color = "#FFFFFF";

```

这适用于 DCF 中的每个合并部分标题。市场数据、情景块、现金流预测、终值、估值摘要、敏感性表格。

**公式覆盖硬编码 (非可协商)：**
- 每个预测、利润率、折现因子、现值和敏感性单元格必须是活的 Excel 公式 — 绝对不是在 Python 中计算并在 Python 中作为数字写入。
- 使用 openpyxl 时：`ws["D20"] = "=D19*(1+$B$8)"` 是正确的；`ws["D20"] = calculated_revenue` 是错误的。
- 允许的唯一硬编码数字是：(1) 历史输入，(2) 假设驱动因素（增长率、WACC 输入、终值 g），(3) 当前市场数据（股价、债务余额）

- 如果你发现自己用 Python 计算某项内容并写入结果 — 停止。模型必须在用户更改假设时灵活。

**逐步验证与用户确认 (不要端到端构建)：**
- 数据检索后 → 向用户展示原始输入块（收入、利润率、股份、净债务）并确认后再进行预测
- 收入预测后 → 展示预测的顶线、增长率，确认后再构建利润率
- FCF 构建后 → 展示完整的 FCF 时间表，确认逻辑后再计算 WACC
- WACC 后 → 展示计算和输入，确认后再折现
- 终值 + PV 后 → 展示股权桥梁（EV → 股权价值 → 每股），确认后再构建敏感性表格

- 在每个阶段捕获错误 — 在构建敏感性表格后发现错误的利润率假设意味着需要重建下游所有内容

**敏感性表格：**
- **使用奇数行和列**（标准：5×5，有时 7×7）— 这保证了真正的中心单元格
- **中心单元格 = 基准情况。** 构建轴值，使中间行标题和中间列标题正好等于模型的实际假设（例如，如果基准 WACC = 9.0%，则中间行是 9.0%；如果终值 g = 3.0%，则中间列是 3.0%）。因此，中心单元格的输出必须等于模型的实际隐含股价 — 这是确保表格构建正确的合理性检查。
- **突出显示中心单元格** 使用中等蓝色填充 (`#BDD7EE`) + 粗体字，以便立即识别哪个单元格是基准情况。
- 填充所有单元格（通常 3 个表格 × 25 个单元格 = 75）与完整 DCF 重新计算公式
- 使用 openpyxl 循环（或 Office JS 循环）程序化编写公式
- 不允许占位符文本，不允许线性近似，不允许手动步骤
- 每个单元格必须重新计算该假设组合的完整 DCF

**单元格注释：**
- 创建单元格注释时添加每个硬编码值
- 格式："来源：[系统/文档], [日期], [参考], [URL 如果适用]"
- 每个蓝色输入必须有注释，然后才能移动到下一个部分
- 不要推迟到最后或写入 "TODO: 添加来源"

**模型布局规划：**
- 在编写任何公式之前定义所有部分行位置
- 首先编写所有标题和标签
- 其次编写所有部分分隔线和空白行
- 然后使用锁定的行位置编写公式
- 创建后立即测试公式

**公式重新计算：**
- 在交付前运行 `python recalc.py model.xlsx 30`
- 修复所有错误，直到状态为 "success"
- 零公式错误要求 (#REF!, #DIV/0!, #VALUE!, 等.)

**情景块：**
- 为熊市/基准/牛市情况创建单独的块
- 在每个块中水平显示假设，投影年份
- 使用 IF 公式：`=IF($B$6=1,[熊市单元格],IF($B$6=2,[基准单元格],[牛市单元格])`

- 验证公式是否引用正确的情景块单元格

## DCF 流程工作流

### 第 1 步：数据检索和验证

从 MCP 服务器、用户提供的数据和 Web 检索数据。

**数据源优先级：**
1. **MCP 服务器**（如果配置）- 来自 Daloopa 等提供者的结构化财务数据
2. **用户提供的数据** - 来自其研究的歷史财务数据
3. **网络搜索/获取** - 当需要时获取当前价格、贝塔、债务和现金

**验证清单：**
- 验证净债务与净现金（对估值至关重要）
- 确认稀释股份总数（检查最近的回购/发行情况）
- 验证历史利润率是否与商业模式一致
- 收入增长率与行业基准进行交叉检查
- 验证税率是否合理（通常为 21-28%）

### 第 2 步：历史分析 (3-5 年)

分析和记录：
- **收入增长趋势**：计算 CAGR，识别驱动因素
- **利润率进展**：跟踪毛利率、EBIT 利润率、FCF 利润率
- **资本强度**：D&A 和 CapEx 作为收入百分比
- **营运资本效率**：NWC 变化作为收入增长的百分比
- **回报指标**：ROIC、ROE 趋势

创建摘要表格显示：
```
历史指标 (LTM):
收入：$X 百万
收入增长：X% CAGR
毛利率：X%
EBIT 利润率：X%
D&A 收入百分比：X%
CapEx 收入百分比：X%
FCF 利润率：X%
```

### 第 3 步：构建收入预测

**方法：**
1. 从最新实际收入（LTM 或最近财政年度）开始
2. 对每个预测年度应用增长率
3. 显示美元金额和计算出的增长率 %

**增长率框架：**
- 第 1-2 年：较高的增长率反映短期可见性
- 第 3-4 年：逐渐放缓至行业平均水平
- 第 5 年 +：接近终值增长率

**公式结构：**
- 收入(年份 N) = 收入(年份 N-1) × (1 + 增长率)
- 增长 %(年份 N) = 收入(年份 N) / 收入(年份 N-1) - 1

**三种情景方法：**
```
熊市：保守增长（例如，8-12%）
基准：最可能的情况（例如，12-16%）
牛市：乐观增长（例如，16-20%）

```

### 第 4 步：营业费用建模

**固定/可变成本分析：**

营业费用应模拟现实的营业杠杆：
- **销售和市场**：通常为收入的 15-40%，具体取决于商业模式
- **研发**：通常为技术公司的 10-30%
- **一般和行政**：通常为收入的 8-15%，显示规模效应

**关键原则：**
- 所有百分比基于收入，而不是毛利润
- 模拟营业杠杆：%应随着收入扩大而下降
- 保持 S&M、R&D、G&A 的单独行项
- 计算 EBIT = 毛利润 - 总营业费用

**利润率扩展框架：**
```
当前状态 → 目标状态（第 5 年）
毛利率：X% → Y%（根据规模、效率进行说明）
EBIT 利润率：X% → Y%（结果是收入增长 + 营业费用杠杆）
```

### 第 5 步：自由现金流计算

**按正确顺序构建 FCF：**

```
EBIT
(-) 税费 (EBIT × 税率)
= NOPAT (税后营业利润)
(+) D&A（非现金费用，收入百分比）
(-) CapEx（收入百分比，通常为 4-8%）
(-) Δ NWC（营运资本变化）
= 杠杆自由现金流
```

**营运资本建模：**
- 计算为收入变化的百分比（delta 收入）
- 典型范围：-2% 至 +2% 的收入变化
- 负数 = 现金来源（营运资本释放）
- 正数 = 现金使用（营运资本构建）

**维护与增长 CapEx：**
- 维护 CapEx：维持当前运营 (~2-3% 收入)
- 增长 CapEx：支持扩张（额外 2-5% 收入）
- 总 CapEx 应与公司的增长战略一致

### 第 6 步：资本成本 (WACC) 研究

**CAPM 方法论用于成本权益：**

```
成本权益 = 无风险利率 + 贝塔 × 权益风险溢价

其中：
- 无风险利率 = 当前 10 年国债收益率
- 贝塔 = 5 年月度股票贝塔与市场指数
- 权益风险溢价 = 5.0-6.0%（市场标准）

```

**成本债务计算：**

```
税后成本债务 = 税前成本债务 × (1 - 税率)

从以下来源确定税前成本债务：
- 信用评级（如果可用）
- 公司债券的当前收益率
- 利息费用 / 总债务来自财务报表

```

**资本结构权重：**

```
市值权益 = 当前股价 × 股份总数
净债务 = 总债务 - 现金及等价物
企业价值 = 市值 + 净债务

权益权重 = 市值 / 企业价值
债务权重 = 净债务 / 企业价值

WACC = (成本权益 × 权益权重) + (税后成本债务 × 债务权重)

```

**特殊情况：**
- **净现金头寸**：如果现金 > 债务，净债务为负
  - 债务权重可能为负
  - WACC 计算相应调整
- **无债务**：WACC = 成本权益

**典型 WACC 范围：**
- 大型资本、稳定：7-9%
- 增长型公司：9-12%
- 高增长/风险：12-15%

### 第 7 步：折现率应用 (5-10 年预测)

**中年惯例：**
- 现金流假定发生在中年
- 折现期：0.5, 1.5, 2.5, 3.5, 4.5, 等.
- 折现因子 = 1 / (1 + WACC)^Period

**现值计算：**
```
对于每个预测年份：
PV of FCF = 杠杆自由现金流 × 折现因子

示例（第 1 年）：
FCF = $1,000
WACC = 10%
Period = 0.5
折现因子 = 1 / (1.10)^0.5 = 0.9535
PV = $1,000 × 0.9535 = $954
```

**预测期选择：**
- **5 年**：大多数分析的标准
- **7-10 年**：高增长公司，跑道更长
- **3 年**：成熟、稳定的业务

### 第 8 步：终值计算

**永续增长法（首选）：**

```
终值 FCF = 最终年份 FCF × (1 + 终值增长率)
终值 = 终值 FCF / (WACC - 终值增长率)

关键约束：终值增长率 < WACC（否则价值无限）

```

**终值增长率选择：**
- 保守：2.0-2.5%（GDP 增长率）
- 中等：2.5-3.5%
- 激进：3.5-5.0%（仅限市场领导者）

**不要超过**：无风险利率或长期 GDP 增长

**退出乘数法（替代方法）：**

```
终值 = 最终年份 EBITDA × 退出乘数

其中退出乘数来自：
- 行业可比交易乘数
- 先例交易乘数
- 典型范围：8-15x EBITDA

```

**终值现值：**

```
PV of Terminal Value = 终值 / (1 + WACC)^Final Period

其中 Final Period 考虑了时间：
5 年模型与中年惯例：Period = 4.5
```

**终值合理性检查：**
- 应代表 50-70% 的企业价值
- 如果 >75%，模型可能过度依赖终值假设
- 如果 <40%，请检查终值假设是否过于保守

### 第 9 步：企业价值到股权价值桥梁

**估值摘要结构：**

```
(+) 预测 FCF 现值之和 = $X 百万
(+) 终值现值 = $Y 百万
= 企业价值 = $Z 百万

(-) 净债务 [或 + 净现金如果为负] = $A 百万
= 股权价值 = $B 百万

÷ 稀释股份总数 = C 百万股
= 隐含每股价格 = $XX.XX

当前股价 = $YY.YY
隐含回报 = (隐含价格 / 当前价格) - 1 = XX%
```

**关键调整：**
- **净债务 = 总债务 - 现金及等价物**
  - 如果为正：从 EV 中减去（减少股权价值）
  - 如果为负（净现金）：加到 EV（增加股权价值）
- **使用稀释股份**：包括期权、RSU、可转换证券
- **其他调整**（如果适用）：
  - 少数股权
  - 养老金负债
  - 营业租赁义务

**估值输出格式：**
```csv
估值组件,金额 ($M)
PV 显式 FCFs,X.X
PV 终值,Y.Y
企业价值,Z.Z
(-) 净债务,A.A
股权价值,B.B
,,,
股份总数 (M),C.C
隐含每股价格,$XX.XX
当前股价,$YY.YY
隐含上行/(下行),+XX%
```

### 第 10 步：敏感性分析

在 DCF 表格底部构建三个敏感性表格，显示估值如何随不同假设变化：

1. **WACC 与终值增长率** - 显示企业价值对折现率和永续增长敏感
2. **收入增长与 EBIT 利润率** - 显示顶线增长和营业杠杆的影响
3. **Beta 与无风险利率** - 显示对权益成本组成部分的敏感性

**实施**：这些是简单的 2D 网格（不是 Excel 的“数据表”功能（数据 → 什么是假设分析 → 数据表）。您将使用 openpyxl 将常规 Excel 公式写入每个单元格。

**总公式要写入：75**（这是必需的，不是可选的）

**关键约束**：所有敏感性表格单元格必须使用 openpyxl 程序化填充公式。不要使用线性近似。不要留下占位符文本或关于手动步骤的注释。敏感性表格必须在用户打开文件时即可完全工作。

## 案例选择实现

**三案例框架：**

### 熊市
- 保守收入增长（历史范围的下限）
- 利润率压缩或没有扩张
- 较高的 WACC（风险溢价增加）
- 较低的终值增长率
- 较高的 CapEx 假设

### 基准
- 一致性或管理层指导收入增长
- 基于运营杠杆的适度利润率扩展
- 当前市场隐含 WACC
- 与 GDP 对齐的终值增长率（2.5-3.0%）
- 标准的 CapEx 假设

### 牛市
- 乐观收入增长（预测的高端）
- 显著的利润率扩展
- 较低的 WACC（降低风险溢价）
- 较高的终值增长率（3.5-5.0%）
- 降低 CapEx 强度

**公式实现：**

**不要使用嵌套 IF 公式散布在整个模型中。** 相反，创建一个合并列，使用 INDEX 或 OFFSET 公式从正确的情景块中提取值。

**推荐模式（使用 INDEX）：**
`=INDEX(B10:D10, 1, $B$6)` 其中 `B10:D10` = 熊市/基准/牛市值，`1` = 行偏移，`$B$6` = 案例选择器（1, 2 或 3）

**然后，在所有预测中引用合并列：**
`Revenue Year 1: =D29*(1+$E$10)` 其中 $E$10 是合并列的 Year 1 增长率值（包含 INDEX 公式）

这种方法集中了情景逻辑，使模型更容易审计和维护。

## 交付物结构

**文件命名**：`[Ticker]_DCF_Model_[Date].xlsx`

**两个工作表**：
1. **DCF** - 完整模型，包含熊市/基准/牛市案例 + 底部的三个敏感性表格（WACC 与终值增长率、收入增长与 EBIT 利润率、Beta 与无风险利率）
2. **WACC** - 成本计算

**关键功能**：案例选择器（1/2/3），合并列包含 INDEX/OFFSET 公式，颜色编码单元格，所有输入的单元格注释，专业边框

## 最佳实践

### 模型构建
1. **逐步构建**：完成每个部分后再移动到下一个
2. **边构建边测试**：输入示例数字以验证公式
3. **使用一致的结构**：相似的计算遵循相似的模式
4. **注释复杂公式**：为不寻常的计算添加注释
5. **构建检查**：在适用情况下进行总和检查和平衡检查

### 文档记录
1. **记录所有假设**：解释关键输入背后的推理
2. **引用数据来源**：注明每个数据点来自哪里
3. **解释方法**：描述任何非标准方法
4. **标记不确定性**：突出显示有有限可见性的区域

### 质量控制
1. **交叉检查计算**：以多种方式验证数学
2. **敏感性测试**：确保模型稳健
3. **同行评审**：让其他人检查公式
4. **版本控制**：随着工作的进行保存版本

## 常见变化

### 高增长技术公司
- 较长的预测期（7-10 年）
- 较高的初始增长率（20-30%）
- 随时间推移显著的利润率扩展
- 较高的 WACC（12-15%）
- 模型单位经济（用户、ARPU 等）

### 成熟/稳定公司
- 较短的预测期（3-5 年）
- 适度的增长率（GDP +1-3%）
- 稳定的利润率
- 较低的 WACC（7-9%）
- 关注现金流产生和资本配置

### 周期性公司
- 模拟经济周期
- 在周期中标准化利润率
- 考虑低谷和高峰情景
- 调整贝塔以反映周期性

### 多部门公司
- 为每个业务单元创建单独的 DCF
- 每个部门具有不同的增长率和利润率
- 部分估值
- 考虑协同效应

## 故障排除

如果你遇到错误或无法合理的结果，请阅读 [TROUBLESHOOTING.md](./TROUBLESHOOTING.md) 以获取详细的调试指导。

## 工作流集成

### DCF 构建开始时

1. **收集市场数据**：
   - 检查是否有可用的 MCP 服务器获取当前市场数据
   - 使用网络搜索/获取获取股价、贝塔和其他市场指标
   - 如果需要特定数据，请向用户提供

2. **收集历史财务数据**：
   - 检查是否有可用的 MCP 服务器（Daloopa 等）
   - 如果 MCP 不可用，请向用户提供
   - 如有必要，从 10-K 中手动提取

3. **开始使用 DCF 方法论构建模型** 本技能中详细说明

### 构建模型期间

1. **使用 openpyxl 构建 Excel 模型** 使用公式（不要硬编码值）
2. **遵循 xlsx 技能规范** 进行公式构建和格式设置
3. **如果用户请求** 使用 fill 颜色

### 交付模型前（强制）

1. **验证结构**：
   - 熊市/基准/牛市案例块，假设横跨投影年份
   - 案例选择器功能正常，引用正确的情景块
   - 敏感性表格位于 DCF 表格底部（不是单独的工作表）
   - 字体颜色：蓝色输入，黑色公式，绿色工作表链接
   - 所有输入单元格都有单元格注释
   - 专业边框围绕主要部分

2. **重新计算公式**：运行 `python recalc.py model.xlsx 30`

3. **检查输出**：
   - 如果 `status` 是 `"success"` → 继续步骤 4
   - 如果 `status` 是 `"errors_found"` → 检查 `error_summary` 并阅读 [TROUBLESHOOTING.md] 以获取调试指导

4. **修复错误并重新运行 recalc.py** 直到状态为 "success"

5. **快速检查公式**：
   - 测试一个 FCF 公式 - 它是否引用了正确的假设行？
   - 更改案例选择器 - 合并列是否正确更新？
   - 验证收入公式是否引用合并列（不要嵌套 IF 公式）

6. **交付模型**

### 可用数据源

- **MCP 服务器**：如果配置（Daloopa 等历史财务数据）
- **网络搜索/获取**：用于当前股价、贝塔、市场数据
- **用户提供的数据**：历史财务数据、一致估计
- **手动提取**：SEC EDGAR 文件作为后备

## 最终输出清单

交付 DCF 模型前：

**强制：**
- 运行 `python recalc.py model.xlsx 30` 直到状态为 "success"（零公式错误）
- 两个工作表：DCF（敏感性在底部），WACC
- 字体颜色：蓝色=输入，黑色=公式，绿色=工作表链接
- 单元格注释：所有输入
- 敏感性表格完全填充公式
- 专业边框围绕主要部分

**验证：**
- OpEx 基于收入（不是毛利润）
- 终值 50-70% 的 EV
- 终值增长率 < WACC
- 税率 21-28%
- 文件命名：`[Ticker]_DCF_Model_[Date].xlsx`
