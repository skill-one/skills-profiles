# 财务数据包构建器

构建专业、标准化的财务数据包，适用于私募股权、投资银行和资产管理领域。将来自CIMs（公司信息管理）、要约备忘录、SEC（美国证券交易委员会）申报、网络搜索或MCP服务器访问的财务数据转化为精美的Excel工作簿，供投资委员会审阅。

**重要提示：** 在整个工作流程中，所有Excel文件的创建和操作都必须使用xlsx技能。

## 关键成功因素

每个数据包都必须达到这些标准。任何一点的失败都会使交付物无法使用。

### 1. 数据准确性（零容忍错误）
- 每个数字都必须追溯到源文档，并包含页码参考
- 仅使用基于公式的计算（不允许使用硬编码值）
- 核对子总计和总计，确保内部一致性
- 验证资产负债表平衡：资产 = 负债 + 权益
- 确认现金流与资产负债表变化相匹配

### 2. 基本规则

**规则1：财务数据（衡量金钱）→ 使用$符号的货币格式**
触发条件：收入、销售额、收入、EBITDA、利润、亏损、成本、费用、现金、债务、资产、负债、权益、资本支出
格式：$#,##0.0用于百万，$#,##0用于千
负数：$(123.0) 不等于 -$123

**规则2：运营数据（计数事物）→ 数字格式，无$符号**
触发条件：单位、门店、地点、员工、客户、平方英尺、物业、员工人数
格式：#,##0，带逗号
负数：(123) 与表格其他部分保持一致

**规则3：百分比（率和比率）→ 百分比格式**
触发条件：利润率、增长率、比率、百分比、收益率、回报率、利用率、入住率
格式：0.0% 用于一位小数
显示：15.0% 不等于 0.15

**规则4：年份 → 文本格式，防止插入逗号**
格式：文本或自定义格式，防止插入2,024
显示：2020, 2021, 2022, 2023A, 2024E

**规则5：当上下文混合时，每个指标都获得其适当的格式**
示例：
```
分段分析, 2022, 2023, 2024
零售收入, $50.0, $55.0, $60.0
  门店, 100, 110, 120
  每门店收入, $0.5, $0.5, $0.5
```
收入和每门店指标使用$符号，门店数量使用数字格式。

**规则6：使用公式进行所有计算 → 永远不使用硬编码的计算值**
所有子总计、总计、比率和派生指标都必须基于公式，而不是硬编码值。这确保了准确性并允许动态更新。

### 3. 专业展示标准

**格式标准：**

**配色方案 - 两层：**

**第一层：字体颜色（xlsx技能强制要求）**
- **蓝色文本（RGB: 0,0,255）**：所有硬编码输入（历史数据、假设），不是正常文本
- **黑色文本（RGB: 0,0,0）**：所有公式和计算
- **绿色文本（RGB: 0,128,0）**：链接到其他工作表

**第二层：填充颜色（可选，用于增强展示效果）**
- 填充颜色是可选的，并且只有在用户请求或增强展示效果时才应应用
- 如果用户请求颜色或专业格式，请使用此标准方案：
  - **分段标题**：深蓝色（RGB: 68,114,196）背景，白色文本
  - **子标题/列标题**：浅蓝色（RGB: 217,225,242）背景，黑色文本
  - **输入单元格**：浅绿色/奶油色（RGB: 226,239,218）背景，蓝色文本
  - **计算单元格**：白色背景，黑色文本
- 用户可以覆盖自定义品牌颜色（如果指定）

**两层如何协同工作（如果使用填充颜色）：**
- 输入单元格：蓝色文本 + 浅绿色填充 = "用户输入的数据"
- 公式单元格：黑色文本 + 白色背景 = "计算值"
- 工作表链接：绿色文本 + 白色背景 = "来自另一个选项卡的引用"

**字体颜色告诉你这是什么。填充颜色告诉你在哪里（如果使用）。**

**重要提示：** xlsx技能的字体颜色是强制性的。填充颜色是可选的 - 默认为白色/无填充，除非用户请求增强格式或颜色。

**始终应用：**
- 粗体标题，左对齐
- 数字右对齐
- 子项缩进2空格
- 子总计上方单下划线
- 最终总计下方双下划线
- 冻结行/列标题
- 最小化边框（仅在结构上需要时使用）
- 统一字体（通常为Calibri或Arial 11pt）

**永远不包含：**
- 每个单元格周围的边框
- 多种字体或字体大小
- 除非特别要求，否则不包含图表
- 过度格式化或装饰

## 结构一致性
除非明确指示否则使用标准的8选项卡结构：
1. 执行摘要
2. 历史财务报表（损益表）
3. 资产负债表
4. 现金流量表
5. 运营指标
6. 物业/分段绩效（如果适用）
7. 市场分析
8. 投资亮点

### 选项卡1：执行摘要
目的：为忙碌的执行人员提供一页概览

内容：
- 公司概述（2-3句关于商业模式）
- 关键投资亮点（3-5个要点）
- 财务快照表（最近3年的收入、EBITDA、增长率 + 预测）
- 如果适用，交易概述
- 突出显示关键指标

格式：简洁，粗体标题，最小化装饰，强调关键数字

### 选项卡2：历史财务报表（损益表）
目的：完整的利润和亏损历史

内容：
- 按分段/产品线分解的收入
- 销货成本/收入成本
- 毛利润和毛利率%
- 详细说明运营费用（销售与管理、研发、一般与行政）
- EBITDA和调整后EBITDA
- 以下线项目（折旧与摊销、利息、税收）
- 净收入

格式：
- 年份作为列（文本格式：2020, 2021, 2022）
- $百万或$千（在顶部明确指定单位）
- 所有财务数据的会计格式
- 子总计上方单下划线，净收入下方双下划线
- 所有数字右对齐

### 选项卡3：资产负债表
目的：期末财务状况

内容：
- 流动资产（现金、应收账款、库存、预付费用、其他）
- 长期资产（固定资产、无形资产、商誉、其他）
- 流动负债（应付账款、应计费用、债务的流动部分、其他）
- 长期负债（长期债务、递延税收、其他）
- 股东权益（普通股、留存收益、其他）

格式：
- 验证公式：资产 = 负债 + 权益
- 一致日期标签
- 包括营运资本计算
- 子总计上方单下划线，最终总计下方双下划线

### 选项卡4：现金流量表
目的：现金生成和使用分析

内容：
- 营业现金流（首选间接法）
- 投资现金流（资本支出、收购、资产出售）
- 融资现金流（债务发行/偿还、股权、股息）
- 现金净变化
- 期初和期末现金余额

格式：
- 尽可能链接到损益表和资产负债表
- 显示净收入到营业现金流的调节
- 清晰标记现金使用（流出）与来源（流入）

### 选项卡5：运营指标
目的：非财务KPI和运营数据

内容（取决于行业）：
- 单位数量、客户数量、地点
- 生产率指标（每位员工/每门店/每单位的收入）
- 能力利用率
- 市场份额
- 客户保留/流失率
- 行业特定KPI

**关键格式说明：**
运营指标上没有美元符号。这些是数量，不是货币。

格式：
- 指定清晰单位（客户、员工、门店、平方英尺等）
- 带逗号的整数：1,250 不等于 $1,250
- 百分比用于比率：95.0%
- 数字右对齐

### 选项卡6：物业/分段绩效（如果适用）
目的：按业务单元、物业或分段进行详细分解

内容：
- 按分段/产品线的收入和盈利能力
- 按地点/产品的关键指标
- 分段特定KPI
- 比较绩效分析

格式：与财务选项卡一致，用于收入/EBITDA，运营指标使用数字格式

### 选项卡7：市场分析
目的：行业背景和竞争定位

内容：
- 市场规模和增长趋势
- 竞争格局概述
- 市场份额分析
- 行业基准和同行比较
- 如相关，监管环境

格式：结合叙述文本和表格，引用市场数据来源

### 选项卡8：投资亮点
目的：关键投资逻辑点的叙述总结

内容：
- 竞争优势的详细说明
- 增长机会和战略举措
- 风险因素和缓解策略
- 管理层评估和业绩记录
- 投资逻辑总结

格式：清晰标题，要点，简洁段落

## 分步工作流程

### 第一阶段：文档处理和数据提取

**步骤1.1：分析源数据**
- 访问源材料：上传的文档、网络搜索公共申报或MCP服务器数据
- 审查数据结构，识别关键部分
- 定位财务报表（通常为3-5年历史）
- 确定是否包含管理层预测
- 记录财政年度结束日期
- 立即标记任何数据质量问题

**步骤1.2：提取财务报表**
- 定位历史损益表数据
- 提取资产负债表快照（年末或季末）
- 找到现金流量表
- 如果可用，提取管理层预测
- 记录所有页码参考，以便追溯

**步骤1.3：提取运营指标**
- 确定与行业相关的非财务KPI
- 捕获单位经济数据
- 提取客户/地点/能力数据
- 记录增长指标和趋势

**步骤1.4：提取市场和行业数据**
- 竞争定位信息
- 市场规模和增长率
- 行业基准数据
- 同行比较信息

**步骤1.5：记录关键背景**
- 交易结构和理由
- 管理团队背景
- 源材料中的投资亮点
- 风险因素和考虑事项
- 任何数据差距或不一致

### 第二阶段：数据规范化和标准化

**步骤2.1：规范化会计表述**
- 确保所有年份的行项目名称一致
- 标准化收入确认处理
- 识别并记录一次性费用
- 如有必要，创建“调整后EBITDA”调节表
- 记录任何会计政策变化

**步骤2.2：应用格式检测逻辑**
针对每个数据点，根据完整上下文确定格式：
- 读取选项卡名称、表格标题、列标题和行标签
- 应用基本规则（见上文）
- 当不确定时，检查原始源文档
- 默认使用更简洁的格式（少即是多）

**步骤2.3：识别规范化调整**
常见的文档调整：
- 重组费用（如果确实非经常性，则加回）
- 股票期权补偿（按行业标准加回）
- 收购相关费用（按类型记录具体金额）
- 法律和解或诉讼费用（评估复发风险）
- 资产出售或减值（从经营结果中排除）
- 关联方调整（按市场利率标准化）
注意：源引用格式因数据源而异（文档页码、URL、服务器参考）

**步骤2.4：创建调整计划**
对于每个规范化：
- 记录调整了什么以及为什么
- 引用源（文档页码、URL或数据源参考）
- 按年份量化美元影响
- 评估复发风险
- 显示从报告到调整的计算

**步骤2.5：验证数据完整性**
- 使用公式确认子总计正确相加
- 验证资产负债表平衡
- 检查现金流与资产负债表变化相匹配
- 跨选项卡核对数字，确保一致性
- 标记任何需要调查的不一致

### 第三阶段：构建Excel工作簿

**关键：** 使用xlsx技能进行所有Excel文件操作。在进行下一步之前，请阅读xlsx技能文档。

**步骤3.1：创建标准化选项卡结构**
创建包含以下选项卡的工作簿：
- 执行摘要
- 历史财务报表
- 资产负债表
- 现金流量
- 运营指标
- 物业绩效（如果适用）
- 市场分析
- 投资亮点

**步骤3.2：使用正确的格式构建每个选项卡**
系统性地应用格式规则：
- 标题：粗体，左对齐，11pt字体
- 财务数据：货币格式 $#,##0.0 用于百万
- 运营数据：数字格式 #,##0（无$符号）
- 百分比：0.0%格式
- 年份：文本格式，防止插入逗号
- 负数：使用会计格式，带括号
- 下划线：子总计上方单下划线，总计下方双下划线

**步骤3.3：插入公式进行计算**
- 所有子总计和总计都必须基于公式
- 适当链接资产负债表到损益表
- 链接现金流量表到损益表和资产负债表
- 创建交叉表引用以进行验证
- 避免硬编码任何计算值

### 错误：硬编码行偏移

**不要使用相对偏移 - 当表格结构变化时会失效：**

```python
# ❌ 错误 - 易碎的偏移引用
formula = f"=B{row-15}/B{row-19}"  # row-15是什么？row-19是什么？

# ❌ 错误 - 魔术数字
formula = f"=B{current_row-10}*C{current_row-20}"
```

**为什么这会失败：**
- 静默中断，当添加/删除行时
- 无法通过阅读代码验证正确性
- 在交付的Excel文件中创建调试噩梦

### 第四阶段：情景构建（如果包含预测）

**管理层情景：**
呈现公司提供的预测：
- 提取所有管理层假设
- 记录增长率、利润率扩张、资本需求
- 记录关键驱动因素和敏感性
- 标记需要怀疑的“冰球棒”拐点
- 呈现为“管理层情景”，并清晰标记

**基准情景（风险调整）：**
根据公司特定风险因素对管理层预测进行保守调整：
- 应用收入增长折扣，反映执行风险和历史预测准确性
- 适度调整利润率假设，基于行业基准和运营杠杆
- 如果增长依赖，增加资本支出假设
- 如果低估了营运资本，增加营运资本需求
- 如果适用，基于整合复杂性延迟协同效应的实现
- 记录所有调整的理由和支撑分析

**下行情景（可选但建议用于LBO分析）：**
基于行业周期性和公司脆弱性的压力测试场景：
- 模拟收入下降，反映衰退风险或竞争压力
- 假设压力下的利润率压缩（数量去杠杆、价格压力）
- 测试契约合规性和流动性
- 评估下行保护
- 记录正在压力测试的关键风险

**情景文档要求：**
创建假设时间表，显示：
- 按情景的关键假设（收入增长、利润率、资本支出百分比）
- 每个调整的理由
- 关键变量的敏感性分析
- 如果可用，历史预测准确性
- 与行业基准的比较

### 第五阶段：质量控制与验证

**步骤5.1：数据准确性检查**
验证：
- 每个数字都追溯到源（检查样本，引用文档/URL/服务器）
- 所有计算都是基于公式的（没有硬编码的计算值）
- 子总计和总计数学上正确
- 年份显示正确：2024 不等于 2,024
- 没有公式错误：#REF!, #VALUE!, #DIV/0!, #N/A

**步骤5.2：格式一致性检查**
验证：
- 财务数据有$符号：$50.0, $125.5
- 运营指标没有$符号：100家门店，250名员工
- 百分比格式正确：15.0%, 25.5%
- 负数使用括号：$(15.0) 不等于 -$15.0

**步骤5.3：结构和完整性检查**
确认：
- 所有必需的选项卡存在且按逻辑顺序排列
- 执行摘要简洁（适合一页）
- 全面捕获所有关键指标
- 逻辑地从摘要到详细内容
- 每个选项卡中具有适当的粒度
- 没有缺失数据或不完整的部分

**步骤5.4：专业展示检查**
审查：
- 最小化边框（仅用于结构）
- 一致的缩进（子项缩进2空格）

## 规范化模式

### 常见调整EBITDA

**1. 重组费用**
- 如果确实非经常性（设施关闭、一次性遣散费），则加回
- 如果公司每年重组，则不添加回
- 记录具体性质和非经常性理由
- 示例：2023年重组：$3.0M设施关闭，在源材料中有记录，一次性事件

**2. 股票期权补偿**
- 行业标准：为私募股权分析加回
- 治理为非现金运营费用
- 在所有时期保持一致
- 注意如果异常高或包括一次性拨款

**3. 收购相关费用**
- 加回交易费、整合成本
- 按类型记录具体金额
- 不添加回持续的整合投资
- 引用每个调整的源

**4. 法律和解或诉讼**
- 如果确实孤立事件，则加回
- 评估复发风险（一次性和解 vs. 诉讼模式）
- 记录和解性质
- 考虑这是否是正常业务

**5. 资产出售或减值**
- 从经营EBITDA中排除资产出售的收益/损失
- 如果确实非经常性，则移除减值费用
- 记录出售/减值的资产和原因
- 如果资产产生经营收入，则调整收入

**6. 关联方调整**
- 标准化市场价格以上的关联方费用（租金、管理费）
- 调整为市场利率，并附有支持性文件
- 移除通过业务运行的私人费用
- 记录市场利率比较

### 保守与激进规范化

**管理层情景：**
- 包含管理层提出的所有调整
- 接受公司对“非经常性”的定义
- 更激进的EBITDA调整
- 用于了解管理层的观点

**基准情景（建议用于投资决策）：**
- 仅包含明显的非经常性项目
- 对经常性“一次性”费用进行更严格的审查
- 排除投机性调整
- 更保守、有说服力的，可供投资委员会参考

## 行业特定调整

### 科技/软件即服务
要捕获的关键指标：
- 年收入（ARR）和月收入（MRR）
- 按组合划分的客户数量
- 客户获取成本（CAC）和客户终身价值（LTV）
- 流失率（毛流失率 和 净流失率）
- 净收入留存率
- 40法则（增长率% + EBITDA利润率%）
- 魔术数字（销售效率）

格式说明：ARR是货币（$），客户数量是数字（无$），比率是 %

### 制造业/工业
要捕获的关键指标：
- 生产能力和能力利用率%
- 按产品线生产的产品数量
- 库存周转率
- 毛利率按产品线
- 订单积压

格式说明：单位、产能是数字（无$），利用率是%，收入/成本是货币

### 房地产/酒店
要捕获的关键指标：
- 物业/房间/平方英尺
- 入住率%
- 平均每日房价（ADR）- 货币格式
- 每间可售房收入（RevPAR）- 货币格式
- 净运营收入（NOI）- 货币格式
- 资本化率%
- FF&E储备

格式说明：房间/平方英尺是数字，入住率是%，ADR/RevPAR是货币

### 医疗保健/服务
要捕获的关键指标：
- 地点/设施
- 提供者/员工
- 患者/访问量（数量指标）
- 每次访问收入 - 货币
- 付款人组合%
- 同店增长%

格式说明：地点/访问量是数字，每次访问收入是货币，比率是 %
