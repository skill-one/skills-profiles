# 清理数据

清理活动工作表或指定范围内的混乱数据。

## 环境

- **如果运行在 Excel 内部（Office 插件 / Office JS）：** 直接使用 Office JS (`Excel.run(async (context) => {...})`)。通过 `range.values` 读取，通过 `range.formulas = [["=TRIM(A2)"]]` 写入辅助列公式。原位处理与辅助列决策仍然适用。
- **如果操作的是独立的 .xlsx 文件：** 使用 Python/openpyxl。

## 工作流程

### 第一步：范围

- 如果给定范围（例如 `A1:F200`），则使用它
- 否则使用活动工作表的全用范围
- 分析每一列：检测其主要类型（文本 / 数字 / 日期）并识别异常值

### 第二步：检测问题

| 问题 | 需要查找的内容 |
|---|---|
| 空白 | 前导/尾随空格、重复空格 |
| 案例格式 | 分类列中不一致的大小写 (`usa` / `USA` / `Usa`) |
| 数字作为文本 | 存储为文本的数值；数字单元格中的 `$`、`,`、`%` 等杂项 |
| 日期 | 同一列中混合的日期格式 (`3/8/26`、`2026-03-08`、`March 8 2026`) |
| 重复项 | 完全重复的行和近似重复项（大小写/空格差异） |
| 空值 | 其他列已填充但为空的单元格 |
| 混合类型 | 98% 是数字但包含 3 个文本条目的列 |
| 编码 | mojibake (`Ã©`、`â€™`)、非打印字符 |
| 错误 | `#REF!`、`#N/A`、`#VALUE!`、`#DIV/0!` |

### 第三步：建议修复方案

在更改任何内容之前显示摘要表格：

| 列 | 问题 | 数量 | 建议修复方案 |
|---|---|---|---|

### 第四步：应用

- **优先使用公式而不是硬编码的清理值** — 如果清理后的输出可以用公式表示（例如 `=TRIM(A2)`、`=VALUE(SUBSTITUTE(B2,"$",""))`、`=UPPER(C2)`、`=DATEVALUE(D2)`），请在相邻的辅助列中写入公式，而不是在 Python 中计算结果并覆盖原始数据。这使转换保持透明和可审计。
- 仅在用户明确要求时，或当不存在合理的公式等效方案时（例如编码/mojibake 修复）才原地覆盖计算值
- 对于破坏性操作（删除重复项、填充空白、覆盖原始数据），首先需要用户确认
- 在每个修复类别（空白 → 案例格式 → 数字转换 → 日期 → 去重）之后，向用户展示更改的样本并获取确认，然后才能进入下一个类别
- 报告更改前后的摘要
