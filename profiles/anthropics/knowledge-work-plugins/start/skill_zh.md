# 启动命令

> 如果你看到不熟悉的占位符，或者需要检查哪些工具已连接，请参阅 [CONNECTORS.md](../../CONNECTORS.md)。

初始化任务和内存系统，然后打开统一控制面板。

## 说明

### 1. 检查已存在的内容

检查工作目录是否存在以下内容：
- `TASKS.md` — 任务列表
- `CLAUDE.md` — 工作内存
- `memory/` — 深度内存目录
- `dashboard.html` — 可视化界面

### 2. 创建缺失的内容

**如果 `TASKS.md` 不存在：** 使用标准模板创建它（参见任务管理技能）。将其放置在当前工作目录中。

**如果 `dashboard.html` 不存在：** 从 `${CLAUDE_PLUGIN_ROOT}/skills/dashboard.html` 复制到当前工作目录。

**如果 `CLAUDE.md` 和 `memory/` 不存在：** 这是一个全新设置 — 打开控制面板后，开始内存引导工作流程（见下文）。将这些文件放置在当前工作目录中。

### 3. 打开控制面板

不要使用 `open` 或 `xdg-open` — 在 Cowork 中，代理在虚拟机中运行，shell 打开命令无法到达用户的浏览器。相反，告诉用户：“控制面板已准备好在 `dashboard.html`。从你的文件浏览器中打开它以开始使用。”

### 4. 指导用户

如果一切已初始化：
```
控制面板已打开。你的任务和内存都已加载。
- /productivity:update 以同步任务和检查内存
- /productivity:update --comprehensive 进行所有活动的深度扫描
```

如果内存尚未引导，继续执行步骤 5。

### 5. 引导内存（仅首次运行）

只有当 `CLAUDE.md` 和 `memory/` 还不存在时才执行此操作。

工作场所语言的最佳来源是用户的实际任务列表。真实任务 = 真实缩写。

**询问用户：**
```
你将待办事项或任务列表保存在哪里？这可以是：
- 本地文件（例如，TASKS.md，todo.txt）
- 应用程序（例如。Asana，Linear，Jira，Notion，Todoist）
- 笔记文件

我将使用你的任务来学习你的工作场所缩写。
```

**一旦你获得任务列表的访问权限：**

对每个任务项进行分析，查找潜在的缩写：
- 可能是昵称的名称
- 首字母缩略词或缩写
- 项目引用或代号
- 内部术语或行话

**对每个项进行交互式解码：**

```
任务："向 Todd 发送 PSR，关于凤凰障碍物"

我看到一些我需要确保我理解的术语：

1. **PSR** - 这代表什么？
2. **Todd** - Todd 是谁？（全名，角色）
3. **凤凰** - 这是一个项目代号吗？它是什么？
```

继续对每个任务进行解码，仅询问你尚未解码的术语。

### 6. 可选的全面扫描

解码任务列表后，提供：
```
你想让我对你的消息、电子邮件和文档进行全面扫描吗？
这需要更长时间，但会构建更丰富的关于你工作中的人、项目和术语的上下文。

或者我们可以保留现有内容，稍后添加上下文。
```

**如果他们选择全面扫描：**

从可用的 MCP 源收集数据：
- **聊天：** 最近的消息、频道、私信
- **电子邮件：** 发送的消息、收件人
- **文档：** 最近文档、协作者
- **日历：** 会议、参与者

构建一个包含人员、项目和术语的脑图。按置信度分组呈现结果：
- **准备添加**（高置信度） — 提供直接添加的选项
- **需要澄清** — 询问用户
- **低频率 / 不明确** — 记录以备后用

### 7. 编写内存文件

从收集到的所有内容中创建：

**CLAUDE.md**（工作内存，约 50-80 行）：
```markdown
# 内存

## 我
[Name]，[Role] 在 [Team]。

## 人员
| 谁 | 角色 |
|-----|------|
| **[Nickname]** | [Full Name]，[role] |

## 术语
| 术语 | 含义 |
|------|---------|
| [acronym] | [expansion] |

## 项目
| 名称 | 什么 |
|------|------|
| **[Codename]** | [description] |

## 偏好
- [发现的偏好]
```

**memory/** 目录：
- `memory/glossary.md` — 完整的解码环（首字母缩略词、术语、昵称、代号）
- `memory/people/{name}.md` — 个人资料
- `memory/projects/{name}.md` — 项目详情
- `memory/context/company.md` — 团队、工具、流程

### 8. 报告结果

```
生产力系统就绪：
- 任务：TASKS.md（X 项）
- 内存：X 人，X 术语，X 项目
- 控制面板：在浏览器中打开

使用 /productivity:update 以保持最新状态（添加 --comprehensive 进行深度扫描）。
```

## 备注

- 如果内存已初始化，这只会打开控制面板
- 昵称至关重要 — 始终捕获人们实际如何称呼
- 如果某个源不可用，跳过并记录差距
- 内存通过自然对话在引导后有机增长
