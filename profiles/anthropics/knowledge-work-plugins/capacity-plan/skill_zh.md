# /capacity-plan

> 如果你看到不熟悉的占位符或需要检查哪些工具已连接，请参阅 [CONNECTORS.md](../../CONNECTORS.md)。

分析团队产能并规划资源分配。

## 使用方法

```
/capacity-plan $ARGUMENTS
```

## 我需要你提供的信息

- **团队规模和角色**：你们有哪些人员？
- **当前工作量**：他们正在做什么？（从项目追踪器上传或描述）
- **即将开始的工作**：下一季度有什么计划？
- **限制条件**：预算、招聘时间表、技能要求

## 规划维度

### 人员
- 可用人数和技能
- 当前分配和利用率
- 计划招聘和时间表
- 合同工和供应商的产能

### 预算
- 按类别的运营预算
- 项目特定预算
- 差额跟踪
- 预测与实际对比

### 时间
- 项目时间表和依赖关系
- 关键路径分析
- 缓冲和应急计划
- 截止日期管理

## 利用率目标

| 角色类型 | 目标利用率 | 备注 |
|-----------|-------------------|-------|
| IC / 专家 | 75-80% | 留出空间用于应急工作和成长 |
| 经理 | 60-70% | 管理开销、会议、一对一沟通 |
| 应急响应 / 支持 | 50-60% | 中断式工作是不可预测的 |

## 常见误区

- 规划100%利用率（没有缓冲来应对意外情况）
- 忽略会议负荷和上下文切换成本
- 没有考虑休假、节假日和病假
- 将所有时间视为等同（创意工作≠行政工作）

## 如果连接器可用

如果 **~~项目追踪器** 已连接：
- 自动获取当前工作量和工单分配
- 显示每个人的即将到来的冲刺或季度承诺

如果 **~~日历** 已连接：
- 考虑带薪休假、节假日和定期会议负荷
- 计算每个人的实际可用小时数

## 小贴士

1. **包含所有工作** — 常规工作、项目、支持、会议。人们并非100%可用于项目工作。
2. **规划缓冲** — 目标为80%利用率。100%意味着没有空间应对意外情况。
3. **定期更新** — 产能计划很快过时。每月审查。
