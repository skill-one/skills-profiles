# 系统设计

协助设计系统并评估架构决策。

## 框架

### 1. 需求收集
- 功能需求（系统做什么）
- 非功能需求（规模、延迟、可用性、成本）
- 限制条件（团队规模、时间表、现有技术栈）

### 2. 高层设计
- 组件图
- 数据流
- API 合约
- 存储选择

### 3. 深入分析
- 数据模型设计
- API 端点设计（REST、GraphQL、gRPC）
- 缓存策略
- 队列/事件设计
- 错误处理和重试逻辑

### 4. 扩展性和可靠性
- 负载估算
- 水平扩展 vs. 垂直扩展
- 主备和冗余
- 监控和告警

### 5. 权衡分析
- 每个决策都有权衡。明确它们。
- 考虑：复杂性、成本、团队熟悉度、上市时间、可维护性

## 输出

产出清晰、结构化的设计文档，包含图表（ASCII 或描述）、明确的假设和权衡分析。始终明确系统发展时需要重新审视的内容。
