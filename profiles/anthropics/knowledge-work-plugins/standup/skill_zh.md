# /standup

> 如果你看到不熟悉的占位符，或者需要检查哪些工具已连接，请参阅 [CONNECTORS.md](../../CONNECTORS.md)。

通过整合你各个工具的近期活动来生成站会更新。

## 工作原理

```
┌─────────────────────────────────────────────────────────────────┐
│                        STANDUP                                    │
├─────────────────────────────────────────────────────────────────┤
│  STANDALONE (始终可用)                                       │
│  ✓ 告诉我你做了什么，我会帮你整理             │
│  ✓ 格式化为每日站会（昨天 / 今天 / 阻塞点）      │
│  ✓ 保持简洁、以行动为导向                          │
├─────────────────────────────────────────────────────────────────┤
│  SUPERCHARGED (当你连接你的工具时)                      │
│  + 版本控制：最近的提交和 PR                  │
│  + 项目追踪器：工单状态变更                        │
│  + 聊天：相关的讨论和决策                      │
│  + CI/CD：构建和部署状态                                │
└─────────────────────────────────────────────────────────────────┘
```

## 我需要你提供的信息

**选项 A：让我来提取**
如果你的工具已连接，只需输入 `/standup`，我会自动收集所有信息。

**选项 B：告诉我你做了什么**
"处理了认证迁移，审查了 3 个 PR，在 API 速率限制问题上遇到了阻塞。"

## 输出

```markdown
## 站会 — [日期]

### 昨天
- [如有工单引用，请填写完成的项]
- [完成的项]

### 今天
- [计划中的项（如有工单引用）]
- [计划中的项]

### 阻塞点
- [阻塞点（包含背景信息和可提供帮助的人）]
```

## 如果连接了连接器

如果 **~~版本控制~~** 已连接：
- 提取最近的提交和 PR（已打开、已审查、已合并）
- 高层次总结代码变更

如果 **~~项目追踪器~~** 已连接：
- 提取状态已移动到“进行中”或“已完成”的工单
- 显示即将到来的冲刺项

如果 **~~聊天~~** 已连接：
- 扫描相关的讨论和决策
- 标记需要你回复的线程

## 小贴士

1. **每天早上运行** — 建立习惯，不再为站会笔记手忙脚乱。
2. **添加背景信息** — 生成后，补充关于阻塞点或优先级的任何细节。
3. **分享格式** — 让我为你格式化为 Slack、邮件或你团队的站会工具。
