# 日记账条目准备

**重要提示**：此功能协助处理日记账条目工作流程，但并不提供财务建议。所有条目在发布前均应由具备资质的财务专业人士进行审核。

关于日记账条目准备的最佳实践、标准条目类型、文档要求以及审核工作流程。

## 标准应计类型及其条目

### 应付账款应计

在期末对已收到但尚未开票的商品或服务进行应计。

**典型条目：**
- 借记：费用账户（若符合资产资格则应资本化）
- 贷记：应计负债

**计算来源：**
- 包含已确认收货的采购订单
- 已提供服务但尚未开票的合同
- 定期供应商安排（公用事业、订阅、专业服务）
- 已提交但尚未处理的员工费用报告

**关键注意事项：**
- 在下个期间进行冲销（建议自动冲销）
- 保持期间间一致的估计方法
- 记录估计依据（采购订单金额、合同条款、历史运行率）
- 跟踪实际值与应计值的差异以优化未来估计

### 固定资产折旧

对有形及无形资产计提定期折旧费用。

**典型条目：**
- 借记：折旧/摊销费用（按部门或成本中心）
- 贷记：累计折旧/摊销

**折旧方法：**
- **直线法**：(成本 - 残值) / 使用年限 — 最常见的财务报告方法
- **递减余额法**：加速方法，按固定比率应用于账面净值
- **产量法**：基于实际使用或产出与总预期

**关键注意事项：**
- 从固定资产登记簿或计划运行折旧
- 验证新增资产是否设置正确的使用年限和方法
- 检查报废或减值需要冲销的情况
- 确保账面折旧与税务折旧跟踪的一致性

### 预付费用摊销

在受益期间内摊销预付费用。

**典型条目：**
- 借记：费用账户（保险、软件、租金等）
- 贷记：预付费用

**常见的预付类别：**
- 保险费（通常为12个月期政策）
- 软件许可证和订阅
- 预付租金（如适用租赁条款）
- 预付维护合同
- 会议和活动押金

**关键注意事项：**
- 维护摊销计划，包含开始/结束日期和月度金额
- 审查任何应全额费用化的预付项目（不重要金额）
- 检查已取消或终止的合同需要加速摊销
- 验证新预付款项及时添加到计划中

### 工资应计

对期间应计薪酬及相关成本。

**典型条目：**

*工资应计（支付周期与月末不匹配时）：*
- 借记：工资费用（按部门）
- 贷记：应计工资

*奖金应计：*
- 借记：奖金费用（按部门）
- 贷记：应计奖金

*福利应计：*
- 借记：福利费用
- 贷记：应计福利

*工资税应计：*
- 借记：工资税费用
- 贷记：应计工资税

**关键注意事项：**
- 基于期间工作日与支付周期计算工资应计
- 奖金应计应反映计划条款（目标金额、绩效指标、支付时间）
- 包括雇主侧税费和福利（FICA、FUTA、健康保险、401k匹配）
- 如政策或地区要求，跟踪PTO/休假应计负债

### 收入确认

基于履约义务和交付确认收入。

**典型条目：**

*确认之前递延的收入：*
- 借记：递延收入
- 贷记：收入

*确认新应收款收入：*
- 借记：应收账款
- 贷记：收入

*递延预收收入：*
- 借记：现金 / 应收账款
- 贷记：递延收入

**关键注意事项：**
- 遵循ASC 606五步框架处理与客户合同
- 确定每个合同中的可区分履约义务
- 确定交易价格（包括可变考虑因素）
- 将交易价格分配给履约义务
- 在履约义务满足时确认收入
- 维持合同级详细信息以支持审计

## 支持性文档要求

每个日记账条目应有：

1. **条目描述/备忘录**：清晰、具体地描述条目记录的内容及原因
2. **计算支持**：金额如何得出的依据（公式、计划、源数据参考）
3. **源文件**：参考底层交易或事件（采购订单号、发票号、合同参考、工资登记簿）
4. **期间**：条目适用的会计期间
5. **制单人识别**：谁准备了条目及时间
6. **审批**：根据授权矩阵进行的审核和审批证据
7. **冲销指示器**：条目是否自动冲销及冲销日期

## 审核和审批工作流程

### 典型审批矩阵

| 条目类型 | 金额阈值 | 审批人 |
|---------|-----------------|----------|
| 标准定期 | 任何金额 | 会计经理 |
| 非定期/手动 | < 5万美元 | 会计经理 |
| 非定期/手动 | 5万 - 25万美元 | 总监 |
| 非定期/手动 | > 25万美元 | 首席财务官/财务副总裁 |
| 顶层/合并 | 任何金额 | 总监或以上 |
| 期间外调整 | 任何金额 | 总监或以上 |

*注意：阈值应根据贵组织的实质性和风险承受能力设置。*

### 审核检查清单

在批准日记账条目前，审阅者应验证：

- [ ] 借记等于贷记（条目平衡）
- [ ] 正确的会计期间（未发布到已关闭期间）
- [ ] 账户代码存在且适用于交易
- [ ] 金额数学上准确并支持计算
- [ ] 描述清晰、具体且足以满足审计目的
- [ ] 部门/成本中心/项目编码正确
- [ ] 处理与前期和会计政策一致
- [ ] 自动冲销设置适当（应计项应冲销）
- [ ] 支持性文档完整并已引用
- [ ] 条目金额在制单人权限范围内
- [ ] 无重复现有条目
- [ ] 异常或大额金额有解释和说明

## 常见错误检查

1. **不平衡条目**：借记不等于贷记（系统应防止，但检查手动条目）
2. **错误期间**：条目发布到不正确或已关闭的期间
3. **错误符号**：借记输入为贷记或反之
4. **重复条目**：同一交易记录两次（发布前检查重复）
5. **错误账户**：条目发布到不正确的总账账户（特别是相似账户代码）
6. **缺失冲销**：应计条目未设置为自动冲销，导致重复计算
7. **陈旧应计**：定期应计未根据变化情况更新
8. **圆数估计**：可疑的圆整金额可能无法反映实际计算
9. **错误外汇汇率**：外币条目使用错误汇率或日期
10. **缺失内部公司抵销**：实体间条目无对应抵销
11. **资本化错误**：应资本化的费用，或应费用化的资本化项目
12. **截止错误**：基于交付或服务日期将交易记录在错误期间
