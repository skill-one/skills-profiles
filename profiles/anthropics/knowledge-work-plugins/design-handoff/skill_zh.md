# /设计交付

> 如果您看到不熟悉的占位符或需要检查哪些工具已连接，请参阅 [CONNECTORS.md](../../CONNECTORS.md)。

从设计生成全面的开发者交付文档。

## 使用方法

```
/design-handoff $ARGUMENTS
```

为：@$1 生成交付规范

如果提供了 Figma URL，则从 Figma 拉取设计。否则，从提供的描述或截图进行工作。

## 应包含的内容

### 视觉规范
- 精确的尺寸（内边距、边距、宽度）
- 设计令牌引用（颜色、排版、间距）
- 响应式断点和行为
- 组件变体和状态

### 交互规范
- 点击/轻触行为
- 悬停状态
- 过渡和动画（持续时间、缓动）
- 手势支持（滑动、捏合、长按）

### 内容规范
- 字符限制
- 截断行为
- 空状态
- 加载状态
- 错误状态

### 边缘情况
- 最小/最大内容
- 国际文本（更长的字符串）
- 慢速连接
- 缺失数据

### 可访问性
- 聚焦顺序
- ARIA 标签和角色
- 键盘交互
- 屏幕阅读器公告

## 原则

1. **不要假设** — 如果没有指定，开发者会猜测。指定所有内容。
2. **使用令牌而不是值** — 引用 `spacing-md` 而不是 `16px`。
3. **显示所有状态** — 默认、悬停、激活、禁用、加载、错误、空。
4. **描述原因** — "这会在移动设备上折叠，因为用户主要使用单手" 帮助开发者做出良好的判断。
