# 关闭管理

**重要提示**：此技能协助关闭管理流程，但并不提供财务建议。所有关闭活动均应由具备资格的财务专业人士进行审核。

月度关闭检查清单、任务排序和依赖关系、状态跟踪以及按日组织的常见关闭活动。

## 月度关闭检查清单

### 关闭前（月份最后2-3个营业日）

- [ ] 向所有贡献者发送关闭日历和截止日期提醒
- [ ] 与应付账款（AP）、应收账款（AR）、工资和资金部门确认截止流程
- [ ] 验证所有子系统是否正常运行（ERP、工资、银行）
- [ ] 完成初步银行对账（除最后一天的活动外）
- [ ] 审查未结采购订单，以确定潜在的应计需求
- [ ] 确认工资处理时间表与关闭时间表一致
- [ ] 收集任何已知异常交易的信息

### 关闭日1（T+1：月末第一个营业日）

- [ ] 确认所有明细账模块已完成期末处理
- [ ] 运行应付账款（AP）应计项目，针对已收到但未开票的商品/服务
- [ ] 登记工资条目和工资应计项目（如果工资周期跨越月末）
- [ ] 记录截至月末的现金收入和支出
- [ ] 登记内部交易并确认交易对手方
- [ ] 完成银行对账，使用最终银行对账单
- [ ] 运行固定资产折旧
- [ ] 登记预付费用摊销

### 关闭日2（T+2）

- [ ] 完成收入确认分录和递延收入调整
- [ ] 登记所有剩余应计分录
- [ ] 完成应收账款（AR）明细账对账
- [ ] 完成应付账款（AP）明细账对账
- [ ] 记录库存调整（如适用）
- [ ] 登记外币余额的汇率重估分录
- [ ] 开始资产负债表账户对账

### 关闭日3（T+3）

- [ ] 完成所有资产负债表对账
- [ ] 登记在对账过程中发现的任何调整分录
- [ ] 完成内部交易对账和抵销分录
- [ ] 运行初步试算平衡表和损益表
- [ ] 对损益表进行初步流量分析
- [ ] 调查和解决重大差异

### 关闭日4（T+4）

- [ ] 登记税收准备分录（所得税、销售税、财产税）
- [ ] 完成权益转回（股票补偿、库存股）
- [ ] 最终化所有分录——软关闭
- [ ] 生成初步财务报表（P&L、BS、CF）
- [ ] 进行详细流量分析并准备差异说明
- [ ] 管理层审查财务报表和关键指标

### 关闭日5（T+5）

- [ ] 登记管理层审查后的任何最终调整
- [ ] 最终化财务报表——硬关闭
- [ ] 在ERP/总账系统中锁定期间
- [ ] 向利益相关者分发财务报告包
- [ ] 根据实际结果更新预测/预测
- [ ] 进行关闭回顾——识别流程改进

## 任务排序和依赖关系

### 依赖关系图

任务按必须完成才能开始下一个任务的顺序组织：

```
级别1（无依赖关系——可以立即在T+1开始）：
├── 现金收入/支出记录
├── 银行对账单获取
├── 工资处理/应计
├── 固定资产折旧运行
├── 预付摊销
├── 应付账款（AP）应计准备
└── 内部交易登记

级别2（依赖级别1完成）：
├── 银行对账（需要：现金条目+银行对账单）
├── 收入确认（需要：账单/交付数据最终确定）
├── 应收账款（AR）明细账对账（需要：所有收入/现金条目）
├── 应付账款（AP）明细账对账（需要：所有AP条目/应计）
├── 汇率重估（需要：所有外币条目已登记）
└── 剩余应计分录（需要：所有源数据审查）

级别3（依赖级别2完成）：
├── 所有资产负债表对账（需要：所有分录已登记）
├── 内部交易对账（需要：双方已登记）
├── 对账过程中的调整分录
└── 初步试算平衡表

级别4（依赖级别3完成）：
├── 税收准备（需要：税前收入最终确定）
├── 权益转回
├── 合并和抵销
├── 初步财务报表
└── 初步流量分析

级别5（依赖级别4完成）：
├── 管理层审查
├── 最终调整
├── 硬关闭/期间锁定
├── 财务报告包
└── 预测更新
```

### 关键路径

关键路径决定了最低关闭持续时间。典型关键路径：

```
现金/AP/AR条目 → 明细账对账 → 资产负债表对账 →
  税收准备 → 初步财务报表 → 管理层审查 → 硬关闭
```

要缩短关闭时间：
- 自动化级别1条目（折旧、预付摊销、标准应计）
- 在月份期间进行预对账（持续对账）
- 并行处理独立的对账
- 设定明确的截止日期，对延迟提交采取后果措施
- 使用标准化模板以减少对账准备时间

## 状态跟踪和报告

### 关闭状态仪表板

使用以下属性跟踪每个关闭任务：

| 任务 | 负责人 | 截止日期 | 状态 | 阻塞项 | 备注 |
|------|-------|----------|--------|---------|-------|
| [任务名称] | [人员/角色] | [第T+N天] | 未开始 / 进行中 / 完成 / 阻塞 | [如果阻塞，是什么阻塞] | [任何备注] |

### 状态定义

- **未开始**：任务尚未开始（可能正在等待依赖关系）
- **进行中**：任务正在积极处理中
- **完成**：任务已完成并已审查/批准
- **阻塞**：由于依赖关系、缺失数据或问题，任务无法进行
- **有风险**：任务正在进行中，但可能无法在截止日期前完成

### 每日关闭状态会议（推荐）

在关闭期间，举行简短的（15分钟）每日站立会议：

1. **审查状态板**：逐个检查未完成的任务，标记任何落后的任务
2. **识别阻塞项**：暴露任何阻止任务完成的问题
3. **重新分配或升级**：调整所有权或升级阻塞项以快速解决
4. **更新时间表**：如果任何任务有风险，评估对整体关闭时间表的影响

### 要长期跟踪的关闭指标

| 指标 | 定义 | 目标 |
|--------|-------|------|
| 关闭持续时间 | 从期间结束到硬关闭的营业天数 | 随时间减少 |
| 软关闭后的调整分录数量 | 管理层审查期间提交的分录 | 最小化 |
| 延迟任务数量 | 在截止日期后完成的任务 | 零 |
| 对账异常数量 | 需要调查的对账项 | 随时间减少 |
| 重述/更正数量 | 关闭后发现的错误 | 零 |

## 按日组织的常见关闭活动

### 典型5天关闭日历

| 天数 | 关键活动 | 负责人 |
|------|----------|--------|
| **T+1** | 现金条目、工资、AP应计、折旧、预付摊销、内部交易登记 | 会计人员、工资 |
| **T+2** | 收入确认、剩余应计、明细账对账（AR、AP、FA）、汇率重估 | 收入会计、AP/AR、资金 |
| **T+3** | 资产负债表对账、内部交易对账、抵销、初步试算平衡表、初步流量 | 会计团队、合并 |
| **T+4** | 税收准备、权益转回、初步财务报表、详细流量分析、管理层审查 | 税务、总账、财务规划与分析（FP&A） |
| **T+5** | 最终调整、硬关闭、期间锁定、报告包分发、预测更新、回顾 | 总账、FP&A、财务领导 |

### 加速关闭（3天目标）

对于目标更快关闭的组织：

| 天数 | 关键活动 |
|------|----------|
| **T+1** | 所有分录登记（自动化+手动）、所有明细账对账、银行对账、内部交易对账、初步试算平衡表 |
| **T+2** | 所有资产负债表对账、税收准备、合并、初步财务报表、流量分析、管理层审查 |
| **T+3** | 最终调整、硬关闭、报告包、预测更新 |

**3天关闭的前提条件：**
- 自动化定期分录（折旧、摊销、标准应计）
- 月份期间持续对账（不是在月末全部对账）
- 自动化内部交易抵销
- 月末前完成的预关闭活动（截止日期、应计估计）
- 赋能团队，明确所有权，减少交接
- 实时或近实时子系统集成

## 关闭流程改进

### 常见瓶颈和解决方案

| 瓶颈 | 根本原因 | 解决方案 |
|------|----------|---------|
| 延迟的AP应计 | 等待部门支出确认 | 实施持续应计估计；设定截止日期 |
| 手动分录 | 每月手动准备重复分录 | 在ERP中自动化标准定期分录 |
| 慢速对账 | 每月从头开始 | 实施持续/滚动对账 |
| 内部交易延迟 | 等待交易对手方确认 | 自动化内部交易匹配；设定更严格的截止日期 |
| 管理层审查变更 | 审查期间发现大量调整 | 改进初步审查流程；授权团队尽早发现问题 |
| 缺失支持文件 | 关闭时匆忙寻找文件 | 在整个月份维护文件 |

### 关闭回顾问题

每次关闭后，询问：
1. 这次关闭做得好的地方，我们应该继续什么？
2. 哪些任务比预期花费时间长，为什么？
3. 我们遇到了哪些阻塞项，如何预防？
4. 我们应该在更早的时候发现财务结果的任何意外吗？
5. 我们可以为下个月自动化或简化什么？
