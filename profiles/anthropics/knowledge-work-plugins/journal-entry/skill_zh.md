# 日记账条目准备

> 如果您看到不熟悉的占位符，或者需要检查哪些工具已连接，请参阅 [CONNECTORS.md](../../CONNECTORS.md)。

**重要提示**：此命令有助于辅助日记账条目工作流程，但并不提供财务建议。所有条目在发布前都应由合格的专业财务人员审核。

准备日记账条目时，请确保包含正确的借项、贷项、支持性细节，并查阅相关文档。

## 使用方法

```
/je <类型> <期间>
```

### 参数

- `类型` — 日记账条目类型。可选值包括：
  - `ap-accrual` — 已收到但尚未开票的商品/服务应付账款
  - `fixed-assets` — 固定资产和无形资产的折旧摊销条目
  - `prepaid` — 预付费用摊销（保险、软件、租金等）
  - `payroll` — 薪酬应计费用，包括工资、福利、税费和奖金应计费用
  - `revenue` — 收入确认条目，包括递延收入调整

- `期间` — 会计期间（例如，`2024-12`、`2024-Q4`、`2024`）

## 工作流程

### 1. 收集源数据

如果已连接 ~~erp 或 ~~数据仓库：
- 拉取指定期间的试算平衡表
- 拉取相关账户的明细账信息
- 拉取同类型的前期条目以供参考
- 确定受影响账户的当前总账余额

如果未连接数据源：
> 连接 ~~erp 或 ~~数据仓库以自动拉取总账数据。您也可以粘贴试算平衡表数据或上传电子表格。

提示用户提供：
- 受影响账户的试算平衡表或总账余额
- 明细账信息或支持性报表
- 供参考的前期条目（可选）

### 2. 计算条目

根据 JE 类型：

**应付账款应计费用**：
- 识别截至期末已收到但尚未开票的商品/服务
- 根据采购订单收据、合同或估算计算应计金额
- 借记：费用账户（或资本化项目的资产账户）
- 贷记：应计负债

**固定资产**：
- 拉取固定资产登记簿或折旧表
- 根据资产类别和方法（直线法、加速折旧法、产量法）计算期间折旧
- 借记：折旧费用（按部门/成本中心）
- 贷记：累计折旧

**预付费用**：
- 拉取预付费用摊销表
- 计算每个预付项目的期间摊销金额
- 借记：费用账户（按类型——保险、软件、租金等）
- 贷记：预付费用账户

**薪酬**：
- 计算已工作但尚未支付的应计工资
- 计算应计福利（健康、退休金、带薪休假）
- 计算雇主薪酬税应计费用
- 计算奖金应计费用（如适用，根据计划条款）
- 借记：工资费用、福利费用、薪酬税费用
- 贷记：应计薪酬、应计福利、应计薪酬税

**收入**：
- 审查合同和履约义务
- 根据交付/履行计算应确认的收入
- 调整递延收入余额
- 借记：递延收入（或应收账款）
- 贷记：收入账户（按业务流/类别）

### 3. 生成日记账条目

以标准格式呈现条目：

```
日记账条目：[类型] — [期间]
编制人：[用户]
日期：[期间末日]

| 行号 | 账户代码 | 账户名称 | 借项 | 贷项 | 部门 | 备注 |
|------|-------------|--------------|-------|--------|------------|------|
| 1    | XXXX        | [名称]       | X,XXX |        | [部门]     | [细节] |
| 2    | XXXX        | [名称]       |       | X,XXX  | [部门]     | [细节] |
|      |             | **总计**    | X,XXX | X,XXX  |            |      |

支持性细节：
- [计算依据和假设]
- [支持性报表或文档的参考]

冲销：[是/否——如为是，请指定冲销日期]
```

### 4. 审核清单

最终确定前，请核实：

- [ ] 借项等于贷项
- [ ] 会计期间正确
- [ ] 账户代码有效且映射到正确的总账账户
- [ ] 金额计算正确，并附有支持性细节
- [ ] 备注/描述清晰且足够详细以供审计
- [ ] 部门/成本中心编码正确
- [ ] 条目与前期处理一致
- [ ] 冲销标志设置适当（应计费用应自动冲销）
- [ ] 参考了支持性文档或已附加
- [ ] 条目在用户的审批权限范围内
- [ ] 无异常或非典型金额需要调查

### 5. 输出

提供：
1. 格式化的日记账条目
2. 支持性计算
3. 与同类型前期条目的比较（如可用）
4. 需要审核或跟进的项目
5. 发布说明（手动录入或用户 ERP 的上传格式）
