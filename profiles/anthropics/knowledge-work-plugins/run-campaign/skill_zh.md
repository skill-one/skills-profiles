按顺序链式触发三个技能来运行完整的活动流程。所有者在每个交接点进行批准——未经明确确认，不得越过任何关卡。

解析参数：
- `--lookback`（默认 `90d`）— 向后查找收入下滑的时间范围
- `--channel`（默认 `both`）— `email`、`social` 或 `both`

## 第一步 — 销售分析 + 内容概要（content-strategy）

触发 `content-strategy` 技能工作流：
1. 从 QuickBooks 和 PayPal 拉取指定时间范围内的销售数据。
2. 识别收入下滑——是哪个产品/服务，哪个时间段，幅度如何。
3. 生成 30 天优先级内容概要：要推广什么，要运行什么优惠活动，要保留什么。
4. 向所有者展示概要。等待明确批准“批准，制作资产”后再继续。

如果所有者修改了概要，则整合修改并重新展示。

## 第二步 — 资产生成 + 发送测试（canva-creator）

在第一步批准后，触发 `canva-creator` 技能工作流：
1. 将第一步的批准概要作为输入。
2. 根据概要的优先级构建发布日历。
3. 为每个发布生成品牌一致的 Canva 资产（在所有者批准前，每个资产都要进行屏幕应用预览）。
4. 为每个发布起草标题文案。
5. 在 HubSpot 中安排发送（仅测试，不要实际发送）。
6. 向所有者展示测试中的活动。等待明确批准“批准，发送给 X 分段”后再进行第三步。

## 第三步 — 受众细分（lead-triage）

在第二步批准后，触发 `lead-triage` 技能工作流：
1. 从批准的概要中拉取 HubSpot 联系人，这些联系人匹配活动的目标分段。
2. 根据参与度、公司匹配度、紧急性标记进行评分。
3. 生成两个交付物：
   - **批量发送列表**——接收第二步测试活动的分段
   - **高优先级电话列表**——所有者应亲自致电的前 5 个线索及通话要点
4. 为电话列表预留日历时间。
5. 展示两个列表。等待明确批准“发送”后再将 HubSpot 活动正式上线。

## 批准关卡（必须遵守）
- 不得在步骤间自动推进。每个交接点都需要所有者的明确批准。
- 未经第三步所有者的“发送”指令，不得发送 HubSpot 活动。
- 如果任何连接器无法访问（QuickBooks、PayPal、Canva、HubSpot），则停止，报告失败的连接器，并询问是否重试或中止。

## 输出

以一段总结结束运行：已识别收入下滑，已生成发布内容，分段规模，已安排通话。发送后，链接到 HubSpot 活动URL。
