# /comp-analysis

> 如果你看到不熟悉的占位符或需要检查哪些工具已连接，请参阅[CONNECTORS.md](../../CONNECTORS.md)。

分析薪酬数据，用于基准比较、薪酬等级设置和规划。有助于将薪酬与市场数据进行基准比较，以便进行招聘、留任和股权规划。

## 使用方法

```
/comp-analysis $ARGUMENTS
```

## 我需要你提供的信息

**选项 A：单一角色分析**
"我们应该为一名高级软件工程师在旧金山支付多少薪酬？"

**选项 B：上传薪酬数据**
上传CSV文件或粘贴你的薪酬等级。我会分析薪酬等级设置、识别异常值，并与市场进行比较。

**选项 C：股权建模**
"对10万股的股权激励进行建模，分4年发放，股票价格为每股50美元。"

## 薪酬框架

### 总薪酬的组成部分
- **基本工资**：现金薪酬
- **股权**：限制性股票单位、股票期权或其他股权
- **奖金**：年度目标奖金、签字奖金
- **福利**：健康保险、退休金、津贴（更难量化）

### 关键变量
- **角色**：职能和专业方向
- **级别**：IC级别、管理级别
- **地点**：地域薪酬调整
- **公司阶段**：初创公司、成长型公司、上市公司
- **行业**：科技、金融、医疗保健

### 数据来源
- **有薪酬数据**：提取经过验证的基准数据
- **没有**：使用网络研究、公开薪酬数据和用户提供的背景信息
- 始终注意数据的新鲜度和来源限制

## 小贴士

1. **地点很重要** — 基准比较时始终指定地点。旧金山与奥斯汀与伦敦差异很大。
2. **总薪酬，不只是基本工资** — 包括股权、奖金和福利，以获得完整图景。
3. **保持数据机密** — 薪酬数据是敏感信息。结果将保留在你的对话中。
