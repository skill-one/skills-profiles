# /setup-zoom-oauth

当认证是关键障碍或认证选择将决定整个集成时，使用此技能。

## 范围

- 应用类型选择
- OAuth 授权选择
- 范围规划
- 令牌交换和刷新
- 认证调试和环境假设

## 工作流

1. 确定应用模型和谁在授权谁。
2. 选择正确的授权流程。
3. 确定用户流程所需的最小范围。
4. 定义令牌存储和刷新行为。
5. 在以上步骤明确后，才路由到最相关的参考文档。

## 主要参考

- [oauth](../oauth/SKILL.md)
- [general](../general/SKILL.md)
- [rest-api](../rest-api/SKILL.md)

## 常见错误

- 在阐明参与者模型和租户模型之前选择授权方式
- 在确认具体工作流之前要求广泛范围
- 忘记刷新令牌行为和令牌生命周期处理
- 成功刷新后重用旧的刷新令牌而不是存储新返回的令牌
- 在检查应用配置之前将认证失败视为 API 失败
