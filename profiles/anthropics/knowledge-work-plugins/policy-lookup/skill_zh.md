# /policy-lookup

> 如果你看到不熟悉的占位符或需要检查哪些工具已连接，请参阅[CONNECTORS.md](../../CONNECTORS.md)。

以通俗易懂的语言查询和解释公司政策。通过搜索已连接的知识库或使用提供的手册内容，回答员工关于政策、福利和程序的问题。

## 使用方法

```
/policy-lookup $ARGUMENTS
```

搜索与：$ARGUMENTS 匹配的政策

## 工作原理

```
┌─────────────────────────────────────────────────────────────────┐
│                    POLICY LOOKUP                                   │
├─────────────────────────────────────────────────────────────────┤
│  独立运行（始终可用）                                       │
│  ✓ 用通俗易懂的语言提问任何政策问题                    │
│  ✓ 粘贴你的员工手册，我会搜索它              │
│  ✓ 获得清晰、无专业术语的答案                               │
├─────────────────────────────────────────────────────────────────┤
│  升级版（当你连接你的工具时）                      │
│  + 知识库：自动搜索手册和政策文档                     │
│  + HRIS：提取特定员工的详细信息（PTO余额、福利） │
└─────────────────────────────────────────────────────────────────┘
```

## 常见政策主题

- **PTO和休假**：休假、病假、产假、丧假、带薪休假
- **福利**：健康保险、牙科保险、视力保险、401k、HSA/FSA、健康福利
- **薪酬**：工资时间表、奖金时间、股权归属、费用报销
- **远程工作**：远程工作政策、远程地点、设备津贴、共享办公空间
- **出差**：预订政策、每日津贴、费用报销、审批流程
- **行为准则**：行为准则、骚扰政策、利益冲突
- **职业发展**：专业发展预算、会议政策、学费报销

## 回答方法

1. 搜索与相关政策文件相关的知识库
2. 提供清晰、通俗易懂的答案
3. 引用具体的政策语言
4. 注明任何例外或特殊情况
5. 指向谁可以联系以处理边缘情况

**重要原则：**
- 始终引用源文件和章节
- 如果找不到政策，要明确说明，而不是猜测
- 对于法律或合规问题，建议直接咨询人力资源或法律部门

```markdown
### 例外 / 特殊情况
[任何相关的例外或边缘情况]

### 联系对象
[负责记录之外问题的个人或团队]

[信息来源——文件名、页码或章节]
```

## 如果连接器可用

如果 **~~知识库** 已连接：
- 自动搜索员工手册和政策文档
- 引用具体的文件、章节和页码

如果 **~~HRIS** 已连接：
- 提取员工特定信息，如PTO余额、福利选举和参保状态

## 小贴士

1. **用通俗易懂的语言提问** — "我可以为一个月在欧洲工作吗？" 比 "国际远程工作政策" 更好。
2. **具体提问** — "加利福尼亚州兼职员工的PTO" 比问 "PTO政策" 能得到更好的答案。
