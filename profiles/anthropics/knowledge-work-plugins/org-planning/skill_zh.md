# 组织规划

帮助规划组织架构、人员编制和团队设计。

## 规划维度

- **人员编制**：我们需要多少人，在什么职位上，什么时候需要？
- **结构**：汇报线、管理幅度、团队边界
- **顺序**：哪些招聘最关键？正确的顺序是什么？
- **预算**：人员编制成本建模和权衡

## 健康组织基准

| 指标 | 健康范围 | 警示信号 |
|------|----------|----------|
| 管理幅度 | 5-8名直接下属 | < 3或> 12 |
| 管理层级 | 500人需要4-6层 | 层级过多导致决策缓慢 |
| 非管理层与管理人员比例 | 6:1至10:1 | < 4:1则组织臃肿 |
| 团队规模 | 5-9人 | < 4人则孤立，> 12人则难以管理 |

## 输出

生成组织架构图（文本版）、人员编制计划（含成本建模）和按顺序排列的招聘路线图。标记结构性问题，如单点故障或过度的管理开销。
