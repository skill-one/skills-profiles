运行周五赢家与关注要点简报。提取数据，突出重点，为负责人提供清晰的周末总结。

解析参数：
- `--lookback`（默认：`7d`）— `7d`表示一周或`14d`表示两周滚动对比

## 第一步 — 收入脉搏

使用`business-pulse`技能工作流：

1. 提取lookback期间内的PayPal交易。
2. 提取同一窗口期的HubSpot交易关闭情况。
3. 计算周环比收入变化。
4. 突出贡献排名前三的收入来源（产品/客户/渠道）。

## 第二步 — 销售分解

1. 列出按销量和收入排名前五的产品/服务。
2. 列出销量最低的三项（与前期相比预期下滑）。
3. 标记出现突然增长或下降（变化>20%）的项目。

## 第三步 — 赢家与关注要点总结

格式化输出如下：

```
周五简报 — {日期}

赢家
• {赢家1}
• {赢家2}
• {赢家3}

关注要点
• {关注点1} — {推荐行动}
• {关注点2} — {推荐行动}

本周收入：${金额}（与上周相比{+/-}X%）
```

## 连接器故障

连接任何可用的数据源——该命令会优雅降级。如果PayPal缺失，则跳过交易数据并注明"PayPal未连接——仅使用HubSpot交易数据"。如果HubSpot缺失，则跳过交易关闭情况并注明。如果两者都未连接，则停止并告知负责人："未连接任何收入数据源。连接PayPal或HubSpot以运行周五简报。"

## 审批关卡

- **切勿自动发送或发布此简报。** 始终先显示给负责人审核。
- **切勿自动取消或修改任何内容。** 仅展示数据和建议。

## 输出

以格式化简报结束，并询问负责人："是否需要我发布到Slack、发送给自己邮件或保存？"
