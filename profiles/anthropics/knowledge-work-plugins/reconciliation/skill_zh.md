# 对账

**重要提示**：此功能协助对账工作流程，但并不提供财务建议。所有对账工作均需在正式确认前由具备资质的财务专业人士进行审核。

涵盖总账到明细账、银行对账和公司间对账的账户对账方法及最佳实践。包括对账项目分类、账龄分析和升级处理。

## 对账类型

### 总账到明细账对账

将总账控制账户余额与明细账详细余额进行比较。

**常见账户：**
- 应收账款（总账控制 vs 应收账款明细账账龄）
- 应付账款（总账控制 vs 应付账款明细账账龄）
- 固定资产（总账控制 vs 固定资产登记簿）
- 库存（总账控制 vs 库存估值报告）
- 预付费用（总账控制 vs 预付费用摊销计划）
- 应计负债（总账控制 vs 应计明细表）

**流程：**
1. 提取截至期末的控制账户总账余额
2. 提取截至同一日期的明细账试算平衡表或明细报告
3. 比较总额——如果实时入账则应一致
4. 调查任何差异（入账时间、未反映的手工分录、接口错误）

**常见差异原因：**
- 手工分录已入账到控制账户但未反映在明细账
- 明细账交易尚未与总账接口
- 批量入账的时间差异
- 总账中的重分类分录未进行明细账调整
- 系统接口错误或失败入账

### 银行对账

将总账现金余额与银行对账单余额进行比较。

**流程：**
1. 获取截至期末的银行对账单余额
2. 提取截至同一日期的总账现金账户余额
3. 确认未兑现支票（已开出但银行未结清）
4. 确认在途存款（已入账到总账但银行尚未入账）
5. 确认总账尚未记录的银行费用、利息或调整
6. 双方对账至调整后余额

**标准格式：**

```
银行对账单余额：         $XX,XXX
加：在途存款            $X,XXX
减：未兑现支票           ($X,XXX)
加/减：银行错误               $X,XXX
调整后银行余额：              $XX,XXX

总账余额：         $XX,XXX
加：未记录的利息/贷项            $X,XXX
减：未记录的银行费用       ($X,XXX)
加/减：总账错误                 $X,XXX
调整后总账余额：                $XX,XXX

差异：                         $0.00
```

### 公司间对账

对关联实体的余额进行对账，确保合并时净额为零。

**流程：**
1. 提取每对实体的公司间应收/应付余额
2. 比较实体A从实体B的应收款与实体B对实体A的应付款
3. 识别并解决差异
4. 确认所有公司间交易均已在双方记录
5. 验证合并消除分录是否正确

**常见差异原因：**
- 一方记录但另一方未记录的交易（时间差异）
- 各实体使用的汇率不同
- 分类错误（公司间 vs 第三方）
- 争议金额或未应用的付款
- 各实体间不同的期末截止做法

## 对账项目分类

### 类别1：时间差异

因正常处理时间而产生的项目，无需采取行动即可清除：

- **未兑现支票**：已入账到总账但等待银行结清的支票
- **在途存款**：已入账到总账但等待银行入账的存款
- **在途交易**：在一个系统中已入账但等待接口到另一个系统的项目
- **待审批交易**：等待在一个系统中审批后入账的交易

**预期解决**：这些项目应在正常处理周期内清除（通常为1-5个营业日）。无需调整分录。

### 类别2：需要调整

需要通过分录纠正的项目：

- **未记录的银行费用**：银行费用、电汇费用、退回项目费用
- **未记录的利息**：银行/贷款机构的利息收入或支出
- **记录错误**：金额错误、账户错误、重复记录
- **缺失分录**：在一个系统中存在但另一个系统无对应分录的交易
- **分类错误**：正确记录但在错误账户中

**操作**：准备调整分录以纠正总账或明细账。

### 类别3：需要调查

无法立即解释的项目：

- **未识别差异**：无明显原因的方差
- **争议项目**：双方争议的金额
- **账龄未清除项目**：未在预期时间内清除的项目
- **重复未解释差异**：每期都出现的同类差异

**操作**：调查根本原因，记录调查结果，如未解决则升级。

## 未清项目账龄分析

跟踪未清项目的账龄以识别需要升级的陈旧项目：

| 账龄区间 | 状态 | 操作 |
|-----------|--------|--------|
| 0-30天 | 当前 | 监控——在正常处理周期内 |
| 31-60天 | 账龄 | 调查——跟进项目未清除原因 |
| 61-90天 | 过期 | 升级——通知主管，记录调查 |
| 90天以上 | 陈旧 | 升级至管理层——可能需要冲销或调整 |

### 账龄报告格式

| 项目编号 | 描述 | 金额 | 起始日期 | 账龄（天） | 类别 | 状态 | 负责人 |
|--------|-------------|--------|-----------------|------------|----------|--------|-------|
| 1      | [详情]    | $X,XXX | [日期]          | XX         | [类型]   | [状态] | [姓名] |

### 趋势分析

跟踪对账项目总额随时间变化以识别增长余额：

- 比较本期未清项目总额与上期
- 如未清对账项目总额超过重要性门槛则标记
- 如项目数量逐期增长则标记
- 识别每期都出现的项目（可能表明流程问题）

## 升级阈值

根据组织的风险承受能力定义升级触发条件：

| 触发条件 | 阈值（示例） | 升级 |
|---------|---------------------|------------|
| 单个项目金额 | > $10,000 | 主管审核 |
| 单个项目金额 | > $50,000 | 控制师审核 |
| 未清对账项目总额 | > $100,000 | 控制师审核 |
| 项目账龄 | > 60天 | 主管跟进 |
| 项目账龄 | > 90天 | 控制师/管理层审核 |
| 未对账差异 | 任何金额 | 无法关闭——必须解决或记录 |
| 增长趋势 | 3+连续期 | 流程改进调查 |

*注意：根据组织的材料重要性水平和风险偏好设置阈值。上述示例仅供参考。*

## 对账最佳实践

1. **及时性**：在对账工作应在期末后（通常为T+3至T+5个营业日）完成的截止日历期限内完成
2. **完整性**：按定义频率对账所有资产负债表账户（重要账户每月，不重要账户每季度）
3. **文档记录**：每项对账工作应包括编制人、审核人、日期和对账项目的清晰说明
4. **职责分离**：对账人员不应是同一账户交易处理人员
5. **跟进处理**：跟踪未清项目直至解决——不要无限期地结转项目
6. **根本原因分析**：对于重复的对账项目，调查并解决底层流程问题
7. **标准化**：在所有账户中使用一致的模板和流程
8. **文档保留**：根据组织的文档保留政策保留对账和支撑明细
