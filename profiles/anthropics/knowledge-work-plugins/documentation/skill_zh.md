# 技术文档

为不同的受众和目的编写清晰、可维护的技术文档。

## 文档类型

### README
- 文档是什么以及为什么存在
- 快速入门（5分钟内获得首次成功）
- 配置和使用
- 贡献指南

### API文档
- 带有请求/响应示例的端点参考
- 身份验证和错误代码
- 速率限制和分页
- SDK示例

### 运维手册
- 何时使用此运维手册
- 前置条件和所需的访问权限
- 步骤详解
- 回滚步骤
- 升级路径

### 架构文档
- 背景和目标
- 带有图表的高级设计
- 关键决策和权衡
- 数据流和集成点

### 入门指南
- 环境设置
- 关键系统及其连接方式
- 常见任务带步骤演示
- 需要向谁咨询什么问题

## 原则

1. **为读者而写** — 谁在阅读以及他们需要什么？
2. **从最有用的信息开始** — 不要埋没重点
3. **展示而非说明** — 代码示例、命令、截图
4. **保持更新** — 过时的文档比没有文档更糟糕
5. **链接而非复制** — 引用其他文档而不是复制
