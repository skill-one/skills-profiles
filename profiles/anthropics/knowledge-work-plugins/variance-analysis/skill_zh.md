# 差异分析

**重要提示**：此技能可协助差异分析工作流程，但并不提供财务建议。所有分析结果在使用于报告前，均应由具备资质的财务专业人士进行审核。

差异分解技术、重要性门槛、叙述性生成、瀑布图方法以及预算与实际与预测的比较。

## 差异分解技术

### 价格/数量分解

最基础的一种差异分解方法。用于收入、商品成本以及任何可表示为价格×数量的指标。

**公式：**
```
总差异 = 实际值 - 预算值（或前期值）

数量效应 = (实际数量 - 预算数量) × 预算价格
价格效应 = (实际价格 - 预算价格) × 实际数量
组合效应 = 剩余项（交互项），或按比例分配

验证：数量效应 + 价格效应 = 总差异
               （当组合效应包含在价格/数量项中时）
```

**三向分解（分离组合效应）：**
```
数量效应 = (实际数量 - 预算数量) × 预算价格 × 预算组合
价格效应  = (实际价格 - 预算价格) × 预算数量 × 实际组合
组合效应    = 预算价格 × 预算数量 × (实际组合 - 预算组合)
```

**示例 — 收入差异：**
- 预算：10,000单位@ $50 = $500,000
- 实际：11,000单位@ $48 = $528,000
- 总差异：+$28,000有利
  - 数量效应：+1,000单位 × $50 = +$50,000（有利 — 销售了更多单位）
  - 价格效应：-$2 × 11,000单位 = -$22,000（不利 — ASP下降）
  - 净额：+$28,000

### 率/组合分解

用于分析跨不同单位经济模型的混合率。

**公式：**
```
率效应 = Σ(实际数量_i × (实际率_i - 预算率_i))
组合效应  = Σ(预算率_i × (实际数量_i - 预算组合下的预期数量_i))
```

**示例 — 毛利率差异：**
- 产品A：60%的毛利率，产品B：40%的毛利率
- 预算组合：50% A，50% B → 混合毛利率50%
- 实际组合：40% A，60% B → 混合毛利率48%
- 组合效应解释了2个百分点的毛利率压缩

### 人员数量/薪酬分解

用于分析工资和人力成本差异。

```
总薪酬差异 = 实际薪酬 - 预算薪酬

分解为：
1. 人员数量差异    = (实际HC - 预算HC) × 预算平均薪酬
2. 率差异         = (实际平均薪酬 - 预算平均薪酬) × 预算HC
3. 组合差异          = 由于层级/部门组合变化导致的差异
4. 时间差异       = 招聘早于/晚于计划（部分期间效应）
5. 人员流失影响      = 非计划离职带来的节省（部分被填补成本抵消）
```

### 支出类别分解

用于经营费用分析，当价格/数量不适用时。

```
总经营费用差异 = 实际经营费用 - 预算经营费用

分解为：
1. 人员驱动成本    （工资、福利、工资税、招聘）
2. 数量驱动成本       （托管、交易费、佣金、运费）
3. 自由裁量支出       （差旅、活动、专业服务、营销计划）
4. 合同/固定成本   （租金、保险、软件许可证、订阅）
5. 一次性 / 非经常性  （遣散费、法律和解、冲销、项目成本）
6. 时间 / 分阶段          （支出在不同期间之间的转移与计划）
```

## 重要性门槛和调查触发条件

### 设置门槛

重要性门槛决定哪些差异需要调查和叙述性解释。根据以下条件设置门槛：

1. **财务报表重要性：** 通常为关键基准（收入、总资产、净利润）的1-5%
2. **项目金额：** 金额较大的项目应设置较低百分比门槛
3. **波动性：** 波动性较大的项目可能需要更高的门槛以避免噪音
4. **管理层关注：** 哪个级别的差异会改变决策？

### 推荐的门槛框架

| 比较类型 | 美元门槛 | 百分比门槛 | 触发条件 |
|----------------|-----------------|---------------------|---------|
| 实际与预算 | 组织特定 | 10% | 任何一方超出 |
| 实际与前期 | 组织特定 | 15% | 任何一方超出 |
| 实际与预测 | 组织特定 | 5% | 任何一方超出 |
| 顺序（环比） | 组织特定 | 20% | 任何一方超出 |

*根据组织规模设置美元门槛。常见做法：收入报表项目为0.5%-1%的收入。*

### 调查优先级

当多个差异超出门槛时，按以下顺序优先调查：

1. **最大绝对金额差异** — 对P&L最大的影响
2. **最大百分比差异** — 可能表明流程问题或错误
3. **意外方向** — 差异与趋势或预期相反
4. **新差异** — 原本正常的项现在偏离
5. **累积/趋势差异** — 每期都在增长

## 叙述性生成用于差异解释

### 每个差异叙述的结构

```
[项目名称]: [有利/不利]差异$[金额]([百分比]%)
与[比较基础]对于[期间]

驱动因素：[主要驱动因素描述]
[2-3句话解释差异的业务原因，具体量化贡献因素]

展望：[一次性 / 预计持续 / 改善 / 恶化]
行动：[无需处理 / 监控 / 进一步调查 / 更新预测]
```

### 叙述质量检查清单

好的差异叙述应该：

- [ ] **具体：** 指出实际驱动因素，而不仅仅是“高于预期”
- [ ] **量化：** 包括每个驱动因素的金额和百分比影响
- [ ] **因果：** 解释为什么会发生，而不仅仅是发生了什么
- [ ] **前瞻性：** 说明差异是否预计会持续
- [ ] **可行动：** 确定是否需要后续处理或决策
- [ ] **简洁：** 2-4句话，不是一段填充内容

### 常见叙述反模式需避免

- “收入高于预算是由于收入更高”（循环论证 — 无实际解释）
- “本期费用提高”（模糊 — 哪些费用？为什么？）
- “时间”而不具体说明是什么早于/晚于以及何时会正常化
- “一次性”而不解释项目是什么
- “各种小额项目”对于重大差异（必须进一步分解）
- 只关注最大驱动因素而忽略抵消项

## 瀑布图方法

### 概念

瀑布图（或桥梁图）显示如何通过一系列正负贡献因素从某个值到另一个值。用于可视化差异分解。

### 数据结构

```
起始值：  [基准/预算/前期期间金额]
驱动因素： [列出带符号金额的贡献因素]
结束值：    [实际/当前期间金额]

验证：    起始值 + 所有驱动因素之和 = 结束值
```

### 基于文本的瀑布格式

当没有图表工具可用时，以文本瀑布形式呈现：

```
瀑布图：收入 — Q4实际与Q4预算

Q4预算收入                                    $10,000K
  |
  |--[+] 数量增长（新客户）               +$800K
  |--[+] 扩张收入（现有客户）              +$400K
  |--[-] 价格下调 / 折扣               -$200K
  |--[-] 流失 / 收缩                          -$350K
  |--[+] 外汇利好                          +$50K
  |--[-] 时间（交易滑至Q1）                 -$150K
  |
Q4实际收入                                    $10,550K

净差异：+$550K (+5.5%有利)
```

### 桥接对账表

补充瀑布图的对账表：

| 驱动因素 | 金额 | 差异百分比 | 累计 |
|--------|--------|---------------|------------|
| 数量增长 | +$800K | 145% | +$800K |
| 扩张收入 | +$400K | 73% | +$1,200K |
| 价格下调 | -$200K | -36% | +$1,000K |
| 流失 / 收缩 | -$350K | -64% | +$650K |
| 外汇利好 | +$50K | 9% | +$700K |
| 时间（交易滑移） | -$150K | -27% | +$550K |
| **总差异** | **+$550K** | **100%** | |

*注意：单个驱动因素的百分比可能超过100%，当存在抵消项时。*

### 瀑布图最佳实践

1. 驱动因素按从最大正到最大负（或逻辑业务顺序）排序
2. 最多5-8个驱动因素 — 将较小项汇总到“其他”
3. 验证瀑布图对账（起始值 + 驱动因素 = 结束值）
4. 颜色编码：有利为绿色，不利为红色（在视觉图表中）
5. 每个条形标注金额和简短描述
6. 包含“总差异”总结条形

## 预算与实际与预测比较

### 三向比较框架

| 指标 | 预算 | 预测 | 实际 | 预算差异 ($) | 预算差异 (%) | 预测差异 ($) | 预测差异 (%) |
|--------|--------|----------|--------|-------------|-------------|---------------|---------------|
| 收入 | $X | $X | $X | $X | X% | $X | X% |
| 成本 | $X | $X | $X | $X | X% | $X | X% |
| 毛利润 | $X | $X | $X | $X | X% | $X | X% |

### 使用每种比较的时机

- **实际与预算：** 年度绩效评估、薪酬决策、董事会报告。预算在年初设定且通常不更改。
- **实际与预测：** 运营管理、识别新兴问题。预测定期（每月或每季度）更新以反映当前预期。
- **预测与预算：** 了解自规划以来预期如何变化。用于识别规划准确性问题。
- **实际与前期：** 趋势分析、顺序绩效。当预算无意义时有用（新业务线、并购后）。
- **实际与上年同期：** 同比增长分析、季节性调整比较。

### 预测准确性分析

跟踪预测随时间准确性以改进规划：

```
预测准确性 = 1 - |实际 - 预测| / |实际|

MAPE（平均绝对百分比误差） = 各期 |实际 - 预测| / |实际| 的平均值
```

| 期间 | 预测 | 实际 | 差异 | 准确性 |
|--------|----------|--------|----------|----------|
| 1月    | $X       | $X     | $X (X%)  | XX%      |
| 2月    | $X       | $X     | $X (X%)  | XX%      |
| ...    | ...      | ...    | ...      | ...      |
| **平均**|          |        | **MAPE** | **XX%**  |

### 差异趋势分析

跟踪差异随年度变化以识别系统性偏差：

- **持续有利：** 预算可能过于保守（沙袋）
- **持续不利：** 预算可能过于激进或执行问题
- **增长不利：** 性能恶化或目标不切实际
- **缩小差异：** 预测准确性逐年提高（正常模式）
- **波动：** 不可预测的业务或预测方法不佳
