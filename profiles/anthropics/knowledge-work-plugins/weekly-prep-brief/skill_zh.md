# 每周准备简报

生成一份全面的每周简报，涵盖未来7天内与所有外部客户或潜在客户的每一次会议，并从 Common Room 获取每场会议的账户和联系人研究。

## 简报流程

### 第一步：获取本周的外部会议

**选项 A — 连接日历：**
使用 `~~calendar` 连接器获取未来7天（或用户指定范围）内安排的所有会议。筛选以仅保留外部会议——那些有组织外部人员参加的会议。丢弃仅限内部的会议、与同事的一对一会议以及重复性的内部同步会议。

为每场外部会议识别：
- 公司名称
- 会议日期和时间
- 外部参会人员姓名和电子邮件地址

**选项 B — 未连接日历：**
询问用户："为了构建您的每周准备简报，我需要您的即将到来的外部通话。请列出它们：公司名称、日期/时间和参会人员姓名。"

接受自由格式输入，并在继续之前将其解析为结构化列表。

### 第二步：确认会议列表

在开始研究之前，向用户展示已识别的会议以供确认：

> "这是我为您找到的本周外部通话。请告诉我是否有任何遗漏或应该排除的内容：
> - [公司] — [日期]，[时间] — [参会人员]
> - ..."

这可以防止在已取消或错误的会议上进行浪费研究。

### 第三步：研究每场会议

对于每场确认的外部会议，尽可能并行运行：
1. **账户研究** — 使用账户研究技能获取完整的账户快照
2. **联系人研究** — 使用联系人研究技能为每个外部参会人员获取个人资料

Common Room 数据是主要来源。在 CR 研究之后，对每家公司进行快速 **时效性检查**——这是补充性的，不是主要的：
- 搜索 `"[公司名称]" 新闻` 并限定在最后7天内
- 对于高管参会人员，搜索他们的姓名以查找最近的公开帖子或访谈
- 仅包含真正值得注意的发现（融资、领导层变动、重大新闻）。不要用一般新闻填充简报。

深度校准：
- 对于高优先级账户（大账户、开放机会、续订风险），进行完整深度研究
- 对于低优先级或简短会议，生成简短的快照（每个3-4个要点）

### 第四步：整合每周简报

将所有逐次会议的研究整合到一份结构化文档中，按会议日期/时间排序。

以简报级别的概述开头，标出：
- 任何有紧急信号的账户（有风险、试用到期、扩张机会）
- 任何需要特别准备或高管参与的会议
- 外部通话总数和估计时间投入

## 输出格式

```
# 每周准备简报 — [日期]周

## 周概述
[2-4个要点：关键主题、标记的优先级、通话数量]

---

## [星期一 / 星期二 / 等.]

### [公司名称] — [时间]
**参会人员：** [姓名和职务]
**会议类型：** [发现性会议 / QBR / 续订 / 扩张 / 等. — 如果可能则推断]

**公司快照**
[4-5个要点：账户状态、主要信号、近期活动]

**参会人员简介**
- **[姓名]** ([职务])：[2-3个要点关于他们的信号、角色、对话角度]
- [重复每个参会人员]

**本周主要信号**
[2-3个最相关的信号，针对此特定通话]

**本周新闻** [如果发现值得注意的新闻]
[仅包含真正值得注意的发现——融资、领导层变动、重大新闻]

**建议目标**
[1-2句话：在这次会议中要实现什么]

---

[按日期/时间排序，重复每个会议]
```

## 当会议数据稀疏时

如果 Common Room 对特定会议的账户或参会人员返回有限数据，请使用压缩格式代替完整模板生成该会议：

```
### [公司名称] — [时间] ⚠️ 数据有限
**参会人员：** [如果知道，姓名和职务]
**可用数据：** [Common Room 实际返回的内容]

**网络搜索结果**
[来自网络搜索的发现——公司新闻、参会人员领英资料]

**注意：** Common Room 对此账户的数据有限。代表可能需要在此次通话前直接在 CR 中检查或从同事那里收集背景信息。
```

不要从稀疏数据生成完整的会议准备部分（公司快照、信号重点、谈话要点、建议目标）。简短的诚实部分比虚构的完整部分更有用。

## 质量标准

- 保持每个会议部分可扫描——代表们通常在早上用手机阅读这些内容
- 始终按日期/时间升序排序
- 突出标记紧急情况（风险、试用到期、开放机会）——不要隐藏它们
- 如果会议的 Common Room 数据非常稀疏，请使用上述稀疏数据格式——永远不要用猜测填充完整模板
- 对于有4-6次会议的一周，总简报应在10-15分钟内可读
- **每个事实都必须来自工具调用**——没有虚构的交易背景、活动或信号
