# 统计分析技能

描述性统计、趋势分析、异常值检测、假设检验以及在何时应谨慎对待统计声明。

## 描述性统计方法

### 中心趋势

根据数据选择合适的中心趋势度量：

| 情况 | 使用 | 原因 |
|---|---|---|
| 对称分布，无异常值 | 均值 | 最有效的估计量 |
| 偏态分布 | 中位数 | 对异常值具有鲁棒性 |
| 分类或顺序数据 | 众数 | 非数值数据的唯一选项 |
| 高偏态且存在异常值（例如，每用户收入） | 中位数+均值 | 报告两者；差距显示偏态 |

**始终报告商业指标中的均值和中位数。** 如果它们差异很大，则数据是偏态的，仅凭均值会具有误导性。

### 变异和离散程度

- **标准差**：值通常偏离均值的程度。用于正态分布数据。
- **四分位距（IQR）**：从p25到p75的距离。对异常值具有鲁棒性。用于偏态数据。
- **变异系数（CV）**：StdDev / Mean。用于比较不同尺度的指标之间的变异性。
- **极差**：最大值减去最小值。对异常值敏感，但能快速了解数据范围。

### 商业环境中的百分位数

报告关键百分位数，以比均值提供更丰富的故事：

```
p1:   最底1% (地板 / 典型最小值)
p5:   正常范围的下限
p25:  第一四分位数
p50:  中位数 (典型用户)
p75:  第三四分位数
p90:  顶部10% / 高价值用户
p95:  正常范围的上限
p99:  顶部1% / 极端用户
```

**示例叙述**： "中位数会话时长为4.2分钟，但顶部10%的用户每次会话超过22分钟，将均值拉高至7.8分钟。"

### 描述分布

描述你分析的每个数值分布：

- **形状**：正态、右偏态、左偏态、双峰、均匀、重尾
- **中心**：均值和中位数（以及它们之间的差距）
- **离散程度**：标准差或IQR
- **异常值**：有多少以及多么极端
- **界限**：是否存在自然地板（零）或天花板（100%）？

## 趋势分析和预测

### 识别趋势

**移动平均**来平滑噪声：
```python
# 7天移动平均（适用于具有周周期性的每日数据）
df['ma_7d'] = df['metric'].rolling(window=7, min_periods=1).mean()

# 28天移动平均（平滑周周期和月周期）
df['ma_28d'] = df['metric'].rolling(window=28, min_periods=1).mean()
```

**同期比较**：
- 周同比 (WoW)：与上周同一天比较
- 月同比 (MoM)：与上个月同期比较
- 年同比 (YoY)：季节性业务的黄金标准
- 同日去年：与特定日历日比较

**增长率**：
```
简单增长率：(当前 - 上一个) / 上一个
CAGR：(期末 / 期初) ^ (1 / 年数) - 1
对数增长率：ln(当前 / 上一个) -- 更适用于波动较大的序列
```

### 季节性检测

检查周期性模式：
1. 绘制原始时间序列 -- 首先进行视觉检查
2. 计算星期几平均值：是否存在明显的周模式？
3. 计算年份内月份平均值：是否存在年度周期？
4. 比较期间时，始终使用年同比或同期比较，以避免将趋势与季节性混淆

### 预测（简单方法）

对于商业分析师（而非数据科学家），使用简单方法：

- **朴素预测**：明天=今天。用作基线。
- **季节性朴素**：明天=上周同一天/去年同一天。
- **线性趋势**：将历史数据拟合成一条直线。仅适用于明显的线性趋势。
- **移动平均预测**：使用移动平均作为预测值。

**始终传达不确定性**。提供范围，而不是点估计：
- "根据3个月趋势，我们预计下个月将有10K-12K次注册"
- 不是 "下个月我们将正好获得11,234次注册"

**何时升级给数据科学家**：非线性趋势、多个季节性、外部因素（营销支出、假期），或当预测精度对资源分配很重要时。

## 异常值和异常值检测

### 统计方法

**Z分数方法**（适用于正态分布数据）：
```python
z_scores = (df['value'] - df['value'].mean()) / df['value'].std()
outliers = df[abs(z_scores) > 3]  # 超过3个标准差
```

**IQR方法**（对非正态分布具有鲁棒性）：
```python
Q1 = df['value'].quantile(0.25)
Q3 = df['value'].quantile(0.75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR
outliers = df[(df['value'] < lower_bound) | (df['value'] > upper_bound)]
```

**百分位数方法**（最简单）：
```python
outliers = df[(df['value'] < df['value'].quantile(0.01)) |
              (df['value'] > df['value'].quantile(0.99))]
```

### 处理异常值

不要自动删除异常值。相反：

1. **调查**：这是数据错误、真实极端值还是不同的人群？
2. **数据错误**：修正或删除（例如，负年龄、1970年的时间戳）
3. **真实极端值**：保留它们，但考虑使用稳健统计（中位数而不是均值）
4. **不同的人群**：将它们分段进行单独分析（例如，企业客户与中小企业客户）

**报告你做了什么**： "我们排除了47条记录（0.3%），交易金额>50K，这些记录代表单独分析的企业批量订单。"

### 时间序列异常值检测

用于检测时间序列中不寻常值的：

1. 计算预期值（移动平均或去年同期）
2. 计算与预期的偏差
3. 标记超过阈值的偏差（通常为2-3个标准差的残差）
4. 区分点异常值（单个不寻常值）和变化点（持续变化）

## 假设检验基础

### 何时使用

当你需要确定观察到的差异是否可能是真实的，或者可能是由于随机机会造成的时，使用假设检验。常见场景：

- A/B测试结果：变体B是否实际上比A更好？
- 前后比较：产品变化是否真的推动了指标？
- 分组比较：企业客户是否真的留存率更高？

### 框架

1. **零假设 (H0)**：没有差异（默认假设）
2. **备择假设 (H1)**：存在差异
3. **选择显著性水平（alpha）**：通常为0.05（5%的假阳性概率）
4. **计算检验统计量和p值**
5. **解释**：如果p < alpha，则拒绝H0（存在真实差异的证据）

### 常见检验

| 场景 | 检验 | 何时使用 |
|---|---|---|
| 比较两组均值 | t检验（独立） | 正态数据，两组 |
| 比较两组比例 | 比例z检验 | 转化率，二元结果 |
| 比较配对测量 | 配对t检验 | 同一实体的前后比较 |
| 比较三组以上均值 | 方差分析 | 多个分组或变体 |
| 非正态数据，两组 | Mann-Whitney U检验 | 偏态指标，顺序数据 |
| 类别之间的关联 | 卡方检验 | 两个分类变量 |

### 实际意义与统计意义

**统计意义**意味着差异不太可能由于机会造成。

**实际意义**意味着差异足够大，对商业决策有影响。

差异可能具有统计意义，但实际无意义（大样本时常见）。始终报告：
- **效应量**：差异有多大？（例如， "变体B将转化率提高了0.3个百分点"）
- **置信区间**：真实效应的可能范围？
- **商业影响**：这会转化为多少收入、用户或其他商业术语？

### 样本量考虑

- 小样本即使p值显著也会产生不可靠的结果
- 比例的经验法则：每组至少需要30个事件才能基本可靠
- 检测小效应（例如，1%转化率变化），每组可能需要数千个观察值
- 如果样本量小，请说明： "每组只有200个观察值，我们无法检测到小于X%的效应"

## 何时应谨慎对待统计声明

### 相关性不等于因果关系

当你发现相关性时，明确考虑：
- **反向因果关系**：也许是B导致A，而不是A导致B
- **混杂变量**：也许是C导致A和B
- **巧合**：变量足够多时，虚假相关性是不可避免的

**你能说的**： "使用功能X的用户留存率提高了30%"
**你不能说的（除非有更多证据）**： "功能X导致留存率提高了30%"

### 多重比较问题

当你测试许多假设时，一些会由于机会而"显著"：
- 测试20个指标在p=0.05时意味着大约1个会虚假显著
- 如果你测试了许多分组后才找到一个不同的，请说明
- 使用Bonferroni校正（将alpha除以测试次数）或报告运行了多少次测试来调整多重比较

### 辛普森悖论

聚合数据中的趋势在数据分段时可能逆转：
- 始终检查结论是否适用于关键分组
- 示例：整体转化率上升，但每个分组的转化率下降 -- 因为混合转向了更高转化的分组

### 幸存者偏差

你只能分析"幸存"到数据集中的实体：
- 分析活跃用户会忽略那些已流失的用户
- 分析成功公司会忽略那些失败的公司
- 始终问： "这个数据集中缺少谁，如果包括他们，结论会改变吗？"

### 生态谬误

聚合趋势可能不适用于个人：
- "X值较高的国家Y值也较高" 并不意味着 "X值较高的个人Y值也较高"
- 小心将组级发现应用于个案

### 对特定数字的锚定

警惕虚假精度：
- "下个季度流失率将为4.73%" 暗示了比实际更确定的信心
- 倾向于范围： "根据历史模式，我们预计流失率在4-6%之间"
- 适当舍入： "大约5%" 通常比 "4.73%" 更诚实
