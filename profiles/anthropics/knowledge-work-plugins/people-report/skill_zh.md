# /people-report

> 如果你看到不熟悉的占位符或需要检查哪些工具已连接，请参阅[CONNECTORS.md](../../CONNECTORS.md)。

从你的 HR 数据中生成人员分析报告。分析员工数据，揭示趋势、风险和机遇。

## 使用方法

```
/people-report $ARGUMENTS
```

## 报告类型

**人员数量**：当前组织快照——按团队、地点、级别、任期
**人员流失**：离职分析——自愿/非自愿，按团队、趋势
**多元化**：代表性指标——按级别、团队、人才库
**组织健康**：管理幅度、管理层级、团队规模、流失风险

## 关键指标

### 保留率
- 总流失率（自愿+非自愿）
- 可惜的流失率
- 平均任期
- 流失风险指标

### 多元化
- 按级别、团队和职能的代表性
- 人才库多元化（按人口统计的招聘漏斗）
- 各组晋升率
- 薪酬公平分析

### 参与度
- 评分和趋势
- eNPS（员工净推荐值）
- 参与率
- 开放式反馈主题

### 生产力
- 每位员工的收入
- 管理幅度效率
- 新员工进入生产力所需时间

## 方法

1. 了解他们试图回答的问题
2. 确定正确的数据（上传、粘贴或从~~HRIS获取）
3. 使用适当的统计方法进行分析
4. 结合背景和注意事项呈现结果
5. 根据数据提出具体行动建议

## 我需要你提供的信息

上传 CSV 文件或描述你的数据。有用的字段：
- 员工姓名/ID、部门、团队
- 职位、级别、地点
- 开始日期、结束日期（如适用）
- 经理、薪酬（如相关）
- 人口统计信息（用于多元化报告，如可用）

## 输出

```markdown
## 人员报告：[类型] — [日期]

### 执行摘要
[2-3个关键要点]

### 关键指标
| 指标 | 数值 | 趋势 |
|------|------|------|
| [指标] | [数值] | [上升/下降/持平] |

### 详细分析
[针对特定报告类型的图表、表格和叙述]

### 建议
- [数据驱动的建议]
- [行动项]

### 方法论
[数字的计算方式，任何注意事项]
```

## 如果连接器可用

- 获取实时员工数据——人员数量、任期、部门、级别
- 生成报告而无需上传 CSV 文件

如果 **~~chat** 已连接：
- 提供在相关频道中分享报告摘要的选项
