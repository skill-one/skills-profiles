# /financial-statements

> 如果你看到不熟悉的占位符或需要检查哪些工具已连接，请参阅[CONNECTORS.md](../../CONNECTORS.md)。

**重要提示**：此命令有助于财务报表工作流程，但并不提供财务建议。所有报表在使用于报告或申报前，都应由合格的专业财务人员进行审核。

生成具有期间间比较和差异分析的财务报表。以下工作流程将指导收入报表的生成；资产负债表和现金流量报表的参考格式、GAAP列报要求（ASC 220/210/230）以及常见的期末调整作为支持性参考材料包含在内。

## 使用方法

```
/financial-statements <期间类型> <期间>
```

### 参数

- `期间类型` — 报告期间类型：
  - `monthly` — 单月损益表，与上月和上年同期月比较
  - `quarterly` — 季度损益表，与上季度和上年同期季度比较
  - `annual` — 全年损益表，与上年比较
  - `ytd` — 年度累计损益表，与上年同期年度累计比较
- `期间` — 报告期间（例如，`2024-12`，`2024-Q4`，`2024`）

## 工作流程

### 1. 收集财务数据

如果已连接~~ERP或~~数据仓库：
- 拉取指定期间的试算平衡表或损益表数据
- 拉取比较期间数据（上期、上年、预算/预测）
- 拉取账户体系结构和分组，用于列报

如果未连接数据源：
> 连接~~ERP或~~数据仓库以自动拉取财务数据。你也可以粘贴试算平衡表数据、上传电子表格或提供损益表数据进行分析。

提示用户提供：
- 当前期间收入和费用数据（按账户或类别）
- 比较期间数据（上期、上年和/或预算）
- 任何已知的调整或重新分类

### 3. 差异分析

对每一行项目，计算并标记重大差异。

#### 差异计算

对每一行项目，计算：
- **金额差异**：当前期间 - 上期期间（或当前期间 - 预算）
- **百分比差异**： (当前 - 上期) / |上期| x 100
- **基点变化**：对于利润率和比率，以基点表示变化（1 bp = 0.01%）

#### 重大性阈值

定义构成需要调查的“重大”差异的内容。常见方法：

- **固定金额阈值**：超过设定金额的差异（例如，$50K，$100K）
- **百分比阈值**：超过设定百分比（例如，10%，15%）
- **组合**：金额或百分比阈值之一被超过
- **按比例**：根据项目的大小和波动性设定不同的阈值

*示例阈值（根据你的组织进行调整）：*

| 项目规模 | 金额阈值 | 百分比阈值 |
|---------------|-----------------|---------------------|
| > $10M        | $500K           | 5%                  |
| $1M - $10M    | $100K           | 10%                 |
| < $1M         | $50K            | 15%                 |

#### 差异分解

将总差异分解为驱动因素：

- **数量/数量效应**：按上期期间率变化数量
- **比率/价格效应**：按当前期间数量变化比率/价格
- **结构效应**：不同比率/利润率项目之间的组成变化
- **新增/终止项目**：在一个期间存在但在另一个期间不存在的项目
- **一次性/非经常性项目**：不预期重复的项目
- **时间效应**：项目在不同期间之间转移（不是实际运行率变化）
- **汇率效应**：汇率变化对翻译结果的影响

#### 调查和说明

对每个重大差异：
1. 定量差异（$ 和 %）
2. 确定是否有利或不利
3. 使用上述类别分解
4. 提供业务原因的说明
5. 评估差异是否为暂时性或代表趋势变化
6. 注明任何所需行动（进一步调查、预测更新、流程变更）

## GAAP列报要求

### 损益表（ASC 220 / IAS 1）

- 列报期间确认的所有收入和费用项目
- 按性质（材料、人工、折旧）或按职能（COGS、研发、销售&市场、一般&管理）分类费用——职能分类在美国公司中更常见
- 如果按职能分类，则在附注中披露按性质分类的折旧、摊销和员工福利成本
- 将营业和非营业项目分开列报
- 将所得税费用列为单独一行
- 美国GAAP和IFRS均禁止非常规项目
- 终止经营业务单独列报，税后

**常见的列报考虑因素：**

- **收入分解**：ASC 606要求将收入分解为反映经济因素如何影响收入的性质、金额、时间和不确定性的类别
- **基于股票的补偿**：按职能费用类别（研发、销售&市场、一般&管理）分类，总SBC在附注中披露
- **重组费用**：如重大，单独列报，或计入营业费用并在附注中披露
- **非GAAP调整**：如列报非GAAP指标（在盈利发布中常见），需清晰标注并与GAAP进行 reconciliation

### 资产负债表（ASC 210 / IAS 1）

- 区分流动资产和非流动资产及负债
- 流动：预期在12个月内实现、消耗或结算（或营业周期更长）
- 按流动性顺序列报资产（最流动的优先）——美国标准惯例
- 应收账款按信用损失准备金计提后列报（ASC 326）
- 固定资产按累计折旧计提后列报
- 商誉不摊销——每年进行减值测试（ASC 350）
- 租赁：确认使用权资产和租赁负债（经营租赁和融资租赁）（ASC 842）

### 现金流量表（ASC 230 / IAS 7）

- 间接法最常见（以净利润开始，调整非现金项目）
- 直接法允许但很少使用（需要补充间接 reconciliation）
- 利息支付和所得税支付必须披露（在正表或附注中）
- 非现金投资和融资活动单独披露（例如，租赁下的资产、为收购发行股票）
- 现金等价物：短期、高度流动的投资，原始到期日为3个月或更短

## 常见调整和重新分类

### 期末调整

1. **应计费用**：记录已发生但尚未支付的费用（应付账款应计费用、工资应计费用、利息应计费用）
2. **递延费用**：调整预付费用、递延收入和递延成本
3. **折旧和摊销**：按固定资产和无形资产时间表记录定期折旧/摊销
4. **坏账准备**：根据账龄分析和历史损失率调整信用损失准备
5. **存货调整**：记录过时、滞销或受损存货的减记
6. **汇率重估**：按期末汇率重估外币计价的货币性资产和负债
7. **税项**：记录当前和递延所得税费用
8. **公允价值调整**：对投资、衍生品和其他公允价值项目进行市价重估

### 重新分类

1. **流动/非流动重新分类**：将12个月内到期的长期债务重新分类为流动
2. **抵消账户净额**：将准备金与应收账款总额抵消，累计折旧与资产总额抵消
3. **内部公司抵消**：在合并中消除内部余额和交易
4. **终止经营**：将终止经营结果重新分类为单独项目，税后
5. **权益法调整**：记录对权益法投资的投资收益/损失
6. **部门重新分类**：确保交易按经营部门正确分类
