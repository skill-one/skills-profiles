# 品牌审核

> 如果您看到不熟悉的占位符或需要检查哪些工具已连接，请参阅 [CONNECTORS.md](../../CONNECTORS.md)。

将营销内容与品牌声音、风格指南和沟通标准进行对比。标记偏差并提供具体的改进建议。

## 触发条件

用户运行 `/brand-review` 或要求根据品牌指南审核、检查或审计内容。

## 输入

1. **待审核内容** — 接受以下任何形式的内容：
   - 直接粘贴到对话中
   - 文件路径或~~知识库引用（例如 Notion 页面、共享文档）
   - 已发布页面的 URL
   - 多份内容进行批量审核

2. **品牌指南来源**（自动确定）：
   - 如果在本地设置中配置了品牌风格指南，则自动使用它
   - 如果未配置，则询问：“您是否有品牌风格指南或声音指南需要我进行审核？您可以粘贴它们、共享文件或描述您的品牌声音。否则，我将进行一般性审核以确保清晰度、一致性和专业性。”

## 审核流程

### 已配置品牌指南

根据以下维度评估内容：

#### 声音和语气
- 内容是否与定义的品牌声音属性相符？
- 语气是否适合内容类型和受众？
- 声音是否有不一致的转换？
- 标记与原因解释相符的特定句子或短语

#### 术语和语言
- 是否正确使用首选品牌术语？
- 是否存在“避免”术语或短语？
- 术语水平是否适合目标受众？
- 产品名称、功能名称和品牌术语的使用是否正确（大小写、格式）？

#### 沟通支柱
- 内容是否与定义的沟通支柱或价值主张一致？
- 声称是否与批准的沟通一致？
- 内容是否强化或违背品牌定位？

#### 风格指南合规性
- 根据风格指南的语法和标点符号（例如，牛津逗号、标题大小写与句子大小写）
- 格式约定（标题、列表、强调）
- 数字格式、日期格式
- 首次使用时缩写词的定义？

### 未配置品牌指南（通用审核）

评估内容以检查：

#### 清晰度
- 主信息是否在第一段内清晰？
- 句子是否简洁易懂？
- 结构是否逻辑清晰且易于遵循？
- 是否存在模糊的陈述或不清的引用？

#### 一致性
- 语气是否一致？
- 术语是否一致使用（不使用同义词表示同一概念）？
- 格式是否一致（标题、列表、大小写）？

#### 专业性
- 内容是否没有拼写错误、语法错误和尴尬的表达？
- 语气是否适合目标受众？
- 声称是否得到支持或证实？

### 法律和合规性标记（始终检查）

无论是否配置了品牌指南，均标记：
- **未经证实的声明** — 没有证据或限定条件的最高级（“最佳”、“最快”、“唯一”）
- **缺失的免责声明** — 可能需要法律免责声明的财务声明、健康声明或保证
- **比较声明** — 可能受到挑战的与竞争对手的比较
- **监管语言** — 可能需要合规性审查的内容（金融服务、医疗保健等）
- **证言问题** — 没有归属或披露的引言或推荐
- **版权问题** — 看起来与来源内容非常相似的释义内容

## 品牌声音参考

使用这些框架评估内容是否符合品牌标准或帮助用户记录品牌声音。

### 品牌声音文档框架

完整的品牌声音文档应涵盖以下方面：

1. **品牌个性** — 将品牌视为一个人。例如：“如果我们的品牌是一个人，他们将成为一个知识渊博的同事，能够简单解释复杂事物，真诚地庆祝您的成功，并且永远不会居高临下地与您交谈。”
2. **声音属性** — 定义品牌如何沟通的 3-5 个属性，每个属性都定义其实际含义、它不意味着什么（以防止误解），并提供一个示例。
3. **受众意识** — 品牌在说什么人（主要和次要），他们关心什么，他们的专业知识水平，以及他们期望如何被对待。
4. **核心沟通支柱** — 品牌始终沟通的 3-5 个关键主题，这些主题的层次结构，以及每个支柱如何与受众需求相关联。
5. **语气范围** — 在保持品牌可识别性的同时，声音如何适应不同环境。
6. **风格规则** — 具体的语法、格式和语言规则。
7. **术语** — 首选术语和避免使用的术语。

### 声音属性范围

在定义或评估品牌声音时，将属性定位在范围内：

| 范围 | 一端 | 另一端 |
|------|------|--------|
| 正式性 | 正式、机构化 | 非正式、对话式 |
| 权威性 | 专家、权威 | 同级、协作 |
| 情感 | 温暖、有同理心 | 直接、实事求是 |
| 复杂性 | 技术、精确 | 简单、易于理解 |
| 能量 | 大胆、充满活力 | 平静、适度 |
| 幽默 | 俏皮、诙谐 | 严肃、认真 |
| 创新 | 前沿、前瞻性 | 成熟、经过验证 |

对于每个选择的属性，按以下格式记录：

**[属性名称]**
- **我们**：[实际含义]
- **我们不**：[常见的误解要避免]
- **这听起来像**：[展示属性的示例句子]
- **这听起来不像**：[违反属性的示例句子]

示例：

**平易近人**
- **我们**：友好、清晰、无术语、欢迎初学者和专家
- **我们不**：降低难度、过于随意或缺乏实质内容
- **这听起来像**：“如何开始——大约需要五分钟。”
- **这听起来不像**：“嘿！这超级简单，即使是新手也能做 lol。”

### 不同渠道和情境下的语气调整

品牌声音保持一致，但语气会根据情境调整。语气是应用于声音的情绪起伏。

#### 按渠道的语气

| 渠道 | 语气调整 | 示例 |
|------|----------|------|
| 博客 | 信息量丰富、对话式、教育性 | “让我们逐步了解如何使用以及它为何对您的团队重要。” |
| 社交媒体（领英） | 专业、引人深思、简洁 | “本季度我们通过运行 50 个活动学到的三件事。” |
| 社交媒体（推特/X） | 简洁、直接、有时诙谐 | “您的着陆页有 3 秒。让他们发挥作用。” |
| 邮件营销 | 个性化、有帮助、以行动为导向 | “我们整理了一些我们认为对您有用的内容。” |
| 销售资料 | 自信、以利益为导向、具体 | “使用我们平台的团队将报告时间缩短 40%。” |
| 支持/帮助文档 | 清晰、耐心、逐步 | “如果您看到此错误，请按以下方式修复。” |
| 新闻稿 | 正式、事实性、新闻性 | “该公司今日宣布了...的发布。” |
| 错误消息 | 有同理心、有帮助、无责备 | “我们这边出了点问题。我们正在调查。” |

#### 按情境的语气

| 情境 | 语气调整 |
|------|----------|
| 产品发布 | 充满热情、自信、前瞻性 |
| 事件或故障 | 透明、有同理心、负责 |
| 客户成功故事 | 庆祝、具体、归功于客户 |
| 思想领导力 | 权威、细致、有证据支持 |
| 欢迎新用户 | 热情、鼓励、清晰 |
| 坏消息（价格上涨、弃用） | 诚实、尊重、以解决方案为导向 |
| 竞争对手比较 | 自信但公平、基于事实、不贬低 |

#### 语气调整规则
声音属性保持固定。语气根据情境调整它们。例如，如果品牌是“大胆和温暖”：
- 在产品发布时，加大大胆程度
- 在事件响应时，加大温暖程度
- 两个属性都不会消失；平衡会发生变化

### 风格指南执行

#### 语法和机械
一致地记录和执行以下选择：

| 规则 | 选项 | 示例 |
|------|------|------|
| 牛津逗号 | 是/否 | "快速、可靠、安全" vs. "快速、可靠和安全" |
| 句子大小写与标题大小写（标题） | 句子/标题 | "如何开始" vs. "如何开始" |
| 缩写 | 使用/避免 | "我们" vs. "我们是" |
| 破折号间距 | 无空格/空格 | "这——更多" vs. "这 — 更多" |
| 数字 | 1-9 写出，10+ 使用数字 / 始终使用数字 | "五个功能" vs. "5 个功能" |
| 百分比 | % / 百分比 | "50%" vs. "50%" |
| 日期格式 | 月 DD, YYYY / DD/MM/YYYY / 等. | "2025 年 1 月 15 日" |
| 时间格式 | 12 小时制/24 小时制 | "下午 3:00" vs. "15:00" |
| 列表 | 逗号/片段后不加逗号 | "设置您的账户。" vs. "设置您的账户" |

#### 格式约定
- 标题层级（何时使用 H1、H2、H3）
- 粗体和斜体使用（粗体用于强调，斜体用于标题/术语）
- 链接文本（描述性 vs. "点击这里"——始终描述性）
- 图片替代文本要求
- 代码格式（对于技术品牌）
- 提示框或高亮框使用

#### 标点符号和强调
- 感叹号政策（有限使用，不超过一个）
- 省略号使用（大多数专业环境中避免）
- ALL CAPS 政策（避免；使用粗体代替强调）
- 按渠道使用表情符号（专业渠道：最少或无；社交：适当）

### 术语管理

#### 首选术语

维护一个首选术语及其不正确替代词的列表：

| 使用这个 | 不要这个 | 备注 |
|------|------|------|
| 注册（动词） | signup（动词） | "signup" 是名词形式 |
| 登录（动词） | login（动词） | "login" 是名词/形容词形式 |
| 设置（动词） | setup（动词） | "setup" 是名词/形容词形式 |
| 邮件 | e-mail | 无连字符 |
| 网站 | web site | 一个词 |
| 数据是（单数） | 数据是 | 除非出版物要求复数 |

#### 产品和功能名称
- 产品名称的官方大小写
- 何时使用完整产品名称 vs. 简称
- 是否在产品名称前使用 "the"
- 如何在文本中处理版本
- 商标和注册符号（何时需要和何时省略）

#### 包容性语言
- 使用性别中性的语言（对未知个体使用 they/them）
- 避免歧视性语言（“疯狂”、“盲点”、“笨拙”）
- 在适当的地方使用以人为本的语言
- 避免可能无法翻译的文化特定习语
- 使用“简单”或“直接”而不是“容易”（容易因人而异）

#### 行业术语管理
- 定义哪些技术术语的受众无需解释
- 列出应始终定义为普通语言替换的术语
- 指定哪些缩写词需要在首次使用时拼写出来
- 针对受众的术语表，这些术语对不同读者有不同的含义

#### 竞争对手和类别术语
- 如何指代您的产品类别（使用您的首选框架）
- 如何指代竞争对手（通过名称或泛指）
- 竞争对手创造的术语，您应避免使用（以防止强化他们的定位）
- 您的首选差异化语言

## 输出格式

以以下方式呈现审核结果：

### 摘要
- 总体评估：内容与品牌标准的一致性（或一般质量）
- 1-2 句话总结最大的优势
- 1-2 句话总结最重要的改进

### 详细发现

对于每个发现的问题，提供：

| 问题 | 位置 | 严重性 | 建议 |
|------|------|------|------|

其中严重性是：
- **高** — 与品牌声音矛盾、包含合规风险或严重损害沟通
- **中** — 与指南不一致但不会造成损害
- **低** — 轻微的风格或偏好问题

### 修改部分

对于前 3-5 个最高严重性的问题，提供原始文本和修改建议的显示。

### 法律/合规性标记

单独列出任何法律或合规性问题，并建议采取的行动。

## 审核后

询问：“您希望我：
- 应用这些建议修改全部内容吗？
- 只修复高严重性问题吗？
- 根据相同指南审核更多内容吗？
- 帮助您记录品牌声音以供未来审核吗？”
