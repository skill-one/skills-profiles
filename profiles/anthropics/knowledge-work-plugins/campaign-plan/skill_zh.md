# 营销活动计划

> 如果你看到不熟悉的占位符，或者需要检查哪些工具已连接，请参阅 [CONNECTORS.md](../../CONNECTORS.md)。

生成一份全面的营销活动简报，包括目标、受众、信息、渠道策略、内容日历和成功指标。

## 触发条件

用户运行 `/campaign-plan` 命令，或要求策划、设计或构建营销活动。

## 输入

从用户处收集以下信息。如果未提供，请在继续前询问：

1. **活动目标** — 主要目标（例如，促进注册、提高认知度、推出产品、产生潜在客户、重新激活流失用户）
2. **目标受众** — 活动面向的对象（人口统计特征、角色、行业、痛点、购买阶段）
3. **时间线** — 活动持续时间及任何固定日期（启动日期、活动日期、季节性截止日期）
4. **预算范围** — 大约预算或预算层级（可选；如果未提供，则生成与渠道无关的计划，并注明预算分配的要点）
5. **附加背景信息**（可选）：
   - 推广的产品或服务
   - 关键差异化或价值主张
   - 之前的活动表现或经验教训
   - 品牌指南或限制
   - 地域重点

## 活动简报结构

生成包含以下部分的简报：

### 1. 活动概述
- 活动名称建议
- 一句话的活动总结
- 具体的可衡量目标
- 次要目标（如果适用）

### 2. 目标受众
- 主要受众细分及描述
- 次要受众细分（如果适用）
- 受众的痛点和动机
- 他们花费时间的地方（渠道、社区、出版物）
- 购买阶段匹配（认知度、考虑、决策）

### 3. 关键信息
- 核心活动信息（一句话）
- 3-4 条针对受众痛点的支持信息
- 按渠道调整的信息（如果需要不同语气）
- 支持每条信息的证据点

### 4. 渠道策略
根据受众和目标推荐渠道。每个渠道包括：
- 为什么这个渠道适合受众和目标
- 内容格式建议
- 预计努力程度（低、中、高）
- 预算分配建议（如果提供了预算）

考虑以下渠道：
- 自有渠道：博客、电子邮件、网站、社交媒体资料
- 赢得渠道：公关、影响者合作、客座文章、社区参与
- 付费渠道：搜索广告、社交媒体广告、展示广告、赞助内容、活动

### 5. 内容日历
创建按周（或对于短期活动按天）的内容日历：
- 每周要制作的内容
- 每个内容针对的渠道
- 关键里程碑和截止日期
- 内容之间的依赖关系（例如，“落地页必须在付费广告启动前上线”）

格式化为表格：

| 周次 | 内容片段 | 渠道 | 负责人/备注 | 状态 |
|------|----------|---------|-------------|--------|

### 6. 需要的内容片段
列出活动所需的所有内容资产：
- 资产名称和类型（博客文章、电子邮件、社交媒体帖子、广告创意、落地页等）
- 简要描述内容应包含的内容
- 优先级（必须有的 vs. 可选的）
- 建议的创作时间线

### 7. 成功指标
定义与活动目标一致的 KPI：
- 主要 KPI 及目标数值
- 次要 KPI（3-5 个）
- 每个指标如何跟踪
- 建议的汇报频率

如果 ~~产品分析已连接，参考可用的历史表现基准来设定目标。

### 8. 预算分配（如果提供预算）
- 按渠道或活动分解
- 生产成本 vs. 分配成本
- 备用金建议（通常为 10-15%）

### 9. 风险和缓解措施
- 2-3 个潜在风险（时间线、受众不匹配、渠道表现不佳）
- 每个风险的缓解策略

### 10. 下一步行动
- 启动活动的即时行动项
- 需要利益相关者批准的事项
- 关键决策点

## 规划参考

### 活动框架：目标、受众、信息、渠道、衡量

每个活动都应基于这个五部分框架构建：

#### 目标
在规划任何内容之前，先定义成功的标准。

- **认知度**：提高品牌或产品的知名度（通过触达率、展示次数、市场份额衡量）
- **考虑**：推动参与和教育（通过内容参与度、电子邮件注册、网络研讨会参与度衡量）
- **转化**：产生潜在客户或销售（通过注册、演示、购买、管道衡量）
- **留存**：重新激活现有客户（通过降低流失率、追加销售、NPS 衡量）
- **倡导**：将客户转变为推广者（通过推荐、评价、UGC 衡量）

好的目标是 SMART：具体的、可衡量的、可实现的、相关的、有时间限制的。

示例：“在活动启动后 6 周内，从北美中市场 SaaS 公司中产生 200 个营销合格潜在客户。”

#### 受众
定义你要接触的人群，具体到足以指导信息传递和渠道决策的程度。

- **人口统计特征**：角色/头衔、级别、公司规模、行业
- **心理特征**：动机、痛点、目标、异议
- **行为特征**：他们消费内容的地方、购买方式、之前参与过的内容
- **购买阶段**：他们是否不了解问题、正在研究解决方案，还是准备购买？

为活动规划创建一个简要的受众简介（不是完整的角色）：
> “[角色] 在 [公司类型] 工作，他们正面临 [痛点]，并寻求 [期望结果]。他们通常通过 [渠道] 发现解决方案，最关心 [优先事项]。”

#### 信息
构思核心信息和支持点，以引起受众共鸣。

- **核心信息**：一句话概括你希望受众思考、感受或采取的行动
- **支持信息**：3-4 个点，提供证据、解决异议或阐述利益
- **证据点**：数据、案例研究、客户评价或第三方验证
- **差异化**：你的产品或服务与替代方案的不同之处（包括不采取行动）

信息层级：
1. 我为什么要关心？（解决痛点或机会）
2. 解决方案是什么？（定位你的产品）
3. 为什么是你？（与替代方案区分）
4. 我该做什么？（行动号召）

#### 渠道
根据受众在哪里选择渠道，而不是你习惯在哪里。见下方的渠道选择指南。

#### 衡量
定义你将如何知道活动是否成功。见下方的按活动类型划分的成功指标。

### 渠道选择指南

#### 自有渠道

| 渠道 | 适合 | 典型指标 | 努力程度 |
|---------|----------|----------------|--------|
| 博客/网站 | SEO、思想领导力、教育 | 流量、页面停留时间、转化 | 中等 |
| 电子邮件 | 培养、留存、公告 | 打开率、点击率、转化 | 低-中等 |
| 社交媒体（自然） | 认知度、社区、品牌建设 | 参与度、触达率、粉丝增长 | 中等 |
| 网络研讨会 | 教育、潜在客户生成、产品演示 | 注册、参与度、管道 | 高 |
| 播客 | 思想领导力、品牌认知度 | 下载量、订阅者增长 | 高 |

#### 赢得渠道

| 渠道 | 适合 | 典型指标 | 努力程度 |
|---------|----------|----------------|--------|
| 公关/媒体 | 认知度、信誉、发布 | 覆盖率、市场份额、推荐流量 | 高 |
| 客座内容 | 受众扩展、SEO、信誉 | 推荐流量、反向链接 | 中等 |
| 影响者/合作伙伴 | 受众扩展、信任 | 触达率、参与度、推荐转化 | 中高 |
| 社区 | 认知度、信任、反馈 | 提及量、参与度、推荐流量 | 中等 |
| 评论/评分 | 信誉、SEO、考虑 | 评论量、评分、转化提升 | 低-中等 |

#### 付费渠道

| 渠道 | 适合 | 典型指标 | 努力程度 |
|---------|----------|----------------|--------|
| 搜索广告（SEM） | 高意向潜在客户捕获 | 每点击成本、点击率、转化率、每潜在客户成本 | 中等 |
| 社交媒体广告 | 认知度、再营销、潜在客户生成 | 每千次展示成本、每点击成本、点击率、每潜在客户成本、广告支出回报率 | 中等 |
| 展示/程序化 | 认知度、再营销 | 展示次数、每千次展示成本、观看转化 | 低-中等 |
| 赞助内容 | 思想领导力、潜在客户生成 | 参与度、潜在客户、每潜在客户成本 | 中等 |
| 活动/赞助 | 关系建立、品牌 | 潜在客户、会议、影响管道 | 高 |

#### 渠道选择标准
选择渠道时，考虑：
- 你的目标受众在哪里花费时间？
- 你要瞄准的购买阶段是什么？（认知度渠道 vs. 转化渠道）
- 你的预算是多少？（付费渠道需要支出；自有/赢得渠道需要时间）
- 你已经拥有或可以制作哪些内容资产？
- 过去哪些渠道有效？（如有可用历史数据，请参考）

### 内容日历创建

#### 日历规划流程
1. **从里程碑开始**：活动启动、活动日期、产品发布、季节性时刻
2. **倒推**：什么需要上线以及何时？制作需要多长时间？
3. **映射内容到漏斗阶段**：确保覆盖认知度、考虑和转化
4. **按主题批量**：将相关内容片段分组为每周或每两周一次的主题
5. **平衡渠道**：不要过度依赖某个渠道；确保受众在各个触点看到活动
6. **留出灵活性**：将日历的 20% 空白用于反应性或机会性内容

#### 内容频率指南
- **博客**：每周 1-4 篇，取决于团队规模和目标
- **电子邮件简报**：大多数受众每周或每两周一次
- **社交媒体**：每个平台每周 3-7 篇（因平台而异）
- **付费活动**：在活动期间持续进行，每 2-4 周更新创意
- **网络研讨会**：每月或每季度，取决于资源

#### 制作时间线基准
- 博客文章：3-5 个工作日（研究、草稿、审核、发布）
- 电子邮件活动：2-3 个工作日（文案、设计、测试、发送）
- 社交媒体帖子：1-2 个工作日（草稿、设计、安排）
- 落地页：5-7 个工作日（文案、设计、开发、测试）
- 视频内容：2-4 周（脚本、制作、剪辑）
- 电子书/白皮书：2-4 周（大纲、草稿、设计、审核）

### 预算分配方法

#### 收入百分比法
- 行业基准：营销预算为收入的 5-15%，B2B 通常为 5-10%，B2C 为 10-15%
- 初创公司和成长型公司通常将收入的 15-25% 投入营销
- 在营销预算中，按品牌（长期）和绩效（短期）分配

#### 渠道分配框架
一个常见的起始框架（根据目标和历史数据调整）：

| 类别 | 预算百分比 | 示例 |
|---------|---------------------|----------|
| 付费获取 | 30-40% | 搜索广告、社交媒体广告、展示广告 |
| 内容制作 | 20-30% | 博客、视频、设计、电子书 |
| 活动和赞助 | 10-20% | 会议、网络研讨会、会议 |
| 工具和技术 | 10-15% | 分析、自动化、CRM |
| 测试和实验 | 5-10% | 新渠道、A/B 测试、试点 |

#### 预算优化原则
- 从你最自信的渠道开始，将 60-70% 的付费预算分配给该渠道
- 保留 15-20% 用于测试新渠道或策略
- 根据表现数据每月调整预算（不要设定后忘记）
- 考虑生产成本，而不仅仅是媒体支出
- 包含 10-15% 的备用金，用于意外机会或超支

### 按活动类型划分的成功指标

#### 认知度活动
| 指标 | 衡量内容 |
|--------|-----------------|
| 触达率/展示次数 | 多少人看到了活动 |
| 品牌提及量 | 品牌对话的增加 |
| 市场份额 | 你的提及量 vs. 竞争对手 |
| 直接流量 | 没有提示就来到你网站的人 |
| 社交媒体粉丝增长 | 受众建设 |

#### 潜在客户生成活动
| 指标 | 衡量内容 |
|--------|-----------------|
| 总潜在客户 | 新联系人的数量 |
| 营销合格潜在客户 (MQL) | 达到质量标准的潜在客户 |
| 每潜在客户成本 (CPL) | 支出的效率 |
| 潜在客户到 MQL 转化率 | 生成的潜在客户质量 |
| 影响管道 | 创造的营收机会 |

#### 产品发布活动
| 指标 | 衡量内容 |
|--------|-----------------|
| 注册或试用 | 新产品的采用 |
| 激活率 | 完成关键首次操作的用户 |
| 媒体报道 | 赢得媒体曝光 |
| 社交媒体热度 | 提及量、分享量、参与度激增 |
| 功能采用 | 推出的特定功能的使用 |

#### 留存/参与活动
| 指标 | 衡量内容 |
|--------|-----------------|
| 流失率变化 | 客户留存改善 |
| 参与率 | 与活动内容的互动 |
| NPS 或 CSAT 变化 | 满意度提升 |
| 追加销售/交叉销售收入 | 扩展收入 |
| 功能采用 | 推广功能的使用 |

#### 活动网络研讨会
| 指标 | 衡量内容 |
|--------|-----------------|
| 注册 | 产生的兴趣 |
| 参与率 | 从注册到转化的转化 |
| 活动期间参与度 | 问题、投票、聊天活动 |
| 活动后转化 | 参与者的潜在客户或管道 |
| 内容再利用触达率 | 录音的下游受众 |

## 输出

以清晰的标题和格式呈现完整的活动简报。简报后，询问：

"您希望我：
- 深入研究任何部分？
- 根据日历起草具体的内容片段？
- 创建竞争分析以指导信息传递？
- 调整预算或时间线计划？"
