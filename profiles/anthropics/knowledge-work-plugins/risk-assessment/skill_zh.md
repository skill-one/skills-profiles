# 风险评估

系统性地识别、评估和规划运营风险。

## 风险评估矩阵

| | 低影响 | 中等影响 | 高影响 |
|---|-----------|---------------|-------------|
| **高可能性** | 中等 | 高 | 关键 |
| **中等可能性** | 低 | 中等 | 高 |
| **低可能性** | 低 | 低 | 中等 |

## 风险类别

- **运营**：流程故障、人员短缺、系统停机
- **财务**：预算超支、供应商成本增加、收入影响
- **合规**：监管违规、审计发现、政策违规
- **战略**：市场变化、竞争威胁、技术变革
- **声誉**：客户影响、公众认知、合作伙伴关系
- **安全**：数据泄露、访问控制故障、第三方漏洞

## 风险登记册格式

针对每个风险，记录：
- **描述**：可能发生什么
- **可能性**：高 / 中等 / 低
- **影响**：高 / 中等 / 低
- **风险等级**：关键 / 高 / 中等 / 低
- **缓解措施**：我们正在采取什么措施来降低可能性或影响
- **负责人**：谁负责管理此风险
- **状态**：未解决 / 已缓解 / 已接受 / 已关闭

## 输出

产出具有优先级的风险登记册，包含具体的、可执行的风险缓解措施。重点关注可控且重大的风险。
