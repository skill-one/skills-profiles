# /vendor-review

> 如果你看到不熟悉的占位符或需要检查哪些工具已连接，请参阅 [CONNECTORS.md](../../CONNECTORS.md)。

使用结构化分析评估供应商，涵盖成本、风险、性能和匹配度。

## 使用方法

```
/vendor-review $ARGUMENTS
```

## 我需要你提供的信息

- **供应商名称**：你在评估谁？
- **背景**：是新供应商评估、续约决策还是比较？
- **详细信息**：合同条款、定价、提案文档或当前性能数据

## 评估框架

### 成本分析（总拥有成本）
- 总拥有成本（不仅仅是许可证费用）
- 实施和迁移成本
- 培训和入职成本
- 持续支持和维护
- 退出成本（数据迁移、合同终止）

### 风险评估
- 供应商财务稳定性
- 安全和合规性态势
- 集中风险（对单一供应商的依赖）
- 合同锁定和退出条款
- 业务连续性和灾难恢复

### 性能指标
- SLA合规性
- 支持响应时间
- 可用性和可靠性
- 功能交付节奏
- 客户满意度

### 对比矩阵
在比较供应商时，生成一个涵盖定价、功能、集成、安全、支持、合同条款和参考的横向对比矩阵。

## 如果连接了连接器

如果 **~~知识库** 已连接：

## 小贴士

1. **上传提案** — 我可以从供应商文档中提取定价、条款和SLA。
2. **比较供应商** — "比较供应商A与供应商B"会为你提供横向分析。
3. **包含当前支出** — 对于续约，了解你现在支付的费用有助于评估价格变化。
