# /create-viz - 创建可视化

> 如果你看到不熟悉的占位符或需要检查哪些工具已连接，请参阅 [CONNECTORS.md](../../CONNECTORS.md)。

使用 Python 创建出版质量的 数据可视化。根据最佳实践从数据生成图表，确保清晰度、准确性和设计性。

## 使用方法

```
/create-viz <数据源> [图表类型] [附加说明]
```

## 工作流程

### 1. 理解请求

确定：

- **数据源**：查询结果、粘贴的数据、CSV/Excel 文件或待查询的数据
- **图表类型**：明确请求或需要推荐
- **目的**：探索、演示、报告、仪表板组件
- **受众**：技术团队、高管、外部利益相关者

### 2. 获取数据

**如果数据仓库已连接且需要查询数据：**
1. 编写并执行查询
2. 将结果加载到 pandas DataFrame 中

**如果数据已粘贴或上传：**
1. 将数据解析为 pandas DataFrame
2. 根据需要清理和准备（类型转换、空值处理）

**如果数据来自对话中的先前分析：**
1. 引用现有数据

### 3. 选择图表类型

如果用户未指定图表类型，根据数据和问题推荐一个：

| 数据关系 | 推荐图表 |
|---|---|
| 随时间变化趋势 | 折线图 |
| 类别间比较 | 条形图（类别较多时使用水平条形图） |
| 部分与整体构成 | 堆叠条形图或面积图（类别少于6个时避免饼图） |
| 值的分布 | 直方图或箱线图 |
| 两个变量之间的相关性 | 散点图 |
| 随时间变化的两个变量比较 | 双轴折线图或分组条形图 |
| 地理数据 | 颜色填充地图 |
| 排名 | 水平条形图 |
| 流程或过程 | Sankey 图 |
| 关系矩阵 | 热力图 |

如果用户未指定，简要解释推荐理由。

### 4. 生成可视化

根据需求使用以下库之一编写 Python 代码：

- **matplotlib + seaborn**：最适合静态、出版质量的图表。默认选择。
- **plotly**：最适合交互式图表或用户请求交互时。

**代码要求：**

```python
import matplotlib.pyplot as plt
import seaborn as sns
import pandas as pd

# 设置专业风格
plt.style.use('seaborn-v0_8-whitegrid')
sns.set_palette("husl")

# 创建适当大小的图形
fig, ax = plt.subplots(figsize=(10, 6))

# [图表特定代码]

# 始终包含：
ax.set_title('清晰、描述性的标题', fontsize=14, fontweight='bold')
ax.set_xlabel('X轴标签', fontsize=11)
ax.set_ylabel('Y轴标签', fontsize=11)

# 适当格式化数字
# - 百分比：'45.2%' 而不是 '0.452'
# - 货币：'$1.2M' 而不是 '1200000'
# - 大数字：'2.3K' 或 '1.5M' 而不是 '2300' 或 '1500000'

# 移除图表垃圾
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)

plt.tight_layout()
plt.savefig('chart_name.png', dpi=150, bbox_inches='tight')
plt.show()
```

### 5. 应用设计最佳实践

**颜色：**
- 使用一致且对色盲友好的调色板
- 有意义地使用颜色（非装饰性）
- 用对比色突出关键数据点或趋势
- 将次要参考数据变灰

**字体：**
- 描述性标题，说明洞察，而不仅仅是指标（例如，“年收入同比增长23%”而不是“按月收入”）
- 可读的轴标签（如果避免旋转90度）
- 在关键点添加数据标签以增加清晰度

**布局：**
- 适当的空白和边距
- 不遮挡数据的图例位置
- 按值排序类别（非字母顺序），除非有自然顺序

**准确性：**
- 条形图的Y轴从零开始
- 无误导性轴断点，除非有明确标注
- 比较面板时保持一致的比例
- 适当的精度（不要显示10位小数）

### 6. 保存和展示

1. 将图表保存为具有描述性名称的PNG文件
2. 向用户展示图表
3. 提供所使用的代码以便他们修改
4. 建议变体（不同图表类型、不同分组、缩放时间范围）
