# /onboarding

> 如果你看到不熟悉的占位符，或者需要检查哪些工具已连接，请参阅 [CONNECTORS.md](../../CONNECTORS.md)。

为新的团队成员生成一份全面的入职计划。

## 使用方法

```
/onboarding $ARGUMENTS
```

## 我需要你提供的信息

- **新员工姓名**：谁将开始工作？
- **职位**：担任什么职位？
- **团队**：加入哪个团队？
- **开始日期**：何时开始？
- **经理**：谁是他们的经理？

## 如果连接了工具

如果 **~~HRIS** 已连接：
- 提取新员工的详细信息和组织结构图
- 根据职位自动填充工具访问列表

如果 **~~知识库** 已连接：
- 链接到相关的入职文档、团队维基和操作手册
- 提取团队的现有入职清单进行定制

如果 **~~日历** 已连接：
- 自动创建第一天日历事件和第一周会议邀请

## 小贴士

1. **根据职位定制** — 工程师的入职流程与设计师的不同。
2. **不要让第一天过于繁忙** — 专注于设置和建立关系。深入工作从第二周开始。
3. **指派一个伙伴** — 有一个不是他们经理的可以随时求助的人会带来巨大帮助。
