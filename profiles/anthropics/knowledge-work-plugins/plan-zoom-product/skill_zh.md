# /plan-zoom-product

> 如果你看到不熟悉的占位符，或者需要检查哪些工具已连接，请参阅 [CONNECTORS.md](../../CONNECTORS.md)。

针对特定用例，选择 Zoom REST API、Webhooks、WebSockets、会议 SDK、视频 SDK、Zoom 应用程序 SDK、电话、联络中心或 MCP。

## 使用方法

```text
/plan-zoom-product $ARGUMENTS
```

## 工作流程

1. 确定用户的实际目标。
2. 判断问题是否属于自动化、嵌入式会议、自定义视频、客户端应用行为、事件传递、AI 工具或支持/电话/联络中心工作。
3. 如果请求不明确，在锁定推荐之前先问一个简短的澄清问题。
4. 推荐主要的 Zoom 接口，并列出最低支持组件。
5. 解释为什么被拒绝的替代方案在此情况下更差。
6. 以具体的下一步计划结束。

## 输出

- 推荐的 Zoom 接口
- 所需的支持组件
- 关键权衡和限制
- 建议的实施顺序
- 下一步相关的技能链接
