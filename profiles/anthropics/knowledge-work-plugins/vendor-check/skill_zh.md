# /vendor-check -- 供应商协议状态

> 如果您看到不熟悉的占位符或需要检查哪些工具已连接，请参阅 [CONNECTORS.md](../../CONNECTORS.md)。

检查所有已连接系统中与供应商的现有协议状态。提供法律关系的综合视图。

**重要提示**：此命令协助法律工作流程，但不会提供法律建议。协议状态报告应由合格的法律专业人士与原始文件进行核对。

## 调用方式

```
/vendor-check [供应商名称]
```

如果未提供供应商名称，则提示用户指定要检查的供应商。

## 工作流程

### 第一步：识别供应商

接受用户提供的供应商名称。处理常见变体：
- 全称法律名称与商号（例如，“Alphabet Inc.”与“Google”）
- 缩写（例如，“AWS”与“Amazon Web Services”）
- 母公司/子公司关系

如果供应商名称不明确，请要求用户澄清。

### 第二步：搜索已连接系统

按优先顺序在所有可用的已连接系统中搜索供应商：

#### CLM（合同生命周期管理）-- 如果已连接
搜索涉及该供应商的所有合同：
- 活跃协议
- 过期协议（过去3年）
- 协议谈判中或待签署
- 修订和补充协议

#### CRM -- 如果已连接
搜索供应商/账户记录：
- 账户状态和关系类型
- 相关机会或交易
- 供应商法律/合同团队的联系方式

#### 电子邮件 -- 如果已连接
搜索最近的关联通信：
- 合同相关电子邮件（过去6个月）
- NDA或协议附件
- 谈判线程

#### 文件（例如，Box、Egnyte、SharePoint）-- 如果已连接
搜索：
- 已签署协议
- 审阅稿和草稿
- 尽职调查材料

#### 聊天（例如，Slack、Teams）-- 如果已连接
搜索最近的提及：
- 涉及此供应商的合同请求
- 关于供应商的法律问题
- 相关团队讨论（过去3个月）

### 第三步：汇总协议状态

对于每个找到的协议，报告：

| 字段 | 详情 |
|-------|---------|
| **协议类型** | NDA、MSA、SOW、DPA、SLA、许可协议等 |
| **状态** | 活跃、过期、谈判中、待签署 |
| **生效日期** | 协议开始时间 |
| **到期日期** | 协议到期或续订时间 |
| **自动续订** | 是/否，包括续订期限和通知期 |
| **关键条款** | 责任限制、适用法律、终止条款 |
| **修订** | 文件中存在的任何修订或补充 |

### 第四步：差距分析

识别已存在的协议和可能缺失的协议：

```
## 协议覆盖范围

[CHECK] NDA -- [状态]
[CHECK/MISSING] MSA -- [状态或“未找到”]
[CHECK/MISSING] DPA -- [状态或“未找到”]
[CHECK/MISSING] SOW(s) -- [状态或“未找到”]
[CHECK/MISSING] SLA -- [状态或“未找到”]
[CHECK/MISSING] 保险证书 -- [状态或“未找到”]
```

根据关系类型（例如，如果存在MSA但没有DPA且供应商处理个人数据）标记可能需要的任何差距。

### 第五步：生成报告

输出综合报告：

```
## 供应商协议状态：[供应商名称]

**搜索日期**：[今天的日期]
**已检查来源**：[搜索的系统列表]
**不可用来源**：[未连接的系统列表，如有]

## 关系概述

**供应商**：[全称法律名称]
**关系类型**：[供应商/合作伙伴/客户等]
**CRM状态**：[如有]

## 协议摘要

### [协议类型1] -- [状态]
- **生效**：[日期]
- **到期**：[日期] ([自动续订 / 不自动续订])
- **关键条款**：[主要条款摘要]
- **存储位置**：[已签署副本的存储位置]

### [协议类型2] -- [状态]
[等]

## 差距分析

[已实施的内容与可能需要的内容]

## 即将采取的行动

- [任何临近到期或续订截止日期]
- [尚未实施的必要协议]
- [可能需要修订或更新的内容]

## 备注

[电子邮件/聊天搜索中的相关背景信息]
```

### 第六步：处理缺失来源

如果关键系统通过MCP未连接：

- **无CLM**：注明未连接CLM。建议用户手动检查CLM。报告在其他系统中找到的内容。
- **无CRM**：跳过CRM背景信息。注明差距。
- **无电子邮件**：注明未搜索电子邮件。建议用户搜索电子邮件中的“[供应商名称]协议”或“[供应商名称]NDA”。
- **无文件**：注明未搜索文件存储。

始终明确说明已检查和未检查的来源，以便用户了解报告的完整性。

## 备注

- 如果在任何已连接系统中未找到协议，请明确报告并询问用户是否在其他地方存储协议
- 对于供应商集团（例如，拥有多个子公司的供应商），询问用户是否要检查特定实体还是整个集团
- 标记任何已过期但可能仍有存续义务的协议（保密、赔偿等）
- 如果协议即将到期（90天内），请突出显示
