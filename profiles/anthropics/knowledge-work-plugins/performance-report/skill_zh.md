# 性能报告

> 如果你看到不熟悉的占位符或需要检查哪些工具已连接，请参阅[CONNECTORS.md](../../CONNECTORS.md)。

生成包含关键指标、趋势分析、洞察和优化建议的营销性能报告。

## 触发条件

用户运行`/performance-report`或要求营销报告、性能分析、活动结果或指标摘要。

## 输入

1. **报告类型** — 确定用户需要的报告类型：
   - **活动报告** — 特定活动的性能
   - **渠道报告** — 特定渠道（电子邮件、社交、付费、SEO等）的性能
   - **内容性能** — 内容的表现情况
   - **整体营销报告** — 跨渠道摘要（每周、每月、每季度）
   - **自定义** — 用户定义的范围

2. **时间范围** — 报告窗口（上周、上个月、上季度、自定义日期范围）

3. **数据源**：
   - 如果~~营销分析已连接，发现可用的账户和平台，然后自动拉取性能数据
   - 如果~~产品分析已连接：自动拉取性能数据
   - 如果未连接：要求用户提供指标。提示：“请粘贴或分享您的性能数据。我可以处理电子表格、CSV数据、描述仪表板的屏幕截图，或仅关键数字。”

4. **比较周期**（可选） — 前期或同比，用于趋势背景

5. **利益相关者受众**（可选） — 谁将阅读此报告（执行摘要风格与详细分析师视图）

## 报告结构

### 1. 执行摘要
- 2-3句概述报告期间的性能
- 标题指标与趋势方向（上升/下降/持平 vs. 前期）
- 一个关键成功和一个需要关注的领域

### 2. 关键指标仪表板

以摘要表格呈现核心指标：

| 指标 | 本期 | 前期 | 变化 | 目标 | 状态 |

状态指示器：
- 正常（达到或超过目标）
- 风险（低于目标但在可接受范围内）
- 偏离轨道（显著低于目标）

#### 指标按报告类型

**活动报告：**
- 展示次数和覆盖范围
- 点击率（CTR）
- 转化率
- 获取成本（CPA）
- 广告支出回报率（ROAS）或投资回报率（ROI）
- 总转化/注册/线索数

**渠道报告（电子邮件）：**
- 发送邮件数、送达数、退回数
- 打开率
- 点击率
- 取消订阅率
- 转化率

**渠道报告（社交）：**
- 展示次数和覆盖范围
- 参与率（点赞、评论、分享）
- 粉丝增长
- 点击率
- 表现最佳的内容

**渠道报告（付费）：**
- 支出
- 展示次数和点击数
- 点击率
- 每点击成本（CPC）和每千次展示成本（CPM）
- 转化和获取成本
- 广告支出回报率

**渠道报告（SEO/自然）：**
- 自然搜索会话
- 关键词排名（变化）
- 索引页面数
- 获得的外部链接
- 表现最佳的内容

**内容性能：**
- 页面浏览量和独立访客数
- 页面停留时间
- 跳出率
- 社交分享
- 归因于内容的转化
- 表现最佳和最差的内容

**整体营销报告：**
- 产生的总线索数
- 营销合格线索（MQLs）
- 订单管道贡献
- 客户获取成本（CAC）
- 渠道按渠道摘要

### 3. 趋势分析
- 报告期间的性能趋势（周环比或月环比）
- 显著的拐点和原因
- 观察到的季节性或周期性模式
- 与基准或目标的比较

### 4. 哪些有效
- 3-5个关键成功案例及具体数据
- 为什么表现良好（假设）
- 如何复制或扩展

### 5. 需要改进的方面
- 表现最差的3-5个内容及具体数据
- 表现不佳的假设
- 推荐的改进措施

### 6. 洞察和观察
- 数据中不明显模式
- 受众行为洞察
- 引起共鸣的内容或创意主题
- 可能影响性能的外部因素（季节性、新闻、竞争行为）

### 7. 建议
针对每项建议：
- 要做什么
- 为什么（链接到数据中的具体洞察）
- 预期影响（高、中、低）
- 实施难度（高、中、低）
- 优先级（立即、下一个sprint、下一个季度）

以2x2矩阵格式优先排序建议：

| | 低工作量 | 高工作量 |
|---|---|---|
| **高影响** | 首先执行 | 计划下一个sprint |
| **低影响** | 如果有时间允许 | 降级 |

### 8. 下个周期的重点
- 下个周期的3个优先事项
- 要运行的测试或实验
- 关键指标的目标

## 指标定义和基准

### 电子邮件营销

| 指标 | 定义 | 基准范围 | 告诉你什么 |
|--------|-----------|----------------|-------------------|
| 送达率 | 送达邮件数 / 发送邮件数 | 95-99% | 列表健康度和发件人声誉 |
| 打开率 | 独立打开数 / 送达邮件数 | 15-30% | 标题行和发件人有效性 |
| 点击率（CTR） | 独立点击数 / 送达邮件数 | 2-5% | 内容相关性和CTA有效性 |
| 点击打开率（CTOR） | 独立点击数 / 独立打开数 | 10-20% | 电子邮件内容质量（对于打开的用户） |
| 取消订阅率 | 取消订阅数 / 送达邮件数 | <0.5% | 内容与受众的匹配度和频率容忍度 |
| 退回率 | 退回数 / 发送邮件数 | <2% | 列表质量和数据卫生 |
| 转化率 | 转化数 / 送达邮件数 | 1-5% | 电子邮件端到端有效性 |
| 每邮件收入 | 总收入 / 发送邮件数 | 变化 | 直接收入归因 |
| 列表增长率 | （新订阅者 - 取消订阅者） / 总列表 | 每月2-5% | 受众建设健康状况 |

### 社交媒体

| 指标 | 定义 | 告诉你什么 |
|--------|-----------|-------------------|
| 展示次数 | 内容显示次数 | 内容分发和覆盖范围 |
| 覆盖范围 | 独立看到内容的用户数 | 受众广度 |
| 参与率 | （点赞 + 评论 + 分享） / 覆盖范围 | 内容共鸣 |
| 点击率 | 链接点击数 / 展示次数 | 交通驱动有效性 |
| 粉丝增长率 | 每期净新粉丝 / 总粉丝数 | 受众建设 |
| 分享/转发率 | 分享数 / 覆盖范围 | 内容病毒传播和拥护 |
| 视频观看率 | 观看数 / 展示次数 | 视频内容钩子有效性 |
| 视频完成率 | 完成观看数 / 总观看数 | 视频内容质量和长度匹配 |
| 社交声量 | 你的提及数 / 总类别提及数 | 与竞争对手的品牌可见度 |

### 付费广告（搜索和社交）

| 指标 | 定义 | 告诉你什么 |
|--------|-----------|-------------------|
| 展示次数 | 广告显示次数 | 预算利用和定位广度 |
| 点击率（CTR） | 点击数 / 展示次数 | 广告创意和定位相关性 |
| 每点击成本（CPC） | 总支出 / 点击数 | 流量生成成本效率 |
| 每千次展示成本（CPM） | 每千次展示成本 | 意识成本效率 |
| 转化率 | 转化数 / 点击数 | 登录页面和报价有效性 |
| 获取成本（CPA） | 总支出 / 转化数 | 全管道成本效率 |
| 广告支出回报率（ROAS） | 收入 / 广告支出 | 收入生成效率 |

| 视觉转化 | 看到但未点击的用户转化 | 显示/意识活动影响 |

## 按节奏报告模板

### 每周营销报告
团队站会快速扫描格式：
- **3个关键指标**与周环比变化
- **本周表现**（1-2个带数据的要点）
- **需要关注**（1-2个带数据的要点）
- **本周重点**（3-5个行动项）

### 每月营销报告
标准利益相关者报告：
1. 执行摘要（3-5句话）
2. 关键指标仪表板（带MoM和目标比较的表格）
3. 渠道按渠道性能摘要
4. 活动亮点和结果
5. 表现良好和表现不佳（带假设）
6. 建议和下月重点
7. 预算支出与计划

### 季度业务回顾（QBR）
领导层战略回顾：
1. 季度性能与目标对比
2. 年度至今轨迹
3. 渠道ROI分析
4. 活动性能摘要
5. 竞争和市场观察
6. 下个季度的战略建议
7. 预算请求和分配计划
8. 关键实验和学习

### 仪表板设计原则
- 首先展示与业务目标映射的指标（不是虚荣指标）
- 显示随时间变化的趋势，而不仅仅是快照
- 包括比较背景：前期、目标、基准
- 使用一致的彩色编码：绿色（正常）、黄色（风险）、红色（偏离轨道）
- 按漏斗阶段或业务问题分组指标
- 保持仪表板在一页/屏幕上——详细信息放在附录
- 更新节奏应与决策节奏匹配（付费实时，内容每周）

## 趋势分析和预测

### 趋势识别

分析性能数据时，寻找：

1. **方向性趋势**：指标在4个以上周期内是否持续上升、下降或持平？
2. **拐点**：性能何时改变方向以及发生了什么？
3. **季节性**：是否存在按周、月或季度的可预测模式？
4. **异常值**：一次性峰值或下降——是什么原因造成的，是否可重复？
5. **领先指标**：哪些指标首先变化并预测未来结果？

### 趋势分析流程

1. 绘制指标随时间变化（至少8-12个数据点以获得有意义的趋势）
2. 确定总体方向（上升、下降、持平、周期性）
3. 计算变化率（是加速还是减速？）
4. 叠加关键事件（活动启动、产品变更、市场事件）
5. 与基准或目标比较
6. 确定与其他指标的相关性
7. 关于因果关系形成假设（并计划测试以验证）

### 简单预测方法

- **线性外推**：将当前趋势线向前延伸（适用于稳定指标）
- **移动平均**：通过平均最近3-6期来平滑噪声
- **同比比较**：使用去年的模式作为基线，调整增长率
- **漏斗数学**：根据输入预测输出（例如，如果我们产生X线索，转化率为Y，我们将得到Z客户）
- **情景建模**：创建最佳情况、预期情况和最差情况的预测

### 预测注意事项

- 短期预测（1-3个月）比长期更可靠
- 基于少于12个数据点的预测应标记为低置信度
- 外部因素（市场变化、竞争行为、经济变化）可能使基于趋势的预测无效
- 始终将预测表示为范围，而不是确切数字

## 归因模型基础

### 什么是归因？

归因确定哪些营销触点为转化获得信用。这很重要，因为买家通常在转化前与多个渠道互动。

### 常见归因模型

| 模型 | 工作原理 | 适合 | 限制 |
|-------|-------------|----------|------------|
| 最后触点 | 100% 信用给转化前的最后一次互动 | 理解最终转化触发因素 | 忽略认知和培育 |
| 首次触点 | 100% 信用给第一次互动 | 理解顶部漏斗有效性 | 忽略培育和转化驱动因素 |
| 线性 | 所有触点平均分配信用 | 公平代表所有渠道 | 不反映相对影响 |
| 时间衰减 | 越接近转化的触点获得越多信用 | 平衡的视图，偏向近期互动 | 可能低估认知 |
| 位置基础（U形） | 第一次40%，最后一次40%，中间20%平均分配 | 重视发现和转化 | 某种程度上是任意权重 |
| 数据驱动 | 基于转化模式算法分配信用 | 最准确的表现 | 需要大量数据量 |

### 归因实用指南

- 如果没有模型，从最后触点归因开始——它是最简单且可操作的
- 比较首次触点和最后触点，以了解哪些渠道驱动认知 vs. 转化
- 使用位置基础（U形）作为大多数B2B公司的合理中间立场
- 数据驱动归因需要高转化量才能具有统计意义
- 没有完美的模型——方向性地使用归因，而不是作为绝对真理
- 多触点归因比单触点更好，但任何模型都比没有好

### 归因陷阱

- 不要基于单触点归因孤立地优化一个渠道
- 认知渠道（展示、社交、公关）在最后触点模型中始终表现不佳
- 转化渠道（搜索、再营销）在首次触点模型中始终表现不佳
- 自报归因（“你是怎么知道我们的？”）提供有用的定性信息，但作为定量数据不可靠
- 跨设备和跨渠道跟踪差距意味着归因数据总是不完整的

## 优化建议框架

### 优化流程

1. **识别**：哪些指标与目标或基准表现不佳？
2. **诊断**：问题出现在漏斗的哪个环节？（展示、点击、转化、留存）
3. **假设**：是什么原因导致表现不佳？（受众、信息、创意、报价、时间、技术）
4. **优先排序**：哪些修复将产生最大影响且工作量最小？
5. **测试**：设计一个实验来验证假设
6. **衡量**：变化是否改善了指标？
7. **扩展或迭代**：广泛推广成功案例；对结论性或失败的测试进行迭代

### 漏斗阶段优化杠杆

| 漏斗阶段 | 问题信号 | 优化杠杆 |
|-------------|---------------|---------------------|
| 认知 | 展示次数低，覆盖范围低 | 预算，定位，渠道组合，创意格式 |
| 兴趣 | 点击率低，参与率低 | 广告创意，标题，内容钩子，受众定位 |
| 考虑 | 跳出率高，页面停留时间低 | 登录页面内容，页面速度，内容相关性，用户体验 |
| 转化 | 转化率低 | 报价，CTA，表单长度，信任信号，页面布局 |
| 留存 | 挖掘率高，重复参与低 | 在线引导，电子邮件培育，产品体验，支持 |

### 测试最佳实践

- 每次只测试一个变量以获得清晰结果
- 在启动测试前定义成功指标
- 在开始前计算所需样本量（不要提前结束测试）
- 运行测试的最少一个完整业务周期（通常为B2B一周）
- 记录所有测试和结果，无论结果如何
- 在团队中分享学习成果——失败的测试也是宝贵信息
- 确认现状的测试不是失败——它增强了您当前方法的信心

### 持续优化节奏

- **每日**：监控付费活动预算进度、异常和被拒绝的广告
- **每周**：审查渠道性能，暂停表现不佳者，扩展赢家
- **双周**：刷新广告创意并测试新变体
- **每月**：完整性能回顾，识别新的优化机会，更新预测
- **每季度**：渠道组合、预算分配和定位策略的战略回顾
