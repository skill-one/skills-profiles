# 诊断 SEO

用于爬取问题、规范化错误、索引问题和渲染失败的 结构化诊断框架。

## 诊断方法

技术 SEO 问题分为四类。按此顺序诊断——每一层都依赖于前一层正确运行：

1. **可爬取性** — 搜索引擎能否找到并访问页面？
2. **可索引性** — 页面是否允许被索引？
3. **可渲染性** — 搜索引擎能否看到完整内容？
4. **信号** — 是否存在正确的信号（标题、结构化数据、链接）？

## 第 1 层：可爬取性

按顺序检查：

### robots.txt
- 获取 `[domain]/robots.txt` 并查看规则
- 查找过于宽泛的 `Disallow` 规则，阻止重要路径
- 验证 `Sitemap:` 指令指向正确的站点地图 URL
- 检查针对不同用户代理的不同规则（Googlebot 与其他）

**常见错误：**
- `Disallow: /` 阻止整个网站（通常来自测试环境）
- 阻止 Googlebot 渲染所需的 CSS/JS 文件
- 阻止加载动态内容的 API 或 AJAX 端点
- 测试环境的 robots.txt 意外部署到生产环境

### XML 站点地图
- 获取站点地图 URL 并检查：
  - 是否返回 200？是否为有效的 XML？
  - 是否列出所有重要页面？
  - 是否排除不应被索引的页面（404、重定向、noindex 页面）？
  - `<lastmod>` 日期是否准确且最近？
  - 对于大型网站：是否存在站点地图索引？

### 站点架构
- 页面应能在从主页出发的 3 次点击内访问
- 检查是否存在孤儿页面（没有内部链接指向）
- 检查重定向链（页面 A → B → C — 应为 A → C）
- 检查重定向循环

### 服务器响应
- 所有重要页面是否返回 HTTP 200？
- 检查意外的 301/302 重定向
- 检查软 404（页面返回 200 但显示“未找到”内容）
- 验证强制 HTTPS（HTTP 应 301 重定向到 HTTPS）

## 第 2 层：可索引性

### Meta Robots / X-Robots-Tag
- 检查不应被索引的页面是否存在 `<meta name="robots" content="noindex">`
- 检查 HTTP 头部是否存在 `X-Robots-Tag: noindex`
- 常见原因：CMS 意外将 noindex 应用于分页、标签页面或新页面

### 规范化标签
- 每个页面应有指向自身的 `<link rel="canonical">`（自我规范化）
- 检查规范化标签是否指向错误页面（分页内容、过滤 URL 中常见）
- 检查冲突信号：规范化指向页面 A，但设置了 noindex，或页面重定向

**规范化诊断清单：**
- [ ] 规范化 URL 是否与实际 URL 匹配？
- [ ] 规范化 URL 是否可访问（返回 200）？
- [ ] 规范化 URL 是否包含相同内容？
- [ ] 页面上是否只有一个规范化标签？

### 重复内容
- 检查同一内容是否在多个 URL 可访问：
  - 带尾随斜杠与不带尾随斜杠（`/page` vs `/page/`）
  - 带 `www` 与不带 `www`（`example.com` vs `www.example.com`）
  - HTTP 与 HTTPS
  - URL 参数创建重复页面（`?sort=price`，`?page=1`）
- 每个重复集需要一个规范化 URL；其他应重定向或使用规范化标签

## 第 3 层：可渲染性

### JavaScript 渲染
- 页面内容是否出现在原始 HTML 源中？或通过 JavaScript 加载？
- 如果是 JS 渲染：Googlebot 能否看到完整内容？（使用 Search Console 中的 URL 检查工具）
- 检查点击事件、选项卡或手风琴隐藏的内容
- 检查仅通过滚动出现的懒加载内容

### 核心内容可见性
- 主要内容是否在初始 HTML 中？或异步加载？
- 重要元素（标题、标题、产品详情）是否在首次渲染时出现在 DOM 中？
- 检查需要登录或 Cookie 才能查看的内容

## 第 4 层：信号

### 标题标签
- 每个页面有唯一的 `<title>`
- 标题包含主要关键词
- 60 个字符以内（避免在搜索结果页被截断）
- 描述性强且吸引点击

### Meta 描述
- 每个重要页面有 Meta 描述
- 150-160 个字符
- 包含目标关键词和价值主张
- 每页唯一

### 标题结构
- 每页有一个包含主要关键词的 H1
- 逻辑标题层级（H1 → H2 → H3，无跳过）
- 标题描述段落内容（非装饰性）

### 结构化数据
- 检查适合页面类型的 JSON-LD 结构化数据
- 使用 Google 的丰富结果测试进行验证
- 常见类型：Article、Product、FAQ、HowTo、BreadcrumbList、Organization

### Hreflang（多语言网站）
- 检查正确的 `hreflang` 标签，链接语言变体
- 验证互惠标签（页面 A 指向 B，B 指向 A）
- 检查 `x-default` 标签
