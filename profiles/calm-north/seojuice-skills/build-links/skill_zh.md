# 建立链接

使用资产映射、潜在客户评分和触达序列设计来设计一个有针对性的链接获取活动。

## 开始前

收集以下背景信息（如未提供，请询问）：

1. **域名和细分领域。** 哪个网站需要链接？哪个行业？
2. **当前的背链配置文件。** 对当前引用域名数量、域名评级/权威性是否有了解？
3. **可链接的资产。** 该网站是否有：原创研究、工具、数据、信息图表、综合指南？
4. **预算和资源。** 团队能否投资于内容创作、触达工具或公关？
5. **限制条件。** 具有严格链接建设道德的行业（金融、健康）需要特别小心。

## 域名配置文件诊断

在选择策略之前，诊断哪个维度的权威性最弱。这决定了链接建设工作将在哪里产生最大影响：

| 维度 | 衡量标准 | 弱势迹象 |
|-----------|-----------------|-------------------|
| **引用** | 来自优质来源的入站引用 | 引用域名少、低权威性链接者、没有编辑链接 |
| **身份** | 品牌认知和实体一致性 | 没有品牌搜索量、没有知识面板、NAP不一致 |
| **信任** | 合法性和操纵缺失 | 垃圾邮件式背链配置文件、没有HTTPS、内容单薄、手动操作 |
| **卓越** | 可见性和行业地位 | 有机流量低、没有SERP功能、没有媒体提及 |

### 根据弱点制定策略

- **引用弱点**（引用域名少）→ 优先考虑数量：客座文章、资源页面触达、破损链接建设
- **身份弱点**（品牌未被认知）→ 优先考虑品牌提及：公关、维基百科/维基数据、行业目录、播客出现
- **信任弱点**（垃圾邮件式配置文件）→ 首先优先清理（拒绝有毒链接），然后从权威发布商那里获得编辑链接
- **卓越弱点**（没有行业存在感）→ 优先考虑思想领导力：原创研究、会议演讲、专家评论为记者提供

大多数网站有1-2个薄弱维度。诊断后再下结论。

## 链接建设策略（按有效性排序）

### 第一梯队：高权威性、可扩展

**原创研究与数据**
- 发布原创数据、调查、研究或行业报告
- 记者和博主会自然地引用原创数据
- 有效的原因：其他人没有这些数据
- 示例："我们分析了10,000页，发现..."

**免费工具和计算器**
- 建立与您的细分领域相关的真正有用的工具
- 人们会链接到他们使用和推荐的工具
- 有效的原因：持续实用性 = 持续链接
- 示例：投资回报率计算器、审核工具、模板生成器

**综合指南（10倍内容）**
- 创建关于某个主题的权威资源
- 必须比第1页上的所有其他内容都好
- 有效的原因：人们会链接到最好的资源
- 定期更新以保持链接价值

### 第二梯队：有针对性、基于关系

**客座文章（优质）**
- 为您细分领域内相关的权威出版物撰写文章
- 专注于您的受众实际阅读的网站，而不仅仅是DA
- 在一个相关、权威的网站上发布1个链接 > 在通用博客上发布10个链接
- 提供独特的角度，而不是重复的内容

**资源页面链接建设**
- 找到在您的细分领域内收集资源链接的页面
- 搜索：`[主题] + "资源"`，`[主题] + "有用链接"`，`[主题] + "工具"`
- 提供您真正有用的内容以供包含

**破损链接建设**
- 在相关网站上找到破损的出站链接
- 创建或识别可以替代死资源的内容
- 联系网站："我注意到一个破损的链接，这里有一个可用的替代方案"

### 第三梯队：社区和公关

**记者查询平台（Connectively、Qwoted、Featured）**
- 监控记者查询平台上的相关来源请求
- 提供带有资质的专家引言
- 快速响应时间至关重要（在几小时内）

**社区参与**
- 真诚地为社区做出贡献（Reddit、论坛、Slack群组）
- 分享专业知识，而不是链接——当人们发现您的内容时，链接会自然到来
- 首先建立声誉，然后内容会自然传播

**数字公关**
- 使用数据或专家评论新闻劫持热门话题
- 创建与季节性事件或行业里程碑相关的内容
- 向记者提供有数据支持的视角进行推销

## 链接质量评分（LQS）

对每个链接目标（或现有背链）在6个因素上评分。每个因素评1-5分：

### 因素1：域名权威性（25%权重）

| 分数 | DR/DA范围 | 示例 |
|-------|-------------|---------|
| 5 | DR 70+ | 主要出版物、NYTimes、BBC |
| 4 | DR 50-69 | 行业出版物、成熟博客 |
| 3 | DR 30-49 | 中等博客、成长型公司 |
| 2 | DR 15-29 | 小型博客、新公司 |
| 1 | DR <15 | 新建或单薄网站 |

### 因素2：主题相关性（25%权重）

| 分数 | 相关性级别 |
|-------|----------------|
| 5 | 精确匹配——相同细分领域、相同子主题 |
| 4 | 密切相关——相同行业、相邻主题 |
| 3 | 广泛相关——相同一般领域 |
| 2 | 间接相关 |
| 1 | 不相关 |

### 因素3：链接页面流量（15%权重）

| 分数 | 月流量 |
|-------|----------------|
| 5 | 10,000+ |
| 4 | 1,000-9,999 |
| 3 | 100-999 |
| 2 | 10-99 |
| 1 | <10 |

### 因素4：链接位置（15%权重）

| 分数 | 位置 |
|-------|----------|
| 5 | 内容中、编辑提及 |
| 4 | 内容中、上下文资源部分 |
| 3 | 作者简介或关于部分 |
| 2 | 侧边栏或专用链接部分 |
| 1 | 页脚、全站或隐藏 |

### 因素5：锚文本质量（10%权重）

| 分数 | 锚文本类型 |
|-------|-------------|
| 5 | 描述性、自然语言 |
| 4 | 部分关键词匹配、自然 |
| 3 | 品牌名称 |
| 2 | 裸URL |
| 1 | 通用（"点击这里"、"阅读更多"） |

### 因素6：跟随状态（10%权重）

| 分数 | 状态 |
|-------|--------|
| 5 | Dofollow、编辑 |
| 4 | Dofollow、非编辑 |
| 3 | 赞助（rel="sponsored"） |
| 2 | UGC（rel="ugc"） |
| 1 | Nofollow |

### 计算 LQS

```
LQS = (权威性 x 0.25) + (相关性 x 0.25) + (流量 x 0.15)
    + (位置 x 0.15) + (锚文本 x 0.10) + (跟随 x 0.10)
```

| LQS范围 | 评级 | 行动 |
|-----------|--------|--------|
| 4.0-5.0 | 高级链接 | 高优先级——积极追求 |
| 2.5-3.9 | 可接受链接 | 如果触达工作力度低，值得追求 |
| 1.0-2.4 | 低质量 | 跳过——如果是现有背链，则审查风险 |

### 链接配置文件健康基准

使用这些指标来评估整体背链配置文件：

| 指标 | 健康 | 警告 | 危急 |
|--------|---------|---------|----------|
| Dofollow比率 | 60-80% | >90% | >95% |
| 精确匹配锚文本% | <15% | 15-25% | >25% |
| 品牌锚文本% | 25-45% | <15% | <5% |
| 有毒链接% | <5% | 5-10% | >10% |
| 平均链接DR | 25+ | 15-25 | <15 |

## 触达模板框架

**绝对不要使用通用模板。** 每封邮件都要个性化。但这里有一个结构：

### 首次触达
1. **个性化钩子** — 提及他们内容中的具体内容（您喜欢的文章、您同意的观点）
2. **价值主张** — 您提供的内容（而不是索取）
3. **资产** — 链接到您的内容，并附上一句话描述
4. **软请求** — "您可能觉得这对您的读者有用"（而不是"你能给我一个链接吗？")

### 跟进（5-7天后）
- 简短，增加新价值（新数据点、相关资源）
- 最多一次跟进。如果第一次错过了，两次是可以接受的。三次是垃圾邮件。

### 不该做什么
- 批量发送相同的邮件
- 以"我想获得一个链接"开头
- 提供付费链接（违反Google指南）
- 使用虚假赞美或明显通用的AI生成个性化内容
- 发送超过2次跟进

## 活动跟踪

在简单的表格中跟踪触达：

| 潜在客户 | URL | 分数 | 策略 | 状态 | 发送日期 | 响应 | 链接已上线？ |
|----------|-----|-------|----------|--------|-----------|----------|-----------|
| ... | ... | 8/10 | 客座文章 | 提交了 | [日期] | 感兴趣 | 待定 |
| ... | ... | 7/10 | 破损链接 | 发送 | [日期] | 无回复 | — |

**基准：**
- 响应率：5-15% 是冷触达的正常值
- 转化率（响应→链接）：20-40% 的响应
- 总体：预期每100封触达邮件获得1-5个链接
- 高质量活动与优质资产：每100封触达邮件获得10-20个链接
