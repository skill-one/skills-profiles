# 内容简报

制作一份完整、可供编辑使用的内容简报，涵盖意图分析、竞争SERP分析、内容大纲、E-E-A-T要求以及SEO目标。

## 开始前

收集以下背景信息（如未提供，请询问）：

1. **目标关键词或主题。** 内容应排名靠前的核心关键词。
2. **商业背景。** 公司从事什么业务？读者阅读后应做什么（注册、购买、联系）？
3. **内容类型偏好。** 博客文章、着陆页、指南、比较、教程？
4. **目标受众。** 谁会阅读这篇内容？初学者、从业者、决策者？

## 第一步：SERP分析

分析当前目标关键词的排名情况：

1. **搜索关键词**（使用网络搜索）并查看前5-10个结果。
2. **确定主导意图。** 结果是信息性指南、产品页面、列表文章、工具？
3. **注意内容格式。** 平均字数、标题结构、图片/表格/视频的使用。
4. **寻找差距。** 所有顶级结果都涵盖了什么？哪些方面没有很好地覆盖？

记录：

| 排名 | 标题 | URL | 格式 | 大约长度 | 独特角度 |
|------|-------|-----|--------|---------------|--------------|
| 1 | ... | ... | 指南 / 列表文章 / 教程 | ... | ... |

## 第二步：意图映射

确定精确的用户意图并将其映射到内容结构：

- **"如何做"意图** → 带编号步骤的教程
- **"什么是"意图** → 定义 + 背景 + 示例 + 下一步
- **"最佳X"意图** → 精选列表，包含比较标准和推荐
- **"X与Y比较"意图** → 并列比较表 + 结论
- **"评测"意图** → 实际操作评估，优缺点/替代方案

内容结构必须符合搜索者期望找到的内容。

## 第三步：内容大纲

构建详细大纲，包含：

### 标题选项（2-3个变体）

选择与内容类型匹配的公式：

| 内容类型 | 公式 | 示例 |
|-------------|---------|---------|
| 如何做 / 教程 | "如何在[时间段]内[目标]" | "如何在30分钟内修复爬虫错误" |
| 如何做（有异议） | "如何[目标]而不[异议]" | "如何建立链接而不进行冷接触" |
| 列表文章 | "[数字][形容词][主题][限定词]" | "9种有效的链接建设策略用于SaaS" |
| 比较 | "[A]与[B]：哪种更适合[目标]？" | "Ahrefs与SEMrush：哪种更适合关键词研究？" |
| 定义 | "什么是[主题]？[简短说明]" | "什么是主题权威？它如何影响排名" |
| 终极指南 | "关于[主题]的[完整/权威]指南" | "关于技术SEO的完整指南" |
| 错误 | "[数字][主题]错误[后果]" | "7个内部链接错误会破坏排名" |

**CTR提升元素** — 测试添加以下元素：

| 元素 | 预期CTR影响 |
|---------|-------------------|
| 添加数字 | +15-25% |
| 添加当前年份 | +10-15% |
| 添加括号或方括号 | +10-38% |
| 添加强力词（已证实、必要、终极） | +5-12% |

**规则：**
- 包含核心关键词
- 保持在60个字符以内（55个字符用于移动端安全）
- 列表文章中使用奇数（它们比偶数表现更好）
- 如果CTR在1-3名低于2%或在4-10名低于5%，则需重写

### 元描述

选择模板并进行调整：

| 内容类型 | 模板 |
|-------------|---------|
| 博客 / 指南 | "通过我们的[限定词]指南学习[主题]。涵盖[要点1]、[要点2]和[要点3]。[行动号召]" |
| 问答 | "[问题]？这个[年份]指南解释了[什么]、[为什么]和[如何]。立即获取实用技巧。" |
| 列表文章 | "发现[数字][形容词][主题]策略，可以[结果]。有[证据元素]支持。阅读指南。" |
| 比较 | "[A]与[B]：哪种更适合[使用场景]？我们比较了[标准]。查看胜者+详细分析。" |
| 产品/服务 | "[产品]帮助您[利益]。[功能1]、[功能2]、[功能3]。[价格/优惠]。[行动号召]" |

**规则：**
- 150-160个字符（目标140-155个字符，用于移动端安全）
- 自然地包含核心关键词
- 以清晰的价值主张或行动号召结尾
- 尽可能添加数字或统计数据（+5-15% CTR提升）

### 标题结构
规划每个H2和H3，并为每个部分提供简要指导：

```
H1: [标题]
  H2: [部分1] — 要涵盖的内容，目标长度
    H3: [子部分] — 具体要点
  H2: [部分2] — 要涵盖的内容
  ...
  H2: 常见问题解答 — 来自"人们还问"的3-5个问题
```

### 每个部分的要点
对于每个H2部分，指定：
- 要传达的主要观点
- 要包含的数据或示例
- 与竞争对手覆盖内容的差异
- 内部链接机会（链接到网站上的相关页面）

## 第四步：E-E-A-T要求

### YMYL检查

首先，确定关键词是否属于"你的钱或你的命"领域（健康、金融、法律、安全）。MYYL主题会触发谷歌的E-E-A-T要求提升：

- **MYYL关键词**需要：署名作者具有可验证的资质，引用官方来源（.gov、.edu、专业机构），明确披露关联关系，并在适用情况下进行医疗/法律/财务审查。
- **非MYYL关键词**仍然受益于E-E-A-T，但不需要同样的严格性。

### 作者资质

指定作者对此主题需要的资质：

| 主题类型 | 作者要求 |
|-----------|-------------------|
| MYYL（健康、金融、法律） | 执业专业人士或具有公开资质的可验证专家 |
| 技术（代码、工程） | 证明的从业者经验（作品集、GitHub、出版物） |
| 商业/营销 | 行业经验或命名案例研究 |
| 一般信息性 | 带有简介的署名即可 |

### 证据底线

设定此篇内容的最低证据标准：

| 内容类型 | 最低来源数量 | 来源等级要求 |
|---|---|---|
| 研究/数据驱动型 | 5个以上引用 | 至少2个主要来源（官方文档、研究、.gov/.edu） |
| 如何做 / 教程 | 2-3个引用 | 引用工具/方法的官方文档 |
| 意见/思想领导力 | 3个以上引用 | 支持每个主要声明的数据 |
| 比较 / "最佳X" | 每个评审项目1个 | 每个项目的第一手测试证据 |

### E-E-A-T信号

指定内容需要包含：

- **经验：** 第一手示例、案例研究、截图、"我们测试过"的声明
- **专长：** 引用具体数据，参考行业标准，深度超过表面水平
- **权威性：** 链接到权威外部来源，参考公认的框架
- **可信度：** 包含日期、更新频率、作者简介、透明的方法论

### E-E-A-T按内容类型优先级

不同内容类型对E-E-A-T信号的权重不同。将精力集中在最重要的地方：

| 内容类型 | 经验 | 专长 | 权威 | 可信 | 优先级 |
|-------------|-----------|-----------|-----------|-------|-------------|
| 产品评测 | 关键 | 高 | 中 | 高 | 经验 — 手动测试证据 |
| 如何做指南 | 高 | 关键 | 中 | 高 | 专长 — 展示深厚知识 |
| 研究/数据 | 中 | 关键 | 关键 | 关键 | 权威 + 可信 — 源自数据，方法论 |
| 意见文章 | 关键 | 高 | 高 | 中 | 经验 — 个人资质和观点 |
| 比较 | 高 | 高 | 中 | 关键 | 可信 — 公平标准，透明方法论 |
| 新闻/报道 | 中 | 中 | 关键 | 关键 | 权威 — 认可来源，编辑标准 |

### 内容质量检查清单（最高优先级）

对于每一篇内容，至少验证：

- [ ] 作者已识别，相关资质在页面上可见
- [ ] 至少有1个第一手经验元素（案例研究、截图、"我们测试过"）
- [ ] 所有统计数据都有命名来源和日期
- [ ] 至少有2个主要来源的引用（不仅仅是其他博客文章）
- [ ] 发布日期可见；内容在18个月内更新
- [ ] 没有未经证据支持的超级形容词（"最佳"、"最快"、"最有效"）

|---------|--------|

| 特性片段目标 | [是/否 — 如果是，哪种格式：段落、列表、表格] |

## 第六步：差异化角度

简报必须说明是什么让这篇内容比现有排名的更好：

- **更及时：** 更新数据，最近的示例
- **更实用：** 模板、清单、带步骤截图
- **更全面：** 涵盖竞争对手忽略的子主题
- **更具体：** 针对宽泛内容遗漏的利基市场
- **原创数据：** 调查结果、内部数据分析、专家引言

选择1-2个角度。试图在所有维度上获胜会产生通用内容。
