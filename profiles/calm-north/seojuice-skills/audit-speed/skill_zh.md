# 审计速度

对 Deep Core Web Vitals 进行审计，并提供根本原因分析树和资源优化建议。

## 核心网络指标阈值

| 指标 | 优秀 | 需要改进 | 差 |
|------|------|----------|----|
| LCP (Largest Contentful Paint) | < 2.5秒 | 2.5秒 - 4.0秒 | > 4.0秒 |
| CLS (Cumulative Layout Shift) | < 0.1 | 0.1 - 0.25 | > 0.25 |
| INP (Interaction to Next Paint) | < 200毫秒 | 200毫秒 - 500毫秒 | > 500毫秒 |
| FCP (First Contentful Paint) | < 1.8秒 | 1.8秒 - 3.0秒 | > 3.0秒 |
| TTFB (Time to First Byte) | < 800毫秒 | 800毫秒 - 1800毫秒 | > 1800毫秒 |

## 开始前准备

收集以下信息：

1. **哪些页面？** 首页、关键着陆页或特定慢速页面。
2. **当前分数。** 如果用户有 Lighthouse 或 PageSpeed Insights 数据，从那里开始。
3. **技术栈。** CMS、框架、托管服务——这决定了哪些优化可用。
4. **已知限制。** 无法移除的第三方脚本、限制优化的设计要求。

如果无数据可用，建议在关键 URL 上运行 Google PageSpeed Insights。

## LCP 根本原因分析树

LCP 衡量最大可见元素完成渲染的时间。诊断：

**TTFB 是否慢 (> 800毫秒)？**
- → 服务器响应时间问题
- 检查：托管质量、CDN 配置、数据库查询、服务器端渲染时间
- 修复：升级托管服务、添加 CDN、优化服务器端代码、启用缓存

**LCP 元素是否为图片？**
- → 图片优化问题
- 检查：图片格式（使用 WebP/AVIF）、图片大小（提供响应式尺寸）、LCP 图片是否启用懒加载（不应懒加载）
- 修复：转换为现代格式、添加 `width`/`height` 属性、在 LCP 图片上使用 `fetchpriority="high"`、预加载 LCP 图片

**LCP 元素是否为文本？**
- → 字体加载问题
- 检查：自定义字体阻塞渲染、字体文件大小、字体显示策略
- 修复：使用 `font-display: swap` 或 `optional`、预加载关键字体、字体子集化

**阻塞渲染的 CSS/JS 是否延迟了 LCP？**
- 检查：`<head>` 中的大型 CSS 文件、内容之前的同步 JS
- 修复：内联关键 CSS、延迟非关键 CSS、异步/延迟 JS

## CLS 根本原因分析树

CLS 衡量意外的布局偏移。诊断：

**图片/视频是否缺少尺寸？**
- → 浏览器无法在加载前预留空间
- 修复：为所有 `<img>` 和 `<video>` 元素添加 `width` 和 `height` 属性、使用 CSS `aspect-ratio`

**广告或嵌入内容是否注入内容？**
- → 动态内容将现有内容向下推
- 修复：为广告位预留最小高度、为懒加载内容使用 `contain-intrinsic-size`

**字体是否导致文本重排？**
- → FOUT（无样式文本闪烁）在自定义字体加载时导致布局偏移
- 修复：使用 `font-display: optional`（无替换 = 无偏移），或匹配备用字体指标

**动态内容是否插入在视口上方？**
- → 横幅、Cookie 通知、通知将内容向下推
- 修复：使用覆盖层而不是内联插入，或使用固定高度容器预留空间

## INP 根本原因分析树

INP 衡量对用户交互的响应性。诊断：

**主线程是否被长任务阻塞？**
- 检查：JavaScript 执行时间、第三方脚本、大型 DOM
- 修复：使用 `requestIdleCallback` 或 `setTimeout` 分割长任务、代码拆分重型模块

**事件处理程序是否执行重量级同步工作？**
- 检查：触发大型 DOM 更新的点击处理程序、每次按键的表单验证
- 修复：防抖输入、使用 `requestAnimationFrame` 进行视觉更新、将工作卸载到 Web Workers

**第三方脚本是否竞争主线程？**
- 检查：分析工具、聊天小部件、A/B 测试工具、社交嵌入
- 修复：交互后延迟加载、为嵌入使用 `loading="lazy"`、考虑移除低价值脚本

- 总页面重量低于 1.5 MB 为良好
- 大多数网站 JavaScript 低于 300 KB（压缩）
- CSS 低于 100 KB（压缩）
- 第一方字体低于 100 KB
