# 防御塔游戏

一个防御塔游戏的攻略——敌人路径规划、波次生成、防御塔目标选择以及将它们联系起来的经济系统。这是一种**组合型**技能：它将路径规划、AI和UI编排成一个防御塔游戏的循环。它不会重新教授路径规划；它定义了决定一个防御塔游戏是紧张刺激还是枯燥无味的系统以及平衡杠杆（DPS与HP与收入）。

## 使用场景

- 当构建一个玩家**放置防御塔**的游戏时，这些防御塔会自动攻击**按路径行进的敌人波次**，花费获得的货币来扩展/升级，并且如果太多敌人突破防线则输掉游戏时使用。
- 当设计波次构成/节奏、防御塔目标优先级或金币经济系统时使用。

**不适用场景**：玩家直接控制射击者 → `fps-shooter`。自由形式的基地建设有需求 → `survival-crafting`。对于路径规划算法本身，使用 `game-ai`。

## 核心循环

**准备（用当前金币放置/升级防御塔）→ 开始波次 → 敌人沿路径向目标前进，防御塔自动射击 → 从击杀中赚取金币 → 幸存该波次 → 重复对抗更难的波次。** 紧张感是一个规划谜题：我当前的DPS是否足以应对接下来的挑战，以及我是否负担得起答案？

## 必须的系统

1. **敌人路径** — 路径点通道，或网格+路径规划用于迷宫型防御塔游戏（参考资料）。
2. **波次生成器** — 定时、脚本化的敌人类型序列，具有每波次的缩放。
3. **防御塔** — 范围、射速、伤害、弹道/命中扫描、范围伤害；放置有效性。
4. **目标选择** — 每个防御塔的优先级（第一个/最后一个/最近/最强/最弱）（参考资料）。
5. **经济系统** — 从击杀中赚取金币+波次奖励；防御塔/升级成本；出售退款。
6. **生命/泄漏** — 敌人到达目标会损失生命；0 = 游戏结束。
7. **波次/准备UI** — 生命、金币、下一波次预览、开始下一波次控制。

## 设计调节器

| 调节器                  | 效果                  | 备注                                    |
| ------------------------- | ----------------------- | ---------------------------------------- |
| 敌人HP增长/波次      | 升级压力        | 几何级数 ~1.1–1.2×（参考资料）。              |
| 收入与HP曲线      | 难度              | 玩家应该几乎负担得起每一波次。             |
| 防御塔DPS / 范围 / 成本  | 防御塔特性          | 便宜+宽泛 vs. 昂贵+高。                   |
| 目标选择优先级        | 最佳放置       | 比原始属性更能改变游戏。                  |
| 敌人多样性             | 反制一成不变胜利 | 快速 / 装甲 / 飞行 / 群体 / 大型敌人。  |
| 泄漏惩罚              | 赌注                  | 损失生命 _和_ 失去悬赏。                |
| 升级与建造经济 | 策略深度          | 递减的升级回报。                         |
| 波次节奏               | 紧张曲线           | 激增 → 休息 → 激增，非单调。             |

### 2. 防御塔目标选择（过滤到范围，然后按优先级选择）

```python
# 伪代码。"第一个"（路径上最远的）是停止泄漏的标准默认值。
def acquire_target(tower, enemies, mode="first"):
    in_range = [e for e in enemies if distance(tower.pos, e.pos) <= tower.range]
    if not in_range: return None
    if mode == "first":    return max(in_range, key=lambda e: e.progress)   # 路径上最远（停止泄漏）
    if mode == "last":     return min(in_range, key=lambda e: e.progress)   # 进展最少（守卫入口）
    if mode == "closest":  return min(in_range, key=lambda e: distance(tower.pos, e.pos))
    if mode == "strongest":return max(in_range, key=lambda e: e.hp)         # 首先摧毁坦克
    if mode == "weakest":  return min(in_range, key=lambda e: e.hp)         # 确保击杀 / 最后击杀悬赏
    return in_range[0]
```

### 3. "这条通道能承受吗？" 检查（DPS与HP）

```python
# 伪代码。一个防御塔对一个穿过其范围的敌人的伤害。
tower_dps     = tower.damage * tower.fire_rate
time_in_range = tower.range_coverage_length / enemy.speed

```

## 陷阱 / 失败模式

- **敌人HP增长慢于玩家收入/DPS** → 几波次后游戏变得枯燥无味。
  调整HP曲线与收入曲线（参考资料）。
- **一个主导的防御塔/策略** → 没有决策。添加能硬反制建筑的敌人类型
  （装甲 vs. 快速射击，飞行 vs. 仅地面），以及递减的升级回报。
- **迷宫型防御塔可以完全阻挡目标** → 敌人卡住/软锁。禁止切断路径的放置；
  当防御塔变化时重新计算路径（参考资料）。
- **没有下一波次的预告** → 特殊感觉随机且不公平。预览即将到来的构成。
- **每帧移动未按`dt`缩放** → 速度随帧率变化。按`dt`缩放转向。
- **泄漏只损失生命，不损失金币** → 有时泄漏是最优的。让泄漏也损失悬赏。
- **单调难度提升** → 令人筋疲力尽。调整激增和休息的节奏。

## 组合（从这些技能构建）

- **路径规划**：`game-ai`用于A\*/流场/转向；对于固定通道，简单的路径点跟随。
- **敌人移动**：`godot-2d-movement`（或引擎等效）沿路径移动；`unity-navmesh`用于基于导航的路径规划。
- **地图**：`godot-tilemap` / `unity-tilemap-2d`用于网格/通道；`level-design`用于地图布局。
- **数据**：`godot-resources` / `unity-scriptableobjects`定义防御塔、敌人和波次作为资源。
- **UI**：`game-ui-ux`用于HUD布局、缩放和建造菜单；`godot-ui-control`用于具体的控件（生命、金币、波次预览）。
- **润色**：`audio-design`用于射击/命中/泄漏的音效提示。
