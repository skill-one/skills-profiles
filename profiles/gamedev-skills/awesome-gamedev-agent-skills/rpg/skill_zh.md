# 角色扮演游戏

角色扮演游戏的框架——属性与成长、物品/装备、任务、对话和战斗。这是一种**组合式**技能：它将数据驱动内容、对话和存档功能结合起来。它不会重新教授那些基础概念；它定义了让成长和选择感觉有意义的系统，并指向实现每个系统的技能。

## 使用场景

- 在构建RPG/日式RPG/动作RPG时使用：玩家拥有**增长的属性**、**物品栏**、**任务**、**对话**和持续的成长进度。
- 在设计等级曲线、伤害公式、物品/装备模型或任务状态机时使用。

**不适用场景**：无持久角色永久死亡地牢挑战 → `roguelike`。纯对话/分支故事 → `visual-novel`。开放世界需求/制作/基地建设 → `survival-crafting`。对于对话引擎本身，使用 `dialogue-systems`。

## 核心循环

**探索 → 遭遇（战斗/对话/解决）→ 获得奖励（经验值、战利品、故事）→ 成长（升级、装备升级、解锁）→ 挑战更难的内容。** 幻想的核心是*变得更强并塑造你的角色*；每个系统都应该支持这种成长与选择循环。

## 必须包含的系统

1. **属性 + 升级** — 基础属性、衍生战斗属性、经验值曲线、升级收益。
2. **物品栏 + 装备** — 数据定义的物品、堆叠、槽位、属性修正。
3. **战斗** — 回合制或动作式；伤害公式、状态效果、胜负。
4. **任务** — 目标、状态机（可用→激活→完成→提交），奖励。
5. **对话** — 分支对话线、基于游戏状态的条件、有意义的抉择。
6. **存档/读档** — 持久化角色、物品栏、任务进度、世界标志，并支持版本管理。
7. **经济 + 成长限制** — 金币/商店；通过等级/任务/区域限制力量。
8. **UI** — 屏幕提示、物品栏、任务日志、对话框、角色面板。

## 设计调节器

| 调节器 | 效果 | 备注 |
|------|--------|-------|
| 经验值曲线形状 | 力量增长节奏 | 早期快速，后期缓慢（见参考资料）。 |
| 属性→衍生属性缩放 | 构建多样性 | 没有属性应该主导。 |
| 伤害公式 | 战术感觉 | 减法与比例减免（见参考资料）。 |
| 随机变量/暴击 | 波动性 | ±10% 和 ~1.5×暴击是安全的默认值。 |
| 落物率 / 经济 | 奖励节奏 | 避免用战利品使商店变得无意义。 |
| 力量限制 | 难度限制 | 等级/区域/任务锁定。 |
| 可逆修正器 | 加益/装备正确性 | 堆叠修正；从不修改基础属性。 |
| 选择后果 | 角色扮演权重 | 任务/对话标志应分支结果。 |

## 模式

### 1. 从基础属性计算衍生属性（重新计算，不存储为真实值）

```python
# 伪代码。基础属性是唯一“真实值”；战斗属性每次都重新计算。
def derive(base, mods):
    s = apply_modifiers(base, mods)          # 基础 + 固定加成 + 百分比，然后限制
    return {
        "max_hp":  20 + s["VIT"] * 8,
        "attack":  s["STR"] * 2,
        "defense": s["VIT"] + s["AGI"] * 0.5,
    }
# 装备会推入修正器；卸装备会弹出。HP/攻击会自动重新计算。
```

### 2. 经验值曲线 + 升级

```python
# 伪代码。二次曲线：早期等级快速，后期缓慢。
def xp_to_next(level, base=100): return base * level * level

def gain_xp(actor, amount):
    actor.xp += amount
    while actor.xp >= xp_to_next(actor.level):
        actor.xp -= xp_to_next(actor.level)
        actor.level += 1
        actor.base["STR"] += 2; actor.base["VIT"] += 2   # 授予增益/技能点
        on_level_up(actor)                                # 恢复、解锁、通知
```

### 3. 由游戏事件驱动的任务目标更新

```python
# 伪代码。游戏事件会推进匹配的目标；完成会给予奖励。
def on_event(kind, data):
    for q in active_quests:
        for obj in q.objectives:
            if obj.event == kind and matches(obj, data) and not obj.done:
                obj.count += 1
                if obj.count >= obj.needed: obj.done = True
        if all(o.done for o in q.objectives):
            q.state = "complete"                # 提交会给予经验值/金币/物品
```

## 陷阱 / 失败模式

- **修改基础属性以获得加成/装备** → 存档/读档时值会漂移并损坏。保持一个修正器层；推入/弹出（模式1）。
- **存储衍生属性为真实值** → 属性变更后会出现不同步。从基础重新计算。
- **失控的经验值/伤害数值** → 要么是无上限的指数曲线，要么是在极大值时使用减法公式。故意选择曲线和公式系列（见参考资料）。
- **内容作为代码** → 每个物品/任务硬编码。将物品、敌人和任务定义为**数据**（`godot-resources` / `unity-scriptableobjects`）。
- **无版本字段的存档格式** → 更新时旧存档会损坏。添加一个 `version` 并从第一天开始提供迁移路径（见 `save-systems`）。
- **无后果的选择** → 立即重新汇聚的对话分支会感觉空洞。设置实际改变后续任务/世界状态的标志。
- **未持久化的任务进度** → 读档时会丢失中途任务状态。存档任务状态，而不仅仅是完成状态。

## 组合（从这些技能构建）

- **对话**：`dialogue-systems`（Yarn Spinner / Ink）— 分支对话线、条件、变量。
- **持久化**：`save-systems` — 角色、物品栏、任务标志、世界状态，并支持版本管理。
- **内容数据**：`godot-resources` / `unity-scriptableobjects` — 物品、敌人、任务、技能作为资源。
- **战斗AI**：`game-ai` 用于敌人行为；对于回合顺序重用 `roguelike` 中的调度器概念。
- **UI**：`game-ui-ux` 用于屏幕提示/菜单布局、分辨率缩放和控制器/键盘导航；`godot-ui-control` 用于具体的物品栏、任务日志、角色面板和对话框。
- **世界**：`level-design` 加上你的引擎的瓦片地图/3D技能（`godot-tilemap`，`godot-3d-essentials`）。
