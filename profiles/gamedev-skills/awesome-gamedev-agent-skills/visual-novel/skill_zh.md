# 视觉小说

视觉小说的剧本工具——分支脚本、呈现方式（文本框、角色、背景）、选择以及玩家期望的质量提升系统（随时存档、存档记录、跳过、自动播放）。这是一种**组合**技能：它驱动对话引擎和UI层。它不会重新教学对话引擎或UI节点；它定义了脚本模型和让VN阅读体验愉悦的玩家便利功能。

## 使用场景

- 当游戏**主要包含带角色艺术和背景的分支文本**时使用：
  视觉小说、恋爱模拟、分支交互小说、故事选择游戏。
- 当设计选择/路线结构、故事标志或VN便利功能（存档记录、跳过、自动播放、随时存档）时使用。

**不适用场景**：对话作为大型游戏中的一个功能 → `rpg` 消耗 `dialogue-systems`。卡牌/棋盘玩法 → 其他类型。对于分支脚本引擎本身，使用 `dialogue-systems`（Ink / Yarn Spinner）。

## 核心循环

**读一行 → 前进 →（在分支点）做出选择 → 故事根据标志/选择分支 → 继续阅读 → 达到结局。** “游戏”是分支的*形状*以及选择是否感觉有后果；其他一切都是呈现和便利。

## 必须的系统

1. **分支脚本** — 有序的行 + 选择 + 跳转，带有条件和变量（Ink/Yarn）。
2. **文本框** — 发言人姓名、正文文本、打字机揭示、点击/按键前进。
3. **角色** — 带有表情/姿态的精灵、位置、显示/隐藏过渡。
4. **背景 + 过渡** — 场景图像、淡入/淡出。
5. **选择** — 展示选项、根据标志门禁、记录选择。
6. **故事状态** — 分支脚本的标志/变量，解锁内容。
7. **存档/加载（随时存档）** — 完整脚本位置 + 状态；多个插槽；快速存档。
8. **VN便利功能** — 存档记录/历史记录、跳过（阅读文本）、自动播放、文本速度设置。
9. **音频** — 每个场景的音乐、音效、可选的语音片段。

## 设计旋钮

| 旋钮 | 效果 | 备注 |
|------|------|------|
| 文本速度 / 立即 | 阅读舒适度 | 始终允许立即 + 跳过。 |
| 自动播放延迟 | 无手阅读 | 可调；在选择处暂停。 |
| 跳过范围 | 重新阅读 | 默认仅跳过*已读*文本。 |
| 分支广度/深度 | 重玩价值 vs. 成本 | 分支会乘以写作/艺术工作量。 |
| 标志门禁内容 | 反应性 | 检查过去决定的行/选择。 |
| 路线结构 | 故事形状 | 分支合并 vs. 独立路线（参考资料）。 |
| 选择可见性 | 公平性 | 显示锁定选择 vs. 隐藏它们。 |
| 存档记录长度 | 便利性 | 保留足够内容以重新阅读最近上下文。 |

## 模式

### 1. 脚本作为引擎遍历的数据

```python
# 伪代码。行、选择和跳转作为数据——通常在Ink/Yarn中编写并通过该运行时逐步执行。引擎向脚本询问“要显示的下一条内容”。
node = script.current()
if node.kind == "line":
    show_text(node.speaker, node.text)        # 等待前进输入
elif node.kind == "choice":
    options = [o for o in node.options if condition_met(o.condition, flags)]  # 根据标志门禁
    show_choices(options)                      # 等待选择
elif node.kind == "set":
    flags[node.var] = eval_expr(node.expr, flags)
script.advance(selected_option_or_none)
```

### 2. 打字机揭示 + 前进（可跳过）

```python
# 伪代码。随时间揭示字符；第一次点击立即完成整行，然后前进。
def show_text(speaker, text):
    name_label.text = speaker
    revealed = 0
    while revealed < len(text):
        if advance_pressed():                  # 第一次按下：立即揭示整行
            revealed = len(text); break
        revealed += chars_per_second * dt
        body_label.text = text[:int(revealed)]
        push_to_backlog_when_complete(speaker, text)
    wait_for_advance()                          # 第二次按下：进入下一行
```

### 3. 选择设置标志，分支后续内容

```python
# 伪代码。选择写入标志；后续条件读取它们——这就是“反应性”。
def on_choice(option):
    if option.set: flags[option.set] = True     # 例如 flags["helped_npc"] = True
    script.jump(option.target)                   # 跟随分支

# 其他地方，行/选择/结局检查标志：
if flags.get("helped_npc"): play_route("good_ending") else: play_route("neutral_ending")
```

## 陷阱 / 失败模式

- **仅存储检查点的存档** → VN需要**随时存档**。持久化确切的脚本位置*和*所有标志/变量（以及已读文本数据），以便加载时从同一行继续。
- **呈现逻辑嵌入脚本中** → 难以维护。将*内容*（文本、选择）保留在脚本中，将*外观*（精灵、过渡）保留在引擎层。
- **没有跳过/自动/存档记录** → 读者感觉被困住，尤其是在重玩时。这些都是预期的基本功能，不是附加功能。
- **跳过未读文本** → 玩家错过内容。跳过应快进**已读**文本。
- **没有后果的选择** → 立即重新汇聚的分支感觉虚假。设置标志，使后续行、选择或结局明显变化。
- **组合分支爆炸** → 无法发售。优先选择分支合并和少量标志变体，而不是完全独立的树（参考资料）。
- **丢失阅读上下文** → 没有存档记录以重新阅读最后一行。保留历史缓冲区。
- **硬编码语言** → 没有本地化路径。将文本保留在数据中，键入翻译。

## 组合（从这些技能构建）

- **脚本引擎**：`dialogue-systems`（Ink / Yarn Spinner）— 分支、条件、变量、本地化钩子。
- **呈现**：`game-ui-ux` 用于文本框/选择菜单布局、缩放和安全区域；`godot-ui-control` 用于具体的文本框、选择菜单、姓名牌和存档记录UI。
- **持久化**：`save-systems` 用于随时存档插槽、已读文本/跳过数据和设置。
- **音频**：`audio-design` 用于每个场景的音乐、音效和语音播放。
- **视觉效果**：引擎动画/`Tween` 技能用于精灵/背景过渡；`shader-programming` 用于淡入淡出。
- **流程**：`prototype-fast` 在添加艺术之前，用纯文本测试分支结构。
