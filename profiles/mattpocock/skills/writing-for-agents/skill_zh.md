当您要编写的文档内容是**技能（skill）**时，请阅读 [`SKILL-MECHANICS.md`](SKILL-MECHANICS.md)，了解其前置元数据（frontmatter）、调用方式及路由器技能。

## 上下文指针

**上下文指针**是存在于智能体上下文中的一种引用，它指代某些不在上下文中的材料，并编码了抵达该材料的条件。技能的描述算一种；`AGENTS.md` 中命名某文档的一行，属于同一类对象。指针的**措辞**（而非其目标），决定了智能体何时抵达该材料、以及抵达的可靠性。指向一个表述较弱的指针，背后却必须抵达一个重要目标，这属于**变差（variance）缺陷**：应先优化措辞，仅在优化失败时才将材料内联。

一个指针承担两项工作：说明该材料是什么，并列出**应当触发抵达该材料的分支**（分支是文档所处理的某个独立情形，因此不同的运行会经由该分支走不同的路径）。始终加载的指针中的每一个词，在每一次回合中都要付出代价，因此其精简难度也高于正文：

- **前置开头词**：指针是完成触发工作的位置。
- **每个分支一个触发条件**。对同一分支使用同义词重复命名，等于将同一分支写成两遍；应合并它们，只保留真正独立的分支。
- **删除正文已承载的身份信息**。

## 两种加载

您添加的每一份文档和指针，都要消耗两类预算中的**一种**：

- **上下文加载（Context load）** 是始终加载的材料在智能体窗口中的代价：一行 `AGENTS.md`、一个技能描述、任何每一回合都驻留在上下文中的内容，无论是否触发，都在消耗 token 与注意力。
- **认知加载（Cognitive load）** 是人类付出的代价：哪些文档存在，以及何时为每份文档伸手寻找。人是索引。这不是需要最小化的代价：它是人类自主权的代价；在人类判断重要的地方投入，在不重要的地方移除。

仅通过指针抵达的材料，以指针自身那一行代价逃脱上下文加载；没有任何指针的材料，完全依赖认知加载。

## 信息层级

文档由两种内容类型构建：**步骤（steps）**（智能体执行的、按序的动作）和**引用（reference）**（按需查阅的定义、规则、事实）。两者自由混合：全部是步骤（一份食谱）、全部是引用（一份审查的规则、本技能），或两者兼具。核心决策在于每部分在**信息层级**（information hierarchy）中处于何处——该层级按智能体对该材料需求的即时性排序：

1. **文件内步骤** 是主要层级：智能体按序执行的内容。
2. **文件内引用** 按需查阅。常是合法且平级的集合（一份审查中每条规则各占一档），这是一种良好的安排，而非异常。
3. **披露引用** 被推入单独文件，由上下文指针抵达，仅在指针触发时加载。可跨越同一文件夹内的同级文件；也可指向完全外部的、位于任何处的内容——任何文档均可指向它。

向下推载太少，顶部会臃肿；推载过多，则会让智能体实际需要的材料被藏匿。这种张力，就是全部决策所在。

**渐进式披露（Progressive disclosure）** 是沿层级向下（移出主文件、置于指针之后）的举措，目的是让顶部保持可读。它并非 primarily 为 token 优化：它是如何保护层级的方式。分支是最清晰的披露检验：对每个分支所需的内容内联，仅部分分支能抵达的内容置于指针之后。当文档含有步骤、且应当披露的文件内引用将其藏匿，并将注意它们变成一次随机尝试时，它就是一个变差杠杆，而不仅仅是可读性杠杆。

**共置（Co-location）** 是文件内部的配套：一旦层级决定某部分向下放置多深，共置决定在该深度处与之并列的内容是什么。将一个概念的定义、规则与注意事项归置于一个标题之下，而非分散各处，使得阅读其中一个部分时，其邻近内容也随之被带出。检验标准：文档应读起来像是为智能体撰写的文档。分组的内容读起来如此；分散的内容则不然。（与重复不同：重复是在两处重复同一含义；分散是将同一含义的零碎片段散落在多处。）

**蔓延（Sprawl）** 是此处的失败模式：文档过于冗长，即便每一行都是鲜活且唯一的。注意力的密度在被过度撑开的长度上变薄，多出的每一行都是多出的一项需要保持相关性的内容。解决方法是层级：将引用置于指针之后的披露位置，并按分支或顺序拆分，使每条路径只携带所需内容。

## 步骤与完成标准

每一步都以**完成标准（completion criterion）**收尾——该标准告诉智能体工作已完成。两项属性使其成为杠杆：

- **清晰度**：智能体能否区分"已完成"与"未完成"？模糊的界定（"达到理解"）会招致**过早完成**：在步骤真正完成前结束该步骤，注意力滑向"已做完"。待完成步骤（**完成后步骤**）的可见内容提供牵引；完成标准的清晰度则是阻力。按顺序捍卫：**先优化界定**（本地且成本低）；仅在界定本质模糊且观察到匆忙时，才通过拆分序列隐藏后续步骤。隐藏仅在跨真实上下文边界时有效（交接或子代理派发；内联调用会使后续步骤留在上下文中，且不会清除任何内容）。
- **需求度**：它要求多少内容。"每个修改后的模型都已涵盖"会迫使在"产出变更列表"无法要求的场合进行充分工作。需求度驱动**必要劳动（legwork）**（智能体在工作内所做的挖掘，隐含于措辞之中，而非作为独立步骤书写），且它不绑定于步骤本身："每一条规则都已应用"与"每一步都已完成"一样，约束一整块平坦的引用内容，这正是全引用文档仍能承载穷尽性门槛的方式。

最强的标准兼具可检查性与穷尽性。

## 何时拆分

将一份文档拆分为两份，会消耗两类预算之一，因此仅在切割能使其合理时拆分：

- **按顺序拆分**：拆分一系列步骤，其中完成后步骤诱使智能体仓促处理其前序步骤。将其移出视线能驱动对当前任务的更多必要劳动。需警惕反向情况：合并序列会将每步的后续步骤暴露于其后内容之下，招致过早完成。
- **按调用拆分**，技能特定的：见 [`SKILL-MECHANICS.md`](SKILL-MECHANICS.md)。

## 引导词

**引导词（leading word）** 是模型预训练中已内化的一条紧凑概念，智能体在运行文档时会以其思考（_lesson_, _fog of war_, _tracer bullets_）。以 token 形式重复出现，而非以句子形式出现，它积累出分布式的定义，并通过招募模型已有的先验，在最少的 token 内锚定整个行为区域。自行造词只要定义清晰即可，但虚构的词不招募任何先验：你需投入定义 token 来换取预训练词所免费的收益；应优先寻找已有的词。

它双重锚定。在正文中，**执行（execution）**：每当该词出现，智能体每次都会寻求同一行为，并在平坦引用中聚焦注意力于一类需要查找的事物。在指针中，**调用（invocation）**：当同一词出现在你的提示词、文档与代码库中时，智能体会将这种共享语言与材料关联起来，并更可靠地抵达它。

寻找重构以引导词的机会。在三个位置展开的三元组，或一个指针为指代同一理念花一整句时，每一处都是一个渴望收缩为单个 token 的段落：

- "快速、确定性、低开销" → _tight_（_tight_ 循环）。
- "你信服的循环" → _red_，将模糊的门控转化为二值可观测状态（循环在有 bug 时变 _red_，否则不变）。

你双重获益：token 更少，且智能体抓住思考的钩子更锐利。假设每一份文档都在承载可由引导词退役的重复表述。去找到它们。

**否定（Negation）** 是此项杠杆旁的失败模式：以禁止为导向的引导将被禁止的行为拖入上下文，使其**更易**获得，而非更难。"不要想象一头象"，而象就是全部；否定是弱修饰，被强激活的概念将其淹没，因此该禁令半数被读作执行该行为的指令。应提示**正向**：陈述目标行为（"写单行注释"），使被禁止的内容永不提及。禁止仅在作为你无法以正向措辞表达的硬护栏时才有其位置；即便如此，也应与正向目标配对，使注意力落在该做的内容上。

## 精简

- 将每个含义保持在**单一权威来源**：一个权威位置，使行为变更只需一处编辑。**重复（Duplication）**（在同一含义出现多于一处）消耗维护成本与 token，并使该含义在层级上的显著度超过其实际等级。（引导词的偶然反向，即有意重复一个 token，而非含义。）
- **环境**同样是权威来源（`package.json` 脚本、配置文件、目录布局、`--help` 输出），而重复环境的文档是**缓存**：查找的副本，仅在查找成本高时才获得加载。缓存智能体无法通过查找获得的内容：未书写的约定、某项选择背后的原因、配置无法坦白的前瞻隐患。将查找单一文件、单一命令的内容留给环境，在那里它们不会过期。
- 检查每一行是否**相关**：它是否仍支撑文档所做的事？一行失去相关性，要么是因从不支撑任务（仅作铺陈，或本应被披露的分支），要么是因所描述的行为或世界发生变化而变得陈旧。更短的文档更容易保持相关性。缺少精简纪律时，默认命运是**沉积物（sediment）**：因添加感觉安全、移除感觉冒险而沉淀的陈旧层，直到你必须穿过它们去核心清理，才能找到仍然鲜活的内容。
- 逐句寻找**无效操作（no-op）**：模型默认就遵守的指令，对其多言一句却支付了加载成本。检验（相比默认行为，它是否改变行为？）是模型相关的，而非读者相关的：两人在关于无效操作上不一致，意味着他们对默认行为也不一致，且应通过运行文档来定，而非辩论。当一句失败时，删除整句，而非从中裁剪词语。该检验也衡量引导词：一个不足以超越默认的弱词（当智能体已大致充分时"彻底一些"）是无效操作，且修复方式是更强的词（_relentless_），而非不同的技术。</think>**编写智能体消费的任何文档的参考：** 一种技能（skill）、一个 `AGENTS.md` / `CLAUDE.md`、或一个通过指针（pointer）可达的文档。包装方式各不相同；但写作方式是一致的：相同的"杠杆"让每一种都具备可预测性，因为智能体在每一次运行时都遵循**相同的流程**，而非产出相同的结果。

## 引导词

**引导词（leading word）** 是模型预训练中已内化的一条紧凑概念，智能体在运行文档时会以其思考（_lesson_, _fog of war_, _tracer bullets_）。以 token 形式重复出现，而非以句子形式出现，它积累出分布式的定义，并通过招募模型已有的先验，在最少的 token 内锚定整个行为区域。自行造词只要定义清晰即可，但虚构的词不招募任何先验：你需投入定义 token 来换取预训练词所免费的收益；应优先寻找已有的词。

它双重锚定。在正文中，**执行（execution）**：每当该词出现，智能体每次都会寻求同一行为，并在平坦引用中聚焦注意力于一类需要查找的事物。在指针中，**调用（invocation）**：当同一词出现在你的提示词、文档与代码库中时，智能体会将这种共享语言与材料关联起来，并更可靠地抵达它。

寻找重构以引导词的机会。在三个位置展开的三元组，或一个指针为指代同一理念花一整句时，每一处都是一个渴望收缩为单个 token 的段落：

- "快速、确定性、低开销" → _tight_（_tight_ 循环）。
- "你信服的循环" → _red_，将模糊的门控转化为二值可观测状态（循环在有 bug 时变 _red_，否则不变）。

你双重获益：token 更少，且智能体抓住思考的钩子更锐利。假设每一份文档都在承载可由引导词退役的重复表述。去找到它们。

**否定（Negation）** 是此项杠杆旁的失败模式：以禁止为导向的引导将被禁止的行为拖入上下文，使其**更易**获得，而非更难。"不要想象一头象"，而象就是全部；否定是弱修饰，被强激活的概念将其淹没，因此该禁令半数被读作执行该行为的指令。应提示**正向**：陈述目标行为（"写单行注释"），使被禁止的内容永不提及。禁止仅在作为你无法以正向措辞表达的硬护栏时才有其位置；即便如此，也应与正向目标配对，使注意力落在该做的内容上。

## 精简

- 将每个含义保持在**单一权威来源**：一个权威位置，使行为变更只需一处编辑。**重复（Duplication）**（在同一含义出现多于一处）消耗维护成本与 token，并使该含义在层级上的显著度超过其实际等级。（引导词的偶然反向，即有意重复一个 token，而非含义。）
- **环境**同样是权威来源（`package.json` 脚本、配置文件、目录布局、`--help` 输出），而重复环境的文档是**缓存**：查找的副本，仅在查找成本高时才获得加载。缓存智能体无法通过查找获得的内容：未书写的约定、某项选择背后的原因、配置无法坦白的前瞻隐患。将查找单一文件、单一命令的内容留给环境，在那里它们不会过期。
- 检查每一行是否**相关**：它是否仍支撑文档所做的事？一行失去相关性，要么是因从不支撑任务（仅作铺陈，或本应被披露的分支），要么是因所描述的行为或世界发生变化而变得陈旧。更短的文档更容易保持相关性。缺少精简纪律时，默认命运是**沉积物（sediment）**：因添加感觉安全、移除感觉冒险而沉淀的陈旧层，直到你必须穿过它们去核心清理，才能找到仍然鲜活的内容。
- 逐句寻找**无效操作（no-op）**：模型默认就遵守的指令，对其多言一句却支付了加载成本。检验（相比默认行为，它是否改变行为？）是模型相关的，而非读者相关的：两人在关于无效操作上不一致，意味着他们对默认行为也不一致，且应通过运行文档来定，而非辩论。当一句失败时，删除整句，而非从中裁剪词语。该检验也衡量引导词：一个不足以超越默认的弱词（当智能体已大致充分时"彻底一些"）是无效操作，且修复方式是更强的词（_relentless_），而非不同的技术。
