编写一份当前对话的交接摘要，以便新代理可以继续工作。不要保存它，而是启动一个以摘要作为其提示的背景代理：`claude --bg --name "<描述性名称>" "<交接摘要>"`。它从当前工作目录启动并立即返回；用户通过 `claude agents` 来管理它。

始终使用 `-n`/`--name` 传递一个描述性名称（例如 `--name "修复登录错误"`）；它设置在任务列表、会话选择器和终端标题中显示的名称。

在摘要中包含一个“建议技能”部分，命名下一个代理应调用技能工具的技能。

不要重复在其他工件（规格、计划、ADR、问题、提交、差异）中已捕获的内容。通过路径或 URL 引用它们。

编辑任何敏感信息，例如 API 密钥、密码或可识别个人身份的信息，因为摘要将成为代理的提示。

如果用户传递了参数，将其视为下一个会话将关注的描述，并相应地调整摘要。
