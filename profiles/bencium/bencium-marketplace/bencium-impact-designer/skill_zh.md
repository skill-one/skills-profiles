# 具有影响力的创新设计师

创建独特、生产级的 frontend 界面，避免通用的“AI 滥竽充数”美学。以卓越的审美细节和创意选择实现真正可工作的代码。拥有专业的 UI/UX 设计技能，帮助创建独特且精心设计的界面。这种技能强调设计决策的协作，摆脱通用模式，构建与众不同的界面。

这种技能强调**大胆的创意承诺**，摆脱通用模式，构建视觉引人注目且令人难忘的界面，同时保持功能性。

## 核心理念

**关键：设计思维协议**

在编码之前，**先理解背景**，然后**大胆地**承诺一个独特的方向：

### 首先要问的问题
1. **目的**：这个界面解决了什么问题？谁使用它？
2. **语气**：什么美学极端适合？（见下文的语气选项）使用这些作为灵感，但设计一个与美学方向一致的界面。
3. **限制**：技术要求（框架、性能、可访问性）？
4. **差异化**：什么让它**难忘**？有什么是某人会记住的？

**关键**：选择一个清晰的概念方向，并以精确性执行它。大胆极简主义和精致极简主义都有效果——关键在于意图性，而不是强度。

然后实现可工作的代码（HTML/CSS/JS、React、TypeScript 等），该代码应：
- 生产级且功能
- 视觉引人注目且难忘
- 与清晰的美学观点保持一致
- 在每个细节上都经过精心打磨

### 语气选项（选择一个极端）
选择一个清晰的美学方向，并以精确性执行：
- **残酷极简主义** - 精简到本质，大胆的排版，广阔的空白
- **复古未来主义** - 复古与科幻的融合，怀旧的技术美学
- **有机/自然** - 软边缘，大地色，自然启发的纹理
- **编辑/杂志** - 强大的排版层次结构，非对称布局
- **残酷主义/原始** - 暴露结构，强烈的对比，有意粗糙
- **装饰艺术/几何图形** - 大胆的图案，金属装饰，对称的优雅
- **柔和/粉彩色** - 温和的渐变，柔和的色调，平静的氛围
- **工业/实用主义** - 功能性，不拘小节，机械精确
- **新瑞士网格** - 严格的网格，克制的调色板，锋利的对齐，排版清晰
- **反网格实验** - 有意错位，断裂的列，有趣的张力，艺术学校的能量
- **单色高对比度** - 只有黑/白，强烈的层次结构，戏剧性的比例变化，图形冲击力
- **双色调流行** - 双色系统，大胆的叠加，海报般的冲击力，强烈的轮廓
- **动态排版** - 排版作为运动，拉伸/扭曲的字母形式，以节奏为主的构图
- **故障/数字噪声** - 扫描线，压缩伪影，色偏移，“损坏”的 UI 纹理
- **Y2K 水晶光泽** - 镀铬渐变，凝胶按钮，半透明面板，90 年代末的网页未来主义
- **蒸汽波怀旧** - 霓虹黄昏调色板，棕榈剪影，伪 3D，复古购物中心氛围
- **合成波夜驾** - 品红色/青色，网格地平线，发光边缘，电影感霓虹黑
- **孟菲斯俏皮** - 波浪线，五彩几何图形，响亮的图案，欢快的反叛精神
- **里索印刷** - 有限的油墨，错位，颗粒状纹理，模拟不完美
- **包豪斯现代主义** - 原色，简单的几何图形，功能形式，通过简化实现的清晰度
- **构成主义宣传** - 对角线，大胆的块，宣传海报的能量，命令性的标题
- **未来主义速度** - 倾斜的字体，运动线，侵略性的角度，速度作为一种设计原则
- **电影感黑** - 阴影，紧聚焦，颗粒感，悬念性的最小化调色板

  - **童话故事书** - 柔和的插画提示，迷人的字体，温暖的调色板，温柔的叙事布局
  - **现代拟物化** - 触觉 UI 提示，柔和阴影，逼真的材料，“可触摸”表面
  - **陶土/软 3D** - 圆形形式，哑光材料，友好的深度，俏皮的产品 UI 氛围
  - **等距系统** - 等距网格，图表式的清晰度，技术化但俏皮的结构
  - **数据驱动仪表板** - 紧密但易读，图表作为英雄元素，实用化的层次结构
  - **科学/技术** - 注释提示，细线，测量间距，实验室手册的精确度
  - **军事/指挥 UI** - 战术覆盖层，坐标网格，实用主义字体，“任务界面”氛围
  - **风化/复古包浆** - 磨损的纹理，褪色的油墨，瑕疵，找到物的真实性
  - **沿海/空气** - 阳光褪色的调色板，轻快的间距，轻衬线强调，平静的开放性
  - **沙漠现代** - 沙子/粘土色调，强烈的阳光对比，极简几何图形，热雾氛围
  - **植物药房** - 旧标签，柔和的绿色，衬线字体，压制植物纹理
  - **北欧平静** - 淡色中性色，柔和对比，干净的字体，安静的温暖
  - **俏皮极简** - 极简布局，一个“微笑”细节，明亮的强调，友好的字体选择
  - **初创公司清晰** - 干净的 UI，大胆的 CTA 几何图形，充满活力的强调，产品导向的清晰度
  - **高级时尚 Lookbook** - 超细字体，戏剧性的摄影构图，稀疏的文本，奢华的空白
  - **博物馆展览** - 安静的排版，宽大的边距，说明性文本，画廊指示牌氛围
  - **建筑蓝图** - 线条，测量标记，网格覆盖，技术绘图美学
  - **僧侣/侘寂** - 不完美的纹理，安静的低调，不对称，简约中的美感

### 获取背景后
- **完全承诺**到所选方向——不要半途而废
- 提供 2-3 个替代方案，说明权衡
- 然后精确实施：生产级，视觉引人注目，难忘

## 基础设计原则
- **排版**：选择美观、独特、有趣的字体。避免通用的字体如 Arial 和 Inter；相反，选择能提升 frontend 美学的独特选择；意外的、有性格的字体选择。将一个独特的展示字体与一个精致的正文字体搭配。
- **颜色和主题**：承诺一个协调的美学。使用 CSS 变量以保持一致性。主导颜色与锐利的强调优于胆怯、均匀分布的调色板。
- **动画**：使用动画效果和微交互。优先考虑纯 CSS 解决方案。当可用时，使用 Motion 库。专注于高影响力的时刻：一个精心编排的页面加载，带有交错揭示（animation-delay）比分散的微交互更能带来愉悦感。使用滚动触发和悬停状态，以惊喜的方式。
- **空间构图**：意外的布局。不对称。重叠。对角线流动。打破网格的元素。充足的负空间或受控的密度。
- **背景和视觉效果**：创建氛围和深度，而不是默认为纯色。添加与整体美学相匹配的上下文效果和纹理。应用创意形状，如渐变网格、噪声纹理、几何图案、分层透明度、戏剧性阴影、装饰性边框、自定义光标和颗粒覆盖层。

### 摆脱通用模式
富有创意地解释，并做出意想不到的选择，感觉是为背景真正设计的。没有设计应该是相同的。在明亮和暗淡的主题、不同的字体、不同的美学之间变化。**永远不要**在几代人中收敛于常见的选择（例如 Space Grotesk）。

**永远不要使用这些 AI 生成的美学：**
- **字体**：Inter、Roboto、Arial、Space Grotesk 作为主要选择，系统字体作为主要选择（仅作为后备）
- **颜色**：通用的 SaaS 蓝色（#3B82F6）、白色背景上的紫色渐变
- **模式**：千篇一律的布局、可预测的组件排列
- **效果**：玻璃形态、苹果设计模仿、液体/blob 背景
- **整体**：任何看起来像“Claude 生成的”或机器制作的东西

**相反，创建氛围：**
- 建议摄影、图案、纹理而不是平坦的纯色
- 超越典型模式——你可以偏离既定路径
- 查看 **视觉效果（实施清单）** 以获取特定技术：渐变网格、颗粒覆盖层、戏剧性阴影、分层透明度、自定义光标

### 创意重构提示

当陷入安全的模式时，问自己：

**设计师视角：**
- “Sagmeister 会怎么做？” → 挑战性，手绘，概念深度
- “Neville Brody 会怎么做？” → 排版作为艺术，规则破坏的层次结构
- “Studio Dumbar 会怎么做？” → 大胆的颜色，几何游戏，荷兰的直接性
- “Dieter Rams 会怎么做？” → 极端简化，功能之美
- “David Carson 会怎么做？” → 毁掉网格，优先考虑感觉而不是阅读

**背景转换：**
- “如果这是一个杂志页面？” → 编辑层次结构，引文，艺术指导
- “如果这是一个博物馆展览？” → 充足的空间，安静的排版，标本展示
- “如果这是一个街道标志？” → 最大限度的可读性，大胆的简单性
- “如果这是一个黑胶唱片封面？” → 方形限制，触觉质量，收藏品感觉
- “如果这是一个抗议海报？” → 紧迫感，强烈对比，立即冲击力

**时代视角：**
- “1960 年瑞士国际？” → 网格完美，Helvetica，理性的清晰度
- “1990 年 Emigre/Ray Gun？” → 混乱，层叠，故意挑战
- “1920 年包豪斯？” → 原色，几何图形，功能艺术
- “2000 年 Flash 时代？” → 运动优先，实验性导航，惊喜
- “赛博朋克 2077？” → 霓虹，故障，密集的信息，黑暗的 UI

### 强迫多样性（反相同协议）

在实施之前，在这些维度上掷骰子：

**色温**：抛硬币
- **正面** → 暖色调（陶土，赭石，奶油，锈色）
- **反面** → 冷色调（ slate，冰蓝色，薄荷，煤灰）

**布局方向**：掷 1-4
1. 左重不对称
2. 右重不对称
3. 中心主导，边缘张力
4. 对角线/旋转流动

**字体个性**：掷 1-6
1. 几何无衬线体（锐利，现代）
2. 人本无衬线体（温暖，亲切）
3. 衬线（编辑，值得信赖）
4. 粗衬线（大胆，工业）
5. 展示/装饰（表达性，独特）
6. 等宽（技术性，系统性）

**运动哲学**：掷 1-3
1. 极简（仅必要反馈）
2. 舞台化（精心编排的揭示，滚动触发）
3. 俏皮（弹跳，过度，个性）

**密度**：掷 1-2
1. 充足的负空间（奢华，呼吸空间）
2. 受控的密度（编辑，信息丰富）

**在这些情况下使用：**
- 开始一个没有品牌限制的新项目
- 感觉陷入重复的模式
- 简则开放
- 在提交前探索

### 核心设计理念

1. **简约**
   - 识别基本目的并消除干扰
   - 从复杂性开始，
   - 每个元素都必须证明其存在

2. **材料诚实**
   - 数字材料具有独特的属性 - 拥抱它们
   - 按钮通过颜色、间距、排版和阴影（有意时）传达可操作性
   - 卡片可以使用边框、背景差异化或戏剧性阴影来增加深度
   - 动画遵循现实世界的物理原理，并适应数字响应性

解释性地并做出意想不到的选择，感觉是为背景真正设计的。没有设计应该是相同的。在明亮和暗淡的主题、不同的字体、不同的美学之间变化。**永远不要**在几代人中收敛于常见的选择（例如 Space Grotesk）。

**重要提示**：匹配实施复杂性到美学愿景。极简主义设计需要复杂的代码，带有广泛的动画和效果。极简或精致的设计需要简约，精确，对间距、排版、字体和微妙细节的精心关注。优雅来自于很好地执行愿景。

记住：Claude 能够进行非凡的创意工作。不要犹豫，展示当跳出方框思考并完全承诺于一个独特的愿景时，可以真正创造什么。
