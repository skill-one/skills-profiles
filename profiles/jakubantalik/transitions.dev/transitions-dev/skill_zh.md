# Transitions.dev

包含三十二种便携式 CSS 过渡效果，每个效果都使用 `t-*` 选择器命名空间，并具有语义 CSS 自定义属性。即插即用：粘贴代码片段，连接文档中记录的 HTML 钩子，完成。无需框架依赖，无需特定演示的标记，并且每个代码片段都包含 `prefers-reduced-motion` 防护措施。

## 决策规则

当用户请求过渡效果时，首先匹配可见的 UI 元素，然后匹配动词：

- **触发器 + 顶部漂浮的小圆点** → 通知徽章。
- **触发器 + 从其处增长的表面** → 下拉菜单（锚定，感知原点）或模态框（居中，无锚定）。
- **滑入页面区域的表面** → 面板显示。
- **两个屏幕，列表 ↔ 详情或步骤 1 ↔ 步骤 2** → 页面并排。
- **元素更改宽度或高度** → 卡片调整大小。
- **元素文本内容原地更改** → 文本状态交换。
- **同一插槽中的两个图标** → 图标交换。
- **数字更新** → 数字弹出。
- **确认/成功/"完成"时刻**（勾选标记，支付处理，文件上传）→ 成功检查。
- **在水平堆栈中悬停项目**（头像，芯片，分段按钮，标签药丸）→ 头像组悬停。
- **表单验证错误/"这是错误的"反馈**（无效字段，错误的 PIN，重复名称）→ 错误状态摇晃。
- **清除文本字段**（搜索框 × 按钮，过滤器重置）→ 输入清除带溶解。
- **加载后然后交换到真实内容的占位符**（列表行，卡片，个人资料头部）→ 骨架加载器显示。
- **应感觉活跃的进行中/"思考"文本**（加载标签，流式状态）→ 闪烁文本。
- **具有移动高亮的小水平互斥选项集**（视图切换器，分段控制，过滤器选项卡）→ 选项卡滑动。
- **悬停/聚焦提示出现在触发器上方**（图标工具提示，信息气泡）→ 工具提示打开/关闭。
- **堆叠的标题 + 带有节奏感地进入的辅助行**（英雄文本，空状态，引导步骤）→ 文本显示。
- **卡片/瓦片应在悬停时以 3D 方式对指针做出反应**（产品卡片，封面艺术，会员卡，带或不带光晕）→ 卡片悬停倾斜。
- **圆形触发器变为它打开的表面**（+ FAB 变形为菜单/面板，组合按钮展开）→ 加号到菜单变形。如果表面是一个仅仅是从此触发器处增长的*独立*弹出层，则使用菜单下拉菜单。
- **可折叠的标题，其主体在高度上增长/缩小**（设置组，常见问题解答，过滤器部分，"显示更多"，披露）→ 手风琴展开。
- **没有明显匹配** → 落回 `transitions reveal` 并让用户选择。不要猜测。

如果两个过渡效果都适用，则优先选择开销较低的过渡效果（卡片调整大小优先于面板显示，下拉菜单优先于模态框，成功检查优先于完整模态框庆祝），除非设计明确要求使用更重的表面。成功检查仅包含动画——如果你还需要从旋转器交换到检查，请将其与 **图标交换** 配对。

## 命令

该技能暴露了四个命名空间动词，代理应该能够识别，除了直接过渡请求。每个命令都以 `transitions` 开头，因此调用永远不会与同一项目中安装的其他技能的动词冲突。

### transitions reveal — 列出所有过渡效果

**触发短语：** `transitions reveal`，"显示过渡效果"，"列出所有过渡效果"，"这个技能中有哪些过渡效果"，"显示过渡效果目录"。

**行为：** 将三十二种过渡效果作为编号纯文本列表打印出来——名称、一句话摘要和匹配的参考文件名。重用上面 `## 快速参考` 中的行；不要编造新的副本。不需要项目访问权限。

### transitions review — 审计项目以确定适用性

**触发短语：** `transitions review`，"审查我的项目"，“审计我的动画”，“transitions.dev 如何提供帮助”，“找到使用这个技能的地方”。

**行为：**

1. 在工作区中搜索指示：`transition:` 声明，`@keyframes`，样式文件中硬编码的 `ms` / `s` 持续时间，与决策规则模式匹配的组件（模态框，下拉菜单，徽章，搜索输入，骨架，选项卡，工具提示，…）。
2. 对于每个命中，根据决策规则选择单个最佳匹配过渡效果。
3. 按文件分组输出编号列表：
   - `path/to/Component.tsx:L42` — 看起来像下拉菜单正在打开，建议 **menu-dropdown** (`05-menu-dropdown.md`)。
   - 跳过已经使用 `t-*` 类的临时过渡效果。
4. 不要编辑任何内容。以："在任何行上运行 `transitions apply` 来安装建议的过渡效果" 结尾。

### transitions apply — 安装最佳匹配的过渡效果

**触发短语：** `transitions apply`，"在这里应用过渡效果"，"添加正确的过渡效果"，"安装 transitions-dev"，"修复这个元素的动画"。

**行为：**

1. 读取上下文：当前打开的文件，光标最近的元素，周围的 CSS / JSX。如果用户明确指定了过渡效果（例如 `transitions apply menu-dropdown`），则使用它。
2. 运行 `## 决策规则` 中的决策规则，并选择**一个**过渡效果。如果有两个适用，则优先选择较低开销的过渡效果（使用现有规则相同的破平规则）。
3. 显示一条单行建议："我会在这里应用 **menu-dropdown**，因为该元素从触发器处打开并且是锚定的。确认安装？"。
4. 在确认后，逐字遵循 `## 输出格式` 中现有的五步程序（根块，代码片段，钩子，减少运动防护，如果需要则 JS 协调）。
5. 如果代理不能有信心地选择单个过渡效果，则回退到 `transitions reveal` 并要求用户选择。

### transitions refine — 用运动标记替换临时运动

**触发短语：** `transitions refine`，"优化我的过渡效果"，"扫描临时过渡效果"，"用运动标记替换硬编码持续时间"，"标记我的动画"，"调整持续时间/缓动"，"审计我的自定义关键帧"，"使时间保持一致"，"与运动标记对齐"。

**行为：**

1. **扫描整个项目**（不仅限于专用样式表——还包括内联 `style=` / CSS-in-JS，styled-components，`<style>` 块，Tailwind 任意值，如 `duration-[300ms]`）中的临时运动：`transition` / `animation` 短语和长格式，自定义 `@keyframes` 块，硬编码持续时间（`…ms` / `…s`），缓动（`cubic-bezier(...)` 或关键字），平移距离（`px`），`scale(`)，`blur(`)。
2. 对于每个值，根据周围的 选择器 / 组件推断**运动的效果**（模态框关闭，下拉菜单打开，工具提示，徽章出现，文本显示，页面滑动，摇晃，…）从 `## 决策规则`。对于 `@keyframes` 块，读取驱动它的 `animation` 并判断关键帧自身的持续时间和缓动。
3. **关键决策点是使用情况，而不是原始数字。** 在 `## 运动标记` 中查找推断的使用情况，并建议与文档中记录的使用情况匹配的标记——只有当使用情况一致时。300ms 模态框关闭映射到 `--duration-quick`，因为两者都是"模态框关闭"，尽管数字不同。如果一个值的用法与**没有任何**标记的用法匹配，则将其列为 `no matching token usage` 并保持不变——永远不要因为数字接近而强制交换。
4. 按文件分组输出编号列表，仅显示应更改的值，每个值作为 `path/to/Component.css:L42` — `modal close: 300ms → var(--duration-quick) (150ms)`，`ease → var(--ease-smooth-out)`。对于由关键帧驱动的运动，建议驱动 `animation` 的持续时间/缓动所需的标记。
5. 不要编辑任何内容。以："确认任何行以应用更改，或运行 `transitions apply` 以安装完整的过渡效果" 结尾。

## 运动标记

三十二种过渡效果背后的共享运动比例——与 [transitions.dev](https://transitions.dev) 运动标记选项卡暴露的相同标记。它们位于 [`_root.css`](./_root.css) 的顶部，因此一旦导入，您就可以将它们中的任何标记作为 `var(--…)` 引用（例如 `transition: transform var(--duration-fast) var(--ease-smooth-out)`）。

`transitions refine` 将每个现有值映射到下面的使用情况，然后建议要引用的标记。根据**使用情况**而不是原始数字进行匹配——300ms 模态框关闭仍然映射到 `--duration-quick` (150ms)。

**持续时间**

| 标记 | 值 | 使用情况 |
| --- | --- | --- |
| `--duration-stagger` | `40ms` | 每个项目的交错偏移 |
| `--duration-micro` | `80ms` | 工具提示/路径延迟，摇晃段，大交错 |
| `--duration-quick` | `150ms` | 模态框/下拉菜单关闭，文本交换，工具提示出现 |
| `--duration-fast` | `250ms` | 图标交换，下拉菜单/模态框打开，选项卡滑动，页面滑动 |
| `--duration-medium` | `350ms` | 面板关闭，吐司关闭 |
| `--duration-slow` | `400ms` | 面板打开，骨架内容显示，输入清除 |
| `--duration-very-slow` | `500ms` | 强调时刻，徽章出现，文本显示，成功检查 |

**缓动**

| 标记 | 值 | 使用情况 |
| --- | --- | --- |
| `--ease-smooth-out` | `cubic-bezier(0.22, 1, 0.36, 1)` | 模态框/下拉菜单/面板打开 + 关闭，页面滑动，调整大小，位置更改 |
| `--ease-in-out` | `ease-in-out` | 图标交换，文本交换，文本显示，骨架显示 |
| `--ease-out` | `ease-out` | 工具提示打开 / 关闭 |
| `--ease-linear` | `linear` | 闪烁，骨架脉冲，旋转器 |
| `--ease-bounce` | `cubic-bezier(0.34, 1.36, 0.64, 1)` | 徽章弹出打开 |
| `--ease-bounce-strong` | `cubic-bezier(0.34, 3.85, 0.64, 1)` | 弹性悬停出（头像返回） |

**距离**

| 标记 | 值 | 使用情况 |
| --- | --- | --- |
| `--distance-micro` | `4px` | 文本交换 |
| `--distance-small` | `6px` | 错误摇晃（小段） |
| `--distance-base` | `8px` | 徽章对角线显示，页面滑动，错误摇晃（大段） |
| `--distance-medium` | `12px` | 文本显示 |
| `--distance-large` | `30px` | 勾选徽章出现 |

**缩放**

| 标记 | 值 | 使用情况 |
| --- | --- | --- |
| `--scale-large` | `0.96` | 模态框打开 / 关闭 |
| `--scale-medium` | `0.97` | 下拉菜单打开 |
| `--scale-small` | `0.98` | 工具提示打开 |
| `--scale-tiny` | `0.99` | 下拉菜单关闭 |

**模糊**

| 标记 | 值 | 使用情况 |
| --- | --- | --- |
| `--blur-small` | `2px` | 面板显示，图标交换，文本交换，骨架显示，数字弹出 |
| `--blur-medium` | `3px` | 页面滑动，文本显示 |
| `--blur-large` | `8px` | 成功检查打开 |

## 通用安装

将 [`_root.css`](./_root.css) 复制到您的项目中**一次**，然后导入它（或将其 `:root` 块粘贴到您的全局样式表中）。它以共享的**运动标记比例** (`--duration-*`, `--ease-*`, `--distance-*`, `--scale-*`, `--blur-*` — 见 `## 运动标记`）开头，然后是所有三十二种过渡效果的语义可调变量。每个代码片段都从此处读取——`--resize-*`, `--badge-*`, `--dropdown-*`, `--clear-*`, `--shimmer-*`, `--tabs-*`, `--tt-*`, `--stagger-*`, `--tilt-*`, `--morph-*`, `--acc-*`，以及其余部分。

每个参考文件也重新声明了代码片段所需的变量，因此您可以安装单个过渡效果，而无需拉取整个块。不要复制块——如果 `_root.css` 已经导入，请跳过重新粘贴任何每个代码片段的 `:root`。

[transitions.dev](https://transitions.dev) 中的实时演示使用的 `--pX-*` 源标记**故意不**导出。可调值被重命名为语义名称，以便用户拥有设计词汇。几个过渡效果（输入清除，闪烁文本，选项卡，工具提示）带有**颜色**标记，这些标记因主题而异——每个参考文件都记录了 `html[data-theme="dark"]` 覆盖。

## 输出格式

当将过渡效果插入用户的项目中时：

1. **将 `_root.css` 中的变量安装到用户的全局样式表中**，但仅当它们尚未存在时——或者从参考文件中安装单个过渡效果的每个代码片段 `:root` 块。如果通用块已经导入，则**不要**重复它。
2. **逐字粘贴所选过渡效果的 CSS** 从相关的参考文件。不要重写选择器，不要将过渡效果压缩为简写，不要删除 `will-change`。代码片段经过调整和测试。
3. **连接文档中记录的 HTML 钩子**——类名（`.t-dropdown`, `.t-modal`, `.t-success-check`, `.t-avatar`, `.t-clear`, `.t-skel`, `.t-shimmer`, `.t-tabs`, `.t-tt`, `.t-stagger`, `.t-tilt`, `.t-morph`, `.t-acc`, …）和状态属性 (`data-open`, `data-state`, `data-page`, `data-origin`, `aria-selected`, `aria-expanded`, `.is-open`, `.is-closing`, `.is-error`, `.is-shaking`, `.has-value`, `.is-clearing`, `.is-pulsing`, `.is-revealed`, `.is-shown`, `.is-hiding`, `.is-hover`, `.is-tilting`).

## 避免常见错误

- **删除下拉菜单/模态框的关闭状态类清理**——如果没有 `setTimeout` 删除 `.is-closing`，下一个打开将从关闭的缩放跳转到静止的预打开缩放。
- **忘记文本交换，数字弹出，成功检查重播和错误状态摇晃中的重排**——`void el.offsetWidth`（或 `offsetHeight`）在类/属性移除和重新添加之间进行重排，这是确保动画重播的关键。
- **对一个容器进行动画**而不是内部部件——对于徽章，动画圆点，而不是触发器；对于页面滑动，动画页面部分，而不是容器。
- **用 `transition: …` 替换 `transition: all`**——每个代码片段都故意枚举了确切的属性，以便无关的样式更改不会免费搭乘。
- **硬编码成功检查的 `stroke-dasharray`**——代码片段将 `20` 作为占位符。用 `path.getTotalLength()` 四舍五入为 1 替换*您*的路径，否则笔划会预先显示或过度绘制。
- **在 CSS 中设置 `transition-timing-function`** 对于头像组悬停——它必须在 JS 中*之前* `--shift` / `--scale-active` 写入，以便弹性的缓动只适用于 `mouseleave`。
- **将 `.is-error` 和 `.is-shaking` 混合成一个类** 用于错误状态摇晃——保持它们正交是允许摇晃在不 flickering 整个错误处理中重播（移除 → 重排 → 重新添加）。
- **在暗黑模式下留下输入清除光晕在 `mix-blend-mode: multiply`**——切换到 `screen`，将 `--glow-opacity` 提高到 ~0.85，并用 JS 绘制白色渐变。
- **忘记在第一次绘制和调整大小时不使用过渡效果来编写选项卡药丸的初始位置**——在第一次绘制和调整大小时，使用 `transition: none` 设置 `transform` + `width`（然后重排 + 恢复），或者药丸会从 `translateX(0)` / `width: 0` 动画进入。
- **在倾斜元素本身上跟踪指针** 对于卡片悬停倾斜——将 `pointermove` 绑定到扁平的外部 `.t-tilt` 包装器，而不是 `.t-tilt-card`，否则旋转边缘会滑到光标下，悬停会闪烁。
- **在手风琴网格轨道上设置填充**——将填充放在 `.t-acc-panel-inner` 上，永远不要放在 `.t-acc-panel` 上；`0fr` 轨道上的填充会留下残高的条带，因此面板永远不会完全关闭。
- **变形手风琴旗标的 `d` 路径**——CSS `d:` 路径插值仅在 Chromium 中可用，因此它永远不会在移动 Safari / Firefox 上动画。将旗标垂直翻转 (`transform: scaleY(-1)`)，它就像路径变形一样穿过中间的平坦线，并且可以在任何地方工作。保持路径关于其 viewBox 中心的对称性，并添加 `vector-effect: non-scaling-stroke` 以使笔划在翻转过程中保持不变。这是代码片段发送的。
