# 期权收益曲线技能

通过 `visualize:show_widget` 生成一个完全交互式的 HTML 小部件，显示：

- **到期收益曲线**（虚线灰色）—— 到期时的内在价值
- **理论价值曲线**（实线彩色）—— 当前 DTE/IV 的 Black-Scholes 价格
- 所有关键参数的动态滑块
- 实时统计数据：最大利润、最大亏损、盈亏平衡点、当前现货 P&L

---

## 第 1 步：从用户输入中提取策略

当用户提供截图或文本时，提取：

| 字段 | 在哪里查找 | 缺失时的默认值 |
|---|---|---|
| 策略类型 | 标题栏 / 合约描述 | "自定义" |
| 标的资产 | 股票代码 | SPX |
| 执行价 | 标题或合约表中的 K1、K2、K3... | 最接近的整数 |
| 支付/收取的权利金 | 填充价格或平均价格 | 5.00 |
| 数量 | 头寸规模 | 1 |
| 乘数 | 股票期权为 100，SPX 为 100 | 100 |
| 到期日 | 标题中的日期 | 30 DTE |
| 现货价格 | 当前标的资产价格（不是执行价） | 中间执行价 |
| 波动率 | 显示在希腊字母面板中，或从 vega 估算 | 20% |
| 无风险利率 | — | 4.3% |

**对于截图的关键点**：现货价格是标的指数/股票的**当前价格**，不是执行价。切勿将现货默认为执行价。

## 第 2 步：识别策略类型

匹配以下支持的一种策略，然后阅读 `references/strategies.md` 中相应的部分。

| 策略 | 合约数量 | 关键标识符 |
|---|---|---|
| **蝶式价差** | 买入 K1，卖出 2×K2，买入 K3 | 3 个执行价，标题中包含 "Butterfly" |
| **垂直价差** | 买入 K1，卖出 K2（相同到期日） | 2 个执行价，贷方或借方 |
| **日历价差** | 买入远期到期 K，卖出近期到期 K | 相同执行价，2 个到期日 |
| **铁蝶式价差** | 卖出 K2/K3，买入 K1/K4 翅膀 | 4 个执行价，2 个价差 |
| **跨式价差** | 买入看涨期权 K + 买入看跌期权 K | 相同执行价，两种类型 |
| **宽跨式价差** | 买入 OTM 看涨期权 + 买入 OTM 看跌期权 | 2 个执行价，均为 OTM |
| **备兑看涨期权** | 持有 100 股 + 卖出看涨期权 K | 股票 + 空头看涨期权 |
| **裸看跌期权** | 卖出看跌期权 K | 单一合约 |
| **比例价差** | 买入 1×K1，卖出 N×K2 | 不等的数量 |

对于未列出的策略，使用 `自定义` 模式：分解为单个合约并汇总其 P&L。

## 第 3 步：计算收益

### Black-Scholes 看跌期权价格
```
d1 = (ln(S/K) + (r + σ²/2)·T) / (σ·√T)
d2 = d1 - σ·√T
put = K·e^(-rT)·N(-d2) - S·N(-d1)
```

### Black-Scholes 看涨期权价格（通过看跌期权平价）
```
call = put + S - K·e^(-rT)
```

### 蝶式看跌期权收益（到期）
```
if S >= K3: 0
if S >= K2: K3 - S
if S >= K1: S - K1
else: 0
```
每股净 P&L = 收益 − 支付的权利金

### 垂直价差（看涨期权借方）收益（到期）
```
long_call = max(S - K1, 0)
short_call = max(S - K2, 0)
payoff = long_call - short_call - 净借方
```

### 日历价差理论价值
日历无法表示为简单的到期函数 — 始终使用 BS 定价计算两个合约：
```
value = BS(S, K, T_far, r, IV_far) - BS(S, K, T_near, r, IV_near)
```
对于日历的到期曲线：近期合约到期作废，远期合约 = 剩余 T 的 BS 定价。

### 铁蝶式价差收益（到期）
```
put_spread = max(K2-S, 0) - max(K1-S, 0)   // 空头看跌价差
call_spread = max(S-K3, 0) - max(S-K4, 0)  // 空头看涨价差
payoff = 收取的信用 - put_spread - call_spread
```

## 第 4 步：渲染小部件

使用 `visualize:read_me` 并包含模块 `["chart", "interactive"]` 在构建之前。

### 必需的控件（滑块）

**结构部分**：
- 所有执行价（K1、K2、K3... 根据策略需要）
- 支付/收取的权利金
- 数量
- 乘数（默认为 100，显示以增加清晰度）

**定价变量部分**：
- 波动率 %（5–80%，步长 0.5）
- DTE — 到期日（0–90）
- 无风险利率 %（0–8%）

**现货价格**：
- 全宽滑块，范围 = [最小执行价 - 20%，最大执行价 + 20%]，默认为**实际当前现货**

### 必需的统计卡片（实时更新）
- 最大利润（到期）
- 最大亏损（到期）
- 盈亏平衡点 — 对于双边策略显示两个
- 当前现货的理论 P&L

### 图表规格
- X 轴：SPX/标的资产价格
- Y 轴：总美元 P&L（不是每股）
- 蓝色实线 = 当前 DTE/IV 的理论价值
- 灰色虚线 = 到期收益
- 绿色虚线垂直线 = 执行价（K2 中心执行价更亮）
- 黄色虚线垂直线 = 当前现货价格
- 0 上方填充 = 绿色 10% 透明度；0 下方填充 = 红色 10% 透明度
- 提示：悬停时显示两条曲线
