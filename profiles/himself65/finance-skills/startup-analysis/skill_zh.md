# 初创公司分析

生成多角度的初创公司分析，通过三个不同视角来审视公司健康状况和潜力：

1. **风险投资家视角** — 这是否是一个好的投资？市场规模、单位经济模型、增长轨迹、团队质量、防御性
2. **求职者视角** — 我应该在这里工作吗？股权价值、跑道风险、文化信号、职业发展、薪酬公平性
3. **CEO/创始人视角** — 这家公司的健康状况如何？产品市场契合度、烧钱效率、竞争护城河、组织健康

每个视角都能揭示其他视角所忽略的见解。一家公司可能是一个很好的投资，但一个糟糕的工作场所（反之亦然）。目标是给用户一个360度的视角，以便他们能够做出明智的决策。

---

## 第一步：收集信息

在进行分析之前，尽可能收集关于初创公司的公开信息。使用网络搜索、公司网站、Crunchbase数据、新闻报道以及任何其他可用的资源。

**需要收集的关键数据：**

| 类别 | 查找内容 |
|------|---------|
| **基本信息** | 成立时间、总部位置、员工数量、产品功能 |
| **融资情况** | 总融资额、最后一轮融资（规模、日期、如果已知估值）、主要投资者 |
| **产品** | 他们销售什么、谁购买、定价模式、主要竞争对手 |
| **进展** | 用户数、收入（如果公开）、增长信号、知名客户 |
| **团队** | 创始人背景、关键招聘、领英员工数量趋势 |
| **市场** | 行业、市场规模估计、顺风/逆风 |
| **新闻** | 最近新闻报道、产品发布、合作、裁员、转型 |

如果某些数据无法公开获取（例如，私营公司的收入），请记录差距，并从间接信号中推断出你能知道的内容（招聘速度、客户Logo、网络流量代理、招聘信息）。

### 信息不足时

许多初创公司——尤其是早期或利基市场的公司——的公开信息有限。如果网络搜索无法提供足够的信息来生成有意义的分析（例如，你无法确定公司做什么、谁创立了它或它是如何融资的），**请在继续之前要求用户提供公司网站URL**。公司网站通常是信息密度最高的单一来源，直接阅读它（关于页面、定价页面、团队页面、博客）可以填补大多数空白。

你也可以要求用户提供：
- 公司网站或着陆页URL
- Crunchbase、领英或PitchBook链接
- 任何他们拥有的路演演示文稿、招聘信息或新闻报道
- 他们已经了解的特定背景（例如，“他们刚刚从Sequoia获得了A轮融资”）

要求URL并生成准确的分析比猜测并生成误导性的分析要好。

---

## 第二步：确定要涵盖哪些视角

默认情况下，生成所有三个视角。如果用户指定了特定角度（例如，“我正在考虑加入他们”或“应该投资吗”），强调该视角，但仍然包括其他视角作为背景——它们通常揭示相关信息。

| 用户情况 | 主要视角 | 仍然包含 |
|--------|--------|--------|
| 考虑投资 | 风险投资家 | 求职者（人才信号）、CEO（运营健康） |
| 考虑工作机会 | 求职者 | 风险投资家（资金跑道）、CEO（战略方向） |
| 经营公司/顾问 | CEO/创始人 | 风险投资家（投资者如何看待你）、求职者（人才吸引力） |
| 一般好奇心/研究 | 三个视角同等 | — |

---

## 第三步：从每个视角进行分析

阅读相关参考文件以获取每个视角的详细框架。这些包含具体的标准、指标和评估的红色/绿色标志。

### 风险投资家分析

阅读 `references/vc-framework.md` 以获取完整的评估框架。

需要评估的核心领域：
- **市场机会** — TAM/SAM/SOM、市场时机、长期趋势
- **产品与进展** — 产品市场契合度信号、增长指标、留存率
- **单位经济模型** — CAC、LTV、利润率、烧钱倍数、盈利路径
- **团队** — 创始人与市场契合度、技术深度、招聘能力
- **防御性** — 护城河（网络效应、转换成本、数据、品牌、监管）
- **交易条款背景** — 阶段适当的估值、可比退出

生成清晰的**投资理念**（看涨情况）和**关键风险**（看跌情况）。最后以一个结论结束：强力通过 / 轻度通过 / 轻度投资 / 强力投资，并说明理由。

### 求职者分析

阅读 `references/job-applicant-framework.md` 以获取完整的评估框架。

需要评估的核心领域：
- **财务稳定性** — 跑道、烧钱率、融资轨迹、收入健康状况
- **股权价值** — 期权/股权包分析、稀释风险、清算优先权、现实的退出情景
- **职业发展** — 职位范围、学习机会、简历价值、导师指导
- **文化与工作生活** — Glassdoor信号、员工任期数据、领导风格
- **产品与市场风险** — PMF是否真实？如果初创公司失败会发生什么？
- **红旗** — 高流失率、持续转型、模糊指标、创始人套现

生成清晰的**为什么加入**（优点）和**注意**（风险）。最后以一个结论结束：强力通过 / 轻度通过 / 轻度加入 / 强力加入，并说明理由。

### CEO/创始人分析

阅读 `references/ceo-framework.md` 以获取完整的评估框架。

需要评估的核心领域：
- **产品市场契合度** — 留存曲线、有机增长、Sean Ellis测试代理
- **增长效率** — 烧钱倍数、CAC回收期、魔法数字
- **竞争地位** — 护城河强度、竞争动态、市场份额轨迹
- **组织健康** — 招聘管道、流失率、团队能力差距
- **融资准备情况** — 指标与下一轮融资基准的对比、投资者叙事
- **战略风险** — 平台依赖、客户集中度、监管风险

生成清晰的**需要加倍关注的优势**和**紧急需要解决的领域**。最后以健康等级结束：关键 / 困难 / 稳定 / 强力 / 卓越，并说明理由。

---

## 第四步：综合跨视角见解

完成三个分析后，添加一个综合部分，突出显示：

1. **视角一致之处** — 如果所有三个透镜都标记了相同的优势或劣势，它可能就是真实的
2. **视角分歧之处** — 一家公司可能对风险投资家有吸引力（巨大的市场），但对员工有风险（高烧钱率、低跑道）。指出这些。
3. **底线** — 一段总结：这家公司是什么类型的公司，它最可能的轨迹是什么，以及根据其声明的（或暗示的）情况用户应该做什么

---

## 第五步：呈现报告

将输出结构化为一个干净、可扫描的报告：

```
# [公司名称] — 初创公司分析

## 摘要
[2-3句关键概述，包含主要结论]

## 风险投资家视角
### 市场机会
### 产品与进展
### 单位经济模型（如果可用）
### 团队
### 防御性
### 投资结论：[强力通过 / 轻度通过 / 轻度投资 / 强力投资]
[理由]

## 求职者视角
### 财务稳定性
### 股权价值评估
### 职业发展潜力
### 文化与工作生活信号
### 风险因素
### 就业结论：[强力通过 / 轻度通过 / 轻度加入 / 强力加入]
[理由]

## CEO/创始人视角
### 产品市场契合度评估
### 增长效率
### 竞争地位
### 组织健康
### 战略风险
### 健康等级：[关键 / 困难 / 稳定 / 强力 / 卓越]
[理由]

## 跨视角综合
### 一致之处
### 分歧之处
### 底线
```

根据可用数据调整部分深度——如果财务状况完全不透明，请说明并专注于可观察的内容。不要编造指标，但要做出有根据的推断，并说明你的信心水平。
