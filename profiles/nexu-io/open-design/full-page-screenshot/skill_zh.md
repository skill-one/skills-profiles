# 全页截图

> 由 @LewisLiu007 整理。

## 功能

通过 Chrome DevTools 协议捕获网页的全页截图，无需任何依赖。适用于作品集、案例研究和审计报告。

## 来源

- 上游：https://github.com/LewisLiu007/full-page-screenshot
- 分类：`screenshots`
