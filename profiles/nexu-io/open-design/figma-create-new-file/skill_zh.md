# figma-create-new-file

> 来自 Figma 的 MCP 服务器指南。

## 功能

创建一个新的空白 Figma 设计或 FigJam 文件。可作为脚本化设计系统或工作坊工作流程的第一步。

## 来源

- 上游：https://github.com/figma/skills
- 分类：`figma`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划时发现它。要运行完整的上游工作流程及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/figma/skills
```

然后请代理通过名称（`figma-create-new-file`）或使用此技能的 frontmatter 中列出的触发短语来调用此技能。
