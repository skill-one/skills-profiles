# screenshots-marketing

> 由 @Shpigford 精选。

## 功能

使用 Playwright 生成营销截图。适用于落地页主图、App Store 截图和版本更新视觉图。

## 来源

- 上游：https://github.com/Shpigford/screenshots
- 分类：`screenshots`

## 使用方法

此目录项在 OpenDesign 中宣传该技能，以便代理在规划阶段发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活跃代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/Shpigford/screenshots
```

然后通过名称（`screenshots-marketing`）或使用本技能 frontmatter 中列出的触发短语之一来请求代理调用此技能。
