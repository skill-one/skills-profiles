# 设计评审

> 由 Garry Tan (gstack) 精选。

## 功能

Designer Who Codes：进行视觉审核，然后通过原子提交和前后截图进行修复。适用于在发布前优化已发布的 UI。

## 来源

- 上游：https://github.com/garrytan/gstack
- 分类：`创意方向`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。要使用上游的完整工作流程及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游的 README 获取确切路径
open https://github.com/garrytan/gstack
```

然后请代理通过名称（`design-review`）或使用此技能的前置文本中列出的触发短语来调用此技能。
