# fal-vision

> 由 fal.ai 社区团队精选推荐。

## 功能

分析图像 — 分割对象、检测、运行 OCR、描述，并通过 fal.ai 视觉模型回答视觉问题。

## 来源

- 上游：https://github.com/fal-ai-community/skills
- 分类：`image-generation`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划时发现它。若要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活跃代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/fal-ai-community/skills
```

然后通过名称（`fal-vision`）或使用本技能 frontmatter 中列出的触发短语，让代理调用此技能。
