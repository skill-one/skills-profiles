# sora

> 由 OpenAI 技能库精选。

## 功能

通过 OpenAI 的 Sora API 生成、混音和管理短视频片段。适用于电影镜头、B-roll 和快速概念视频迭代。

## 来源

- 上游：https://github.com/openai/skills
- 类别：`video-generation`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划时发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 以获取确切路径
open https://github.com/openai/skills
```

然后请代理通过名称（`sora`）或使用本技能 frontmatter 中列出的触发短语来调用此技能。
