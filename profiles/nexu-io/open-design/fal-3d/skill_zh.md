# fal-3d

> 由 fal.ai 社区团队整理推荐。

## 功能

通过 fal.ai 从文本或图像生成 3D 模型。适用于游戏资源、AR 预览、产品原型和概念雕刻。

## 来源

- 上游：https://github.com/fal-ai-community/skills
- 分类：`3d-shaders`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划时发现它。若要使用完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活跃代理的技能目录中：

```bash
# 查看上游 README 获取确切路径
open https://github.com/fal-ai-community/skills
```

然后请代理通过名称（`fal-3d`）或使用本技能 frontmatter 中列出的触发短语来调用此技能。
