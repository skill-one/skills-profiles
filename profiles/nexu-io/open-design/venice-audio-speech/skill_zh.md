# venice-audio-speech

> 由 Venice.ai 团队整理提供。

## 功能说明

Venice.ai 提供的文本转语音模型、声音、格式和流媒体服务。适用于旁白、配音和对话式代理的声音。

## 来源

- 上游：https://github.com/veniceai/skills
- 类别：`audio-music`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划过程中发现它。若要使用完整的上游工作流程及其原始资源、脚本和引用，请将上游包安装到您的活跃代理的技能目录中：

```bash
# 查看上游 README 获取确切路径
open https://github.com/veniceai/skills
```

然后通过名称（`venice-audio-speech`）或使用本技能 frontmatter 中列出的触发短语来请求代理调用此技能。
