# 高级代理前端技能

## 1. 活跃基线配置
* **设计偏差 (DESIGN_VARIANCE):** 8 (1=完美对称, 10=艺术混沌)
* **运动强度 (MOTION_INTENSITY):** 6 (1=静态/无运动, 10=电影感/魔法物理)
* **视觉密度 (VISUAL_DENSITY):** 4 (1=艺术画廊/空气感, 10=飞行员驾驶舱/密集数据)

**AI 指令:** 所有生成的标准基线严格设置为这些值 (8, 6, 4)。不要要求用户编辑此文件。否则，始终倾听用户：根据他们在聊天提示中明确的要求动态调整这些值。使用这些基线（或用户覆盖的）值作为您的全局变量来驱动第 3 至 7 节的特定逻辑。

## 2. 默认架构与约定
除非用户明确指定不同的技术栈，否则请遵守这些结构约束以保持一致性：

* **依赖项验证 [强制]:** 在导入任何第三方库（例如 `framer-motion`, `lucide-react`, `zustand`）之前，您必须检查 `package.json`。如果缺少包，您必须在提供代码之前输出安装命令（例如 `npm install package-name`）。**永远**不要假设库存在。
* **框架与交互性:** React 或 Next.js。默认使用服务器组件 (`RSC`)。
    * **RSC 安全性:** 全局状态仅在客户端组件中有效。在 Next.js 中，将提供者包装在 `"use client"` 组件中。
    * **交互性隔离:** 如果第 4 或 7 节（运动/液态玻璃）处于活动状态，特定的交互式 UI 组件必须作为隔离的叶组件提取，并在顶部使用 `'use client'`。服务器组件必须专门渲染静态布局。
* **状态管理:** 使用本地 `useState`/`useReducer` 进行隔离的 UI。严格使用全局状态以避免深度属性钻取。
* **样式策略:** 使用 Tailwind CSS (v3/v4) 进行 90% 的样式。
    * **Tailwind 版本锁定:** 首先检查 `package.json`。不要在 v3 项目中使用 v4 语法。
    * **T4 配置保护:** 对于 v4，不要在 `postcss.config.js` 中使用 `tailwindcss` 插件。使用 `@tailwindcss/postcss` 或 Vite 插件。
* **反表情符号策略 [关键]:** **永远**不要在代码、标记、文本内容或替代文本中使用表情符号。用高质量图标（Radix、Phosphor）或干净的 SVG 原语替换符号。表情符号被禁止。
* **响应式与间距:**
  * 标准化断点 (`sm`, `md`, `lg`, `xl`)。
  * 使用 `max-w-[1400px] mx-auto` 或 `max-w-7xl` 包含页面布局。
  * **视口稳定性 [关键]:** **永远**不要使用 `h-screen` 用于全高英雄区域。**始终**使用 `min-h-[100dvh]` 以防止移动浏览器（iOS Safari）上的灾难性布局跳跃。
  * **网格优于 Flex-Math:** **永远**不要使用复杂的 flexbox 百分比数学 (`w-[calc(33%-1rem)]`)。**始终**使用 CSS 网格 (`grid grid-cols-1 md:grid-cols-3 gap-6`) 以获得可靠的布局。
* **图标:** 您必须使用 `@phosphor-icons/react` 或 `@radix-ui/react-icons` 作为导入路径（检查已安装版本）。全局标准化 `strokeWidth`（例如，仅使用 `1.5` 或 `2.0`）。

## 3. 设计工程指令（偏差校正）
LLM 对特定的 UI 陈词滥调模式有统计偏差。使用这些工程规则主动构建高级界面：

**规则 1: 确定性排版**
* **显示/标题:** 默认为 `text-4xl md:text-6xl tracking-tighter leading-none`。
    * **反松散:** 避免使用 `Inter` 进行“高级”或“创意”感觉。强制使用独特的字符，使用 `Geist`、`Outfit`、`Cabinet Grotesk` 或 `Satoshi`。
    * **技术 UI 规则:** 对于 Dashboard/软件 UI，严格禁止使用衬线字体。在这些上下文中，请仅使用高端无衬线字体搭配（`Geist` + `Geist Mono` 或 `Satoshi` + `JetBrains Mono`）。
* **正文/段落:** 默认为 `text-base text-gray-600 leading-relaxed max-w-[65ch]`。

**规则 2: 颜色校准**
* **约束:** 最大 1 个强调色。饱和度 < 80%。
* **LILA 禁令:** 严格禁止“AI 紫色/蓝色”美学。没有紫色按钮发光，没有霓虹渐变。使用绝对中性基础（Zinc/Slate）和高对比度、单一强调色（例如 Emerald、Electric Blue 或 Deep Rose）。
* **颜色一致性:** 在整个输出中坚持一个调色板。不要在同一项目中在暖色和冷灰色之间波动。

**规则 3: 布局多样化**
* **反居中偏差:** 当 `LAYOUT_VARIANCE > 4` 时，严格禁止居中的英雄/H1 区域。强制使用“分屏”（50/50）、“左对齐内容/右对齐资产”或“非对称空白”结构。

**规则 4: 材质性、阴影和“反卡片过度使用”**
* **仪表板硬化:** 对于 `VISUAL_DENSITY > 7`，严格禁止通用卡片容器。使用 `border-t`、`divide-y` 或纯粹负空间进行逻辑分组。数据指标应该呼吸而不被框住，除非提升（z-index）在功能上需要。
* **执行:** 仅在提升传达层次结构时使用卡片。当使用阴影时，将其调色到背景色调。

**规则 5: 交互式 UI 状态**
* **强制生成:** LLM 自然生成“静态”成功的状态。您必须实现完整的交互周期：
  * **加载:** 与布局大小匹配的骨骼加载器（避免通用的圆形旋转器）。
  * **空状态:** 美妙组合的空状态，指示如何填充数据。
  * **错误状态:** 清晰的行内错误报告（例如，表单）。
  * **触觉反馈:** 在 `:active` 上，使用 `-translate-y-[1px]` 或 `scale-[0.98]` 来模拟物理推力，指示成功/操作。

**规则 6: 数据与表单模式**
* **表单:** 标签必须位于输入框上方。辅助文本是可选的，但应在标记中存在。错误文本位于输入框下方。使用标准的 `gap-2` 用于输入块。

## 4. 创意主动性（反松散实施）
为积极对抗通用的 AI 设计，系统性地实施这些高端编码概念作为您的基线：
* **“液态玻璃”折射:** 当需要玻璃效果时，超越 `backdrop-blur`。添加 1px 内边框（`border-white/10`）和微妙的内阴影（`shadow-[inset_0_1px_0_rgba(255,255,255,0.1)]`）以模拟物理边缘折射。
* **磁性微观物理（如果 MOTION_INTENSITY > 5）:** 实现被鼠标光标轻微拉向的按钮。**关键:** **永远**不要使用 React `useState` 进行磁性悬停或连续动画。仅使用 EXCLUSIVELY Framer Motion 的 `useMotionValue` 和 `useTransform` 在 React 渲染周期之外，以防止移动设备上的性能崩溃。
* **持续的微观交互:** 当 `MOTION_INTENSITY > 5` 时，将连续的、无限期的微观动画（脉冲、打字机、浮动、闪烁、轮播）嵌入标准组件（头像、状态点、背景）。对所有交互元素应用高端弹簧物理（`type: "spring", stiffness: 100, damping: 20`）——不要使用线性缓动。
* **布局过渡:** 始终使用 Framer Motion 的 `layout` 和 `layoutId` 属性进行平滑的重新排序、调整大小和跨状态更改的共享元素过渡。
* **交错编排:** 不要立即挂载列表或网格。使用 `staggerChildren`（Framer）或 CSS 级联（`animation-delay: calc(var(--index) * 100ms)`）创建顺序瀑布式揭示。**关键:** 对于 `staggerChildren`，父级（`variants`）和子级必须位于相同的客户端组件树中。如果数据异步获取，请将数据作为属性传递到中央父级 Motion 包装器。

## 5. 性能护栏
* **DOM 成本:** 将晶粒/噪声过滤器仅应用于固定、`pointer-event-none` 伪元素（例如，`fixed inset-0 z-50 pointer-events-none`），永远不要应用于滚动容器，以防止连续的 GPU 重绘和移动性能下降。
* **硬件加速:** 永远不要动画化 `top`、`left`、`width` 或 `height`。仅通过 `transform` 和 `opacity` 动画化。
* **Z-索引限制:** **永远**不要未经提示地滥用任意的 `z-50` 或 `z-10`。严格使用 z-索引用于系统层上下文（粘性导航栏、模态框、覆盖层）。

## 6. 技术参考（旋钮定义）

### 设计偏差 (DESIGN_VARIANCE) (级别 1-10)
* **1-3 (可预测):** Flexbox `justify-center`，严格的 12 列对称网格，相等的填充。
* **4-7 (偏移):** 使用 `margin-top: -2rem` 重叠，不同的图像宽高比（例如，4:3 旁边 16:9），左对齐标题在中心对齐的数据上方。
* **8-10 (非对称):** 马赛克布局，CSS 网格使用分数单位（例如，`grid-template-columns: 2fr 1fr 1fr`），巨大的空白区域（`padding-left: 20vw`）。
* **移动覆盖:** 对于级别 4-10，任何在 `md:` 之上的非对称布局都必须在视口 `< 768px` 上激进地回退到严格的单列布局（`w-full`，`px-4`，`py-8`）以防止水平滚动和布局破坏。

### 运动强度 (MOTION_INTENSITY) (级别 1-10)
* **1-3 (静态):** 没有自动动画。仅使用 CSS `:hover` 和 `:active` 状态。
* **4-7 (流动态 CSS):** 使用 `transition: all 0.3s cubic-bezier(0.16, 1, 0.3, 1)`。使用 `animation-delay` 级联进行加载动画。严格专注于 `transform` 和 `opacity`。谨慎使用 `will-change: transform`。
* **8-10 (高级编舞):** 复杂的滚动触发揭示或视差。使用 Framer Motion 钩子。**永远**不要使用 `window.addEventListener('scroll')`。

### 视觉密度 (VISUAL_DENSITY) (级别 1-10)
* **1-3 (艺术画廊模式):** 大量的空白。巨大的部分间隙。一切感觉都非常昂贵和干净。
* **4-7 (日常应用模式):** 标准间距用于标准 Web 应用。
* **8-10 (驾驶舱模式):** 微小的填充。没有卡片框；只是 1px 线条来分隔数据。一切都打包得很紧。**强制:** 使用 Monospace (`font-mono`) 为所有数字。

## 7. AI 告知（禁止模式）
为确保高级、非通用的输出，您必须严格避免这些常见的 AI 设计签名，除非明确要求：

### 视觉与 CSS
* **无霓虹/外部发光:** 不要使用默认的 `box-shadow` 发光或自动发光。使用内边框或微妙的调色阴影。
* **无纯黑色:** 永远不要使用 `#000000`。使用 Off-Black、Zinc-950 或 Charcoal。
* **无过度饱和强调色:** 降低强调色的饱和度，使其与中性色优雅融合。
* **无过度渐变文本:** 不要使用用于大型标题的文本填充渐变。
* **无自定义鼠标光标:** 它们已过时，会破坏性能和可访问性。

### 排版
* **无 Inter 字体:** 禁用。使用 `Geist`、`Outfit`、`Cabinet Grotesk` 或 `Satoshi`。
* **无超大 H1:** 第一个标题不应喊叫。通过重量和颜色控制层次结构，而不仅仅是巨大的规模。
* **衬线限制:** 仅在创意/编辑性设计中使用衬线字体。**永远**不要在干净的仪表板中使用衬线。

### 布局与间距
* **完美对齐和间距:** 确保填充和边距在数学上是完美的。避免浮动元素与尴尬的间隙。
* **无 3 列卡片布局:** 通用的“水平 3 个等宽卡片”功能行被禁止。使用 2 列锯齿形、非对称网格或水平滚动方法代替。

### 内容与数据（“Jane Doe”效应）
* **无通用名称:** “John Doe”、“Sarah Chan”或“Jack Su”被禁止。使用高度创意、听起来真实的名称。
* **无通用头像:** 不要使用标准的 SVG “蛋”或 Lucide 用户图标作为头像。使用创意、可信的照片占位符或特定样式。
* **无假数字:** 避免可预测的输出，如 `99.99%`、`50%` 或基本电话号码（`1234567`）。使用有机、混乱的数据（`47.2%`，`+1 (312) 847-1928`）。
* **无初创公司松散名称:** “Acme”、“Nexus”、“SmartFlow”。发明高级、上下文相关的品牌名称。
* **无填充词:** 避免AI文案陈词滥调，如“提升”、“无缝”、“释放”或“下一代”。使用具体的动词。

### 外部资源与组件
* **无破旧的 Unsplash 链接:** 不要使用 Unsplash。使用绝对可靠的占位符，如 `https://picsum.photos/seed/{random_string}/800/600` 或 SVG UI Avatars。
* **shadcn/ui 自定义:** 您可以使用 `shadcn/ui`，但永远不要在其通用默认状态下使用。您必须自定义半径、颜色和阴影以匹配高端项目美学。
* **生产就绪的清洁度:** 代码必须极其干净、引人注目、令人难忘，并在每个细节上都经过精心润色。

## 8. 创意武器库（高端灵感）
不要默认为通用 UI。从这个高级概念库中提取灵感，以确保输出在视觉上引人注目且令人难忘。在适当的情况下，利用 **GSAP (ScrollTrigger/Parallax)** 进行复杂的滚动叙事或 **ThreeJS/WebGL** 进行 3D/Canvas 动画，而不是基本的 CSS 运动。**关键:** 永远不要在同一个组件树中混合 GSAP/ThreeJS 与 Framer Motion。默认使用 Framer Motion 进行 UI/Bento 交互。专用于隔离的全页滚动叙事或 Canvas 背景，并严格包装在 useEffect 清理块中。

### 标准英雄范式
停止在深色图像上居中文本。尝试非对称英雄部分：文本干净地对齐到左侧或右侧。背景应显示高质量的相关图像，并带有微妙的风格化淡出（根据是浅色模式还是深色模式，优雅地淡出到背景颜色中）。

### 导航与菜单
* **Mac OS Dock 放大:** 导航栏在边缘；图标在悬停时流畅缩放。
* **磁性按钮:** 被鼠标光标物理拉向的按钮。
* **粘性菜单:** 子项像粘性液体一样从主按钮分离。
* **动态岛屿:** 一个药丸形状的 UI 组件，它会变形以显示状态/警报。
* **上下文径向菜单:** 一个在点击坐标处展开的圆形菜单。
* **浮动快速操作按钮:** 一个 FAB 弹出成一条曲线的次要操作。
* **巨型菜单揭示:** 全屏下拉菜单，内容依次淡出复杂内容。

### 布局与网格
* **Bento 网格:** 非对称、基于瓦片的分组（例如，Apple 控制中心）。
* **马赛克布局:** 没有固定行高的交错网格（例如，Pinterest）。
* **Chroma 网格:** 网格边框或瓦片显示微妙的、持续动画的颜色渐变。
* **分屏滚动:** 两个屏幕半部分在滚动时向相反方向滑动。
* **窗帘揭示:** 英雄部分像窗帘一样在滚动时中间分开。

### 卡片与容器
* **视差倾斜卡片:** 一个跟踪鼠标坐标的 3D 倾斜卡片。
* **聚光灯边框卡片:** 卡片边框在光标下方动态照亮。
* **液态玻璃面板:** 真正的磨砂玻璃，带有内折射边框。
* **全息箔卡片:** 在悬停时移动彩虹光反射的 iridescent、彩虹光。
* **Tinder 滑动堆栈:** 用户可以滑动掉的物理卡片堆。
* **变形模态框:** 一个按钮无缝扩展为其自己的全屏对话框容器。

### 滚动动画
* **粘性滚动堆栈:** 卡片粘在顶部，并物理堆叠在一起。
* **水平滚动劫持:** 垂直滚动转换为平滑的水平画廊滚动。
* **火车滚动序列:** 视频/3D 序列，其帧率直接与滚动条直接相关。
* **缩放视差:** 当您滚动时，中央背景图像无缝缩放/缩小。
* **滚动进度路径:** 用户滚动时绘制的 SVG 矢量线或路线。
* **液体滑动过渡:** 页面过渡像粘性液体一样擦除屏幕。

### 画廊与媒体
* **穹顶画廊:** 感觉像 3D 画廊的 3D 画廊。
* **Coverflow 轮播:** 中心聚焦，边缘倾斜回的 3D 轮播。
* **拖动平移网格:** 一个无边界网格，您可以自由地向任何方向拖动。
* **手风琴图像滑块:** 窄垂直/水平图像条在悬停时完全展开。
* **悬停图像轨迹:** 鼠标在后面留下一个弹出/淡出图像的轨迹。
* **故障效果图像:** 在悬停时 RGB 通道短暂偏移的数字故障。

### 排版与文本
* **动力学跑马灯:** 无限循环的文本带，在滚动时反向方向或加速。
* **文本遮罩揭示:** 巨大的排版作为透明窗口，显示视频背景。
* **文本打字机效果:** 矩阵风格的字符解码，在加载或悬停时。
* **圆形文本路径:** 文本沿旋转的圆形路径弯曲。
* **渐变描边动画:** 带有沿描边持续运行的渐变文本。
* **动力学排版网格:** 一组字母躲避或旋转，远离光标。

### 微观交互与效果
* **粒子爆炸按钮:** 成功的 CTA 分裂成粒子。
* **液体下拉刷新:** 移动刷新指示器像分离的水滴。
* **骨架闪烁:** 在占位符框上移动的光反射。
* **方向感知悬停按钮:** 悬停填充从鼠标进入的确切侧进入。
* **涟漪点击效果:** 精确从点击坐标开始传播的视觉波浪。
* **动画 SVG 线绘制:** 向量实时绘制自己的轮廓。
* **网格渐变背景:** 有机、类似岩浆灯的动画颜色块。
* **镜头模糊深度:** 动态模糊背景 UI 层，以突出前景操作。

## 9. “运动引擎” Bento 范式
在生成现代 SaaS 仪表板或功能部分时，您必须利用以下“Bento 2.0”架构和运动哲学。这超越了静态卡片，并强制执行“Vercel-core meets Dribbble-clean”美学，高度依赖持续的物理。

### A. 核心设计理念
* **美学:** 高端、简约且实用。
* **调色板:** 背景 `#f9fafb`。卡片为纯白色 (`#ffffff`)，带有 `border-slate-200/50` 的 1px 边框。
* **表面:** 对所有主要容器使用 `rounded-[2.5rem]`。应用“扩散阴影”（非常轻、广泛散开的阴影，例如 `shadow-[0_20px_40px_-15px_rgba(0,0,0,0.05)]`）以创建深度而不杂乱。
* **排版:** 严格 `Geist`、`Satoshi` 或 `Cabinet Grotesk` 字体堆栈。对标题使用微妙的跟踪 (`tracking-tight`)。
* **标签:** 标题和描述必须放置在卡片**外部和下方**以保持干净的画廊式呈现。
* **像素完美:** 卡片内部使用充足的 `p-8` 或 `p-10` 填充。

### B. 动画引擎规范（持续运动）
所有卡片必须包含 **“持续微观交互”**。使用以下 Framer Motion 原则：
* **弹簧物理:** 不要使用线性缓动。使用 `type: "spring", stiffness: 100, damping: 20` 以获得高端、有重量的感觉。
* **布局过渡:** 大量使用 `layout` 和 `layoutId` 属性，以确保平滑的重新排序、调整大小和跨状态更改的共享元素过渡。
* **无限循环:** 每个卡片必须有一个“活动状态”无限循环（脉冲、打字机、浮动或轮播）以确保仪表板感觉“活着”。
* **性能:** 将动态列表包装在 `<AnimatePresence>` 中并针对 60fps 进行优化。**性能关键:** 任何持续的微观运动或无限循环都必须被 memoized (React.memo) 并完全隔离在其自己的微观客户端组件中。永远不要在父布局中触发重新渲染。

### C. 5 卡片原型（微观动画规范）
在构建 Bento 网格（例如，行 1: 3 列 | 行 2: 2 列分割 70/30）时，实施这些特定的微观动画：
1. **智能列表:** 垂直堆叠的项目具有无限自动排序循环。使用 `layoutId` 使项目交换位置，模拟 AI 实时优先处理任务。
2. **命令输入:** 搜索/AI 条件栏具有多步骤打字机效果。它循环通过复杂的提示，包括一个闪烁的光标和一个带有闪烁加载渐变的“处理”状态。
3. **实时状态:** 调度界面具有“呼吸”状态指示器。包括一个以“过度弹簧”效果出现的弹出通知徽章，持续 3 秒，然后消失。
4. **宽数据流:** 水平“无限轮播”的数据卡片或指标。确保循环是无缝的（使用 `x: ["0%", "-100%"]`）并且速度感觉毫不费力。
5. **上下文 UI（聚焦模式）:** 一个文档视图，动画化文本块的交错高亮，然后是一个“浮动”的浮动操作工具栏，带有微小的图标。
