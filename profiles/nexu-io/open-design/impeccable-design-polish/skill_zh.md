# 无懈可击的设计润色

将此技能用作现有设计的后生成处理步骤。它不应从头开始重启项目；它应使当前产物更清晰、更易用，并更接近设计师会发布的东西。

## 后续模式

- **审计**：识别层级、间距、颜色、字体、交互状态、响应式设计、可访问性等方面的最高影响问题。
- **评论**：解释哪些地方感觉过于通用、过度设计、设计不足或不一致。
- **润色**：直接编辑产物以改进主要问题，同时保留用户的意图。
- **动画**：仅在改进反馈或故事讲述时添加克制、有用的动画效果。
- **加固**：修复移动端溢出、文本裁剪、对比度问题、缺失状态、断链和脆弱的布局假设。
- **发布**：为演示或分享准备产物，包括最终的视觉质量保证和清晰的下一步行动。

## 操作规则

1. 在编辑前检查当前的HTML/页面。不要仅凭提示进行猜测。
2. 除非用户明确要求更改，否则保留现有内容、品牌和场景。
3. 优先选择少数决定性修复，而不是广泛的表面修改。
4. 移除常见的AI痕迹：
   - 没有产品理由的紫色-蓝色光晕渐变
   - 通用3卡片功能行
   - 到处都是过大的圆角卡片
   - 空白的市场营销形容词
   - 不一致的间距和字体比例
   - 不支持理解的装饰效果
5. 保留可访问性：焦点状态、对比度、语义控件、可读文本和减少运动的回退方案。
6. 以更好的可运行状态完成产物，而不仅仅是评论列表。

## 最佳搭配

- 与 `design-taste-frontend` 或 `gpt-taste` 搭配，用于更强的反杂乱重设计工作。
- 与 `emilkowalski-motion` 或 GSAP技能搭配，用于特定运动的润色。
- 当产物需要真实视觉资产而非纯CSS装饰时，与图像/视频技能搭配。
