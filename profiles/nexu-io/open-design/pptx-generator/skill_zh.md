# pptx-generator

## 功能

使用 PptxGenJS 从头开始创建和编辑 PowerPoint 演示文稿 — MiniMax 的经过生产测试的演示文稿流程。

## 来源

- 上游：https://github.com/MiniMax-AI/skills
- 类别：`slides`

## 如何使用

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 以获取确切路径
open https://github.com/MiniMax-AI/skills
```

然后请代理通过名称（`pptx-generator`）或使用此技能的前置文本中列出的触发短语来调用此技能。
