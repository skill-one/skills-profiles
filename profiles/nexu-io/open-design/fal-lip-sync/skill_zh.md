# fal-lip-sync

> 由 fal.ai 社区团队精选。

## 功能

通过 fal.ai 创建口型匹配的视频和音频。适用于解释性头像、多语言配音预览和社交剪辑。

## 来源

- 上游：https://github.com/fal-ai-community/skills
- 分类：`video-generation`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划过程中发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/fal-ai-community/skills
```

然后请代理通过名称（`fal-lip-sync`）或使用本技能 frontmatter 中列出的触发短语来调用此技能。
