# 平台设计

> 由 @ehmo 精选。

## 功能

Apple HIG、Material Design 3 和 WCAG 2.2 提供的 300 多条设计规则，适用于跨平台应用。当需要在 iOS、Android 和 Web 上发布统一设计时非常有用。

## 来源

- 上游：https://github.com/ehmo/platform-design-skills
- 分类：`design-systems`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划时发现它。若要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活跃代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/ehmo/platform-design-skills
```

然后通过名称（`platform-design`）或使用此技能 frontmatter 中列出的触发短语之一来询问代理调用该技能。
