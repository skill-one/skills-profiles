# fal-upscale

> 由 fal.ai 社区团队精选。

## 功能

使用 fal.ai 上托管的 AI 超分辨率模型，对图像和视频分辨率进行提升和增强。

## 来源

- 上游：https://github.com/fal-ai-community/skills
- 类别：`image-generation`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。要使用完整的上游工作流程及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游的 README 获取确切路径
open https://github.com/fal-ai-community/skills
```

然后通过名称（`fal-upscale`）或使用此技能 frontmatter 中列出的触发短语之一来询问代理调用此技能。
