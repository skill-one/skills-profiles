# swiftui-design

> 由 @wholiver 精选。

## 功能

SwiftUI 前端设计技能 — 反对 AI 低劣设计规则、设计方向顾问、品牌资产协议以及五维审查。可与 Claude Code、Cursor、Codex 和 OpenCode 协作。

## 来源

- 上游：https://github.com/wholiver/swiftui-design-skill
- 分类：`design-systems`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划时发现它。若要使用其原始资产、脚本和引用的完整上游工作流程，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/wholiver/swiftui-design-skill
```

然后请代理通过名称（`swiftui-design`）或使用本技能 frontmatter 中列出的触发短语来调用此技能。
