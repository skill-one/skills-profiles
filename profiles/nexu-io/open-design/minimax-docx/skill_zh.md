# minimax-docx

> 由 MiniMax AI 团队整理。

## 功能

使用 OpenXML SDK 进行专业的 DOCX 文档创建和编辑。适用于品牌报告、精炼提案和基于模板的编写。

## 来源

- 上游：https://github.com/MiniMax-AI/skills
- 分类：`documents`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划时发现它。要运行完整的上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游的 README 获取确切路径
open https://github.com/MiniMax-AI/skills
```

然后请代理通过名称（`minimax-docx`）或使用此技能的前置文本中列出的触发短语来调用此技能。
