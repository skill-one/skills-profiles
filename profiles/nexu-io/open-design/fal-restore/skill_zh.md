# fal-restore

> 由 fal.ai 社区团队整理提供。

## 功能

恢复和修复图像质量 — 模糊去焦、降噪、修复人脸、以及使用 fal.ai 的托管恢复模型修复旧文档。

## 来源

- 上游：https://github.com/fal-ai-community/skills
- 分类：`image-generation`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划过程中发现它。若要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活跃代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/fal-ai-community/skills
```

然后请代理通过名称（`fal-restore`）或使用本技能 frontmatter 中列出的触发短语来调用此技能。
