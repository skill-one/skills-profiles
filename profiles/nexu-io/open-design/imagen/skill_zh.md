# imagen

> 由 @sanjay3290 精选。

## 功能

使用 Google Gemini 的图像生成 API 生成图像，用于 UI 模板、图标、插图和视觉资源。

## 来源

- 上游：https://github.com/sanjay3290/imagen
- 分类：`image-generation`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/sanjay3290/imagen
```

然后通过名称（`imagen`）或使用此技能 frontmatter 中列出的触发短语之一来询问代理调用此技能。
