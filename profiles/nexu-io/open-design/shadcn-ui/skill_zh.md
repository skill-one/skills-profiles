# shadcn-ui

> 由 Google Labs (Stitch) 精选。

## 功能

使用 shadcn/ui 构建 UI 组件。与 Stitch 设计循环配合使用，可快速交付结构化、可访问的组件。

## 来源

- 上游：https://github.com/google-labs-code/skills
- 类别：`design-systems`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/google-labs-code/skills
```

然后请代理通过名称 (`shadcn-ui`) 或使用此技能 frontmatter 中列出的触发短语之一来调用此技能。
