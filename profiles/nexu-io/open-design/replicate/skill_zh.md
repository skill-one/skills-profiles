## 功能

使用 Replicate 的 API 发现、比较和运行 AI 模型。非常适合需要频繁切换模型的图像、音频和视频生成流程。

## 来源

- 分类：`image-generation`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划时发现它。要运行完整的上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/replicate/skills
```

然后通过名称（`replicate`）或使用本技能 frontmatter 中列出的触发短语之一来要求代理调用此技能。
