# ad-creative

> 由 Corey Haines 整理。

## 功能

生成和迭代广告创意，包括标题、描述和主要文本。适用于付费社交和搜索广告迭代。

## 来源

- 上游：https://github.com/coreyhaines31/marketingskills
- 类别：`marketing-creative`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划过程中发现它。若要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/coreyhaines31/marketingskills
```

然后请代理通过名称（`ad-creative`）或使用本技能 frontmatter 中列出的触发短语来调用此技能。
