# venice-video

> 由 Venice.ai 团队整理。

## 功能

通过 Venice.ai API 进行视频生成和转录工作流。

## 来源

- 上游：https://github.com/veniceai/skills
- 分类：`video-generation`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。要运行完整的上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/veniceai/skills
```

然后通过名称（`venice-video`）或使用此技能 frontmatter 中列出的触发短语之一来要求代理调用此技能。
