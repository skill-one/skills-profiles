# FAQ 页面技能

生成一个包含可折叠手风琴区域、搜索功能和分类筛选的 FAQ 页面。

## 工作流程

1. **读取活跃的 DESIGN.md**（位于上方注入）。使用组件标记来定义交互元素（手风琴标题、搜索输入框、分类药丸）。
2. **从简报中选择领域**（例如，SaaS 产品、电子商务、服务），并针对 3-4 个分类编写 12-18 个真实的 FAQ 条目。
   - **边缘情况**：
     - 如果简报提供的 FAQ 少于 8 个，请要求更多内容或根据领域生成逼真的问题。
     - 对于 1-5 个 FAQ，跳过分类和搜索；显示一个简单的列表。
     - 对于非常长的答案（>100 字），将其分成段落或项目符号以保持可读性。
3. **部分的顺序**：
   - **页眉** — 页面标题（“常见问题”或“帮助中心”），可选的副标题（1 句话解释用户可以在这里找到什么）。
   - **搜索栏** — 醒目的搜索输入框，带有占位符文本和图标。功能 JS 实时过滤问题。
   - **分类筛选器** — 3-4 个药丸式按钮，按分类筛选（例如，“账单”、“账户”、“技术”、“一般”）。默认选中“全部”。
   - **FAQ 手风琴** — 可折叠的问题/答案对：
     - 问题作为可点击的标题，带有展开/折叠图标（箭头或加号/减号）。
     - 答案默认隐藏，点击时平滑展开。
     - 每个条目都有 `data-category` 属性用于筛选。
   - **页脚 CTA** — “还有其他问题吗？”部分，包含联系链接或支持邮箱。
4. **编写**一个 HTML 文档：
   - `<!doctype html>` 到 `</html>`，CSS 和 JS 内联。
   - 手风琴使用语义 HTML（`<details>` 和 `<summary>` 用于渐进增强，或带有适当 ARIA 属性的自定义 JS）。
   - 搜索通过匹配问题或答案中的文本来过滤问题。
   - 分类筛选器根据 `data-category` 显示/隐藏问题。
   - 平滑的展开/折叠过渡（最大高度或 grid-template-rows）。
   - `data-od-id` 在页眉、搜索、分类、手风琴容器、页脚上。
5. **自我检查**：
   - 问题具体且逼真（不是通用的占位符）。
   - 答案简洁（2-4 句话）但完整。
   - 键盘导航正常（通过问题 Tab，按 Enter 展开）。
   - 搜索不区分大小写，通过匹配文本过滤。
   - 一次只有一个手风琴项展开（可选，取决于 UX 偏好）。
   - 适合移动设备（手风琴标题可点击，搜索可用）。

## 输出合同

在 `<artifact>` 标签之间输出：

```
<artifact identifier="faq-page" type="text/html" title="FAQ Page">
<!doctype html>
<html>...</html>
</artifact>
```

在 artifact 之前有一句，之后没有。

## 按分类的示例问题

**账单**
- 如何更新我的支付方式？
- 你们接受哪些支付方式？
- 我可以退款吗？
- 如何取消我的订阅？

**账户**
- 如何重置我的密码？
- 我可以更改我的邮箱地址吗？
- 如何删除我的账户？
- 取消后我的数据会怎样？

**技术**
- 你们支持哪些浏览器？
- 有移动应用吗？
- 如何导出我的数据？
- 你们 API 的速率限制是多少？

**一般**
- [产品名称] 是什么？
- 如何开始使用？
- 你们提供客户支持吗？
- 我在哪里可以找到你们的条款服务？
