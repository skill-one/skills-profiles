# 幻灯片

> 来自 OpenAI 技能仓库的精选。

## 功能

使用 PptxGenJS 创建和编辑 .pptx 演示文稿。适用于销售演示文稿、启动简报和设计系统展示。

## 来源

- 上游：https://github.com/openai/skills
- 类别：`slides`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划时发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 以获取确切路径
open https://github.com/openai/skills
```

然后请代理通过名称（`slides`）或使用此技能 frontmatter 中列出的触发短语之一来调用此技能。
