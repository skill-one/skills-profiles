# flutter-animating-apps

> 由 Flutter 团队推荐。

## 功能

在 Flutter 应用中实现动画效果、过渡和运动。适用于原生 iOS/Android 运动设计。

## 来源

- 上游：https://github.com/flutter/skills
- 分类：`animation-motion`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/flutter/skills
```

然后请代理通过名称（`flutter-animating-apps`）或使用此技能的前置元数据中列出的触发短语来调用此技能。
