# ui-skills

> 由 @ibelick 精选。

## 功能

提供主观的、不断演进的约束条件，以指导代理在构建界面时进行操作。适用于保持跨多个小型 UI 组件的输出一致性。

## 来源

- 上游：https://github.com/ibelick/ui-skills
- 分类：`design-systems`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划过程中发现它。若要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活跃代理的技能目录中：

```bash
# 检查上游的 README 获取确切路径
open https://github.com/ibelick/ui-skills
```

然后通过名称（`ui-skills`）或使用本技能 frontmatter 中列出的触发短语之一来询问代理调用此技能。
