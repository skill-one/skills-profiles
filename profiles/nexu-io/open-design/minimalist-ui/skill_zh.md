# 协议：高级功利主义极简主义 UI 架构

## 1. 协议概述
名称：高级功利主义极简主义 & 编辑式 UI
描述：一个用于生成高度精致、极致极简、类似“文档式”网页界面的前端工程指令，这些界面类似于顶级工作平台。该协议严格强制执行高对比度暖色调单色板、定制化的字体层级、严谨的结构宏观空白、箱式网格布局以及极致扁平的组件架构，并带有精心设计的柔和粉彩色调点缀。它主动拒绝标准的通用 SaaS 设计趋势。

## 2. 绝对禁止约束（禁止元素）
AI 必须严格避免以下通用网页开发默认设置：
- 不得使用“Inter”、“Roboto”或“Open Sans”字体。
- 不得使用通用细线图标库，如“Lucide”、“Feather”或标准的“Heroicons”。
- 不得使用 Tailwind 的默认重阴影（例如，`shadow-md`、`shadow-lg`、`shadow-xl`）。阴影必须几乎不存在或高度定制为极扩散且低不透明度（< 0.05）。
- 不得使用主色调背景用于大型元素或区域（例如，无亮蓝色、绿色或红色英雄区域）。
- 不得使用渐变、霓虹色或 3D 玻璃效果（除导航栏轻微模糊外）。
- 不得使用 `rounded-full`（药丸形状）用于大型容器、卡片或主按钮。
- 不得在代码、标记、文本内容、标题或 alt 文本中使用表情符号。用合适的图标或干净的 SVG 基元替换。
- 不得使用通用的占位符名称，如“John Doe”、“Acme Corp”或“Lorem Ipsum”。使用真实、有上下文的内容。
- 不得使用 AI 文案陈词滥调：“提升”、“无缝”、“释放”、“下一代”、“改变游戏规则者”、“深入探索”。使用简洁、具体的语言。

## 3. 字体架构
界面必须依赖极致的字体对比和高级字体选择来建立编辑式感觉。
- 主要无衬线字体（正文、UI、按钮）：使用干净、几何形或系统原生字体，具有字符感。目标：`font-family: 'SF Pro Display', 'Geist Sans', 'Helvetica Neue', 'Switzer', sans-serif`。
- 编辑式衬线字体（英雄标题 & 引用）：目标：`font-family: 'Lyon Text', 'Newsreader', 'Playfair Display', 'Instrument Serif', serif`。应用紧密的间距（`letter-spacing: -0.02em` 至 `-0.04em`）和紧密的行高（`1.1`）。
- 等宽字体（代码、按键、元数据）：目标：`font-family: 'Geist Mono', 'SF Mono', 'JetBrains Mono', monospace`。
- 文本颜色：正文文本绝不能是绝对黑色（`#000000`）。使用浅灰/炭灰（`#111111` 或 `#2F3437`）并带有充足的 `line-height` 为 `1.6` 以确保可读性。次要文本应为柔和的灰色（`#787774`）。

## 4. 色彩板（暖色调单色 + 点状粉彩色）
色彩是一种稀缺资源，仅用于语义意义或微妙点缀。
- 画布/背景：纯白色 `#FFFFFF` 或暖色骨灰/浅白色 `#F7F6F3` / `#FBFBFA`。
- 主要表面（卡片）：`#FFFFFF` 或 `#F9F9F8`。
- 结构性边框/分隔符：极浅灰色 `#EAEAEA` 或 `rgba(0,0,0,0.06)`。
- 点缀色：仅使用高度饱和度、稀释的粉彩色用于标签、内联代码背景或微妙的图标背景。
  - 淡红色：`#FDEBEC`（文本：`#9F2F2D`）
  - 淡蓝色：`#E1F3FE`（文本：`#1F6C9F`）
  - 淡绿色：`#EDF3EC`（文本：`#346538`）
  - 淡黄色：`#FBF3DB`（文本：`#956400`）

## 5. 组件规格
- 箱式特征网格：
  - 使用不对称的 CSS Grid 布局。
  - 卡片必须具有 `border: 1px solid #EAEAEA`。
  - 边框圆角必须清晰：最大 `8px` 或 `12px`。
  - 内部填充必须充足（例如，`24px` 至 `40px`）。
- 主要行动号召（按钮）：
  - 实心背景 `#111111`，文本 `#FFFFFF`。
  - 轻微边框圆角（`4px` 至 `6px`）。无阴影。
  - 悬停状态应为微妙的颜色变化到 `#333333` 或微缩比例 `transform: scale(0.98)`。
- 标签 & 状态徽章：
  - 药丸形状（`border-radius: 9999px`），非常小的字体（`text-xs`），大写字母并带有宽间距（`letter-spacing: 0.05em`）。
  - 背景必须使用定义的柔和粉彩色。
- 折叠面板（FAQ）：
  - 去除所有容器框。仅用 `border-bottom: 1px solid #EAEAEA` 分隔项目。
  - 使用干净的、尖锐的 `+` 和 `-` 图标表示切换状态。
- 按键微 UI：
  - 使用 `<kbd>` 标签渲染快捷键为物理按键：`border: 1px solid #EAEAEA`，`border-radius: 4px`，`background: #F7F6F3`，使用等宽字体。
- 伪操作系统窗口边框：
  - 当模拟软件时，将其包裹在极简容器中，顶部栏包含三个小浅灰色圆圈（复制 macOS 窗口控制）。

## 6. 图标 & 图像指令
- 系统图标：使用“Phosphor Icons（粗体或填充权重）”或“Radix UI Icons”以获得技术感、略粗线条的审美。标准化所有图标的线条宽度。
- 插图：单色、粗糙的连续线墨水素描，在白色背景上，具有单个偏移的几何形状，填充柔和的粉彩色。
- 摄影：使用高质量、饱和度降低、暖色调的图像。应用微妙的覆盖层（`opacity: 0.04` 暖色颗粒）将照片融入单色板。绝不用过饱和的库存照片。当没有真实资源时，使用可靠的占位符 `https://picsum.photos/seed/{context}/1200/800`。
- 英雄 & 区域背景：区域不应感觉空旷和扁平。使用微妙的全宽背景图像（极低不透明度）、柔和的径向光点（`radial-gradient` 暖色调 `opacity: 0.03`）或极简的几何线图案以增加深度，而不会破坏干净的美学。

## 7. 微妙的动画 & 微动画
动画应感觉隐形——存在但从不分散注意力。目标是安静的高级感，而不是壮观。
- 滚动进入：元素在进入视口时柔和地淡入。使用 `translateY(12px)` + `opacity: 0` 在 `600ms` 内解决，使用 `cubic-bezier(0.16, 1, 0.3, 1)`。使用 `IntersectionObserver`，绝不使用 `window.addEventListener('scroll')`。
- 悬停状态：卡片轻微抬起，阴影轻微变化（`box-shadow` 从 `0 0 0` 过渡到 `0 2px 8px rgba(0,0,0,0.04)` 在 `200ms`）。按钮在 `:active` 时响应 `scale(0.98)`。
- 交错揭示：列表和网格项以级联延迟（`animation-delay: calc(var(--index) * 80ms)`）进入。绝不一次性挂载所有内容。
- 背景环境动画：可选。一个极慢移动的径向渐变气泡（`animation-duration: 20s+`，`opacity: 0.02-0.04`）在英雄区域后漂浮。必须应用于 `position: fixed; pointer-events: none` 层。绝不用在滚动容器上。
- 性能：仅通过 `transform` 和 `opacity` 动画。不使用布局触发属性（`top`、`left`、`width`、`height`）。仅在积极动画的元素上使用 `will-change: transform`。

## 8. 执行协议
当被要求编写前端代码（HTML、React、Tailwind、Vue）或设计布局时：
1. 首先建立宏观空白。使用巨大的垂直填充（例如，`py-24` 或 `py-32` 在 Tailwind）。
2. 限制主要字体内容宽度为 `max-w-4xl` 或 `max-w-5xl`。
3. 立即应用定制的字体层级和单色色彩变量。
4. 确保每张卡片、分隔符和边框严格遵循 `1px solid #EAEAEA` 规则。
5. 为所有主要内容块添加滚动进入动画。
6. 通过图像、环境渐变或微妙纹理确保区域具有视觉深度——绝不使用空白的扁平背景。
7. 提供反映这种高端、无杂乱、编辑式美学的代码，无需手动调整。
