# fal-tryon

> 由 fal.ai 社区团队精选。

## 功能

虚拟试穿 — 通过 fal.ai 的托管试穿模型查看衣物穿在人体上的效果。适用于电子商务、时尚目录和造型实验。

- 上游：https://github.com/fal-ai-community/skills
- 类别：`image-generation`

```bash

```
