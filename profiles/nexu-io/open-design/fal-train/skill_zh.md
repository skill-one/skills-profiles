# fal-train

> 由 fal.ai 社区团队整理。

## 功能

在 fal.ai 上训练自定义 AI 模型（LoRA），以生成符合品牌、角色或风格的个性化图像。

## 来源

- 上游：https://github.com/fal-ai-community/skills
- 分类：`image-generation`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划时发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/fal-ai-community/skills
```

然后请代理通过名称（`fal-train`）或使用此技能 frontmatter 中列出的触发短语来调用此技能。
