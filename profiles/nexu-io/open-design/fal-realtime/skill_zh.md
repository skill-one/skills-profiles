# fal-realtime

> 由 fal.ai 社区团队精选。

## 功能简介

通过 fal.ai 实现实时和流式 AI 图像生成。适用于情绪板探索、草稿变体和快速创意迭代。

## 来源

- 上游：https://github.com/fal-ai-community/skills
- 分类：`image-generation`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/fal-ai-community/skills
```

然后请代理通过名称（`fal-realtime`）或使用此技能 frontmatter 中列出的触发短语之一来调用此技能。
