# fal-image-edit

> 由 fal.ai 社区团队精选。

## 功能

使用 fal.ai 托管的模型进行 AI 驱动的图像编辑，包括风格迁移、背景移除、物体移除和修复。

## 来源

- 上游：https://github.com/fal-ai-community/skills
- 分类：`image-generation`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/fal-ai-community/skills
```

然后通过名称（`fal-image-edit`）或使用此技能 frontmatter 中列出的触发短语之一来询问代理调用此技能。
