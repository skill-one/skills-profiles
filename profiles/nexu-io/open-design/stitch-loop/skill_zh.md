# stitch-loop

> 由 Google Labs (Stitch) 精选。

## 功能

迭代式设计到代码的反馈循环。评论 → 调整 → 发布周期，用于提高简报和构建 UI 之间的视觉保真度。

## 来源

- 上游：https://github.com/google-labs-code/skills
- 类别：`design-systems`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。要使用完整的上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游的 README 获取确切路径
open https://github.com/google-labs-code/skills
```

然后请代理通过名称（`stitch-loop`）或使用此技能 frontmatter 中列出的触发短语之一来调用此技能。
