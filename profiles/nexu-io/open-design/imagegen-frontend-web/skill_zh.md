# 硬性输出规则 — 首先阅读

**为每个部分生成一个单独的水平图像。始终如此。没有例外。**

- 请求一个部分 -> 生成一个图像
- 请求四个部分 -> 生成四个图像
- 请求八个部分 -> 生成八个图像
- 请求十二个部分 -> 生成十二个图像
- "着陆页"且没有数量 -> 默认为六个部分 -> 生成六个图像
- "完整网站模板" -> 默认为八个部分 -> 生成八个图像

每个图像都是一个部分，作为自己的图像调用生成。永远不要将多个部分组合成一个框架。永远不要返回一个包含整个页面的单个高宽图像。

如果你只能一次渲染一个图像，请在同一响应中按顺序输出它们，一个接一个，直到每个部分都有自己的图像。宣布每一个 ("第 1 部分，共 8 部分：英雄"，"第 2 部分，共 8 部分：信任条" 等)。

此规则覆盖任何想要将输出合并为单个图像的模型默认设置。

# 英雄构图偏好 — 首先阅读

默认的 **左文本 / 右图像英雄是使用最广泛的 AI 模式**。它是允许的，但不应将其作为你的首选。

- 中心堆叠
- 图像作为画布
- 离网格编辑
- 迷你极简主义
- 右文本 / 左图像（反转经典）

仅在它是真正最佳选择时才使用左文本 / 右图像，而不是默认设置。

  `(1 = 主要为排版，10 = 强烈以图像为主导)`

  `(1 = 相同锚点重复，10 = 跨部分大胆构图变化)`

  `(1 = 纯粹艺术情绪板，10 = 清晰的漏斗 + 高端设计平衡)`

将这些用作全局默认值，除非用户明确要求其他内容。
不要要求用户编辑此文件。
根据提示动态调整这些值。

解释：
- **适应优先级**：用户的简报始终覆盖默认值。仔细阅读提示，然后调整旋钮、英雄比例、背景模式、渐变使用和构图变化以匹配——永远不要强迫与简报相矛盾的配方。
- 如果用户说 "干净"，请减少密度并增加清晰度。
- 如果用户说 "疯狂创意"，请增加差异化和艺术方向。

如果简报对风格保持沉默：
- 使用 §1 + §2 的默认值，并自信地选择背景多样性
- 坚定地选择一个英雄比例，不要折中

如果简报要求克制，则不要使用背景、渐变或全出血处理。如果简报要求氛围，则不要删除它们。

- 平滑手风琴扩展能量

### 构图锚点（每个部分）
**左文本 / 右图像** 布局是允许的，但它是使用最广泛的 AI 模式——不要将其作为默认值。只有在它是真正最佳匹配时才使用它。

选择适合每个部分的 CTA 风格，而不是每次都使用默认的药丸：
- 经典主要药丸
- 轮廓 / 精灵

### 英雄比例（每页）
选择 1——必须与品牌情绪匹配：
- 巨型声明英雄（巨大的文本，大型图像，主导第一个视口）
- 中等编辑英雄（平衡的文本/图像，电影感但不是填满屏幕）
- 迷你极简主义英雄（微小的标志 + 短声明 + 细 CTA，几乎无图像，大量负空间）

迷你并不意味着弱——它意味着自信的克制。

### 叙事 / 概念脊柱
选择 1 并让它贯穿整个页面的视觉和简短副本。
- 艺品 / 收藏品——证据，样本，珍贵的物体框架
- 旅程 / 朝圣——方向性流，路标部分，路线感
- 工具 / 精密仪器——机械细节，校准 UI，触觉控制
- 活系统 / 花园——有机生长隐喻，分支布局，培养语气
- 舞台 / 聚光灯——戏剧性对比，表演者 + 观众框架
- 档案 / 案卷——索引行，标题，低调的权威

### 第二次阅读时刻
选择正好 1 个不明显但可读的主题，并有意放置一次，跨页面：
- 不对称出血，但仍然尊重层次结构
- 一个过大的标点符号或数字，用于结构
- 一个单一意外的材料切换（纸张 vs 光泽 vs 金属强调）
- 一个窄垂直侧轨编辑笔记样式
- 一个宏观裁剪，自然地携带品牌颜色

避免小技巧：这个时刻必须有助于扫描顺序或品牌回忆。

重要：
- 这些不是编码指令。
- 它们是生成的设计应暗示的视觉方向提示。

## 4. 英雄极简主义规则
英雄必须感觉电影感、清晰和有意。

**左文本 / 右图像英雄是最常用的 AI 英雄模式**。它是允许的，但不应将其作为默认的起始点。

优先选择以下之一，除非左文本 / 右图像是真正最佳匹配：

- 图像作为画布，文本在干净安全区域覆盖

- 迷你极简主义英雄（微小的标志 + 短声明 + 细 CTA，几乎无图像，大量负空间）

### 输出前检查
在渲染英雄图像之前，问自己："我是否出于习惯草拟了默认的文本左 / 图像右布局？" 如果是，请从上面的列表中选择一个不同的锚点，除非简报或品牌确实需要经典。

### 绝对英雄规则
- 英雄必须感觉像强烈的开场场景
- 保持英雄构图干净
- 不要过度拥挤第一个视口
- 主标题必须感觉简短有力
- 标题通常应该读起来像 5-10 个强有力的单词，而不是段落
- 保持支持文本简洁
- 优先考虑负空间和对比度
- 避免在英雄中塞满药丸、虚假统计数据、徽章、微小的标志和无意义的细节

### 标题规则
H1 应该在视觉上读起来像高端声明。
不要让它感觉长、弱或过于包装。

### 排版执行
优先选择：
- 中等 / 正常 / 轻柔的优雅
- 紧凑的跟踪
- 控制行数
- 强大的比例对比

避免：
- 随机额外的粗体喊叫
- 渐变文本作为懒惰的高端效果
- 6 行创业标题
- 看起来像生成的文本处理

### 图形克制
不要默认为：
- 巨大的无意义轮廓数字
- 便宜的 SVG 看起来填充图形
- 通用 AI 块
- 随机球体杂乱

使用：
- 排版
- 图像裁剪
- 真实的布局张力
- 高端材料
- 强大的框架

## 5. 图像数量 & 页面切片

### 这是主要的输出规则
为每个部分生成 **一个单独的水平图像**。始终如此。

- 永远不要将多个部分组合在一个图像中
- 永远不要返回一个包含整个页面的单个高宽图像
- 永远不要返回一个 "最佳" 图像并跳过其余部分
- 永远不要用几个部分替换几个部分
- 如果请求对部分数量不明确，**默认为高**：
- "英雄" -> 1 图像
- "着陆页" / "网站模板" -> 默认为 6 个部分 -> 6 图像
- "完整网站" -> 默认为 8 个部分 -> 8 图像
- "营销网站" -> 默认为 8 个部分 -> 8 图像
- "产品页面" -> 默认为 6 个部分 -> 6 图像
- "作品集" -> 默认为 6 个部分 -> 6 图像

如果模型一次只能渲染一个图像，请在同一响应中按顺序生成它们，一个接一个，标记为 "第 X 部分，共 N 部分：<名称>"，直到完整集交付。不要提前停止。不要总结。不要只返回一个图像。

### 格式
- 始终水平（16:9, 16:10 或 21:9 取决于密度）
- 每个图像以高保真度渲染一个聚焦的部分
- 英雄通常为 16:9 或 21:9；较窄的内容部分可以是 16:10

### 计数规则
- 1 部分 -> 1 水平图像
- 4 部分 -> 4 水平图像
- 8 部分 -> 8 水平图像
- 12 部分 -> 12 水平图像

不要将多个部分合并为一个高宽切片。部分大小和密度可能仍然变化，但画布保持水平，**每个部分一个框架**。

### 部分大小多样性
跨整个网站，故意混合部分节奏：
- 一些部分很大，内容丰富，艺术指导
- 一些部分很小，极简主义，几乎无图像，大量负空间
- 一些部分是中等编辑性块

这创造了高端滚动景观，而不是统一的板块。

### 连续性规则
跨所有每个部分图像，强制执行一个品牌世界：
- 相同调色板和强调逻辑
- 相同排版家族和比例
- 相同 CTA 家族（风格变化是允许的，身份不是）
- 相同边框半径语言
- 相同图像处理（颜色等级，材料，框架）
- 任何短副本中的相同色调语气

滚动浏览所有框架的观众必须将它们读作一个网站。

## 6. 创意升级规则
设计必须显示真正的创意雄心。

不要满足于第一个明显的布局解决方案。
将工作推向超出通用的 SaaS 模式。

积极增加至少 3 项：
- 更强的构图
- 更独特的排版
- 更自信的比例对比
- 更难忘的英雄概念
- 更有趣的图像处理
- 更富有表现力的部分节奏
- 更原创的框架 / 裁剪
- 更艺术指导的视觉张力
- 更令人惊讶但清晰布局结构

创意必须感觉有意，而不是混乱。

做：
- 做大胆但受控的设计决策
- 在它改善页面时使用不对称性
- 创建感觉高端且难忘的视觉时刻
- 使页面感觉设计，而不是自动生成

不要：
- 默认安全的模板布局
- 过于频繁地重复相同的块结构
- 混淆创意与杂乱无章
- 使页面过于密集

## 11. 组件执行指南

### 斜向错开的方形马赛克
使用方形图像或内容块，具有强烈的垂直节奏。
应感觉经过策划和图形化，而不是杂乱无章。

### 3D 瀑布卡片堆栈
卡片分层为物理堆栈，具有深度逻辑。
应感觉高端且触觉，而不是花哨。

### 悬停手风琴切片布局
一行压缩的视觉切片，感觉可以展开。
在静态图像中，通过比例和强调清晰地暗示交互。

### 纯净无缝 bento 网格
数学上干净的网格。
没有意外的间隙。
混合大型视觉块与较小的密集信息面板。

### 旋转宝丽来弧
成簇旋转的图像，具有优雅的构图。
应感觉风格化且有意，而不是剪贴簿随机。

### 离网格编辑布局
使用不对称性和张力，控制使用。
必须保持可读性和清晰的结构。

### 产品 UI 面板堆栈
分层 UI 屏幕或界面裁剪，暗示产品故事。
避免通用的虚假仪表板。

### 垂直韵律线
使用细线和平铺系统来加强顺序和优雅。
永远不要让它们成为装饰性杂乱。

## 12. 密度 & 间距纪律
不要使所有内容都过于密集。

页面应该呼吸。
在部分之间留出比默认 AI 生成的设计稍微更多的空白空间。

规则：
- 使用比默认 AI 生成的更均匀的垂直间距。
- 保持主要部分之间的间距一致，除非有强烈的设计原因不这样做。
- 避免一个部分感觉非常拥挤，而下一个部分感觉太空旷。
- 偏好干净的、平衡的节奏。
- 允许负空间创建节奏和强调。
- 用较平静的部分分隔较密集的部分。
- 避免堆叠太多卡片、标签和内容块过于紧密。
- 较小的部分仍然应获得足够的周围空间，使页面感觉整洁且有意。

一个高端页面应该感觉：
- 开放
- 组合
- 平衡
- 自信
- 呼吸空间

不是：
- 拥挤
- 嘈杂
- 不平衡
- 过度填充
- 视觉上筋疲力尽

部分节奏应该在控制下交替：
- 一些部分可以包含更多内容
- 一些部分可以更小，更平静
- 但整体间距节奏仍然应该感觉均匀、干净且有意

空白空间是设计工具。
故意使用它。
不要让间距变得随机。

## 13. 颜色 & 材料规则

### 调色板纪律
在整个网站中使用一个受控的调色板：
- 1 主要（品牌锚点）
- 1 次要（支持色调）
- 1 强调（用于 CTA / 高亮，使用频率低）
- 一个中性等级（背景，表面，文本，发丝线）

部分级别的情绪变化必须重用相同的调色板——每个部分都没有完整的主题切换。

### 背景图像和谐
当使用全出血图像背景时：
- 图像必须色调匹配调色板（不要与之冲突）
- 使用叠加（深色，浅色或颜色色调）以保持文本完全可读
- 品牌强调始终保持一致，无论背景图像如何

### 渐变纪律
渐变是 **允许的，并且鼓励** 当专业且微妙时。它们与 AI 糊涂的渐变不同。

允许（自信地使用）：
- 低色度调色板匹配的色调渐变（例如，墨水到石墨，奶油色到沙子，象牙色到温暖灰色）
- 单色调大气渐变作为英雄摄影的背景
- 柔和的暗角和径向深度，引导视线
- 带有纹理的渐变，添加触觉深度，没有颜色噪声
- 编辑性颜色洗涤，匹配品牌情绪

禁止（AI 渐变糊涂）：
- 彩虹 / 网格块渐变
- 紫色到蓝色的 "AI" 默认
- 粉色到橙色的 "创作者" 默认
- 荧光边缘和光晕光环，没有目的
- 渐变文本作为 "高端" 的快捷方式
- 渐变与图像竞争而不是支持它

### 背景自信规则
不要默认退回到纯白色表面。当简报、品牌情绪或部分工作要求氛围时，使用：
- 全出血图像
- 双色调或分级照片
- 色调渐变
- 触觉材料
- 自信的平面色块——选择是故意的，而不是装饰

### 强指导
- 避免彩虹随机性
- 避免过度霓虹灯，除非要求
- 保持对比有意
- 将强调色匹配所选主题范式
- 渐变必须始终读起来专业且有意，永远不会是视觉噪声

### 材料性
在适当的地方添加：
- 纸张感
- 玻璃感
- 刷涂金属感
- 软模糊深度
- 触觉哑光表面
- 编辑性照片处理

但始终保持前端结构可读。

## 18. 额外创意 & 实施边缘

应用，除非用户选择退出：

### 跨部分对比
跨切片，故意变化前景/背景强度至少两次（浅色 → 丰富 → 平静）所以滚动感觉有节奏，而不是单调的板块。

### CTA 具体性
偏好每个主要视口层级的一个不可忽视的主要操作；次要操作必须看起来次要（比例，轮廓，幽灵），而不是主要操作的克隆。

### 图像内部多样性
在一个组件内混合至少 **两个不同的图像裁剪**，例如宏产品 + 上下文环境，或肖像编辑性 + 宽屏艺术品——避免重复的库存剪影。

### 数据 / KPI 糊涂
除非用户要求，否则不要出现三个相同的统计数据列（99% 满意度，$10 节省，∞ 比例）除非用户要求 KPI
- 虚假仪表板带有无用的图表阴影，遮蔽实际布局

### 文化 / 色调对齐
当简报命名行业或地区时，引导调色板和排版气质以匹配——不要发送默认的 "中性 SF 创业公司" 除非简报故意是通用的 SaaS。

### 暗示移动的保真度（即使对于桌面模拟而言）
保持适合触摸的击中大小和可读的标题大小；堆叠顺序应暗示一个合理的单列叙事。

### 转换焦点
每个部分都有一个工作。即使设计是艺术性的，页面也必须像真实的品牌或产品网站一样具有逻辑：
- 英雄在几秒钟内传达价值，并提供一个明显的下一步操作
- 证据部分（徽标，引言，指标）感觉值得，而不是填充
- 定价或 CTA 部分感觉果断，而不是隐藏
- 最后部分关闭：单个强大的 CTA + 支持性信任提示
避免纯情绪滚动条，没有漏斗逻辑。

### 构图多样性检查
跨所有每个部分图像，内部记录选择的构图锚点和背景模式。如果锚点或背景模式重复使用超过 2 次部分，则拒绝该集：
- 锚点重复使用超过 2 个部分
- 背景模式重复使用超过 3 个部分
- 每个部分都是内联资源（全出血背景从未出现）**并且**简报不要求极简主义 / 仅排版 / 瑞士 / 超简单

对于非极简主义简报：推动至少一个全出血（或双色调 / 氛围）背景和至少一个迷你极简主义部分在任何多部分网站中。

对于极简主义简报：此规则被暂停。克制是设计。

## 19. 响应行为
当用户请求前端设计时：
1. 推断网站类型和主要转换目标
2. 推断部分数量（如果不清楚，使用 §5 的默认值：着陆页 = 6，完整网站 = 8）
3. **大声宣布** 对部分数量的承诺，并宣布 ("生成 N 个水平图像，每个部分一个")。
4. 计划每个水平图像，始终单独生成，永远不要合并
5. 为整个网站选择英雄比例（巨型 / 中等 / 迷你）
6. 选择一个强大的视觉组合（主题，类型，英雄架构，部分系统，运动，叙事脊柱，第二次阅读时刻）
7. 对于每个部分：选择构图锚点，背景模式，CTA 变化——跨部分变化
8. 选择 4 个签名组件，在部分中适当使用
9. 执行英雄极简主义 + 部分大小多样性（一些巨型，一些迷你）
10. 执行强烈的图像使用，包括允许的 **全出血背景**，而不仅仅是内联资源，**当简报允许时**。
11. 变化构图：不要默认为 "文本左，图像右"。跨部分将文本移动到底左、中心、右上等。
12. 保持部分呼吸空间。不要过度填充页面。
13. 偏好比默认值稍微更多的空白空间。
14. 保持转换意识：每个部分都有一个工作（钩子 / 证据 / 教育 / 转换）。

应用 §18 额外创意 & 实施边缘
15. 保持间距慷慨，均匀，干净
16. 移除 AI 拙劣（包括滚动条 / 虚假 KPI 陈词滥调）除非要求
17. 运行 §17 清晰度检查
18. **生成每个部分的水平图像，标记为 "第 X 部分，共 N 部分：<名称>"，** 直到完整集交付。不要提前停止。不要总结。不要只返回一个图像。

如果可以，不要提出不必要的后续问题。如果可以强烈解释，则不要提出。

## 20. 示例解释

### 示例 1
用户："为 AI 创业公司制作一个英雄部分"

解释：
- 1 水平图像
- 英雄比例：中等编辑或巨型声明
- 构图锚点：底部左文本覆盖全出血产品/氛围图像
- 背景模式：全出血图像，带有色调叠加（文本保持高度可读）
- CTA 变化：轮廓内联 + 小标签提示
- 调色板：深色或大胆工作室固体，一个一致的强调色
- 不允许 cliche 仪表板垃圾，不使用紫色 AI 发光

### 示例 2
用户："为金融科技网站设计 8 个部分"

解释：
- 8 个单独的水平图像（每个部分一个）
- 英雄比例：中等编辑（信任驱动）
- 跨部分变化构图锚点（中心低，右三分之一标题，底部右 CTA 集群，堆叠中心）
- 背景模式：纯色 + 内联资源，平面块 + 细节裁剪，偶尔编辑侧图像
- 一个一致的调色板（例如，墨水 + 纸张 + 一个品牌强调色）
- 转换路径：钩子 -> 证据条 -> 功能 -> 用例 -> 证言 -> 定价 -> FAQ -> CTA

### 示例  - 3
用户："创意代理机构的着陆页，12 部分"

解释：
- 12 水平图像（每个部分一个）
- 英雄比例：巨型声明或迷你极简主义（果断选择，不是折中）
- 编辑性 / 海报样式方向；离网格构图出现 2-3 次
- 多种背景模式（英雄 + 展示中全出血图像，案例研究中编辑侧图像，纯色 + 强调）
- 调色板一致，一个大胆的强调色重复出现
- 关闭 CTA 部分：迷你极简主义，强排版，单个主要操作

## 21. 最终目标
生成前端参考图像，这些图像应感觉：
- 艺术
- 高端
- 清晰
- 结构化
- 图像主导
- 呼吸空间
- 难忘
- 反对通用
- 实施友好

结果应看起来像顶级网站概念，具有强大的图像、自信的创意和充足的空白空间，而不是密集、重复的 AI 布局。
