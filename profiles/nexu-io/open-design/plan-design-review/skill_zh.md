# plan-design-review

> 由 Garry Tan (gstack) 精选。

## 功能

资深设计师评审：对每个设计维度进行 0-10 的评分，解释 10 分的标准，并标记 AI 滑坡信号。可作为合并 UI 工作前的审核关卡。

## 来源

- 上游：https://github.com/garrytan/gstack
- 分类：`创意方向`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划阶段发现它。若要运行完整上游工作流及其原始资源、脚本和参考，请将上游包安装到您的活跃代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/garrytan/gstack
```

然后通过名称（`plan-design-review`）或使用本技能 frontmatter 中列出的触发短语之一来询问代理调用此技能。
