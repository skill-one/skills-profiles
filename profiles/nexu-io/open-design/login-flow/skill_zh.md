# 登录流程技能

用于生成移动端优先的登录和认证界面的技能。当用户需要移动应用的登录体验时使用，包括电话+短信验证、基于密码的登录以及社交SSO选项。

## 工作流程

1. **先阅读参考文件**（见下文）
2. **明确认证方法**：电话/SMS、密码或社交SSO
3. **检查清单门禁** — 在发出`<artifact>`前验证P0项
4. **构建HTML原型**，包含正确的状态（默认、加载中、错误）
5. **用`<artifact>`标签包裹**，引用输出文件

## 侧文件

- `references/checklist.md` — P0/P1验收标准

## 输出

一个实现登录界面的单一独立HTML文件，包含：
- 输入框上方的标签（绝不只有占位符）
- 带显示/隐藏切换的密码字段
- 带SVG图标的社交SSO按钮
- 字段下方的错误状态
- 主要CTA中的加载动画
- 触摸目标最小44px

## 移动端优先约束

- 视口：375px宽（iPhone标准）
- 无水平滚动
- 凹口设备的安全区域偏移
- 输入键盘：电话字段使用`tel`，密码字段使用`password`
