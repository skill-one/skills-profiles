# figma-create-design-system-rules

> 从 Figma 的 MCP 服务器指南中精选。

## 功能

为 Figma 到代码的工作流程生成项目特定的设计系统规则。可用于在一个源中捕获 token、命名和 lint 规则。

## 来源

- 上游：https://github.com/figma/skills
- 类别：`figma`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/figma/skills
```

然后请代理通过名称（`figma-create-design-system-rules`）或使用此技能 frontmatter 中列出的触发短语之一来调用此技能。
