# 创意总监

> 由 @smixs 筛选整理。

## 功能概述

具有递归自我评估功能的AI创意总监：包含20多种方法论（SIT、TRIZ、联想、SCAMPER、Synectics），3轴评估体系参照戛纳/D&AD/HumanKind进行校准，从简报到展示的5阶段流程。

## OpenDesign编排模式

当此技能在OpenDesign中调用时，将其视为设计流程总监，而非单一的精修清单。

1. 在更改像素之前，定义“美观”的含义：受众、产品目标、品牌立场、风格参考、信息密度、字体、调色板、动态基调、资源需求，以及明确的反模式，例如通用AI渐变、空白卡片、模糊文案和模板对称性。
2. 检查当前目标：HTML/页面元素、浏览器标签、设计文件、活动设计系统、附加图像或项目文件夹。
3. 搜索所有可用的OpenDesign资源，而不仅限于此技能：技能、插件、MCP服务器和模板、连接的连接器、设计文件、活动浏览器/上下文以及用户提供的资源。
4. 将资源匹配到分阶段的流程中。典型的通道包括评论、风格方向选择、视觉资产生成、动态效果、数据/证据基础、实施精修、响应式/无障碍加固和最终验证。
5. 当设计目标或美学标准不明确时，呈现一个小型的引导式UI风格选择集或表单，并附带推荐默认值。在做出选择后继续流程，而不是在通用问题处停止。
6. 如果最佳资源尚未配置，解释其必要性并指导设置；否则使用最近的配置替代方案并标记权衡。

## 使用方法

此目录条目在OpenDesign中宣传该技能，以便代理在规划期间发现它。要运行完整的上游工作流及其原始资产、脚本和参考，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游README以获取确切路径
open https://github.com/smixs/creative-director-skill
```

然后要求代理通过名称（`creative-director`）或使用此技能的前置部分列出的触发短语来调用此技能。
