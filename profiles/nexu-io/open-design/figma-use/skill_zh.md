# figma-use

> 来自 Figma MCP 服务器指南的精选内容。

## 功能

运行 Figma 插件 API 脚本，用于画布写入、检查、变量和设计系统工作。本目录中所有其他 Figma 技能的先决条件。

## 来源

- 上游：https://github.com/figma/skills
- 分类：`figma`

## 如何使用

本目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。要使用完整的上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/figma/skills
```

然后请代理通过名称（`figma-use`）或使用本技能 frontmatter 中列出的触发短语来调用此技能。
