# remotion

> 由 Remotion 团队整理。

## 功能

使用 React 进行程序化视频创建。适用于品牌解说视频、社交剪辑、仪表盘转视频以及可重复的运动图形。

## 来源

- 上游：https://github.com/remotion-dev/remotion
- 类别：`video-generation`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 以获取确切路径
open https://github.com/remotion-dev/remotion
```

然后请代理通过名称（`remotion`）或使用此技能 frontmatter 中列出的触发短语之一来调用此技能。
