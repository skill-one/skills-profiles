# wpds

> 由 WordPress 开发团队整理提供。

## 功能

WordPress 设计系统。将 WordPress 官方的设计令牌、排版和组件模式应用于主题和站点。

## 来源

- 上游：https://github.com/WordPress/skills
- 分类：`design-systems`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划过程中发现它。若要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活跃代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/WordPress/skills
```

然后请代理通过名称（`wpds`）或使用本技能 frontmatter 中列出的触发短语之一来调用此技能。
