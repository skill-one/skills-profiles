# design-md

> 由 Google Labs (Stitch) 精选。

## 功能

创建和管理 DESIGN.md 文件。可用于在一个单一的真实来源中捕获设计方向、符号和视觉规则。

## 来源

- 上游：https://github.com/google-labs-code/skills
- 类别：`design-systems`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。若要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/google-labs-code/skills
```

然后请代理通过名称（`design-md`）或使用本技能 frontmatter 中列出的触发短语来调用此技能。
