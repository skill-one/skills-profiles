# 手绘图表

> 由 @muthuishere 精选。

## 功能

根据提示生成手绘风格的 Excalidraw 图表 — 动画 SVG、托管编辑链接和 PNG 导出。支持 Claude Code、Codex、Gemini CLI 以及任何支持标准技能路径的代理。

## 来源

- 上游：https://github.com/muthuishere/hand-drawn-diagrams
- 分类：`diagrams`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划时发现它。若要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/muthuishere/hand-drawn-diagrams
```

然后通过名称（`hand-drawn-diagrams`）或使用本技能 frontmatter 中列出的触发短语之一来询问代理调用此技能。
