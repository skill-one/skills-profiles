# frontend-slides

> 由 @zarazhangrui 精选。

## 功能

生成带有动画效果的 HTML 演示文稿，并提供视觉风格预览。适用于在线主题演讲、嵌入式演讲和交互式简报。

## 来源

- 上游：https://github.com/zarazhangrui/frontend-slides
- 类别：`slides`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划过程中发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/zarazhangrui/frontend-slides
```

然后请代理通过名称（`frontend-slides`）或使用此技能 frontmatter 中列出的触发短语之一来调用此技能。
