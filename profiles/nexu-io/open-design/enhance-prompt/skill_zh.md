# enhance-prompt

> 由 Google Labs (Stitch) 精选。

## 功能

使用设计规范和 UI/UX 词汇来优化提示。适用于设计到代码的工作流程，并澄清对视觉输出的请求。

## 来源

- 上游：https://github.com/google-labs-code/skills
- 类别：`design-systems`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。若要运行完整上游工作流程及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/google-labs-code/skills
```

然后通过名称（`enhance-prompt`）或使用此技能 frontmatter 中列出的触发短语之一来询问代理调用此技能。
