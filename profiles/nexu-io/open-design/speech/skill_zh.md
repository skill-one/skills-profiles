# 语音

> 来自 OpenAI 技能库的精选。

## 功能

使用 OpenAI 的 API 和内置语音将文本转换为语音。适用于旁白解释、讲座音频和快速配音轨道。

## 来源

- 上游：https://github.com/openai/skills
- 类别：`audio-music`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 以获取确切路径
open https://github.com/openai/skills
```

然后请代理通过名称（`speech`）或使用此技能 frontmatter 中列出的触发短语来调用此技能。
