# figma-implement-design

> 来自 Figma MCP 服务器指南的精选。

## 功能

将 Figma 设计转换为可生产的代码，保持 1:1 的视觉保真度。适用于将 Figma 帧直接交接给前端开发人员。

## 来源

- 上游：https://github.com/figma/skills
- 分类：`figma`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。若要使用完整的上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活跃代理的技能目录中：

```bash
# 检查上游的 README 获取确切路径
open https://github.com/figma/skills
```

然后通过名称（`figma-implement-design`）或使用本技能 frontmatter 中列出的触发短语，要求代理调用此技能。
