# gif-sticker-maker

> 由 MiniMax AI 团队整理推荐。

## 功能简介

通过 MiniMax API 将照片转换为 Funko Pop / Pop Mart 风格的动态 GIF 贴纸。适用于个性化聊天贴纸和头像包。
