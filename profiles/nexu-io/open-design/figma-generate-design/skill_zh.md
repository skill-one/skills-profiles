# figma-generate-design

> 来自 Figma 的 MCP 服务器指南的精选。

## 它的作用

使用设计系统组件从代码或描述构建或更新 Figma 中的屏幕。使用设计令牌将应用页面转换为 Figma。

## 来源

- 上游：https://github.com/figma/skills
- 类别：`figma`

## 如何使用

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划期间发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 以获取确切路径
open https://github.com/figma/skills
```

然后请代理通过名称（`figma-generate-design`）或使用此技能 frontmatter 中列出的触发短语之一来调用此技能。
