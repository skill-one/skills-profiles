# shader-dev

> 由 MiniMax AI 团队整理。

## 功能

用于光线步进、流体模拟、粒子系统和程序化生成的 GLSL 着色器技术。适用于英雄视觉效果和动态静止画面。

## 来源

- 上游：https://github.com/MiniMax-AI/skills
- 分类：`3d-shaders`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划过程中发现它。要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/MiniMax-AI/skills
```

然后请代理通过名称（`shader-dev`）或使用本技能 frontmatter 中列出的触发短语来调用此技能。
