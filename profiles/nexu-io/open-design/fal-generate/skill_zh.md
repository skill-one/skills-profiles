# fal-generate

> 由 fal.ai 社区团队整理。

## 功能

使用 fal.ai AI 模型生成图像和视频。生产级目录涵盖 Flux、SDXL、ideogram 以及其他社区提供的端点。

## 来源

- 上游：https://github.com/fal-ai-community/skills
- 分类：`image-generation`

## 使用方法

此目录条目在 OpenDesign 中宣传该技能，以便代理在规划时发现它。若要运行完整上游工作流及其原始资源、脚本和引用，请将上游包安装到您的活动代理的技能目录中：

```bash
# 检查上游 README 获取确切路径
open https://github.com/fal-ai-community/skills
```

然后通过名称（`fal-generate`）或使用此技能 frontmatter 中列出的触发短语，要求代理调用此技能。
