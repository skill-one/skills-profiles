# PARA 内存文件

基于 Tiago Forte 的 PARA 方法的持久化、基于文件的内存组织。分为三个层级：知识图谱、日常笔记和隐性知识。所有路径相对于 `$AGENT_HOME`。

## 三个内存层级

### 层级 1：知识图谱 (`$AGENT_HOME/life/` -- PARA)

基于实体的存储。每个实体获得一个包含两个层级的文件夹：

1. `summary.md` -- 快速上下文，优先加载。
2. `items.yaml` -- 原子事实，按需加载。

```text
$AGENT_HOME/life/
  projects/          # 有明确目标/截止日期的活跃工作
    <name>/
      summary.md
      items.yaml
  areas/             # 持续的责任，无截止日期
    people/<name>/
    companies/<name>/
  resources/         # 参考材料、感兴趣的主题
    <topic>/
  archives/          # 其他三个类别中的非活动项
  index.md
```

**PARA 规则：**

- **项目** -- 有目标或截止日期的活跃工作。完成后移至存档。
- **领域** -- 持续的（人、公司、责任）。无截止日期。
- **资源** -- 参考材料、感兴趣的主题。
- **存档** -- 任何类别的非活动项。

**事实规则：**

- 立即将持久事实保存到 `items.yaml`。
- 每周：从活跃事实中重写 `summary.md`。
- 永不删除事实。用替代代替（`status: superseded`，添加 `superseded_by`）。
- 当一个实体变为非活动时，将其文件夹移至 `$AGENT_HOME/life/archives/`。

**何时创建实体：**

- 提及 3 次以上，或
- 与用户直接相关（家人、同事、伴侣、客户），或
- 用户生活中的重要项目或公司。
- 否则，在日常笔记中记录。

关于原子事实 YAML 模式和内存衰减规则，请参阅 [references/schemas.md](references/schemas.md)。

### 层级 2：日常笔记 (`$AGENT_HOME/memory/YYYY-MM-DD.md`)

事件的时间线记录 -- “何时”层级。

- 在对话期间持续记录。
- 在心跳期间将持久事实提取到层级 1。

### 层级 3：隐性知识 (`$AGENT_HOME/MEMORY.md`)

用户如何操作 -- 模式、偏好、学到的教训。

- 不是关于世界的事实；是关于用户的事实。
- 每次学习新的操作模式时更新。

## 记录下来 -- 不要记在脑中

内存不会在会话重启后存活。文件会。

- 想记住某事 -> 写到文件中。
- “记住这个” -> 更新 `$AGENT_HOME/memory/YYYY-MM-DD.md` 或相关实体文件。
- 学到教训 -> 更新 AGENTS.md、TOOLS.md 或相关技能文件。
- 犯错 -> 记录下来，以免未来的你重复犯错。
- 磁盘上的文本文件总是比在临时上下文中保留要好。

## 内存检索 -- 使用 qmd

使用 `qmd` 而不是文件搜索：

```bash
qmd query "圣诞节发生了什么"   # 带重新排序的语义搜索
qmd search "特定短语"              # BM25 关键词搜索
qmd vsearch "概念性问题"         # 纯向量相似度
```

索引你的个人文件夹：`qmd index $AGENT_HOME`

向量 + BM25 + 重新排序即使措辞不同也能找到内容。

## 规划

在项目根目录下的 `plans/` 中的时间戳文件中保存计划（在个人记忆之外，以便其他代理可以访问它们）。使用 `qmd` 搜索计划。计划会过时 -- 如果存在更新的计划，不要被旧版本混淆。如果你注意到过时，请更新文件以注明它被什么替代了。
