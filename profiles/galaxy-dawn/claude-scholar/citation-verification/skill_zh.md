# 引文验证参考指南

一份用于学术论文写作中引文验证的参考指南，提供验证原则和最佳实践。

**核心原则**：在写作过程中，应使用程序化或规范化的学术来源（如arXiv、DOI/CrossRef、Semantic Scholar、出版社首页和Zotero元数据）主动验证每一处引文。谷歌学术可用于手动发现，但它不是规范化的验证权威。

## 核心问题

学术论文中的引文问题严重影响研究诚信：

1. **虚假引文** - 引用不存在的论文（AI生成引文常见问题）
2. **信息错误** - 作者、标题、年份等信息不匹配
3. **格式不一致** - 混合引文格式
4. **缺失引文** - 已参考但未标注的文献

这些问题可能导致：
- 论文被拒或撤回
- 损害学术声誉
- 审稿人质疑研究严谨性

**AI辅助写作的特殊风险**：AI生成的引文错误率约为40%；必须通过WebSearch进行验证。

## 验证原则

本技能基于规范化的学术元数据和声明级检查提供验证原则：

### 1. 主动验证（写作时验证）

**核心思想**：添加引文时立即验证，而不是写完后再检查。

- 每次需要引文时通过WebSearch搜索论文
- 在谷歌学术上确认论文存在
- 验证通过后才能添加到参考文献列表

### 2. 规范化元数据验证

首选权威顺序：
1. DOI / 出版社首页
2. arXiv ID或arXiv首页
3. CrossRef
4. Semantic Scholar
5. 从已验证标识符导入的Zotero元数据
6. 仅用于手动发现或备查的谷歌学术

**验证步骤**：
1. 找到DOI、arXiv ID、出版社URL或已验证的Zotero条目。
2. 确认标题、第一作者、年份、发表场所和标识符。
3. 在可能的情况下从CrossRef、arXiv、出版社元数据、Zotero或其他程序化来源获取BibTeX。
4. 如果只能通过谷歌学术找到条目，标记为手动验证，直到在其他地方检查元数据后才将BibTeX视为最终结果。

### 3. 信息匹配验证

**必须匹配的信息**：
- 标题（允许轻微差异，如大小写）
- 作者（至少第一作者必须匹配）
- 年份（允许±1年差异，考虑预印本）
- 发表场所（会议/期刊名称）

### 4. 声明验证

**关键原则**：引用具体声明时，必须确认声明确实出现在论文中。

- 使用WebSearch访问论文PDF
- 搜索相关关键词
- 确认声明准确性
- 记录声明出现的章节/页码

## 验证工作流

### 写作流程集成

```
写作时需要引文
    ↓
找到DOI / arXiv ID / 出版社页面 / 已验证Zotero条目
    ↓
使用CrossRef / arXiv / Semantic Scholar / 出版社 / Zotero验证元数据
    ↓
确认论文详情
    ↓
获取BibTeX
    ↓
（如果引用具体声明）验证声明
    ↓
添加到参考文献列表
```

**要点**：验证是写作过程的一部分，而不是独立的后处理步骤。

## 使用指南

### 与ml-paper-writing配合使用

本技能的验证原则已集成到`ml-paper-writing`技能的引文工作流中。

**自动触发**：使用ml-paper-writing技能写作论文时，引文验证将自动执行。

**手动参考**：当需要详细验证原则时，请参考本技能。

### 验证步骤示例

**场景**：需要引用Transformer论文

```
步骤1：WebSearch查找
查询："Attention is All You Need Vaswani 2017"
结果：找到该论文的多个来源

步骤2：谷歌学术验证
查询："site:scholar.google.com Attention is All You Need Vaswani"
结果：✅ 论文存在，50,000+引用，NeurIPS 2017

步骤3：确认详情
- 标题："Attention is All You Need"
- 作者：Vaswani, Ashish; Shazeer, Noam; Parmar, Niki; ...
- 年份：2017
- 场所：NeurIPS (NIPS)

步骤4：获取BibTeX
- 在谷歌学术上点击"Cite"
- 选择BibTeX格式
- 复制BibTeX条目

步骤5：添加到参考文献列表
- 粘贴到.bib文件
- 在论文中使用\cite{vaswani2017attention}
```

### 处理验证失败

**如果无法通过规范化来源验证论文**：

1. **检查拼写** - 标题或作者名是否正确？
2. **尝试不同查询** - 使用不同的关键词组合
3. **寻找替代来源** - 尝试arXiv、DOI、CrossRef、Semantic Scholar、出版社页面或Zotero
4. **标记为待验证** - 使用[CITATION NEEDED]标记
5. **通知用户** - 明确说明无法验证的引文

**如果信息不匹配**：

1. **确认来源** - 是否找到了正确的论文？
2. **检查版本** - 预印本与已发表版本
3. **更新信息** - 使用最准确版本
4. **记录差异** - 注明差异原因

## 最佳实践

### 防止虚假引文

1. **不要凭记忆生成引文** - AI生成引文错误率40%
2. **使用WebSearch查找** - 通过WebSearch验证每处引文
3. **在谷歌学术上确认** - 验证论文存在性
4. **及时验证** - 添加引文时立即验证，不要等到写完

### 处理验证失败

1. **不要猜测** - 如果找不到论文，不要编造信息
2. **明确标记** - 使用[CITATION NEEDED]明确标记
3. **通知用户** - 明确说明哪些引文无法验证
4. **说明原因** - 解释验证失败的原因（未找到、信息不匹配等）

### 提高验证准确性

1. **完整查询** - 包含标题、作者、年份
2. **检查引用次数** - 谷歌学术上的引用次数是可信度指标
3. **确认场所** - 验证会议/期刊名称是否正确
4. **验证声明** - 引用具体声明时，确认其存在于论文中

### 常见误区

❌ **错误做法**：
- 凭记忆生成BibTeX
- 跳过谷歌学术验证
- 假设论文存在
- 不标记无法验证的引文

✅ **正确做法**：
- 使用WebSearch搜索每处引文
- 在谷歌学术上确认
- 从谷歌学术复制BibTeX
- 明确标记无法验证的引文

## 总结

**核心原则**：在写作过程中使用WebSearch和谷歌学术主动验证每处引文。

**关键步骤**：
1. WebSearch查找论文
2. 谷歌学术验证存在性
3. 确认详情
4. 获取BibTeX
5. 验证声明（如果需要）
6. 添加到参考文献列表

**失败处理**：验证失败时，标记为[CITATION NEEDED]并明确通知用户。

**集成**：本技能的原则已集成到ml-paper-writing技能中，用于自动验证。
