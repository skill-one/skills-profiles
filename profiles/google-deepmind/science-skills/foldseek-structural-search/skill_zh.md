## 前置条件

1.  **`uv`**: 阅读 `uv` 技能并遵循其设置说明，确保 `uv` 已安装并在 PATH 路径中。
2.  **用户通知**: 如果工作区根目录中不存在 `.licenses/foldseek_structural_search_LICENSE.txt` 文件，则 (1) 醒目地通知用户检查 https://search.foldseek.com/search 和 https://github.com/steineggerlab/foldseek 上的条款，然后 (2) 创建一个记录通知文本和时间戳的文件。

## 目标

将用户提供的 3D 蛋白质结构文件（`.cif`、`.mmcif` 或 `.pdb`）提交到 Foldseek 网络服务器 API 以查找结构相似的蛋白质。报告顶级结构命中结果，解释关键比对指标，总结推断的蛋白质功能，将 Markdown 格式的表格保存为 `.md` 文件，并将完整详细结果保存到本地 JSON 文件中。

## 核心规则

-   **文件要求**: 此工具绝对不能按序列、名称或登录 ID 进行搜索。它严格要求 `.pdb`、`.cif` 或 `.mmcif` 文件路径。
-   **严格验证**: 绝不绕过输入验证或数据库允许列表检查。
-   **不要解析 JSON**: 完全依赖生成的 `.md` 文件进行即时总结。JSON 仅用于后续专用工具使用。
-   **不进行原始解析**: 不要尝试解析或读取原始 3D 坐标；始终将文件传递给脚本。
-   **通知**: 如果使用此技能，请确保在输出中提及。

## 说明

1.  **严格输入验证**: 验证用户是否在工作区中明确提供了一个有效的 `.cif`、`.mmcif` 或 `.pdb` 文件路径。
    *   如果用户提供了蛋白质名称、氨基酸序列或登录 ID（例如，UniProt ID），但没有下载的结构文件，**立即停止**。不要运行脚本。
    *   告知用户 Foldseek 需要一个物理 3D 坐标文件，并建议首先下载结构（例如，使用 AlphaFold 获取工具）。
2.  **数据库验证**: 检查用户是否请求搜索特定数据库。
    *   **允许列表**: `afdb50`、`afdb-swissprot`、`pdb100`、`BFVD`、`mgnify_esm30`、`cath50`、`gmgcl_id`、`bfmd`、`afdb-proteome`。
    *   如果用户请求的数据库不在该列表中，**立即停止**。不要运行脚本。告知用户数据库不受支持，并提供允许列表。
3.  **生成文件名**: 根据输入文件生成描述性的输出文件名，用于 JSON 数据和 Markdown 表格（例如，`proteinA_foldseek_results.json` 和 `proteinA_foldseek_results.md`）。
4.  根据用户请求执行 python 脚本，将标准输出重定向到生成的 `.md` 文件：
    *   **默认（未指定数据库）**: `uv run scripts/search.py <文件路径> -o <生成的文件名.json> > <生成的文件名.md>`
    *   **自定义（指定有效数据库）**: `uv run scripts/search.py <文件路径> -o <生成的文件名.json> --databases <db1,db2,db3> > <生成的文件名.md>`
5.  脚本将查询数据库，保存完整的 JSON 负载，并将 Markdown 格式的表格写入指定的 `.md` 文件。
6.  **读取结果**: 仔细打开并阅读新生成的 `.md` 文件以查看 Markdown 表格。
7.  **解释指标**: 总结前 3 到 5 个具有有意义注释的结构匹配结果，供用户参考。报告时，使用以下特定字段评估匹配质量：
    *   **Prob（概率）**: 接近 1.0（100%）的值表示对折叠是真实结构同源物的信心极高。
    *   **Q-Cov（查询覆盖率）**: 高百分比意味着匹配覆盖了查询蛋白质的大部分整体形状，而不仅仅是小局部基序。
    *   **E-value & Seq Identity**: 使用这些指标提供额外的进化背景。
8.  **进行功能分析**: 分析报告匹配结果中 `Target ID` 列中嵌入的文本描述。
    *   明确报告顶级结构同源体的具体蛋白质名称/功能。
    *   提供综合概述，总结整个同源体列表中发现的全部不同功能、结构域或蛋白质家族（例如，“大多数命中是门控蛋白，但也有一个独特的病毒衣壳匹配集群...”）。
9.  明确告知用户新创建的文件（`.json` 和 `.md`）及其位置，以便它们可以无缝用于后续分析步骤。

## * 如果 API 返回错误或文件丢失，请向用户清晰地说明并要求他们验证文件路径。
