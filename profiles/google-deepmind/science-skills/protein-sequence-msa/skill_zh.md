2.  **用户通知**: 如果工作区根目录中不存在 `.licenses/protein_sequence_msa_LICENSE.txt` 文件，则 (1) 在 https://www.ebi.ac.uk/jdispatcher/msa/clustalo 和 https://www.ebi.ac.uk/about/terms-of-use/ 等显眼位置通知用户检查条款，然后 (2) 创建一个记录通知文本和时间戳的文件。
3.  **`.env` 文件**: 确保您的家目录中存在 `.env` 文件。如果不存在，请创建它。
4.  **`USER_EMAIL`**: Clustal Omega 任务跟踪包装脚本所需。EBI 推荐使用此值。如果此技能与用户的请求相关，您 **必须** 在 `credentials` 技能中使用安全凭证协议检查并请求此凭证。

## 核心规则

-   **使用包装脚本**: 始终使用 `scripts/msa_align.py` 执行比对，而不是编写您自己的 curl 或自定义 Python 请求。脚本会自动执行所需的速率限制，以尊重 EBI 的使用条款。
-   **通知**: 如果使用此技能，请确保在输出中提及。
*   **始终说明方法**: 每份报告都必须明确说明比对是使用 **EBI Clustal Omega** 执行的。
-   **禁止臆造**: 不要编造比对或保守度量。仅报告比对文件中存在的内容。

## 目标

获取一个包含多个蛋白质序列的 FASTA 格式文件，使用 EBI Clustal Omega API 执行多序列比对，将结果比对保存在本地以供未来的程序分析，并根据用户的具体研究目标（例如，评估相似性、识别保守结构域或分析关键残基）解释结果。

## 说明

1.  **准备输入文件**: 输入必须是一个包含两个或多个蛋白质序列的纯文本 FASTA 格式文件。每个序列头必须以 `>` 符号开头。示例：

    ```
    >Sequence_1_Name
    MQIFVKTLTGKTITLEVEPSDTIENVKAKIQDKEGIPPDQ
    QRLIFAGKQLEDGRTLSDYNIQKESTLHLVLRLRGG
    >Sequence_2_Name
    MQIFVKTLTGKTITLEVEPSDTIENVKAKIQDKEGIPPDQ
    QRLIFAGKQLEDGRTLSDYNIQKESTLHLVLRLRGG
    ```

2.  **执行比对**: 运行比对脚本：

    ```bash
    uv run scripts/msa_align.py <INPUT_FASTA> -o <OUTPUT_FILE>
    ```

    始终使用 `-o` 或 `--output` 指定输出文件。

3.  **解释和报告结果**: 通过选择与研究目标一致的指标和映射策略来分析 Clustal Omega 比对。请注意，虽然 Clustal Omega 生成全局比对，但可以提取成对指标来评估集合内的特定关系：

    *   **身份指标选项**: 分母的选择决定了插入/删除（间隙）如何影响最终百分比。根据生物学背景选择最合适的计算方法：
        *   **成对 - 序列覆盖率**: `(相同残基匹配数) / (较短序列的长度)`。用于确定特定结构域或片段是否在大蛋白质中完全保留。这忽略了较长序列中的间隙，仅关注较短序列的“内容”。
        *   **成对 - 全局身份**: `(相同残基匹配数) / (总比对列数)`。用于比较预期长度相似的完整序列。这是最保守的指标；它会惩罚任何序列在 MSA 中引入的所有间隙（indels）。
        *   **成对 - 重叠身份**: `(相同残基匹配数) / (总比对列数 - 末端间隙)`。用于将片段与完整蛋白质比较，或当序列有长未比对“尾部”时使用。这仅关注序列物理重叠处的相似性。
        *   **多序列 - 保守指数**: `(完全保守列数) / (总比对列数)`。用于量化整个比对集中 100% 相同的残基百分比。这识别了蛋白质家族的核心进化特征。
    *   **特征映射**: 利用特定序列的已知生物学数据来为分析提供基础：
        *   **知识收集**: 从输入或通过外部工具识别相关的已知位点或区域（例如，催化残基、结合基序）。
        *   **坐标投影**: 将这些特征映射到比对相应的列索引。
        *   **目标导向讨论**: 使用这些列来驱动评估：
            *   **局部保守性**: 分析已知功能残基是否在整个集合中保持不变。
            *   **区域特定指标**: 在映射的功能区域而不是整个序列内计算身份/相似性。
            *   **目标贡献**: 讨论这些数据如何有助于您的目标，例如使用保守性来证实预测或使用分化来拒绝功能假设。
