# JSON Canvas Skill

## 文件结构

画布文件（`.canvas`）包含两个顶层数组，遵循[JSON Canvas Spec 1.0](https://jsoncanvas.org/spec/1.0/)：

```json
{
  "nodes": [],
  "edges": []
}
```

- `nodes`（可选）：节点对象数组
- `edges`（可选）：连接节点的边对象数组

## 常用工作流程

### 1. 创建新画布

1. 使用基础结构 `{"nodes": [], "edges": []}` 创建 `.canvas` 文件
2. 为每个节点生成唯一的 16 位十六进制 ID（例如，`"6f0ad84f44ce9c17"`）
3. 添加包含必需字段的节点：`id`、`type`、`x`、`y`、`width`、`height`
4. 通过 `fromNode` 和 `toNode` 添加引用有效节点 ID 的边
5. **验证**：解析 JSON 以确认其有效，并验证所有 `fromNode`/`toNode` 值均存在于 nodes 数组中

### 2. 向现有画布中添加节点

1. 读取并解析现有的 `.canvas` 文件
2. 生成一个不与现有节点或边 ID 冲突的唯一 ID
3. 选择 `(x`, `y`) 位置，避免与现有节点重叠（保持 50-100px 的间距）
4. 将新节点对象追加到 `nodes` 数组中
5. 可选添加将新节点与现有节点连接的边
6. **验证**：确认所有 ID 唯一，且所有边的引用均能解析到现有节点

### 3. 连接两个节点

1. 确定源节点和目标节点的 ID
2. 生成唯一的边 ID
3. 将 `fromNode` 和 `toNode` 设置为源节点和目标节点 ID
4. 可选设置 `fromSide`/`toSide`（顶、右、底、左）作为锚点
5. 可选设置 `label` 以在边上添加描述性文本
6. 将边追加到 `edges` 数组中
7. **验证**：确认 `fromNode` 和 `toNode` 均引用现有节点 ID

### 4. 编辑现有画布

1. 将 `.canvas` 文件作为 JSON 读取并解析
2. 通过 `id` 定位目标节点或边
3. 修改所需的属性（文本、位置、颜色等）
4. 将更新后的 JSON 写回文件
5. **验证**：在编辑后重新检查所有 ID 的唯一性以及边的引用完整性

## 节点

节点是放置在画布上的对象。数组顺序决定 z-index：第一个节点 = 底层，最后一个节点 = 顶层。

### 节点通用属性

| 属性 | 必填 | 类型 | 说明 |
|-----------|----------|------|-------------|
| `id` | 是 | string | 唯一的 16 位十六进制标识符 |
| `type` | 是 | string | `文本`、`文件`、`链接` 或 `组` |
| `x` | 是 | integer | 像素 X 位置 |
| `y` | 是 | integer | 像素 Y 位置 |
| `width` | 是 | integer | 宽度（像素） |
| `height` | 是 | integer | 高度（像素） |
| `color` | 否 | canvasColor | 预设 `"1"`-`"6"` 或十六进制（例如，`"#FF0000"`） |

### 文本节点

| 属性 | 必填 | 类型 | 说明 |
|-----------|----------|------|-------------|
| `文本` | 是 | string | 包含 Markdown 语法的纯文本 |

```json
{
  "id": "6f0ad84f44ce9c17",
  "type": "text",
  "x": 0,
  "y": 0,
  "width": 400,
  "height": 200,
  "text": "# Hello World\n\nThis is **Markdown** content."
}
```

**换行警告**：在 JSON 字符串中使用 `\n` 表示换行。**不要**使用字面量 `\\n` —— Obsidian 会将其渲染为字符 `\` 和 `n`。

### 文件节点

| 属性 | 必填 | 类型 | 说明 |
|-----------|----------|------|-------------|
| `文件` | 是 | string | 系统内的文件路径 |
| `子路径` | 否 | string | 指向标题或代码块（以 `#` 开头） |

```json
{
  "id": "a1b2c3d4e5f67890",
  "type": "file",
  "x": 500,
  "y": 0,
  "width": 400,
  "height": 300,
  "file": "Attachments/diagram.png"
}
```

### 链接节点

| 属性 | 必填 | 类型 | 说明 |
|-----------|----------|------|-------------|
| `url` | 是 | string | 外部 URL |

```json
{
  "id": "c3d4e5f678901234",
  "type": "link",
  "x": 1000,
  "y": 0,
  "width": 400,
  "height": 200,
  "url": "https://obsidian.md"
}
```

### 组节点

组是用于组织其他节点的视觉容器。将子节点放置在组的范围内。

| 属性 | 必填 | 类型 | 说明 |
|-----------|----------|------|-------------|
| `标签` | 否 | string | 组的文本标签 |
| `背景` | 否 | string | 背景图片路径 |
| `背景样式` | 否 | string | `cover`、`ratio` 或 `repeat` |

```json
{
  "id": "d4e5f6789012345a",
  "type": "group",
  "x": -50,
  "y": -50,
  "width": 1000,
  "height": 600,
  "label": "Project Overview",
  "color": "4"
}
```

## 边

边通过 `fromNode` 和 `toNode` ID 连接节点。

| 属性 | 必填 | 类型 | 默认值 | 说明 |
|-----------|----------|--------|---------|-------------|
| `id` | 是 | string | - | 唯一标识符 |
| `fromNode` | 是 | string | - | 源节点 ID |
| `fromSide` | 否 | string | - | `顶`、`右`、`底` 或 `左` |
| `fromEnd` | 否 | string | `none` | `none` 或 `箭头` |
| `toNode` | 是 | string | - | 目标节点 ID |
| `toSide` | 否 | string | - | `顶`、`右`、`底` 或 `左` |
| `toEnd` | 否 | string | `arrow` | `none` 或 `箭头` |
| `颜色` | 否 | canvasColor | - | 线条颜色 |
| `标签` | 否 | string | - | 文本标签 |

```json
{
  "id": "0123456789abcdef",
  "fromNode": "6f0ad84f44ce9c17",
  "fromSide": "right",
  "toNode": "a1b2c3d4e5f67890",
  "toSide": "left",
  "toEnd": "arrow",
  "label": "leads to"
}
```

## 颜色

`canvasColor` 类型可接受十六进制字符串或预设数值：

| 预设 | 颜色 |
|--------|-------|
| `"1"` | 红色 |
| `"2"` | 橙色 |
| `"3"` | 黄色 |
| `"4"` | 绿色 |
| `"5"` | 青色 |
| `"6"` | 紫色 |

预设颜色值刻意留空 —— 应用使用其自身的品牌颜色。

## ID 生成

生成 16 位小写十六进制字符串（64 位随机值）：

```
"6f0ad84f44ce9c17"
"a3b2c1d0e9f8a7b6"
```

## 布局指南

- 坐标可以为负值（画布无限延伸）
- `x` 向右递增，`y` 向下递增；位置为左上角
- 节点之间保持 50-100px 的间距；组内保留 20-50px 的内边距
- 对齐网格（10 或 20 的倍数），以获得更简洁的布局

| 节点类型 | 建议宽度 | 建议高度 |
|-----------|------------------|------------------ |
| Small text | 200-300 | 80-150 |
| Medium text | 300-450 | 150-300 |
| Large text | 400-600 | 300-500 |
| File preview | 300-500 | 200-400 |
| Link preview | 250-400 | 100-200 |

## 验证清单

创建或编辑画布文件后，验证：

1. 所有 `id` 值在节点和边中均唯一
2. 每个 `fromNode` 和 `toNode` 均引用现有节点 ID
3. 每种节点类型均包含必需字段（文本节点为 `文本`，文件节点为 `文件`，链接节点为 `url`）
4. `type` 值为：`文本`、`文件`、`链接` 或 `组`
5. `fromSide`/`toSide` 值为：`顶`、`右`、`底` 或 `左`
6. `fromEnd`/`toEnd` 值为：`none` 或 `箭头`
7. 颜色预设为 `"1"` 到 `"6"` 或有效的十六进制（例如，`"#FF0000"`）
8. JSON 有效且可解析

如果验证失败，请检查是否存在重复 ID、悬空边引用，或格式错误的 JSON 字符串（特别是文本内容中未转义换行符）。
