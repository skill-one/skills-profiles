为当前对话撰写一份交接摘要，以便全新的 agent 可以继续工作。无需保存这份摘要，而是启动一个以这份摘要作为 prompt 的后台 agent：`claude --bg --name "<描述性名称>" "<交接摘要>"`。它将在当前工作目录中启动并立即返回；用户可以使用 `claude agents` 来管理它。

始终带上 `-n`/`--name` 并给出描述性名称（例如 `--name "修复登录 Bug"`）——它设置显示名称，会出现在任务列表、会话选择器和终端标题中。

在摘要中包含一个 "建议技能" section，明确说明下一个 agent 应调用 Skill 工具并指定哪些技能。

不要重复其它工件（PRDs、计划、ADRs、问题、提交、差异）中已经记录的内容，改为使用路径或 URL 引用它们。

删除任何敏感信息，例如 API 密钥、密码或个人身份信息——这份摘要将作为 agent 的 prompt。

如果用户传入了参数，把它们当作对下一个会话重点的描述，并据此调整摘要。
