# 查找技能

通过搜索**所有主要注册中心**，并以各自的原生指标展示每个平台，来为任务找到合适的代理技能——而不是依赖单一网站的排行榜。

## 何时使用此技能

- 用户询问“如何做X”，而X是一个常见的任务，很可能有一个已发布的技能
- “查找X的技能” / “是否有X的技能” / “我应该为X安装什么”
- 用户希望扩展代理功能（测试、设计、部署、特定模型/API、领域工作流）
- 你即将从头开始构建某物，而一个经过实战检验的技能可能已经涵盖了它

## 多源的重要性

每个注册中心只显示自己的部分内容，具有不同的信号：

| 注册中心 | 搜索 | 暴露的信号 | 盲点 |
| --- | --- | --- | --- |
| **skills.sh** | `GET /api/search?q=` | 终身安装量、源代码库 | 无星级、无摘要、安装量滞后约2.5小时 |
| **clawhub.ai** | `/api/search` + `/api/skill?slug=` | 摘要、安装量、星级、版本 | 语料库比skills.sh小 |
| **GitHub** | `gh search repos --topic {claude-skills,agent-skills,claude-code-skills}` | 仓库星级、描述、维护状态 | 仓库级别，不是技能级别；仅显示主题标记的仓库 |

一个技能在一个网站上可能排名#1，有50个安装量，而在另一个网站上，一个有1,300个安装量的等效技能可能未被排名。只搜索一个注册中心会给出有偏见的答案。此技能**并行**查询所有三个注册中心，按各自的原生指标对每个平台进行排名，标记在两个注册中心都出现的技能（基于*标准化*名称，双向匹配——所以`face-swap` ↔ `faceswap`对齐），并显示每个平台的顶部，让你看到整个生态系统——而不是一个网站的排行榜。

## 如何运行它

使用用户的需要作为查询运行捆绑的聚合器：

```bash
bash scripts/find.sh "<用户需要什么>"
```

示例：

```bash
bash scripts/find.sh "react性能"
bash scripts/find.sh "pdf表单填写" --limit 8
bash scripts/find.sh "视频生成" --scan 5
bash scripts/find.sh "部署到vercel" --no-scan --json
```

标志：

- `--limit N` — 每个来源的结果数量（默认10；非数字回退到10）
- `--scan K` — 在每个注册中心上安全扫描前K个可安装的候选者（默认2，最大5）
- `--no-scan` — 跳过安全扫描（更快；扫描会添加几秒钟，因为它会获取每个候选者的真实SKILL.md）
- `--json` — 发出机器可读的JSON而不是格式化报告
- `-h` / `--help` — 打印用法并退出

该脚本需要`curl`和`jq`。它使用`gh`来处理GitHub部分和获取skills.sh技能正文，以及`unzip`在扫描期间处理clawhub技能正文——所有这些都是可选的，如果缺失会优雅降级。不需要API密钥。
