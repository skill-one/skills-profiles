# Three.js 图像生成器

Three.js 游戏的 2D 图层：概念、纹理、贴花、UI 艺术以及为 `threejs-3d-generator` 提供的用于图像转 3D 的源图像。

从实际加载的技能文件中解析 `<this-skill-dir>`。首先解析其旁边的同级技能，然后使用运行器发现的路径。不要混用已安装的版本或假设特定的家目录。

## 使用场景

- 图像转 3D 参考：角色、生物、建筑、飞船、汽车、武器、道具、拾取物、地形模块。
- 纹理和材质参考：地形、道路、岩石、沙子、金属、科幻面板、饰面板、贴花、危险标签、标志。
- 环境板：天空、背景、城市地平线、星云、菜单背景、视差层。
- UI 艺术：标志、阵营标记、图标、物品卡、能力徽章、驾驶舱贴花、GUI 面板、标题艺术。
- 编辑现有图像：风格变体、清理、调色板对齐、概念细化。

对于包含生成范围的高级图形工作，生成高价值的 2D 表面，而不是默认使用手写的 CSS 和纯色。尊重明确的过程式艺术和外部服务限制。从游戏设计中选择资源，而不是固定的标志、天空或图标配额。

## API 密钥

脚本读取 `--api-key` 或 `GEMINI_API_KEY`。密钥永远不会放在技能文件、游戏代码或报告中。

```bash
uv run <this-skill-dir>/scripts/generate_image.py probe   # GEMINI_API_KEY=SET|MISSING
```

仅在 shell 配置文件中定义的密钥可能不在进程环境中。如果纯文本的 probe 意外打印出 MISSING，请使用 `threejs-game-director/scripts/probe_asset_credentials.sh`，它会加载配置文件并探测所有三个提供者。

## 命令

从游戏项目运行，以便输出位于其中：

```bash
uv run <this-skill-dir>/scripts/generate_image.py \
  --prompt "你的图像描述" --filename assets/concepts/output.png --resolution 2K

uv run <this-skill-dir>/scripts/generate_image.py \
  --input-image assets/concepts/ship.png \
  --prompt "战斗磨损的红色赛车涂装，材质区域更清晰" \
  --filename assets/concepts/ship-red-livery.png --resolution 2K
```

分辨率：`1K` 用于快速概念、图标和草稿图纸 · `2K`（默认值）用于生产参考、图像转 3D、纹理、背景、UI 面板 · `4K` 用于英雄横幅艺术、高细节纹理参考和大型天空板。

## 提示模式

图像转 3D 参考：
> 创建一个干净的 3D 生成参考图像 `[资源]`。居中单个对象，完整对象可见，纯色背景，可读的轮廓，清晰的材质区域，游戏就绪的 `[类型/风格]`，无运动模糊，无裁剪部分，无文本。

可绑定角色或生物：
> 创建用于 3D 绑定的全身 `[T 形/ A 形/ 侧视生物]` 参考图：`[细节]`。对称姿态，可见的手/脚/肢体，纯色背景，可读的服装和解剖层，无武器与手融合。

纹理或材质：
> 创建无缝游戏纹理参考 `[表面]`。正交俯视，PBR 友好的反照率，清晰的材料变化，无透视，无烘焙的强阴影，`[风格细节]`。

标志、图标或 UI 艺术：
> 创建清晰的 3D 游戏用 `[标志/图标/徽章/面板]` `[阵营/物品/能力]`。透明度友好的轮廓，小尺寸高对比度，`[类型风格]`，无微小的不可读文本。

天空或背景：
> 创建 `[环境]` 的宽游戏背景板。分层深度，可读的地平线，`[时间/天气/风格]`，适合作为实时 Three.js 场景的背景，无前景主题。

## 集成

将概念和图像转 3D 源保存在 `assets/concepts/` 下；将纹理、贴花、图标和 GUI 源保存在 `assets/textures/`、`assets/decals/` 或 `assets/ui/` 下。通过路径将图像转 3D 源交给 `threejs-3d-generator`。

有意将 PNG 转换为运行时格式：PNG 用于需要 alpha 的 UI、图标、贴花，JPG/WebP/KTX2 用于更大的不透明纹理（如果管道支持）。API 是一个工具步骤——永远不会从游戏代码中调用。

在花费于图像转 3D 或依赖变体之前检查图像。检查运行时图像在游戏中的外观，而不仅仅是文件是否已写入。当用户更改需求时保留有用的现有图像，并更新项目笔记而不是重新生成所有内容。

## 恢复

对于协调的游戏使用导演的 `references/asset-recovery.md`。缺失的凭证或用尽的积分允许诚实地使用本地替代方案；瞬态错误不是。区分无效输入和身份验证与服务故障。不要盲目重试不确定的付费生成：保留现有文件并首先协调提供者结果。此命令没有 Tripo 风格的任务恢复界面。继续独立的游戏工作，而只有依赖的图像工作被阻塞。

## 报告

提示和目的，输出路径，分辨率，是否直接使用、进一步编辑或交给 `threejs-3d-generator`，以及任何剩余工作，如压缩、UV 分配、alpha 清理或图集打包。
