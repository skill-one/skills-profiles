# 拉尔夫·威格姆

> 基于规范的自主AI编程

## 拉尔夫·威格姆是什么？

拉尔夫·威格姆结合了**杰弗里·亨特利（Geoffrey Huntley）的迭代bash循环**与**基于规范的开发**，用于完全自主的AI辅助软件开发。

核心洞察：**每次迭代都有新的上下文**。每个循环都会启动一个新的代理进程，并使用干净的上下文窗口，防止上下文溢出和退化。

## 何时使用此技能

当你需要使用拉尔夫·威格姆时：

- 你有多个规范/功能需要实现
- 你希望AI能够自主完成任务
- 你需要一致且可验证的验收标准完成
- 你希望避免长会话中的上下文窗口问题

## 工作原理

```
┌─────────────────────────────────────────────────────────────┐
│                     拉尔夫循环                              │
├─────────────────────────────────────────────────────────────┤
│  循环1：选择规范A → 实现 → 测试 → 提交 → 完成              │
│  循环2：选择规范B → 实现 → 测试 → 提交 → 完成              │
│  循环3：选择规范C → 实现 → 测试 → 提交 → 完成              │
│  ...                                                        │
│                                                             │
│  每次迭代 = 新的上下文窗口                                  │
│  共享状态 = 磁盘上的文件 (规范、计划、历史记录)             │
└─────────────────────────────────────────────────────────────┘
```


### 完整设置（推荐）

对于带有宪法和面试的完整拉尔夫·威格姆设置：

```bash
# 告诉你的AI代理：
"使用 https://github.com/fstandhartinger/ralph-wiggum 设置拉尔夫·威格姆"
```

代理将引导你完成**轻量级、愉悦的设置**：

1. **快速设置** (~1分钟) — 创建目录、下载脚本
2. **项目面试** — 关注你的**愿景和目标**（不是技术细节）
3. **宪法** — 创建所有会话的指导文件
4. **下一步** — 清晰的创建规范和启动拉尔夫的指导

对于现有项目，代理会自动检测你的技术栈。面试优先理解*你在构建什么以及为什么*。

## 核心概念

### 1. 每次循环都有新的上下文

拉尔夫循环的每次迭代都会启动一个新的AI代理进程。这意味着：

- 没有上下文窗口溢出
- 随时间不会退化
- 每个任务都有干净的起点

### 2. 磁盘上的共享状态

状态通过文件在循环之间持久化：

- `specs/` — 带有验收标准的特征规范
- `ralph_history.txt` — 创新突破、障碍、学习的日志
- `IMPLEMENTATION_PLAN.md` — 可选的详细任务分解

### 3. 完成信号

代理输出 `<promise>DONE</promise>` **仅当**：

- 所有验收标准都经过验证
- 测试通过
- 变更已提交并推送

bash循环会检查这个短语。如果找不到，它会重试。

### 4. 通过测试进行反向压力

测试、代码风格检查和构建充当护栏。代理必须在输出完成信号之前修复问题。

## 使用方法

### 创建规范

**成功的关键**：每个规范都需要**清晰、可测试的验收标准**。这是告诉拉尔夫任务何时真正“完成”的方式。

```markdown
# 功能：用户认证

## 要求
- 使用Google的OAuth登录
- 会话管理
- 退出功能

## 验收标准
- [ ] 用户可以使用Google登录
- [ ] 会话可以在页面重新加载时持续
- [ ] 用户可以退出
- [ ] 测试通过

**完成时输出：** `<promise>DONE</promise>`
```

**好的标准**： "用户可以使用Google登录且会话可以持续"
**坏的标准**： "认证功能正常"

你的验收标准越具体，拉尔夫的表现就越好。

### 运行循环

```bash
# 开始构建 (Claude Code)
./scripts/ralph-loop.sh

# 使用最大迭代次数
./scripts/ralph-loop.sh 20

# 使用Codex CLI
./scripts/ralph-loop-codex.sh
```

### 日志记录（所有输出都会被捕获）

每次循环运行都会将**所有输出**写入 `logs/` 中的日志文件：

- **会话日志：** `logs/ralph_*_session_YYYYMMDD_HHMMSS.log`（整个运行，包括CLI输出）
- **迭代日志：** `logs/ralph_*_iter_N_YYYYMMDD_HHMMSS.log`（每次迭代的CLI输出）
- **Codex最后消息：** `logs/ralph_codex_output_iter_N_*.txt`

## 两种模式

| 模式 | 目的 | 命令 |
|------|---------|---------|
| **build** (默认) | 选择规范、实现、测试、提交 | `./scripts/ralph-loop.sh` |
| **plan** (可选) | 创建详细任务分解 | `./scripts/ralph-loop.sh plan` |
