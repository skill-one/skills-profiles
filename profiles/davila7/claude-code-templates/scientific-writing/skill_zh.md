# 科研写作

## 概述

**这是深度研究和写作工具的核心技能**—结合AI驱动的深度研究与格式良好的书面输出。生成的每个文档都基于全面的文献检索和通过研究查找技能验证的引用。

科研写作是一个以精确性和清晰度传达研究的过程。使用IMRAD结构、引用（APA/AMA/Vancouver）、图表/表格和报告指南（CONSORT/STROBE/PRISMA）撰写手稿。将此技能应用于研究论文和期刊投稿。

**关键原则：始终使用完整段落和流畅的散文进行写作。最终手稿中绝不能提交项目符号列表。** 使用两阶段流程：首先使用研究查找技能创建包含要点的小节提纲，然后将这些提纲转换为完整段落。

## 使用此技能的场景

当出现以下情况时，应使用此技能：
- 撰写或修改科学手稿的任何部分（摘要、引言、方法、结果、讨论）
- 使用IMRAD或其他标准格式构建研究论文
- 以特定样式（APA、AMA、Vancouver、Chicago、IEEE）格式化引用和参考文献
- 创建、格式化或改进图表、表格和数据可视化
- 应用特定研究的报告指南（CONSORT用于试验、STROBE用于观察性研究、PRISMA用于综述）
- 撰写符合期刊要求的摘要（结构化或非结构化）
- 准备提交给特定期刊的手稿
- 提高写作清晰度、简洁性和精确性
- 确保正确使用特定领域的术语和命名法
- 回应审稿人意见并修改手稿

## 核心功能

### 1. 手稿结构和组织

**IMRAD格式**：指导论文通过跨大多数科学学科使用的标准引言、方法、结果和讨论结构。这包括：
- **引言**：建立研究背景，识别差距，陈述目标
- **方法**：详细说明研究设计、人群、程序和分析方法
- **结果**：客观呈现结果，不进行解释
- **讨论**：解释结果，承认局限性，提出未来方向

有关IMRAD结构的详细指南，请参阅`references/imrad_structure.md`。

**替代结构**：支持特定学科的格式，包括：
- 综述文章（叙述性、系统性、范围性）
- 病例报告和病例系列
-荟萃分析和合并分析
- 理论/建模论文
- 方法论文和方案

### 2. 部分特定写作指导

**摘要撰写**：撰写简洁、独立的摘要（100-250字），捕捉论文的目的、方法、结果和结论。支持结构化摘要（带有标记部分）和非结构化单段格式。

**引言发展**：构建引人入胜的引言，该引言：
- 建立研究问题的重要性
- 系统地回顾相关文献
- 识别知识差距或争议
- 陈述清晰的研究问题或假设
- 解释研究的创新性和重要性

**方法记录**：通过以下方式确保可重复性：
- 详细描述参与者/样本
- 清晰的程序记录
- 统计方法及其论证
- 设备和材料规格
- 道德批准和知情同意声明

**结果展示**：通过以下方式呈现结果：
- 逻辑地从主要结果到次要结果
- 与图形和表格整合
- 统计显著性及效应量
- 客观报告，不进行解释

**讨论构建**：通过以下方式综合结果：
- 将结果与研究问题联系起来
- 与现有文献进行比较
- 坦诚承认局限性
- 提出机制解释
- 建议实际意义和未来研究

### 3. 引用和参考文献管理

跨学科正确应用引用样式。有关全面的样式指南，请参阅`references/citation_styles.md`。

**主要引用样式：**
- **AMA（美国医学会）**：编号的 superscript 引用，在医学中很常见
- **Vancouver**：方括号中的编号引用，生物医学标准
- **APA（美国心理学会）**：文中作者-日期引用，社会科学中很常见
- **Chicago**：注释-参考文献或作者-日期，人文科学和自然科学
- **IEEE**：编号的方括号，工程和计算机科学

**最佳实践：**
- 尽可能引用原始来源
- 包含最新文献（活跃领域最近5-10年）
- 在引言和讨论中平衡引用分布
- 核对所有引用与原始来源
- 使用参考文献管理软件（Zotero、Mendeley、EndNote）

### 4. 图形和表格

创建有效的数据可视化，以增强理解。有关详细的最佳实践，请参阅`references/figures_tables.md`。

**何时使用表格与图形：**
- **表格**：精确的数值数据、复杂的数据集、需要精确值的多个变量
- **图形**：趋势、模式、关系、最好通过视觉理解的比较

**设计原则：**
- 使每个表格/图形具有完整的标题，并具有完整的说明
- 在所有显示项中使用一致的格式和术语
- 标注所有轴、列和行，并注明单位
- 包括样本量（n）和统计注释
- 遵循“每1000字一个表格/图形”的指南
- 避免在文本、表格和图形之间重复信息

**常见图形类型：**
- 条形图：比较离散类别
- 折线图：显示随时间变化的趋势
- 散点图：显示相关性
- 箱线图：显示分布和异常值
- 热图：可视化矩阵和模式

### 5. 按研究类型划分的报告指南

通过遵循既定的报告标准，确保完整性和透明度。有关全面的指南详细信息，请参阅`references/reporting_guidelines.md`。

**关键指南：**
- **CONSORT**：随机对照试验
- **STROBE**：观察性研究（队列、病例对照、横断面）
- **PRISMA**：系统评价和荟萃分析
- **STARD**：诊断准确性研究
- **TRIPOD**：预测模型研究
- **ARRIVE**：动物研究
- **CARE**：病例报告
- **SQUIRE**：质量改进研究
- **SPIRIT**：临床试验方案
- **CHEERS**：经济评价

每个指南都提供清单，确保报告所有关键方法学要素。

### 6. 写作原则和风格

应用基本的科研写作原则。有关详细指南，请参阅`references/writing_principles.md`。

**清晰度**：
- 使用精确、无歧义的语言
- 在首次使用时定义技术术语和缩写
- 在段落内和段落之间保持逻辑流程
- 在适当的时候使用主动语态以增强清晰度

**简洁性**：
- 消除冗余的词语和短语
- 偏爱较短的句子（平均15-20个词）
- 移除不必要的限定词
- 严格尊重字数限制

**准确性**：
- 报告精确的值并注明适当的精度
- 在整个文档中使用一致的术语
- 区分观察结果和解释
- 适当承认不确定性

**客观性**：
- 客观呈现结果
- 避免过度陈述结果或意义
- 承认相互矛盾的证据
- 保持专业、中立的语气

### 7. 写作过程：从提纲到完整段落

**关键：始终使用完整段落，科研论文中绝不能提交项目符号列表。**

科研论文必须使用完整的、流畅的散文。使用此两阶段方法进行有效写作：

**阶段1：使用研究查找技能创建包含要点的小节提纲**

开始一个新的部分时：
1. 使用研究查找技能收集相关的文献和数据
2. 创建一个结构化的提纲，使用项目符号标记：
   - 要呈现的主要论点或发现
   - 要引用的关键研究
   - 要包含的数据点和统计数据
   - 逻辑流程和组织
3. 这些项目符号作为框架——它们不是最终手稿

**示例提纲（引言部分）：**
```
- 背景：AI在药物发现中的应用日益增多
  * 引用最近的综述（Smith 2023，Jones 2024）
  * 传统方法缓慢且昂贵
- 差距：对罕见疾病的应用有限
  * 仅有的两项研究（Lee 2022，Chen 2023）
  * 小数据集仍然是一个挑战
- 我们的方法：从常见疾病迁移学习
  * 结合X和Y的新型架构
- 研究目标：在3个罕见疾病数据集上验证
```

**阶段2：将要点转换为完整段落**

提纲完成后，将每个项目符号扩展为适当的散文：

1. **将项目符号转换为包含主语、动词和宾语的完整句子**
2. **添加过渡**，在句子和想法之间（然而，此外，相反，随后）
3. **自然地整合引用**，而不是作为列表
4. **扩展上下文和解释**，这些要点省略了
5. **确保每个段落内句子之间的逻辑流程**
6. **变化句子结构**，以保持读者参与度

**示例转换为散文：**

```
人工智能方法在过去十年中在药物发现管道中获得了显著进展 
(Smith, 2023; Jones, 2024)。虽然这些计算方法显示出加速识别治疗候选物的潜力， 
但传统的实验方法仍然缓慢且资源密集，通常需要数年的实验室工作和大量的资金投入。然而， 
将AI应用于罕见疾病的应用有限，仅有两项研究展示了概念验证结果 
(Lee, 2022; Chen, 2023)。主要障碍是影响小人群的培训数据稀缺。 

为了应对这一挑战，我们开发了一种迁移学习方法，该方法是利用从特征明确的常见疾病中获取的知识来预测罕见疾病的治疗靶点。我们的新型神经网络架构结合了用于分子特征提取的卷积层和用于蛋白质-配体相互作用建模的注意力机制。本研究的目的是在三个独立罕见疾病数据集上验证我们的方法，评估结果的预测准确性和生物学可解释性。
```

**提纲与最终文本之间的关键区别：**

| 提纲（规划阶段） | 最终手稿 |
|------------------|------------------|
| 项目符号和片段 | 完整的句子和段落 |
| 电报式笔记 | 完整的解释和上下文 |
| 引用列表 | 整合到散文中的引用 |
| 简化的想法 | 发展的论点，带有过渡 |
| 仅限您自己看 | 用于出版和同行评审 |

**要避免的常见错误：**

- ❌ **绝不**在最终手稿中留下项目符号
- ❌ **绝不**提交列表，而应该用段落
- ❌ **不要**在结果或讨论部分使用编号或项目符号列表（除了特定情况，如研究假设或纳入/排除标准）
- ❌ **不要**写句子片段或不完整的想法
- ✅ **要**在方法中偶尔使用列表（例如，纳入/排除标准、材料和试剂）
- ✅ **要**确保每个部分都作为连贯的散文流动
- ✅ **要**朗读段落以检查自然流程

**何时列表是可接受的（有限情况）：**

列表仅在特定上下文中出现：
- **方法**：纳入/排除标准、材料和试剂、参与者特征
- **补充材料**：扩展方案、设备列表、详细参数
- **绝不**在：摘要、引言、结果、讨论、结论

**与研究查找的集成：**

研究查找技能对于阶段1（创建提纲）至关重要：
1. 使用研究查找技能搜索相关论文
2. 提取关键发现、方法和数据
3. 将发现组织为提纲中的项目符号
4. 然后在阶段2将提纲转换为完整段落

这种两阶段流程可确保您：
- 系统地收集和组织信息
- 在写作之前创建逻辑结构
- 生成经过打磨的、可供发表的散文
- 保持对叙事流程的关注

### 8. 期刊特定格式

调整手稿以符合期刊要求：
- 遵循作者指南关于结构、长度和格式的要求
- 应用期刊特定的引用样式
- 满足图形/表格规范（分辨率、文件格式、尺寸）
- 包括所需声明（资金、利益冲突、数据可用性、伦理批准）
- 遵守每个部分的字数限制
- 根据提供的模板要求进行格式化

### 9. 特定领域的语言和术语

调整语言、术语和惯例，以匹配特定的科学学科。每个领域都有其建立的词汇、首选短语和特定领域的惯例，这些惯例表明专业知识，并确保目标受众的清晰度。

**识别特定领域的语言惯例：**
- 回顾目标期刊中近期高影响力论文中使用的术语
- 注意特定领域的缩写、单位和符号系统
- 确定首选术语（例如，“参与者”而不是“受试者”，“化合物”而不是“药物”，“标本”而不是“样本”）
- 观察如何描述方法、生物体或技术

**生物医学和临床科学：**
- 使用精确的解剖和临床术语（例如，在正式写作中，“心肌梗死”而不是“心脏病发作）
- 遵循标准疾病命名法（ICD、DSM、SNOMED-CT）
- 使用通用名称首先指定药物名称，如果需要，可以在括号中添加品牌名称
- 使用“患者”进行临床研究，使用“参与者”进行社区研究
- 遵循人类基因组变异学会（HGVS）命名法报告遗传变异
- 使用标准单位报告实验室值（大多数国际期刊中使用SI单位）

**分子生物学和遗传学：**
- 使用斜体表示基因符号（例如，*TP53*），常规字体表示蛋白质（例如，p53）
- 遵循特定物种的基因命名法（人类：*BRCA1*；小鼠：*Brca1*）
- 在首次提及时使用全名，然后使用接受的缩写（例如，*Escherichia coli*，然后*E. coli*）
- 使用标准遗传符号（例如，+/+，+/-，-/-表示基因型）
- 使用标准术语表示分子技术（例如，“定量PCR”或“qPCR”，而不是“实时PCR”）

**化学和药物科学：**
- 遵循IUPAC命名法报告化学化合物
- 使用系统名称报告新型化合物，使用常用名称报告众所周知的物质
- 使用标准符号报告化学结构（例如，SMILES、InChI用于数据库）
- 报告浓度使用适当的单位（mM、μM、nM或% w/v、v/v）
- 使用公认的合成路线命名法描述合成路线
- 使用术语如“生物利用度”、“药代动力学”、“IC50”始终与领域定义一致

**生态学和环境科学：**
- 使用双名法表示物种（斜体：*Homo sapiens*）
- 在首次提及物种时指定分类权威，如果相关
- 使用标准栖息地和生态系统分类
- 使用一致的术语表示生态指标（例如，“物种丰富度”、“Shannon多样性指数”）
- 使用现场标准术语描述采样方法（例如，“样线”、“样方”、“标记重捕”）

**物理学和工程学：**
- 一致使用SI单位，除非领域惯例另有规定
- 使用标准符号表示物理量（标量与矢量、张量）
- 使用领域标准术语表示现象（例如，“量子纠缠”、“层流”）
- 指定设备时注明型号和制造商，如果相关
- 使用与领域标准一致的数学符号（ℏ为约化普朗克常数）

**神经科学：**
- 使用标准脑区命名法（参考艾伦脑图谱等）
- 使用标准立体定位系统指定脑区坐标
- 遵循神经术语惯例（例如，“动作电位”而不是“尖峰”在正式写作中）
- 根据测量方法适当使用“神经活动”、“神经元放电”、“脑激活”
- 使用记录技术的适当具体性（例如，“全细胞电压钳”、“细胞外记录”）

**社会科学和行为科学：**
- 在适当的时候使用以人为本的语言（例如，“患有精神分裂症的人”而不是“精神分裂症患者”）
- 使用标准心理构念和经过验证的评估名称
- 遵循APA指南减少语言中的偏见
- 指定理论框架使用公认的术语
- 使用“参与者”而不是“受试者”进行人类研究

**一般原则：**

**匹配受众专业知识：**
- 对于专业期刊：自由使用领域特定术语，仅定义高度专业或新颖的术语
- 对于广泛影响期刊（例如，*Nature*、*Science*）：定义更多技术术语，为更广泛的受众提供背景，定义不可知的概念
- 对于跨学科受众：平衡精确性和可访问性，在首次使用时定义术语

**策略性地定义技术术语：**
- 在首次使用时定义缩写：“信使RNA (mRNA)”
- 当为更广泛的受众撰写时，提供对专业技术的简要解释
- 避免对目标受众已知的术语过度定义，这表明不熟悉领域
- 如果不可避免地有大量专业术语，请创建词汇表

**保持一致性：**
- 对同一概念使用相同的术语（不要在“药物”、“药物”和“药物”之间交替）
- 遵循一致的缩写系统（在首次定义后决定使用“PCR”或“聚合酶链反应”）
- 在整个文档中应用相同的命名法系统（尤其是基因、物种、化学物质）

**避免领域混合错误：**
- 不要用临床术语表示基础科学（例如，不要将小鼠称为“患者”）
- 避免使用非领域的非正式术语或过于笼统的术语来代替精确的领域术语
- 不要从相邻领域导入术语，而不用确保正确的使用

**验证术语使用：**
- 咨询领域特定的风格指南和命名法资源
- 检查目标期刊中近期论文如何使用术语
- 使用特定领域的数据库和本体（例如，Gene Ontology、MeSH术语）
- 在不确定时，引用建立术语的关键参考

### 10. 要避免的常见错误

**拒稿的主要原因：**
1. 不适当、不完整或描述不足的统计
2. 过度解释结果或不受支持的结论
3. 描述不佳的方法影响可重复性
4. 小、有偏差或不适当的样本
5. 写作质量差或难以理解的文本
6. 文献综述或背景不足
7. 不清晰或设计不佳的图形和表格
8. 未能遵循报告指南

**写作质量问题：**
- 不恰当地混合时态（使用过去时态报告方法/结果，现在时态报告既定事实）
- 过多的行话或未定义的缩写
- 段落中断破坏逻辑流程
- 段落之间缺少过渡
- 不一致的符号或术语

## 手稿开发的工作流程

**阶段1：规划**
1. 确定目标期刊并审查作者指南
2. 确定适用的报告指南（CONSORT、STROBE等）
3. 概述手稿结构（通常为IMRAD）
4. 规划图形和表格作为论文的骨干

**阶段2：起草**（对每个部分使用两阶段写作流程）
1. 从图形和表格开始（论文的核心数据故事）
2. 对于以下每个部分，遵循两阶段流程：
   - **首先**：使用研究查找技能创建包含要点的小节提纲
   - **其次**：将要点转换为完整段落，带有流畅的散文
3. 撰写方法（通常是最容易起草的部分）
4. 起草结果（客观描述图形/表格）
5. 构思讨论（解释发现）
6. 撰写引言（建立研究问题）
7. 构思摘要（综合整个故事）
8. 创建标题（简洁且描述性强）

**记住**：项目符号仅用于规划——最终手稿必须是完整段落。

**阶段3：修改**
1. 检查整个文档的逻辑流程和“红线”
2. 验证术语和符号的一致性
3. 确保图形/表格具有自我解释性
4. 确认遵循报告指南
5. 核对所有引用准确并正确格式化
6. 检查每个部分的字数
7. 校对语法、拼写和清晰度

**阶段4：最终准备**
1. 根据期刊要求进行格式化
2. 准备补充材料
3. 撰写封面信，突出重要性
4. 完成提交清单
5. 收集所有必需的声明和表格
