# UI 设计系统

用于创建和维护可扩展设计系统的专业工具包。

## 核心功能
- 设计令牌生成（颜色、排版、间距）
- 组件系统架构
- 响应式设计计算
- 无障碍合规性
- 开发者交接文档

## 关键脚本

### design_token_generator.py
从品牌颜色生成完整的设计系统令牌。

**使用方式**： `python scripts/design_token_generator.py [品牌颜色] [风格] [格式]`
- 风格：现代、经典、俏皮
- 格式：json、css、scss

**功能**：
- 完整的调色板生成
- 模块化排版尺度
- 8pt 间距网格系统
- 阴影和动画令牌
- 响应式断点
- 多种导出格式
