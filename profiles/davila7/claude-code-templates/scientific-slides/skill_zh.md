# 科学术语幻灯片

## 概述

学术演讲是传达研究、分享成果并与学术界和专业观众互动的关键媒介。这项技能为创建有效的学术演讲提供了全面的指导，从结构和内容开发到视觉设计和演讲准备。

**主要关注点**： 会议、研讨会、答辩和专业演讲的口头演讲。

**关键设计理念**： 学术演讲应该具有视觉吸引力和研究支持。不惜一切代价避免枯燥、文字过多的幻灯片。优秀的学术演讲结合了：
- **引人入胜的视觉效果**： 高质量的图片、图像、图表（而不仅仅是项目符号）
- **研究背景**： 从研究查询中引用适当的文献以建立可信度
- **最少文字**： 项目符号作为提示，您口头提供解释
- **专业设计**： 现代配色方案、强大的视觉层次结构、充足的空白区域
- **故事驱动**： 清晰的叙事弧线，而不仅仅是数据堆砌

**记住**： 乏味的演讲 = 遗忘的科学。在保持科学严谨性的同时，使您的幻灯片具有视觉记忆点，并通过适当的引用。

## 使用此技能的时机

当您需要使用此技能时：
- 准备会议演讲（5-20分钟）
- 开发学术研讨会（45-60分钟）
- 创建论文或论文答辩演讲
- 设计资助提案演讲
- 准备期刊俱乐部演讲
- 在机构或公司进行研究演讲
- 关于科学主题的教学或教程演讲

## 使用 Nano Banana Pro 生成幻灯片

**此技能使用 Nano Banana Pro AI 自动生成令人惊叹的演示幻灯片。**

根据输出格式，有两种工作流程：

### 默认工作流程：PDF 幻灯片（推荐）

将每个幻灯片生成为一个完整的图像，然后组合成一个 PDF。这会产生最令人惊叹的视觉效果。

**工作原理**：
1. **规划演示文稿**： 为每张幻灯片创建详细的计划（标题、要点、视觉元素）
2. **生成幻灯片**： 调用 Nano Banana Pro 为每张幻灯片创建完整的幻灯片图像
3. **组合为 PDF**： 将幻灯片图像组装成一个单独的 PDF 演示文稿

**步骤 1：规划每张幻灯片**

在生成之前，为您的演示文稿创建详细的计划：

```markdown
# 演示文稿计划：机器学习的介绍

## 幻灯片 1：标题幻灯片
- 标题："机器学习：从理论到实践"
- 副标题："2025 年人工智能会议"
- 演讲者：Jane Smith 博士，XYZ 大学
- 视觉效果：现代抽象神经网络背景

## 幻灯片 2：介绍
- 标题："机器学习的重要性"
- 要点：行业采用、突破性应用、未来潜力
- 视觉效果：显示不同机器学习应用的图标（医疗保健、金融、机器人）

## 幻灯片 3：核心概念
- 标题："三种学习类型"
- 内容：监督学习、无监督学习、强化学习
- 视觉效果：三部分图表，展示每种类型的示例

...（继续为所有幻灯片）
```

**步骤 2：生成每张幻灯片**

使用 `generate_slide_image.py` 脚本创建每张幻灯片。

**关键格式一致性协议**

为确保演示文稿中所有幻灯片的格式统一：

1. **定义格式目标** 在演示文稿开始时定义，并在每个提示中包含：
   - 配色方案（例如，“深蓝色背景 (#1a237e)，白色文本，金色点缀 (#ffc107)")
   - 字体样式（例如，“粗体无衬线标题，干净的正文文本")
   - 视觉风格（例如，“简约、专业、企业风格")
   - 布局方法（例如，“充足的空白区域，左对齐内容")

2. **在生成后续幻灯片时始终附加前一张幻灯片** 使用 `--attach`：
   - 这允许 Nano Banana Pro 查看并匹配现有风格
   - 在整个演示文稿中创建视觉连续性
   - 确保颜色、字体和设计语言的一致性

3. **默认作者为 "K-Dense"**，除非指定其他名称

4. **在提示中直接包含引用** 对于引用研究的幻灯片：
   - 在提示文本中添加引用，以便它们出现在生成的幻灯片中
   - 使用格式："包含引用：作者等，年份" 或 "显示参考文献：作者等，年份"
   - 对于多个引用，在提示中列出所有引用
   - 引用应出现在幻灯片底部的较小文本或相关内容附近

5. **附加现有图形/数据以用于结果幻灯片**（对于数据驱动演示文稿至关重要）：
   - 在创建关于结果的幻灯片时，始终检查以下位置的现有图形：
     - 工作目录（例如，`figures/`，`results/`，`plots/`，`images/`)
     - 用户提供的输入文件或目录
     - 任何与演示文稿相关的数据可视化、图表或图形
   - 使用 `--attach` 将这些图形附加到 Nano Banana Pro 以便将其纳入其中：
     - 将实际数据图形/图表附加到结果幻灯片
     - 将相关图表附加到方法幻灯片
     - 将标志或机构图像附加到标题幻灯片
   - 在附加数据图形时，在提示中描述您想要的内容：
     - "创建一张演示文稿，展示附加的结果图表，突出显示关键发现"
     - "围绕这张附加的图形创建一张幻灯片，添加标题和要点来解释数据"
     - "将附加的图表纳入结果幻灯片，并添加解释"
   - **在创建结果幻灯片之前**： 列出工作目录中的文件以找到相关图形
   - 可以附加多个图形：`--attach fig1.png --attach fig2.png`

**包含格式一致性、引用和图形附件的示例**：

```bash
# 标题幻灯片（建立风格 - 默认作者：K-Dense）
python scripts/generate_slide_image.py "标题幻灯片：'您的科研标题'. 会议名称，K-Dense. 格式目标：[您的配色方案]，简约专业设计，无装饰元素，干净的企业风格。" -o slides/01_title.png

# 内容幻灯片，带引用（附加前一张幻灯片以保持一致性）
python scripts/generate_slide_image.py "标题幻灯片：'为什么机器学习很重要'。三个要点，带有简单的图标。引用：在底部包含：Smith 等人，2023 年；Jones 等人，2024 年。格式目标：完全匹配附加幻灯片的风格。" -o slides/02_intro.png --attach slides/01_title.png

# 继续为每张幻灯片（始终附加前一张，在相关的地方包含引用）
python scripts/generate_slide_image.py "标题幻灯片：'方法'。关键方法要点。引用：基于 Chen 等人，2022 年。格式目标：完全匹配附加幻灯片的风格。" -o slides/03_methods.png --attach slides/02_intro.png

# 合并到 PDF
python scripts/slides_to_pdf.py slides/*.png -o presentation.pdf
```

**步骤 3：合并到 PDF**

```bash
# 将所有幻灯片合并到一个 PDF 演示文稿
python scripts/slides_to_pdf.py slides/*.png -o presentation.pdf
```

### PPT 工作流程：使用生成的视觉效果创建 PowerPoint

在创建 PowerPoint 演示文稿时，使用 Nano Banana Pro 生成图像和图表，然后使用 PPTX 技能单独添加文本。

**工作原理**：
1. **规划演示文稿**： 为每张幻灯片创建内容计划
2. **生成视觉效果**： 使用 `--visual-only` 标志使用 Nano Banana Pro 生成幻灯片的图像
3. **构建 PPTX**： 使用 PPTX 技能（html2pptx 或基于模板）创建带有生成视觉效果的幻灯片和单独的文本

**步骤 1：为每张幻灯片生成视觉效果**

```bash
# 为介绍幻灯片生成图形
python scripts/generate_slide_image.py "图表描述" -o figures/ml_applications.png --visual-only

# 为方法幻灯片生成图表
python scripts/generate_slide_image.py "神经网络架构图表，显示输入层、三个隐藏层和输出层。干净的技术风格，节点连接。蓝色和灰色配色方案。" -o figures/neural_network.png --visual-only

# 为结果生成概念图形
python scripts/generate_slide_image.py "前后比较，显示改进：左侧显示杂乱数据，右侧显示组织良好的见解。箭头连接它们。专业的商业风格。" -o figures/results_visual.png --visual-only
```

**步骤 3：使用 PPTX 技能构建 PowerPoint**

使用 PPTX 技能的 html2pptx 工作流程创建包含以下内容的幻灯片：
- 从步骤 1 生成的图像
- 标题和正文文本添加单独地
- 专业的布局和格式

有关完整的 PPTX 创建文档，请参阅 `document-skills/pptx/SKILL.md`。
