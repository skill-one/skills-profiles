# 市场研究报告

## 概述

市场研究报告是全面性的战略文件，通过分析行业、市场和竞争格局来为企业决策、投资策略和战略规划提供信息。这项技能可以生成**50页以上的专业级报告**，包含丰富的视觉内容，其交付成果借鉴了麦肯锡、BCG、贝恩、Gartner和Forrester等顶级咨询公司的标准。

**主要特点：**
- **全面的篇幅**：报告设计为50页以上，无标记限制
- **视觉丰富的内容**：开始时生成5-6个关键图表（根据需要写作过程中添加更多）
- **数据驱动分析**：与市场数据查询深度集成
- **多框架方法**：波特五力模型、PESTLE、SWOT、BCG矩阵、TAM/SAM/SOM
- **专业格式化**：咨询公司级别的排版、颜色和布局
- **可操作的推荐**：战略重点与实施路线图

**输出格式**：LaTeX带专业样式，编译为PDF。使用`market_research.sty`样式包，确保专业格式化。

## 使用此技能的场景

当需要以下情况时，应使用此技能：
- 创建用于投资决策的全面市场分析
- 开发用于战略规划的行业报告
- 分析竞争格局和市场动态
- 进行市场规模估算（TAM/SAM/SOM）
- 评估市场进入机会
- 准备并购活动的尽职调查材料
- 创建用于行业定位的思想领导力内容
- 开发市场进入策略文档
- 分析法规和政策对市场的影响
- 为新产品发布构建商业案例

## 报告结构（50页以上）

### 前置部分（约5页）

#### 封面页（1页）
- 报告标题和副标题
- 英雄视觉（生成）
- 日期和分类
- 面向/由谁准备

#### 目录（1-2页）
- 从LaTeX自动生成
- 图表列表
- 表格列表

#### 执行摘要（2-3页）
- **市场快照框**：关键指标一览
- **投资论点**：3-5个要点总结
- **关键发现**：主要发现和见解
- **战略推荐**：前3-5个可操作的推荐
- **执行摘要信息图表**：报告重点的视觉综合

### 核心分析（约35页）

#### 第一章：市场概述与定义（4-5页）

**内容要求：**
- 市场定义和范围
- 行业生态系统映射
- 关键利益相关者及其作用
- 市场边界和邻近区域
- 历史背景和演变

**必需视觉（2个）：**
1. 市场生态系统/价值链图表
2. 行业结构图表

**关键数据点：**
- 市场定义标准
- 包含/排除细分
- 地理范围
- 分析时间范围

---

#### 第二章：市场规模与增长分析（6-8页）

**内容要求：**
- 总可寻址市场（TAM）计算
- 可服务可寻址市场（SAM）定义
- 可服务可获取市场（SOM）估算
- 历史增长分析（5-10年）
- 增长预测（5-10年）
- 增长驱动因素和抑制因素
- 区域市场分解
- 细分级分析

**必需视觉（4个）：**
1. 市场增长轨迹图表（历史+预测）
2. TAM/SAM/SOM同心圆图表
3. 区域市场分解（饼图或树状图）
4. 细分增长比较（条形图）

**关键数据点：**
- 当前市场规模（带来源）
- CAGR（历史和预测）
- 市场规模按区域
- 市场规模按细分
- 预测的关键假设

**数据来源：**
使用`research-lookup`查找：
- 市场研究报告（Gartner、Forrester、IDC等）
- 行业协会数据
- 政府统计数据
- 公司财务报告
- 学术研究

---

#### 第三章：行业驱动因素与趋势（5-6页）

**内容要求：**
- 宏观经济因素
- 技术趋势
- 监管驱动因素
- 社会和文化转变
- 环境因素
- 行业特定趋势

**分析框架：**
- **PESTLE分析**：政治、经济、社会、技术、法律、环境
- **趋势影响评估**：可能性vs影响矩阵

**必需视觉（3个）：**
1. 行业趋势时间线或雷达图
2. 驱动因素影响矩阵
3. PESTLE分析图表

**关键数据点：**
- 顶级5-10个增长驱动因素及其量化影响
- 新兴趋势及其时间线
- 破坏性因素

---

#### 第四章：竞争格局（6-8页）

**内容要求：**

## 工作流程

### 第一阶段：研究与数据收集

**步骤1：定义范围**
- 明确市场定义
- 设置地理边界
- 确定时间范围
- 确定要回答的关键问题

**步骤2：进行深入研究**

使用`research-lookup`广泛收集市场数据：

```bash
# 市场规模和增长数据
python skills/research-lookup/scripts/research_lookup.py \
  "当前[市场]行业的市场规模和预测增长率是多少？包括TAM、SAM、SOM估算和CAGR预测"

# 竞争格局
python skills/research-lookup/scripts/research_lookup.py \
  "[市场]市场的前十大竞争对手是谁？他们的市场份额和竞争定位是什么？"

# 行业趋势
python skills/research-lookup/scripts/research_lookup.py \
  "2024-2030年[市场]行业的主要趋势和增长驱动因素是什么？"

# 监管环境
python skills/research-lookup/scripts/research_lookup.py \
  "[市场]行业的关键法规和政策变化是什么？"
```

**步骤3：数据组织**
- 创建`sources/`文件夹，包含研究笔记
- 按章节组织数据
- 确定数据差距
- 如有需要，进行后续研究

### 第二阶段：分析与框架应用

**步骤4：应用分析框架**

针对每个框架进行结构化分析：

- **市场规模**：TAM → SAM → SOM，明确假设
- **波特五力模型**：对每个力量进行高/中/低评级，并说明理由
- **PESTLE**：分析每个维度，并说明趋势和影响
- **SWOT**：内部优势/劣势，外部机会/威胁
- **竞争定位**：定义轴，绘制竞争对手

**步骤5：发展见解**
- 将发现综合为关键见解
- 确定战略影响
- 制定推荐
- 优先考虑机会

## 质量标准

### 页数目标

| 章节 | 最小页数 | 目标页数 |
|------|----------|----------|
| 前置部分 | 4 | 5 |
| 市场概述 | 4 | 5 |
| 市场规模与增长 | 5 | 7 |
| 行业驱动因素 | 4 | 6 |
| 竞争格局 | 5 | 7 |
| 客户分析 | 3 | 5 |
| 技术格局 | 3 | 5 |
| 监管环境 | 2 | 4 |
| 风险分析 | 2 | 4 |
| 战略推荐 | 3 | 5 |
| 实施路线图 | 2 | 4 |
| 投资论点 | 2 | 4 |
| 附加部分 | 4 | 5 |
| **总计** | **43** | **66** |

### 视觉质量要求

- **分辨率**：所有图像至少300 DPI
- **格式**：位图使用PNG，矢量图使用PDF
- **可访问性**：无障碍配色方案
- **一致性**：整个文档使用相同的配色方案
- **标签**：所有轴、图例和数据点都有标签
- **来源归因**：图表标题中引用来源

### 数据质量要求

- **时效性**：数据不超过2年（最好是当前年份）
- **来源**：所有统计数据都有具体来源
- **验证**：尽可能交叉引用多个来源
- **假设**：所有预测都说明其基本假设
- **局限性**：承认数据局限性和差距

### 写作质量要求

- **客观性**：平衡分析，承认不确定性
- **清晰度**：避免术语，定义技术术语
- **精确性**：使用具体数字而不是模糊限定词
- **结构**：清晰的标题，逻辑流程，平滑过渡
- **可操作性**：推荐是具体的和可实施的

## LaTeX格式化

### 使用样式包

`market_research.sty`样式包提供专业格式化。在您的文档中包含它：

```latex
\documentclass[11pt,letterpaper]{report}
\usepackage{market_research}
```

### 盒子环境

使用彩色框突出显示关键内容：

```latex
% 关键见解框（蓝色）
\begin{keyinsightbox}[关键发现]
市场预计将以15.3%的CAGR增长至2030年。
\end{keyinsightbox}

% 市场数据框（绿色）
\begin{marketdatabox}[市场快照]
\begin{itemize}
    \item 市场规模（2024年）：$45.2B
    \item 预测规模（2030年）：$98.7B
    \item CAGR：15.3%
\end{itemize}
\end{marketdatabox}

% 风险框（橙色/警告）
\begin{riskbox}[关键风险]
监管变化可能影响40%的市场参与者。
\end{riskbox}

% 推荐框（紫色）
\begin{recommendationbox}[战略推荐]
优先考虑在亚太地区进入市场。
\end{recommendationbox}

% 叫出框（灰色）
\begin{calloutbox}[定义]
TAM（总可寻址市场）代表总收入机会。
\end{calloutbox}
```
