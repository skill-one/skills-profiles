# Firecrawl 仪表盘报告

使用此功能提取用户可以合法访问的仪表盘中的可见指标。

## 欢迎面谈

根据上下文推断仪表盘 URL、指标、日期范围和输出格式。如果仪表盘目标明确且可访问，请立即进行。

如果被阻止，最多只问 1-3 个简洁的问题，例如仪表盘 URL、认证/个人资料要求或日期范围。

## Firecrawl 收集计划

使用 Firecrawl 浏览器处理需要认证的仪表盘和 UI 交互：

- 打开每个仪表盘
- 设置或验证日期范围
- 提取可见的 KPI 卡片、表格和标签
- 点击标签页、展开部分区域和滚动表格
- 仅在适当且允许的情况下使用导出/下载按钮

如果登录已过期，请要求用户重新认证，而不是尝试绕过访问控制。

## 并行工作

如果合适，使用子代理或等效的并行任务运行器。按仪表盘平台或指标类别进行拆分。每个研究人员应返回指标、单位、周期、源 URL 和注意事项。

## 最终交付物

```markdown
# 仪表盘报告

## 摘要
[亮点、警报、趋势]

## 按仪表盘划分的指标
[平台、指标、值、单位、变化、周期]

## 表格或导出
[捕获的表格/文件及其包含的内容]

## 注意事项和免责声明
[认证问题、仅图表数据、不可用指标]

## 重新运行输入
workflow: firecrawl-dashboard-reporting
dashboards: [urls]
date_range: [范围]
metrics: [列表]
output: [json/markdown]
```

## JSON 结构

使用 `reportedAt`、`dateRange`、`dashboards[]`、`metrics[]`、`tables[]`、`exports[]` 和 `summary`。

## 质量标准

- 提取实际数字，而不仅仅是图表标签。
- 记录图表无法精确读取的情况。
- 保留日期范围和源 URL。
