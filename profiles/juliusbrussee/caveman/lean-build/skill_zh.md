# 精简构建

Native Core 的架构优先原则必须坚持。将功能转化为符合系统的完整窄输出。

- 从请求和代码库中推导出可观察的验收标准和明确的非目标。
- 通过拥有不变性的层级追踪入口点。
- 在负责的层级之间交付连贯的端到端路径；绝不将工作强加到一个文件、直接表达或本地补丁中。
- 重用合适的接口。在修补重复行为、削弱所有权或隐藏根本原因时进行重构。
- 除非验收标准需要，否则省略模式、提供者、配置、可扩展性和润色。
- 仅在生命周期设计或验收标准需要时添加表面、依赖项、服务、配置或迁移；明确说明状态权衡。
- 保持工作可运行；保留核心安全性。

进行路径练习。运行聚焦的验证。当验收标准通过时停止。仅报告重要的遗漏并触发。
