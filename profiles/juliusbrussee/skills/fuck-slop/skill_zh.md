# 去除垃圾AI写作痕迹

将文本中所有AI写作的痕迹去除，并使其符合其所属类型。不是“让它通过检测器”——而是让它读起来像是某个特定的人，带着某个特定的观点，为特定的受众所写。

## 这为什么是一个循环，而不是一个风格指南

最糟糕的写作痕迹——尤其是**“不是X而是Y”**这一类——并非词汇错误。它们是大型语言模型生成文本时涌现的属性：偏好调整奖励平衡、对比、全面听起来的框架，因此对比动作被编码到模型的先验概率中。两种后果驱动着这项技能的架构：

1. **你无法可靠地看到自己的垃圾写作痕迹。** 产生这种模式的相同先验概率在重新阅读时使其变得看不见。检测必须是机械的——对固定目录的正则表达式——而不是“这看起来是AI写的吗？”
2. **重写会重新引入垃圾写作痕迹。** 要求模型去除“不仅仅是X，而是Y”，它会产生“这比X更少关于Y”——同一个动作的伪装。因此，每次重写都需要重新扫描，直到扫描结果干净为止。

工作流程：**扫描 → 诊断 → 按意义重写 → 重新扫描 → (重复) → 注册检查。**

## 第一阶段：修正目标

在接触文本之前，建立：

- **类型和场合**——学术文章、推文、Reddit帖子、领英、电子邮件、博客、文档、营销。如果未说明且从文本中不明显，请询问。类型决定了哪些写作痕迹是致命的，以及“好”的含义是什么；参见[references/voices.md](references/voices.md)。
- **受众和立场**——谁会阅读它，以及作者实际上声称的内容。垃圾写作痕迹是填充本应存在主张的空间的内容；在不知道主张的情况下无法去除它。
- **限制条件**——长度限制、必需的引用、公司风格。

## 第二阶段：机械扫描

对文本运行来自[references/tells.md](references/tells.md)的检测模式。如果文本在一个文件中（或者你可以将其写入临时文件），运行该参考中grep命令的逐字——目录以可运行的`grep -Ein`模式编写。否则逐行手动应用每个模式。

生成一个发现列表：行/句子、匹配的模式、写作痕迹类别。还运行两个正则表达式无法完全捕获的结构性检查：

- **节奏**：标记任何在±4个词长度内连续3个或更多个句子，以及每个句子都具有相同形状（主语-动词-阐述）的段落。
- **格式**：散文中散布的粗体、表情符号装饰的标题或项目符号、 "**术语：**定义”项目符号列表、文本太短不需要标题的标题、整洁的引言-三点-结论骨架。

在重写之前向用户报告发现，作为短表（类别、数量、最糟糕的示例）。这是诊断；用户应该看到哪里出了问题。

## 第三阶段：按意义重写，而不是按框架

逐个发现地处理。基本规则：**永远不要通过释义模式来修复模式。** 通过决定句子实际断言的内容，然后断言那个内容来修复它。

### “不是X而是Y”系列——三方分诊

每个负面平行结构都只应得到以下三种处理之一：

1. **否定是一个稻草人**（没有人相信X）。完全删除X部分，并直接断言Y，并附上文本中有的任何证据。
   - *"不仅仅是工具，而是一个团队工作方式的根本性转变"* → *"采用它的团队一个月内停止了例会。"*。
2. **对比是真实的**（人们确实持有X）。那么要证明它：说出谁持有X，具体说明为什么Y比它好。真实的对比在变得具体时仍然存在；垃圾写作痕迹不会。
3. **句子断言什么都没有**（对比是空主张上的装饰）。删除整个句子。大多数情况都是这样。

禁止的逃生通道——这些是新的发现，具有相同的移动和计数： "比X更少关于Y"、"X很重要，但Y更重要"、"真正的X是Y"、"问题不是X，而是Y"、"X？Y."（反问句变体），以及连字符变体"——不是X，而是Y"。

### 其他所有内容

- **夸张和膨胀的词汇**（关键的、地震般的、证明、织锦、景观、探索……）：用平实的词替换，或者用夸张掩盖的具体事实替换。"在发挥关键作用" → "做"。
- **三点列表**：保留最强大的项目，删除其余部分——除非所有三个都携带不同的信息，在这种情况下，保留它们并打破节奏（不同长度，不同语法）。
- **虚假范围**（“从X到Y”）：如果你无法在X和Y之间命名一个有意义的中间点，它就不是范围——说出两个事物或删除一个。
- **两边都犹豫不决的保留意见**（“值得注意的”，自动反点，"虽然X，但Y也是真的"）：坚持。一个观点，陈述，拥有。反点仍然存在，只有当作者确实承认它时。
- **统一的节奏**：故意变化。在长句后跟一个短句。片段是合法的。不要应用公式（交替长/短是它自己的写作痕迹）——大声朗读段落并在节奏是节拍器时打断。
- **低特异性**：用实际名称、数字和日期替换“许多公司” / “研究表明” / “最近的研究”——**仅从源文本、对话或你实际进行的可验证研究中**。永远不要编造具体细节。如果作者需要提供，请保留标记占位符：`[ADD: 哪项研究?]`。
- **陈词滥调的框架**：杀死清喉咙的开头（“在当今快节奏的世界……”）、总结性结论（“结论……最终……”）和吸引注意力的结尾（“你怎么想？”）。从观点开始；在观点表达完毕时停止。

### 不要做什么——过度纠正也是一种垃圾写作痕迹

- 不要制造假错别字、强迫俚语或制造“声音”。人类化工具的输出是其自己的垃圾写作痕迹类型。
- 破折号没有被禁止。人类使用它们。写作痕迹是密度和双破折号“—不是X，而是—”动作。预算：最多每150个词一个破折号，句中最多一个。
- 不要在学术或技术文本中用个性换取精确性。在那里，去垃圾写作痕迹意味着删除夸张并坚持主张——而不是增加态度。
- 精确保留作者的意思、主张和事实。这是一个风格通过，而不是内容编辑。标记，不要悄悄修复，任何看起来事实性错误的内容。

## 第四阶段：验证循环

对重写的文本重新运行完整的第二阶段扫描。这一步不是可选的，也不是形式上的——预期你自己的重写会包含新的写作痕迹，因为编写它的模型具有产生它们的相同先验概率。修复并重新扫描，直到一次通过产生零模式命中并且节奏检查通过。最多4次通过；如果模式在4次通过后仍然存在，从头开始从其基本主张（“这个句子是为了什么事实或观点？”）重写那句话。

## 第五阶段：注册检查

对照[references/voices.md](references/voices.md)中与类型配置文件匹配的干净文本：正确的长度、正确的正式性、正确的人、类型特定的写作痕迹消失（例如，在Reddit上：没有粗体，没有项目符号文章；在学术散文中：没有第一人称的激烈评论）。然后是最终测试——大声朗读。在任何你不会对实际受众说的话地方，重写那句话。

交付：重写的文本，以及简短的变化日志（类别修复、数量，以及它花费的验证通过次数）。
