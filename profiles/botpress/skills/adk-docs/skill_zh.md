# ADK 文档管理

在帮助用户为其 ADK 项目创建、审阅、更新或维护文档时使用此技能。用户为其自己的机器人和功能编写指南和文档——代码示例应来自其项目或官方 ADK 仓库。

## 何时使用此技能

在用户以下情况时激活此技能：

- 想要为其机器人创建文档（"记录我的订单工作流"、"为我的自定义操作编写指南"）
- 需要审阅现有项目文档的准确性（"我的文档是否仍然正确"）
- 想要在更改其机器人后更新文档（"我重构了结账流程，更新文档"）
- 需要检查文档是否与其代码同步（"我的文档是否为最新？"）
- 想要搜索其项目文档（"查找关于我的支付处理器的文档"）
- 询问文档标准或模板
- 提及 `/adk-document`

## 可用命令

| 命令（和建议的子命令）               | 描述                                           |
| ------------------------------------------------ | ----------------------------------------------------- |
| `/adk-document create [主题]`                   | 为用户机器人的功能创建文档                      |
| `/adk-document review [文档路径]`                | 审阅项目文档的准确性和完整性                   |
| `/adk-document update [文档路径] [已更改内容]` | 在代码更改后更新项目文档                      |
| `/adk-document sync [可选的文档路径]`         | 检查项目文档是否与机器人的代码同步             |
| `/adk-document search [搜索词]`             | 搜索项目文档中的特定主题                      |

## 共享原则

### 1. AI 优化的结构

- 清晰的章节标题（`##`、`###`、`####`），以便 ripgrep 可以找到章节
- 顶部有目录，并带有锚链接
- 根据文档类型适当大小（参见 doc-standards 参考）
- 关键词丰富的章节名称——没有模糊的"高级主题"或"其他"

### 2. 以代码为先的方法

- 每个概念都需要来自实际项目代码的可用代码示例
- 包括文件路径和行号以供验证
- 示例的主要来源（按优先顺序）：
  1. 用户的自己的 ADK 项目（在工作区中查找 `agent.config.ts`）—— 最佳
  2. 官方 ADK 仓库示例（克隆或本地查找）
  3. ADK 运行时使用（`@botpress/runtime` 包）
- 永远不要编造或推测示例——所有代码都必须可验证

### 3. 关键区别

- ADK 原语（来自 `@botpress/runtime`）与 Botpress SDK 原语
- 会话中的 `this.send()` 与工作流中的 `client.createMessage()`
- 消息（持久存储）与事件（短暂存储）
- 无关紧要的 API 与特定渠道的功能

### 4. 无推测

- 除非用户明确提供，否则不要添加常见错误或最佳实践部分
- 只有在记录实际报告的错误时才使用 `❌ WRONG` / `✅ CORRECT`
- 工作流和示例必须从实际代码中验证，而不是想象

### 5. 写作风格

- **直接和可操作**——"使用 `this.send()`"，而不是"你可能需要考虑..."
- **技术准确**——测试示例与实际 ADK 代码
- **假设智能**——提供上下文和指导，而不是手把手
- **无营销花哨**——直接到技术实质

## 如何回答

当用户询问关于文档而没有调用特定命令时：

1. **加载 `adk` 技能（以及更多，如果需要）**以获取 ADK 上下文和知识
2. **识别他们的需求**——创建、审阅、更新、同步或搜索
3. **指向正确的命令**或直接使用上述原则提供帮助
4. **参考 doc-standards**以获取模板和质量指导

## 文档位置

文档编写在用户的自己的项目中。如果位置不明显，询问用户想要将文档保存在哪里（常见位置：`./docs/`、`./guides/`或项目根目录）。

## 发现代码来源

发现用户的项目和官方 ADK 仓库以获取示例：

```javascript
// 在工作区中查找 ADK 项目
Glob({ pattern: '**/agent.config.ts' })

// 在用户的项目中查找 ADK 运行时使用
Grep({ pattern: 'from [\'"]@botpress/runtime', output_mode: 'files_with_matches' })

// 查找现有的项目文档
Glob({ pattern: './{docs,guides}/**/*.md' })

// 如果有官方 ADK 示例，则查找
Glob({ pattern: '**/adk/examples/**/*.ts' })
```

## 交叉引用

- **`adk` 技能**——核心 ADK 知识（操作、工作流、会话等）
- **`adk-evals` 技能**——测试和 eval 文档
- **`adk-frontend` 技能**——前端集成文档
- **`adk` 技能 `integrations.md` 参考**——集成生命周期文档
