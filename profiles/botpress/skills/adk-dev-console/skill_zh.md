# ADK 开发控制台

开发控制台是在 `adk dev` 过程中运行于端口 `3001`（默认，但可自定义）的本地应用程序。它为开发者提供了对其代理行为的实时可见性——对话、执行跟踪、数据、集成和配置。

开发控制台是一个**单例共享仪表板**：每个用户一个 UI 服务器，多个 `adk dev` 代理动态注册和注销。开发者可以在侧边栏中切换正在运行的代理，在开发和生产目标之间切换，并连接到已部署的云端机器人——所有这些都可以在同一个浏览器标签页中完成。

## 何时使用此技能

在用户询问以下内容时激活：

- **UI 概念** — "代理步骤是什么？"、"观察标签页显示什么？"、"什么是回合？"、"什么是组件注册表？"、"什么是代理地图？"
- **Agent(0) UI** — "Agent(0) 下的任务有哪些？"、"待办列表从哪里来？"、"为什么 Agent(0) 显示任务进度？"
- **开发控制台导航** — "有哪些可用的标签页？"、"我在哪里可以找到跟踪信息？"、"如何测试 RAG？"
- **读取执行数据** — "步骤代表什么意思？"、"为什么我的步骤是红色的？"、"显示的成本是什么？"
- **组件注册表** — "我在哪里可以找到自定义组件？"、"如何安装组件？"、"有哪些可用的组件？"
- **多代理仪表板** — "如何在不同代理之间切换？"、"如何运行多个代理？"、"代理选择器显示什么？"、"如何查看正在运行的代理？"
- **控制台模式和目标** — "开发和生产有什么区别？"、"如何连接到云端机器人？"、"什么是云端开发控制台？"
- **代理管理 CLI** — "如何列出正在运行的代理？"、"如何停止代理？"、"`adk ps` 显示什么？"、"如何打开仪表板？"
- **特定页面** — "如何使用评估页面？"、"我在哪里配置集成？"、"如何搜索知识？"
- **比较 UI 和 CLI** — "我应该在开发控制台或 CLI 中进行调试吗？"
- 提及 `localhost:3001`、"开发控制台"、"组件注册表"、"代理选择器"、"代理选择器"、"代理地图"、"云端开发控制台" 或特定标签页名称（聊天、构建、组件、数据、测试、观察、配置）

## 如何回答

与问题的深度相匹配：

- **"什么是 X？"**（例如，"什么是代理步骤？"）→ 一句话定义 + 用户看到的内容。不要堆砌完整的数据模型。
- **"我在哪里可以找到 X？"** → 指出标签页组和页面，给出 URL 路径。
- **"如何读取 X？"** → 解释视觉层次结构以及每个元素的含义。
- **"这个是什么意思？"**（指向 UI 中的某个内容）→ 识别组件，解释其含义。

### Agent(0) 任务停靠窗

当 Agent(0) 使用其待办工具时，面板会显示一个紧凑的 **任务** 停靠窗，包含已完成/总数、当前任务和可展开的任务列表。状态图标映射到待处理、进行中、已完成和已取消；优先级显示为低/中/高芯片。

### 多代理侧边栏

侧边栏标题显示当前选中的代理，带有状态指示器和模式药丸（开发/生产/云端）。点击它会打开 **代理选择器** 下拉菜单：

- **活动代理** — 所有带有状态点、名称、项目路径和关闭按钮的本地运行代理
- **云端开发控制台** — 切换到已部署的 Botpress 云端机器人（工作区 + 机器人选择器）
- **最近项目** — 之前打开但目前未运行的项目
- **页脚操作** — 创建新项目、打开现有、切换环境（开发↔生产）、关于

### 代理步骤（聊天页面）

聊天页面的右侧面板显示 **代理步骤** — 代理处理每条消息所执行操作的实时可视化。

**层次结构：** 回合 → 迭代 → 工具 / 消息 / 状态变更

- **回合** = 一次对话交换（用户消息 → 代理处理 → 响应）
- **迭代** = 代理的一个自主循环（思考 → 决策 → 行动）
- **工具** = 迭代中的一个工具调用（紫色卡片）
- **消息** = 发送的机器人消息（蓝色卡片）
- **状态变更** = 状态变更（蓝绿色卡片，显示前后）

**状态指示器：** ✓ 绿色 = 正常，✗ 红色 = 错误，⟳ 蓝色旋转 = 运行中

**每迭代的 AI 指标：** 模型名称、输入/输出令牌、成本（美元）

### 多代理 CLI 命令

| 命令         | 目的                                                                          |
| --------------- | -------------------------------------------------------------------------------- |
| `adk ps`        | 列出正在运行的代理和进程及其 PID、端口、运行时间（支持 `--watch`）                |
| `adk dashboard` | 以独立模式打开开发控制台（无需代理）                                           |
| `adk kill`      | 停止代理或整个开发控制台（`--all`、`--current`、`--pid` 或按名称）                |
| `adk status`    | 显示项目健康状态和状态信息                                                    |
