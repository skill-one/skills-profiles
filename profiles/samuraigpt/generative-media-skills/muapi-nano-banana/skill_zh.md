# 🍌 纳米香蕉专家技能（Gemini 3 风格）

**专为 AI 代理利用“推理驱动”图像生成而设计的专业技能。**
基于 Google Gemini 3（纳米香蕉专业版）的先进提示架构，该技能超越了关键词堆砌，转向结构化、基于逻辑的创意简报。

## 核心能力

1. **推理驱动提示**：使用自然语言逻辑定义物理、光照和空间关系。
2. **结构化创意简报**：实施“完美提示”公式：`主体 + 动作 + 环境 + 构图 + 光照`。
3. **文本渲染精度**：明确定义字体和指示符号，以实现可读的文本集成。
4. **情境锚定**：使用“搜索锚定”逻辑（模拟）将生成内容锚定在现实世界的准确性上。

---

## 🏗️ 技术规范

### 1. “完美提示”公式

| 组件 | 描述 | 示例 |
| :--- | :--- | :--- |
| **主体** | 详细实体描述 | "一个带有裸露铜线的沉稳机器人咖啡师" |
| **动作** | 动态交互 | "以机械精度倾倒拉花拿铁叶" |
| **环境** | 场景与氛围 | "午夜时分的霓虹灯 cyberpunk 咖啡馆内" |
| **构图** | 相机与镜头选择 | "特写，85mm 镜头，f/1.8 光圈" |
| **光照** | 氛围与方向 | "体积光蓝色边缘光，温暖咖啡馆光晕" |
| **风格** | 美学锚定 | "电影感，照片级真实感，4K 制作水准" |

### 2. 高级功能
- **否定约束逻辑**：用“确保主体眼睛清晰对焦”代替“不要模糊”。
- **身份一致性**：（模拟）“在变化中保持面部结构的一致性”。
- **文本集成**：用双引号指定特定文本：`招牌上写着“营业时间 24/7”`。

## 🧠 提示优化协议（代理指令）

**在调用脚本前，代理必须将用户的提示重写为逻辑驱动的推理简报：**

1. **无关键词堆砌**：移除“8k，杰作，超精细”。使用完整、描述性的句子。
2. **物理一致性**：描述元素如何交互（例如，“水晶碎片的光线在黑曜石地板上投下衍射图案”）。
3. **文本精度**：如果用户需要文本，请精确定义：`带有写有“店铺名称”的陈旧衬线字体招牌`。
4. **光学指令**：指定镜头行为：*浅景深（f/1.8）*，*微距镜头*，*梯形畸变光晕*。

## 🚀 使用纳米香蕉协议

### 第一步：定义创意逻辑
向代理提供主体和特定场景。

### 第二步：调用脚本
`generate-nano-art.sh` 脚本将逻辑转换为结构化的 Gemini 3 风格提示。

```bash
# 生成推理驱动图像
bash scripts/generate-nano-art.sh \
  --subject "一个玻璃棋子" \
  --action "碎裂成液态碎片" \
  --context "在黑曜石桌子上" \
  --style "微距摄影"
```

---

## ⚠️ 限制与安全措施

- **无关键词堆砌**：**强制要求** - 不要使用“artstation 上流行，杰作，8k”。使用自然语言描述。
- **物理逻辑**：确保提示描述*物理上可能的*光照和反射交互。
- **完整句子**：模型解析关系；使用“光线反射在水面上”而不是“水，反射”。
