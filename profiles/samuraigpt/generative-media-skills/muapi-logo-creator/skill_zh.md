# 🖼️ Logo Creator 技能

**AI 代理的专业品牌标识设计技能。**
Logo Creator 技能将品牌愿景转化为极简、可扩展、标志性的矢量风格标记。

## 核心能力

1. **几何基础图形构建**：使用基本形状（圆形、方形、三角形）创建令人难忘的图标。
2. **负空间操控**：通过策略性地使用空白空间融入次要含义。
3. **符号抽象化**：将复杂的品牌概念简化为其最简单的视觉本质。
4. **可扩展性意识**：确保设计从 16px（网站图标）到广告牌都能保持清晰。

---

## 🏗️ 技术规范

### 1. Logo 分类表

| Logo 类型 | 风格 | 适用场景 | 重点 |
| :--- | :--- | :--- | :--- |
| **图形标记** | 象征性 | 成熟品牌 | 标志性识别 |
| **抽象标记** | 几何形 | 科技/现代 | 概念/感觉 |
| **字母标记/花押字** | 字体设计 | 长名称 | 首字母/字体风格 |
| **徽章** | 传统式 | 机构/咖啡馆 | 细节/徽章 |
| **吉祥物** | 角色型 | 社区/游戏 | 个性 |

### 2. 品牌设计指南
- `色彩理论`：使用高冲击力的单色或双色调调色板以实现专业“分量”。
- `字体设计`：将标记与干净的几何无衬线字体（例如 Gotham、Helvetica 风格）搭配。
- `风格`：仅限扁平化设计。不使用渐变、3D 效果或照片真实纹理。

---

## 🧠 提示优化协议（代理指令）

**调用脚本前，代理必须将品牌愿景提炼为几何极简简报：**

1. **基础图形重点**：将概念简化为基本形状：*圆形、方形、三角形*。
2. **负空间**：明确指示模型使用*负空间*传达次要含义（例如，“字母之间的空间形成一个箭头”）。
3. **生产限制**：使用*纯色*、*单色调色板*，仅限*扁平化设计*。不使用渐变或 3D 效果。
4. **居中构图**：始终指定*白色背景上的独立展示*和*完美居中*以实现可扩展性。

## 🚀 使用 Logo Creator 协议

### 第 1 步：定义品牌简报
向代理提供品牌名称、核心价值和行业。

### 第 2 步：调用脚本
`create-logo.sh` 脚本生成全面的品牌设计简报。

```bash
# 设计金融科技 Logo
bash scripts/create-logo.sh \
  --brand "Aura" \
  --concept "几何安全盾牌与火花" \
  --style 极简 \
  --color "黑色和金色"
```

---

## ⚠️ 限制与安全措施

- **生产就绪**：**强制要求** - 仅限纯白/黑色背景。不使用纹理、桌面、模型（T 恤/名片）。
- **可读性**：避免细线或在小尺寸下消失的复杂重叠。
- **极简主义**：将标记限制在最多 3 个核心几何元素。
- **无伪影**：使用 Flux 准确渲染品牌名称在 Logo 内。

---

## ⚙️ 实现细节
此技能作为 `core/media/generate-image.sh` 基础图形的“高级品牌标识”层。它生成 `EXPERT_LOGO_BRIEF`，强制执行几何对称和负空间原则。
