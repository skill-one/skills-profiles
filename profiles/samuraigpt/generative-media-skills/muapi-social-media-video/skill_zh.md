# 社交媒体视频创作者

**端到端流程：品牌文件 → 故事板 → 参考图片 → Seedance 2.0 视频。**

读取您的品牌标识、ICP（目标客户画像）和沟通文件，以生成符合品牌调性的社交视频——完全优化以适应Seedance 2.0的指令提示语法和您的目标平台。

---

## 代理执行协议

### 第1步 — 读取品牌文件

在生成任何内容之前，代理必须读取所有可用的品牌文件。在工作目录或任何`brand/`子目录中查找它们：

| 文件 | 提取内容 |
|:---|:---|
| `brand-identity.md` | 视觉风格、调色板、语气、标志/产品美学、品牌个性 |
| `ICP.md` | 目标受众——他们的身份、痛点、激励因素 |
| `messaging.md` | 核心价值主张、钩子、行动号召、活动主题、口号 |

如果某个文件缺失，请使用现有内容继续并记录缺失项。

---

### 第2步 — 撰写社交帖子 + 故事板

使用品牌上下文生成：

**社交帖子文案**（用于标题/文案）：
- 钩子行（前1-2句话——必须停止滚动）
- 正文（3-5句话：问题 → 解决方案 → 证明 → 行动号召）
- 标签（5-8个相关标签）
- 行动号召（一个明确的行动）

**故事板**（匹配平台规格的时长）：
```
0–3s:  [开场场景——钩子/视觉惊喜——摄像机移动]
3–7s:  [核心信息——产品/主题在行动——摄像机移动]
7–10s: [解决方案——品牌时刻——屏幕上显示行动号召文本]
10–15s: [标志/口号停留——背景音乐淡出]
```

语气必须与品牌个性匹配。如果品牌是活泼的 → 节奏明快的转场，明亮的色调。
如果品牌是高端的 → 缓慢的揭示，奢华的暗调美学，情绪化的灯光。

---

### 第3步 — 构建Seedance 2.0导演提示

将故事板转换为Seedance 2.0的**技术导演简报**。

**规则：**
1. 不要使用模糊的描述（“美丽”、“惊人”、“8k”）。使用技术电影语言。
2. 始终指定摄像机移动、镜头类型和物理照明。
3. 对于10秒以上的视频，使用时间码片段：`0–3s: [...] 3–7s: [...] 7–10s: [...]`
4. 如果提供图片，集成`@image1`、`@image2`参考标签。
5. 始终包含声音方向（即使简短）——Seedance生成音频。
6. 以构图开头，以纹理和微动结束。

**导演简报模板：**
```
[场景] {环境、照明、一天中的时间}
[主体] {产品/角色/主题的特定细节}
[动作] {发生什么——流畅、连续、物理上可信}
[摄像机] {移动 + 镜头 + 构图}
[风格] {色调、情绪、如果有帮助的电影参考}
[声音] {音乐基调、音效、环境音}
0–Xs: {如果是多节拍}
```

---

### 第4步 — 生成参考图片（如果需要）

**何时生成参考图片：**

| 场景 | 模式 | 需要的图片 |
|:---|:---|:---|
| 产品展示 | `i2v` | 1张产品照片作为第一帧 |
| 场景过渡 | `first-last` | 2张图片——开场和结束帧 |
| 品牌角色 | `i2v` | 1个角色参考 |
| 纯概念 | `t2v` | 无——仅文本 |
| 情绪/风格锚点 | `i2v` | 1张风格参考图片 |

**图片生成——按用途推荐的最佳模型：**

| 用途 | 推荐模型 | 原因 |
|:---|:---|:---|
| 照片级真实产品/场景 | `google-imagen4-ultra` | 最高真实性，出色的照明 |
| 概念艺术 / 精致风格 | `flux-kontext-pro-t2i` | 创意保真度，风格遵循 |
| 最快周转 | `google-imagen4-fast` | 速度与良好质量 |
| 高度详细/编辑 | `hidream-i1-full` | 细节丰富，编辑质量 |
| 带身份的角色 | `ideogram-v3-t2i` | 强大的文本+角色渲染 |

**参考图片提示格式：**
编写干净、技术性的图片提示（不是Seedance提示）。包括：
- 主题描述 + 关键产品/品牌视觉元素
- 照明（工作室、黄金时刻等）
- 拍摄构图（中景、产品特写等）
- 情绪/色调匹配品牌标识
- 无运动语言（这是静态帧）

执行图片生成：
```bash
bash core/media/generate-image.sh \
  --model google-imagen4-ultra \
  --prompt "your image prompt" \
  --aspect-ratio 9:16 \
  --view
```

---

### 第5步 — 生成视频

根据内容类型和可用资源选择模式、等级和摄像机。

**模式选择：**

| 情况 | 模式 | 命令 |
|:---|:---|:---|
| 无参考图片 | `t2v` | 默认 |
| 1张图片（第一帧） | `i2v` | `--mode i2v --file ref.jpg` |
| 开始 + 结束帧 | `first-last` | `--mode first-last --tier global --file start.jpg --file end.jpg` |
| 多参考混合 | `i2v` | 最多9张图片 |

**调用脚本：**
```bash
bash library/social/social-media-video/scripts/run-social-video.sh \
  --prompt "your director brief here" \
  --platform instagram \
  --camera drone \
  [--mode t2v|i2v|first-last] \
  [--file ref_image.jpg] \
  [--gen-ref "reference image prompt"] \
  [--tier global] \
  [--quality high] \
  [--view]
```

## 平台规格

| 平台 | 格式 | 纵横比 | 时长 | 备注 |
|:---|:---|:---|:---|:---|
| Instagram Reels | 垂直 | 9:16 | 10–15秒 | 在前1秒内设置钩子 |
| Instagram Feed | 方形 | 1:1 | 10秒 | 静态感效果很好 |
| TikTok | 垂直 | 9:16 | 10–15秒 | 高能量，快速剪辑 |
| YouTube Shorts | 垂直 | 9:16 | 15秒 | 最高质量 |
| LinkedIn | 横向 | 16:9 | 10–15秒 | 专业语气 |
| Twitter/X | 横向 | 16:9 | 10秒 | 简洁直接 |
| YouTube（长） | 横向 | 16:9 | 15秒 | 电影感，缓慢构建 |
| Pinterest | 竖向 | 4:3 | 10秒 | 生活方式导向 |

> **等级注意：** 使用`--tier global`或`--tier vip`用于1:1和21:9格式。中文等级仅支持16:9、9:16、4:3、3:4。

## 摄像机语言参考

### 标准摄像机意图（--camera / --intent 标志）

| 意图 | 移动 | 最佳用途 |
|:---|:---|:---|
| `reveal` | 缓慢的俯仰上升，广角建立 | 产品发布，品牌揭示 |
| `epic` | 推车进入 + 轨道，低主视角 | 品牌宣言，情感故事 |
| `product` | 静态宏轨道，精确揭示 | 电子商务，产品演示 |
| `narrative` | 追踪镜头，稳定器 | 证言，故事驱动 |
| `tense` | 手持抖动，荷兰角 | 高能量，紧迫感 |
| `comedy` | 反应性手持，有力的变焦 | 轻松的品牌内容 |

### 特殊摄像机意图（新）

| 意图 | 描述 | 最佳用途 |
|:---|:---|:---|
| `fpv` | 第一人称主观视角——沉浸式GoPro风格，持续向前运动，周边细节特写 | 动作品牌，旅行，运动，技术演示 |
| `drone` | 航空电影飞越——平稳云台稳定，横向扫视，从高空下降进入场景 | 房地产，奢华，户外品牌，史诗揭示 |
| `flythrough` | 地面级建筑飞越——持续推车穿过空间，无缝门户过渡 | 建筑，室内设计，场地展示 |

**FPV提示增强：**
```
沉浸式第一人称视角镜头。摄像机在眼平高度滑过[场景]。
轻微的自然运动稳定，GoPro风格的广角。
周边细节飞驰而过——[细节]。平滑的持续向前运动。
全程无剪辑。[主体]在前景周边可见。
```

**无人机飞越提示增强：**
```
电影级航拍镜头。摄像机从200米高度下降至[主体/场景]，
下降过程中进行横向弧线扫视。云台稳定平稳运动。
黄金时刻氛围，长影横跨[地形/场景]。
最后一帧稳定为中等建立镜头。
航拍电影，DJI Inspire美学。
```

## 提示质量检查清单

在最终确定Seedance提示之前，请验证：

- [ ] 场景环境是物理上具体的（不是“美丽的背景”）
- [ ] 摄像机移动明确命名（推车进入，轨道，无人机飞越，FPV等）
- [ ] 照明描述技术性（体积光，轮廓光，柔和漫射等）
- [ ] 主题/产品描述包含品牌标识.md中的视觉细节
- [ ] 包含声音方向（即使一句话）
- [ ] 10秒以上视频使用时间码
- [ ] 如果提供图片，引用`@image1`等
- [ ] 在最后几秒包含品牌行动号召或口号
- [ ] 无模糊形容词（“惊人”、“美丽”、“惊人”）——用技术术语替换

## 示例：完整工作流程

**用户**： "为我们的冷萃咖啡品牌制作Instagram Reel，无人机拍摄，高端感"

**第1步 — 品牌读取**：读取`brand-identity.md`（极简包装，深烘焙，黑+金调色板），`ICP.md`（都市专业人士25-40岁，重视品质），`messaging.md`（"精准萃取。零妥协。"）

**第2步 — 故事板**：
```
0–2s:  无人机在日出时分飞越屋顶露台，下方有雾气。
2–5s:  无人机俯冲至白色大理石上的咖啡杯，蒸汽升起。
5–9s:  特写环绕瓶身，金色高光，冰块。
9–11s: 产品稳定，黑色屏幕淡入：“零妥协。”+标志
声音：极简轻音乐，5秒时咖啡倒入音效。
```

**第3步 — Seedance导演提示**：
```
0–2s: 电影级航拍无人机镜头。摄像机以30°角度下降至屋顶露台，日出时分。
黄金时刻氛围，旧金山湾区地平线下有雾。云台稳定平稳下降。
2–5s: 无人机快速接近露台上的一杯冷萃咖啡。
蒸汽向上盘旋。微距镜头接近。湿玻璃表面的衍射光图案。
5–9s: 缓慢精确环绕冷萃咖啡瓶。黑色磨砂标签上刻有金色凸起文字，反射高光。
冰块具有次表面光散射。商业微距美学。
9–11s: 静态产品主角镜头。画中画裁剪，深度焦点，从两侧淡入黑色。
声音：极简环境音乐，单个钢琴音符，5秒处有咖啡液体音效。
保持电影色调——深黑色，温暖金色中调。
```

**第4步 — 生成参考**：`google-imagen4-ultra` → 冷萃咖啡瓶产品照片（9:16）

**第5步 — 生成视频**：
```bash
bash library/social/social-media-video/scripts/run-social-video.sh \
  --prompt "0–2s: 电影级航拍无人机镜头..." \
  --platform instagram \
  --camera drone \
  --mode i2v \
  --file media_outputs/coldbrew_ref.jpg \
  --duration 11 \
  --tier global \
  --view
```

## 常见错误避免

1. **读取品牌文件但忽略它们**——故事板必须视觉上匹配品牌调色板和语气。
2. **通用提示**——"一个产品的好视频"产生通用输出。每个标记都必须指导。
3. **错误等级用于纵横比**——1:1和21:9需要`--tier global`或`--tier vip`。
4. **忘记声音**——Seedance生成音频。指导它，否则结果随机。
5. **FPV与静态主题**——FPV需要场景中的持续运动。与富含运动的环境搭配使用。
6. **无人机没有建立镜头**——无人机在进入某物（产品、场景、主题）时效果最佳。
7. **5秒内场景变化过多**——匹配复杂度与时长。5秒=1节拍。15秒=3-4节拍。
