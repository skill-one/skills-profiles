# 产品视频广告制作器

**从简单的产品照片开始，创建高端电影感的产品视频广告。**

## 输入

| 名称 | 类型 | 必填 | 默认值 | 描述 |
|:---|:---|:---|:---|:---|
| `product_image` | image_url | 是 | — | 用于广告的产品照片。 |
| `scene_description` | text | 否 | 被鲜花环绕和柔和的晨光 | 产品场景或背景的描述。 |


## 步骤

### 阶段 A — 高级产品渲染

如果 `{{product_image}}` 未提供，则提示用户上传产品照片。

照片可用后，提交计划，仅执行一步以在高级场景中重新渲染产品：

1. **产品渲染** — `muapi image edit` (模型=`flux-2-pro-edit`):
   - 参考图像: `{{product_image}}`
   - 提示: `参考图像中产品的高端、专业的商业照片，{{scene_description}}。柔和的影棚灯光，逼真的反射，电影景深，产品焦点清晰。8k分辨率，优雅和极简构图。`
   - 纵横比: 1:1 或 4:5

向用户展示高级产品图像以供审批。

### 阶段 B — 电影感视频广告生成

图像审批通过后，提交计划将其动画化为视频广告：

1. **视频广告生成** — `muapi video from-image` (模型=`wan2.5-image-to-video-fast`):
   - 参考图像: 阶段 A 中的高级图像。
   - 提示: `电影感产品广告视频。平滑、慢动作的摄像机运动扫过产品。微妙的环环境运动（例如，树叶摇曳，光线变化）。高质量的商业电影摄影，优雅的过渡，专业外观。`
   - 纵横比: 16:9 或 9:16

生成后，向用户展示最终的产品视频广告。

## 执行代理注意事项

- 此配方由 LLM 协调：读取每个阶段，从用户那里收集任何缺失的输入，然后调用 `muapi` CLI 命令。如果 `MUAPI_API_KEY` 未设置，请先使用 `muapi auth configure`。
- 对于尚未提供 CLI 别名 的模型 ID，通过 `curl -X POST https://api.muapi.ai/api/v1/<endpoint> -H "x-api-key: $MUAPI_API_KEY" -H 'content-type: application/json' -d '{...}'` 落回原始端点，并使用 `muapi predict wait <request_id>` 进行轮询。
- 在发出每个调用之前，用用户的实际输入替换 `{{input_name}}` 占位符。
