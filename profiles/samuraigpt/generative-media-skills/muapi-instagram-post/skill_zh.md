# Instagram 文章

**创建一个精美的、符合品牌的 Instagram 文章 — 方形或竖版英雄图片，并配上匹配的标题和话题标签。**

## 输入

| 名称 | 类型 | 必填 | 默认值 | 描述 |
|:---|:---|:---|:---|:---|
| `brief` | 文本 | 是 | — | 文章的主题（例如："我们在咖啡馆的夏日咖啡发布，温暖的金色氛围"）。 |
| `brand_style` | 文本 | 否 | 现代、活力四射、干净的字体、生活方式摄影美学 | 品牌个性和视觉风格标签。 |
| `format` | 文本 | 否 | 1:1 | 文章格式 — "1:1" 用于信息流方形，"4:5" 用于竖版信息流，"9:16" 用于 Reels。 |


## 步骤

此技能生成一个精美的、Instagram 适用的视觉效果 + 标题。如果生成多个变体，请使用此计划。

### 阶段 A — 生成英雄图片

1. 根据 `{{brief}}` 和 `{{brand_style}}` 写一个详细、富有氛围的图片提示：
   - 包括光线方向、色彩搭配、情绪、主体位置和镜头感觉。
   - 优化 Instagram 美学：干净、有力、单一焦点。
   - 添加风格标签：`{{brand_style}}, 社交媒体摄影, 高度详细`。
2. 调用 `muapi image generate` (模型=nano-banana-2, 纵横比=`{{format}}`)。
3. 如果用户在会话中提供了产品或主题图片，优先使用 `muapi image edit` 以保持视觉一致性。

### 阶段 B — 标题 & 话题标签

图片生成后，编写并返回：
- **标题**：2-4 行。首先使用钩子行（有力、引发好奇），然后是品牌信息，最后是行动号召。
- **话题标签**：15-20 个目标话题标签（混合专业、中档和广泛标签）。作为单独的块格式化。

## 注意事项
- 优先考虑阻止用户滚动的第一印象 — 图片必须在 2 秒内视觉传达简要内容。
- 如果 `format` 是 `9:16`（Reels 封面），请注意文本叠加是常见的；包括屏幕上文本放置的建议。
- 除非用户明确要求，否则不要生成多个变体。

## 触发关键词

`instagram post`, `ig post`, `instagram`, `feed post`, `instagram creative`

## 执行代理的注意事项

- 此配方由 LLM 协调：读取每个阶段，从用户那里收集任何缺失的输入，然后调用 `muapi` CLI 命令。如果 `MUAPI_API_KEY` 未设置，请先使用 `muapi auth configure`。
- 对于还没有 CLI 别名的模型 ID，通过 `curl -X POST https://api.muapi.ai/api/v1/<endpoint> -H "x-api-key: $MUAPI_API_KEY" -H 'content-type: application/json' -d '{...}'` 落回原始端点，并使用 `muapi predict wait <request_id>` 进行轮询。
- 在发出每个调用之前，用用户的实际输入替换 `{{input_name}}` 占位符。
