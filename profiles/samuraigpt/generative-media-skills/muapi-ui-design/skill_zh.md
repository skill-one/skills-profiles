# 🎨 UI/UX 设计原型制作技能

**AI 代理构建高保真数字界面的专业技能。**
UI/UX 设计技能将产品需求转化为高保真原型、线框图和设计系统的技术设计规范。

## 核心能力

1. **原子设计编排**：从原子（按钮）到有机体（页眉）构建界面，确保系统一致性。
2. **平台特定布局**：为移动端（iOS/Android）和网页（SaaS/电商）设计响应式断点。
3. **设计系统整合**：指定字体大小等级、间距标记和色彩调色板（十六进制/HSV）。
4. **启发式设计意识**：确保设计遵循既定的可用性原则（尼尔森十大可用性原则）。

---

## 🏗️ 技术规范

### 1. 意图映射表

| 创意意图 | 风格 | 布局模式 | 重点 |
| :--- | :--- | :--- | :--- |
| **企业级 SaaS** | 现代/简洁 | 仪表盘/网格 | 数据密度 |
| **消费级应用** | 玻璃态 | F 型/卡片 | 视觉特效 |
| **电商** | 极简主义 | Z 型/产品网格 | 转化率 |
| **作品集** | 原始主义 | 非对称 | 身份标识 |
| **工具/应用** | 新态 | 控制面板 | 触觉反馈 |

### 2. 设计标记与变量
- `字体`：技术类使用几何无衬线体（Inter/Roboto）；奢侈品使用衬线体（Playfair）。
- `间距`：8pt 网格系统确保一致的韵律间距。
- `色彩`：高对比度无障碍调色板（符合 WCAG 2.1 标准）。
- `层级`：基于阴影的深度与平面设计层。

## 🧠 提示优化协议（代理指令）

**调用脚本前，代理必须将用户需求扩展为设计规范：**

1. **原子结构**：提及具体组件（原子）：*玻璃态按钮*、*4px 边框的输入框*、*标志性侧边栏*。
2. **层级结构**：使用布局模式：*F 型*适用于内容密集型网站，*Z 型*适用于着陆页，*基于网格的仪表盘*。
3. **字体与标记**：注入设计标记：*Inter 无衬线体*、*8pt 间距系统*、*WCAG 高对比度色彩*。
4. **避免拟物化**：确保提示强制*平面设计*或*玻璃态*，避免“屏幕照片”结果。

## 🚀 使用 UI 设计器的协议

### 第一步：定义产品简报
向代理提供功能列表和目标受众。

### 第二步：调用脚本
`generate-mockup.sh` 脚本使用设计系统的内部知识扩展简报。

```bash
# 设计金融科技移动应用
bash scripts/generate-mockup.sh \
  --desc "加密钱包主页带价格图表" \
  --平台 mobile \
  --主题 dark \
  --风格 glassmorphism
```

## ⚠️ 限制与约束

- **设备真实性**：**强制要求** - 不得显示手部、实体手机或桌面。仅生成纯 UI/UX 原型。
- **无障碍性**：避免在亮背景上使用低对比度文本。
- **复杂性**：确保单页生成中“原子”保持一致。
- **文本渲染**：使用 Flux 确保可读的标题；为小号正文指定占位符文本。
