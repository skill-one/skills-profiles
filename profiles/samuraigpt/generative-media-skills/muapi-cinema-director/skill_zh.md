# 🎬 AI电影导演技能

**AI代理的专用技能，用于指导高保真度电影视频。**
电影导演技能将高级创意意图转化为技术电影指令，用于最先进的视频模型（Veo3、Kling、Luma）。

## 核心能力

1. **镜头构图分析**：将情绪节奏映射到合适的构图（例如，特写镜头用于亲密感，远景镜头用于孤立感）。
2. **摄像机运动编排**：指导复杂的物理运动（摇摄、移摄、升降镜头）和基于镜头的效果（聚焦切换、变焦镜头）。
3. **灯光与氛围设计**：指定时间性和风格化的灯光（黄金时刻、明暗对比、体积光）。
4. **技术参数优化**：自动选择最佳帧率、宽高比和模型特定的偏差。

---

## 🏗️ 技术规格

### 1. 意图映射表

| 创意意图 | 构图 | 运动 | 灯光 |
| :--- | :--- | :--- | :--- |
| **英雄登场** | 低角度/远景 | 升降镜头/环绕运动 | 轮廓光/高对比度 |
| **紧张/不安** | 倾斜角度 | 手持晃动 | 低光/硬阴影 |
| **内省** | 特写镜头 | 缓慢推入 | 柔和的伦勃朗式/窗户光 |
| **庄严/史诗** | 极端远景 | 飞行无人机 | 黄金时刻/体积光 |
| **忧郁** | 侧面/中景 | 缓慢拉出 | 蓝色时刻/去饱和 |

### 2. 物理摄像机运动
- `Dolly In/Out`：摄像机沿轨道向/远离主体移动。
- `Truck Left/Right`：横向物理运动。
- `Crane/Jib`：从高处扫过的垂直运动。
- `Orbit`：围绕中心点的圆形运动。
- `Pedestal`：垂直高度变化（不倾斜）。

### 3. 镜头与光学控制
- `浅景深`：背景模糊（焦外光）。
- `变形宽银幕`：水平光晕和宽银幕电影感。
- `聚焦切换`：在镜头内切换焦点。

## 🧠 提示优化协议（代理指令）

**在调用脚本之前，代理必须使用导演规则扩展用户的原始提示：**

1. **技术注入**：将“酷炫动作”转化为技术镜头。
   - *公式*：`[镜头类型] + [主体/动作] + [环境] + [灯光] + [摄像机运动] + [镜头效果]`
2. **运动动态**：使用电影动词：*Dolly In*（亲密感）、*Crane Up*（庄严）、*Orbit*（英雄）、*Truck*（平行运动）。
3. **灯光配方**：应用特定照明：*体积光*、*蓝橙色调*、*赛博朋克轮廓光*、*伦勃朗肖像灯光*。
4. **物理逻辑**：描述光线关系（例如，“霓虹灯在雨滑的柏油路上闪烁”）以触发模型推理。

## 🚀 使用电影导演协议

### 第一步：定义创意简报
向代理提供主题和“导演意图”。

### 第二步：调用脚本
`generate-film.sh` 脚本接受 `--brief`，它使用其内部电影摄影知识扩展该简报。

```bash
# 指导一个场景
bash scripts/generate-film.sh 
  --subject "一个孤独的武士在暴风雪中" 
  --intent "史诗登场" 
  --model "kling-master"
```

### 第三步：处理异步响应
视频生成是异步的。使用返回的 `request_id` 通过 `core/platform/check-result.sh` 进行轮询以检查完成情况。

## ⚠️ 限制与安全措施

- **时间一致性**：避免在单个镜头中复杂地变换主体（例如，“男人变成鸟”）。
- **运动冲突**：不要同时组合矛盾的运动（例如，“Dolly In”和“Dolly Out”）。
- **物理真实性**：优先选择使用真实设备可能实现的运动，以获得更专业的“电影”外观。
- **模型偏差**： 
  - `Veo3`：最适合慢速、高质量美学镜头。
  - `Kling`：最适合复杂角色运动和物理。
  - `Luma`：最适合快节奏、高动作电影序列。
