# 论文写作

## 概述

使用此技能将研究论文改写成给审稿人看的、高清晰度的草稿。
优先考虑第一印象质量（图表/表格/布局）、逻辑流程和有证据支持的论点。

## 核心工作流程

1. 在句子级别的修改之前，先理清论文的故事线。
2. 使用 `references/` 中的各章节特定指导。
3. 逐段重写，每段只传达一个信息。
4. 写完每个章节后运行逆向提纲。
5. 检查摘要/引言中的每个主要论点是否与实验证据相符。
6. 使用 `references/paper-review.md` 运行最终论文的对抗性审阅。

## 全局原则

1. 每个段落只表达一个信息。
2. 在段落的第一句话中陈述段落信息。
3. 使名词自包含；在使用新术语之前定义它们。
4. 保持句子之间的流程（因果关系、对比关系、结果或细化）。
5. 进行对抗性自我审阅：像一位怀疑的审稿人那样阅读。
6. 将视觉质量视为核心内容，而不是装饰。
7. 使用简洁的引言图和流程图。
8. 使用易读的、墨迹最少的表格。
9. 保持格式一致且整洁。

## 段落清晰度检查（重要）

每当用户询问段落是否“流畅”或清晰时，使用此快速测试。

1. 像外部读者一样阅读：
   - 这个段落是否有一个明确的信息？
   - 第一句话是否说明了这段话要做什么？
   - 所有关键名词/术语是否无需隐藏背景就能理解？
   - 每句话是否与上一句有明确的关联（因果关系、对比关系、结果或细化、例子）？
2. 对当前章节运行逆向提纲：
   - 写下论点/主要论点。
   - 写下每个段落的主题句。
   - 写下每个段落下的证据/解释点。
   - 检查映射：主题句 -> 论点，证据 -> 主题句。
   - 修改或删除任何无法清晰映射的段落。
3. 如果流程仍然较弱，在修订过程中添加临时的章节标题和明确的过渡短语，然后在最终确定之前删除不必要的标题。

此检查的来源参考：

- `references/does-my-writing-flow-source.md`

## 论文审阅核心要点

使用 `references/paper-review.md` 获取完整的检查清单和工作流程。

1. 在草稿结束时添加五个维度的自我审阅问题清单：
   - 贡献，
   - 写作清晰度，
   - 实验强度，
   - 评估完整性，
   - 方法设计合理性。
2. 将论点-证据一致性视为硬约束，特别是对于摘要和引言。
3. 进行对抗性写作：像一位怀疑的审稿人一样审阅，并解决每个高风险问题。
4. 修改直到明确解决了主要的拒绝风险。

## 执行规则

1. 在撰写散文之前构建一个迷你提纲。
2. 对于每个子章节，在适用的情况下明确包含动机、设计和技术优势。
3. 避免看起来像是对朴素基线的增量补丁的写作风格。
4. 在整篇论文中保持术语稳定。
5. 如果一个论点无法由结果支持，则削弱或删除该论点。
6. 在最终确定之前，附加并回答一个五个维度的自我审阅问题清单，然后根据未解决的问题修改论文。
7. 不要一次加载所有章节参考（引言/摘要/相关工作/方法/实验/结论）；只加载当前编辑目标所需的特定章节指南。

## 输出契约

当被要求重写或起草章节时，返回：

1. 一个紧凑的章节提纲（3-7个要点）。
2. 带有明确段落角色（开场/挑战/方法/优势/证据/局限性）的修订段落。
3. 一个涵盖清晰度、流程、术语一致性、未支持的论点和缺失证据的简短自我审阅清单。
4. 使用 `Claim: ... | Evidence: ... | Status: supported/needs evidence` 对修订文本中的每个主要论点进行论点-证据映射。
