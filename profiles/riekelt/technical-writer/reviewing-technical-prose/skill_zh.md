# 审阅技术性文本

**必要背景：** `技术写作` 技能，包括 `参考资料/风格.md`（禁止的结构）和 `参考资料/事实.md`（主张规则）。

## 概述

编辑就是诊断。每次编辑都要指明它修复的具体缺陷；能修复该缺陷的最小编辑胜出。在未指明缺陷的情况下重写自然语言或已批准的文本本身就是一种缺陷。

审阅完整文档，而不是它的摘要。

## 何时使用，以及何时不用

在审阅或重写他人技术文本、撰写文档的调查报告，以及在你自己撰写的任何内容交付前的最终检查时使用。**绝对不要**用于代码审查（仅审查其中的文本），并且不要使用审阅轮次来重新辩论已决定的决策、扩大范围或按照你自己的偏好重新编排文档。

## 严重程度映射

- **阻断项**：硬性规则违规（禁止的连字符、版本日志部分、文本中的交付历史）以及任何来源不支持的主张或追溯到无源的主张。
- **警告**：禁止的结构、结构性缺陷（疑问标题、隐藏的结论、可重新排列的段落），以及仅勉强支持的主张。
- **观察项**：歧义、缺失的润色，以及任何专注的作者可能会发现的问题。

## 重写他人文本

以上所有规则中，有一条是至高无上的：**内容必须保持完全一致。** 按以下顺序工作：

1.  阅读源文本。标记每一个禁止的结构和用词违规。
2.  写一个版本。大声朗读它。
3.  提出三个控制问题：
   - 哪个句子仍然听起来像语言模型？
   - 重写是否添加或删除了事实、数字、日期、名称、来源或主张？
   - 重写是否以新的修辞形式重新创造了被删除的模式？

   将重写的段落当作源文本重新扫描。

4.  修复控制问题暴露的问题。增加和删除都算作错误，即使文本因此读起来更好。

永远不要为了完成句子而添加事实：询问作者或选择一个更简单的句子。如果一个句子在两次尝试后仍然显得生硬，就围绕其要点重写整个段落。仅修改运行文本：代码块、前导元数据、表格数据和链接目标保持不变。

- **重写保持文档的语言。** 一份荷兰语文档将以荷兰语返回，结构性和真实性规则始终适用；如果该语言有相应的词汇检查列表，则用该语言自己的列表替换英语特定的词汇检查。
- **当作者可联系时，差异比较是提议。** 在覆盖他们的文本之前展示重写版本。在仓库中未受关注的提交是提议，审阅执行相同的工作。

当源文本断言无恢复内容（设置、注释、意义句子）时，正确的重写是删除加上一个标记的空白（`**[需要输入：<句子应主张的主张]****`，核心技能的 `**[需要来源：...]****` 的主张级兄弟），在那里应该有一个真实的主张。一个满是标记空白的重写是主张来源文本的预期结果，而不是失败。

## 留待保留的调查结果

禁止结构列表本身并不能证明任何东西；每个模式也出现在良好的人类写作中。仅在同一个段落中同时出现多个迹象时才标记。

- 光滑的语法和一致的格式。
- 一个重复的句子开头：仅在重复无意义时才修复。
- 一个短句用于强调：只有当一排片段是一个问题时才是一个问题。
- 一般的正式词汇：列表命名特定词汇；并非每个正式词汇都需要简化。
- 一个事实性对比："管道设置标签，开发者不设置"是一个陈述，而不是反讽。
- 一个读者会认真权衡的严重替代方案：它属于文档。
- 限定词：范围、假设和安全或法律注释保持不变。只有堆叠会改变。
- 对迁移文档或版本说明中先前情况的引用：在那里变化是主题。
- 一个引用词：永远不会在引文、标题或讨论该词的示例内部重写。
- 解释性的隐喻：只有围绕它的装饰会改变。
- 故意的不协调：一个清晰的片段或不平衡的句子仅仅因为可以被润色而不会是一个缺陷。

## 审阅报告

- 第一行是裁决，调查结果按最严重程度排序。
- 报告中使用的严重程度词汇定义：**阻断项**（无法继续），**警告**（可能需要重做；修复但不阻断），**观察项**（值得注意）。
- 每个调查结果：一个陈述缺陷的句子、位置（`文件:行号`、章节、任务 ID）、建议的修复和置信度。
- 一个命名的空案例（"调查结果：无"）。
- 文档主张与代码矛盾是一个文档缺陷；报告它与冲突来源一起。在旁路中注意到的不相关错误不是你的调查结果。
- 重新审阅仅列出剩余内容。
- 承认好的地方。

## 交付清单

在文档发出前：

- [ ] **与同一目录中的现有文档匹配**，如果存在则添加到 `README.md` 索引
- [ ] **无连字符、半连字符或 ` -- `**；无版本日志部分或“最后更新”字段；文本中无工单键、阶段或 SHA
- [ ] **无禁止结构**（`技术写作` 技能的 `参考资料/风格.md`）；至少检查摘要和结尾段落
- [ ] **标题命名内容**：无疑问形式，无“X是什么意思”，无标题在其第一句中重复
- [ ] **结论优先**：在文档、章节和段落级别
- [ ] **程序**：每句一个动作，有执行者
- [ ] **文档提议或决定的地方**：每个非平凡的选择都有其推理和严重的替代方案记录，成本不仅在于收益
- [ ] **事实和提议可区分**；估计有标签；未知项明确未知
- [ ] **每个与数字相关的主张**都追溯到文档中命名的来源
- [ ] **通过跟随它们检查引用**：章节编号、相对链接和文件名确实存在
- [ ] **术语一致**并在首次使用时定义；每个概念一个术语
- [ ] **大声朗读**：至少摘要；无片段行，无三个句子有相同的开头
- [ ] **对开头和摘要进行删除名称测试**：删除产品名称后，陌生人仍然可以知道文本是关于什么的
- [ ] **冷读，整读**：对从未见过产生它的对话或反馈轮的某人不自然；整个声音，无拼凑的接缝，无解释为什么这样写文档的句子
- [ ] **在重写时**：无事实、数字、日期或来源添加或丢失
