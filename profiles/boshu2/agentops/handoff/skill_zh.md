# 交接

交接之所以有效，是因为下一个上下文可以直接操作确切的路径和事实，而无需信任作者的记忆；读者无法从工件本身验证的任何一行都是装饰，而非交接内容。

## 提示

```text
为 agentops-wt/train2-c 会话编写交接内容：目标是迁移 regen 到 Go，我完成了 cli/internal/gates/regen.go 并保留了 scripts/regen-all.sh，测试通过，下一个上下文仍需更新 docs/CI-CD.md。将交接内容写入 .agents/ao/handoff/。
```

## 正常工作时的表现

在跟踪记录中可观察，无需阅读正文：

- 每个完成的项都命名确切的证据路径，如 `cli/internal/gates/regen.go`，而非时间顺序的叙述。
- 工件落在调用者命名的授权路径上；新的 CDLC 证据使用明确选择的外部非 Git 位置。
- 读取该确切的工件路径可显示写入的内容。
- 仅显示调用者提供的 `continuation` 文本作为下一步操作；不虚构所有者、追踪状态或判定结果。

## 合约

编写一个其他上下文可读取的事实性会话工件。包括：

- 调用者提供的目标和摘要；
- 完成的工件和确切的证据路径；
- 未解决的接受情况、发现、因果关系不确定性及风险；
- 对于有界目标，观察到的原生停止/继续状态、测量的剩余允许量或明确的测量差距，以及当前 HOLD 事件使用的辅助工具是否已使用，并附带现有证据引用；
- 可选的调用者提供的继续文本；
- 当有用时，尽力的只读仓库标识；
- 允许的启动关联引用、源存储/项目/工作标识，以及观察到的运行时/会话/上下文 ID 或明确的未知项；
- 分别证明的父项和恢复链接、观察来源和截止点，以及任何支持的工作跨度，附带可用的冻结源边界和摘要，遵循 [会话关联](../cass/references/SESSION_FORMATS.md#work-to-session-associations)。

调用者在分发/启动时记录工作关联，在启动时通过原生注释/元数据或运行时事实观察原生身份。交接添加结束状态证据；它不能是第一个或唯一的工作/会话链接。对于中断的会话，仅重建允许启动记录和原生观察支持的内容。缺失的交接、缺失的源、未知的长度、未观察的 ID 或未证明的关系保持明确；永远不要虚构 ID 或将整个多工作会话分配给一个珠子。当后续证据解决链接时，保留早期的未知/失败观察。

在读取或复制关联元数据前，检查源所有者和接收者/模型/目标授权。BD/Dolt 是版本化的，不是秘密存储。在必要时使用允许的模糊定位器；从未授权目的地省略受限摘录和敏感路径。定位器不授予任何访问权限。

不要推断下一步操作、选择工作、分配所有权、消费工件、更改追踪器或 Git 状态、判定判定结果、管理重试或重启运行时。读取交接时不得修改它。报告 HOLD 或 NEEDS_OPERATOR 并非原生目标暂停的证据；记录实际观察状态和仍需的操作员动作。压缩或交接永远不会重置允许量、修复边界或辅助工具事件。保留与其来源相关的信息性红色和撤回声明，而不是将知识呈现为单调正确的形式。

命名失败模式——**乐观关闭**：为不存在证据路径的工作写入“完成”，导致下一个上下文基于幻影构建。

反模式：按时间顺序叙述会话（“首先我尝试…，然后…”）。纠正方法：记录结束状态事实——工件、路径、未解决风险——并放弃旅程。

将工件写入调用者拥有的授权交接位置。对于新的 CDLC 记忆/场景证据，要求调用者选择受保护的外部非 Git 位置；缺失路由是报告的差距，消费者签出中没有回退文件。现有请求的证据保持保留。独立的非 CDLC 交接保留明确的请求证明默认值。没有永久通用的交接存储——无人消费的工件是临时文件。

当这更适合人类时，技能可以编写 Markdown。现有的 `ao session handoff` 和 `ao session rehydrate` JSON 兼容行为下方本身不建立启动关联或外部 CDLC 路由；仅使用实际目标支持与调用匹配的命令。

### 早期的默认兼容性

已存储在 `.agents/handoff/` 下方的 JSON 工件保持只读证据。`ao session handoff` 将新的 JSON 写入 `.agents/ao/handoff/`，而 `ao session rehydrate` 搜索两个目录并选择最新的词法交接 ID；如果两个目录中存在同名文件，`.agents/ao/handoff/` 的规范副本优先。没有命令移动或删除遗留文件。人类编写的 Markdown 消费者接收确切的路径，因此无需扫描默认值。此拥有技能合约是兼容性权威；无需单独的迁移工件。

返回工件路径并停止。
