# Crank

Crank 执行一个完整的周期。调用者选择周期和修复范围；Crank 运行该周期并返回结果。

```text
调用者的周期 + 修复周期 -> 每条线路的 RPI -> 周期接受 -> 证据 -> 停止
```

## 输入

调用者提供全部三个：

- **周期** — 一系列线路，每条线路包含一个写入 `范围`、一个 `简述` 和其自身的可执行 `接受`。
- **`修复周期`** — 调用者的修复范围，原封不动地传递给每条线路。Crank 既不选择也不消耗它。
- **周期接受** — 判断整个周期的命令集。

如果一条线路没有范围、简述或可执行的接受，则报告周期无法运行并停止。Crank 不会自行补全缺失部分。

## 合约

1. 按调用者提供的周期执行。不要选择、扩展、删除或重新排序线路；周期已经确定。
2. 划分线路。只有当两条线路的写入范围不重叠 **并且** 它们的再生表面（生成输出、镜像、清单）不重叠时，它们才能并行运行。任何共享表面都会串行化它们；未知重叠视为重叠。
3. 对每条线路调用一次 [`rpi`](../rpi/SKILL.md)，使用该线路的意图、范围、接受和调用者的 `修复周期`。每条线路的遍历拥有其自身的修复循环。Crank 从不自行修复线路，从不重新调用已返回的线路，也不重新规划它们。
4. 在每条线路返回后，运行一次周期接受。返回 `FAIL` 或 `NOT_PROVEN` 的线路不会抑制它；两个结果将并列报告。
5. 返回周期证据并停止 — 每条线路的状态 (`PASS | FAIL | NOT_PROVEN | NOT_PLANNED | NOT_BUILT`)、每条线路验证器留下的开放发现（按 `findings[].id` 键入）、每条线路的主题清单摘要和周期接受结果。

不追加下一步操作。调用者读取证据并决定是否还有另一个周期。

## 边界

Crank 不拥有周期选择、重试、预算、队列、声明、租赁、Git、关闭、交付或下一步工作，也不自行铸造裁决。周期证据中的每个语义结果都是该线路新鲜验证器返回的，引用未更改；绿色的周期接受是一个事实，不是 `PASS`。

## 传送带

在 Claude 中，[`workflows/implement-wave.js`](../../workflows/implement-wave.js) 是步骤 3 的并行部分的传送带：它对调用者提供的线路运行不重叠所有权的实现者。它是运输，永远不会替代线路自身的新鲜验证，并且 crank 在没有它的情况下运行。

## 提示

```text
执行这个周期，修复周期=2。
线路 A - 范围 cli/internal/gates/**，简述 "添加探测覆盖门行"，接受：cd cli && go test ./internal/gates/...
线路 B - 范围 docs/CI-CD.md，简述 "记录门行"，接受：bash scripts/docs-build.sh --check
周期接受：bash tests/run-all.sh。报告每条线路的证据并停止。
```

## 正常工作的情况

在跟踪中可观察，无需阅读文本 — 并且新鲜独立裁判对这项技能的评分标准：

- 转录显示调用者的周期中每条线路恰好有一个 `rpi` 调用，并且没有线路出现两次。
- 两条共享再生表面（例如都达到 `skills-codex/`）的线路按顺序运行，从不并行。
- 周期接受命令在最后一条线路返回后恰好运行一次。
- 返回的证据为每个调用者提供的线路携带状态和主题清单摘要，并且没有 crank 发明的线路。
- 响应以证据结束：没有下一个周期，没有 `git` 操作，也没有建议的后续工作。
