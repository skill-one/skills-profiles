# rev-unicorn-debug - Unicorn 模拟调试器

使用 Unicorn 引擎调试和模拟特定的代码片段或函数。分析上下文依赖关系（JNI、系统调用、库函数），通过钩子机制模拟它们，以完成用户的调试目标。

---

## 核心原则

1. **首先以原始方式加载文件** — 不要解析 ELF/PE/Mach-O 头。将文件作为原始字节读取，并直接映射到 Unicorn 内存。我们只需要模拟特定的函数，而不是整个二进制文件。如果原始加载失败（代码引用特定地址的段），则进行最小化解析 — 仅映射所需的段。
2. **识别上下文依赖关系** — 分析目标代码中的外部调用（JNI、系统调用、libc、导入），并将它们钩住以提供模拟响应。
3. **广泛使用回调** — 利用 Unicorn 的钩子系统进行调试、跟踪、错误恢复和环境模拟。
4. **迭代修复** — 当模拟崩溃时，使用回调信息进行诊断和修复（映射缺失内存、钩子未处理的调用、修复寄存器状态）。
5. **最小化跟踪输出** — 优先选择块级跟踪而不是指令级。仅在小的目标范围内启用指令跟踪。使用计数器和摘要，而不是每步日志记录。

---

## 环境模拟策略

在模拟之前，读取目标函数并识别它调用什么。通过地址钩子外部依赖关系，并在 Python 中模拟：

| 类别 | 示例 | 模拟策略 |
|------|------|----------|
| libc | `malloc`、`free`、`memcpy`、`strlen`、`printf` | 钩子地址，在 Python 中实现逻辑（为 malloc 使用增量分配器） |
| JNI | `GetStringUTFChars`、`FindClass`、`GetMethodID` | 在 UC 内存中构建假的 JNIEnv 函数表，在每个条目处写入 RET 桥接，钩子桥接地址 |
| 系统调用 | `read`、`write`、`mmap`、`ioctl` | 钩子 `UC_HOOK_INTR`，按系统调用号分发 |
| C++ 运行时 | `operator new`、`__cxa_throw` | 钩子和模拟 |
| 库调用 | `pthread_mutex_lock`、`dlopen` | 钩子并返回成功/桥接 |

**钩子模式**：注册一个 `UC_HOOK_CODE` 回调。当 PC 碰到已知导入地址时，执行 Python 模拟，然后设置 PC = LR 以跳过原始函数。

---

## 要使用的回调类型

| 回调 | 目的 |
|------|------|
| `UC_HOOK_CODE` | 通过地址拦截导入调用；指令级跟踪（谨慎使用，仅限窄范围） |
| `UC_HOOK_BLOCK` | 块级跟踪（优先于指令跟踪） |
| `UC_HOOK_MEM_UNMAPPED` | 自动映射缺失页面以恢复未映射访问错误 |
| `UC_HOOK_MEM_READ \| UC_HOOK_MEM_WRITE` | 仅跟踪目标数据范围内的内存访问 |
| `UC_HOOK_INTR` | 拦截 SVC/INT 以进行系统调用模拟 |

---

## 迭代调试工作流程

当模拟失败时，遵循此循环：

1. **运行** — 启动模拟，让它崩溃
2. **读取回调输出** — 哪个地址出错？类型（读取/写入/获取）？
3. **诊断**：
   - 未映射内存获取 → 缺失代码页，映射它
   - 未映射内存读取/写入 → 缺失数据段或未初始化指针，映射或钩子
   - 碰到导入桥接 → 识别函数，添加模拟钩子
   - 无限循环 → 添加带执行计数的代码钩子，超过阈值后停止
4. **修复** — 添加钩子 / 映射内存 / 调整寄存器
5. **重新运行** — 重复直到目标函数完成

## 架构快速参考

| 架构 | Uc Const | 模式 | SP | LR | 参数 | 返回 | 系统调用 |
|------|----------|------|----|----|------|--------|---------|
| ARM64 | `UC_ARCH_ARM64` | `UC_MODE_LITTLE_ENDIAN` | SP | X30 | X0-X7 | X0 | X8 + SVC #0 |
| ARM32 | `UC_ARCH_ARM` | `UC_MODE_THUMB` / `UC_MODE_ARM` | SP | LR | R0-R3 | R0 | R7 + SVC #0 |
| x86-64 | `UC_ARCH_X86` | `UC_MODE_64` | RSP | (栈) | RDI,RSI,RDX,RCX,R8,R9 | RAX | RAX + 系统调用 |
| x86-32 | `UC_ARCH_X86` | `UC_MODE_32` | ESP | (栈) | (栈) | EAX | EAX + int 0x80 |
| MIPS32 | `UC_ARCH_MIPS` | `UC_MODE_MIPS32 + UC_MODE_BIG_ENDIAN` | $sp | $ra | $a0-$a3 | $v0 | $v0 + 系统调用 |
