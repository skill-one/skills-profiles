## 如何路由

1. 读取用户消息并识别其所属类别
2. 告知用户正在路由至哪个技能
3. 完全遵循该技能的 SKILL.md 文件

如果意图不明确，请要求用户澄清：

```
问题: "您想创建什么？"
选项:
  - "ListenHub 语音" — 端到端音频：音效、多音色对话、参考音频克隆、图片→音频
  - "语音克隆" — 将您自己的声音克隆为可重用的扬声器
  - "播客" — 关于某个主题的音频讨论
  - "解说视频" — 带有 AI 视觉的旁白视频
  - "幻灯片" — 幻灯片演示文稿/演示
  - "音乐" — AI 音乐：生成、混音、纯音乐、配乐、分轨、人声克隆
  - "视频" — 从文本或参考材料生成 AI 视频
```

## 前置条件

大多数技能需要 ListenHub CLI。检查：

```bash
listenhub auth status --json
```

如果未安装或未登录，请自动处理——永远不要要求用户运行安装命令：

1. 自动安装：静默运行 `npm install -g @marswave/listenhub-cli`
2. 自动登录：运行 `listenhub auth login`（打开浏览器）

例外：`/asr` 在本地运行，无需 CLI 或 API 密钥。
