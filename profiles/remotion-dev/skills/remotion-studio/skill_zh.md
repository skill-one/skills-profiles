执行以下命令：

```bash
npx remotion studio --no-open
```

如果 Studio 已经打开，将打印 URL 并退出该命令。
否则，将启动一个长时间运行的过程，并打印 URL。

在浏览器中打开 URL。

## 有用的标志

| 参数          | 用途                                                                                       |
| ------------- | --------------------------------------------------------------------------------------------- |
| `--log=<级别>`   | 设置 `error`、`warn`、`info`（默认）或 `verbose` 日志级别。                                  |
| `--port=<数字>` | 请求 Studio 服务器端口；否则 Remotion 会寻找一个可用的端口。                           |
| `--force-new`     | 即使对于同一项目和端口已经有一个正在运行的 Studio 实例，也要启动另一个 Studio 实例。 |
