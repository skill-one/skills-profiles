# Slack

使用 `message` 工具并指定 `channel: "slack"`。该工具的架构描述了当前 Slack 账户启用的操作；不要假设未列出的操作。

## 工作流

- 优先使用来自上下文的稳定 Slack ID。当前对话之外的发送应使用 `channel:<id>` 或 `user:<id>` 目标。
- 除非用户要求顶级帖子，否则将回复保持在当前线程中。对于其他线程，请将其 Slack 时间戳作为 `threadId` 传递；对于消息特定操作，请使用相同的 `messageId`。
- 在编辑、删除、置顶或对模糊消息进行反应之前，请阅读对话并确定其确切 ID。
- 当配置了多个 Slack 账户时，请传递 `accountId` 而不是猜测。
- 当目标或意图不明确时，请确认破坏性删除。

当前的 `message` 工具提示会自动描述 Slack 格式、提及和可用操作。请遵循这些提示，而不是在此维护第二个操作目录。
