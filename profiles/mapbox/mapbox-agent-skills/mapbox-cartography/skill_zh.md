# Mapbox 地图制图技能

此技能提供专业的地图制图知识，帮助您使用 Mapbox 设计有效、美观且功能完善的地图。

## 核心地图制图原则

### 视觉层次

地图必须引导观众的注意力到最重要的事物上：

- **最重要**：兴趣点（POI）、用户位置、路线高亮
- **次要**：主要道路、城市标签、地标
- **一般**：次要街道、行政边界
- **背景**：水域、土地利用、地形

**实现方式：**

- 使用大小、颜色强度和对比度来建立层次
- 主要特征：高对比度、较大的符号、醒目的颜色
- 背景特征：低对比度、柔和的颜色、较小的文字

### 地图用色理论

**色彩和谐：**

- **类似色**：使用色轮上相邻的颜色（蓝-绿-青色）用于协调设计
- **互补色**：使用相对的颜色（蓝/橙、红/绿）用于高对比度强调
- **单色系**：单一色调，通过饱和度/亮度变化用于优雅、简约的设计

**色彩心理学：**

- **蓝色**：水域、信任、平静、专业（默认用于水域）
- **绿色**：公园、自然、成长、环保（植被、公园）
- **红/橙**：紧急、重要、餐饮（警报、餐厅）
- **黄色**：警告、高亮、注意（警告、选中项）
- **灰色**：中性、背景、道路（基础设施）

**无障碍性：**

- 确保 4.5:1 对比度（WCAG AA 标准）
- 不要仅依赖颜色来传达信息
- 使用色盲模拟器测试设计
- 避免使用红/绿组合进行关键区分

**色彩调色板模板：**

浅色主题（日间/专业）：

```json
{
  "background": "#f5f5f5",
  "water": "#a0c8f0",
  "parks": "#d4e7c5",
  "roads": "#ffffff",
  "buildings": "#e0e0e0",
  "text": "#333333"
}
```

深色主题（夜间模式）：

```json
{
  "background": "#1a1a1a",
  "water": "#0d47a1",
  "parks": "#2e7d32",
  "roads": "#3a3a3a",
  "buildings": "#2d2d2d",
  "text": "#ffffff"
}
```

> **深色主题中的道路颜色规则**：道路必须使用中性深灰色（`#3a3a3a`），与背景明显区分但不可着色。不要用琥珀色、蓝色或其他色调装饰道路——保留颜色用于应用数据层（路线、标记）。着色的基础道路和着色的数据层会视觉冲突。当地面道路与背景（`#1e1e1e` 在 `#1a1a1a` 上）融合时，会创建"悬浮标签"问题，街道名称会出现在下方无可见道路的情况下。

高对比度（无障碍性）：

```json
{
  "background": "#000000",
  "water": "#0066ff",
  "parks": "#00ff00",
  "roads": "#ffffff",
  "buildings": "#808080",
  "text": "#ffffff"
}
```

复古风格：

```json
{
  "background": "#f4e8d0",
  "water": "#b8d4d4",
  "parks": "#c8d4a4",
  "roads": "#d4c4a8",
  "buildings": "#e4d4c4",
  "text": "#4a3828"
}
```

### 地图比例尺下的字体

**字体选择：**

- **无衬线体**（Roboto、Open Sans）：现代、简洁、小尺寸下高可读性 - 用于标签
- **衬线体**（Noto Serif）：传统、正式 - 仅少量用于标题或历史地图
- **等宽体**：技术数据、坐标

**文字大小：**

```
放置标签（城市、POI）：11-14px
街道标签：9-11px
特征标签（公园）：10-12px
地图标题：16-20px
归属信息：8-9px
```

**标签位置：**

- 点状标签：居中或略微偏移（避免与符号重叠）
- 线状标签：跟随线路曲线，长特征重复标注
- 区域标签：居中于多边形，大小适当
- 优先级：主要特征优先标注，次要特征如有空间允许标注

### 缩放级别策略

**缩放 0-4**（世界到大陆）：

- 主要国家边界
- 海洋和海洋标签
- 仅首都城市

**缩放 5-8**（国家到州）：

- 州/省边界
- 主要城市
- 主要高速公路
- 大型水域

**缩放 9-11**（都市区）：

- 城市边界
- 社区
- 所有高速公路和主要道路
- 公园和地标

**缩放 12-15**（社区）：

- 所有街道
- 建筑物轮廓
- POI（餐厅、商店）
- 街道名称

> **注意**：Mapbox 的托管街道样式默认在缩放 14 左右显示大多数 POI。对于自定义样式，从缩放 12 开始 POI——这是社区比例尺，密度可管理且用户正在浏览。缩放 14 太晚；缩放 10（都市区比例尺）太早，会导致严重图标杂乱。

**缩放 16-22**（街道级）：

- 所有细节
- 门牌号
- 停车场
- 精细级 POI

## Mapbox 特定实现指导

### 样式图层最佳实践

**图层顺序（从下到上）：**

1. 背景（纯色或图案）
2. 土地利用（公园、住宅、商业）
3. 水体（海洋、湖泊、河流）
4. 地形/明暗处理（如使用海拔）
5. 建筑（3D 或 2D 轮廓）
6. 道路（高速公路→当地街道）
7. 边界（国家、州线）
8. 标签（地名、街道名）
9. POI 符号
10. 用户生成内容（路线、标记）

> **常见错误**：开发者经常将应用的路线线或活动标记放在 POI 符号**下方**，理由是"POI 必须保持可见"。这是反的——用户生成内容（您的路线、选中位置、用户位置）是最重要的图层，必须渲染在所有内容之上，包括 POI。覆盖 POI 图标的路线线是可接受的；被 POI 图标遮挡的路线则不可接受。

### 地图上下文考虑

**了解您的受众：**

- **普通公众**：简化，使用熟悉模式（Google/Apple 风格）
- **技术用户**：包含更多细节、技术图层、数据精度
- **领域专家**：显示专业数据，使用领域特定符号

**平台考虑：**

- **移动端**：更大的触摸目标（最小 44x44px），设计更简单，手臂长度可读
- **桌面端**：可包含更多细节，悬停交互，复杂叠加层
- **打印**：更高对比度，较大文字，考虑 CMYK 色彩空间
- **户外/明亮**：更高对比度，避免微妙灰色

**用例优化：**

- **导航**：强调道路，清晰层次，路线可见性
- **数据可视化**：柔和的基础地图，让数据突出
- **讲故事**：引导观众注意力，用颜色建立氛围
- **位置选择**：清晰显示 POI，提供上下文
- **分析**：包含相关图层，不同缩放下保持清晰
