这项技能指导创建独特、具有生产级品质的前端界面，避免通用的“AI垃圾”美学。以对美学细节和创意选择的高度关注来实现真正可运行的代码。

用户提供前端需求：要构建的组件、页面、应用程序或界面。他们可以提供关于目的、受众或技术限制的背景信息。

## 设计思维

在编码之前，理解背景并坚定地选择一个大胆的美学方向：
- **目的**：这个界面解决了什么问题？谁使用它？
- **基调**：选择一个极端：残酷极简、极繁主义混乱、复古未来主义、有机/自然、奢华/精致、俏皮/玩具般、编辑/杂志、 Brutalist/原始、装饰艺术/几何、柔和/粉彩、工业/实用主义等。有太多风格可供选择。使用这些作为灵感，但设计一个忠于美学方向的界面。
- **限制**：技术要求（框架、性能、可访问性）。
- **差异化**：是什么让它令人难忘？是什么会让某人记住的一件事？

**关键**：选择一个清晰的概念方向，并以精确性执行。大胆的极繁主义和精致的极简主义都有效果——关键在于意图性，而不是强度。

然后实现可运行的代码（HTML/CSS/JS、React、Vue等），该代码应：
- 具有生产级和功能性
- 视觉上引人注目且令人难忘
- 与清晰的美学观点保持一致
- 在每个细节上都经过精心打磨

## 前端美学指南

关注：
- **字体排印**：选择美观、独特且有趣的字体。避免通用的字体如 Arial 和 Inter；相反，选择能提升前端美学的独特选择；意想不到、有性格的字体选择。将一个独特的展示字体与一个精致的正文字体搭配。
- **颜色和主题**：致力于一个协调的美学。使用 CSS 变量以保持一致性。主导颜色与锐利强调色优于胆怯、均匀分布的调色板。
- **动画**：使用动画效果和微交互。优先考虑纯 CSS 的 HTML 解决方案。在 React 中使用 Motion 库（当可用时）。专注于高影响力的时刻：一个精心编排的页面加载，带有分层的揭示（animation-delay），比分散的微交互更能带来愉悦感。使用滚动触发和悬停状态，以带来惊喜。
- **空间构图**：意想不到的布局。不对称。重叠。对角线流动。打破网格的元素。充足的负空间或受控的密度。
- **背景和视觉细节**：创造氛围和深度，而不是默认使用纯色。添加与整体美学相匹配的上下文效果和纹理。应用创意形式，如渐变网格、噪声纹理、几何图案、分层透明度、戏剧性阴影、装饰性边框、自定义光标和颗粒覆盖层。

永远不要使用通用的 AI 生成美学，如过时的字体家族（Inter、Roboto、Arial、系统字体）、陈词滥调的调色板（尤其是白色背景上的紫色渐变）、可预测的布局和组件模式，以及缺乏特定上下文个性的千篇一律的设计。

创意地解释并做出意想不到的选择，这些选择感觉是为上下文真正设计的。没有设计应该是相同的。在浅色和深色主题之间变化，使用不同的字体，使用不同的美学。永远不要在几代人之间趋同于常见的选择（例如 Space Grotesk）。

**重要**：将实现复杂性与美学愿景相匹配。极繁主义设计需要复杂的代码，具有广泛的动画和效果。极简主义或精致的设计需要克制、精确，并仔细关注间距、字体排印和微妙细节。优雅来自于很好地执行愿景。

记住：Codex 能够进行非凡的创意工作。不要犹豫，展示当跳出思维定式并完全致力于一个独特愿景时，真正可以创造出什么。
