# 卓越型 PowerPoint 设计师

将内容转化为世界级的演示文稿，具备苹果发布会、微软产品发布和谷歌 I/O 的设计品质。这项技能应用 2024-2025 演示设计趋势和品牌级一致性，创建令人惊叹的专业幻灯片。

## 核心设计理念

**原则：**
1. **简约优先** - 去除一切无明确目的的元素
2. **大胆清晰** - 大号字体、高对比度、自信的配色
3. **视觉层级** - 通过大小、颜色和间距引导注意力
4. **一致的品牌化** - 每个元素遵循设计系统
5. **目的性动效** - 仅在增加清晰度或强调时使用动画

## 何时使用此技能

- 用户请求"专业演示文稿"或"路演 PPT"
- 将 markdown 或文本转换为 PowerPoint
- 用户提到"世界级"、"高质量"或"品牌级"设计
- 创建商业、销售、产品发布或发布会的演示文稿
- 用户想要"苹果/微软/谷歌风格"的演示文稿
- 请求包含术语：幻灯片、套件、演示文稿、PowerPoint、PPTX

## 设计系统与品牌风格

### 可用的品牌风格

**1. 科技发布会 (苹果/特斯拉风格)**
- **颜色**：深黑 (#000000)、白 (#FFFFFF)、强调蓝 (#0071E3)
- **字体**：SF Pro Display (标题 72-96pt)、SF Pro Text (正文 32-44pt)
- **布局**：极致留白，每张幻灯片一个焦点
- **过渡**：推入、淡出 (持续时间：0.6s)
- **风格**：极简、高端、产品导向

**2. 企业专业 (微软/IBM 风格)**
- **颜色**：海军蓝 (#003366)、钢蓝 (#0078D4)、暖灰 (#F3F2F1)
- **字体**：Segoe UI (标题 54-72pt)、正文 (24-32pt)
- **布局**：平衡、网格化、数据友好
- **过渡**：变形、淡出 (持续时间：0.8s)
- **风格**：值得信赖、数据驱动、企业级

**3. 创意大胆 (谷歌/爱彼迎风格)**
- **颜色**：亮色原色、渐变、大胆组合
- **字体**：Product Sans 或 Montserrat (标题 64-84pt)
- **布局**：动态、非对称、活泼的间距
- **过渡**：缩放、揭示 (持续时间：0.5s)
- **风格**：充满活力、创新、设计导向

**4. 金融精英 (高盛/麦肯锡风格)**
- **颜色**：炭灰 (#2C3E50)、金色强调 (#D4AF37)、白
- **字体**：Garamond 或 Georgia (衬线、优雅)
- **布局**：传统层级、居中、平衡
- **过渡**：仅微妙淡出 (持续时间：0.4s)
- **风格**：精致、权威、高端

**5. 初创企业路演 (Y Combinator/500 Startups 风格)**
- **颜色**：高对比度黑白与品牌强调色
- **字体**：Inter 或 Roboto (现代无衬线)
- **布局**：问题-解决方案导向、指标密集
- **过渡**：快速推入 (持续时间：0.3s)
- **风格**：充满活力、数据驱动、创始人友好

## 工作流程

### 第一步：分析内容并选择风格

```python
python scripts/analyze_content.py input.md
```

**分析考虑：**
- 内容类型（商业、创意、技术、金融）
- 受众（高管、投资者、客户、技术）
- 内容中的语气指示（正式、活力、创新）
- 前置代码中的明确风格请求

**自动选择品牌风格**或询问用户：
- 科技发布会用于产品发布、演示
- 企业专业用于商业报告、提案
- 创意大胆用于营销、设计展示
- 金融精英用于投资者套件、财务报告
- 初创企业路演用于融资、加速器演示

### 第二步：解析内容并映射到模板

**幻灯片类型检测：**
```markdown
# 标题 → title_slide (英雄式处理)
## 章节 → chapter_intro (章节分隔符)
### 主要要点 → key_message_slide (1-3 个要点)
* 项目符号 → bullet_hierarchy_slide (视觉项目符号)
> 引用 → quote_slide (大号、有冲击力)
![图片] → full_bleed_image (沉浸式)
| 表格 | → data_visualization (自动图表化)
---metrics--- → metrics_dashboard (KPI 展示)
```

### 第三步：应用设计系统

**字体层级：**
```
英雄标题：72-96pt，粗体，1.1 倍行高
章节标题：54-72pt，半粗体，1.2 倍行高
幻灯片标题：44-54pt，半粗体，1.3 倍行高
正文大号：32-36pt，常规，1.4 倍行高
正文：24-28pt，常规，1.5 倍行高
说明文字：18-20pt，浅色，1.6 倍行高
```

**间距系统：**
```
边缘间隙：100-120px
标题底部外边距：60-80px
章节间距：40-60px
段落间距：24-32px
项目符号缩进：40px
元素填充：20-30px
```

**颜色应用：**
```
背景：品牌背景色（通常为白/黑）
主色：标题、关键元素、CTA
次色：副标题、次要文本
强调色：高亮、数据点、强调
文本：95% 不透明度，保证可读性
```

### 第四步：智能模板选择

使用 Office-PowerPoint-MCP-Server 的 25+ 模板进行智能映射：

**内容类型 → 模板**
```
开场/结束 → title_slide, thank_you_slide
新章节 → chapter_intro
要点 (1-3) → key_metrics_dashboard
比较 → before_after_comparison, chart_comparison
流程 → process_flow, timeline_slide
团队 → team_introduction
数据 → data_table_slide, 图表布局
混合内容 → two_column_text, three_column_layout
全图 → full_image_slide
引用/证言 → quote_testimonial
```

### 第五步：专业润色

**过渡与动画：**
- **幻灯片过渡**：每套 PPT 最多 1-2 种，匹配品牌风格
- **持续时间**：0.3s（快）、0.6s（中）、0.8s（慢）基于品牌
- **进入动画**：文本淡入 (0.4s)，可选图片擦除
- **强调**：关键数字/指标脉冲（一次，微妙）
- **退出**：淡出 (0.3s)
- **规则**：每张幻灯片最多 3 个动画元素

**视觉效果：**
```python
# 应用于所有文本框
阴影 = {
    "距离": 2,
    "角度": 135,
    "模糊": 4,
    "不透明度": 60%
}

# 应用于图片
叠加 = {
    "渐变": "线性",
    "不透明度": 20%  # 保证文本可读性
}
```

### 第六步：一致性验证

```python
python scripts/validate_consistency.py output.pptx
```

**检查项：**
- 字体一致性（最多 2 个字体家族）
- 色彩方案遵循（所有颜色来自设计系统）
- 间距一致性（边距、间隙、填充）
- 模板使用（是否适合内容）
- 动画时间（符合品牌指南）
- 图片质量（最小 1920x1080）

## 动画与过渡指南

### 专业过渡规则

**第一级：始终安全（自由使用）**
- 淡出 (0.6s) - 通用、优雅
- 推入 (0.4s) - 干净、方向性
- 变形 (0.8s) - 仅 PowerPoint，精致

**第二级：谨慎使用（特殊时刻）**
- 缩放 (0.5s) - 产品展示、前后对比
- 揭示 (0.6s) - 章节过渡
- 擦除 (0.5s) - 图片密集型 PPT

**第三级：避免（不专业）**
- 摇摆轮、窗帘、溶解、折纸 - 绝对不用

### 动画最佳实践

**"啊哈时刻"规则：**
- 每套 PPT 选择 1-2 张关键幻灯片
- 应用单一强调动画（脉冲、放大）
- 持续时间：0.8-1.0s
- 只发生一次，非循环

**文本动画：**
```python
# 专业进入效果
效果 = "淡入"
持续时间 = 0.4
项目符号间隔 = 0.3  # 如果有项目符号，错开
```

**图片动画：**
```python
# 产品图或关键视觉可选
效果 = "擦除" 或 "淡入"
持续时间 = 0.6
方向 = "从底部" # 自然，如上升
```

## 获取最佳效果技巧

1. **先定风格**：在 markdown 中添加前置代码，指定所需品牌风格
   ```yaml
   ---
   style: tech-keynote
   accent-color: "#0071E3"
   ---
   ```

2. **少即是多**：目标为每分钟 1 张幻灯片

3. **图片质量重要**：使用高分辨率图片（最小 1920x1080，优先 4K）

4. **测试动画**：预览 PPT 确保过渡专业

5. **打印准备**：设计同样适用于 PDF 导出（动画变为静态）

6. **无障碍性**：保持 4.5:1 对比度，保证文本可读性

## 故障排除

**问题**：颜色与品牌不完全匹配
**解决方案**：在前置代码中指定精确十六进制代码：
```yaml
---
colors:
  primary: "#003366"
  accent: "#0078D4"
  background: "#FFFFFF"
---
```

**问题**：动画过多
**解决方案**：在前置代码设置动画级别：
```yaml
---
animations: minimal  # minimal, moderate, full
---
```

**问题**：幻灯片过于密集
**解决方案**：遵循"6x6 规则" - 最多 6 个项目符号，每个项目符号最多 6 个词。Claude 会自动拆分内容。
