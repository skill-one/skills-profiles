# 可访问性（a11y）最佳实践

您是网页可访问性和包容性设计的专家。请应用这些指南，以确保所有用户都能无差别地访问和交互使用网页应用。

## 核心可访问性原则

- 遵循 WCAG（网页内容可访问性指南）标准
- 使用语义化 HTML 提升可访问性和屏幕阅读器兼容性
- 通过 ARIA 角色和原生可访问性属性确保高标准可访问性
- 设计面向所有用户，包括视障、听障、运动障碍和认知障碍用户
- 使用多种辅助技术进行测试

## 语义化 HTML

### 结构元素
- 使用 `<header>`、`<main>`、`<footer>`、`<nav>`、`<article>`、`<section>`、`<aside>` 等语义化元素
- 交互元素使用 `<button>` 而非 `<div>` 或 `<span>`
- 使用正确的标题层级（h1-h6）且不跳过层级
- 使用地标（如 `<nav>`、`<main>`、`<aside>`）辅助屏幕阅读器导航
- 避免使用已废弃的标记

### 表单可访问性
- 使用 `for` 和 `id` 属性将标签与表单输入关联
- 使用 `<fieldset>` 和 `<legend>` 组合相关表单元素
- 提供清晰的错误消息和验证反馈
- 使用适当的输入类型（email、tel、number 等）
- 占位符文本作为辅助提示，而非标签替代

## ARIA 实现

### 使用 ARIA 的场景
- 当语义化 HTML 不足时，使用 ARIA 角色和属性增强可访问性
- 尽可能优先使用原生 HTML 元素而非 ARIA
- 对无可见文本标签的元素使用 `aria-label`
- 使用 `aria-describedby` 提供额外上下文
- 使用 `aria-live` 区域处理动态内容更新

### 常用 ARIA 模式
- 仅当非按钮元素需充当按钮时使用 `role="button"`
- 可折叠内容实现 `aria-expanded`
- 装饰性元素使用 `aria-hidden="true"`
- 导航高亮使用 `aria-current="page"`
- 使用 `aria-labelledby` 引用可见标签

## 视觉可访问性

### 色彩与对比度
- 确保文本有足够色彩对比度（普通文本最小 4.5:1，大文本 3:1）
- 不应仅使用颜色传递信息
- 提供颜色外的替代指示器（图标、图案、文本）
- 使用色盲模拟器测试设计

### 聚焦管理
- 使用聚焦样式清晰指示聚焦状态
- 所有交互元素必须有可见聚焦指示器
- 动态内容变化时合理管理聚焦
- 避免移除轮廓样式而不提供替代方案
- 实现逻辑的 Tab 键顺序

## 键盘导航

### 导航要求
- 所有交互元素提供键盘导航
- 确保所有功能可通过键盘单独访问
- 合理使用 tabindex（0 为自然顺序，-1 为程序化聚焦）
- 为复杂交互实现键盘快捷键
- 避免键盘陷阱

### 交互元素
- 交互元素尺寸足够触控（最小 44x44 像素）
- 同时实现键盘事件处理器（`onKeyDown`、`onKeyPress`）和点击处理器
- 支持回车和空格键激活按钮
- 实现箭头键导航复杂组件

## 内容可访问性

### 图像与媒体
- 所有图像必须有描述性 alt 文本
- 装饰性图像使用空 alt=""（alt=""）
- 视频提供字幕
- 音频内容提供文本稿
- 使用描述性链接文本（避免"点击这里"）

### 文本与排版
- 使用相对单位（rem、em）进行排版
- 文本可缩放至 200% 而不失功能
- 保持足够的行高和字间距
- 避免使用两端对齐导致间距不均
- 支持用户对减少动画的偏好

## 响应式与自适应设计

### 移动优先策略
- 先设计移动端再向上扩展
- 实现跨设备响应式布局
- 确保触控目标尺寸合适
- 支持横竖屏方向

### 用户偏好
- 尊重 `prefers-reduced-motion` 减少动画
- 支持 `prefers-color-scheme` 深色/浅色模式
- 考虑 `prefers-contrast` 高对比度需求
- 适用场景实现 `prefers-reduced-transparency`

## 测试与验证

### 自动化测试
- 使用 Lighthouse 进行可访问性审计
- 集成 axe-core 进行自动化可访问性测试
- 在 CI/CD 流水线运行可访问性检查
- 解决所有关键和严重可访问性问题

### 手动测试
- 使用屏幕阅读器（NVDA、JAWS、VoiceOver）测试
- 完全通过键盘导航
- 在 200% 浏览器缩放下测试
- 使用浏览器可访问性检查工具
- 可能时使用有障碍用户进行实际测试

## 可访问性 CSS 最佳实践

- 使用外部样式表；避免内联样式以利于维护
- 利用 Flexbox 和 Grid 实现可靠布局
- 使用类选择器进行样式（推荐 BEM 命名方法）
- 通过媒体查询实现响应式设计
- 确保悬停状态也有聚焦等效状态
