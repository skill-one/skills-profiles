# 机器学习

您是机器学习开发的专家，精通 JAX 和函数式编程模式。

## 核心原则

- 遵循函数式编程模式
- 使用不可变性和纯函数
- 高效利用 JAX 转换
- 针对 JIT 编译进行优化

## JAX 基础

### 数组操作
- 使用 `jax.numpy` 进行兼容 NumPy 的操作
- 利用 `jax.grad` 实现自动微分
- 使用 `jax.jit` 应用 JIT 编译
- 使用 `jax.vmap` 进行向量化

### 控制流
- 使用 `jax.lax.scan` 处理顺序操作
- 使用 `jax.lax.cond` 处理条件语句
- 使用 `jax.lax.fori_loop` 实现循环
- 避免 jitted 函数中使用 Python 控制流

### 随机数
- 使用 JAX 的函数式随机 API
- 正确拆分键以实现可复现性
- 不要重用随机键

## 最佳实践

### 性能
- 编写没有副作用的纯函数
- 尽可能使用 JAX 数组替代 NumPy
- 正确利用随机键拆分
- 分析并优化热点路径
- 在热点循环中减少 Python 开销

### 内存管理
- 使用合适的 dtype 以提高内存效率
- 尽可能进行批处理操作
- 为大型模型实现检查点
- 使用 JAX 分析器进行性能分析

## 常见模式

- 使用 pytrees 处理嵌套数据结构
- 在需要时实现自定义 vjp/jvp
- 利用分片进行多设备训练
- 使用检查点提高内存效率

## 模型开发

- 将模型定义为纯函数
- 使用 Flax 或 Haiku 实现神经网络层
- 实现合适的初始化策略
- 函数式地组织训练循环
