# OpenSEO 链接潜力挖掘

## 目标

寻找可能引用用户页面、产品、研究、指南或工具的现实页面、网站和作者。使用 OpenSEO 进行潜力挖掘，然后使用可用的网络/搜索/浏览器工具进行联系方式挖掘。

## 必填输入

- `projectId`
- 用户域名或目标 URL
- 可链接的资产、页面、产品、研究、工具或主题
- 可选的竞争对手
- 可选的市场/位置/语言

## 项目上下文

项目上下文工具免费，与应用程序和其他代理共享。

1. 首先调用 `get_project_context` 并基于其进行沟通——定位资料提供了使链接值得提供的声明，保存的竞争对手是用于挖掘的反向链接资料。
2. 此技能需要 `定位` 和竞争对手。如果其中任何一个为空，运行最小的内联设置：询问用户为什么有人会引用他们以及他们与谁竞争，或从网站和 `find_serp_competitors` 推断并确认，使用 `update_project_context` 写回，然后继续潜力挖掘。不要预先加载完整访谈；建议在最后使用 `seo-project-setup` 进行其余部分。
3. 在花费信用之前，检查研究日志。如果相同的研究在最近 30 天内运行过，则重用该结果并说明，而不是重新购买。
4. 完成后，写回持久内容——通过 `addKeyPages` 的可链接资产，任何其反向链接资料被证明有用的竞争对手通过 `addCompetitors`——并附加一个研究日志条目：`{ appendResearchLog: { summary: "链接潜力挖掘: <资产/目标页面>. 结论: <结论>" } }`。

## 以报告形式交付

通过 `seo-report` 技能交付，使用 `skill: "link-prospecting"` 保存。如果该技能不可用，则说明并停止在写入 HTML 之前。

## OpenSEO MCP 工具

- `get_serp_results`：寻找排名文章、列表、资源页面、比较和主题发布者。
- `get_backlinks_overview`：检查竞争对手域名或页面的反向链接/引用域名模式。
- `get_domain_overview`：确定重要的潜力域名。
- `get_ranked_keywords`：了解潜在对象或竞争对手在主题匹配重要时排名什么。
- `search_local_businesses` 和 `get_local_serp_results`：用于本地 SEO 链接潜力挖掘，当附近的业务、本地竞争对手或地图/类别信号可以揭示合作目标时使用。
- `research_keywords`：扩展潜力挖掘查询。

## 联系方式挖掘工具

在 OpenSEO 确定良好潜力后，使用可用的非 OpenSEO 浏览或搜索工具进行公开联系方式挖掘。根据客户，这可能涉及网络搜索、页面获取、浏览器自动化或搜索 API。

寻找：

- 作者署名页面
- 联系页面
- 编辑指南
- 关于/团队页面
- LinkedIn、X、Bluesky 或其他专业资料
- 订阅或出版物页眉页面
- 页面 HTML 或可见页面文本中的公共电子邮件地址
- 结构化数据，如 `Person`、`Organization`、`sameAs` 或 `email`

仅记录实际找到的联系方式。包括任何电子邮件、资料或联系表单的源 URL。

## 潜力挖掘查询模式

从资产/主题构建查询：

- `<主题> 资源`
- `最佳 <类别> 工具`
- `<竞争对手> 替代品`
- `<主题> 统计`
- `<主题> 指南`
- `<主题> 示例`
- `<主题> 模板`
- `<主题> 软件`
- `<主题> 适用于 <受众>`

使用 `get_serp_results` 批量发送最相关的模式。每次调用最多发送 10 个查询。

## 工作流程

1. 明确可链接的资产和某人引用它的原因。
2. 默认构建 5-10 个潜力挖掘查询。
3. 调用 `get_serp_results` 为这些查询。
4. 如果提供了竞争对手，首先调用 `get_backlinks_overview` 为最强的竞争对手域名或页面。如果没有反向链接证据，则继续。
5. 对于本地 SEO，使用 `search_local_businesses` 和 `get_local_serp_results` 围绕优先位置识别附近的竞争对手、类别和本地 SERP 证据，然后再搜索本地商会、协会、校园资源、社区页面和目录。
6. 过滤潜力：
   - 保留主题相关性和编辑页面。
   - 优先考虑文章、目录、资源页面、比较、统计页面、模板和精选列表。
   - 降级主页、登录页面、薄型联盟页面、垃圾邮件、不相关的论坛和直接竞争对手，除非比较角度有效。
7. 对于每个良好潜力，定义沟通角度：
   - 破损/缺失资源
   - 更好的当前数据
   - 有用的工具/模板
   - 替代品或比较包含
   - 专家引言或支持性参考
8. 对于最强的潜力，访问或搜索潜力网站以找到最佳联系方式。
9. 起草沟通消息。如果找到联系方式，请包括源。如果没有，请列出下一个最佳联系方式挖掘路径。

## 输出格式

`h1`：可链接的资产。

如果适用报告模板（见 `seo-report`），其部分和语气将替换此列表。

按顺序包含以下部分：

1. **角度**——一个或两个开篇句子命名最佳沟通角度和要首先处理的潜力类型。
2. **潜力**——一个表格，包含潜力 URL、网站、源、建议角度、联系方式和优先级。保持大约八列；删除对本次运行无用的列。
3. **原因**——每个潜力一个发现值得解释：它们链接到这类内容的证据，然后是确切的请求。
4. **沟通草稿**——每个两个或三个可重用角度的消息文本：资源或列表包含、文章更新和比较提及。
5. **限制**——笔记：未找到的联系方式、直接竞争对手或可能付费放置的潜力，以及哪个源找到每个联系方式。
6. **下一步**——一个有序列表：首先发送给谁，以及顺序。
7. **报告制作方式**——以 `seo-report` 的技能链接行开头，指向 `https://openseo.so/docs/skills/link-prospecting`（"OpenSEO 链接潜力挖掘技能"），然后是哪些工具返回了潜力，哪些来自网络或浏览器。

## 防护措施

- 不要编造电子邮件地址、社交账号或联系人姓名。
- 除非 OpenSEO 工具返回了联系方式，否则不要说 OpenSEO 找到了联系方式。将联系方式挖掘归因于使用的网络/搜索/浏览器源。
- 在合理搜索后如果联系方式不可用，建议具体的挖掘步骤，例如检查作者页面、联系页面、LinkedIn、X 或信誉良好的联系方式丰富工具。
- 避免垃圾邮件式的大规模沟通。通过页面和原因进行个性化。
- 标记直接竞争对手或可能付费放置的潜力。
