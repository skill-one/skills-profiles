# YouTube 缩略图设计

使用 [inference.sh](https://inference.sh) CLI 通过 AI 图像生成创建高 CTR 的 YouTube 缩略图。

## 快速入门

> 需要 inference.sh CLI (`belt`)。[安装说明](https://raw.githubusercontent.com/inference-sh/skills/refs/heads/main/cli-install.md)

```bash
belt login

# 生成缩略图
belt app run falai/flux-dev-lora --input '{
  "prompt": "YouTube 缩略图风格，特写人物表情惊讶兴奋地盯着发光的笔记本电脑屏幕，充满活力的蓝橙配色方案，戏剧性的工作室灯光，浅景深，高对比度，电影感",
  "width": 1280,
  "height": 720
}'
```

## 规格

| 规格 | 值 |
|------|-------|
| 尺寸 | 最小 1280 x 720 px |
| 推荐 | 1920 x 1080 px |
| 纵横比 | 16:9 |
| 最大文件大小 | 2 MB |
| 格式 | JPG, GIF, PNG |

## 120px 测试

您的缩略图在手机上大约显示为 **120px 宽** — 这就是大多数观众首先看到它的方式。

**在 120px 时，观众必须能够识别：**
1. 氛围/情绪（从颜色和表情）
2. 主题（从构图）
3. 文本（如果有 — 只有在足够大时）

**测试：** 将您的缩略图宽度调整为 120px。如果它模糊不清，请重新设计。

## 安全区域

```
┌─────────────────────────────────────────────┐
│                                             │
│   ✅ 适用于文本和关键元素                 │
│                                             │
│                                             │
│                                             │
│                                             │
│                                       ┌───┐ │
│                                       │ ⏱ │ │ ← 时间戳叠加
│                              ┌────────┴───┘ │    (右下角)
│   ┌────┐                     │  时长      │
│   │ CH │ 章节标记      └──────────────│
└───┴────┴────────────────────────────────────┘
     ↑ 左下角：章节/进度标记
```

**避免将关键元素放置在：**
- 右下角（视频时长时间戳）
- 左下角（章节标记、进度条）
- 极端边缘（裁剪因设备而异）

## 配色策略

### 高对比度搭配效果好的组合

| 组合 | 氛围 | 适用于 |
|-------------|------|----------|
| 黄色 + 黑色 | 紧急、注意力 | 科技、商业、列表 |
| 红色 + 白色 | 能量、兴奋 | 娱乐、反应 |
| 蓝色 + 橙色 | 专业对比 | 教育、教程 |
| 绿色 + 白色 | 成长、金钱 | 金融、成功故事 |
| 紫色 + 黄色 | 高端、创意 | 设计、艺术、创意 |
| 白色 + 深色 | 干净、极简 | 奢侈、极简频道 |

### 配色规则

- **背景** 和 **文本/主题** 应该互补或高对比度
- 避免相同温度的颜色接触（红色在橙色上 = 污浊）
- 每个缩略图最多使用 **3 种颜色**
- 比现实生活更饱和 — 缩略图需要与明亮的 UI 竞争

## 缩略图上的文本

### 何时使用文本

- 列表/数字："7 个技巧"、"前 10 名"
- 强烈的观点："停止这样做"
- 结果："30 天内赚 10K 美元"
- 比较：两个事物之间的 "vs"

### 何时**不**使用文本

- 视频标题已经说明了（重复）
- 情绪/视觉效果在讲述故事
- 您无法使其在 120px 时足够大以阅读

### 文本规则

| 规则 | 原因 |
|------|--------|
| 最大 6 个词 | 在缩略图尺寸下可读性 |
| 最小 60pt 等效 | 在 120px 宽度下必须可读 |
| 粗体无衬线字体 | 细字体在小尺寸下消失 |
| 对比描边/阴影 | 确保在任何背景下都可读 |
| 无小文本 | 如果在小尺寸下不可读，请删除 |

## 脸部表情心理学

带有脸部的缩略图比无脸缩略图获得**更高的 CTR**。表情很重要：

| 表情 | CTR 影响 | 适用于 |
|------------|-----------|----------|
| **惊讶/震惊** | 最高 | 反应、揭露、发现内容 |
| **好奇** | 高 | 教程、如何做、技巧 |
| **兴奋** | 高 | 开箱、评测、公告 |
| **担忧/焦虑** | 中高 | 警告、错误、问题内容 |
| **自信** | 中 | 专家建议、权威内容 |
| **中性** | 最低 | 除非您的品牌是极简的，否则避免 |

### 脸部构图规则

- 脸部应占据缩略图的 **30-50%**
- 眼睛看向 **文本或主题**（引导观众注意力）
- 眼睛看向镜头 = 连接。眼睛看向物体 = 好奇。
- 将脸部放在一侧（通常是左侧），文本或主题放在另一侧

```bash
# 生成面向镜头的脸部缩略图
belt app run falai/flux-dev-lora --input '{
  "prompt": "特写肖像，男性表情真诚惊讶，嘴巴微张，眉毛上扬，看向镜头，画面左侧，充满活力的蓝绿色背景，戏剧性的边缘照明，YouTube 缩略图风格，高对比度，电影感",
  "width": 1280,
  "height": 720
}'

# 生成看向主题的脸部缩略图
belt app run bytedance/seedream-4-5 --input '{
  "prompt": "人物惊讶地看着一个发光的全息图表，显示向上增长，戏剧性的蓝绿色照明，右侧侧面视图，深色背景，科技美学，高能量",
  "size": "2K"
}'
```

## A/B 测试

一次测试一个变量：

| 变量 | 测试 A vs B |
|----------|-------------|
| 脸部 vs 无脸部 | 相同构图，有/无人物 |
| 表情 | 惊讶 vs 好奇 |
| 配色方案 | 暖色调 vs 冷色调 |
| 文本 vs 无文本 | 有/无文本叠加 |
| 背景 | 明亮 vs 深色 |
| 构图 | 左侧主题 vs 右侧主题 |

```bash
# 生成变体 A
belt app run falai/flux-dev-lora --input '{
  "prompt": "..., 明亮的黄色背景，...",
  "width": 1280, "height": 720
}' --no-wait

# 生成变体 B（相同提示，不同背景）
belt app run falai/flux-dev-lora --input '{
  "prompt": "..., 深海军蓝色背景，...",
  "width": 1280, "height": 720
}' --no-wait
```

## 缩略图检查清单

- [ ] 最小 1280x720（推荐 1920x1080）
- [ ] 文件大小小于 2MB
- [ ] 通过 120px 眯眼测试
- [ ] 右下角（时间戳）或左下角（章节）无关键元素
- [ ] 最多 3 种颜色，高对比度
- [ ] 文本（如果有）最多 6 个词，粗体，带对比描边
- [ ] 脸部表情与内容能量匹配（如果适用）
- [ ] 不重复视频标题
- [ ] 与周围缩略图区分开来（检查您的细分市场）
- [ ] 在亮色和深色 YouTube 背景上都适用

## 常见错误

| 错误 | 问题 | 修复 |
|---------|---------|-----|
| 文本过多 | 在缩略图尺寸下不可读 | 最大 6 个词或无文本 |
| 对比度低 | 在信息流中消失 | 使用互补颜色 |
| 构图杂乱 | 眼睛不知道看向哪里 | 一个焦点 |
| 通用股票照片感觉 | 没有个性，被跳过 | 真实表情，独特角度 |
| 细节太小 | 在 120px 时丢失 | 粗简的形状 |
| 每个视频都使用相同风格 | 观众疲劳 | 在品牌指南内变化 |
| 缩略图误导 | 毁坏信任，伤害留存 | 与实际内容匹配 |
