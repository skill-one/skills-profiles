# 付费媒体计划

1. 读取设置配置文件、商业经济数据、证据、当前账户状态以及相关行业模板作为可选输入。
2. 定义目标、客户、产品、转化、价值、约束条件、地理区域、受监管类别、时间范围和成功标准。
3. 从基本原理评估渠道角色和排除项；无需要求所有支持的平台。对于十二平台合同之外的渠道，加载 `ads/references/additional-platforms.md` 并返回研究线索，除非其当前的购买、资格、衡量和创意证据存在。
4. 在提出 Meta 预算、学习阶段预期、竞价、整合或绩效预测之前，按照合同在 `skills/ads-meta/SKILL.md` 中收集账户、像素和转化冷启动维度。当任何维度为冷或 `unknown` 时，计划进行衡量验证、明确的创意假设、分阶段可逆测试和置信度标签；不要将成熟账户基准应用于缺失的历史记录。
5. 指定活动架构、受众策略、创意系统、预算和节奏、衡量、实验、政策控制和运营节奏。
6. 启动、学习、优化和扩展前的阶段前提条件。
7. 为每个操作分配负责人、时间、依赖关系、护栏、证据、成功指标以及回滚或退出条件。
8. 返回规范 JSON 并渲染请求的人类计划。

该计划具有建议性。只有通过启动或优化变异门，它才会成为账户变更。
