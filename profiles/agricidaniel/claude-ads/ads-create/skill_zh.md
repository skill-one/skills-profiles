# 活动概念与文案

1. 加载经过验证的设置/品牌资料、目标、受众、优惠、证据、平台/位置要求、政策背景和可选的审计发现。
2. 区分事实声明、运营者批准的声明和创意假设。
3. 对于Meta工作，根据`skills/ads-meta/SKILL.md`中的合同要求收集账户、像素和转化冷启动维度。当任何维度为冷或`unknown`时，在简报中说明，不要重用成熟账户的创意基准或性能声明，并且绝不能因为像素是新的就标记现有创意为差。
4. 生成实质性不同的策略概念，而不是表面上的修改。
5. 对于每个概念，定义洞察、承诺、证据、钩子、叙事、CTA、反对意见、平台适应性、目的地和实验假设。
6. 验证文案限制和政策，并与当前的平台参考进行比对。仅加载`ads/references/google-creative-specs.md`、`meta-creative-specs.md`、`youtube-creative-specs.md`、`linkedin-creative-specs.md`、`tiktok-creative-specs.md`和`microsoft-creative-specs.md`中的活跃文件；使用日期来源账本来验证每个当前规范声明。
7. 在运行目录内返回一个版本化的创意简报和文案演示文稿。

不要编造证言、认证、稀缺性、价格、结果或受监管的声明。在生产和发布前仍需人工审核。
