# SEO 内容简报生成器

生成基于研究的 内容简报，帮助写作者制作能够超越当前顶级搜索结果的页面。简报包括竞争对手分析（含差距评分）、各部分字数分解、关键词布局规则以及针对不同页面类型的模板。

## 流程

### 1. 确定简报模式

**改进模式**（提供现有页面URL）：
- 获取现有页面内容和结构
- 确定哪些部分已经很强（保留）
- 确定缺失、薄弱或过时的部分
- 在大纲中区分“保留/强化”与“新增”部分
- 当目标改进可以取得胜利时，不建议全面重写

**新页面模式**（提供关键词或主题，无现有页面）：
- 仅使用目标网站首页或站点地图获取业务背景
- 从零开始构建新页面的简报
- 专注于新页面可以填补的竞争差距

### 2. 获取上下文

- 获取目标URL或首页以了解业务
- 获取站点地图以发现所有现有页面、分类和服务
- 此上下文对于“网站相关性规则”（见下文）至关重要

### 3. 分析搜索结果页面（SERP）

- 确定目标关键词排名前5的页面
- 过滤非竞争对手（维基百科、Reddit、Pinterest、亚马逊、YouTube、政府网站、SEO工具页面、招聘板、目录、新闻聚合器、社交平台）。参见`references/excluded-domains.md`获取完整列表。
- 对每个真实竞争对手进行评分：深度（1-10）、格式（1-10）、SEO（1-10）、用户体验（UX）（1-10）
- 确定三种差距类型：
  - **主题差距**：竞争对手完全遗漏的子主题
  - **深度差距**：已覆盖但浅显的主题
  - **质量差距**：过时信息、缺乏专家视角、格式差
- 计算差距优先级：`影响 x 竞争优势 / 努力程度`

### 4. 分类搜索意图

- **信息型**：用户想学习（指南、操作方法、定义）
- **商业型**：用户在购买前进行调研（比较、评论、“最佳X”）
- **交易型**：用户准备采取行动（购买、预订、咨询、注册）
- **导航型**：用户正在寻找特定网站或页面

确定Google为该查询奖励的SERP格式：长文指南、清单文章、比较表、落地页、常见问题解答、视频、本地包。

### 5. 构建简报

应用`references/page-type-templates.md`中的页面类型模板，然后根据竞争对手差距和搜索意图进行定制。

## 关键规则

### 网站相关性规则

您建议的每个标题、子主题、关键词和常见问题解答都必须基于目标网站实际的服务或产品，使其能够可信地撰写相关内容。

- 阅读网站首页和站点地图以了解其业务
- 如果竞争对手的某些部分涵盖了该网站不提供的服务，则不要借鉴其结构
- 在每个建议之前问自己：“这个网站实际上能够实现这些内容吗？”如果不能，请删除它。

### 站点结构覆盖规则

当简报一个枢纽页、概述页、分类页或“类型”页时：
- 大纲必须引用该网站上所有相关的产品类别、服务或子页面
- 不要编造不存在的类别，不要遗漏已存在的类别
- 每个类别应作为独立部分出现，并建议内部链接
- 这确保了页面可以作为真正的枢纽链接到所有子页面

对于非枢纽页（单个服务页、博客文章），使用站点结构建议相关内部链接，但不要强迫每个类别都进入大纲。

### 输出语言规则

- 不要在输出中提及研究人员姓名、框架名称或工具名称（不要“Ben Goodey方法”、“Frase.io公式”、“Princeton GEO”、“Clearscope”、“Backlinko”）
- 这些只是内部思考工具。输出必须读起来像普通的、专业的建议。
- 写作对象是商业主或内容写作者，而不是SEO学术人员

## 关键词密度和布局

阅读`references/keyword-density.md`获取完整规则。摘要：

**主要关键词使用**：在关键位置自然使用主要关键词。
- 不要优化固定密度。将密度检查视为可选的内部可读性/填充启发式算法。
- 前1-2次提及有助于建立主题上下文。之后收益递减。
- 对于一篇1,000字的文章，避免在标题、正文和alt文本中强制重复。

**主要关键词必须出现在**：
1. 标题标签（靠近开头）
2. H1标签（靠近开头）
3. URL别名
4. 元描述
5. 第一段/前100字
6. 至少一个图像alt文本

**主要关键词不需要出现在**：
- 每个H2或H3（子主题自然传递上下文，如果H1已涵盖）
- 每个段落或部分

**次要关键词**：
- 5-8个紧密相关的支持性术语分布在正文内容中
- 10-15个更广泛的语义术语涵盖相关概念
- 在H2-H6子标题中自然使用
- 同义词提高可读性，不计入关键词密度

**各部分关键词指导**：对于大纲中的每个部分，指定：
- 哪个关键词（主要或次要）应出现在标题中
- 正文是否应包含主要关键词或变体
- 示例：“在H2中使用次要关键词‘结构制图服务’。正文：提及一次主要关键词。”

**分布**：均匀分布主要关键词。不要前置或集中在一个部分。

## 元标签规则

**标题标签**：
- 50-60个字符（从未少于50个，也从未超过60个）
- 主要关键词优先，品牌名最后
- 用管道符或短横线分隔品牌（匹配网站现有模式）
- 尽可能以结果、数字或具体内容开头

**元描述**：
- 130-150个字符（从未少于130个，也从未超过150个）
- 使用主动语态，用USP和具体内容扩展标题
- 以号召性用语结尾
- 标题末尾不要出现品牌名（它已经在标题中）
- 不要使用引号（Google在引号处截断）

## 信息增益（不可协商）

每个简报必须明确说明此内容添加了哪些新价值，而当前排名页面无法提供。必须具体：
- 专有数据或原始研究
- 带有真实结果的案例研究
- 专家引言或亲身体验
- 原创综合或独特框架
- 不是“更多细节”或“更好格式”

## E-E-A-T要求

列出此内容需要的确切信任信号：
- 与主题相关的作者资质和简介
- 来自权威来源的专家引言或引用
- 带有日期的引用研究、数据或统计
- 最后更新日期
- 对于YMVL主题（健康、金融、法律、安全）尤其关键

## 内部链接

- 建议3-5个具体的内部链接机会，并附上锚文本
- 指定页面是枢纽（链接到集群页）还是辐条（链接到支柱页）
- 使用站点地图中的站点结构找到真实的链接目标

## 输出格式

始终以以下精确结构输出：

```
## 内容简报：[主要关键词]

### 搜索意图
[意图类型、SERP奖励的格式、目标受众和知识水平。3-4行。]

### 竞争对手分析
| # | URL | 关键H2部分 | 预估字数 | 分数 | 主要差距 |
|---|-----|------------|----------|------|----------|
| 1 | ... | ...        | ...      | X/40  | ...      |

### 内容差距和机会
[要点列表：主题差距、深度差距、质量差距的具体内容]

### 胜利大纲

**H1**：[包含主要关键词的H1]
**URL别名**：/[别名]
**目标字数**：~[X]字（竞争对手平均：~[X]字）

[完整的H2/H3大纲，包括：
- 每部分的字数
- 内容格式说明（项目符号列表、表格、定义框等）
- 标记为“FS目标”的精选片段目标
- 每部分关键词指导]

### 推荐元标签

**标题**
[标题，最多60个字符]

**元描述**
[描述，最多150个字符]

### 独特角度和信息增益
[具体段落：此内容具体添加了哪些新价值]

### E-E-A-T要求
[要点列表：需要的确切信任信号]

### 内部链接机会
[3-5个建议，包括锚文本和目标URL]
```

## 大纲模式

当用户要求“仅大纲”或“内容大纲”而不是完整简报时，跳过竞争对手分析表格、内容差距部分、信息增益部分和E-E-A-T部分。仅输出：

```
## 内容大纲：[主要关键词]

**H1**：[包含主要关键词的H1]
**URL别名**：/[别名]
**目标字数**：~[X]字（竞争对手平均：~[X]字）

[完整的H2/H3大纲，包括字数、格式说明、FS目标、关键词指导，以及每部分1-2句写作说明]
```

## DataForSEO集成（可选）

如果DataForSEO MCP工具可用，使用`serp_organic_live_advanced`获取真实SERP数据和竞争对手分析，`kw_data_google_ads_search_volume`获取关键词量，`dataforseo_labs_bulk_keyword_difficulty`获取难度分数，`dataforseo_labs_search_intent`获取意图分类，以及`on_page_content_parsing`获取竞争对手内容提取。

## Ahrefs集成（可选）

如果Ahrefs MCP工具可用，使用`keywords-explorer-overview`获取关键词量和难度，`serp-overview`获取SERP分析，`site-explorer-organic-keywords`获取现有关键词排名，以及`site-explorer-top-pages`获取竞争对手页面性能。

## 错误处理

| 情景 | 操作 |
|------|------|
| 目标URL无法访问 | 报告错误。不要猜测页面内容。请用户验证URL。 |
| 过滤后未找到竞争对手 | 扩大搜索范围以包含部分匹配竞争对手。在简报中注明竞争环境薄弱。 |
| 未找到站点地图 | 无站点结构上下文的情况下继续。注明内部链接建议可能不完整。 |
| 未指定页面类型 | 根据关键词意图和SERP格式自动检测。在简报中说明检测到的类型。 |
| 未指定目标字数 | 使用竞争对手平均值为基准。在大纲中注明。 |
