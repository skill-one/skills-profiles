# 战略SEO规划

## 流程

### 1. 探索
- 业务类型、目标受众、竞争对手、目标
- 当前网站评估（如果存在）
- 预算和时间限制
- 关键绩效指标（KPI）

### 2. 竞争分析
- 确定前5名竞争对手
- 分析其内容策略、模式使用、技术设置
- 识别关键词差距和内容机会
- 评估其E-E-A-T信号
- 估计其域名权威性

### 3. 架构设计
- 从`assets/`目录加载行业模板
- 设计URL层次结构和内容支柱
- 规划内部链接策略
- 具有质量门禁的站点地图结构
- 用户旅程的信息架构

### 4. 内容策略
- 与竞争对手的内容差距
- 页面类型和估计数量
- 博客/资源主题和发布节奏
- E-E-A-T建设计划（作者简介、资质、经验信号）
- 带有优先级的内容日历

### 5. 技术基础
- 托管和性能要求
- 每个页面类型的模式标记计划
- 核心网络指标基线目标
- AI搜索准备要求
- 移动优先考虑

### 6. 实施路线图（4阶段）

#### 第一阶段：基础（第1-4周）
- 技术设置和基础设施
- 核心页面（主页、关于、联系方式、主要服务）
- 基本模式实施
- 分析和跟踪设置

#### 第二阶段：扩展（第5-12周）
- 主要页面的内容创建
- 博客启动和初始帖子
- 内部链接结构
- 本地SEO设置（如果适用）

#### 第三阶段：扩展（第13-24周）
- 高级内容开发
- 链接建设和外联
- GEO优化
- 性能优化

#### 第四阶段：权威（第7-12个月）
- 思想领导力内容
- PR和媒体提及
- 高级模式实施
- 持续优化

## 行业模板

从`assets/`目录加载：
- `saas.md`：软件公司
- `local-service.md`：本地服务企业
- `ecommerce.md`：电子商务商店
- `publisher.md`：内容发布者/媒体
- `agency.md`：代理机构和咨询公司
- `generic.md`：通用业务模板

## DataForSEO集成（可选）

如果DataForSEO MCP工具可用，使用`dataforseo_labs_google_competitors_domain`和`dataforseo_labs_google_domain_intersection`获取真实的竞争情报，使用`dataforseo_labs_bulk_traffic_estimation`获取流量估计，使用`kw_data_google_ads_search_volume`和`dataforseo_labs_bulk_keyword_difficulty`进行关键词研究，使用`business_data_business_listings_search`获取本地企业数据。

## 错误处理

| 场景 | 操作 |
|------|------|
| 未知业务类型 | 回退到`generic.md`模板。通知用户未找到行业特定模板，并使用通用业务模板继续。 |
| 未提供网站URL | 进入新站规划模式。跳过需要实时URL的当前网站评估和竞争差距分析。 |
| 行业模板未找到 | 检查`assets/`目录中的可用模板。如果请求的模板文件缺失，使用`generic.md`并在输出中注明缺失的模板。 |
