# 竞品对比与替代页面

创建高转化率的对比和替代页面，针对竞争意图关键词，提供准确、结构化的内容。

## 页面类型

### 1. "X vs Y" 对比页面
- 两个产品/服务的直接头对头对比
- 平衡的功能逐项分析
- 清晰的结论或推荐，并附有理由
- 目标关键词：`[产品A] vs [产品B]`

### 2. "X的替代品"页面
- 特定产品/服务的替代品列表
- 每个替代品附有简短摘要、优缺点、最佳适用场景
- 目标关键词：`[产品]替代品`，`[产品]的最佳替代品`

### 3. "最佳[类别]工具"汇总页面
- 某一类别中顶级工具/服务的精选列表
- 清晰说明排名标准
- 目标关键词：`最佳[类别]工具[年份]`，`顶级[类别]软件`

### 4. 对比表格页面
- 多个产品按列排列的功能矩阵
- 如果是交互式，则可排序/可筛选
- 目标关键词：`[类别]对比`，`[类别]对比图表`

## 对比表格生成

### 功能矩阵布局
```
| 功能          | 您的产品 | 竞品A | 竞品B |
|--------------|:--------:|:--------:|:--------:|
| 功能1        | ✅       | ✅       | ❌       |
| 功能2        | ✅       | ⚠️ 部分支持 | ✅       |
| 功能3        | ✅       | ❌       | ❌       |
| 价格（起）    | $X/月     | $Y/月     | $Z/月     |
| 免费版        | ✅       | ❌       | ✅       |
```

### 数据准确性要求
- 所有功能声明必须能从公开来源验证
- 价格必须是最新的（包含"截至[日期]"注释）
- 更新频率：每季度审核或当竞品发布重大变更时
- 尽可能为每个竞品数据点链接到来源

## Schema 标注建议

### 带有AggregateRating的产品Schema
```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "[产品名称]",
  "description": "[产品描述]",
  "brand": {
    "@type": "Brand",
    "name": "[品牌名称]"
  },
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "[评分]",
    "reviewCount": "[数量]",
    "bestRating": "5",
    "worstRating": "1"
  }
}
```

### SoftwareApplication（用于软件对比）
```json
{
  "@context": "https://schema.org",
  "@type": "SoftwareApplication",
  "name": "[软件名称]",
  "applicationCategory": "[类别]",
  "operatingSystem": "[操作系统]",
  "offers": {
    "@type": "Offer",
    "price": "[价格]",
    "priceCurrency": "USD"
  }
}
```

### ItemList（用于汇总页面）
```json
{
  "@context": "https://schema.org",
  "@type": "ItemList",
  "name": "最佳[类别]工具[年份]",
  "itemListOrder": "https://schema.org/ItemListOrderDescending",
  "numberOfItems": "[数量]",
  "itemListElement": [
    {
      "@type": "ListItem",
      "position": 1,
      "name": "[产品名称]",
      "url": "[产品URL]"
    }
  ]
}
```

## 关键词定位

### 对比意图模式
| 模式 | 示例 | 搜索量信号 |
|------|------|-----------|
| `[A] vs [B]` | "Slack vs Teams" | 高 |
| `[A] alternative` | "Figma alternatives" | 高 |
| `[A] alternatives [year]` | "Notion alternatives 2026" | 高 |
| `best [category] tools` | "best project management tools" | 高 |
| `[A] vs [B] for [use case]` | "AWS vs Azure for startups" | 中 |
| `[A] review [year]` | "Monday.com review 2026" | 中 |
| `[A] vs [B] pricing` | "HubSpot vs Salesforce pricing" | 中 |
| `is [A] better than [B]` | "is Notion better than Confluence" | 中 |

### 标题标签公式
- X vs Y：`[A] vs [B]：[关键差异化] ([年份])`
- 替代品：`[N] 最佳 [A] 替代品在 [年份]（免费与付费）`
- 汇总：`[N] 最佳 [类别] 工具在 [年份]，对比与排名`

### H1 模式
- 匹配标题标签意图
- 自然包含主要关键词
- 保持在70个字符以内

## 转化优化布局

### CTA 位置
- **页面上方**：简短对比摘要与主要CTA
- **对比表格后**：`免费试用[您的产品]` CTA
- **页面底部**：最终推荐与CTA
- 避免在竞品描述部分使用侵略性CTA（降低信任度）

### 社会证明部分
- 与对比标准相关的客户证言
- G2/Capterra/TrustPilot评分（带来源链接）
- 显示从竞品迁移的案例研究
- `"从[竞品]迁移"`故事

### 价格亮点
- 清晰的价格对比表格
- 突出价值优势（而不仅仅是最低价格）
- 包含隐藏成本（设置费、按用户定价、超额费用）
- 链接到完整价格页面

### 信任信号
- `"最后更新[日期]"`时间戳
- 具有相关专长的作者
- 方法论披露（对比是如何进行的）
- 披露自身产品关联

## 公平性指南

- **准确性**：所有竞品信息必须能从公开来源验证
- **不诽谤**：切勿对竞品做出虚假或误导性声明
- **引用来源**：链接到竞品网站、评测网站或文档
- **及时更新**：竞品发布重大变更时审核和更新
- **披露关联**：明确说明哪个产品是您的
- **平衡呈现**：诚实承认竞品优势
- **价格准确性**：所有价格数据包含`"截至[日期]"`免责声明
- **功能验证**：尽可能测试竞品功能，否则引用文档

## 内部链接

- 从对比部分链接到您自己的产品/服务页面
- 在相关对比页面之间交叉链接（例如，`"A vs B"`链接到`"A vs C"`)
- 讨论单个功能时链接到功能特定页面
- 面包屑：首页 > 对比 > [此页面]
- 页面底部相关对比部分
- 链接到对比中提到的案例研究和证言

## 错误处理

| 情景 | 操作 |
|------|------|
| 竞品URL无法访问 | 报告哪些竞品URL失败。使用可用数据继续，并注明对比中的空白。 |
| 竞品数据不足（价格、功能不可用） | 清晰标记缺失数据点。在对比表格中使用`"公开不可用"`而不是猜测。 |
| 未发现产品/服务重叠 | 报告产品服务于不同市场。建议具有功能重叠的替代竞品，或转向类别汇总格式。 |
