# 单页分析

## 需要分析的内容

### 在页SEO
- 标题标签：50-60个字符，包含主要关键词，独特
- 元描述：150-160个字符，引人入胜，包含关键词
- 元描述不是标题的复述：运行
  `"${CLAUDE_PLUGIN_ROOT}/scripts/claude-seo" run metadata_template.py --title "<title>" --description "<desc>" --json`
  (启发式，确定性字符串比较)。以重复自身标题开头并以通用CTA（"立即免费试用"，
  "免费开始！"）结尾的描述是模板化元数据，批量生成任务会生成全站通用的形状，无论正文内容多原创，
  模板化或重复的元数据都是已记录的内容质量问题
- H1：仅一个，匹配页面意图，包含关键词
- H2-H6：逻辑层次（无跳过级别），描述性
- URL：简短，描述性，带连字符，无参数
- 内部链接：充足，相关锚文本，无孤儿页面
- 外部链接：指向权威来源，合理数量

### 内容质量
- 字数与页面类型最低要求（见quality-gates.md）
- 可读性：Flesch易读性分数，年级水平
- 关键词密度：自然（1-3%），包含语义变体
- E-E-A-T信号：作者简介，资质，一手经验标记
- 内容新鲜度：发布日期，最后更新日期

### 技术要素
- 规范标签：存在，自我引用或正确
- 元robots：除非有意阻止，否则为索引/跟随
- Open Graph：og:title，og:description，og:image，og:url
- Twitter Card：twitter:card，twitter:title，twitter:description
- Hreflang：如果多语言，正确实现

### Schema标记
- 检测所有类型（优先JSON-LD）
- 验证必需属性
- 识别缺失机会
- 永不推荐HowTo（已弃用）或FAQ用于丰富结果（将于2026年5月退役）；现有的FAQPage无需删除，使用QAPage处理真实问答

### 图片
- 替换文本：存在，描述性，在自然情况下包含关键词
- 文件大小：标记>200KB（警告），>500KB（严重）
- 格式：推荐WebP/AVIF优于JPEG/PNG
- 尺寸：为防止CLS设置宽度和高度
- 懒加载：按图片报告`lazy_method`（原生 | perfmatters | ewww | js-generic | 无）。当检测到JS懒加载器（Perfmatters，EWWW，lazysizes）时，不要标记"未懒加载"，它们有意移除原生`loading="lazy"`属性并使用`data-src`占位符

### 核心网页指标（仅作参考，不能单独从HTML测量）
- 标记潜在LCP问题（巨大的英雄图片，渲染阻塞资源）
- 标记潜在INP问题（重量级JS，无异步/延迟）
- 标记潜在CLS问题（缺少图片尺寸，注入内容）

## 错误处理

| 情景 | 操作 |
|------|------|
| URL无法访问（DNS失败，连接拒绝） | 清晰报告错误。不要猜测页面内容。建议用户验证URL并重试。 |
| 页面需要认证（401/403） | 报告页面需要认证。建议用户提供渲染后的HTML或公开可访问的URL。 |
| JavaScript渲染内容（HTML中空体） | 注意关键内容可能是在客户端渲染的。分析可用HTML并标记结果可能不完整。建议使用浏览器渲染快照（如果可用）。 |
