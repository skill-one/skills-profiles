# 视频广告规格

通过 [inference.sh](https://inference.sh) CLI 创建平台特定的视频广告。

## 快速入门

> 需要 inference.sh CLI (`belt`)。[安装说明](https://raw.githubusercontent.com/inference-sh/skills/refs/heads/main/cli-install.md)

```bash
belt login

# 生成竖屏视频广告场景
belt app run bytedance/seedance-2-0 --input '{
  "prompt": "竖屏视频，一个人兴奋地拆开产品，干净现代的房间，明亮自然光照，社交媒体广告风格，真实感",
  "ratio": "9:16",
  "generate_audio": true
}'
```

## 平台规格

### TikTok

| 规格 | 值 |
|------|-------|
| 纵横比 | **9:16** (竖屏) |
| 分辨率 | 1080 x 1920 px |
| 时长 | 5-60 秒 (推荐 15-30 秒) |
| 文件大小 | 最大 500 MB |
| 格式 | MP4, MOV |
| 音频 | 默认开启 (带声音设计) |
| 文本安全区 | 距离所有边缘 150px |
| 吸睛窗口 | **1 秒** — 第一帧必须吸引注意力 |

### Instagram Reels

| 规格 | 值 |
|------|-------|
| 纵横比 | **9:16** (竖屏) |
| 分辨率 | 1080 x 1920 px |
| 时长 | 最长 90 秒 (广告推荐 15-30 秒) |
| 封面图 | 单独上传，显示在网格中 |
| 音频 | 默认开启 |
| 标题区域 | 底部 20% 预留文字叠加 |

### Instagram Stories

| 规格 | 值 |
|------|-------|
| 纵横比 | **9:16** |
| 分辨率 | 1080 x 1920 px |
| 时长 | 每个片段最长 15 秒 |
| 滑动/链接 | 广告可用 |
| 顶部/底部 | 顶部 14% 和底部 20% = 关键内容不安全 |

### YouTube

| 格式 | 纵横比 | 时长 | 跳过 |
|--------|--------|----------|------|
| Bumper | 16:9 | **6 秒** 恰好 | 不可跳过 |
| 不可跳过 | 16:9 | **15 秒** | 不可跳过 |
| 可跳过 (TrueView) | 16:9 | 任意长度 | 5 秒后可跳过 |
| Shorts | 9:16 | 最长 60 秒 | N/A |

分辨率：1920 x 1080 (16:9) 或 1080 x 1920 (Shorts)

### Facebook Feed

| 规格 | 值 |
|------|-------|
| 纵横比 | **1:1** (方形) 或 **4:5** (推荐移动端) |
| 分辨率 | 1080 x 1080 或 1080 x 1350 |
| 时长 | 最长 240 分钟 (推荐 15-30 秒) |
| 自动播放 | **静音** — 标题至关重要 |
| 音频 | 85% 的 Facebook 视频是无声观看 |

### LinkedIn

| 规格 | 值 |
|------|-------|
| 纵横比 | **1:1** 或 **16:9** |
| 分辨率 | 1080 x 1080 或 1920 x 1080 |
| 时长 | 3 秒到 10 分钟 (广告推荐 15-30 秒) |
| 调性 | 专业 |
| 自动播放 | 汇流中静音 |

## AIDA 框架用于视频广告

| 阶段 | 时间 | 目标 | 技巧 |
|-------|------|------|-----------|
| **吸引** | 0-3s | 停止滚动 | 打断模式、大胆视觉、提问 |
| **兴趣** | 3-10s | 继续观看 | 陈述问题、展示相关性 |
| **欲望** | 10-20s | 想要解决方案 | 展示产品/结果、社会证明 |
| **行动** | 最后 3-5s | 点击/购买/注册 | 清晰的 CTA、紧迫感、优惠 |

### 吸睛技巧 (前 3 秒)

| 技巧 | 示例 |
|-----------|---------|
| 大胆陈述 | "这个工具取代了我整个营销团队" |
| 提问 | "你为什么还在手动做这个？" |
| 惊人视觉 | 意想不到的转换、前后对比展示 |
| 模式打断 | 在动作中开始、不寻常角度、亮色 |
| 社会证明 | "200 万人切换到这个" |
| 痛点 | "如果你讨厌 [常见困扰]，请看这个" |

## 创建视频广告

### 竖屏 (TikTok, Reels, Stories, Shorts)

```bash
# 吸睛场景 (0-3s)
belt app run google/veo-3-1-fast --input '{
  "prompt": "竖屏 9:16 视频，特写双手处理缠绕的线缆和杂乱的桌面，沮丧能量，手持摄像机晃动，真实社交媒体风格，明亮光照"
}'

# 解决方案展示 (3-15s)
belt app run bytedance/seedance-2-0 --input '{
  "prompt": "竖屏视频，平滑产品展示，极简桌面上的无线充电站，令人满意的整理转换，现代明亮房间，社交媒体广告美学",
  "ratio": "9:16",
  "generate_audio": true
}'

# 添加旁白
belt app run falai/dia-tts --input '{
  "prompt": "[S1] 停止浪费时间在这个混乱中。这个产品改变了我的整个设置。一切都充电。一切都井井有条。生物链接中见。"
}'

# 合并视频 + 音频
belt app run infsh/video-audio-merger --input '{
  "video": "solution-reveal.mp4",
  "audio": "voiceover.mp3"
}'

# 添加字幕 (对静音自动播放至关重要)
belt app run infsh/caption-videos --input '{
  "video": "ad-with-audio.mp4",
  "caption_file": "captions.srt"
}'
```

### 方形 (Facebook, LinkedIn Feed)

```bash
belt app run google/veo-3-1-fast --input '{
  "prompt": "方形 1:1 视频，专业人士在办公桌前发现一款新软件工具，笔记本电脑屏幕显示干净仪表盘，自然办公室光照，企业广告风格，满意表情"
}'
```

### YouTube Bumper (6 秒)

```bash
# 6 秒横幅：一条信息、一个视觉、一个 CTA
belt app run google/veo-3-1-fast --input '{
  "prompt": "6 秒产品广告，快速蒙太奇展示手机上使用的时尚应用，快速剪辑，现代、充满活力，品牌标志在结尾处展示，有力且动态，宽 16:9"
}'

# 保持紧凑
belt app run falai/dia-tts --input '{
  "prompt": "[S1] 你的报告。自动化。免费试用 DataFlow。"
}'
```

## 字幕是强制性的

85% 的 Facebook 和 40%+ 的 Instagram 视频是无声观看。

### 字幕最佳实践

| 规则 | 原因 |
|------|--------|
| 始终添加字幕 | 大多数平台默认无声观看 |
| 大号易读字体 | 小字在移动端看不见 |
| 高对比度 | 白色文字带深色轮廓/背景 |
| 居中或底三分之一 | 标准观看位置 |
| 一次最多 2 行 | 文字过多 = 无法快速阅读 |
| 关键词加粗/颜色 | 吸引对重要词的注意力 |

```bash
# 从音频生成字幕
# (从你的脚本创建 SRT 文件，然后烧入)
belt app run infsh/caption-videos --input '{
  "video": "ad-video.mp4",
  "caption_file": "ad-captions.srt"
}'
```

## 广告结构模板

### 证言广告 (15-30 秒)

| 时间 | 内容 |
|------|---------|
| 0-3s | 客户陈述他们遇到的问题 |
| 3-15s | 他们如何发现并尝试产品 |
| 15-25s | 他们取得的特定结果 |
| 25-30s | 产品名称 + CTA |

### 演示广告 (15-30 秒)

| 时间 | 内容 |
|------|---------|
| 0-3s | 问题 (文字或视觉) |
| 3-20s | 产品演示展示解决方案 |
| 20-25s | 关键结果/利益 |
| 25-30s | CTA + 优惠 |

### 前后对比广告 (15 秒)

| 时间 | 内容 |
|------|---------|
| 0-3s | "之前"状态 (杂乱、缓慢、令人沮丧) |
| 3-5s | 过渡/产品介绍 |
| 5-12s | "之后"状态 (干净、快速、令人满意) |
| 12-15s | CTA |

## 常见错误

| 错误 | 问题 | 修复 |
|---------|---------|-----|
| 前 1-3 秒没有吸睛 | 观众滚动过去 | 以模式打断开始 |
| 竖屏平台使用横屏视频 | 黑边，看起来业余 | 使用 9:16 竖屏平台 |
| 没有字幕 | 大多数观众无声观看 | 始终添加字幕 |
| CTA 太晚 | 观众已经离开 | 在最后 5 秒内清晰 CTA |
| 对平台来说太长 | 强制跳过或流失 | 符合平台时长规范 |
| 所有平台使用同一广告 | 规格错误、调性错误 | 创建平台特定版本 |
| 前 3 秒有标志 | 感觉像商业广告，被跳过 | 保留品牌标识到最后 |
| 文字在危险区域 | 被平台 UI 切割 | 每个平台检查安全区域 |

## 检查清单

- [ ] 目标平台正确纵横比
- [ ] 前 1-3 秒有吸睛内容
- [ ] 添加字幕 (易读、高对比度)
- [ ] CTA 清晰且在最后 5 秒内
- [ ] 时长符合平台规范
- [ ] 文字不在平台危险区域
- [ ] 音频设计适用于有声和无声
- [ ] 平台特定版本 (非一刀切)
