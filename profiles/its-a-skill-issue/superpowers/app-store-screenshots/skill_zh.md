# 应用商店截图

通过 [inference.sh](https://inference.sh) CLI 创建应用商店截图和预览视频。

## 快速入门

> 需要 inference.sh CLI (`belt`)。[安装说明](https://raw.githubusercontent.com/inference-sh/skills/refs/heads/main/cli-install.md)

```bash
belt login

# 生成设备模拟场景
belt app run falai/flux-dev-lora --input '{
  "prompt": "iPhone 15 Pro 展示简洁现代的应用界面，包含分析仪表盘，略微倾斜，柔和渐变背景，专业产品摄影，微妙阴影，营销模拟风格",
  "width": 1024,
  "height": 1536
}'
```

## 平台规范

### 苹果 App Store (iOS)

| 设备 | 尺寸 (px) | 必须满足 |
|------|----------|----------|
| iPhone 6.7" (15 Pro Max) | 1290 x 2796 | 必须满足 |
| iPhone 6.5" (11 Pro Max) | 1284 x 2778 | 必须满足 |
| iPhone 5.5" (8 Plus) | 1242 x 2208 | 可选 |
| iPad Pro 12.9" (第 6 代) | 2048 x 2732 | 如果是 iPad 应用 |
| iPad Pro 11" | 1668 x 2388 | 如果是 iPad 应用 |

- 每个本地化最多 **10 张截图**
- 前 **3 张截图** 在不滚动的情况下可见（关键）
- 格式：PNG 或 JPEG（JPEG 不支持 Alpha/透明度）

### Google Play 商店 (Android)

| 规格 | 值 |
|------|-------|
| 最小尺寸 | 320 px (任意边) |
| 最大尺寸 | 3840 px (任意边) |
| 纵横比 | 16:9 或 9:16 |
| 最大截图数量 | 每种设备类型 8 张 |
| 格式 | PNG 或 JPEG (24 位，无 Alpha) |

- 功能图形：1024 x 500 px（用于推荐时必须）
- 推广视频：YouTube URL（可选但推荐）

## 前三原则

**80% 的应用商店印象只显示前 3 张截图**（用户滚动前）。这 3 张必须：

1. 传达核心价值主张
2. 展示最佳功能/结果
3. 与竞争对手区分开来

### 截图库顺序

| 位置 | 内容 | 目的 |
|------|------|------|
| **1** | 英雄图 — 核心价值，最佳功能 | 停止滚动，传达应用做什么 |
| **2** | 关键差异化点 | 与竞争对手有什么不同 |
| **3** | 最受欢迎的功能 | 用户最喜欢的东西 |
| **4** | 社会证明或结果 | 评分、结果、用户评价 |
| **5-8** | 其他功能 | 支持性功能、设置、集成 |
| **9-10** | 边缘案例 | 专为小众用户设计的专业功能 |

## 截图风格

### 1. 设备框架带标题

标准：显示应用的设备模拟图，标题文本在上方/下方。

```
┌──────────────────────────┐
│   "轻松追踪习惯"         │  ← 标题（以利益为导向）
│    无需费力"            │
│                          │
│   ┌──────────────────┐   │
│   │                  │   │
│   │   应用界面       │   │  ← 设备框架中的实际应用 UI
│   │   内容          │   │
│   │                  │   │
│   │                  │   │
│   └──────────────────┘   │
│                          │
└──────────────────────────┘
```

### 2. 全出血 UI（无设备框架）

应用 UI 填满整个截图。适用于沉浸式应用。

### 3. 生活方式场景

显示真实世界场景中的设备（手持手机、在桌上等）。

### 4. 功能突出带标注

UI 截图，箭头/圆圈指向特定功能。

## 标题写作

### 规则

- **最多 2 行** 文本
- **以利益为导向**，不是以功能为导向
- **30pt+ 等效** 字体大小（必须在商店中可读）

### 示例

```
❌ 以功能为导向：
"推送通知系统"
"日历视图带过滤"
"数据导出功能"

✅ 以利益为导向：
"再也不会错过截止日期"
"一目了然查看本周"
"一键分享报告"
```

## 预览视频

### 苹果 App Store

| 规格 | 值 |
|------|-------|
| 时长 | 15-30 秒 |
| 方向 | 竖屏或横屏（与应用匹配） |
| 音频 | 可选（在商店中静音循环） |
| 格式 | H.264，.mov 或 .mp4 |

### Google Play

| 规格 | 值 |
|------|-------|
| 源 | YouTube URL |
| 时长 | 推荐 30 秒-2 分钟 |
| 方向 | 横屏优先 |

### 预览视频结构

| 段落 | 时长 | 内容 |
|------|------|------|
| 钩子 | 0-3 秒 | 展示核心结果/惊艳时刻 |
| 功能 1 | 3-10 秒 | 演示顶级功能 |
| 功能 2 | 10-18 秒 | 第二个关键功能 |
| 功能 3 | 18-25 秒 | 第三个功能或社会证明 |
| CTA | 25-30 秒 | 结束屏幕带应用图标 |

```bash
# 生成预览视频场景
belt app run google/veo-3-1-fast --input '{
  "prompt": "平滑屏幕录制风格，手指点击现代移动应用界面，滑动屏幕展示图表和数据可视化，干净 UI 过渡，专业应用演示"
}'
```

## 本地化

每种语言都有自己的截图集。优先级：

| 市场 | 本地化级别 |
|------|------------|
| 主要市场 | 完整：新截图 + 翻译标题 |
| 次要市场 | 翻译标题，相同截图 |
| 其他 | 英语默认 |

关键本地化市场：英语、日语、韩语、简体中文、德语、法语、西班牙语、葡萄牙（巴西）

## A/B 测试（Google Play）

Google Play Console 支持商店列表实验：

- 测试不同的截图顺序
- 测试带/不带设备框架
- 测试不同标题
- 测试不同配色方案
- 运行 7 天以上，流量 50%+ 以获得显著结果

## 常见错误

| 错误 | 问题 | 修复 |
|------|------|------|
| 设置界面作为截图 | 没人关心设置 | 展示核心价值，不是基础设施 |
| 引导流程截图 | 显示摩擦，不是价值 | 展示应用使用状态 |
| 文本过多 | 商店中难以阅读 | 最多 2 行，30pt+ 字体 |
| 错误尺寸 | 被商店拒绝 | 使用精确平台规范 |
| 所有截图看起来都一样 | 没有理由滚动 | 变化构图和内容 |
| 以功能为导向的标题 | 不会传达利益 | "再也不会错过截止日期" > "推送通知" |
| 过时的 UI | 看起来被遗弃 | 每次重大版本发布都更新截图 |
| 没有英雄截图 | 弱势第一印象 | 位置 1 = 你的最佳截图 |

## 检查清单

- [ ] 目标平台正确尺寸
- [ ] 前 3 张截图传达核心价值
- [ ] 标题以利益为导向，最多 2 行
- [ ] 无引导或设置界面
- [ ] 预览视频 15-30 秒，前 3 秒有钩子
- [ ] 顶级市场本地化
- [ ] Google Play 功能图形（1024x500）
- [ ] 截图更新为当前应用版本
- [ ] 准备了 A/B 测试变体
