# OKX.AI 支持 — 客户服务指南

仅提供指导功能的技能。它返回一个固定的帮助中心操作指南，以便用户能够联系 OKX.AI 支持。它完全在对话层运行：不进行 CLI 调用，不发起网络请求，不访问钱包或凭证，没有副作用。


## 使用场景

触发并渲染模板


## 响应

```
您可以通过 OKX.AI 帮助中心获取帮助：

🔗 OKX.AI 帮助中心：https://okx.ai 

在那里您可以：
* 在线与支持人员聊天 — 实时交谈以报告问题或提出投诉

如何在线与支持人员聊天：
1. 点击 https://okx.ai 链接进入 OKX.AI 网站
2. 在页面右下角找到支持图标
3. 在出现的聊天窗口中，点击开始聊天
4. 选择您的区域，然后点击继续
5. 一切就绪 — 您可以立即开始聊天
```
