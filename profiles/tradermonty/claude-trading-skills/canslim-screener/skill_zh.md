# CANSLIM 股票筛选器 - 第三阶段（完整 CANSLIM）

## 概述

本技能使用威廉·欧奈尔（William O'Neil）经过验证的 CANSLIM 方法筛选美国股票，这是一种系统的方法，用于识别具有强大基本面和价格动量的增长型股票。CANSLIM 分析 7 个关键组成部分：**C** 当前的收益、**A** 年度增长、**N** 新兴/新高、**S** 供应/需求、**L** 领导/RS 排名、**I** 机构支持，以及 **M** 市场方向。

**第三阶段** 实现了全部 7 个 CANSLIM 组成部分（C、A、N、S、L、I、M），代表了 **100% 的完整方法**。

**两阶段方法：**
1. **第一阶段（FMP API + Finviz）**：使用所有 7 个 CANSLIM 组成部分分析股票池
2. **第二阶段（报告）**：按综合评分排序并生成可操作的报告

**主要功能：**
- 综合评分（0-100 分制），具有加权组成部分
- **Finviz 备用**：用于机构持股数据（当 FMP 数据不完整时自动触发）
- 逐步过滤以优化 API 使用
- JSON + Markdown 输出格式
- 解释带：卓越+（90+）、卓越（80-89）、强劲（70-79）、高于平均水平（60-69）
- 市场保护（M 组成部分门控）

**第三阶段.1 组成部分权重（原始 O'Neil 权重）：**
- C（当前收益）：15%
- A（年度增长）：20%
- N（新颖性）：15%
- S（供应/需求）：15%
- L（领导/RS 排名）：20% — 多周期加权 RS（3m/6m/12m 对可配置基准）
- I（机构）：10%
- M（市场方向）：5%

**加权 RS 公式：**
```
加权 RS = 0.40 × rel_3m + 0.30 × rel_6m + 0.30 × rel_12m
```
可用周期在缺少某些数据时重新标准化。默认基准是 `^GSPC`；使用 `--rs-benchmark SPY/QQQ/IWM/...` 覆盖。

**当多周期数据不完整时的备用层次结构：**
1. 无基准 → 加权绝对股票表现 + 20% 惩罚。
2. 所有多周期窗口丢失但 >=50 根价格历史 → 落回传统的 365 天全窗口绝对回报作为评分输入（如果没有基准，则 20% 惩罚）。
3. <50 根价格历史 → 分数=0，`error` 设置。

## 工作流程

### 第一步：验证 API 访问和需求

检查用户是否配置了 FMP API 密钥：

```bash
# 检查环境变量
echo $FMP_API_KEY

# 如果未设置，提示用户提供
```

**需求：**
- **FMP API 密钥**（免费层：每天 250 次调用，足够用于 40 只股票）
- **Python 3.9+** 以及必需的库：
  - `requests`（FMP API 调用）
  - `beautifulsoup4`（Finviz 网页抓取）
  - `lxml`（HTML 解析）

**安装：**
```bash
pip install requests beautifulsoup4 lxml
```

如果 API 密钥缺失，指导用户：
1. 在 https://site.financialmodelingprep.com/developer/docs 注册
2. 获取免费 API 密钥（每天 250 次调用）
3. 设置环境变量：`export FMP_API_KEY=your_key_here`

### 第二步：确定股票池

**选项 A：默认池（推荐）**
使用按市值排序的前 40 只 S&P 500 股票（脚本中预定义）：

```bash
python3 skills/canslim-screener/scripts/screen_canslim.py
```

**选项 B：自定义池**
用户提供特定代码或行业：

```bash
python3 skills/canslim-screener/scripts/screen_canslim.py \
  --universe AAPL MSFT GOOGL AMZN NVDA META TSLA
```

**选项 C：特定行业**
用户可以提供专注于行业的列表（技术、医疗保健等）

**API 预算考虑（第三阶段）：**
- 40 只股票 × 每只股票 7 次 FMP 调用 = 280 次 API 调用
  - FMP：每只股票 7 次调用（配置文件、报价、收益×2、历史 90 天、历史 365 天、机构）
  - Finviz：约 1.8 次调用/股票（机构持股备用，2 秒速率限制，不计入 FMP 预算）
- 市场数据（^GSPC 报价、^VIX 报价、^GSPC 52 周历史）：3 次 FMP 调用
- 总计：~283 次 FMP 调用/每次筛选运行（超过免费层的 250 次）
- **建议**：使用 `--max-candidates 35`（免费层）（35 × 7 + 3 = 248 次调用），或升级到 FMP 起步层（每月 29.99 美元，每天 750 次调用）以进行完整的 40 只股票筛选

### 第三步：执行 CANSLIM 筛选脚本

使用适当的参数运行主筛选脚本：

```bash
cd skills/canslim-screener/scripts

# 基本运行（40 只股票，报告中前 20 只）
python3 screen_canslim.py --api-key $FMP_API_KEY

# 自定义参数
python3 screen_canslim.py \
  --api-key $FMP_API_KEY \
  --max-candidates 40 \
  --top 20 \
  --output-dir ../..

# 自定义 RS 基准（第三阶段.1）
python3 screen_canslim.py --rs-benchmark SPY

# 禁用 L 组成部分（节省每只股票的 365 天获取；L 固定在 50 的中性 50）
python3 screen_canslim.py --disable-rs
```

**脚本工作流程（第三阶段 - 完整 CANSLIM）：**
1. **市场方向（M）**：分析 S&P 500 趋势与 50 天 EMA（使用真实历史数据以获得准确的 EMA）
   - 如果检测到熊市（M=0），警告用户提高现金
2. **S&P 500 历史数据**：获取 52 周数据用于 M 组成部分的 EMA 和 L 组成部分的 RS 计算
3. **股票分析**：针对每只股票计算：
   - **C 组成部分**：季度 EPS/收入增长（同比）
   - **A 组成部分**：3 年 EPS CAGR 和稳定性
   - **N 组成部分**：距离 52 周高，突破检测
   - **S 组成部分**：基于成交量的积累/分配（上涨日成交量与下跌日成交量）
   - **L 组成部分**：与 S&P 500 相比 52 周相对强度
   - **I 组成部分**：机构持有人数量 + 持股百分比（Finviz 备用）
4. **综合评分**：所有 7 个组成部分的加权平均值
5. **排名**：按综合评分排序（最高优先）
6. **报告**：生成 JSON + Markdown 输出

**预期执行时间（第三阶段）：**
- 40 只股票：**~2 分钟**（每只股票额外获取 52 周历史数据用于 L 组成部分）
- Finviz 备用增加了 ~2 秒/股票（速率限制）
- L 组成部分需要每只股票的 365 天历史数据

**Finviz 备用行为：**
- 当 FMP `sharesOutstanding` 不可用时自动触发
- 从 Finviz.com 抓取机构持股百分比（免费，无需 API 密钥）
- 将 I 组成部分的准确性从 35/100 提高到 60-100/100
- 用户看到：`✅ 使用 Finviz 机构持股数据为 NVDA：68.3%`

### 第四步：读取和解析筛选结果

脚本生成两个输出文件：
- `canslim_screener_YYYY-MM-DD_HHMMSS.json` - 结构化数据
- `canslim_screener_YYYY-MM-DD_HHMMSS.md` - 人类可读报告

读取 Markdown 报告以识别顶级候选股：

```bash
# 找到最新的报告
ls -lt canslim_screener_*.md | head -1

# 读取报告
cat canslim_screener_YYYY-MM-DD_HHMMSS.md
```

**报告结构（第三阶段 - 完整 CANSLIM）：**
- 市场状况摘要（趋势、M 评分、警告）
- 顶级 N 个 CANSLIM 候选股（排序，N = --top 参数）
- 每只股票：
  - 综合评分和评级（卓越+ / 卓越 / 强劲 / 等级）
  - 组成部分分析（C、A、N、S、L、I、M 评分及详细信息）
  - 解释（评级描述、指导、最弱的组成部分）
  - 警告（质量问题、市场状况、数据源说明）
- 统计摘要（评级分布）
- 方法论说明（第三阶段：C、A、N、S、L、I、M - 100% 覆盖）

**报告中组成部分的详细信息：**
- **S 组成部分**："上涨/下跌成交量比率：1.06 ✓ 积累"
- **L 组成部分（第三阶段.1）**："3m/6m/12m：+12.4%/+18.7%/+44.1% (rel +5.2%/+8.3%/+22.0%) | RS：88 (强劲)"
- **I 组成部分**："6199 名持有人，68.3% 持股 ⭐ 超级投资者"

在第三阶段.1 报告中候选股列表上方出现一个新的 **摘要表**，显示排名、代码、综合评分、评级、RS 评级和 RS 百分位数，以便快速扫描。

### 第五步：分析顶级候选股并提供建议

审查顶级排名的股票并进行交叉参考：

**参考文档：**
1. `references/interpretation_guide.md` - 了解评级带和投资组合规模
2. `references/canslim_methodology.md` - 深入了解组成部分含义（现在包括 S 和 I）
3. `references/scoring_system.md` - 了解评分公式（第三阶段权重）

**分析框架：**

对于 **卓越+ 股票（90-100 分）**：
- 所有组成部分接近完美（C≥85, A≥85, N≥85, S≥80, L≥85, I≥80, M≥80）
- 指导：立即买入，激进仓位规模（15-20% 的投资组合）
- 示例： "NVDA 评分 97.2 - 爆炸性季度收益 (100), 强劲的 3 年增长 (95), 在新高 (98), 成交量积累 (85), RS 领先 (92), 强劲的机构支持 (90), 上升趋势 (100)"

对于 **卓越股票（80-89 分）**：
- 卓越的基本面 + 强劲的动量
- 指导：强烈买入，标准规模（10-15% 的投资组合）

对于 **强劲股票（70-79 分）**：
- 在所有组成部分中都很稳固，有轻微弱点
- 指导：买入，标准规模（8-12% 的投资组合）
- 第三阶段示例： "股票评分 77.5 - 强劲的收益 (85), 稳固的增长 (80), 接近高点 (70), 积累 (60), RS 领先 (75), 良好的机构 (60), 上升趋势 (90)"

对于 **高于平均水平股票（60-69 分）**：
- 符合标准，一个组成部分较弱
- 指导：回调时买入，保守规模（5-8% 的投资组合）

**熊市覆盖：**
- 如果 M 组成部分 = 0（检测到熊市），**无论其他分数如何，都不要买入**
- 指导：提高 80-100% 的现金，等待市场复苏
- CANSLIM 在熊市中不起作用（4 只股票中有 3 只跟随市场趋势）
