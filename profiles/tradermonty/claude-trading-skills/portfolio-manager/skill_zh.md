# 投资组合管理器

## 概述

通过与 Alpaca MCP 服务器集成来获取实时持仓数据，然后执行涵盖资产配置、多元化、风险指标、个股评估和再平衡建议的全面分析。生成包含可操作见解的详细投资组合报告。

该技能利用 Alpaca 的经纪 API 通过 MCP（模型上下文协议）访问实时投资组合数据，确保分析基于实际当前头寸，而不是手动输入的数据。

## 使用场景

在以下用户请求时调用此技能：
- "分析我的投资组合"
- "查看我的当前持仓"
- "我的资产配置是多少？"
- "检查我的投资组合风险"
- "我应该再平衡我的投资组合吗？"
- "评估我的持仓"
- "投资组合绩效回顾"
- "我应该买入或卖出哪些股票？"
- 任何涉及投资组合级分析或管理的请求

## 前提条件

### Alpaca MCP 服务器设置

此技能需要配置并连接 Alpaca MCP 服务器。MCP 服务器提供对以下内容的访问：
- 当前投资组合头寸
- 账户净值和买入权限
- 历史头寸和交易记录
- 持有证券的市场数据

**使用的 MCP 服务器工具：**
- `get_account_info` - 获取账户净值、买入权限、现金余额
- `get_positions` - 检索所有当前头寸，包括数量、成本基础和市场价值
- `get_portfolio_history` - 历史投资组合绩效数据
- 用于价格报价和基本面的市场数据工具

如果 Alpaca MCP 服务器未连接，请告知用户并从 `references/alpaca-mcp-setup.md` 提供设置说明。

### REST 回退连接检查

从仓库根目录运行连接检查。首先使用模拟凭证；
切勿将凭证粘贴到报告中或将它们提交到仓库。

```bash
export ALPACA_API_KEY="<alpaca-key-id>"
export ALPACA_SECRET_KEY="<alpaca-secret-key>"
export ALPACA_PAPER="true"
uv run python skills/portfolio-manager/scripts/check_alpaca_connection.py
```

该命令将写入经过编辑的诊断摘要到 stdout，并且仅在账户和头寸端点成功时才返回零。它不会创建报告文件或下订单。

## 工作流程

### 第 1 步：通过 Alpaca MCP 或 REST 回退获取投资组合数据

当可用时，使用 Alpaca MCP 服务器工具收集当前投资组合信息。在计划的 Hermes 工作中，即使存在 Alpaca 凭证，MCP 工具也可能不可用；在这种情况下，直接使用 Alpaca REST API 与 `ALPACA_API_KEY`、`ALPACA_SECRET_KEY` 和 `ALPACA_PAPER`。

**1.1 获取账户信息：**
```
首选：使用 mcp__alpaca__get_account_info 获取：
- 账户净值（投资组合总价值）
- 现金余额
- 买入权限
- 账户状态

回退 REST 端点：
- 模拟：https://paper-api.alpaca.markets/v2/account
- 实时： https://api.alpaca.markets/v2/account
标头：
- APCA-API-KEY-ID=$ALPACA_API_KEY
- APCA-API-SECRET-KEY=$ALPACA_SECRET_KEY
```

**1.2 获取当前持仓：**
```
首选：使用 mcp__alpaca__get_positions 获取所有持仓：
- 证券代码
- 持有数量
- 平均入场价格（成本基础）
- 当前市场价格
- 当前市场价值
- 未实现盈亏（美元和百分比）
- 持仓占投资组合的百分比

回退 REST 端点：
- 模拟：https://paper-api.alpaca.markets/v2/positions
- 实时： https://api.alpaca.markets/v2/positions
```

**1.3 获取投资组合历史（可选）：**
```
首选：使用 mcp__alpaca__get_portfolio_history 进行绩效分析：
- 历史净值
- 时间加权回报计算
- 回撤分析

回退 REST 端点：
- /v2/account/portfolio/history
```

**计划任务回退纪律：**
- 清晰标记来源为 `Alpaca REST 回退` 而不是 MCP。
- 使用 `ALPACA_PAPER=true` 选择模拟端点；否则使用实时端点。
- 仍然验证长期市场价值加上现金大约与净值相吻合，并在 `long_market_value > equity` 时突出显示保证金/杠杆。
- 对于每周核心投资组合 cron 任务，使用净值作为分母以及总市值计算敞口：`gross_long_exposure = long_market_value / equity`，`cash_pct = cash / equity`，并在总敞口明显高于 100% 或现金为负时明确标记保证金融资投资组合。不要让行业权重看起来无害，当账户杠杆时仅使用总长头寸分母。

**当请求强调股息持仓或强制审查触发时，从实时持仓构建标准化监控输入并将其交给 `kanchi-dividend-review-monitor` 而不是将股息审查视为仅叙述性部分。当请求账户位置笔记时，也为 `kanchi-dividend-us-tax-accounting` 构建税务规划输入；如果账户类型或持有期窗口不可用，则将其标记为降级。**

**数据验证：**
- 验证所有持仓都有有效的证券代码
- 确认市场价值总和约等于账户净值
- 检查是否有任何过时或非活跃的持仓
- 处理边缘情况（分数股、期权、如果支持加密货币）

### 第 2 步：丰富持仓数据

对于投资组合中的每个持仓，收集额外的市场数据和基本面：

**2.1 当前市场数据：**
- 实时或延迟的价格报价
- 每日交易量和流动性指标
- 52 周区间
- 市值

**2.2 基本面数据：**
使用 WebSearch 或可用的市场数据 API 获取：
- 行业和行业分类
- 关键估值指标（市盈率、市净率、股息收益率）
- 最近收益和财务健康状况指标
- 分析师评级和价格目标
- 最近新闻和重大发展

**2.3 技术分析：**
- 价格趋势（20 日、50 日、200 日移动平均线）
- 相对强度
- 支撑和阻力水平
- 动量指标（RSI、MACD 如果可用）

### 第 3 步：投资组合级分析

使用参考文件中的框架执行全面的投资组合分析：

#### 3.1 资产配置分析

**阅读 references/asset-allocation.md** 以了解配置框架

分析跨多个维度的当前配置：

**按资产类别：**
- 股票与固定收益与现金与另类投资
- 与用户风险配置文件的目标配置进行比较
- 评估配置是否与投资目标匹配

**按行业：**
- 技术、医疗保健、金融、消费等
- 识别行业集中风险
- 与基准行业权重（例如，标普 500）进行比较

**按市值：**
- 大盘股与中盘股与小盘股分布
- 大型市值集中
- 市值多元化得分

**按地域：**
- 美国 vs 国际 vs 新兴市场
- 国内集中风险评估

**输出格式（说明性值）：**
```markdown
## 资产配置

### 当前配置与目标
| 资产类别 | 当前 | 目标 | 差异 |
|-------------|---------|--------|----------|
| 美国股票 | 70.0% | 60.0% | +10.0 pp |

### 行业细分
[饼图描述或包含行业百分比的表格]

### 顶级持仓
| 排名 | 代码 | 占投资组合的百分比 | 行业 |
|------|--------|----------------|--------|
| 1 | AAPL | 8.5% | 技术 |
```

#### 3.2 多元化分析

**阅读 references/diversification-principles.md** 以了解多元化理论

评估投资组合多元化质量：

**持仓集中度：**
- 识别顶级持仓及其总权重
- 标记任何单个持仓是否超过 10-15% 的投资组合
- 计算赫芬达尔-赫希曼指数 (HHI) 以进行集中度测量

**行业集中度：**
- 识别主导行业
- 标记任何行业是否超过 30-40% 的投资组合
- 与基准行业多元化进行比较

**相关性分析：**
- 估计主要持仓之间的相关性
- 识别高度相关的持仓（潜在的冗余）
- 评估真实的多元化收益

**持仓数量：**
- 最佳范围：个人投资组合 15-30 股票
- 标记如果多元化不足（<10 股票）或过度多元化（>50 股票）

**输出（说明性值）：**
```markdown
## 多元化评估

**集中风险：** [低 / 中 / 高]
- 顶级 5 持仓代表 42% 的投资组合
- 最大单个持仓：AAPL 占 12%

**行业多元化：** [优秀 / 良好 / 一般 / 差]
- 主导行业：技术占 31%
- [跨行业平衡评估]

**持仓数量：** [最佳 / 多元化不足 / 过度多元化]
- 总持仓：18 股票
- [建议]

**相关性问题：**
- [列出任何高度相关的持仓对]
- [多元化改进建议]
```

#### 3.3 风险分析

**阅读 references/portfolio-risk-metrics.md** 以了解风险测量框架

计算和解释关键风险指标：

**波动性指标：**
- 估计投资组合贝塔（持仓贝塔的加权平均值）
- 单个持仓波动性
- 投资组合标准差（如果可用历史数据）

**下行风险：**
- 最大回撤（从投资组合历史）
- 当前从峰值回撤
- 有重大未实现亏损的持仓

**风险集中度：**
- 高波动性股票（贝塔 > 1.5）的百分比
- 投机性/亏损公司百分比
- 杠杆使用（如果适用）

**尾部风险：**
- 暴露于潜在的黑色天鹅事件
- 单个股票集中风险
- 行业特定事件风险

**输出（说明性值）：**
```markdown
## 风险评估

**整体风险配置：** [保守 / 中等 / 激进]

**投资组合贝塔：** 1.12（市场为 1.00）
- 解释：投资组合比市场[更/少]波动

**最大回撤：** -14.2%（从 $125,000 到 $107,250）
- 当前从峰值回撤：-6.3%

**高风险持仓：**
| 代码 | 占投资组合的百分比 | 贝塔 | 风险因素 |
|--------|----------------|------|-------------|
| NVDA | 11% | 1.65 | 高波动性 |

**风险集中度：**
- 31% 在单一行业（技术）
- 18% 在贝塔高于 1.5 的股票
- [其他集中风险]

**风险评分：** 68/100（中等风险）
```

#### 3.4 绩效分析

使用可用数据评估投资组合绩效：

**绝对回报：**
- 整体投资组合未实现盈亏（美元和百分比）
- 表现最好的持仓（按百分比收益前 5）
- 表现最差的持仓（按百分比亏损后 5）

**时间加权回报（如果可用历史数据）：**
- 年初回报
- 1 年、3 年、5 年年化回报
- 与基准（标普 500、相关指数）进行比较

**持仓级绩效：**
- 胜者与败者比率
- 胜者平均收益
- 败者平均亏损
- 接近 52 周高点/低点的持仓

**输出（说明性值）：**
```markdown
## 绩效回顾

**投资组合总价值：** $100,000
**总盈亏：** $8,500 (+9.3%)
**现金余额：** $5,000 (5% 的投资组合)

**表现最佳者：**
| 代码 | 收益 | 持仓价值 |
|--------|------|----------------|
| AAPL | +22.4% | $12,240 |

**表现最差者：**
| 代码 | 亏损 | 持仓价值 |
|--------|------|----------------|
| INTC | -12.0% | $6,600 |

**与基准比较（说明性值）：**
- 投资组合回报：+9.3%
- 标普 500 回报：+7.8%
- Alpha：+1.5 个百分点
```

### 第 4 步：个股分析

对关键持仓（按投资组合权重前 10-15）执行详细分析：

**阅读 references/position-evaluation.md** 以了解持仓分析框架

对每个重要持仓：

**4.1 当前投资策略验证：**
- 如果已知，为什么启动此持仓？（如果从用户上下文中知道）
- 投资策略是否实现或破裂？
- 最近的公司发展和新闻

**4.2 估值评估：**
- 当前估值指标（市盈率、市净率等）
- 与历史估值范围进行比较
- 与行业同行进行比较
- 过高估 / 公平 / 低估评估

**4.3 技术健康状况：**
- 价格趋势（上升趋势、下降趋势、横盘）
- 持仓相对于移动平均线
- 支撑和阻力水平
- 动量状态

**4.4 持仓规模：**
- 当前在投资组合中的权重
- 考虑到信念和风险，规模是否适当？
- 过度配置或配置不足 vs 最佳

**4.5 行动建议：**
- **持有** - 持仓规模合适且策略完好
- **增持** - 配置不足，策略加强
- **减持** - 过度配置或估值拉伸
- **卖出** - 策略破裂，有更好的机会

**每个持仓的输出（说明性值）：**
```markdown
### AAPL - Apple Inc. (8.5% 的投资组合)

**持仓详情：**
- 股票：50
- 平均成本：$150.00
- 当前价格：$170.00
- 市值：$8,500
- 未实现盈亏：$1,000 (+13.3%)

**基本面快照：**
- 行业：[行业]
- 市值：$3.2T
- 市盈率：31.4 | 股息收益率：0.5%
- 最近发展：[关键新闻或收益]

**技术状态：**
- 趋势：[上升趋势 / 下降趋势 / 横盘]
- 价格 vs 50 日 MA：高于 4.2%
- 支撑：$162.00 | 阻力：$176.00

**持仓评估：**
- **策略状态：** [完好 / 削弱 / 破裂 / 加强]
- **估值：** [低估 / 公平 / 过高估]
- **持仓规模：** [最佳 / 过度配置 / 配置不足]

**建议：** [持有 / 增持 / 减持 / 卖出]
**理由：** [1-2 句话解释]
```

### 第 5 步：再平衡建议

**阅读 references/rebalancing-strategies.md** 以了解再平衡方法

生成具体的再平衡建议：

**5.1 确定再平衡触发因素：**
- 持仓已显著偏离目标权重
- 需要调整的行业/资产类别配置
- 需要减持的过度配置持仓（超过阈值）
- 需要增持的不足区域（低于阈值）
- 税务考虑（资本利得影响）

**5.2 制定再平衡计划：**

**需要减持的持仓：**
- 超过目标偏差的过度配置持仓（>阈值偏差）
- 价格上涨显著的股票（估值问题）
- 超过 15-20% 投资组合的集中持仓
- 策略破裂的持仓

**需要增持的持仓：**
- 不足的行业或资产类别
- 高信念目前配置不足的持仓
- 改善多元化的新机会

**现金部署：**
- 如果有盈余现金（>10% 的投资组合），建议部署
- 根据机会和配置差距优先考虑

**5.3 优先级：**
按优先级对再平衡行动进行排序：
1. **立即** - 风险降低（减持集中持仓）
2. **高优先级** - 主要配置偏差（>10% 从目标）
3. **中优先级** - 适度偏差（5-10% 从目标）
4. **低优先级** - 精细调整和机会性调整

**输出（说明性值）：**
```markdown
## 再平衡建议

### 摘要
- **需要再平衡：** [是 / 否 / 可选]
- **主要原因：** [集中风险 / 行业偏差 / 现金部署 / 等等]
- **估计交易：** 2 个卖出订单，3 个买入订单

### 推荐行动

#### 高优先级：风险降低
**减持 NVDA** 从 18% 到 12% 的投资组合
- **要卖出的股份数量：** 25 股（约 $3,000）
- **理由：** [过度配置 / 估值延伸 / 等等]
- **税务影响：** $600 资本利得（估计）

#### 中优先级：资产配置
**增持投资级债券敞口**
- **目标：** 从 10% 增加到 20%
- **建议证券：** [选择符合用户委托的流动性证券]
- **投资金额：** 约 $10,000

#### 现金部署
**当前现金：** $5,000 (5% 的投资组合)
- **建议：** [部署 / 保持以寻找机会 / 减少到目标]
- **建议配置：** [跨行业/股票的分配]

### 实施计划
1. [第一个行动 - 最高优先级]
2. [第二个行动]
3. [第三个行动]
...

**时间考虑：**
- [税务年度规划 / 收益季节 / 市场状况]
- [如果适用，建议分阶段执行]
```

### 第 7 步：交互式后续处理

准备好回答后续问题：

**常见问题：**

**"为什么我应该卖出 [SYMBOL]?"**
- 解释具体担忧（估值、策略破裂、集中度）
- 提供支持数据
- 如果适用，提供替代持仓

**"我应该买什么来替代?"**
- 建议具体的股票以改善配置
- 解释它们如何解决投资组合差距
- 提供简要的投资策略

**"我最大的风险是什么?"**
- 识别主要风险因素（集中度、行业敞口、波动性）
- 量化风险
- 建议缓解策略

**"我的投资组合与 [基准] 相比如何?"**
- 比较配置、行业权重、风险指标
- 突出显示主要差异
- 评估差异是否合理

**"我应该现在再平衡还是等待?"**
- 考虑市场状况、税务影响、交易成本
- 提供时间建议及理由

**"你能更详细地分析 [特定持仓] 吗?"**
- 如果需要，使用 us-stock-analysis 技能执行深度分析
- 将结果整合到投资组合背景中

## 分析框架

### 目标配置模板

此技能包括针对不同投资者配置的参考配置模型：

**阅读 references/target-allocations.md** 以了解详细模型：

- **保守**（资本保全，收入重点）
- **温和**（平衡增长和收入）
- **增长**（长期资本增值）
- **激进**（最大增长，高风险承受能力）

每个模型包括：
- 资产类别目标（股票/债券/现金/另类投资）
- 行业指南
- 市值分布
- 地域配置
- 持仓规模规则

使用这些作为用户未指定其配置策略时的比较基准。

### 风险配置评估

如果用户的目标配置未知，根据以下内容评估适当的风险配置：
- 年龄（如果提到）
- 投资时间线（如果提到）
- 当前配置（揭示偏好）
- 持仓类型（保守型与投机性股票）

**阅读 references/risk-profile-questionnaire.md** 以了解评估框架

## 输出指南

**语气和风格：**
- 客观和分析
- 可操作的推荐，理由清晰
- 承认市场预测的不确定性
- 平衡乐观与风险意识
- 尽可能量化

**数据呈现：**
- 表格用于比较和指标
- 百分比用于配置和回报
- 美元金额用于绝对值
- 全文格式一致

**推荐清晰度：**
- 明确的行动动词（减持、增持、持有、卖出）
- 根据实时持仓规模和当前价格得出具体数量
- 优先级级别（立即、高、中、低）
- 每个推荐的支持理由

**视觉描述：**
- 描述配置细分，如同创建饼图
- 行业权重作为条形图等效物
- 绩效趋势与方向指示器（↑ ↓ →）

## 错误处理

**如果 Alpaca MCP 服务器未连接：**
1. 告知用户需要 Alpaca 集成
2. 提供来自 references/alpaca-mcp-setup.md 的设置说明
3. 提供替代方案：手动数据输入（不太理想，用户提供持仓的 CSV）

**如果 API 返回不完整数据：**
- 继续使用可用数据
- 在报告中注明限制
- 建议手动验证缺失持仓

**如果持仓数据似乎过时：**
- 标记问题
- 建议刷新连接或检查 Alpaca 状态
- 继续进行分析，但对结果持保留意见

**如果用户没有持仓：**
- 承认空投资组合
- 提供投资组合构建指导，而不是分析
- 建议使用 value-dividend-screener 或 us-stock-analysis 获取股票想法

## 高级功能

### 税收亏损套利机会

识别适合税收亏损套利的持仓：
- 亏损 >5% 的持仓
- 持有期考虑（避免洗售规则）
- 替代证券建议（类似但非实质性相同）

### 股息收入分析

对于包含股息支付股票的投资组合：
- 估计年度股息收入
- 股息增长率轨迹
- 股息覆盖率和可持续性
- 长期持仓的股息收益率

### 相关性矩阵

对于包含 5-20 个持仓的投资组合：
- 估计主要持仓之间的相关性
- 识别冗余持仓（相关性 >0.8）
- 建议多元化改进

### 情景分析

模拟投资组合在不同情景下的行为：
- **牛市** (+20% 股票增值)
- **熊市** (-20% 股票下跌)
- **行业轮动** (技术疲软，价值强劲)
- **利率上升** (对增长股票和债券的影响)
