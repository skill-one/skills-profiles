# 市场顶部检测技能

## 目的

使用量化6成分评分系统（0-100）检测市场顶部形成的概率。整合了三种经过验证的市场顶部检测方法：

1. **O'Neil** - 分配日累积（机构卖出）
2. **Minervini** - 领头股恶化模式
3. **Monty** - 防御性板块轮动信号

与泡沫检测器（宏观/多个月评估）不同，此技能专注于**战术性2-8周的时机信号**，这些信号预示着10-20%的市场回调。

## 何时使用此技能

**英文：**
- 用户询问“市场是否见顶？”或“我们是否接近顶部？”
- 用户注意到分配日累积
- 用户观察到防御性板块跑赢成长板块
- 用户看到领头股开始崩盘而指数仍在支撑
- 用户询问减少股票敞口时机
- 用户想评估未来2-8周的回调概率

**日文：**
- 「天井が近い？」「今は利確すべき？」
- ディストリビューションデーの蓄積を懸念
- ディフェンシブセクターがグロースをアウトパフォーム
- 先導株が崩れ始めているが指数はまだ持ちこたえている
- エクスポージャー縮小のタイミング判断
- 今後2〜8週間の調整確率を評価したい

## 前置条件

**必需：**
- **FMP API Key：** 设置 `$FMP_API_KEY` 环境变量或传递 `--api-key`。免费套餐足够（每次执行约33个API调用）。
- **WebSearch访问：** 需要收集标普500广度（50DMA %）和CBOE买入/卖出比率数据。

**可选：**
- **杠杆债务数据：** 增强情绪评分，但通常有1-2个月的滞后。
- **VIX期限结构：** 如果有VIX3M报价，则自动从FMP API检测；通过 `--vix-term` 手动覆盖。

**数据新鲜度：** 所有手动收集的数据应来自最近3个交易日，以进行准确分析。

## 与泡沫检测器的区别

| 方面 | 市场顶部检测器 | 泡沫检测器 |
|------|---------------|-----------|
| 时间范围 | 2-8周 | 月至年 |
| 目标 | 10-20%回调 | 泡沫崩溃（30%+） |
| 方法论 | O'Neil/Minervini/Monty | Minsky/Kindleberger |
| 数据 | 价格/成交量 + 广度 | 估值 + 情绪 + 社交 |
| 评分范围 | 0-100综合 | 0-15分 |

## 执行工作流程

### 第一阶段：通过WebSearch收集数据

在运行Python脚本之前，使用WebSearch收集以下数据。
**数据新鲜度要求：** 所有数据必须来自最近3个交易日。过时的数据会降低分析质量。

```
1. 标普500广度（200DMA以上%）
   从TraderMonty CSV自动获取（无需WebSearch）
   脚本会自动从GitHub页面CSV数据获取此数据。
   覆盖：--breadth-200dma [值] 以使用手动值。
   禁用：--no-auto-breadth 完全跳过自动获取。

2. [必需] 标普500广度（50DMA以上%）
   有效范围：20-100
   主要搜索：“标普500超过50天移动平均的股票百分比”
   备用： "market breadth 50dma site:barchart.com"
   直接备用：当搜索片段质量差时：获取 `https://www.barchart.com/stocks/quotes/$S5FI/overview` 并提取嵌入的 `lastPrice` / `tradeTime`（“标普500超过50天平均的股票”）。
   记录数据日期

3. [必需] CBOE股票买入/卖出比率
   有效范围：0.30-1.50
   主要搜索：“CBOE股票买入/卖出比率今天”
   备用： "CBOE总买入/卖出比率当前"
   备用： "买入/卖出比率 site:cboe.com"
   当Cboe CSV端点过时时直接备用：获取 `https://ycharts.com/indicators/cboe_equity_put_call_ratio` 并解析“最后值”/“最新周期”表字段。将其视为次要来源并在新鲜度笔记中引用。
   记录数据日期

4. [可选] VIX期限结构
   值：陡峭的期货溢价 / 溢价 / 平价 / 背离
   主要搜索：“VIX VIX3M比率期限结构今天”
   备用： "VIX期货期限结构溢价背离"
   注意：如果VIX3M报价可用，则从FMP API自动检测。
   CLI --vix-term覆盖自动检测。

5. [可选] 杠杆债务同比增长%
   主要搜索：“FINRA杠杆债务最新同比增长百分比”
   备用： "NYSE杠杆债务月度"
   注意：通常有1-2个月的滞后。记录报告月份。
```

### 第二阶段：执行Python脚本

使用收集的数据作为CLI参数运行脚本：

```bash
python3 skills/market-top-detector/scripts/market_top_detector.py \
  --api-key $FMP_API_KEY \
  --breadth-50dma [值] --breadth-50dma-date [YYYY-MM-DD] \
  --put-call [值] --put-call-date [YYYY-MM-DD] \
  --vix-term [陡峭的期货溢价|溢价|平价|背离] \
  --margin-debt-yoy [值] --margin-debt-date [YYYY-MM-DD] \
  --output-dir reports/ \
  --context "消费者信心=[值]" "黄金价格=[值]"
# 200DMA广度从TraderMonty CSV自动获取。
# 如需覆盖，请使用 --breadth-200dma [值]。
# 如需禁用，请使用 --no-auto-breadth 跳过自动获取。
```

脚本将：
1. 从FMP API获取标普500、QQQ、VIX报价和历史数据
2. 获取领先ETF（ARKK、WCLD、IGV、XBI、SOXX、SMH、KWEB、TAN）数据
3. 获取板块ETF（XLU、XLP、XLV、VNQ、XLK、XLC、XLY）数据
4. 计算所有6个成分
5. 生成综合评分和报告

### 第三阶段：展示结果

向用户展示生成的Markdown报告，突出显示：
- 综合评分和风险区域
- 数据新鲜度警告（如果有数据超过3天）
- 最强的警告信号（最高成分评分）
- 历史比较（最近的顶部模式）
- 假设情景（对关键变化的敏感性）
- 基于风险区域推荐的操作
- 随后日状态（如适用）
- 与上一次运行的Delta（如果存在先前的报告）

## 6成分评分系统

| # | 成分 | 权重 | 数据来源 | 关键信号 |
|---|------|------|----------|----------|
| 1 | 分配日计数 | **25%** | FMP API | 过去25个交易日内的机构卖出 |
| 2 | 领头股健康状况 | **20%** | FMP API | 成长ETF篮子恶化 |
| 3 | 防御性板块轮动 | **15%** | FMP API | 防御性vs成长性的相对表现 |
| 4 | 市场广度背离 | **15%** | 自动（CSV）+WebSearch | 200DMA（自动）/50DMA（WebSearch）广度与指数水平 |
| 5 | 指数技术状况 | **15%** | FMP API | 均线结构、失败的反弹、更低的高点 |
| 6 | 情绪与投机 | **10%** | FMP + WebSearch | VIX、买入/卖出比率、期限结构 |

## 风险区域映射

| 评分 | 区域 | 风险预算 | 操作 |
|------|------|----------|------|
| 0-20 | 绿色（正常） | 100% | 正常操作 |
| 21-40 | 黄色（早期警告） | 80-90% | 收紧止损，减少新入场 |
| 41-60 | 橙色（风险升高） | 60-75% | 对弱势头寸获利了结 |
| 61-80 | 红色（高概率顶部） | 40-55% | 积极获利了结 |
| 81-100 | 危险（顶部形成） | 20-35% | 最大防御，对冲 |

## 交易所日历和重播

在运行检测器之前安装 `requirements.txt`。新鲜度使用XNYS会话而不是工作日。`--as-of YYYY-MM-DD` 接受用于实时评估日期，但历史实时重播因当前报价端点不是点时源而失败关闭。
