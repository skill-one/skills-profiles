# 广阔图表分析师

## 概述

这项技能能够对两种互补的市场广阔图表进行专业分析，这些图表提供战略（中到长期）和战术（短期）的市场视角。分析广阔图表图像以评估市场健康状况，根据回测策略识别交易信号，并制定仓位建议。所有思考和输出均严格使用英语进行。

## 使用场景

在以下情况下使用此技能：
- 用户提供了标普500广阔指数（基于200日移动平均）图表图像进行分析
- 用户提供了美国股市上升趋势股票比率图表图像进行分析
- 用户要求市场广阔评估或市场健康评估
- 用户基于广阔指标询问中期战略仓位
- 用户需要短期战术交易时机信号
- 用户希望获得结合战略和战术的市场展望
- **用户请求广阔分析但不提供图表图像**（CSV数据模式）

不使用此技能的情况：
- 用户询问个股分析（请使用`us-stock-analysis`技能）
- 用户需要没有广阔图表的板块轮动分析（请使用`sector-analyst`技能）
- 用户希望基于新闻的市场分析（请使用`market-news-analyst`技能）

## 前提条件

- **图表图像可选**：来自公共来源的CSV数据是主要数据来源；图表图像提供补充的视觉上下文
- **无需API密钥**：CSV数据从公共GitHub页面获取；无需外部API订阅
- **语言**：所有分析和输出均使用英语进行

## 输出

此技能生成保存在`reports/`目录中的markdown分析报告：
- 仅图表1：`breadth_200ma_analysis_[YYYY-MM-DD].md`
- 仅图表2：`uptrend_ratio_analysis_[YYYY-MM-DD].md`
- 两个图表：`breadth_combined_analysis_[YYYY-MM-DD].md`

报告包括执行摘要、当前读数、信号识别、情景分析（含概率）以及针对不同交易者的可操作仓位建议。

## 核心原则

1. **双时间框架分析**：结合战略（图表1：200MA广阔）和战术（图表2：上升趋势比率）视角
2. **回测策略重点**：应用基于历史模式的经过验证的系统策略
3. **客观信号识别**：专注于明确定义的阈值、转换和标记
4. **英语沟通**：所有分析和报告生成均使用英语进行
5. **可操作建议**：为不同投资者类型提供具体的仓位指导

## 图表类型和目的

### 图表1：标普500广阔指数（基于200日移动平均）

**目的**：中到长期战略市场仓位

**关键元素**：
- **8日移动平均线（橙色线）**：短期广阔趋势，主要入场信号生成器
- **200日移动平均线（绿线）**：长期广阔趋势，主要出场信号生成器
- **红色虚线（73%）**：平均峰值水平 - 市场过热阈值
- **蓝色虚线（23%）**：平均8MA低谷水平 - 极端超卖，绝佳买入机会
- **三角形**：
  - 紫色▼ = 8MA低谷（反转时为买入信号）
  - 蓝色▼ = 200MA低谷（主要周期低点）
  - 红色▲ = 200MA峰值（卖出信号）
- **粉色背景**：下跌周期

**回测策略**：
- **买入**：当8MA从低谷反转（尤其是低于23%时）
- **卖出**：当200MA形成峰值（通常在/高于73%时）
- **结果**：历史表现优异，避免熊市

### 图表2：美国股市上升趋势股票比率

**目的**：短期战术时机和波段交易

**关键元素**：
- **上升趋势股票定义**：高于200MA/50MA/20MA且1个月表现积极的股票
- **绿色区域**：市场处于上升趋势阶段
- **红色区域**：市场处于下跌趋势阶段
- **约10%水平（下方橙色虚线）**：短期底部，极度超卖
- **约40%水平（上方橙色虚线）**：短期顶部，市场过热

**波段交易策略**：
- **做多入场**：当颜色从红色变为绿色（尤其是从<10-15%水平）
- **做空出场**：当颜色从绿色变为红色（尤其是从>35-40%水平）
- **时间框架**：几天到几周

### 步骤1.5：两阶段图表分析（提供图表时必须执行）

**关键**：使用**两阶段分析**方法以防止将历史数据误读为当前值。

#### 阶段1：完整图表分析（历史上下文）

首先，分析完整图表图像以了解：
- 整体历史趋势和周期
- 关键历史事件（低谷、峰值、复苏）
- 长期模式和上下文

#### 阶段2：右侧边缘聚焦分析（当前值）

然后，提取并分析图表的**最右侧25%**，以准确确定当前值。

**执行提取右侧边缘的Python脚本**：

```bash
python3 skills/breadth-chart-analyst/scripts/extract_chart_right_edge.py <image_path> --percent 25
```

#### 为什么必须执行两阶段分析

| 阶段 | 目的 | 提取内容 |
|------|------|----------|
| **阶段1（完整）** | 历史上下文，趋势周期 | 整体模式，过去的低谷/峰值 |
| **阶段2（右侧边缘）** | **当前值（关键）** | 8MA值，200MA值，当前颜色，当前斜率 |

**此两阶段分析可防止的常见错误**：
- LLM读取2025年中期低谷（8MA ~25-30%）而不是当前值（8MA ~60-65%）
- 通过隔离右侧边缘，当前数据是明确的

#### 分析协议

1. **读取完整图表** → 记录历史上下文
2. **运行提取脚本** → 生成右侧边缘图像
3. **读取右侧边缘图像** → 以高置信度记录当前值
4. **交叉检查**：如果阶段1和阶段2的值差异很大，**阶段2（右侧边缘）优先**
5. **报告两者**：包括阶段1上下文和阶段2当前值

### 步骤4：分析图表1（200MA-Based Breadth Index）

如果提供图表1，进行系统分析：

#### 4.1 提取当前读数

从图表图像中识别：
- **当前8MA水平（橙色线）**：具体百分比
- **当前200MA水平（绿线）**：具体百分比
- **8MA斜率**：上升、下降或平缓
- **200MA斜率**：上升、下降或平缓
- **距离73%阈值的距离**：距离过热有多近
- **距离23%阈值的距离**：距离极端超卖有多近
- **最新日期**可见于图表

#### 4.1.5 关键：最新数据点详细趋势分析

**此步骤是必须的，以避免误读最近的趋势变化。**

**关键警告**：图表可能具有欺骗性。大多数分析错误是因为分析师：
1. 混淆8MA（橙色）和200MA（绿色）
2. 读取历史趋势而不是当前方向
3. 误识别哪个线在上升或下降

**在分析趋势方向之前，首先确认线颜色**：
- ✓ **8MA = 橙色线**（移动更快，更波动）
- ✓ **200MA = 绿线**（移动较慢，更平滑）
- 如果不确定哪个是哪个，停止并重新检查图表图例/颜色

专注于图表最右侧的**3-5个数据点**（最近几周）：

**对于8MA（橙色线） - 分析最新的轨迹**：
1. **识别绝对最新位置**：图表最右侧的8MA在哪里？
2. **回溯3-5个数据点**（大约3-5周）：
   - 1周前8MA是多少？
   - 2周前8MA是多少？
   - 3周前8MA是多少？
3. **计算方向变化**：
   - 8MA的最新值比1周前高还是低？
   - 8MA的最新值比2周前高还是低？
   - 趋势：持续上升、持续下降还是混合？
4. **确定当前斜率**（不是历史斜率）：
   - **上升**：最新数据点比前2-3点高，并且显示上升趋势
   - **下降**：最新数据点比前2-3点低，并且显示下降趋势
   - **平缓**：最新数据点大约等于前几个点（在2-3%以内）

**关键问题要回答**：
- [ ] 8MA目前在最右侧边缘是上升还是下降？
- [ ] 如果最近有低谷，8MA是否**持续**了上升趋势，还是已经反转？
- [ ] 连续上升的周期数：8MA已经连续上升了几个周期？（需要2-3个周期确认）
- [ ] 连续下降的周期数：8MA已经连续下降？（如果在低谷后下降表示反转失败）

**对于200MA（绿色线） - 分析最新的轨迹**：
1. **识别绝对最新位置**：图表最右侧的200MA在哪里？
2. **回溯4-6周**：
   - 2周前200MA是多少？
   - 4周前200MA是多少？
3. **确定当前斜率**：
   - 在最近一段时间内是上升、下降还是平缓？

**失败反转检测**（关键）：
如果最近识别了8MA低谷（紫色▼）：
- [ ] 8MA是否在低谷后开始上升？
- [ ] 8MA是否在1-2个周期后再次下降？
- [ ] 8MA目前是否在下降？
- **如果**回答是肯定的：这是一个**失败的反转** - 不要入场，信号无效

**示例分析格式**：
```
最新8MA数据点（最右侧到最左侧）:
- 当前（第0周）：48%
- 1周前：52%
- 2周前：55%
- 3周前：50%

分析：8MA在下降。它从50%上升到55%（第3-2周），但之后已经下降到48%。
这显示了失败的反转模式 - 弹升是暂时的，下跌趋势已经恢复。
斜率：下降（不是上升！）
```

**必须交叉检查**（以捕获误读）：
在确定趋势后，问自己：
- [ ] "如果我认为8MA在上升，但它实际上一直在下降，那会是什么样子？"
  - 回答：最右侧的数据点比前几个点低（确认下降）
- [ ] "我的分析是否与图表最右侧的橙色线视觉斜率一致？"
  - 如果橙色线在图表最右侧视觉上斜向下 → 它在下降
  - 如果橙色线在图表最右侧视觉上斜向上 → 它在上升
- [ ] "最右侧边缘是否有粉色背景（下跌周期）？"
  - 如果有 → 这确认了下跌条件，8MA很可能在下降
- [ ] "8MA和200MA是收敛（越来越近）还是发散（越来越远）？"
  - 从下方收敛 → 可能形成死亡交叉 → 熊市
  - 从上方收敛 → 可能形成黄金交叉 → 牛市
- [ ] "如果不确定任何趋势方向，明确说明不确定性，而不是猜测

### 步骤5：分析图表2（Uptrend Stock Ratio）

- **当前颜色**：绿色（上升趋势）或红色（下跌趋势）

- **距离10%阈值的距离**：距离极度超卖有多近

寻找并记录：

- **当前颜色阶段的持续时间**：当前趋势持续了多久

根据图表中的具体证据支持分类。

#### 5.4 确定交易仓位

应用波段交易策略规则：

**检查入场长多信号**：
- 颜色从红色变为绿色？
- 转换时是否处于超卖水平（<15%）？
- 转换是否得到确认（2-3天绿色）？

**检查出场长多信号**：
- 颜色从绿色变为红色？
- 转换时是否处于过买水平（>35%）？
- 动能是否减弱？

**当前仓位**：长多、平缓、准备入场或准备出场

#### 5.5 制定情景

创建2-3个情景，并给出概率估计：
- 基本情景（最高概率）
- 其他情景
- 每个情景包括：描述、支持因素、交易含义、关键水平
