# 赚益日历

## 概述

该技能使用 Financial Modeling Prep (FMP) API 获取美国股票的即将到来的盈利公告。它专注于市值重大的公司（中盘股及以上，超过 20 亿美元），这些公司可能会影响市场波动。该技能生成结构化的 markdown 报告，显示哪些公司在接下来的一周内报告盈利，并按日期和时间（开盘前、收盘后或未公布时间）进行分组。

**主要功能**：
- 使用 FMP API 获取可靠、结构化的盈利数据
- 按市值（>20 亿美元）过滤，专注于可能影响市场的公司
- 包含每股收益（EPS）和收入预估
- 多环境支持（CLI、桌面版、网页版）
- 灵活的 API 密钥管理
- 按日期、时间和市值组织

### 第 1 步：获取当前日期并计算目标周

**关键**：始终首先获取准确的当前日期。

- 注意："今天的日期"由环境提供（<env> 标签）
- 计算目标周：从当前日期起的未来 7 天

**日期范围计算**：
```
当前日期：[例如，2025 年 11 月 2 日]
目标周开始：[当前日期 + 1 天，例如，2025 年 11 月 3 日]
目标周结束：[当前日期 + 7 天，例如，2025 年 11 月 9 日]
```

**为什么这很重要**：
- 盈利日历具有时效性
- "下周"必须从实际当前日期计算

**以 YYYY-MM-DD 格式表示日期，以兼容 API**。

### 第 4 步：通过 FMP API 获取盈利数据

使用 Python 脚本从 FMP API 获取盈利数据。

**脚本位置**：
```
scripts/fetch_earnings_fmp.py
```

**执行**：

**选项 A：使用环境变量 (CLI)**：
```bash
python scripts/fetch_earnings_fmp.py 2025-11-03 2025-11-09
```

**选项 B：使用会话 API 密钥 (桌面版/网页版)**：
```bash
python scripts/fetch_earnings_fmp.py 2025-11-03 2025-11-09 "${API_KEY}"
```

**脚本工作流程**（自动）：
1. 验证 API 密钥和日期参数
2. 调用 FMP 盈利日历 API（日期范围）
3. 获取公司概况（市值、行业、部门）
4. 过滤市值 >20 亿美元的公司
5. 规范时间（BMO/AMC/TAS）
6. 按日期 → 时间 → 市值（降序）排序
7. 将 JSON 输出到标准输出

**预期输出格式**（JSON）：
```json
[
  {
    "symbol": "AAPL",
    "companyName": "Apple Inc.",
    "date": "2025-11-04",
    "timing": "AMC",
    "marketCap": 3000000000000,
    "marketCapFormatted": "$3.0T",
    "sector": "Technology",
    "industry": "Consumer Electronics",
    "epsEstimated": 1.54,
    "revenueEstimated": 123400000000,
    "fiscalDateEnding": "2025-09-30",
    "exchange": "NASDAQ"
  },
  ...
]
```

**保存到文件**（建议用于与报告生成器一起使用）：
```bash
python scripts/fetch_earnings_fmp.py 2025-11-03 2025-11-09 "${API_KEY}" > earnings_data.json
```

或捕获到变量：
```bash
earnings_data=$(python scripts/fetch_earnings_fmp.py 2025-11-03 2025-11-09 "${API_KEY}")
```

**错误处理**：

如果脚本返回错误：
- **401 未授权**：无效的 API 密钥 → 验证密钥或重新输入
- **429 达到速率限制**：每天 250 次调用已用完 → 等待或升级套餐
- **空结果**：日期范围内没有盈利 → 扩大日期范围或在报告中注明
- **连接错误**：网络问题 → 重试或使用缓存数据（如果可用）

## 故障排除

### 问题：API 密钥无效

**解决方案**：
- 验证 API 密钥是否正确（小心复制粘贴）
- 检查 API 密钥是否有效（登录 FMP 控制面板）
- 确保密钥前后没有多余空格
- 尝试从 FMP 控制面板生成新的 API 密钥

### 问题：脚本返回空结果

**解决方案**：
- 验证日期范围在将来（不是过去的日期）
- 检查日期格式为 YYYY-MM-DD
- 尝试更宽的日期范围（例如，14 天而不是 7 天）
- 验证公司在该周内确实有宣布盈利日期

### 问题：遗漏主要公司

**解决方案**：
- 公司可能尚未宣布盈利日期
- 一些公司可能在最后一天（1-2 天前）才宣布日期
- 与公司投资者关系网站交叉验证
- 市值可能已低于 2 亿美元门槛

### 问题：达到速率限制（429 错误）

**解决方案**：
- 免费套餐：每天 250 次API调用
- 每周报告使用 ~3-5 次API调用
- 检查是否有其他工具/脚本使用相同的 API 密钥
- 等待 24 小时重置速率限制
- 如有需要，考虑升级到付费套餐

### 问题：脚本执行错误

**解决方案**：
- 验证已安装 Python 3：`python3 --version`
- 安装 requests 库：`pip install requests`
- 检查脚本具有执行权限：`chmod +x fetch_earnings_fmp.py`
- 明确使用 python3 运行：`python3 fetch_earnings_fmp.py ...`
