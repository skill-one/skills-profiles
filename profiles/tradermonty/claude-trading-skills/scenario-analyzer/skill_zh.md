# 场景分析器

## 概述

该技能从新闻标题开始，分析中到长期（18个月）的投资场景。它按顺序调用两个专业代理（`scenario-analyst` 和 `strategy-reviewer`），并将多角度分析与批判性审查整合到一份综合报告中。

## 何时使用此技能

当您需要：

- 分析新闻标题的中到长期投资影响
- 构建多个18个月场景
- 将行业/股票影响组织为1级/2级/3级效应
- 需要包含第二意见的综合分析

**示例：**
```
/scenario-analyzer "美联储加息50基点，暗示未来可能继续加息"
/scenario-analyzer "中国宣布对美半导体征收新关税"
/scenario-analyzer "OPEC+同意每天削减200万桶石油产量"
```

## 前置条件

- **API密钥**：无（仅使用 WebSearch/WebFetch）
- **MCP服务器**：无
- **依赖项**：场景分析器代理和策略审查器代理必须通过任务工具可用

## 工作流程

### 第一阶段：准备

#### 第1.1步：标题解析

解析用户提供的标题。

1. **标题检查**
   - 确认是否将标题作为参数传递
   - 如果未提供，请要求用户输入

2. **关键词提取**
   - 关键实体（公司名称、国家名称、机构名称）
   - 数字数据（利率、价格、数量）
   - 行动（提高、削减、宣布、同意等）

#### 第1.2步：事件类型分类

将标题分类到以下类别之一：

| 类别 | 示例 |
|----------|----------|
| 货币政策 | FOMC、ECB、BOJ、加息、降息、QE/QT |
| 地缘政治 | 战争、制裁、关税、贸易摩擦 |
| 监管与政策 | 环境监管、金融监管、反垄断 |
| 技术 | AI、电动汽车、可再生能源、半导体 |
| 商品 | 原油、黄金、铜、农产品 |
| 公司与并购 | 收购、破产、盈利、行业重组 |

#### 第1.3步：参考资料加载

根据事件类型，加载相关参考资料：

```
读取 references/headline_event_patterns.md
读取 references/sector_sensitivity_matrix.md
读取 references/scenario_playbooks.md
```

**参考资料内容：**
- `headline_event_patterns.md`：历史事件模式和市场反应
- `sector_sensitivity_matrix.md`：事件×行业影响幅度矩阵
- `scenario_playbooks.md`：场景构建模板和最佳实践

---

### 第二阶段：代理调用

#### 第2.1步：调用 scenario-analyst

使用代理工具调用主要分析代理。

```
代理工具：
- subagent_type: "scenario-analyst"
- prompt: |
    对以下标题进行18个月场景分析。

    ## 目标标题
    [输入标题]

    ## 事件类型
    [分类结果]

    ## 参考信息
    [加载参考资料的摘要]

    ## 分析要求
    1. 使用 WebSearch 收集过去2周的相关新闻
    2. 构建3个场景——基准/看涨/看跌（概率总和为100%）
    3. 按行业分析1级/2级/3级影响
    4. 选择3-5只正影响和3-5只负影响的股票（仅限美国市场）
    5. 以英文输出所有内容
```

**预期输出：**
- 相关新闻文章列表
- 3个场景（基准/看涨/看跌）的详细信息
- 行业影响分析（1级/2级/3级）
- 股票推荐列表

#### 第2.2步：调用 strategy-reviewer

使用场景分析器的结果，调用审查代理。

```
代理工具：
- subagent_type: "strategy-reviewer"
- prompt: |
    审查以下场景分析。

    ## 目标标题
    [输入标题]

    ## 分析结果
    [场景分析器的完整输出]

    ## 审查要求
    从以下角度进行审查：
    1. 遗漏的行业/股票
    2. 场景概率分配的有效性
    3. 影响分析的逻辑一致性
    4. 检测乐观/悲观偏见
    5. 提出替代场景
    6. 时间表的现实性

    以英文输出建设性和具体的反馈。
```

**预期输出：**
- 指出盲点
- 对场景概率的意见
- 指出偏见
- 提出替代场景
- 最终建议

---

### 第三阶段：整合 & 报告生成

#### 第3.1步：整合结果

整合两个代理的输出，生成最终的投资判断。

**整合点：**
1. 填充审查中提出的盲点
2. 调整概率分配（如有必要）
3. 考虑偏见进行最终判断
4. 制定具体行动计划

#### 第3.2步：生成报告

以以下格式生成最终报告并保存到文件。

**保存位置：** `reports/scenario_analysis_<主题>_YYYYMMDD.md`

```markdown
# 标题场景分析报告

**分析时间**： YYYY-MM-DD HH:MM
**目标标题**： [输入标题]
**事件类型**： [分类类别]

---

## 1. 相关新闻文章
[场景分析器收集的新闻列表]

## 2. 场景概述（展望18个月）

### 基准案例（XX%概率）
[场景详细信息]

### 看涨案例（XX%概率）
[场景详细信息]

### 看跌案例（XX%概率）
[场景详细信息]

## 3. 行业/行业影响

### 1级影响（直接）
[影响表格]

### 2级影响（价值链/相关行业）
[影响表格]

### 3级影响（宏观/监管/技术）
[影响表格]

## 4. 预期受益的股票（3-5个代码）
[股票表格]

## 5. 预期受损的股票（3-5个代码）
[股票表格]

## 6. 第二意见/审查
[strategy-reviewer输出]

## 7. 最终投资判断与启示

### 推荐行动
[基于审查的具体行动]

### 风险因素
[关键风险列表]

### 监控点
[指标/事件跟踪]

---
**生成者**： scenario-analyzer 技能
**代理**： scenario-analyst, strategy-reviewer
```

#### 第3.3步：保存报告

1. 如果不存在，创建 `reports/` 目录
2. 保存为 `scenario_analysis_<主题>_YYYYMMDD.md`（例如，`scenario_analysis_venezuela_20260104.md`）
3. 通知用户保存完成
4. **不要直接保存到项目根目录**

## 重要提示

### 语言
- 所有分析和输出均为 **英文**
- 股票代码保持其标准（英文）符号

### 目标市场
- 股票选择仅限 **美国上市股票**
- 包含ADR

### 时间范围
- 场景目标 **18个月**
- 描述为3个阶段：0-6个月 / 6-12个月 / 12-18个月

### 概率分配
- 基准 + 看涨 + 看跌 = **100%**
- 每个场景的概率都附带其理由描述

### 第二意见
- **必须**（始终调用 strategy-reviewer）
- 审查结果反映在最终判断中

### 输出位置（重要）
- **始终** 保存到 `reports/` 目录
- 路径：`reports/scenario_analysis_<主题>_YYYYMMDD.md`
- 示例：`reports/scenario_analysis_fed_rate_hike_20260104.md`
- 如果不存在，创建 `reports/` 目录
- **必须不直接保存到项目根目录**
