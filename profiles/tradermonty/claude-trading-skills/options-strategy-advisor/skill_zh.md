# 期权策略顾问

## 概述

该技能使用理论定价模型提供全面的期权策略分析和教育。它帮助交易者理解、分析和模拟期权策略，而无需实时市场数据订阅。

**核心功能：**
- **布莱克-斯科尔斯定价**：理论期权价格和希腊字母计算
- **策略模拟**：主要期权策略的盈亏分析
- **收益策略**：结合收益日历的收益前波动率交易
- **风险管理**：头寸规模、希腊字母敞口、最大亏损/盈利分析
- **教育重点**：策略和风险指标的详细解释

**数据来源：**
- FMP API：股票价格、历史波动率、股息、收益日期
- 用户输入：隐含波动率 (IV)、无风险利率
- 理论模型：布莱克-斯科尔斯用于定价和希腊字母

## 前置条件

**必需：**
- Python 3.9+ 以及 `numpy`、`scipy`、`requests`

**可选：**
- FMP API 密钥（用于实时股票价格和历史波动率）
  - 通过 `FMP_API_KEY` 环境变量或 `--api-key` 参数设置
  - 无 API 密钥：使用手动输入的股票价格和波动率


## 支持的策略

### 收益策略
1. **保护性看涨期权** - 持有股票，卖出看涨期权（产生收入，限制上涨）
2. **有担保看跌期权** - 用现金卖出看跌期权（收取溢价，愿意买入股票）
3. **穷人的保护性看涨期权** - LEAPS 看涨期权 + 短期看涨期权（资本高效）

### 保护策略
4. **保护性看跌期权** - 持有股票，买入看跌期权（保险，限制下跌）
5. **领口策略** - 持有股票，卖出看涨期权 + 买入看跌期权（限制上涨/下跌）

### 方向性策略
6. **牛市看涨期权价差** - 买入较低行权价看涨期权，卖出较高行权价看涨期权（有限风险/收益看涨）
7. **牛市看跌期权价差** - 卖出较高行权价看跌期权，买入较低行权价看跌期权（信用价差，看涨）
8. **熊市看涨期权价差** - 卖出较低行权价看涨期权，买入较高行权价看涨期权（信用价差，看跌）
9. **熊市看跌期权价差** - 买入较高行权价看跌期权，卖出较低行权价看跌期权（有限风险/收益看跌）

### 波动率策略
10. **买入跨式期权** - 买入平值看涨期权 + 平值看跌期权（从任何方向的大幅波动中获利）
11. **买入宽跨式期权** - 买入虚值看涨期权 + 虚值看跌期权（比跨式期权便宜，需要更大波动）
12. **卖出跨式期权** - 卖出平值看涨期权 + 平值看跌期权（从无波动中获利，无限风险）
13. **卖出宽跨式期权** - 卖出虚值看涨期权 + 虚值看跌期权（从无波动中获利，更宽的波动范围）

### 范围策略
14. **铁蝶式期权** - 牛市看跌期权价差 + 熊市看涨期权价差（从范围波动中获利）
15. **铁飞鸟式期权** - 卖出平值跨式期权，买入虚值宽跨式期权（从紧密范围中获利）

### 高级策略
16. **日历价差** - 卖出短期期权，买入长期期权（从时间衰减中获利）
17. **斜率价差** - 日历价差，不同行权价（方向性 + 时间衰减）
18. **比例价差** - 不平衡价差（一个腿的合约更多）

## 分析工作流程

### 第 1 步：收集输入数据

**用户提供的必需信息：**
- 股票代码
- 策略类型
- 行权价
- 到期日
- 头寸规模（合约数量）

**用户提供的可选信息：**
- 隐含波动率 (IV) - 如果未提供，则使用历史波动率 (HV)
- 无风险利率 - 默认为当前 3 个月国库券利率（~5.3% 截至 2025 年）

**从 FMP API 获取的信息：**
- 当前股票价格
- 历史价格（用于计算 HV）
- 股息收益率
- 即将到来的收益日期（用于收益策略）

**示例用户输入：**
```
股票代码：AAPL
策略：牛市看涨期权价差
买入行权价：$180
卖出行权价：$185
到期日：30 天
合约数量：10
IV：25%（或使用 HV 如果未提供）
```

### 第 2 步：计算历史波动率（如果未提供 IV）

**目标：** 从历史价格波动中估计波动率。

**方法：**
```python
# 获取 90 天的价格数据
prices = get_historical_prices("AAPL", days=90)

# 计算每日回报
returns = np.log(prices / prices.shift(1))

# 年化波动率
HV = returns.std() * np.sqrt(252)  # 252 个交易日
```

**输出：**
- 历史波动率（年化百分比）
- 对用户的提示：“HV = 24.5%，考虑使用当前市场 IV 以获得更高的准确性”

**用户可以覆盖：**
- 从经纪商平台（ThinkorSwim、TastyTrade 等）提供 IV
- 脚本接受 `--iv 28.0` 参数

### 第 3 步：使用布莱克-斯科尔斯定价期权

**布莱克-斯科尔斯模型：**

对于欧式期权：
```
看涨期权价格 = S * N(d1) - K * e^(-r*T) * N(d2)
看跌期权价格 = K * e^(-r*T) * N(-d2) - S * N(-d1)

其中：
d1 = [ln(S/K) + (r + σ²/2) * T] / (σ * √T)
d2 = d1 - σ * √T

S = 当前股票价格
K = 行权价
r = 无风险利率
T = 到期时间（年）
σ = 波动率（IV 或 HV）
N() = 标准正态分布累积函数
```

**调整：**
- 对于看涨期权，减去股息现值
- 美式期权：使用近似值或注意“欧式定价，可能低估美式期权”
