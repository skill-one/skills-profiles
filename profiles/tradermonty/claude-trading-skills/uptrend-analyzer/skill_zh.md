# 上升趋势分析技能

## 目的

使用蒙蒂的趋势比率仪表板诊断市场广度健康状况，该仪表板追踪美国约2,800家股票，涵盖11个行业。生成0-100的复合评分（越高表示越健康），并提供配置建议。

与市场顶部检测器（基于API的风险评分器）不同，此技能使用免费的CSV数据来评估“参与广度”——即市场上涨是广泛的还是狭窄的。

## 使用此技能的场景

**英文：**
- 用户询问“市场广度是否健康？”或“反弹有多广泛？”
- 用户希望评估各行业的上升趋势比率
- 用户询问市场参与度或广度状况
- 用户需要基于广度分析的配置建议
- 用户提及蒙蒂的趋势仪表板或上升趋势比率

**日文：**
- 「市場のブレドスは健全？」「上昇の裾野は広い？」
- セクター別のアップトレンド比率を確認したい
- 相場参加率・ブレドス状況を診断したい
- ブレドス分析に基づくエクスポージャーガイダンスが欲しい
- Montyのアップトレンドダッシュボードについて質問

## 前置条件

- **Python 3.9+** 与 `requests` 库（CSV解析使用标准库 `csv`/`io` 模块）
- **互联网连接** 从GitHub获取CSV数据（无需API密钥）
- 无需付费API订阅

## 与市场顶部检测器的差异

| 方面 | 上升趋势分析器 | 市场顶部检测器 |
|------|---------------|---------------|
| 评分方向 | 越高越健康 | 越高越风险 |
| 数据源 | 免费GitHub CSV | FMP API（付费） |
| 重点 | 广度参与度 | 顶部形成风险 |
| API密钥 | 不需要 | 需要（FMP） |
| 方法论 | 蒙蒂上升趋势比率 | 奥尼尔/明内维尼/蒙蒂 |

## 执行工作流程

### 第一阶段：执行Python脚本

运行分析脚本（无需API密钥）：

```bash
python3 skills/uptrend-analyzer/scripts/uptrend_analyzer.py
```

脚本将：
1. 从蒙蒂的GitHub仓库下载CSV数据
2. 计算5个组成部分评分
3. 生成复合评分和报告

### 第二阶段：展示结果

向用户展示生成的Markdown报告，突出显示：
- 复合评分和区域分类
- 配置建议（全量/正常/减少/防御/保全）
- 行业热力图显示最强和最弱的行业
- 关键动量信号和轮动信号

## 5组成部分评分系统

| 编号 | 组成部分 | 权重 | 关键信号 |
|------|----------|------|----------|
| 1 | 市场广度（整体） | **30%** | 比率水平+趋势方向 |
| 2 | 行业参与度 | **25%** | 上升趋势行业数量+比率跨度 |
| 3 | 行业轮动 | **15%** | 周期性vs防御性平衡 |
| 4 | 动量 | **20%** | 斜率方向+加速度 |
| 5 | 历史背景 | **10%** | 历史百分位排名 |

## 评分区域

| 评分 | 区域 | 配置建议 |
|------|------|----------|
| 80-100 | 强牛市 | 全量配置（100%） |
| 60-79 | 牛市 | 正常配置（80-100%） |
| 40-59 | 中性 | 减少配置（60-80%） |
| 20-39 | 谨慎 | 防御（30-60%） |
| 0-19 | 熊市 | 资本保全（0-30%） |

### 7级区域详细说明

每个评分区域进一步细分为子区域，用于更精细的评估：

| 评分 | 区域详细说明 | 颜色 |
|------|---------------|------|
| 80-100 | 强牛市 | 绿色 |
| 70-79 | 牛市-上 | 浅绿色 |
| 60-69 | 牛市-下 | 浅绿色 |
| 40-59 | 中性 | 黄色 |
| 30-39 | 谨慎-上 | 橙色 |
| 20-29 | 谨慎-下 | 橙色 |
| 0-19 | 熊市 | 红色 |

### 警报系统

激活警报会触发配置惩罚，即使复合评分很高也会收紧建议：

| 警报 | 条件 | 惩罚 |
|------|------|------|
| **晚周期** | 商品平均 > 周期性和防御性均 | -5 |
| **高跨度** | 最大-最小行业比率跨度 > 40pp | -3 |
| **背离** | 组内标准差 > 8pp，跨度 > 20pp，或趋势分歧者 | -3 |

惩罚叠加（最大-10）+ 多重警报折扣（≥2激活时+1）。在复合评分后应用。

### 动量平滑

评分前使用EMA(3)（指数移动平均，跨度=3）平滑斜率值。加速度通过比较最近10点平均与平滑斜率的前10点平均（10v10窗口）计算得出，数据点少于20时回退至5v5。

### 历史置信度指标

历史背景组成部分包括基于以下内容的置信度评估：
- **样本量**：可用的历史数据点数量
- **体制覆盖**：观察到不同市场体制（牛市/熊市/中性）的比例
- **时效性**：最新数据点的最近程度

置信度等级：高、中、低。
