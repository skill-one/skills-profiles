# 市场广度分析技能

## 目的

使用数据驱动的6成分评分系统（0-100）量化市场广度健康状况。利用TraderMonty公开发布的CSV数据，衡量市场在反弹或下跌中参与的广泛程度。

**评分方向：** 100 = 最大健康度（广泛参与），0 = 严重弱势。

**无需API密钥** - 使用GitHub Pages上免费提供的CSV数据。

## 使用此技能的时机

**英文：**
- 用户询问“市场反弹是否广泛？”或“市场广度健康状况如何？”
- 用户希望评估市场参与率
- 用户询问关于上涨-下跌指标或广度推动力
- 用户想知道市场是否收窄（参与股票减少）
- 用户询问基于广度状况的股票敞口水平

**日文：**
- 「マーケットブレッドスはどうですか？」「市場の参加率は？」
- 「上昇は広がっている？」「一部の銘柄だけの上昇？」
- 基于广度指标的敞口判断
- 希望通过数据确认市场健康度

## 前置条件

- **Python 3.9+** 及 `requests` 库（用于获取CSV数据）
- **互联网访问** 以访问GitHub Pages URL
- **无需API密钥** - 使用免费提供的公共CSV数据

## 与广度图表分析师的区别

| 方面 | 市场广度分析器 | 广度图表分析师 |
|------|---------------|---------------|
| 数据源 | CSV（自动） | 图表图像（手动） |
| API要求 | 无 | 无 |
| 输出 | 定量0-100分数 | 定性图表分析 |
| 成分 | 6个评分维度 | 视觉模式识别 |
| 可重复性 | 完全可重复 | 依赖分析师 |

## 执行工作流程

### 第一阶段：执行Python脚本

运行分析脚本。如果使用嵌套或带日期戳的 `--output-dir` 在cron运行中，请先创建它；历史记录写入器期望目录已经存在。

```bash
mkdir -p reports/<例行或日期>
python3 skills/market-breadth-analyzer/scripts/market_breadth_analyzer.py \
  --detail-url "https://tradermonty.github.io/market-breadth-analysis/market_breadth_data.csv" \
  --summary-url "https://tradermonty.github.io/market-breadth-analysis/market_breadth_summary.csv" \
  --output-dir reports/<例行或日期>
```

对于简单的临时运行，省略 `--output-dir` 或使用现有目录。在从仓库根目录执行的定时cron运行中，优先使用仓库相对输出目录，例如 `reports/after-close-YYYY-MM-DD` 而不是绝对路径。如果绝对嵌套的 `--output-dir` 在历史记录写入步骤中意外失败，尽管目录存在，请重新运行一次使用等效的仓库相对路径，然后再将广度分析视为不可用。

脚本将：
1. 获取详细CSV（~2,500行，2016年至今）和摘要CSV（8个指标）
2. 验证数据新鲜度（如果> 5天则警告）
3. 计算6个成分分数（如果任何成分缺乏数据则自动重新分配权重）
4. 生成复合分数和区域分类
5. 跟踪分数历史并计算趋势（改善/恶化/稳定）
6. 输出JSON和Markdown报告

### 第二阶段：展示结果

向用户展示生成的Markdown报告，突出显示：
- 复合分数和健康区域
- 最强和最弱的成分
- 推荐的股票敞口水平
- 需要关注的广度关键水平
- 任何数据新鲜度警告

## 6成分评分系统

| # | 成分 | 权重 | 关键信号 |
|---|------|------|---------|
| 1 | 广度水平与趋势 | **25%** | 当前8MA水平 + 200MA趋势方向 + 8MA方向修饰器 |
| 2 | 8MA与200MA交叉 | **20%** | 通过MA缺口和方向体现的动量 |
| 3 | 峰值/谷值周期 | **20%** | 广度周期中的位置 |
| 4 | 下跌信号 | **15%** | 回测下跌信号标志 |
| 5 | 历史百分位数 | **10%** | 当前与完整历史分布的对比 |
| 6 | 标普500背离 | **10%** | 多窗口（20d + 60d）价格与广度的背离 |

**权重重新分配：** 如果任何成分缺乏足够数据（例如，未检测到峰值/谷值标记），则将其排除，并将其权重按比例重新分配给剩余成分。报告显示原始和有效权重。

**分数历史：** 复合分数跨运行持久化（按数据日期键）。当有多个观察值时，报告包含趋势摘要（改善/恶化/稳定）。

## 健康区域映射（100 = 健康）

| 分数 | 区域 | 股票敞口 | 行动 |
|------|------|----------|------|
| 80-100 | 强健 | 90-100% | 全仓，倾向于增长/动量 |
| 60-79 | 健康 | 75-90% | 正常操作 |
| 40-59 | 中性 | 60-75% | 选择性配置，收紧止损 |
| 20-39 | 削弱 | 40-60% |获利了结，增加现金 |
| 0-19 | 危机 | 25-40% | 资本保全，关注谷值 |

## 数据源

**详细CSV：** `market_breadth_data.csv`
- ~2,500行，从2016-02至今
- 列：日期、标普500价格、广度指数原始值、广度指数200MA、广度指数8MA、广度200MA趋势、下跌信号、是否峰值、是否谷值、是否8MA低于04

**摘要CSV：** `market_breadth_summary.csv`
- 8个汇总指标（平均峰值、平均谷值、计数、分析期间）

两者都公开托管在GitHub Pages上 - 无需身份验证。

## 输出文件

- JSON：`market_breadth_YYYY-MM-DD_HHMMSS.json`
- Markdown：`market_breadth_YYYY-MM-DD_HHMMSS.md`
- 历史：`market_breadth_history.json`（跨运行持久化，最多20条记录）
