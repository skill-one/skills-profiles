# 配对交易筛选器

## 概述

该技能通过配对交易识别和分析统计套利机会。配对交易是一种市场中性策略，通过两个相关性强的证券的相对价格变动获利，而不管整体市场方向如何。该技能使用严格的统计方法，包括相关性分析和协整检验，以找到稳健的交易对。

**核心方法：**
- 识别具有高相关性和相似行业/部门敞口的一对股票
- 检验协整性（长期统计关系）
- 计算价差z分数以识别均值回归机会
- 根据统计阈值生成入场/出场信号
- 提供市场中性敞口的头寸规模

**主要优势：**
- 市场中性：在上涨、下跌或横盘市场中获利
- 风险管理：限制对整体市场变动的敞口
- 统计基础：数据驱动，非主观判断
- 分散化：与传统仅做多策略不相关

## 分析工作流

### 第1步：定义配对宇宙

**目标：** 建立要分析配对关系的股票池。

**选项A：基于行业的筛选（推荐）**

选择特定行业进行筛选：
- 科技
- 金融
- 医疗保健
- 消费 discretionary
- 工业
- 能源
- 材料
- 消费必需品
- 公用事业
- 房地产
- 通信服务

**选项B：自定义股票列表**

用户提供特定股票代码进行分析：
```
示例：["AAPL", "MSFT", "GOOGL", "META", "NVDA"]
```

**选项C：特定行业**

将焦点缩小到特定行业的子集：
- 示例：科技行业内的“软件”
- 示例：金融行业内的“区域银行”

**筛选标准：**
- 市值下限：$2B（中盘和以上）
- 平均成交量下限：每天1M股（流动性要求）
- 活跃交易：无退市或非活跃股票
- 同一交易所偏好：避免跨交易所问题

### 第2步：检索历史价格数据

**目标：** 为相关性和协整分析检索价格历史。

**数据要求：**
- 时间范围：2年（至少252个交易日）
- 频率：每日收盘价
- 调整：调整分割和股息
- 清洁数据：无缺口或缺失值

**FMP API端点：**
```
GET /v3/historical-price-full/{symbol}?apikey=YOUR_API_KEY
```

**数据验证：**
- 验证所有符号之间的一致日期范围
- 移除缺失数据超过10%的股票
- 使用前向填充法填充小缺口
- 记录数据质量问题

**脚本执行：**
```bash
uv run --with 'statsmodels>=0.14,<0.15' python \
  skills/pair-trade-screener/scripts/find_pairs.py \
  --sector Technology \

  --output /tmp/pair-trade/technology.json
```

### 第3步：计算相关性和贝塔

**目标：** 识别具有强线性关系的候选配对。

**相关性分析：**

对于宇宙中的每对股票(i, j)：
1. 计算皮尔逊相关系数(ρ)
2. 计算滚动相关（90天窗口）以进行稳定性检查
3. 过滤ρ ≥ 0.70（强正相关性）的配对

**相关性解释：**
- ρ ≥ 0.90：非常强的相关性（最佳候选）
- ρ 0.70-0.90：强相关性（良好候选）
- ρ 0.50-0.70：中等相关性（边际）
- ρ < 0.50：弱相关性（排除）

**贝塔计算：**

对于每个候选配对（股票A，股票B）：
```
Beta = Covariance(A, B) / Variance(B)
```

贝塔表示对冲比率：
- Beta = 1.0：等金额度
- Beta = 1.5：每$1.00的A对应$1.50的B
- Beta = 0.8：每$1.00的A对应$0.80的B

**相关性稳定性检查：**
- 计算多个时期（6mo，1yr，2yr）的相关性
- 要求相关性保持稳定（不恶化）
- 标记最近相关性低于历史相关性超过0.15的配对

### 第4步：协整检验

**目标：** 统计验证长期均衡关系。

**协整的重要性：**
- 相关性衡量短期共同运动
- 协整证明长期均衡关系
- 协整配对可预测地均值回归
- 非协整配对可能永久性偏离

**增强迪基-福勒（ADF）检验：**

对于每个相关配对：
1. 计算价差：`Spread = Price_A - (Beta × Price_B)`
2. 对价差序列运行ADF检验
3. 检查p值：p < 0.05表示协整（拒绝单位根的零假设）
4. 提取ADF统计量以进行强度排名

**协整解释：**
- p-value < 0.01：非常强的协整（★★★）
- p-value 0.01-0.05：中等协整（★★）
- p-value > 0.05：无协整（排除）

**半衰期计算：**

估计均值回归速度：
```
Half-Life = -log(2) / log(mean_reversion_coefficient)
```

- 半衰期 < 30天：快速均值回归（适合短期交易）
- 半衰期 30-60天：中等速度（标准）
- 半衰期 > 60天：慢速均值回归（长期持有期）

**Python实现：**
```python
from statsmodels.tsa.stattools import adfuller

# 计算价差
spread = price_a - (beta * price_b)

# ADF检验
result = adfuller(spread)
adf_stat = result[0]
p_value = result[1]

# 解释
is_cointegrated = p_value < 0.05
```

### 第5步：价差分析和Z分数计算

**目标：** 定量当前价差与均衡的偏差。

**价差计算：**

两种常见方法：

**方法1：价格差（加法）**
```
Spread = Price_A - (Beta × Price_B)
```
适用：价格水平相似的股票

**方法2：价格比率（乘法）**
```
Spread = Price_A / Price_B
```
适用：价格水平不同的股票，更容易解释

**Z分数计算：**

衡量当前价差与其均值的标准差是多少：
```
Z-Score = (Current_Spread - Mean_Spread) / Std_Dev_Spread
```

**Z分数解释：**
- Z > +2.0：股票A相对于B昂贵（做空A，做多B）
- Z > +1.5：中等昂贵（注意入场）
- Z -1.5到+1.5：正常范围（无交易）
- Z < -1.5：中等便宜（注意入场）
- Z < -2.0：股票A相对于B便宜（做多A，做空B）

**历史价差分析：**
- 计算90天滚动窗口的均值和标准差
- 绘制历史Z分数分布
- 确定最大历史Z分数偏差
- 检查结构断裂（价差格局变化）

### 第6步：生成入场/出场建议

**目标：** 提供具有明确规则的交易信号。

**入场条件：**

**保守方法（Z ≥ ±2.0）：**
```
LONG信号：
- Z分数 < -2.0（价差2+标准差低于均值）
- 价差是均值回归的（协整p < 0.05）
- 半衰期 < 60天
→ 行动：买入股票A，做空股票B（对冲比率=贝塔）

SHORT信号：
- Z分数 > +2.0（价差2+标准差高于均值）
- 价差是均值回归的（协整p < 0.05）
- 半衰期 < 60天
→ 行动：做空股票A，买入股票B（对冲比率=贝塔）
```

**激进方法（Z ≥ ±1.5）：**
- 较低阈值，交易更频繁
- 赢率更高，但每笔交易平均利润较小
- 需要更严格的风险管理

**出场条件：**

**主要出场：均值回归（Z = 0）**
```
当价差返回均值（z分数穿过0）时出场
→ 同时关闭两腿
```

**次要出场：部分获利了结**
```
当z分数达到±1.0时出场50%
在z分数=0时出场剩余50%
```

**止损：**
```
如果z分数超出±3.0（极端偏离）则出场
风险：关系可能发生结构性断裂
```

**基于时间的出场：**
```
如果在90天内没有均值回归则出场
防止无限期持有断裂的对
```

### 第7步：头寸规模和风险管理

**目标：** 确定用于市场中性敞口的金额。

**市场中性规模：**

对于配对（股票A，股票B）与贝塔=β：

**等金额度敞口：**
```
如果投资组合大小=$10,000分配给这对配对：
- 买入$5,000的股票A
- 做空$5,000 × β的股票B

示例（β = 1.2）：
- 买入$5,000股票A
- 做空$6,000股票B
→ 市场中性，贝塔=0
```

**头寸规模考虑：**
- 每对配对的总量配置：投资组合的10-20%
- 最大配对数量：5-8个活跃配对以实现分散化
- 配对之间的相关性：避免高度相关的配对

**风险指标：**
- 每对的最大损失：总投资组合的2-3%
- 止损触发器：Z分数 > ±3.0或价差损失-5%
- 投资组合级风险：所有配对风险之和≤10%

### 第8步：生成配对分析报告

**目标：** 创建包含发现和建议的结构化markdown报告。

**报告部分：**

1. **执行摘要**
   - 分析的配对总数
   - 找到的协整配对数量
   - 按统计强度排名的前5个机会

2. **协整配对表**
   - 配对名称（股票A / 股票B）
   - 相关系数
   - 协整p值
   - 当前z分数
   - 交易信号（做多/做空/无）
   - 半衰期

3. **详细分析（前10对）**
   - 配对描述
   - 统计指标
   - 当前价差位置
   - 入场/出场建议
   - 头寸规模
   - 风险评估

4. **价差图表（基于文本）**
   - 历史Z分数图（ASCII艺术）
   - 标记入场/出场水平
   - 当前位置指示器

5. **风险警告**
   - 相关性恶化的配对
   - 检测到结构断裂
   - 低流动性警告

**文件命名约定：**
```
pair_trade_analysis_[SECTOR]_[YYYY-MM-DD].md
```

示例：`pair_trade_analysis_Technology_2025-11-08.md`

## 输出

`find_pairs.py` 创建请求的父目录并写入一个包含`metadata`和`pairs`键的JSON对象。每个配对包括相关性、对冲比率、ADF结果、半衰期、当前z分数、信号和生成时间戳。进度和排名摘要写入stdout。文件系统错误产生简洁的stderr消息和非零退出。

`analyze_spread.py` 将单个配对的统计报告写入stdout，并且不创建文件。两个命令在发出API请求之前都会拒绝无效或非有限阈值、不足的回溯窗口和重复符号。缺少`statsmodels`会在stderr生成安装命令，而不会生成traceback。

## 质量标准

### 统计严谨性

**有效配对的最小要求：**
- ✓ 相关性 ≥ 0.70 在2年期间
- ✓ 协整p值 < 0.05 (ADF检验)
- ✓ 价差平稳性确认
- ✓ 半衰期 < 90天
- ✓ 最近6个月内无结构断裂

**红旗（排除配对）：**
- 相关性在最近6个月内下降 >0.20
- 协整p值 > 0.05
- 半衰期随时间增加（均值回归减弱）
- 显著的Corporate事件（盈利、指引变化）
- 流动性问题（平均成交量 < 500K股/天）

### 实际考虑

**交易成本：**
- 假设每腿0.1%的往返成本
- 每对配对的总成本 = 0.4%（入场+出场，两腿）
- 最小z分数阈值应超过交易成本

**卖空：**
- 验证股票可卖空（非难借）
- 考虑卖空利息成本（借费）
- 监控卖空挤压风险

**执行：**
- 同时进入/退出两腿（避免单腿风险）
- 使用限价单控制滑点
- 在入场前预先定位卖空

## 可用脚本

### scripts/find_pairs.py

**目的：** 在特定行业或自定义列表中筛选协整配对。

**用法：**
```bash
# 基于行业的筛选
uv run --with 'statsmodels>=0.14,<0.15' python \
  skills/pair-trade-screener/scripts/find_pairs.py \
  --sector Technology \
  --min-correlation 0.70 \
  --output /tmp/pair-trade/technology.json

# 自定义股票列表
uv run --with 'statsmodels>=0.14,<0.15' python \
  skills/pair-trade-screener/scripts/find_pairs.py \
  --symbols AAPL,MSFT,GOOGL,META \
  --min-correlation 0.75 \
  --output /tmp/pair-trade/custom.json

# 完整选项
uv run --with 'statsmodels>=0.14,<0.15' python \
  skills/pair-trade-screener/scripts/find_pairs.py \
  --sector Financials \
  --min-correlation 0.70 \
  --min-market-cap 2000000000 \
  --lookback-days 730 \
  --output /tmp/pair-trade/financials.json
```

**参数：**
- `--sector`：行业名称（科技、金融等）
- `--symbols`：股票代码列表（替代行业）
- `--min-correlation`：最小相关性阈值（默认：0.70）
- `--min-market-cap`：最小市值过滤器（默认：$2B）
- `--lookback-days`：历史数据期间（默认：730天）
- `--output`：输出JSON文件（默认：`pair_analysis.json`）
- `--api-key`：FMP API密钥（或设置FMP_API_KEY环境变量）

**输出：**
```json
[
  {
    "pair": "AAPL/MSFT",
    "stock_a": "AAPL",
    "stock_b": "MSFT",
    "correlation": 0.87,
    "beta": 1.15,
    "cointegration_pvalue": 0.012,
    "adf_statistic": -3.45,
    "half_life_days": 42,
    "current_zscore": -2.3,
    "signal": "LONG",
    "strength": "Strong"
  }
]
```

## 故障排除

**问题：未找到协整配对**

解决方案：
- 扩大宇宙（降低市值阈值）
- 将协整p值放宽到0.10
- 尝试不同行业（公用事业通常协整良好）
- 增加回溯期到3年

**问题：所有z分数接近零（无交易信号）**

解决方案：
- 正常市场条件（配对处于均衡状态）
- 检查稍后或扩大宇宙
- 将入场阈值降至±1.5而不是±2.0

**问题：配对相关性破裂**

解决方案：
- 检查是否有公司事件（盈利、指引变化）
- 验证无M&A活动或重组
- 如果确认结构断裂，则从观察列表中删除配对
- 观察30天后再重新进入
