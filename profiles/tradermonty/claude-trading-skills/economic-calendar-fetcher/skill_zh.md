# 经济日历获取器

## 概述

从 Financial Modeling Prep (FMP) 经济日历 API 获取即将到来的经济事件和数据发布。此技能获取计划中的经济指标，包括央行货币政策决定、就业报告、通胀数据（CPI/PPI）、GDP 发布、零售销售、制造业数据以及其他影响金融市场的市场变动事件。

该技能使用 Python 脚本查询 FMP API，并返回原始 JSON 或文本输出。助手随后筛选事件，评估市场影响，并为每个计划中的事件生成按时间顺序排列的 Markdown 报告。不会自动生成文件。

**主要功能：**
- 获取指定日期范围内的经济事件（最多 90 天）
- 支持灵活的 API 密钥提供（环境变量或 CLI 参数）
- 按影响级别、国家或事件类型筛选（筛选由助手执行）
- 将筛选结果作为结构化 Markdown 报告呈现，包含影响分析（由助手生成，非脚本生成）
- 默认为未来 7 天，以便快速了解市场前景

**数据来源：**
- FMP 经济日历 API：`https://financialmodelingprep.com/stable/economic-calendar`（单数形式“economic”）
- 涵盖主要经济体：美国、欧盟、英国、日本、中国、加拿大、澳大利亚
- 事件类型：央行决定、就业、通胀、GDP、贸易、住房、调查
- 注意：FMP 已于 2025-08-31 完全停用 `api/v3/economic_calendar` 端点，现在返回 `403 Legacy Endpoint` — 请勿使用它，包括作为备用。

## 何时使用此技能

当用户请求以下内容时使用此技能：

1. **经济日历查询：**
   - "这周有哪些经济事件即将到来？"
   - "显示未来两周的经济日历"
   - "下次 FOMC 会议是什么时候？"
   - "下个月将发布哪些主要经济数据？"

2. **市场事件规划：**
   - "这周我需要关注哪些市场动态？"
   - "是否有任何高影响的经济发布即将到来？"
   - "下次就业报告 / CPI 发布 / GDP 报告是什么时候？"

3. **特定日期范围请求：**
   - "获取 1 月 1 日至 1 月 31 日的经济事件"
   - "2025 年第一季度经济日历上有哪些内容？"

4. **国家特定查询：**
   - "显示下周的美国经济数据发布"
   - "ECB 有哪些计划中的事件？"
   - "日本何时发布通胀数据？"

**不要使用此技能用于：**
- 过去的经济事件（使用 market-news-analyst 进行历史分析）
- 公司盈利日历（此技能不包括盈利）
- 实时市场数据或实时报价
- 技术分析或图表解释

## 前提条件

- **FMP API 密钥**（必需）：在 https://financialmodelingprep.com 注册免费密钥（每天 250 次请求）。通过 `FMP_API_KEY` 环境变量或向脚本传递 `--api-key` 设置。
- **Python 3.10+**：运行 `skills/economic-calendar-fetcher/scripts/get_economic_calendar.py` 所需。
- **无需第三方包**：脚本仅使用 Python 标准库。

## 工作流程

按照以下步骤获取和分析经济日历：

### 第 1 步：获取 FMP API 密钥

**检查 API 密钥可用性（按优先顺序）：**

1. **推荐：** 检查 `FMP_API_KEY` 环境变量是否设置 — 这将密钥保持在会话日志之外
2. **可接受：** 对于一次性运行，使用 `--api-key` CLI 参数
3. **不推荐：** 要求用户将密钥粘贴到聊天中 — 会话日志可能会保留它
4. 如果用户没有 API 密钥，提供说明：
   - 访问 https://financialmodelingprep.com
   - 注册免费账户（每天 250 次请求限制）
   - 导航到 API 仪表板以获取密钥

**示例用户交互：**
```
用户: "显示下周经济事件"
助手: "我将获取经济日历。如果设置了 FMP_API_KEY 环境变量，我将使用它。否则，请在运行脚本时通过 --api-key 传递密钥。"
```

### 第 2 步：确定日期范围

**根据用户请求设置适当的日期范围：**

**默认（无特定日期）：** 今天 + 7 天
**用户指定时间段：** 使用确切日期（验证格式：YYYY-MM-DD）
**最大范围：** 90 天（FMP API 限制）

**示例：**
- "下周" → 今天到 +7 天
- "下两周" → 今天到 +14 天
- "2025 年 1 月" → 2025-01-01 到 2025-01-31
- "2025 年第一季度" → 2025-01-01 到 2025-03-31

**验证日期范围：**
- 确保开始日期 ≤ 结束日期
- 确保范围 ≤ 90 天
- 如果查询过去日期，则发出警告

### 第 3 步：执行 API 获取脚本

**使用适当参数运行 `get_economic_calendar.py` 脚本：**

**基本用法（默认 7 天）：**
```bash
python3 skills/economic-calendar-fetcher/scripts/get_economic_calendar.py --api-key YOUR_KEY
```

**使用特定日期范围：**
```bash
python3 skills/economic-calendar-fetcher/scripts/get_economic_calendar.py \
  --from 2025-01-01 \
  --to 2025-01-31 \
  --api-key YOUR_KEY \
  --format json
```

**使用环境变量（无需 --api-key）：**
```bash
export FMP_API_KEY=your_key_here
python3 skills/economic-calendar-fetcher/scripts/get_economic_calendar.py \
  --from 2025-01-01 \
  --to 2025-01-07
```

**脚本参数：**
- `--from`：开始日期（YYYY-MM-DD）- 默认：今天
- `--to`：结束日期（YYYY-MM-DD）- 默认：今天 + 7 天
- `--api-key`：FMP API 密钥（如果设置了 FMP_API_KEY 环境变量则可选）
- `--format`：输出格式（json 或 text）- 默认：json
- `--output`：输出文件路径（可选，默认：stdout）

**处理错误和空结果：**
- 无效 API 密钥 → 要求用户验证密钥
- 超出速率限制（429）→ 建议等待或升级 FMP 层级
- 受限端点（402 付费要求）→ 脚本会明确报错，说明当前的 FMP 订阅层级不包括经济日历端点。告知用户需要升级 FMP 计划至 https://financialmodelingprep.com/ — 不要将其视为“零事件”，也不要回退到旧版 v3 端点（FMP 于 2025-08-31 停用，并返回 `403 Legacy Endpoint`）。
- 网络错误 → 检查您的连接并重新运行脚本
- 无效日期格式 → 提供正确格式示例
- **对于合理当前/未来范围内的空列表 `[]`：** 在当前脚本版本中，来自 API 的空列表是“无事件”的真实响应 — 404 或受限端点响应现在会引发明确错误，而不是被静默转换为 `[]`。如果您仍然怀疑数据缺失，请重新验证日期范围和 API 密钥，而不是假设端点损坏。

### 第 4 步：解析和筛选事件

**处理脚本的 JSON 响应：**

1. **解析事件数据：** 从 API 响应中提取所有事件
2. **应用用户筛选（如果指定）：**
   - 影响级别：高、中、低
   - 国家："US"、"EU"、"JP"、"CN" 等
   - 事件类型：FOMC、CPI、就业、GDP 等
   - 货币：USD、EUR、JPY 等

**筛选示例：**
- "仅显示高影响事件" → 筛选 impact == "High"
- "美国事件仅" → 筛选 country == "US"
- "央行决定" → 搜索事件名称中的 "Rate"、"Policy"、"FOMC"、"ECB"、"BOJ"

**事件数据结构：**
```json
{
  "date": "2025-01-15 14:30:00",
  "country": "US",
  "event": "消费者价格指数 (CPI 年增长率)",
  "currency": "USD",
  "previous": 2.6,
  "estimate": 2.7,
  "actual": null,
  "change": null,
  "impact": "高",
  "changePercentage": null
}
```

### 第 5 步：评估市场影响

**评估每个事件的市场重要性：**

**影响级别分类（来自 FMP）：**
- **高影响：** 主要影响市场的经济事件
  - FOMC 利率决定、ECB/BOJ 政策会议
  - 非农就业数据 (NFP)、CPI、GDP
  - 市场通常显示 0.5-2%+ 的日内波动率

- **中影响：** 显著但波动性较低
  - 零售销售、工业生产
  - PMI 调查、消费者信心
  - 住房数据、耐用品订单

- **低影响：** 次要指标
  - 周度失业救济金（除非极端）
  - 区域制造业调查
  - 小型拍卖结果

**其他上下文因素：**

1. **当前市场敏感性：**
   - 高通胀环境 → CPI/PPI 提升重要性
   - 经济衰退担忧 → 就业数据更关键
   - 利率削减预期 → 央行会议至关重要

2. **意外潜力：**
   - 比较预期值与先前读数
   - 预期变化大 = 更受关注
   - 一致性不确定性 = 更高影响潜力

3. **事件集中：**
   - 同一天多个相关事件 = 放大影响
   - 示例：CPI + 零售销售 + 联邦讲话 = 非常高影响的日子

4. **前瞻性意义：**
   - 此事件是否影响即将到来的央行决定？
   - 这是初步读数还是最终读数？
   - 这份数据会被修订吗？

### 第 6 步：生成输出报告

> **责任：** 脚本输出原始 JSON 或文本。此步骤由助手执行，使用脚本输出。不会自动生成 Markdown 文件；结果在聊天中显示，并可根据要求保存到 `reports/`。

**创建结构化 Markdown 报告，包含以下部分：**

**报告标题：**
```markdown
# 经济日历
**期间：** [开始日期] 至 [结束日期]
**报告生成时间：** [时间戳]
**总事件数：** [数量]
**高影响事件数：** [数量]
```

**事件列表（按时间顺序）：**

对于每个事件，提供：

```markdown
## [日期] - [星期几]

### [事件名称] ([影响级别])
- **国家：** [国家代码] ([货币])
- **时间：** [HH:MM UTC]
- **先前值：** [数值]
- **预期值：** [一致预期]
- **影响评估：** [您的分析]

**市场影响：**
[2-3 句话说明为什么这很重要，市场关注什么，典型的反应模式]

---
```

**示例事件条目：**

```markdown
## 2025-01-15 - 星期三

### 消费者价格指数 (CPI 年增长率) (高影响)
- **国家：** 美国 (USD)
- **时间：** 14:30 UTC (美国东部时间 8:30 AM)
- **先前值：** 2.6%
- **预期值：** 2.7%
- **影响评估：** 非常高 - 央行政策决策的核心通胀指标

**市场影响：**
CPI 读数高于预期 (>2.7%) 可能会加强美联储的鹰派预期，可能对股市和美元构成压力。读数等于或低于 2.7% 可能会强化通缩叙事并支持风险资产。期权市场定价 1.2% S&P 500 在发布当天波动。

---
```

**总结部分：**

在末尾添加分析总结：

```markdown
## 关键要点

**最高影响日期：**
- [日期]：[事件] - [综合影响理由]
- [日期]：[事件] - [综合影响理由]

**央行活动：**
- [总结任何计划的 Fed/ECB/BOJ 会议或讲话]

**主要数据发布：**
- 就业：[NFP、失业率日期]
- 通胀：[CPI、PPI 日期]
- 增长：[GDP、零售销售 日期]

**市场定位考虑：**
[2-3 个要点说明交易员如何围绕这些事件进行定位]

**风险事件：**
[突出显示任何特别高不确定性或意外潜力的事件]
```

**筛选说明：**

如果用户请求了特定筛选器，请在顶部注明：
```markdown
**已应用筛选器：**
- 影响级别：仅高
- 国家：美国
- 显示事件：[X] 个中的 [Y] 个事件在日期范围内
```

**输出：**
- 结果在聊天中显示。不会自动生成文件。
- 要保存 **原始 JSON/文本数据**：在运行脚本时使用 `--output reports/economic_calendar_[START]_to_[END].json`。
- 要保存 **Markdown 报告**：要求助手将其写入 `reports/`。

## 助手生成的报告格式

**Markdown 结构要求：**

1. **按时间顺序排列：** 事件按日期和时间排序（最早优先）
2. **影响级别指示器：** 使用 (高影响)、(中影响)、(低影响) 标签
3. **时区清晰度：** 始终指定 UTC；ET/PT 转换由助手根据美国 DST 日历执行
4. **数据完整性：** 包括所有可用字段（先前值、预期值、实际值（如果已过））
5. **空值处理：** 对于空值显示 "N/A" 或 "无预期值"
6. **影响评估：** 每个高/中影响事件都必须有市场影响分析

**表格格式选项（用于密集列表）：**

```markdown
| 日期/时间 (UTC) | 事件 | 国家 | 影响 | 先前值 | 预期值 | 评估 |
|-----------------|-------|---------|--------|----------|----------|------------|
| 01-15 14:30 | CPI YoY | US | 高 | 2.6% | 2.7% | 核心通胀指标 |
```

**语言：** 所有报告均为英文

  - 缓存和效率的最佳实践

**API 详情：**
- 主要端点：`https://financialmodelingprep.com/stable/economic-calendar`（单数形式“economic” — 复数 `economics-calendar` 是一个无效的 URL，会返回 404）
- 已停用的旧版端点：`https://financialmodelingprep.com/api/v3/economic_calendar` 被 FMP 于 2025-08-31 停用，现在返回 `403 Legacy Endpoint`。不要使用它或作为回退。
- 受限端点注意事项：稳定的 经济日历端点可能需要付费 FMP 订阅层级。如果 API 密钥没有权限，它返回 `402 付费要求`，脚本会明确报错，而不是将空列表视为“零事件”。
- 日期范围注意事项：响应可以包括请求的 `from`/`to` 窗口之外的事件行；获取后，本地筛选事件（通过解析的 `date`），以便仅报告请求的日期范围。
- 身份验证：需要 API 密钥（免费层：每天 250 次请求）
- 最大日期范围：每次请求 90 天
- 响应格式：JSON 数组的事件对象
- 速率限制：每秒 5 个请求（免费层）

**事件覆盖：**
- 主要经济体：美国、欧盟、英国、日本、中国、加拿大、澳大利亚、瑞士
- 事件类别：货币政策、就业、通胀、GDP、贸易、住房、调查
- 更新频率：实时（事件按计划添加/更新）
- 历史数据：可用于过去事件的实际值

**使用技巧：**
1. 缓存结果以减少 API 调用（事件一旦计划很少更改）
2. 查询 7-30 天范围以实现最佳请求效率
3. 不要查询 >6 个月的未来（数据稀疏，预测日期）
4. 每天刷新缓存以获取即将到来的一周以捕获时间变化
5. 使用较小范围（1-7 天）进行实时事件监控

**错误处理：**
- API 密钥错误：提供清晰的用户指导以获取免费密钥
- 速率限制（429）：建议等待或升级 FMP 层级；等待后重新运行脚本
- 受限端点（402）：脚本会明确报错 — FMP 订阅层级没有访问此端点的权限；直接引导用户在 https://financialmodelingprep.com/ 升级。不要回退到旧版 v3 端点（2025-08-31 停用，返回 403）。
- 网络故障：检查连接并重新运行；脚本中没有自动重试或缓存
- 真实 404：脚本现在会报错而不是静默返回空列表 — 调查而不是假设零事件。
- 无效日期：验证并提供有用的错误消息
