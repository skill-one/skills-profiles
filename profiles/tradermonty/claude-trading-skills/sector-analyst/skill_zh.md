# 行业分析师

## 概述

该技能通过从 TraderMonty 的公共 CSV 数据集获取上升趋势比率数据，实现行业轮动和市场周期定位的全面分析。它对行业进行排名，计算周期性 vs 防御性风险状态分数，识别超买/超卖状态，并估计当前市场周期阶段。图表图像可选择性补充数据驱动分析，提供行业级细节。

## 何时使用此技能

在以下情况下使用此技能：
- 用户请求行业轮动分析（无需图表图像）
- 用户询问周期性 vs 防御性定位
- 用户想知道哪些行业超买或超卖
- 用户请求市场周期阶段估计
- 用户提供行业表现图表进行补充分析
- 用户询问基于行业的情景分析或预测

示例用户请求：
- "运行行业轮动分析"
- "哪些行业领先——周期性还是防御性？"
- "现在是否有行业超买？"
- "我们处于市场周期的哪个阶段？"
- "分析这些行业表现图表，告诉我我们处于市场周期的哪个阶段"

## 前置条件

- **Python 3.9+**；无需第三方库（CSV 通过 stdlib `urllib` 获取）
- **无需 API 密钥**——数据从公共 GitHub 仓库获取
- **可选**：行业表现图表图像用于补充分析

## 数据源

行业上升趋势比率从 TraderMonty 的公共 GitHub 仓库获取（无需 API 密钥）：
- **行业摘要**：`sector_summary.csv`——每个行业的上升趋势比率、趋势、斜率和状态
- **新鲜度检查**：`uptrend_ratio_timeseries.csv`——使用 max(date) 验证数据时效性

## 运行脚本

```bash
# 默认：获取 CSV，打印人类可读分析
python3 scripts/analyze_sector_rotation.py

# JSON 输出
python3 scripts/analyze_sector_rotation.py --json

# 保存到文件
python3 scripts/analyze_sector_rotation.py --save --output-dir reports/
```

## 分析工作流

遵循此结构化工作流：

### 第 1 步：CSV 数据收集

1. 运行分析脚本：`python3 scripts/analyze_sector_rotation.py`
2. 从输出中提取：
   - 按上升趋势比率排名的行业
   - 风险状态（周期性 vs 防御性）和分数
   - 超买/超卖行业
   - 周期阶段估计和置信度
3. 如果出现数据新鲜度警告，请在分析中注明

### 第 2 步：市场周期评估

使用脚本的周期阶段估计作为起点：
- 阅读 `references/sector_rotation.md` 以访问市场周期和行业轮动框架
- 将脚本的定量发现与每个周期阶段的预期模式进行比较：
  - 早期周期复苏
  - 中期周期扩张
  - 晚期周期
  - 萧条
- 添加基于知识库的定性解释

如果提供图表图像，使用它们补充行业级细节：
- 从图表图像中提取行业级表现数据
- 比较 1 周和 1 个月的表现以确认趋势
- 注意行业内部表现强劲或疲软的具体行业

### 第 3 步：当前情况分析

综合观察结果进行客观评估：
- 说明当前表现最接近哪个市场周期阶段
- 突出支持证据（哪些行业/行业证实此观点）
- 注意任何矛盾信号或异常模式
- 基于信号一致性评估置信度

使用数据驱动语言并引用具体表现数据。

### 第 4 步：情景发展

基于行业轮动原则和当前定位，为下一阶段开发 2-4 个潜在情景：

对于每个情景：
- 描述市场周期过渡
- 确定哪些行业可能表现优异
- 确定哪些行业可能表现疲软
- 指定确认此情景的催化剂或条件
- 分配概率（见 sector_rotation.md 中的概率评估框架）

情景应从最可能（最高概率）到替代/反主流情景排列。

### 第 5 步：输出生成

创建具有以下部分的 Markdown 文档：

**必需部分：**
1. **执行摘要**：2-3 句话概述关键发现
2. **当前情况**：当前表现模式和市场周期定位的详细分析
3. **支持证据**：支持周期评估的具体行业表现数据
4. **情景分析**：2-4 个情景，包括描述和概率分配
5. **推荐定位**：基于情景概率的战略和战术定位建议
6. **关键风险**：值得关注的风险或矛盾信号

## 关键分析原则

进行分析时：

1. **客观优先**：让数据引导结论，而非先入为主
2. **概率思维**：通过概率范围表达不确定性
3. **多时间框架**：比较 1 周和 1 个月数据以确认趋势
4. **相对表现**：关注相对强度，而非绝对回报
5. **广度重要**：广泛趋势比孤立运动更重要
6. **无绝对性**：市场很少完全按教科书模式运行
7. **历史背景**：参考典型轮动模式，但承认独特性

## 概率指南

根据证据强度应用以下概率范围：

- **70-85%**：强证据，多个跨行业和时间框架的确认信号
- **50-70%**：中等证据，部分确认信号但指标混合
- **30-50%**：弱证据，有限或矛盾信号
- **15-30%**：投机情景，与当前指标相反但可能

所有情景的总概率应约为 100%。

## 重要说明

- 所有分析思考应以英语进行
- 输出 Markdown 文件必须为英语
- 参考行业轮动知识库进行每次分析
- 保持客观性，避免确认偏差
- 如有新数据，更新概率评估
- 图表图像可选；CSV 数据是主要分析输入
- 脚本使用与 uptrend-analyzer 相同的行业分类以保持一致性
