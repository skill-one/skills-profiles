# 市场环境分析

全面分析工具，用于随时了解市场状况并创建专业的市场报告。

## 使用场景

- 当您需要全面了解全球市场状况时
- 在做出交易或投资决策之前
- 用于每日/每周市场简报
- 在评估风险偏好/风险规避情绪时
- 用于理解跨市场相关性及行业轮动
- 在为客户或个人记录准备市场报告时

## 前置条件

- **WebSearch访问权限**：用于获取实时市场数据
- **无需API密钥**：该技能使用网络搜索进行数据收集
- **可选**：经济日历数据，用于事件驱动分析

## 核心工作流程

### 1. 初始数据收集
使用web_search工具收集最新市场数据：
1. 主要股票指数（标普500、纳斯达克、道琼斯、日经225、上证综指、恒生指数）
2. 外汇汇率（美元/日元、欧元/美元、主要货币对）
3. 商品价格（WTI原油、黄金、白银）
4. 美国国债收益率（2年期、10年期、30年期）
5. VIX指数（恐慌指标）
6. 市场交易状态（开盘/收盘/当前值）

### 2. 市场环境评估
从收集的数据中评估以下内容：
- **趋势方向**：上升趋势/下降趋势/区间震荡
- **风险情绪**：风险偏好/风险规避
- **波动率状态**：VIX指标反映的市场焦虑程度
- **行业轮动**：资本流向何处

### 3. 报告结构

#### 标准报告格式：
```
1. 执行摘要（3-5个关键点）
2. 全球市场概览
   - 美国市场
   - 亚洲市场
   - 欧洲市场
3. 外汇与商品趋势
4. 重要事件与经济指标
5. 风险因素分析
6. 投资策略启示
```

## 脚本使用

### market_utils.py
提供报告创建的常用函数：
```bash
# 生成报告标题
python scripts/market_utils.py

# 可用函数：
- format_market_report_header(): 创建标题
- get_market_session_times(): 检查交易时间
- categorize_volatility(vix): 解释VIX水平
- format_percentage_change(value): 格式化价格变动
```

## 交易所日历和重播

在使用`scripts/market_utils.py`前安装`requirements.txt`。其`--as-of`标志需要带偏移的ISO-8601时间戳（或`Z`）；纯日期会被拒绝，因为东京、伦敦和纽约状态必须共享一个明确的时间点。会话状态会考虑节假日、午休时间、夏令时和提前收盘。

## 重要注意事项

### 时区意识
- 考虑所有主要市场时区
- 美国市场：傍晚至清晨（亚洲时间）
- 欧洲市场：下午至傍晚（亚洲时间）
- 亚洲市场：上午至下午（当地时间）

### 经济日历优先级
按重要性分类：
- ⭐⭐⭐ 关键（FOMC、NFP、CPI等）
- ⭐⭐ 重要（GDP、零售销售等）
- ⭐ 参考水平

### 数据源优先级
1. 官方发布（央行、政府统计）
2. 主要财经媒体（彭博、路透社）
3. 经纪人报告
4. 分析师一致预期

## 故障排除

### 数据收集注意事项
- 检查市场假日（假日日历）
- 注意夏令时变化
- 区分闪报数据与最终数据

### 市场波动响应
1. 首先整理事实
2. 参考历史类似事件
3. 多源验证
4. 保持客观分析

## 定制选项

根据用户的投资风格调整：
- **日内交易者**：日内图表、订单流关注
- **波段交易者**：每日/每周技术分析重点
- **长期投资者**：基本面、宏观经济学关注
- **外汇交易者**：货币相关性、利率差异
- **期权交易者**：波动率分析、希腊字母监控
