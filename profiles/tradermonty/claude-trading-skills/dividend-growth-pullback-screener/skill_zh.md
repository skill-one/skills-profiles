# 股息增长回调筛选器

## 概述

该技能筛选具有强大基本面特征但暂时出现技术弱势的股息增长股票。它针对股息增长率（年复合增长率12%以上）异常且回调至RSI超卖水平（≤40）的股票，为长期股息增长投资者创造潜在的入场机会。

**投资逻辑：** 高质量的股息增长股票（通常股息收益率1-2.5%）通过股息增长而非高当前收益率来复利财富。在暂时回调期间（RSI ≤40）买入这些股票可以通过结合强大的基本面增长和有利的入场时机来提高总回报率。

## 使用此技能的时机

当您需要以下情况时，请使用此技能：
- 寻找具有卓越复利潜力的股息增长股票（股息年复合增长率12%以上）
- 在暂时市场疲软期间寻找优质股票的入场机会
- 愿意接受较低的当前收益率（1.5-3%）以换取更高的股息增长
- 专注于5-10年的总回报率而非当前收入
- 市场状况显示行业轮动或广泛回调影响优质股票

**不使用时：**
- 寻求高当前收入（请使用价值股息筛选器）
- 要求即时股息收益率>3%
- 寻找具有严格市盈率或市净率要求的深度价值投资
- 专注于短期交易（<6个月）

## 前置条件

- **FMP API密钥**（必需）：设置`FMP_API_KEY`环境变量或传递`--fmp-api-key`。免费套餐（每天250次调用）足以用于仅FMP模式（≤40只股票）。[注册](https://site.financialmodelingprep.com/developer/docs)。
- **FINVIZ Elite API密钥**（可选，推荐）：设置`FINVIZ_API_KEY`环境变量或传递`--finviz-api-key`。将执行时间从10-15分钟缩短到2-3分钟。[注册](https://elite.finviz.com/)。
- 安装了`requests`库的Python 3.9+。

## 筛选工作流程

### 第1步：设置API密钥

#### 两阶段方法（推荐）

为了最佳性能，使用FINVIZ Elite API进行预筛选，然后使用FMP API进行详细分析：

```bash
# 将两个API密钥设置为环境变量
export FMP_API_KEY=your_fmp_key_here
export FINVIZ_API_KEY=your_finviz_key_here
```

**为什么使用两阶段？**
- **FINVIZ**：使用RSI过滤器进行快速预筛选（1次API调用→约10-50个候选）
- **FMP**：仅在预筛选候选上进行详细基本面分析
- **结果**：使用更少的FMP API调用分析更多股票（保持在免费套餐限制内）

#### FMP单一方法（原始方法）

如果您没有FINVIZ Elite访问权限：

```bash
export FMP_API_KEY=your_key_here
```

**限制**：FMP免费套餐（每天250次请求）将分析限制在约40只股票。使用`--max-candidates 40`以保持在限制内。

2. FMP详细分析：验证12%以上股息年复合增长率，计算精确RSI，分析基本面

**FMP单一筛选：**


### 第3步：查看结果

脚本生成两个输出：

1. **JSON文件**：`dividend_growth_pullback_results_YYYY-MM-DD.json`
   - 包含所有指标的格式化数据，用于进一步分析
   - 包括股息增长率、RSI值、财务健康指标

2. **Markdown报告**：`dividend_growth_pullback_screening_YYYY-MM-DD.md`
   - 人类可读的分析，包含股票简介
   - 基于情景的概率评估
   - 入场时机建议

### 第4步：分析合格股票

报告为每个合格股票包括：

**股息增长概况：**
- 当前股息收益率和年度股息
- 3年股息年复合增长率和一致性
- 派息比率可持续性评估

**技术时机：**
- 当前RSI值（≤40=超卖）
- RSI背景（极端超卖<30 vs. 早期回调30-40）
- 相对于最近趋势的价格走势

**质量指标：**
- 收入和EPS增长（确认业务动力）
- 财务健康状况（债务水平、流动性比率）
- 盈利能力（ROE、利润率）

**投资建议：**
- 入场时机评估（立即入场 vs. 等待确认）
- 股票特定风险因素
- 基于股息增长复利的上行情景

## 筛选标准详情

### 第1阶段：基本面筛选（FMP API）

**初始筛选：**
- 股息收益率 ≥ 1.5%（根据实际股息支付计算）
- 市值 ≥ 20亿美元（流动性和稳定性）
- 交易所：NYSE、NASDAQ（排除OTC/粉单）

**股息增长分析：**
- 3年股息年复合增长率 ≥ 12%（6年内股息翻倍）
- 股息一致性：过去4年未削减
- 派息比率 < 100%（可持续性检查）

**财务健康状况：**
- 3年正收入增长
- 3年正EPS增长
- 负债权益率 < 2.0（可管理杠杆）
- 流动比率 > 1.0（流动性）

### 第2阶段：技术筛选（RSI计算）

**RSI计算：**
- 使用每日收盘价计算14周期RSI
- 公式：RSI = 100 - (100 / (1 + RS))
  - RS = 14周期平均收益/平均损失
- 数据来源：FMP历史价格（过去30天）

**RSI过滤器：**
- RSI ≤ 40（超卖/回调条件）
- RSI解释：
  - < 30：极端超卖（潜在反转）
  - 30-40：早期回调（上升趋势修正）
  - > 40：未超卖（排除）

### 第3阶段：排名和输出

**综合评分（0-100）：**
- 股息增长（40%）：奖励更高的CAGR和一致性
- 财务质量（30%）：ROE、利润率、债务水平
- 技术设置（20%）：RSI越低=更好的入场机会
- 估值（10%）：市盈率和市净率提供参考（非排除性）

股票按综合评分排名。得分最高的股票结合了卓越的股息增长和有吸引力的技术入场点。

## 理解结果

### 解读RSI水平

**RSI 25-30（极端超卖）：**
- 常常表明恐慌性抛售或负面消息
- 风险较高但潜在回报也最高
- 建议：等待RSI抬头（稳定迹象）
- 入场：分批建仓50%仓位，RSI >30时加仓

**RSI 30-35（强超卖）：**
- 强上升趋势中的正常回调
- 风险低于极端超卖
- 建议：可立即入场
- 入场：可接受全仓位，止损设在5-8%下方

**RSI 35-40（早期回调）：**
- 上升趋势中的轻微弱势
- 进一步下跌风险最低
- 建议：对高确定性股票采取保守入场
- 入场：全仓位，紧止损3-5%下方

### 股息增长复利示例

**12%股息年复合增长率（最低阈值）：**
- 起始收益率：1.5%
- 第6年：成本收益率2.96%（翻倍）
- 第12年：成本收益率5.85%（4倍）
- 案例：Visa (V)、Mastercard (MA) 历史概况

**15%股息年复合增长率（优秀）：**
- 起始收益率：1.8%
- 第6年：成本收益率4.08%（2.3倍）
- 第12年：成本收益率9.22%（5.1倍）
- 案例：微软 (MSFT) 2010-2020期间

**20%股息年复合增长率（卓越）：**
- 起始收益率：2.0%
- 第6年：成本收益率6.00%（3倍）
- 第12年：成本收益率18.0%（9倍）
- 案例：苹果 (AAPL) 2012-2020期间

**关键洞察：** 较低起始收益率+高增长 > 较高起始收益率+低增长（10年以上）。

## 故障排除

### 未找到结果

**可能原因：**
1. **市场状况：** 强牛市中超卖股票较少
2. **标准过于严格：** 12%股息增长很少见（通常5-10只股票符合条件）
3. **RSI阈值过低：** 考虑将RSI ≤45（早期回调阶段）

**解决方案：**
- 放宽RSI阈值：`--rsi-max 45`
- 降低股息增长：`--min-div-growth 10.0`
- 降低最低收益率：`--min-yield 1.0`

### API速率限制达到

**FMP免费套餐限制：**
- 每天250次请求
- 每只股票分析需要6次API调用（报价、股息、价格、收入、资产负债、现金流、指标）
- FMP单一模式每天最多约40只股票

**解决方案：**

**1. 使用FINVIZ两阶段方法（推荐）**
```bash
python3 skills/dividend-growth-pullback-screener/scripts/screen_dividend_growth_rsi.py --use-finviz
```
- FINVIZ预筛选：1次API调用→10-50个候选（已按RSI过滤）
- FMP分析：6次调用×10-50只股票=60-300次FMP调用
- **优势**：FINVIZ RSI过滤器大幅减少候选，保持在FMP限制内

**2. 限制FMP单一候选数量**
```bash
python3 skills/dividend-growth-pullback-screener/scripts/screen_dividend_growth_rsi.py --max-candidates 40
```

**3. 等待24小时速率限制重置**
- FMP在UTC午夜重置

**4. 升级到FMP付费套餐**
- 启动者($14/月)：每天500次请求
- 专业版($29/月)：每天1000次请求

**注意：** FINVIZ Elite订阅($40/月)+FMP免费套餐在此用例中比FMP付费套餐更具成本效益。

### RSI计算错误

**问题：** "不足价格数据用于RSI计算"

**原因：** 股票交易历史少于30天（IPO或非活跃）

**解决方案：** 脚本自动跳过数据不足的股票，无需操作。

## 与其他技能结合

**预筛选背景：**
1. **市场新闻分析师** → 识别行业轮动或市场回调
2. **广度图表分析师** → 确认更广泛市场超卖状况
3. **经济日历获取器** → 检查即将到来的利率决定或宏观事件

**筛选后分析：**
1. **技术分析师** → 分析合格候选的个别股票图表
2. **美国股票分析** → 在入场前深入分析特定股票
3. **回测专家** → 历史验证RSI+股息增长策略

**示例工作流程：**
```
1. 市场新闻分析师："本周市场因美联储鹰派言论回调5%"
2. 广度图表分析师：确认市场超卖（标普广度疲软）
3. 股息增长回调筛选器：找到8只优质股息增长者，RSI <35
4. 技术分析师：分析前3个候选的支撑位和入场时机
5. 执行：分批建仓，6-12个月时间范围
```
