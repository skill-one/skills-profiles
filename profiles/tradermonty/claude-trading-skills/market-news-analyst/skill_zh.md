# 市场新闻分析师

## 概述

这项技能能够全面分析过去10天内具有市场影响力的新闻事件，重点关注其对美国股票市场和商品的影响。该技能使用WebSearch和WebFetch工具自动收集来自可信来源的新闻，评估市场影响程度，分析实际市场反应，并生成按市场影响重要性排序的结构化英文报告。

## 前置条件

- **工具：** 必须提供WebSearch和WebFetch工具进行新闻收集
- **API密钥：** 无需提供（使用内置网络搜索功能）
- **知识：** 熟悉金融市场术语有助于但不要求

## 输出

这项技能在分析期间生成**对话式指导**。当完整工作流程执行时，Claude会生成一份全面的Markdown报告（请参阅第6步的格式），用户可以根据要求将其保存到`reports/`目录中。不会自动生成文件；输出以对话形式呈现。

## 何时使用此技能

使用此技能的情况包括：

- 用户请求分析过去10天内的重大市场新闻
- 用户想了解市场对特定事件（FOMC决定、收益、地缘政治）的反应
- 用户需要具有影响评估的全面市场新闻摘要
- 用户询问新闻事件与商品价格变动之间的相关性
- 用户要求分析中央银行政策声明如何影响市场

示例用户请求：
- "分析过去10天内的重大市场新闻"
- "最新的FOMC决定如何影响市场？"
- "本周最重要的市场驱动事件是什么？"
- "分析最近的地缘政治新闻和商品价格反应"
- "审查巨型科技公司的收益及其市场影响"

## 分析工作流程

在分析市场新闻时，请遵循以下结构化的6步工作流程：

### 第1步：通过WebSearch/WebFetch收集新闻

**目标：** 收集过去10天内涵盖重大市场驱动事件的全面新闻。

**搜索策略：**

执行并行WebSearch查询，涵盖不同的新闻类别：

**货币政策：**
- 搜索："FOMC会议过去10天"、"美联储利率"、"欧洲央行政策决定"、"日本银行"
- 目标：中央银行决定、前瞻指引变化、通胀评论

**通胀/经济数据：**
- 搜索："CPI通胀报告[当前月份]"、"就业报告NFP"、"GDP数据"、"PPI生产价格"
- 目标：主要经济数据发布和意外情况

**巨型公司收益：**
- 搜索："苹果收益[当前季度]"、"微软收益"、"英伟达收益"、"亚马逊收益"、"特斯拉收益"、"Meta收益"、"谷歌收益"
- 目标：最大公司的结果、指引、市场反应

**地缘政治事件：**
- 搜索："中东冲突油价"、"乌克兰战争"、"中美紧张局势"、"贸易战关税"
- 目标：冲突、制裁、影响市场的贸易争端

**商品市场：**
- 搜索："过去一周油价新闻"、"金价"、"OPEC会议"、"天然气价格"、"铜价"
- 目标：供应中断、需求变化、价格变动

**企业新闻：**
- 搜索："重大并购宣布"、"银行收益"、"科技行业新闻"、"破产"、"信用评级下调"
- 目标：巨型公司以外的重大企业事件

**推荐新闻来源（优先顺序）：**
1. 官方来源：FederalReserve.gov、SEC.gov（EDGAR）、Treasury.gov、BLS.gov
2. 一级金融新闻：Bloomberg、Reuters、华尔街日报、金融时报
3. 专业：CNBC（实时）、MarketWatch（摘要）、S&P Global Platts（商品）

**搜索执行：**
- 使用WebSearch进行广泛主题搜索
- 使用WebFetch获取来自官方来源或主要新闻机构的特定URL
- 收集出版日期以确保新闻在10天窗口内
- 捕获：事件日期、来源、标题、关键细节、市场背景（开盘前、交易时段、盘后）

**过滤标准：**
- 聚焦于一级市场驱动事件（请参阅参考资料/市场事件模式.md）
- 优先考虑具有明确市场影响的新闻（价格变动、成交量激增）
- 排除：中小盘股特定新闻、小规模产品更新、例行申报

在整个收集过程中用英语思考。记录每个重大新闻项目：
- 日期和时间
- 事件类型（货币政策、收益、地缘政治等）
- 来源可靠性等级
- 初始市场反应（如果可观察）

### 第2步：加载知识库参考资料

**目标：** 访问领域专业知识以提供影响评估。

根据收集的新闻类型加载相关参考文件：

**始终加载：**
- `references/market_event_patterns.md` - 所有主要事件类型的综合模式
- `references/trusted_news_sources.md` - 来源信誉评估

**根据收集的新闻条件加载：**

如果发现**货币政策新闻**：
- 关注：market_event_patterns.md → 中央银行货币政策事件部分
- 关键框架：加息/降息反应、量化宽松/紧缩影响、鹰派/鸽派基调

如果发现**地缘政治事件**：
- 加载：`references/geopolitical_commodity_correlations.md`
- 关注：能源商品、贵金属、与事件匹配的区域框架

如果发现**巨型公司收益**：
- 加载：`references/corporate_news_impact.md`
- 关注：特定公司部分、行业传染模式

如果发现**商品新闻**：
- 加载：`references/geopolitical_commodity_correlations.md`
- 关注：特定商品部分（石油、黄金、铜等）

**知识整合：**
将收集的新闻与历史模式进行比较，以：
- 预测预期的市场反应
- 识别异常（市场反应与历史模式不同）
- 评估反应是否为典型规模或过度反应
- 确定是否按预期发生传染

### 第3步：影响程度评估

**目标：** 按市场影响重要性对每个新闻事件进行排名。

**影响评估框架：**

对每个新闻项目，评估三个维度：

**1. 资产价格影响（主要因素）：**

衡量实际或估计的价格变动：

**股票市场：**
- 指数级：标普500、纳斯达克100、道琼斯
  - 严重：日内±2%+
  - 主要：±1-2%
  - 中等：±0.5-1%
  - 轻微：±0.2-0.5%
  - 微不足道：<0.2%

- 行业级：特定行业ETF
  - 严重：±5%+
  - 主要：±3-5%
  - 中等：±1-3%
  - 轻微：<1%

- 股票特定：个别巨型公司
  - 严重：±10%+（且指数权重导致指数变动）
  - 主要：±5-10%
  - 中等：±2-5%

**商品市场：**
- 石油（WTI/Brent）：
  - 严重：±5%+
  - 主要：±3-5%
  - 中等：±1-3%

- 黄金：
  - 严重：±3%+
  - 主要：±1.5-3%
  - 中等：±0.5-1.5%

- 基金属（铜等）：
  - 严重：±4%+
  - 主要：±2-4%
  - 中等：±1-2%

**债券市场：**
- 10年期国债收益率：
  - 严重：日内±20个基点+
  - 主要：±10-20个基点
  - 中等：±5-10个基点

**货币市场：**
- 美元指数（DXY）：
  - 严重：±1.5%+
  - 主要：±0.75-1.5%
  - 中等：±0.3-0.75%

**2. 影响广度（乘数）：**

评估受影响的多少市场/行业：

- **系统性（3倍乘数）：** 多种资产类别、全球市场
  - 示例：FOMC意外、银行危机、主要战争爆发

- **跨资产（2倍乘数）：** 股票+商品，或股票+债券
  - 示例：通胀意外、地缘政治供应冲击

- **行业级（1.5倍乘数）：** 整个行业或相关行业
  - 示例：科技收益集群、能源政策声明

- **股票特定（1倍乘数）：** 单个公司（除非巨型公司对指数有影响）
  - 示例：个别公司收益、并购

**3. 前瞻性重要性（修正因子）：**

考虑未来影响：

- **体制变化（+50%）：** 基本市场结构变化
  - 示例：美联储从加息转向降息、主要地缘政治重组

- **趋势确认（+25%）：** 确认现有轨迹
  - 示例：连续强劲的通胀数据、持续的收益超预期

- **孤立事件（0%）：** 一次性且有限的前瞻性信号
  - 示例：单个数据点在范围内、公司特定问题

- **相反信号（-25%）：** 与现有叙事相矛盾
  - 示例：好消息被市场忽视、坏消息上涨

**影响分数计算：**

```
影响分数 = （价格影响分数 × 广度乘数）+ 前瞻性修正因子

价格影响分数：
- 严重：10分
- 主要：7分
- 中等：4分
- 轻微：2分
- 微不足道：1分
```

**示例计算：**

**FOMC 75个基点加息（鹰派基调）：**
- 价格影响：标普500 -2.5%（严重 = 10分）
- 广度：系统性（股票、债券、美元、商品都变动）= 3倍
- 前瞻性：趋势确认（持续的紧缩）= +25%
- **分数： (10 × 3) × 1.25 = 37.5**

**英伟达收益超预期：**
- 价格影响：NVDA +15%，纳斯达克 +1.5%（严重 = 10分）
- 广度：行业级（半导体、科技广泛）= 1.5倍
- 前瞻性：趋势确认（AI需求）= +25%
- **分数： (10 × 1.5) × 1.25 = 18.75**

**地缘政治紧张局势（中东）：**
- 价格影响：石油 +8%，标普 -1.2%（严重 = 10分）
- 广度：跨资产（石油、股票、黄金）= 2倍
- 前瞻性：孤立事件（无升级）= 0%
- **分数： (10 × 2) × 1.0 = 20**

**单个股票收益（非巨型公司）：**
- 价格影响：股票 +12%，无指数影响（主要 = 7分）
- 广度：股票特定 = 1倍
- 前瞻性：孤立 = 0%
- **分数： (7 × 1) × 1.0 = 7**

**排名：**
对所有新闻项目评分后，从最高到最低排序。这决定了报告顺序。

### 第4步：市场反应分析

**目标：** 分析市场实际上如何对每个事件做出反应。

对每个重大新闻项目（影响分数>5），进行详细反应分析：

**即时反应（日内）：**
- 方向：正面、负面、混合
- 规模：与价格影响类别一致
- 时间：开盘前、交易中、盘后
- 波动性：VIX变动、买卖价差

**多资产反应：**

**股票：**
- 指数表现（标普500、纳斯达克、道琼斯、罗素2000）
- 行业轮动（哪些行业表现好/差）
- 个股变动（巨型公司、相关公司）
- 成长与价值、大盘与小盘差异

**固定收益：**
- 国债收益率（2年期、10年期、30年期）
- 收益率曲线形状（变陡、变平、倒挂）
- 信用利差（投资级、高收益）
- TIPS折价（通胀预期）

**商品：**
- 能源：石油（WTI、布伦特）、天然气
- 贵金属：黄金、白银
- 基金属：铜、铝（如果相关）
- 农业产品：小麦、玉米、大豆（如果相关）

**货币：**
- 美元指数（DXY）
- 欧元/美元、美元/日元、英镑/美元
- 新兴市场货币
- 安全避风港（日元、瑞士法郎）

**衍生品：**
- VIX（波动率指数）
- 期权活动（看跌/看涨比率、异常成交量）
- 期货头寸

**模式比较：**

将观察到的反应与知识库中的预期模式进行比较：

- **一致：** 反应与历史模式匹配
  - 示例：美联储加息 → 科技股下跌，美元上涨（如预期）

- **放大：** 反应超过典型模式
  - 示例：通胀数据+0.3%高于预期 → 空头出货2倍典型
  - 调查：头寸、情绪、累积因素

- **减弱：** 反应小于历史模式
  - 示例：地缘政治事件 → 石油几乎未变动
  - 调查：已反映、其他抵消因素

- **相反：** 反应与历史模式相反
  - 示例：好消息被忽视，坏消息上涨
  - 调查："好消息是坏消息"动态、美联储转向希望

**异常识别：**

标记与模式显著偏离的反应：
- 市场对通常具有市场影响力的新闻无动于衷
- 对通常较小的新闻过度反应
- 传染未能按预期扩散
- 安全避风港不起作用（相关性破裂）

**情绪指标：**

- 风险偏好：哪种状态占主导地位
- 头寸：是否有证据表明拥挤交易正在平仓
- 动量：后续交易中的持续或反转

### 第5步：相关性和因果关系评估

**目标：** 区分直接影响的和偶然的时机。

**多事件分析：**

当10天期内发生多个重大事件时，评估相互作用：

**强化事件：**
- 相同方向影响
- 示例：鹰派FOMC + 热CPI → 对股票都不利，放大变动
- 组合影响通常非线性的（大于各部分之和）

**抵消事件：**
- 相反方向影响
- 示例：强劲收益（正面）+ 地缘政治紧张局势（负面）→ 净反应温和
- 确定哪个因素占主导地位

**连续事件：**
- 一个事件为下一个事件设置了反应
- 示例：第一次加息反应适度，第二次加息严重（累积紧缩担忧）
- 路径依赖很重要

**偶然时机：**
- 事件无关但同时发生
- 难以分离个别影响
- 注意归因的不确定性

**地缘政治-商品相关性：**

对于地缘政治事件，特别分析商品市场反应，使用geopolitical_commodity_correlations.md：

**能源：**
- 将冲突/制裁映射到供应中断风险
- 评估实际与预期的供应影响
- 持续时间：暂时性峰值 vs 持续性上升

**贵金属：**
- 安全避风港资金流向 vs 实际利率驱动
- 黄金对风险规避事件的反应
- 中央银行购买影响

**工业金属：**
- 经济放缓担忧导致的需求破坏
- 供应链中断
- 中国因素在铜、铝中的影响

**农业（如果相关）**
- 黑海谷物出口（俄罗斯-乌克兰）
- 天气叠加
- 食物安全政策响应

**传导机制：**

追踪新闻如何通过市场传导：

**直接渠道：**
- 新闻 → 立即资产价格反应
- 示例：OPEC减产 → 石油价格立即上涨

**间接渠道：**
- 新闻 → 经济影响 → 资产价格
- 示例：加息 → 抵押贷款利率上升 → 房地产放缓 → 建筑商股票下跌

**情绪渠道：**
- 新闻 → 风险偏好变化 → 广泛的资产重新配置
- 示例：银行危机 → 风险规避 → 国债上涨，股票下跌

**反馈循环：**
- 初始反应创造二级效应
- 示例：股票抛售 → 保证金追缴 → 强制卖出 → 更深的抛售

### 第6步：报告生成

**目标：** 创建按市场影响排序的结构化英文Markdown报告。

**报告结构：**

```markdown

[3-4句话涵盖:]
- 分析期间（具体日期）
- 确定的重大事件数量
- 市场主题/体制（风险偏好/风险规避，行业轮动）
- 最重要的事件前1-2个

## 市场影响排名

[表格格式，按影响分数降序排列]

| 排名 | 事件 | 日期 | 影响分数 | 受影响的资产类别 | 市场反应 |
|------|-------|------|----------|------------------------|-----------------|
| 1 | [事件] | [日期] | [分数] | [股票、商品等] | [简要反应] |
| 2 | ... | ... | ... | ... | ... |

---

## 详细事件分析

[按排名顺序为每个事件提供全面分析]

### [排名]. [事件名称] (影响分数: [X])

**事件日期:** [日期, 时间]
**事件类型:** [货币政策 / 收益 / 地缘政治 / 经济数据 / 企业]
**新闻来源:** [来源，包括信誉等级]

#### 事件摘要
[3-4句话描述发生了什么]
- 关键细节（例如，利率决定、收益超预期/不及预期的幅度、冲突发展）
- 背景（是否预期，意外因素）
- 前瞻指引或影响

#### 市场反应

**即时（当日）：**
- **股票：** 标普500 [+/-X%], 纳斯达克 [+/-X%], 道琼斯 [+/-X%], 罗素2000
- **债券：** 10年期收益率 [变化], 信用利差 [变动]
- **商品：** 石油 [+/-X%], 黄金 [+/-X%], 铜 [+/-X%]（如果相关）

- [方向：持续、反转或巩固]

- **预期反应：** [基于知识库的历史模式]
- **实际与预期：** [一致 / 放大 / 减弱 / 相反]

## 关键分析原则

进行市场新闻分析时：

1. **影响优于噪音:** 聚焦真正具有市场影响力的新闻，过滤掉次要事件
2. **多资产视角:** 跨股票、债券、商品、货币进行分析以了解全面影响
3. **模式识别:** 与历史先例进行比较，同时注意独特之处
4. **因果关系纪律:** 严格区分市场变动与特定新闻的因果关系 vs 偶然时机
5. **前瞻性:** 强调对未来市场行为的影响，而不仅仅是向后描述
6. **客观性:** 分离市场反应（发生了什么）和个人市场观点（应该发生什么）
7. **量化：** 使用具体数字（%, bps）而不是模糊术语（“重大”，“大规模”）
8. **来源可信度：** 优先考虑官方来源和一级新闻，而不是谣言和未经证实的报告
9. **广度分析：** 个股变动只有在巨型公司或系统性信号时才重要
10. **英语一致性：** 所有思考、分析和输出均为英语，以确保一致性

## 常见陷阱避免

**过度归因：**
- 并非每个市场变动都是新闻驱动的（技术性、资金流、月末再平衡存在）
- 承认当归因不确定时

**近期偏差：**
- 最新新闻不一定是最重要的
- 按实际影响排名，而不是按时间顺序

**后见之明偏差：**
- 区分“事后看来很明显”与“当时令人惊讶”
- 注意共识预期与实际结果

**单一因素分析：**
- 市场同时响应多个因素
- 承认相互作用效应

**忽略规模：**
- “热”CPI高于预期0.1%与0.5%高于预期不同
- 量化意外因素
