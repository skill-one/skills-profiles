# C级高管咨询生态系统

为创始人及高管提供的完整虚拟董事会。

## 快速入门

```
1. 运行 /cs:setup → 创建 company-context.md (所有代理都将读取此文件)
   ✓ 在继续之前，请验证 company-context.md 是否已创建并包含您的公司名称、阶段和核心指标。
2. 提出任何战略问题 → 首席助理将路由到正确的角色
3. 对于重大决策 → /cs:board 触发多角色董事会会议
   ✓ 在接受结论之前，请确认至少有3个角色已进行过评估。
```

### 命令

#### `/cs:setup` — 欢迎问卷

引导以下提示并将 `company-context.md` 写入项目根目录。每个公司或当背景发生显著变化时运行一次。

```
Q1. 您的公司名称和一句话描述是什么？
Q2. 您处于哪个阶段？(想法 / 预种子轮 / 种子轮 / A轮 / B轮及以上)
Q3. 您当前的 ARR（或 MRR）是多少，以及剩余的月数？
Q4. 您的团队规模和结构是什么？
Q5. 您服务于哪个行业和客户细分？
Q6. 您未来90天的前三个优先事项是什么？
Q7. 您目前最大的风险或障碍是什么？
```

收集答案后，代理将生成结构化输出：

```markdown
# 公司背景
- 名称: <答案>
- 阶段: <答案>
- 行业: <答案>
- 团队规模: <答案>
- 关键指标: <ARR/MRR, 增长率, 剩余时间>
- 优先事项: <答案>
- 关键风险: <答案>
```

#### `/cs:board` — 全体董事会会议

召集所有相关的执行角色，分为三个阶段：

```
阶段1 — 框架：首席助理陈述决策和成功标准。
阶段2 — 隔离：每个角色生成独立分析（不进行交叉沟通）。
阶段3 — 辩论：角色暴露冲突，检验假设，就建议达成一致。不同意的观点将保存在日志中。
```

用于高风险或跨职能决策。在接受结论之前，请确认至少有3个角色已进行过评估。

### 首席助理路由矩阵

当问题没有角色前缀时，首席助理使用以下主要信号将其映射到适当的执行者：

| 主题信号 | 主要角色 | 支持角色 |
|---|---|---|
| 融资、估值、烧钱 | 财务总监 | 首席执行官, 首席增长官 |
| 架构、自建与购买、技术债务 | 首席技术官 | 首席产品官, 首席信息官 |
| 招聘、文化、绩效 | 首席人力资源官 | 首席执行官, 执行导师 |
| 市场推广、需求生成、定位 | 首席营销官 | 首席增长官, 首席产品官 |
| 收入、管道、销售动作 | 首席增长官 | 首席营销官, 财务总监 |
| 安全、合规、风险 | 首席信息官 | 首席技术官, 财务总监 |
| 产品路线图、优先级 | 首席产品官 | 首席技术官, 首席营销官 |
| 运营、流程、扩展 | 首席运营官 | 财务总监, 首席人力资源官 |
| 视野、战略、投资者关系 | 首席执行官 | 执行导师 |
| 职业发展、创始人心理、领导力 | 执行导师 | 首席执行官, 首席人力资源官 |
| 多领域 / 不明确 | 首席助理召集董事会 | 所有相关角色 |

### 直接调用特定角色

要绕过首席助理路由并直接向一位高管提问，请用角色名称作为问题前缀：

```
CFO: 我们的最佳烧钱率是多少，将进入A轮？
CTO: 我们应该内部重建认证层还是购买解决方案？
CHRO: 我们如何为15人的团队设计绩效评估流程？
```

首席助理仍然会记录这次交流；只是路由被跳过了。

### 示例：战略问题

**输入：** "我们现在应该进行A轮融资还是延长剩余时间，优先增长ARR？"

**输出格式：**
- **核心结论：** 延长6个月剩余时间；在$2M ARR时进行融资以获得更好的条款。
- **是什么：** 当前的$800K ARR低于大多数A轮投资者基准的阈值。
- **为什么：** 现在融资会增加稀释风险；6个月的延期是当前烧钱率下可实现的。
- **如何行动：** 削减2个低ROI渠道，达到$2M ARR，然后进行6周的融资冲刺。
- **您的决定：** 进行延期 / 无论如何立即融资（选择一个）。

### 示例：company-context.md (在 /cs:setup 之后)

```markdown
# 公司背景
- 名称: Acme Inc.
- 阶段: 种子轮 ($800K ARR)
- 行业: B2B SaaS
- 团队规模: 12
- 关键指标: 15% 月环比增长, 18个月剩余时间
- 优先事项: A轮融资准备, 企业级市场推广
```

## 包含内容

### 10 C级高管角色
首席执行官, 首席技术官, 首席运营官, 首席产品官, 首席营销官, 财务总监, 首席增长官, 首席信息官, 首席人力资源官, 执行导师

### 6 编排技能
创始人入职, 首席助理 (路由器), 董事会会议, 决策记录器, 代理协议, 背景引擎

### 6 跨领域能力
董事会演示文稿生成器, 假设战室, 竞争情报, 组织健康诊断, 并购手册, 国际扩张

### 6 文化与协作
文化架构师, 公司操作系统, 创始人教练, 战略协同, 变革管理, 内部叙事

## 核心功能

- **内部质量循环：** 自我验证 → 同行验证 → 批评者预审 → 汇报
- **双层记忆：** 原始记录 + 批准的决策（防止幻觉的共识）
- **董事会会议隔离：** 在交叉质询之前进行第二阶段独立分析
- **主动触发：** 基于背景的早期预警，无需提问
- **结构化输出：** 核心结论 → 是什么 → 为什么 → 如何行动 → 您的决定
- **25个Python工具：** 所有标准库，CLI优先，JSON输出，零依赖
