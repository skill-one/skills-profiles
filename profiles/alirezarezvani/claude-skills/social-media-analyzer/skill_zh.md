## 分析工作流

分析社交媒体活动表现：

1. 验证输入数据的完整性（覆盖范围 > 0，日期有效）
2. 按每篇帖子计算互动指标
3. 汇总活动级指标
4. 如提供广告支出则计算投资回报率
5. 与平台基准进行比较
6. 识别表现最佳和最差的帖子
7. 生成建议
8. **验证：** 互动率 < 100%，投资回报率与支出数据匹配

### 输入要求

| 字段 | 必填 | 描述 |
|-------|----------|-------------|
| platform | 是 | instagram, facebook, twitter, linkedin, tiktok |
| posts[] | 是 | 帖子数据数组 |
| posts[].likes | 是 | 点赞/反应数量 |
| posts[].comments | 是 | 评论数量 |
| posts[].reach | 是 | 独特用户覆盖范围 |
| posts[].impressions | 否 | 总观看次数 |
| posts[].shares | 否 | 分享/转发数量 |
| posts[].saves | 否 | 保存/收藏数量 |
| posts[].clicks | 否 | 链接点击次数 |
| total_spend | 否 | 广告支出（用于投资回报率） |

### 数据验证检查

在分析前验证：

- [ ] 所有帖子的覆盖范围 > 0（避免除以零）
- [ ] 互动计数为非负数
- [ ] 日期范围有效（开始 < 结束）
- [ ] 平台被识别
- [ ] 如请求投资回报率，支出 > 0

## 互动指标

### 互动率计算

```
互动率 = (点赞 + 评论 + 分享 + 保存) / 覆盖范围 × 100
```

### 指标定义

| 指标 | 公式 | 解释 |
|--------|---------|----------------|
| 互动率 | 互动 / 覆盖范围 × 100 | 受众互动水平 |
| CTR | 点击 / 观看次数 × 100 | 内容点击吸引力 |
| 覆盖率 | 覆盖范围 / 关注者 × 100 | 内容传播 |
| 传播率 | 分享 / 观看次数 × 100 | 分享价值 |
| 保存率 | 保存 / 覆盖范围 × 100 | 内容价值 |

### 表现类别

| 评级 | 互动率 | 行动 |
|--------|-----------------|--------|
| 优秀 | > 6% | 扩展并复制 |
| 良好 | 3-6% | 优化并扩展 |
| 一般 | 1-3% | 测试改进 |
| 差 | < 1% | 分析并调整 |

## 投资回报率计算

计算广告支出回报：

1. 汇总所有帖子的总互动量
2. 计算每次互动成本（CPE）
3. 如有点击则计算每次点击成本（CPC）
4. 使用基准率估算互动价值
5. 计算投资回报率百分比
6. **验证：** 投资回报率 = (价值 - 支出) / 支出 × 100

### 投资回报率公式

| 指标 | 公式 |
|--------|---------|
| 每次互动成本（CPE） | 总支出 / 总互动 |
| 每次点击成本（CPC） | 总支出 / 总点击 |
| 每千次成本（CPM） | (支出 / 观看次数) × 1000 |
| 广告支出回报（ROAS） | 收入 / 广告支出 |

### 互动价值估算

| 行动 | 价值 | 理由 |
|--------|-------|-----------|
| 点赞 | $0.50 | 品牌认知 |
| 评论 | $2.00 | 积极互动 |
| 分享 | $5.00 | 放大 |
| 保存 | $3.00 | 意图信号 |
| 点击 | $1.50 | 流量价值 |

### 投资回报率解释

| 投资回报率 % | 评级 | 建议 |
|-------|--------|----------------|
| > 500% | 优秀 | 大幅增加预算 |
| 200-500% | 良好 | 适度增加预算 |
| 100-200% | 可接受 | 优化后再扩展 |
| 0-100% | 收支平衡 | 审查定位和创意 |
| < 0% | 负面 | 暂停并调整 |

## 示例

### 示例输入

见 `assets/sample_input.json`：

```json
{
  "platform": "instagram",
  "total_spend": 500,
  "posts": [
    {
      "post_id": "post_001",
      "content_type": "image",
      "likes": 342,
      "comments": 28,
      "shares": 15,
      "saves": 45,
      "reach": 5200,
      "impressions": 8500,
      "clicks": 120
    }
  ]
}
```

### 示例输出

见 `assets/expected_output.json`：

```json
{
  "campaign_metrics": {
    "total_engagements": 1521,
    "avg_engagement_rate": 8.36,
    "ctr": 1.55
  },
  "roi_metrics": {
    "total_spend": 500.0,
    "cost_per_engagement": 0.33,
    "roi_percentage": 660.5
  },
  "insights": {
    "overall_health": "excellent",
    "benchmark_comparison": {
      "engagement_status": "excellent",
      "engagement_benchmark": "1.22%",
      "engagement_actual": "8.36%"
    }
  }
}
```

### 解释

示例活动显示：
- **互动率 8.36%** vs 1.22% 基准 = 优秀（6.8倍于平均水平）
- **点击率 1.55%** vs 0.22% 基准 = 优秀（7倍于平均水平）
- **投资回报率 660%** = $500 支出的出色回报
- **建议：** 扩大预算，复制成功元素

## 主动触发器

- **互动率低于平台平均水平** → 内容未引起共鸣。分析最佳表现以寻找模式。
- **粉丝增长停滞** → 内容传播或频率问题。审计发布模式。
- **高观看次数、低互动** → 覆盖范围无共鸣。内容质量问题。
- **竞争对手表现显著优于** → 内容差距。分析其成功帖子。

## 沟通

所有输出通过质量验证：
- 自我验证：来源归因、假设审计、信心评分
- 输出格式：要点 → 什么（带信心）→ 为什么 → 如何行动
- 仅结果。每个发现标记：🟢 已验证、🟡 中等、🔴 假设。
