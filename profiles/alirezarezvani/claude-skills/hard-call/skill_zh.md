# /em:hard-call — 没有正确选项的决策框架

**命令：** `/em:hard-call <决策>`

用于那些让你凌晨三点辗转反侧的决策。解雇联合创始人。裁员20%。停止一个深受客户喜爱的产品。转型。关闭。

这些决策没有正确答案。它们只有“不那么错误”的选项。这个框架帮助你找到它。

---

## 为什么这些决策如此艰难

不是因为数据不清晰。通常，数据是清晰的。它们之所以艰难，是因为：

1. **影响真实的人** — 有人会失业，关系会结束，团队会受到伤害
2. **你一直在回避这个决策** — 这意味着问题已经比之前更糟了
3. **不可逆性** — 与大多数商业决策不同，你无法轻易撤销这个决定
4. **你身在其中** — 你对正确决策的判断被你对这件事的感受所蒙蔽

你回避一个艰难决策的时间越长，情况通常就会越糟糕。六个月前需要10%的裁员的公司，现在需要25%的裁员。四个月前就应该进行的联合创始人谈话，现在发生在十四个月。

**大多数艰难的决策都是迟到的决策。**

---

## 框架

### 第一步：可逆性测试

首先要问的最重要的问题：**你能撤销这个决定吗？**

- **可逆的** — 尝试它，学习，调整（解雇供应商，停止功能，改变策略）
- **部分可逆的** — 撤销起来痛苦但可能（重组，改变联合创始人角色）
- **不可逆的** — 无法撤销（解雇一个人，关闭一个有客户锁定效应的产品，关闭一个法律实体）

对于不可逆的决策，确定性的门槛更高。在行动之前，你必须进行更多的尽职调查。不是因为你可能会错——而是因为你无法挽回。

**如果你把一个可逆的决策当作不可逆的来处理，你就是在回避它。**

### 第二步：10/10/10框架

对每个选项问三个问题：

- **10分钟后**：做出这个决定后，你立刻会感觉如何？
- **10个月后**：影响是什么？问题会解决吗？
- **10年后**：当你回看时，这个决定会是正确的吗？

10分钟后的感觉通常是最低不可靠的指南。10年的视角通常会澄清正确的决定到底是什么。

**大多数艰难的决策在10年后看起来都很明显。问题在于你是否能忍受10分钟的痛苦。**

### 第三步：安迪·格鲁夫测试

安迪·格鲁夫对战略决策的测试：“如果我们明天被替换，新任CEO会做什么？”

用全新的视角，没有对当前路径的情感投入，没有沉没成本。从外部看，明显的正确决定是什么？

如果答案对旁观者来说很清晰，问题就变成了：你为什么还没做？

### 第四步：利益相关者影响映射

对每个选项，映射谁受影响以及如何受影响：

| 利益相关者 | 选项A影响 | 选项B影响 | 他们的反应 |
|-------------|----------------|----------------|----------------|
| 受影响的员工 | | | |
| 剩余团队 | | | |
| 客户 | | | |
| 投资者 | | | |
| 你 | | | |

这并不是要找到一个不会伤害任何人的选项——没有这样的选项。它是在你做决定之前了解全局。

### 第五步：预先公告测试

在做决定之前：写好公告。给团队的邮件，给客户的消息，你将要进行的谈话。

**如果你无法写出那个公告，你还没有准备好做这个决定。**

写公告迫使你面对你正在做的事情的现实。它也暴露了你的理由是否经得起检验。“我们做出这个改变是因为……”——这句话是否真实可信？

### 第六步：沟通计划

如果沟通不好，艰难的决策几乎总会变得更艰难。决策本身并不是唯一重要的东西——如何执行它极其重要。

对每个艰难的决策，计划：
- **谁需要首先知道**（直接受影响的人，在其他人之前）
- **你将如何告诉他们**（尽可能当面，永远不要通过邮件进行个人影响）
- **你会说什么**（诚实、直接、富有同情心——参见 `../executive-mentor/references/hard_things.md`）
- **他们可以问什么**（准备好回答每一个问题）
- **接下来会发生什么**（给他们一个清晰的关于之后会发生什么的画面）

## 针对特定决策的框架

### 解雇联合创始人
参见 `../executive-mentor/references/hard_things.md — 联合创始人冲突` 获取完整框架。

首先要回答的关键问题：
- 这是绩效问题还是价值观/文化问题？（不同的谈话）
- 你是否明确——不是暗示，而是直接——地指出了问题？
- 资本表是什么样子，以及法律影响是什么？
- 有没有更适合他们的角色，或者这是完全退出？
- 谁需要知道（董事会、团队、投资者）以及顺序是什么？

**规则：** 如果你考虑这件事超过三个月，你已经知道答案了。问题在于何时，而不是是否。

### 裁员
关键问题：
- 这是一次性重置还是长期衰退的开始？（一次重置是可以恢复的。连续裁员会摧毁文化。）
- 你裁员的程度是否足够深？（不够充分的裁员比不裁员更糟——两轮裁员会摧毁信任。）
- 谁拥有公告权，并且是直接的、诚实的？
- 离职补偿是否公平？
- 你如何防止最好的员工在之后离开？

**规则：** 一次裁员，一次深裁，有尊严地裁员。不确定性比清晰更糟。

### 转型
关键问题：
- 这是一次真正的转型（新方向）还是优化（相同方向，不同策略）？
- 你保留什么，放弃什么？
- 你有证据表明新方向有效，还是你在逃避失败？
- 你如何告诉购买旧愿景的现有客户？
- 这对董事会信心有什么影响？

**规则：** 转型应该由新机遇的证据推动，而不是由当前路径的失败推动。

### 停止产品线
关键问题：
- 目前使用它的客户会发生什么？
- 迁移路径是什么？
- 建造它的人会做什么？
- “停止”是正确的决定，还是“出售”或“分拆”更好？
- 叙事——内部和外部是什么？

---

## 回避测试

如果你一直在回避一个艰难的决策，如果你：
- 每周都在考虑它，超过一个月
- 希望情况会“自行解决”
- 等待更多数据，而你觉得永远不够
- 在脑海中已经多次进行过谈话，但现实中没有
- 你周围的人已经注意到了问题

**延迟的成本几乎总是高于决策的成本。**

你等待的每一月，问题都会加剧。不合作的联合创始人会变得更加根深蒂固。需要被停止的产品线会消耗更多资源。需要被解雇的人会影响周围的人。

做出决定。清晰地做出决定。有尊严地做出决定。
