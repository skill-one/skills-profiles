# /em:board-prep — 董事会会议准备

**命令：** `/em:board-prep <议程>`

为你们董事会的对抗性版本做准备，而不是友好的版本。准备好他们将要问的每一个难题。记住每一个你们需要熟练掌握的数字。讲述一个承认弱点但不失人心的故事。

---

## 董事会会议的现实

你们的董事会成员已经见过50多家公司。他们目睹过创始人面对自己的数字时畏缩不前，将坏消息包装成“学习机会”，并展示经过美化的演示文稿来掩盖实际情况。

他们知道你们是否在坦诚地对待他们。问题不是他们是否会问难题——而是你们是否准备好了。

最好的董事会会议不是那些看起来一切顺利的会议。而是那些CEO能够清晰看到现实、有计划，并在压力下能够执行的计划。

---

## 准备框架

### 第一阶段：数字熟练掌握

在会议之前，你们演示文稿中的每一个数字都应该牢记在心，而不仅仅是在幻灯片上。

**你们必须熟练掌握的数字：**
- 当前月度经常性收入（MRR）/年度经常性收入（ARR）和月度环比增长率
- 燃烧率（每月）和剩余时间（当前燃烧率下的月数）
- 按部门统计的员工人数
- 按渠道/细分市场的客户获取成本（CAC）和客户终身价值（LTV）
- 净收入留存率
- 订单管道：价值、转化率、平均销售周期
- 流失率：比率、主要原因、主要流失账户
- 毛利率（产品）、净利率（公司）
- 空缺的关键招聘职位和时间到岗

**自我压力测试：** 你们能否毫不犹豫地回答“你们的燃烧率是多少？” “按细分市场你们的流失率是多少？” 如果你们需要停顿，说明你们不知道。

### 第二阶段：预见难题

对于议程上的每一项内容，生成对抗性的问题版本。

**按主题划分的标准对抗性问题：**

*收入表现：*
- “你们本季度的收入目标差了20%。具体是什么出了问题？”
- “这是管道问题、转化问题还是产能问题？”
- “如果是因为一个大单子没完成，你们的模式对单子依赖度有多高？”
- “你们何时预计会恢复？你们有哪些领先指标表明你们是对的？”

*剩余时间/燃烧率：*
- “按当前燃烧率，你们还有N个月。如果下一轮融资需要9个月，你们的计划是什么？”
- “如果你们需要延长6个月的剩余时间，你们首先会削减什么？”
- “是否存在不进行下一轮融资的情况？”

*产品/路线图：*
- “你们发布了X。客户实际上是如何使用它的？”
- “你们在本季度砍掉了什么？为什么？”
- “你们的路线图落后在哪里？什么在延误？”

*团队：*
- “谁有离职风险？这会如何影响执行？”
- “你们有3位副总裁级别的招聘没有成功。你们看到了什么模式？”
- “这个阶段的团队是否合适？”

*竞争：*
- “竞争对手Y刚刚融资5000万美元。这会如何改变你们的地位？”
- “如果他们在90天内复制了你们最好的功能，你们的护城河是什么？”

### 第三阶段：构建叙事

董事会会议不是状态更新，而是领导力的展示。

**有效的结构：**

1. **我们现在的位置（诚实）** — 业务的当前状态，真实的数字，而不是平滑后的数字
2. **我们学到了什么** — 数据告诉我们90天前不知道的事情
3. **我们做错了什么** — 直接点名。不要让他们提问。
4. **我们正在如何解决** — 具体且有时间节点的行动
5. **我们需要这个会议室做什么** — 具体的要求。不是“支持”——而是具体的引荐、决策、资源。

**关于坏消息的规则：** 永远不要让董事会感到意外。如果一个季度表现不佳，他们应该在演示文稿之前就知道。3天前发送一封5句话的邮件：“收入为X美元，目标为Y美元。发生了什么，我正在做什么，我需要你们什么。”

### 第四阶段：对抗性准备

进行一次模拟董事会会议。让某人扮演你们最难缠的董事。

**模拟：**
- 按照你们会的方式展示你们的演示文稿
- 模拟董事提出每一个令人不适的问题
- 你们不参考演示文稿回答
- 之后：记录每一个让你们犹豫或感到防御性的问题

**让你们感到防御性的问题 = 你们需要准备的问题。**

### 第五阶段：逐位董事准备

不是所有董事会成员都希望从会议中得到同样的事情。

**对于每位董事，了解：**
- 他们当前的主要关注点（通常与他们的投资逻辑相关）
- 他们最密切关注的指标
- 什么会让他们对你们失去信心
- 他们在上次会议中说过的话，你们应该回应

**常见的董事类型：**
- **运营型** — 想知道什么在出问题，谁负责解决
- **财务投资者** — 关注盈利路径或下一轮融资
- **战略投资者** — 担心竞争地位和护城河
- **独立董事** — 关注治理、团队动态和你们的判断

## 会议前检查清单

**会议前48小时：**
- [ ] 所有数字与源系统核对（不是上周的导出）
- [ ] 演示文稿检查内部一致性
- [ ] 发送给董事会预读（演示文稿+1页关于关键主题的摘要）
- [ ] 与任何可能存在担忧的董事进行一对一沟通
- [ ] 3个你们预期的最难问题——大声练习

**会议当天：**
- [ ] 分发带有时间分配的议程
- [ ] 了解每个议程项目的请求（需要决策、需要输入、仅供参考）
- [ ] 准备好留下的材料
- [ ] 准备好后续行动模板

---

## 会议期间

**董事会关注什么：**
- 你们是承担坏消息还是转移话题？
- 你们是在维护叙事还是分享现实？
- 你们是否知道你们的数字还是需要查找？
- 被挑战时，你们是变得防御还是参与？
- 你们是否知道你们不知道什么？

**你们能做的最好的事情：** 在他们提问之前说出难题。“我想直接讨论收入目标差的问题。发生了什么，我之前应该注意到什么，我做了哪些改变。”

---

## 会议后

在24小时内：
- 发送行动项及其负责人和日期
- 发送你们承诺但没有的任何数据
- 记录你们没有准备好的问题
- 与任何看起来不满意的董事安排后续会议

下一次董事会准备现在就开始。
