# 故事板创建

通过 [inference.sh](https://inference.sh) CLI 使用 AI 图像生成创建视觉故事板。

## 快速入门

> 需要 inference.sh CLI (`belt`)。[安装说明](https://raw.githubusercontent.com/inference-sh/skills/refs/heads/main/cli-install.md)

```bash
belt login

# 生成故事板面板
belt app run falai/flux-dev-lora --input '{
  "prompt": "故事板面板，现代城市天际线的宽景，日落时分，电影化构图，略微去饱和的色彩，电影剧照风格，16:9 的宽高比",
  "width": 1248,
  "height": 832
}'

# 将面板拼接成故事板
belt app run infsh/stitch-images --input '{
  "images": ["panel1.png", "panel2.png", "panel3.png"],
  "direction": "horizontal"
}'
```

## 拍摄类型

| 缩写 | 名称 | 拍摄构图 | 使用场景 |
|-------------|------|---------|-------------|
| **ECU** | 极特写 | 仅眼睛，细节 | 强烈情感，揭示细节 |
| **CU** | 特写 | 脸部充满画面 | 情感，反应，对话 |
| **MCU** | 中特写 | 头部和肩膀 | 采访，对话 |
| **MS** | 中景 | 腰部以上 | 一般对话，动作 |
| **MLS** | 中长景 | 膝盖以上 | 行走，随意互动 |
| **LS** | 长景 | 全身 | 角色在环境中 |
| **WS** | 宽景 | 环境主导 | 建立地点，规模 |
| **EWS** | 极宽景 | 广阔景观 | 史诗范围，孤立，过渡 |

### 生成每种拍摄类型

```bash
# 特写 — 情感聚焦
belt app run falai/flux-dev-lora --input '{
  "prompt": "特写镜头，一位女性脸部表现出担忧，左侧柔和戏剧性光线，浅景深，电影化剧照，略微去饱和",
  "width": 1248,
  "height": 832
}'

# 中景 — 对话场景
belt app run falai/flux-dev-lora --input '{
  "prompt": "中景，两个人在咖啡馆桌旁交谈，温暖的午后阳光透过窗户，自然构图，电影化剧照，35mm 镜头效果",
  "width": 1248,
  "height": 832
}'

# 宽景 — 建立场景
belt app run falai/flux-dev-lora --input '{
  "prompt": "未来派实验室内部的宽景建立镜头，戏剧性顶光，长走廊带玻璃墙，科幻氛围，电影化构图，柱状透镜风格",
  "width": 1248,
  "height": 832
}'
```

## 摄影机角度

| 角度 | 效果 | 使用场景 |
|-------|--------|-------------|
| **水平视角** | 中性，自然 | 大多数场景的默认设置 |
| **高角度** | 主体看起来渺小，脆弱 | 显示弱点，全景 |
| **低角度** | 主体看起来强大，主导 | 权威，英雄主义，威胁 |
| **鸟瞰视角** | 神一般的全景 | 地图，建立地理 |
| **虫眼视角** | 极端力量，敬畏 | 建筑，高耸的人物 |
| **倾斜角度** | 焦躁，迷失方向 | 紧张，疯狂，动作 |
| **过肩镜头 (OTS)** | 观众与角色位置一致 | 对话，第一人称视角 |

## 摄影机运动

| 运动 | 描述 | 情感 |
|----------|-------------|---------|
| **摇摄** | 摄影机水平旋转（三脚架） | 扫描，跟随，揭示 |
| **俯仰** | 摄影机垂直旋转（三脚架） | 揭示高度，力量 |
| **推镜头** | 摄影机向/远离主体移动 | 亲密（入），距离（出） |
| **横移** | 摄影机横向移动 | 沿边跟随，揭示 |
| **起重机/桅杆** | 摄影机垂直上下移动 | 宏伟揭示，过渡 |
| **变焦** | 镜头焦距变化（摄影机保持不动） | 聚焦转换，戏剧性强调 |
| **稳定器/云台** | 平滑手持跟踪 | 沉浸，跟随动作 |
| **手持** | 故意摄影机抖动 | 紧迫，纪录片感，混乱 |
| **固定** | 摄影机不移动 | 稳定性，观察，紧张 |

在故事板中，用画在面板上的箭头表示运动。

## 连续性规则

### 180 度规则

想象两个对话角色之间的线（轴线）。摄影机必须保持在这一侧的任何一边。

```
         角色 A        角色 B
              ●─────────────────●
             /                   \
           /     摄影机区域      \
         /     (保持在这一侧)  \
       📷          📷          📷
     摄影机 1   摄影机 2   摄影机 3
```

**跨越这条线**会使观众对空间关系感到困惑。只有有意跨越（在中间使用中性镜头或可见的摄影机移动）。

### 动作匹配

当在两个相同动作的角度之间切换时，动作必须无缝衔接：

```
面板 A: 手伸向门把手（中景）
面板 B: 手抓住门把手（特写）
         ↑ 动作从同一点继续
```

### 眼线匹配

当角色看着某物时，下一镜头应显示他们看到的物体，从他们的大致视点拍摄。

```
面板 A: 角色向上看并向右看
面板 B: 他们看到的物体，从略微左下方的视角拍摄
```

### 屏幕方向

如果角色在一镜头中从左到右移动，他们在下一镜头中应继续从左到右移动。反转方向意味着他们转过了身。

## 面板布局

### 标准格式

| 布局 | 面板数量 | 使用场景 |
|--------|--------|---------|
| 2x3 (6 个面板) | 每页 6 个 | 详细场景，对话 |
| 3x3 (9 个面板) | 每页 9 个 | 动作序列，蒙太奇 |
| 2x2 (4 个面板) | 每页 4 个 | 关键时刻，演示 |
| 单个 | 每页 1 个 | 英雄镜头，关键时刻 |

### 面板注释格式

每个面板应包括：

```
┌────────────────────────────────────┐
│ 场景 3 — 拍摄 2                   │ ← 场景和拍摄编号
│                                    │
│   [此处为生成的图像]               │ ← 视觉
│                                    │
├────────────────────────────────────┤
│ 拍摄：中景，水平视角                │ ← 拍摄类型和角度
│ 运动：缓慢推镜头入                │ ← 摄影机运动
│ 持续时间：4 秒                    │ ← 预计持续时间
│ 动作：Sarah 打开信件             │ ← 发生了什么
│ 对话："这改变了所有事情"            │ ← 任何说过的台词
│ 音效：纸张沙沙声，时钟滴答声       │ ← 音效
│ 音乐：紧张感增强                  │ ← 音乐提示
└────────────────────────────────────┘
```

## 故事板工作流程

### 第 1 步：拍摄列表

在生成图像之前，编写拍摄列表：

```
场景 1 — 办公室，白天

1.1  WS  - 办公楼外部的建立镜头，早晨
1.2  MS  - Sarah 走过办公室，拿着咖啡
1.3  CU  - Sarah 的脸部，注意到桌子上有东西
1.4  ECU - 桌上的信封，陌生的笔迹
1.5  MS  - Sarah 拿起信封，打开它
1.6  CU  - Sarah 的眼睛睁大，因为她在阅读
1.7  ECU - 信上的关键短语（插入文本）
```

### 第 2 步：生成面板

在所有面板上使用一致的风格：

```bash
# 建立一致的风格提示后缀
STYLE="电影化剧照，略微去饱和，温暖色调，35mm 镜头，浅景深"

# 面板 1.1 — 宽景
belt app run falai/flux-dev-lora --input "{
  \"prompt\": \"宽镜头，现代玻璃办公楼外，早晨的黄金时刻光线，人们进入，$STYLE\",
  \"width\": 1248, \"height\": 832
}" --no-wait

# 面板 1.2 — 中景
belt app run falai/flux-dev-lora --input "{
  \"prompt\": \"中景，一位职业女性走过现代开放式办公室，拿着咖啡杯，午后的阳光透过窗户，$STYLE\",
  \"width\": 1248, \"height\": 832
}" --no-wait

# 面板 1.3 — 特写
belt app run falai/flux-dev-lora --input "{
  \"prompt\": \"特写，一位女性脸部向下看着桌子，表情好奇，柔和的办公室灯光，$STYLE\",
  \"width\": 1248, \"height\": 832
}" --no-wait
```

### 第 3 步：组装故事板

```bash
# 将面板拼接成行
belt app run infsh/stitch-images --input '{
  "images": ["panel_1_1.png", "panel_1_2.png", "panel_1_3.png"],
  "direction": "horizontal"
}'

belt app run infsh/stitch-images --input '{
  "images": ["panel_1_4.png", "panel_1_5.png", "panel_1_6.png"],
  "direction": "horizontal"
}'

# 然后垂直拼接行以获得完整页面
belt app run infsh/stitch-images --input '{
  "images": ["row1.png", "row2.png"],
  "direction": "vertical"
}'
```

## 风格一致性提示

- 在所有面板上使用**相同的风格后缀**（镜头，色调，灯光）
- 如果需要跨面板保持一致的角色，使用 **FLUX LoRA**
- 保持所有面板的**相同宽高比**
- 生成**比需要更多的面板**，并选择最佳的一个
- 如果面板风格不匹配，使用调整提示重新生成

## 常见错误

| 错误 | 问题 | 修复 |
|---------|---------|-----|
| 跨越 180 度线 | 使空间关系混乱 | 保持在一侧或使用中性镜头 |
| 所有相同拍摄类型 | 视觉上单调，没有节奏 | 在 CU，MS，WS 之间变化 |
| 没有建立镜头 | 观众不知道他们在哪里 | 从 WS 或 EWS 开始场景 |
| 每个场景太多拍摄 | 节奏拖慢 | 每个场景 5-8 个拍摄是典型的 |
| 面板之间风格不一致 | 看起来像不同的项目 | 使用相同的风格提示后缀 |
| 缺少注释 | 面板含义不明确 | 始终注明拍摄类型，运动，动作 |
