# repo-intake-and-plan

将本文件用作 Rigor Intake 助手。已安装的标识符（slug）保持
`repo-intake-and-plan` 不变，以确保兼容性。

## 何时应用

- README 优先的复现工作开始时。
- 主技能需要快速了解仓库结构及文档化的命令时。
- 推理、评估和训练候选内容需要谨慎分类时。
- 用户明确希望先检查仓库，尚未执行任何操作时。

## 何时不应用

- 执行已经开始，当前任务涉及运行命令或编写输出时。
- 目标并非基于仓库的复现任务时。
- 用户仅需论文解读而无需检查仓库时。
- 用户已有选定的文档化命令，仅需设置或执行时。

## 明确边界

- 本技能用于扫描与规划。
- 本技能属于辅助层级，通常应由编排器调用。
- 本技能不安装环境。
- 本技能不准备大型资源。
- 本技能不执行实质性的复现命令。
- 本技能不做高风险补丁决策。

## 输入期望

- 目标仓库路径。
- 如存在，可访问 README 和常见项目文件。
- 用户关于期望优先级的可选提示，如以推理为先。

## 输出期望

- 简洁的仓库结构摘要
- 文档化命令清单
- 推断出的候选类别：推理、评估、训练、其他
- 最低可信度的复现建议
- 显著的歧义或风险清单

## 备注

使用 `references/repo-scan-rules.md` 以及 `scripts/` 下的辅助脚本。
