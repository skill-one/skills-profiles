# paper-context-resolver

作为 Rigor Paper Context 的辅助工具使用。已安装的标识符保持 `paper-context-resolver` 以确保兼容性。

## 何时适用

- README 和仓库文件存在影响复现的关键缺口。
- 该缺口涉及数据集版本、划分、预处理、评估协议、检查点映射或运行假设。
- 主技能需要的是狭义的佐证补充，而非完整的论文摘要。
- 已存在需要回答的具体复现问题。

## 何时不适用

- README 已提供足够的复现细节。
- 用户需要的是通用论文解释，而非复现支持。
- 目标是在未记录冲突的情况下覆盖 README 的指令。
- 可用的唯一输入仅是论文标题，且尚未存在具体的复现缺口。

## 明确边界

- 本技能为可选。
- 本技能属于辅助层级，通常应由编排器调用。
- 本技能补充以 README 为主的复现流程。
- 本技能不替代主编排流程。
- 本技能默认不整篇总结论文。

## 输入期望

- 目标仓库元数据
- 复现关键问题
- 现有 README 或仓库证据
- 任何已知的论文链接

## 输出期望

- 缩小的来源列表
- 仅限与复现相关的答案
- 如适用，需明确说明 README 与论文的冲突
- 清晰区分直接证据与推断
