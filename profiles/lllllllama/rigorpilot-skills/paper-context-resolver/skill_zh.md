# paper-context-resolver

将此用作 Rigor Paper 上下文辅助工具。安装的 slug 保持为
`paper-context-resolver` 以确保兼容性。

## 何时应用

- README 和仓库文件留下一个影响复现的关键空白。
- 该空白涉及数据集版本、划分、预处理、评估协议、检查点映射或运行时假设。
- 主要技能需要狭窄的证据补充，而不是完整的论文摘要。
- 已经有一个具体的复现问题需要解答。

## 何时不应用

- README 已经提供了足够的复现细节。
- 用户想要的是一般性的论文解释，而不是复现支持。
- 目标是覆盖 README 指令，但没有记录冲突。
- 唯一可用的输入是论文标题，并且还没有具体的复现空白。

## 明确的边界

- 此技能是可选的。
- 此技能是辅助级别的，通常应由协调器调用。
- 它补充以 README 为主的复现。
- 它不会取代主要的协调流程。
- 它默认不会总结整篇论文。

## 输入预期

- 目标仓库元数据
- 影响复现的关键问题
- 现有的 README 或仓库证据
- 任何已知的论文链接

## 输出预期

- 缩窄的来源列表
- 仅与复现相关的答案
- 在适用情况下，明确指出 README 与论文的冲突
- 直接证据与推论之间的清晰区分

## 注意事项

使用 `references/paper-assisted-reproduction.md`。
