# 在运行中的应用上迁移模式 / 数据

## 工作流程

1. 首先将新字段设为可选（这样部署就不会拒绝现有行）。

3. 运行迁移；验证所有行都有效。
4. 回填完成后，收紧验证器（将字段设为必填）。

## 规则

- 在回填完成前，永远不要收紧验证器——它会拒绝现有行并破坏运行中的应用。
