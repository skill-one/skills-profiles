# CCF 反驳撰写器

## 家庭文件合同

撰写前，确定每个任务/成果的规范输出和一个稳定的作业目录。复用明确的或已建立的路径；否则使用项目根目录 `ccfa-workfiles/<用途>/<成果ID>/`，仅在需要时使用 `source/`、`assets/`、`cache/` 和 `build/`。就地更新当前文件；不要分散中间文件或创建迭代副本。保留输入和所需证据；仅清理由本任务创建的已验证的可丢弃文件。使用 UTF-8 文本 I/O，并在保存或渲染后检查中文文本。对于文件工作，应用 [成果合同.md](../ccf-common/references/artifact-contracts.md) 并在技能转换时复用相同的路径。

## 协作合同

在专家执行前，先阅读并应用 [ccf-humanization](../ccf-humanization/SKILL.md)，然后应用 [ccf-common](../ccf-common/SKILL.md)。在每次交接时，复用适用的活跃规则或刷新缺失/变更的规则。即使没有文字，两个预检也是必需的；详细的编辑、实验和维护模式仅在相关时运行。

保留一个集成负责人，并积极使用其他技能来解决缺失的先决条件或检查材料发现。复用适用的证据；不要跳过必要的准备工作以节省代币。在最终确定前，集成贡献并验证受影响的成果。遵循条件性 [合作路线](../ccf-common/references/routing.md)；避免无关的阶段和重复报告。

## 核心规则

处理评审后沟通和修订责任。回复必须冷静、基于事实、有证据支持，并仅承诺可行的变更。重新提交的适应性默认保守：除非用户明确授权，否则不进行新实验和书目变更。遵循用户请求的回复格式：纯文本、TeX、逐评审员、按问题分组、表优先或简短回复。

## 模式

- `rebuttal`：在字数或时间预算内，评审员/AC 的回复。
- `revision-ledger`：评审员评论 -> 行动 -> 手稿位置 -> 负责人 -> 状态。
- `response-letter`：修订摘要或相机就绪的回复信。
- `resubmission`：使用保守默认值，将已撰写的论文适应到新会议。

## 工作流程

1. 确定会议、回复格式、字数预算、截止日期、评审分数/信心，以及这是反驳、修订还是重新提交。
2. 按评审员、关注类型、严重程度、可用证据、回复策略和承诺的论文变更，将评论解析为问题组。
3. 对于实质性回复，加载 `references/response-strategy.md` 并应用 `../ccf-paper-writer/references/prose-quality-guardrails.md`；首先回答实际的高影响问题：正确性、新颖性、缺失证据、错误假设和共同关注。
4. 每当需要跟踪承诺的编辑、手稿位置、重新提交行动、评审轮次或跨版本分数变更时，加载 `references/revision-ledger.md`。就地更新一个规范账本；除非用户请求快照，否则不要为每轮创建单独的账本。
5. 对于完整反驳，加载 `references/tex-templates.md`，并在需要时使用 `assets/templates/` 中的 TeX 模板。
6. 对于重新提交，通过 `ccf-submission-checker` 将旧评审员关注映射到新会议的约束；不要默默添加实验或书目变更。
7. 通过其负责人完成必要的贡献：论文撰写器用于请求的修订、实验设计者用于授权的证据工作，以及提交检查器用于适用的会议/包规则。使用完整性审计员解决未解决的声明/结果冲突，并使用评审员处理未解决的后果性批评。在回复中声明完成前，集成返回的证据并验证实际变更；计划的实验或承诺的编辑保持计划状态。

## 自适应输出合同

首先放置请求的回复成果。对于 "撰写反驳"，首先输出反驳文本或 TeX。对于 "制作账本"，首先输出账本。使用以下完整结构进行标准多评审员回复规划，或当用户请求策略加草稿时：

```text
模式：
会议和约束：
问题表：
回复策略：
草稿回复或回复文件：
承诺的论文变更：
修订账本：
重新提交适应性说明：
声明/承诺要避免的：
下一轮 CCFA 负责人：
清单状态：
```

## 授权回复工作

遵循 `../ccf-common/references/handoff-modes.md` 和 `../ccf-common/references/task-modes.md`。请求的回复加修订授权通过其负责人交付两个成果。合并重复评论时保留评审员归属和回答覆盖范围。区分提供的成果、计划的实验、承诺的修订和完成的编辑；在声明编辑已做出前验证其位置。保留字数预算，并针对实际关注点回复，不要无谓的道歉、想象的反对或防御性重复。简洁的事实澄清不是科学让步。回复起草不授权发布或提交。
