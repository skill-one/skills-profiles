# 优化动画性能

解决动画性能问题。

## 如何使用

- `/优化动画性能`
  将这些约束应用于此对话中的任何 UI 动画工作。

- `/优化动画性能 <文件>`
  根据以下所有规则审查文件，并报告：
  - 违规行为（引用确切的行或代码片段）
  - 原因（一句话简述）
  - 具体修复方案（代码级建议）

除非明确要求，否则不要迁移动画库。在现有技术栈中应用规则。

## 适用场景

参考这些指南，当：
- 添加或更改 UI 动画（CSS、WAAPI、Motion、rAF、GSAP）
- 重构卡顿的交互或过渡效果
- 实现滚动关联动画或滚动显示动画
- 动画布局、过滤器、遮罩、渐变或 CSS 变量
- 审查使用 will-change、变换或测量的组件

## 渲染步骤术语表

- 合成：变换、不透明度
- 绘制：颜色、边框、渐变、遮罩、图像、滤镜
- 布局：大小、位置、流、网格、弹性布局

## 按优先级分类的规则类别

| 优先级 | 类别 | 影响 |
|--------|------|------|
| 1 | 绝对禁止的模式 | 关键 |
| 2 | 选择机制 | 关键 |
| 3 | 测量 | 高 |
| 4 | 滚动 | 高 |
| 5 | 绘制 | 中高 |
| 6 | 图层 | 中 |
| 7 | 模糊和滤镜 | 中 |
| 8 | 视图过渡 | 低 |
| 9 | 工具边界 | 关键 |

## 快速参考

### 1. 绝对禁止的模式（关键）

- 不要在同一帧中交错布局读取和写入
- 不要在大型或重要的表面上连续动画化布局
- 不要从 scrollTop、scrollY 或滚动事件驱动动画
- 没有停止条件的 requestAnimationFrame 循环
- 不要混合多个动画系统，每个系统都会测量或突变布局

### 2. 选择机制（关键）

- 默认使用变换和不透明度进行动画
- 仅当交互需要时才使用 JS 驱动的动画
- 绘制或布局动画仅在小型、隔离的表面上可接受
- 一次性效果比连续动画更常见
- 优先降级技术而不是完全移除动画

### 3. 测量（高）

- 一次性测量，然后通过变换或不透明度动画化
- 在写入之前批量所有 DOM 读取
- 在动画期间不要重复读取布局
- 优先使用 FLIP 风格的过渡效果进行布局类效果
- 优先使用批量测量和写入的方法

### 4. 滚动（高）

- 当可用时，优先使用滚动或视图时间线进行滚动关联动画
- 使用 IntersectionObserver 进行可见性和暂停
- 不要轮询滚动位置进行动画
- 当离屏时暂停或停止动画
- 滚动关联动画不得在大型表面上触发连续布局或绘制

### 5. 绘制（中高）

- 仅在小型、隔离的元素上允许绘制触发动画
- 不要在大型容器上动画化绘制密集的属性
- 不要动画化用于变换、不透明度或位置的 CSS 变量
- 不要动画化继承的 CSS 变量
- 在本地作用域动画化 CSS 变量并避免继承

### 6. 图层（中）

- 合成器动画需要图层提升，永远不要假设
- 临时和外科手术式使用 will-change
- 避免许多或大型提升的图层
- 当性能重要时，使用工具验证图层行为

### 7. 模糊和滤镜（中）

- 保持模糊动画较小（<=8px）
- 仅用于短时一次性效果使用模糊
- 不要连续动画化模糊
- 不要在大型表面上动画化模糊
- 优先使用不透明度和平移而不是模糊

### 8. 视图过渡（低）

- 仅用于导航级更改使用视图过渡
- 避免用于交互密集的 UI 的视图过渡
- 当需要中断或取消时避免视图过渡
- 将大小变化视为潜在的布局触发

### 9. 工具边界（关键）

- 除非明确要求，否则不要迁移或重写动画库
- 在现有的动画系统中应用这些规则
- 永远不要部分迁移 API 或在同一组件中混合样式

## 常见修复方案

```css
/* 布局抖动：用 transform 代替 width 动画 */
/* 之前 */ .panel { transition: width 0.3s; }
/* 之后 */  .panel { transition: transform 0.3s; }

/* 滚动关联：用 scroll-timeline 代替 JS */
/* 之前 */ window.addEventListener('scroll', () => el.style.opacity = scrollY / 500)
/* 之后 */  .reveal { animation: fade-in linear; animation-timeline: view(); }
```

```js
// 测量：在写入前批量读取（FLIP）
// 之前 — 布局抖动
el.style.left = el.getBoundingClientRect().left + 10 + 'px';
// 之后 — 一次性测量，通过 transform 动画
const first = el.getBoundingClientRect();
el.classList.add('moved');
const last = el.getBoundingClientRect();
el.style.transform = `translateX(${first.left - last.left}px)`;
requestAnimationFrame(() => { el.style.transition = 'transform 0.3s'; el.style.transform = ''; });
```

## 审查指南

- 首先执行关键规则（绝对禁止的模式、工具边界）
- 选择与意图匹配的最小成本渲染工作
- 对于任何非默认选择，说明证明它的约束（表面大小、持续时间或交互要求）
- 审查时，优先考虑可操作的注释和具体替代方案而不是理论
