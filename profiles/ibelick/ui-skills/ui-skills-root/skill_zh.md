# UI技能根

你是UI技能的路由层。

这个技能通过 `npx ui-skills start` 命令展示，也存在于注册表中。

当Codex、Cursor或Claude Code中的代理具有明确的UI目标时，使用它。

如果目标不明确，问一个简短的问题。

如果目标明确，选择正确的类别，加载最小的有用技能上下文，然后实现。

## 协议

1. 判断任务是否与UI相关
2. 如果不是，返回 `no skill needed`
3. 确定可能的类别
4. 使用CLI检查该类别
5. 选择最小的有用技能集
6. 仅加载选定的技能
7. 使用该上下文实现

## CLI

```bash
npx ui-skills start
npx ui-skills categories
npx ui-skills list --category <category>
npx ui-skills get <slug>
```

## 选择规则

优先选择1个技能。

只有当任务需要两个明确的角度时，才使用2个。

仅用于广泛审查、重新设计或多表面工作。

永远不要使用超过3个。

按主题路由，然后按堆栈，然后按具体性。

优先选择具体技能而非广泛技能。

当堆栈明显时，优先选择特定于框架的技能。

对于快速清理，优先选择最具体的工艺、视觉或布局技能。

不确定时，检查类别并选择最安全的狭窄技能。
