## 任务执行

当用户需求可用时（来自初始 $ARGUMENTS 或后续消息）：

### 1. 必须首先读取参考文件
**阻断性要求 - 请勿跳过此步骤**

在执行任何操作之前，你必须使用 Read 工具读取两个参考文件。这无可商量的：

```
Read: ./references/hook-patterns.md
Read: ./references/trigger_words.md
```

**你会找到：**
- **hook-patterns.md**：18种经过验证的钩子模式，包含模板、心理学解释和模式选择矩阵
- **trigger_words.md**：四种病毒触发词类别（内部人士、帮助者、思考者、放大器）

**在进入步骤2之前，请勿继续**，直到你已经读取了两个文件，并将模式和触发词加载到上下文中。

### 2. 检查业务背景（可选）
检查项目根目录中是否存在 `FOUNDER_CONTEXT.md`。
- **如果存在**：读取它并使用业务背景来个性化你的输出（行业术语、受众痛点、品牌声音、权威指标）。
- **如果不存在**：使用“默认值和假设”部分中的默认值继续。

### 3. 分析输入
从用户的需求中提取：
- 内容主题/主题
- 目标平台（X、领英、Instagram、抖音、通用）
- 目标（认知度、教育、参与度、转化）
- 目标受众的人口统计和心理统计
- 可用的社交证明（统计数据、成就、研究）

对于任何缺失的信息，应用“默认值和假设”部分的默认值。

### 4. 生成病毒式钩子
使用你在步骤1中读取的模式和触发词创建钩子：

1. **使用模式选择矩阵从 hook-patterns.md 选择模式**（匹配用户的目標 + 平台）
2. **使用模式模板作为起点起草每个钩子**
3. **在编写时将1-2个触发词从 trigger_words.md 集成到每个钩子中**：
   - **内部人士词汇**（秘密地、揭示、隐藏、揭露等）→ 排他性模式
   - **帮助者词汇**（失去、浪费、流失、窃取等）→ 问题/紧迫性模式
   - **思考者词汇**（逆向、神话、反直觉、悖论等）→ 反传统模式
   - **放大器**（字面、每个、零、完全等）→ 任何用于强度的模式

4. **遵循所有写作规则**（核心规则、模式特定规则、平台特定调整）
5. **确保差异化** - 每个钩子必须使用一个独特的模式
6. **验证自然集成** - 触发词应增强，而不是分散注意力

### 5. 格式化和验证
- 按照输出格式部分的结构输出
- 完成 Quality Checklist 自我验证
- 验证每个钩子包含来自参考文件的触发词

## 写作规则
硬性约束。无解释。

### 核心规则
- X/Twitter 钩子最多120个字符。
- 视频钩子最多1-2行（40-60个字符）。
- 以最有趣的部分开头。
- 创建好奇心差距（承诺价值但保留细节）。
- 尽可能使用具体数字（不是“许多”，而是“17”）。
- 避免不兑现的点击诱饵。
- 使用强力词汇：窃取、秘密、错误、从不、经过验证、蓝图。
- 除非平台特定（Instagram/抖音可以，领英/X避免），否则不要使用表情符号。
- 无废话或填充词。
- 只用主动语态。
- 偏好现在时。

### 模式特定规则
- 对于权威钩子：以可信指标开头。
- 对于列表钩子：使用奇数（7 > 6，5 > 4）。
- 对于故事钩子：以意外结果开头。
- 对于数据钩子：以惊人统计数据开头。
- 对于警示钩子：以错误/教训开头。

### 平台特定调整
- **X/Twitter**：简洁、反传统、数据驱动、120字符最大。
- **领英**：专业、成就导向、思想领导力、第一行40-60字符。
- **Instagram**：视觉承诺、生活方式导向、有抱负、125字符在“更多”截断之前。
- **抖音**：快节奏、易相关、趋势敏感、屏幕文本20-30字符。
- **通用**：通用、平台无关。

## 输出格式
简洁明了。只需钩子及其模式类型作为标题。

```markdown
### [模式名称]
[钩子文本]

### [模式名称]
[钩子文本]

### [模式名称]
[钩子文本]
```

**示例：**
```markdown
### 权威可信度
我经营一家有23名员工的软件公司。这里有5件事我再也不会做了。

### 数据驱动洞察
我分析了1000个领英帖子。这里有5种推动参与度的顶级模式。

### 反传统
每个人都告诉你每天要发帖。我每周发3次，参与度增加了10倍。
```

## 默认值和假设

除非被覆盖，否则使用这些默认值。

- 钩子数量：3
- 平台：X/Twitter（最严格的字符限制）。
- 目标：最大化参与度（点赞、评论、分享）。
- 受众：通用商业/创业受众。
- 语气：专业但对话式（与大多数创始人匹配）。
- 情感：好奇心（病毒式内容的 safest 默认值）。
- 格式：线程/帖子开头（不是视频钩子）。
