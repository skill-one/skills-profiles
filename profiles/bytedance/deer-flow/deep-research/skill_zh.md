# 深度研究技能

## 概述

此技能为进行彻底的网络研究提供了系统化的方法论。**在开始任何内容生成任务之前加载此技能**，以确保从多个角度、深度和来源收集足够的信息。

## 何时使用此技能

**始终在以下情况下加载此技能：**

### 研究问题
- 用户询问“什么是X”、“解释X”、“研究X”、“调查X”
- 用户希望深入理解某个概念、技术或主题
- 问题需要来自多个来源的当前、全面信息
- 单次网络搜索不足以正确回答

### 内容生成（预研究）
- 创建演示文稿（PPT/幻灯片）
- 创建前端设计或UI原型
- 撰写文章、报告或文档
- 制作视频或多媒体内容
- 任何需要真实世界信息、示例或当前数据的内容

## 核心原则

**切勿仅凭一般知识生成内容。** 您输出的质量直接取决于事先进行的研究的质量和数量。单个搜索查询绝对不够。

## 研究方法论

### 第一阶段：广泛探索

从广泛搜索开始，以了解整体格局：

1. **初步调查**：搜索主要主题，以了解整体背景
2. **识别维度**：从初步结果中，识别需要深入探索的关键子主题、主题、角度或方面
3. **绘制领域地图**：记录存在的不同视角、利益相关者或观点

示例：
```
主题："医疗保健中的AI"
初步搜索：
- "2024年AI医疗保健应用"
- "人工智能医学诊断"
- "医疗保健AI市场趋势"

识别的维度：
- 诊断AI（放射学、病理学）
- 治疗推荐系统
- 行政自动化
- 患者监测
- 监管环境
- 伦理考量
```

### 第二阶段：深入挖掘

针对每个识别的重要维度进行有针对性的研究：

1. **具体查询**：使用精确的关键词搜索每个子主题
2. **多种表述**：尝试不同的关键词组合和表述方式
3. **获取完整内容**：使用`web_fetch`完整阅读重要来源，而不仅仅是片段
4. **追踪参考文献**：当来源提到其他重要资源时，搜索这些资源

示例：
```
维度："放射学中的诊断AI"
目标搜索：
- "FDA批准的AI放射学系统"
- "胸部X光AI检测准确率"
- "放射学AI临床试验结果"

然后获取并阅读：
- 关键研究论文或摘要
- 行业报告
- 真实案例研究
```

### 第三阶段：多样性与验证

通过寻求不同类型的信息来确保全面覆盖：

| 信息类型 | 目的 | 示例搜索 |
|----------|------|----------|
| **事实与数据** | 具体证据 | "统计数据"、"数据"、"数字"、"市场规模" |
| **示例与案例** | 真实世界应用 | "案例研究"、"示例"、"实施" |
| **专家观点** | 权威视角 | "专家分析"、"访谈"、"评论" |
| **趋势与预测** | 未来方向 | "2024年趋势"、"预测"、"未来" |
| **比较** | 上下文和替代方案 | "vs"、"比较"、"替代方案" |
| **挑战与批评** | 平衡观点 | "挑战"、"局限性"、"批评" |

### 第四阶段：综合检查

在进行内容生成之前，验证：

- [ ] 我是否从至少3-5个不同角度进行了搜索？
- [ ] 我是否获取并完整阅读了最重要的来源？
- [ ] 我是否拥有具体的数据、示例和专家观点？
- [ ] 我是否探索了正面方面和挑战/局限性？
- [ ] 我的信息是否当前且来自权威来源？

**如果任何答案是否定的，则在生成内容之前继续研究。**

## 搜索策略技巧

### 有效的查询模式

```
# 对上下文进行具体化
❌ "AI趋势"
✅ "2024年企业AI采用趋势"

# 包含权威来源暗示
"[主题]研究论文"
"[主题]麦肯锡报告"
"[主题]行业分析"

# 搜索特定内容类型
"[主题]案例研究"
"[主题]统计数据"
"[主题]专家访谈"

# 使用时间限定词 —— 始终使用从<current_date>获取的实际当前年份
"[主题]2026"   # ← 用实际当前年份替换，切勿硬编码过去年份
"[主题]最新"
"[主题]近期发展"
```

### 时间意识

**在形成任何搜索查询之前，始终检查上下文中的`<current_date>`。**

`<current_date>`为您提供完整日期：年、月、日和星期几（例如`2026-02-28, Saturday`）。根据用户询问的内容，使用适当的时间精度：

| 用户意图 | 需要的时间精度 | 示例查询 |
|---|---|---|
| "今天 / 今早 / 刚发布" | **月 + 日** | `"科技新闻 2026年2月28日"` |
| "本周" | **周范围** | `"本周科技发布 2026年2月24日"` |
| "最近 / 最新 / 新" | **月** | `"AI突破 2026年2月"` |
| "今年 / 趋势" | **年** | `"软件趋势 2026"` |

**规则：**
- 当用户询问“今天”或“刚发布”时，在搜索查询中使用**月 + 日 + 年**以获取当日结果
- 当需要日级精度时，切勿降级到仅年级 —— `"科技新闻 2026"`将不会显示今日新闻
- 尝试多种表述：数字形式（`2026-02-28`）、书面形式（`February 28 2026`）和相对术语（`今天`、`本周`）在不同查询中使用

❌ 用户询问“今天科技有何新动态” → 搜索`"新科技 2026"` → 错过今日新闻
✅ 用户询问“今天科技有何新动态” → 搜索`"新科技 2026年2月28日"` + `"今日科技新闻 2月28日"` → 获取今日结果

### 何时使用web_fetch

在以下情况下使用`web_fetch`阅读完整内容：
- 搜索结果看起来高度相关且权威
- 需要超出片段的详细信息
- 来源包含数据、案例研究或专家分析
- 想要了解某个发现的完整背景

### 迭代优化

研究是迭代的。初步搜索后：
1. 回顾所学内容
2. 识别理解上的差距
3. 制定新的、更有针对性的查询
4. 重复直到获得全面覆盖

## 质量标准

当您能够自信地回答以下问题时，您的研究就足够了：
- 关键事实和数据点是什么？
- 有哪些2-3个具体的真实世界示例？
- 专家对此主题有何看法？
- 当前趋势和未来方向是什么？
- 有哪些挑战或局限性？
- 为什么这个主题现在相关或重要？

## 常见错误避免

- ❌ 仅在1-2次搜索后停止
- ❌ 依赖搜索片段而不阅读完整来源
- ❌ 仅搜索多方面主题的一个方面
- ❌ 忽略相互矛盾的观点或挑战
- ❌ 存在当前数据时使用过时信息
- ❌ 在研究完成前开始内容生成

## 输出

完成研究后，您应该拥有：
1. 从多个角度对主题的全面理解
2. 具体的数据点、统计数据和事实
3. 真实世界示例和案例研究
4. 专家观点和权威来源
5. 当前趋势和相关背景

**然后才能进行内容生成**，使用收集到的信息创建高质量、信息丰富的内容。
