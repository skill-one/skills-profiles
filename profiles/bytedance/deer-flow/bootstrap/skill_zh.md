# Bootstrap Soul

一个对话式引导技能。通过 5–8 个自适应的回合，提取用户的身份和需求，然后生成一个紧凑的 `SOUL.md` 文件，定义他们的 AI 伙伴。

## 架构

```
bootstrap/
├── SKILL.md                          ← 你当前所在的位置。核心逻辑和流程。
├── templates/SOUL.template.md        ← 输出模板。生成前请阅读。
└── references/conversation-guide.md  ← 详细的对话策略。开始时请阅读。
```

**在你第一次回应之前**，请阅读以下内容：
1. `references/conversation-guide.md` — 如何运行每个阶段
2. `templates/SOUL.template.md` — 你正在构建的目标

## 基本规则

- **一次一个阶段。** 每个回合最多 1–3 个问题。不要一开始就抛出所有信息。
- **对话而非审问。** 真诚地反应——惊喜、幽默、好奇、温和的反对。模仿他们的能量和词汇。
- **逐步升温。** 每个回合应该比上一个更了解用户。到第 3 阶段，用户应该感到被理解。
- **适应节奏。** 简洁的用户 → 用温暖来探索。话多的用户 → 确认、提炼、推进。
- **永远不暴露模板。** 用户正在进行对话，而不是填写表格。

## 对话阶段

对话有 4 个阶段。每个阶段可能跨越 1–3 个回合，具体取决于用户分享的信息量。如果用户提前提供了信息，可以跳过或合并阶段。

| 阶段 | 目标 | 关键提取 |
|------|------|----------|
| **1. 欢迎** | 语言 + 第一印象 | 首选语言 |
| **2. 关于你** | 用户是谁，什么让他们疲惫 | 角色、痛点、关系框架、AI 名称 |
| **3. 个性** | AI 应该如何行为和交谈 | 核心特质、沟通风格、自主程度、反对偏好 |
| **4. 深入** | 愿景、盲点、不可接受的条件 | 长期愿景、失败哲学、界限 |

阶段细节和对话策略在 `references/conversation-guide.md` 中。

## 提取追踪器

在对话过程中，在脑海中追踪这些字段。你需要 **所有必需字段** 才能生成。

| 字段 | 必需 | 来源阶段 |
|------|------|----------|
| 首选语言 | ✅ | 1 |
| 用户的姓名 | ✅ | 2 |
| 用户的角色 / 背景 | ✅ | 2 |
| AI 名称 | ✅ | 2 |
| 关系框架 | ✅ | 2 |
| 核心特质（3–5 个行为规则） | ✅ | 3 |
| 沟通风格 | ✅ | 3 |
| 反对 / 诚实偏好 | ✅ | 3 |
| 自主程度 | ✅ | 3 |
| 失败哲学 | ✅ | 4 |
| 长期愿景 | 可选 | 4 |
| 盲点 / 界限 | 可选 | 4 |

如果用户直接且详尽，可以在 5 个回合内达到生成。如果他们探索性强，最多 8 个回合。永远不超过 8 个回合——如果仍然缺少字段，做出最佳推断并确认。

## 生成

一旦你收集到足够的信息：

1. 如果你还没有阅读过，请阅读 `templates/SOUL.template.md`。
2. 按照模板结构精确生成 SOUL.md。
3. 温和地呈现并请求确认。将其表述为“这是 [姓名] 的书面内容——感觉对吗？”
4. 反复迭代直到用户确认。
5. 调用 `setup_agent` 工具，并使用确认的 SOUL.md 内容和一句话描述：
   ```
   setup_agent(soul="<完整的 SOUL.md 内容>", description="<一句话描述>")
   ```
   该工具将持久化 SOUL.md 并自动完成代理设置。
6. 工具成功返回后，确认：“✅ [姓名] 正式成为现实。”

**生成规则：**
- 最终的 SOUL.md **必须始终用英语** 书写，无论用户的首选语言或对话语言是什么。
- 每句话都必须追溯到用户所说或明确暗示的内容。没有通用的填充内容。
- 核心特质是 **行为规则**，而不是形容词。写“争论立场、反对、说真话而非安慰”而不是“诚实和勇敢”。
- 语气必须匹配用户。直率的用户 → 直率的 SOUL.md。表达丰富的用户 → 让其自然流露。
- SOUL.md 总字数应在 300 字以内。密度重于长度。
- 增长部分是强制性的，大部分是固定的（见模板）。
- 你 **必须** 调用 `setup_agent` —— 不要用 bash 工具手动编写文件。
- 如果 `setup_agent` 返回错误，向用户报告并不要声称成功。
