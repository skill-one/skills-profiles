# 移动应用 UI/UX 设计技能

本技能指导创建专业、精致的移动应用界面，遵循 Airbnb、Duolingo、Spotify、Revolut 和 Phantom 等顶级应用所使用的成熟设计原则。

## 核心理念

优秀的移动 UI 并非追求炫酷——它关乎目的性。每个像素、每个间距值、每个色彩选择都应服务于用户。目标是创建流畅、个性化和充满活力的界面——而不仅仅是功能性的。

在设计任何内容之前，理解三件事：
1. **用户试图完成什么？**（减少达成目标的阻力）
2. **这应该如何让用户感觉？**（信任、愉悦、自信、平静）
3. **他们首先应该注意到什么？**（视觉层级）

## 设计流程

对任何移动屏幕，遵循以下顺序：

### 第一步：理解背景
- 应用类型是什么？（健身、金融、社交、生产力、健康、加密货币等）
- 用户是谁？（新用户、回访用户、高级用户——调整体验）
- 此屏幕上的主要操作是什么？
- 适用哪些行业设计惯例？（参见 `references/industry-conventions.md`）

### 第二步：先结构化（从 UX 视角）
- 绘制用户流程：前一个屏幕和后一个屏幕是什么？
- 确定最小可行产品（MVP）元素——仅此屏幕必需的内容
- 将主要操作放置在**拇指区域**（屏幕底部的 1/3）
- 遵循 **F 型阅读顺序**进行内容布局
- 减少交互成本：直接展示内容，而不是隐藏在点击之后
- 将空状态转化为机会，通过指导、插图和行动号召（CTA）
- 选择合适的输入方式：滑块/滚动轮用于一次性设置，文本字段用于重复/精确输入

### 第三步：应用视觉设计（从 UI 视角）
按顺序遵循以下规则：

#### 字体排印
- 使用 **一种字体家族**（最多两种，具有清晰的层级目的）
- 最大 **4 种字体大小**和 **2 种字体粗细**
- 使用等宽变体表示大数字（价格、统计数据、指标）
- 将文本容器宽度保持在 600px 以下，以确保可读性
- 通过大小、粗细和透明度创建层级——而不仅仅是加粗所有内容

#### 色彩系统（60/30/10 规则）
- **60%** — 中性基础（白色、浅灰色或深色背景）
- **30%** — 互补色（黑色文本、深色元素）
- **10%** — 品牌/强调色（CTA、关键指示器、图标）
- 使用中性色的**透明度变化**表示文本层级：100% 用于标题，80% 用于正文，60-70% 用于次要文本
- 使用 5% 透明度的强调色表示次要按钮和微妙的卡片高亮
- 使阴影颜色与背景匹配（色调阴影，彩色背景上不要使用纯灰色/黑色）
- 将强烈颜色（如红色）用于有意义时刻——过度使用会破坏层级

#### 间距（8 点网格系统）
- 所有间距值必须是 **8 或 4 的倍数**（8、12、16、24、32、48、64、80、96）
- 使用**基于关系**的间距：相关元素靠得更近，不相关元素分得更开
- 乘数规则：如果相关文本元素相距 16px，则下一组之间的间隙应为 2 倍（32px）
- 区块垂直填充：至少 80-96px（在大屏幕上主要区块为 160px）
- 卡片内部填充：24-32px 基线
- 较大的文本需要更大的间距

#### 阴影
- 始终使用**柔和阴影**——绝不用刺眼/清晰的阴影
- 使阴影颜色与背景匹配，使用色调阴影
- 在按钮上使用微妙的白色内部阴影以增加维度
- 添加褪色的下落阴影以增加深度，而不会显得沉重

#### 视觉提示与图像
- 使用图标、表情符号、插图和图像使信息易于理解
- 用户头像/照片 > 首字母 > 通用图标（用于代表人物）
- 使用带柔和实色背景和干净独立图像的色彩编码类别
- 在整个应用中保持视觉风格一致——不要随机混合股票照片
- 使用与色彩调色板匹配的 AI 生成或精选图像

### 第四步：为情感设计（峰值-结尾法则）
用户会记住两个时刻：**峰值**（最强烈）和**结尾**（最后印象）。

- **确定你的峰值时刻**：完成核心任务、达成里程碑、找到他们想要的内容
- **设计峰值**：微动画、庆祝性反馈、闪光、徽章、鼓励性文案
- **设计结尾**：总结卡片、进度确认、温和的回归提示
- 添加**情感反馈循环**：成功状态应感觉有回报（弹跳、发光、闪光）
- 庆祝小胜利——成功状态不必巨大，但应有目的性
- 使用动效和动画作为信任信号，特别是在高风险领域（金融、加密货币、健康）

### 第五步：润色与细节
- 在关键元素背后添加微妙的光晕效果（模糊 + 透明度）
- 在主要按钮上使用微小的白色内部阴影
- 在次要元素上添加 5% 透明度的主要颜色边框
- 考虑为状态变化添加微动画
- 确保所有点击目标至少为 44×44pt
- 检查对比度比例，确保无障碍性
- 设计错误状态、空状态、加载状态和成功状态

## 可应用的智能模式

### 根据用户阶段进行个性化
- **新用户**：简单的欢迎界面、引导设置、最少选项
- **回访用户**：个性化内容、以常规为中心、进度指示器
- **高级用户**：高级统计数据、优化工具、密集信息

### 更智能的搜索
永远不要显示空白搜索屏幕。包括：
- 最近搜索
- 热门/趋势项目
- 个性化推荐

### 订单/状态跟踪
- 以自信的状态消息开始
- 使用照片、姓名、快速操作按钮进行人性化处理
- 使用视觉时间线代替基于文本的日期列表

### 类别屏幕
- 使用带柔和背景和干净独立图像的色彩编码卡片
- 确保所有类别项目之间视觉一致
- 在布局中创建节奏，以便轻松扫描

### 选择优于手动输入
- 为常见选项（职位名称、偏好等）提供可点击选择
- 在选项旁边添加图标/表情符号以增加个性
- 提供“其他”选项，并作为后备方案提供手动输入

## 需避免的反模式
- 过度使用闪亮的渐变和模糊效果（除非你能真正驾驭它）
- 超过 4 种字体大小或 3 种字体粗细
- 随机间距值（使用 8 点网格！）
- 将关键内容隐藏在横幅或额外点击之后
- 将 CTA 放置在拇指区域之外
- 使用没有指导的通用空状态
- 使用滑块进行频繁/精确的数据输入
- 使所有信息具有相同的视觉权重（没有层级）
- 强调标签而不是值（例如，使“销售额”比“591”更大）
- 在彩色背景上使用纯灰色/黑色阴影

## 实现说明

在构建这些设计为 React 组件或 HTML 时：
- 使用 Tailwind CSS 工具类进行间距、色彩和字体排印
- 导入 Lucide React 以获得干净、一致的图标
- 使用 Recharts 进行任何数据可视化
- 应用 CSS 过渡效果进行微交互和状态变化
- 使用 CSS 变量定义色彩系统
- 移动优先：以 375px 宽度（iPhone SE）为基线设计
- 使用 `rounded-2xl` 或 `rounded-3xl` 获取现代卡片美学
- 在适当的地方应用 `backdrop-blur` 以实现玻璃态效果

有关特定行业惯例和情感设计模式的更深入指导，请阅读 `references/industry-conventions.md`。
