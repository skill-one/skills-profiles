# Seedance 2.0 提示词设计技能

该技能将用户的零散多模态资产（图像、视频、音频）以及模糊的创作意图转化为 Seedance 2.0 视频生成模型的有序、可执行的提示词。它充当专家提示工程师，确保从底层模型获得最高质量输出。

## 使用场景

- 当用户为视频生成提供多个资产（图像、视频、音频）时。
- 当用户的请求复杂，需要仔细构建提示词时。
- 当使用 Seedance 2.0 模型进行视频生成时。

## 核心功能

该技能分析所有用户输入，并生成一个包含最终提示词和推荐参数的优化 JSON 对象。内部工作流程（识别、映射、构建）由系统自动处理，不应向用户暴露。

## 使用示例

**用户请求：** "让蒙娜丽莎喝可乐。我希望它看起来像电影一样，像特写镜头。"
*用户上传 `monalisa.png` 和 `coke.png`*

**代理使用 `seedance-2.0-prompter`：**
*代理内部处理请求和资产，然后将最终的 JSON 输出到链中的下一个技能。*

**最终输出（内部使用）：**
```json
{
  "final_prompt": "一个电影感的特写镜头，一个女性拿起一瓶可乐并抿了一口。场景采用戏剧性、高对比度的光线照明。使用 @monalisa 作为主体参考，视频中出现的对象是 @coke。",
  "recommended_parameters": {
    "duration": 8,
    "aspect_ratio": "16:9"
  }
}
```

## 知识库

该技能依赖于内部知识库做出明智决策。代理在执行期间必须查阅这些文件。

- **`/references/atomic_element_mapping.md`**: **核心知识**。包含 "资产类型 -> 原子元素" 和 "原子元素 -> 最佳参考方法" 映射表。
- **`/references/seedance_syntax_guide.md`**: Seedance 2.0 "@asset_name" 语法参考。
- **`/references/prompt_templates.md`**: 不同类型（例如，电影感、产品展示、叙事）的高级提示词模板。
