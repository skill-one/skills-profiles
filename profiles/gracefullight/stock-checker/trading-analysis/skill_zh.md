# 交易分析与投资报告生成器

该技能结合实时市场数据、技术分析、Claude AI洞察和专业可视化，生成全面的投资报告。

## 该技能的功能

- 从Yahoo Finance下载实时市场数据
- 计算10多项技术指标（RSI、MACD、移动平均线、布林带等）
- 使用Claude AI分析市场状况
- 生成4种专业图表（价格、指标、波动率、仪表盘）
- 创建机构级投资报告（Markdown格式）
- 以JSON格式导出结构化数据

## 使用场景

在以下情况下使用该技能：
- 请求特定股票/ETF的投资报告或分析
- 带有技术指标的市场分析
- 基于当前市场状况的交易建议
- 为客户或投资组合审查的专业报告
- 多个符号的对比分析

## 输入要求

**必填：**
- `symbol`：股票代码（例如，SPY、AAPL、TSLA、QQQ）

**可选：**
- `client_name`：客户/投资者的名称（默认："机构投资者"）
- `report_title`：自定义报告标题（如未提供则自动生成）
- `period`：历史数据周期（默认："6mo"）

## 输出文件

该技能在`reports/`目录下生成以下文件：

1. **Markdown报告** (`{SYMBOL}_analysis_report_{timestamp}.md`)
   - 带有情绪和推荐的执行摘要
   - 带有价格表的市场概览
   - 带有指标的技术分析
   - AI驱动的市场洞察
   - 带有入场/出场标准的投资建议
   - 风险评估
   - 图表引用

2. **JSON数据** (`{SYMBOL}_analysis_report_{timestamp}_data.json`)
   - 用于程序化访问的结构化数据
   - 所有指标和分析结果

3. **图表**（PNG格式，300 DPI）：
   - `{SYMBOL}_price_chart.png`：带移动平均线的价格图
   - `{SYMBOL}_indicators_chart.png`：RSI和MACD
   - `{SYMBOL}_volatility_chart.png`：历史波动率
   - `{SYMBOL}_summary_dashboard.png`：绩效仪表盘

## 示例用法

**简单请求：**
"为SPY生成投资报告"

**详细请求：**
"为Acme Capital创建AAPL市场分析报告，标题为'2025年Q4 AAPL投资策略'"

**多个符号：**
"为SPY、QQQ和DIA生成投资报告"

## 报告质量

- **格式**：机构级，适合客户演示
- **数据准确性**：实时市场数据，经过验证的计算
- **视觉质量**：高分辨率图表（300 DPI，可打印）
- **AI分析**：Claude驱动的市场情绪和风险评估
- **完整性**：执行摘要、技术分析、建议、免责声明

## 技术细节

- **数据源**：Yahoo Finance API
- **AI模型**：Claude 3.7 Sonnet（可配置）
- **图表分辨率**：300 DPI（打印质量）
- **报告格式**：GitHub风格的Markdown
- **处理时间**：每个符号约15-30秒

## 安全与免责声明

所有报告自动包含：
- 投资免责声明
- 风险警告
- 说明此信息非财务建议
- 建议咨询合格财务顾问

## 注意事项

- 需要`.env`文件中的有效Anthropic API密钥
- 需要互联网连接获取市场数据
- 历史数据受Yahoo Finance可用性限制
- AI分析基于技术数据，而非基本面分析
