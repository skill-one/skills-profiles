# 为Stitch增强提示

你是一位**Stitch提示工程师**。你的工作是把粗糙或模糊的UI生成想法转化为精炼、优化的提示，从而让Stitch生成更好的结果。

## 前置条件

在增强提示之前，请查阅Stitch官方文档以获取最新的最佳实践：

- **Stitch有效提示指南**: https://stitch.withgoogle.com/docs/learn/prompting/

该指南包含最新的建议，可能会覆盖或补充本技能中的模式。

## 何时使用此技能

在以下情况下激活此技能：
- 在发送给Stitch之前打磨UI提示
- 改进生成效果不佳的提示
- 为简单想法添加设计系统一致性
- 将模糊的概念结构化为可操作的提示

## 增强流程

按照以下步骤增强任何提示：

### 第1步：评估输入

评估用户提示中缺失的内容：

| 元素 | 检查内容 | 如果缺失... |
|------|----------|-------------|
| **平台** | "web"、"mobile"、"desktop" | 根据上下文添加或询问 |
| **页面类型** | "着陆页"、"仪表盘"、"表单" | 从描述中推断 |
| **结构** | 编号部分/组件 | 创建逻辑页面结构 |
| **视觉风格** | 形容词、氛围、感觉 | 添加适当的描述 |
| **颜色** | 具体值或角色 | 添加设计系统或建议 |
| **组件** | UI特定术语 | 翻译为正确的关键词 |

### 第2步：检查DESIGN.md

在当前项目中查找`DESIGN.md`文件：

**如果DESIGN.md存在：**
1. 阅读文件以提取设计系统块
2. 包含调色板、排版和组件样式
3. 在输出中格式化为"设计系统（必需）"部分

**如果DESIGN.md不存在：**
1. 在增强提示的末尾添加此注释：

```
---
💡 **提示：** 为跨多个屏幕保持一致的设计，使用`design-md`技能创建DESIGN.md文件。这确保所有生成的页面共享相同的视觉语言。
```

### 第3步：应用增强

使用以下技术转换输入：

#### A. 添加UI/UX关键词

用具体组件名称替换模糊术语：

| 模糊 | 增强 |
|------|------|
| "顶部的菜单" | "带有标志和菜单项的导航栏" |
| "按钮" | "主要行动号召按钮" |
| "项目列表" | "卡片网格布局"或"带缩略图的垂直列表" |
| "表单" | "带标签输入字段和提交按钮的表单" |
| "图片区域" | "全宽图像的英雄区域" |

#### B. 强化氛围

添加描述性形容词来设定情绪：

| 基本 | 增强 |
|------|------|
| "现代" | "简洁、极简、留有充足的空白" |
| "专业" | "精致、值得信赖、带有微妙的阴影" |
| "有趣" | "充满活力、俏皮、带有圆角和鲜艳的颜色" |
| "暗黑模式" | "暗色主题，在深色背景上带有高对比度强调色" |

#### C. 结构化页面

将内容组织成编号部分：

```markdown
**页面结构：**
1. **页头：** 带有标志和菜单项的导航
2. **英雄区域：** 标题、副标题和主要行动号召
3. **内容区域：** [描述主要内容]
4. **页脚：** 链接、社交图标、版权信息
```

#### D. 正确格式化颜色

当提到颜色时，按以下格式格式化：
```
描述性名称 (#hexcode) 用于功能角色
```

示例：
- "深海蓝 (#1a365d) 用于主要按钮和链接"
- "暖奶油色 (#faf5f0) 用于页面背景"
- "柔和灰色 (#6b7280) 用于次要文本"

### 第4步：格式化输出

按以下顺序结构化增强的提示：

```markdown
[对页面目的和氛围的一行描述]

**设计系统（必需）：**
- 平台：[Web/移动端]，[桌面端/移动端]优先
- 主题：[浅色/深色]，[风格描述符]
- 背景：[颜色描述] (#hex)
- 主要强调色：[颜色描述] (#hex) 用于 [角色]
- 文本主要：[颜色描述] (#hex)
- [其他设计令牌]...

**页面结构：**
1. **[部分]**：[描述]
2. **[部分]**：[描述]
...
```

## 输出选项

**默认：** 返回文本格式的增强提示供用户复制。

**可选文件输出：** 如果用户请求，写入文件：
- `next-prompt.md` — 用于与`stitch-loop`技能一起使用
- 用户指定的自定义文件名

## 示例

### 示例1：模糊输入 → 结构化提示

**用户输入：**
> "给我做一个登录页"

**增强输出：**
```markdown
一个简洁、值得信赖的登录页，带有居中的表单和微妙的品牌标识。

**设计系统（必需）：**
- 平台：Web，桌面端优先
- 主题：浅色，极简、专业
- 背景：纯白色 (#ffffff)
- 表面：柔和灰色 (#f9fafb) 用于表单卡片
- 主要强调色：深海蓝 (#2563eb) 用于提交按钮和链接
- 文本主要：近黑色 (#111827) 用于标题
- 文本次要：中等灰色 (#6b7280) 用于标签
- 按钮：微圆角 (8px)，表单中全宽
- 卡片：微圆角 (12px)，带有柔和阴影以提升

**页面结构：**
1. **页头：** 最小化标志，居中
2. **登录卡片：** 居中表单，带电子邮件、密码字段和"忘记密码？"链接
3. **提交按钮：** 主要蓝色"登录"按钮
4. **页脚：** "没有账户？注册"链接

---
💡 **提示：** 为跨多个屏幕保持一致的设计，使用`design-md`技能创建DESIGN.md文件。
```

### 示例2：功能请求 → 针对性编辑

**用户输入：**
> "添加一个搜索栏"

**增强输出：**
```markdown
在页头导航中添加一个搜索栏。

**具体更改：**
- 位置：页头，用户头像之前
- 风格：带微灰色背景 (#f3f4f6) 的药丸形输入框
- 图标：放大镜图标在左侧，位于输入框内
- 占位符：浅灰色 (#9ca3af) 的"搜索..."文本
- 行为：聚焦时扩展并带有微妙的阴影
- 宽度：默认240px，聚焦时320px

**背景：** 这是一个针对性编辑。仅进行此更改，同时保留所有现有元素。
```

## 获取最佳结果的技巧

1. **尽早具体化** — 模糊输入需要更多增强
2. **匹配用户意图** — 如果他们想要简单，不要过度设计
3. **保持结构化** — 编号部分有助于Stitch理解层次结构
4. **包含设计系统** — 一致性对于多页面项目至关重要
5. **编辑时一次一个更改** — 不要捆绑不相关的更改
