# 角色设计表

通过 [inference.sh](https://inference.sh) CLI 在多张 AI 生成的图像中创建一致的字符。

## 快速入门

> 需要 inference.sh CLI (`belt`)。[安装说明](https://raw.githubusercontent.com/inference-sh/skills/refs/heads/main/cli-install.md)

```bash
belt login

# 生成角色概念
belt app run falai/flux-dev-lora --input '{
  "prompt": "角色设计参考表，年轻女性正面视图，短红色头发，绿色眼睛，穿着蓝色夹克和白色T恤，全身像，白色背景，线条清晰，概念艺术风格，角色转向",
  "width": 1024,
  "height": 1024
}'
```

## 一致性问题

AI 图像生成每次生成的角色外观都不同，即使使用相同的提示。这是 AI 艺术中任何需要跨多张图像保持相同角色的项目的首要挑战。

### 解决方案（按有效性排序）

| 技术 | 一致性 | 努力 | 适合 |
|-----------|-------------|--------|----------|
| **FLUX LoRA**（基于角色训练） | 非常高 | 高（需要训练数据） | 持续项目，多张图像 |
| **详细描述锚点** | 中高 | 低 | 快速项目，少量图像 |
| **相同种子 + 类似提示** | 中等 | 低 | 单一姿势的变体 |
| **图像到图像的细化** | 中等 | 中等 | 细化现有图像 |
| **提示中的参考图像** | 变化 | 低 | 当模型支持时 |

## 描述锚点技术

最实用的保持一致性的技术：写一个 **50+ 字的详细描述** 并在每个提示中完全重复它。

### 模板

```
[年龄] [性别] 的 [头发：颜色，长度，风格]，[眼睛颜色] 眼睛，
[肤色]，[面部特征：任何显著标记]，
穿着 [上衣：特定颜色和风格]，[下装：特定颜色和风格]，
[鞋子：特定颜色和风格]，[配饰：特定物品]
```

### 示例

```
二十多岁中年的女性，不对称赤陶红色短发
向右侧扫起，明亮祖母绿眼睛，浅暖肤色
左眼下有一枚小美人痣，穿着合身海军蓝飞行员夹克，银色拉链，白色连帽T恤，
深石板色修身牛仔裤，亮红色帆布鞋，小银色耳钉
```

**在所有提示中完全使用这个块**，仅更改动作/场景。

## 比例指南

| 风格 | 头身比例 | 适合 |
|-------|-------------------|----------|
| 写实 | 7.5 : 1 | 电影，照片逼真 |
| 英雄 | 8 : 1 | 超级英雄，动作 |
| 动漫/漫画 | 5-6 : 1 | 日本动画风格 |
| 风格化 | 4-5 : 1 | 西方动画 |
| Q版/超变形 | 2-3 : 1 | 可爱，喜剧，吉祥物 |

在提示中包含比例风格： "写实比例" vs "动漫风格比例" vs "Q版比例"

## 使用 LoRA 保持一致性

对于需要大量相同角色图像的项目，训练一个 LoRA：

```bash
# 使用 FLUX 和角色 LoRA
belt app run falai/flux-dev-lora --input '{
  "prompt": "maya_chen 角色，坐在咖啡馆读书，温暖的午后阳光，随性摄影风格",
  "loras": [{"path": "path/to/maya-chen-lora.safetensors", "scale": 0.8}]
}'
```

**LoRA 训练技巧：**
- 需要 10-20 张角色的参考图像（一致风格）
- 在特定触发词上训练（例如，"maya_chen"）
- 比例 0.7-0.9 在一致性和提示灵活性之间取得平衡
- 低比例 = 更多的创作自由，高比例 = 更严格的匹配

## 常见一致性失败

| 问题 | 原因 | 补救 |
|-------|---------------|------------|
| **头发颜色漂移** | 模型每次解释 "红色头发" 都不同 | 使用特定色调： "赤陶红 #C0392B" |
| **眼睛颜色变化** | 生成中低优先级 | 在提示中尽早提及眼睛颜色 |
| **服装不一致** | 模型进行创意填充 | 明确描述每件衣物 |
| **年龄变化** | 模糊的年龄描述 | 使用 "二十多岁中" 而不是 "年轻" |
| **面部结构变化** | 不同生成 = 不同面部 | 使用 LoRA 或相同种子基础 |
| **比例变化** | 风格解释不同 | 指定 "7.5 头比例" |

## 角色圣经模板

对于持续项目，维护一个角色圣经文档：

```markdown
# 角色：Maya Chen

## 视觉描述（用于所有提示）
二十多岁中年的女性，不对称赤陶红色短发...
[完整的 50+ 字锚点描述]

## 色彩搭配
- 皮肤：#F5D0A9
- 头发：#C0392B
- 眼睛：#27AE60
- 主要服装：海军 #2C3E50
- 辅色：红 #E74C3C

## 性格笔记（用于表情/姿势选择）
- 自信但亲切
- 默认表情：轻微好奇的微笑
- 手势：用手说话，感兴趣时身体前倾

## 风格关键词
概念艺术，线条清晰，细节锐利，[艺术风格参考]

## LoRA（如果已训练）
路径：./loras/maya-chen-v2.safetensors
触发：maya_chen
推荐比例：0.8
```

## 常见错误

| 错误 | 问题 | 修复 |
|---------|---------|-----|
| 模糊描述 | 每次生成不同角色 | 50+ 字详细锚点 |
| 提示结构不一致 | 不同强调 = 不同结果 | 相同结构，仅更改动作/场景 |
| 仅生成单视图 | 无法在不同环境中使用角色 | 创建完整的转向参考 |
| 无色彩记录 | 颜色跨代漂移 | 记录确切十六进制代码 |
| 忽略表情表 | 角色感觉单维 | 生成 6+ 种表情 |
| 未使用 LoRA 进行大型项目 | 不一致性累积 | 训练 LoRA 用于 10+ 图像项目 |
