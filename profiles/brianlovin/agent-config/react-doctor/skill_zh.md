# React Doctor

扫描您的 React 代码库，查找安全、性能、正确性和架构问题。输出 0-100 分数并提供可操作的诊断建议。

## 使用方法

```bash
npx -y react-doctor@latest . --verbose
```

## 工作流程

1. 在项目根目录下运行上述命令
2. 查看包含文件路径和行号的每项诊断建议
3. 从错误（最高严重性）开始修复问题
4. 重新运行以验证分数是否提升

## 规则 (47+)

- **安全**: 客户端包中硬编码的密钥、eval() 函数
- **状态与副作用**: useEffect 中的派生状态、缺少清理操作、从 props 调用的 useState、级联的 setState
- **架构**: 组件嵌套、巨型组件、内联渲染函数
- **性能**: 布局属性动画、transition-all、大模糊值
- **正确性**: 数组索引作为键、条件渲染错误
- **Next.js**: 缺少元数据、服务器数据客户端获取、异步客户端组件
- **包体积**: 模块化导入、完整的 lodash、moment.js、缺少代码拆分
- **服务器**: 服务器操作中缺少认证、没有 after() 的阻塞操作
- **可访问性**: 缺少 prefers-reduced-motion
- **无用代码**: 未使用的文件、导出、类型

## 分数

- **75+**: 优秀
- **50-74**: 需要改进
- **0-49**: 危急
