# 应用 CMS 品牌

通用技能，用于搜索、提取并将 Salesforce CMS 的品牌指南应用于生成内容。

## 范围

**此技能用于将 Salesforce CMS 中的现有品牌指南应用于您生成的内容。**

**当用户需要时使用此技能：**
- 将其品牌语气/语调应用于生成内容
- 查找并使用 Salesforce CMS 中存储的品牌指南
- 搜索其组织中的现有品牌
- 获取内容生成的品牌说明
- 确保生成内容与其品牌身份一致
- 将品牌样式、语气或声音应用于页面、组件或应用程序

**当用户不需要时不要使用此技能：**
- 搜索图像或媒体（使用搜索媒体技能）
- 从零开始创建新品牌
- 编辑 CMS 中的品牌定义
- 生成标志或视觉品牌资产

## 开始前

**关键：在生成或修改任何品牌之前，您必须检索品牌说明。**

当用户请求品牌化内容时：

1. **搜索可用品牌**（如果品牌尚未确定）
2. **提取所选品牌的品牌说明**
3. **将品牌指南应用于所有您生成的内容**

**切勿先生成内容，然后再后期添加品牌。** 品牌说明必须从一开始就指导内容生成。

## 工作流程概述

复制此清单并跟踪您的进度：

```
CMS 品牌化进度：
- [ ] 第 1 步：确定品牌是否已确定或需要搜索
- [ ] 第 2 步：搜索品牌（如果需要）并向用户展示选项
- [ ] 第 3 步：提取所选品牌的品牌说明
```

## 第 1 步：确定品牌上下文

检查用户是否已经指定要使用哪个品牌：

**品牌已知**（用户命名了，或者只有一个品牌存在）：
- 跳转到第 3 步（提取品牌说明）

**品牌未知**（用户说“应用我的品牌”但没有指定哪个）：
- 继续第 2 步（搜索品牌）

## 第 2 步：搜索品牌

**工具：** `search_brands`

**流程：**

1. **确定搜索查询** — 使用用户的描述、公司名称或一般关键词
2. **构建请求：**

```json
{
  "inputs": [{
    "searchQuery": "关键词或品牌名称"
  }]
}
```

3. **使用查询调用 `search_brands`**
4. **解析响应** — 提取品牌结果：
   - `managedContentId` — 唯一 ID（用于第 3 步中的提取）
   - `managedContentKey` — 内容键标识
   - `title` — 品牌显示名称
   - `contentUrl` — 品牌内容的 URL
   - `totalResults` — 找到的品牌数量

### 展示品牌结果

**如果找到多个品牌**，使用 `ask_followup_question` 展示选项：

```
我在您的 CMS 中找到了 [N] 个品牌。我应该应用哪个？

1. [品牌标题 1]
2. [品牌标题 2]
3. [品牌标题 3]

您想使用哪个品牌？
```

**如果找到一个品牌**，向用户确认：

```
我找到了品牌 "[品牌标题]"。我应该将此品牌的指南应用于内容吗？
```

**如果未找到品牌：**

```
Salesforce CMS 中未找到品牌。要使用品牌化：
1. 在 Salesforce CMS 中创建品牌（内容类型：sfdc_cms__brand）
2. 在此对话中直接提供品牌指南

您想在不使用 CMS 品牌化的情况下继续，还是手动提供指南？
```

**切勿未经确认自动选择品牌。** 始终等待用户选择。

## 第 3 步：提取品牌说明

**工具：** `get_brand_instructions`

**流程：**

1. **调用 `get_brand_instructions`** — 这会检索品牌提取提示模板
2. **解析响应：**
   - `promptBody` — 包含完整的品牌说明提示模板，其中包含提取和应用规则

3. **遵循 `promptBody` 中的说明** — 提示模板包含关于以下方面的具体指导：
   - 如何从品牌内容中提取品牌属性
   - 品牌语气和语调规则
   - 字体和颜色指南
   - 内容格式规则
   - 守护栏和限制

### 品牌说明包含的内容

提取的品牌说明通常包括：

| 属性 | 描述 |
|---|---|
| 品牌语气 | 品牌如何说话（例如，专业、友好、权威） |
| 品牌语调 | 沟通的情感质量（例如，自信、温暖、有同理心） |
| 关键信息 | 核心信息支柱和价值主张 |
| 内容规则 | 内容生成的可做和不可做 |
| 样式指南 | 字体、颜色、间距偏好 |
| 守护栏 | 对语言、主题或声明的硬性限制 |

## 错误处理

| 错误 | 响应 |
|---|---|
| `search_brands` 不可用 | "品牌搜索不可用。请直接提供您的品牌名称或指南。" |
| `get_brand_instructions` 不可用 | "无法检索品牌说明。请在此对话中共享您的品牌指南，我将手动应用。" |
| 组织缺乏 Vibes 品牌化 | "此组织未启用 CMS 品牌化。请联系管理员启用 Agentforce Vibes 品牌化功能。" |
| 权限被拒绝 | "您没有权限访问 CMS 品牌。确保您具有管理内容创作权限。" |
| 品牌提取返回空 | "品牌存在但没有配置的指南。请在 CMS 中添加品牌属性或在此处提供指南。" |

**切勿无声失败。** 始终告知用户并提供替代方案。

## 关键原则

1. **先品牌，后内容** — 始终在生成内容之前提取品牌说明
2. **绝不假设品牌指南** — 仅应用从 CMS 明确检索到的内容
3. **绝对尊重守护栏** — 品牌内容规则是硬性约束，不是建议
4. **确认品牌选择** — 未经用户确认切勿自动选择品牌
5. **展示您的工作** — 告知用户您应用了哪些指南以及如何应用
6. **优雅降级** — 如果工具不可用，请要求手动指南，而不是不使用品牌化继续
