# 冷启动邮件撰写工具

## 使用场景

当用户需要以下情况时，使用此技能：
- 向招聘经理、创始人或招聘人员发送冷启动邮件
- 联系未获推荐的职位空缺
- 向希望加入的公司进行自我介绍
- 提及："冷启动邮件"、"联系"、"介绍邮件"、"启动联系"、"联系招聘经理"

## 核心原则

冷启动邮件失败是因为它们听起来像求职信。目标是表现得像一个真正注意到公司某些具体细节的聪明人——而不是一个在广播自己资质的候选人。

**邮件应感觉像：** 同事提到他们读到的一些有趣的事情，而不是一个销售演讲。

## 模板结构

### 主题
```
快速介绍 — [姓名]
```
简单。不要点击诱饵。不要职位头衔。只需一个名字。

### 开头——钩子（2-3句话）
从真正吸引候选人的地方开始。必须针对这家公司——不是泛泛的恭维。

```
我刚刚了解到[公司]，结果比预期花费了更多时间在上面。
[一个特定的吸引他们的点——一个数据、一个产品决策、一个市场洞察来自职位描述或网站]
```

**一个好的钩子是什么：**
- 来自公司材料的特定数字或数据（"只有5%的市场是线上的"）
- 一个产品决策，表明你理解这个领域（"你正在从零开始与承保人合作，而不仅仅是分销"）
- 来自职位描述的技术洞察（"为LLM使用改进数据基础设施，而不仅仅是模型层"）

**一个坏的钩子是什么：**
- 泛泛的："我喜欢你在做的事情"
- 模糊的："你的使命与我产生共鸣"
- 奉承的："你是这个领域最令人兴奋的公司之一"

### 地点披露（如果国际）
如果候选人与公司位于不同的国家，应尽早轻松披露：

```
在继续阅读之前，我应该提到我位于[国家]。但如果我们都觉得有很强的匹配度，我愿意尝试解决。
```

### 经验差距（如果适用）
如果职位列出的经验年限多于候选人，简要承认并转移：

```
该职位提到[X]年的经验——我目前有[Y]，但我的工作面向生产，我宁愿让你直接判断。
```

### 正文——他们是谁（3-5句话）
当前职位→相关过去→一个或两个项目。保持上下文，不要列出来。

```
关于我：我目前在[公司]，[一句话说明公司做什么]，在那里我[他们实际做什么——不是职位头衔]。之前我在[地区]与团队合作，主要围绕[相关领域]。

业余时间我一直在开发[项目]（如果适用则提供链接）——[一句话：它是什么，一个证明点如"获得付费客户"或"20K下载量"]。
```

**规则：**
- 将工作作为背景提及，而不是作为伟大成就的证据
- 没有成就列表（"我使X增加了Y%"）——让项目说话
- 如果当前公司是远程的，有一个欧洲/国际团队，请明确说明
- 最多提及一两个项目——只有最相关的

### 连接（1-2句话）
在他们背景和特定职位之间建立桥梁。应该感觉像一个观察，而不是一个声明。

```
我认为你在寻找[职位实际需要的东西]——那是我一直在做的工作，老实说我觉得我会是一个很好的匹配。
```

或者更具体：
```
我的技术栈与你们自然匹配——[具体技术重叠]。但不仅仅是技术栈，我对[领域/问题]真正感兴趣。
```

### 作品集链接
```
更多关于我：[作品集URL]
```

一句话。不要详细说明。

### 结尾
以低压力、自信的能量结束。不是绝望的，不是企业化的。

```
我目前在[公司]，对下一步持开放态度。我认为我的经验与你们正在做的事情很契合——所以我认为我们双方都能从对话中获得一些东西。

[姓名]
[邮箱]
```

**避免：**
- "我期待您的回复"
- "请附上我的简历"
- "我非常希望有机会..."
- "我很兴奋有可能加入..."

## 写作前的调研

在撰写邮件之前收集：
1. **公司角度**——阅读他们的网站、职位描述或关于页面。找到一个值得提及的具体点。
2. **收件人姓名**——领英、团队页面或AngelList。"你好[姓名]"比"你好招聘经理"每次都好。
3. **相关项目**——将候选人的最相关工作与职位领域相匹配。
4. **技术栈重叠**——只有当有真实匹配时才提及。

如果用户提供了职位描述但没有公司网站，请在写作前请求它或获取它。

## 长度指南

- **理想：** 200-300字
- **最大：** 400字
- **最小：** 150字（不要为了简洁而删减内容）

如果每句话都值得其位置，那么更长是可以的。剪掉任何可能适用于任何公司的内容。

## 输出格式

始终将最终的邮件包裹在纯代码块中，以便干净地复制粘贴：

```
主题：快速介绍 — [姓名]

你好[姓名]，

[邮件正文]

[姓名]
[邮箱]
```

## 常见错误避免

**过于自信：**
❌ "我会成为你们团队的杰出补充"
❌ "我的背景使我有独特的优势适合这个职位"
✅ "我觉得我会是一个很好的匹配"——陈述一种信念，而不是声称确定性

**过于谦虚：**
❌ "我知道我可能没有你正在寻找的所有经验，但..."
❌ "我只是碰巧联系..."
✅ 直接承认差距并继续——不要道歉

**过于冗长：**
❌ 列出每个成就的三个段落
✅ 一段关于背景，一段关于连接

**过于泛泛：**
❌ 以"我写信表达我对...的兴趣"开头
✅ 以什么特别吸引他们到这家公司开头

**没有调研：**
❌ "我喜欢你们的产品和使命"
✅ "5%的数据——只有5%的250亿美元市场是线上的——这感觉不是一个功能差距，而是一个尚未数字化的整个行业"

## 示例邮件

```
主题：快速介绍 — Sarah Chen

你好Marcus，

我刚刚了解到Meridian，结果比计划花费了更多时间在你的网站上。
吸引我的是你们数据基础设施的框架——你们不是在现有记录之上构建LLM层，而是在重新思考临床数据如何在整个系统中流动。这是一个更难的问题，一个更有趣的问题。

我位于印度，提前说明这一点。如果真的有匹配度，我很乐意尝试解决其余部分。

我目前在Lune工作，这是一家位于伦敦的气候智能公司，我在那里为排放合规构建事件驱动数据管道和代理式AI工作流程——受监管的、数据密集型系统，可靠性不是可选的。我还从零开始构建了Memos，一个RAG系统：混合检索、重新排序、ChromaDB、FastAPI。以及InframetAI，一个用于LLM成本和延迟可观察性的SDK，这是在数据层不是围绕模型实际工作方式设计时出现的问题中产生的。

我认为你在寻找实际构建了端到端AI系统的工程师，而不仅仅是包装API。这就是我一直在做的工作。

更多关于我：yourportfolio.com/about

我目前在Lune，对下一步持开放态度。我认为我的经验与你们正在做的事情非常契合——所以我认为我们双方都能从对话中获得一些东西。

Sarah
sarah@email.com
```
