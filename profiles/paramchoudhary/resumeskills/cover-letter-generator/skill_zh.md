# 求职信生成器

## 使用此技能的场景

当用户需要时使用此技能：
- 撰写求职申请的求职信
- 创建个性化的申请信
- 以信函格式回应特定的工作要求
- 提及："求职信"、"申请信"、"撰写求职信"、"求职信"

在使用前分析职位描述，以便明确讨论要点。

## 核心功能

- 根据简历+职位描述生成个性化的求职信
- 使语气与企业文化相匹配
- 策略性地回应资质差距
- 创建引人入胜的开头
- 构建有说服力的竞选论点
- 在有效销售的同时保持真实性

## 求职信理念

**问题：** 大多数求职信都是通用的、无聊的，除了简历外没有增加任何价值。

**解决方案：** 一封优秀的求职信应该：
1. 展示你已研究过该公司
2. 将你的具体经验与他们的具体需求联系起来
3. 回应"为什么是你、为什么现在、为什么在这里"的问题
4. 添加简历无法传达的个性和背景

## 完美的求职信结构

### 长度与格式
- **长度：** 250-400字（3-4段）
- **格式：** 专业商务信函风格
- **语气：** 自信但不傲慢，个性化但专业

### 结构概述
```
[你的联系方式]
[日期]
[收件人信息]

开头段落：钩子+职位+为什么这家公司（2-3句话）

正文段落1：你最强的资质匹配（3-4句话）

正文段落2：其他资质+处理任何差距（3-4句话）

结尾段落：行动号召+热情（2-3句话）

[专业结束语]
```

## 开头段落策略

开头至关重要——你有5秒钟的时间抓住注意力。

### 钩子类型（选择一个）

**1. 具体公司知识**
```
"看到TechCorp最近推出了你们的API市场，我非常兴奋——作为一名有3年开发工具经验的产品经理，我立即看到我的经验如何加速你们平台的增长。"
```

**2. 共同联系人**
```
"你们工程团队的Sarah Chen提到你们正在寻找一位领导支付计划的产品经理。我在[前公司]与Sarah共事过，并在[当前公司]领导过支付集成，我很乐意讨论我如何能做出贡献。"
```

**3. 问题解决者**
```
"你们的职位描述提到协调技术和业务利益相关者的挑战——我正是处理过这个挑战的人，通过建立工程、销售和执行团队之间的共享路线图可见性，成功推出了8个产品。"
```

**4. 令人印象深刻的成就**
```
"去年，我领导了一个在6个月内从0增长到10万用户的产品。我对将这种增长思维带到[公司]不断扩展的产品线感到兴奋。"
```

**5. 行业洞察**
```
"B2B支付领域正处于转折点，而[公司]对嵌入式金融的方法使你们完美地处于下一波浪潮中。作为一名在金融科技领域工作了5年的人来说，我很乐意为这种增长做出贡献。"
```

### 开头禁忌
- ❌ "我写信申请..."（无聊、明显）
- ❌ "我是完美的候选人..."（让他们决定）
- ❌ "我在LinkedIn上看到你们的职位发布..."（通用）
- ❌ 以"I"开头（从他们或钩子开始）

## 正文段落框架

### 正文段落1：直接匹配

将你的最强经验与他们的首要要求联系起来。

**公式：** [他们的需求] + [你的确切经验] + [具体结果]

```
你们对数据驱动产品决策的关注与我采取的方法完美一致。在[公司]，我实施了一个产品分析框架，通过A/B测试和用户行为分析，确定了并优先考虑了高影响力的机会，使功能采用率提高了40%。
```

### 正文段落2：更广泛的价值+差距处理

展示更多价值，并主动处理问题。

**如果你有差距，处理它们：**
```
虽然我的SQL经验还在发展中（目前正在完成DataCamp的SQL课程），但我通过构建Tableau仪表板展示了强大的分析能力，这些仪表板为2亿美元的决策提供了信息。我始终与数据团队有效合作，并有一个快速掌握新工具的记录。"
```

**如果你没有差距，增加更多价值：**
```
除了产品管理，我还带来了[相关技能]。在[公司]，这使我能够[具体成就]。我特别被[公司]吸引，因为[具体原因显示研究]。"
```

## 结尾段落

以自信和明确的行动号召结束。

**强烈的结尾示例：**
```
我非常兴奋有机会将我的[具体技能]经验带到[公司]的[具体计划或产品]。我非常乐意有机会讨论我的[关键领域]背景如何为您的团队目标做出贡献。感谢您考虑我的申请。
```

**良好结尾的要素：**
- 表达真诚的热情（针对具体事物）
- 提及你将做出的具体贡献
- 明确的行动号召（讨论、见面等）
- 感谢他们

**结尾禁忌：**
- ❌ "我期待您的回复"（被动）
- ❌ "请附上我的简历"（明显）
- ❌ "您方便时可以面试"（绝望）

```
[开头钩子 - 1-2句话抓住注意力，提及公司知识、共同联系人或令人印象深刻的成就]

[你的名字]
```

## 行业特定考虑

### 科技/工程
- 提及特定技术
- 提及GitHub、作品集或技术项目
- 展示你了解他们的技术栈

### 市场/创意
- 在合理范围内展示信函本身的创意
- 提及他们的活动或品牌声音
- 包括相关指标（参与度、转化率等）

### 金融/咨询
- 更正式的语气
- 首先强调资历/认证
- 强调分析严谨性和结果

### 初创企业 vs. 大型企业
**初创企业：** 更随意，展示灵活性，强调成长心态
**大型企业：** 更正式，强调流程和规模经验

## 处理常见场景

### 当你不知道招聘经理时
```
尊敬的招聘经理，
OR
尊敬的[部门]团队，
OR
尊敬的[公司名称]招聘团队，
```
避免"敬启者"（太不个性）

### 当你有推荐人时
首先提及：
```
"[姓名]在你们[团队]团队建议我申请[职位]职位。通过[与推荐人的联系]，我很高兴了解[公司]在[领域]的工作。"
```

### 当你资历不足时
不要道歉。相反，强调：
- 可转移技能
- 快速学习能力
- 真诚的热情
- 相关经验可以弥补

### 当你资历过高时
解释你的动机：
```
"在领导大型团队10年后，我回到[职能]工作的机会让我充满活力，在一家公司我可以直接对[具体领域]产生影响。"
```

### 当你正在转行时
```
"虽然我的背景是[前领域]，但我一直在通过[课程、项目等]积极构建[新领域]技能。我在[可转移技能]方面的经验直接转化为[新角色]通过[具体联系]。"
```

## 质量检查清单

在交付任何求职信之前：

1. ✅ 以钩子开头（不是"我写信申请"）
2. ✅ 提及具体公司知识
3. ✅ 将经验直接与职位要求联系起来
4. ✅ 至少包含一个具体指标/成就
5. ✅ 处理任何明显的差距（如果适用）
6. ✅ 语气自信但不傲慢
7. ✅ 以明确的行动号召结束
8. ✅ 长度250-400字（3-4段）
9. ✅ 不含拼写或语法错误
10. ✅ 会让你想面试这个人
