# 面试准备生成器

## 使用此技能的场景

当用户想要时，使用此技能：
- 准备工作面试
- 练习回答面试问题
- 从个人经历中创建STAR故事
- 针对特定职位预测问题
- 提及： "面试准备"、"准备面试"、"STAR故事"、"面试问题"、"行为问题"

## 核心功能

- 生成特定职位的面试问题
- 从简历要点中创建STAR故事
- 根据职位描述预测问题
- 准备常见问题的答案
- 为每段经历创建谈话要点
- 识别潜在问题并准备应对措施

## 面试准备框架

### 第一阶段：角色分析
- 从职位描述中提取可能的问题
- 确定将被测试的技能
- 调查公司面试风格

### 第二阶段：故事库建设
- 将简历要点转换为STAR故事
- 为常见能力创建故事
- 练习简洁的表达

### 第三阶段：模拟准备
- 练习常见问题
- 准备要问的问题
- 调查公司特定主题

## STAR方法详解

### 结构
- **S**ituation：设定背景（1-2句话）
- **T**ask：描述你的职责（1句话）
- **A**ction：解释你做了什么（2-3句话）
- **R**esult：分享结果并附带指标（1-2句话）

### STAR故事模板

```
SITUATION: "在[公司]，我们面临[具体挑战/背景]..."

TASK: "我负责[具体职责]..."

ACTION: "我[具体行动1]、[具体行动2]和[具体行动3]..."

RESULT: "结果[量化成果]。这导致了[业务影响]。"
```

### 示例STAR故事

**问题：** "告诉我一次你带领团队完成困难项目的情况。"

**回答：**
```
SITUATION: "在TechCorp，我们的主要产品因竞争对手推出更好的移动体验而失去客户。我们每月流失率从正常的2%上升到5%。"

TASK: "作为产品经理，我负责扭转我们的移动产品以停止流失并赢回客户。"

ACTION: "我首先采访了30名流失客户，了解他们离开的原因。根据这些研究，我确定了5个关键功能，以实现与竞争对手的同等水平。然后我与工程团队重新调整了路线图，与领导层协商增加了2名合同开发人员，并实施了每周冲刺评审以保持项目进度。我还为50名最佳客户启动了测试计划，以在全面推出前获取反馈。"

RESULT: "我们在3个月内推出了改进的移动应用，60天内将流失率从5%降至2%。我们恢复了35%的流失客户，我们的移动应用的NPS从32上升到58。这个项目在公司全员大会上被评为转型成功。"

**时间：** 90秒到2分钟

## 故事库建设流程

### 第一步：确定核心能力

**领导力故事需要：**
- 带领团队克服挑战
- 管理冲突
- 做出艰难决定
- 有效授权
- 培养/指导他人

**解决问题故事需要：**
- 解决复杂技术问题
- 修复有问题的流程
- 处理意外障碍
- 在信息不完整的情况下做决定
- 主动改进某事

**协作故事需要：**
- 与难相处的同事合作
- 对跨职能利益相关者达成一致
- 建立共识
- 与其他团队合作
- 无需授权影响他人

**成就故事需要：**
- 超出目标/期望
- 在压力下交付
- 做出额外努力
- 主动承担
- 完成值得骄傲的事情

**失败/成长故事需要：**
- 做出错误并从中学习
- 收到批评性反馈
- 失败并恢复
- 根据学习改变方法

### 第二步：将简历映射到故事

对于每个简历要点，创建一个完整的STAR故事：

```
简历要点: "带领12人的跨职能团队完成价值200万美元的产品发布"

STAR扩展：

SITUATION: 我们的公司因竞争对手推出更好的移动体验而失去市场份额，领导层决定我们在6个月内需要推出新产品线。

TASK: 作为产品经理，我被分配领导产品从概念到发布的整个过程，协调工程、设计、营销和销售团队（总共12人）。

ACTION: 
- 我建立了每周跨职能同步和共享的Notion工作区
- 创建了详细的路线图，包括里程碑和依赖关系
- 实施了快速原型设计流程，每2周进行一次设计冲刺
- 亲自解决了工程和营销之间的3个主要冲突
- 每月向领导层汇报以保持一致

RESULT: 
- 按时按预算发布
- 第一年产生200万美元收入
- 获取50个新的企业客户
- 团队获得公司创新奖
```

### 第三步：创建多个版本

每个故事应有：
- **完整版本：** 2分钟（用于"告诉我一次..."）
- **简短版本：** 60秒（用于后续问题）
- **一句话版本：** 15秒（用于"给我一个例子"）

## 按类别划分的常见面试问题

### 行为问题

**领导力：**
- "告诉我一次你带领团队的经历。"
- "描述一个你不得不做出不受欢迎决定的情境。"
- "你如何培养团队成员？"
- "告诉我一次你处理难相处的团队成员的经历。"

**解决问题：**
- "描述一个你解决的复杂问题。"
- "告诉我一次事情没有按计划进行的情况。"
- "你如何处理信息不完整的问题？"
- "给我一个你开发创新解决方案的例子。"

**协作：**
- "告诉我一次与难相处的同事合作的经历。"
- "描述一个你不得不在无权的情况下影响他人的情境。"
- "你如何处理与同事的分歧？"
- "告诉我一次成功的跨职能项目。"

**成就：**
- "你最大的职业成就是什么？"
- "告诉我一次你超出了期望。"
- "描述一个你克服困难实现的目标。"
- "你职业生涯中最大的影响是什么？"

**失败/成长：**
- "告诉我一次你失败的经历。"
- "你在工作中犯过的最大错误是什么？"
- "你如何处理批评？"
- "你在职业生涯中会做不同的改变是什么？"

### 职位特定问题

**产品管理：**
- "你如何确定功能优先级？"
- "带我走过你如何处理[产品问题]的方法。"
- "你如何衡量产品成功？"
- "告诉我一次你从0到1发布产品的经历。"

**工程：**
- "描述你使用[特定技术]的经验。"
- "你如何处理代码评审？"
- "告诉我一次你解决的挑战性技术问题。"
- "你如何平衡技术债务和功能？"

**营销：**
- "你如何衡量活动成功？"
- "告诉我一次活动没有成功的经历。"
- "你如何分配渠道预算？"
- "描述你建立品牌的方法。"

**销售：**
- "带我走过你的销售流程。"
- "告诉我一次你失去的交易和原因。"
- "你如何处理异议？"
- "描述你最大的成交额。"

### 标准问题

**关于你：**
- "告诉我关于你的事情。"（2分钟介绍）
- "带我走过你的简历。"
- "你为什么想找新的工作？"
- "你5年后希望自己是什么样子？"

**关于职位：**
- "为什么这个职位？"
- "你对这个职位有什么兴趣？"
- "你认为这个职位包含什么？"
- "你上任后90天会做什么？"

**关于公司：**
- "为什么这家公司？"
- "你了解我们吗？"
- "你为什么想在这里工作？"
- "你对我们使命有什么兴奋之处？"

## 要问面试官的问题

### 对于招聘经理
- "在这个职位上，30/60/90天的成功标准是什么？"
- "团队面临的最大挑战是什么？"
- "如何衡量绩效？"
- "团队结构是什么？"

### 对于团队成员
- "典型的一天/一周是什么样的？"
- "你最喜欢的工作是什么？"
- "团队如何协作？"
- "新员工需要知道什么？"

### 对于高管
- "公司下一年的战略是什么？"
- "这个团队如何为公司目标做出贡献？"
- "是什么让你对这家公司保持兴奋？"

### 要避免的问题
- ❌ 薪资/福利问题（留到HR）
- ❌ 你可以轻松搜索到的问题
- ❌ 关于公司问题的负面问题
- ❌ 是/否问题（问开放式问题）

## 处理困难问题

### "你最大的弱点是什么？"

**公式：** 真实的弱点 + 自我认知 + 改进措施

```
"我倾向于过于注重细节，这有时会让我放慢速度。我意识到了这一点，现在为任务设定时间限制，并询问何时足够好。在我的当前职位上，我也学会了在适当的时候分配详细工作。"
```

### "你为什么离开现在的公司？"

**保持：**
- 积极的（以成长为导向）
- 前瞻性的（不是抱怨）
- 简洁的（不要过多解释）

```
"我在[公司]学到了很多东西，但我正在寻找[具体机会]，在我当前的路径上看不到。这个职位在[公司]正好提供了这个机会——有机会[具体事情]。"
```

### "告诉我一次你失败的经历"

**必须包括：**
- 真实的失败（不是谦虚的吹嘘）
- 你学到了什么
- 你如何应用学习

```
"在我担任产品经理的第一年，我未经充分的用户研究就推出了一个功能。这个功能在技术上很完善，但用户觉得它很困惑。只有10%的人使用它。我痛苦地意识到，构建正确的东西比正确地构建东西更重要。从那时起，我从不跳过用户研究——我现在在做出重大功能决定之前总是至少进行10次用户访谈。"
```

### 薪资问题

**推迟回答直到必须回答：**

```
"我对薪酬很灵活，更关注找到合适的工作。你能分享这个职位预算的范围吗？"
```

**如果被追问：**
```
"根据我的研究和经验，我期望的薪资范围是X-Y，但我愿意讨论完整的薪酬包。"
```

## 实施清单

为了完整的面试准备：
1. ✅ 分析职位描述以确定能力
2. ✅ 创建8-10个STAR故事，涵盖所有能力
3. ✅ 写"告诉我关于你的事情"介绍
4. ✅ 准备可能问题的答案
5. ✅ 彻底研究公司
6. ✅ 准备有深度的问题
7. ✅ 大声练习（计时）
8. ✅ 准备后勤（着装、路线、技术检查）
9. ✅ 面试前一天复习
10. ✅ 面试后发送感谢信
