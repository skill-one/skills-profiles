# 薪酬谈判准备

## 使用此技能的时机

当用户想要：
- 谈判工作机会或薪资
- 研究其职位的市价
- 制定反要价策略
- 了解整体薪酬包
- 提及：“薪酬谈判”、“谈判机会”、“反要价”、“薪酬”、“我应该要求多少”

## 核心功能

- 研究和验证市场薪酬
- 制定谈判策略和脚本
- 计算整体薪酬（不只是基本工资）
- 准备反要价回复
- 识别谈判杠杆点
- 应对困难的薪酬对话

## 谈判心态

**关键原则：**
1. 谈判是预期中的 - 公司会为此预算
2. 84% 的雇主期望候选人谈判
3. 不谈判会在整个职业生涯中损失 50 万至 100 万美元
4. 目标是双赢，而不是对抗

**你真正谈判的：**
- 基本工资
- 签约奖金
- 年度奖金/佣金
- 股权（股票期权、限制性股票单位）
- 福利（401k 补贴、保险）
- 补偿（休假、远程工作、职业发展）
- 开始日期
- 职位

## 研究阶段

### 第 1 步：确定市场价位

**需要检查的来源：**
- Levels.fyi（最适合科技行业）
- Glassdoor（综合，需谨慎对待）
- LinkedIn Salary
- Blind（匿名报告）
- PayScale
- Salary.com
- H1B 薪酬数据（公开可用）

**建立范围：**
```
低（25 分位）：$XXX,XXX
目标（50 分位）：$XXX,XXX  
高（75 分位）：$XXX,XXX
拉伸（90 分位）：$XXX,XXX
```

### 第 2 步：了解自身价值

**提高你价值的因素：**
- 相关经验年数
- 专业化/稀缺技能
- 结果记录
- 高需求认证
- 当前竞争性报价
- 员工推荐
- 你所在领域的市场需求

**可能限制价值的因素：**
- 入门级或职业转换
- 经验不如理想候选人
- 必要技能的差距
- 地理位置差异（生活成本较低）

### 第 3 步：计算整体薪酬

**总薪酬 = 基本工资 + 奖金 + 股权 + 福利**

```
示例：
基本工资：$150,000
目标奖金（15%）：$22,500
RSU 授予（4 年）：$200,000（每年 $50,000）
401k 补贴（4%）：$6,000
福利价值：~$15,000

总年度薪酬：$243,500
```

**常见股权条款：**
- **RSU：** 限制性股票单位（真实股份，在归属时纳税）
- **期权：** 购买权（价值 = 当前价格 - 行权价）
- **归属：** 通常 4 年，1 年分水岭
- **刷新授予：** 年度额外股权授予

## 谈判策略

### 何时谈判

**最佳时机：** 收到书面报价后，签字前

**时间线：**
1. 收到口头报价 → 表达热情，要求书面报价
2. 收到书面报价 → 感谢他们，要求审查时间
3. 研究和准备 → 24-48 小时
4. 反要价 → 通过邮件或电话
5. 讨论/来回 → 可能需要多轮
6. 最终协议 → 书面形式

### 反要价框架

**结构：**
1. 表达热情
2. 强化你的价值
3. 提出具体要求
4. 提供理由
5. 开放讨论

### 反要价邮件模板

```
主题：[你的名字] - 报价讨论

嗨 [招聘人员/招聘经理]，

非常感谢您提供加入 [公司] 担任 [职位] 的机会。我对 [关于职位的特定方面] 的机会非常兴奋。在与团队交谈并了解更多关于 [特定内容] 后，我确信这是正确的选择。

我已经有时间审查报价细节，并想讨论薪酬。根据我对市场和我的 [X 年经验 / 特定有价值技能 / 竞争性报价] 的研究，我希望我们能讨论基本工资为 $[你的要求] 而不是 $[他们的报价]。

[可选：添加具体理由 - 例如，“我看到类似职位在 [可比公司] 中的这个价位”或“鉴于职位的范围和我的 [具体成就] 记录，我认为这反映了我的价值。”]

我愿意并开放讨论套餐的其他要素。您有时间进行简短通话吗？

再次感谢这个机会。我期待找到一个对双方都合适的套餐。

最好的，
[你的名字]
```

### 反要价通话脚本

```
“嗨 [名字]，感谢您抽出时间。我对这个机会真的很兴奋 - [真诚的特定理由]。

我已审查报价并想讨论薪酬。根据我的市场研究和 [X 年经验 / 关键成就 / 竞争性报价]，我希望基本工资接近 $[金额]。

有灵活性吗？”

[倾听 - 让他们回应]

[如果他们反对:]
“我理解有约束。我灵活 - 我们能看看其他要素，如签约奖金、股权或 [其他要素] 来弥补差距吗？”

[如果他们说需要时间确认:]
“这完全公平。什么时候重新联系合适？”

```

## 常见谈判场景

### 场景 1：第一报价偏低

**方法：**
- 不要立即接受
- 表达对职位的热情
- 用研究支持的数量反要价
- 准备好解释

**脚本：**
```
“我对这个机会感到非常兴奋。基本工资低于我的预期。对于这个职位和市场，我期望的是 $X-$Y 范围。有空间接近 $X 吗？”
```

### 场景 2：他们先问你的薪资期望

**转移策略：**
```
“我很有弹性，专注于找到合适的职位。你们为这个职位预算了多少？”
```

**如果被追问:**
```
“根据我对这个职位和市场的调查，我期望的是 $X-$Y，但我愿意讨论完整的薪酬图景。”
```

### 场景 3：他们不愿让步基本工资

**谈判替代方案：**
- 签约奖金（一次性，更容易批准）
- 额外股权
- 更早绩效评估（更快加薪）
- 更多休假天数
- 远程工作灵活性
- 职业发展预算
- 职位升级
- 安家补助
- 开始日期

**脚本：**
```
“我理解基本工资是固定的。我们能讨论一笔签约奖金来弥补差距吗？大约 $X 范围会让我接受。”
```

### 场景 4：你有竞争性报价

**谨慎使用：**
- 只有在真实的情况下才提及
- 不要使其成为威胁
- 以解决问题的方式提出

**脚本：**
```
“我想保持透明 - 我还在与 [另一家公司/几家公司] 讨论。他们提供 $X。[你的公司] 是我的首选，因为 [真诚的理由]，但我希望薪酬具有竞争力。”
```

### 场景 5：他们询问当前薪资

**在许多州，这个问题是违法的**

**如果被问（且合法）：**
```
“我宁愿专注于我能为这个职位带来的价值以及市场价位。你们预算了多少？”
```

**或转移话题:**
```
“我当前的薪酬与这个职位/地点/结构不太可比。根据我对这个职位的研究，我目标是 $X-$Y。”
```

## 谈判技巧

### 该做的：
- ✅ 总是谈判（尊重地）
- ✅ 谈判前获得书面报价
- ✅ 彻底研究
- ✅ 用数字具体说明
- ✅ 表达真诚的热情
- ✅ 给他们一个说“是”的方式
- ✅ 考虑整体薪酬
- ✅ 保持耐心 - 过程需要时间
- ✅ 将最终协议书面化

### 不该做的：
- ❌ 立即接受
- ❌ 提供薪资历史（如果法律未要求）
- ❌ 做最后通牒
- ❌ 谎言关于竞争性报价
- ❌ 无礼或攻击性
- ❌ 为了谈判而谈判
- ❌ 不经书面确认接受口头承诺
- ❌ 如果不成功则烧毁桥梁

## 整体薪酬比较

### 对比分析

```markdown
## 报价对比

| 要素 | 公司 A | 公司 B | 备注 |
|-------|--------|--------|------|
| 基本工资 | $150,000 | $140,000 | A 胜 |
| 目标奖金 | 15% ($22,500) | 20% ($28,000) | B 胜 |
| 签约奖金 | $20,000 | $10,000 | A 胜 |
| 股权（年度） | $50,000 | $75,000 | B 胜 |
| 401k 补贴 | 4% ($6,000) | 6% ($8,400) | B 胜 |
| 福利 | 标准 | 高级 | B 胜 |
| 远程办公 | 混合（3 天） | 全远程 | B 胜 |
| 休假 | 3 周 | 无限 | 取决于 |

**第一年总薪酬：**
公司 A：$248,500
公司 B：$261,400

**分析：** 公司 B 总薪酬更高，但公司 A 基本工资更高，这会影响未来的加薪和购房资格。
```

## 谈判时间线模板

```
第 1 天：收到报价
- 感谢他们，表达热情
- 要求书面报价
- 要求回复截止日期

第 1-3 天：研究
- 验证市场价位
- 计算整体薪酬
- 确定优先事项
- 准备反要价

第 3-5 天：反要价
- 发送反要价邮件或安排通话
- 具体说明要求

第 5-10 天：讨论
- 可能需要多轮
- 保持耐心但及时回应
- 保持专业和积极

第 10 天后：解决
- 达成协议
- 将所有内容书面化
- 签署并庆祝！
```
