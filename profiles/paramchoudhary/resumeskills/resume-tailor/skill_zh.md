# 简历定制工具

## 使用场景

当用户需要以下操作时，请使用此技能：
- 针对特定职位定制简历
- 调整简历以匹配职位要求
- 创建有针对性的简历版本
- 提及："定制简历"、"调整简历"、"针对职位"、"特定职位"、"匹配职位描述"

在使用前，请先使用职位描述分析器了解需要强调的内容。

## 核心功能

- 根据目标职位相关性重新排序经验部分
- 针对特定职位调整专业概要
- 从职位描述中添加缺失的关键词
- 修改要点以匹配职位要求
- 在优化匹配度的同时保持真实性
- 创建多个有针对性的简历版本

## 定制理念

**核心原则：** 你不是在撒谎或编造 - 你是在突出你真实经验中最相关的内容。

将你的完整经验视为一个成就图书馆。定制意味着选择最适合每位雇主需求的书籍。

## 定制流程

### 第一步：分析职位（使用职位描述分析器先进行分析）
- 确定所需技能和关键词
- 注意公司的优先事项
- 了解职位的主要职责

### 第二步：审核你的简历
针对每个部分，问自己：
- 这是否支持我申请这个特定职位？
- 是否有更好的方式来表述这个职位？
- 是否应该提高或降低优先级？

### 第三步：进行战略性调整

**专业概要：** 重写以匹配职位的关键要求

**技能部分：** 重新排序，将最相关的技能放在前面，添加缺失的关键词

**经验：**
- 如果一个较不近期的职位更相关，则重新排序工作经历
- 交换要点，以突出最相关的成就
- 自然地将关键词添加到现有要点中

**教育背景：** 突出相关的课程、证书

## 分部分定制指南

### 专业概要

这是你的"电梯演讲" - 针对每个申请进行定制。

**通用概要（避免使用）：**
```
结果导向的专业人士，拥有5年业务运营经验。具备强大的分析和沟通能力。寻求具有挑战性的机会以实现个人成长。
```

**针对运营经理职位的定制：**
```
拥有5年优化供应链流程并降低成本25%的运营经理。精通精益六西格玛、供应商管理以及跨职能团队领导。在提高运营效率的同时保持质量标准的记录。
```

**针对项目经理职位的定制（同一个人）：**
```
拥有5年从概念到交付领导跨职能计划的专业人士。PMP认证，精通敏捷方法、利益相关者管理以及预算监督。在超过10M美元的投资组合中实现按时、预算内项目交付的记录。
```

### 技能部分重新排序

**职位描述强调：** 数据分析、SQL、Python、利益相关者沟通

**之前（通用顺序）：**
```
技能：Microsoft Office、沟通、项目管理、Python、SQL、数据可视化、领导力
```

**之后（定制顺序）：**
```
技能：SQL、Python、数据分析、数据可视化、利益相关者沟通、项目管理、Microsoft Office
```

### 经验部分

**策略1：重新排序工作经历**

如果你的最近工作与申请的职位不太相关：

**之前：**
1. 市场协调员（目前，但申请数据职位）
2. 数据分析师（之前，高度相关）

**之后：**
1. 数据分析师（标注日期，提升至前位）
2. 市场协调员（仍然包含，但次要）

**策略2：交换要点顺序**

以与目标职位最相关的要点开头。

**申请管理职位 - 以以下要点开头：**
- "领导12人的团队..."
- "管理200万美元的预算..."

**申请技术职位 - 以以下要点开头：**
- "开发了自动化系统..."
- "分析了50万+数据点..."

**策略3：调整要点语言**

在保持真实的同时，融入职位描述关键词。

**职位描述说：** "利益相关者管理"
**你的要点说：** "与不同团队合作"
**定制版本：** "管理5个部门的利益相关者关系，确保项目优先级的对齐"

## 常见定制场景

### 场景1：非技术公司的技术职位

**挑战：** 他们需要技术技能，但也需要商业头脑

**策略：**
- 以技术成就开头
- 在每个技术要点中包含商业影响
- 添加"将技术概念翻译给商业利益相关者"

### 场景2：管理职位（但你做过IC和管理工作）

**挑战：** 展示领导力，同时不放弃技术信誉

**策略：**
- 概要：强调领导力
- 经验：以团队管理要点开头
- 保留一些技术要点，以显示你了解工作

### 场景3：初创公司（但你曾在大公司工作）

**挑战：** 展示你能在模糊性和多任务处理中茁壮成长

**策略：**
- 突出跨职能工作
- 强调主动性和自我启动
- 展示灵活、创造性的问题解决能力
- 减少对严格流程和大团队结构的强调

### 场景4：大公司（但你曾在初创公司工作）

**挑战：** 展示你能在结构和规模下工作

**策略：**
- 强调流程改进
- 突出可扩展的工作
- 显示跨团队协作
- 添加显示规模影响的指标

## 关键词整合规则

### 要做：

- 添加真实描述你工作的关键词
- 当准确时，使用职位描述中的确切措辞
- 自然地将关键词放在上下文中
- 在概要、技能、经验中多次包含关键词

### 不要做：

- 添加你没有的技能
- 关键词堆砌（重复同一个术语10次）
- 创建与实际经验不同的含义
- 牺牲可读性以换取关键词密度

## 真实性与定制界限

**可接受的定制：**
- 重新排序真实信息
- 强调相关的经验
- 使用行业标准术语
- 为模糊的陈述添加背景
- 使语言风格与职位描述匹配

**不可接受（撒谎）：**
- 添加你没有的技能
- 改变数字或指标
- 创建虚假经历
- 声称你没有持有的头衔
- 声称你没有的证书

## 版本管理

### 维护主简历
- 保持一个包含所有经历的完整文档
- 包含你写过的每个要点
- 这是你的"事实来源"

### 创建目标版本
- 清晰命名文件： "JohnSmith_Resume_ProductManager_TechCorp.pdf"
- 跟踪哪个版本发送给了哪家公司
- 保存定制笔记以备面试准备

### 版本命名规范
```
[LastName]_Resume_[TargetRole]_[Company]_[Date].pdf

示例：
- Smith_Resume_PM_Google_Jan2024.pdf
- Smith_Resume_DataAnalyst_Meta_Jan2024.pdf
- Smith_Resume_General_Master.docx (你的主文件)
```

## 快速定制检查清单

提交任何简历前：

1. ✅ 概要提到了确切的职位名称/功能
2. ✅ 顶部5个技能与职位描述的前5个要求匹配
3. ✅ 最相关的经验放在首位
4. ✅ 每个职位的顶级要点都解决了职位的关键要求
5. ✅ 职位描述中的关键词自然地出现在全文中
6. ✅ 正确使用公司/行业术语
7. ✅ 所有声明都是真实的
8. ✅ 文件命名适当
9. ✅ ATS格式保持一致
10. ✅ 保存以备面试准备参考
