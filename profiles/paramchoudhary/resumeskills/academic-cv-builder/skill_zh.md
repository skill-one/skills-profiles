# 学术简历构建器

## 使用此技能的场景

当用户：
- 申请学术职位（教职、研究、博士后）
- 需要创建或更新简历
- 想要格式化出版物、资助和教学经历
- 在学术界或转向学术职业
- 提及：“学术简历”、“简历”、“教职职位”、“研究简历”、“教授简历”

## 核心功能

- 为学术职位构建简历结构
- 格式化出版物、演示和资助
- 组织教学和研究经历
- 包含适当的学术部分
- 针对不同学术角色定制（tenure-track、博士后、讲师）
- 平衡研究、教学和服务

## 学术简历与简历的区别

| 简历 | 学术简历 |
|------|--------|
| 1-2页 | 2-20+页（长度随职业增长） |
| 突出相关经验 | 全面记录 |
| 结果导向 | 奖学金导向 |
| 行业关键词 | 学科专长 |
| 技能部分突出 | 发表物突出 |
| 教育信息简略 | 教育信息详细 |

## 标准学术简历部分

### 典型顺序

```
1. 联系信息
2. 教育背景
3. 研究/学术职位
4. 发表物
5. 演讲
6. 资助与资金
7. 教学经历
8. 指导
9. 服务
10. 专业会员资格
11. 荣誉与奖项
12. 推荐信（或“按需提供”）
```

### 部分顺序因以下因素变化：
- **研究职位**：发表物、资助、研究经历优先
- **教学职位**：教学、课程开发优先
- **行政职位**：领导力、服务优先

### 4. 发表物

**对研究职位最重要的部分**

#### 格式选项

**选项1：编号列表（科学领域常见）**
```
发表物

同行评审期刊文章

15. 姓氏，F.M.，合著者，A.B.，& 高级，C.D. (2023). 文章标题。期刊名称，45(2)，123-145。doi:10.1000/xyz

14. 姓氏，F.M.，& 合著者，A.B. (2022). 文章标题。期刊名称，44(1)，10-25。doi:10.1000/abc
```

**选项2：分类（适用于多种类型）**
```
发表物

同行评审期刊文章（15）

书籍章节（3）

书籍（1）

审稿中（2）

准备中（3）
```

**格式细节**：
- **突出你的名字**在作者列表中
- 可用时包含DOI
- 如有要求/相关，注明影响因子
- 标记学生合著者*
- 某些领域要求倒序时间；其他领域要求时间顺序

**考虑分类**：
- 同行评审期刊文章
- 书籍和书籍章节
- 会议论文集
- 技术报告
- 非同行评审出版物
- 审稿中作品
- 准备中作品

## 角色特定强调

### Tenure-Track 教授

**强调**：
1. 发表物（尤其是近期、高影响力）
2. 资助（尤其是独立资助）
3. 研究轨迹和愿景
4. 教学经历
5. 指导记录

### 博士后职位

**强调**：
1. 发表物（博士和博士后期间）
2. 研究经验和技能
3. 合作经验
4. 未来研究潜力
5. 任何资助/奖学金

### 讲师/教学教职

**强调**：
1. 教学经历（课程、评估）
2. 课程开发
3. 教学培训
4. 指导本科生
5. 教学奖项

### 研究科学家

**强调**：
1. 发表物
2. 技术技能
3. 资助写作经验
4. 合作记录
5. 相关研究经验

## 学科特定惯例

### 科学（生物学、化学、物理学）
- 作者顺序很重要（第一作者、最后作者=资深）
- 有时包含影响因子
- 编号发表物列表常见
- 会议演讲不如发表物重要

### 人文（历史、文学、哲学）
- 单作者发表物高度重视
- 书籍发表物至关重要
- 会议演讲很重要
- 公共学术价值

### 社会科学
- 单独和合作工作都重视
- 混合期刊文章和书籍
- 资助研究很重要
- 政策影响很重要

## 简历长度指南

| 职业阶段 | 预期长度 |
|---------|---------|
| 研究生 | 2-4页 |
| 博士后 | 3-6页 |
| 早期职业教职 | 5-10页 |
| 中期职业教职 | 10-20页 |
| 高级教职 | 15-30+页 |

**规则**：你的简历会随着你的职业发展而增长。不要填充，但不要人为限制长度。
