# 简历ATS优化器

## 使用此技能的场景

当用户需要时使用此技能：
- 优化其简历以适应申请人追踪系统（ATS）
- 检查其简历能否通过自动筛选
- 了解为何其申请未获回复
- 提及关键词：ATS、未获得面试机会、简历无效、优化简历、关键词优化

当用户提供简历文件并提及正在求职时也使用此技能。

## 核心功能

- 解析简历并测试ATS兼容性
- 提取并分析职位描述中的关键词
- 识别导致ATS解析器失效的格式问题
- 计算简历与职位发布的匹配分数
- 建议关键词的添加和位置
- 生成ATS友好的格式建议

## ATS问题

75%的简历在人类查看之前就被申请人追踪系统拒绝了。公司使用ATS的原因：
- 自动筛选不合格候选人
- 搜索职位要求中的特定关键词
- 将简历解析为结构化数据
- 按关键词匹配百分比对候选人进行排名

简历无法通过ATS的常见原因：
1. 格式不佳（表格、列、页眉/页脚）
2. 缺少职位描述中的关键词
3. 章节标题不一致
4. 非标准字体或特殊字符
5. 文本嵌入在图片中
6. 文件格式不正确

## ATS兼容性检查清单

### 文件格式
- ✅ 使用.docx或.pdf（不要.pages、.odt）
- ✅ PDF必须是文本格式，不是扫描图像
- ✅ 文件名："FirstName_LastName_Resume.pdf"

### 字体和格式
- ✅ 标准字体：Arial、Calibri、Georgia、Times New Roman
- ✅ 字体大小：10-12pt用于正文，14-16pt用于标题
- ✅ 无文本框、表格或列
- ✅ 无页眉/页脚（将联系信息放在正文）
- ✅ 无图片、图形或图表
- ✅ 日期格式一致（MM/YYYY）
- ✅ 标准项目符号（•、-、*）

### 章节标题
使用标准、可识别的标题：
- ✅ "专业经验"或"工作经验"（不是"我去过哪里"）
- ✅ "教育"（不是"学术背景"）
- ✅ "技能"（不是"核心能力"）
- ✅ "摘要"或"专业摘要"

### 联系信息
```
约翰·史密斯
email@example.com | (555) 123-4567 | LinkedIn: linkedin.com/in/johnsmith
旧金山，CA
```

不在页眉/页脚，并避免：
- ❌ 用表格表示联系信息
- ❌ 邮箱中包含特殊字符
- ❌ 多个电话号码
- ❌ 完整的邮寄地址（城市/州足够）

## 关键词优化流程

### 第一步：提取职位描述中的关键词

识别三种类型的关键词：

**硬技能（技术）**
- 编程语言（Python、Java、SQL）
- 工具和平台（Salesforce、AWS、Excel）
- 认证（PMP、CPA、CFA）
- 方法论（敏捷、六西格玛、SDLC）

**软技能**
- 领导力、协作、沟通
- 问题解决、分析思维
- 项目管理、利益相关者管理

**行业术语**
- B2B、SaaS、电子商务
- 企业、中小企业、中市场
- ARR、MRR、流失率

### 第二步：匹配分析

对于职位描述中的每个关键词：
1. 检查简历中是否出现确切短语
2. 检查同义词或变体
3. 计数提及频率
4. 记录位置（摘要、经验、技能）

### 第三步：计算匹配分数

```
匹配分数 = (匹配关键词数 / 总要求关键词数) × 100

示例：
职位有20个要求关键词
您的简历有15个
匹配分数 = 75%

目标：80%+为强匹配
```

### 第四步：关键词位置策略

**优先级1：专业摘要（简历顶部）**
- 包含5-8个最重要的关键词
- 自然地使用在3-4句段落中
- 示例："数据科学家，5年以上使用Python、SQL和机器学习驱动业务洞察的经验..."

**优先级2：技能部分**
- 明确列出关键词
- 如有必要按类别分组
- 使用职位描述中的确切措辞

**优先级3：经验要点**
- 将关键词融入成就声明
- 不要强行插入关键词
- 在整个简历中使用变体

**关键词密度指南：**
- 关键关键词：在整个简历中出现2-4次
- 重要关键词：出现1-2次
- 不要关键词堆砌 - 保持自然
- 变化措辞（例如："领导团队"和"团队领导"）

## 分析输出格式

分析简历时，提供此结构化报告：

```markdown
# ATS 兼容性报告

## 总分：[X]/100

### 文件格式检查 ✅/❌
- 格式：[DOCX/PDF]
- 文本提取：[成功/失败]
- 文件大小：[X KB/MB]

### 格式问题
✅ 未检测到表格或列
❌ 联系信息在页眉（移至正文）
⚠️ 技能部分有两种不同的字体大小

### 关键词分析

职位要求 vs 您的简历：

**关键关键词（必须）：**
✅ 项目管理 - 发现3次
✅ 敏捷/Scrum - 发现2次
❌ 利益相关者管理 - 缺失（职位描述中提及5次）
❌ 预算管理 - 缺失（职位描述中提及3次）

**重要关键词：**
✅ 跨职能团队 - 发现1次
⚠️ "风险管理" - 您有"风险缓解"（接近但不完全匹配）
✅ 流程改进 - 发现2次

**匹配分数：65%**
目标：80%+建议

### 建议修改

**1. 添加缺失关键词：**

在专业摘要中更改：
"经验丰富的项目经理，有良好的业绩..."

改为：
"经验丰富的项目经理，在利益相关者管理和预算监督方面有良好的业绩..."

在经验部分添加要点：
"管理跨3个部门的利益相关者沟通和执行领导团队"
"指导2.5M项目组合的预算管理"

**2. 修复格式：**
- 将联系信息从页眉移至简历正文
- 使所有技能部分项目字体大小相同（目前混合10pt和11pt）

**3. 加强现有关键词：**
将"风险缓解"改为"风险管理"以实现确切匹配

### 预计新匹配分数：85%
```

## 常见的ATS失败模式

### 模式1：创意格式
```
❌ 问题：
[两列布局带图形]
[技能条和熟练度图表]
[彩色框中的文本]

✅ 解决方案：
- 单列布局
- 纯文本技能列表
- 简单项目符号
```

### 模式2：非标准章节名称
```
❌ 问题：
"我的旅程"（而不是经验）
"我能带来的价值"（而不是技能）
"学术追求"（而不是教育）

✅ 解决方案：
使用ATS可识别的标准标题
```

### 模式3：缺失关键词
```
❌ 问题：
职位要求："Python、SQL、数据可视化"
简历说："编程、数据库、制作图表"

✅ 解决方案：
使用职位描述中的确切术语
```

### 模式4：关键词堆砌
```
❌ 问题：
技能："Python、Python编程、Python开发人员、Python专家、Python专家、高级Python..."

✅ 解决方案：
技能："Python、SQL、JavaScript、React、Node.js"
（然后在要点中自然融入）
```

## 行业特定注意事项

### 技术简历
- 强调编程语言和框架
- 在技能部分包含GitHub、作品集链接（不要在页眉）
- 认证和课程非常重要

### 商业/金融
- 专注于软件熟练度（Excel、SAP、Salesforce）
- 认证至关重要（CPA、CFA、PMP）
- 行业关键词（损益表、投资回报率、关键绩效指标）

### 医疗保健
- 需要执照和认证
- 特定系统（Epic、Cerner、MEDITECH）
- 合规关键词（HIPAA、联合委员会）

### 营销
- 平台专业知识（HubSpot、Salesforce、Google Analytics）
- 渠道关键词（SEO、PPC、电子邮件营销）
- 结果导向语言

## 边缘案例和特殊情况

### 职业转换者
- 专注于可转移技能
- 使用目标行业的关键词，而不仅仅是当前行业
- 可能需要两个ATS简历版本

### 毕业生
- 教育部分成为关键词优先级
- 包括相关课程、项目
- 实习经验算作经验 - 使用这些关键词

### 高管级别
- ATS对高级职位仍然重要
- 专注于战略关键词
- 包括董事会经验、损益表规模、团队规模

### 雇佣空白
- 如果有助于使用年份（而不是月份）
- 包括自由职业/咨询与关键词
- 志愿工作可以包含相关关键词

## 实施检查清单

帮助用户优化ATS时：

1. ✅ 扫描当前简历的ATS兼容性问题
2. ✅ 分析职位描述中的所需关键词
3. ✅ 计算当前匹配分数
4. ✅ 确定具体缺失的关键词
5. ✅ 建议新关键词的确切位置
6. ✅ 标记格式问题
7. ✅ 提供前后示例
8. ✅ 建议更改后重新评分
9. ✅ 验证文件格式和命名
10. ✅ 如有可能使用ATS模拟器测试

## 成功指标

优化后，简历应：
- 对目标职位描述达到80%+的匹配分数
- 通过ATS解析测试（所有章节被识别）
- 无格式错误
- 包含所有关键关键词2-4次
- 自然阅读（不是关键词堆砌）
- 立即准备提交
