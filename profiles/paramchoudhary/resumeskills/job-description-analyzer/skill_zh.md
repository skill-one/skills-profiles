# 工作描述分析器

## 何时使用此技能

当用户：
- 想要分析职位发布
- 询问"我应该申请这个工作吗？"
- 想要了解自己在某个职位上的匹配度
- 需要帮助理解工作要求
- 想要为特定职位量身定制简历
- 提及："分析这个工作"、"我符合条件吗"、"匹配分数"、"我应该申请"

在定制简历之前使用此技能，以确保付出的努力是值得的。

## 核心功能

- 提取和分类工作要求（必需品与可选项）
- 计算用户的经验和工作要求之间的匹配分数
- 识别技能差距和优势
- 检测职位发布中的警示信号
- 优先考虑哪些经验要突出
- 生成简历定制策略
- 创建求职信要点
- 评估公司文化契合度指标

## 战略性问题

大多数求职者浪费时间在：
- 不符合资格的工作（匹配度<60%）
- 资格过高（离职风险）
- 有警示信号的工作（高离职率、有毒文化）
- 盲目申请50多个工作，希望有收获

更好的方法：
- 策略性地申请10-15个工作
- 目标是匹配度70-90%的工作
- 每个职位都要深度定制
- 更高的回复率，更少的倦怠

## 分析流程

### 第一步：提取要求

将职位描述分为以下类别：

**必需品（必须具备）**
- 教育要求
- 工作经验年数
- 特定技术技能
- 证书/执照
- 行业经验

**可选项（可选项）**
- "加分项"技能
- 高级证书
- 领域专业知识
- 特定工具经验

**软技能/文化**
- 沟通风格
- 工作环境
- 团队结构
- 公司价值观

### 第二步：关键词提取

识别三种类型：

**硬技能**（技术能力）
- 工具：Salesforce、Python、AWS、Excel
- 方法论：敏捷、六西格玛、SDLC
- 证书：PMP、CPA、AWS认证

**软技能**（人际交往能力）
- 领导力、协作、沟通
- 问题解决、批判性思维
- 适应能力、主动性

**行业/领域知识**
- B2B SaaS、医疗保健、金融科技
- 大型企业与中小企业
- 监管知识（HIPAA、SOX、GDPR）

### 第三步：计算匹配分数

```
匹配计算：

必需技能：
- 用户有10个中的8个必需技能 = 80%

可选项技能：
- 用户有5个中的3个可选项 = 60%

总体匹配度：
- 必需技能权重70%，可选项权重30%
- (80% × 0.7) + (60% × 0.3) = 74%

解释：
90-100% = 资格过高（可能有离职风险）
75-89% = 非常匹配（立即申请）
60-74% = 良好匹配（需要强有力的求职信）
50-59% = 拉伸角色（如果热情可以申请）
<50% = 不符合资格（除非是梦想工作）

```

### 第四步：差距分析

对于每个缺失的要求：
- **关键差距**：无法接受（不要申请）
- **主要差距**：显著但可以弥补（在求职信中提及）
- **次要差距**：容易学习（淡化或强调相关技能）

### 第五步：警示信号检测

扫描警告信号：

**工作量警示信号：**
- "身兼数职"
- "快节奏环境"
- "快速上手"
- "在模糊情况下自我驱动"

**文化警示信号：**
- "摇滚明星/忍者/大师"
- "努力工作，尽情玩乐"
- "无限假期"
- "像家庭一样"

**薪酬警示信号：**
- "有竞争力的薪酬"（不会告诉你范围）
- "股权为主"（低现金薪酬）
- "佣金制"（没有基本工资）
- "DOE"但没有范围

**关键差距**：无 ✅

## 警示信号分析

### 潜在担忧：⚠️ 轻微

**警示信号1：** "快节奏环境"
- 描述中提到2次
- 解释：可能是初创公司或高增长

**警示信号2：** 薪酬范围较宽（$140K-$180K）
- 29%的差距
- 可能意味着：经验范围灵活，或谈判空间

## 决策因素

### 申请理由 ✅

1. 强匹配（78%）- 您符合大多数要求
2. 职位与职业目标一致
3. 薪酬范围适合您的经验
4. 公司阶段符合您的偏好
5. 您有独特的相关经验（开发者工具）

### 犹豫理由 ⚠️

1. SQL差距确实存在 - 准备好解释
2. "快节奏"可能意味着高压力
3. 需要更多研究公司文化

### 总体建议：

**申请 - 这是一个很好的机会**

您符合80%的必需技能和67%的可选项技能。您的开发者工具和B2B SaaS经验使您成为差异化候选人。SQL差距可以通过诚实和强调您的分析技能来弥补。在职位发布新鲜时（48小时内）申请。

## 要求分类指南

### 识别"必需品"与"可选项"

**表示必需的语言：**
- "必须..."
- "必需：X年..."
- "您有..."
- "基本资格"
- 列在"要求"下
- 在描述中提到3次以上

**表示可选项的语言：**
- "可选项..."
- "如果有加分..."
- "可选项资格"
- "理想情况下，您会有..."
- "如果有..."
- 提到1-2次

### 决定性警示信号

**绝对决定性警示信号（不要申请）：**
- 您没有的必需执照（医疗、法律、CPA）
- 您无法获得的必需许可
- 工作经验低于要求50%以上
- 您没有的必需学位（当声明为"必需"时）
- 您无法满足的地点要求

**不是决定性警示信号（仍然可以申请）：**
- 经验略低于要求（例如，3年而他们要5年）
- 您没有的"可选项"学位
- 您可以学习的"可选项"工具/技能
- 行业经验，但您有可转移技能

## 边缘情况

### 模糊的职位描述
- 标记为潜在警示信号
- 提取尽可能多的关键词
- 建议在申请前联系以澄清
- 使用行业标准要求作为基准

### 一个职位描述中包含多个角色
- 识别核心角色与"其他职责"
- 专注于主要职责的匹配分数
- 标记范围蔓延问题

### 内部职位（已经在那里工作）
- 不同策略 - 强调内部知识
- 突出跨团队关系
- 提及特定公司计划

### 重新发布的工作
- 可能意味着：之前的员工没有工作，角色扩大，或第一次搜索失败
- 值得申请，但要研究重新发布的原因
- 检查要求是否与原始发布相比有所变化
