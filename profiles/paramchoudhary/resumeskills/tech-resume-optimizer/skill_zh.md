# 技术简历优化器

## 使用此技能的场景

当用户：
- 申请软件工程职位
- 希望优化技术简历
- 需要开发者/项目经理/技术岗位申请帮助
- 提及："技术简历"、"软件工程师简历"、"开发者简历"、"技术简历"、"SWE简历"、"PM简历"

## 核心功能

- 优化技术岗位（SWE、PM、数据、DevOps）的简历
- 有效构建技术技能部分
- 突出项目和技术成就
- 平衡技术深度与商业影响
- 适配ATS和技术招聘人员格式
- 包含GitHub、作品集和技术链接

## 技术简历理念

**技术招聘人员关注的内容：**
1. 相关技术技能（语言、框架、工具）
2. 规模和影响（用户数、交易量、数据量）
3. 问题解决能力
4. 系统设计理解
5. 协作能力
6. 成长轨迹

## 技术简历结构

### 推荐顺序

```
1. 联系信息（包括GitHub、作品集）
2. 职业概要（可选但有助于）
3. 技术技能（对ATS至关重要）
4. 工作经历（包含技术成就）
5. 项目（对早期职业尤其重要）
6. 教育
7. 证书（如相关）
```

## 技术岗位经历部分

### 技术要点公式

**[动作动词] + [技术内容] + [规模/影响] + [使用的技术]**

**示例：**

❌ **弱技术要点：**
```
- 参与后端服务
- 帮助提升系统性能
- 为产品构建功能
```

✅ **强技术要点：**
```
- 架构微服务迁移从单体应用，将部署时间从2小时缩短到15分钟，并实现独立团队部署
- 优化PostgreSQL查询并实现Redis缓存，将API延迟降低60%（从500ms到200ms），服务于100K日活跃用户
- 使用WebSockets和AWS SNS构建实时通知系统，每日处理1M+消息，交付率达99.9%
```

### 技术指标包含内容

**规模：**
- 用户： "服务500K DAU"
- 请求： "处理10K请求/秒"
- 数据： "每日处理50TB"
- 可用性： "保持99.99%可用性"

**性能：**
- 延迟： "从Xms缩短到Yms"
- 速度： "提升X%"
- 加载时间： "减少X秒"

**效率：**
- 成本： "降低AWS成本40%"
- 时间： "将部署时间从X缩短到Y"
- 资源： "减少内存使用X%"

**商业：**
- 收入： "功能驱动$XM收入"
- 转化率： "提升结账率X%"
- 参与度： "增加DAU X%"

## 项目部分

**对以下人员至关重要：**
- 初级工程师
- 职业转换者
- 创业营毕业生
- 任何有空白期的人

### 项目格式

```
项目名称 | 技术 | 链接
• 项目描述
• 技术亮点和解决的问题
• 规模或使用指标（如有）
```

### 示例项目部分

```
项目

分布式任务队列 | Python、Redis、Docker | github.com/user/taskqueue
• 构建处理每小时10K+任务的分布式任务队列，支持自动重试和死信队列
• 实现优先级队列和速率限制，支持多租户

• 支持百人以上并发用户的全栈聊天应用，实现实时消息
• 实现端到端加密和消息持久化

• 在1M+数据点上训练回归模型，价格预测准确率达92%
• 部署为REST API，实现自动模型重训练管道
```

### 好项目的要素

**包含：**
- 有真实用户的项目
- 开源贡献
- 技术博客文章
- 竞赛项目（尤其是获奖者）
- 复杂的个人项目

**不包含：**
- 教程跟随
- 重复的待办应用
- 未完成的项目
- 课程作业（除非特别突出）

## 技术特定建议

### GitHub个人资料优化

**确保你的GitHub显示：**
- 指定仓库（你最好的6个）
- 绿色贡献图（活跃度）
- 个人资料README
- 完整的项目README

**项目README应包含：**
- 项目做什么
- 使用的技术
- 如何运行
- 截图/演示
- 你的贡献（对于协作项目）

### 处理技术栈

**如果你匹配他们的技术栈：**
- 首先突出这些技术
- 量化你的经验

**如果你不完全匹配：**
- 强调可转移技能
- 展示学习能力
- 突出类似技术
- 示例："Django" → "丰富的Python Web框架经验（Django）；快速适应新框架"

### 技术面试准备提示

技术简历应支持你的面试：
- 只声称你能深入讨论的技术
- 准备好解释列出的每个项目
- 了解你构建的系统架构
- 准备好每个要点的故事

## ATS + 技术招聘人员平衡

记住：你的简历必须通过ATS和给技术招聘人员留下深刻印象。

**对ATS：**
- 包含精确技能关键词
- 使用标准部分标题
- 避免表格和图形

**对技术招聘人员：**
- 展示技术深度
- 包含指标和规模
- 展示问题解决能力
- 显示你理解系统
