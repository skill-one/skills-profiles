# 简历部分构建器

## 何时使用此技能

当用户需要：
- 帮助处理特定的简历部分
- 优化简历的某个部分
- 不确定在某个部分应包含哪些内容
- 需要针对特定部分的指导
- 提及："简历部分"、"技能部分"、"概述部分"、"经验部分"、"应包含哪些内容"

## 核心功能

- 构建有针对性的专业概述
- 有效构建技能部分
- 优化经验部分
- 合适地创建教育部分
- 策略性地添加补充部分
- 针对不同职业阶段调整各部分内容

## 专业概述部分

### 何时包含

**如果包含概述：**
- 职业转换者（需要解释转换过程）
- 高级专业人士（提炼长期职业经历）
- 重新进入职场者（弥补工作空缺）
- 高度专业化角色（强调匹配度）

**如果跳过概述：**
- 入门级且经验有限
- 职业发展路径直接
- 空间有限

### 概述框架

**公式：** [标题/身份] + [年数/经验] + [关键技能] + [价值主张]

### 按职业阶段划分

**入门级：**
```
来自加州大学伯克利分校的计算机科学应届毕业生，具有全栈开发的实习经验。精通 Python、React 和 AWS。希望利用学术项目在机器学习和用户界面应用开发方面在软件工程职位上发挥作用。
```

**中端职业：**
```
具有 6 年经验的产品经理，负责从概念到规模推动 B2B SaaS 产品。通过数据驱动的路线图优先级排序和跨职能领导，成功推出创造了 1000 万美元以上年经常性收入的多个产品。精通 API 产品、开发者工具和企业销售流程。
```

**高级/高管：**
```
具有 15 年以上经验的技术高管，在全球市场将工程组织从 50 人扩展到 500 人以上。在领导数字化转型计划、并购整合和平台现代化方面证明成功。负责 1 亿美元以上收入并记录 40% 以上的效率提升。
```

**职业转换者：**
```
具有 5 年顾问式销售经验并证明能够建立长期客户关系的销售专业人士，现正转型为客户成功领域。精通需求评估、解决方案设计和利益相关者管理。希望将关系建立专业知识应用于推动客户保留和扩张。
```

### 概述禁忌

- ❌ "寻求具有挑战性的职位..."
- ❌ "勤奋的团队合作者..."
- ❌ "以结果为导向的专业人士..."
- ❌ 第三人称 ("John 是一个...")
- ❌ 目标（你想要什么 vs. 你能提供什么）

## 技能部分

### 组织选项

**选项 1：简单列表**
```
技能
Python、JavaScript、SQL、React、Node.js、AWS、Docker、Git、敏捷、JIRA
```
最佳用途：ATS 优化、空间限制

**选项 2：分类**
```
技术技能
语言：Python、JavaScript、TypeScript、SQL
框架：React、Node.js、Django、FastAPI
云：AWS (EC2、S3、Lambda)、GCP、Docker、Kubernetes
工具：Git、JIRA、Confluence、Datadog
```
最佳用途：技术职位、广泛的技能组合

**选项 3：熟练程度**（谨慎使用）
```
技能
专家：Python、SQL、产品管理
高级：AWS、数据分析、利益相关者管理
熟练：机器学习、Figma、财务建模
```
最佳用途：需要特定熟练程度的职位、诚实表达

### 应包含的内容

**技术/硬技能：**
- 编程语言
- 软件和工具
- 方法论（敏捷、精益）
- 平台（Salesforce、SAP）
- 认证

**功能性技能：**
- 项目管理
- 财务分析
- 数据分析
- 市场研究

**行业知识：**
- 领域专业知识
- 监管知识
- 行业认证

### 应排除的内容

- ❌ Microsoft Office（假定）
- ❌ "基础"技能
- ❌ 你无法在面试中讨论的技能
- ❌ 软技能（展示而非列表）
- ❌ 过时的技术

## 经验部分

### 标准格式

```
公司名称 | 城市，州
职位名称 | 开始日期 - 结束日期

• 带有指标和影响的成就要点
• 带有指标和影响的成就要点
• 带有指标和影响的成就要点
```

### 按职业阶段的要点指南

**入门级（0-2 年）：**
- 每个职位 3-5 个要点
- 包含相关项目
- 尽可能量化
- 展示主动性和学习能力

**中端职业（3-10 年）：**
- 最近职位 4-6 个要点
- 早期职位 2-3 个要点
- 侧重成就而非职责
- 全程强调指标

**高级（10 年以上）：**
- 最近职位 5-6 个要点
- 早期职位 2-3 个要点
- 强调领导和战略
- 展示范围扩大

### 处理不同情况

**同一公司担任多个职位：**
```
公司名称 | 城市，州
高级经理 | 2021 - 现在
• [当前职位的要点]

经理 | 2019 - 2021
• [先前职位的要点]

分析师 | 2017 - 2019
• [最早职位的要点]
```

**短期任职：**
- 如果相关经验则包含
- 围绕项目或成就构建
- 不要在简历中道歉或解释

**合同/自由职业：**
```
自由职业产品顾问 | 2022 - 现在
客户包括：公司 A、公司 B、公司 C
• [与客户 A 的成就]
• [与客户 B 的成就]
```

## 教育部分

### 标准格式

```
教育

计算机科学理学学士
加州大学伯克利分校 | 2020
GPA：3.8/4.0 | 荣誉：优等生
```

### 按职业阶段包含的内容

**入门级：**
- 学位、专业、学校、年份
- GPA（如果 3.5+）
- 荣誉和奖项
- 相关课程
- 学术项目
- 海外学习

**中端职业：**
- 学位、专业、学校、年份
- 仅在特别突出时提供 GPA
- 跳过课程（被经验取代）

**高级：**
- 学位、学校
- 可能跳过年份（年龄歧视）
- 专业发展更相关

### 高级学位

```
MBA，金融与战略
哈佛商学院 | 2022
• 领导成员
• 相关课程：公司金融、并购战略

计算机科学硕士
斯坦福大学 | 2018
• 专业：人工智能
• 论文："论文标题"
```

### 认证

```
认证
AWS 解决方案架构师助理 | 亚马逊网络服务 | 2023
PMP（项目管理专业人士） | PMI | 2022
谷歌分析认证 | 谷歌 | 2023
```

## 额外部分

### 何时包含每个部分

**项目部分：**
- 入门级且工作经验有限
- 职业转换者展示新技能
- 技术职位具有个人项目

**志愿者部分：**
- 相关志愿者经验
- 领导职位
- 有意义地填补就业空缺

**语言：**
- 如果与职位/公司相关
- 准确列出熟练程度
- 仅在超出基本会话能力时包含

**出版物/专利：**
- 学术职位
- 研究职位
- 技术思想领导力

**奖项/认可：**
- 显著行业奖项
- 公司范围认可
- 相关荣誉

### 格式示例

**项目：**
```
项目
电子商务平台 | React、Node.js、PostgreSQL | github.com/user/project
• 构建了具有 500 多名活跃用户的全栈市场
• 实现了与 Stripe 集成的支付处理
```

**志愿者：**
```
志愿者经历
董事会成员 | 当地非营利组织 | 2021 - 现在
• 领导筹款委员会，使年度捐款增加 40%
```

**语言：**
```
语言
英语（母语） | 西班牙语（专业） | 普通话（会话）
```

## 按角色类型划分的部分顺序

### 标准顺序
1. 联系方式
2. 概述（可选）
3. 技能
4. 经验
5. 教育
6. 额外部分

### 技术职位
1. 联系方式
2. 技能（优先）
3. 经验
4. 项目
5. 教育
6. 认证

### 近期毕业生
1. 联系方式
2. 教育（优先）
3. 技能
4. 经验/实习
5. 项目
6. 活动

### 高管
1. 联系方式
2. 高管概述
3. 职业亮点
4. 经验
5. 董事会职位
6. 教育

### 职业转换者
1. 联系方式
2. 概述（解释转换）
3. 技能（可转移）
4. 经验（重新构建）
5. 桥接经验
6. 教育

## 输出格式

构建简历部分时：

```markdown
# 简历部分建议

## 针对：[用户的情况/角色]

### 推荐部分顺序
1. [部分] - [原因]
2. [部分] - [原因]
...

### 部分详情

#### 专业概述
**建议：** [包含/跳过]
**草稿：**
[如果建议，则写入概述]

#### 技能部分
**格式：** [简单/分类/熟练程度]
**内容：**
[组织好的技能列表]

#### 经验部分
**格式：** [标准/功能性/混合]
**每个职位的要点：**
- 最近：[X] 个要点
- 早期：[X] 个要点

#### 教育部分
**包含：**
- [要包含的项目]
**排除：**
- [要排除的项目]

#### 额外部分
**推荐：** [部分名称] 因为 [原因]
**跳过：** [部分名称] 因为 [原因]
```

## 部分构建检查清单

- ✅ 部分顺序针对角色优化
- ✅ 概述简洁且有针对性（如果包含）
- ✅ 技能相关且组织
- ✅ 经验要点以成就为中心
- ✅ 教育适合职业阶段
- ✅ 额外部分增加价值（非填充）
- ✅ 全程格式一致
- ✅ 所有部分支持目标角色
- ✅ 不包含无关或过时的内容
- ✅ 总长度适当（1-2 页）
