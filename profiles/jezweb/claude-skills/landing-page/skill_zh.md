# 网站首页生成器

生成一个完整的、可部署的网站首页，作为一个单一的 HTML 文件。无需构建步骤，无需依赖——直接在浏览器中打开或部署到任何地方。

## 工作流程

### 1. 收集需求简报

向用户收集以下信息：

| 字段         | 是否必需 | 示例                 |
|--------------|----------|----------------------|
| 商业/产品名称 | 是       | "Acme Plumbing"      |
| 价值主张     | 是       | "纽卡斯尔全天候紧急管道维修服务" |
| 目标受众     | 是       | "猎人谷地区的房主"     |
| 主要行动号召 | 是       | "立即致电" / "获取报价" / "注册" |
| 次要行动号召 | 否       | "了解更多" / "查看价格"   |
| 品牌颜色     | 否       | 主要色：#1E40AF，强调色：#F59E0B |
| Logo URL 或文字 | 否       | Logo 图片的 URL，或直接使用商业名称 |
| 电话/邮箱     | 否       | 用于联系部分           |
| 需要的部分   | 否       | 默认：英雄区、功能介绍、客户评价、常见问题解答、页脚 |

如果未提供品牌颜色，建议使用 `color-palette` 技能生成，或使用合理的默认颜色（灰石色/蓝色）。

### 2. 生成 HTML

生成一个**单一的 HTML 文件**，包含：

```html
<!DOCTYPE html>
<html lang="en" class="scroll-smooth">
<head>
  <!-- Meta, OG 标签, favicon -->
  <script src="https://cdn.tailwindcss.com"></script>
  <script>tailwind config with custom colours</script>
</head>
<body>
  <!-- 导航栏 -->
  <!-- 英雄区 -->
  <!-- 功能介绍 -->
  <!-- 社会证明 -->
  <!-- 价格（可选） -->
  <!-- 常见问题解答 -->
  <!-- 页脚 -->
  <!-- 深色模式切换脚本 -->
</body>
</html>
```

### 3. 部分模式

#### 导航栏
- 顶部固定导航栏，包含 Logo/名称 + 链接到各部分
- 移动端汉堡菜单（纯 CSS 或极简 JS）
- 导航栏中的行动号召按钮（右对齐）

#### 英雄区
- 全宽，置于视窗可见区域
- 标题（h1）—— 价值主张，非商业名称
- 副标题 —— 辅助信息，1-2 句话
- 主要行动号召按钮（大尺寸，对比色）
- 可选：英雄区图片占位符或渐变背景
- 模式：桌面端左对齐文本（60/40 分割，图片在右），移动端居中

#### 功能/服务
- 3-6 个项目，响应式网格（移动端 1 列，桌面端 2-3 列）
- 每个：图标占位符 + 标题 + 简短描述
- 使用语义化标题（h2 用于部分，h3 用于项目）

#### 社会证明/客户评价
- 2-3 个评价卡片，包含引言、姓名、角色/公司
- 如适用：星级评分
- 替代方案：客户/合作伙伴 Logo 条

#### 价格（可选）
- 2-3 级别卡片（基础/专业/企业模式）
- 突出显示“推荐”级别
- 每级别对应的功能对比列表
- 每级别一个行动号召按钮

#### 常见问题解答
- 手风琴模式（details/summary —— 无需 JS）
- 4-6 个常见问题
- Schema.org FAQPage 标记以优化 SEO

#### 页脚
- 商业名称、联系信息、社交链接
- 法律链接（隐私政策、条款）作为占位符
- 版权年份（使用 JS 自动更新）

### 4. 技术要求

**响应式设计**：移动优先，三个断点
```
默认：移动端 (< 640px)
sm: 640px+（平板）
lg: 1024px+（桌面）
```

**深色模式**：三态切换（亮色/深色/系统）
- CSS 变量用于颜色
- `<html>` 元素上的 `.dark` 类 —— 无需 CSS 媒体查询
- 小段 JS 代码用于切换 + localStorage 持久化

**无障碍性**：
- 正确的标题层级（h1 → h2 → h3，无跳过）
- 所有图片的替代文本占位符
- 交互元素上的 `focus-visible` 样式
- 足够的颜色对比度（最小 4.5:1）
- 跳过内容链接

**SEO**：
- 语义化 HTML5 元素（header、main、section、footer）
- OG 元标签（标题、描述、图片、url）
- Twitter 卡片元标签
- 独占 URL
- JSON-LD 用于 LocalBusiness（参考 `seo-local-business` 技能）

**性能**：
- 无需 JS 即可渲染核心内容
- 图片懒加载（`loading="lazy"`）
- 系统字体堆栈（无外部字体请求）
- 单文件 —— 无外部 CSS/JS，仅 Tailwind CDN

### 5. 颜色应用

如果用户提供了品牌颜色，内联配置 Tailwind：

```html
<script>
tailwind.config = {
  darkMode: 'class',
  theme: {
    extend: {
      colors: {
        primary: { DEFAULT: '#1E40AF', light: '#3B82F6', dark: '#1E3A8A' },
        accent: { DEFAULT: '#F59E0B', light: '#FBBF24', dark: '#D97706' },
      }
    }
  }
}
</script>
```

如果未提供颜色，使用 Tailwind 内置调色板（中性色用灰石色，主要色用蓝色）。

### 6. 输出

将文件写入用户指定位置，或默认为 `./index.html`。

生成后：
1. 告知用户如何预览：`open index.html`（macOS）或 `python3 -m http.server` 用于本地服务器
2. 建议部署选项：拖到 Cloudflare Pages、Netlify 拖放，或 `wrangler deploy` 用于 Workers
3. 列出需要替换的占位符内容（图片、客户评价、电话号码）

## 质量规则

1. **无占位符的“Lorem ipsum”** —— 根据商业类型生成逼真的占位符文本
2. **无损坏的布局** —— 在脑海中测试响应式网格：1 列 → 2 列 → 3 列
3. **无内联样式** —— 仅使用 Tailwind 类
4. **真实的交互** —— 平滑滚动到各部分，可工作的手风琴，可工作的深色模式切换
5. **默认无障碍性** —— 不要为了美观而牺牲无障碍性
6. **澳大利亚惯例** —— 如果商业是澳大利亚的，使用 +61 电话格式、澳大利亚拼写、ABN 占位符

## 变体

| 请求         | 方法                 |
|--------------|----------------------|
| "即将推出页面" | 英雄区 + 邮箱订阅表单 + 倒计时计时器 |
| "产品发布"   | 英雄区 + 功能介绍 + 价格 + 行动号召密集 |
| "作品集"     | 英雄区 + 项目网格 + 关于 + 联系 |
| "活动页面"   | 英雄区 + 时间表 + 演讲者 + 场地 + 注册行动号召 |
| "应用下载"   | 英雄区 + 功能介绍 + 截图 + 应用商店徽章 |

根据页面目的调整部分选择。并非每个页面都需要价格或常见问题解答。
