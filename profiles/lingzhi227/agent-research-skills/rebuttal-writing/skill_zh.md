# 反驳写作

生成结构化、基于证据的同行评审意见反驳。

## 输入

- `$0` — 评审人意见（文本文件，或直接粘贴）
- 可选：当前论文草稿供参考

## 参考文献

- 反驳提示和格式模板：`~/.claude/skills/rebuttal-writing/references/rebuttal-prompts.md`

## 工作流程

### 第一步：解析评审意见
针对每位评审人：
1. 提取单个关注点/问题/弱点
2. 对每个进行分类：主要关注点、次要关注点、问题、建议
3. 确定每个关注点背后的核心问题

### 第二步：生成回复
针对每个关注点：
1. **承认**评审人的观点
2. **提供证据进行回复** — 引用论文中的具体部分、公式、实验或结果
3. **描述已做的事情**（而不是将要做什么）— "我们已添加..."、"我们的实验表明..."
4. 如果需要额外实验，具体描述新结果

### 第三步：格式化反驳
使用标准的反驳格式：

```
# 对评审人的回复

我们感谢所有评审人的建设性反馈。我们逐项回应如下。

## 评审人 #1

**关注点 #1：** [提取的关注点]
**作者回复：** [包含证据的详细回复]

**关注点 #2：** [提取的关注点]
**作者回复：** [包含证据的详细回复]

## 评审人 #2
...
```

### 第四步：变更总结
在顶部添加简要总结，列出论文所有主要变更：
- 新增实验
- 修订章节
- 增加说明

## 规则

- **回复已做的事情，而不是将要做什么** — "我们已进行额外实验"而不是"我们将进行..."
- **保持具体** — 引用具体章节、表格编号、公式编号
- **保持尊重** — 感谢评审人，承认有效关注点
- **回应所有关注点** — 不要跳过任何评审人观点
- **提供证据** — 每个回复应包含具体数据、引用或推理
- **保持回复简洁** — 详细到足以回应关注点，但不要冗余
- **突出变更** — 在引用修改文本时，使用蓝色文本或清晰标记修订
