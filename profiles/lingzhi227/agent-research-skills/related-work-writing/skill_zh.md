# 相关工作撰写

生成具有正确引用和主题组织的、符合发表标准的“相关工作”部分。

## 输入

- `$0` — 当前论文草稿或方法描述
- `$1` — 收集的文献（BibTeX条目、论文摘要或文献综述笔记）

## 参考文献

- 相关工作撰写提示和策略：`~/.claude/skills/related-work-writing/references/related-work-prompts.md`

## 工作流程

### 第一步：分析论文的贡献
- 阅读当前论文草稿（尤其是方法和引言部分）
- 识别关键贡献和新颖性主张
- 列出需要文献背景的技术组件

### 第二步：按主题组织文献
将相关论文分组到主题集群中：
- 每个集群应代表一个研究方向或技术
- 常见主题：问题表述、方法家族、应用领域、评估方法
- 从最相关到最不相关依次排列主题

### 第三步：撰写每个主题段落
针对每个主题组：
1. **主题句** — 介绍研究方向
2. **描述关键文献** — 总结2-5篇代表性论文
3. **比较和对比** — 每种方法与你的方法有何不同？
4. **过渡** — 连接到下一个主题或你的贡献

### 第四步：完善
- 确保每篇引用的论文都有明确的纳入理由
- 检查通过比较能否清晰体现你的工作新颖性
- 核实所有 `\cite{}` 标识符是否存在于 `.bib` 文件中
- 目标为1-2页（单栏）或0.5-1页（双栏）

## 规则

- **比较和对比，而非仅仅描述** — "与[X]假设...不同，我们的方法..."
- **按主题组织，而非按时间顺序** — 按研究方向分组
- **广泛引用** — 不仅限于最流行的论文；包含近期和多样化的工作
- **保持公正** — 在陈述局限性之前，承认先前工作的优势
- **解释不适用性** — 如果某种方法适用于你的场景，解释为何不进行实验比较，或将其添加到实验中
- **用现在时态描述既定事实** — "Smith等人提出..."或"这种方法使用..."
- **以定位结尾** — 最后一段应清晰地将你的工作定位在所有讨论过的先前工作之中
