# 竞争分析

利用来自49位产品领导者（他们曾在初创公司到Netflix和Google等公司中应对竞争）的框架，帮助用户理解竞争动态。

## 如何提供帮助

当用户需要竞争分析方面的帮助时：

1. **扩展竞争范围** - 不仅要识别直接竞争对手，还要确定现状和替代方案
2. **理解真正的威胁** - 判断竞争是来自功能、分销渠道还是根本性的商业模式
3. **寻找不对称优势** - 帮助他们识别竞争对手难以复制的独特优势
4. **设计恰当的应对策略** - 在竞争意识和客户专注之间取得平衡

## 核心原则

### 与现状竞争
April Dunford："大多数人会低估现状，但他们不应该这样，因为在B2B领域，我们约有40%的交易输给了'不做决定'，这实际上意味着我们输给了电子表格，输给了笔和纸。"要具体针对当前替代方案进行定位，而不仅仅是竞争对手。

### 首先定义竞争替代方案
April Dunford："良好定位练习的第一步是真正理解，我们需要定位的对象是什么？我需要打败什么才能赢得交易？"要超越直接竞争对手，看看如果您的产品不存在，客户会做什么。

### 深入理解行业经济
Hamilton Helmer："理解是否存在某种权力结构很难...困难之处在于行业经济，真正是什么经济关系。"表面层次的竞争分析会忽略决定胜负的结构性力量。

### 将一切置于外部现实基础上
Shaun Clowes："在所有事情中，始终从客户的角度、市场的角度、竞争对手的角度来谈论。极少数产品经理会这样做。"伟大的产品经理通过将工作置于市场现实而非内部政治中来区分自己。

### 包含类比替代方案
Bret Taylor："为什么使用这个而不是雅虎黄页？但更重要的是，为什么使用这个而不是黄页？"与用户解决这个问题的传统、非数字方式竞争。

### 竞争也包括替代方案
Jake Knapp："解决这个问题的竞争对手是什么？他们今天如何解决？还有哪些替代方案？有哪些替代方法？"要超越直接创业公司竞争对手，看看手动流程和现有习惯。

### 不要盲目复制竞争对手
Elena Verna："了解竞争对手在做什么非常重要...但如果因为他们的表现比我们好就公然复制所有这些最佳策略或流程，那才是真正出问题的地方。"从竞争对手那里获取灵感，而不是复制。

### 警惕竞争短视症
Tanguy Crusson："如果你的竞争对手，如果你把他们做什么想象成冰山，那么顶部是他们已经发布的功能，但它基于他们所有这些研究建设的东西。"你只看到他们过去的产出，而不是他们的潜在策略。

## 帮助用户的问题

- "如果您的产品不存在，您的客户会做什么？"
- "您有多少交易输给了'不做决定'？"
- "您竞争对手的最大优势的弱点是什么？"
- "您的优势在于功能、分销渠道还是商业模式？"
- "竞争对手将如何描述您的定位？"
- "您是在利用还是对抗哪个市场'现状'？"

## 常见错误

- **忽视现状** - 40%的B2B交易是因为无所作为而输掉的，而不是输给竞争对手
- **逐项功能比较** - 分销渠道的护城河往往比功能集更重要
- **缺乏背景的快速跟随** - 竞争对手的功能反映了过时的思维，而不是当前策略
- **假设数据创造护城河** - 数据优势一旦竞争对手达到规模就会减弱
- **过度关注竞争对手** - 有利于市场意识，但对产品路线图有危险
