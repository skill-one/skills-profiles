# 合作与业务拓展

利用来自9位产品领袖的洞察，帮助用户建立战略合作伙伴关系和业务拓展交易。

## 如何提供帮助

当用户需要关于合作伙伴关系或业务拓展的帮助时：

1. **理解机会** - 询问潜在合作伙伴、双方各自的需求以及理想的结果
2. **评估网络与实力动态** - 判断成功是否取决于关系或产品质量，并据此制定计划
3. **设计方法** - 帮助他们制定一个展示互惠互利的提案，而不仅仅是自己的需求
4. **引导谈判** - 指导他们关于时机、杠杆作用以及何时说“不”

## 核心原则

### 在某些行业，合作伙伴关系依赖于网络
Ayo Omojola：“很多时候，事情能否成功取决于网络关系，而不仅仅是事物本身的实力。有些公司之所以存在，是因为其创始人与每位主要付款人的CEO都认识。” 在医疗保健、金融或企业等行业，关系比产品更重要。尽早确定你的业务是否依赖于网络。

### 将自己定位为平台的案例研究
Adam Grenier：“让我进入你们的alpha版本，因为我有五年购买移动广告的经验。如果你与我们合作，我们就是一个绝佳的案例研究，可以证明你们希望发展的类别。” 与主要平台合作时，展示你的成功如何帮助它们证明其商业模式。提供成为新功能alpha测试者的机会。

### 构建可扩展的平台，而不是定制化交易
Keith Yandell：“我们会为你构建一个产品，这样你就不需要每次都来问我们。然后你将知道你可以谈判的参数。” 有效的业务拓展团队与产品团队合作，为合作伙伴创建自助服务平台，而不是协商一次性集成。这可以提高速度并减少工程负载。

### 战略耐心带来更好的交易
Jason Droege：“麦当劳来找我们，我说‘不’。我让他们等了四五个月。结果证明这是一笔净收益，因为我们得到了一个很好的交易。” 不要因为合作伙伴的规模而急于建立合作伙伴关系。最初的阻力可能带来更好的条款或排他性。

### 渠道合作伙伴不会像创始人那样销售
Jen Abel：“渠道合作伙伴的问题是，名单上有你一百个，你期望他们代表你销售。他们不是愿景家，而是顾问。” 不要期望Accenture或Deloitte来推广你的产品。他们缺乏创始人的愿景塑造能力。

### 利用企业开发寻找内部支持者
Julia Schottenstein：“利用那支企业开发团队的优势。参加那次会议，说你目前对收购不感兴趣，但要求他们引荐一个可以支持交易的人——通常是产品或总经理。” 企业开发团队是通往内部支持者的门户，即使你不想出售也是如此。

### 在需要时找到合作伙伴
Meltem Kuran：“风险投资家会问他们的投资组合公司‘你们信任哪个招聘平台？’所以人们会去问他们的风险投资家这类问题。” 最好的合作伙伴是那些在目标受众遇到问题时，他们已经咨询的合作伙伴。

### 将合作伙伴关系视为重复囚徒困境
Tobi Lutke：“成为一个好的合作伙伴就像公司倾向于失败的 корпоративный marshmallow test。重复囚徒困境的正确玩法是为双方协调——从长远来看更有价值。” 不要以牺牲合作伙伴为代价将未来的利润提前。长期协调总是优于短期背叛。

### 在构建前进行手动操作测试
Keith Yandell：“我们应该在一个酒店用简陋的操作来测试这个，然后再要求产品资源。” 在投入工程时间之前，用手动操作验证合作伙伴关系假设。梦想要大，起步要小。

## 帮助用户的提问

- “合作伙伴在这笔交易中想要什么？这对他们有什么好处？”
- “这个行业是依赖于网络，还是产品实力会取胜？”
- “你能将自己定位为他们想证明的案例研究吗？”
- “你的杠杆作用是什么？你能说‘不’吗？”
- “你是在构建可扩展的平台，还是在协商一次性交易？”
- “合作伙伴组织中内部有谁能内部支持这件事？”

## 常见错误提示

- **期望合作伙伴为你销售** - 渠道合作伙伴和顾问不会像创始人那样推广。不要外包愿景塑造
- **急于建立大公司合作伙伴关系** - 战略耐心通常带来更好的交易条款。不要让FOMO驱动糟糕的交易
- **在验证前构建** - 在投入工程资源之前，用手动操作测试合作伙伴关系想法
- **忽视网络动态** - 在某些行业，关系比产品更重要。知道你在玩什么游戏
- **短期背叛** - 以牺牲合作伙伴为代价将利润提前会破坏长期价值。玩长期游戏
