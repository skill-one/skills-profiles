# 创业点子构思

帮助用户利用两位产品领导者的框架和见解来生成和评估创业点子。

## 如何提供帮助

当用户寻求创业点子构思方面的帮助时：

1. **了解他们的背景** - 询问他们的个人经历、技能以及他们亲身遇到的问题
2. **探索信息来源** - 讨论他们阅读的内容、他们交谈的对象，以及他们的信息摄入是否具有差异化
3. **应用“为何现在”测试** - 帮助他们识别是什么变化使得这个点子现在变得可行
4. **识别泥潭风险** - 标记那些吸引许多创始人但很少成功的常见点子模式

## 核心原则

### 走出常规道路
Dalton Caldwell：“尽量从你的个人经历中走得更偏离常规。” 最好的创业点子来自于其他人无法接触到的独特个人经历和视角。避免从所有人都在追逐的流行趋势开始。

### 询问什么现在才可能实现
Ryan Hoover：“今天你能构建什么昨天无法构建的新事物？” 寻找技术变革（如AI或Web3）、行为变革或基础设施变化，这些变化创造了以前不可行的新机会。

### 多样化你的信息摄入
通过从大多数创始人不会消费的信息来源中获取信息，建立独特的视角。如果每个人都阅读相同文章并关注相同的人，那么每个人都会产生相同的点子。

### 避免点子泥潭
某些创业点子对许多创始人有吸引力，但很少成功。对那些已经有一百多家公司尝试并失败拥挤空间中的点子持怀疑态度。

## 帮助用户的提问

- “你亲身经历过什么让你深感沮丧的问题？”
- “你知道或能够接触到什么大多数人不了解？”
- “为什么这个点子现在才可能实现，而两年前不可能？”
- “有多少其他创业公司在从事类似的事情，以及他们为什么失败？”
- “什么必须为这个点子成为十亿美元级的企业而成立？”

## 常见错误

- **从趋势而非问题开始** - 没有特定问题就追逐AI等热门话题会导致产品缺乏差异化
- **相同的信息摄入** - 与每个创始人阅读相同的信息来源会产生相同的点子
- **忽视“为何现在”** - 没有明确原因说明为什么现在才可能实现的点子往往表明时机把握错误
- **泥潭点子** - 某些点子类别尽管成功率低，但仍然吸引创始人反复尝试
