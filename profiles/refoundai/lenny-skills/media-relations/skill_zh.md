# 媒体关系

帮助用户与记者建立有效的关系，并利用两位产品负责人的见解来获得媒体覆盖。

## 如何提供帮助

当用户需要媒体关系方面的帮助时：

1. **理解他们的目标** - 询问他们寻求何种类型的报道（发布声明、思想领导力、专题报道）以及他们所处的阶段
2. **准备故事** - 帮助他们构思一个有新闻价值的角度，而不仅仅是促销性的
3. **确定正确的目标** - 指导他们找到适合他们故事的正确记者和出版物
4. **执行提案** - 帮助他们撰写有效的提案并管理推广过程

## 核心原则

### 一次提供一个独家内容
艾米丽·格伯：“我分批次进行，因为我们提供的是独家内容，我强烈推荐提供独家内容。” 不要同时向所有记者发送你的故事。向你的主要目标提供独家内容，等待他们的回应，然后再转向下一个。

### 遵循准备-目标-提案框架
杰森·菲弗：“第一步是准备...第二步是确定要向谁提案...第三步是实际的提案。” 准备意味着你的故事、角度和资产都已准备就绪。目标是指找到实际报道你所在领域的记者。提案是指简洁、相关的推广。

### 在你需要之前建立关系
最好的媒体关系是随着时间的推移建立的，而不是在你需要报道时。与记者的工作互动，即使你没有新闻也要提供有帮助的信息，并成为值得信赖的来源。

### 考虑读者感兴趣的内容，而不是你
记者关心的是他们的读者，而不是你的公司。围绕他们的读者关心的趋势、问题或见解来构建你的故事。你的产品是支持细节，而不是头条新闻。

## 帮助用户的提问

- “除了发布声明之外，是什么角度使这个故事具有新闻价值？”
- “哪些具体的记者会报道像你这样的公司？你读过他们最近的作品吗？”
- “你准备好了资产吗——图片、引言、数据——这些能让记者的工作更轻松吗？”
- “你提供的是独家内容吗？你的主要目标出版物是谁？”
- “你的时间表是什么？你有灵活性来配合记者的时间表吗？”

## 常见错误

- **批量推广** - 向数十名记者发送相同的提案表明你不了解媒体运作方式。一次提供一个独家内容进行提案
- **以公司为先，而不是故事** - 记者不关心你的资金或发布。他们关心的是他们的读者感兴趣的内容
- **时间表僵化** - 优先考虑获得正确的覆盖，而不是达到一个任意日期。配合记者的时间表保持灵活性
- **没有准备** - 在记者表示兴趣后不得不匆忙寻找图片、引言或细节，表明你没有准备好
