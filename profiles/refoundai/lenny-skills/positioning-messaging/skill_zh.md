# 定位与信息传递

帮助用户运用来自58位产品领导者和营销人员的框架，制定引人入胜的产品定位与信息传递。

## 如何提供帮助

当用户需要定位与信息传递方面的帮助时：

1. **了解目标受众** - 询问他们具体想要触达的人群以及这些人对什么感兴趣
2. **识别竞争框架** - 确定客户在比较时将他们与哪些替代方案进行对比
3. **寻找差异化价值** - 帮助他们阐述其产品独特且有价值之处
4. **测试信息共鸣** - 指导他们使用能反映客户描述自身问题的语言

## 核心原则

### 定位决定一切
Arielle Jackson: "我坚信定位决定了营销的许多方面，并且应该始终是第一件事。我上一堂课的学生...他说，我永远不会在没有先做定位的情况下写一行代码。" 定位是营销的基础要素，应在产品开发和所有其他营销活动之前进行。

### 弱定位导致管道摩擦
April Dunford: "弱定位在管道的早期阶段会伤害你，因为人们真的不明白你是谁，所以他们对你的营销反应不佳。你会在管道中间感到迟滞。" 监测客户在演示中要求销售代表"回去重新开始"的信号——这表明定位存在问题。

### 沟通由接收者定义
Gina Gotthilf: "沟通不在于能否传递信息，而在于能否以听众能接收、理解并记住的方式传递信息。" 有效的沟通由听众理解和记忆信息的能力来定义，而不仅仅是发送信息的行为。

### 使用模式匹配应对媒体
Emilie Gerber: "你可能会对自己的信息太过纠结，想要构建一个巨大的问题陈述...但如果你能直截了当并使用模式匹配，通常效果会更好。" 直截了当的模式匹配比复杂的问题描述或趋势故事对媒体更有效。

### 品牌设定预期
Jessica Hische: "书的封面应该告诉人们可以期待他们即将接触的事物。" 品牌的视觉识别应作为共生预览，为产品体验设定正确的预期和基调。

### 从困境时刻开始
Bob Moesta: "困境时刻会引发需求。你开始意识到，在某些情况下，困境时刻存在且可能长期存在，但没有人解决它。" 优秀的定位始于理解用户感到困顿的具体情境，而不是产品功能。

### 差异化需要牺牲
April Dunford: "你不能满足所有人。" 真正的定位需要明确决定不服务于哪些人以及不提供哪些功能。

## 帮助用户的提问

- "当客户切换到你的产品时，他们是从什么产品切换过来的？切换前他们在做什么？"
- "如果你的产品明天消失，你最忠实的客户会最想念什么？"
- "你最快乐的客户在向朋友推荐你时会说些什么？"
- "哪些人具体不适合你的产品，为什么？"
- "你明确将产品定位与哪些竞争替代方案进行对比？"
- "公司里每个人能否始终如一地描述你们做什么？"

## 常见错误

- **以功能为先的信息传递** - 优先介绍产品做什么，而不是客户能实现什么
- **形容词定位** - 使用"强大"或"易于使用"等所有竞争对手都声称的词汇
- **试图取悦所有人** - 因害怕错失机会而拒绝缩小目标受众
- **复杂的问题陈述** - 而不是使用直截了当的模式匹配来解释问题
- **以公司为中心的语言** - 使用内部术语或产品名称，而潜在客户无法理解
