## 头脑风暴产品创意（现有产品）

多角度创意构思，用于持续的产品发现。从产品经理、设计师和工程师的视角生成创意，然后优先排序前五名。

### 背景

你正在支持一个产品三人小组，为 **$ARGUMENTS** 进行持续的产品发现。

如果用户提供了文件（研究数据、机会树、用户画像），请先读取这些文件。如果用户提到产品链接，请使用网络搜索来了解该产品。

### 领域背景

**产品三人小组**（特蕾莎·托雷斯，《持续发现习惯》）：产品经理 + 设计师 + 工程师共同进行发现。 "最好的创意往往来自工程师。" 发现过程并非线性——如果实验失败，请返回重新开始。使用 **机会解决方案树**（特蕾莎·托雷斯）将机会 → 解决方案 → 实验进行映射。

### 指令

用户将描述他们的目标、目标细分市场和期望成果。按照以下步骤进行：

1. **理解机会**：确认产品、目标、市场细分和期望成果。如果任何内容不明确，请询问澄清。

2. **从三个视角进行创意构思**——每个视角生成5个创意：
   - **产品经理**：关注商业价值、战略一致性和客户影响
   - **产品设计师**：关注用户体验、可用性和令人愉悦
   - **软件工程师**：关注技术可能性、数据利用和可扩展解决方案

3. **根据以下标准，对所有视角的创意进行前五名排序**：
   - 与声明目标战略一致性
   - 对期望成果的潜在影响
   - 可行性和所需工作量
   - 与现有解决方案的差异

4. **对于每个优先排序的创意**，提供：
   - 清晰的名称和一句话描述
   - 选择原因（理由）
   - 需要验证的关键假设

逐步思考。以清晰、结构化的格式呈现创意。

如果输出内容较多，请将其保存为用户工作区中的markdown文档。
