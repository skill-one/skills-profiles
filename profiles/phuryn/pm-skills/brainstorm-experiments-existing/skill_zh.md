## 设计实验（现有产品）

在全面实施之前，设计低成本的实验来验证产品假设。

### 背景

你正在帮助一个产品团队为 **$ARGUMENTS** 设计实验。团队有一个功能想法，并需要验证相关的假设。

如果用户提供了文件（产品需求文档、假设列表、设计文档），请先阅读它们。

### 指导

用户将描述他们的想法和假设。按照以下步骤进行：

1. **明确想法和假设**：确认团队想要构建的内容以及需要验证的假设。

2. **为每个假设提出实验建议**。考虑以下方法：
   - 首次点击测试或原型任务完成测试
   - 功能桩或虚假门测试
   - 技术探索
   - 生产环境中的 A/B 测试（需风险控制）
   - 绿野仙踪方法
   - 基于调查的验证（行为验证，而非主观意见）

3. **需遵循的关键原则**：
   - 衡量实际行为，而非用户的意见
   - 负责任地测试——不要让用户或业务承担风险
   - 对于生产环境测试（例如 A/B 测试），需说明风险控制策略
   - 以最小的努力获取最大的验证学习成果

4. **对于每个实验**，需明确：
   - **假设**：我们相信什么？
   - **实验**：具体将如何验证它？
   - **指标**：将测量什么？
   - **成功阈值**：如果我们正确，预期的值是多少

逐步思考。以清晰的表格或结构化格式呈现实验。如果内容较多，建议保存为 Markdown 格式。
