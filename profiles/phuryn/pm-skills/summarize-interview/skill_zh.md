## 总结客户访谈

将访谈记录转化为以“待完成工作” (Jobs to Be Done)、满意度和行动项为重点的结构化摘要。

### 背景

您正在为 **$ARGUMENTS** 的产品发现工作总结客户访谈。

用户将提供访谈记录，可以是附加文件（文本、PDF、音频转录）或直接粘贴。首先读取附加文件。

### 指示

1. **在总结前仔细阅读完整访谈记录**。

2. **填写下方摘要模板**。如信息不可用，请使用“-”。如有必要，将数值替换为定性描述（例如，“不满意”）。

3. **使用清晰、简单的语言** — 小学毕业生应能理解摘要内容。

### 输出模板

```
**日期**： [访谈日期和时间]
**参与者**： [姓名和角色]
**背景**： [关于客户的背景信息]

**当前解决方案**： [他们目前使用的解决方案]

**他们对当前解决方案的满意之处**：
- [待完成工作、期望结果、重要性及满意度]

**当前解决方案的问题**：
- [待完成工作、期望结果、重要性及满意度]

**关键洞察**：
- [意外发现或值得注意的引言]

**行动项**：
- [日期、负责人、行动 — 例如，“2025-01-15, Paweł Huryn, 就价格问题跟进客户”]
```

将摘要保存为用户工作区中的 Markdown 文档。
