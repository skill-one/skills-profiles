## 定价策略

设计一个基于价值传递、竞争定位和支付意愿的定价策略。

### 背景

您正在为 **$ARGUMENTS** 制定定价策略。

如果用户提供了文件（竞争对手定价、调查数据、财务模型或使用数据），请先阅读这些文件。如有需要，使用网络搜索研究竞争对手的定价。

### 指导说明

1. **理解传递的价值**：
   - 核心价值主张是什么？
   - 用户的替代方案是什么（及其成本）？
   - 产品能带来哪些可量化的成果？（节省时间、增加收入、降低成本）
   - 基于这些价值，用户的支付意愿如何？

2. **评估定价模型** — 推荐最合适的模型：

   | 模型 | 适合场景 | 示例 |
   |---|---|---|
   | **固定价格** | 简单产品、成本可预测 | Basecamp ($99/月固定) |
   | **按座收费** | 协作工具、团队产品 | Slack, Figma |
   | **按量计费** | 基础设施、API产品 | AWS, Twilio |
   | **分层定价** | 具有不同用户群体的产品 | 大多数SaaS（免费/专业/企业版） |
   | **免费增值** | 具有病毒式/网络效应的产品 | Spotify, Notion |
   | **免费增值+按量计费** | 平台产品 | Vercel, OpenAI API |
   | **价值定价** | 高影响企业工具 | Salesforce, Palantir |

3. **分析竞争定价**：
   - 绘制竞争对手的定价层级及包含内容
   - 确定您的产品所处的位置（高端、中端、经济型）
   - 找出定价差距或机会
   - 注意任何行业定价惯例

4. **设计定价结构**：
   - **层级**：定义2-4个层级，并明确区分
   - **功能门控**：哪些功能属于哪个层级？（使用价值指标，而非任意限制）
   - **价值指标**：您基于什么单位收费？（用户、事件、存储、API调用）
   - **锚定定价**：将最受欢迎的层级设置为明显的选择
   - **年度折扣**：通常每月定价打15-20%折扣

5. **估算价格敏感度**：
   - Van Westendorp价格敏感度计量表（如有调查数据）：
     - 太便宜 → 质量担忧
     - 便宜 → 良好价值
     - 昂贵 → 开始犹豫
     - 太贵 → 不会购买
   - 或者，根据竞争对手定价和传递的价值进行估算

6. **规划定价实验**：
   - A/B测试定价页面（不同的价格点、层级名称、功能包）
   - 创始人主导的销售对话以测试支付意愿
   - 使用不同价格锚定的着陆页测试
   - 按价格点分析转化率的队列分析

7. **输出定价建议**：
   ```
   推荐模型：[模型类型]
   价值指标：[您基于什么单位收费]

   | 层级 | 价格 | 目标群体 | 关键功能 | 定位 |
   |---|---|---|---|---|

   关键假设：
   - [假设] → [如何验证]

   风险：
   - [风险] → [缓解措施]
   ```

逐步思考。保存为Markdown格式。标记任何在上线前需要验证的假设。
