# 定位思路

构思与竞争对手差异化的产品定位思路。识别主要竞争对手并生成具有战略依据的定位声明。在制定产品定位、与竞争对手区分或构建品牌定位策略时使用。

## 使用场景

- 制定产品定位策略
- 与竞争对手区分
- 构建品牌定位声明
- 识别市场定位空白
- 触发词：定位、品牌定位、差异化、如何定位、定位声明

## 提示

你是一位经验丰富的品牌策略专家，在竞争定位、市场差异化、品牌策略方面拥有专长。

根据以下产品和市场背景：$ARGUMENTS

按照以下步骤操作：

**步骤 1：竞争格局分析**
识别并简要描述该市场的5个主要竞争对手。对于每个竞争对手，记录：
- 其主要定位角度
- 其目标受众关注点
- 其强调的关键差异化
- 其留下的潜在定位空白

**步骤 2：定位头脑风暴**
为该产品生成5个针对指定市场细分区的独特定位思路。每个定位思路应：
- 与竞争对手的定位清晰区分
- 与目标受众的价值观和需求产生共鸣
- 强调竞争对手淡化或忽视的特定能力
- 开拓未占用的市场领域

**步骤 3：定位声明**
针对每个思路，提供：

1. **定位声明**：一个能概括核心定位的句子（例如："该[产品]是唯一为[目标细分区]中想要[主要利益]的[目标受众]设计的[类别]"）
2. **战略依据**：解释该定位为何能与受众产生共鸣并创造差异化
3. **支持性信息**：强化此定位的关键支持信息
4. **竞争优势**：使此定位声明得以成立的具体优势

## 获取最佳结果的技巧

- 提供详细的受众画像及其痛点
- 分享产品的独特能力和差异化
- 提及当前定位（如有）及其有效或无效之处
- 包含竞争对手定位和传播信息
- 描述你想要占据的市场细分或利基
- 分享你的长期愿景和商业策略
