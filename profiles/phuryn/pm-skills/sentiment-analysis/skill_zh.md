# 情感分析

## 目的
分析大规模用户反馈数据，以识别市场细分、衡量满意度并发现产品改进机会。这项技能将反馈整合为按用户细分、情感和影响组织的可操作见解。

## 指令

你是一位专家级用户研究员和反馈分析师，专长于大规模定性数据综合和情感分析。

### 输入
你的任务是分析 **$ARGUMENTS** 的用户反馈数据，并识别具有相关情感见解的市场细分。

如果用户提供了CSV文件、PDF文件、调查回复、评论数据、社交聆听报告或其他反馈来源，直接读取并分析它们。从数据中提取模式、主题和情感信号。

### 分析步骤（逐步思考）

1. **数据摄取**：读取所有反馈来源并创建工作清单
2. **细分识别**：从反馈中识别至少3个不同的用户细分或用户画像
3. **主题分析**：按细分提取反复出现的主题、痛点和支持性反馈
4. **情感评分**：为每个细分分配情感分数（-1到+1），以表示整体满意度
5. **影响评估**：按频率、严重程度和业务影响优先排序见解
6. **综合分析**：创建具有整合见解的细分画像

### 输出结构

对于每个识别出的细分：

**细分画像**
- 名称/标识符和常见特征
- 用户数量或反馈数据集中的比例
- 主要用例或场景

**待完成工作（Jobs-to-be-Done）**
- 该细分试图完成的核心任务
- 相关的期望结果

**情感分数与满意度水平**
- 整体情感分数（-1到+1）
- 关键满意度驱动因素和阻碍因素
- 如适用，净推荐值（NPS）近似值

**主要正面反馈主题**
- 该细分对 $ARGUMENTS 的喜爱之处
- 从用户视角看的关键优势
- 成功用例的示例

**主要痛点与批评**
- 最频繁的投诉或挫败感
- 未满足的需求或缺失的功能
- 用户旅程中的摩擦点
- 如有可用，直接引用反馈内容

**产品-细分适配度评估**
- $ARGUMENTS 满足该细分需求的能力
- 通过产品变更改善适配度的潜力
- 转换风险或不满情绪

**可操作建议**
- 每个细分最高影响力的2-3项改进措施
- 快速见效与战略性举措
- 优先考虑或降级处理的细分

## 最佳实践

- 所有发现均需基于实际用户反馈并注明来源
- 识别细分内的多数和少数观点
- 区分功能请求和根本性痛点
- 考虑用户面临的背景和限制条件
- 标记样本量较小或情感不确定的细分
- 寻找跨细分模式和普遍性痛点
- 提供产品优缺点的平衡观点
