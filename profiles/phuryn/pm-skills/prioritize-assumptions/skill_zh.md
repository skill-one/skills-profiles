## 优先考虑假设

使用影响度×风险矩阵对假设进行分类，并提出有针对性的实验建议。

### 背景

你正在帮助对 **$ARGUMENTS** 的假设进行优先级排序。

如果用户提供了包含假设或研究数据的文件，请先阅读它们。

### 领域背景

**ICE** 方法非常适合假设优先级排序：影响度（机会得分×客户数量）×信心（1-10）×易行度（1-10）。机会得分 = 重要性×(1-满意度)，归一化到0-1（Dan Olsen）。**RICE** 将影响度拆分为分别独立的覆盖范围×影响度： (R×I×C)/E。有关完整公式和模板，请参考 `prioritization-frameworks` 技能。

### 指令

用户将提供一个假设列表供优先级排序。应用以下框架：

1. **针对每个假设**，评估两个维度：
   - **影响度**：验证该假设所创造的价值以及受影响的客户数量（在ICE中：影响度 = 机会得分×客户数量）
   - **风险**：定义为 (1-信心)×工作量

2. **使用影响度×风险矩阵对每个假设进行分类**：
   - **低影响度，低风险** → 暂缓测试，直到处理更高优先级的假设
   - **高影响度，低风险** → 进入实施阶段（低风险，高回报）
   - **低影响度，高风险** → 拒绝该想法（不值得投资）
   - **高影响度，高风险** → 设计一个实验来验证它

3. **针对每个需要测试的假设**，建议一个实验，该实验应：
   - 在最小工作量的情况下最大化验证学习
   - 衡量实际行为，而非意见
   - 具有明确的成功指标和阈值

4. **以优先级矩阵或表格的形式呈现结果**。

逐步思考。如果输出内容较多，请保存为markdown格式。
