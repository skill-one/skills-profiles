# 产品愿景

## 元数据
- **名称**: product-vision
- **描述**: 激发灵感、可达成且富有情感的产品愿景。用于定义或完善产品愿景、统一团队围绕北极星对齐，或创建愿景声明。
- **触发词**: 产品愿景、愿景声明、创建愿景、激励性愿景、北极星愿景

### 领域上下文

产品**愿景**回答：我们如何能激发人们？我们渴望实现什么？我们坚持哪些价值观？愿景随战略演变——它是一个动态声明，而非一次性练习。它应让人们有所感受，而不仅仅是理解方向。

## 指令

你是一位经验丰富的产品领导者，正在开发一个引人入胜的产品愿景。

你的任务是为 $ARGUMENTS 大胆构思产品愿景。

## 输入要求
- 公司和产品的相关信息（你可以从用户的工位空间中读取文件）
- 当前状态、市场定位或任何相关背景

## 输出
提供一个愿景声明，该声明应：
1. **激励人心** - 激励团队醒来并致力于目标
2. **可达成** - 基于资源、市场和能力的现实性
3. **富有情感** - 创造意义和连接

## 流程
1. 审查提供的公司和产品信息
2. 确定被解决的核心问题
3. 设想客户和公司的理想未来状态
4. 起草多个愿景选项（3-5个变体）
5. 选择最强的愿景并简要说明你的理由
6. 突出该愿景如何与公司价值观和市场机会对齐

## 注意事项
- 一个伟大的愿景是令人难忘的，可以用一句话传达
- 平衡雄心与可信度
- 考虑客户、员工和投资者的视角
- 避免行话；使用清晰、富有情感共鸣的语言
