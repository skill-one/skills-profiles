# SQL 查询生成器

## 目的
将自然语言需求转换为跨多个数据库平台的优化 SQL 查询。这项技能帮助产品经理、分析师和工程师生成准确查询，而无需手动编写语法。

## 工作原理

### 第一步：理解您的数据库架构
- 如果您提供架构文件（SQL、文档或图描述），我将读取并分析它
- 提取表名、列定义、数据类型和关系
- 识别主键、外键和索引策略

### 第二步：处理您的请求
- 明确您需要检索或分析的数据
- 确认 SQL 语法（BigQuery、PostgreSQL、MySQL、Snowflake 等）
- 询问任何其他要求（过滤器、聚合、排序）

### 第三步：生成优化查询
- 编写利用您的数据库结构的有效 SQL
- 添加注释解释复杂逻辑
- 为大数据集添加性能考虑
- 如适用，提供替代方案

### 第四步：解释和测试
- 用普通英语解释查询逻辑
- 建议如何测试或验证结果
- 提供性能优化的技巧
- 如果您需要，可以生成测试脚本或样本数据

## 使用示例

**示例 1：从架构文件查询**
```
上传您的 database_schema.sql 文件并说明：
"生成一个查询来查找过去 30 天注册的用户
并且至少有 5 次活跃会话"
```

**示例 2：从图描述查询**
```
"这是我的数据库：Users 表（id、email、created_at），Sessions 表
(id、user_id、timestamp、duration)。生成一个查询来获取 2026 年 1 月
每个用户的平均会话时长。"
```

**示例 3：复杂分析查询**
```
"创建一个 BigQuery 查询来分析我们的收入按地区和客户等级划分，
包括同比增长率。"
```

## 核心功能

- **多语法支持**：支持 BigQuery、PostgreSQL、MySQL、Snowflake、SQL Server
- **文件读取**：读取架构文件、SQL 导出和数据文档
- **查询优化**：建议索引、分区和性能改进
- **解释**：分解查询用于学习和文档
- **测试**：可以生成测试查询和样本数据脚本
- **脚本执行**：为您的数据库创建可执行的 SQL 脚本

## 获取最佳效果的建议

1. **提供上下文**：分享您的数据库架构或结构
2. **具体说明**：明确描述您需要的数据和任何过滤器
3. **提及数据库**：指定您使用的 SQL 语法
4. **包含约束**：提及数据量、时间范围和性能需求
5. **请求格式**：如果您需要特定输出，请询问查询结果格式

## 输出格式

您将收到：
- **SQL 查询**：带注释的生产就绪 SQL 代码
- **解释**：查询的作用和工作原理
- **性能说明**：优化技巧和注意事项
- **测试脚本**（如果请求）：样本数据和验证查询
