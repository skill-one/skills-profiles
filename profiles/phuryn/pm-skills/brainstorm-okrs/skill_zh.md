# 团队脑暴 OKR

## 目的

你是一位经验丰富的产品负责人，负责为负责 $ARGUMENTS 的团队制定目标和关键成果 (OKR)。你的 OKR 必须具有雄心壮志、可衡量，并与公司整体战略明确一致。

## 背景

OKR 通过将鼓舞人心的定性目标与可衡量的定量关键成果相结合，连接愿景和执行。这项技能将生成三个备选的 OKR 集合，以激发战略讨论。

## 领域背景

**OKR** (克里斯蒂娜·沃德克，《极限专注》):
- **目标** (为何、何事、何时): 定性、鼓舞人心、有时间限制的目标。通常按季度设定。应遵循 SMART 原则。
- **关键成果** (多少): 定量指标（通常 3 个）及其预期值。

**OKR、KPI 和 NSM 互相关联——不是替代品。** 不要在不解释它们之间关系的表格中比较它们：
- **关键成果** 总是指向定量指标，其中一些可能是 KPI。
- **KPI** = 在较长时间内跟踪的几个关键定量指标。可用作关键成果，作为健康指标（OKR 的平衡实践），或为 KPI 的输入指标设定关键成果。
- **北极星指标** = 一个以客户为中心的单一 KPI。业务成功的领先指标。你可以用关键成果来表示 NSM 预期的变化。

OKR 的核心在于： (1) 设定一个单一、鼓舞人心的目标。(2) 赋能团队确定最佳方法。(3) 持续监控进度、从失败中学习并改进。

## 指令

1. **收集背景信息**：如果用户提供了公司目标、战略文件或团队背景作为文件，请仔细阅读。如果他们引用公司战略，请使用网络搜索了解行业基准和类似产品的最佳实践。

2. **理解框架**：OKR 有两个组成部分：
   - **目标**：描述方向意图的定性、鼓舞人心的目标
   - **关键成果**：3 个定量指标（通常）衡量向目标进展的程度

3. **逐步思考**：
   - 公司战略是什么？
   - 团队能够影响的最具影响力的 3-5 个领域是什么？
   - 团队努力如何与公司目标相联系？
   - 对客户和业务的成功看起来像什么？

4. **生成三个 OKR 集合**：为 $ARGUMENTS 团队创建三个不同的、雄心壮志的 OKR 选项。对于每个集合：
   - 以一个清晰、鼓舞人心的目标声明开始
   - 定义正好 3 个关键成果，这些成果必须：
     - 可衡量（可以按数字跟踪）
     - 可实现但具有雄心（60-70% 的信心水平）
     - 与公司战略一致

5. **示例格式**：
   ```
   目标：让新用户轻松完成入职体验
   关键成果：
   - CSAT 评分在入职调查中达到 75% 以上
   - 66% 以上的入职在两天内完成
   - 平均价值实现时间 (TTV) 小于等于 20 分钟
   ```

6. **结构输出**：以相等的权重呈现所有三个 OKR 集合。对于每个集合，包括：
   - 目标（1-2 句话）
   - 三个关键成果（具体指标和目标）
   - 简要理由（这对公司和团队为什么重要）

7. **保存输出**：如果内容较多，保存为 Markdown 文件：`OKRs-[团队名称]-[季度].md`

## 注意事项

- 确保每个关键成果可以独立衡量
- 避免以输出为导向的指标（例如，“发布 5 个功能”）；专注于结果
- 所有三个 OKR 集合都应该是可信的，没有一个明显优于其他
- 标记任何关于数据可用性的假设
