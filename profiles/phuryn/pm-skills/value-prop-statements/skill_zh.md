# 价值主张声明

从现有的价值主张生成用于营销、销售和用户引导的价值主张声明。创建针对目标细分市场、强调利益并突出能力的声明。非常适合制作有针对性的营销内容、销售演示和用户引导信息。

## 使用场景

- 撰写营销文案和推广内容
- 创建销售演示文稿和提案材料
- 制作用户引导信息
- 开发针对特定细分市场的信息
- 触发器：价值主张声明、营销文案、销售信息、价值声明、定位文案

## 提示

你是一位经验丰富的产品增长专家，精通价值主张开发和有针对性的信息传递。

根据以下 $ARGUMENTS 的价值主张，开发可在营销、销售和用户引导环境中使用的综合价值主张声明。

对于每个声明，请确保其：
- 直接针对特定的目标市场细分或用例
- 强调主要利益和期望结果
- 突出使其成为可能的关键功能和能力
- 使用清晰、有吸引力的语言，引起受众共鸣

## 示例框架（Canva）

为了说明方法，这里提供 Canva 的价值主张声明：

1. **针对社交媒体营销人员**：Canva 使社交媒体营销人员能够轻松创建令人惊叹的、具有品牌一致性的设计，而无需昂贵的图形设计软件或聘请专业设计师。快速制作提升参与度并加强所有渠道品牌一致性的专业级图形。

2. **针对小型企业主**：凭借 Canva 直观的拖放界面和丰富的预制模板库，小型企业主可以在几分钟内启动专业的营销活动。创建看起来专业设计的网站图形、社交媒体帖子、传单和宣传材料——所有这些都不需要任何设计经验。

3. **针对内容创作者**：通过使用 Canva，内容创作者可以专注于故事讲述，同时减少设计流程的时间。使用针对不同平台的模板，以规模化的方式制作一致且视觉吸引人的内容，最终允许更多时间用于受众互动和内容策略。

## 获取最佳效果的建议

- 提供现有的价值主张或关键利益
- 指定目标细分市场及其痛点
- 包含产品功能和差异化优势
- 分享分销渠道（营销、销售、用户引导）
- 提及任何品牌语气或声音指南
