## 产品指标仪表盘

设计一个全面的产品指标仪表盘，包含合适的指标、可视化和警报阈值。

### 背景

您正在为 **$ARGUMENTS** 设计一个指标仪表盘。

如果用户提供了文件（现有的仪表盘、分析数据、OKRs 或战略文档），请先阅读它们。

### 领域背景

**指标 vs KPI vs NSM**：指标 = 所有可衡量的东西。KPI = 少数关键的定量指标，在较长时间内进行跟踪。北极星指标 = 一个以客户为中心的 KPI，是业务成功的领先指标。

**一个良好指标的 4 个标准**（Ben Yoskovitz, *Lean Analytics*）： (1) 易于理解 — 创建共同语言。(2) 可比较 — 需要跨时间比较，而不是快照。(3) 比率或速率 — 比绝对数字更有揭示力。(4) 改变行为 — 黄金法则：“如果一个指标不会改变你的行为，它就是一个糟糕的指标。”

**8 种指标类型**：虚荣指标 vs 可行动指标（只有可行动指标会改变行为）、定性指标 vs 定量指标（WHAT vs WHY — 你需要两者；永远不要停止与客户沟通）、探索性指标 vs 报告性指标（探索数据以发现意外见解）、滞后指标 vs 领先指标（领先指标可以更快地学习周期，例如客户投诉可以预测流失）。

**5 个行动步骤**： (1) 根据良好的指标标准进行指标审计。(2) 更新仪表盘 — 确保所有关键指标都是良好的指标。(3) 识别虚荣指标 — 小心使用它们。(4) 区分领先指标和滞后指标。(5) 选择一个问题，深入挖掘数据。

案例研究和更多细节：[你正在跟踪正确的指标吗？](https://www.productcompass.pm/p/are-you-tracking-the-right-metrics) by Ben Yoskovitz

### 指令

1. **确定指标框架** — 将指标组织成层级：

   **北极星指标**：最能捕捉核心价值传递的单个指标

   **输入指标**（3-5）：驱动北极星的杠杆

   **健康指标**：确保整体产品健康的护栏

   **业务指标**：收入、成本和单位经济指标

2. **为每个指标定义**：

   | 指标 | 定义 | 数据来源 | 可视化 | 目标 | 警报阈值 |
   |---|---|---|---|---|---|
   | [名称] | [精确计算：分子/分母，时间窗口] | [数据来源] | [折线图 / 条形图 / 数字 / 漏斗] | [目标值] | [何时触发警报] |

3. **设计仪表盘布局**：

   ```
   ┌─────────────────────────────────────────────┐
   │  北极星：[指标] — [当前值]                 │
   │  趋势：[↑/↓ X% vs 上期]                    │
   ├──────────────────┬──────────────────────────┤
   │  输入指标 1    │  输入指标 2                │
   │  [Sparkline]    │  [Sparkline]               │
   ├──────────────────┼──────────────────────────┤
   │  输入指标 3    │  输入指标 4                │
   │  [Sparkline]    │  [Sparkline]               │
   ├──────────────────┴──────────────────────────┤
   │  健康：[延迟] [错误率] [NPS]               │
   ├─────────────────────────────────────────────┤
   │  业务：[MRR] [CAC] [LTV] [流失率]          │
   └─────────────────────────────────────────────┘
   ```

4. **设置审查周期**：
   - **每日**：运营健康（错误、延迟、关键流程）
   - **每周**：输入指标和参与趋势
   - **每月**：北极星、业务指标、OKR 进度
   - **每季度**：战略审查和指标重新校准

5. **定义警报**：
   - 什么阈值会触发调查？
   - 谁会收到警报，通过什么渠道？
   - 预期的响应时间是什么？

6. **根据用户背景推荐工具**：
   - Amplitude、Mixpanel、PostHog 用于产品分析
   - Looker、Metabase、Mode 用于基于 SQL 的仪表盘
   - Datadog、Grafana 用于运营健康

逐步思考。将仪表盘规范保存为 Markdown 文档。
