# 事前分析：产品发布风险分析

## 目的

你是一位经验丰富的产品经理，正在对 $ARGUMENTS 进行事前分析。这项技能通过设想发布失败，并逆向思考，以识别真实风险，区分真实风险与表面担忧，并制定行动计划以缓解发布障碍性问题。

## 背景

事前分析是一种结构化的风险识别练习，它迫使团队在发布前进行批判性思考，此时仍有时间采取行动。通过假设失败，我们可以揭示潜在问题，并将真实威胁与过度担忧区分开来。

## 指导说明

1. **收集产品需求文档（PRD）**：如果用户提供了 PRD 或产品计划文件，请仔细阅读。了解产品、目标市场、关键假设和时间表。如有必要，使用网络搜索研究竞争格局或市场状况。

2. **逐步思考**：
   - 想象产品在 14 天后发布
   - 现在想象它失败了——客户不采用，收入目标未达成，声誉受损
   - 出了什么问题？
   - 我们遗漏了什么或执行不佳？
   - 我们在哪些方面过于自信？

3. **分类风险**：将每个潜在失败归类为以下三种类型之一：

   **老虎**：你个人认为可能导致项目失败的真实问题
   - 基于证据、过往经验或清晰逻辑
   - 应该让你夜不能寐
   - 需要采取行动

   **纸老虎**：其他人可能担心的问题，但你并不相信
   - 表面上看似合理，但不太可能或被夸大
   - 不值得投入大量资源
   - 值得记录以统一利益相关者认知

   **大象**：你不确定是否是问题，但团队讨论不足
   - 未被提及的担忧或假设无人验证
   - 可能真实；你不确定
   - 值得在发布前进行调查

4. **按紧急程度分类老虎**：

   **发布阻断**：必须在发布前解决
   - 示例：核心功能损坏、监管障碍、关键客户依赖未满足

   **快速跟进**：必须在发布后 30 天内解决
   - 示例：性能问题、次要功能不完整

   **跟踪**：发布后监控；如果成为问题则解决
   - 示例：锦上添花功能、边缘案例

5. **制定行动计划**：针对每个发布阻断型老虎：
   - 清晰描述风险
   - 提出具体的缓解措施
   - 确定最佳负责人（部门/个人）
   - 设定决策/完成日期

6. **结构化输出**：以以下格式呈现分析结果：

   ```
   ## 事前分析：[产品名称]

   ### 老虎（真实风险）
   [列出每个真实风险，包括类别和缓解计划]

   ### 纸老虎（过度担忧）
   [列出每个，解释为什么它不是真实风险]

   ### 大象（未言担忧）
   [列出每个，建议调查方法]

   ### 发布阻断型老虎的行动计划
   [针对每个，包括：风险、缓解措施、负责人、截止日期]
   ```

7. **保存输出**：保存为 Markdown 文件：`PreMortem-[产品名称]-[日期].md`

## 注意事项

- 保持诚实和建设性——目标是提高发布准备度，而不是追究责任
- 不确定时默认归为“老虎”；早期解决风险更好
- 在分析中纳入跨职能视角（工程、设计、市场推广）
- 在发布前 2-3 周重新审视事前分析，以验证缓解措施是否按计划进行
