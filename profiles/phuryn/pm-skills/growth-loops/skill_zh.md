# 增长循环

## 概述
识别和设计增长循环（飞轮），以创造可持续的牵引力。这项技能评估了五种经过验证的增长循环机制，以减少对付费获取的依赖并构建产品驱动的增长。

## 使用场景
- 设计产品的增长机制
- 建立可持续的病毒式或推荐式牵引力
- 减少对付费获取的依赖
- 分析竞争对手的增长策略
- 优化产品以实现产品驱动的增长

## 五种增长循环类型

### 1. 病毒式循环
用户在产品中创建的内容在外部平台上分享，将新用户带回产品。
- **机制**：用户在产品中创建内容 → 在社交/外部平台分享 → 新用户发现并注册
- **示例**：Figma 设计作为链接分享，Loom 视频通过邮件分享
- **优势**：如果内容具有天然的分享性，则用户获取呈指数级增长
- **挑战**：需要高度可分享的输出和强烈的分享激励

### 2. 使用循环
用户在产品中创建内容或价值，然后分享，这会邀请新用户或推动重新参与。
- **机制**：用户创建 → 分享创作 → 他者消费 → 成为活跃用户
- **示例**：Twitter 线程，Medium 文章，Notion 模板公开发布
- **优势**：增长直接与产品使用和网络效应相关联
- **挑战**：需要内容创建的摩擦非常低

### 3. 协作循环
用户邀请同事在产品内共同创建或协作，在组织内扩展用户群。
- **机制**：用户创建 → 邀请同事协作 → 同事发现产品价值
- **示例**：Google Docs 邀请，Figma 团队项目，Slack 频道
- **优势**：深度组织渗透和高留存率
- **挑战**：最适合协作/团队型产品

### 4. 用户生成循环
用户通过其他用户的创作发现新内容或功能，然后创建和分享自己的内容。
- **机制**：用户发现内容 → 创建类似内容 → 分享创作 → 他者发现
- **示例**：TikTok，Pinterest，YouTube 趋势推动创作者参与
- **优势**：创造内容飞轮和网络效应
- **挑战**：需要临界质量的高质量内容来维持

### 5. 推荐循环
用户通过奖励、激励或社会认可邀请其他潜在用户。
- **机制**：用户推荐 → 被推荐用户加入 → 推荐者获得奖励 → 分享更多推荐
- **示例**：Dropbox 推荐奖金，Uber 乘客推荐，PayPal 注册奖金
- **优势**：直接激励获取；易于衡量 ROI
- **挑战**：需要没有侵蚀单位经济学的有价值激励

## 工作原理

### 第一步：定义产品价值
阐明用户体验的核心价值：
- 用户在您的产品中执行的主要操作
- 每个用户操作的创建价值
- 现有的网络效应（如有）
- 体验中的摩擦点

### 第二步：评估循环匹配度
评估哪些增长循环与您的产品相符：
- 产品类型（协作型、内容型、效用型等）
- 目标用户行为和分享习惯
- 现有的网络效应
- 现有用户群和参与度

### 第三步：设计循环机制
创建特定的循环实现：
- 触发分享或邀请的机制
- 参与激励（内在或外在）
- 分享机制的便捷性
- 邀请到激活的转化率
- 每个用户循环重复的频率

### 第四步：计算循环系数
估计增长速度：
- 每个用户每个周期的邀请/分享数
- 邀请到新用户的转化率
- 每个周期的净新用户
- 每个周期迭代的时间

### 第五步：构建循环
首先实施最具杠杆效应的循环：
- 从最适合您产品的循环开始
- 优化消息和摩擦
- 衡量循环指标和转化率
- 随时间累积结果

## 输入格式
使用 $ARGUMENTS 传递：
- 产品描述和主要用户操作
- 目标用户人口统计和行为
- 现有的分享/协作功能
- 当前增长渠道和指标
- 约束或机会

## 输出
包括增长循环分析的输出：
- 对您的产品所有五种循环类型的排名评估
- 推荐的主要增长循环及实施计划
- 随时间叠加的次要循环
- 关键指标和测量框架
- 30-60-90 天实施路线图
- 潜在循环系数和增长预测

## 框架
基于 Ognjen Bošković 的增长循环研究。专注于通过内置的、产品原生的分享和协作机制实现用户获取的复合增长。

## 小贴士
- 先从一个循环开始并掌握它，然后再增加复杂性
- 病毒式循环复合最快，但需要时间构建
- 协作循环创造最强的留存和 LTV
- 在优化阶段每周测量循环健康状况
- 一旦达到规模，结合循环以实现乘法效应
