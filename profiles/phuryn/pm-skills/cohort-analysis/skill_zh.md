# 群组分析 & 留存率探索器

## 目的
通过群组分析用户参与度和留存模式，识别用户行为、功能采用和长期参与的趋势。结合定量洞察与定性研究建议。

## 工作原理

### 第一步：读取并验证您的数据
- 接受包含用户群组信息的 CSV、Excel 或 JSON 数据文件
- 验证数据结构：群组标识符、时间段、参与度指标
- 检查缺失值和数据质量问题
- 汇总关键统计数据（群组规模、日期范围、可用指标）

### 第二步：生成定量分析
- 计算群组留存率和参与度趋势
- 识别留存曲线、流失模式及异常情况
- 计算群组间的功能采用率
- 计算月度环比或期度环比变化
- 如有请求，生成使用 pandas 和 numpy 的 Python 分析脚本

### 第三步：创建可视化
- 生成留存热力图（群组与时间段对比）
- 创建显示群组进展的折线图
- 构建功能采用度对比图表
- 可视化流失点和参与度趋势
- 输出为交互式图表或静态图像

### 第四步：识别洞察与模式
- 发现一个或多个显著模式：
  - 特定群组的早期流失
  - 后期阶段参与度变化
  - 功能采用度聚集
  - 季节性或时间性趋势
- 突出显示意外发现和偏差
- 比较群组表现以建立基准

### 第五步：建议后续研究
- 推荐定性研究方法：
  - 针对流失用户的用户访谈
  - 高参与度群组的特征使用调查
  - 关键交互模式的会话回放
  - 高留存与低留存群组的赢/输分析
- 设计后续定量研究
- 建议 A/B 测试或功能实验

## 使用示例

**示例 1：上传 CSV 数据**
```
上传 cohort_engagement.csv，列包括：cohort_month、weeks_active、
user_id、feature_x_usage、engagement_score

请求："分析留存模式，并识别为何 2025 年第四季度群组表现低于第三季度"
```

**示例 2：描述数据格式**
```
"我拥有 2025 年 1 月至 12 月的月度用户群组数据。每行显示：
群组日期、用户 ID、购买频率和支持工单。
分析哪些群组表现出最佳长期留存度。"
```

**示例 3：功能采用度分析**
```
上传 feature_usage.xlsx，包含群组采用数据。

请求："比较新功能在群组间的采用曲线。
哪些群组采用最快？是否存在模式？"
```

## 核心功能

- **数据读取**：导入 CSV、Excel、JSON、SQL 查询结果
- **留存分析**：计算并可视化随时间的留存率
- **群组比较**：比较群组间的指标
- **异常检测**：标记异常模式或流失
- **Python 脚本**：生成可复用的分析代码用于持续分析
- **可视化**：创建热力图、图表和交互式仪表板
- **研究设计**：建议有针对性的后续研究和访谈方法
- **统计摘要**：提供定量指标和相关性分析
