# 在 Replicate 上提示图像模型

根据 Replicate 博客关于提示图像模型的文章（2024-2026）整理。这些技术模型无关，专注于可迁移的原则。

## 使用 API 选择模型，而非依赖记忆

本技巧描述了通用的提示技术。要选择模型，请使用 [find-models](../find-models/SKILL.md) 技能并查询 Replicate API。图像模型领域每周都在变化。不要根据你之前见过的名称就假设特定模型存在或仍然是顶尖的。始终在 API 中搜索当前选项，然后在运行任何内容之前阅读架构。

有关定价和功能比较，请参阅 [compare-models](../compare-models/SKILL.md) 技能。

## 编写提示

### 使用自然语言，而非关键词列表

用完整的句子描述你想要的内容。现代图像模型对语法和上下文的理解远比堆砌关键词的提示要好得多。

好的："一个女子站在黄昏时的东京巷子里，霓虹灯在湿漉漉的人行道上反射"
不好的："女子，东京，巷子，黄昏，霓虹灯，湿漉漉的人行道"

### 保持具体性和明确性

指定确切的颜色、材料、照明设置、相机设备以及空间关系。像"让它变得更好"或"艺术化"这样模糊的术语会得到不可预测的结果。

好的："一座 brutalist 混凝土建筑映照在雨后完美静止的水洼中。一个穿着红色雨伞的孤独身影沿着边缘行走，是这幅单色场景中唯一的色彩。阴天，均匀散射的光线，边缘使用移轴镜头效果。"
不好的："一个酷炫的建筑，附近有个人，雨天"

### 直接命名主体

使用描述性短语，如"留着黑色短发的女子"或"红色汽车"。避免代词，因为它们通常对图像模型来说太模糊了。

### 使用长而详细的提示

大多数现代模型接受数千个 token。结构清晰、描述详细的长提示比短提示效果更好。一个包含 12 个以上具体要求（物体上的文字、标记图表、颜色编码元素、特定材料）的提示可以起作用，前提是每个要求都表述得很清楚。但要小心：提示越长、越复杂，就越有可能遗漏某些内容。

### 从简单开始，然后迭代

从基本变化开始。先测试小的修改，然后再在此基础上进行。大多数编辑模型支持迭代编辑，所以要充分利用这一功能。

## 摄影术语

现代图像模型深入理解相机和摄影术语。使用这些词汇可以让你精确控制图像的外观。

### 相机和镜头

- 胶片类型：Kodak Portra 800、Fuji Velvia 50、Ilford HP5
- 镜头特性：50mm Summilux 全开光圈、85mm f/1.4、24mm 广角
- 景深：浅（主体清晰，背景模糊）、深（所有内容都清晰）
- 拍摄技巧：黄金时刻、蓝色时刻、长时间曝光、双重曝光

### 照明设置

- 伦勃朗光：经典的肖像照明，脸颊上有三角形光线
- 柔和的散射工作室照明：清晰的亮部和平和的阴影
- 轮廓光/背光：从后面用光线勾勒主体轮廓
- 均匀散射的光线：阴天，均匀照明，阴影最小
- 体积光：可见的光束、雾、薄雾

### 构图

- 三分法、居中构图、对称
- 远景、中景、特写、微距
- 俯视角度、低角度、平视角度、鸟瞰视角
- 移轴镜头制造微缩效果

## 文本渲染

在图像中渲染文本是一项常见任务。这些技术可以提高跨模型的准确性。

- 在提示中用双引号包裹所需的文本："设计一个标题为 'BLUE NOTE SESSIONS' 的海报，使用粗体压缩的无衬线字体"
- 坚持使用可读字体。高度风格化的文本可能效果不佳。
- 在现有图像中编辑文本时，使用模式："将 '旧文本' 更改为 '新文本'"
- 尽可能匹配文本长度：字符数量的巨大变化可能会改变布局
- 如果字体风格很重要，请明确说明要保留字体风格
- 对于复杂的排版（海报、版面布局），寻找将文本视为构图一部分而不是将其叠加在顶部的模型
- 一些模型可以进行文本 inpainting：遮盖要编辑的区域，然后用新文本提示，它会匹配原始字体和风格

## 风格迁移

- 直接命名确切风格："印象派绘画"、"1960 年代波普艺术"、"水墨画"
- 引用特定艺术家或流派以获得更清晰的指导
- 如果风格标签不起作用，描述其关键特征："可见的笔触、厚重的纹理、丰富的色彩深度"
- 指出应该保持不变的内容："保持原始构图"
- 当风格很难用文字描述时，一些模型支持基于示例的编辑：提供一个原始/修改后的图像对，然后提供一个第三张图像。模型推断转换并将其应用

## 角色一致性

在多次生成中保持角色一致性是图像生成中最难挑战之一。

- 从清晰的参考描述开始："留着黑色短发和绿色眼睛的女子，穿着海军蓝夹克"
- 说明正在改变的内容（场景、活动、风格）以及应该保持不变的内容（面部、表情、服装）
- 当模型支持时使用参考图像。一些模型可以同时处理多个参考图像以实现更强的连贯性
- 将复杂的角色变化分解为步骤：先改变服装，然后改变场景
- 生成合成训练数据：创建许多角色的图像，挑选最好的，用于微调或作为参考

## 图像编辑

### 基本原则

- 指定要保留的内容：明确说明应该保持不变的内容。使用"保持姿势和表情不变"或"保持原始构图"等短语
- 仔细选择动词："transform" 暗示全面重做。使用具体动作，如"将她的服装改为维京服装，保持她的面部和表情不变"或"用海滩替换背景"
- 精确指定范围："将背景改为海滩，同时保持人物在完全相同的位置，保持相同的主体位置、相机角度、构图和透视。仅替换他们周围的环境"

### 物体移除

- 描述应该填充留下的空间，而不仅仅是说明要移除什么
- 一些编辑模型可以干净地处理移除；其他人会留下结构性伪影。如果一个模型处理不好，请尝试另一个

### 背景编辑

- 详细描述新背景：照明、时间、环境
- 指定主体应保持在完全相同的位置和相同的光照条件下

### 透视和角度变化

- 这些是最难编辑的。并非所有模型都能很好地处理它们
- 一些模型将自己限制在初始构图内，难以处理新角度

### Inpainting 和 outpainting

- 对于 inpainting：遮盖要编辑的区域，然后用应该填充的内容提示
- 一些模型有"魔法提示"或自动重写功能。当它开启时，你可以专注于描述要编辑的区域。当它关闭时，描述整个场景
- 仅描述遮盖区域会使模型更强调提示，这可以对目标编辑产生更好的结果
- ControlNet 风格的条件（边缘检测、深度图）有助于在生成过程中保留结构

## 多图像和故事板生成

一些模型可以在单个提示中生成多个相关图像。

- 要求"一系列"、"一组"，或指定网格布局（例如，"2x2 故事板网格"）
- 分别描述每个面板，并使用一致的字符描述
- 通过重复确切的描述来保持风格和角色的一致性
- 一些模型支持基于示例的编辑：为一张图像提供一个原始/修改后的图像对，然后将相同的转换应用于其他图像

## 产品摄影和商业工作

- 精确指定材料："抛光钢"、"磨砂铝"、"牛皮纸"、"磨砂玻璃"
- 描述照明设置："柔和的散射工作室照明，清晰的亮部和平和的阴影"
- 对于品牌资产和图标，寻找可以生成原生 SVG 输出（真实的可编辑矢量文件）的模型
- 对于包含品牌和文字布局的布局，寻找具有强大排版和设计构图能力的模型

## 微调和 LoRAs

- 在每个提示中使用你训练模型的触发词
- 当组合多个 LoRAs 时，使用比例参数（通常为 0.9-1.1）平衡它们的影响
- 生成合成训练数据：生成许多图像，挑选最好的，重新训练
- 使用一致角色工作流程从单个参考图像生成训练数据

## 常见陷阱

1. **关键词堆砌的提示**：现代模型对自然语言句子比逗号分隔的关键词列表反应更好。像描述场景一样写作，而不是给照片打标签。

2. **当你想要小编辑时使用 "transform"**："将这个人变成维京人" 可能会完全改变身份。使用目标语言："将她的服装改为维京服装，保持她的面部和表情不变。"

3. **没有指定要保留的内容**：在编辑时，始终说明应该保持不变的内容。如果没有明确的指示，模型可能会改变任何内容。

4. **在未针对它们进行训练的模型上使用负面提示**：一些模型没有用负面提示进行训练。在这些模型上使用它们会引入噪声，而不是移除不需要的元素。检查模型的文档。

5. **指导比例 (CFG) 太高**：如果图像看起来"烧焦"并有过多的对比度，请降低指导比例。每个模型都有一个推荐范围。

6. **期望实时知识**：没有图像模型有互联网访问权限。一些模型从训练数据中 baked in 强大的世界知识，但它不是实时的。

7. **对于复杂场景使用短提示**：现代模型接受数千个 token。对于具有许多具体要求的复杂构图，使用这种容量。

8. **忽略纵横比**：大多数模型有它们最佳工作的特定分辨率（通常约为 1 兆像素）。太大会产生边缘伪影。太小会产生生硬的裁剪。使用模型推荐的纵横比。

9. **为任务选择错误的模型**：并非每个模型都擅长每个任务。有些在文本渲染方面表现出色，但在物体移除方面表现不佳。有些在风格迁移方面很棒，但在背景编辑方面很糟糕。如果一个模型在特定编辑类型上表现不佳，请尝试另一个，而不是与提示作斗争。有关指导，请参阅 [compare-models](../compare-models/SKILL.md) 技能。

10. **不迭代**：最好的结果来自迭代工作流程。进行小的改变，评估，细化，重复。不要试图在单次生成中就做对一切。
