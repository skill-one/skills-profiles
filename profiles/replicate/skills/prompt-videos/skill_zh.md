# 在 Replicate 上提示视频模型

本文内容源自 Replicate 博客中关于提示视频模型的文章（2025-2026 年）。这些技术对模型无关，专注于可迁移的原则。

## 使用 API 选择模型，而非依赖记忆

本技巧描述了通用的提示技术。要选择模型，请使用 [find-models](../find-models/SKILL.md) 技能并查询 Replicate API。视频模型领域每周都在变化。不要根据你之前见过的名称就假设某些模型存在或仍然是顶尖的。始终在 API 中搜索当前选项，然后在运行任何内容之前阅读架构。

有关定价和功能比较，请参阅 [compare-models](../compare-models/SKILL.md) 技能。

## 场景描述

一个好的视频提示是一个场景描述，而不是标题。描述发生了什么、在哪里发生以及它看起来如何。

### 将这些元素分层到每个提示中

1. **主体**：场景中谁或什么（一个人、动物、物体、风景）。
2. **背景**：主体在哪里（室内、城市街道、森林、太空走廊）。
3. **动作**：主体做什么（走路、转身、拿起电话、奔跑）。
4. **风格**：视觉美学（电影感、动画、定格动画、纪录片）。
5. **摄像机**：摄像机如何移动（摇摄镜头、跟踪、静态、手持）。
6. **构图**：如何拍摄画面（远景、特写、过肩镜头）。
7. **氛围**：情绪和光照（暖色调、蓝色光线、黄金时刻、阴天）。

### 具体描述，而非模糊描述

模糊： "一辆车追逐"

具体： "一场高速车追逐，发生在夜晚被雨水浸湿的高速公路上。两辆肌肉车在 140 英里/小时的速度下穿梭于车流中，车灯划破暴雨。一辆车撞上一辆卡车，火花四溅，横跨六个车道。轮胎在积水上水滑。霓虹高速公路标志在头顶模糊地旋转。"

### 过度描述

现代视频模型能够很好地处理长而密集的提示。不要写 "一个男人在打电话"。写 "一个绝望的男人穿着一件破旧的绿色风衣，拿起一个安装在粗糙砖墙上的老式转盘电话，沐浴在绿色霓虹灯的诡异光芒中。" 你添加的每一条具体细节都会给模型更少的自由度去胡乱发挥。

### 直接命名主体

使用描述性短语，如 "穿着红色夹克的女人" 或 "留着胡子的男人穿着法兰绒"。避免代词，因为它们对视频模型来说和图像模型一样具有歧义性。

## 摄像机和电影摄影

视频模型理解电影制作语言。使用它来指导镜头，而不是希望得到好的构图。

### 枪机类型

使用标准的枪机术语来控制构图：

- 远景/建立镜头：显示整个场景和环境。
- 中景：从腰部左右拍摄主体。
- 特写：用主体的脸或关键物体填满画面。
- 极特写：隔离一个细节（一只眼睛、一只紧握把手的手、一滴水）。

### 摄像机运动

描述摄像机如何移动：

- 静态/三脚架：锁定，无运动。
- 摇镜头：水平旋转左或右。
- 倾斜：垂直旋转上或下。
- 推镜头：摄像机向主体物理移动或远离。
- 跟踪：摄像机与主体一起移动。
- 俯仰：垂直上升或下降。
- 手持：摇晃，纪录片风格运动。
- 飞行器/航拍：俯视或扫视的鸟瞰镜头。
- 推镜头变焦（希区柯克/眩晕效果）：背景拉伸，而主体保持锁定。

### 摄像机位置

指定摄像机的高度和角度：

- 眼平线：中立、自然视角。
- 低角度/虫眼：向上看主体（使主体感觉强大或有压迫感）。
- 高角度/鸟眼：向下看（使主体感觉渺小或脆弱）。
- 过肩镜头：从另一个主体背后框定一个主体。
- 第一人称/主观镜头：摄像机是主体的眼睛。

### 镜头和焦点语言

- 浅景深：主体清晰，背景模糊。
- 深景深：从前景到背景一切都清晰。
- 微距镜头：极端特写，浅景深。
- 广角镜头：夸张的透视，更多环境可见。
- 倾斜变焦：微型效果，选择性焦点带。

### 升级模式

对于短视频，自然的进展是远 > 中 > 特写 > 极特写。这很好地映射到 8-15 秒的视频，并为模型提供了清晰的结构。例如：

- 0-3 秒：地点的远景建立镜头，静态摄像机，黎明时的雾蒙蒙竹林。
- 3-7 秒：中景，慢推入，战士向前迈步。
- 7-12 秒：特写，轨道镜头，战士出击，慢动作。
- 12-15 秒：极特写，细节（一只手、一只眼睛、一滴雨）。

每个镜头应指定：

- 摄像机位置和运动
- 主体动作
- 光照或情绪变化

### 过渡语言

使用明确的过渡指令在镜头之间进行过渡：

- "硬切到..." 用于突然切换。
- "无缝变形到..." 用于流畅过渡。
- "快速摇摄到..." 用于快速、充满活力的切换。
- "猛切到..." 用于令人震惊、戏剧性的转换。

没有明确的过渡，模型会即兴发挥，这可能与你的意图不符。

### 示例：多镜头广告

```
(0-3 秒) 微距镜头：一个豪华香水瓶在散落的粉红色牡丹花中，浅景深，花瓣在温暖的午后阳光下漂浮，柔和的环境音乐。
(3-7 秒) 摄像机滑入，一只女性的手从右侧进入画面，手指轻轻触摸玻璃瓶，丝绸摩擦的声音。
(7-12 秒) 硬切到慢动作喷洒，金色迷雾在空中扩散，颗粒在暗背景下反射轮廓光，喷雾器的嘶嘶声。
(12-15 秒) 无缝拉出到英雄镜头，产品居中，体积感光照，极简奶油背景，优雅的寂静。
```

## 参考输入

许多视频模型接受图像、视频片段或音频文件作为参考输入，与文本提示一起使用。这使工作流程从"提示"转变为更接近"导演"。

### 图像到视频

提供一个起始图像并描述运动。模型从该帧进行动画。

- 输入图像成为视频的第一帧
- 描述变化（动作、摄像机运动），而不是模型已经可以看到的静态场景
- 风格保留是一个优势：动画风格、绘画、照片和色彩分级都得以保留
- 为了最大限度地控制风格，首先使用专门的图像模型生成起始图像，然后将其传递给视频模型

### 第一帧和最后一帧插值

一些模型接受起始和结束图像。模型生成它们之间的过渡。这适用于：

- 主体之间的变形（例如，一种动物变成另一种动物）
- 之前/之后的变形（房间翻新、季节变化）
- 控制叙事弧，其中你知道起始和结束状态

### 主体参考

一些模型接受角色、产品或物体的参考图像，并在生成的视频中保持其外观。这适用于：

- UGC 风格的产品评测视频（角色参考图像 + 产品参考图像）
- 跨多个视频片段的品牌一致性
- 将现有角色放置在新场景中

当参考输入资产时，许多模型在提示中使用括号语法，如 `[Image1]` 或 `[Audio1]`，以指定哪个参考映射到哪个角色："[Image2] 在 [Image1] 的内部。"

### 音频驱动生成

一些模型接受音频文件，并将生成的视频与音频同步。模型可以匹配：

- 嘴唇运动与语音
- 切换和运动与音乐节拍
- 环境节奏与环境声音

在使用音频参考时，最好在文本提示本身中也转录音频内容，并使视频持续时间与音频长度匹配。

### 多参考工作流程

最强大的结果来自于结合多种参考类型：

- 一个角色外观的图像
- 一个视频片段用于运动风格
- 一个音轨用于节奏和节奏
- 一个文本提示描述如何将所有内容结合起来


## 风格控制

### 明确命名风格

视频模型理解风格标签。直接在提示中包含它们：

- "以黏土动画风格"
- "皮克斯动画风格"
- "动漫"
- "定格动画"
- "8 位复古"
- "漫画书"
- "纪录片片段"
- "折纸"
- "乐高"
- "蓝图技术绘图"

风格标签不仅影响视觉外观，还影响角色如何移动和互动。黏土动画风格产生笨拙、定格动画的运动。动漫风格产生流畅、夸张的运动。

### 质量锚点

短语如 "超逼真，8k" 或 "电影感" 推动模型朝其最高保真度输出。当你想要逼真的结果时使用它们。

### 电影和类型语言

参考特定类型或电影制作风格以营造情绪和基调：

- "迈克尔·曼电影摄影"（霓虹灯、夜晚、城市）
- "韦斯·安德森"（对称、粉彩色、古怪）
- "罗杰·德凯恩斯光照"（自然主义、精确）
- "银翼杀手 2049 电影摄影"（大气、橙色/青色）
- "国家地理纪录片"（自然、稳定、观察）

### 使用输入图像进行风格

与其用语言描述风格，不如使用图像模型生成你想要的精确美学图像，然后将它传递给视频模型。这让你对外观有像素级的控制。视频模型保留风格、色彩分级和构图，同时添加运动。

### 颗粒和纹理

添加 "略微颗粒感，电影感" 或 "VHS 风格" 将输出从过于干净的 AI 外观推向更有机的视频。

## 角色一致性

### 逐字重复描述

当生成具有相同角色的多个片段时，在提示中跨提示使用相同的角色描述。创建一个 "角色表"，使用确切的措辞：

"约翰，一个 40 多岁的男人，留着棕色短发，穿着蓝色夹克和眼镜，看起来若有所思"

将此描述粘贴到约翰出现的每个提示中。描述越具体、越独特，结果就越一致。

### 要指定什么

- 外貌：年龄、头发、皮肤、身材
- 衣服：确切的衣物、颜色、材料
- 配饰：眼镜、珠宝、帽子
- 表情或态度：若有所思、愉快、强烈

### 改变场景，而不是角色

当将一致的角色放置在不同的场景中时，只改变动作、位置和摄像机工作。保持角色描述逐字相同。

### 参考图像用于身份

如果模型支持主体参考图像，使用角色的清晰照片作为输入。这比单独的文本描述更可靠，尤其是在跨片段保持面部特征时。

## 常见陷阱

1. **未描述音频**：如果你跳过音频提示，模型会想象环境声音。一个常见的失败是添加不适当的笑声或 "现场观众"。始终描述声音场景。

2. **镜头长度过多的对话**：一个 8 秒的镜头可以容纳大约 2-3 个简短的句子。塞入一个段落会产生不自然的快速说话或截断输出。

3. **镜头长度过少的对话**：如果你只提供几个词给长镜头，模型会用胡言乱语或尴尬的停顿填充沉默。使对话长度与镜头持续时间匹配。

4. **未指定要保留不变的内容**：在使用参考图像或编辑时，始终说明应该保持不变的内容。没有明确的指令，模型可能会改变任何东西。

5. **期望从相同的提示中获得变化**：与图像模型不同，一些视频模型对相同的提示（即使使用不同的种子）产生非常相似的输出。如果你想要变化，改变提示，而不是重新运行它。

6. **未提示摄像机运动**：没有摄像机指导，你会得到静态镜头或不可预测的运动。明确描述摄像机。

7. **字幕污染**：许多模型是在带有内置字幕的视频上训练的。使用冒号进行对话（而不是引号），添加 "(无字幕)"，并在必要时重复。

8. **对复杂场景的模糊提示**：现代视频模型可以处理长而详细的提示。如果每个要求（摄像机运动、光照、声音设计、主体动作、环境细节）都明确陈述，具有 12 个以上的具体要求的提示可以起作用。不要低估你想要的东西。

9. **忽略宽高比和分辨率**：大多数视频模型有特定的分辨率支持（480p、720p、1080p）。检查模型支持什么，并选择适合你用例的正确分辨率。如果你需要竖屏视频，而模型只输出横屏，你可能需要使用单独的工具重新构图。

10. **忘记视频模型没有互联网访问权限**：没有视频模型有实时信息。它们基于训练数据工作。不要期望它们了解时事或实时信息。
