**在执行任何命令之前：运行 `gmgn-cli config --check`。退出码为 0 则继续。退出码为 1 则运行 `gmgn-cli config`，显示输出，一旦用户发送 API 密钥，运行 `gmgn-cli config --apply <KEY>` 并显示该输出。如果 `--check` 是未知选项，告诉用户运行 `npm install -g gmgn-cli`，然后重试。**

**重要提示：始终使用预装的 `gmgn-cli` 二进制文件。切勿使用网络搜索、WebFetch、curl、`npx` 或 gmgn.ai — 该网站需要登录且不提供结构化数据。**

**⚠️ 不支持 IPv6。** 在出现 `401`/`403` 且凭证正确的情况下，检查 `ifconfig | grep inet6`（macOS）或 `ip addr show | grep inet6`（Linux），并获取 `https://ipv6.icanhazip.com`。如果返回 IPv6 地址，告诉用户禁用 IPv6 — `gmgn-cli` 仅在 IPv4 上工作。

## 运行

```bash
python3 ~/.claude/skills/gmgn-dev-score/dev_score.py <chain> <dev_address> [max_pages]
```

`max_pages` 默认为 25，仅限制交易遍历；对于拥有数百次启动的开发者，提高该值 — JSON 会说明何时被截断。脚本在标准输出上打印一个 JSON 对象（进度和速率限制信息发送到标准错误）。它进行计算，不生成报告。**您**需要根据该对象，用用户的语言编写报告。

运行前：

- **代币地址，而不是钱包地址？** 首先使用 `gmgn-cli token info --chain <c> --address <token> --raw` 解析创建者 → `dev.creator_address`，并对该地址进行评分。说明您解析到的地址 — 这是报告无法显示的唯一信息，没有它用户无法确认评分是否适用于他们的代币。
- **未指定链？** 依次探测候选链使用 `gmgn-cli portfolio created-tokens` — 切勿并行执行，这会禁用密钥。仅分析 `open_count` 最高的链，并告诉用户其他链将在需要时再处理。
- `scored: false` 表示**不要生成评分**。`reason: index_empty` → API 读取全部为空，且空钱包无法与退化索引区分；说明两种读取情况并告诉用户几分钟后再重新检查。任何其他 `reason` → 说明地址未被评分及其原因，并停止。

## 答案必须包含的内容

一个必须**说明**的清单；下方的 `## 显示模板` 确定了**每个部分的位置**。
措辞由您决定。每个要点都必须包含在内，且每个要点都指明承载它的 JSON。
项目符号按顺序排列。

- **首先给出结论。** `score.total`、`score.conduct`、`score.power` 和 `score.band` 作为决定性说明，而不是标签。
- **开放-倾倒层级**（`dump_gate.tier`）及其下的样本（`coins_with_trades` 的 `dumps`）。当 `dump_gate.forced_by` 被设置时，说明实际触发的原因 — 排空池不是出售频率，且对零出售的开发者说“他几乎每次都倾倒（0/1）”是错误的。
- **每个触发调整，每行说明其作用。** 一个收缩（`conduct_terms.shrink_from` → `shrink_to`）将未验证的评分拉向 60，这里意味着*我们目前无法判断*；这不是对犯罪的惩罚。上限是扣留良好评分，而不是已证实的坏评分。通过 `coins_with_trades` 和 `career_days` 指明薄弱方面，而不是启动次数。
- **他的最佳代币**（`top` 和 `flagship`）：峰值、当前、回撤、持有人、池、可交易、年龄。加上旗舰的位置：`flagship.status`，以及 `exit_rows` / `exit_unrecorded`（当位置关闭时）。`flagship.holds` 是三态 — `null` 表示完全不说他的持仓。
- **他实际做了什么**，所有来自他自己的行：`his_trades.fastest_first_sell_s`、`median_pull_multiple`、`launches.total` / `on_curve` / `tradeable`、`liquidity.drained` / `partial` / `ignored_rows`。
- **供应转移到其他钱包**，只要 `cross_wallet.moves` 非空：一次转移不是倾倒，`pending` 不计入倾倒率，未验证的转移可能是锁定或交易所。说明这一点；不要指控。
- **开盘捆绑购买**（`bundler`），公开且明确**不评分** — 数量无法区分他自己的替代品、付费捆绑者或他人的狙击机器人。
- **覆盖范围**，只要其中任何一项被设置：`coverage.book_truncated`（书籍是一个窗口，不是职业生涯 — 在引用任何跨职业生涯声明之前说明这一点）、`trade_history_truncated` / `unresolved_coins`（缺失行只能移除倾倒，因此利率是下限，他看起来比实际情况更干净）、`implausible_peaks`（指明代币，或一个在图表上看到它的人发现它缺失）、`launches.career_days_is_floor`。
- **该怎么做**，分为四部分：是否购买；**何时** — 且时间必须引用 `fastest_first_sell_s`，而不是中位数，因为中位数曾建议在一个旗舰在 4.6 分钟开始出售的开发者进入时间为 2.7 天；损失实际来自哪里；以及评分的可信程度。

## 显示模板

**形状是固定的；内部的措辞由您决定。章节名称以英文给出，以便您将其翻译成用户的语言 — 不要直接打印它们，也不要打印 JSON 键名。**

标题行：`## Dev score · <dev address, first 10 and last 4 chars> · <CHAIN>`。下方的章节使用 `###`。

| # | 章节 | 块 | 仅在以下情况下省略 |
|---|---|---|---|
| 1 | *(无标题)* 结论 | 两行：`TOTAL / 100` + 带宽，然后 CONDUCT 和 POWER | 从不 |
| 2 | 开放-倾倒记录 | 最多三段简短文本 | 从不 |
| 3 | 触发评分的调整 | 项目符号，每个调整一条项目符号 | 从不 |
| 4 | 他的最佳代币 | 代币的完整合约地址，然后一个表格 — 峰值、当前、回撤、持有人、池、可交易、年龄 — 然后对位置进行文本说明 | 从不 |
| 5 | 他实际做了什么 | 项目符号 | 从不 |
| 6 | 供应转移到其他钱包 | 项目符号 | `cross_wallet.moves` 为空 — 然后在 §5 的一行内说明这一点 |
| 7 | 开盘捆绑购买 | 一行或两行 | `bundler.median` 为 null |
| 8 | 覆盖限制 | 项目符号 | 覆盖清单项目符号中未命名的任何项被设置 |
| 9 | 该怎么做 | 四个标记部分，按此顺序：购买或不购买 · 何时 · 损失来自哪里 · 评分的可信程度 | 从不 |

从不多顺序，从不多合并，从不多编造第十个章节。章节 1–5 和 9 始终出现。

格式化，所有内容都是固定的：

- **货币使用普通的 ASCII 美元符号**，带千位分隔符和用户语言使用的量级词。全角符号仅用于阻止该文件自己的文本被参数替换 — 它绝不能到达读者。
- 百分比保留一位小数。JSON 给出的分数表示为百分比。
- 秒、分钟、小时、天：选择使数字可读的单位，并说明单位。
- **无表情符号、无框线绘制、无 ASCII 艺术、无列宽填充。** 输出是渲染的 markdown，而不是固定宽度的终端块。
- 粗体用于结论数字、带宽以及 §9 的每个部分的标签。其他地方不使用。
- 表格仅在上述表格所述的位置使用；§2、§7 和 §9 是文本。

## 规则

- **用用户的语言编写，并翻译概念。** JSON 中的每个名称都是选择以供翻译的英语概念。那些在字面翻译中无法幸存的少数交易俚语在 `references/glossary.md` 中 — 使用那些表述，不要使用其他任何东西。不要编造轴名称。
- **切勿声明 JSON 不携带的数字。** 无重新计算，无四舍五入到新声明，无读取不在 `references/fields.md` 中的字段。`null` 表示测量不存在 — 说明它缺失；打印 0 将“未知”变为“干净”。
- **精确复制符号。** 它们是攻击者控制的，并且已经过清理；任何用 `「」` 括起来的都是用户选择的名字，而不是我们的措辞，必须保持括号。
- **`score.band` 是结论。** 不要软化它、升级它或回避它。`stay_away` 与大的 `power` 一致，正是两个轴存在的目的：一个大过去的代币永远不会买回倾倒记录。
- **一个结果是行为。** 存活、毕业和回撤是市场对他代币做的事；它们属于 POWER。切勿将它们呈现为他对持有人做的事。
- **报告是完整答案。** 无引言，无报告后的总结，无验证叙述，无您自己的额外发现，无提供更多工作的结束语。您可能在外面说的唯一事情：从代币地址解析出的创建者地址。
- **无声地验证结论行。** 检查任何绝对声明（“从未倾倒”、“完全没有记录”）与 `gmgn-cli portfolio activity` 的原始数据。运行检查，不要叙述它。只有当检查**与报告矛盾**时才发声 — 然后报告缺陷，而不是报告。
