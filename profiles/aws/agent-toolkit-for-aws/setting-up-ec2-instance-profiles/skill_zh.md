# 设置 EC2 实例配置文件

## 概述

领域专业知识，用于使用 IAM 角色和实例配置文件授予 EC2 实例对 AWS 服务的安全访问权限。涵盖完整生命周期：识别所需权限、创建或重用具有最小权限策略的 IAM 角色创建实例配置文件、将它们附加到 EC2 实例，并验证凭证可用性。

## 配置 EC2 实例配置文件

要为 EC2 实例设置 IAM 角色和实例配置文件，请严格按照程序操作。请参阅 [EC2 实例配置文件设置程序](references/ec2-instance-profile-setup.md)。

## 故障排除

### 未找到实例

验证实例 ID 和区域是否正确。使用 `aws ec2 describe-instances --region <region>` 列出实例。

### 实例已存在配置文件

该程序处理替换 — 它将在解除关联现有配置文件之前提示。

### 附加后凭证不可用

实例配置文件传播可能需要 30-60 秒。应用程序可能需要重新启动以获取新凭证。

### 访问被拒绝错误

检查角色的策略是否包含所需操作和资源 ARN。查看 CloudTrail 日志以了解被拒绝的具体操作。

### 应用程序仍然使用硬编码凭证

从配置文件、环境变量 (`AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`) 和 `~/.aws/credentials` 中删除凭证。然后，SDK 默认凭证链将使用实例配置文件。
