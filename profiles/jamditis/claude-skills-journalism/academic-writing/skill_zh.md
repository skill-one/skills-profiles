# 学术写作与研究方法

系统化的学术写作方法、研究设计以及学术交流方法。

## 研究设计基础

### 研究问题发展

```markdown
## 构思研究问题

### FINER 标准
- **F**easible：你能实际完成这项研究吗？
- **I**nteresting：它对领域重要吗？
- **N**ovel：它是否增加新知识？
- **E**thical：它能否合乎道德地完成？
- **R**elevant：它是否解决实际问题？

### 问题类型
| 类型 | 目的 | 例子 |
|------|-------|-------|
| 描述性 | 记录现象 | "X 的特征是什么？" |
| 比较性 | 比较组别/条件 | "X 在不同组别之间有何差异？" |
| 相关性 | 检验关系 | "X 和 Y 之间是否存在关系？" |
| 因果性 | 建立因果关系 | "X 是否导致 Y？" |
| 探索性 | 生成假设 | "哪些因素可能解释 X？" |

### 优化你的问题
从宽泛开始 → 逐步缩小范围

草稿 1："社交媒体如何影响政治？"
草稿 2："Twitter 的使用如何影响政治极化？"
草稿 3："接触党派性 Twitter 账户如何影响美国成年人政治态度极化？"
草稿 4："增加接触同质化 Twitter 信息流是否会增加 18-35 岁参与政治的美国成年人情感极化？"
```

### 文献综述策略

```markdown
## 系统文献检索

### 按领域选择数据库
- **跨学科**：Web of Science、Scopus、Google Scholar
- **社会科学**：JSTOR、ProQuest、SSRN
- **传播学**：Communication Abstracts、ComAbstracts
- **健康**：PubMed、MEDLINE、CINAHL
- **教育**：ERIC
- **商业**：Business Source Complete

### 检索策略模板
1. **从研究问题中识别关键概念**
2. **为每个概念生成同义词**
3. **使用布尔运算符组合**

以 "社交媒体政治极化" 为例：

概念 1：社交媒体
- OR：Twitter、Facebook、Instagram、"社交网站"、"在线平台"、"数字媒体"

概念 2：政治
- OR：党派性、意识形态、选举、公民

概念 3：极化
- OR：分裂、极端主义、"态度变化"、激进化

组合检索：
(Twitter OR Facebook OR "社交媒体" OR "社交网站")
AND (政治 OR 党派性 OR 意识形态)
AND (极化 OR 分裂 OR 极端主义)

### 包含/排除标准
记录你的标准：
- 发表日期范围：[X 至现在]
- 语言：[仅英语 / 多种语言]
- 发表类型：[仅同行评审 / 包含预印本]
- 地理范围：[全球 / 特定国家]
- 研究方法：[所有方法 / 特定方法]

### 管理检索
- 保存检索以供后续重新运行
- 将结果导出到参考文献管理器
- 跟踪每个阶段的检索结果数量
- 记录每次检索的日期
```

## 论文结构与写作

### IMRaD 结构（科学论文）

```markdown
## 标准研究论文部分

### 摘要（通常 150-300 字）
- 背景（1-2 句）
- 目的/目标（1 句）
- 方法（2-3 句）
- 结果（2-3 句）
- 结论（1-2 句）

### 引言
**漏斗结构：**
1. 广阔背景 - 为什么这个主题重要？
2. 聚焦 - 具体问题是什么？
3. 差距识别 - 我们不知道什么？
4. 研究问题/假设 - 你将研究什么？
5. 贡献预览 - 为什么这项研究很重要？

### 文献综述
**按主题组织，而非按时间顺序：**
1. 主题 1：关键发现、争论、差距
2. 主题 2：关键发现、争论、差距
3. 主题 3：关键发现、争论、差距
4. 综合：主题如何与你的研究相关联

### 方法
**可重复性测试：** 另一个研究者能否仅凭这一部分复制你的研究？

包括：
- 参与者/样本（谁，如何选择，N）
- 材料/测量（什么工具，其有效性）
- 程序（一步一步发生了什么）
- 分析方法（统计测试、定性方法）
- 伦理考虑（IRB、知情同意）

### 结果
**报告，不要解释：**
- 系统地呈现发现
- 使用表格/图表呈现复杂数据
- 报告效应量，而不仅仅是 p 值
- 回答每个研究问题/假设

### 讨论
**反向漏斗结构：**
1. 关键发现总结
2. 在文献背景下解释
3. 理论意义
4. 实践意义
5. 局限性
6. 未来研究方向
7. 结论
```

### 学术写作风格

```markdown
## 写作规范

### 语气和时态
| 部分 | 时态 | 例子 |
|------|-------|-------|
| 摘要 | 过去（方法/结果），现在（结论） | "我们发现... 这表明..." |
| 引言 | 现在（建立既有知识） | "研究表明..." |
| 方法 | 过去 | "参与者完成了..." |
| 结果 | 过去 | "分析显示..." |
| 讨论 | 现在 + 过去 | "这些发现表明... 我们发现..." |

### 委婉语言
适当使用委婉语（避免过度主张）：
- "这可能表明..."（而不是“这证明了...”）
- "可能与...有关"（而不是“导致”）
- "结果表明..."（而不是“结果明确证明...”）
- "一种可能的解释是..."（而不是“解释是...”）

### 按功能分类的过渡词
**添加：** furthermore、moreover、additionally、in addition
**对比：** however、nevertheless、conversely、in contrast
**因果关系：** therefore、consequently、as a result、thus
**举例：** for instance、specifically、to illustrate
**顺序：** first、subsequently、finally、meanwhile
**总结：** in summary、overall、in conclusion

### 段落
每个段落应：
1. 以主题句开头
2. 包含一个主要观点
3. 包括支持证据
4. 与相邻段落建立联系
5. 平均 100-200 字（因领域而异）
```

### 常见写作问题

```markdown
## 需要避免的问题

### 词语冗余
❌ "值得注意的是，结果证明了..."
✅ "结果证明了..."

❌ "为了调查..."
✅ "调查..."

❌ "共有 50 名参与者..."
✅ "50 名参与者..."

### 动词薄弱
❌ "这项研究由研究人员进行"
✅ "研究人员进行了这项研究"

❌ "发现存在显着差异"
✅ "我们发现存在显着差异"

### 含糊语言
❌ "一些研究表明..."
✅ "三篇研究（作者，年份；作者，年份；作者，年份）表明..."

❌ "结果显着"
✅ "结果在统计上显着（p < .05, d = 0.45）"

### 不必要的术语
- 首次使用技术术语时定义
- 当同样精确时使用更简单的词
- 考虑你的受众的专业知识水平

### 引文问题
❌ 未注明的情况下引用了二手资料
✅ "(作者，年份，引自作者，年份)"

❌ 未综合地串联引文
✅ 将提出相同观点的引文分组；区分不同的引文
```

## 发表策略

### 期刊选择

```markdown
## 评估期刊

### 质量指标
- 影响因子（谨慎使用）
- 接受率
- 审稿时间
- 发表时间
- 在你领域的声誉
- 索引（Web of Science、Scopus）

### 匹配指标
- 范围匹配
- 受众匹配
- 文章类型（实证、理论、综述）
- 开放获取途径（见下文）

### 开放获取途径
- **黄金 OA**：在完全开放获取期刊中发表 OA；通常需要文章处理费 (APC)，通常为 $1,000-$3,000+。
- **绿色 OA**：封闭获取期刊，但作者在出版商允许的 embargo 期内将接受的稿件存档在存储库（机构、arXiv 等）。
- **钻石/白金 OA**：完全开放获取期刊，无 APC；由赞助商（学会、大学、联盟）支持。在社会科学和人文学科中越来越常见。
- **混合型**：封闭获取期刊，允许单独文章以 APC 形式 OA。注意：混合型 *不符合* Plan S 合规性，也不符合许多资助者的 OA 命令，提交前请核实。
- **青铜**：免费阅读，无正式 OA 许可；出版商可以撤销访问。在合规目的上将其视为非 OA。

### 资助者命令（美国 + 欧洲，截至 2026 年）
- **OSTP Nelson备忘录（美国）**，联邦资助的研究必须在发表后立即公开获取，无 embargo。实施截止日期为 **2025 年底**，因此截至 2026 年，这对所有主要美国资助者（NIH、NSF、DOE、NASA 等）都适用。
- **Plan S（cOAlition S）**，欧洲资助者（Wellcome、UKRI、ANR、许多其他）要求立即以黄金或钻石 OA 形式发表，或无 embargo 且具有 CC-BY 许可的绿色 OA。混合型不符合要求。
- 提交前请核实目标期刊的最新政策，接受的途径会变化，一些资助者会限制 APC。

### 陷阱（掠夺性期刊）
- 积极的电子邮件推销
- 快速“同行评审”（几天）
- 不明确的编委会
- 未在主要数据库中索引
- “付费发表”而无明确的 OA 模型
- 网站质量差

### 审核期刊 + 伦理资源
- **Think. Check. Submit.**（thinkchecksubmit.org），合法性清单。
- **DOAJ**（开放获取期刊目录），经审核的 OA 期刊索引。
- **Journal Citation Reports**，付费 Web of Science 产品，用于影响因子。
- **Cabells Predatory Reports**，基于订阅的替代品，用于 2017 年被撤下的原始 Beall's List（2017 年后被撤下，只有陈旧的镜像仍然存在，不要将其作为当前信息的来源）。
- **Retraction Watch Database**，可搜索的撤稿和出版商不当行为记录；用于审核作者和期刊。
- **COPE**（出版伦理委员会，publicationethics.org），编辑和作者在伦理和诚信方面的权威指南。
- **ICMJE**（国际医学期刊编辑委员会，icmje.org/recommendations），定义作者资格、利益冲突披露和报告标准，在许多领域都使用。

## 预印本和持久标识符

### 预印本服务器（发布工作版本，提前获得引用）

预印本是作者在正式同行评审前提交的稿件。现在大多数期刊都允许（或积极鼓励）预印，如果你不确定，请提交前核实目标期刊的政策。

| 服务器 | 领域 | 备注 |
|--------|-------|-------|
| **arXiv** (arxiv.org) | 物理学、数学、计算机科学、定量生物学、经济学、统计学 | 最古老、最大；由各领域审核。 |
| **SSRN** (ssrn.com) | 社会科学、法律、经济学、金融 | 自 2016 年由 Elsevier 拥有，一些作者更喜欢 SocArXiv 作为替代。 |
| **bioRxiv** (biorxiv.org) | 生物学 | 冷泉港实验室；广泛引用。 |
| **medRxiv** (medrxiv.org) | 健康科学、医学 | 轻度审核安全声明；不要在没有预先注册的情况下预印临床试验结果。 |
| **EarthArXiv** | 地球、行星、环境科学 | 通过 OSF 基础设施运行的社区项目。 |
| **PsyArXiv** | 心理学 + 行为科学 | OSF 托管的。 |
| **SocArXiv** | 社会学 + 社会科学 | OSF 托管的；Elsevier 的替代品，SSRN。 |
| **EngrXiv** | 工程 | OSF 托管的。 |

**预印的原因：** 更早的时间戳（优先权主张）、在期刊接受前可引用，以及更广泛的反馈（在最终评审前）。（2026 年 OSTP Nelson 备忘录规定了联邦资助的美国研究的同行评审版本在发表后立即公开获取，这不是预印命令。预印是一种自愿选择，补充而不是满足 Nelson 备忘录合规性。）

### 持久标识符，获取 ORCID 并使用 DOI

- **ORCID iD** (orcid.org)，免费 16 位标识符，可明确地将你跨出版商、资助者和机构链接。大多数主要期刊和资助者都要求使用。将其连接到你的 CV、稿件、数据集、软件和资助申请。
- **DOI** (doi.org)，学术对象的持久标识符。期刊在接受时自动分配；你也可以通过 Zenodo（zenodo.org）或你的机构存储库为你的数据集、代码、海报和预印本创建 DOI，这对于引用非期刊输出很有用。
- **ROR** (ror.org)，研究组织的持久标识符，资助者和出版商用于区分机构名称。

## 研究伦理

### 伦理考虑清单

```markdown
## 开始研究前

### 人类受试者
- [ ] 获得伦理委员会/伦理委员会批准
- [ ] 建立知情同意程序
- [ ] 确定并保护弱势群体
- [ ] 隐私和保密措施到位
- [ ] 数据安全计划
- [ ] 风险/收益比可接受

### 数据管理
- [ ] 创建数据管理计划
- [ ] 安排安全存储
- [ ] 记录共享/存档计划
- [ ] 确定保留期限
- [ ] 建立销毁程序

### 作者资格
- [ ] 讨论贡献标准（使用 ICMJE 定义：实质性贡献 + 撰写/修订 + 最终批准 + 责任）
- [ ] 确定作者顺序
- [ ] 所有贡献者都将满足作者资格
- [ ] 计划对非作者贡献者的致谢
- [ ] **CRediT 分类法**（credit.niso.org）角色分配给每位作者，大多数主要期刊现在要求或建议使用 CRediT，它有 14 个标准贡献者角色（概念化、方法、软件、验证、形式分析、调查、资源、数据管理、原始草稿写作、审阅和编辑写作、可视化、监督、项目管理、资金获取）。

### 利益冲突
- 识别财务利益冲突
- 识别非财务利益冲突
- 建立披露计划

### 可重复性
- 在 **OSF** (osf.io) 或 **AsPredicted** (aspredicted.org) 在数据收集前预先注册分析，区分确认性和探索性分析，并防止 HARKing。检查目标期刊是否接受 **注册报告**（在数据收集前对设计进行同行评审，无论结果如何，原则上接受），这种格式现在存在于 2026 年 350 多家期刊中，涵盖心理学、生物医学和社会科学。

- 将代码共享（考虑使用 GitHub 发布 + Zenodo DOI 进行版本化、可引用的代码存档）
- 将数据共享（FAIR 原则；机构存储库、Dryad、Figshare 或适当领域存储库）
- 将材料共享
```

### 避免研究不当行为

```markdown
## 不当行为类型

### 编造
- 编造数据或结果
- 在任何情况下都不应接受

### 捏造
- 操纵数据、设备或流程
- 选择性地省略数据以改变结论
- 图像处理超出可接受的调整

### 抄袭
- 无归属地使用他人的文字
- 自我抄袭（未经承认地重复自己已发表的作品）
- 过于接近地释义

### 其他可疑做法
- P-hacking（运行多次分析直到发现显著结果）
- HARKing（在结果已知后提出假设）
- 切片（将一项研究拆分成多篇论文）
- 赠送/幽灵作者
- 选择性报告结果
```

## AI / LLM 在学术写作中的使用

LLM 辅助写作是 2024-2026 年学术出版中定义的道德问题。每个主要期刊、资助者和伦理机构都在这一年发布了政策，政策仍在收紧。
将以下内容视为底线，而不是上限：提交前请阅读目标期刊当前的提交指南和你的资助者的最新政策。

### 统一禁止（截至 2026 年）

- **LLM 作者资格**。ICMJE、COPE、Nature、Science、NEJM、Cell、JAMA、Lancet 以及主要大学出版社都明确禁止将 LLM（ChatGPT、Claude、Gemini 等）列为合著者。LLM 无法满足作者资格所需的责任和批准标准。使用致谢部分或方法/披露声明，切勿使用作者姓名。

- **生成编造的引文**。LLM 已被证明会产生看似合理但实际上编造的 DOI、页码，甚至编造不存在的作者/标题组合。稿件中的每个引文都必须与来源核实，LLM 诱导的假引文率自 2023 年以来一直是撤稿的主要触发因素。

- **生成数据、结果或图像**。综合实验数据、编造图表或使用生成式 AI 来“填补”未实际获得的实验结果是研究不当行为，根据 COPE 的定义。

- **未披露的实质性使用**。大多数期刊要求披露超出 trivial 校对/语法协助的任何 LLM 使用。未披露有意义的使用可能构成研究不当行为。

### 允许使用（需披露）

- 想法头脑风暴和提纲
- 语言润色和语法校正
- 将自己的写作翻译
- 生成分析代码（需明确测试）
- 总结自己的笔记或转录
- 生成样板部分（封面信、IRB 语言），然后你亲自核实并拥有

### 披露语言（模板）

大多数期刊需要一个方法/致谢声明，命名工具、版本（如果可用）以及它被用于什么。例如：

> 在准备这项工作时，作者使用了 [工具名称, 例如 GPT-5.6 Sol, Claude Opus 5, Gemini 3.7 Flash] 来 [具体用途，例如润色引言；为第 3.2 节中的聚类分析编写代码]。使用该工具后，作者根据需要进行了审查和编辑，并对其发表内容负全部责任。

根据目标期刊的确切要求调整，Elsevier、Springer Nature、Wiley、Taylor & Francis、IEEE 和 ACM 各自发布其首选语言。

### 提交前披露清单

- [ ] 阅读目标期刊当前的 AI/LLM 政策在提交指南中（每年更新多次）。
- [ ] 阅读你的资助方政策，一些（Wellcome、NSF）比期刊有更严格的规定。
- [ ] 使用期刊的首选语言添加披露声明。
- [ ] 手动核实每个引文，不要信任 LLM 输出任何 DOI、作者列表、页码或引用段落。
- [ ] 核实每个数字声明、日期和命名事实。
- [ ] 重新阅读全文，确保你的语气和论证结构占主导地位，而不是 LLM 的。
- [ ] 如果 LLM 用于代码或分析，使用种子重新运行并核实所有报告的数字是否可重复。

### 检测工具（有限可靠性）

GPTZero、Turnitin AI 检测、Originality.ai 和类似工具已记录在非母语作家和合法人类编写的技术文本的高误报率，以及当前模型在轻微编辑时的高漏报率。**Pangram Labs**（pangram.com）已发布更严格的基准，在类似设置下表现优于旧检测器，但作者编辑 LLM 输出程度较大时，仍然不是最终仲裁者。检测结果不应作为唯一依据，期刊将其作为证据仅作为与作者进一步讨论的标志，而不是作为独立的证据。
