# 回测框架

构建稳健、生产级的回测系统，避免常见陷阱，并生成可靠的策略性能估计。

## 何时使用这项技能

- 开发交易策略回测
- 构建回测基础设施
- 验证策略性能
- 避免常见回测偏差
- 实施滚动前向分析
- 比较策略备选方案

## 核心概念

### 1. 回测偏差

| 偏差             | 描述               | 缓解措施              |
| ---------------- | ------------------------- | ----------------------- |
| **提前看**   | 使用未来信息  | 点时数据      |
| **幸存者偏差** | 仅测试幸存者 | 使用已退市证券 |
| **过度拟合**  | 历史曲线拟合  | 样外测试   |
| **选择偏差**    | 挑选策略 | 预注册        |
| **交易成本偏差**  | 忽略交易成本    | 真实成本模型   |

### 2. 正确的回测结构

```
历史数据
      │
      ▼
┌─────────────────────────────────────────┐
│              训练集               │
│  (策略开发与优化)  │
└─────────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────────┐
│             验证集              │
│  (参数选择，禁止窥视)      │
└─────────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────────┐
│               测试集                  │
│  (最终性能评估)         │
└─────────────────────────────────────────┘
```

### 3. 滚动前向分析

```
窗口1：[Train──────][Test]
窗口2：     [Train──────][Test]
窗口3：         [Train──────][Test]
窗口4：             [Train──────][Test]
                                     ─────▶ 时间
```

## 最佳实践

### 应该做

- **使用点时数据** - 避免提前看偏差
- **包含交易成本** - 真实估计
- **样外测试** - 始终保留数据
- **使用滚动前向** - 不仅是训练/测试
- **蒙特卡洛分析** - 理解不确定性

### 不应该做

- **不要过度拟合** - 限制参数
- **不要忽略幸存者偏差** - 包含已退市
- **不要随意使用调整数据** - 理解调整
- **不要在完整历史上优化** - 保留测试集
- **不要忽略容量** - 市场影响很重要
