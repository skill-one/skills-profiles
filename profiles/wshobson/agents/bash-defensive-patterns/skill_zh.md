# Bash 防御性模式

使用防御性编程技术、错误处理和安全最佳实践编写生产就绪型 Bash 脚本的全面指南，以防止常见陷阱并确保可靠性。

## 何时使用此技能

- 编写生产自动化脚本
- 构建 CI/CD 管道脚本
- 创建系统管理工具
- 开发容错型部署自动化
- 编写必须安全处理边缘情况的脚本
- 构建可维护的 Shell 脚本库
- 实施全面的日志记录和监控
- 创建必须跨不同平台运行的脚本

## 最佳实践总结

1. **始终使用严格模式** - `set -Eeuo pipefail`
2. **对所有变量进行引号处理** - `"$variable"` 可防止单词拆分
3. **使用 [[]] 条件判断** - 比 `[ ]` 更健壮
4. **实现错误捕获** - 优雅地捕获和处理错误
5. **验证所有输入** - 检查文件存在性、权限、格式
6. **使用函数实现可重用性** - 前缀有意义的名称
7. **实现结构化日志记录** - 包含时间戳和级别
8. **支持干运行模式** - 允许用户预览变更
9. **安全处理临时文件** - 使用 mktemp，通过 trap 进行清理
10. **设计幂等性** - 脚本应安全地重新运行
11. **记录需求** - 列出依赖项和最低版本
12. **测试错误路径** - 确保错误处理正常工作
13. **使用 `command -v`** - 比 `which` 更安全地检查可执行文件
14. **优先使用 printf 而不是 echo** - 跨系统更可预测
