# ShellCheck 配置和静态分析

关于配置和使用 ShellCheck 以提高 shell 脚本质量、捕获常见陷阱以及通过静态代码分析强制执行最佳实践的全面指南。

## 何时使用此技能

- 在 CI/CD 管道中为 shell 脚本设置代码检查
- 分析现有 shell 脚本中的问题
- 理解 ShellCheck 错误代码和警告
- 配置 ShellCheck 以满足特定项目要求
- 将 ShellCheck 集成到开发工作流程中
- 抑制误报并配置规则集
- 强制执行一致的代码质量标准
- 将脚本迁移以满足质量门禁

## 最佳实践

1. **在 CI/CD 中运行 ShellCheck** - 在合并前捕获问题
2. **针对目标 shell 进行配置** - 不要将 bash 作为 sh 进行分析
3. **记录排除项** - 解释为什么抑制违规
4. **处理违规** - 不要只是禁用警告
5. **启用严格模式** - 使用 `--enable=all` 并谨慎排除
6. **定期更新** - 保持 ShellCheck 更新以进行新的检查
7. **使用 pre-commit 钩子** - 在推送前在本地捕获问题
8. **与编辑器集成** - 在开发过程中实时获取反馈
