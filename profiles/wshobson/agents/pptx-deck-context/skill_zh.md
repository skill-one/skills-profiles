# PPTX文件制作背景

在协调或PPTX对象创作之前，请准备好文件。这项技能拥有业务叙述、来源谱系和设计锁定权。

## 决策顺序

1. 确认受众、决策、幻灯片数量、语言、来源和品牌要求。
2. 使用用户选择的叙述框架。如果没有指定，则提供`mckinsey`、`scqa`、`pyramid`、`mece`、`action-title`、`assertion-evidence`、`exec-summary-first`或`custom`；不要无声选择。
3. 为每个指标、引用、图表值和事实声明分配稳定的来源ID，并规划`source_ref`。
4. 选择一个有文档记录的设计方向。优先使用用户品牌指南，然后是只读参考文件证据，然后是从`references/design-profiles.md`中获取的可重用配置文件。
5. 在制作幻灯片之前，在`summary`中记录框架、假设、来源清单、调色板、字体、间距和签名元素。

## 规则

- 一张幻灯片应传达一个信息，在框架要求时使用行动式标题。
- 将设计参考视为设计证据，而不是内容或资产来源。
- 不要在没有记录的许可证据的情况下复制外部字体、图像、图标或标志。
- 将设计信号转化为明确的填充、字体、间距和边界框；不要依赖自动布局引擎。
- 保持长来源材料简洁。请求摘要或与决策相关的摘录，而不是将文件规范变成文档转储。

有关可重用配置文件的指导，请参阅`references/design-profiles.md`。
