# 混合搜索实现

结合向量相似度和基于关键词的搜索的模式。

## 何时使用此技能

- 构建召回率更高的 RAG 系统
- 结合语义理解与精确匹配
- 处理包含特定术语的查询（名称、代码）
- 改进特定领域词汇的搜索
- 当纯向量搜索遗漏关键词匹配时

## 核心概念

### 1. 混合搜索架构

```
Query → ┬─► 向量搜索 ──► 候选集 ─┐
        │                                  │
        └─► 关键词搜索 ─► 候选集 ─┴─► 融合 ─► 结果
```

### 2. 融合方法

| 方法            | 描述              | 最适用于        |
| -------------- | ---------------- | -------------- |
| **RRF**         | 互惠排名融合      | 通用用途      |
| **Linear**      | 分数的加权求和    | 可调平衡      |
| **Cross-encoder** | 使用神经模型重新排序 | 最高质量      |
| **Cascade**     | 过滤后重新排序    | 效率          |

## 最佳实践

### 应该做

- **经验性地调整权重** - 在你的数据上测试
- **使用 RRF 以简化** - 无需调整即可很好地工作
- **添加重新排序** - 显著提高质量
- **记录两个分数** - 有助于调试
- **进行 A/B 测试** - 衡量真实用户影响

### 不应该做

- **不要假设一刀切** - 不同的查询需要不同的权重
- **不要跳过关键词搜索** - 更好地处理精确匹配
- **不要过度获取** - 平衡召回率与延迟
- **不要忽略边缘情况** - 空结果、单个词查询
