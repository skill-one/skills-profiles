# PPTX 视觉素材

使用视觉素材来辅助幻灯片的主题，切勿用它来扁平化或替换可编辑内容。

## 工作流程

1. 仅在它能够提升理解力时才选择素材类型：图标、图片、SVG、图表或信息图。
2. 在放置之前，确认本地素材路径、来源、使用权限和简洁的替代文本。
3. 使用最终英寸的bbox、深思熟虑的z-index，以及`content`或`layout_design`分类来添加素材。
4. 保持宽高比，并检查没有素材覆盖可读文本或将关键信息锁定在图片中。

## 规则

- 使用简单、清晰的图标配合文本标签。
- 将图片说明放在图片旁边而不是覆盖在图片上。
- 仅在它们是干净的矢量图时才使用真正的SVG来源；切勿将位图包裹在SVG中并称其为可编辑的。
- 使用原生的PowerPoint对象重新创建关键标签、图例、数值和处理步骤。
- 如果没有权利、来源或合适的素材，则省略素材并报告缺失。切勿添加占位符作为完成的视觉效果。
- 在来源清单中记录提供者或来源详情。切勿在聊天中要求机密信息。

有关许可、放置和SVG限制的信息，请参阅`references/asset-guidance.md`。
