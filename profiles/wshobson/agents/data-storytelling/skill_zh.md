# 数据叙事

将原始数据转化为引人入胜的故事，以推动决策并激发行动。

## 何时使用这项技能

- 向高管展示分析结果
- 创建季度业务回顾
- 制作投资者演示文稿
- 撰写数据驱动报告
- 向非技术受众传达见解
- 基于数据提出建议

## 核心概念

### 1. 故事结构

```
铺垫 → 冲突 → 解决

铺垫：背景和基线
冲突：问题或机会
解决：见解和建议
```

### 2. 叙事弧

```
1. 钩子：用惊人的见解吸引注意力
2. 背景：建立基线
3. 上升行动：通过数据点构建
4. 高潮：关键见解
5. 解决：建议
6. 行动号召：下一步
```

### 3. 三大支柱

| 支柱        | 目的  | 组成部分                       |
| ------------- | -------- | -------------------------------- |
| **数据**      | 证据  | 数字、趋势、比较             |
| **叙事**      | 含义  | 背景、因果关系、启示         |
| **视觉**      | 清晰度  | 图表、图表、重点             |

## 最佳实践

### 应做

- **从“所以呢”开始** - 以见解开篇
- **使用三法则** - 三个要点，三个比较
- **展示而非讲述** - 让数据说话
- **使其个性化** - 与受众目标相关联
- **以行动结尾** - 清晰的下一步

### 不应做

- **不要数据倾泻** - 严格筛选
- **不要埋没见解** - 首先突出关键发现
- **不要使用术语** - 匹配受众词汇
- **不要先展示方法** - 先背景后方法
- **不要忘记叙事** - 数字需要意义
