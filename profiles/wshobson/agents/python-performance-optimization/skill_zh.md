# Python 性能优化

全面指南，用于分析、评估和优化 Python 代码性能，包括 CPU 分析、内存优化和最佳实践。

## 使用此技能的场景

- 识别 Python 应用中的性能瓶颈
- 降低应用延迟和响应时间
- 优化 CPU 密集型操作
- 减少内存消耗和内存泄漏
- 提高数据库查询性能
- 优化 I/O 操作
- 加速数据处理管道
- 实现高性能算法
- 分析生产应用

## 核心概念

### 1. 分析类型

- **CPU 分析**：识别耗时函数
- **内存分析**：跟踪内存分配和泄漏
- **逐行分析**：按行粒度分析
- **调用图**：可视化函数调用关系

### 2. 性能指标

- **执行时间**：操作耗时
- **内存使用**：峰值和平均内存消耗
- **CPU 利用率**：处理器使用模式
- **I/O 等待**：I/O 操作耗时

### 3. 优化策略

- **算法优化**：更好的算法和数据结构
- **实现优化**：更高效的代码模式
- **并行化**：多线程/多进程
- **缓存**：避免重复计算
- **本地扩展**：C/Rust 用于关键路径

## 快速入门

### 基本计时

```python
import time

def measure_time():
    """简单计时测量。"""
    start = time.time()

    # 你的代码
    result = sum(range(1000000))

    elapsed = time.time() - start
    print(f"执行时间：{elapsed:.4f} 秒")
    return result

# 更好：使用 timeit 进行精确测量
import timeit

execution_time = timeit.timeit(
    "sum(range(1000000))",
    number=100
)
print(f"平均时间：{execution_time/100:.6f} 秒")
```

## 最佳实践

1. **优化前先分析** - 测量以找到真实瓶颈
2. **关注热点路径** - 优化最频繁执行的代码
3. **使用合适的数据结构** - 字典用于查找，集合用于成员资格
4. **避免过早优化** - 先保证清晰，再优化
5. **使用内置函数** - 它们用 C 实现
6. **缓存昂贵计算** - 使用 lru_cache
7. **批量 I/O 操作** - 减少系统调用
8. **使用生成器** 处理大数据集
9. **考虑使用 NumPy** 进行数值操作
10. **分析生产代码** - 使用 py-spy 分析实时系统

## 常见陷阱

- 未分析就优化
- 不必要地使用全局变量
- 未使用合适的数据结构
- 创建不必要的数据副本
- 未使用数据库连接池
- 忽略算法复杂度
- 过度优化罕见代码路径
- 未考虑内存使用
