# 风险指标计算

用于投资组合管理的全面风险度量工具包，包括风险价值（VaR）、预期 shortfall（ES）和回撤分析。

## 使用此技能的场景

- 度量投资组合风险
- 实施风险限额
- 构建风险仪表盘
- 计算风险调整后收益
- 设置仓位大小
- 监管报告

## 核心概念

### 1. 风险指标类别

| 类别          | 指标         | 应用场景             |
| ------------- | ------------ | -------------------- |
| **波动率**    | 标准差、Beta | 一般风险             |
| **尾部风险**  | VaR、CVaR    | 极端损失             |
| **回撤**      | 最大回撤、Calmar | 资本保全             |
| **风险调整**  | Sharpe、Sortino | 绩效                 |

### 2. 时间范围

```
日内：   交易者使用的分钟/小时级 VaR
日度：   标准风险报告
周度：   再平衡决策
月度：   绩效归因
年度：   战略配置
```

## 最佳实践

### 应做事项

- **使用多个指标** - 没有单一指标能捕捉所有风险
- **考虑尾部风险** - VaR 不足以使用 CVaR
- **滚动分析** - 风险随时间变化
- **压力测试** - 历史和假设性
- **记录假设** - 分布、回溯期等

### 不应做事项

- **不要单独依赖 VaR** - 低估尾部风险
- **不要假设正态分布** - 收益呈厚尾分布
- **不要忽略相关性** - 增加压力
- **不要使用短期回溯期** - 错过状态变化
- **不要忘记交易成本** - 影响实际风险
