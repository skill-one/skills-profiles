# 嵌入策略

指导如何为向量搜索应用选择和优化嵌入模型。

## 使用此技能的场景

- 为 RAG 选择嵌入模型
- 优化分块策略
- 针对特定领域微调嵌入
- 比较嵌入模型性能
- 降低嵌入维度
- 处理多语言内容

## 核心概念

### 2. 嵌入流程

```
文档 → 分块 → 预处理 → 嵌入模型 → 向量
                ↓
        [重叠, 大小]  [清理, 标准化]  [API/本地]
```

## 最佳实践

### 应该做

- **根据使用场景匹配模型**: 代码 vs 文本 vs 多语言
- **谨慎分块**: 保留语义边界
- **标准化嵌入**: 用于余弦相似度搜索
- **批量请求**: 比逐个请求更高效
- **缓存嵌入**: 避免对静态内容重复计算
- **使用 Voyage AI for Claude 应用**: Anthropic 推荐

### 不应该做

- **不要忽略令牌限制**: 截断会丢失信息
- **不要混合嵌入模型**: 向量空间不兼容
- **不要跳过预处理**: 垃圾进，垃圾出
- **不要过度分块**: 丢失重要上下文
- **不要忽略元数据**: 对过滤和调试至关重要
