# 响应式设计

掌握现代响应式设计技术，创建能够无缝适应所有屏幕尺寸和设备上下文的用户界面。

## 何时使用这项技能

- 实现移动优先的响应式布局
- 使用容器查询实现组件级别的响应式
- 创建流体排版和间距比例
- 使用 CSS Grid 和 Flexbox 构建复杂布局
- 为设计系统设计断点策略
- 实现响应式图像和媒体
- 创建自适应导航模式
- 构建响应式表格和数据展示

## 最佳实践

1. **移动优先**：从移动端样式开始，为更大屏幕进行增强
2. **内容断点**：基于内容而非设备设置断点
3. **流体优先**：为排版和间距使用流体值
4. **容器查询**：用于组件级别的响应式
5. **测试真实设备**：模拟器无法捕获所有问题
6. **性能优化**：优化图像，对屏幕外内容进行懒加载
7. **触摸目标**：在移动端保持 44x44px 的最小尺寸
8. **逻辑属性**：使用内联/块级属性支持国际化

## 常见问题

- **水平溢出**：内容超出视口范围
- **固定宽度**：使用 px 而非相对单位
- **视口高度**：移动浏览器上的 100vh 问题
- **字体大小**：移动端文字太小
- **触摸目标**：按钮太小无法准确点击
- **宽高比**：图像被挤压或拉伸
- **z-index 堆叠**：不同屏幕上的覆盖层失效
