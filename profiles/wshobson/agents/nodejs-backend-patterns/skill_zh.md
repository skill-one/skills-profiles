# Node.js Backender Patterns

关于使用现代框架、架构模式与最佳实践，构建可扩展、可维护且适合生产环境的 Node.js 后端应用程序的全面指导。

## 何时使用此技能

- 构建 REST API 或 GraphQL 服务器
- 使用 Node.js 创建微服务
- 实现认证与授权
- 设计可扩展的后端架构
- 配置中间件和错误处理
- 集成数据库（SQL 与 NoSQL）
- 使用 WebSockets 构建实时应用程序
- 实现后台任务处理

## 最佳实践

1. **使用 TypeScript**：类型安全可防止运行时错误
2. **实现正确的错误处理**：使用自定义错误类
3. **验证输入**：使用 Zod 或 Joi 等库
4. **使用环境变量**：切勿硬编码密钥
5. **实现日志记录**：使用结构化日志（Pino、Winston）
6. **添加速率限制**：防止滥用
7. **使用 HTTPS**：在生产环境中始终使用
8. **正确实现 CORS**：生产环境中不要使用 `*`
9. **使用依赖注入**：便于测试与维护
10. **编写测试**：单元测试、集成测试与端到端（E2E）测试
11. **处理优雅关闭**：清理资源
12. **使用连接池**：用于数据库
13. **实现健康检查**：用于监控
14. **使用压缩**：减小响应大小
15. **监控性能**：使用 APM 工具
