# 威胁缓解映射

将威胁与控制措施关联起来，以进行有效的安全规划。

## 使用此技能的场景

- 优先考虑安全投资
- 创建修复路线图
- 验证控制覆盖范围
- 设计纵深防御
- 安全架构审查
- 风险处理规划

## 核心概念

### 1. 控制类别

```
预防性 ────► 在攻击发生前阻止攻击
   │              (防火墙、输入验证)
   │
检测性 ─────► 识别正在进行的攻击
   │              (IDS、日志监控)
   │
纠正性 ────► 响应并从攻击中恢复
                  (事件响应、备份恢复)
```

### 2. 控制层次

| 层级           | 示例                             |
| --------------- | ------------------------------------ |
| **网络**     | 防火墙、WAF、DDoS防护       |
| **应用**     | 输入验证、身份验证     |
| **数据**        | 加密、访问控制          |
| **端点**    | EDR、补丁管理                |
| **流程**     | 安全培训、事件响应 |

### 3. 纵深防御

```
                    ┌──────────────────────┐
                    │      边界       │ ← 防火墙、WAF
                    │   ┌──────────────┐   │
                    │   │   网络    │   │ ← 逻辑隔离、IDS
                    │   │  ┌────────┐  │   │
                    │   │  │  主机  │  │   │ ← EDR、加固
                    │   │  │ ┌────┐ │  │   │
                    │   │  │ │应用│ │  │   │ ← 身份验证、验证
                    │   │  │ │数据│ │  │   │ ← 加密
                    │   │  │ └────┘ │  │   │
                    │   │  └────────┘  │   │
                    │   └──────────────┘   │
                    └──────────────────────┘
```

## 最佳实践

### 应做

- **映射所有威胁** - 没有威胁应该未被映射
- **分层控制** - 纵深防御至关重要
- **混合控制类型** - 预防性、检测性、纠正性
- **跟踪有效性** - 衡量并改进
- **定期审查** - 控制会随时间退化

### 不应做

- **不要依赖单一控制** - 单点故障
- **不要忽视成本** - 投资回报率很重要
- **不要跳过测试** - 未测试的控制可能会失效
- **不要设置后遗忘** - 持续改进
- **不要忽视人员/流程** - 技术本身是不够的
