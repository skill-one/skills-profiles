# mTLS 配置

实现零信任服务网格通信中相互 TLS 的全面指南。

## 何时使用此技能

- 实现零信任网络
- 保障服务间通信安全
- 证书轮换与管理
- 调试 TLS 握手问题
- 合规性要求（PCI-DSS、HIPAA）
- 多集群安全通信

## 核心概念

### 1. mTLS 流程

```
┌─────────┐                              ┌─────────┐
│ 服务 A  │                              │ 服务 B  │
│         │                              │         │
└────┬────┘                              └────┬────┘
     │                                        │
┌────┴────┐      TLS 握手          ┌────┴────┐
│  代理  │◄───────────────────────────►│  代理  │
│(边车) │  1. ClientHello             │(边车) │
│         │  2. ServerHello + 证书    │         │
│         │  3. Client 证书           │         │
│         │  4. 验证双方证书          │         │
│         │  5. 加密通道              │         │
└─────────┘                              └─────────┘
```

### 2. 证书层级

```
根 CA (自签名，长期有效)
    │
    ├── 中间 CA (集群级)
    │       │
    │       ├── 工作负载证书 (服务 A)
    │       └── 工作负载证书 (服务 B)
    │
    └── 中间 CA (多集群)
            │
            └── 跨集群证书
```

## 最佳实践

### 应做事项

- **从 PERMISSIVE 开始** - 逐步迁移至 STRICT
- **监控证书过期** - 设置警报
- **使用短期证书** - 工作负载使用 24 小时或更短
- **定期轮换 CA** - 规划 CA 轮换
- **记录 TLS 错误** - 用于调试和审计

### 不应做事项

- **不要禁用 mTLS** - 为生产环境中的便利性
- **不要忽视证书过期** - 自动化轮换
- **不要使用自签名证书** - 使用正确的 CA 层级
- **不要跳过验证** - 验证完整证书链
