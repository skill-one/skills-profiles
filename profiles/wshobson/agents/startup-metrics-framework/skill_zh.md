# 创业公司指标框架

全面指南，用于追踪、计算和优化不同创业公司商业模式从种子阶段到A轮融资的关键绩效指标。

## 概述

在正确阶段追踪正确的指标。关注对融资和运营卓越至关重要的单位经济、增长效率和现金流管理指标。

## 通用创业公司指标

### 收入指标

**月度经常性收入 (MRR)**

```
MRR = Σ (活跃订阅量 × 月度价格)
```

**年度经常性收入 (ARR)**

```
ARR = MRR × 12
```

**增长率**

```
月环比增长率 = (本月MRR - 上月MRR) / 上月MRR
年环比增长率 = (本年ARR - 去年ARR) / 去年ARR
```

**目标基准：**

- 种子阶段：15-20% 月环比增长率
- A轮融资：10-15% 月环比增长率，3-5倍年增长率
- B轮及以上：100%+ 年增长率（40法则）

### 单位经济

**客户获取成本 (CAC)**

```
CAC = 总销售与市场支出 / 新获取的客户数
```

包含：销售薪酬、市场支出、工具、管理费用

**客户终身价值 (LTV)**

```
LTV = ARPU × 毛利率% × (1 / 资产流失率)
```

简化公式：

```
LTV = ARPU × 平均客户生命周期 × 毛利率%
```

**LTV:CAC比率**

```
LTV:CAC = LTV / CAC
```

**基准：**

- LTV:CAC > 3.0 = 健康
- LTV:CAC 1.0-3.0 = 需要改进
- LTV:CAC < 1.0 = 不可持续

**CAC回收期**

```
CAC回收期 = CAC / (ARPU × 毛利率%)
```

**基准：**

- < 12个月 = 优秀
- 12-18个月 = 良好
- > 24个月 = 令人担忧

### 现金效率指标

**烧钱率**

```
月度烧钱 = 月度收入 - 月度支出
```

负烧钱率 = 亏损（典型早期阶段）

**资金储备期**

```
资金储备期（月）= 现金余额 / 月度烧钱率
```

**目标：** 始终保持12-18个月的资金储备期

**烧钱倍数**

```
烧钱倍数 = 净烧钱 / 净新增ARR
```

**基准：**

- < 1.0 = 卓越的效率
- 1.0-1.5 = 良好
- 1.5-2.0 = 可接受
- > 2.0 = 效率低下

越低越好（以更少的支出产生ARR）

## SaaS指标

### 收入构成

**新增MRR**
新增客户 × ARPU

**扩展MRR**
现有客户追加销售和交叉销售

**缩减MRR**
现有客户降级

**流失MRR**
流失客户

**净新增MRR公式：**

```
净新增MRR = 新增MRR + 扩展MRR - 缩减MRR - 流失MRR
```

### 留存指标

**Logo留存率**

```
Logo留存率 = (期末客户数 - 新增客户数) / 期初客户数
```

**美元留存率 (NDR - 净美元留存率)**

```
NDR = (期初ARR + 扩展 - 缩减 - 流失) / 期初ARR
```

**基准：**

- NDR > 120% = 行业领先
- NDR 100-120% = 良好
- NDR < 100% = 需要改进

**毛留存率**

```
毛留存率 = (期初ARR - 流失 - 缩减) / 期初ARR
```

**基准：**

- > 90% = 优秀
- 85-90% = 良好
- < 85% = 令人担忧

### SaaS特定指标

**魔力数字**

```
魔力数字 = 本季度净新增ARR / 上一季度销售与市场支出
```

**基准：**

- > 0.75 = 高效，准备规模化
- 0.5-0.75 = 中等效率
- < 0.5 = 效率低下，暂不规模

**40法则**

```
40法则 = 收入增长率% + 利润率%
```

**基准：**

- > 40% = 优秀
- 20-40% = 可接受
- < 20% = 需要改进

**示例：**
50%增长 + (10%)利润率 = 40% ✓

**速动比率**

```
速动比率 = (新增MRR + 扩展MRR) / (流失MRR + 缩减MRR)
```

**基准：**

- > 4.0 = 健康增长
- 2.0-4.0 = 中等
- < 2.0 = 流失问题

## 交易平台指标

### 总交易额 (GMV)

**总交易量：**

```
GMV = Σ (交易额)
```

**增长率：**

```
GMV增长率 = (当期GMV - 前期GMV) / 前期GMV
```

**目标：** 早期阶段月环比增长率20%+

### 抽成率

```
抽成率 = 净收入 / GMV
```

**典型范围：**

- 支付处理器：2-3%
- 电子商务交易平台：10-20%
- 服务交易平台：15-25%
- 高价值B2B：5-15%

### 交易平台流动性

**交易达成时间**
从发布到成交/匹配需要多长时间？

**成交率**
%的请求导致成交

**复购率**
%的用户多次交易

**基准：**

- 成交率 > 80% = 强流动性
- 复购率 > 60% = 强留存

### 交易平台平衡

**供需比率：**
追踪供给和需求两边的相对增长。

**警示信号：**

- 供给过多：低成交率，供应商不满
- 需求过多：等待时间长，客户不满

**目标：** 平衡增长（理想1:1比率，但随模式变化）

## 消费者/移动指标

### 用户参与指标

**日活跃用户 (DAU)**
每天活跃的唯一用户数

**月活跃用户 (MAU)**
每月活跃的唯一用户数

**DAU/MAU比率**

```
DAU/MAU = DAU / MAU
```

**基准：**

- > 50% = 卓越（每日习惯）
- 20-50% = 良好
- < 20% = 用户参与度弱

**会话频率**
每个用户每天/每周的平均会话数

**会话时长**
每个会话的平均时长

### 留存曲线

**第1天留存率：** 返回下一天的用户%
**第7天留存率：** 注册7天后活跃的用户%
**第30天留存率：** 注册30天后活跃的用户%

**基准（第30天）：**

- > 40% = 优秀
- 25-40% = 良好
- < 25% = 弱

**留存曲线形状：**

- 平缓曲线 = 良好（用户形成习惯）
- 陡峭下降 = 产品市场匹配度差

### 病毒系数 (K因子)

```
K因子 = 每用户邀请数 × 邀请转化率
```

**示例：**
10次邀请/用户 × 20%转化 = 2.0 K因子

**基准：**

- K > 1.0 = 病毒式增长
- K = 0.5-1.0 = 强推荐
- K < 0.5 = 弱病毒性

## B2B指标

### 销售效率

**成交率**

```
成交率 = 成交交易数 / 总机会数
```

**目标：** 新销售团队20-30%，成熟团队30-40%

**销售周期长度**
从机会到成交的平均天数

**越短越好：**

- SMB：30-60天
- 中端市场：60-120天
- 大型企业：120-270天

**平均合同价值 (ACV)**

```
ACV = 总合同价值 / 合同期限（年）
```

### 销售管道指标

**管道覆盖率**

```
管道覆盖率 = 总管道价值 / 配额
```

**目标：** 3-5倍覆盖率（需要3-5倍管道达成配额）

**各阶段转化率：**

- 潜在客户 → 机会：10-20%
- 机会 → 产品演示：50-70%
- 产品演示 → 报价：30-50%
- 报价 → 成交：20-40%

## 各阶段指标

### 早期种子阶段（产品市场匹配）

**关注指标：**

1. 活跃用户增长
2. 用户留存（第7天，第30天）
3. 核心参与度（会话数，使用功能）
4. 定性反馈（NPS，访谈）

**无需关注：**

- 收入（可能为零）
- CAC（尚未优化）
- 单位经济

### 种子阶段 ($500K-$2M ARR)

**关注指标：**

1. MRR增长率（15-20% 月环比）
2. CAC和LTV（建立基准）
3. 毛留存率 (> 85%)
4. 核心产品参与度

**开始追踪：**

- 销售效率
- 烧钱率和资金储备期

### A轮融资阶段 ($2M-$10M ARR)

**关注指标：**

1. ARR增长率（3-5倍年增长率）
2. 单位经济（LTV:CAC > 3，回收期<18个月）
3. 净美元留存率 (> 100%)
4. 烧钱倍数 (< 2.0)
5. 魔力数字 (> 0.5)

**成熟追踪：**

- 40法则
- 销售效率
- 管道覆盖率

## 指标追踪最佳实践

### 数据基础设施

**要求：**

- 单一数据源（分析平台）
- 实时或每日更新
- 自动计算
- 历史追踪

**工具：**

- Mixpanel, Amplitude（产品分析）
- ChartMogul, Baremetrics（SaaS指标）
- Looker, Tableau（BI仪表盘）

### 报告频率

**每日：**

- MRR，活跃用户
- 注册数，转化率

**每周：**

- 增长率
- 留存队列
- 销售管道

**每月：**

- 完整指标集
- 仪表盘报告
- 投资者更新

**每季度：**

- 趋势分析
- 基准对比
- 策略评审

### 常见错误

**错误1：虚荣指标**
不要关注：

- 总用户数（无留存）
- 页面浏览量（无参与度）
- 下载量（无激活）

关注与价值相关的可行动指标。

**错误2：指标过多**
追踪5-7个核心指标，而非50个松散指标。

**错误3：忽视单位经济**
即使种子阶段，CAC和LTV也至关重要。

**错误4：未细分**
按客户细分、渠道、队列分解指标。

**错误5：指标游戏**
优化真实业务成果，而非仪表盘数字。

## 投资者指标

### 投资人关注点

**种子轮：**

- MRR增长率
- 用户留存
- 早期单位经济
- 产品参与度

**A轮融资：**

- ARR和增长率
- CAC回收期<18个月
- LTV:CAC > 3.0
- 净美元留存率 > 100%
- 烧钱倍数 < 2.0

**B轮及以上：**

- 40法则 > 40%
- 高效增长（魔力数字）
- 盈利路径
- 市场领导指标

### 指标呈现

**仪表盘格式：**

```
当前MRR: $250K (↑ 18% 月环比)
ARR: $3.0M (↑ 280% 年环比)
CAC: $1,200 | LTV: $4,800 | LTV:CAC = 4.0x
NDR: 112% | Logo留存率: 92%
烧钱: $180K/月 | 资金储备期: 18个月
```

**包含：**

- 当前值
- 增长率或趋势
- 背景（目标，基准）

## 快速入门

实施创业公司指标框架：

1. **确定商业模式** - SaaS，交易平台，消费者，B2B
2. **选择5-7个核心指标** - 基于阶段和模式
3. **建立追踪** - 设置分析和仪表盘
4. **计算单位经济** - CAC，LTV，回收期
5. **设定目标** - 使用基准作为目标
6. **定期评审** - 核心指标每周
7. **团队共享** - 对齐目标和进展
8. **向投资者更新** - 每月/每季度报告
