# 服务网格可观测性

Istio、Linkerd 和服务网格部署的可观测性模式完整指南。

## 使用此技能的场景

- 跨服务设置分布式追踪
- 实施服务网格指标和仪表板
- 调试延迟和错误问题
- 为服务通信定义 SLO
- 可视化服务依赖关系
- 排查网格连接问题

## 核心概念

### 1. 可观测性的三大支柱

```
┌─────────────────────────────────────────────────────┐
│                  可观测性                       │
├─────────────────┬─────────────────┬─────────────────┤
│     指标       │     追踪       │      日志       │
│                 │                 │                 │
│ • 请求速率     │ • 跨段上下文  │ • 访问日志   │
│ • 错误率      │ • 延迟       │ • 错误详情   │
│ • 延迟 P50     │ • 依赖关系  │ • 调试信息    │
│ • 资源饱和度   │ • 瓶颈       │ • 审计轨迹   │
└─────────────────┴─────────────────┴─────────────────┘
```

### 2. 网格的黄金信号

| 信号         | 描述               | 报警阈值   |
| ------------ | ------------------------- | ----------------- |
| **延迟**    | 请求持续时间 P50, P99 | P99 > 500ms       |
| **流量**    | 每秒请求数       | 异常检测   |
| **错误**     | 5xx 错误率            | > 1%              |
| **饱和度** | 资源利用率      | > 80%             |

## 最佳实践

### 应做事项

- **适当采样** - 开发环境 100%，生产环境 1-10%
- **使用追踪上下文** - 保持头部信息一致传递
- **设置报警** - 针对黄金信号
- **关联指标/追踪** - 使用示例数据
- **策略性保留** - 热存储/冷存储分层

### 不应做事项

- **不要过度采样** - 存储成本会累积
- **不要忽略基数** - 限制标签值
- **不要跳过仪表板** - 可视化依赖关系
- **不要忘记成本** - 监控可观测性成本
