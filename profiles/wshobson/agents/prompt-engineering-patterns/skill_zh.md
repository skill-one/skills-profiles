# 提示工程模式

掌握高级提示工程技术，以最大化大型语言模型的性能、可靠性和可控性。

## 何时使用这项技能

- 设计用于生产环境大型语言模型的复杂提示
- 优化提示性能和一致性
- 实现结构化推理模式（思维链、思维树）
- 构建具有动态示例选择的少样本学习系统
- 创建具有变量插值的可重用提示模板
- 调试和优化产生不一致输出的提示
- 实现用于专业AI助手的系统提示
- 使用结构化输出（JSON模式）进行可靠解析

## 核心功能

### 1. 少样本学习

- 示例选择策略（语义相似度、多样性采样）
- 在上下文窗口限制下平衡示例数量
- 构建有效的输入输出对演示
- 从知识库中动态检索示例
- 通过策略性示例选择处理边缘情况

### 2. 思维链提示

- 步骤推理引导
- 零样本CoT（“让我们逐步思考”）
- 少样本CoT（带推理轨迹）
- 自洽性技术（采样多个推理路径）
- 验证和校验步骤

### 3. 结构化输出

- JSON模式进行可靠解析
- Pydantic模式强制执行
- 类型安全的响应处理
- 错误处理不规范的输出

### 4. 提示优化

- 迭代改进工作流
- A/B测试提示变体
- 衡量提示性能指标（准确率、一致性、延迟）
- 在保持质量的同时减少令牌使用
- 处理边缘情况和故障模式

### 5. 模板系统

- 变量插值和格式化
- 条件提示部分
- 多轮对话模板
- 基于角色的提示组合
- 模块化提示组件

### 6. 系统提示设计

- 设置模型行为和约束
- 定义输出格式和结构
- 建立角色和专业知识
- 安全指南和内容政策
- 设置上下文和背景信息

## 快速入门

```python
from langchain_anthropic import ChatAnthropic
from langchain_core.prompts import ChatPromptTemplate
from pydantic import BaseModel, Field

# 定义结构化输出模式
class SQLQuery(BaseModel):
    query: str = Field(description="SQL查询")
    explanation: str = Field(description="查询的简要说明")
    tables_used: list[str] = Field(description="引用的表列表")

# 使用结构化输出初始化模型
llm = ChatAnthropic(model="claude-sonnet-5")
structured_llm = llm.with_structured_output(SQLQuery)

# 创建提示模板
prompt = ChatPromptTemplate.from_messages([
    ("system", """你是一位专业的SQL开发者。生成高效、安全的SQL查询。
    始终使用参数化查询以防止SQL注入。
    简要说明你的推理。"""),
    ("user", "将这个转换为SQL：{query}")
])

# 创建链
chain = prompt | structured_llm

# 使用
result = await chain.ainvoke({
    "query": "查找过去30天内注册的所有用户"
})
print(result.query)
print(result.explanation)
```

## 最佳实践

1. **明确具体**：模糊的提示会产生不一致的结果
2. **展示而非说明**：示例比描述更有效
3. **使用结构化输出**：使用Pydantic强制执行模式以获得可靠性
4. **广泛测试**：在多样化、有代表性的输入上评估
5. **快速迭代**：小的改变可能产生大的影响
6. **监控性能**：在生产中跟踪指标
7. **版本控制**：将提示视为代码，并进行适当的版本控制
8. **记录意图**：解释为什么提示会以这种方式结构化

## 常见陷阱

- **过度设计**：在尝试简单提示之前开始使用复杂的提示
- **示例污染**：使用与目标任务不匹配的示例
- **上下文溢出**：使用过多示例超出令牌限制
- **模糊指令**：留出多种解释的空间
- **忽略边缘情况**：不在不寻常或边界输入上测试
- **无错误处理**：假设输出始终格式良好
- **硬编码值**：不参数化提示以供重用

## 成功指标

跟踪以下KPI以评估您的提示：

- **准确率**：输出的正确性
- **一致性**：相似输入的可重复性
- **延迟**：响应时间（P50、P95、P99）
- **令牌使用**：每个请求的平均令牌数
- **成功率**：有效、可解析输出的百分比
- **用户满意度**：评分和反馈
