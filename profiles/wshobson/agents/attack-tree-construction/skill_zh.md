# 攻击树构建

系统化攻击路径的可视化与分析。

## 使用此技能的场景

- 可视化复杂的攻击场景
- 识别防御缺口与优先级
- 向利益相关者传达风险
- 规划防御性投资
- 渗透测试规划
- 安全架构评审

## 核心概念

### 1. 攻击树结构

```
                    [根目标]
                         |
            ┌────────────┴────────────┐
            │                         │
       [子目标 1]              [子目标 2]
       (OR 节点)                 (AND 节点)
            │                         │
      ┌─────┴─────┐             ┌─────┴─────┐
      │           │             │           │
   [攻击]   [攻击]      [攻击]   [攻击]
    (叶节点)     (叶节点)        (叶节点)     (叶节点)
```

### 2. 节点类型

| 类型     | 符号    | 描述             |
| -------- | --------- | ----------------------- |
| **OR**   | 椭圆      | 任意子目标达成即可 |
| **AND**  | 矩形      | 所有子目标均需达成 |
| **Leaf** | 方框      | 原子级攻击步骤      |

### 3. 攻击属性

| 属性     | 描述             | 取值             |
| ------------- | ----------------------- | ------------------ |
| **成本**      | 所需资源        | $, $$, $$$         |
| **时间**      | 执行持续时间     | 小时, 天, 周     |
| **技能**     | 所需专业知识      | 低, 中, 高  |
| **检测** | 检测可能性      | 低, 中, 高  |

## 最佳实践

### 应做事项

- **从明确的目标开始** - 定义攻击者意图
- **力求详尽** - 考虑所有攻击向量
- **标注攻击属性** - 成本、技能与检测
- **定期更新** - 新威胁不断涌现
- **专家验证** - 红队评审

### 不应做事项

- **不要过度简化** - 真实攻击很复杂
- **不要忽略依赖关系** - AND 节点很重要
- **不要忘记内部威胁** - 并非所有攻击者都是外部人员
- **不要跳过缓解措施** - 树用于防御规划
- **不要使其静态** - 威胁环境不断演变
