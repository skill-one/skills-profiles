# 相似度搜索模式

用于在生产系统中实现高效相似度搜索的模式。

## 何时使用此技能

- 构建语义搜索系统
- 实现RAG检索
- 创建推荐引擎
- 优化搜索延迟
- 扩展到数百万个向量
- 结合语义搜索和关键词搜索

## 核心概念

### 1. 距离度量

| 度量             | 公式            | 最适用于              |
| ------------------ | ------------------ | --------------------- | --- | -------------- |
| **余弦**         | 1 - (A·B)/(‖A‖‖B‖) | 归一化嵌入            |
| **欧几里得（L2）** | √Σ(a-b)²           | 原始嵌入              |
| **点积**         | A·B                | 大小重要              |
| **曼哈顿（L1）** | Σ                  | a-b                   |     | 稀疏向量      |

### 2. 索引类型

```
┌─────────────────────────────────────────────────┐
│                 索引类型                      │
├─────────────┬───────────────┬───────────────────┤
│    扁平     │     HNSW      │    IVF+PQ         │
│ (精确)     │ (基于图)     │ (量化)           │
├─────────────┼───────────────┼───────────────────┤
│ O(n)搜索   │ O(log n)      │ O(√n)             │
│ 100%召回   │ ~95-99%       │ ~90-95%           │
│ 小数据     │ 中等-大      │ 非常大            │
└─────────────┴───────────────┴───────────────────┘
```

## 最佳实践

### 该做

- **使用合适的索引** - 大多数情况下使用HNSW
- **调整参数** - ef_search, nprobe用于召回/速度
- **实现混合搜索** - 与关键词搜索结合
- **监控召回率** - 衡量搜索质量
- **尽可能预过滤** - 减少搜索空间

### 不该做

- **不要跳过评估** - 优化前进行测量
- **不要过度索引** - 从扁平索引开始，逐步扩展
- **不要忽略延迟** - P99对用户体验很重要
- **不要忘记成本** - 向量存储会累积费用
