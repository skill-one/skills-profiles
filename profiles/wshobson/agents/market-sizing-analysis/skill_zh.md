# 市场规模分析

用于初创企业机会计算总可寻址市场（TAM）、可服务市场（SAM）和可服务获取市场（SOM）的全面市场规模分析方法。

## 概述

市场规模分析为初创企业战略、融资和商业规划提供基础。使用三种互补的方法计算市场机会：自上而下（行业报告）、自下而上（客户细分计算）和价值理论（支付意愿）。

## 核心概念

### 三层市场框架

**TAM（总可寻址市场）**

- 若实现100%市场份额时的总收入机会
- 定义潜在客户的范围
- 用于长期愿景和市场验证
- 示例：全球所有电子邮件营销软件收入

**SAM（可服务市场）**

- 可用当前产品/服务触及的TAM部分
- 考虑地理、细分或能力限制
- 代表现实的可寻址机会
- 示例：北美电商的AI驱动电子邮件营销

**SOM（可服务获取市场）**

- 3-5年内可实现的现实市场份额
- 考虑竞争、资源和市场动态
- 用于财务预测和融资
- 示例：基于竞争格局的SAM的2-5%

### 何时使用每种方法

**自上而下分析**

- 当存在成熟的市场研究时使用
- 适用于成熟、定义明确的市场
- 验证市场存在和增长潜力
- 从行业报告开始并逐步细化

**自下而上分析**

- 当针对特定客户细分时使用
- 适用于新市场或利基市场
- 对投资者最具说服力
- 从客户数据和定价构建

**价值理论**

- 当创建新的市场类别时使用
- 适用于颠覆性创新
- 基于价值创造进行估算
- 计算问题解决方案的支付意愿
