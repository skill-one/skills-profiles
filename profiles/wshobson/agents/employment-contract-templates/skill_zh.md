# 雇佣合同模板

用于创建具有法律效力的雇佣文件的模板和范例，包括合同、录用通知书和人力资源政策。

## 使用此技能的时机

- 起草雇佣合同
- 创建录用通知书
- 编写员工手册
- 制定人力资源政策
- 标准化雇佣文件
- 入职文件

## 核心概念

### 1. 雇佣文件类型

| 文件                | 目的                 | 使用时机     |
| ----------------------- | ----------------------- | ------------- |
| **录用通知书**        | 初始工作录用       | 录用前      |
| **雇佣合同**        | 正式协议        | 录用后      |
| **员工手册**        | 政策与程序       | 入职时      |
| **保密协议（NDA）** | 保密性         | 接触前      |
| **竞业限制协议**         | 竞争限制         | 录用/离职时 |

### 2. 关键法律注意事项

```
雇佣关系:
├── 试工制 vs. 合同制
├── 员工 vs. 自由职业者
├── 全职 vs. 兼职
├── 绩效工资 vs. 非绩效工资
└── 地区特定要求
```

**免责声明：这些模板仅供参考，不构成法律建议。在使用任何雇佣文件前，请咨询合格的法律顾问。**

## 最佳实践

### 应做事项

- **咨询法律顾问** - 雇佣法律因地区而异
- **保留签署副本** - 记录所有协议
- **定期更新** - 法律和政策会变化
- **清晰具体** - 避免模糊不清
- **培训管理人员** - 关于政策和程序

### 不应做事项

- **不要使用通用模板** - 根据您的地区进行定制
- **不要做出承诺** - 那可能产生默示合同
- **不要歧视** - 在语言或应用上
- **不要遗漏试工制条款** - 如适用
- **不要跳过审核** - 所有文件都应由法律顾问审核
