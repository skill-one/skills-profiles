# 产品摄影

通过 [inference.sh](https://inference.sh) CLI 使用 AI 创建专业的产品图像。

## 快速入门

> 需要 inference.sh CLI (`belt`)。[安装说明](https://raw.githubusercontent.com/inference-sh/skills/refs/heads/main/cli-install.md)

```bash
belt login

# 清洁工作室产品拍摄
belt app run bytedance/seedream-4-5 --input '{
  "prompt": "专业产品摄影，单个高端无线耳机在干净的白色背景下，柔和的工作室灯光和微妙的阴影，商业电商风格，清晰对焦，4K 质量",
  "size": "2K"
}'
```

## 拍摄类型

### 1. 主角拍摄（主要图像）

客户首先看到的图像。干净、专注、有抱负。

```bash
belt app run bytedance/seedream-4-5 --input '{
  "prompt": "主角产品拍摄，高端智能手表以微角度漂浮，干净的渐变背景从白色过渡到浅灰色，戏剧性的轮廓光，下方有微妙反射，商业摄影，杂志质量，清晰的细节",
  "size": "2K"
}'
```

| 规则 | 原因 |
|------|-----|
| 产品占据画面的 80% | 最大化视觉冲击力 |
| 微角度（15-30 度） | 与正面平视相比增加维度 |
| 一个主角光 + 填充光 | 创建深度而不产生刺眼的阴影 |
| 中性或品牌色背景 | 保持对产品的关注 |

### 2. 产品拍摄（电商白色背景）

亚马逊、Shopify 和大多数市场需要纯白色背景。

```bash
# 纯白色背景产品拍摄
belt app run bytedance/seedream-4-5 --input '{
  "prompt": "产品拍摄，皮质钱包直立放置在纯白色背景 #FFFFFF 上，柔和均匀的工作室灯光，无阴影，电商产品摄影，亚马逊列表风格，干净清晰对焦",
  "size": "2K"
}'
```

**亚马逊要求：**
- 纯白色背景（RGB 255, 255, 255）
- 产品占据 85%+ 的画面
- 无道具、文字、标志或水印
- 最长边最小 1000px（推荐 1600px+ 用于缩放）
- JPEG 或 PNG，sRGB 色彩

### 3. 生活方式拍摄

产品在场景中——展示其使用方式或所属环境。

```bash
belt app run bytedance/seedream-4-5 --input '{
  "prompt": "生活方式产品摄影，高端咖啡杯放在乡村木桌上，旁边有一本打开的书和阅读眼镜，清晨阳光透过窗户，温馨的家庭氛围，浅景深，暖色调，编辑风格",
  "size": "2K"
}'
```

### 4. 比例拍摄

展示产品相对于熟悉物体或人手的尺寸。

```bash
belt app run falai/flux-dev-lora --input '{
  "prompt": "产品比例摄影，紧凑便携式音箱一手拿着，人展示其小巧便携，干净模糊的背景，自然光线，生活方式科技摄影",
  "width": 1024,
  "height": 1024
}'
```

### 5. 细节/特写拍摄

突出纹理、材质质量或特定功能。

```bash
belt app run bytedance/seedream-4-5 --input '{
  "prompt": "极端特写产品细节，高端皮革包的缝线和纹理，微距摄影，浅景深，柔和的方向性光线突出纹理，奢华产品摄影，编辑质量",
  "size": "2K"
}'
```

### 6. 组合/系列拍摄

多个产品或变体放在一起。

```bash
belt app run bytedance/seedream-4-5 --input '{
  "prompt": "产品系列平面摄影，三个护肤品瓶以三角形构图排列在大理石表面上，最小化道具，柔和的顶部照明，美容产品摄影，编辑风格，协调的品牌美学",
  "size": "2K"
}'
```

## 摄影角度

| 角度 | 适合 | 提示关键词 |
|-------|------|---------------|
| **视线水平** | 大多数产品，有亲和力 | "视线水平拍摄", "正面" |
| **略微上方（30°）** | 平面布局，食品，化妆品 | "俯视角度", "45 度角" |
| **鸟瞰（90°）** | 平面布局构图 | "平面布局", "顶部向下", "俯视" |
| **低角度** | 使产品看起来强大/高端 | "低角度", "仰视产品" |
| **3/4 角** | 最通用，显示深度 | "3/4 视角", "微角度" |

## 灯光设置

| 设置 | 效果 | 提示关键词 |
|-------|------|----------------|
| **柔光箱（柔光）** | 均匀，最小阴影 | "柔和工作室灯光", "柔光" |
| **轮廓光/边缘光** | 戏剧性的轮廓光晕 | "轮廓光", "边缘光", "背光" |
| **自然窗户** | 温暖，真实，生活方式 | "自然窗户光", "黄金时刻" |
| **硬方向性** | 强阴影，编辑风格 | "戏剧性方向性灯光", "硬阴影" |
| **平面/均匀** | 电商，无阴影 | "均匀灯光", "无阴影", "平面光" |

## 阴影类型

| 阴影 | 效果 | 使用场景 |
|--------|--------|-------------|
| **无阴影** | 干净，漂浮 | 亚马逊/电商要求 |
| **接触阴影** | 微小阴影，产品接触表面 | 立足但干净 |
| **投影阴影** | 产品下方柔和阴影 | 增加深度，专业 |
| **戏剧性阴影** | 长，方向性阴影 | 编辑，奢华，氛围 |
| **反射** | 镜像表面下方 | 科技，奢华，高端感 |

## 背景指南

| 背景 | 适合 | 提示关键词 |
|------------|----------|----------------|
| 纯白色 (#FFFFFF) | 电商，市场 | "纯白色背景" |
| 浅灰色渐变 | 主角拍摄，高端 | "渐变背景从白色到灰色" |
| 大理石/石头 | 奢华，美容，珠宝 | "大理石表面" |
| 木/乡村 | 手工艺，食品，天然产品 | "乡村木桌" |
| 颜色（品牌） | 品牌一致性 | "背景颜色 [十六进制]" |
| 生活方式环境 | 场景拍摄 | "厨房柜台", "桌子", "浴室架子" |

## 构图规则

| 规则 | 应用 |
|------|------------|
| **三分法** | 将产品放在生活方式拍摄的交叉点上 |
| **居中主导** | 电商/产品拍摄——产品居中 |
| **负空间** | 如果用于营销，留出文字叠加的空间 |
| **引导线** | 使用桌子边缘，阴影引导眼睛到产品 |
| **奇数** | 3 个或 5 个产品比 2 个或 4 个更好 |
| **三角形构图** | 将 3 个项目以三角形排列以保持平衡 |

## 电商图像集

完整的商品列表需要 7-9 张图像，按以下顺序排列：

| 位置 | 图像类型 | 目的 |
|----------|-----------|---------|
| 1 | **主角/产品拍摄** | 主要列表图像，白色背景 |
| 2 | **生活方式** | 产品在使用/场景中 |
| 3 | **功能突出显示** | 突出关键功能 |
| 4 | **比例参考** | 手持或与已知物体并排的尺寸 |
| 5 | **细节特写** | 材质质量，工艺 |
| 6 | **备用角度** | 背面或侧面视图 |
| 7 | **信息图表** | 尺寸，规格，包含内容 |
| 8 | **包装** | 开箱体验 |
| 9 | **社会证明** | 评分叠加或带标题的生活方式图像 |

```bash
# 生成完整的电商集
# 1. 主角产品拍摄
belt app run bytedance/seedream-4-5 --input '{
  "prompt": "高端蓝牙音箱在白色背景下，工作室产品摄影",
  "size": "2K"
}' --no-wait

# 2. 生活方式
belt app run bytedance/seedream-4-5 --input '{
  "prompt": "生活方式产品摄影，蓝牙音箱放在泳池边桌子上，夏季设置，附近有太阳镜和饮料，温暖的自然光，度假氛围，编辑风格",
  "size": "2K"
}' --no-wait

# 3. 细节
belt app run bytedance/seedream-4-5 --input '{
  "prompt": "音箱格栅纹理和高端材料的极端特写，微距产品摄影，柔和照明，展示工艺质量，清晰细节",
  "size": "2K"
}' --no-wait

# 4. 比例
belt app run falai/flux-dev-lora --input '{
  "prompt": "人一手拿着紧凑型蓝牙音箱，展示便携尺寸，干净模糊的背景，自然光，生活方式科技摄影",
  "width": 1024,
  "height": 1024
}' --no-wait
```

## 产品类别

### 食品和饮料

```
关键：俯视角度，自然光，可见纹理，蒸汽/新鲜感提示
提示添加："食品摄影，诱人，新鲜，自然日光，浅景深"
避免：人工感颜色，完美对称的摆盘（看起来不真实）
```

### 珠宝和配饰

```
关键：微距细节，反射表面，黑色或渐变背景
提示添加："珠宝摄影，微距，闪光，反射表面，奢华"
避免：平面照明（杀死闪光），繁忙的背景
```

### 电子产品和科技

```
关键：干净的线条，深色或渐变背景，轮廓光
提示添加："科技产品摄影，时尚，现代，轮廓光，高端"
避免：温暖/乡村背景（错误美学）
```

### 化妆品和美容

```
关键：平面布局或微角度，大理石/干净表面，柔和粉彩色
提示添加："美容产品摄影，干净，简约，柔和光线，编辑"
避免：刺眼阴影，黑暗情绪照明（除非奢华/小众）
```

### 服装和时尚

```
关键：模特或平面布局，生活方式场景，品牌情绪
提示添加："时尚摄影，编辑，造型，自然姿势"
避免：生活方式纯白色背景（仅限电商使用）
```

## 图像编辑工作流程

```bash
# 生成基础产品图像
belt app run bytedance/seedream-4-5 --input '{
  "prompt": "高端耳机在白色背景下，工作室产品摄影",
  "size": "2K"
}'

# 编辑：更改背景为生活方式
belt app run bytedance/seededit-3-0-i2i --input '{
  "prompt": "将背景更改为现代简约的桌子设置，带有温暖的下午光，保持耳机完全相同",
  "image": "headphones-white.png"
}'

# 升级用于印刷
belt app run falai/topaz-image-upscaler --input '{
  "image": "headphones-lifestyle.png"
}'
```

## 常见错误

| 错误 | 问题 | 修复 |
|---------|---------|-----|
| 繁忙的背景 | 产品丢失 | 干净、简单的背景——产品是主角 |
| 平面正面角度 | 看起来像通缉令 | 微角度 15-30° 增加维度 |
| 类别错误的灯光 | 科技放在乡村木头上，食品在冷光下 | 与产品类别惯例匹配灯光 |
| 过多的道具 | 分散对产品的注意力 | 生活方式拍摄最多 2-3 个支撑道具 |
| 集合风格不一致 | 看起来不专业 | 相同的灯光设置，相同的背景系列 |
| 无比例参考 | 客户无法判断尺寸 | 至少包含一张与手或已知物体并排的拍摄 |
| 低分辨率 | 无法缩放，看起来业余 | 生成 2K+ 并根据需要升级 |
| 一切都完美居中 | 静态，无聊的布局 | 生活方式使用三分法，仅电商拍摄居中 |
