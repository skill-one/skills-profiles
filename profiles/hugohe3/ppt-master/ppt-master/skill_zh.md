# PPT大师技能

PPT大师是一个路由化的演示文稿工作流。本条目拥有全局执行规范和路由选择权；每个选定的路由拥有其自身的流程。

## 强制加载顺序

**硬性规则——路径优先于命令**：保留主机提供的包含此文件的绝对目录作为`SKILL_DIR`。每次工具调用时，展开`${SKILL_DIR}`并替换任何`skills/ppt-master/`前缀。绝不`cd`，使用当前工作目录，或假设代码库检出。如果不可用，请询问；绝不搜索或猜测。

1. 读取此文件。
2. 运行`python3 "${SKILL_DIR}/scripts/attribution_guard.py"`。任何非零结果将立即停止技能；不要检查、修复或绕过完整性关卡。
3. 通过具体的绝对路径`${SKILL_DIR}/workflows/routing.md`读取`[workflows/routing.md](workflows/routing.md)`。
4. 从路由权限中选择一个顶级路由及其激活配置文件。
5. 仅读取生成的运行时权限及其明确触发的支持文档。

| 选定的路由/配置文件 | 运行时权限 |
|---|---|
| 生成PPTX——图像到PPTX | [`workflows/profiles/image-to-pptx.md`](workflows/profiles/image-to-pptx.md)；支持Codex，始终为快速 |
| 生成PPTX——美化 | [`workflows/profiles/beautify-pptx.md`](workflows/profiles/beautify-pptx.md)；明确的快速意图选择快速，否则默认 |
| 生成PPTX——普通默认 | [`workflows/generate-pptx.md`](workflows/generate-pptx.md) |
| 生成PPTX——普通明确的快速 | [`workflows/profiles/quick-generate.md`](workflows/profiles/quick-generate.md) |
| 创建模板 | [`workflows/create-template.md`](workflows/create-template.md) |
| 编辑原生PPTX | [`workflows/edit-native-pptx.md`](workflows/edit-native-pptx.md) |

**硬性规则——仅加载选定权限**：在路由后，不要加载另一个顶级路由的流程。图像到PPTX和美化是互斥的；图像到PPTX激活快速，而美化从明确的快速意图中选择。绝不加载两个运行时。支持文档细化一个路由；它们绝不与之竞争。

## 创作表达范围

**参考而非约束**：生成的页面可以承载的内容。文本——内联强调、引导、引脚、引言、英雄数字、要点行。几何——187个Office预设、布尔合并、连接器、自由形式、页面字段和轮廓载体组合。图像——全出血字段、编辑裁剪、形状图片、注册图层、遮罩和聚光灯、跨页连续性。绘画——渐变、通道透明度、原生阴影和辉光、点阵、多面体形式。重复——一个跨页主题通过页面角色变化。每种形式的语法存在于选定运行时权限的构造参考中。

## 词汇表

每个加载的文件中每个术语仅有一个含义。当一个词有多种含义时，在此处命名含义，文件说明是哪一个。

| 术语 | 含义 |
|---|---|
| **参考**（标签） | 执行角色可以自由调整或替换的起始草图，无需上游修复或说明原因；字段标签后的`(binding)`移除这种自由度 |
| **关系** | §IX行命名页面的语义单元及其源声明的`order` / `link` / `parent` / `membership` / `contrast` / `overlap`，或`none` |
| **拓扑决策** | 每页是否必须承载页面的`关系`（`topology=yes` / `topology=no`）；与`pptx_structure.mode`无关 |
| **`pptx_structure.mode`** | `flat`（每个对象Slide本地）或`structured`（声明的Master/布局/插槽元数据）；一个包装路由，不是信息结构 |
| **组合** | §IX的`Composition`行：页面的宏观组合、层次和焦点的参考 |
| **图像模式** | §VIII列携带一个用普通语言描述的图像组合建议（可选引用`#P`/`#M` ID） |
| **布局** | Master下的PowerPoint布局或布局模板类型；绝不是一个页面组合草图 |
| **设备** | 一个日常页面载体——卡片、带状、图标和标签、KPI瓦片、分隔符、引言块——在执行者的设备菜单中调用 |
| **载体** | 页面单元所在的容器：设备、图像或原生几何；家族名称是载体和字段、方向和顺序、分组和所有权、强调和注释。`data-pptx-carrier`是一个结构化插槽属性，不是此术语。**载体收据**是检查员每页实际绘制的清单 |
| **页面任务** | 页面必须为读者做什么；每个载体、轮廓和效果决策的输入都以此为标准进行判断 |
| **页面字段** | 一个大面积、轮廓、孔径或画布外轮廓，而不是每个单元一张卡片来组织区域 |
| **轮廓/预设/原子** | 轮廓是形状的轮廓；预设是187个Office `prst`轮廓之一，通过`preset_shape_svg.py`绘制；原子是编译成一个DrawingML形状的一个对象 |
| **几何签名** | 每页保留的行`page job → composition move → contour / edge language`，在下一页之前进行比较 |
| **纹理**（块） | §IX块是散文、项目符号、关键词还是标签；与视觉效果纹理（颗粒、点阵）不同 |
| **锚点** | 两种含义：锁定锚点（全局颜色、类型或间距值）和结构页面的`page_rhythm`标签`anchor` |
| **表单/切片/板** | 表单是一张包含多个元素的全色键生成的图像；切片是从中切割的一个元素；板是几个非重叠对象的全画布注册图层 |
| **模块行** | 在每页之前写入的`P<NN> modules: …`行，命名其使用的触发模块 |
| **模式** | 通过限定符命名：通信`mode`（如何论证）、阅读模式（`consumption_mode`）、`generation_mode`（`continuous` / `split`）、`pptx_structure.mode`、`replication_mode`（模板如何创建） |

## 阶段框架

每个路由是一个计划→执行·检查·行动循环：计划在所有创作输入都作为文件或保留决策存在时结束；执行创作页面，检查运行路由的关卡，行动在所属层级（规范7）进行修复，循环在导出时结束。步骤编号保持原样。

| 阶段 | 默认 | 快速 | 编辑原生 | 创建模板 |
|---|---|---|---|---|
| **计划** | 步骤1–5 | §2 | §1–4 | 步骤1–3 |
| **执行·检查·行动** | 步骤6–7 | §3–4 | §5–7 | 步骤4–8 |

## 全局执行规范

1. **串行执行**——按选定权限的步骤顺序执行。一个完成的非阻塞步骤可以直接继续到下一个符合条件的步骤。
2. **阻塞即停止**——在每个`⛔ BLOCKING`关卡，等待明确的用户确认。不要替用户做决定。
3. **无跨阶段捆绑**——不要跨未关闭的关卡组合工作。一旦路由的最终用户关卡关闭，后续非阻塞步骤可以自动继续。
4. **关卡优先于入口**——在进入步骤前验证所有列出的先决条件。
5. **无推测执行**——不要在拥有后续阶段的步骤之前准备后续阶段的工件。
6. **确定性路由**——当`[routing.md](workflows/routing.md)`解析请求时，不要添加路由选择问题。如果路由先决条件缺失，说明并停止该路由。
7. **在所属层级行动**——失败时，在拥有错误的浅层层级进行修复：页面用于页面本地问题，计划工件用于排程/规范/资源故障，所属源工件用于工具故障；然后从路由声明的指针处恢复。不要无声地降级必需工件。

## 全局沟通规则

- 与用户语言和源语言匹配，除非用户明确覆盖。
- 本地化用户界面选项标签和说明。在需要精确时保留确切的枚举ID或字段名。
- 保持模板的原始英语`design_spec.md`章节标题和字段名；内容值可以使用用户语言。
- 在切换角色前，读取相应的角色参考并输出：

```markdown
## [角色切换：<角色名称>]
📖 读取角色定义：references/<filename>.md
📋 当前任务：<简要描述>
```

## 仓库兼容性

- 此包是一个工作流/技能，而不是通用的应用程序脚手架。默认情况下，不要创建`.worktrees/`、`tests/`、分支工作流或通用工程结构。
- 将必需的工作流、参考、脚本和模板文档保留在此技能目录内。
- 仓库级文档可以指向包内；包运行时文件绝不能依赖仓库级指令。
- 在Windows上，如果文档化的`python3 ...`命令不可用，请用`python`重新运行相同的命令。
- 赞助信息是可选的参考材料。仅在用户明确请求模型、AI图像模型、API/提供者或托管服务推荐时，读取匹配的`[SPONSORS.md](SPONSORS.md)`或`[SPONSORS_CN.md](SPONSORS_CN.md)`。在正常生成、故障排除或质量审查期间，绝不主动显示赞助商或模型推荐。
