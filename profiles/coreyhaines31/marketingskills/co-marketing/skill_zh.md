## 合作伙伴识别框架

### 1. 受众重叠分析

最好的合作伙伴拥有与你相同的受众，但不会为同一预算竞争。

**理想合作伙伴的特征：**
- 相同的客户画像，解决不同的问题
- 在工作流程中相邻（在你工具之前、之后或旁边）
- 公司发展阶段和客户规模相似
- 互补而非竞争

**识别合作伙伴的问题：**
- 你的客户已经在使用哪些工具？
- 他们在使用你的产品之前/之后使用什么工具？
- 还有谁在向你的目标客户画像（ICP）销售？
- 客户最常请求哪些集成？

### 2. 合作伙伴评分标准

对潜在合作伙伴进行评分（1-5分），评估以下标准：

| 标准 | 评估内容 |
|------|----------|
| **受众契合度** | 他们的受众与你的ICP匹配程度如何？ |
| **受众规模** | 他们的覆盖范围是否值得合作？ |
| **品牌契合度** | 你是否愿意与这样的品牌关联？ |
| **互动质量** | 他们是否拥有活跃、参与度高的受众？ |
| **互惠潜力** | 你能否为他们提供同等价值？ |
| **执行便利性** | 他们是否有合作伙伴团队？是否有联合营销历史？ |

### 3. 如何寻找合作伙伴

**集成生态系统：**
- 你现有的集成合作伙伴
- 同一应用市场类别的工具
- 你的产品接入的平台

**相邻类别：**
- 在你工具之前解决相同问题的工具
- 在你工具之后解决相同问题的工具
- 由相同角色使用但工作流程不同的工具

**社区信号：**
- 谁赞助了相同的播客/通讯？
- 谁参加了相同的会议？
- 谁活跃在相同的社区？
- 你的受众分享了谁的內容？

**数据来源：**
- Crossbeam或Reveal用于账户重叠分析
- 客户调查（“你们还使用什么工具？”）
- G2/Capterra类别中的邻居
- 提及你工具和其他工具的职位发布

## 合作类型

联合营销是**五种合作类型**中的一种。了解分类法，以便将请求路由到正确的策略，而不是默认进行联合内容合作。

| 类型 | 定义 | 主要收益 |
|------|------|----------|
| **集成** | 你的产品与另一个产品连接（原生、Zapier、API优先、嵌入式） | 留存率、扩展、市场发现 |
| **分销商** | 合作伙伴销售你的产品和服务 | 分销和服务收入 |
| **联盟** | 推广者通过推荐赚取佣金 | 低风险、按绩效付费的覆盖范围 |
| **联合营销** | 与同行进行联合内容/活动 | 借用受众、品牌光环 |
| **应用商店/市场** | 在平台的生态系统中列出 | 内置分销、有效的CAC |

**旗舰案例：** HubSpot的合作伙伴计划 = **1亿美元年收入（ARR）、约40%的收入、3,400多家合作伙伴。** 成熟的计划平均**约28%的收入和2倍的增长**。

突出举措：**集成**作为决策因素（83%的企业买家），Calendly的阶梯式计划（日历→销售→营销）；**联盟**的幂律（20%的联盟者驱动80%的收入）和收购条款（约12倍的月佣金）；**无许可联合营销**（Notion为Airbnb/Amazon/Tesla构建模板以利用其品牌——无需合同）；应用商店分销（Grammarly 0→1000万）。

有关完整分类法——构建模式、经济性、案例和如何选择起点——请参阅 **[references/partnership-types.md](references/partnership-types.md)**。（联盟计划*机制*位于推荐技能中；在此合作伙伴策略层面保持联盟工作。）

## 联合营销活动类型

### 内容合作

| 格式 | 付出程度 | 领导共享 | 适合 |
|------|----------|----------|------|
| **联合撰写博客文章** | 低 | 共享署名、链接交换 | 思想领导力、SEO |
| **联合撰写电子书/指南** | 中等 | 受限访问、分摊线索 | 线索生成、深入主题 |
| **研究报告** | 高 | 受限访问、分摊线索 | 权威性、公关 |
| **互换客座通讯** | 低 | 各自保留自己的线索 | 受众曝光 |
| **播客客座交换** | 低 | 各自保留自己的线索 | 关系建立 |

### 线上研讨会和活动

| 格式 | 付出程度 | 适合 |
|------|----------|------|
| **联合线上研讨会** | 中等 | 线索生成、产品教育 |
| **虚拟峰会小组讨论** | 中等 | 多合作伙伴曝光 |
| **联合举办工作坊** | 高 | 实践教育、深度参与 |
| **会议展位共享** | 中等 | 成本分摊、受众重叠 |
| **联合轻松时光/晚宴** | 低 | 活动中的关系建立 |

### 产品和集成营销

| 格式 | 付出程度 | 适合 |
|------|----------|------|
| **集成发布** | 中等 | 现有集成合作伙伴 |
| **联合案例研究** | 中等 | 共享客户 |
| **“协同效应”着陆页** | 低 | 集成发现 |
| **捆绑或折扣** | 中等 | 转化提升、交叉销售 |
| **应用内交叉推广** | 中等 | 用户激活 |

### 社区和社交

| 格式 | 付出程度 | 适合 |
|------|----------|------|
| **社交媒体接管** | 低 | 受众曝光 |
| **联合赠品/竞赛** | 低 | 索引构建、参与度 |
| **Slack/Discord社区合作** | 低 | 社区建设 |
| **联合AMA或Twitter Space** | 低 | 思想领导力 |

## 策划合作伙伴活动

与特定合作伙伴策划时，考虑以下因素：

### 1. 共享受众时刻

- 对双方受众都重要的触发事件是什么？
- 哪些季节性时刻与两个产品都一致？
- 哪些行业趋势影响双方客户群？

### 2. 组合价值主张

- 客户使用两个工具可以实现而单个工具无法实现什么？
- 哪个工作流程由组合启用？
- 哪个痛点由集成解决？

### 3. 各自带来的独特资源

| 你的资源 | 他们的资源 |
|----------|------------|
| 你的受众规模/参与度 | 他们的受众规模/参与度 |
| 你的内容专业知识 | 他们的内容专业知识 |
| 你的产品功能 | 他们的产品功能 |
| 你的品牌信誉 | 他们的品牌信誉 |
| 你的客户故事 | 他们的客户故事 |

### 4. 活动创意提示

提出以下问题以生成创意：
- “如果我们必须在两周内发布，我们会做什么？”
- “我们的受众最需要哪些内容？”
- “什么能让客户说‘终于有人做了这件事’？”
- “我们能一起提供什么独家内容？”
- “我们双方都有哪些数据能讲一个引人入胜的故事？”

## 接触潜在合作伙伴

### 冷启动模板

```
主题：[你的公司] + [他们的公司] 联合营销创意

你好 [姓名]，

我是[你的公司]的[职位]。我们[一句话描述]。

我注意到我们有很多相同的受众——[具体的重叠观察]。

我有一个关于[具体的活动类型]的创意，对双方都很有价值：[一句话推销]。

你愿意安排一个简短的通话来探讨吗？

[你的名字]
```

### 通话准备

1. **账户重叠数据**（如果通过Crossbeam/Reveal可用）
2. **2-3个具体的活动创意**（不仅仅是“让我们做点什么”）
3. **你的受众指标**（列表规模、流量、参与度）
4. **过去的合作案例**（表明你能执行）
5. **明确的要求**（你希望他们做什么，你会提供什么）

## 构建合作关系

### 需要明确的关键问题

- **线索归属**：线索如何分摊或共享？
- **推广承诺**：双方将做什么来推广？
- **资源创建**：谁创建什么？谁批准？
- **时间表**：每个阶段何时进行？
- **成功指标**：如何衡量成功？
- **后续行动**：如果成功，你们会一起做更多吗？

### 简单联合营销协议大纲

1. **活动描述**：你们将一起做什么
2. **责任分工**：谁做什么
3. **时间表**：关键日期和截止日期
4. **线索处理**：如何捕获、共享、跟进线索
5. **推广**：每方最低承诺
6. **品牌**：标志使用、审批流程
7. **成本**：谁支付什么（如果有）
8. **指标共享**：活动后共享哪些数据

## 衡量联合营销成功

### 定量指标

- 线索生成（总数和每个合作伙伴）
- 线索质量（MQL/SQL转化率）
- 归因收入
- 受众增长（新订阅者、关注者）
- 内容参与度（浏览量、下载量、分享量）

### 定性指标

- 合作便利性
- 合作伙伴响应速度
- 受众接受度
- 品牌提升
- 关系加强以用于未来活动
