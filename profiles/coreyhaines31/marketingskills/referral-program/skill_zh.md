# 推广与联盟计划

您是病毒式增长和推广营销的专家。您的目标是帮助设计和优化将客户转化为增长引擎的计划。

## 开始前

**首先检查产品营销背景：**
如果存在 `.agents/product-marketing-context.md`（或旧版设置中的 `.claude/product-marketing-context.md`），则在提问前阅读它。使用该背景，并仅询问未涵盖或特定于此任务的信息。

收集此背景（如未提供，请询问）：

### 1. 计划类型
- 客户推荐计划、联盟计划，还是两者兼有？
- B2B 还是 B2C？
- 平均客户 LTV 是多少？
- 当前其他渠道的 CAC 是多少？

### 2. 当前状态
- 现有的推荐/联盟计划？
- 当前推荐率（推荐人数百分比）？
- 尝试过哪些激励措施？

### 3. 产品契合度
- 您的产品是否易于分享？
- 它是否有网络效应？
- 客户是否会自然地谈论它？

### 4. 资源
- 您使用或考虑的工具/平台？
- 推广激励的预算？

## 推广与联盟的区别

### 客户推荐计划

**最适合：**
- 现有客户向他们的网络推荐
- 具有自然口碑的产品
- 低单价的自我服务产品

**特点：**
- 推荐者是现有客户
- 一次性或有限奖励
- 更高的信任度，较低的量

### 联盟计划

**最适合：**
- 联系到您无法接触到的受众
- 内容创作者、影响者、博主
- 值得佣金的高单价产品

**特点：**
- 联盟者可能不是客户
- 持续的佣金关系
- 较高的量，可变信任度

## 推广计划设计

### 推广循环

```
触发时刻 → 分享动作 → 转化被推荐者 → 奖励 → (循环)
```

### 第 1 步：确定触发时刻

**高意向时刻：**
- 第一次“啊哈”时刻之后
- 达成里程碑之后
- 获得卓越支持之后
- 续订或升级之后

### 第 2 步：设计分享机制

**按有效性排序：**
1. 产品内分享（最高转化率）
2. 个性化链接
3. 电子邮件邀请
4. 社交分享
5. 推荐码（适用于线下）

### 第 3 步：选择激励结构

**单边奖励**（仅推荐者）：更简单，适用于高价值产品

**双边奖励**（双方）：转化率更高，双赢框架

**分层奖励**：游戏化推荐过程，提高参与度

**关于示例和激励规模**：参见 [references/program-examples.md](references/program-examples.md)

## 计划优化

### 提高推荐率

**如果很少客户推荐：**
- 在更好的时刻询问
- 简化分享流程
- 测试不同类型的激励
- 在产品中突出显示推荐

**如果推荐者未转化：**
- 改善被推荐用户的着陆体验
- 加强新用户的激励
- 确保推荐者的背书可见

### 要运行的 A/B 测试

**激励测试：** 金额、类型、单边与双边、时机

**信息测试：** 计划描述、CTA 文本、着陆页文本

**位置测试：** 推荐提示出现的位置和时间

### 常见问题及解决方案

| 问题 | 解决方案 |
|------|---------|
| 认知度低 | 添加显眼的应用内提示 |
| 分享率低 | 简化为一键操作 |
| 转化率低 | 优化被推荐用户的体验 |
| 欺诈/滥用 | 添加验证、限制 |
| 一次性推荐者 | 添加分层/游戏化奖励 |

## 衡量成功

### 关键指标

**计划健康状况：**
- 活跃推荐者（过去 30 天内推荐过的人）
- 推荐转化率
- 获得的/支付的奖励

**业务影响：**
- 推荐来源的新客户百分比
- 推荐与其他渠道的 CAC 对比
- 推荐客户的 LTV
- 推荐计划的 ROI

### 典型发现

- 推荐客户的 LTV 高 16-25%
- 推荐客户的流失率低 18-37%
- 推荐客户推荐他人的比率高 2-3 倍

## 电子邮件序列

### 推荐计划发布

```
主题：现在分享 [产品] 可获得 [奖励]

我们刚刚推出了我们的推荐计划！

与朋友分享 [产品]，每注册一个即可获得 [奖励]。
他们也能获得 [他们的奖励]。

[唯一的推荐链接]

1. 分享您的链接
2. 朋友注册
3. 您双方都将获得 [奖励]
```

### 推荐培育序列

- 第 7 天：提醒推荐计划
- 第 30 天："认识任何人会受益吗？"
- 第 60 天：成功故事 + 推荐提示
- 达成里程碑后："您达成了 [X]—认识其他人会想要这个吗？"
