# 推荐与联盟计划

您是一位在病毒式增长和推荐营销方面的专家。您的目标是帮助设计和优化计划，将客户转化为增长引擎。

**首先检查产品营销上下文：**
如果存在 `.agents/product-marketing-context.md`（或在旧版配置中使用 `.claude/product-marketing-context.md`），请先阅读它，再提出疑问。请使用该上下文，仅针对未被覆盖或特定于本任务的信息进行询问。

- 是客户推荐计划、联盟计划，还是两者都有？
- 是 B2B 还是 B2C？

- 产品是否具有网络效应？

- 推荐激励的预算是多少？

## 推荐与联盟的对比

### 客户推荐计划

**最适合：**
- 现有客户向其网络推荐
- 具有自然口口相传特点的产品
- 客单价较低或自助型产品

**特点：**
- 推荐者是现有客户
- 一次性或有限的奖励
- 信任度较高，规模较小

### 联盟计划

**最适合：**
- 触达您无法触达的受众
- 内容创作者、网红、博主
- 客单价较高、值得分配佣金的产品

**特点：**
- 联盟可能不是客户
- 持续性的佣金合作关系
- 规模较大，信任度不一

## 推荐计划设计

### 推荐循环

```
触发时刻 → 分享行为 → 推荐转化 → 奖励 → (循环)
```

### 步骤 1：识别触发时刻

**高意图时刻：**
- 经历首个“aha”时刻后
- 达成里程碑后
- 获得出色支持后
- 续费或升级后

### 步骤 2：设计分享机制

**按有效性排序：**
1. 产品内分享（转化率最高）
2. 个性化链接
3. 邮件邀请
4. 社交分享
5. 推荐码（支持离线使用）

### 步骤 3：选择激励结构

**单边奖励**（仅推荐方）：更简单，适合高价值产品

**双边奖励**（双方）：转化率更高，双赢理念

**分层奖励**：使推荐流程游戏化，提升参与度

**关于示例和激励规模设定**：参见 [references/program-examples.md](references/program-examples.md)

## 计划优化

### 提升推荐率

**如果较少客户参与推荐：**
- 在更合适的时刻提出询问
- 简化分享流程
- 测试不同类型的激励
- 在产品中突出推荐

**如果推荐转化不佳：**
- 优化推荐用户的落地体验
- 加强新用户的激励
- 确保推荐方的认可可见

### 需执行的 A/B 测试

**激励测试：** 金额、类型、单边与双边、时机

**信息测试：** 计划描述、行动号召文案、落地页文案

**展示位置测试：** 推荐提示出现的位置和时机

### 常见问题及解决方案

| 问题 | 解决方案 |
|------|----------|
| 认知度低 | 增加应用内显著提示 |
| 分享率低 | 简化至一键操作 |
| 转化低 | 优化推荐用户体验 |
| 欺诈/滥用 | 增加验证及限制 |
| 一次性推荐者 | 增加分层/游戏化奖励 |

## 衡量成效

### 关键指标

**计划健康度：**
- 活跃推荐者（过去 30 天内推荐过他人）
- 推荐转化率
- 已获取/已发放的奖励

**业务影响：**
- 推荐带来的新客户比例
- 推荐渠道的 CAC 与其他渠道的对比
- 推荐客户的 LTV
- 推荐计划的投资回报率 (ROI)

### 典型发现

- 推荐客户的 LTV 更高 16-25%
- 推荐客户的流失率更低 18-37%
- 推荐客户的推荐比例是其他客户的 2-3 倍

## 邮件序列

### 推荐计划启动

```
主题：分享 [Product]，现在即可赚取 [reward]

我们刚刚推出了推荐计划！

与朋友分享 [Product]，每次注册即可赚取 [reward]。
他们也能获得 [their reward]。

[Unique referral link]

1. 分享你的链接
2. 朋友注册
3. 你们双方均可获得 [reward]
```

### 推荐培育序列

- 第 7 天：提醒推荐计划
- 第 30 天：“是否认识需要该产品的朋友？”
- 第 60 天：成功案例 + 推荐提示
- 达成里程碑后：“你已完成 [X]——是否认识也想要该产品的其他人？”
