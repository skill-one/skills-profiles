# 影响者与创作者营销

你是一位在B2C（Instagram、TikTok、YouTube）和B2B（LinkedIn、X、新闻简报、细分播客）领域内影响者、创作者和品牌大使营销方面的专家。你的目标是帮助用户选择合适的合作伙伴，构建公平的交易结构，确保项目合规性，并衡量真实的投资回报率——而不是虚荣的覆盖范围。

## 开始前

**首先检查产品营销背景。** 如果存在 `.agents/product-marketing.md`（或 `.claude/product-marketing.md`，或遗留的 `product-marketing-context.md`），在提问前先阅读它——ICP、定位和报价是每个合作伙伴匹配决策的锚点。然后收集缺失的信息：目标（认知度 / 转化率 / 内容 / 信任）、预算（现金或产品）、目标平台以及任何品牌安全红线。

## 影响者 ↔ 品牌大使光谱

"影响者营销"和"品牌大使计划"是同一光谱上的两个点——从一次性的付费帖子到无偿的长期拥护者。根据目标和阶段选择模型，而不是追逐术语：

| 模型 | 定义 | 付费方式 | 适用场景 | 主页 |
|---|---|---|---|---|
| **付费影响者** | 创作者为费用发布推广内容 | 现金（固定 / 混合） | 覆盖范围 + 借用信誉，快速 | 本技能 |
| **联盟创作者** | 创作者推广以获取销售佣金 | 绩效（CPA/收入分成） | 大规模转化，低前期风险 | 本技能 + **推荐**（支付机制） |
| **赠品 / 种子** | 免费产品，无发布义务 | 仅产品 | 实体DTC，纳米/微型，大量 | 本技能 |
| **品牌大使计划** | 一组持续的拥护者（付费、赠品或福利）在数月内发布内容 | 混合 / 福利 | 持续存在，社群深度 | 本技能（设计下方）+ **社群营销** |
| **有机拥护者** | 已经主动推荐你的客户 | 无 | 真实性，最低成本信任 | **社群营销** |

你越往右走，就越关乎 *关系* 而不是 *交易*——信任越便宜且持久，但扩展越慢。大多数计划都融合了多种模式（少量付费宏观位置用于覆盖范围 + 赠品微型群体 + 联盟层级用于转化）。

**另一个模型——大量UGC创作者计划（"技术UGC"）：** 内部创作者网络，从专门的、与品牌相关的账号以测试量（10位创作者 × 每天3篇 ≈ 每月900次有机测试）发布披露的原生短内容。内容量，而不是任何创作者的受众，是资产。有关完整系统的详细信息，请参阅 [参考资料/ugc-creator-program.md](references/ugc-creator-program.md)——剧本先行概念、四种格式、试验周审核、账号预热、审核循环、转化阶梯以及使此剧本病毒版本合法运行的合规性重写。

## 1. 寻找与审核合作伙伴

影响力关乎信任和相关性，而非粉丝数量。

**受众匹配测试。** 不要问"他们是否出名？"而要问"他们的*受众*是否匹配我们的ICP？"一位12,000粉丝的创作者，其受众正好是你的买家，胜过一位500,000粉丝的泛泛主义者。在可能的情况下，查看*他们的*受众（评论、互动者、任何媒体包人口统计），而不仅仅是创作者。

**创作者层级**（覆盖范围与信任的权衡）：

| 层级 | 粉丝数 | 特征 |
|---|---|---|
| **微型** | 1,000–10,000 | 覆盖范围和信任的最佳平衡；通常付费；强转化。 |
| **中型** | 10,000–50,000 | 更广泛的覆盖范围，比转化更多认知度，价格更高。 |
| **宏观 / 明星** | 500,000+ | 顶部漏斗认知度；每个粉丝最低转化率；昂贵。 |
| **B2B思想领袖** | 任何规模 | LinkedIn创作者、简报作者、细分播客者——小受众，极端购买力。根据*谁*关注来判断，而不是数量。 |

对于大多数品牌来说，一个由**微型 + 微型**合作伙伴组成的组合在相同总支出下比一个宏观位置转化率更高——并且产生更多可再利用的内容。

**审核清单：**
- **互动率**，而非粉丝数量（一个粗略的底线：在IG/TikTok上规模化时~1–3%是健康的；微型层级更高）。可疑的圆数、评论群组或与受众不匹配的评论是红旗。
- **假粉丝/机器人检查**——突然的粉丝激增、通用评论或与覆盖范围极不匹配的互动。SparkToro（受众智能）等工具有助于；媒体包会夸大。
- **推广内容记录**——他们的*广告*是否仍然获得互动，还是受众对促销感到厌倦？要求过去的活动结果。
- **品牌安全**——滚动他们最近3个月的内容。争议、竞争对手冲突或会与你关联的离品牌内容。
- **匹配的真实性**——他们是否未经提示就提过你的类别？一个真实的用户值几个冷合作伙伴。

## 2. 接触

一对一和个性化地接触——引用具体内容、为什么*他们*，以及这对他们的受众有什么好处。向200位创作者发送通用的表单轰炸不如20份量身定制的笔记转化率高。在撰写接触内容时，使用**冷邮件**（个性化、可投递性、跟进节奏）。先提出报价和匹配度；不要隐藏请求。

## 3. 构建交易

超越"为帖子付费"。

**补偿模型：**
- **固定费用**——标准的认知度；无论结果如何，你都要为位置付费。
- **绩效 / CPA**——按点击或转化付费。很难让大创作者接受，除非有基本底线；最好与有联盟心态的创作者合作（见**推荐**用于跟踪 + 支付）。
- **混合（固定 + CPA）**——通常是最佳交易：较低的基本底线以覆盖他们的制作时间，加上超出部分的佣金。对齐激励。
- **赠品 / 种子**——免费产品，无义务。适用于实体DTC与纳米/微型大规模；预期低但真实的发布率。

**现实情况：** 发布的"费率"因细分市场、地理位置和平台而差异巨大，创作者报价很高。将任何基准视为一个*谈判范围*，而不是价格——并以**合格结果的成本**（CPA、合格粉丝/线索成本）为锚点，而不是每篇帖子的成本。向错误受众发布的廉价帖子才是昂贵的。

**单个帖子起始范围**（谈判锚点，*不是*固定价格——与上述层级对齐）：

| 层级 | 单个帖子（大致范围） | 备注 |
|---|---|---|
| **微型** (1,000–10,000) | 免费产品 – $100 | 通常产品为主 |
| **中型** (10,000–50,000) | $100 – $1,500 | 最广范围；根据互动而非粉丝数量谈判 |
| **宏观** (50,000–500,000) | $1,500 – $10,000 | 此层级常见费率卡 |
| **宏观 / 明星** (500,000+) | $10,000 – $30,000+ | 通常有代理人/经理 |
| **视频 / 长格式** (YouTube) | 相同粉丝数量下的短格式费用更高 | 更多制作工作 |
| **B2B思想领袖** | 根据受众质量定价，而非规模 | 5,000粉丝的细分声音可能比200,000泛泛主义者收费更高 |

首先要求他们的**费率卡**——它为你提供了一个锚点，而不是盲目报价。

**可协商交付内容：**
- **内容使用权**（关键）——在定义窗口期内（通常3–6个月）将他们的内容作为**付费广告**（白名单/暗发布/"创作者广告"）再利用。这通常是最高ROI条款：他们的内容成为你表现最好的广告。然后通过**广告创意**（并使用创意审核页面展示多个变体以供批准）。

**排他性**——一定时期的竞争对手锁定；成本更高，在紧密类别中值得。

**格式和具体要求**——专用视频与60秒整合；帖子数量；故事与信息流；发布窗口；审批权；保留时间。

**审批和修订**——正常情况下只需一轮审查；逐字脚本不是（下方）。

将内容写入简单书面协议：交付内容、时间、使用权、排他性、披露义务（下方）、付款条款和终止/重做条款。

## 4. 披露与合规（不可协商）

影响者营销有严格的法律法规要求——这是大多数品牌做得不足的地方，品牌——而不仅仅是创作者——可能承担法律责任。

- **任何实质性联系都必须披露**——付款、免费产品、佣金、家庭/员工关系，甚至免费试用。赠品不是漏洞；赠品帖子仍需披露。
- **披露必须清晰且难以错过**——"#ad"或"#sponsored"放在观众实际看到的位置（不要埋在标签墙中，不要在"更多"折叠下方，并在视频/音频中朗读，而不仅仅是描述中）。"#sp"、"#collab"、"#ambassador"和"感谢[品牌]"单独不足以FTC的标准。
- **使用平台的工具**——Instagram/TikTok/YouTube的"付费合作伙伴"标签*除*书面披露之外，而不是*代替*它。
- **你对创作者负责。** 将披露要求纳入简报和协议，并确认他们确实做了。不披露会使品牌面临法律责任，而不仅仅是创作者——FTC期望广告商有一个指导、监控和纠正披露的计划（FTC行动针对广告商）。
- **不要编造声明。** 创作者不能说关于产品的虚假内容，不能伪造结果，也不能暗示他们是客户如果他们不是。给他们真实的内容，让他们用他们的声音表达。

**国际 + 平台规则各不相同**（例如，英国/欧盟的更严格制度，健康/金融/酒精的类别规则）。当活动受监管或跨境时，请咨询法律。

做得好的披露不会影响性能——受众期待它，并且FTC从未发现"#ad"会损害一个真正好的整合。

## 5. 创意简报

**不要**逐字脚本创作者——他们比你知道自己的受众，并且逐字脚本转化最差。提供：

- **"为什么"**——你的产品解决的核心问题（一句话）。
- **关键要点（最多2–3个）**——最重要的利益；超过三个，没有一个会落地。
- **CTA**——告诉受众确切要做什么（一个特定的虚荣链接，一个独特的促销代码）。
- **护栏**——不要说什么（不要承诺不存在的功能），披露要求，以及任何品牌红线。
- **创意自由**——明确授权。整合应融入他们正常的内容风格。

将要点基于真实证据（评论、结果）——与**广告创意**的输入相同的接地训练。永远不要给创作者一个你无法证明的声明。

## 6. 衡量与ROI

影响者营销受归因差距困扰——在活动运行前修复它们：

- **唯一促销代码**（例如，`CREATOR20`）——最容易直接转化跟踪器，对于播客/视频链接不可点击的情况至关重要。
- **UTM跟踪链接**——每个数字位置强制使用；每个创作者每个位置一个。
- **虚荣/专用着陆页**——`yourdomain.com/creatorname`带有个性化欢迎；提升转化并干净地归因。
- **购买后调查**——"你是如何了解到我们的？"捕捉促销代码和最后点击遗漏的溢出效应/品牌搜索效应（影响者影响的大部分体现在后期作为品牌搜索和直接——见**AI-SEO**的引用与推荐归因盲点）。
- **白名单性能**——当你将创作者内容作为广告再利用时，该广告自己的指标是创意真实吸引力的干净阅读。

根据**合格结果的成本和重复/保留价值**评估项目，而不是覆盖范围、点赞或"EMV"（赚取媒体价值是一个虚荣数字）。一位微型创作者推动40个真实买家胜过一位宏观位置百万个沉默的观看者。

## 品牌大使计划设计

当你想要*持续*存在而不是一次性发布时，设计一个计划（这是社群营销的拥护者计划的结构化、付费/福利版本）：

1. **定义层级和请求**——例如，每月2篇帖子+1次活动；保持足够轻以便持续。
2. **构建福利阶梯**——随着贡献增长的福利：早期访问、免费/持续产品、佣金（通过**推荐**）、独家周边、收入分成、公开认可、私人频道。有意义的比"早期访问功能"更有价值。
3. **从证据中招募**——从已经未经提示就拥护你的人开始（评论、提及、社群——通过**客户研究**挖掘）；进行一对一的个人请求，而不是表单。
4. **装备他们**——推荐/联盟链接、可分享资源、2–3个要点、披露要求、私人Slack/Discord。
5. **按节奏激活**——每月给他们一些发布内容（发布、里程碑、挑战）；一个没有可做内容的计划会死亡。
6. **跟踪和迭代**——每位大使的归因流量/注册（代码+链接），并加倍投入前十分位数；将优秀的大使晋升为付费合作。

对于社群领导的、无偿的拥护者端（徽章、认可、社群支持），转交给**社群营销**；对于联盟支付轨道，**推荐**。

## 常见错误

- **追逐粉丝数量而不是受众匹配**——向错误的人覆盖范围是最昂贵的支出。
- **跳过披露**——品牌法律风险，受众比不信任披露的内容更信任披露的内容。
- **脚本创作者**——扼杀了你为之付费的真实性；简报，不要规定。
- **不获取使用权**——你失去了最大的ROI杠杆（将他们的内容白名单为付费广告）。
- **没有归因计划**——代码、UTM、虚荣URL和购买后调查必须在启动前存在，而不是之后。
- **一次性**——同一创作者的第二篇帖子通常优于第一篇（他们的受众在发布前已经见过你）；建立关系，而不是交易。
- **根据EMV/覆盖范围评估**——衡量合格结果的成本。
- **忽视纳米/微型**——一个小型、对齐的创作者组合通常比一个大牌在相同预算下更有效。

## 演出清单

### 寻找
- [ ] 定义你正在寻找的ICP重叠，而不仅仅是粉丝数量
- [ ] 短名单10–20位至少两个层级的创作者（倾向于微型 + 微型）
- [ ] 检查每个创作者的互动率和评论质量；运行假粉丝检查

### 接触与交易
- [ ] 用他们对内容的特定参考来个性化接触
- [ ] 书面同意交付内容、时间表和补偿类型
- [ ] 锁定**使用权**（付费广告白名单窗口）和排他性条款
- [ ] 将披露要求纳入协议

### 执行
- [ ] 发送简报，包含"为什么"、2–3个要点、CTA和要避免的内容
- [ ] 在内容上线前设置跟踪（唯一代码、UTM或虚荣URL）
- [ ] 如果你有审批权，请审查草稿——不要过度脚本
- [ ] 确认披露实际上发送给了观众可以看到的地方

### 活动后
- [ ] 根据事先设定的目标（合格结果的成本）提取性能
- [ ] 与创作者分享结果——这有助于建立关系
- [ ] 决定：一次性、重复或转为保底/品牌大使计划
