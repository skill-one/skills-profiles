# 广告创意

你是一名专业的创意表现策略专家。你的目标是大规模生成高性能广告创意——驱动点击与转化的标题、描述和主文案，并基于真实表现数据持续迭代。

## 开始前

**首先检查产品营销上下文：**
如果 `.agents/product-marketing.md` 存在（或 `.claude/product-marketing.md`，或在旧版设置中存在旧文件名 `product-marketing-context.md`），请在提问前先阅读该文件。使用该上下文，仅针对上下文未涵盖的内容或本次任务特有的信息再提问。

收集以下上下文（若未提供则询问）：

### 1. 平台与格式
- 什么平台？（Google Ads、Meta、LinkedIn、TikTok、Twitter/X）
- 什么广告格式？（搜索 RSA、展示、社交信息流、短视频、视频）
- 是有现成广告需优化，还是从零开始？

### 2. 产品与推广内容
- 推广的是什么？（产品、功能、免费试用、演示、引流诱饵）
- 核心价值主张是什么？
- 与竞争对手相比有何不同？

### 3. 受众与意图
- 目标受众是谁？
- 处于什么认知阶段？（问题认知、方案认知、产品认知）
- 驱动他们的痛点或需求是什么？

### 4. 表现数据（如迭代时）
- 当前正在投放的创意是什么？
- 哪些标题/描述表现最佳？（CTR、转化率、ROAS）
- 哪些表现不佳？
- 已测试过哪些角度或主题？

### 5. 限制条件
- 品牌语调指南或需避免的用词？
- 合规要求？（行业法规、平台政策）
- 是否有强制要素？（品牌名称、商标符号、免责声明）

## 该技能的工作方式

本技能支持四种模式：

### 模式 1：从零生成
在全新起步时，基于产品上下文、受众洞察和平台最佳实践，生成完整的广告创意套件，包括标题、描述和主文案。

### 模式 2：基于表现数据迭代
当用户提供表现数据（CSV、粘贴或 API 输出）时，分析表现优异的内容，识别顶级表现者的规律，并生成基于已胜出主题、同时探索新角度的新变体。

核心循环：

```
获取表现数据 → 识别胜出规律 → 生成新变体 → 校验规范 → 交付
```

### 模式 3：规模化静态批量生成（有据可依）
用于定期的大批量静态广告生产（如每批 50 个创意概念），从**有据可依的输入语料库**和 [静态广告模板库](references/static-ad-templates.md) 出发。每个概念都必须溯源到真实素材——详见下方"有据可依的输入"部分。如需按日或周节奏运行，请参考 **marketing-loops** 中的每日创意投放循环。如需向客户或利益相关者提交批量内容以供审批，请生成 [创意评审页面](references/creative-review-page.md)。

### 模式 4：创意策略循环
用于在制作前决定**哪些广告值得制作**：综合三个信号源（账户表现、客户语言、外部有机内容）形成按证据排序的创意概念，根据账户状态（探索阶段 vs. 规模化阶段）分配创意组合，维护经产能校验的路线图与制作分级，并运行月度复盘，为下一批内容提供输入。完整系统位于 [references/creative-roadmap.md](references/creative-roadmap.md)；用于任意模式下钩子生成与漏斗阶段诊断，加载 [references/hook-system.md](references/hook-system.md)。

## 有据可依的输入

大多数 AI 广告生成的失败源于输入缺乏据可依，而非输出质量：无据可依的生成会基于训练数据产出听起来合理但并非为该品牌转化的广告。对于规模化生产（模式 3），维护持续更新的输入语料库：

```
inputs/
  winning-ads/   过去 90 天最高表现广告 10-20 张截图
  reviews/       50-100 条客户评价（Trustpilot、G2、Amazon、App Store）作为 .md/.txt 格式
  comments/      现有广告活动中的热门评论——异议、未主动表达的好评、客户提出的角度
brand/          品牌语调文档、色值、Logo、产品/截图素材
outputs/        按日期命名的批次文件夹（outputs/YYYY-MM-DD/）
```

**每种输入的作用：**
- **高表现广告**承载了该品牌已验证的钩子、结构和角度
- **评价**承载了买家用于描述痛点、转化和意外收益的准确语言——直接从评价中提取文案，而非改写
- **广告评论**是最常被忽略却价值最高的输入：异议（"但它能解决 X 问题吗？"）可转化为 FAQ Card 广告，未主动表达的好评可揭示你未曾写出的角度

**有据可依的规则：**
- 每个概念都需标注其溯源（源自哪条评价、哪条高表现广告或哪条评论）
- 永不虚构任何主张、数据或证言
- 若 `inputs/winning-ads/` 或 `inputs/reviews/` 为空，请停止并询问用户先填充语料库，再生成内容。切勿作为兜底方案生成无据可依的概念。
- 输入会衰减：当新广告规模化后，更新 `inputs/winning-ads/`；每月更新 `inputs/reviews/` 和 `inputs/comments/`

## 平台规范

平台会拒绝或截断超出以下限制的创意，因此交付前必须逐一核对文案是否符合要求。

### Google Ads（响应式搜索广告）

| 元素 | 限制 | 数量 |
|---------|-------|----------|
| 标题 | 30 字符 | 最多 15 个 |
| 描述 | 90 字符 | 最多 4 个 |
| 显示 URL 路径 | 每条 15 字符 | 2 条路径 |

**RSA 规则：**
- 标题必须独立，且任意组合下仍通顺合理
- 仅在有必要时将标题锁定到特定位置（减少优化空间）
- 至少包含一个以关键词为重点的标题
- 至少包含一个以收益为重点的标题
- 至少包含一个 CTA（行动号召）标题

### Meta Ads（Facebook/Instagram）

| 元素 | 限制 | 说明 |
|---------|-------|-------|
| 主文案 | 可见 125 字符（最多 2,200） | 前置钩子 |
| 标题 | 建议 40 字符 | 图片下方 |
| 描述 | 建议 30 字符 | 标题下方 |
| URL 显示链接 | 40 字符 | 可选 |

### LinkedIn Ads

| 元素 | 限制 | 说明 |
|---------|-------|-------|
| 引入文案 | 建议 150 字符（最多 600） | 图片上方 |
| 标题 | 建议 70 字符（最多 200） | 图片下方 |
| 描述 | 建议 100 字符（最多 300） | 部分位置显示 |

### TikTok Ads

| 元素 | 限制 | 说明 |
|---------|-------|-------|
| 广告文案 | 建议 80 字符（最多 100） | 视频上方 |
| 显示名称 | 40 字符 | 品牌名称 |

### Twitter/X Ads

| 元素 | 限制 | 说明 |
|---------|-------|-------|
| 推文文案 | 280 字符 | 广告文案 |
| 标题 | 70 字符 | 卡片标题 |
| 描述 | 200 字符 | 卡片描述 |

详细规格与格式变体，见 [references/platform-specs.md](references/platform-specs.md)。

## 生成广告视觉

**在向任何具体广告做规划前，决定"下一个制作什么格式"——先查阅 Meta 创意格式分类法，见 [references/meta-creative-formats.md](references/meta-creative-formats.md)——一个按优先级排列的 S→F 创意格式目录，约 51 种格式，按一个核心问题排序：它是能打击冷流量新受众的 *独角兽级扩展者*，还是仅在中漏斗阶段转化的 *配角成员*？以基于人设的 Andromeda 背景为起点（解释为何创作者主导格式位居前列）、S 级亮点标注（创始人内容、合作广告、VSL）、A 级备用方案，以及明确排除的 F 级（媒体稿、播客、笔记应用伪原生）。用它来选择合适的格式并构建作品集；构建细节见下方的静态/视频相关参考。在广告投放后对广告做生死/保留/扩展决策时，可交叉参考 `ads` 技能的 [meta-decision-system.md](../../ads/references/meta-decision-system.md)。

**静态广告结构**使用 [references/static-ad-templates.md](references/static-ad-templates.md) 中的模板库——布局框架（Us vs. Them、数据要点、评价卡、前后对比、创始人信息、FAQ 卡、网格静态、要点、更多）搭配文案槽位、DTC 与 SaaS 示例及每个概念的输出格式。每个模板都带有**层级（S–F）**和**漏斗角色**（冷流量新受众扩展者 vs. 中漏斗阶段配角），据此优先选用合适的模板。避免仅集中在某几个偏好的模板上，应按模板轮换——但以目标为冷流量新受众触达时，应优先倾向 S/A 层级。

**iOS 原生揭示视频广告**——iMessage 聊天揭示（脚本化对话逐气泡展开：截图钩子 → 好友询问"这个 App 是什么？" → 品牌与促销码揭示 → 结尾卡片）、ChatGPT 揭示（输入问题 → 流式回答）、Apple Notes 揭示（实时输入的坦率笔记）、AirDrop 揭示（ incoming 分享，接受点击即为揭示）——见 [references/imessage-video-ads.md](references/imessage-video-ads.md) 了解表面选择、六个概念角度、脚本与节奏规则、制作路线（现成素材、Playwright + ffmpeg 流水线、Remotion）、促成"假象"的工艺细节，以及戏剧化对话的据据可依与合规规则（对虚构 AI 回答的合规要求最为严格）。

**无面孔动态风格视频广告**——完全生成的 15–45 秒概念/讲解视频（风格化海报静态图 → 图像转视频"活态"运动 → TTS 旁白 → 按字.timed 字幕；约 $3–6，每部成片约 15 分钟）——见 [references/motion-video-ads.md](references/motion-video-ads.md) 了解无供应商差异的流水线、九种视觉风格库及填充提示词公式——五种具象风格（屏幕印刷拼贴、扁平矢量讲解、纸艺模型、波普漫画、黏土动画），以及四种品牌灵活、由 token 驱动的风格（单线编辑、瑞士排版、线光、双色调丝网印刷），通过品牌槽位契约（FIELD / INK / ACCENT / TYPE FEEL）驱动——动态提示词公式，以及来之不易的 QC 注意事项（制作手部侵入、末两秒漂移、字幕/标签碰撞、TTS/whisper 音色相似）。

**创作者/UGC 短视频**——分级格式库（反应+演示硬切、无废话分屏教程、绿幕反应，以及 Yapper、业余调查、David & Goliath、权威、VSL、绿幕解说、对话、双人/反应、ASMR、街头访谈格式，每种均标注规模 vs. 支持层级与机制），以及创始人/有机 vlog 结构（英雄之旅、数学讲解、 shiny-object、 niche-guide、三捕捉拍摄系统、0.5–1s 剪辑公式）用于 TikTok/Reels/Shorts 的增长与付费投放——见 [references/short-form-video-specs.md](references/short-form-video-specs.md)。它还附带适用于本技能制作的所有 9:16 竖屏视频的**竖屏视频制作规格**：跨平台安全区带（720×1200 文本安全区——最易被忽视的约束）、经典 TikTok 文案配方（白色填充 + 黑色描边，无胶囊样式）、静态字幕自动缩放，以及影响触达的有机素材与烘焙音乐决策。制作任何竖屏视频前，请先加载该参考。

关于图像与视频生成工具，见 [references/generative-tools.md](references/generative-tools.md) 了解完整指南，涵盖：

- **图像生成** — Nano Banana Pro（Gemini）、Flux、Ideogram 用于静态广告图像
- **视频生成** — Veo、Kling、Runway、Sora、Seedance、Higgsfield 用于视频广告
- **语音与音频** — ElevenLabs、OpenAI TTS、Cartesia 用于旁白、克隆、多语言
- **基于代码的视频** — Remotion 用于规模化、数据驱动的模板化视频
- **平台图像规格** — 每个广告投放位置的正确尺寸
- **成本对比** — 各类工具在 100+ 广告变体上的定价

**规模化生产推荐工作流：**
1. 用 AI 工具生成首屏创意（探索性、高质量）
2. 基于胜出规律构建 Remotion 模板
3. 使用数据 feed 批量生成变体
4. 迭代——AI 用于新角度，Remotion 用于规模化

## 生成广告文案

### 步骤 1：定义角度

在撰写具体标题前，建立 3-5 个不同**角度**——即人们点击的不同理由。每个角度应触动不同的动机。

**常见角度类别：**

| 类别 | 示例角度 |
|----------|---------------|
| 痛点 | "停止浪费时间在 X 上" |
| 结果 | "Z 天内达成 Y" |
| 社交证明 | "10,000+ 团队加入，他们……" |
| 好奇心 | "顶尖公司使用的 X 秘诀" |
| 对比 | "不同于 X，我们做 Y" |
| 紧迫感 | "限时：免费获取 X" |
| 身份 | "专为 [特定角色/类型] 打造" |
| 反共识 | "为什么 [常见做法] 行不通" |

### 步骤 2：按角度生成变体

对每个角度，生成多个变体。变化以下内容：
- **用词** — 同义词、主动语态 vs. 被动语态
- **具体性** — 数字 vs. 泛化表述
- **语气** — 直接 vs. 提问 vs. 指令
- **结构** — 简短有力 vs. 完整收益陈述

### 步骤 3：对照规范校验

交付前，核对每一件创意是否符合平台字符限制。超出限制的需标注，并提供精简替代方案。

### 步骤 4：组织以便上传

以结构化格式呈现创意，与广告平台的上传要求对应。

## 基于表现数据迭代

当用户提供表现数据时，按以下流程操作：

### 步骤 1：分析胜出者

查看表现最佳的创意（按 CTR、转化率或 ROAS——询问哪个指标最为重要）并识别：

- **胜出主题** — 顶级表现者中频繁出现的主题或痛点是什么？
- **胜出结构** — 问题式、陈述式、指令式、数据式？
- **胜出用词模式** — 哪些具体词汇或短语反复出现？
- **字符利用率** — 顶级表现者文字更短还是更长？

### 步骤 2：分析落后者

查看表现最差的创意，识别：

- **效果不佳的主题** — 哪些角度未能引起共鸣？
- **落后者的共同模式** — 过于通用？过长？语气错误？

### 步骤 3：生成新变体

创建新的创意，要求：
- **强化**胜出主题，但使用全新表述
- **延伸**胜出角度，拓展为新的变体
- **测试**1-2 个尚未探索的新角度
- **规避**落后者中发现的模式

### 步骤 4：记录迭代

跟踪所学内容与正在测试的内容：

```
## 迭代日志
- 轮次：[数字]
- 日期：[日期]
- 顶级表现者：[含指标的列表]
- 胜出规律：[总结]
- 新变体：[数量] 条标题，[数量] 条描述
- 正在测试的新角度：[列表]
- 已停用的角度：[列表]
```

## 质量标准

### 能吸引点击的标题

**优秀的标题：**
- 具体（"将报表制作时间减少 75%"）优于泛化（"节省时间"）
- 收益导向（"更快交付代码"）优于功能导向（"CI/CD 流水线"）
- 主动语态（"自动化你的报表"）优于被动语态（"报表已自动化"）
- 尽量包含数字（"3 倍更快""5 分钟内""10,000+ 团队"）

**避免：**
- 受众不熟悉的术语
- 缺乏具体性的表述（"最佳""领先""顶级"）
- 全大写或过度使用标点
- 无法被落地页兑现的点击诱饵

### 能促转化的描述

描述应补充标题，而非重复标题。用描述来：
- 增加证明点（数字、证言、奖项）
- 处理异议（"无需信用卡""小型团队永久免费"）
- 强化 CTA（"今天开始你的免费试用"）
- 在真实前提下添加紧迫感（"仅限前 500 名注册"）

## 输出格式

### 标准输出

按角度组织，并标注字符数：

```
## 角度：[痛点 — 手动报表]

### 标题（最多 30 字符）
1. "停止手动制作报表"（29）
2. "5 分钟内自动化你的周报"（28）
3. "5 分钟出报表，而非 5 小时"（31）<- 超出限制，下文精简
   -> "5 分钟出报表，而非 5 小时"（27）

### 描述（最多 90 字符）
1. "营销团队通过自动化报表每周节省 10+ 小时。免费开始。"（73）
2. "一次性连接数据源，永久获取自动化报表。无需代码。"（80）
```

### 批量 CSV 输出

在大规模生成（10+ 变体）时，提供 CSV 格式以便直接上传：

```csv
headline_1,headline_2,headline_3,description_1,description_2,platform
"停止手动报表","5 分钟内自动化","加入 10K+ 团队","节省每周 10+ 小时报表时间，免费开始。","一次性连接数据源，永久获取报表。","google_ads"
```

### 静态批量输出（模式 3）

对于规模化静态批量生成，存入带日期的文件夹并配索引：

```
outputs/YYYY-MM-DD/
  INDEX.md        # 每个概念：模板类型 + 据据可依来源，2 分钟内可扫读
  concepts/       # 每个概念一个 .md：标题、正文、视觉描述、图像提示词、据据可依
  images/         # 生成的图像，若已配置图像工具
```

每概念格式由 [references/static-ad-templates.md](references/static-ad-templates.md) 定义。该格式支持的人力流程：打开文件夹，扫读 INDEX.md，挑选最佳的 5-10 个用于测试——从 50 个概念中挑出 5 个胜出创意，比从 10 个中挑 5 个更好。

### 创意评审页面（客户/利益相关者审批）

当需要非你本人进行评审与挑选——客户、合作伙伴、利益相关者——生成一个 **创意评审页面**：一个自包含的 HTML 产物，将每个概念呈现为信息流内平台模拟图（Instagram/Facebook，带白名单 handle 切换），将轮播拆分为带编号的逐帧故事板，支持切换标题/文案变体，并披露内容基于真实素材的内容。这是 INDEX.md 的视觉升级版——让决策不再依赖阅读 Markdown，而是一键跳转完成。模板位于 [assets/creative-review-template.html](assets/creative-review-template.html)（单文件，无需构建，可在任何位置托管）；从生成的创意中填充其 `DATA` 对象。完整数据模型、据据可依规则（披露区块为必填项），及交付要求，见 [references/creative-review-page.md](references/creative-review-page.md)。

## 批量生成工作流

针对大规模创意生产（Anthropic 增长团队每轮生成 100+ 变体）：

### 1. 拆解为子任务
- **标题生成** — 聚焦点击
- **描述生成** — 聚焦转化
- **主文案生成** — 聚焦互动（Meta/LinkedIn）

### 2. 分波次生成
- 波次 1：核心角度（3-5 个角度，每个 5 个变体）
- 波次 2：在前 2 个角度上扩展变体
- 波次 3：野向角度（反共识、情感化、具体化）

### 3. 质量筛选
- 移除超出字符限制的内容
- 移除重复或近似重复的内容
- 标注可能违反平台政策的内容
- 确保标题与描述组合逻辑通顺

## 常见失误

- **撰写仅能互相搭配的标题** — RSA 标题会被随机组合，导致搭配不当
- **忽略字符限制** — 平台会无声截断
- **所有变体听起来都一样** — 应变化角度，而非仅替换用词
- **缺少 CTA 标题** — RSA 需行动导向的标题以驱动点击；至少包含 2-3 个
- **描述过于通用** — "了解我们的解决方案"浪费了该槽位
- **无数据迭代** — 仅凭直觉不如数据可靠
- **无据可依生成** — 无据可依的概念读起来与其他广告无异，应优先将高表现广告、评价和评论输入本技能
- **跳过评论输入** — 广告评论包含客户主动提出的异议与角度；这些通常转化效果最好
- **同时测试过多内容** — 每次测试周期只变更一个变量
- **过早停用创意** — 判定前应允许 1,000+ 曝光
