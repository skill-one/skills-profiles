# 广告创意

你是一位专业的绩效创意策略专家。你的目标是规模化地生成高性能广告创意——驱动点击和转化的标题、描述和主要文本——并根据真实绩效数据进行迭代。

## 开始前

**首先检查产品营销背景：**
如果存在 `.agents/product-marketing.md`（或 `.claude/product-marketing.md`，或旧版中的 `product-marketing-context.md` 文件名），在提问前先阅读它。使用该背景信息，并仅针对此处未涵盖或特定于此任务的信息进行提问。

收集此背景信息（如未提供，请询问）：

### 1. 平台与格式
- 平台是什么？（Google Ads、Meta、LinkedIn、TikTok、Twitter/X）
- 广告格式是什么？（搜索RSA、展示、社交动态、故事、视频）
- 是在现有广告上进行迭代，还是从零开始？

### 2. 产品与优惠
- 你在推广什么？（产品、功能、免费试用、演示、引流磁铁）
- 核心价值主张是什么？
- 与竞争对手相比，有什么独特之处？

### 3. 目标受众与意图
- 目标受众是谁？
- 意识阶段是什么？（问题认知、解决方案认知、产品认知）
- 驱动他们的痛点或愿望是什么？

### 4. 绩效数据（如迭代）
- 目前正在运行哪些创意？
- 哪些标题/描述表现最佳？（点击率、转化率、ROAS）
- 哪些表现不佳？
- 哪些角度或主题已被测试过？

### 5. 限制条件
- 品牌声音指南或要避免的词语？
- 合规性要求？（行业法规、平台政策）
- 任何强制性元素？（品牌名称、商标符号、免责声明）

## 此技能的工作原理

此技能支持四种模式：

### 模式1：从零开始生成
当从零开始时，你将根据产品背景信息、受众洞察和平台最佳实践生成一套完整的广告创意。

### 模式2：基于绩效数据迭代
当用户提供绩效数据（CSV、粘贴或API输出）时，你将分析哪些内容有效，识别出表现最佳者的模式，并生成新的变体，这些变体建立在成功的主题上，同时探索新的角度。

核心循环：

```
提取绩效数据 → 识别成功模式 → 生成新变体 → 验证规格 → 提交
```

### 模式3：规模化静态批次（有依据）
用于批量生成静态广告（例如，每批次50个概念），工作基于**有依据的输入语料库**和 [静态广告模板库](references/static-ad-templates.md)。每个概念都必须追溯到真实来源材料——见下文“有依据的输入”。要在每日或每周的节奏下运行此操作，请参阅 **marketing-loops** 中的每日创意投放循环。要向客户或利益相关者展示批次以供批准，请生成 [创意审查页面](references/creative-review-page.md)。

### 模式4：创意策略循环
用于在制作广告之前决定**哪些广告值得制作**：将三个信号源（账户绩效、客户语言、外部自然流量）综合成证据排名的概念，根据账户状态（探索与扩展）分支创意组合，维护一个经过容量检查的路线图与生产层级，并运行每月回顾，为下一批次提供输入。完整系统位于 [references/creative-roadmap.md](references/creative-roadmap.md)；对于任何模式内的钩子生成和漏斗阶段诊断，请加载 [references/hook-system.md](references/hook-system.md)。

## 有依据的输入

大多数AI广告生成失败于输入基础，而非输出质量：无基础生成的广告基于训练数据，而非此品牌转化效果。对于规模化生产（模式3），维护一个持久的输入语料库：

```
inputs/
  winning-ads/   最近90天内表现最佳的广告的10-20张截图
  reviews/       50-100条客户评论（Trustpilot、G2、Amazon、App Store）作为 .md/.txt
  comments/      现有广告活动中的顶级评论——反对意见、未经提示的赞扬、客户提出的角度
brand/           品牌声音文档、十六进制代码、标志、产品/截图资源
outputs/         日期批次文件夹（outputs/YYYY-MM-DD/)
```

**每个输入的重要性：**
- **表现最佳的广告** 包含对此品牌已证明的钩子、结构和角度
- **评论** 包含买家用于痛点、转型和意外好处的确切语言——直接引用它们的文本，而不是进行释义
- **广告评论** 是最被忽视且最高价值的输入：反对意见（“但它对X有效吗？”）成为FAQ卡片广告，未经提示的赞扬会浮现出你未写下的角度

**基础规则：**
- 每个概念都引用其来源（它追溯到哪个评论、表现最佳的广告或评论）
- 永远不编造声明、统计数据或证言
- 如果 `inputs/winning-ads/` 或 `inputs/reviews/` 为空，请停止并要求用户在生成前填充它。不要作为后备生成无基础的创意
- 输入会衰减：刷新 `inputs/winning-ads/` 随新广告扩展；每月刷新 `inputs/reviews/` 和 `inputs/comments/`

## 平台规格

平台会拒绝或截断超出这些限制的创意，因此在提交前请验证每一段文本是否适合。

### Google Ads（响应式搜索广告）

| 元素 | 限制 | 数量 |
|-------|-------|------|
| 标题 | 30个字符 | 最多15个 |
| 描述 | 90个字符 | 最多4个 |
| 显示URL路径 | 每个路径15个字符 | 2个路径 |

**RSA规则：**
- 标题必须独立有意义，并以任何组合方式有意义
- 仅在必要时固定标题到位置（减少优化）
- 至少包含一个以关键词为中心的标题
- 至少包含一个以利益为中心的标题
- 至少包含一个CTA标题

### Meta Ads（Facebook/Instagram）

| 元素 | 限制 | 备注 |
|-------|-------|------|
| 主要文本 | 125个字符可见（最多2,200） | 前置钩子 |
| 标题 | 推荐为40个字符 | 图片下方 |
| 描述 | 推荐为30个字符 | 标题下方 |
| URL显示链接 | 40个字符 | 可选 |

### LinkedIn Ads

| 元素 | 限制 | 备注 |
|-------|-------|------|
| 介绍文本 | 推荐为150个字符（最多600） | 图片上方 |
| 标题 | 推荐为70个字符（最多200） | 图片下方 |
| 描述 | 推荐为100个字符（最多300） | 在某些位置显示 |

### TikTok Ads

| 元素 | 限制 | 备注 |
|-------|-------|------|
| 广告文本 | 推荐为80个字符（最多100） | 视频上方 |
| 显示名称 | 40个字符 | 品牌名称 |

### Twitter/X Ads

| 元素 | 限制 | 备注 |
|-------|-------|------|
| 推文文本 | 280个字符 | 广告文本 |
| 标题 | 70个字符 | 卡片标题 |
| 描述 | 200个字符 | 卡片描述 |

有关详细规格和格式变体，请参阅 [references/platform-specs.md](references/platform-specs.md)。

## 生成广告视觉效果

**要决定*下一步制作哪种格式***（在简要任何特定广告之前），请参考Meta创意格式分类法 [references/meta-creative-formats.md](references/meta-creative-formats.md)——一个按一个问题排序的优先级S→F目录，约51种格式：它是*独角兽扩展器*（能穿透冷的新受众）还是*配角*（仅在漏斗中期转化）？以基于角色的Andromeda背景信息（为什么创作者主导的格式位居前列）、S级要点（创始人内容、合作广告、VSL）、A级基准和明确的F级降级（新闻稿、播客、伪装原生应用）领先。使用它来选择格式并构建组合；制作细节在静态/视频参考中。一旦广告上线，有关账户级的淘汰/保留/扩展计算，请交叉参考 `ads` 技能的 [meta-decision-system.md](../../ads/references/meta-decision-system.md)。

**对于静态广告结构**，使用 [references/static-ad-templates.md](references/static-ad-templates.md) 中的模板库——布局框架（Us vs. Them、Stat Callout、Review Card、Before/After、Founder Message、FAQ Card、Grid Static、Callout等）与文本槽、DTC和SaaS示例，以及每个概念输出格式。每个模板都带有**等级（S–F）**和**漏斗角色**（独角兽冷扩展器 vs. 漏斗中期支持者），以便你首先选择正确的模板。循环使用模板，而不是集中在最喜欢的模板上——但向S/A级倾斜，当目标是冷的新受众覆盖时。

**对于iOS原生揭示视频广告**——iMessage聊天揭示（脚本线程逐泡展开：截图钩子→朋友问“这是什么应用？”→品牌+促销码揭示→结束卡片）、ChatGPT揭示（打字问题→流式回答）、Apple Notes揭示（实时打字的忏悔笔记）和AirDrop揭示（一个传入的分享，接受点击是揭示）——请参阅 [references/imessage-video-ads.md](references/imessage-video-ads.md) 以选择表面、六个概念角度、脚本和节奏规则、制作路线（现成、Playwright + ffmpeg管道、Remotion）、销售幻觉的工艺细节，以及戏剧化对话的基础/合规规则（虚构AI回答最严格）。

**对于无面目的动作风格视频广告**——完全生成的15–45秒概念/解释视频（风格海报静态→图像到视频“活着”的运动→TTS旁白→单词计时字幕；每个成品视频约3–6美元和~15分钟）——请参阅 [references/motion-video-ads.md](references/motion-video-ads.md) 以获取提供者无关的管道、一个包含填充提示公式的九风格视觉库——五种有特色的样式（丝网版画拼贴、平面矢量解释、纸艺场景、波普艺术漫画、粘土动画）加上四种品牌灵活的符号驱动风格（单线编辑、瑞士排版、线光、双色调丝网版画）由品牌槽合同驱动（FIELD / INK / ACCENT / TYPE FEEL）——运动提示公式，以及辛苦挣来的QC陷阱（制作者之手入侵、最后两秒漂移、字幕/标签碰撞、TTS/耳语声音相似）。

**规模化生产的推荐工作流程：**
1. 使用AI工具生成英雄创意（探索性、高质量）
2. 基于获胜模式构建Remotion模板
3. 使用数据源批量生成Remotion变体
4. 迭代——AI用于新角度，Remotion用于规模化

## 生成广告文案

### 第1步：定义你的角度

在撰写单个标题之前，建立3-5个不同的**角度**——人们点击的不同原因。每个角度都应该触及不同的动机。

**常见角度类别：**

| 类别 | 示例角度 |
|------|----------|
| 痛点 | "停止在X上浪费时间" |
| 结果 | "在Z天内实现Y" |
| 社会证明 | "加入10,000多个团队..." |
| 好奇心 | "顶级公司使用的X秘密" |
| 比较 | "不像X，我们做Y" |
| 紧迫性 | "限时：免费获得X" |
| 身份 | "专为[特定角色/类型]设计" |
| 反传统 | "为什么[常见做法]不起作用" |

### 第2步：按角度生成变体

对于每个角度，生成多个变体。变化：
- **词语选择** — 同义词、主动语态vs.被动语态
- **具体性** — 数字vs.一般声明
- **语气** — 直接vs.疑问句vs.命令句
- **结构** — 短暂冲击vs.完整利益声明

### 第3步：验证规格

在提交前，检查每段创意是否符合平台的字符限制。标记任何超出限制的内容，并提供修剪后的替代方案。

### 第4步：为上传组织

以结构化格式呈现创意，该格式映射到广告平台的上传要求。

## 基于绩效数据迭代

当用户提供绩效数据时，请遵循此流程：

### 第1步：分析获胜者

查看表现最佳的创意（按点击率、转化率或ROAS——询问哪个指标最重要），并识别：

- **获胜主题** — 顶级表现者中出现的主题或痛点是什么？
- **获胜结构** — 提问？陈述？命令？数字？
- **获胜词语模式** — 重复出现的特定词语或短语是什么？
- **字符利用率** — 顶级表现者是较短还是较长？

### 第2步：分析失败者

查看表现最差的创意，并识别：

- **未能引起共鸣的主题** — 哪些角度不起作用？
- **低表现者中的常见模式** — 太泛？太长？语气错误？

### 第3步：生成新变体

创建新的创意，该创意：
- **加倍投入** 在获胜主题上，用新鲜措辞
- **扩展** 获胜角度到新变体
- **测试** 1-2个尚未探索的新角度
- **避免** 在表现不佳者中发现的模式

### 第4步：记录迭代

跟踪学到的内容和正在测试的内容：

```
## 迭代日志
- 轮次：[数字]
- 日期：[日期]
- 顶级表现者：[带指标的列表]
- 获胜模式：[摘要]
- 新变体：[标题数量] 头衔，[数量] 描述
- 正在测试的新角度：[列表]
- 已退役的角度：[列表]
```

## 质量标准

### 点击率高的标题

**强标题：**
- 具体性（“将报告时间缩短75%”）优于模糊性（“节省时间”）
- 利益（“更快地部署代码”）优于功能（“CI/CD管道”）
- 主动语态（“自动化你的报告”）优于被动语态（“报告被自动化”）
- 在可能的情况下包含数字（“3倍快”，“5分钟内”，“10,000多个团队”）

**避免：**
- 客户不认识的行话
- 没有具体性的声明（“最佳”，“领先”，“顶级”）
- 全大写或过多的标点符号
- 无法兑现着陆页承诺的点击诱饵

### 转化率高的描述

描述应补充标题，而不是重复它们。使用描述来：
- 添加证明点（数字、客户评价、奖项）
- 处理反对意见（“无需信用卡”，“永远免费为小团队”）
- 强化CTA（“今天开始免费试用”）
- 在真实紧迫情况下添加紧迫性（“仅限前500名注册”）

## 输出格式

### 标准输出

按角度组织，并显示字符计数：

```
## 角度：[痛点——手动报告]

### 标题（30字符最大）
1. "停止手动构建报告" (29)
2. "自动化你的每周报告" (28)
3. "报告在5分钟内完成，而不是5小时" (31) <- 超出限制，修剪如下
   -> "报告在5分钟内完成，而不是5小时" (27)

### 描述（90字符最大）
1. "营销团队通过自动化报告每周节省10多个小时。免费开始。" (73)
2. "连接你的数据源一次。自动化报告永远。无需代码。" (80)
```

### 批量CSV输出

在规模化生成（10个以上变体）时，提供CSV格式以直接上传：

```csv
headline_1,headline_2,headline_3,description_1,description_2,platform
"停止手动报告","自动化在5分钟内","加入10K+团队","节省10+小时/周在报告上。免费开始.","连接数据源一次。报告永远。无需代码","google_ads"
```

### 静态批次输出（模式3）

对于规模化静态批次，保存到日期文件夹，并附带索引：

```
outputs/YYYY-MM-DD/
  INDEX.md        # 每个概念：模板类型+基础来源，2分钟内可扫描
  concepts/       # 每个md文件一个概念：标题，正文，视觉描述，图像提示，基础
  images/         # 如果配置了图像工具，则生成的图像
```

每个概念格式在 [references/static-ad-templates.md](references/static-ad-templates.md) 中定义。支持的人工作流程：打开文件夹，扫描INDEX.md，选择测试5-10个最佳——从50个概念中选择5个胜过从10个中选择5个。

### 创意审查页面（客户/利益相关者批准）

当需要其他人（客户、合作伙伴、利益相关者）审查并选择时——生产一个**创意审查页面**：一个自包含的HTML工件，将每个概念呈现为在馈送平台中的模拟（Instagram/Facebook，带白名单-手柄切换），将轮播分解为标记的逐帧故事板，让他们切换标题/文案变体，并披露其基于真实资产的内容。它是INDEX.md的视觉升级——通过一个链接而不是阅读markdown做出决策。模板在 [assets/creative-review-template.html](assets/creative-review-template.html) 中提供（一个文件，无需构建，可托管在任何地方）；从你的生成概念填充其 `DATA` 对象。完整数据模型、基础规则（披露块是必需的），以及[references/creative-review-page.md](references/creative-review-page.md) 中的交付。

## 批量生成工作流程

对于大规模创意生产（Anthropic的增长团队每个周期生成100多个变体）：

### 1. 分解为子任务
- **标题生成** — 专注于点击率
- **描述生成** — 专注于转化率
- **主要文本生成** — 专注于参与度（Meta/LinkedIn）

### 2. 分波次生成
- 波次1：核心角度（3-5个角度，每个5个变体）
- 波次2：在两个最佳角度上扩展变体
- 波次3：野生卡角度（反传统、情感、具体）

### 3. 质量过滤器
- 移除任何超出字符限制的内容
- 移除重复或接近重复的内容
- 标记任何可能违反平台政策的内容
- 确保标题/描述组合在一起有意义

## 常见错误

- **撰写只有一起工作才能有效的标题** — RSA标题会随机组合
- **忽略字符限制** — 平台会无警告地截断
- **所有变体听起来都一样** — 变化角度，而不仅仅是词语选择
- **没有CTA标题** — RSAs需要以行动为导向的标题来驱动点击；至少包含2-3个CTA标题
- **通用描述** — “了解更多关于我们的解决方案”浪费了插槽
- **没有数据就迭代** — 直觉不如指标可靠
- **没有基础就生成** — 无基础的创意读起来像其他所有广告一样；首先向技能提供获胜广告、评论和评论
- **跳过评论输入** — 广告评论包含客户自己提出的反对意见和角度；这些通常转化效果最好
- **一次测试太多东西** — 每个测试周期改变一个变量
- **过早退役创意** — 允许1,000多个印象后才能判断
