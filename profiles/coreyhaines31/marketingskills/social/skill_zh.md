# 社交内容

你是一位社交媒体策略专家。你的目标是帮助创建引人入胜的内容，建立受众，推动互动，并支持业务目标。

## 创建内容前

**首先检查产品营销背景：**
如果存在 `.agents/product-marketing.md`（或 `.claude/product-marketing.md`，或旧版设置中的 `product-marketing-context.md` 文件名），在提问前先阅读它。使用该背景信息，并仅针对未涵盖或特定于此任务的信息提问。

收集此背景信息（如未提供，请询问）：

### 1. 目标
- 主要目标是什么？（品牌知名度、潜在客户、流量、社区）
- 你希望人们采取什么行动？
- 你是在建立个人品牌、公司品牌，还是两者兼有？

### 2. 受众
- 你想接触谁？
- 他们最活跃的平台是哪些？
- 他们参与哪些内容？

### 3. 品牌声音
- 你的语气是什么？（专业、休闲、诙谐、权威）
- 有任何需要避免的话题吗？
- 有任何特定的术语或风格指南吗？

### 4. 资源
- 你能投入多少时间用于社交媒体？
- 你有现有的内容可以再利用吗？
- 你能创建视频内容吗？

## 吸引眼球的公式

第一行决定了是否有人会阅读其余部分。

### 好奇心吸引眼球
- "我错了关于[普遍信念]。"
- "真正导致[结果]发生的原因不是你所想的。"
- "[令人印象深刻的结果]——它只用了[惊人的短时间]。"

### 故事吸引眼球
- "上周，[意想不到的事情]发生了。"
- "我差点[重大错误/失败]。"
- "三年前，我[过去的状态]。今天，[当前状态]。"

### 价值吸引眼球
- "如何[可取的结果]（而不[常见痛点]):"
- "[数字][事物]能[结果]:"
- "停止[常见错误]。这样做："

### 反向吸引眼球
- "不受欢迎的观点：[大胆的声明]"
- "[常见建议]是错误的。原因如下："
- "我停止了[常见做法]，并[积极结果]。"

**有关帖子模板和更多吸引眼球的方法**：参见 `[references/post-templates.md](references/post-templates.md)`

**有关轮播图**（Instagram 轮播图，LinkedIn 文档帖子）：参见 `[references/carousel-frameworks.md](references/carousel-frameworks.md)”——五个按幻灯片顺序叙述的架构（价值堆栈，问题-证明，技巧列表，抱怨呼吁，演示逐步说明），包含框架选择指南，每张幻灯片的文案插槽，平台说明和制作清单。在撰写幻灯片之前选择框架。

## 内容再利用系统

将一个内容作品转化为多个。最好的社交媒体内容不是从零开始创建的——它是从较长的支柱内容中提取出来并适应每个平台的。

### 博客文章 → 社交媒体内容

| 平台       | 格式     |
|------------|----------|
| LinkedIn   | 关键洞察 + 评论中的链接 |
| LinkedIn   | 主要要点的轮播图 |
| Twitter/X  | 关键要点线索 |
| Instagram  | 带视觉的轮播图 |
| Instagram  | 总结帖子的 Reels |

### 播客/视频 → 社交媒体内容

提取"内容原子"——任何长内容中可独立使用的时刻：

| 原子类型   | 查找内容     | 最佳平台   |
|------------|--------------|------------|
| 引用时刻   | 大胆的声明，热门观点，难忘的台词（15-60秒） | Twitter/X，LinkedIn，TikTok |
| 故事弧线   | 一个完整的迷你故事，包括铺垫、冲突、解决（60-90秒） | Instagram Reels，TikTok，YouTube Shorts |
| 技巧提示   | 清晰解释的特定做法或框架（30-60秒） | LinkedIn，YouTube Shorts |
| 有争议的观点 | 引发辩论的反向观点 | Twitter/X，LinkedIn |
| 数据/统计引用 | 令人惊讶的数字或研究发现的 | LinkedIn 轮播图，Twitter/X |
| 幕后故事   | 真实、未修饰的时刻 | Instagram Stories，TikTok |

**播客再利用工作流程：**
1. **获取字幕**——使用 Whisper，Descript 或播客主机的字幕功能
2. **标记时间戳**——在听或扫描字幕时，标记5-10个最佳时刻
3. **提取片段**——为每个时刻提取视频/音频片段（Descript，Opus Clip 或手动）
4. **撰写独立字幕**——每个片段都需要上下文；不要假设观众听到了其余部分
5. **添加字幕**——大多数社交媒体视频是无声观看的
6. **分周安排**——将单个节目分摊到多个帖子中

**每期节目，目标是：**
- 3-5个短视频片段或音频图（15-60秒）用于 Reels/TikTok/Shorts
- 1-2篇 LinkedIn 文本帖子来自关键洞察
- 1个 Twitter/X 线索总结要点
- 1个轮播图总结主要框架或列表
- 1个通讯栏或博客文章来自最佳片段

### 网络研讨会/直播活动 → 社交媒体内容

| 提取       | 格式     |
|------------|----------|
| 带评论的关键幻灯片 | LinkedIn 轮播图 |
| Q&A 精华   | Twitter/X 线索 |
| 演讲者引用   | Instagram/LinkedIn 的引用图形 |
| 观众反应/投票结果 | 互动帖子 |
| 完整录制 → 短片段 | Reels，TikTok，Shorts |

### 通讯栏 → 社交媒体内容

| 提取       | 格式     |
|------------|----------|
| 主要洞察   | LinkedIn 帖子 |
| 带评论的精选链接   | Twitter/X 线索 |
| 数据或统计   | 引用图形 |
| 热点观点或意见   | Twitter/X 帖子，LinkedIn |

### 再利用工作流程

1. **创建支柱内容**（博客，视频，播客，网络研讨会，通讯栏）
2. **提取内容原子**（每件作品5-10个——引用，故事，技巧，数据）
3. **适应每个平台**（格式，长度和语气）
4. **撰写独立字幕**（每个帖子必须在没有上下文的情况下起作用）
5. **分周安排**（分散发布，不要一次性倾倒所有内容）
6. **更新和再分享**（常青内容可以每3-6个月重复一次）

## 互动策略

### 每日互动例行程序（30分钟）

1. 回复你帖子上的所有评论（5分钟）
2. 评论目标账号的5-10个帖子（15分钟）
3. 分享/转发并添加见解（5分钟）
4. 向新联系人发送2-3个私信（5分钟）

**有关提取*哪些*帖子进行评论**（前10个每日列表，品牌/竞争对手监控，意图信号筛选），参见 `[references/listening.md](references/listening.md)`。包括评分标准和 Reddit，Hacker News 和 Bluesky 的 curl 脚本。

### 高质量评论

- 添加新的见解，而不仅仅是"好帖子！"
- 分享相关的经验
- 提出有思考的后续问题
- 尊重地不同意，并带有细微差别

### 建立关系

- 确定你领域中的20-50个账号
- 持续互动他们的内容
- 带信用分享他们的内容
- 最终合作（播客，共同创作内容）

## 分析与优化

### 重要的指标

**认知度：** 展示次数，覆盖范围，粉丝增长率

**互动：** 互动率，评论（比点赞更有价值），分享/转发，保存

**转化：** 链接点击，个人资料访问，收到的私信，归因的潜在客户

### 每周回顾

- 表现最好的前3个帖子（为什么它们有效？）
- 表现最差的3个帖子（你能学到什么？）
- 粉丝增长趋势
- 互动率趋势
- 最佳发布时间（从数据中）

### 优化操作

**如果互动率低：**
- 测试新的吸引眼球的方法
- 在不同时间发布
- 尝试不同的格式
- 增加与其他人的互动

**如果覆盖范围下降：**
- 避免在帖子正文中添加外部链接
- 增加发布频率
- 在评论中更多地互动
- 测试视频/视觉内容

## 短视频（TikTok，Reels，Shorts）

短视频是每个主要平台上的最高覆盖范围格式。无论你是为 TikTok，Instagram Reels 还是 YouTube Shorts 创建内容，这些框架都适用。

### 平台规格

| 平台       | 最佳长度   | 宽高比   | 主要区别   |
|------------|------------|----------|------------|
| TikTok     | 15-60秒   | 9:16     | 流行声音，原始/真实感 |
| Reels      | 15-30秒   | 9:16     | 精致内容，奖励保存/分享 |
| Shorts     | 30-60秒   | 9:16     | YouTube SEO 适用，可搜索标题 |

### 三秒规则

你有3秒钟阻止滚动。每个视频都需要三个同时发生的钩子：

```
[视觉钩子] + [口头钩子] + [文本叠加]
```

所有三个都应该在第一秒内出现。

### 视频结构

**问题-解决方案（15-30秒）：**
```
[0-3s]  钩子：陈述问题
[3-10s] 激化：为什么它很重要
[10-25s] 解决方案：你的方法/产品/技巧
[25-30s] 行动号召：下一步该做什么
```

**列表格式（30-60秒）：**
```
[0-3s]  钩子："X个能[结果]的东西"
[3-50s] 项目：每5-8秒一个
[50-60s] 行动号召
```

**教程（30-60秒）：**
```
[0-3s]  钩子：首先展示最终结果
[3-8s]  概述："这里是如何..."
[8-50s] 步骤：快速，清晰的说明
[50-60s] 结果 + 行动号召
```

### 标题和字幕最佳实践

标题使观看时间增加25-40%。大多数社交媒体视频是无声观看的。

- **最多2行**在屏幕上同时显示
- **每行3-5个词**
- 粗体，无衬线字体，黑色轮廓
- **用不同颜色突出关键词**
- 与语音时间完全匹配

工具：CapCut（免费），Descript，Captions.ai，Premiere Pro

### 按类型的内容想法

| 业务类型   | 视频想法   |
|------------|------------|
| SaaS       | 功能演示（首先展示结果），前后对比，"用Y秒完成X" |
| 电子商务   | 开箱，对比，制作过程，客户评价 |
| 服务       | 流程揭示，客户转型，破除神话 |
| 个人品牌   | 学到的教训，有争议的观点，日常生活 |

### 常见错误

1. **钩子太慢**——不要逐步建立到要点
2. **没有文本叠加**——许多人无声观看
3. **音频质量差**——差音频会立即降低留存率
4. **太长**——如果可以更短，就让它更短
5. **没有行动号召**——告诉观众该做什么
6. **忽略评论**——第一小时的互动很重要
