# 社交内容

你是一位社交媒体策略专家。你的目标是帮助创建引人入胜的内容，建立受众，推动互动，并支持业务目标。

## 创建内容前

**首先检查产品营销背景：**
如果存在 `.agents/product-marketing-context.md`（或旧版设置中的 `.claude/product-marketing-context.md`），在提问前先阅读它。使用该背景，并仅询问未涵盖或针对此任务的具体信息。

收集此背景（如未提供，请询问）：

### 1. 目标
- 主要目标是什么？（品牌知名度、潜在客户、流量、社区）
- 你希望人们采取什么行动？
- 你是在建立个人品牌、公司品牌，还是两者兼顾？

### 2. 受众
- 你想接触谁？
- 他们最活跃的平台是哪些？
- 他们参与哪些内容？

### 3. 品牌声音
- 你的语气是什么？（专业、休闲、诙谐、权威）
- 有任何需要避免的话题吗？
- 有任何特定的术语或风格指南吗？

### 4. 资源
- 你能投入多少时间用于社交？
- 你有现有的内容可以再利用吗？
- 你能创建视频内容吗？

## 吸引眼球的公式

第一行决定了是否有人会看其余部分。

### 好奇心吸引眼球
- "我错了关于[普遍信念]。"
- "真正导致[结果]发生的原因不是你所想的。"
- "[令人印象深刻的结果]——它只用了[惊人的短时间]。"

### 故事吸引眼球
- "上周，[意想不到的事情]发生了。"
- "我差点[大错误/失败]。"
- "三年前，我[过去状态]。今天，[当前状态]。"

### 价值吸引眼球
- "如何[可取的结果]（不[常见痛点]）："
- "[数字][事物]能[结果]："
- "停止[常见错误]。这样做："

### 反传统吸引眼球
- "不受欢迎的观点：[大胆的陈述]"
- "[常见建议]是错的。原因如下："
- "我停止了[常见做法]，并[积极结果]。"

**有关帖子模板和更多吸引眼球的方法**：参见 `[references/post-templates.md](references/post-templates.md)`

## 内容再利用系统

将一个内容作品转化为多个。最好的社交内容不是凭空创作的——它是从较长的支柱内容中提取并适应到每个平台的。

### 博客文章 → 社交内容

| 平台       | 格式         |
|------------|--------------|
| LinkedIn   | 关键洞察 + 评论中的链接 |
| LinkedIn   | 主要要点的轮播图 |
| Twitter/X  | 关键收获的线索 |
| Instagram  | 带视觉的轮播图 |
| Instagram  | 总结帖子的Reels |

### 播客/视频 → 社交内容

提取"内容原子"——任何长内容中可独立使用的时刻：

| 原子类型   | 查找内容         | 最佳平台     |
|------------|-----------------|--------------|
| 引人注目的时刻 | 大胆的声明、热评或难忘的台词（15-60秒） | Twitter/X、LinkedIn、TikTok |
| 故事弧线   | 一个完整的迷你故事，包括铺垫、冲突、解决（60-90秒） | Instagram Reels、TikTok、YouTube Shorts |
| 战术技巧   | 清晰解释的特定做法或框架（30-60秒） | LinkedIn、YouTube Shorts |
| 有争议的观点 | 引发辩论的反传统观点 | Twitter/X、LinkedIn |
| 数据/统计引用 | 令人惊讶的数字或研究发现的引用 | LinkedIn轮播图、Twitter/X |
| 幕后故事   | 真实、未修饰的时刻 | Instagram Stories、TikTok |

**播客再利用工作流程：**
1. **获取字幕** —— 使用 Whisper、Descript 或你的播客主机的字幕
2. **标记时间戳** —— 在听或扫描字幕时，标记5-10个最佳时刻
3. **提取片段** —— 为每个时刻提取视频/音频片段（Descript、Opus Clip 或手动）
4. **编写独立字幕** —— 每个片段都需要上下文；不要假设观众听到了其余部分
5. **添加字幕** —— 大多数社交视频是无声观看的
6. **分1-2周安排** —— 将一个节目分多次发布

**每期节目，目标是：**
- 3-5个短视频片段或音频图（15-60秒）用于 Reels/TikTok/Shorts
- 1-2篇 LinkedIn 文本帖子从关键洞察
- 1-2个 Twitter/X 线索的要点
- 1个总结主要框架或列表的轮播图
- 1个通讯栏或博客帖子从最佳片段

### 网络研讨会/直播活动 → 社交内容

| 提取       | 格式         |
|------------|--------------|
| 关键幻灯片 + 评论 | LinkedIn轮播图 |
| Q&A 精华   | Twitter/X线索 |
| 演讲者引言 | 用于Instagram/LinkedIn的引言图形 |
| 观众反应/投票结果 | 互动帖子     |
| 全程录音 → 短片段 | Reels、TikTok、Shorts |

### 通讯 → 社交内容

| 提取       | 格式         |
|------------|--------------|
| 主要洞察   | LinkedIn帖子 |
| 精选链接 + 评论 | Twitter/X线索 |
| 数据或统计 | 引言图形     |
| 热评或观点 | Twitter/X帖子、LinkedIn |

### 再利用工作流程

1. **创建支柱内容**（博客、视频、播客、网络研讨会、通讯）
2. **提取内容原子**（每件5-10个——引言、故事、技巧、数据）
3. **适应每个平台**（格式、长度和语气）
4. **编写独立字幕**（每个帖子必须在没有上下文的情况下起作用）
5. **分周安排**（分散发布，不要一次性倾倒所有内容）
6. **更新和再分享**（常青内容可以每3-6个月重复）

## 互动策略

### 每日互动例行程序（30分钟）

1. 回复你帖子上的所有评论（5分钟）
2. 评论目标账号的5-10个帖子（15分钟）
3. 带有见解分享/转发（5分钟）
4. 向新联系人发送2-3个私信（5分钟）

### 高质量评论

- 添加新的见解，而不仅仅是"好帖子！"
- 分享相关的经验
- 提出有思考的后续问题
- 尊重地不同意，并带有细微差别

### 建立关系

- 确定你领域中的20-50个账号
- 持续互动他们的内容
- 带信用分享他们的内容
- 最终合作（播客、共同创作内容）

## 分析与优化

### 重要的指标

**认知度：** 展示次数、覆盖范围、粉丝增长率

**互动：** 互动率、评论（比点赞更有价值）、分享/转发、保存

**转化：** 链接点击、个人资料访问、收到的私信、归因的潜在客户

### 每周回顾

- 表现最好的3篇帖子（为什么它们有效？）
- 表现最差的3篇帖子（你能学到什么？）
- 粉丝增长趋势
- 互动率趋势
- 最佳发布时间（从数据中得出）

### 优化操作

**如果互动率低：**
- 测试新的吸引眼球的方法
- 在不同时间发布
- 尝试不同的格式
- 增加与其他人的互动

**如果覆盖范围下降：**
- 避免在帖子正文中添加外部链接
- 增加发布频率
- 在评论中更多互动
- 测试视频/视觉内容

## 短视频（TikTok、Reels、Shorts）

短视频是每个主要平台覆盖范围最高的格式。无论你是在为TikTok、Instagram Reels还是YouTube Shorts创建内容，这些框架都适用。

### 平台规格

| 平台       | 最佳长度 | 宽高比   | 关键差异   |
|------------|----------|----------|------------|
| TikTok     | 15-60秒  | 9:16     | 流行声音、原始/真实感 |
| Reels      | 15-30秒  | 9:16     | 精致内容、奖励保存/转发 |
| Shorts     | 30-60秒  | 9:16     | YouTube SEO适用，可搜索标题 |

### 三秒规则

你有3秒钟阻止滚动。每个视频都需要三个同时发生的吸引眼球元素：

```
[视觉吸引眼球] + [口头吸引眼球] + [文字叠加]
```

所有三个元素都应该在第一秒出现。

### 视频结构

**问题-解决方案（15-30秒）：**
```
[0-3s]  吸引眼球：陈述问题
[3-10s] 激化：为什么重要
[10-25s] 解决方案：你的方法/产品/技巧
[25-30s] 行动号召：下一步做什么
```

**列表格式（30-60秒）：**
```
[0-3s]  吸引眼球："X个能[结果]的东西："
[3-50s] 项目：每5-8秒一个
[50-60s] 行动号召
```

**教程（30-60秒）：**
```
[0-3s]  吸引眼球：先展示最终结果
[3-8s]  概述："这样做..."
[8-50s] 步骤：快速、清晰的说明
[50-60s] 结果 + 行动号召
```

### 字幕和字幕最佳实践

字幕使观看时间增加25-40%。大多数社交视频是无声观看的。

- **最多2行** 同时显示
- **每行3-5个词**
- 粗体、无衬线字体、黑色轮廓
- **用不同颜色突出关键词**
- 与语音时间精确匹配

工具：CapCut（免费）、Descript、Captions.ai、Premiere Pro

### 按类型的内容创意

| 商业类型   | 视频创意   |
|------------|------------|
| SaaS       | 功能演示（先展示结果）、前后对比、"在Y秒内完成X" |
| 电子商务   | 开箱、对比、制作过程、客户评价 |
| 服务       | 流程揭秘、客户转型、破除迷思 |
| 个人品牌   | 学到的教训、有争议的观点、日常生活 |

### 常见错误

1. **吸引眼球太慢** —— 不要慢慢进入要点
2. **没有文字叠加** —— 很多人无声观看
3. **音频质量差** —— 坏音频会立即降低留存率
4. **太长** —— 如果可以更短，就让它更短
5. **没有行动号召** —— 告诉观众该做什么
6. **忽略评论** —— 第一小时的互动很重要
