## 钩子公式

第一行决定了其他人是否继续阅读。

### 好奇心钩子
- "我关于[常见观念]是错的。"
- "[结果的真正原因]并非你想象的那样。"
- "[显著成果]——而且只用了[出人意料地短的时间]。"

### 故事钩子
- "上周，[意外的事]发生了。"
- "我差点[重大失误/失败]。"
- "3 年前，我是[过去的状态]。今天，是[当前状态]。"

### 价值钩子
- "如何实现[理想结果]（无需[常见痛点]）："
- "[数量][事物]让[结果]实现：："
- "停止[常见错误做法]。改用此方法："

### 逆向思维钩子
- "不受欢迎的观点：[大胆陈述]"
- "[常见建议]是错误的。原因如下："
- "我停止了[常见做法]，并获得了[积极结果]。"

## 内容再创作系统

将一篇内容转化为多篇内容。最好的社交内容并非从零创作——而是从长篇支柱内容中提炼出来，并适配到各平台。

### 博客文章 → 社交内容

| 平台 | 形式 |
|------|------|
| LinkedIn | 核心洞察 + 评论区置顶链接 |
| LinkedIn | 主要观点轮播图 |
| Twitter/X | 关键要点文字串 |
| Instagram | 搭配视觉的轮播图 |
| Instagram | 总结帖的 Reel |

### 播客 / 视频 → 社交内容

提炼"内容原子"——即任何长篇内容中自包含、可独立使用的片段：

| 原子类型 | 查找方向 | 最佳平台 |
|----------|----------|----------|
| 可引用片段 | 大胆主张、犀利观点或令人难忘的语句（15-60 秒） | Twitter/X、LinkedIn、TikTok |
| 故事弧 | 包含铺垫、冲突、解决的小型完整故事（60-90 秒） | Instagram Reels、TikTok、YouTube Shorts |
| 战术技巧 | 清晰讲解的特定操作方法或框架（30-60 秒） | LinkedIn、YouTube Shorts |
| 争议性观点 | 能引发讨论的逆向思维观点 | Twitter/X、LinkedIn |
| 数据/数据亮点 | 令人惊讶的数字或研究结论 | LinkedIn 轮播图、Twitter/X |
| 幕后花絮 | 真实、未经打磨的瞬间 | Instagram Stories、TikTok |

**播客再创作工作流程：**
1. **获取文稿** —— 使用 Whisper、Descript 或播客主平台的转录功能
2. **标记时间戳** —— 边听或边浏览文稿时，标记出 5-10 个最佳片段
3. **提取片段** —— 为每个片段提取视频/音频片段（Descript、Opus Clip 或手动提取）
4. **撰写独立字幕** —— 每个片段都需要上下文；不能默认受众已了解后续内容
5. **添加字幕** —— 大多数社交视频在无声音的情况下播放
6. **在 1-2 周内排期** —— 将单期内容分散为多篇帖子发布

**每期目标产出：**
- 为 Reels/TikTok/Shorts 制作 3-5 个短视频片段或音频摘要（15-60 秒）
- 从关键洞察中生成 1-2 条 LinkedIn 文字帖
- 一条 Twitter/X 文字串总结要点
- 一张总结主要框架或列表的轮播图
- 从最佳片段中提炼 1 个新闻简报章节或博客文章

### 线上研讨会 / 现场活动 → 社交内容

| 提取内容 | 形式 |
|----------|------|
| 带点评的关键幻灯片 | LinkedIn 轮播图 |
| 问答亮点 | Twitter/X 文字串 |
| 讲者引用 | Instagram/LinkedIn 的引语配图 |
| 观众反应/投票结果 | 互动帖 |
| 完整录制 → 短片段 | Reels、TikTok、Shorts |

### 邮件简报 → 社交内容

| 提取内容 | 形式 |
|----------|------|
| 核心洞察 | LinkedIn 帖子 |
| 带点评的精选链接 | Twitter/X 文字串 |
| 数据或关键数据 | 引语配图 |
| 犀利观点或看法 | Twitter/X 帖子、LinkedIn |

### 再创作工作流程

1. **创作支柱内容**（博客、视频、播客、线上研讨会、邮件简报）
2. **提取内容原子**（每篇 5-10 个，包括引语、故事、技巧、数据）
3. **适配各平台**（调整形式、长度和语调）
4. **撰写独立字幕**（每篇帖子必须无需上下文即可独立成立）
5. **在周内排期**（分散发布，避免一次性集中发布）
6. **更新与转发**（常青内容可每 3-6 个月重复发布）

## 互动策略

### 每日互动流程（30 分钟）

1. 回复所有帖子评论（5 分钟）
2. 给目标账号的 5-10 篇内容留言（15 分钟）
3. 转发/再传播并附加见解（5 分钟）
4. 向新联系的人发送 2-3 条私信（5 分钟）

### 优质评论

- 增加新见解，而不仅是"好帖！"
- 分享相关经验
- 提出有深度的追问
- 以有 nuance 的尊重方式提出不同意见

### 建立关系

- 识别同领域 20-50 个账号
- 持续参与其内容互动
- 引用其内容并注明出处
- 逐步进行合作（播客、共创内容等）

## 数据分析与优化

### 关键指标

**认知类：** 展示量、触达、粉丝增长速率

**互动类：** 互动率、评论（价值高于点赞）、转发/再传播、收藏

**转化类：** 链接点击、主页访问、收到的私信、归属的线索

### 每周回顾

- 表现最好的 3 篇帖子（为什么成功？）
- 表现最差的 3 篇帖子（能从中学到什么？）
- 粉丝增长趋势
- 互动率趋势
- 最佳发布时间（基于数据）

### 优化措施

**如果互动率较低：**
- 测试新钩子
- 在不同时间发布
- 尝试不同形式
- 与其他账号互动提升互动量

**如果触达量下降：**
- 避免在帖子正文中使用外部链接
- 增加发布频率
- 在评论中更积极地互动
- 测试视频/视觉内容

## 短视频（TikTok、Reels、Shorts）

短视频是各大平台触达范围最高的形式。以下框架适用于 TikTok、Instagram Reels 或 YouTube Shorts 的创作。

### 平台规格

| 平台 | 最佳时长 | 画面比例 | 关键差异 |
|------|----------|----------|----------|
| TikTok | 15-60 秒 | 9:16 | 热门音效、原生真实感 |
| Reels | 15-30 秒 | 9:16 | 精致内容，奖励收藏/转发 |
| Shorts | 30-60 秒 | 9:16 | 适用 YouTube SEO，标题可搜索 |

### 三秒法则

你有 3 秒时间阻止用户划走。每个视频都需要三个同时生效的钩子：

```
[视觉钩子] + [口头钩子] + [文字叠加]
```

三者都应在前一秒内生效。

### 视频结构

**问题-解决方案（15-30 秒）：**
```
[0-3秒] 钩子：陈述问题
[3-10秒] 强调：为什么重要
[10-25秒] 解决方案：你的方法/产品/技巧
[25-30秒] 行动号召：下一步做什么
```

**列表格式（30-60 秒）：**
```
[0-3秒] 钩子："X 件事实现[结果]"
[3-50秒] 条目：每 5-8 秒一项
[50-60秒] 行动号召
```

**教程（30-60 秒）：**
```
[0-3秒] 钩子：先展示最终结果
[3-8秒] 概述："以下是如何操作..."
[8-50秒] 步骤：快速、清晰的说明
[50-60秒] 结果 + 行动号召
```

### 字幕与字幕文案最佳实践

字幕可提升观看时长 25-40%。大多数社交视频在无声音的情况下播放。

- **屏幕上同时最多 2 行**
- **每行 3-5 个词**
- 粗体、无衬线字体，带黑色描边
- **用不同颜色高亮关键词**
- 与说话内容严格匹配时间

工具：CapCut（免费）、Descript、Captions.ai、Premiere Pro

### 按类型的内容创意

| 业务类型 | 视频创意 |
|----------|----------|
| SaaS | 功能演示（先展示结果）、前后对比、"我用 Y 秒完成 X" |
| 电商 | 开箱、对比、制作过程、客户评价 |
| 服务类 | 流程揭秘、客户转化、打假 |
| 个人品牌 | 经验教训、争议性观点、一天记录 |

### 常见错误

1. **钩子太慢** —— 不要铺垫到点
2. **缺少文字叠加** —— 很多人无声音播放
3. **音频质量差** —— 差音频会立刻导致留存下降
4. **过长** —— 如果可以更短，就做得更短
5. **缺少行动号召** —— 告诉观众下一步做什么
6. **忽视评论** —— 首小时的互动很重要

### 价值钩子
- "如何实现[理想结果]（无需[常见痛点]）："
- "[数量][事物]让[结果]实现：："
- "停止[常见错误做法]。改用此方法："

### 逆向思维钩子
- "不受欢迎的观点：[大胆陈述]"
- "[常见建议]是错误的。原因如下："

## 内容再创作系统

将一篇内容转化为多篇内容。最好的社交内容并非从零创作——而是从长篇支柱内容中提炼出来，并适配到各平台。

### 博客文章 → 社交内容

| 平台 | 形式 |
|------|------|
| LinkedIn | 核心洞察 + 评论区置顶链接 |
| LinkedIn | 主要观点轮播图 |
| Twitter/X | 关键要点文字串 |
| Instagram | 搭配视觉的轮播图 |
| Instagram | 总结帖的 Reel |

### 播客 / 视频 → 社交内容

提炼"内容原子"——即任何长篇内容中自包含、可独立使用的片段：

| 原子类型 | 查找方向 | 最佳平台 |
|----------|----------|----------|
| 可引用片段 | 大胆主张、犀利观点或令人难忘的语句（15-60 秒） | Twitter/X、LinkedIn、TikTok |
| 故事弧 | 包含铺垫、冲突、解决的小型完整故事（60-90 秒） | Instagram Reels、TikTok、YouTube Shorts |
| 战术技巧 | 清晰讲解的特定操作方法或框架（30-60 秒） | LinkedIn、YouTube Shorts |
| 争议性观点 | 能引发讨论的逆向思维观点 | Twitter/X、LinkedIn |
| 数据/数据亮点 | 令人惊讶的数字或研究结论 | LinkedIn 轮播图、Twitter/X |
| 幕后花絮 | 真实、未经打磨的瞬间 | Instagram Stories、TikTok |

**播客再创作工作流程：**
1. **获取文稿** —— 使用 Whisper、Descript 或播客主平台的转录功能
2. **标记时间戳** —— 边听或边浏览文稿时，标记出 5-10 个最佳片段
3. **提取片段** —— 为每个片段提取视频/音频片段（Descript、Opus Clip 或手动提取）
4. **撰写独立字幕** —— 每个片段都需要上下文；不能默认受众已了解后续内容
5. **添加字幕** —— 大多数社交视频在无声音的情况下播放
6. **在 1-2 周内排期** —— 将单期内容分散为多篇帖子发布

**每期目标产出：**
- 为 Reels/TikTok/Shorts 制作 3-5 个短视频片段或音频摘要（15-60 秒）
- 从关键洞察中生成 1-2 条 LinkedIn 文字帖
- 一条 Twitter/X 文字串总结要点
- 一张总结主要框架或列表的轮播图
- 从最佳片段中提炼 1 个新闻简报章节或博客文章

### 线上研讨会 / 现场活动 → 社交内容

| 提取内容 | 形式 |
|----------|------|
| 带点评的关键幻灯片 | LinkedIn 轮播图 |
| 问答亮点 | Twitter/X 文字串 |
| 讲者引用 | Instagram/LinkedIn 的引语配图 |
| 观众反应/投票结果 | 互动帖 |
| 完整录制 → 短片段 | Reels、TikTok、Shorts |

### 邮件简报 → 社交内容

| 提取内容 | 形式 |
|----------|------|
| 核心洞察 | LinkedIn 帖子 |
| 带点评的精选链接 | Twitter/X 文字串 |
| 数据或关键数据 | 引语配图 |
| 犀利观点或看法 | Twitter/X 帖子、LinkedIn |

### 再创作工作流程

1. **创作支柱内容**（博客、视频、播客、线上研讨会、邮件简报）
2. **提取内容原子**（每篇 5-10 个，包括引语、故事、技巧、数据）
3. **适配各平台**（调整形式、长度和语调）
4. **撰写独立字幕**（每篇帖子必须无需上下文即可独立成立）
5. **在周内排期**（分散发布，避免一次性集中发布）
6. **更新与转发**（常青内容可每 3-6 个月重复发布）

## 数据分析与优化

### 关键指标

**认知类：** 展示量、触达、粉丝增长速率

**互动类：** 互动率、评论（价值高于点赞）、转发/再传播、收藏

**转化类：** 链接点击、主页访问、收到的私信、归属的线索

### 每周回顾

- 表现最好的 3 篇帖子（为什么成功？）
- 表现最差的 3 篇帖子（能从中学到什么？）
- 粉丝增长趋势
- 互动率趋势
- 最佳发布时间（基于数据）

### 优化措施

**如果互动率较低：**
- 测试新钩子
- 在不同时间发布
- 尝试不同形式
- 与其他账号互动提升互动量

**如果触达量下降：**
- 避免在帖子正文中使用外部链接
- 增加发布频率
- 在评论中更积极地互动
- 测试视频/视觉内容

## 短视频（TikTok、Reels、Shorts）

短视频是各大平台触达范围最高的形式。以下框架适用于 TikTok、Instagram Reels 或 YouTube Shorts 的创作。

### 平台规格

| 平台 | 最佳时长 | 画面比例 | 关键差异 |
|------|----------|----------|----------|
| TikTok | 15-60 秒 | 9:16 | 热门音效、原生真实感 |
| Reels | 15-30 秒 | 9:16 | 精致内容，奖励收藏/转发 |
| Shorts | 30-60 秒 | 9:16 | 适用 YouTube SEO，标题可搜索 |

### 三秒法则

你有 3 秒时间阻止用户划走。每个视频都需要三个同时生效的钩子：

```
[视觉钩子] + [口头钩子] + [文字叠加]
```

三者都应在前一秒内生效。

### 视频结构

**问题-解决方案（15-30 秒）：**
```
[0-3秒] 钩子：陈述问题
[3-10秒] 强调：为什么重要
[10-25秒] 解决方案：你的方法/产品/技巧
[25-30秒] 行动号召：下一步做什么
```

**列表格式（30-60 秒）：**
```
[0-3秒] 钩子："X 件事实现[结果]"
[3-50秒] 条目：每 5-8 秒一项
[50-60秒] 行动号召
```

**教程（30-60 秒）：**
```
[0-3秒] 钩子：先展示最终结果
[3-8秒] 概述："以下是如何操作..."
[8-50秒] 步骤：快速、清晰的说明
[50-60秒] 结果 + 行动号召
```

### 字幕与字幕文案最佳实践

字幕可提升观看时长 25-40%。大多数社交视频在无声音的情况下播放。

- **屏幕上同时最多 2 行**
- **每行 3-5 个词**
- 粗体、无衬线字体，带黑色描边
- **用不同颜色高亮关键词**
- 与说话内容严格匹配时间

工具：CapCut（免费）、Descript、Captions.ai、Premiere Pro

### 按类型的内容创意

| 业务类型 | 视频创意 |
|----------|----------|
| SaaS | 功能演示（先展示结果）、前后对比、"我用 Y 秒完成 X" |
| 电商 | 开箱、对比、制作过程、客户评价 |
| 服务类 | 流程揭秘、客户转化、打假 |
| 个人品牌 | 经验教训、争议性观点、一天记录 |

### 常见错误

1. **钩子太慢** —— 不要铺垫到点
2. **缺少文字叠加** —— 很多人无声音播放
3. **音频质量差** —— 差音频会立刻导致留存下降
4. **过长** —— 如果可以更短，就做得更短
5. **缺少行动号召** —— 告诉观众下一步做什么
6. **忽视评论** —— 首小时的互动很重要
