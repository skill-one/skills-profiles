## 目的

为任何 SaaS 财务指标提供快速参考，无需深入教学。当你需要快速查找公式、检查基准或提醒决策框架时，使用它。有关详细解释、计算和示例，请参阅相关的深入技能。

这不是一个教学工具——它是一份为速度优化的速查表。扫描、查找、应用。

## 输入

**最佳使用场景：** 你需要的指标——命名它并获取公式、基准和决策背景。
**也很有用：** 你的数据，如果你想在现场应用公式。

在调用本身中提供的任何内容——技能名称后的文本、粘贴的上下文转储或附加的 `ARGUMENTS:` 行——都计为已给出的答案。使用它并跳过它所涵盖的内容；不要重复提问。

**空手而来？那也行。** 询问你所工作的指标类别（收入、留存、效率、资本），然后从此开始扫描。

**示例调用：** `Quick ref: burn multiple — formula, benchmark, and whether 1.7 is bad for Series B.`

## 关键概念

### 指标类别

指标分为四个类别：

1. **收入与增长** — 顶线收入（收入、ARPU、ARPA、MRR/ARR、流失率、NRR、扩张）
2. **单位经济** — 客户级盈利能力（CAC、LTV、回收期、利润率）
3. **资本效率** — 现金管理（烧钱率、续航期、运营支出、净利润）
4. **效率比率** — 增长与盈利能力平衡（40法则、魔法数字）

### 何时使用此技能

**使用此技能时：**
- 你需要一个快速公式或基准
- 你正在准备董事会会议或投资者电话会议
- 你在评估决策时需要检查哪些指标重要
- 你想快速识别红旗

**不使用此技能时：**
- 你需要详细的计算指导（使用 `saas-revenue-growth-metrics` 或 `saas-economics-efficiency-metrics`）
- 你是第一次学习这些指标（从深入技能开始）
- 你需要示例和常见陷阱（在相关技能中涵盖）

## 应用

### 所有指标参考表

| **指标** | **公式** | **衡量内容** | **良好基准** | **红旗** |
|------------|-------------|----------------------|-------------------|--------------|
| **收入** | 销售总额（不含费用） | 赚取的顶线收入 | 年增长率 >20%（因阶段而异） | 收入增长慢于成本 |
| **ARPU** | 总收入 / 总用户数 | 每个用户的收入 | 因模式而异；跟踪趋势 | ARPU 同期下降 |
| **ARPA** | MRR / 活跃账户数 | 每个客户账户的收入 | 中小企业：$100-$1K；中型：$1K-$10K；大型：$10K+ | 高 ARPA + 低 ARPU（未充分利用的座位） |
| **ACV** | 每份合同的年度经常性收入 | 年度化合同价值 | 中小企业：$5K-$25K；中型：$25K-$100K；大型：$100K+ | ACV 下降（无意中转向低端市场） |
| **MRR/ARR** | MRR × 12 = ARR | 可预测的经常性收入 | 增长 + 质量很重要；跟踪组成部分 | 新 MRR 下降而流失率稳定/增长 |
| **流失率** | 失去客户数 / 初始客户数 | 取消的客户百分比 | 月度 <2% 很好，<5% 可以；年度 <10% 很好 | 流失率同期上升 |
| **NRR** | (初始 ARR + 扩张 - 流失 - 收缩) / 初始 ARR × 100 | 收入留存 + 扩张 | >120% 很好；100-120% 好；90-100% 可以 | NRR <100%（基础正在收缩） |
| **扩张收入** | 附加销售 + 横向销售 + 使用增长 | 来自现有客户的额外收入 | 总收入的 20-30% | 扩张 <10% 的 MRR |
| **快速比率** | (新 MRR + 扩张 MRR) / (流失 MRR + 收缩) | 收入增长与损失 | >4 很好；2-4 健康；<2 漏斗 | 快速比率 <2（漏斗） |
| **毛利率** | (收入 - COGS) / 收入 × 100 | 直接成本后的收入百分比 | SaaS：70-85% 好；<60% 令人担忧 | 毛利率 <60% 或下降 |
| **CAC** | 总销售与营销支出 / 新客户数 | 获取一个客户的成本 | 因行业而异：大型企业 $10K+ 可以；中小企业 <$500 | CAC 上升而 LTV 平稳 |
| **LTV** | ARPU × 毛利率百分比 / 流失率 | 一个客户的总收入 | 必须 3 倍 + CAC；因细分而异 | LTV 同期下降 |
| **LTV:CAC** | LTV / CAC | 单位经济效率 | 3:1 健康；<1:1 不可持续；>5:1 未能投资 | LTV:CAC <1.5:1 |
| **回收期** | CAC / (月度 ARPU × 毛利率百分比) | 恢复 CAC 所需的月数 | <12 个月 很好；12-18 个月 可以；>24 个月 令人担忧 | 回收期 >24 个月（现金陷阱） |
| **贡献边际** | (收入 - 所有变动成本) / 收入 × 100 | 变动成本后的真实贡献 | 60-80% 好；SaaS；<40% 令人担忧 | 贡献边际 <40% |
| **烧钱率** | 每月现金支出 - 收入 | 每月消耗的现金 | 早期净烧钱 <$200K 可管理；<$500K 增长 | 净烧钱加速 |
| **续航期** | 现金余额 / 每月净烧钱 | 资金耗尽前的月数 | 12 个月 + 很好；6-12 个月 可以；<6 个月 危机 | 续航期 <6 个月 |
| **运营支出** | 销售与营销 + 研发 + 一般与行政 | 运营业务的成本 | 应该比收入增长慢 | 运营支出比收入增长快 |
| **净利润** | 收入 - 所有费用 | 实际利润/亏损 | 早期为负可以；成熟 10-20%+ 利润率 | 亏损加速而无增长 |
| **40法则** | 收入增长率百分比 + 利润率百分比 | 增长与效率的平衡 | >40 健康；25-40 可以；<25 令人担忧 | 40法则 <25 |
| **魔法数字** | (本季度收入 - 上季度收入) × 4 / 上季度销售与营销 | 销售与营销效率 | >0.75 高效；0.5-0.75 可以；<0.5 需要改进 GTM | 魔法数字 <0.5 |
| **运营杠杆** | 收入增长与运营支出增长 | 扩张效率 | 收入增长 > 运营支出增长 | 运营支出增长快于收入 |
| **毛收入与净收入** | 净收入 = 毛收入 - 折扣 - 退款 - 信用 | 你实际保留的收入 | 退款 <10%；折扣 <20% | 退款 >10%（产品问题） |
| **收入集中度** | 顶级 N 客户 / 总收入 | 对最大客户的依赖 | 顶级客户 <10%；顶级 10 个 <40% | 顶级客户 >25%（生存风险） |
| **收入结构** | 产品/细分收入 / 总收入 | 产品组合构成 | 没有单一产品 >60% 理想 | 单一产品 >80%（缺乏多元化） |
| **队列分析** | 按加入日期分组客户；跟踪行为 | 业务是否改善或恶化 | 最近队列与旧队列相同/更好 | 新队列表现更差 |
| **CAC 按渠道回收** | CAC / 每月贡献（按渠道） | 按收购渠道的回收 | 比较不同渠道 | 一个渠道远差于其他渠道 |
| **毛利润回收** | CAC / (月度 ARPU × 毛利率百分比) | 使用实际利润的回收 | 通常 1.5-2 倍简单回收 | 使用利润 >36 个月回收 |
| **单位经济** | 每个单位的收入 - 每个单位的成本 | 每个“单位”的盈利能力 | 需要正贡献 | 负贡献边际 |
| **细分回收** | CAC / 每月贡献（按细分） | 按客户细分的回收 | 比较以分配资源 | 一个细分不盈利 |
| **增量** | 由行动引起的收入 - 基线 | 市场营销/促销的真实影响 | 使用保留测试测量 | 庆祝本来就会发生的收入 |
| **营运资金** | 收入和收款之间的现金时间 | 现金与收入的时间 | 年度预付款 > 月度计费 | 长支付条款导致续航期缩短 |

### 快速决策框架

使用这些框架将指标结合起来，以进行常见的 PM 决策。

#### 框架 1：我们应该开发这个功能吗？

**询问：**
1. **收入影响？** 直接（定价、附加功能）或间接（留存、转化）？
2. **利润率影响？** COGS 是什么？它会稀释利润率吗？
3. **投资回报率？** 收入影响 / 开发成本

**开发如果：**
- 投资回报率第一年 >3 倍（直接货币化），OR
- LTV 影响大于开发成本的 10 倍（留存），OR
- 战略价值超过短期投资回报率

**不开发如果：**
- 即使在最乐观的采用情况下，贡献边际为负
- 回收期超过平均客户生命周期

**需要检查的指标：** 收入、毛利率、LTV、贡献边际

---

#### 框架 2：我们应该扩展这个获取渠道吗？

**询问：**
1. **单位经济？** CAC、LTV、LTV:CAC 比率
2. **现金效率？** 回收期
3. **客户质量？** 队列留存、按渠道的 NRR
4. **可扩展性？** 魔法数字、可服务量

**扩展如果：**
- LTV:CAC >3:1 AND
- 回收期 <18 个月 AND
- 客户质量满足/超过其他渠道 AND
- 魔法数字 >0.75

**不扩展如果：**
- LTV:CAC <1.5:1 AND
- 没有明确的改进路径

**需要检查的指标：** CAC、LTV、LTV:CAC、回收期、NRR、魔法数字

---

#### 框架 3：我们应该改变定价吗？

**询问：**
1. **ARPU/ARPA 影响？** 每个客户的收入会增加吗？
2. **转化影响？** 帮助或损害免费试用到付费转化？
3. **流失影响？** 创造流失风险或减少它？
4. **NRR 影响？** 启用扩张或创造收缩？

**实施如果：**
- 在流失风险后净收入影响为正
- 可以在广泛推出前对细分进行测试

**不改变如果：**
- 高流失风险而没有抵消的扩张
- 在承诺之前无法测试假设

**需要检查的指标：** ARPU、ARPA、流失率、NRR、CAC 回收期

---

#### 框架 4：业务是否健康？

**按阶段检查：**

**早期阶段（收入 < $10M ARR）：**
- 年增长率 >50%
- LTV:CAC >3:1
- 毛利率 >70%
- 续航期 >12 个月

**增长阶段（$10M-$50M ARR）：**
- 年增长率 >40%
- NRR >100%
- 40法则 >40
- 魔法数字 >0.75

**扩展阶段（收入 >$50M ARR）：**
- 年增长率 >25%
- NRR >110%
- 40法则 >40
- 利润率 >10%

**需要检查的指标：** 收入增长、NRR、LTV:CAC、40法则、魔法数字、毛利率

### 按类别划分的红旗

#### 收入与增长红旗
| **红旗** | **含义** | **行动** |
|--------------|-------------------|------------|
| 流失率同期上升 | 产品市场契合度下降 | 停止扩大获取；优先解决留存问题 |
| NRR <100% | 基础正在收缩 | 优先解决扩张或减少流失；再扩大 |
| 收入流失 > 标识流失 | 失去大客户 | 调查为什么高价值客户离开 |
| 快速比率 <2 | 漏斗（勉强弥补损失） | 优先解决留存；再扩大获取 |
| 扩张收入 <10% 的 MRR | 没有追加销售/交叉销售引擎 | 建立扩张路径 |
| 收入前 10 个客户集中度 >50% | 生存依赖风险 | 多元化客户群 |

#### 单位经济红旗
| **红旗** | **含义** | **行动** |
|--------------|-------------------|------------|
| LTV:CAC <1.5:1 | 以亏损购买收入 | 在扩大之前减少 CAC 或提高 LTV |
| 回收期 >24 个月 | 现金陷阱（长期现金回收） | 谈判年度预付款或减少 CAC |
| 毛利率 <60% | 每美元低盈利能力 | 提高价格或降低 COGS |
| CAC 上升而 LTV 平稳 | 单位经济恶化 | 优化转化或缩短销售周期 |
| 贡献边际 <40% | 变动成本后不盈利 | 削减变动成本或提高价格 |

#### 资本效率红旗
| **红旗** | **含义** | **行动** |
|--------------|-------------------|------------|
| 续航期 <6 个月 | 生存危机 | 立即融资或削减烧钱 |
| 净烧钱加速而无收入增长 | 烧钱速度比结果快 | 削减成本或提高收入紧迫性 |
| 运营支出比收入增长快 | 负运营杠杆 | 暂停招聘；优化支出 |
| 40法则 <25 | 烧钱而无增长 | 提高增长或削减至盈利 |
| 魔法数字 <0.5 | GTM 引擎损坏 | 在扩大支出之前修复 GTM 效率 |

### 何时使用哪个指标

**优先考虑功能：**
- 收入影响 → 收入、ARPU、扩张收入
- 利润率影响 → 毛利率、贡献边际
- 投资回报率 → LTV 影响、开发成本

**评估渠道：**
- 获取成本 → CAC、按渠道的 CAC
- 客户价值 → LTV、按渠道的 NRR
- 回收期 → 回收期、按渠道的 CAC 回收期
- 可扩展性 → 魔法数字

**定价决策：**
- 货币化 → ARPU、ARPA、ACV
- 影响 → 流失率、NRR、扩张收入
- 效率 → CAC 回收期（定价变化会影响它吗？）

**业务健康：**
- 增长 → 收入增长、MRR/ARR 增长
- 留存 → 流失率、NRR、快速比率
- 经济 → LTV:CAC、回收期、毛利率
- 效率 → 40法则、魔法数字、运营杠杆
- 生存 → 烧钱率、续航期

**董事会/投资者报告：**
- 关键指标：ARR、收入增长率、NRR、LTV:CAC、40法则、魔法数字、烧钱率、续航期
- 阶段特定：早期阶段强调增长 + 单位经济；增长阶段强调 40法则 + 魔法数字；扩展阶段强调盈利能力 + 效率

## 示例

### 示例 1：功能投资合理性检查

你正在决定是否开发一个高级导出功能。

1. 使用框架 1（我们应该开发这个功能吗？）
2. 拉取基线指标：ARPU、毛利率、LTV、贡献边际
3. 模拟乐观、基准和下行采用情况
4. 如果下行情况下贡献边际为负，则拒绝

快速输出：
- 基准投资回报率：3.8 倍
- 贡献边际影响：+4 点
- 决策：立即开发，90 天后检查流失率和扩张

### 示例 2：渠道扩展决策

付费社交媒体产生了许多注册用户，但留存率较弱。

1. 使用框架 2（我们应该扩展这个获取渠道吗？）
2. 检查 CAC、LTV:CAC、回收期和按渠道的 NRR
3. 与表现最好的渠道比较，而不是公司平均水平

快速输出：
- LTV:CAC：1.6:1
- 回收期：26 个月
- NRR：88%
- 决策：不扩展；限制支出并运行有针对性的优化测试

## 常见陷阱

- 使用混合公司平均值而不是队列或渠道级指标
- 当快速比率较弱且留存正在恶化时扩展获取
- 将高 LTV:CAC 视为足够，而未检查回收期和续航期影响
- 仅基于 ARPU 提升而提高价格，而未建模流失和收缩
- 比较不匹配公司阶段或商业模式基准
- 跟踪许多指标而没有明确的决策问题
