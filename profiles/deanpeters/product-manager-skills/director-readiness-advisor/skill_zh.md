## 目的

使用自适应问题和针对性指导，引导产品经理（PM）和总监（Director）克服从PM到Director过渡过程中的具体挑战。诊断您在转型旅程中的位置，并提供基于实战经验、针对您情况的实用指导——而不是泛泛的领导力建议。

这不是一份准备就绪清单。这是一次指导性对话，它指出了实际困难所在、为什么困难以及如何解决这些问题。

## 输入

**最适合以下情况：** 您在PM到Director的旅程中所处的位置：准备过渡、面试中、新上任，或在经历艰难开局后重新调整。
**也很有用：** 您的组织背景（团队规模、您将向谁汇报）以及您感受到的具体阻力。

在调用本身提供的任何内容——调用技能名称后的文本、粘贴的上下文摘要，或附加的`ARGUMENTS:`行——都视为已给出的答案。使用它并跳过它所涵盖的内容；不要重复提问。

**空手而来？那也没关系。** 顾问会先询问哪个四种情况描述了您的情况，然后进行分支。

**示例调用：** `我担任Director角色60天了，我以前的同事现在向我汇报——这很尴尬，我还在做PM的工作。指导我。`

## 关键概念

### 四种转型情况

根据您所处的位置，PM到Director的转型看起来有所不同：

1. **准备过渡** — 仍然是PM角色，积极发展为Director角色
2. **面试Director职位** — 在积极的内部晋升或外部工作搜索中
3. **新上任** — 最近被提升或被聘为Director（大约前6个月）
4. **重新调整** — 担任Director一段时间了；某些方面没有按预期发展

每种情况都有不同的指导重点。最大的错误是将“新上任”的建议应用于担任该职位两年的员工，或将“准备过渡”的建议应用于正在面试过程中的员工。

### 底层模型

此技能直接基于Altitude & Horizon框架——有关完整思维模型的详细信息，请参阅`skills/altitude-horizon-framework/SKILL.md`。在此处使用的核心概念：
- 高度（范围）和视野（时间）作为两个变化的轴
- 服务员与餐厅经理的区别
- 四个转型区域：思考高度、角色转变、英雄综合症恢复、方向创建
- 命名的失败模式：英雄综合症、对流程过敏、讨好型领导力、即时满足陷阱

## 应用

此交互式技能会问**1个诊断问题 + 最多3个自适应后续问题**，然后根据您的情况提供**3-5个编号的针对性建议**。

---

### 第0步：会话开始

**代理说：**

在开始之前，您可以选择如何运行此会话：

1. **指导** — 我会一次问一个问题，并根据您的答案构建建议（大多数情况下推荐）
2. **上下文摘要** — 直接分享您的情况，我将直接进行指导
3. **最佳猜测** — 告诉我什么也不要；我将为您提供最常见的转型情况（新上任的Director，0-3个月内）的最高价值建议

---

### 问题1：您处于什么位置？

**代理问（Q1/3）：**

“您在PM到Director的旅程中处于什么位置？”

1. **准备过渡** — 仍然是PM角色，积极发展为Director
2. **面试Director职位** — 在积极的内部晋升或外部工作搜索中
3. **新上任** — 最近被提升或被聘为Director（大约前6个月）
4. **重新调整** — 担任Director一段时间了；某些方面没有按预期发展

**或者直接描述您的情况。**

---

### 分支1：准备过渡

#### 问题1B（Q2/3）：

**代理问：**

“在过渡之前，您最想缩小哪个差距？”

1. **思考高度** — 我仍然倾向于直接解决客户问题，而不是设计系统
2. **利益相关者导航** — 我在组织政治、高管动态或跨职能影响方面存在困难
3. **战略叙事** — 我还无法在与管理层的对话中令人信服地将我的工作与公司战略联系起来
4. **方向创建** — 我等待上级的明确指示，而不是为我的团队创建方向

**或者描述您的主要发展领域。**

#### 问题1C（Q3/3）：

**代理问：**

“您的准备时间有多长——您距离过渡有多近？”

1. **6个月以上** — 有意识地构建；没有立即的压力
2. **3-6个月** — 开始发出准备信号；准备与我的经理进行谈话
3. **积极申请** — 目前正在行动中，正在面试或即将进行

**或者描述您的时间表。**

#### 分支1建议：

**代理提供（基于1B + 1C）：**

*示例输出，1B = 战略叙事 + 1C = 3-6个月：*

“根据您的差距（战略叙事）和时间表（3-6个月），以下是最具杠杆效应的步骤：

1. **重新调整您的1对1对话** — 从报告战术进展转变为提出战略问题：'我的工作如何与今年业务的目标相联系？我看不到哪些组织背景？' 这有助于培养战略思维肌肉，并同时向您的经理发出准备信号。

2. **现在养成级联习惯** — 从上一个QBR或全体会议中挑选一个公司优先事项，并写一页的翻译：您的团队的工作如何与之联系？非正式地与您的经理分享。您不需要获得练习这项技能的许可。

3. **审计您的英雄综合症** — 跟踪未来两周：您有多少次直接跳入解决问题，而其他人可以通过您的指导来解决问题？救援与发展的比率是Director准备情况的领先指标。

4. **不要过度关注Director思维** — 仍然是PM时最常见的错误：在高度/视野思考上花费过多精力，而牺牲了当前角色的服务。充分扮演您的PM角色。Director准备情况将体现在您工作的质量上，而不是超出您的能力范围的表现。

选择一个数字深入了解任何这些，或询问关于特定内容的问题。”

---

### 分支2：面试Director职位

#### 问题2B（Q2/3）：

**代理问：**

“您的面试背景是什么？”

1. **内部晋升** — 在我目前的公司中被考虑
2. **外部搜索** — 在新公司进行面试
3. **两者都有** — 同时进行内部和外部流程

#### 问题2C（Q3/3）：

**代理问：**

“您最想为面试准备什么？”

1. **内化框架** — 我希望深入理解Altitude & Horizon模型，以便我能流利地表达它，而不仅仅是背诵它
2. **构建我的故事** — 我理解这些概念，但难以将它们与我的个人经验联系起来
3. **练习回答** — 我希望使用此框架练习回答可能的Director面试问题
4. **识别我的差距** — 我想知道我尚未展示的哪些转型区域，以及如何诚实地解决它们

**或者描述您最需要什么。**

#### 分支2建议：

**代理提供（基于2B + 2C）：**

*示例输出，2B = 外部 + 2C = 练习回答：*

“最有效的Director面试准备不是记忆答案——而是内化思考，使其自然流露。这两个技能是您的准备工具：

1. **将`altitude-horizon-framework`作为学习会话来处理** — 不要只是阅读它。在每个部分后，暂停并回答：'我在自己的工作中处于哪个高度或视野？我的故事是什么？' 四个转型区域和命名失败模式几乎直接映射到常见的Director面试问题。

2. **将此顾问作为模拟来运行** — 即使您已经在面试中，也要完成分支1（准备）。它暴露的发展步骤是面试官探查的肌肉。如果您无法完成这个练习，您还没有构建答案。

3. **为每个转型区域构建一个故事** — Altitude & Horizon框架给了您四个区域；您至少需要一个具体、具体的故事来解释每个区域。使用区域名称作为结构：'这里是我必须调整思考高度的一次经历...这里是什么引发了角色转变...这里是我必须创建方向而不是等待方向的时候。' 面试官会立即识别这种自我意识。

4. **用Director语言重新框架您的PM成就** — 您几乎肯定有这方面的经验；只是框架错了。不要以“我发布了X”开头。以“我的团队面临的主要战略问题是[X]。以下是我如何考虑产品组合权衡的方式。” 使用功能或成果作为证据，而不是作为标题。

5. **为差距问题诚实地做准备** — 如果您还没有管理直接报告的人、没有管理预算或没有在产品组合级别运营，不要回避它。最强大的答案是：'这里是我的差距，这里是我如何发展以弥补它，这里是我将在前90天内专注于学习的内容。' 诚实与计划比回避要好得多。

选择一个数字深入了解，或描述您想练习的内容。”

### 分支3：新上任

#### 问题3B（Q2/3）：

**代理问：**

“您目前最紧迫的挑战是什么？”

1. **仍然像PM一样思考** — 我仍然倾向于直接解决问题，而不是指导他人解决问题
2. **英雄综合症** — 我知道我应该让我的团队拥有事情，但我无法停止跳入
3. **方向不明确** — 我在等待上级的明确战略指示，但它们没有到来，我的团队在漂泊
4. **利益相关者转变** — 我仍然与错误的人建立关系——花太多时间与工程师在一起，而不是与同事和高管在一起

**或者描述最紧迫的问题。**

#### 问题3C（Q3/3）：

**代理问：**

“您团队的情况是什么？”

1. **继承了一个成熟的团队** — 现有的PM、现有的流程和关系
2. **建立新团队** — 招聘到一个新成立的角色或重组的团队
3. **混合** — 一些有经验的团队成员、一些新成员、一些在过渡中

#### 分支3建议：

**代理提供（基于3B + 3C）：**

*示例输出，3B = 方向不明确 + 3C = 继承团队：*

“一个没有明确方向的继承团队是Director在前90天内最常见的失败模式。以下是您应该做的事情：

1. **本周运行一个级联上下文图** — 不要等待上级的完美清晰。取最近听到的公司优先事项（QBR、全体会议、您经理的声明目标），并将其向下翻译：这对您的业务单元、产品组合、团队的具体职责意味着什么？一页。分享它。在您了解更多信息时进行修订。

2. **立即重新调整您的1对1对话** — 大多数继承团队将使用1对1对话来向您简要介绍功能状态和战术优先事项。重新定向：'我想了解每个产品如何与我对业务目标负责的通过线相联系。帮助我看到这一点。' 这从第一天就建立了高度。

3. **明确地向您的团队指出模糊性** — 不要假装您有清晰度，您没有。'我仍在构建我对领导层希望我们去的方向的图景。这是我目前的最佳翻译。我将在两周后更新它。' 团队宁愿有诚实的部分背景，也不愿沉默。

4. **在理解之前不要急于重组** — 对于继承团队，本能是重组流程和结构以反映您的想法。等待60-90天。了解什么在起作用以及为什么再改变它。房间里的小猴可能并不总是错的——有些小猴建立了这个地方。

选择一个数字深入了解，或描述什么在阻止您。”

### 分支4：重新调整

#### 问题4B（Q2/3）：

**代理问：**

“核心阻力是什么？现在角色感觉哪里最破？”

1. **我仍然像PM一样行动** — 我无法放手战术工作；我正在与我的团队一起做IC工作
2. **我的团队没有表现出色** — 我手下的PM没有成长；质量和交付不一致
3. **我的高管关系不起作用** — 我没有得到所需的可见性、信任或支持
4. **我没有产品组合清晰度** — 我的产品组合缺乏连贯的战略；我管理的是一系列路线图，而不是一个系统

**或者描述什么不起作用。**

#### 问题4C（Q3/3）：

**代理问：**

“您担任Director角色有多久了？”

1. **不到1年** — 仍在转型期
2. **1-2年** — 过了转型期；这感觉像是一种持续的模式
3. **2年以上** — 在角色中已确立；这已成为一个结构性问题

#### 分支4建议：

**代理提供（基于4B + 4C）：**

*示例输出，4B = 仍然像PM一样行动 + 4C = 1-2年：*

“一个在12个月以上担任Director的Director如果仍然在做IC工作，那么他们并没有在转型——他们已经陷入了一个不可持续的混合角色。以下是诊断和修复：

1. **精确地命名英雄综合症模式** — 跟踪未来两周：您有多少时间用于解决问题而不是指导能够解决问题的人？大多数处于这种模式的Director的IC工作时间在60-70%。目标是更接近20%。

2. **找出是什么让您陷入其中** — 通常有三个原因：(a) 您对自己的判断比对团队的判断更信任，(b) 团队还没有发展到没有您的帮助就能拥有事情，(c) 您正在获得强化IC行为的奖励信号（表扬、可见性）。是哪一个？

3. **为您的三个IC活动创建一个明确的交接** — 列出您最常做的三件事，PM应该拥有。对于每一项：写下“做得好”的样子，与PM讨论拥有它，然后在他们遇到困难时不要救援。通过失败进行指导是工作。

4. **改变奖励循环** — 作为PM时得到的表扬作为Director不会到来。Director的成功更安静、更延迟。找到新的信号：一个PM独自完成困难的利益相关者对话，一个团队创建自己的上下文级联，一个您做出的产品组合决策在压力下经受住了考验。开始注意到这些胜利。

5. **如果这种模式在1-2年后根深蒂固，请考虑角色是否适合您** — 有些人作为高级IC或Principal PM更快乐、更有效。这不是失败——这是自我认知。IC路径是合法的；留在Director角色中而像PM一样运作是不匹配的。

选择一个数字深入了解，或告诉我您想下一步做什么。”
