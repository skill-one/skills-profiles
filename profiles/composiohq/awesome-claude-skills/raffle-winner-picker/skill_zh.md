# 抽奖赢家选择器

这个技能可以从列表、电子表格或 Google Sheets 中随机选择赢家，用于赠送礼品和竞赛。

## 何时使用此技能

- 运行社交媒体赠送礼品
- 在活动中挑选抽奖赢家
- 随机选择调查或测试的参与者
- 从竞赛提交中挑选赢家
- 公平分配有限的席位或资源
- 随机分配团队

## 此技能的功能

1. **随机选择**：使用加密随机选择
2. **多源支持**：兼容 CSV、Excel、Google Sheets 或纯文本列表
3. **多赢家选择**：可以挑选一个或多个赢家
4. **防止重复**：确保同一个人不能重复中奖
5. **透明结果**：清晰展示选择过程
6. **赢家详情**：显示所有与赢家相关的信息

## 使用方法

### 从 Google Sheets

```
从这个 Google Sheet 中随机选择一行来挑选赠送礼品的赢家：[Sheet URL]
```

### 从本地文件

```
从 entries.csv 中随机挑选 3 个赢家
```

### 从列表

```
从这个列表中随机挑选一个赢家：
- Alice (alice@email.com)
- Bob (bob@email.com)
- Carol (carol@email.com)
...
```

### 多赢家选择

```
从 contest-entries.xlsx 中随机挑选 5 个赢家，确保不重复
```

## 功能

### 公平选择
- 使用安全的随机数生成
- 无偏见或模式
- 透明过程
- 可重复（带种子，用于验证）

### 排除
```
排除先前赢家后随机挑选一个赢家： 
Alice, Bob, Carol
```

### 加权选择
```
根据 "entries" 列的加权概率（1 条目 = 1 张票）挑选赢家
```

### 并列赢家
```
从列表中挑选 1 个赢家和 3 个并列赢家
```

## 示例工作流程

### 社交媒体赠送礼品
1. 将 Google 表单条目导出到 Sheets
2. "从 [Sheet URL] 中随机挑选一个赢家"
3. 验证赢家详情
4. 带时间戳公开宣布

### 活动抽奖
1. 创建包含参会者姓名和邮箱的 CSV 文件
2. "从 attendees.csv 中随机挑选 10 个赢家"
3. 导出赢家列表
4. 直接邮件通知赢家

### 团队分配
1. 拥有参与者列表
2. "将此列表随机分成 4 个均等的团队"
3. 审查分配结果
4. 分享团队名单

## 小贴士

- **记录过程**：保存时间戳和方法
- **公开宣布**：分享选择详情以示透明
- **检查资格**：验证赢家是否符合竞赛规则
- **准备备选方案**：若赢家不合格，挑选并列赢家
- **导出结果**：保存赢家列表以备记录
