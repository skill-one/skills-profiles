# 会议洞察分析器

这项技能将您的会议记录转化为关于您沟通模式的可操作洞察，帮助您成为更有效的沟通者和领导者。

## 何时使用此技能

- 分析跨多个会议的沟通模式
- 获取关于您的领导力和引导风格的反馈
- 识别您何时避免艰难对话
- 了解您的说话习惯和填充词
- 跟踪沟通技巧随时间的改进
- 准备带有具体例子的绩效评估
- 指导团队成员的沟通风格

## 此技能的功能

1. **模式识别**：识别会议中反复出现的模式，例如：
   - 避免冲突或间接沟通
   - 说话比例和轮流发言
   - 提问与陈述模式的对比
   - 积极倾听指标
   - 决策方法

2. **沟通分析**：评估沟通效果：
   - 清晰度和直接性
   - 填充词和犹豫用语的运用
   - 语气和情感模式
   - 会议控制和引导

3. **可操作反馈**：提供具体、带时间戳的示例，包括：
   - 发生了什么
   - 为什么重要
   - 如何改进

4. **趋势跟踪**：分析多个会议时比较模式随时间的变化

## 如何使用

### 基本设置

1. 将您的会议记录下载到文件夹（例如，`~/meetings/`）
2. 在Claude Code中导航到该文件夹
3. 询问您想要的分析

### 快速入门示例

```
分析此文件夹中的所有会议，并告诉我何时我避免了冲突。
```

```
查看过去一个月的会议，并识别我的沟通模式。
```

```
比较这两个会议文件夹之间的引导风格。
```

### 高级分析

```
分析此文件夹中的所有记录，并：
1. 识别我何时打断他人
2. 计算我的说话比例
3. 找到我避免直接反馈的时刻
4. 跟踪我使用填充词的情况
5. 展示积极倾听的良好示例
```

## 说明

当用户请求会议分析时：

1. **发现可用数据**
   - 扫描文件夹中的记录文件（.txt, .md, .vtt, .srt, .docx）
   - 检查文件是否包含发言人标签和时间戳
   - 确认会议的日期范围
   - 识别记录中的用户姓名/标识符

2. **澄清分析目标**
   
   如果未指定，询问他们想学习什么：
   - 具体行为（避免冲突、打断、填充词）
   - 沟通效果（清晰度、直接性、倾听）
   - 会议引导技巧
   - 说话模式和比例
   - 改进的增长领域

3. **分析模式**

   对于每个请求的洞察：
   
   **避免冲突**：
   - 寻找犹豫用语（"可能"、"有点"、"我认为"）
   - 间接措辞而非直接请求
   - 在紧张时转移话题
   - 同意但不承诺（"是的，但是..."）
   - 不解决明显问题
   
   **说话比例**：
   - 计算会议中说话的时间百分比
   - 统计打断次数（对用户和用户打断他人）
   - 测量平均说话回合长度
   - 跟踪提问与陈述的比例
   
   **填充词**：
   - 计算"嗯"、"啊"、"像"、"你知道"、"实际上"等词的数量
   - 记录每分钟或每回合的频率
   - 识别增加的情况（紧张、不确定）
   
   **积极倾听**：
   - 提问时引用他人的先前观点
   - 概括或总结他人的想法
   - 建立在他人贡献的基础上
   - 提出澄清问题
   
   **领导力与引导**：
   - 决策方法（指令性 vs. 协作性）
   - 如何处理分歧
   - 包含较沉默的参与者
   - 时间管理和议程控制
   - 跟进和行动项清晰度

4. **提供具体示例**

   对于每个发现的模式，包括：
   
   ```markdown
   ### [模式名称]
   
   **发现**：[模式的单句总结]
   
   **频率**：[X次跨Y次会议]
   
   **示例**：
   
   1. **[会议名称/日期]** - [时间戳]
      
      **发生什么**：
      > [记录中的实际引语]
      
      **为什么这很重要**：
      [解释影响或错失的机会]
      
      **更好的方法**：
      [具体的替代措辞或行为]
   
   [重复2-3个最强的示例]
   ```

5. **综合洞察**

   分析所有模式后，提供：
   
   ```markdown
   # 会议洞察总结
   
   **分析周期**：[日期范围]
   **分析的会议**：[X次会议]
   **总时长**：[X小时]
   
   ## 确定的关键模式
   
   ### 1. [主要模式]
   - **观察**：[您看到的内容]
   - **影响**：[为什么这很重要]
   - **建议**：[如何改进]
   
   ### 2. [第二个模式]
   [相同的结构]
   
   ## 沟通优势
   
   1. [优势1及示例]
   2. [优势2及示例]
   3. [优势3及示例]
   
   ## 增长机会
   
   1. **[领域1]**：[具体的可操作建议]
   2. **[领域2]**：[具体的可操作建议]
   3. **[领域3]**：[具体的可操作建议]
   
   ## 说话统计
   
   - 平均说话时间：[X%的会议]
   - 提问次数：[每次会议的平均值]
   - 填充词：[每分钟X次]
   - 打断次数：[每次会议X次给出/Y次收到]
   
   ## 下一步
   
   [3-5个具体的沟通改进行动]
   ```

6. **提供后续选项**
   - 在未来的会议中跟踪这些相同指标
   - 深入特定会议或模式
   - 与行业基准进行比较
   - 制定个人沟通发展计划
   - 生成绩效评估摘要

## 示例

### 示例1：避免冲突分析（受Dan Shipper启发）

**用户**： "我下载了所有的会议录音，并将它们放在一个文件夹中。告诉我所有我巧妙避免冲突的时刻。"

**输出**： 
```markdown
# 避免冲突模式

在15次会议中发现了23次您使用间接沟通或直接避免直接解决紧张情况的情况。

## 模式：对关键反馈的犹豫

**频率**：7次会议中的8次

**示例1：与Sarah的1对1会议** - 00:14:32

**发生什么**：
> "所以，我在想...可能我们最好，像，有可能考虑再次查看时间表？我是说，如果你认为这有道理。但是无论你觉得什么最好！"

**为什么这很重要**：
您需要解决Sarah的项目进度落后的问题，但犹豫用语（"可能"、"有可能"、"如果你认为"）和结尾的转移话题（"无论你觉得"）使她容易忽视紧迫性。

**更好的方法**：
"Sarah，项目进度落后两周。我们需要讨论什么阻碍了进展，并今天制定新的时间表。"

[其他示例...]

## 建议

1. **直接命名问题**在第一句话
2. **移除犹豫词**如"可能"、"有点"、"有点"
3. **提出具体问题**而不是暗示
4. **安排艰难对话**而不是随意提出
```

### 示例2：领导力引导

**用户**： "分析我的团队会议，并告诉我我的引导风格。"

**输出**： 提供关于以下方面的洞察：
- 您说话的次数与团队成员的比例（60% vs. 40%）
- 您提问与陈述的比例（3:1）
- 如何处理分歧（倾向于过快解决）
- 谁最不说话以及您是否引导他们
- 良好和错失的引导时刻示例

### 示例3：个人发展跟踪

**用户**： "比较Q1和Q2的会议，看看我的倾听技巧是否有所改进。"

**输出**： 创建比较分析，显示：
- 打断次数减少（每次会议8次→3次）
- 澄清问题增加（2次→每次会议7次）
- 积极建立他人想法的改进
- 具体示例显示差异
- 剩余的增长领域

## 设置技巧

### 获取会议记录

**来自Granola**（免费订阅Lenny的简报）：
- Granola自动转录您的会议
- 将记录导出到文件夹：[说明如何]
- 指向Claude Code该文件夹

**来自Zoom**：
- 启用云录制和转录
- 会议后下载VTT或SRT文件
- 存储在专用文件夹中

**来自Google Meet**：
- 使用Google Docs自动转录
- 将记录文档保存到文件夹
- 保存为.txt文件或授予Claude Code访问权限

**来自Fireflies.ai、Otter.ai等**：
- 批量导出记录
- 存储在本地文件夹中
- 运行文件夹分析

### 最佳实践

1. **一致的命名**：使用`YYYY-MM-DD - 会议名称.txt`格式
2. **定期分析**：每月或每季度查看趋势
3. **具体查询**：一次询问一个行为以深入分析
4. **隐私**：保留敏感会议数据在本地
5. **以行动为导向**：一次专注于一个改进领域
