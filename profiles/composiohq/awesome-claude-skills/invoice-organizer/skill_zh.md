# 发票组织器

这项技能能够将杂乱的发票、收据和财务文件文件夹转化为干净、适用于报税的归档系统，无需手动操作。

## 使用场景

- 准备报税季节，需要整理记录
- 管理来自多个供应商的业务费用
- 整理来自混乱文件夹或邮件下载的收据
- 设置自动发票归档以进行持续账务处理
- 按年份或类别归档财务记录
- 核销费用以申请报销
- 准备给会计师的文件

## 该技能的功能

1. **读取发票内容**：从PDF、图像和文档中提取信息：
   - 供应商/公司名称
   - 发票编号
   - 日期
   - 金额
   - 产品或服务描述
   - 付款方式

2. **统一重命名文件**：创建标准化的文件名：
   - 格式：`YYYY-MM-DD 供应商 - 发票 - 产品或服务.pdf`
   - 示例：`2024-03-15 Adobe - 发票 - 创意云.pdf`

3. **按类别组织**：分类到逻辑文件夹：
   - 按供应商
   - 按费用类别（软件、办公用品、差旅等）
   - 按时间段（年份、季度、月份）
   - 按税务类别（可抵扣、个人等）

4. **支持多种格式**：可处理：
   - PDF发票
   - 扫描的收据（JPG、PNG）
   - 邮件附件
   - 屏幕截图
   - 银行对账单

5. **保留原件**：在组织副本的同时保留原始文件

## 使用方法

### 基本使用

导航到您的混乱发票文件夹：
```
cd ~/Desktop/receipts-to-sort
```

然后询问Claude Code：
```
组织这些发票以备报税
```

或者更具体：
```
读取此文件夹中的所有发票，将它们重命名为"YYYY-MM-DD 供应商 - 发票 - 产品.pdf"格式，并按供应商组织
```

### 高级组织

```
组织这些发票：
1. 从每个文件中提取日期、供应商和描述
2. 重命名为标准格式
3. 按费用类别（软件、办公用品、差旅等）归档到文件夹
4. 创建包含所有发票详情的CSV电子表格以供我的会计师使用
```

## 说明

当用户请求发票组织时：

1. **扫描文件夹**

   识别所有发票文件：
   ```bash
   # 查找所有发票相关文件
   find . -type f \( -name "*.pdf" -o -name "*.jpg" -o -name "*.png" \) -print
   ```
   
   报告结果：
   - 文件总数
   - 文件类型
   - 日期范围（如果从名称中可识别）
   - 当前组织状态（或缺乏组织）

2. **从每个文件中提取信息**

   对每个发票，提取：
   
   **从PDF发票**：
   - 使用文本提取读取发票内容
   - 查找常见模式：
     - "发票日期："、"日期："、"签发："
     - "发票编号："、"发票编号："
     - 公司名称（通常在顶部）
     - "应付金额："、"总计："、"金额："
     - "描述："、"服务："、"产品："
   
   **从图像收据**：
   - 从图像中读取可见文本
   - 识别供应商名称（通常在顶部）
   - 查找日期（常见格式）
   - 找到总金额
   
   **对于不清晰的文件**：
   - 使用文件名线索
   - 检查文件创建/修改日期
   - 如果关键信息缺失，标记为手动审核

3. **确定组织策略**

   如果未指定，询问用户偏好：
   
   ```markdown
   我找到了[X]个来自[日期范围]的发票。
   
   您希望如何组织它们？
   
   1. **按供应商**（Adobe/、Amazon/、Stripe/等）
   2. **按类别**（软件/、办公用品/、差旅/等）
   3. **按日期**（2024/Q1/、2024/Q2/等）
   4. **按税务类别**（可抵扣/、个人/等）
   5. **自定义**（描述您的结构）
   
   或者我可以使用默认结构：年份/类别/供应商
   ```

4. **创建标准化文件名**

   对每个发票，创建符合此模式的文件名：
   
   ```
   YYYY-MM-DD 供应商 - 发票 - 描述.ext
   ```
   
   示例：
   - `2024-03-15 Adobe - 发票 - 创意云.pdf`
   - `2024-01-10 Amazon - 收据 - 办公用品.pdf`
   - `2023-12-01 Stripe - 发票 - 月度支付处理.pdf`
   
   **文件名最佳实践**：
   - 除连字符外，删除特殊字符
   - 正确大写供应商名称
   - 保持描述简洁但有意义
   - 使用一致的日期格式（YYYY-MM-DD）进行排序
   - 保留原始文件扩展名

5. **执行组织**

   在移动文件之前，显示计划：
   
   ```markdown
   # 组织计划
   
   ## 提议结构
   ```
   Invoices/
   ├── 2023/
   │   ├── Software/
   │   │   ├── Adobe/
   │   │   └── Microsoft/
   │   ├── Services/
   │   └── Office/
   └── 2024/
       ├── Software/
       ├── Services/
       └── Office/
   ```
   
   ## 示例变更
   
   之前：`invoice_adobe_march.pdf`
   之后：`2024-03-15 Adobe - 发票 - 创意云.pdf`
   位置：`Invoices/2024/Software/Adobe/`
   
   之前：`IMG_2847.jpg`
   之后：`2024-02-10 Staples - 收据 - 办公用品.jpg`
   位置：`Invoices/2024/Office/Staples/`
   
   处理[X]个文件？（是/否）
   ```
   
   经批准后：
   ```bash
   # 创建文件夹结构
   mkdir -p "Invoices/2024/Software/Adobe"
   
   # 复制（不要移动）以保留原始文件
   cp "original.pdf" "Invoices/2024/Software/Adobe/2024-03-15 Adobe - 发票 - 创意云.pdf"
   
   # 或者如果用户更喜欢移动
   mv "original.pdf" "new/path/standardized-name.pdf"
   ```

6. **生成摘要报告**

   创建包含所有发票详情的CSV文件：
   
   ```csv
   日期,供应商,发票编号,描述,金额,类别,文件路径
   2024-03-15,Adobe,INV-12345,创意云,52.99,软件,Invoices/2024/Software/Adobe/2024-03-15 Adobe - 发票 - 创意云.pdf
   2024-03-10,Amazon,123-4567890-1234567,办公用品,127.45,办公用品,Invoices/2024/Office/Amazon/2024-03-10 Amazon - 收据 - 办公用品.pdf
   ...
   ```
   
   此CSV文件可用于：
   - 导入会计软件
   - 与会计师共享
   - 费用跟踪和报告
   - 税务准备

7. **提供完成摘要**

   ```markdown
   # 组织完成！ 📊
   
   ## 摘要
   - **处理**：[X]个发票
   - **日期范围**：[最早]至[最新]
   - **总金额**：$[总和]（如果提取了金额）
   - **供应商**：[Y]个唯一供应商
   
   ## 新结构
   ```
   Invoices/
   ├── 2024/ (45个文件)
   │   ├── Software/ (23个文件)
   │   ├── Services/ (12个文件)
   │   └── Office/ (10个文件)
   └── 2023/ (12个文件)
   ```
   
   ## 创建的文件
   - `/Invoices/` - 组织后的发票
   - `/Invoices/invoice-summary.csv` - 用于会计的电子表格
   - `/Invoices/originals/` - 原始文件（如果复制）
   
   ## 需要审核的文件
   [列出任何信息无法完全提取的文件]
   
   ## 下一步
   1. 查看`invoice-summary.csv`文件
   2. 检查"需要审核"文件夹中的文件
   3. 将CSV导入您的会计软件
   4. 设置自动组织以供未来发票
   
   准备好报税季节！ 🎉
   ```

## 自动化设置

对于持续组织：

```
创建一个脚本，监视我的 ~/Downloads/invoices 文件夹 
并使用我们的标准命名和文件夹结构自动组织任何新的发票文件。
```

这创建了一个持久解决方案，可以在发票到达时自动组织。

## 专业技巧

1. **将邮件扫描为PDF**：使用预览或类似工具首先将邮件发票保存为PDF
2. **一致的下载**：将所有发票保存到一个文件夹以进行批量处理
3. **每月例行**：每月组织发票，而不是每年
4. **备份原件**：在重新组织之前保留原始文件
5. **在CSV中包含金额**：用于预算跟踪
6. **按可抵扣性标记**：注明哪些费用是可抵扣的
7. **保留收据7年**：标准的审计期限

## 处理特殊情况

### 缺少信息

如果日期/供应商无法提取：
- 标记文件以供手动审核
- 使用文件修改日期作为后备
- 创建"Needs-Review/"文件夹

### 重复发票

如果同一发票出现多次：
- 比较文件哈希值
- 保留最高质量版本
- 在摘要中注明重复

### 多页发票

对于跨文件分割的发票：
- 如有需要，合并PDF
- 使用一致的命名
- 如果发票分割，在CSV中注明

### 非标准格式

对于不寻常的收据格式：
- 尽可能提取信息
- 标准化可以的部分
- 如果关键信息缺失，标记为审核
