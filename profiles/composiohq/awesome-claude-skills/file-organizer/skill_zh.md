# 文件组织器

这项技能充当您的个人组织助理，帮助您在计算机上维护干净、逻辑清晰的文件结构，而无需承受持续手动组织的心理负担。

## 何时使用此技能

- 您的下载文件夹是一团糟
- 您找不到文件，因为它们散落在各处
- 您有重复文件占用空间
- 您的文件夹结构不再合理
- 您想建立更好的组织习惯
- 您开始新项目并需要一个良好的结构
- 您在归档旧项目前进行清理

## 此技能的功能

1. **分析当前结构**：检查您的文件夹和文件，了解您拥有什么
2. **查找重复文件**：识别系统中的重复文件
3. **建议组织**：根据您的内容提出逻辑的文件夹结构
4. **自动清理**：在您的批准下移动、重命名和组织文件
5. **保持上下文**：根据文件类型、日期和内容做出智能决策
6. **减少杂乱**：识别您可能不再需要的旧文件

## 说明

当用户请求文件组织帮助时：

1. **理解范围**

   提出澄清问题：
   - 哪个目录需要组织？（下载、文档、整个家目录？）
   - 主要问题是什么？（找不到东西、重复、太乱、没有结构？）
   - 有任何要避免的文件或文件夹吗？（当前项目、敏感数据？）
   - 组织的强度如何？（保守与彻底清理）

2. **分析当前状态**

   检查目标目录：
   ```bash
   # 获取当前结构的概览
   ls -la [目标目录]
   
   # 检查文件类型和大小
   find [目标目录] -type f -exec file {} \; | head -20
   
   # 识别最大的文件
   du -sh [目标目录]/* | sort -rh | head -20
   
   # 统计文件类型
   find [目标目录] -type f | sed 's/.*\.//' | sort | uniq -c | sort -rn
   ```
   
   总结发现：
   - 文件和文件夹总数
   - 文件类型分解
   - 大小分布
   - 日期范围
   - 明显的组织问题

3. **识别组织模式**

   根据文件确定逻辑分组：
   
   **按类型**：
   - 文档（PDF、DOCX、TXT）
   - 图片（JPG、PNG、SVG）
   - 视频（MP4、MOV）
   - 压缩文件（ZIP、TAR、DMG）
   - 代码/项目（包含代码的目录）
   - 电子表格（XLSX、CSV）
   - 演示文稿（PPTX、KEY）
   
   **按目的**：
   - 工作与个人
   - 活动与归档
   - 项目特定
   - 参考材料
   - 临时/草稿文件
   
   **按日期**：
   - 当前年份/月份
   - 前一年
   - 非常旧的（归档候选）

4. **查找重复文件**

   当请求时，搜索重复文件：
   ```bash
   # 通过哈希查找精确重复文件
   find [目录] -type f -exec md5 {} \; | sort | uniq -d
   
   # 查找同名文件
   find [目录] -type f -printf '%f\n' | sort | uniq -d
   
   # 查找相似大小的文件
   find [目录] -type f -printf '%s %p\n' | sort -n
   ```
   
   对于每一组重复文件：
   - 显示所有文件路径
   - 显示大小和修改日期
   - 建议保留哪个（通常是最新或命名最好的）
   - **重要**：删除前始终确认

5. **提出组织计划**

   在进行更改前提出清晰的计划：
   
   ```markdown
   # [目录] 组织计划
   
   ## 当前状态
   - X 个文件跨 Y 个文件夹
   - 总大小 [大小]
   - 文件类型：[分解]
   - 问题：[列出问题]
   
   ## 提议结构
   
   ```
   [目录]/
   ├── 工作/
   │   ├── 项目/
   │   ├── 文档/
   │   └── 归档/
   ├── 个人/
   │   ├── 照片/
   │   ├── 文档/
   │   └── 媒体/
   └── 下载/
       ├── 待整理/
       └── 归档/
   ```
   
   ## 我将进行的更改
   
   1. **创建新文件夹**：[列表]
   2. **移动文件**：
      - X 个 PDF → 工作/文档/
      - Y 张图片 → 个人/照片/
      - Z 个旧文件 → 归档/
   3. **重命名文件**：[任何重命名模式]
   4. **删除**：[重复或垃圾文件]
   
   ## 需要您决定的文件
   
   - [列出任何您不确定的文件]
   
   准备继续？(是/否/修改)
   ```

6. **执行组织**

   批准后，系统性地组织：
   
   ```bash
   # 创建文件夹结构
   mkdir -p "path/to/new/folders"
   
   # 清晰记录地移动文件
   mv "old/path/file.pdf" "new/path/file.pdf"
   
   # 使用一致的模式重命名文件
   # 示例："YYYY-MM-DD - 描述.ext"
   ```
   
   **重要规则**：
   - 删除任何东西前始终确认
   - 记录所有移动以备撤销
   - 保留原始修改日期
   - 优雅处理文件名冲突
   - 如遇意外情况，停止并询问

7. **提供总结和维护建议**

   组织完成后：
   
   ```markdown
   # 组织完成！✨
   
   ## 发生了什么变化
   
   - 创建了 [X] 个新文件夹
   - 组织了 [Y] 个文件
   - 通过删除重复文件释放了 [Z] GB
   - 归档了 [W] 个旧文件
   
   ## 新结构
   
   [显示新的文件夹树]
   
   ## 维护建议
   
   为保持组织：
   
   1. **每周**：整理新下载
   2. **每月**：审查并归档已完成的项目
   3. **每季度**：检查新的重复文件
   4. **每年**：归档旧文件
   
   ## 您的快速命令
   
   ```bash
   # 查找本周修改的文件
   find . -type f -mtime -7
   
   # 按类型整理下载
   [自定义命令，根据他们的设置]
   
   # 查找重复文件
   [自定义命令]
   ```
   
   想要组织另一个文件夹吗？
   ```

## 专业技巧

1. **从小处着手**：从一个混乱的文件夹（如下载）开始，以建立信任
2. **定期维护**：在下载上每周运行清理
3. **一致命名**：使用 "YYYY-MM-DD - 描述" 格式对重要文件进行命名
4. **积极归档**：将旧项目移动到归档而不是删除
5. **保持活动分离**：在活动工作和归档工作之间保持清晰的界限
6. **信任过程**：让 Claude 处理文件应该去哪的脑力负担

## 最佳实践

### 文件夹命名

- 使用清晰、描述性的名称
- 避免空格（使用连字符或下划线）
- 具体化： "客户提案" 而不是 "文档"
- 使用前缀进行排序： "01-当前"，"02-归档"

### 文件命名

- 包含日期： "2024-10-17-会议笔记.md"
- 描述性： "q3-财务报告.xlsx"
- 名称中避免版本号（使用版本控制）
- 删除下载残留物： "document-final-v2 (1).pdf" → "document.pdf"

### 何时归档

- 6 个月以上未触碰的项目
- 完成的可能以后会参考的工作
- 迁移到新系统后的旧版本
- 您犹豫删除的文件（先归档）
