# 定制简历生成器

## 何时使用此技能

- 申请特定职位
- 针对不同行业或角色定制简历
- 突出相关经验以实现职业转型
- 优化简历以适应ATS（申请人追踪系统）
- 为不同工作申请创建多个简历版本
- 强调职位描述中提到的特定技能

## 此技能的功能

1. **分析职位描述**：从职位发布中提取关键要求、技能、资格和关键词
2. **确定优先级**：根据职位描述的语言和结构确定雇主最看重的内容
3. **定制内容**：重新组织并强调相关经验、技能和成就
4. **优化关键词**：在简历中自然地融入ATS友好的关键词
5. **专业排版**：创建适合各种格式的简洁专业简历布局
6. **提供建议**：提出改进建议并突出需要弥补的差距

## 如何使用

### 基本使用方法
提供职位描述和您的背景信息：

```
我正在申请这个职位：

[paste job description]

这是我的背景：
- 5年软件工程师在TechCorp
- 带领3名开发人员进行移动应用项目
- 擅长Python、JavaScript、React
- State University计算机科学学位
```

### 使用现有简历
上传或粘贴您当前的简历以及职位描述：

```
请为我这个职位定制简历：

职位描述：
[paste job description]

我的当前简历：
[paste resume content]
```

### 职业转型
在转换行业或角色时：

```
我正在从市场营销转型到产品管理。
这是我申请的职位：

[paste job description]

我的可转移经验：
- 7年数字市场营销经验
- 带领跨职能团队
- 管理产品发布
- 数据分析和A/B测试
```

## 指导

当用户请求定制简历时：

### 1. 收集信息

**职位描述分析**：
- 如果未提供完整职位描述，请请求
- 询问公司名称和职位

**候选人背景**：
- 如果用户提供现有简历，将其作为基础
- 如果没有，请请求：
  - 工作经历（职位、公司、日期、职责）
  - 教育背景
  - 关键技能和技术专长
  - 显著成就和指标
  - 认证或奖项
  - 任何其他相关信息

### 2. 分析职位要求

提取并优先排序：
- **必须具备的资格**：工作经验、所需技能、教育
- **关键技能**：技术工具、方法、能力
- **软技能**：沟通、领导力、团队合作
- **行业知识**：特定领域的经验
- **关键词**：重复的术语、短语和ATS优化的热门词汇
- **公司价值观**：职位描述中的文化契合度指标

在脑海中绘制：
- 优先级1：关键要求（决定性因素）
- 优先级2：重要资格（强烈期望）
- 优先级3：锦上添花的技能（加分项）

### 3. 将候选人经验与要求匹配

针对每个职位要求：
- 从候选人背景中识别匹配的经验
- 如果没有直接匹配，找到可转移技能
- 记录需要弥补或弱化的差距
- 确定要突出的独特优势

### 4. 结构化定制简历

**专业概要**（3-4行）：
- 以目标角色/领域的年数经验开头
- 包含职位描述中要求的前3-4项技能
- 提及相关行业经验
- 突出独特的价值主张

**技术/核心技能部分**：
- 按照职位要求对技能进行分类
- 首先列出所需的工具和技术
- 使用职位描述中的确切术语
- 只包括您可以证明经验支持的技能

**专业经验**：
- 针对每个角色，强调与职位要求一致的职责和成就
- 使用行动动词：领导、开发、实施、优化、管理、创建、分析
- **量化成就**：包括数字、百分比、时间段、规模
- 重新排序要点以优先考虑最相关的经验
- 自然地使用职位描述中的关键词
- 格式：**[行动动词] + [内容] + [如何/为什么] + [结果/影响]**

**教育**：
- 列出与职位相关的学位、认证
- 如果是早期职业生涯，包括相关课程
- 添加与职位要求匹配的认证

**可选部分**（如果适用）：
- 认证和许可证
- 出版物或演讲活动
- 奖项和认可
- 志愿工作（如果与角色相关）
- 项目（尤其是技术角色）

### 5. 优化ATS（申请人追踪系统）

- 使用标准部分标题（专业经验、教育、技能）
- 自然地融入职位描述中的确切关键词
- 避免表格、图形、页眉/页脚或复杂格式
- 使用标准字体和项目符号
- 包括缩写和全称（例如，“SQL（结构化查询语言）”）
- 与职位术语保持一致

### 6. 格式和呈现

**格式选项**：
- **Markdown**：简洁、易读、易于复制
- **纯文本**：ATS优化、适用于所有系统
- **Word/PDF提示**：提供格式指导

**简历结构指南**：
- 10年以下经验保持1页，10年以上经验保持2页
- 使用一致的格式和间距
- 确保联系信息突出
- 使用倒序时间顺序（最近的优先）
- 保持简洁、可扫描的布局和空白

### 7. 提供战略建议

在展示定制简历后，提供：

**优势分析**：
- 候选人竞争力的原因
- 要在求职信或面试中强调的独特资格

**差距分析**：
- 未完全满足的要求
- 建议如何弥补差距（课程、项目、重新表述经验）

**面试准备提示**：
- 与简历对齐的关键谈话要点
- 基于职位要求准备的故事
- 提问以展示契合度的问题

**求职信钩子**：
- 建议求职信的2-3个开头句
- 要扩展的关键成就

### 8. 迭代和改进

询问用户是否希望：
- 调整重点或语气
- 添加或删除部分
- 为不同角色生成不同版本
- 创建格式变体（传统与现代）
- 为多个类似职位创建特定版本

### 9. 最佳实践

**要**：
- 真实准确 - 不要编造经验
- 使用行业标准术语
- 用具体指标量化成就
- 为每个职位定制简历
- 校对语法和一致性
- 保持语言简洁有力

**不要**：
- 包括个人信息（年龄、婚姻状况、照片，除非要求）
- 使用第一人称代词（我、我、我的）
- 包括推荐信（“可应要求提供”已过时）
- 如果职业生涯超过20年，不要列出每个工作（专注于相关、最近的经验）
- 使用未经定制的通用模板
- 超过2页，除非是高级职位

### 10. 特殊考虑

**职业转型者**：
- 使用功能或混合简历格式
- 强调可转移技能
- 创建引人入胜的概述
- 专注于相关项目和课程

**应届毕业生**：
- 以教育为先
- 包括相关课程、项目、实习
- 强调学生组织的领导力
- 如果GPA超过3.5，请包括

**高级管理人员**：
- 以执行摘要开头
- 侧重于领导力和战略影响
- 包括董事会成员、演讲活动
- 强调收入增长、团队建设、愿景

**技术角色**：
- 突出显示技术技能部分
- 列出编程语言、框架、工具
- 包括GitHub、作品集或项目链接
- 提及方法（敏捷、Scrum等）

**创意角色**：
- 包括作品集链接
- 突出创意成就和活动
- 提及工具和软件专长
- 考虑更创意的格式（同时保持ATS兼容性）

## 获取最佳结果的技巧

- **具体**：提供完整的职位描述和详细的背景信息
- **分享指标**：在描述经验时包括数字、百分比和可量化的成就
- **指示格式偏好**：让技能知道您是否需要ATS优化、创意或传统格式
- **提及限制**：分享任何特定要求（页限制、包含/排除部分）
- **迭代**：不要犹豫要求修订或替代方法
- **多个申请**：为不同角色生成不同的定制版本
