# 竞品广告提取器

此技能从广告库中提取您的竞争对手广告，并分析哪些广告效果良好——他们强调的问题、目标用例以及引起共鸣的文案/创意。

## 使用此技能的场景

- 研究竞品广告策略
- 为自己的广告寻找灵感
- 了解市场定位
- 识别成功的广告模式
- 分析有效的文案
- 发现新的用例或痛点
- 基于成熟概念规划广告活动

## 此技能的功能

1. **提取广告**：从 Facebook 广告库、领英等平台抓取广告
2. **捕获截图**：保存所有广告的视觉副本
3. **分析文案**：识别问题、用例和价值主张
4. **分类广告**：按主题、受众或格式分组
5. **识别模式**：发现常见的成功方法
6. **提供洞察**：解释为什么某些广告可能表现良好

## 如何使用

### 基本提取

```
从 Facebook 广告库中提取 [竞品名称] 的所有当前广告
```

```
抓取 [公司] 的广告并分析其文案
```

### 特定分析

```
获取 [竞品] 关于 [特定问题] 的所有广告。他们强调了哪些痛点？
```

### 竞品组合

```
从这 5 个竞品中提取广告：[列表]。比较他们的方法，告诉我哪些有效。
```

### 特定平台

```
获取 [竞品] 的领英广告，并分析其 B2B 定位策略
```

## 示例

**用户**："从 Notion 在 Facebook 广告库中提取广告，并告诉我他们的文案哪些效果良好。"

**流程**：
```
访问 Facebook 广告库...
搜索：Notion
找到：23 个活跃广告

提取截图...
[████████████████████] 100%

保存到：competitor-ads/notion/
- ad-001-collaboration.png
- ad-002-productivity.png
- ad-003-templates.png
...

分析文案...
```

**输出**：
```
# Notion 广告分析

## 概述
- 活跃广告总数：23
- 主要主题：生产力 (35%)、协作 (30%)、模板 (20%)、AI 功能 (15%)
- 广告格式：静态图片 (60%)、视频 (40%)
- CTA 模式："免费试用"、"立即开始"

## 他们强调的关键问题

1. **信息分散** (8 个广告)
   文案："停止在 10 个不同的工具之间切换"
   为什么有效：直接针对许多团队面临的问题

2. **会议过多** (5 个广告)
   文案："用异步更新取代不必要的会议"
   为什么有效：后疫情时代远程工作的痛点

3. **文档丢失** (4 个广告)
   文案："再也不用问'文件在哪里？'"
   为什么有效：普遍的职场困扰

## 成功的创意模式

### 模式 1：前后对比分割
- 展示混乱的工具环境 → 干净的 Notion 工作空间
- 用于 6 个表现优异的广告
- 视觉隐喻立即清晰

### 模式 2：功能展示
- 实际产品使用的 GIF
- 在 5 秒内展示特定功能
- 用于新功能 (AI、模板)

### 模式 3：社会证明
- "加入 2000 万用户" 的文案
- 客户标志
- 用于 4 个针对企业的广告

## 有效的文案

最佳标题：
1. "您的团队知识，终于在一个地方"
   → 以利益为导向，直接解决痛点

2. "一站式工作空间"
   → 清晰定位，广泛吸引

3. "真正帮助您工作的 AI"
   → 解决对 AI 的怀疑，实用角度

最佳正文文案模式：
- 短句（少于 10 个词）
- 关注结果而非功能
- 包含具体数字（"减少会议 50%"）

## 受众定位洞察

根据广告变化：
- 创始人：个人生产力角度
- 团队负责人：协作和对齐
- 企业：安全和合规提及
- 学生：免费计划、模板、组织

## 对您广告的建议

1. **测试"工具泛滥"的痛点**
   → 基于其广告频率的强烈共鸣

2. **使用产品截图而非抽象视觉**
   → 他们所有表现最好的广告都展示实际 UI

3. **先提出问题，再提供解决方案**
   → "厌倦了 X？" 比起 "推出 Y" 表现更好

4. **保持文案在 100 字以内**
   → 他们最短的广告似乎最频繁

5. **测试前后对比视觉格式**
   → 他们创意中的成熟模式

## 保存的文件
- 所有广告：~/competitor-ads/notion/
- 分析：~/competitor-ads/notion/analysis.md
- 最佳表现者：~/competitor-ads/notion/top-10/
```

**灵感来源**：Sumant Subrahmanya 在 Lenny's Newsletter 中的用例

## 您可以学习到什么

### 文案分析
- 他们强调哪些问题
- 他们如何与竞争者定位
- 引起共鸣的价值主张
- 目标受众细分

### 创意模式
- 哪些视觉风格有效
- 视频与静态图片的表现
- 色彩方案和品牌
- 布局模式

### 文案公式
- 标题结构
- CTA 模式
- 长度和语气
- 情感触发器

### 活动策略
- 季节性活动
- 产品发布方法
- 功能发布策略
- 再营销模式

## 最佳实践

### 法律与道德
✓ 仅用于研究和灵感
✓ 不要直接复制广告
✓ 尊重知识产权
✓ 使用洞察来启发原创创意
✗ 不要剽窃文案或窃取设计

### 分析技巧
1. **寻找模式**：哪些主题重复出现？
2. **随时间追踪**：每月保存广告以查看演变
3. **测试假设**：根据您的品牌调整成功模式
4. **按受众细分**：为不同目标受众提供不同信息
5. **比较平台**：领英与 Facebook 的文案不同

## 常见工作流程

### 广告活动规划
1. 提取竞品广告
2. 识别成功模式
3. 记录其文案中的空白
4. 借鉴独特角度
5. 草拟测试广告变体

### 定位研究
1. 获取 5 个竞品的广告
2. 绘制其定位
3. 发现未被满足的角度
4. 开发差异化文案
5. 与他们的方法进行测试

### 创意灵感
1. 按主题提取广告
2. 分析视觉模式
3. 记录色彩和布局趋势
4. 改编成功模式
5. 创建原创变体

## 成功技巧

1. **定期监控**：每月检查变化
2. **广泛研究**：也要看相邻的竞品
3. **保存所有内容**：建立参考库
4. **测试洞察**：进行自己的实验
5. **追踪表现**：A/B 测试受启发的概念
6. **保持原创**：用于灵感而非抄袭
7. **多个平台**：比较 Facebook、领英、抖音等

## 输出格式

- **截图**：所有广告保存为图片
- **分析报告**：洞察的 Markdown 摘要
- **电子表格**：包含广告文案、CTA、主题的 CSV
- **演示文稿**：表现最好的视觉幻灯片
- **模式库**：按方法分类
