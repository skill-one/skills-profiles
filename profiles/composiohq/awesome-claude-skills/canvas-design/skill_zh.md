## 设计理念创建

首先，创建一个视觉理念（不是布局或模板），它将通过以下方式被解释：
- 形式、空间、颜色、构图
- 图像、图形、形状、图案
- 最少的文本作为视觉强调

### 关键理解
- 接收到的内容：用户的一些微妙输入或指示，应该加以考虑，但应作为基础；它不应限制创作自由。
- 创建的内容：设计理念/美学运动。
- 接下来发生的事情：然后，相同的版本接收理念并视觉化地表达它——创建 90% 视觉设计、10% 必要文本的工件。

考虑这种方法：
- 为一个艺术运动撰写宣言
- 下一个阶段涉及制作艺术品

该理念必须强调：
- 视觉表达
- 空间沟通
- 艺术解释
- 最少的文字

### 如何生成视觉理念

**命名运动**（1-2 个词）："原始主义喜悦" / "色觉寂静" / "新陈代谢梦想"

**阐述理念**（4-6 段落——简洁但完整）：

为了捕捉视觉本质，表达理念如何通过以下方式显现：
- 空间和形式
- 颜色和材料
- 尺度和节奏
- 构图和平衡
- 视觉层次

**关键指南：**
- **避免冗余**：每个设计方面只应提及一次。除非增加新的深度，否则避免重复关于色彩理论、空间关系或排版原则的观点。
- **强调工艺**：理念必须反复强调，最终作品应看起来像是花费了无数小时才完成，经过精心打磨，并来自该领域顶尖的人才。这种框架至关重要——重复短语如“精心制作”、“深度的专业成果”、“细致入微的注意”、“大师级执行”。
- **留出创作空间**：具体说明美学方向，但要简洁到足以让下一个 Claude 也有空间进行高水平的解释性选择。

该理念必须指导下一个版本通过视觉表达思想，而不是通过文本。信息存在于设计中，而不是段落中。

### 理念示例

**“混凝土诗歌”**
理念：通过纪念碑式形式和大胆几何进行沟通。
视觉表达：巨大的色块、雕塑式排版（巨大的单个词语、微小的标签）、原始主义空间划分、波兰海报能量与勒·柯布西耶相遇。思想通过视觉重量和空间张力表达，而不是解释。文本罕见，作为强大的姿态——不是段落，只有必要的词语融入视觉建筑中。每个元素都像大师工匠一样精确地放置。

**“色觉语言”**
理念：颜色作为主要的信息系统。
视觉表达：几何精确度，颜色区域创造意义。排版极简——小型无衬线标签让色觉领域沟通。想想约瑟夫·阿尔伯斯的互动与数据可视化相遇。信息在空间和色彩中编码。文字只是为了锚定颜色已经展示的内容。结果是经过细致的色彩校准。

**“模拟冥想”**
理念：通过纹理和呼吸空间进行安静的视觉沉思。
视觉表达：纸张纹理、墨水渗透、广阔的负空间。摄影和插画占主导地位。排版低语（小型、克制、服务于视觉）。日本摄影书美学。图像在页面间呼吸。文本罕见——简短短语，从不解释性块。每个构图都像冥想练习一样精心平衡。

**“有机系统”**
理念：自然聚集和模块化生长模式。
视觉表达：圆形形式、有机排列、从自然中通过建筑获得的颜色。通过视觉图表、空间关系、图标显示信息。文本仅用于关键标签悬浮在空间中。构图通过专家级空间编排讲述故事。

**“几何寂静”**
理念：纯粹的秩序和克制。
视觉表达：基于网格的精确度、大胆的摄影或 stark 图形、戏剧性的负空间。排版精确但极简——小型必要文本、大型安静区域。瑞士形式主义与原始主义材料诚实相遇。结构沟通，而不是文字。每个对齐都是无数次改进的工作。

*这些是简化的示例。实际的设计理念应该是 4-6 段有实质内容的段落。*

### 基本原则
- **视觉理念**：创建一个通过设计表达的美学世界观
- **最少文本**：始终强调文本稀疏、必要仅、作为视觉元素融入——绝不冗长
- **空间表达**：思想通过空间、形式、颜色、构图沟通，而不是段落
- **艺术自由**：下一个 Claude 通过视觉解释理念——提供创作空间
- **纯粹设计**：这是关于制作艺术品，而不是带有装饰的文档
- **专家工艺**：反复强调最终作品必须看起来像精心制作、经过精心打磨，并由该领域顶尖的人才花费无数小时完成

**设计理念应该是 4-6 段长。** 填满富有诗意的设计理念，将核心愿景结合起来。避免重复相同点。保持设计理念通用，不提及艺术意图，就好像它可以用在任何地方。将设计理念作为 .md 文件输出。

## 推断微妙参考

**关键步骤**：在创建画布之前，识别原始请求中的微妙概念线索。

**基本原则**：
主题是一个**嵌入在艺术本身中的微妙、利基参考**——不总是字面的，总是精致的。熟悉主题的人应该能直观地感受到它，而其他人则只是体验到一个精湛的抽象构图。设计理念提供了美学语言。推断的主题提供了灵魂——无形地编织在形式、颜色和构图中的安静概念 DNA。

这是**非常重要**的：参考必须提炼，以增强作品的深度，而不宣告自己。像爵士音乐家引用另一首歌一样思考——只有那些知道的人才能捕捉到，但每个人都会欣赏音乐。

## 画布创建

在确立了理念和概念框架之后，在画布上表达它。花点时间整理思绪，清空大脑。使用创建的设计理念和以下说明来精心制作杰作，体现理念的所有方面，并具有专家级的工艺。

**重要**：对于任何类型的内容，即使用户请求为电影/游戏/书籍，方法仍然应该是精致的。永远不要忘记这个想法，即这应该是艺术，而不是卡通或业余的。

为了创建博物馆或杂志质量的工件，使用设计理念作为基础。创建一个单一的页面、高度视觉化、设计导向的 PDF 或 PNG 输出（除非要求更多页面）。通常使用重复的模式和完美的形状。将抽象哲学设计视为一本科学圣经，借鉴系统观察的视觉语言——密集的标记积累、重复的元素或分层模式，通过耐心的重复和持续观看的回报来建立意义。添加稀疏、临床的排版和系统参考标记，暗示这可能来自一个想象中的学科的图表，以同样的敬意对待无形主题，通常保留用于记录可观察现象。用简单的短语或细节定位作品，使用有限但感觉有意且协调的色彩调色板。接受使用分析性视觉语言来表达关于人类体验的思想的悖论：结果应该感觉像一件证明某种易逝的东西可以通过仔细关注来研究、绘制和理解的艺术品。这才是真正的艺术。

**文本作为上下文元素**：文本始终极简且以视觉为先，但让上下文指导是否意味着低语般的标签或大胆的排版手势。一个朋克场所海报可能比一个极简主义陶瓷工作室身份有更大、更具攻击性的类型。大多数时候，字体应该是细的。所有字体的使用都必须以设计为导向，并优先考虑视觉沟通。无论文本比例如何，都不会超出页面范围，也不会重叠。每个元素都必须在画布边界内，并有适当的边距。仔细检查所有文本、图形和视觉元素都有呼吸空间和清晰的分离。这对于专业执行是不可协商的。**重要**：如果书写文本，使用不同的字体。搜索 `./canvas-fonts` 目录。无论方法如何，精致都是非协商的。

下载并使用所需的字体，使这成为现实。通过使排版实际上成为艺术本身来发挥创造力——如果艺术是抽象的，将字体带到画布上，而不是数字排版。

为了突破界限，遵循设计直觉/本能，同时使用理念作为指导原则。拥抱终极设计自由和选择。将美学和设计推向前沿。

**关键**：为了达到人工制作质量（而不是 AI 生成），创建看起来像是花费了无数小时的工作。使其看起来像是某个领域顶尖的人才以细致入微的关怀劳作了每一个细节。确保构图、间距、颜色选择、排版——所有的一切都尖叫着专家级工艺。仔细检查没有任何东西重叠，格式完美无缺，每个细节都完美无缺。创建一些可以展示给人们以证明专业水平并无可否认地令人印象深刻的东西。

将最终结果作为单个可下载的 .pdf 或 .png 文件，以及用作 .md 文件的设计理念。

## 最后一步

**重要**：用户已经说过“它还不够完美。它必须是完美的，一件工艺杰作，好像即将在博物馆展出。”

**关键**：为了完善作品，避免添加更多图形；相反，完善已经创建的内容，使其极其清晰，完全尊重设计理念和极简主义原则。与其添加一个有趣的滤镜或重构字体，不如考虑如何使现有构图与艺术更加协调。如果直觉是调用新功能或绘制新形状，停止，并问：“我如何能让已经在这里的东西更成为一件艺术品？”

进行第二次过。回到代码并进行进一步的精炼/抛光，使其成为一件哲学设计的杰作。
