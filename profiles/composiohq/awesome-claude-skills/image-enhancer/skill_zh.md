# 图像增强

这项技能可以处理您的图像和截图，使其效果更好——更清晰、更锐利、更专业。

## 使用场景

- 提升博客文章或文档的截图质量
- 在社交媒体分享前增强图像
- 为演示文稿或报告准备图像
- 提升低分辨率图像
- 锐化模糊照片
- 清理压缩图像

## 功能说明

1. **分析图像质量**：检查分辨率、清晰度和压缩伪影
2. **提升分辨率**：智能提升图像
3. **增强清晰度**：增强边缘和细节
4. **减少伪影**：清理压缩伪影和噪点
5. **优化使用场景**：根据预期用途调整（网页、印刷、社交媒体）

## 小贴士

- 始终保留原始文件作为备份
- 对截图和数字图像效果最佳
- 可批量处理整个文件夹
- 如需指定输出格式（PNG 用于质量，JPG 用于更小的文件大小）
- 用于社交媒体时，请说明平台以获得最佳尺寸

## 常见使用场景

- **博客文章**：发布前增强截图
- **文档**：使 UI 截图清晰如水晶
- **社交媒体**：为 Twitter、LinkedIn、Instagram 优化图像
- **演示文稿**：提升图像以适应大屏幕
- **印刷材料**：增加分辨率以适应物理媒体
