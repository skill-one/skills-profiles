# CSV数据摘要工具

该技能分析CSV文件，并提供包含统计信息和可视化的综合摘要。

## 何时使用此技能

Claude应在用户以下情况时使用此技能：
- 上传或引用CSV文件
- 要求摘要、分析或可视化表格数据
- 请求从CSV数据中获取洞察
- 希望了解数据结构和质量

### 自动分析步骤：

**该技能通过首先检查数据，然后确定最相关的分析，智能地适应不同的数据类型和行业。**

1. **加载并检查** CSV文件到pandas DataFrame
2. **识别数据结构** - 列类型、日期列、数值列、类别列
3. **确定相关分析** 基于数据中实际包含的内容：
   - **销售/电商数据**（订单日期、收入、产品）：时间序列趋势、收入分析、产品表现
   - **客户数据**（人口统计、细分、区域）：分布分析、细分、地理模式
   - **财务数据**（交易、金额、日期）：趋势分析、统计摘要、相关性
   - **运营数据**（时间戳、指标、状态）：时间序列、性能指标、分布
   - **调查数据**（分类响应、评分）：频率分析、交叉制表、分布
   - **通用表格数据**：根据发现的列类型进行适应

4. **仅创建对特定数据集有意义的可视化**：
   - 仅当存在日期/时间戳列时才创建时间序列图
   - 仅当存在多个数值列时才创建相关性热图
   - 仅当存在分类列时才创建类别分布
   - 当相关时为数值分布创建直方图
   
5. **自动生成综合输出** 包括：
   - 数据概览（行数、列数、类型）
   - 与数据类型相关的关键统计和指标
   - 缺失数据分析
   - 多个相关可视化（仅适用那些）
   - 基于在本特定数据集中发现的模式的可操作洞察
   
6. **在一个完整的分析中呈现所有内容** - 无需后续提问

**示例适应：**
- 带有患者ID的医疗服务数据 → 侧重人口统计、治疗模式、时间趋势
- 库存数据带有库存水平 → 侧重数量分布、补货模式、SKU分析  
- 带有时间戳的网络分析数据 → 侧重流量模式、转化指标、一天中的时间分析
- 调查响应 → 侧重响应分布、人口统计细分、情感模式

### 使用方法

该技能提供一个Python函数 `summarize_csv(file_path)`，它：
- 接受CSV文件路径
- 返回包含统计的综合文本摘要
- 根据数据结构自动生成多个可视化

- 所有数值列都包含在统计摘要中
