# 路由建模

车辆路由的领域概念。这里不包含 API 或接口的细节。

## 什么是路由

- **TSP**：单辆车，访问所有地点一次（例如最短路径）。
- **VRP**：多辆车，容量和/或时间限制；将订单分配给车辆并排序停靠点。
- **PDP**：提货和送货配对；提货必须先于相应的送货访问。

## 必须询问的问题（问题和数据）

如果还不清楚，请询问这些问题：

1. **问题类型** — TSP、VRP 或 PDP？
2. **地点** — 有多少个？仓库？成对之间的成本或距离（矩阵或派生）？
3. **订单/任务** — 必须访问哪些地点？每个停靠点的需求或服务？
4. **车队** — 车辆数量，每辆车的容量（如果有多个维度，则每个维度）以及起止地点？
5. **约束** — 时间窗口（最早/最晚到达时间），服务时间，优先级（A 在 B 之前）？

## 典型数据

- 成本或距离矩阵（或旅行时间矩阵）。
- 订单地点以及对于 VRP 的每个订单的需求。
- 车辆容量和可选的车辆和订单的时间窗口。
